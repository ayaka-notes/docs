多年來，許多使用 Overleaf Community Edition 的人都對 Overleaf Server Pro 表現出濃厚的興趣。因為 Overleaf CE 有太多限制，例如：

* 沒有沙箱機制，LaTeX 編譯會以與容器相同的權限執行。
* 不支援切換 TeX Live 版本，每個版本都需要手動安裝。
* 沒有追蹤修訂功能，使協作撰寫與評論相當困難。
* 沒有 Git 整合，使本機 LaTeX 使用者難以加入協作專案。

然而，清楚且可靠的價格資訊一直很難找到。在 Overleaf 的網站上，唯一的選項就是聯絡業務。Server Pro 似乎無法由個人使用者直接購買。透過搜尋引擎，我們找到了一些價格資訊。

根據我們在社群中蒐集到的資訊，**Server Pro 的報價為**：

* 您需要購買 _至少_ 10 人的授權。
* 10 人授權約需 €3,477.61。（2024 年）
* 教育機構方面，20 位使用者每年 2640 歐元，50 位使用者 6050 歐元，100 位使用者 9963 歐元。
* Server Pro 僅在特定地區提供（例如不包含中國大陸）。

到了 2026 年，我們使用 ChatGPT Search 找出了更多曾購買 Overleaf Server Pro 的機構。

Overleaf Server Pro 的費用似乎約為每位使用者每年 \$300。美國較小規模的合約顯示，每位使用者的年費約為 \$320–\$370。大型機構協議可獲得較低的單一使用者價格。例如，馬克斯普朗克學會（Max Planck Society）的三年協議平均每位使用者每年約 €51。合約條款、支援與部署範圍可能有所不同。這些紀錄並非 Overleaf 官方價目表。

### 打造線上 LaTeX 編輯器？沒那麼簡單！

自 2026 年初以來，在 Claude 或 Codex 等程式碼代理的協助下，幾乎每個月都會出現一個 Overleaf 替代品。OpenAI 也推出了 [Prism](https://prism.openai.com/)，一款用於科學 LaTeX 寫作的產品。

儘管許多人大肆炒作「Overleaf 已死，Prism 將成為最好的免費 LaTeX 編輯器」的說法，但我們發現 Prism 距離成熟產品仍有很大的差距。

下方截圖擷取自 OpenAI 社群中關於 Prism 的討論。大多數評論都表示 Prism 錯誤很多，尚未達到可日常使用的程度。

**打造一個可靠的線上 LaTeX 編輯器絕非易事。** 根據我們的觀察，Prism 會在開啟專案時配置一個沙箱並使其持續運行，這很可能是因為 Codex 在背景中持續待命。如此一來，當使用者開始 AI 對話時，Codex 便能快速回應。在我們的測試中，每個沙箱約配置了 5 個 vCPU、6 GB 記憶體與 64 GB 磁碟空間。

當數千名使用者同時編輯 LaTeX 專案時，這種架構可能會帶來可觀的運算負擔。Ayakaleaf 採取了不同的做法：只有在要求編譯時才會建立沙箱。每次編譯限制為 1 個 vCPU 與 1 GB 記憶體，並在編譯完成後立即終止沙箱。這大幅降低了持續性的資源消耗，也讓大規模部署的容量規劃更加可預測。

更廣泛地說，Prism 說明了即使擁有強大的模型與成熟的開源軟體生態系，要將 AI 能力與可靠的線上開發環境結合仍然十分困難。AI 可以改善體驗，但無法取代紮實的系統工程。歸根究柢，使用者仰賴的是可靠、可預測且穩定的服務。

### 為什麼選擇 Ayakaleaf Pro？

**Ayakaleaf Pro** 是 Overleaf Community Edition 的分支，為自架部署帶來 Server Pro 等級與 SaaS 等級的功能，且不需要按使用者計費的授權。它與上游 Overleaf 程式碼庫保持同步，因此您能使用熟悉的相同編輯器與工作流程，並額外獲得：

* 沙箱化的 LaTeX 編譯
* 多個 TeX Live 版本
* 追蹤修訂與評論
* Git 與 GitHub 整合
* SSO 與管理面板
* 私有範本管理
* Zotero 與進階參考文獻搜尋
* Pandoc 匯入／匯出
* Python 指令碼執行器
* 無按使用者計費的授權費用

我們的目標是提供更完整的自架 Overleaf 體驗，而且不需要 Server Pro 授權或 SaaS 訂閱。Ayakaleaf Pro 保留了熟悉的 Overleaf 工作流程與上游相容性，同時新增了協作、管理、整合與安全編譯等功能。

### 為什麼我們總是在重新發明輪子？

有一個更廣泛的問題值得思考：_**當一個成熟的開源專案已經解決了大部分的困難問題時，為什麼人們的直覺往往是從頭重寫**_？

重新實作編輯器、即時協作層、編譯管線，以及多年來累積的各種邊緣案例修正，成本極其高昂，而且大部分心力都花在重新發現原始專案早已解決的問題上。在多數情況下，擴充一個穩固的基礎並將缺少的部分回饋給社群，才是更務實的工程選擇。

我真正想談的是這一點：

> _在 AI 時代，人們熱愛炫耀。_

「我打造了自己的 Overleaf」聽起來遠比「我為 Overleaf 加了一些功能」更令人印象深刻，所以人們更喜歡講前者的故事。這也是為什麼似乎每個月都會冒出一個新的「AI LaTeX 編輯器」。

但實際上，這些借助 AI 重寫的產品，遠遠比不上像 Overleaf 這樣經過十年真實環境考驗所累積的可靠性與成熟度。給它們兩個月，它們就會像二月時的聖誕玩具一樣被拋棄。相信我。
