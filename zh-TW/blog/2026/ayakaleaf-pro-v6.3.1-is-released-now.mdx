我們非常自豪地宣布推出 Overleaf Pro 6.3.1，這是社群中功能最強大、最豐富的線上 LaTeX 編輯器。修補版本通常只包含少數小修正，但這一版更進一步：除了數十項錯誤修正之外，還帶來五項新功能，並將您的專案連接到您早已在使用的地方，從 Dropbox、GitLab 到您終端機中的 AI 代理程式。

### 變更內容

* Dropbox 同步（早期預覽版）：讓每個專案與您自己的 Dropbox 雙向保持同步。
* GitLab 同步（早期預覽版）：與 GitLab.com 或您自行管理的 GitLab 雙向同步。
* MCP Server：讓 Claude Code、Codex、Cursor、VS Code 或 Gemini CLI 直接處理專案。
* GitHub Enterprise：將 GitHub 同步指向您自己的 GitHub Enterprise 執行個體。
* 手寫符號辨識：畫出符號，即可取得對應的 LaTeX 指令。
* `OVERLEAF_DISABLE_LOCAL_LOGIN`：隱藏電子郵件與密碼登入，讓使用者只能透過 SSO 登入。
* 由我們的 E2E 測試系統與內部 Horizon 問題調查（Internal Horizon Issue Investigation）發現的錯誤修正。
* 上游 Overleaf 6.3.1 修補。

<Info>

Dropbox 同步與 GitLab 同步在 6.3.1 中以**早期預覽版**推出，供灰度測試使用，並將在 v6.4.0 正式發布。在此之前，其設定與行為仍可能變更。兩者預設皆為關閉。如有任何問題，請在 [GitHub](https://github.com/ayaka-notes/ayakaleaf-pro/issues) 上回報。

</Info>

#### 功能 01：Dropbox 同步（預覽版）

有些人永遠不想碰 Git。他們只希望自己的論文是筆電上的一個資料夾，而 Dropbox 同步正好能做到。每位使用者連結自己的 Dropbox 帳號後，其擁有及與其共用的專案都會出現在 `Apps/<your app name>/` 下。在 Overleaf 中編輯，變更就會出現在 Dropbox 中。在本機用您喜愛的編輯器修改檔案並儲存，變更就會透過簽署的 webhook 回傳至 Overleaf。

對於管理員：必須啟用 Git bridge。在 Dropbox App Console 中建立應用程式，然後設定 `DROPBOX_ENABLED`、`DROPBOX_APP_KEY`、`DROPBOX_APP_SECRET`、`DROPBOX_APP_NAME` 與 `DROPBOX_TOKEN_CIPHER_PASSWORD`。`DROPBOX_SYNC_PROXY_URL` 為選用項目，適用於無法直接連線至 Dropbox 的伺服器。接著，在使用者連結帳號之前，一次性建立 Dropbox 同步所需的 MongoDB 索引。

完整的設定說明請參閱 [Dropbox 同步](/zh-TW/on-premises/configuration/overleaf-toolkit/dropbox-synchronisation  "mention")。

#### 功能 02：GitLab 同步（預覽版）

自 6.2 以來，GitHub 同步一直是我們最受喜愛的功能之一，而許多大學與公司則將程式碼存放在 GitLab 上。GitLab 同步的運作方式相同：連結您的帳號，從新增專案選單匯入儲存庫，或將專案匯出為新的 GitLab 專案。接著在編輯器中推送與拉取，並透過合併請求進行合併。

它支援 GitLab.com 以及 15.10 或更新版本的自行管理 GitLab。請設定 `GITLAB_SYNC_ENABLED`、`GITLAB_SYNC_CLIENT_ID`、`GITLAB_SYNC_CLIENT_SECRET` 與 `GITLAB_TOKEN_CIPHER_PASSWORD`，若為自行管理的執行個體，還需設定 `GITLAB_SYNC_URL`。

完整的設定說明請參閱 [GitLab 同步](/zh-TW/on-premises/configuration/overleaf-toolkit/gitlab-synchronisation  "mention")。

#### 功能 03：MCP Server

在 6.3 中，我們把 AI 助理放進了編輯器。在 6.3.1 中，我們從另一個方向打開大門：現在每個專案都有自己的 MCP Server，因此您早已在使用的 AI 代理程式可以直接處理您的論文。請 Claude Code 修正引言中的錯字，請 Codex 編譯並修正 LaTeX 錯誤，或請 Cursor 回覆尚未處理的審閱留言。代理程式會即時讀取與編輯檔案，因此您與協作者會看到它的編輯隨著輸入出現在編輯器中。它也可以編譯、讀取記錄、取得 PDF、計算字數並列出版本。

端點為 `/project/<project_id>/mcp`。請使用與 `git clone` 相同的 Git 權杖進行驗證。存取權限遵循專案的共用設定，因此檢視者的代理程式只能讀取而無法編輯，且每個工具都有速率限制。無需其他設定：MCP Server 會與 Git bridge 一同啟用。

<img src="https://github.com/user-attachments/assets/a8702201-db3f-4985-a050-b7ebdbe7a952" alt="MCP Server" width="787" />

如何連接各個 AI 用戶端，請參閱 [MCP Server](/zh-TW/on-premises/configuration/overleaf-toolkit/mcp-server  "mention")。

#### 功能 04：GitHub Enterprise

GitHub 同步不再侷限於 github.com。將 `GITHUB_SYNC_URL` 設為您的 GitHub Enterprise Server，或具備資料落地的 GitHub Enterprise Cloud（`GHE.com`），REST 與 GraphQL 端點就會由此推導。若您的執行個體有特殊之處，可使用 `GITHUB_SYNC_API_URL` 與 `GITHUB_SYNC_GRAPHQL_URL` 覆寫。若不設定，一切都會維持使用 github.com。

詳細資訊請參閱 [GitHub 同步](/zh-TW/on-premises/configuration/overleaf-toolkit/github-synchronisation#github-enterprise  "mention")。

#### 功能 05：手寫符號辨識

您知道符號長什麼樣子，卻不知道它叫什麼。是 `\varsigma` 還是 `\zeta`？是 `\models` 還是 `\vDash`？將符號面板切換為繪製模式，用滑鼠或觸控板畫出它，面板就會建議相符的 LaTeX 指令。

辨識完全在瀏覽器中執行，使用由 ayaka-notes 訓練的模型，因此您畫的任何內容都不會離開您的電腦。在不支援 `OffscreenCanvas` 的瀏覽器（例如 Safari 15）上，繪製切換按鈕會被隱藏。

#### 錯誤修正

此版本也帶來一長串修正。其中許多是由我們新的 E2E 測試系統發現的，該系統現在每天為每個模組執行測試套件；另一些則來自內部 Horizon 問題調查：每當我們修正一個錯誤，都會在關閉它之前，掃描整個程式碼庫中的同類問題。

* **身分驗證**：在啟用 SSO 的執行個體上，本機帳號可以設定與變更密碼，OIDC 使用者不再能變更自己的電子郵件。當名稱屬性有多個值時，LDAP、SAML 與 OIDC 登入不再失敗，SAML/OIDC 登出也恢復正常。
* **已停權的使用者**：停權使用者現在會結束其工作階段並關閉其開啟的編輯器，其 Git 權杖與 MCP 下載也會被拒絕。
* **GitHub 同步**：只有擁有者可以匯出專案，拉取期間所做的編輯會維持待處理狀態，空白檔案會被同步，手動合併會在 GitHub 上驗證。
* **Zotero / Mendeley**：當您的憑證失效時，會顯示重新連結的訊息，且匯入後會重新索引參考文獻。
* **外部服務**：對 Zotero、Mendeley、GitHub、GitLab 與網頁搜尋的請求，連線逾時由 1 秒改為 3 秒，因此較慢的網路不再失敗。
* **追蹤修訂**：審閱資料包含尚未載入的文件與尚未儲存的變更。
* **管理面板**：還原已刪除的專案、變更擁有者與編輯使用者皆能正常運作，電子郵件寄送失敗也不再影響帳號的建立或刪除。
* **範本庫**：無效的排序會回傳 400 而非 500，發布沒有主檔案的專案時會要求指定主檔案。

完整清單請參閱 [6.3.1 版本說明](/zh-TW/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.1  "mention")。

#### 升級

* 從 6.3.0 升級：無需遷移。拉取新映像檔並重新啟動即可。
* 從 6.2.x 或更早版本升級且有使用 Zotero 或 Mendeley：請先執行 6.3.0 的 [Zotero / Mendeley 遷移](/zh-TW/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention")。
* Dropbox 同步與 GitLab 同步預設為關閉。GitLab 同步只需要新的環境變數。Dropbox 同步還需要在使用者連結帳號之前，一次性建立其 MongoDB 索引：請參閱[建立資料庫索引](/zh-TW/on-premises/configuration/overleaf-toolkit/dropbox-synchronisation#create-the-database-indexes  "mention")。
