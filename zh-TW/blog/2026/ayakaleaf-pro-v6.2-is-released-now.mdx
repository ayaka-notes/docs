我們很榮幸宣布 Ayakaleaf Pro 6.2 正式發布，這是社群中功能最強大、最豐富的線上 LaTeX 編輯器。特別感謝 yu-i-i 與 davrot 的寶貴貢獻，他們強化了 GitHub Sync，並帶來了進階引用搜尋與 Zotero 整合。

### 注意事項

* 新增了必要的環境變數 `OVERLEAF_INVITE_TOKEN_SECRET`，您必須使用 `openssl rand -base64 32` 產生它。若未設定，您的 Overleaf 執行個體將無法啟動。
* 若您啟用 GitHub Sync，則必須設定 `GITHUB_TOKEN_CIPHER_PASSWORD` 環境變數。此變數用於安全地加密 GitHub 存取權杖。若未設定，您的 Overleaf 執行個體將無法啟動。
* 新增 `DEFAULT_LATEX_COMPILER` 環境變數，用於設定新專案的預設編譯器（pdflatex、latex、xelatex 或 lualatex 其中之一）。
* 重新設計的編輯器現在是唯一可用的選項。

### 變更內容

此版本包含以下改進與新功能。

* `MAX_UPLOAD_SIZE` 現在可以自行設定，不再受限於 **50 MB**。
* 修正停用沙箱編譯時容器不斷重新啟動的問題。
* 針對 OAuth2 強制僅限擁有者刪除 PAT。
* 修正 LDAP 匯入問題。

新功能包括：

* 新增瀏覽器端的 Python 執行器。
* 新增 Pandoc 支援，可匯入與匯出 Markdown、DOCX 及其他格式。
* 新增 GitHub Sync。
* 新增完整的中文翻譯。
* 新增 Zotero 整合。
* 新增 `DEFAULT_LATEX_COMPILER`。

#### 功能 01：GitHub Sync

讓您的 LaTeX 專案與 GitHub 儲存庫保持同步，打造流暢的開發工作流程。直接在編輯器中推送與拉取變更、透過 pull request 協作，並與現有的 CI/CD 管線整合。版本控制讓您輕鬆追蹤修訂、審閱變更，並維護可重現的學術或技術文件。

請參閱：[GitHub 同步](/zh-TW/on-premises/configuration/overleaf-toolkit/github-synchronisation  "mention")。

![](https://github.com/user-attachments/assets/5137e708-77cb-4fdf-b081-4aa04b4b762e)

#### 功能 02：Pandoc 匯入／匯出

將 Microsoft Word 與 Markdown 文件匯入為可完整編輯的 LaTeX 專案，或一鍵將 LaTeX 專案匯出為 Markdown 與 DOCX。此功能由 Pandoc 驅動，可在學術寫作、協作編輯與出版工作流程之間無縫互通，並盡可能保留文件結構。

請參閱：[Pandoc 匯入與匯出](/zh-TW/on-premises/configuration/overleaf-toolkit/pandoc-import-and-export  "mention")。

<img src="https://github.com/user-attachments/assets/085a94a0-c673-46fe-9da4-7a5a68e46589" alt="" width="563" />

#### 功能 03：進階文獻搜尋

從多個學術資料庫搜尋並插入書目文獻，支援智慧篩選與即時引用。快速探索論文、預覽中繼資料，並建立正確的 BibTeX 條目，無須在不同的研究網站之間切換，大幅提升文獻回顧的效率。

![image](https://github.com/user-attachments/assets/42e45b73-af4b-4d1f-81f4-9e116ba5d043)

#### 功能 04：Python 執行器

無須離開編輯器，即可直接在專案中執行 Python 程式碼。非常適合用來產生圖表、處理資料集、自動化文件工作流程，或執行可重現的研究腳本。執行結果可整合到您的 LaTeX 文件中，讓科學運算與寫作成為統一工作流程的一部分。

![image](https://github.com/user-attachments/assets/a4c314b3-fdb5-4836-aea7-12eeece5cd2f)

#### 功能 05：Zotero

將您的 Zotero 文獻庫直接連接到寫作流程，無須離開編輯器即可管理參考文獻。搜尋您個人的 Zotero 收藏、一鍵插入引用，並自動產生與同步 BibTeX 條目。此整合可讓您的參考書目保持最新，簡化學術論文、學位論文與技術文件的文獻管理。

請參閱：[Zotero 整合](/zh-TW/on-premises/configuration/overleaf-toolkit/zotero-integration  "mention")。
