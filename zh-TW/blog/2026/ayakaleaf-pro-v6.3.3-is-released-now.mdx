我們非常自豪地宣布 Overleaf Pro 6.3.3 正式發布。上游 Overleaf 6.3.3 是一個安全性版本，更新了 Node.js 與已安裝的套件。我們將它與新管理面板的早期預覽、每個帳戶多個電子郵件、更強大的 MCP Server 以及更好的 AI 助理一同推出。

### 變更內容 {#changes}

* 新管理面板（早期預覽）：使用者、專案與範本頁面、稽核日誌，以及依使用者開關的功能。
* 每個帳戶多個電子郵件（早期預覽）。
* MCP Server：歷史記錄、追蹤修訂、留言、聊天與檔案移動。
* AI 助理：OpenAI Responses API，以及 PDF 附件、讀取網頁與長對話（早期預覽）。
* 註冊與登入：reCAPTCHA v2 與公開註冊的電子郵件網域清單（早期預覽）。
* Node.js 24.22.3 與套件更新：上游 Overleaf 6.3.3 中的安全性更新。
* 由我們的 E2E 測試系統與內部 Horizon 問題調查（Internal Horizon Issue Investigation）發現的錯誤修正。

<Info>

新管理面板、多個電子郵件、AI 助理附件與新的註冊選項在 6.3.3 中以**早期預覽**形式提供，用於灰度測試，並將於 v6.4.0 正式發布。在此之前，它們的行為仍可能改變。如有任何問題，請在 [GitHub](https://github.com/ayaka-notes/ayakaleaf-pro/issues) 上回報。

</Info>

#### 功能 01：新管理面板（預覽版） {#feature-01-new-admin-panel-preview}

為實驗室或系所執行執行個體，每週都會遇到同樣的問題：為什麼這位學生無法登入、是誰給了那個帳戶管理員權限、去年的論文跑到哪裡去了。新管理面板為所有使用者與所有專案各提供一份清單，為每位使用者與每個專案提供個別頁面，還有範本管理與稽核日誌。管理員可以一次對多位使用者執行操作，在無法寄送電子郵件時複製啟用與密碼連結，並為單一使用者開啟或關閉 Dropbox、Git、AI 助理、追蹤修訂與符號面板等重要功能。

#### 功能 02：每個帳戶多個電子郵件（預覽版） {#feature-02-multiple-emails-per-account-preview}

使用者可透過寄送到每個信箱的驗證碼為帳戶新增更多電子郵件，並可將另一個設為主要電子郵件，例如在大學信箱被收回之前。只有主要電子郵件可以登入並接收密碼重設信。當執行個體可以寄送電子郵件時，此功能即會開啟。

請參閱 [多個電子郵件](/zh-TW/on-premises/user-guide/users/multiple-emails  "mention")。

#### 功能 03：MCP Server {#feature-03-mcp-server}

Claude Code、Codex 或 Cursor 等 AI 用戶端現在可以瀏覽專案歷史並還原版本、審閱追蹤修訂、將自己的編輯作為追蹤修訂、對文字新增留言、閱讀與傳送聊天訊息，以及移動或重新命名檔案。MCP Server 現在有 33 個工具，先前為 17 個。

請參閱 [MCP Server](/on-premises/user-guide/users/mcp-server  "mention")。

#### 功能 04：OpenAI Responses API {#feature-04-openai-responses-api}

OpenAI 較新的推理模型（例如 gpt-6.x）在 Chat Completions 上拒絕函式工具，因此 AI 助理與錯誤助理無法使用它們。設定 `AI_API_MODE=responses` 即可改為呼叫 OpenAI Responses API。附件與 token 配額照常運作。

請參閱 [AI 整合](/zh-TW/on-premises/configuration/overleaf-toolkit/integrations/ai-integration  "mention")。

#### 功能 05：AI 助理改進（預覽版） {#feature-05-ai-assistant-improvements-preview}

除了圖片，還可以附加最大 2 MB 的 PDF 檔案，並可透過選用的 `AI_PDF_MODEL` 指定能讀取 PDF 的模型。助理會透過 linked URL 代理讀取網頁，並在搜尋網路時知道當天日期。長對話會被摘要，舊的工具輸出會被壓縮，讓對話能持續進行而不會塞滿模型的上下文。

請參閱 [AI 助理](/on-premises/user-guide/users/ai-assistant  "mention")。

#### 功能 06：註冊與登入（預覽版） {#feature-06-sign-up-and-login-preview}

設定 `RECAPTCHA_SITE_KEY` 與 `RECAPTCHA_SECRET_KEY`，即可用 reCAPTCHA v2 保護登入、LDAP 登入、註冊與密碼重設。`OVERLEAF_ALLOW_PUBLIC_REGISTRATION` 現在接受電子郵件網域清單，例如 `@example.edu,@*.example.org`，或以 `@*` 表示任何網域。登入與註冊頁面會在卡片中顯示表單。

請參閱 [reCAPTCHA](/zh-TW/on-premises/configuration/overleaf-toolkit/authentication/recaptcha  "mention") 與 [公開存取](/zh-TW/on-premises/configuration/overleaf-toolkit/authentication/public-access  "mention")。

#### 錯誤修正 {#bug-fixes}

* **管理面板**：已被刪除的管理員在稽核日誌與「Deleted by」中仍以電子郵件顯示，徹底清除後則顯示為「Deleted user」。直接要求停用、刪除或降級自己帳戶的請求會被拒絕。
* **AI 助理**：未設定 `AI_PDF_MODEL` 時，包含 PDF 檔案與圖片的對話會送往 `AI_MODEL`，而不是可能無法讀取 PDF 檔案的圖片模型。
* **範本庫**：編輯只接受表單中的欄位，非文字欄位會回應 400 而不是 500。
* **Git bridge**：複製指令會在複製區塊的邊緣換行，而不是在標點符號處換行。

完整清單請參閱 [6.3.3 版本說明](/zh-TW/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.3  "mention")。

#### 升級 {#upgrade}

* 從 6.3.2、6.3.1 或 6.3.0 升級：不需要遷移。拉取新映像檔並重新啟動即可。
* 從 6.2.x 或更早版本升級且有使用 Zotero 或 Mendeley：請先執行 6.3.0 的 [Zotero / Mendeley 遷移](/zh-TW/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention")。
* 新管理面板取代舊面板。多個電子郵件需要郵件寄送功能；reCAPTCHA、網域清單與 `AI_API_MODE` 只需要新的環境變數。
