### 作業系統

為了在執行 Overleaf 時獲得最佳體驗，我們強烈建議使用**以 Debian 為基礎**的作業系統，例如 **Ubuntu**。這與軟體的開發環境一致，也是大多數 Overleaf 使用者的首選。

<Danger>

在 Server Pro 中使用沙箱編譯時，**請特別注意**應用程式需要以 root 權限存取 Docker socket。

</Danger>

### 相依套件

* Docker 25.0 與 29
* MongoDB 7.0 與 8.0
* Redis 6.2 與 7.5

<Info>

您可以透過 endoflife.date 服務追蹤上述相依套件及其他熱門產品的生命週期結束（EOL）日期：[https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

執行 Server CE 或 Server Pro 時，`docker compose` 會自動拉取 MongoDB 與 Redis，除非已設定為使用其他安裝。

</Info>

Toolkit 相依於下列程式：

* bash
* Docker

`docker compose` 為必要項目，通常會隨 Docker 一併安裝。

我們建議您安裝適用於您作業系統的最新版 Docker。

正確安裝 Docker 後，您應該能順利執行下列指令而不發生錯誤：

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2)
docker compose version

# List the running Docker containers on your system
docker ps
```
