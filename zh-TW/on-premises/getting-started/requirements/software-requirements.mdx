### 作業系統 {#operating-systems}

對於共用與正式環境的伺服器，我們建議使用**以 Debian 為基礎的 Linux** 系統，例如 **Ubuntu**。Ayakaleaf Pro 也可以在[搭配 Docker Desktop 的 macOS](/zh-TW/on-premises/installation/using-docker-compose/macos) 以及[搭配 WSL 2 與 Docker Desktop 的 Windows](/zh-TW/on-premises/installation/using-docker-compose/windows) 上執行。這三種平台都使用 Linux 容器與相同的 Toolkit；請依照你主機作業系統對應的指南操作。

<Danger>

使用沙箱編譯時，**務必**注意該應用程式需要以 root 權限存取 Docker socket。

</Danger>

### 相依套件 {#dependencies}

* Docker 25.0 與 29
* MongoDB 7.0 與 8.0
* Redis 6.2 與 7.5

<Info>

你可以使用 endoflife.date 服務追蹤上述相依套件及其他熱門產品的生命週期結束（EOL）日期： [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

執行 Ayakaleaf Pro 時，`docker compose` 會自動拉取 MongoDB 與 Redis，除非已設定使用其他安裝。

</Info>

Toolkit 相依於下列程式：

* bash
* Docker

`docker compose` 為必要元件，通常會隨 Docker 一併安裝。

我們建議你安裝作業系統可用的最新版 Docker。

正確安裝 Docker 後，你應該可以無誤地執行下列指令：

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2 or later, such as v5)
docker compose version

# List the running Docker containers on your system
docker ps
```
