在進行任何 Overleaf 安裝之前，請務必詳細閱讀本節內容。

### 安裝 Server Pro 與 Community Edition 的需求

<Warning>

我們強烈建議您在近期且穩定的 Ubuntu 版本（例如 2025–2026 年的 Ubuntu 24.04）上，搭配較新版本的 Docker 執行 Server Pro。雖然也可以在其他系統上執行 Server Pro，但對於非預設的 Ubuntu/Docker 環境，我們將更難以提供支援。此外，我們也無法針對 Docker 本身的問題提供支援。

</Warning>
