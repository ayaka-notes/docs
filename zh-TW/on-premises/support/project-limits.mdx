---
title: 專案限制
icon: list-check
---

| 功能                                             | 限制                                                                                                                                                                    |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 編譯逾時                                         | **預設：** 180 秒。如需自訂此值，請參閱[更新專案編譯逾時](/zh-TW/on-premises/user-and-project-management/project-management)。                                          |
| 每個專案的檔案數量上限                           | 2000                                                                                                                                                                    |
| 每個專案可編輯內容的大小上限                     | **預設：** 7 MB。如需自訂此值，請參閱[環境變數](/zh-TW/on-premises/configuration/overleaf-toolkit/environment-variables)。                                              |
| 單一可編輯文字檔的大小上限                       | 2 MB\*                                                                                                                                                                  |
| 單次上傳的大小上限                               | 50 MB（可透過 `MAX_UPLOAD_SIZE` 設定）                                                                                                                                  |
| 上傳之 .zip 檔解壓縮後的大小上限                 | 6 × `MAX_UPLOAD_SIZE`（預設為 300 MB）                                                                                                                                  |
| 專案大小上限                                     | 無限制†                                                                                                                                                                 |
| 專案數量上限                                     | 無限制                                                                                                                                                                  |

\* 在某些情況下，部分較大的檔案仍可能保持可編輯狀態。不過，為確保檔案可以編輯，建議將其大小限制在 2 MB 以內。

† 專案總大小沒有強制限制。不過，在處理非常大的專案時，您可能會遇到一些技術上的限制。我們建議專案大小不超過 500 MB；若使用我們的 [Git 整合](https://www.overleaf.com/learn/how-to/Git_integration)，則建議小於 100 MB。超過這些大小的專案或許仍可運作，但維持在這些限制之內能帶來最佳的使用體驗。
