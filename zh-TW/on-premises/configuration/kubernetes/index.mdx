Kubernetes 部署讀取的環境變數與 Toolkit 相同。當 Toolkit 頁面寫著「將此加入 `config/variables.env`」時，請將該值放入 ConfigMap `overleaf-env`；若該值是密碼、金鑰或權杖，則放入 Secret `overleaf-secrets`。然後重新啟動：

```bash
kubectl -n overleaf apply -f 30-config.yaml        # after editing the ConfigMap
kubectl -n overleaf patch secret overleaf-secrets --type merge \
  -p '{"stringData":{"GITHUB_TOKEN_CIPHER_PASSWORD":"'"$(openssl rand -hex 32)"'"}}'
kubectl -n overleaf rollout restart deployment/overleaf
```

`config/overleaf.rc` 中的值是 Toolkit 的設定，而非環境變數；本頁最後的問與答說明了取代它們的方式。

### 憑證與其他檔案

部分功能接受檔案路徑而非值：SAML 憑證（`OVERLEAF_SAML_IDP_CERT`、...）、LDAP CA（`OVERLEAF_LDAP_TLS_OPTS_CA_PATH`），或自行託管之 GitHub Enterprise、GitLab 或 Gitea 的私有 CA（`NODE_EXTRA_CA_CERTS`）。請將這些檔案放入 Secret，並將其掛載至 Toolkit 頁面所預期的位置 `/var/lib/overleaf/certs`：

```bash
kubectl -n overleaf create secret generic overleaf-certs --from-file=idp_cert.pem --from-file=ca.pem
```

```yaml title="40-overleaf.yaml (additions)"
          volumeMounts:
            # ...
            - name: certs
              mountPath: /var/lib/overleaf/certs
              readOnly: true
      volumes:
        # ...
        - name: certs
          secret:
            secretName: overleaf-certs
```

接著在 ConfigMap 中以路徑參照這些檔案，例如 `NODE_EXTRA_CA_CERTS: /var/lib/overleaf/certs/ca.pem`，然後重新啟動。

<Warning>

<strong>加密密碼。</strong>請在 Secret 中設定您所使用之功能的每一個 `*_CIPHER_PASSWORD`。否則，部分功能會在首次使用時於資料磁碟區中產生金鑰檔案：在一個副本的情況下，這在磁碟區遺失之前都能運作；在多個副本的情況下，每個副本會使用不同的金鑰進行加密。

</Warning>

### 問與答

<Accordion title="我需要 `config/overleaf.rc` 中的哪些 Toolkit 設定？">

<strong>回答：</strong>Ayakaleaf Pro 不會讀取其中任何一項。它們在 Kubernetes 中的對應方式如下：

| `config/overleaf.rc`                         | Kubernetes                                                        |
| -------------------------------------------- | ----------------------------------------------------------------- |
| `OVERLEAF_LISTEN_IP`、`OVERLEAF_PORT`        | Service（NodePort）或您的 ingress                                 |
| `SIBLING_CONTAINERS_ENABLED`                 | ConfigMap 中的 `SANDBOXED_COMPILES*`，以及 pod 中的 Docker socket |
| `GIT_BRIDGE_ENABLED`                         | [Git 整合](/zh-TW/on-premises/configuration/kubernetes/integrations/git-integration)                             |
| `MONGO_ENABLED`、`REDIS_ENABLED`、`MONGO_URL`、`REDIS_HOST` | StatefulSet 或您的託管服務、`OVERLEAF_MONGO_URL` 與 `OVERLEAF_REDIS_HOST` |
| `REDIS_AOF_PERSISTENCE`                      | `20-redis.yaml` 中的 `--appendonly yes`                           |
| `NGINX_ENABLED`、`TLS_*`                     | 您的 ingress 或負載平衡器                                         |

</Accordion>
