**web** 服務會在使用者註冊、設定或變更密碼時檢查本機密碼。SSO 登入（LDAP、SAML、OIDC）不受影響；它們的密碼由身分提供者負責。Toolkit 的說明請參閱[密碼限制](/zh-TW/on-premises/configuration/overleaf-toolkit/authentication/password-restrictions)。

| | |
| --- | --- |
| 服務 | web，位於每個 Ayakaleaf Pro pod 中；於 web 啟動時讀取 |
| 網路 | 無 |
| 定期工作 | 無 |

### 設定

加入 ConfigMap `overleaf-env` 並重新啟動：

```yaml title="30-config.yaml (additions)"
  OVERLEAF_PASSWORD_VALIDATION_MIN_LENGTH: "12"
  OVERLEAF_PASSWORD_VALIDATION_MAX_LENGTH: "72"
```

```bash
kubectl apply -f 30-config.yaml
kubectl -n overleaf rollout restart deployment/overleaf     # or statefulset/overleaf
```

| 變數 | 預設值 | |
| --- | --- | --- |
| `OVERLEAF_PASSWORD_VALIDATION_MIN_LENGTH` | `8` | 可接受的最短密碼長度。 |
| `OVERLEAF_PASSWORD_VALIDATION_MAX_LENGTH` | `72` | 可接受的最長密碼長度；大於 `72` 的值會視為 `72`。 |

請為數字加上引號：ConfigMap 只能存放字串。

<Warning>

`OVERLEAF_PASSWORD_VALIDATION_PATTERN` 會被讀取但不會強制執行：不符合該模式的密碼仍會被接受。只有長度限制會生效。

</Warning>

### 多個副本

不需要額外處理：每個副本都讀取相同的 ConfigMap。

### 在 Kubernetes 上的測試

在 Kubernetes 1.37 上以一個副本進行測試，於 ConfigMap 中設定 `OVERLEAF_PASSWORD_VALIDATION_MIN_LENGTH: "12"` 與 `OVERLEAF_PASSWORD_VALIDATION_PATTERN: aA$3`，啟用新帳號時拒絕了 10 個字元的密碼，並接受了僅由小寫字母組成的 20 個字元密碼，而該密碼原本會被模式拒絕。我們針對註冊的端對端測試也會在預設值下以過短為由拒絕 `123456`。
