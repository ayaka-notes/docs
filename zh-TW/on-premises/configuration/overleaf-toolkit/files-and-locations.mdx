本頁說明 Toolkit 用來設定 Overleaf 本地部署的各個設定檔。

### 持久性資料

Overleaf Toolkit 需要儲存持久性資料，例如編譯 LaTeX 專案所需的檔案，以及 MongoDB 資料庫的內容。這是透過將主機上的幾個目錄掛載到 Docker 容器中，並將資料寫入這些目錄來達成的。

#### 資料目錄

`sharelatex` 容器需要一個目錄來儲存與 LaTeX 編譯相關的資料。此目錄由 `config/overleaf.rc` 中的 `OVERLEAF_DATA_PATH` 變數設定。

`mongo` 容器（若已啟用）需要一個目錄來儲存其資料庫檔案，`redis` 容器也是如此。這些目錄同樣可以在 `config/overleaf.rc` 中設定。

#### 檔案權限

由於 Docker 以 `root` 身分執行，即使 Toolkit 是由非 root 使用者使用，資料目錄最終仍會由 `root` 使用者擁有。這並不是問題，但如果您打算從容器外部修改持久性資料，就值得留意這一點。

### 設定檔位置

所有使用者擁有的設定檔都位於 `config/` 目錄中。

此目錄已從 git 版本控制系統中**排除**，因此更新 Toolkit 程式碼時不會變更它。未經您的許可，Toolkit **不會**變更 `config/` 目錄中的任何資料。

<Info>

對設定檔的變更不會自動套用到現有的容器，即使容器已停止並重新啟動（使用 `bin/stop` 與 `bin/start`）也一樣。若要套用變更，請執行 `bin/up`，`docker compose` 會在背後自動將設定變更套用到新的容器。（如果您不想附加到 Docker 日誌，也可以執行 `bin/up -d`。）

</Info>

### `overleaf.rc` 檔案

`config/overleaf.rc` 檔案包含 Toolkit 使用的最重要的頂層設定。其中的陳述式以 `VARIABLE_NAME=value` 的格式設定變數。

若要查看所有可用設定選項的詳細說明，請參閱我們的設定章節。

### `variables.env` 檔案

`config/variables.env` 檔案包含會載入 `sharelatex` 容器的環境變數，用於設定 Overleaf 微服務。其中包括顯示在網頁介面頁首中的應用程式名稱、寄送電子郵件的設定，以及其他進階設定，例如搭配 Server Pro 使用的 SSO。

若要查看所有可用環境變數的詳細說明，請參閱[環境變數](/zh-TW/on-premises/configuration/overleaf-toolkit/environment-variables)章節。

### `version` 檔案

`config/version` 檔案包含 Docker 映像檔的版本號碼，該映像檔將用於建立您 Overleaf 伺服器的執行個體。

<Info>

對這些設定檔的變更不會自動套用到現有的容器，即使容器已停止並重新啟動（使用 `bin/stop` 與 `bin/start`）也一樣。若要套用變更，請執行 `bin/up`，Toolkit 會自動為您建立一個已套用設定變更的新容器。

</Info>

### `docker-compose.override.yml` 檔案

若存在 `config/docker-compose.override.yml` 檔案，它會被納入 `docker compose` 的呼叫中。這對於覆寫 Docker Compose 特有的設定很有用。

詳情請參閱 [docker-compose 文件](https://docs.docker.com/compose/extends/#adding-and-overriding-configuration)。
