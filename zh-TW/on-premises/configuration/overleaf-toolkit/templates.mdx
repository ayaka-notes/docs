### 設定

從 6.3.0 開始，範本庫會在伺服器端執行分頁、搜尋與排序，不需要進行遷移。若範本庫規模較大，請參閱版本資訊中的[選用 MongoDB 索引](/zh-TW/on-premises/release-notes/release-notes-6.x.x#feature-04-template-pagination  "mention")。

範本庫功能由以下環境變數控制：

* `OVERLEAF_TEMPLATE_GALLERY`：設為 `true` 以啟用範本庫。
*   `OVERLEAF_TEMPLATE_CATEGORIES`：選用，以空白分隔的零個或多個範本類別鍵值清單。有效的鍵值包括：

    * _`academic-journal`_
    * _`book`_
    * _`presentation`_
    * _`poster`_
    * _`cv`_
    * _`homework`_
    * _`bibliography`_
    * _`calendar`_
    * _`formal-letter`_
    * _`report`_
    * _`thesis`_
    * _`newsletter`_

    特殊鍵值 _`all`_ 會自動附加，代表包含所有範本的類別。

    對於每個類別鍵值，可以設定以下選用環境變數：

    * `TEMPLATE_<KEY>_NAME`：範本類別的顯示名稱。
    * `TEMPLATE_<KEY>_DESCRIPTION`：類別的簡短說明。

    如果類別鍵值包含連字號（`-`），請在環境變數名稱中將其替換為底線（`_`）。
* `ENABLE_CONVERSIONS`：必須設為 `true`，才能為範本產生縮圖與預覽。

### 發布權限

管理員可以發布範本。您也可以指派一位非管理員使用者，管理顯示在本機範本庫 `/templates` 中的精選範本。

為此，您需要在 `toolkit/config/variables.env` 中將環境變數 `OVERLEAF_TEMPLATES_USER_ID` 設為執行個體中負責範本管理之使用者的 `ID`，例如：

```dotenv
OVERLEAF_TEMPLATES_USER_ID=56a8865231faeb5f07d69959
```

### 發布範本

對於每個要上傳的範本：

1. 建立一個包含範本原始碼的專案，並確認它能成功編譯。
2. 在編輯器中，選擇 **File** > **Manage Template**。
3. 在出現的表單中，輸入範本詳細資訊：
   * _標題_必須是唯一的。
   * _說明_欄位支援 Markdown 格式。
   * _作者_欄位接受 Markdown 格式的連結。

送出後，可以透過範本庫頁面編輯範本詳細資訊或刪除範本。管理員與範本使用者（`OVERLEAF_TEMPLATES_USER_ID`）可以管理任何範本。

以下是一個範例：

```dotenv wrap expandable
#################
#   TEMPLATES   #
#################

ENABLE_CONVERSIONS=true

OVERLEAF_TEMPLATE_GALLERY=true
OVERLEAF_TEMPLATE_CATEGORIES=academic-journal book presentation poster cv homework bibliography calendar formal-letter report thesis newsletter

TEMPLATE_ACADEMIC_JOURNAL_NAME=Journal articles
TEMPLATE_ACADEMIC_JOURNAL_DESCRIPTION=Templates for academic journal submissions, including formats for major publishers and preprint servers.

TEMPLATE_BIBLIOGRAPHY_NAME=Bibliographies
TEMPLATE_BIBLIOGRAPHY_DESCRIPTION=Styles for creating and managing bibliographies with BibTeX or BibLaTeX. Suitable for use in academic papers, theses, and reports.

TEMPLATE_BOOK_NAME=Books
TEMPLATE_BOOK_DESCRIPTION=Templates for writing books or long-form documents, including chapter structuring, front matter, and indexing.

TEMPLATE_CALENDAR_NAME=Calendars
TEMPLATE_CALENDAR_DESCRIPTION=Templates to create yearly, monthly, or weekly calendars. Useful for personal planners or event scheduling.

TEMPLATE_CV_NAME=CVs and résumés
TEMPLATE_CV_DESCRIPTION=Templates for CVs and résumés with various formats for academic, industry, and creative positions.

TEMPLATE_FORMAL_LETTER_NAME=Formal letters
TEMPLATE_FORMAL_LETTER_DESCRIPTION=Templates for professional letters, such as cover letters, recommendation letters, and official correspondence.

TEMPLATE_HOMEWORK_NAME=Assignments
TEMPLATE_HOMEWORK_DESCRIPTION=Templates for homework, coursework, and problem sets. Designed to be clean and well-structured for students and educators.

TEMPLATE_NEWSLETTER_NAME=Newsletters
TEMPLATE_NEWSLETTER_DESCRIPTION=Templates for creating newsletters with formats for academic, corporate, or community communications.

TEMPLATE_POSTER_NAME=Posters
TEMPLATE_POSTER_DESCRIPTION=Templates for scientific and academic posters, typically used in conferences and research presentations.

TEMPLATE_PRESENTATION_NAME=Presentations
TEMPLATE_PRESENTATION_DESCRIPTION=Templates for Beamer and other presentation formats, tailored for academic talks and lectures.

TEMPLATE_REPORT_NAME=Reports

TEMPLATE_THESIS_NAME=Theses
```

### 從 overleaf.com 轉移範本

由於 Overleaf Pro 的架構設計為可離線運作，因此沒有自動化的方式能將 [overleaf.com](https://www.overleaf.com/) 範本庫中的範本整合到您的自建安裝中，不過可以逐一手動完成。

預設情況下，Overleaf Pro 設定為使用 basic scheme 版本的 TeX Live 進行編譯。這個基本版本相當輕量，只包含非常有限的 LaTeX 套件子集，因此當使用者嘗試在本機自建執行個體上使用 [overleaf.com](https://www.overleaf.com/) 的範本時，很可能會遇到缺少套件的錯誤。

可惜的是，雖然沒有自動安裝缺少套件的方法，但 Server Pro 中有一項可設定的功能，能讓使用者以更安全的方式編譯專案，並使用更多套件。此功能稱為[沙箱編譯](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles)（也稱為同層容器，Sibling Containers）。

為確保下載的範本與您的自建 Server Pro 執行個體相容，我們強烈建議您啟用[沙箱編譯](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles)，因為此功能能讓使用者使用與 [overleaf.com](https://www.overleaf.com/) 相同的 TeX Live 環境。這些映像檔包含最常用的套件與字型，並已針對我們範本庫中的範本進行過測試。

關於如何設定使用者可在專案中選擇的 TeX Live 版本，以及為新專案設定預設 TeX Live 映像檔版本的更多資訊，請參閱我們文件中的[變更 TeX Live 映像檔](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles#changing-the-tex-live-image)一節。

1. 前往 [overleaf.com](https://www.overleaf.com/) 上的[範本庫](https://www.overleaf.com/latex/templates)並找到所需的範本，例如 [IEEE Photonics Journal Paper Template - Example Submission](https://www.overleaf.com/latex/examples/ieee-photonics-journal-paper-template-example-submission/bsfjjfkdsjds)
2. 點擊 **Open as Template** 按鈕
3. 點擊專案選單並選擇 **Download Source**
4. 接著，登入自建 Server Pro 帳號
5. 在專案儀表板中點擊 **New Project** 按鈕，然後選擇 **Upload Project**
6. 點擊 **Select a .zip file** 按鈕，並選擇已下載的範本 zip 檔案

使用者接著便能在自己的帳號中使用這個新上傳的範本；若您是範本使用者，也可以將其發布供其他使用者使用。

### 問與答

<Accordion title="發布對應的範本後，我可以刪除該專案嗎？">

**答：** 可以，但我們不建議這麼做。發布範本時，我們會為專案建立快照，並在發布當下將專案儲存為 zip 檔案。這可確保即使您刪除了範本對應的專案，範本也不會受到影響。

不過，我們也會記錄與此範本相關聯的 ProjectID，方便您日後更新範本。

如果您刪除了對應的專案，就不會在範本詳細資訊頁面上看到「Admin: Source Project」按鈕（見下圖）。

<Accordion title="為什麼某些專案發布範本需要花很長的時間？">

**答：** 發布範本時，我們會將專案儲存為 zip 與 PDF 檔案，這通常很快。然而，我們還需要為 PDF 產生縮圖，以便在範本詳細資訊中顯示。

縮圖產生時間通常取決於 PDF 第一頁的內容。為了在顯示品質與轉換時間之間取得平衡，我們選擇了適中的寬度。

然而，如果 PDF 第一頁包含大量文字，轉換縮圖可能需要 40 秒甚至更久，請耐心等候。以下是一個大型海報的範例，它需要較長的時間。
