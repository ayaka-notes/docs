title: 整合
description: 將您的執行個體連接至 Git、GitHub、GitLab、Gitea、Dropbox、文獻管理工具、AI 服務及其他網站。
icon: puzzle-piece
---

除了 Overleaf 匯入 API 以外，每項整合預設皆為關閉。GitHub、GitLab、Gitea 與 Dropbox 同步以及 MCP Server 也需要先啟用 [Git 整合](/zh-TW/on-premises/configuration/overleaf-toolkit/integrations/git-integration)。啟用任一整合後，請使用 `bin/up -d` 重新建立容器。
