您可以透過三種方式將 Overleaf 執行個體開放給沒有帳號的人：

* [專案存取](/zh-TW/on-premises/configuration/overleaf-toolkit/public-access#project-access  "mention")：讓訪客無需登入即可開啟分享的專案連結
* [頁面存取](/zh-TW/on-premises/configuration/overleaf-toolkit/public-access#page-access  "mention")：讓未登入的訪問者瀏覽 `/learn`、`/templates` 與 `/devs` 等頁面
* [公開註冊](/zh-TW/on-premises/configuration/overleaf-toolkit/public-access#public-registration  "mention")：讓使用者自行註冊，並可選擇限制特定電子郵件網域

### 專案存取

<Info>

預設情況下，即使使用者取得了專案分享連結，也必須先**登入**才能加入協作編輯專案。

</Info>

若要允許匿名存取透過連結分享的專案，請設定以下兩個變數：

```dotenv title="config/variables.env"
OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING=true
OVERLEAF_ALLOW_PUBLIC_ACCESS=true
```

`OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` 會啟用對連結分享專案的匿名讀寫。

`OVERLEAF_ALLOW_PUBLIC_ACCESS` 可避免未經驗證的使用者被重新導向至登入頁面。

使用 `bin/up` 重新建立容器，然後在無痕視窗中開啟連結分享 URL。

### 頁面存取

預設情況下（未設定 `OVERLEAF_ALLOW_PUBLIC_ACCESS`），除了登入與註冊頁面之外，**所有**頁面都會將未登入的訪問者重新導向至登入頁面。這也包括原本應公開的頁面，因此這些頁面的連結只對已登入的使用者有效。

設定 `OVERLEAF_ALLOW_PUBLIC_ACCESS=true` 後，未登入的訪問者可以開啟：

| 頁面                                                                  | 需求                         |
| --------------------------------------------------------------------- | -------------------------------- |
| 位於 `/learn` 的 LaTeX 說明（請參閱 [adding-latex-user-help.md](/zh-TW/on-premises/configuration/overleaf-toolkit/adding-latex-user-help  "mention")） | `OVERLEAF_PROXY_LEARN=true`      |
| 位於 `/templates` 的範本庫、範本頁面、預覽與 ZIP 下載（請參閱 [templates.md](/zh-TW/on-premises/configuration/overleaf-toolkit/templates  "mention")） | `OVERLEAF_TEMPLATE_GALLERY=true` |
| 位於 `/devs` 的 Overleaf Import API 頁面（請參閱 [overleaf-import-api.md](/zh-TW/on-premises/configuration/overleaf-toolkit/overleaf-import-api  "mention")） | —                                |

它也讓 [Overleaf Import API](/zh-TW/on-premises/configuration/overleaf-toolkit/overleaf-import-api#signed-out-visitors  "mention") 能保留未登入訪問者送出的表單，直到他們登入為止。

專案清單、編輯器以及建立專案（包括從範本或透過 Import API 建立）仍然需要登入。

### 公開註冊

公開註冊功能僅在 [ayaka-notes/overleaf-pro](https://github.com/ayaka-notes/overleaf-pro) 中提供。

<Danger>

請注意，一旦啟用公開註冊，**任何**能存取您 Overleaf 執行個體的人都可以註冊成為使用者。

註冊流程不會驗證電子郵件地址，因此請僅在內部網路或受信任的環境中使用，或在不再需要註冊時將其停用。

</Danger>

預設情況下，Community Edition 與 Overleaf Pro 都不允許公開註冊。

若要啟用，請將以下內容加入 `config/variables.env`：

```dotenv title="config/variables.env"
OVERLEAF_ALLOW_PUBLIC_REGISTRATION=true
```

使用 `bin/up` 重新建立容器。

然後點擊**註冊**或前往 `/register`。

### 限制網域的註冊

限制網域的公開註冊功能僅在 [ayaka-notes/overleaf-pro](https://github.com/ayaka-notes/overleaf-pro) 中提供。

啟用此功能前，請先設定電子郵件寄送，讓使用者能收到邀請與通知。請參閱[電子郵件寄送](/zh-TW/on-premises/configuration/overleaf-toolkit/email-delivery)。

然後在 `config/variables.env` 中加入下列這一行：

```dotenv title="config/variables.env" wrap
OVERLEAF_ALLOW_PUBLIC_REGISTRATION=@example.domain
```

`OVERLEAF_ALLOW_PUBLIC_REGISTRATION` 可以設定為：

* `true`：允許任何能連上網站的人註冊
* `@example.domain`：僅允許該網域的電子郵件註冊
