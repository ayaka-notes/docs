### 設定 GitHub 同步

<Warning>

使用 GitHub 同步之前，您需要先啟用 [git-bridge](/zh-TW/on-premises/configuration/overleaf-toolkit/git-integration)。

```dotenv title="config/overleaf.rc"
GIT_BRIDGE_ENABLED=true
```

</Warning>

前往 [developers settings](https://github.com/settings/developers) 建立您的 GitHub OAuth 應用程式，並複製您的 `CLIENT_ID` 與 `SECRET`。

**注意**：您的 OAuth 回呼 URL 為：`${OVERLEAF_SITE_URL}/user/github-sync/oauth2/callback`。

接著，將以下設定加入您的 overleaf 環境變數檔案。

```dotenv title="config/variables.env" wrap
# used to encrypt the user's GitHub access token.
# How to generate: `openssl rand -hex 32`
GITHUB_TOKEN_CIPHER_PASSWORD=0123456789ABCDEFG # changed to yours

# Github Sync Settings
GITHUB_SYNC_ENABLED=true
GITHUB_SYNC_CLIENT_ID=
GITHUB_SYNC_CLIENT_SECRET=

# OAuth callback is: ${OVERLEAF_SITE_URL}/user/github-sync/oauth2/callback
# (Optional) GITHUB_SYNC_PROXY_URL=http://10.0.0.1:10808
```

<Warning>

設定 GitHub OAuth 回呼 URL 之前，請確認 `OVERLEAF_SITE_URL` 已正確設定。

</Warning>

如果您位於中國大陸，可能需要設定代理伺服器才能存取 GitHub。請設定以下環境變數：`GITHUB_SYNC_PROXY_URL=http://10.0.0.1:10808`。

<Warning>

請勿使用 `127.0.0.1` 作為代理主機。如果代理伺服器在主機伺服器上執行，請使用伺服器的區域網路 IP 位址（例如 `192.168.1.xx`），並確認代理伺服器已設定為接受來自區域網路裝置的連線。

</Warning>
