### 全域設定

必須設定環境變數 `EXTERNAL_AUTH` 才能啟用特定的驗證模組。此環境變數指定要啟用哪些外部驗證方式。可用的選項如下（小寫）：

* saml
* ldap
* oidc

### SSO 建議

我測試過 Overleaf 的 saml、ldap 與 oauth。saml 和 oauth 在 Overleaf 中都運作良好，但 ldap 則視情況而定。它在 [https://docs.goauthentik.io/](https://docs.goauthentik.io/) 上無法正常運作，但在 openLDAP（[https://github.com/rroemhild/docker-test-openldap](https://github.com/rroemhild/docker-test-openldap)）上運作良好。

<Info>

我們需要更新 passport-ldapauth。最近我嘗試以 [https://goauthentik.io/](https://goauthentik.io/) 測試 Overleaf 的 ldap，結果失敗了。將 "passport-ldapauth" 更新至 3.0.0 後，一切運作正常。

```text
"passport-ldapauth": "^3.0.0",
```

原本的版本是 2.x.x，那已經是 6 年前的版本了。

</Info>

我不確定原因為何，因為我們都依賴外部套件來進行 LDAP（以及 saml、oauth）驗證。如果無法運作，Overleaf Server Pro 的情況可能也一樣，因為我們只是將所有環境變數傳遞給內部套件，若其中有錯誤，目前我們也無從得知。

**因此我強烈建議使用者建立開發環境，搭配完整原始碼來測試 SSO**，相關說明請參閱[設定開發環境（本機）](/zh-TW/dev/environment/setup-develop-environment-local  "mention")。在開發環境中，您可以在終端機中看到所有記錄，方便進行除錯。
