### 頁首

本節將說明如何個人化您本地部署執行個體的關鍵元素。您可以依照自己的偏好，自訂網站標題、導覽連結、頁首、頁尾與標誌。

### 網站標題

導覽列標題可透過 `OVERLEAF_NAV_TITLE` 環境變數自訂；若未設定標誌，此文字會顯示在導覽列的左上角。

```bash
# add to config/variables.env
OVERLEAF_NAV_TITLE=Our Overleaf Instance
```

## 標誌

您可以設定 `OVERLEAF_HEADER_IMAGE_URL` 環境變數，以自訂標誌取代文字。此值應指向外部託管的圖片檔案。

```bash title="config/variables.env"
# add to config/variables.env
OVERLEAF_HEADER_IMAGE_URL=https://mysite.somewhere.com/img/logo.png
```

#### 淺色與深色主題標誌

從 6.3.0 版開始，您可以使用 `OVERLEAF_HEADER_IMAGE_URL_LIGHT` 與 `OVERLEAF_HEADER_IMAGE_URL_DARK` 環境變數，分別為淺色與深色主題設定不同的標誌。這兩個值都應指向外部託管的圖片檔案。

```text
# add to config/variables.env
OVERLEAF_HEADER_IMAGE_URL_LIGHT=https://mysite.somewhere.com/img/logo-light.png
OVERLEAF_HEADER_IMAGE_URL_DARK=https://mysite.somewhere.com/img/logo-dark.png
```

<Info>

若其中任一變數未設定，該主題會改用 `OVERLEAF_HEADER_IMAGE_URL` 所設定的標誌。

</Info>

## 頁首導覽連結

將 `OVERLEAF_HEADER_EXTRAS` 環境變數設定為由物件組成的 JSON 陣列，即可在導覽頁首中加入額外的導覽項目。例如：

```json wrap
[\
  {\
    "text": "Some link",\
    "url": "http://example.com/somelink",\
    "class": "subdued",\
    "only_when_logged_out": true\
  },\
  {\
    "text": "Help",\
    "class": "subdued",\
    "dropdown": [\
      {\
        "text": "Documentation",\
        "url": "/learn"\
      },\
      {\
        "text": "Contact Admin",\
        "url": "http://example.com/contact"\
      }\
    ]\
  }\
]
```

將跳脫後的 JSON 格式加入 toolkit/variables.env：

```bash title="toolkit/variables.env" wrap
# add to toolkit/variables.env
OVERLEAF_HEADER_EXTRAS=[{"text":"Some link","url":"http://example.com/somelink","class":"subdued","only_when_logged_out":true},{"text":"Help","class":"subdued","dropdown":[{"text":"Documentation","url":"/learn"},{"text":"Contact Admin","url":"http://example.com/contact"}]}]
```

## 頁尾

您可以使用 `OVERLEAF_LEFT_FOOTER` 與 `OVERLEAF_RIGHT_FOOTER` 環境變數，自訂左側頁尾與較小的右側頁尾（顯示於 `/project` 等頁面）。兩者都需要一個由 JSON 物件組成的陣列，其內容會被插入頁面中。

兩者都需要一個 JSON 陣列，其內容會被插入頁面中。

```json
[\
  {\
    "text": "This is an example text footer entry!"\
  },\
  {\
    "text": "This is an example URL footer link!", "url" : "/my-first-link.htm"\
  }\
]
```

<Info>

僅使用 `text` 時，其中不得包含 HTML，因為該值會以純文字呈現。

</Info>

這些資料必須是有效的 JSON 才能運作，且以環境變數傳入時，引號需要跳脫。

```bash title="config/variables.env" wrap
# add to config/variables.env
OVERLEAF_LEFT_FOOTER=[{"text": "This is an example text footer entry!"}]
OVERLEAF_RIGHT_FOOTER=["text": "This is an example URL footer link!", "url" : "/my-first-link.htm"]
```

<Info>

除了 `text` 與 `url` 之外，JSON 物件也接受 `class` 與 `label` 屬性，以進行更多自訂。

</Info>

### 維護頁面

您可以使用 `OVERLEAF_MAINTENANCE_MESSAGE` 環境變數自訂維護頁面上顯示的訊息，此文字會取代頁面標題下方的預設訊息。

```text wrap
# add to config/variables.env
OVERLEAF_MAINTENANCE_MESSAGE=Our Overleaf Instance is down for maintenance and will be back shortly.
```

若要加入連結或其他格式，請改用 `OVERLEAF_MAINTENANCE_MESSAGE_HTML`。若兩者皆有設定，則以 `OVERLEAF_MAINTENANCE_MESSAGE_HTML` 為優先。

```text wrap
# add to config/variables.env
OVERLEAF_MAINTENANCE_MESSAGE_HTML=Our Overleaf Instance is down for maintenance. For urgent requests, contact <a href="mailto:admin@example.com">admin@example.com</a>.
```

<Info>

`OVERLEAF_MAINTENANCE_MESSAGE` 會以純文字呈現，因此**不得**包含 HTML。`OVERLEAF_MAINTENANCE_MESSAGE_HTML` 則會以未經跳脫的 HTML 呈現。

</Info>

若兩者皆未設定，當已設定 `OVERLEAF_STATUS_PAGE_URL` 時，預設訊息會連結到您的狀態頁面；若未設定，則會顯示管理員的電子郵件地址。
