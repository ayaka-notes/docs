只要在 Toolkit 的 `config/variables.env` 檔案中加入 `OVERLEAF_PROXY_LEARN=true` 並執行 `bin/up` 指令，即可在您的 Overleaf Pro 執行個體中啟用 Overleaf 的 [Learn](https://www.overleaf.com/learn) 頁面存取。

這讓使用者只要點選導覽選單中的 **Documentation** 按鈕，就能存取最新的文件與學習資源，完全無需離開您的執行個體。

<Info>

預設情況下，只有已登入的使用者可以開啟 `/learn`。若要讓未登入的訪客也能使用，請同時設定 `OVERLEAF_ALLOW_PUBLIC_ACCESS=true`，請參閱[頁面存取](/zh-TW/on-premises/configuration/overleaf-toolkit/public-access#page-access  "mention")。

</Info>

<Info>

若使用 Docker Compose 部署，您需要在 `docker-compose.yml` 檔案中 `sharelatex` 服務的 **environment** 區段加入環境變數 `OVERLEAF_PROXY_LEARN: true`。

</Info>

<Info>

您的 Server Pro 部署需要能存取網際網路，以便對 [https://learn.sharelatex.com](https://docs.overleaf.com/on-premises/welcome) 發出外部 `GET` 請求。

</Info>

<Danger>

當您第一次啟用此選項並重新啟動 Overleaf Docker 時，系統需要下載相關的 Wiki，這可能需要 5 分鐘或更久。只有在下載完成後，您才能成功看到 Overleaf 登入頁面。

</Danger>
