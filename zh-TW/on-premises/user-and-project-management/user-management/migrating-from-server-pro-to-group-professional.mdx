---
title: 從 Server Pro 遷移至 Group Professional
icon: rectangle-pro
noindex: true
---

從自架的 Server Pro 執行個體轉換至全新的雲端 Overleaf Group Professional 訂閱是一項重大變更，為了讓此流程盡可能順利，我們整理了以下指引。

一般而言，我們建議從您的續約日開始設定三個月的重疊期。這表示：

* 您現有的 Server Pro 執行個體與新的 Group Professional 訂閱都將完全啟用。
* 您的技術團隊可以安排時間設定 Group Professional 訂閱，並決定地端 Server Pro 部署的未來規劃。
* 最重要的是，您的使用者將有充裕的時間將他們的專案複製到新的 Overleaf Group Professional 平台。

這份快速指南將引導您完成此遷移的關鍵步驟。讓我們開始吧！

<Steps>
<Step title="第 1 階段：設定與配置">
（連結：https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-1-setup-and-configuration）

* Overleaf 將建立您的 Group Professional 訂閱，並新增您的主要管理員。
* 您的群組管理員將能夠啟用[受管理使用者](https://docs.overleaf.com/groups/user-management/managed-user-accounts)、設定[單一登入（SSO）](https://docs.overleaf.com/groups/overleaf-group-single-sign-on/setting-up-group-sso)，以及[邀請終端使用者](https://docs.overleaf.com/groups/user-management/how-to-add-and-remove-users)。

<Warning>

啟用受管理使用者並實作 SSO 是符合 FedRAMP® LI-SaaS 規範的必要步驟。如果您的組織需要符合 FedRAMP 規範，請在邀請終端使用者之前先設定受管理使用者與 SSO。

</Warning>
</Step>

<Step title="第 2 階段：使用者遷移與資料管理">
（連結：https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-2-user-migration-and-data-management）

這是主要的遷移期間，各方職責如下：

#### 終端使用者

* 使用者應將任何想保留的專案從您的 Server Pro 執行個體遷移至他們在 [overleaf.com](http://overleaf.com/) 上的新帳號。此流程包括從 Server Pro [匯出專案](https://www.overleaf.com/learn/how-to/Exporting_your_work_from_Overleaf)，再將其[上傳](https://www.overleaf.com/learn/how-to/Uploading_a_project)至他們在 [overleaf.com](http://overleaf.com/) 上的帳號。如果使用者尚未擁有 [overleaf.com](http://overleaf.com/) 帳號，可以在 [overleaf.com/register](http://overleaf.com/register) 註冊。

<Warning>

透過此匯出程序只會轉移專案原始碼（LaTeX 與二進位檔案）。任何現有的專案設定、分享設定、留言、追蹤修訂等都**不會**被轉移。使用者需要在遷移後重新邀請他們的協作者。

</Warning>

#### 技術人員

* 在此階段，您的技術團隊應規劃遷移後如何處理地端 Server Pro 執行個體及其資料。
* **資料備份：** 您可以在停用前匯出所有專案以建立封存，以便協助可能忘記遷移或下載其作品的使用者。操作說明：https://docs.overleaf.com/on-premises/maintenance/data-and-backups/exporting-projects
* **Server Pro 停用：** 在遷移期間結束且您的授權金鑰被停用後，對於 Server Pro 執行個體本身，您有兩個主要選項（請參閱下一個步驟）。
</Step>

<Step title="Server Pro 停用選項">
<Steps>
<Step title="完全解除安裝 Server Pro">
解除安裝將停用 Server Pro 並完全移除該軟體。
</Step>

<Step title="切換至 Community Edition">
切換會將執行個體從 Server Pro 轉換為 Community Edition，並保留包含完整專案歷程的使用者與專案資料庫。
</Step>
</Steps>

<Info>

Community Edition **不包含**[沙箱編譯](https://docs.overleaf.com/on-premises#overview-of-server-pro-and-community-edition)，也不包含 [LDAP](/zh-TW/on-premises/configuration/overleaf-toolkit/authentication/ldap-authentication)/[SAML](/zh-TW/on-premises/configuration/overleaf-toolkit/authentication/saml-authentication)。如果您需要改回原生驗證（使用者名稱／密碼），請參閱：https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-to-ldap-or-saml#going-the-other-way-switching-from-ldap-saml-back-to-native-authentication

如需 Server CE 與 Server Pro 的比較，請參閱：https://docs.overleaf.com/on-premises/welcome/server-pro-vs.-community-edition

</Info>
</Step>

<Step title="第 3 階段：停用 Server Pro">
（連結：https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-3-server-pro-decommission）

* Overleaf 團隊將正式停用您的 Server Pro 授權金鑰，並在完成後寄送確認通知。
* 屆時，請執行上述其中一項停用操作：完全解除安裝 Server Pro，或切換至 Community Edition。
</Step>
</Steps>
