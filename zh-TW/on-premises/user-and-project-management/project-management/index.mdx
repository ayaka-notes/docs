### 檢視專案的稽核日誌

管理員可以查看每個專案的**稽核日誌（Audit Log）**。此稽核日誌會顯示各種事件，例如連結分享在私人／權杖模式之間切換的時間、邀請的寄送／接受時間，以及使用者透過權杖加入專案的時間。管理員可以透過 **Your Instance** -> **Admin** -> **Manage Users** 逐一檢視各專案的日誌，接著：

* 搜尋該使用者
* 點擊 **Projects** 分頁
* 選擇一個專案
* 點擊 (i) 圖示
* 點擊 **Audit Log** 分頁

如果專案以電子郵件地址分享給具名協作者，當收件者加入後，他們將連同其權限一起列在分享視窗中，專案擁有者也能看到。管理員透過管理面板檢視該專案的 Project Info 分頁時，也會看到這些資訊。

### 復原已刪除的文件

1. 使用您的管理員憑證登入
2. 點擊 **Admin** 並選擇 **Manage Users**
3. 在搜尋欄位中，輸入您要為其復原文件之使用者的電子郵件
4. 在搜尋結果清單中點擊其電子郵件地址，開啟其使用者資訊頁面
5. 點擊 **Projects** 分頁，並使用搜尋欄位搜尋該專案
6. 點擊專案名稱旁的資訊圖示，開啟 **Project Info**
7. 點擊 **Deleted Docs** 分頁
8. 點擊已刪除文件旁的 **Undelete** 按鈕，將其還原至使用者的專案中。

還原後的檔案將採用以下格式：`FILENAME-TIMESTAMP.EXTENSION`。例如，`main.tex` 的還原版本會以檔名 `main-2024-02-23-130441542.tex` 還原至專案的根目錄。

### 轉移專案擁有權

Server Pro 的管理面板為每個專案提供專屬頁面。您可以在「/admin/user」上搜尋該使用者，進入其 **Projects** 分頁，在清單中找到該專案並點擊資訊圖示；或者使用已知的專案 ID 直接前往頁面 [**https://your-instance-url/admin/project/**](https://your-instance-url/admin/project/)。在專案資訊頁面上，您可以找到 **Transfer Ownership** 按鈕，點擊後會開啟一個視窗，讓您指定任何使用者作為新的擁有者。新的擁有者不需要是該專案現有的協作者。

<Info>

請注意，在擁有權轉移過程中，先前的擁有者會被新增為具有讀寫權限的專案協作者。

</Info>

### 更新專案編譯逾時

目前專案的預設編譯逾時設定為 180 秒。此值可以變更，需透過兩個步驟完成。

首先，編輯 **config/variables.env** 檔案，新增 `COMPILE_TIMEOUT` 環境變數，並將其值設為所需的逾時秒數。例如，`COMPILE_TIMEOUT=300` 代表 5 分鐘。

<Danger>

將逾時設定超過 10 分鐘並沒有意義。若這麼做，您很可能會在應用程式的其他元件中遇到逾時。

</Danger>

完成此變更後，您需要執行 `bin/up -d` 指令來重新建立 **sharelatex** 容器。

設定此環境變數只會更新新使用者的逾時值，**不會**追溯套用至現有使用者，因為此值是在使用者首次建立時填入的。

若要調整現有使用者的逾時，您需要變更資料庫中每一筆使用者記錄。我們建議在執行此操作時務必非常謹慎，並建議在進行任何變更之前先建立一致性備份。

您可以在[這裡](/zh-TW/on-premises/maintenance/data-and-backups)找到有關執行備份的資訊。

若要更新所有現有使用者的編譯逾時值，您需要在 Docker 主機上執行以下 shell 指令：

```bash wrap
echo 'db.users.updateMany({}, {$set: {"features.compileTimeout": <value>}})' | docker exec -i mongo mongosh --quiet localhost/sharelatex
```

您需要將上述查詢中的 `<value>` 替換為所需的逾時秒數。

指令完成後，您應該會看到一則確認訊息，顯示已修改的記錄數量。接著您可以輸入 exit 並按下 Enter 鍵，返回主機的 shell。

### 追蹤專案存取

您可以使用以下指令查看專案在何時被誰載入：

```bash wrap
docker exec sharelatex bash -c 'grep "join project request" /var/log/overleaf/web.log'
```

這會提供 `timestamp`、`user_id` 與 `project_id`。
