為了體現開源精神，Overleaf 在 [GitHub: Overleaf](https://github.com/overleaf/overleaf) 提供了開源的社群版本。然而，為了推銷其所謂的 [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud)，Overleaf 刻意對其開源的社群版本進行了許多隱藏程式碼的修改，甚至將純前端的數學_符號面板_當作**付費**功能販售。

過去幾年來，我們眼看著 Overleaf 的編譯時間從**一分鐘降到二十秒，甚至十秒**，而訂閱費用卻不斷攀升。讓人不禁感嘆：<strong>天下苦 Overleaf 久矣。</strong>

此外，Overleaf 的定價在全球幾乎一致，即使是最便宜的學生會員方案每月也要 \$10 起，這對歐美以外的大多數學生來說是負擔不起的。更離譜的是，還有每年要價 \$399 的 Pro 方案，只能用天價來形容。

### 我們需要改變

可以說，無論是個別學生還是整個研究機構，這些年來大家都被 Overleaf 不斷上漲的價格牽著走。

而在 AI 時代，Overleaf 非但沒有帶來所承諾的變革，反而持續依賴其舊有技術，同時從終端使用者身上榨取越來越多。

多年來，許多社群開發者為改進 Overleaf Community Edition 付出了大量心力。他們是：

* [https://github.com/ertuil/overleaf](https://github.com/ertuil/overleaf)
* [https://github.com/AllanChain/lcpu-overleaf](https://github.com/AllanChain/lcpu-overleaf)
* [https://github.com/yu-i-i/overleaf-cep/](https://github.com/yu-i-i/overleaf-cep/)
* [https://github.com/ayaka-notes/overleaf](https://github.com/ayaka-notes/overleaf)
* [https://github.com/davrot/overleaf\_with\_admin\_extension](https://github.com/davrot/overleaf_with_admin_extension)
* [https://github.com/overleaf/overleaf/pull/1447](https://github.com/overleaf/overleaf/pull/1447)（Git 整合）
* [https://github.com/overleaf/overleaf/pull/1385](https://github.com/overleaf/overleaf/pull/1385)（Typst 支援）

其中有些人提交了拉取請求（PR），但遺憾的是，在開源社群中，這些 PR 大多被忽視。因此，我們常常質疑 Overleaf 所謂的開源究竟是什麼樣的開源。

2026 年 1 月，OpenAI 宣布推出 [Prism](https://prism.openai.com/)。在許多社群中，人們都說 Prism 已經終結了 Overleaf。

_<strong>這告訴我們，在 AI 時代，如果一家公司只依賴重新包裝的 API 和層層疊疊的功能限制來綁住使用者，最終將會被越來越多的競爭者超越。</strong>_

回到正題，集結所有功能於一身，我們很高興宣布推出 Overleaf Pro。這些文件專為有興趣架設與維護 Overleaf Pro 的人所撰寫。

Overleaf Pro 與 Community Edition 皆在 Docker 容器中執行，將其與同一主機上的其他應用程式隔離。這可防止潛在的跨應用程式攻擊，提供額外一層安全性。

它們可以在離線隔離（air-gapped）伺服器上執行，這表示它們可以與其他網路（包括網際網路）完全隔離。Docker 提供了將應用程式從連網環境轉移到離線隔離環境的工具。

在初次下載後，無需任何網際網路連線，大幅降低了外部威脅的風險。
