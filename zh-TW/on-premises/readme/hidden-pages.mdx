為了體現開源精神，Overleaf 在 [GitHub: Overleaf](https://github.com/overleaf/overleaf) 上提供了開源的社群版本。然而，為了推銷其所謂的 [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud)，Overleaf 刻意對其開源社群版本做了許多隱藏程式碼的修改，甚至將純前端的數學_符號面板（Symbol Palette）_作為**付費**功能販售。

過去幾年，我們眼看著 Overleaf 的編譯時間限制從**一分鐘降到二十秒，甚至十秒**，而訂閱費用卻不斷水漲船高。實在令人忍不住感嘆：**天下學者苦 Overleaf 久矣。**

此外，Overleaf 的定價在全球幾乎一致，即使是最便宜的學生會員每月也要 \$10 起，這對歐美以外的大多數學生來說難以負擔。更離譜的是，還有每年 \$399 的 Pro 方案，只能用天價來形容。

### 我們需要改變

可以說，無論是個別學生還是整個研究機構，這些年來每個人都被 Overleaf 不斷上漲的價格牽著走。

而在 AI 時代，Overleaf 非但沒有帶來承諾中的變革，反而持續依賴其老舊技術，同時從終端使用者身上榨取越來越多。

多年來，許多社群開發者為改進 Overleaf Community Edition 付出了大量心力。他們是：

* [https://github.com/ertuil/overleaf](https://github.com/ertuil/overleaf)
* [https://github.com/AllanChain/lcpu-overleaf](https://github.com/AllanChain/lcpu-overleaf)
* [https://github.com/yu-i-i/overleaf-cep/](https://github.com/yu-i-i/overleaf-cep/)
* [https://github.com/ayaka-notes/overleaf](https://github.com/ayaka-notes/overleaf)
* [https://github.com/davrot/overleaf\_with\_admin\_extension](https://github.com/davrot/overleaf_with_admin_extension)
* [https://github.com/overleaf/overleaf/pull/1447](https://github.com/overleaf/overleaf/pull/1447)（Git 整合）
* [https://github.com/overleaf/overleaf/pull/1385](https://github.com/overleaf/overleaf/pull/1385)（Typst 支援）

其中一些人發起了 pull request（PR），但遺憾的是，在開源社群中，這些 PR 大多被忽視。因此，我們常常質疑 Overleaf 所謂的開源究竟是什麼樣的開源。

2026 年 1 月，OpenAI 宣布推出 [Prism](https://prism.openai.com/)。在許多社群中，人們都表示 Prism 已經殺死了 Overleaf。

_**這告訴我們，在 AI 時代，如果一家公司只依賴重新包裝的 API 與層層疊加的功能限制來綁住使用者，終究會被越來越多的競爭者超越。**_

回到正題，集結所有功能，我們很高興宣布推出 Overleaf Pro。這些文件專為有興趣架設與維護 Overleaf Pro 的人所撰寫。

Overleaf Pro 與 Community Edition 皆在 Docker 容器中執行，與同一主機上的其他應用程式相互隔離。這可防止潛在的跨應用程式攻擊，提供額外一層安全保障。

它們可以在離線隔離（air-gapped）的伺服器上執行，也就是能與包括網際網路在內的其他網路完全隔離。Docker 提供了將應用程式從連網環境轉移到離線隔離環境的工具。

完成初次下載後，便不再需要網際網路連線，大幅降低外部威脅的風險。
