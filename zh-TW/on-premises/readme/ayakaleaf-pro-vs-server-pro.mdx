<Info>

Ayakaleaf Pro 是 Overleaf Community Edition 的增強實作，_**免費**_提供 Server Pro 的所有_**進階**_功能。與 [https://www.overleaf.com/](https://www.overleaf.com/) 上的 Overleaf Common 不同，我們沒有編譯時間限制、使用者人數無須授權，而且您可以完全自行託管自己的資料，確保絕對安全。

Overleaf Server Pro 是 Overleaf 的商業版自行託管部署，提供官方支援。關於 Server Pro 的更多資訊，請造訪 [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud)。

</Info>

<Warning>

Overleaf Community Edition 適用於**所有**使用者皆受信任的環境。由於不提供沙箱編譯（Sandbox Compiles），Community Edition **不**適用於需要隔離使用者的情境。

在沒有沙箱的情況下，LaTeX 編譯會以與容器相同的權限執行，因而能存取容器的檔案系統、網路與環境變數。這會造成資料外洩或系統遭入侵的風險。非沙箱編譯僅應在完全受信任的環境中使用；對於多使用者或正式環境部署，強烈建議使用沙箱編譯。

關於沙箱編譯的更多資訊，請參閱我們的[文件](/zh-TW/on-premises/configuration/overleaf-toolkit/sandboxed-compiles)。

</Warning>

### 社群支援

對於使用自行託管 Overleaf 執行個體的使用者，支援由社群透過 GitHub [Issues](https://github.com/ayaka-notes/overleaf-pro/issues) 提供。

為了維持在受支援的版本上，您可以將以下指令的輸出與版本資訊中發布的映像檔 ID 進行比對，以確認您正在執行的 Overleaf 版本。

```bash
docker inspect --format '{{.Image}}' sharelatex | awk -F: '{print substr($2, 1, 12)}'
```
