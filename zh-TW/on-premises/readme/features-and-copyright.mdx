我們尊重著作權，因此在此列出本專案使用的所有功能與程式碼。本頁提供 Ayakaleaf Pro 新功能及相關程式碼著作權的資訊。

除非另有說明，我們使用 OpenAI 的 Codex 進行程式碼審查與 PR 審查。在此過程中，我們修正了許多安全性問題，並對他們致上誠摯的謝意。詳細資訊請參閱 [ayaka-notes/ayakaleaf-pro/pull](https://github.com/ayaka-notes/ayakaleaf-pro/pulls)。

### 概覽

多年來，許多社群開發者為改善 Overleaf Community Edition 付出了大量心力。他們是：

* [https://github.com/ertuil/overleaf](https://github.com/ertuil/overleaf)
* [https://github.com/AllanChain/lcpu-overleaf](https://github.com/AllanChain/lcpu-overleaf)
* [https://github.com/yu-i-i/overleaf-cep/](https://github.com/yu-i-i/overleaf-cep/)
* [https://github.com/ayaka-notes/overleaf](https://github.com/ayaka-notes/overleaf)
* [https://github.com/davrot/overleaf\_with\_admin\_extension](https://github.com/davrot/overleaf_with_admin_extension)
* [https://github.com/overleaf/overleaf/pull/1447](https://github.com/overleaf/overleaf/pull/1447)（GitHub 整合）
* [https://github.com/overleaf/overleaf/pull/1385](https://github.com/overleaf/overleaf/pull/1385)（Typst 支援）

我們的專案中可能使用了相關的程式碼，在此向他們表達感謝。

#### 功能 01：範本系統

此功能主要由 [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep) 開發。我們修改了部分程式碼加以強化，讓您可以：

* 直接在範本頁面下載範本。
* 開啟範本對應的專案。
* 轉換出品質更高的封面圖片（且所需時間更短）。

#### 功能 03：Git 整合

此功能由 [ayaka-notes/overleaf-pro](https://github.com/ayaka-notes/overleaf-pro) 開發。Overleaf 提供了一個名為 git-bridge 的官方元件，可在[這裡](https://github.com/overleaf/overleaf/tree/main/services/git-bridge)取得。

我們只是實作了 git-bridge 與 Overleaf 之間的連接器，與 Overleaf 在其 SaaS 平台上的做法相同。

#### 功能 05：管理面板

<Warning>

當您的系統有 1000 位使用者或 1000 個專案時，管理面板只會顯示最新的 1000 位使用者或 1000 個專案。請使用搜尋面板搜尋特定的使用者或專案。

</Warning>

此功能主要由 [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep) 開發。我們修改了部分程式碼加以強化，讓您可以：

* 在使用者超過 1000 位時，透過後端搜尋使用者。
* 在專案超過 1000 個時，透過後端搜尋專案。
* 直接在專案管理面板中開啟專案。
* 在管理面板中檢視並調整使用者的編譯時間限制。
* 直接在管理面板中重設使用者的密碼。
* 其他強化功能……

#### 功能 06：審閱面板

此功能主要由 [Overleaf 官方](https://github.com/overleaf/overleaf/tree/main/services/clsi)開發，我們只是從 [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep) 與 [ertuil/overleaf](https://github.com/ertuil/overleaf) 補上缺少的程式碼，也就是聊天與 web 服務之間的連接器。

#### 功能 07：外部 URL

此功能主要由 [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep) 開發。CEP 實作了一個名為 linked-url-proxy 的外部服務，可在網域/IP 限制下安全地擷取外部檔案。

此功能主要由 [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep) 開發。CEP 實作了一個子模組，將 passport 與 Overleaf 的 web 驗證串接起來。

#### 功能 09：支援 ARM

我們使用 GitHub Actions 為 x86 與 arm 架構建置並發布 Docker 映像檔。當您下載映像檔時，系統會根據您的環境自動選擇合適的架構。

#### 功能 10：自行註冊

此功能由 [ayaka-notes/overleaf-pro](https://github.com/ayaka-notes/overleaf-pro) 開發。您可以：

* 限制只有特定網域的使用者才能註冊
* 開放任何能存取您 Overleaf 的人註冊

#### 功能 11：Learn Wiki

此功能由 [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) 開發。您可以查看來自 Overleaf 的最新 Learn Wiki，但我們並不擁有這些文件的任何著作權！我們只是在您首次啟用此功能時從 Overleaf 伺服器下載，並定期更新。

#### 功能 16：AI 聊天與 LaTeX 錯誤助理

Ayakaleaf Pro 帶來了 AI 助理與錯誤助理：AI 助理可以使用您的專案文件與目前的選取內容作為脈絡，回答問題並提出編輯建議供您審閱；錯誤助理則會在您選取 LaTeX 編譯錯誤時，提出針對性的修正方案。
