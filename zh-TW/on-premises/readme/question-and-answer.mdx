我們在此整理了一些關於 Ayakaleaf Pro 的常見問題解答。

### 基本問題

<Accordion title="Q01：Ayakaleaf Pro 是免費試用版嗎？需要授權嗎？">

不是。Ayakaleaf Pro 完全免費使用。它不是試用版，也不需要任何授權。

</Accordion>

<Accordion title="Q02：Ayakaleaf Pro 是否包含所有 Overleaf Server Pro 的功能？">

是的。Ayakaleaf Pro 包含所有 Overleaf Server Pro 的功能，包括 Git-Bridge 整合。此外也納入了 Overleaf SaaS 平台的部分功能。我們會持續開發並改進 Ayakaleaf Pro。

</Accordion>

<Accordion title="Q03：Overleaf Server Pro 的價格是多少？">

Overleaf Server Pro 每位使用者每年約需 \$300。至少需要購買 10 個授權，因此部署費用每年約從 \$3,000 起跳。美國較小型的公開合約顯示，每位使用者每年的費用約為 \$320–\$370。這使得 Server Pro 相當昂貴，對小型團隊而言尤其如此。有關已記錄的採購與價格資訊，請參閱 [#information-and-price-about-overleaf-server-pro](/zh-TW/on-premises#information-and-price-about-overleaf-server-pro  "mention")。

</Accordion>

<Accordion title="Q04：為什麼 Overleaf Server Pro 不包含 GitHub 同步或 AI 功能？">

Overleaf Server Pro 常被政府機關使用。他們會將其部署在私有網路中，並嚴格控管存取權限。為了保護敏感資料，其內建功能會避免與第三方服務交換資料。如果您需要 GitHub 同步、AI 或類似的連網功能，Overleaf 建議訂閱其 SaaS 平台。

</Accordion>

<Accordion title="Q05：Ayakaleaf Pro 安全可靠嗎？">

Ayakaleaf Pro 是開放原始碼軟體。我們使用 Codex Security 等工具審查程式碼，以強化其安全性與可靠性。如果您未啟用第三方資料同步，您的資料將保留在您自己的伺服器上。Ayakaleaf Pro 不包含任何會將您的資料傳送至他處的遙測功能。

</Accordion>

<Accordion title="Q06：Ayakaleaf Pro 會長期維護嗎？">

我們將盡一切努力長期維護此專案。

</Accordion>

<Accordion title="Q07：Ayakaleaf Pro 是否合規？">

Ayakaleaf Pro 是社群分支（fork）。其程式碼與整合功能皆來自社群貢獻，並採用 AGPL v3 授權。只要部署符合該授權的要求，即可遵循此授權。

</Accordion>

<Accordion title="Q08：為什麼這個專案叫做 Ayakaleaf Pro？">

本專案最初於 2024 年命名為 Overleaf Pro。開發曾暫停一段時間，之後於 2025 年底重新啟動。2026 年第一季，Overleaf 將其具備 AI 功能的訂閱方案更名為 Pro。社群回饋也指出，Overleaf Pro 這個名稱可能帶來商標與冒充的風險，可能讓使用者誤以為本專案是官方產品。

為了避免這種混淆，我們將專案更名為 Ayakaleaf Pro。這個名稱可以理解為「Ayaka-notes Overleaf Pro」。維護者從學生時期起便參與 Overleaf 社群開發，至今已超過五年。這段經驗支撐著我們長期維護的承諾。

</Accordion>

<Accordion title="Q09：Ayakaleaf Pro 與較新的 AI 打造 LaTeX 編輯器有何不同？">

自 2026 年起，開源社群已推出許多由 AI 打造的 LaTeX 編輯器，包括 OpenAI Prism。Ayakaleaf Pro 會將您的資料與服務保留在您自己的伺服器上，讓您能直接掌控自己的部署與資料。

許多實驗性的社群編輯器並沒有明確的長期維護計畫。第三方 LaTeX 編譯平台也可能在使用者基礎或營收不足時停止營運。Ayakaleaf Pro 提供完整的原始碼，讓您能自行託管所有服務。即使維護停止，您現有的自架服務仍可繼續運作。

</Accordion>

### LaTeX

<Accordion title="Q01：使用者的 LaTeX 專案編譯是否相互隔離？是否啟用 Shell Escape？">

啟用沙箱編譯（Sandbox Compiles）後，每位使用者的編譯都會在獨立的 Docker 容器中執行，並與其他使用者的編譯相互隔離。沙箱編譯預設已啟用 Shell Escape。

</Accordion>

<Accordion title="Q02：沙箱編譯映像檔可靠嗎？編譯可能會失敗嗎？">

過去三年來，我們持續改進用於沙箱編譯的 TeX Live Full 映像檔。在大多數情況下，能在 overleaf.com 上編譯的專案，也能在 Ayakaleaf Pro 中正確編譯。如果缺少所需的字型，請手動將該字型上傳至您的專案。

</Accordion>
