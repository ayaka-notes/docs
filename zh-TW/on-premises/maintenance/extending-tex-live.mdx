您可以使用新的 Dockerfile 擴充現有的 TeX Live 映像檔，並設定應用程式使用新的映像檔。

以下提供一些安裝新套件或字型的指引，但自訂映像檔的設定不在我們的支援條款範圍內。

TeX Live 映像檔的更新頻率不高。我們建議在升級 Server Pro 時重新建置自訂映像檔。

<Danger>

以下各節僅適用於 Server Pro 與 [Sandboxed Compiles](/zh-TW/on-premises/configuration/overleaf-toolkit/sandboxed-compiles)。

</Danger>

### 安裝與更新新套件

您可以使用 `tlmgr install`、`tlmgr update` 等 `tlmgr` 指令來管理 TeX Live 套件，如下例所示：

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2023.1

RUN tlmgr update --force ebproof
```

### 在較舊的 TeX Live 映像檔中使用 `tlmgr`

預設情況下，`tlmgr` 會從最新的 TeX Live 版本下載資源。修補較舊的 TeX Live 映像檔時，必須將下載來源切換到對應的封存庫。封存庫的鏡像站清單請參閱 [https://www.tug.org/historic/](https://www.tug.org/historic/)。

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2022.1

RUN tlmgr option repository <MIRROR>/systems/texlive/<YEAR>/tlnet-final
# e.g. RUN tlmgr option repository ftp://tug.org/historic/systems/texlive/2022/tlnet-final

RUN tlmgr update --force ebproof
```

### 安裝新字型

在 TeX Live 發行版中安裝新字型有多種不同的程序，安裝自訂字型可能需要好幾個步驟。參考 TeX Live 官方文件中的[安裝 TeX 字型說明](https://tug.org/fonts/fontinstall.html)會是不錯的起點。

以下 `Dockerfile` 示範如何在現有的 TeX Live 2022 映像檔上安裝 TrueType 字型：

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2022.1

COPY ./myfonts/*.ttf /usr/share/fonts/truetype/myfont/

# rebuild font information cache
RUN fc-cache
```

### 設定 Server Pro 使用新映像檔

使用 `ghcr.io/ayaka-notes/texlive-full` 這個名稱搭配自訂標籤來建置新映像檔，例如：

```bash
docker build -t ghcr.io/ayaka-notes/texlive-full:2023.1-custom
```

接著，我們可以更新 `TEX_LIVE_DOCKER_IMAGE` 與 `ALL_TEX_LIVE_DOCKER_IMAGES` 環境變數，設定 Server Pro 使用新的 `2023.1-custom` 映像檔：

```text wrap
TEX_LIVE_DOCKER_IMAGE: "ghcr.io/ayaka-notes/texlive-full:2023.1-custom"
ALL_TEX_LIVE_DOCKER_IMAGES: "ghcr.io/ayaka-notes/texlive-full:2023.1,ghcr.io/ayaka-notes/texlive-full:2023.1-custom"
```

在上述範例中，新專案預設會使用新的 `2023.1-custom` 映像檔，而 `2023.1` 仍可在需要時使用。
