你可以使用新的 Dockerfile 擴充既有的 TeX Live 映像檔，並設定應用程式使用新的映像檔。

以下是安裝新套件或字型的一些指引。

TeX Live 映像檔的更新頻率不高。我們建議在升級 Ayakaleaf Pro 時重新建置自訂映像檔。

<Danger>

以下各節僅適用於[沙箱編譯](/zh-TW/on-premises/configuration/overleaf-toolkit/sandboxed-compiles)。

</Danger>

### 安裝與更新新套件

你可以使用 `tlmgr install` 與 `tlmgr update` 等 `tlmgr` 指令來管理 TeX Live 套件，如下例所示：

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2023.1

RUN tlmgr update --force ebproof
```

### 在較舊的 TeX Live 映像檔中使用 `tlmgr`

預設情況下，`tlmgr` 會從最新的 TeX Live 版本下載資源。為較舊的 TeX Live 映像檔進行修補時，需要將下載來源切換至相應的封存庫。封存庫的鏡像站清單請參閱 [https://www.tug.org/historic/](https://www.tug.org/historic/)。

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2022.1

RUN tlmgr option repository <MIRROR>/systems/texlive/<YEAR>/tlnet-final
# e.g. RUN tlmgr option repository ftp://tug.org/historic/systems/texlive/2022/tlnet-final

RUN tlmgr update --force ebproof
```

### 安裝新字型

在 TeX Live 發行版中安裝新字型有多種不同的程序，安裝自訂字型可能需要好幾個步驟。參考 TeX Live 官方文件中的[安裝 TeX 字型說明](https://tug.org/fonts/fontinstall.html)會是不錯的起點。

以下 `Dockerfile` 示範如何在既有的 TeX Live 2022 映像檔上安裝 TrueType 字型：

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2022.1

COPY ./myfonts/*.ttf /usr/share/fonts/truetype/myfont/

# rebuild font information cache
RUN fc-cache
```

### 設定 Ayakaleaf Pro 使用新的映像檔

使用名稱 `ghcr.io/ayaka-notes/texlive-full` 搭配自訂標籤來建置新映像檔，例如：

```bash
docker build -t ghcr.io/ayaka-notes/texlive-full:2023.1-custom .
```

現在，我們可以透過更新 `TEX_LIVE_DOCKER_IMAGE`、`ALL_TEX_LIVE_DOCKER_IMAGES` 與 `ALL_TEX_LIVE_DOCKER_IMAGE_NAMES` 環境變數（名稱為選填，並依照映像檔的順序對應），設定 Ayakaleaf Pro 使用新的 `2023.1-custom` 映像檔：

```text wrap
TEX_LIVE_DOCKER_IMAGE: "ghcr.io/ayaka-notes/texlive-full:2023.1-custom"
ALL_TEX_LIVE_DOCKER_IMAGES: "ghcr.io/ayaka-notes/texlive-full:2023.1,ghcr.io/ayaka-notes/texlive-full:2023.1-custom"
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES: "TeX Live 2023,TeX Live 2023 custom"
```

在上述範例中，新專案預設會使用新的 `2023.1-custom` 映像檔，而 `2023.1` 仍可在需要時使用。

自訂映像檔只存在於你的主機上，因此 `bin/up` 無法拉取它。請在 `config/overleaf.rc` 中設定 `SIBLING_CONTAINERS_PULL=false`（其他映像檔請自行使用 `docker pull` 拉取），然後執行 `bin/up -d` 套用新設定。

### 問與答

<Accordion title="使用 XeLaTeX 編譯中文文件時，需要安裝中文字型嗎？">

<strong>回答：</strong>使用 `texlive-full` 映像檔時不需要。這些映像檔已包含 TeX Live 中文套件（`ctex`、`xeCJK`）與 Fandol 字型，以及 Noto CJK 字型（例如 `Noto Serif CJK SC`）。請在編輯器設定中將專案的編譯器設為 XeLaTeX，然後進行編譯，例如：

```latex
\documentclass{ctexart}
\begin{document}
你好，世界！
\end{document}
```

若要改用 Noto 而非 Fandol，請加入 `\setCJKmainfont{Noto Serif CJK SC}`。不需要 `latexmkrc`。若要使用其他字型，請依照[安裝新字型](#installing-new-fonts)中的說明建置自訂映像檔。

</Accordion>
