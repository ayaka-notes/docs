<Danger>

請務必在每次主要版本升級**之前**進行[一致性備份](/zh-TW/on-premises/maintenance/data-and-backups#performing-a-consistent-backup)，以便在必要時能夠回復。

</Danger>

[ayakaleaf toolkit↗](https://github.com/ayaka-notes/toolkit) 是一個 git 儲存庫，因此可以輕鬆取得新的 Toolkit 功能。只要執行 `bin/upgrade` 指令並依照畫面上的提示操作即可。

值得注意的是，Docker 映像檔版本（位於 `config/version`）與 Toolkit 程式碼更新是分開管理的。更新 Toolkit 程式碼**不會**自動變更您正在執行的 Docker 映像檔版本。這表示在大多數情況下，您可以升級 Toolkit 版本而無需升級您的部署。

#### `bin/upgrade` 指令碼

執行 `bin/upgrade` 指令時，指令碼會檢查 Toolkit 程式碼是否有可用的更新，並詢問是否要更新您的 Toolkit。您隨時可以拒絕此升級，且不會有任何變更。

如果您選擇更新 Toolkit 程式碼，指令碼接著會檢查_預設_ Docker 映像檔版本是否已變更，並詢問是否要將本機版本檔案（位於 `config/version`）升級為新的預設值。

如果您選擇切換版本，指令碼會引導您完成關閉 Docker 服務、進行備份以及重新啟動 Docker 服務的流程。您的舊版本檔案會自動複製到 `config/__old-version`，以備您需要回復到該版本的 Docker 映像檔。

<Info>

對於手動匯入 Docker 映像檔的離線隔離（air-gapped）環境，請在 `config/overleaf.rc` 檔案中設定 `PULL_BEFORE_UPGRADE=false`。

有關在離線隔離／離線環境中部署的更多資訊，請參閱[這裡](/zh-TW/on-premises/installation/air-gapped-offline-deployments)。

</Info>

### 升級路徑

如果您執行的是 v6.0.0 之前的 Overleaf Community 舊版本，請參閱 [Overleaf 官方文件](https://docs.overleaf.com/on-premises/maintenance/upgrading-your-deployment#upgrade-path)完成升級。
