<Danger>

請務必在每次主要版本升級**之前**進行[一致性備份](/zh-TW/on-premises/maintenance/data-and-backups#performing-a-consistent-backup)，以便在需要時能夠復原。

</Danger>

[ayakaleaf toolkit↗](https://github.com/ayaka-notes/toolkit) 是一個 Git 儲存庫，因此取得新的 Toolkit 功能非常容易。只需執行 `bin/upgrade` 指令並依照螢幕上的提示操作即可。

值得注意的是，Docker 映像檔版本（位於 `config/version`）與 Toolkit 程式碼更新是分開管理的。更新 Toolkit 程式碼**不會**自動變更您正在執行的 Docker 映像檔版本。這表示在大多數情況下，您可以升級 Toolkit 版本而不需升級您的部署。

#### `bin/upgrade` 腳本

當您執行 `bin/upgrade` 指令時，腳本會檢查 Toolkit 程式碼是否有可用的更新，並詢問是否要更新您的 Toolkit。您隨時可以拒絕此升級，任何內容都不會變更。

如果您選擇更新 Toolkit 程式碼，腳本接著會檢查_預設_ Docker 映像檔版本是否已變更，並詢問是否要將您的本機版本檔案（位於 `config/version`）升級為新的預設值。

如果您選擇切換版本，腳本會引導您完成關閉 Docker 服務、進行備份以及重新啟動 Docker 服務的流程。您的舊版本檔案會自動複製到 `config/__old-version`，以防您需要復原到該版本的 Docker 映像檔。

<Info>

對於手動匯入 Docker 映像檔的離線隔離（air-gapped）環境，請在 `config/overleaf.rc` 檔案中設定 `PULL_BEFORE_UPGRADE=false`。

有關在離線隔離／離線環境中部署的更多資訊，請參閱[這裡](/zh-TW/on-premises/installation/air-gapped-offline-deployments)。

</Info>

### 升級路徑

如果您正在執行 v6.0.0 之前的舊版 Overleaf Community，請參閱 [Overleaf 官方文件](https://docs.overleaf.com/on-premises/maintenance/upgrading-your-deployment#upgrade-path)以完成升級。

在 Ayakaleaf Pro 中，請先升級至目前版本線的最新修補版本，再升級至下一個版本線，例如 `6.2.0 → 6.2.2 → 6.3.2`。請閱讀您所經過每個版本的[版本資訊](/zh-TW/on-premises/release-notes/release-notes-6.x.x)，其中部分版本需要額外的步驟。僅支援最新的發行版本。
