### 四處看看

現在您已經有了 Toolkit 的本機副本，讓我們使用 `ls` 指令來看看這個儲存庫的結構。

```bash title="Run this"
ls -l
```

<Info>

`ls -l` 指令會以詳細的長清單格式顯示目錄內容，並提供權限、擁有者與大小等額外的檔案資訊。

</Info>

如果一切都成功複製，您應該會看到類似以下的內容：

```text
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 bin
-rw-r--r-- 1 fry fry  6465 Aug 30 14:16 CHANGELOG.md
drwxr-xr-x 2 fry fry  4096 Sep  6 12:43 config
drwxr-xr-x 5 fry fry  4096 Aug 30 14:22 data
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 doc
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 lib
-rw-r--r-- 1 fry fry 34520 Aug 30 14:16 LICENSE
-rw-r--r-- 1 fry fry  1178 Aug 30 14:16 README.md
```

<Info>

所有使用者自有的設定檔都位於 `config/` 目錄中。此目錄**不受** git 版本控制系統管理，因此更新 Toolkit 時不會變更其內容。

</Info>

## 儲存庫結構

| 名稱     | 說明                                                                                                                                                                                                                                               |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `bin`    | 此資料夾包含一系列協助您管理 Overleaf 伺服器執行個體的指令碼。您可以在下方的「指令」章節進一步了解這些指令碼。                                                                                     |
| `config` | 此資料夾包含您自己的本機設定檔。                                                                                                                                                                                                  |
| `lib`    | 此資料夾包含 Toolkit 使用的基礎設定檔。                                                                                                                                                                                        |
| `data`   | 預設情況下，此資料夾是 MongoDb、Redis 與 Overleaf 的儲存位置。詳細資訊請參閱下方的[持久性資料](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/files-and-locations#persistent-data)章節。 |

<Warning>

我們建議**不要**直接修改 `/config` 資料夾以外的檔案。如果需要進行變更，可以透過在 **config/variables.env** 或 **config/overleaf.rc** 中設定環境變數來完成。\
例如，若要設定 `mongo` 服務的映像檔，請不要直接編輯 `lib/docker-compose.mongo.yml`，而是在 `config/overleaf.rc` 中使用環境變數 `MONGO_IMAGE` 設定映像檔。詳細資訊請參閱 [Toolkit 設定](/zh-TW/on-premises/configuration/overleaf-toolkit/toolkit-settings)頁面。

</Warning>

<Info>

未經您的許可，Toolkit **不會**變更 `config/` 目錄中的任何資料。

</Info>
