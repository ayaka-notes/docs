### 下載 Toolkit

Toolkit 同時相容於 Server CE 與 Ayakaleaf Pro，也是建議的安裝方式。使用 Toolkit 可讓您輕鬆開始使用 Server CE，並在需要時順利升級至 Ayakaleaf Pro。

<Info>

[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) 經過修改，會直接使用 ghcr 上的 overleaf-pro 映像檔，並搭配 ayaka-notes 提供的 TeX Live。您也可以改為下載官方的 overleaf-toolkit。

</Info>

<Steps>
<Step title="複製 Overleaf Toolkit 儲存庫">
要安裝 Toolkit，請先切換到預定的安裝路徑，然後使用以下指令複製 Overleaf Toolkit（@Ayaka-notes）GitHub 儲存庫：

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
# official toolkit (Not Recommended)
# git clone https://github.com/overleaf/toolkit.git ./overleaf-toolkit
```

<Info>

為避免可能的權限問題，我們建議將 Toolkit 安裝在使用者的 `$HOME` 目錄中。

</Info>
</Step>

<Step title="切換到 Toolkit 目錄">
等待複製程序完成後，切換到新建立的 `overleaf-toolkit` 目錄：

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
