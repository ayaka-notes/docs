---
title: 4. 取得 Ayakaleaf Pro 映像檔
icon: split
---

Ayakaleaf Pro 以 Docker 映像檔的形式發布於 [ghcr](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/) 映像檔倉庫，並對所有人**公開存取**。我們同時提供 amd64 與 arm64 架構的映像檔。拉取映像檔時，系統會根據您的系統架構自動選擇對應的映像檔。

#### Ayaka-notes Toolkit 使用者

如果您使用的是 [ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)，Ayakaleaf Pro 可以直接取代 Community Edition，因此您可以沿用現有的設定與自訂內容。若要在 Toolkit 中啟用 Pro，請編輯 `config/overleaf.rc` 並設定 `SERVER_PRO` 環境變數：

```text title="config/overleaf.rc"
SERVER_PRO=true
```

下次執行 `bin/up` 時，Toolkit 會自動下載並使用 Ayakaleaf Pro 映像檔。

#### 官方 Toolkit 使用者

如果您使用的是 [overleaf/toolkit](https://github.com/overleaf/toolkit)，請執行以下指令拉取 Pro 映像檔：

```bash title="Pull Docker Images"
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

接著，在 `overleaf-toolkit/config` 目錄中新增一個名為 `docker-compose.override.yml` 的檔案，內容如下：

```yml title="docker-compose.override.yml"
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

下次執行 `bin/up` 時，Toolkit 會自動下載並使用 Ayakaleaf Pro 映像檔。
