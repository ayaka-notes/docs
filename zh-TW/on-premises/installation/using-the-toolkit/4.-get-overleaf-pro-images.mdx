---
title: 4. 取得 Ayakaleaf Pro 映像檔
icon: split
---

Ayakaleaf Pro 是發布於 [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/) 上的免費 Docker 映像檔。拉取映像檔不需要帳號，也不需要登入。映像檔同時為 amd64 與 arm64 架構建置，Docker 會自動選擇與您伺服器相符的版本。

開啟 `config/overleaf.rc` 並設定：

```text title="config/overleaf.rc"
SERVER_PRO=true
```

下次執行 `bin/up` 時，Toolkit 會下載 Ayakaleaf Pro 映像檔，並以它取代官方的 Overleaf Community Edition。您在 `config/` 中的設定仍可繼續使用。

<Accordion title="已經在使用官方的 Overleaf Toolkit（overleaf/toolkit）？">

您不需要重新安裝。請拉取 Ayakaleaf Pro 映像檔：

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

接著，在 `overleaf-toolkit/config` 目錄中新增一個名為 `docker-compose.override.yml` 的檔案，內容如下：

```yml
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

下次執行 `bin/up` 時，Toolkit 就會使用 Ayakaleaf Pro 映像檔。

</Accordion>
