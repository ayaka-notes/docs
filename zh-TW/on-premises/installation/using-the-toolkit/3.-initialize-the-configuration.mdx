### 初始化設定

讓我們執行內建的 `bin/init` 指令碼，以一些合理的預設值初始化新伺服器的設定檔。

```text title="Run initialization"
bin/init
```

此指令碼**不會**覆寫任何既有的設定檔。

現在，讓我們使用 `ls` 指令檢查 `config/` 目錄的內容：

```text title="List the config directory"
ls config
```

若一切初始化成功，您應該會看到三個設定檔：`overleaf.rc`、`variables.env` 和 `version`。這些是伺服器的主要設定檔，可讓您自訂伺服器的運作方式，以及使用者與執行個體互動的方式。

| 名稱            | 說明                                             |
| --------------- | ------------------------------------------------------- |
| `overleaf.rc`   | 主要的最上層設定檔。                  |
| `variables.env` | 載入至 Docker 容器的環境變數。 |
| `version`       | 要使用的 Docker 映像檔版本。                 |

<Info>

目前您只需要知道這些檔案的存在以及它們的位置即可。在文件後續內容中，我們會更詳細地介紹每個檔案，並說明如何使用它們來自訂您的執行個體。若想先睹為快，可以在[檔案與位置頁面](/zh-TW/on-premises/configuration/overleaf-toolkit/files-and-locations)查看這些設定檔的完整說明。

</Info>
