[Toolkit](https://github.com/ayaka-notes/toolkit) 是部署 Ayakaleaf Pro 執行個體的建議方式。

在本節中，我們將引導您從 GitHub 下載 Toolkit、熟悉 Toolkit 的一些指令，並設定一些基本設定。完成本頁後，您應該就會有一個正在執行的地端 Overleaf 執行個體。

<Info>

預設情況下，執行個體只接受來自伺服器本機的連線，位址為 `http://localhost`。若要從其他電腦或其他連接埠開啟，請在 `config/overleaf.rc` 中設定 `OVERLEAF_LISTEN_IP` 與 `OVERLEAF_PORT`，如 [5. 個人化您的執行個體](/zh-TW/on-premises/installation/using-the-toolkit/5.-personalizing-your-instance)所述。

</Info>
