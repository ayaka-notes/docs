Overleaf 在 Docker 上執行。您必須安裝：

* Docker Engine（Docker CE）
* Docker Compose 外掛程式（`docker compose`，v2）

以下步驟適用於近期的 Ubuntu LTS 版本（20.04/22.04/24.04）。

<Warning>

請避免從 Ubuntu 預設的 apt 儲存庫安裝 `docker.io`。\
請使用 Docker 官方儲存庫，以取得較新的 Docker 版本與 `docker compose` 外掛程式。

</Warning>

官方文件來源：[https://docs.docker.com/engine/install/ubuntu/](https://docs.docker.com/engine/install/ubuntu/)。

<Steps>
<Step title="1) 移除舊版或衝突的套件（若存在）">
如果先前曾從其他來源安裝 Docker，請先將其移除：

```bash wrap
sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-compose-v2 docker-doc podman-docker containerd runc | cut -f1)
```

即使部分套件並未安裝，執行此指令也是安全的。
</Step>

<Step title="2) 新增 Docker 官方 apt 儲存庫">
安裝必要套件：

```bash
sudo apt update
sudo apt install -y ca-certificates curl
```

新增 Docker GPG 金鑰：

```bash wrap
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```

新增儲存庫：

```bash wrap
# Add the repository to Apt sources:
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Signed-By: /etc/apt/keyrings/docker.asc
EOF

sudo apt update
```
</Step>

<Step title="3) 安裝 Docker Engine 與 Compose 外掛程式">
安裝 Docker 與 Compose 外掛程式：

```bash wrap
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

設定 Docker 開機自動啟動：

```bash
sudo systemctl enable --now docker
```
</Step>

<Step title="4) 驗證安裝">
以下指令應能正常執行而不出現錯誤：

```bash
docker --version
docker compose version
sudo docker run --rm hello-world
docker ps
```
</Step>

<Step title="5)（選用）不使用 sudo 執行 Docker">
將您的使用者加入 `docker` 群組：

```bash
sudo usermod -aG docker $USER
```

接著**登出後重新登入**，或執行：

```bash
newgrp docker
```

現在以下指令應該不需要 `sudo` 即可執行：

```bash
docker ps
```

<Danger>

`docker` 群組在主機上擁有等同 root 的存取權限。\
這在一般的 Overleaf 安裝中屬於預期情況，若您啟用了沙箱編譯（Sandboxed Compiles）則更需特別注意。

</Danger>
</Step>
</Steps>
