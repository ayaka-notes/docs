---
title: 隔離網路／離線部署
description: 透過匯出、傳輸與載入 Docker 映像檔，以離線方式部署 Ayakaleaf Pro。
icon: block-brick
---

一般而言，我們不建議在離線環境中部署 Ayakaleaf Pro，因為它的許多功能（例如 GitHub 同步與 Zotero 整合）都需要網際網路連線。

如果您想在離線狀態下工作，可能無法連上 `ghcr.io` 映像檔倉庫來拉取所需的 `ayakaleaf-pro` 與 TeX Live 映像檔。這不成問題，因為 Docker 提供了匯出與匯入映像檔的工具，可協助您進行離線／隔離網路部署。

整體而言，您需要在可連上網際網路的裝置上下載所需的映像檔，將其匯出至可攜式裝置（或使用 SCP/Rsync 傳輸），再匯入到隔離網路的伺服器上。

為此，您需要完成下列步驟：

* 在可連上網際網路的機器上拉取所有需要的映像檔（`overleaf-pro`、`git-bridge`、`mongo`、`redis`，以及[沙箱編譯](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles)所需的任何 [TeX Live 映像檔](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles#available-tex-live-images)）
  * `docker pull ghcr.io/ayaka-notes/overleaf-pro:6.1.2`
  * `docker pull quay.io/sharelatex/git-bridge:6.1.2` （標籤必須與 `overleaf-pro` 相同）
  * `docker pull mongo:6` （請改為實際版本）
  * `docker pull redis:6.2` （請改為實際版本）
  * `docker pull ghcr.io/ayaka-notes/texlive-full:2024.1` （請改為實際版本）
* 接著，您需要將拉取的**每個**映像檔匯出為 .tar 檔案。例如：`docker save ghcr.io/ayaka-notes/overleaf-pro:6.1.2 > overleaf-pro:6.1.2.tar`
* 使用您偏好的方式，將 `.tar` 檔案從可連網的機器傳輸到離線／隔離網路的伺服器
* 對於每個 .tar 檔案，使用 `docker load` 指令從 .tar 檔案載入映像檔。例如：`docker load < overleaf-pro:6.1.2.tar`
* 最後，執行 `docker images` 指令以檢視／確認映像檔已成功載入且可供使用

<Danger>

預設情況下，執行 `bin/up` 指令時，Toolkit 會嘗試自動拉取 `config/variables.env` 中透過 `ALL_TEX_LIVE_DOCKER_IMAGES` 設定的每個 TeX Live 映像檔。由於您的部署處於隔離網路環境，這會失敗；您可以在 `config/overleaf.rc` 中設定 `SIBLING_CONTAINERS_PULL=false` 來停止此行為。

</Danger>
