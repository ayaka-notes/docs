---
title: 0. 準備主機
description: 在設定 rootless Podman 之前，檢查作業系統和 SELinux，並安裝 git。

---

您不需要手動安裝 Podman：[2. 執行 podman-setup](/zh-TW/on-premises/installation/using-podman/2.-run-podman-setup) 會把它和其他所需的套件一起安裝。在這裡，您只需檢查主機並安裝 `git`，下載 Toolkit 時需要用到它。

<Steps>
<Step title="檢查作業系統和 SELinux">
以將要執行 Ayakaleaf Pro 的使用者（而不是 `root`）登入，檢查發行版和 SELinux 模式：

```bash title="Check the host"
grep PRETTY_NAME /etc/os-release
getenforce
```

您應該會看到版本為 9 或更新的 RHEL、Rocky Linux、AlmaLinux 或 CentOS Stream，以及 `Enforcing`：

```text
PRETTY_NAME="Rocky Linux 9.9 (Blue Onyx)"
Enforcing
```
</Step>

<Step title="檢查您能否使用 sudo">
`bin/podman-setup --apply` 會透過 `sudo` 安裝套件並載入 SELinux 模組，需要時會詢問您的密碼：

```bash title="Check sudo"
sudo -v
```

如果失敗，請要求管理員將您的使用者加入 `wheel` 群組。
</Step>

<Step title="安裝 git">
```bash title="Install git"
sudo dnf install -y git
```

<Warning>

請勿在這台主機上安裝 Docker Engine。`bin/podman-setup` 安裝的套件 `podman-docker` 提供 `docker` 指令，而且只要存在 `podman` 指令，Toolkit 就會將主機視為 Podman 主機。

</Warning>
</Step>
</Steps>
