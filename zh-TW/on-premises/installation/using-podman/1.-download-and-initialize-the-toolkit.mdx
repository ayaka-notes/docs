title: 1. 下載並初始化 Toolkit
description: 複製 Ayakaleaf Toolkit、建立設定，並為在 Podman 上執行 Ayakaleaf Pro 進行設定。
icon: arrow-down-to-bracket
---

<Steps>
<Step title="複製 Toolkit">
將 **Ayakaleaf Toolkit**（[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)）複製到您的主目錄，並切換到該目錄：

```bash title="Clone the Toolkit" wrap
git clone https://github.com/ayaka-notes/toolkit.git ~/overleaf-toolkit
cd ~/overleaf-toolkit
```

後續所有指令都在這個目錄中執行。
</Step>

<Step title="建立設定">
```bash title="Run initialization"
bin/init
```

這會建立 `config/overleaf.rc`、`config/variables.env` 和 `config/version`，詳見 Docker 指南中的 [3. 初始化設定](/zh-TW/on-premises/installation/using-docker-compose/linux/3.-initialize-the-configuration)。`bin/init` 目前還不需要 Podman。
</Step>

<Step title="設定 config/overleaf.rc">
開啟 `config/overleaf.rc` 並修改以下幾行：

```bash title="config/overleaf.rc"
SERVER_PRO=true
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
```

然後在檔案末尾加入這一行：

```bash title="config/overleaf.rc"
SELINUX_MODE=managed
```

| 設定                              | 原因                                                                                                                                                                                                        |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SERVER_PRO=true`                 | 使用來自 `ghcr.io` 的 Ayakaleaf Pro 映像檔，無需登入。                                                                                                                                                       |
| `OVERLEAF_PORT=8080`              | Rootless Podman 無法監聽低於 `1024` 的連接埠，預設的 `80` 會失敗。                                                                                                                                           |
| `SIBLING_CONTAINERS_ENABLED=true` | 每次編譯都在獨立的 TeX Live 容器中執行。預設已經是 `true`；Podman 設定只支援這種模式。                                                                                                                       |
| `SELINUX_MODE=managed`            | 以 SELinux 類型 `sharelatex_t` 執行 `sharelatex` 容器，該類型可以使用 Podman 通訊端，除此之外沒有其他權限。`bin/podman-setup --apply` 會為它安裝原則模組。其他模式請參閱 [Toolkit 設定](/zh-TW/on-premises/configuration/overleaf-toolkit/toolkit-settings)。 |

保持 `DOCKER_SOCKET_PATH` 不變：`bin/podman-setup --apply` 會在下一步將它設定為您的 Podman 通訊端。

<Warning>

請維持 `GIT_BRIDGE_ENABLED=false`。在 Ayakaleaf Pro 6.3.4 中，Git 整合無法在 Podman 上使用，請參閱 [已知限制](/zh-TW/on-premises/installation/using-podman#known-limitations)。

</Warning>
</Step>

<Step title="選擇 TeX Live 映像檔">
開啟 `config/variables.env`，移除 `TEX_LIVE_DOCKER_IMAGE` 和 `ALL_TEX_LIVE_DOCKER_IMAGES` 前面的 `#`，並列出要使用的 TeX Live 映像檔：

```bash title="config/variables.env" wrap
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
```

如果清單為空，`bin/up` 會停止並顯示 `Please configure ALL_TEX_LIVE_DOCKER_IMAGES`。`texlive-full` 很大；對於測試伺服器，小得多的 `ghcr.io/ayaka-notes/texlive-basic:2026.1` 也可以使用。可用的映像檔請參閱 [沙箱編譯](/zh-TW/on-premises/configuration/overleaf-toolkit/sandboxed-compiles)。

依照 [5. 個人化你的執行個體](/zh-TW/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance#required-environment-variables) 中的說明設定其他變數，例如 `OVERLEAF_SITE_URL`。使用預設監聽位址時，請使用 `http://localhost:8080`。
</Step>
</Steps>
