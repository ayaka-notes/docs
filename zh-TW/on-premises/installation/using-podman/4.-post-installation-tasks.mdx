### 建立您的第一個管理員帳戶 {#create-your-first-administrator-account}

開啟 [http://localhost:8080/launchpad](http://localhost:8080/launchpad)，或者您的 `OVERLEAF_SITE_URL` 加上 `/launchpad`，註冊管理員帳戶。從這裡開始，一切都與 Docker 相同：依照 Docker 指南中的 [6. 安裝後工作](/zh-TW/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks) 操作，並在其中的 `localhost` 連結裡使用連接埠 `8080`。

建立範例專案並編譯它。產生的 PDF 表示編譯透過 Podman 在 TeX Live 容器中執行。若要查看編譯容器：

```bash title="List the compile containers"
podman ps -a --filter name=project- --format "{{.Names}} {{.Image}} {{.Status}}"
```

### 使用 HTTPS {#use-https}

Toolkit 的 [TLS 代理](/zh-TW/on-premises/configuration/overleaf-toolkit/tls-proxy) 可以在 Podman 上使用：執行 `bin/init --tls`，並依照該頁面的說明設定憑證和 `NGINX_ENABLED=true`。它監聽連接埠 `80` 和 `443`，而 rootless Podman 預設無法使用這些連接埠。允許非特權使用者使用從 `80` 開始的連接埠：

```bash title="Allow ports 80 and 443"
echo "net.ipv4.ip_unprivileged_port_start=80" | sudo tee /etc/sysctl.d/99-unprivileged-ports.conf
sudo sysctl --system
```

這會讓伺服器上的每位使用者都能監聽這些連接埠，因此只應在專用於 Ayakaleaf Pro 的伺服器上這麼做。然後在防火牆中開放這些連接埠：

```bash title="Open ports 80 and 443"
sudo firewall-cmd --permanent --add-port=80/tcp --add-port=443/tcp
sudo firewall-cmd --reload
```

將 `OVERLEAF_SITE_URL` 設定為您的 `https://` 位址，然後執行 `bin/up -d`。保持預設的 `NGINX_HTTP_PORT=80` 和 `TLS_PORT=443`：使用其他連接埠時，從 HTTP 到 HTTPS 的重新導向會指向錯誤的連接埠。

<Info>

使用 TLS 代理時，請將 `OVERLEAF_LISTEN_IP` 保持為 `127.0.0.1`，讓其他電腦無法連線到連接埠 `8080`。

</Info>

### 升級 {#upgrade}

使用 `bin/upgrade` 升級，詳見 [升級您的部署](/zh-TW/on-premises/maintenance/upgrading-your-deployment)。在 Podman 上，它也會將新版本的 seccomp 設定檔擷取到 `config/seccomp/<version>/`，並更新 `SECCOMP_PROFILE`：

```text
Over-writing config/version with 6.3.4
Set SECCOMP_PROFILE=/home/<user>/overleaf-toolkit/config/seccomp/6.3.4/clsi-profile.json in config/variables.env
```

升級後，執行 `bin/podman-setup` 檢查設定。

### 變更 SELinux 模式 {#change-the-selinux-mode}

`config/overleaf.rc` 中的 `SELINUX_MODE` 決定 SELinux 如何限制 `sharelatex` 容器。這些頁面設定的是 `managed`；其他模式請參閱 [Toolkit 設定](/zh-TW/on-premises/configuration/overleaf-toolkit/toolkit-settings)。變更後請執行 `bin/up -d`。
