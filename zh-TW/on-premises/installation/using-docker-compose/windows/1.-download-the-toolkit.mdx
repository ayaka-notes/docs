<Steps>
<Step title="安裝命令列工具">
在 **Ubuntu** 中執行，並使用您在步驟 0 建立的 Linux 密碼：

```bash
sudo apt update
sudo apt install -y git ca-certificates curl perl gawk openssl
```

Ubuntu 本身已提供 Bash、GNU sed 與 coreutils。與 macOS 不同，它不需要 Homebrew 或另外安裝 GNU sed。
</Step>

<Step title="複製 Ayakaleaf Toolkit 儲存庫">
請將 Toolkit 及其資料保存在 Ubuntu 的 Linux 檔案系統中，放在您的家目錄底下：

```bash
cd "$HOME"
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

對於線上資料庫與專案資料，請避免使用 `/mnt/c`、`/mnt/d`、OneDrive 與暫存目錄。Linux 檔案系統路徑可提供容器所預期的權限與檔案系統行為，並避免跨檔案系統的額外負擔；請參閱 [Microsoft 的檔案系統指引](https://learn.microsoft.com/en-us/windows/wsl/filesystems)。

<Warning>

若該目錄中已有安裝，請直接使用它，或為新執行個體選擇另一個目錄。請勿取代既有部署的設定或資料。

</Warning>
</Step>
</Steps>
