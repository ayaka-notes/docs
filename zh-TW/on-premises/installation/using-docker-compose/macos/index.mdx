在本節中，我們會使用 Docker Desktop 與 [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit)，在您的 Mac 上於本機執行 Ayakaleaf Pro。本指南使用 `http://localhost:8080`，將資料保存在您的家目錄中，並在沙箱容器中以 TeX Live 2026 進行編譯。

Docker Desktop 會在 Linux 虛擬機器中執行應用程式、MongoDB、Redis 與 TeX Live 編譯器。您不需要在 macOS 本身安裝 MongoDB、Redis 或 MacTeX。

此設定適用於個人使用與本機測試。若要提供全天候的共用服務，我們建議使用 [Linux 指南](/zh-TW/on-premises/installation/using-docker-compose/linux)，並搭配 HTTPS、備份與存取控制。當 Mac 進入睡眠或 Docker Desktop 停止時，執行個體將無法使用，請參閱[保持執行個體可用](/zh-TW/on-premises/installation/using-docker-compose/macos/6.-post-installation-tasks#keep-the-instance-available)。

## 開始之前 {#before-you-start}

您需要：

* [Docker Desktop for Mac](https://docs.docker.com/desktop/setup/install/mac-install/) 所支援的 macOS 版本。
* Git、[Homebrew](https://brew.sh/) 與 GNU sed。Toolkit 會使用 macOS 內建的 BSD sed 不接受的 GNU sed 選項。
* 足以同時供 macOS 與 Docker 使用的資源。對於小型的本機執行個體，請先為 Docker Desktop 配置 4 個 CPU 與 8 GB 記憶體。這是建議的起始值，而非實際量測的最低需求。
* 完整 TeX Live 映像檔所需的至少 40 GB 可用儲存空間，以及存放專案的空間。請同時檢查 Mac 上的可用空間與 Docker Desktop 的磁碟用量上限。請先從一個 TeX Live 版本開始：每增加一個版本，大約就需要同樣多的空間。

應用程式與 TeX Live 映像檔皆以 `arm64` 與 `amd64` 發布。在 Apple silicon 上，請讓 Docker 選擇原生的 ARM 映像檔，不要強制使用 `platform: linux/amd64`。
