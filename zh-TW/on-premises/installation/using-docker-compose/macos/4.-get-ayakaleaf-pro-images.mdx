---
title: 4. 取得 Ayakaleaf Pro 映像檔
description: 將 Mac 上的 Toolkit 切換為公開的 Ayakaleaf Pro 映像檔。
icon: split
---

Ayakaleaf Pro 是放在 [GitHub Container Registry（ghcr.io）](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/)上的免費 Docker 映像檔。您不需要帳號、登入或商業 Overleaf 授權即可拉取。

開啟 `config/overleaf.rc` 並設定：

```bash title="config/overleaf.rc"
SERVER_PRO=true
```

下次執行 `bin/up` 時，Toolkit 會拉取 `config/version` 所指定版本的 `ghcr.io/ayaka-notes/overleaf-pro`，而不是官方的 Overleaf Community Edition。

此映像檔是為 `arm64` 與 `amd64` 建置的，Docker 會選擇符合您 Mac 的版本。在 Apple silicon 上，請勿在覆寫設定中加入 `platform: linux/amd64`：否則映像檔將會在模擬環境下執行。
