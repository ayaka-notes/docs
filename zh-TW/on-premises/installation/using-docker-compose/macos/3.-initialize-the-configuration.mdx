---
title: 3. 初始化設定
description: 在 Mac 上使用 bin/init 建立 Toolkit 設定檔。
icon: circle-play
---

在 Toolkit 目錄中，於 GNU sed 已加入 `PATH` 的終端機內執行：

```bash
bin/init
```

`bin/init` 會建立三個檔案：

| 檔案 | 用途 |
| --- | --- |
| `config/overleaf.rc` | 容器設定、對外發布的連接埠與資料位置 |
| `config/variables.env` | 應用程式設定與機密 |
| `config/version` | 應用程式映像檔版本 |

它也會在 `config/variables.env` 中產生 `OVERLEAF_INVITE_TOKEN_SECRET`。請妥善保存，且不要公開此檔案或將其提交至版本控制。

請保留 Toolkit 為新安裝所選擇的版本。若之後要變更既有執行個體的版本，請依照[升級您的部署](/zh-TW/on-premises/maintenance/upgrading-your-deployment)操作。

<Warning>

若 `bin/init` 因 `sed: ... invalid command code` 而停止，表示它是以 macOS 的 BSD sed 執行的。這樣失敗的執行可能會在 `config/` 中留下三個檔案，且其中的 `OVERLEAF_INVITE_TOKEN_SECRET` 為空值，之後再次執行 `bin/init` 會回報 `Config files already exist`。請參閱[疑難排解](/zh-TW/on-premises/installation/using-docker-compose/macos/troubleshooting#initialization-fails-with-invalid-command-code)。

</Warning>
