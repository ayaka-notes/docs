description: 為 Mac 上的本機執行個體設定連接埠、網站 URL 與 TeX Live 映像檔，檢查 Docker VM 核心，並啟動 Ayakaleaf Pro。
icon: square-sliders
---

<Steps>
<Step title="容器設定">
編輯 `config/overleaf.rc` 中的這些既有項目：

```bash title="config/overleaf.rc"
PROJECT_NAME=ayakaleaf-macos
SERVER_PRO=true
OVERLEAF_LISTEN_IP=127.0.0.1
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
DOCKER_SOCKET_PATH=/var/run/docker.sock
```

請保留預設的資料路徑，以及內建的 MongoDB 與 Redis 服務。設定 `OVERLEAF_LISTEN_IP=127.0.0.1` 後，只有這台 Mac 上的瀏覽器能開啟執行個體。
</Step>

<Step title="應用程式設定">
在 `config/variables.env` 中設定以下值，並取代任何同名的已啟用項目：

```dotenv title="config/variables.env"
OVERLEAF_SITE_URL=http://localhost:8080
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES="TeX Live 2026"
```

產生一個 session 機密：

```bash
openssl rand -hex 32
```

將結果以 `OVERLEAF_SESSION_SECRET` 加入 `config/variables.env`。若沒有設定，每次 `bin/up` 重新建立容器時都會讓所有使用者登出，請參閱[環境變數](/zh-TW/on-premises/configuration/overleaf-toolkit/environment-variables)。

對於不使用電子郵件的本機執行個體，請保持 SMTP 設定與 `OVERLEAF_EMAIL_FROM_ADDRESS` 未設定。Git Bridge、外部驗證與其他整合功能，之後都可以依照各自的[設定頁面](/zh-TW/on-premises/configuration/overleaf-toolkit)加入。
</Step>

<Step title="檢查 Docker VM 的 Linux 核心" id="check-the-docker-vms-linux-kernel">
MongoDB 是在 Docker Desktop 虛擬機器的 Linux 核心上執行，而不是在 macOS 上。請在第一次啟動之前檢查其版本：

```bash
docker info --format '{{.KernelVersion}}'
```

MongoDB 文件記載了與 Linux 核心 **6.19 至 7.0.13** 的不相容問題，這也會影響 Docker 中的 MongoDB。修正方式是使用 **7.0.14 或更新版本**的核心，它會隨 Docker Desktop 更新一併提供，請參閱 [MongoDB 的正式環境注意事項](https://www.mongodb.com/docs/manual/administration/production-notes/)。

若您的 Docker VM 使用受影響的核心，請將以下內容加入 `config/docker-compose.override.yml`，並與您在其中已有的任何 `services` 合併：

```yaml title="config/docker-compose.override.yml"
services:
  mongo:
    environment:
      GLIBC_TUNABLES: glibc.pthread.rseq=1
```

<Warning>

有已修正的核心時，請進行更新。若您的核心不在受影響的範圍內，則不需要此因應措施。

</Warning>
</Step>

<Step title="啟動您的執行個體">
在 Toolkit 目錄中執行：

```bash
bin/up -d
```

Toolkit 會初始化 MongoDB 的複本集、拉取 TeX Live 映像檔並啟動應用程式。第一次下載需要一段時間。若要追蹤進度：

```bash
bin/docker-compose ps
bin/docker-compose logs --tail=100 -f sharelatex
```

按下 `Ctrl+C` 即可停止追蹤記錄。容器會繼續執行。

檢查對外發布的連接埠與首次執行頁面：

```bash
bin/docker-compose port sharelatex 80
curl -I http://localhost:8080/launchpad
```

連接埠應為 `127.0.0.1:8080`。
</Step>
</Steps>

<Info>

若之後要讓其他電腦開啟執行個體，請依照 Linux 指南的 [5. 個人化您的執行個體](/zh-TW/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance)說明，變更監聽位址與網站 URL，並設定 HTTPS。屆時 Mac 必須保持喚醒狀態，請參閱[保持執行個體可用](/zh-TW/on-premises/installation/using-docker-compose/macos/6.-post-installation-tasks#keep-the-instance-available)。

</Info>
