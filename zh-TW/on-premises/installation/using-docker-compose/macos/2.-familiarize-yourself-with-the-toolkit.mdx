Toolkit 在 macOS 與 Linux 上是相同的。它的目錄結構、`config/` 目錄以及 `bin/` 指令，都已在 Linux 指南的 [2. 熟悉 Toolkit](/zh-TW/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) 中說明。

在 macOS 上，請留意三項差異：

* 請在 GNU sed 位於 `PATH` 最前面的終端機中執行指令碼，請參閱 [1. 下載 Toolkit](/zh-TW/on-premises/installation/using-docker-compose/macos/1.-download-the-toolkit)。
* 在執行會與 Docker 溝通的指令碼（例如 `bin/up`、`bin/start` 或 `bin/docker-compose`）之前，請先啟動 Docker Desktop。
* `bin/doctor` 包含沿用自官方 Overleaf Toolkit 的檢查。在 macOS 上出現 `This system seems to not be Linux` 警告是正常的，而關於未登入 `quay.io` 的警告並不適用於公開的 `ghcr.io/ayaka-notes/overleaf-pro` 映像檔。報告中的其他問題仍然需要處理。
