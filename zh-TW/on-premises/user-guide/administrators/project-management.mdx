## 尋找專案 {#find-a-project}

在 **Search by project name, ID, owner or link** 中輸入內容。連結可以是專案的網址，也可以是它的某個分享連結。使用 **Status** 篩選器縮小清單範圍。點選 **Title** 或 **Last modified** 即可排序。

已刪除的專案不會出現在結果中。如果你的搜尋也符合某個已刪除的專案，表格上方會有一行提示，例如 **Found 1 matching deleted projects**。點選 **Display deleted projects** 即可查看。

## 專案狀態 {#project-status}

每個專案都有一個狀態，**Status** 篩選器會顯示每種狀態下的專案數量。

<Frame caption="Status 篩選器">
  <img src="/images/on-premises/project-management-status-filter.png" alt="包含 All、Active、Archived、Trashed 和 Deleted 的 Status 篩選器" />
</Frame>

| 狀態 | 意義 |
| --- | --- |
| **All** | 所有未刪除的專案。 |
| **Active** | 正常狀態。 |
| **Archived** | 擁有者已將其封存。專案完好無缺，可以還原。 |
| **Trashed** | 擁有者已將其移至垃圾桶。專案完好無缺，可以還原。 |
| **Deleted** | 由擁有者從垃圾桶中刪除、由管理員刪除，或隨擁有者帳號一起刪除。只有管理員可以還原。 |

專案會分階段經歷這些狀態：

1. **Active、Archived 和 Trashed** 由擁有者在自己的專案頁面中選擇。擁有者隨時可以改回來。從垃圾桶 **Restore** 一律回到 Active，即使專案之前是封存狀態。
2. **Deleted** 是下一個階段。擁有者只能從垃圾桶中刪除；管理員可以從這三種狀態中的任何一種刪除。
3. **Restore** 會將已刪除的專案還原為 **Active**，無論之前是什麼狀態，且專案名稱結尾會加上 `(Restored)`。只有管理員可以執行此操作。如果擁有者的帳號也已刪除，請先還原帳號：否則對話方塊會顯示 **The owner of this project is deleted: restore the owner first**。
4. **Delete permanently** 是最後階段，無法復原。除此之外，已刪除的專案會一直保留，直到你將其移除，除非執行個體設定了 [`ENABLE_CRON_RESOURCE_DELETION`](/zh-TW/on-premises/configuration/overleaf-toolkit/environment-variables)，該設定會在 90 天後移除它們。

<Info>

狀態只跟隨擁有者。當協作者封存共享專案或將其移至垃圾桶時，專案只在協作者自己的專案頁面中移動，這裡的狀態維持不變。

</Info>

## 專案操作 {#actions-on-a-project}

| 圖示 | 操作 | 作用 |
| --- | --- | --- |
| 開啟 | **Open Project** | 在新分頁的編輯器中開啟專案。 |
| 資料夾 | **Change project owner** | 將專案轉給另一位使用者。 |
| 垃圾桶 | **Delete** | 將專案移至 **Deleted**。 |
| 箭頭 | **Restore** | 還原已刪除的專案。僅適用於已刪除的專案。 |
| 打叉的垃圾桶 | **Delete permanently** | 永久移除已刪除的專案。僅適用於已刪除的專案。 |

### 變更擁有者 {#change-the-owner}

點選資料夾圖示，輸入姓名或電子郵件，選擇使用者，然後點選 **Change project owner**。對話方塊會提醒此操作無法復原，且新擁有者會收到通知並可變更專案的存取設定。已停用的帳號不會出現在選項中。如果選擇後又修改了文字，選擇會被取消：請重新選擇使用者。

<Frame caption="變更專案的擁有者">
  <img src="/images/on-premises/project-management-change-owner.png" alt="顯示警告並已選擇新擁有者的 Change project owner 對話方塊" />
</Frame>

若要一次轉移某位使用者的所有專案，請參閱[轉移使用者的專案](/zh-TW/on-premises/user-guide/administrators/user-management#transfer-a-users-projects)。

### 刪除、還原或永久刪除 {#delete-restore-or-permanently-delete}

點選垃圾桶圖示，然後點選 **Delete**。若要再次找到該專案，請在 **Status** 篩選器中選擇 **Deleted**。

<Frame caption="已刪除的專案">
  <img src="/images/on-premises/project-management-deleted.png" alt="清單中一個帶有 Restore 和 Delete permanently 圖示的已刪除專案" />
</Frame>

點選箭頭圖示再點選 **Restore** 可還原專案；點選打叉的垃圾桶再點選 **Delete permanently** 可將其移除。

<Frame caption="永久刪除專案">
  <img src="/images/on-premises/project-management-purge.png" alt="提醒此操作無法復原的 Delete permanently 對話方塊" />
</Frame>

### 一次變更多個專案 {#change-several-projects-at-once}

在清單中勾選專案。搜尋框旁會出現按鈕：**Download**、**Change project owner** 和 **Delete**。**Download** 會將所選專案儲存為一個 `.zip` 檔案。使用 **Change project owner** 時，無法選擇所勾選專案的目前擁有者。在 **Deleted** 檢視中，按鈕為 **Restore** 和 **Delete permanently**。

<Frame caption="批次操作">
  <img src="/images/on-premises/project-management-bulk.png" alt="兩個已勾選的專案以及 Download、Change project owner 和 Delete 按鈕" />
</Frame>

## 專案頁面 {#the-project-page}

點選專案標題即可開啟其頁面。頂端是用於編輯、開啟、下載和刪除專案的圖示。頁面有五個分頁。

### 概覽 {#overview}

專案的詳細資料和設定。點選鉛筆圖示可變更 **Name**、**Link sharing**、**Compiler**、**TeX Live version** 和 **Main document**，或點選 **Change project owner**。然後點選 **Save**。

<Frame caption="編輯專案">
  <img src="/images/on-premises/project-management-edit.png" alt="處於編輯模式的 Overview 分頁" />
</Frame>

### 檔案樹 {#file-tree}

專案的檔案和資料夾，唯讀。

<Frame caption="專案的檔案">
  <img src="/images/on-premises/project-management-files.png" alt="列出 frog.jpg、main.tex 和一個已還原 bib 檔案的 File tree 分頁" />
</Frame>

### 成員 {#members}

誰有存取權：擁有者、協作者和待處理的邀請。點選鉛筆圖示進行變更：

* 為協作者選擇 **Editor**、**Reviewer** 或 **Viewer**。變更會立即生效。
* 點選協作者旁的垃圾桶，然後點選 **Remove access**。
* 對於待處理的邀請，點選信封圖示可 **Resend invite**，點選垃圾桶可 **Revoke Invite**。

完成後點選 **Done**。此處無法變更擁有者：請使用 **Overview** 分頁上的 **Change project owner**。

<Frame caption="變更專案的成員">
  <img src="/images/on-premises/project-management-members.png" alt="處於編輯模式的 Members 分頁，包含角色選單、一個待處理的邀請和操作圖示" />
</Frame>

### 已刪除的檔案 {#deleted-files}

從專案中移除的檔案。點選檔案旁的箭頭圖示，然後點選 **Restore file**。一個名稱中帶日期的副本會放入專案根資料夾，該列會顯示副本的名稱。已刪除的檔案仍保留在清單中。

重新載入頁面後，副本會出現在 **File tree** 分頁中。

<Frame caption="已還原的檔案">
  <img src="/images/on-premises/project-management-deleted-files.png" alt="顯示 sample.bib 及其還原副本名稱的 Deleted files 分頁" />
</Frame>

此專案發生過的事情：日期、操作、執行者、IP 位址和詳細資料。你可以搜尋，也可以依 **Operation** 篩選。
