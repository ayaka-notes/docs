你可以在編輯器中發佈範本，並在範本庫中的範本頁面或管理面板中管理範本。

<Info>

要開啟範本庫、選擇其分類或允許非管理員使用者發佈範本，請參閱[範本](/zh-TW/on-premises/configuration/overleaf-toolkit/templates)。

</Info>

## 發佈專案 {#publish-a-project}

<Steps>
<Step title="編譯專案">
開啟專案並點擊 **Recompile**。你看到的 PDF 就是範本庫將顯示的 PDF。

當編輯器中沒有 PDF 時，例如開啟一個無法編譯的專案時，**Manage Template** 會顯示為灰色。

<Frame caption="還沒有 PDF，因此無法發佈">
  <img src="/images/on-premises/templates-admin-no-pdf.png" alt="File 選單中 Manage Template 顯示為灰色，旁邊是 No PDF 訊息" />
</Frame>

<Warning>

發佈會儲存檔案的目前狀態，以及最後一次成功編譯產生的 PDF。如果你在那次編譯之後編輯了專案，或最後一次編譯失敗，範本庫會在較新的檔案旁顯示舊的 PDF，而這些檔案可能無法編譯。請反覆編譯直到 PDF 正確，然後再發佈。

</Warning>
</Step>

<Step title="開啟表單">
在編輯器的頂部選單中，點擊 **File**，然後點擊 **Manage Template**。

<Frame caption="File 選單">
  <img src="/images/on-premises/templates-admin-file-menu.png" alt="包含 Manage Template 的 File 選單" />
</Frame>
</Step>

<Step title="填寫表單">
<Frame caption="Manage Template 對話方塊">
  <img src="/images/on-premises/templates-admin-publish-form.png" alt="已填寫的 Manage Template 對話方塊，作者為 Markdown 連結，描述中使用了 Markdown" />
</Frame>

| 欄位 | 說明 |
| --- | --- |
| **Title** | 預設為專案名稱。在範本庫中必須唯一。最多 150 個字元。 |
| **Author** | 預設為你的名字。像 `[Demo Author](https://example.com)` 這樣的 Markdown 連結會在範本頁面上顯示為連結。 |
| **Categories** | 一個分類，請參閱[分類](/zh-TW/on-premises/user-guide/administrators/template-management#categories)。 |
| **Description** | 支援 Markdown。最多 4096 個字元。範本頁面將其顯示為 **Abstract**，範本庫以純文字顯示其開頭部分。 |
| **License** | **Creative Commons CC BY 4.0**、**LaTeX Project Public License 1.3c** 或 <strong>Other (as stated in the work)</strong>。 |

專案的編譯器和主文件會隨範本一起儲存，因此請先在專案中設定好。從範本開啟的專案會使用相同的設定。
</Step>

<Step title="點擊 Publish">
範本頁面隨即開啟。

<Frame caption="新範本">
  <img src="/images/on-premises/templates-admin-template-page.png" alt="範本頁面，包含 Open as Template、View PDF 和下載按鈕、詳細資訊，以及 Admin: Source Project、Edit 和 Delete" />
</Frame>

**Admin: Source Project**、**Edit** 和 **Delete** 只對你顯示。其他使用者只會看到 **Open as Template**、**View PDF** 和下載按鈕。
</Step>

<Step title="檢查範本庫">
點擊右上角的 **Templates**。新範本位於清單的第一位。
</Step>
</Steps>

## 分類 {#categories}

一個範本屬於一個分類。分類的名稱和描述來自你的[設定](/zh-TW/on-premises/configuration/overleaf-toolkit/templates#configuration)，無法在網站中修改。

你會在以下位置看到分類：

* 表單中的 **Categories**。
* 範本庫頁面 `/templates` 頂部的卡片。在 **All templates** 頁面點擊 **Template Gallery** 即可進入。
* 每個分類各自的頁面，例如 `/templates/presentation`。沒有範本的分類會顯示 <strong>No Templates.</strong>
* 專案頁面上的 **New project**，然後是 **More templates**。
* 範本頁面標題上方的連結。

<Frame caption="範本庫頁面上的分類">
  <img src="/images/on-premises/templates-admin-categories.png" alt="範本庫頁面，包含 Journal articles、Books 和 Presentations 卡片" />
</Frame>

表單中的 **All templates** 表示沒有自己的分類：該範本只會出現在完整清單中。

## 更新範本 {#update-a-template}

要變更檔案和 PDF，請以相同的標題再次發佈專案。

<Steps>
<Step title="修改專案">
編輯專案並點擊 **Recompile**。
</Step>

<Step title="再次發佈">
點擊 **File**，然後點擊 **Manage Template**。表單會顯示範本的詳細資訊，你可以修改它們。點擊 **Publish**。

會出現一則訊息，說明該標題已存在，按鈕變為 **Overwrite**。

<Frame caption="以相同標題發佈">
  <img src="/images/on-premises/templates-admin-overwrite.png" alt="Manage Template 對話方塊，顯示訊息 A template with this title already exists 和 Overwrite 按鈕" />
</Frame>

如果此時修改了 **Title**，訊息會消失，**Publish** 會建立一個新範本。
</Step>

<Step title="點擊 Overwrite">
同一個範本頁面會開啟，並顯示新的 PDF。

<Frame caption="已更新的範本">
  <img src="/images/on-premises/templates-admin-overwritten.png" alt="範本頁面，其預覽現在顯示文件的新標題" />
</Frame>

使用者已經從該範本開啟的專案不會改變。
</Step>
</Steps>

<Warning>

表單透過專案名稱尋找範本。如果你用 **Edit** 重新命名了範本，表單開啟時會顯示專案名稱、你的名字、第一個分類和空白的描述，而且輸入範本標題也無法還原其詳細資訊。此時 **Overwrite** 會用表單中的內容取代詳細資訊，因此請先重新填寫。

</Warning>

## 編輯詳細資訊 {#edit-the-details}

這會變更範本庫中顯示的範本資訊，而不會變更其檔案或 PDF。

<Steps>
<Step title="開啟範本">
點擊右上角的 **Templates**，點擊範本，然後點擊 **Edit**。
</Step>

<Step title="修改欄位">
欄位與發佈時相同，另外多了一個：**Language** 是從該範本開啟的專案的拼字檢查語言。對於以預設語言發佈的專案，它顯示 **Off**，從中開啟的專案使用 <strong>English (American)</strong>。

<Frame caption="Edit template 對話方塊">
  <img src="/images/on-premises/templates-admin-edit.png" alt="Edit template 對話方塊，包含 Title、Author、Categories、Description、License 和 Language" />
</Frame>

與其他範本相同的標題會被拒絕：在你修改 **Title** 之前，**Save** 一直顯示為灰色。
</Step>

<Step title="點擊 Save">
對話方塊關閉，範本頁面顯示新的詳細資訊。
</Step>
</Steps>

## 來源專案 {#the-source-project}

**Admin: Source Project** 會開啟發佈該範本的專案。

範本保有自己的檔案副本。如果你永久刪除了該專案，此按鈕會消失，使用者仍然可以開啟範本。僅位於 **Trash** 中的專案會保留此按鈕。另請參閱[範本](/zh-TW/on-premises/configuration/overleaf-toolkit/templates)下的問答。

## 刪除範本 {#delete-a-template}

<Steps>
<Step title="點擊 Delete">
在範本頁面上，點擊 **Delete**。對話方塊會顯示範本的名稱。

<Frame caption="Delete template 對話方塊">
  <img src="/images/on-premises/templates-admin-delete.png" alt="帶有 Confirm 按鈕的 Delete template 對話方塊" />
</Frame>
</Step>

<Step title="點擊 Confirm">
你會回到先前所在的頁面，該範本不再出現在範本庫中。其連結現在顯示 **Not found**。

來源專案會保留，使用者從該範本開啟的專案也會保留。
</Step>
</Steps>

## 在管理面板中管理範本 {#manage-templates-in-the-admin-panel}

點擊 **Admin**，然後點擊 **Project/Object Lookup**，再點擊 **Templates** 分頁。它會列出所有範本及其作者和擁有者，並且可以搜尋。

<Frame caption="管理面板中的所有範本">
  <img src="/images/on-premises/templates-admin-panel-tab.png" alt="管理面板的 Templates 分頁，顯示每個範本的標題、作者、擁有者和最後修改日期" />
</Frame>

* 點擊標題開啟範本頁面，或點擊開啟圖示在新分頁中開啟。
* 點擊擁有者開啟該使用者的頁面。
* 點擊垃圾桶圖示，然後點擊 **Delete** 刪除範本。對話方塊會警告此操作無法復原，範本將從範本庫中移除。

## 發佈被拒絕時 {#if-publishing-is-refused}

表單允許你輸入超過網站所接受的內容。**Title** 超過 150 個字元時顯示 `Template title exceeds the maximum length of 150 characters.`，**Description** 超過 4096 個字元時顯示 `Template description exceeds the maximum length of 4096 characters.`

之後即使你縮短了文字，**Publish** 仍然顯示為灰色。點擊 **Cancel**，再點擊 **File**，然後點擊 **Manage Template**，重新填寫表單。
