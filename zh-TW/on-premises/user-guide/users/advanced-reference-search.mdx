---

文獻搜尋會查找專案中所有的 `.bib` 檔案，因此你不必記得引用鍵也能找到參考文獻。不需要任何設定。

你的專案至少需要一個 `.bib` 檔案。你可以上傳一個，或從 [Zotero](/zh-TW/on-premises/user-guide/users/zotero-integration) 或 [Mendeley](/zh-TW/on-premises/user-guide/users/mendeley-integration) 匯入文獻庫。

## 插入引用 {#insert-a-citation}

<Steps>
<Step title="開始引用">
在 `.tex` 檔案中輸入 `\cite{`。編輯器會自動補上右大括號。游標下方會顯示引用鍵與一個藍色框 **Open advanced reference search**。

<Frame caption="引用下方的藍色框">
  <img src="/images/on-premises/reference-search-hint.png" alt="編輯器中的 \cite{}、引用鍵清單以及帶 Search 按鈕的藍色框" />
</Frame>

工具列中的 **Insert citation** 按鈕，以及 **Insert** 再選 **Citation**，也會為你插入 `\cite{}`。其他引用指令也會出現此框，例如 `\citep`、`\autocite`、`\parencite` 與 `\textcite`。
</Step>

<Step title="開啟搜尋">
點擊藍色框中的 **Search**，或在大括號之間按 Ctrl+Space。對話框會列出每筆條目及其標題、引用鍵、作者、期刊與年份。

<Frame caption="專案中的所有條目">
  <img src="/images/on-premises/reference-search-dialog.png" alt="列出五筆條目的 Search the .bib files in this project 對話框" />
</Frame>
</Step>

<Step title="尋找條目">
在搜尋框中輸入。它會在引用鍵、作者、標題、期刊與年份中查找，並醒目標示找到的內容。每個字詞都必須相符，因此 `turing 1936` 會找到 Turing 1936 年的論文。其他欄位（例如出版商）不會被搜尋。

<Frame caption="依作者與年份搜尋">
  <img src="/images/on-premises/reference-search-filter.png" alt="搜尋框中輸入 turing 1936，一筆條目的相符內容以紅色顯示" />
</Frame>
</Step>

<Step title="選擇一或多筆條目">
點擊一筆條目。它會變成綠色，其鍵會顯示在清單上方。若要再加入一筆，點擊它或重新搜尋：已選內容會保留。若要移除，再次點擊它或點擊其鍵旁的 <strong>×</strong>。

<Frame caption="已選擇兩筆條目">
  <img src="/images/on-premises/reference-search-selected.png" alt="清單上方的 knuth1984 與 einstein1905 兩個鍵，以及以綠色顯示的條目" />
</Frame>
</Step>

<Step title="點擊 Insert">
這些鍵會以逗號分隔出現在大括號之間。如果文件還沒有參考文獻列表，請在 `\end{document}` 之前加入以下幾行，使用不含副檔名的 `.bib` 檔案名稱：

```latex
\bibliographystyle{plain}
\bibliography{refs,more}
```

點擊 **Recompile**。參考文獻會出現在 PDF 中。

<Frame caption="編譯後的引用">
  <img src="/images/on-premises/reference-search-compiled.png" alt="編輯器中的 \cite{knuth1984, einstein1905}，以及包含兩筆參考文獻的 PDF" />
</Frame>
</Step>
</Steps>

在 **Visual** 編輯器中，搜尋的用法完全相同。

## 修改引用 {#change-a-citation}

<strong>加入參考文獻：</strong>將游標放在現有引用的大括號之間，然後開啟搜尋。**Insert** 會把新鍵加到已有的鍵之後。

<strong>取代參考文獻：</strong>在編輯器中選取這些鍵，然後按 Ctrl+Space。這些鍵會顯示在清單上方，按鈕變為 **Replace**。移除不需要的鍵，加入其他鍵，然後點擊 **Replace**。不在任何 `.bib` 檔案中的鍵會一直保留，直到你將其移除。

<Frame caption="取代選取的鍵">
  <img src="/images/on-premises/reference-search-replace.png" alt="清單上方顯示 knuth1984、missing2000 與 turing1936 以及 Replace 按鈕的對話框" />
</Frame>

## 使用鍵盤 {#use-the-keyboard}

| 按鍵 | 作用 |
| --- | ------------ |
| **下箭頭** | 從搜尋框移入清單，然後在清單中向下移動 |
| **上箭頭** | 在清單中向上移動 |
| **空白鍵** | 選擇該條目，或將其從已選內容中移除 |
| **Enter** | 在清單中時，插入已選內容 |
| **Tab** | 在搜尋框、清單與按鈕之間切換 |
| **Esc** | 關閉對話框，不做任何變更 |

## 條目的來源 {#where-the-entries-come-from}

搜尋涵蓋專案中的每個 `.bib` 檔案，包括從 Zotero 或 Mendeley 匯入的檔案。編輯 `.bib` 檔案後，下一次搜尋就能找到新條目。

## 如果發生問題 {#if-something-goes-wrong}

| 你看到的情況 | 原因 | 解決方法 |
| ------------ | --- | ---------- |
| 對話框中的清單是空的 | 專案中沒有 `.bib` 檔案 | 上傳或建立一個 |
| 沒有藍色框，且 Ctrl+Space 列出的是 LaTeX 指令 | 游標不在引用的大括號之間 | 點擊大括號之間 |
| Ctrl+Space 沒有反應 | 你的電腦將此快速鍵用於其他用途 | 點擊藍色框中的 **Search** |
| 找不到某筆條目 | 搜尋只涵蓋鍵、作者、標題、期刊與年份 | 依其中某個欄位搜尋 |
