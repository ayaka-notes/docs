## 匯入文件 {#import-a-document}

此操作會從 Word 文件（`.docx`）或 Markdown 檔案（`.md`）建立新的 LaTeX 專案。專案名稱取自檔案名稱。

<Steps>
<Step title="開啟匯入對話方塊">
在專案頁面上，按一下 **New project**。在 **Import** 下，按一下 **Word document** 或 **Markdown document**。

<Frame caption="New project 選單">
  <img src="/images/on-premises/word-import-menu.png" alt="New project 選單，Import 下有 Word document 和 Markdown document" />
</Frame>
</Step>

<Step title="選擇檔案">
按一下 **Select .docx file**，或將檔案拖曳到對話方塊中。若是 Markdown，按鈕為 **Select .md file**。匯入會立即開始。

<Frame caption="選擇 Word 文件">
  <img src="/images/on-premises/word-import-dialog.png" alt="帶有 Select .docx file 按鈕的 Choose Word document 對話方塊" />
</Frame>
</Step>

<Step title="開始編輯">
新專案開啟時會顯示訊息 **Document ready for editing**。按一下 **Start editing**。

<Frame caption="匯入已完成">
  <img src="/images/on-premises/word-import-ready.png" alt="帶有 Start editing 按鈕的 Document ready for editing 對話方塊" />
</Frame>
</Step>

<Step title="檢查結果">
文件現在位於 `main.tex` 中，其標題會顯示在檔案大綱中。按一下 **Recompile** 查看 PDF。請檢查樣式，尤其是表格、圖片和引用，這些可能需要編輯。

<Frame caption="匯入的專案">
  <img src="/images/on-premises/word-import-project.png" alt="編輯器中匯入的專案，包含 main.tex、檔案大綱和編譯後的 PDF" />
</Frame>
</Step>
</Steps>

### 如果匯入失敗 {#if-the-import-fails}

如果檔案無法轉換，對話方塊會顯示 **Your document couldn't be imported**。展開 **Conversion error details** 查看原因。不會建立專案。

<Frame caption="無法匯入的文件">
  <img src="/images/on-premises/word-import-error.png" alt="帶有錯誤訊息和 Conversion error details 的匯入對話方塊" />
</Frame>

對話方塊只接受你所選的類型。在 Word 對話方塊中選擇 `.md` 檔案會顯示 **You can only upload: .docx**。

## 匯出專案 {#export-a-project}

開啟專案，然後按一下編輯器頂端的專案名稱。按一下下列其中一個選項：

| 選項                              | 你會得到                                       |
| ----------------------------------- | --------------------------------------------- |
| <strong>Export as Word document (.docx)</strong> | 以專案命名的 `.docx` 檔案        |
| <strong>Export as Markdown (.md)</strong>        | 包含 `main.md` 的 `.zip` 檔案                  |
| <strong>Export as HTML (.html)</strong>          | 包含 `main.html` 的 `.zip` 檔案                |

下載會自動開始。轉換無法重現所有 LaTeX 格式，因此請檢查結果。

</Frame>
