[TeX Live](https://www.tug.org/texlive/) 是由 [TeX Users Group](https://www.tug.org/) 每年發布的自由軟體發行版。它提供 LaTeX 套件、字型、TeX 引擎，以及在所有標準作業系統上支援 LaTeX 排版所需的眾多軟體工具。

TeX Live 是 Overleaf 的重要組成部分，因為我們的伺服器使用它來編譯您的 LaTeX 程式碼並產生即時 PDF 預覽。它也讓 Overleaf 使用者能輕鬆使用每個 TeX Live 版本中所包含的 5,000 多個 LaTeX 套件。

您不必侷限於使用最新版的 TeX Live 來編譯專案，因為 Overleaf 的伺服器也提供先前的 TeX Live 版本。專案可以輕鬆切換為使用較早版本的 TeX Live——例如因套件相容性問題而需要時。<br />
