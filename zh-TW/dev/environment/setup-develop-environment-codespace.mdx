為了節省時間並快速建立開發環境，我們提供了另一種開發環境設定方式，也就是 GitHub Codespace。

## 設定教學

<Steps>
<Step title="建立 Codespaces">
點擊下方按鈕，即可建立用於 server-pro 開發的雲端 Codespaces。

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/overleaf-pro)

建議選擇至少 **4-core** 的 **Machine Type**。若需要更大規格的機器類型，可以[在此](https://support.github.com/contact?tags=rr-codespaces%2Ccat_codespaces)提交工單，向 GitHub 官方支援團隊提出申請。

<Frame>
  <img src="/images/dev/image.png" alt="" />
</Frame>
</Step>

<Step title="執行設定指令碼">
建立 Codespace 需要一些時間，請耐心等候。當您可以存取終端機後，執行以下指令：

```text
cd develop/
bin/setup
```

<Frame>
  <img src="/images/dev/image-1.png" alt="" />
</Frame>

<Warning>

此指令碼（`bin/setup`）可讓您以最短的時間，在 `server-pro` 分支的最新 commit 上建立開發環境。它可能不適用於舊版本或其他分支。

我們每天都會透過 [GitHub Action](https://github.com/ayaka-notes/overleaf-pro/actions) 建置開發用 Docker 映像檔。

</Warning>
</Step>

<Step title="存取 Launchpad">
切換到連接埠（Ports）分頁，您會看到可用的網頁連接埠清單。點擊 `80` 那一個，此時應該會看到 Launchpad 頁面。

<Frame>
  <img src="/images/dev/image-2.png" alt="" />
</Frame>

您會看到：

<Frame>
  <img src="/images/dev/image-3.png" alt="" />
</Frame>
</Step>

<Step title="開始開發">
現在，屬於您的時間到了！開始打造您的精彩功能吧。您需要執行以下指令來啟用即時顯示：

```bash title="bash" wrap
docker compose -f docker-compose.yml -f docker-compose.dev.yml -f ./docker-compose.image.yml up --no-deps --detach
```
</Step>
</Steps>
