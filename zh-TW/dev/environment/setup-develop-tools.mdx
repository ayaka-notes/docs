## 推薦的開發工具

這些選用服務並非執行 Overleaf 的必要條件，但在本機開發期間進行開發、除錯與檢查時，強烈建議使用。

* **Hoppscotch** 是一款類似 Postman 的輕量 API 測試工具，但以瀏覽器為基礎，對開發而言非常方便。
  * 前端：[http://localhost:3000](http://localhost:3000/)
  * Proxy（用於繞過 CORS）：[http://localhost:9159](http://localhost:9159/)
* **RedisInsight** 提供檢視 Redis 資料的視覺化介面。UI 位於：[http://localhost:5540](http://localhost:5540/)
* **Mongo Express** 是 MongoDB 的網頁版 UI。您可以造訪 [http://localhost:8081](http://localhost:8081/)，**登入憑證**為：`admin:pass`

請將以下內容加入您的 `docker-compose.yml`：

<Accordion title="develop/docker-compose.yml">

```yml title="develop/docker-compose.yml"
# services: 
  # Overleaf Dev Containers
  # ...
  
  # Add those for your development
  # API debug
  hoppscotch-frontend:
    image: hoppscotch/hoppscotch-frontend:latest
    ports:
      - "3000:3000"

  hoppscotch-proxy:
    image: hoppscotch/proxyscotch:latest
    environment:
      - PORT=9159
    ports:
      - "9159:9159"

  # Redis-insight
  redis-insight:
    image: redislabs/redisinsight:latest
    ports:
      - "5540:5540"
    depends_on:
      - redis
    volumes:
      - ./data/redis-insight:/data

  # mongo-express
  # basicAuth credentials are "admin:pass"
  mongo-express:
    image: mongo-express
    ports:
      - "8081:8081"
    environment:
      ME_CONFIG_MONGODB_SERVER: mongo
```

</Accordion>

#### CSRF 問題

<Warning>

如果您使用 Postman 或其他除錯工具發送 **post** 請求，可能會發現登入被**禁止**，原因是 401 錯誤。這是因為 Overleaf 受到 **csrf** 驗證保護。

</Warning>

<Frame>
  <img src="/images/dev/image-9.png" alt="" />
</Frame>

在主控台中，您可能會看到：

<Frame>
  <img src="/images/dev/image-10.png" alt="" />
</Frame>

要在 Overleaf 開發中處理這個問題，您需要設定 csrf token。以下是詳細教學。

<Steps>
<Step title="新增 Pre Request">
將以下程式碼加入 Pre-Request：

<Frame>
  <img src="/images/dev/image-11.png" alt="" />
</Frame>

指令碼如下：

```js wrap
pm.sendRequest("http://web:3000/dev/csrf", function (err, res) {
    if (err) {
        console.log(err);
        return;
    }

    // 1) Save CSRF token (/dev/csrf)
    const token = res.text().trim();
    pw.env.set("csrftoken", token);
    console.log("csrftoken =", token);

    const setCookieHeader = (res.headers || []).find(h => h.key?.toLowerCase() === "set-cookie")?.value;
    console.log("set-cookie =", setCookieHeader);

    if (!setCookieHeader) return;

    const cookiePair = setCookieHeader.split(";")[0].trim(); // overleaf.sid=...
    pw.env.set("cookie_header", cookiePair);
    console.log("cookie_header =", cookiePair);
});
```
</Step>

<Step title="新增請求標頭">
您需要新增以下標頭：

| 標頭名稱  | 標頭值        |
| ------------ | ------------------- |
| Content-Type | `application/json`  |
| X-Csrf-Token | `<<csrftoken>>`     |
| Cookie       | `<<cookie_header>>` |

<Frame>
  <img src="/images/dev/image-12.png" alt="" />
</Frame>
</Step>

<Step title="使用 API 工具登入">
現在您可以使用您的使用者名稱與密碼登入。

```json5
{
  "_csrf": "<<csrftoken>>",
  "email": "admin@overleaf.com",
  "password": "xxxxxx"
}
```

</Step>
