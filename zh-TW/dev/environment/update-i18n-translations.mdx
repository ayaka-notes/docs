---
title: 更新 i18n 翻譯
icon: language
---

前端只會載入 `services/web/frontend/extracted-translations.json` 中列出的翻譯鍵（`services/web/frontend/translations-loader.js`）。後端及其範本會讀取 `services/web/locales/` 中的完整檔案。

首次設定後在 `develop` 目錄中執行一次，之後每次新增翻譯或切換分支後再執行一次：

```bash
bin/i18n
```

`bin/i18n` 會做兩件事：

1. 將 `services/web/locales/*.json` 重設為已提交的檔案，然後依照映像檔建置的方式套用語系修補：最高版本的 `locales_patches/v*` 資料夾中的檔案會取代語系檔，再將 `locales_patches/added/*.json` 逐鍵合併到其上。
2. 在 `webpack` 容器中以 `node` 使用者執行 `yarn run extract-translations`，重寫 `extracted-translations.json`。如果缺少 webpack 映像檔，它會先用 `bin/sync` 同步 `yarn.lock` 並建置映像檔。

它需要主機上安裝 `jq`。

<Warning>

`bin/i18n` 對 `services/web/locales/*.json` 所做的變更僅在本機有效。請不要提交這些變更。

</Warning>

請盡可能重用既有的鍵。語系檔來自 Overleaf 上游或第三方翻譯網站，因此不要直接編輯它們。新鍵應新增到 `services/web/locales/locales_patches/added/` 中，並同時寫入每種語言的檔案（`en.json`、`zh-CN.json` 等）。
