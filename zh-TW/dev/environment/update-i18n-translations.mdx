---
title: 更新 i18n 翻譯
icon: language
---

在 `services/web/frontend/extracted-translations.json` 中有一個檔案，Overleaf web 只會使用此檔案中擷取出的翻譯。

如果您新增了一些內容，請執行以下指令來更新擷取出的翻譯。

```bash
user ➜ ~/overleaf-pro/develop (server-pro) $ bin/shell webpack
root@432836260f8a:/overleaf/services/web# npm run extract-translations
```

一般而言，請不要編輯翻譯文字檔，請優先使用現有的翻譯，因為這些檔案都是從 Overleaf 上游或第三方翻譯網站更新而來。
