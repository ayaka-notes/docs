title: docstore
icon: database
---

將每個專案的每份文件（行、版本、範圍）儲存在 Mongo 的 `docs` 集合中，並在設定後端時將文件封存到物件儲存。由 web 呼叫；document-updater 透過 web 存取它。

* <strong>位址：</strong> `http://docstore:3016`, 位於 Docker 網路內
* <strong>驗證：</strong>無
* <strong>OpenAPI 檔案：</strong> [`develop/hoppscotch/openapi/docstore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/docstore.yaml)
