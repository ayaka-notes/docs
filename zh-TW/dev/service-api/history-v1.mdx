儲存每個專案的完整歷史：變更區塊存放在 Mongo 或 Postgres 以及物件儲存中，檔案內容以 blob 形式儲存。project-history 向其寫入變更；web、project-history 與 git-bridge 從中讀取 blob、快照與 zip。

* <strong>位址：</strong> `http://history-v1:3100`, 位於 Docker 網路內
* <strong>驗證：</strong>依路由而定，使用 `STAGING_PASSWORD` 以 `staging` 身分進行 HTTP 基本驗證，或使用 JWT。
* <strong>OpenAPI 檔案：</strong> [`develop/hoppscotch/openapi/history-v1.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/history-v1.yaml)
