從物件儲存提供檔案：範本檔案（zip、pdf 及其預覽圖），以及以唯讀方式提供 history-v1 寫入的專案與全域 blob。由 web（template-gallery 模組、編譯檔案 URL）與 clsi 呼叫，clsi 從這裡下載專案的二進位檔案。

* <strong>位址：</strong> `http://filestore:3009`, 位於 Docker 網路內
* <strong>驗證：</strong>無
* <strong>OpenAPI 檔案：</strong> [`develop/hoppscotch/openapi/filestore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/filestore.yaml)
