為 web 擷取外部 URL 並以串流方式傳回回應，同時拒絕內部位址，使使用者無法存取 Docker 網路。web 透過它傳送 URL 檔案、Open in Overleaf 匯入以及 AI 代理的 web_fetch。

* <strong>位址：</strong> `http://linked-url-proxy:3066`, 位於 Docker 網路內
* <strong>驗證：</strong>無
* <strong>OpenAPI 檔案：</strong> [`develop/hoppscotch/openapi/linked-url-proxy.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/linked-url-proxy.yaml)
