將專案聊天與留言串（其訊息與已解決狀態）儲存在 Mongo 的 `rooms` 與 `messages` 集合中。由 web 透過 `ChatApiHandler` 呼叫。

* <strong>位址：</strong> `http://chat:3010`, 位於 Docker 網路內
* <strong>驗證：</strong>無
* <strong>OpenAPI 檔案：</strong> [`develop/hoppscotch/openapi/chat.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/chat.yaml)
