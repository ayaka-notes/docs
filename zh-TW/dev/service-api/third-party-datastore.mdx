將專案與 Dropbox 同步：它為每位使用者維護一個 Redis 工作佇列，並有一個 worker 將 Overleaf 的變更傳送到 Dropbox 並輪詢 Dropbox 的變更。只有 web 會呼叫它，用來加入工作與讀取佇列大小。

* <strong>位址：</strong> `http://third-party-datastore:3002`, 位於 Docker 網路內
* <strong>驗證：</strong>無
* <strong>OpenAPI 檔案：</strong> [`develop/hoppscotch/openapi/third-party-datastore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/third-party-datastore.yaml)
