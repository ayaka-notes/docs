web（Overleaf 主應用程式）的私有 API。其他服務（real-time、document-updater、project-history、third-party-datastore、git-bridge）與 Server CE 映像檔的 cron 指令碼會呼叫它。這些路由只需要 HTTP 基本驗證，不需要 CSRF 權杖：私有路由器掛載在 web 路由器之前，且只有 web 路由器會執行 CSRF 檢查。設定 `BLOCK_CROSS_ORIGIN_REQUESTS=true`（預設關閉）後，對於 `Origin` 標頭不在 `ALLOWED_ORIGINS`（預設：網站 URL）中的任何請求，web 都會傳回 403。瀏覽器在 POST 時會傳送 `Origin`，因此開啟此開關後，從瀏覽器中的 Hoppscotch 送出的 POST 會收到 403，除非經過 Hoppscotch 代理。

* <strong>位址：</strong> `http://web:3000`, 位於 Docker 網路內
* <strong>驗證：</strong>使用 `WEB_API_USER` 與 `WEB_API_PASSWORD` 的 HTTP 基本驗證，status、health 與 metrics 除外。git-bridge 路由改用個人存取權杖。
* <strong>OpenAPI 檔案：</strong> [`develop/hoppscotch/openapi/web.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/web.yaml)
