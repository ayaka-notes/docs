title: OAuth Access Tokens 集合
icon: ticket
---

`oauthAccessTokens` 儲存 web 接受的 bearer 權杖。在 Ayakaleaf Pro 中，這些是使用者在帳戶設定頁面建立、用於 git-bridge 與 MCP 端點的個人存取權杖（Git 驗證權杖）。一份文件對應一個權杖。Schema 位於 `services/web/app/src/models/OauthAccessToken.mjs`；web 模組 `oauth2-server` 寫入該集合，大多透過原生驅動程式。

#### 寫入方 {#who-writes-it}

| 程式碼 | 作用 |
| ---- | ------------ |
| `OAuthPersonalAccessTokenManager.mjs:53-88` (`createToken`) | 插入個人存取權杖。路由 `POST /oauth/personal-access-tokens`（`services/web/modules/oauth2-server/app/src/OAuthPersonalAccessTokenRouter.mjs:22-27`）要求使用者具備 `gitBridge` 功能，且每位使用者最多 10 個權杖（`OAuthPersonalAccessTokenController.mjs:7,34-38`）。 |
| `OAuthPersonalAccessTokenManager.mjs:90-105` (`removeToken`) | 刪除使用者的一個權杖。路由 `DELETE /oauth/personal-access-tokens/:token_id`（`OAuthPersonalAccessTokenRouter.mjs:29-32`）。 |
| `OAuthPersonalAccessTokenManager.mjs:136-140`, `OAuth2Model.mjs:58-61` | 驗證成功後設定 `lastUsedAt`。 |

#### 備註 {#notes}

* 刪除使用者不會刪除其權杖。`UserDeleter` 會觸發 `cleanupPersonalAccessTokens` 掛鉤（`services/web/app/src/Features/User/UserDeleter.mjs:230-234`），但沒有模組監聽它。由於使用者已不存在，兩種權杖驗證都會拒絕這些權杖，TTL 索引會在 `accessTokenExpiresAt` 之後一天將其移除。
* 停權使用者只會結束其工作階段。權杖仍會保留，只要 `users.suspended` 為 `true`，兩種權杖驗證都會拒絕它們（`OAuth2Model.mjs:51-54`, `OAuthPersonalAccessTokenManager.mjs:129-134`）。
