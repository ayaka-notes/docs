---
title: Docs 集合
icon: file-lines
---

`Docs`：Docs 是 Overleaf 對可編輯檔案的內部稱呼，例如純 `tex` 檔或 `.bib` 檔。它儲存檔案內容、修訂資訊以及刪除狀態。

#### 核心識別

* `_id`：識別此文件記錄的唯一 MongoDB ObjectId。
* `project_id`：此檔案所屬專案的參照（`Project._id`）。
* `name`：專案檔案樹中顯示的檔名（例如 `main.tex`、`sample.bib`）。

#### 修訂與版本控制

* `rev`：此文件在專案歷史中的修訂編號。
* `version`：編輯器後端使用的內部結構描述或格式版本。

這些欄位由 Overleaf 自訂的版本控制系統使用，用來追蹤增量編輯，並支援歷史記錄與回復。

#### 檔案內容

*   `lines`：\
    以字串陣列逐行表示檔案內容。\
    每個元素對應來源檔案中的一個邏輯行。

    在此範例中，它儲存了一筆 BibTeX 條目：

    * `@article{greenwade93, ... }`
* `ranges`：保留給編輯器註解或追蹤範圍的資料結構\
  （例如選取範圍、註解或變更追蹤）。沒有作用中的範圍時為空。`op` 是將註解綁定到文件中特定位置的操作物件。
  * `op.c` — 註解所選取的文字（字元內容）
  * `op.p` — 錨點位置（字元偏移量）
  * `id` 此註解條目的唯一 ObjectId。
  * `metadata` 作者與時間戳記資訊。

#### 刪除狀態

* `deleted`：\
  表示此文件是否已從專案中刪除。
* `deletedAt`：\
  記錄文件被刪除時間的時間戳記。

已刪除的文件通常會保留下來，以供歷史復原與版本瀏覽，而不會立即從資料庫中移除。

以下是一個 Overleaf `docs` 的真實範例。

<Accordion title="簡單範例">

```json5
{
    _id: ObjectId('696b8377933aeebb3d3cc25e'),
    project_id: ObjectId('696b8377933aeebb3d3cc252'),
    rev: 1,
    lines: [
        '@article{greenwade93,',
        '    author  = "George D. Greenwade",',
        '    title   = "The {C}omprehensive {T}ex {A}rchive {N}etwork ({CTAN})",',
        '    year    = "1993",',
        '    journal = "TUGBoat",',
        '    volume  = "14",',
        '    number  = "3",',
        '    pages   = "342--351"',
        '}',
        ''
    ],
    ranges: {},
    version: 0,
    deleted: true,
    deletedAt: ISODate('2026-01-17T13:11:42.580Z'),
    name: 'sample.bib'
}
```

</Accordion>
