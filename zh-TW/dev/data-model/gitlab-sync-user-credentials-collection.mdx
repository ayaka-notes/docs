title: GitLab Sync User Credentials 集合
icon: user-lock
---

`gitlabSyncUserCredentials` 為每位為 GitLab Sync 連結了 GitLab 帳號的使用者保存一份文件。 它以加密形式儲存使用者的 OAuth 權杖。 此集合屬於 `gitlab-sync` web 模組（`services/web/modules/gitlab-sync`）。schema 位於 `services/web/modules/gitlab-sync/app/models/gitlabSyncUserCredentials.mjs`，所有存取都經過 `services/web/modules/gitlab-sync/app/src/TokenManager.mjs`。

#### 欄位 {#fields}

| 欄位 | 型別 | 含義 | 來源 |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | upsert 插入時由 Mongoose 設定。 | |
| `userId` | ObjectId | Overleaf 使用者。必填。schema 寫了 `unique: true`，但不會建立任何索引（見「索引」）；依 `userId` 的 upsert 確保每位使用者只有一份文件。 | `gitlabSyncUserCredentials.mjs:8`, `TokenManager.mjs:88-95` |
| `gitlab` | String | JSON `{ accessToken, refreshToken, expiresAt }`，使用 `@overleaf/access-token-encryptor` 加密。`expiresAt` 是自 Unix 紀元起的毫秒數，或為 `null`；`refreshToken` 可能為 `null`。密碼來自 `GITLAB_TOKEN_CIPHER_PASSWORD`；加密標籤為 `GITLAB_TOKEN_CIPHER_LABEL`，預設 `2026.10-v3`。必填。 | `gitlabSyncUserCredentials.mjs:9-10`, `TokenManager.mjs:18-31`, `services/web/modules/gitlab-sync/app/src/GitLabApiClient.mjs:209-220` |
| `__v` | Number | Mongoose 版本鍵。schema 沒有關閉它。 | Mongoose 預設 |

#### 寫入方 {#who-writes-it}

| 程式碼 | 作用 |
| ---- | ------------ |
| `TokenManager.mjs:88-95` (`saveUserToken`) | 對使用者的加密憑證執行 upsert。 |
| `TokenManager.mjs:99-108` (`linkUserToken`) | 儲存 OAuth 回呼取得的新憑證（`services/web/modules/gitlab-sync/app/src/GitLabSyncController.mjs:146`）。使用者重新連結時，被取代的存取權杖會在背景於 GitLab 上撤銷。 |
| `TokenManager.mjs:53-78` (`refreshUserToken`) | 當存取權杖距 `expiresAt` 不到 5 分鐘時（`:13,47-49`），以更新權杖取得新權杖並儲存（`:75`）。它在每位使用者的 `gitlabSyncToken` 鎖下執行（`:15,54`），因為 GitLab 的更新權杖用過一次就失效。 |
| `TokenManager.mjs:111-126` (`removeUserToken`) | 在 GitLab 上撤銷存取權杖（盡力而為），然後刪除文件。在取消連結時（`GitLabSyncController.mjs:173`）以及已刪除使用者過期時（`services/web/modules/gitlab-sync/index.mjs:56-58`）呼叫。 |

#### 讀取方 {#who-reads-it}

| 程式碼 | 作用 |
| ---- | ------------ |
| `TokenManager.mjs:41-45,81-85` (`getUserCredentials`, `getUserToken`) | 為每次 GitLab API 呼叫解密憑證，權杖即將到期時先更新：`services/web/modules/gitlab-sync/app/src/GitLabSyncHandler.mjs`（例如 `:27`）和 `services/web/modules/gitlab-sync/app/src/GitMerge.mjs:52`。沒有文件或憑證無法解密或更新時，拋出 `InvalidTokenError`，使用者視為未連結（`GitLabSyncHandler.mjs:25-37`）。 |
| `services/web/modules/admin-tools/app/src/AdminUserListManager.mjs:394` | 檢查使用者是否有文件，用於管理面板中顯示的整合。 |

#### 索引 {#indexes}

| 名稱 | 鍵 | 選項 | 遷移 |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

Mongoose 的 `autoIndex` 已關閉（`services/web/app/src/infrastructure/Mongoose.mjs:7`），因此 schema 中 `userId` 上的 `unique: true` 不會建立任何索引。 沒有遷移為此集合建立索引。

#### 備註 {#notes}

* 變更 `GITLAB_TOKEN_CIPHER_PASSWORD` 會使已儲存的憑證無法讀取。這些使用者在重新連結之前都視為未連結。
* 已刪除的使用者會保留該文件，直到該使用者過期。
