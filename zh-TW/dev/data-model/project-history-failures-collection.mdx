title: Project History Failures 集合
icon: triangle-exclamation
---

`projectHistoryFailures` 中每個專案一個文件：project-history 無法處理其歷史更新的專案，或已為其啟動重新同步的專案。一旦處理成功，該文件就會再次被刪除。project-history 在 `services/project-history/app/js/ErrorRecorder.js` 中寫入它；型別定義在 `services/project-history/app/js/mongo-types.ts:3-24` 中。Web 也有它的 Mongoose schema（`services/web/app/src/models/ProjectHistoryFailure.mjs:5-19`），但沒有 Web 程式碼使用該模型。

| 欄位 | 型別 | 含義 | 來源 |

#### 說明 {#notes}

* 文件會一直保留，直到該專案的某次 flush 成功或專案被刪除（見上文 `clearError`），因此每個文件都標記著一個最近一次 flush 或重新同步尚未成功的專案。
* 以 `OError:` 開頭的錯誤字串會以 `Error:` 的形式回傳（`ErrorRecorder.js:18-26`）；儲存的值不變。
