`messages` 中每則訊息對應一個文件：專案聊天中的一行，或審閱註解討論串中的一則註解或回覆。只有 chat 服務寫入它，位置在 `services/chat/app/js/Features/Messages/MessageManager.js`。沒有 Mongoose schema。每則訊息都屬於 [rooms](/zh-TW/dev/data-model/rooms-collection) 集合中的一個聊天室。

#### 欄位 {#fields}

| 欄位 | 型別 | 含義 | 來源 |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | 訊息 ID。 | `MessageManager.js:13-14` |
| `room_id` | ObjectId | 聊天室（`rooms._id`），不是專案 ID，也不是討論串 ID。 | `MessageManager.js:8,106-108` |
| `user_id` | ObjectId | 作者。 | `MessageManager.js:9,103-105` |
| `content` | String | 訊息文字，1 到 10240 個字元（`MAX_MESSAGE_LENGTH`）。 | `MessageManager.js:7`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:3,12-15` |
| `timestamp` | Number | 傳送時間，以自 1970 年起的毫秒數表示（`Date.now()`），不是 Date。 | `MessageManager.js:10`, `services/chat/app/js/Features/Messages/MessageHttpController.js:288` |
| `edited_at` | Number | 最後編輯時間，以毫秒表示（`Date.now()`）。從未編輯過則不存在。 | `MessageManager.js:65-69`, `MessageHttpController.js:189,213` |

#### 寫入方 {#who-writes-it}

| 程式碼 | 作用 |
| ---- | ------------ |
| `MessageManager.js:5-16` `createMessage` | 插入一則訊息（`MessageHttpController.js:275-294`）。Web 從 `services/web/app/src/Features/Chat/ChatController.mjs:32` 傳送專案聊天訊息，並從 track-changes 模組（`services/web/modules/track-changes/app/src/TrackChangesController.mjs:95`）和 mcp-server 模組（`services/web/modules/mcp-server/app/src/CommentTools.mjs:133`）傳送註解。 |
| `MessageManager.js:51-72` `updateMessage` | 設定 `content` 和 `edited_at`。如果提供了使用者 ID，則只比對該使用者的訊息（`MessageManager.js:62-64`）。由 `ChatController.mjs:135` 和 `TrackChangesController.mjs:110` 呼叫。 |
| `MessageManager.js:74-80` `deleteMessage` | 刪除一則訊息。由 `ChatController.mjs:105` 和 `TrackChangesController.mjs:129` 呼叫。 |
| `MessageManager.js:39-49` `deleteAllMessagesInRoom(s)` | 刪除已刪除討論串的訊息（`MessageHttpController.js:172-173`），或在已刪除專案過期時刪除整個專案的訊息（`MessageHttpController.js:261-271`，由 `services/web/app/src/Features/Project/ProjectDeleter.mjs:391` 呼叫）。 |
| `MessageManager.js:115-127` `duplicateRoomToOtherRoom` | 把每則訊息的 `content`、`timestamp` 和 `user_id` 複製到另一個聊天室，不包括 `edited_at`。在歷史還原複製討論串時使用（`MessageHttpController.js:316-342`），以及在連同範圍一起複製專案時使用（`MessageHttpController.js:344-357`）。 |

#### 讀取方 {#who-reads-it}

| 程式碼 | 作用 |
| ---- | ------------ |
| `MessageManager.js:18-29` `getMessages` | 最新的在前，最多 `limit` 則（預設 50），且早於 `before`（一個 `timestamp`）。用於專案聊天（`ChatController.mjs:80`）。 |
| `MessageManager.js:31-37` `findAllMessagesInRooms` | 若干聊天室的全部訊息，用於審閱面板的討論串清單（`TrackChangesController.mjs:82`）、mcp-server 模組（`CommentTools.mjs:83`）和歷史還原（`services/web/app/src/Features/History/RestoreManager.mjs:259`）。Web 也會檢查討論串的第一則訊息，讓審閱者只能修改自己發起的討論串（`services/web/app/src/Features/Authorization/AuthorizationManager.mjs:409-411`）。 |
| `MessageManager.js:90-100` `getMessage` | 一則訊息。使用者編輯或刪除自己的訊息之前，Web 會檢查其 `user_id`（`services/web/app/src/Features/Authorization/AuthorizationMiddleware.mjs:253-257`、`TrackChangesController.mjs:124-125`）。 |

#### 說明 {#notes}

* 要查找某則註解的訊息，先依 `project_id` 和 `thread_id` 查找聊天室，再查詢 `room_id`。文件中的註解 ID 是 `thread_id`，不是 `room_id`。
* 註解指向的文字是 `docs.ranges.comments` 中的 `op.c`；討論內容保存在這裡。
