### <Icon icon="docker" iconType="brands" /> 由 @Ayaka-Notes 建置的 Docker 版 $\TeX$ Live

Overleaf 使用 **Docker** 容器編譯您的 $\LaTeX$ 專案。您的專案會在隔離的 Docker 沙箱中編譯，確保絕對的**安全性**。

因此，我們提供 $\TeX$ Live 映像檔（從 2019 到最新版本），可自由切換版本，並包含所有字型與 $\LaTeX$ 套件。
