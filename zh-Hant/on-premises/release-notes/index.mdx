### 了解 Overleaf 版本號

Overleaf 使用 **6.X.y** 形式的語意化版本號。

* **6.X** 代表主要發行系列。當新的 **6.X.0** 版本發布時，它就會成為該世代的基準版本。
* **y** 代表同一主要系列中的修補更新。後續版本（例如 **6.X.1**、**6.X.2**……）通常是建立在 **6.X.0** 之上的維護更新，包含錯誤修正、安全性修正與小幅改進，而非大型功能變更。

### Ayakaleaf Pro 版本

我們的 Ayakaleaf Pro 版本號與 Overleaf 官方發行版本**完全一致**。除非另有說明，所有已發布的版本皆為完整功能的 Pro 版映像檔。

我們嚴格將版本與 Overleaf 社群版對齊，讓您可以使用開源的 Overleaf 外掛。我們不會變更 Overleaf 的核心介面。因此，任何與對應 `A.X.y` 社群版相容的外掛，都完全相容於 Ayakaleaf Pro `A.X.y`。
