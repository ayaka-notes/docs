Python 指令碼在你的瀏覽器中執行，因此輸出會直接顯示在編輯器下方。無需任何設定。

<Steps>
<Step title="建立指令碼">
在檔案樹中，按一下 **New file** 圖示。輸入以 `.py` 結尾的名稱，然後按一下 **Create**。

<Frame caption="新的 Python 檔案">
  <img src="/images/on-premises/python-runner-new-file.png" alt="名稱為 analysis.py 的 Add Files 對話方塊" />
</Frame>

編輯器下方會出現 **Run** 按鈕和輸出窗格。第一次使用時，在 Python 載入期間該按鈕會維持停用狀態。
</Step>

<Step title="執行指令碼">
撰寫程式碼並按一下 **Run**。指令碼列印的內容會顯示在輸出窗格中。不需要先儲存。

指令碼寫出的檔案會存入你的專案。一則訊息會告訴你是哪個檔案，例如 **results.txt saved to your project**，該檔案也會出現在檔案樹中。

<Frame caption="輸出和已儲存的檔案">
  <img src="/images/on-premises/python-runner-output.png" alt="編輯器中的指令碼、下方列印的輸出，以及訊息 results.txt saved to your project" />
</Frame>
</Step>

<Step title="停止指令碼">
指令碼執行時，**Run** 會變成 **Stop**。按一下即可中斷指令碼。輸出窗格會以 **Execution interrupted** 結尾。

<Frame caption="正在執行的指令碼">
  <img src="/images/on-premises/python-runner-stop.png" alt="Stop 按鈕和正在執行的指令碼的輸出" />
</Frame>
</Step>
</Steps>

## 在文件中使用圖表 {#use-a-figure-in-your-document}

繪圖沒有可以顯示的視窗，因此請將其儲存為檔案。例如：

```python
import matplotlib.pyplot as plt

plt.plot([1, 2, 3], [1, 4, 9])
plt.savefig("figure.png")
```

`figure.png` 會出現在你的專案中，可直接用於 `\includegraphics{figure.png}`。

<Frame caption="已儲存的繪圖">
  <img src="/images/on-premises/python-runner-figure.png" alt="在編輯器中開啟的 figure.png，以及訊息 figure.png saved to your project" />
</Frame>

## 讀取專案中的檔案 {#read-your-project’s-files}

指令碼可以依路徑開啟專案中的檔案：

```python
print(open("results.txt").read())
```

## 發生問題時 {#if-something-goes-wrong}

<strong>指令碼引發錯誤。</strong>錯誤會以紅色顯示在輸出窗格中，位於指令碼先前列印的所有內容之後。

<Frame caption="指令碼中的錯誤">
  <img src="/images/on-premises/python-runner-error.png" alt="列印的文字後接一段紅色的 traceback" />
</Frame>

<strong>`ModuleNotFoundError: No module named ...`。</strong>只能使用 Pyodide 內建的套件，無法使用以 `pip` 安裝的套件。NumPy 和 Matplotlib 都在可用之列，該訊息也會連結到[完整清單](https://pyodide.org/en/stable/usage/packages-in-pyodide.html)。

<Frame caption="無法使用的套件">
  <img src="/images/on-premises/python-runner-missing-package.png" alt="輸出窗格中的 ModuleNotFoundError" />
</Frame>
