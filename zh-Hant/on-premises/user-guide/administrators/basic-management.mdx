點選 **Admin**，然後點選 **Manage Site**。**Admin Panel** 有三個分頁：**System Messages**、**Open Sockets** 和 **Open/Close Editor**。

## 系統訊息 {#system-messages}

系統訊息是顯示在 **Projects** 頁面和編輯器頂端的藍色橫幅。所有使用者都看得到。

### 發布訊息 {#post-a-message}

在 **Message** 下輸入文字，然後點選 **Post Message**。此分頁會列出目前正在顯示的訊息。

<Frame caption="兩則已發布的訊息">
  <img src="/images/on-premises/basic-management-posted.png" alt="System Messages 分頁，在 Message 欄位、Post Message 按鈕和 Clear all messages 按鈕上方列出兩則已發布的訊息" />
</Frame>

<Frame caption="使用者看到的內容">
  <img src="/images/on-premises/basic-management-user-projects.png" alt="某使用者的 Projects 頁面，頂端以藍色橫幅顯示兩則訊息" />
</Frame>

* 使用者可以點選 <strong>×</strong> 關閉訊息。在該瀏覽器中它會維持關閉。
* 已開啟的頁面每 15 分鐘檢查一次新訊息。重新載入頁面會立即顯示新訊息。

### 移除訊息 {#remove-messages}

**Clear all messages** 會一次移除所有訊息，且不會要求確認。你無法單獨移除某一則訊息。

## 開啟的 socket {#open-sockets}

這是一個診斷檢視，顯示 web 服務此刻開啟的對外連線。它不會顯示誰在線上：即使有使用者正在使用編輯器，清單也可能是空的。

## 為維護關閉編輯器 {#close-the-editor-for-maintenance}

使用 **Open/Close Editor** 分頁。其中的按鈕會立即生效且不要求確認，此分頁也不會顯示編輯器是否已關閉。若要確認，請點選 **Projects**：編輯器關閉時你會看到 **Maintenance** 頁面。

<Frame caption="Open/Close Editor 分頁">
  <img src="/images/on-premises/basic-management-open-close.png" alt="包含 Close Editor、Disconnect all users 和 Reopen Editor 按鈕的 Open/Close Editor 分頁" />
</Frame>

<Steps>
<Step id="tell-your-users" title="通知你的使用者">
[發布一則訊息](/zh-Hant/on-premises/user-guide/administrators/basic-management#post-a-message)，寫明維護時間。
</Step>

<Step id="click-close-editor" title="點選 Close Editor">
儘管名稱如此，它幾乎會關閉整個網站。除了管理面板外，所有頁面都會顯示 **Maintenance**，包括 **Projects**、**Account Settings**、**Templates** 和登入頁面。**Manage Users** 和 **Project/Object Lookup** 仍可使用。

<Frame caption="編輯器關閉時使用者看到的內容">
  <img src="/images/on-premises/basic-management-closed-page.png" alt="提示執行個體目前正在維護的 Maintenance 頁面" />
</Frame>

已開啟編輯器的使用者會維持連線。他們可以繼續輸入，變更也會保留，但 **Recompile** 會以 **Server Error** 結束。

若要變更此頁面的文字，請參閱[維護頁面](/zh-Hant/on-premises/configuration/overleaf-toolkit/branding#maintenance-page)。
</Step>

<Step id="click-disconnect-all-users" title="點選 Disconnect all users">
編輯器中的使用者會看到 **Please wait** 對話方塊，從 10 秒開始倒數。接著頁面重新整理並顯示 **Maintenance**。

<Frame caption="編輯器中的使用者看到的內容">
  <img src="/images/on-premises/basic-management-disconnect-dialog.png" alt="編輯器前方的 Please wait 對話方塊，提示編輯器將在 8 秒後自動重新整理" />
</Frame>

請先關閉編輯器：否則重新整理會讓使用者直接回到編輯器。
</Step>

<Step id="do-the-maintenance-then-click-reopen-editor" title="完成維護，然後點選 Reopen Editor">
所有頁面會立即恢復運作。使用者重新載入頁面即可繼續。
</Step>
</Steps>

<Warning>

登入頁面也會關閉，因此在重新開啟編輯器之前請保持登入。如果你被鎖在外面，請重新啟動執行個體：關閉狀態只保存在記憶體中，因此重新啟動會再次開啟編輯器。

</Warning>

<Info>

在有多個副本的 Kubernetes 上，**Close Editor** 只會關閉處理你請求的那個副本。請改用[維護模式](/zh-Hant/on-premises/configuration/kubernetes/branding#maintenance-mode)。

</Info>
