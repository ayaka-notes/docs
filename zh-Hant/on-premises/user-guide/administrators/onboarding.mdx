---
title: 初始設定
description: 建立第一個管理員，檢查執行個體，並新增第一個使用者。
icon: user-plus
---

請在[安裝](/zh-Hant/on-premises/installation/introduction)完成後立即執行一次以下步驟。本頁使用預設的密碼登入方式。

<Steps>
<Step id="open-the-launchpad" title="開啟 launchpad">
在你的執行個體上開啟 `/launchpad`，例如 `http://localhost/launchpad`。你會看到 **Create the first Admin account**。

此表單只在第一個管理員建立之前存在。之後，未登入的訪客會被導向登入頁面。
</Step>

<Step id="create-the-administrator-account" title="建立管理員帳號">
輸入電子郵件和密碼，然後點選 **Register**。

<Frame caption="第一個管理員帳號">
  <img src="/images/on-premises/onboarding-launchpad-filled.png" alt="填入 admin@example.com 的 launchpad 表單" />
</Frame>

如果密碼遭拒，表單上方會出現一則訊息，且不會建立帳號。

<Frame caption="遭拒的密碼">
  <img src="/images/on-premises/onboarding-password-error.png" alt="launchpad 表單上方的訊息 password is too short" />
</Frame>

| 訊息                                       | 意義                                                                                                                           |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| `password is too short`                    | 少於 8 個字元。                                                                                                                |
| `password is too long`                     | 多於 72 個字元。                                                                                                               |
| `password contains an invalid character`   | 允許的字元為字母 `a-z` 和 `A-Z`、數字以及 `@#$%^&*()-_=+[]{};:<>/?!£€.,`。不允許空格、帶重音符號的字母或非拉丁字母。          |
| `password contains part of email address`  | 密碼包含電子郵件或 `@` 之前的部分，或密碼是電子郵件的一部分。對於 `admin@example.com`，`admin-7Tq9-demo` 和 `example.com` 都會遭拒。 |
| `password is too similar to email address` | 密碼與電子郵件過於相似，例如 `adm1n@example.c0m`。                                                                             |

預設不要求大寫字母、數字和符號。若要變更長度限制，請參閱[密碼限制](/zh-Hant/on-premises/configuration/overleaf-toolkit/authentication/password-restrictions)。
</Step>

<Step id="log-in" title="登入">
點選 **Register** 後你會進入登入頁面。輸入相同的電子郵件和密碼，然後點選 **Login**。

<Frame caption="使用新帳號登入">
  <img src="/images/on-premises/onboarding-login.png" alt="填入 admin@example.com 的登入頁面" />
</Frame>

你會回到 launchpad，此時頁面上多了 **Status Checks**。
</Step>

<Step id="check-the-instance" title="檢查執行個體">
`websockets` 應顯示 **OK**。

若要測試電子郵件，請在 **Send a test email** 下輸入你的地址，點選 **Send**，然後檢查收件匣。

<Frame caption="狀態檢查與測試郵件">
  <img src="/images/on-premises/onboarding-launchpad-checks.png" alt="launchpad 上 websockets 為 OK，測試郵件表單顯示 Email Sent，底部有兩個按鈕" />
</Frame>

<Warning>

**Email Sent** 並不能證明郵件已離開伺服器。若沒有設定[電子郵件寄送](/zh-Hant/on-premises/configuration/overleaf-toolkit/email-delivery)，頁面會顯示相同的文字，但不會收到任何郵件。

</Warning>

**Start Using** _你的網站名稱_ 會開啟你的專案。**Go To Admin Panel** 會開啟網站工具，請參閱[基本管理](/on-premises/user-guide/administrators/basic-management)。
</Step>

<Step id="create-the-first-user" title="建立第一個使用者">
在頂端選單中點選 **Admin**，然後點選 **Manage Users**。

<Frame caption="Admin 選單">
  <img src="/images/on-premises/onboarding-admin-menu.png" alt="包含 Manage Site、Manage Users 和 Project/Object Lookup 的 Admin 選單" />
</Frame>

點選 **Create account**。

<Frame caption="使用者清單">
  <img src="/images/on-premises/onboarding-user-list.png" alt="包含管理員和 Create account 按鈕的使用者清單" />
</Frame>

輸入使用者的電子郵件。**First name** 和 **Last name** 為選填。只有在建立另一個管理員時才勾選 **Admin**。點選 **Create**。

<Frame caption="Create account 對話方塊">
  <img src="/images/on-premises/onboarding-create-account.png" alt="填入 user@example.com 的 Create account 對話方塊" />
</Frame>

接著對話方塊會顯示新帳號及其啟用連結，該連結 7 天後失效：

* **Email Sent** 表示啟用郵件已寄出。
* <strong>No email was sent. Copy the link and pass it on.</strong> 表示郵件沒有寄出，例如因為未設定[電子郵件寄送](/zh-Hant/on-premises/configuration/overleaf-toolkit/email-delivery)。

<Frame caption="新帳號及其啟用連結">
  <img src="/images/on-premises/onboarding-account-created.png" alt="Demo User 的 Create account 對話方塊，顯示未寄出郵件的警告、連結、複製圖示和 Expires in 7 days" />
</Frame>

點選 **Close**。該帳號會以 **Pending** 狀態出現在清單中。

<Frame caption="新帳號在首次登入前維持 Pending">
  <img src="/images/on-premises/onboarding-user-pending.png" alt="Demo User 處於 Pending 狀態的使用者清單" />
</Frame>
</Step>

<Step id="give-the-user-access" title="為使用者開通存取權">
**已設定電子郵件寄送時**，使用者會收到一封附有 **Set password** 連結的啟用郵件。該連結會開啟下方的頁面。使用者輸入密碼並點選 **Activate**，隨後進入專案頁面。上述密碼規則同樣適用。

<Frame caption="使用者開啟連結後看到的頁面">
  <img src="/images/on-premises/onboarding-activate.png" alt="要求使用者設定密碼的啟用頁面" />
</Frame>

**未設定電子郵件寄送時**，請自行轉交連結。在點選 **Create** 後的對話方塊中點選複製圖示，然後把連結傳給使用者，使用者依上述方式設定密碼。

如果你關閉了對話方塊或連結已失效，請在 **Manage Users** 中點選該使用者那一列的信封圖示，然後點選 **Send activation email**。對話方塊會顯示一個新連結，該連結 7 天後失效。

<Frame caption="新的啟用連結">
  <img src="/images/on-premises/onboarding-activation-link.png" alt="Demo User 的 Send activation email 對話方塊，顯示未寄出郵件的警告、連結、複製圖示和 Expires in 7 days" />
</Frame>

你也可以自行設定密碼。在 **Manage Users** 中點選使用者名稱，然後點選鉛筆圖示。輸入 **New password** 並點選 **Save**。把密碼轉交給使用者，使用者在 `/login` 登入。

<Frame caption="在 Account 分頁設定密碼">
  <img src="/images/on-premises/onboarding-set-password.png" alt="處於編輯模式的使用者 Account 分頁，已填入 New password 欄位" />
</Frame>
</Step>

<Step id="confirm-it-worked" title="確認操作成功">
使用者首次登入後，**Manage Users** 中的狀態會變為 **Active**。

<Frame caption="使用者已登入">
  <img src="/images/on-premises/onboarding-user-active.png" alt="Demo User 處於 Active 狀態的使用者清單" />
</Frame>
</Step>
</Steps>

<Info>

預設情況下，**Sign up** 不會建立帳號：該頁面會請訪客聯絡 `OVERLEAF_ADMIN_EMAIL` 中的地址。若要讓使用者自行註冊，請參閱[公開存取](/zh-Hant/on-premises/configuration/overleaf-toolkit/authentication/public-access)。

</Info>
