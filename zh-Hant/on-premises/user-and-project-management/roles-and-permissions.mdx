### 帳號

從管理自身帳號的角度來看，**所有**使用者都被視為一般使用者 — `Site Admins` 與 `Template Users` **不會**獲得任何額外權限。不過，一般使用者可執行的操作會依其驗證方式而有所限制。

#### 設定

**驗證類型：內部帳號 | SSO（SAML/LDAP）**

| 操作                                      | 內部帳號 | SSO（SAML/LDAP） |
| ----------------------------------------- | ----------------: | --------------: |
| 更新帳號資訊                              |                是 |              否 |
| 變更密碼                                  |                是 |              否 |
| 產生 Git bridge 驗證權杖                  |                是 |              是 |
| 刪除 Git bridge 驗證權杖                  |                是 |              是 |
| 管理工作階段                              |                是 |              是 |

<Info>

Git Bridge 整合**僅**在 Server Pro 中提供。更多資訊請參閱 [Server Pro 與 Community Edition 比較](/zh-Hant/on-premises/readme/ayakaleaf-pro-vs-server-pro)。

</Info>

#### 您的工作階段

| 操作                 | 使用者 |
| -------------------- | ---: |
| 清除工作階段         |   是 |
| 檢視目前的工作階段   |   是 |
| 檢視其他工作階段     |   是 |

### 編輯器 IDE

從 Overleaf 編輯器 IDE 的角度來看，您可以是以下其中一種角色：`Project Owner`、`Editor`、`Reviewer`、`Viewer`、`Site Administrator` 或 `Template User`。

<Info>

Server Pro 與 Community Edition 支援為專案提供匿名的**唯讀**與**讀寫**存取權。

更多相關資訊，請參閱[這裡](/zh-Hant/on-premises/configuration/overleaf-toolkit/environment-variables)的 `OVERLEAF_ALLOW_PUBLIC_ACCESS` 與 `OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` 環境變數。

</Info>
