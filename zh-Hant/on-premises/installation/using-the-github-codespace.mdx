測試 Ayakaleaf Pro 最簡單的方式是使用 GitHub Codespace，所有環境變數皆已預先設定，確保您能開箱即用。

<Warning>

當您使用 GitHub Codespaces 執行 Docker 容器時，Codespace 不會自動關閉，並將持續**計費**。關於 GitHub Codespaces 的計費規則，請參閱 [github codespaces 計費規則](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces)。

若要管理您的 GitHub Codespaces，請前往 [https://github.com/codespaces](https://github.com/codespaces)。當您不再需要時，請及時刪除您的 Codespace。

</Warning>

我們已**預先設定**以下功能：

* [x] 使用 TeXLive **Basic**（2024-2026）的沙箱化 LaTeX 編譯
* [x] Pandoc 匯入／匯出（SaaS 平台功能）
* [x] Python 腳本執行器（SaaS 平台功能）
* [x] Git-Bridge 支援（Server Pro 功能）
* [x] 進階參考文獻搜尋（SaaS 平台功能）
* [x] 管理面板（全域使用者／專案管理）
* [x] 追蹤修訂（含審閱與留言面板）
* [x] 完整專案歷程記錄（含還原與下載）
* [x] 符號面板（Server Pro／SaaS 平台功能）

<Warning>

標準 GitHub Codespaces 提供 32 GB 的儲存空間，這對於我們的 `texlive-full` 安裝來說並不足夠。若要測試完整映像檔，請提交 GitHub 支援工單，申請使用大型執行器（8 核心以上）的 Codespace。

</Warning>

GitHub 同步、LDAP、OAuth、SSO、Zotero 整合及其他功能在此試用環境中_**並未設定**_。您可以參考 [toolkit 設定](/zh-Hant/on-premises/configuration/overleaf-toolkit/toolkit-settings)，了解如何在您自己的部署中設定這些功能。

#### 使用 TeXLive Full 映像檔

如果您可以使用 8 核心／64 GB 的 GitHub Codespaces，即可在此試用環境中使用 TeXLive Full 映像檔。您可以在 `toolkit/config/variables.env` 檔案中變更以下環境變數，改用 TeXLive Full 映像檔取代 TeXLive Basic 映像檔。

```dotenv wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1, ghcr.io/ayaka-notes/texlive-full:2024.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025, Texlive 2024
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```

變更環境變數後，您需要重新啟動 toolkit 以套用變更。您可以執行以下指令來重新啟動 toolkit。

```bash
cd toolkit && bin/up -d
```
