### 建立您的第一個管理員帳號 {#creating-your-first-administrator-account}

開啟 `OVERLEAF_SITE_URL` 後接 `/launchpad`，例如 `http://192.0.2.10:30080/launchpad`，並依照 [Toolkit 的安裝後工作](/zh-Hant/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks)註冊管理員帳號。接著建立一個範例專案並進行編譯。

您也可以從命令列建立使用者：

```bash
kubectl -n overleaf exec deploy/overleaf -- bash -c \
  'cd /overleaf/services/web && node modules/server-ce-scripts/scripts/create-user.mjs --admin --email=admin@example.com'
```

它會輸出一個用於設定密碼的連結。

### 檢查編譯是否在沙箱中執行 {#checking-that-compiles-are-sandboxed}

編譯一個專案，然後查看執行該 Pod 的節點：

```bash
kubectl -n overleaf get pod -l app=overleaf -o wide   # NODE column
# on that node:
sudo docker ps -a --filter ancestor=ghcr.io/ayaka-notes/texlive-full:2026.1
ls -ln /srv/overleaf/compiles                          # owned by uid 33 (www-data)
```

每次編譯都會顯示為一個短暫存在、名為 `project-<project id>-<user id>-...` 的容器。

### 日誌與 shell {#logs-and-a-shell}

| Toolkit          | Kubernetes                                                               |
| ---------------- | ------------------------------------------------------------------------ |
| `bin/logs web`   | `kubectl -n overleaf exec deploy/overleaf -- tail -f /var/log/overleaf/web.log` |
| `bin/shell`      | `kubectl -n overleaf exec -it deploy/overleaf -- bash`                    |
| `bin/up`         | `kubectl apply -f .`，接著執行 `kubectl -n overleaf rollout restart deployment/overleaf` |

容器會在 `/var/log/overleaf/` 中為每個服務寫入一個日誌檔案（`web.log`、`clsi.log`、`real-time.log`、`document-updater.log`……）；`kubectl logs` 則顯示啟動輸出。

### Q\&A {#q&a}

<Accordion title="編譯失敗或一直無法完成。">

<strong>回答：</strong>請在執行該 Pod 的節點上確認 Docker 正在執行，且具有 `TEX_LIVE_DOCKER_IMAGE` 中指定的映像檔，並確認 `SANDBOXED_COMPILES_HOST_DIR_*` 與 `hostPath` 路徑相符。Pod 中的 `/var/log/overleaf/clsi.log` 會指出失敗的步驟。

</Accordion>

<Accordion title="每次重新啟動 Pod 後，使用者都會被登出。">

<strong>回答：</strong>Secret `overleaf-secrets` 中缺少 `OVERLEAF_SESSION_SECRET`，請參閱[步驟 2](/zh-Hant/on-premises/installation/using-kubernetes/2.-create-the-namespace-and-secrets)。

</Accordion>
