### 下載 Toolkit

你需要使用 **Ayakaleaf Toolkit**（[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)）來安裝 Ayakaleaf Pro，這是一組會替你在 Docker 中執行 Overleaf 的腳本。

預設情況下，Toolkit 會啟動免費的官方 Overleaf Community Edition（CE）。[4. 取得 Ayakaleaf Pro 映像檔](/zh-Hant/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images) 只需一項設定即可將其切換為 Ayakaleaf Pro。

<Accordion title="已經在執行官方的 Overleaf Toolkit（overleaf/toolkit）？">

你不需要重新安裝。保留你現有的安裝，並依照 [4. 取得 Ayakaleaf Pro 映像檔](/zh-Hant/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images) 的最後一部分操作即可。

</Accordion>

<Steps>
<Step title="複製 Ayakaleaf Toolkit 儲存庫">
若要安裝 Toolkit，請先切換到預計的安裝路徑，然後使用以下指令複製 Ayakaleaf Toolkit 儲存庫：

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
```

<Info>

為了避免潛在的權限問題，我們建議將 Toolkit 安裝在你使用者的 `$HOME` 目錄中。

</Info>
</Step>

<Step title="切換至 toolkit 目錄">
等待複製程序完成後，切換到新建立的 `overleaf-toolkit` 目錄：

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
