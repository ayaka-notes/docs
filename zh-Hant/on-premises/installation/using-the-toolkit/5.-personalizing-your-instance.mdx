### 個人化你的執行個體

首次啟動 Overleaf 執行個體之前，請在 `config/variables.env` 設定檔中填入你的自訂資訊。

<Steps>
<Step title="編輯變數檔案">
使用你慣用的文字編輯器開啟 `config/variables.env`，並將下列環境變數更新為所需的值。
</Step>

<Step title="必要的環境變數">
更新 `config/variables.env` 中的下列變數：

| 名稱                          | 說明                                                                                                                                                    | 範例                         |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| `OVERLEAF_SITE_URL`           | Overleaf 執行個體對外公開的位址。此值用於公開連結以及 WebSocket 連線，因此**必須正確設定**！ | `https://overleaf.lilliput.com` |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | 此電子郵件地址將作為所有外寄郵件的 `from` 地址。                                                                                 | `no-reply@lilliput.com`         |
| `OVERLEAF_ADMIN_EMAIL`        | 使用者可用來聯絡網站管理者的電子郵件地址。                                                                                          | `it-services@lilliput.com`      |

更新這些環境變數後，儲存並離開。
</Step>

<Step title="設定沙箱編譯">
接著，為 [sandboxed-compiles.md](/zh-Hant/on-premises/configuration/overleaf-toolkit/sandboxed-compiles  "mention") 設定 TeX Live Full。開啟 `config/variables.env` 並更新下列環境變數：

```dotenv title="config/variables.env" wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```
</Step>

<Step title="啟動執行個體">
執行下列指令以啟動執行個體：

```text title="Start the instance"
bin/up
```

此指令會下載包括 TeX Live 在內的所需映像檔、（依照你的自訂設定）建立容器並啟動執行個體。你應該會看到各個 Docker 容器的日誌輸出。

之後若要再次啟動（且不附加到日誌輸出），請執行：

```text title="Start without attaching to logs"
bin/start
```
</Step>
</Steps>

<Info>

Toolkit 使用 `docker compose` 管理 Overleaf 的 Docker 容器。Toolkit 提供一組包裝 `docker compose` 的指令碼，替你處理大部分細節。

</Info>

若一切順利，在瀏覽器中前往 [http://127.0.0.1/](http://127.0.0.1/) 或 [http://localhost/](http://localhost/)，應該就能看到新 Overleaf 執行個體的登入頁面。

<Warning>

視你的網路設定以及 Overleaf 執行個體的託管位置而定，你可能需要進行額外的設定變更。詳情請參閱 Toolkit 設定： [toolkit-settings.md](/zh-Hant/on-premises/configuration/overleaf-toolkit/toolkit-settings  "mention")

</Warning>
