### 建立您的第一個管理員帳號 {#creating-your-first-administrator-account}

在瀏覽器中開啟 [http://localhost/launchpad](http://localhost/launchpad)。若您變更了 `OVERLEAF_LISTEN_IP` 或 `OVERLEAF_PORT`，請改用您的 `OVERLEAF_SITE_URL`，例如 `http://192.168.1.20:8080/launchpad`。本頁其他 `localhost` 連結也同樣適用。您應該會看到一個包含電子郵件與密碼欄位的表單。填入您想作為管理員帳號使用的憑證，然後按一下 **Register**。

<Info>

密碼長度必須至少 8 個字元（不超過 72 個字元），不能包含電子郵件地址或與電子郵件地址過於相似，且只能包含有效字元。

</Info>

![在 launchpad 上建立第一個管理員帳號](/images/on-premises/post-installation-launchpad.png)

接著系統會帶您前往登入頁面（[http://localhost/login](http://localhost/login)）。輸入憑證。登入後，您會再次看到 launchpad，此時會顯示狀態檢查。

![登入後的 launchpad 狀態檢查](/images/on-premises/post-installation-status-checks.png)

按一下頁面底部的綠色按鈕，開始使用 Overleaf。

### 建立您的第一個範例專案 {#creating-your-first-example-project}

在瀏覽器中開啟 [http://localhost/project](http://localhost/project)，您會看到一個提示您建立第一個專案的按鈕。

![建立新專案選單](/images/on-premises/post-installation-create-project.png)

按一下此按鈕，選擇 **Example project**，然後依照畫面上的指示操作。

系統會帶您進入新專案，您會看到文字編輯器與 PDF 預覽。

![編輯器中的範例專案](/images/on-premises/post-installation-editor.png)

最後，您可以按一下左上角的 Overleaf 標誌返回您的專案頁面。
