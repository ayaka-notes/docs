在本節中，我們將引導您安裝 Docker、從 GitHub 下載 Toolkit、熟悉 Toolkit 的一些指令，並設定一些基本設定。完成本節後，您應該就會有一個正在執行的地端 Overleaf 執行個體。

這些步驟以近期的 Ubuntu LTS 為對象。若使用其他發行版，請依照 [Docker 文件](https://docs.docker.com/engine/install/) 安裝 Docker Engine 與 Compose 外掛，然後繼續進行 [1. 下載 Toolkit](/zh-Hant/on-premises/installation/using-docker-compose/linux/1.-download-the-toolkit)。

<Info>

預設情況下，執行個體只接受來自伺服器本身、位於 `http://localhost` 的連線。若要從其他電腦或在其他連接埠上開啟，請在 `config/overleaf.rc` 中設定 `OVERLEAF_LISTEN_IP` 與 `OVERLEAF_PORT`，如 [5. 個人化你的執行個體](/zh-Hant/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance)中所述。

</Info>
