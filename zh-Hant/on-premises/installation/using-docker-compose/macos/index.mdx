在本節中，我們會使用 Docker Desktop 與 [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit) 在您的 Mac 上本機執行 Ayakaleaf Pro。本指南使用 `http://localhost:8080`，將資料保存在您的家目錄中，並在沙箱容器中以 TeX Live 2026 進行編譯。

Docker Desktop 會在 Linux 虛擬機器中執行應用程式、MongoDB、Redis 與 TeX Live 編譯器。您不需要在 macOS 本身安裝 MongoDB、Redis 或 MacTeX。

此設定適用於個人使用與本機測試。若要提供全天候運作的共用服務，我們建議依照 [Linux 指南](/zh-Hant/on-premises/installation/using-docker-compose/linux) 操作，並搭配 HTTPS、備份與存取控制。當 Mac 進入睡眠或 Docker Desktop 停止時，執行個體將無法使用，請參閱 [保持執行個體可用](/zh-Hant/on-premises/installation/using-docker-compose/macos/6.-post-installation-tasks#keep-the-instance-available)。

## 開始之前 {#before-you-start}

您需要：

* [Docker Desktop for Mac](https://docs.docker.com/desktop/setup/install/mac-install/) 支援的 macOS 版本。
* Git、[Homebrew](https://brew.sh/) 與 GNU sed。Toolkit 使用了 macOS 內建 BSD sed 不接受的 GNU sed 選項。
* 足以同時供 macOS 與 Docker 使用的資源。對於小型本機執行個體，請先為 Docker Desktop 分配 4 個 CPU 與 8 GB 記憶體。這是建議的起始值，而非經過測量的最低需求。
* 至少 40 GB 的可用儲存空間以存放完整的 TeX Live 映像檔，另加上專案所需的空間。請同時檢查 Mac 上的可用空間與 Docker Desktop 的磁碟用量上限。先從一個 TeX Live 版本開始：每多一個版本，大約就需要再多一倍的空間。

應用程式與 TeX Live 映像檔皆提供 `arm64` 與 `amd64` 版本。在 Apple silicon 上，請讓 Docker 自動選擇原生 ARM 映像檔，不要強制設定 `platform: linux/amd64`。
