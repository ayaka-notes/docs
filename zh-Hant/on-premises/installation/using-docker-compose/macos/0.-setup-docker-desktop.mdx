Ayakaleaf Pro 在 Docker 上執行。在 Mac 上，您會使用 Docker Desktop，它會在 Linux 虛擬機器中執行 Docker 引擎。

<Steps>
<Step title="安裝並啟動 Docker Desktop">
安裝適用於您 Mac（Apple silicon 或 Intel）的 [Docker Desktop](https://docs.docker.com/desktop/setup/install/mac-install/) 版本，開啟它，並等待引擎啟動完成。您也可以從終端機啟動它：

```bash
open -a Docker
```
</Step>

<Step title="檢查 Docker 引擎">
在終端機中執行以下指令：

```bash
docker context show
docker info
docker compose version
```

context 應指向您本機的 Docker Desktop 引擎，通常是 `desktop-linux`。若選取的是其他 context，請在繼續之前切換到 Docker Desktop：

```bash
docker context use desktop-linux
```

`docker info` 必須輸出 **Server** 區段。單獨執行 `docker --version` 只能顯示用戶端已安裝。
</Step>

<Step title="檢查資源與檔案分享">
在 Docker Desktop 的 **Settings** 中，對照 [開始之前](/zh-Hant/on-premises/installation/using-docker-compose/macos#before-you-start) 檢查 CPU、記憶體與磁碟上限，並檢查檔案分享設定，請參閱 [Docker Desktop 設定](https://docs.docker.com/desktop/settings-and-maintenance/settings/)。

本指南將 Toolkit 放在 `/Users` 下，Docker Desktop 預設會分享此目錄。若您使用其他位置，且 `bin/up` 失敗並出現 `Mounts denied`，請將該目錄加入檔案分享。
</Step>

<Step title="檢查用於沙箱編譯的 Docker socket">
Toolkit 會將 `/var/run/docker.sock` 掛載到應用程式中，讓它能為每次編譯啟動獨立的 TeX Live 容器。請在 `config/overleaf.rc` 中保留 `DOCKER_SOCKET_PATH=/var/run/docker.sock`。

macOS 上的 Docker CLI 可能會透過 `~/.docker/run/docker.sock` 連線。那是 Mac 上的用戶端端點，並不是變更 Toolkit 掛載來源的理由：編譯器需要的是 Linux 容器所看到的引擎 socket。

若 Mac 上沒有 `/var/run/docker.sock`，請在 **Settings → Advanced** 下開啟 **Allow the default Docker socket to be used**，請參閱 [Docker 的權限需求](https://docs.docker.com/desktop/setup/install/mac-permission-requirements/)。

<Danger>

請勿對 socket 執行 `chmod 777` 來規避錯誤。存取 Docker socket 等同於擁有 Docker 虛擬機器的 root 權限。

</Danger>
</Step>
</Steps>
