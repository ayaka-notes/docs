<Steps>
<Step title="檢查 Git 與 Homebrew">
```bash
git --version
brew --version
```

若執行 Git 時 macOS 要求您安裝 Command Line Tools，請先安裝它們。若缺少 Homebrew，請依照 [官方說明](https://brew.sh/) 安裝。
</Step>

<Step title="將 GNU sed 加入 PATH">
Toolkit 腳本使用了 macOS 內建 BSD sed 會拒絕的 GNU sed 選項。請安裝 [GNU sed](https://formulae.brew.sh/formula/gnu-sed)，並在此終端機中將它放在 `PATH` 的最前面：

```bash
brew install gnu-sed
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
sed --version
```

最後一個指令應該會輸出 **GNU sed**。

僅設定像 `alias sed=gsed` 這樣的別名是不夠的：Toolkit 執行的是 Bash 腳本，而這些腳本看不到您互動式 shell 的別名。您不需要取代 `/usr/bin/sed`。

在每個用於操作 Toolkit 的新終端機中，請再次執行 `export PATH=...` 這一行，或將它加入您的 shell 啟動檔中，並放在 Homebrew 自身的初始化之後。
</Step>

<Step title="複製 Ayakaleaf Toolkit 儲存庫">
請選擇一個會持續保存的目錄。對於正在使用的資料庫與專案資料，請避免使用 `/tmp`、可移除式磁碟，以及 iCloud Drive 等雲端同步資料夾。本指南使用 `~/ayakaleaf-toolkit`：

```bash
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

<Warning>

若該目錄中已有一個安裝，請直接沿用，或為新的執行個體選擇其他目錄。請勿在現有部署上初始化新的設定。

</Warning>
</Step>
</Steps>
