Toolkit 在 macOS 與 Linux 上是相同的。其結構、`config/` 目錄與 `bin/` 指令都在 Linux 指南的 [2. 熟悉 Toolkit](/zh-Hant/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) 中說明。

在 macOS 上，請留意三項差異：

* 請在 GNU sed 位於 `PATH` 最前面的終端機中執行腳本，請參閱 [1. 下載 Toolkit](/zh-Hant/on-premises/installation/using-docker-compose/macos/1.-download-the-toolkit)。
* 在執行會與 Docker 溝通的腳本（例如 `bin/up`、`bin/start` 或 `bin/docker-compose`）之前，請先啟動 Docker Desktop。
* `bin/doctor` 包含從官方 Overleaf Toolkit 繼承而來的檢查。它的 `This system seems to not be Linux` 警告在 macOS 上是預期中的，而關於未登入 `quay.io` 的警告也不適用於公開的 `ghcr.io/ayaka-notes/overleaf-pro` 映像檔。報告中的其他問題仍然需要處理。
