在單一伺服器上使用 Docker Compose 是部署 Ayakaleaf Pro 的建議方式。您會透過 [Toolkit](https://github.com/ayaka-notes/toolkit) 來執行它：這是一組包裝 `docker compose` 的腳本，會從單一 `config/` 目錄讀取您的設定，因此以 `bin/up` 取代 `docker compose up`。
