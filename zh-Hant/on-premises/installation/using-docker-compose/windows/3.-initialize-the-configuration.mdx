---
title: 3. 初始化設定
description: 在 WSL 2 上的 Ubuntu 中使用 bin/init 建立 Toolkit 設定檔。
icon: circle-play
---

在 **Ubuntu** 的 Toolkit 目錄中執行：

```bash
bin/init
```

`bin/init` 會建立三個檔案：

| 檔案 | 用途 |
| --- | --- |
| `config/overleaf.rc` | 容器設定、對外發布的連接埠與資料位置 |
| `config/variables.env` | 應用程式設定與機密 |
| `config/version` | 應用程式映像檔版本 |

它也會在 `config/variables.env` 中產生 `OVERLEAF_INVITE_TOKEN_SECRET`。請妥善保留，且不要公開此檔案或將其提交至版本控制。

對於新安裝，請保留 Toolkit 所選擇的版本。若之後要變更現有執行個體的版本，請依照 [升級您的部署](/zh-Hant/on-premises/maintenance/upgrading-your-deployment) 操作。

<Info>

`bin/init` 不會覆寫現有的設定。若它回報檔案已存在，請在繼續之前先檢查這些檔案。重新啟動或升級執行個體時，請保留 `config/` 與 `data/`。

</Info>
