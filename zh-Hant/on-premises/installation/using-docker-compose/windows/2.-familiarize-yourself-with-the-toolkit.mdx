Toolkit 與 Linux 上的相同。其結構、`config/` 目錄與 `bin/` 指令都在 Linux 指南的 [2. 熟悉 Toolkit](/zh-Hant/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) 中說明。

在 Windows 上，請留意以下差異：

* 請在 **Ubuntu Bash** 中，從 `~/ayakaleaf-toolkit` 執行 `bin/` 指令。標示為 **PowerShell** 的指令則在 Windows 中執行。
* 在使用 `bin/up`、`bin/start` 或 `bin/docker-compose` 之前，請先啟動 Docker Desktop 並啟用 Ubuntu 的 WSL Integration。
* 請讓設定檔保持 Linux 換行字元（LF）。請在 Ubuntu 中使用 `nano`，或使用已連接至 WSL 的編輯器來編輯它們。CRLF 換行字元可能會導致 Bash 錯誤。
* `bin/doctor` 會在 Ubuntu 內執行 Linux 檢查。它關於未登入 `quay.io` 的警告不適用於公開的 `ghcr.io/ayaka-notes/overleaf-pro` 映像檔。其他警告仍需留意。

```bash
bin/doctor
```
