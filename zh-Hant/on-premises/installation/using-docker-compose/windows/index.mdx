在本節中，我們會使用 WSL 2、Ubuntu、Docker Desktop 與 [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit) 在 Windows 上本機執行 Ayakaleaf Pro。本指南使用 `http://localhost:8080`，將資料保存在 Ubuntu 的家目錄中，並啟用沙箱編譯。

應用程式、MongoDB、Redis 與 TeX Live 在由 Docker Desktop 管理的 Linux 容器中執行。請在 Ubuntu 中執行 Toolkit 指令，並在 Windows 瀏覽器中開啟應用程式。[步驟 0](/zh-Hant/on-premises/installation/using-docker-compose/windows/0.-setup-wsl-and-docker-desktop) 會說明 Windows 與 Linux 部分如何搭配運作，並從安裝 WSL 開始。

您可以將 Windows 用於本機執行個體，或透過步驟 6 中的可用性設定讓它持續運作。對於共用與正式環境的伺服器，我們建議依照 [Linux 指南](/zh-Hant/on-premises/installation/using-docker-compose/linux) 操作，並搭配 HTTPS、備份與存取控制。Windows 睡眠、Docker Desktop 關閉與 WSL 關閉都會中斷此本機執行個體；請參閱 [保持執行個體可用](/zh-Hant/on-premises/installation/using-docker-compose/windows/6.-post-installation-tasks#keep-the-instance-available)。

## 開始之前 {#before-you-start}

您需要：

* [Docker Desktop for Windows](https://docs.docker.com/desktop/setup/install/windows-install/) 支援的 Windows 版本與處理器，且已啟用硬體虛擬化。本指南使用 x86-64 上的 Windows 11。
* 啟用 WSL 與安裝軟體的權限。WSL 必須為 2.1.5 或更新版本，且 Ubuntu 以 WSL 2 模式執行。
* 足以同時供 Windows 與容器使用的記憶體。對於小型本機執行個體，提供給 Docker 4 個 CPU 與 8 GB 記憶體是建議的起始值，而非經過測量的最低需求。
* 存放 WSL 與 Docker 資料的 Windows 磁碟上的可用儲存空間。完整的 TeX Live 環境加上專案資料請預留至少 40 GB；[步驟 5](/zh-Hant/on-premises/installation/using-docker-compose/windows/5.-personalizing-your-instance) 中的 basic 映像檔較小，適合用於初次部署測試。額外的映像檔版本需要額外的空間。
* 可連線至 GitHub、GitHub Container Registry（`ghcr.io`）與 Docker Hub 的網路，以便複製 Toolkit 並下載映像檔。

**PowerShell** 區塊在 Windows 中執行。除非另有說明，**Bash** 區塊與 `bin/` 指令都在 Ubuntu 中執行。請勿在 PowerShell 或 Windows Git Bash 中執行 Toolkit 腳本。
