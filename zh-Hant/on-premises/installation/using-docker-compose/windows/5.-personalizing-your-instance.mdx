請在 **Ubuntu** 中，從 `~/ayakaleaf-toolkit` 執行指令並編輯檔案。

<Steps>
<Step title="容器設定">
在 `config/overleaf.rc` 中編輯既有項目：

```bash title="config/overleaf.rc"
PROJECT_NAME=ayakaleaf-wsl
SERVER_PRO=true
OVERLEAF_LISTEN_IP=127.0.0.1
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
DOCKER_SOCKET_PATH=/var/run/docker.sock
```

保留預設的資料路徑，以及內建的 MongoDB 與 Redis 服務。連接埠 `8080` 供本機 Windows 瀏覽器使用；綁定至 `127.0.0.1` 可讓它只在本機可用。沙箱編譯會為每次編譯使用獨立的 Linux 容器，而不是在應用程式容器內執行 TeX。Docker socket 讓應用程式能建立這些容器，而 Toolkit 會在 `data/overleaf/data/compiles` 下提供編譯資料的主機路徑。
</Step>

<Step title="應用程式設定">
在 `config/variables.env` 中設定以下值，並取代任何同名的現行項目：

```dotenv title="config/variables.env"
OVERLEAF_SITE_URL=http://localhost:8080
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES="TeX Live 2026"
```

full 映像檔包含各式各樣專案所需的套件與字型。請為它與應用程式預留至少 40 GB 的可用儲存空間，另加上專案資料與未來更新所需的空間。

若只是要快速測試部署，請改用較小的 **basic** 映像檔。它足以完成步驟 6 中的簡單 article 測試，但不包含完整的套件與字型集：

```dotenv
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-basic:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-basic:2026.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES="TeX Live 2026 Basic"
```

請從這兩組中選擇一組，且不要有重複的現行鍵值。basic 映像檔的 [Dockerfile](https://github.com/ayaka-notes/texlive-full/blob/main/texlive/2026/Dockerfile.basic) 包含 `latexmk`、XeTeX 與 `fontspec`，但不包含 `ctex` 或完整的字型集。basic 中缺少某個 LaTeX 套件，本身並不代表沙箱有問題。

產生一個工作階段密鑰：

```bash
openssl rand -hex 32
```

將結果以 `OVERLEAF_SESSION_SECRET` 加入 `config/variables.env`。也請保留已產生的邀請權杖密鑰。對於不使用電子郵件的本機執行個體，請不要設定 SMTP 相關設定與 `OVERLEAF_EMAIL_FROM_ADDRESS`。
</Step>

<Step title="啟動您的執行個體">
```bash
bin/up -d
```

Toolkit 會啟動 MongoDB、初始化其副本集、下載所選的 TeX Live 映像檔，並啟動 Redis 與應用程式。下載大型映像檔時，它看起來可能像是暫停了。在第一個 `bin/up` 仍在執行時，請勿執行第二個 `bin/up`。

在另一個 Ubuntu 終端機中檢查：

```bash
cd "$HOME/ayakaleaf-toolkit"
bin/docker-compose ps
bin/docker-compose logs --tail=100 mongo
bin/docker-compose logs --tail=100 -f sharelatex
```

按下 `Ctrl+C` 即可停止追蹤日誌；以分離模式執行的容器會繼續執行。若啟動在 MongoDB 階段失敗，請先依照 [MongoDB 無法啟動](/zh-Hant/on-premises/installation/using-docker-compose/windows/troubleshooting#mongodb-fails-to-start) 處理再重試。請勿為了重設現有安裝而刪除其資料目錄。

檢查連接埠與首次執行頁面：

```bash
bin/docker-compose port sharelatex 80
curl -I http://localhost:8080/launchpad
```

連接埠應為 `127.0.0.1:8080`。若 HTTP 請求一開始失敗，請等待應用程式完成初始化。
</Step>

<Step title="從 Windows 開啟執行個體">
在您的 **Windows 瀏覽器** 中開啟 [http://localhost:8080/launchpad](http://localhost:8080/launchpad)。在 Windows 中也請使用這個位址，而不是暫時性的 WSL IP 位址。

若要在瀏覽器之外另行檢查 Windows 的 HTTP 存取，請在 **PowerShell** 中執行：

```powershell
curl.exe -I http://localhost:8080/launchpad
```

若 Ubuntu 可以連到頁面但 Windows 不行，請參閱 [Windows 無法開啟 localhost](/zh-Hant/on-premises/installation/using-docker-compose/windows/troubleshooting#windows-cannot-open-localhost)。
</Step>
</Steps>
