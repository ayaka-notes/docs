---
title: 3. 啟動 Ayakaleaf Pro
description: 在 Podman 上啟動 Ayakaleaf Pro，使用 podman-setup 與 bin/doctor 驗證，並讓它在重新開機後自動啟動。
icon: circle-play
---

<Steps>
<Step title="啟動容器">
```bash title="Start Ayakaleaf Pro"
bin/up -d
```

第一次啟動會下載 MongoDB、Redis 與 TeX Live 映像檔，並在 `data/` 中建立資料目錄。它會印出一則警告，說明 Podman 支援仍屬實驗性質。

<Info>

第一次啟動也可能印出 `MongoNetworkError: connect ECONNREFUSED 127.0.0.1:27017`。Toolkit 會在 MongoDB 仍在啟動時設定 MongoDB 複本集，並持續重試直到它回應。你可以忽略這一行。

</Info>

一兩分鐘後，檢查容器是否正在執行：

```bash title="List the containers"
podman ps --format "{{.Names}} {{.Status}}"
```

```text
mongo Up 34 seconds (healthy)
redis Up 20 seconds
sharelatex Up 20 seconds
```
</Step>

<Step title="再次檢查設定">
現在資料目錄已經存在，`sharelatex` 容器也在執行，`bin/podman-setup` 可以完成它的檢查了：

```bash title="Check the setup"
bin/podman-setup
```

它會檢查新資料目錄的擁有者，並從 `sharelatex` 容器內部測試 Podman socket：

```text
====== Socket Connectivity ======
[✓] host → socket OK
[✓] container → socket OK

====== Data Directory Permissions ======
[✓] mongo data dir owned by 999
[✓] redis data dir owned by 999
[✓] overleaf data dir owned by 33
...
====== Summary ======
[✓] 27 passed  [!] 1 warnings  [✗] 0 failures
[!] Warnings:
[!] not logged in to quay.io
```

`container → socket OK` 表示 Ayakaleaf Pro 可以啟動編譯容器。如果某項檢查失敗，請執行 `bin/podman-setup --apply`，然後執行 `bin/up -d`。quay.io 警告不適用於 Ayakaleaf Pro，請參閱 [2. 執行 podman-setup](/zh-Hant/on-premises/installation/using-podman/2.-run-podman-setup)。
</Step>

<Step title="執行 doctor">
```bash title="Run the doctor"
bin/doctor
```

在 Podman 上，報告會顯示執行環境與安全性設定：

```text
- Container Daemon
    - status: up
    - runtime: podman
    - server version: 5.8.5
    - socket: /run/user/1000/podman/podman.sock
    - DOCKER_HOST: unix:///run/user/1000/podman/podman.sock
    - host → socket: OK
    - container → socket: OK
- Security
    - SELinux: Enforcing
    - SELINUX_MODE: managed
    - SELINUX_LABEL: sharelatex_t
    - SELinux module: loaded (podman_socket_clsi)
    - SELinux rules: present
    - Seccomp profile: present
```

結尾的警告 `Server Pro enabled, but not logged in to quay.io repository` 是同一個 quay.io 檢查，請參閱 [取得協助](/zh-Hant/on-premises/support/getting-help#q-and-a)。
</Step>

<Step title="重新開機後啟動 Ayakaleaf Pro">
使用 Docker 時，Docker 常駐程式會在重新開機後再次啟動容器。Rootless Podman 沒有常駐程式：請啟用在伺服器開機時啟動你的容器的使用者服務：

```bash title="Start the containers at boot"
systemctl --user enable podman-restart.service
```

它會啟動你的使用者底下所有重新啟動原則為 `always` 的容器，Toolkit 為它的所有容器都設定了此原則。這需要 lingering，而 `bin/podman-setup --apply` 已經啟用它。如果沒有這個服務，請在每次重新開機後執行 `bin/up -d`。
</Step>

<Step title="在防火牆中開放連接埠">
預設情況下，執行個體只接受來自伺服器本身的連線，位址為 `http://localhost:8080`。若要從其他電腦存取，請依照 [5. 個人化你的執行個體](/zh-Hant/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance#listen-address-and-port) 的說明，在 `config/overleaf.rc` 中設定 `OVERLEAF_LISTEN_IP`，在 `config/variables.env` 中設定 `OVERLEAF_SITE_URL`，然後再次執行 `bin/up -d`。

與 Docker 不同，rootless Podman 不會繞過主機防火牆。如果 `firewalld` 正在執行（這是 RHEL 上的預設），請開放連接埠：

```bash title="Open port 8080"
sudo firewall-cmd --permanent --add-port=8080/tcp
sudo firewall-cmd --reload
```

在雲端伺服器上，也要在供應商的安全性群組中允許該連接埠。在將執行個體公開到網際網路之前請使用 HTTPS，請參閱 [4. 安裝後工作](/zh-Hant/on-premises/installation/using-podman/4.-post-installation-tasks#use-https)。
</Step>
</Steps>
