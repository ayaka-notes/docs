### 作業系統

為了在執行 Overleaf 時獲得最佳體驗，我們強烈建議使用**以 Debian 為基礎**的作業系統，例如 **Ubuntu**。這與軟體的開發環境一致，也是大多數 Overleaf 使用者的首選。

<Danger>

使用 Server Pro 搭配沙箱編譯時，**務必**注意該應用程式需要以 root 權限存取 Docker socket。

</Danger>

### 相依套件

* Docker 25.0 與 29
* MongoDB 7.0 與 8.0
* Redis 6.2 與 7.5

<Info>

你可以使用 endoflife.date 服務追蹤上述相依套件及其他熱門產品的生命週期結束（EOL）日期： [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

執行 Server CE 或 Server Pro 時，`docker compose` 會自動拉取 MongoDB 與 Redis，除非已設定使用其他安裝。

</Info>

Toolkit 相依於下列程式：

* bash
* Docker

`docker compose` 為必要元件，通常會隨 Docker 一併安裝。

我們建議你安裝作業系統可用的最新版 Docker。

正確安裝 Docker 後，你應該可以無誤地執行下列指令：

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2)
docker compose version

# List the running Docker containers on your system
docker ps
```
