我們尊重著作權，因此在此列出本專案使用的所有功能與程式碼。本頁提供 Ayakaleaf Pro 新功能及相關程式碼著作權的資訊。

除非另有說明，我們使用 OpenAI 的 Codex 進行程式碼審查與 PR 審查。在此過程中，我們修正了許多安全性問題，並對他們致上誠摯的謝意。詳細資訊請參閱 [ayaka-notes/ayakaleaf-pro/pull](https://github.com/ayaka-notes/ayakaleaf-pro/pulls)。

### 概覽 {#overview}

多年來，許多社群開發者為改善 Overleaf Community Edition 付出了大量心力。他們是：

* [https://github.com/ertuil/overleaf](https://github.com/ertuil/overleaf)
* [https://github.com/AllanChain/lcpu-overleaf](https://github.com/AllanChain/lcpu-overleaf)
* [https://github.com/yu-i-i/overleaf-cep/](https://github.com/yu-i-i/overleaf-cep/)
* [https://github.com/ayaka-notes/overleaf](https://github.com/ayaka-notes/overleaf)
* [https://github.com/davrot/overleaf\_with\_admin\_extension](https://github.com/davrot/overleaf_with_admin_extension)
* [https://github.com/overleaf/overleaf/pull/1447](https://github.com/overleaf/overleaf/pull/1447)（GitHub 整合）
* [https://github.com/overleaf/overleaf/pull/1385](https://github.com/overleaf/overleaf/pull/1385)（Typst 支援）

我們的專案中可能使用了相關的程式碼，在此向他們表達感謝。

* 直接在範本頁面下載範本。

<Warning>

當您的系統有 1000 位使用者或 1000 個專案時，管理面板只會顯示最新的 1000 位使用者或 1000 個專案。請使用搜尋面板搜尋特定的使用者或專案。

* 直接在專案管理面板中開啟專案。
* 在管理面板中檢視並調整使用者的編譯時間限制。
* 直接在管理面板中重設使用者的密碼。
* 其他強化功能……

#### 功能 13：Python 執行器 {#features-13-python-runner}

此功能由 Overleaf 官方開發。您可以在瀏覽器中執行 Python 腳本。

此功能為內建，無須任何設定：在專案中開啟 `.py` 檔案並點擊 **Run** 即可。腳本會透過 Pyodide 在使用者的瀏覽器中執行，因此只能使用 Pyodide 的內建套件。

* 編輯器下方的輸出窗格會顯示腳本印出的內容（最後 100 行）。點擊 **Stop** 可中斷執行。每次執行都會啟動全新的 Python，因此不會沿用上一次執行的任何狀態。
* 每次執行前，專案的文字檔案會被複製到腳本的工作資料夾，因此腳本可以依專案路徑開啟這些檔案，例如 `open('data/results.csv')`。圖片與 PDF 等二進位檔案不會被複製。
* 腳本寫入該資料夾的檔案，會在執行成功時以相同路徑儲存至專案，並取代同名檔案。執行失敗時不會儲存任何內容。單次執行最多可儲存 50 個檔案，每個檔案上限 50 MB，總計上限 100 MB。
* Matplotlib 沒有顯示介面：請使用 `plt.savefig('figure.png')` 儲存圖表，再將該圖片插入您的 LaTeX 文件。
* Pyodide 及其套件（例如 NumPy、pandas、SciPy 與 Matplotlib）由您的執行個體提供，因此瀏覽器無須連線至網際網路。無法使用透過 pip 安裝的套件。

#### 功能 17：文獻管理工具整合 {#features-17-reference-manager-integration}

此功能由 [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) 開發。Zotero 整合最初由 [davrot](https://github.com/davrot) 與 [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep) 開發；我們在 v6.3.0 中以 OAuth 重新打造，並新增了 Mendeley 整合（OAuth 2.0）。您可以：

* 在帳戶設定中連結您的 Zotero 與 Mendeley 帳戶。
* 將您的個人文獻庫或群組文獻庫以 `.bib` 檔案匯入至專案。
* 隨時重新整理匯入的 `.bib` 檔案，使其保持最新。

設定方式請參閱 [Zotero 整合](/zh-Hant/on-premises/configuration/overleaf-toolkit/integrations/zotero-integration) 與 [Mendeley 整合](/zh-Hant/on-premises/configuration/overleaf-toolkit/integrations/mendeley-integration)。

#### 功能 18：Open in Overleaf API {#features-18-open-in-overleaf-api}

此功能由 [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) 開發，相容於 overleaf.com 的「Open in Overleaf」API。您可以在您的網站、部落格或範本庫中加入「Open in Ayakaleaf」連結或按鈕，讓訪客只需點擊一下，即可將 LaTeX 程式碼片段、遠端檔案或 ZIP 專案作為新專案在您的執行個體中開啟。詳情請造訪您執行個體上的 `/devs`，並參閱 [Overleaf Import API](/zh-Hant/on-premises/configuration/overleaf-toolkit/integrations/overleaf-import-api)。

#### 功能 20：Dropbox 同步 {#features-20-dropbox-sync}

此功能由 [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) 於 v6.3.1 以早期預覽版開發（於 v6.4.0 正式發布），與 overleaf.com 上的 Dropbox 同步相同。使用者連結 Dropbox 帳號後，其每個專案都會以資料夾的形式出現在其 Dropbox 中：在 Overleaf 中所做的變更會傳送至 Dropbox，而在 Dropbox 中所做的變更也會回傳至 Overleaf。設定方式請參閱 [Dropbox 同步](/zh-Hant/on-premises/configuration/overleaf-toolkit/integrations/dropbox-synchronisation)。
