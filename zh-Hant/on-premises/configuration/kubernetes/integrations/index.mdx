---
title: 整合
description: 將 Kubernetes 部署連接至 Git、GitHub、GitLab、Gitea、Dropbox、文獻管理工具、AI 服務及其他網站。
icon: puzzle-piece
---

除了 Overleaf 匯入 API 之外，每項整合預設皆為關閉。GitHub、GitLab、Gitea 與 Dropbox 同步以及 MCP Server 也需要 [Git 整合](/zh-Hant/on-premises/configuration/kubernetes/integrations/git-integration)。在 ConfigMap 或 Secret 中啟用某項整合後，請使用 `kubectl -n overleaf rollout restart` 重新啟動副本。
