你可以透過三種方式向沒有帳號的人開放 Overleaf 執行個體：

* [專案存取](/zh-Hant/on-premises/configuration/overleaf-toolkit/public-access#project-access  "mention")：讓訪客無需登入即可開啟分享的專案連結
* [頁面存取](/zh-Hant/on-premises/configuration/overleaf-toolkit/public-access#page-access  "mention")：讓未登入的訪問者瀏覽 `/learn`、`/templates` 與 `/devs` 等頁面
* [公開註冊](/zh-Hant/on-premises/configuration/overleaf-toolkit/public-access#public-registration  "mention")：讓使用者自行註冊，並可選擇搭配啟用電子郵件及限制於特定電子郵件網域

### 專案存取

<Info>

預設情況下，即使使用者取得專案分享連結，也必須先**登入**才能加入協作專案的編輯工作階段。

</Info>

若要允許匿名存取透過連結分享的專案，請設定下列兩個變數：

```dotenv title="config/variables.env"
OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING=true
OVERLEAF_ALLOW_PUBLIC_ACCESS=true
```

`OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` 可讓透過連結分享的專案允許匿名讀寫。

`OVERLEAF_ALLOW_PUBLIC_ACCESS` 可避免未經驗證的使用者被重新導向至登入頁面。

使用 `bin/up` 重新建立容器，接著在無痕視窗中開啟連結分享網址。

### 頁面存取

預設情況下（未設定 `OVERLEAF_ALLOW_PUBLIC_ACCESS`），除了登入與註冊頁面之外，**所有**頁面都會將未登入的訪問者重新導向至登入頁面。這也包括原本應公開的頁面，因此這些頁面的連結只對已登入的使用者有效。

設定 `OVERLEAF_ALLOW_PUBLIC_ACCESS=true` 後，未登入的訪問者可以開啟：

| 頁面                                                                  | 需求                         |
| --------------------------------------------------------------------- | -------------------------------- |
| 位於 `/learn` 的 LaTeX 說明（請參閱 [adding-latex-user-help.md](/zh-Hant/on-premises/configuration/overleaf-toolkit/adding-latex-user-help  "mention")） | `OVERLEAF_PROXY_LEARN=true`      |
| 位於 `/templates` 的範本庫、範本頁面、預覽與 ZIP 下載（請參閱 [templates.md](/zh-Hant/on-premises/configuration/overleaf-toolkit/templates  "mention")） | `OVERLEAF_TEMPLATE_GALLERY=true` |
| 位於 `/devs` 的 Overleaf Import API 頁面（請參閱 [overleaf-import-api.md](/zh-Hant/on-premises/configuration/overleaf-toolkit/overleaf-import-api  "mention")） | —                                |

它也讓 [Overleaf Import API](/zh-Hant/on-premises/configuration/overleaf-toolkit/overleaf-import-api#signed-out-visitors  "mention") 能保留未登入訪問者送出的表單，直到對方登入為止。

專案清單、編輯器與建立專案（包括從範本或透過 Import API 建立）仍需要登入。

### 公開註冊

公開註冊僅在 [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) 中提供。

<Danger>

請注意，一旦啟用公開註冊，**任何**能存取你 Overleaf 執行個體的人都可以註冊為使用者。

設為 `true` 時，註冊流程不會驗證電子郵件地址，因此請僅在內部網路或受信任的環境中使用，或改用[透過啟用電子郵件註冊](/zh-Hant/on-premises/configuration/overleaf-toolkit/public-access#registration-with-activation-email)。

在啟用 OIDC 的執行個體上，請勿使用 `true`：任何人都可以在同事首次 OIDC 登入之前，以該同事的電子郵件註冊，導致同事被連結至該帳號。請使用[透過啟用電子郵件註冊](/zh-Hant/on-premises/configuration/overleaf-toolkit/public-access#registration-with-activation-email)或不開放公開註冊，請參閱[帳號與密碼](/zh-Hant/on-premises/configuration/overleaf-toolkit/authentication#accounts-and-passwords)。

</Danger>

預設情況下，社群版與 Overleaf Pro 都不允許公開註冊。

若要啟用，請在 `config/variables.env` 中加入：

```dotenv title="config/variables.env"
OVERLEAF_ALLOW_PUBLIC_REGISTRATION=true
```

使用 `bin/up` 重新建立容器。

接著點選 **Sign up** 或前往 `/register`。

### 透過啟用電子郵件註冊

透過啟用電子郵件註冊僅在 [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) 中提供。使用者只需以電子郵件註冊，並透過啟用電子郵件中的連結設定密碼，因此只有該地址的擁有者能使用此帳號。網域清單與萬用字元需要 v6.4.0 或更新版本；較早的版本只接受單一網域，例如 `@example.com`。

啟用前，請先設定電子郵件寄送，否則使用者永遠收不到啟用電子郵件。請參閱[電子郵件寄送](/zh-Hant/on-premises/configuration/overleaf-toolkit/email-delivery)。

接著在 `config/variables.env` 中加入下列這行：

```dotenv title="config/variables.env" wrap
OVERLEAF_ALLOW_PUBLIC_REGISTRATION=@example.com,@*.example.org
```

`OVERLEAF_ALLOW_PUBLIC_REGISTRATION` 可設定為：

| 值                            | 誰可以註冊                                             | 驗證電子郵件 |
| ----------------------------- | ----------------------------------------------------- | :------------: |
| `true`                        | 任何人，使用電子郵件與密碼                             |       否       |
| `@example.com`                | `example.com` 的地址                                   |       是       |
| `@*.example.org`              | 子網域（例如 `cs.example.org`）的地址，不含 `example.org` 本身 |       是       |
| `@example.com,@*.example.org` | 列出的任一項目，以逗號分隔                             |       是       |
| `@*`                          | 任何人                                                 |       是       |

網域比對不區分大小寫。若要同時允許某網域及其子網域，請將兩者都列出：`@example.org,@*.example.org`。

### Q\&A

<Accordion title="未登入的編輯者可以對留言做什麼？">

<strong>回答：</strong>透過編輯連結開啟專案的未登入使用者，會獲得與編輯者相同的存取權限，但需要記錄操作者身分的動作除外：

| 動作 | 未登入的編輯者 |
| ------------------------------------------------- | ----------------: |
| 編輯文字、檢視留言與追蹤修訂 | 是 |
| 接受追蹤修訂、切換編輯模式 | 是 |
| 刪除留言或整個討論串 | 是 |
| 新增、回覆或編輯留言 | 否 |
| 解決或重新開啟留言 | 否 |

審閱面板仍會向他們顯示 **Resolve** 按鈕，但解決操作會失敗並顯示錯誤訊息。

透過檢視連結開啟專案的使用者完全看不到留言，請參閱[角色與權限](/zh-Hant/on-premises/user-and-project-management/roles-and-permissions#collaborating)。

</Accordion>
