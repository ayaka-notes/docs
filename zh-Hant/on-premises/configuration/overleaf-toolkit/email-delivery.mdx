---
title: 電子郵件傳送
icon: paper-plane-top
---

Overleaf 支援兩種寄送電子郵件的方式：簡易郵件傳輸協定（SMTP）與 [Amazon Simple Email Service（SES）](https://aws.amazon.com/ses/)。如果您的 localhost 上啟用了監聽本機連線的郵件伺服器，即可使用 SMTP。

## 設定

電子郵件透過以下環境變數進行設定。

#### 寄件者設定

| 名稱                          | 說明                                                                                                                                                 |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | <p>寄件者地址，例如 <a href="mailto:support@mycompany.com">`'support@mycompany.com'`</a><br /><br />- <strong>必填</strong>：是</p> |
| `OVERLEAF_EMAIL_REPLY_TO`     | 回覆地址，例如 `'noreply@mycompany.com'`                                                                                                             |

#### SMTP

| 名稱                                    | 說明                                                                                                                                                                                                                                                                     |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST`              | 要連線的主機名稱或 IP 位址。必須能從 Docker 容器存取                                                                                                                                                                                                                     |
| `OVERLEAF_EMAIL_SMTP_PORT`              | 要連線的連接埠                                                                                                                                                                                                                                                           |
| `OVERLEAF_EMAIL_SMTP_SECURE`            | 若為 `true`，連線至伺服器時會使用 TLS。若為 `false` 或未設定，則在伺服器支援 `STARTTLS` 擴充功能時使用 TLS。在大多數情況下，若連線至連接埠 `465`，請將此值設為 `true`；若為連接埠 `587` 或 `25`，請保持 `false` |
| `OVERLEAF_EMAIL_SMTP_USER`              | 用於向 SMTP 伺服器進行驗證的使用者名稱                                                                                                                                                                                                                                   |
| `OVERLEAF_EMAIL_SMTP_PASS`              | 與 SMTP 使用者名稱相關聯的密碼                                                                                                                                                                                                                                           |
| `OVERLEAF_EMAIL_SMTP_TLS_REJECT_UNAUTH` | 若為 `false`，將允許連線至使用自簽或無效 TLS 憑證的 TLS 伺服器                                                                                                                                                                                                           |
| `OVERLEAF_EMAIL_SMTP_IGNORE_TLS`        | 當此值為 `true` 且 `OVERLEAF_EMAIL_SMTP_SECURE` 為 `false` 時，即使伺服器支援 `STARTTLS` 擴充功能也不會使用 TLS                                                                                                                                                          |
| `OVERLEAF_EMAIL_SMTP_NAME`              | 選用，若 `OVERLEAF_EMAIL_SMTP_HOST` 設為 IP 位址，此主機名稱用於 TLS 驗證，預設為本機的主機名稱。                                                                                                                                                                        |
| `OVERLEAF_EMAIL_SMTP_LOGGER`            | 若為 `true`，會將日誌訊息輸出到 `web.log`。                                                                                                                                                                                                                              |

#### Amazon SES SMTP 介面

您可以在[這裡](https://docs.aws.amazon.com/ses/latest/dg/send-email-smtp.html)進一步了解如何使用 Amazon SES SMTP 介面寄送電子郵件。

| 名稱                       | 說明                                                                                       |
| -------------------------- | ------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST` | 要連線的主機名稱或 IP 位址。必須能從 Docker 容器存取                                       |
| `OVERLEAF_EMAIL_SMTP_PORT` | 要連線的連接埠                                                                             |
| `OVERLEAF_EMAIL_SMTP_USER` | 用於向 SMTP 伺服器進行驗證的使用者名稱                                                     |
| `OVERLEAF_EMAIL_SMTP_PASS` | 與 SMTP 使用者名稱相關聯的密碼                                                             |

#### Amazon SES API

您可以在[這裡](https://docs.aws.amazon.com/ses/latest/dg/send-email-api.html)進一步了解如何使用 Amazon SES API 寄送電子郵件。

| 名稱                                   | 說明                                        |
| -------------------------------------- | ------------------------------------------- |
| `OVERLEAF_EMAIL_AWS_SES_ACCESS_KEY_ID` | 若使用 AWS SES，此為存取金鑰                |
| `OVERLEAF_EMAIL_AWS_SES_SECRET_KEY`    | 若使用 AWS SES，此為秘密金鑰                |
| `OVERLEAF_EMAIL_AWS_SES_REGION`        | 若未設定，預設區域為 US-EAST-1              |

#### 搭配執行個體角色使用 AWS SES

| 名稱                    | 說明                                                                                                                             |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_DRIVER` | 當此值設為 `ses` 時，電子郵件系統將使用 SES API 方式，並依賴已設定的執行個體角色來寄送電子郵件。                                 |

#### 自訂

| 名稱                           | 說明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_CUSTOM_EMAIL_FOOTER` | <p>附加到所有電子郵件的自訂 HTML。例如：<br /><br /><strong>範例</strong>：`"<div>This system is run by department x </div> <div> If you have any questions please look at our faq <a href='`<a href="https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/https:/somwhere.com'%3Ehere&#x3C;/a%3E&#x3C;/div%3E">`https://somwhere.com'>here&#x3C;/a>&#x3C;/div>`</a>`"`</p> |
