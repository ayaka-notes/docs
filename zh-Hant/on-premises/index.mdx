### Overleaf 概覽

Overleaf 是一款深受研究人員與技術團隊喜愛的協作式 LaTeX 編輯器。其雲端版本可在 [overleaf.com](https://www.overleaf.com/) 使用，提供功能完整的線上 LaTeX 編輯器。然而，Overleaf Common（SaaS 版本）有許多功能限制，您還必須忍受 _**10 秒的編譯時間限制**_ 與昂貴的會員費用。

雖然 Overleaf 提供開放原始碼的社群版本（可在 [GitHub: Overleaf](https://github.com/overleaf/overleaf) 取得），但它也有許多限制，例如：

<Warning>

Overleaf Community Edition 適用於**所有**使用者都受信任的環境。由於無法使用沙箱編譯，Community Edition **不**適合需要隔離使用者的情境。

在沒有沙箱的情況下，LaTeX 編譯會以與容器相同的權限執行，因此可以存取其檔案系統、網路與環境變數。這會造成資料外洩或系統遭入侵的風險。非沙箱編譯只應在完全受信任的環境中使用；對於多使用者或正式環境部署，強烈建議使用沙箱編譯。

關於沙箱編譯的更多資訊，請參閱：[sandboxed-compiles.md](/zh-Hant/on-premises/configuration/overleaf-toolkit/sandboxed-compiles  "mention")

</Warning>

### Overleaf Server Pro 的資訊與價格

Overleaf 網站只提供聯絡 Server Pro 支援的入口，因此關於 Server Pro 的資訊非常有限。但根據我們在社群中蒐集到的資訊，**Server Pro 的報價為**：

* 您需要購買_至少_ 10 人的授權。
* 10 人授權的費用約為 €3,477.61。（2024 年）
* 教育方案中，20 位使用者每年 2640 歐元，50 位使用者 6050 歐元，100 位使用者 9963 歐元。
* Server Pro 僅在特定地區提供（例如不包括中國大陸）。

根據目前可取得的資訊，Overleaf Server Pro 的費用約為每位使用者每年 \$300，且至少需購買 10 份授權，是非常昂貴的選擇。此外，Server Pro 提供的功能遠少於 Ayakaleaf Pro。我們由衷感謝社群開發者多年來的貢獻，讓我們得以打造 Ayakaleaf Pro，並最終在功能與能力上超越 Overleaf Server Pro。

### 為什麼選擇 Ayakaleaf Pro？

<Info>

Ayakaleaf Pro 與 Overleaf, Inc. 或其母公司 Digital Science _**沒有**_任何關係。它也_不是_ Server Pro 版本（Server Pro 是 Overleaf, Inc. 提供的商業產品）。[ayaka-notes](https://github.com/ayaka-notes) 以獨立專案的形式開發並維護 Ayakaleaf Pro。

</Info>

Ayakaleaf Pro 是 Overleaf Community Edition 的增強實作，_**免費**_提供 Server Pro 的_**所有進階**_功能。與 [https://www.overleaf.com/](https://www.overleaf.com/) 上的 Overleaf Common 或商業版 Server Pro 不同，我們：

* 編譯時間_**沒有限制**_
* 使用者人數_**不需授權**_
* 解鎖 Server Pro 的_**所有功能**_
