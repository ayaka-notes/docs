[TeX Live](https://www.tug.org/texlive/) 是由 [TeX Users Group](https://www.tug.org/) 每年發布的自由軟體發行版。它提供了 LaTeX 套件、字型、TeX 引擎，以及在所有主流作業系統上支援以 LaTeX 排版所需的眾多軟體工具。

TeX Live 是 Overleaf 的重要元件，因為我們的伺服器使用它來編譯你的 LaTeX 程式碼，並產生即時 PDF 預覽。它也讓 Overleaf 使用者能輕鬆使用每個 TeX Live 版本中所包含的 5,000 多個 LaTeX 套件。

你並不受限於只能使用最新版本的 TeX Live 來編譯專案，因為 Overleaf 的伺服器也提供先前的 TeX Live 版本。專案可以輕鬆切換為使用較早版本的 TeX Live——例如在遇到套件相容性問題時。<br />
