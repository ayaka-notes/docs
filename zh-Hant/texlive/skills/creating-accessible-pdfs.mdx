隨著時間推移，PDF 建立功能的持續更新已讓 PDF 無障礙成為可能。包括 [LaTeX Tagging Project](https://latex3.github.io/tagging-project/documentation/) 在內的各項進展，也讓以 LaTeX 產生的 PDF 能夠具備無障礙特性，而且改進仍在持續進行中。

<Check>

特別是 [TeX Live 2025](https://www.overleaf.com/blog/tex-live-2025-is-now-available) 的發布，讓這個流程得以在 Overleaf 中實現。請注意，使用 MathML 時建議使用 **LuaLaTeX** 編譯器。

您可以了解如何[變更編譯器與 TeX Live 版本](https://docs.overleaf.com/getting-started/recompiling-your-project/selecting-a-tex-live-version-and-latex-compiler)，以確保您的專案設定正確。

</Check>

我們的做法主要參考 LaTeX Project 的[無障礙 PDF 說明](https://latex3.github.io/tagging-project/documentation/usage-instructions)，您可以參閱該說明以了解以下主題的更多細節。

<Warning>

請注意，實施這些做法並不保證您專案中的每個元素都具備無障礙特性——詳細資訊請參閱本頁的常見問題章節。

</Warning>

### <Icon icon="tag" /> 標記

本質上，PDF 標記（tagging）是一個自動建立「結構」的過程，這個結構能輕易被螢幕閱讀器辨識，並且無論現在或未來都更易於搜尋。它會利用您 LaTeX 程式碼中已定義的結構，讓螢幕閱讀器能夠區分標題、內文、圖片與方程式等元素。

TeX Live 2025 透過 `\DocumentMetaData` 宣告完整支援自動 PDF 標記。請將此宣告加在 `\documentclass` 之前。此宣告中有兩個影響標記功能的重要鍵：`tagging` 與 `tagging-setup`。

#### **`tagging`**

將 `tagging` 鍵設為 `on`，以確保啟用標記功能。

```latex wrap expandable
\DocumentMetadata{tagging=on}
```

#### **`tagging-setup`**

變更 `tagging-setup` 鍵的值，以設定文件的標記方式。

```latex wrap expandable
\DocumentMetadata{tagging=on,tagging-setup={math/setup=mathml-SE}}
```

<Info>

在此範例中，我們使用 \`math/setup=mathml-SE\` 進行 MathML 結構元素標記，但它可以設為 \[\`\tagpdfsetup\`]\(https://ctan.math.washington.edu/tex-archive/macros/latex/contrib/tagpdf/tagpdf.pdf) 所支援的任何值。

</Info>

### <Icon icon="text-size" /> 描述

除了自動標記之外，您可能還需要為元素的內容加上描述，特別是當您的文件包含圖片和／或表格時。

#### <Icon icon="image" /> 圖片

在 Overleaf 中為圖片加上重要的描述很簡單，這也有助於在參考 LaTeX 程式碼時理解特定圖片的情境。您只需在每個 `\includegraphics` 中加入對應的圖片描述選項即可。就無障礙而言，主要需區分三種圖片類型：需要替代（alt）文字的圖片、裝飾性元素（artifact），以及對應實際文字的圖片。

**替代文字**

為圖片加上替代文字，可確保圖片具有描述，作為視覺內容的文字替代。請使用 `alt` 鍵並輸入文字值。

```latex title="Alt text example" wrap
\includegraphics[width=0.25\linewidth,alt={Macro photo of a green frog's head and hands}]{frog.jpg}
```

**裝飾性元素**

如果圖片不需要被螢幕閱讀器讀取（亦即純粹作為裝飾），請將其標記為裝飾性元素（artifact）。請使用 `artifact` 鍵，不需指定值。

```latex title="Artifact example" wrap
\includegraphics[artifact]{.jpg}
```

**實際文字**

如果圖片僅僅是一個 Unicode 字元的圖像，請加入該字元的文字形式。請使用 `actualtext` 鍵，並指定單一字元（不加括號）。

```latex title="Actual text example" wrap
\includegraphics[actualtext=B]{.jpg}
```

#### <Icon icon="table" /> 表格

雖然表格通常帶有文字，但確保文字與表格的正確部分相關聯仍然很重要。請在 `tabular` 之前或導言區加入 `\tagpdfsetup`，開始設定您 Overleaf 專案中的表格。就無障礙而言，主要需區分兩種表格類型：資料表格與版面表格。

**資料表格**

如果表格至少有一列標題列，請指定哪些列是標題列。請使用 `table/header-rows` 鍵，並輸入一系列對應標題列位置的數字。

```latex title="Data table example"
\tagpdfsetup{table/header-rows={1}}
\begin{tabular}{l|r}
Item & Quantity \\\hline
Widgets & 42 \\
Gadgets & 13
\end{tabular}
```

**版面表格**

如果表格不應被螢幕閱讀器解讀為表格，請將其標記為版面表格（presentation table）。請使用 `table/tagging=presentation` 鍵。

```latex title="Presentation table example"
\tagpdfsetup{table/tagging=presentation}
\begin{tabular}{cc}
\textbullet & \textbullet \\
''' & '''
\end{tabular}
```

### <Icon icon="comments-question" /> 常見問題

<Accordion title="有沒有工具可以協助驗證我的文件是否具備無障礙特性？">

有的，有多種外部工具可以使用，包括 [veraPDF](https://verapdf.org/)，可用於驗證 PDF/A 的部分與符合等級。此外，您可以使用 [WebAIM](https://webaim.org/) 等工具計算兩種顏色之間的對比度。

</Accordion>

<Accordion title="我 Overleaf 專案中的套件與這些功能相容嗎？">

您可以參閱 LaTeX Tagging Project 的[套件狀態清單](https://latex3.github.io/tagging-project/tagging-status/)。

</Accordion>

<Accordion title="我還能使用 `beamer` 嗎？有其他可用於簡報的套件嗎？">

使用 `beamer` 有一些限制；請參考實驗性的 [`ltx-talk` 文件類別](https://ctan.org/pkg/ltx-talk)。

</Accordion>

<Accordion title="Overleaf 編輯器具備無障礙特性嗎？">

是的。作為一個 Web 應用程式，Overleaf 運用了現代網頁瀏覽器的無障礙特性與功能，而這些瀏覽器會定期由無障礙專家進行評估。我們最新完成的[自願性產品無障礙範本（VPAT）](https://www.overleaf.com/for/customers/vpat)顯示其符合網頁內容無障礙指引（WCAG）2.2 AA 等級。

</Accordion>

<Accordion title="Overleaf 產生的 PDF 能否滿足美國身心障礙者法案（ADA）第二章與歐洲無障礙協調標準（EN 301 549）的要求？">

可以。美國與歐洲的法規要求 PDF 須符合 WCAG 2.1 AA。若要符合 WCAG 2.1 AA，PDF 必須是已標記的 PDF。TeX Live 2025 已提供 PDF 標記支援。

</Accordion>

<Accordion title="Overleaf 產生的 PDF 能否符合 PDF/UA-1 標準？">

可以。LaTeX Project 的 Tagging Project 正是專為產生 PDF/UA-1（以及即將推出的 PDF/UA-2）所需的結構標記而設計。如果使用者遵循 LaTeX Project 目前的標記建議，實際上就是在建立一份「PDF/UA-ready」的文件，這是滿足美國與歐洲法規所要求之 WCAG 2.1 AA 法定規範最有力的方式。

</Accordion>

<Accordion title="如何將編譯器切換為 LuaLaTeX？">

切換為 LuaLaTeX 很容易，這是 LaTeX 標記專案團隊所推薦的 LaTeX 編譯引擎。雖然 Overleaf 的預設編譯器是 PDFLaTeX，但您可以[在專案設定中切換為 LuaLaTeX](https://docs.overleaf.com/getting-started/recompiling-your-project/selecting-a-tex-live-version-and-latex-compiler)。

</Accordion>

<Accordion title="我可以在哪裡選擇最新版本的 TeX Live？">

您可以在 [Overleaf Labs](https://www.overleaf.com/labs/participate) 中取得最新版本，它提供 Overleaf 中「rolling TeX Live」映像檔的存取權，包括最新的 PDF 標記支援。這個實驗性的 TeX Live 版本主要用於測試 TeX Live 與套件的變更，以及在新的無障礙功能納入我們年度 TeX Live 發行版之前搶先預覽。

大部分 PDF 標記功能都已包含在標準的 [TeX Live 2025](https://www.overleaf.com/blog/tex-live-2025-is-now-available) 映像檔中。

</Accordion>
