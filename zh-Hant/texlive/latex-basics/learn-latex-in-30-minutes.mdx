## 什麼是 LaTeX？

LaTeX（讀作「_LAY_-tek」或「_LAH_-tek」）是一套用來排版出專業外觀文件的工具。不過，LaTeX 的運作方式與你可能用過的許多其他文書處理應用程式（例如 Microsoft Word 或 LibreOffice Writer）大不相同：那些「[所見即所得（WYSIWYG）](https://en.wikipedia.org/wiki/WYSIWYG)」工具為使用者提供一個互動式頁面，讓使用者在其中輸入、編輯文字並套用各種樣式。LaTeX 的運作方式則截然不同：你的文件是一個純文字檔案，其中穿插著用來表達預期（排版）結果的 LaTeX _指令_。為了產生可見的排版文件，你的 LaTeX 檔案會交由一個稱為 _TeX 引擎_的軟體處理，該引擎會依據嵌入在文字檔中的指令來引導與控制排版流程，將 LaTeX 指令與文件文字轉換成經過專業排版的 PDF 檔案。這意味著你只需要專注於文件的_內容_，而電腦會透過 LaTeX 指令與 TeX 引擎處理_視覺外觀_（格式）。

## 為什麼要學 LaTeX？

對於是否該學習使用 LaTeX 而非其他文件撰寫應用程式，有各種支持或反對的論點；但說到底，這是一個依據個人偏好、喜好以及文件需求所做的個人選擇。

支持 LaTeX 的論點包括：

* 支援排版極為複雜的數學式、表格，以及自然科學領域的技術內容；
* 提供註腳、交叉引用與參考文獻管理功能；
* 能輕鬆產生複雜或繁瑣的文件元素，例如索引、詞彙表、目錄、圖表目錄；
* 由於其本身的可程式化特性，加上數千個[免費附加套件](https://www.ctan.org/pkg)所提供的擴充性，能高度自訂以製作量身打造的文件。

整體而言，LaTeX 讓使用者能高度掌控文件的製作，並以極高的標準進行排版。當然，也有一些文件或出版品類型並非 LaTeX 的強項，包括許多雜誌類出版品中常見的「自由版面」頁面設計。

LaTeX 的一大重要優點是將文件內容與文件樣式分離：一旦你寫好文件的內容，就能輕鬆改變其外觀。同樣地，你可以建立一個定義特定文件類型版面／樣式的 LaTeX 檔案，並將該檔案作為_範本_，用來標準化同類型其他文件的撰寫與製作；例如，這讓科學出版商能以 LaTeX 建立論文範本，供作者撰寫投稿至期刊的論文。Overleaf 擁有一個[包含數千個範本的範本庫](https://www.overleaf.com/gallery)，涵蓋各式各樣的文件類型——從科學論文、報告、書籍到履歷與簡報，應有盡有。由於這些範本已定義好文件的版面與樣式，作者只需在 Overleaf 中開啟範本（建立新專案），即可開始撰寫並加入自己的內容。

## 撰寫你的第一段 LaTeX

第一步是建立一個新的 LaTeX 專案。你可以在自己的電腦上建立一個新的 `.tex` 檔案；或者，也可以在 Overleaf 中開始一個新專案。

讓我們從最簡單的可運作範例開始，此範例可以直接在 Overleaf 中開啟：

```latex
\documentclass{article}
\begin{document}
First document. This is a simple example, with no 
extra parameters or packages included.
\end{document}
```

[在 Overleaf 中開啟此範例。](https://www.overleaf.com/docs?engine=pdflatex&snip%5Fname=Simplest+working+example+LaTeX+document&snip=%5Cdocumentclass%7Barticle%7D%0A%5Cbegin%7Bdocument%7D%0AFirst+document.+This+is+a+simple+example%2C+with+no+%0Aextra+parameters+or+packages+included.%0A%5Cend%7Bdocument%7D)

此範例會產生以下輸出：

你可以看到 LaTeX 已自動將段落的第一行縮排，替你處理好了這項格式。讓我們仔細看看程式碼的每個部分各有什麼作用。

第一行程式碼 `\documentclass{article}` 宣告了文件的類型，也就是所謂的_文件類別（class）_，它控制文件的整體外觀。不同類型的文件需要不同的類別；例如，履歷所需的類別會與科學論文不同，後者可能使用標準的 LaTeX `article` 類別。你可能處理的其他類型文件，也可能需要 `book` 或 `report` 等不同的類別。若想了解有哪些眾多可用的 LaTeX 類別，請[造訪 CTAN（Comprehensive TeX Archive Network）上的相關頁面](https://www.ctan.org/topic/class)。

設定好文件類別後，我們的內容（也就是文件的_本文（body）_）會寫在 `\begin{document}` 與 `\end{document}` 標籤之間。開啟上述範例後，你可以修改文字，完成後透過_重新編譯文件_來檢視排版後的 PDF。在 Overleaf 中，只要按下 **Recompile** 即可，如下方簡短影片所示：

了解如何在文件中加入內容後，下一步是為文件加上標題。為此，我們必須先簡單談談**導言區（preamble）**。

## 文件的導言區

上方的螢幕截圖顯示 Overleaf 將 LaTeX 文件儲存為名為 `main.tex` 的檔案：依照慣例，包含文件 LaTeX 程式碼的檔案會使用 `.tex` 副檔名。

前一個範例示範了文件內容如何輸入在 `\begin{document}` 指令之後；而 `.tex` 檔案中出現在該處_之前_的所有內容都稱為_導言區（preamble）_，它扮演著文件「設定」區段的角色。在導言區中，你會定義文件類別（類型），以及撰寫文件時要使用的語言等細節；載入你想使用的_套件_（[稍後](/zh-Hant/texlive/latex-basics/learn-latex-in-30-minutes#Finding%5Fand%5Fusing%5FLaTeX%5Fpackages)會有更多說明），也會在這裡套用其他類型的設定。

一個最精簡的文件導言區可能如下所示：

```latex
\documentclass[12pt, letterpaper]{article}
\usepackage{graphicx}
```

其中 `\documentclass[12pt, letterpaper]{article}` 定義了文件的整體類別（類型）。額外的參數必須以逗號分隔，並放在方括號（`[...]`）中，用來設定此 article 類別的實例；也就是我們希望這份以 `article` 類別為基礎的文件所使用的設定。

在此範例中，這兩個參數的作用如下：

* `12pt` 設定字型大小
* `letterpaper` 設定紙張大小

當然，也可以使用其他字型大小，例如 `9pt`、`11pt`、`12pt`；但若未指定，預設大小為 `10pt`。至於紙張大小，其他可用的值有 `a4paper` 與 `legalpaper`。詳細資訊請參閱有關頁面大小與邊界的文章。

導言區中的這一行

```latex
\usepackage{graphicx}
```

是載入外部套件（此處為 [graphicx](https://ctan.org/pkg/graphicx?lang=en)）以擴充 LaTeX 功能的範例，讓 LaTeX 能夠匯入外部圖形檔案。LaTeX 套件會在[尋找與使用 LaTeX 套件](/zh-Hant/texlive/latex-basics/learn-latex-in-30-minutes#Finding%5Fand%5Fusing%5FLaTeX%5Fpackages)一節中討論。

## 加入標題、作者與日期資訊

若要為文件加入標題、作者與日期，需要在_導言區_（_而非_文件本文）中再加入三行。這三行分別是：

* `\title{My first LaTeX document}`：文件標題
* `\author{Hubert Farnsworth}`：在此寫下作者姓名，並可選擇在大括號內使用 `\thanks` 指令：
  * `\thanks{Funded by the Overleaf team.}`：可以加在 `author` 指令大括號內的作者姓名之後。它會加上一個上標，以及一個內容為大括號內文字的註腳。如果你需要在論文中感謝某個機構，這會很有用。
* `\date{August 2022}`：你可以手動輸入日期，或使用 `\today` 指令，在每次編譯文件時排版出當天的日期

加入這幾行後，你的導言區看起來應該會像這樣：

```latex
\documentclass[12pt, letterpaper]{article}
\title{My first LaTeX document}
\author{Hubert Farnsworth\thanks{Funded by the Overleaf team.}}
\date{August 2022}
```

若要排版標題、作者與日期，請在文件的_本文_中使用 `\maketitle` 指令：

```latex
\begin{document}
\maketitle
We have now added a title, author and date to our first \LaTeX{} document!
\end{document}
```

現在可以將導言區與本文合併，產生一份可以在 Overleaf 中開啟的完整文件：

```latex
\documentclass[12pt, letterpaper]{article}
\title{My first LaTeX document}
\author{Hubert Farnsworth\thanks{Funded by the Overleaf team.}}
\date{August 2022}
\begin{document}
\maketitle
We have now added a title, author and date to our first \LaTeX{} document!
\end{document}
```

## 加入註解

LaTeX 是一種「程式碼」，只不過專門用於文件排版；因此，就像以任何其他程式語言撰寫的程式碼一樣，在文件中加入註解會非常有用。LaTeX 註解是一段不會被排版、也不會以任何方式影響文件的文字——常用於加入「待辦」備註、加入說明性的備註、為複雜的巨集提供行內解釋，或在偵錯時將幾行／幾段 LaTeX 程式碼註解掉。

若要在 LaTeX 中建立註解，只要在該行開頭寫上 `%` 符號即可，如下方以前述範例為基礎的程式碼所示：

```latex
\documentclass[12pt, letterpaper]{article}
\title{My first LaTeX document}
\author{Hubert Farnsworth\thanks{Funded by the Overleaf team.}}
\date{August 2022}
\begin{document}
\maketitle
We have now added a title, author and date to our first \LaTeX{} document!

% This line here is a comment. It will not be typeset in the document.
\end{document}
```

[在 Overleaf 中開啟此範例。](https://www.overleaf.com/docs?engine=pdflatex&snip%5Fname=My+first+LaTeX+document+with+a+comment&snip=%5Cdocumentclass%5B12pt%2C+letterpaper%5D%7Barticle%7D%0A%5Ctitle%7BMy+first+LaTeX+document%7D%0A%5Cauthor%7BHubert+Farnsworth%5Cthanks%7BFunded+by+the+Overleaf+team.%7D%7D%0A%5Cdate%7BAugust+2022%7D%0A%5Cbegin%7Bdocument%7D%0A%5Cmaketitle%0AWe+have+now+added+a+title%2C+author+and+date+to+our+first+%5CLaTeX%7B%7D+document%21%0A%0A%25+This+line+here+is+a+comment.+It+will+not+be+typeset+in+the+document.%0A%5Cend%7Bdocument%7D)

此範例產生的輸出，與先前不含註解的 LaTeX 程式碼完全相同。

## 粗體、斜體與底線

接下來，我們來看看一些文字格式指令：

* **粗體**：在 LaTeX 中，粗體文字使用 `\textbf{...}` 指令排版。
* _斜體_：斜體文字使用 `\textit{...}` 指令產生。
* 底線：若要為文字加上底線，請使用 `\underline{...}` 指令。

下一個範例示範了這些指令：

```latex
Some of the \textbf{greatest}
discoveries in \underline{science} 
were made by \textbf{\textit{accident}}.
```

[在 Overleaf 中開啟此範例。](https://www.overleaf.com/docs?engine=pdflatex&snip%5Fname=First+example+with+formatted+text&snip=%5Cdocumentclass%5B12pt%2C+letterpaper%5D%7Barticle%7D%0A%5Ctitle%7BMy+first+LaTeX+document%7D%0A%5Cauthor%7BHubert+Farnsworth%5Cthanks%7BFunded+by+the+Overleaf+team.%7D%7D%0A%5Cdate%7BAugust+2022%7D%0A%5Cbegin%7Bdocument%7D%0A%5Cmaketitle%0ASome+of+the+%5Ctextbf%7Bgreatest%7D%0Adiscoveries+in+%5Cunderline%7Bscience%7D+%0Awere+made+by+%5Ctextbf%7B%5Ctextit%7Baccident%7D%7D.%0A%5Cend%7Bdocument%7D)

另一個非常實用的指令是 `\emph{_argument_}`，它對 `_argument_` 的效果取決於上下文。在一般文字中，強調的文字會以斜體呈現；但如果在斜體文字中使用，此行為就會反轉——請看下一個範例：

```latex

were made by accident.

\textit{Some of the greatest \emph{discoveries}

\textbf{Some of the greatest \emph{discoveries}
```

## 加入圖片

在本節中，我們將說明如何在 LaTeX 文件中加入圖片。Overleaf 支援三種插入圖片的方式：

1. 使用位於編輯器工具列上的 [**Insert Figure** 按鈕](https://learn.overleaf.com/learn/Kb/How_to_insert_figures_in_Overleaf#Using%5FInsert%5FFigure%5Fto%5Fadd%5Fa%5Ffigure%5Fto%5Fyour%5Fproject)（![編輯器工具列上的 Insert Figure 按鈕](https://sharelatex-wiki-cdn-671420.cdn77.org/learn-scripts/images/a/a8/InsertFigureButton.png)），將圖片插入 **Visual Editor** 或 **Code Editor**。
2. 將圖片複製並貼上至 **Visual Editor** 或 **Code Editor**。
3. 使用 **Code Editor** 撰寫插入圖形的 LaTeX 程式碼。

方式 1 與 2 會自動產生插入圖片所需的 LaTeX 程式碼，而這裡我們要介紹的是方式 3——請注意，你需要先將這些圖片[上傳](https://docs.overleaf.com/writing-and-editing/inserting-images)到你的 Overleaf 專案中。以下範例示範如何加入一張圖片：

```latex
\documentclass{article}
\usepackage{graphicx} %LaTeX package to import graphics
\graphicspath{{images/}} %configuring the graphicx package
 
\begin{document}
The universe is immense and it seems to be homogeneous, 
on a large scale, everywhere we look.

% The \includegraphics command is 
% provided (implemented) by the 
% graphicx package
\includegraphics{universe}  
 
There's a picture of a galaxy above.
\end{document}
```

[在 Overleaf 中開啟此圖片範例。](https://www.overleaf.com/project/new/template/25686?id=107971142&templateName=Example+using+images+in+LaTeX&latexEngine=pdflatex&texImage=texlive-full%3A2022.1&mainFile=)

此範例會產生以下輸出：

![顯示匯入 LaTeX 文件之圖片的圖形](https://images.ctfassets.net/nrgyaltdicpt/4p5toat08FUgehv4yuNwXS/efc9e75e4342c9caeec94f26627fa337/LL30Fig5v2-plain.svg)

將圖形匯入 LaTeX 文件需要一個[附加_套件_](/zh-Hant/texlive/latex-basics/learn-latex-in-30-minutes#Finding%5Fand%5Fusing%5FLaTeX%5Fpackages)，它提供引入外部圖形檔案所需的指令與功能。上述範例載入了 [graphicx 套件](https://ctan.org/pkg/graphicx?lang=en)，它提供了許多指令，其中包括用來匯入圖形的 `\includegraphics{...}`，以及用來告知 LaTeX 圖形所在位置的 `\graphicspath{...}`。

若要使用 `graphicx` 套件，請在 Overleaf 文件的導言區中加入以下這一行：

```latex
\usepackage{graphicx}
```

在我們的範例中，指令 `\graphicspath{{images/}}` 告訴 LaTeX，圖片存放在目前目錄下名為 `images` 的資料夾中：

![顯示 LaTeX 存取資料夾中圖片的示意圖](https://sharelatex-wiki-cdn-671420.cdn77.org/learn-scripts/images/1/17/ImagesInAFolder.png)

`\includegraphics{universe}` 指令負責實際將圖片插入文件中。這裡的 `universe` 是不含副檔名的圖片檔案名稱。

**注意**：

* 雖然 `\includegraphics` 指令允許使用包含副檔名的完整檔名，但最佳做法是省略副檔名，因為這樣會讓 LaTeX 搜尋所有支援的格式。
* 一般而言，圖形的檔名不應包含空白或多個句點；此外，將圖片檔案上傳至 Overleaf 時，也建議副檔名使用小寫字母。

更多關於 LaTeX 套件的資訊，請參閱本教學最後的[尋找與使用 LaTeX 套件](/zh-Hant/texlive/latex-basics/learn-latex-in-30-minutes#Finding%5Fand%5Fusing%5FLaTeX%5Fpackages)一節。

## 圖說、標籤與參照

可以透過 `figure` 環境為圖片加上圖說、標籤與參照，如下所示：

```latex
\documentclass{article}
\usepackage{graphicx}
\graphicspath{{images/}}
 
\begin{document}

\begin{figure}[h]
    \centering
    \includegraphics[width=0.75\textwidth]{mesh}
    \caption{A nice plot.}
    \label{fig:mesh1}
\end{figure}
```

## 在 LaTeX 中建立清單

你可以使用_環境（environment）_建立不同類型的清單；環境用來封裝實作特定排版功能所需的 LaTeX 程式碼。環境以 `\begin{_environment-name_}` 開始，並以 `\end{_environment-name_}` 結束，其中 `_environment-name_` 可以是 `figure`、`tabular`，或是其中一種清單類型：用於無序清單的 `itemize`，或用於有序清單的 `enumerate`。

### 無序清單

無序清單由 `itemize` 環境產生。每個清單項目前面都必須加上 `\item` 指令，如下所示：

```latex
\documentclass{article}
\begin{document}
\begin{itemize}
  \item The individual entries are indicated with a black dot, a so-called bullet.
  \item The text in the entries may be of any length.
\end{itemize}
\end{document}
```

## 在 LaTeX 中加入數學式

LaTeX 的主要優點之一，就是能輕鬆撰寫數學式。LaTeX 提供兩種排版數學的撰寫模式：

* _行內（inline）_數學模式，用於撰寫屬於段落一部分的公式
* _展示（display）_數學模式，用於撰寫不屬於文字或段落一部分、而是排版在獨立行上的數學式

### 行內數學模式

讓我們來看一個行內數學模式的範例：

```latex
\documentclass[12pt, letterpaper]{article}
\begin{document}
In physics, the mass-energy equivalence is stated 
by the equation $E=mc^2$, discovered in 1905 by Albert Einstein.
\end{document}
```

較長的文件，無論使用何種撰寫軟體，通常都會劃分為部、章、節、小節等。LaTeX 也提供了文件結構指令，但可用的指令及其實作方式（它們的作用）可能會因所使用的文件類別而異。舉例來說，使用 `book` 類別建立的文件可以劃分為部、章、節、小節等，但 `letter` 類別則不提供（不支援）任何這類指令。

下一個範例示範用來建構以 `book` 類別為基礎之文件結構的指令：

```latex
\documentclass{book}
\begin{document}

\chapter{First Chapter}

\section{Introduction}

This is the first section.

Lorem  ipsum  dolor  sit  amet,  consectetuer  adipiscing  
elit. Etiam  lobortisfacilisis sem.  Nullam nec mi et 
neque pharetra sollicitudin.  Praesent imperdietmi nec ante. 
Donec ullamcorper, felis non sodales...

\section{Second Section}

Lorem ipsum dolor sit amet, consectetuer adipiscing elit.  
Etiam lobortis facilisissem.  Nullam nec mi et neque pharetra 
sollicitudin.  Praesent imperdiet mi necante...

\subsection{First Subsection}
Praesent imperdietmi nec ante. Donec ullamcorper, felis non sodales...

\section*{Unnumbered Section}
Lorem ipsum dolor sit amet, consectetuer adipiscing elit.  
Etiam lobortis facilisissem...
\end{document}
```

章節指令的名稱大多一目了然；例如，`\chapter{First Chapter}` 會建立一個標題為 `First Chapter` 的新章，`\section{Introduction}` 會產生一個標題為 `Introduction` 的節，依此類推。節還可以進一步劃分為 `\subsection{...}`，甚至 `\subsubsection{...}`。節、小節等的編號是自動產生的，但可以使用相應指令的所謂_星號版本_來停用編號，也就是在指令結尾加上星號（\*），例如 `\section*{...}` 與 `\subsection*{...}`。

_整體而言_，LaTeX 文件類別提供以下章節指令，而各個類別分別支援其中相關的子集：

* `\part{part}`
* `\chapter{chapter}`
* `\section{section}`
* `\subsection{subsection}`
* `\subsubsection{subsubsection}`
* `\paragraph{paragraph}`
* `\subparagraph{subparagraph}`

### 加入框線

`tabular` 環境支援在表格中加入水平線與垂直線（框線）：

* 若要在列的上方與下方加入水平框線，請使用 `\hline` 指令
* 若要在欄與欄之間加入垂直框線，請使用垂直線參數 `|`

```latex
\begin{center}
\begin{tabular}{|c|c|c|}

 cell4 & cell5 & cell6 \\ 
 cell7 & cell8 & cell9 \\ 
 \hline
\end{tabular}
\end{center}
```

## 尋找與使用 LaTeX 套件

LaTeX 不僅提供強大的排版功能，還透過附加_套件_提供了一個_可擴充的框架_。LaTeX 並不試圖提供「包山包海」的指令與功能，而是被設計為_可擴充的_，讓使用者能載入外部程式碼（套件），以提供更專門的排版功能，或擴充 LaTeX 的內建功能——例如排版表格。如[加入圖片](/zh-Hant/texlive/latex-basics/learn-latex-in-30-minutes#Adding%5Fimages)一節中所見，`graphicx` 套件透過提供匯入圖形檔案的指令來擴充 LaTeX，而它是透過在導言區中寫入以下內容來載入的：

```latex
\usepackage{graphicx}
```

### 載入套件

如上所述，套件是透過 `\usepackage` 指令在文件導言區中載入的；但由於（許多）LaTeX 套件提供了一組可用來設定其行為的_選項_，因此 `\usepackage` 指令通常看起來像這樣：

```latex
\usepackage[options]{somepackage}
```

方括號「`[...]`」告訴 LaTeX 在載入 `somepackage` 時應套用哪一組選項。在使用者所要求的選項組中，個別選項或設定通常以逗號分隔；例如，[geometry 套件](https://ctan.org/pkg/geometry)提供許多用來設定 LaTeX 頁面版面的選項，因此 `geometry` 的典型用法可能如下所示：

```latex
\usepackage[total={6.5in,8.75in},
top=1.2in, left=0.9in, includefoot]{geometry}
```

`geometry` 套件是由全球 LaTeX 社群成員撰寫並貢獻、免費提供給任何想使用者的套件之一。

如果某個 LaTeX 套件不提供任何選項，或使用者想使用套件選項的預設值，則可以這樣載入：

```latex
\usepackage{somepackage}
```

當你寫下 `\usepackage[...]{somepackage}` 時，LaTeX 會尋找一個名為 `_somepackage_.sty` 的對應檔案，並需要載入及處理它——以便讓套件的指令可供使用，並執行該套件所提供的任何其他程式碼。如果 LaTeX 找不到 `_somepackage_.sty`，就會以錯誤終止，如下方 Overleaf 範例所示：

```latex
\documentclass[12pt, letterpaper]{article}
\usepackage{somepackage}% a NON-EXISTENT package
\begin{document}
This will fail!
\end{document}
```

### Overleaf 上可用的套件：認識 TeX Live

每年，CTAN 上託管的套件中會有一個（龐大的）_子集_，連同 LaTeX 相關字型與其他軟體，被彙整並以名為 [TeX Live](https://tug.org/texlive/) 的系統發布，你可以用它來安裝自己的（本機）LaTeX 環境。事實上，[Overleaf 的伺服器也使用 TeX Live](https://www.overleaf.com/learn/latex/Overleaf_and_TeX_Live)，並會在新版 TeX Live 發布時進行更新。Overleaf 的 TeX Live 更新並非立即進行，而是在發布數個月後才進行，讓我們有時間針對新版 TeX Live 與[範本庫中的數千個範本](https://www.overleaf.com/gallery)進行相容性測試。例如，這是我們的 [TeX Live 2025 升級公告](https://www.overleaf.com/blog/tex-live-2025-is-now-available)。

雖然 TeX Live 包含了 CTAN 套件中一個（龐大的）_子集_，但你仍可能找到一些有趣的套件——例如[用於排版圍棋棋譜的 igo](https://ctan.org/pkg/igo?lang=en)——它託管在 CTAN 上，卻未包含在 TeX Live 中（未由 TeX Live 散布），因此在 Overleaf 上無法使用。有些託管在 CTAN 上的套件未納入 TeX Live 的原因有很多：可能是套件已過時、有授權問題、非常新（最近才上傳），或具有平台相依性，例如只能在 Windows 而無法在 Linux 上運作。

新套件以及既有套件的更新，全年都會上傳至 CTAN，但 TeX Live 的更新則是每年發布一次；因此，目前版本的 TeX Live 中所包含的套件，不會像 CTAN 上託管的套件那樣新。由於 Overleaf 的伺服器使用 TeX Live，安裝在我們伺服器上的套件（也就是使用者可用的套件）可能並非 CTAN 上提供的最新版本，但一般而言，這不太可能造成問題。
