`projectAuditLogEntries` 是專案的稽核記錄：共用、邀請、擁有權轉移、下載以及管理員操作。一份文件是一個專案上的一個事件。由 `web` 負責；結構描述為 `services/web/app/src/models/ProjectAuditLogEntry.mjs`，核心程式碼透過 `services/web/app/src/Features/Project/ProjectAuditLogHandler.mjs` 寫入。

`tools/migrations/20220929193200_add_auditLog_indexes.mjs` 最初在 `{ projectId: 1 }` 上建立了 `project_id_1`；`20250912102601` 以複合索引取代它。由於 Mongoose 自動建立索引已關閉（`services/web/app/src/infrastructure/Mongoose.mjs:7`），結構描述中的 `index: true` 標記不會生效。`managedSubscriptionId` 的索引遷移只帶有 `saas` 標籤。

#### 說明 {#notes}

* 項目透過 TTL 索引在 `timestamp` 之後 2.5 年過期；專案的已刪除記錄過期時，該專案的所有項目也會一併刪除。
