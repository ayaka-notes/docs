`projects` 中每個專案對應一份文件：名稱、擁有者與成員、共用、檔案樹以及專案設定。文件的內文不在這裡（參見 [Docs 集合](/zh-Hant/dev/data-model/docs-collection)），二進位檔案則以其 `hash` 存放在 history-v1 的 blob 儲存空間中。Schema 為 `services/web/app/src/models/Project.mjs`，檔案樹定義在同目錄的 `Folder.mjs`、`File.mjs` 和 `Doc.mjs` 中。

在「來源」欄中，`Project.mjs:N` 表示該 schema 的某一行，其他不帶路徑的檔名位於 `services/web/app/src/Features/` 下，`modules/...` 位於 `services/web/` 下。行號取自撰寫時的 `server-pro`。

#### 說明 {#notes}

* Mongoose 的 `autoIndex` 已關閉（`services/web/app/src/infrastructure/Mongoose.mjs:7`）：schema 中的 `index` 選項之所以存在，只是因為上面的遷移會建立它們。
* 遷移 `20250620152657_ensure_collaborator_arrays` 會將缺少的 `collaberator_refs`、`pendingEditor_refs`、`pendingReviewer_refs`、`readOnly_refs` 和 `reviewer_refs` 設為 `[]`。
* 刪除專案會把文件移到 `deletedProjects`（參見 [Deleted Projects Collection](/dev/data-model/deleted-projects-collection)）。
