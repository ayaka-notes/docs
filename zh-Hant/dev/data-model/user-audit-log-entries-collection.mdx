`userAuditLogEntries` 是使用者帳號的稽核記錄：登入、密碼和電子郵件變更、連結的帳號以及管理員操作。一份文件是一個帳號上的一個事件。由 `web` 負責；結構描述為 `services/web/app/src/models/UserAuditLogEntry.mjs`，核心程式碼透過 `services/web/app/src/Features/User/UserAuditLogHandler.mjs` 寫入。

| 欄位 | 型別 | 意義 | 來源 |
| --- | --- | --- | --- |
| `_id` | ObjectId | 項目 id。 | `UserAuditLogEntry.mjs:4` |
| `userId` | ObjectId | 事件所涉及的帳號。 | `UserAuditLogEntry.mjs:6` |
| `operation` | String | 發生了什麼，為 kebab-case 名稱，例如 `login`（見下表）。 | `UserAuditLogEntry.mjs:11` |
