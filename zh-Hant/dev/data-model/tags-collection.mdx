`tags` 儲存使用者在專案儀表板上用來分類專案的標籤（資料夾）。一份文件是一位使用者的一個標籤。由 `web` 負責；結構描述為 `services/web/app/src/models/Tag.mjs`，所有寫入都經過 `services/web/app/src/Features/Tags/TagsHandler.mjs`。

#### 欄位 {#fields}

| 欄位 | 型別 | 意義 | 來源 |
| --- | --- | --- | --- |
| `_id` | ObjectId | 標籤 id，用於 `/tag/:tagId` 路由。 | `Tag.mjs:10` |
| `user_id` | String | 標籤的擁有者。由於歷史因素，這是一般字串，而不是 ObjectId。 | `Tag.mjs:7-12` |
| `name` | String | 標籤名稱，最多 50 個字元（`MAX_TAG_LENGTH`）。每位使用者內唯一。 | `Tag.mjs:13`, `TagsHandler.mjs:4` |
| `color` | String | 選用的顏色：類似 `#a1b2c3` 的十六進位碼，或 `hsl(<n>, 70%, 45%)` 值（`TAG_COLOR_REGEX`）。 | `Tag.mjs:5`, `Tag.mjs:14-22` |
| `project_ids` | Array of String | 此標籤中專案的 id，以字串儲存。 | `Tag.mjs:23` |
| `__v` | Number | Mongoose 版本鍵，在 `Tag.create` 建立文件時加入。 | `TagsHandler.mjs:27` |

#### 索引 {#indexes}

| 名稱 | 鍵 | 選項 | 遷移 |
| --- | --- | --- | --- |
| `user_id_1_name_1` | `{ user_id: 1, name: 1 }` | unique | `tools/migrations/20190912145029_create_tags_indexes.mjs` |

同一個遷移也建立了 `user_id_1`；由於複合索引已涵蓋它，`tools/migrations/20231031164732_drop_redundant_indexes.mjs` 會再次刪除它。

#### 說明 {#notes}

* 標籤依使用者區分：同一專案的兩位協作者各自保有自己的標籤。
* `user_id` 和 `project_ids` 是字串，因此請以字串 id 查詢，而不是 ObjectId。
* 刪除使用者（`services/web/app/src/Features/User/UserDeleter.mjs`）不會變動 `tags`。
