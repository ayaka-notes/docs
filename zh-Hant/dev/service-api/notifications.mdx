將在專案清單中顯示給使用者的通知（例如專案邀請）儲存在 Mongo 的 `notifications` 集合中。由 web 與 third-party-datastore 呼叫；它沒有驗證，只能在 Docker 網路內存取。

* <strong>位址：</strong> `http://notifications:3042`, 位於 Docker 網路內
* <strong>驗證：</strong>無
* <strong>OpenAPI 檔案：</strong> [`develop/hoppscotch/openapi/notifications.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/notifications.yaml)
