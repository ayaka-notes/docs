CLSI（Common LaTeX Service Interface）負責編譯專案，對編譯輸出執行 SyncTeX 與 texcount，並以 pandoc 轉換文件。由 web 呼叫；輸出檔案本身由 clsi-nginx 提供，而不是這個連接埠。沒有驗證：只能在 Docker 網路內存取。

* <strong>位址：</strong> `http://clsi:3013`, 位於 Docker 網路內
* <strong>驗證：</strong>無
* <strong>OpenAPI 檔案：</strong> [`develop/hoppscotch/openapi/clsi.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/clsi.yaml)
