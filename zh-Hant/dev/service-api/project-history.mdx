在 Redis 中為每個專案的編輯排入佇列，將其轉換為歷史變更並傳送給 history-v1；它也在 Mongo 中保存歷史標籤、重新同步狀態與失敗紀錄。由 web、document-updater、history-v1 與 server-ce 的 cron 指令碼呼叫；它沒有驗證。

* <strong>位址：</strong> `http://project-history:3054`, 位於 Docker 網路內
* <strong>驗證：</strong>無
* <strong>OpenAPI 檔案：</strong> [`develop/hoppscotch/openapi/project-history.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/project-history.yaml)
