為了節省時間並快速建置開發環境，我們提供了另一種開發環境設定方式，也就是 GitHub Codespace。

## 設定教學 {#configuration-tutorial}

<Steps>
<Step title="建立 Codespaces">
點擊下方按鈕，建立用於 server-pro 開發的雲端 codespace。

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/ayakaleaf-pro)

建議將 **Machine Type** 選擇為至少 **4-core**。若需要更大的機器規格，你可以在[這裡](https://support.github.com/contact?tags=rr-codespaces%2Ccat_codespaces)提交工單，向 GitHub 官方支援團隊提出申請。

<Frame>
  <img src="/images/dev/image.png" alt="" />
</Frame>
</Step>

<Step title="執行設定腳本">
你需要耐心等待 codespace 建立完成。當你可以使用終端機後，執行以下指令：

```text
cd develop/
bin/setup
bin/i18n
```

`bin/setup` 會拉取映像檔並啟動服務；接著 `bin/i18n` 會套用 Ayakaleaf Pro 模組的翻譯，這些翻譯不在已提交的語系檔中，請參閱 [更新 i18n 翻譯](/zh-Hant/dev/environment/update-i18n-translations)。

<Frame>
  <img src="/images/dev/image-1.png" alt="" />
</Frame>

<Warning>

此腳本（`bin/setup`）可讓你以最短的時間，在 `server-pro` 分支的最新 commit 上設定好開發環境。它可能不適用於較舊的版本或其他分支。

我們每天都會透過 [GitHub Action](https://github.com/ayaka-notes/ayakaleaf-pro/actions) 建置開發用的 Docker 映像檔。

</Warning>
</Step>

<Step title="存取你的 Launchpad">
切換到連接埠分頁，你會看到可用 Web 連接埠的清單。點選 `80` 連接埠（即 `develop/dev.rc` 中的 `OVERLEAF_PORT`），現在應該能看到 launchpad 頁面。Mailpit、Grafana、Mongo Express 和 RedisInsight 位於同一連接埠的路徑下（`/mailpit/`、`/grafana/`、`/mongo-express/` 和 `/redis-insight/`），登入後網站的 **Dev tools** 選單會連結到它們。RustFS 主控台在 9001 連接埠，Hoppscotch 在 9170 連接埠，請參閱 [連接埠](/zh-Hant/dev/environment/setup-develop-environment-local#ports)。

  <img src="/images/dev/image-2.png" alt="" />
</Frame>

你會看到：

</Frame>
</Step>

<Step title="享受開發">
現在，屬於你的時間到了！開始打造你的精彩功能吧。`bin/setup` 已經以開發模式啟動所有服務（`node --watch`，與 `bin/dev` 相同），因此程式碼變更無需額外指令即可生效。

修改 `develop/dev.rc` 後，請再次執行 `bin/setup`：它會透過 `bin/docker-compose` 執行，後者會加入已開啟功能的檔案。

<Warning>

不要手動使用 `docker compose -f docker-compose.yml -f docker-compose.dev.yml -f docker-compose.image.yml up` 啟動服務。該指令會略過 `dev.rc` 的功能檔案，因此 `web`、`filestore` 和 `history-v1` 會在沒有 RustFS 設定的情況下重新建立，並退回使用本機磁碟區，而本機磁碟區中沒有你專案的歷史記錄和二進位檔案。

</Warning>
</Step>
</Steps>
