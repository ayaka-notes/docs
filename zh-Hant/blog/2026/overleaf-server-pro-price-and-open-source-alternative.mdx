多年來，許多使用 Overleaf 社群版的人對 Overleaf Server Pro 表現出濃厚興趣，因為 Overleaf CE 的限制實在太多，例如：

* 沒有沙箱機制，LaTeX 編譯會以與容器相同的權限執行。
* 不支援切換 TeX Live 版本，每個版本都需要手動安裝。
* 沒有追蹤修訂功能，使協作撰寫與註解相當困難。
* 沒有 Git 整合，使本機 LaTeX 使用者難以加入協作專案。

然而，清楚可靠的價格資訊一直很難找到。在 Overleaf 的網站上，唯一的選項是聯絡業務。Server Pro 似乎無法由個人使用者直接購買。我們透過搜尋引擎找到了一些價格資訊。

根據我們在社群中蒐集到的資訊，**Server Pro 的報價為**：

* 你需要購買_至少_ 10 人的授權。
* 10 人授權約 €3,477.61（2024 年）。
* 教育機構方面，20 位使用者每年 2640 歐元，50 位使用者 6050 歐元，100 位使用者 9963 歐元。
* Server Pro 僅在特定地區提供（例如不含中國大陸）。

到了 2026 年，我們使用 ChatGPT Search 找出了更多購買過 Overleaf Server Pro 的組織。

Overleaf Server Pro 的費用約為每位使用者每年 \$300。較小型的美國合約顯示，每位使用者的年費約為 \$320–\$370。大型機構協議則可取得較低的單人價格。例如，馬克斯普朗克學會（Max Planck Society）的三年協議平均每位使用者每年約 €51。合約條款、支援與部署範圍可能有所不同。這些紀錄並非 Overleaf 官方價目表。

### 打造線上 LaTeX 編輯器？沒那麼簡單！

自 2026 年初以來，借助 Claude 或 Codex 等程式碼代理，幾乎每個月都會出現一個 Overleaf 替代品。OpenAI 也推出了 [Prism](https://prism.openai.com/)，一款用於科學 LaTeX 寫作的產品。

**打造一個可靠的線上 LaTeX 編輯器絕非易事。** 根據我們的觀察，Prism 會在開啟專案時配置一個沙箱並持續運作，這很可能是因為 Codex 一直在背景待命。如此一來，使用者開始 AI 對話時，Codex 便能快速回應。在我們的測試中，每個沙箱約配置 5 個 vCPU、6 GB 記憶體與 64 GB 磁碟空間。

當數千名使用者同時編輯 LaTeX 專案時，這種架構可能帶來可觀的運算開銷。Ayakaleaf 採取不同的做法：只有在請求編譯時才建立沙箱。每次編譯限制為 1 個 vCPU 與 1 GB 記憶體，編譯完成後沙箱即被終止。這大幅降低了常駐資源消耗，也讓大規模部署的容量規劃更加可預測。

更廣泛地說，Prism 說明了即使擁有強大的模型與成熟的開源軟體生態系，要將 AI 能力與可靠的線上開發環境結合起來仍然相當困難。AI 可以改善體驗，但無法取代紮實的系統工程。歸根究柢，使用者仰賴的是可靠、可預測且穩定的服務。

### 為什麼選擇 Ayakaleaf Pro？

**Ayakaleaf Pro** 是 Overleaf 社群版的分支，為自架部署帶來 Server Pro 等級與 SaaS 等級的功能——無需按使用者計費的授權。它與上游 Overleaf 程式碼庫保持同步，因此你能享有熟悉的編輯器與工作流程，外加：

* 沙箱化 LaTeX 編譯
* 多個 TeX Live 版本
* 追蹤修訂與註解
* Git 與 GitHub 整合
* SSO 與管理面板
* 私有範本管理
* Zotero 與進階參考文獻搜尋
* Pandoc 匯入／匯出
* Python 指令碼執行器
* 無按使用者計費的授權費用

我們的目標是提供更完整的自架 Overleaf 體驗——無需 Server Pro 授權或 SaaS 訂閱。Ayakaleaf Pro 保留熟悉的 Overleaf 工作流程與上游相容性，同時加入協作、管理、整合與安全編譯等功能。

### 我們為什麼總是在重新發明輪子？

有一個更廣泛的問題值得探討：_**當一個成熟的開源專案已經解決了大部分難題，為什麼人們的直覺往往是從頭重寫**_？

重新實作編輯器、即時協作層、編譯流程，以及多年來累積的各種邊界情況修正，成本極其高昂——而且其中大部分心力都花在重新發現原專案早已解決的問題上。在多數情況下，擴充一個穩固的基礎並將缺少的部分回饋上游，才是更務實的工程選擇。

我真正想談的是：

> _在 AI 時代，人們熱愛炫耀。_

「我打造了自己的 Overleaf」聽起來遠比「我為 Overleaf 加了一些功能」厲害得多——所以人們更喜歡講前者的故事。這也是為什麼似乎每個月都會冒出一個新的「AI LaTeX 編輯器」。

但實際上，這些靠 AI 輔助重寫的產品，遠遠比不上像 Overleaf 這樣經過十年真實環境淬煉所累積的可靠性與成熟度。給它們兩個月，它們就會像二月的聖誕玩具一樣被拋棄。相信我。
