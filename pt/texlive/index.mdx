O [TeX Live](https://www.tug.org/texlive/) é uma distribuição de software livre publicada anualmente pelo [TeX Users Group](https://www.tug.org/). Ele fornece os pacotes LaTeX, fontes, engines TeX e inúmeras ferramentas de software necessárias para suportar a composição tipográfica baseada em LaTeX em todos os sistemas operacionais padrão.

O TeX Live é um componente importante do Overleaf, pois nossos servidores o utilizam para compilar seu código LaTeX e gerar a pré-visualização do PDF em tempo real. Ele também oferece aos usuários do Overleaf acesso fácil a mais de 5.000 pacotes LaTeX contidos em cada versão do TeX Live.

Você não está restrito a usar a versão mais recente do TeX Live para compilar seus projetos, pois os servidores do Overleaf oferecem acesso a versões anteriores do TeX Live. Os projetos podem ser facilmente alterados para usar uma versão anterior do TeX Live — por exemplo, devido a problemas de compatibilidade de pacotes.<br />
