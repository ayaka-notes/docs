Temos o orgulho de anunciar o lançamento do Ayakaleaf Pro 6.2, o editor LaTeX online mais poderoso e completo da comunidade. Agradecimentos especiais a yu-i-i e davrot por suas valiosas contribuições. Eles aprimoraram o GitHub Sync e introduziram a Advanced Citation Search e a integração com o Zotero.

### Observações

* Foi introduzida uma nova variável de ambiente obrigatória, `OVERLEAF_INVITE_TOKEN_SECRET`; você deve gerá-la com: `openssl rand -base64 32` Se ela não estiver configurada, sua instância do Overleaf não iniciará.
* Se você habilitar o GitHub Sync, deverá configurar a variável de ambiente `GITHUB_TOKEN_CIPHER_PASSWORD`. Essa variável é necessária para criptografar com segurança os tokens de acesso do GitHub. Sem ela, sua instância do Overleaf não iniciará.
* Foi adicionada uma nova variável de ambiente `DEFAULT_LATEX_COMPILER` para definir o compilador padrão usado por novos projetos (pdflatex, latex, xelatex ou lualatex).
* O editor redesenhado agora é a única opção disponível.

### Alterações

Esta versão inclui as seguintes melhorias e novos recursos.

* `MAX_UPLOAD_SIZE` agora é configurável, em vez de limitado a **50 MB**.
* Corrigido um loop de reinicialização do contêiner quando as compilações em sandbox estavam desabilitadas.
* A exclusão de PATs no OAuth2 agora é restrita ao proprietário.
* Corrigido um problema de importação do LDAP.

Os recursos incluem:

* Adicionado um executor de Python baseado no navegador.
* Adicionado suporte ao Pandoc para importar e exportar Markdown, DOCX e outros formatos.
* Adicionado o GitHub Sync.
* Adicionadas traduções completas para chinês.
* Adicionada a integração com o Zotero.
* Adicionado `DEFAULT_LATEX_COMPILER`.

#### Recurso 01: GitHub Sync

Mantenha seus projetos LaTeX sincronizados com repositórios do GitHub para um fluxo de desenvolvimento contínuo. Envie e receba alterações diretamente do editor, colabore por meio de pull requests e integre-se a pipelines de CI/CD existentes. O controle de versão facilita o acompanhamento de revisões, a análise de alterações e a manutenção de documentos acadêmicos ou técnicos reproduzíveis.

Veja: [GitHub Synchronisation](/pt/on-premises/configuration/overleaf-toolkit/github-synchronisation  "mention").

#### Recurso 02: Importação/exportação com Pandoc

Importe documentos do Microsoft Word e Markdown como projetos LaTeX totalmente editáveis, ou exporte projetos LaTeX de volta para Markdown e DOCX com um único clique. Com tecnologia do Pandoc, este recurso permite uma interoperabilidade perfeita entre escrita acadêmica, edição colaborativa e fluxos de publicação, preservando a estrutura do documento tanto quanto possível.

Veja: [Pandoc Import and Export](/pt/on-premises/configuration/overleaf-toolkit/pandoc-import-and-export  "mention").

#### Recurso 03: Pesquisa avançada de referências

Pesquise e insira referências bibliográficas de várias bases de dados acadêmicas, com filtragem inteligente e suporte instantâneo a citações. Descubra artigos rapidamente, pré-visualize metadados e crie entradas BibTeX precisas sem alternar entre diferentes sites de pesquisa, melhorando significativamente a eficiência da revisão de literatura.

![imagem](https://github.com/user-attachments/assets/42e45b73-af4b-4d1f-81f4-9e116ba5d043)

#### Recurso 04: Executor de Python

Execute código Python diretamente no seu projeto sem sair do editor. Ideal para gerar figuras, processar conjuntos de dados, automatizar fluxos de documentos ou executar scripts de pesquisa reproduzíveis. Os resultados podem ser integrados aos seus documentos LaTeX, tornando a computação científica e a escrita parte de um fluxo de trabalho unificado.

![imagem](https://github.com/user-attachments/assets/a4c314b3-fdb5-4836-aea7-12eeece5cd2f)

#### Recurso 05: Zotero

Conecte sua biblioteca do Zotero diretamente ao seu fluxo de escrita e gerencie referências sem sair do editor. Pesquise suas coleções pessoais do Zotero, insira citações com um único clique e gere e sincronize automaticamente entradas BibTeX. Essa integração mantém sua bibliografia atualizada, simplificando o gerenciamento de literatura para artigos acadêmicos, teses e documentos técnicos.

Veja: [Zotero Integration](/pt/on-premises/configuration/overleaf-toolkit/zotero-integration  "mention").
