---
title: Coleção Project History Labels
icon: tag
---

`projectHistoryLabels` guarda os rótulos que os usuários colocam em versões na visualização Histórico, um documento por rótulo. O project-history é o dono e a escreve em `services/project-history/app/js/LabelsManager.js`; não há schema Mongoose. O web só a acessa pela API do project-history.

#### Campos {#fields}

| Campo | Tipo | Significado | Origem |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Id do rótulo. | `LabelsManager.js:81-85` |
| `project_id` | ObjectId | O projeto. | `LabelsManager.js:73` |
| `comment` | String | O texto do rótulo. | `LabelsManager.js:74` |
| `version` | Number | A versão do histórico do projeto para a qual o rótulo aponta. | `LabelsManager.js:75` |
| `created_at` | Date | Quando o rótulo foi criado; a requisição pode passar a própria hora, senão é agora. | `LabelsManager.js:70`, `76` |
| `user_id` | ObjectId | Quem criou o rótulo. Omitido quando a requisição não tem usuário. | `LabelsManager.js:78-80` |

#### Quem a escreve {#who-writes-it}

| Código | O que faz |
| ---- | ------------ |
| `services/project-history/app/js/LabelsManager.js:44-90` | `createLabel`: insere um rótulo, para o project-history `POST /project/:project_id/labels` (`services/project-history/app/js/HttpController.js:1134-1171`). O web o chama quando um usuário adiciona um rótulo, com o id do usuário (`services/web/app/src/Features/History/HistoryController.mjs:529-546`). |
| `LabelsManager.js:113-126` | `deleteLabel`: exclui um rótulo do projeto, para `DELETE /project/:project_id/labels/:label_id`. O web o usa quando o dono do projeto exclui um rótulo (`HistoryController.mjs:649-670`). |
| `LabelsManager.js:92-111` | `deleteLabelForUser`: exclui um rótulo só se o usuário o criou, para `DELETE /project/:project_id/user/:user_id/labels/:label_id`. O web o usa para todos os outros. |
| `LabelsManager.js:128-143` | `transferLabels`: transfere todos os rótulos de um usuário para outro, para `POST /user/:from_user/labels/transfer/:to_user` (`services/project-history/app/js/Router.js:52-55`). Nada no web chama esta rota. |
| `LabelsManager.js:7-25` | `cloneLabels`: copia os rótulos de um projeto para outro projeto, para o project-history `POST /project/:project_id/clone` (`HttpController.js:113`), que nada no web chama. |

#### Quem a lê {#who-reads-it}

| Código | O que faz |
| ---- | ------------ |
| `LabelsManager.js:27-42` | `getLabels`: todos os rótulos de um projeto, retornados como `{ id, comment, version, user_id, created_at }` (`LabelsManager.js:163-171`). Usado por `GET /project/:project_id/labels` (`HttpController.js:1076-1100`), que o web chama para a visualização Histórico, preenchendo os nomes de usuário (`HistoryController.mjs:488-499`). |
| `services/project-history/app/js/SummarizedUpdatesManager.js:57` | Adiciona os rótulos à lista de atualizações do histórico. |

#### Notas {#notes}

* Antes de inserir um rótulo, o project-history processa as atualizações enfileiradas do projeto e verifica se o history-v1 tem um chunk para essa versão, a menos que a requisição envie `validate_exists: false` (`LabelsManager.js:53-59`, `173-195`; `HttpController.js:1109-1115`).
* Nenhum código exclui os rótulos de um projeto quando o projeto é excluído: o project-history `DELETE /project/:project_id` só limpa o estado de sincronização e o registro de falha (`HttpController.js:1363-1396`), e nenhum outro serviço toca nesta coleção.
