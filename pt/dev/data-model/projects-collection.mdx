`Project` representa um único projeto LaTeX no Overleaf. Ele armazena os metadados do projeto, a propriedade e o controle de acesso, a estrutura de arquivos, as configurações de compilação e o estado da colaboração.

#### Identificação principal e metadados

* `_id`: ObjectId único do MongoDB que identifica o projeto.
* `name`: nome de exibição do projeto.
* `description`: descrição textual opcional do projeto.
* `active`: indica se o projeto está ativo no momento.
* `version`: versão interna do esquema ou do formato do projeto.
* `trashed`: lista de itens movidos para a lixeira (exclusão lógica).
* `deletedDocs`: registros de documentos excluídos permanentemente.

#### Propriedade e controle de acesso

* `owner_ref`: referência ao usuário proprietário do projeto.
* `collaberator_refs`: usuários com permissão de edição.
* `reviewer_refs`: usuários com acesso de revisor.
* `readOnly_refs`: usuários com acesso somente leitura.
* `pendingEditor_refs` / `pendingReviewer_refs`: convites pendentes.

#### Acesso baseado em tokens

* `tokens`: registro de tokens para links compartilhados.
* `tokenAccessReadOnly_refs`: tokens que concedem acesso somente leitura.
* `tokenAccessReadAndWrite_refs`: tokens que concedem acesso de leitura e escrita.

#### Rastreamento de atividade

* `lastUpdated`: data e hora da modificação mais recente.
* `lastUpdatedBy`: usuário que realizou a última atualização.
* `lastOpened`: data e hora da última vez em que o projeto foi aberto.
* `deletedByExternalDataSource`: indica se a exclusão foi acionada por uma integração externa.

#### Estrutura do projeto

Documento raiz e pasta

* `rootDoc_id`: ObjectId do documento LaTeX principal de entrada (geralmente `main.tex`).
* `rootFolder`: representação embutida da árvore de arquivos do projeto.

Cada entrada de pasta contém:

* `name` / `_id`: nome e identificador da pasta.
* `docs`: lista de documentos-fonte LaTeX com nome e `_id`.
* `fileRefs`: referências a arquivos binários (imagens, arquivos de dados), incluindo:
  * `name`: nome do arquivo
  * `created`: data e hora do upload
  * `rev`: contador de revisões
  * `hash`: hash do conteúdo para deduplicação
  * `linkedFileData`: vínculo com armazenamento externo (se houver)
* `folders`: subpastas aninhadas.

#### Configurações de compilação e do editor

* `compiler`: mecanismo LaTeX selecionado (`pdflatex`, `xelatex`, `lualatex` etc.).
* `spellCheckLanguage`: idioma do corretor ortográfico para este projeto.

#### Configurações públicas e de compartilhamento

* `publicAccesLevel`: visibilidade do projeto (`private`, `readOnly`, `public` etc.).
* `collabratecUsers`: usuários vinculados de plataformas de colaboração externas.

#### Extensões específicas do Overleaf

* `overleaf.history`:
  * `id`: identificador usado pelo serviço de histórico.
  * `display`: indica se o histórico está habilitado e visível.

#### Versionamento interno

* `__v`: chave de versão interna do Mongoose para controle de concorrência.
