title: Coleção Contacts
icon: address-book
---

`contacts` lembra com quais usuários um usuário trabalhou, para que a caixa de diálogo de compartilhamento possa sugeri-los. Um documento por usuário. `web` é o proprietário, sem schema do Mongoose; o código é `services/web/app/src/Features/Contacts/ContactManager.mjs`.

#### Campos {#fields}

| Campo | Tipo | Significado | Fonte |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id do documento, criado pelo upsert. | `ContactManager.mjs:5-12` |
| `user_id` | ObjectId | O usuário dono destes contatos. Um documento por usuário. | `ContactManager.mjs:6` |
| `contacts` | Object | Mapa indexado pelo id de usuário do contato (como string). | `ContactManager.mjs:8-9` |
| `contacts.<userId>.n` | Number | Quantas vezes os dois usuários foram aproximados. | `ContactManager.mjs:8` |
| `contacts.<userId>.ts` | Date | Quando isso aconteceu pela última vez. | `ContactManager.mjs:9` |

#### Quem escreve {#who-writes-it}

| Código | O que faz |
| --- | --- |
| `ContactManager.mjs:4-13` (`touchContact`), `:23-28` (`addContact`) | Faz upsert dos documentos dos dois usuários: `$inc` em `n`, `$set` de `ts`. |
| `services/web/app/src/Features/Collaborators/CollaboratorsHandler.mjs:155-157` | `addUserIdToProject` chama `addContact` quando recebe o usuário que está adicionando: um convite aceito (quem convidou e quem foi convidado, `services/web/app/src/Features/Collaborators/CollaboratorsInviteHandler.mjs:199-205`) e uma transferência de propriedade (novo e antigo proprietário, `services/web/app/src/Features/Collaborators/OwnershipTransferHandler.mjs:138-144`). Entrar por um link de compartilhamento não passa nenhum usuário que adiciona (`services/web/app/src/Features/TokenAccess/TokenAccessController.mjs:386-388`, `:632-634`), portanto não adiciona contato. |

#### Quem lê {#who-reads-it}

| Código | O que faz |
| --- | --- |
| `ContactManager.mjs:15-21`, `:30-42` | `getContactIds`: ordena por `n` e depois por `ts`, ambos do maior para o menor. |
| `services/web/app/src/Features/Contacts/ContactController.mjs:19-59` | `GET /user/contacts` (`services/web/app/src/Features/Contacts/ContactRouter.mjs:22-26`): retorna os 50 primeiros como usuários, sem contas provisórias, mais o que os módulos acrescentam pelo hook `getContacts`. |

#### Observações {#notes}

* Os contatos valem nos dois sentidos: adicionar B ao projeto de A torna B um contato de A e A um contato de B.
* Nada remove um contato ou o documento, nem mesmo quando um usuário é excluído.
