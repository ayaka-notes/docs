---
title: Coleção Migrations
icon: list-check
---

`migrations` registra quais migrações de banco de dados foram executadas. Um documento é uma migração de `tools/migrations/`. Ele é escrito pelo adaptador da ferramenta de migração [east](https://github.com/okv/east), `tools/migrations/lib/adapter.mjs`, e não por um serviço em execução.

#### Campos {#fields}

| Campo | Tipo | Significado | Fonte |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id do documento. | `adapter.mjs:103` |
| `name` | String | Nome do arquivo da migração sem a extensão, por exemplo `20190912145029_create_tags_indexes`. | `adapter.mjs:104` |
| `migratedAt` | Date | Quando a migração terminou. | `adapter.mjs:105` |

#### Quem escreve {#who-writes-it}

| Código | O que faz |
| --- | --- |
| `adapter.mjs:101-107` (`markExecuted`) | Insere um documento depois que uma migração é executada. |
| `adapter.mjs:109-114` (`unmarkExecuted`) | Exclui-o novamente quando uma migração é revertida. |

O CE executa `yarn run migrations migrate -t server-ce` a cada inicialização do contêiner (`server-ce/init_scripts/900_run_web_migrations.sh:4-12`; `-t server-pro` quando `OVERLEAF_IS_SERVER_PRO=true`). Somente as migrações cujas `tags` incluem esse ambiente são executadas, então apenas elas recebem um documento aqui.

#### Quem lê {#who-reads-it}

| Código | O que faz |
| --- | --- |
| `adapter.mjs:72-99` (`getExecutedMigrationNames`) | O east ignora toda migração cujo nome já está aqui. |
| `tools/migrations/lib/helpers.mjs:67-75` (`assertDependency`) | Uma migração que precisa que outra tenha sido executada antes lança um erro quando esse nome está ausente. |

#### Índices {#indexes}

| Nome | Chaves | Opções | Migração |
| --- | --- | --- | --- |
| `name_1` | `{ name: 1 }` | unique | `tools/migrations/20190720165251_create_migrations.mjs` |

#### Observações {#notes}

* Excluir um documento faz essa migração ser executada novamente na próxima inicialização do contêiner, se as tags corresponderem.
* Com um cluster Mongo auxiliar (`mongo.auxUrl`), as migrações com a tag `auxiliary` são registradas na coleção `migrations` desse cluster (`adapter.mjs:8-15`, `:64-70`). `mongo.auxUrl` vem de `MONGO_AUX_CONNECTION_STRING` (`tools/migrations/config/settings.defaults.js:19`), que não está definido por padrão.
