---
title: Coleção Dropbox Entities
icon: file-arrow-up
---

`dropboxEntities` contém um documento por arquivo que a sincronização com o Dropbox copiou entre um projeto e o Dropbox de um usuário, além de tombstones de curta duração. Ela pertence à sincronização com o Dropbox: o third-party-datastore (`services/third-party-datastore/app/js/StateManager.mjs`) a escreve e a lê, e o módulo web `dropbox` (`services/web/modules/dropbox/app/src/DropboxHandler.mjs`) a limpa. Não há esquema Mongoose.

#### Campos {#fields}

| Campo | Tipo | Significado | Fonte |
| ----- | ---- | ----------- | ----- |
| `_id` | ObjectId | Definido pelo driver na inserção. | `StateManager.mjs:46,97` |
| `overleaf.userId` | ObjectId | O usuário em cujo Dropbox está o arquivo. Definido em todos os documentos. | `StateManager.mjs:48,98` |
| `overleaf.projectId` | ObjectId | O projeto do doc ou arquivo. Definido quando conhecido; tombstones não o têm. | `StateManager.mjs:49-51` |
| `overleaf.id` | ObjectId | O `_id` do doc ou arquivo no `rootFolder` do projeto. Definido quando conhecido. | `StateManager.mjs:52` |
| `overleaf.type` | String | `doc` ou `file`. O código atual o escreve, mas não o lê. | `StateManager.mjs:53`; valores de `services/web/app/src/Features/ThirdPartyDataStore/TpdsUpdateSender.mjs:35,96` e `UpdateMerger.mjs:104,119` |
| `dropbox.id` | String | O `id` do arquivo nos metadados de arquivo do Dropbox. Não definido em tombstones. | `StateManager.mjs:56` |
| `dropbox.pathLower` | String | O caminho do arquivo no Dropbox, em minúsculas e sem barra final. Atualizado quando o arquivo ou a pasta do projeto é movido. | `StateManager.mjs:14-16,57,91,99` |
| `dropbox.rev` | String | A revisão do Dropbox na última sincronização. O próximo upload a envia, para que um arquivo alterado no Dropbox não seja sobrescrito. | `StateManager.mjs:58`, `JobProcessor.mjs:114-122` |
| `dropbox.contentHash` | String | O hash de conteúdo do Dropbox na última sincronização. Um arquivo listado com o mesmo hash é ignorado, pois é nosso próprio upload ou já foi aplicado. | `StateManager.mjs:59`, `PullManager.mjs:147-149` |
| `tombstone` | Boolean | `true` marca um caminho que o próprio third-party-datastore excluiu ou moveu no Dropbox. Quando o Dropbox informa essa exclusão de volta, ela não é aplicada ao projeto. | `StateManager.mjs:100`, `PullManager.mjs:189-192` |
| `createdAt` | Date | Apenas tombstones: quando foi criado. Um pull concluído remove os tombstones criados antes de seu início. | `StateManager.mjs:101,115-121` |

Um tombstone tem apenas `overleaf.userId`, `dropbox.pathLower`, `tombstone` e `createdAt` (`StateManager.mjs:96-103`).

#### Quem a escreve {#who-writes-it}

| Código | O que faz |
| ------ | --------- |
| `services/third-party-datastore/app/js/StateManager.mjs:35-62` (`recordEntity`) | Exclui os documentos do usuário com o mesmo `dropbox.id`, `dropbox.pathLower` ou `overleaf.id` e depois insere o novo estado. |
| `services/third-party-datastore/app/js/JobProcessor.mjs:102-134` (`addEntity`) | Registra um doc ou arquivo após enviá-lo do Overleaf para o Dropbox (`:125-133`). |
| `services/third-party-datastore/app/js/PullManager.mjs:142-177` (`applyFile`) | Registra um arquivo do Dropbox depois que o web o aplicou ao projeto (`:168-176`). |
| `StateManager.mjs:80-94` (`moveEntities`) | Reescreve `dropbox.pathLower` sob um caminho movido: renomeação de projeto (`JobProcessor.mjs:195`) e movimentação de arquivo ou pasta (`JobProcessor.mjs:239`). |
| `StateManager.mjs:96-103` (`addTombstone`) | Após uma exclusão (`JobProcessor.mjs:153`), uma renomeação de projeto (`:202`) ou uma movimentação (`:240`) no Dropbox. |
| `StateManager.mjs:72-78` (`removeEntities`) | Exclui as entradas em um caminho e abaixo dele, exceto tombstones: após uma exclusão a partir do Overleaf (`JobProcessor.mjs:152`) ou no Dropbox (`PullManager.mjs:206`). |
| `StateManager.mjs:115-121` (`clearTombstones`) | No fim de um pull (`PullManager.mjs:31,69`). |
| `StateManager.mjs:186-190` (`removeUserState`), chamado a partir de `services/third-party-datastore/app/js/QueueWorker.mjs:43` | Exclui todos os documentos do usuário quando o third-party-datastore desvincula uma conta que não pode mais usar. |
| `DropboxHandler.mjs:142-146` (`removeUserState`) | Exclui todos os documentos do usuário ao vincular (`:125`), ao desvincular (`:183`) e quando um usuário excluído expira (`services/web/modules/dropbox/index.mjs:62-64`). |
| `DropboxHandler.mjs:150-154` (`removeProjectState`) | Exclui os documentos do projeto quando um projeto excluído expira (`index.mjs:54-56`). |

#### Quem a lê {#who-reads-it}

| Código | O que faz |
| ------ | --------- |
| `StateManager.mjs:64-70` (`findEntityByPath`) | Obtém `dropbox.rev` antes de um upload (`JobProcessor.mjs:114`) e `dropbox.contentHash` antes de aplicar um arquivo do Dropbox (`PullManager.mjs:147`). |
| `StateManager.mjs:106-112` (`findTombstone`) | Verifica uma exclusão relatada no caminho ou em um de seus pais (`PullManager.mjs:189`). |
| `StateManager.mjs:160-175` (`getSyncedPaths`) | Lista os caminhos de arquivos sincronizados após uma redefinição do cursor, para que um arquivo ausente da listagem conte como excluído (`PullManager.mjs:74-85`). |

#### Índices {#indexes}

| Nome | Chaves | Opções | Migração |
| ---- | ------ | ------ | -------- |
| `_id_` | `_id: 1` | | default |
| `overleaf_userId_1_overleaf_projectId_1` | `overleaf.userId: 1, overleaf.projectId: 1` | | `tools/migrations/20250130104049_create_dropboxEntities_userId_projectId_index.mjs` |

`20220811111800_create_dropboxEntities_index.mjs` e `20220825160708_recreate_dropboxEntities.mjs` têm apenas a tag `saas`, então o CE não tem seus índices únicos em `(overleaf.userId, dropbox.id)` e `(overleaf.userId, overleaf.id)`, nem seu índice hashed em `dropbox.pathLower`.

#### Notas {#notes}

* A unicidade vem apenas da exclusão antes de cada inserção em `recordEntity` (`StateManager.mjs:38-45`). O comentário em `StateManager.mjs:3-11` menciona índices únicos; o CE não os tem.
* Consultas por usuário e caminho (`findEntityByPath`, `findTombstone`, `removeEntities`) usam o índice apenas para `overleaf.userId`.
