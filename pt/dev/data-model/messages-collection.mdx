title: Coleção Messages
icon: message
---

`messages` guarda um documento por mensagem: uma linha do chat do projeto, ou um comentário ou resposta em um tópico de comentários de revisão. Só o serviço chat a escreve, em `services/chat/app/js/Features/Messages/MessageManager.js`. Não há schema Mongoose. Cada mensagem pertence a uma sala da coleção [rooms](/pt/dev/data-model/rooms-collection).

#### Campos {#fields}

| Campo | Tipo | Significado | Origem |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Id da mensagem. | `MessageManager.js:13-14` |
| `room_id` | ObjectId | A sala (`rooms._id`), não o id do projeto nem o id do tópico. | `MessageManager.js:8,106-108` |
| `user_id` | ObjectId | Autor. | `MessageManager.js:9,103-105` |
| `content` | String | Texto da mensagem, de 1 a 10240 caracteres (`MAX_MESSAGE_LENGTH`). | `MessageManager.js:7`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:3,12-15` |
| `timestamp` | Number | Quando foi enviada, em milissegundos desde 1970 (`Date.now()`), não um Date. | `MessageManager.js:10`, `services/chat/app/js/Features/Messages/MessageHttpController.js:288` |
| `edited_at` | Number | Quando foi editada pela última vez, em milissegundos (`Date.now()`). Ausente se nunca foi editada. | `MessageManager.js:65-69`, `MessageHttpController.js:189,213` |

#### Quem a escreve {#who-writes-it}

| Código | O que faz |
| ---- | ------------ |
| `MessageManager.js:5-16` `createMessage` | Insere uma mensagem (`MessageHttpController.js:275-294`). O web envia mensagens do chat do projeto a partir de `services/web/app/src/Features/Chat/ChatController.mjs:32`, e comentários a partir do módulo track-changes (`services/web/modules/track-changes/app/src/TrackChangesController.mjs:95`) e do módulo mcp-server (`services/web/modules/mcp-server/app/src/CommentTools.mjs:133`). |
| `MessageManager.js:51-72` `updateMessage` | Define `content` e `edited_at`. Quando um id de usuário é informado, só a mensagem desse usuário corresponde (`MessageManager.js:62-64`). Chamado a partir de `ChatController.mjs:135` e `TrackChangesController.mjs:110`. |
| `MessageManager.js:74-80` `deleteMessage` | Exclui uma mensagem. Chamado a partir de `ChatController.mjs:105` e `TrackChangesController.mjs:129`. |
| `MessageManager.js:39-49` `deleteAllMessagesInRoom(s)` | Exclui as mensagens de um tópico excluído (`MessageHttpController.js:172-173`) ou de um projeto inteiro quando um projeto excluído expira (`MessageHttpController.js:261-271`, chamado a partir de `services/web/app/src/Features/Project/ProjectDeleter.mjs:391`). |
| `MessageManager.js:115-127` `duplicateRoomToOtherRoom` | Copia `content`, `timestamp` e `user_id` de cada mensagem para outra sala, sem `edited_at`. Usado quando uma restauração do histórico duplica um tópico (`MessageHttpController.js:316-342`) e quando um projeto é copiado com seus intervalos (`MessageHttpController.js:344-357`). |

#### Quem a lê {#who-reads-it}

| Código | O que faz |
| ---- | ------------ |
| `MessageManager.js:18-29` `getMessages` | Mais recentes primeiro, no máximo `limit` (padrão 50) anteriores a `before` (um `timestamp`). Usado no chat do projeto (`ChatController.mjs:80`). |
| `MessageManager.js:31-37` `findAllMessagesInRooms` | Todas as mensagens de algumas salas, para a lista de tópicos do painel de revisão (`TrackChangesController.mjs:82`), o módulo mcp-server (`CommentTools.mjs:83`) e a restauração do histórico (`services/web/app/src/Features/History/RestoreManager.mjs:259`). O web também verifica a primeira mensagem de um tópico para que um revisor só altere tópicos que ele iniciou (`services/web/app/src/Features/Authorization/AuthorizationManager.mjs:409-411`). |
| `MessageManager.js:90-100` `getMessage` | Uma mensagem. O web verifica seu `user_id` antes que um usuário edite ou exclua a própria mensagem (`services/web/app/src/Features/Authorization/AuthorizationMiddleware.mjs:253-257`, `TrackChangesController.mjs:124-125`). |

#### Notas {#notes}

* Para encontrar as mensagens de um comentário, procure primeiro a sala por `project_id` e `thread_id` e depois consulte `room_id`. O id do comentário no doc é o `thread_id`, não o `room_id`.
* O texto para o qual um comentário aponta é `op.c` em `docs.ranges.comments`; a discussão fica aqui.
