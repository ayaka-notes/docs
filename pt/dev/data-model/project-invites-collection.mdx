title: Coleção Project Invites
icon: envelope-open-text
---

`projectInvites` contém os convites que o dono de um projeto envia a partir da caixa de diálogo de partilha. Um documento é um convite para um endereço de email. É apagado quando o convite é aceite ou revogado, ou pelo Mongo quando expira. O esquema é `services/web/app/src/models/ProjectInvite.mjs`, e quem o escreve é `services/web/app/src/Features/Collaborators/CollaboratorsInviteHandler.mjs`.

Um convite não torna ninguém membro. Os membros estão nos arrays `*_refs` de um projeto, veja [Coleção Projects](/pt/dev/data-model/projects-collection).

#### Quem escreve {#who-writes-it}

| Código | O que faz |
| ---- | ------------ |
| `CollaboratorsInviteHandler.mjs:76-101` (`inviteToProject`) | Cria um convite por email e depois envia o email e, para um utilizador existente, uma notificação. Chamado por `POST /project/:Project_id/invite` (`services/web/app/src/Features/Collaborators/CollaboratorsRouter.mjs:114-125`). |
| `CollaboratorsInviteHandler.mjs:118-133` (`revokeInvite`) | Apaga um convite e marca a sua notificação como lida. Chamado por `DELETE /project/:Project_id/invite/:invite_id` (`CollaboratorsRouter.mjs:154-159`). |
| `CollaboratorsInviteHandler.mjs:135-153` (`generateNewInvite`) | Reenviar: apaga o convite e cria um novo com um novo token (`CollaboratorsRouter.mjs:161-169`). |
| `CollaboratorsInviteHandler.mjs:103-116` (`revokeInviteForUser`) | Apaga o convite enviado para um dos emails confirmados do utilizador, quando o utilizador entra através de um token de partilha por link (`services/web/app/src/Features/TokenAccess/TokenAccessController.mjs:396-401`) ou recebe acesso após um pedido de acesso (`services/web/app/src/Features/Collaborators/CollaboratorsController.mjs:503-513`). |
| `CollaboratorsInviteHandler.mjs:155-221` (`acceptInvite`) | Adiciona o utilizador ao projeto e depois apaga o convite, a menos que seja `reusable`. |
| `CollaboratorsInviteHandler.mjs:249-269` (`createSharingLinkInvite`), `CollaboratorsInviteController.mjs:689-724` (`updateSharingLink`) | Criam ou atualizam o único convite reutilizável por link de partilha de um projeto. Estas rotas exigem o split test `sharing-updates-new-link` (`CollaboratorsRouter.mjs:134-152`), que não está em `splitTestOverrides` (`services/web/config/settings.defaults.js:1371-1383`). Por isso respondem 403 enquanto esse split test não estiver configurado. |

#### Notas {#notes}

* Se o projeto não tiver nenhum lugar de editor livre quando um convite `readAndWrite` ou `review` for aceite, o utilizador entra só com leitura e fica listado em `pendingEditor_refs` ou `pendingReviewer_refs` do projeto (`CollaboratorsInviteHandler.mjs:162-205`).
* Os convites mais antigos guardavam o token em texto simples num campo `token`. A migração `20240524135408_add_token_hmac_project_invite_tokens.mjs` adicionou `tokenHmac` e `20240531082910_remove_project_invite_tokens.mjs` removeu `token`.
* Nada apaga os convites de um projeto eliminado; ficam até o índice TTL os remover.
