title: Coleção Doc Snapshots

---

`docSnapshots` guarda cópias de um doc que o document-updater tira logo antes de uma edição que recolhe comentários ou alterações controladas. Só o document-updater a escreve, em `services/document-updater/app/js/SnapshotManager.js`. O web tem um modelo Mongoose em `services/web/app/src/models/DocSnapshot.mjs`, mas nenhum código o usa.

#### Campos {#fields}

| Campo | Tipo | Significado | Origem |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Id do snapshot. | `SnapshotManager.js:24` |
| `project_id` | ObjectId | Projeto. | `SnapshotManager.js:19,26`, `DocSnapshot.mjs:7` |
| `doc_id` | ObjectId | O doc (`docs._id`). | `SnapshotManager.js:20,27`, `DocSnapshot.mjs:8` |
| `version` | Number | Versão OT do doc antes da edição. | `SnapshotManager.js:28`, `services/document-updater/app/js/UpdateManager.js:132,264-271`, `DocSnapshot.mjs:9` |
| `lines` | Array of String | Conteúdo do doc antes da edição. | `SnapshotManager.js:29`, `DocSnapshot.mjs:10` |
| `pathname` | String | Caminho do doc no projeto naquele momento. | `SnapshotManager.js:30`, `DocSnapshot.mjs:11` |
| `ranges` | Mixed | `comments` e `changes` antes da edição, com a mesma forma de `docs.ranges` (veja [docs](/pt/dev/data-model/docs-collection)). `id`, `op.t` e `metadata.user_id` são convertidos em ObjectIds e `metadata.ts` em Dates. | `SnapshotManager.js:31,41-68`, `DocSnapshot.mjs:12` |
| `ts` | Date | Quando o snapshot foi tirado. O índice TTL o exclui 30 dias depois. | `SnapshotManager.js:32`, `DocSnapshot.mjs:13` |

#### Quem a escreve {#who-writes-it}

| Código | O que faz |
| ---- | ------------ |
| `UpdateManager.js:248-271` | Depois de aplicar uma edição, o document-updater registra o doc como estava antes dela quando a edição recolheu intervalos: mais intervalos ficaram vazios, ou mais de um intervalo foi removido (`services/document-updater/app/js/RangesManager.js:104-106`). |
| `SnapshotManager.js:17-36` `recordSnapshot` | Insere o snapshot. |

#### Quem a lê {#who-reads-it}

Nenhum código a lê. O modelo do web está definido, mas não é usado em lugar nenhum.

#### Notas {#notes}

* Só as edições que passam por `UpdateManager.applyUpdate` tiram snapshots. As tratadas por `HistoryOTUpdateManager` não tiram (`UpdateManager.js:74-77`).
* Não há índice em `doc_id`. Encontre os snapshots de um doc por `project_id` e `ts` e depois filtre por `doc_id`.
