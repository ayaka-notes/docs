---
title: Coleção OAuth Authorization Codes
icon: lock-open
---

`oauthAuthorizationCodes` destina-se aos códigos do fluxo OAuth authorization code: um documento por código, que um cliente troca por um token de acesso. O esquema é `services/web/app/src/models/OauthAuthorizationCode.mjs`, e o módulo web `oauth2-server` tem o código que escreveria nela. No Ayakaleaf Pro nada chega a esse código, por isso a coleção fica vazia (veja Notas).

#### Campos {#fields}

| Campo | Tipo | Significado | Origem |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Id do documento. | `OauthAuthorizationCode.mjs:6` |
| `authorizationCode` | String | O próprio código, guardado como está (sem hash). | `OauthAuthorizationCode.mjs:8`, `services/web/modules/oauth2-server/app/src/OAuth2Model.mjs:280` |
| `expiresAt` | Date | Fim da validade. `getAuthorizationCode` rejeita um código depois dela, e o índice TTL apaga-o. | `OauthAuthorizationCode.mjs:9`, `OAuth2Model.mjs:150-153,281` |
| `oauthApplication_id` | ObjectId | Cliente em [OAuth Applications](/pt/dev/data-model/oauth-applications-collection) que pediu o código. | `OauthAuthorizationCode.mjs:10`, `OAuth2Model.mjs:275-284` |
| `redirectUri` | String | URI de redirecionamento do pedido. | `OauthAuthorizationCode.mjs:11`, `OAuth2Model.mjs:282` |
| `scope` | String | Scope pedido. | `OauthAuthorizationCode.mjs:12`, `OAuth2Model.mjs:283` |
| `user_id` | ObjectId | Utilizador que concedeu o código. | `OauthAuthorizationCode.mjs:13`, `OAuth2Model.mjs:285` |
| `codeChallenge`, `codeChallengeMethod` | String | Challenge PKCE e o seu método. | `OauthAuthorizationCode.mjs:14-15`, `OAuth2Model.mjs:286-287` |

#### Quem escreve {#who-writes-it}

| Código | O que faz |
| ---- | ------------ |
| `OAuth2Model.mjs:274-300` (`saveAuthorizationCode`) | Insere um código. Não é alcançado, veja Notas. |
| `OAuth2Model.mjs:307-312` (`revokeAuthorizationCode`) | Apaga um código depois de usado. Não é alcançado. |

#### Quem lê {#who-reads-it}

| Código | O que faz |
| ---- | ------------ |
| `OAuth2Model.mjs:137-177` (`getAuthorizationCode`) | Carrega um código com o seu utilizador e cliente. Não é alcançado. |

#### Índices {#indexes}

| Nome | Chaves | Opções | Migração |
| ---- | ---- | ------- | --------- |
| `expiresAt_1` | `{ expiresAt: 1 }` | TTL, `expireAfterSeconds: 0`, parcial: `expiresAt` existe | `20230406125632_oauth_tokens_ttl.mjs` |

As migrações estão em `tools/migrations/`. O índice único `authorizationCode_1` vem apenas de migrações marcadas `saas` e `server-pro`, que o Community Edition não executa.

#### Notas {#notes}

* Os métodos do modelo acima só são chamados pelos handlers authorize e token de `@node-oauth/oauth2-server`. O web usa essa biblioteca apenas para verificar tokens bearer (`services/web/app/src/Features/Authentication/AuthenticationController.mjs:409-450`), e nenhuma rota serve `/oauth/authorize` ou `/oauth/token`, por isso nunca é escrito nenhum código. Os tokens de acesso pessoal são criados diretamente, veja [OAuth Access Tokens](/pt/dev/data-model/oauth-access-tokens-collection).
