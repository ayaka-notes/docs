title: Coleção User Audit Log Entries
icon: user-clock
---

`userAuditLogEntries` é o log de auditoria das contas de usuário: logins, alterações de senha e de e-mail, contas vinculadas e ações de administração. Um documento é um evento em uma conta. `web` é o proprietário; o schema é `services/web/app/src/models/UserAuditLogEntry.mjs`, e o núcleo escreve por meio de `services/web/app/src/Features/User/UserAuditLogHandler.mjs`.

#### Campos {#fields}

| Campo | Tipo | Significado | Fonte |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id da entrada. | `UserAuditLogEntry.mjs:4` |
| `userId` | ObjectId | A conta a que o evento se refere. | `UserAuditLogEntry.mjs:6` |
| `operation` | String | O que aconteceu, um nome em kebab-case como `login` (veja a tabela abaixo). | `UserAuditLogEntry.mjs:11` |
| `initiatorId` | ObjectId | Quem fez: o usuário, ou um administrador nas ações de administração. Pode faltar em algumas operações, como `reset-password` (`UserAuditLogHandler.mjs:19-33`). | `UserAuditLogEntry.mjs:9` |
| `ipAddress` | String | Endereço IP da requisição (`req.ip`). Pode faltar em algumas operações (`UserAuditLogHandler.mjs:8-17`). | `UserAuditLogEntry.mjs:10` |
| `info` | Object | Detalhes do evento; as chaves dependem da operação. | `UserAuditLogEntry.mjs:8` |
| `timestamp` | Date | Quando a entrada foi escrita (padrão `Date.now`). | `UserAuditLogEntry.mjs:12` |
| `managedSubscriptionId` | ObjectId | Assinatura de grupo gerenciada do usuário. Só é definida quando o recurso `saas` está ativo (`UserAuditLogHandler.mjs:92-107`), portanto nunca no CE. | `UserAuditLogEntry.mjs:7` |
| `__v` | Number | Chave de versão do Mongoose, adicionada por `UserAuditLogEntry.create`. | `UserAuditLogHandler.mjs:109` |

`tools/migrations/20220929193200_add_auditLog_indexes.mjs` criou primeiro `user_id_1` em `{ userId: 1 }`; `20251117093546` o substitui pelo índice composto. O schema marca `userId` e `managedSubscriptionId` com `index: true`, mas a indexação automática do Mongoose está desativada (`services/web/app/src/infrastructure/Mongoose.mjs:7`), então somente as migrações acima criam índices. A migração do índice de `managedSubscriptionId` tem apenas a tag `saas`.

#### Observações {#notes}

* As entradas expiram 2,5 anos após `timestamp` por meio do índice TTL.
