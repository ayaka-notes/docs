---
title: Coleção Spelling Preferences
icon: spell-check
---

`spellingPreferences` guarda o dicionário de cada usuário: as palavras que o usuário adicionou por "Add to dictionary" na verificação ortográfica do editor. Um documento por usuário. `web` é o proprietário, sem schema do Mongoose; o código é `services/web/app/src/Features/Spelling/LearnedWordsManager.mjs`.

#### Campos {#fields}

| Campo | Tipo | Significado | Fonte |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id do documento, criado pelo upsert. | `LearnedWordsManager.mjs:21-31` |
| `token` | String | O id do usuário. Apesar do nome, as rotas de ortografia passam o id do usuário conectado (`SessionManager.getLoggedInUserId`). | `LearnedWordsManager.mjs:23` |
| `learnedWords` | Array of String | As palavras que o usuário adicionou. | `LearnedWordsManager.mjs:26` |

#### Quem escreve {#who-writes-it}

| Código | O que faz |
| --- | --- |
| `LearnedWordsManager.mjs:13-32` (`learnWord`) | `POST /spelling/learn` (`services/web/app/src/router.mjs:1037-1041`, `services/web/app/src/Features/Spelling/SpellingController.mjs:45-58`): `$addToSet` da palavra, com upsert. Recusa quando a lista ultrapassaria `Settings.maxDictionarySize` bytes. |
| `LearnedWordsManager.mjs:38-47` (`unlearnWord`) | `POST /spelling/unlearn` (`router.mjs:1043-1047`, `SpellingController.mjs:66-79`): `$pull` da palavra. |
| `LearnedWordsManager.mjs:84-86` (`deleteUsersLearnedWords`) | Exclui o documento. Seu único wrapper, `SpellingHandler.deleteUserDictionary` (`services/web/app/src/Features/Spelling/SpellingHandler.mjs:24-26`), não tem chamadores no web nem em seus módulos. |

#### Quem lê {#who-reads-it}

| Código | O que faz |
| --- | --- |
| `LearnedWordsManager.mjs:52-67` (`getLearnedWords`) | Retorna as palavras sem duplicatas. |
| `services/web/app/src/Features/Project/ProjectController.mjs:671` | Envia o dicionário ao editor quando um projeto é aberto (`SpellingHandler.getUserDictionary`). |

#### Observações {#notes}

* O índice não é único; o upsert em `token` mantém um documento por usuário.
* Excluir um usuário não exclui este documento.
