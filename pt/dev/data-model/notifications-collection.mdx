---
title: Coleção Notifications
icon: bell
---

`notifications` guarda os avisos exibidos no topo do painel de projetos de um usuário. Um documento é um aviso para um usuário, identificado pela sua `key`. Somente o serviço `notifications` acessa a coleção (`services/notifications/app/js/Notifications.js`); `web` e `third-party-datastore` chamam sua API HTTP. Não há schema do Mongoose.

#### Campos {#fields}

| Campo | Tipo | Significado | Fonte |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id do aviso. `web` marca um aviso como lido por este id. | `Notifications.js:58-65` |
| `user_id` | ObjectId | O usuário que vê o aviso. | `Notifications.js:26` |
| `key` | String | Identifica o aviso, por exemplo `project-invite-<inviteId>`. O upsert mantém um documento por `user_id` e `key`; não há índice único. | `Notifications.js:27`, `:51-55` |
| `templateKey` | String | Qual aviso o frontend renderiza. Removido quando o aviso é lido ou dispensado; o documento permanece. | `Notifications.js:29`, `:63`, `:72`, `:78` |
| `messageOpts` | Object | Valores para o texto do aviso, conforme o `templateKey` (para um convite de projeto: `userName`, `projectName`, `projectId`, `token`). Removido quando o usuário dispensa o aviso pelo id. | `Notifications.js:28`, `:63` |
| `expires` | Date | Opcional. O índice TTL exclui o documento após esse momento. | `Notifications.js:35-50` |

`NotificationsBuilder.mjs` também monta chaves para convites de grupo, afiliações institucionais, assinaturas e projetos antigos de depuração. Quem as chama está no código de assinaturas e instituições, e a verificação de projetos antigos de depuração só é executada com `isSaas` (`services/web/app/src/Features/Project/ProjectListController.mjs:234-236`).

#### Observações {#notes}

* Um aviso lido não é excluído: apenas o `templateKey` some. Como o documento ainda contém a chave, um `addNotification` posterior sem `forceCreate` para a mesma chave não faz nada (`Notifications.js:21-24`).
* As rotas `/key/:key` atuam apenas sobre a chave, para todos os usuários (`Notifications.js:76-100`).
* Se `web` não tiver `apis.notifications.url`, ele não cria nem lê avisos (`NotificationsHandler.mjs:17`, `:41`).
