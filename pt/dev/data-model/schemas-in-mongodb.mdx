Nesta seção, discutiremos o modelo de dados do Overleaf. O Overleaf usa o MongoDB para persistência de dados, e o único banco de dados se chama `sharelatex`, que também é o nome do predecessor do Overleaf.

Se você ainda não configurou o Mongo Express para o Overleaf, é altamente recomendável consultar [setup-develop-tools.md](/pt/dev/environment/setup-develop-tools  "mention") e configurar o seu Mongo.

Depois de configurar o Mongo Express, você pode fazer login em [http://localhost:8081/](http://localhost:8081/) com as credenciais `admin:pass`.
