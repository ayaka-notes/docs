`tags` guarda as tags (pastas) em que um usuário organiza projetos no painel de projetos. Um documento é uma tag de um usuário. `web` é o proprietário; o schema é `services/web/app/src/models/Tag.mjs`, e todas as escritas passam por `services/web/app/src/Features/Tags/TagsHandler.mjs`.

#### Campos {#fields}

| Campo | Tipo | Significado | Fonte |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id da tag, usado nas rotas `/tag/:tagId`. | `Tag.mjs:10` |
| `user_id` | String | Proprietário da tag. Uma string simples, não um ObjectId, por razões históricas. | `Tag.mjs:7-12` |
| `name` | String | Nome da tag, com no máximo 50 caracteres (`MAX_TAG_LENGTH`). Único por usuário. | `Tag.mjs:13`, `TagsHandler.mjs:4` |
| `color` | String | Cor opcional: um código hexadecimal como `#a1b2c3` ou um valor `hsl(<n>, 70%, 45%)` (`TAG_COLOR_REGEX`). | `Tag.mjs:5`, `Tag.mjs:14-22` |
| `project_ids` | Array of String | Ids dos projetos nesta tag, como strings. | `Tag.mjs:23` |
| `__v` | Number | Chave de versão do Mongoose, adicionada quando `Tag.create` cria o documento. | `TagsHandler.mjs:27` |

#### Quem escreve {#who-writes-it}

| Código | O que faz |
| --- | --- |
| `TagsHandler.mjs:18-35` (`createTag`) | `POST /tag` (`services/web/app/src/router.mjs:873-874`). Com um nome duplicado, retorna a tag existente. |
| `TagsHandler.mjs:37-70` (`renameTag`, `editTag`) | `POST /tag/:tagId/rename` e `/tag/:tagId/edit` (`router.mjs:879-886`): definem `name`, ou `name` e `color`. |
| `TagsHandler.mjs:72-77` (`deleteTag`) | `DELETE /tag/:tagId` (`router.mjs:891-892`). |
| `TagsHandler.mjs:79-113` | Adiciona ou remove um ou vários projetos (`$addToSet` / `$pull` / `$pullAll` em `project_ids`), rotas `router.mjs:897-916`. |
| `TagsHandler.mjs:124-128` (`removeProjectFromAllTags`) | Chamado para cada membro quando um projeto é excluído (`services/web/app/src/Features/Project/ProjectDeleter.mjs:236-238`) e quando um usuário é removido de um projeto ou sai dele (`services/web/app/src/Features/Collaborators/CollaboratorsController.mjs:621`). |
| `TagsHandler.mjs:130-134` (`addProjectToTags`) | Coloca um projeto copiado nas mesmas tags do original (`services/web/app/src/Features/Project/ProjectDuplicator.mjs:190-194`). |
| `services/web/modules/server-ce-scripts/scripts/rename-tag.mjs:20-23` | Script de administração que renomeia uma tag de um usuário diretamente no Mongo. |

#### Observações {#notes}

* As tags são por usuário: dois colaboradores do mesmo projeto mantêm cada um as próprias tags para ele.
* `user_id` e `project_ids` são strings, portanto consulte-os com ids em string, não com ObjectIds.
* Excluir um usuário (`services/web/app/src/Features/User/UserDeleter.mjs`) não altera `tags`.
