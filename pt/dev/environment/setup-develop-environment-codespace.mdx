Para economizar tempo e criar rapidamente o ambiente de desenvolvimento, oferecemos outra versão da configuração do ambiente de desenvolvimento: o GitHub Codespace.

## Tutorial de configuração

<Steps>
<Step title="Criar Codespaces">
Clique no botão a seguir para criar um codespace na nuvem para o desenvolvimento do server-pro.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/ayakaleaf-pro)

Recomenda-se escolher um **Machine Type** de pelo menos **4-core**. Para tipos de máquina maiores, você pode enviar uma solicitação à equipe de suporte oficial do GitHub abrindo um ticket [aqui](https://support.github.com/contact?tags=rr-codespaces%2Ccat_codespaces).

<Frame>
  <img src="/images/dev/image.png" alt="" />
</Frame>
</Step>

<Step title="Executar o script de configuração">
Você precisará aguardar pacientemente até que o codespace seja criado. Depois de ter acesso ao seu Terminal, execute o seguinte comando:

```text
cd develop/
bin/setup
```

<Frame>
  <img src="/images/dev/image-1.png" alt="" />
</Frame>

<Warning>

Este script (`bin/setup`) permite configurar o ambiente de desenvolvimento no commit mais recente da branch `server-pro` no menor tempo possível. Ele pode não ser aplicável a versões mais antigas/outras branches.

Construímos a imagem docker de desenvolvimento todos os dias com o [GitHub Action](https://github.com/ayaka-notes/ayakaleaf-pro/actions).

</Warning>
</Step>

<Step title="Acessar o Launchpad">
Mude para a aba de portas e você verá uma lista das portas web disponíveis. Clique na que tem `80`. Agora você deverá ver a página do launchpad.

<Frame>
  <img src="/images/dev/image-2.png" alt="" />
</Frame>

Você verá:

<Frame>
  <img src="/images/dev/image-3.png" alt="" />
</Frame>
</Step>

<Step title="Aproveite o desenvolvimento">
Agora o tempo é seu! Comece a construir seu recurso incrível. Você precisa executar o seguinte comando para ativar a exibição em tempo real:

```bash title="bash" wrap
docker compose -f docker-compose.yml -f docker-compose.dev.yml -f ./docker-compose.image.yml up --no-deps --detach
```
</Step>
</Steps>
