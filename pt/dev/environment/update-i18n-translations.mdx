---
title: Atualizar traduções i18n
icon: language
---

Existe um arquivo em `services/web/frontend/extracted-translations.json`, e o Overleaf web usará apenas as traduções extraídas presentes nesse arquivo.

Execute o comando a seguir para atualizar as traduções extraídas caso você tenha adicionado algum conteúdo.

```bash
user ➜ ~/overleaf-pro/develop (server-pro) $ bin/shell webpack
root@432836260f8a:/overleaf/services/web# npm run extract-translations
```

Em geral, não edite os arquivos de texto de tradução; use primeiro os já existentes, pois todos esses arquivos são atualizados a partir do upstream do Overleaf ou de um site de tradução de terceiros.
