title: docstore
icon: database
---

Armazena cada documento (linhas, versão, intervalos) de cada projeto na coleção do Mongo `docs` e arquiva documentos em armazenamento de objetos quando há um backend definido. É chamado pelo web; o document-updater o acessa por meio do web.

* <strong>Endereço:</strong> `http://docstore:3016`, dentro da rede Docker
* <strong>Autenticação:</strong> nenhuma
* <strong>Arquivo OpenAPI:</strong> [`develop/hoppscotch/openapi/docstore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/docstore.yaml)
