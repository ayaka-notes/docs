Enfileira no Redis as edições de cada projeto, transforma-as em alterações de histórico e as envia ao history-v1; também mantém no Mongo os rótulos de histórico, o estado de ressincronização e os registros de falhas. É chamado pelo web, document-updater, history-v1 e pelos scripts cron do server-ce; não tem autenticação.

* <strong>Endereço:</strong> `http://project-history:3054`, dentro da rede Docker
* <strong>Autenticação:</strong> nenhuma
* <strong>Arquivo OpenAPI:</strong> [`develop/hoppscotch/openapi/project-history.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/project-history.yaml)
