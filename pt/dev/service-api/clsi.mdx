O CLSI (Common LaTeX Service Interface) compila projetos, executa SyncTeX e texcount na saída da compilação e converte documentos com pandoc. O web o chama; os arquivos de saída são servidos pelo clsi-nginx, não por esta porta. Sem autenticação: só é acessível dentro da rede Docker.

* <strong>Endereço:</strong> `http://clsi:3013`, dentro da rede Docker
* <strong>Autenticação:</strong> nenhuma
* <strong>Arquivo OpenAPI:</strong> [`develop/hoppscotch/openapi/clsi.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/clsi.yaml)
