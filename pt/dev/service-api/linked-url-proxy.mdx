title: linked-url-proxy
icon: link
---

Busca uma URL externa para o web e devolve a resposta em streaming, recusando endereços internos para que os usuários não alcancem a rede Docker. O web envia por ele os arquivos de URL, as importações do Open in Overleaf e o web_fetch do agente de IA.

* <strong>Endereço:</strong> `http://linked-url-proxy:3066`, dentro da rede Docker
* <strong>Autenticação:</strong> nenhuma
* <strong>Arquivo OpenAPI:</strong> [`develop/hoppscotch/openapi/linked-url-proxy.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/linked-url-proxy.yaml)
