Armazena o chat do projeto e os tópicos de comentários (suas mensagens e o estado de resolvido) nas coleções do Mongo `rooms` e `messages`. É chamado pelo web por meio de `ChatApiHandler`.

* <strong>Endereço:</strong> `http://chat:3010`, dentro da rede Docker
* <strong>Autenticação:</strong> nenhuma
* <strong>Arquivo OpenAPI:</strong> [`develop/hoppscotch/openapi/chat.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/chat.yaml)
