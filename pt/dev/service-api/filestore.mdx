Serve arquivos do armazenamento de objetos: arquivos de modelos (zip, pdf e suas imagens de prévia) e, somente leitura, os blobs de projeto e globais que o history-v1 grava. É chamado pelo web (módulo template-gallery, URLs de arquivos da compilação) e pelo clsi, que baixa dele os arquivos binários do projeto.

* <strong>Endereço:</strong> `http://filestore:3009`, dentro da rede Docker
* <strong>Autenticação:</strong> nenhuma
* <strong>Arquivo OpenAPI:</strong> [`develop/hoppscotch/openapi/filestore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/filestore.yaml)
