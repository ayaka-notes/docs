title: third-party-datastore
icon: cloud-arrow-up
---

Sincroniza projetos com o Dropbox: mantém uma fila de jobs do Redis por usuário e um worker que envia as alterações do Overleaf ao Dropbox e consulta o Dropbox em busca de alterações. Só o web o chama, para enfileirar jobs e ler o tamanho das filas.

* <strong>Endereço:</strong> `http://third-party-datastore:3002`, dentro da rede Docker
* <strong>Autenticação:</strong> nenhuma
* <strong>Arquivo OpenAPI:</strong> [`develop/hoppscotch/openapi/third-party-datastore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/third-party-datastore.yaml)
