Armazena as notificações exibidas aos usuários na lista de projetos (por exemplo, convites para projetos) na coleção do Mongo `notifications`. O web e o third-party-datastore o chamam; não tem autenticação e só é acessível dentro da rede Docker.

* <strong>Endereço:</strong> `http://notifications:3042`, dentro da rede Docker
* <strong>Autenticação:</strong> nenhuma
* <strong>Arquivo OpenAPI:</strong> [`develop/hoppscotch/openapi/notifications.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/notifications.yaml)
