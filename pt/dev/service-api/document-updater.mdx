Mantém no Redis os documentos abertos no editor, aplica as edições a eles e os grava de volta no Mongo por meio do web. É chamado pelo web e pelo real-time.

* <strong>Endereço:</strong> `http://document-updater:3003`, dentro da rede Docker
* <strong>Autenticação:</strong> nenhuma
* <strong>Arquivo OpenAPI:</strong> [`develop/hoppscotch/openapi/document-updater.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/document-updater.yaml)
