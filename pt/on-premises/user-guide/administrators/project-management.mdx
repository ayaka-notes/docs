## Encontrar um projeto {#find-a-project}

Digite em **Search by project name, ID, owner or link**. Um link pode ser o endereço do projeto ou um de seus links de compartilhamento. Use o filtro **Status** para restringir a lista. Clique em **Title** ou **Last modified** para ordenar.

Projetos excluídos não aparecem nos resultados. Se sua pesquisa também corresponder a um deles, uma linha acima da tabela informa isso, por exemplo **Found 1 matching deleted projects**. Clique em **Display deleted projects** para vê-los.

## Status do projeto {#project-status}

Todo projeto tem um status, e o filtro **Status** mostra quantos projetos há em cada um.

<Frame caption="O filtro Status">
  <img src="/images/on-premises/project-management-status-filter.png" alt="O filtro Status com All, Active, Archived, Trashed e Deleted" />
</Frame>

| Status | O que significa |
| --- | --- |
| **All** | Todos os projetos que não foram excluídos. |
| **Active** | O estado normal. |
| **Archived** | O proprietário o arquivou. O projeto está intacto e pode ser recuperado. |
| **Trashed** | O proprietário o moveu para a lixeira. O projeto está intacto e pode ser recuperado. |
| **Deleted** | Excluído pelo proprietário a partir da lixeira, por um administrador ou junto com a conta do proprietário. Apenas um administrador pode recuperá-lo. |

Um projeto passa pelos status em etapas:

1. **Active, Archived e Trashed** são escolhidos pelo proprietário na própria página de projetos. O proprietário sempre pode voltar atrás. **Restore** a partir da lixeira sempre leva a Active, mesmo que o projeto estivesse arquivado antes.
2. **Deleted** é a próxima etapa. O proprietário só pode excluir a partir da lixeira; um administrador pode excluir a partir de qualquer um dos três.
3. **Restore** traz um projeto excluído de volta como **Active**, qualquer que fosse seu status, e seu nome recebe `(Restored)` no final. Apenas um administrador pode fazer isso. Se a conta do proprietário também estiver excluída, restaure a conta primeiro: caso contrário, a caixa de diálogo informa **The owner of this project is deleted: restore the owner first**.
4. **Delete permanently** é a última etapa e não pode ser desfeita. Fora isso, projetos excluídos permanecem até que você os remova, a menos que a instância defina [`ENABLE_CRON_RESOURCE_DELETION`](/pt/on-premises/configuration/overleaf-toolkit/environment-variables), que os remove após 90 dias.

<Info>

O status segue apenas o proprietário. Quando um colaborador arquiva um projeto compartilhado ou o move para a lixeira, ele muda apenas na página de projetos desse colaborador, e o status aqui continua o mesmo.

</Info>

## Ações em um projeto {#actions-on-a-project}

| Ícone | Ação | O que faz |
| --- | --- | --- |
| Abrir | **Open Project** | Abre o projeto no editor, em uma nova aba. |
| Pasta | **Change project owner** | Passa o projeto para outro usuário. |
| Lixeira | **Delete** | Move o projeto para **Deleted**. |
| Seta | **Restore** | Recupera um projeto excluído. Apenas para projetos excluídos. |
| Lixeira riscada | **Delete permanently** | Remove definitivamente um projeto excluído. Apenas para projetos excluídos. |

### Alterar o proprietário {#change-the-owner}

Clique no ícone de pasta, digite um nome ou e-mail, escolha o usuário e clique em **Change project owner**. A caixa de diálogo avisa que isso não pode ser desfeito e que o novo proprietário será notificado e poderá alterar as configurações de acesso do projeto. Contas desativadas não são oferecidas. Se você alterar o texto depois de escolher, a escolha é cancelada: escolha o usuário novamente.

<Frame caption="Alterar o proprietário de um projeto">
  <img src="/images/on-premises/project-management-change-owner.png" alt="A caixa de diálogo Change project owner com um aviso e um novo proprietário escolhido" />
</Frame>

Para mover todos os projetos de um usuário de uma vez, veja [Transferir os projetos de um usuário](/pt/on-premises/user-guide/administrators/user-management#transfer-a-users-projects).

### Excluir, restaurar ou excluir permanentemente {#delete-restore-or-permanently-delete}

Clique no ícone de lixeira e depois em **Delete**. Para encontrar o projeto novamente, escolha **Deleted** no filtro **Status**.

<Frame caption="Um projeto excluído">
  <img src="/images/on-premises/project-management-deleted.png" alt="Um projeto excluído na lista com os ícones Restore e Delete permanently" />
</Frame>

Clique no ícone de seta e depois em **Restore** para recuperá-lo, ou na lixeira riscada e depois em **Delete permanently** para removê-lo.

<Frame caption="Excluir um projeto permanentemente">
  <img src="/images/on-premises/project-management-purge.png" alt="A caixa de diálogo Delete permanently avisando que a ação não pode ser desfeita" />
</Frame>

### Alterar vários projetos de uma vez {#change-several-projects-at-once}

Marque os projetos na lista. Botões aparecem ao lado da pesquisa: **Download**, **Change project owner** e **Delete**. **Download** salva os projetos selecionados em um único arquivo `.zip`. Com **Change project owner**, os proprietários atuais dos projetos marcados não podem ser escolhidos. Na visualização **Deleted**, os botões são **Restore** e **Delete permanently**.

<Frame caption="Ações em massa">
  <img src="/images/on-premises/project-management-bulk.png" alt="Dois projetos marcados e os botões Download, Change project owner e Delete" />
</Frame>

## A página do projeto {#the-project-page}

Clique no título de um projeto para abrir sua página. No topo estão os ícones para editar, abrir, baixar e excluir o projeto. Ela tem cinco abas.

### Visão geral {#overview}

Os detalhes e as configurações do projeto. Clique no ícone de lápis para alterar **Name**, **Link sharing**, **Compiler**, **TeX Live version** e **Main document**, ou para clicar em **Change project owner**. Depois clique em **Save**.

<Frame caption="Editar um projeto">
  <img src="/images/on-premises/project-management-edit.png" alt="A aba Overview no modo de edição" />
</Frame>

### Árvore de arquivos {#file-tree}

Os arquivos e pastas do projeto, somente leitura.

<Frame caption="Os arquivos de um projeto">
  <img src="/images/on-premises/project-management-files.png" alt="A aba File tree listando frog.jpg, main.tex e um arquivo bib restaurado" />
</Frame>

### Membros {#members}

Quem tem acesso: o proprietário, os colaboradores e os convites pendentes. Clique no ícone de lápis para alterá-los:

* Escolha **Editor**, **Reviewer** ou **Viewer** para um colaborador. A alteração vale imediatamente.
* Clique na lixeira ao lado de um colaborador e depois em **Remove access**.
* Para um convite pendente, clique no envelope para **Resend invite**, ou na lixeira para **Revoke Invite**.

Clique em **Done** quando terminar. O proprietário não pode ser alterado aqui: use **Change project owner** na aba **Overview**.

<Frame caption="Alterar os membros de um projeto">
  <img src="/images/on-premises/project-management-members.png" alt="A aba Members no modo de edição com um menu de função, um convite pendente e os ícones de ação" />
</Frame>

### Arquivos excluídos {#deleted-files}

Arquivos removidos do projeto. Clique no ícone de seta ao lado de um arquivo e depois em **Restore file**. Uma cópia com a data no nome vai para a pasta raiz do projeto, e a linha mostra o nome dela. O arquivo excluído continua na lista.

A cópia aparece na aba **File tree** depois que você recarrega a página.

  <img src="/images/on-premises/project-management-deleted-files.png" alt="A aba Deleted files mostrando sample.bib e o nome de sua cópia restaurada" />
