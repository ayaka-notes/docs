Clique em **Admin** e depois em **Manage Site**. O **Admin Panel** tem três abas: **System Messages**, **Open Sockets** e **Open/Close Editor**.

## Mensagens do sistema {#system-messages}

Uma mensagem do sistema é um banner azul no topo da página **Projects** e do editor. Todos os usuários a veem.

### Publicar uma mensagem {#post-a-message}

Digite o texto em **Message** e clique em **Post Message**. A aba lista as mensagens que estão sendo exibidas agora.

<Frame caption="Duas mensagens publicadas">
  <img src="/images/on-premises/basic-management-posted.png" alt="A aba System Messages listando duas mensagens publicadas acima do campo Message, do botão Post Message e do botão Clear all messages" />
</Frame>

<Frame caption="O que os usuários veem">
  <img src="/images/on-premises/basic-management-user-projects.png" alt="A página Projects de um usuário com as duas mensagens como banners azuis no topo" />
</Frame>

* Um usuário pode fechar uma mensagem com o <strong>×</strong>. Ela permanece fechada naquele navegador.
* Uma página já aberta verifica novas mensagens a cada 15 minutos. Recarregar a página as mostra imediatamente.

### Remover mensagens {#remove-messages}

**Clear all messages** remove todas as mensagens de uma vez e não pede confirmação. Não é possível remover uma única mensagem.

## Sockets abertos {#open-sockets}

Uma visão de diagnóstico das conexões de saída que o serviço web tem abertas neste momento. Ela não mostra quem está online: a lista pode estar vazia enquanto há usuários no editor.

## Fechar o editor para manutenção {#close-the-editor-for-maintenance}

Use a aba **Open/Close Editor**. Seus botões agem imediatamente e não pedem confirmação, e a aba não mostra se o editor está fechado. Para verificar, clique em **Projects**: você vê a página **Maintenance** enquanto ele estiver fechado.

<Frame caption="A aba Open/Close Editor">
  <img src="/images/on-premises/basic-management-open-close.png" alt="A aba Open/Close Editor com os botões Close Editor, Disconnect all users e Reopen Editor" />
</Frame>

<Steps>
<Step id="tell-your-users" title="Avise seus usuários">
[Publique uma mensagem](/pt/on-premises/user-guide/administrators/basic-management#post-a-message) com o horário da manutenção.
</Step>

<Step id="click-close-editor" title="Clique em Close Editor">
Apesar do nome, isso fecha quase o site inteiro. Todas as páginas, exceto o painel de administração, mostram **Maintenance**, incluindo **Projects**, **Account Settings**, **Templates** e a página de login. **Manage Users** e **Project/Object Lookup** continuam funcionando.

<Frame caption="O que os usuários veem enquanto o editor está fechado">
  <img src="/images/on-premises/basic-management-closed-page.png" alt="A página Maintenance informando que a instância está em manutenção no momento" />
</Frame>

Usuários que já estão com o editor aberto continuam conectados. Eles podem continuar digitando e suas alterações são mantidas, mas **Recompile** termina com **Server Error**.

Para alterar o texto desta página, veja [Página de manutenção](/pt/on-premises/configuration/overleaf-toolkit/branding#maintenance-page).
</Step>

<Step id="click-disconnect-all-users" title="Clique em Disconnect all users">
Os usuários no editor veem a caixa de diálogo **Please wait**, que faz uma contagem regressiva a partir de 10 segundos. Depois a página deles é atualizada e mostra **Maintenance**.

<Frame caption="O que os usuários no editor veem">
  <img src="/images/on-premises/basic-management-disconnect-dialog.png" alt="O editor atrás da caixa de diálogo Please wait, que informa que o editor será atualizado automaticamente em 8 segundos" />
</Frame>

Feche o editor primeiro: caso contrário, a atualização leva os usuários de volta direto ao editor.
</Step>

<Step id="do-the-maintenance-then-click-reopen-editor" title="Faça a manutenção e depois clique em Reopen Editor">
Todas as páginas voltam a funcionar imediatamente. Os usuários recarregam a página para continuar.
</Step>
</Steps>

<Warning>

A página de login também fica fechada, então permaneça conectado até reabrir o editor. Se ficar sem acesso, reinicie a instância: o estado fechado fica apenas na memória, então uma reinicialização reabre o editor.

</Warning>

<Info>

No Kubernetes com várias réplicas, **Close Editor** fecha apenas a réplica que atendeu sua requisição. Use o [modo de manutenção](/pt/on-premises/configuration/kubernetes/branding#maintenance-mode) no lugar.

</Info>
