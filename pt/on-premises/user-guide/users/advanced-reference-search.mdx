A pesquisa de referências percorre todos os arquivos `.bib` do seu projeto, para que você encontre uma referência sem lembrar da chave de citação. Não é preciso configurar nada.

Seu projeto precisa de pelo menos um arquivo `.bib`. Você pode enviar um ou importar sua biblioteca do [Zotero](/pt/on-premises/user-guide/users/zotero-integration) ou do [Mendeley](/pt/on-premises/user-guide/users/mendeley-integration).

## Inserir uma citação {#insert-a-citation}

<Steps>
<Step title="Começar uma citação">
Em um arquivo `.tex`, digite `\cite{`. O editor adiciona a chave de fechamento. Abaixo do cursor você vê as chaves de citação e uma caixa azul, **Open advanced reference search**.

<Frame caption="A caixa azul abaixo de uma citação">
  <img src="/images/on-premises/reference-search-hint.png" alt="O editor com \cite{}, a lista de chaves de citação e a caixa azul com um botão Search" />
</Frame>

O botão **Insert citation** da barra de ferramentas e **Insert** seguido de **Citation** também iniciam um `\cite{}` para você. A caixa aparece também para outros comandos de citação, como `\citep`, `\autocite`, `\parencite` e `\textcite`.
</Step>

<Step title="Abrir a pesquisa">
Clique em **Search** na caixa azul ou pressione Ctrl+Espaço entre as chaves. A caixa de diálogo lista todas as entradas, com título, chave de citação, autor, periódico e ano.

<Frame caption="Todas as entradas do projeto">
  <img src="/images/on-premises/reference-search-dialog.png" alt="A caixa de diálogo Search the .bib files in this project listando cinco entradas" />
</Frame>
</Step>

<Step title="Encontrar a entrada">
Digite na caixa de pesquisa. Ela procura na chave de citação, no autor, no título, no periódico e no ano, e destaca o que encontrou. Todas as palavras precisam corresponder, então `turing 1936` encontra o artigo de Turing de 1936. Outros campos, como a editora, não são pesquisados.

<Frame caption="Pesquisa por autor e ano">
  <img src="/images/on-premises/reference-search-filter.png" alt="A caixa de pesquisa com turing 1936 e uma entrada com as correspondências em vermelho" />
</Frame>
</Step>

<Step title="Escolher uma ou mais entradas">
Clique em uma entrada. Ela fica verde e sua chave aparece acima da lista. Para adicionar outra, clique nela ou pesquise novamente: o que você escolheu é mantido. Para remover uma, clique nela novamente ou no <strong>×</strong> ao lado da sua chave.

<Frame caption="Duas entradas escolhidas">
  <img src="/images/on-premises/reference-search-selected.png" alt="As chaves knuth1984 e einstein1905 acima da lista e suas entradas em verde" />
</Frame>
</Step>

<Step title="Clicar em Insert">
As chaves de citação aparecem entre as chaves, separadas por vírgulas. Se o seu documento ainda não tem bibliografia, adicione estas linhas antes de `\end{document}`, usando os nomes dos seus arquivos `.bib` sem a extensão:

```latex
\bibliographystyle{plain}
\bibliography{refs,more}
```

Clique em **Recompile**. As referências aparecem no PDF.

<Frame caption="A citação compilada">
  <img src="/images/on-premises/reference-search-compiled.png" alt="O editor com \cite{knuth1984, einstein1905} e o PDF com as duas referências" />
</Frame>
</Step>
</Steps>

A pesquisa funciona da mesma forma no editor **Visual**.

## Alterar uma citação {#change-a-citation}

<strong>Adicionar uma referência:</strong> coloque o cursor entre as chaves de uma citação existente e abra a pesquisa. **Insert** adiciona as novas chaves depois das que já estão lá.

<strong>Substituir referências:</strong> selecione as chaves no editor e pressione Ctrl+Espaço. As chaves aparecem acima da lista e o botão agora diz **Replace**. Remova as que você não quer, adicione outras e clique em **Replace**. Uma chave que não está em nenhum arquivo `.bib` permanece até você removê-la.

## Usar o teclado {#use-the-keyboard}

| Tecla | O que faz |
| --- | ------------ |
| **Seta para baixo** | Passa da caixa de pesquisa para a lista e depois desce na lista |
| **Seta para cima** | Sobe na lista |
| **Espaço** | Escolhe a entrada ou a remove do que você escolheu |
| **Enter** | Insere o que você escolheu, quando você está na lista |
| **Tab** | Alterna entre a caixa de pesquisa, a lista e os botões |
| **Esc** | Fecha a caixa de diálogo sem alterar nada |

## De onde vêm as entradas {#where-the-entries-come-from}

A pesquisa abrange todos os arquivos `.bib` do projeto, incluindo os importados do Zotero ou do Mendeley. Quando você edita um arquivo `.bib`, a próxima pesquisa encontra as novas entradas.

## Se algo der errado {#if-something-goes-wrong}

| O que você vê | Por quê | O que fazer |
| ------------ | --- | ---------- |
| A lista na caixa de diálogo está vazia | O projeto não tem arquivo `.bib` | Envie um ou crie um |
| Não há caixa azul, e Ctrl+Espaço lista comandos LaTeX | O cursor não está entre as chaves de uma citação | Clique entre as chaves |
| Ctrl+Espaço não faz nada | Seu computador usa esse atalho para outra coisa | Clique em **Search** na caixa azul |
| Uma entrada não é encontrada | A pesquisa abrange apenas chave, autor, título, periódico e ano | Pesquise por um desses campos |
