Os scripts Python são executados no seu navegador, então a saída aparece logo abaixo do editor. Não é preciso configurar nada.

<Steps>
<Step title="Criar um script">
Na árvore de arquivos, clique no ícone **New file**. Digite um nome que termine em `.py` e clique em **Create**.

<Frame caption="Um novo arquivo Python">
  <img src="/images/on-premises/python-runner-new-file.png" alt="A caixa de diálogo Add Files com o nome analysis.py" />
</Frame>

O botão **Run** e um painel de saída aparecem abaixo do editor. Na primeira vez, o botão fica desativado enquanto o Python carrega.
</Step>

<Step title="Executar">
Escreva seu código e clique em **Run**. O que o script imprime aparece no painel de saída. Você não precisa salvar antes.

Os arquivos que o script escreve vão para o seu projeto. Uma mensagem informa quais, por exemplo **results.txt saved to your project**, e o arquivo aparece na árvore de arquivos.

<Frame caption="A saída e um arquivo salvo">
  <img src="/images/on-premises/python-runner-output.png" alt="Um script no editor, sua saída impressa abaixo e a mensagem results.txt saved to your project" />
</Frame>
</Step>

<Step title="Parar um script">
Enquanto um script é executado, **Run** se torna **Stop**. Clique nele para interromper o script. O painel de saída termina com **Execution interrupted**.

<Frame caption="Um script em execução">
  <img src="/images/on-premises/python-runner-stop.png" alt="O botão Stop e a saída de um script em execução" />
</Frame>
</Step>
</Steps>

## Usar uma figura no seu documento {#use-a-figure-in-your-document}

Os gráficos não têm uma janela onde aparecer, então salve-os em um arquivo. Por exemplo:

```python
import matplotlib.pyplot as plt

plt.plot([1, 2, 3], [1, 4, 9])
plt.savefig("figure.png")
```

`figure.png` aparece no seu projeto, pronto para `\includegraphics{figure.png}`.

<Frame caption="Um gráfico salvo">
  <img src="/images/on-premises/python-runner-figure.png" alt="figure.png aberto no editor, com a mensagem figure.png saved to your project" />
</Frame>

## Ler os arquivos do seu projeto {#read-your-project’s-files}

Um script pode abrir os arquivos do seu projeto pelo caminho:

```python
print(open("results.txt").read())
```

## Se algo der errado {#if-something-goes-wrong}

<strong>O script gera um erro.</strong> O erro aparece em vermelho no painel de saída, depois de tudo o que o script imprimiu antes.

<Frame caption="Um erro em um script">
  <img src="/images/on-premises/python-runner-error.png" alt="Texto impresso seguido de um traceback em vermelho" />
</Frame>

<strong>`ModuleNotFoundError: No module named ...`.</strong> Apenas os pacotes incluídos no Pyodide estão disponíveis, e pacotes instalados com `pip` não podem ser usados. NumPy e Matplotlib estão entre os disponíveis, e a mensagem leva à [lista completa](https://pyodide.org/en/stable/usage/packages-in-pyodide.html).
