## Importar um documento {#import-a-document}

Isso cria um novo projeto LaTeX a partir de um documento Word (`.docx`) ou de um arquivo Markdown (`.md`). O nome do projeto vem do nome do arquivo.

<Steps>
<Step title="Abrir a caixa de diálogo de importação">
Na página de projetos, clique em **New project**. Em **Import**, clique em **Word document** ou **Markdown document**.

<Frame caption="O menu New project">
  <img src="/images/on-premises/word-import-menu.png" alt="O menu New project com Word document e Markdown document em Import" />
</Frame>
</Step>

<Step title="Escolher o arquivo">
Clique em **Select .docx file** ou arraste o arquivo para a caixa de diálogo. Para Markdown, o botão é **Select .md file**. A importação começa imediatamente.

<Frame caption="Escolhendo um documento Word">
  <img src="/images/on-premises/word-import-dialog.png" alt="A caixa de diálogo Choose Word document com o botão Select .docx file" />
</Frame>
</Step>

<Step title="Começar a editar">
O novo projeto abre com a mensagem **Document ready for editing**. Clique em **Start editing**.

<Frame caption="A importação terminou">
  <img src="/images/on-premises/word-import-ready.png" alt="A caixa de diálogo Document ready for editing com o botão Start editing" />
</Frame>
</Step>

<Step title="Verificar o resultado">
O documento agora está em `main.tex`, com seus títulos no esboço do arquivo. Clique em **Recompile** para ver o PDF. Verifique a formatação, principalmente tabelas, figuras e citações, que podem precisar de edição.

<Frame caption="O projeto importado">
  <img src="/images/on-premises/word-import-project.png" alt="O projeto importado no editor, com main.tex, o esboço do arquivo e o PDF compilado" />
</Frame>
</Step>
</Steps>

### Se a importação falhar {#if-the-import-fails}

Se o arquivo não puder ser convertido, a caixa de diálogo mostra **Your document couldn't be imported**. Expanda **Conversion error details** para ver o motivo. Nenhum projeto é criado.

<Frame caption="Um documento que não pôde ser importado">
  <img src="/images/on-premises/word-import-error.png" alt="A caixa de diálogo de importação com uma mensagem de erro e Conversion error details" />
</Frame>

A caixa de diálogo só aceita o tipo que você escolheu. Um arquivo `.md` na caixa de diálogo do Word mostra **You can only upload: .docx**.

## Exportar um projeto {#export-a-project}

Abra o projeto e clique no nome dele no topo do editor. Clique em uma destas opções:

| Opção                              | Você recebe                                       |
| ----------------------------------- | --------------------------------------------- |
| <strong>Export as Word document (.docx)</strong> | Um arquivo `.docx` com o nome do projeto        |
| <strong>Export as Markdown (.md)</strong>        | Um arquivo `.zip` com `main.md`                  |
| <strong>Export as HTML (.html)</strong>          | Um arquivo `.zip` com `main.html`                |

O download começa sozinho. A conversão não consegue reproduzir toda a formatação LaTeX, então verifique o resultado.
