---
title: Limites de projeto
icon: list-check
---

| Recurso                                          | Limite                                                                                                                                                                   |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tempo limite de compilação                       | **Padrão:** 180 segundos. Consulte [Atualizar o tempo limite de compilação do projeto](/pt/on-premises/user-and-project-management/project-management) para mais informações sobre como personalizar este valor. |
| Número máximo de arquivos por projeto            | 2000                                                                                                                                                                    |
| Tamanho máximo do material editável por projeto  | **Padrão:** 7 MB. Consulte [Variáveis de ambiente](/pt/on-premises/configuration/overleaf-toolkit/environment-variables) para mais informações sobre como personalizar este valor.           |
| Tamanho máximo de um arquivo de texto editável individual | 2 MB\*                                                                                                                                                                  |
| Tamanho máximo de um upload individual           | 50 MB (configurável via `MAX_UPLOAD_SIZE`)                                                                                                                              |
| Tamanho máximo descompactado de um .zip carregado | 6 × `MAX_UPLOAD_SIZE` (300 MB por padrão)                                                                                                                               |
| Tamanho máximo do projeto                        | Ilimitado†                                                                                                                                                              |
| Número máximo de projetos                        | Ilimitado                                                                                                                                                               |

\* Alguns arquivos maiores podem continuar editáveis em determinadas circunstâncias. No entanto, para garantir que um arquivo continue editável, você deve limitar o seu tamanho a 2 MB ou menos.

† Não há um limite imposto para o tamanho total do projeto. No entanto, você pode encontrar algumas limitações técnicas ao trabalhar com projetos muito grandes. Recomendamos um tamanho máximo de projeto de 500 MB, ou menos de 100 MB se usar a nossa [integração com o Git](https://www.overleaf.com/learn/how-to/Git_integration). Projetos acima destes tamanhos podem funcionar, mas manter-se dentro destes limites proporcionará a melhor experiência.
