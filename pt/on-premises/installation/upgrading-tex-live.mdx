---
title: Atualizando o TeX Live
description: Atualize o TeX Live ou instale pacotes em uma implantação do Overleaf Community Edition.
icon: square-up
---

<Danger>

As instruções a seguir se aplicam **apenas** a instalações do **Community Edition**. Recomendamos fortemente que nossos usuários do Ayakaleaf Pro ativem os [Sandboxed Compiles](/pt/on-premises/configuration/overleaf-toolkit/sandboxed-compiles), pois isso dá aos usuários acesso a imagens do TeX Live quase idênticas às usadas no [overleaf.com](https://www.overleaf.com), além de proporcionar isolamento entre as compilações dos projetos para maior segurança.

</Danger>

Para economizar largura de banda, tanto a imagem do Overleaf Community Edition quanto a do Ayakaleaf Pro vêm apenas com uma instalação mínima do [TeX Live](https://www.tug.org/texlive/). Você pode instalar mais pacotes ou atualizar para uma instalação completa do TeX Live usando o comando [tlmgr](https://www.tug.org/texlive/tlmgr.html) no contêiner `sharelatex`.

#### Entrando no contêiner sharelatex

Para iniciar um shell dentro do contêiner `sharelatex`, execute

```bash
bin/shell
```

Você verá um prompt parecido com este:

```bash
root@309b192d4030:/#
```

Nas instruções a seguir, vamos supor que você está dentro do contêiner.

#### Determinando sua versão atual do TeX Live

O TeX Live é lançado todos os anos por volta do mês de abril. Os passos para usar o `tlmgr` são diferentes dependendo de você estar usando a versão atual ou uma mais antiga. Você pode verificar qual versão do TeX Live está executando com `tlmgr --version`. Por exemplo, esta instalação executa o TeX Live 2021:

```bash
# tlmgr --version
tlmgr revision 59291 (2021-05-21 05:14:40 +0200)
tlmgr using installation: /usr/local/texlive/2021
TeX Live (https://tug.org/texlive) version 2021
```

<Info>

A versão atual do TeX Live pode ser encontrada na [página inicial do TeX Live](https://www.tug.org/texlive/).

</Info>

Se você estiver executando uma versão mais antiga do TeX Live, há duas opções. Uma nova versão da imagem Docker do Overleaf geralmente é lançada pouco depois de um lançamento do TeX Live; você pode esperar por ela e atualizar sua implantação usando o script `bin/upgrade` ou, se preferir manter a versão mais antiga do TeX Live, primeiro precisará dizer ao `tlmgr` para usar um repositório histórico. Você encontrará instruções para isso [aqui](https://www.tug.org/texlive/acquire.html#past).

#### Instalando pacotes

Para obter uma instalação completa do TeX Live, execute este comando dentro do contêiner `sharelatex`:

```text
tlmgr install scheme-full
```

Você também pode instalar pacotes individuais manualmente:

```bash
tlmgr install tikzlings tikzmarmots tikzducks
```

<Warning>

A partir da versão `3.3.0`, executar `tlmgr path add` é novamente **obrigatório** após cada uso de `tlmgr install`, para criar corretamente os links simbólicos de todos os binários no path do sistema.

</Warning>

Há muitos outros comandos disponíveis. Saiba mais com:

```text
tlmgr help
```

Quando terminar, digite `exit` ou pressione Control-D para sair do shell.

#### Salvando suas alterações

As alterações que você acabou de fazer modificaram o contêiner `sharelatex`, mas são efêmeras -- serão perdidas se o Docker Compose recriar o contêiner, por exemplo, ao atualizar a configuração.

Para torná-las persistentes, use `docker commit` para salvar as alterações em uma nova imagem docker:

```bash
cat config/version #5.2.1
docker commit sharelatex sharelatex/sharelatex:5.2.1-with-texlive-full
echo 5.2.1-with-texlive-full > config/version
```

Depois de fazer o commit das alterações, atualize o `config/version` de acordo. Em seguida, execute `bin/up` para recriar o contêiner `sharelatex`.

<Danger>

Você precisará repetir esses passos sempre que [atualizar](https://github.com/overleaf/toolkit/blob/master/doc/upgrading.md) para uma nova versão do Overleaf.

</Danger>
