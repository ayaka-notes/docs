Use o Claude Code ou o Codex para planejar e executar uma implantação do Ayakaleaf Pro. O agente pode pesquisar esta documentação via MCP enquanto trabalha.

O agente auxilia na implantação. Você continua responsável por revisar os comandos e proteger as credenciais.

### Antes de começar

Prepare um servidor Linux compatível com acesso SSH. Revise os [requisitos](/pt/on-premises/getting-started/requirements  "mention") antes de continuar.

<Warning>

Não cole senhas, chaves privadas, tokens ou chaves de licença nos prompts do agente. Revise cada comando antes de executá-lo, especialmente comandos que modificam arquivos, redes ou contêineres.

</Warning>

### Conectar a documentação

Adicione o endpoint MCP da documentação ao seu agente local.

<Tabs>
<Tab title="Claude Code">

```bash wrap
claude mcp add ayakaleaf-pro --scope user --transport http https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>

<Tab title="Codex">

```bash wrap
codex mcp add ayakaleaf-pro --url https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>
</Tabs>

Inicie uma nova sessão depois de adicionar o servidor. Peça ao agente para confirmar que consegue pesquisar a documentação do Ayakaleaf Pro.

### Implantar o Ayakaleaf Pro

Abra um terminal no seu servidor de implantação. Inicie o Claude Code ou o Codex ali. Em seguida, envie este prompt:

```text wrap
Use the Ayakaleaf Pro documentation MCP server to guide this deployment.
First, inspect the requirements and installation guides.
Ask me for missing deployment details before making changes.
Use the Ayakaleaf Toolkit unless the documentation requires another approach.
Before configuring the instance, summarize relevant optional features.
Ask which features and integrations I want to enable.
Include TLS, sandboxed compiles, Git integration, external MongoDB or Redis,
SSO (OIDC, SAML, or LDAP), GitHub Synchronisation, Zotero, S3 storage,
email delivery, branding, and localization when relevant.
Explain each selected option's prerequisites, security impact, and configuration steps.
Keep unselected optional features disabled.
Show each command before running it.
Do not expose, store, or request secrets in chat.
After deployment, verify that the service is healthy and summarize the changes.
```

O agente deve guiá-lo pela configuração do Docker, configuração do Toolkit, obtenção da imagem e inicialização. Siga o guia [using-the-toolkit](/pt/on-premises/installation/using-the-toolkit  "mention") para o fluxo de trabalho canônico.

### Escolher recursos opcionais

Peça ao agente para recomendar apenas recursos adequados ao seu ambiente. As escolhas típicas incluem:

* <strong>Acesso e segurança:</strong> TLS, compilações em sandbox e SSO via OIDC, SAML ou LDAP.
* <strong>Serviços externos:</strong> MongoDB, Redis, armazenamento S3 e envio de e-mails.
* <strong>Colaboração:</strong> integração com Git, GitHub Synchronisation e Zotero.

O agente deve explicar as dependências antes de editar a configuração. Revise [toolkit-settings.md](/pt/on-premises/configuration/overleaf-toolkit/toolkit-settings  "mention") e [authentication](/pt/on-premises/configuration/overleaf-toolkit/authentication  "mention") antes de habilitar integrações em produção.

### Verificar a implantação

Depois que o agente concluir as etapas:

1. Confirme que todos os comandos foram concluídos sem erros.
2. Abra a URL configurada do Ayakaleaf Pro no navegador.
3. Conclua as [6.-post-installation-tasks.md](/pt/on-premises/installation/using-the-toolkit/6.-post-installation-tasks  "mention").

Para uma instalação existente do Community Edition, use o guia [migrate-from-existing.md](/pt/on-premises/installation/migrate-from-existing  "mention") em vez de uma implantação nova.
