Assim como o Overleaf Server Pro, nosso Ayakaleaf Pro é fornecido como um contêiner Docker e é um substituto direto que inclui adicionalmente recursos como SSO via LDAP e SAML2, segurança aprimorada, controle de alterações, comentários, nossa versão otimizada do TeX Live, templates e painel de administração.

* Se você quer apenas testar os recursos do Ayakaleaf Pro ou experimentar a demonstração, pode seguir nosso tutorial [using-the-github-codespace.md](/pt/on-premises/installation/using-the-github-codespace  "mention"). O ambiente de demonstração usa uma instalação mínima do TeX Live, portanto alguns dos seus projetos podem não compilar com sucesso.
* Se você nunca implantou nenhuma versão do Overleaf antes, consulte [Configurar o Docker](/pt/on-premises/installation/setup-docker) para instalar primeiro o Docker Engine e, em seguida, instale o Overleaf [using-the-toolkit](/pt/on-premises/installation/using-the-toolkit  "mention").
* Se você já implantou a Community Edition do Overleaf, consulte [migrate-from-existing.md](/pt/on-premises/installation/migrate-from-existing  "mention") para migrar para o Ayakaleaf Pro.
* Se você prefere usar agentes como Claude ou Codex, pode consultar: [using-claude-or-codex.md](/pt/on-premises/installation/using-claude-or-codex  "mention").
* Se você precisa implantar em um ambiente offline ou air-gapped, consulte: [air-gapped-offline-deployments.md](/pt/on-premises/installation/air-gapped-offline-deployments  "mention").
* Se você já é usuário do Server Pro, abra uma issue para nos avisar antes de migrar para o Ayakaleaf Pro, pois os dados de templates são armazenados em um formato ligeiramente diferente. Teremos muito prazer em ajudar você a migrar do Server Pro para o Ayakaleaf Pro gratuitamente.
* Se algum dia você se cansar do nosso Ayakaleaf Pro e quiser voltar para a Overleaf Community Edition oficial, isso é totalmente suportado. Nenhum dos seus dados será perdido. Para usuários do Overleaf Toolkit oficial, basta remover o arquivo YAML de override. Para usuários do toolkit da ayaka-notes, desative a opção `SERVER_PRO`. Tudo voltará então à Community Edition padrão.

### Requisitos de hardware

Realizamos testes e constatamos que, se você executar o Overleaf em um servidor com 2 núcleos e 2 GB de RAM, seus componentes principais — baseados principalmente em Node.js — consumirão aproximadamente 1 GB de memória. O Redis e o MongoDB podem exigir mais 0,5 GB, enquanto iniciar um contêiner Docker isolado para compilação pode consumir outros 0,3 GB. Isso significa que um servidor com 2 núcleos e 2 GB, na prática, consegue lidar com apenas cerca de uma compilação simultânea por vez.

* Os requisitos mínimos de hardware para instalar o Ayakaleaf Pro são uma CPU de 2 núcleos e 3 GB de RAM.
* Devido ao tamanho da nossa imagem do TeX Live, são necessários pelo menos 40 GB de armazenamento para habilitar a compilação em sandbox.
* Se você quiser instalar o conjunto completo de imagens do TeX Live de 2020 a 2026, certifique-se de ter pelo menos 150 GB de espaço livre em disco.

Aqui estão algumas configurações de hardware recomendadas para diferentes cenários de uso:

| Caso de uso                                                  | Configuração recomendada                                                                                         |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| Uso pessoal, com colaboração ocasional                       | 2 núcleos de CPU, 4 GB de RAM, 80 GB de armazenamento                                                            |
| Equipes pequenas, até 10 usuários com colaboração leve       | 2 núcleos de CPU, 8 GB de RAM, 256 GB de armazenamento                                                           |
| Equipes de médio porte, até 100 usuários                     | 4 núcleos de CPU, 16 GB de RAM, 1 TB de armazenamento                                                            |
| Implantações em larga escala ou universitárias               | Implantação em cluster distribuído, com armazenamento S3; entre em contato conosco se precisar de ajuda na implantação |

### Requisitos de software

Quanto aos requisitos de software, recomendamos usar uma versão recente e estável do Ubuntu (por exemplo, Ubuntu 24.04 em 2025–2026, Ubuntu 22.04 em 2023–2024) junto com a versão estável mais recente do Docker.

<Info>

A estabilidade vem em primeiro lugar: escolha o Ubuntu LTS mais recente que já esteja disponível há algum tempo, e não um que acabou de ser lançado. Por exemplo, em outubro de 2026, o Ubuntu 26.04 não é suportado: ele vem com o kernel Linux 7.0, e o MongoDB se recusa a iniciar nos kernels Linux 6.19 a 7.0.13 ([detalhes](https://www.mongodb.com/docs/manual/administration/production-notes/)); portanto, use o Ubuntu 24.04.

</Info>

Não recomendamos implantar o Ayakaleaf Pro no Windows ou em outros sistemas operacionais não suportados, como o CentOS, pois você pode encontrar problemas de compatibilidade ou problemas inesperados durante a instalação e a operação.

Mas, se você quiser experimentar implantar o Ayakaleaf Pro em sistemas baseados em ARM ou no macOS, convidamos você a compartilhar sua experiência e seu feedback com a comunidade.

### Desempenho do LaTeX

O LaTeX é um programa single-thread, o que significa que ele só consegue utilizar um núcleo de CPU por vez. Ao compilar um único documento, o desempenho é limitado principalmente pela frequência de clock de núcleo único da CPU. Portanto, quanto maior o desempenho de núcleo único da sua CPU, mais rápido você conseguirá compilar um documento. Mais núcleos de CPU só trazem benefícios quando vários usuários estão compilando documentos simultaneamente.

Usando o [template ThuThesis](https://www.overleaf.com/latex/templates/thuthesis-tsinghua-university-thesis-latex-template/cfwgcxtvkbsx) como exemplo, o tempo de compilação é de cerca de 6 segundos em um Intel Core i9-14900K (5,6 GHz), enquanto leva cerca de 13 segundos em uma instância Azure Standard D2as v5 (2 vCPUs, 8 GiB de RAM) equipada com um AMD EPYC 7763 (3,2 GHz).

É claro que o desempenho real de compilação depende da sua configuração de hardware. A maioria das CPUs de servidor não opera em frequências tão altas quanto o 14900K, então você precisará encontrar um equilíbrio entre custo e velocidade de compilação.

Além disso, também realizamos uma análise aprofundada do desempenho de compilação do LaTeX. Se tiver interesse, consulte nosso blog [Overleaf Benchmark: A Deep Research of Concurrent LaTeX Compilation in Overleaf (SaaS and Self-host)](/pt/blog/2026/overleaf-benchmark  "mention").
