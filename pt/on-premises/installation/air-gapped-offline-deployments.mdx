---
title: Implantações air-gapped/offline
description: Implante o Ayakaleaf Pro offline exportando, transferindo e carregando imagens Docker.
icon: block-brick
---

Em geral, não recomendamos implantar o Ayakaleaf Pro em um ambiente offline, pois muitos de seus recursos, como o GitHub Sync e a integração com o Zotero, exigem conexão com a internet.

Se você quiser trabalhar offline, nem sempre será possível acessar o registro `ghcr.io` para baixar as imagens necessárias do `ayakaleaf-pro` e do TeX Live. Isso não é um problema, pois o Docker oferece ferramentas para exportar e importar imagens que ajudarão você em uma implantação offline/air-gapped.

Em linhas gerais, você baixará as imagens necessárias em um dispositivo com conexão à internet, as exportará para um dispositivo portátil (ou as transferirá usando SCP/Rsync) e as importará no servidor air-gapped.

Para isso, você precisará concluir as seguintes etapas:

* Baixe todas as imagens necessárias ( `overleaf-pro`, `git-bridge`, `mongo`, `redis` + quaisquer [imagens do TeX Live](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles#available-tex-live-images) necessárias para uso com [Sandboxed Compiles](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles)) em uma máquina com conexão à internet
  * `docker pull ghcr.io/ayaka-notes/overleaf-pro:6.1.2`
  * `docker pull quay.io/sharelatex/git-bridge:6.1.2` (a tag deve ser a mesma do `overleaf-pro`)
  * `docker pull mongo:6` (altere para a versão real)
  * `docker pull redis:6.2` (altere para a versão real)
  * `docker pull ghcr.io/ayaka-notes/texlive-full:2024.1` (altere para a versão real)
* Em seguida, você precisará exportar **cada uma** das imagens baixadas para um arquivo .tar. Por exemplo, `docker save ghcr.io/ayaka-notes/overleaf-pro:6.1.2 > overleaf-pro:6.1.2.tar`
* Usando o método de sua preferência, transfira os arquivos `.tar` da máquina conectada à internet para o servidor offline/air-gapped
* Para cada um dos arquivos .tar, use o comando `docker load` para carregar a imagem a partir do arquivo .tar. Por exemplo, `docker load < overleaf-pro:6.1.2.tar`
* Por fim, execute o comando `docker images` para visualizar/confirmar que as imagens foram carregadas com sucesso e estão disponíveis

<Danger>

Por padrão, ao executar o comando `bin/up`, o Toolkit tentará baixar automaticamente cada uma das imagens do TeX Live definidas via `ALL_TEX_LIVE_DOCKER_IMAGES` em `config/variables.env`. Como sua implantação é air-gapped, isso falhará -- você pode impedir isso usando `SIBLING_CONTAINERS_PULL=false` em `config/overleaf.rc`.

</Danger>
