O Overleaf é executado no Docker. Você precisa instalar:

* Docker Engine (Docker CE)
* Plugin Docker Compose (`docker compose`, v2)

Estas etapas são voltadas para uma versão LTS recente do Ubuntu (20.04/22.04/24.04).

<Warning>

Evite instalar o `docker.io` a partir do repositório apt padrão do Ubuntu.\
Use o repositório oficial do Docker para obter uma versão recente do Docker e o plugin `docker compose`.

</Warning>

A documentação oficial está disponível em: [https://docs.docker.com/engine/install/ubuntu/](https://docs.docker.com/engine/install/ubuntu/).

<Steps>
<Step title="1) Remover pacotes antigos/conflitantes (se houver)">
Se o Docker tiver sido instalado anteriormente a partir de outra fonte, remova-o primeiro:

```bash wrap
sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-compose-v2 docker-doc podman-docker containerd runc | cut -f1)
```

Este comando é seguro mesmo que alguns pacotes não estejam instalados.
</Step>

<Step title="2) Adicionar o repositório apt oficial do Docker">
Instale os pré-requisitos:

```bash
sudo apt update
sudo apt install -y ca-certificates curl
```

Adicione a chave GPG do Docker:

```bash wrap
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```

Adicione o repositório:

```bash wrap
# Add the repository to Apt sources:
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Signed-By: /etc/apt/keyrings/docker.asc
EOF

sudo apt update
```
</Step>

<Step title="3) Instalar o Docker Engine + plugin Compose">
Instale o Docker e o plugin Compose:

```bash wrap
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

Inicie o Docker na inicialização do sistema:

```bash
sudo systemctl enable --now docker
```
</Step>

<Step title="4) Verificar a instalação">
Estes comandos devem ser executados sem erros:

```bash
docker --version
docker compose version
sudo docker run --rm hello-world
docker ps
```
</Step>

<Step title="5) (Opcional) Executar o Docker sem sudo">
Adicione seu usuário ao grupo `docker`:

```bash
sudo usermod -aG docker $USER
```

Em seguida, **saia da sessão e entre novamente**, ou execute:

```bash
newgrp docker
```

Agora isto deve funcionar sem `sudo`:

```bash
docker ps
```

<Danger>

O grupo `docker` tem acesso equivalente ao root no host.\
Isso é esperado em instalações típicas do Overleaf e é especialmente relevante se você ativar os Sandboxed Compiles.

</Danger>
</Step>
</Steps>
