Nesta seção, executamos o Ayakaleaf Pro localmente no seu Mac com o Docker Desktop e o [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). O guia usa `http://localhost:8080`, mantém os dados no seu diretório pessoal e compila com o TeX Live 2026 em contêineres sandbox.

O Docker Desktop executa a aplicação, o MongoDB, o Redis e o compilador do TeX Live em uma máquina virtual Linux. Você não instala o MongoDB, o Redis nem o MacTeX no próprio macOS.

Use esta configuração para uso pessoal e testes locais. Para um serviço compartilhado sempre ativo, recomendamos o [guia para Linux](/pt/on-premises/installation/using-docker-compose/linux), com HTTPS, backups e controle de acesso. A instância fica indisponível enquanto o Mac está em repouso ou o Docker Desktop está parado; consulte [Manter a instância disponível](/pt/on-premises/installation/using-docker-compose/macos/6.-post-installation-tasks#keep-the-instance-available).

## Antes de começar {#before-you-start}

Você precisa de:

* Uma versão do macOS compatível com o [Docker Desktop for Mac](https://docs.docker.com/desktop/setup/install/mac-install/).
* Git, [Homebrew](https://brew.sh/) e GNU sed. O Toolkit usa opções do GNU sed que o BSD sed embutido no macOS não aceita.
* Recursos suficientes para o macOS e o Docker. Para uma pequena instância local, comece com 4 CPUs e 8 GB de memória alocados ao Docker Desktop. Este é um ponto de partida sugerido, não um mínimo medido.
* Pelo menos 40 GB de armazenamento livre para uma imagem completa do TeX Live, além de espaço para os seus projetos. Verifique tanto o espaço livre no Mac quanto o limite de uso de disco do Docker Desktop. Comece com uma única versão do TeX Live: cada versão adicional precisa de aproximadamente o mesmo espaço.

As imagens da aplicação e do TeX Live são publicadas para `arm64` e `amd64`. No Apple silicon, deixe o Docker escolher a imagem ARM nativa e não force `platform: linux/amd64`.
