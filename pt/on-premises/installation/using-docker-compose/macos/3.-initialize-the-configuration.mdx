---
title: 3. Inicializar a configuração
description: Crie os arquivos de configuração do Toolkit no seu Mac com bin/init.
icon: circle-play
---

No diretório do Toolkit, em um terminal com o GNU sed no `PATH`, execute:

```bash
bin/init
```

`bin/init` cria três arquivos:

| Arquivo | Finalidade |
| --- | --- |
| `config/overleaf.rc` | Configurações do contêiner, a porta publicada e os locais dos dados |
| `config/variables.env` | Configurações e segredos da aplicação |
| `config/version` | A versão da imagem da aplicação |

Ele também gera `OVERLEAF_INVITE_TOKEN_SECRET` em `config/variables.env`. Guarde-o e não publique esse arquivo nem faça commit dele no controle de versão.

Mantenha a versão que o Toolkit seleciona para uma nova instalação. Para alterar a versão de uma instância existente mais tarde, siga [Atualizando sua implantação](/pt/on-premises/maintenance/upgrading-your-deployment).

<Warning>

Se `bin/init` parar com `sed: ... invalid command code`, ele foi executado com o BSD sed do macOS. Uma execução com falha desse tipo pode deixar os três arquivos em `config/` com um `OVERLEAF_INVITE_TOKEN_SECRET` vazio, e executar `bin/init` novamente passa a informar `Config files already exist`. Consulte [Solução de problemas](/pt/on-premises/installation/using-docker-compose/macos/troubleshooting#initialization-fails-with-invalid-command-code).

</Warning>
