O Ayakaleaf Pro é uma imagem Docker gratuita no [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Você não precisa de conta, login nem licença comercial do Overleaf para baixá-la.

Abra `config/overleaf.rc` e defina:

```bash title="config/overleaf.rc"
SERVER_PRO=true
```

Na próxima vez que você executar `bin/up`, o Toolkit baixará `ghcr.io/ayaka-notes/overleaf-pro` na versão indicada em `config/version`, em vez da Overleaf Community Edition oficial.

A imagem é construída para `arm64` e `amd64`, e o Docker escolhe a que corresponde ao seu Mac. No Apple silicon, não adicione `platform: linux/amd64` em um override: a imagem passaria a ser executada sob emulação.
