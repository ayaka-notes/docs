<Steps>
<Step title="Verificar o Git e o Homebrew">
```bash
git --version
brew --version
```

Se o macOS pedir que você instale as Command Line Tools ao executar o Git, instale-as primeiro. Se o Homebrew não estiver instalado, instale-o seguindo as [instruções oficiais](https://brew.sh/).
</Step>

<Step title="Colocar o GNU sed no PATH">
Os scripts do Toolkit usam opções do GNU sed que o BSD sed embutido no macOS rejeita. Instale o [GNU sed](https://formulae.brew.sh/formula/gnu-sed) e coloque-o em primeiro lugar no `PATH` neste terminal:

```bash
brew install gnu-sed
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
sed --version
```

O último comando deve exibir **GNU sed**.

Um alias como `alias sed=gsed` não é suficiente: o Toolkit executa scripts Bash, que não enxergam os aliases do seu shell interativo. Você não precisa substituir `/usr/bin/sed`.

Execute a linha `export PATH=...` novamente em cada novo terminal que você usar para o Toolkit, ou adicione-a ao arquivo de inicialização do seu shell, depois da inicialização do próprio Homebrew.
</Step>

<Step title="Clonar o repositório do Ayakaleaf Toolkit">
Escolha um diretório persistente. Evite `/tmp`, unidades removíveis e pastas sincronizadas com a nuvem, como o iCloud Drive, para o banco de dados ativo e os dados dos projetos. Este guia usa `~/ayakaleaf-toolkit`:

```bash
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

<Warning>

Se o diretório já contiver uma instalação, use-a como está ou escolha outro diretório para uma nova instância. Não inicialize uma nova configuração sobre uma implantação existente.

</Warning>
</Step>
</Steps>
