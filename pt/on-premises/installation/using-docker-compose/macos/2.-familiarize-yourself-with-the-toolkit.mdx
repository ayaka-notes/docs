O Toolkit é o mesmo no macOS e no Linux. Sua estrutura, o diretório `config/` e os comandos `bin/` são descritos em [2. Familiarize-se com o Toolkit](/pt/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) do guia para Linux.

No macOS, tenha em mente três diferenças:

* Execute os scripts a partir de um terminal em que o GNU sed venha primeiro no `PATH`; consulte [1. Baixar o Toolkit](/pt/on-premises/installation/using-docker-compose/macos/1.-download-the-toolkit).
* Inicie o Docker Desktop antes de executar um script que se comunica com o Docker, como `bin/up`, `bin/start` ou `bin/docker-compose`.
* `bin/doctor` inclui verificações herdadas do Overleaf Toolkit oficial. O aviso `This system seems to not be Linux` é esperado no macOS, e o aviso sobre não estar logado em `quay.io` não se aplica à imagem pública `ghcr.io/ayaka-notes/overleaf-pro`. Os demais problemas do relatório continuam sendo relevantes.
