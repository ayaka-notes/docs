---
title: 3. Inicializar a configuração
description: Crie os arquivos de configuração do Toolkit no Ubuntu no WSL 2 com bin/init.
icon: circle-play
---

No diretório do Toolkit no **Ubuntu**, execute:

```bash
bin/init
```

`bin/init` cria três arquivos:

| Arquivo | Finalidade |
| --- | --- |
| `config/overleaf.rc` | Configurações do contêiner, a porta publicada e os locais dos dados |
| `config/variables.env` | Configurações e segredos da aplicação |
| `config/version` | A versão da imagem da aplicação |

Ele também gera `OVERLEAF_INVITE_TOKEN_SECRET` em `config/variables.env`. Guarde-o e não publique esse arquivo nem faça commit dele no controle de versão.

Mantenha a versão que o Toolkit seleciona para uma nova instalação. Para alterar a versão de uma instância existente mais tarde, siga [Atualizando sua implantação](/pt/on-premises/maintenance/upgrading-your-deployment).

<Info>

`bin/init` não sobrescreve uma configuração existente. Se ele informar que os arquivos já existem, inspecione-os antes de continuar. Mantenha `config/` e `data/` ao reiniciar ou atualizar a instância.

</Info>
