O Toolkit é o mesmo que no Linux. Sua estrutura, o diretório `config/` e os comandos `bin/` são descritos em [2. Familiarize-se com o Toolkit](/pt/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) do guia para Linux.

No Windows, tenha em mente estas diferenças:

* Execute os comandos `bin/` no **Bash do Ubuntu**, a partir de `~/ayakaleaf-toolkit`. Os comandos marcados como **PowerShell** são executados no Windows.
* Inicie o Docker Desktop e ative a WSL Integration do Ubuntu antes de usar `bin/up`, `bin/start` ou `bin/docker-compose`.
* Mantenha os arquivos de configuração com finais de linha do Linux (LF). Edite-os com o `nano` no Ubuntu ou com um editor conectado ao WSL. Finais de linha CRLF podem causar erros no Bash.
* `bin/doctor` executa verificações do Linux dentro do Ubuntu. O aviso sobre não estar logado em `quay.io` não se aplica à imagem pública `ghcr.io/ayaka-notes/overleaf-pro`. Os demais avisos ainda precisam de atenção.

```bash
bin/doctor
```
