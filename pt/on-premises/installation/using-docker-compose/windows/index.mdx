Nesta seção, executamos o Ayakaleaf Pro localmente no Windows com o WSL 2, o Ubuntu, o Docker Desktop e o [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). O guia usa `http://localhost:8080`, mantém os dados no diretório pessoal do Ubuntu e ativa as compilações em sandbox.

A aplicação, o MongoDB, o Redis e o TeX Live são executados em contêineres Linux gerenciados pelo Docker Desktop. Execute os comandos do Toolkit no Ubuntu; abra a aplicação no seu navegador do Windows. A [etapa 0](/pt/on-premises/installation/using-docker-compose/windows/0.-setup-wsl-and-docker-desktop) explica como as partes Windows e Linux se encaixam e começa pela instalação do WSL.

Você pode usar o Windows para uma instância local ou mantê-la em execução contínua com as configurações de disponibilidade da etapa 6. Para servidores compartilhados e de produção, recomendamos o [guia para Linux](/pt/on-premises/installation/using-docker-compose/linux), com HTTPS, backups e controle de acesso. O repouso do Windows, o encerramento do Docker Desktop e o desligamento do WSL interrompem esta instância local; consulte [Manter a instância disponível](/pt/on-premises/installation/using-docker-compose/windows/6.-post-installation-tasks#keep-the-instance-available).

## Antes de começar {#before-you-start}

Você precisa de:

* Uma versão do Windows e um processador compatíveis com o [Docker Desktop for Windows](https://docs.docker.com/desktop/setup/install/windows-install/), com a virtualização de hardware ativada. Este guia usa o Windows 11 em x86-64.
* Permissão para ativar o WSL e instalar software. O WSL deve estar na versão 2.1.5 ou posterior, com o Ubuntu sendo executado no modo WSL 2.
* Memória suficiente para o Windows e os contêineres. Para uma pequena instância local, 4 CPUs e 8 GB disponíveis para o Docker são um ponto de partida sugerido, não um mínimo medido.
* Armazenamento livre no disco do Windows que contém os dados do WSL e do Docker. Reserve pelo menos 40 GB para uma configuração completa do TeX Live mais os dados dos projetos; a imagem basic da [etapa 5](/pt/on-premises/installation/using-docker-compose/windows/5.-personalizing-your-instance) é menor e adequada para o teste inicial de implantação. Versões adicionais de imagem precisam de espaço adicional.
* Acesso de rede ao GitHub, ao GitHub Container Registry (`ghcr.io`) e ao Docker Hub para clonar o Toolkit e baixar as imagens.

Os blocos **PowerShell** são executados no Windows. Os blocos **Bash** e os comandos `bin/` são executados no Ubuntu, salvo indicação em contrário. Não execute os scripts do Toolkit no PowerShell nem no Git Bash do Windows.
