<Steps>
<Step title="Instalar as ferramentas de linha de comando">
Execute no **Ubuntu**, usando a senha do Linux que você criou na etapa 0:

```bash
sudo apt update
sudo apt install -y git ca-certificates curl perl gawk openssl
```

O Ubuntu já fornece Bash, GNU sed e coreutils. Diferentemente do macOS, ele não precisa do Homebrew nem de uma instalação separada do GNU sed.
</Step>

<Step title="Clonar o repositório do Ayakaleaf Toolkit">
Mantenha o Toolkit e seus dados no sistema de arquivos Linux do Ubuntu, no seu diretório pessoal:

```bash
cd "$HOME"
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

Evite `/mnt/c`, `/mnt/d`, o OneDrive e diretórios temporários para o banco de dados ativo e os dados dos projetos. Caminhos no sistema de arquivos Linux oferecem as permissões e o comportamento de sistema de arquivos esperados pelos contêineres e evitam a sobrecarga entre sistemas de arquivos; consulte as [orientações da Microsoft sobre sistemas de arquivos](https://learn.microsoft.com/en-us/windows/wsl/filesystems).

<Warning>

Se o diretório já contiver uma instalação, use-a como está ou escolha outro diretório para uma nova instância. Não substitua a configuração nem os dados de uma implantação existente.

</Warning>
</Step>
</Steps>
