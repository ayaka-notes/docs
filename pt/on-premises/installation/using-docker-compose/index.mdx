O Docker Compose em um único servidor é a forma recomendada de implantar o Ayakaleaf Pro. Você o executa por meio do [Toolkit](https://github.com/ayaka-notes/toolkit): um conjunto de scripts que encapsulam o `docker compose` e leem suas configurações de um único diretório `config/`, de modo que `bin/up` substitui `docker compose up`.
