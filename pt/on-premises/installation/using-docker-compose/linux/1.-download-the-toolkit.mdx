### Baixando o Toolkit {#downloading-the-toolkit}

Você instala o Ayakaleaf Pro com o **Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)), um conjunto de scripts que executa o Overleaf no Docker para você.

Por padrão, o Toolkit inicia a Overleaf Community Edition (CE) oficial e gratuita. [4. Obter as imagens do Ayakaleaf Pro](/pt/on-premises/installation/using-docker-compose/linux/4.-get-overleaf-pro-images) muda para o Ayakaleaf Pro com uma única configuração.

<Accordion title="Já usa o Overleaf Toolkit oficial (overleaf/toolkit)?">

Você não precisa reinstalar. Mantenha a sua instalação e siga a última parte de [4. Obter as imagens do Ayakaleaf Pro](/pt/on-premises/installation/using-docker-compose/linux/4.-get-overleaf-pro-images).

</Accordion>

<Steps>
<Step title="Clonar o repositório do Ayakaleaf Toolkit">
Para instalar o toolkit, navegue até o caminho de instalação desejado e clone o repositório do Ayakaleaf Toolkit usando este comando:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
```

<Info>

Para evitar possíveis problemas de permissão, recomendamos instalar o Toolkit no diretório `$HOME` do seu usuário.

</Info>
</Step>

<Step title="Entrar no diretório do toolkit">
Aguarde a conclusão da clonagem e, em seguida, entre no diretório `overleaf-toolkit` recém-criado:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
