### Inicializando a configuração {#initializing-the-configuration}

Vamos inicializar os arquivos de configuração do nosso novo servidor com alguns valores padrão sensatos executando o script incluído `bin/init`.

```text title="Run initialization"
bin/init
```

Este script **não** sobrescreverá nenhum arquivo de configuração existente.

Agora vamos verificar o conteúdo do diretório `config/` usando o comando `ls`:

```text title="List the config directory"
ls config
```

Se tudo tiver sido inicializado com sucesso, você deverá ver três arquivos de configuração: `config/overleaf.rc`, `config/variables.env` e `config/version`. Esses são os principais arquivos de configuração do servidor e permitem personalizar como o seu servidor funciona e como os seus usuários interagem com a sua instância.

| Nome            | Descrição                                                   |
| --------------- | ----------------------------------------------------------- |
| `config/overleaf.rc`   | O arquivo de configuração principal de nível superior, lido pelos scripts do Toolkit. Define como os contêineres são executados, por exemplo o endereço e a porta de escuta (`OVERLEAF_LISTEN_IP`, padrão `127.0.0.1`, e `OVERLEAF_PORT`, padrão `80`). |
| `config/variables.env` | Variáveis de ambiente carregadas no contêiner Docker. Definem como o Overleaf se comporta, por exemplo `OVERLEAF_SITE_URL`. |
| `config/version`       | A versão da imagem Docker a ser usada.                      |

Ele também gera `OVERLEAF_INVITE_TOKEN_SECRET` em `config/variables.env`. Guarde-o, e não publique este arquivo nem o envie para um controle de versão.

<Info>

Por enquanto, basta saber que esses arquivos existem e onde encontrá-los. Mais adiante na documentação, abordaremos cada um dos arquivos em mais detalhes e explicaremos como você pode personalizar sua instância usando-os. Se quiser adiantar-se, você pode ver uma descrição completa desses arquivos de configuração na [página Arquivos e locais](/pt/on-premises/configuration/overleaf-toolkit/files-and-locations).

</Info>
