A maneira mais fácil de testar o nosso Ayakaleaf Pro é usar o GitHub Codespace, onde todas as variáveis de ambiente já vêm pré-configuradas para que você possa usá-lo imediatamente.

<Warning>

Quando você executa contêineres Docker usando o GitHub Codespaces, o Codespace não é desligado automaticamente e continuará sendo **cobrado**. Para as regras de cobrança do GitHub Codespaces, consulte as [regras de cobrança do github codespaces](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces).

Para gerenciar seus GitHub Codespaces, acesse [https://github.com/codespaces](https://github.com/codespaces). Quando não precisar mais dele, exclua seu Codespace o quanto antes.

</Warning>

**Pré-configuramos** os seguintes recursos:

* [x] Compilação LaTeX em sandbox com TeXLive **Basic** (2024-2026)
* [x] Importação/exportação com Pandoc (recurso da plataforma SaaS)
* [x] Executor de scripts Python (recurso da plataforma SaaS)
* [x] Suporte ao Git-Bridge (recurso do Server Pro)
* [x] Pesquisa avançada de referências (recurso da plataforma SaaS)
* [x] Painel de administração (gerenciamento global de usuários/projetos)
* [x] Controle de alterações (com painel de revisão e comentários)
* [x] Histórico completo do projeto (com restauração e download)
* [x] Paleta de símbolos (recurso do Server Pro/plataforma SaaS)

<Warning>

Os GitHub Codespaces padrão oferecem 32 GB de armazenamento. Isso é insuficiente para a nossa instalação `texlive-full`. Para testar a imagem completa, abra um chamado no suporte do GitHub solicitando um Codespace com runners maiores (8 núcleos ou mais).

</Warning>

Sincronização com GitHub, LDAP, OAuth, SSO, integração com Zotero e outros recursos _**não estão configurados**_ neste playground. Você pode consultar as [configurações do Toolkit](/pt/on-premises/configuration/overleaf-toolkit/toolkit-settings) para mais detalhes sobre como configurar esses recursos na sua própria implantação.

<Steps>
<Step title="Criar seu GitHub Codespace">
Clique no botão a seguir para criar seu GitHub Codespace. Em termos de configuração do servidor, **2 núcleos com 8 GB de RAM** geralmente são suficientes para um teste. Se você planeja usar o [**TeX Live Full**](https://github.com/ayaka-notes/texlive-full), recomendamos escolher uma configuração com **8 núcleos e 64 GB**.

[![Abrir no GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/ayakaleaf-pro-playground)
</Step>

<Step title="Inicializar a instância do Overleaf">
Quando seu codespace estiver pronto, execute o seguinte comando no bash para inicializar sua instância do Overleaf.

```bash title="bash"
./init.sh
```

#### Usar a imagem TeXLive Full

Se você tiver acesso a GitHub Codespaces com 8 núcleos/64 GB, poderá usar a imagem TeXLive Full neste playground. Você pode alterar as seguintes variáveis de ambiente no arquivo `toolkit/config/variables.env` para usar a imagem TeXLive Full em vez da imagem TeXLive Basic.

```dotenv wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1, ghcr.io/ayaka-notes/texlive-full:2024.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025, Texlive 2024
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```

Após alterar as variáveis de ambiente, é necessário reiniciar o Toolkit para aplicar as alterações. Você pode executar o seguinte comando para reiniciá-lo.

```bash
cd toolkit && bin/up -d
```
