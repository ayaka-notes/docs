### Migrar do Overleaf Community

#### Caso 01: A partir do Overleaf Toolkit

Se você estiver usando o Overleaf Toolkit oficial para o Overleaf Community, basta adicionar um arquivo chamado `docker-compose.override.yml` com o conteúdo a seguir (ou semelhante) ao diretório `overleaf-toolkit/config`:

```yml title="docker-compose.override.yml"
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:X.x.x # change to specific version
```

Para iniciar sua instância, execute:

```bash
bin/up
```

Pronto! Está tudo configurado. Em seguida, você pode verificar se a sua instância do Ayakaleaf está funcionando corretamente e se é possível acessar a interface web. Quando tudo estiver funcionando, continue com as etapas de [configuração](/pt/on-premises/configuration/overleaf-toolkit) abaixo para ativar recursos avançados como:

* [sandboxed-compiles.md](/pt/on-premises/configuration/overleaf-toolkit/sandboxed-compiles  "mention")
* [authentication](/pt/on-premises/configuration/overleaf-toolkit/authentication  "mention")
* [github-synchronisation.md](/pt/on-premises/configuration/overleaf-toolkit/github-synchronisation  "mention")
* [zotero-integration.md](/pt/on-premises/configuration/overleaf-toolkit/zotero-integration  "mention")

#### Caso 02: A partir de um arquivo Docker Compose

Se você usa um `docker-compose.yml` independente, primeiro migre-o para o Overleaf Toolkit. O Toolkit simplifica a instalação on-premises, as atualizações e a manutenção.

Siga o guia [docker-compose.yml-to-toolkit-migration.md](/pt/on-premises/maintenance/docker-compose.yml-to-toolkit-migration  "mention") para converter sua implantação existente. Preserve sua configuração atual e os caminhos dos volumes de dados durante essa migração.

Depois que a implantação do Toolkit estiver em execução, siga [#from-overleaf-toolkit](/pt/on-premises/installation/migrate-from-existing#from-overleaf-toolkit  "mention") para trocar a imagem pelo Ayakaleaf Pro. Inicie a instância com `bin/up` e, em seguida, verifique se você consegue acessar a interface web.

### Migrar do Overleaf Server Pro

Se você estiver executando atualmente uma instância do [Overleaf Server Pro](https://www.overleaf.com/for/enterprises) com licença comercial e quiser migrar para o Ayakaleaf Pro, saiba que a migração pode exigir algum trabalho adicional, pois certos formatos de dados (`templates`) podem não ser totalmente compatíveis. No entanto, teremos prazer em ajudar. [Abra uma issue](https://github.com/ayaka-notes/ayakaleaf-pro/issues) ou entre em contato conosco pelo e-mail [ayaka-notes@outlook.com](mailto:ayaka-notes@outlook.com), e ajudaremos você a migrar para o Ayakaleaf Pro gratuitamente.

***

### Migrar do Overleaf CEP

Recebemos com frequência perguntas de usuários sobre a possibilidade de migrar do [Overleaf CEP](https://github.com/yu-i-i/overleaf-cep) para o Ayakaleaf Pro. Na maioria dos casos, o Overleaf CEP e o Ayakaleaf Pro oferecem funcionalidades amplamente equivalentes e continuam compatíveis em termos de dados até a versão 6.2.0. Os dois projetos podem lançar recursos em momentos diferentes; por exemplo, podemos incorporar (cherry-pick) um recurso do Overleaf CEP, e vice-versa. Embora nossas implementações de um mesmo recurso possam diferir ligeiramente, em geral não há um motivo convincente para migrar.

Se mesmo assim você quiser migrar para o Ayakaleaf Pro ou experimentá-lo, consulte: [#case-01-from-overleaf-toolkit](/pt/on-premises/installation/migrate-from-existing#case-01-from-overleaf-toolkit  "mention"). O processo de migração é o mesmo.

***

### Migrar do Overleaf SaaS

Infelizmente, migrar da plataforma Overleaf SaaS para uma instância auto-hospedada do Ayakaleaf Pro pode ser consideravelmente mais difícil. No momento, o único método disponível de forma geral é baixar cada projeto como um arquivo ZIP e depois enviá-lo para a sua instância auto-hospedada do Ayakaleaf Pro. Isso transfere apenas os arquivos atuais do projeto, o que significa que você _**perderá**_:

* Todo o histórico do projeto e as revisões anteriores
* Todos os comentários e alterações rastreadas
* Todos os metadados do Git e o histórico de commits
* Todos os vínculos e configurações de sincronização com o GitHub
* Todos os vínculos entre arquivos BibTeX e plataformas de terceiros de gerenciamento de referências

***

### Migrar de um fork do Overleaf de terceiros

O Ayakaleaf Pro pode não oferecer suporte a recursos específicos de um determinado fork do Overleaf de terceiros. Quando um fork diverge significativamente da base de código upstream do Overleaf — ou introduz alterações sem manter a compatibilidade com o upstream —, mesclar as versões posteriores do Overleaf pode se tornar extremamente difícil. Você ainda pode tentar o método de migração descrito acima, mas a compatibilidade não é garantida, e talvez não possamos oferecer assistência ou suporte técnico para migrações a partir de forks não suportados.
