---
title: 0. Preparar o host
description: Verifique o sistema operacional e o SELinux e instale o git antes de configurar o Podman rootless.
icon: server
---

Você não instala o Podman manualmente: [2. Executar o podman-setup](/pt/on-premises/installation/using-podman/2.-run-podman-setup) o instala junto com os outros pacotes necessários. Aqui você apenas verifica o host e instala o `git`, necessário para baixar o Toolkit.

<Steps>
<Step title="Verificar o sistema operacional e o SELinux">
Faça login como o usuário que vai executar o Ayakaleaf Pro, não como `root`, e verifique a distribuição e o modo do SELinux:

```bash title="Check the host"
grep PRETTY_NAME /etc/os-release
getenforce
```

Você deve ver RHEL, Rocky Linux, AlmaLinux ou CentOS Stream na versão 9 ou posterior, e `Enforcing`:

```text
PRETTY_NAME="Rocky Linux 9.9 (Blue Onyx)"
Enforcing
```
</Step>

<Step title="Verificar se você pode usar o sudo">
O `bin/podman-setup --apply` instala pacotes e carrega um módulo do SELinux com `sudo`, e pede sua senha quando precisa:

```bash title="Check sudo"
sudo -v
```

Se isso falhar, peça ao seu administrador para adicionar seu usuário ao grupo `wheel`.
</Step>

<Step title="Instalar o git">
```bash title="Install git"
sudo dnf install -y git
```

<Warning>

Não instale o Docker Engine neste host. O pacote `podman-docker`, que o `bin/podman-setup` instala, fornece o comando `docker`, e o Toolkit trata o host como Podman sempre que o comando `podman` existe.

</Warning>
</Step>
</Steps>
