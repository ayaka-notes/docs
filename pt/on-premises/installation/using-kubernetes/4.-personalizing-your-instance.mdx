---
title: 4. Personalizando sua instância
description: Coloque suas configurações no ConfigMap que substitui o config/variables.env.
icon: square-sliders
---

O ConfigMap `overleaf-env` ocupa o lugar do `config/variables.env` do Toolkit: todas as variáveis de ambiente da [documentação do Toolkit](/pt/on-premises/configuration/overleaf-toolkit/environment-variables) vão aqui, e os segredos vão para o Secret da [etapa 2](/pt/on-premises/installation/using-kubernetes/2.-create-the-namespace-and-secrets).

```yaml title="30-config.yaml" wrap
apiVersion: v1
kind: ConfigMap
metadata:
  name: overleaf-env
  namespace: overleaf
data:
  OVERLEAF_APP_NAME: Ayakaleaf Pro
  OVERLEAF_SITE_URL: http://192.0.2.10:30080      # the address users open; https://... behind TLS
  OVERLEAF_ADMIN_EMAIL: admin@example.com
  # Emails: add the sender and the SMTP server together, see Email delivery
  # All members, so that the driver finds the primary even when mongo-0 is down
  OVERLEAF_MONGO_URL: mongodb://mongo-0.mongo:27017,mongo-1.mongo:27017,mongo-2.mongo:27017/sharelatex?replicaSet=overleaf
  OVERLEAF_REDIS_HOST: redis
  REDIS_HOST: redis
  ENABLED_LINKED_FILE_TYPES: project_file,project_output_file,url
  ENABLE_CONVERSIONS: "true"
  EMAIL_CONFIRMATION_DISABLED: "true"
  # Requests arrive from kube-proxy or your ingress controller, inside the pod network
  OVERLEAF_TRUSTED_PROXY_IPS: loopback,10.244.0.0/16
  # Sandboxed compiles. The HOST_DIR paths are paths ON THE NODE: the hostPath volumes that
  # the Deployment mounts at /var/lib/overleaf/data/{compiles,output,cache}.
  SANDBOXED_COMPILES: "true"
  SANDBOXED_COMPILES_SIBLING_CONTAINERS: "true"
  DOCKER_RUNNER: "true"
  SANDBOXED_COMPILES_HOST_DIR_COMPILES: /srv/overleaf/compiles
  SANDBOXED_COMPILES_HOST_DIR_OUTPUT: /srv/overleaf/output
  SANDBOXED_COMPILES_HOST_DIR_CACHE: /srv/overleaf/cache
  # Each image must be pulled into Docker on every node that can run Ayakaleaf Pro (step 0)
  ALL_TEX_LIVE_DOCKER_IMAGES: ghcr.io/ayaka-notes/texlive-full:2026.1
  ALL_TEX_LIVE_DOCKER_IMAGE_NAMES: TeX Live 2026
  TEX_LIVE_DOCKER_IMAGE: ghcr.io/ayaka-notes/texlive-full:2026.1
```

```bash
kubectl apply -f 30-config.yaml
```

| Variável                                | Defina como                                                                                                                                                     |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_SITE_URL`                     | A URL que os usuários digitam no navegador. Com a NodePort da [etapa 5](/pt/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro), o IP de qualquer nó e a porta `30080`; atrás de um ingress ou balanceador de carga, a URL dele. |
| `OVERLEAF_MONGO_URL`                    | Seu replica set. Use `?replicaSet=` com o nome de `rs.initiate`.                                                                                               |
| `OVERLEAF_REDIS_HOST` e `REDIS_HOST`    | Ambos, para o Service do Redis.                                                                                                                                |
| `OVERLEAF_TRUSTED_PROXY_IPS`            | `loopback` mais as redes a partir das quais seus proxies se conectam. `10.244.0.0/16` é a rede de pods do flannel; use o CIDR de pods do seu cluster.         |
| `SANDBOXED_COMPILES_HOST_DIR_*`         | Os caminhos no nó dos volumes de compilação. Eles precisam corresponder aos volumes `hostPath` da [etapa 5](/pt/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro).                  |

Atrás de HTTPS, defina também `OVERLEAF_SECURE_COOKIE: "true"`, veja [Proxy TLS](/pt/on-premises/configuration/overleaf-toolkit/tls-proxy).

<Info>

Um ConfigMap alterado só chega aos pods em execução após uma reinicialização: `kubectl -n overleaf rollout restart deployment/overleaf`.

</Info>
