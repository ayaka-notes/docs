---
title: 2. Criar o namespace e os segredos
description: Crie o namespace e os segredos de que o Ayakaleaf Pro precisa.
icon: key
---

Tudo fica no namespace `overleaf`:

```bash
kubectl create namespace overleaf
```

O Ayakaleaf Pro lê seus segredos a partir de variáveis de ambiente. Gere-os uma vez e mantenha-os em um Secret:

```bash wrap
HISTORY=$(openssl rand -hex 32)
kubectl -n overleaf create secret generic overleaf-secrets \
  --from-literal=OVERLEAF_INVITE_TOKEN_SECRET="$(openssl rand -base64 32)" \
  --from-literal=OVERLEAF_SESSION_SECRET="$(openssl rand -hex 32)" \
  --from-literal=WEB_API_PASSWORD="$(openssl rand -hex 32)" \
  --from-literal=STAGING_PASSWORD="$HISTORY" \
  --from-literal=V1_HISTORY_PASSWORD="$HISTORY" \
  --from-literal=CRYPTO_RANDOM="$(openssl rand -hex 32)" \
  --from-literal=OT_JWT_AUTH_KEY="$(openssl rand -hex 32)"
```

| Segredo                                        | Por quê                                                                                                                                              |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_INVITE_TOKEN_SECRET`                 | Obrigatório. Sem ele, o pod para com "Missing required secrets". Alterá-lo invalida os convites de projeto pendentes.                                |
| `OVERLEAF_SESSION_SECRET`                      | Assina os cookies de sessão. Sem ele, cada reinicialização do pod desconecta todos os usuários.                                                     |
| `WEB_API_PASSWORD`, `CRYPTO_RANDOM`, `OT_JWT_AUTH_KEY` | Segredos internos. O contêiner os gera a cada inicialização quando estão ausentes; com mais de uma réplica, todas as réplicas precisam compartilhá-los. |
| `STAGING_PASSWORD` e `V1_HISTORY_PASSWORD`     | Segredo interno do histórico; ambos precisam ter o **mesmo** valor.                                                                                  |

<Warning>

Faça backup do Secret (`kubectl -n overleaf get secret overleaf-secrets -o yaml`) junto com os seus dados. Recursos que criptografam tokens no MongoDB também precisam de suas próprias senhas de criptografia neste Secret, por exemplo `GITHUB_TOKEN_CIPHER_PASSWORD` para a [Sincronização com GitHub](/pt/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation).

</Warning>
