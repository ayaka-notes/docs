### Baixando o Toolkit

O Toolkit é compatível tanto com o Server CE quanto com o Ayakaleaf Pro e é o método de instalação recomendado. Usar o Toolkit permitirá que você comece facilmente com o Server CE e faça a atualização para o Ayakaleaf Pro sem complicações, se necessário.

<Info>

O [ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) foi modificado para usar diretamente a imagem overleaf-pro do ghcr, com o TeX Live fornecido pela ayaka-notes. Como alternativa, você pode baixar o overleaf-toolkit oficial.

</Info>

<Steps>
<Step title="Clonar o repositório do Overleaf Toolkit">
Para instalar o toolkit, navegue até o caminho de instalação desejado e clone o repositório do Overleaf Toolkit (@Ayaka-notes) no GitHub usando este comando:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
# official toolkit (Not Recommended)
# git clone https://github.com/overleaf/toolkit.git ./overleaf-toolkit
```

<Info>

Para evitar possíveis problemas de permissão, recomendamos instalar o Toolkit no diretório `$HOME` do seu usuário.

</Info>
</Step>

<Step title="Entrar no diretório do toolkit">
Aguarde a conclusão da clonagem e, em seguida, entre no diretório `overleaf-toolkit` recém-criado:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
