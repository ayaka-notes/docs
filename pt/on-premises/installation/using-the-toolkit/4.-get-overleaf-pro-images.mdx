---
title: 4. Obter as imagens do Ayakaleaf Pro
icon: split
---

O Ayakaleaf Pro é uma imagem Docker gratuita no [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Você não precisa de uma conta nem de login para baixá-la. As imagens são geradas para amd64 e arm64, e o Docker escolhe a que corresponde ao seu servidor.

Abra `config/overleaf.rc` e defina:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

Na próxima vez que você executar `bin/up`, o Toolkit baixará a imagem do Ayakaleaf Pro e a usará no lugar da Overleaf Community Edition oficial. Suas configurações em `config/` continuam funcionando.

<Accordion title="Já usa o Overleaf Toolkit oficial (overleaf/toolkit)?">

Você não precisa reinstalar. Baixe a imagem do Ayakaleaf Pro:

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Em seguida, adicione um arquivo chamado `docker-compose.override.yml` com o seguinte conteúdo ao diretório `overleaf-toolkit/config`:

```yml
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

Na próxima vez que você executar `bin/up`, o Toolkit usará a imagem do Ayakaleaf Pro.

</Accordion>
