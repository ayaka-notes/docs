---
title: 4. Obter as imagens do Ayakaleaf Pro
icon: split
---

O Ayakaleaf Pro é distribuído como uma imagem Docker no registro [ghcr](https://github.com/ayaka-notes/overleaf-pro/pkgs/container/overleaf-pro/), com **acesso aberto** a qualquer pessoa. Disponibilizamos imagens para as arquiteturas amd64 e arm64. Ao baixar a imagem, a versão adequada será selecionada automaticamente com base na arquitetura do seu sistema.

#### Usuários do Toolkit da ayaka-notes

Se você estiver usando o [ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit), o Ayakaleaf Pro pode ser usado como substituto direto da Community Edition, para que você possa manter as suas configurações e personalizações existentes. Ative o Pro no Toolkit editando `config/overleaf.rc` e definindo a variável de ambiente `SERVER_PRO`:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

Na próxima vez que você executar `bin/up`, o Toolkit baixará e usará automaticamente a imagem do Ayakaleaf Pro.

#### Usuários do Toolkit oficial

Se você estiver usando o [overleaf/toolkit](https://github.com/overleaf/toolkit), para obter uma imagem Pro, execute o seguinte comando para baixá-la:

```bash title="Pull Docker Images"
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Em seguida, adicione um arquivo chamado `docker-compose.override.yml` com o seguinte conteúdo ao diretório `overleaf-toolkit/config`:

```yml title="docker-compose.override.yml"
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

Na próxima vez que você executar `bin/up`, o Toolkit baixará e usará automaticamente a imagem do Ayakaleaf Pro.
