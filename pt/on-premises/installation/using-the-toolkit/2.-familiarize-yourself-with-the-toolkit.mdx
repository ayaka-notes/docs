### Dando uma olhada

Agora que você tem uma cópia local do Toolkit, vamos analisar a estrutura do repositório usando o comando `ls`.

```bash title="Run this"
ls -l
```

<Info>

O comando `ls -l` exibe uma listagem detalhada do conteúdo de um diretório, fornecendo informações adicionais sobre os arquivos, como permissões, proprietário e tamanho.

</Info>

Se tudo tiver sido clonado com sucesso, você deverá ver algo assim:

```text
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 bin
-rw-r--r-- 1 fry fry  6465 Aug 30 14:16 CHANGELOG.md
drwxr-xr-x 2 fry fry  4096 Sep  6 12:43 config
drwxr-xr-x 5 fry fry  4096 Aug 30 14:22 data
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 doc
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 lib
-rw-r--r-- 1 fry fry 34520 Aug 30 14:16 LICENSE
-rw-r--r-- 1 fry fry  1178 Aug 30 14:16 README.md
```

<Info>

Todos os arquivos de configuração do usuário encontram-se no diretório `config/`. Este diretório é **excluído** do sistema de controle de versão git, portanto não será alterado ao atualizar o Toolkit.

</Info>

## Estrutura do repositório

| Nome     | Descrição                                                                                                                                                                                                                                               |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `bin`    | Esta pasta contém um conjunto de scripts que ajudam a gerenciar a sua instância do servidor Overleaf. Você pode ler mais sobre esses scripts na seção Comandos abaixo.                                                                                     |
| `config` | Esta pasta contém os seus próprios arquivos de configuração locais.                                                                                                                                                                                                  |
| `lib`    | Esta pasta contém os arquivos de configuração base usados pelo Toolkit.                                                                                                                                                                                        |
| `data`   | Por padrão, esta pasta contém o local de armazenamento do MongoDb, do Redis e do Overleaf. Para mais informações, consulte a seção [Dados persistentes](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/files-and-locations#persistent-data) abaixo. |

<Warning>

Recomendamos **não** alterar diretamente arquivos fora da pasta `/config`. Em vez disso, se precisar fazer alterações, elas podem ser feitas através de variáveis de ambiente definidas em **config/variables.env** ou **config/overleaf.rc**.\
Por exemplo, para definir a imagem do serviço `mongo`, em vez de editar `lib/docker-compose.mongo.yml` diretamente, defina a imagem usando a variável de ambiente `MONGO_IMAGE` em `config/overleaf.rc`. Para mais informações, consulte a página [Configurações do Toolkit](/pt/on-premises/configuration/overleaf-toolkit/toolkit-settings).

</Warning>

<Info>

O Toolkit **não** alterará nenhum dado no diretório `config/` sem a sua permissão.

</Info>
