Respeitamos os direitos autorais, por isso listamos aqui todos os recursos e o código usado neste projeto. Nesta página, fornecemos informações sobre os novos recursos do Ayakaleaf Pro e os direitos autorais do código relacionado.

Salvo indicação em contrário, usamos o Codex da OpenAI para revisão de código e de PRs. Durante esse processo, corrigimos muitos problemas de segurança, e expressamos a eles nossa sincera gratidão. Para mais detalhes, consulte [ayaka-notes/ayakaleaf-pro/pull](https://github.com/ayaka-notes/ayakaleaf-pro/pulls).

### Visão geral {#overview}

Ao longo dos anos, muitos desenvolvedores da comunidade fizeram esforços significativos para melhorar o Overleaf Community Edition. São eles:

* [https://github.com/ertuil/overleaf](https://github.com/ertuil/overleaf)
* [https://github.com/AllanChain/lcpu-overleaf](https://github.com/AllanChain/lcpu-overleaf)
* [https://github.com/yu-i-i/overleaf-cep/](https://github.com/yu-i-i/overleaf-cep/)
* [https://github.com/ayaka-notes/overleaf](https://github.com/ayaka-notes/overleaf)
* [https://github.com/davrot/overleaf\_with\_admin\_extension](https://github.com/davrot/overleaf_with_admin_extension)
* [https://github.com/overleaf/overleaf/pull/1447](https://github.com/overleaf/overleaf/pull/1447) (integração com o GitHub)
* [https://github.com/overleaf/overleaf/pull/1385](https://github.com/overleaf/overleaf/pull/1385) (suporte ao Typst)

Podemos ter usado código relacionado em nosso projeto e gostaríamos de expressar nossa gratidão a eles.

#### Recurso 05: Painel de administração {#features-05-admin-panel}

<Warning>

Quando o seu sistema tiver 1000 usuários ou projetos, o painel de administração exibirá apenas os 1000 usuários ou projetos mais recentes. Use o painel de pesquisa para procurar usuários ou projetos específicos.

</Warning>

Este recurso foi desenvolvido principalmente por [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep). Modificamos parte do código para aprimorá-lo, de modo que você possa:

* Pesquisar usuários pelo backend quando tiver mais de 1000 usuários.
* Pesquisar projetos pelo backend quando tiver mais de 1000 projetos.
* Abrir projetos diretamente no painel de administração de projetos.
* Visualizar e ajustar o limite de tempo de compilação do usuário no painel de administração.
* Redefinir a senha do usuário diretamente no painel de administração.
* Outras melhorias...

#### Recurso 13: Python Runner {#features-13-python-runner}

Este recurso foi desenvolvido pelo Overleaf oficial. Você pode executar scripts Python no seu navegador.

Ele é integrado e não precisa de configuração: abra um arquivo `.py` em um projeto e clique em **Run**. O script é executado com o Pyodide no navegador do usuário, portanto apenas os pacotes integrados do Pyodide estão disponíveis.

* O painel de saída abaixo do editor mostra o que o script imprime (as últimas 100 linhas). Clique em **Stop** para interromper uma execução. Cada execução inicia um Python novo, portanto nada é mantido da execução anterior.
* Antes de cada execução, os arquivos de texto do projeto são copiados para a pasta de trabalho do script, para que o script possa abri-los pelo caminho no projeto, por exemplo `open('data/results.csv')`. Arquivos binários, como imagens e PDFs, não são copiados.
* Os arquivos que o script grava nessa pasta são salvos no projeto no mesmo caminho quando a execução é bem-sucedida, substituindo um arquivo com o mesmo nome. Uma execução com falha não salva nada. Uma execução pode salvar até 50 arquivos, 50 MB por arquivo e 100 MB no total.
* O Matplotlib não tem display: salve os gráficos com `plt.savefig('figure.png')` e, em seguida, inclua a imagem no seu documento LaTeX.
* O Pyodide e seus pacotes (como NumPy, pandas, SciPy e Matplotlib) são servidos pela sua instância, portanto o navegador não precisa de acesso à internet. Pacotes instalados com pip não podem ser usados.

#### Recurso 17: Integração com gerenciadores de referências {#features-17-reference-manager-integration}

Este recurso foi desenvolvido por [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro). A integração com o Zotero foi inicialmente desenvolvida por [davrot](https://github.com/davrot) e [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep); nós a reformulamos com OAuth e adicionamos a integração com o Mendeley (OAuth 2.0) na v6.3.0. Você pode:

* Vincular suas contas do Zotero e do Mendeley nas configurações da conta.
* Importar sua biblioteca pessoal ou uma biblioteca de grupo como um arquivo `.bib` para o seu projeto.
* Atualizar o arquivo `.bib` importado a qualquer momento para mantê-lo atualizado.

Consulte [Integração com Zotero](/pt/on-premises/configuration/overleaf-toolkit/integrations/zotero-integration) e [Integração com Mendeley](/pt/on-premises/configuration/overleaf-toolkit/integrations/mendeley-integration) para a configuração.

#### Recurso 18: API Open in Overleaf {#features-18-open-in-overleaf-api}

Este recurso foi desenvolvido por [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) e é compatível com a API "Open in Overleaf" do overleaf.com. Você pode adicionar um link ou botão "Open in Ayakaleaf" ao seu site, blog ou biblioteca de modelos, para que os visitantes possam abrir um trecho de LaTeX, um arquivo remoto ou um projeto ZIP como um novo projeto na sua instância com um clique. Acesse `/devs` na sua instância para obter detalhes e consulte [Overleaf Import API](/pt/on-premises/configuration/overleaf-toolkit/integrations/overleaf-import-api).

#### Recurso 19: Sincronização com GitLab {#features-19-gitlab-sync}

#### Recurso 20: Sincronização com Dropbox {#features-20-dropbox-sync}

Este recurso foi desenvolvido por [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) na v6.3.1 como prévia antecipada (lançamento oficial na v6.4.0), como a sincronização com Dropbox do overleaf.com. Depois que um usuário vincula sua conta do Dropbox, cada um de seus projetos aparece como uma pasta no seu Dropbox: as alterações feitas no Overleaf são enviadas ao Dropbox, e as alterações feitas no Dropbox voltam para o Overleaf. Consulte [Sincronização com Dropbox](/pt/on-premises/configuration/overleaf-toolkit/integrations/dropbox-synchronisation) para a configuração.
