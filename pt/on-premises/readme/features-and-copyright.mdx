Respeitamos os direitos autorais, por isso listamos aqui todos os recursos e o código usado neste projeto. Nesta página, fornecemos informações sobre os novos recursos do Ayakaleaf Pro e os direitos autorais do código relacionado.

Salvo indicação em contrário, usamos o Codex da OpenAI para revisão de código e de PRs. Durante esse processo, corrigimos muitos problemas de segurança, e expressamos a eles nossa sincera gratidão. Para mais detalhes, consulte [ayaka-notes/ayakaleaf-pro/pull](https://github.com/ayaka-notes/ayakaleaf-pro/pulls).

### Visão geral

Ao longo dos anos, muitos desenvolvedores da comunidade fizeram esforços significativos para melhorar o Overleaf Community Edition. São eles:

* [https://github.com/ertuil/overleaf](https://github.com/ertuil/overleaf)
* [https://github.com/AllanChain/lcpu-overleaf](https://github.com/AllanChain/lcpu-overleaf)
* [https://github.com/yu-i-i/overleaf-cep/](https://github.com/yu-i-i/overleaf-cep/)
* [https://github.com/ayaka-notes/overleaf](https://github.com/ayaka-notes/overleaf)
* [https://github.com/davrot/overleaf\_with\_admin\_extension](https://github.com/davrot/overleaf_with_admin_extension)
* [https://github.com/overleaf/overleaf/pull/1447](https://github.com/overleaf/overleaf/pull/1447) (integração com o GitHub)
* [https://github.com/overleaf/overleaf/pull/1385](https://github.com/overleaf/overleaf/pull/1385) (suporte ao Typst)

Podemos ter usado código relacionado em nosso projeto e gostaríamos de expressar nossa gratidão a eles.

#### Recurso 01: Sistema de templates

Este recurso foi desenvolvido principalmente por [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep). Modificamos parte do código para aprimorá-lo, de modo que você possa:

* Baixar templates diretamente nas páginas de templates.
* Abrir o projeto correspondente ao template.
* Converter para imagens de capa de maior qualidade (e em menos tempo).

#### Recurso 05: Painel de administração

<Warning>

Quando o seu sistema tiver 1000 usuários ou projetos, o painel de administração exibirá apenas os 1000 usuários ou projetos mais recentes. Use o painel de pesquisa para procurar usuários ou projetos específicos.

</Warning>

Este recurso foi desenvolvido principalmente por [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep). Modificamos parte do código para aprimorá-lo, de modo que você possa:

* Pesquisar usuários pelo backend quando tiver mais de 1000 usuários.
* Pesquisar projetos pelo backend quando tiver mais de 1000 projetos.
* Abrir projetos diretamente no painel de administração de projetos.
* Visualizar e ajustar o limite de tempo de compilação do usuário no painel de administração.
* Redefinir a senha do usuário diretamente no painel de administração.
* Outras melhorias...

#### Recurso 16: Chat com IA e assistentes de erros LaTeX

O Ayakaleaf Pro traz um AI Assistant que pode usar os documentos do seu projeto e a seleção atual como contexto para responder a perguntas e sugerir edições para você revisar, enquanto o Error Assistant propõe uma correção direcionada quando você seleciona um erro de compilação LaTeX.
