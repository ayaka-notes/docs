title: Overleaf Server Pro vs. Ayakaleaf Pro
description: O Overleaf Server Pro e a edição Ayakaleaf Pro são ambas versões on-premises do Overleaf. Mas quais são as diferenças?
icon: scale-balanced
---

<Info>

O Ayakaleaf Pro é uma implementação aprimorada do Overleaf Community Edition, que oferece todos os recursos _**premium gratuitamente**_ do Server Pro. Ao contrário do Overleaf Common, disponível em [https://www.overleaf.com/](https://www.overleaf.com/), não temos limitações de tempo de compilação nem exigências de licença quanto ao número de usuários, e você pode hospedar totalmente seus próprios dados, garantindo segurança absoluta.

O Overleaf Server Pro é uma implantação comercial e auto-hospedada do Overleaf, com suporte oficial. Para mais informações sobre o Server Pro, visite [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud).

</Info>

<Warning>

O Overleaf Community Edition destina-se a ambientes em que **todos** os usuários são confiáveis. O Community Edition **não** é adequado para cenários em que o isolamento entre usuários é necessário, pois as Sandbox Compiles não estão disponíveis.

Sem sandbox, as compilações LaTeX são executadas com os mesmos privilégios do contêiner, permitindo acesso ao seu sistema de arquivos, à rede e às variáveis de ambiente. Isso cria um risco de exposição de dados ou de comprometimento do sistema. Compilações sem sandbox só devem ser usadas em ambientes totalmente confiáveis; para implantações multiusuário ou de produção, as Sandbox Compiles são fortemente recomendadas.

Para mais informações sobre Sandbox Compiles, consulte nossa [documentação](/pt/on-premises/configuration/overleaf-toolkit/sandboxed-compiles).

</Warning>

### Suporte da comunidade

Para quem usa uma instância auto-hospedada do Overleaf, o suporte é fornecido pela comunidade por meio das [Issues](https://github.com/ayaka-notes/overleaf-pro/issues) do GitHub.

Para permanecer em uma versão com suporte, você pode confirmar qual versão do Overleaf está executando comparando a saída do comando abaixo com os Image IDs publicados nas notas de versão.

```bash
docker inspect --format '{{.Image}}' sharelatex | awk -F: '{print substr($2, 1, 12)}'
```
