Aqui reunimos as respostas a algumas perguntas frequentes sobre o Ayakaleaf Pro.

### Perguntas básicas

<Accordion title="P01: O Ayakaleaf Pro é uma versão de avaliação gratuita? Ele exige uma licença?">

Não. O Ayakaleaf Pro é totalmente gratuito. Não é uma versão de avaliação e não exige licença.

</Accordion>

<Accordion title="P02: O Ayakaleaf Pro inclui todos os recursos do Overleaf Server Pro?">

Sim. O Ayakaleaf Pro inclui todos os recursos do Overleaf Server Pro, incluindo a integração com o Git-Bridge. Ele também inclui recursos selecionados da plataforma SaaS do Overleaf. Continuamos a desenvolver e a aprimorar o Ayakaleaf Pro.

</Accordion>

<Accordion title="P03: Quanto custa o Overleaf Server Pro?">

O Overleaf Server Pro custa cerca de \$300 por usuário por ano. São necessárias pelo menos 10 licenças, portanto as implantações começam em aproximadamente \$3.000 por ano. Contratos públicos menores nos EUA mostram custos anuais de cerca de \$320–\$370 por usuário. Isso torna o Server Pro caro, especialmente para equipes menores. Consulte [#information-and-price-about-overleaf-server-pro](/pt/on-premises#information-and-price-about-overleaf-server-pro  "mention") para ver compras e preços documentados.

</Accordion>

<Accordion title="P04: Por que o Overleaf Server Pro não inclui sincronização com o GitHub nem recursos de IA?">

O Overleaf Server Pro é amplamente usado por organizações governamentais. Elas o implantam em redes privadas e controlam rigorosamente o acesso. Para proteger dados sensíveis, os recursos incluídos evitam trocar dados com serviços de terceiros. Se você precisar de sincronização com o GitHub, IA ou recursos conectados semelhantes, o Overleaf recomenda uma assinatura da sua plataforma SaaS.

</Accordion>

<Accordion title="P05: O Ayakaleaf Pro é seguro e confiável?">

O Ayakaleaf Pro é de código aberto. Revisamos o código com ferramentas como o Codex Security para reforçar a sua segurança e confiabilidade. Se você não ativar a sincronização de dados com terceiros, os seus dados permanecem no seu servidor. O Ayakaleaf Pro não contém telemetria que envie os seus dados para outro lugar.

</Accordion>

<Accordion title="P06: O Ayakaleaf Pro será mantido a longo prazo?">

Faremos todos os esforços para manter este projeto a longo prazo.

</Accordion>

<Accordion title="P07: O Ayakaleaf Pro está em conformidade com as licenças?">

O Ayakaleaf Pro é um fork comunitário. O seu código e os recursos integrados vêm de contribuições da comunidade. Ele é licenciado sob a AGPL v3. As implantações podem estar em conformidade com esta licença quando cumprem os seus requisitos.

</Accordion>

<Accordion title="P08: Por que o projeto se chama Ayakaleaf Pro?">

O projeto chamava-se originalmente Overleaf Pro em 2024. O desenvolvimento ficou pausado por um tempo e foi retomado no final de 2025. No primeiro trimestre de 2026, o Overleaf renomeou o seu plano de assinatura com IA para Pro. O feedback da comunidade também apontou que o nome Overleaf Pro poderia criar riscos relacionados a marcas registradas e de falsificação de identidade, podendo levar os usuários a pensar que o projeto era oficial.

Renomeamos o projeto para Ayakaleaf Pro para evitar essa confusão. O nome pode ser lido como "Ayaka-notes Overleaf Pro". O mantenedor contribui para o desenvolvimento da comunidade Overleaf desde os seus tempos de estudante, há mais de cinco anos. Essa experiência sustenta o nosso compromisso de manutenção a longo prazo.

</Accordion>

<Accordion title="P09: O que distingue o Ayakaleaf Pro dos editores de LaTeX mais recentes criados com IA?">

Desde 2026, a comunidade de código aberto lançou muitos editores de LaTeX criados com IA, incluindo o OpenAI Prism. O Ayakaleaf Pro mantém os seus dados e serviços no seu próprio servidor. Isso lhe dá controle direto sobre a sua implantação e os seus dados.

Muitos editores experimentais da comunidade não têm um plano de manutenção de longo prazo estabelecido. Plataformas de compilação LaTeX de terceiros também podem deixar de operar quando a sua base de usuários ou receita é insuficiente. O Ayakaleaf Pro disponibiliza todo o código-fonte e permite hospedar por conta própria todos os serviços. Mesmo que a manutenção parasse, o seu serviço auto-hospedado existente poderia continuar funcionando.

</Accordion>

### LaTeX

<Accordion title="P01: As compilações dos projetos LaTeX dos usuários são isoladas? O Shell Escape está ativado?">

Ao ativar as Sandbox Compiles, a compilação de cada usuário é executada num contêiner Docker separado e fica isolada das compilações dos outros usuários. O Shell Escape está ativado por padrão nas Sandbox Compiles.

</Accordion>

<Accordion title="P02: A imagem das Sandbox Compiles é confiável? A compilação pode falhar?">

Aprimoramos a nossa imagem TeX Live Full para Sandbox Compiles ao longo dos últimos três anos. Na maioria dos casos, os projetos que compilam no overleaf.com também compilam corretamente com o Ayakaleaf Pro. Se uma fonte necessária não estiver disponível, carregue essa fonte manualmente no seu projeto.

</Accordion>
