### Entendendo os números de versão do Overleaf

O Overleaf usa números de versão no estilo semântico, no formato **6.X.y**.

* **6.X** representa a série de versões principais. Quando uma nova versão **6.X.0** é lançada, ela se torna a base dessa geração.
* **y** representa atualizações de patch dentro da mesma série principal. As versões seguintes (por exemplo **6.X.1**, **6.X.2**, …) são normalmente atualizações de manutenção construídas sobre a **6.X.0**, contendo correções de bugs, correções de segurança e pequenas melhorias, em vez de grandes mudanças de funcionalidades.

### Versão do Ayakaleaf Pro

Os números de versão do Ayakaleaf Pro estão **totalmente alinhados** com as versões oficiais do Overleaf. Salvo indicação em contrário, todas as versões publicadas são imagens da edição Pro com todas as funcionalidades.

Alinhamos rigorosamente nossas versões com o Overleaf Community Edition. Isso permite que você use plugins de código aberto do Overleaf. Não alteramos as interfaces principais do Overleaf. Portanto, qualquer plugin compatível com a versão `A.X.y` correspondente do Community Edition é totalmente compatível com o Ayakaleaf Pro `A.X.y`.
