Você pode usar o script `bin/logs` para visualizar os logs dos serviços.

Exemplos de uso básico:

```bash
# View the web service logs
bin/logs web

# Show help
bin/logs --help

# View logs for multiple services at once
bin/logs filestore docstore web clsi

# Follow log output (like tail -f)
bin/logs -f filestore docstore web clsi

# Limit the number of lines printed (default 50)
bin/logs -n 50 web

# Show all log lines
bin/logs -n all web

# Redirect output to a file
bin/logs -n all web > web.log
```

Você pode usar o script `bin/logs` para visualizar os logs dos seguintes serviços: `clsi`, `contacts`, `docstore`, `document-updater`, `filestore`, `git-bridge`, `mongo`, `notifications`, `real-time`, `redis`, `spelling`, `tags`, `track-changes`, `web`, `web-api`, `history-v1`, `project-history`.

## Copiando logs

Consulte a documentação original: https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/logging#copying-logs

Copie os arquivos de log do contêiner principal `sharelatex` para o seu computador local:

```bash
docker cp sharelatex:/var/log/overleaf/{service-name}.log {service-name}.log
```

## Persistindo logs

Os contêineres Docker são efêmeros, o que significa que arquivos/diretórios criados dentro do contêiner durante a execução (incluindo arquivos de log) serão descartados se o contêiner for recriado (por exemplo, ao executar `bin/up`). Para manter os arquivos de log entre recriações do contêiner:

* Defina a variável de ambiente `OVERLEAF_LOG_PATH` no arquivo `config/overleaf.rc` usado pelo Toolkit. Ela deve apontar para o diretório no host que será montado (bind mount) no diretório de logs dentro do contêiner `sharelatex`.
* Depois de alterar isso e executar `bin/up -d`, os arquivos de log serão persistidos no host e poderão ser acessados diretamente.

<Warning>

Você deve definir como proprietário do diretório de logs do host usado no bind mount o usuário `www-data` (uid=33) e garantir que as permissões sejam `drwxr-xr-x` (755).

Exemplo:

```bash
chown 33:33 data/overleaf/logs
chmod 755 data/overleaf/logs
```

</Warning>
