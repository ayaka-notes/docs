O Overleaf suporta o envio de e-mails por dois métodos: Simple Mail Transfer Protocol (SMTP) e [Amazon Simple Email Service (SES)](https://aws.amazon.com/ses/). O SMTP pode ser usado se você tiver um servidor de e-mail habilitado no seu localhost escutando conexões locais.

## Vários e-mails por conta {#several-emails-per-account}

<Info>

Este recurso é desenvolvido por [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) e está disponível a partir da v6.4.0.

</Info>

Com o e-mail configurado, a página de configurações lista os e-mails de uma conta em vez do campo de e-mail único. Os usuários adicionam um e-mail digitando um código de 6 dígitos enviado a ele e clicam em **Make primary** para transferir a conta para ele. É assim que alguém mantém a conta quando um endereço vai deixar de existir, como o de uma universidade após a formatura. O [guia do usuário](/pt/on-premises/user-guide/users/multiple-emails) traz as etapas com capturas de tela.

* Somente o e-mail principal faz login e recebe redefinições de senha. Um e-mail secundário não faz nenhuma das duas coisas, então um endereço reatribuído a outra pessoa não consegue assumir a conta.
* Clique em **Make primary** antes que a caixa de correio antiga seja encerrada. Depois disso, um administrador precisa alterar o e-mail em **Admin → Manage Users**.
* Um e-mail principal antigo que nunca foi confirmado é removido quando outro e-mail se torna principal. Um confirmado permanece como e-mail secundário até que o usuário o remova.
* **Make primary** é recusado quando LDAP ou SAML está ativado, porque essas contas não conseguiriam fazer login com o novo e-mail. Veja [Contas e senhas](/pt/on-premises/configuration/overleaf-toolkit/authentication#accounts-and-passwords).
* Sem as configurações de e-mail, o campo de e-mail único permanece.

## Configuração {#configuration}

O e-mail é configurado por meio das seguintes variáveis de ambiente.

#### Configuração do remetente {#sender-configuration}

| Nome                          | Descrição                                                                                                                                          |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | <p>O endereço do remetente, por exemplo <a href="mailto:support@mycompany.com">`'support@mycompany.com'`</a><br /><br />- <strong>Obrigatório</strong>: sim</p> |
| `OVERLEAF_EMAIL_REPLY_TO`     | O endereço de resposta, por exemplo `'noreply@mycompany.com'`                                                                                                  |

#### SMTP {#smtp}

| Nome                                    | Descrição                                                                                                                                                                                                                                                              |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST`              | O nome do host ou endereço IP ao qual se conectar. Precisa estar acessível a partir do contêiner Docker                                                                                                                                                                               |
| `OVERLEAF_EMAIL_SMTP_PORT`              | A porta à qual se conectar                                                                                                                                                                                                                                                   |
| `OVERLEAF_EMAIL_SMTP_SECURE`            | Se `true`, a conexão usará TLS ao se conectar ao servidor. Se `false` ou não definido, o TLS será usado se o servidor suportar a extensão `STARTTLS`. Na maioria dos casos, defina este valor como `true` se estiver se conectando à porta `465`. Para as portas `587` ou `25`, mantenha `false` |
| `OVERLEAF_EMAIL_SMTP_USER`              | O nome de usuário que deve ser usado para autenticação no servidor SMTP                                                                                                                                                                                                 |
| `OVERLEAF_EMAIL_SMTP_PASS`              | A senha associada ao nome de usuário SMTP                                                                                                                                                                                                                           |
| `OVERLEAF_EMAIL_SMTP_TLS_REJECT_UNAUTH` | Se `false`, permite abrir uma conexão com um servidor TLS que use um certificado TLS autoassinado ou inválido                                                                                                                                                                        |
| `OVERLEAF_EMAIL_SMTP_IGNORE_TLS`        | Quando `true` e `OVERLEAF_EMAIL_SMTP_SECURE` for `false`, o TLS não é usado, mesmo que o servidor suporte a extensão `STARTTLS`                                                                                                                                            |
| `OVERLEAF_EMAIL_SMTP_NAME`              | Nome de host opcional para validação TLS caso `OVERLEAF_EMAIL_SMTP_HOST` tenha sido definido como um endereço IP; o padrão é o nome de host da máquina.                                                                                                                                        |
| `OVERLEAF_EMAIL_SMTP_LOGGER`            | Quando `true`, imprime mensagens de log em `web.log`.                                                                                                                                                                                                                        |

#### Interface SMTP do Amazon SES {#amazon-ses-smtp-interface}

Você pode ler mais sobre o uso da interface SMTP do Amazon SES para enviar e-mails [aqui](https://docs.aws.amazon.com/ses/latest/dg/send-email-smtp.html).

| Nome                       | Descrição                                                                                |
| -------------------------- | ------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST` | O nome do host ou endereço IP ao qual se conectar. Precisa estar acessível a partir do contêiner Docker |
| `OVERLEAF_EMAIL_SMTP_PORT` | A porta à qual se conectar                                                                     |
| `OVERLEAF_EMAIL_SMTP_USER` | O nome de usuário que deve ser usado para autenticação no servidor SMTP                   |
| `OVERLEAF_EMAIL_SMTP_PASS` | A senha associada ao nome de usuário SMTP                                             |

#### API do Amazon SES {#amazon-ses-api}

Você pode ler mais sobre o uso da API do Amazon SES para enviar e-mails [aqui](https://docs.aws.amazon.com/ses/latest/dg/send-email-api.html).

| Nome                                   | Descrição                                 |
| -------------------------------------- | ------------------------------------------- |
| `OVERLEAF_EMAIL_AWS_SES_ACCESS_KEY_ID` | A chave de acesso, se estiver usando o AWS SES             |
| `OVERLEAF_EMAIL_AWS_SES_SECRET_KEY`    | A chave secreta, se estiver usando o AWS SES             |
| `OVERLEAF_EMAIL_AWS_SES_REGION`        | Se não for definida, a região padrão é US-EAST-1 |

#### AWS SES com funções de instância {#aws-ses-with-instance-roles}

| Nome                    | Descrição                                                                                                                      |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_DRIVER` | Quando definido como `ses`, o sistema de e-mail usará o método da API do SES e dependerá das funções de instância (instance roles) configuradas para enviar e-mails. |

#### Personalização {#customisation}

| Nome                           | Descrição                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_CUSTOM_EMAIL_FOOTER` | <p>HTML personalizado que é anexado a todos os e-mails. Por exemplo:<br /><br /><strong>Exemplo</strong>: `"<div>This system is run by department x </div> <div> If you have any questions please look at our faq <a href='https://somwhere.com'>here</a></div>"`</p> |
