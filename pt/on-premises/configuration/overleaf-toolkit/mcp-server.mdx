Cada projeto tem um servidor MCP, para que clientes de IA como Claude Code, Codex, Cursor, VS Code ou Gemini CLI possam trabalhar nele: ler e editar seus arquivos, compilá-lo, ler o log do LaTeX, baixar o PDF e responder a comentários.

<Info>

Este recurso foi desenvolvido por [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro). Ele foi introduzido na v6.4.0 e posteriores.

</Info>

### Configuração

O servidor MCP vem com a integração com Git: habilite o [git-bridge](/pt/on-premises/configuration/overleaf-toolkit/git-integration), e o servidor MCP também ficará disponível. Não há mais nada a configurar.

### Conectar um cliente de IA

1. Em **Account Settings**, gere um token de autenticação do Git. O mesmo token é usado para o servidor MCP e para o Git.
2. No editor, abra **Integrations** e clique em **MCP server**. São exibidos o endereço do servidor MCP do projeto, `https://<your-overleaf>/project/<project_id>/mcp`, e como adicioná-lo a cada cliente de IA: copie o comando e substitua `<token>` pelo seu token.

### Uso

Depois de conectado, faça pedidos ao cliente de IA em linguagem natural. Por exemplo:

| Você pede | O cliente de IA usa |
| --- | --- |
| _Corrija os erros de digitação na introdução._ | `read_file`, `edit_file`: as edições aparecem em tempo real no editor |
| _Compile o projeto e corrija os erros de LaTeX._ | `compile`, `get_compile_log`, `edit_file` |
| _Responda aos comentários abertos e depois resolva-os._ | `list_comments`, `reply_to_comment`, `resolve_comment` |
| _Mude para XeLaTeX e baixe o PDF._ | `update_settings`, `compile`, `get_output_file_link` |

### Ferramentas

| Grupo | Ferramentas |
| --- | --- |
| Projeto | `get_clone_info`, `get_settings`, `update_settings`, `list_versions` |
| Arquivos | `list_files`, `read_file`, `edit_file`, `write_file`, `delete_file` |
| Compilação | `compile`, `get_compile_log`, `get_output_file_link`, `word_count` |
| Comentários | `list_comments`, `reply_to_comment`, `resolve_comment`, `reopen_comment` |

As edições feitas com `edit_file` e `write_file` aparecem em tempo real no editor e são mescladas com as dos colaboradores. Para muitos arquivos de uma vez, arquivos binários ou renomeações, o cliente de IA também pode clonar o projeto com Git e fazer push.

### Permissões

O servidor MCP segue as configurações de compartilhamento do projeto, assim como o Git:

* Todos que podem visualizar o projeto podem lê-lo, compilá-lo e baixar seus resultados.
* Apenas o proprietário e os editores podem alterar seus arquivos e configurações.
* Os revisores também podem responder a comentários e resolver ou reabrir os comentários que eles iniciaram.
* Os visualizadores que entraram por meio de um link não podem ver os comentários, assim como no editor.
