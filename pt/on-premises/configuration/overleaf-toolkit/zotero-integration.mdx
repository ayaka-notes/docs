### Configurar a integração com Zotero

1. Abra [este link](https://www.zotero.org/oauth/apps) para criar um cliente OAuth do Zotero (como mostra a imagem)
2. Escolha **Application Type**: **Browser**
3. Configure a Callback URL com o seu `${OVERLEAF_SITE_URL}/user/zotero/oauth/callback`
4. Configure o seu `config/variables.env`

<Frame>
  <img src="/images/on-premises/image-41.png" alt="" width="375" />
</Frame>

```dotenv title="config/variables.env"
#################
#    Zotero     #
#################
# 'zotero' must be in ENABLED_LINKED_FILE_TYPES (set in develop/docker-compose.yml)
ENABLED_LINKED_FILE_TYPES=project_file,project_output_file,url,zotero

# From a Zotero OAuth client (register at https://www.zotero.org/oauth/apps)
# Application Type: Browser 
# Callback URL -> ${OVERLEAF_SITE_URL}/user/zotero/oauth/callback
ZOTERO_CLIENT_ID=
ZOTERO_CLIENT_SECRET=
# Encrypts the Zotero API key in mongo (set in dev to avoid writing a key file
# to /var/lib/overleaf/data, which the dev web container can't create)
# How to generate: `openssl rand -hex 32`
ZOTERO_CIPHER_PASSWORD=dev-zotero-cipher-password
# Optional: route the module's server-side Zotero requests (OAuth + API) through
# an HTTP proxy (must be reachable from the web container; same as github-sync)
# http://10.0.0.1:10808
# (Optional) ZOTERO_PROXY_URL=
```

### Observações

<Warning>

Ao atualizar uma instalação existente com arquivos de bibliografia vinculados ao Zotero para a versão 6.3.0 relançada, siga as [instruções de migração do Zotero / Mendeley](/pt/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention"). Novas instalações não precisam dessa migração.

</Warning>

<Danger>

Como o Ayakaleaf é uma plataforma colaborativa, para melhorar a segurança, a partir da versão 6.3.0, apenas o criador original de um arquivo `bib` de referências poderá atualizar o arquivo importado.

</Danger>

Por exemplo, suponha que o proprietário do projeto, o Usuário A, ative o compartilhamento por link e crie um arquivo `test.bib` no projeto, vinculando-o à sua própria conta do Zotero. Se outro usuário, o Usuário B, acessar o projeto pelo link compartilhado, o Usuário B ainda poderá ler e baixar `test.bib`, mas não poderá atualizar nem reimportar o arquivo do Zotero. Somente o Usuário A, como criador original do arquivo de referências, pode realizar atualizações. Em outras palavras, apenas o criador original do arquivo `.bib` tem permissão para atualizá-lo.
