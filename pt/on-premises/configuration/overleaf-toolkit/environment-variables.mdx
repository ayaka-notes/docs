Esta página descreve as variáveis de ambiente suportadas no arquivo `config/variables.env` em implantações com o Toolkit.

O arquivo `config/variables.env` consiste em definições de variáveis no formato `NAME=value`; linhas que começam com `#` são tratadas como comentários.

<Info>

É necessário recriar os contêineres Docker após alterar qualquer coisa em `overleaf.rc` ou `variables.env`, executando `bin/up`.

</Info>

### Todas as versões

Estas variáveis de ambiente são compatíveis com o Server CE e o Server Pro e oferecem um caminho de migração simples entre essas duas versões on-premises. Elas também podem ser usadas tanto em implantações com o Toolkit quanto com Docker Compose.

<Info>

Anteriormente, estas variáveis de ambiente tinham o prefixo `SHARELATEX_` em vez de `OVERLEAF_`.

</Info>

<Info>

É possível impor restrições de senha aos usuários ao usar o sistema de login do Overleaf (contas locais), e não uma opção de SSO como o LDAP. Para contas SSO, as políticas de senha serão aplicadas pelo seu provedor de identidade ou serviço de diretório, o que também permite o suporte à autenticação multifator.

</Info>
