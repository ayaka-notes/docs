Cada integração vem desativada por padrão, exceto a API de importação do Overleaf. As sincronizações com GitHub, GitLab, Gitea e Dropbox e o servidor MCP também exigem a [integração com Git](/pt/on-premises/configuration/overleaf-toolkit/integrations/git-integration). Depois de ativar uma delas, recrie os contêineres com `bin/up -d`.
