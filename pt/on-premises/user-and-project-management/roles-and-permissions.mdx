### Conta

Do ponto de vista do gerenciamento da própria conta, **todos** os usuários são tratados como usuários comuns — `Site Admins` e `Template Users` **não** recebem nenhuma permissão adicional. No entanto, há restrições sobre as ações que os usuários comuns podem realizar, dependendo da forma como se autenticam.

#### Configurações

**Tipos de autenticação: contas internas | SSO (SAML/LDAP)**

| Ação                                    | Contas internas | SSO (SAML/LDAP) |
| ----------------------------------------- | ----------------: | --------------: |
| Atualizar informações da conta                       |               Sim |              Não |
| Alterar senha                           |               Sim |              Não |
| Gerar tokens de autenticação do Git bridge |               Sim |             Sim |
| Excluir tokens de autenticação do Git bridge   |               Sim |             Sim |
| Gerenciar sessões                           |               Sim |             Sim |

<Info>

A integração com o Git Bridge está disponível **somente** no Server Pro. Consulte [Server Pro vs. Community Edition](/pt/on-premises/readme/ayakaleaf-pro-vs-server-pro) para mais informações.

</Info>

#### Suas sessões

| Ação               | Usuário |
| -------------------- | ---: |
| Limpar sessões       |  Sim |
| Ver a sessão atual |  Sim |
| Ver outras sessões  |  Sim |

### IDE do editor

Do ponto de vista da IDE do editor do Overleaf, você pode ter uma das seguintes funções: `Project Owner`, `Editor`, `Reviewer`, `Viewer`, `Site Administrator` ou `Template User`.

<Info>

No Server Pro e no Community Edition, há suporte para fornecer acesso anônimo de **somente leitura** e de **leitura e escrita** aos projetos.

Para mais informações sobre isso, consulte as variáveis de ambiente `OVERLEAF_ALLOW_PUBLIC_ACCESS` e `OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` [aqui](/pt/on-premises/configuration/overleaf-toolkit/environment-variables).

</Info>
