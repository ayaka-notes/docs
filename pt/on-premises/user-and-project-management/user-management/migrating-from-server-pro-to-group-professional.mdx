---
title: Migrar do Server Pro para o Group Professional
icon: rectangle-pro
noindex: true
---

Mudar de uma instância auto-hospedada do Server Pro para uma nova assinatura do Overleaf Group Professional baseada na nuvem é uma grande mudança, por isso reunimos as orientações a seguir para tornar este processo o mais tranquilo possível.

Em geral, propomos um período de sobreposição de três meses a partir da sua data de renovação. Isso significa que:

* A sua instância existente do Server Pro e a sua nova assinatura do Group Professional estarão ambas totalmente ativas.
* A sua equipe técnica pode reservar tempo para configurar a assinatura do Group Professional e decidir o futuro da sua implantação on-premises do Server Pro.
* Mais importante ainda, os seus usuários terão tempo de sobra para copiar os seus projetos para a nova plataforma Overleaf Group Professional.

Este guia rápido apresentará as principais etapas desta migração. Vamos começar!

<Steps>
<Step title="Fase 1: Instalação e configuração">
(Link: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-1-setup-and-configuration)

* O Overleaf criará a sua assinatura do Group Professional e adicionará o seu administrador principal.
* O administrador do seu grupo poderá ativar os [Managed Usersarrow-up-right](https://docs.overleaf.com/groups/user-management/managed-user-accounts), configurar o [Single Sign-On (SSO)arrow-up-right](https://docs.overleaf.com/groups/overleaf-group-single-sign-on/setting-up-group-sso) e [convidar os usuários finaisarrow-up-right](https://docs.overleaf.com/groups/user-management/how-to-add-and-remove-users).

<Warning>

Ativar os Managed Users e implementar o SSO é uma etapa obrigatória para a conformidade com o FedRAMP® LI-SaaS. Se a sua organização exigir conformidade com o FedRAMP, configure os Managed Users e o SSO antes de convidar os usuários finais.

</Warning>
</Step>

<Step title="Fase 2: Migração de usuários e gerenciamento de dados">
(Link: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-2-user-migration-and-data-management)

Esta é a janela principal de migração, com as seguintes responsabilidades:

#### Usuários finais

* Os usuários devem migrar todos os projetos que desejam manter da sua instância do Server Pro para as suas novas contas no [overleaf.comarrow-up-right](http://overleaf.com/). O processo envolve [exportar os projetosarrow-up-right](https://www.overleaf.com/learn/how-to/Exporting_your_work_from_Overleaf) do Server Pro e [carregá-losarrow-up-right](https://www.overleaf.com/learn/how-to/Uploading_a_project) na sua conta no [overleaf.comarrow-up-right](http://overleaf.com/). Se um usuário ainda não tiver uma conta no [overleaf.comarrow-up-right](http://overleaf.com/), poderá registrar-se em [overleaf.com/registerarrow-up-right](http://overleaf.com/register).

<Warning>

Apenas o código-fonte do projeto (arquivos LaTeX e binários) será transferido por este procedimento de exportação. As configurações existentes do projeto, configurações de compartilhamento, comentários, alterações rastreadas etc. NÃO serão transferidos. Os usuários precisarão convidar novamente os seus colaboradores após a migração.

</Warning>

#### Equipe técnica

* Durante esta fase, a sua equipe técnica deve planejar o tratamento pós-migração da sua instância on-premises do Server Pro e dos seus dados.
* <strong>Backup de dados:</strong> você pode exportar todos os projetos antes da desativação para criar um arquivo que permita ajudar usuários que tenham se esquecido de migrar ou baixar o seu trabalho. Instruções: https://docs.overleaf.com/on-premises/maintenance/data-and-backups/exporting-projects
* <strong>Desativação do Server Pro:</strong> depois de encerrada a janela de migração e desativada a sua chave de licença, você tem duas opções principais para a instância do Server Pro em si (veja a próxima etapa).
</Step>

<Step title="Opções de desativação do Server Pro">
<Steps>
<Step title="Desinstalar completamente o Server Pro">
A desinstalação desativará o Server Pro e removerá o software por completo.
</Step>

<Step title="Mudar para a Community Edition">
A mudança preserva o banco de dados de usuários e projetos, com o histórico completo dos projetos, convertendo a instância do Server Pro para a Community Edition.
</Step>
</Steps>

<Info>

A Community Edition NÃO inclui [Sandboxed Compilesarrow-up-right](https://docs.overleaf.com/on-premises#overview-of-server-pro-and-community-edition) nem [LDAP](/pt/on-premises/configuration/overleaf-toolkit/authentication/ldap-authentication)/[SAML](/pt/on-premises/configuration/overleaf-toolkit/authentication/saml-authentication). Se precisar voltar para a autenticação nativa (nome de usuário/senha), consulte: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-to-ldap-or-saml#going-the-other-way-switching-from-ldap-saml-back-to-native-authentication

Para uma comparação entre o Server CE e o Server Pro, consulte: https://docs.overleaf.com/on-premises/welcome/server-pro-vs.-community-edition

</Info>
</Step>

<Step title="Fase 3: Desativação do Server Pro">
(Link: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-3-server-pro-decommission)

* A equipe do Overleaf desativará formalmente a sua chave de licença do Server Pro e enviará uma confirmação quando o processo estiver concluído.
* Nesse momento, execute uma das ações de desativação descritas acima: desinstalar completamente o Server Pro ou mudar para a Community Edition.
</Step>
</Steps>

Os recursos adicionais e os links mencionados acima permanecem inalterados.
