### Sistemas operacionais

Para a melhor experiência ao executar o Overleaf, recomendamos fortemente o uso de um sistema operacional **baseado em Debian**, como o **Ubuntu**. Essa escolha está alinhada ao ambiente de desenvolvimento do software e é a opção preferida pela maioria dos usuários do Overleaf.

<Danger>

Ao usar o Server Pro com Sandboxed Compiles, é **importante** observar que a aplicação requer acesso root ao socket do Docker.

</Danger>

### Dependências

* Docker 25.0 e 29
* MongoDB 7.0 e 8.0
* Redis 6.2 e 7.5

<Info>

Você pode acompanhar as datas de fim de vida (EOL) das dependências acima e de outros produtos populares usando o serviço endoflife.date aqui: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

O MongoDB e o Redis são baixados automaticamente pelo `docker compose` ao executar o Server CE ou o Server Pro, a menos que esteja configurado para usar uma instalação diferente.

</Info>

O Toolkit depende dos seguintes programas:

* bash
* Docker

O `docker compose` é obrigatório e geralmente é instalado junto com o Docker.

Recomendamos que você instale a versão mais recente do Docker disponível para o seu sistema operacional.

Depois que o Docker estiver instalado corretamente, você deverá conseguir executar estes comandos sem erros:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2)
docker compose version

# List the running Docker containers on your system
docker ps
```
