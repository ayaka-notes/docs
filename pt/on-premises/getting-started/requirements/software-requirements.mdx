### Sistemas operacionais {#operating-systems}

Recomendamos um sistema **Linux baseado em Debian**, como o **Ubuntu**, para servidores compartilhados e de produção. O Ayakaleaf Pro também pode ser executado no [macOS com Docker Desktop](/pt/on-premises/installation/using-docker-compose/macos) e no [Windows com WSL 2 e Docker Desktop](/pt/on-premises/installation/using-docker-compose/windows). As três plataformas usam contêineres Linux e o mesmo Toolkit; siga o guia do sistema operacional do seu host.

<Danger>

Ao usar Sandboxed Compiles, é **importante** observar que a aplicação requer acesso root ao socket do Docker.

</Danger>

### Dependências {#dependencies}

* Docker 25.0 e 29
* MongoDB 7.0 e 8.0
* Redis 6.2 e 7.5

<Info>

Você pode acompanhar as datas de fim de vida (EOL) das dependências acima e de outros produtos populares usando o serviço endoflife.date aqui: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

O MongoDB e o Redis são baixados automaticamente pelo `docker compose` ao executar o Ayakaleaf Pro, a menos que esteja configurado para usar uma instalação diferente.

</Info>

O Toolkit depende dos seguintes programas:

* bash
* Docker

O `docker compose` é obrigatório e geralmente é instalado junto com o Docker.

Recomendamos que você instale a versão mais recente do Docker disponível para o seu sistema operacional.

Depois que o Docker estiver instalado corretamente, você deverá conseguir executar estes comandos sem erros:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2 or later, such as v5)
docker compose version

# List the running Docker containers on your system
docker ps
```
