### Requisitos para instalar o Server Pro e a Community Edition

<Warning>

Recomendamos fortemente que você execute o Server Pro numa versão recente e estável do Ubuntu (por exemplo, Ubuntu 24.04 em 2025–2026) com uma versão recente do Docker. É possível executar o Server Pro em outros sistemas, mas isso tornará muito mais difícil oferecermos suporte para configurações de Ubuntu/Docker fora do padrão. Também não podemos oferecer suporte para problemas do próprio Docker.

</Warning>
