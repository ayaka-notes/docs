---
title: O que é o Ayakaleaf Toolkit?
icon: toolbox
---

O Ayakaleaf Toolkit é o método de implantação recomendado para instalações on-premises do Community Edition e do Ayakaleaf Pro. Ele foi projetado para funcionar no ambiente mais comum: um único servidor físico ou máquina virtual. O Toolkit usa `docker compose` para gerenciar os contêineres Docker do seu servidor e fornece um conjunto de scripts que encapsulam comandos `docker` para ajudar com a parte mais técnica do gerenciamento de uma versão on-premises do Overleaf.

#### O wrapper `bin/docker-compose`

O script `bin/docker-compose` é um wrapper em torno do `docker compose`. Ele carrega a configuração do diretório `config/` antes de invocar o `docker compose` com os argumentos que foram passados ao script.

Você pode tratar o `bin/docker-compose` como um wrapper transparente para o programa `docker compose` instalado na sua máquina.

Exemplo:

```bash title="Check running containers"
$ bin/docker-compose ps
```

#### Scripts auxiliares

Além do `bin/docker-compose`, o Toolkit fornece scripts práticos para ajudar em tarefas comuns:

* `bin/up`: atalho para `bin/docker-compose up`
* `bin/start`: atalho para `bin/docker-compose start`
* `bin/stop`: atalho para `bin/docker-compose stop`
* `bin/shell`: inicia um shell dentro do contêiner **sharelatex**
* `bin/doctor`: script usado para coletar informações sobre a instalação e a implantação. Consulte a seção "Verificando seu servidor" abaixo
* `bin/mongo`: inicia um shell dentro do contêiner **mongo** e muda para o banco de dados correto (**sharelatex**)
* `bin/backup-config`: cria uma cópia (zip ou tar) da sua configuração atual e a armazena em um diretório de destino de sua escolha
* `bin/logs`: visualiza/acompanha os logs dos serviços
* `bin/error-logs`: visualiza/acompanha os logs de erro dos serviços
* `bin/rename-env-vars-5-0`: script de migração para atualizar variáveis de ambiente em **config/variables.env** (mudança de marca de ShareLaTeX para Overleaf)
* `bin/rename-rc-vars`: script de migração para atualizar variáveis de ambiente em **config/overleaf.rc** (mudança de marca de ShareLaTeX para Overleaf)
* `bin/run-script`: auxiliar para simplificar a execução de scripts armazenados no contêiner **sharelatex**
* `bin/upgrade`: auxilia nas atualizações da instância. O script verifica se há atualizações do Toolkit (via git) e oferece a opção de baixar as alterações, verifica a versão mais recente da imagem Docker e oferece a opção de atualizá-la. Ele fornece confirmação passo a passo, a opção de fazer backup da configuração atual e cuida de parar/iniciar os serviços Docker. Consulte Atualizando sua implantação para mais informações: https://docs.overleaf.com/on-premises/maintenance/upgrading-your-deployment

<Info>

Se preferir executar sua instância sem se conectar aos logs do Docker, você pode executar `bin/up -d` para rodar em modo destacado (detached).

</Info>

#### Verificando seu servidor

O Overleaf Toolkit inclui um script prático chamado `bin/doctor`, que gera um relatório indicando qualquer dependência não atendida.

Antes de continuar, execute o script `bin/doctor` e verifique se tudo está funcionando corretamente:

```bash title="Run Overleaf Doctor"
bin/doctor
```
