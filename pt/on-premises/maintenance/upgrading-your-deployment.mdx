<Danger>

É importante garantir que você faça um [backup consistente](/pt/on-premises/maintenance/data-and-backups#performing-a-consistent-backup) **antes** de cada atualização de versão principal, para poder reverter caso seja necessário.

</Danger>

O [ayakaleaf toolkit↗](https://github.com/ayaka-notes/toolkit) é um repositório git, portanto é fácil obter novos recursos do Toolkit. Basta executar o comando `bin/upgrade` e seguir as instruções na tela.

Vale observar que a versão da imagem Docker (em `config/version`) é gerenciada separadamente das atualizações do código do Toolkit. Atualizar o código do Toolkit **não** altera automaticamente a versão da imagem Docker em execução. Isso significa que, na maioria dos casos, você pode atualizar a versão do Toolkit sem atualizar sua implantação.

#### O script `bin/upgrade`

Ao executar o comando `bin/upgrade`, o script verificará se há uma atualização disponível para o código do Toolkit e oferecerá atualizá-lo. Você sempre pode recusar essa atualização, e nada será alterado.

Se você optar por atualizar o código do Toolkit, o script verificará em seguida se a versão _padrão_ da imagem Docker mudou e oferecerá atualizar seu arquivo de versão local (em `config/version`) para corresponder ao novo padrão.

Se você optar por mudar de versão, o script o guiará por um processo de desligamento dos serviços Docker, realização de um backup e reinicialização dos serviços Docker. Seu arquivo de versão antigo será copiado automaticamente para `config/__old-version`, caso você precise reverter para aquela versão das imagens Docker.

<Info>

Para ambientes isolados (air-gapped) que importam imagens Docker manualmente, defina `PULL_BEFORE_UPGRADE=false` no seu arquivo `config/overleaf.rc`.

Consulte [esta página](/pt/on-premises/installation/air-gapped-offline-deployments) para mais informações sobre implantação em ambientes isolados/offline.

</Info>

### Caminho de atualização

Se você estiver executando uma versão do Overleaf Community anterior à v6.0.0, consulte a [documentação oficial do Overleaf](https://docs.overleaf.com/on-premises/maintenance/upgrading-your-deployment#upgrade-path) para concluir a atualização.
