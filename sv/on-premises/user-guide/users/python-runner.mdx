Python-skript körs i din webbläsare, så utdata visas direkt under redigeraren. Inget behöver konfigureras.

<Steps>
<Step title="Skapa ett skript">
Klicka på ikonen **New file** i filträdet. Ange ett namn som slutar på `.py` och klicka på **Create**.

<Frame caption="En ny Python-fil">
  <img src="/images/on-premises/python-runner-new-file.png" alt="Dialogrutan Add Files med namnet analysis.py" />
</Frame>

Knappen **Run** och en utdatapanel visas under redigeraren. Första gången är knappen inaktiverad medan Python läses in.
</Step>

<Step title="Kör det">
Skriv din kod och klicka på **Run**. Det som skriptet skriver ut visas i utdatapanelen. Du behöver inte spara först.

Filer som skriptet skriver hamnar i ditt projekt. Ett meddelande talar om vilka, till exempel **results.txt saved to your project**, och filen visas i filträdet.

<Frame caption="Utdata och en sparad fil">
  <img src="/images/on-premises/python-runner-output.png" alt="Ett skript i redigeraren, dess utskrift nedanför och meddelandet results.txt saved to your project" />
</Frame>
</Step>

<Step title="Stoppa ett skript">
Medan ett skript körs blir **Run** till **Stop**. Klicka på den för att avbryta skriptet. Utdatapanelen slutar med **Execution interrupted**.

<Frame caption="Ett skript som körs">
  <img src="/images/on-premises/python-runner-stop.png" alt="Knappen Stop och utdata från ett skript som körs" />
</Frame>
</Step>
</Steps>

## Använd en figur i ditt dokument {#use-a-figure-in-your-document}

Diagram har inget fönster att visas i, så spara dem i en fil. Till exempel:

```python
import matplotlib.pyplot as plt

plt.plot([1, 2, 3], [1, 4, 9])
plt.savefig("figure.png")
```

`figure.png` visas i ditt projekt, redo för `\includegraphics{figure.png}`.

<Frame caption="Ett sparat diagram">
  <img src="/images/on-premises/python-runner-figure.png" alt="figure.png öppen i redigeraren, med meddelandet figure.png saved to your project" />
</Frame>

## Läs ditt projekts filer {#read-your-project’s-files}

Ett skript kan öppna ditt projekts filer via deras sökväg:

```python
print(open("results.txt").read())
```

## Om något går fel {#if-something-goes-wrong}

<strong>Skriptet ger ett fel.</strong> Felet visas i rött i utdatapanelen, efter allt som skriptet skrev ut innan.

<Frame caption="Ett fel i ett skript">
  <img src="/images/on-premises/python-runner-error.png" alt="Utskriven text följd av en traceback i rött" />
</Frame>

<strong>`ModuleNotFoundError: No module named ...`.</strong> Bara paketen som är inbyggda i Pyodide är tillgängliga, och paket som installerats med `pip` kan inte användas. NumPy och Matplotlib finns bland de tillgängliga, och meddelandet länkar till den [fullständiga listan](https://pyodide.org/en/stable/usage/packages-in-pyodide.html).

<Frame caption="Ett paket som inte är tillgängligt">
  <img src="/images/on-premises/python-runner-missing-package.png" alt="Ett ModuleNotFoundError i utdatapanelen" />
</Frame>
