## Importera ett dokument {#import-a-document}

Detta skapar ett nytt LaTeX-projekt från ett Word-dokument (`.docx`) eller en Markdown-fil (`.md`). Projektets namn hämtas från filnamnet.

<Steps>
<Step title="Öppna importdialogen">
Klicka på **New project** på projektsidan. Under **Import** klickar du på **Word document** eller **Markdown document**.

<Frame caption="Menyn New project">
  <img src="/images/on-premises/word-import-menu.png" alt="Menyn New project med Word document och Markdown document under Import" />
</Frame>
</Step>

<Step title="Välj filen">
Klicka på **Select .docx file** eller dra filen till dialogen. För Markdown heter knappen **Select .md file**. Importen startar direkt.

<Frame caption="Välja ett Word-dokument">
  <img src="/images/on-premises/word-import-dialog.png" alt="Dialogen Choose Word document med knappen Select .docx file" />
</Frame>
</Step>

<Step title="Börja redigera">
Det nya projektet öppnas med meddelandet **Document ready for editing**. Klicka på **Start editing**.

<Frame caption="Importen är klar">
  <img src="/images/on-premises/word-import-ready.png" alt="Dialogen Document ready for editing med knappen Start editing" />
</Frame>
</Step>

<Step title="Kontrollera resultatet">
Dokumentet finns nu i `main.tex`, med rubrikerna i filens disposition. Klicka på **Recompile** för att se PDF:en. Kontrollera formateringen, särskilt tabeller, figurer och citat, som kan behöva redigeras.

<Frame caption="Det importerade projektet">
  <img src="/images/on-premises/word-import-project.png" alt="Det importerade projektet i redigeraren, med main.tex, filens disposition och den kompilerade PDF:en" />
</Frame>
</Step>
</Steps>

### Om importen misslyckas {#if-the-import-fails}

Om filen inte kan konverteras visar dialogen **Your document couldn't be imported**. Expandera **Conversion error details** för att se varför. Inget projekt skapas.

<Frame caption="Ett dokument som inte kunde importeras">
  <img src="/images/on-premises/word-import-error.png" alt="Importdialogen med ett felmeddelande och Conversion error details" />
</Frame>

Dialogen tar bara emot den typ du valde. En `.md`-fil i Word-dialogen visar **You can only upload: .docx**.

## Exportera ett projekt {#export-a-project}

Öppna projektet och klicka sedan på dess namn högst upp i redigeraren. Klicka på något av följande:

| Alternativ                              | Du får                                       |
| ----------------------------------- | --------------------------------------------- |
| <strong>Export as Word document (.docx)</strong> | En `.docx`-fil med projektets namn        |
| <strong>Export as Markdown (.md)</strong>        | En `.zip`-fil med `main.md`                  |
| <strong>Export as HTML (.html)</strong>          | En `.zip`-fil med `main.html`                |

Nedladdningen startar av sig själv. Konverteringen kan inte återge all LaTeX-formatering, så kontrollera resultatet.
