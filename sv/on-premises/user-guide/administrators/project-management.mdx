## Hitta ett projekt {#find-a-project}

Skriv i **Search by project name, ID, owner or link**. En länk kan vara projektets adress eller en av dess delningslänkar. Använd filtret **Status** för att begränsa listan. Klicka på **Title** eller **Last modified** för att sortera.

Borttagna projekt visas inte i resultaten. Om sökningen även matchar ett borttaget projekt anger en rad ovanför tabellen det, till exempel **Found 1 matching deleted projects**. Klicka på **Display deleted projects** för att se dem.

## Projektstatus {#project-status}

Varje projekt har en status, och filtret **Status** visar hur många projekt varje status har.

<Frame caption="Filtret Status">
  <img src="/images/on-premises/project-management-status-filter.png" alt="Filtret Status med All, Active, Archived, Trashed och Deleted" />
</Frame>

| Status | Betydelse |
| --- | --- |
| **All** | Alla projekt som inte är borttagna. |
| **Active** | Normalt läge. |
| **Archived** | Ägaren har arkiverat det. Projektet är intakt och kan hämtas tillbaka. |
| **Trashed** | Ägaren har flyttat det till papperskorgen. Projektet är intakt och kan hämtas tillbaka. |
| **Deleted** | Borttaget av ägaren från papperskorgen, av en administratör eller tillsammans med ägarens konto. Bara en administratör kan hämta tillbaka det. |

Ett projekt går igenom statusarna i steg:

1. **Active, Archived och Trashed** väljer ägaren på sin egen projektsida. Ägaren kan alltid gå tillbaka. **Restore** från papperskorgen leder alltid till Active, även om projektet var arkiverat tidigare.
2. **Deleted** är nästa steg. Ägaren kan bara ta bort från papperskorgen; en administratör kan ta bort från vilken som helst av de tre.
3. **Restore** hämtar tillbaka ett borttaget projekt som **Active**, oavsett tidigare status, och namnet får `(Restored)` i slutet. Bara en administratör kan göra detta. Om även ägarens konto är borttaget återställer du kontot först: annars visar dialogrutan **The owner of this project is deleted: restore the owner first**.
4. **Delete permanently** är det sista steget och kan inte ångras. Annars finns borttagna projekt kvar tills du tar bort dem, om inte instansen anger [`ENABLE_CRON_RESOURCE_DELETION`](/sv/on-premises/configuration/overleaf-toolkit/environment-variables), som tar bort dem efter 90 dagar.

<Info>

Statusen följer bara ägaren. När en medarbetare arkiverar ett delat projekt eller flyttar det till papperskorgen flyttas det bara på medarbetarens egen projektsida, och statusen här förblir densamma.

</Info>

## Åtgärder för ett projekt {#actions-on-a-project}

| Ikon | Åtgärd | Vad den gör |
| --- | --- | --- |
| Öppna | **Open Project** | Öppnar projektet i redigeraren i en ny flik. |
| Mapp | **Change project owner** | Ger projektet till en annan användare. |
| Papperskorg | **Delete** | Flyttar projektet till **Deleted**. |
| Pil | **Restore** | Hämtar tillbaka ett borttaget projekt. Bara för borttagna projekt. |
| Överkorsad papperskorg | **Delete permanently** | Tar bort ett borttaget projekt för gott. Bara för borttagna projekt. |

### Ändra ägaren {#change-the-owner}

Klicka på mappikonen, skriv ett namn eller en e-postadress, välj användaren och klicka sedan på **Change project owner**. Dialogrutan varnar för att detta inte kan ångras och att den nya ägaren får ett meddelande och kan ändra projektets åtkomstinställningar. Inaktiverade konton erbjuds inte. Om du ändrar texten efter att ha valt avbryts valet: välj användaren igen.

<Frame caption="Ändra ett projekts ägare">
  <img src="/images/on-premises/project-management-change-owner.png" alt="Dialogrutan Change project owner med en varning och en vald ny ägare" />
</Frame>

Se [Överför en användares projekt](/sv/on-premises/user-guide/administrators/user-management#transfer-a-users-projects) för att flytta alla en användares projekt på en gång.

### Ta bort, återställ eller ta bort permanent {#delete-restore-or-permanently-delete}

Klicka på papperskorgsikonen och sedan på **Delete**. Välj **Deleted** i filtret **Status** för att hitta projektet igen.

<Frame caption="Ett borttaget projekt">
  <img src="/images/on-premises/project-management-deleted.png" alt="Ett borttaget projekt i listan med ikonerna Restore och Delete permanently" />
</Frame>

Klicka på pilikonen och sedan på **Restore** för att hämta tillbaka det, eller på den överkorsade papperskorgen och sedan på **Delete permanently** för att ta bort det.

<Frame caption="Ta bort ett projekt permanent">
  <img src="/images/on-premises/project-management-purge.png" alt="Dialogrutan Delete permanently som varnar för att åtgärden inte kan ångras" />
</Frame>

### Ändra flera projekt samtidigt {#change-several-projects-at-once}

Markera projekten i listan. Knappar visas bredvid sökningen: **Download**, **Change project owner** och **Delete**. **Download** sparar de valda projekten i en enda `.zip`-fil. Med **Change project owner** kan de markerade projektens nuvarande ägare inte väljas. I vyn **Deleted** är knapparna **Restore** och **Delete permanently**.

<Frame caption="Massåtgärder">
  <img src="/images/on-premises/project-management-bulk.png" alt="Två markerade projekt och knapparna Download, Change project owner och Delete" />
</Frame>

## Projektsidan {#the-project-page}

Klicka på ett projekts titel för att öppna dess sida. Högst upp finns ikonerna för att redigera, öppna, ladda ned och ta bort projektet. Sidan har fem flikar.

### Översikt {#overview}

Projektets uppgifter och inställningar. Klicka på pennikonen för att ändra **Name**, **Link sharing**, **Compiler**, **TeX Live version** och **Main document**, eller för att klicka på **Change project owner**. Klicka sedan på **Save**.

<Frame caption="Redigera ett projekt">
  <img src="/images/on-premises/project-management-edit.png" alt="Fliken Overview i redigeringsläge" />
</Frame>

### Filträd {#file-tree}

Projektets filer och mappar, skrivskyddade.

<Frame caption="Ett projekts filer">
  <img src="/images/on-premises/project-management-files.png" alt="Fliken File tree som listar frog.jpg, main.tex och en återställd bib-fil" />
</Frame>

### Medlemmar {#members}

Vem som har åtkomst: ägaren, medarbetarna och de väntande inbjudningarna. Klicka på pennikonen för att ändra dem:

* Välj **Editor**, **Reviewer** eller **Viewer** för en medarbetare. Ändringen gäller direkt.
* Klicka på papperskorgen bredvid en medarbetare och sedan på **Remove access**.
* För en väntande inbjudan klickar du på kuvertet för **Resend invite**, eller på papperskorgen för **Revoke Invite**.

Klicka på **Done** när du är klar. Ägaren kan inte ändras här: använd **Change project owner** på fliken **Overview**.

<Frame caption="Ändra ett projekts medlemmar">
  <img src="/images/on-premises/project-management-members.png" alt="Fliken Members i redigeringsläge med en rollmeny, en väntande inbjudan och åtgärdsikonerna" />
</Frame>

### Borttagna filer {#deleted-files}

Filer som tagits bort från projektet. Klicka på pilikonen bredvid en fil och sedan på **Restore file**. En kopia med datumet i namnet läggs i projektets rotmapp, och raden visar dess namn. Den borttagna filen finns kvar i listan.

Kopian visas på fliken **File tree** när du har laddat om sidan.

<Frame caption="En återställd fil">
  <img src="/images/on-premises/project-management-deleted-files.png" alt="Fliken Deleted files som visar sample.bib och namnet på dess återställda kopia" />
</Frame>

### Granskningsloggar {#audit-logs}

Vad som har hänt med projektet: datum, åtgärd, vem som utförde den, IP-adress och detaljer. Sök i dem eller filtrera efter **Operation**.
