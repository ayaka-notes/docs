<Info>

Den här funktionen tillhandahålls av [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) med stöd för OAuth 2.0 och är tillgänglig från v6.3.0. Vi välkomnar din feedback om du stöter på problem.

</Info>

#### Konfigurera Mendeley-integrationen

1. Gå till [den här länken](https://dev.mendeley.com/myapps.html) för att registrera en Mendeley OAuth-applikation
2. Ange **Redirect URL** som: `${OVERLEAF_SITE_URL}/user/mendeley/oauth/callback`
3. Anteckna det genererade **ID** (vanligtvis numeriskt, som `24061` nedan) och **Secret** för din applikation
4. Ändra din `config/variables.env`&#x20;
5. Behåll Authorisation Flow: Elsevier (som rekommenderat)

  <img src="/images/on-premises/image-44.png" alt="" />
</Frame>

```dotenv title="config/variables.env"
#################
#   Mendeley    #
#################
# 'mendeley' must be in ENABLED_LINKED_FILE_TYPES (keep 'zotero' too if you use both)
ENABLED_LINKED_FILE_TYPES=project_file,project_output_file,url,mendeley

# From a Mendeley OAuth application (register at https://dev.mendeley.com/myapps.html)
# Redirect URL -> ${OVERLEAF_SITE_URL}/user/mendeley/oauth/callback
MENDELEY_CLIENT_ID=
MENDELEY_CLIENT_SECRET=
# Encrypts the Mendeley OAuth tokens in mongo; if unset, a key file is generated
# in /var/lib/overleaf/data on first use
# How to generate: `openssl rand -hex 32`
MENDELEY_CIPHER_PASSWORD=
# Optional: route the module's server-side Mendeley requests (OAuth + API) through
# an HTTP proxy (must be reachable from the web container; same as github-sync)
# http://10.0.0.1:10808
# (Optional) MENDELEY_PROXY_URL=
```

<Info>

&#x20;`mendeley` måste ingå i `ENABLED_LINKED_FILE_TYPES` (behåll även `zotero` i listan om du använder båda). `MENDELEY_CLIENT_ID` och `MENDELEY_CLIENT_SECRET` kommer från din registrerade OAuth-applikation. Chifferlösenordet krypterar Mendeleys OAuth-tokens i MongoDB (generera ett med `openssl rand -hex 32`); utan det genereras en nyckelfil i datavolymen vid första användningen. Du kan även ange `MENDELEY_PROXY_URL` för att dirigera Mendeley-förfrågningarna på serversidan (OAuth + API) via en HTTP-proxy som är nåbar från webbcontainern.

</Info>

### Anmärkningar

<Warning>

När du uppgraderar en befintlig installation med länkade Mendeley-bibliografifiler till den återutgivna 6.3.0, följ [migreringsanvisningarna för Zotero / Mendeley](/sv/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention"). Nya installationer behöver inte denna migrering.

</Warning>

<Danger>

Eftersom Ayakaleaf är en samarbetsplattform får, för att förbättra säkerheten, från och med version 6.3.0 endast den ursprungliga skaparen av en referensfil (`bib`) uppdatera den importerade filen.

</Danger>

Anta till exempel att projektägaren, användare A, aktiverar länkdelning och skapar en fil `test.bib` i projektet som är länkad till hens eget Zotero-konto. Om en annan användare, användare B, öppnar projektet via den delade länken kan användare B fortfarande läsa och ladda ned `test.bib`, men får inte uppdatera eller återimportera filen från Zotero. Endast användare A, som den ursprungliga skaparen av referensfilen, kan utföra uppdateringar. Med andra ord har endast den ursprungliga skaparen av `.bib`-filen behörighet att uppdatera den.
