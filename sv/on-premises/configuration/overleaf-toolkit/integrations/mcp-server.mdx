Varje projekt har en MCP-server, så att AI-klienter som Claude Code, Codex, Cursor, VS Code eller Gemini CLI kan arbeta med det: läsa och redigera dess filer, kompilera det, läsa LaTeX-loggen, ladda ned PDF-filen och svara på kommentarer. Från v6.3.3 kan de också gå igenom historiken och återställa versioner, granska spårade ändringar, lägga till kommentarer, använda projektchatten och flytta filer.

<Info>

Den här funktionen är utvecklad av [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro). Den introducerades i v6.3.1 och finns i senare versioner. Verktygen för historik, spårade ändringar, projektchatt, nya kommentarer och flytt av filer finns från v6.3.3, se [Nytt i v6.3.3](/sv/on-premises/user-guide/users/mcp-server#new-in-v6.3.3).

</Info>

### Konfiguration {#setup}

MCP-servern ingår i Git-integrationen: aktivera [git-bridge](/sv/on-premises/configuration/overleaf-toolkit/integrations/git-integration), så blir MCP-servern också tillgänglig. Inget annat behöver konfigureras.

### Anslut en AI-klient {#connect-an-ai-client}

1. Generera en autentiseringstoken för Git i **Kontoinställningar**. Samma token används för MCP-servern och för Git.
2. Öppna **Integrationer** i redigeraren och klicka på **MCP-server**. Där visas adressen till projektets MCP-server, `https://<your-overleaf>/project/<project_id>/mcp`, och hur du lägger till den i varje AI-klient: kopiera kommandot och ersätt `<token>` med din token.

Token skickas som HTTP-huvudet `Authorization: Bearer <token>`. Kommandot för Claude Code är till exempel:

```bash
claude mcp add --transport http overleaf \
  https://<your-overleaf>/project/<project_id>/mcp \
  --header "Authorization: Bearer <token>"
```

### Användning {#usage}

När anslutningen är klar ber du AI-klienten om saker med vanliga ord. Till exempel:

| Du ber om | AI-klienten använder |
| --- | --- |
| _Rätta stavfelen i inledningen._ | `read_file`, `edit_file`: ändringarna syns live i redigeraren |
| _Kompilera projektet och åtgärda LaTeX-felen._ | `compile`, `get_compile_log`, `edit_file` |
| _Svara på de öppna kommentarerna och markera dem sedan som lösta._ | `list_comments`, `reply_to_comment`, `resolve_comment` |
| _Byt till XeLaTeX och ladda ned PDF-filen._ | `update_settings`, `compile`, `get_output_file_link` |
| _Skriv om sammanfattningen som en spårad ändring._ | `read_file`, `edit_file` med `trackChanges` (v6.3.3) |
| _Vad har ändrats sedan den inskickade versionen?_ | `list_versions`, `list_changes`, `diff` (v6.3.3) |
| _Flytta kapitlen till en mapp som heter chapters._ | `move_file` (v6.3.3) |

### Verktyg {#tools}

| Grupp | Verktyg |
| --- | --- |
| Projekt | `get_clone_info`, `get_settings`, `update_settings` |
| Filer | `list_files`, `read_file`, `edit_file`, `write_file`, `delete_file`, `move_file`, `create_folder` |
| Kompilering | `compile`, `get_compile_log`, `get_output_file_link`, `word_count` |
| Kommentarer | `list_comments`, `reply_to_comment`, `resolve_comment`, `reopen_comment`, `add_comment`, `edit_comment_message`, `delete_comment_message` |
| Spårade ändringar | `list_tracked_changes`, `accept_tracked_changes`, `reject_tracked_changes` |
| Historik | `list_versions`, `list_changes`, `diff`, `create_version`, `delete_version`, `restore_file`, `restore_project` |
| Chatt | `list_chat_messages`, `send_chat_message` |

v6.3.3 har 33 verktyg, eller 31 med `OVERLEAF_DISABLE_CHAT=true`, som tar bort chattverktygen. v6.3.1 och v6.3.2 har de övriga 17: allt ovan utom `move_file`, `create_folder`, `add_comment`, `edit_comment_message`, `delete_comment_message`, verktygen för spårade ändringar, chattverktygen och historikverktygen utom `list_versions`. I v6.3.3 läser `read_file` även en fil i en version av historiken, `edit_file` och `write_file` tar `trackChanges`, och `update_settings` anger även språket för stavningskontrollen.

Ändringar som görs med `edit_file`, `write_file` och `move_file` visas direkt i editorn och slås ihop med medarbetarnas. För många filer på en gång eller binära filer kan AI-klienten också klona projektet med Git och pusha.

Med `trackChanges` blir en ändring av en befintlig fil en spårad ändring av tokenets användare, även när spåra ändringar är avstängt i projektet; en ny fil blir det aldrig. Utan `trackChanges` följer ändringarna projektets inställning för spåra ändringar.

### Behörigheter {#permissions}

MCP-servern följer projektets delningsinställningar, precis som Git:

* Alla som kan visa projektet kan läsa det, kompilera det och ladda ned dess utdata.
* Endast ägaren och redigerare kan ändra dess filer och inställningar, återställa versioner och godkänna eller avvisa spårade ändringar.
* Granskare kan också lägga till kommentarer och svara på dem, lösa, öppna igen eller ta bort de kommentarer de startat, och spara versioner. De kan inte redigera filer, inte ens som spårade ändringar.
* Alla redigerar bara sina egna kommentarsmeddelanden, och granskare tar bara bort sina egna.
* Endast ägaren tar bort versioner som andra har sparat.
* Läsare som gick med via en länk kan inte se kommentarerna, de spårade ändringarna, historiken eller chatten, precis som i editorn. Inbjudna läsare kan se dem och använda chatten.
* Om projektägaren inte har **Full project history** visar historikverktygen bara ändringarna från de senaste 24 timmarna, som historikpanelen gör. Administratörer ser alla.

Användarguiden har en tabell över vad varje roll får göra, se [Vem får göra vad](/sv/on-premises/user-guide/users/mcp-server#who-may-do-what).

### Frågor och svar {#q&a}

<Accordion title="Jag ser inte Integrations eller MCP server i redigeraren">

<strong>Svar:</strong> MCP-servern har ingen egen miljövariabel. Den aktiveras med `GIT_BRIDGE_ENABLED=true` i `config/overleaf.rc`, se [Git-integration](/sv/on-premises/configuration/overleaf-toolkit/integrations/git-integration). Kör `bin/up -d` när du har ändrat den. Utan git-bridge visar redigeraren inte fliken **Integrations** i sin vänstra list.

</Accordion>

<Accordion title="AI-klienten säger ”Track changes is off for this project”">

<strong>Svar:</strong> Klienten bad om en spårad ändring, men projektägarens konto har inte spåra ändringar. Klicka på **Admin** och sedan på **Manage Users**, öppna ägaren och slå på **Track changes** på fliken **Features**, se [Features](/sv/on-premises/user-guide/administrators/user-management#features). Ändringar utan `trackChanges` fungerar fortfarande.

</Accordion>

<Accordion title="AI-klienten ser bara ändringarna från de senaste 24 timmarna">

<strong>Svar:</strong> Projektägarens konto har inte fullständig projekthistorik, så historikverktygen visar det som historikpanelen visar: ändringarna från de senaste 24 timmarna. Klicka på **Admin** och sedan på **Manage Users**, öppna ägaren och slå på **Full project history** på fliken **Features**, se [Features](/sv/on-premises/user-guide/administrators/user-management#features).

</Accordion>
