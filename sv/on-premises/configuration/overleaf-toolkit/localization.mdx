### i18n-konfiguration i Overleaf

<Info>

Det här dokumentet beskriver hur du konfigurerar internationalisering (i18n) för en självhostad **Overleaf**-instans.

</Info>

Overleaf har översatts till flera språk. Med rätt konfiguration kan du:

* Köra din Overleaf-instans på **ett enda fast språk**, eller
* Aktivera **flera språk** så att användarna kan byta språk dynamiskt, på liknande sätt som på `www.overleaf.com`.

***

#### Konfiguration med ett språk

Webbplatsens språk konfigureras med miljövariabeln `OVERLEAF_SITE_LANGUAGE` (eller `SHARELATEX_SITE_LANGUAGE` för Overleaf-versioner **4.x och tidigare**).

Språkkoder som stöds:

* `en` - engelska (standard)
* `es` - spanska
* `pt` - portugisiska
* `de` - tyska
* `fr` - franska
* `cs` - tjeckiska
* `nl` - nederländska
* `sv` - svenska
* `it` - italienska
* `tr` - turkiska
* `zh-CN` - kinesiska (förenklad)
* `no` - norska
* `da` - danska
* `ru` - ryska
* `ko` - koreanska
* `ja` - japanska
* `pl` - polska
* `fi` - finska

Engelska är standardspråket. För att byta gränssnittsspråk (till exempel till förenklad kinesiska) lägger du till följande rad i `config/variables.env`:

```bash title="config/variables.env"
OVERLEAF_SITE_LANGUAGE=zh-CN
```

Tillämpa sedan konfigurationen:

```bash
bin/up
```

När tjänsterna har startats om bör gränssnittsspråket i webbgränssnittets menyer återspegla den nya inställningen.

#### Konfiguration med flera språk

För att användarna ska kunna **byta språk utan att loggas ut** måste din Overleaf-instans konfigureras för att visa olika språk baserat på domännamn.

Det här avsnittet förutsätter att:

* Din primära domän är `overleaftest.com`
* Du har ett **wildcard-TLS-certifikat** (t.ex. `*.overleaftest.com`)
* Du **inte använder `localhost`** (eftersom det inte stöder språkroutning baserad på underdomäner)

För lokala tester kan du använda en domän som `dev-overleaf.com`.

<Steps>
<Step title="Konfiguration av TLS-proxy (Nginx)">
Din omvända TLS-proxy måste vidarebefordra det ursprungliga `Host`-huvudet så att Overleaf kan avgöra vilken språkdomän användaren besökte.

Se till att följande direktiv finns med:

```nginx
proxy_set_header Host $host;
```

Här är ett exempel på en Nginx-konfiguration:

```nginx
server {
    listen 443 ssl;
    server_name    _; # Catch all, see http://nginx.org/en/docs/http/server_names.html
    server_name *.overleaftest.com;
    ssl_certificate /etc/nginx/ssl/nginx.crt;
    ssl_certificate_key /etc/nginx/ssl/nginx.key;
    ssl_protocols               TLSv1 TLSv1.1 TLSv1.2;
    ssl_prefer_server_ciphers   on;
    # used cloudflares ciphers https://github.com/cloudflare/sslconfig/blob/master/conf
    ssl_ciphers EECDH+CHACHA20:EECDH+AES128:RSA+AES128:EECDH+AES256:RSA+AES256:EECDH+3DES:RSA+3DES:!MD5;

    # config to enable HSTS(HTTP Strict Transport Security) https://developer.mozilla.org/en-US/docs/Security/HTTP_Strict_Transport_Security
    # to avoid ssl stripping https://en.wikipedia.org/wiki/SSL_stripping#SSL_stripping	
    add_header Strict-Transport-Security "max-age=31536000; includeSubdomains;";
    server_tokens off;
    add_header X-Frame-Options SAMEORIGIN;
    add_header X-Content-Type-Options nosniff;
    client_max_body_size 50M;

    location / {
        proxy_pass http://localhost:5000; # change to whatever host/port the docker container is listening on.
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 3m;
        proxy_send_timeout 3m;
        
        # add this to your nginx conf
        proxy_set_header Host $host;
    }
}
```
</Step>

<Step title="Konfigurera cookiedomän">
För att användare inte ska loggas ut när de byter språk måste cookies delas mellan språkens underdomäner.

Lägg till följande rad i `config/variables.env`:

```env title="config/variables.env"
# Note the leading dot
COOKIE_DOMAIN=.overleaftest.com
```

Det säkerställer att autentiseringscookies är giltiga för alla underdomäner under `overleaftest.com`.
</Step>

<Step title="Mappning mellan språk och domän">
Definiera sedan hur språkkoder mappas till underdomäner med\
`OVERLEAF_LANG_DOMAIN_MAPPING`.

#### Exempelkonfiguration

```dotenv title="config/variables.env" wrap
OVERLEAF_LANG_DOMAIN_MAPPING='{"www": {"lngCode": "en","url": "https:\/\/www.overleaftest.com"},"cn": {"lngCode": "zh-CN","url": "https:\/\/cn.overleaftest.com"}}'
```

Med den här konfigurationen:

* `https://www.overleaftest.com` → engelskt gränssnitt
* `https://cn.overleaftest.com` → gränssnitt på förenklad kinesiska

Du kan utöka mappningen med fler språk och underdomäner efter behov.
</Step>

<Step title="Omdirigera apexdomänen">
Omdirigera slutligen apexdomänen (`overleaftest.com`) till standardspråkets domän (`www.overleaftest.com`).

```nginx
server{
    listen 80;
    server_name overleaftest.com;
    return 301 https://www.overleaftest.com$request_uri;
}

server {
    listen 443 ssl http2;
    server_name overleaftest.com;
    ssl_certificate     /path/to/fullchain.cer;
    ssl_certificate_key /path/to/overleaftest.com.key;
    return 301 https://www.overleaftest.com$request_uri;
}
```
</Step>
</Steps>
