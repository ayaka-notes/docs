### Konfiguration

Från och med 6.3.0 utför galleriet sidindelning, sökning och sortering på servern. Ingen migrering krävs. För stora gallerier, se de [valfria MongoDB-indexen](/sv/on-premises/release-notes/release-notes-6.x.x#feature-04-template-pagination  "mention") i versionsinformationen.

Funktionen Template Gallery styrs med följande miljövariabler:

* `OVERLEAF_TEMPLATE_GALLERY`: Sätt till `true` för att aktivera Template Gallery.
*   `OVERLEAF_TEMPLATE_CATEGORIES`: En valfri, blankstegsseparerad lista med noll eller flera nycklar för mallkategorier. Giltiga nycklar är:

    * _`academic-journal`_
    * _`book`_
    * _`presentation`_
    * _`poster`_
    * _`cv`_
    * _`homework`_
    * _`bibliography`_
    * _`calendar`_
    * _`formal-letter`_
    * _`report`_
    * _`thesis`_
    * _`newsletter`_

    Specialnyckeln _`all`_ läggs till automatiskt. Den representerar en kategori som innehåller alla mallar.

    För varje kategorinyckel kan följande valfria miljövariabler sättas:

    * `TEMPLATE_<KEY>_NAME`: Mallkategorins visningsnamn.
    * `TEMPLATE_<KEY>_DESCRIPTION`: En kort beskrivning av kategorin.

    Om en kategorinyckel innehåller ett bindestreck (`-`) ersätter du det med ett understreck (`_`) i miljövariabelnamnen.
* `ENABLE_CONVERSIONS`: Måste sättas till `true` för att aktivera generering av miniatyrbilder och förhandsvisningar för mallar.

### Behörigheter för publicering

Administratörer kan publicera mallar. Du kan också utse en användare som inte är administratör att hantera de utvalda mallarna som visas i ditt lokala galleri på `/templates`.

För att göra det sätter du miljövariabeln `OVERLEAF_TEMPLATES_USER_ID` i `toolkit/config/variables.env` till `ID` för den användare som ska ansvara för mallhanteringen i din instans, till exempel:

```dotenv
OVERLEAF_TEMPLATES_USER_ID=56a8865231faeb5f07d69959
```

### Publicera mallar

För varje mall du vill ladda upp:

1. Skapa ett projekt som innehåller mallens källkod och kontrollera att det går att kompilera.
2. Välj **File** > **Manage Template** i editorn.
3. Ange mallens uppgifter i formuläret som visas:
   * _Title_ måste vara unik.
   * Fältet _Description_ stöder Markdown-formatering.
   * Fältet _Author_ accepterar länkar formaterade med Markdown.

När mallen har skickats in kan uppgifterna redigeras, eller mallen tas bort, via sidan Template Gallery. Administratörer och mallanvändaren (`OVERLEAF_TEMPLATES_USER_ID`) kan hantera alla mallar.

Här är ett exempel:

```dotenv wrap expandable
#################
#   TEMPLATES   #
#################

OVERLEAF_TEMPLATE_GALLERY=true
OVERLEAF_TEMPLATE_CATEGORIES=academic-journal book presentation poster cv homework bibliography calendar formal-letter report thesis newsletter

TEMPLATE_ACADEMIC_JOURNAL_NAME=Journal articles
TEMPLATE_ACADEMIC_JOURNAL_DESCRIPTION=Templates for academic journal submissions, including formats for major publishers and preprint servers.

TEMPLATE_BIBLIOGRAPHY_NAME=Bibliographies
TEMPLATE_BIBLIOGRAPHY_DESCRIPTION=Styles for creating and managing bibliographies with BibTeX or BibLaTeX. Suitable for use in academic papers, theses, and reports.

TEMPLATE_BOOK_NAME=Books
TEMPLATE_BOOK_DESCRIPTION=Templates for writing books or long-form documents, including chapter structuring, front matter, and indexing.

TEMPLATE_CALENDAR_NAME=Calendars
TEMPLATE_CALENDAR_DESCRIPTION=Templates to create yearly, monthly, or weekly calendars. Useful for personal planners or event scheduling.

TEMPLATE_CV_NAME=CVs and résumés
TEMPLATE_CV_DESCRIPTION=Templates for CVs and résumés with various formats for academic, industry, and creative positions.

TEMPLATE_FORMAL_LETTER_NAME=Formal letters

TEMPLATE_HOMEWORK_NAME=Assignments

TEMPLATE_NEWSLETTER_NAME=Newsletters

TEMPLATE_POSTER_NAME=Posters
```

### Överföra mallar från overleaf.com

Eftersom Overleaf Pro är utformat för att fungera offline finns det inget automatiserat sätt att integrera mallar från galleriet på [overleaf.com](https://www.overleaf.com/) i din lokala installation, men det går att göra manuellt för en mall i taget.

Som standard är Overleaf Pro konfigurerat att använda en version av TeXLive med basic-schemat för kompilering. Den här grundversionen är lättviktig och innehåller bara en mycket begränsad delmängd av LaTeX-paket, vilket med största sannolikhet leder till fel om saknade paket när dina användare försöker använda mallar från [overleaf.com](https://www.overleaf.com/) på din lokala instans.

Tyvärr finns det inget automatiskt sätt att installera saknade paket, men det finns en konfigurerbar inställning i Server Pro som låter dina användare kompilera projekt med tillgång till fler paket, och på ett säkrare sätt. Funktionen heter [Sandbox Compiles](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles) (även kallad Sibling Containers).

För att säkerställa att nedladdade mallar är kompatibla med din lokala Server Pro-instans rekommenderar vi starkt att du aktiverar [Sandbox Compiles](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles), eftersom funktionen ger dina användare tillgång till samma TeX Live-miljö som på [overleaf.com](https://www.overleaf.com/). Dessa images innehåller de mest populära paketen och typsnitten och har redan testats mot våra gallerimallar.

Mer information om hur du konfigurerar vilka TeX Live-versioner användarna kan välja mellan i sina projekt, samt hur du anger standardversionen av TeX Live-imagen för nya projekt, finns i avsnittet [Changing the TeX Live Image](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles#changing-the-tex-live-image) i vår dokumentation.

1. Gå till [Template Gallery](https://www.overleaf.com/latex/templates) på [overleaf.com](https://www.overleaf.com/) och leta upp önskad mall, till exempel [IEEE Photonics Journal Paper Template - Example Submission](https://www.overleaf.com/latex/examples/ieee-photonics-journal-paper-template-example-submission/bsfjjfkdsjds)
2. Klicka på knappen **Open as Template**
3. Klicka på projektmenyn och välj **Download Source**
4. Logga sedan in på kontot i den lokala Server Pro-instansen
5. Klicka på knappen **New Project** på projektöversikten och välj **Upload Project**
6. Klicka på knappen **Select a .zip file** och välj den nedladdade zip-filen med mallen

Användaren kan sedan använda den nyuppladdade mallen i sitt eget konto, eller så kan du som mallanvändare publicera den så att andra användare kan använda den.

### Frågor och svar

<Accordion title="Kan jag ta bort projektet efter att ha publicerat motsvarande mall?">

<strong>Svar:</strong> Ja, men vi rekommenderar inte det. När du publicerar en mall tar vi en ögonblicksbild av projektet och sparar det som en zip-fil vid publiceringstillfället. Det säkerställer att mallen inte påverkas även om du tar bort projektet som hör till mallen.

Vi registrerar dock även det ProjectID som är kopplat till mallen, vilket gör det enkelt för dig att uppdatera mallen i framtiden.

Om du tar bort motsvarande projekt ser du inte knappen "Admin: Source Project" på mallens detaljsida (se bilden nedan).

<Accordion title="Varför tar det så lång tid att publicera en mall för vissa projekt?">

<strong>Svar:</strong> När du publicerar mallen sparar vi projektet som en zip- och en pdf-fil, vilket oftast går snabbt. Vi måste dock också generera miniatyrbilder av PDF-filen så att de kan visas i mallens detaljer.

Tiden för att generera miniatyrbilder beror vanligtvis på innehållet på PDF-filens första sida. För att balansera visningskvalitet och konverteringstid väljer vi en medelstor bredd.

Om PDF-filens första sida innehåller mycket text kan konverteringen av miniatyrbilderna dock ta 40 sekunder eller ännu längre, så ha tålamod. Här är ett exempel på en stor poster som tar längre tid.
