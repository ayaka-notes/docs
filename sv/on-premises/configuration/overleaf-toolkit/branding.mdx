### Sidhuvud

I det här avsnittet går vi igenom hur du anpassar viktiga delar av din lokala instans. Du kan anpassa webbplatsens titel, navigeringslänkar, sidhuvud, sidfot och logotyp efter dina önskemål.

### Webbplatsens titel

Navigeringsfältets titel kan anpassas med miljövariabeln `OVERLEAF_NAV_TITLE`. Texten visas i det övre vänstra hörnet av navigeringen om ingen logotyp är angiven.

```bash
# add to config/variables.env
OVERLEAF_NAV_TITLE=Our Overleaf Instance
```

## Logotyp

Du kan lägga till en anpassad logotyp i stället för text genom att ange miljövariabeln `OVERLEAF_HEADER_IMAGE_URL`. Värdet ska peka på en bildfil som ligger på en extern server.

```bash title="config/variables.env"
# add to config/variables.env
OVERLEAF_HEADER_IMAGE_URL=https://mysite.somewhere.com/img/logo.png
```

#### Logotyper för ljust och mörkt tema

Från version 6.3.0 kan du ange separata logotyper för det ljusa och det mörka temat med miljövariablerna `OVERLEAF_HEADER_IMAGE_URL_LIGHT` och `OVERLEAF_HEADER_IMAGE_URL_DARK`. Båda värdena ska peka på en bildfil som ligger på en extern server.

```text
# add to config/variables.env
OVERLEAF_HEADER_IMAGE_URL_LIGHT=https://mysite.somewhere.com/img/logo-light.png
OVERLEAF_HEADER_IMAGE_URL_DARK=https://mysite.somewhere.com/img/logo-dark.png
```

<Info>

Om någon av variablerna inte är angiven används logotypen från `OVERLEAF_HEADER_IMAGE_URL` för det temat.

</Info>

## Navigeringslänkar i sidhuvudet

Extra navigeringsobjekt kan läggas till i navigeringshuvudet genom att sätta miljövariabeln `OVERLEAF_HEADER_EXTRAS` till en JSON-array med objekt. Till exempel:

```json wrap
[\
  {\
    "text": "Some link",\
    "url": "http://example.com/somelink",\
    "class": "subdued",\
    "only_when_logged_out": true\
  },\
  {\
    "text": "Help",\
    "class": "subdued",\
    "dropdown": [\
      {\
        "text": "Documentation",\
        "url": "/learn"\
      },\
      {\
        "text": "Contact Admin",\
        "url": "http://example.com/contact"\
      }\
    ]\
  }\
]
```

Lägg till den escapade JSON-formen i toolkit/variables.env:

```bash title="toolkit/variables.env" wrap
# add to toolkit/variables.env
OVERLEAF_HEADER_EXTRAS=[{"text":"Some link","url":"http://example.com/somelink","class":"subdued","only_when_logged_out":true},{"text":"Help","class":"subdued","dropdown":[{"text":"Documentation","url":"/learn"},{"text":"Contact Admin","url":"http://example.com/contact"}]}]
```

## Sidfötter

Det är möjligt att anpassa både den vänstra och den mindre högra sidfoten (som finns på sidor som `/project`) med miljövariablerna `OVERLEAF_LEFT_FOOTER` och `OVERLEAF_RIGHT_FOOTER`. Båda förväntar sig en array med JSON-objekt som infogas.

Båda förväntar sig en JSON-array som infogas.

```json
[\
  {\
    "text": "This is an example text footer entry!"\
  },\
  {\
    "text": "This is an example URL footer link!", "url" : "/my-first-link.htm"\
  }\
]
```

<Info>

När du endast använder `text` får den inte innehålla HTML, eftersom värdet återges som ren text.

</Info>

Dessa data måste vara giltig JSON för att fungera, med escapade citattecken när de skickas som en miljövariabel.

```bash title="config/variables.env" wrap
# add to config/variables.env
OVERLEAF_LEFT_FOOTER=[{"text": "This is an example text footer entry!"}]
OVERLEAF_RIGHT_FOOTER=["text": "This is an example URL footer link!", "url" : "/my-first-link.htm"]
```

<Info>

Utöver `text` och `url` accepterar JSON-objektet även egenskaperna `class` och `label` för ytterligare anpassning.

</Info>

### Underhållssida

Du kan anpassa meddelandet som visas på underhållssidan med miljövariabeln `OVERLEAF_MAINTENANCE_MESSAGE`. Texten ersätter standardmeddelandet under sidans titel.

```text wrap
# add to config/variables.env
OVERLEAF_MAINTENANCE_MESSAGE=Our Overleaf Instance is down for maintenance and will be back shortly.
```

Om du vill inkludera länkar eller annan formatering använder du i stället `OVERLEAF_MAINTENANCE_MESSAGE_HTML`. Om båda är angivna har `OVERLEAF_MAINTENANCE_MESSAGE_HTML` företräde.

```text wrap
# add to config/variables.env
OVERLEAF_MAINTENANCE_MESSAGE_HTML=Our Overleaf Instance is down for maintenance. For urgent requests, contact <a href="mailto:admin@example.com">admin@example.com</a>.
```

<Info>

`OVERLEAF_MAINTENANCE_MESSAGE` återges som ren text och får därför **inte** innehålla HTML. `OVERLEAF_MAINTENANCE_MESSAGE_HTML` återges som HTML utan escaping.

</Info>

Om ingen av dem är angiven länkar standardmeddelandet till din statussida när `OVERLEAF_STATUS_PAGE_URL` är angiven, och visar administratörens e-postadress när den inte är det.
