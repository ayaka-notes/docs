### Konfigurera Zotero-integrationen

1. Öppna [den här länken](https://www.zotero.org/oauth/apps) för att skapa en Zotero OAuth-klient (som bilden visar)
2. Välj **Application Type**: **Browser**
3. Ange Callback URL till din `${OVERLEAF_SITE_URL}/user/zotero/oauth/callback`
4. Konfigurera din `config/variables.env`

<Frame>
  <img src="/images/on-premises/image-41.png" alt="" width="375" />
</Frame>

```dotenv title="config/variables.env"
#################
#    Zotero     #
#################
# 'zotero' must be in ENABLED_LINKED_FILE_TYPES (set in develop/docker-compose.yml)
ENABLED_LINKED_FILE_TYPES=project_file,project_output_file,url,zotero

# From a Zotero OAuth client (register at https://www.zotero.org/oauth/apps)
# Application Type: Browser 
# Callback URL -> ${OVERLEAF_SITE_URL}/user/zotero/oauth/callback
ZOTERO_CLIENT_ID=
ZOTERO_CLIENT_SECRET=
# Encrypts the Zotero API key in mongo (set in dev to avoid writing a key file
# to /var/lib/overleaf/data, which the dev web container can't create)
# How to generate: `openssl rand -hex 32`
ZOTERO_CIPHER_PASSWORD=dev-zotero-cipher-password
# Optional: route the module's server-side Zotero requests (OAuth + API) through
# an HTTP proxy (must be reachable from the web container; same as github-sync)
# http://10.0.0.1:10808
# (Optional) ZOTERO_PROXY_URL=
```

### Anmärkningar

<Warning>

När du uppgraderar en befintlig installation med länkade Zotero-bibliografifiler till den återutgivna versionen 6.3.0 ska du följa [migreringsinstruktionerna för Zotero / Mendeley](/sv/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention"). Nya installationer behöver inte denna migrering.

</Warning>

<Danger>

Eftersom Ayakaleaf är en samarbetsplattform tillåts, för att förbättra säkerheten, från och med version 6.3.0 endast den ursprungliga skaparen av en referensfil (`bib`) att uppdatera den importerade filen.

</Danger>

Anta till exempel att projektägaren, användare A, aktiverar länkdelning och skapar en fil `test.bib` i projektet som är länkad till hens eget Zotero-konto. Om en annan användare, användare B, öppnar projektet via den delade länken kan användare B fortfarande läsa och ladda ner `test.bib`, men får inte uppdatera eller importera om filen från Zotero. Endast användare A, som ursprunglig skapare av referensfilen, kan utföra uppdateringar. Med andra ord har endast den ursprungliga skaparen av `.bib`-filen behörighet att uppdatera den.
