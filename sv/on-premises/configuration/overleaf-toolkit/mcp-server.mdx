Varje projekt har en MCP-server, så att AI-klienter som Claude Code, Codex, Cursor, VS Code eller Gemini CLI kan arbeta med det: läsa och redigera dess filer, kompilera det, läsa LaTeX-loggen, ladda ned PDF-filen och svara på kommentarer.

<Info>

Den här funktionen är utvecklad av [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro). Den introducerades i v6.3.1 och finns i senare versioner.

</Info>

### Konfiguration

MCP-servern ingår i Git-integrationen: aktivera [git-bridge](/sv/on-premises/configuration/overleaf-toolkit/git-integration), så blir MCP-servern också tillgänglig. Inget annat behöver konfigureras.

### Anslut en AI-klient

1. Generera en autentiseringstoken för Git i **Kontoinställningar**. Samma token används för MCP-servern och för Git.
2. Öppna **Integrationer** i redigeraren och klicka på **MCP-server**. Där visas adressen till projektets MCP-server, `https://<your-overleaf>/project/<project_id>/mcp`, och hur du lägger till den i varje AI-klient: kopiera kommandot och ersätt `<token>` med din token.

### Användning

När anslutningen är klar ber du AI-klienten om saker med vanliga ord. Till exempel:

| Du ber om | AI-klienten använder |
| --- | --- |
| _Rätta stavfelen i inledningen._ | `read_file`, `edit_file`: ändringarna syns live i redigeraren |
| _Kompilera projektet och åtgärda LaTeX-felen._ | `compile`, `get_compile_log`, `edit_file` |
| _Svara på de öppna kommentarerna och markera dem sedan som lösta._ | `list_comments`, `reply_to_comment`, `resolve_comment` |
| _Byt till XeLaTeX och ladda ned PDF-filen._ | `update_settings`, `compile`, `get_output_file_link` |

### Verktyg

| Grupp | Verktyg |
| --- | --- |
| Projekt | `get_clone_info`, `get_settings`, `update_settings`, `list_versions` |
| Filer | `list_files`, `read_file`, `edit_file`, `write_file`, `delete_file` |
| Kompilering | `compile`, `get_compile_log`, `get_output_file_link`, `word_count` |
| Kommentarer | `list_comments`, `reply_to_comment`, `resolve_comment`, `reopen_comment` |

Ändringar som görs med `edit_file` och `write_file` syns live i redigeraren och slås samman med medarbetarnas ändringar. För många filer på en gång, binära filer eller namnbyten kan AI-klienten också klona projektet med Git och pusha.

### Behörigheter

MCP-servern följer projektets delningsinställningar, precis som Git:

* Alla som kan visa projektet kan läsa det, kompilera det och ladda ned dess utdata.
* Endast ägaren och redigerare kan ändra dess filer och inställningar.
* Granskare kan även svara på kommentarer samt lösa eller återöppna de kommentarer som de själva har startat.
* Användare som har anslutit via en länk och bara kan visa projektet ser inte kommentarerna, precis som i redigeraren.
