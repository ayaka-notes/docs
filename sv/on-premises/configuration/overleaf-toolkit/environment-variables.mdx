Den här sidan beskriver de miljövariabler som stöds i filen `config/variables.env` för driftsättningar med Toolkit.

Filen `config/variables.env` består av variabeldefinitioner på formen `NAME=value`; rader som börjar med `#` behandlas som kommentarer.

<Info>

Du måste återskapa Docker-containrarna genom att köra `bin/up` efter att du har ändrat något i `overleaf.rc` eller `variables.env`.

</Info>

### Alla versioner

Dessa miljövariabler är kompatibla med Server CE och Server Pro och ger en enkel migreringsväg mellan dessa två lokala versioner. De kan också användas med både Toolkit- och Docker Compose-driftsättningar.

<Info>

Tidigare hade dessa miljövariabler prefixet `SHARELATEX_` i stället för `OVERLEAF_`.

</Info>
