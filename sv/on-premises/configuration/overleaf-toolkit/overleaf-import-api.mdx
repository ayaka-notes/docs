### Funktionen "Overleaf Import API"

Från och med Ayakaleaf Pro v6.3 kan du skapa länkar som importerar en LaTeX-fil eller ett zippat projekt från en URL och öppnar det i din egen Ayakaleaf-instans, på liknande sätt som Overleafs [API ”Open in Overleaf”](https://cn.overleaf.com/devs).

Funktionen är aktiverad som standard; du behöver bara besöka `your.overleaf.com/devs` för att se en detaljerad sida med instruktioner.

<Info>

Sidan `/devs` kräver inloggning om inte `OVERLEAF_ALLOW_PUBLIC_ACCESS=true`, se [Utloggade besökare](/sv/on-premises/configuration/overleaf-toolkit/overleaf-import-api#signed-out-visitors  "mention").

</Info>

Om du till exempel tillhandahåller en LaTeX-fil på `https://example.com/main.tex` eller ett komplett projekt på `https://example.com/project.zip` kan du skapa en länk som importerar den till din egen Ayakaleaf Pro-instans och öppnar det nya projektet:

<Tabs>
<Tab title="LaTeX-fil">

```text wrap
https://ayakaleaf.example.com/docs?snip_uri=https%3A%2F%2Fexample.com%2Fmain.tex
```

</Tab>

<Tab title="ZIP-projekt">

```text wrap
https://ayakaleaf.example.com/docs?snip_uri=https%3A%2F%2Fexample.com%2Fproject.zip
```

</Tab>
</Tabs>

Ersätt `ayakaleaf.example.com` med din instans domän.

#### Öppna ett LaTeX-projekt i Ayakaleaf Pro

Från och med Ayakaleaf Pro v6.3 kan du skapa en länk som importerar en LaTeX-fil eller ett zippat projekt till din egen Ayakaleaf Pro-instans. När någon öppnar länken skapar Ayakaleaf Pro ett nytt projekt av den angivna filen och öppnar det i editorn.

Skicka länken till din instans endpoint `/docs`:

| Parameter       | Beskrivning                                                                                        | Exempel                                           |
| --------------- | -------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| `snip_uri`      | URL till en LaTeX-fil som ska importeras. En enskild ZIP-fil accepteras också, men använd `zip_uri` för projekt. | `https://example.com/main.tex`                    |
| `zip_uri`       | URL till ett zippat LaTeX-projekt som ska importeras.                                                           | `https://example.com/project.zip`                 |
| `snip_uri[]`    | Importera flera filer genom att upprepa den här parametern.                                                 | `snip_uri[]=.../main.tex&snip_uri[]=.../refs.bib` |
| `snip_name[]`   | Ange filnamnet för varje `snip_uri[]`, i samma ordning.                                         | `snip_name[]=main.tex`                            |
| `engine`        | Ange kompilatorn: `latex_dvipdf`, `pdflatex`, `xelatex` eller `lualatex`.                            | `engine=xelatex`                                  |
| `main_document` | Ange huvudfilen `.tex` i det importerade projektet.                                                  | `main_document=main.tex`                          |
| `name`          | Ange namnet på det nya projektet. `project_name` accepteras också.                                  | `name=My%20Project`                               |

Om dina filer till exempel finns på `example.com` importerar dessa länkar dem till en Ayakaleaf Pro-instans som körs på `ayakaleaf.example.com` .

#### Importera ett projekt med Base64

Du kan bädda in en LaTeX-fil eller ett zippat projekt direkt i en ”Open in Ayakaleaf”-länk som en Base64-data-URL. På så sätt kan du skapa en importlänk utan att lägga filen på en separat URL.

| Innehåll        | Parameter  | Format för data-URL                                      |
| -------------- | ---------- | ---------------------------------------------------- |
| LaTeX-fil     | `snip_uri` | `data:application/x-tex;base64,<base64-encoded-tex>` |
| Zippat projekt | `zip_uri`  | `data:application/zip;base64,<base64-encoded-zip>`   |

För att importera ett ZIP-projekt Base64-kodar du i stället ZIP-filen och skickar den via `zip_uri`. Använd `encodeURIComponent` på hela data-URL:en när du skapar någon av länkarna. För stora projekt bör du använda en ZIP-URL på en server, eftersom längdbegränsningar för URL:er i webbläsare och servrar kan göra Base64-länkar opraktiska.

#### Lägg till en ”Open in Ayakaleaf”-knapp

Du kan använda ett HTML-formulär för att importera en fil när en besökare klickar på en knapp. Skicka formuläret till din instans endpoint `/docs` med `method="post"`.

För en LaTeX-fil på en server:

```text
<form action="https://ayakaleaf.example.com/docs" method="post" target="_blank">
  <input type="hidden" name="snip_uri" value="https://example.com/main.tex">
  <input type="hidden" name="engine" value="xelatex">
  <button type="submit">Open in Ayakaleaf</button>
</form>
```

För att importera ett zippat projekt ersätter du `snip_uri` med `zip_uri` och låter den peka på ZIP-filen. Du kan också skicka LaTeX-källkod direkt med `snip` för råtext eller `encoded_snip` för URL-kodad text.

Ersätt `ayakaleaf.example.com` med din instans domän. Om din instans har blockering av förfrågningar mellan olika ursprung (cross-origin) aktiverad lägger du till webbplatsen som har formuläret i `ALLOWED_ORIGINS`.

#### Utloggade besökare

Det nya projektet skapas i besökarens konto, så besökaren måste logga in. Hur en utloggad besökare kommer dit beror på hur importen skickas:

* **Länkar** (`GET /docs?...`) fungerar på alla instanser: besökaren skickas till inloggningssidan och importen fortsätter efter inloggningen.
* **Formulär** (`POST /docs`) kräver `OVERLEAF_ALLOW_PUBLIC_ACCESS=true` för utloggade besökare. Inskickade data sparas då i 10 minuter tills besökaren har loggat in och används en gång.

<Warning>

Som standard (`OVERLEAF_ALLOW_PUBLIC_ACCESS` inte satt) skickas ett formulär från en utloggad besökare till inloggningssidan innan Ayakaleaf Pro läser det, och de inskickade data går förlorade: efter inloggningen ser besökaren _no snippet, snip\_uri or zip\_uri provided_. Använd länkar, be besökarna logga in först eller aktivera offentlig åtkomst, se [Sidåtkomst](/sv/on-premises/configuration/overleaf-toolkit/public-access#page-access  "mention").

</Warning>

<Accordion title="Vilka ZIP- eller TeX-resurser kan jag importera?">

Ayakaleaf Pro använder mikrotjänsten `linked-url-proxy` (som främst används för [external-url.md](/sv/on-premises/configuration/overleaf-toolkit/external-url  "mention")) för att hämta externa resurser. Generellt kan alla offentligt åtkomliga ZIP- eller TeX-resurser som finns tillgängliga via internet importeras. Resurser i privata eller interna nätverk blockeras av säkerhetsskäl.

Från och med den återutgivna Ayakaleaf Pro 6.3.0 (3 oktober 2026) kan du konfigurera en HTTP(S)-proxy för att hämta externa ZIP- och TeX-resurser med `OVERLEAF_LINKED_URL_OUTBOUND_PROXY`. Se [Utgående proxy](/sv/on-premises/configuration/overleaf-toolkit/external-url#outbound-proxy  "mention") för konfiguration och begränsningar av nätverksåtkomst.

</Accordion>
