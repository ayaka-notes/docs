Du kan öppna din Overleaf-instans för personer utan konto på tre sätt:

* [Projektåtkomst](/sv/on-premises/configuration/overleaf-toolkit/public-access#project-access  "mention"): låt gäster öppna en delad projektlänk utan att logga in
* [Sidåtkomst](/sv/on-premises/configuration/overleaf-toolkit/public-access#page-access  "mention"): låt utloggade besökare bläddra bland sidor som `/learn`, `/templates` och `/devs`
* [Offentlig registrering](/sv/on-premises/configuration/overleaf-toolkit/public-access#public-registration  "mention"): låt användare registrera sig själva, eventuellt begränsat till en e-postdomän

### Projektåtkomst

<Info>

Som standard måste en användare **logga in** innan hen kan delta i en gemensam redigeringssession för ett projekt, även om hen har fått en delningslänk till projektet.

</Info>

För att tillåta anonym åtkomst till projekt som delas via länk sätter du båda variablerna nedan:

```dotenv title="config/variables.env"
OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING=true
OVERLEAF_ALLOW_PUBLIC_ACCESS=true
```

`OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` aktiverar anonym läs- och skrivåtkomst till projekt som delas via länk.

`OVERLEAF_ALLOW_PUBLIC_ACCESS` förhindrar att oautentiserade användare omdirigeras till inloggningssidan.

Återskapa containrarna med `bin/up`. Öppna sedan en delningslänk i ett privat fönster.

### Sidåtkomst

Som standard (när `OVERLEAF_ALLOW_PUBLIC_ACCESS` inte är satt) omdirigeras utloggade besökare till inloggningssidan från **alla** sidor utom inloggnings- och registreringssidorna. Det gäller även sidor som är avsedda att vara offentliga, så länkar till dem fungerar bara för användare som redan är inloggade.

Med `OVERLEAF_ALLOW_PUBLIC_ACCESS=true` kan utloggade besökare öppna:

| Sida                                                                  | Kräver                           |
| --------------------------------------------------------------------- | -------------------------------- |
| LaTeX-hjälp på `/learn` (se [adding-latex-user-help.md](/sv/on-premises/configuration/overleaf-toolkit/adding-latex-user-help  "mention")) | `OVERLEAF_PROXY_LEARN=true`      |
| Mallgalleriet på `/templates`, mallsidor, förhandsvisningar och ZIP-nedladdningar (se [templates.md](/sv/on-premises/configuration/overleaf-toolkit/templates  "mention")) | `OVERLEAF_TEMPLATE_GALLERY=true` |
| Sidan för Overleaf Import API på `/devs` (se [overleaf-import-api.md](/sv/on-premises/configuration/overleaf-toolkit/overleaf-import-api  "mention")) | —                                |

Det gör också att [Overleaf Import API](/sv/on-premises/configuration/overleaf-toolkit/overleaf-import-api#signed-out-visitors  "mention") kan behålla ett formulär som skickats av en utloggad besökare tills hen har loggat in.

Projektlistan, editorn och att skapa projekt (även från en mall eller via Import API) kräver fortfarande inloggning.

### Offentlig registrering

Offentlig registrering finns bara i [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro).

<Danger>

Observera att när du har aktiverat offentlig registrering kan **vem som helst** med åtkomst till din Overleaf-instans registrera sig som användare.

Registreringsprocessen verifierar inte e-postadresser, så använd den bara i ett intranät eller i en betrodd miljö, eller inaktivera den när du inte längre behöver registrering.

</Danger>

Som standard tillåter varken Community Edition eller Overleaf Pro offentlig registrering.

För att aktivera den lägger du till detta i `config/variables.env`:

```dotenv title="config/variables.env"
OVERLEAF_ALLOW_PUBLIC_REGISTRATION=true
```

Återskapa containrarna med `bin/up`.

Klicka sedan på **Sign up** eller besök `/register`.

### Registrering med begränsad domän

Offentlig registrering med begränsad domän finns bara i [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro).

Innan du aktiverar detta bör du konfigurera e-postleverans så att användarna kan ta emot inbjudningar och aviseringar. Se [E-postleverans](/sv/on-premises/configuration/overleaf-toolkit/email-delivery).

Lägg sedan till följande rad i `config/variables.env`:

```dotenv title="config/variables.env" wrap
OVERLEAF_ALLOW_PUBLIC_REGISTRATION=@example.domain
```

`OVERLEAF_ALLOW_PUBLIC_REGISTRATION` kan sättas till:

* `true` för att låta alla som kan nå webbplatsen registrera sig
* `@example.domain` för att begränsa registreringen till e-postadresser i den domänen
