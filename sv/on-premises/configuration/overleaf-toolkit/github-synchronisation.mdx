### Konfigurera GitHub-synkronisering

<Warning>

Du måste aktivera [git-bridge](/sv/on-premises/configuration/overleaf-toolkit/git-integration) innan du kan använda GitHub-synkronisering.

```dotenv title="config/overleaf.rc"
GIT_BRIDGE_ENABLED=true
```

</Warning>

Gå till [utvecklarinställningarna](https://github.com/settings/developers) för att skapa din GitHub OAuth-applikation och kopiera ditt `CLIENT_ID` och `SECRET`.

**Obs!** Din OAuth-callback-URL är: `${OVERLEAF_SITE_URL}/user/github-sync/oauth2/callback`.

Lägg sedan till följande inställningar i dina filer med miljövariabler för Overleaf.

```dotenv title="config/variables.env" wrap
# used to encrypt the user's GitHub access token.
# How to generate: `openssl rand -hex 32`
GITHUB_TOKEN_CIPHER_PASSWORD=0123456789ABCDEFG # changed to yours

# Github Sync Settings
GITHUB_SYNC_ENABLED=true
GITHUB_SYNC_CLIENT_ID=
GITHUB_SYNC_CLIENT_SECRET=

# OAuth callback is: ${OVERLEAF_SITE_URL}/user/github-sync/oauth2/callback
# (Optional) GITHUB_SYNC_PROXY_URL=http://10.0.0.1:10808
```

<Warning>

Kontrollera att `OVERLEAF_SITE_URL` är korrekt angiven innan du konfigurerar callback-URL:en för GitHub OAuth.

</Warning>

Om du befinner dig i Fastlandskina kan du behöva konfigurera en proxy för att nå GitHub. Ange följande miljövariabel: `GITHUB_SYNC_PROXY_URL=http://10.0.0.1:10808`.

<Warning>

Använd inte `127.0.0.1` som proxyvärd. Om proxyn körs på värdservern använder du serverns LAN-IP-adress (till exempel `192.168.1.xx`) och ser till att proxyn är konfigurerad att ta emot anslutningar från enheter i det lokala nätverket.

</Warning>
