En Kubernetes-driftsättning läser samma miljövariabler som Toolkit. Där en Toolkit-sida säger ”lägg till detta i `config/variables.env`” lägger du värdet i ConfigMap `overleaf-env`, eller i Secret `overleaf-secrets` när det är ett lösenord, en nyckel eller en token. Starta sedan om:

```bash
kubectl -n overleaf apply -f 30-config.yaml        # after editing the ConfigMap
kubectl -n overleaf patch secret overleaf-secrets --type merge \
  -p '{"stringData":{"GITHUB_TOKEN_CIPHER_PASSWORD":"'"$(openssl rand -hex 32)"'"}}'
kubectl -n overleaf rollout restart deployment/overleaf
```

Värden i `config/overleaf.rc` är Toolkit-inställningar, inte miljövariabler; avsnittet Frågor och svar i slutet av den här sidan beskriver vad som ersätter dem.

### Certifikat och andra filer

Vissa funktioner tar en filsökväg i stället för ett värde: SAML-certifikaten (`OVERLEAF_SAML_IDP_CERT`, ...), LDAP-CA:n (`OVERLEAF_LDAP_TLS_OPTS_CA_PATH`) eller en privat CA för en egenhostad GitHub Enterprise, GitLab eller Gitea (`NODE_EXTRA_CA_CERTS`). Lägg filerna i en Secret och montera den där Toolkit-sidorna förväntar sig dem, `/var/lib/overleaf/certs`:

```bash
kubectl -n overleaf create secret generic overleaf-certs --from-file=idp_cert.pem --from-file=ca.pem
```

```yaml title="40-overleaf.yaml (additions)"
          volumeMounts:
            # ...
            - name: certs
              mountPath: /var/lib/overleaf/certs
              readOnly: true
      volumes:
        # ...
        - name: certs
          secret:
            secretName: overleaf-certs
```

Hänvisa sedan till dem via sökväg i ConfigMap, till exempel `NODE_EXTRA_CA_CERTS: /var/lib/overleaf/certs/ca.pem`, och starta om.

<Warning>

<strong>Chifferlösenord.</strong> Ange varje `*_CIPHER_PASSWORD` för de funktioner du använder i Secret. Annars genererar vissa funktioner en nyckelfil på datavolymen vid första användningen: med en replik fungerar det tills volymen går förlorad, med flera repliker skulle varje replik kryptera med en annan nyckel.

</Warning>

### Frågor och svar

<Accordion title="Vilka Toolkit-inställningar från `config/overleaf.rc` behöver jag?">

<strong>Svar:</strong> Ingen av dem läses av Ayakaleaf Pro. Deras motsvarigheter i Kubernetes:

| `config/overleaf.rc`                         | Kubernetes                                                        |
| -------------------------------------------- | ----------------------------------------------------------------- |
| `OVERLEAF_LISTEN_IP`, `OVERLEAF_PORT`        | Service (NodePort) eller din ingress                              |
| `SIBLING_CONTAINERS_ENABLED`                 | `SANDBOXED_COMPILES*` i ConfigMap, Docker-socketen i podden       |
| `GIT_BRIDGE_ENABLED`                         | [Git-integration](/sv/on-premises/configuration/kubernetes/integrations/git-integration)                             |
| `MONGO_ENABLED`, `REDIS_ENABLED`, `MONGO_URL`, `REDIS_HOST` | StatefulSets eller dina hanterade tjänster, `OVERLEAF_MONGO_URL` och `OVERLEAF_REDIS_HOST` |
| `REDIS_AOF_PERSISTENCE`                      | `--appendonly yes` i `20-redis.yaml`                              |
| `NGINX_ENABLED`, `TLS_*`                     | din ingress eller lastbalanserare                                 |

</Accordion>
