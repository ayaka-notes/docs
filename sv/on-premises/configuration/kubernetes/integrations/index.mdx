Varje integration är avstängd som standard, utom Overleaf Import API. GitHub-, GitLab-, Gitea- och Dropbox-synkronisering samt MCP-servern kräver också [Git-integrationen](/sv/on-premises/configuration/kubernetes/integrations/git-integration). När du har slagit på en integration i ConfigMap:en eller Secret:en startar du om replikerna med `kubectl -n overleaf rollout restart`.
