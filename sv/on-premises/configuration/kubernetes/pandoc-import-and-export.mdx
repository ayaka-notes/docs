title: Import och export med Pandoc

---

Pandoc-konverteringar körs av tjänsten **clsi** i varje Ayakaleaf Pro-pod, precis som kompileringar: clsi ber nodens Docker Engine att starta en container från `PANDOC_IMAGE`. Tjänsten **web** visar menyerna för import och export. Vad funktionen gör och hur du bygger avbildningen beskrivs i [Import och export med Pandoc](/sv/on-premises/configuration/overleaf-toolkit/pandoc-import-and-export).

| | |
| --- | --- |
| Tjänster | web (menyer och routes), clsi (kör konverteringen), i varje Ayakaleaf Pro-pod |
| Nod | Docker Engine och `PANDOC_IMAGE`, på varje nod som kan köra Ayakaleaf Pro |
| Kräver | [Sandlådekompilering](/sv/on-premises/configuration/kubernetes/sandboxed-compiles) |
| Periodiska jobb | inga |

### Konfiguration

<Steps>
<Step title="Lägg in avbildningen i Docker på varje nod">
Bygg avbildningen en gång från mappen `develop/pandoc` i repositoriet [ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) och läs sedan in den i Docker på varje nod som kan köra Ayakaleaf Pro:

```bash
docker build -t overleaf-pandoc:local develop/pandoc
docker save overleaf-pandoc:local | ssh node-1 sudo docker load    # repeat for every node
```

Eller pusha den till ett register som noderna kan nå och kör `sudo docker pull` på varje nod. Precis som med TeX Live-avbildningarna måste den finnas i **Docker**, inte bara i containerd.
</Step>

<Step title="ConfigMap">
```yaml
  ENABLE_PANDOC_CONVERSIONS: "true"
  PANDOC_IMAGE: overleaf-pandoc:local
```

Både web och clsi läser `ENABLE_PANDOC_CONVERSIONS` från samma ConfigMap, så de kan inte vara oense på Kubernetes.
</Step>

<Step title="Tillämpa och starta om">
```bash
kubectl apply -f 30-config.yaml
kubectl -n overleaf rollout restart deployment/overleaf     # or statefulset/overleaf
```
</Step>
</Steps>

### Flera repliker

Inget extra utöver att avbildningen finns på varje nod: varje replik konverterar på sin egen nod.

### Testat på Kubernetes

Med avbildningen byggd från `develop/pandoc` och inläst i Docker på varje nod med `docker save | docker load`, på Kubernetes 1.37 med en replik, klarar våra end-to-end-tester för Pandoc sig (6 fall): import av ett Markdown-dokument som ett LaTeX-projekt, felet som visas för ett trasigt Word-dokument, export till Word (som kan importeras igen), Markdown och HTML samt menyerna som döljs utan `ENABLE_PANDOC_CONVERSIONS`.
