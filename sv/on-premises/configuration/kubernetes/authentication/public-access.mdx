Gäståtkomst till delade projekt, offentliga sidor och självregistrering aktiveras med miljövariabler som tjänsten **web** läser; realtidstjänsten betjänar sedan gäster via deras session. Vad varje inställning öppnar beskrivs i [Offentlig åtkomst](/sv/on-premises/configuration/overleaf-toolkit/authentication/public-access).

| | |
| --- | --- |
| Tjänst | web (och real-time för gäster i redigeraren), i varje Ayakaleaf Pro-pod; läses när web startar |
| Pod → utsidan | SMTP-servern, när registreringen skickar aktiveringsmejl |
| Tillstånd | gästers åtkomsttokens i sessionen, hastighetsbegränsningar för registrering i Redis |
| Periodiska jobb | inga |

### Konfiguration

Lägg till de inställningar du behöver i ConfigMap `overleaf-env`:

```yaml title="30-config.yaml (additions)"
  # Guests open link-shared projects without an account
  OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING: "true"
  # Signed-out visitors may open /learn, /templates, /devs and view links
  OVERLEAF_ALLOW_PUBLIC_ACCESS: "true"
  # Self-registration: "true", or only some domains
  OVERLEAF_ALLOW_PUBLIC_REGISTRATION: "@example.com, @*.uni.example"
```

```bash
kubectl apply -f 30-config.yaml
kubectl -n overleaf rollout restart deployment/overleaf     # or statefulset/overleaf
```

Citera varje värde. Värden som börjar med `@` måste citeras i YAML, annars avvisar `kubectl apply` filen.

Registrering som är begränsad till domäner skickar ett aktiveringsmejl, så [E-postleverans](/sv/on-premises/configuration/kubernetes/email-delivery) måste fungera från poddarna: lägg SMTP-värden i ConfigMap och `OVERLEAF_EMAIL_SMTP_PASS` i Secret.

### Flera repliker

Inget extra. En gästs åtkomst till ett projekt sparas i sessionen i Redis, så redigeraren fungerar på vilken replik lastbalanseraren än väljer.

### Testat på Kubernetes

På Kubernetes 1.37 klarar våra end-to-end-tester för offentlig åtkomst sig: på en replik, självregistrering med `OVERLEAF_ALLOW_PUBLIC_REGISTRATION` satt till `true`, till en domän, till flera domäner med ett jokertecken för underdomäner och till `@*`, med aktiveringsmejl för domänlägena (43 fall); utloggade besökare på `/devs` och ett postat kodavsnitt som bevaras genom inloggningen med `OVERLEAF_ALLOW_PUBLIC_ACCESS` (2 fall); en utloggad gäst i ett länkdelat projekt med båda inställningarna aktiverade (3 fall); och på tre repliker bakom HAProxy, OIDC tillsammans med offentlig åtkomst (1 fall).
