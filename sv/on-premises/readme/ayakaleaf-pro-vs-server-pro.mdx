---
title: Overleaf Server Pro vs. Ayakaleaf Pro
description: Overleaf Server Pro och Ayakaleaf Pro Edition är båda lokalt driftsatta versioner av Overleaf. Men vilka är skillnaderna?
icon: scale-balanced
---

<Info>

Ayakaleaf Pro är en förbättrad implementation av Overleaf Community Edition som erbjuder alla premiumfunktioner från Server Pro _**gratis**_. Till skillnad från Overleaf Common på [https://www.overleaf.com/](https://www.overleaf.com/) har vi inga begränsningar för kompileringstid och inga licenskrav för antalet användare, och du kan själv hysa all din data, vilket garanterar absolut säkerhet.

Overleaf Server Pro är en kommersiell, egenhostad driftsättning av Overleaf med officiell support. Mer information om Server Pro finns på [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud).

</Info>

<Warning>

Overleaf Community Edition är avsedd att användas i miljöer där **alla** användare är betrodda. Community Edition är **inte** lämplig för scenarier där användare måste isoleras från varandra, eftersom Sandbox Compiles inte är tillgängligt.

Utan sandlåda körs LaTeX-kompileringar med samma behörigheter som containern, vilket ger åtkomst till dess filsystem, nätverk och miljövariabler. Detta medför risk för dataläckage eller att systemet komprometteras. Kompileringar utan sandlåda bör endast användas i helt betrodda miljöer; för fleranvändar- eller produktionsdriftsättningar rekommenderas Sandbox Compiles starkt.

Mer information om Sandbox Compiles finns i vår [dokumentation](/sv/on-premises/configuration/overleaf-toolkit/sandboxed-compiles).

</Warning>

### Community-support

För dig som använder en egenhostad Overleaf-instans ges support av communityn via GitHub [Issues](https://github.com/ayaka-notes/ayakaleaf-pro/issues).

För att hålla dig på en version som stöds kan du kontrollera vilken version av Overleaf du kör genom att jämföra utdata från kommandot nedan med de avbildnings-ID:n som publiceras i versionsinformationen.

```bash
docker inspect --format '{{.Image}}' sharelatex | awk -F: '{print substr($2, 1, 12)}'
```
