### Översikt över Overleaf

Overleaf är en samarbetsinriktad LaTeX-redigerare som är omtyckt av forskare och tekniska team. Molnversionen finns på [overleaf.com](https://www.overleaf.com/). Den erbjuder en fullfjädrad LaTeX-redigerare online. Overleaf Common (SaaS-versionen) har dock många funktionsbegränsningar, och du måste stå ut med en _**kompileringstidsgräns på 10 sekunder**_ och dyra medlemsavgifter.

<Warning>

Overleaf Community Edition är avsedd att användas i miljöer där **alla** användare är betrodda. Community Edition är **inte** lämplig för scenarier där användare måste isoleras från varandra, eftersom Sandbox Compiles inte är tillgängligt.

Utan sandlåda körs LaTeX-kompileringar med samma behörigheter som containern, vilket ger åtkomst till dess filsystem, nätverk och miljövariabler. Detta medför risk för dataläckage eller att systemet komprometteras. Kompileringar utan sandlåda bör endast användas i helt betrodda miljöer; för fleranvändar- eller produktionsdriftsättningar rekommenderas Sandbox Compiles starkt.

Mer information om Sandbox Compiles finns i: [sandboxed-compiles.md](/sv/on-premises/configuration/overleaf-toolkit/sandboxed-compiles  "mention")

</Warning>

### Information och pris för Overleaf Server Pro

Overleafs webbplats erbjuder endast ett sätt att kontakta support angående Server Pro, så informationen om Server Pro är mycket begränsad. Men baserat på den information vi har samlat in i communityn är **offerten för Server Pro**:

* Du måste köpa licenser för _minst_ 10 personer.
* En licens för 10 personer kostar cirka 3 477,61 €. (2024)
* För utbildning kostar 20 användare 2640 euro per år, 50 användare 6050 euro och 100 användare 9963 euro.
* Server Pro är endast tillgängligt i utvalda regioner (t.ex. inte i Kina).

Baserat på den information som för närvarande finns tillgänglig verkar Overleaf Server Pro kosta omkring \$300 per användare och år, med ett minimiköp på 10 licenser, vilket gör det till ett mycket dyrt alternativ. Dessutom erbjuder Server Pro betydligt färre funktioner än Ayakaleaf Pro. Vi är djupt tacksamma mot de communityutvecklare vars bidrag genom åren har gjort det möjligt för oss att bygga Ayakaleaf Pro och i slutändan överträffa Overleaf Server Pro i både funktionalitet och kapacitet.

Följande offentliga uppgifter visar dokumenterade köp och priser för Overleaf Server Pro. Mindre amerikanska kontrakt tyder på årliga kostnader på ungefär \$320–\$370 per användare. Stora institutionella avtal kan få lägre pris per användare. Till exempel ger Max Planck-sällskapets treåriga avtal i genomsnitt cirka 51 € per användare och år. Avtalsvillkor, support och driftsättningens omfattning kan skilja sig åt. Dessa uppgifter är ingen officiell prislista från Overleaf.

### Varför Ayakaleaf Pro?

<Info>

Ayakaleaf Pro är _**inte**_ knutet till Overleaf, Inc. eller dess moderbolag Digital Science. Det är heller _inte Server Pro_ Edition, som är en kommersiell produkt från Overleaf, Inc. [ayaka-notes](https://github.com/ayaka-notes) utvecklar och underhåller Ayakaleaf Pro som ett oberoende projekt.

</Info>

Ayakaleaf Pro är en förbättrad implementation av Overleaf Community Edition som erbjuder _**alla**_ premiumfunktioner från Server Pro _**gratis**_. Till skillnad från Overleaf Common på [https://www.overleaf.com/](https://www.overleaf.com/), eller den kommersiella utgåvan Server Pro, har vi

* _**inga begränsningar**_ för kompileringstid
* _**inga licenskrav**_ för antalet användare
* _**alla funktioner**_ från Server Pro upplåsta
