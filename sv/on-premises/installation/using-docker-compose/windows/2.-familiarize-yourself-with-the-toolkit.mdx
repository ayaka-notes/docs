Toolkit är detsamma som på Linux. Dess struktur, katalogen `config/` och kommandona i `bin/` beskrivs i [2. Bekanta dig med Toolkit](/sv/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) i Linux-guiden.

På Windows ska du tänka på följande skillnader:

* Kör `bin/`-kommandon i **Ubuntu Bash**, från `~/ayakaleaf-toolkit`. Kommandon som är markerade med **PowerShell** körs i stället i Windows.
* Starta Docker Desktop och aktivera Ubuntus WSL Integration innan du använder `bin/up`, `bin/start` eller `bin/docker-compose`.
* Behåll Linux-radslut (LF) i konfigurationsfilerna. Redigera dem med `nano` i Ubuntu eller med en redigerare som är ansluten till WSL. CRLF-radslut kan orsaka Bash-fel.
* `bin/doctor` kör Linux-kontroller inuti Ubuntu. Varningen om att du inte är inloggad på `quay.io` gäller inte den publika avbildningen `ghcr.io/ayaka-notes/overleaf-pro`. Andra varningar behöver fortfarande åtgärdas.

```bash
bin/doctor
```
