Ayakaleaf Pro är en kostnadsfri Docker-avbildning i [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Du behöver inget konto, ingen inloggning och ingen kommersiell Overleaf-licens för att hämta den.

Öppna `config/overleaf.rc` och ange:

```bash title="config/overleaf.rc"
SERVER_PRO=true
```

Nästa gång du kör `bin/up` hämtar Toolkit `ghcr.io/ayaka-notes/overleaf-pro` i versionen från `config/version`, i stället för den officiella Overleaf Community Edition.

Avbildningen byggs för `arm64` och `amd64`, och Docker väljer den som matchar Docker-motorns arkitektur.
