I det här avsnittet kör vi Ayakaleaf Pro lokalt på Windows med WSL 2, Ubuntu, Docker Desktop och [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). Guiden använder `http://localhost:8080`, lagrar data i Ubuntus hemkatalog och aktiverar sandlådekompilering.

Applikationen, MongoDB, Redis och TeX Live körs i Linux-containrar som hanteras av Docker Desktop. Kör Toolkit-kommandon i Ubuntu; öppna applikationen i din webbläsare i Windows. [Steg 0](/sv/on-premises/installation/using-docker-compose/windows/0.-setup-wsl-and-docker-desktop) förklarar hur Windows- och Linux-delarna hänger ihop och börjar med installationen av WSL.

Du kan använda Windows för en lokal instans eller hålla den igång kontinuerligt med tillgänglighetsinställningarna i steg 6. För delade servrar och produktionsservrar rekommenderar vi [Linux-guiden](/sv/on-premises/installation/using-docker-compose/linux), med HTTPS, säkerhetskopior och åtkomstkontroll. Windows viloläge, avstängning av Docker Desktop och avstängning av WSL avbryter den här lokala instansen; se [Håll instansen tillgänglig](/sv/on-premises/installation/using-docker-compose/windows/6.-post-installation-tasks#keep-the-instance-available).

## Innan du börjar {#before-you-start}

Du behöver:

* En Windows-version och en processor som stöds av [Docker Desktop for Windows](https://docs.docker.com/desktop/setup/install/windows-install/), med hårdvaruvirtualisering aktiverad. Den här guiden använder Windows 11 på x86-64.
* Behörighet att aktivera WSL och installera programvara. WSL måste vara version 2.1.5 eller senare, med Ubuntu i WSL 2-läge.
* Tillräckligt med minne för Windows och containrarna. För en liten lokal instans är 4 CPU:er och 8 GB tillgängliga för Docker en föreslagen utgångspunkt, inte ett uppmätt minimum.
* Ledigt lagringsutrymme på den Windows-disk som innehåller WSL- och Docker-data. Räkna med minst 40 GB för en fullständig TeX Live-konfiguration plus projektdata; basavbildningen i [steg 5](/sv/on-premises/installation/using-docker-compose/windows/5.-personalizing-your-instance) är mindre och lämpar sig för det första driftsättningstestet. Ytterligare avbildningsversioner kräver ytterligare utrymme.
* Nätverksåtkomst till GitHub, GitHub Container Registry (`ghcr.io`) och Docker Hub för att klona Toolkit och ladda ner avbildningar.

**PowerShell**-block körs i Windows. **Bash**-block och `bin/`-kommandon körs i Ubuntu om inget annat anges. Kör inte Toolkit-skript i PowerShell eller i Git Bash för Windows.
