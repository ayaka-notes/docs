<Steps>
<Step title="Installera kommandoradsverktygen">
Kör i **Ubuntu** med det Linux-lösenord som du skapade i steg 0:

```bash
sudo apt update
sudo apt install -y git ca-certificates curl perl gawk openssl
```

Ubuntu har redan Bash, GNU sed och coreutils. Till skillnad från macOS behövs varken Homebrew eller en separat installation av GNU sed.
</Step>

<Step title="Klona Ayakaleaf Toolkit-repositoriet">
Behåll Toolkit och dess data i Ubuntus Linux-filsystem, under din hemkatalog:

```bash
cd "$HOME"
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

Undvik `/mnt/c`, `/mnt/d`, OneDrive och temporära kataloger för den aktiva databasen och projektdata. Sökvägar i Linux-filsystemet ger de behörigheter och det filsystemsbeteende som containrarna förväntar sig, och undviker overhead mellan filsystem; se [Microsofts vägledning om filsystem](https://learn.microsoft.com/en-us/windows/wsl/filesystems).

<Warning>

Om katalogen redan innehåller en installation använder du den som den är, eller väljer en annan katalog för en ny instans. Ersätt inte konfigurationen eller data för en befintlig driftsättning.

</Warning>
</Step>
</Steps>
