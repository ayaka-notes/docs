---
title: 4. Hämta Ayakaleaf Pro-avbildningar
icon: split
---

Ayakaleaf Pro är en kostnadsfri Docker-avbildning i [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Du behöver inget konto eller någon inloggning för att hämta den. Avbildningarna byggs för amd64 och arm64, och Docker väljer den som passar din server.

Öppna `config/overleaf.rc` och ange:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

Nästa gång du kör `bin/up` laddar Toolkit ned Ayakaleaf Pro-avbildningen och använder den i stället för den officiella Overleaf Community Edition. Dina inställningar i `config/` fortsätter att fungera.

<Accordion title="Kör du redan det officiella Overleaf Toolkit (overleaf/toolkit)?">

Du behöver inte installera om. Hämta Ayakaleaf Pro-avbildningen:

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Lägg sedan till en fil med namnet `docker-compose.override.yml` med följande innehåll i katalogen `overleaf-toolkit/config`:

```yml
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

Nästa gång du kör `bin/up` använder Toolkit Ayakaleaf Pro-avbildningen.

</Accordion>
