Docker Compose på en enskild server är det rekommenderade sättet att driftsätta Ayakaleaf Pro. Du kör det via [Toolkit](https://github.com/ayaka-notes/toolkit): en uppsättning skript som omsluter `docker compose` och läser dina inställningar från en enda `config/`-katalog, så att `bin/up` ersätter `docker compose up`.
