Toolkit är detsamma på macOS och Linux. Dess struktur, katalogen `config/` och kommandona i `bin/` beskrivs i [2. Bekanta dig med Toolkit](/sv/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) i Linux-guiden.

På macOS ska du tänka på tre skillnader:

* Kör skripten från en terminal där GNU sed kommer först i `PATH`, se [1. Ladda ner Toolkit](/sv/on-premises/installation/using-docker-compose/macos/1.-download-the-toolkit).
* Starta Docker Desktop innan du kör ett skript som kommunicerar med Docker, till exempel `bin/up`, `bin/start` eller `bin/docker-compose`.
* `bin/doctor` innehåller kontroller som ärvts från det officiella Overleaf Toolkit. Varningen `This system seems to not be Linux` är förväntad på macOS, och varningen om att du inte är inloggad på `quay.io` gäller inte den publika avbildningen `ghcr.io/ayaka-notes/overleaf-pro`. Andra problem i rapporten är fortfarande viktiga.
