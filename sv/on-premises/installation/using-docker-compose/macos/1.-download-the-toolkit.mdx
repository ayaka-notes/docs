<Steps>
<Step title="Kontrollera Git och Homebrew">
```bash
git --version
brew --version
```

Om macOS ber dig installera Command Line Tools när du kör Git installerar du dem först. Om Homebrew saknas installerar du det enligt de [officiella instruktionerna](https://brew.sh/).
</Step>

<Step title="Lägg GNU sed i PATH">
Toolkits skript använder GNU sed-alternativ som den BSD sed som är inbyggd i macOS inte accepterar. Installera [GNU sed](https://formulae.brew.sh/formula/gnu-sed) och lägg det först i `PATH` i den här terminalen:

```bash
brew install gnu-sed
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
sed --version
```

Det sista kommandot ska skriva ut **GNU sed**.

Ett alias som `alias sed=gsed` räcker inte: Toolkit kör Bash-skript, som inte ser aliasen i ditt interaktiva skal. Du behöver inte ersätta `/usr/bin/sed`.

Kör raden `export PATH=...` igen i varje ny terminal som du använder för Toolkit, eller lägg till den i skalets startfil efter Homebrews egen initiering.
</Step>

<Step title="Klona Ayakaleaf Toolkit-repositoriet">
Välj en katalog som består. Undvik `/tmp`, flyttbara enheter och molnsynkroniserade mappar som iCloud Drive för den aktiva databasen och projektdata. Den här guiden använder `~/ayakaleaf-toolkit`:

```bash
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

<Warning>

Om katalogen redan innehåller en installation använder du den som den är, eller väljer en annan katalog för en ny instans. Initiera inte en ny konfiguration ovanpå en befintlig driftsättning.

</Warning>
