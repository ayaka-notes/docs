---
title: 3. Initiera konfigurationen
description: Skapa Toolkits konfigurationsfiler på din Mac med bin/init.
icon: circle-play
---

Kör följande från Toolkit-katalogen, i en terminal med GNU sed i `PATH`:

```bash
bin/init
```

`bin/init` skapar tre filer:

| Fil | Syfte |
| --- | --- |
| `config/overleaf.rc` | Containerinställningar, den publicerade porten och dataplatserna |
| `config/variables.env` | Applikationsinställningar och hemligheter |
| `config/version` | Applikationsavbildningens version |

Det genererar också `OVERLEAF_INVITE_TOKEN_SECRET` i `config/variables.env`. Behåll den, och publicera inte filen eller checka in den i versionshantering.

Behåll den version som Toolkit väljer för en ny installation. För att senare ändra versionen för en befintlig instans följer du [Uppgradera din driftsättning](/sv/on-premises/maintenance/upgrading-your-deployment).

<Warning>

Om `bin/init` stoppar med `sed: ... invalid command code` kördes det med macOS BSD sed. En sådan misslyckad körning kan lämna alla tre filerna i `config/` med en tom `OVERLEAF_INVITE_TOKEN_SECRET`, och om du kör `bin/init` igen rapporteras då `Config files already exist`. Se [Felsökning](/sv/on-premises/installation/using-docker-compose/macos/troubleshooting#initialization-fails-with-invalid-command-code).

</Warning>
