I det här avsnittet kör vi Ayakaleaf Pro lokalt på din Mac med Docker Desktop och [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). Guiden använder `http://localhost:8080`, lagrar data i din hemkatalog och kompilerar med TeX Live 2026 i sandlådecontainrar.

Docker Desktop kör applikationen, MongoDB, Redis och TeX Live-kompilatorn i en virtuell Linux-maskin. Du installerar inte MongoDB, Redis eller MacTeX i själva macOS.

Använd den här konfigurationen för personligt bruk och lokal testning. För en delad tjänst som alltid är igång rekommenderar vi [Linux-guiden](/sv/on-premises/installation/using-docker-compose/linux), med HTTPS, säkerhetskopior och åtkomstkontroll. Instansen är inte tillgänglig medan din Mac är i viloläge eller Docker Desktop är stoppat, se [Håll instansen tillgänglig](/sv/on-premises/installation/using-docker-compose/macos/6.-post-installation-tasks#keep-the-instance-available).

## Innan du börjar {#before-you-start}

Du behöver:

* En macOS-version som stöds av [Docker Desktop for Mac](https://docs.docker.com/desktop/setup/install/mac-install/).
* Git, [Homebrew](https://brew.sh/) och GNU sed. Toolkit använder GNU sed-alternativ som den BSD sed som är inbyggd i macOS inte accepterar.
* Tillräckliga resurser för både macOS och Docker. För en liten lokal instans kan du börja med 4 CPU:er och 8 GB minne tilldelade till Docker Desktop. Detta är en föreslagen utgångspunkt, inte ett uppmätt minimum.
* Minst 40 GB ledigt lagringsutrymme för en fullständig TeX Live-avbildning, plus utrymme för dina projekt. Kontrollera både det lediga utrymmet på din Mac och Docker Desktops gräns för diskanvändning. Börja med en TeX Live-version: varje ytterligare version kräver ungefär lika mycket utrymme till.

Applikations- och TeX Live-avbildningarna publiceras för `arm64` och `amd64`. På Apple silicon låter du Docker välja den inbyggda ARM-avbildningen och tvingar inte fram `platform: linux/amd64`.
