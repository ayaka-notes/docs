Ayakaleaf Pro körs på Docker. På en Mac använder du Docker Desktop, som kör Docker-motorn i en virtuell Linux-maskin.

<Steps>
<Step title="Installera och starta Docker Desktop">
Installera den version av [Docker Desktop](https://docs.docker.com/desktop/setup/install/mac-install/) som passar din Mac (Apple silicon eller Intel), öppna den och vänta tills motorn har startat. Du kan också starta den från Terminal:

```bash
open -a Docker
```
</Step>

<Step title="Kontrollera Docker-motorn">
Kör dessa kommandon i Terminal:

```bash
docker context show
docker info
docker compose version
```

Kontexten ska peka på din lokala Docker Desktop-motor, normalt `desktop-linux`. Om en annan kontext är vald byter du till Docker Desktop innan du fortsätter:

```bash
docker context use desktop-linux
```

`docker info` måste skriva ut ett **Server**-avsnitt. `docker --version` visar bara att klienten är installerad.
</Step>

<Step title="Kontrollera resurser och fildelning">
I Docker Desktops **Settings** kontrollerar du gränserna för CPU, minne och disk mot [Innan du börjar](/sv/on-premises/installation/using-docker-compose/macos#before-you-start), samt inställningarna för fildelning, se [Docker Desktop settings](https://docs.docker.com/desktop/settings-and-maintenance/settings/).

Den här guiden placerar Toolkit under `/Users`, som Docker Desktop delar som standard. Om du använder en annan plats och `bin/up` misslyckas med `Mounts denied` lägger du till den katalogen i fildelningen.
</Step>

<Step title="Kontrollera Docker-socketen för sandlådekompilering">
Toolkit monterar `/var/run/docker.sock` i applikationen så att den kan starta en separat TeX Live-container för varje kompilering. Behåll `DOCKER_SOCKET_PATH=/var/run/docker.sock` i `config/overleaf.rc`.

Docker CLI på macOS kan ansluta via `~/.docker/run/docker.sock`. Det är klientens slutpunkt på din Mac, inte ett skäl att ändra källan för Toolkits montering: kompilatorn behöver motorns socket så som Linux-containrar ser den.

Om `/var/run/docker.sock` saknas på din Mac aktiverar du **Allow the default Docker socket to be used** under **Settings → Advanced**, se [Dockers behörighetskrav](https://docs.docker.com/desktop/setup/install/mac-permission-requirements/).

<Danger>

Kör inte `chmod 777` på socketen för att kringgå fel. Åtkomst till Docker-socketen motsvarar root-åtkomst till Dockers virtuella maskin.

</Danger>
</Step>
</Steps>
