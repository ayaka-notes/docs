### Skapa administratören och ett första projekt {#create-the-administrator-and-a-first-project}

Öppna [http://localhost:8080/launchpad](http://localhost:8080/launchpad), skapa det första administratörskontot och logga in. Följ sedan [6. Uppgifter efter installationen](/sv/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks) i Linux-guiden och använd port `8080` i dess exempel-URL:er.

### Verifiera kompileringen {#verify-compilation}

Att en inloggningssida öppnas bevisar inte att de separata kompileringscontainrarna och deras datamonteringar fungerar. Skapa ett tomt projekt och kompilera denna `main.tex`:

```latex
\documentclass{article}
\begin{document}
Ayakaleaf Pro on macOS.
\end{document}
```

PDF-förhandsvisningen ska visa texten. Välj vid behov TeX Live 2026 i projektinställningarna.

För ett projekt med kinesisk text väljer du **XeLaTeX** som kompilator och testar:

```latex
\documentclass{ctexart}
\begin{document}
你好，Ayakaleaf Pro。
\end{document}
```

### Verifiera beständigheten {#verify-persistence}

```bash
bin/stop
bin/start
```

Öppna projektet igen och kompilera det på nytt. Ditt konto, källkoden och projektfilerna ska fortfarande finnas kvar. Med standardsökvägarna ligger de aktiva data i Toolkits katalog `data/` på din Mac.

### Håll instansen tillgänglig {#keep-the-instance-available}

Medan din Mac är i viloläge pausar macOS Docker Desktops virtuella maskin med alla containrar i den: ingen kan öppna instansen, och en pågående kompilering stoppas tills din Mac vaknar. Det är bara systemets viloläge som spelar roll. Skärmen får stängas av.

Om andra personer använder instansen, eller om du låter långa uppgifter köras, håller du din Mac ansluten till ström och förhindrar automatiskt viloläge, se [Ställa in vilo- och väckningsinställningar på datorn](https://support.apple.com/guide/mac-help/set-sleep-and-wake-settings-mchle41a6ccd/mac):

| Mac | Inställning |
| --- | --- |
| Stationär Mac (Mac mini, iMac, Mac Studio, Mac Pro) | **System Settings → Energy**: aktivera **Prevent automatic sleeping when the display is off** |
| MacBook | **System Settings → Battery → Options**: aktivera **Prevent automatic sleeping on power adapter when the display is off**. Detta gäller bara när strömadaptern är ansluten, och om locket stängs går MacBooken fortfarande i viloläge |

För att bara hålla din Mac vaken en stund kör du i stället `caffeinate -i` i ett Terminal-fönster. Det förhindrar viloläge vid inaktivitet tills du trycker på `Ctrl+C` eller stänger fönstret.

Docker Desktop är en app i din användarsession. För att instansen ska komma tillbaka efter en omstart aktiverar du **Start Docker Desktop when you sign in to your computer** under Docker Desktops **Settings → General**. Toolkits containrar använder `restart: always`, så Docker startar dem igen när Docker Desktop körs, utan `bin/up`. Tills någon loggar in på din Mac efter en omstart förblir instansen nere.

<Info>

En Mac som hålls vaken använder mer ström. För en tjänst som alltid måste vara nåbar rekommenderar vi en Linux-server, se [Linux](/sv/on-premises/installation/using-docker-compose/linux).

</Info>

### Daglig användning {#daily-use}

Öppna Docker Desktop innan du hanterar instansen. I en ny terminal:

```bash
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
cd "$HOME/ayakaleaf-toolkit"
```

| Uppgift | Kommando |
| --- | --- |
| Starta de befintliga containrarna | `bin/start` |
| Stoppa containrarna och behåll data | `bin/stop` |
| Tillämpa konfigurationsändringar | `bin/up -d` |
| Kontrollera statusen | `bin/docker-compose ps` |
| Läs startloggarna | `bin/docker-compose logs --tail=100 sharelatex` |
| Läs kompilatorloggarna | `bin/logs -f clsi` |

`bin/start` tillämpar inte ändringar i `config/`: kör `bin/up -d` efter att du har redigerat konfigurationen. Behåll `config/` och `data/`, och följ [Data och säkerhetskopior](/sv/on-premises/maintenance/data-and-backups) före en uppgradering eller innan du flyttar installationen. Att kopiera databasfilerna medan MongoDB skriver till dem ger ingen konsekvent säkerhetskopia.

Behåll instansen på `127.0.0.1` för lokal användning. För att betjäna andra datorer anger du medvetet lyssningsadress, webbplats-URL och HTTPS, se [5. Anpassa din instans](/sv/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance) i Linux-guiden.

Om något inte fungerar, se [Felsökning](/sv/on-premises/installation/using-docker-compose/macos/troubleshooting).
