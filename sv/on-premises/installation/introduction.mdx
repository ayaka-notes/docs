Precis som Overleaf Server Pro levereras vår Ayakaleaf Pro som en Docker-container och är en direkt ersättning som dessutom innehåller funktioner som SSO via LDAP och SAML2, förbättrad säkerhet, spårade ändringar, kommentarer, vår optimerade version av TeX Live, mallar och en administrationspanel.

* Om du bara vill testa Ayakaleaf Pros funktioner eller prova demon kan du följa vår guide [using-the-github-codespace.md](/sv/on-premises/installation/using-the-github-codespace  "mention"). Demomiljön använder en minimal TeX Live-installation, så vissa av dina projekt kanske inte kompileras.
* Om du aldrig har driftsatt någon version av Overleaf tidigare, se [Konfigurera Docker](/sv/on-premises/installation/setup-docker) för att först installera Docker Engine, och installera sedan Overleaf [using-the-toolkit](/sv/on-premises/installation/using-the-toolkit  "mention").
* Om du redan har driftsatt Community Edition av Overleaf, se [migrate-from-existing.md](/sv/on-premises/installation/migrate-from-existing  "mention") för att migrera till Ayakaleaf Pro.
* Om du föredrar att använda agenter som Claude eller Codex kan du läsa: [using-claude-or-codex.md](/sv/on-premises/installation/using-claude-or-codex  "mention").
* Om du behöver driftsätta i en offlinemiljö eller isolerad miljö, se: [air-gapped-offline-deployments.md](/sv/on-premises/installation/air-gapped-offline-deployments  "mention").
* Om du är en befintlig Server Pro-användare ber vi dig öppna ett issue och meddela oss innan du migrerar till Ayakaleaf Pro, eftersom malldata lagras i ett något annorlunda format. Vi hjälper dig gärna att migrera från Server Pro till Ayakaleaf Pro kostnadsfritt.
* Om du någon gång tröttnar på vår Ayakaleaf Pro och vill byta tillbaka till den officiella Overleaf Community Edition stöds det fullt ut. Ingen av dina data går förlorad. Användare av den officiella Overleaf Toolkit tar helt enkelt bort sin override-YAML-fil. Användare av ayaka-notes toolkit inaktiverar alternativet `SERVER_PRO`. Allt återgår då till standardversionen av Community Edition.

### Hårdvarukrav

Vi har genomfört relevanta tester och funnit att om du kör Overleaf på en server med 2 kärnor och 2 GB RAM förbrukar dess kärnkomponenter – som huvudsakligen bygger på Node.js – cirka 1 GB minne. Redis och MongoDB kan kräva ytterligare 0,5 GB, och att starta en Docker-container i sandlåda för kompilering kan förbruka ytterligare 0,3 GB. Det innebär att en server med 2 kärnor och 2 GB i praktiken bara klarar ungefär en samtidig kompilering åt gången.

* Minimikraven på hårdvara för att installera Ayakaleaf Pro är en processor med 2 kärnor och 3 GB RAM.
* På grund av storleken på vår TeX Live-image krävs minst 40 GB lagringsutrymme för att aktivera kompilering i sandlåda.
* Om du vill installera hela uppsättningen TeX Live-images från 2020 till 2026 bör du se till att ha minst 150 GB ledigt diskutrymme.

Här är några rekommenderade hårdvarukonfigurationer för olika användningsscenarier:

| Användningsfall                                      | Rekommenderad konfiguration                                                                          |
| ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Personligt bruk, med enstaka samarbeten              | 2 CPU-kärnor, 4 GB RAM, 80 GB lagring                                                                |
| Små team, upp till 10 användare med lätt samarbete   | 2 CPU-kärnor, 8 GB RAM, 256 GB lagring                                                               |
| Medelstora team, upp till 100 användare              | 4 CPU-kärnor, 16 GB RAM, 1 TB lagring                                                                |
| Storskaliga driftsättningar eller universitet        | Distribuerad klusterdriftsättning med S3-lagring; kontakta oss om du behöver hjälp med driftsättningen |

### Programvarukrav

När det gäller programvara rekommenderar vi en nyare och stabil version av Ubuntu (t.ex. Ubuntu 24.04 under 2025–2026, Ubuntu 22.04 under 2023–2024) tillsammans med den senaste stabila versionen av Docker.

<Info>

Stabilitet går först: välj den nyaste Ubuntu LTS-versionen som har funnits ett tag, inte en som precis har släppts. Till exempel stöds inte Ubuntu 26.04 per oktober 2026: den levereras med Linux-kärnan 7.0, och MongoDB vägrar starta på Linux-kärnor från 6.19 till och med 7.0.13 ([detaljer](https://www.mongodb.com/docs/manual/administration/production-notes/)), så använd Ubuntu 24.04.

</Info>

Vi rekommenderar inte att Ayakaleaf Pro driftsätts på Windows eller andra operativsystem som inte stöds, som CentOS, eftersom du kan stöta på kompatibilitetsproblem eller oväntade problem vid installation och drift.

Men om du vill prova att driftsätta Ayakaleaf Pro på ARM-baserade system eller macOS är du välkommen att dela dina erfarenheter och din feedback med communityn.

### LaTeX-prestanda

LaTeX är ett enkeltrådat program, vilket innebär att det bara kan använda en CPU-kärna åt gången. När ett enskilt dokument kompileras begränsas prestandan främst av processorns klockfrekvens per kärna. Ju snabbare enkärnsprestanda din processor har, desto snabbare kan du alltså kompilera ett dokument. Fler CPU-kärnor är bara till nytta när flera användare kompilerar dokument samtidigt.

Med [ThuThesis-mallen](https://www.overleaf.com/latex/templates/thuthesis-tsinghua-university-thesis-latex-template/cfwgcxtvkbsx) som exempel tar kompileringen cirka 6 sekunder på en Intel Core i9-14900K (5,6 GHz), medan den tar cirka 13 sekunder på en Azure Standard D2as v5-instans (2 vCPU:er, 8 GiB RAM) med en AMD EPYC 7763 (3,2 GHz).

Den faktiska kompileringsprestandan beror förstås på din hårdvarukonfiguration. De flesta serverprocessorer har inte lika hög klockfrekvens som 14900K, så du måste göra en avvägning mellan kostnad och kompileringshastighet.

Vi har också gjort en djupgående analys av LaTeX-kompileringens prestanda. Om du är intresserad kan du läsa vårt blogginlägg [Overleaf Benchmark: A Deep Research of Concurrent LaTeX Compilation in Overleaf (SaaS and Self-host)](/sv/blog/2026/overleaf-benchmark  "mention").
