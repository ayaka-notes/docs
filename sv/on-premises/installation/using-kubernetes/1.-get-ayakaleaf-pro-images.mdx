Kubernetes kör samma avbildningar som Toolkit. Det finns ingen separat Kubernetes-avbildning.

| Avbildning                                           | Används av                                                              |
| ---------------------------------------------------- | ----------------------------------------------------------------------- |
| `ghcr.io/ayaka-notes/overleaf-pro:6.3.2`             | Deployment `overleaf`                                                   |
| `ghcr.io/ayaka-notes/overleaf-pro/git-bridge:6.3.2`  | [Git-integration](/sv/on-premises/configuration/kubernetes/integrations/git-integration) (valfritt), samma tagg som ovan |
| `ghcr.io/ayaka-notes/texlive-*`                      | kompileringar, hämtade till Docker på noderna i [steg 0](/sv/on-premises/installation/using-kubernetes/0.-prepare-the-nodes) |

Avbildningarna är offentliga på [ghcr.io](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/) för amd64 och arm64, så kubelet kan hämta dem utan inloggningsuppgifter.

<Warning>

Använd alltid en versionstagg, till exempel `6.3.2`, inte `latest`. Uppgraderingar kör databasmigreringar och måste följa [Uppgradera på Kubernetes](/sv/on-premises/maintenance/upgrading-on-kubernetes); en rörlig tagg skulle uppgradera en pod varje gång den schemaläggs om.

</Warning>

### Frågor och svar

<Accordion title="Våra noder kan inte nå ghcr.io. Vad gör vi?">

<strong>Svar:</strong> Kopiera avbildningarna till ett register som noderna kan nå och använd det namnet i manifesten, till exempel:

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:6.3.2
docker tag ghcr.io/ayaka-notes/overleaf-pro:6.3.2 registry.example.com/ayakaleaf/overleaf-pro:6.3.2
docker push registry.example.com/ayakaleaf/overleaf-pro:6.3.2
```

För ett register utan TLS behöver containerd en `/etc/containerd/certs.d/<registry>/hosts.toml` med `server = "http://<registry>"` på varje nod, och `config_path` inställd som i [steg 0](/sv/on-premises/installation/using-kubernetes/0.-prepare-the-nodes). Docker självt pushar bara över vanlig HTTP till `localhost`, så pusha via `localhost:<port>` på registervärden eller lägg till det i `insecure-registries`.

</Accordion>
