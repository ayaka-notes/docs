---
title: 2. Skapa namnrymden och hemligheterna
description: Skapa namnrymden och de hemligheter som Ayakaleaf Pro behöver.
icon: key
---

Allt hamnar i namnrymden `overleaf`:

```bash
kubectl create namespace overleaf
```

Ayakaleaf Pro läser sina hemligheter från miljövariabler. Generera dem en gång och spara dem i en Secret:

```bash wrap
HISTORY=$(openssl rand -hex 32)
kubectl -n overleaf create secret generic overleaf-secrets \
  --from-literal=OVERLEAF_INVITE_TOKEN_SECRET="$(openssl rand -base64 32)" \
  --from-literal=OVERLEAF_SESSION_SECRET="$(openssl rand -hex 32)" \
  --from-literal=WEB_API_PASSWORD="$(openssl rand -hex 32)" \
  --from-literal=STAGING_PASSWORD="$HISTORY" \
  --from-literal=V1_HISTORY_PASSWORD="$HISTORY" \
  --from-literal=CRYPTO_RANDOM="$(openssl rand -hex 32)" \
  --from-literal=OT_JWT_AUTH_KEY="$(openssl rand -hex 32)"
```

| Hemlighet                                      | Varför                                                                                                                                               |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_INVITE_TOKEN_SECRET`                 | Obligatorisk. Utan den stoppar podden med ”Missing required secrets”. Om du ändrar den blir väntande projektinbjudningar ogiltiga.                    |
| `OVERLEAF_SESSION_SECRET`                      | Signerar sessionscookies. Utan den loggas alla ut vid varje omstart av podden.                                                                        |
| `WEB_API_PASSWORD`, `CRYPTO_RANDOM`, `OT_JWT_AUTH_KEY` | Interna hemligheter. Containern genererar dem vid varje start när de saknas; med fler än en replik måste alla repliker dela dem.               |
| `STAGING_PASSWORD` och `V1_HISTORY_PASSWORD`   | Intern hemlighet för historiken; båda måste ha **samma** värde.                                                                                       |

<Warning>

Säkerhetskopiera Secret:en (`kubectl -n overleaf get secret overleaf-secrets -o yaml`) tillsammans med dina data. Funktioner som krypterar tokens i MongoDB behöver också sina egna krypteringslösenord i denna Secret, till exempel `GITHUB_TOKEN_CIPHER_PASSWORD` för [GitHub-synkronisering](/sv/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation).

</Warning>
