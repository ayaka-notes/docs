---
title: 4. Anpassa din instans
description: Lägg dina inställningar i den ConfigMap som ersätter config/variables.env.
icon: square-sliders
---

ConfigMap:en `overleaf-env` ersätter Toolkits `config/variables.env`: varje miljövariabel från [Toolkit-dokumentationen](/sv/on-premises/configuration/overleaf-toolkit/environment-variables) hamnar här, och hemligheter hamnar i Secret:en från [steg 2](/sv/on-premises/installation/using-kubernetes/2.-create-the-namespace-and-secrets).

```yaml title="30-config.yaml" wrap
apiVersion: v1
kind: ConfigMap
metadata:
  name: overleaf-env
  namespace: overleaf
data:
  OVERLEAF_APP_NAME: Ayakaleaf Pro
  OVERLEAF_SITE_URL: http://192.0.2.10:30080      # the address users open; https://... behind TLS
  OVERLEAF_ADMIN_EMAIL: admin@example.com
  # Emails: add the sender and the SMTP server together, see Email delivery
  # All members, so that the driver finds the primary even when mongo-0 is down
  OVERLEAF_MONGO_URL: mongodb://mongo-0.mongo:27017,mongo-1.mongo:27017,mongo-2.mongo:27017/sharelatex?replicaSet=overleaf
  OVERLEAF_REDIS_HOST: redis
  REDIS_HOST: redis
  ENABLED_LINKED_FILE_TYPES: project_file,project_output_file,url
  ENABLE_CONVERSIONS: "true"
  EMAIL_CONFIRMATION_DISABLED: "true"
  # Requests arrive from kube-proxy or your ingress controller, inside the pod network
  OVERLEAF_TRUSTED_PROXY_IPS: loopback,10.244.0.0/16
  # Sandboxed compiles. The HOST_DIR paths are paths ON THE NODE: the hostPath volumes that
  # the Deployment mounts at /var/lib/overleaf/data/{compiles,output,cache}.
  SANDBOXED_COMPILES: "true"
  SANDBOXED_COMPILES_SIBLING_CONTAINERS: "true"
  DOCKER_RUNNER: "true"
  SANDBOXED_COMPILES_HOST_DIR_COMPILES: /srv/overleaf/compiles
  SANDBOXED_COMPILES_HOST_DIR_OUTPUT: /srv/overleaf/output
  SANDBOXED_COMPILES_HOST_DIR_CACHE: /srv/overleaf/cache
  # Each image must be pulled into Docker on every node that can run Ayakaleaf Pro (step 0)
  ALL_TEX_LIVE_DOCKER_IMAGES: ghcr.io/ayaka-notes/texlive-full:2026.1
  ALL_TEX_LIVE_DOCKER_IMAGE_NAMES: TeX Live 2026
  TEX_LIVE_DOCKER_IMAGE: ghcr.io/ayaka-notes/texlive-full:2026.1
```

```bash
kubectl apply -f 30-config.yaml
```

| Variabel                                | Ange den till                                                                                                                                                   |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_SITE_URL`                     | Den URL som användarna skriver in i webbläsaren. Med NodePort från [steg 5](/sv/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro), valfri nods IP-adress och port `30080`; bakom en ingress eller lastbalanserare, dess URL. |
| `OVERLEAF_MONGO_URL`                    | Din replikuppsättning. Använd `?replicaSet=` med namnet från `rs.initiate`.                                                                                    |
| `OVERLEAF_REDIS_HOST` och `REDIS_HOST`  | Båda, till Redis-Service:en.                                                                                                                                    |
| `OVERLEAF_TRUSTED_PROXY_IPS`            | `loopback` plus de nätverk som dina proxyer ansluter från. `10.244.0.0/16` är flannels poddnätverk; använd ditt klusters pod-CIDR.                              |
| `SANDBOXED_COMPILES_HOST_DIR_*`         | Nodsökvägarna för kompileringsvolymerna. De måste stämma överens med `hostPath`-volymerna i [steg 5](/sv/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro). |

Bakom HTTPS anger du även `OVERLEAF_SECURE_COOKIE: "true"`, se [TLS-proxy](/sv/on-premises/configuration/overleaf-toolkit/tls-proxy).

<Info>

En ändrad ConfigMap når körande poddar först efter en omstart: `kubectl -n overleaf rollout restart deployment/overleaf`.

</Info>
