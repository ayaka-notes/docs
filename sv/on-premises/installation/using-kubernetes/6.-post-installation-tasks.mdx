### Skapa ditt första administratörskonto

Öppna `OVERLEAF_SITE_URL` följt av `/launchpad`, till exempel `http://192.0.2.10:30080/launchpad`, och registrera administratörskontot som i [Toolkits uppgifter efter installationen](/sv/on-premises/installation/using-the-toolkit/6.-post-installation-tasks). Skapa sedan ett exempelprojekt och kompilera det.

Du kan också skapa användare från kommandoraden:

```bash
kubectl -n overleaf exec deploy/overleaf -- bash -c \
  'cd /overleaf/services/web && node modules/server-ce-scripts/scripts/create-user.mjs --admin --email=admin@example.com'
```

Det skriver ut en länk som ställer in lösenordet.

### Kontrollera att kompileringar körs i sandlåda

Kompilera ett projekt och titta sedan på noden som kör podden:

```bash
kubectl -n overleaf get pod -l app=overleaf -o wide   # NODE column
# on that node:
sudo docker ps -a --filter ancestor=ghcr.io/ayaka-notes/texlive-full:2026.1
ls -ln /srv/overleaf/compiles                          # owned by uid 33 (www-data)
```

Varje kompilering visas som en kortlivad container med namnet `project-<project id>-<user id>-...`.

### Loggar och ett skal

| Toolkit          | Kubernetes                                                               |
| ---------------- | ------------------------------------------------------------------------ |
| `bin/logs web`   | `kubectl -n overleaf exec deploy/overleaf -- tail -f /var/log/overleaf/web.log` |
| `bin/shell`      | `kubectl -n overleaf exec -it deploy/overleaf -- bash`                    |
| `bin/up`         | `kubectl apply -f .` och sedan `kubectl -n overleaf rollout restart deployment/overleaf` |

Containern skriver en loggfil per tjänst i `/var/log/overleaf/` (`web.log`, `clsi.log`, `real-time.log`, `document-updater.log`, ...); `kubectl logs` visar uppstartsutdata.

### Frågor och svar

<Accordion title="Kompileringen misslyckas eller blir aldrig klar.">

<strong>Svar:</strong> Kontrollera på noden som kör podden att Docker körs och har avbildningen som anges i `TEX_LIVE_DOCKER_IMAGE`, och att `SANDBOXED_COMPILES_HOST_DIR_*` stämmer överens med `hostPath`-sökvägarna. `/var/log/overleaf/clsi.log` i podden anger vilket steg som misslyckas.

</Accordion>

<Accordion title="Användare loggas ut efter varje omstart av podden.">

<strong>Svar:</strong> `OVERLEAF_SESSION_SECRET` saknas i Secret:en `overleaf-secrets`, se [steg 2](/sv/on-premises/installation/using-kubernetes/2.-create-the-namespace-and-secrets).

</Accordion>
