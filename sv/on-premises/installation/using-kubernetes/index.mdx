[Toolkit](/sv/on-premises/installation/using-docker-compose) är det rekommenderade sättet att köra Ayakaleaf Pro på en enskild server. Om du redan kör ett Kubernetes-kluster driftsätter det här avsnittet samma container där med vanliga `kubectl`-manifest: ingen extra avbildning, inget Helm-diagram.

I slutet av det här avsnittet har du en Ayakaleaf Pro-instans med sandlådekompilering, en MongoDB-replikuppsättning och Redis, allt i namnrymden `overleaf`. För att köra flera instanser bakom en lastbalanserare fortsätter du därefter med [Horisontell skalning](/sv/on-premises/configuration/kubernetes/horizontal-scaling).

<Info>

Stödet för Kubernetes är experimentellt. Vi publicerar inget Helm-diagram och inga Kubernetes-specifika avbildningar. Manifesten på dessa sidor är de som vi testade på Kubernetes 1.37 (kubeadm, containerd 2.4, flannel) med tre noder med 2 vCPU:er och 4 GB minne vardera. Anpassa lagring, nätverk och ingress till ditt kluster.

</Info>

### Hur delarna hänger ihop {#how-the-pieces-fit}

| Toolkit (en server)                          | Kubernetes                                                               |
| -------------------------------------------- | ------------------------------------------------------------------------ |
| `config/variables.env`                       | ConfigMap `overleaf-env` och Secret `overleaf-secrets`                   |
| containern `sharelatex`                      | Deployment `overleaf` (en pod som kör alla Overleaf-tjänster)            |
| containrarna `mongo` och `redis`             | StatefulSets `mongo` (replikuppsättning) och `redis`, eller dina hanterade tjänster |
| `~/overleaf-toolkit/data/overleaf`           | PersistentVolumeClaim `overleaf-data`                                    |
| Docker på värden, används för kompileringar  | Docker Engine på varje nod som kör Ayakaleaf Pro                         |
| `bin/up`, `bin/logs`, `bin/shell`            | `kubectl apply`, `kubectl logs`, `kubectl exec`                          |

### Vad du behöver {#what-you-need}

* Ett Kubernetes-kluster där du kan installera paket: varje nod som kan köra Ayakaleaf Pro behöver **Docker Engine**, eftersom kompileringar körs i TeX Live-containrar som Ayakaleaf Pro startar via nodens `/var/run/docker.sock`. Se [0. Förbered noderna](/sv/on-premises/installation/using-kubernetes/0.-prepare-the-nodes).
* En standard-StorageClass med `ReadWriteOnce`-volymer.
* `kubectl` och `openssl` på din arbetsstation.
