Det enklaste sättet att testa Ayakaleaf Pro är att använda GitHub Codespace, där alla miljövariabler är förkonfigurerade så att du kan använda det direkt.

<Warning>

När du kör Docker-containrar i GitHub Codespaces stängs din Codespace inte av automatiskt och fortsätter att **debiteras**. Information om debiteringsreglerna för GitHub Codespaces finns i [debiteringsregler för GitHub Codespaces](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces).

Hantera dina GitHub Codespaces på [https://github.com/codespaces](https://github.com/codespaces). När du inte längre behöver din Codespace bör du ta bort den i tid.

</Warning>

Vi har **förkonfigurerat** följande funktioner:

* [x] Sandlådad LaTeX-kompilering med TeXLive **Basic** (2024–2026)
* [x] Import/export med Pandoc (funktioner i SaaS-plattformen)
* [x] Python Script Runner (funktioner i SaaS-plattformen)
* [x] Stöd för Git-Bridge (funktioner i Server Pro)
* [x] Avancerad referenssökning (funktioner i SaaS-plattformen)
* [x] Adminpanel (global hantering av användare/projekt)
* [x] Spåra ändringar (med panel för granskning och kommentarer)
* [x] Fullständig projekthistorik (med återställning och nedladdning)
* [x] Symbol Palette (funktioner i Server Pro/SaaS-plattformen)

<Warning>

Vanliga GitHub Codespaces har 32 GB lagringsutrymme. Det räcker inte för vår `texlive-full`-installation. För att testa den fullständiga avbildningen skickar du ett supportärende till GitHub om en Codespace med stora runners (8+ kärnor).

</Warning>

GitHub Sync, LDAP, OAuth, SSO, Zotero-integration och andra funktioner är _**inte konfigurerade**_ i den här testmiljön. Se [Toolkit-inställningar](/sv/on-premises/configuration/overleaf-toolkit/toolkit-settings) för mer information om hur du konfigurerar dessa funktioner i din egen driftsättning.

<Steps>
<Step title="Skapa din GitHub Codespace">
Klicka på knappen nedan för att skapa din GitHub Codespace. När det gäller serverkonfiguration räcker **2 kärnor med 8 GB RAM** i allmänhet för testsyften. Om du planerar att använda [**TeX Live Full**](https://github.com/ayaka-notes/texlive-full) rekommenderar vi en konfiguration med **8 kärnor och 64 GB**.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/ayakaleaf-pro-playground)

<Step title="Initiera Overleaf-instansen">
När din Codespace är klar kör du följande kommando i bash för att initiera din Overleaf-instans.

```bash title="bash"

```

#### Använda TeXLive Full-avbildningen

Om du har tillgång till GitHub Codespaces med 8 kärnor/64 GB kan du använda TeXLive Full-avbildningen i den här testmiljön. Du kan ändra följande miljövariabler i filen `toolkit/config/variables.env` för att använda TeXLive Full-avbildningen i stället för TeXLive Basic-avbildningen.

```dotenv wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1, ghcr.io/ayaka-notes/texlive-full:2024.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025, Texlive 2024
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```

När du har ändrat miljövariablerna måste du starta om Toolkit för att tillämpa ändringarna. Du kan köra följande kommando för att starta om Toolkit.

```bash
cd toolkit && bin/up -d
```
