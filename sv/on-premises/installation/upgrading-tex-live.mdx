<Danger>

Följande instruktioner gäller **endast** installationer av **Community Edition**. Vi rekommenderar starkt att våra Ayakaleaf Pro-användare aktiverar [Sandboxed Compiles](/sv/on-premises/configuration/overleaf-toolkit/sandboxed-compiles), eftersom det ger användarna tillgång till nästan samma TeX Live-avbilder som används på [overleaf.com](https://www.overleaf.com) och dessutom isolerar projektkompileringar från varandra för ökad säkerhet.

</Danger>

För att spara bandbredd levereras både Overleaf Community Edition- och Ayakaleaf Pro-avbilderna endast med en minimal installation av [TeX Live](https://www.tug.org/texlive/). Du kan installera fler paket eller uppgradera till en fullständig TeX Live-installation med kommandot [tlmgr](https://www.tug.org/texlive/tlmgr.html) i containern `sharelatex`.

#### Komma in i sharelatex-containern

Kör följande för att starta ett skal i containern `sharelatex`:

```bash
bin/shell
```

Du får en prompt som ser ut så här:

```bash
root@309b192d4030:/#
```

I följande instruktioner antar vi att du befinner dig i containern.

#### Ta reda på din nuvarande TeX Live-version

TeX Live släpps varje år runt april. Stegen för att använda `tlmgr` skiljer sig åt beroende på om du använder den aktuella utgåvan eller en äldre. Du kan kontrollera vilken version av TeX Live du kör med `tlmgr --version`. Den här installationen kör till exempel TeX Live 2021:

```bash
# tlmgr --version
tlmgr revision 59291 (2021-05-21 05:14:40 +0200)
tlmgr using installation: /usr/local/texlive/2021
TeX Live (https://tug.org/texlive) version 2021
```

<Info>

Den aktuella utgåvan av TeX Live finns på [TeX Lives webbplats](https://www.tug.org/texlive/).

</Info>

Om du kör en äldre TeX Live-version har du två alternativ. En ny version av Overleafs Docker-avbild släpps vanligtvis kort efter en TeX Live-utgåva. Du kan antingen vänta på den och uppgradera din driftsättning med skriptet `bin/upgrade`, eller, om du föredrar att behålla den äldre TeX Live-utgåvan, först instruera `tlmgr` att använda ett historiskt repository. Instruktioner för detta hittar du [här](https://www.tug.org/texlive/acquire.html#past).

#### Installera paket

Kör det här kommandot i containern `sharelatex` för att installera en fullständig TeX Live-installation:

```text
tlmgr install scheme-full
```

Du kan också installera enskilda paket manuellt:

```bash
tlmgr install tikzlings tikzmarmots tikzducks
```

<Warning>

Från och med version `3.3.0` är det återigen **obligatoriskt** att köra `tlmgr path add` efter varje användning av `tlmgr install`, för att alla binärfiler ska länkas korrekt till systemsökvägen.

</Warning>

Det finns många fler kommandon. Läs mer med:

```text
tlmgr help
```

När du är klar skriver du `exit` eller trycker på Control-D för att lämna skalet.

#### Spara dina ändringar

Ändringarna du just gjort har modifierat containern `sharelatex`, men de är tillfälliga -- de går förlorade om Docker Compose återskapar containern, till exempel när konfigurationen uppdateras.

För att göra dem beständiga använder du `docker commit` för att spara ändringarna i en ny Docker-avbild:

```bash
cat config/version #5.2.1
docker commit sharelatex sharelatex/sharelatex:5.2.1-with-texlive-full
echo 5.2.1-with-texlive-full > config/version
```

När du har sparat ändringarna uppdaterar du `config/version` i enlighet med detta. Kör sedan `bin/up` för att återskapa containern `sharelatex`.

<Danger>

Du måste upprepa dessa steg varje gång du [uppgraderar](https://github.com/overleaf/toolkit/blob/master/doc/upgrading.md) till en ny version av Overleaf.

</Danger>
