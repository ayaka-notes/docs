Overleaf körs på Docker. Du måste installera:

* Docker Engine (Docker CE)
* Docker Compose-pluginet (`docker compose`, v2)

Dessa steg är avsedda för en aktuell Ubuntu LTS (20.04/22.04/24.04).

<Warning>

Undvik att installera `docker.io` från Ubuntus standardförråd för apt.\
Använd Dockers officiella förråd så att du får en aktuell Docker-version och pluginet `docker compose`.

</Warning>

Den officiella dokumentationen finns på: [https://docs.docker.com/engine/install/ubuntu/](https://docs.docker.com/engine/install/ubuntu/).

<Steps>
<Step title="1) Ta bort gamla/konfliktande paket (om sådana finns)">
Om Docker tidigare har installerats från en annan källa, ta först bort den:

```bash wrap
sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-compose-v2 docker-doc podman-docker containerd runc | cut -f1)
```

Kommandot är säkert även om vissa paket inte är installerade.
</Step>

<Step title="2) Lägg till Dockers officiella apt-förråd">
Installera förutsättningarna:

```bash
sudo apt update
sudo apt install -y ca-certificates curl
```

Lägg till Dockers GPG-nyckel:

```bash wrap
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```

Lägg till förrådet:

```bash wrap
# Add the repository to Apt sources:
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Signed-By: /etc/apt/keyrings/docker.asc
EOF

sudo apt update
```
</Step>

<Step title="3) Installera Docker Engine + Compose-pluginet">
Installera Docker och Compose-pluginet:

```bash wrap
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

Starta Docker vid systemstart:

```bash
sudo systemctl enable --now docker
```
</Step>

<Step title="4) Verifiera installationen">
Dessa kommandon ska köras utan fel:

```bash
docker --version
docker compose version
sudo docker run --rm hello-world
docker ps
```
</Step>

<Step title="5) (Valfritt) Kör Docker utan sudo">
Lägg till din användare i gruppen `docker`:

```bash
sudo usermod -aG docker $USER
```

**Logga sedan ut och in igen**, eller kör:

```bash
newgrp docker
```

Nu bör detta fungera utan `sudo`:

```bash
docker ps
```

<Danger>

Gruppen `docker` har åtkomst motsvarande root på värddatorn.\
Detta är förväntat för typiska Overleaf-installationer och särskilt relevant om du aktiverar Sandboxed Compiles.

</Danger>
</Step>
</Steps>

### Nästa steg
