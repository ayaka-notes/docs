---
title: 4. Hämta Ayakaleaf Pro-avbildningar
icon: split
---

Ayakaleaf Pro distribueras som en Docker-avbildning i registret [ghcr](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/), med **öppen åtkomst** för alla. Vi tillhandahåller avbildningar för både amd64- och arm64-arkitekturerna. När du hämtar avbildningen väljs rätt avbildning automatiskt baserat på systemets arkitektur.

#### Användare av Ayaka-notes Toolkit

Om du använder [ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) kan Ayakaleaf Pro användas som en direkt ersättning för Community Edition, så att du kan behålla dina befintliga inställningar och anpassningar. Aktivera Pro i Toolkit genom att redigera `config/overleaf.rc` och sätta miljövariabeln `SERVER_PRO`:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

Nästa gång du kör `bin/up` kommer Toolkit automatiskt att ladda ned och använda Ayakaleaf Pro-avbildningen.

#### Användare av det officiella Toolkit

Om du använder [overleaf/toolkit](https://github.com/overleaf/toolkit) hämtar du en Pro-avbildning genom att köra följande kommando:

```bash title="Pull Docker Images"
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Lägg sedan till en fil med namnet `docker-compose.override.yml` med följande innehåll i katalogen `overleaf-toolkit/config`:

```yml title="docker-compose.override.yml"
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

Nästa gång du kör `bin/up` kommer Toolkit automatiskt att ladda ned och använda Ayakaleaf Pro-avbildningen.
