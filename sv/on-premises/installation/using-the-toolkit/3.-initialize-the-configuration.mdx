### Initiera konfigurationen

Låt oss initiera den nya serverns konfigurationsfiler med några rimliga standardvärden genom att köra det medföljande skriptet `bin/init`.

```text title="Run initialization"
bin/init
```

Skriptet skriver **inte** över några befintliga konfigurationsfiler.

Låt oss nu kontrollera innehållet i katalogen `config/` med kommandot `ls`:

```text title="List the config directory"
ls config
```

Om allt initierades korrekt bör du se tre konfigurationsfiler: `overleaf.rc`, `variables.env` och `version`. Dessa är serverns huvudsakliga konfigurationsfiler och låter dig anpassa hur servern fungerar och hur användarna interagerar med din instans.

| Namn            | Beskrivning                                             |
| --------------- | ------------------------------------------------------- |
| `overleaf.rc`   | Den huvudsakliga konfigurationsfilen på toppnivå.       |
| `variables.env` | Miljövariabler som läses in i Docker-containern.        |
| `version`       | Versionen av Docker-imagen som ska användas.            |

<Info>

För tillfället räcker det att veta att dessa filer finns och var du hittar dem. Längre fram i dokumentationen går vi igenom varje fil mer i detalj och förklarar hur du kan anpassa din instans med dem. Om du vill hoppa framåt finns en fullständig genomgång av dessa konfigurationsfiler på [sidan Filer och platser](/sv/on-premises/configuration/overleaf-toolkit/files-and-locations).

</Info>
