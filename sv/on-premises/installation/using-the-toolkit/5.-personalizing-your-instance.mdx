### Anpassa din instans

Innan du startar din Overleaf-instans för första gången uppdaterar du konfigurationsfilen `config/variables.env` med dina egna uppgifter.

<Steps>
<Step title="Redigera variabelfilen">
Öppna `config/variables.env` i din favoritredigerare och uppdatera miljövariablerna nedan med de värden som krävs.
</Step>

<Step title="Obligatoriska miljövariabler">
Uppdatera följande variabler i `config/variables.env`:

| Namn                          | Beskrivning                                                                                                                                                    | Exempel                         |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| `OVERLEAF_SITE_URL`           | Var din Overleaf-instans är offentligt tillgänglig. Används i offentliga länkar och vid anslutning via websockets, så den **måste vara korrekt konfigurerad**! | `https://overleaf.lilliput.com` |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | Den här e-postadressen används som `from`-adress för all utgående e-post.                                                                                      | `no-reply@lilliput.com`         |
| `OVERLEAF_ADMIN_EMAIL`        | E-postadressen där användarna kan nå den som driver webbplatsen.                                                                                               | `it-services@lilliput.com`      |

När du har uppdaterat miljövariablerna sparar du och avslutar.
</Step>

<Step title="Konfigurera kompilering i sandlåda">
Konfigurera sedan TeX Live Full för [sandboxed-compiles.md](/sv/on-premises/configuration/overleaf-toolkit/sandboxed-compiles  "mention"). Öppna `config/variables.env` och uppdatera följande miljövariabler:

```dotenv title="config/variables.env" wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```
</Step>

<Step title="Starta din instans">
Starta din instans genom att köra:

```text title="Start the instance"
bin/up
```

Det här kommandot laddar ned de images som krävs, inklusive texlive, skapar containrarna (med dina anpassningar) och startar instansen. Du bör se loggutdata från de olika Docker-containrarna.

För att starta dem igen senare (utan att koppla till loggutdatan) kör du:

```text title="Start without attaching to logs"
bin/start
```
</Step>
</Steps>

<Info>

Toolkit använder `docker compose` för att hantera Overleafs Docker-containrar. Toolkit tillhandahåller en uppsättning skript som omsluter `docker compose` och tar hand om de flesta detaljer åt dig.

</Info>

Om allt går bra bör du kunna se inloggningssidan för din nya Overleaf-instans genom att gå till [http://127.0.0.1/](http://127.0.0.1/) eller [http://localhost/](http://localhost/) i webbläsaren.

<Warning>

Beroende på din nätverkskonfiguration och var din Overleaf-instans är hostad kan du behöva göra ytterligare konfigurationsändringar. Se Toolkit-inställningarna för mer information: [toolkit-settings.md](/sv/on-premises/configuration/overleaf-toolkit/toolkit-settings  "mention")

</Warning>
