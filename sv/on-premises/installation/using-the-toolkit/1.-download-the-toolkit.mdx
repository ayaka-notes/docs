### Ladda ner Toolkit

Toolkit är kompatibelt med både Server CE och Ayakaleaf Pro och är den rekommenderade installationsmetoden. Med Toolkit kan du enkelt komma igång med Server CE och smidigt uppgradera till Ayakaleaf Pro vid behov.

<Info>

[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) är modifierat för att använda overleaf-pro-avbilden direkt från ghcr, med TeX Live som tillhandahålls av ayaka-notes. Alternativt kan du ladda ner det officiella overleaf-toolkit.

</Info>

<Steps>
<Step title="Klona Overleaf Toolkit-repositoriet">
För att installera Toolkit navigerar du till den avsedda installationssökvägen och klonar sedan GitHub-repositoriet Overleaf Toolkit (@Ayaka-notes) med detta kommando:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
# official toolkit (Not Recommended)
# git clone https://github.com/overleaf/toolkit.git ./overleaf-toolkit
```

<Info>

För att undvika eventuella behörighetsproblem rekommenderar vi att du installerar Toolkit i din användares `$HOME`-katalog.

</Info>
</Step>

<Step title="Byt till Toolkit-katalogen">
Vänta tills kloningen är klar och byt sedan till den nyskapade katalogen `overleaf-toolkit`:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
