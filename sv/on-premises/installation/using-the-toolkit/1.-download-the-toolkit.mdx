### Ladda ner Toolkit

Du installerar Ayakaleaf Pro med **Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)), en uppsättning skript som kör Overleaf i Docker åt dig.

Som standard startar Toolkit den kostnadsfria officiella Overleaf Community Edition (CE). [4. Hämta Ayakaleaf Pro-avbildningar](/sv/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images) byter till Ayakaleaf Pro med en enda inställning.

<Accordion title="Kör du redan det officiella Overleaf Toolkit (overleaf/toolkit)?">

Du behöver inte installera om. Behåll din installation och följ den sista delen av [4. Hämta Ayakaleaf Pro-avbildningar](/sv/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images).

</Accordion>

<Steps>
<Step title="Klona Ayakaleaf Toolkit-repositoriet">
För att installera Toolkit navigerar du till den avsedda installationssökvägen och klonar sedan repositoriet Ayakaleaf Toolkit med detta kommando:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
```

<Info>

För att undvika eventuella behörighetsproblem rekommenderar vi att du installerar Toolkit i din användares `$HOME`-katalog.

</Info>
</Step>

<Step title="Byt till Toolkit-katalogen">
Vänta tills kloningen är klar och byt sedan till den nyskapade katalogen `overleaf-toolkit`:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
