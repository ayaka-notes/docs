### Skapa ditt första administratörskonto {#create-your-first-administrator-account}

Öppna [http://localhost:8080/launchpad](http://localhost:8080/launchpad), eller din `OVERLEAF_SITE_URL` följd av `/launchpad`, och registrera administratörskontot. Härifrån fungerar allt som med Docker: följ [6. Uppgifter efter installationen](/sv/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks) i Docker-guiden och använd port `8080` i dess `localhost`-länkar.

Skapa exempelprojektet och kompilera det. PDF-filen visar att kompileringarna körs i sina TeX Live-containrar via Podman. Så här ser du kompileringscontainern:

```bash title="List the compile containers"
podman ps -a --filter name=project- --format "{{.Names}} {{.Image}} {{.Status}}"
```

### Använd HTTPS {#use-https}

Toolkits [TLS-proxy](/sv/on-premises/configuration/overleaf-toolkit/tls-proxy) fungerar på Podman: kör `bin/init --tls` och ställ in ditt certifikat och `NGINX_ENABLED=true` enligt beskrivningen där. Den lyssnar på portarna `80` och `443`, som rootless Podman inte får använda som standard. Tillåt oprivilegierade användare att använda portar från `80` och uppåt:

```bash title="Allow ports 80 and 443"
echo "net.ipv4.ip_unprivileged_port_start=80" | sudo tee /etc/sysctl.d/99-unprivileged-ports.conf
sudo sysctl --system
```

Detta låter alla användare på servern lyssna på de här portarna, så gör det bara på en server som är dedikerad till Ayakaleaf Pro. Öppna dem sedan i brandväggen:

```bash title="Open ports 80 and 443"
sudo firewall-cmd --permanent --add-port=80/tcp --add-port=443/tcp
sudo firewall-cmd --reload
```

Ställ in `OVERLEAF_SITE_URL` på din `https://`-adress och kör `bin/up -d`. Behåll standardvärdena `NGINX_HTTP_PORT=80` och `TLS_PORT=443`: med andra portar leder omdirigeringen från HTTP till HTTPS till fel port.

<Info>

Låt `OVERLEAF_LISTEN_IP` vara `127.0.0.1` när du använder TLS-proxyn, så att port `8080` inte kan nås från andra datorer.

</Info>

### Uppgradera {#upgrade}

Uppgradera med `bin/upgrade` enligt beskrivningen i [Uppgradera din driftsättning](/sv/on-premises/maintenance/upgrading-your-deployment). På Podman extraherar det också den nya versionens seccomp-profil till `config/seccomp/<version>/` och uppdaterar `SECCOMP_PROFILE`:

```text
Over-writing config/version with 6.3.4
Set SECCOMP_PROFILE=/home/<user>/overleaf-toolkit/config/seccomp/6.3.4/clsi-profile.json in config/variables.env
```

Efter en uppgradering kör du `bin/podman-setup` för att kontrollera konfigurationen.

### Ändra SELinux-läget {#change-the-selinux-mode}

`SELINUX_MODE` i `config/overleaf.rc` anger hur SELinux begränsar containern `sharelatex`. `managed` är det läge som de här sidorna konfigurerar; de andra lägena beskrivs i [Toolkit-inställningar](/sv/on-premises/configuration/overleaf-toolkit/toolkit-settings). Kör `bin/up -d` efter att du har ändrat det.
