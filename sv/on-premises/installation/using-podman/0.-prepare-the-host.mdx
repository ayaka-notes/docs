---
title: 0. Förbered värden
description: Kontrollera operativsystemet och SELinux och installera git innan du konfigurerar rootless Podman.
icon: server
---

Du installerar inte Podman för hand: [2. Kör podman-setup](/sv/on-premises/installation/using-podman/2.-run-podman-setup) installerar det tillsammans med de andra paket som behövs. Här kontrollerar du bara värden och installerar `git`, som du behöver för att ladda ned Toolkit.

<Steps>
<Step title="Kontrollera operativsystemet och SELinux">
Logga in som den användare som ska köra Ayakaleaf Pro, inte som `root`, och kontrollera distributionen och SELinux-läget:

```bash title="Check the host"
grep PRETTY_NAME /etc/os-release
getenforce
```

Du bör se RHEL, Rocky Linux, AlmaLinux eller CentOS Stream med version 9 eller senare, och `Enforcing`:

```text
PRETTY_NAME="Rocky Linux 9.9 (Blue Onyx)"
Enforcing
```
</Step>

<Step title="Kontrollera att du kan använda sudo">
`bin/podman-setup --apply` installerar paket och läser in en SELinux-modul med `sudo`, och frågar efter ditt lösenord när det behövs:

```bash title="Check sudo"
sudo -v
```

Om det misslyckas ber du din administratör att lägga till din användare i gruppen `wheel`.
</Step>

<Step title="Installera git">
```bash title="Install git"
sudo dnf install -y git
```

<Warning>

Installera inte Docker Engine på den här värden. Paketet `podman-docker`, som `bin/podman-setup` installerar, tillhandahåller kommandot `docker`, och Toolkit behandlar värden som Podman så fort kommandot `podman` finns.

</Warning>
</Step>
</Steps>
