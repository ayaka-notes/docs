Använd Claude Code eller Codex för att planera och genomföra en driftsättning av Ayakaleaf Pro. Agenten kan söka i den här dokumentationen via MCP medan den arbetar.

Agenten hjälper till med driftsättningen. Du ansvarar fortfarande för att granska kommandon och skydda inloggningsuppgifter.

### Innan du börjar

Förbered en Linux-server som stöds med SSH-åtkomst. Gå igenom [krav](/sv/on-premises/getting-started/requirements  "mention") innan du fortsätter.

<Warning>

Klistra inte in lösenord, privata nycklar, tokens eller licensnycklar i agentens prompter. Granska varje kommando innan du kör det, särskilt kommandon som ändrar filer, nätverk eller containrar.

</Warning>

### Anslut dokumentationen

Lägg till dokumentationens MCP-slutpunkt i din lokala agent.

<Tabs>
<Tab title="Claude Code">

```bash wrap
claude mcp add ayakaleaf-pro --scope user --transport http https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>

<Tab title="Codex">

```bash wrap
codex mcp add ayakaleaf-pro --url https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>
</Tabs>

Starta en ny session efter att du har lagt till servern. Be agenten bekräfta att den kan söka i Ayakaleaf Pro-dokumentationen.

### Driftsätt Ayakaleaf Pro

Öppna en terminal på din driftsättningsserver. Starta Claude Code eller Codex där. Skicka sedan den här prompten:

```text wrap
Use the Ayakaleaf Pro documentation MCP server to guide this deployment.
First, inspect the requirements and installation guides.
Ask me for missing deployment details before making changes.
Use the Ayakaleaf Toolkit unless the documentation requires another approach.
Before configuring the instance, summarize relevant optional features.
Ask which features and integrations I want to enable.
Include TLS, sandboxed compiles, Git integration, external MongoDB or Redis,
SSO (OIDC, SAML, or LDAP), GitHub Synchronisation, Zotero, S3 storage,
email delivery, branding, and localization when relevant.
Explain each selected option's prerequisites, security impact, and configuration steps.
Keep unselected optional features disabled.
Show each command before running it.
Do not expose, store, or request secrets in chat.
After deployment, verify that the service is healthy and summarize the changes.
```

Agenten bör guida dig genom Docker-installation, Toolkit-konfiguration, hämtning av avbildningar och uppstart. Följ guiden [using-the-toolkit](/sv/on-premises/installation/using-the-toolkit  "mention") för det rekommenderade arbetsflödet.

### Välj valfria funktioner

Be agenten att endast rekommendera funktioner som passar din miljö. Vanliga val är:

* <strong>Åtkomst och säkerhet:</strong> TLS, sandboxed compiles och SSO via OIDC, SAML eller LDAP.
* <strong>Externa tjänster:</strong> MongoDB, Redis, S3-lagring och e-postleverans.
* <strong>Samarbete:</strong> Git-integration, GitHub Synchronisation och Zotero.

Agenten bör förklara beroenden innan konfigurationen ändras. Gå igenom [toolkit-settings.md](/sv/on-premises/configuration/overleaf-toolkit/toolkit-settings  "mention") och [authentication](/sv/on-premises/configuration/overleaf-toolkit/authentication  "mention") innan du aktiverar integrationer i produktion.

### Verifiera driftsättningen

När agenten har slutfört stegen:

1. Bekräfta att varje kommando slutfördes utan fel.
2. Öppna den konfigurerade Ayakaleaf Pro-URL:en i din webbläsare.
3. Slutför [6.-post-installation-tasks.md](/sv/on-premises/installation/using-the-toolkit/6.-post-installation-tasks  "mention").

För en befintlig Community Edition-installation, använd guiden [migrate-from-existing.md](/sv/on-premises/installation/migrate-from-existing  "mention") i stället för en ny driftsättning.
