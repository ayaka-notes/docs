### Doktorn

Overleaf Toolkit levereras med ett praktiskt `doctor`-skript som hjälper till vid felsökning. Kör `bin/doctor` så skriver skriptet ut information om din värdmiljö, din konfiguration och de beroenden som Toolkit behöver. Utdata kan också hjälpa oss att diagnostisera problem i dina Ayakaleaf Pro-installationer.

<Info>

Användare av Overleaf Pro kan [skapa ett ärende på GitHub](https://github.com/ayaka-notes/overleaf/issues).

Det är en bra idé att inkludera utdata från skriptet `bin/doctor` i ditt meddelande.

</Info>

```bash title="Run doctor"
bin/doctor
```

### Värdinformation

Avsnittet `Host Information` innehåller information om maskinen som kör Toolkit (till exempel Linux-distribution och version).

<Accordion title="Exempel på utdata för värdinformation">

```text
- Host Information
    - Linux
    - Output of 'lsb_release -a':
            No LSB modules are available.
            Distributor ID:	Ubuntu
            Description:	Ubuntu 22.04.5 LTS
            Release:	22.04
            Codename:	jammy
```

</Accordion>

### Beroenden

Avsnittet `Dependencies` listar de verktyg som krävs för att Toolkit ska fungera. Om ett verktyg finns listas det som `status: present` med versionsinformation. Om det saknas listas det som `status: MISSING!` och en varning läggs till längst ner i utdata från `doctor`.

<Accordion title="Exempel på utdata för beroenden (finns)">

```text
- docker
    - status: present
    - version info: Docker version 28.0.4, build b8034c0
```

</Accordion>

<Accordion title="Exempel på utdata för beroenden (saknas)">

```text
- docker
    - status: MISSING!
```

</Accordion>

Om några beroenden saknas kommer Toolkit nästan säkert inte att fungera.

### Konfiguration

Avsnittet `Configuration` innehåller information om filerna i katalogen `config/`. För `config/overleaf.rc` skriver doktorn ut några viktiga värden. Saknade filer listas som `status: MISSING!` och en varning läggs till längst ner i utdata från `doctor`.

<Accordion title="Exempel på utdata för konfiguration">

```text
====== Configuration ======
- config/version
    - status: present
    - version: 5.4.0
- config/overleaf.rc
    - status: present
    - values
        - OVERLEAF_DATA_PATH: /tmp/overleaf
        - SERVER_PRO: false
        - MONGO_ENABLED: false
        - REDIS_ENABLED: true
- config/variables.env
    - status: MISSING!
```

</Accordion>

Anmärkningar om exemplet ovan:

* `OVERLEAF_DATA_PATH` satt till `/tmp/overleaf` är kanske inte en säker plats för viktiga data.
* `MONGO_ENABLED: false` innebär att Toolkit inte tillhandahåller en egen MongoDB; se vid behov till att `MONGO_URL` pekar på en externt hanterad MongoDB.
* `config/variables.env` saknas i exemplet.

### Varningar

Avsnittet `Warnings` sammanfattar problem som doctor-skriptet har upptäckt. Om det inte finns några problem anges det i det här avsnittet.

<Accordion title="Exempel på utdata för varningar">

```text
====== Warnings ======
- configuration file variables.env not found
- rc file, OVERLEAF_DATA_PATH not set
====== End =======
```

</Accordion>
