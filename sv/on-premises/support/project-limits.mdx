title: Projektgränser
icon: list-check
---

| Funktion                                          | Gräns                                                                                                                                                                   |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tidsgräns för kompilering                                  | **Standard:** 180 sekunder. Se [Uppdatera tidsgränsen för projektkompilering](/sv/on-premises/user-and-project-management/project-management) för mer information om hur du anpassar värdet. |
| Maximalt antal filer per projekt              | 2000                                                                                                                                                                    |
| Maximal storlek på redigerbart material per projekt    | **Standard:** 7 MB. Se [Miljövariabler](/sv/on-premises/configuration/overleaf-toolkit/environment-variables) för mer information om hur du anpassar värdet.           |
| Maximal storlek på en enskild redigerbar textfil | 2 MB\*                                                                                                                                                                  |
| Maximal storlek på en enskild uppladdning             | 50 MB (kan konfigureras via `MAX_UPLOAD_SIZE`)                                                                                                                              |
| Maximal okomprimerad storlek på en uppladdad .zip    | 6 × `MAX_UPLOAD_SIZE` (300 MB som standard)                                                                                                                               |
| Maximal projektstorlek                          | Obegränsad†                                                                                                                                                              |
| Maximalt antal projekt                       | Obegränsat                                                                                                                                                               |

\* Vissa större filer kan under vissa omständigheter förbli redigerbara. För att säkerställa att en fil förblir redigerbar bör du dock begränsa dess storlek till 2 MB eller mindre.

† Det finns ingen tvingande gräns för den totala projektstorleken. Du kan dock stöta på vissa tekniska begränsningar när du arbetar med mycket stora projekt. Vi rekommenderar en maximal projektstorlek på 500 MB, eller mindre än 100 MB om du använder vår [Git-integration](https://www.overleaf.com/learn/how-to/Git_integration). Projekt som är större än så kan fungera, men om du håller dig inom dessa gränser får du den bästa upplevelsen.
