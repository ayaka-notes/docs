---
title: Migrera från Server Pro till Group Professional
icon: rectangle-pro
noindex: true
---

Att byta från en egendriftad Server Pro-instans till en ny molnbaserad Overleaf Group Professional-prenumeration är en stor förändring, så för att göra processen så smidig som möjligt har vi sammanställt följande vägledning.

Generellt föreslår vi en överlappningsperiod på tre månader med start på ert förnyelsedatum. Det innebär att:

* Er befintliga Server Pro-instans och er nya Group Professional-prenumeration kommer båda att vara fullt aktiva.
* Ert tekniska team kan planera in tid för att konfigurera Group Professional-prenumerationen och besluta om framtiden för er lokala installation av Server Pro.
* Viktigast av allt får era användare gott om tid att kopiera över sina projekt till den nya Overleaf Group Professional-plattformen.

Den här snabbguiden leder dig genom de viktigaste stegen i migreringen. Nu sätter vi igång!

<Steps>
<Step title="Fas 1: Installation och konfiguration">
(Länk: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-1-setup-and-configuration)

* Overleaf skapar er Group Professional-prenumeration och lägger till er huvudadministratör (Lead Administrator).
* Er gruppadministratör kan aktivera [Managed Users](https://docs.overleaf.com/groups/user-management/managed-user-accounts), konfigurera [Single Sign-On (SSO)](https://docs.overleaf.com/groups/overleaf-group-single-sign-on/setting-up-group-sso) och [bjuda in slutanvändarna](https://docs.overleaf.com/groups/user-management/how-to-add-and-remove-users).

<Warning>

Att aktivera Managed Users och implementera SSO är ett obligatoriskt steg för efterlevnad av FedRAMP® LI-SaaS. Om er organisation kräver FedRAMP-efterlevnad ska ni konfigurera Managed Users och SSO innan ni bjuder in slutanvändare.

</Warning>
</Step>

<Step title="Fas 2: Användarmigrering och datahantering">
(Länk: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-2-user-migration-and-data-management)

Detta är det huvudsakliga migreringsfönstret, med följande ansvarsområden:

#### Slutanvändare

* Användarna bör migrera de projekt de vill behålla från er Server Pro-instans till sina nya konton på [overleaf.com](http://overleaf.com/). Processen innebär att [exportera projekt](https://www.overleaf.com/learn/how-to/Exporting_your_work_from_Overleaf) från Server Pro och [ladda upp dem](https://www.overleaf.com/learn/how-to/Uploading_a_project) till kontot på [overleaf.com](http://overleaf.com/). Om en användare inte redan har ett konto på [overleaf.com](http://overleaf.com/) kan hen registrera sig på [overleaf.com/register](http://overleaf.com/register).

<Warning>

Endast projektets källkod (LaTeX- och binärfiler) överförs med den här exportproceduren. Befintliga projektinställningar, delningsinställningar, kommentarer, spårade ändringar osv. överförs INTE. Användarna måste bjuda in sina medarbetare på nytt efter migreringen.

</Warning>

#### Teknisk personal

* Under den här fasen bör ert tekniska team planera för hur den lokala Server Pro-instansen och dess data ska hanteras efter migreringen.
* <strong>Säkerhetskopiering av data:</strong> Ni kan exportera alla projekt före avvecklingen för att skapa ett arkiv som gör det möjligt att hjälpa användare som har glömt att migrera eller ladda ned sitt arbete. Instruktioner: https://docs.overleaf.com/on-premises/maintenance/data-and-backups/exporting-projects
* <strong>Avveckling av Server Pro:</strong> När migreringsfönstret har stängts och er licensnyckel har inaktiverats har ni två huvudsakliga alternativ för själva Server Pro-instansen (se nästa steg).
</Step>

<Step title="Alternativ för avveckling av Server Pro">
<Steps>
<Step title="Avinstallera Server Pro helt">
Avinstallation avvecklar Server Pro och tar bort programvaran helt.
</Step>

<Step title="Byt till Community Edition">
Ett byte bevarar databasen med användare och projekt, inklusive fullständig projekthistorik, genom att instansen konverteras från Server Pro till Community Edition.
</Step>
</Steps>

<Info>

Community Edition innehåller INTE [Sandboxed Compiles](https://docs.overleaf.com/on-premises#overview-of-server-pro-and-community-edition) eller [LDAP](/sv/on-premises/configuration/overleaf-toolkit/authentication/ldap-authentication)/[SAML](/sv/on-premises/configuration/overleaf-toolkit/authentication/saml-authentication). Om ni behöver återgå till inbyggd autentisering (användarnamn/lösenord), se: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-to-ldap-or-saml#going-the-other-way-switching-from-ldap-saml-back-to-native-authentication

En jämförelse mellan Server CE och Server Pro finns här: https://docs.overleaf.com/on-premises/welcome/server-pro-vs.-community-edition

</Info>
</Step>

<Step title="Fas 3: Avveckling av Server Pro">
(Länk: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-3-server-pro-decommission)

* Overleaf-teamet inaktiverar formellt er Server Pro-licensnyckel och skickar en bekräftelse när det är klart.
* Utför då en av de avvecklingsåtgärder som beskrivs ovan: avinstallera Server Pro helt eller byt till Community Edition.
</Step>
</Steps>

Ytterligare resurser och länkar som hänvisas till ovan är oförändrade.
