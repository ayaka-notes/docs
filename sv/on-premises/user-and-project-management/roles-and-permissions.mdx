### Konto

När det gäller hantering av det egna kontot behandlas **alla** användare som vanliga användare – `Site Admins` och `Template Users` får **inga** ytterligare behörigheter. Det finns dock begränsningar för vilka åtgärder vanliga användare kan utföra beroende på hur de autentiserar sig.

#### Inställningar

| Åtgärd | Interna konton | SSO (SAML/LDAP) |
| ----------------------------------------- | ----------------: | --------------: |
| Uppdatera kontoinformation | Ja | Nej |
| Byta lösenord | Ja | Nej |
| Generera autentiseringstokens för Git bridge | Ja | Ja |
| Ta bort autentiseringstokens för Git bridge | Ja | Ja |
| Hantera sessioner | Ja | Ja |

<Info>

Git Bridge-integrationen är **endast** tillgänglig i Server Pro. Se [Server Pro jämfört med Community Edition](/sv/on-premises/readme/ayakaleaf-pro-vs-server-pro) för mer information.

</Info>

### Redigerarens IDE

<Info>

I Server Pro och Community Edition finns stöd för att ge anonym **skrivskyddad** åtkomst och anonym **läs- och skrivåtkomst** till projekt.

Mer information finns i beskrivningen av miljövariablerna `OVERLEAF_ALLOW_PUBLIC_ACCESS` och `OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` [här](/sv/on-premises/configuration/overleaf-toolkit/environment-variables).
