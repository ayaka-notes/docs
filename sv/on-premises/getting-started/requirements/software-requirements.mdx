### Operativsystem

För bästa upplevelse när du kör Overleaf rekommenderar vi starkt att du använder ett **Debian-baserat** operativsystem, till exempel **Ubuntu**. Det valet stämmer överens med programvarans utvecklingsmiljö och är det alternativ som de flesta Overleaf-användare föredrar.

<Danger>

När du använder Server Pro med Sandboxed Compiles är det **viktigt** att notera att applikationen kräver root-åtkomst till Docker-socketen.

</Danger>

### Beroenden

* Docker 25.0 och 29
* MongoDB 7.0 och 8.0
* Redis 6.2 och 7.5

<Info>

Du kan följa datum för supportens upphörande (End-of-Life, EOL) för ovanstående beroenden och andra populära produkter via tjänsten endoflife.date här: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

MongoDB och Redis hämtas automatiskt av `docker compose` när du kör Server CE eller Server Pro, om inget annat har konfigurerats för att använda en annan installation.

</Info>

Toolkit är beroende av följande program:

* bash
* Docker

`docker compose` krävs och installeras i regel tillsammans med Docker.

Vi rekommenderar att du installerar den senaste versionen av Docker som finns tillgänglig för ditt operativsystem.

När Docker är korrekt installerat bör du kunna köra dessa kommandon utan fel:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2)
docker compose version

# List the running Docker containers on your system
docker ps
```
