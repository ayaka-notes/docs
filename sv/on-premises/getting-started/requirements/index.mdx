### Krav för att installera Server Pro och Community Edition

<Warning>

Vi rekommenderar starkt att du kör Server Pro på en aktuell och stabil version av Ubuntu (t.ex. Ubuntu 24.04 under 2025–2026) med en aktuell version av Docker. Det är möjligt att köra Server Pro på andra system, men det gör det mycket svårare för oss att erbjuda support för Ubuntu/Docker-uppsättningar som avviker från standard. Vi kan inte heller erbjuda support för problem med själva Docker.

</Warning>
