---
title: Vad är Ayakaleaf Toolkit?
icon: toolbox
---

Ayakaleaf Toolkit är den rekommenderade driftsättningsmetoden för lokala installationer av Community Edition och Ayakaleaf Pro. Den är utformad för den vanligaste miljön: en enda fysisk server eller virtuell maskin. Toolkit använder `docker compose` för att hantera serverns Docker-containrar och tillhandahåller en uppsättning skript som omsluter `docker`-kommandon för att underlätta den mer tekniska sidan av att hantera en lokal Overleaf-version.

#### Omslaget `bin/docker-compose`

Skriptet `bin/docker-compose` är ett omslag (wrapper) runt `docker compose`. Det läser in konfigurationen från katalogen `config/` innan det anropar `docker compose` med de argument som skickats till skriptet.

Du kan betrakta `bin/docker-compose` som ett transparent omslag för programmet `docker compose` som är installerat på din dator.

Exempel:

```bash title="Check running containers"
$ bin/docker-compose ps
```

#### Praktiska hjälpskript

Utöver `bin/docker-compose` tillhandahåller Toolkit praktiska skript som underlättar vanliga uppgifter:

* `bin/up`: genväg för `bin/docker-compose up`
* `bin/start`: genväg för `bin/docker-compose start`
* `bin/stop`: genväg för `bin/docker-compose stop`
* `bin/shell`: startar ett skal i containern **sharelatex**
* `bin/doctor`: skript som samlar in information om installation och driftsättning. Se avsnittet "Kontrollera din server" nedan
* `bin/mongo`: startar ett skal i containern **mongo** och växlar till rätt databas (**sharelatex**)
* `bin/backup-config`: skapar en kopia (zip eller tar) av din aktuella konfiguration och lagrar den i en valfri målkatalog
* `bin/logs`: visa/följ tjänsteloggar
* `bin/error-logs`: visa/följ tjänsternas felloggar
* `bin/rename-env-vars-5-0`: migreringsskript som uppdaterar miljövariabler i **config/variables.env** (namnbyte från ShareLaTeX till Overleaf)
* `bin/rename-rc-vars`: migreringsskript som uppdaterar miljövariabler i **config/overleaf.rc** (namnbyte från ShareLaTeX till Overleaf)
* `bin/run-script`: hjälpskript som förenklar körning av skript som lagras i containern **sharelatex**
* `bin/upgrade`: hjälper till med uppgradering av instansen. Skriptet söker efter uppdateringar av Toolkit (via git) och erbjuder sig att hämta ändringarna, söker efter den senaste versionen av Docker-imagen och erbjuder sig att uppdatera den. Det ger stegvis bekräftelse, möjlighet att säkerhetskopiera den aktuella konfigurationen och hanterar stopp/start av Docker-tjänster. Mer information finns i Uppgradera din driftsättning: https://docs.overleaf.com/on-premises/maintenance/upgrading-your-deployment

<Info>

Om du föredrar att köra din instans utan att koppla till Docker-loggarna kan du köra `bin/up -d` för att köra i frånkopplat läge.

</Info>

#### Kontrollera din server

Overleaf Toolkit innehåller ett praktiskt skript som heter `bin/doctor` och som tar fram en rapport som pekar ut eventuella ouppfyllda beroenden.

Innan du fortsätter, kör skriptet `bin/doctor` och kontrollera att allt fungerar korrekt:

```bash title="Run Overleaf Doctor"
bin/doctor
```
