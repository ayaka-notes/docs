Lagrar hela historiken för varje projekt: block av ändringar i Mongo eller Postgres och objektlagring, samt filinnehåll som blobbar. project-history skriver ändringar dit; web, project-history och git-bridge läser blobbar, ögonblicksbilder och zip-filer därifrån.

* <strong>Adress:</strong> `http://history-v1:3100`, inom Docker-nätverket
* <strong>Autentisering:</strong> HTTP basic auth som `staging` med `STAGING_PASSWORD`, eller en JWT, beroende på rutten.
* <strong>OpenAPI-fil:</strong> [`develop/hoppscotch/openapi/history-v1.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/history-v1.yaml)
