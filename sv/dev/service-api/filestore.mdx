Levererar filer från objektlagring: mallfiler (zip, pdf och deras förhandsgranskningsbilder) och, skrivskyddat, de projekt- och globala blobbar som history-v1 skriver. Anropas av web (modulen template-gallery, fil-URL:er för kompileringar) och av clsi, som laddar ner binära projektfiler därifrån.

* <strong>Adress:</strong> `http://filestore:3009`, inom Docker-nätverket
* <strong>Autentisering:</strong> ingen
* <strong>OpenAPI-fil:</strong> [`develop/hoppscotch/openapi/filestore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/filestore.yaml)
