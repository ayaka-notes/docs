Lagrar projektchatten och kommentarstrådarna (deras meddelanden och lösta status) i Mongo-samlingarna `rooms` och `messages`. Anropas av web via `ChatApiHandler`.

* <strong>Adress:</strong> `http://chat:3010`, inom Docker-nätverket
* <strong>Autentisering:</strong> ingen
* <strong>OpenAPI-fil:</strong> [`develop/hoppscotch/openapi/chat.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/chat.yaml)
