icon: link
---

Hämtar en extern URL åt web och strömmar tillbaka svaret, och nekar interna adresser så att användare inte når Docker-nätverket. Web skickar URL-filer, Open in Overleaf-importer och AI-agentens web_fetch genom den.

* <strong>Adress:</strong> `http://linked-url-proxy:3066`, inom Docker-nätverket
* <strong>Autentisering:</strong> ingen
* <strong>OpenAPI-fil:</strong> [`develop/hoppscotch/openapi/linked-url-proxy.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/linked-url-proxy.yaml)
