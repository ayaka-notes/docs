Håller dokumenten som är öppna i editorn i Redis, tillämpar ändringar på dem och skriver tillbaka dem till Mongo via web. Anropas av web och real-time.

* <strong>Adress:</strong> `http://document-updater:3003`, inom Docker-nätverket
* <strong>Autentisering:</strong> ingen
* <strong>OpenAPI-fil:</strong> [`develop/hoppscotch/openapi/document-updater.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/document-updater.yaml)
