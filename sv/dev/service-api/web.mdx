Privat API för web, Overleafs huvudapp. Andra tjänster (real-time, document-updater, project-history, third-party-datastore, git-bridge) och cronskripten i Server CE-avbildningen anropar det. Dessa rutter kräver bara HTTP basic auth, ingen CSRF-token: den privata routern monteras före webbroutern, och bara webbroutern kör CSRF-kontrollen. Med `BLOCK_CROSS_ORIGIN_REQUESTS=true` (av som standard) returnerar web 403 för varje begäran vars `Origin`-huvud inte finns i `ALLOWED_ORIGINS` (standard: webbplatsens URL). Webbläsare skickar `Origin` vid POST, så med den inställningen på får POST-anrop från Hoppscotch i webbläsaren 403 om de inte går via Hoppscotch-proxyn.

* <strong>Adress:</strong> `http://web:3000`, inom Docker-nätverket
* <strong>Autentisering:</strong> HTTP basic auth med `WEB_API_USER` och `WEB_API_PASSWORD`, utom för status, health och metrics. git-bridge-rutterna använder i stället en personlig åtkomsttoken.
* <strong>OpenAPI-fil:</strong> [`develop/hoppscotch/openapi/web.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/web.yaml)
