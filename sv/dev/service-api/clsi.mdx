CLSI (Common LaTeX Service Interface) kompilerar projekt, kör SyncTeX och texcount på kompileringsutdata och konverterar dokument med pandoc. Web anropar den; själva utdatafilerna levereras av clsi-nginx, inte via den här porten. Ingen autentisering: den nås bara inom Docker-nätverket.

* <strong>Adress:</strong> `http://clsi:3013`, inom Docker-nätverket
* <strong>Autentisering:</strong> ingen
* <strong>OpenAPI-fil:</strong> [`develop/hoppscotch/openapi/clsi.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/clsi.yaml)
