Lagrar aviseringarna som visas för användare i projektlistan (till exempel projektinbjudningar) i Mongo-samlingen `notifications`. Web och third-party-datastore anropar den; den har ingen autentisering och nås bara inom Docker-nätverket.

* <strong>Adress:</strong> `http://notifications:3042`, inom Docker-nätverket
* <strong>Autentisering:</strong> ingen
* <strong>OpenAPI-fil:</strong> [`develop/hoppscotch/openapi/notifications.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/notifications.yaml)
