`tags` innehåller de taggar (mappar) som en användare sorterar projekt i på projektpanelen. Ett dokument är en tagg för en användare. `web` äger den; schemat är `services/web/app/src/models/Tag.mjs`, och alla skrivningar går via `services/web/app/src/Features/Tags/TagsHandler.mjs`.

#### Fält {#fields}

| Fält | Typ | Betydelse | Källa |
| --- | --- | --- | --- |
| `_id` | ObjectId | Taggens id, används i routerna `/tag/:tagId`. | `Tag.mjs:10` |
| `user_id` | String | Taggens ägare. En vanlig sträng, inte ett ObjectId, av historiska skäl. | `Tag.mjs:7-12` |
| `name` | String | Taggens namn, högst 50 tecken (`MAX_TAG_LENGTH`). Unikt per användare. | `Tag.mjs:13`, `TagsHandler.mjs:4` |
| `color` | String | Valfri färg: en hexkod som `#a1b2c3` eller ett värde `hsl(<n>, 70%, 45%)` (`TAG_COLOR_REGEX`). | `Tag.mjs:5`, `Tag.mjs:14-22` |
| `project_ids` | Array of String | Id för projekten i taggen, som strängar. | `Tag.mjs:23` |
| `__v` | Number | Mongoose-versionsnyckel, läggs till när `Tag.create` skapar dokumentet. | `TagsHandler.mjs:27` |

#### Anmärkningar {#notes}

* Taggar gäller per användare: två medarbetare i samma projekt har var sina egna taggar för det.
* `user_id` och `project_ids` är strängar, så fråga efter dem med sträng-id, inte med ObjectId.
* Att radera en användare (`services/web/app/src/Features/User/UserDeleter.mjs`) påverkar inte `tags`.
