---
title: Samlingen Tokens
icon: key
---

`tokens` innehåller engångstoken: hemligheten i en länk som låter någon ange ett lösenord. Ett dokument är en token. Det finns ingen Mongoose-modell; web skriver samlingen via `services/web/app/src/Features/Security/OneTimeTokenHandler.mjs` med den inbyggda drivrutinen.

#### Fält {#fields}

| Fält | Typ | Betydelse | Källa |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Dokument-id. | `OneTimeTokenHandler.mjs:40` |
| `use` | String | Vad token är till för, se [Användningar](#uses) nedan. Varje uppslag filtrerar på det. | `OneTimeTokenHandler.mjs:41` |
| `token` | String | Hemligheten i länken: 32 slumpmässiga byte som 64 hextecken, lagrad som den är. | `OneTimeTokenHandler.mjs:38,42` |
| `data` | Object | Vad token står för; returneras när den används. | `OneTimeTokenHandler.mjs:43` |
| `data.user_id` | String | Användarens id, skrivet som sträng av varje anropare. | `services/web/app/src/Features/PasswordReset/PasswordResetHandler.mjs:27`, `services/web/app/src/Features/User/UserRegistrationHandler.mjs:117`, `services/web/modules/admin-tools/app/src/AdminUserManager.mjs:79` |
| `data.email` | String | Användarens e-post när token skapades. En lösenordsåterställning slår upp användaren via denna primära e-post (`PasswordResetHandler.mjs:66-70`). | samma som `data.user_id` |
| `createdAt` | Date | Tidpunkt för skapande. TTL-indexet tar bort token 90 dagar senare. | `OneTimeTokenHandler.mjs:36,44` |
| `expiresAt` | Date | `createdAt` plus `expiresIn` sekunder: 1 timme som standard, 1 vecka för en aktiveringslänk. Uppslag ignorerar en token efter denna tidpunkt. | `OneTimeTokenHandler.mjs:35-37,45` |
| `peekCount` | Number | Hur många gånger token har tittats på utan att användas. Varje `peekValueFromToken` lägger till 1; vid 4 (`MAX_PEEKS`) slutar token fungera. | `OneTimeTokenHandler.mjs:8-31,107` |
| `usedAt` | Date | Tidpunkt då token användes eller avbröts. Uppslag ignorerar en token som har det. | `OneTimeTokenHandler.mjs:51-104` |

#### Användningar {#uses}

| `use` | Funktion | Giltighet | Kod |
| ----- | ------- | ------ | ---- |
| `password` | E-post för lösenordsåterställning, från sidan "glömt lösenord" | 1 timme | `PasswordResetHandler.mjs:14-42` |
| `password` | Aktiveringslänk: ett konto skapat med ett slumpmässigt lösenord, sedan en länk för att ange ett. Används av offentlig registrering (`services/web/modules/login-register/app/src/RegisterController.mjs:65`), adminregistreringssidan i `user-activate` (`services/web/modules/user-activate/app/src/UserActivateController.mjs:27-30`) och skriptet `create-user` (`services/web/modules/server-ce-scripts/scripts/create-user.mjs:21`) | 1 vecka | `UserRegistrationHandler.mjs:97-130` |
| `password` | Aktiverings- eller återställningslänk skickad från adminpanelen (modulen `admin-tools`) | 1 vecka (aktivering), 1 timme (återställning) | `AdminUserManager.mjs:76-103,196-206` |
| `email_confirmation` | Länk för att bekräfta e-post. Läses bara: inget i detta repo skapar längre sådana token, eftersom bekräftelsen nu skickar en 6-siffrig kod (`services/web/app/src/Features/User/UserEmailsConfirmationHandler.mjs:15-35`) | | `UserEmailsConfirmationHandler.mjs:12,37-66` |

#### Vem skriver {#who-writes-it}

| Kod | Vad den gör |
| ---- | ------------ |
| `OneTimeTokenHandler.mjs:34-49` (`getNewToken`) | Infogar en token. Anropare: `PasswordResetHandler.mjs:28`, `UserRegistrationHandler.mjs:115-119`, `AdminUserManager.mjs:77-81`. |
| `OneTimeTokenHandler.mjs:8-32` (`peekValueFromToken`) | Returnerar `data` för en giltig token och lägger till 1 i `peekCount`. Används när sidan för lösenordsåterställning öppnas (`services/web/app/src/Features/PasswordReset/PasswordResetController.mjs:195-208`), igen när det nya lösenordet anges (`PasswordResetHandler.mjs:94-96`) och av e-postbekräftelsen (`UserEmailsConfirmationHandler.mjs:38-41`). |
| `OneTimeTokenHandler.mjs:75-88` (`expireToken`) | Sätter `usedAt` på en token: efter att ett nytt lösenord har angetts (`PasswordResetHandler.mjs:44-48,119`) eller en e-post har bekräftats (`UserEmailsConfirmationHandler.mjs:65`). |
| `OneTimeTokenHandler.mjs:90-104` (`expireAllTokensForUser`) | Sätter `usedAt` på varje öppen `password`-token för en användare, när användaren byter lösenord i inställningarna (`services/web/app/src/Features/User/UserController.mjs:146-149`) eller en administratör anger det i adminpanelen (`AdminUserManager.mjs:479-488`). |

| Kod | Vad den gör |
| ---- | ------------ |
| `PasswordResetHandler.mjs:50-70,94-119` | Omvandlar en återställnings- eller aktiveringstoken till användaren och anger sedan lösenordet. Aktiveringssidan i `user-activate` skickar bara vidare token till detta formulär. |

#### Anteckningar {#notes}

* En använd eller utgången token tas inte bort direkt: den finns kvar, med `usedAt` eller ett passerat `expiresAt`, tills TTL-indexet tar bort den 90 dagar efter `createdAt`.
* `OneTimeTokenHandler` har också `getValueFromTokenAndExpire` (`OneTimeTokenHandler.mjs:51-73`), men inget anropar den.
