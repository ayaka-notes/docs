---
title: Samlingen Spelling Preferences
icon: spell-check
---

`spellingPreferences` innehåller varje användares ordlista: de ord som användaren har lagt till via "Add to dictionary" i redigerarens stavningskontroll. Ett dokument per användare. `web` äger den, utan Mongoose-schema; koden är `services/web/app/src/Features/Spelling/LearnedWordsManager.mjs`.

#### Fält {#fields}

| Fält | Typ | Betydelse | Källa |
| --- | --- | --- | --- |
| `_id` | ObjectId | Dokumentets id, skapat av upserten. | `LearnedWordsManager.mjs:21-31` |
| `token` | String | Användarens id. Trots namnet skickar stavningsrouterna id för den inloggade användaren (`SessionManager.getLoggedInUserId`). | `LearnedWordsManager.mjs:23` |
| `learnedWords` | Array of String | Orden som användaren har lagt till. | `LearnedWordsManager.mjs:26` |

#### Vem skriver {#who-writes-it}

| Kod | Vad den gör |
| --- | --- |
| `LearnedWordsManager.mjs:13-32` (`learnWord`) | `POST /spelling/learn` (`services/web/app/src/router.mjs:1037-1041`, `services/web/app/src/Features/Spelling/SpellingController.mjs:45-58`): `$addToSet` av ordet, med upsert. Nekar när listan skulle bli större än `Settings.maxDictionarySize` byte. |
| `LearnedWordsManager.mjs:38-47` (`unlearnWord`) | `POST /spelling/unlearn` (`router.mjs:1043-1047`, `SpellingController.mjs:66-79`): `$pull` av ordet. |
| `LearnedWordsManager.mjs:84-86` (`deleteUsersLearnedWords`) | Raderar dokumentet. Dess enda omslag, `SpellingHandler.deleteUserDictionary` (`services/web/app/src/Features/Spelling/SpellingHandler.mjs:24-26`), anropas ingenstans i web eller dess moduler. |

#### Vem läser {#who-reads-it}

| Kod | Vad den gör |
| --- | --- |
| `LearnedWordsManager.mjs:52-67` (`getLearnedWords`) | Returnerar orden utan dubbletter. |
| `services/web/app/src/Features/Project/ProjectController.mjs:671` | Skickar ordlistan till redigeraren när ett projekt öppnas (`SpellingHandler.getUserDictionary`). |
