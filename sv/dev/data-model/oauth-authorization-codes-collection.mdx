---
title: Samlingen OAuth Authorization Codes
icon: lock-open
---

`oauthAuthorizationCodes` är avsedd för koderna i OAuth-flödet authorization code: ett dokument per kod, som en klient byter mot en åtkomsttoken. Schemat är `services/web/app/src/models/OauthAuthorizationCode.mjs`, och webbmodulen `oauth2-server` innehåller koden som skulle skriva till den. I Ayakaleaf Pro når inget den koden, så samlingen förblir tom (se Anteckningar).

#### Fält {#fields}

| Fält | Typ | Betydelse | Källa |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Dokument-id. | `OauthAuthorizationCode.mjs:6` |
| `authorizationCode` | String | Själva koden, lagrad som den är (inte hashad). | `OauthAuthorizationCode.mjs:8`, `services/web/modules/oauth2-server/app/src/OAuth2Model.mjs:280` |
| `expiresAt` | Date | Giltighetens slut. `getAuthorizationCode` avvisar en kod efter det, och TTL-indexet tar bort den. | `OauthAuthorizationCode.mjs:9`, `OAuth2Model.mjs:150-153,281` |
| `oauthApplication_id` | ObjectId | Klienten i [OAuth Applications](/sv/dev/data-model/oauth-applications-collection) som begärde koden. | `OauthAuthorizationCode.mjs:10`, `OAuth2Model.mjs:275-284` |
| `redirectUri` | String | Begärans omdirigerings-URI. | `OauthAuthorizationCode.mjs:11`, `OAuth2Model.mjs:282` |
| `scope` | String | Begärd scope. | `OauthAuthorizationCode.mjs:12`, `OAuth2Model.mjs:283` |
| `user_id` | ObjectId | Användaren som beviljade koden. | `OauthAuthorizationCode.mjs:13`, `OAuth2Model.mjs:285` |
| `codeChallenge`, `codeChallengeMethod` | String | PKCE-challenge och dess metod. | `OauthAuthorizationCode.mjs:14-15`, `OAuth2Model.mjs:286-287` |

#### Vem skriver {#who-writes-it}

| Kod | Vad den gör |
| ---- | ------------ |
| `OAuth2Model.mjs:274-300` (`saveAuthorizationCode`) | Infogar en kod. Nås inte, se Anteckningar. |
| `OAuth2Model.mjs:307-312` (`revokeAuthorizationCode`) | Tar bort en kod när den har använts. Nås inte. |

#### Vem läser {#who-reads-it}

| Kod | Vad den gör |
| ---- | ------------ |
| `OAuth2Model.mjs:137-177` (`getAuthorizationCode`) | Läser in en kod med dess användare och klient. Nås inte. |

#### Index {#indexes}

| Namn | Nycklar | Alternativ | Migrering |
| ---- | ---- | ------- | --------- |
| `expiresAt_1` | `{ expiresAt: 1 }` | TTL, `expireAfterSeconds: 0`, partiellt: `expiresAt` finns | `20230406125632_oauth_tokens_ttl.mjs` |

Migreringarna finns i `tools/migrations/`. Det unika indexet `authorizationCode_1` kommer bara från migreringar taggade `saas` och `server-pro`, som Community Edition inte kör.

#### Anteckningar {#notes}

* Modellmetoderna ovan anropas bara av authorize- och token-hanterarna i `@node-oauth/oauth2-server`. Web använder det biblioteket bara för att kontrollera bearer-token (`services/web/app/src/Features/Authentication/AuthenticationController.mjs:409-450`), och ingen route betjänar `/oauth/authorize` eller `/oauth/token`, så ingen kod skrivs någonsin. Personliga åtkomsttoken skapas direkt, se [OAuth Access Tokens](/sv/dev/data-model/oauth-access-tokens-collection).
