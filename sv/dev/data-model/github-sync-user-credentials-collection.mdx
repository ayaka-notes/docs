---
title: Samlingen GitHub Sync User Credentials
icon: key
---

`githubSyncUserCredentials` innehåller ett dokument per användare som har kopplat ett GitHub-konto för GitHub Sync. Den lagrar användarens OAuth-åtkomsttoken, krypterad. Samlingen hör till webbmodulen `github-sync` (`services/web/modules/github-sync`). Schemat finns i `services/web/modules/github-sync/app/models/githubSyncUserCredentials.mjs`, och all åtkomst går via `services/web/modules/github-sync/app/src/TokenManager.mjs`.

#### Fält {#fields}

| Fält | Typ | Betydelse | Källa |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Sätts av Mongoose när upserten infogar. | |
| `userId` | ObjectId | Overleaf-användaren. Obligatoriskt. Schemat anger `unique: true`, men inget index byggs (se Index); upserten på `userId` håller ett dokument per användare. | `githubSyncUserCredentials.mjs:8`, `TokenManager.mjs:44-48` |
| `github` | String | GitHubs OAuth-åtkomsttoken, krypterad med `@overleaf/access-token-encryptor`. Lösenordet kommer från `GITHUB_TOKEN_CIPHER_PASSWORD`; chifferetiketten är `GITHUB_TOKEN_CIPHER_LABEL`, standard `2026.3-v3`. Obligatoriskt. | `githubSyncUserCredentials.mjs:9`, `TokenManager.mjs:12-25` |
| `__v` | Number | Mongoose versionsnyckel. Schemat stänger inte av den. | Mongoose-standard |

Bara åtkomsttoken lagras: OAuth-callbacken behåller `access_token` från GitHubs svar (`services/web/modules/github-sync/app/src/GitHubApiClient.mjs:180-191`). Det finns ingen uppdateringstoken eller utgångstid.

#### Vem skriver {#who-writes-it}

| Kod | Vad den gör |
| ---- | ------------ |
| `TokenManager.mjs:42-58` (`saveUserToken`) | Gör upsert av användarens krypterade token. När användaren kopplar igen återkallas den ersatta token hos GitHub i bakgrunden. Anropas från OAuth-callbacken (`services/web/modules/github-sync/app/src/GitHubSyncController.mjs:146`). |
| `TokenManager.mjs:61-76` (`removeUserToken`) | Återkallar token hos GitHub (i mån av möjlighet) och tar sedan bort dokumentet. Anropas vid bortkoppling (`GitHubSyncController.mjs:167`) och när en borttagen användare löper ut (`services/web/modules/github-sync/index.mjs:66-68`). |

#### Vem läser {#who-reads-it}

| Kod | Vad den gör |
| ---- | ------------ |
| `TokenManager.mjs:36-40` (`getUserToken`) | Dekrypterar token för varje anrop till GitHubs API: `services/web/modules/github-sync/app/src/GitHubSyncHandler.mjs` (till exempel `:27`) och `services/web/modules/github-sync/app/src/GitMerge.mjs:43`. Utan dokument, eller med en token som inte går att dekryptera, kastar den `InvalidTokenError`, och användaren räknas som inte kopplad (`GitHubSyncHandler.mjs:25-37`). |
| `services/web/modules/admin-tools/app/src/AdminUserListManager.mjs:393` | Kontrollerar om användaren har ett dokument, för integrationerna som visas i adminpanelen. |

#### Index {#indexes}

| Namn | Nycklar | Alternativ | Migrering |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

Mongoose `autoIndex` är avstängt (`services/web/app/src/infrastructure/Mongoose.mjs:7`), så schemats `unique: true` på `userId` skapar ingenting. `tools/migrations/20190912145011_create_githubSyncUserCredentials_indexes.mjs` (upstreams `user_id`) är bara taggad `saas` och körs inte i CE.

#### Anteckningar {#notes}

* Att ändra `GITHUB_TOKEN_CIPHER_PASSWORD` gör de lagrade token oläsliga. De användarna räknas då som inte kopplade tills de kopplar igen.
* En borttagen användare behåller dokumentet tills användaren löper ut.
