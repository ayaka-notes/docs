---
title: Samlingen Project History Sharded Blobs
icon: cubes-stacked
---

`projectHistoryShardedBlobs` innehåller de blobposter som inte fick plats i [projectHistoryBlobs](/dev/data-model/project-history-blobs-collection): när hinken för ett hashprefix redan har 8 poster där hamnar nästa här. Ett projekt har högst 16 dokument här, ett per första hexsiffra i hashen. Det finns inget Mongoose-schema; history-v1 skriver den i `services/history-v1/storage/lib/blob_store/mongo.js` (struktur beskriven vid `mongo.js:1-16`).

#### Fält {#fields}

| Fält | Typ | Betydelse | Källa |
| ----- | ---- | ------- | ------ |
| `_id` | Binary | 13 byte: projektets historik-id, ett `0`, och shardsiffran, läst som hex (`<history id>0<digit>`). Shardsiffran är hashens första hexsiffra. | `mongo.js:439-453` |
| `blobs` | Object | Blobposter grupperade i hinkar. En hinks nyckel är hexsiffrorna 2 till 4 i hashen. | `mongo.js:439-443` |
| `blobs.<bcd>` | Array of Object | Hinkens poster. Koden begränsar inte storleken. | `mongo.js:399-407` |
| `blobs.<bcd>[].h` | Binary | Hashen, 20 byte, som i projectHistoryBlobs. | `mongo.js:472` |
| `blobs.<bcd>[].b` | Number | Innehållets längd i byte. | `mongo.js:473` |
| `blobs.<bcd>[].s` | Number | Innehållets längd som text; `null` när innehållet inte är redigerbar text. | `mongo.js:474` |

#### Vem skriver {#who-writes-it}

| Kod | Vad den gör |
| ---- | ------------ |
| `services/history-v1/storage/lib/blob_store/mongo.js:399-407` | `insertRecordSharded`: upsert med `$addToSet` i hinken. Anropas av `insertBlob` när hinken i projectHistoryBlobs är full (`mongo.js:387-389`). |
| `mongo.js:75-103` | `clone`: kopierar projektets shards till ett annat historik-id, för history-v1 `POST /projects/:project_id/clone`, som inget i web anropar. |
| `mongo.js:413-422` | `deleteBlobs`: tar bort alla projektets shards tillsammans med dess projectHistoryBlobs-dokument, vid history-v1 `DELETE /projects/:project_id`. |

#### Vem läser {#who-reads-it}

| Kod | Vad den gör |
| ---- | ------------ |
| `mongo.js:144-157` | `findBlobSharded`: en blob, som bara slås upp när dess hink i projectHistoryBlobs har 8 poster och inte innehåller den (`mongo.js:127-131`). |
| `mongo.js:217-260` | `findBlobsSharded`: de blobbar som `findBlobs` inte hittade i projectHistoryBlobs (`mongo.js:202-206`). |
| `mongo.js:285-306` | `getProjectBlobs`: alla shards i ett projekt. |
| `mongo.js:337-361` | `getProjectBlobsBatch`: alla shards i flera projekt, för routen för blobstatistik. |

#### Index {#indexes}

Bara standardindexet `_id`. Ingen migrering i `tools/migrations/` lägger till något.

#### Anteckningar {#notes}

* Ett projekts shards ligger bredvid varandra i `_id`-ordning, så koden hittar dem med ett `_id`-intervall från `<history id>00` till `<history id>0f` (`mongo.js:75-80`, `287-295`).
* Samlingen uppstår först när något projekt har fler än 8 blobbar med samma tresiffriga hashprefix, så en liten instans kanske inte har den alls.
