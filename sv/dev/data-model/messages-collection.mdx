title: Samlingen Messages
icon: message
---

`messages` innehåller ett dokument per meddelande: en rad i projektchatten, eller en kommentar eller ett svar i en tråd med granskningskommentarer. Bara chattjänsten skriver den, i `services/chat/app/js/Features/Messages/MessageManager.js`. Det finns inget Mongoose-schema. Varje meddelande hör till ett rum i samlingen [rooms](/sv/dev/data-model/rooms-collection).

#### Fält {#fields}

| Fält | Typ | Betydelse | Källa |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Meddelandets id. | `MessageManager.js:13-14` |
| `room_id` | ObjectId | Rummet (`rooms._id`), inte projekt-id:t eller tråd-id:t. | `MessageManager.js:8,106-108` |
| `user_id` | ObjectId | Författare. | `MessageManager.js:9,103-105` |
| `content` | String | Meddelandets text, 1 till 10240 tecken (`MAX_MESSAGE_LENGTH`). | `MessageManager.js:7`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:3,12-15` |
| `timestamp` | Number | När det skickades, i millisekunder sedan 1970 (`Date.now()`), inte ett Date. | `MessageManager.js:10`, `services/chat/app/js/Features/Messages/MessageHttpController.js:288` |
| `edited_at` | Number | När det senast redigerades, i millisekunder (`Date.now()`). Saknas om det aldrig redigerats. | `MessageManager.js:65-69`, `MessageHttpController.js:189,213` |

#### Vem skriver {#who-writes-it}

| Kod | Vad den gör |
| ---- | ------------ |
| `MessageManager.js:5-16` `createMessage` | Infogar ett meddelande (`MessageHttpController.js:275-294`). Web skickar projektchattmeddelanden från `services/web/app/src/Features/Chat/ChatController.mjs:32`, och kommentarer från modulen track-changes (`services/web/modules/track-changes/app/src/TrackChangesController.mjs:95`) och modulen mcp-server (`services/web/modules/mcp-server/app/src/CommentTools.mjs:133`). |
| `MessageManager.js:51-72` `updateMessage` | Sätter `content` och `edited_at`. När ett användar-id anges matchar bara den användarens meddelande (`MessageManager.js:62-64`). Anropas från `ChatController.mjs:135` och `TrackChangesController.mjs:110`. |
| `MessageManager.js:74-80` `deleteMessage` | Tar bort ett meddelande. Anropas från `ChatController.mjs:105` och `TrackChangesController.mjs:129`. |
| `MessageManager.js:39-49` `deleteAllMessagesInRoom(s)` | Tar bort meddelandena i en borttagen tråd (`MessageHttpController.js:172-173`) eller i ett helt projekt när ett borttaget projekt löper ut (`MessageHttpController.js:261-271`, anropas från `services/web/app/src/Features/Project/ProjectDeleter.mjs:391`). |
| `MessageManager.js:115-127` `duplicateRoomToOtherRoom` | Kopierar `content`, `timestamp` och `user_id` för varje meddelande till ett annat rum, utan `edited_at`. #### Anteckningar {#notes}

* För att hitta meddelandena för en kommentar slår du först upp rummet via `project_id` och `thread_id` och frågar sedan på `room_id`. Kommentarens id i doc:et är `thread_id`, inte `room_id`.
* Texten som en kommentar pekar på är `op.c` i `docs.ranges.comments`; diskussionen finns här.
