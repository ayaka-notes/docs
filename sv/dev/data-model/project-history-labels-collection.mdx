---
title: Samlingen Project History Labels
icon: tag
---

`projectHistoryLabels` innehåller de etiketter som användare sätter på versioner i History-vyn, ett dokument per etikett. project-history äger den och skriver den i `services/project-history/app/js/LabelsManager.js`; det finns inget Mongoose-schema. Web når den bara via project-history-API:t.

#### Fält {#fields}

| Fält | Typ | Betydelse | Källa |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Etikettens id. | `LabelsManager.js:81-85` |
| `project_id` | ObjectId | Projektet. | `LabelsManager.js:73` |
| `comment` | String | Etikettens text. | `LabelsManager.js:74` |
| `version` | Number | Den version av projekthistoriken som etiketten pekar på. | `LabelsManager.js:75` |
| `created_at` | Date | När etiketten skapades; förfrågan kan skicka en egen tid, annars är det nu. | `LabelsManager.js:70`, `76` |
| `user_id` | ObjectId | Vem som skapade etiketten. Utelämnas när förfrågan saknar användare. | `LabelsManager.js:78-80` |

#### Vem skriver {#who-writes-it}

| Kod | Vad den gör |
| ---- | ------------ |
| `services/project-history/app/js/LabelsManager.js:44-90` | `createLabel`: infogar en etikett, för project-history `POST /project/:project_id/labels` (`services/project-history/app/js/HttpController.js:1134-1171`). Web anropar den när en användare lägger till en etikett, med användarens id (`services/web/app/src/Features/History/HistoryController.mjs:529-546`). |
| `LabelsManager.js:113-126` | `deleteLabel`: tar bort en etikett i projektet, för `DELETE /project/:project_id/labels/:label_id`. Web använder den när projektägaren tar bort en etikett (`HistoryController.mjs:649-670`). |
| `LabelsManager.js:92-111` | `deleteLabelForUser`: tar bort en etikett bara om användaren skapade den, för `DELETE /project/:project_id/user/:user_id/labels/:label_id`. Web använder den för alla andra. |
| `LabelsManager.js:128-143` | `transferLabels`: flyttar alla etiketter från en användare till en annan, för `POST /user/:from_user/labels/transfer/:to_user` (`services/project-history/app/js/Router.js:52-55`). Inget i web anropar den här routen. |
| `LabelsManager.js:7-25` | `cloneLabels`: kopierar ett projekts etiketter till ett annat projekt, för project-history `POST /project/:project_id/clone` (`HttpController.js:113`), som inget i web anropar. |

#### Anteckningar {#notes}

* Innan project-history infogar en etikett bearbetar den projektets köade uppdateringar och kontrollerar att history-v1 har en chunk för den versionen, om inte förfrågan skickar `validate_exists: false` (`LabelsManager.js:53-59`, `173-195`; `HttpController.js:1109-1115`).
* Ingen kod tar bort ett projekts etiketter när projektet tas bort: project-history `DELETE /project/:project_id` rensar bara synkroniseringsstatusen och felposten (`HttpController.js:1363-1396`), och ingen annan tjänst rör den här samlingen.
