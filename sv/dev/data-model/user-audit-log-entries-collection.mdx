title: Samlingen User Audit Log Entries
icon: user-clock

`userAuditLogEntries` är granskningsloggen för användarkonton: inloggningar, ändringar av lösenord och e-post, länkade konton och administratörsåtgärder. Ett dokument är en händelse på ett konto. `web` äger den; schemat är `services/web/app/src/models/UserAuditLogEntry.mjs`, och kärnan skriver via `services/web/app/src/Features/User/UserAuditLogHandler.mjs`.
