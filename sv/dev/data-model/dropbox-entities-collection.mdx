---
title: Samlingen Dropbox Entities
icon: file-arrow-up
---

`dropboxEntities` innehåller ett dokument per fil som Dropbox-synkroniseringen har kopierat mellan ett projekt och en användares Dropbox, samt kortlivade tombstones. Samlingen hör till Dropbox-synkroniseringen: third-party-datastore (`services/third-party-datastore/app/js/StateManager.mjs`) skriver och läser den, och webbmodulen `dropbox` (`services/web/modules/dropbox/app/src/DropboxHandler.mjs`) rensar den. Det finns inget Mongoose-schema.

#### Fält {#fields}

| Fält | Typ | Betydelse | Källa |
| ---- | --- | --------- | ----- |
| `_id` | ObjectId | Sätts av drivrutinen vid infogning. | `StateManager.mjs:46,97` |
| `overleaf.userId` | ObjectId | Användaren vars Dropbox har filen. Sätts på varje dokument. | `StateManager.mjs:48,98` |
| `overleaf.projectId` | ObjectId | Projektet för docen eller filen. Sätts när det är känt; tombstones har inget. | `StateManager.mjs:49-51` |
| `overleaf.id` | ObjectId | `_id` för docen eller filen i projektets `rootFolder`. Sätts när den är känd. | `StateManager.mjs:52` |
| `overleaf.type` | String | `doc` eller `file`. Den nuvarande koden skriver det men läser det inte. | `StateManager.mjs:53`; värden från `services/web/app/src/Features/ThirdPartyDataStore/TpdsUpdateSender.mjs:35,96` och `UpdateMerger.mjs:104,119` |
| `dropbox.id` | String | Filens `id` i Dropbox-filens metadata. Sätts inte på tombstones. | `StateManager.mjs:56` |
| `dropbox.pathLower` | String | Filens sökväg i Dropbox, i gemener och utan avslutande snedstreck. Uppdateras när filen eller dess projektmapp flyttas. | `StateManager.mjs:14-16,57,91,99` |
| `dropbox.rev` | String | Dropbox-revisionen vid den senaste synkningen. Nästa uppladdning skickar den, så att en fil som ändrats i Dropbox inte skrivs över. | `StateManager.mjs:58`, `JobProcessor.mjs:114-122` |
| `dropbox.contentHash` | String | Dropbox-innehållshashen vid den senaste synkningen. En listad fil med samma hash hoppas över, eftersom den är vår egen uppladdning eller redan tillämpad. | `StateManager.mjs:59`, `PullManager.mjs:147-149` |
| `tombstone` | Boolean | `true` markerar en sökväg som third-party-datastore själv har tagit bort eller flyttat bort i Dropbox. När Dropbox rapporterar tillbaka borttagningen tillämpas den inte på projektet. | `StateManager.mjs:100`, `PullManager.mjs:189-192` |
| `createdAt` | Date | Endast tombstones: när den skapades. En avslutad pull tar bort de tombstones som skapades innan den startade. | `StateManager.mjs:101,115-121` |

En tombstone har bara `overleaf.userId`, `dropbox.pathLower`, `tombstone` och `createdAt` (`StateManager.mjs:96-103`).

#### Index {#indexes}

| Namn | Nycklar | Alternativ | Migrering |
| ---- | ------- | ---------- | --------- |
| `_id_` | `_id: 1` | | default |
| `overleaf_userId_1_overleaf_projectId_1` | `overleaf.userId: 1, overleaf.projectId: 1` | | `tools/migrations/20250130104049_create_dropboxEntities_userId_projectId_index.mjs` |

`20220811111800_create_dropboxEntities_index.mjs` och `20220825160708_recreate_dropboxEntities.mjs` har bara taggen `saas`, så CE har varken deras unika index på `(overleaf.userId, dropbox.id)` och `(overleaf.userId, overleaf.id)` eller deras hashade index på `dropbox.pathLower`.

#### Anteckningar {#notes}

* Unikheten kommer enbart från borttagningen före varje infogning i `recordEntity` (`StateManager.mjs:38-45`). Kommentaren i `StateManager.mjs:3-11` nämner unika index; CE har dem inte.
* Frågor på användare och sökväg (`findEntityByPath`, `findTombstone`, `removeEntities`) använder indexet bara för `overleaf.userId`.
