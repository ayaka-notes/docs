title: Samlingen Doc Snapshots
icon: camera
---

`docSnapshots` innehåller kopior av ett doc som document-updater tar precis före en redigering som fäller ihop kommentarer eller spårade ändringar. Bara document-updater skriver den, i `services/document-updater/app/js/SnapshotManager.js`. Web har en Mongoose-modell i `services/web/app/src/models/DocSnapshot.mjs`, men ingen kod använder den.

#### Fält {#fields}

| Fält | Typ | Betydelse | Källa |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Ögonblicksbildens id. | `SnapshotManager.js:24` |
| `project_id` | ObjectId | Projekt. | `SnapshotManager.js:19,26`, `DocSnapshot.mjs:7` |
| `doc_id` | ObjectId | Doc:et (`docs._id`). | `SnapshotManager.js:20,27`, `DocSnapshot.mjs:8` |
| `version` | Number | Doc:ets OT-version före redigeringen. | `SnapshotManager.js:28`, `services/document-updater/app/js/UpdateManager.js:132,264-271`, `DocSnapshot.mjs:9` |
| `lines` | Array of String | Doc:ets innehåll före redigeringen. | `SnapshotManager.js:29`, `DocSnapshot.mjs:10` |
| `pathname` | String | Doc:ets sökväg i projektet vid den tidpunkten. | `SnapshotManager.js:30`, `DocSnapshot.mjs:11` |
| `ranges` | Mixed | `comments` och `changes` före redigeringen, i samma form som `docs.ranges` (se [docs](/sv/dev/data-model/docs-collection)). `id`, `op.t` och `metadata.user_id` görs om till ObjectIds och `metadata.ts` till Dates. | `SnapshotManager.js:31,41-68`, `DocSnapshot.mjs:12` |
| `ts` | Date | När ögonblicksbilden togs. TTL-indexet tar bort den 30 dagar senare. | `SnapshotManager.js:32`, `DocSnapshot.mjs:13` |

#### Vem skriver {#who-writes-it}

| Kod | Vad den gör |
| ---- | ------------ |
| `UpdateManager.js:248-271` | När document-updater har tillämpat en redigering sparar den doc:et som det var före redigeringen om redigeringen fällde ihop intervall: fler intervall blev tomma, eller mer än ett intervall togs bort (`services/document-updater/app/js/RangesManager.js:104-106`). |
| `SnapshotManager.js:17-36` `recordSnapshot` | Infogar ögonblicksbilden. |

#### Vem läser {#who-reads-it}

Ingen kod läser den. Web-modellen är definierad men används ingenstans.

#### Anteckningar {#notes}

* Bara redigeringar som går genom `UpdateManager.applyUpdate` tar ögonblicksbilder. Redigeringar som `HistoryOTUpdateManager` hanterar gör det inte (`UpdateManager.js:74-77`).
* Det finns inget index på `doc_id`. Hitta ett docs ögonblicksbilder via `project_id` och `ts` och filtrera sedan på `doc_id`.
