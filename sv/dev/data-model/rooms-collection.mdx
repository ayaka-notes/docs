title: Samlingen Rooms
icon: comments
---

`rooms` innehåller ett dokument per chattrum i ett projekt: projektchatten eller en tråd med granskningskommentarer. Bara chattjänsten skriver den, i `services/chat/app/js/Features/Threads/ThreadManager.js`. Det finns inget Mongoose-schema. Ett rums meddelanden finns i samlingen [messages](/sv/dev/data-model/messages-collection).

#### Fält {#fields}

| Fält | Typ | Betydelse | Källa |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Rummets id. `messages.room_id` pekar hit. | `ThreadManager.js:57-61` |
| `project_id` | ObjectId | Projektet som rummet tillhör. | `ThreadManager.js:43-54` |
| `thread_id` | ObjectId | Bara på kommentarstrådar: kommentarens id, samma som `id` och `op.t` för kommentaren i `docs.ranges.comments` (se [docs](/sv/dev/data-model/docs-collection)). Saknas på projektchattens rum. | `ThreadManager.js:38-55`, `services/docstore/app/js/RangeManager.js:54-57` |
| `resolved` | Object | Sätts när tråden löses och tas bort när den öppnas igen. En tråd utan fältet är öppen. | `ThreadManager.js:94-123` |
| `resolved.user_id` | String | Id för användaren som löste tråden. Lagras som en sträng, inte som ObjectId: förfrågans body kontrolleras bara som ett giltigt id och konverteras inte. | `ThreadManager.js:103`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:70` |
| `resolved.ts` | Date | När tråden löstes. | `ThreadManager.js:104` |

#### Anteckningar {#notes}

* Ett projekt har högst ett rum utan `thread_id`: projektchatten. Chattjänsten hittar det med `thread_id: { $exists: false }` (`ThreadManager.js:38-45`).
* En kommentars lösta status finns bara här. Docstore tar bort `op.resolved` innan den sparar intervall (`services/docstore/app/js/RangeManager.js:59-61`).
* Efter en projektkopia finns samma `thread_id` i två projekt. Fråga alltid på `project_id` och `thread_id` tillsammans, som chattjänsten gör.
* Rummen i ett borttaget projekt finns kvar tills det borttagna projektet löper ut.
