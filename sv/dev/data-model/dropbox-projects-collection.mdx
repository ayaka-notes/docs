---
title: Samlingen Dropbox Projects
icon: folder-open
---

`dropboxProjects` kopplar ett projekt till dess mapp i en användares Dropbox. Ett projekt som delas med flera Dropbox-användare har ett dokument per användare. Samlingen hör till Dropbox-synkroniseringen: third-party-datastore (`services/third-party-datastore/app/js/StateManager.mjs`) skriver den, och webbmodulen `dropbox` (`services/web/modules/dropbox/app/src/DropboxHandler.mjs`) läser och rensar den. Det finns inget Mongoose-schema.

| Fält | Typ | Betydelse | Källa |
| ---- | --- | --------- | ----- |
| `_id` | ObjectId | Sätts av drivrutinen vid infogning. | `StateManager.mjs:144` |
| `userId` | ObjectId | Overleaf-användaren vars Dropbox har mappen. | `StateManager.mjs:145` |
| `projectId` | ObjectId | Projektet som synkas till mappen. | `StateManager.mjs:146` |
| `dropboxId` | String | Mappens `id` i Dropbox-mappens metadata. | `StateManager.mjs:147`, `JobProcessor.mjs:82-87`, `PullManager.mjs:138` |
| `pathLower` | String | Mappens sökväg i Dropbox, i gemener och utan avslutande snedstreck. Projektmappar ligger på översta nivån, en per projekt, till exempel `/thesis (1)` när Dropbox numrerade den bredvid ett annat projekts `Thesis`. | `StateManager.mjs:14-16,148`, `PullManager.mjs:112-117` |

#### Index {#indexes}

| Namn | Nycklar | Alternativ | Migrering |
| ---- | ------- | ---------- | --------- |
| `_id_` | `_id: 1` | | default |

CE har inget annat index här. De unika indexen `projectId_userId_1` och `userId_dropboxId_1` kommer från `tools/migrations/20220815105500_create_dropboxProjects_index.mjs` och `20220817120900_create_dropboxProjects_index.mjs`, som bara har taggen `saas`, så CE kör dem aldrig.

#### Anteckningar {#notes}

* Unikheten kommer enbart från borttagningen före varje infogning i `setProjectFolder` (`StateManager.mjs:140-149`). Kommentaren i `StateManager.mjs:3-11` nämner unika index; CE har dem inte.
* När ett projekts koppling tas bort ligger mappen kvar i Dropbox. En redigering där läses då som ett nytt projekt, som för en mapp skapad i Dropbox (`DropboxHandler.mjs:148-149`).
* Ett borttaget projekt behåller sin koppling tills det löper ut, eftersom det fortfarande kan återställas (`index.mjs:52-53`).
* Användarens Dropbox-markör `list_folder` finns inte här. Den är `users.dropbox.cursor` (`StateManager.mjs:177-184`).
