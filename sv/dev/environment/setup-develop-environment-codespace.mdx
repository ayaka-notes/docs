För att spara tid och snabbt bygga utvecklingsmiljön erbjuder vi en alternativ konfiguration av utvecklingsmiljön, nämligen GitHub Codespace.

## Konfigurationsguide

<Steps>
<Step title="Skapa Codespaces">
Klicka på följande knapp för att skapa en codespace i molnet för utveckling av server-pro.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/ayakaleaf-pro)

Vi rekommenderar att du väljer en **Machine Type** med minst **4-core**. Om du behöver en större maskintyp kan du skicka en begäran till GitHubs officiella supportteam genom att skapa ett ärende [här](https://support.github.com/contact?tags=rr-codespaces%2Ccat_codespaces).

<Frame>
  <img src="/images/dev/image.png" alt="" />
</Frame>
</Step>

<Step title="Kör installationsskriptet">
Du behöver vänta tålmodigt medan din codespace skapas. När du har tillgång till terminalen kör du följande kommando:

```text
cd develop/
bin/setup
```

<Frame>
  <img src="/images/dev/image-1.png" alt="" />
</Frame>

<Warning>

Det här skriptet (`bin/setup`) låter dig konfigurera utvecklingsmiljön på den senaste committen i grenen `server-pro` på kortast möjliga tid. Det fungerar inte nödvändigtvis för äldre versioner eller andra grenar.

Vi bygger en Docker-avbild för utveckling varje dag med [GitHub Action](https://github.com/ayaka-notes/ayakaleaf-pro/actions).

</Warning>
</Step>

<Step title="Öppna din Launchpad">
Byt till fliken för portar så ser du en lista över tillgängliga webbportar. Klicka på den med `80`. Nu bör du se launchpad-sidan.

<Frame>
  <img src="/images/dev/image-2.png" alt="" />
</Frame>

Du kommer att se:

<Frame>
  <img src="/images/dev/image-3.png" alt="" />
</Frame>
</Step>

<Step title="Lycka till med utvecklingen">
Nu är det din tur! Börja bygga din fantastiska funktion. Du behöver köra följande kommando för att aktivera visning i realtid:

```bash title="bash" wrap
docker compose -f docker-compose.yml -f docker-compose.dev.yml -f ./docker-compose.image.yml up --no-deps --detach
```
</Step>
</Steps>
