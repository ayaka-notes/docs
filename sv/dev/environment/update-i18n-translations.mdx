---
title: Uppdatera i18n-översättningar
icon: language
---

Det finns en fil i `services/web/frontend/extracted-translations.json`, och Overleafs webbtjänst använder endast de extraherade översättningarna i den här filen.

Kör följande kommando för att uppdatera de extraherade översättningarna om du har lagt till innehåll.

```bash
user ➜ ~/overleaf-pro/develop (server-pro) $ bin/shell webpack
root@432836260f8a:/overleaf/services/web# npm run extract-translations
```

Redigera i allmänhet inte översättningarnas textfiler, utan använd i första hand befintliga översättningar, eftersom alla dessa filer uppdateras från Overleaf uppströms eller från en extern översättningstjänst.
