<Warning>

**Uppdaterad 3 oktober 2026:** Version 6.3.0 har återutgivits för att åtgärda problem med AI-assistenten samt Zotero- och Mendeley-integrationerna. Hämta den senaste `6.3.0`-avbildningen när du uppgraderar. Befintliga installationer med länkade bibliografifiler från Zotero eller Mendeley måste också följa [migreringsanvisningarna](/sv/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention"). Nya installationer behöver inte denna migrering.

</Warning>

Vi är mycket stolta över att presentera Overleaf Pro 6.3.0, den mest kraftfulla och funktionsrika LaTeX-redigeraren online i communityn. Eftersom vi alltid har fokuserat på att förbättra våra användares upplevelse innehåller den här versionen stora förändringar och fantastiska funktioner som du garanterat kommer att älska, bland annat en AI-assistent och integration med tredjepartstjänster för referenser.

### Ändringar

* AI-chattassistent: Chatta med en AI-modell via din egen leverantör, direkt i redigeraren.
* LaTeX-felassistent: Få AI-föreslagna lösningar på kompileringsfel i LaTeX.
* Mendeley-integration: Importera referenser från Mendeley på samma sätt som från Zotero.
* Open in Overleaf API: Lade till ett API för att öppna innehåll i Overleaf.
* Mallgalleri: Lade till sidindelning, sökning och sortering på serversidan, så att stora gallerier inte längre behöver läsa in alla mallar i webbläsaren.
* Översättningar: Uppdaterade översättningspatchar för 6.3.0, inklusive ny gränssnittstext för alla språk som stöds.
* Overleaf 6.3.0 uppströms: Inkluderar filredigering i flikar, separata logotyper i sidhuvudet för ljust och mörkt tema samt uppdateringar av beroenden och basavbildning.
* Lade till `OVERLEAF_HEADER_IMAGE_URL_LIGHT` och `OVERLEAF_HEADER_IMAGE_URL_DARK` för stöd för separata logotypbilder i sidhuvudet för ljust och mörkt tema.
* Filer kan nu öppnas i olika flikar i redigeraren.
* Hämtning av externa URL:er och Open in Overleaf API stöder nu HTTP(S)-proxyer via `OVERLEAF_LINKED_URL_OUTBOUND_PROXY`. Se [Utgående proxy](/sv/on-premises/configuration/overleaf-toolkit/external-url#outbound-proxy  "mention") för konfiguration.

#### Funktion 01: AI-assistenten är nu tillgänglig

AI-assistenten finns i redigerarens sidopanel och kommunicerar med den modelleverantör du konfigurerar. Fråga den sådant du skulle fråga en kollega: stram upp det här stycket, vad gör det här makrot, varför blir min tabell inte rak. Den svarar inte i blindo. Den kan läsa och söka i filerna i ditt projekt, kontrollera LaTeX-diagnostiken, kompilera projektet och till och med titta på de renderade PDF-sidorna, så dess svar utgår från ditt faktiska dokument.

När den vill ändra något visar den först en diff. Ingenting skrivs förrän du godkänner det, så artikeln förblir din.

<img src="https://github.com/user-attachments/assets/ea4e0dad-3561-4726-b380-5d9dcfe29693" alt="Demo av AI-chatt och felassistent" width="787" />

LaTeX-felassistenten är till för det välbekanta ögonblicket sent på kvällen: ett rött fel i loggen och ingen aning om vad det betyder. Klicka på Suggest fix bredvid felet, så läser assistenten filen som orsakade det och föreslår den minsta ändring som bör åtgärda det, utan att röra resten av din formatering. Om det ser rätt ut kan du tillämpa ändringen med ett klick och kompilera igen. När en åtgärd påverkar paket, kommandon eller dokumentstruktur bör du ta en snabb titt först.

<img src="https://github.com/user-attachments/assets/91b2aefb-c1e4-4e4a-a94d-9824865cdf29" alt="Användningsexempel för felassistenten" width="787" />

AI-funktionerna är avstängda som standard. Ayakaleaf Pro fungerar med alla OpenAI-kompatibla slutpunkter, oavsett om det är OpenAI självt, ditt företags gateway eller en modell du själv hostar.

Se [AI Integration](/sv/on-premises/configuration/overleaf-toolkit/ai-integration  "mention") för konfiguration av leverantörer, behörigheter, kvoter och valfria söktjänster.

#### Funktion 02: Open in Overleaf API

Om du driver en kurssida, ett mallbibliotek eller en dokumentationswebbplats kan du nu ge läsarna en knapp som tar dem direkt till ett fungerande projekt. Funktionen är aktiverad som standard. Besök `your.overleaf.com/devs` för fullständig referens och liveexempel.

<Frame>
  <img src="/images/blog/img-2fac54e7.png" alt="" />
</Frame>

Det enda som krävs är en länk eller ett litet formulär. Du kan skicka ett LaTeX-utdrag (`snip` eller `encoded_snip`), och ett fristående fragment omsluts automatiskt av ett minimalt dokument. Du kan peka på en eller flera fjärrfiler med `snip_uri` (upp till 50 åt gången), eller lämna över ett helt projekt som ZIP med `zip_uri`. Valfria parametrar anger kompilatorn (`engine`), huvuddokumentet (`main_document`) och projektnamnet (`name`). Innehållet öppnas som ett nytt projekt i din instans, redo att redigeras och kompileras. Om besökaren inte är inloggad ännu loggar hen in först och hamnar ändå i sitt nya projekt.

```html wrap
<a href="https://your.overleaf.com/docs?snip_uri=https://example.com/paper.tex&engine=xelatex">
  Open in Overleaf
</a>
```

#### Funktion 03: Mendeley-integration

I 6.2 lade vi till Zotero, och Mendeley-användare har sedan dess bett om samma sak. Länka ditt Mendeley-konto, välj ett bibliotek eller en grupp, så importeras dina referenser som en `.bib`-fil som du kan uppdatera när ditt bibliotek ändras. Precis som på overleaf.com kan endast den person som importerade filen uppdatera den i ett delat projekt.

För administratörer: lägg till `mendeley` i `ENABLED_LINKED_FILE_TYPES` och ange `MENDELEY_CLIENT_ID` och `MENDELEY_CLIENT_SECRET` från din Mendeley-utvecklarapp.

Se [Mendeley Integration](/sv/on-premises/configuration/overleaf-toolkit/mendeley-integration  "mention") för fullständiga installationsanvisningar.

#### Funktion 04: Sidindelning av mallar

Galleriet brukade läsa in alla mallar i webbläsaren och sortera dem där. Det fungerade för femtio mallar men var plågsamt för femtusen. Nu sker sidindelning, sökning och sortering i MongoDB, och webbläsaren tar bara emot den sida du tittar på.

Det fungerar utan några förberedelser. Om ditt galleri har tusentals mallar håller dessa index det snabbt. Skriptet kan köras flera gånger utan risk; ersätt `mongo` och `sharelatex` med namnen på din container och databas:

```bash
docker exec mongo mongosh sharelatex --quiet --eval '
db.templates.createIndex({category:1,lastUpdated:-1},{name:"category_1_lastUpdated_-1",background:true});
db.templates.createIndex({lastUpdated:-1},{name:"lastUpdated_-1",background:true});
db.templates.createIndex({category:1,name:1},{name:"category_1_name_1_ci",collation:{locale:"en",strength:2},background:true});
db.templates.createIndex({name:1},{name:"name_1_ci",collation:{locale:"en",strength:2},background:true});
'
```

Behåll `collation` på de två `*_ci`-indexen som det står — galleriet ställer frågor med samma collation och MongoDB använder bara ett matchande index.

#### Övrigt

För import av externa filer kan du konfigurera `OVERLEAF_LINKED_URL_OUTBOUND_PROXY` för att använda en HTTP(S)-proxy, även en lokalt hostad proxy. Inställningen gäller både länkade URL-filer och fjärranslutna ZIP- eller TeX-resurser som importeras via Open in Overleaf API. Se [Extern URL — Utgående proxy](/sv/on-premises/configuration/overleaf-toolkit/external-url#outbound-proxy  "mention") för konfiguration och begränsningar av nätverksåtkomst.

* Lade till `OVERLEAF_HEADER_IMAGE_URL_LIGHT` och `OVERLEAF_HEADER_IMAGE_URL_DARK` för stöd för separata logotypbilder i sidhuvudet för ljust och mörkt tema.
* Filer kan nu öppnas i olika flikar i redigeraren.
