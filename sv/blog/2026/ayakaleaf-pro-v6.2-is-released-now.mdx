Vi är stolta över att presentera Ayakaleaf Pro 6.2, den mest kraftfulla och funktionsrika LaTeX-redigeraren online i communityn. Ett särskilt tack till yu-i-i och davrot för deras värdefulla bidrag. De förbättrade GitHub Sync och introducerade avancerad referenssökning samt Zotero-integration.

### Anmärkningar

* En ny obligatorisk miljövariabel `OVERLEAF_INVITE_TOKEN_SECRET` har införts. Du måste generera den med: `openssl rand -base64 32` Om den inte är konfigurerad kommer din Overleaf-instans inte att starta.
* Om du aktiverar GitHub Sync måste du konfigurera miljövariabeln `GITHUB_TOKEN_CIPHER_PASSWORD`. Variabeln krävs för att kryptera GitHub-åtkomsttokens på ett säkert sätt. Utan den kommer din Overleaf-instans inte att starta.
* En ny miljövariabel `DEFAULT_LATEX_COMPILER` har lagts till för att ange standardkompilatorn för nya projekt (pdflatex, latex, xelatex eller lualatex).
* Den omdesignade redigeraren är nu det enda tillgängliga alternativet.

### Ändringar

Den här versionen innehåller följande förbättringar och nya funktioner.

* `MAX_UPLOAD_SIZE` kan nu konfigureras i stället för att vara begränsad till **50 MB**.
* Åtgärdade en omstartsloop för containern när sandboxed compiles var inaktiverat.
* Införde ägarbegränsad borttagning av PAT för OAuth2.
* Åtgärdade ett problem med LDAP-import.

Nya funktioner:

* Lade till en webbläsarbaserad Python-körare.
* Lade till Pandoc-stöd för import och export av Markdown, DOCX och andra format.
* Lade till GitHub Sync.
* Lade till fullständiga kinesiska översättningar.
* Lade till Zotero-integration.
* Lade till `DEFAULT_LATEX_COMPILER`.

#### Funktion 01: GitHub Sync

Håll dina LaTeX-projekt synkroniserade med GitHub-repositorier för ett smidigt utvecklingsarbetsflöde. Pusha och pulla ändringar direkt från redigeraren, samarbeta via pull requests och integrera med befintliga CI/CD-pipelines. Versionshantering gör det enkelt att spåra revisioner, granska ändringar och underhålla reproducerbara akademiska eller tekniska dokument.

Se: [GitHub Synchronisation](/sv/on-premises/configuration/overleaf-toolkit/github-synchronisation  "mention").

#### Funktion 02: Pandoc-import/export

Importera Microsoft Word- och Markdown-dokument till fullt redigerbara LaTeX-projekt, eller exportera LaTeX-projekt tillbaka till Markdown och DOCX med ett enda klick. Funktionen drivs av Pandoc och möjliggör smidig samverkan mellan akademiskt skrivande, samarbetsredigering och publiceringsflöden, samtidigt som dokumentstrukturen bevaras så långt det går.

Se: [Pandoc Import and Export](/sv/on-premises/configuration/overleaf-toolkit/pandoc-import-and-export  "mention").

#### Funktion 03: Avancerad referenssökning

Sök och infoga bibliografiska referenser från flera akademiska databaser med intelligent filtrering och omedelbart citeringsstöd. Hitta artiklar snabbt, förhandsgranska metadata och skapa korrekta BibTeX-poster utan att växla mellan olika forskningswebbplatser, vilket avsevärt effektiviserar litteraturgenomgången.

![bild](https://github.com/user-attachments/assets/42e45b73-af4b-4d1f-81f4-9e116ba5d043)

#### Funktion 04: Python Runner

Kör Python-kod direkt i ditt projekt utan att lämna redigeraren. Perfekt för att generera figurer, bearbeta datamängder, automatisera dokumentflöden eller köra reproducerbara forskningsskript. Resultaten kan integreras i dina LaTeX-dokument, vilket gör vetenskapliga beräkningar och skrivande till en del av ett enhetligt arbetsflöde.

![bild](https://github.com/user-attachments/assets/a4c314b3-fdb5-4836-aea7-12eeece5cd2f)

#### Funktion 05: Zotero

Anslut ditt Zotero-bibliotek direkt till ditt skrivflöde och hantera referenser utan att lämna redigeraren. Sök i dina personliga Zotero-samlingar, infoga citeringar med ett enda klick och generera och synkronisera BibTeX-poster automatiskt. Integrationen håller din bibliografi uppdaterad och förenklar litteraturhanteringen för vetenskapliga artiklar, avhandlingar och tekniska dokument.

Se: [Zotero Integration](/sv/on-premises/configuration/overleaf-toolkit/zotero-integration  "mention").
