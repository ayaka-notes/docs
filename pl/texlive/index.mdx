[TeX Live](https://www.tug.org/texlive/) to darmowa dystrybucja oprogramowania wydawana co roku przez [TeX Users Group](https://www.tug.org/). Zawiera pakiety LaTeX, fonty, silniki TeX oraz liczne narzędzia programowe potrzebne do składu tekstu w LaTeX we wszystkich popularnych systemach operacyjnych.

TeX Live jest ważnym elementem Overleaf, ponieważ nasze serwery używają go do kompilowania Twojego kodu LaTeX i generowania podglądu PDF w czasie rzeczywistym. Zapewnia też użytkownikom Overleaf łatwy dostęp do ponad 5000 pakietów LaTeX zawartych w każdym wydaniu TeX Live.

Nie musisz kompilować projektów przy użyciu najnowszej wersji TeX Live, ponieważ serwery Overleaf zapewniają dostęp do wcześniejszych wydań TeX Live. Projekty można łatwo przełączyć na wcześniejszą wersję TeX Live — na przykład z powodu problemów ze zgodnością pakietów.<br />
