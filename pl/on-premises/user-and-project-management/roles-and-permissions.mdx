### Konto

Z perspektywy zarządzania własnym kontem **wszyscy** użytkownicy są traktowani jak zwykli użytkownicy — `Site Admins` i `Template Users` **nie** otrzymują żadnych dodatkowych uprawnień. Istnieją jednak ograniczenia dotyczące działań, jakie mogą wykonywać zwykli użytkownicy, zależne od sposobu uwierzytelniania.

#### Ustawienia

<strong>Typy uwierzytelniania: konta wewnętrzne | SSO (SAML/LDAP)</strong>

| Działanie | Konta wewnętrzne | SSO (SAML/LDAP) |
| ----------------------------------------- | ----------------: | --------------: |
| Aktualizacja informacji o koncie | Tak | Nie |
| Zmiana hasła | Tak | Nie |
| Generowanie tokenów uwierzytelniania Git bridge | Tak | Tak |
| Usuwanie tokenów uwierzytelniania Git bridge | Tak | Tak |
| Zarządzanie sesjami | Tak | Tak |

<Info>

Integracja Git Bridge jest dostępna **wyłącznie** w Server Pro. Więcej informacji znajdziesz w porównaniu [Server Pro vs. Community Edition](/pl/on-premises/readme/ayakaleaf-pro-vs-server-pro).

</Info>

#### Twoje sesje

| -------------------- | ---: |

| Wyświetlanie bieżącej sesji | Tak |
| Wyświetlanie innych sesji | Tak |

### Edytor IDE

Z perspektywy edytora IDE Overleaf możesz mieć jedną z następujących ról: `Project Owner`, `Editor`, `Reviewer`, `Viewer`, `Site Administrator` lub `Template User`.

<Info>

Server Pro i Community Edition obsługują anonimowy dostęp do projektów **tylko do odczytu** oraz **do odczytu i zapisu**.

Więcej informacji na ten temat znajdziesz w opisie zmiennych środowiskowych `OVERLEAF_ALLOW_PUBLIC_ACCESS` i `OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` [tutaj](/pl/on-premises/configuration/overleaf-toolkit/environment-variables).

</Info>
