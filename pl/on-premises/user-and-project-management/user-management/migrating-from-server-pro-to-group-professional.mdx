---
title: Migracja z Server Pro do Group Professional
icon: rectangle-pro
noindex: true
---

Przejście z samodzielnie hostowanej instancji Server Pro na nową, chmurową subskrypcję Overleaf Group Professional to duża zmiana, dlatego aby ten proces przebiegł jak najsprawniej, przygotowaliśmy poniższe wskazówki.

Zasadniczo proponujemy trzymiesięczny okres przejściowy, rozpoczynający się w dniu odnowienia. Oznacza to, że:

* Twoja istniejąca instancja Server Pro i nowa subskrypcja Group Professional będą jednocześnie w pełni aktywne.
* Twój zespół techniczny może zaplanować czas na skonfigurowanie subskrypcji Group Professional i podjąć decyzję o przyszłości lokalnego wdrożenia Server Pro.
* Co najważniejsze, Twoi użytkownicy będą mieli mnóstwo czasu na skopiowanie swoich projektów na nową platformę Overleaf Group Professional.

Ten krótki przewodnik przeprowadzi Cię przez najważniejsze etapy migracji. Zaczynajmy!

<Steps>
<Step title="Faza 1: Instalacja i konfiguracja">
(Link: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-1-setup-and-configuration)

* Overleaf utworzy Twoją subskrypcję Group Professional i doda Twojego głównego administratora (Lead Administrator).
* Administrator grupy będzie mógł włączyć [Managed Users](https://docs.overleaf.com/groups/user-management/managed-user-accounts), skonfigurować [Single Sign-On (SSO)](https://docs.overleaf.com/groups/overleaf-group-single-sign-on/setting-up-group-sso) i [zaprosić użytkowników końcowych](https://docs.overleaf.com/groups/user-management/how-to-add-and-remove-users).

<Warning>

Włączenie Managed Users i wdrożenie SSO jest wymaganym krokiem do uzyskania zgodności z FedRAMP® LI-SaaS. Jeśli Twoja organizacja wymaga zgodności z FedRAMP, skonfiguruj Managed Users i SSO przed zaproszeniem użytkowników końcowych.

</Warning>
</Step>

<Step title="Faza 2: Migracja użytkowników i zarządzanie danymi">
(Link: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-2-user-migration-and-data-management)

To główny okres migracji, obejmujący następujące obowiązki:

#### Użytkownicy końcowi

* Użytkownicy powinni przenieść wszystkie projekty, które chcą zachować, z instancji Server Pro na swoje nowe konta na [overleaf.com](http://overleaf.com/). Proces polega na [eksporcie projektów](https://www.overleaf.com/learn/how-to/Exporting_your_work_from_Overleaf) z Server Pro i [przesłaniu ich](https://www.overleaf.com/learn/how-to/Uploading_a_project) na swoje konto na [overleaf.com](http://overleaf.com/). Jeśli użytkownik nie ma jeszcze konta na [overleaf.com](http://overleaf.com/), może zarejestrować się na [overleaf.com/register](http://overleaf.com/register).

<Warning>

W ramach tej procedury eksportu przenoszony jest wyłącznie kod źródłowy projektu (pliki LaTeX i pliki binarne). Istniejące ustawienia projektu, ustawienia udostępniania, komentarze, śledzone zmiany itp. NIE zostaną przeniesione. Po migracji użytkownicy będą musieli ponownie zaprosić swoich współpracowników.

</Warning>

#### Personel techniczny

* W tej fazie zespół techniczny powinien zaplanować, co po migracji stanie się z lokalną instancją Server Pro i jej danymi.
* **Kopia zapasowa danych:** Przed wycofaniem instancji możesz wyeksportować wszystkie projekty, aby utworzyć archiwum, które pozwoli pomóc użytkownikom, którzy zapomnieli przenieść lub pobrać swoją pracę. Instrukcje: https://docs.overleaf.com/on-premises/maintenance/data-and-backups/exporting-projects
* **Wycofanie Server Pro:** Po zamknięciu okresu migracji i dezaktywacji klucza licencyjnego masz dwie główne opcje dotyczące samej instancji Server Pro (patrz następny krok).
</Step>

<Step title="Opcje wycofania Server Pro">
<Steps>
<Step title="Całkowite odinstalowanie Server Pro">
Odinstalowanie wycofuje Server Pro z użycia i całkowicie usuwa oprogramowanie.
</Step>

<Step title="Przejście na Community Edition">
Przejście zachowuje bazę danych użytkowników i projektów wraz z pełną historią projektów dzięki przekształceniu instancji z Server Pro w Community Edition.
</Step>
</Steps>

<Info>

Community Edition NIE zawiera [Sandboxed Compiles](https://docs.overleaf.com/on-premises#overview-of-server-pro-and-community-edition) ani [LDAP](/pl/on-premises/configuration/overleaf-toolkit/authentication/ldap-authentication)/[SAML](/pl/on-premises/configuration/overleaf-toolkit/authentication/saml-authentication). Jeśli musisz wrócić do natywnego uwierzytelniania (nazwa użytkownika/hasło), zobacz: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-to-ldap-or-saml#going-the-other-way-switching-from-ldap-saml-back-to-native-authentication

Porównanie Server CE i Server Pro znajdziesz tutaj: https://docs.overleaf.com/on-premises/welcome/server-pro-vs.-community-edition

</Info>
</Step>

<Step title="Faza 3: Wycofanie Server Pro">
(Link: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-3-server-pro-decommission)

* Zespół Overleaf formalnie dezaktywuje Twój klucz licencyjny Server Pro i po zakończeniu wyśle potwierdzenie.
* Wtedy wykonaj jedną z opisanych powyżej czynności wycofania: całkowicie odinstaluj Server Pro lub przejdź na Community Edition.
</Step>
</Steps>

Dodatkowe zasoby i linki, o których mowa powyżej, pozostają bez zmian.
