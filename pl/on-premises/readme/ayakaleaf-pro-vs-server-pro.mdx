<Info>

Ayakaleaf Pro to rozszerzona implementacja Overleaf Community Edition, oferująca wszystkie funkcje premium z Server Pro _**za darmo**_. W przeciwieństwie do Overleaf Common dostępnego pod adresem [https://www.overleaf.com/](https://www.overleaf.com/) nie mamy ograniczeń czasu kompilacji ani wymagań licencyjnych co do liczby użytkowników, a swoje dane możesz w pełni hostować samodzielnie, zapewniając absolutne bezpieczeństwo.

Overleaf Server Pro to komercyjne, samodzielnie hostowane wdrożenie Overleaf z oficjalnym wsparciem. Więcej informacji o Server Pro znajdziesz na stronie [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud).

</Info>

<Warning>

Overleaf Community Edition jest przeznaczony do użytku w środowiskach, w których **wszyscy** użytkownicy są zaufani. Community Edition **nie** nadaje się do scenariuszy wymagających izolacji użytkowników, ponieważ Sandbox Compiles nie są w nim dostępne.

Bez piaskownicy kompilacje LaTeX działają z tymi samymi uprawnieniami co kontener, co daje dostęp do jego systemu plików, sieci i zmiennych środowiskowych. Stwarza to ryzyko ujawnienia danych lub przejęcia systemu. Kompilacje bez piaskownicy powinny być używane wyłącznie w w pełni zaufanych środowiskach; w przypadku wdrożeń wieloużytkownikowych lub produkcyjnych zdecydowanie zaleca się Sandbox Compiles.

Więcej informacji o Sandbox Compiles znajdziesz w naszej [dokumentacji](/pl/on-premises/configuration/overleaf-toolkit/sandboxed-compiles).

</Warning>

### Wsparcie społeczności

Osobom korzystającym z samodzielnie hostowanej instancji Overleaf wsparcia udziela społeczność za pośrednictwem [Issues](https://github.com/ayaka-notes/overleaf-pro/issues) na GitHub.

Aby pozostać na wspieranej ścieżce, możesz sprawdzić, jaką wersję Overleaf uruchamiasz, porównując wynik poniższego polecenia z identyfikatorami obrazów (Image ID) opublikowanymi w informacjach o wydaniach.

```bash
docker inspect --format '{{.Image}}' sharelatex | awk -F: '{print substr($2, 1, 12)}'
```
