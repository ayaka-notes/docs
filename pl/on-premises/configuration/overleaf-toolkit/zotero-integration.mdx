### Konfiguracja integracji z Zotero

1. Otwórz [ten link](https://www.zotero.org/oauth/apps), aby utworzyć klienta OAuth Zotero (jak pokazano na obrazku)
2. Wybierz **Application Type**: **Browser**
3. Ustaw Callback URL na `${OVERLEAF_SITE_URL}/user/zotero/oauth/callback`
4. Skonfiguruj plik `config/variables.env`

<Frame>
  <img src="/images/on-premises/image-41.png" alt="" width="375" />
</Frame>

```dotenv title="config/variables.env"
#################
#    Zotero     #
#################
# 'zotero' must be in ENABLED_LINKED_FILE_TYPES (set in develop/docker-compose.yml)
ENABLED_LINKED_FILE_TYPES=project_file,project_output_file,url,zotero

# From a Zotero OAuth client (register at https://www.zotero.org/oauth/apps)
# Application Type: Browser 
# Callback URL -> ${OVERLEAF_SITE_URL}/user/zotero/oauth/callback
ZOTERO_CLIENT_ID=
ZOTERO_CLIENT_SECRET=
# Encrypts the Zotero API key in mongo (set in dev to avoid writing a key file
# to /var/lib/overleaf/data, which the dev web container can't create)
# How to generate: `openssl rand -hex 32`
ZOTERO_CIPHER_PASSWORD=dev-zotero-cipher-password
# Optional: route the module's server-side Zotero requests (OAuth + API) through
# an HTTP proxy (must be reachable from the web container; same as github-sync)
# http://10.0.0.1:10808
# (Optional) ZOTERO_PROXY_URL=
```

### Uwagi

<Warning>

Przy aktualizacji istniejącej instalacji z powiązanymi plikami bibliografii Zotero do ponownie wydanej wersji 6.3.0 postępuj zgodnie z [instrukcjami migracji Zotero / Mendeley](/pl/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention"). Nowe instalacje nie wymagają tej migracji.

</Warning>

<Danger>

Ponieważ Ayakaleaf jest platformą do współpracy, w celu zwiększenia bezpieczeństwa od wersji 6.3.0 tylko pierwotny twórca pliku bibliografii `bib` może aktualizować zaimportowany plik.

</Danger>

Załóżmy na przykład, że właściciel projektu, Użytkownik A, włącza udostępnianie przez link i tworzy w projekcie plik `test.bib` powiązany z własnym kontem Zotero. Jeśli inny użytkownik, Użytkownik B, uzyska dostęp do projektu przez udostępniony link, nadal będzie mógł odczytać i pobrać `test.bib`, ale nie będzie mógł zaktualizować ani ponownie zaimportować pliku z Zotero. Tylko Użytkownik A, jako pierwotny twórca pliku bibliografii, może wykonywać aktualizacje. Innymi słowy, uprawnienia do aktualizacji pliku `.bib` ma wyłącznie jego pierwotny twórca.
