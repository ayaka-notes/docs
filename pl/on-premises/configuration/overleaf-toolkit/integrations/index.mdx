Każda integracja jest domyślnie wyłączona, z wyjątkiem Overleaf Import API. Synchronizacja z GitHub, GitLab, Gitea i Dropbox oraz serwer MCP wymagają również [integracji z Git](/pl/on-premises/configuration/overleaf-toolkit/integrations/git-integration). Po włączeniu integracji odtwórz kontenery za pomocą `bin/up -d`.
