Każdy projekt ma serwer MCP, dzięki czemu klienci AI, tacy jak Claude Code, Codex, Cursor, VS Code czy Gemini CLI, mogą nad nim pracować: odczytywać i edytować jego pliki, kompilować go, odczytywać log LaTeX, pobierać plik PDF i odpowiadać na komentarze.

<Info>

Ta funkcja została opracowana przez [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro). Jest dostępna od wersji v6.3.1.

</Info>

### Konfiguracja

Serwer MCP jest dostępny razem z integracją z Git: włącz [git-bridge](/pl/on-premises/configuration/overleaf-toolkit/git-integration), a serwer MCP również stanie się dostępny. Nie trzeba niczego więcej konfigurować.

### Łączenie klienta AI

1. W **Account Settings** wygeneruj token uwierzytelniania Git. Ten sam token służy do serwera MCP i do Git.
2. W edytorze otwórz **Integrations** i kliknij **MCP server**. Zostanie wyświetlony adres serwera MCP projektu, `https://<your-overleaf>/project/<project_id>/mcp`, oraz sposób dodania go do każdego klienta AI: skopiuj polecenie i zastąp `<token>` swoim tokenem.

### Użycie

Po połączeniu poproś klienta AI o wykonanie zadania zwykłymi słowami. Na przykład:

| Prosisz o | Klient AI używa |
| --- | --- |
| _Popraw literówki we wstępie._ | `read_file`, `edit_file`: zmiany są widoczne na bieżąco w edytorze |
| _Skompiluj projekt i popraw błędy LaTeX._ | `compile`, `get_compile_log`, `edit_file` |
| _Odpowiedz na otwarte komentarze, a następnie je rozwiąż._ | `list_comments`, `reply_to_comment`, `resolve_comment` |
| _Przełącz na XeLaTeX i pobierz plik PDF._ | `update_settings`, `compile`, `get_output_file_link` |

### Narzędzia

| Grupa | Narzędzia |
| --- | --- |
| Projekt | `get_clone_info`, `get_settings`, `update_settings`, `list_versions` |
| Pliki | `list_files`, `read_file`, `edit_file`, `write_file`, `delete_file` |
| Kompilacja | `compile`, `get_compile_log`, `get_output_file_link`, `word_count` |
| Komentarze | `list_comments`, `reply_to_comment`, `resolve_comment`, `reopen_comment` |

Zmiany wprowadzone za pomocą `edit_file` i `write_file` są widoczne na bieżąco w edytorze i scalane ze zmianami współpracowników. W przypadku wielu plików naraz, plików binarnych lub zmian nazw klient AI może również sklonować projekt za pomocą Git i wypchnąć zmiany.

### Uprawnienia

Serwer MCP przestrzega ustawień udostępniania projektu, podobnie jak Git:

* Każdy, kto może wyświetlić projekt, może go odczytywać, kompilować i pobierać jego wyniki.
* Tylko właściciel i edytorzy mogą zmieniać jego pliki i ustawienia.
* Recenzenci mogą również odpowiadać na komentarze oraz rozwiązywać lub ponownie otwierać komentarze, które sami rozpoczęli.
* Osoby z dostępem tylko do odczytu, które dołączyły przez link, nie widzą komentarzy, tak jak w edytorze.

### Pytania i odpowiedzi

<Accordion title="Nie widzę Integrations ani serwera MCP w edytorze">

<strong>Odpowiedź:</strong> Serwer MCP nie ma własnej zmiennej środowiskowej. Włącza się go za pomocą `GIT_BRIDGE_ENABLED=true` w `config/overleaf.rc`, zobacz [Integracja z Git](/pl/on-premises/configuration/overleaf-toolkit/git-integration). Po zmianie uruchom `bin/up -d`. Bez git-bridge edytor nie wyświetla karty **Integrations** na lewym pasku.

</Accordion>
