<Info>

Ta funkcja jest dostarczana przez [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) z obsługą OAuth 2.0 i jest dostępna od wersji v6.3.0. Jeśli napotkasz jakiekolwiek problemy, chętnie poznamy Twoją opinię.

</Info>

#### Konfiguracja integracji z Mendeley

1. Przejdź pod [ten link](https://dev.mendeley.com/myapps.html), aby zarejestrować aplikację OAuth Mendeley
2. Ustaw **Redirect URL** na: `${OVERLEAF_SITE_URL}/user/mendeley/oauth/callback`
3. Zanotuj wygenerowany **ID** (zwykle liczbowy, np. `24061` jak poniżej) oraz **Secret** swojej aplikacji
4. Zmodyfikuj plik `config/variables.env`&#x20;
5. Pozostaw Authorisation Flow: Elsevier (zgodnie z zaleceniem)

```dotenv title="config/variables.env"
#################
#   Mendeley    #
#################
# 'mendeley' must be in ENABLED_LINKED_FILE_TYPES (keep 'zotero' too if you use both)
ENABLED_LINKED_FILE_TYPES=project_file,project_output_file,url,mendeley

# From a Mendeley OAuth application (register at https://dev.mendeley.com/myapps.html)
# Redirect URL -> ${OVERLEAF_SITE_URL}/user/mendeley/oauth/callback
MENDELEY_CLIENT_ID=
MENDELEY_CLIENT_SECRET=
# Encrypts the Mendeley OAuth tokens in mongo; if unset, a key file is generated
# in /var/lib/overleaf/data on first use
# How to generate: `openssl rand -hex 32`
MENDELEY_CIPHER_PASSWORD=
# Optional: route the module's server-side Mendeley requests (OAuth + API) through
# an HTTP proxy (must be reachable from the web container; same as github-sync)
# http://10.0.0.1:10808
# (Optional) MENDELEY_PROXY_URL=
```

<Info>

&#x20;`mendeley` musi być uwzględniony w `ENABLED_LINKED_FILE_TYPES` (pozostaw na liście także `zotero`, jeśli korzystasz z obu). `MENDELEY_CLIENT_ID` i `MENDELEY_CLIENT_SECRET` pochodzą z zarejestrowanej aplikacji OAuth. Hasło szyfrujące (cipher password) szyfruje tokeny OAuth Mendeley w MongoDB (wygeneruj je poleceniem `openssl rand -hex 32`); bez niego przy pierwszym użyciu w wolumenie danych zostanie wygenerowany plik klucza. Opcjonalnie ustaw `MENDELEY_PROXY_URL`, aby kierować żądania Mendeley po stronie serwera (OAuth + API) przez serwer proxy HTTP dostępny z kontenera web.

</Info>

### Uwagi

<Warning>

Podczas aktualizacji istniejącej instalacji z plikami bibliografii powiązanymi z Mendeley do ponownie wydanej wersji 6.3.0 postępuj zgodnie z [instrukcjami migracji Zotero / Mendeley](/pl/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention"). Nowe instalacje nie wymagają tej migracji.

</Warning>

<Danger>

Ponieważ Ayakaleaf jest platformą do współpracy, w celu zwiększenia bezpieczeństwa od wersji 6.3.0 tylko pierwotny twórca pliku bibliografii `bib` może aktualizować zaimportowany plik.

</Danger>

Załóżmy na przykład, że właściciel projektu, Użytkownik A, włącza udostępnianie przez link i tworzy w projekcie plik `test.bib`, łącząc go z własnym kontem Zotero. Jeśli inny użytkownik, Użytkownik B, uzyska dostęp do projektu przez udostępniony link, nadal będzie mógł odczytać i pobrać `test.bib`, ale nie będzie mógł zaktualizować ani ponownie zaimportować pliku z Zotero. Aktualizacje może wykonywać tylko Użytkownik A jako pierwotny twórca pliku bibliografii. Innymi słowy, uprawnienia do aktualizacji pliku `.bib` ma wyłącznie jego pierwotny twórca.
