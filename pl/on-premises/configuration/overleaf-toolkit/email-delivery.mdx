Overleaf obsługuje wysyłanie wiadomości e-mail na dwa sposoby: za pomocą protokołu Simple Mail Transfer Protocol (SMTP) oraz [Amazon Simple Email Service (SES)](https://aws.amazon.com/ses/). SMTP można używać, jeśli na hoście lokalnym działa serwer pocztowy nasłuchujący połączeń lokalnych.

## Kilka adresów e-mail na konto {#several-emails-per-account}

<Info>

Ta funkcja została opracowana przez [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) i jest dostępna od wersji v6.4.0.

</Info>

Gdy poczta jest skonfigurowana, strona ustawień zamiast pojedynczego pola e-mail wyświetla listę adresów e-mail konta. Użytkownicy dodają adres e-mail, wpisując 6-cyfrowy kod wysłany na ten adres, i klikają **Make primary**, aby przenieść na niego konto. W ten sposób można zachować konto, gdy adres zostanie odebrany, na przykład uczelniany po ukończeniu studiów. [Przewodnik użytkownika](/pl/on-premises/user-guide/users/multiple-emails) zawiera kroki ze zrzutami ekranu.

* Tylko główny adres e-mail umożliwia logowanie i otrzymuje resetowanie hasła. Dodatkowy adres e-mail nie robi żadnej z tych rzeczy, więc adres przydzielony ponownie komuś innemu nie może przejąć konta.
* Kliknij **Make primary**, zanim stara skrzynka zostanie zamknięta. Potem adres e-mail musi zmienić administrator w **Admin → Manage Users**.
* Stary główny adres e-mail, który nigdy nie został potwierdzony, jest usuwany, gdy inny adres staje się główny. Potwierdzony pozostaje jako dodatkowy adres e-mail, dopóki użytkownik go nie usunie.
* **Make primary** jest odrzucane, gdy włączono LDAP lub SAML, ponieważ te konta nie mogłyby zalogować się nowym adresem e-mail. Zobacz [Konta i hasła](/pl/on-premises/configuration/overleaf-toolkit/authentication#accounts-and-passwords).
* Bez ustawień poczty pozostaje pojedyncze pole e-mail.

## Konfiguracja {#configuration}

Poczta e-mail jest konfigurowana za pomocą poniższych zmiennych środowiskowych.

#### Konfiguracja nadawcy {#sender-configuration}

| Nazwa                         | Opis                                                                                                                                                 |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | <p>Adres nadawcy, np. <a href="mailto:support@mycompany.com">`'support@mycompany.com'`</a><br /><br />- <strong>Wymagane</strong>: tak</p> |
| `OVERLEAF_EMAIL_REPLY_TO`     | Adres do odpowiedzi, np. `'noreply@mycompany.com'`                                                                                                   |

#### SMTP {#smtp}

| Nazwa                                   | Opis                                                                                                                                                                                                                                                                     |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST`              | Nazwa hosta lub adres IP, z którym należy się połączyć. Musi być dostępny z kontenera Docker                                                                                                                                                                            |
| `OVERLEAF_EMAIL_SMTP_PORT`              | Port, z którym należy się połączyć                                                                                                                                                                                                                                       |
| `OVERLEAF_EMAIL_SMTP_SECURE`            | Jeśli `true`, połączenie z serwerem będzie używać TLS. Jeśli `false` lub nieustawione, TLS jest używany, gdy serwer obsługuje rozszerzenie `STARTTLS`. W większości przypadków ustaw `true`, jeśli łączysz się z portem `465`. Dla portów `587` lub `25` pozostaw `false` |
| `OVERLEAF_EMAIL_SMTP_USER`              | Nazwa użytkownika używana do uwierzytelniania na serwerze SMTP                                                                                                                                                                                                           |
| `OVERLEAF_EMAIL_SMTP_PASS`              | Hasło powiązane z nazwą użytkownika SMTP                                                                                                                                                                                                                                 |
| `OVERLEAF_EMAIL_SMTP_TLS_REJECT_UNAUTH` | Jeśli `false`, umożliwia nawiązanie połączenia z serwerem TLS z certyfikatem samopodpisanym lub nieprawidłowym                                                                                                                                                           |
| `OVERLEAF_EMAIL_SMTP_IGNORE_TLS`        | Gdy `true`, a `OVERLEAF_EMAIL_SMTP_SECURE` ma wartość `false`, TLS nie jest używany, nawet jeśli serwer obsługuje rozszerzenie `STARTTLS`                                                                                                                               |
| `OVERLEAF_EMAIL_SMTP_NAME`              | Opcjonalna nazwa hosta do walidacji TLS, jeśli `OVERLEAF_EMAIL_SMTP_HOST` ustawiono na adres IP; domyślnie nazwa hosta maszyny.                                                                                                                                         |
| `OVERLEAF_EMAIL_SMTP_LOGGER`            | Gdy `true`, zapisuje komunikaty logowania do `web.log`.                                                                                                                                                                                                                  |

#### Interfejs SMTP Amazon SES {#amazon-ses-smtp-interface}

Więcej o wysyłaniu wiadomości e-mail za pomocą interfejsu SMTP Amazon SES przeczytasz [tutaj](https://docs.aws.amazon.com/ses/latest/dg/send-email-smtp.html).

| Nazwa                      | Opis                                                                                         |
| -------------------------- | -------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_SMTP_HOST` | Nazwa hosta lub adres IP, z którym należy się połączyć. Musi być dostępny z kontenera Docker |
| `OVERLEAF_EMAIL_SMTP_PORT` | Port, z którym należy się połączyć                                                           |
| `OVERLEAF_EMAIL_SMTP_USER` | Nazwa użytkownika używana do uwierzytelniania na serwerze SMTP                               |
| `OVERLEAF_EMAIL_SMTP_PASS` | Hasło powiązane z nazwą użytkownika SMTP                                                     |

#### API Amazon SES {#amazon-ses-api}

Więcej o wysyłaniu wiadomości e-mail za pomocą API Amazon SES przeczytasz [tutaj](https://docs.aws.amazon.com/ses/latest/dg/send-email-api.html).

| Nazwa                                  | Opis                                                   |
| -------------------------------------- | ------------------------------------------------------ |
| `OVERLEAF_EMAIL_AWS_SES_ACCESS_KEY_ID` | Klucz dostępu, jeśli używasz AWS SES                   |
| `OVERLEAF_EMAIL_AWS_SES_SECRET_KEY`    | Klucz tajny, jeśli używasz AWS SES                     |
| `OVERLEAF_EMAIL_AWS_SES_REGION`        | Jeśli nie ustawiono, domyślnym regionem jest US-EAST-1 |

#### AWS SES z rolami instancji {#aws-ses-with-instance-roles}

| Nazwa                   | Opis                                                                                                                                         |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_DRIVER` | Gdy ustawiono wartość `ses`, system poczty użyje metody API SES i będzie polegać na skonfigurowanych rolach instancji przy wysyłaniu e-maili. |

#### Dostosowywanie {#customisation}

| Nazwa                          | Opis                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_CUSTOM_EMAIL_FOOTER` | <p>Niestandardowy kod HTML dołączany do wszystkich wiadomości e-mail, np.<br /><br /><strong>Przykład</strong>: `"<div>This system is run by department x </div> <div> If you have any questions please look at our faq <a href='https://somwhere.com'>here</a></div>"`</p> |
