## Ayakaleaf Pro 6.3.0

**Data wydania:** 2026.10.03 (ponowne wydanie; pierwotnie wydane 2026.09.24)

Zobacz: [https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.3.0](https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.3.0)

<Warning>

Ayakaleaf Pro 6.3.0 zostało pierwotnie wydane 24 września 2026 r. To ponowne wydanie rozwiązuje problemy z asystentem AI oraz integracjami z Zotero i Mendeley spowodowane aktualizacjami w wersji nadrzędnej.

Wcześniej wydana wersja nie uszkadza Twoich danych. Pobierz najnowszy obraz `6.3.0` i zaktualizuj wdrożenie. **Istniejące instalacje z plikami bibliografii połączonymi z Zotero lub Mendeley muszą również uruchomić poniższą migrację.** Nowe instalacje nie wymagają tej migracji.

</Warning>

<Accordion title="Migracja Zotero / Mendeley dla istniejących instalacji">

Podczas aktualizacji do ponownie wydanego obrazu 6.3.0 przeprowadź migrację metadanych istniejących plików bibliografii połączonych z Zotero/Mendeley za pomocą poniższego skryptu. Migracja ta towarzyszy poprawce `12031b8dfd`.

Zmienia ona nazwy `zoteroGroupId` / `mendeleyGroupId` na `group_id`, zmienia nazwę `importedByUserId` na `importer_id` oraz usuwa `importedByName`.

Przed uruchomieniem migracji utwórz kopię zapasową MongoDB i zatrzymaj aplikację. Pozostaw MongoDB uruchomione. Otwórz jego powłokę (zastąp `mongo` nazwą swojego kontenera):

```bash
docker exec -it mongo mongosh
```

Uruchom następujący kod w `mongosh` (zastąp `sharelatex` nazwą swojej bazy danych):

```javascript
use sharelatex

(async () => {
  let updated = 0
  await db.projects.find({}, { rootFolder: 1 }).forEach(async project => {
    const changes = {}
    function visit(folders, path) {
      for (const [i, folder] of (folders || []).entries()) {
        const folderPath = `${path}.${i}`
        for (const [j, file] of (folder.fileRefs || []).entries()) {
          const data = { ...file.linkedFileData }
          if (!["zotero", "mendeley"].includes(data.provider)) continue
          const groupKey = `${data.provider}GroupId`
          if (![groupKey, "importedByUserId", "importedByName"].some(key => key in data)) continue
          for (const [oldKey, newKey] of [[groupKey, "group_id"], ["importedByUserId", "importer_id"]]) {
            if (data[oldKey] != null && data[oldKey] !== "") {
              const value = String(data[oldKey])
              if (newKey in data && data[newKey] !== value) {
                throw new Error(`Conflicting ${newKey}: project ${project._id}, file ${file._id}`)
              }
              data[newKey] = value
            }
            delete data[oldKey]
          }
          delete data.importedByName
          changes[`${folderPath}.fileRefs.${j}.linkedFileData`] = data
        }
        visit(folder.folders, `${folderPath}.folders`)
      }
    }
    visit(project.rootFolder, "rootFolder")
    if (!Object.keys(changes).length) return
    const result = await db.projects.updateOne(
      { _id: project._id, rootFolder: { $eq: project.rootFolder } },
      { $set: changes }
    )
    if (!result.matchedCount) throw new Error(`Project changed during migration: ${project._id}`)
    updated += result.modifiedCount
  })
  print(`Updated ${updated} project(s).`)
})()
```

Skrypt uwzględnia zagnieżdżone foldery i zmienia wyłącznie metadane Zotero/Mendeley. Można go bezpiecznie uruchomić ponownie: po zakończonej migracji kolejne uruchomienie zgłosi `Updated 0 project(s).`. Jeśli skrypt zatrzyma się z powodu konfliktu, sprawdź zgłoszony projekt/plik; wcześniejsze projekty mogły już zostać zmigrowane.

Uruchom zaktualizowaną aplikację, przeładuj edytor i odśwież istniejący plik bibliografii jako jego pierwotny importer. Historyczne migawki nie są przepisywane. Aby wrócić do starej wersji aplikacji, przywróć kopię zapasową MongoDB.

</Accordion>

Z dumą ogłaszamy wydanie Overleaf Pro 6.3.0 — najpotężniejszego i najbogatszego w funkcje edytora LaTeX online w społeczności. Ponieważ zawsze koncentrujemy się na poprawie doświadczeń naszych użytkowników, to wydanie przynosi ogromne zmiany i wspaniałe funkcje, które z pewnością pokochasz, w tym asystenta AI i integrację z zewnętrznymi menedżerami bibliografii.

### Zmiany

* Asystent czatu AI: rozmawiaj z modelem AI za pośrednictwem własnego dostawcy, bezpośrednio w edytorze.
* Asystent błędów LaTeX: otrzymuj sugerowane przez AI poprawki błędów kompilacji LaTeX.
* Integracja z Mendeley: importuj bibliografię z Mendeley, podobnie jak z Zotero.
* Open in Overleaf API: dodano API do otwierania treści w Overleaf.
* Galeria szablonów: dodano paginację, wyszukiwanie i sortowanie po stronie serwera, dzięki czemu duże galerie nie muszą już wczytywać wszystkich szablonów w przeglądarce.
* Tłumaczenia: zaktualizowano poprawki tłumaczeń dla wersji 6.3.0, w tym nowe teksty interfejsu we wszystkich obsługiwanych językach.
* Nadrzędny Overleaf 6.3.0: obejmuje edycję plików w kartach, osobne logo nagłówka dla jasnego i ciemnego motywu oraz aktualizacje zależności i obrazu bazowego.
* Dodano `OVERLEAF_HEADER_IMAGE_URL_LIGHT` i `OVERLEAF_HEADER_IMAGE_URL_DARK`, aby obsługiwać osobne obrazy logo nagłówka dla jasnego i ciemnego motywu.
* Pliki można teraz otwierać w edytorze w różnych kartach.
* Dodano obsługę konfigurowalnych serwerów proxy HTTP(S), w tym proxy hostowanych lokalnie, za pomocą `OVERLEAF_LINKED_URL_OUTBOUND_PROXY`, z którego korzysta również Open in Overleaf API.

#### Funkcja 04: Paginacja szablonów

Galeria wykonuje teraz stronicowanie, sortowanie i wyszukiwanie w MongoDB. Działa bez żadnych przygotowań; przy tysiącach szablonów nadal możesz dodać poniższe indeksy, aby zachować szybkość działania (można je bezpiecznie uruchomić ponownie, `mongo`/`sharelatex` = nazwy Twojego kontenera i bazy danych):

```bash
docker exec mongo mongosh sharelatex --quiet --eval '
db.templates.createIndex({category:1,lastUpdated:-1},{name:"category_1_lastUpdated_-1",background:true});
db.templates.createIndex({lastUpdated:-1},{name:"lastUpdated_-1",background:true});
db.templates.createIndex({category:1,name:1},{name:"category_1_name_1_ci",collation:{locale:"en",strength:2},background:true});
db.templates.createIndex({name:1},{name:"name_1_ci",collation:{locale:"en",strength:2},background:true});
'
```

Zachowaj `collation` w dwóch indeksach `*_ci` dokładnie tak, jak zapisano — galeria wykonuje zapytania z tym samym ustawieniem collation, a MongoDB używa tylko pasującego indeksu.

## Ayakaleaf Pro 6.2.2

**Data wydania:** 2026.07.23

Zobacz: [https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.2](https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.2)

### Zmiany

Przeniesienie (backport) oficjalnych poprawek hotfix dostarczonych w nadrzędnym Overleaf `6.2.2` (na bazie `6.2.1`):

* Zatrzymano wyciek sekretu tokenu zaproszeń do projektów do logów. Moduł szyfrujący tokeny zaproszeń zapisywał w logach własną konfigurację przy każdym szyfrowaniu/odszyfrowaniu, w tym hasła szyfrów wyprowadzone z `OVERLEAF_INVITE_TOKEN_SECRET`.
* Przeniesiono wysyłkę e-maili z wycofanego klienta AWS SES v1 na SESv2. Instancje skonfigurowane ze sterownikiem e-mail `ses` mogły w ogóle nie wysyłać wiadomości; wysyłka odbywa się teraz przez `SESv2Client`.
* Pozycje grup na liście rozwijanej udostępniania projektu są teraz zależne od nowej flagi funkcji `group-link-sharing`, dzięki czemu udostępnianie linków grupom nie jest już oferowane w instancjach, których nie dotyczy.
* Naprawiono okno udostępniania projektu dla współpracowników. Otwarcie go przez osobę niebędącą właścicielem lub przy wyłączonym przepływie `sharing-updates` powodowało wysłanie żądania, które zawsze kończyło się niepowodzeniem i wyświetlało błąd "something went wrong".
* Dodano do document-updater skrypt `scripts/flush_docs_with_pending_updates.js` — skrypt konserwacyjny, który odzyskuje dokumenty z zablokowaną kolejką `PendingUpdates` w Redis po opróżnieniu lub trwałym usunięciu ich projektu. Obsługuje `--dry-run` oraz kontrolę bezpieczeństwa `--estimated-docs`.
* Zaktualizowano zależności: `multer` 2.2.0, `form-data` 2.5.6, `protobufjs` 7.6.3, `@grpc/grpc-js` 1.14.4.

To wydanie zawiera również następujące poprawki i ulepszenia z Ayakaleaf Pro:

* Dodano pełne tłumaczenia dla 16 dodatkowych języków (cs, da, de, es, fi, fr, it, ja, ko, nl, no, pl, pt, ru, sv, tr), naprawiając nieprzetłumaczone teksty, np. na stronie resetowania hasła. Naprawia [#38](https://github.com/ayaka-notes/ayakaleaf-pro/issues/38).
* Naprawiono licznik elementów na przycisku "show N more projects" w panelu administracyjnym, który pokazywał błędną liczbę, ponieważ symbol zastępczy liczby mnogiej nie był poprawnie przekazywany.
* Naprawiono błędy walidacji eksportu do GitHub, które są teraz wyświetlane za pomocą statycznych kluczy i18n zamiast surowych komunikatów, oraz usunięto klucze błędów, które nie są już używane przez okno GitHub Sync.

## Ayakaleaf Pro 6.2.0

**Data wydania:** 2026.07.10

Zobacz: [https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.0](https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.0)

Z dumą ogłaszamy wydanie Overleaf Pro 6.2.0 — najpotężniejszego i najbogatszego w funkcje edytora LaTeX online w społeczności. Szczególne podziękowania dla yu-i-i i davrot za ich cenny wkład. Ulepszyli oni GitHub Sync oraz wprowadzili zaawansowane wyszukiwanie cytowań i integrację z Zotero.

### Uwagi

<Warning>

* Wprowadzono nową wymaganą zmienną środowiskową `OVERLEAF_INVITE_TOKEN_SECRET`. Musisz ją wygenerować poleceniem `openssl rand -base64 32`. Jeśli nie zostanie skonfigurowana, Twoja instancja Overleaf się nie uruchomi.
* Jeśli włączysz GitHub Sync, musisz skonfigurować zmienną środowiskową `GITHUB_TOKEN_CIPHER_PASSWORD`. Jest ona wymagana do bezpiecznego szyfrowania tokenów dostępu GitHub. Bez niej Twoja instancja Overleaf się nie uruchomi.

</Warning>

* Dodano nową zmienną środowiskową `DEFAULT_LATEX_COMPILER` do ustawiania domyślnego kompilatora używanego przez nowe projekty (`pdflatex`, `latex`, `xelatex` lub `lualatex`).
* Przeprojektowany edytor jest teraz jedyną dostępną opcją.

### Zmiany

To wydanie zawiera następujące ulepszenia i nowe funkcje.

* `MAX_UPLOAD_SIZE` można teraz konfigurować, zamiast być ograniczonym do **50 MB**.
* Naprawiono pętlę ponownego uruchamiania kontenera, gdy kompilacje w trybie sandbox były wyłączone.
* Wymuszono usuwanie PAT ograniczone do właściciela dla OAuth2.
* Naprawiono problem z importem LDAP.

Nowe funkcje obejmują:

* Dodano uruchamianie kodu Python w przeglądarce.
* Dodano obsługę Pandoc do importu i eksportu formatów Markdown, DOCX i innych.
* Dodano GitHub Sync.
* Dodano pełne tłumaczenie na język chiński.
* Dodano integrację z Zotero.
* Dodano `DEFAULT_LATEX_COMPILER`.
