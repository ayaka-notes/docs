### Wymagania dotyczące instalacji Server Pro i Community Edition

<Warning>

Zdecydowanie zalecamy uruchamianie Server Pro na aktualnej i stabilnej wersji systemu Ubuntu (np. Ubuntu 24.04 w latach 2025–2026) z aktualną wersją Dockera. Uruchomienie Server Pro na innych systemach jest możliwe, ale znacznie utrudni nam udzielanie wsparcia w przypadku niestandardowych konfiguracji Ubuntu/Docker. Nie możemy również oferować wsparcia w przypadku problemów z samym Dockerem.

</Warning>
