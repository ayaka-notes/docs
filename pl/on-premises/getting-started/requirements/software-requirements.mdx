### Systemy operacyjne {#operating-systems}

Dla serwerów współdzielonych i produkcyjnych zalecamy system **Linux oparty na Debianie**, taki jak **Ubuntu**. Ayakaleaf Pro może też działać w [macOS z Docker Desktop](/pl/on-premises/installation/using-docker-compose/macos) oraz w [Windows z WSL 2 i Docker Desktop](/pl/on-premises/installation/using-docker-compose/windows). Wszystkie trzy platformy korzystają z kontenerów Linux i tego samego Toolkit; postępuj zgodnie z przewodnikiem dla systemu operacyjnego Twojego hosta.

<Danger>

W przypadku korzystania z funkcji Sandboxed Compiles **należy pamiętać**, że aplikacja wymaga dostępu root do gniazda (socket) Dockera.

</Danger>

### Zależności {#dependencies}

* Docker 25.0 i 29
* MongoDB 7.0 i 8.0
* Redis 6.2 i 7.5

<Info>

Daty zakończenia wsparcia (End-of-Life, EOL) powyższych zależności oraz innych popularnych produktów możesz śledzić za pomocą serwisu endoflife.date: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

MongoDB i Redis są automatycznie pobierane przez `docker compose` podczas uruchamiania Ayakaleaf Pro, chyba że skonfigurowano użycie innej instalacji.

</Info>

Toolkit wymaga następujących programów:

* bash
* Docker

`docker compose` jest wymagany i zazwyczaj instaluje się go razem z Dockerem.

Zalecamy zainstalowanie najnowszej wersji Dockera dostępnej dla Twojego systemu operacyjnego.

Po poprawnej instalacji Dockera powinno być możliwe uruchomienie tych poleceń bez błędów:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2 or later, such as v5)
docker compose version

# List the running Docker containers on your system
docker ps
```
