### Systemy operacyjne

Aby uzyskać najlepsze rezultaty podczas uruchamiania Overleaf, zdecydowanie zalecamy korzystanie z systemu operacyjnego **opartego na Debianie**, takiego jak **Ubuntu**. Taki wybór jest zgodny ze środowiskiem, w którym rozwijane jest oprogramowanie, i jest preferowaną opcją wśród większości użytkowników Overleaf.

<Danger>

W przypadku korzystania z Server Pro z funkcją Sandboxed Compiles **należy pamiętać**, że aplikacja wymaga dostępu root do gniazda (socket) Dockera.

</Danger>

### Zależności

* Docker 25.0 i 29
* MongoDB 7.0 i 8.0
* Redis 6.2 i 7.5

<Info>

Daty zakończenia wsparcia (End-of-Life, EOL) powyższych zależności oraz innych popularnych produktów możesz śledzić za pomocą serwisu endoflife.date: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

MongoDB i Redis są automatycznie pobierane przez `docker compose` podczas uruchamiania Server CE lub Server Pro, chyba że skonfigurowano użycie innej instalacji.

</Info>

Toolkit wymaga następujących programów:

* bash
* Docker

`docker compose` jest wymagany i zazwyczaj instaluje się go razem z Dockerem.

Zalecamy zainstalowanie najnowszej wersji Dockera dostępnej dla Twojego systemu operacyjnego.

Po poprawnej instalacji Dockera powinno być możliwe uruchomienie tych poleceń bez błędów:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2)
docker compose version

# List the running Docker containers on your system
docker ps
```
