<Danger>

Poniższe instrukcje dotyczą **wyłącznie** instalacji **Community Edition**. Użytkownikom Ayakaleaf Pro zdecydowanie zalecamy włączenie [Sandboxed Compiles](/pl/on-premises/configuration/overleaf-toolkit/sandboxed-compiles), ponieważ zapewnia to dostęp do niemal tych samych obrazów TeX Live, które są używane w [overleaf.com](https://www.overleaf.com), a także izolację między kompilacjami projektów w celu zwiększenia bezpieczeństwa.

</Danger>

Aby oszczędzać przepustowość, obrazy Overleaf Community Edition i Ayakaleaf Pro zawierają tylko minimalną instalację [TeX Live](https://www.tug.org/texlive/). Możesz zainstalować więcej pakietów lub przejść na pełną instalację TeX Live za pomocą polecenia [tlmgr](https://www.tug.org/texlive/tlmgr.html) w kontenerze `sharelatex`.

#### Wejście do kontenera sharelatex

Aby uruchomić powłokę w kontenerze `sharelatex`, wykonaj

```bash
bin/shell
```

Pojawi się znak zachęty podobny do tego:

```bash
root@309b192d4030:/#
```

W poniższych instrukcjach zakładamy, że jesteś wewnątrz kontenera.

#### Ustalanie bieżącej wersji TeX Live

TeX Live jest wydawany co roku około kwietnia. Sposób korzystania z `tlmgr` różni się w zależności od tego, czy używasz bieżącego wydania, czy starszego. Wersję TeX Live, której używasz, możesz sprawdzić poleceniem `tlmgr --version`. Na przykład ta instalacja używa TeX Live 2021:

```bash
# tlmgr --version
tlmgr revision 59291 (2021-05-21 05:14:40 +0200)
tlmgr using installation: /usr/local/texlive/2021
TeX Live (https://tug.org/texlive) version 2021
```

<Info>

Bieżące wydanie TeX Live znajdziesz na [stronie głównej TeX Live](https://www.tug.org/texlive/).

</Info>

Jeśli używasz starszej wersji TeX Live, masz dwie możliwości. Nowa wersja obrazu Docker Overleaf jest zwykle publikowana wkrótce po wydaniu TeX Live — możesz na nią poczekać i zaktualizować wdrożenie za pomocą skryptu `bin/upgrade` lub, jeśli wolisz pozostać przy starszym wydaniu TeX Live, musisz najpierw wskazać `tlmgr`, aby korzystał z repozytorium historycznego. Instrukcje znajdziesz [tutaj](https://www.tug.org/texlive/acquire.html#past).

#### Instalowanie pakietów

Aby zainstalować pełną dystrybucję TeX Live, uruchom to polecenie wewnątrz kontenera `sharelatex`:

```text
tlmgr install scheme-full
```

Możesz też ręcznie instalować pojedyncze pakiety:

```bash
tlmgr install tikzlings tikzmarmots tikzducks
```

<Warning>

Począwszy od wydania `3.3.0` uruchomienie `tlmgr path add` jest ponownie **wymagane** po każdym użyciu `tlmgr install`, aby poprawnie utworzyć dowiązania symboliczne wszystkich plików binarnych w ścieżce systemowej.

</Warning>

Dostępnych jest znacznie więcej poleceń. Więcej informacji uzyskasz za pomocą:

```text
tlmgr help
```

Po zakończeniu wpisz `exit` lub naciśnij Control-D, aby wyjść z powłoki.

#### Zapisywanie zmian

Wprowadzone właśnie zmiany zmodyfikowały kontener `sharelatex`, ale są ulotne — zostaną utracone, jeśli Docker Compose odtworzy kontener, np. podczas aktualizacji konfiguracji.

Aby je utrwalić, użyj `docker commit`, aby zapisać zmiany w nowym obrazie Docker:

```bash
cat config/version #5.2.1
docker commit sharelatex sharelatex/sharelatex:5.2.1-with-texlive-full
echo 5.2.1-with-texlive-full > config/version
```

Po zatwierdzeniu zmian odpowiednio zaktualizuj `config/version`. Następnie uruchom `bin/up`, aby odtworzyć kontener `sharelatex`.

<Danger>

Te kroki trzeba będzie powtarzać przy każdej [aktualizacji](https://github.com/overleaf/toolkit/blob/master/doc/upgrading.md) do nowej wersji Overleaf.

</Danger>
