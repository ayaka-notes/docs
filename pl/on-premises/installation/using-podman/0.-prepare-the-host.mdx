---
title: 0. Przygotowanie hosta
description: Sprawdź system operacyjny i SELinux oraz zainstaluj git przed skonfigurowaniem rootless Podman.

---

Nie instalujesz Podmana ręcznie: krok [2. Uruchomienie podman-setup](/pl/on-premises/installation/using-podman/2.-run-podman-setup) instaluje go wraz z innymi potrzebnymi pakietami. Tutaj tylko sprawdzasz hosta i instalujesz `git`, który jest potrzebny do pobrania Toolkit.

<Steps>
<Step title="Sprawdzenie systemu operacyjnego i SELinux">
Zaloguj się jako użytkownik, który będzie uruchamiał Ayakaleaf Pro, a nie jako `root`, i sprawdź dystrybucję oraz tryb SELinux:

```bash title="Check the host"
grep PRETTY_NAME /etc/os-release
getenforce
```

Powinieneś zobaczyć RHEL, Rocky Linux, AlmaLinux lub CentOS Stream w wersji 9 lub nowszej oraz `Enforcing`:

```text
PRETTY_NAME="Rocky Linux 9.9 (Blue Onyx)"
Enforcing
```
</Step>

<Step title="Sprawdzenie dostępu do sudo">
`bin/podman-setup --apply` instaluje pakiety i ładuje moduł SELinux za pomocą `sudo`, a gdy to potrzebne, prosi o hasło:

```bash title="Check sudo"
sudo -v
```

Jeśli to się nie powiedzie, poproś administratora o dodanie Twojego użytkownika do grupy `wheel`.
</Step>

<Step title="Instalacja git">
```bash title="Install git"
sudo dnf install -y git
```

<Warning>

Nie instaluj Docker Engine na tym hoście. Pakiet `podman-docker`, który instaluje `bin/podman-setup`, dostarcza polecenie `docker`, a Toolkit traktuje hosta jako Podmana zawsze, gdy istnieje polecenie `podman`.

</Warning>
</Step>
</Steps>
