Najłatwiejszym sposobem na przetestowanie Ayakaleaf Pro jest użycie GitHub Codespace, w którym wszystkie zmienne środowiskowe są wstępnie skonfigurowane, dzięki czemu możesz korzystać z niego od razu.

<Warning>

Gdy uruchamiasz kontenery Docker w GitHub Codespaces, Codespace nie wyłączy się automatycznie i nadal będzie **naliczana opłata**. Zasady rozliczeń GitHub Codespaces znajdziesz w [zasadach rozliczeń github codespaces](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces).

Aby zarządzać swoimi GitHub Codespaces, odwiedź [https://github.com/codespaces](https://github.com/codespaces). Gdy Codespace przestanie być potrzebny, usuń go w odpowiednim czasie.

</Warning>

**Wstępnie skonfigurowaliśmy** następujące funkcje:

* [x] Kompilacja LaTeX w piaskownicy z TeXLive **Basic** (2024-2026)
* [x] Import/eksport Pandoc (funkcja platformy SaaS)
* [x] Uruchamianie skryptów Python (funkcja platformy SaaS)
* [x] Obsługa Git-Bridge (funkcja Server Pro)
* [x] Zaawansowane wyszukiwanie bibliografii (funkcja platformy SaaS)
* [x] Panel administratora (globalne zarządzanie użytkownikami/projektami)
* [x] Śledzenie zmian (z panelem recenzji i komentarzy)
* [x] Pełna historia projektu (z przywracaniem i pobieraniem)
* [x] Paleta symboli (funkcja Server Pro/platformy SaaS)

<Warning>

Standardowe GitHub Codespaces zapewniają 32 GB przestrzeni dyskowej. To za mało dla naszej instalacji `texlive-full`. Aby przetestować pełny obraz, złóż zgłoszenie do pomocy technicznej GitHub o Codespace z dużymi maszynami (8+ rdzeni).

</Warning>

GitHub Sync, LDAP, OAuth, SSO, integracja z Zotero i inne funkcje _**nie są skonfigurowane**_ w tym środowisku testowym. Więcej informacji o konfigurowaniu tych funkcji we własnym wdrożeniu znajdziesz w [ustawieniach toolkit](/pl/on-premises/configuration/overleaf-toolkit/toolkit-settings).

<Steps>
<Step title="Utwórz GitHub Codespace">
Kliknij poniższy przycisk, aby utworzyć GitHub Codespace. Jeśli chodzi o konfigurację serwera, do testów zazwyczaj wystarczą **2 rdzenie i 8 GB RAM**. Jeśli planujesz używać [**TeX Live Full**](https://github.com/ayaka-notes/texlive-full), zalecamy wybranie konfiguracji z **8 rdzeniami i 64 GB**.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/ayakaleaf-pro-playground)
</Step>

<Step title="Zainicjuj instancję Overleaf">
Gdy Codespace będzie gotowy, uruchom w bashu poniższe polecenie, aby zainicjować instancję Overleaf.

```bash title="bash"
./init.sh
```

#### Użycie pełnego obrazu TeXLive

Jeśli masz dostęp do GitHub Codespaces z 8 rdzeniami/64 GB, możesz użyć w tym środowisku testowym obrazu TeXLive Full. Aby używać obrazu TeXLive Full zamiast TeXLive Basic, zmień poniższe zmienne środowiskowe w pliku `toolkit/config/variables.env`.

```dotenv wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1, ghcr.io/ayaka-notes/texlive-full:2024.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025, Texlive 2024
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```

Po zmianie zmiennych środowiskowych musisz zrestartować toolkit, aby zastosować zmiany. Możesz to zrobić za pomocą poniższego polecenia.

```bash
cd toolkit && bin/up -d
```
