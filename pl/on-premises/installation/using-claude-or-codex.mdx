Użyj Claude Code lub Codex, aby zaplanować i przeprowadzić wdrożenie Ayakaleaf Pro. Podczas pracy agent może przeszukiwać tę dokumentację przez MCP.

Agent pomaga we wdrożeniu. To Ty odpowiadasz za przeglądanie poleceń i ochronę danych uwierzytelniających.

### Zanim zaczniesz

Przygotuj obsługiwany serwer Linux z dostępem SSH. Przed kontynuowaniem zapoznaj się z [wymaganiami](/pl/on-premises/getting-started/requirements  "mention").

<Warning>

Nie wklejaj haseł, kluczy prywatnych, tokenów ani kluczy licencyjnych do promptów agenta. Przejrzyj każde polecenie przed jego uruchomieniem, zwłaszcza polecenia modyfikujące pliki, sieci lub kontenery.

</Warning>

### Podłącz dokumentację

Dodaj punkt końcowy MCP dokumentacji do swojego lokalnego agenta.

<Tabs>
<Tab title="Claude Code">

```bash wrap
claude mcp add ayakaleaf-pro --scope user --transport http https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>

<Tab title="Codex">

```bash wrap
codex mcp add ayakaleaf-pro --url https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>
</Tabs>

Po dodaniu serwera rozpocznij nową sesję. Poproś agenta o potwierdzenie, że może przeszukiwać dokumentację Ayakaleaf Pro.

### Wdróż Ayakaleaf Pro

Otwórz terminal na serwerze docelowym. Uruchom tam Claude Code lub Codex. Następnie wyślij ten prompt:

```text wrap
Use the Ayakaleaf Pro documentation MCP server to guide this deployment.
First, inspect the requirements and installation guides.
Ask me for missing deployment details before making changes.
Use the Ayakaleaf Toolkit unless the documentation requires another approach.
Before configuring the instance, summarize relevant optional features.
Ask which features and integrations I want to enable.
Include TLS, sandboxed compiles, Git integration, external MongoDB or Redis,
SSO (OIDC, SAML, or LDAP), GitHub Synchronisation, Zotero, S3 storage,
email delivery, branding, and localization when relevant.
Explain each selected option's prerequisites, security impact, and configuration steps.
Keep unselected optional features disabled.
Show each command before running it.
Do not expose, store, or request secrets in chat.
After deployment, verify that the service is healthy and summarize the changes.
```

Agent powinien przeprowadzić Cię przez konfigurację Docker, konfigurację Toolkit, pobranie obrazu i uruchomienie. Kanoniczny przebieg pracy opisano w przewodniku [using-the-toolkit](/pl/on-premises/installation/using-the-toolkit  "mention").

### Wybierz funkcje opcjonalne

Poproś agenta, aby polecał tylko funkcje pasujące do Twojego środowiska. Typowe wybory to:

* **Dostęp i bezpieczeństwo:** TLS, kompilacja w piaskownicy (sandboxed compiles) oraz SSO przez OIDC, SAML lub LDAP.
* **Usługi zewnętrzne:** MongoDB, Redis, magazyn S3 i wysyłka e-maili.
* **Współpraca:** integracja z Git, GitHub Synchronisation i Zotero.

Agent powinien wyjaśnić zależności przed edycją konfiguracji. Przed włączeniem integracji produkcyjnych zapoznaj się z [toolkit-settings.md](/pl/on-premises/configuration/overleaf-toolkit/toolkit-settings  "mention") oraz [authentication](/pl/on-premises/configuration/overleaf-toolkit/authentication  "mention").

### Zweryfikuj wdrożenie

Gdy agent zakończy wszystkie kroki:

1. Potwierdź, że każde polecenie zakończyło się bez błędów.
2. Otwórz skonfigurowany adres URL Ayakaleaf Pro w przeglądarce.
3. Wykonaj [6.-post-installation-tasks.md](/pl/on-premises/installation/using-the-toolkit/6.-post-installation-tasks  "mention").

W przypadku istniejącej instalacji Community Edition zamiast nowego wdrożenia skorzystaj z przewodnika [migrate-from-existing.md](/pl/on-premises/installation/migrate-from-existing  "mention").
