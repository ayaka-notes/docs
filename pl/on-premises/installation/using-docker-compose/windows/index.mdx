W tej sekcji uruchomimy Ayakaleaf Pro lokalnie w systemie Windows za pomocą WSL 2, Ubuntu, Docker Desktop i [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). Przewodnik używa adresu `http://localhost:8080`, przechowuje dane w katalogu domowym Ubuntu i włącza kompilacje w piaskownicy.

Aplikacja, MongoDB, Redis i TeX Live działają w kontenerach Linux zarządzanych przez Docker Desktop. Polecenia Toolkit uruchamiaj w Ubuntu; aplikację otwieraj w przeglądarce w systemie Windows. [Krok 0](/pl/on-premises/installation/using-docker-compose/windows/0.-setup-wsl-and-docker-desktop) wyjaśnia, jak współpracują części Windows i Linux, i zaczyna się od instalacji WSL.

Możesz używać systemu Windows do lokalnej instancji lub utrzymywać ją stale uruchomioną dzięki ustawieniom dostępności z kroku 6. Dla serwerów współdzielonych i produkcyjnych zalecamy [przewodnik dla systemu Linux](/pl/on-premises/installation/using-docker-compose/linux) z HTTPS, kopiami zapasowymi i kontrolą dostępu. Uśpienie systemu Windows, zamknięcie Docker Desktop i zamknięcie WSL przerywają działanie tej lokalnej instancji; zobacz [Utrzymywanie dostępności instancji](/pl/on-premises/installation/using-docker-compose/windows/6.-post-installation-tasks#keep-the-instance-available).

## Zanim zaczniesz {#before-you-start}

Potrzebujesz:

* Wersji systemu Windows i procesora obsługiwanych przez [Docker Desktop for Windows](https://docs.docker.com/desktop/setup/install/windows-install/), z włączoną wirtualizacją sprzętową. Ten przewodnik używa systemu Windows 11 na x86-64.
* Uprawnień do włączenia WSL i instalowania oprogramowania. WSL musi być w wersji 2.1.5 lub nowszej, a Ubuntu musi działać w trybie WSL 2.
* Wystarczającej ilości pamięci dla systemu Windows i kontenerów. Dla małej lokalnej instancji 4 procesory i 8 GB dostępne dla Dockera to sugerowany punkt wyjścia, a nie zmierzone minimum.
* Wolnego miejsca na dysku Windows, na którym przechowywane są dane WSL i Dockera. Przeznacz co najmniej 40 GB na pełną konfigurację TeX Live oraz dane projektów; podstawowy obraz z [kroku 5](/pl/on-premises/installation/using-docker-compose/windows/5.-personalizing-your-instance) jest mniejszy i nadaje się do pierwszego testu wdrożenia. Dodatkowe wersje obrazów wymagają dodatkowego miejsca.
* Dostępu sieciowego do GitHub, GitHub Container Registry (`ghcr.io`) i Docker Hub, aby sklonować Toolkit i pobrać obrazy.

Bloki **PowerShell** uruchamiaj w systemie Windows. Bloki **Bash** i polecenia `bin/` uruchamiaj w Ubuntu, chyba że zaznaczono inaczej. Nie uruchamiaj skryptów Toolkit w PowerShell ani w Windows Git Bash.
