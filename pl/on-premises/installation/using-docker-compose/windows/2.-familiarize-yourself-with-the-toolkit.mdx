Toolkit jest taki sam jak w systemie Linux. Jego struktura, katalog `config/` i polecenia `bin/` są opisane w kroku [2. Poznaj Toolkit](/pl/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) przewodnika dla systemu Linux.

W systemie Windows pamiętaj o tych różnicach:

* Uruchamiaj polecenia `bin/` w **Ubuntu Bash**, z katalogu `~/ayakaleaf-toolkit`. Polecenia oznaczone jako **PowerShell** uruchamiaj natomiast w systemie Windows.
* Uruchom Docker Desktop i włącz WSL Integration dla Ubuntu, zanim użyjesz `bin/up`, `bin/start` lub `bin/docker-compose`.
* Zachowaj w plikach konfiguracyjnych linuksowe znaki końca wiersza (LF). Edytuj je za pomocą `nano` w Ubuntu lub edytora połączonego z WSL. Znaki końca wiersza CRLF mogą powodować błędy Bash.
* `bin/doctor` wykonuje kontrole systemu Linux w Ubuntu. Jego ostrzeżenie o braku zalogowania do `quay.io` nie dotyczy publicznego obrazu `ghcr.io/ayaka-notes/overleaf-pro`. Pozostałe ostrzeżenia nadal wymagają uwagi.

```bash
bin/doctor
```
