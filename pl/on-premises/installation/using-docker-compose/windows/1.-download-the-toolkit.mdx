---
title: 1. Pobierz Toolkit
description: Zainstaluj zależności wiersza poleceń i sklonuj Ayakaleaf Toolkit w Ubuntu w WSL 2.
icon: arrow-down-to-bracket
---

<Steps>
<Step title="Zainstaluj narzędzia wiersza poleceń">
Uruchom w **Ubuntu**, używając hasła linuksowego utworzonego w kroku 0:

```bash
sudo apt update
sudo apt install -y git ca-certificates curl perl gawk openssl
```

Ubuntu zawiera już Bash, GNU sed i coreutils. W przeciwieństwie do macOS nie potrzebuje Homebrew ani osobnej instalacji GNU sed.
</Step>

<Step title="Sklonuj repozytorium Ayakaleaf Toolkit">
Trzymaj Toolkit i jego dane w linuksowym systemie plików Ubuntu, w swoim katalogu domowym:

```bash
cd "$HOME"
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

Dla działającej bazy danych i danych projektów unikaj `/mnt/c`, `/mnt/d`, OneDrive i katalogów tymczasowych. Ścieżki linuksowego systemu plików zapewniają uprawnienia i zachowanie systemu plików oczekiwane przez kontenery oraz pozwalają uniknąć narzutu związanego z dostępem między systemami plików; zobacz [wskazówki Microsoft dotyczące systemów plików](https://learn.microsoft.com/en-us/windows/wsl/filesystems).

<Warning>

Jeśli katalog zawiera już instalację, użyj jej bez zmian lub wybierz inny katalog dla nowej instancji. Nie zastępuj konfiguracji ani danych istniejącego wdrożenia.

</Warning>
</Step>
</Steps>
