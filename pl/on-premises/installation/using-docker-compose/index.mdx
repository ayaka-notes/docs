Docker Compose na jednym serwerze to zalecany sposób wdrażania Ayakaleaf Pro. Uruchamiasz go za pomocą [Toolkit](https://github.com/ayaka-notes/toolkit): zestawu skryptów, które opakowują `docker compose` i odczytują ustawienia z jednego katalogu `config/`, dzięki czemu `bin/up` zastępuje `docker compose up`.
