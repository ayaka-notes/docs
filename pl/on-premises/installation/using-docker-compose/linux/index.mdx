W tej sekcji przeprowadzimy Cię przez instalację Dockera, pobranie Toolkit z GitHub, zapoznanie się z niektórymi poleceniami Toolkit oraz skonfigurowanie podstawowych ustawień. Po zakończeniu tej sekcji powinieneś mieć działającą lokalną (on-premises) instancję Overleaf.

Kroki dotyczą najnowszej wersji Ubuntu LTS. W innej dystrybucji zainstaluj Docker Engine i wtyczkę Compose zgodnie z [dokumentacją Dockera](https://docs.docker.com/engine/install/), a następnie przejdź do kroku [1. Pobierz Toolkit](/pl/on-premises/installation/using-docker-compose/linux/1.-download-the-toolkit).

<Info>

Domyślnie instancja akceptuje połączenia tylko z samego serwera, pod adresem `http://localhost`. Aby otworzyć ją z innych komputerów lub na innym porcie, ustaw `OVERLEAF_LISTEN_IP` i `OVERLEAF_PORT` w `config/overleaf.rc`, zgodnie z opisem w kroku [5. Personalizacja instancji](/pl/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance).

</Info>
