---
title: 4. Pobierz obrazy Ayakaleaf Pro
description: Przełącz Toolkit na Macu na publiczny obraz Ayakaleaf Pro.
icon: split
---

Ayakaleaf Pro to bezpłatny obraz Docker w [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Aby go pobrać, nie potrzebujesz konta, logowania ani komercyjnej licencji Overleaf.

Otwórz `config/overleaf.rc` i ustaw:

```bash title="config/overleaf.rc"
SERVER_PRO=true
```

Przy następnym uruchomieniu `bin/up` Toolkit pobierze `ghcr.io/ayaka-notes/overleaf-pro` w wersji z `config/version` zamiast oficjalnej wersji Overleaf Community Edition.

Obraz jest budowany dla `arm64` i `amd64`, a Docker wybiera ten, który pasuje do Twojego Maca. Na komputerach z Apple silicon nie dodawaj `platform: linux/amd64` w pliku nadpisującym: obraz działałby wtedy w emulacji.
