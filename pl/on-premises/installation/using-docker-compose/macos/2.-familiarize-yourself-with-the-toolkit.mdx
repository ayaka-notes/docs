Toolkit jest taki sam w macOS i w systemie Linux. Jego struktura, katalog `config/` i polecenia `bin/` są opisane w kroku [2. Poznaj Toolkit](/pl/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) przewodnika dla systemu Linux.

W macOS pamiętaj o trzech różnicach:

* Uruchamiaj skrypty z terminala, w którym GNU sed znajduje się na początku `PATH`, zobacz [1. Pobierz Toolkit](/pl/on-premises/installation/using-docker-compose/macos/1.-download-the-toolkit).
* Uruchom Docker Desktop, zanim uruchomisz skrypt komunikujący się z Dockerem, taki jak `bin/up`, `bin/start` lub `bin/docker-compose`.
* `bin/doctor` zawiera kontrole odziedziczone z oficjalnego Overleaf Toolkit. Jego ostrzeżenie `This system seems to not be Linux` jest w macOS oczekiwane, a ostrzeżenie o braku zalogowania do `quay.io` nie dotyczy publicznego obrazu `ghcr.io/ayaka-notes/overleaf-pro`. Pozostałe problemy w raporcie nadal są istotne.
