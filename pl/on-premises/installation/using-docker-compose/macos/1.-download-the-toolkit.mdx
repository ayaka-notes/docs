<Steps>
<Step title="Sprawdź Git i Homebrew">
```bash
git --version
brew --version
```

Jeśli przy uruchomieniu Git macOS poprosi o instalację Command Line Tools, najpierw je zainstaluj. Jeśli brakuje Homebrew, zainstaluj go zgodnie z [oficjalnymi instrukcjami](https://brew.sh/).
</Step>

<Step title="Umieść GNU sed w PATH">
Skrypty Toolkit używają opcji GNU sed, które odrzuca wbudowany w macOS BSD sed. Zainstaluj [GNU sed](https://formulae.brew.sh/formula/gnu-sed) i umieść go na początku `PATH` w tym terminalu:

```bash
brew install gnu-sed
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
sed --version
```

Ostatnie polecenie powinno wyświetlić **GNU sed**.

Alias taki jak `alias sed=gsed` nie wystarczy: Toolkit uruchamia skrypty Bash, które nie widzą aliasów Twojej interaktywnej powłoki. Nie musisz zastępować `/usr/bin/sed`.

Uruchamiaj wiersz `export PATH=...` ponownie w każdym nowym terminalu, którego używasz do pracy z Toolkit, lub dodaj go do pliku startowego powłoki po inicjalizacji samego Homebrew.
</Step>

<Step title="Sklonuj repozytorium Ayakaleaf Toolkit">
Wybierz katalog, który będzie trwały. Dla działającej bazy danych i danych projektów unikaj `/tmp`, dysków wymiennych oraz folderów synchronizowanych z chmurą, takich jak iCloud Drive. Ten przewodnik używa `~/ayakaleaf-toolkit`:

```bash
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

<Warning>

Jeśli katalog zawiera już instalację, użyj jej bez zmian lub wybierz inny katalog dla nowej instancji. Nie inicjalizuj nowej konfiguracji na istniejącym wdrożeniu.

</Warning>
</Step>
</Steps>
