W tej sekcji uruchomimy Ayakaleaf Pro lokalnie na Twoim Macu za pomocą Docker Desktop i [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). Przewodnik używa adresu `http://localhost:8080`, przechowuje dane w Twoim katalogu domowym i kompiluje za pomocą TeX Live 2026 w kontenerach piaskownicy.

Docker Desktop uruchamia aplikację, MongoDB, Redis i kompilator TeX Live w maszynie wirtualnej Linux. Nie instalujesz MongoDB, Redis ani MacTeX bezpośrednio w macOS.

Używaj tej konfiguracji do użytku osobistego i lokalnych testów. Dla stale działającej usługi współdzielonej zalecamy [przewodnik dla systemu Linux](/pl/on-premises/installation/using-docker-compose/linux) z HTTPS, kopiami zapasowymi i kontrolą dostępu. Instancja jest niedostępna, gdy Mac jest uśpiony lub Docker Desktop jest zatrzymany, zobacz [Utrzymywanie dostępności instancji](/pl/on-premises/installation/using-docker-compose/macos/6.-post-installation-tasks#keep-the-instance-available).

## Zanim zaczniesz {#before-you-start}

Potrzebujesz:

* Wersji macOS obsługiwanej przez [Docker Desktop for Mac](https://docs.docker.com/desktop/setup/install/mac-install/).
* Git, [Homebrew](https://brew.sh/) i GNU sed. Toolkit używa opcji GNU sed, których nie akceptuje wbudowany w macOS BSD sed.
* Wystarczających zasobów zarówno dla macOS, jak i dla Dockera. Dla małej lokalnej instancji zacznij od 4 procesorów i 8 GB pamięci przydzielonych do Docker Desktop. To sugerowany punkt wyjścia, a nie zmierzone minimum.
* Co najmniej 40 GB wolnego miejsca na pełny obraz TeX Live oraz miejsca na projekty. Sprawdź zarówno wolne miejsce na Macu, jak i limit użycia dysku w Docker Desktop. Zacznij od jednej wersji TeX Live: każda dodatkowa wersja wymaga mniej więcej tyle samo miejsca.

Obrazy aplikacji i TeX Live są publikowane dla `arm64` i `amd64`. Na komputerach z Apple silicon pozwól Dockerowi wybrać natywny obraz ARM i nie wymuszaj `platform: linux/amd64`.
