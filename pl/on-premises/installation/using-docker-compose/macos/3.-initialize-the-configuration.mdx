---
title: 3. Inicjalizacja konfiguracji
description: Utwórz pliki konfiguracyjne Toolkit na Macu za pomocą bin/init.
icon: circle-play
---

W katalogu Toolkit, w terminalu z GNU sed w `PATH`, uruchom:

```bash
bin/init
```

`bin/init` tworzy trzy pliki:

| Plik | Przeznaczenie |
| --- | --- |
| `config/overleaf.rc` | Ustawienia kontenerów, publikowany port i lokalizacje danych |
| `config/variables.env` | Ustawienia aplikacji i sekrety |
| `config/version` | Wersja obrazu aplikacji |

Generuje też `OVERLEAF_INVITE_TOKEN_SECRET` w `config/variables.env`. Zachowaj go i nie publikuj tego pliku ani nie zatwierdzaj go w systemie kontroli wersji.

Zachowaj wersję, którą Toolkit wybiera dla nowej instalacji. Aby później zmienić wersję istniejącej instancji, postępuj zgodnie z instrukcją [Aktualizacja wdrożenia](/pl/on-premises/maintenance/upgrading-your-deployment).

<Warning>

Jeśli `bin/init` zatrzymuje się z komunikatem `sed: ... invalid command code`, został uruchomiony z BSD sed z macOS. Takie nieudane uruchomienie może pozostawić wszystkie trzy pliki w `config/` z pustym `OVERLEAF_INVITE_TOKEN_SECRET`, a ponowne uruchomienie `bin/init` zgłasza wtedy `Config files already exist`. Zobacz [Rozwiązywanie problemów](/pl/on-premises/installation/using-docker-compose/macos/troubleshooting#initialization-fails-with-invalid-command-code).

</Warning>
