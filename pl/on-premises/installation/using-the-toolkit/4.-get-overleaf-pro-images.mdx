---
title: 4. Pobierz obrazy Ayakaleaf Pro
icon: split
---

Ayakaleaf Pro to bezpłatny obraz Dockera dostępny w [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Do jego pobrania nie potrzebujesz konta ani logowania. Obrazy są budowane dla architektur amd64 i arm64, a Docker wybiera ten, który pasuje do Twojego serwera.

Otwórz plik `config/overleaf.rc` i ustaw:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

Przy następnym uruchomieniu `bin/up` Toolkit pobierze obraz Ayakaleaf Pro i użyje go zamiast oficjalnej wersji Overleaf Community Edition. Twoje ustawienia w `config/` nadal działają.

<Accordion title="Korzystasz już z oficjalnego Overleaf Toolkit (overleaf/toolkit)?">

Nie musisz instalować wszystkiego od nowa. Pobierz obraz Ayakaleaf Pro:

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Następnie dodaj do katalogu `overleaf-toolkit/config` plik o nazwie `docker-compose.override.yml` o następującej zawartości:

```yml
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

Przy następnym uruchomieniu `bin/up` Toolkit użyje obrazu Ayakaleaf Pro.

</Accordion>
