---
title: 4. Pobierz obrazy Ayakaleaf Pro
icon: split
---

Ayakaleaf Pro jest dystrybuowany jako obraz Dockera w rejestrze [ghcr](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/) i jest **ogólnodostępny** dla każdego. Udostępniamy obrazy dla architektur amd64 i arm64. Podczas pobierania obrazu odpowiedni wariant zostanie wybrany automatycznie na podstawie architektury Twojego systemu.

#### Użytkownicy Toolkitu Ayaka-notes

Jeśli używasz [ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit), Ayakaleaf Pro może bezpośrednio zastąpić Community Edition, więc możesz zachować dotychczasowe ustawienia i dostosowania. Włącz wersję Pro w Toolkicie, edytując plik `config/overleaf.rc` i ustawiając zmienną środowiskową `SERVER_PRO`:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

Przy następnym uruchomieniu `bin/up` Toolkit automatycznie pobierze obraz Ayakaleaf Pro i zacznie go używać.

#### Użytkownicy oficjalnego Toolkitu

Jeśli używasz [overleaf/toolkit](https://github.com/overleaf/toolkit), aby uzyskać obraz Pro, pobierz go następującym poleceniem:

```bash title="Pull Docker Images"
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Następnie dodaj do katalogu `overleaf-toolkit/config` plik o nazwie `docker-compose.override.yml` o następującej zawartości:

```yml title="docker-compose.override.yml"
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

Przy następnym uruchomieniu `bin/up` Toolkit automatycznie pobierze obraz Ayakaleaf Pro i zacznie go używać.
