### Inicjalizacja konfiguracji

Zainicjalizujmy pliki konfiguracyjne nowego serwera rozsądnymi wartościami domyślnymi, uruchamiając dołączony skrypt `bin/init`.

```text title="Run initialization"
bin/init
```

Ten skrypt **nie** nadpisze żadnych istniejących plików konfiguracyjnych.

Teraz sprawdźmy zawartość katalogu `config/` za pomocą polecenia `ls`:

```text title="List the config directory"
ls config
```

Jeśli inicjalizacja przebiegła pomyślnie, powinny być widoczne trzy pliki konfiguracyjne: `overleaf.rc`, `variables.env` oraz `version`. Są to główne pliki konfiguracyjne serwera, które pozwalają dostosować sposób jego działania oraz sposób, w jaki użytkownicy korzystają z Twojej instancji.

| Nazwa           | Opis                                                    |
| --------------- | ------------------------------------------------------- |
| `overleaf.rc`   | Główny plik konfiguracyjny najwyższego poziomu.         |
| `variables.env` | Zmienne środowiskowe ładowane do kontenera Docker.      |
| `version`       | Wersja obrazu Docker, która ma zostać użyta.            |

<Info>

Na razie wystarczy wiedzieć, że te pliki istnieją i gdzie można je znaleźć. W dalszej części dokumentacji omówimy szczegółowo każdy z nich i wyjaśnimy, jak za ich pomocą dostosować swoją instancję. Jeśli chcesz przejść dalej, pełny opis tych plików konfiguracyjnych znajdziesz na [stronie Pliki i lokalizacje](/pl/on-premises/configuration/overleaf-toolkit/files-and-locations).

</Info>
