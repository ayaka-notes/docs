### Pobieranie Toolkit

Ayakaleaf Pro instalujesz za pomocą **Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)) — zestawu skryptów, które uruchamiają za Ciebie Overleaf w Dockerze.

Domyślnie Toolkit uruchamia bezpłatną, oficjalną wersję Overleaf Community Edition (CE). Krok [4. Pobierz obrazy Ayakaleaf Pro](/pl/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images) przełącza go na Ayakaleaf Pro za pomocą jednego ustawienia.

<Accordion title="Korzystasz już z oficjalnego Overleaf Toolkit (overleaf/toolkit)?">

Nie musisz instalować wszystkiego od nowa. Zachowaj swoją instalację i wykonaj ostatnią część kroku [4. Pobierz obrazy Ayakaleaf Pro](/pl/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images).

</Accordion>

<Steps>
<Step title="Sklonuj repozytorium Ayakaleaf Toolkit">
Aby zainstalować Toolkit, przejdź do docelowej ścieżki instalacji, a następnie sklonuj repozytorium Ayakaleaf Toolkit za pomocą tego polecenia:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
```

<Info>

Aby uniknąć potencjalnych problemów z uprawnieniami, zalecamy instalację Toolkit w katalogu `$HOME` Twojego użytkownika.

</Info>
</Step>

<Step title="Przejdź do katalogu toolkit">
Poczekaj na zakończenie klonowania, a następnie przejdź do nowo utworzonego katalogu `overleaf-toolkit`:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
