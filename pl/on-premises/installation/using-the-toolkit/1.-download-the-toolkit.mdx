### Pobieranie Toolkit

Toolkit jest zgodny zarówno z Server CE, jak i z Ayakaleaf Pro, i jest zalecaną metodą instalacji. Korzystając z Toolkit, łatwo zaczniesz pracę z Server CE i w razie potrzeby bezproblemowo przejdziesz na Ayakaleaf Pro.

<Info>

[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) został zmodyfikowany tak, aby bezpośrednio korzystał z obrazu overleaf-pro z ghcr, z TeX Live dostarczanym przez ayaka-notes. Alternatywnie możesz pobrać oficjalny overleaf-toolkit.

</Info>

<Steps>
<Step title="Sklonuj repozytorium Overleaf Toolkit">
Aby zainstalować Toolkit, przejdź do docelowej ścieżki instalacji, a następnie sklonuj repozytorium GitHub Overleaf Toolkit (@Ayaka-notes) za pomocą tego polecenia:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
# official toolkit (Not Recommended)
# git clone https://github.com/overleaf/toolkit.git ./overleaf-toolkit
```

<Info>

Aby uniknąć potencjalnych problemów z uprawnieniami, zalecamy instalację Toolkit w katalogu `$HOME` Twojego użytkownika.

</Info>
</Step>

<Step title="Przejdź do katalogu toolkit">
Poczekaj na zakończenie klonowania, a następnie przejdź do nowo utworzonego katalogu `overleaf-toolkit`:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
