Overleaf działa w oparciu o Dockera. Musisz zainstalować:

* Docker Engine (Docker CE)
* Wtyczkę Docker Compose (`docker compose`, v2)

Poniższe kroki dotyczą aktualnych wersji Ubuntu LTS (20.04/22.04/24.04).

<Warning>

Unikaj instalowania pakietu `docker.io` z domyślnego repozytorium apt Ubuntu.\
Korzystaj z oficjalnego repozytorium Dockera, aby uzyskać aktualną wersję Dockera oraz wtyczkę `docker compose`.

</Warning>

Oficjalna dokumentacja jest dostępna pod adresem: [https://docs.docker.com/engine/install/ubuntu/](https://docs.docker.com/engine/install/ubuntu/).

<Steps>
<Step title="1) Usuń stare lub konfliktujące pakiety (jeśli istnieją)">
Jeśli Docker był wcześniej zainstalowany z innego źródła, najpierw go usuń:

```bash wrap
sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-compose-v2 docker-doc podman-docker containerd runc | cut -f1)
```

To polecenie jest bezpieczne, nawet jeśli niektóre pakiety nie są zainstalowane.
</Step>

<Step title="2) Dodaj oficjalne repozytorium apt Dockera">
Zainstaluj wymagane pakiety:

```bash
sudo apt update
sudo apt install -y ca-certificates curl
```

Dodaj klucz GPG Dockera:

```bash wrap
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```

Dodaj repozytorium:

```bash wrap
# Add the repository to Apt sources:
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Signed-By: /etc/apt/keyrings/docker.asc
EOF

sudo apt update
```
</Step>

<Step title="3) Zainstaluj Docker Engine i wtyczkę Compose">
Zainstaluj Dockera i wtyczkę Compose:

```bash wrap
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

Włącz uruchamianie Dockera przy starcie systemu:

```bash
sudo systemctl enable --now docker
```
</Step>

<Step title="4) Sprawdź instalację">
Poniższe polecenia powinny wykonać się bez błędów:

```bash
docker --version
docker compose version
sudo docker run --rm hello-world
docker ps
```
</Step>

<Step title="5) (Opcjonalnie) Uruchamiaj Dockera bez sudo">
Dodaj swojego użytkownika do grupy `docker`:

```bash
sudo usermod -aG docker $USER
```

Następnie **wyloguj się i zaloguj ponownie** lub uruchom:

```bash
newgrp docker
```

Teraz poniższe polecenie powinno działać bez `sudo`:

```bash
docker ps
```

<Danger>

Grupa `docker` ma na hoście uprawnienia równoważne uprawnieniom roota.\
Jest to oczekiwane w typowych instalacjach Overleaf i szczególnie istotne, jeśli włączysz Sandboxed Compiles.

</Danger>
</Step>
</Steps>

Gdy Docker już działa, przejdź do kroków instalacji Toolkit opisanych w sekcji [Korzystanie z Toolkit](/pl/on-premises/installation/using-the-toolkit).
