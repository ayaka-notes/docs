ConfigMap `overleaf-env` zastępuje plik `config/variables.env` z Toolkit: trafia do niej każda zmienna środowiskowa z [dokumentacji Toolkit](/pl/on-premises/configuration/overleaf-toolkit/environment-variables), a sekrety trafiają do Secret z [kroku 2](/pl/on-premises/installation/using-kubernetes/2.-create-the-namespace-and-secrets).

```yaml title="30-config.yaml" wrap
apiVersion: v1
kind: ConfigMap
metadata:
  name: overleaf-env
  namespace: overleaf
data:
  OVERLEAF_APP_NAME: Ayakaleaf Pro
  OVERLEAF_SITE_URL: http://192.0.2.10:30080      # the address users open; https://... behind TLS
  OVERLEAF_ADMIN_EMAIL: admin@example.com
  # Emails: add the sender and the SMTP server together, see Email delivery
  # All members, so that the driver finds the primary even when mongo-0 is down
  OVERLEAF_MONGO_URL: mongodb://mongo-0.mongo:27017,mongo-1.mongo:27017,mongo-2.mongo:27017/sharelatex?replicaSet=overleaf
  OVERLEAF_REDIS_HOST: redis
  REDIS_HOST: redis
  ENABLED_LINKED_FILE_TYPES: project_file,project_output_file,url
  ENABLE_CONVERSIONS: "true"
  EMAIL_CONFIRMATION_DISABLED: "true"
  # Requests arrive from kube-proxy or your ingress controller, inside the pod network
  OVERLEAF_TRUSTED_PROXY_IPS: loopback,10.244.0.0/16
  # Sandboxed compiles. The HOST_DIR paths are paths ON THE NODE: the hostPath volumes that
  # the Deployment mounts at /var/lib/overleaf/data/{compiles,output,cache}.
  SANDBOXED_COMPILES: "true"
  SANDBOXED_COMPILES_SIBLING_CONTAINERS: "true"
  DOCKER_RUNNER: "true"
  SANDBOXED_COMPILES_HOST_DIR_COMPILES: /srv/overleaf/compiles
  SANDBOXED_COMPILES_HOST_DIR_OUTPUT: /srv/overleaf/output
  SANDBOXED_COMPILES_HOST_DIR_CACHE: /srv/overleaf/cache
  # Each image must be pulled into Docker on every node that can run Ayakaleaf Pro (step 0)
  ALL_TEX_LIVE_DOCKER_IMAGES: ghcr.io/ayaka-notes/texlive-full:2026.1
  ALL_TEX_LIVE_DOCKER_IMAGE_NAMES: TeX Live 2026
  TEX_LIVE_DOCKER_IMAGE: ghcr.io/ayaka-notes/texlive-full:2026.1
```

```bash
kubectl apply -f 30-config.yaml
```

| Zmienna                                 | Ustaw na                                                                                                                                                        |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_SITE_URL`                     | Adres URL, który użytkownicy wpisują w przeglądarce. Z NodePort z [kroku 5](/pl/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro) — adres IP dowolnego węzła i port `30080`; za ingress lub load balancerem — jego adres URL. |
| `OVERLEAF_MONGO_URL`                    | Twój zestaw replik. Użyj `?replicaSet=` z nazwą z `rs.initiate`.                                                                                               |
| `OVERLEAF_REDIS_HOST` i `REDIS_HOST`    | Obie na usługę Redis.                                                                                                                                          |
| `OVERLEAF_TRUSTED_PROXY_IPS`            | `loopback` oraz sieci, z których łączą się Twoje serwery proxy. `10.244.0.0/16` to sieć podów flannel; użyj CIDR podów swojego klastra.                       |
| `SANDBOXED_COMPILES_HOST_DIR_*`         | Ścieżki na węźle woluminów kompilacji. Muszą odpowiadać woluminom `hostPath` z [kroku 5](/pl/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro).                                     |

Za HTTPS ustaw również `OVERLEAF_SECURE_COOKIE: "true"`, zobacz [Proxy TLS](/pl/on-premises/configuration/overleaf-toolkit/tls-proxy).

<Info>

Zmieniona ConfigMap dociera do działających podów dopiero po ponownym uruchomieniu: `kubectl -n overleaf rollout restart deployment/overleaf`.

</Info>
