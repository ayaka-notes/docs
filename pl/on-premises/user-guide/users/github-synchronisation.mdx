Połącz projekt z repozytorium GitHub. Zmiany przepływają w obu kierunkach i tylko wtedy, gdy klikniesz **Sync**: nic nie synchronizuje się samo.

<Info>

Jeśli nie widzisz opcji GitHub w **Account settings** ani w edytorze, poproś administratora o włączenie [synchronizacji z GitHub](/pl/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation).

</Info>

## Łączenie konta GitHub {#link-your-github-account}

Robisz to raz.

<Steps>
<Step title="Otwórz ustawienia konta">
Kliknij **Account**, a następnie **Account settings**. Przewiń do **GitHub** i kliknij **Link**.

<Frame caption="GitHub w ustawieniach konta">
  <img src="/images/on-premises/github-sync-link.png" alt="Sekcja GitHub w ustawieniach konta z przyciskiem Link" />
</Frame>
</Step>

<Step title="Autoryzuj w GitHub">
Otworzy się GitHub. Zaloguj się, jeśli zostaniesz o to poproszony, a następnie autoryzuj aplikację.
</Step>

<Step title="Sprawdź połączenie">
Wracasz do ustawień konta, a na przycisku jest teraz napis **Unlink**.

<Frame caption="Twoje konto GitHub jest połączone">
  <img src="/images/on-premises/github-sync-linked.png" alt="Sekcja GitHub w ustawieniach konta z przyciskiem Unlink" />
</Frame>
</Step>
</Steps>

Jeśli Twoje konto nie jest jeszcze połączone, **Import from GitHub** i karta **GitHub** w edytorze najpierw poproszą o jego połączenie. Kliknij **Link to your GitHub account**. Również w ten sposób trafisz do ustawień konta, w nowej karcie, jeśli zacząłeś w edytorze. Następnie wróć i zacznij od nowa.

<Frame caption="Komunikat, gdy konto nie jest połączone">
  <img src="/images/on-premises/github-sync-link-prompt.png" alt="Okno dialogowe Import from GitHub z przyciskiem Link to your GitHub account" />
</Frame>

## Importowanie repozytorium {#import-a-repository}

Tworzy to nowy projekt z repozytorium GitHub, już z nim połączony.

<Steps>
<Step title="Otwórz okno importu">
Na stronie projektów kliknij **New project**, a następnie **Import from GitHub**.

<Frame caption="Menu New project">
  <img src="/images/on-premises/github-sync-new-project-menu.png" alt="Menu New project z opcją Import from GitHub" />
</Frame>

<Info>

**New project** pojawia się, gdy masz już projekt. Menu **Create a new project** na stronie powitalnej nie ma importu, więc najpierw utwórz pusty projekt.

</Info>
</Step>

<Step title="Wybierz repozytorium">
Kliknij **Import to Overleaf** obok repozytorium. Lista zawiera Twoje repozytoria i repozytoria Twoich organizacji.

<Frame caption="Twoje repozytoria GitHub">
  <img src="/images/on-premises/github-sync-import.png" alt="Okno dialogowe Import from GitHub z listą czterech repozytoriów" />
</Frame>

Jeśli brakuje repozytorium organizacji, kliknij <strong>Can't see what you're looking for?</strong>, aby otworzyć pomoc GitHub dotyczącą zatwierdzania aplikacji dla tej organizacji.
</Step>

<Step title="Sprawdź projekt">
Nowy projekt otworzy się z plikami repozytorium.

<Frame caption="Zaimportowany projekt">
  <img src="/images/on-premises/github-sync-imported.png" alt="Edytor z zaimportowanym projektem, jego plikami i skompilowanym plikiem PDF" />
</Frame>
</Step>
</Steps>

## Eksportowanie projektu do nowego repozytorium {#export-a-project-to-a-new-repository}

Tworzy to repozytorium z projektu, którego jesteś właścicielem, i łączy je. Projekt można połączyć tylko w ten sposób lub przez import: nie można połączyć go z istniejącym już repozytorium.

<Steps>
<Step title="Otwórz GitHub w edytorze">
Otwórz projekt. Na lewym pasku kliknij **Integrations**, a następnie **GitHub**.

<Frame caption="Panel Integrations">
  <img src="/images/on-premises/github-sync-integrations.png" alt="Panel Integrations z kartą GitHub" />
</Frame>
</Step>

<Step title="Wypełnij dane repozytorium">
Wybierz **Owner**: może to być Twoje konto lub jedna z Twoich organizacji. **Repository Name** początkowo jest nazwą projektu. Opis jest opcjonalny, a **Private** jest domyślnie zaznaczone. Kliknij **Create a GitHub repository**.

<Frame caption="Export Project to GitHub">
  <img src="/images/on-premises/github-sync-export.png" alt="Wypełniony formularz Export Project to GitHub" />
</Frame>
</Step>

<Step title="Sprawdź połączenie">
Okno dialogowe pokazuje teraz **This project is linked to** i nazwę repozytorium.

<Frame caption="Projekt jest połączony">
  <img src="/images/on-premises/github-sync-exported.png" alt="Okno dialogowe Sync with GitHub po eksporcie" />
</Frame>
</Step>
</Steps>

## Synchronizacja {#sync}

<Steps>
<Step title="Otwórz okno synchronizacji">
Otwórz połączony projekt. Na lewym pasku kliknij **Integrations**, a następnie **GitHub**.

**Recent commits in GitHub** pokazuje, co trafi do projektu.

<Frame caption="Nowy commit czeka w GitHub">
  <img src="/images/on-premises/github-sync-new-commits.png" alt="Okno dialogowe Sync with GitHub z jednym nowym commitem" />
</Frame>
</Step>

<Step title="Opisz swoje zmiany">
Jeśli coś zmieniłeś w projekcie, pojawi się pole na komunikat commita. Jest opcjonalne: jeśli zostawisz je puste, commit będzie nazywał się `Updates from Overleaf`.

<Frame caption="Komunikat commita dla Twoich zmian">
  <img src="/images/on-premises/github-sync-commit-message.png" alt="Okno dialogowe Sync with GitHub z wypełnionym komunikatem commita" />
</Frame>
</Step>

<Step title="Kliknij Sync">
Kliknij **Sync**. Nowe commity z GitHub trafiają do projektu, a Twoje zmiany do domyślnej gałęzi repozytorium. Jeśli obie strony zmieniły różne rzeczy, zostaną one scalone automatycznie.
</Step>

<Step title="Sprawdź wynik">
Okno dialogowe pokazuje <strong>No new commits in GitHub since last merge.</strong>, a pole komunikatu commita znika. Pliki w edytorze i commity w GitHub są aktualne.

<Frame caption="Wszystko jest zsynchronizowane">
  <img src="/images/on-premises/github-sync-done.png" alt="Okno dialogowe Sync with GitHub po synchronizacji, bez nowych commitów" />
</Frame>
</Step>
</Steps>

### Jeśli te same wiersze zmieniły się po obu stronach {#if-the-same-lines-changed-on-both-sides}

Okno dialogowe informuje, że zmian nie udało się scalić, i podaje nazwę nowej gałęzi `overleaf-YYYY-MM-DD-HHMMSS`, która zawiera Twoje zmiany.

<Frame caption="Konflikt">
  <img src="/images/on-premises/github-sync-conflict.png" alt="Okno dialogowe Sync with GitHub z ostrzeżeniem o konflikcie scalania" />
</Frame>

1. Scal tę gałąź z gałęzią domyślną w GitHub lub za pomocą Git. W międzyczasie możesz zamknąć okno dialogowe: po ponownym otwarciu pokaże ten sam komunikat.
2. Kliknij **I have manually merged. Continue**. Scalony wynik trafi do projektu.
3. Gałąź pozostaje w GitHub. Usuń ją, gdy nie będzie już potrzebna.

## Odłączanie projektu {#unlink-a-project}

Zrób to, gdy nie chcesz już synchronizować projektu. Może to zrobić tylko właściciel projektu.

<Steps>
<Step title="Kliknij Unlink">
W oknie synchronizacji kliknij **Unlink**.
</Step>

<Step title="Potwierdź">
Kliknij **Confirm**. Uwaga o subskrypcji nie przeszkadza w ponownym połączeniu projektu.

<Frame caption="Potwierdzenie odłączenia">
  <img src="/images/on-premises/github-sync-unlink-project.png" alt="Okno dialogowe Sync with GitHub z prośbą o potwierdzenie odłączenia" />
</Frame>
</Step>

<Step title="Sprawdź wynik">
Okno dialogowe pokazuje teraz **Export Project to GitHub**. Projekt i repozytorium zachowują swoją zawartość. Aby ponownie synchronizować, wyeksportuj projekt do nowego repozytorium lub zaimportuj repozytorium do nowego projektu.
</Step>
</Steps>

## Odłączanie konta GitHub {#unlink-your-github-account}

W **Account settings**, w sekcji **GitHub**, kliknij **Unlink**, a następnie ponownie **Unlink** w oknie dialogowym.

<Frame caption="Odłączanie konta">
  <img src="/images/on-premises/github-sync-unlink-account.png" alt="Okno dialogowe Unlink GitHub Account" />
</Frame>

Twoje projekty pozostają połączone ze swoimi repozytoriami. Nie możesz ich synchronizować, dopóki ponownie nie połączysz konta.

<Info>

Informacje o tym, kto może co robić we wspólnym projekcie, znajdziesz w sekcji [Kto może łączyć i synchronizować](/pl/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation#who-can-link-and-sync). Każdy współpracownik, który synchronizuje, łączy własne konto GitHub.

</Info>
