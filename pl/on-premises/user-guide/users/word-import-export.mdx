## Importuj dokument {#import-a-document}

Ta operacja tworzy nowy projekt LaTeX z dokumentu Word (`.docx`) lub pliku Markdown (`.md`). Nazwa projektu pochodzi z nazwy pliku.

<Steps>
<Step title="Otwórz okno importu">
Na stronie projektów kliknij **New project**. W sekcji **Import** kliknij **Word document** lub **Markdown document**.

<Frame caption="Menu New project">
  <img src="/images/on-premises/word-import-menu.png" alt="Menu New project z pozycjami Word document i Markdown document w sekcji Import" />
</Frame>
</Step>

<Step title="Wybierz plik">
Kliknij **Select .docx file** albo przeciągnij plik do okna. Dla Markdown przycisk nazywa się **Select .md file**. Import zaczyna się od razu.

<Frame caption="Wybór dokumentu Word">
  <img src="/images/on-premises/word-import-dialog.png" alt="Okno Choose Word document z przyciskiem Select .docx file" />
</Frame>
</Step>

<Step title="Zacznij edytować">
Nowy projekt otwiera się z komunikatem **Document ready for editing**. Kliknij **Start editing**.

<Frame caption="Import zakończony">
  <img src="/images/on-premises/word-import-ready.png" alt="Okno Document ready for editing z przyciskiem Start editing" />
</Frame>
</Step>

<Step title="Sprawdź wynik">
Dokument znajduje się teraz w `main.tex`, a jego nagłówki widać w konspekcie pliku. Kliknij **Recompile**, aby zobaczyć PDF. Sprawdź formatowanie, zwłaszcza tabele, rysunki i cytowania, które mogą wymagać poprawek.

<Frame caption="Zaimportowany projekt">
  <img src="/images/on-premises/word-import-project.png" alt="Zaimportowany projekt w edytorze z main.tex, konspektem pliku i skompilowanym PDF" />
</Frame>
</Step>
</Steps>

### Jeśli import się nie powiedzie {#if-the-import-fails}

Jeśli pliku nie da się przekonwertować, okno wyświetla **Your document couldn't be imported**. Rozwiń **Conversion error details**, aby zobaczyć przyczynę. Projekt nie zostaje utworzony.

<Frame caption="Dokument, którego nie udało się zaimportować">
  <img src="/images/on-premises/word-import-error.png" alt="Okno importu z komunikatem o błędzie i Conversion error details" />
</Frame>

Okno przyjmuje tylko wybrany typ. Plik `.md` w oknie Word powoduje komunikat **You can only upload: .docx**.

## Eksportuj projekt {#export-a-project}

Otwórz projekt, a następnie kliknij jego nazwę u góry edytora. Kliknij jedną z opcji:

| Opcja                              | Otrzymujesz                                       |
| ----------------------------------- | --------------------------------------------- |
| <strong>Export as Word document (.docx)</strong> | Plik `.docx` nazwany tak jak projekt        |
| <strong>Export as Markdown (.md)</strong>        | Plik `.zip` z `main.md`                  |
| <strong>Export as HTML (.html)</strong>          | Plik `.zip` z `main.html`                |

Pobieranie zaczyna się samo. Konwersja nie odtworzy całego formatowania LaTeX, więc sprawdź wynik.
