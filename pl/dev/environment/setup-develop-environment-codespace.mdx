Aby zaoszczędzić czas i szybko zbudować środowisko deweloperskie, udostępniamy alternatywną wersję konfiguracji środowiska deweloperskiego opartą na GitHub Codespace.

## Samouczek konfiguracji

<Steps>
<Step title="Utwórz Codespaces">
Kliknij poniższy przycisk, aby utworzyć chmurowe codespaces do rozwoju server-pro.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/overleaf-pro)

Zalecamy wybranie **typu maszyny** (**Machine Type**) z co najmniej **4 rdzeniami**. Jeśli potrzebujesz większej maszyny, możesz złożyć prośbę do oficjalnego zespołu wsparcia GitHub, tworząc zgłoszenie [tutaj](https://support.github.com/contact?tags=rr-codespaces%2Ccat_codespaces).

<Frame>
  <img src="/images/dev/image.png" alt="" />
</Frame>
</Step>

<Step title="Uruchom skrypt konfiguracyjny">
Musisz cierpliwie poczekać, aż codespace zostanie utworzony. Gdy uzyskasz dostęp do terminala, uruchom następujące polecenie:

```text
cd develop/
bin/setup
```

<Frame>
  <img src="/images/dev/image-1.png" alt="" />
</Frame>

<Warning>

Ten skrypt (`bin/setup`) pozwala w możliwie najkrótszym czasie skonfigurować środowisko deweloperskie na najnowszym commicie gałęzi `server-pro`. Może nie działać ze starszymi wersjami lub innymi gałęziami.

Codziennie budujemy deweloperski obraz Docker za pomocą [GitHub Action](https://github.com/ayaka-notes/overleaf-pro/actions).

</Warning>
</Step>

<Step title="Otwórz swój Launchpad">
Przejdź do zakładki portów — zobaczysz listę dostępnych portów webowych. Kliknij ten z numerem `80`. Powinna pojawić się strona launchpada.

<Frame>
  <img src="/images/dev/image-2.png" alt="" />
</Frame>

Zobaczysz:

<Frame>
  <img src="/images/dev/image-3.png" alt="" />
</Frame>
</Step>

<Step title="Miłego programowania">
Teraz czas na Twoją pracę! Zacznij budować swoją świetną funkcję. Aby włączyć podgląd w czasie rzeczywistym, uruchom następujące polecenie:

```bash title="bash" wrap
docker compose -f docker-compose.yml -f docker-compose.dev.yml -f ./docker-compose.image.yml up --no-deps --detach
```
</Step>
</Steps>
