---
title: Aktualizacja tłumaczeń i18n
icon: language
---

W repozytorium znajduje się plik `services/web/frontend/extracted-translations.json` — aplikacja webowa Overleaf używa wyłącznie wyodrębnionych tłumaczeń z tego pliku.

Jeśli dodałeś nowe treści, uruchom poniższe polecenie, aby zaktualizować wyodrębnione tłumaczenia.

```bash
user ➜ ~/overleaf-pro/develop (server-pro) $ bin/shell webpack
root@432836260f8a:/overleaf/services/web# npm run extract-translations
```

Co do zasady prosimy nie edytować plików z tekstami tłumaczeń i w pierwszej kolejności korzystać z istniejących, ponieważ wszystkie te pliki są aktualizowane z upstreamu Overleaf lub z zewnętrznego serwisu tłumaczeniowego.
