---
title: Kolekcja Project Invites
icon: envelope-open-text
---

`projectInvites` przechowuje zaproszenia, które właściciel projektu wysyła z okna udostępniania. Jeden dokument to jedno zaproszenie na jeden adres e-mail. Dokument jest usuwany, gdy zaproszenie zostanie przyjęte lub cofnięte, albo przez Mongo, gdy wygaśnie. Schemat to `services/web/app/src/models/ProjectInvite.mjs`, a zapisuje go `services/web/app/src/Features/Collaborators/CollaboratorsInviteHandler.mjs`.

Zaproszenie nie czyni nikogo członkiem. Członkowie są w tablicach `*_refs` projektu, zobacz [Kolekcja projektów](/pl/dev/data-model/projects-collection).

#### Pola {#fields}

| Pole | Typ | Znaczenie | Źródło |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Id zaproszenia. Powiadomienie o zaproszeniu istniejącego użytkownika używa klucza `project-invite-<_id>` (`services/web/app/src/Features/Notifications/NotificationsBuilder.mjs:102`). | `ProjectInvite.mjs:14` |
| `email` | String | Adres, na który wysłano zaproszenie. Przy cofaniu zaproszenia dla użytkownika jest porównywany z potwierdzonymi adresami użytkownika (`CollaboratorsInviteHandler.mjs:103-116`). Nieustawiony w zaproszeniu przez link udostępniania. | `ProjectInvite.mjs:16`, `CollaboratorsInviteHandler.mjs:84` |
| `tokenHmac` | String | HMAC-SHA256 (klucz `overleaf-token-invite`) tokenu z linku zaproszenia. Jawny token jest tylko w e-mailu i powiadomieniu; wyszukiwania haszują token z adresu URL i porównują go z tym polem. | `ProjectInvite.mjs:18`, `services/web/app/src/Features/Collaborators/CollaboratorsInviteHelper.mjs:11-15`, `CollaboratorsInviteHandler.mjs:82,256` |
| `encryptedToken` | String | Tylko w zaproszeniach przez link udostępniania: token zaszyfrowany za pomocą `Settings.projectInviteEncryptorOptions`, aby właściciel mógł ponownie zobaczyć link (`services/web/app/src/Features/Collaborators/CollaboratorsInviteController.mjs:606-611`). | `ProjectInvite.mjs:17`, `CollaboratorsInviteHelper.mjs:30-47`, `CollaboratorsInviteHandler.mjs:255-258` |
| `sendingUserId` | ObjectId | Użytkownik, który wysłał zaproszenie. Przy przyjęciu jest przekazywany jako użytkownik, który dodał nowego członka (`CollaboratorsInviteHandler.mjs:199-205`). Nieustawiony w zaproszeniu przez link udostępniania. | `ProjectInvite.mjs:19`, `CollaboratorsInviteHandler.mjs:86` |
| `projectId` | ObjectId | Projekt, którego dotyczy zaproszenie. | `ProjectInvite.mjs:20`, `CollaboratorsInviteHandler.mjs:87` |
| `privileges` | String or Boolean | Dostęp, który otrzymuje zaproszona osoba: `readOnly`, `readAndWrite` lub `review` (`services/web/app/src/Features/Authorization/PrivilegeLevels.mjs:6-12`). Zaproszenie przez link udostępniania może też zawierać `false`, czyli brak dostępu. | `ProjectInvite.mjs:21-25`, `CollaboratorsInviteHandler.mjs:88` |
| `createdAt` | Date | Ustawiane przez wartość domyślną schematu przy zapisie zaproszenia. | `ProjectInvite.mjs:26` |
| `expires` | Date | Wartość domyślna schematu: 30 dni po utworzeniu. Indeks TTL usuwa zaproszenie około 10 sekund po tym czasie. `null` w zaproszeniu przez link udostępniania, które nigdy nie wygasa. | `ProjectInvite.mjs:6-12,27-31`, `CollaboratorsInviteHandler.mjs:264` |
| `reusable` | Boolean | `false` w zaproszeniu e-mailowym, które jest usuwane po przyjęciu (`CollaboratorsInviteHandler.mjs:207-220`). `true` w zaproszeniu przez link udostępniania, które zostaje. | `ProjectInvite.mjs:32`, `CollaboratorsInviteHandler.mjs:89,263` |
| `subscriptionId` | ObjectId | Tylko w zaproszeniach przez link udostępniania: subskrypcja grupowa, której członkowie mogą przyjąć link (`CollaboratorsInviteController.mjs:490-501`). | `ProjectInvite.mjs:33`, `CollaboratorsInviteHandler.mjs:262` |

#### Kto zapisuje {#who-writes-it}

| Kod | Co robi |
| ---- | ------------ |
| `CollaboratorsInviteHandler.mjs:76-101` (`inviteToProject`) | Tworzy zaproszenie e-mailowe, a następnie wysyła e-mail oraz, dla istniejącego użytkownika, powiadomienie. Wywoływane przez `POST /project/:Project_id/invite` (`services/web/app/src/Features/Collaborators/CollaboratorsRouter.mjs:114-125`). |
| `CollaboratorsInviteHandler.mjs:118-133` (`revokeInvite`) | Usuwa jedno zaproszenie i oznacza jego powiadomienie jako przeczytane. Wywoływane przez `DELETE /project/:Project_id/invite/:invite_id` (`CollaboratorsRouter.mjs:154-159`). |
| `CollaboratorsInviteHandler.mjs:135-153` (`generateNewInvite`) | Ponowne wysłanie: usuwa zaproszenie i tworzy nowe z nowym tokenem (`CollaboratorsRouter.mjs:161-169`). |
| `CollaboratorsInviteHandler.mjs:103-116` (`revokeInviteForUser`) | Usuwa zaproszenie wysłane na jeden z potwierdzonych adresów użytkownika, gdy użytkownik dołącza przez token udostępniania linkiem (`services/web/app/src/Features/TokenAccess/TokenAccessController.mjs:396-401`) lub otrzymuje dostęp po prośbie o dostęp (`services/web/app/src/Features/Collaborators/CollaboratorsController.mjs:503-513`). |
| `CollaboratorsInviteHandler.mjs:155-221` (`acceptInvite`) | Dodaje użytkownika do projektu, a potem usuwa zaproszenie, chyba że jest `reusable`. |
| `CollaboratorsInviteHandler.mjs:249-269` (`createSharingLinkInvite`), `CollaboratorsInviteController.mjs:689-724` (`updateSharingLink`) | Tworzą lub aktualizują jedyne wielokrotnego użytku zaproszenie przez link udostępniania w projekcie. Te trasy wymagają split testu `sharing-updates-new-link` (`CollaboratorsRouter.mjs:134-152`), którego nie ma w `splitTestOverrides` (`services/web/config/settings.defaults.js:1371-1383`). Dlatego odpowiadają 403, dopóki ten split test nie zostanie skonfigurowany. |

#### Uwagi {#notes}

* Jeśli przy przyjęciu zaproszenia `readAndWrite` lub `review` projekt nie ma wolnego miejsca dla edytora, użytkownik dołącza tylko z prawem odczytu i trafia do `pendingEditor_refs` lub `pendingReviewer_refs` projektu (`CollaboratorsInviteHandler.mjs:162-205`).
* Starsze zaproszenia przechowywały jawny token w polu `token`. Migracja `20240524135408_add_token_hmac_project_invite_tokens.mjs` dodała `tokenHmac`, a `20240531082910_remove_project_invite_tokens.mjs` usunęła `token`.
* Nic nie usuwa zaproszeń usuniętego projektu; zostają, dopóki indeks TTL ich nie usunie.
