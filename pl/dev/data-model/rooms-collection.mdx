`rooms` przechowuje jeden dokument na pokój czatu projektu: czat projektu albo jeden wątek komentarzy recenzji. Zapisuje do niej tylko usługa chat, w `services/chat/app/js/Features/Threads/ThreadManager.js`. Nie ma schematu Mongoose. Wiadomości pokoju znajdują się w kolekcji [messages](/pl/dev/data-model/messages-collection).

#### Pola {#fields}

| Pole | Typ | Znaczenie | Źródło |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Identyfikator pokoju. Wskazuje tu `messages.room_id`. | `ThreadManager.js:57-61` |
| `project_id` | ObjectId | Projekt, do którego należy pokój. | `ThreadManager.js:43-54` |
| `thread_id` | ObjectId | Tylko w wątkach komentarzy: identyfikator komentarza, taki sam jak `id` i `op.t` komentarza w `docs.ranges.comments` (zobacz [docs](/pl/dev/data-model/docs-collection)). Brak w pokoju czatu projektu. | `ThreadManager.js:38-55`, `services/docstore/app/js/RangeManager.js:54-57` |
| `resolved` | Object | Ustawiane, gdy wątek zostaje rozwiązany, usuwane, gdy zostaje ponownie otwarty. Wątek bez tego pola jest otwarty. | `ThreadManager.js:94-123` |
| `resolved.user_id` | String | Identyfikator użytkownika, który rozwiązał wątek. Zapisany jako string, a nie ObjectId: treść żądania jest tylko sprawdzana pod kątem poprawnego identyfikatora, nie konwertowana. | `ThreadManager.js:103`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:70` |
| `resolved.ts` | Date | Kiedy wątek został rozwiązany. | `ThreadManager.js:104` |

#### Uwagi {#notes}

* Projekt ma najwyżej jeden pokój bez `thread_id`: czat projektu. Usługa chat znajduje go za pomocą `thread_id: { $exists: false }` (`ThreadManager.js:38-45`).
* Stan rozwiązania komentarza istnieje tylko tutaj. Docstore usuwa `op.resolved` przed zapisaniem zakresów (`services/docstore/app/js/RangeManager.js:59-61`).
* Po skopiowaniu projektu ten sam `thread_id` istnieje w dwóch projektach. Zawsze odpytuj `project_id` i `thread_id` razem, tak jak robi to usługa chat.
* Pokoje usuniętego projektu pozostają, dopóki usunięty projekt nie wygaśnie.
