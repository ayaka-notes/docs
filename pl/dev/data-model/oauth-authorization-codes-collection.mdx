---
title: Kolekcja OAuth Authorization Codes
icon: lock-open
---

`oauthAuthorizationCodes` jest przeznaczona na kody przepływu OAuth authorization code: jeden dokument na kod, który klient wymienia na token dostępu. Schemat to `services/web/app/src/models/OauthAuthorizationCode.mjs`, a moduł web `oauth2-server` zawiera kod, który by do niej zapisywał. W Ayakaleaf Pro nic nie dociera do tego kodu, więc kolekcja pozostaje pusta (zobacz Uwagi).

#### Pola {#fields}

| Pole | Typ | Znaczenie | Źródło |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Id dokumentu. | `OauthAuthorizationCode.mjs:6` |
| `authorizationCode` | String | Sam kod, zapisany bez zmian (bez haszowania). | `OauthAuthorizationCode.mjs:8`, `services/web/modules/oauth2-server/app/src/OAuth2Model.mjs:280` |
| `expiresAt` | Date | Koniec ważności. Po tym czasie `getAuthorizationCode` odrzuca kod, a indeks TTL go usuwa. | `OauthAuthorizationCode.mjs:9`, `OAuth2Model.mjs:150-153,281` |
| `oauthApplication_id` | ObjectId | Klient w [OAuth Applications](/pl/dev/data-model/oauth-applications-collection), który poprosił o kod. | `OauthAuthorizationCode.mjs:10`, `OAuth2Model.mjs:275-284` |
| `redirectUri` | String | URI przekierowania żądania. | `OauthAuthorizationCode.mjs:11`, `OAuth2Model.mjs:282` |
| `scope` | String | Żądany zakres. | `OauthAuthorizationCode.mjs:12`, `OAuth2Model.mjs:283` |
| `user_id` | ObjectId | Użytkownik, który przyznał kod. | `OauthAuthorizationCode.mjs:13`, `OAuth2Model.mjs:285` |
| `codeChallenge`, `codeChallengeMethod` | String | Challenge PKCE i jego metoda. | `OauthAuthorizationCode.mjs:14-15`, `OAuth2Model.mjs:286-287` |

#### Kto zapisuje {#who-writes-it}

| Kod | Co robi |
| ---- | ------------ |
| `OAuth2Model.mjs:274-300` (`saveAuthorizationCode`) | Wstawia kod. Nigdy nie jest wywoływane, zobacz Uwagi. |
| `OAuth2Model.mjs:307-312` (`revokeAuthorizationCode`) | Usuwa kod po jego użyciu. Nigdy nie jest wywoływane. |

#### Kto odczytuje {#who-reads-it}

| Kod | Co robi |
| ---- | ------------ |
| `OAuth2Model.mjs:137-177` (`getAuthorizationCode`) | Wczytuje kod wraz z użytkownikiem i klientem. Nigdy nie jest wywoływane. |

#### Indeksy {#indexes}

| Nazwa | Klucze | Opcje | Migracja |
| ---- | ---- | ------- | --------- |
| `expiresAt_1` | `{ expiresAt: 1 }` | TTL, `expireAfterSeconds: 0`, częściowy: `expiresAt` istnieje | `20230406125632_oauth_tokens_ttl.mjs` |

Migracje znajdują się w `tools/migrations/`. Unikalny indeks `authorizationCode_1` pochodzi tylko z migracji oznaczonych `saas` i `server-pro`, których Community Edition nie uruchamia.

#### Uwagi {#notes}

* Powyższe metody modelu wywołują tylko handlery authorize i token z `@node-oauth/oauth2-server`. Web używa tej biblioteki tylko do sprawdzania tokenów bearer (`services/web/app/src/Features/Authentication/AuthenticationController.mjs:409-450`), a żadna trasa nie obsługuje `/oauth/authorize` ani `/oauth/token`, więc żaden kod nigdy nie jest zapisywany. Osobiste tokeny dostępu są tworzone bezpośrednio, zobacz [OAuth Access Tokens](/pl/dev/data-model/oauth-access-tokens-collection).
