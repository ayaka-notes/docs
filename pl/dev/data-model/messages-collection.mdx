`messages` przechowuje jeden dokument na wiadomość: linię w czacie projektu albo komentarz lub odpowiedź w wątku komentarzy recenzji. Zapisuje do niej tylko usługa chat, w `services/chat/app/js/Features/Messages/MessageManager.js`. Nie ma schematu Mongoose. Każda wiadomość należy do pokoju w kolekcji [rooms](/pl/dev/data-model/rooms-collection).

#### Pola {#fields}

| Pole | Typ | Znaczenie | Źródło |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Identyfikator wiadomości. | `MessageManager.js:13-14` |
| `room_id` | ObjectId | Pokój (`rooms._id`), a nie identyfikator projektu ani wątku. | `MessageManager.js:8,106-108` |
| `user_id` | ObjectId | Autor. | `MessageManager.js:9,103-105` |
| `content` | String | Treść wiadomości, od 1 do 10240 znaków (`MAX_MESSAGE_LENGTH`). | `MessageManager.js:7`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:3,12-15` |
| `timestamp` | Number | Czas wysłania w milisekundach od 1970 roku (`Date.now()`), nie Date. | `MessageManager.js:10`, `services/chat/app/js/Features/Messages/MessageHttpController.js:288` |
| `edited_at` | Number | Czas ostatniej edycji w milisekundach (`Date.now()`). Brak, jeśli wiadomości nigdy nie edytowano. | `MessageManager.js:65-69`, `MessageHttpController.js:189,213` |

#### Kto zapisuje {#who-writes-it}

| Kod | Co robi |
| ---- | ------------ |
| `MessageManager.js:5-16` `createMessage` | Wstawia wiadomość (`MessageHttpController.js:275-294`). Web wysyła wiadomości czatu projektu z `services/web/app/src/Features/Chat/ChatController.mjs:32`, a komentarze z modułu track-changes (`services/web/modules/track-changes/app/src/TrackChangesController.mjs:95`) i modułu mcp-server (`services/web/modules/mcp-server/app/src/CommentTools.mjs:133`). |
| `MessageManager.js:51-72` `updateMessage` | Ustawia `content` i `edited_at`. Gdy podano identyfikator użytkownika, pasuje tylko wiadomość tego użytkownika (`MessageManager.js:62-64`). Wywoływane z `ChatController.mjs:135` i `TrackChangesController.mjs:110`. |
| `MessageManager.js:74-80` `deleteMessage` | Usuwa jedną wiadomość. Wywoływane z `ChatController.mjs:105` i `TrackChangesController.mjs:129`. |
| `MessageManager.js:39-49` `deleteAllMessagesInRoom(s)` | Usuwa wiadomości usuniętego wątku (`MessageHttpController.js:172-173`) albo całego projektu, gdy wygasa usunięty projekt (`MessageHttpController.js:261-271`, wywoływane z `services/web/app/src/Features/Project/ProjectDeleter.mjs:391`). |
| `MessageManager.js:115-127` `duplicateRoomToOtherRoom` | Kopiuje `content`, `timestamp` i `user_id` każdej wiadomości do innego pokoju, bez `edited_at`. Używane, gdy przywracanie historii duplikuje wątek (`MessageHttpController.js:316-342`), oraz gdy projekt jest kopiowany razem z zakresami (`MessageHttpController.js:344-357`). |

#### Kto odczytuje {#who-reads-it}

| Kod | Co robi |
| ---- | ------------ |
| `MessageManager.js:18-29` `getMessages` | Od najnowszych, najwyżej `limit` (domyślnie 50) starszych niż `before` (wartość `timestamp`). Używane w czacie projektu (`ChatController.mjs:80`). |
| `MessageManager.js:31-37` `findAllMessagesInRooms` | Wszystkie wiadomości kilku pokojów, dla listy wątków panelu recenzji (`TrackChangesController.mjs:82`), modułu mcp-server (`CommentTools.mjs:83`) i przywracania historii (`services/web/app/src/Features/History/RestoreManager.mjs:259`). Web sprawdza też pierwszą wiadomość wątku, aby recenzent mógł zmieniać tylko wątki, które sam rozpoczął (`services/web/app/src/Features/Authorization/AuthorizationManager.mjs:409-411`). |
| `MessageManager.js:90-100` `getMessage` | Jedna wiadomość. Web sprawdza jej `user_id`, zanim użytkownik edytuje lub usunie własną wiadomość (`services/web/app/src/Features/Authorization/AuthorizationMiddleware.mjs:253-257`, `TrackChangesController.mjs:124-125`). |

#### Uwagi {#notes}

* Aby znaleźć wiadomości komentarza, najpierw wyszukaj pokój po `project_id` i `thread_id`, a potem odpytaj `room_id`. Identyfikator komentarza w dokumencie to `thread_id`, a nie `room_id`.
* Tekst, na który wskazuje komentarz, to `op.c` w `docs.ranges.comments`; dyskusja jest tutaj.
