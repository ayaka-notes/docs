---
title: Kolekcja Project History Failures
icon: triangle-exclamation
---

`projectHistoryFailures` przechowuje jeden dokument na projekt, którego aktualizacji historii project-history nie mógł przetworzyć albo dla którego uruchomił ponowną synchronizację. Dokument jest znowu usuwany, gdy tylko przetwarzanie się powiedzie. project-history zapisuje ją w `services/project-history/app/js/ErrorRecorder.js`; jej typ jest w `services/project-history/app/js/mongo-types.ts:3-24`. Web też ma dla niej schemat Mongoose (`services/web/app/src/models/ProjectHistoryFailure.mjs:5-19`), ale żaden kod web nie używa tego modelu.

#### Uwagi {#notes}

* Dokument pozostaje, dopóki flush projektu się nie powiedzie albo projekt nie zostanie usunięty (`clearError` powyżej), więc każdy dokument oznacza projekt, którego ostatni flush lub ponowna synchronizacja jeszcze się nie powiodły.
* Ciągi błędów zaczynające się od `OError:` są zwracane jako `Error:` (`ErrorRecorder.js:18-26`); zapisana wartość się nie zmienia.
