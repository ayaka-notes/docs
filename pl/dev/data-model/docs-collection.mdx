---
title: Kolekcja Docs
icon: file-lines
---

`docs` przechowuje zawartość edytowalnych plików tekstowych projektu (Overleaf nazywa je docs), na przykład `main.tex` lub `sample.bib`. Jeden dokument na każdy doc: jego wiersze, komentarze i śledzone zmiany, dwa liczniki i stan usunięcia. Nazwy pliku i jego miejsca w drzewie tu nie ma, są w `projects.rootFolder` (zobacz [Kolekcja projektów](/pl/dev/data-model/projects-collection)). Plików binarnych też tu nie ma.

Poza migracjami i skryptami konserwacyjnymi do tej kolekcji zapisuje tylko docstore, w `services/docstore/app/js/MongoManager.js`. Nie ma modelu Mongoose; web i document-updater korzystają z niej przez HTTP API docstore (`services/docstore/app.js:31-70`). W kolumnie Źródło same nazwy plików znajdują się w `services/docstore/app/js/`.

#### Pola {#fields}

| Pole | Typ | Znaczenie | Źródło |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Id doc, takie samo jak `_id` wpisu doc w `projects.rootFolder`. | `MongoManager.js:142-147` |
| `project_id` | ObjectId | Projekt doc. | `MongoManager.js:144` |
| `lines` | Array of String | Tekst, jeden element na wiersz. Brak, gdy doc jest zarchiwizowany (`inS3: true`). | `DocManager.js:314-316`, `MongoManager.js:203` |
| `ranges` | Object | Komentarze i śledzone zmiany, zobacz poniżej. Brak, gdy doc jest zarchiwizowany. | `DocManager.js:317-319`, `RangeManager.js:36-65` |
| `rev` | Number | Własny licznik docstore. Zaczyna się od 1 i rośnie o 1 przy każdej zmianie `lines` lub `ranges`. Każda aktualizacja sprawdza stary `rev`, więc dwóch zapisujących nie może nadpisać się nawzajem. To nie jest wersja historii. | `MongoManager.js:115-136`, `:145`, `:254-269` |
| `version` | Number | Wersja OT doc z document-updater, zapisywana przy flushu. docstore odrzuca flush z niższą wersją. Starsze docs trzymały ją w kolekcji `docOps`; migracja `20231105000000_move_doc_versions_from_docops_to_docs` przeniosła ją tutaj. | `DocManager.js:283-290`, `:320-322` |
| `deleted` | Boolean | `true`, gdy doc został usunięty z projektu. Brak w docs, które nigdy nie były usuwane. | `services/docstore/app/js/HttpController.js:80-90` |
| `deletedAt` | Date | Kiedy doc został usunięty. | `HttpController.js:87` |
| `name` | String | Nazwa pliku w chwili usunięcia. Ustawiana tylko przy usunięciu doc; aktywne docs nie mają tu `name`. | `HttpController.js:88`, `services/web/app/src/Features/Docstore/DocstoreManager.mjs:28-36` |
| `inS3` | Boolean | `true`, gdy `lines`, `ranges` i `rev` przeniesiono do persistora docstore (`Settings.docstore.bucket`, klucz `<project_id>/<doc_id>`), a `lines` i `ranges` usunięto z Mongo. Usuwane ponownie, gdy doc zostanie odczytany z powrotem. | `MongoManager.js:198-206`, `:213-237`, `DocArchiveManager.js:43`, `:64-69` |
| `archivingUntil` | Date | Blokada utrzymywana podczas archiwizowania doc. | `MongoManager.js:177-193` |

#### Ranges {#ranges}

`ranges` ma dwie tablice. document-updater buduje je za pomocą `libraries/ranges-tracker/index.cjs`; docstore przed zapisem zamienia id na ObjectId, a `ts` na Date (`RangeManager.js:41-63`). Doc bez komentarzy i śledzonych zmian ma `ranges: {}` albo nie ma `ranges`.

| Pole | Typ | Znaczenie | Źródło |
| ----- | ---- | ------- | ------ |
| `ranges.comments` | Array of Object | Skomentowane fragmenty tekstu. | `libraries/ranges-tracker/index.cjs:217-236` |
| `ranges.comments.id` | ObjectId | Id komentarza. Jest równe `op.t`, id wątku komentarza w kolekcji `rooms`; docstore wymusza ich zgodność. | `RangeManager.js:54-57` |
| `ranges.comments.op.c` | String | Skomentowany tekst w doc (nie treść komentarza). | `index.cjs:226-230` |
| `ranges.comments.op.p` | Number | Przesunięcie w znakach początku `op.c` w doc. | `index.cjs:226-230` |
| `ranges.comments.op.t` | ObjectId | Id wątku, zobacz `id`. | `index.cjs:226-230`, `RangeManager.js:57` |
| `ranges.comments.metadata` | Object | `user_id` i `ts` komentarza. | `index.cjs:232`, `RangeManager.js:62` |
| `ranges.changes` | Array of Object | Śledzone zmiany, posortowane według pozycji. | `index.cjs:640-660` |
| `ranges.changes.id` | ObjectId | Id zmiany. | `index.cjs:643-647`, `RangeManager.js:51` |
| `ranges.changes.op.i` / `op.d` | String | Wstawiony lub usunięty tekst. Jedno z dwóch. | `index.cjs:640-660` |
| `ranges.changes.op.p` | Number | Przesunięcie zmiany w znakach. | `index.cjs:640-660` |
| `ranges.changes.metadata.user_id` | ObjectId or String | Autor. Zmiany anonimowych edytorów zachowują ciąg `anonymous-user`. | `RangeManager.js:45-46`, `DocManager.js:192` |
| `ranges.changes.metadata.ts` | Date | Kiedy wprowadzono zmianę. | `RangeManager.js:42-43` |

Tekstu komentarza i odpowiedzi na niego nie ma w `docs`: znajduje się w kolekcji `messages`, w room, której `thread_id` jest id komentarza. To, czy komentarz jest rozwiązany, jest zapisywane w tej room, nie tutaj; docstore odrzuca flagę `resolved`, jeśli zostanie przesłana (`RangeManager.js:59-61`). Zobacz [Kolekcja Rooms](/pl/dev/data-model/rooms-collection) i [Kolekcja Messages](/pl/dev/data-model/messages-collection).

#### Kto zapisuje {#who-writes-it}

| Kod | Co robi |
| ---- | ------------ |
| `DocManager.js:223-338` (`POST /project/:project_id/doc/:doc_id`) | Tworzy lub aktualizuje doc: `lines`, `ranges` i `version`. Web wywołuje to przy tworzeniu doc i gdy document-updater wykonuje flush otwartego doc (`services/web/app/src/Features/Project/ProjectEntityUpdateHandler.mjs:174`). |
| `DocManager.js:346-366` (`PATCH /project/:project_id/doc/:doc_id`) | Oznacza doc jako usunięty za pomocą `deleted`, `deletedAt` i `name`. |
| `DocArchiveManager.js:29-88` | Archiwizuje doc: kopiuje `lines`, `ranges` i `rev` do persistora i ustawia `inS3`. Działa dla całego projektu, gdy zostaje on dezaktywowany, oraz dla pojedynczego doc przy usunięciu, gdy `ARCHIVE_ON_SOFT_DELETE=true` (`DocManager.js:355-363`). |
| `DocArchiveManager.js:150-174` | Przywraca zarchiwizowany doc do Mongo przy odczycie (`DocManager.js:40-41`). |
| `MongoManager.js:272-274` | Usuwa wszystkie docs projektu, gdy projekt zostaje zniszczony. |

#### Kto odczytuje {#who-reads-it}

| Kod | Co robi |
| ---- | ------------ |
| `services/document-updater/app/js/PersistenceManager.js:18-30` | Wczytuje doc (przez web), gdy ktoś go otwiera. |
| `services/web/app/src/Features/Docstore/DocstoreManager.mjs` | Wszystkie odczyty web: jeden doc, wszystkie docs projektu, wszystkie ranges, usunięte docs. |
| `services/web/app/src/Features/Project/ProjectDuplicator.mjs:49` | Kopiuje projekt; najpierw wykonuje flush document-updater. |
| `services/web/modules/admin-tools/app/src/AdminProjectManager.mjs:395-413` | Wyświetla usunięte docs projektu w panelu administracyjnym. |

#### Indeksy {#indexes}

Wszystkie pochodzą z migracji z tagiem `server-ce` w `tools/migrations/`.

| Nazwa | Klucze | Opcje | Migracja |
| ---- | ---- | ------- | --------- |
| `project_id_deleted_deletedAt_1` | `project_id: 1, deleted: 1, deletedAt: -1` | | `20210408123210_create_docs_project_id_deleted_deletedAt_index` |
| `project_id_1_inS3_1_deleted_1` | `project_id: 1, inS3: 1, deleted: 1` | | `20250321092555_add_deleted_to_project_id_in_s3_index` |

#### Uwagi {#notes}

* Gdy doc jest otwarty, jego najnowszy tekst znajduje się w document-updater (Redis), nie tutaj. Mongo jest aktualizowane dopiero przy flushu document-updater (`services/document-updater/app/js/PersistenceManager.js:128-160`). Kod odczytujący docs całego projektu powinien najpierw wywołać `flushProjectToMongo`, tak jak robi to `ProjectDuplicator`.
* Usunięte docs pozostają w tej kolekcji z `deleted: true`, dopóki projekt nie zostanie zniszczony. docstore zwraca najwyżej `MAX_DELETED_DOCS` (domyślnie 2000) z nich, od najnowszych (`MongoManager.js:29-44`, `services/docstore/config/settings.defaults.cjs:40`). Panel historii ich nie używa; odczytuje history-v1.
* Liczniki `rev` i `version` nie mają związku z wersjami historii projektu w history-v1.

```json5
    rev: 1,
    lines: [
        '@article{greenwade93,',
        '    author  = "George D. Greenwade",',
        '    title   = "The {C}omprehensive {T}ex {A}rchive {N}etwork ({CTAN})",',
        '    year    = "1993",',
        '    journal = "TUGBoat",',
        '    volume  = "14",',
        '    number  = "3",',
        '    pages   = "342--351"',
        '}',
        ''
    ],
    ranges: {},
    version: 0,
    deleted: true,
    deletedAt: ISODate('2026-01-17T13:11:42.580Z'),
    name: 'sample.bib'
}
```
