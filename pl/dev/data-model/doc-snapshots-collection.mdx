`docSnapshots` przechowuje kopie dokumentu, które document-updater wykonuje tuż przed edycją zwijającą komentarze lub śledzone zmiany. Zapisuje do niej tylko document-updater, w `services/document-updater/app/js/SnapshotManager.js`. Web ma model Mongoose w `services/web/app/src/models/DocSnapshot.mjs`, ale żaden kod go nie używa.

#### Pola {#fields}

| Pole | Typ | Znaczenie | Źródło |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Identyfikator migawki. | `SnapshotManager.js:24` |
| `project_id` | ObjectId | Projekt. | `SnapshotManager.js:19,26`, `DocSnapshot.mjs:7` |
| `doc_id` | ObjectId | Dokument (`docs._id`). | `SnapshotManager.js:20,27`, `DocSnapshot.mjs:8` |
| `version` | Number | Wersja OT dokumentu przed edycją. | `SnapshotManager.js:28`, `services/document-updater/app/js/UpdateManager.js:132,264-271`, `DocSnapshot.mjs:9` |
| `lines` | Array of String | Zawartość dokumentu przed edycją. | `SnapshotManager.js:29`, `DocSnapshot.mjs:10` |
| `pathname` | String | Ścieżka dokumentu w projekcie w tamtym momencie. | `SnapshotManager.js:30`, `DocSnapshot.mjs:11` |
| `ranges` | Mixed | `comments` i `changes` sprzed edycji, w tej samej postaci co `docs.ranges` (zobacz [docs](/pl/dev/data-model/docs-collection)). `id`, `op.t` i `metadata.user_id` są zamieniane na ObjectId, a `metadata.ts` na Date. | `SnapshotManager.js:31,41-68`, `DocSnapshot.mjs:12` |
| `ts` | Date | Kiedy wykonano migawkę. Indeks TTL usuwa ją po 30 dniach. | `SnapshotManager.js:32`, `DocSnapshot.mjs:13` |

#### Kto zapisuje {#who-writes-it}

| Kod | Co robi |
| ---- | ------------ |
| `UpdateManager.js:248-271` | Po zastosowaniu edycji document-updater zapisuje dokument w stanie sprzed edycji, jeśli edycja zwinęła zakresy: więcej zakresów stało się pustych albo usunięto więcej niż jeden zakres (`services/document-updater/app/js/RangesManager.js:104-106`). |
| `SnapshotManager.js:17-36` `recordSnapshot` | Wstawia migawkę. |

#### Kto odczytuje {#who-reads-it}

Żaden kod jej nie odczytuje. Model web jest zdefiniowany, ale nigdzie nieużywany.

Indeks `project_id_1` z `20190912145007_create_docSnapshots_indexes.mjs` został usunięty przez `20231101191643_drop_unused_indexes.mjs`.

#### Uwagi {#notes}

* Migawki tworzą tylko edycje przechodzące przez `UpdateManager.applyUpdate`. Edycje obsługiwane przez `HistoryOTUpdateManager` ich nie tworzą (`UpdateManager.js:74-77`).
* Na `doc_id` nie ma indeksu. Szukaj migawek dokumentu po `project_id` i `ts`, a potem filtruj po `doc_id`.
