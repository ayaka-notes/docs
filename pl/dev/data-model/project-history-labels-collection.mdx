---
title: Kolekcja Project History Labels
icon: tag
---

`projectHistoryLabels` przechowuje etykiety, które użytkownicy nadają wersjom w widoku History, po jednym dokumencie na etykietę. Właścicielem jest project-history, który zapisuje ją w `services/project-history/app/js/LabelsManager.js`; nie ma schematu Mongoose. Web sięga do niej tylko przez API project-history.

#### Pola {#fields}

| Pole | Typ | Znaczenie | Źródło |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Identyfikator etykiety. | `LabelsManager.js:81-85` |
| `project_id` | ObjectId | Projekt. | `LabelsManager.js:73` |
| `comment` | String | Tekst etykiety. | `LabelsManager.js:74` |
| `version` | Number | Wersja historii projektu, na którą wskazuje etykieta. | `LabelsManager.js:75` |
| `created_at` | Date | Kiedy utworzono etykietę; żądanie może przekazać własny czas, w przeciwnym razie jest to chwila obecna. | `LabelsManager.js:70`, `76` |
| `user_id` | ObjectId | Kto utworzył etykietę. Pomijane, gdy żądanie nie ma użytkownika. | `LabelsManager.js:78-80` |

#### Kto zapisuje {#who-writes-it}

| Kod | Co robi |
| ---- | ------------ |
| `services/project-history/app/js/LabelsManager.js:44-90` | `createLabel`: wstawia etykietę, dla project-history `POST /project/:project_id/labels` (`services/project-history/app/js/HttpController.js:1134-1171`). Web wywołuje go, gdy użytkownik dodaje etykietę, z identyfikatorem użytkownika (`services/web/app/src/Features/History/HistoryController.mjs:529-546`). |
| `LabelsManager.js:113-126` | `deleteLabel`: usuwa etykietę projektu, dla `DELETE /project/:project_id/labels/:label_id`. Web używa go, gdy właściciel projektu usuwa etykietę (`HistoryController.mjs:649-670`). |
| `LabelsManager.js:92-111` | `deleteLabelForUser`: usuwa etykietę tylko wtedy, gdy utworzył ją ten użytkownik, dla `DELETE /project/:project_id/user/:user_id/labels/:label_id`. Web używa go dla wszystkich pozostałych. |
| `LabelsManager.js:128-143` | `transferLabels`: przenosi wszystkie etykiety jednego użytkownika na innego, dla `POST /user/:from_user/labels/transfer/:to_user` (`services/project-history/app/js/Router.js:52-55`). Nic w web nie wywołuje tej trasy. |
| `LabelsManager.js:7-25` | `cloneLabels`: kopiuje etykiety projektu do innego projektu, dla project-history `POST /project/:project_id/clone` (`HttpController.js:113`), której nic w web nie wywołuje. |

#### Kto odczytuje {#who-reads-it}

| Kod | Co robi |
| ---- | ------------ |
| `LabelsManager.js:27-42` | `getLabels`: wszystkie etykiety projektu, zwracane jako `{ id, comment, version, user_id, created_at }` (`LabelsManager.js:163-171`). Używane przez `GET /project/:project_id/labels` (`HttpController.js:1076-1100`), które web wywołuje dla widoku History, uzupełniając nazwy użytkowników (`HistoryController.mjs:488-499`). |
| `services/project-history/app/js/SummarizedUpdatesManager.js:57` | Dodaje etykiety do listy aktualizacji historii. |

#### Uwagi {#notes}

* Przed wstawieniem etykiety project-history przetwarza zakolejkowane aktualizacje projektu i sprawdza, czy history-v1 ma chunk dla tej wersji, chyba że żądanie wysyła `validate_exists: false` (`LabelsManager.js:53-59`, `173-195`; `HttpController.js:1109-1115`).
* Żaden kod nie usuwa etykiet projektu przy jego usunięciu: project-history `DELETE /project/:project_id` czyści tylko stan synchronizacji i rekord błędu (`HttpController.js:1363-1396`), a żadna inna usługa nie dotyka tej kolekcji.
