title: Kolekcja Templates
icon: book-open
---

`templates` zawiera jeden dokument na każdy szablon w galerii szablonów. Plików szablonu (zip projektu i PDF) tu nie ma: są przechowywane w filestore pod `template/<_id>/v/<version>/`. Kolekcja należy do modułu web `template-gallery` (`services/web/modules/template-gallery`). Schemat to model Mongoose `Template` w `services/web/modules/template-gallery/app/src/models/Template.mjs`; logika znajduje się w `services/web/modules/template-gallery/app/src/TemplateGalleryManager.mjs` i w sąsiednim `TemplateGalleryHelper.mjs`.

#### Pola {#fields}

| Pole | Typ | Znaczenie | Źródło |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Ustawiane przez Mongoose. To także folder plików szablonu w filestore. | `TemplateGalleryHelper.mjs:148-150` |
| `name` | String | Tytuł. Wymagany, maksymalnie 150 znaków. Publikowanie wyszukuje szablon po nazwie, a edycja odrzuca nazwę, którą ma inny szablon, więc nazwy pozostają unikalne bez indeksu. | `Template.mjs:7`, `TemplateGalleryHelper.mjs:50-52`, `TemplateGalleryManager.mjs:30-38,55` |
| `category` | String | Link kategorii `/templates/<key>`, gdzie `<key>` to jedna z wartości `OVERLEAF_TEMPLATE_CATEGORIES` lub `all`. Wymagany. | `Template.mjs:8`, `services/web/modules/template-gallery/index.mjs:17-31`, `TemplateGalleryManager.mjs:206` |
| `descriptionMD` | String | Opis w postaci wpisanej, w Markdown. Maksymalnie 4096 znaków. Przeszukiwany przez galerię. | `Template.mjs:10`, `TemplateGalleryHelper.mjs:53-55`, `TemplateGalleryManager.mjs:207-212` |

#### Kto zapisuje {#who-writes-it}

| Kod | Co robi |
| ---- | ------------ |
| `TemplateGalleryManager.mjs:53-97` (`createTemplateFromProject`) | `POST /template/new/:Project_id`. Kopiuje ustawienia projektu (`TemplateGalleryHelper.mjs:94-134`), przesyła zip i PDF do filestore i zapisuje. Jeśli nazwa jest zajęta, odpowiada konfliktem, chyba że klient poprosił o nadpisanie: wtedy aktualizuje ten szablon, zwiększa jego `version`, a następnie usuwa pliki poprzedniej wersji. |
| `TemplateGalleryManager.mjs:21-47` (`editTemplate`) | `POST /template/:template_id/edit`. Przypisuje przesłane pola do dokumentu, ponownie renderuje `description` i `author` oraz ustawia `lastUpdated`. Formularz edycji przesyła zmienione pola spośród `name`, `license`, `category`, `language`, `authorMD` i `descriptionMD` (`services/web/modules/template-gallery/frontend/js/pages/template/util/api.ts:22-29`). |
| `TemplateGalleryHelper.mjs:186-222` (`deleteTemplateAssets`) | `DELETE /template/:template_id/delete` usuwa dokument i pliki podanej wersji (`TemplateGalleryManager.mjs:49-51`). |

Tylko administratorzy witryny i użytkownik z `OVERLEAF_TEMPLATES_USER_ID` mogą wywoływać te trzy trasy (`services/web/modules/template-gallery/app/src/Router.mjs:55-62,70-84`, `PermissionsMiddleware.mjs:8-19`).

#### Kto odczytuje {#who-reads-it}

| Kod | Co robi |
| ---- | ------------ |
| `TemplateGalleryManager.mjs:158-183` (`getTemplate`) | Znajduje jeden szablon po `_id` lub `name` dla strony szablonu i dla `GET /api/template` (`services/web/modules/template-gallery/app/src/TemplateGalleryController.mjs:210-232`). Jeśli `project_id` wskazuje projekt, który już nie istnieje, odpowiedź go pomija; dokument nie jest zmieniany. |
| `TemplateGalleryManager.mjs:190-236` (`getCategoryTemplates`) | `GET /api/templates`: jedna strona kategorii, przeszukiwana w `name`, `authorMD` i `descriptionMD`, sortowana według `lastUpdated` lub `name` (bez rozróżniania wielkości liter). |
| `TemplateGalleryHelper.mjs:64-80` (`canUserOverrideTemplate`) | Odczytuje `owner`, aby podać właściciela w komunikacie o konflikcie. |

#### Indeksy {#indexes}

| Nazwa | Klucze | Opcje | Migracja |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | domyślny |

`autoIndex` w Mongoose jest wyłączone (`services/web/app/src/infrastructure/Mongoose.mjs:7`). `tools/migrations/20190912145030_create_templates_indexes.mjs` (unikalne `project_id`, `user_id`, `name`) ma tagi `server-pro` i `saas`, więc nie działa w CE, które uruchamia tylko migracje `server-ce` (`server-ce/init_scripts/900_run_web_migrations.sh`).

#### Uwagi {#notes}

* Upstream traktuje `templates` jako przestarzałą kolekcję i usuwa ją na własnej witrynie (`tools/migrations/20241002180623_drop_unused_collections.mjs`, z tagiem `saas`). W Ayakaleaf Pro używa jej moduł galerii szablonów.
* Sortowanie po nazwie używa porównywania bez rozróżniania wielkości liter, a komentarz przy `TemplateGalleryManager.mjs:186-188` zauważa, że indeks `name` potrzebowałby tego samego. CE nie ma indeksu `name`, więc Mongo sortuje w pamięci.
* Usunięcie projektu źródłowego lub właściciela nie usuwa szablonu.
