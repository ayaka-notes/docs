Przechowuje powiadomienia wyświetlane użytkownikom na liście projektów (na przykład zaproszenia do projektów) w kolekcji Mongo `notifications`. Wywołują go web i third-party-datastore; nie ma uwierzytelniania i jest dostępny tylko wewnątrz sieci Docker.

* <strong>Adres:</strong> `http://notifications:3042`, wewnątrz sieci Docker
* <strong>Uwierzytelnianie:</strong> brak
* <strong>Plik OpenAPI:</strong> [`develop/hoppscotch/openapi/notifications.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/notifications.yaml)
