Kolejkuje w Redis zmiany każdego projektu, zamienia je na zmiany historii i wysyła do history-v1; przechowuje też w Mongo etykiety historii, stan ponownej synchronizacji i rekordy błędów. Wywołują go web, document-updater, history-v1 i skrypty cron server-ce; nie ma uwierzytelniania.

* <strong>Adres:</strong> `http://project-history:3054`, wewnątrz sieci Docker
* <strong>Uwierzytelnianie:</strong> brak
* <strong>Plik OpenAPI:</strong> [`develop/hoppscotch/openapi/project-history.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/project-history.yaml)
