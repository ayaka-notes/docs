Przechowuje pełną historię każdego projektu: fragmenty zmian w Mongo lub Postgres i w magazynie obiektów oraz zawartość plików jako bloby. project-history zapisuje do niego zmiany; web, project-history i git-bridge odczytują z niego bloby, migawki i pliki zip.

* <strong>Adres:</strong> `http://history-v1:3100`, wewnątrz sieci Docker
* <strong>Uwierzytelnianie:</strong> HTTP basic auth jako `staging` z `STAGING_PASSWORD` lub JWT, zależnie od trasy.
* <strong>Plik OpenAPI:</strong> [`develop/hoppscotch/openapi/history-v1.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/history-v1.yaml)
