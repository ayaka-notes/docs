Przechowuje czat projektu i wątki komentarzy (ich wiadomości i stan rozwiązania) w kolekcjach Mongo `rooms` i `messages`. Wywoływany przez web za pomocą `ChatApiHandler`.

* <strong>Adres:</strong> `http://chat:3010`, wewnątrz sieci Docker
* <strong>Uwierzytelnianie:</strong> brak
* <strong>Plik OpenAPI:</strong> [`develop/hoppscotch/openapi/chat.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/chat.yaml)
