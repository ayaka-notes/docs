title: docstore
icon: database
---

Przechowuje każdy dokument (wiersze, wersję, zakresy) każdego projektu w kolekcji Mongo `docs` i archiwizuje dokumenty w magazynie obiektów, gdy ustawiono backend. Wywoływany przez web; document-updater łączy się z nim przez web.

* <strong>Adres:</strong> `http://docstore:3016`, wewnątrz sieci Docker
* <strong>Uwierzytelnianie:</strong> brak
* <strong>Plik OpenAPI:</strong> [`develop/hoppscotch/openapi/docstore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/docstore.yaml)
