Pobiera zewnętrzny adres URL dla web i przesyła odpowiedź strumieniowo, odrzucając adresy wewnętrzne, aby użytkownicy nie mogli dostać się do sieci Docker. Web przepuszcza przez niego pliki URL, importy Open in Overleaf i web_fetch agenta AI.

* <strong>Adres:</strong> `http://linked-url-proxy:3066`, wewnątrz sieci Docker
* <strong>Uwierzytelnianie:</strong> brak
* <strong>Plik OpenAPI:</strong> [`develop/hoppscotch/openapi/linked-url-proxy.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/linked-url-proxy.yaml)
