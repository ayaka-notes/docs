Przechowuje w Redis dokumenty otwarte w edytorze, stosuje do nich zmiany i zapisuje je z powrotem w Mongo przez web. Wywoływany przez web i real-time.

* <strong>Adres:</strong> `http://document-updater:3003`, wewnątrz sieci Docker
* <strong>Uwierzytelnianie:</strong> brak
* <strong>Plik OpenAPI:</strong> [`develop/hoppscotch/openapi/document-updater.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/document-updater.yaml)
