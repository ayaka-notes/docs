CLSI (Common LaTeX Service Interface) kompiluje projekty, uruchamia SyncTeX i texcount na wyniku kompilacji oraz konwertuje dokumenty za pomocą pandoc. Wywołuje go web; same pliki wynikowe serwuje clsi-nginx, a nie ten port. Brak uwierzytelniania: jest dostępny tylko wewnątrz sieci Docker.

* <strong>Adres:</strong> `http://clsi:3013`, wewnątrz sieci Docker
* <strong>Uwierzytelnianie:</strong> brak
* <strong>Plik OpenAPI:</strong> [`develop/hoppscotch/openapi/clsi.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/clsi.yaml)
