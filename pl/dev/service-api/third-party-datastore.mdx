Synchronizuje projekty z Dropbox: utrzymuje jedną kolejkę zadań Redis na użytkownika i workera, który wysyła zmiany z Overleaf do Dropbox i odpytuje Dropbox o zmiany. Wywołuje go tylko web, aby dodawać zadania do kolejki i odczytywać rozmiary kolejek.

* <strong>Adres:</strong> `http://third-party-datastore:3002`, wewnątrz sieci Docker
* <strong>Uwierzytelnianie:</strong> brak
* <strong>Plik OpenAPI:</strong> [`develop/hoppscotch/openapi/third-party-datastore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/third-party-datastore.yaml)
