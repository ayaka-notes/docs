Prywatne API web, głównej aplikacji Overleaf. Wywołują je inne usługi (real-time, document-updater, project-history, third-party-datastore, git-bridge) oraz skrypty cron obrazu Server CE. Te trasy wymagają tylko HTTP basic auth, bez tokenu CSRF: prywatny router jest montowany przed routerem web, a kontrolę CSRF wykonuje tylko router web. Przy `BLOCK_CROSS_ORIGIN_REQUESTS=true` (domyślnie wyłączone) web zwraca 403 dla każdego żądania, którego nagłówek `Origin` nie znajduje się w `ALLOWED_ORIGINS` (domyślnie: adres URL witryny). Przeglądarki wysyłają `Origin` przy POST, więc po włączeniu tej opcji żądania POST wysyłane z Hoppscotch w przeglądarce otrzymują 403, chyba że przechodzą przez proxy Hoppscotch.

* <strong>Adres:</strong> `http://web:3000`, wewnątrz sieci Docker
* <strong>Uwierzytelnianie:</strong> HTTP basic auth z `WEB_API_USER` i `WEB_API_PASSWORD`, z wyjątkiem status, health i metrics. Trasy git-bridge używają zamiast tego osobistego tokenu dostępu.
* <strong>Plik OpenAPI:</strong> [`develop/hoppscotch/openapi/web.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/web.yaml)
