Serwuje pliki z magazynu obiektów: pliki szablonów (zip, pdf i ich obrazy podglądu) oraz, tylko do odczytu, bloby projektowe i globalne zapisywane przez history-v1. Wywoływany przez web (moduł template-gallery, adresy URL plików kompilacji) i przez clsi, który pobiera z niego binarne pliki projektu.

* <strong>Adres:</strong> `http://filestore:3009`, wewnątrz sieci Docker
* <strong>Uwierzytelnianie:</strong> brak
* <strong>Plik OpenAPI:</strong> [`develop/hoppscotch/openapi/filestore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/filestore.yaml)
