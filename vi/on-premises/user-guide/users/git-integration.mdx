Làm việc với dự án trên máy tính của bạn bằng Git. Thay đổi chỉ được chuyển khi bạn chạy `git pull` hoặc `git push`.

<Info>

Quản trị viên phải bật [tích hợp Git](/vi/on-premises/configuration/overleaf-toolkit/integrations/git-integration) trước.

</Info>

## Tạo token {#create-a-token}

Git đăng nhập bằng token xác thực Git, không phải bằng mật khẩu tài khoản của bạn.

<Steps>
<Step title="Mở cài đặt tài khoản">
Nhấp vào **Account**, sau đó **Account settings**. Trong **Git integration**, nhấp vào **Generate token**. Khi bạn đã có token, nút này có tên **Add another token**.

<Frame caption="Tích hợp Git trong cài đặt tài khoản">
  <img src="/images/on-premises/git-integration-settings.png" alt="Mục Git integration trong cài đặt tài khoản với nút Generate token" />
</Frame>
</Step>

<Step title="Sao chép token">
Nhấp vào **Copy** và cất token ở nơi an toàn. Bạn chỉ thấy token một lần. Sau đó nhấp vào **Close**.

<Frame caption="Token mới của bạn">
  <img src="/images/on-premises/git-integration-token.png" alt="Hộp thoại token xác thực Git với nút Copy" />
</Frame>
</Step>

<Step title="Kiểm tra token">
Danh sách giờ hiển thị phần đầu của token, thời điểm tạo và lần sử dụng gần nhất. Token hết hạn sau một năm. Bạn có thể có tối đa 10 token.

<Frame caption="Các token của bạn">
  <img src="/images/on-premises/git-integration-tokens.png" alt="Danh sách token với một token" />
</Frame>
</Step>
</Steps>

## Sao chép dự án {#clone-a-project}

<Steps>
<Step title="Mở tích hợp Git trong trình soạn thảo">
Mở dự án. Ở thanh bên trái, nhấp vào **Integrations**, sau đó **Git integration**.

<Frame caption="Bảng Integrations">
  <img src="/images/on-premises/git-integration-panel.png" alt="Bảng Integrations với thẻ Git integration" />
</Frame>
</Step>

<Step title="Sao chép lệnh">
Hộp thoại **Clone with Git** hiển thị lệnh, kèm địa chỉ trang của bạn và ID của dự án. Nhấp vào **Copy**. Nếu bạn chưa có token, **Go to settings** mở cài đặt tài khoản trong một tab mới.

<Frame caption="Lệnh sao chép">
  <img src="/images/on-premises/git-integration-clone.png" alt="Hộp thoại Clone with Git với lệnh git clone" />
</Frame>
</Step>

<Step title="Chạy lệnh">
Dán lệnh vào terminal. Khi Git hỏi mật khẩu, hãy dán token của bạn.

```text
$ git clone https://git@<your-site>/git/<project-id>
Cloning into '<project-id>'...
Password for 'https://git@<your-site>': <your-token>
```

Một thư mục mang tên ID dự án giờ chứa các tệp của dự án, trên nhánh `main`. Để chọn tên thư mục, hãy thêm tên vào cuối lệnh.
</Step>
</Steps>

Git hỏi token mỗi lần kết nối với trang. Để token được ghi nhớ, hãy bật credential helper: Git hỏi thêm một lần, sau đó giữ token. Helper `store` lưu token ở dạng không mã hóa trong `~/.git-credentials`.

```bash
git config --global credential.helper store
```

## Kéo thay đổi từ trình soạn thảo {#pull-changes-from-the-editor}

Bên trong thư mục, chạy:

```bash
git pull
```

Git liệt kê các tệp đã thay đổi. Thay đổi thực hiện trong trình soạn thảo đến dưới dạng các commit có tên `Update on Overleaf.`.

```text
Updating db007e3..c3e6332
Fast-forward
 main.tex | 2 +-
 1 file changed, 1 insertion(+), 1 deletion(-)
```

## Đẩy thay đổi của bạn {#push-your-changes}

Commit các thay đổi, sau đó push:

```bash
git add main.tex
git commit -m "Add a line from Git"
git push
```

Dòng cuối của đầu ra cho biết nhánh đã di chuyển:

```text
   53aca61..db007e3  main -> main
```

Thay đổi xuất hiện trong trình soạn thảo, và trình soạn thảo đang mở tự cập nhật. Tệp, thư mục mới và việc đổi tên xuất hiện trong cây tệp. Trong **History**, thay đổi của bạn được đánh dấu <strong>You (via Git)</strong>. Thông điệp commit của bạn không hiển thị ở đó.

### Nếu Git từ chối push của bạn {#if-git-refuses-your-push}

Nếu dự án đã thay đổi trong lúc đó, Git từ chối push:

```text
 ! [rejected]        main -> main (fetch first)
```

Hãy lấy những thay đổi đó trước, sau đó push lại:

```bash
git pull --no-rebase --no-edit
git push
```

Một lệnh `git pull` đơn thuần có thể dừng với `fatal: Need to specify how to reconcile divergent branches.` Tùy chọn `--no-rebase` ở trên giải quyết điều đó: nó hợp nhất hai phía.

Nếu cùng các dòng đã thay đổi ở cả hai phía, pull dừng với `CONFLICT (content): Merge conflict in main.tex`. Sửa tệp, sau đó chạy:

```bash
git add main.tex
git commit -m "Merge the changes from the editor"
git push
```

Có hai điều trang không chấp nhận:

* Nhánh khác: `! [remote rejected] feature -> feature (wrong branch)`. Chỉ có `main`, vì vậy hãy push công việc của bạn lên đó.
* Force push: `! [remote rejected] main -> main (forced push prohibited)`. Thay vào đó, hãy đặt thay đổi của bạn lên trên `main` hiện tại.

### Nếu Git báo Authentication failed {#if-git-says-authentication-failed}

```text
remote: Enter your Git authentication token when prompted for a password.
fatal: Authentication failed for 'https://<your-site>/git/<project-id>/'
```

Token sai hoặc đã bị xóa, hoặc bạn đã nhập mật khẩu tài khoản. Hãy tạo token mới nếu bạn không còn token, vì bạn không thể xem lại token hiện có.

## Xóa token {#delete-a-token}

Trong **Account settings**, ở mục **Git integration**, nhấp vào biểu tượng xóa bên cạnh token, sau đó nhấp **Delete** trong hộp thoại. Từ đó trở đi, Git trả lời `Authentication failed` cho token đó.
