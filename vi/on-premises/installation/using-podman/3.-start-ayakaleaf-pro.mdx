---
title: 3. Khởi động Ayakaleaf Pro
description: Khởi động Ayakaleaf Pro trên Podman, xác minh bằng podman-setup và bin/doctor, và khởi động nó sau khi reboot.
icon: circle-play
---

<Steps>
<Step title="Khởi động các container">
```bash title="Start Ayakaleaf Pro"
bin/up -d
```

Lần khởi động đầu tiên tải các image MongoDB, Redis và TeX Live, và tạo các thư mục dữ liệu trong `data/`. Nó in ra một cảnh báo rằng hỗ trợ Podman đang ở giai đoạn thử nghiệm.

<Info>

Lần khởi động đầu tiên cũng có thể in ra `MongoNetworkError: connect ECONNREFUSED 127.0.0.1:27017`. Toolkit thiết lập replica set của MongoDB trong khi MongoDB vẫn đang khởi động, và thử lại cho đến khi nó phản hồi. Bạn có thể bỏ qua dòng này.

</Info>

Sau một hoặc hai phút, kiểm tra rằng các container đang chạy:

```bash title="List the containers"
podman ps --format "{{.Names}} {{.Status}}"
```

```text
mongo Up 34 seconds (healthy)
redis Up 20 seconds
sharelatex Up 20 seconds
```
</Step>

<Step title="Kiểm tra lại thiết lập">
Giờ các thư mục dữ liệu đã tồn tại và container `sharelatex` đang chạy, `bin/podman-setup` có thể hoàn tất các kiểm tra:

```bash title="Check the setup"
bin/podman-setup
```

Nó kiểm tra chủ sở hữu của các thư mục dữ liệu mới và kiểm thử socket Podman từ bên trong container `sharelatex`:

```text
====== Socket Connectivity ======
[✓] host → socket OK
[✓] container → socket OK

====== Data Directory Permissions ======
[✓] mongo data dir owned by 999
[✓] redis data dir owned by 999
[✓] overleaf data dir owned by 33
...
====== Summary ======
[✓] 27 passed  [!] 1 warnings  [✗] 0 failures
[!] Warnings:
[!] not logged in to quay.io
```

`container → socket OK` nghĩa là Ayakaleaf Pro có thể khởi chạy các container biên dịch. Nếu một kiểm tra thất bại, hãy chạy `bin/podman-setup --apply`, rồi `bin/up -d`. Cảnh báo quay.io không áp dụng cho Ayakaleaf Pro, xem [2. Chạy podman-setup](/vi/on-premises/installation/using-podman/2.-run-podman-setup).
</Step>

<Step title="Chạy doctor">
```bash title="Run the doctor"
bin/doctor
```

Trên Podman, báo cáo hiển thị môi trường chạy và các thiết lập bảo mật:

```text
- Container Daemon
    - status: up
    - runtime: podman
    - server version: 5.8.5
    - socket: /run/user/1000/podman/podman.sock
    - DOCKER_HOST: unix:///run/user/1000/podman/podman.sock
    - host → socket: OK
    - container → socket: OK
- Security
    - SELinux: Enforcing
    - SELINUX_MODE: managed
    - SELINUX_LABEL: sharelatex_t
    - SELinux module: loaded (podman_socket_clsi)
    - SELinux rules: present
    - Seccomp profile: present
```

Cảnh báo `Server Pro enabled, but not logged in to quay.io repository` ở cuối là cùng một kiểm tra quay.io, xem [Nhận trợ giúp](/vi/on-premises/support/getting-help#q-and-a).
</Step>

<Step title="Khởi động Ayakaleaf Pro sau khi reboot">
Với Docker, Docker daemon khởi động lại các container sau khi reboot. Podman không cần root không có daemon: hãy bật dịch vụ người dùng khởi động các container của bạn khi máy chủ khởi động:

```bash title="Start the containers at boot"
systemctl --user enable podman-restart.service
```

Nó khởi động mọi container của người dùng bạn có chính sách khởi động lại là `always`, chính sách mà Toolkit đặt cho tất cả container của nó. Việc này cần lingering, thứ mà `bin/podman-setup --apply` đã bật. Nếu không có dịch vụ này, hãy chạy `bin/up -d` sau mỗi lần reboot.
</Step>

<Step title="Mở cổng trên tường lửa">
Theo mặc định, phiên bản chỉ chấp nhận kết nối từ chính máy chủ, tại `http://localhost:8080`. Để mở nó cho các máy tính khác, hãy đặt `OVERLEAF_LISTEN_IP` trong `config/overleaf.rc` và `OVERLEAF_SITE_URL` trong `config/variables.env` như mô tả trong [5. Cá nhân hóa phiên bản của bạn](/vi/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance#listen-address-and-port), rồi chạy lại `bin/up -d`.

Không giống Docker, Podman không cần root không bỏ qua tường lửa của máy chủ. Nếu `firewalld` đang chạy, như mặc định trên RHEL, hãy mở cổng:

```bash title="Open port 8080"
sudo firewall-cmd --permanent --add-port=8080/tcp
sudo firewall-cmd --reload
```

Trên máy chủ đám mây, hãy cho phép cổng trong security group của nhà cung cấp. Dùng HTTPS trước khi công khai phiên bản ra Internet, xem [4. Các tác vụ sau cài đặt](/vi/on-premises/installation/using-podman/4.-post-installation-tasks#use-https).
</Step>
</Steps>
