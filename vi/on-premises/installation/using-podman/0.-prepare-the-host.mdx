Bạn không cài Podman thủ công: [2. Chạy podman-setup](/vi/on-premises/installation/using-podman/2.-run-podman-setup) sẽ cài nó cùng các gói khác cần thiết. Ở đây bạn chỉ kiểm tra máy chủ và cài `git`, thứ bạn cần để tải Toolkit.

<Steps>
<Step title="Kiểm tra hệ điều hành và SELinux">
Đăng nhập bằng người dùng sẽ chạy Ayakaleaf Pro, không phải `root`, và kiểm tra bản phân phối cùng chế độ SELinux:

```bash title="Check the host"
grep PRETTY_NAME /etc/os-release
getenforce
```

Bạn sẽ thấy RHEL, Rocky Linux, AlmaLinux hoặc CentOS Stream phiên bản 9 trở lên, và `Enforcing`:

```text
PRETTY_NAME="Rocky Linux 9.9 (Blue Onyx)"
Enforcing
```
</Step>

<Step title="Kiểm tra rằng bạn có thể dùng sudo">
`bin/podman-setup --apply` cài các gói và nạp một module SELinux bằng `sudo`, và hỏi mật khẩu của bạn khi cần:

```bash title="Check sudo"
sudo -v
```

Nếu lệnh này thất bại, hãy nhờ quản trị viên thêm người dùng của bạn vào nhóm `wheel`.
</Step>

<Step title="Cài đặt git">
```bash title="Install git"
sudo dnf install -y git
```

<Warning>

Đừng cài Docker Engine trên máy chủ này. Gói `podman-docker`, do `bin/podman-setup` cài, cung cấp lệnh `docker`, và Toolkit coi máy chủ là Podman bất cứ khi nào lệnh `podman` tồn tại.

</Warning>
</Step>
</Steps>
