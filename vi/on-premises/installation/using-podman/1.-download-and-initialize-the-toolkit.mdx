<Steps>
<Step title="Clone Toolkit">
Clone **Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)) vào thư mục home của bạn và chuyển vào đó:

```bash title="Clone the Toolkit" wrap
git clone https://github.com/ayaka-notes/toolkit.git ~/overleaf-toolkit
cd ~/overleaf-toolkit
```

Chạy tất cả các lệnh tiếp theo từ thư mục này.
</Step>

<Step title="Tạo cấu hình">
```bash title="Run initialization"
bin/init
```

Lệnh này tạo `config/overleaf.rc`, `config/variables.env` và `config/version`, như mô tả trong [3. Khởi tạo cấu hình](/vi/on-premises/installation/using-docker-compose/linux/3.-initialize-the-configuration) của hướng dẫn Docker. `bin/init` chưa cần Podman.
</Step>

<Step title="Thiết lập config/overleaf.rc">
Mở `config/overleaf.rc` và thay đổi các dòng sau:

```bash title="config/overleaf.rc"
SERVER_PRO=true
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
```

Sau đó thêm dòng này vào cuối tệp:

```bash title="config/overleaf.rc"
SELINUX_MODE=managed
```

| Thiết lập                         | Lý do                                                                                                                                                                                                       |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SERVER_PRO=true`                 | Dùng image Ayakaleaf Pro từ `ghcr.io`. Không cần đăng nhập.                                                                                                                                                  |
| `OVERLEAF_PORT=8080`              | Podman không cần root không thể lắng nghe trên các cổng dưới `1024`. Cổng mặc định `80` sẽ thất bại.                                                                                                         |
| `SIBLING_CONTAINERS_ENABLED=true` | Chạy mỗi lần biên dịch trong một container TeX Live riêng. Mặc định đã là `true`; thiết lập Podman chỉ hỗ trợ chế độ này.                                                                                    |
| `SELINUX_MODE=managed`            | Chạy container `sharelatex` với kiểu SELinux `sharelatex_t`, kiểu này được phép dùng socket Podman và không gì khác. `bin/podman-setup --apply` cài module chính sách cho nó. Xem [Cài đặt Toolkit](/vi/on-premises/configuration/overleaf-toolkit/toolkit-settings) cho các chế độ khác. |

Giữ nguyên `DOCKER_SOCKET_PATH`: `bin/podman-setup --apply` sẽ đặt nó thành socket Podman của bạn ở bước tiếp theo.

<Warning>

Giữ `GIT_BRIDGE_ENABLED=false`. Trong Ayakaleaf Pro 6.3.4, tích hợp Git không hoạt động trên Podman, xem [Hạn chế đã biết](/vi/on-premises/installation/using-podman#known-limitations).

</Warning>
</Step>

<Step title="Chọn image TeX Live">
Mở `config/variables.env`, xóa `#` phía trước `TEX_LIVE_DOCKER_IMAGE` và `ALL_TEX_LIVE_DOCKER_IMAGES`, và liệt kê các image TeX Live sẽ dùng:

```bash title="config/variables.env" wrap
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
```

`bin/up` dừng với `Please configure ALL_TEX_LIVE_DOCKER_IMAGES` nếu danh sách trống. `texlive-full` rất lớn; với máy chủ thử nghiệm, image nhỏ hơn nhiều `ghcr.io/ayaka-notes/texlive-basic:2026.1` cũng dùng được. Xem [Biên dịch trong sandbox](/vi/on-premises/configuration/overleaf-toolkit/sandboxed-compiles) để biết các image có sẵn.

Đặt các biến khác, chẳng hạn `OVERLEAF_SITE_URL`, như mô tả trong [5. Cá nhân hóa phiên bản của bạn](/vi/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance#required-environment-variables). Với địa chỉ lắng nghe mặc định, hãy dùng `http://localhost:8080`.
</Step>
</Steps>
