`bin/podman-setup` kiểm tra mọi thứ Ayakaleaf Pro cần trên Podman. Khi không có tùy chọn, nó chỉ báo cáo; với `--apply`, nó còn sửa những gì tìm thấy.

<Steps>
<Step title="Kiểm tra máy chủ">
```bash title="Check only"
bin/podman-setup
```

Trên một máy chủ mới, hầu hết các kiểm tra đều thất bại, ví dụ:

```text
====== Packages ======
[✗] podman not installed
[✗] podman-docker not installed
...
====== Summary ======
[✓] 7 passed  [!] 13 warnings  [✗] 4 failures
```
</Step>

<Step title="Áp dụng các bản sửa">
```bash title="Check and fix"
bin/podman-setup --apply
```

Hãy chạy nó trong terminal: nó hỏi mật khẩu `sudo` của bạn cho các bước trên toàn hệ thống. Nó cũng tải image Ayakaleaf Pro để trích xuất hồ sơ seccomp, việc này mất vài phút ở lần đầu. Cuối cùng nó kiểm tra lại máy chủ:

```text
====== Summary ======
[✓] 23 passed  [!] 2 warnings  [✗] 0 failures
[!] Warnings remaining:
[!] not logged in to quay.io
[!] container → socket skipped (sharelatex not running)
```

Cả hai cảnh báo đều là bình thường ở thời điểm này:

* `not logged in to quay.io`: kiểm tra này đến từ Toolkit chính thức, nơi image Server Pro nằm trên một registry riêng tư. Các image Ayakaleaf Pro là công khai trên `ghcr.io` và không cần đăng nhập, nên hãy bỏ qua nó. Nó vẫn còn sau khi cài đặt.
* `container → socket skipped (sharelatex not running)`: kiểm thử này cần phiên bản đang chạy. Bạn sẽ chạy lại script trong [3. Khởi động Ayakaleaf Pro](/vi/on-premises/installation/using-podman/3.-start-ayakaleaf-pro).

Script thoát với `0` khi mọi kiểm tra đều đạt, `1` khi có cảnh báo và `2` khi có lỗi. Vì cảnh báo quay.io, hãy chờ đợi `1`.
</Step>
</Steps>

### Những gì script thay đổi {#what-the-script-changes}

Với `--apply`, script có thể thay đổi những điều sau.

Trên toàn hệ thống, bằng `sudo`:

* Cài `podman`, `podman-docker`, `git`, `curl`, `checkpolicy` và `policycoreutils` bằng `dnf`.
* Bật lingering cho người dùng của bạn bằng `loginctl`, để các container tiếp tục chạy sau khi bạn đăng xuất.
* Tạo `/etc/containers/nodocker`, giúp ẩn thông báo "Emulate Docker CLI using podman".
* Nạp module chính sách SELinux `podman_socket_clsi`, khi `SELINUX_MODE=managed`.

Cho người dùng của bạn:

* Bật dịch vụ người dùng `podman.socket`, API tương thích Docker mà Ayakaleaf Pro dùng để khởi chạy biên dịch.
* Cài Docker Compose v2 từ GitHub vào `~/.local/bin/docker-compose`, và liên kết nó trong `~/.docker/cli-plugins/`.
* Khiến Podman dùng Compose này trong `~/.config/containers/containers.conf`.
* Thêm các bí danh `mongo` và `redis` trong `~/.config/containers/registries.conf.d/overleaf-toolkit.conf`, để Podman biết nơi kéo các tên image ngắn này.

Trong Toolkit:

* Đặt `DOCKER_SOCKET_PATH` và `DOCKER_HOST` trong `config/overleaf.rc` thành `/run/user/<uid>/podman/podman.sock`.
* Trích xuất hồ sơ seccomp cho biên dịch từ image Ayakaleaf Pro vào `config/seccomp/<version>/clsi-profile.json`, và đặt `SECCOMP_PROFILE` trong `config/variables.env`. Không giống Docker, Podman cần hồ sơ này dưới dạng một tệp trên máy chủ.
* Build module chính sách SELinux trong `config/selinux/`.
* Đặt chủ sở hữu của các thư mục dữ liệu trong `data/` bằng `podman unshare chown`, khi chúng đã tồn tại.

<Info>

Mỗi thay đổi tương ứng với một kiểm tra. Nếu bạn thay đổi gì đó thủ công, ví dụ trong `config/overleaf.rc`, hãy chạy lại `bin/podman-setup` để xác minh.

</Info>
