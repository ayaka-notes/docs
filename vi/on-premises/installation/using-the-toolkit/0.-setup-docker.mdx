Overleaf chạy trên Docker. Bạn phải cài đặt:

* Docker Engine (Docker CE)
* Plugin Docker Compose (`docker compose`, v2)

Các bước này dành cho phiên bản Ubuntu LTS gần đây (20.04/22.04/24.04).

<Warning>

Tránh cài đặt `docker.io` từ kho apt mặc định của Ubuntu.\
Hãy sử dụng kho chính thức của Docker để có phiên bản Docker mới và plugin `docker compose`.

</Warning>

Tài liệu chính thức có tại: [https://docs.docker.com/engine/install/ubuntu/](https://docs.docker.com/engine/install/ubuntu/).

<Steps>
<Step title="1) Gỡ bỏ các gói cũ/xung đột (nếu có)">
Nếu Docker đã được cài đặt trước đó từ một nguồn khác, hãy gỡ bỏ trước:

```bash wrap
sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-compose-v2 docker-doc podman-docker containerd runc | cut -f1)
```

Lệnh này vẫn an toàn nếu một số gói chưa được cài đặt.
</Step>

<Step title="2) Thêm kho apt chính thức của Docker">
Cài đặt các gói tiên quyết:

```bash
sudo apt update
sudo apt install -y ca-certificates curl
```

Thêm khóa GPG của Docker:

```bash wrap
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```

Thêm kho:

```bash wrap
# Add the repository to Apt sources:
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Signed-By: /etc/apt/keyrings/docker.asc
EOF

sudo apt update
```
</Step>

<Step title="3) Cài đặt Docker Engine + plugin Compose">
Cài đặt Docker và plugin Compose:

```bash wrap
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

Khởi động Docker cùng hệ thống:

```bash
sudo systemctl enable --now docker
```
</Step>

<Step title="4) Kiểm tra cài đặt">
Các lệnh sau sẽ chạy mà không có lỗi:

```bash
docker --version
docker compose version
sudo docker run --rm hello-world
docker ps
```
</Step>

<Step title="5) (Tùy chọn) Chạy Docker không cần sudo">
Thêm người dùng của bạn vào nhóm `docker`:

```bash
sudo usermod -aG docker $USER
```

Sau đó **đăng xuất và đăng nhập lại**, hoặc chạy:

```bash
newgrp docker
```

Bây giờ lệnh này sẽ hoạt động mà không cần `sudo`:

```bash
docker ps
```

<Danger>

Nhóm `docker` có quyền truy cập tương đương root trên máy host.\
Đây là điều bình thường đối với các bản cài đặt Overleaf thông thường, và đặc biệt liên quan nếu bạn bật Sandboxed Compiles.

</Danger>
</Step>
</Steps>

### Bước tiếp theo

Khi Docker đã hoạt động, hãy tiếp tục với các bước cài đặt Toolkit trong [Sử dụng Toolkit](/vi/on-premises/installation/using-the-toolkit).
