---
title: 4. Tải image Ayakaleaf Pro
icon: split
---

Ayakaleaf Pro được phân phối dưới dạng Docker image trên registry [ghcr](https://github.com/ayaka-notes/overleaf-pro/pkgs/container/overleaf-pro/), **mở cho tất cả mọi người** truy cập. Chúng tôi cung cấp image cho cả hai kiến trúc amd64 và arm64. Khi bạn pull image, image phù hợp sẽ được tự động chọn dựa trên kiến trúc hệ thống của bạn.

#### Người dùng Ayaka-notes Toolkit

Nếu bạn đang sử dụng [ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit), Ayakaleaf Pro có thể được dùng để thay thế trực tiếp cho Community Edition, vì vậy bạn có thể giữ nguyên các thiết lập và tùy chỉnh hiện có. Bật Pro trong Toolkit bằng cách chỉnh sửa `config/overleaf.rc` và đặt biến môi trường `SERVER_PRO`:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

Lần tiếp theo bạn chạy `bin/up`, Toolkit sẽ tự động tải xuống và sử dụng image Ayakaleaf Pro.

#### Người dùng Toolkit chính thức

Nếu bạn đang sử dụng [overleaf/toolkit](https://github.com/overleaf/toolkit), để lấy image Pro, hãy chạy lệnh sau để pull:

```bash title="Pull Docker Images"
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Sau đó, thêm một tệp có tên `docker-compose.override.yml` với nội dung sau vào thư mục `overleaf-toolkit/config`:

```yml title="docker-compose.override.yml"
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

Lần tiếp theo bạn chạy `bin/up`, Toolkit sẽ tự động tải xuống và sử dụng image Ayakaleaf Pro.
