### Tải xuống Toolkit

Toolkit tương thích với cả Server CE và Ayakaleaf Pro, và là phương thức cài đặt được khuyến nghị. Sử dụng Toolkit giúp bạn dễ dàng bắt đầu với Server CE và nâng cấp liền mạch lên Ayakaleaf Pro khi cần.

<Info>

[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) đã được chỉnh sửa để sử dụng trực tiếp image overleaf-pro từ ghcr, với TeX Live do ayaka-notes cung cấp. Ngoài ra, bạn cũng có thể tải overleaf-toolkit chính thức.

</Info>

<Steps>
<Step title="Clone kho lưu trữ Overleaf Toolkit">
Để cài đặt toolkit, bạn cần di chuyển đến đường dẫn cài đặt mong muốn rồi clone kho lưu trữ GitHub Overleaf Toolkit (@Ayaka-notes) bằng lệnh sau:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
# official toolkit (Not Recommended)
# git clone https://github.com/overleaf/toolkit.git ./overleaf-toolkit
```

<Info>

Để tránh các vấn đề tiềm ẩn về quyền truy cập, chúng tôi khuyến nghị cài đặt Toolkit trong thư mục `$HOME` của người dùng.

</Info>
</Step>

<Step title="Chuyển vào thư mục toolkit">
Chờ quá trình clone hoàn tất, sau đó chuyển vào thư mục `overleaf-toolkit` vừa được tạo:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
