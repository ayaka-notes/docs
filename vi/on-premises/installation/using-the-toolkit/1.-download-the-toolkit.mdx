### Tải xuống Toolkit

Bạn cài đặt Ayakaleaf Pro bằng **Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)), một bộ script giúp bạn chạy Overleaf trong Docker.

Theo mặc định, Toolkit khởi chạy Overleaf Community Edition (CE) chính thức miễn phí. [4. Tải image Ayakaleaf Pro](/vi/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images) sẽ chuyển nó sang Ayakaleaf Pro chỉ với một thiết lập.

<Accordion title="Bạn đang chạy Overleaf Toolkit chính thức (overleaf/toolkit)?">

Bạn không cần cài đặt lại. Hãy giữ nguyên bản cài đặt của bạn và làm theo phần cuối của [4. Tải image Ayakaleaf Pro](/vi/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images).

</Accordion>

<Steps>
<Step title="Clone kho lưu trữ Ayakaleaf Toolkit">
Để cài đặt toolkit, bạn cần di chuyển đến đường dẫn cài đặt mong muốn rồi clone kho lưu trữ Ayakaleaf Toolkit bằng lệnh sau:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
```

<Info>

Để tránh các vấn đề tiềm ẩn về quyền truy cập, chúng tôi khuyến nghị cài đặt Toolkit trong thư mục `$HOME` của người dùng.

</Info>
</Step>

<Step title="Chuyển vào thư mục toolkit">
Chờ quá trình clone hoàn tất, sau đó chuyển vào thư mục `overleaf-toolkit` vừa được tạo:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
