<Danger>

Các hướng dẫn sau **chỉ** áp dụng cho các bản cài đặt **Community Edition**. Chúng tôi đặc biệt khuyến nghị người dùng Ayakaleaf Pro bật [Sandboxed Compiles](/vi/on-premises/configuration/overleaf-toolkit/sandboxed-compiles), vì tính năng này cho phép người dùng truy cập các image TeX Live gần như giống hệt với image được dùng trên [overleaf.com](https://www.overleaf.com), đồng thời cô lập các lần biên dịch giữa các dự án để tăng cường bảo mật.

</Danger>

Để tiết kiệm băng thông, cả image Overleaf Community Edition và Ayakaleaf Pro chỉ đi kèm bản cài đặt tối thiểu của [TeX Live](https://www.tug.org/texlive/). Bạn có thể cài thêm gói hoặc nâng cấp lên bản cài đặt TeX Live đầy đủ bằng lệnh [tlmgr](https://www.tug.org/texlive/tlmgr.html) trong container `sharelatex`.

#### Truy cập vào bên trong container sharelatex

Để mở một shell bên trong container `sharelatex`, hãy chạy

```bash
bin/shell
```

Bạn sẽ thấy một dấu nhắc lệnh trông như sau:

```bash
root@309b192d4030:/#
```

Trong các hướng dẫn dưới đây, chúng tôi giả định rằng bạn đang ở trong container.

#### Xác định phiên bản TeX Live hiện tại

TeX Live được phát hành mỗi năm vào khoảng tháng Tư. Các bước sử dụng `tlmgr` sẽ khác nhau tùy thuộc vào việc bạn đang dùng bản phát hành hiện tại hay một bản cũ hơn. Bạn có thể kiểm tra phiên bản TeX Live đang chạy bằng `tlmgr --version`. Ví dụ, bản cài đặt này đang chạy TeX Live 2021:

```bash
# tlmgr --version
tlmgr revision 59291 (2021-05-21 05:14:40 +0200)
tlmgr using installation: /usr/local/texlive/2021
TeX Live (https://tug.org/texlive) version 2021
```

<Info>

Bạn có thể tìm thấy bản phát hành TeX Live hiện tại trên [trang chủ TeX Live](https://www.tug.org/texlive/).

</Info>

Nếu bạn đang chạy một phiên bản TeX Live cũ hơn, bạn có hai lựa chọn. Một phiên bản mới của Docker image Overleaf thường được phát hành ngay sau mỗi bản phát hành TeX Live; bạn có thể chờ phiên bản đó và nâng cấp bản triển khai bằng script `bin/upgrade`, hoặc nếu muốn giữ bản phát hành TeX Live cũ, trước tiên bạn cần chỉ định cho `tlmgr` sử dụng một kho lưu trữ lịch sử. Bạn có thể tìm hướng dẫn thực hiện việc này [tại đây](https://www.tug.org/texlive/acquire.html#past).

#### Cài đặt gói

Để cài đặt TeX Live đầy đủ, hãy chạy lệnh sau bên trong container `sharelatex`:

```text
tlmgr install scheme-full
```

Bạn cũng có thể cài đặt thủ công từng gói riêng lẻ:

```bash
tlmgr install tikzlings tikzmarmots tikzducks
```

<Warning>

Từ bản phát hành `3.3.0` trở đi, việc chạy `tlmgr path add` lại **bắt buộc** sau mỗi lần dùng `tlmgr install`, để tạo symlink chính xác cho tất cả các tệp thực thi vào đường dẫn hệ thống.

</Warning>

Còn nhiều lệnh khác nữa. Tìm hiểu thêm bằng:

```text
tlmgr help
```

Khi hoàn tất, gõ `exit` hoặc nhấn Control-D để thoát shell.

#### Lưu các thay đổi

Những thay đổi bạn vừa thực hiện đã làm thay đổi container `sharelatex`, nhưng chúng chỉ là tạm thời -- chúng sẽ bị mất nếu Docker Compose tạo lại container, chẳng hạn khi cập nhật cấu hình.

Để lưu giữ chúng lâu dài, hãy dùng `docker commit` để lưu các thay đổi thành một Docker image mới:

```bash
cat config/version #5.2.1
docker commit sharelatex sharelatex/sharelatex:5.2.1-with-texlive-full
echo 5.2.1-with-texlive-full > config/version
```

Sau khi commit các thay đổi, hãy cập nhật `config/version` cho phù hợp. Sau đó chạy `bin/up` để tạo lại container `sharelatex`.

<Danger>

Bạn sẽ cần lặp lại các bước này mỗi khi [nâng cấp](https://github.com/overleaf/toolkit/blob/master/doc/upgrading.md) lên một phiên bản Overleaf mới.

</Danger>
