<Steps>
<Step title="Thiết lập container">
Chỉnh sửa các mục hiện có sau trong `config/overleaf.rc`:

```bash title="config/overleaf.rc"
PROJECT_NAME=ayakaleaf-macos
SERVER_PRO=true
OVERLEAF_LISTEN_IP=127.0.0.1
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
DOCKER_SOCKET_PATH=/var/run/docker.sock
```

Hãy giữ các đường dẫn dữ liệu mặc định và các dịch vụ MongoDB và Redis đi kèm. Với `OVERLEAF_LISTEN_IP=127.0.0.1`, chỉ các trình duyệt trên máy Mac này mới có thể mở phiên bản.
</Step>

<Step title="Thiết lập ứng dụng">
Trong `config/variables.env`, đặt các giá trị sau, thay thế mọi mục đang hoạt động có cùng tên:

```dotenv title="config/variables.env"
OVERLEAF_SITE_URL=http://localhost:8080
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES="TeX Live 2026"
```

Tạo một session secret:

```bash
openssl rand -hex 32
```

Thêm kết quả dưới dạng `OVERLEAF_SESSION_SECRET` trong `config/variables.env`. Nếu không có nó, mỗi lần `bin/up` tạo lại container sẽ đăng xuất tất cả người dùng, xem [Biến môi trường](/vi/on-premises/configuration/overleaf-toolkit/environment-variables).

Đối với một phiên bản cục bộ không dùng email, hãy để trống các thiết lập SMTP và `OVERLEAF_EMAIL_FROM_ADDRESS`. Git Bridge, xác thực bên ngoài và các tích hợp khác có thể được thêm sau bằng các [trang cấu hình](/vi/on-premises/configuration/overleaf-toolkit) riêng của chúng.
</Step>

<Step title="Kiểm tra kernel Linux của máy ảo Docker" id="check-the-docker-vms-linux-kernel">
MongoDB chạy trên kernel Linux của máy ảo Docker Desktop, không phải trên macOS. Hãy kiểm tra phiên bản của nó trước lần khởi động đầu tiên:

```bash
docker info --format '{{.KernelVersion}}'
```

MongoDB ghi nhận một sự không tương thích với các kernel Linux từ **6.19 đến 7.0.13**, điều này cũng ảnh hưởng đến MongoDB trong Docker. Cách khắc phục là một kernel **7.0.14 trở lên**, đi kèm với một bản cập nhật Docker Desktop, xem [ghi chú production của MongoDB](https://www.mongodb.com/docs/manual/administration/production-notes/).

Nếu máy ảo Docker của bạn dùng một kernel bị ảnh hưởng, hãy thêm nội dung sau vào `config/docker-compose.override.yml`, hợp nhất với mọi `services` bạn đã có ở đó:

```yaml title="config/docker-compose.override.yml"
services:
  mongo:
    environment:
      GLIBC_TUNABLES: glibc.pthread.rseq=1
```

<Warning>

Hãy cập nhật lên một kernel đã được sửa khi có thể. Nếu kernel của bạn nằm ngoài phạm vi bị ảnh hưởng, cách khắc phục tạm thời này là không cần thiết.

</Warning>
</Step>

<Step title="Khởi động phiên bản của bạn">
Từ thư mục Toolkit, hãy chạy:

```bash
bin/up -d
```

Toolkit khởi tạo replica set của MongoDB, pull TeX Live image và khởi động ứng dụng. Lần tải xuống đầu tiên sẽ mất một lúc. Để theo dõi tiến trình:

```bash
bin/docker-compose ps
bin/docker-compose logs --tail=100 -f sharelatex
```

Nhấn `Ctrl+C` để ngừng theo dõi log. Các container vẫn tiếp tục chạy.

Kiểm tra cổng được publish và trang chạy lần đầu:

```bash
bin/docker-compose port sharelatex 80
curl -I http://localhost:8080/launchpad
```

Cổng phải là `127.0.0.1:8080`.
</Step>
</Steps>

<Info>

Để mở phiên bản từ các máy tính khác sau này, hãy thay đổi địa chỉ lắng nghe và URL trang web, đồng thời thiết lập HTTPS, như mô tả trong [5. Cá nhân hóa phiên bản của bạn](/vi/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance) của hướng dẫn cho Linux. Khi đó máy Mac phải luôn thức, xem [Giữ cho phiên bản luôn khả dụng](/vi/on-premises/installation/using-docker-compose/macos/6.-post-installation-tasks#keep-the-instance-available).

</Info>
