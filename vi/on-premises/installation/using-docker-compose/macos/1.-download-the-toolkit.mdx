<Steps>
<Step title="Kiểm tra Git và Homebrew">
```bash
git --version
brew --version
```

Nếu macOS yêu cầu bạn cài đặt Command Line Tools khi chạy Git, hãy cài đặt chúng trước. Nếu chưa có Homebrew, hãy cài đặt nó theo [hướng dẫn chính thức](https://brew.sh/).
</Step>

<Step title="Đưa GNU sed vào PATH">
Các script của Toolkit sử dụng các tùy chọn GNU sed mà BSD sed tích hợp sẵn trong macOS không chấp nhận. Hãy cài đặt [GNU sed](https://formulae.brew.sh/formula/gnu-sed) và đặt nó lên đầu `PATH` trong terminal này:

```bash
brew install gnu-sed
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
sed --version
```

Lệnh cuối cùng phải in ra **GNU sed**.

Một alias như `alias sed=gsed` là không đủ: Toolkit chạy các script Bash, vốn không nhìn thấy các alias của shell tương tác của bạn. Bạn không cần thay thế `/usr/bin/sed`.

Hãy chạy lại dòng `export PATH=...` trong mỗi terminal mới mà bạn dùng cho Toolkit, hoặc thêm nó vào tệp khởi động shell của bạn sau phần khởi tạo của chính Homebrew.
</Step>

<Step title="Clone kho lưu trữ Ayakaleaf Toolkit">
Hãy chọn một thư mục lưu trữ lâu dài. Tránh `/tmp`, các ổ đĩa rời và các thư mục đồng bộ đám mây như iCloud Drive cho cơ sở dữ liệu và dữ liệu dự án đang hoạt động. Hướng dẫn này sử dụng `~/ayakaleaf-toolkit`:

```bash
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

<Warning>

Nếu thư mục đã chứa một bản cài đặt, hãy dùng nó như hiện tại, hoặc chọn một thư mục khác cho phiên bản mới. Không khởi tạo một cấu hình mới đè lên một bản triển khai hiện có.

</Warning>
</Step>
</Steps>
