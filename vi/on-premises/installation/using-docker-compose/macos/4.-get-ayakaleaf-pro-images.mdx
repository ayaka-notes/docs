---

Ayakaleaf Pro là một Docker image miễn phí trên [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Bạn không cần tài khoản, đăng nhập hay giấy phép Overleaf thương mại để pull image này.

Mở `config/overleaf.rc` và đặt:

```bash title="config/overleaf.rc"
SERVER_PRO=true
```

Lần tới khi bạn chạy `bin/up`, Toolkit sẽ pull `ghcr.io/ayaka-notes/overleaf-pro` theo phiên bản trong `config/version`, thay vì Overleaf Community Edition chính thức.

Image được build cho `arm64` và `amd64`, và Docker sẽ chọn image phù hợp với máy Mac của bạn. Trên Apple silicon, không thêm `platform: linux/amd64` trong một override: khi đó image sẽ chạy dưới chế độ giả lập.
