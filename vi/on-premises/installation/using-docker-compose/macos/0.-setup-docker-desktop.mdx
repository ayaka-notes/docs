Ayakaleaf Pro chạy trên Docker. Trên máy Mac, bạn sử dụng Docker Desktop, công cụ chạy Docker engine trong một máy ảo Linux.

<Steps>
<Step title="Cài đặt và khởi động Docker Desktop">
Cài đặt bản [Docker Desktop](https://docs.docker.com/desktop/setup/install/mac-install/) dành cho máy Mac của bạn (Apple silicon hoặc Intel), mở nó và đợi cho đến khi engine đã khởi động. Bạn cũng có thể khởi động nó từ Terminal:

```bash
open -a Docker
```
</Step>

<Step title="Kiểm tra Docker engine">
Chạy các lệnh sau trong Terminal:

```bash
docker context show
docker info
docker compose version
```

Context phải trỏ đến Docker Desktop engine cục bộ của bạn, thường là `desktop-linux`. Nếu một context khác đang được chọn, hãy chuyển sang Docker Desktop trước khi tiếp tục:

```bash
docker context use desktop-linux
```

`docker info` phải in ra một phần **Server**. Chỉ riêng `docker --version` chỉ cho thấy client đã được cài đặt.
</Step>

<Step title="Kiểm tra tài nguyên và chia sẻ tệp">
Trong **Settings** của Docker Desktop, hãy đối chiếu giới hạn CPU, bộ nhớ và ổ đĩa với [Trước khi bắt đầu](/vi/on-premises/installation/using-docker-compose/macos#before-you-start), và kiểm tra các thiết lập chia sẻ tệp, xem [Thiết lập Docker Desktop](https://docs.docker.com/desktop/settings-and-maintenance/settings/).

Hướng dẫn này đặt Toolkit trong `/Users`, thư mục mà Docker Desktop chia sẻ theo mặc định. Nếu bạn dùng một vị trí khác và `bin/up` thất bại với lỗi `Mounts denied`, hãy thêm thư mục đó vào phần chia sẻ tệp.
</Step>

<Step title="Kiểm tra Docker socket cho sandboxed compiles">
Toolkit gắn `/var/run/docker.sock` vào ứng dụng để nó có thể khởi động một container TeX Live riêng cho mỗi lần biên dịch. Hãy giữ `DOCKER_SOCKET_PATH=/var/run/docker.sock` trong `config/overleaf.rc`.

Docker CLI trên macOS có thể kết nối qua `~/.docker/run/docker.sock`. Đó là endpoint của client trên máy Mac, không phải lý do để thay đổi nguồn mount của Toolkit: trình biên dịch cần socket của engine theo cách mà các container Linux nhìn thấy nó.

Nếu `/var/run/docker.sock` không tồn tại trên máy Mac, hãy bật **Allow the default Docker socket to be used** trong **Settings → Advanced**, xem [yêu cầu về quyền của Docker](https://docs.docker.com/desktop/setup/install/mac-permission-requirements/).

<Danger>

Không chạy `chmod 777` trên socket để khắc phục lỗi. Quyền truy cập Docker socket tương đương với quyền root trên máy ảo Docker.

</Danger>
</Step>
</Steps>
