Docker Compose trên một máy chủ duy nhất là cách được khuyến nghị để triển khai Ayakaleaf Pro. Bạn chạy nó thông qua [Toolkit](https://github.com/ayaka-notes/toolkit): một bộ script bao bọc `docker compose` và đọc các thiết lập của bạn từ một thư mục `config/` duy nhất, vì vậy `bin/up` thay thế cho `docker compose up`.
