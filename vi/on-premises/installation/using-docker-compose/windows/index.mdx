Trong phần này, chúng ta sẽ chạy Ayakaleaf Pro cục bộ trên Windows bằng WSL 2, Ubuntu, Docker Desktop và [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). Hướng dẫn sử dụng `http://localhost:8080`, lưu dữ liệu trong thư mục home của Ubuntu và bật sandboxed compiles.

Ứng dụng, MongoDB, Redis và TeX Live chạy trong các container Linux do Docker Desktop quản lý. Hãy chạy các lệnh Toolkit trong Ubuntu; mở ứng dụng trong trình duyệt trên Windows. [Bước 0](/vi/on-premises/installation/using-docker-compose/windows/0.-setup-wsl-and-docker-desktop) giải thích cách các thành phần Windows và Linux kết hợp với nhau và bắt đầu từ việc cài đặt WSL.

Bạn có thể dùng Windows cho một phiên bản cục bộ hoặc giữ nó chạy liên tục bằng các thiết lập về tính khả dụng ở bước 6. Đối với các máy chủ dùng chung và máy chủ production, chúng tôi khuyến nghị [hướng dẫn cho Linux](/vi/on-premises/installation/using-docker-compose/linux), với HTTPS, sao lưu và kiểm soát truy cập. Chế độ ngủ của Windows, việc tắt Docker Desktop và việc tắt WSL sẽ làm gián đoạn phiên bản cục bộ này; xem [Giữ cho phiên bản luôn khả dụng](/vi/on-premises/installation/using-docker-compose/windows/6.-post-installation-tasks#keep-the-instance-available).

## Trước khi bắt đầu {#before-you-start}

Bạn cần:

* Một phiên bản Windows và bộ xử lý được hỗ trợ bởi [Docker Desktop for Windows](https://docs.docker.com/desktop/setup/install/windows-install/), với ảo hóa phần cứng được bật. Hướng dẫn này sử dụng Windows 11 trên x86-64.
* Quyền bật WSL và cài đặt phần mềm. WSL phải là phiên bản 2.1.5 trở lên, với Ubuntu chạy ở chế độ WSL 2.
* Đủ bộ nhớ cho Windows và các container. Đối với một phiên bản cục bộ nhỏ, 4 CPU và 8 GB khả dụng cho Docker là điểm khởi đầu được gợi ý, không phải mức tối thiểu đã được đo lường.
* Dung lượng trống trên ổ đĩa Windows chứa dữ liệu WSL và Docker. Hãy dành ít nhất 40 GB cho một thiết lập TeX Live đầy đủ cộng với dữ liệu dự án; image basic ở [bước 5](/vi/on-premises/installation/using-docker-compose/windows/5.-personalizing-your-instance) nhỏ hơn và phù hợp cho lần thử nghiệm triển khai ban đầu. Các phiên bản image bổ sung cần thêm dung lượng.
* Quyền truy cập mạng tới GitHub, GitHub Container Registry (`ghcr.io`) và Docker Hub để clone Toolkit và tải xuống các image.

Các khối **PowerShell** được chạy trong Windows. Các khối **Bash** và các lệnh `bin/` được chạy trong Ubuntu trừ khi có ghi chú khác. Không chạy các script của Toolkit trong PowerShell hoặc Git Bash của Windows.
