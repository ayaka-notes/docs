<Steps>
<Step title="Cài đặt các công cụ dòng lệnh">
Chạy trong **Ubuntu**, sử dụng mật khẩu Linux bạn đã tạo ở bước 0:

```bash
sudo apt update
sudo apt install -y git ca-certificates curl perl gawk openssl
```

Ubuntu đã có sẵn Bash, GNU sed và coreutils. Khác với macOS, nó không cần Homebrew hay một bản cài đặt GNU sed riêng.
</Step>

<Step title="Clone kho lưu trữ Ayakaleaf Toolkit">
Hãy giữ Toolkit và dữ liệu của nó trong hệ thống tệp Linux của Ubuntu, dưới thư mục home của bạn:

```bash
cd "$HOME"
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

Tránh `/mnt/c`, `/mnt/d`, OneDrive và các thư mục tạm thời cho cơ sở dữ liệu và dữ liệu dự án đang hoạt động. Các đường dẫn trong hệ thống tệp Linux cung cấp quyền và hành vi hệ thống tệp mà các container mong đợi, đồng thời tránh chi phí truy cập chéo giữa các hệ thống tệp; xem [hướng dẫn về hệ thống tệp của Microsoft](https://learn.microsoft.com/en-us/windows/wsl/filesystems).

<Warning>

Nếu thư mục đã chứa một bản cài đặt, hãy dùng nó như hiện tại, hoặc chọn một thư mục khác cho phiên bản mới. Không thay thế cấu hình hoặc dữ liệu của một bản triển khai hiện có.

</Warning>
</Step>
</Steps>
