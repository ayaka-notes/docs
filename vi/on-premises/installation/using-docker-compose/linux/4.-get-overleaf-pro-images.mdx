---
title: 4. Tải image Ayakaleaf Pro
icon: split
---

Ayakaleaf Pro là một Docker image miễn phí trên [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Bạn không cần tài khoản hay đăng nhập để pull image này. Image được build cho amd64 và arm64, và Docker sẽ chọn image phù hợp với máy chủ của bạn.

Mở `config/overleaf.rc` và đặt:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

Lần tiếp theo bạn chạy `bin/up`, Toolkit sẽ tải xuống image Ayakaleaf Pro và sử dụng nó thay cho Overleaf Community Edition chính thức. Các thiết lập của bạn trong `config/` vẫn tiếp tục hoạt động.

<Accordion title="Bạn đang chạy Overleaf Toolkit chính thức (overleaf/toolkit)?">

Bạn không cần cài đặt lại. Hãy pull image Ayakaleaf Pro:

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Sau đó, thêm một tệp có tên `docker-compose.override.yml` với nội dung sau vào thư mục `overleaf-toolkit/config`:

```yml
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

Lần tiếp theo bạn chạy `bin/up`, Toolkit sẽ sử dụng image Ayakaleaf Pro.

</Accordion>
