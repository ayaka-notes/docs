### Tạo tài khoản quản trị viên đầu tiên {#creating-your-first-administrator-account}

Mở `OVERLEAF_SITE_URL` kèm theo `/launchpad`, ví dụ `http://192.0.2.10:30080/launchpad`, và đăng ký tài khoản quản trị viên như trong [các tác vụ sau cài đặt của Toolkit](/vi/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks). Sau đó tạo một dự án mẫu và biên dịch nó.

Bạn cũng có thể tạo người dùng từ dòng lệnh:

```bash
kubectl -n overleaf exec deploy/overleaf -- bash -c \
  'cd /overleaf/services/web && node modules/server-ce-scripts/scripts/create-user.mjs --admin --email=admin@example.com'
```

Lệnh này in ra một liên kết để đặt mật khẩu.

### Kiểm tra rằng các lần biên dịch chạy trong sandbox {#checking-that-compiles-are-sandboxed}

Biên dịch một dự án, sau đó kiểm tra node đang chạy pod:

```bash
kubectl -n overleaf get pod -l app=overleaf -o wide   # NODE column
# on that node:
sudo docker ps -a --filter ancestor=ghcr.io/ayaka-notes/texlive-full:2026.1
ls -ln /srv/overleaf/compiles                          # owned by uid 33 (www-data)
```

Mỗi lần biên dịch xuất hiện dưới dạng một container tồn tại ngắn có tên `project-<project id>-<user id>-...`.

### Log và shell {#logs-and-a-shell}

| Toolkit          | Kubernetes                                                               |
| ---------------- | ------------------------------------------------------------------------ |
| `bin/logs web`   | `kubectl -n overleaf exec deploy/overleaf -- tail -f /var/log/overleaf/web.log` |
| `bin/shell`      | `kubectl -n overleaf exec -it deploy/overleaf -- bash`                    |
| `bin/up`         | `kubectl apply -f .` sau đó `kubectl -n overleaf rollout restart deployment/overleaf` |

Container ghi một tệp log cho mỗi dịch vụ trong `/var/log/overleaf/` (`web.log`, `clsi.log`, `real-time.log`, `document-updater.log`, ...); `kubectl logs` hiển thị đầu ra khởi động.
