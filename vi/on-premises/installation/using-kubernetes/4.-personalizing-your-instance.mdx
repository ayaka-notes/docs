ConfigMap `overleaf-env` thay thế cho `config/variables.env` của Toolkit: mọi biến môi trường trong [tài liệu Toolkit](/vi/on-premises/configuration/overleaf-toolkit/environment-variables) đều được đặt ở đây, còn các secret được đưa vào Secret từ [bước 2](/vi/on-premises/installation/using-kubernetes/2.-create-the-namespace-and-secrets).

```yaml title="30-config.yaml" wrap
apiVersion: v1
kind: ConfigMap
metadata:
  name: overleaf-env
  namespace: overleaf
data:
  OVERLEAF_APP_NAME: Ayakaleaf Pro
  OVERLEAF_SITE_URL: http://192.0.2.10:30080      # the address users open; https://... behind TLS
  OVERLEAF_ADMIN_EMAIL: admin@example.com
  # Emails: add the sender and the SMTP server together, see Email delivery
  # All members, so that the driver finds the primary even when mongo-0 is down
  OVERLEAF_MONGO_URL: mongodb://mongo-0.mongo:27017,mongo-1.mongo:27017,mongo-2.mongo:27017/sharelatex?replicaSet=overleaf
  OVERLEAF_REDIS_HOST: redis
  REDIS_HOST: redis
  ENABLED_LINKED_FILE_TYPES: project_file,project_output_file,url
  ENABLE_CONVERSIONS: "true"
  EMAIL_CONFIRMATION_DISABLED: "true"
  # Requests arrive from kube-proxy or your ingress controller, inside the pod network
  OVERLEAF_TRUSTED_PROXY_IPS: loopback,10.244.0.0/16
  # Sandboxed compiles. The HOST_DIR paths are paths ON THE NODE: the hostPath volumes that
  # the Deployment mounts at /var/lib/overleaf/data/{compiles,output,cache}.
  SANDBOXED_COMPILES: "true"
  SANDBOXED_COMPILES_SIBLING_CONTAINERS: "true"
  DOCKER_RUNNER: "true"
  SANDBOXED_COMPILES_HOST_DIR_COMPILES: /srv/overleaf/compiles
  SANDBOXED_COMPILES_HOST_DIR_OUTPUT: /srv/overleaf/output
  SANDBOXED_COMPILES_HOST_DIR_CACHE: /srv/overleaf/cache
  # Each image must be pulled into Docker on every node that can run Ayakaleaf Pro (step 0)
  ALL_TEX_LIVE_DOCKER_IMAGES: ghcr.io/ayaka-notes/texlive-full:2026.1
  ALL_TEX_LIVE_DOCKER_IMAGE_NAMES: TeX Live 2026
  TEX_LIVE_DOCKER_IMAGE: ghcr.io/ayaka-notes/texlive-full:2026.1
```

```bash
kubectl apply -f 30-config.yaml
```

| Biến                                | Đặt thành                                                                                                                                                       |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_SITE_URL`                     | URL mà người dùng nhập vào trình duyệt. Với NodePort từ [bước 5](/vi/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro), là IP của bất kỳ node nào và cổng `30080`; nếu ở phía sau ingress hoặc load balancer, là URL của nó. |
| `OVERLEAF_MONGO_URL`                    | Replica set của bạn. Dùng `?replicaSet=` với tên từ `rs.initiate`.                                                                                         |
| `OVERLEAF_REDIS_HOST` và `REDIS_HOST`  | Cả hai, trỏ tới Service Redis.                                                                                                                                    |
| `OVERLEAF_TRUSTED_PROXY_IPS`            | `loopback` cùng với các mạng mà proxy của bạn kết nối từ đó. `10.244.0.0/16` là mạng pod của flannel; hãy dùng pod CIDR của cluster của bạn.                               |
| `SANDBOXED_COMPILES_HOST_DIR_*`         | Đường dẫn trên node của các volume biên dịch. Chúng phải khớp với các volume `hostPath` ở [bước 5](/vi/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro).                                       |

Khi ở phía sau HTTPS, hãy đặt thêm `OVERLEAF_SECURE_COOKIE: "true"`, xem [Proxy TLS](/vi/on-premises/configuration/overleaf-toolkit/tls-proxy).

<Info>

Một ConfigMap đã thay đổi chỉ có hiệu lực với các pod đang chạy sau khi khởi động lại: `kubectl -n overleaf rollout restart deployment/overleaf`.

</Info>
