Cách dễ nhất để dùng thử Ayakaleaf Pro là sử dụng GitHub Codespace, nơi tất cả biến môi trường đã được cấu hình sẵn để bạn có thể dùng ngay.

<Warning>

Khi bạn chạy các container Docker bằng GitHub Codespaces, Codespace sẽ không tự động tắt và sẽ tiếp tục bị **tính phí**. Về quy tắc tính phí của GitHub Codespaces, vui lòng tham khảo [github codespaces billing rules](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces).

Để quản lý GitHub Codespaces của bạn, vui lòng truy cập [https://github.com/codespaces](https://github.com/codespaces). Khi không còn cần dùng nữa, hãy xóa Codespace của bạn kịp thời.

</Warning>

Chúng tôi đã **cấu hình sẵn** các tính năng sau:

* [x] Biên dịch LaTeX trong sandbox với TeXLive **Basic** (2024-2026)
* [x] Nhập/Xuất bằng Pandoc (tính năng của nền tảng SaaS)
* [x] Trình chạy script Python (tính năng của nền tảng SaaS)
* [x] Hỗ trợ Git-Bridge (tính năng của Server Pro)
* [x] Tìm kiếm tài liệu tham khảo nâng cao (tính năng của nền tảng SaaS)
* [x] Bảng quản trị (quản lý người dùng/dự án toàn cục)
* [x] Theo dõi thay đổi (kèm bảng Review và Comment)
* [x] Toàn bộ lịch sử dự án (kèm khôi phục và tải xuống)
* [x] Bảng ký hiệu (tính năng của Server Pro/nền tảng SaaS)

<Warning>

GitHub Codespaces tiêu chuẩn cung cấp 32 GB dung lượng lưu trữ. Dung lượng này không đủ cho bản cài đặt `texlive-full` của chúng tôi. Để dùng thử image đầy đủ, hãy gửi yêu cầu hỗ trợ tới GitHub để có Codespace với large runner (từ 8 lõi trở lên).

</Warning>

GitHub Sync, LDAP, OAuth, SSO, tích hợp Zotero và các tính năng khác _**chưa được cấu hình**_ trong môi trường thử nghiệm này. Bạn có thể tham khảo [cài đặt toolkit](/vi/on-premises/configuration/overleaf-toolkit/toolkit-settings) để biết thêm chi tiết về cách cấu hình các tính năng này trong triển khai của riêng bạn.

<Steps>
<Step title="Tạo GitHub Codespace của bạn">
Nhấp vào nút sau để tạo GitHub Codespace của bạn. Về cấu hình máy chủ, **2 lõi với 8 GB RAM** thường là đủ cho mục đích thử nghiệm. Nếu bạn định sử dụng [**TeX Live Full**](https://github.com/ayaka-notes/texlive-full), chúng tôi khuyến nghị chọn cấu hình **8 lõi 64GB**.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/ayakaleaf-pro-playground)
</Step>


#### Sử dụng image TeXLive Full

Nếu bạn có quyền truy cập GitHub Codespaces 8 lõi/64 GB, bạn có thể sử dụng image TeXLive Full trong môi trường thử nghiệm này. Bạn có thể thay đổi các biến môi trường sau trong tệp `toolkit/config/variables.env` để dùng image TeXLive Full thay cho image TeXLive Basic.

```dotenv wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1, ghcr.io/ayaka-notes/texlive-full:2024.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025, Texlive 2024
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```

Sau khi thay đổi biến môi trường, bạn cần khởi động lại toolkit để áp dụng thay đổi. Bạn có thể chạy lệnh sau để khởi động lại toolkit.

```bash
cd toolkit && bin/up -d
```
