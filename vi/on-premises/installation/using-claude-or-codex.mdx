Sử dụng Claude Code hoặc Codex để lập kế hoạch và thực hiện việc triển khai Ayakaleaf Pro. Agent có thể tìm kiếm trong tài liệu này thông qua MCP trong khi làm việc.

Agent chỉ hỗ trợ quá trình triển khai. Bạn vẫn chịu trách nhiệm xem xét các lệnh và bảo vệ thông tin xác thực.

### Trước khi bắt đầu

Chuẩn bị một máy chủ Linux được hỗ trợ có quyền truy cập SSH. Xem lại [các yêu cầu](/vi/on-premises/getting-started/requirements  "mention") trước khi tiếp tục.

<Warning>

Không dán mật khẩu, khóa riêng tư, token hoặc khóa giấy phép vào prompt của agent. Xem xét kỹ mọi lệnh trước khi chạy, đặc biệt là các lệnh sửa đổi tệp, mạng hoặc container.

</Warning>

### Kết nối tài liệu

Thêm endpoint MCP của tài liệu vào agent cục bộ của bạn.

<Tabs>
<Tab title="Claude Code">

```bash wrap
claude mcp add ayakaleaf-pro --scope user --transport http https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>

<Tab title="Codex">

```bash wrap
codex mcp add ayakaleaf-pro --url https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>
</Tabs>

Bắt đầu một phiên mới sau khi thêm máy chủ. Yêu cầu agent xác nhận rằng nó có thể tìm kiếm trong tài liệu Ayakaleaf Pro.

### Triển khai Ayakaleaf Pro

Mở terminal trên máy chủ triển khai của bạn. Khởi động Claude Code hoặc Codex tại đó. Sau đó gửi prompt sau:

```text wrap
Use the Ayakaleaf Pro documentation MCP server to guide this deployment.
First, inspect the requirements and installation guides.
Ask me for missing deployment details before making changes.
Use the Ayakaleaf Toolkit unless the documentation requires another approach.
Before configuring the instance, summarize relevant optional features.
Ask which features and integrations I want to enable.
Include TLS, sandboxed compiles, Git integration, external MongoDB or Redis,
SSO (OIDC, SAML, or LDAP), GitHub Synchronisation, Zotero, S3 storage,
email delivery, branding, and localization when relevant.
Explain each selected option's prerequisites, security impact, and configuration steps.
Keep unselected optional features disabled.
Show each command before running it.
Do not expose, store, or request secrets in chat.
After deployment, verify that the service is healthy and summarize the changes.
```

Agent sẽ hướng dẫn bạn qua các bước thiết lập Docker, cấu hình Toolkit, tải image và khởi động. Hãy làm theo hướng dẫn [using-the-toolkit](/vi/on-premises/installation/using-the-toolkit  "mention") để biết quy trình chuẩn.

### Chọn các tính năng tùy chọn

Yêu cầu agent chỉ đề xuất những tính năng phù hợp với môi trường của bạn. Các lựa chọn thường gặp bao gồm:

* <strong>Truy cập và bảo mật:</strong> TLS, biên dịch trong sandbox (sandboxed compiles) và SSO qua OIDC, SAML hoặc LDAP.
* <strong>Dịch vụ bên ngoài:</strong> MongoDB, Redis, lưu trữ S3 và gửi email.
* <strong>Cộng tác:</strong> Tích hợp Git, GitHub Synchronisation và Zotero.

Agent nên giải thích các phụ thuộc trước khi chỉnh sửa cấu hình. Xem lại [toolkit-settings.md](/vi/on-premises/configuration/overleaf-toolkit/toolkit-settings  "mention") và [authentication](/vi/on-premises/configuration/overleaf-toolkit/authentication  "mention") trước khi bật các tích hợp cho môi trường production.

### Kiểm tra việc triển khai

Sau khi agent hoàn tất các bước:

1. Xác nhận mọi lệnh đã chạy xong mà không có lỗi.
2. Mở URL Ayakaleaf Pro đã cấu hình trong trình duyệt.
3. Hoàn thành [6.-post-installation-tasks.md](/vi/on-premises/installation/using-the-toolkit/6.-post-installation-tasks  "mention").

Đối với một bản cài đặt Community Edition hiện có, hãy sử dụng hướng dẫn [migrate-from-existing.md](/vi/on-premises/installation/migrate-from-existing  "mention") thay vì triển khai mới.
