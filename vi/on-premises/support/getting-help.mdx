### Doctor

Overleaf Toolkit đi kèm một script `doctor` tiện dụng để hỗ trợ gỡ lỗi. Chạy `bin/doctor` và script sẽ in ra thông tin về môi trường máy host, cấu hình của bạn và các phụ thuộc mà Toolkit cần. Kết quả này cũng có thể giúp chúng tôi chẩn đoán sự cố cho các bản cài đặt Ayakaleaf Pro của bạn.

<Info>

Người dùng Overleaf Pro có thể [mở issue trên GitHub](https://github.com/ayaka-notes/overleaf/issues).

Bạn nên đính kèm kết quả đầu ra của script `bin/doctor` trong tin nhắn của mình.

</Info>

### Tham khảo ý kiến Doctor

Chạy script doctor:

```bash title="Run doctor"
bin/doctor
```

Bạn sẽ thấy kết quả tương tự như ví dụ dưới đây.

### Thông tin máy host

Phần `Host Information` chứa thông tin về máy đang chạy Toolkit (ví dụ: bản phân phối Linux và phiên bản phát hành).

<Accordion title="Ví dụ kết quả Host Information">

```text
- Host Information
    - Linux
    - Output of 'lsb_release -a':
            No LSB modules are available.
            Distributor ID:	Ubuntu
            Description:	Ubuntu 22.04.5 LTS
            Release:	22.04
            Codename:	jammy
```

</Accordion>

### Phụ thuộc

Phần `Dependencies` liệt kê các công cụ cần thiết để Toolkit hoạt động. Nếu một công cụ có mặt, nó sẽ được liệt kê với `status: present` kèm thông tin phiên bản. Nếu thiếu, nó sẽ được liệt kê với `status: MISSING!` và một cảnh báo sẽ được thêm vào cuối kết quả của `doctor`.

<Accordion title="Ví dụ kết quả Dependency (có mặt)">

```text
- docker
    - status: present
    - version info: Docker version 28.0.4, build b8034c0
```

</Accordion>

<Accordion title="Ví dụ kết quả Dependency (bị thiếu)">

```text
- docker
    - status: MISSING!
```

</Accordion>

Nếu thiếu bất kỳ phụ thuộc nào, gần như chắc chắn Toolkit sẽ không hoạt động.

### Cấu hình

Phần `Configuration` chứa thông tin về các tệp trong thư mục `config/`. Đối với `config/overleaf.rc`, doctor sẽ in ra một số giá trị quan trọng. Các tệp bị thiếu sẽ được liệt kê với `status: MISSING!` và một cảnh báo sẽ được thêm vào cuối kết quả của `doctor`.

<Accordion title="Ví dụ kết quả Configuration">

```text
====== Configuration ======
- config/version
    - status: present
    - version: 5.4.0
- config/overleaf.rc
    - status: present
    - values
        - OVERLEAF_DATA_PATH: /tmp/overleaf
        - SERVER_PRO: false
        - MONGO_ENABLED: false
        - REDIS_ENABLED: true
- config/variables.env
    - status: MISSING!
```

</Accordion>

Ghi chú từ ví dụ trên:

* `OVERLEAF_DATA_PATH` được đặt là `/tmp/overleaf` có thể không phải là vị trí an toàn cho dữ liệu quan trọng.
* `MONGO_ENABLED: false` nghĩa là Toolkit sẽ không tự cấp phát MongoDB; hãy đảm bảo `MONGO_URL` trỏ đến một MongoDB được quản lý bên ngoài nếu cần.
* `config/variables.env` bị thiếu trong ví dụ.

### Cảnh báo

Phần `Warnings` tóm tắt các vấn đề được script doctor phát hiện. Nếu không có vấn đề nào, phần này sẽ cho biết điều đó.

<Accordion title="Ví dụ kết quả Warnings">

```text
====== Warnings ======
- configuration file variables.env not found
- rc file, OVERLEAF_DATA_PATH not set
====== End =======
```

</Accordion>
