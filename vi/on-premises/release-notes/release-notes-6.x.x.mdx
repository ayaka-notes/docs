<Accordion title="Di chuyển Zotero / Mendeley cho các bản cài đặt hiện có">

Khi nâng cấp lên image 6.3.0 được phát hành lại, hãy di chuyển metadata của các tệp tài liệu tham khảo được liên kết từ Zotero/Mendeley hiện có bằng script dưới đây. Việc di chuyển này đi kèm với bản sửa lỗi `12031b8dfd`.

Script này đổi tên `zoteroGroupId` / `mendeleyGroupId` thành `group_id`, đổi tên `importedByUserId` thành `importer_id`, và xóa `importedByName`.

Sao lưu MongoDB và dừng ứng dụng trước khi chạy việc di chuyển. Giữ MongoDB tiếp tục chạy. Mở shell của nó (thay `mongo` bằng tên container của bạn):

```bash
docker exec -it mongo mongosh
```

Chạy đoạn sau trong `mongosh` (thay `sharelatex` bằng tên cơ sở dữ liệu của bạn):

```javascript
use sharelatex

(async () => {
  let updated = 0
  await db.projects.find({}, { rootFolder: 1 }).forEach(async project => {
    const changes = {}
    function visit(folders, path) {
      for (const [i, folder] of (folders || []).entries()) {
        const folderPath = `${path}.${i}`
        for (const [j, file] of (folder.fileRefs || []).entries()) {
          const data = { ...file.linkedFileData }
          if (!["zotero", "mendeley"].includes(data.provider)) continue
          const groupKey = `${data.provider}GroupId`
          if (![groupKey, "importedByUserId", "importedByName"].some(key => key in data)) continue
          for (const [oldKey, newKey] of [[groupKey, "group_id"], ["importedByUserId", "importer_id"]]) {
            if (data[oldKey] != null && data[oldKey] !== "") {
              const value = String(data[oldKey])
              if (newKey in data && data[newKey] !== value) {
                throw new Error(`Conflicting ${newKey}: project ${project._id}, file ${file._id}`)
              }
              data[newKey] = value
            }
            delete data[oldKey]
          }
          delete data.importedByName
          changes[`${folderPath}.fileRefs.${j}.linkedFileData`] = data
        }
        visit(folder.folders, `${folderPath}.folders`)
      }
    }
    visit(project.rootFolder, "rootFolder")
    if (!Object.keys(changes).length) return
    const result = await db.projects.updateOne(
      { _id: project._id, rootFolder: { $eq: project.rootFolder } },
      { $set: changes }
    )
    if (!result.matchedCount) throw new Error(`Project changed during migration: ${project._id}`)
    updated += result.modifiedCount
  })
  print(`Updated ${updated} project(s).`)
})()
```

Script bao gồm cả các thư mục lồng nhau và chỉ thay đổi metadata của Zotero/Mendeley. Có thể chạy lại một cách an toàn: một lần di chuyển đã hoàn tất sẽ báo `Updated 0 project(s).` ở lần chạy tiếp theo. Nếu script dừng do xung đột, hãy kiểm tra dự án/tệp được báo cáo; các dự án trước đó có thể đã được di chuyển.

Khởi động ứng dụng đã cập nhật, tải lại trình soạn thảo và làm mới một tệp tài liệu tham khảo hiện có với tư cách người đã nhập ban đầu. Các snapshot lịch sử không bị ghi lại. Để hạ cấp về ứng dụng cũ, hãy khôi phục bản sao lưu MongoDB.

</Accordion>

Chúng tôi rất tự hào thông báo phát hành Overleaf Pro 6.3.0, trình soạn thảo LaTeX trực tuyến mạnh mẽ và giàu tính năng nhất trong cộng đồng. Vì chúng tôi luôn tập trung vào việc cải thiện trải nghiệm người dùng, bản phát hành này mang đến những thay đổi lớn và các tính năng tuyệt vời mà chắc chắn bạn sẽ yêu thích, bao gồm trợ lý AI và tích hợp tài liệu tham khảo của bên thứ ba.

### Thay đổi

* AI Chat Assistant: Trò chuyện với mô hình AI thông qua nhà cung cấp của riêng bạn, ngay trong trình soạn thảo.
* LaTeX Error Assistant: Nhận gợi ý sửa lỗi biên dịch LaTeX từ AI.
* Tích hợp Mendeley: Nhập tài liệu tham khảo từ Mendeley tương tự như Zotero.
* Open in Overleaf API: Thêm API để mở nội dung trong Overleaf.
* Template Gallery: Thêm phân trang, tìm kiếm và sắp xếp phía máy chủ, để các thư viện mẫu lớn không còn phải tải mọi mẫu trong trình duyệt.
* Bản dịch: Cập nhật các bản vá dịch thuật cho 6.3.0, bao gồm văn bản giao diện mới trên các ngôn ngữ được hỗ trợ.
* Upstream Overleaf 6.3.0: Bao gồm chỉnh sửa tệp theo tab, logo header riêng cho giao diện sáng và tối, cùng các cập nhật phụ thuộc và base image.
* Thêm `OVERLEAF_HEADER_IMAGE_URL_LIGHT` và `OVERLEAF_HEADER_IMAGE_URL_DARK` để hỗ trợ ảnh logo header riêng cho giao diện sáng và tối.
* Giờ đây các tệp có thể được mở trong các tab khác nhau trong trình soạn thảo.
* Thêm hỗ trợ cho các proxy HTTP(S) có thể cấu hình, bao gồm proxy được lưu trữ cục bộ, thông qua `OVERLEAF_LINKED_URL_OUTBOUND_PROXY`, biến này cũng được Open in Overleaf API sử dụng.

#### Tính năng 04: Phân trang mẫu

Thư viện mẫu giờ đây phân trang, sắp xếp và tìm kiếm trong MongoDB. Tính năng này hoạt động mà không cần chuẩn bị gì; với hàng nghìn mẫu, bạn vẫn có thể thêm các chỉ mục sau để giữ tốc độ nhanh (có thể chạy lại an toàn, `mongo`/`sharelatex` = tên container và cơ sở dữ liệu của bạn):

```bash
docker exec mongo mongosh sharelatex --quiet --eval '
db.templates.createIndex({category:1,lastUpdated:-1},{name:"category_1_lastUpdated_-1",background:true});
db.templates.createIndex({lastUpdated:-1},{name:"lastUpdated_-1",background:true});
db.templates.createIndex({category:1,name:1},{name:"category_1_name_1_ci",collation:{locale:"en",strength:2},background:true});
db.templates.createIndex({name:1},{name:"name_1_ci",collation:{locale:"en",strength:2},background:true});
'
```

Giữ nguyên `collation` trên hai chỉ mục `*_ci` như đã viết — thư viện mẫu truy vấn với cùng collation và MongoDB chỉ sử dụng chỉ mục khớp.

## Ayakaleaf Pro 6.2.2

<strong>Ngày phát hành:</strong> 2026.07.23

Xem: [https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.2](https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.2)

### Thay đổi

Backport các bản vá hotfix chính thức được phát hành trong Overleaf upstream `6.2.2` (trên nền `6.2.1`):

* Ngừng làm lộ secret của token mời vào dự án trong log. Bộ mã hóa token mời đã ghi log cấu hình của chính nó ở mỗi lần mã hóa/giải mã, bao gồm cả các mật khẩu cipher được suy ra từ `OVERLEAF_INVITE_TOKEN_SECRET`.
* Chuyển việc gửi email từ client AWS SES v1 đã hết vòng đời sang SESv2. Các phiên bản được cấu hình với driver email `ses` có thể hoàn toàn không gửi được email; việc gửi giờ đây đi qua `SESv2Client`.
* Đặt các mục nhóm trong menu thả xuống chia sẻ dự án sau cờ tính năng mới `group-link-sharing`, để tính năng chia sẻ liên kết nhóm không còn được hiển thị trên các phiên bản không áp dụng.
* Sửa hộp thoại chia sẻ dự án cho cộng tác viên. Việc mở nó khi không phải chủ sở hữu, hoặc khi luồng `sharing-updates` bị tắt, đã gửi một yêu cầu luôn thất bại và hiển thị lỗi "something went wrong".
* Thêm `scripts/flush_docs_with_pending_updates.js` vào document-updater, một script bảo trì giúp khôi phục các tài liệu bị kẹt hàng đợi `PendingUpdates` trong Redis sau khi dự án của chúng đã được flush hoặc bị xóa cứng. Hỗ trợ `--dry-run` và kiểm tra an toàn `--estimated-docs`.
* Cập nhật phụ thuộc: `multer` 2.2.0, `form-data` 2.5.6, `protobufjs` 7.6.3, `@grpc/grpc-js` 1.14.4.

Bản phát hành này cũng bao gồm các bản sửa lỗi và cải tiến sau từ Ayakaleaf Pro:

* Thêm bản dịch đầy đủ cho 16 ngôn ngữ bổ sung (cs, da, de, es, fi, fr, it, ja, ko, nl, no, pl, pt, ru, sv, tr), sửa các chuỗi chưa được dịch như trang đặt lại mật khẩu. Khắc phục [#38](https://github.com/ayaka-notes/ayakaleaf-pro/issues/38).
* Sửa số lượng mục trong nút "show N more projects" của bảng quản trị, vốn hiển thị sai số vì placeholder số nhiều không được truyền đúng.
* Sửa các lỗi xác thực khi xuất sang GitHub, giờ được hiển thị thông qua các khóa i18n tĩnh thay vì thông báo thô, và loại bỏ các khóa lỗi không còn được hộp thoại GitHub Sync sử dụng.

## Ayakaleaf Pro 6.2.0

<strong>Ngày phát hành:</strong> 2026.07.10

Xem: [https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.0](https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.0)

Chúng tôi tự hào thông báo phát hành Overleaf Pro 6.2.0, trình soạn thảo LaTeX trực tuyến mạnh mẽ và giàu tính năng nhất trong cộng đồng. Xin đặc biệt cảm ơn yu-i-i và davrot vì những đóng góp quý giá của họ. Họ đã cải tiến GitHub Sync và giới thiệu tính năng Tìm kiếm trích dẫn nâng cao cùng tích hợp Zotero.

### Lưu ý

<Warning>

* Một biến môi trường bắt buộc mới `OVERLEAF_INVITE_TOKEN_SECRET` đã được giới thiệu. Bạn phải tạo nó bằng `openssl rand -base64 32`. Nếu biến này không được cấu hình, phiên bản Overleaf của bạn sẽ không khởi động được.
* Nếu bạn bật GitHub Sync, bạn phải cấu hình biến môi trường `GITHUB_TOKEN_CIPHER_PASSWORD`. Biến này là bắt buộc để mã hóa an toàn các access token của GitHub. Nếu thiếu, phiên bản Overleaf của bạn sẽ không khởi động được.

</Warning>

* Thêm biến môi trường mới `DEFAULT_LATEX_COMPILER` để đặt trình biên dịch mặc định cho các dự án mới (một trong `pdflatex`, `latex`, `xelatex` hoặc `lualatex`).
* Trình soạn thảo được thiết kế lại giờ đây là lựa chọn duy nhất.

### Thay đổi

Bản phát hành này bao gồm các cải tiến và tính năng mới sau.

* `MAX_UPLOAD_SIZE` giờ đây có thể cấu hình thay vì bị giới hạn ở **50 MB**.
* Sửa lỗi vòng lặp khởi động lại container khi biên dịch trong sandbox bị tắt.
* Bắt buộc việc xóa PAT theo phạm vi chủ sở hữu cho OAuth2.
* Sửa một lỗi khi nhập từ LDAP.

Các tính năng bao gồm:

* Thêm trình chạy Python trên trình duyệt.
* Thêm hỗ trợ Pandoc để nhập và xuất Markdown, DOCX và các định dạng khác.
* Thêm GitHub Sync.

* Thêm `DEFAULT_LATEX_COMPILER`.
