Hãy đảm bảo bạn đọc kỹ phần này trước khi tiến hành bất kỳ quá trình cài đặt Overleaf nào.

### Yêu cầu để cài đặt Server Pro và Community Edition

<Warning>

Chúng tôi đặc biệt khuyến nghị bạn chạy Server Pro trên một phiên bản Ubuntu mới và ổn định (ví dụ: Ubuntu 24.04 trong giai đoạn 2025–2026) cùng với phiên bản Docker gần đây. Có thể chạy Server Pro trên các hệ thống khác, nhưng điều đó sẽ khiến chúng tôi gặp nhiều khó khăn hơn trong việc hỗ trợ các cấu hình Ubuntu/Docker không mặc định. Chúng tôi cũng không thể hỗ trợ các vấn đề liên quan đến bản thân Docker.

</Warning>
