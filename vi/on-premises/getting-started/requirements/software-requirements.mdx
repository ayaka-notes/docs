### Hệ điều hành

Để có trải nghiệm tốt nhất khi chạy Overleaf, chúng tôi đặc biệt khuyến nghị sử dụng hệ điều hành **dựa trên Debian**, chẳng hạn như **Ubuntu**. Lựa chọn này phù hợp với môi trường phát triển của phần mềm và là lựa chọn được đa số người dùng Overleaf ưa chuộng.

<Danger>

Khi sử dụng Server Pro với Sandboxed Compiles, **cần lưu ý** rằng ứng dụng yêu cầu quyền root đối với Docker socket.

</Danger>

### Phụ thuộc

* Docker 25.0 và 29
* MongoDB 7.0 và 8.0
* Redis 6.2 và 7.5

<Info>

Bạn có thể theo dõi ngày kết thúc vòng đời (EOL) của các phụ thuộc trên cùng các sản phẩm phổ biến khác bằng dịch vụ endoflife.date tại đây: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

MongoDB và Redis được `docker compose` tự động pull khi chạy Server CE hoặc Server Pro, trừ khi được cấu hình để sử dụng một bản cài đặt khác.

</Info>

Toolkit phụ thuộc vào các chương trình sau:

* bash
* Docker

`docker compose` là bắt buộc và thường được cài đặt cùng với Docker.

Chúng tôi khuyên bạn nên cài đặt phiên bản Docker mới nhất có sẵn cho hệ điều hành của mình.

Sau khi Docker được cài đặt đúng cách, bạn sẽ có thể chạy các lệnh sau mà không gặp lỗi:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2)
docker compose version

# List the running Docker containers on your system
docker ps
```
