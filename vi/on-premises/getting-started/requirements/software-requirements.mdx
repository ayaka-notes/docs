### Hệ điều hành {#operating-systems}

Chúng tôi khuyến nghị một hệ thống **Linux dựa trên Debian**, chẳng hạn như **Ubuntu**, cho các máy chủ dùng chung và máy chủ production. Ayakaleaf Pro cũng có thể chạy trên [macOS với Docker Desktop](/vi/on-premises/installation/using-docker-compose/macos) và [Windows với WSL 2 và Docker Desktop](/vi/on-premises/installation/using-docker-compose/windows). Cả ba nền tảng đều sử dụng container Linux và cùng một Toolkit; hãy làm theo hướng dẫn dành cho hệ điều hành máy chủ host của bạn.

<Danger>

Khi sử dụng Sandboxed Compiles, **cần lưu ý** rằng ứng dụng yêu cầu quyền root đối với Docker socket.

</Danger>

### Phụ thuộc {#dependencies}

* Docker 25.0 và 29
* MongoDB 7.0 và 8.0
* Redis 6.2 và 7.5

<Info>

Bạn có thể theo dõi ngày kết thúc vòng đời (EOL) của các phụ thuộc trên cùng các sản phẩm phổ biến khác bằng dịch vụ endoflife.date tại đây: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

MongoDB và Redis được `docker compose` tự động pull khi chạy Ayakaleaf Pro, trừ khi được cấu hình để sử dụng một bản cài đặt khác.

</Info>

Toolkit phụ thuộc vào các chương trình sau:

* bash
* Docker

`docker compose` là bắt buộc và thường được cài đặt cùng với Docker.

Chúng tôi khuyên bạn nên cài đặt phiên bản Docker mới nhất có sẵn cho hệ điều hành của mình.

Sau khi Docker được cài đặt đúng cách, bạn sẽ có thể chạy các lệnh sau mà không gặp lỗi:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2 or later, such as v5)
docker compose version

# List the running Docker containers on your system
docker ps
```
