title: Tích hợp
description: Kết nối phiên bản của bạn với Git, GitHub, GitLab, Gitea, Dropbox, các trình quản lý tài liệu tham khảo, dịch vụ AI và các trang web khác.
icon: puzzle-piece
---

Mỗi tích hợp đều bị tắt theo mặc định, ngoại trừ Overleaf Import API. Đồng bộ hóa GitHub, GitLab, Gitea và Dropbox cũng như MCP server còn cần đến [tích hợp Git](/vi/on-premises/configuration/overleaf-toolkit/integrations/git-integration). Sau khi bật một tích hợp, hãy tạo lại các container bằng `bin/up -d`.
