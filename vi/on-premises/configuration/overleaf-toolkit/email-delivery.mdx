Overleaf hỗ trợ gửi email qua hai phương thức: Simple Mail Transfer Protocol (SMTP) và [Amazon Simple Email Service (SES)](https://aws.amazon.com/ses/). Bạn có thể dùng SMTP nếu có một máy chủ email được bật trên localhost và đang lắng nghe các kết nối cục bộ.

## Cấu hình

Email được cấu hình bằng các biến môi trường sau.

#### Cấu hình người gửi

| Tên                           | Mô tả |
| ----------------------------- | ----- |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | <p>Địa chỉ người gửi, ví dụ <a href="mailto:support@mycompany.com">`'support@mycompany.com'`</a><br /><br />- <strong>Bắt buộc</strong>: có</p> |
| `OVERLEAF_EMAIL_REPLY_TO`     | Địa chỉ trả lời, ví dụ `'noreply@mycompany.com'` |

#### SMTP

| Tên                                     | Mô tả |
| --------------------------------------- | ----- |
| `OVERLEAF_EMAIL_SMTP_HOST`              | Tên máy chủ hoặc địa chỉ IP để kết nối. Phải truy cập được từ container Docker |
| `OVERLEAF_EMAIL_SMTP_PORT`              | Cổng để kết nối |
| `OVERLEAF_EMAIL_SMTP_SECURE`            | Nếu là `true`, kết nối sẽ dùng TLS khi kết nối tới máy chủ. Nếu là `false` hoặc không được đặt, TLS sẽ được dùng nếu máy chủ hỗ trợ phần mở rộng `STARTTLS`. Trong hầu hết trường hợp, hãy đặt giá trị này là `true` nếu bạn kết nối tới cổng `465`. Với cổng `587` hoặc `25`, hãy giữ là `false` |
| `OVERLEAF_EMAIL_SMTP_USER`              | Tên người dùng dùng để xác thực với máy chủ SMTP |
| `OVERLEAF_EMAIL_SMTP_PASS`              | Mật khẩu tương ứng với tên người dùng SMTP |
| `OVERLEAF_EMAIL_SMTP_TLS_REJECT_UNAUTH` | Nếu là `false`, sẽ cho phép mở kết nối tới máy chủ TLS có chứng chỉ TLS tự ký hoặc không hợp lệ |
| `OVERLEAF_EMAIL_SMTP_IGNORE_TLS`        | Khi là `true` và `OVERLEAF_EMAIL_SMTP_SECURE` là `false`, TLS sẽ không được dùng ngay cả khi máy chủ hỗ trợ phần mở rộng `STARTTLS` |
| `OVERLEAF_EMAIL_SMTP_NAME`              | Tên máy chủ tùy chọn dùng để xác thực TLS nếu `OVERLEAF_EMAIL_SMTP_HOST` được đặt là địa chỉ IP, mặc định là tên máy chủ của máy. |
| `OVERLEAF_EMAIL_SMTP_LOGGER`            | Khi là `true`, các thông điệp log sẽ được in ra `web.log`. |

#### Giao diện SMTP của Amazon SES

Bạn có thể đọc thêm về việc sử dụng giao diện SMTP của Amazon SES để gửi email [tại đây](https://docs.aws.amazon.com/ses/latest/dg/send-email-smtp.html).

| Tên                        | Mô tả |
| -------------------------- | ----- |
| `OVERLEAF_EMAIL_SMTP_HOST` | Tên máy chủ hoặc địa chỉ IP để kết nối. Phải truy cập được từ container Docker |
| `OVERLEAF_EMAIL_SMTP_PORT` | Cổng để kết nối |
| `OVERLEAF_EMAIL_SMTP_USER` | Tên người dùng dùng để xác thực với máy chủ SMTP |
| `OVERLEAF_EMAIL_SMTP_PASS` | Mật khẩu tương ứng với tên người dùng SMTP |

#### Amazon SES API

Bạn có thể đọc thêm về việc sử dụng Amazon SES API để gửi email [tại đây](https://docs.aws.amazon.com/ses/latest/dg/send-email-api.html).

| Tên                                    | Mô tả |
| -------------------------------------- | ----- |
| `OVERLEAF_EMAIL_AWS_SES_ACCESS_KEY_ID` | Access key khi sử dụng AWS SES |
| `OVERLEAF_EMAIL_AWS_SES_SECRET_KEY`    | Secret key khi sử dụng AWS SES |
| `OVERLEAF_EMAIL_AWS_SES_REGION`        | Nếu không được đặt, region mặc định là US-EAST-1 |

#### AWS SES với Instance Role

| Tên                     | Mô tả |
| ----------------------- | ----- |
| `OVERLEAF_EMAIL_DRIVER` | Khi giá trị này được đặt là `ses`, hệ thống email sẽ dùng phương thức SES API và dựa vào các instance role đã cấu hình để gửi email. |

| ------------------------------ | ----- |
| `OVERLEAF_CUSTOM_EMAIL_FOOTER` | <p>HTML tùy chỉnh được thêm vào cuối tất cả email, ví dụ<br /><br /><strong>Ví dụ</strong>: `"<div>This system is run by department x </div> <div> If you have any questions please look at our faq <a href='`<a href="https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/https:/somwhere.com'%3Ehere&#x3C;/a%3E&#x3C;/div%3E">`https://somwhere.com'>here&#x3C;/a>&#x3C;/div>`</a>`"`</p> |
