### Header

Trong phần này, chúng tôi sẽ hướng dẫn cách cá nhân hóa các thành phần chính của phiên bản on-premises. Bạn có thể tùy chỉnh tiêu đề trang, liên kết điều hướng, header, footer và logo theo ý muốn.

### Tiêu đề trang

Tiêu đề thanh điều hướng có thể được tùy chỉnh bằng biến môi trường `OVERLEAF_NAV_TITLE`; văn bản này được hiển thị ở góc trên bên trái của thanh điều hướng nếu chưa đặt logo.

```bash
# add to config/variables.env
OVERLEAF_NAV_TITLE=Our Overleaf Instance
```

## Logo

Bạn có thể thêm logo tùy chỉnh thay cho văn bản bằng cách đặt biến môi trường `OVERLEAF_HEADER_IMAGE_URL`. Giá trị này phải trỏ đến một tệp hình ảnh được lưu trữ bên ngoài.

```bash title="config/variables.env"
# add to config/variables.env
OVERLEAF_HEADER_IMAGE_URL=https://mysite.somewhere.com/img/logo.png
```

#### Logo cho giao diện sáng và tối

Từ phiên bản 6.3.0, bạn có thể đặt logo riêng cho giao diện sáng và tối bằng các biến môi trường `OVERLEAF_HEADER_IMAGE_URL_LIGHT` và `OVERLEAF_HEADER_IMAGE_URL_DARK`. Cả hai giá trị đều phải trỏ đến một tệp hình ảnh được lưu trữ bên ngoài.

```text
# add to config/variables.env
OVERLEAF_HEADER_IMAGE_URL_LIGHT=https://mysite.somewhere.com/img/logo-light.png
OVERLEAF_HEADER_IMAGE_URL_DARK=https://mysite.somewhere.com/img/logo-dark.png
```

<Info>

Nếu một trong hai biến không được đặt, giao diện tương ứng sẽ dùng logo được đặt trong `OVERLEAF_HEADER_IMAGE_URL`.

</Info>

## Liên kết điều hướng trên header

Có thể thêm các mục điều hướng bổ sung vào header bằng cách đặt biến môi trường `OVERLEAF_HEADER_EXTRAS` thành một mảng JSON gồm các đối tượng. Ví dụ:

```json wrap
[\
  {\
    "text": "Some link",\
    "url": "http://example.com/somelink",\
    "class": "subdued",\
    "only_when_logged_out": true\
  },\
  {\
    "text": "Help",\
    "class": "subdued",\
    "dropdown": [\
      {\
        "text": "Documentation",\
        "url": "/learn"\
      },\
      {\
        "text": "Contact Admin",\
        "url": "http://example.com/contact"\
      }\
    ]\
  }\
]
```

Thêm dạng JSON đã được escape vào toolkit/variables.env:

```bash title="toolkit/variables.env" wrap
# add to toolkit/variables.env
OVERLEAF_HEADER_EXTRAS=[{"text":"Some link","url":"http://example.com/somelink","class":"subdued","only_when_logged_out":true},{"text":"Help","class":"subdued","dropdown":[{"text":"Documentation","url":"/learn"},{"text":"Contact Admin","url":"http://example.com/contact"}]}]
```

## Footer

Bạn có thể tùy chỉnh cả footer bên trái và footer nhỏ hơn bên phải (xuất hiện trên các trang như `/project`) bằng các biến môi trường `OVERLEAF_LEFT_FOOTER` và `OVERLEAF_RIGHT_FOOTER`. Cả hai đều nhận một mảng các đối tượng JSON sẽ được chèn vào.

Cả hai đều nhận một mảng JSON sẽ được chèn vào.

```json
[\
  {\
    "text": "This is an example text footer entry!"\
  },\
  {\
    "text": "This is an example URL footer link!", "url" : "/my-first-link.htm"\
  }\
]
```

<Info>

Khi chỉ dùng `text`, giá trị không được chứa HTML vì nó sẽ được hiển thị dưới dạng văn bản thô.

</Info>

Dữ liệu này phải là JSON hợp lệ thì mới hoạt động, và các dấu ngoặc kép cần được escape khi truyền vào dưới dạng biến môi trường.

```bash title="config/variables.env" wrap
# add to config/variables.env
OVERLEAF_LEFT_FOOTER=[{"text": "This is an example text footer entry!"}]
OVERLEAF_RIGHT_FOOTER=["text": "This is an example URL footer link!", "url" : "/my-first-link.htm"]
```

<Info>

Ngoài `text` và `url`, đối tượng JSON còn chấp nhận các thuộc tính `class` và `label` để tùy chỉnh thêm.

</Info>

### Trang bảo trì

Bạn có thể tùy chỉnh thông báo hiển thị trên trang Bảo trì bằng biến môi trường `OVERLEAF_MAINTENANCE_MESSAGE`; văn bản này sẽ thay thế thông báo mặc định bên dưới tiêu đề trang.

```text wrap
# add to config/variables.env
OVERLEAF_MAINTENANCE_MESSAGE=Our Overleaf Instance is down for maintenance and will be back shortly.
```

Để chèn liên kết hoặc định dạng khác, hãy dùng `OVERLEAF_MAINTENANCE_MESSAGE_HTML`. Nếu cả hai đều được đặt, `OVERLEAF_MAINTENANCE_MESSAGE_HTML` sẽ được ưu tiên.

```text wrap
# add to config/variables.env
OVERLEAF_MAINTENANCE_MESSAGE_HTML=Our Overleaf Instance is down for maintenance. For urgent requests, contact <a href="mailto:admin@example.com">admin@example.com</a>.
```

<Info>

`OVERLEAF_MAINTENANCE_MESSAGE` được hiển thị dưới dạng văn bản thuần, vì vậy **không** được chứa HTML. `OVERLEAF_MAINTENANCE_MESSAGE_HTML` được hiển thị dưới dạng HTML mà không escape.

</Info>

Nếu không biến nào được đặt, thông báo mặc định sẽ liên kết đến trang trạng thái của bạn khi `OVERLEAF_STATUS_PAGE_URL` được đặt, và hiển thị địa chỉ email quản trị viên khi biến này không được đặt.
