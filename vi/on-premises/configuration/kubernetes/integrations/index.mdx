---
title: Tích hợp
description: Kết nối một bản triển khai Kubernetes với Git, GitHub, GitLab, Gitea, Dropbox, các trình quản lý tài liệu tham khảo, dịch vụ AI và các trang khác.
icon: puzzle-piece
---

Mỗi tích hợp đều tắt theo mặc định, ngoại trừ Overleaf Import API. Đồng bộ hóa GitHub, GitLab, Gitea và Dropbox cùng với MCP server cũng cần [Tích hợp Git](/vi/on-premises/configuration/kubernetes/integrations/git-integration). Sau khi bật một tích hợp trong ConfigMap hoặc Secret, hãy khởi động lại các replica bằng `kubectl -n overleaf rollout restart`.
