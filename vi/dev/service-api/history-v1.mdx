Lưu toàn bộ lịch sử của mọi dự án: các khối thay đổi trong Mongo hoặc Postgres và kho đối tượng, cùng nội dung tệp dưới dạng blob. project-history ghi thay đổi vào đó; web, project-history và git-bridge đọc blob, ảnh chụp và zip từ đó.

* <strong>Địa chỉ:</strong> `http://history-v1:3100`, bên trong mạng Docker
* <strong>Xác thực:</strong> HTTP basic auth với tư cách `staging` và `STAGING_PASSWORD`, hoặc JWT, tùy route.
* <strong>Tệp OpenAPI:</strong> [`develop/hoppscotch/openapi/history-v1.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/history-v1.yaml)
