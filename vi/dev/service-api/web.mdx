API riêng của web, ứng dụng chính của Overleaf. Các dịch vụ khác (real-time, document-updater, project-history, third-party-datastore, git-bridge) và các script cron của image Server CE gọi nó. Các route này chỉ cần HTTP basic auth, không cần mã CSRF: router riêng được gắn trước router web, và chỉ router web chạy kiểm tra CSRF. Với `BLOCK_CROSS_ORIGIN_REQUESTS=true` (tắt theo mặc định), web trả về 403 cho mọi yêu cầu có header `Origin` không nằm trong `ALLOWED_ORIGINS` (mặc định: URL của trang). Trình duyệt gửi `Origin` khi POST, nên khi bật tùy chọn này, các POST gửi từ Hoppscotch trong trình duyệt sẽ nhận 403 trừ khi đi qua proxy Hoppscotch.

* <strong>Địa chỉ:</strong> `http://web:3000`, bên trong mạng Docker
* <strong>Xác thực:</strong> HTTP basic auth với `WEB_API_USER` và `WEB_API_PASSWORD`, trừ status, health và metrics. Các route git-bridge dùng mã truy cập cá nhân thay thế.
* <strong>Tệp OpenAPI:</strong> [`develop/hoppscotch/openapi/web.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/web.yaml)
