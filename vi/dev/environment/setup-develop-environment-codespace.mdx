Để tiết kiệm thời gian và nhanh chóng dựng môi trường phát triển, chúng tôi cung cấp thêm một phiên bản cấu hình môi trường phát triển khác, đó là GitHub Codespace.

## Hướng dẫn cấu hình

<Steps>
<Step title="Tạo Codespaces">
Nhấp vào nút sau để tạo một codespace trên đám mây phục vụ phát triển server-pro.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/ayakaleaf-pro)

Bạn nên chọn **Machine Type** tối thiểu là **4-core**. Để dùng loại máy lớn hơn, bạn có thể gửi yêu cầu đến đội ngũ hỗ trợ chính thức của GitHub bằng cách tạo ticket [tại đây](https://support.github.com/contact?tags=rr-codespaces%2Ccat_codespaces).

<Frame>
  <img src="/images/dev/image.png" alt="" />
</Frame>
</Step>

<Step title="Chạy script thiết lập">
Bạn cần kiên nhẫn chờ cho đến khi codespace được tạo xong. Khi đã truy cập được Terminal, hãy chạy lệnh sau:

```text
cd develop/
bin/setup
```

<Frame>
  <img src="/images/dev/image-1.png" alt="" />
</Frame>

<Warning>

Script này (`bin/setup`) cho phép bạn thiết lập môi trường phát triển trên commit mới nhất của nhánh `server-pro` trong thời gian ngắn nhất có thể. Nó có thể không áp dụng được cho các phiên bản cũ hơn hoặc các nhánh khác.

Chúng tôi build Docker image phát triển hằng ngày bằng [GitHub Action](https://github.com/ayaka-notes/ayakaleaf-pro/actions).

</Warning>
</Step>

<Step title="Truy cập Launchpad">
Chuyển sang tab cổng (port), bạn sẽ thấy danh sách các cổng web khả dụng. Nhấp vào cổng `80`. Lúc này bạn sẽ thấy trang launchpad.

  <img src="/images/dev/image-2.png" alt="" />

Bạn sẽ thấy:

<Frame>
  <img src="/images/dev/image-3.png" alt="" />
</Frame>
</Step>

<Step title="Tận hưởng việc phát triển">
Giờ là thời gian của riêng bạn! Hãy bắt đầu xây dựng những tính năng tuyệt vời. Bạn cần chạy lệnh sau để bật hiển thị thời gian thực:

```bash title="bash" wrap
docker compose -f docker-compose.yml -f docker-compose.dev.yml -f ./docker-compose.image.yml up --no-deps --detach
```
</Step>
</Steps>
