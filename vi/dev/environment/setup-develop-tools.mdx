## Các công cụ phát triển được khuyến nghị {#develop-tools-recommended}

Các dịch vụ tùy chọn này không bắt buộc để chạy Overleaf, nhưng chúng giúp ích rất nhiều khi phát triển, gỡ lỗi và xem xét dữ liệu. Tất cả đều là một phần của môi trường phát triển, nên không cần thêm gì vào `docker-compose.yml`. Sau khi bạn đăng nhập vào trang web, menu **Dev tools** trên thanh điều hướng sẽ liên kết tới các công cụ mà trang web phục vụ trên đường dẫn riêng của nó.

| Công cụ | Địa chỉ | Được định nghĩa trong |
| --- | --- | --- |
| **Grafana**, trạng thái, số liệu và nhật ký của mọi dịch vụ | [http://localhost/grafana/](http://localhost/grafana/) | `develop/grafana/docker-compose.yml`, bật khi `GRAFANA_ENABLED=true` trong `develop/dev.rc` (mặc định) |
| **Mailpit**, hộp thư cho mọi email mà trang web gửi đi | [http://localhost/mailpit/](http://localhost/mailpit/) | `develop/mail/docker-compose.yml`, bật khi `MAILPIT_ENABLED=true` (mặc định) |
| **Mongo Express**, giao diện cho MongoDB | [http://localhost/mongo-express/](http://localhost/mongo-express/) | `develop/docker-compose.yml`, luôn bật |
| **RedisInsight**, giao diện cho dữ liệu Redis | [http://localhost/redis-insight/](http://localhost/redis-insight/) | `develop/docker-compose.yml`, luôn bật |
| **Hoppscotch**, ứng dụng API trên trình duyệt, tương tự Postman | [http://localhost:9170](http://localhost:9170/) (`HOPPSCOTCH_PORT`) | `develop/hoppscotch/docker-compose.yml`, bật khi `HOPPSCOTCH_ENABLED=true` (mặc định) |

<Warning>

Không công cụ nào trong số này có đăng nhập: người dùng ẩn danh của Grafana là quản trị viên của nó, và Mongo Express có thể thay đổi bất kỳ tài liệu nào. Trang web, Hoppscotch, Mongo Express (8081) và RedisInsight (5540) chỉ lắng nghe trên `127.0.0.1` của máy chủ, nên các máy khác không thể truy cập.

</Warning>

### Grafana {#grafana}

Grafana được trang web phục vụ tại `/grafana/` thông qua webpack-dev-server, nên không cần cổng riêng. Thư mục **Overleaf Develop** của nó có các dashboard sau:

| Dashboard | Nội dung hiển thị |
| --- | --- |
| All services (trang chủ) | Trạng thái mọi dịch vụ, chỉ số máy chủ, tải và nhật ký. Nhấp vào một dịch vụ để mở dashboard của nó |
| Server | CPU, tải, bộ nhớ, ổ đĩa và mạng của máy chủ, cùng các lần biên dịch của clsi |
| Errors | Nhật ký lỗi, phản hồi 5xx và 4xx, các thông báo lỗi thường gặp nhất và các route bị lỗi |
| Data flow | Đường đi của một chỉnh sửa: document-updater và Redis, project-history, history-v1, Mongo, kho đối tượng |
| Containers | Trạng thái mọi container, CPU, bộ nhớ, mạng và ổ đĩa, bao gồm cả biên dịch trong sandbox |
| Mỗi dịch vụ một dashboard | Các dịch vụ Node.js, git-bridge (JVM), mongo và redis |

Prometheus thu thập `/metrics` của các dịch vụ, `mongodb-exporter`, `redis-exporter`, `cadvisor` và `node-exporter`; Alloy gửi nhật ký của mọi container trong dự án tới Loki, nơi các bộ lọc **Log search**, **Service** và **Log level** của dashboard đọc chúng. Dữ liệu của chúng chỉ nằm trong container, nên tạo lại container sẽ xóa sạch. cAdvisor chạy ở chế độ đặc quyền và đọc `/`, `/sys`, dữ liệu Docker và socket containerd của máy chủ ở chế độ chỉ đọc; node-exporter đọc `/` của máy chủ.

Các dashboard được tạo tự động: hãy sửa `develop/grafana/make-dashboards` và chạy nó, thay vì chỉnh sửa các tệp JSON.

### Mailpit {#mailpit}

Với `MAILPIT_ENABLED=true`, `web` gửi mọi email tới Mailpit thay vì một máy chủ thư thật, và xác nhận email được bật (`EMAIL_CONFIRMATION_DISABLED=false`). Khi đó bạn có thể mở các liên kết kích hoạt, lời mời dự án, đặt lại mật khẩu và mã xác nhận từ hộp thư.

### Thiết lập Hoppscotch {#setup-hoppscotch}

#### Proxy cho yêu cầu API {#proxy-api-request}

Hoppscotch gửi yêu cầu từ trình duyệt, vốn không thể truy cập các dịch vụ bằng tên Docker của chúng. Proxy của nó, Proxyscotch, chạy bên trong mạng Docker và được phục vụ tại `/proxy` của địa chỉ Hoppscotch. Mở [http://localhost:9170](http://localhost:9170/), vào Settings → Interceptor, chọn **Proxy** và đặt Proxy URL thành `http://localhost:9170/proxy`. Cài đặt được lưu trong trình duyệt.

#### Nhập API của các dịch vụ {#import-the-service-apis}

`develop/hoppscotch/openapi/` có một tệp OpenAPI cho API nội bộ của mỗi dịch vụ. Trong Hoppscotch, mở Collections → Import → Import from File và chọn tất cả các tệp cùng lúc. Mỗi tệp trở thành một collection có các yêu cầu gửi tới địa chỉ Docker của dịch vụ. Các tệp tương tự được hiển thị trong phần [API dịch vụ](/vi/dev/service-api/overview).

#### Vấn đề CSRF {#csrf-problems}

<Warning>

Nếu bạn dùng Postman hoặc các công cụ gỡ lỗi khác để tạo một yêu cầu **post**, bạn có thể thấy việc đăng nhập bị **từ chối (forbidden)**, với lỗi 403. Đó là vì Overleaf được bảo vệ bằng cơ chế xác minh **csrf**.

</Warning>

<Frame>
  <img src="/images/dev/image-8.png" alt="" />
</Frame>

Trong console, bạn có thể thấy:

<Frame>
  <img src="/images/dev/image-9.png" alt="" />

Để xử lý vấn đề này khi phát triển Overleaf, bạn cần thiết lập csrf token. Dưới đây là hướng dẫn chi tiết.

<Steps>
<Step title="Thêm Pre Request">
Thêm đoạn mã sau vào Pre-Request

<Frame>
  <img src="/images/dev/image-10.png" alt="" />
</Frame>

Script như sau:

```js wrap
pm.sendRequest("http://web:3000/dev/csrf", function (err, res) {
    if (err) {
        console.log(err);
        return;
    }

    // 1) Save CSRF token (/dev/csrf)
    const token = res.text().trim();
    pw.env.set("csrftoken", token);
    console.log("csrftoken =", token);

    const setCookieHeader = (res.headers || []).find(h => h.key?.toLowerCase() === "set-cookie")?.value;
    console.log("set-cookie =", setCookieHeader);

    if (!setCookieHeader) return;

    const cookiePair = setCookieHeader.split(";")[0].trim(); // overleaf.sid=...
    pw.env.set("cookie_header", cookiePair);
    console.log("cookie_header =", cookiePair);
});
```
</Step>

<Step title="Thêm Request Header">
Bạn cần thêm các header sau:

| Tên header   | Giá trị header      |
| ------------ | ------------------- |
| Content-Type | `application/json`  |
| X-Csrf-Token | `<<csrftoken>>`     |
| Cookie       | `<<cookie_header>>` |

<Frame>
  <img src="/images/dev/image-11.png" alt="" />
</Frame>
</Step>

<Step title="Đăng nhập bằng công cụ API">
Bây giờ bạn có thể đăng nhập bằng tên người dùng và mật khẩu của mình.

```json5
{
  "_csrf": "<<csrftoken>>",
  "email": "admin@overleaf.com",
  "password": "xxxxxx"
}
```

Đây là phản hồi khi bạn nhập sai tên người dùng hoặc mật khẩu.
