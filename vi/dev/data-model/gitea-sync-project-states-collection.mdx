`giteaSyncProjectStates` lưu một tài liệu cho mỗi dự án được liên kết với một kho Gitea: kho nào, và lần đồng bộ gần nhất dừng ở đâu. Collection này thuộc module web `gitea-sync` (`services/web/modules/gitea-sync`). Schema nằm trong `services/web/modules/gitea-sync/app/models/giteaSyncProjectStates.mjs`, và mọi truy cập đều đi qua `services/web/modules/gitea-sync/app/src/SyncStateManager.mjs`. Các trường giống với [GitHub Sync Project States](/vi/dev/data-model/github-sync-project-states-collection).

#### Chỉ mục {#indexes}

| Tên | Khóa | Tùy chọn | Migration |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

`autoIndex` của Mongoose bị tắt (`services/web/app/src/infrastructure/Mongoose.mjs:7`), nên `unique: true` của schema trên `projectId` không tạo ra gì. Không có migration nào tạo chỉ mục cho collection này.

#### Ghi chú {#notes}

* API của Gitea không thể tạo commit bên ngoài một nhánh như API của GitHub. Đồng bộ commit thẳng lên nhánh được đồng bộ khi có thể tiến lên, nếu không thì commit lên một nhánh tạm rồi gộp qua một pull request (`GitMerge.mjs:16-21`).
* Một lần đồng bộ chạy dưới khóa `gitSync` của dự án, dùng chung với GitHub Sync và GitLab Sync (`GitMerge.mjs:25-32`).
* Một dự án đã xóa giữ lại tài liệu của nó cho đến khi dự án hết hạn.
* Token Gitea của người dùng nằm trong [Gitea Sync User Credentials](/vi/dev/data-model/gitea-sync-user-credentials-collection).
