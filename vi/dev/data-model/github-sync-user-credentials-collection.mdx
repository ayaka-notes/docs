`githubSyncUserCredentials` lưu một tài liệu cho mỗi người dùng đã liên kết tài khoản GitHub cho GitHub Sync. Nó lưu access token OAuth của người dùng ở dạng mã hóa. Collection này thuộc module web `github-sync` (`services/web/modules/github-sync`). Schema nằm trong `services/web/modules/github-sync/app/models/githubSyncUserCredentials.mjs`, và mọi truy cập đều đi qua `services/web/modules/github-sync/app/src/TokenManager.mjs`.

#### Các trường {#fields}

| Trường | Kiểu | Ý nghĩa | Nguồn |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Do Mongoose đặt khi upsert chèn tài liệu. | |
| `userId` | ObjectId | Người dùng Overleaf. Bắt buộc. Schema ghi `unique: true`, nhưng không có chỉ mục nào được tạo (xem Chỉ mục); upsert theo `userId` giữ một tài liệu cho mỗi người dùng. | `githubSyncUserCredentials.mjs:8`, `TokenManager.mjs:44-48` |
| `github` | String | Access token OAuth của GitHub, được mã hóa bằng `@overleaf/access-token-encryptor`. Mật khẩu lấy từ `GITHUB_TOKEN_CIPHER_PASSWORD`; nhãn mã hóa là `GITHUB_TOKEN_CIPHER_LABEL`, mặc định `2026.3-v3`. Bắt buộc. | `githubSyncUserCredentials.mjs:9`, `TokenManager.mjs:12-25` |
| `__v` | Number | Khóa phiên bản của Mongoose. Schema không tắt nó. | Mặc định của Mongoose |

Chỉ access token được lưu: callback OAuth giữ `access_token` từ phản hồi của GitHub (`services/web/modules/github-sync/app/src/GitHubApiClient.mjs:180-191`). Không có refresh token hay thời hạn.

#### Ai ghi {#who-writes-it}

| Mã | Chức năng |
| ---- | ------------ |
| `TokenManager.mjs:42-58` (`saveUserToken`) | Upsert token đã mã hóa của người dùng. Khi người dùng liên kết lại, token bị thay thế sẽ bị thu hồi trên GitHub ở chế độ nền. Được gọi từ callback OAuth (`services/web/modules/github-sync/app/src/GitHubSyncController.mjs:146`). |
| `TokenManager.mjs:61-76` (`removeUserToken`) | Thu hồi token trên GitHub (cố gắng hết mức), rồi xóa tài liệu. Được gọi khi hủy liên kết (`GitHubSyncController.mjs:167`) và khi một người dùng đã xóa hết hạn (`services/web/modules/github-sync/index.mjs:66-68`). |

#### Ai đọc {#who-reads-it}

| Mã | Chức năng |
| ---- | ------------ |
| `TokenManager.mjs:36-40` (`getUserToken`) | Giải mã token cho mỗi lệnh gọi API GitHub: `services/web/modules/github-sync/app/src/GitHubSyncHandler.mjs` (ví dụ `:27`) và `services/web/modules/github-sync/app/src/GitMerge.mjs:43`. Khi không có tài liệu, hoặc token không giải mã được, nó ném `InvalidTokenError`, và người dùng được coi là chưa liên kết (`GitHubSyncHandler.mjs:25-37`). |
| `services/web/modules/admin-tools/app/src/AdminUserListManager.mjs:393` | Kiểm tra người dùng có tài liệu hay không, cho các tích hợp hiển thị trong bảng quản trị. |

#### Chỉ mục {#indexes}

| Tên | Khóa | Tùy chọn | Migration |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

`autoIndex` của Mongoose bị tắt (`services/web/app/src/infrastructure/Mongoose.mjs:7`), nên `unique: true` của schema trên `userId` không tạo ra gì. `tools/migrations/20190912145011_create_githubSyncUserCredentials_indexes.mjs` (`user_id` của upstream) chỉ được gắn thẻ `saas` và không chạy trong CE.

#### Ghi chú {#notes}

* Đổi `GITHUB_TOKEN_CIPHER_PASSWORD` khiến các token đã lưu không đọc được. Những người dùng đó khi ấy được coi là chưa liên kết cho đến khi họ liên kết lại.
* Một người dùng đã xóa giữ lại tài liệu cho đến khi người dùng đó hết hạn.
