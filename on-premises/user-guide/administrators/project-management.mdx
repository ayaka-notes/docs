## Find a project

Type in **Search by project name, ID, owner or link**. A link can be the project's address or one of its sharing links. Use the **Status** filter to narrow the list. Click **Title** or **Last modified** to sort.

Deleted projects do not appear in the results. If your search also matches one, a line above the table says so, for example **Found 1 matching deleted projects**. Click **Display deleted projects** to see them.

## Project status

Every project has one status, and the **Status** filter shows how many projects each one has.

<Frame caption="The Status filter">
  <img src="/images/on-premises/project-management-status-filter.png" alt="The Status filter with All, Active, Archived, Trashed and Deleted" />
</Frame>

| Status       | What it means                                                                                                               |
| ------------ | --------------------------------------------------------------------------------------------------------------------------- |
| **All**      | Every project that is not deleted.                                                                                          |
| **Active**   | The normal state.                                                                                                           |
| **Archived** | The owner archived it. The project is intact and can be brought back.                                                       |
| **Trashed**  | The owner moved it to the trash. The project is intact and can be brought back.                                             |
| **Deleted**  | Deleted by the owner from the trash, by an administrator, or together with the owner's account. Only an administrator can bring it back. |

A project moves through the statuses in stages:

1. **Active, Archived and Trashed** are the owner's choice, made on their own projects page. The owner can always go back. **Restore** from the trash always leads to Active, even if the project was archived before.
2. **Deleted** is the next stage. The owner can only delete from the trash; an administrator can delete from any of the three.
3. **Restore** brings a deleted project back as **Active**, whatever its status was, and its name gets `(Restored)` at the end. Only an administrator can do this. If the owner's account is deleted too, restore the account first: otherwise the dialog says **The owner of this project is deleted: restore the owner first**.
4. **Delete permanently** is the last stage and cannot be undone. Deleted projects otherwise stay until you remove them, unless the instance sets [`ENABLE_CRON_RESOURCE_DELETION`](/on-premises/configuration/overleaf-toolkit/environment-variables), which removes them after 90 days.

<Info>

The status follows the owner only. When a collaborator archives or trashes a shared project, it moves on their own projects page, and the status here stays the same.

</Info>

## Actions on a project

| Icon        | Action                   | What it does                                                         |
| ----------- | ------------------------ | -------------------------------------------------------------------- |
| Open        | **Open Project**         | Opens the project in the editor, in a new tab.                       |
| Folder      | **Change project owner** | Gives the project to another user.                                   |
| Bin         | **Delete**               | Moves the project to **Deleted**.                                    |
| Arrow       | **Restore**              | Brings a deleted project back. Only for deleted projects.            |
| Crossed bin | **Delete permanently**   | Removes a deleted project for good. Only for deleted projects.       |

### Change the owner

Click the folder icon, type a name or email, choose the user, then click **Change project owner**. The dialog warns that this cannot be undone, and that the new owner will be notified and can change the project's access settings. Disabled accounts are not offered. If you change the text after choosing, the choice is cancelled: choose the user again.

<Frame caption="Changing a project's owner">
  <img src="/images/on-premises/project-management-change-owner.png" alt="The Change project owner dialog with a warning and a new owner chosen" />
</Frame>

To move all of a user's projects at once, see [Transfer a user's projects](/on-premises/user-guide/administrators/user-management#transfer-a-users-projects).

### Delete, restore or permanently delete

Click the bin icon, then **Delete**. To find the project again, choose **Deleted** in the **Status** filter.

<Frame caption="A deleted project">
  <img src="/images/on-premises/project-management-deleted.png" alt="A deleted project in the list with the Restore and Delete permanently icons" />
</Frame>

Click the arrow icon, then **Restore**, to bring it back, or the crossed bin, then **Delete permanently**, to remove it.

<Frame caption="Deleting a project permanently">
  <img src="/images/on-premises/project-management-purge.png" alt="The Delete permanently dialog warning that the action cannot be undone" />
</Frame>

### Change several projects at once

Tick the projects in the list. Buttons appear next to the search: **Download**, **Change project owner** and **Delete**. **Download** saves the selected projects in one `.zip` file. With **Change project owner**, the current owners of the ticked projects cannot be chosen. In the **Deleted** view, the buttons are **Restore** and **Delete permanently**.

## The project page

Click a project's title to open its page. At the top are the icons to edit, open, download and delete the project. It has five tabs.

### Overview

The project's details and settings. Click the pencil icon to change the **Name**, **Link sharing**, **Compiler**, **TeX Live version** and **Main document**, or to click **Change project owner**. Then click **Save**.

<Frame caption="Editing a project">
  <img src="/images/on-premises/project-management-edit.png" alt="The Overview tab in edit mode" />
</Frame>

### File tree

The project's files and folders, read-only.

<Frame caption="A project's files">
  <img src="/images/on-premises/project-management-files.png" alt="The File tree tab listing frog.jpg, main.tex and a restored bib file" />
</Frame>

### Members

Who has access: the owner, the collaborators and the pending invitations. Click the pencil icon to change them:

* Choose **Editor**, **Reviewer** or **Viewer** for a collaborator. The change applies at once.
* Click the bin next to a collaborator, then **Remove access**.
* For a pending invitation, click the envelope to **Resend invite**, or the bin to **Revoke Invite**.

Click **Done** when you have finished. The owner cannot be changed here: use **Change project owner** on the **Overview** tab.

<Frame caption="Changing a project's members">
  <img src="/images/on-premises/project-management-members.png" alt="The Members tab in edit mode with a role menu, a pending invitation and the action icons" />
</Frame>

### Deleted files

Files removed from the project. Click the arrow icon next to a file, then **Restore file**. A copy with the date in its name goes into the project's root folder, and the row shows its name. The deleted file stays in the list.

The copy appears on the **File tree** tab after you reload the page.

<Frame caption="A restored file">
  <img src="/images/on-premises/project-management-deleted-files.png" alt="The Deleted files tab showing sample.bib and the name of its restored copy" />
</Frame>

### Audit logs

What happened to this project: the date, the operation, who did it, the IP address and details. Search it, or filter by **Operation**.
