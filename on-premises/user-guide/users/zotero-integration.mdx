Import a Zotero library into a project as a `.bib` file, then cite from it as usual. The file is a copy: it changes only when you click **Refresh**.

<Info>

If you see no Zotero option in **Account settings**, ask your administrator to turn on [Zotero Integration](/on-premises/configuration/overleaf-toolkit/integrations/zotero-integration).

</Info>

## Link your Zotero account

You do this once.

<Steps>
<Step title="Open your account settings">
Click **Account**, then **Account settings**. Under **Reference managers**, find **Zotero** and click **Link to Zotero**.

<Frame caption="Zotero in the account settings">
  <img src="/images/on-premises/zotero-link.png" alt="The Zotero section of the account settings with a Link to Zotero button" />
</Frame>

The **Zotero** card in the editor's **Integrations** panel takes you to the same place, in the same tab.

<Frame caption="The Integrations panel">
  <img src="/images/on-premises/zotero-integrations.png" alt="The Integrations panel with the Zotero card" />
</Frame>
</Step>

<Step title="Authorize on Zotero">
Zotero opens. Sign in if you are asked to, then authorize the application. It only asks to read your library and your groups, so it cannot change anything in Zotero.
</Step>

<Step title="Check the link">
You are back in the account settings. A green message says **Reference manager linked**, and the button now says **Unlink**.

<Frame caption="Your Zotero account is linked">
  <img src="/images/on-premises/zotero-linked.png" alt="The Zotero section of the account settings with a green message and an Unlink button" />
</Frame>
</Step>
</Steps>

If you do not allow access on Zotero, the same section says **Sorry, something went wrong**. Click **Link to Zotero** to try again.

## Create a file from your library

<Steps>
<Step title="Open the Add files dialog">
Open a project. In the file tree, click **New file**, then **From Zotero**. This entry is only there once your account is linked.
</Step>

<Step title="Choose the file name and the library">
**File Name** starts as `zotero.bib`. Keep the `.bib` ending: without it you get no preview, and neither `\cite` nor `\bibliography` finds its entries.

**Library** starts as **My Library**, and also lists your group libraries. One file holds one library.

<Frame caption="A file from your personal library">
  <img src="/images/on-premises/zotero-new-file.png" alt="The From Zotero tab of the Add files dialog with zotero.bib and My Library" />
</Frame>
</Step>

<Step title="Click Create">
The dialog closes and the file is in the file tree. Click it: it shows when it was imported, and its entries. You cannot edit it in the editor.

<Frame caption="The imported file">
  <img src="/images/on-premises/zotero-file.png" alt="The imported zotero.bib open in the editor with a Refresh button" />
</Frame>

If **Create** seems to do nothing, a file with that name already exists. Choose another name.
</Step>
</Steps>

### Import a group library

Do the same again, with a file name of its own, and choose the group under **Library**. A project can have several of these files.

<Frame caption="A file from a group library">
  <img src="/images/on-premises/zotero-group.png" alt="The From Zotero tab with the file name reading-group.bib and the library Reading group" />
</Frame>

## Cite from the file

<Steps>
<Step title="Start a citation">
In a `.tex` file, type `\cite{`. The list shows the entries of all the `.bib` files in the project. Click one to insert it.

<Frame caption="The entries of the imported files">
  <img src="/images/on-premises/zotero-cite.png" alt="The editor listing citation keys under a citation" />
</Frame>
</Step>

<Step title="Or search by title or author">
Click **Search** under the list, or press Ctrl+Space inside the braces. Type to filter, click one or more entries, then click **Insert**.

<Frame caption="The reference search">
  <img src="/images/on-premises/zotero-search.png" alt="The Search the .bib files in this project dialog with one entry selected" />
</Frame>
</Step>

<Step title="Add the bibliography">
Add these lines before `\end{document}`, using the names of your files without `.bib`, separated by commas:

```latex
\bibliographystyle{plain}
\bibliography{reading-group,zotero}
```

Click **Recompile**. The reference appears in the PDF.

<Frame caption="The compiled reference">
  <img src="/images/on-premises/zotero-compiled.png" alt="The editor with the citation and bibliography, and the compiled PDF with a reference" />
</Frame>
</Step>
</Steps>

Imported files are not offered in **Settings** under **References**, **Main bibliography file for this project**, so the list stays empty if the project has no other `.bib` file. You can still cite from them.

<Frame caption="The empty list is expected">
  <img src="/images/on-premises/zotero-settings-references.png" alt="The References tab of the project settings with an empty, disabled list" />
</Frame>

## Refresh the file

Changes in your Zotero library do not reach the project on their own, and compiling does not fetch them.

<Steps>
<Step title="Open the file">
In the file tree, click the imported file.
</Step>

<Step title="Click Refresh">
The whole file is imported again from the library you chose when you created it: new entries appear and removed ones disappear. The time at the top changes.

<Frame caption="The refreshed file">
  <img src="/images/on-premises/zotero-refresh.png" alt="The refreshed zotero.bib with a new entry and a new import time" />
</Frame>
</Step>

<Step title="Recompile">
New entries are in the `\cite{` list right away. Click **Recompile** to update the PDF.
</Step>
</Steps>

Each file refreshes on its own: refresh your group's file separately. For who can refresh a file in a shared project, see the [notes for administrators](/on-premises/configuration/overleaf-toolkit/integrations/zotero-integration#notes).

## Unlink your Zotero account

In **Account settings**, under **Zotero**, click **Unlink**, then **Unlink** again in the dialog. The button says **Link to Zotero** again.

<Frame caption="Unlink your account">
  <img src="/images/on-premises/zotero-unlink.png" alt="The Unlink Zotero Account dialog" />
</Frame>

The files you imported stay in your projects and still compile. **From Zotero** is gone from the **Add files** dialog, and **Refresh** shows an error until you link your account again.

<Frame caption="Refreshing without a linked account">
  <img src="/images/on-premises/zotero-relink-error.png" alt="An imported file with the error Could not load references from Zotero, please re-link your account and try again" />
</Frame>

After you link again, **Refresh** works on the same files.

## If something goes wrong

**Could not load references from Zotero, please re-link your account and try again**, or **There was an error accessing your Zotero data** in the **Add files** dialog: Overleaf can no longer read your library, for example because you removed its access on Zotero. In **Account settings**, click **Unlink**, then **Link to Zotero**. **Create** also fails until then, with the message **The project that contains this file is not shared with you**, even in your own project.

<Frame caption="Overleaf can no longer read your library">
  <img src="/images/on-premises/zotero-access-error.png" alt="The From Zotero tab with both error messages" />
</Frame>

**The remote service produced an error** when you click **Refresh**: the request to Zotero failed. The file keeps its content. Click **Refresh** again later.
