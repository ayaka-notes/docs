#### Features 13: Python Runner

This feature is developed by overleaf official. You can run Python scripts in your browser.

It is built in and needs no configuration: open a `.py` file in a project and click **Run**. The script runs with Pyodide in the user's browser, so only Pyodide's built-in packages are available.

* The output pane below the editor shows what the script prints (the last 100 lines). Click **Stop** to interrupt a run. Each run starts a fresh Python, so nothing carries over from the previous run.
* Before each run, the project's text files are copied into the script's working folder, so the script can open them by their project path, e.g. `open('data/results.csv')`. Binary files such as images and PDFs are not copied.
* Files the script writes into that folder are saved to the project at the same path when the run succeeds, replacing a file with the same name. A failed run saves nothing. A run may save up to 50 files, 50 MB per file and 100 MB in total.
* Matplotlib has no display: save plots with `plt.savefig('figure.png')`, then include the image in your LaTeX document.
* Pyodide and its packages (such as NumPy, pandas, SciPy and Matplotlib) are served by your instance, so the browser does not need internet access. Packages installed with pip cannot be used.

#### Features 17: Reference Manager Integration

This feature is developed by [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro). Zotero integration was initially developed by [davrot](https://github.com/davrot) and [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep); we reworked it with OAuth and added Mendeley integration (OAuth 2.0) in v6.3.0. You can:

* Link your Zotero and Mendeley accounts in Account settings.
* Import your personal library or a group library as a `.bib` file into your project.
* Refresh the imported `.bib` file at any time to keep it up to date.

See [Zotero Integration](/on-premises/configuration/overleaf-toolkit/zotero-integration) and [Mendeley Integration](/on-premises/configuration/overleaf-toolkit/mendeley-integration) for setup.

#### Features 18: Open in Overleaf API

This feature is developed by [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro), compatible with the "Open in Overleaf" API of overleaf.com. You can add an "Open in Ayakaleaf" link or button to your website, blog or template library, so visitors can open a LaTeX snippet, a remote file or a ZIP project as a new project in your instance with one click. Visit `/devs` on your instance for details, and see [Overleaf Import API](/on-premises/configuration/overleaf-toolkit/overleaf-import-api).

#### Features 19: GitLab Sync

This feature is developed by [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) in v6.3.1 as an early preview (official release in v6.4.0). Like GitHub Sync, you can link a project to a repository on GitLab.com or your self-hosted GitLab, push commits from Overleaf and merge commits from GitLab. #### Features 20: Dropbox Sync

This feature is developed by [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) in v6.3.1 as an early preview (official release in v6.4.0), like Dropbox Sync on overleaf.com. Once a user links their Dropbox account, each of their projects appears as a folder in their Dropbox: changes in Overleaf are sent to Dropbox, and changes made in Dropbox come back to Overleaf. See [Dropbox Synchronisation](/on-premises/configuration/overleaf-toolkit/dropbox-synchronisation) for setup.

#### Features 21: MCP Server

This feature is developed by [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) in v6.3.1. Each project has an MCP server, so AI clients such as Claude Code, Codex, Cursor, VS Code or Gemini CLI can read and edit its files live, compile it, read the LaTeX log, download the PDF and answer comments. See [MCP Server](/on-premises/configuration/overleaf-toolkit/mcp-server) for setup.
