title: Integrations
description: Connect a Kubernetes deployment to Git, GitHub, GitLab, Gitea, Dropbox, reference managers, AI services and other sites.
icon: puzzle-piece
---

Each integration is off by default, except the Overleaf Import API. GitHub, GitLab, Gitea and Dropbox Synchronisation and the MCP server also need the [Git integration](/on-premises/configuration/kubernetes/integrations/git-integration). After turning one on in the ConfigMap or the Secret, restart the replicas with `kubectl -n overleaf rollout restart`.
