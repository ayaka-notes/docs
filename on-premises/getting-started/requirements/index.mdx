### Requirements for installing Ayakaleaf Pro and Community Edition

<Warning>

We strongly recommend you run Ayakaleaf Pro on a recent and stable version of Ubuntu (e.g. Ubuntu 24.04 in 2025–2026) with a recent version of Docker.

</Warning>
