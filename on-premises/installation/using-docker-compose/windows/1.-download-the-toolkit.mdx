<Steps>
<Step title="Install the command-line tools">
Run in **Ubuntu**, using the Linux password you created in step 0:

```bash
sudo apt update
sudo apt install -y git ca-certificates curl perl gawk openssl
```

Ubuntu already supplies Bash, GNU sed and coreutils. Unlike macOS, it does not need Homebrew or a separate GNU sed installation.
</Step>

<Step title="Clone the Ayakaleaf Toolkit repository">
Keep the Toolkit and its data in Ubuntu's Linux filesystem, under your home directory:

```bash
cd "$HOME"
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

Avoid `/mnt/c`, `/mnt/d`, OneDrive and temporary directories for the live database and project data. Linux filesystem paths provide the permissions and filesystem behavior expected by the containers, and avoid cross-filesystem overhead; see [Microsoft's filesystem guidance](https://learn.microsoft.com/en-us/windows/wsl/filesystems).

<Warning>

If the directory already contains an installation, use it as it is, or choose another directory for a new instance. Do not replace an existing deployment's configuration or data.

</Warning>
</Step>
</Steps>
