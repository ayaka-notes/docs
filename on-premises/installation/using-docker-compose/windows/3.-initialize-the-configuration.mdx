---
title: 3. Initialize the configuration
description: Create the Toolkit configuration files in Ubuntu on WSL 2 with bin/init.
icon: circle-play
---

From the Toolkit directory in **Ubuntu**, run:

```bash
bin/init
```

`bin/init` creates three files:

| File | Purpose |
| --- | --- |
| `config/overleaf.rc` | Container settings, the published port and the data locations |
| `config/variables.env` | Application settings and secrets |
| `config/version` | The application image version |

It also generates `OVERLEAF_INVITE_TOKEN_SECRET` in `config/variables.env`. Keep it, and do not publish this file or commit it to version control.

Keep the version that the Toolkit selects for a new installation. To change the version of an existing instance later, follow [Upgrading your deployment](/on-premises/maintenance/upgrading-your-deployment).

<Info>

`bin/init` does not overwrite existing configuration. If it reports that files already exist, inspect them before continuing. Keep `config/` and `data/` when restarting or upgrading the instance.

</Info>
