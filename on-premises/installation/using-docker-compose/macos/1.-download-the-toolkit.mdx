title: 1. Download the Toolkit
description: Install GNU sed and clone the Ayakaleaf Toolkit on your Mac.

<Steps>
<Step title="Check Git and Homebrew">
```bash
git --version
brew --version
```

If macOS asks you to install the Command Line Tools when you run Git, install them first. If Homebrew is missing, install it with the [official instructions](https://brew.sh/).
</Step>

<Step title="Put GNU sed on the PATH">
The Toolkit scripts use GNU sed options that the BSD sed built into macOS rejects. Install [GNU sed](https://formulae.brew.sh/formula/gnu-sed) and put it first on the `PATH` in this terminal:

```bash
brew install gnu-sed
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
sed --version
```

The last command should print **GNU sed**.

An alias such as `alias sed=gsed` is not enough: the Toolkit runs Bash scripts, which do not see the aliases of your interactive shell. You don't need to replace `/usr/bin/sed`.

Run the `export PATH=...` line again in every new terminal that you use for the Toolkit, or add it to your shell startup file after Homebrew's own initialization.
</Step>

<Step title="Clone the Ayakaleaf Toolkit repository">
Choose a directory that persists. Avoid `/tmp`, removable drives and cloud-synchronized folders such as iCloud Drive for the live database and project data. This guide uses `~/ayakaleaf-toolkit`:

```bash
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

<Warning>

If the directory already contains an installation, use it as it is, or choose another directory for a new instance. Do not initialize a new configuration over an existing deployment.

</Warning>
</Step>
</Steps>
