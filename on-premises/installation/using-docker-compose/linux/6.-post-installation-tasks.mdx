### Creating your first administrator account

In a browser, open [http://localhost/launchpad](http://localhost/launchpad). If you changed `OVERLEAF_LISTEN_IP` or `OVERLEAF_PORT`, use your `OVERLEAF_SITE_URL` instead, for example `http://192.168.1.20:8080/launchpad`. The same applies to the other `localhost` links on this page. You should see a form with email and password fields. Fill these in with the credentials you want to use as the administrator account, then click **Register**.

<Info>

Passwords must be at least 8 characters long (no more than 72), cannot contain email addresses or be too similar to email addresses, and must contain only valid characters.

</Info>

![Create the first admin account on the launchpad](/images/on-premises/post-installation-launchpad.png)

You are then taken to the login page ([http://localhost/login](http://localhost/login)). Enter the credentials. Once you're logged in, you'll see the launchpad again, now with the status checks.

![Launchpad status checks after logging in](/images/on-premises/post-installation-status-checks.png)

Click the green button at the bottom of the page to start using Overleaf.

### Creating your first example project

Open [http://localhost/project](http://localhost/project) in your browser and you will see a button prompting you to create your first project.

![Create a new project menu](/images/on-premises/post-installation-create-project.png)

Click this button, select **Example project**, and follow the on-screen instructions.

You will be taken to the new project, where you will see a text editor and a PDF preview.

![The example project in the editor](/images/on-premises/post-installation-editor.png)

To finish you can click on the Overleaf logo in the top left corner to return to your projects page.
