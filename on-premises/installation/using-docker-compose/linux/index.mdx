In this section we will guide you through installing Docker, downloading the Toolkit from GitHub, familiarizing yourself with some of the Toolkit's commands, and configuring some basic settings. By the end of this section you should have a running on-premises instance of Overleaf.

The steps target a recent Ubuntu LTS. On another distribution, install Docker Engine and the Compose plugin as described in [Docker's documentation](https://docs.docker.com/engine/install/), then continue with [1. Download the Toolkit](/on-premises/installation/using-docker-compose/linux/1.-download-the-toolkit).

<Info>

By default, the instance only accepts connections from the server itself, on `http://localhost`. To open it from other computers or on another port, set `OVERLEAF_LISTEN_IP` and `OVERLEAF_PORT` in `config/overleaf.rc`, as described in [5. Personalizing your instance](/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance).

</Info>
