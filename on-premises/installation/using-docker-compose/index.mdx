Docker Compose on a single server is the recommended way to deploy Ayakaleaf Pro. You run it through the [Toolkit](https://github.com/ayaka-notes/toolkit): a set of scripts that wrap `docker compose` and read your settings from one `config/` directory, so `bin/up` replaces `docker compose up`.
