Docker Compose on a single server is the recommended way to deploy Ayakaleaf Pro. You run it through the [Toolkit](https://github.com/ayaka-notes/toolkit): a set of scripts that wrap `docker compose` and read your settings from one `config/` directory, so `bin/up` replaces `docker compose up`.

Pick the guide for the machine that runs Docker:

| Platform          | Docker         | Use it for                                                                  |
| ----------------- | -------------- | --------------------------------------------------------------------------- |
| [Linux](/on-premises/installation/using-docker-compose/linux)   | Docker Engine  | A server, including production. This is the setup we support and test.     |
| [macOS](/on-premises/installation/using-docker-compose/macos)   | Docker Desktop | A local instance on your Mac, for personal use and testing.                 |

Both guides use the same Toolkit and the same `config/` files, so the [Docker Compose configuration](/on-premises/configuration/overleaf-toolkit) pages apply to both.
