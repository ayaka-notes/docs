### Downloading the Toolkit

You install Ayakaleaf Pro with the **Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)), a set of scripts that runs Overleaf in Docker for you.

By default, the Toolkit starts the free official Overleaf Community Edition (CE). [4. Get Ayakaleaf Pro Images](/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images) switches it to Ayakaleaf Pro with one setting.

<Accordion title="Already running the official Overleaf Toolkit (overleaf/toolkit)?">

You don't need to reinstall. Keep your installation and follow the last part of [4. Get Ayakaleaf Pro Images](/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images).

</Accordion>

<Steps>
<Step title="Clone the Ayakaleaf Toolkit repository">
To install the toolkit you'll need to navigate to the intended installation path and then clone the Ayakaleaf Toolkit repository using this command:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
```

<Info>

To prevent any potential permissions issues we recommend installing the Toolkit in your user's `$HOME` directory.

</Info>
</Step>

<Step title="Change into the toolkit directory">
Wait for the cloning process to complete then let's switch into the newly created `overleaf-toolkit` directory:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
