### Downloading the Toolkit

The Toolkit is compatible with both the Server CE and Ayakaleaf Pro and is the recommended installation method. Using the Toolkit will allow you to easily get started with Server CE and seamlessly upgrade to Ayakaleaf Pro if required.

<Info>

[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) is modified to use the overleaf-pro image from ghcr directly, with TeX Live provided by ayaka-notes. Alternatively, you can download the official overleaf-toolkit.

</Info>

<Steps>
<Step title="Clone the Overleaf Toolkit repository">
To install the toolkit you'll need to navigate to the intended installation path and then clone the Overleaf Toolkit (@Ayaka-notes) GitHub repository using this command:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
# official toolkit (Not Recommended)
# git clone https://github.com/overleaf/toolkit.git ./overleaf-toolkit
```

<Info>

To prevent any potential permissions issues we recommend installing the Toolkit in your user's `$HOME` directory.

</Info>
</Step>

<Step title="Change into the toolkit directory">
Wait for the cloning process to complete then let's switch into the newly created `overleaf-toolkit` directory:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
