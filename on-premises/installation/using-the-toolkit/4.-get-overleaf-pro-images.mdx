---
title: 4. Get Ayakaleaf Pro Images
icon: split
---

Ayakaleaf Pro is distributed as a Docker image on the [ghcr](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/) registry, with **open access** to anyone. We provide images for both amd64 and arm64 architectures. When you pull the image, the appropriate image will be automatically selected based on your system architecture.

#### Ayaka-notes Toolkit Users

If you are using [ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit),  Ayakaleaf Pro can be used as a drop-in replacement for the Community Edition, so you can use your existing settings and customizations. Enable Pro in the Toolkit by editing `config/overleaf.rc` and setting the `SERVER_PRO` environment variable:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

The next time you run `bin/up`, the Toolkit will automatically download and use the Ayakaleaf Pro image.

#### Official Toolkit Users

If you are using [overleaf/toolkit](https://github.com/overleaf/toolkit), to get a Pro image, run the following command to pull:

```bash title="Pull Docker Images"
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Then, add a file named `docker-compose.override.yml` with the following content into the `overleaf-toolkit/config` directory:

```yml title="docker-compose.override.yml"
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

The next time you run `bin/up`, the Toolkit will automatically download and use the Ayakaleaf Pro image.
