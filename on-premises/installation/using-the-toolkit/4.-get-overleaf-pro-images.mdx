---
title: 4. Get Ayakaleaf Pro Images
icon: split
---

Ayakaleaf Pro is a free Docker image on [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). You don't need an account or a login to pull it. Images are built for amd64 and arm64, and Docker picks the one that matches your server.

Open `config/overleaf.rc` and set:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

The next time you run `bin/up`, the Toolkit downloads the Ayakaleaf Pro image and uses it instead of the official Overleaf Community Edition. Your settings in `config/` keep working.

<Accordion title="Already running the official Overleaf Toolkit (overleaf/toolkit)?">

You don't need to reinstall. Pull the Ayakaleaf Pro image:

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Then add a file named `docker-compose.override.yml` with the following content into the `overleaf-toolkit/config` directory:

```yml
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

The next time you run `bin/up`, the Toolkit uses the Ayakaleaf Pro image.

</Accordion>
