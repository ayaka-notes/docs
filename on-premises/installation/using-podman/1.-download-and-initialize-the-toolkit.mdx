---
title: 1. Download and initialize the Toolkit
description: Clone the Ayakaleaf Toolkit, create the configuration and set it up for Ayakaleaf Pro on Podman.
icon: arrow-down-to-bracket
---

<Steps>
<Step title="Clone the Toolkit">
Clone the **Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)) into your home directory and change into it:

```bash title="Clone the Toolkit" wrap
git clone https://github.com/ayaka-notes/toolkit.git ~/overleaf-toolkit
cd ~/overleaf-toolkit
```

Run all the following commands from this directory.
</Step>

<Step title="Create the configuration">
```bash title="Run initialization"
bin/init
```

This creates `config/overleaf.rc`, `config/variables.env` and `config/version`, as described in [3. Initialize the configuration](/on-premises/installation/using-docker-compose/linux/3.-initialize-the-configuration) of the Docker guide. `bin/init` doesn't need Podman yet.
</Step>

<Step title="Set up config/overleaf.rc">
Open `config/overleaf.rc` and change these lines:

```bash title="config/overleaf.rc"
SERVER_PRO=true
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
```

Then add this line at the end of the file:

```bash title="config/overleaf.rc"
SELINUX_MODE=managed
```

| Setting                           | Why                                                                                                                                                                                                         |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SERVER_PRO=true`                 | Uses the Ayakaleaf Pro image from `ghcr.io`. No login is needed.                                                                                                                                             |
| `OVERLEAF_PORT=8080`              | Rootless Podman can't listen on ports below `1024`. The default `80` fails.                                                                                                                                  |
| `SIBLING_CONTAINERS_ENABLED=true` | Runs each compile in its own TeX Live container. Already `true` by default; the Podman setup only supports this mode.                                                                                       |
| `SELINUX_MODE=managed`            | Runs the `sharelatex` container with the SELinux type `sharelatex_t`, which may use the Podman socket and nothing more. `bin/podman-setup --apply` installs the policy module for it. See [Toolkit settings](/on-premises/configuration/overleaf-toolkit/toolkit-settings) for the other modes. |

Leave `DOCKER_SOCKET_PATH` as it is: `bin/podman-setup --apply` sets it to your Podman socket in the next step.

<Warning>

Keep `GIT_BRIDGE_ENABLED=false`. In Ayakaleaf Pro 6.3.4 the Git integration doesn't work on Podman, see [Known limitations](/on-premises/installation/using-podman#known-limitations).

</Warning>
</Step>

<Step title="Choose the TeX Live images">
Open `config/variables.env`, remove the `#` in front of `TEX_LIVE_DOCKER_IMAGE` and `ALL_TEX_LIVE_DOCKER_IMAGES`, and list the TeX Live images to use:

```bash title="config/variables.env" wrap
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
```

`bin/up` stops with `Please configure ALL_TEX_LIVE_DOCKER_IMAGES` if the list is empty. `texlive-full` is large; for a test server, the much smaller `ghcr.io/ayaka-notes/texlive-basic:2026.1` works too. See [Sandboxed Compiles](/on-premises/configuration/overleaf-toolkit/sandboxed-compiles) for the available images.

Set the other variables, such as `OVERLEAF_SITE_URL`, as described in [5. Personalizing your instance](/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance#required-environment-variables). With the default listen address, use `http://localhost:8080`.
</Step>
</Steps>
