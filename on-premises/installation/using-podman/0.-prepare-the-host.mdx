title: 0. Prepare the host
description: Check the operating system and SELinux, and install git, before setting up rootless Podman.

You don't install Podman by hand: [2. Run podman-setup](/on-premises/installation/using-podman/2.-run-podman-setup) installs it with the other packages it needs. Here you only check the host and install `git`, which you need to download the Toolkit.

<Steps>
<Step title="Check the operating system and SELinux">
Log in as the user that will run Ayakaleaf Pro, not as `root`, and check the distribution and the SELinux mode:

```bash title="Check the host"
grep PRETTY_NAME /etc/os-release
getenforce
```

You should see RHEL, Rocky Linux, AlmaLinux or CentOS Stream with version 9 or later, and `Enforcing`:

```text
PRETTY_NAME="Rocky Linux 9.9 (Blue Onyx)"
Enforcing
```
</Step>

<Step title="Check that you can use sudo">
`bin/podman-setup --apply` installs packages and loads an SELinux module with `sudo`, and asks for your password when it needs it:

```bash title="Check sudo"
sudo -v
```

If this fails, ask your administrator to add your user to the `wheel` group.
</Step>

<Step title="Install git">
```bash title="Install git"
sudo dnf install -y git
```

<Warning>

Don't install Docker Engine on this host. The package `podman-docker`, which `bin/podman-setup` installs, provides the `docker` command, and the Toolkit treats the host as Podman whenever the `podman` command exists.

</Warning>
</Step>
</Steps>
