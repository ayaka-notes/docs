### Create your first administrator account

Open [http://localhost:8080/launchpad](http://localhost:8080/launchpad), or your `OVERLEAF_SITE_URL` followed by `/launchpad`, and register the administrator account. From here on everything works as with Docker: follow [6. Post-installation tasks](/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks) of the Docker guide, using port `8080` in its `localhost` links.

Create the example project and compile it. The PDF shows that compiles run in their TeX Live containers through Podman. To see the compile container:

```bash title="List the compile containers"
podman ps -a --filter name=project- --format "{{.Names}} {{.Image}} {{.Status}}"
```

### Use HTTPS

The Toolkit's [TLS proxy](/on-premises/configuration/overleaf-toolkit/tls-proxy) works on Podman: run `bin/init --tls`, set your certificate and `NGINX_ENABLED=true` as described there. It listens on ports `80` and `443`, which rootless Podman may not use by default. Allow unprivileged users to use ports from `80` up:

```bash title="Allow ports 80 and 443"
echo "net.ipv4.ip_unprivileged_port_start=80" | sudo tee /etc/sysctl.d/99-unprivileged-ports.conf
sudo sysctl --system
```

This lets every user on the server listen on these ports, so only do it on a server dedicated to Ayakaleaf Pro. Then open them in the firewall:

```bash title="Open ports 80 and 443"
sudo firewall-cmd --permanent --add-port=80/tcp --add-port=443/tcp
sudo firewall-cmd --reload
```

Set `OVERLEAF_SITE_URL` to your `https://` address and run `bin/up -d`. Keep the defaults `NGINX_HTTP_PORT=80` and `TLS_PORT=443`: with other ports, the redirect from HTTP to HTTPS leads to the wrong port.

<Info>

Leave `OVERLEAF_LISTEN_IP` at `127.0.0.1` when you use the TLS proxy, so that port `8080` isn't reachable from other computers.

</Info>

### Upgrade

Upgrade with `bin/upgrade`, as described in [Upgrading your deployment](/on-premises/maintenance/upgrading-your-deployment). On Podman it also extracts the seccomp profile of the new version to `config/seccomp/<version>/` and updates `SECCOMP_PROFILE`:

```text
Over-writing config/version with 6.3.4
Set SECCOMP_PROFILE=/home/<user>/overleaf-toolkit/config/seccomp/6.3.4/clsi-profile.json in config/variables.env
```

After an upgrade, run `bin/podman-setup` to check the setup.

### Change the SELinux mode

`SELINUX_MODE` in `config/overleaf.rc` sets how SELinux confines the `sharelatex` container. `managed` is the one these pages set up; the other modes are described in [Toolkit settings](/on-premises/configuration/overleaf-toolkit/toolkit-settings). Run `bin/up -d` after changing it.
