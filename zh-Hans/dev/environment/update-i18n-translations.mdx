---
title: 更新 i18n 翻译
icon: language
---

前端只加载 `services/web/frontend/extracted-translations.json` 中列出的翻译键（`services/web/frontend/translations-loader.js`）。后端及其模板读取 `services/web/locales/` 中的完整文件。

首次设置后在 `develop` 目录中运行一次，之后每次添加翻译或切换分支后再运行一次：

```bash
bin/i18n
```

`bin/i18n` 会做两件事：

1. 将 `services/web/locales/*.json` 重置为已提交的文件，然后按照镜像构建的方式应用语言补丁：最高版本的 `locales_patches/v*` 文件夹中的文件替换语言文件，再将 `locales_patches/added/*.json` 按键逐一合并到其上。
2. 在 `webpack` 容器中以 `node` 用户运行 `yarn run extract-translations`，重写 `extracted-translations.json`。如果缺少 webpack 镜像，它会先用 `bin/sync` 同步 `yarn.lock` 并构建镜像。

它需要主机上安装 `jq`。

<Warning>

`bin/i18n` 对 `services/web/locales/*.json` 所做的修改仅在本地有效。请不要提交这些修改。

</Warning>

请尽可能复用已有的键。语言文件来自 Overleaf 上游或第三方翻译网站，因此不要直接编辑它们。新键应添加到 `services/web/locales/locales_patches/added/` 中，并同时写入每种语言的文件（`en.json`、`zh-CN.json` 等）。
