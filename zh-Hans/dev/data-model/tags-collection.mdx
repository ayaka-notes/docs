`tags` 保存用户在项目面板上用来归类项目的标签（文件夹）。一个文档是一个用户的一个标签。由 `web` 负责；schema 为 `services/web/app/src/models/Tag.mjs`，所有写入都经过 `services/web/app/src/Features/Tags/TagsHandler.mjs`。

#### 字段 {#fields}

| 字段 | 类型 | 含义 | 来源 |
| --- | --- | --- | --- |
| `_id` | ObjectId | 标签 id，用于 `/tag/:tagId` 路由。 | `Tag.mjs:10` |
| `user_id` | String | 标签的所有者。由于历史原因，这是普通字符串，而不是 ObjectId。 | `Tag.mjs:7-12` |
| `name` | String | 标签名称，最多 50 个字符（`MAX_TAG_LENGTH`）。每个用户内唯一。 | `Tag.mjs:13`, `TagsHandler.mjs:4` |
| `color` | String | 可选颜色：类似 `#a1b2c3` 的十六进制代码，或 `hsl(<n>, 70%, 45%)` 值（`TAG_COLOR_REGEX`）。 | `Tag.mjs:5`, `Tag.mjs:14-22` |
| `project_ids` | Array of String | 此标签中项目的 id，以字符串形式保存。 | `Tag.mjs:23` |
| `__v` | Number | Mongoose 版本键，在 `Tag.create` 创建文档时添加。 | `TagsHandler.mjs:27` |

#### 索引 {#indexes}

| 名称 | 键 | 选项 | 迁移 |
| --- | --- | --- | --- |
| `user_id_1_name_1` | `{ user_id: 1, name: 1 }` | unique | `tools/migrations/20190912145029_create_tags_indexes.mjs` |

同一迁移还创建了 `user_id_1`；由于复合索引已覆盖它，`tools/migrations/20231031164732_drop_redundant_indexes.mjs` 会再次删除它。

#### 说明 {#notes}

* 标签按用户区分：同一项目的两位协作者各自保留自己的标签。
* `user_id` 和 `project_ids` 是字符串，因此请用字符串 id 查询，而不是 ObjectId。
* 删除用户（`services/web/app/src/Features/User/UserDeleter.mjs`）不会改动 `tags`。
