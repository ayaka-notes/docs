---
title: Dropbox Projects 集合
icon: folder-open
---

`dropboxProjects` 将一个项目映射到某个用户 Dropbox 中的文件夹。与多个 Dropbox 用户共享的项目，每个用户各有一个文档。该集合属于 Dropbox 同步：third-party-datastore（`services/third-party-datastore/app/js/StateManager.mjs`）写入它，`dropbox` web 模块（`services/web/modules/dropbox/app/src/DropboxHandler.mjs`）读取并清除它。没有 Mongoose schema。

#### 字段 {#fields}

| 字段 | 类型 | 含义 | 来源 |
| ---- | ---- | ---- | ---- |
| `_id` | ObjectId | 插入时由驱动设置。 | `StateManager.mjs:144` |
| `userId` | ObjectId | 其 Dropbox 中有该文件夹的 Overleaf 用户。 | `StateManager.mjs:145` |
| `projectId` | ObjectId | 同步到该文件夹的项目。 | `StateManager.mjs:146` |
| `dropboxId` | String | Dropbox 文件夹元数据中该文件夹的 `id`。 | `StateManager.mjs:147`、`JobProcessor.mjs:82-87`、`PullManager.mjs:138` |
| `pathLower` | String | 文件夹在 Dropbox 中的路径，小写且不带末尾斜杠。项目文件夹位于顶层，每个项目一个，例如 Dropbox 在另一个项目的 `Thesis` 旁为其编号时为 `/thesis (1)`。 | `StateManager.mjs:14-16,148`、`PullManager.mjs:112-117` |

#### 索引 {#indexes}

| 名称 | 键 | 选项 | 迁移 |
| ---- | -- | ---- | ---- |
| `_id_` | `_id: 1` | | default |

CE 在这里没有其他索引。唯一索引 `projectId_userId_1` 和 `userId_dropboxId_1` 来自 `tools/migrations/20220815105500_create_dropboxProjects_index.mjs` 和 `20220817120900_create_dropboxProjects_index.mjs`，它们只带有 `saas` 标签，因此 CE 从不运行它们。

#### 说明 {#notes}

* 唯一性仅来自 `setProjectFolder` 中每次插入前的删除（`StateManager.mjs:140-149`）。`StateManager.mjs:3-11` 的注释提到了唯一索引；CE 没有这些索引。
* 项目的映射被删除后，其文件夹仍留在 Dropbox 中。在那里的编辑会被当作新项目读取，与在 Dropbox 中创建的文件夹一样（`DropboxHandler.mjs:148-149`）。
* 已删除的项目在过期前保留其映射，因为它仍可被恢复（`index.mjs:52-53`）。
* 用户的 Dropbox `list_folder` 游标不在这里，而在 `users.dropbox.cursor` 中（`StateManager.mjs:177-184`）。
