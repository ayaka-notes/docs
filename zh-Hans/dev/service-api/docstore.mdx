title: docstore
icon: database
---

将每个项目的每个文档（行、版本、范围）存储在 Mongo 的 `docs` 集合中，并在设置了后端时将文档归档到对象存储。由 web 调用；document-updater 通过 web 访问它。

* <strong>地址：</strong> `http://docstore:3016`, 位于 Docker 网络内
* <strong>认证：</strong>无
* <strong>OpenAPI 文件：</strong> [`develop/hoppscotch/openapi/docstore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/docstore.yaml)
