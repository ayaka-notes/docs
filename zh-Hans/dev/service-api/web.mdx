web（Overleaf 主应用）的私有 API。其他服务（real-time、document-updater、project-history、third-party-datastore、git-bridge）和 Server CE 镜像的 cron 脚本会调用它。这些路由只需要 HTTP 基本认证，不需要 CSRF 令牌：私有路由器挂载在 web 路由器之前，只有 web 路由器会执行 CSRF 检查。设置 `BLOCK_CROSS_ORIGIN_REQUESTS=true`（默认关闭）后，对于 `Origin` 请求头不在 `ALLOWED_ORIGINS`（默认：站点 URL）中的任何请求，web 都返回 403。浏览器在 POST 时会发送 `Origin`，因此开启该开关后，从浏览器中的 Hoppscotch 发送的 POST 会收到 403，除非经过 Hoppscotch 代理。

* <strong>地址：</strong> `http://web:3000`, 位于 Docker 网络内
* <strong>认证：</strong>使用 `WEB_API_USER` 和 `WEB_API_PASSWORD` 的 HTTP 基本认证，status、health 和 metrics 除外。git-bridge 路由改用个人访问令牌。
* <strong>OpenAPI 文件：</strong> [`develop/hoppscotch/openapi/web.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/web.yaml)
