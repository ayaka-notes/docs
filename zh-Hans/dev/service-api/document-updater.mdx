将编辑器中打开的文档保存在 Redis 中，对其应用编辑，并通过 web 写回 Mongo。由 web 和 real-time 调用。

* <strong>地址：</strong> `http://document-updater:3003`, 位于 Docker 网络内
* <strong>认证：</strong>无
* <strong>OpenAPI 文件：</strong> [`develop/hoppscotch/openapi/document-updater.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/document-updater.yaml)
