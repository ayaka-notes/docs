将在项目列表中向用户显示的通知（例如项目邀请）存储在 Mongo 的 `notifications` 集合中。由 web 和 third-party-datastore 调用；它没有认证，只能在 Docker 网络内访问。

* <strong>地址：</strong> `http://notifications:3042`, 位于 Docker 网络内
* <strong>认证：</strong>无
* <strong>OpenAPI 文件：</strong> [`develop/hoppscotch/openapi/notifications.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/notifications.yaml)
