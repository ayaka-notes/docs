将项目聊天和评论线程（其消息和已解决状态）存储在 Mongo 的 `rooms` 和 `messages` 集合中。由 web 通过 `ChatApiHandler` 调用。

* <strong>地址：</strong> `http://chat:3010`, 位于 Docker 网络内
* <strong>认证：</strong>无
* <strong>OpenAPI 文件：</strong> [`develop/hoppscotch/openapi/chat.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/chat.yaml)
