在 Redis 中为每个项目的编辑排队，将其转换为历史变更并发送给 history-v1；它还在 Mongo 中保存历史标签、重新同步状态和失败记录。由 web、document-updater、history-v1 和 server-ce 的 cron 脚本调用；它没有认证。

* <strong>地址：</strong> `http://project-history:3054`, 位于 Docker 网络内
* <strong>认证：</strong>无
* <strong>OpenAPI 文件：</strong> [`develop/hoppscotch/openapi/project-history.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/project-history.yaml)
