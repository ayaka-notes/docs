将项目与 Dropbox 同步：它为每个用户维护一个 Redis 任务队列，并有一个 worker 将 Overleaf 的变更发送到 Dropbox 并轮询 Dropbox 的变更。只有 web 调用它，用于加入任务和读取队列长度。

* <strong>地址：</strong> `http://third-party-datastore:3002`, 位于 Docker 网络内
* <strong>认证：</strong>无
* <strong>OpenAPI 文件：</strong> [`develop/hoppscotch/openapi/third-party-datastore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/third-party-datastore.yaml)
