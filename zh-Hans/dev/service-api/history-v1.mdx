存储每个项目的完整历史：变更块存放在 Mongo 或 Postgres 以及对象存储中，文件内容以 blob 形式存储。project-history 向其写入变更；web、project-history 和 git-bridge 从中读取 blob、快照和 zip。

* <strong>地址：</strong> `http://history-v1:3100`, 位于 Docker 网络内
* <strong>认证：</strong>根据路由不同，使用 `STAGING_PASSWORD` 以 `staging` 身份进行 HTTP 基本认证，或使用 JWT。
* <strong>OpenAPI 文件：</strong> [`develop/hoppscotch/openapi/history-v1.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/history-v1.yaml)
