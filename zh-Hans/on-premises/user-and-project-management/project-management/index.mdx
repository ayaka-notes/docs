### 查看项目审计日志

管理员可以查看每个项目的**审计日志**。审计日志会显示各类事件，例如链接共享方式在私有/基于令牌之间的切换、邀请的发送/接受，以及用户通过令牌加入项目等。管理员可以通过 **Your Instance** -> **Admin** -> **Manage Users** 按项目查看这些日志，然后：

* 搜索该用户
* 点击 **Projects** 选项卡
* 选择一个项目
* 点击 (i) 图标
* 点击 **Audit Log** 选项卡

如果项目通过邮箱地址共享给了指定的协作者，那么在对方加入后，他们将连同其权限一起显示在共享对话框中，项目所有者可以看到。管理员在通过管理面板查看该项目的 Project Info 选项卡时，也会看到这些信息。

### 恢复已删除的文档

1. 使用管理员凭据登录
2. 点击 **Admin** 并选择 **Manage Users**
3. 在搜索框中输入你要为其恢复文档的用户的邮箱
4. 在返回的结果列表中点击该用户的邮箱地址，打开其用户信息页面
5. 点击 **Projects** 选项卡，并使用搜索框搜索该项目
6. 点击项目名称旁边的信息图标，打开 **Project Info**
7. 点击 **Deleted Docs** 选项卡
8. 点击已删除文档旁边的 **Undelete** 按钮，将其恢复到用户的项目中。

恢复的文件将采用以下格式：`FILENAME-TIMESTAMP.EXTENSION`。例如，`main.tex` 的恢复版本将被恢复到项目根目录，文件名为 `main-2024-02-23-130441542.tex`。

### 转移项目所有权

Server Pro 的管理面板为每个项目提供了专门的页面。你可以在"/admin/user"上搜索该用户，然后进入其 **Projects** 选项卡，在列表中找到该项目并点击信息图标；也可以使用已知的项目 ID 直接访问页面 [**https://your-instance-url/admin/project/**](https://your-instance-url/admin/project/)。在项目信息页面上，你可以找到 **Transfer Ownership** 按钮，点击后会打开一个对话框，你可以在其中指定任意用户作为新的所有者。新所有者不必是该项目的现有协作者。

<Info>

请注意，在所有权转移过程中，原所有者会被添加为对该项目拥有读写权限的协作者。

</Info>

### 更新项目编译超时

项目的默认编译超时时间目前设置为 180 秒。可以更改此值，需要分两步完成。

首先，编辑 **config/variables.env** 文件，添加 `COMPILE_TIMEOUT` 环境变量，并将其值设置为所需的超时时间（以秒为单位）。例如，`COMPILE_TIMEOUT=300` 表示 5 分钟。

<Danger>

将超时时间设置为超过 10 分钟没有意义。如果这样做，你很可能会在应用程序的其他组件中遇到超时。

</Danger>

完成此更改后，你需要运行 `bin/up -d` 命令重新创建 **sharelatex** 容器。

设置此环境变量只会更新新用户的超时值，**不会**追溯应用于现有用户，因为该值是在用户首次创建时写入的。

要调整现有用户的超时时间，你需要修改数据库中的每条用户记录。我们建议在执行此操作时务必谨慎，并建议在进行任何更改之前先进行一致性备份。

你可以在[这里](/zh-Hans/on-premises/maintenance/data-and-backups)找到有关执行备份的信息。

要更新所有现有用户的编译超时值，你需要在 Docker 宿主机上运行以下 shell 命令：

```bash wrap
echo 'db.users.updateMany({}, {$set: {"features.compileTimeout": <value>}})' | docker exec -i mongo mongosh --quiet localhost/sharelatex
```

你需要将上述查询中的 `<value>` 替换为所需的超时值（以秒为单位）。

命令执行完成后，你应该会看到一条确认信息，其中包含被修改的记录数。然后你可以输入 exit 并按回车键返回宿主机 shell。

### 跟踪项目访问

可以使用以下命令查看项目在何时被何人加载：

```bash wrap
docker exec sharelatex bash -c 'grep "join project request" /var/log/overleaf/web.log'
```

这将提供 `timestamp`、`user_id` 和 `project_id`。
