---
title: 从 Server Pro 迁移到 Group Professional
icon: rectangle-pro
noindex: true
---

从自托管的 Server Pro 实例切换到基于云的全新 Overleaf Group Professional 订阅是一项重大变更，为了让这一过程尽可能顺利，我们整理了以下指南。

一般而言，我们建议从你的续订日期开始设置一个为期三个月的过渡期。这意味着：

* 你现有的 Server Pro 实例和新的 Group Professional 订阅将同时完全可用。
* 你的技术团队可以安排时间设置 Group Professional 订阅，并决定本地部署的 Server Pro 的后续处理方式。
* 最重要的是，你的用户将有充足的时间把他们的项目复制到新的 Overleaf Group Professional 平台。

本快速指南将引导你完成此次迁移的关键步骤。让我们开始吧！

<Steps>
<Step title="阶段 1：设置与配置">
（链接：https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-1-setup-and-configuration）

* Overleaf 将为你创建 Group Professional 订阅，并添加你的主管理员。
* 你的群组管理员将能够启用[托管用户](https://docs.overleaf.com/groups/user-management/managed-user-accounts)、配置[单点登录（SSO）](https://docs.overleaf.com/groups/overleaf-group-single-sign-on/setting-up-group-sso)，以及[邀请最终用户](https://docs.overleaf.com/groups/user-management/how-to-add-and-remove-users)。

<Warning>

启用托管用户并实施 SSO 是满足 FedRAMP® LI-SaaS 合规要求的必要步骤。如果你的组织需要符合 FedRAMP 要求，请在邀请最终用户之前设置好托管用户和 SSO。

</Warning>
</Step>

<Step title="阶段 2：用户迁移与数据管理">
（链接：https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-2-user-migration-and-data-management）

这是主要的迁移窗口期，各方职责如下：

#### 最终用户

* 用户应将希望保留的所有项目从你的 Server Pro 实例迁移到他们在 [overleaf.com](http://overleaf.com/) 上的新账户。具体过程是从 Server Pro [导出项目](https://www.overleaf.com/learn/how-to/Exporting_your_work_from_Overleaf)，然后将其[上传](https://www.overleaf.com/learn/how-to/Uploading_a_project)到他们在 [overleaf.com](http://overleaf.com/) 上的账户。如果用户还没有 [overleaf.com](http://overleaf.com/) 账户，可以在 [overleaf.com/register](http://overleaf.com/register) 注册。

<Warning>

通过此导出流程只会转移项目源代码（LaTeX 和二进制文件）。现有的项目设置、共享设置、评论、修订跟踪等都**不会**被转移。用户需要在迁移后重新邀请他们的协作者。

</Warning>

#### 技术人员

* 在此阶段，你的技术团队应规划迁移后如何处理本地部署的 Server Pro 实例及其数据。
* **数据备份：** 你可以在停用之前导出所有项目，以创建一个归档，以便协助那些可能忘记迁移或下载其作品的用户。说明：https://docs.overleaf.com/on-premises/maintenance/data-and-backups/exporting-projects
* **Server Pro 停用：** 在迁移窗口期结束且你的许可证密钥被禁用后，对于 Server Pro 实例本身，你有两个主要选项（参见下一步）。
</Step>

<Step title="Server Pro 停用选项">
<Steps>
<Step title="完全卸载 Server Pro">
卸载将停用 Server Pro 并彻底删除该软件。
</Step>

<Step title="切换到社区版">
切换会将实例从 Server Pro 转换为社区版，从而保留包含完整项目历史的用户和项目数据库。
</Step>
</Steps>

<Info>

社区版**不**包含[沙盒编译](https://docs.overleaf.com/on-premises#overview-of-server-pro-and-community-edition)，也不包含 [LDAP](/zh-Hans/on-premises/configuration/overleaf-toolkit/authentication/ldap-authentication)/[SAML](/zh-Hans/on-premises/configuration/overleaf-toolkit/authentication/saml-authentication)。如果你需要恢复为原生认证（用户名/密码），请参阅：https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-to-ldap-or-saml#going-the-other-way-switching-from-ldap-saml-back-to-native-authentication

有关 Server CE 与 Server Pro 的对比，请参阅：https://docs.overleaf.com/on-premises/welcome/server-pro-vs.-community-edition

</Info>
</Step>

<Step title="阶段 3：停用 Server Pro">
（链接：https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-3-server-pro-decommission）

* Overleaf 团队将正式停用你的 Server Pro 许可证密钥，并在完成后发送确认。
* 届时，请执行上述停用操作之一：完全卸载 Server Pro 或切换到社区版。
</Step>
</Steps>

上文引用的其他资源和链接保持不变。
