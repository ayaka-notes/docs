文献搜索会查找项目中所有的 `.bib` 文件，因此你无需记住引用键也能找到参考文献。无需任何设置。

你的项目至少需要一个 `.bib` 文件。你可以上传一个，或从 [Zotero](/zh-Hans/on-premises/user-guide/users/zotero-integration) 或 [Mendeley](/zh-Hans/on-premises/user-guide/users/mendeley-integration) 导入文献库。

## 插入引用 {#insert-a-citation}

<Steps>
<Step title="开始引用">
在 `.tex` 文件中输入 `\cite{`。编辑器会自动补上右花括号。光标下方会显示引用键和一个蓝色框 **Open advanced reference search**。

<Frame caption="引用下方的蓝色框">
  <img src="/images/on-premises/reference-search-hint.png" alt="编辑器中的 \cite{}、引用键列表以及带 Search 按钮的蓝色框" />
</Frame>

工具栏中的 **Insert citation** 按钮，以及 **Insert** 再选择 **Citation**，也会为你插入 `\cite{}`。其他引用命令也会显示该框，例如 `\citep`、`\autocite`、`\parencite` 和 `\textcite`。
</Step>

<Step title="打开搜索">
点击蓝色框中的 **Search**，或在花括号之间按 Ctrl+Space。对话框会列出每个条目及其标题、引用键、作者、期刊和年份。

<Frame caption="项目中的所有条目">
  <img src="/images/on-premises/reference-search-dialog.png" alt="列出五个条目的 Search the .bib files in this project 对话框" />
</Frame>
</Step>

<Step title="查找条目">
在搜索框中输入。它会在引用键、作者、标题、期刊和年份中查找，并高亮匹配内容。每个词都必须匹配，因此 `turing 1936` 会找到 Turing 1936 年的论文。其他字段（例如出版社）不会被搜索。

<Frame caption="按作者和年份搜索">
  <img src="/images/on-premises/reference-search-filter.png" alt="搜索框中输入 turing 1936，一个条目的匹配内容以红色显示" />
</Frame>
</Step>

<Step title="选择一个或多个条目">
点击一个条目。它会变成绿色，其键会显示在列表上方。要再添加一个，点击它或重新搜索：已选内容会保留。要移除某个条目，再次点击它或点击其键旁的 <strong>×</strong>。

<Frame caption="已选择两个条目">
  <img src="/images/on-premises/reference-search-selected.png" alt="列表上方的 knuth1984 和 einstein1905 两个键，以及它们以绿色显示的条目" />
</Frame>
</Step>

<Step title="点击 Insert">
这些键会以逗号分隔出现在花括号之间。如果文档还没有参考文献列表，请在 `\end{document}` 之前添加以下几行，使用不带扩展名的 `.bib` 文件名：

```latex
\bibliographystyle{plain}
\bibliography{refs,more}
```

点击 **Recompile**。参考文献会出现在 PDF 中。

<Frame caption="编译后的引用">
  <img src="/images/on-premises/reference-search-compiled.png" alt="编辑器中的 \cite{knuth1984, einstein1905}，以及包含两条参考文献的 PDF" />
</Frame>
</Step>
</Steps>

在 **Visual** 编辑器中，搜索的用法完全相同。

## 修改引用 {#change-a-citation}

<strong>添加参考文献：</strong>将光标放在现有引用的花括号之间，然后打开搜索。**Insert** 会把新键添加到已有键之后。

<strong>替换参考文献：</strong>在编辑器中选中这些键，然后按 Ctrl+Space。这些键会显示在列表上方，按钮变为 **Replace**。移除不需要的键，添加其他键，然后点击 **Replace**。不在任何 `.bib` 文件中的键会一直保留，直到你将其移除。

  <img src="/images/on-premises/reference-search-replace.png" alt="列表上方显示 knuth1984、missing2000 和 turing1936 以及 Replace 按钮的对话框" />
</Frame>

## 使用键盘 {#use-the-keyboard}

| 按键 | 作用 |
| --- | ------------ |
| **下箭头** | 从搜索框移入列表，然后在列表中向下移动 |
| **上箭头** | 在列表中向上移动 |
| **空格** | 选择该条目，或将其从已选内容中移除 |
| **回车** | 在列表中时，插入已选内容 |
| **Tab** | 在搜索框、列表和按钮之间切换 |
| **Esc** | 关闭对话框，不做任何更改 |

## 条目的来源 {#where-the-entries-come-from}

搜索涵盖项目中的每个 `.bib` 文件，包括从 Zotero 或 Mendeley 导入的文件。编辑 `.bib` 文件后，下一次搜索就能找到新条目。

## 如果出现问题 {#if-something-goes-wrong}

| 你看到的情况 | 原因 | 解决方法 |
| ------------ | --- | ---------- |
| 对话框中的列表为空 | 项目中没有 `.bib` 文件 | 上传或创建一个 |
| 没有蓝色框，且 Ctrl+Space 列出的是 LaTeX 命令 | 光标不在引用的花括号之间 | 点击花括号之间 |
| Ctrl+Space 没有反应 | 你的电脑将此快捷键用于其他用途 | 点击蓝色框中的 **Search** |
| 找不到某个条目 | 搜索只涵盖键、作者、标题、期刊和年份 | 按其中某个字段搜索 |
