你可以在编辑器中发布模板，并在模板库中的模板页面或管理面板中管理模板。

<Info>

要开启模板库、选择其分类或允许非管理员用户发布模板，请参阅[模板](/zh-Hans/on-premises/configuration/overleaf-toolkit/templates)。

</Info>

## 发布项目 {#publish-a-project}

<Steps>
<Step title="编译项目">
打开项目并点击 **Recompile**。你看到的 PDF 就是模板库将显示的 PDF。

当编辑器中没有 PDF 时，例如打开一个无法编译的项目时，**Manage Template** 会显示为灰色。

<Frame caption="还没有 PDF，因此无法发布">
  <img src="/images/on-premises/templates-admin-no-pdf.png" alt="File 菜单中 Manage Template 显示为灰色，旁边是 No PDF 提示" />
</Frame>

<Warning>

发布会保存文件的当前状态，以及最后一次成功编译生成的 PDF。如果你在那次编译之后编辑了项目，或者最后一次编译失败，模板库会在较新的文件旁显示旧的 PDF，而这些文件可能无法编译。请反复编译直到 PDF 正确，然后再发布。

</Warning>
</Step>

<Step title="打开表单">
在编辑器的顶部菜单中，点击 **File**，然后点击 **Manage Template**。

<Frame caption="File 菜单">
  <img src="/images/on-premises/templates-admin-file-menu.png" alt="包含 Manage Template 的 File 菜单" />
</Frame>
</Step>

<Step title="填写表单">
<Frame caption="Manage Template 对话框">
  <img src="/images/on-premises/templates-admin-publish-form.png" alt="已填写的 Manage Template 对话框，作者为 Markdown 链接，描述中使用了 Markdown" />
</Frame>

| 字段 | 说明 |
| --- | --- |
| **Title** | 默认为项目名称。在模板库中必须唯一。最多 150 个字符。 |
| **Author** | 默认为你的名字。像 `[Demo Author](https://example.com)` 这样的 Markdown 链接会在模板页面上显示为链接。 |
| **Categories** | 一个分类，请参阅[分类](/zh-Hans/on-premises/user-guide/administrators/template-management#categories)。 |
| **Description** | 支持 Markdown。最多 4096 个字符。模板页面将其显示为 **Abstract**，模板库以纯文本显示其开头部分。 |
| **License** | **Creative Commons CC BY 4.0**、**LaTeX Project Public License 1.3c** 或 <strong>Other (as stated in the work)</strong>。 |

项目的编译器和主文档会随模板一起保存，因此请先在项目中设置好它们。从模板打开的项目会使用相同的设置。
</Step>

<Step title="点击 Publish">
模板页面随即打开。

<Frame caption="新模板">
  <img src="/images/on-premises/templates-admin-template-page.png" alt="模板页面，包含 Open as Template、View PDF 和下载按钮、详细信息，以及 Admin: Source Project、Edit 和 Delete" />
</Frame>

**Admin: Source Project**、**Edit** 和 **Delete** 只对你显示。其他用户只能看到 **Open as Template**、**View PDF** 和下载按钮。
</Step>

<Step title="检查模板库">
点击右上角的 **Templates**。新模板位于列表的第一位。
</Step>
</Steps>

## 分类 {#categories}

一个模板属于一个分类。分类的名称和描述来自你的[配置](/zh-Hans/on-premises/configuration/overleaf-toolkit/templates#configuration)，无法在站点中修改。

你会在以下位置看到分类：

* 表单中的 **Categories**。
* 模板库页面 `/templates` 顶部的卡片。在 **All templates** 页面点击 **Template Gallery** 即可进入。
* 每个分类各自的页面，例如 `/templates/presentation`。没有模板的分类会显示 <strong>No Templates.</strong>
* 项目页面上的 **New project**，然后是 **More templates**。
* 模板页面标题上方的链接。

<Frame caption="模板库页面上的分类">
  <img src="/images/on-premises/templates-admin-categories.png" alt="模板库页面，包含 Journal articles、Books 和 Presentations 卡片" />
</Frame>

表单中的 **All templates** 表示没有自己的分类：该模板只出现在完整列表中。

## 更新模板 {#update-a-template}

要更改文件和 PDF，请以相同的标题再次发布项目。

<Steps>
<Step title="修改项目">
编辑项目并点击 **Recompile**。
</Step>

<Step title="再次发布">
点击 **File**，然后点击 **Manage Template**。表单会显示模板的详细信息，你可以修改它们。点击 **Publish**。

会出现一条提示，说明该标题已存在，按钮变为 **Overwrite**。

<Frame caption="以相同标题发布">
  <img src="/images/on-premises/templates-admin-overwrite.png" alt="Manage Template 对话框，显示提示 A template with this title already exists 和 Overwrite 按钮" />
</Frame>

如果此时修改了 **Title**，提示会消失，**Publish** 会创建一个新模板。
</Step>

<Step title="点击 Overwrite">
同一个模板页面会打开，并显示新的 PDF。

<Frame caption="已更新的模板">
  <img src="/images/on-premises/templates-admin-overwritten.png" alt="模板页面，其预览现在显示文档的新标题" />
</Frame>

用户已经从该模板打开的项目不会改变。
</Step>
</Steps>

<Warning>

表单通过项目名称查找模板。如果你用 **Edit** 重命名了模板，表单打开时会显示项目名称、你的名字、第一个分类和空的描述，并且输入模板标题也无法恢复其详细信息。此时 **Overwrite** 会用表单中的内容替换详细信息，因此请先重新填写。

</Warning>

## 编辑详细信息 {#edit-the-details}

这会更改模板库中显示的模板信息，而不会更改其文件或 PDF。

<Steps>
<Step title="打开模板">
点击右上角的 **Templates**，点击模板，然后点击 **Edit**。
</Step>

<Step title="修改字段">
字段与发布时相同，另外多了一个：**Language** 是从该模板打开的项目的拼写检查语言。对于以默认语言发布的项目，它显示 **Off**，从中打开的项目使用 <strong>English (American)</strong>。

<Frame caption="Edit template 对话框">
  <img src="/images/on-premises/templates-admin-edit.png" alt="Edit template 对话框，包含 Title、Author、Categories、Description、License 和 Language" />
</Frame>

与其他模板相同的标题会被拒绝：在你修改 **Title** 之前，**Save** 一直显示为灰色。
</Step>

<Step title="点击 Save">
对话框关闭，模板页面显示新的详细信息。
</Step>
</Steps>

## 源项目 {#the-source-project}

**Admin: Source Project** 会打开发布该模板的项目。

模板保存了自己的文件副本。如果你永久删除了该项目，此按钮会消失，用户仍然可以打开模板。仅位于 **Trash** 中的项目会保留此按钮。另请参阅[模板](/zh-Hans/on-premises/configuration/overleaf-toolkit/templates)下的问答。

## 删除模板 {#delete-a-template}

<Steps>
<Step title="点击 Delete">
在模板页面上，点击 **Delete**。对话框会显示模板的名称。

<Frame caption="Delete template 对话框">
  <img src="/images/on-premises/templates-admin-delete.png" alt="带有 Confirm 按钮的 Delete template 对话框" />
</Frame>
</Step>

<Step title="点击 Confirm">
你会回到之前所在的页面，该模板不再出现在模板库中。其链接现在显示 **Not found**。

源项目会保留，用户从该模板打开的项目也会保留。
</Step>
</Steps>

## 在管理面板中管理模板 {#manage-templates-in-the-admin-panel}

点击 **Admin**，然后点击 **Project/Object Lookup**，再点击 **Templates** 选项卡。它列出所有模板及其作者和所有者，并且可以搜索。

<Frame caption="管理面板中的所有模板">
  <img src="/images/on-premises/templates-admin-panel-tab.png" alt="管理面板的 Templates 选项卡，显示每个模板的标题、作者、所有者和最后修改日期" />
</Frame>

* 点击标题打开模板页面，或点击打开图标在新标签页中打开。
* 点击所有者打开该用户的页面。
* 点击垃圾桶图标，然后点击 **Delete** 删除模板。对话框会警告此操作无法撤销，模板将从模板库中移除。

## 发布被拒绝时 {#if-publishing-is-refused}

表单允许你输入超过站点所接受的内容。**Title** 超过 150 个字符时显示 `Template title exceeds the maximum length of 150 characters.`，**Description** 超过 4096 个字符时显示 `Template description exceeds the maximum length of 4096 characters.`

此后即使你缩短了文本，**Publish** 仍然显示为灰色。点击 **Cancel**，再点击 **File**，然后点击 **Manage Template**，重新填写表单。
