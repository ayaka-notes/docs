---
title: 入门设置
description: 创建第一个管理员，检查实例，并添加第一个用户。
icon: user-plus
---

请在[安装](/zh-Hans/on-premises/installation/introduction)完成后立即执行一次以下步骤。本页使用默认的密码登录方式。

<Steps>
<Step id="open-the-launchpad" title="打开 launchpad">
在你的实例上打开 `/launchpad`，例如 `http://localhost/launchpad`。你会看到 **Create the first Admin account**。

该表单只在第一个管理员创建之前存在。之后，未登录的访问者会被转到登录页面。
</Step>

<Step id="create-the-administrator-account" title="创建管理员账号">
输入邮箱和密码，然后点击 **Register**。

<Frame caption="第一个管理员账号">
  <img src="/images/on-premises/onboarding-launchpad-filled.png" alt="填写了 admin@example.com 的 launchpad 表单" />
</Frame>

如果密码被拒绝，表单上方会出现一条消息，并且不会创建账号。

<Frame caption="被拒绝的密码">
  <img src="/images/on-premises/onboarding-password-error.png" alt="launchpad 表单上方的消息 password is too short" />
</Frame>

| 消息                                       | 含义                                                                                                                       |
| ------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| `password is too short`                    | 少于 8 个字符。                                                                                                            |
| `password is too long`                     | 多于 72 个字符。                                                                                                           |
| `password contains an invalid character`   | 允许的字符为字母 `a-z` 和 `A-Z`、数字以及 `@#$%^&*()-_=+[]{};:<>/?!£€.,`。不允许空格、带重音的字母或非拉丁字母。          |
| `password contains part of email address`  | 密码包含邮箱或 `@` 之前的部分，或者密码是邮箱的一部分。对于 `admin@example.com`，`admin-7Tq9-demo` 和 `example.com` 都会被拒绝。 |
| `password is too similar to email address` | 密码与邮箱过于相似，例如 `adm1n@example.c0m`。                                                                             |

默认情况下不要求大写字母、数字和符号。要修改长度限制，请参阅[密码限制](/zh-Hans/on-premises/configuration/overleaf-toolkit/authentication/password-restrictions)。
</Step>

<Step id="log-in" title="登录">
点击 **Register** 后你会进入登录页面。输入相同的邮箱和密码，然后点击 **Login**。

<Frame caption="使用新账号登录">
  <img src="/images/on-premises/onboarding-login.png" alt="填写了 admin@example.com 的登录页面" />
</Frame>

你会回到 launchpad，此时页面上多了 **Status Checks**。
</Step>

<Step id="check-the-instance" title="检查实例">
`websockets` 应显示 **OK**。

要测试邮件，请在 **Send a test email** 下输入你的地址，点击 **Send**，然后检查收件箱。

<Frame caption="状态检查和测试邮件">
  <img src="/images/on-premises/onboarding-launchpad-checks.png" alt="launchpad 上 websockets 为 OK，测试邮件表单显示 Email Sent，底部有两个按钮" />
</Frame>

<Warning>

**Email Sent** 并不能证明邮件已经离开服务器。如果没有配置[邮件发送](/zh-Hans/on-premises/configuration/overleaf-toolkit/email-delivery)，页面会显示相同的文字，但不会收到任何邮件。

</Warning>

**Start Using** _你的站点名称_ 会打开你的项目。**Go To Admin Panel** 会打开站点工具，请参阅[基本管理](/on-premises/user-guide/administrators/basic-management)。
</Step>

<Step id="create-the-first-user" title="创建第一个用户">
在顶部菜单中点击 **Admin**，然后点击 **Manage Users**。

<Frame caption="Admin 菜单">
  <img src="/images/on-premises/onboarding-admin-menu.png" alt="包含 Manage Site、Manage Users 和 Project/Object Lookup 的 Admin 菜单" />
</Frame>

点击 **Create account**。

<Frame caption="用户列表">
  <img src="/images/on-premises/onboarding-user-list.png" alt="包含管理员和 Create account 按钮的用户列表" />
</Frame>

输入用户的邮箱。**First name** 和 **Last name** 是可选的。只有在创建另一个管理员时才勾选 **Admin**。点击 **Create**。

<Frame caption="Create account 对话框">
  <img src="/images/on-premises/onboarding-create-account.png" alt="填写了 user@example.com 的 Create account 对话框" />
</Frame>

随后对话框会显示新账号及其激活链接，该链接 7 天后过期：

* **Email Sent** 表示激活邮件已发出。
* <strong>No email was sent. Copy the link and pass it on.</strong> 表示邮件没有发出，例如因为没有配置[邮件发送](/zh-Hans/on-premises/configuration/overleaf-toolkit/email-delivery)。

<Frame caption="新账号及其激活链接">
  <img src="/images/on-premises/onboarding-account-created.png" alt="Demo User 的 Create account 对话框，显示未发送邮件的警告、链接、复制图标和 Expires in 7 days" />
</Frame>

点击 **Close**。该账号会以 **Pending** 状态出现在列表中。

<Frame caption="新账号在首次登录前保持 Pending">
  <img src="/images/on-premises/onboarding-user-pending.png" alt="Demo User 处于 Pending 状态的用户列表" />
</Frame>
</Step>

<Step id="give-the-user-access" title="为用户开通访问">
**已配置邮件发送时**，用户会收到一封带有 **Set password** 链接的激活邮件。该链接会打开下面的页面。用户输入密码并点击 **Activate**，随后进入项目页面。上述密码规则同样适用。

<Frame caption="用户打开链接后看到的页面">
  <img src="/images/on-premises/onboarding-activate.png" alt="要求用户设置密码的激活页面" />
</Frame>

**未配置邮件发送时**，请自己转交链接。在点击 **Create** 后的对话框中点击复制图标，然后把链接发给用户，用户按上述方式设置密码。

如果你关闭了对话框或链接已过期，请在 **Manage Users** 中点击该用户所在行的信封图标，然后点击 **Send activation email**。对话框会显示一个新链接，该链接 7 天后过期。

<Frame caption="新的激活链接">
  <img src="/images/on-premises/onboarding-activation-link.png" alt="Demo User 的 Send activation email 对话框，显示未发送邮件的警告、链接、复制图标和 Expires in 7 days" />
</Frame>

你也可以自己设置密码。在 **Manage Users** 中点击用户名，然后点击铅笔图标。输入 **New password** 并点击 **Save**。把密码转交给用户，用户在 `/login` 登录。

<Frame caption="在 Account 标签页设置密码">
  <img src="/images/on-premises/onboarding-set-password.png" alt="处于编辑模式的用户 Account 标签页，已填写 New password 字段" />
</Frame>
</Step>

<Step id="confirm-it-worked" title="确认操作成功">
用户首次登录后，**Manage Users** 中的状态会变为 **Active**。

<Frame caption="用户已登录">
  <img src="/images/on-premises/onboarding-user-active.png" alt="Demo User 处于 Active 状态的用户列表" />
</Frame>
</Step>
</Steps>

<Info>

默认情况下，**Sign up** 不会创建账号：该页面会请访问者联系 `OVERLEAF_ADMIN_EMAIL` 中的地址。要让用户自行注册，请参阅[公开访问](/zh-Hans/on-premises/configuration/overleaf-toolkit/authentication/public-access)。

</Info>
