点击 **Admin**，然后点击 **Manage Site**。**Admin Panel** 有三个标签页：**System Messages**、**Open Sockets** 和 **Open/Close Editor**。

## 系统消息 {#system-messages}

系统消息是显示在 **Projects** 页面和编辑器顶部的蓝色横幅。所有用户都能看到。

### 发布消息 {#post-a-message}

在 **Message** 下输入文字，然后点击 **Post Message**。该标签页会列出当前正在显示的消息。

  <img src="/images/on-premises/basic-management-posted.png" alt="System Messages 标签页，在 Message 字段、Post Message 按钮和 Clear all messages 按钮上方列出两条已发布的消息" />
</Frame>

<Frame caption="用户看到的内容">
  <img src="/images/on-premises/basic-management-user-projects.png" alt="某用户的 Projects 页面，顶部以蓝色横幅显示两条消息" />
</Frame>

* 用户可以点击 <strong>×</strong> 关闭消息。在该浏览器中它会保持关闭。
* 已经打开的页面每 15 分钟检查一次新消息。刷新页面会立即显示新消息。

### 移除消息 {#remove-messages}

**Clear all messages** 会一次性移除所有消息，并且不会要求确认。你无法单独移除某一条消息。

## 打开的 socket {#open-sockets}

这是一个诊断视图，显示 web 服务此刻打开的出站连接。它不显示谁在线：即使有用户正在使用编辑器，列表也可能为空。

## 为维护关闭编辑器 {#close-the-editor-for-maintenance}

使用 **Open/Close Editor** 标签页。其中的按钮会立即生效且不要求确认，该标签页也不会显示编辑器是否已关闭。要确认状态，请点击 **Projects**：编辑器关闭时你会看到 **Maintenance** 页面。

<Frame caption="Open/Close Editor 标签页">
  <img src="/images/on-premises/basic-management-open-close.png" alt="包含 Close Editor、Disconnect all users 和 Reopen Editor 按钮的 Open/Close Editor 标签页" />
</Frame>

<Steps>
<Step id="tell-your-users" title="通知你的用户">
[发布一条消息](/zh-Hans/on-premises/user-guide/administrators/basic-management#post-a-message)，写明维护时间。
</Step>

<Step id="click-close-editor" title="点击 Close Editor">
尽管名称如此，它几乎会关闭整个站点。除管理面板外，所有页面都会显示 **Maintenance**，包括 **Projects**、**Account Settings**、**Templates** 和登录页面。**Manage Users** 和 **Project/Object Lookup** 仍可使用。

<Frame caption="编辑器关闭时用户看到的内容">
  <img src="/images/on-premises/basic-management-closed-page.png" alt="提示实例当前正在维护的 Maintenance 页面" />
</Frame>

已经打开编辑器的用户会保持连接。他们可以继续输入，修改也会被保存，但 **Recompile** 会以 **Server Error** 结束。

要修改此页面的文字，请参阅[维护页面](/zh-Hans/on-premises/configuration/overleaf-toolkit/branding#maintenance-page)。
</Step>

<Step id="click-disconnect-all-users" title="点击 Disconnect all users">
编辑器中的用户会看到 **Please wait** 对话框，从 10 秒开始倒计时。随后页面刷新并显示 **Maintenance**。

<Frame caption="编辑器中的用户看到的内容">
  <img src="/images/on-premises/basic-management-disconnect-dialog.png" alt="编辑器前方的 Please wait 对话框，提示编辑器将在 8 秒后自动刷新" />
</Frame>

请先关闭编辑器：否则刷新会把用户直接带回编辑器。
</Step>

<Step id="do-the-maintenance-then-click-reopen-editor" title="完成维护，然后点击 Reopen Editor">
所有页面会立即恢复可用。用户刷新页面即可继续。
</Step>
</Steps>

<Warning>

登录页面也会关闭，因此在重新打开编辑器之前请保持登录状态。如果你被锁在外面，请重启实例：关闭状态只保存在内存中，因此重启会重新打开编辑器。

</Warning>

<Info>

在有多个副本的 Kubernetes 上，**Close Editor** 只会关闭处理你请求的那个副本。请改用[维护模式](/zh-Hans/on-premises/configuration/kubernetes/branding#maintenance-mode)。

</Info>
