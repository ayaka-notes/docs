Overleaf 支持通过两种方式发送邮件：简单邮件传输协议（SMTP）和 [Amazon Simple Email Service (SES)](https://aws.amazon.com/ses/)。如果你在本机上启用了监听本地连接的邮件服务器，则可以使用 SMTP。

## 每个账户多个邮箱 {#several-emails-per-account}

<Info>

此功能由 [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) 开发，自 v6.4.0 起可用。

</Info>

配置邮件后，设置页面会列出账户的所有邮箱，取代原来的单一邮箱字段。用户输入发送到某个邮箱的 6 位验证码即可添加该邮箱，然后点击 **Make primary** 将账户迁移到该邮箱。这样，在某个邮箱即将被收回时（例如毕业后的学校邮箱），用户仍能保留自己的账户。[用户指南](/zh-Hans/on-premises/user-guide/users/multiple-emails)中有带截图的操作步骤。

* 只有主邮箱可以登录和接收密码重置邮件。辅助邮箱两者都不行，因此被重新分配给他人的邮箱地址无法接管该账户。
* 请在旧邮箱关闭前点击 **Make primary**。之后只能由管理员在 **Admin → Manage Users** 中修改邮箱。
* 从未验证过的旧主邮箱会在其他邮箱成为主邮箱时被移除。已验证的旧主邮箱会保留为辅助邮箱，直到用户将其删除。
* 启用 LDAP 或 SAML 时，**Make primary** 会被拒绝，因为这些账户无法使用新邮箱登录。请参阅[账户和密码](/zh-Hans/on-premises/configuration/overleaf-toolkit/authentication#accounts-and-passwords)。
* 没有邮件设置时，仍保留单一邮箱字段。

## 配置 {#configuration}

邮件通过以下环境变量进行配置。

#### 发件人配置 {#sender-configuration}

| 名称                          | 说明                                                                                                                                          |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | <p>发件人地址，例如 <a href="mailto:support@mycompany.com">`'support@mycompany.com'`</a><br /><br />- <strong>必填</strong>：是</p> |
| `OVERLEAF_EMAIL_REPLY_TO`     | 回复地址，例如 `'noreply@mycompany.com'`                                                                                                  |

#### SMTP {#smtp}

| 名称                                    | 说明                                                                                                                                                                                                                                                              |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST`              | 要连接的主机名或 IP 地址。必须能从 Docker 容器内访问                                                                                                                                                                               |
| `OVERLEAF_EMAIL_SMTP_PORT`              | 要连接的端口                                                                                                                                                                                                                                                   |
| `OVERLEAF_EMAIL_SMTP_SECURE`            | 如果为 `true`，连接服务器时将使用 TLS。如果为 `false` 或未设置，则在服务器支持 `STARTTLS` 扩展时使用 TLS。大多数情况下，如果连接的是 `465` 端口，请将此值设为 `true`；对于 `587` 或 `25` 端口，请保持为 `false` |
| `OVERLEAF_EMAIL_SMTP_USER`              | 用于向 SMTP 服务器进行身份验证的用户名                                                                                                                                                                                                 |
| `OVERLEAF_EMAIL_SMTP_PASS`              | 与 SMTP 用户名对应的密码                                                                                                                                                                                                                           |
| `OVERLEAF_EMAIL_SMTP_TLS_REJECT_UNAUTH` | 如果为 `false`，将允许连接使用自签名或无效 TLS 证书的 TLS 服务器                                                                                                                                                                        |
| `OVERLEAF_EMAIL_SMTP_IGNORE_TLS`        | 当此值为 `true` 且 `OVERLEAF_EMAIL_SMTP_SECURE` 为 `false` 时，即使服务器支持 `STARTTLS` 扩展也不使用 TLS                                                                                                                                            |
| `OVERLEAF_EMAIL_SMTP_NAME`              | 可选，当 `OVERLEAF_EMAIL_SMTP_HOST` 设置为 IP 地址时用于 TLS 验证的主机名，默认为本机主机名。                                                                                                                                        |
| `OVERLEAF_EMAIL_SMTP_LOGGER`            | 为 `true` 时，将日志消息输出到 `web.log`。                                                                                                                                                                                                                        |

#### Amazon SES SMTP 接口 {#amazon-ses-smtp-interface}

你可以在[此处](https://docs.aws.amazon.com/ses/latest/dg/send-email-smtp.html)详细了解如何使用 Amazon SES SMTP 接口发送邮件。

| 名称                       | 说明                                                                                |
| -------------------------- | ------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST` | 要连接的主机名或 IP 地址。必须能从 Docker 容器内访问 |
| `OVERLEAF_EMAIL_SMTP_PORT` | 要连接的端口                                                                     |
| `OVERLEAF_EMAIL_SMTP_USER` | 用于向 SMTP 服务器进行身份验证的用户名                   |
| `OVERLEAF_EMAIL_SMTP_PASS` | 与 SMTP 用户名对应的密码                                             |

#### Amazon SES API {#amazon-ses-api}

你可以在[此处](https://docs.aws.amazon.com/ses/latest/dg/send-email-api.html)详细了解如何使用 Amazon SES API 发送邮件。

| 名称                                   | 说明                                 |
| -------------------------------------- | ------------------------------------------- |
| `OVERLEAF_EMAIL_AWS_SES_ACCESS_KEY_ID` | 使用 AWS SES 时的 access key             |
| `OVERLEAF_EMAIL_AWS_SES_SECRET_KEY`    | 使用 AWS SES 时的 secret key             |
| `OVERLEAF_EMAIL_AWS_SES_REGION`        | 如果未设置，默认区域为 US-EAST-1 |

#### 使用实例角色的 AWS SES {#aws-ses-with-instance-roles}

| 名称                    | 说明                                                                                                                      |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_DRIVER` | 设置为 `ses` 时，邮件系统将使用 SES API 方式，并依赖已配置的实例角色发送邮件。 |

#### 自定义 {#customisation}

| 名称                           | 说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_CUSTOM_EMAIL_FOOTER` | <p>附加到所有邮件末尾的自定义 HTML。<br /><br /><strong>示例</strong>： `"<div>This system is run by department x </div> <div> If you have any questions please look at our faq <a href='https://somwhere.com'>here</a></div>"`</p> |
