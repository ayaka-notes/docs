#### 设置 Mendeley 集成

1. 访问[此链接](https://dev.mendeley.com/myapps.html)注册一个 Mendeley OAuth 应用
2. 将 **Redirect URL** 配置为：`${OVERLEAF_SITE_URL}/user/mendeley/oauth/callback`
3. 记下应用生成的 **ID**（通常是数字，如下图中的 `24061`）和 **Secret**
4. 修改你的 `config/variables.env`
5. 保持授权流程为 Elsevier（推荐）即可

<Frame>
  <img src="/images/on-premises/image-44.png" alt="" />
</Frame>

```dotenv title="config/variables.env"
#################
#   Mendeley    #
#################
# 'mendeley' must be in ENABLED_LINKED_FILE_TYPES (keep 'zotero' too if you use both)
ENABLED_LINKED_FILE_TYPES=project_file,project_output_file,url,mendeley

# From a Mendeley OAuth application (register at https://dev.mendeley.com/myapps.html)
# Redirect URL -> ${OVERLEAF_SITE_URL}/user/mendeley/oauth/callback
MENDELEY_CLIENT_ID=
MENDELEY_CLIENT_SECRET=
# Encrypts the Mendeley OAuth tokens in mongo; if unset, a key file is generated
# in /var/lib/overleaf/data on first use
# How to generate: `openssl rand -hex 32`
MENDELEY_CIPHER_PASSWORD=
# Optional: route the module's server-side Mendeley requests (OAuth + API) through
# an HTTP proxy (must be reachable from the web container; same as github-sync)
# http://10.0.0.1:10808
# (Optional) MENDELEY_PROXY_URL=
```

<Info>

`mendeley` 必须包含在 `ENABLED_LINKED_FILE_TYPES` 中（如果你同时使用两者，请在列表中保留 `zotero`）。`MENDELEY_CLIENT_ID` 和 `MENDELEY_CLIENT_SECRET` 来自你注册的 OAuth 应用。加密密码用于加密存储在 MongoDB 中的 Mendeley OAuth 令牌（可通过 `openssl rand -hex 32` 生成）；如果未设置，首次使用时会在数据卷中生成一个密钥文件。你还可以选择设置 `MENDELEY_PROXY_URL`，使服务端的 Mendeley 请求（OAuth + API）通过一个可从 web 容器访问的 HTTP 代理进行转发。

</Info>

### 注意事项

<Warning>

将包含 Mendeley 关联参考文献文件的现有安装升级到重新发布的 6.3.0 时，请按照 [Zotero / Mendeley 迁移说明](/zh-Hans/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention")进行操作。全新安装无需此迁移。

</Warning>

<Danger>

由于 Ayakaleaf 是一个协作平台，为了提高安全性，从 6.3.0 版本开始，只有参考文献 `bib` 文件的原始创建者才被允许更新导入的文件。

</Danger>

例如，假设项目所有者用户 A 启用了链接共享，并在项目中创建了一个 `test.bib` 文件，将其关联到自己的 Zotero 账户。如果另一个用户 B 通过共享链接访问该项目，用户 B 仍然可以读取和下载 `test.bib`，但不允许从 Zotero 更新或重新导入该文件。只有作为参考文献文件原始创建者的用户 A 才能执行更新。换言之，只有 `.bib` 文件的原始创建者才有权更新它。
