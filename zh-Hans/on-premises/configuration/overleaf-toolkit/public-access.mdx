你可以通过三种方式向没有账户的用户开放你的 Overleaf 实例：

* [项目访问](/zh-Hans/on-premises/configuration/overleaf-toolkit/public-access#project-access  "mention")：允许访客无需登录即可打开共享的项目链接
* [页面访问](/zh-Hans/on-premises/configuration/overleaf-toolkit/public-access#page-access  "mention")：允许未登录的访问者浏览 `/learn`、`/templates` 和 `/devs` 等页面
* [公开注册](/zh-Hans/on-premises/configuration/overleaf-toolkit/public-access#public-registration  "mention")：允许用户自行注册，可选择使用激活邮件并限制为特定的邮箱域名

### 项目访问

<Info>

默认情况下，即使用户获得了项目分享链接，也必须先**登录**才能加入协作项目的编辑会话。

</Info>

要允许匿名访问通过链接分享的项目，请同时设置以下两个变量：

```dotenv title="config/variables.env"
OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING=true
OVERLEAF_ALLOW_PUBLIC_ACCESS=true
```

`OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` 为通过链接分享的项目启用匿名读写。

`OVERLEAF_ALLOW_PUBLIC_ACCESS` 可防止未认证的用户被重定向到登录页面。

使用 `bin/up` 重新创建容器。然后在隐私窗口中打开链接分享 URL 进行验证。

### 页面访问

默认情况下（未设置 `OVERLEAF_ALLOW_PUBLIC_ACCESS`），除登录和注册页面外，**所有**页面都会将未登录的访问者重定向到登录页面。这也包括那些本应公开的页面，因此指向这些页面的链接只对已登录的用户有效。

设置 `OVERLEAF_ALLOW_PUBLIC_ACCESS=true` 后，未登录的访问者可以打开：

| 页面                                                                  | 依赖条件                         |
| --------------------------------------------------------------------- | -------------------------------- |
| 位于 `/learn` 的 LaTeX 帮助（参见 [adding-latex-user-help.md](/zh-Hans/on-premises/configuration/overleaf-toolkit/adding-latex-user-help  "mention")） | `OVERLEAF_PROXY_LEARN=true`      |
| 位于 `/templates` 的模板库、模板页面、预览和 ZIP 下载（参见 [templates.md](/zh-Hans/on-premises/configuration/overleaf-toolkit/templates  "mention")） | `OVERLEAF_TEMPLATE_GALLERY=true` |
| 位于 `/devs` 的 Overleaf Import API 页面（参见 [overleaf-import-api.md](/zh-Hans/on-premises/configuration/overleaf-toolkit/overleaf-import-api  "mention")） | —                                |

它还允许 [Overleaf Import API](/zh-Hans/on-premises/configuration/overleaf-toolkit/overleaf-import-api#signed-out-visitors  "mention") 保留未登录访问者提交的表单，直到其登录为止。

项目列表、编辑器以及创建项目（包括从模板或通过 Import API 创建）仍然需要登录。

### 公开注册

公开注册功能仅在 [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) 中提供。

<Danger>

请注意，一旦启用公开注册，**任何**能够访问你的 Overleaf 实例的人都可以注册为用户。

设置为 `true` 时，注册过程不会验证邮箱地址，因此请仅在内网或受信任的环境中使用，或者改用[通过激活邮件注册](/zh-Hans/on-premises/configuration/overleaf-toolkit/public-access#registration-with-activation-email)。

在启用 OIDC 的实例上，请不要使用 `true`：任何人都可以在同事首次 OIDC 登录之前使用该同事的邮箱注册，这会导致同事被关联到该账户。请使用[通过激活邮件注册](/zh-Hans/on-premises/configuration/overleaf-toolkit/public-access#registration-with-activation-email)或不开放公开注册，参见[账户与密码](/zh-Hans/on-premises/configuration/overleaf-toolkit/authentication#accounts-and-passwords)。

</Danger>

默认情况下，社区版和 Overleaf Pro 均不允许公开注册。

要启用该功能，请在 `config/variables.env` 中添加：

```dotenv title="config/variables.env"
OVERLEAF_ALLOW_PUBLIC_REGISTRATION=true
```

使用 `bin/up` 重新创建容器。

然后点击 **Sign up** 或访问 `/register`。

### 通过激活邮件注册

通过激活邮件注册的功能仅在 [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) 中提供。用户只需使用邮箱注册，并通过激活邮件中的链接设置密码，因此只有邮箱地址的所有者才能使用该账户。域名列表和通配符需要 v6.4.0 或更高版本；早期版本只支持单个域名，例如 `@example.com`。

启用此功能之前，请先配置邮件发送，否则用户将永远收不到激活邮件。参见[邮件发送](/zh-Hans/on-premises/configuration/overleaf-toolkit/email-delivery)。

然后在 `config/variables.env` 中添加以下行：

```dotenv title="config/variables.env" wrap
OVERLEAF_ALLOW_PUBLIC_REGISTRATION=@example.com,@*.example.org
```

`OVERLEAF_ALLOW_PUBLIC_REGISTRATION` 可以设置为：

| 值                            | 谁可以注册                                             | 验证邮箱 |
| ----------------------------- | ----------------------------------------------------- | :------------: |
| `true`                        | 任何人，使用邮箱和密码                                  |       否       |
| `@example.com`                | `example.com` 的邮箱地址                               |      是       |
| `@*.example.org`              | `cs.example.org` 等子域名的邮箱地址，不包括 `example.org` 本身 |      是       |
| `@example.com,@*.example.org` | 所列条目中的任意一项，以逗号分隔                         |      是       |
| `@*`                          | 任何人                                                 |      是       |

域名匹配不区分大小写。要允许某个域名及其子域名，请同时列出两者：`@example.org,@*.example.org`。

### Q\&A

<Accordion title="未登录的编辑者可以对评论做什么？">

<strong>回答：</strong>通过编辑链接打开项目的未登录用户获得与编辑者相同的权限，但需要记录操作者身份的操作除外：

| 操作 | 未登录的编辑者 |
| ------------------------------------------------- | ----------------: |
| 编辑文本、查看评论和修订 | 是 |
| 接受修订、切换编辑模式 | 是 |
| 删除评论或整个讨论串 | 是 |
| 添加、回复或编辑评论 | 否 |
| 解决或重新打开评论 | 否 |

审阅面板仍会向他们显示 **Resolve** 按钮，但解决操作会失败并显示错误消息。

通过查看链接打开项目的用户完全看不到评论，请参阅[角色与权限](/zh-Hans/on-premises/user-and-project-management/roles-and-permissions#collaborating)。

</Accordion>
