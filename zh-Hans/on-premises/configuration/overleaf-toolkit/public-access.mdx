你可以通过三种方式向没有账户的用户开放你的 Overleaf 实例：

* [项目访问](/zh-Hans/on-premises/configuration/overleaf-toolkit/public-access#project-access  "mention")：允许访客无需登录即可打开共享的项目链接
* [页面访问](/zh-Hans/on-premises/configuration/overleaf-toolkit/public-access#page-access  "mention")：允许未登录的访问者浏览 `/learn`、`/templates` 和 `/devs` 等页面
* [公开注册](/zh-Hans/on-premises/configuration/overleaf-toolkit/public-access#public-registration  "mention")：允许用户自行注册，并可选择限制为特定的邮箱域名

### 项目访问

<Info>

默认情况下，即使用户获得了项目分享链接，也必须先**登录**才能加入协作项目的编辑会话。

</Info>

要允许匿名访问通过链接分享的项目，请同时设置以下两个变量：

```dotenv title="config/variables.env"
OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING=true
OVERLEAF_ALLOW_PUBLIC_ACCESS=true
```

`OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` 为通过链接分享的项目启用匿名读写。

`OVERLEAF_ALLOW_PUBLIC_ACCESS` 可防止未认证的用户被重定向到登录页面。

使用 `bin/up` 重新创建容器。然后在隐私窗口中打开链接分享 URL 进行验证。

### 页面访问

默认情况下（未设置 `OVERLEAF_ALLOW_PUBLIC_ACCESS`），除登录和注册页面外，**所有**页面都会将未登录的访问者重定向到登录页面。这也包括那些本应公开的页面，因此指向这些页面的链接只对已登录的用户有效。

设置 `OVERLEAF_ALLOW_PUBLIC_ACCESS=true` 后，未登录的访问者可以打开：

| 页面                                                                  | 依赖条件                         |
| --------------------------------------------------------------------- | -------------------------------- |
| 位于 `/learn` 的 LaTeX 帮助（参见 [adding-latex-user-help.md](/zh-Hans/on-premises/configuration/overleaf-toolkit/adding-latex-user-help  "mention")） | `OVERLEAF_PROXY_LEARN=true`      |
| 位于 `/templates` 的模板库、模板页面、预览和 ZIP 下载（参见 [templates.md](/zh-Hans/on-premises/configuration/overleaf-toolkit/templates  "mention")） | `OVERLEAF_TEMPLATE_GALLERY=true` |
| 位于 `/devs` 的 Overleaf Import API 页面（参见 [overleaf-import-api.md](/zh-Hans/on-premises/configuration/overleaf-toolkit/overleaf-import-api  "mention")） | —                                |

它还允许 [Overleaf Import API](/zh-Hans/on-premises/configuration/overleaf-toolkit/overleaf-import-api#signed-out-visitors  "mention") 保留未登录访问者提交的表单，直到其登录为止。

项目列表、编辑器以及创建项目（包括从模板或通过 Import API 创建）仍然需要登录。

### 公开注册

公开注册功能仅在 [ayaka-notes/overleaf-pro](https://github.com/ayaka-notes/overleaf-pro) 中提供。

<Danger>

请注意，一旦启用公开注册，**任何**能够访问你的 Overleaf 实例的人都可以注册为用户。

注册过程不会验证邮箱地址，因此请仅在内网或受信任的环境中使用，或者在不再需要注册时将其禁用。

</Danger>

默认情况下，社区版和 Overleaf Pro 均不允许公开注册。

要启用该功能，请在 `config/variables.env` 中添加：

```dotenv title="config/variables.env"
OVERLEAF_ALLOW_PUBLIC_REGISTRATION=true
```

使用 `bin/up` 重新创建容器。

然后点击 **Sign up** 或访问 `/register`。

### 限制域名的注册

限制域名的公开注册功能仅在 [ayaka-notes/overleaf-pro](https://github.com/ayaka-notes/overleaf-pro) 中提供。

启用此功能之前，请先配置邮件发送，以便用户能够收到邀请和通知。参见[邮件发送](/zh-Hans/on-premises/configuration/overleaf-toolkit/email-delivery)。

然后在 `config/variables.env` 中添加以下行：

```dotenv title="config/variables.env" wrap
OVERLEAF_ALLOW_PUBLIC_REGISTRATION=@example.domain
```

`OVERLEAF_ALLOW_PUBLIC_REGISTRATION` 可以设置为：

* `true`：允许任何能访问该站点的人注册
* `@example.domain`：仅允许该域名下的邮箱注册
