### 创建你的第一个管理员账户 {#creating-your-first-administrator-account}

打开 `OVERLEAF_SITE_URL` 后接 `/launchpad` 的地址，例如 `http://192.0.2.10:30080/launchpad`，并按照 [Toolkit 的安装后任务](/zh-Hans/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks)中的说明注册管理员账户。然后创建一个示例项目并编译它。

你也可以从命令行创建用户：

```bash
kubectl -n overleaf exec deploy/overleaf -- bash -c \
  'cd /overleaf/services/web && node modules/server-ce-scripts/scripts/create-user.mjs --admin --email=admin@example.com'
```

它会输出一个用于设置密码的链接。

### 检查编译是否处于沙盒中 {#checking-that-compiles-are-sandboxed}

编译一个项目，然后查看运行该 pod 的节点：

```bash
kubectl -n overleaf get pod -l app=overleaf -o wide   # NODE column
# on that node:
sudo docker ps -a --filter ancestor=ghcr.io/ayaka-notes/texlive-full:2026.1
ls -ln /srv/overleaf/compiles                          # owned by uid 33 (www-data)
```

每次编译都会显示为一个名为 `project-<project id>-<user id>-...` 的短暂容器。

### 日志和 shell {#logs-and-a-shell}

| Toolkit          | Kubernetes                                                               |
| ---------------- | ------------------------------------------------------------------------ |
| `bin/logs web`   | `kubectl -n overleaf exec deploy/overleaf -- tail -f /var/log/overleaf/web.log` |
| `bin/shell`      | `kubectl -n overleaf exec -it deploy/overleaf -- bash`                    |
| `bin/up`         | `kubectl apply -f .` 然后 `kubectl -n overleaf rollout restart deployment/overleaf` |

容器会在 `/var/log/overleaf/` 中为每个服务写入一个日志文件（`web.log`、`clsi.log`、`real-time.log`、`document-updater.log`……）；`kubectl logs` 显示的是启动输出。

### 重启后保留哪些内容 {#what-survives-a-restart}

`kubectl rollout restart` 会替换 Pod。只有存储在卷上的内容会保留。通过 `kubectl exec` 在 Pod 内所做的修改（例如安装的软件包或编辑的文件）会随 Pod 一起丢失；如果 `/var/log/overleaf` 不在卷上，日志也会丢失，请参阅[日志](/zh-Hans/on-premises/configuration/kubernetes/logging)。请在清单中进行持久修改。

### 问答 {#q&a}

<Accordion title="编译失败或始终无法完成。">

<strong>回答：</strong>在运行该 pod 的节点上，检查 Docker 是否正在运行并且拥有 `TEX_LIVE_DOCKER_IMAGE` 中指定的镜像，以及 `SANDBOXED_COMPILES_HOST_DIR_*` 是否与 `hostPath` 路径一致。pod 中的 `/var/log/overleaf/clsi.log` 会指出失败的步骤。

</Accordion>

<Accordion title="每次 pod 重启后用户都会被退出登录。">

<strong>回答：</strong>Secret `overleaf-secrets` 中缺少 `OVERLEAF_SESSION_SECRET`，参见[第 2 步](/zh-Hans/on-premises/installation/using-kubernetes/2.-create-the-namespace-and-secrets)。

</Accordion>
