---
title: 2. 创建命名空间和密钥
description: 创建 Ayakaleaf Pro 所需的命名空间和密钥。
icon: key
---

所有资源都放在命名空间 `overleaf` 中：

```bash
kubectl create namespace overleaf
```

Ayakaleaf Pro 从环境变量中读取其密钥。请生成一次并保存在一个 Secret 中：

```bash wrap
HISTORY=$(openssl rand -hex 32)
kubectl -n overleaf create secret generic overleaf-secrets \
  --from-literal=OVERLEAF_INVITE_TOKEN_SECRET="$(openssl rand -base64 32)" \
  --from-literal=OVERLEAF_SESSION_SECRET="$(openssl rand -hex 32)" \
  --from-literal=WEB_API_PASSWORD="$(openssl rand -hex 32)" \
  --from-literal=STAGING_PASSWORD="$HISTORY" \
  --from-literal=V1_HISTORY_PASSWORD="$HISTORY" \
  --from-literal=CRYPTO_RANDOM="$(openssl rand -hex 32)" \
  --from-literal=OT_JWT_AUTH_KEY="$(openssl rand -hex 32)"
```

| 密钥                                           | 原因                                                                                                                                                 |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_INVITE_TOKEN_SECRET`                 | 必需。缺少它时 pod 会以 "Missing required secrets" 停止。更改它会使待处理的项目邀请失效。                                                             |
| `OVERLEAF_SESSION_SECRET`                      | 用于签名会话 cookie。缺少它时，pod 每次重启都会让所有人退出登录。                                                                                     |
| `WEB_API_PASSWORD`、`CRYPTO_RANDOM`、`OT_JWT_AUTH_KEY` | 内部密钥。缺少时容器会在每次启动时生成它们；使用多个副本时，所有副本必须共享这些密钥。 |
| `STAGING_PASSWORD` 和 `V1_HISTORY_PASSWORD`    | 内部历史记录密钥；两者必须具有**相同**的值。                                                                                                          |

<Warning>

请将该 Secret（`kubectl -n overleaf get secret overleaf-secrets -o yaml`）与你的数据一起备份。在 MongoDB 中加密令牌的功能同样需要在此 Secret 中设置各自的加密密码，例如 [GitHub 同步](/zh-Hans/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation) 所需的 `GITHUB_TOKEN_CIPHER_PASSWORD`。

</Warning>
