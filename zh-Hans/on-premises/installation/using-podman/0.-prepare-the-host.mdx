---
title: 0. 准备主机
description: 在设置 rootless Podman 之前，检查操作系统和 SELinux，并安装 git。
icon: server
---

你不需要手动安装 Podman：[2. 运行 podman-setup](/zh-Hans/on-premises/installation/using-podman/2.-run-podman-setup) 会连同它需要的其他软件包一起安装。这里你只需检查主机并安装 `git`，下载 Toolkit 时需要用到它。

<Steps>
<Step title="检查操作系统和 SELinux">
以将要运行 Ayakaleaf Pro 的用户身份登录，而不是 `root`，然后检查发行版和 SELinux 模式：

```bash title="Check the host"
grep PRETTY_NAME /etc/os-release
getenforce
```

你应该看到版本 9 或更高的 RHEL、Rocky Linux、AlmaLinux 或 CentOS Stream，以及 `Enforcing`：

```text
PRETTY_NAME="Rocky Linux 9.9 (Blue Onyx)"
Enforcing
```
</Step>

<Step title="检查你能否使用 sudo">
`bin/podman-setup --apply` 会通过 `sudo` 安装软件包并加载 SELinux 模块，需要时会询问你的密码：

```bash title="Check sudo"
sudo -v
```

如果失败，请让管理员把你的用户加入 `wheel` 组。
</Step>

<Step title="安装 git">
```bash title="Install git"
sudo dnf install -y git
```

<Warning>

不要在这台主机上安装 Docker Engine。`bin/podman-setup` 安装的软件包 `podman-docker` 提供了 `docker` 命令，而只要存在 `podman` 命令，Toolkit 就会把主机视为 Podman 主机。

</Warning>
</Step>
</Steps>
