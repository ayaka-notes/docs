title: 1. 下载并初始化 Toolkit

---

<Steps>
<Step title="克隆 Toolkit">
把 **Ayakaleaf Toolkit**（[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)）克隆到你的主目录并进入该目录：

```bash title="Clone the Toolkit" wrap
git clone https://github.com/ayaka-notes/toolkit.git ~/overleaf-toolkit
cd ~/overleaf-toolkit
```

后续所有命令都在这个目录中运行。
</Step>

<Step title="创建配置">
```bash title="Run initialization"
bin/init
```

这会创建 `config/overleaf.rc`、`config/variables.env` 和 `config/version`，如 Docker 指南中的 [3. 初始化配置](/zh-Hans/on-premises/installation/using-docker-compose/linux/3.-initialize-the-configuration) 所述。`bin/init` 暂时还不需要 Podman。
</Step>

<Step title="设置 config/overleaf.rc">
打开 `config/overleaf.rc` 并修改以下几行：

```bash title="config/overleaf.rc"
SERVER_PRO=true
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
```

然后在文件末尾添加这一行：

```bash title="config/overleaf.rc"
SELINUX_MODE=managed
```

| 设置                              | 原因                                                                                                                                                                                                        |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SERVER_PRO=true`                 | 使用来自 `ghcr.io` 的 Ayakaleaf Pro 镜像，无需登录。                                                                                                                                                           |
| `OVERLEAF_PORT=8080`              | Rootless Podman 无法监听 `1024` 以下的端口，默认的 `80` 会失败。                                                                                                                                                |
| `SIBLING_CONTAINERS_ENABLED=true` | 每次编译都在独立的 TeX Live 容器中运行。默认已为 `true`；Podman 设置只支持这种模式。                                                                                                                              |
| `SELINUX_MODE=managed`            | 以 SELinux 类型 `sharelatex_t` 运行 `sharelatex` 容器，该类型只允许使用 Podman socket，别无其他权限。`bin/podman-setup --apply` 会为它安装策略模块。其他模式请参阅 [Toolkit 设置](/zh-Hans/on-premises/configuration/overleaf-toolkit/toolkit-settings)。 |

保持 `DOCKER_SOCKET_PATH` 不变：`bin/podman-setup --apply` 会在下一步把它设置为你的 Podman socket。

<Warning>

保持 `GIT_BRIDGE_ENABLED=false`。在 Ayakaleaf Pro 6.3.4 中，Git 集成在 Podman 上无法工作，请参阅 [已知限制](/zh-Hans/on-premises/installation/using-podman#known-limitations)。

</Warning>
</Step>

<Step title="选择 TeX Live 镜像">
打开 `config/variables.env`，删除 `TEX_LIVE_DOCKER_IMAGE` 和 `ALL_TEX_LIVE_DOCKER_IMAGES` 前面的 `#`，并列出要使用的 TeX Live 镜像：

```bash title="config/variables.env" wrap
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
```

如果列表为空，`bin/up` 会以 `Please configure ALL_TEX_LIVE_DOCKER_IMAGES` 停止。`texlive-full` 体积很大；对于测试服务器，小得多的 `ghcr.io/ayaka-notes/texlive-basic:2026.1` 也可以使用。可用镜像请参阅 [沙盒编译](/zh-Hans/on-premises/configuration/overleaf-toolkit/sandboxed-compiles)。

按照 [5. 个性化你的实例](/zh-Hans/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance#required-environment-variables) 中的说明设置其他变量，例如 `OVERLEAF_SITE_URL`。使用默认监听地址时，请使用 `http://localhost:8080`。
</Step>
</Steps>
