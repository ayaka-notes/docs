---
title: 3. 初始化配置
description: 在 WSL 2 的 Ubuntu 中使用 bin/init 创建 Toolkit 配置文件。
icon: circle-play
---

在 **Ubuntu** 中的 Toolkit 目录下运行：

```bash
bin/init
```

`bin/init` 会创建三个文件：

| 文件 | 用途 |
| --- | --- |
| `config/overleaf.rc` | 容器设置、对外发布的端口以及数据位置 |
| `config/variables.env` | 应用程序设置和密钥 |
| `config/version` | 应用程序镜像版本 |

它还会在 `config/variables.env` 中生成 `OVERLEAF_INVITE_TOKEN_SECRET`。请保留它，不要公开此文件，也不要将其提交到版本控制中。

对于新安装，请保留 Toolkit 选择的版本。如果以后要更改现有实例的版本，请按照[升级你的部署](/zh-Hans/on-premises/maintenance/upgrading-your-deployment)进行操作。

<Info>

`bin/init` 不会覆盖现有配置。如果它报告文件已存在，请在继续之前检查这些文件。重启或升级实例时，请保留 `config/` 和 `data/`。

</Info>
