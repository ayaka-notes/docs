在本节中，我们将使用 Docker Desktop 和 [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit) 在你的 Mac 上本地运行 Ayakaleaf Pro。本指南使用 `http://localhost:8080`，将数据保存在你的主目录中，并在沙盒容器中使用 TeX Live 2026 进行编译。

Docker Desktop 会在一个 Linux 虚拟机中运行应用程序、MongoDB、Redis 和 TeX Live 编译器。你无需在 macOS 本身上安装 MongoDB、Redis 或 MacTeX。

此设置适用于个人使用和本地测试。对于始终在线的共享服务，我们推荐使用 [Linux 指南](/zh-Hans/on-premises/installation/using-docker-compose/linux)，并配置 HTTPS、备份和访问控制。当 Mac 处于睡眠状态或 Docker Desktop 已停止时，实例将无法访问，请参阅[保持实例可用](/zh-Hans/on-premises/installation/using-docker-compose/macos/6.-post-installation-tasks#keep-the-instance-available)。

## 开始之前 {#before-you-start}

你需要：

* 一个受 [Docker Desktop for Mac](https://docs.docker.com/desktop/setup/install/mac-install/) 支持的 macOS 版本。
* Git、[Homebrew](https://brew.sh/) 和 GNU sed。Toolkit 使用的 GNU sed 选项不被 macOS 内置的 BSD sed 接受。
* 足够同时供 macOS 和 Docker 使用的资源。对于小型本地实例，建议先为 Docker Desktop 分配 4 个 CPU 和 8 GB 内存。这是一个建议的起点，而不是经过测量的最低要求。
* 至少 40 GB 的可用存储空间用于完整的 TeX Live 镜像，另加存放项目的空间。请同时检查 Mac 上的可用空间和 Docker Desktop 的磁盘使用上限。先只使用一个 TeX Live 版本：每增加一个版本大约需要同样多的空间。

应用程序和 TeX Live 镜像均提供 `arm64` 和 `amd64` 版本。在 Apple 芯片上，请让 Docker 自动选择原生 ARM 镜像，不要强制设置 `platform: linux/amd64`。
