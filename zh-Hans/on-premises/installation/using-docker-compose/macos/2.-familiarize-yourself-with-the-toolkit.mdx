Toolkit 在 macOS 和 Linux 上是相同的。其目录结构、`config/` 目录以及 `bin/` 命令在 Linux 指南的 [2. 熟悉 Toolkit](/zh-Hans/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) 中有详细介绍。

在 macOS 上，请记住以下三点不同：

* 请在 GNU sed 位于 `PATH` 最前面的终端中运行脚本，参见 [1. 下载 Toolkit](/zh-Hans/on-premises/installation/using-docker-compose/macos/1.-download-the-toolkit)。
* 在运行需要与 Docker 通信的脚本（例如 `bin/up`、`bin/start` 或 `bin/docker-compose`）之前，请先启动 Docker Desktop。
* `bin/doctor` 包含从官方 Overleaf Toolkit 继承而来的检查。在 macOS 上出现 `This system seems to not be Linux` 警告是正常的，而关于未登录 `quay.io` 的警告不适用于公开的 `ghcr.io/ayaka-notes/overleaf-pro` 镜像。报告中的其他问题仍然需要处理。
