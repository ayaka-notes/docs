### 下载 Toolkit

Toolkit 同时兼容 Server CE 和 Ayakaleaf Pro，是推荐的安装方式。使用 Toolkit，你可以轻松上手 Server CE，并在需要时无缝升级到 Ayakaleaf Pro。

<Info>

[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) 经过修改，可直接使用 ghcr 上的 overleaf-pro 镜像，并使用由 ayaka-notes 提供的 TeX Live。你也可以下载官方的 overleaf-toolkit。

</Info>

<Steps>
<Step title="克隆 Overleaf Toolkit 仓库">
要安装 Toolkit，请进入目标安装路径，然后使用以下命令克隆 Overleaf Toolkit（@Ayaka-notes）GitHub 仓库：

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
# official toolkit (Not Recommended)
# git clone https://github.com/overleaf/toolkit.git ./overleaf-toolkit
```

<Info>

为避免潜在的权限问题，我们建议将 Toolkit 安装在你用户的 `$HOME` 目录中。

</Info>
</Step>

<Step title="进入 Toolkit 目录">
等待克隆完成后，切换到新创建的 `overleaf-toolkit` 目录：

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
