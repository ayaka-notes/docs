你可以通过新的 Dockerfile 扩展现有的 TeX Live 镜像，并配置应用程序使用新镜像。

以下是一些安装新宏包或字体的指导。

TeX Live 镜像的更新频率较低。我们建议在升级 Ayakaleaf Pro 时重新构建自定义镜像。

<Danger>

以下内容仅适用于[沙盒编译（Sandboxed Compiles）](/zh-Hans/on-premises/configuration/overleaf-toolkit/sandboxed-compiles)。

</Danger>

### 安装和更新新宏包

你可以使用 `tlmgr install`、`tlmgr update` 等 `tlmgr` 命令管理 TeX Live 宏包，示例如下：

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2023.1

RUN tlmgr update --force ebproof
```

### 在旧版 TeX Live 镜像中使用 `tlmgr`

默认情况下，`tlmgr` 会从最新的 TeX Live 版本下载资源。为旧版 TeX Live 镜像打补丁时，需要将下载源切换到相应的归档。归档镜像列表请参见 [https://www.tug.org/historic/](https://www.tug.org/historic/)。

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2022.1

RUN tlmgr option repository <MIRROR>/systems/texlive/<YEAR>/tlnet-final
# e.g. RUN tlmgr option repository ftp://tug.org/historic/systems/texlive/2022/tlnet-final

RUN tlmgr update --force ebproof
```

### 安装新字体

在 TeX Live 发行版中安装新字体有多种方法，安装自定义字体可能需要多个步骤。查阅 TeX Live 官方文档中的[TeX 字体安装说明](https://tug.org/fonts/fontinstall.html)或许是一个不错的起点。

下面的 `Dockerfile` 展示了在现有 TeX Live 2022 镜像上安装 TrueType 字体的示例：

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2022.1

COPY ./myfonts/*.ttf /usr/share/fonts/truetype/myfont/

# rebuild font information cache
RUN fc-cache
```

### 配置 Ayakaleaf Pro 使用新镜像

使用名称 `ghcr.io/ayaka-notes/texlive-full` 和自定义标签构建新镜像，例如：

```bash
docker build -t ghcr.io/ayaka-notes/texlive-full:2023.1-custom .
```

现在，我们可以通过更新 `TEX_LIVE_DOCKER_IMAGE`、`ALL_TEX_LIVE_DOCKER_IMAGES` 和 `ALL_TEX_LIVE_DOCKER_IMAGE_NAMES` 环境变量（名称是可选的，并与镜像的顺序一一对应），配置 Ayakaleaf Pro 使用新的 `2023.1-custom` 镜像：

```text wrap
TEX_LIVE_DOCKER_IMAGE: "ghcr.io/ayaka-notes/texlive-full:2023.1-custom"
ALL_TEX_LIVE_DOCKER_IMAGES: "ghcr.io/ayaka-notes/texlive-full:2023.1,ghcr.io/ayaka-notes/texlive-full:2023.1-custom"
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES: "TeX Live 2023,TeX Live 2023 custom"
```

在上面的示例中，新项目默认使用新的 `2023.1-custom` 镜像，而 `2023.1` 仍可在需要时使用。

自定义镜像只存在于你的主机上，因此 `bin/up` 无法拉取它。请在 `config/overleaf.rc` 中设置 `SIBLING_CONTAINERS_PULL=false`（其他镜像请自行使用 `docker pull` 拉取），然后运行 `bin/up -d` 以应用新设置。

### 问答

<Accordion title="使用 XeLaTeX 编译中文文档需要安装中文字体吗？">

<strong>回答：</strong>使用 `texlive-full` 镜像时不需要。这些镜像包含 TeX Live 中文宏包（`ctex`、`xeCJK`）及 Fandol 字体，以及 Noto CJK 字体（例如 `Noto Serif CJK SC`）。在编辑器设置中将项目的编译器设置为 XeLaTeX，然后进行编译，例如：

```latex
\documentclass{ctexart}
\begin{document}
你好，世界！
\end{document}
```

如需使用 Noto 而非 Fandol，请添加 `\setCJKmainfont{Noto Serif CJK SC}`。无需 `latexmkrc`。如需使用其他字体，请按照[安装新字体](#installing-new-fonts)中的说明构建自定义镜像。

</Accordion>
