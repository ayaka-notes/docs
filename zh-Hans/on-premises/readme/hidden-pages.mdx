为了体现开源精神，Overleaf 在 [GitHub: Overleaf](https://github.com/overleaf/overleaf) 上提供了开源的社区版本。然而，为了推销其所谓的 [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud)，Overleaf 刻意对开源的社区版本做了大量隐藏代码的改动，甚至将纯前端的数学 _符号面板_ 作为**付费**功能出售。

在过去几年里，我们眼看着 Overleaf 的编译时间从**一分钟降到二十秒，甚至十秒**，而订阅费用却一路水涨船高。让人不禁感叹：**天下学者苦 Overleaf 久矣。**

此外，Overleaf 的定价在全球几乎统一，即便是最便宜的学生会员也要每月 \$10 起，这对于欧美以外的大多数学生来说难以负担。更离谱的是，还有一个每年 \$399 的 Pro 套餐，只能用漫天要价来形容。

### 我们需要改变

可以说，无论是个人学生还是整个科研机构，这些年来所有人都被 Overleaf 不断上涨的价格裹挟着前行。

而在 AI 时代，Overleaf 并没有带来所承诺的变革，反而继续依赖其陈旧的技术，同时从终端用户身上榨取越来越多。

多年来，许多社区开发者为改进 Overleaf Community Edition 付出了巨大努力。他们包括：

* [https://github.com/ertuil/overleaf](https://github.com/ertuil/overleaf)
* [https://github.com/AllanChain/lcpu-overleaf](https://github.com/AllanChain/lcpu-overleaf)
* [https://github.com/yu-i-i/overleaf-cep/](https://github.com/yu-i-i/overleaf-cep/)
* [https://github.com/ayaka-notes/overleaf](https://github.com/ayaka-notes/overleaf)
* [https://github.com/davrot/overleaf\_with\_admin\_extension](https://github.com/davrot/overleaf_with_admin_extension)
* [https://github.com/overleaf/overleaf/pull/1447](https://github.com/overleaf/overleaf/pull/1447)（Git 集成）
* [https://github.com/overleaf/overleaf/pull/1385](https://github.com/overleaf/overleaf/pull/1385)（Typst 支持）

其中一些人提交了拉取请求（PR），但遗憾的是，在开源社区中，这些 PR 大多被忽视。因此，我们常常质疑 Overleaf 所谓的开源究竟是怎样的开源。

2026 年 1 月，OpenAI 宣布发布 [Prism](https://prism.openai.com/)。在众多社区中，人们纷纷表示 Prism 已经杀死了 Overleaf。

_**这告诉我们：在 AI 时代，如果一家公司仅依靠重新包装的 API 和层层叠加的功能限制来锁定用户，它终将被越来越多的竞争者超越。**_

回到正题，集齐所有功能之后，我们很高兴地宣布 Overleaf Pro 正式发布。本文档专为有意搭建和维护 Overleaf Pro 的用户编写。

Overleaf Pro 和 Community Edition 都运行在 Docker 容器中，与同一主机上的其他应用相互隔离。这通过防止潜在的跨应用攻击提供了额外一层安全保障。

它们可以在离线（air-gapped）服务器上运行，这意味着它们可以与包括互联网在内的其他网络完全隔离。Docker 提供了将应用从联网环境迁移到离线环境的工具。

完成初次下载后，便无需任何互联网连接，从而大幅降低了外部威胁的风险。
