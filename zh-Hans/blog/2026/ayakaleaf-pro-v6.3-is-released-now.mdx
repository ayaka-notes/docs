**2026 年 10 月 3 日更新：** 6.3.0 版本已重新发布，以解决 AI 助手、Zotero 和 Mendeley 集成的问题。升级时请拉取最新的 `6.3.0` 镜像。已有安装中如存在 Zotero 或 Mendeley 关联的参考文献文件，还必须按照[迁移说明](/zh-Hans/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention")进行操作。全新安装无需此迁移。

</Warning>

我们非常自豪地宣布 Overleaf Pro 6.3.0 正式发布，这是社区中功能最强大、最丰富的在线 LaTeX 编辑器。我们始终专注于改善用户体验，本次发布带来了巨大的变化和精彩的功能，包括 AI 助手和第三方文献集成，相信你一定会喜欢。

### 变更

* AI 聊天助手：通过你自己的服务提供商，直接在编辑器中与 AI 模型对话。
* LaTeX 错误助手：获取 AI 针对 LaTeX 编译错误给出的修复建议。
* Mendeley 集成：与 Zotero 类似，从 Mendeley 导入参考文献。
* Open in Overleaf API：新增用于在 Overleaf 中打开内容的 API。
* 模板库：新增服务端分页、搜索和排序，大型模板库不再需要在浏览器中加载所有模板。
* 翻译：更新了 6.3.0 的翻译补丁，包括所有支持语言中新增的界面文本。
* 上游 Overleaf 6.3.0：包括标签页式文件编辑、浅色和深色主题的独立页眉 Logo，以及依赖和基础镜像更新。
* 新增 `OVERLEAF_HEADER_IMAGE_URL_LIGHT` 和 `OVERLEAF_HEADER_IMAGE_URL_DARK`，支持为浅色和深色主题分别设置页眉 Logo 图片。
* 现在可以在编辑器的不同标签页中打开文件。
* 外部 URL 获取和 Open in Overleaf API 现在支持通过 `OVERLEAF_LINKED_URL_OUTBOUND_PROXY` 使用 HTTP(S) 代理。配置方法请参见[出站代理](/zh-Hans/on-premises/configuration/overleaf-toolkit/external-url#outbound-proxy  "mention")。

#### 功能 01：AI 助手现已推出

AI 助手位于编辑器的侧边栏，与你配置的模型服务提供商进行通信。你可以像问同事一样向它提问：精简这段文字、这个宏是做什么的、为什么我的表格对不齐。它不会盲目作答。它可以读取和搜索项目中的文件、检查 LaTeX 诊断信息、编译项目，甚至查看渲染后的 PDF 页面，因此它的回答都基于你的实际文档。

当它想要修改内容时，会先向你展示 diff。在你批准之前不会写入任何内容，论文始终由你掌控。

<img src="https://github.com/user-attachments/assets/ea4e0dad-3561-4726-b380-5d9dcfe29693" alt="AI 聊天与错误助手演示" width="787" />

LaTeX 错误助手专为那个熟悉的深夜时刻而设计：日志中出现一条红色错误，而你完全不知道它是什么意思。点击错误旁边的"建议修复"，助手会读取导致错误的文件，并提出能够修复它的最小改动，同时不影响你的其他格式。如果看起来没问题，一键应用并重新编译即可。当修复涉及宏包、命令或文档结构时，请先快速检查一下。

<img src="https://github.com/user-attachments/assets/91b2aefb-c1e4-4e4a-a94d-9824865cdf29" alt="错误助手用例" width="787" />

AI 功能默认关闭。Ayakaleaf Pro 可与任何兼容 OpenAI 的端点配合使用，无论是 OpenAI 本身、你公司的网关，还是你自己托管的模型。

关于服务提供商配置、权限、配额和可选搜索服务，请参见 [AI 集成](/zh-Hans/on-premises/configuration/overleaf-toolkit/ai-integration  "mention")。

#### 功能 02：Open in Overleaf API

如果你运营课程页面、模板库或文档站点，现在可以为读者提供一个按钮，让他们直接进入一个可用的项目。此功能默认启用。访问 `your.overleaf.com/devs` 可查看完整参考和在线示例。

<Frame>
  <img src="/images/blog/img-2fac54e7.png" alt="" />
</Frame>

只需一个链接或一个小表单即可。你可以发送 LaTeX 代码片段（`snip` 或 `encoded_snip`），单独的片段会被自动包装进一个最小文档中。你可以使用 `snip_uri` 指向一个或多个远程文件（一次最多 50 个），或使用 `zip_uri` 以 ZIP 形式提供整个项目。可选参数可设置编译器（`engine`）、主文档（`main_document`）和项目名称（`name`）。内容会在你的实例中以新项目形式打开，随时可以编辑和编译。如果访问者尚未登录，他们会先登录，然后仍会进入新创建的项目。

```html wrap
<a href="https://your.overleaf.com/docs?snip_uri=https://example.com/paper.tex&engine=xelatex">
  Open in Overleaf
</a>
```

#### 功能 03：Mendeley 集成

我们在 6.2 中添加了 Zotero，从那以后 Mendeley 用户一直在请求同样的功能。关联你的 Mendeley 账户，选择一个文献库或群组，你的参考文献就会以 `.bib` 文件的形式导入，每当文献库发生变化时都可以刷新。与 overleaf.com 一样，在共享项目中只有导入该文件的人才能刷新它。

对于管理员：将 `mendeley` 添加到 `ENABLED_LINKED_FILE_TYPES`，并使用你的 Mendeley 开发者应用中的值设置 `MENDELEY_CLIENT_ID` 和 `MENDELEY_CLIENT_SECRET`。

完整的设置说明请参见 [Mendeley 集成](/zh-Hans/on-premises/configuration/overleaf-toolkit/mendeley-integration  "mention")。

#### 功能 04：模板分页

模板库以前会将所有模板加载到浏览器中再进行排序。五十个模板没问题，五千个就很痛苦了。现在分页、搜索和排序都在 MongoDB 中完成，浏览器只接收你正在查看的那一页。

它无需任何准备即可工作。如果你的模板库有数千个模板，以下索引可以保持其速度。该脚本可以安全地多次运行；请将 `mongo` 和 `sharelatex` 替换为你的容器名和数据库名：

```bash
docker exec mongo mongosh sharelatex --quiet --eval '
db.templates.createIndex({category:1,lastUpdated:-1},{name:"category_1_lastUpdated_-1",background:true});
db.templates.createIndex({lastUpdated:-1},{name:"lastUpdated_-1",background:true});
db.templates.createIndex({category:1,name:1},{name:"category_1_name_1_ci",collation:{locale:"en",strength:2},background:true});
db.templates.createIndex({name:1},{name:"name_1_ci",collation:{locale:"en",strength:2},background:true});
'
```

请按原样保留两个 `*_ci` 索引上的 `collation`——模板库使用相同的 collation 进行查询，而 MongoDB 只会使用匹配的索引。

#### 其他

对于外部文件导入，可配置 `OVERLEAF_LINKED_URL_OUTBOUND_PROXY` 以使用 HTTP(S) 代理，包括本地托管的代理。此设置同时适用于关联 URL 文件以及通过 Open in Overleaf API 导入的远程 ZIP 或 TeX 资源。设置方法和网络访问限制请参见[外部 URL — 出站代理](/zh-Hans/on-premises/configuration/overleaf-toolkit/external-url#outbound-proxy  "mention")。

* 新增 `OVERLEAF_HEADER_IMAGE_URL_LIGHT` 和 `OVERLEAF_HEADER_IMAGE_URL_DARK`，支持为浅色和深色主题分别设置页眉 Logo 图片。
* 现在可以在编辑器的不同标签页中打开文件。
