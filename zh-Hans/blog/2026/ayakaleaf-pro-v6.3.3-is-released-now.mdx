我们非常自豪地宣布 Overleaf Pro 6.3.3 正式发布。上游 Overleaf 6.3.3 是一个安全版本，更新了 Node.js 和已安装的软件包。我们将它与新管理面板的早期预览、每个账户多个邮箱、更强大的 MCP 服务器以及更好的 AI 助手一同发布。

### 变更 {#changes}

* 新管理面板（早期预览）：用户、项目和模板页面，审计日志，以及按用户开关的功能。
* 每个账户多个邮箱（早期预览）。
* MCP 服务器：历史记录、修订、评论、聊天和文件移动。
* AI 助手：OpenAI Responses API，以及 PDF 附件、读取网页和长对话（早期预览）。
* 注册和登录：reCAPTCHA v2 和公开注册的邮箱域名列表（早期预览）。
* Node.js 24.22.3 和软件包更新：上游 Overleaf 6.3.3 中的安全更新。
* 由我们的 E2E 测试系统和内部 Horizon 问题排查（Internal Horizon Issue Investigation）发现的问题修复。

<Info>

新管理面板、多个邮箱、AI 助手附件和新的注册选项在 6.3.3 中作为**早期预览**提供，用于灰度测试，并将在 v6.4.0 中正式发布。在此之前，它们的行为仍可能发生变化。如有任何问题，请在 [GitHub](https://github.com/ayaka-notes/ayakaleaf-pro/issues) 上反馈。

</Info>

#### 功能 01：新管理面板（预览版） {#feature-01-new-admin-panel-preview}

为实验室或院系运行实例，每周都会遇到同样的问题：为什么这个学生无法登录，是谁给了那个账户管理员权限，去年的论文去哪儿了。新管理面板为所有用户和所有项目各提供一个列表，为每个用户和项目提供单独的页面，还有模板管理和审计日志。管理员可以一次对多个用户执行操作，在无法发送邮件时复制激活和密码链接，并为单个用户开启或关闭 Dropbox、Git、AI 助手、修订和符号面板等重要功能。

#### 功能 02：每个账户多个邮箱（预览版） {#feature-02-multiple-emails-per-account-preview}

用户可以通过发送到每个邮箱的验证码为账户添加更多邮箱，并可以将另一个邮箱设为主邮箱，例如在大学邮箱被收回之前。只有主邮箱可以登录并接收密码重置邮件。当实例可以发送邮件时，此功能即会开启。

参阅 [多个邮箱](/zh-Hans/on-premises/user-guide/users/multiple-emails  "mention")。

#### 功能 03：MCP 服务器 {#feature-03-mcp-server}

Claude Code、Codex 或 Cursor 等 AI 客户端现在可以浏览项目历史并恢复版本、审阅修订、将自己的编辑作为修订提交、对文本添加评论、阅读和发送聊天消息，以及移动或重命名文件。MCP 服务器现在有 33 个工具，此前为 17 个。

参阅 [MCP 服务器](/on-premises/user-guide/users/mcp-server  "mention")。

#### 功能 04：OpenAI Responses API {#feature-04-openai-responses-api}

OpenAI 较新的推理模型（例如 gpt-6.x）在 Chat Completions 上拒绝函数工具，因此 AI 助手和错误助手无法使用它们。设置 `AI_API_MODE=responses` 即可改为调用 OpenAI Responses API。附件和 token 配额照常工作。

参阅 [AI 集成](/zh-Hans/on-premises/configuration/overleaf-toolkit/integrations/ai-integration  "mention")。

#### 功能 05：AI 助手改进（预览版） {#feature-05-ai-assistant-improvements-preview}

除图片外，还可以附加最大 2 MB 的 PDF 文件，并可通过可选的 `AI_PDF_MODEL` 指定能读取 PDF 的模型。助手通过 linked URL 代理读取网页，并在搜索网络时知道当天的日期。长对话会被总结，旧的工具输出会被压缩，因此对话可以持续进行而不会占满模型的上下文。

参阅 [AI 助手](/on-premises/user-guide/users/ai-assistant  "mention")。

#### 功能 06：注册和登录（预览版） {#feature-06-sign-up-and-login-preview}

设置 `RECAPTCHA_SITE_KEY` 和 `RECAPTCHA_SECRET_KEY`，即可用 reCAPTCHA v2 保护登录、LDAP 登录、注册和密码重置。`OVERLEAF_ALLOW_PUBLIC_REGISTRATION` 现在接受邮箱域名列表，例如 `@example.edu,@*.example.org`，或用 `@*` 表示任意域名。登录和注册页面会在卡片中显示表单。

参阅 [reCAPTCHA](/zh-Hans/on-premises/configuration/overleaf-toolkit/authentication/recaptcha  "mention") 和 [公开访问](/zh-Hans/on-premises/configuration/overleaf-toolkit/authentication/public-access  "mention")。

#### 问题修复 {#bug-fixes}

* **管理面板**：已被删除的管理员在审计日志和“Deleted by”中仍以邮箱显示，被彻底清除后显示为“Deleted user”。直接请求停用、删除或降级自己账户的操作会被拒绝。
* **AI 助手**：在未设置 `AI_PDF_MODEL` 时，包含 PDF 文件和图片的对话会发送到 `AI_MODEL`，而不是可能无法读取 PDF 文件的图片模型。
* **模板库**：编辑只接受表单中的字段，非文本字段返回 400 而不是 500。
* **Git bridge**：克隆命令在复制框的边缘换行，而不是在标点处换行。

完整列表请参见 [6.3.3 发行说明](/zh-Hans/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.3  "mention")。

#### 升级 {#upgrade}

* 从 6.3.2、6.3.1 或 6.3.0 升级：无需迁移。拉取新镜像并重启即可。
* 从 6.2.x 或更早版本升级且正在使用 Zotero 或 Mendeley：请先运行 6.3.0 中的 [Zotero / Mendeley 迁移](/zh-Hans/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention")。
* 新管理面板取代旧面板。多个邮箱需要邮件发送功能；reCAPTCHA、域名列表和 `AI_API_MODE` 只需要新的环境变量。
