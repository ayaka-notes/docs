Siamo orgogliosi di annunciare il rilascio di Ayakaleaf Pro 6.2, l'editor LaTeX online più potente e ricco di funzionalità della community. Un ringraziamento speciale a yu-i-i e davrot per i loro preziosi contributi: hanno migliorato GitHub Sync e introdotto la ricerca avanzata delle citazioni e l'integrazione con Zotero.

### Note

* È stata introdotta una nuova variabile d'ambiente obbligatoria `OVERLEAF_INVITE_TOKEN_SECRET`, che devi generare con: `openssl rand -base64 32` Se non è configurata, l'istanza di Overleaf non si avvierà.
* Se abiliti GitHub Sync, devi configurare la variabile d'ambiente `GITHUB_TOKEN_CIPHER_PASSWORD`. Questa variabile è necessaria per cifrare in modo sicuro i token di accesso GitHub. Senza di essa, l'istanza di Overleaf non si avvierà.
* È stata aggiunta una nuova variabile d'ambiente `DEFAULT_LATEX_COMPILER` per impostare il compilatore predefinito usato dai nuovi progetti (pdflatex, latex, xelatex o lualatex).
* L'editor riprogettato è ora l'unica opzione disponibile.

### Modifiche

Questa release include i seguenti miglioramenti e nuove funzionalità.

* `MAX_UPLOAD_SIZE` è ora configurabile invece di essere limitato a **50 MB**.
* Risolto un ciclo di riavvio del container quando le compilazioni in sandbox erano disabilitate.
* Applicata l'eliminazione dei PAT limitata al proprietario per OAuth2.
* Risolto un problema di importazione LDAP.

Le funzionalità includono:

* Aggiunto un esecutore Python basato su browser.
* Aggiunto il supporto Pandoc per importare ed esportare Markdown, DOCX e altri formati.
* Aggiunto GitHub Sync.
* Aggiunte le traduzioni complete in cinese.
* Aggiunta l'integrazione con Zotero.
* Aggiunto `DEFAULT_LATEX_COMPILER`.

#### Funzionalità 01: GitHub Sync

Mantieni i tuoi progetti LaTeX sincronizzati con i repository GitHub per un flusso di lavoro senza interruzioni. Esegui push e pull delle modifiche direttamente dall'editor, collabora tramite pull request e integra le pipeline CI/CD esistenti. Il controllo di versione semplifica il monitoraggio delle revisioni, la revisione delle modifiche e la gestione di documenti accademici o tecnici riproducibili.

Vedi: [GitHub Synchronisation](/it/on-premises/configuration/overleaf-toolkit/github-synchronisation  "mention").

#### Funzionalità 02: Importazione/Esportazione Pandoc

Importa documenti Microsoft Word e Markdown in progetti LaTeX completamente modificabili, oppure esporta i progetti LaTeX in Markdown e DOCX con un solo clic. Basata su Pandoc, questa funzionalità consente un'interoperabilità fluida tra scrittura accademica, editing collaborativo e flussi di pubblicazione, preservando il più possibile la struttura del documento.

Vedi: [Pandoc Import and Export](/it/on-premises/configuration/overleaf-toolkit/pandoc-import-and-export  "mention").

#### Funzionalità 03: Ricerca avanzata dei riferimenti

Cerca e inserisci riferimenti bibliografici da più database accademici con filtri intelligenti e supporto immediato alle citazioni. Scopri rapidamente articoli, visualizza in anteprima i metadati e crea voci BibTeX accurate senza passare da un sito di ricerca all'altro, migliorando notevolmente l'efficienza della revisione della letteratura.

![image](https://github.com/user-attachments/assets/42e45b73-af4b-4d1f-81f4-9e116ba5d043)

#### Funzionalità 04: Python Runner

Esegui codice Python direttamente all'interno del progetto senza lasciare l'editor. Ideale per generare figure, elaborare dataset, automatizzare i flussi di lavoro dei documenti o eseguire script di ricerca riproducibili. I risultati possono essere integrati nei documenti LaTeX, rendendo calcolo scientifico e scrittura parte di un unico flusso di lavoro.

![image](https://github.com/user-attachments/assets/a4c314b3-fdb5-4836-aea7-12eeece5cd2f)

#### Funzionalità 05: Zotero

Collega la tua libreria Zotero direttamente al tuo flusso di scrittura e gestisci i riferimenti senza lasciare l'editor. Cerca nelle tue raccolte Zotero personali, inserisci citazioni con un solo clic e genera e sincronizza automaticamente le voci BibTeX. Questa integrazione mantiene aggiornata la bibliografia, semplificando la gestione della letteratura per articoli accademici, tesi e documenti tecnici.

Vedi: [Zotero Integration](/it/on-premises/configuration/overleaf-toolkit/zotero-integration  "mention").
