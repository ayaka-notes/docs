Mantiene in Redis i documenti aperti nell'editor, vi applica le modifiche e li riscrive in Mongo tramite web. Viene chiamato da web e real-time.

* <strong>Indirizzo:</strong> `http://document-updater:3003`, all'interno della rete Docker
* <strong>Autenticazione:</strong> nessuna
* <strong>File OpenAPI:</strong> [`develop/hoppscotch/openapi/document-updater.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/document-updater.yaml)
