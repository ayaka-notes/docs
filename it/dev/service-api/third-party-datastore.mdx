Sincronizza i progetti con Dropbox: mantiene una coda di job Redis per utente e un worker che invia le modifiche di Overleaf a Dropbox e interroga Dropbox per rilevare modifiche. Solo web lo chiama, per accodare job e leggere la dimensione delle code.

* <strong>Indirizzo:</strong> `http://third-party-datastore:3002`, all'interno della rete Docker
* <strong>Autenticazione:</strong> nessuna
* <strong>File OpenAPI:</strong> [`develop/hoppscotch/openapi/third-party-datastore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/third-party-datastore.yaml)
