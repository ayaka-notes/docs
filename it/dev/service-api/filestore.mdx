Serve file dall'object storage: i file dei modelli (zip, pdf e le relative immagini di anteprima) e, in sola lettura, i blob di progetto e globali scritti da history-v1. Viene chiamato da web (modulo template-gallery, URL dei file di compilazione) e da clsi, che ne scarica i file binari dei progetti.

* <strong>Indirizzo:</strong> `http://filestore:3009`, all'interno della rete Docker
* <strong>Autenticazione:</strong> nessuna
* <strong>File OpenAPI:</strong> [`develop/hoppscotch/openapi/filestore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/filestore.yaml)
