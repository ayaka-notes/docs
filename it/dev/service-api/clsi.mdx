CLSI (Common LaTeX Service Interface) compila i progetti, esegue SyncTeX e texcount sull'output di compilazione e converte documenti con pandoc. Web lo chiama; i file di output sono serviti da clsi-nginx, non da questa porta. Nessuna autenticazione: è raggiungibile solo all'interno della rete Docker.

* <strong>Indirizzo:</strong> `http://clsi:3013`, all'interno della rete Docker
* <strong>Autenticazione:</strong> nessuna
* <strong>File OpenAPI:</strong> [`develop/hoppscotch/openapi/clsi.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/clsi.yaml)
