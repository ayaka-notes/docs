---
title: docstore
icon: database
---

Memorizza ogni documento (righe, versione, range) di ogni progetto nella collection Mongo `docs` e archivia i documenti in un object storage quando è impostato un backend. Viene chiamato da web; document-updater lo raggiunge tramite web.

* <strong>Indirizzo:</strong> `http://docstore:3016`, all'interno della rete Docker
* <strong>Autenticazione:</strong> nessuna
* <strong>File OpenAPI:</strong> [`develop/hoppscotch/openapi/docstore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/docstore.yaml)
