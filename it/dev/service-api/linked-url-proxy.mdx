icon: link

Recupera un URL esterno per web e restituisce la risposta in streaming, rifiutando gli indirizzi interni affinché gli utenti non possano raggiungere la rete Docker. Web vi fa passare i file URL, le importazioni Open in Overleaf e il web_fetch dell'agente IA.

* <strong>Indirizzo:</strong> `http://linked-url-proxy:3066`, all'interno della rete Docker
* <strong>Autenticazione:</strong> nessuna
* <strong>File OpenAPI:</strong> [`develop/hoppscotch/openapi/linked-url-proxy.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/linked-url-proxy.yaml)
