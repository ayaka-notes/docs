Memorizza la cronologia completa di ogni progetto: blocchi di modifiche in Mongo o Postgres e nell'object storage, e il contenuto dei file come blob. project-history vi scrive le modifiche; web, project-history e git-bridge ne leggono blob, snapshot e zip.

* <strong>Indirizzo:</strong> `http://history-v1:3100`, all'interno della rete Docker
* <strong>Autenticazione:</strong> autenticazione HTTP basic come `staging` con `STAGING_PASSWORD`, oppure un JWT, a seconda della route.
* <strong>File OpenAPI:</strong> [`develop/hoppscotch/openapi/history-v1.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/history-v1.yaml)
