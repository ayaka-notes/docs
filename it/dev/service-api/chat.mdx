Memorizza la chat del progetto e i thread di commenti (i loro messaggi e lo stato di risolto) nelle collection Mongo `rooms` e `messages`. Viene chiamato da web tramite `ChatApiHandler`.

* <strong>Indirizzo:</strong> `http://chat:3010`, all'interno della rete Docker
* <strong>Autenticazione:</strong> nessuna
* <strong>File OpenAPI:</strong> [`develop/hoppscotch/openapi/chat.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/chat.yaml)
