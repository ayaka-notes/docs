Accoda in Redis le modifiche di ogni progetto, le trasforma in modifiche della cronologia e le invia a history-v1; conserva inoltre in Mongo le etichette della cronologia, lo stato di risincronizzazione e i record degli errori. Lo chiamano web, document-updater, history-v1 e gli script cron di server-ce; non ha autenticazione.

* <strong>Indirizzo:</strong> `http://project-history:3054`, all'interno della rete Docker
* <strong>Autenticazione:</strong> nessuna
* <strong>File OpenAPI:</strong> [`develop/hoppscotch/openapi/project-history.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/project-history.yaml)
