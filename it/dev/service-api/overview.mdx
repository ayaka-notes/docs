Overleaf viene eseguito come diversi servizi che si chiamano a vicenda via HTTP all'interno della rete Docker. Le pagine di questa sezione descrivono queste API interne. Derivano dai file OpenAPI in [`develop/hoppscotch/openapi/`](https://github.com/ayaka-notes/ayakaleaf-pro/tree/server-pro/develop/hoppscotch/openapi), scritti a partire dal codice di ciascun servizio.

Nessuna di queste API è pubblica: sono raggiungibili solo all'interno della rete Docker e la maggior parte non ha autenticazione.

## Servizi {#services}

| Servizio | Indirizzo | Cosa fa |
| ------------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------------------ |
| [web](/it/dev/service-api/web)                                     | `http://web:3000`                   | L'applicazione principale. La sua API privata viene chiamata dagli altri servizi e dagli script cron dell'immagine  |
| [document-updater](/it/dev/service-api/document-updater)           | `http://document-updater:3003`      | Mantiene in Redis i documenti aperti nell'editor, applica le modifiche e li riscrive in Mongo         |
| [docstore](/it/dev/service-api/docstore)                           | `http://docstore:3016`              | Memorizza ogni documento di ogni progetto nella collection Mongo `docs`                                 |
| [real-time](/it/dev/service-api/real-time)                         | `http://real-time:3026`             | Gestisce le connessioni socket.io dell'editor e inoltra le modifiche tra browser e servizi          |
| [chat](/it/dev/service-api/chat)                                   | `http://chat:3010`                  | Memorizza la chat del progetto e i thread di commenti                                                  |
| [project-history](/it/dev/service-api/project-history)             | `http://project-history:3054`       | Trasforma le modifiche in coda in modifiche della cronologia e le invia a history-v1; conserva le etichette               |
| [history-v1](/it/dev/service-api/history-v1)                       | `http://history-v1:3100`            | Memorizza la cronologia completa di ogni progetto e il contenuto dei file come blob                           |
| [filestore](/it/dev/service-api/filestore)                         | `http://filestore:3009`             | Serve i file dei modelli e, in sola lettura, i blob scritti da history-v1                           |
| [clsi](/it/dev/service-api/clsi)                                   | `http://clsi:3013`                  | Compila i progetti, esegue SyncTeX e il conteggio delle parole, converte documenti                              |
| [notifications](/it/dev/service-api/notifications)                 | `http://notifications:3042`         | Memorizza le notifiche mostrate nell'elenco dei progetti                                               |
| [linked-url-proxy](/it/dev/service-api/linked-url-proxy)           | `http://linked-url-proxy:3066`      | Recupera URL esterni per web e rifiuta gli indirizzi interni                                     |
| [third-party-datastore](/it/dev/service-api/third-party-datastore) | `http://third-party-datastore:3002` | Sincronizza i progetti con Dropbox tramite una coda di job per utente                                       |

## Autenticazione {#authentication}

* <strong>web:</strong> autenticazione HTTP basic con `WEB_API_USER` e `WEB_API_PASSWORD`. Le route di git-bridge usano invece un token di accesso personale.
* <strong>history-v1:</strong> autenticazione HTTP basic come `staging` con `STAGING_PASSWORD`, oppure un JWT.
* <strong>Tutti gli altri servizi:</strong> nessuna.

## Provarle {#try-them}

L'ambiente di sviluppo esegue [Hoppscotch](https://github.com/hoppscotch/hoppscotch) su `http://localhost:9170`, con un proxy che raggiunge i servizi tramite i loro indirizzi Docker. Il suo [README](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/README.md#hoppscotch) spiega come impostare il proxy e importare i file OpenAPI.
