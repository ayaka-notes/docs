`projects` contiene un documento per progetto: nome, proprietario e membri, condivisione, albero dei file e impostazioni del progetto. Il testo dei documenti non è qui (vedi [Collezione Docs](/it/dev/data-model/docs-collection)), e i file binari si trovano nell'archivio di blob di history-v1 sotto il loro `hash`. Lo schema è `services/web/app/src/models/Project.mjs`, con l'albero dei file in `Folder.mjs`, `File.mjs` e `Doc.mjs` accanto.

Nella colonna Origine, `Project.mjs:N` è una riga di quello schema, gli altri nomi di file senza percorso si trovano in `services/web/app/src/Features/`, e `modules/...` si trova in `services/web/`. I numeri di riga provengono da `server-pro` al momento della stesura.

#### Note {#notes}

* `autoIndex` di Mongoose è disattivato (`services/web/app/src/infrastructure/Mongoose.mjs:7`): le opzioni `index` nello schema esistono solo perché le migrazioni sopra le creano.
* La migrazione `20250620152657_ensure_collaborator_arrays` imposta a `[]` i campi `collaberator_refs`, `pendingEditor_refs`, `pendingReviewer_refs`, `readOnly_refs` e `reviewer_refs` mancanti.
* L'eliminazione di un progetto sposta il documento in `deletedProjects` (vedi [Deleted Projects Collection](/dev/data-model/deleted-projects-collection)).
