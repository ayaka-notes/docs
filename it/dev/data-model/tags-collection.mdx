`tags` contiene i tag (cartelle) in cui un utente organizza i progetti nella dashboard dei progetti. Un documento è un tag di un utente. Ne è proprietario `web`; lo schema è `services/web/app/src/models/Tag.mjs`, e tutte le scritture passano da `services/web/app/src/Features/Tags/TagsHandler.mjs`.

#### Campi {#fields}

| Campo | Tipo | Significato | Fonte |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id del tag, usato nelle route `/tag/:tagId`. | `Tag.mjs:10` |
| `user_id` | String | Proprietario del tag. Una semplice stringa, non un ObjectId, per motivi storici. | `Tag.mjs:7-12` |
| `name` | String | Nome del tag, al massimo 50 caratteri (`MAX_TAG_LENGTH`). Univoco per utente. | `Tag.mjs:13`, `TagsHandler.mjs:4` |
| `color` | String | Colore facoltativo: un codice esadecimale come `#a1b2c3` o un valore `hsl(<n>, 70%, 45%)` (`TAG_COLOR_REGEX`). | `Tag.mjs:5`, `Tag.mjs:14-22` |
| `project_ids` | Array of String | Id dei progetti in questo tag, come stringhe. | `Tag.mjs:23` |
| `__v` | Number | Chiave di versione di Mongoose, aggiunta quando `Tag.create` crea il documento. | `TagsHandler.mjs:27` |

#### Chi la scrive {#who-writes-it}

| Codice | Cosa fa |
| --- | --- |
| `TagsHandler.mjs:18-35` (`createTag`) | `POST /tag` (`services/web/app/src/router.mjs:873-874`). Con un nome duplicato restituisce il tag esistente. |
| `TagsHandler.mjs:37-70` (`renameTag`, `editTag`) | `POST /tag/:tagId/rename` e `/tag/:tagId/edit` (`router.mjs:879-886`): impostano `name`, oppure `name` e `color`. |
| `TagsHandler.mjs:72-77` (`deleteTag`) | `DELETE /tag/:tagId` (`router.mjs:891-892`). |
| `TagsHandler.mjs:79-113` | Aggiunge o rimuove uno o più progetti (`$addToSet` / `$pull` / `$pullAll` su `project_ids`), route `router.mjs:897-916`. |
| `TagsHandler.mjs:124-128` (`removeProjectFromAllTags`) | Chiamato per ogni membro quando un progetto viene eliminato (`services/web/app/src/Features/Project/ProjectDeleter.mjs:236-238`) e quando un utente viene rimosso da un progetto o lo abbandona (`services/web/app/src/Features/Collaborators/CollaboratorsController.mjs:621`). |
| `TagsHandler.mjs:130-134` (`addProjectToTags`) | Mette un progetto copiato negli stessi tag dell'originale (`services/web/app/src/Features/Project/ProjectDuplicator.mjs:190-194`). |
| `services/web/modules/server-ce-scripts/scripts/rename-tag.mjs:20-23` | Script di amministrazione che rinomina un tag di un utente direttamente in Mongo. |

#### Indici {#indexes}

| Nome | Chiavi | Opzioni | Migrazione |
| --- | --- | --- | --- |
| `user_id_1_name_1` | `{ user_id: 1, name: 1 }` | unique | `tools/migrations/20190912145029_create_tags_indexes.mjs` |

La stessa migrazione ha creato anche `user_id_1`; `tools/migrations/20231031164732_drop_redundant_indexes.mjs` lo elimina di nuovo, poiché l'indice composto lo copre.

#### Note {#notes}

* I tag sono per utente: due collaboratori dello stesso progetto mantengono ciascuno i propri tag per quel progetto.
* `user_id` e `project_ids` sono stringhe, quindi interrogali con id di tipo stringa, non con ObjectId.
* L'eliminazione di un utente (`services/web/app/src/Features/User/UserDeleter.mjs`) non tocca `tags`.
