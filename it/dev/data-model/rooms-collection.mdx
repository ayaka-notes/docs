`rooms` contiene un documento per ogni stanza di chat di un progetto: la chat del progetto o un thread di commenti di revisione. Solo il servizio chat la scrive, in `services/chat/app/js/Features/Threads/ThreadManager.js`. Non esiste uno schema Mongoose. I messaggi di una stanza sono nella collezione [messages](/it/dev/data-model/messages-collection).

#### Campi {#fields}

| Campo | Tipo | Significato | Fonte |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Id della stanza. `messages.room_id` punta qui. | `ThreadManager.js:57-61` |
| `project_id` | ObjectId | Progetto a cui appartiene la stanza. | `ThreadManager.js:43-54` |
| `thread_id` | ObjectId | Solo nei thread di commenti: l’id del commento, uguale a `id` e `op.t` del commento in `docs.ranges.comments` (vedi [docs](/it/dev/data-model/docs-collection)). Assente nella stanza della chat del progetto. | `ThreadManager.js:38-55`, `services/docstore/app/js/RangeManager.js:54-57` |
| `resolved` | Object | Impostato quando il thread viene risolto, rimosso quando viene riaperto. Un thread senza questo campo è aperto. | `ThreadManager.js:94-123` |
| `resolved.user_id` | String | Id dell’utente che ha risolto il thread. Salvato come stringa, non come ObjectId: il corpo della richiesta viene solo verificato come id valido, non convertito. | `ThreadManager.js:103`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:70` |
| `resolved.ts` | Date | Quando il thread è stato risolto. | `ThreadManager.js:104` |

#### Chi la scrive {#who-writes-it}

| Codice | Cosa fa |
| ---- | ------------ |

| `ThreadManager.js:94-109` `resolveThread` | Imposta `resolved`. | `ThreadManager.js:111-123` `reopenThread` | Rimuove `resolved`. Stessi chiamanti: `TrackChangesController.mjs:160`, `RestoreManager.mjs:285`, `CommentTools.mjs:183`. |

| `ThreadManager.js:12-29` `cloneThreads` | Copia ogni stanza di thread di un progetto in un altro progetto, con un nuovo `_id` e lo stesso `thread_id`. Usato quando un progetto viene copiato con i suoi intervalli (`services/web/app/src/Features/Project/ProjectDuplicator.mjs:197`). |

#### Note {#notes}

* Un progetto ha al massimo una stanza senza `thread_id`: la chat del progetto. Il servizio chat la trova con `thread_id: { $exists: false }` (`ThreadManager.js:38-45`).
* Lo stato risolto di un commento esiste solo qui. Docstore rimuove `op.resolved` prima di salvare gli intervalli (`services/docstore/app/js/RangeManager.js:59-61`).
* Dopo la copia di un progetto, lo stesso `thread_id` esiste in due progetti. Interroga sempre `project_id` e `thread_id` insieme, come fa il servizio chat.
* Le stanze di un progetto eliminato restano finché il progetto eliminato non scade.
