title: Collezione Migrations
icon: list-check
---

`migrations` registra quali migrazioni del database sono state eseguite. Un documento è una migrazione di `tools/migrations/`. Viene scritto dall'adattatore dello strumento di migrazione [east](https://github.com/okv/east), `tools/migrations/lib/adapter.mjs`, non da un servizio in esecuzione.

#### Campi {#fields}

| Campo | Tipo | Significato | Fonte |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id del documento. | `adapter.mjs:103` |
| `name` | String | Nome file della migrazione senza estensione, per esempio `20190912145029_create_tags_indexes`. | `adapter.mjs:104` |
| `migratedAt` | Date | Quando la migrazione è terminata. | `adapter.mjs:105` |

#### Chi la scrive {#who-writes-it}

| Codice | Cosa fa |
| --- | --- |
| `adapter.mjs:101-107` (`markExecuted`) | Inserisce un documento dopo l'esecuzione di una migrazione. |
| `adapter.mjs:109-114` (`unmarkExecuted`) | Lo elimina di nuovo quando una migrazione viene annullata. |

CE esegue `yarn run migrations migrate -t server-ce` a ogni avvio del container (`server-ce/init_scripts/900_run_web_migrations.sh:4-12`; `-t server-pro` quando `OVERLEAF_IS_SERVER_PRO=true`). Vengono eseguite solo le migrazioni i cui `tags` includono quell'ambiente, quindi solo quelle ottengono un documento qui.

#### Chi la legge {#who-reads-it}

| Codice | Cosa fa |
| --- | --- |
| `adapter.mjs:72-99` (`getExecutedMigrationNames`) | east salta ogni migrazione il cui nome è già presente qui. |
| `tools/migrations/lib/helpers.mjs:67-75` (`assertDependency`) | Una migrazione che richiede che un'altra sia stata eseguita prima genera un errore quando quel nome manca. |

#### Indici {#indexes}

| Nome | Chiavi | Opzioni | Migrazione |
| --- | --- | --- | --- |
| `name_1` | `{ name: 1 }` | unique | `tools/migrations/20190720165251_create_migrations.mjs` |

#### Note {#notes}

* Eliminare un documento fa rieseguire quella migrazione al successivo avvio del container, se i suoi tag corrispondono.
* Con un cluster Mongo ausiliario (`mongo.auxUrl`), le migrazioni con tag `auxiliary` vengono registrate invece nella collezione `migrations` di quel cluster (`adapter.mjs:8-15`, `:64-70`). `mongo.auxUrl` proviene da `MONGO_AUX_CONNECTION_STRING` (`tools/migrations/config/settings.defaults.js:19`), che per impostazione predefinita non è impostato.
