`docSnapshots` contiene copie di un doc che document-updater acquisisce subito prima di una modifica che comprime commenti o modifiche tracciate. Solo document-updater la scrive, in `services/document-updater/app/js/SnapshotManager.js`. Web ha un modello Mongoose in `services/web/app/src/models/DocSnapshot.mjs`, ma nessun codice lo usa.

#### Campi {#fields}

| Campo | Tipo | Significato | Fonte |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Id dello snapshot. | `SnapshotManager.js:24` |
| `project_id` | ObjectId | Progetto. | `SnapshotManager.js:19,26`, `DocSnapshot.mjs:7` |
| `doc_id` | ObjectId | Il doc (`docs._id`). | `SnapshotManager.js:20,27`, `DocSnapshot.mjs:8` |
| `version` | Number | Versione OT del doc prima della modifica. | `SnapshotManager.js:28`, `services/document-updater/app/js/UpdateManager.js:132,264-271`, `DocSnapshot.mjs:9` |
| `lines` | Array of String | Contenuto del doc prima della modifica. | `SnapshotManager.js:29`, `DocSnapshot.mjs:10` |
| `pathname` | String | Percorso del doc nel progetto in quel momento. | `SnapshotManager.js:30`, `DocSnapshot.mjs:11` |
| `ranges` | Mixed | `comments` e `changes` prima della modifica, con la stessa forma di `docs.ranges` (vedi [docs](/it/dev/data-model/docs-collection)). `id`, `op.t` e `metadata.user_id` vengono convertiti in ObjectId e `metadata.ts` in Date. | `SnapshotManager.js:31,41-68`, `DocSnapshot.mjs:12` |
| `ts` | Date | Quando è stato acquisito lo snapshot. L’indice TTL lo elimina 30 giorni dopo. | `SnapshotManager.js:32`, `DocSnapshot.mjs:13` |

#### Chi la scrive {#who-writes-it}

| Codice | Cosa fa |
| ---- | ------------ |
| `UpdateManager.js:248-271` | Dopo aver applicato una modifica, document-updater registra il doc com’era prima della modifica quando questa ha compresso degli intervalli: più intervalli sono diventati vuoti, oppure è stato rimosso più di un intervallo (`services/document-updater/app/js/RangesManager.js:104-106`). |
| `SnapshotManager.js:17-36` `recordSnapshot` | Inserisce lo snapshot. |

#### Chi la legge {#who-reads-it}

Nessun codice la legge. Il modello web è definito ma non viene usato da nessuna parte.

#### Note {#notes}

* Solo le modifiche che passano da `UpdateManager.applyUpdate` creano snapshot. Quelle gestite da `HistoryOTUpdateManager` no (`UpdateManager.js:74-77`).
* Non esiste un indice su `doc_id`. Cerca gli snapshot di un doc per `project_id` e `ts`, poi filtra su `doc_id`.
