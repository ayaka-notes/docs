---
title: Aggiornare le traduzioni i18n
icon: language
---

Esiste un file in `services/web/frontend/extracted-translations.json`: il web di Overleaf userà solo le traduzioni estratte presenti in questo file.

Esegui il comando seguente per aggiornare le traduzioni estratte se hai aggiunto dei contenuti.

```bash
user ➜ ~/overleaf-pro/develop (server-pro) $ bin/shell webpack
root@432836260f8a:/overleaf/services/web# npm run extract-translations
```

In generale, non modificare i file di testo delle traduzioni: usa prima quelle esistenti, poiché tutti questi file vengono aggiornati dall'upstream di Overleaf o da siti di traduzione di terze parti.
