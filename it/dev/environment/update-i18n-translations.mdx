---
title: Aggiornare le traduzioni i18n
icon: language
---

Il frontend carica solo le chiavi di traduzione elencate in `services/web/frontend/extracted-translations.json` (`services/web/frontend/translations-loader.js`). Il backend e i suoi template leggono i file completi in `services/web/locales/`.

Esegui questo comando nella directory `develop` una volta dopo la prima configurazione, e di nuovo dopo aver aggiunto una traduzione o cambiato branch:

```bash
bin/i18n
```

`bin/i18n` fa due cose:

1. Ripristina `services/web/locales/*.json` ai file committati, poi applica le patch delle localizzazioni come fanno le build dell'immagine: i file della cartella `locales_patches/v*` più alta sostituiscono le localizzazioni, e `locales_patches/added/*.json` vengono uniti sopra, chiave per chiave.
2. Esegue `yarn run extract-translations` come utente `node` nel container `webpack`, riscrivendo `extracted-translations.json`. Se l'immagine webpack manca, prima sincronizza `yarn.lock` con `bin/sync` e costruisce l'immagine.

Richiede `jq` sull'host.

<Warning>

Le modifiche che `bin/i18n` apporta a `services/web/locales/*.json` sono solo locali. Non committarle.

</Warning>

Riutilizza una chiave esistente quando possibile. I file delle localizzazioni provengono da Overleaf upstream o da un sito di traduzione di terze parti, quindi non modificarli direttamente. Una nuova chiave va in `services/web/locales/locales_patches/added/`, nel file di ogni lingua contemporaneamente (`en.json`, `zh-CN.json` e gli altri).
