Per risparmiare tempo e creare rapidamente l'ambiente di sviluppo, mettiamo a disposizione un'ulteriore configurazione dell'ambiente di sviluppo basata su GitHub Codespace.

## Guida alla configurazione

<Steps>
<Step title="Creare i Codespaces">
Fai clic sul pulsante seguente per creare un codespace nel cloud per lo sviluppo di server-pro.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/overleaf-pro)

Si consiglia di scegliere un **Machine Type** con almeno **4-core**. Per tipi di macchina più grandi, puoi inviare una richiesta al team di supporto ufficiale di GitHub aprendo un ticket [qui](https://support.github.com/contact?tags=rr-codespaces%2Ccat_codespaces).

<Frame>
  <img src="/images/dev/image.png" alt="" />
</Frame>
</Step>

<Step title="Avviare lo script di configurazione">
Dovrai attendere pazientemente che il codespace venga creato. Quando avrai accesso al terminale, esegui il comando seguente:

```text
cd develop/
bin/setup
```

<Frame>
  <img src="/images/dev/image-1.png" alt="" />
</Frame>

<Warning>

Questo script (`bin/setup`) consente di configurare l'ambiente di sviluppo sull'ultimo commit del branch `server-pro` nel minor tempo possibile. Potrebbe non essere applicabile a versioni precedenti o ad altri branch.

Compiliamo ogni giorno l'immagine Docker di sviluppo con [GitHub Action](https://github.com/ayaka-notes/overleaf-pro/actions).

</Warning>
</Step>

<Step title="Accedere al Launchpad">
Passa alla scheda delle porte: vedrai un elenco delle porte web disponibili. Fai clic su quella con `80`. Ora dovresti vedere la pagina del launchpad.

<Frame>
  <img src="/images/dev/image-2.png" alt="" />
</Frame>

Vedrai:

<Frame>
  <img src="/images/dev/image-3.png" alt="" />
</Frame>
</Step>

<Step title="Buon sviluppo">
Ora il tempo è tutto tuo! Inizia a sviluppare la tua fantastica funzionalità. Devi eseguire il comando seguente per abilitare la visualizzazione in tempo reale:

```bash title="bash" wrap
docker compose -f docker-compose.yml -f docker-compose.dev.yml -f ./docker-compose.image.yml up --no-deps --detach
```
</Step>
</Steps>
