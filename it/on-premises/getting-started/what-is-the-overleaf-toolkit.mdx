---
title: Che cos'è l'Ayakaleaf Toolkit?
icon: toolbox
---

L'Ayakaleaf toolkit è il metodo di deployment consigliato per le installazioni on-premises della Community Edition e di Ayakaleaf Pro. È stato progettato per funzionare nell'ambiente più comune: un singolo server fisico o una macchina virtuale. Il Toolkit usa `docker compose` per gestire i container Docker del server e fornisce una serie di script che incapsulano i comandi `docker` per semplificare gli aspetti più tecnici della gestione di una versione on-premises di Overleaf.

#### Il wrapper `bin/docker-compose`

Lo script `bin/docker-compose` è un wrapper attorno a `docker compose`. Carica la configurazione dalla directory `config/` e poi invoca `docker compose` con gli argomenti passati allo script.

Puoi considerare `bin/docker-compose` come un wrapper trasparente per il programma `docker compose` installato sulla tua macchina.

Esempio:

```bash title="Check running containers"
$ bin/docker-compose ps
```

#### Script di utilità

Oltre a `bin/docker-compose`, il Toolkit fornisce script pratici per svolgere le attività più comuni:

* `bin/up`: scorciatoia per `bin/docker-compose up`
* `bin/start`: scorciatoia per `bin/docker-compose start`
* `bin/stop`: scorciatoia per `bin/docker-compose stop`
* `bin/shell`: avvia una shell all'interno del container **sharelatex**
* `bin/doctor`: script usato per raccogliere informazioni sull'installazione e sul deployment. Consulta la sezione "Verificare il server" più sotto
* `bin/mongo`: avvia una shell all'interno del container **mongo** e passa al database corretto (**sharelatex**)
* `bin/backup-config`: crea una copia (zip o tar) della configurazione corrente e la salva in una directory di destinazione a tua scelta
* `bin/logs`: visualizza/segue i log dei servizi
* `bin/error-logs`: visualizza/segue i log degli errori dei servizi
* `bin/rename-env-vars-5-0`: script di migrazione per aggiornare le variabili d'ambiente in **config/variables.env** (cambio di nome da ShareLaTeX a Overleaf)
* `bin/rename-rc-vars`: script di migrazione per aggiornare le variabili d'ambiente in **config/overleaf.rc** (cambio di nome da ShareLaTeX a Overleaf)
* `bin/run-script`: helper per semplificare l'esecuzione degli script presenti nel container **sharelatex**
* `bin/upgrade`: aiuta ad aggiornare l'istanza. Lo script verifica la presenza di aggiornamenti del Toolkit (tramite git) e propone di scaricare le modifiche, controlla l'ultima versione dell'immagine Docker e propone di aggiornarla. Chiede conferma a ogni passaggio, offre la possibilità di eseguire un backup della configurazione corrente e gestisce l'arresto e l'avvio dei servizi Docker. Per maggiori informazioni consulta Upgrading your deployment: https://docs.overleaf.com/on-premises/maintenance/upgrading-your-deployment

<Info>

Se preferisci eseguire l'istanza senza collegarti ai log di Docker, puoi eseguire `bin/up -d` per avviarla in modalità detached.

</Info>

#### Verificare il server

L'Overleaf Toolkit include un comodo script chiamato `bin/doctor` che genera un report indicando eventuali dipendenze non soddisfatte.

Prima di continuare, esegui lo script `bin/doctor` e verifica che tutto funzioni correttamente:

```bash title="Run Overleaf Doctor"
bin/doctor
```
