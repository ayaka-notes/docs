### Requisiti per l'installazione di Server Pro e Community Edition

<Warning>

Consigliamo vivamente di eseguire Server Pro su una versione recente e stabile di Ubuntu (ad es. Ubuntu 24.04 nel 2025–2026) con una versione recente di Docker. È possibile eseguire Server Pro su altri sistemi, ma ciò renderà molto più difficile per noi offrire supporto per configurazioni Ubuntu/Docker non predefinite. Inoltre, non possiamo offrire supporto per problemi relativi a Docker stesso.

</Warning>
