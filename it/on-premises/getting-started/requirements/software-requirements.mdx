### Sistemi operativi

Per un'esperienza ottimale con Overleaf, consigliamo vivamente di usare un sistema operativo **basato su Debian**, come **Ubuntu**. Questa scelta è in linea con l'ambiente di sviluppo del software ed è l'opzione preferita dalla maggior parte degli utenti di Overleaf.

<Danger>

Quando si usa Server Pro con le compilazioni in sandbox (Sandboxed Compiles), è **importante** tenere presente che l'applicazione richiede l'accesso root al socket Docker.

</Danger>

### Dipendenze

* Docker 25.0 e 29
* MongoDB 7.0 e 8.0
* Redis 6.2 e 7.5

<Info>

Puoi monitorare le date di fine vita (EOL) delle dipendenze sopra elencate e di altri prodotti diffusi tramite il servizio endoflife.date: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

MongoDB e Redis vengono scaricati automaticamente da `docker compose` quando si esegue Server CE o Server Pro, a meno che non siano configurati per usare un'installazione diversa.

</Info>

Il Toolkit dipende dai seguenti programmi:

* bash
* Docker

`docker compose` è obbligatorio e viene generalmente installato insieme a Docker.

Ti consigliamo di installare la versione più recente di Docker disponibile per il tuo sistema operativo.

Una volta installato correttamente Docker, dovresti essere in grado di eseguire questi comandi senza errori:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2)
docker compose version

# List the running Docker containers on your system
docker ps
```
