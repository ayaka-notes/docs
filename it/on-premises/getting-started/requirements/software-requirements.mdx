### Sistemi operativi {#operating-systems}

Per i server condivisi e di produzione consigliamo un sistema **Linux basato su Debian**, come **Ubuntu**. Ayakaleaf Pro può funzionare anche su [macOS con Docker Desktop](/it/on-premises/installation/using-docker-compose/macos) e su [Windows con WSL 2 e Docker Desktop](/it/on-premises/installation/using-docker-compose/windows). Tutte e tre le piattaforme usano container Linux e lo stesso Toolkit; segui la guida per il sistema operativo del tuo host.

<Danger>

Quando usi le Sandboxed Compiles, è **importante** tenere presente che l'applicazione richiede l'accesso root al socket Docker.

</Danger>

### Dipendenze {#dependencies}

* Docker 25.0 e 29
* MongoDB 7.0 e 8.0
* Redis 6.2 e 7.5

<Info>

Puoi monitorare le date di fine vita (EOL) delle dipendenze sopra indicate, e di altri prodotti diffusi, usando il servizio endoflife.date: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

MongoDB e Redis vengono scaricati automaticamente da `docker compose` quando si esegue Ayakaleaf Pro, a meno che non sia configurato l'uso di un'installazione diversa.

</Info>

Il Toolkit dipende dai seguenti programmi:

* bash
* Docker

`docker compose` è obbligatorio e generalmente viene installato insieme a Docker.

Ti consigliamo di installare la versione più recente di Docker disponibile per il tuo sistema operativo.

Una volta installato correttamente Docker, dovresti essere in grado di eseguire questi comandi senza errori:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2 or later, such as v5)
docker compose version

# List the running Docker containers on your system
docker ps
```
