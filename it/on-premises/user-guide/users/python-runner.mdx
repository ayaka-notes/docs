Gli script Python vengono eseguiti nel tuo browser, quindi l'output appare subito sotto l'editor. Non serve configurare nulla.

<Steps>
<Step title="Crea uno script">
Nell'albero dei file, fai clic sull'icona **New file**. Inserisci un nome che termina con `.py` e fai clic su **Create**.

<Frame caption="Un nuovo file Python">
  <img src="/images/on-premises/python-runner-new-file.png" alt="La finestra Add Files con il nome analysis.py" />
</Frame>

Sotto l'editor compaiono il pulsante **Run** e un riquadro di output. La prima volta, il pulsante resta disattivato mentre Python si carica.
</Step>

<Step title="Eseguilo">
Scrivi il codice e fai clic su **Run**. Ciò che lo script stampa compare nel riquadro di output. Non devi salvare prima.

I file che lo script scrive finiscono nel tuo progetto. Un messaggio ti dice quali, ad esempio **results.txt saved to your project**, e il file compare nell'albero dei file.

<Frame caption="L'output e un file salvato">
  <img src="/images/on-premises/python-runner-output.png" alt="Uno script nell'editor, il suo output stampato sotto e il messaggio results.txt saved to your project" />
</Frame>
</Step>

<Step title="Interrompi uno script">
Mentre uno script è in esecuzione, **Run** diventa **Stop**. Fai clic per interrompere lo script. Il riquadro di output termina con **Execution interrupted**.

<Frame caption="Uno script in esecuzione">
  <img src="/images/on-premises/python-runner-stop.png" alt="Il pulsante Stop e l'output di uno script in esecuzione" />
</Frame>
</Step>
</Steps>

## Usa una figura nel tuo documento {#use-a-figure-in-your-document}

I grafici non hanno una finestra in cui comparire, quindi salvali in un file. Ad esempio:

```python
import matplotlib.pyplot as plt

plt.plot([1, 2, 3], [1, 4, 9])
plt.savefig("figure.png")
```

`figure.png` compare nel tuo progetto, pronto per `\includegraphics{figure.png}`.

<Frame caption="Un grafico salvato">
  <img src="/images/on-premises/python-runner-figure.png" alt="figure.png aperto nell'editor, con il messaggio figure.png saved to your project" />
</Frame>

## Leggi i file del tuo progetto {#read-your-project’s-files}

Uno script può aprire i file del tuo progetto tramite il loro percorso:

```python
print(open("results.txt").read())
```

## Se qualcosa va storto {#if-something-goes-wrong}

<strong>Lo script genera un errore.</strong> L'errore compare in rosso nel riquadro di output, dopo tutto ciò che lo script ha stampato prima.

<Frame caption="Un errore in uno script">
  <img src="/images/on-premises/python-runner-error.png" alt="Testo stampato seguito da un traceback in rosso" />
</Frame>

<strong>`ModuleNotFoundError: No module named ...`.</strong> Sono disponibili solo i pacchetti integrati in Pyodide, e i pacchetti installati con `pip` non si possono usare. NumPy e Matplotlib sono tra quelli disponibili, e il messaggio rimanda all'[elenco completo](https://pyodide.org/en/stable/usage/packages-in-pyodide.html).
