## Importa un documento {#import-a-document}

In questo modo crei un nuovo progetto LaTeX da un documento Word (`.docx`) o da un file Markdown (`.md`). Il nome del progetto deriva dal nome del file.

<Steps>
<Step title="Apri la finestra di importazione">
Nella pagina dei progetti, fai clic su **New project**. In **Import**, fai clic su **Word document** o **Markdown document**.

<Frame caption="Il menu New project">
  <img src="/images/on-premises/word-import-menu.png" alt="Il menu New project con Word document e Markdown document in Import" />
</Frame>
</Step>

<Step title="Scegli il file">
Fai clic su **Select .docx file** oppure trascina il file nella finestra. Per Markdown, il pulsante è **Select .md file**. L'importazione parte subito.

<Frame caption="Scelta di un documento Word">
  <img src="/images/on-premises/word-import-dialog.png" alt="La finestra Choose Word document con il pulsante Select .docx file" />
</Frame>
</Step>

<Step title="Inizia a modificare">
Il nuovo progetto si apre con il messaggio **Document ready for editing**. Fai clic su **Start editing**.

<Frame caption="L'importazione è terminata">
  <img src="/images/on-premises/word-import-ready.png" alt="La finestra Document ready for editing con il pulsante Start editing" />
</Frame>
</Step>

<Step title="Controlla il risultato">
Il documento ora si trova in `main.tex`, con i titoli nella struttura del file. Fai clic su **Recompile** per vedere il PDF. Controlla la formattazione, in particolare tabelle, figure e citazioni, che potrebbero richiedere modifiche.

<Frame caption="Il progetto importato">
  <img src="/images/on-premises/word-import-project.png" alt="Il progetto importato nell'editor, con main.tex, la struttura del file e il PDF compilato" />
</Frame>
</Step>
</Steps>

### Se l'importazione non riesce {#if-the-import-fails}

Se il file non può essere convertito, la finestra mostra **Your document couldn't be imported**. Espandi **Conversion error details** per vedere il motivo. Nessun progetto viene creato.

<Frame caption="Un documento che non è stato possibile importare">
  <img src="/images/on-premises/word-import-error.png" alt="La finestra di importazione con un messaggio di errore e Conversion error details" />
</Frame>

La finestra accetta solo il tipo che hai scelto. Un file `.md` nella finestra Word mostra **You can only upload: .docx**.

## Esporta un progetto {#export-a-project}

Apri il progetto, poi fai clic sul suo nome in cima all'editor. Fai clic su una di queste opzioni:

| Opzione                              | Ottieni                                       |
| ----------------------------------- | --------------------------------------------- |
| <strong>Export as Word document (.docx)</strong> | Un file `.docx` con il nome del progetto        |
| <strong>Export as Markdown (.md)</strong>        | Un file `.zip` con `main.md`                  |
| <strong>Export as HTML (.html)</strong>          | Un file `.zip` con `main.html`                |

Il download parte da solo. La conversione non può riprodurre tutta la formattazione LaTeX, quindi controlla il risultato.
