Collega un progetto a un repository GitHub. Le modifiche vanno in entrambe le direzioni, e solo quando fai clic su **Sync**: niente si sincronizza da solo.

<Info>

Se non vedi alcuna opzione GitHub in **Account settings** o nell'editor, chiedi al tuo amministratore di attivare la [sincronizzazione con GitHub](/it/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation).

</Info>

## Collegare il tuo account GitHub {#link-your-github-account}

Lo fai una sola volta.

<Steps>
<Step title="Apri le impostazioni dell'account">
Fai clic su **Account**, poi su **Account settings**. Scorri fino a **GitHub** e fai clic su **Link**.

<Frame caption="GitHub nelle impostazioni dell'account">
  <img src="/images/on-premises/github-sync-link.png" alt="La sezione GitHub delle impostazioni dell'account con un pulsante Link" />
</Frame>
</Step>

<Step title="Autorizza su GitHub">
Si apre GitHub. Accedi se richiesto, poi autorizza l'applicazione.
</Step>

<Step title="Controlla il collegamento">
Torni alle impostazioni dell'account, e il pulsante ora indica **Unlink**.

<Frame caption="Il tuo account GitHub è collegato">
  <img src="/images/on-premises/github-sync-linked.png" alt="La sezione GitHub delle impostazioni dell'account con un pulsante Unlink" />
</Frame>
</Step>
</Steps>

Se il tuo account non è ancora collegato, **Import from GitHub** e la scheda **GitHub** nell'editor ti chiedono prima di collegarlo. Fai clic su **Link to your GitHub account**. Anche così arrivi alle impostazioni dell'account, in una nuova scheda se hai iniziato dall'editor. Poi torna indietro e ricomincia.

<Frame caption="La richiesta quando il tuo account non è collegato">
  <img src="/images/on-premises/github-sync-link-prompt.png" alt="La finestra di dialogo Import from GitHub con un pulsante Link to your GitHub account" />
</Frame>

## Importare un repository {#import-a-repository}

Crea un nuovo progetto da un repository GitHub, già collegato a esso.

<Steps>
<Step title="Apri la finestra di importazione">
Nella pagina dei progetti, fai clic su **New project**, poi su **Import from GitHub**.

<Frame caption="Il menu New project">
  <img src="/images/on-premises/github-sync-new-project-menu.png" alt="Il menu New project con Import from GitHub" />
</Frame>

<Info>

**New project** compare quando hai almeno un progetto. Il menu **Create a new project** della pagina di benvenuto non ha l'importazione, quindi crea prima un progetto vuoto.

</Info>
</Step>

<Step title="Scegli il repository">
Fai clic su **Import to Overleaf** accanto al repository. L'elenco include i tuoi repository e quelli delle tue organizzazioni.

<Frame caption="I tuoi repository GitHub">
  <img src="/images/on-premises/github-sync-import.png" alt="La finestra di dialogo Import from GitHub con quattro repository" />
</Frame>

Se manca il repository di un'organizzazione, fai clic su <strong>Can't see what you're looking for?</strong> per la guida di GitHub sull'approvazione dell'applicazione per quell'organizzazione.
</Step>

<Step title="Controlla il progetto">
Il nuovo progetto si apre con i file del repository.

<Frame caption="Il progetto importato">
  <img src="/images/on-premises/github-sync-imported.png" alt="L'editor con il progetto importato, i suoi file e il PDF compilato" />
</Frame>
</Step>
</Steps>

## Esportare un progetto in un nuovo repository {#export-a-project-to-a-new-repository}

Crea un repository da un progetto di cui sei proprietario e li collega. Un progetto può essere collegato solo in questo modo o tramite importazione: non puoi collegarlo a un repository già esistente.

<Steps>
<Step title="Apri GitHub nell'editor">
Apri il progetto. Nella barra a sinistra, fai clic su **Integrations**, poi su **GitHub**.

<Frame caption="Il pannello Integrations">
  <img src="/images/on-premises/github-sync-integrations.png" alt="Il pannello Integrations con la scheda GitHub" />
</Frame>
</Step>

<Step title="Compila il repository">
Scegli l'**Owner**, che può essere tu o una delle tue organizzazioni. **Repository Name** parte dal nome del progetto. La descrizione è facoltativa, e **Private** è selezionato per impostazione predefinita. Fai clic su **Create a GitHub repository**.

<Frame caption="Export Project to GitHub">
  <img src="/images/on-premises/github-sync-export.png" alt="Il modulo Export Project to GitHub compilato" />
</Frame>
</Step>

<Step title="Controlla il collegamento">
La finestra di dialogo ora indica **This project is linked to** e il nome del repository.

<Frame caption="Il progetto è collegato">
  <img src="/images/on-premises/github-sync-exported.png" alt="La finestra di dialogo Sync with GitHub dopo l'esportazione" />
</Frame>
</Step>
</Steps>

## Sincronizzare {#sync}

<Steps>
<Step title="Apri la finestra di sincronizzazione">
Apri un progetto collegato. Nella barra a sinistra, fai clic su **Integrations**, poi su **GitHub**.

**Recent commits in GitHub** elenca ciò che entrerà nel progetto.

<Frame caption="Un nuovo commit in attesa su GitHub">
  <img src="/images/on-premises/github-sync-new-commits.png" alt="La finestra di dialogo Sync with GitHub con un nuovo commit" />
</Frame>
</Step>

<Step title="Descrivi le tue modifiche">
Se hai modificato qualcosa nel progetto, compare un campo per il messaggio di commit. È facoltativo: se lo lasci vuoto, il commit si chiama `Updates from Overleaf`.

<Frame caption="Il messaggio di commit delle tue modifiche">
  <img src="/images/on-premises/github-sync-commit-message.png" alt="La finestra di dialogo Sync with GitHub con un messaggio di commit compilato" />
</Frame>
</Step>

<Step title="Fai clic su Sync">
Fai clic su **Sync**. I nuovi commit da GitHub entrano nel progetto, e le tue modifiche vanno al branch predefinito del repository. Se entrambi i lati hanno modificato cose diverse, vengono unite per te.
</Step>

<Step title="Controlla il risultato">
La finestra di dialogo mostra <strong>No new commits in GitHub since last merge.</strong> e il campo del messaggio di commit è sparito. I file nell'editor e i commit su GitHub sono aggiornati.

<Frame caption="Tutto è sincronizzato">
  <img src="/images/on-premises/github-sync-done.png" alt="La finestra di dialogo Sync with GitHub dopo la sincronizzazione, senza nuovi commit" />
</Frame>
</Step>
</Steps>

### Se le stesse righe sono cambiate su entrambi i lati {#if-the-same-lines-changed-on-both-sides}

La finestra di dialogo indica che le modifiche non sono state unite e nomina un nuovo branch, `overleaf-YYYY-MM-DD-HHMMSS`, che contiene le tue modifiche.

<Frame caption="Un conflitto">
  <img src="/images/on-premises/github-sync-conflict.png" alt="La finestra di dialogo Sync with GitHub con un avviso di conflitto di merge" />
</Frame>

1. Unisci quel branch nel branch predefinito su GitHub o con Git. Nel frattempo puoi chiudere la finestra di dialogo: mostra lo stesso messaggio quando la riapri.
2. Fai clic su **I have manually merged. Continue**. Il risultato unito entra nel progetto.
3. Il branch resta su GitHub. Eliminalo quando non ti serve più.

## Scollegare un progetto {#unlink-a-project}

Fallo quando non vuoi più che il progetto si sincronizzi. Solo il proprietario del progetto può farlo.

<Steps>
<Step title="Fai clic su Unlink">
Nella finestra di sincronizzazione, fai clic su **Unlink**.
</Step>

<Step title="Conferma">
Fai clic su **Confirm**. La nota su un abbonamento non ti impedisce di collegare di nuovo il progetto.

<Frame caption="Conferma lo scollegamento">
  <img src="/images/on-premises/github-sync-unlink-project.png" alt="La finestra di dialogo Sync with GitHub che chiede di confermare lo scollegamento" />
</Frame>
</Step>

<Step title="Controlla il risultato">
La finestra di dialogo ora mostra **Export Project to GitHub**. Il progetto e il repository conservano entrambi il loro contenuto. Per sincronizzare di nuovo, esporta il progetto in un nuovo repository o importa il repository in un nuovo progetto.
</Step>
</Steps>

## Scollegare il tuo account GitHub {#unlink-your-github-account}

In **Account settings**, sotto **GitHub**, fai clic su **Unlink**, poi di nuovo su **Unlink** nella finestra di dialogo.

<Frame caption="Scollega il tuo account">
  <img src="/images/on-premises/github-sync-unlink-account.png" alt="La finestra di dialogo Unlink GitHub Account" />
</Frame>

I tuoi progetti restano collegati ai loro repository. Non puoi sincronizzarli finché non colleghi di nuovo il tuo account.

<Info>

Per sapere chi può fare cosa in un progetto condiviso, consulta [Chi può collegare e sincronizzare](/it/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation#who-can-link-and-sync). Ogni collaboratore che sincronizza collega il proprio account GitHub.

</Info>
