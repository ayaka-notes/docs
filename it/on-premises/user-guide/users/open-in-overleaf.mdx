Metti un link sul tuo sito web, blog o pagina del corso. Chiunque lo clicchi ottiene un nuovo progetto tutto suo con i tuoi file. Non serve configurare nulla.

I visitatori hanno bisogno di un account sulla tua istanza. Un visitatore che non ha effettuato l'accesso passa prima dalla pagina di accesso, e il progetto si apre dopo l'accesso.

Le pagine di questa funzionalità usano il nome Overleaf. Il tuo link o pulsante può riportare qualsiasi testo, ad esempio **Open in Ayakaleaf**.

## Guarda gli esempi {#see-the-examples}

Apri `/devs` sul tuo sito, ad esempio `https://ayakaleaf.example.com/devs`. Nessun menu porta a questa pagina, quindi digita l'indirizzo. Per impostazione predefinita devi aver effettuato l'accesso per vederla.

## Collega un file del tuo sito web {#link-to-a-file-on-your-website}

<Steps>
<Step title="Costruisci il link">
Metti l'indirizzo del file, codificato come URL, dopo `/docs?snip_uri=`:

```text
https://ayakaleaf.example.com/docs?snip_uri=https%3A%2F%2Fexample.com%2Fmain.tex
```

Per un progetto compresso, usa `zip_uri`:

```text
https://ayakaleaf.example.com/docs?zip_uri=https%3A%2F%2Fexample.com%2Fproject.zip
```

La tua istanza scarica il file, quindi deve essere raggiungibile via HTTP o HTTPS. Gli indirizzi su una rete privata vengono rifiutati, vedi [External URL](/it/on-premises/configuration/overleaf-toolkit/external-url).
</Step>

<Step title="Aggiungilo alla tua pagina">
```html
<a href="https://ayakaleaf.example.com/docs?snip_uri=https%3A%2F%2Fexample.com%2Fmain.tex">Open in Ayakaleaf</a>
```
</Step>

<Step title="Fai clic">
Il nuovo progetto si apre nell'editor, con un unico file salvato come `main.tex`.

<Frame caption="Un progetto aperto da un link">
  <img src="/images/on-premises/open-in-overleaf-project.png" alt="Il progetto Hello from a link nell'editor, con main.tex e il suo PDF" />
</Frame>

Ogni clic crea un altro progetto. Il progetto è una copia, quindi le modifiche successive al tuo file non lo raggiungono.
</Step>
</Steps>

## Metti il file nel link {#put-the-file-in-the-link}

Per un file piccolo non devi ospitare nulla: metti il suo contenuto nel link come data URL Base64. In JavaScript:

```javascript
const tex = '\\documentclass{article}\n\\begin{document}\nHello from a link.\n\\end{document}\n'
const link = 'https://ayakaleaf.example.com/docs?' + new URLSearchParams({
  snip_uri: 'data:application/x-tex;base64,' + btoa(tex),
  name: 'Hello from a link',
})
```

`btoa` accetta solo caratteri Latin-1, quindi codifica prima in UTF-8 qualsiasi altro testo. Per un progetto compresso, usa `zip_uri` e `data:application/zip;base64,`.

Un link più lungo di circa 8 KB viene rifiutato con l'errore **414 Request-URI Too Large**. Per contenuti più grandi, ospita il file o usa un [modulo](#use-a-button-instead-of-a-link).

## Scegli le opzioni {#choose-the-options}

Aggiungi questi parametri al link, oppure al modulo come campi nascosti:

| Parametro                   | Cosa fa                                                                                                                 | Esempio                                            |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| `name`                      | Dà il nome al progetto. Senza di esso, un progetto compresso prende il nome dal suo `\title`, tutto il resto si chiama `Open in Overleaf project`. | `name=My%20notes`                                  |
| `engine`                    | Imposta il compilatore: `latex_dvipdf`, `pdflatex`, `xelatex` o `lualatex`.                                                      | `engine=xelatex`                                   |
| `main_document`             | Imposta il file `.tex` principale, che si apre per primo.                                                                                | `main_document=thesis.tex`                         |
| `snip_uri[]`, `snip_name[]` | Importa più file, ognuno con il proprio nome, nello stesso ordine.                                                            | `snip_uri[]=.../a.tex&snip_name[]=a.tex`           |

Un file `.tex` senza `\documentclass` viene racchiuso in un documento standard, quindi si compila subito:

```latex
\documentclass[12pt]{article}
\usepackage[english]{babel}
\usepackage{amsmath}
\usepackage{tikz}
\begin{document}
Your file
\end{document}
```

## Usa un pulsante invece di un link {#use-a-button-instead-of-a-link}

Un modulo invia gli stessi parametri di un link:

```html
<form action="https://ayakaleaf.example.com/docs" method="post" target="_blank">
  <input type="hidden" name="snip_uri" value="https://example.com/main.tex">
  <input type="hidden" name="engine" value="xelatex">
  <button type="submit">Open in Ayakaleaf</button>
</form>
```

Per inviare direttamente il LaTeX, usa `snip` per il testo semplice o `encoded_snip` per il testo passato attraverso `encodeURIComponent`.

Un modulo non funziona sempre, per questo un link è la scelta migliore, a meno che il tuo file sia troppo lungo per starci:

| Dove si trova il modulo                                     | Il visitatore ha effettuato l'accesso            | Il visitatore non ha effettuato l'accesso        |
| ----------------------------------------------------- | ------------------------------- | ------------------------------- |
| Sullo stesso dominio della tua istanza, o su un sottodominio   | Il progetto si apre               | Pagina di accesso, nessun progetto      |
| Su un altro dominio                                     | Pagina di accesso, nessun progetto      | Pagina di accesso, nessun progetto      |

Se il tuo amministratore imposta `OVERLEAF_ALLOW_PUBLIC_ACCESS=true`, il progetto si apre in tutti questi casi, dopo l'accesso se necessario. Questa impostazione apre anche altre pagine ai visitatori non autenticati, vedi [Page Access](/it/on-premises/configuration/overleaf-toolkit/authentication/public-access#page-access).

Per il resto di ciò che gli amministratori possono impostare, vedi [Overleaf Import API](/it/on-premises/configuration/overleaf-toolkit/integrations/overleaf-import-api). La pagina `/devs` contiene altri esempi.

## Se il progetto non si apre {#if-the-project-does-not-open}

La pagina indica cosa è andato storto. **View the Overleaf API docs** ti porta a `/devs`.

<Frame caption="Un link che l'istanza non può usare">
  <img src="/images/on-premises/open-in-overleaf-error.png" alt="La pagina Open in Overleaf con il messaggio invalid url e il pulsante View the Overleaf API docs" />
</Frame>

| Messaggio                                      | Perché                                                 | Cosa fare                                  |
| -------------------------------------------- | --------------------------------------------------- | ------------------------------------------- |
| `no snippet, snip_uri or zip_uri provided`   | Il link non contiene nessuno di questi parametri                          | Controlla i nomi dei parametri                   |
| `invalid url: ...`                           | L'indirizzo non inizia con HTTP o HTTPS       | Usa un indirizzo HTTP o HTTPS, o un data URL |
| `could not download ... (HTTP 404)`          | Il file non si trova a quell'indirizzo                     | Controlla l'indirizzo                           |
| `could not download ... (HTTP 403)`          | L'indirizzo si trova su una rete privata                 | Ospita il file dove la tua istanza può raggiungerlo |
| `zip_uri did not resolve to a zip archive`   | Il file dietro `zip_uri` non è un file zip         | Controlla il file                              |
| `invalid base64 data url`                    | Il data URL è danneggiato                             | Codifica di nuovo il file e codifica il link come URL |
