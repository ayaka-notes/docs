Importa una libreria Zotero in un progetto come file `.bib`, poi cita da esso come al solito. Il file è una copia: cambia solo quando fai clic su **Refresh**.

<Info>

Se in **Account settings** non vedi alcuna opzione Zotero, chiedi al tuo amministratore di attivare l'[integrazione Zotero](/it/on-premises/configuration/overleaf-toolkit/integrations/zotero-integration).

</Info>

## Collegare il tuo account Zotero {#link-your-zotero-account}

Lo fai una sola volta.

<Steps>
<Step title="Aprire le impostazioni dell'account">
Fai clic su **Account**, poi su **Account settings**. In **Reference managers**, trova **Zotero** e fai clic su **Link to Zotero**.

<Frame caption="Zotero nelle impostazioni dell'account">
  <img src="/images/on-premises/zotero-link.png" alt="La sezione Zotero delle impostazioni dell'account con un pulsante Link to Zotero" />
</Frame>

La scheda **Zotero** nel pannello **Integrations** dell'editor ti porta nello stesso punto, nella stessa scheda del browser.

<Frame caption="Il pannello Integrations">
  <img src="/images/on-premises/zotero-integrations.png" alt="Il pannello Integrations con la scheda Zotero" />
</Frame>
</Step>

<Step title="Autorizzare su Zotero">
Si apre Zotero. Accedi se ti viene chiesto, poi autorizza l'applicazione. Chiede solo di leggere la tua libreria e i tuoi gruppi, quindi non può modificare nulla in Zotero.
</Step>

<Step title="Verificare il collegamento">
Torni alle impostazioni dell'account. Un messaggio verde dice **Reference manager linked** e il pulsante ora dice **Unlink**.

<Frame caption="Il tuo account Zotero è collegato">
  <img src="/images/on-premises/zotero-linked.png" alt="La sezione Zotero delle impostazioni dell'account con un messaggio verde e un pulsante Unlink" />
</Frame>
</Step>
</Steps>

Se non consenti l'accesso su Zotero, la stessa sezione dice **Sorry, something went wrong**. Fai clic su **Link to Zotero** per riprovare.

## Creare un file dalla tua libreria {#create-a-file-from-your-library}

<Steps>
<Step title="Aprire la finestra Add files">
Apri un progetto. Nell'albero dei file, fai clic su **New file**, poi su **From Zotero**. Questa voce compare solo dopo aver collegato l'account.
</Step>

<Step title="Scegliere il nome del file e la libreria">
**File Name** parte da `zotero.bib`. Mantieni l'estensione `.bib`: senza di essa non ottieni l'anteprima, e né `\cite` né `\bibliography` trovano le sue voci.

**Library** parte da **My Library** ed elenca anche le tue librerie di gruppo. Un file contiene una libreria.

<Frame caption="Un file dalla tua libreria personale">
  <img src="/images/on-premises/zotero-new-file.png" alt="La scheda From Zotero della finestra Add files con zotero.bib e My Library" />
</Frame>
</Step>

<Step title="Fare clic su Create">
La finestra si chiude e il file è nell'albero dei file. Fai clic su di esso: mostra quando è stato importato e le sue voci. Non puoi modificarlo nell'editor.

<Frame caption="Il file importato">
  <img src="/images/on-premises/zotero-file.png" alt="Il file zotero.bib importato aperto nell'editor con un pulsante Refresh" />
</Frame>

Se **Create** sembra non fare nulla, esiste già un file con quel nome. Scegli un altro nome.
</Step>
</Steps>

### Importare una libreria di gruppo {#import-a-group-library}

Ripeti l'operazione con un nome di file diverso e scegli il gruppo in **Library**. Un progetto può avere più file di questo tipo.

## Citare dal file {#cite-from-the-file}

<Steps>
<Step title="Iniziare una citazione">
In un file `.tex`, digita `\cite{`. L'elenco mostra le voci di tutti i file `.bib` del progetto. Fai clic su una per inserirla.

<Frame caption="Le voci dei file importati">
  <img src="/images/on-premises/zotero-cite.png" alt="L'editor che elenca le chiavi di citazione sotto una citazione" />
</Frame>
</Step>

<Step title="Oppure cercare per titolo o autore">
Fai clic su **Search** sotto l'elenco, oppure premi Ctrl+Spazio tra le parentesi graffe. Digita per filtrare, fai clic su una o più voci, poi su **Insert**.

<Frame caption="La ricerca dei riferimenti">
  <img src="/images/on-premises/zotero-search.png" alt="La finestra Search the .bib files in this project con una voce selezionata" />
</Frame>
</Step>

<Step title="Aggiungere la bibliografia">
Aggiungi queste righe prima di `\end{document}`, usando i nomi dei tuoi file senza `.bib`, separati da virgole:

```latex
\bibliographystyle{plain}
\bibliography{reading-group,zotero}
```

Fai clic su **Recompile**. Il riferimento compare nel PDF.

<Frame caption="Il riferimento compilato">
  <img src="/images/on-premises/zotero-compiled.png" alt="L'editor con la citazione e la bibliografia, e il PDF compilato con un riferimento" />
</Frame>
</Step>
</Steps>

I file importati non vengono proposti in **Settings** sotto **References**, **Main bibliography file for this project**, quindi l'elenco resta vuoto se il progetto non ha altri file `.bib`. Puoi comunque citare da essi.

<Frame caption="L'elenco vuoto è previsto">
  <img src="/images/on-premises/zotero-settings-references.png" alt="La scheda References delle impostazioni del progetto con un elenco vuoto e disattivato" />
</Frame>

## Aggiornare il file {#refresh-the-file}

Le modifiche alla tua libreria Zotero non arrivano da sole nel progetto, e la compilazione non le recupera.

<Steps>
<Step title="Aprire il file">
Nell'albero dei file, fai clic sul file importato.
</Step>

<Step title="Fare clic su Refresh">
L'intero file viene reimportato dalla libreria scelta al momento della creazione: le nuove voci compaiono e quelle rimosse scompaiono. L'ora in alto cambia.

<Frame caption="Il file aggiornato">
  <img src="/images/on-premises/zotero-refresh.png" alt="Il file zotero.bib aggiornato con una nuova voce e un nuovo orario di importazione" />
</Frame>
</Step>

<Step title="Ricompilare">
Le nuove voci sono subito nell'elenco di `\cite{`. Fai clic su **Recompile** per aggiornare il PDF.
</Step>
</Steps>

Ogni file si aggiorna separatamente: aggiorna a parte il file del tuo gruppo. Per sapere chi può aggiornare un file in un progetto condiviso, consulta le [note per gli amministratori](/on-premises/configuration/overleaf-toolkit/integrations/zotero-integration#notes).

## Scollegare il tuo account Zotero {#unlink-your-zotero-account}

In **Account settings**, sotto **Zotero**, fai clic su **Unlink**, poi di nuovo su **Unlink** nella finestra. Il pulsante torna a dire **Link to Zotero**.

<Frame caption="Scollegare l'account">
  <img src="/images/on-premises/zotero-unlink.png" alt="La finestra Unlink Zotero Account" />
</Frame>

I file importati restano nei tuoi progetti e si compilano ancora. **From Zotero** scompare dalla finestra **Add files**, e **Refresh** mostra un errore finché non ricolleghi l'account.

<Frame caption="Aggiornamento senza account collegato">
  <img src="/images/on-premises/zotero-relink-error.png" alt="Un file importato con l'errore Could not load references from Zotero, please re-link your account and try again" />
</Frame>

Dopo averlo ricollegato, **Refresh** funziona sugli stessi file.

## Se qualcosa va storto {#if-something-goes-wrong}

**Could not load references from Zotero, please re-link your account and try again**, oppure **There was an error accessing your Zotero data** nella finestra **Add files**: Overleaf non riesce più a leggere la tua libreria, per esempio perché ne hai revocato l'accesso su Zotero. In **Account settings**, fai clic su **Unlink**, poi su **Link to Zotero**. Fino ad allora anche **Create** non riesce, con il messaggio **The project that contains this file is not shared with you**, anche nel tuo progetto.

<Frame caption="Overleaf non riesce più a leggere la tua libreria">
  <img src="/images/on-premises/zotero-access-error.png" alt="La scheda From Zotero con entrambi i messaggi di errore" />
</Frame>

**The remote service produced an error** quando fai clic su **Refresh**: la richiesta a Zotero non è riuscita. Il file mantiene il suo contenuto. Fai di nuovo clic su **Refresh** più tardi.
