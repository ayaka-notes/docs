---
title: Aggiornare TeX Live
description: Aggiorna TeX Live o installa pacchetti in un'installazione di Overleaf Community Edition.
icon: square-up
---

<Danger>

Le istruzioni seguenti si applicano **solo** alle installazioni **Community Edition**. Consigliamo vivamente agli utenti di Ayakaleaf Pro di abilitare le [Sandboxed Compiles](/it/on-premises/configuration/overleaf-toolkit/sandboxed-compiles), perché offrono accesso a immagini TeX Live quasi identiche a quelle usate su [overleaf.com](https://www.overleaf.com) e forniscono inoltre isolamento tra le compilazioni dei progetti per una maggiore sicurezza.

</Danger>

Per risparmiare banda, sia l'immagine di Overleaf Community Edition sia quella di Ayakaleaf Pro includono solo un'installazione minima di [TeX Live](https://www.tug.org/texlive/). Puoi installare altri pacchetti o passare a un'installazione completa di TeX Live usando il comando [tlmgr](https://www.tug.org/texlive/tlmgr.html) nel container `sharelatex`.

#### Accedere al container sharelatex

Per avviare una shell all'interno del container `sharelatex`, esegui

```bash
bin/shell
```

Otterrai un prompt simile a questo:

```bash
root@309b192d4030:/#
```

Nelle istruzioni seguenti supporremo che tu ti trovi all'interno del container.

#### Determinare la versione attuale di TeX Live

TeX Live viene rilasciato ogni anno intorno al mese di aprile. I passaggi per usare `tlmgr` cambiano a seconda che tu stia usando la release corrente o una precedente. Puoi verificare quale versione di TeX Live stai eseguendo con `tlmgr --version`. Ad esempio, questa installazione esegue TeX Live 2021:

```bash
# tlmgr --version
tlmgr revision 59291 (2021-05-21 05:14:40 +0200)
tlmgr using installation: /usr/local/texlive/2021
TeX Live (https://tug.org/texlive) version 2021
```

<Info>

La release corrente di TeX Live è indicata sulla [homepage di TeX Live](https://www.tug.org/texlive/).

</Info>

Se stai eseguendo una versione meno recente di TeX Live, hai due opzioni. Una nuova versione dell'immagine Docker di Overleaf viene di solito pubblicata poco dopo una release di TeX Live: puoi attenderla e aggiornare la tua installazione con lo script `bin/upgrade` oppure, se preferisci mantenere la release di TeX Live meno recente, dovrai prima indicare a `tlmgr` di usare un repository storico. Le istruzioni per farlo sono disponibili [qui](https://www.tug.org/texlive/acquire.html#past).

#### Installare i pacchetti

Per installare TeX Live in versione completa, esegui questo comando all'interno del container `sharelatex`:

```text
tlmgr install scheme-full
```

Puoi anche installare manualmente singoli pacchetti:

```bash
tlmgr install tikzlings tikzmarmots tikzducks
```

<Warning>

A partire dalla release `3.3.0`, è di nuovo **necessario** eseguire `tlmgr path add` dopo ogni utilizzo di `tlmgr install`, per creare correttamente i link simbolici di tutti i binari nel percorso di sistema.

</Warning>

Sono disponibili molti altri comandi. Scopri di più con:

```text
tlmgr help
```

Quando hai finito, digita `exit` o premi Ctrl-D per uscire dalla shell.

#### Salvare le modifiche

Le modifiche appena apportate hanno cambiato il container `sharelatex`, ma sono temporanee: andranno perse se Docker Compose ricrea il container, ad esempio durante l'aggiornamento della configurazione.

Per renderle persistenti, usa `docker commit` per salvare le modifiche in una nuova immagine Docker:

```bash
cat config/version #5.2.1
docker commit sharelatex sharelatex/sharelatex:5.2.1-with-texlive-full
echo 5.2.1-with-texlive-full > config/version
```

Dopo aver eseguito il commit delle modifiche, aggiorna di conseguenza `config/version`. Quindi esegui `bin/up` per ricreare il container `sharelatex`.

<Danger>

Dovrai ripetere questi passaggi ogni volta che esegui l'[aggiornamento](https://github.com/overleaf/toolkit/blob/master/doc/upgrading.md) a una nuova versione di Overleaf.

</Danger>
