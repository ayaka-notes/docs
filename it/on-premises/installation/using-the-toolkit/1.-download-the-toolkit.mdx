### Scaricare il Toolkit

Il Toolkit è compatibile sia con Server CE sia con Ayakaleaf Pro ed è il metodo di installazione consigliato. L'uso del Toolkit ti permette di iniziare facilmente con Server CE e di passare senza problemi ad Ayakaleaf Pro, se necessario.

<Info>

[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) è stato modificato per usare direttamente l'immagine overleaf-pro da ghcr, con TeX Live fornito da ayaka-notes. In alternativa, puoi scaricare l'overleaf-toolkit ufficiale.

</Info>

<Steps>
<Step title="Clonare il repository Overleaf Toolkit">
Per installare il toolkit devi spostarti nel percorso di installazione desiderato e poi clonare il repository GitHub Overleaf Toolkit (@Ayaka-notes) con questo comando:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
# official toolkit (Not Recommended)
# git clone https://github.com/overleaf/toolkit.git ./overleaf-toolkit
```

<Info>

Per evitare potenziali problemi di permessi, consigliamo di installare il Toolkit nella directory `$HOME` del tuo utente.

</Info>
</Step>

<Step title="Spostarsi nella directory del toolkit">
Attendi il completamento della clonazione, quindi spostati nella directory `overleaf-toolkit` appena creata:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
