### Inizializzazione della configurazione

Inizializziamo i file di configurazione del nuovo server con alcuni valori predefiniti ragionevoli, eseguendo lo script incluso `bin/init`.

```text title="Run initialization"
bin/init
```

Questo script **non** sovrascrive eventuali file di configurazione esistenti.

Ora controlliamo il contenuto della directory `config/` con il comando `ls`:

```text title="List the config directory"
ls config
```

Se l'inizializzazione è andata a buon fine, dovresti vedere tre file di configurazione: `overleaf.rc`, `variables.env` e `version`. Sono i file di configurazione principali del server e ti permettono di personalizzare il funzionamento del server e il modo in cui gli utenti interagiscono con la tua istanza.

| Nome            | Descrizione                                             |
| --------------- | ------------------------------------------------------- |
| `overleaf.rc`   | Il file di configurazione principale di primo livello.  |
| `variables.env` | Variabili d'ambiente caricate nel container Docker.     |
| `version`       | La versione dell'immagine Docker da usare.              |

<Info>

Per ora è sufficiente sapere che questi file esistono e dove trovarli. Più avanti nella documentazione esamineremo ciascun file in modo più dettagliato e spiegheremo come usarli per personalizzare la tua istanza. Se vuoi andare avanti, puoi trovare una descrizione completa di questi file di configurazione nella [pagina File e percorsi](/it/on-premises/configuration/overleaf-toolkit/files-and-locations).

</Info>
