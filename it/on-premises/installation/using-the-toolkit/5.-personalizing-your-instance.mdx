### Personalizzare la tua istanza

Prima di avviare la tua istanza di Overleaf per la prima volta, aggiorna il file di configurazione `config/variables.env` con le tue informazioni personalizzate.

<Steps>
<Step title="Modificare il file delle variabili">
Apri `config/variables.env` nel tuo editor di testo preferito e aggiorna le variabili d'ambiente seguenti con i valori richiesti.
</Step>

<Step title="Variabili d'ambiente obbligatorie">
Aggiorna le seguenti variabili in `config/variables.env`:

| Nome                          | Descrizione                                                                                                                                                    | Esempio                         |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| `OVERLEAF_SITE_URL`           | L'indirizzo a cui la tua istanza di Overleaf è accessibile pubblicamente. Viene usato nei link pubblici e nelle connessioni tramite websocket, quindi **deve essere configurato correttamente**! | `https://overleaf.lilliput.com` |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | Questo indirizzo email verrà usato come indirizzo `from` per tutte le email in uscita.                                                                        | `no-reply@lilliput.com`         |
| `OVERLEAF_ADMIN_EMAIL`        | L'indirizzo email a cui gli utenti possono contattare il responsabile del sito.                                                                                | `it-services@lilliput.com`      |

Dopo aver aggiornato queste variabili d'ambiente, salva ed esci.
</Step>

<Step title="Configurare le Sandbox Compiles">
Quindi configura TeX Live Full per le [sandboxed-compiles.md](/it/on-premises/configuration/overleaf-toolkit/sandboxed-compiles  "mention"). Apri `config/variables.env` e aggiorna le seguenti variabili d'ambiente:

```dotenv title="config/variables.env" wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```
</Step>

<Step title="Avviare la tua istanza">
Per avviare la tua istanza esegui:

```text title="Start the instance"
bin/up
```

Questo comando scaricherà le immagini necessarie, incluso TeX Live, creerà i container (usando le tue personalizzazioni) e avvierà l'istanza. Dovresti vedere l'output dei log dei vari container Docker.

Per avviarli di nuovo in seguito (senza collegarti all'output dei log) esegui:

```text title="Start without attaching to logs"
bin/start
```
</Step>
</Steps>

<Info>

Il Toolkit usa `docker compose` per gestire i container Docker di Overleaf. Il Toolkit fornisce una serie di script che incapsulano `docker compose` e si occupano per te della maggior parte dei dettagli.

</Info>

Se tutto va bene, dovresti riuscire a visualizzare la pagina di accesso della tua nuova istanza di Overleaf visitando [http://127.0.0.1/](http://127.0.0.1/) o [http://localhost/](http://localhost/) nel browser.

<Warning>

A seconda della configurazione di rete e di dove è ospitata la tua istanza di Overleaf, potrebbero essere necessarie ulteriori modifiche alla configurazione. Per maggiori dettagli, consulta le impostazioni del Toolkit: [toolkit-settings.md](/it/on-premises/configuration/overleaf-toolkit/toolkit-settings  "mention")

</Warning>
