### Diamo un'occhiata

Ora che hai una copia locale del Toolkit, diamo un'occhiata alla struttura del repository usando il comando `ls`.

```bash title="Run this"
ls -l
```

<Info>

Il comando `ls -l` mostra un elenco dettagliato in formato esteso del contenuto di una directory, fornendo informazioni aggiuntive sui file come permessi, proprietario e dimensione.

</Info>

Se la clonazione è andata a buon fine, dovresti vedere qualcosa di simile:

```text
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 bin
-rw-r--r-- 1 fry fry  6465 Aug 30 14:16 CHANGELOG.md
drwxr-xr-x 2 fry fry  4096 Sep  6 12:43 config
drwxr-xr-x 5 fry fry  4096 Aug 30 14:22 data
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 doc
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 lib
-rw-r--r-- 1 fry fry 34520 Aug 30 14:16 LICENSE
-rw-r--r-- 1 fry fry  1178 Aug 30 14:16 README.md
```

<Info>

Tutti i file di configurazione di proprietà dell'utente si trovano nella directory `config/`. Questa directory è **esclusa** dal sistema di controllo di versione git, quindi non verrà modificata dall'aggiornamento del Toolkit.

</Info>

## Struttura del repository

| Nome     | Descrizione                                                                                                                                                                                                                                               |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `bin`    | Questa cartella contiene una raccolta di script che ti aiutano a gestire la tua istanza del server Overleaf. Puoi leggere di più su questi script nella sezione Comandi più avanti.                                                                         |
| `config` | Questa cartella contiene i tuoi file di configurazione locali.                                                                                                                                                                                            |
| `lib`    | Questa cartella contiene i file di configurazione di base utilizzati dal Toolkit.                                                                                                                                                                         |
| `data`   | Per impostazione predefinita, questa cartella contiene la posizione di archiviazione per MongoDb, Redis e Overleaf. Per ulteriori informazioni, consulta la sezione [Dati persistenti](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/files-and-locations#persistent-data) più avanti. |

<Warning>

Ti consigliamo di **non** modificare direttamente i file al di fuori della cartella `/config`. Se invece devi apportare modifiche, puoi farlo tramite variabili d'ambiente impostate in **config/variables.env** o **config/overleaf.rc**.\
Ad esempio, per impostare l'immagine del servizio `mongo`, invece di modificare direttamente `lib/docker-compose.mongo.yml`, imposta l'immagine usando la variabile d'ambiente `MONGO_IMAGE` in `config/overleaf.rc`. Per ulteriori informazioni, consulta la pagina [Impostazioni del Toolkit](/it/on-premises/configuration/overleaf-toolkit/toolkit-settings).

</Warning>

<Info>

Il Toolkit **non** modificherà alcun dato nella directory `config/` senza il tuo permesso.

</Info>
