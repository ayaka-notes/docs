---
title: 4. Ottenere le immagini di Ayakaleaf Pro
icon: split
---

Ayakaleaf Pro è distribuito come immagine Docker sul registry [ghcr](https://github.com/ayaka-notes/overleaf-pro/pkgs/container/overleaf-pro/), con **accesso libero** per chiunque. Forniamo immagini per entrambe le architetture amd64 e arm64. Quando scarichi l'immagine, quella appropriata verrà selezionata automaticamente in base all'architettura del tuo sistema.

#### Utenti di Ayaka-notes Toolkit

Se utilizzi [ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit), Ayakaleaf Pro può essere usato come sostituto diretto della Community Edition, quindi puoi mantenere le impostazioni e le personalizzazioni esistenti. Abilita Pro nel Toolkit modificando `config/overleaf.rc` e impostando la variabile d'ambiente `SERVER_PRO`:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

La prossima volta che esegui `bin/up`, il Toolkit scaricherà e utilizzerà automaticamente l'immagine di Ayakaleaf Pro.

#### Utenti del Toolkit ufficiale

Se utilizzi [overleaf/toolkit](https://github.com/overleaf/toolkit), per ottenere un'immagine Pro esegui il seguente comando:

```bash title="Pull Docker Images"
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Quindi aggiungi un file denominato `docker-compose.override.yml` con il seguente contenuto nella directory `overleaf-toolkit/config`:

```yml title="docker-compose.override.yml"
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

La prossima volta che esegui `bin/up`, il Toolkit scaricherà e utilizzerà automaticamente l'immagine di Ayakaleaf Pro.
