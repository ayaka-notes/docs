<Steps>
<Step title="Installare gli strumenti da riga di comando">
Esegui in **Ubuntu**, usando la password Linux creata nel passaggio 0:

```bash
sudo apt update
sudo apt install -y git ca-certificates curl perl gawk openssl
```

Ubuntu fornisce già Bash, GNU sed e coreutils. A differenza di macOS, non servono Homebrew né un'installazione separata di GNU sed.
</Step>

<Step title="Clonare il repository dell'Ayakaleaf Toolkit">
Mantieni il Toolkit e i suoi dati nel filesystem Linux di Ubuntu, sotto la tua home directory:

```bash
cd "$HOME"
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

Evita `/mnt/c`, `/mnt/d`, OneDrive e le directory temporanee per il database e i dati dei progetti in uso. I percorsi del filesystem Linux forniscono i permessi e il comportamento del filesystem che i container si aspettano ed evitano il sovraccarico tra filesystem diversi; consulta le [indicazioni di Microsoft sui filesystem](https://learn.microsoft.com/en-us/windows/wsl/filesystems).

<Warning>

Se la directory contiene già un'installazione, usala così com'è oppure scegli un'altra directory per una nuova istanza. Non sostituire la configurazione o i dati di una distribuzione esistente.

</Warning>
</Step>
</Steps>
