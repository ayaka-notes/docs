In questa sezione eseguiamo Ayakaleaf Pro in locale su Windows con WSL 2, Ubuntu, Docker Desktop e l'[Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). La guida usa `http://localhost:8080`, conserva i dati nella home directory di Ubuntu e abilita le sandboxed compiles.

L'applicazione, MongoDB, Redis e TeX Live vengono eseguiti in container Linux gestiti da Docker Desktop. Esegui i comandi del Toolkit in Ubuntu; apri l'applicazione nel browser di Windows. Il [passaggio 0](/it/on-premises/installation/using-docker-compose/windows/0.-setup-wsl-and-docker-desktop) spiega come si combinano la parte Windows e la parte Linux e parte dall'installazione di WSL.

Puoi usare Windows per un'istanza locale oppure mantenerla in esecuzione continua con le impostazioni di disponibilità del passaggio 6. Per i server condivisi e di produzione, consigliamo la [guida per Linux](/it/on-premises/installation/using-docker-compose/linux), con HTTPS, backup e controllo degli accessi. La sospensione di Windows, l'arresto di Docker Desktop e l'arresto di WSL interrompono questa istanza locale; vedi [Mantenere l'istanza disponibile](/it/on-premises/installation/using-docker-compose/windows/6.-post-installation-tasks#keep-the-instance-available).

## Prima di iniziare {#before-you-start}

Ti servono:

* Una versione di Windows e un processore supportati da [Docker Desktop for Windows](https://docs.docker.com/desktop/setup/install/windows-install/), con la virtualizzazione hardware abilitata. Questa guida usa Windows 11 su x86-64.
* L'autorizzazione ad abilitare WSL e installare software. WSL deve essere alla versione 2.1.5 o successiva, con Ubuntu eseguito in modalità WSL 2.
* Memoria sufficiente per Windows e i container. Per una piccola istanza locale, 4 CPU e 8 GB disponibili per Docker sono un punto di partenza suggerito, non un minimo misurato.
* Spazio libero sul disco di Windows che ospita i dati di WSL e Docker. Prevedi almeno 40 GB per una configurazione TeX Live completa più i dati dei progetti; l'immagine basic del [passaggio 5](/it/on-premises/installation/using-docker-compose/windows/5.-personalizing-your-instance) è più piccola e adatta al test iniziale della distribuzione. Le versioni aggiuntive delle immagini richiedono ulteriore spazio.
* Accesso di rete a GitHub, GitHub Container Registry (`ghcr.io`) e Docker Hub per clonare il Toolkit e scaricare le immagini.

I blocchi **PowerShell** vengono eseguiti in Windows. I blocchi **Bash** e i comandi `bin/` vengono eseguiti in Ubuntu, salvo diversa indicazione. Non eseguire gli script del Toolkit in PowerShell o in Git Bash per Windows.
