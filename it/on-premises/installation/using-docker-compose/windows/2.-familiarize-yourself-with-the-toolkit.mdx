Il Toolkit è lo stesso che su Linux. La sua struttura, la directory `config/` e i comandi `bin/` sono descritti in [2. Familiarizzare con il Toolkit](/it/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) della guida per Linux.

Su Windows, tieni presenti queste differenze:

* Esegui i comandi `bin/` in **Ubuntu Bash**, da `~/ayakaleaf-toolkit`. I comandi contrassegnati come **PowerShell** vengono invece eseguiti in Windows.
* Avvia Docker Desktop e abilita la WSL Integration di Ubuntu prima di usare `bin/up`, `bin/start` o `bin/docker-compose`.
* Mantieni i file di configurazione con terminazioni di riga Linux (LF). Modificali con `nano` in Ubuntu o con un editor connesso a WSL. Le terminazioni di riga CRLF possono causare errori di Bash.
* `bin/doctor` esegue controlli Linux all'interno di Ubuntu. Il suo avviso sul mancato accesso a `quay.io` non si applica all'immagine pubblica `ghcr.io/ayaka-notes/overleaf-pro`. Gli altri avvisi richiedono comunque attenzione.

```bash
bin/doctor
```
