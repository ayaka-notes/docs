### Scaricare il Toolkit {#downloading-the-toolkit}

Ayakaleaf Pro si installa con l'**Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)), un insieme di script che esegue Overleaf in Docker al posto tuo.

Per impostazione predefinita, il Toolkit avvia la Overleaf Community Edition (CE) ufficiale e gratuita. [4. Ottenere le immagini di Ayakaleaf Pro](/it/on-premises/installation/using-docker-compose/linux/4.-get-overleaf-pro-images) lo fa passare ad Ayakaleaf Pro con una sola impostazione.

<Accordion title="Usi già l'Overleaf Toolkit ufficiale (overleaf/toolkit)?">

Non è necessario reinstallare. Mantieni la tua installazione e segui l'ultima parte di [4. Ottenere le immagini di Ayakaleaf Pro](/it/on-premises/installation/using-docker-compose/linux/4.-get-overleaf-pro-images).

</Accordion>

<Steps>
<Step title="Clonare il repository Ayakaleaf Toolkit">
Per installare il toolkit dovrai spostarti nel percorso di installazione previsto e quindi clonare il repository Ayakaleaf Toolkit con questo comando:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
```

<Info>

Per evitare potenziali problemi di permessi, consigliamo di installare il Toolkit nella directory `$HOME` del tuo utente.

</Info>
</Step>

<Step title="Spostarsi nella directory del toolkit">
Attendi il completamento della clonazione, quindi spostati nella directory `overleaf-toolkit` appena creata:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
