### Inizializzare la configurazione {#initializing-the-configuration}

Inizializziamo i file di configurazione del nuovo server con alcuni valori predefiniti ragionevoli eseguendo lo script incluso `bin/init`.

```text title="Run initialization"
bin/init
```

Questo script **non** sovrascrive alcun file di configurazione esistente.

Ora controlliamo il contenuto della directory `config/` con il comando `ls`:

```text title="List the config directory"
ls config
```

Se l'inizializzazione è andata a buon fine, dovresti vedere tre file di configurazione: `config/overleaf.rc`, `config/variables.env` e `config/version`. Sono i file di configurazione principali del server e ti permettono di personalizzare il funzionamento del server e il modo in cui gli utenti interagiscono con la tua istanza.

| Nome            | Descrizione                                                     |
| --------------- | --------------------------------------------------------------- |
| `config/overleaf.rc`   | Il file di configurazione principale di primo livello, letto dagli script del Toolkit. Stabilisce come vengono eseguiti i container, ad esempio l'indirizzo e la porta di ascolto (`OVERLEAF_LISTEN_IP`, predefinito `127.0.0.1`, e `OVERLEAF_PORT`, predefinito `80`). |
| `config/variables.env` | Variabili d'ambiente caricate nel container Docker. Stabiliscono il comportamento di Overleaf, ad esempio `OVERLEAF_SITE_URL`. |
| `config/version`       | La versione dell'immagine Docker da utilizzare.                 |

Genera anche `OVERLEAF_INVITE_TOKEN_SECRET` in `config/variables.env`. Conservalo, e non pubblicare questo file né inserirlo in un sistema di controllo versione.

<Info>

Per ora è sufficiente sapere che questi file esistono e dove trovarli. Più avanti nella documentazione esamineremo ciascun file in modo più dettagliato e spiegheremo come usarli per personalizzare la tua istanza. Se vuoi andare avanti, puoi trovare una descrizione completa di questi file di configurazione nella [pagina File e percorsi](/it/on-premises/configuration/overleaf-toolkit/files-and-locations).

</Info>
