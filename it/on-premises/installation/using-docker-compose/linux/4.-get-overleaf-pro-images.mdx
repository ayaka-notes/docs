---
title: 4. Ottenere le immagini di Ayakaleaf Pro
icon: split
---

Ayakaleaf Pro è un'immagine Docker gratuita disponibile su [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Per scaricarla non servono un account né un accesso. Le immagini sono compilate per amd64 e arm64, e Docker sceglie quella adatta al tuo server.

Apri `config/overleaf.rc` e imposta:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

La prossima volta che eseguirai `bin/up`, il Toolkit scaricherà l'immagine di Ayakaleaf Pro e la userà al posto della Overleaf Community Edition ufficiale. Le tue impostazioni in `config/` continuano a funzionare.

<Accordion title="Usi già l'Overleaf Toolkit ufficiale (overleaf/toolkit)?">

Non è necessario reinstallare. Scarica l'immagine di Ayakaleaf Pro:

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Quindi aggiungi un file chiamato `docker-compose.override.yml` con il seguente contenuto nella directory `overleaf-toolkit/config`:

```yml
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

La prossima volta che eseguirai `bin/up`, il Toolkit userà l'immagine di Ayakaleaf Pro.

</Accordion>
