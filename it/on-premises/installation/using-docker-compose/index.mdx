Docker Compose su un singolo server è il metodo consigliato per distribuire Ayakaleaf Pro. Lo esegui tramite il [Toolkit](https://github.com/ayaka-notes/toolkit): un insieme di script che incapsulano `docker compose` e leggono le tue impostazioni da un'unica directory `config/`, quindi `bin/up` sostituisce `docker compose up`.
