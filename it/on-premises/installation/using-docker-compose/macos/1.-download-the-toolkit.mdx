<Steps>
<Step title="Controllare Git e Homebrew">
```bash
git --version
brew --version
```

Se macOS ti chiede di installare i Command Line Tools quando esegui Git, installali prima. Se Homebrew manca, installalo seguendo le [istruzioni ufficiali](https://brew.sh/).
</Step>

<Step title="Mettere GNU sed nel PATH">
Gli script del Toolkit usano opzioni di GNU sed che il sed BSD integrato in macOS rifiuta. Installa [GNU sed](https://formulae.brew.sh/formula/gnu-sed) e mettilo per primo nel `PATH` di questo terminale:

```bash
brew install gnu-sed
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
sed --version
```

L'ultimo comando dovrebbe stampare **GNU sed**.

Un alias come `alias sed=gsed` non basta: il Toolkit esegue script Bash, che non vedono gli alias della tua shell interattiva. Non è necessario sostituire `/usr/bin/sed`.

Esegui di nuovo la riga `export PATH=...` in ogni nuovo terminale che usi per il Toolkit, oppure aggiungila al file di avvio della tua shell dopo l'inizializzazione di Homebrew.
</Step>

<Step title="Clonare il repository dell'Ayakaleaf Toolkit">
Scegli una directory persistente. Evita `/tmp`, le unità rimovibili e le cartelle sincronizzate con il cloud, come iCloud Drive, per il database e i dati dei progetti in uso. Questa guida usa `~/ayakaleaf-toolkit`:

```bash
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

<Warning>

Se la directory contiene già un'installazione, usala così com'è oppure scegli un'altra directory per una nuova istanza. Non inizializzare una nuova configurazione sopra una distribuzione esistente.

</Warning>
