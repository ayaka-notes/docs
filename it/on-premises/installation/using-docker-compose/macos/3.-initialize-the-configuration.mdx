---
title: 3. Inizializzare la configurazione
description: Crea i file di configurazione del Toolkit sul tuo Mac con bin/init.
icon: circle-play
---

Dalla directory del Toolkit, in un terminale con GNU sed nel `PATH`, esegui:

```bash
bin/init
```

`bin/init` crea tre file:

| File | Scopo |
| --- | --- |
| `config/overleaf.rc` | Impostazioni dei container, porta pubblicata e posizioni dei dati |
| `config/variables.env` | Impostazioni e segreti dell'applicazione |
| `config/version` | La versione dell'immagine dell'applicazione |

Genera inoltre `OVERLEAF_INVITE_TOKEN_SECRET` in `config/variables.env`. Conservalo e non pubblicare questo file né eseguirne il commit nel controllo di versione.

Mantieni la versione che il Toolkit seleziona per una nuova installazione. Per cambiare in seguito la versione di un'istanza esistente, segui [Aggiornare la tua installazione](/it/on-premises/maintenance/upgrading-your-deployment).

<Warning>

Se `bin/init` si interrompe con `sed: ... invalid command code`, è stato eseguito con il sed BSD di macOS. Un'esecuzione fallita di questo tipo può lasciare tutti e tre i file in `config/` con un `OVERLEAF_INVITE_TOKEN_SECRET` vuoto, e rieseguire `bin/init` segnala quindi `Config files already exist`. Vedi [Risoluzione dei problemi](/it/on-premises/installation/using-docker-compose/macos/troubleshooting#initialization-fails-with-invalid-command-code).

</Warning>
