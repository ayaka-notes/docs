Ayakaleaf Pro è un'immagine Docker gratuita su [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Per scaricarla non servono un account, un login o una licenza commerciale di Overleaf.

Apri `config/overleaf.rc` e imposta:

```bash title="config/overleaf.rc"
SERVER_PRO=true
```

La prossima volta che esegui `bin/up`, il Toolkit scarica `ghcr.io/ayaka-notes/overleaf-pro` nella versione indicata in `config/version`, invece della Overleaf Community Edition ufficiale.

L'immagine è compilata per `arm64` e `amd64`, e Docker sceglie quella adatta al tuo Mac. Su Apple silicon, non aggiungere `platform: linux/amd64` in un override: l'immagine verrebbe altrimenti eseguita in emulazione.
