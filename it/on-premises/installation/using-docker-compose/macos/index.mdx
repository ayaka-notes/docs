In questa sezione eseguiamo Ayakaleaf Pro in locale sul tuo Mac con Docker Desktop e l'[Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). La guida usa `http://localhost:8080`, conserva i dati nella tua home directory e compila con TeX Live 2026 in container sandbox.

Docker Desktop esegue l'applicazione, MongoDB, Redis e il compilatore TeX Live in una macchina virtuale Linux. Non installi MongoDB, Redis o MacTeX direttamente su macOS.

Usa questa configurazione per uso personale e test in locale. Per un servizio condiviso sempre attivo, consigliamo la [guida per Linux](/it/on-premises/installation/using-docker-compose/linux), con HTTPS, backup e controllo degli accessi. L'istanza non è disponibile mentre il Mac è in sospensione o Docker Desktop è arrestato; vedi [Mantenere l'istanza disponibile](/it/on-premises/installation/using-docker-compose/macos/6.-post-installation-tasks#keep-the-instance-available).

## Prima di iniziare {#before-you-start}

Ti servono:

* Una versione di macOS supportata da [Docker Desktop for Mac](https://docs.docker.com/desktop/setup/install/mac-install/).
* Git, [Homebrew](https://brew.sh/) e GNU sed. Il Toolkit usa opzioni di GNU sed che il sed BSD integrato in macOS non accetta.
* Risorse sufficienti sia per macOS sia per Docker. Per una piccola istanza locale, inizia assegnando a Docker Desktop 4 CPU e 8 GB di memoria. Si tratta di un punto di partenza suggerito, non di un minimo misurato.
* Almeno 40 GB di spazio libero per un'immagine TeX Live completa, più lo spazio per i tuoi progetti. Controlla sia lo spazio libero sul Mac sia il limite di utilizzo del disco di Docker Desktop. Inizia con una sola versione di TeX Live: ogni versione aggiuntiva richiede circa altrettanto spazio.

Le immagini dell'applicazione e di TeX Live sono pubblicate per `arm64` e `amd64`. Su Apple silicon, lascia che Docker scelga l'immagine ARM nativa e non forzare `platform: linux/amd64`.
