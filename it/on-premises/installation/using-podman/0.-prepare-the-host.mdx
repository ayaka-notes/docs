---
title: 0. Preparare l'host
description: Controlla il sistema operativo e SELinux e installa git prima di configurare Podman rootless.
icon: server
---

Non installi Podman a mano: [2. Eseguire podman-setup](/it/on-premises/installation/using-podman/2.-run-podman-setup) lo installa insieme agli altri pacchetti necessari. Qui controlli solo l'host e installi `git`, che ti serve per scaricare il Toolkit.

<Steps>
<Step title="Controllare il sistema operativo e SELinux">
Accedi con l'utente che eseguirà Ayakaleaf Pro, non come `root`, e controlla la distribuzione e la modalità di SELinux:

```bash title="Check the host"
grep PRETTY_NAME /etc/os-release
getenforce
```

Dovresti vedere RHEL, Rocky Linux, AlmaLinux o CentOS Stream con versione 9 o successiva, e `Enforcing`:

```text
PRETTY_NAME="Rocky Linux 9.9 (Blue Onyx)"
Enforcing
```
</Step>

<Step title="Controllare di poter usare sudo">
`bin/podman-setup --apply` installa pacchetti e carica un modulo SELinux con `sudo`, e chiede la tua password quando serve:

```bash title="Check sudo"
sudo -v
```

Se il comando fallisce, chiedi al tuo amministratore di aggiungere il tuo utente al gruppo `wheel`.
</Step>

<Step title="Installare git">
```bash title="Install git"
sudo dnf install -y git
```

<Warning>

Non installare Docker Engine su questo host. Il pacchetto `podman-docker`, installato da `bin/podman-setup`, fornisce il comando `docker`, e il Toolkit tratta l'host come Podman ogni volta che esiste il comando `podman`.

</Warning>
</Step>
</Steps>
