---
title: 1. Scaricare e inizializzare il Toolkit
description: Clona il Toolkit di Ayakaleaf, crea la configurazione e preparala per Ayakaleaf Pro su Podman.
icon: arrow-down-to-bracket
---

<Steps>
<Step title="Clonare il Toolkit">
Clona il **Toolkit di Ayakaleaf** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)) nella tua directory home ed entra nella directory:

```bash title="Clone the Toolkit" wrap
git clone https://github.com/ayaka-notes/toolkit.git ~/overleaf-toolkit
cd ~/overleaf-toolkit
```

Esegui tutti i comandi seguenti da questa directory.
</Step>

<Step title="Creare la configurazione">
```bash title="Run initialization"
bin/init
```

Questo crea `config/overleaf.rc`, `config/variables.env` e `config/version`, come descritto in [3. Inizializzare la configurazione](/it/on-premises/installation/using-docker-compose/linux/3.-initialize-the-configuration) della guida Docker. `bin/init` non ha ancora bisogno di Podman.
</Step>

<Step title="Configurare config/overleaf.rc">
Apri `config/overleaf.rc` e modifica queste righe:

```bash title="config/overleaf.rc"
SERVER_PRO=true
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
```

Poi aggiungi questa riga alla fine del file:

```bash title="config/overleaf.rc"
SELINUX_MODE=managed
```

| Impostazione                      | Perché                                                                                                                                                                                                      |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SERVER_PRO=true`                 | Usa l'immagine di Ayakaleaf Pro da `ghcr.io`. Non serve alcun login.                                                                                                                                         |
| `OVERLEAF_PORT=8080`              | Podman rootless non può restare in ascolto su porte inferiori a `1024`. Il valore predefinito `80` fallisce.                                                                                                 |
| `SIBLING_CONTAINERS_ENABLED=true` | Esegue ogni compilazione nel proprio container TeX Live. È già `true` per impostazione predefinita; la configurazione Podman supporta solo questa modalità.                                                  |
| `SELINUX_MODE=managed`            | Esegue il container `sharelatex` con il tipo SELinux `sharelatex_t`, che può usare il socket di Podman e nient'altro. `bin/podman-setup --apply` installa il relativo modulo di policy. Consulta [Impostazioni del Toolkit](/it/on-premises/configuration/overleaf-toolkit/toolkit-settings) per le altre modalità. |

Lascia `DOCKER_SOCKET_PATH` invariato: `bin/podman-setup --apply` lo imposta sul tuo socket di Podman nel passaggio successivo.

<Warning>

Mantieni `GIT_BRIDGE_ENABLED=false`. In Ayakaleaf Pro 6.3.4 l'integrazione Git non funziona su Podman, vedi [Limitazioni note](/it/on-premises/installation/using-podman#known-limitations).

</Warning>
</Step>

<Step title="Scegliere le immagini TeX Live">
Apri `config/variables.env`, rimuovi il `#` davanti a `TEX_LIVE_DOCKER_IMAGE` e `ALL_TEX_LIVE_DOCKER_IMAGES` ed elenca le immagini TeX Live da usare:

```bash title="config/variables.env" wrap
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
```

`bin/up` si interrompe con `Please configure ALL_TEX_LIVE_DOCKER_IMAGES` se l'elenco è vuoto. `texlive-full` è grande; per un server di test va bene anche la molto più piccola `ghcr.io/ayaka-notes/texlive-basic:2026.1`. Consulta [Sandboxed Compiles](/it/on-premises/configuration/overleaf-toolkit/sandboxed-compiles) per le immagini disponibili.

Imposta le altre variabili, come `OVERLEAF_SITE_URL`, come descritto in [5. Personalizzare la tua istanza](/it/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance#required-environment-variables). Con l'indirizzo di ascolto predefinito, usa `http://localhost:8080`.
</Step>
</Steps>
