---
title: 2. Creare il namespace e i secret
description: Crea il namespace e i secret di cui Ayakaleaf Pro ha bisogno.
icon: key
---

Tutto va nel namespace `overleaf`:

```bash
kubectl create namespace overleaf
```

Ayakaleaf Pro legge i propri secret dalle variabili d'ambiente. Generali una sola volta e conservali in un Secret:

```bash wrap
HISTORY=$(openssl rand -hex 32)
kubectl -n overleaf create secret generic overleaf-secrets \
  --from-literal=OVERLEAF_INVITE_TOKEN_SECRET="$(openssl rand -base64 32)" \
  --from-literal=OVERLEAF_SESSION_SECRET="$(openssl rand -hex 32)" \
  --from-literal=WEB_API_PASSWORD="$(openssl rand -hex 32)" \
  --from-literal=STAGING_PASSWORD="$HISTORY" \
  --from-literal=V1_HISTORY_PASSWORD="$HISTORY" \
  --from-literal=CRYPTO_RANDOM="$(openssl rand -hex 32)" \
  --from-literal=OT_JWT_AUTH_KEY="$(openssl rand -hex 32)"
```

| Secret                                         | Perché                                                                                                                                               |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_INVITE_TOKEN_SECRET`                 | Obbligatorio. Senza di esso il pod si arresta con "Missing required secrets". Modificarlo invalida gli inviti ai progetti in sospeso.                |
| `OVERLEAF_SESSION_SECRET`                      | Firma i cookie di sessione. Senza di esso, ogni riavvio del pod disconnette tutti gli utenti.                                                        |
| `WEB_API_PASSWORD`, `CRYPTO_RANDOM`, `OT_JWT_AUTH_KEY` | Secret interni. Il container li genera a ogni avvio se mancano; con più di una replica, tutte le repliche devono condividerli.                 |
| `STAGING_PASSWORD` e `V1_HISTORY_PASSWORD`     | Secret interno della cronologia; entrambi devono avere lo **stesso** valore.                                                                         |

<Warning>

Esegui il backup del Secret (`kubectl -n overleaf get secret overleaf-secrets -o yaml`) insieme ai tuoi dati. Le funzionalità che cifrano token in MongoDB necessitano anche delle proprie password di cifratura in questo Secret, ad esempio `GITHUB_TOKEN_CIPHER_PASSWORD` per la [sincronizzazione con GitHub](/it/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation).

</Warning>
