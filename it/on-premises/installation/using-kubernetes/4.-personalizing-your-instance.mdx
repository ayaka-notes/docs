---
title: 4. Personalizzare la tua istanza
description: Inserisci le tue impostazioni nella ConfigMap che sostituisce config/variables.env.
icon: square-sliders
---

La ConfigMap `overleaf-env` prende il posto del file `config/variables.env` del Toolkit: ogni variabile d'ambiente della [documentazione del Toolkit](/it/on-premises/configuration/overleaf-toolkit/environment-variables) va qui, mentre i secret vanno nel Secret del [passaggio 2](/it/on-premises/installation/using-kubernetes/2.-create-the-namespace-and-secrets).

```yaml title="30-config.yaml" wrap
apiVersion: v1
kind: ConfigMap
metadata:
  name: overleaf-env
  namespace: overleaf
data:
  OVERLEAF_APP_NAME: Ayakaleaf Pro
  OVERLEAF_SITE_URL: http://192.0.2.10:30080      # the address users open; https://... behind TLS
  OVERLEAF_ADMIN_EMAIL: admin@example.com
  # Emails: add the sender and the SMTP server together, see Email delivery
  # All members, so that the driver finds the primary even when mongo-0 is down
  OVERLEAF_MONGO_URL: mongodb://mongo-0.mongo:27017,mongo-1.mongo:27017,mongo-2.mongo:27017/sharelatex?replicaSet=overleaf
  OVERLEAF_REDIS_HOST: redis
  REDIS_HOST: redis
  ENABLED_LINKED_FILE_TYPES: project_file,project_output_file,url
  ENABLE_CONVERSIONS: "true"
  EMAIL_CONFIRMATION_DISABLED: "true"
  # Requests arrive from kube-proxy or your ingress controller, inside the pod network
  OVERLEAF_TRUSTED_PROXY_IPS: loopback,10.244.0.0/16
  # Sandboxed compiles. The HOST_DIR paths are paths ON THE NODE: the hostPath volumes that
  # the Deployment mounts at /var/lib/overleaf/data/{compiles,output,cache}.
  SANDBOXED_COMPILES: "true"
  SANDBOXED_COMPILES_SIBLING_CONTAINERS: "true"
  DOCKER_RUNNER: "true"
  SANDBOXED_COMPILES_HOST_DIR_COMPILES: /srv/overleaf/compiles
  SANDBOXED_COMPILES_HOST_DIR_OUTPUT: /srv/overleaf/output
  SANDBOXED_COMPILES_HOST_DIR_CACHE: /srv/overleaf/cache
  # Each image must be pulled into Docker on every node that can run Ayakaleaf Pro (step 0)
  ALL_TEX_LIVE_DOCKER_IMAGES: ghcr.io/ayaka-notes/texlive-full:2026.1
  ALL_TEX_LIVE_DOCKER_IMAGE_NAMES: TeX Live 2026
  TEX_LIVE_DOCKER_IMAGE: ghcr.io/ayaka-notes/texlive-full:2026.1
```

```bash
kubectl apply -f 30-config.yaml
```

| Variabile                               | Valore da impostare                                                                                                                                                |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_SITE_URL`                     | L'URL che gli utenti digitano nel browser. Con la NodePort del [passaggio 5](/it/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro), l'IP di un qualsiasi nodo e la porta `30080`; dietro un ingress o un load balancer, il suo URL. |
| `OVERLEAF_MONGO_URL`                    | Il tuo replica set. Usa `?replicaSet=` con il nome indicato in `rs.initiate`.                                                                                         |
| `OVERLEAF_REDIS_HOST` e `REDIS_HOST`    | Entrambe, sul Service di Redis.                                                                                                                                   |
| `OVERLEAF_TRUSTED_PROXY_IPS`            | `loopback` più le reti da cui si connettono i tuoi proxy. `10.244.0.0/16` è la rete dei pod di flannel; usa il CIDR dei pod del tuo cluster.                               |
| `SANDBOXED_COMPILES_HOST_DIR_*`         | I percorsi sul nodo dei volumi di compilazione. Devono corrispondere ai volumi `hostPath` del [passaggio 5](/it/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro).                                       |

Dietro HTTPS, imposta anche `OVERLEAF_SECURE_COOKIE: "true"`, vedi [Proxy TLS](/it/on-premises/configuration/overleaf-toolkit/tls-proxy).

<Info>

Una ConfigMap modificata raggiunge i pod in esecuzione solo dopo un riavvio: `kubectl -n overleaf rollout restart deployment/overleaf`.

</Info>
