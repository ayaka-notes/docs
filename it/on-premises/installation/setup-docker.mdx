Overleaf funziona su Docker. Devi installare:

* Docker Engine (Docker CE)
* Il plugin Docker Compose (`docker compose`, v2)

Questi passaggi si riferiscono a una versione recente di Ubuntu LTS (20.04/22.04/24.04).

<Warning>

Evita di installare `docker.io` dal repository apt predefinito di Ubuntu.\
Usa il repository ufficiale di Docker, in modo da ottenere una versione recente di Docker e il plugin `docker compose`.

</Warning>

La documentazione ufficiale è disponibile qui: [https://docs.docker.com/engine/install/ubuntu/](https://docs.docker.com/engine/install/ubuntu/).

<Steps>
<Step title="1) Rimuovere i pacchetti vecchi o in conflitto (se presenti)">
Se Docker era stato installato in precedenza da un'altra fonte, rimuovilo prima:

```bash wrap
sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-compose-v2 docker-doc podman-docker containerd runc | cut -f1)
```

Questo comando è sicuro anche se alcuni pacchetti non sono installati.
</Step>

<Step title="2) Aggiungere il repository apt ufficiale di Docker">
Installa i prerequisiti:

```bash
sudo apt update
sudo apt install -y ca-certificates curl
```

Aggiungi la chiave GPG di Docker:

```bash wrap
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```

Aggiungi il repository:

```bash wrap
# Add the repository to Apt sources:
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Signed-By: /etc/apt/keyrings/docker.asc
EOF

sudo apt update
```
</Step>

<Step title="3) Installare Docker Engine e il plugin Compose">
Installa Docker e il plugin Compose:

```bash wrap
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

Avvia Docker all'avvio del sistema:

```bash
sudo systemctl enable --now docker
```
</Step>

<Step title="4) Verificare l'installazione">
Questi comandi dovrebbero essere eseguiti senza errori:

```bash
docker --version
docker compose version
sudo docker run --rm hello-world
docker ps
```
</Step>

<Step title="5) (Facoltativo) Eseguire Docker senza sudo">
Aggiungi il tuo utente al gruppo `docker`:

```bash
sudo usermod -aG docker $USER
```

Poi **esci e rientra nella sessione**, oppure esegui:

```bash
newgrp docker
```

Ora questo comando dovrebbe funzionare senza `sudo`:

```bash
docker ps
```

<Danger>

Il gruppo `docker` ha un accesso equivalente a root sull'host.\
Questo è normale nelle installazioni tipiche di Overleaf ed è particolarmente rilevante se abiliti le Sandboxed Compiles.

</Danger>
</Step>
</Steps>

### Passaggio successivo

Una volta che Docker funziona, prosegui con i passaggi di installazione del Toolkit in [Usare il Toolkit](/it/on-premises/installation/using-the-toolkit).
