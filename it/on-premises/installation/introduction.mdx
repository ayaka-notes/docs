### Requisiti hardware {#hardware-requirements}

Abbiamo condotto alcuni test e abbiamo rilevato che, se esegui Overleaf su un server con 2 core e 2 GB di RAM, i suoi componenti principali, basati soprattutto su Node.js, consumano circa 1 GB di memoria. Redis e MongoDB possono richiedere altri 0,5 GB, mentre l'avvio di un container Docker in sandbox per la compilazione può consumarne altri 0,3 GB. Ciò significa che un server con 2 core e 2 GB può realisticamente gestire solo circa una compilazione simultanea alla volta.

* I requisiti hardware minimi per installare Ayakaleaf Pro sono una CPU a 2 core e 3 GB di RAM.
* A causa delle dimensioni della nostra immagine TeX Live, sono necessari almeno 40 GB di spazio di archiviazione per abilitare la compilazione in sandbox.
* Se vuoi installare l'intero set di immagini TeX Live dal 2020 al 2026, assicurati di avere almeno 150 GB di spazio libero su disco.

Ecco alcune configurazioni hardware consigliate per diversi scenari d'uso:

| Caso d'uso                                           | Configurazione consigliata                                                                           |
| ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Uso personale, con collaborazione occasionale        | 2 core CPU, 4 GB di RAM, 80 GB di spazio di archiviazione                                            |
| Piccoli team, fino a 10 utenti con collaborazione leggera | 2 core CPU, 8 GB di RAM, 256 GB di spazio di archiviazione                                      |
| Team di medie dimensioni, fino a 100 utenti          | 4 core CPU, 16 GB di RAM, 1 TB di spazio di archiviazione                                            |
| Distribuzioni su larga scala o universitarie         | Distribuzione in cluster distribuito, con archiviazione S3; contattaci se hai bisogno di assistenza per la distribuzione |

### Requisiti software {#software-requirements}

Per quanto riguarda i requisiti software, consigliamo di usare una versione recente e stabile di Ubuntu (ad es. Ubuntu 24.04 nel 2025–2026, Ubuntu 22.04 nel 2023–2024) insieme all'ultima versione stabile di Docker.

<Info>

Ubuntu 26.04 include il kernel Linux 7.0 e MongoDB si rifiuta di avviarsi sui kernel Linux dalla 6.19 alla 7.0.13 ([dettagli](https://www.mongodb.com/docs/manual/administration/production-notes/)). Per eseguirlo su questi kernel, aggiungi quanto segue al servizio `mongo` in `overleaf-toolkit/config/docker-compose.override.yml` (lo stesso file che imposta l'immagine di Ayakaleaf Pro). La nostra CI gira su Ubuntu 26.04 con questa impostazione. I kernel 7.0.14 e successivi non ne hanno bisogno.

```yml title="docker-compose.override.yml"
services:
    mongo:
        environment:
            GLIBC_TUNABLES: glibc.pthread.rseq=1
```

</Info>

Consigliamo Linux per i server condivisi e di produzione. Puoi anche eseguire Ayakaleaf Pro su [macOS](/it/on-premises/installation/using-docker-compose/macos) o su [Windows con WSL 2](/it/on-premises/installation/using-docker-compose/windows) usando Docker Desktop. Segui la guida per la tua piattaforma. Le immagini supportano sia AMD64 sia ARM64.

### Prestazioni di LaTeX {#latex-performance}

LaTeX è un programma a thread singolo, ovvero può usare un solo core della CPU alla volta. Quando si compila un singolo documento, le prestazioni sono limitate principalmente dalla frequenza di clock single-core della CPU. Pertanto, più sono elevate le prestazioni single-core della tua CPU, più velocemente potrai compilare un documento. Un numero maggiore di core è utile solo quando più utenti compilano documenti contemporaneamente.

Prendendo come esempio il [template ThuThesis](https://www.overleaf.com/latex/templates/thuthesis-tsinghua-university-thesis-latex-template/cfwgcxtvkbsx), il tempo di compilazione è di circa 6 secondi su un Intel Core i9-14900K (5,6 GHz), mentre è di circa 13 secondi su un'istanza Azure Standard D2as v5 (2 vCPU, 8 GiB di RAM) basata su AMD EPYC 7763 (3,2 GHz).

Naturalmente, le prestazioni effettive di compilazione dipendono dalla tua configurazione hardware. La maggior parte delle CPU per server non raggiunge frequenze di clock elevate come quelle del 14900K, quindi dovrai trovare un compromesso tra costo e velocità di compilazione.

Abbiamo inoltre condotto un'analisi approfondita delle prestazioni di compilazione di LaTeX. Se ti interessa, consulta il nostro blog [Overleaf Benchmark: A Deep Research of Concurrent LaTeX Compilation in Overleaf (SaaS and Self-host)](/it/blog/2026/overleaf-benchmark  "mention").
