Il modo più semplice per provare Ayakaleaf Pro è usare GitHub Codespace, dove tutte le variabili d'ambiente sono preconfigurate per consentirti di usarlo subito, senza alcuna configurazione.

<Warning>

Quando esegui container Docker con GitHub Codespaces, il Codespace non si spegne automaticamente e continuerà a essere **fatturato**. Per le regole di fatturazione di GitHub Codespaces, consulta le [regole di fatturazione di GitHub Codespaces](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces).

Per gestire i tuoi GitHub Codespaces, visita [https://github.com/codespaces](https://github.com/codespaces). Quando non ti serve più, ricordati di eliminare tempestivamente il tuo Codespace.

</Warning>

Abbiamo **preconfigurato** le seguenti funzionalità:

* [x] Compilazione LaTeX in sandbox con TeXLive **Basic** (2024-2026)
* [x] Importazione/esportazione Pandoc (funzionalità della piattaforma SaaS)
* [x] Esecuzione di script Python (funzionalità della piattaforma SaaS)
* [x] Supporto Git-Bridge (funzionalità di Server Pro)
* [x] Ricerca avanzata dei riferimenti (funzionalità della piattaforma SaaS)
* [x] Pannello di amministrazione (gestione globale di utenti/progetti)
* [x] Revisioni (con pannello di revisione e commenti)
* [x] Cronologia completa del progetto (con ripristino e download)
* [x] Tavolozza dei simboli (funzionalità di Server Pro/piattaforma SaaS)

<Warning>

I GitHub Codespaces standard offrono 32 GB di spazio di archiviazione, che non bastano per la nostra installazione `texlive-full`. Per provare l'immagine completa, apri un ticket di supporto GitHub per ottenere un Codespace con runner di grandi dimensioni (8+ core).

</Warning>

GitHub Sync, LDAP, OAuth, SSO, l'integrazione con Zotero e altre funzionalità _**non sono configurate**_ in questo ambiente di prova. Puoi consultare le [impostazioni del Toolkit](/it/on-premises/configuration/overleaf-toolkit/toolkit-settings) per maggiori dettagli su come configurare queste funzionalità nella tua installazione.

<Steps>
<Step title="Crea il tuo GitHub Codespace">
Fai clic sul pulsante seguente per creare il tuo GitHub Codespace. Per quanto riguarda la configurazione del server, **2 core con 8 GB di RAM** sono generalmente sufficienti per una prova. Se prevedi di usare [**TeX Live Full**](https://github.com/ayaka-notes/texlive-full), ti consigliamo di scegliere una configurazione con **8 core e 64 GB**.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/ayakaleaf-pro-playground)

Quando il tuo codespace è pronto, esegui il comando seguente nel terminale bash per inizializzare la tua istanza Overleaf.

```bash title="bash"

```

#### Usare l'immagine TeXLive Full

Se hai accesso a GitHub Codespaces con 8 core/64 GB, puoi usare l'immagine TeXLive Full in questo ambiente di prova. Puoi modificare le seguenti variabili d'ambiente nel file `toolkit/config/variables.env` per usare l'immagine TeXLive Full al posto dell'immagine TeXLive Basic.

```dotenv wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1, ghcr.io/ayaka-notes/texlive-full:2024.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025, Texlive 2024
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```

Dopo aver modificato le variabili d'ambiente, devi riavviare il Toolkit per applicare le modifiche. Puoi eseguire il comando seguente per riavviarlo.

```bash
cd toolkit && bin/up -d
```
