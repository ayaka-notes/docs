---
title: Deployment air-gapped/offline
description: Distribuisci Ayakaleaf Pro offline esportando, trasferendo e caricando le immagini Docker.
icon: block-brick
---

In generale, sconsigliamo di distribuire Ayakaleaf Pro in un ambiente offline, poiché molte delle sue funzionalità, come GitHub Sync e l'integrazione con Zotero, richiedono una connessione a Internet.

Se vuoi lavorare offline, potrebbe non essere sempre possibile raggiungere il registry `ghcr.io` per scaricare le immagini `ayakaleaf-pro` e TeX Live necessarie. Non è un problema, perché Docker fornisce strumenti per esportare e importare le immagini che ti aiuteranno con un deployment offline/air-gapped.

In sintesi, scaricherai le immagini necessarie su un dispositivo con connessione a Internet, le esporterai su un dispositivo portatile (oppure le trasferirai con SCP/Rsync) e le importerai sul server air-gapped.

Per farlo, dovrai completare i seguenti passaggi:

* Scarica tutte le immagini necessarie ( `overleaf-pro`, `git-bridge`, `mongo`, `redis` + eventuali [immagini TeX Live](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles#available-tex-live-images) da usare con le [Sandboxed Compiles](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles)) su una macchina con connessione a Internet
  * `docker pull ghcr.io/ayaka-notes/overleaf-pro:6.1.2`
  * `docker pull quay.io/sharelatex/git-bridge:6.1.2` (il tag deve essere lo stesso di `overleaf-pro`)
  * `docker pull mongo:6` (sostituisci con la versione effettiva)
  * `docker pull redis:6.2` (sostituisci con la versione effettiva)
  * `docker pull ghcr.io/ayaka-notes/texlive-full:2024.1` (sostituisci con la versione effettiva)
* Per **ciascuna** delle immagini scaricate, dovrai poi esportarla in un file .tar. Ad esempio, `docker save ghcr.io/ayaka-notes/overleaf-pro:6.1.2 > overleaf-pro:6.1.2.tar`
* Con il metodo che preferisci, trasferisci i file `.tar` dalla macchina connessa a Internet al server offline/air-gapped
* Per ciascun file .tar, usa il comando `docker load` per caricare l'immagine dal file .tar. Ad esempio, `docker load < overleaf-pro:6.1.2.tar`
* Infine, esegui il comando `docker images` per visualizzare/verificare che il caricamento delle immagini sia andato a buon fine e che siano disponibili

<Danger>

Per impostazione predefinita, quando esegui il comando `bin/up`, il Toolkit tenterà di scaricare automaticamente ciascuna delle immagini TeX Live impostate tramite `ALL_TEX_LIVE_DOCKER_IMAGES` in `config/variables.env`. Poiché il tuo deployment è air-gapped, questa operazione fallirà: puoi impedirla usando `SIBLING_CONTAINERS_PULL=false` in `config/overleaf.rc`.

</Danger>
