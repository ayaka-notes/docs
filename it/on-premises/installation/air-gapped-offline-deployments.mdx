---
title: Distribuzioni air-gapped/offline
description: Distribuisci Ayakaleaf Pro offline esportando, trasferendo e caricando le immagini Docker.
icon: block-brick
---

In generale, sconsigliamo di distribuire Ayakaleaf Pro in un ambiente offline, poiché molte delle sue funzionalità, come GitHub Sync e l'integrazione con Zotero, richiedono una connessione a Internet.

Se vuoi lavorare offline, potrebbe non essere sempre possibile raggiungere il registry `ghcr.io` per scaricare le immagini `ayakaleaf-pro` e TeX Live necessarie. Non è un problema, perché Docker fornisce strumenti per esportare e importare le immagini che ti aiuteranno in una distribuzione offline/air-gapped.

In sintesi, scaricherai le immagini necessarie su un dispositivo connesso a Internet, le esporterai su un dispositivo portatile (o le trasferirai tramite SCP/Rsync) e le importerai sul server air-gapped.

Per farlo, dovrai completare i seguenti passaggi:

* Scarica tutte le immagini necessarie ( `overleaf-pro`, `git-bridge`, `mongo`, `redis` + eventuali [immagini TeX Live](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles#available-tex-live-images) necessarie per l'uso con le [Sandboxed Compiles](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles)) su una macchina connessa a Internet
  * `docker pull ghcr.io/ayaka-notes/overleaf-pro:6.3.0`
  * `docker pull ghcr.io/ayaka-notes/overleaf-pro/git-bridge:6.3.0` (il tag deve essere lo stesso di `overleaf-pro`)
  * `docker pull mongo:8.0` (sostituisci con la versione effettiva)
  * `docker pull redis:7.4` (sostituisci con la versione effettiva)
  * `docker pull ghcr.io/ayaka-notes/texlive-full:2024.1` (sostituisci con la versione effettiva)
* **Ciascuna** delle immagini scaricate dovrà poi essere esportata in un file .tar. Ad esempio, `docker save ghcr.io/ayaka-notes/overleaf-pro:6.3.0 > overleaf-pro:6.3.0.tar`
* Con il metodo che preferisci, trasferisci i file `.tar` dalla macchina connessa a Internet al server offline/air-gapped
* Per ciascun file .tar, usa il comando `docker load` per caricare l'immagine dal file .tar. Ad esempio, `docker load < overleaf-pro:6.3.0.tar`
* Infine, esegui il comando `docker images` per visualizzare/confermare che il caricamento delle immagini sia riuscito e che siano disponibili

<Danger>

Per impostazione predefinita, quando esegui il comando `bin/up`, il Toolkit tenterà di scaricare automaticamente ciascuna delle immagini TeX Live impostate tramite `ALL_TEX_LIVE_DOCKER_IMAGES` in `config/variables.env`. Poiché la tua distribuzione è air-gapped, l'operazione fallirà: puoi evitarlo usando `SIBLING_CONTAINERS_PULL=false` in `config/overleaf.rc`.

</Danger>
