### Comprendere i numeri di versione di Overleaf

Overleaf usa numeri di versione in stile semantico nel formato **6.X.y**.

* **6.X** rappresenta la serie della release principale. Quando viene rilasciata una nuova versione **6.X.0**, questa diventa la base di riferimento per quella generazione.
* **y** rappresenta gli aggiornamenti patch all'interno della stessa serie principale. Le release successive (ad esempio **6.X.1**, **6.X.2**, …) sono in genere aggiornamenti di manutenzione costruiti sopra **6.X.0**, che contengono correzioni di bug, correzioni di sicurezza e piccoli miglioramenti anziché grandi modifiche alle funzionalità.

### Versione di Ayakaleaf Pro

I numeri di versione di Ayakaleaf Pro sono **completamente allineati** con le release ufficiali di Overleaf. Salvo diversa indicazione, tutte le release pubblicate sono immagini della edizione Pro con tutte le funzionalità.

Allineiamo rigorosamente le nostre versioni con Overleaf Community Edition. Questo ti permette di usare i plugin open source per Overleaf. Non modifichiamo le interfacce principali di Overleaf. Di conseguenza, qualsiasi plugin compatibile con la release `A.X.y` corrispondente della Community Edition è pienamente compatibile con Ayakaleaf Pro `A.X.y`.
