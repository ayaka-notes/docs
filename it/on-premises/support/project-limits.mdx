---
title: Limiti dei progetti
icon: list-check
---

| Funzionalità                                     | Limite                                                                                                                                                                  |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Timeout di compilazione                          | **Predefinito:** 180 secondi. Consulta [Aggiornare il timeout di compilazione dei progetti](/it/on-premises/user-and-project-management/project-management) per ulteriori informazioni sulla personalizzazione di questo valore. |
| Numero massimo di file per progetto              | 2000                                                                                                                                                                    |
| Dimensione massima del materiale modificabile per progetto | **Predefinito:** 7 MB. Consulta [Variabili d'ambiente](/it/on-premises/configuration/overleaf-toolkit/environment-variables) per ulteriori informazioni sulla personalizzazione di questo valore. |
| Dimensione massima di un singolo file di testo modificabile | 2 MB\*                                                                                                                                                       |
| Dimensione massima di un singolo caricamento     | 50 MB (configurabile tramite `MAX_UPLOAD_SIZE`)                                                                                                                         |
| Dimensione massima non compressa di un file .zip caricato | 6 × `MAX_UPLOAD_SIZE` (300 MB per impostazione predefinita)                                                                                                    |
| Dimensione massima del progetto                  | Illimitata†                                                                                                                                                             |
| Numero massimo di progetti                       | Illimitato                                                                                                                                                              |

\* Alcuni file di dimensioni maggiori potrebbero restare modificabili in determinate circostanze. Tuttavia, per garantire che un file resti modificabile, dovresti limitarne la dimensione a 2 MB o meno.

† Non esiste un limite imposto sulla dimensione totale del progetto. Tuttavia, potresti riscontrare alcune limitazioni tecniche lavorando con progetti molto grandi. Consigliamo una dimensione massima del progetto di 500 MB, o inferiore a 100 MB se utilizzi la nostra [integrazione Git](https://www.overleaf.com/learn/how-to/Git_integration). I progetti che superano queste dimensioni potrebbero funzionare, ma restare entro questi limiti ti garantirà la migliore esperienza.
