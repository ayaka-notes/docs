<Danger>

È importante eseguire un [backup coerente](/it/on-premises/maintenance/data-and-backups#performing-a-consistent-backup) **prima** di ogni aggiornamento di versione principale, in modo da poter tornare indietro in caso di necessità.

</Danger>

L'[ayakaleaf toolkit↗](https://github.com/ayaka-notes/toolkit) è un repository git, quindi ottenere le nuove funzionalità del Toolkit è semplice. Basta eseguire il comando `bin/upgrade` e seguire le istruzioni a schermo.

Vale la pena notare che la versione dell'immagine Docker (in `config/version`) è gestita separatamente dagli aggiornamenti del codice del Toolkit. Aggiornare il codice del Toolkit **non** modifica automaticamente la versione dell'immagine Docker in esecuzione. Ciò significa che, nella maggior parte dei casi, puoi aggiornare la versione del Toolkit senza aggiornare la tua installazione.

#### Lo script `bin/upgrade`

Quando esegui il comando `bin/upgrade`, lo script verifica se è disponibile un aggiornamento del codice del Toolkit e ti propone di aggiornarlo. Puoi sempre rifiutare questo aggiornamento e nulla verrà modificato.

Se scegli di aggiornare il codice del Toolkit, lo script verificherà quindi se la versione _predefinita_ dell'immagine Docker è cambiata e ti proporrà di aggiornare il tuo file di versione locale (in `config/version`) in modo che corrisponda al nuovo valore predefinito.

Se scegli di cambiare versione, lo script ti guiderà attraverso il processo di arresto dei servizi Docker, esecuzione di un backup e riavvio dei servizi Docker. Il vecchio file di versione verrà copiato automaticamente in `config/__old-version`, nel caso in cui tu debba tornare a quella versione delle immagini Docker.

<Info>

Per le configurazioni air-gapped che importano manualmente le immagini Docker, imposta `PULL_BEFORE_UPGRADE=false` nel file `config/overleaf.rc`.

Consulta [questa pagina](/it/on-premises/installation/air-gapped-offline-deployments) per maggiori informazioni sull'installazione in ambienti air-gapped/offline.

</Info>

### Percorso di aggiornamento

Se stai usando una versione di Overleaf Community precedente alla v6.0.0, consulta la [documentazione ufficiale di Overleaf](https://docs.overleaf.com/on-premises/maintenance/upgrading-your-deployment#upgrade-path) per completare l'aggiornamento.

All'interno di Ayakaleaf Pro, aggiorna prima all'ultima patch release della tua linea di versione attuale, poi alla successiva, ad esempio `6.2.0 → 6.2.2 → 6.3.2`. Leggi le [note di rilascio](/it/on-premises/release-notes/release-notes-6.x.x) di ogni versione che attraversi, alcune richiedono passaggi aggiuntivi. È supportata solo la release più recente.
