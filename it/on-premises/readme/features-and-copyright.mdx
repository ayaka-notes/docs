#### Funzionalità 13: Python Runner {#features-13-python-runner}

Questa funzionalità è sviluppata da Overleaf ufficiale. Puoi eseguire script Python nel tuo browser.

È integrata e non richiede alcuna configurazione: apri un file `.py` in un progetto e fai clic su **Run**. Lo script viene eseguito con Pyodide nel browser dell'utente, quindi sono disponibili solo i pacchetti integrati di Pyodide.

* Il riquadro di output sotto l'editor mostra ciò che lo script stampa (le ultime 100 righe). Fai clic su **Stop** per interrompere un'esecuzione. Ogni esecuzione avvia un nuovo Python, quindi nulla viene mantenuto dall'esecuzione precedente.
* Prima di ogni esecuzione, i file di testo del progetto vengono copiati nella cartella di lavoro dello script, così lo script può aprirli tramite il loro percorso nel progetto, ad es. `open('data/results.csv')`. I file binari come immagini e PDF non vengono copiati.
* I file che lo script scrive in quella cartella vengono salvati nel progetto allo stesso percorso quando l'esecuzione va a buon fine, sostituendo un eventuale file con lo stesso nome. Un'esecuzione non riuscita non salva nulla. Un'esecuzione può salvare fino a 50 file, 50 MB per file e 100 MB in totale.
* Matplotlib non dispone di un display: salva i grafici con `plt.savefig('figure.png')`, quindi includi l'immagine nel tuo documento LaTeX.
* Pyodide e i suoi pacchetti (come NumPy, pandas, SciPy e Matplotlib) vengono serviti dalla tua istanza, quindi il browser non ha bisogno dell'accesso a Internet. I pacchetti installati con pip non possono essere usati.

#### Funzionalità 17: integrazione con i gestori di riferimenti {#features-17-reference-manager-integration}

Questa funzionalità è sviluppata da [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro). * Collegare i tuoi account Zotero e Mendeley nelle impostazioni dell'account.

* Aggiornare in qualsiasi momento il file `.bib` importato per mantenerlo aggiornato.

Consulta [Integrazione Zotero](/it/on-premises/configuration/overleaf-toolkit/integrations/zotero-integration) e [Integrazione Mendeley](/it/on-premises/configuration/overleaf-toolkit/integrations/mendeley-integration) per la configurazione.

#### Funzionalità 18: API Open in Overleaf {#features-18-open-in-overleaf-api}

Questa funzionalità è sviluppata da [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) ed è compatibile con l'API "Open in Overleaf" di overleaf.com. Puoi aggiungere un link o un pulsante "Open in Ayakaleaf" al tuo sito web, blog o libreria di template, così i visitatori possono aprire con un clic uno snippet LaTeX, un file remoto o un progetto ZIP come nuovo progetto nella tua istanza. Visita `/devs` sulla tua istanza per i dettagli e consulta [API di importazione di Overleaf](/it/on-premises/configuration/overleaf-toolkit/integrations/overleaf-import-api).

#### Funzionalità 19: sincronizzazione con GitLab {#features-19-gitlab-sync}

#### Funzionalità 20: sincronizzazione con Dropbox {#features-20-dropbox-sync}

Questa funzionalità è sviluppata da [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) nella v6.3.1 come anteprima (rilascio ufficiale nella v6.4.0), come la sincronizzazione con Dropbox su overleaf.com. Quando un utente collega il proprio account Dropbox, ciascuno dei suoi progetti compare come cartella nel suo Dropbox: le modifiche in Overleaf vengono inviate a Dropbox e quelle fatte in Dropbox tornano in Overleaf. Consulta [Sincronizzazione con Dropbox](/it/on-premises/configuration/overleaf-toolkit/integrations/dropbox-synchronisation) per la configurazione.

#### Funzionalità 21: server MCP {#features-21-mcp-server}

Questa funzionalità è sviluppata da [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) nella v6.3.1. Ogni progetto ha un server MCP, così i client AI come Claude Code, Codex, Cursor, VS Code o Gemini CLI possono leggerne e modificarne i file in tempo reale, compilarlo, leggere il log LaTeX, scaricare il PDF e rispondere ai commenti.
