Qui abbiamo raccolto le risposte ad alcune domande frequenti su Ayakaleaf Pro.

### Domande di base

<Accordion title="Q01: Ayakaleaf Pro è una prova gratuita? Richiede una licenza?">

No. Ayakaleaf Pro è completamente gratuito. Non è una versione di prova e non richiede alcuna licenza.

</Accordion>

<Accordion title="Q02: Ayakaleaf Pro include tutte le funzionalità di Overleaf Server Pro?">

Sì. Ayakaleaf Pro include tutte le funzionalità di Overleaf Server Pro, compresa l'integrazione Git-Bridge. Include anche alcune funzionalità selezionate della piattaforma SaaS di Overleaf. Continuiamo a sviluppare e migliorare Ayakaleaf Pro.

</Accordion>

<Accordion title="Q03: Quanto costa Overleaf Server Pro?">

Overleaf Server Pro costa circa \$300 per utente all'anno. Richiede almeno 10 licenze, quindi le installazioni partono da circa \$3.000 all'anno. Contratti pubblici statunitensi di dimensioni minori mostrano costi annuali di circa \$320–\$370 per utente. Questo rende Server Pro costoso, soprattutto per i team più piccoli. Consulta [#information-and-price-about-overleaf-server-pro](/it/on-premises#information-and-price-about-overleaf-server-pro  "mention") per acquisti e prezzi documentati.

</Accordion>

<Accordion title="Q04: Perché Overleaf Server Pro non include GitHub Sync o funzionalità di IA?">

Overleaf Server Pro è comunemente utilizzato da organizzazioni governative, che lo installano su reti private e ne controllano rigorosamente l'accesso. Per proteggere i dati sensibili, le funzionalità incluse evitano di scambiare dati con servizi di terze parti. Se hai bisogno di GitHub Sync, dell'IA o di funzionalità connesse simili, Overleaf consiglia un abbonamento alla sua piattaforma SaaS.

</Accordion>

<Accordion title="Q05: Ayakaleaf Pro è sicuro e affidabile?">

Ayakaleaf Pro è open source. Esaminiamo il codice con strumenti come Codex Security per rafforzarne la sicurezza e l'affidabilità. Se non abiliti la sincronizzazione dei dati con terze parti, i tuoi dati restano sul tuo server. Ayakaleaf Pro non contiene alcuna telemetria che invii i tuoi dati altrove.

</Accordion>

<Accordion title="Q06: Ayakaleaf Pro sarà mantenuto a lungo termine?">

Faremo tutto il possibile per mantenere questo progetto a lungo termine.

</Accordion>

<Accordion title="Q07: Ayakaleaf Pro è conforme?">

Ayakaleaf Pro è un fork della community. Il suo codice e le funzionalità integrate provengono da contributi della community. È distribuito con licenza AGPL v3. Le installazioni possono essere conformi a questa licenza quando ne soddisfano i requisiti.

</Accordion>

<Accordion title="Q08: Perché il progetto si chiama Ayakaleaf Pro?">

Il progetto si chiamava originariamente Overleaf Pro nel 2024. Lo sviluppo si è interrotto per un periodo, per poi riprendere alla fine del 2025. Nel primo trimestre del 2026, Overleaf ha rinominato Pro il proprio piano di abbonamento con IA. Inoltre, il feedback della community ha evidenziato che il nome Overleaf Pro poteva creare rischi legati ai marchi e alla sostituzione d'identità, inducendo gli utenti a pensare che il progetto fosse ufficiale.

Abbiamo rinominato il progetto Ayakaleaf Pro per evitare questa confusione. Il nome può essere letto come “Ayaka-notes Overleaf Pro”. Il maintainer contribuisce allo sviluppo della community di Overleaf fin dagli anni da studente, da oltre cinque anni. Questa esperienza sostiene il nostro impegno di manutenzione a lungo termine.

</Accordion>

<Accordion title="Q09: Cosa distingue Ayakaleaf Pro dai nuovi editor LaTeX realizzati con l'IA?">

Dal 2026, la community open source ha rilasciato molti editor LaTeX realizzati con l'IA, tra cui OpenAI Prism. Ayakaleaf Pro mantiene i tuoi dati e servizi sul tuo server, offrendoti il controllo diretto sulla tua installazione e sui tuoi dati.

Molti editor sperimentali della community non hanno un piano consolidato di manutenzione a lungo termine. Anche le piattaforme di compilazione LaTeX di terze parti possono cessare l'attività quando la base di utenti o i ricavi sono insufficienti. Ayakaleaf Pro fornisce tutto il codice sorgente e ti consente di ospitare autonomamente ogni servizio. Anche se la manutenzione si interrompesse, il tuo servizio self-hosted esistente potrebbe continuare a funzionare.

</Accordion>

### LaTeX

<Accordion title="Q01: Le compilazioni dei progetti LaTeX degli utenti sono isolate? Shell Escape è abilitato?">

Quando abiliti le Sandbox Compiles, la compilazione di ogni utente viene eseguita in un container Docker separato ed è isolata dalle compilazioni degli altri utenti. Shell Escape è abilitato per impostazione predefinita per le Sandbox Compiles.

</Accordion>

<Accordion title="Q02: L'immagine delle Sandbox Compiles è affidabile? La compilazione può fallire?">

Negli ultimi tre anni abbiamo migliorato la nostra immagine TeX Live Full per le Sandbox Compiles. Nella maggior parte dei casi, i progetti che compilano su overleaf.com compilano correttamente anche con Ayakaleaf Pro. Se un font necessario non è disponibile, caricalo manualmente nel tuo progetto.

</Accordion>
