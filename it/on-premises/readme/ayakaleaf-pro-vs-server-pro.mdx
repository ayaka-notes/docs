---
title: Overleaf Server Pro vs. Ayakaleaf Pro
description: Overleaf Server Pro e Ayakaleaf Pro Edition sono entrambe versioni on-premises di Overleaf. Ma quali sono le differenze?
icon: scale-balanced
---

<Info>

Ayakaleaf Pro è un'implementazione potenziata di Overleaf Community Edition che offre tutte le funzionalità _**premium gratuitamente**_ di Server Pro. A differenza di Overleaf Common, disponibile su [https://www.overleaf.com/](https://www.overleaf.com/), non abbiamo limitazioni sul tempo di compilazione né requisiti di licenza sul numero di utenti, e puoi ospitare completamente i tuoi dati in autonomia, garantendo una sicurezza assoluta.

Overleaf Server Pro è un deployment commerciale e self-hosted di Overleaf, con assistenza ufficiale. Per maggiori informazioni su Server Pro, visita [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud).

</Info>

<Warning>

Overleaf Community Edition è pensata per ambienti in cui **tutti** gli utenti sono attendibili. La Community Edition **non** è adatta a scenari in cui è richiesto l'isolamento degli utenti, poiché le Sandbox Compiles non sono disponibili.

Senza sandbox, le compilazioni LaTeX vengono eseguite con gli stessi privilegi del container, consentendo l'accesso al suo filesystem, alla rete e alle variabili d'ambiente. Questo comporta il rischio di esposizione dei dati o di compromissione del sistema. Le compilazioni senza sandbox dovrebbero essere usate solo in ambienti completamente attendibili; per deployment multiutente o di produzione, le Sandbox Compiles sono fortemente consigliate.

Per maggiori informazioni sulle Sandbox Compiles, consulta la nostra [documentazione](/it/on-premises/configuration/overleaf-toolkit/sandboxed-compiles).

</Warning>

### Supporto della community

Per chi usa un'istanza Overleaf self-hosted, il supporto è fornito dalla community tramite le [Issues](https://github.com/ayaka-notes/ayakaleaf-pro/issues) di GitHub.

Per restare su una versione supportata, puoi verificare quale versione di Overleaf stai eseguendo confrontando l'output del comando seguente con gli Image ID pubblicati nelle note di rilascio.

```bash
docker inspect --format '{{.Image}}' sharelatex | awk -F: '{print substr($2, 1, 12)}'
```
