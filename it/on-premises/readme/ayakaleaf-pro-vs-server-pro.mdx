---
title: Overleaf Server Pro vs. Ayakaleaf Pro
description: Overleaf Server Pro e Ayakaleaf Pro Edition sono entrambe versioni on-premises di Overleaf. Ma quali sono le differenze?
icon: scale-balanced
---

<Info>

Ayakaleaf Pro è un'implementazione potenziata di Overleaf Community Edition che offre tutte le funzionalità premium di Server Pro in modo _**gratuito**_. A differenza di Overleaf Common, disponibile su [https://www.overleaf.com/](https://www.overleaf.com/), non abbiamo limiti al tempo di compilazione né requisiti di licenza sul numero di utenti, e puoi ospitare completamente in autonomia i tuoi dati, garantendo la massima sicurezza.

Overleaf Server Pro è un'installazione commerciale e self-hosted di Overleaf, con supporto ufficiale. Per ulteriori informazioni su Server Pro, visita [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud).

</Info>

<Warning>

Overleaf Community Edition è pensata per l'uso in ambienti in cui **tutti** gli utenti sono attendibili. Community Edition **non** è adatta a scenari in cui è richiesto l'isolamento degli utenti, poiché le Sandbox Compiles non sono disponibili.

Senza sandbox, le compilazioni LaTeX vengono eseguite con gli stessi privilegi del container, consentendo l'accesso al suo filesystem, alla rete e alle variabili d'ambiente. Ciò comporta il rischio di esposizione dei dati o di compromissione del sistema. Le compilazioni senza sandbox dovrebbero essere usate solo in ambienti completamente attendibili; per installazioni multiutente o di produzione, le Sandbox Compiles sono fortemente consigliate.

Per ulteriori informazioni sulle Sandbox Compiles, consulta la nostra [documentazione](/it/on-premises/configuration/overleaf-toolkit/sandboxed-compiles).

</Warning>

### Supporto della community

Per chi usa un'istanza self-hosted di Overleaf, il supporto è fornito dalla community tramite le [Issues](https://github.com/ayaka-notes/overleaf-pro/issues) di GitHub.

Per restare su una versione supportata, puoi verificare quale versione di Overleaf stai eseguendo confrontando l'output del comando seguente con gli Image ID pubblicati nelle note di rilascio.

```bash
docker inspect --format '{{.Image}}' sharelatex | awk -F: '{print substr($2, 1, 12)}'
```
