### Panoramica di Overleaf

Overleaf è un editor LaTeX collaborativo amato da ricercatori e team tecnici. La sua versione cloud è disponibile su [overleaf.com](https://www.overleaf.com/) e offre un editor LaTeX online completo. Tuttavia, Overleaf Common (la versione SaaS) presenta numerose limitazioni nelle funzionalità e devi tollerare un _**limite di 10 secondi per la compilazione**_ e costosi abbonamenti.

<Warning>

Overleaf Community Edition è pensata per ambienti in cui **tutti** gli utenti sono attendibili. La Community Edition **non** è adatta a scenari in cui è richiesto l'isolamento degli utenti, perché le Sandbox Compiles non sono disponibili.

Senza sandbox, le compilazioni LaTeX vengono eseguite con gli stessi privilegi del container, consentendo l'accesso al suo filesystem, alla rete e alle variabili d'ambiente. Questo comporta il rischio di esposizione dei dati o di compromissione del sistema. Le compilazioni senza sandbox dovrebbero essere usate solo in ambienti completamente attendibili; per deployment multiutente o di produzione, le Sandbox Compiles sono fortemente consigliate.

Per maggiori informazioni sulle Sandbox Compiles, vedi: [sandboxed-compiles.md](/it/on-premises/configuration/overleaf-toolkit/sandboxed-compiles  "mention")

</Warning>

### Informazioni e prezzi di Overleaf Server Pro

Il sito web di Overleaf offre solo un punto di contatto con l'assistenza per Server Pro, quindi le informazioni su Server Pro sono molto limitate. Tuttavia, in base alle informazioni che abbiamo raccolto nella community, il **preventivo per Server Pro è**:

* Devi acquistare licenze per _almeno_ 10 persone.
* Una licenza per 10 persone costa circa 3.477,61 €. (2024)
* Per l'istruzione, 20 utenti costano 2640 euro all'anno, 50 utenti 6050 euro e 100 utenti 9963 euro.
* Server Pro è disponibile solo in alcune regioni (ad esempio, esclusa la Cina continentale).

In base alle informazioni attualmente disponibili, Overleaf Server Pro sembra costare circa \$300 per utente all'anno, con un acquisto minimo di 10 licenze, il che lo rende un'opzione molto costosa. Inoltre, Server Pro offre molte meno funzionalità di Ayakaleaf Pro. Siamo profondamente grati agli sviluppatori della community, i cui contributi nel corso degli anni ci hanno permesso di creare Ayakaleaf Pro e, infine, di superare Overleaf Server Pro sia in funzionalità sia in capacità.

I seguenti documenti pubblici mostrano acquisti e prezzi documentati di Overleaf Server Pro. I contratti statunitensi più piccoli indicano costi annuali di circa \$320–\$370 per utente. I grandi accordi istituzionali possono ottenere prezzi per utente più bassi: ad esempio, l'accordo triennale della Max Planck Society corrisponde in media a circa 51 € per utente all'anno. Le condizioni contrattuali, l'assistenza e l'ambito del deployment possono variare. Questi documenti non costituiscono un listino prezzi ufficiale di Overleaf.

### Perché Ayakaleaf Pro?

<Info>

Ayakaleaf Pro _**non**_ è affiliato con Overleaf, Inc. né con la sua società madre, Digital Science. Non è nemmeno l'edizione _Server Pro_, che è un prodotto commerciale offerto da Overleaf, Inc. [ayaka-notes](https://github.com/ayaka-notes) sviluppa e mantiene Ayakaleaf Pro come progetto indipendente.

</Info>

Ayakaleaf Pro è un'implementazione potenziata di Overleaf Community Edition che offre _**tutte**_ le funzionalità _**premium gratuitamente**_ di Server Pro. A differenza di Overleaf Common, disponibile su [https://www.overleaf.com/](https://www.overleaf.com/), o dell'edizione commerciale Server Pro, abbiamo:

* _**nessuna limitazione**_ sul tempo di compilazione
* _**nessun requisito di licenza**_ sul numero di utenti
* _**tutte le funzionalità**_ di Server Pro sbloccate
