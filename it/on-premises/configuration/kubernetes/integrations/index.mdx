title: Integrazioni

---

Ogni integrazione è disattivata per impostazione predefinita, tranne la Overleaf Import API. Le sincronizzazioni con GitHub, GitLab, Gitea e Dropbox e il server MCP richiedono anche l'[integrazione Git](/it/on-premises/configuration/kubernetes/integrations/git-integration). Dopo averne attivata una nella ConfigMap o nel Secret, riavvia le repliche con `kubectl -n overleaf rollout restart`.
