---
title: Restrizioni sulle password
description: Impostare la lunghezza minima e massima delle password locali in un deployment Kubernetes.
icon: key
---

Il servizio **web** verifica le password locali quando gli utenti si registrano, impostano o modificano una password. Gli accessi SSO (LDAP, SAML, OIDC) non sono interessati; le loro password sono di competenza dell'identity provider. Vedi [Restrizioni sulle password](/it/on-premises/configuration/overleaf-toolkit/authentication/password-restrictions) per il Toolkit.

| | |
| --- | --- |
| Servizio | web, in ogni pod di Ayakaleaf Pro; letto all'avvio di web |
| Rete | nessuna |
| Job periodici | nessuno |

### Configurazione

Aggiungi alla ConfigMap `overleaf-env` e riavvia:

```yaml title="30-config.yaml (additions)"
  OVERLEAF_PASSWORD_VALIDATION_MIN_LENGTH: "12"
  OVERLEAF_PASSWORD_VALIDATION_MAX_LENGTH: "72"
```

```bash
kubectl apply -f 30-config.yaml
kubectl -n overleaf rollout restart deployment/overleaf     # or statefulset/overleaf
```

| Variabile | Predefinito | |
| --- | --- | --- |
| `OVERLEAF_PASSWORD_VALIDATION_MIN_LENGTH` | `8` | Password più corta accettata. |
| `OVERLEAF_PASSWORD_VALIDATION_MAX_LENGTH` | `72` | Password più lunga accettata; i valori superiori a `72` vengono trattati come `72`. |

Metti i numeri tra virgolette: una ConfigMap contiene solo stringhe.

<Warning>

`OVERLEAF_PASSWORD_VALIDATION_PATTERN` viene letto ma non applicato: una password che non vi corrisponde viene accettata. Si applicano solo i limiti di lunghezza.

</Warning>

### Più repliche

Non serve altro: ogni replica legge la stessa ConfigMap.

### Testato su Kubernetes

Su Kubernetes 1.37 con una replica, con `OVERLEAF_PASSWORD_VALIDATION_MIN_LENGTH: "12"` e `OVERLEAF_PASSWORD_VALIDATION_PATTERN: aA$3` nella ConfigMap, l'attivazione di un nuovo account ha rifiutato una password di 10 caratteri e ha accettato una password di 20 caratteri composta solo da lettere minuscole, che il pattern avrebbe rifiutato. Anche i nostri test end-to-end per la registrazione rifiutano `123456` come troppo corta con i valori predefiniti.
