---
title: Aggiungere la guida LaTeX per gli utenti
icon: graduation-cap
---

Puoi abilitare l'accesso alle pagine [Learn](https://www.overleaf.com/learn) di Overleaf all'interno della tua istanza Overleaf Pro semplicemente aggiungendo `OVERLEAF_PROXY_LEARN=true` al file `config/variables.env` del Toolkit ed eseguendo il comando `bin/up`.

In questo modo gli utenti possono consultare la documentazione e le risorse di apprendimento aggiornate facendo clic sul pulsante **Documentation** nel menu di navigazione, senza lasciare la tua istanza.

<Info>

Per impostazione predefinita solo gli utenti che hanno effettuato l'accesso possono aprire `/learn`. Per renderlo disponibile anche ai visitatori non autenticati, imposta anche `OVERLEAF_ALLOW_PUBLIC_ACCESS=true`; vedi [Page Access](/it/on-premises/configuration/overleaf-toolkit/public-access#page-access  "mention").

</Info>

<Info>

Per le installazioni con Docker Compose, è necessario aggiungere la variabile d'ambiente `OVERLEAF_PROXY_LEARN: true` alla sezione **environment** del servizio `sharelatex` nel file `docker-compose.yml`.

</Info>

<Info>

La tua installazione di Server Pro avrà bisogno dell'accesso a Internet per poter eseguire richieste `GET` esterne verso [https://learn.sharelatex.com](https://docs.overleaf.com/on-premises/welcome).

</Info>

<Danger>

Quando abiliti questa opzione per la prima volta e riavvii il container Docker di Overleaf, il sistema deve scaricare la Wiki corrispondente, operazione che può richiedere 5 minuti o più. Solo al termine del download potrai visualizzare correttamente la pagina di accesso di Overleaf.

</Danger>
