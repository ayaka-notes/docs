### Funzionalità "Overleaf Import API"

A partire da Ayakaleaf Pro v6.3, puoi creare link che importano un file LaTeX o un progetto compresso in formato zip da un URL e lo aprono nella tua istanza Ayakaleaf, in modo simile all'[API “Open in Overleaf”](https://cn.overleaf.com/devs) di Overleaf.

Questa funzionalità è abilitata per impostazione predefinita: devi solo visitare `your.overleaf.com/devs` per vedere la pagina dettagliata e le istruzioni.

<Info>

La pagina `/devs` richiede l'accesso a meno che non sia impostato `OVERLEAF_ALLOW_PUBLIC_ACCESS=true`; consulta [Visitatori non autenticati](/it/on-premises/configuration/overleaf-toolkit/overleaf-import-api#signed-out-visitors  "mention").

</Info>

Ad esempio, se ospiti un file LaTeX all'indirizzo `https://example.com/main.tex` o un progetto completo all'indirizzo `https://example.com/project.zip`, puoi creare un link che lo importa nella tua istanza Ayakaleaf Pro e apre il nuovo progetto:

<Tabs>
<Tab title="File LaTeX">

```text wrap
https://ayakaleaf.example.com/docs?snip_uri=https%3A%2F%2Fexample.com%2Fmain.tex
```

</Tab>

<Tab title="Progetto ZIP">

```text wrap
https://ayakaleaf.example.com/docs?snip_uri=https%3A%2F%2Fexample.com%2Fproject.zip
```

</Tab>
</Tabs>

Sostituisci `ayakaleaf.example.com` con il dominio della tua istanza.

#### Aprire un progetto LaTeX in Ayakaleaf Pro

A partire da Ayakaleaf Pro v6.3, puoi creare un link che importa un file LaTeX o un progetto zip nella tua istanza Ayakaleaf Pro. Quando qualcuno apre il link, Ayakaleaf Pro crea un nuovo progetto a partire dal file fornito e lo apre nell'editor.

Indirizza il link all'endpoint `/docs` della tua istanza:

| Parametro       | Descrizione | Esempio |
| --------------- | ----------- | ------- |
| `snip_uri`      | URL di un file LaTeX da importare. È accettato anche un singolo file ZIP, ma per i progetti usa `zip_uri`. | `https://example.com/main.tex`                    |
| `zip_uri`       | URL di un progetto LaTeX compresso in zip da importare. | `https://example.com/project.zip`                 |
| `snip_uri[]`    | Importa più file ripetendo questo parametro. | `snip_uri[]=.../main.tex&snip_uri[]=.../refs.bib` |
| `snip_name[]`   | Imposta il nome file per ciascun `snip_uri[]`, nello stesso ordine. | `snip_name[]=main.tex`                            |
| `engine`        | Imposta il compilatore: `latex_dvipdf`, `pdflatex`, `xelatex` o `lualatex`. | `engine=xelatex`                                  |
| `main_document` | Imposta il file `.tex` principale nel progetto importato. | `main_document=main.tex`                          |
| `name`          | Imposta il nome del nuovo progetto. È accettato anche `project_name`. | `name=My%20Project`                               |

Ad esempio, se i tuoi file sono ospitati su `example.com`, questi link li importano in un'istanza Ayakaleaf Pro ospitata su `ayakaleaf.example.com` .

#### Importare un progetto tramite Base64

Puoi incorporare un file LaTeX o un progetto zip direttamente in un link “Open in Ayakaleaf” come data URL Base64. In questo modo puoi creare un link di importazione senza ospitare il file a un URL separato.

| Contenuto      | Parametro  | Formato del data URL |
| -------------- | ---------- | -------------------- |
| File LaTeX     | `snip_uri` | `data:application/x-tex;base64,<base64-encoded-tex>` |
| Progetto zip   | `zip_uri`  | `data:application/zip;base64,<base64-encoded-zip>`   |

Per importare un progetto ZIP, codifica in Base64 il file ZIP e passalo invece tramite `zip_uri`. Usa `encodeURIComponent` sull'intero data URL quando costruisci uno dei due link. Per i progetti di grandi dimensioni, usa un URL ZIP ospitato, perché i limiti di lunghezza degli URL di browser e server possono rendere poco pratici i link Base64.

#### Aggiungere un pulsante “Open in Ayakaleaf”

Puoi usare un modulo HTML per importare un file quando un visitatore fa clic su un pulsante. Invia il modulo all'endpoint `/docs` della tua istanza con `method="post"`.

Per un file LaTeX ospitato:

```text
<form action="https://ayakaleaf.example.com/docs" method="post" target="_blank">
  <input type="hidden" name="snip_uri" value="https://example.com/main.tex">
  <input type="hidden" name="engine" value="xelatex">
  <button type="submit">Open in Ayakaleaf</button>
</form>
```

Per importare un progetto zip, sostituisci `snip_uri` con `zip_uri` e fallo puntare al file ZIP. Puoi anche inviare direttamente il sorgente LaTeX usando `snip` per il testo grezzo oppure `encoded_snip` per il testo codificato come URL.

Sostituisci `ayakaleaf.example.com` con il dominio della tua istanza. Se la tua istanza abilita il blocco delle richieste cross-origin, aggiungi il sito web che ospita il modulo ad `ALLOWED_ORIGINS`.

#### Visitatori non autenticati

Il nuovo progetto viene creato nell'account del visitatore, che quindi deve effettuare l'accesso. Il percorso seguito da un visitatore non autenticato dipende da come viene inviata l'importazione:

* I **link** (`GET /docs?...`) funzionano su qualsiasi istanza: il visitatore viene indirizzato alla pagina di accesso e l'importazione prosegue dopo il login.
* I **moduli** (`POST /docs`) richiedono `OVERLEAF_ALLOW_PUBLIC_ACCESS=true` per i visitatori non autenticati. In tal caso l'invio viene conservato per 10 minuti finché il visitatore non ha effettuato l'accesso, e viene utilizzato una sola volta.

<Warning>

Per impostazione predefinita (`OVERLEAF_ALLOW_PUBLIC_ACCESS` non impostato), un modulo inviato da un visitatore non autenticato viene indirizzato alla pagina di accesso prima che Ayakaleaf Pro lo legga, e l'invio va perso: dopo l'accesso, il visitatore vede _no snippet, snip\_uri or zip\_uri provided_. Usa i link, chiedi ai visitatori di accedere prima oppure abilita l'accesso pubblico; consulta [Accesso alle pagine](/it/on-premises/configuration/overleaf-toolkit/public-access#page-access  "mention").

</Warning>

<Accordion title="Quali risorse ZIP o TeX posso importare?">

Ayakaleaf Pro utilizza il microservizio `linked-url-proxy` (usato principalmente per [external-url.md](/it/on-premises/configuration/overleaf-toolkit/external-url  "mention")) per recuperare le risorse esterne. In generale, è possibile importare qualsiasi risorsa ZIP o TeX accessibile pubblicamente su Internet. Le risorse ospitate su reti private o interne vengono bloccate per motivi di sicurezza.

A partire dalla nuova release di Ayakaleaf Pro 6.3.0 (3 ottobre 2026), puoi configurare un proxy HTTP(S) per il recupero delle risorse ZIP e TeX esterne con `OVERLEAF_LINKED_URL_OUTBOUND_PROXY`. Consulta [Proxy in uscita](/it/on-premises/configuration/overleaf-toolkit/external-url#outbound-proxy  "mention") per la configurazione e le restrizioni di accesso alla rete.

</Accordion>
