Overleaf supporta l'invio di email tramite due metodi: Simple Mail Transfer Protocol (SMTP) e [Amazon Simple Email Service (SES)](https://aws.amazon.com/ses/). SMTP può essere usato se sul tuo localhost è attivo un server email in ascolto per le connessioni locali.

## Configurazione

L'email si configura tramite le seguenti variabili d'ambiente.

#### Configurazione del mittente

| Nome                          | Descrizione                                                                                                                                          |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | <p>L'indirizzo del mittente, ad es. <a href="mailto:support@mycompany.com">`'support@mycompany.com'`</a><br /><br />- <strong>Obbligatorio</strong>: sì</p> |
| `OVERLEAF_EMAIL_REPLY_TO`     | L'indirizzo di risposta, ad es. `'noreply@mycompany.com'`                                                                                                  |

#### SMTP

| Nome                                    | Descrizione                                                                                                                                                                                                                                                              |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST`              | Il nome host o l'indirizzo IP a cui connettersi. Deve essere raggiungibile dal container Docker                                                                                                                                                                               |
| `OVERLEAF_EMAIL_SMTP_PORT`              | La porta a cui connettersi                                                                                                                                                                                                                                                   |
| `OVERLEAF_EMAIL_SMTP_SECURE`            | Se `true`, la connessione al server userà TLS. Se `false` o non impostato, TLS viene usato se il server supporta l'estensione `STARTTLS`. Nella maggior parte dei casi imposta questo valore a `true` se ti connetti alla porta `465`. Per le porte `587` o `25` lascialo a `false` |
| `OVERLEAF_EMAIL_SMTP_USER`              | Il nome utente da usare per l'autenticazione sul server SMTP                                                                                                                                                                 |
| `OVERLEAF_EMAIL_SMTP_PASS`              | La password associata al nome utente SMTP                                                                                                                                                                                                                           |
| `OVERLEAF_EMAIL_SMTP_TLS_REJECT_UNAUTH` | Se `false`, consente di aprire una connessione a un server TLS con certificato TLS autofirmato o non valido                                                                                                                                                                        |
| `OVERLEAF_EMAIL_SMTP_IGNORE_TLS`        | Se `true` e `OVERLEAF_EMAIL_SMTP_SECURE` è `false`, TLS non viene usato anche se il server supporta l'estensione `STARTTLS`                                                                                                                                            |
| `OVERLEAF_EMAIL_SMTP_NAME`              | Nome host facoltativo per la convalida TLS se `OVERLEAF_EMAIL_SMTP_HOST` è impostato su un indirizzo IP; il valore predefinito è il nome host della macchina.                                                                                                                                        |
| `OVERLEAF_EMAIL_SMTP_LOGGER`            | Se `true`, stampa i messaggi di log in `web.log`.                                                                                                                                                                                                                        |

#### Interfaccia SMTP di Amazon SES

Puoi leggere di più sull'uso dell'interfaccia SMTP di Amazon SES per l'invio di email [qui](https://docs.aws.amazon.com/ses/latest/dg/send-email-smtp.html).

| Nome                       | Descrizione                                                                                |
| -------------------------- | ------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST` | Il nome host o l'indirizzo IP a cui connettersi. Deve essere raggiungibile dal container Docker |
| `OVERLEAF_EMAIL_SMTP_PORT` | La porta a cui connettersi                                                                     |
| `OVERLEAF_EMAIL_SMTP_USER` | Il nome utente da usare per l'autenticazione sul server SMTP                   |
| `OVERLEAF_EMAIL_SMTP_PASS` | La password associata al nome utente SMTP                                             |

#### API di Amazon SES

Puoi leggere di più sull'uso dell'API di Amazon SES per l'invio di email [qui](https://docs.aws.amazon.com/ses/latest/dg/send-email-api.html).

| Nome                                   | Descrizione                                 |
| -------------------------------------- | ------------------------------------------- |
| `OVERLEAF_EMAIL_AWS_SES_ACCESS_KEY_ID` | La access key, se si usa AWS SES             |
| `OVERLEAF_EMAIL_AWS_SES_SECRET_KEY`    | La secret key, se si usa AWS SES             |
| `OVERLEAF_EMAIL_AWS_SES_REGION`        | Se non impostata, la regione predefinita è US-EAST-1 |

#### AWS SES con ruoli dell'istanza

| Nome                    | Descrizione                                                                                                                      |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_DRIVER` | Se impostata su `ses`, il sistema email userà il metodo API di SES e si affiderà ai ruoli dell'istanza configurati per inviare le email. |

#### Personalizzazione

| Nome                           | Descrizione                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_CUSTOM_EMAIL_FOOTER` | <p>HTML personalizzato aggiunto in fondo a tutte le email, ad es.<br /><br /><strong>Esempio</strong>: `"<div>This system is run by department x </div> <div> If you have any questions please look at our faq <a href='`<a href="https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/https:/somwhere.com'%3Ehere&#x3C;/a%3E&#x3C;/div%3E">`https://somwhere.com'>here&#x3C;/a>&#x3C;/div>`</a>`"`</p> |
