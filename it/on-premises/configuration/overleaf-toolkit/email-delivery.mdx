Overleaf supporta l'invio di email tramite due metodi: Simple Mail Transfer Protocol (SMTP) e [Amazon Simple Email Service (SES)](https://aws.amazon.com/ses/). SMTP può essere usato se sul tuo localhost è attivo un server email in ascolto di connessioni locali.

## Più indirizzi email per account {#several-emails-per-account}

<Info>

Questa funzionalità è sviluppata da [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) ed è disponibile dalla v6.4.0.

</Info>

Con l'email configurata, la pagina delle impostazioni elenca gli indirizzi email di un account al posto del campo email singolo. Gli utenti aggiungono un indirizzo email inserendo un codice di 6 cifre inviato a quell'indirizzo e premono **Make primary** per spostare il proprio account su di esso. È così che qualcuno mantiene il proprio account quando un indirizzo gli verrà tolto, come quello di un'università dopo la laurea. La [guida utente](/it/on-premises/user-guide/users/multiple-emails) riporta i passaggi con screenshot.

* Solo l'indirizzo email principale consente l'accesso e riceve i reset della password. Un indirizzo email secondario non fa né l'una né l'altra cosa, quindi un indirizzo riassegnato a qualcun altro non può impossessarsi dell'account.
* Premi **Make primary** prima che la vecchia casella di posta venga chiusa. Dopo, un amministratore dovrà cambiare l'indirizzo email in **Admin → Manage Users**.
* Un vecchio indirizzo email principale mai confermato viene rimosso quando un altro indirizzo diventa principale. Uno confermato resta come indirizzo email secondario finché l'utente non lo rimuove.
* **Make primary** viene rifiutato quando LDAP o SAML è abilitato, perché questi account non potrebbero accedere con il nuovo indirizzo email. Consulta [Account e password](/it/on-premises/configuration/overleaf-toolkit/authentication#accounts-and-passwords).
* Senza le impostazioni email resta il campo email singolo.

## Configurazione {#configuration}

L'email si configura tramite le seguenti variabili d'ambiente.

#### Configurazione del mittente {#sender-configuration}

| Nome                          | Descrizione                                                                                                                                          |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | <p>L'indirizzo del mittente, ad es. <a href="mailto:support@mycompany.com">`'support@mycompany.com'`</a><br /><br />- <strong>Obbligatorio</strong>: sì</p> |
| `OVERLEAF_EMAIL_REPLY_TO`     | L'indirizzo di risposta, ad es. `'noreply@mycompany.com'`                                                                                            |

#### SMTP {#smtp}

| Nome                                    | Descrizione                                                                                                                                                                                                                                                              |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST`              | Il nome host o l'indirizzo IP a cui connettersi. Deve essere raggiungibile dal container Docker                                                                                                                                                                          |
| `OVERLEAF_EMAIL_SMTP_PORT`              | La porta a cui connettersi                                                                                                                                                                                                                                               |
| `OVERLEAF_EMAIL_SMTP_SECURE`            | Se `true`, la connessione al server userà TLS. Se `false` o non impostato, TLS viene usato se il server supporta l'estensione `STARTTLS`. Nella maggior parte dei casi imposta questo valore su `true` se ti connetti alla porta `465`. Per le porte `587` o `25` lascialo su `false` |
| `OVERLEAF_EMAIL_SMTP_USER`              | Il nome utente da usare per l'autenticazione sul server SMTP                                                                                                                                                                                                             |
| `OVERLEAF_EMAIL_SMTP_PASS`              | La password associata al nome utente SMTP                                                                                                                                                                                                                                |
| `OVERLEAF_EMAIL_SMTP_TLS_REJECT_UNAUTH` | Se `false`, consente di aprire una connessione a un server TLS con un certificato TLS autofirmato o non valido                                                                                                                                                            |
| `OVERLEAF_EMAIL_SMTP_IGNORE_TLS`        | Quando è `true` e `OVERLEAF_EMAIL_SMTP_SECURE` è `false`, TLS non viene usato anche se il server supporta l'estensione `STARTTLS`                                                                                                                                         |
| `OVERLEAF_EMAIL_SMTP_NAME`              | Nome host facoltativo per la validazione TLS se `OVERLEAF_EMAIL_SMTP_HOST` è impostato su un indirizzo IP; il valore predefinito è il nome host della macchina.                                                                                                          |
| `OVERLEAF_EMAIL_SMTP_LOGGER`            | Quando è `true`, scrive i messaggi di log in `web.log`.                                                                                                                                                                                                                  |

#### Interfaccia SMTP di Amazon SES {#amazon-ses-smtp-interface}

Puoi leggere di più sull'uso dell'interfaccia SMTP di Amazon SES per inviare email [qui](https://docs.aws.amazon.com/ses/latest/dg/send-email-smtp.html).

| Nome                       | Descrizione                                                                                |
| -------------------------- | ------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST` | Il nome host o l'indirizzo IP a cui connettersi. Deve essere raggiungibile dal container Docker |
| `OVERLEAF_EMAIL_SMTP_PORT` | La porta a cui connettersi                                                                 |
| `OVERLEAF_EMAIL_SMTP_USER` | Il nome utente da usare per l'autenticazione sul server SMTP                               |
| `OVERLEAF_EMAIL_SMTP_PASS` | La password associata al nome utente SMTP                                                  |

#### API di Amazon SES {#amazon-ses-api}

Puoi leggere di più sull'uso dell'API di Amazon SES per inviare email [qui](https://docs.aws.amazon.com/ses/latest/dg/send-email-api.html).

| Nome                                   | Descrizione                                 |
| -------------------------------------- | ------------------------------------------- |
| `OVERLEAF_EMAIL_AWS_SES_ACCESS_KEY_ID` | La chiave di accesso, se usi AWS SES        |
| `OVERLEAF_EMAIL_AWS_SES_SECRET_KEY`    | La chiave segreta, se usi AWS SES           |
| `OVERLEAF_EMAIL_AWS_SES_REGION`        | Se non impostata, la regione predefinita è US-EAST-1 |

#### AWS SES con ruoli di istanza {#aws-ses-with-instance-roles}

| Nome                    | Descrizione                                                                                                                      |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_DRIVER` | Quando è impostato su `ses`, il sistema email userà il metodo API di SES e si affiderà ai ruoli di istanza configurati per inviare le email. |

#### Personalizzazione {#customisation}

| Nome                           | Descrizione                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_CUSTOM_EMAIL_FOOTER` | <p>HTML personalizzato che viene aggiunto in fondo a tutte le email, ad es.<br /><br /><strong>Esempio</strong>: `"<div>This system is run by department x </div> <div> If you have any questions please look at our faq <a href='https://somwhere.com'>here</a></div>"`</p> |
