---
title: Restrizioni sulle password
icon: key
---

È possibile imporre restrizioni sulle password degli account utente quando si utilizza il sistema di accesso nativo di Overleaf per l'autenticazione.

<Info>

**Non** è possibile imporre restrizioni sulle password per gli accessi SSO (LDAP/SAML 2.0). Queste devono essere configurate nel tuo Identity Provider (IdP).

</Info>

Per abilitare le restrizioni sulle password, imposta le relative variabili d'ambiente nel file `config/variables.env` del Toolkit.

| Nome                                      | Descrizione                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | Predefinito |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------: |
| `OVERLEAF_PASSWORD_VALIDATION_MIN_LENGTH` | La lunghezza **minima** richiesta.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |     `8` |
| `OVERLEAF_PASSWORD_VALIDATION_MAX_LENGTH` | La lunghezza **massima** consentita.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |    `72` |
| `OVERLEAF_PASSWORD_VALIDATION_PATTERN`    | <p>Usato per convalidare la <strong>robustezza</strong> della password:</p><ul><li>`abc123` – la password deve contenere 3 lettere e 3 cifre ed essere lunga almeno 6 caratteri</li><li>`aA` – la password deve contenere lettere minuscole e maiuscole ed essere lunga 2 caratteri</li><li>`ab$3` – deve contenere lettere, cifre e simboli ed essere lunga 4 caratteri</li><li>Esistono 4 gruppi di caratteri: lettere, lettere MAIUSCOLE, cifre, simboli. Tutto ciò che non è né una lettera né una cifra è considerato un simbolo.</li></ul> |       — |
