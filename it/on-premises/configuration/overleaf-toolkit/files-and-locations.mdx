Questa pagina descrive i file di configurazione usati dal Toolkit per configurare la tua installazione on-premises di Overleaf.

### Dati persistenti

L'Overleaf Toolkit deve memorizzare dati persistenti, come i file necessari per compilare i progetti LaTeX e il contenuto del database MongoDB. Ciò avviene montando alcune directory della macchina host nei container Docker e scrivendo i dati in tali directory.

#### Directory dei dati

Il container `sharelatex` richiede una directory in cui memorizzare i dati relativi alle compilazioni LaTeX. Questa directory viene impostata con la variabile `OVERLEAF_DATA_PATH` in `config/overleaf.rc`.

Il container `mongo`, se abilitato, richiede una directory in cui memorizzare i file del database, e lo stesso vale per il container `redis`. Anche queste directory possono essere configurate in `config/overleaf.rc`.

#### Permessi dei file

Poiché Docker viene eseguito come `root`, le directory dei dati finiranno per appartenere all'utente `root`, anche se il Toolkit viene usato da un utente non root. Non è un problema, ma è bene saperlo se intendi modificare i dati persistenti dall'esterno dei container.

### Posizione dei file di configurazione

Tutti i file di configurazione di proprietà dell'utente si trovano nella directory `config/`.

Questa directory è **esclusa** dal sistema di controllo versione git, quindi non verrà modificata dall'aggiornamento del codice del Toolkit. Il Toolkit **non** modificherà alcun dato nella directory `config/` senza il tuo permesso.

<Info>

Le modifiche ai file di configurazione non vengono applicate automaticamente ai container esistenti, nemmeno se il container viene arrestato e riavviato (con `bin/stop` e `bin/start`). Per applicare le modifiche, esegui `bin/up`: dietro le quinte, `docker compose` applicherà automaticamente le modifiche di configurazione a un nuovo container. (Oppure esegui `bin/up -d` se preferisci non collegarti ai log di Docker.)

</Info>

### Il file `overleaf.rc`

Il file `config/overleaf.rc` contiene le impostazioni di configurazione di primo livello più importanti usate dal Toolkit. Contiene istruzioni che impostano variabili nel formato: `VARIABLE_NAME=value`

Per una panoramica di tutte le opzioni di configurazione disponibili, consulta la nostra sezione sulle impostazioni.

### Il file `variables.env`

Il file `config/variables.env` contiene le variabili d'ambiente che vengono caricate nel container `sharelatex` e usate per configurare i microservizi di Overleaf. Tra queste ci sono il nome dell'applicazione, mostrato nell'intestazione dell'interfaccia web, le impostazioni per l'invio delle email e altre impostazioni premium come l'SSO da usare con Server Pro.

Per una panoramica di tutte le variabili d'ambiente disponibili, consulta la sezione [Variabili d'ambiente](/it/on-premises/configuration/overleaf-toolkit/environment-variables).

### Il file `version`

Il file `config/version` contiene il numero di versione dell'immagine Docker che verrà usata per creare l'istanza in esecuzione del tuo server Overleaf.

<Info>

Le modifiche a questi file di configurazione non vengono applicate automaticamente ai container esistenti, nemmeno se il container viene arrestato e riavviato (con `bin/stop` e `bin/start`). Per applicare le modifiche, esegui `bin/up` e il Toolkit creerà automaticamente un nuovo container con le modifiche di configurazione applicate.

</Info>

### Il file `docker-compose.override.yml`

Se presente, il file `config/docker-compose.override.yml` verrà incluso nell'invocazione di `docker compose`. È utile per sovrascrivere configurazioni specifiche di Docker Compose.

Per maggiori dettagli, consulta la [documentazione di docker-compose](https://docs.docker.com/compose/extends/#adding-and-overriding-configuration).
