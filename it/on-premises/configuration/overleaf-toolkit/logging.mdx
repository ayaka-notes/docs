Puoi usare lo script `bin/logs` per visualizzare i log dei servizi.

Esempi di utilizzo di base:

```bash
# View the web service logs
bin/logs web

# Show help
bin/logs --help

# View logs for multiple services at once
bin/logs filestore docstore web clsi

# Follow log output (like tail -f)
bin/logs -f filestore docstore web clsi

# Limit the number of lines printed (default 50)
bin/logs -n 50 web

# Show all log lines
bin/logs -n all web

# Redirect output to a file
bin/logs -n all web > web.log
```

Puoi usare lo script `bin/logs` per visualizzare i log dei seguenti servizi: `clsi`, `contacts`, `docstore`, `document-updater`, `filestore`, `git-bridge`, `mongo`, `notifications`, `real-time`, `redis`, `spelling`, `tags`, `track-changes`, `web`, `web-api`, `history-v1`, `project-history`.

## Copiare i log

Consulta la documentazione originale: https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/logging#copying-logs

Copia i file di log dal container principale `sharelatex` al tuo computer locale:

```bash
docker cp sharelatex:/var/log/overleaf/{service-name}.log {service-name}.log
```

## Rendere persistenti i log

I container Docker sono effimeri, il che significa che i file e le directory creati all'interno del container durante l'esecuzione (inclusi i file di log) verranno eliminati se il container viene ricreato (ad esempio, eseguendo `bin/up`). Per conservare i file di log tra una ricreazione e l'altra del container:

* Imposta la variabile d'ambiente `OVERLEAF_LOG_PATH` nel file `config/overleaf.rc` usato dal Toolkit. Deve essere la directory sull'host che verrà montata in bind sulla directory dei log all'interno del container `sharelatex`.
* Dopo aver modificato questa impostazione ed eseguito `bin/up -d`, i file di log verranno resi persistenti sull'host e saranno accessibili direttamente.

<Warning>

Devi impostare come proprietario della directory dei log sull'host usata per il bind mount l'utente `www-data` (uid=33) e assicurarti che i permessi siano `drwxr-xr-x` (755).

Esempio:

```bash
chown 33:33 data/overleaf/logs
chmod 755 data/overleaf/logs
```

</Warning>
