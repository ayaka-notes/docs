Ogni integrazione è disattivata per impostazione predefinita, tranne la Overleaf Import API. La sincronizzazione con GitHub, GitLab, Gitea e Dropbox e il server MCP richiedono anche l'[integrazione Git](/it/on-premises/configuration/overleaf-toolkit/integrations/git-integration). Dopo averne attivata una, ricrea i container con `bin/up -d`.
