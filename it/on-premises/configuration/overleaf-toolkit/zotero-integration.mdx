### Configurare l'integrazione con Zotero

1. Apri [questo link](https://www.zotero.org/oauth/apps) per creare un client OAuth di Zotero (come mostrato nell'immagine)
2. Scegli **Application Type**: **Browser**
3. Imposta il Callback URL con il tuo `${OVERLEAF_SITE_URL}/user/zotero/oauth/callback`
4. Configura il tuo `config/variables.env`

<Frame>
  <img src="/images/on-premises/image-41.png" alt="" width="375" />
</Frame>

```dotenv title="config/variables.env"
#################
#    Zotero     #
#################
# 'zotero' must be in ENABLED_LINKED_FILE_TYPES (set in develop/docker-compose.yml)
ENABLED_LINKED_FILE_TYPES=project_file,project_output_file,url,zotero

# From a Zotero OAuth client (register at https://www.zotero.org/oauth/apps)
# Application Type: Browser 
# Callback URL -> ${OVERLEAF_SITE_URL}/user/zotero/oauth/callback
ZOTERO_CLIENT_ID=
ZOTERO_CLIENT_SECRET=
# Encrypts the Zotero API key in mongo (set in dev to avoid writing a key file
# to /var/lib/overleaf/data, which the dev web container can't create)
# How to generate: `openssl rand -hex 32`
ZOTERO_CIPHER_PASSWORD=dev-zotero-cipher-password
# Optional: route the module's server-side Zotero requests (OAuth + API) through
# an HTTP proxy (must be reachable from the web container; same as github-sync)
# http://10.0.0.1:10808
# (Optional) ZOTERO_PROXY_URL=
```

### Note

<Warning>

Quando aggiorni un'installazione esistente che contiene file di bibliografia collegati a Zotero alla versione 6.3.0 ripubblicata, segui le [istruzioni di migrazione per Zotero / Mendeley](/it/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention"). Le nuove installazioni non necessitano di questa migrazione.

</Warning>

<Danger>

Poiché Ayakaleaf è una piattaforma collaborativa, per migliorare la sicurezza, a partire dalla versione 6.3.0 solo il creatore originale di un file `bib` di riferimenti potrà aggiornare il file importato.

</Danger>

Ad esempio, supponiamo che il proprietario del progetto, l'Utente A, abiliti la condivisione tramite link e crei nel progetto un file `test.bib` collegandolo al proprio account Zotero. Se un altro utente, l'Utente B, accede al progetto tramite il link condiviso, l'Utente B potrà comunque leggere e scaricare `test.bib`, ma non potrà aggiornare né reimportare il file da Zotero. Solo l'Utente A, in quanto creatore originale del file di riferimenti, può eseguire gli aggiornamenti. In altre parole, solo il creatore originale del file `.bib` ha il permesso di aggiornarlo.
