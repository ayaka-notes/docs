### Intestazione

In questa sezione vedremo come personalizzare gli elementi principali della tua istanza on-premises. Puoi personalizzare il titolo del sito, i link di navigazione, l'intestazione, il piè di pagina e il logo secondo le tue preferenze.

### Titolo del sito

Il titolo della barra di navigazione può essere personalizzato con la variabile d'ambiente `OVERLEAF_NAV_TITLE`; questo testo viene mostrato nell'angolo in alto a sinistra della navigazione se non è impostato alcun logo.

```bash
# add to config/variables.env
OVERLEAF_NAV_TITLE=Our Overleaf Instance
```

## Logo

Puoi aggiungere un logo personalizzato al posto del testo impostando la variabile d'ambiente `OVERLEAF_HEADER_IMAGE_URL`. Questo valore deve puntare a un file immagine ospitato esternamente.

```bash title="config/variables.env"
# add to config/variables.env
OVERLEAF_HEADER_IMAGE_URL=https://mysite.somewhere.com/img/logo.png
```

#### Logo per tema chiaro e scuro

A partire dalla versione 6.3.0, puoi impostare loghi distinti per il tema chiaro e quello scuro con le variabili d'ambiente `OVERLEAF_HEADER_IMAGE_URL_LIGHT` e `OVERLEAF_HEADER_IMAGE_URL_DARK`. Entrambi i valori devono puntare a un file immagine ospitato esternamente.

```text
# add to config/variables.env
OVERLEAF_HEADER_IMAGE_URL_LIGHT=https://mysite.somewhere.com/img/logo-light.png
OVERLEAF_HEADER_IMAGE_URL_DARK=https://mysite.somewhere.com/img/logo-dark.png
```

<Info>

Se una delle due variabili non è impostata, quel tema utilizza come ripiego il logo impostato in `OVERLEAF_HEADER_IMAGE_URL`.

</Info>

## Link di navigazione nell'intestazione

È possibile aggiungere voci di navigazione extra all'intestazione impostando la variabile d'ambiente `OVERLEAF_HEADER_EXTRAS` su un array JSON di oggetti. Ad esempio:

```json wrap
[\
  {\
    "text": "Some link",\
    "url": "http://example.com/somelink",\
    "class": "subdued",\
    "only_when_logged_out": true\
  },\
  {\
    "text": "Help",\
    "class": "subdued",\
    "dropdown": [\
      {\
        "text": "Documentation",\
        "url": "/learn"\
      },\
      {\
        "text": "Contact Admin",\
        "url": "http://example.com/contact"\
      }\
    ]\
  }\
]
```

Aggiungi la forma JSON con escape a toolkit/variables.env:

```bash title="toolkit/variables.env" wrap
# add to toolkit/variables.env
OVERLEAF_HEADER_EXTRAS=[{"text":"Some link","url":"http://example.com/somelink","class":"subdued","only_when_logged_out":true},{"text":"Help","class":"subdued","dropdown":[{"text":"Documentation","url":"/learn"},{"text":"Contact Admin","url":"http://example.com/contact"}]}]
```

## Piè di pagina

È possibile personalizzare sia il piè di pagina sinistro sia quello destro, più piccolo (presente in pagine come `/project`), usando le variabili d'ambiente `OVERLEAF_LEFT_FOOTER` e `OVERLEAF_RIGHT_FOOTER`. Entrambe richiedono un array di oggetti JSON che verranno inseriti.

Entrambe richiedono un array JSON che verrà inserito.

```json
[\
  {\
    "text": "This is an example text footer entry!"\
  },\
  {\
    "text": "This is an example URL footer link!", "url" : "/my-first-link.htm"\
  }\
]
```

<Info>

Quando si usa solo `text`, il valore non deve contenere HTML, poiché verrà visualizzato come testo semplice.

</Info>

Per funzionare, questi dati devono essere JSON valido, con le virgolette sottoposte a escape quando vengono passati come variabile d'ambiente.

```bash title="config/variables.env" wrap
# add to config/variables.env
OVERLEAF_LEFT_FOOTER=[{"text": "This is an example text footer entry!"}]
OVERLEAF_RIGHT_FOOTER=["text": "This is an example URL footer link!", "url" : "/my-first-link.htm"]
```

<Info>

Oltre a `text` e `url`, l'oggetto JSON accetta anche le proprietà `class` e `label` per ulteriori personalizzazioni.

</Info>

### Pagina di manutenzione

Puoi personalizzare il messaggio mostrato nella pagina di manutenzione con la variabile d'ambiente `OVERLEAF_MAINTENANCE_MESSAGE`; questo testo sostituisce il messaggio predefinito sotto il titolo della pagina.

```text wrap
# add to config/variables.env
OVERLEAF_MAINTENANCE_MESSAGE=Our Overleaf Instance is down for maintenance and will be back shortly.
```

Per includere link o altra formattazione, usa invece `OVERLEAF_MAINTENANCE_MESSAGE_HTML`. Se sono impostate entrambe, `OVERLEAF_MAINTENANCE_MESSAGE_HTML` ha la precedenza.

```text wrap
# add to config/variables.env
OVERLEAF_MAINTENANCE_MESSAGE_HTML=Our Overleaf Instance is down for maintenance. For urgent requests, contact <a href="mailto:admin@example.com">admin@example.com</a>.
```

<Info>

`OVERLEAF_MAINTENANCE_MESSAGE` viene visualizzato come testo semplice, quindi **non** deve contenere HTML. `OVERLEAF_MAINTENANCE_MESSAGE_HTML` viene visualizzato come HTML senza escape.

</Info>

Se nessuna delle due è impostata, il messaggio predefinito rimanda alla tua pagina di stato quando `OVERLEAF_STATUS_PAGE_URL` è impostata e, in caso contrario, mostra l'indirizzo email dell'amministratore.
