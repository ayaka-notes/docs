Ogni progetto ha un server MCP, così i client AI come Claude Code, Codex, Cursor, VS Code o Gemini CLI possono lavorarci: leggerne e modificarne i file, compilarlo, leggere il log LaTeX, scaricare il PDF e rispondere ai commenti.

<Info>

Questa funzionalità è sviluppata da [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro). È disponibile dalla v6.3.1 in poi.

</Info>

### Configurazione

Il server MCP è incluso nell'integrazione Git: abilita [git-bridge](/it/on-premises/configuration/overleaf-toolkit/git-integration) e anche il server MCP sarà disponibile. Non c'è nient'altro da configurare.

### Collegare un client AI

1. In **Impostazioni account**, genera un token di autenticazione Git. Lo stesso token viene usato per il server MCP e per Git.
2. Nell'editor, apri **Integrazioni** e fai clic su **Server MCP**. Viene mostrato l'indirizzo del server MCP del progetto, `https://<your-overleaf>/project/<project_id>/mcp`, e come aggiungerlo a ciascun client AI: copia il comando e sostituisci `<token>` con il tuo token.

### Utilizzo

Una volta collegato, rivolgiti al client AI con parole semplici. Ad esempio:

| Chiedi | Il client AI usa |
| --- | --- |
| _Correggi i refusi nell'introduzione._ | `read_file`, `edit_file`: le modifiche compaiono in tempo reale nell'editor |
| _Compila il progetto e correggi gli errori LaTeX._ | `compile`, `get_compile_log`, `edit_file` |
| _Rispondi ai commenti aperti, poi risolvili._ | `list_comments`, `reply_to_comment`, `resolve_comment` |
| _Passa a XeLaTeX e scarica il PDF._ | `update_settings`, `compile`, `get_output_file_link` |

### Strumenti

| Gruppo | Strumenti |
| --- | --- |
| Progetto | `get_clone_info`, `get_settings`, `update_settings`, `list_versions` |
| File | `list_files`, `read_file`, `edit_file`, `write_file`, `delete_file` |
| Compilazione | `compile`, `get_compile_log`, `get_output_file_link`, `word_count` |
| Commenti | `list_comments`, `reply_to_comment`, `resolve_comment`, `reopen_comment` |

Le modifiche fatte con `edit_file` e `write_file` compaiono in tempo reale nell'editor e si uniscono a quelle dei collaboratori. Per molti file alla volta, file binari o rinomine, il client AI può anche clonare il progetto con Git ed eseguire il push.

### Permessi

Il server MCP segue le impostazioni di condivisione del progetto, come Git:

* Chiunque possa visualizzare il progetto può leggerlo, compilarlo e scaricarne l'output.
* Solo il proprietario e gli editor possono modificarne i file e le impostazioni.
* I revisori possono anche rispondere ai commenti, e risolvere o riaprire i commenti che hanno avviato.
* Gli utenti in sola visualizzazione che sono entrati tramite link non possono vedere i commenti, come nell'editor.

### Q\&A

<Accordion title="Non vedo Integrations o il server MCP nell'editor">

<strong>Risposta:</strong> Il server MCP non ha una propria variabile d'ambiente. Si abilita con `GIT_BRIDGE_ENABLED=true` in `config/overleaf.rc`, vedi [Integrazione Git](/it/on-premises/configuration/overleaf-toolkit/git-integration). Dopo averla modificata, esegui `bin/up -d`. Senza il git-bridge, l'editor non mostra la scheda **Integrations** nella barra laterale sinistra.

</Accordion>
