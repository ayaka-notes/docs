### Configurare la sincronizzazione con GitHub

<Warning>

Prima di usare la sincronizzazione con GitHub è necessario abilitare [git-bridge](/it/on-premises/configuration/overleaf-toolkit/git-integration).

```dotenv title="config/overleaf.rc"
GIT_BRIDGE_ENABLED=true
```

</Warning>

Visita le [impostazioni per sviluppatori](https://github.com/settings/developers) per creare la tua applicazione OAuth GitHub e copia il `CLIENT_ID` e il `SECRET`.

**Nota**: l'URL di callback OAuth è: `${OVERLEAF_SITE_URL}/user/github-sync/oauth2/callback`.

Quindi aggiungi le seguenti impostazioni ai file delle variabili d'ambiente di Overleaf.

```dotenv title="config/variables.env" wrap
# used to encrypt the user's GitHub access token.
# How to generate: `openssl rand -hex 32`
GITHUB_TOKEN_CIPHER_PASSWORD=0123456789ABCDEFG # changed to yours

# Github Sync Settings
GITHUB_SYNC_ENABLED=true
GITHUB_SYNC_CLIENT_ID=
GITHUB_SYNC_CLIENT_SECRET=

# OAuth callback is: ${OVERLEAF_SITE_URL}/user/github-sync/oauth2/callback
# (Optional) GITHUB_SYNC_PROXY_URL=http://10.0.0.1:10808
```

<Warning>

Prima di configurare l'URL di callback OAuth di GitHub, assicurati che `OVERLEAF_SITE_URL` sia impostato correttamente.

</Warning>

Se ti trovi nella Cina continentale, potrebbe essere necessario configurare un proxy per accedere a GitHub. Imposta la seguente variabile d'ambiente: `GITHUB_SYNC_PROXY_URL=http://10.0.0.1:10808`.

<Warning>

Non usare `127.0.0.1` come host del proxy. Se il proxy è in esecuzione sul server host, usa l'indirizzo IP LAN del server (ad esempio `192.168.1.xx`) e assicurati che il proxy sia configurato per accettare connessioni dai dispositivi della rete locale.

</Warning>
