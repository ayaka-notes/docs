### Account

Per quanto riguarda la gestione del proprio account, **tutti** gli utenti sono trattati come utenti normali: `Site Admins` e `Template Users` **non** ottengono alcun permesso aggiuntivo. Esistono tuttavia restrizioni sulle azioni che gli utenti normali possono eseguire in base al modo in cui si autenticano.

#### Impostazioni

**Tipi di autenticazione: account interni | SSO (SAML/LDAP)**

| Azione                                    | Account interni   | SSO (SAML/LDAP) |
| ----------------------------------------- | ----------------: | --------------: |
| Aggiornare le informazioni dell'account    |               Sì |              No |
| Cambiare la password                      |               Sì |              No |
| Generare token di autenticazione Git bridge |               Sì |             Sì |
| Eliminare token di autenticazione Git bridge |               Sì |             Sì |
| Gestire le sessioni                       |               Sì |             Sì |

<Info>

L'integrazione Git Bridge è disponibile **solo** in Server Pro. Consulta [Server Pro vs. Community Edition](/it/on-premises/readme/ayakaleaf-pro-vs-server-pro) per maggiori informazioni.

</Info>

#### Le tue sessioni

| Azione               | Utente |
| -------------------- | ---: |
| Cancellare le sessioni |  Sì |
| Visualizzare la sessione corrente |  Sì |
| Visualizzare le altre sessioni |  Sì |

### IDE dell'editor

Per quanto riguarda l'IDE dell'editor di Overleaf, puoi avere uno dei seguenti ruoli: `Project Owner`, `Editor`, `Reviewer`, `Viewer`, `Site Administrator` o `Template User`.

<Info>

In Server Pro e nella Community Edition è possibile fornire ai progetti un accesso anonimo in **sola lettura** e in **lettura e scrittura**.

Per maggiori informazioni, consulta le variabili d'ambiente `OVERLEAF_ALLOW_PUBLIC_ACCESS` e `OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` [qui](/it/on-premises/configuration/overleaf-toolkit/environment-variables).

</Info>
