Se nel progetto hai file `.cls`, `.sty` o `.bst`, il processo di compilazione di Overleaf non riuscirà a trovarli a meno che non si trovino al livello principale.

Tuttavia, per organizzare il progetto, potresti voler mettere questi file in cartelle, in modo da trovarli più facilmente ed evitare che il livello principale del progetto sia disordinato.

La buona notizia è che possiamo specificare directory `TEXINPUTS` personalizzate tramite il file `latexmkrc`, così Overleaf sa che deve cercare i file dei pacchetti in quella directory.

Per farlo, supponiamo che tu abbia messo questi file dei pacchetti in una cartella chiamata `tex/` e i file di stile bibliografico in una cartella chiamata `bst/`:

1. Fai clic su “Add file” nella parte superiore della barra laterale del progetto.
2. Seleziona “Blank file” e salva il file con il nome `latexmkrc` (se non esiste già).
3.  Inserisci le seguenti righe in `latexmkrc`:

    ```perl
    $ENV{'TEXINPUTS'}='./tex//:' . $ENV{'TEXINPUTS'}; 
    $ENV{'BSTINPUTS'}='./bst//:' . $ENV{'BSTINPUTS'};
    ```

    (oppure sostituisci i nomi delle cartelle con quelli pertinenti del tuo progetto)

Ora Overleaf cercherà i file dei pacchetti prima nella cartella `tex/` e poi nei `TEXINPUTS` di sistema, e i file di stile bibliografico prima nella cartella `bst/` e poi nei `BSTINPUTS` di sistema.

(Fonte: [https://tex.stackexchange.com/a/50847](https://tex.stackexchange.com/a/50847))

<Info>

Il file del documento principale e il file `latexmkrc` devono rimanere al livello principale del progetto, non in una cartella.

</Info>
