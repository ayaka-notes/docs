Se nel tuo progetto sono presenti file `.cls`, `.sty` o `.bst`, il processo di compilazione di Overleaf non sarà in grado di trovarli a meno che non si trovino al livello principale del progetto.

Tuttavia, per organizzare il progetto, potresti voler mettere questi file in delle cartelle, così da trovarli più facilmente ed evitare di affollare il livello principale del progetto.

La buona notizia è che possiamo specificare directory `TEXINPUTS` personalizzate tramite il file `latexmkrc`, in modo che Overleaf sappia di dover cercare i file dei pacchetti in quella directory.

Per farlo, supponiamo che tu abbia messo questi file dei pacchetti in una cartella chiamata `tex/` e, rispettivamente, i file di stile bibliografico in una cartella chiamata `bst/`:

1. Fai clic su “Aggiungi file” in cima alla barra laterale del progetto.
2. Seleziona “File vuoto” e salva il file con il nome `latexmkrc` (se non esiste già).
3.  Inserisci le seguenti righe in `latexmkrc`:

    ```perl
    $ENV{'TEXINPUTS'}='./tex//:' . $ENV{'TEXINPUTS'}; 
    $ENV{'BSTINPUTS'}='./bst//:' . $ENV{'BSTINPUTS'};
    ```

    (oppure sostituiscile con i nomi delle cartelle pertinenti nel tuo progetto)

Ora Overleaf cercherà prima nella cartella `tex/` e poi nei `TEXINPUTS` di sistema per trovare i file dei pacchetti, e prima nella cartella `bst/` e poi nei `BSTINPUTS` di sistema per trovare i file di stile bibliografico.

(Fonte: [https://tex.stackexchange.com/a/50847](https://tex.stackexchange.com/a/50847))

<Info>

Il file del documento principale e il file `latexmkrc` devono restare al livello principale del progetto, non in una cartella.

</Info>
