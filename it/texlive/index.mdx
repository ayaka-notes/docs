[TeX Live](https://www.tug.org/texlive/) è una distribuzione di software libero pubblicata ogni anno dal [TeX Users Group](https://www.tug.org/). Fornisce i pacchetti LaTeX, i font, i motori TeX e numerosi strumenti software necessari per supportare la composizione tipografica basata su LaTeX su tutti i sistemi operativi più diffusi.

TeX Live è un componente importante di Overleaf, perché i nostri server lo usano per compilare il tuo codice LaTeX e generare l'anteprima PDF in tempo reale. Offre inoltre agli utenti di Overleaf un facile accesso agli oltre 5.000 pacchetti LaTeX contenuti in ogni release di TeX Live.

Non sei obbligato a usare l'ultima versione di TeX Live per compilare i tuoi progetti, perché i server di Overleaf danno accesso anche alle release precedenti di TeX Live. I progetti possono essere facilmente impostati per usare una versione precedente di TeX Live, ad esempio a causa di problemi di compatibilità dei pacchetti.<br />
