CLSI (Common LaTeX Service Interface) projeleri derler, derleme çıktısında SyncTeX ve texcount çalıştırır ve belgeleri pandoc ile dönüştürür. web onu çağırır; çıktı dosyalarının kendisi bu port tarafından değil clsi-nginx tarafından sunulur. Kimlik doğrulama yok: yalnızca Docker ağı içinden erişilebilir.

* <strong>Adres:</strong> `http://clsi:3013`, Docker ağı içinde
* <strong>Kimlik doğrulama:</strong> yok
* <strong>OpenAPI dosyası:</strong> [`develop/hoppscotch/openapi/clsi.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/clsi.yaml)
