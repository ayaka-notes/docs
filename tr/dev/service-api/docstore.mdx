Her projenin her belgesini (satırlar, sürüm, aralıklar) Mongo'nun `docs` koleksiyonunda saklar ve bir arka uç ayarlandığında belgeleri nesne depolamaya arşivler. web tarafından çağrılır; document-updater ona web üzerinden ulaşır.

* <strong>Adres:</strong> `http://docstore:3016`, Docker ağı içinde
* <strong>Kimlik doğrulama:</strong> yok
* <strong>OpenAPI dosyası:</strong> [`develop/hoppscotch/openapi/docstore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/docstore.yaml)
