Proje sohbetini ve yorum dizilerini (mesajlarını ve çözüldü durumlarını) Mongo'nun `rooms` ve `messages` koleksiyonlarında saklar. web tarafından `ChatApiHandler` üzerinden çağrılır.

* <strong>Adres:</strong> `http://chat:3010`, Docker ağı içinde
* <strong>Kimlik doğrulama:</strong> yok
* <strong>OpenAPI dosyası:</strong> [`develop/hoppscotch/openapi/chat.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/chat.yaml)
