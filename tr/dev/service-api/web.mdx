Overleaf'in ana uygulaması web'in özel API'si. Diğer hizmetler (real-time, document-updater, project-history, third-party-datastore, git-bridge) ve Server CE imajının cron betikleri onu çağırır. Bu rotalar yalnızca HTTP basic auth gerektirir, CSRF belirteci gerekmez: özel yönlendirici web yönlendiricisinden önce bağlanır ve CSRF denetimini yalnızca web yönlendiricisi yapar. `BLOCK_CROSS_ORIGIN_REQUESTS=true` (varsayılan olarak kapalı) ile web, `Origin` başlığı `ALLOWED_ORIGINS` içinde olmayan (varsayılan: site URL'si) her istek için 403 döndürür. Tarayıcılar POST isteklerinde `Origin` gönderir; bu nedenle bu ayar açıkken tarayıcıdaki Hoppscotch'tan gönderilen POST istekleri, Hoppscotch proxy'si üzerinden geçmedikçe 403 alır.

* <strong>Adres:</strong> `http://web:3000`, Docker ağı içinde
* <strong>Kimlik doğrulama:</strong> status, health ve metrics dışında `WEB_API_USER` ve `WEB_API_PASSWORD` ile HTTP basic auth. git-bridge rotaları bunun yerine kişisel erişim belirteci kullanır.
* <strong>OpenAPI dosyası:</strong> [`develop/hoppscotch/openapi/web.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/web.yaml)
