---
title: i18n Çevirilerini Güncelleme
icon: language
---

`services/web/frontend/extracted-translations.json` konumunda bir dosya vardır; Overleaf web yalnızca bu dosyadaki çıkarılmış çevirileri kullanır.

Yeni içerik eklediyseniz çıkarılmış çevirileri güncellemek için aşağıdaki komutu çalıştırın.

```bash
user ➜ ~/overleaf-pro/develop (server-pro) $ bin/shell webpack
root@432836260f8a:/overleaf/services/web# npm run extract-translations
```

Genel olarak lütfen çeviri metin dosyalarını düzenlemeyin, önce mevcut olanları kullanın; çünkü bu dosyaların tümü Overleaf upstream'inden veya üçüncü taraf çeviri sitesinden güncellenir.
