## Önerilen Geliştirme Araçları

Bu isteğe bağlı servisler Overleaf'i çalıştırmak için gerekli değildir, ancak yerel geliştirme sırasında geliştirme, hata ayıklama ve inceleme için şiddetle önerilir.

* **Hoppscotch**, Postman'e benzer, ancak tarayıcı tabanlı ve geliştirme için oldukça kullanışlı, hafif bir API test aracıdır.
  * Ön yüz: [http://localhost:3000](http://localhost:3000/)
  * Proxy (CORS'u atlatmak için): [http://localhost:9159](http://localhost:9159/)
* **RedisInsight**, Redis verilerini incelemek için görsel bir arayüz sağlar. Arayüz şu adreste kullanılabilir: [http://localhost:5540](http://localhost:5540/)
* **Mongo Express**, MongoDB için web tabanlı bir arayüzdür. [http://localhost:8081](http://localhost:8081/) adresini `admin:pass` **kimlik bilgileriyle** ziyaret edebilirsiniz.

Lütfen aşağıdakileri `docker-compose.yml` dosyanıza ekleyin:

<Accordion title="develop/docker-compose.yml">

```yml title="develop/docker-compose.yml"
# services: 
  # Overleaf Dev Containers
  # ...
  
  # Add those for your development
  # API debug
  hoppscotch-frontend:
    image: hoppscotch/hoppscotch-frontend:latest
    ports:
      - "3000:3000"

  hoppscotch-proxy:
    image: hoppscotch/proxyscotch:latest
    environment:
      - PORT=9159
    ports:
      - "9159:9159"

  # Redis-insight
  redis-insight:
    image: redislabs/redisinsight:latest
    ports:
      - "5540:5540"
    depends_on:
      - redis
    volumes:
      - ./data/redis-insight:/data

  # mongo-express
  # basicAuth credentials are "admin:pass"
  mongo-express:
    image: mongo-express
    ports:
      - "8081:8081"
    environment:
      ME_CONFIG_MONGODB_SERVER: mongo
```

</Accordion>

#### CSRF Sorunları

<Warning>

Postman veya başka bir hata ayıklama aracıyla bir **post** isteği oluşturursanız, oturum açmanın **yasaklandığını** görebilirsiniz; bunun nedeni 401 hatasıdır. Bunun sebebi Overleaf'in **csrf** doğrulamasıyla korunmasıdır.

</Warning>

<Frame>
  <img src="/images/dev/image-9.png" alt="" />
</Frame>

Konsolunuzda şunu görebilirsiniz:

<Frame>
  <img src="/images/dev/image-10.png" alt="" />
</Frame>

Overleaf geliştirmenizde bununla başa çıkmak için csrf token'ınızı ayarlamanız gerekir. Ayrıntılı eğitim aşağıdadır.

<Steps>
<Step title="Ön İstek (Pre-Request) Ekleme">
Aşağıdaki kodu Pre-Request bölümüne ekleyin

<Frame>
  <img src="/images/dev/image-11.png" alt="" />
</Frame>

Betik şu şekildedir:

```js wrap
pm.sendRequest("http://web:3000/dev/csrf", function (err, res) {
    if (err) {
        console.log(err);
        return;
    }

    // 1) Save CSRF token (/dev/csrf)
    const token = res.text().trim();
    pw.env.set("csrftoken", token);
    console.log("csrftoken =", token);

    const setCookieHeader = (res.headers || []).find(h => h.key?.toLowerCase() === "set-cookie")?.value;
    console.log("set-cookie =", setCookieHeader);

    if (!setCookieHeader) return;

    const cookiePair = setCookieHeader.split(";")[0].trim(); // overleaf.sid=...
    pw.env.set("cookie_header", cookiePair);
    console.log("cookie_header =", cookiePair);
});
```
</Step>

<Step title="İstek Başlıkları Ekleme">
Aşağıdaki başlıkları eklemeniz gerekir:

| Başlık Adı   | Başlık Değeri       |
| ------------ | ------------------- |
| Content-Type | `application/json`  |
| X-Csrf-Token | `<<csrftoken>>`     |
| Cookie       | `<<cookie_header>>` |

<Frame>
  <img src="/images/dev/image-12.png" alt="" />
</Frame>
</Step>

```json5
{
  "_csrf": "<<csrftoken>>",
  "email": "admin@overleaf.com",
  "password": "xxxxxx"
}
```
