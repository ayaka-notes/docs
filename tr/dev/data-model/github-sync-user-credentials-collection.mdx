title: GitHub Sync User Credentials Koleksiyonu
icon: key
---

`githubSyncUserCredentials`, GitHub Sync için bir GitHub hesabı bağlayan her kullanıcı için bir belge tutar. Kullanıcının OAuth erişim belirtecini şifrelenmiş olarak saklar. Koleksiyon `github-sync` web modülüne (`services/web/modules/github-sync`) aittir. Şema `services/web/modules/github-sync/app/models/githubSyncUserCredentials.mjs` içindedir ve tüm erişim `services/web/modules/github-sync/app/src/TokenManager.mjs` üzerinden geçer.

#### Alanlar {#fields}

| Alan | Tür | Anlam | Kaynak |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Upsert ekleme yaptığında Mongoose tarafından ayarlanır. | |
| `userId` | ObjectId | Overleaf kullanıcısı. Zorunlu. Şemada `unique: true` yazar, ancak hiçbir indeks oluşturulmaz (bkz. İndeksler); `userId` ile yapılan upsert kullanıcı başına bir belge tutar. | `githubSyncUserCredentials.mjs:8`, `TokenManager.mjs:44-48` |
| `github` | String | `@overleaf/access-token-encryptor` ile şifrelenmiş GitHub OAuth erişim belirteci. Parola `GITHUB_TOKEN_CIPHER_PASSWORD` değişkeninden gelir; şifre etiketi `GITHUB_TOKEN_CIPHER_LABEL`, varsayılan `2026.3-v3`. Zorunlu. | `githubSyncUserCredentials.mjs:9`, `TokenManager.mjs:12-25` |
| `__v` | Number | Mongoose sürüm anahtarı. Şema bunu kapatmaz. | Mongoose varsayılanı |

Yalnızca erişim belirteci saklanır: OAuth geri çağrısı GitHub yanıtındaki `access_token` değerini tutar (`services/web/modules/github-sync/app/src/GitHubApiClient.mjs:180-191`). Yenileme belirteci veya son kullanma zamanı yoktur.

#### Kim yazar {#who-writes-it}

| Kod | Ne yapar |
| ---- | ------------ |
| `TokenManager.mjs:42-58` (`saveUserToken`) | Kullanıcının şifrelenmiş belirtecini upsert eder. Kullanıcı yeniden bağladığında, değiştirilen belirteç arka planda GitHub'da iptal edilir. OAuth geri çağrısından çağrılır (`services/web/modules/github-sync/app/src/GitHubSyncController.mjs:146`). |
| `TokenManager.mjs:61-76` (`removeUserToken`) | Belirteci GitHub'da iptal eder (elden geldiğince), ardından belgeyi siler. Bağlantı kaldırılırken (`GitHubSyncController.mjs:167`) ve silinmiş bir kullanıcının süresi dolduğunda (`services/web/modules/github-sync/index.mjs:66-68`) çağrılır. |

#### Kim okur {#who-reads-it}

| Kod | Ne yapar |
| ---- | ------------ |
| `TokenManager.mjs:36-40` (`getUserToken`) | Her GitHub API çağrısı için belirtecin şifresini çözer: `services/web/modules/github-sync/app/src/GitHubSyncHandler.mjs` (örneğin `:27`) ve `services/web/modules/github-sync/app/src/GitMerge.mjs:43`. Belge yoksa veya belirtecin şifresi çözülemiyorsa `InvalidTokenError` fırlatır ve kullanıcı bağlı değil sayılır (`GitHubSyncHandler.mjs:25-37`). |
| `services/web/modules/admin-tools/app/src/AdminUserListManager.mjs:393` | Yönetici panelinde gösterilen entegrasyonlar için kullanıcının bir belgesi olup olmadığını denetler. |

#### İndeksler {#indexes}

| Ad | Anahtarlar | Seçenekler | Taşıma |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

Mongoose `autoIndex` kapalıdır (`services/web/app/src/infrastructure/Mongoose.mjs:7`), bu yüzden şemadaki `userId` üzerindeki `unique: true` hiçbir şey oluşturmaz. `tools/migrations/20190912145011_create_githubSyncUserCredentials_indexes.mjs` (upstream'in `user_id` indeksi) yalnızca `saas` etiketlidir ve CE'de çalışmaz.

#### Notlar {#notes}

* `GITHUB_TOKEN_CIPHER_PASSWORD` değerini değiştirmek saklanan belirteçleri okunamaz hale getirir. Bu kullanıcılar yeniden bağlayana kadar bağlı değil sayılır.
* Silinmiş bir kullanıcı, süresi dolana kadar belgeyi korur.
