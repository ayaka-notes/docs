---
title: Docs Koleksiyonu
icon: file-lines
---

`docs`, bir projenin düzenlenebilir metin dosyalarının (Overleaf bunlara doc der) içeriğini tutar, örneğin `main.tex` veya `sample.bib`. Her doc için bir belge: satırları, yorumları ve izlenen değişiklikleri, iki sayaç ve silinme durumu. Dosya adı ve ağaçtaki yeri burada değil, `projects.rootFolder` içindedir (bkz. [Projects Koleksiyonu](/tr/dev/data-model/projects-collection)). İkili dosyalar da burada değildir.

Migration'lar ve bakım betikleri dışında bu koleksiyona yalnızca docstore yazar, `services/docstore/app/js/MongoManager.js` içinde. Mongoose modeli yoktur; web ve document-updater ona docstore HTTP API'si üzerinden erişir (`services/docstore/app.js:31-70`). Kaynak sütununda yolsuz dosya adları `services/docstore/app/js/` altındadır.

| Alan | Tür | Anlam | Kaynak |
| ----- | ---- | ------- | ------ |

| `project_id` | ObjectId | Doc'un projesi. | `MongoManager.js:144` |

#### Ranges {#ranges}

`ranges` iki dizi içerir. document-updater bunları `libraries/ranges-tracker/index.cjs` ile oluşturur; docstore kaydetmeden önce kimlikleri ObjectId'ye, `ts` değerini Date'e dönüştürür (`RangeManager.js:41-63`). Yorumu veya izlenen değişikliği olmayan bir doc'ta `ranges: {}` bulunur ya da hiç `ranges` yoktur.

| Alan | Tür | Anlam | Kaynak |
| ----- | ---- | ------- | ------ |
| `ranges.comments` | Array of Object | Yorum yapılmış metin aralıkları. | `libraries/ranges-tracker/index.cjs:217-236` |
| `ranges.comments.id` | ObjectId | Yorum kimliği. `rooms` koleksiyonundaki yorumun konu kimliği olan `op.t` ile aynıdır; docstore eşleşmelerini zorunlu kılar. | `RangeManager.js:54-57` |
| `ranges.comments.op.c` | String | Doc'ta yorum yapılan metin (yorum mesajı değil). | `index.cjs:226-230` |
| `ranges.comments.op.p` | Number | `op.c` başlangıcının doc içindeki karakter konumu. | `index.cjs:226-230` |
| `ranges.comments.op.t` | ObjectId | Konu kimliği, bkz. `id`. | `index.cjs:226-230`, `RangeManager.js:57` |
| `ranges.comments.metadata` | Object | Yorumun `user_id` ve `ts` değerleri. | `index.cjs:232`, `RangeManager.js:62` |
| `ranges.changes` | Array of Object | İzlenen değişiklikler, konuma göre sıralı. | `index.cjs:640-660` |
| `ranges.changes.id` | ObjectId | Değişikliğin kimliği. | `index.cjs:643-647`, `RangeManager.js:51` |
| `ranges.changes.op.i` / `op.d` | String | Eklenen metin veya silinen metin. İkisinden biri. | `index.cjs:640-660` |
| `ranges.changes.op.p` | Number | Değişikliğin karakter konumu. | `index.cjs:640-660` |
| `ranges.changes.metadata.user_id` | ObjectId or String | Yazar. Anonim düzenleyicilerin yaptığı değişiklikler `anonymous-user` dizesini korur. | `RangeManager.js:45-46`, `DocManager.js:192` |
| `ranges.changes.metadata.ts` | Date | Değişikliğin yapıldığı zaman. | `RangeManager.js:42-43` |

Bir yorumun ve yanıtlarının metni `docs` içinde değildir: `messages` koleksiyonunda, `thread_id` değeri yorum kimliği olan room içindedir. Bir yorumun çözülüp çözülmediği burada değil o room üzerinde saklanır; docstore gönderilen bir `resolved` bayrağını atar (`RangeManager.js:59-61`). Bkz. [Rooms Koleksiyonu](/tr/dev/data-model/rooms-collection) ve [Messages Koleksiyonu](/tr/dev/data-model/messages-collection).

#### Kim yazar {#who-writes-it}

| Kod | Ne yapar |
| ---- | ------------ |
| `DocManager.js:223-338` (`POST /project/:project_id/doc/:doc_id`) | Bir doc oluşturur veya günceller: `lines`, `ranges` ve `version`. Web bunu bir doc oluşturulduğunda ve document-updater açık bir doc'u flush ettiğinde çağırır (`services/web/app/src/Features/Project/ProjectEntityUpdateHandler.mjs:174`). |
| `DocManager.js:346-366` (`PATCH /project/:project_id/doc/:doc_id`) | Bir doc'u `deleted`, `deletedAt` ve `name` ile silinmiş olarak işaretler. |
| `DocArchiveManager.js:29-88` | Bir doc'u arşivler: `lines`, `ranges` ve `rev` değerlerini persistor'a kopyalar ve `inS3` ayarlar. Bir proje devre dışı bırakıldığında tüm proje için, `ARCHIVE_ON_SOFT_DELETE=true` olduğunda da silme sırasında tek bir doc için çalışır (`DocManager.js:355-363`). |
| `DocArchiveManager.js:150-174` | Arşivlenmiş bir doc okunduğunda onu Mongo'ya geri getirir (`DocManager.js:40-41`). |
| `MongoManager.js:272-274` | Proje yok edildiğinde projenin tüm doc'larını siler. |

#### Notlar {#notes}

* Bir doc açıkken en yeni metni burada değil, document-updater'da (Redis) bulunur. Mongo yalnızca document-updater flush ettiğinde güncellenir (`services/document-updater/app/js/PersistenceManager.js:128-160`). Tüm bir projenin doc'larını okuyan kod, `ProjectDuplicator` gibi önce `flushProjectToMongo` çağırmalıdır.
* Silinmiş doc'lar proje yok edilene kadar `deleted: true` ile bu koleksiyonda kalır. docstore bunlardan en fazla `MAX_DELETED_DOCS` (varsayılan 2000) tanesini, en yenisi önce olmak üzere döndürür (`MongoManager.js:29-44`, `services/docstore/config/settings.defaults.cjs:40`). Geçmiş paneli bunları kullanmaz; history-v1'i okur.
* `rev` ve `version` sayaçlarının history-v1'deki proje geçmişi sürümleriyle ilgisi yoktur.

```json5

    rev: 1,
    lines: [
        '@article{greenwade93,',
        '    author  = "George D. Greenwade",',
        '    title   = "The {C}omprehensive {T}ex {A}rchive {N}etwork ({CTAN})",',
        '    year    = "1993",',
        '    journal = "TUGBoat",',
        '    volume  = "14",',
        '    number  = "3",',
        '    pages   = "342--351"',
        '}',
        ''
    ],
    ranges: {},
    version: 0,
    deleted: true,
    deletedAt: ISODate('2026-01-17T13:11:42.580Z'),
    name: 'sample.bib'
}
```
