`docSnapshots`, document-updater’ın yorumları veya izlenen değişiklikleri daraltan bir düzenlemeden hemen önce aldığı doc kopyalarını tutar. Yalnızca document-updater yazar, `services/document-updater/app/js/SnapshotManager.js` içinde. Web’in `services/web/app/src/models/DocSnapshot.mjs` içinde bir Mongoose modeli vardır, ancak hiçbir kod onu kullanmaz.

#### Alanlar {#fields}

| Alan | Tür | Anlamı | Kaynak |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Anlık görüntü kimliği. | `SnapshotManager.js:24` |
| `project_id` | ObjectId | Proje. | `SnapshotManager.js:19,26`, `DocSnapshot.mjs:7` |
| `doc_id` | ObjectId | Doc (`docs._id`). | `SnapshotManager.js:20,27`, `DocSnapshot.mjs:8` |
| `version` | Number | Düzenlemeden önce doc’un OT sürümü. | `SnapshotManager.js:28`, `services/document-updater/app/js/UpdateManager.js:132,264-271`, `DocSnapshot.mjs:9` |
| `lines` | Array of String | Düzenlemeden önce doc’un içeriği. | `SnapshotManager.js:29`, `DocSnapshot.mjs:10` |
| `pathname` | String | O sırada doc’un projedeki yolu. | `SnapshotManager.js:30`, `DocSnapshot.mjs:11` |
| `ranges` | Mixed | Düzenlemeden önceki `comments` ve `changes`; `docs.ranges` ile aynı yapıdadır (bkz. [docs](/tr/dev/data-model/docs-collection)). `id`, `op.t` ve `metadata.user_id` ObjectId’ye, `metadata.ts` ise Date’e dönüştürülür. | `SnapshotManager.js:31,41-68`, `DocSnapshot.mjs:12` |
| `ts` | Date | Anlık görüntünün alındığı zaman. TTL indeksi anlık görüntüyü 30 gün sonra siler. | `SnapshotManager.js:32`, `DocSnapshot.mjs:13` |

#### Kim yazar {#who-writes-it}

| Kod | Ne yapar |
| ---- | ------------ |
| `UpdateManager.js:248-271` | document-updater bir düzenlemeyi uyguladıktan sonra, düzenleme aralıkları daralttıysa (daha fazla aralık boşaldıysa veya birden fazla aralık kaldırıldıysa) doc’un düzenlemeden önceki halini kaydeder (`services/document-updater/app/js/RangesManager.js:104-106`). |
| `SnapshotManager.js:17-36` `recordSnapshot` | Anlık görüntüyü ekler. |

#### Kim okur {#who-reads-it}

Hiçbir kod okumaz. Web modeli tanımlıdır ancak hiçbir yerde kullanılmaz.

#### Notlar {#notes}

* Yalnızca `UpdateManager.applyUpdate` üzerinden geçen düzenlemeler anlık görüntü alır. `HistoryOTUpdateManager` tarafından işlenen düzenlemeler almaz (`UpdateManager.js:74-77`).
* `doc_id` üzerinde indeks yoktur. Bir doc’un anlık görüntülerini `project_id` ve `ts` ile bulun, ardından `doc_id` ile filtreleyin.
