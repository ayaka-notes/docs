title: Project History Labels Koleksiyonu
icon: tag
---

`projectHistoryLabels`, kullanıcıların History görünümünde sürümlere koyduğu etiketleri tutar; her etiket için bir belge. Sahibi project-history’dir ve `services/project-history/app/js/LabelsManager.js` içinde yazar; Mongoose şeması yoktur. Web ona yalnızca project-history API’si üzerinden erişir.

#### Alanlar {#fields}

| Alan | Tür | Anlamı | Kaynak |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Etiket kimliği. | `LabelsManager.js:81-85` |
| `project_id` | ObjectId | Proje. | `LabelsManager.js:73` |
| `comment` | String | Etiket metni. | `LabelsManager.js:74` |
| `version` | Number | Etiketin işaret ettiği proje geçmişi sürümü. | `LabelsManager.js:75` |
| `created_at` | Date | Etiketin oluşturulduğu zaman; istek kendi zamanını iletebilir, aksi halde şimdiki zamandır. | `LabelsManager.js:70`, `76` |
| `user_id` | ObjectId | Etiketi kimin oluşturduğu. İstekte kullanıcı yoksa bırakılır. | `LabelsManager.js:78-80` |

#### Kim yazar {#who-writes-it}

| Kod | Ne yapar |
| ---- | ------------ |
| `services/project-history/app/js/LabelsManager.js:44-90` | `createLabel`: bir etiket ekler, project-history `POST /project/:project_id/labels` için (`services/project-history/app/js/HttpController.js:1134-1171`). Bir kullanıcı etiket eklediğinde Web onu kullanıcının kimliğiyle çağırır (`services/web/app/src/Features/History/HistoryController.mjs:529-546`). |
| `LabelsManager.js:113-126` | `deleteLabel`: projenin bir etiketini siler, `DELETE /project/:project_id/labels/:label_id` için. Proje sahibi bir etiketi sildiğinde Web bunu kullanır (`HistoryController.mjs:649-670`). |
| `LabelsManager.js:92-111` | `deleteLabelForUser`: bir etiketi yalnızca kullanıcı oluşturduysa siler, `DELETE /project/:project_id/user/:user_id/labels/:label_id` için. Web bunu diğer herkes için kullanır. |
| `LabelsManager.js:128-143` | `transferLabels`: bir kullanıcının tüm etiketlerini başka birine taşır, `POST /user/:from_user/labels/transfer/:to_user` için (`services/project-history/app/js/Router.js:52-55`). Web’de bu rotayı çağıran hiçbir şey yoktur. |
| `LabelsManager.js:7-25` | `cloneLabels`: bir projenin etiketlerini başka bir projeye kopyalar, project-history `POST /project/:project_id/clone` için (`HttpController.js:113`); Web’de onu çağıran hiçbir şey yoktur. |

#### Kim okur {#who-reads-it}

| Kod | Ne yapar |

| `LabelsManager.js:27-42` | `getLabels`: bir projenin tüm etiketleri, `{ id, comment, version, user_id, created_at }` biçiminde döndürülür (`LabelsManager.js:163-171`). `GET /project/:project_id/labels` tarafından kullanılır (`HttpController.js:1076-1100`); Web onu History görünümü için çağırır ve kullanıcı adlarını doldurur (`HistoryController.mjs:488-499`). |
| `services/project-history/app/js/SummarizedUpdatesManager.js:57` | Etiketleri geçmiş güncellemeleri listesine ekler. |

#### Notlar {#notes}

* Bir etiket eklemeden önce project-history, projenin kuyruktaki güncellemelerini işler ve history-v1’de o sürüm için bir chunk olup olmadığını denetler; istek `validate_exists: false` gönderirse denetlemez (`LabelsManager.js:53-59`, `173-195`; `HttpController.js:1109-1115`).
* Proje silindiğinde etiketlerini silen hiçbir kod yoktur: project-history `DELETE /project/:project_id` yalnızca eşitleme durumunu ve hata kaydını temizler (`HttpController.js:1363-1396`) ve başka hiçbir hizmet bu koleksiyona dokunmaz.
