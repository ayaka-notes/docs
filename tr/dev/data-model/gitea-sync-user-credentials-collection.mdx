---
title: Gitea Sync User Credentials Koleksiyonu
icon: lock
---

`giteaSyncUserCredentials`, Gitea Sync için bir Gitea hesabı bağlayan her kullanıcı için bir belge tutar. Kullanıcının OAuth belirteçlerini şifrelenmiş olarak saklar. Koleksiyon `gitea-sync` web modülüne (`services/web/modules/gitea-sync`) aittir. Şema `services/web/modules/gitea-sync/app/models/giteaSyncUserCredentials.mjs` içindedir ve tüm erişim `services/web/modules/gitea-sync/app/src/TokenManager.mjs` üzerinden geçer.

#### Alanlar {#fields}

| Alan | Tür | Anlam | Kaynak |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Upsert ekleme yaptığında Mongoose tarafından ayarlanır. | |
| `userId` | ObjectId | Overleaf kullanıcısı. Zorunlu. Şemada `unique: true` yazar, ancak hiçbir indeks oluşturulmaz (bkz. İndeksler); `userId` ile yapılan upsert kullanıcı başına bir belge tutar. | `giteaSyncUserCredentials.mjs:8`, `TokenManager.mjs:89-96` |
| `gitea` | String | `@overleaf/access-token-encryptor` ile şifrelenmiş `{ accessToken, refreshToken, expiresAt }` JSON değeri. `expiresAt` epoch'tan bu yana milisaniye cinsindendir veya `null` olur; `refreshToken` `null` olabilir. Parola `GITEA_TOKEN_CIPHER_PASSWORD` değişkeninden gelir; şifre etiketi `GITEA_TOKEN_CIPHER_LABEL`, varsayılan `2026.10-v3`. Zorunlu. | `giteaSyncUserCredentials.mjs:9-10`, `TokenManager.mjs:17-30`, `services/web/modules/gitea-sync/app/src/GiteaApiClient.mjs:198-209` |
| `__v` | Number | Mongoose sürüm anahtarı. Şema bunu kapatmaz. | Mongoose varsayılanı |

#### Kim yazar {#who-writes-it}

| Kod | Ne yapar |
| ---- | ------------ |
| `TokenManager.mjs:89-96` (`saveUserToken`) | Kullanıcının şifrelenmiş kimlik bilgilerini upsert eder. OAuth geri çağrısından çağrılır (`services/web/modules/gitea-sync/app/src/GiteaSyncController.mjs:146`). GitLab Sync'in aksine, yeniden bağlamak değiştirilen belirteci iptal etmez. |
| `TokenManager.mjs:53-79` (`refreshUserToken`) | Erişim belirtecinin `expiresAt` zamanına 5 dakikadan az kaldığında (`:12`), yenileme belirteciyle yeni belirteçler alır ve kaydeder (`:76`). Gitea yenileme belirtecini kullanıldığında değiştirdiği için kullanıcı başına `giteaSyncToken` kilidi altında çalışır (`:14,54`). |
| `TokenManager.mjs:100-102` (`removeUserToken`) | Belgeyi siler. Gitea'da bir OAuth belirtecini iptal edecek API yoktur, bu yüzden kullanıcı izni Gitea'da iptal eder (`:98-99`). Bağlantı kaldırılırken (`GiteaSyncController.mjs:173`) ve silinmiş bir kullanıcının süresi dolduğunda (`services/web/modules/gitea-sync/index.mjs:56-58`) çağrılır. |

#### Kim okur {#who-reads-it}

| Kod | Ne yapar |
| ---- | ------------ |
| `TokenManager.mjs:40-44,82-86` (`getUserCredentials`, `getUserToken`) | Her Gitea API çağrısı için kimlik bilgilerinin şifresini çözer, belirtecin süresi dolmak üzereyse önce yeniler: `services/web/modules/gitea-sync/app/src/GiteaSyncHandler.mjs` (örneğin `:27`) ve `services/web/modules/gitea-sync/app/src/GitMerge.mjs:52`. Belge yoksa veya kimlik bilgilerinin şifresi çözülemiyor ya da yenilenemiyorsa `InvalidTokenError` fırlatır ve kullanıcı bağlı değil sayılır (`GiteaSyncHandler.mjs:25-37`). |
| `services/web/modules/admin-tools/app/src/AdminUserListManager.mjs:395` | Yönetici panelinde gösterilen entegrasyonlar için kullanıcının bir belgesi olup olmadığını denetler. |

#### İndeksler {#indexes}

| Ad | Anahtarlar | Seçenekler | Taşıma |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

Mongoose `autoIndex` kapalıdır (`services/web/app/src/infrastructure/Mongoose.mjs:7`), bu yüzden şemadaki `userId` üzerindeki `unique: true` hiçbir şey oluşturmaz. Bu koleksiyon için indeks oluşturan bir taşıma yoktur.

#### Notlar {#notes}

* `GITEA_TOKEN_CIPHER_PASSWORD` değerini değiştirmek saklanan kimlik bilgilerini okunamaz hale getirir. Bu kullanıcılar yeniden bağlayana kadar bağlı değil sayılır.
* Silinmiş bir kullanıcı, süresi dolana kadar belgeyi korur.
