---
title: GitLab Sync User Credentials Koleksiyonu
icon: user-lock
---

`gitlabSyncUserCredentials`, GitLab Sync için bir GitLab hesabı bağlayan her kullanıcı için bir belge tutar. Kullanıcının OAuth belirteçlerini şifrelenmiş olarak saklar. Koleksiyon `gitlab-sync` web modülüne (`services/web/modules/gitlab-sync`) aittir. Şema `services/web/modules/gitlab-sync/app/models/gitlabSyncUserCredentials.mjs` içindedir ve tüm erişim `services/web/modules/gitlab-sync/app/src/TokenManager.mjs` üzerinden geçer.

#### Alanlar {#fields}

| Alan | Tür | Anlam | Kaynak |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Upsert ekleme yaptığında Mongoose tarafından ayarlanır. | |
| `userId` | ObjectId | Overleaf kullanıcısı. Zorunlu. Şemada `unique: true` yazar, ancak hiçbir indeks oluşturulmaz (bkz. İndeksler); `userId` ile yapılan upsert kullanıcı başına bir belge tutar. | `gitlabSyncUserCredentials.mjs:8`, `TokenManager.mjs:88-95` |
| `gitlab` | String | `@overleaf/access-token-encryptor` ile şifrelenmiş `{ accessToken, refreshToken, expiresAt }` JSON değeri. `expiresAt` epoch'tan bu yana milisaniye cinsindendir veya `null` olur; `refreshToken` `null` olabilir. Parola `GITLAB_TOKEN_CIPHER_PASSWORD` değişkeninden gelir; şifre etiketi `GITLAB_TOKEN_CIPHER_LABEL`, varsayılan `2026.10-v3`. Zorunlu. | `gitlabSyncUserCredentials.mjs:9-10`, `TokenManager.mjs:18-31`, `services/web/modules/gitlab-sync/app/src/GitLabApiClient.mjs:209-220` |
| `__v` | Number | Mongoose sürüm anahtarı. Şema bunu kapatmaz. | Mongoose varsayılanı |

#### Kim yazar {#who-writes-it}

| Kod | Ne yapar |
| ---- | ------------ |
| `TokenManager.mjs:88-95` (`saveUserToken`) | Kullanıcının şifrelenmiş kimlik bilgilerini upsert eder. |
| `TokenManager.mjs:99-108` (`linkUserToken`) | OAuth geri çağrısından gelen yeni kimlik bilgilerini kaydeder (`services/web/modules/gitlab-sync/app/src/GitLabSyncController.mjs:146`). Kullanıcı yeniden bağladığında, değiştirilen erişim belirteci arka planda GitLab'de iptal edilir. |
| `TokenManager.mjs:53-78` (`refreshUserToken`) | Erişim belirtecinin `expiresAt` zamanına 5 dakikadan az kaldığında (`:13,47-49`), yenileme belirteciyle yeni belirteçler alır ve kaydeder (`:75`). GitLab bir yenileme belirtecini kullanıldığında harcadığı için kullanıcı başına `gitlabSyncToken` kilidi altında çalışır (`:15,54`). |
| `TokenManager.mjs:111-126` (`removeUserToken`) | Erişim belirtecini GitLab'de iptal eder (elden geldiğince), ardından belgeyi siler. Bağlantı kaldırılırken (`GitLabSyncController.mjs:173`) ve silinmiş bir kullanıcının süresi dolduğunda (`services/web/modules/gitlab-sync/index.mjs:56-58`) çağrılır. |

#### Kim okur {#who-reads-it}

| Kod | Ne yapar |
| ---- | ------------ |
| `TokenManager.mjs:41-45,81-85` (`getUserCredentials`, `getUserToken`) | Her GitLab API çağrısı için kimlik bilgilerinin şifresini çözer, belirtecin süresi dolmak üzereyse önce yeniler: `services/web/modules/gitlab-sync/app/src/GitLabSyncHandler.mjs` (örneğin `:27`) ve `services/web/modules/gitlab-sync/app/src/GitMerge.mjs:52`. Belge yoksa veya kimlik bilgilerinin şifresi çözülemiyor ya da yenilenemiyorsa `InvalidTokenError` fırlatır ve kullanıcı bağlı değil sayılır (`GitLabSyncHandler.mjs:25-37`). |
| `services/web/modules/admin-tools/app/src/AdminUserListManager.mjs:394` | Yönetici panelinde gösterilen entegrasyonlar için kullanıcının bir belgesi olup olmadığını denetler. |

#### İndeksler {#indexes}

| Ad | Anahtarlar | Seçenekler | Taşıma |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

Mongoose `autoIndex` kapalıdır (`services/web/app/src/infrastructure/Mongoose.mjs:7`), bu yüzden şemadaki `userId` üzerindeki `unique: true` hiçbir şey oluşturmaz. Bu koleksiyon için indeks oluşturan bir taşıma yoktur.

#### Notlar {#notes}

* `GITLAB_TOKEN_CIPHER_PASSWORD` değerini değiştirmek saklanan kimlik bilgilerini okunamaz hale getirir. Bu kullanıcılar yeniden bağlayana kadar bağlı değil sayılır.
* Silinmiş bir kullanıcı, süresi dolana kadar belgeyi korur.
