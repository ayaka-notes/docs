`projectHistoryShardedBlobs`, [projectHistoryBlobs](/dev/data-model/project-history-blobs-collection) içine sığmayan blob kayıtlarını tutar: bir hash önekinin kovasında orada zaten 8 kayıt varsa sonrakiler buraya gelir. Bir projenin burada en fazla 16 belgesi olur; hash’in her ilk onaltılık basamağı için bir tane. Mongoose şeması yoktur; history-v1 onu `services/history-v1/storage/lib/blob_store/mongo.js` içinde yazar (yapısı `mongo.js:1-16` konumunda açıklanır).

#### Alanlar {#fields}

| Alan | Tür | Anlamı | Kaynak |
| ----- | ---- | ------- | ------ |
| `_id` | Binary | 13 bayt: projenin geçmiş kimliği, bir `0`, ve onaltılık olarak okunan parça basamağı (`<history id>0<digit>`). Parça basamağı hash’in ilk onaltılık basamağıdır. | `mongo.js:439-453` |
| `blobs` | Object | Kovalar halinde gruplanmış blob kayıtları. Bir kovanın anahtarı hash’in 2. ile 4. onaltılık basamaklarıdır. | `mongo.js:439-443` |
| `blobs.<bcd>` | Array of Object | Kovanın kayıtları. Kod boyutuna sınır koymaz. | `mongo.js:399-407` |
| `blobs.<bcd>[].h` | Binary | Hash, 20 bayt, projectHistoryBlobs’taki gibi. | `mongo.js:472` |
| `blobs.<bcd>[].b` | Number | İçeriğin bayt cinsinden uzunluğu. | `mongo.js:473` |
| `blobs.<bcd>[].s` | Number | İçeriğin metin olarak uzunluğu; içerik düzenlenebilir metin değilse `null`. | `mongo.js:474` |

#### Kim yazar {#who-writes-it}

| Kod | Ne yapar |
| ---- | ------------ |
| `services/history-v1/storage/lib/blob_store/mongo.js:399-407` | `insertRecordSharded`: `$addToSet` ile kovaya upsert yapar. projectHistoryBlobs’taki kova dolduğunda `insertBlob` tarafından çağrılır (`mongo.js:387-389`). |
| `mongo.js:75-103` | `clone`: projenin parçalarını başka bir geçmiş kimliğine kopyalar, history-v1 `POST /projects/:project_id/clone` için; Web’de onu çağıran hiçbir şey yoktur. |
| `mongo.js:413-422` | `deleteBlobs`: history-v1 `DELETE /projects/:project_id` sırasında projenin tüm parçalarını projectHistoryBlobs belgesiyle birlikte siler. |

#### Kim okur {#who-reads-it}

| Kod | Ne yapar |
| ---- | ------------ |
| `mongo.js:144-157` | `findBlobSharded`: tek bir blob; yalnızca projectHistoryBlobs’taki kovasında 8 kayıt olup blob orada yoksa aranır (`mongo.js:127-131`). |
| `mongo.js:217-260` | `findBlobsSharded`: `findBlobs` işlevinin projectHistoryBlobs’ta bulamadığı blob’lar (`mongo.js:202-206`). |
| `mongo.js:285-306` | `getProjectBlobs`: bir projenin tüm parçaları. |
| `mongo.js:337-361` | `getProjectBlobsBatch`: birkaç projenin tüm parçaları, blob istatistikleri rotası için. |

#### İndeksler {#indexes}

Yalnızca varsayılan `_id` indeksi. `tools/migrations/` içindeki hiçbir migration indeks eklemez.

#### Notlar {#notes}

* Bir projenin parçaları `_id` sırasında yan yana durur; bu yüzden kod onları `<history id>00` ile `<history id>0f` arasındaki bir `_id` aralığıyla bulur (`mongo.js:75-80`, `287-295`).
* Koleksiyon ancak bir projede aynı 3 basamaklı hash önekine sahip 8’den fazla blob olduğunda ortaya çıkar; bu yüzden küçük bir örnekte hiç olmayabilir.
