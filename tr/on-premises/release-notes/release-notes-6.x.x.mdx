<Warning>

Ayakaleaf Pro 6.3.0 ilk olarak 24 Eylül 2026'da yayımlandı. Bu yeniden yayın, üst kaynak güncellemelerinden kaynaklanan AI Assistant, Zotero ve Mendeley entegrasyonlarındaki sorunları gidermektedir.

Daha önce yayımlanan sürüm verilerinize zarar vermez. En son `6.3.0` imajını çekin ve dağıtımınızı yükseltin. **Zotero veya Mendeley'e bağlı kaynakça dosyaları olan mevcut kurulumların aşağıdaki taşımayı da çalıştırması gerekir.** Yeni kurulumların bu taşımaya ihtiyacı yoktur.

<Accordion title="Mevcut kurulumlar için Zotero / Mendeley taşıması">

Yeniden yayımlanan 6.3.0 imajına yükseltirken, mevcut Zotero/Mendeley bağlı kaynakça meta verilerini aşağıdaki betiği kullanarak taşıyın. Bu taşıma `12031b8dfd` düzeltmesine eşlik eder.

Bu işlem `zoteroGroupId` / `mendeleyGroupId` alanlarını `group_id` olarak, `importedByUserId` alanını `importer_id` olarak yeniden adlandırır ve `importedByName` alanını kaldırır.

Taşımayı çalıştırmadan önce MongoDB'yi yedekleyin ve uygulamayı durdurun. MongoDB'yi çalışır durumda tutun. Kabuğunu açın (`mongo` yerine kendi konteyner adınızı yazın):

```bash
docker exec -it mongo mongosh
```

Aşağıdakini `mongosh` içinde çalıştırın (`sharelatex` yerine kendi veritabanı adınızı yazın):

```javascript
use sharelatex

(async () => {
  let updated = 0
  await db.projects.find({}, { rootFolder: 1 }).forEach(async project => {
    const changes = {}
    function visit(folders, path) {
      for (const [i, folder] of (folders || []).entries()) {
        const folderPath = `${path}.${i}`
        for (const [j, file] of (folder.fileRefs || []).entries()) {
          const data = { ...file.linkedFileData }
          if (!["zotero", "mendeley"].includes(data.provider)) continue
          const groupKey = `${data.provider}GroupId`
          if (![groupKey, "importedByUserId", "importedByName"].some(key => key in data)) continue
          for (const [oldKey, newKey] of [[groupKey, "group_id"], ["importedByUserId", "importer_id"]]) {
            if (data[oldKey] != null && data[oldKey] !== "") {
              const value = String(data[oldKey])
              if (newKey in data && data[newKey] !== value) {
                throw new Error(`Conflicting ${newKey}: project ${project._id}, file ${file._id}`)
              }
              data[newKey] = value
            }
            delete data[oldKey]
          }
          delete data.importedByName
          changes[`${folderPath}.fileRefs.${j}.linkedFileData`] = data
        }
        visit(folder.folders, `${folderPath}.folders`)
      }
    }
    visit(project.rootFolder, "rootFolder")
    if (!Object.keys(changes).length) return
    const result = await db.projects.updateOne(
      { _id: project._id, rootFolder: { $eq: project.rootFolder } },
      { $set: changes }
    )
    if (!result.matchedCount) throw new Error(`Project changed during migration: ${project._id}`)
    updated += result.modifiedCount
  })
  print(`Updated ${updated} project(s).`)
})()
```

Betik iç içe klasörleri de kapsar ve yalnızca Zotero/Mendeley meta verilerini değiştirir. Yeniden çalıştırmak güvenlidir: tamamlanmış bir taşıma bir sonraki çalıştırmada `Updated 0 project(s).` raporlar. Bir çakışma nedeniyle durursa, raporlanan projeyi/dosyayı inceleyin; önceki projeler zaten taşınmış olabilir.

Güncellenmiş uygulamayı başlatın, düzenleyiciyi yeniden yükleyin ve mevcut bir kaynakça dosyasını orijinal içe aktaran kişi olarak yenileyin. Geçmiş anlık görüntüler yeniden yazılmaz. Eski uygulamaya geri dönmek için MongoDB yedeğini geri yükleyin.

</Accordion>

Topluluktaki en güçlü ve en zengin özellikli çevrimiçi LaTeX düzenleyicisi olan Overleaf Pro 6.3.0'ın yayımlandığını duyurmaktan büyük gurur duyuyoruz. Her zaman kullanıcılarımızın deneyimini iyileştirmeye odaklandığımız için bu sürüm, kesinlikle seveceğiniz büyük değişiklikler ve harika özellikler getiriyor; bunlar arasında yapay zekâ asistanı ve üçüncü taraf kaynakça entegrasyonu bulunuyor.

### Değişiklikler

* AI Chat Assistant: Kendi sağlayıcınız üzerinden, doğrudan düzenleyicinizde bir yapay zekâ modeliyle sohbet edin.
* LaTeX Error Assistant: LaTeX derleme hataları için yapay zekâ tarafından önerilen düzeltmeler alın.
* Mendeley entegrasyonu: Zotero'ya benzer şekilde Mendeley'den kaynakça içe aktarın.
* Open in Overleaf API: İçeriği Overleaf'te açmak için bir API eklendi.
* Şablon Galerisi: Sunucu tarafında sayfalama, arama ve sıralama eklendi; böylece büyük galerilerin artık her şablonu tarayıcıda yüklemesi gerekmiyor.
* Çeviriler: Desteklenen diller genelinde yeni arayüz metinleri dahil olmak üzere 6.3.0 için çeviri yamaları güncellendi.
* Üst kaynak Overleaf 6.3.0: Sekmeli dosya düzenleme, açık ve koyu temalar için ayrı başlık logoları ile bağımlılık ve temel imaj güncellemelerini içerir.
* Açık ve koyu temalar için ayrı başlık logosu görsellerini desteklemek üzere `OVERLEAF_HEADER_IMAGE_URL_LIGHT` ve `OVERLEAF_HEADER_IMAGE_URL_DARK` eklendi.
* Dosyalar artık düzenleyicide farklı sekmelerde açılabilir.
* Open in Overleaf API tarafından da kullanılan `OVERLEAF_LINKED_URL_OUTBOUND_PROXY` aracılığıyla, yerel olarak barındırılan proxy'ler dahil yapılandırılabilir HTTP(S) proxy desteği eklendi.

#### Özellik 04: Şablon Sayfalama

Galeri artık sayfalama, sıralama ve aramayı MongoDB'de yapıyor. Herhangi bir hazırlık olmadan çalışır; binlerce şablonunuz varsa hızlı kalması için yine de şu dizinleri ekleyebilirsiniz (yeniden çalıştırmak güvenlidir, `mongo`/`sharelatex` = konteyner ve veritabanı adlarınız):

```bash
docker exec mongo mongosh sharelatex --quiet --eval '
db.templates.createIndex({category:1,lastUpdated:-1},{name:"category_1_lastUpdated_-1",background:true});
db.templates.createIndex({lastUpdated:-1},{name:"lastUpdated_-1",background:true});
db.templates.createIndex({category:1,name:1},{name:"category_1_name_1_ci",collation:{locale:"en",strength:2},background:true});
db.templates.createIndex({name:1},{name:"name_1_ci",collation:{locale:"en",strength:2},background:true});
'
```

İki `*_ci` dizinindeki `collation` ayarını yazıldığı gibi koruyun — galeri aynı collation ile sorgu yapar ve MongoDB yalnızca eşleşen bir dizini kullanır.

## Ayakaleaf Pro 6.2.2

**Yayın tarihi:** 2026.07.23

Bkz.: [https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.2](https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.2)

### Değişiklikler

Üst kaynak Overleaf `6.2.2` ile gelen resmi acil düzeltme yamaları (`6.2.1` üzerine) geri taşındı:

* Proje davet token gizli anahtarının günlüklere sızması durduruldu. Davet token şifreleyicisi her şifreleme/şifre çözme işleminde kendi yapılandırmasını günlüğe yazıyordu; bu yapılandırma `OVERLEAF_INVITE_TOKEN_SECRET` değerinden türetilen şifre parolalarını içeriyordu.
* Giden e-postalar, kullanım ömrü sona ermiş AWS SES v1 istemcisinden SESv2'ye taşındı. `ses` e-posta sürücüsüyle yapılandırılmış örnekler hiç e-posta gönderemeyebiliyordu; gönderim artık `SESv2Client` üzerinden yapılıyor.
* Proje paylaşma açılır menüsündeki grup girdileri yeni `group-link-sharing` özellik bayrağının arkasına alındı; böylece grup bağlantısı paylaşımı artık geçerli olmadığı örneklerde sunulmuyor.
* İşbirlikçiler için proje paylaşma penceresi düzeltildi. Pencereyi sahip olmayan biri olarak veya `sharing-updates` akışı devre dışıyken açmak, her zaman başarısız olan bir istek gönderiyor ve "something went wrong" hatası gösteriyordu.
* document-updater'a `scripts/flush_docs_with_pending_updates.js` eklendi; bu bakım betiği, projeleri boşaltıldıktan veya kalıcı olarak silindikten sonra Redis'te takılı kalmış bir `PendingUpdates` kuyruğuna sahip belgeleri kurtarır. `--dry-run` ve `--estimated-docs` güvenlik denetimini destekler.
* Bağımlılıklar güncellendi: `multer` 2.2.0, `form-data` 2.5.6, `protobufjs` 7.6.3, `@grpc/grpc-js` 1.14.4.

Bu sürüm ayrıca Ayakaleaf Pro'dan gelen şu düzeltmeleri ve iyileştirmeleri içerir:

* 16 ek dil (cs, da, de, es, fi, fr, it, ja, ko, nl, no, pl, pt, ru, sv, tr) için tam çeviriler eklendi; parola sıfırlama sayfası gibi çevrilmemiş metinler düzeltildi. [#38](https://github.com/ayaka-notes/ayakaleaf-pro/issues/38) numaralı sorunu düzeltir.
* Yönetim panelindeki "show N more projects" düğmesinde, çoğul yer tutucusu doğru aktarılmadığı için yanlış sayı gösteren öğe sayısı düzeltildi.
* GitHub dışa aktarma doğrulama hataları düzeltildi; bu hatalar artık ham iletiler yerine statik i18n anahtarlarıyla gösteriliyor ve GitHub Sync penceresinde artık kullanılmayan hata anahtarları kaldırıldı.

Üst kaynak Overleaf `6.2.1` ile gelen resmi acil düzeltme yamaları (`6.2.0` üzerine) geri taşındı:

## Ayakaleaf Pro 6.2.0

**Yayın tarihi:** 2026.07.10

Bkz.: [https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.0](https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.0)

Topluluktaki en güçlü ve en zengin özellikli çevrimiçi LaTeX düzenleyicisi olan Overleaf Pro 6.2.0'ın yayımlandığını duyurmaktan gurur duyuyoruz. Değerli katkıları için yu-i-i ve davrot'a özellikle teşekkür ederiz. GitHub Sync'i geliştirdiler, Gelişmiş Atıf Arama'yı ve Zotero entegrasyonunu sundular.

### Notlar

<Warning>

* Yeni ve zorunlu bir `OVERLEAF_INVITE_TOKEN_SECRET` ortam değişkeni getirildi. Bunu `openssl rand -base64 32` ile oluşturmanız gerekir. Yapılandırılmazsa Overleaf örneğiniz başlatılamaz.
* GitHub Sync'i etkinleştirirseniz `GITHUB_TOKEN_CIPHER_PASSWORD` ortam değişkenini yapılandırmanız gerekir. Bu değişken, GitHub erişim belirteçlerini güvenli bir şekilde şifrelemek için gereklidir. Olmadan Overleaf örneğiniz başlatılamaz.

</Warning>

* Yeni projelerin kullandığı varsayılan derleyiciyi (`pdflatex`, `latex`, `xelatex` veya `lualatex`) ayarlamak için yeni bir `DEFAULT_LATEX_COMPILER` ortam değişkeni eklendi.
* Yeniden tasarlanan düzenleyici artık tek kullanılabilir seçenektir.

### Değişiklikler

Bu sürüm aşağıdaki iyileştirmeleri ve yeni özellikleri içerir.

* `MAX_UPLOAD_SIZE` artık **50 MB** ile sınırlı olmak yerine yapılandırılabilir.
* Yalıtılmış derlemeler devre dışıyken oluşan konteyner yeniden başlatma döngüsü düzeltildi.
* OAuth2 için sahip kapsamlı PAT silme zorunlu hâle getirildi.
* Bir LDAP içe aktarma sorunu düzeltildi.

Özellikler şunlardır:

* Tarayıcı tabanlı bir Python çalıştırıcı eklendi.
* Markdown, DOCX ve diğer biçimleri içe ve dışa aktarmak için Pandoc desteği eklendi.
* GitHub Sync eklendi.
* Eksiksiz Çince çeviriler eklendi.
* Zotero entegrasyonu eklendi.
* `DEFAULT_LATEX_COMPILER` eklendi.

#### Özellik 04: Python Çalıştırıcı

### İkili dosya taşıması

Bu yeni sürüm, ikili dosyaların depolama kullanımını yarıya indirir.

`5.5` sürümüne, yükseltmenin bir parçası olarak kesinti süresini en aza indiren çevrimiçi bir taşıma dahil edilmiştir. Server Pro `v6` sürümüne yükseltmeden önce Server Pro `v5.5`'in en son sürümünü ([Sürüm Notları 5.x.x](https://docs.overleaf.com/on-premises/release-notes/release-notes-5.x.x)) çalıştırdığınızdan ve taşımayı gerçekleştirdiğinizden emin olun.

[Tam taşıma talimatlarına bakın](https://docs.overleaf.com/on-premises/release-notes/release-notes-5.x.x/binary-files-migration).

### MongoDB'nin v8'e yükseltilmesi

Bu sürüm minimum MongoDB sürümünü `8.0`'a yükseltir.

Şu anda MongoDB `v6` veya daha eski bir sürüm kullanıyorsanız, sürümlerinizi her seferinde bir ana sürüm olacak şekilde (`v6 → v7 → v8`) güncellemeniz gerekir.

<Warning>

Lütfen yükseltmeden **önce** bir [veritabanı](https://docs.overleaf.com/on-premises/maintenance/data-and-backups) yedeğiniz olduğundan emin olun. Geri dönüş durumunda veritabanı yedeğini geri yüklemeniz gerekir.

</Warning>

MongoDB'yi `v6 → v7 → v8` şeklinde yükseltme talimatları için adım adım rehberimize [buradan](https://docs.overleaf.com/on-premises/maintenance/updating-mongodb#example-upgrading-mongodb-from-6.0-to-7.0-toolkit-users) bakın.

### Redis'in v7.4'e yükseltilmesi

Bu sürüm ayrıca minimum Redis sürümünü `7.4`'e yükseltir.

`config/overleaf.rc` içindeki `REDIS_IMAGE` değerini `REDIS_IMAGE=7.4` olarak güncelleyin.

### Yeni Özellikler

* Bağlantı paylaşımı artık `OVERLEAF_DISABLE_LINK_SHARING=true` ile devre dışı bırakılabilir.
* Bakım sayfasının başlığını ve içeriğini özelleştirmek için artık `OVERLEAF_MAINTENANCE_MESSAGE` ve `OVERLEAF_MAINTENANCE_MESSAGE_HTML` kullanılabilir.
* Silinen kullanıcıların/projelerin süre sonu gecikmesini (varsayılan 90 gün) değiştirmek için `OVERLEAF_USER_HARD_DELETION_DELAY` ve `OVERLEAF_PROJECT_HARD_DELETION_DELAY` (milisaniye cinsinden) yapılandırılabilir.

### Hata düzeltmeleri

* Bağlantılı alt bilginin (footer) görüntülenmesi düzeltildi.
* SAML giriş hatalarındaki hata iletileri iyileştirildi.
* SSO girişinde bir kullanıcının yönetici durumu güncellendiğinde denetim günlüğü girdisinin eklenmemesi düzeltildi.
* Redis'te TLS etkinken History panelinde oluşan hatalar düzeltildi.
* Yalıtılmamış (non-sandboxed) derlemeler kullanılırken derlemeler artık durdurulabilir.

### Diğer değişiklikler

* Durum sayfasına giden tüm bağlantılar (`OVERLEAF_STATUS_PAGE_URL` ile ayarlanan) artık `HTTPS` kullanır ve yeni bir tarayıcı sekmesinde açılır.
