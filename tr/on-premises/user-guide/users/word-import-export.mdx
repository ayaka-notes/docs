<Info>

Bu seçenekleri görmüyorsanız yöneticinizden [Pandoc Import and Export](/tr/on-premises/configuration/overleaf-toolkit/pandoc-import-and-export) özelliğini açmasını isteyin.

</Info>

## Belge içe aktarma {#import-a-document}

Bu işlem, bir Word belgesinden (`.docx`) veya Markdown dosyasından (`.md`) yeni bir LaTeX projesi oluşturur. Projenin adı dosyanın adından gelir.

<Steps>
<Step title="İçe aktarma iletişim kutusunu açın">
Projeler sayfasında **New project** düğmesine tıklayın. **Import** altında **Word document** veya **Markdown document** seçeneğine tıklayın.

<Frame caption="New project menüsü">
  <img src="/images/on-premises/word-import-menu.png" alt="Import altında Word document ve Markdown document bulunan New project menüsü" />
</Frame>
</Step>

<Step title="Dosyayı seçin">
**Select .docx file** düğmesine tıklayın veya dosyayı iletişim kutusuna sürükleyin. Markdown için düğme **Select .md file** olur. İçe aktarma hemen başlar.

<Frame caption="Bir Word belgesi seçme">
  <img src="/images/on-premises/word-import-dialog.png" alt="Select .docx file düğmesi bulunan Choose Word document iletişim kutusu" />
</Frame>
</Step>

<Step title="Düzenlemeye başlayın">
Yeni proje **Document ready for editing** mesajıyla açılır. **Start editing** düğmesine tıklayın.

<Frame caption="İçe aktarma tamamlandı">
  <img src="/images/on-premises/word-import-ready.png" alt="Start editing düğmesi bulunan Document ready for editing iletişim kutusu" />
</Frame>
</Step>

<Step title="Sonucu kontrol edin">
Belge artık `main.tex` içindedir ve başlıkları dosya ana hattında görünür. PDF'i görmek için **Recompile** düğmesine tıklayın. Biçimlendirmeyi, özellikle düzenleme gerektirebilecek tabloları, şekilleri ve alıntıları kontrol edin.

<Frame caption="İçe aktarılan proje">
  <img src="/images/on-premises/word-import-project.png" alt="Düzenleyicide main.tex, dosya ana hattı ve derlenmiş PDF ile içe aktarılan proje" />
</Frame>
</Step>
</Steps>

### İçe aktarma başarısız olursa {#if-the-import-fails}

Dosya dönüştürülemezse iletişim kutusu **Your document couldn't be imported** mesajını gösterir. Nedenini görmek için **Conversion error details** bölümünü genişletin. Proje oluşturulmaz.

<Frame caption="İçe aktarılamayan bir belge">
  <img src="/images/on-premises/word-import-error.png" alt="Hata mesajı ve Conversion error details bulunan içe aktarma iletişim kutusu" />
</Frame>

İletişim kutusu yalnızca seçtiğiniz türü kabul eder. Word iletişim kutusunda bir `.md` dosyası **You can only upload: .docx** mesajını gösterir.

## Proje dışa aktarma {#export-a-project}

Projeyi açın, ardından düzenleyicinin üst kısmındaki proje adına tıklayın. Şunlardan birine tıklayın:

| Seçenek                              | Elde ettiğiniz                                       |
| ----------------------------------- | --------------------------------------------- |
| <strong>Export as Word document (.docx)</strong> | Projenin adını taşıyan bir `.docx` dosyası        |
| <strong>Export as Markdown (.md)</strong>        | `main.md` içeren bir `.zip` dosyası                  |
| <strong>Export as HTML (.html)</strong>          | `main.html` içeren bir `.zip` dosyası                |

İndirme kendiliğinden başlar. Dönüştürme tüm LaTeX biçimlendirmesini yeniden üretemez, bu yüzden sonucu kontrol edin.

</Frame>
