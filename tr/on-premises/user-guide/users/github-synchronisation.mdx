Bir projeyi bir GitHub deposuna bağlayın. Değişiklikler iki yönlü ve yalnızca **Sync** öğesine tıkladığınızda aktarılır: hiçbir şey kendiliğinden senkronize olmaz.

<Info>

**Account settings** içinde veya düzenleyicide GitHub seçeneği görmüyorsanız yöneticinizden [GitHub Senkronizasyonunu](/tr/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation) açmasını isteyin.

</Info>

## GitHub hesabınızı bağlama {#link-your-github-account}

Bunu bir kez yaparsınız.

<Steps>
<Step title="Hesap ayarlarınızı açın">
**Account**, ardından **Account settings** öğesine tıklayın. **GitHub** bölümüne kaydırın ve **Link** öğesine tıklayın.

<Frame caption="Hesap ayarlarında GitHub">
  <img src="/images/on-premises/github-sync-link.png" alt="Link düğmesi bulunan hesap ayarlarının GitHub bölümü" />
</Frame>
</Step>

<Step title="GitHub'da yetkilendirin">
GitHub açılır. İstenirse oturum açın, ardından uygulamayı yetkilendirin.
</Step>

<Step title="Bağlantıyı kontrol edin">
Hesap ayarlarına geri dönersiniz ve düğmede artık **Unlink** yazar.

<Frame caption="GitHub hesabınız bağlandı">
  <img src="/images/on-premises/github-sync-linked.png" alt="Unlink düğmesi bulunan hesap ayarlarının GitHub bölümü" />
</Frame>
</Step>
</Steps>

Hesabınız henüz bağlı değilse **Import from GitHub** ve düzenleyicideki **GitHub** kartı önce bağlamanızı ister. **Link to your GitHub account** öğesine tıklayın. Bu şekilde de hesap ayarlarına ulaşırsınız; düzenleyicide başladıysanız yeni bir sekmede. Ardından geri dönüp yeniden başlayın.

<Frame caption="Hesabınız bağlı değilken görünen uyarı">
  <img src="/images/on-premises/github-sync-link-prompt.png" alt="Link to your GitHub account düğmesi bulunan Import from GitHub iletişim kutusu" />
</Frame>

## Depoyu içe aktarma {#import-a-repository}

Bu, bir GitHub deposundan, ona zaten bağlı yeni bir proje oluşturur.

<Steps>
<Step title="İçe aktarma iletişim kutusunu açın">
Projeler sayfasında **New project**, ardından **Import from GitHub** öğesine tıklayın.

<Frame caption="New project menüsü">
  <img src="/images/on-premises/github-sync-new-project-menu.png" alt="Import from GitHub içeren New project menüsü" />
</Frame>

<Info>

**New project**, bir projeniz olduğunda görünür. Karşılama sayfasındaki **Create a new project** menüsünde içe aktarma yoktur, bu nedenle önce boş bir proje oluşturun.

</Info>
</Step>

<Step title="Depoyu seçin">
Deponun yanındaki **Import to Overleaf** öğesine tıklayın. Liste, sizin depolarınızı ve kuruluşlarınızın depolarını içerir.

<Frame caption="GitHub depolarınız">
  <img src="/images/on-premises/github-sync-import.png" alt="Dört depoyu listeleyen Import from GitHub iletişim kutusu" />
</Frame>

Bir kuruluşun deposu eksikse, uygulamayı o kuruluş için onaylamaya ilişkin GitHub yardımı için <strong>Can't see what you're looking for?</strong> öğesine tıklayın.
</Step>

<Step title="Projeyi kontrol edin">
Yeni proje, deponun dosyalarıyla açılır.

<Frame caption="İçe aktarılan proje">
  <img src="/images/on-premises/github-sync-imported.png" alt="İçe aktarılan projeyi dosyaları ve derlenmiş PDF ile gösteren düzenleyici" />
</Frame>
</Step>
</Steps>

## Projeyi yeni bir depoya dışa aktarma {#export-a-project-to-a-new-repository}

Bu, sahibi olduğunuz bir projeden bir depo oluşturur ve ikisini bağlar. Bir proje yalnızca bu yolla veya içe aktarılarak bağlanabilir: zaten var olan bir depoya bağlayamazsınız.

<Steps>
<Step title="Düzenleyicide GitHub'ı açın">
Projeyi açın. Sol çubukta **Integrations**, ardından **GitHub** öğesine tıklayın.

<Frame caption="Integrations paneli">
  <img src="/images/on-premises/github-sync-integrations.png" alt="GitHub kartı bulunan Integrations paneli" />
</Frame>
</Step>

<Step title="Depo bilgilerini doldurun">
**Owner** seçin; bu siz veya kuruluşlarınızdan biri olabilir. **Repository Name** başlangıçta projenin adıdır. Açıklama isteğe bağlıdır ve **Private** varsayılan olarak seçilidir. **Create a GitHub repository** öğesine tıklayın.

<Frame caption="Export Project to GitHub">
  <img src="/images/on-premises/github-sync-export.png" alt="Doldurulmuş Export Project to GitHub formu" />
</Frame>
</Step>

<Step title="Bağlantıyı kontrol edin">
İletişim kutusunda artık **This project is linked to** yazar ve depo adı belirtilir.

<Frame caption="Proje bağlandı">
  <img src="/images/on-premises/github-sync-exported.png" alt="Dışa aktarmadan sonra Sync with GitHub iletişim kutusu" />
</Frame>
</Step>
</Steps>

## Senkronize etme {#sync}

<Steps>
<Step title="Senkronizasyon iletişim kutusunu açın">
Bağlı bir projeyi açın. Sol çubukta **Integrations**, ardından **GitHub** öğesine tıklayın.

**Recent commits in GitHub**, projeye gelecek olanları listeler.

<Frame caption="GitHub'da bekleyen yeni bir commit">
  <img src="/images/on-premises/github-sync-new-commits.png" alt="Bir yeni commit listeleyen Sync with GitHub iletişim kutusu" />
</Frame>
</Step>

<Step title="Değişikliklerinizi açıklayın">
Projede bir şey değiştirdiyseniz bir commit mesajı kutusu görünür. İsteğe bağlıdır: boş bırakırsanız commit'in adı `Updates from Overleaf` olur.

<Frame caption="Değişiklikleriniz için commit mesajı">
  <img src="/images/on-premises/github-sync-commit-message.png" alt="Commit mesajı doldurulmuş Sync with GitHub iletişim kutusu" />
</Frame>
</Step>

<Step title="Sync öğesine tıklayın">
**Sync** öğesine tıklayın. GitHub'daki yeni commit'ler projeye gelir ve değişiklikleriniz deponun varsayılan dalına gider. İki taraf farklı şeyler değiştirdiyse bunlar sizin için birleştirilir.
</Step>

<Step title="Sonucu kontrol edin">
İletişim kutusu <strong>No new commits in GitHub since last merge.</strong> gösterir ve commit mesajı kutusu kaybolur. Düzenleyicideki dosyalar ve GitHub'daki commit'ler günceldir.

<Frame caption="Her şey senkronize">
  <img src="/images/on-premises/github-sync-done.png" alt="Senkronizasyondan sonra yeni commit olmayan Sync with GitHub iletişim kutusu" />
</Frame>
</Step>
</Steps>

### Aynı satırlar her iki tarafta da değiştiyse {#if-the-same-lines-changed-on-both-sides}

İletişim kutusu, değişikliklerin birleştirilemediğini söyler ve değişikliklerinizi tutan yeni bir dalın adını verir: `overleaf-YYYY-MM-DD-HHMMSS`.

<Frame caption="Bir çakışma">
  <img src="/images/on-premises/github-sync-conflict.png" alt="Birleştirme çakışması uyarısı gösteren Sync with GitHub iletişim kutusu" />
</Frame>

1. Bu dalı GitHub'da veya Git ile varsayılan dala birleştirin. Bu arada iletişim kutusunu kapatabilirsiniz: yeniden açtığınızda aynı mesajı gösterir.
2. **I have manually merged. Continue** öğesine tıklayın. Birleştirilmiş sonuç projeye gelir.
3. Dal GitHub'da kalır. Artık ihtiyacınız olmadığında silin.

## Projenin bağlantısını kaldırma {#unlink-a-project}

Projenin artık senkronize olmasını istemediğinizde bunu yapın. Bunu yalnızca proje sahibi yapabilir.

<Steps>
<Step title="Unlink öğesine tıklayın">
Senkronizasyon iletişim kutusunda **Unlink** öğesine tıklayın.
</Step>

<Step title="Onaylayın">
**Confirm** öğesine tıklayın. Abonelikle ilgili not, projeyi yeniden bağlamanıza engel olmaz.

<Frame caption="Bağlantı kaldırmayı onaylayın">
  <img src="/images/on-premises/github-sync-unlink-project.png" alt="Bağlantı kaldırmayı onaylamanızı isteyen Sync with GitHub iletişim kutusu" />
</Frame>
</Step>

<Step title="Sonucu kontrol edin">
İletişim kutusu artık **Export Project to GitHub** gösterir. Proje ve depo içeriklerini korur. Yeniden senkronize etmek için projeyi yeni bir depoya dışa aktarın veya depoyu yeni bir projeye içe aktarın.
</Step>
</Steps>

## GitHub hesabınızın bağlantısını kaldırma {#unlink-your-github-account}

**Account settings** içinde, **GitHub** altında **Unlink** öğesine, ardından iletişim kutusunda yeniden **Unlink** öğesine tıklayın.

<Frame caption="Hesabınızın bağlantısını kaldırın">
  <img src="/images/on-premises/github-sync-unlink-account.png" alt="Unlink GitHub Account iletişim kutusu" />
</Frame>

Projeleriniz depolarına bağlı kalır. Hesabınızı yeniden bağlayana kadar onları senkronize edemezsiniz.

<Info>

Paylaşılan bir projede kimin neyi yapabileceği için [Kim bağlayabilir ve senkronize edebilir](/tr/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation#who-can-link-and-sync) bölümüne bakın. Senkronize eden her ortak çalışan kendi GitHub hesabını bağlar.

</Info>
