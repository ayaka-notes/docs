### Hesap

Kendi hesaplarını yönetme açısından **tüm** kullanıcılar normal kullanıcı olarak değerlendirilir — `Site Admins` ve `Template Users` herhangi bir ek izne **sahip değildir**. Ancak normal kullanıcıların hangi eylemleri yapabileceği, kimlik doğrulama yöntemlerine göre kısıtlanır.

#### Ayarlar

<strong>Kimlik doğrulama türleri: Dahili Hesaplar | SSO (SAML/LDAP)</strong>

| Eylem | Dahili Hesaplar | SSO (SAML/LDAP) |
| ----------------------------------------- | ----------------: | --------------: |
| Hesap bilgilerini güncelleme | Evet | Hayır |
| Parola değiştirme | Evet | Hayır |
| Git bridge kimlik doğrulama token'ları oluşturma | Evet | Evet |
| Git bridge kimlik doğrulama token'larını silme | Evet | Evet |
| Oturumları yönetme | Evet | Evet |

<Info>

Git Bridge entegrasyonu **yalnızca** Server Pro'da kullanılabilir. Daha fazla bilgi için [Server Pro ile Community Edition karşılaştırması](/tr/on-premises/readme/ayakaleaf-pro-vs-server-pro) sayfasına göz atın.

</Info>

#### Oturumlarınız

| -------------------- | ---: |
| Oturumları temizleme | Evet |
| Geçerli oturumu görüntüleme | Evet |

### Düzenleyici IDE

Overleaf Düzenleyici IDE'si açısından şu rollerden birine sahip olabilirsiniz: `Project Owner`, `Editor`, `Reviewer`, `Viewer`, `Site Administrator` veya `Template User`.

<Info>

Server Pro ve Community Edition'da projelere anonim **salt okunur** ve **okuma-yazma** erişimi sağlama desteği vardır.

Bu konuda daha fazla bilgi için `OVERLEAF_ALLOW_PUBLIC_ACCESS` ve `OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` ortam değişkenlerine [buradan](/tr/on-premises/configuration/overleaf-toolkit/environment-variables) göz atın.

</Info>
