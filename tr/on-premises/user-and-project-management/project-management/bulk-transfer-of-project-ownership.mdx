```bash wrap
# Legacy docker-compose.yml setup:
$ docker exec sharelatex /bin/bash -c "source /etc/overleaf/env.sh && source /etc/container_environment.sh && cd /overleaf/services/web && node ./modules/server-ce-scripts/scripts/transfer-all-projects-to-user.mjs --from-user=alice@example.com --to-user=bob@example.com"
```

## Bayraklar

| Ad            | Açıklama                                            |
| ------------- | --------------------------------------------------- |
| `--from-user` | Mevcut proje sahibinin e-posta adresi veya user-id'si |
| `--to-user`   | Yeni proje sahibinin e-posta adresi veya user-id'si   |

## Tamamlanma

Betik bir hata nedeniyle erken sonlanırsa, hatayı yazdırır ve başarısız olduğunu belirtmek için 1 koduyla çıkar.

Taşıma başarıyla tamamlanırsa "Done" yazdırır ve 0 koduyla çıkar.
