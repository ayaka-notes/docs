Bir Ayakaleaf Pro kurulumunu planlamak ve yürütmek için Claude Code veya Codex kullanın. Ajan, çalışırken MCP aracılığıyla bu dokümantasyonda arama yapabilir.

Ajan kuruluma yardımcı olur. Komutları gözden geçirmek ve kimlik bilgilerini korumak sizin sorumluluğunuzdadır.

### Başlamadan önce

SSH erişimi olan, desteklenen bir Linux sunucusu hazırlayın. Devam etmeden önce [gereksinimleri](/tr/on-premises/getting-started/requirements  "mention") gözden geçirin.

<Warning>

Ajan istemlerine parola, özel anahtar, belirteç veya lisans anahtarı yapıştırmayın. Her komutu, özellikle dosyaları, ağları veya kapsayıcıları değiştiren komutları çalıştırmadan önce gözden geçirin.

</Warning>

### Dokümantasyonu bağlama

Dokümantasyon MCP uç noktasını yerel ajanınıza ekleyin.

<Tabs>
<Tab title="Claude Code">

```bash wrap
claude mcp add ayakaleaf-pro --scope user --transport http https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>

<Tab title="Codex">

```bash wrap
codex mcp add ayakaleaf-pro --url https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>
</Tabs>

Sunucuyu ekledikten sonra yeni bir oturum başlatın. Ajandan Ayakaleaf Pro dokümantasyonunda arama yapabildiğini doğrulamasını isteyin.

### Ayakaleaf Pro'yu dağıtma

Kurulum sunucunuzda bir terminal açın. Claude Code veya Codex'i orada başlatın. Ardından şu istemi gönderin:

```text wrap
Use the Ayakaleaf Pro documentation MCP server to guide this deployment.
First, inspect the requirements and installation guides.
Ask me for missing deployment details before making changes.
Use the Ayakaleaf Toolkit unless the documentation requires another approach.
Before configuring the instance, summarize relevant optional features.
Ask which features and integrations I want to enable.
Include TLS, sandboxed compiles, Git integration, external MongoDB or Redis,
SSO (OIDC, SAML, or LDAP), GitHub Synchronisation, Zotero, S3 storage,
email delivery, branding, and localization when relevant.
Explain each selected option's prerequisites, security impact, and configuration steps.
Keep unselected optional features disabled.
Show each command before running it.
Do not expose, store, or request secrets in chat.
After deployment, verify that the service is healthy and summarize the changes.
```

Ajan size Docker kurulumu, Toolkit yapılandırması, imajın alınması ve başlatma adımlarında rehberlik etmelidir. Standart iş akışı için [using-the-toolkit](/tr/on-premises/installation/using-the-toolkit  "mention") kılavuzunu izleyin.

### İsteğe bağlı özellikleri seçme

Ajandan yalnızca ortamınıza uyan özellikleri önermesini isteyin. Tipik seçenekler şunlardır:

* **Erişim ve güvenlik:** TLS, sandbox derlemeleri ve OIDC, SAML veya LDAP SSO.
* **Harici hizmetler:** MongoDB, Redis, S3 depolama ve e-posta gönderimi.
* **İş birliği:** Git entegrasyonu, GitHub Senkronizasyonu ve Zotero.

Ajan, yapılandırmayı düzenlemeden önce bağımlılıkları açıklamalıdır. Üretim entegrasyonlarını etkinleştirmeden önce [toolkit-settings.md](/tr/on-premises/configuration/overleaf-toolkit/toolkit-settings  "mention") ve [authentication](/tr/on-premises/configuration/overleaf-toolkit/authentication  "mention") sayfalarını gözden geçirin.

### Kurulumu doğrulama

Ajan adımları tamamladıktan sonra:

1. Her komutun hatasız tamamlandığını doğrulayın.
2. Yapılandırılan Ayakaleaf Pro URL'sini tarayıcınızda açın.
3. [6.-post-installation-tasks.md](/tr/on-premises/installation/using-the-toolkit/6.-post-installation-tasks  "mention") adımlarını tamamlayın.

Mevcut bir Community Edition kurulumu için sıfırdan kurulum yerine [migrate-from-existing.md](/tr/on-premises/installation/migrate-from-existing  "mention") kılavuzunu kullanın.
