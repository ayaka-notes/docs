<Danger>

Aşağıdaki talimatlar **yalnızca** **Community Edition** kurulumları için geçerlidir. Ayakaleaf Pro kullanıcılarımızın [Sandboxed Compiles](/tr/on-premises/configuration/overleaf-toolkit/sandboxed-compiles) özelliğini etkinleştirmesini önemle tavsiye ederiz; bu özellik, kullanıcılara [overleaf.com](https://www.overleaf.com) üzerinde kullanılanlarla neredeyse aynı TeX Live imajlarına erişim sağlamanın yanı sıra gelişmiş güvenlik için proje derlemeleri arasında yalıtım da sağlar.

</Danger>

Bant genişliğinden tasarruf etmek için hem Overleaf Community Edition hem de Ayakaleaf Pro imajları yalnızca minimal bir [TeX Live](https://www.tug.org/texlive/) kurulumuyla gelir. `sharelatex` konteynerinde [tlmgr](https://www.tug.org/texlive/tlmgr.html) komutunu kullanarak daha fazla paket kurabilir veya tam bir TeX Live kurulumuna yükseltebilirsiniz.

#### sharelatex konteynerine girme

`sharelatex` konteyneri içinde bir kabuk başlatmak için şunu çalıştırın:

```bash
bin/shell
```

Şuna benzer bir komut istemi göreceksiniz:

```bash
root@309b192d4030:/#
```

Aşağıdaki talimatlarda konteynerin içinde olduğunuzu varsayacağız.

#### Mevcut TeX Live sürümünüzü belirleme

TeX Live her yıl Nisan ayı civarında yayımlanır. `tlmgr` kullanma adımları, güncel sürümü mü yoksa daha eski bir sürümü mü kullandığınıza bağlı olarak farklılık gösterir. Hangi TeX Live sürümünü çalıştırdığınızı `tlmgr --version` ile kontrol edebilirsiniz. Örneğin, bu kurulum TeX Live 2021 çalıştırıyor:

```bash
# tlmgr --version
tlmgr revision 59291 (2021-05-21 05:14:40 +0200)
tlmgr using installation: /usr/local/texlive/2021
TeX Live (https://tug.org/texlive) version 2021
```

<Info>

TeX Live'ın güncel sürümünü [TeX Live ana sayfasında](https://www.tug.org/texlive/) bulabilirsiniz.

</Info>

Daha eski bir TeX Live sürümü çalıştırıyorsanız iki seçeneğiniz vardır. Overleaf Docker imajının yeni bir sürümü genellikle bir TeX Live sürümünden kısa süre sonra yayımlanır; bunu bekleyip dağıtımınızı `bin/upgrade` betiğiyle yükseltebilirsiniz ya da eski TeX Live sürümünü korumayı tercih ediyorsanız önce `tlmgr`'ye geçmiş bir depo kullanmasını söylemeniz gerekir. Bunun nasıl yapılacağına ilişkin talimatları [burada](https://www.tug.org/texlive/acquire.html#past) bulabilirsiniz.

#### Paket kurma

Tam bir TeX Live kurulumu yapmak için `sharelatex` konteyneri içinde şu komutu çalıştırın:

```text
tlmgr install scheme-full
```

Paketleri tek tek elle de kurabilirsiniz:

```bash
tlmgr install tikzlings tikzmarmots tikzducks
```

<Warning>

`3.3.0` sürümünden itibaren, tüm ikili dosyaların sistem yoluna doğru şekilde sembolik bağlantısının oluşturulması için her `tlmgr install` kullanımından sonra `tlmgr path add` komutunu çalıştırmak yeniden **zorunludur**.

</Warning>

Çok daha fazla komut mevcuttur. Daha fazlasını şununla öğrenin:

```text
tlmgr help
```

İşiniz bittiğinde kabuktan çıkmak için `exit` yazın veya Control-D tuşlarına basın.

#### Değişikliklerinizi kaydetme

Az önce yaptığınız değişiklikler `sharelatex` konteynerini değiştirdi, ancak bunlar geçicidir -- Docker Compose konteyneri yeniden oluşturursa, örneğin yapılandırma güncellemesinin bir parçası olarak, kaybolurlar.

Bunları kalıcı hale getirmek için değişiklikleri yeni bir Docker imajına kaydetmek üzere `docker commit` kullanın:

```bash
cat config/version #5.2.1
docker commit sharelatex sharelatex/sharelatex:5.2.1-with-texlive-full
echo 5.2.1-with-texlive-full > config/version
```

Değişiklikleri commit ettikten sonra `config/version` dosyasını buna göre güncelleyin. Ardından `sharelatex` konteynerini yeniden oluşturmak için `bin/up` komutunu çalıştırın.

Yeni bir Overleaf sürümüne her [yükseltme](https://github.com/overleaf/toolkit/blob/master/doc/upgrading.md) yaptığınızda bu adımları tekrarlamanız gerekecektir.

</Danger>
