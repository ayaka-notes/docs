### Toolkit'i indirme {#downloading-the-toolkit}

Ayakaleaf Pro'yu, Overleaf'i sizin için Docker içinde çalıştıran bir betikler kümesi olan **Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)) ile kurarsınız.

Toolkit varsayılan olarak ücretsiz resmi Overleaf Community Edition'ı (CE) başlatır. [4. Ayakaleaf Pro İmajlarını Edinin](/tr/on-premises/installation/using-docker-compose/linux/4.-get-overleaf-pro-images) adımı, tek bir ayarla onu Ayakaleaf Pro'ya geçirir.

<Accordion title="Resmi Overleaf Toolkit'i (overleaf/toolkit) zaten mi çalıştırıyorsunuz?">

Yeniden kurmanıza gerek yoktur. Kurulumunuzu koruyun ve [4. Ayakaleaf Pro İmajlarını Edinin](/tr/on-premises/installation/using-docker-compose/linux/4.-get-overleaf-pro-images) sayfasının son bölümünü izleyin.

</Accordion>

<Steps>
<Step title="Ayakaleaf Toolkit deposunu klonlayın">
Toolkit'i kurmak için hedeflenen kurulum yoluna gitmeniz ve ardından şu komutla Ayakaleaf Toolkit deposunu klonlamanız gerekir:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
```

<Info>

Olası izin sorunlarını önlemek için Toolkit'i kullanıcınızın `$HOME` dizinine kurmanızı öneririz.

</Info>
</Step>

<Step title="Toolkit dizinine geçin">
Klonlama işleminin tamamlanmasını bekleyin, ardından yeni oluşturulan `overleaf-toolkit` dizinine geçelim:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
