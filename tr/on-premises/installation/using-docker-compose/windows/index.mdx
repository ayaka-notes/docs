Bu bölümde Ayakaleaf Pro'yu WSL 2, Ubuntu, Docker Desktop ve [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit) ile Windows üzerinde yerel olarak çalıştırıyoruz. Kılavuz `http://localhost:8080` adresini kullanır, verileri Ubuntu'nun ana dizininde tutar ve korumalı alan (sandboxed) derlemelerini etkinleştirir.

Uygulama, MongoDB, Redis ve TeX Live, Docker Desktop tarafından yönetilen Linux konteynerlerinde çalışır. Toolkit komutlarını Ubuntu'da çalıştırın; uygulamayı Windows tarayıcınızda açın. [Adım 0](/tr/on-premises/installation/using-docker-compose/windows/0.-setup-wsl-and-docker-desktop), Windows ve Linux bileşenlerinin nasıl bir arada çalıştığını açıklar ve WSL kurulumuyla başlar.

Windows'u yerel bir örnek için kullanabilir veya 6. adımdaki erişilebilirlik ayarlarıyla örneği sürekli çalışır durumda tutabilirsiniz. Paylaşılan sunucular ve üretim sunucuları için HTTPS, yedekleme ve erişim denetimiyle birlikte [Linux kılavuzunu](/tr/on-premises/installation/using-docker-compose/linux) öneririz. Windows uykusu, Docker Desktop'ın kapanması ve WSL'nin kapanması bu yerel örneği kesintiye uğratır; bkz. [Örneği erişilebilir tutun](/tr/on-premises/installation/using-docker-compose/windows/6.-post-installation-tasks#keep-the-instance-available).

## Başlamadan önce {#before-you-start}

Şunlara ihtiyacınız var:

* Donanım sanallaştırması etkinleştirilmiş, [Docker Desktop for Windows](https://docs.docker.com/desktop/setup/install/windows-install/) tarafından desteklenen bir Windows sürümü ve işlemci. Bu kılavuz x86-64 üzerinde Windows 11 kullanır.
* WSL'yi etkinleştirme ve yazılım kurma izni. WSL sürümü 2.1.5 veya üzeri olmalı ve Ubuntu WSL 2 modunda çalışmalıdır.
* Windows ve konteynerler için yeterli bellek. Küçük bir yerel örnek için Docker'a ayrılmış 4 CPU ve 8 GB bellek ölçülmüş bir alt sınır değil, önerilen bir başlangıç noktasıdır.
* WSL ve Docker verilerini barındıran Windows diskinde boş depolama alanı. Tam bir TeX Live kurulumu ve proje verileri için en az 40 GB ayırın; [5. adımdaki](/tr/on-premises/installation/using-docker-compose/windows/5.-personalizing-your-instance) basic imaj daha küçüktür ve ilk dağıtım testi için uygundur. Ek imaj sürümleri ek alan gerektirir.
* Toolkit'i klonlamak ve imajları indirmek için GitHub, GitHub Container Registry (`ghcr.io`) ve Docker Hub'a ağ erişimi.

**PowerShell** blokları Windows'ta çalışır. Aksi belirtilmedikçe **Bash** blokları ve `bin/` komutları Ubuntu'da çalışır. Toolkit betiklerini PowerShell'de veya Windows Git Bash'te çalıştırmayın.
