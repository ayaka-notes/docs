---
title: 3. Yapılandırmayı başlatın
description: WSL 2 üzerindeki Ubuntu'da bin/init ile Toolkit yapılandırma dosyalarını oluşturun.
icon: circle-play
---

**Ubuntu**'da Toolkit dizininden şunu çalıştırın:

```bash
bin/init
```

`bin/init` üç dosya oluşturur:

| Dosya | Amaç |
| --- | --- |
| `config/overleaf.rc` | Konteyner ayarları, yayımlanan port ve veri konumları |
| `config/variables.env` | Uygulama ayarları ve gizli anahtarlar |
| `config/version` | Uygulama imajı sürümü |

Ayrıca `config/variables.env` içinde `OVERLEAF_INVITE_TOKEN_SECRET` değerini üretir. Bu değeri saklayın; bu dosyayı yayımlamayın veya sürüm denetimine commit etmeyin.

Toolkit'in yeni bir kurulum için seçtiği sürümü koruyun. Mevcut bir örneğin sürümünü daha sonra değiştirmek için [Dağıtımınızı yükseltme](/tr/on-premises/maintenance/upgrading-your-deployment) kılavuzunu izleyin.

<Info>

`bin/init` mevcut yapılandırmanın üzerine yazmaz. Dosyaların zaten var olduğunu bildirirse devam etmeden önce onları inceleyin. Örneği yeniden başlatırken veya yükseltirken `config/` ve `data/` dizinlerini koruyun.

</Info>
