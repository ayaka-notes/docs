<Steps>
<Step title="Komut satırı araçlarını kurun">
0. adımda oluşturduğunuz Linux parolasını kullanarak **Ubuntu**'da çalıştırın:

```bash
sudo apt update
sudo apt install -y git ca-certificates curl perl gawk openssl
```

Ubuntu, Bash, GNU sed ve coreutils'i zaten sağlar. macOS'un aksine Homebrew'a veya ayrı bir GNU sed kurulumuna ihtiyaç duymaz.
</Step>

<Step title="Ayakaleaf Toolkit deposunu klonlayın">
Toolkit'i ve verilerini Ubuntu'nun Linux dosya sisteminde, ana dizininizin altında tutun:

```bash
cd "$HOME"
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

Canlı veritabanı ve proje verileri için `/mnt/c`, `/mnt/d`, OneDrive ve geçici dizinlerden kaçının. Linux dosya sistemi yolları, konteynerlerin beklediği izinleri ve dosya sistemi davranışını sağlar ve dosya sistemleri arası ek yükten kaçınır; bkz. [Microsoft'un dosya sistemi kılavuzu](https://learn.microsoft.com/en-us/windows/wsl/filesystems).

<Warning>

Dizin zaten bir kurulum içeriyorsa onu olduğu gibi kullanın veya yeni bir örnek için başka bir dizin seçin. Mevcut bir dağıtımın yapılandırmasını veya verilerini değiştirmeyin.

</Warning>
</Step>
</Steps>
