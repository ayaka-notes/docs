title: 4. Ayakaleaf Pro İmajlarını Edinin
description: WSL 2 üzerindeki Ubuntu'da Toolkit'i herkese açık Ayakaleaf Pro imajına geçirin.
icon: split
---

Ayakaleaf Pro, [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/) üzerinde ücretsiz bir Docker imajıdır. Bunu çekmek için bir hesaba, oturum açmaya veya ticari bir Overleaf lisansına ihtiyacınız yoktur.

`config/overleaf.rc` dosyasını açın ve şunu ayarlayın:

```bash title="config/overleaf.rc"
SERVER_PRO=true
```

`bin/up` komutunu bir sonraki çalıştırışınızda Toolkit, resmi Overleaf Community Edition yerine `config/version` içindeki sürümde `ghcr.io/ayaka-notes/overleaf-pro` imajını çeker.

İmaj `arm64` ve `amd64` için derlenmiştir ve Docker, Docker motorunun mimarisine uyanı seçer.
