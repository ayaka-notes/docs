Komutları çalıştırın ve dosyaları **Ubuntu**'da, `~/ayakaleaf-toolkit` dizininden düzenleyin.

<Steps>
<Step title="Konteyner ayarları">
`config/overleaf.rc` içindeki mevcut girdileri düzenleyin:

```bash title="config/overleaf.rc"
PROJECT_NAME=ayakaleaf-wsl
SERVER_PRO=true
OVERLEAF_LISTEN_IP=127.0.0.1
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
DOCKER_SOCKET_PATH=/var/run/docker.sock
```

Varsayılan veri yollarını ve birlikte gelen MongoDB ve Redis hizmetlerini koruyun. `8080` portu yerel Windows tarayıcısı içindir; `127.0.0.1` adresine bağlamak onu yerel tutar. Korumalı alan derlemeleri, TeX'i uygulama konteyneri içinde çalıştırmak yerine her derleme için ayrı bir Linux konteyneri kullanır. Docker soketi uygulamanın bu konteynerleri oluşturmasını sağlar ve Toolkit, derleme verileri için `data/overleaf/data/compiles` altındaki ana bilgisayar yolunu sağlar.
</Step>

<Step title="Uygulama ayarları">
`config/variables.env` içinde, aynı adlara sahip etkin girdilerin yerine geçecek şekilde şu değerleri ayarlayın:

```dotenv title="config/variables.env"
OVERLEAF_SITE_URL=http://localhost:8080
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES="TeX Live 2026"
```

Tam (full) imaj, çok çeşitli projeler için gereken paketleri ve yazı tiplerini içerir. Bu imaj ve uygulama için en az 40 GB boş depolama alanı ve buna ek olarak proje verileri ile gelecekteki güncellemeler için yer ayırın.

Hızlı bir dağıtım testi için bunun yerine daha küçük **basic** imajı kullanın. 6. adımdaki basit makale testi için yeterlidir, ancak tam paket ve yazı tipi kümesini içermez:

```dotenv
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-basic:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-basic:2026.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES="TeX Live 2026 Basic"
```

Yinelenen etkin anahtarlar olmadan bu kümelerden birini seçin. Basic imajın [Dockerfile](https://github.com/ayaka-notes/texlive-full/blob/main/texlive/2026/Dockerfile.basic) dosyası `latexmk`, XeTeX ve `fontspec` içerir, ancak `ctex` veya tam yazı tipi koleksiyonunu içermez. Basic imajda eksik bir LaTeX paketi tek başına bir korumalı alan sorununa işaret etmez.

Bir oturum gizli anahtarı üretin:

```bash
openssl rand -hex 32
```

Sonucu `config/variables.env` içine `OVERLEAF_SESSION_SECRET` olarak ekleyin. Üretilen davet belirteci gizli anahtarını da saklayın. E-posta olmadan çalışan yerel bir örnek için SMTP ayarlarını ve `OVERLEAF_EMAIL_FROM_ADDRESS` değerini ayarlamadan bırakın.
</Step>

<Step title="Örneğinizi başlatın">
```bash
bin/up -d
```

Toolkit MongoDB'yi başlatır, replika kümesini başlatır, seçilen TeX Live imajını indirir ve Redis ile uygulamayı başlatır. Büyük bir imaj inerken duraklamış gibi görünebilir. İlki hâlâ çalışırken ikinci bir `bin/up` çalıştırmayın.

Başka bir Ubuntu terminalinde şunları kontrol edin:

```bash
cd "$HOME/ayakaleaf-toolkit"
bin/docker-compose ps
bin/docker-compose logs --tail=100 mongo
bin/docker-compose logs --tail=100 -f sharelatex
```

Günlükleri izlemeyi durdurmak için `Ctrl+C` tuşlarına basın; arka planda çalışan konteynerler çalışmaya devam eder. Başlatma MongoDB'de başarısız olursa yeniden denemeden önce [MongoDB başlamıyor](/tr/on-premises/installation/using-docker-compose/windows/troubleshooting#mongodb-fails-to-start) bölümünü izleyin. Mevcut bir kurulumu sıfırlamak için veri dizinini silmeyin.

Portu ve ilk çalıştırma sayfasını kontrol edin:

```bash
bin/docker-compose port sharelatex 80
curl -I http://localhost:8080/launchpad
```

Port `127.0.0.1:8080` olmalıdır. HTTP isteği başlangıçta başarısız olursa uygulamanın başlatılmasını bekleyin.
</Step>

<Step title="Örneği Windows'tan açın">
**Windows tarayıcınızda** [http://localhost:8080/launchpad](http://localhost:8080/launchpad) adresini açın. Windows'ta da geçici bir WSL IP adresi yerine bu adresi kullanın.

Windows HTTP erişimini tarayıcıdan ayrı olarak kontrol etmek için **PowerShell**'de şunu çalıştırın:

```powershell
curl.exe -I http://localhost:8080/launchpad
```

Ubuntu sayfaya ulaşabiliyor ancak Windows ulaşamıyorsa bkz. [Windows localhost'u açamıyor](/tr/on-premises/installation/using-docker-compose/windows/troubleshooting#windows-cannot-open-localhost).
</Step>
</Steps>
