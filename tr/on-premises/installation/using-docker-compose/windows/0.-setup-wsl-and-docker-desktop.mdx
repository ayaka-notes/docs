Ayakaleaf Pro, Linux konteynerlerini kullanır. Windows'ta Docker Desktop'ı WSL 2 arka ucuyla kurun ve Toolkit betiklerini Ubuntu'da çalıştırın.

WSL 2, Linux çekirdeğini sağlar. Docker Desktop, Docker motorunu kendi `docker-desktop` ortamında yönetir; **WSL Integration** seçeneğini etkinleştirmek, Ubuntu'daki Docker CLI'nin bu motorla iletişim kurmasını sağlar. Ardından Toolkit uygulamayı, MongoDB'yi ve Redis'i konteyner olarak başlatır. Korumalı alan derlemeleri etkinleştirildiğinde uygulama, her derleme için ayrı bir TeX Live konteyneri başlatmak üzere motorun Docker soketini kullanır. MongoDB, Redis veya TeX Live'ın Windows kurulumlarına ihtiyacınız yoktur.

<Steps>
<Step title="WSL 2 ve Ubuntu'yu kurun">
Windows'ta **PowerShell'i yönetici olarak** açın ve şunu çalıştırın:

```powershell
wsl --install -d Ubuntu
```

İstenirse Windows'u yeniden başlatın. Başlat menüsünden **Ubuntu**'yu açın ve bir Linux kullanıcı adı ile parolası oluşturun. Bu, Ubuntu içinde `sudo` için kullanılan hesaptır; Windows oturum açma bilgilerinizden ayrıdır.

**PowerShell**'e geri dönüp WSL'yi güncelleyin ve dağıtımı kontrol edin:

```powershell
wsl --update
wsl --version
wsl --list --verbose
```

Ubuntu satırı **VERSION 2** göstermelidir. 1 gösteriyorsa listedeki tam dağıtım adını kullanın:

```powershell
wsl --set-version Ubuntu 2
```

Docker, WSL **2.1.5 veya üzerini** gerektirir; `wsl --version` çıktısındaki WSL yazılım sürümü ile dağıtımın **VERSION 2** sütunu farklı kontrollerdir. Kurulum başarısız olursa [kurulum sorunlarını giderme](/tr/on-premises/installation/using-docker-compose/windows/troubleshooting#wsl-or-docker-reports-that-virtualization-is-unavailable) bölümüne ve [Microsoft'un kurulum talimatlarına](https://learn.microsoft.com/en-us/windows/wsl/install) bakın; WSL sanallaştırmanın kullanılamadığını bildirirse BIOS/UEFI'de donanım sanallaştırmasını etkinleştirin.
</Step>

<Step title="Docker Desktop'ı kurun ve başlatın">
İşlemciniz için [Docker Desktop for Windows](https://docs.docker.com/desktop/setup/install/windows-install/) sürümünü indirin ve yükleyiciyi çalıştırın. Sunulursa **WSL 2** arka ucunu kullanın. Windows Başlat menüsünden **Docker Desktop**'ı açın ve motorun başlamasını bekleyin.

Docker Desktop **Settings → General** içinde, seçenek gösteriliyorsa **Use WSL 2 based engine** seçeneğini etkinleştirin. **Settings → Resources → WSL Integration** altında **Ubuntu** için entegrasyonu etkinleştirin, ardından **Apply** veya **Apply & restart** seçeneğini seçin. Ubuntu varsayılan dağıtımınız değilse onun anahtarını açıkça etkinleştirin.

WSL Integration görünmüyorsa Docker Desktop'ın **Linux containers** kullandığını kontrol edin. Bkz. [Docker'ın WSL 2 arka uç kılavuzu](https://docs.docker.com/desktop/features/wsl/).

Bu kılavuz için Docker Desktop'ın entegrasyonunu kullanın. `apt install docker.io` ile ikinci bir Docker Engine kurmak veya Ubuntu içinde `dockerd` başlatmak ayrı bir kurulum oluşturur ve çakışmalara yol açabilir. Ubuntu'da zaten bir Engine kullanıyorsanız geçiş yapmadan önce Docker'ın geçiş talimatlarını izleyin; mevcut uygulama verilerini ve yedekleri koruyun.
</Step>

<Step title="Docker'ı Ubuntu'dan kontrol edin">
Bir **Ubuntu** terminali açın. Şu komutları orada, `sudo` olmadan çalıştırın:

```bash
docker version
docker compose version
docker ps
```

`docker version` hem **Client** hem de **Server** göstermelidir. Yeni bir kurulumda boş bir konteyner listesi normaldir. Tek başına `docker --version`, motorun çalıştığını kanıtlamaz.

`docker` kullanılamıyorsa veya bağlanamıyorsa WSL Integration'ı uyguladıktan sonra Ubuntu'yu yeniden açın ve Docker Desktop'ın çalıştığını kontrol edin. Bkz. [Sorun giderme](/tr/on-premises/installation/using-docker-compose/windows/troubleshooting#docker-is-unavailable-in-ubuntu).
</Step>

<Step title="Kaynakları ve Docker soketini kontrol edin">
Docker'ın görebildiği kaynakları kontrol edin:

```bash
docker info --format 'CPUs={{.NCPU}} Memory={{.MemTotal}} Kernel={{.KernelVersion}}'
df -h "$HOME"
ls -l /var/run/docker.sock
```

Küçük bir yerel örnek için Docker'a ayrılmış 4 CPU ve 8 GB bellek ölçülmüş bir alt sınır değil, önerilen bir başlangıç noktasıdır. Windows için de yeterli bellek bırakın. WSL 2 arka ucunda kaynak sınırları, Mac'teki Docker Desktop kaynak kaydırıcıları yerine [WSL ayarları](https://learn.microsoft.com/en-us/windows/wsl/wsl-config) üzerinden yönetilir. `wsl --shutdown` gerektiren değişiklikler çalışan tüm WSL dağıtımlarını ve Docker iş yüklerini kesintiye uğratır; bunları örneği başlatmadan önce uygulayın.

Toolkit yapılandırmasında `DOCKER_SOCKET_PATH=/var/run/docker.sock` ayarını olduğu gibi bırakın. Uygulamanın korumalı alan derlemeleri için bu motor soketine ihtiyacı vardır. Bağlantı hatalarını düzeltmek için izinlerini `777` olarak değiştirmeyin; bunun yerine Docker Desktop'ın entegrasyonunu geri yükleyin.
</Step>
</Steps>
