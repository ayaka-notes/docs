Toolkit, Linux'takiyle aynıdır. Yapısı, `config/` dizini ve `bin/` komutları Linux kılavuzunun [2. Toolkit'i tanıyın](/tr/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) bölümünde açıklanmıştır.

Windows'ta şu farkları aklınızda tutun:

* `bin/` komutlarını `~/ayakaleaf-toolkit` dizininden, **Ubuntu Bash** içinde çalıştırın. **PowerShell** olarak işaretlenen komutlar ise Windows'ta çalışır.
* `bin/up`, `bin/start` veya `bin/docker-compose` kullanmadan önce Docker Desktop'ı başlatın ve Ubuntu'nun WSL Integration'ını etkinleştirin.
* Yapılandırma dosyalarını Linux satır sonlarıyla (LF) tutun. Bunları Ubuntu'da `nano` ile veya WSL'ye bağlı bir düzenleyiciyle düzenleyin. CRLF satır sonları Bash hatalarına neden olabilir.
* `bin/doctor`, Ubuntu içinde Linux kontrollerini çalıştırır. `quay.io` oturumu açılmamasıyla ilgili uyarısı herkese açık `ghcr.io/ayaka-notes/overleaf-pro` imajı için geçerli değildir. Diğer uyarılar yine de ilgilenilmesi gereken uyarılardır.

```bash
bin/doctor
```
