<Steps>
<Step title="Git ve Homebrew'u kontrol edin">
```bash
git --version
brew --version
```

Git'i çalıştırdığınızda macOS sizden Command Line Tools'u kurmanızı isterse önce bunları kurun. Homebrew yoksa [resmi talimatlarla](https://brew.sh/) kurun.
</Step>

<Step title="GNU sed'i PATH'e ekleyin">
Toolkit betikleri, macOS'ta yerleşik olarak bulunan BSD sed'in reddettiği GNU sed seçeneklerini kullanır. [GNU sed](https://formulae.brew.sh/formula/gnu-sed) kurun ve bu terminalde `PATH` içinde en başa koyun:

```bash
brew install gnu-sed
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
sed --version
```

Son komut **GNU sed** yazdırmalıdır.

`alias sed=gsed` gibi bir takma ad yeterli değildir: Toolkit, etkileşimli kabuğunuzun takma adlarını görmeyen Bash betiklerini çalıştırır. `/usr/bin/sed` dosyasını değiştirmeniz gerekmez.

Toolkit için kullandığınız her yeni terminalde `export PATH=...` satırını yeniden çalıştırın veya bu satırı kabuk başlangıç dosyanıza, Homebrew'un kendi başlatma satırından sonra ekleyin.
</Step>

<Step title="Ayakaleaf Toolkit deposunu klonlayın">
Kalıcı bir dizin seçin. Canlı veritabanı ve proje verileri için `/tmp`, çıkarılabilir sürücüler ve iCloud Drive gibi bulutla senkronize edilen klasörlerden kaçının. Bu kılavuz `~/ayakaleaf-toolkit` dizinini kullanır:

```bash
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

<Warning>

Dizin zaten bir kurulum içeriyorsa onu olduğu gibi kullanın veya yeni bir örnek için başka bir dizin seçin. Mevcut bir dağıtımın üzerine yeni bir yapılandırma başlatmayın.

</Warning>
</Step>
</Steps>
