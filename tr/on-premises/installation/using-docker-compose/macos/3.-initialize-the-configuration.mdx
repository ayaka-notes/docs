---
title: 3. Yapılandırmayı başlatın
description: bin/init ile Mac'inizde Toolkit yapılandırma dosyalarını oluşturun.
icon: circle-play
---

Toolkit dizininden, GNU sed'in `PATH` üzerinde olduğu bir terminalde şunu çalıştırın:

```bash
bin/init
```

`bin/init` üç dosya oluşturur:

| Dosya | Amaç |
| --- | --- |
| `config/overleaf.rc` | Konteyner ayarları, yayımlanan port ve veri konumları |
| `config/variables.env` | Uygulama ayarları ve gizli anahtarlar |
| `config/version` | Uygulama imajı sürümü |

Ayrıca `config/variables.env` içinde `OVERLEAF_INVITE_TOKEN_SECRET` değerini üretir. Bu değeri saklayın; bu dosyayı yayımlamayın veya sürüm denetimine commit etmeyin.

Toolkit'in yeni bir kurulum için seçtiği sürümü koruyun. Mevcut bir örneğin sürümünü daha sonra değiştirmek için [Dağıtımınızı yükseltme](/tr/on-premises/maintenance/upgrading-your-deployment) kılavuzunu izleyin.

<Warning>

`bin/init`, `sed: ... invalid command code` hatasıyla durursa macOS'un BSD sed'i ile çalışmıştır. Bu şekilde başarısız olan bir çalıştırma, `config/` içindeki üç dosyanın tümünü boş bir `OVERLEAF_INVITE_TOKEN_SECRET` ile bırakabilir; bu durumda `bin/init` yeniden çalıştırıldığında `Config files already exist` bildirir. Bkz. [Sorun giderme](/tr/on-premises/installation/using-docker-compose/macos/troubleshooting#initialization-fails-with-invalid-command-code).

</Warning>
