Ayakaleaf Pro, Docker üzerinde çalışır. Mac'te Docker motorunu bir Linux sanal makinesinde çalıştıran Docker Desktop'ı kullanırsınız.

<Steps>
<Step title="Docker Desktop'ı kurun ve başlatın">
Mac'iniz için (Apple silicon veya Intel) uygun [Docker Desktop](https://docs.docker.com/desktop/setup/install/mac-install/) sürümünü kurun, açın ve motor başlayana kadar bekleyin. Terminal'den de başlatabilirsiniz:

```bash
open -a Docker
```
</Step>

<Step title="Docker motorunu kontrol edin">
Terminal'de şu komutları çalıştırın:

```bash
docker context show
docker info
docker compose version
```

Bağlam (context) yerel Docker Desktop motorunuzu, normalde `desktop-linux` bağlamını göstermelidir. Başka bir bağlam seçiliyse devam etmeden önce Docker Desktop'a geçin:

```bash
docker context use desktop-linux
```

`docker info` bir **Server** bölümü yazdırmalıdır. Tek başına `docker --version` yalnızca istemcinin kurulu olduğunu gösterir.
</Step>

<Step title="Kaynakları ve dosya paylaşımını kontrol edin">
Docker Desktop **Settings** içinde CPU, bellek ve disk sınırlarını [Başlamadan önce](/tr/on-premises/installation/using-docker-compose/macos#before-you-start) bölümüne göre, ayrıca dosya paylaşımı ayarlarını kontrol edin; bkz. [Docker Desktop ayarları](https://docs.docker.com/desktop/settings-and-maintenance/settings/).

Bu kılavuz Toolkit'i, Docker Desktop'ın varsayılan olarak paylaştığı `/Users` altında tutar. Başka bir konum kullanırsanız ve `bin/up` komutu `Mounts denied` hatasıyla başarısız olursa, o dizini dosya paylaşımına ekleyin.
</Step>

<Step title="Korumalı alan derlemeleri için Docker soketini kontrol edin">
Toolkit, her derleme için ayrı bir TeX Live konteyneri başlatabilmesi amacıyla `/var/run/docker.sock` soketini uygulamaya bağlar (mount). `config/overleaf.rc` içinde `DOCKER_SOCKET_PATH=/var/run/docker.sock` ayarını koruyun.

macOS'taki Docker CLI, `~/.docker/run/docker.sock` üzerinden bağlanabilir. Bu, Mac'teki istemci uç noktasıdır ve Toolkit'in bağlama kaynağını değiştirmek için bir neden değildir: derleyicinin, Linux konteynerlerinin gördüğü şekliyle motor soketine ihtiyacı vardır.

Mac'te `/var/run/docker.sock` yoksa **Settings → Advanced** altında **Allow the default Docker socket to be used** seçeneğini açın; bkz. [Docker'ın izin gereksinimleri](https://docs.docker.com/desktop/setup/install/mac-permission-requirements/).

<Danger>

Hataları aşmak için sokette `chmod 777` çalıştırmayın. Docker soketine erişim, Docker sanal makinesine root eşdeğeri erişim demektir.

</Danger>
</Step>
</Steps>
