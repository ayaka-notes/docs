### İlk yönetici hesabınızı oluşturma {#creating-your-first-administrator-account}

`OVERLEAF_SITE_URL` adresini ve ardından `/launchpad` yolunu açın, örneğin `http://192.0.2.10:30080/launchpad`, ve yönetici hesabını [Toolkit'in kurulum sonrası görevlerinde](/tr/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks) anlatıldığı gibi kaydedin. Ardından örnek bir proje oluşturun ve derleyin.

Kullanıcıları komut satırından da oluşturabilirsiniz:

```bash
kubectl -n overleaf exec deploy/overleaf -- bash -c \
  'cd /overleaf/services/web && node modules/server-ce-scripts/scripts/create-user.mjs --admin --email=admin@example.com'
```

Komut, parolayı belirlemek için bir bağlantı yazdırır.

### Derlemelerin sandbox içinde çalıştığını kontrol etme {#checking-that-compiles-are-sandboxed}

Bir projeyi derleyin, ardından pod'u çalıştıran düğüme bakın:

```bash
kubectl -n overleaf get pod -l app=overleaf -o wide   # NODE column
# on that node:
sudo docker ps -a --filter ancestor=ghcr.io/ayaka-notes/texlive-full:2026.1
ls -ln /srv/overleaf/compiles                          # owned by uid 33 (www-data)
```

Her derleme, `project-<project id>-<user id>-...` adlı kısa ömürlü bir konteyner olarak görünür.

### Günlükler ve kabuk {#logs-and-a-shell}

| Toolkit          | Kubernetes                                                               |
| ---------------- | ------------------------------------------------------------------------ |
| `bin/logs web`   | `kubectl -n overleaf exec deploy/overleaf -- tail -f /var/log/overleaf/web.log` |
| `bin/shell`      | `kubectl -n overleaf exec -it deploy/overleaf -- bash`                    |
| `bin/up`         | `kubectl apply -f .` ardından `kubectl -n overleaf rollout restart deployment/overleaf` |

Konteyner, `/var/log/overleaf/` içine hizmet başına bir günlük dosyası yazar (`web.log`, `clsi.log`, `real-time.log`, `document-updater.log`, ...); `kubectl logs` başlangıç çıktısını gösterir.
