---
title: 2. Ad alanını ve gizli anahtarları oluşturun
description: Ayakaleaf Pro'nun ihtiyaç duyduğu ad alanını ve gizli anahtarları oluşturun.
icon: key
---

Her şey `overleaf` ad alanına gider:

```bash
kubectl create namespace overleaf
```

Ayakaleaf Pro gizli anahtarlarını ortam değişkenlerinden okur. Bunları bir kez üretin ve bir Secret içinde saklayın:

```bash wrap
HISTORY=$(openssl rand -hex 32)
kubectl -n overleaf create secret generic overleaf-secrets \
  --from-literal=OVERLEAF_INVITE_TOKEN_SECRET="$(openssl rand -base64 32)" \
  --from-literal=OVERLEAF_SESSION_SECRET="$(openssl rand -hex 32)" \
  --from-literal=WEB_API_PASSWORD="$(openssl rand -hex 32)" \
  --from-literal=STAGING_PASSWORD="$HISTORY" \
  --from-literal=V1_HISTORY_PASSWORD="$HISTORY" \
  --from-literal=CRYPTO_RANDOM="$(openssl rand -hex 32)" \
  --from-literal=OT_JWT_AUTH_KEY="$(openssl rand -hex 32)"
```

| Gizli anahtar                                         | Neden                                                                                                                                                  |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_INVITE_TOKEN_SECRET`                 | Zorunlu. Bu olmadan pod "Missing required secrets" hatasıyla durur. Değiştirilmesi bekleyen proje davetlerini geçersiz kılar.                                 |
| `OVERLEAF_SESSION_SECRET`                      | Oturum çerezlerini imzalar. Bu olmadan pod'un her yeniden başlatılması herkesin oturumunu kapatır.                                                                 |
| `WEB_API_PASSWORD`, `CRYPTO_RANDOM`, `OT_JWT_AUTH_KEY` | Dahili gizli anahtarlar. Eksik olduklarında konteyner bunları her başlangıçta üretir; birden fazla replika varsa tüm replikalar bunları paylaşmalıdır. |
| `STAGING_PASSWORD` ve `V1_HISTORY_PASSWORD`   | Dahili geçmiş gizli anahtarı; ikisinin de **aynı** değere sahip olması gerekir.                                                                                           |

<Warning>

Secret'ı (`kubectl -n overleaf get secret overleaf-secrets -o yaml`) verilerinizle birlikte yedekleyin. MongoDB'de token şifreleyen özellikler de bu Secret içinde kendi şifreleme parolalarına ihtiyaç duyar; örneğin [GitHub Senkronizasyonu](/tr/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation) için `GITHUB_TOKEN_CIPHER_PASSWORD`.

</Warning>
