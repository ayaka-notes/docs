---
title: 4. Örneğinizi kişiselleştirme
description: Ayarlarınızı config/variables.env dosyasının yerini alan ConfigMap'e koyun.

`overleaf-env` ConfigMap'i, Toolkit'in `config/variables.env` dosyasının yerini alır: [Toolkit belgelerindeki](/tr/on-premises/configuration/overleaf-toolkit/environment-variables) her ortam değişkeni buraya, gizli anahtarlar ise [2. adımdaki](/tr/on-premises/installation/using-kubernetes/2.-create-the-namespace-and-secrets) Secret'a gider.

```yaml title="30-config.yaml" wrap
apiVersion: v1
kind: ConfigMap
metadata:
  name: overleaf-env
  namespace: overleaf
data:
  OVERLEAF_APP_NAME: Ayakaleaf Pro
  OVERLEAF_SITE_URL: http://192.0.2.10:30080      # the address users open; https://... behind TLS
  OVERLEAF_ADMIN_EMAIL: admin@example.com
  # Emails: add the sender and the SMTP server together, see Email delivery
  # All members, so that the driver finds the primary even when mongo-0 is down
  OVERLEAF_MONGO_URL: mongodb://mongo-0.mongo:27017,mongo-1.mongo:27017,mongo-2.mongo:27017/sharelatex?replicaSet=overleaf
  OVERLEAF_REDIS_HOST: redis
  REDIS_HOST: redis
  ENABLED_LINKED_FILE_TYPES: project_file,project_output_file,url
  ENABLE_CONVERSIONS: "true"
  EMAIL_CONFIRMATION_DISABLED: "true"
  # Requests arrive from kube-proxy or your ingress controller, inside the pod network
  OVERLEAF_TRUSTED_PROXY_IPS: loopback,10.244.0.0/16
  # Sandboxed compiles. The HOST_DIR paths are paths ON THE NODE: the hostPath volumes that
  # the Deployment mounts at /var/lib/overleaf/data/{compiles,output,cache}.
  SANDBOXED_COMPILES: "true"
  SANDBOXED_COMPILES_SIBLING_CONTAINERS: "true"
  DOCKER_RUNNER: "true"
  SANDBOXED_COMPILES_HOST_DIR_COMPILES: /srv/overleaf/compiles
  SANDBOXED_COMPILES_HOST_DIR_OUTPUT: /srv/overleaf/output
  SANDBOXED_COMPILES_HOST_DIR_CACHE: /srv/overleaf/cache
  # Each image must be pulled into Docker on every node that can run Ayakaleaf Pro (step 0)
  ALL_TEX_LIVE_DOCKER_IMAGES: ghcr.io/ayaka-notes/texlive-full:2026.1
  ALL_TEX_LIVE_DOCKER_IMAGE_NAMES: TeX Live 2026
  TEX_LIVE_DOCKER_IMAGE: ghcr.io/ayaka-notes/texlive-full:2026.1
```

```bash
kubectl apply -f 30-config.yaml
```

| Değişken                                | Ayarlanacak değer                                                                                                                                                       |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_SITE_URL`                     | Kullanıcıların tarayıcıya yazdığı URL. [5. adımdaki](/tr/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro) NodePort ile herhangi bir düğümün IP'si ve `30080` portu; bir ingress veya yük dengeleyicinin arkasında onun URL'si. |
| `OVERLEAF_MONGO_URL`                    | Replika kümeniz. `rs.initiate` içindeki adla `?replicaSet=` kullanın.                                                                                         |
| `OVERLEAF_REDIS_HOST` ve `REDIS_HOST`  | Her ikisi de Redis Service'ine.                                                                                                                                    |
| `OVERLEAF_TRUSTED_PROXY_IPS`            | `loopback` ile proxy'lerinizin bağlandığı ağlar. `10.244.0.0/16` flannel'ın pod ağıdır; kümenizin pod CIDR'ını kullanın.                               |
| `SANDBOXED_COMPILES_HOST_DIR_*`         | Derleme birimlerinin düğümdeki yolları. [5. adımdaki](/tr/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro) `hostPath` birimleriyle eşleşmelidir.                                       |

HTTPS arkasında ayrıca `OVERLEAF_SECURE_COOKIE: "true"` ayarlayın, bkz. [TLS proxy](/tr/on-premises/configuration/overleaf-toolkit/tls-proxy).

<Info>

Değiştirilen bir ConfigMap, çalışan pod'lara yalnızca yeniden başlatmadan sonra ulaşır: `kubectl -n overleaf rollout restart deployment/overleaf`.

</Info>
