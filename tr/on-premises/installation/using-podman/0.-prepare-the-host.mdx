---
title: 0. Ana makineyi hazırlayın
description: Rootless Podman'ı kurmadan önce işletim sistemini ve SELinux'u denetleyin ve git'i kurun.
icon: server
---

Podman'ı elle kurmazsınız: [2. podman-setup'ı çalıştırın](/tr/on-premises/installation/using-podman/2.-run-podman-setup) adımı onu ihtiyaç duyduğu diğer paketlerle birlikte kurar. Burada yalnızca ana makineyi denetler ve Toolkit'i indirmek için gereken `git`'i kurarsınız.

<Steps>
<Step title="İşletim sistemini ve SELinux'u denetleyin">
`root` olarak değil, Ayakaleaf Pro'yu çalıştıracak kullanıcı olarak oturum açın ve dağıtımı ve SELinux modunu denetleyin:

```bash title="Check the host"
grep PRETTY_NAME /etc/os-release
getenforce
```

Sürüm 9 veya sonrasıyla RHEL, Rocky Linux, AlmaLinux veya CentOS Stream ve `Enforcing` görmelisiniz:

```text
PRETTY_NAME="Rocky Linux 9.9 (Blue Onyx)"
Enforcing
```
</Step>

<Step title="sudo kullanabildiğinizi denetleyin">
`bin/podman-setup --apply`, paketleri kurar ve bir SELinux modülünü `sudo` ile yükler; gerektiğinde parolanızı sorar:

```bash title="Check sudo"
sudo -v
```

Bu başarısız olursa yöneticinizden kullanıcınızı `wheel` grubuna eklemesini isteyin.
</Step>

<Step title="git'i kurun">
```bash title="Install git"
sudo dnf install -y git
```

<Warning>

Bu ana makineye Docker Engine kurmayın. `bin/podman-setup`'ın kurduğu `podman-docker` paketi `docker` komutunu sağlar ve Toolkit, `podman` komutu mevcut olduğunda ana makineyi Podman olarak ele alır.

</Warning>
</Step>
</Steps>
