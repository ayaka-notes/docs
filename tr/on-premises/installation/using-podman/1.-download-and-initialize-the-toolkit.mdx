<Steps>
<Step title="Toolkit'i klonlayın">
**Ayakaleaf Toolkit**'i ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)) ana dizininize klonlayın ve içine geçin:

```bash title="Clone the Toolkit" wrap
git clone https://github.com/ayaka-notes/toolkit.git ~/overleaf-toolkit
cd ~/overleaf-toolkit
```

Sonraki tüm komutları bu dizinden çalıştırın.
</Step>

<Step title="Yapılandırmayı oluşturun">
```bash title="Run initialization"
bin/init
```

Bu komut, Docker kılavuzundaki [3. Yapılandırmayı başlatın](/tr/on-premises/installation/using-docker-compose/linux/3.-initialize-the-configuration) adımında açıklandığı gibi `config/overleaf.rc`, `config/variables.env` ve `config/version` dosyalarını oluşturur. `bin/init` henüz Podman'a ihtiyaç duymaz.
</Step>

<Step title="config/overleaf.rc dosyasını ayarlayın">
`config/overleaf.rc` dosyasını açın ve şu satırları değiştirin:

```bash title="config/overleaf.rc"
SERVER_PRO=true
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
```

Ardından dosyanın sonuna şu satırı ekleyin:

```bash title="config/overleaf.rc"
SELINUX_MODE=managed
```

| Ayar                              | Neden                                                                                                                                                                                                        |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `SERVER_PRO=true`                 | `ghcr.io` üzerindeki Ayakaleaf Pro imajını kullanır. Oturum açmak gerekmez.                                                                                                                                  |
| `OVERLEAF_PORT=8080`              | Rootless Podman, `1024` altındaki bağlantı noktalarını dinleyemez. Varsayılan `80` başarısız olur.                                                                                                            |
| `SIBLING_CONTAINERS_ENABLED=true` | Her derlemeyi kendi TeX Live konteynerinde çalıştırır. Varsayılan olarak zaten `true`; Podman kurulumu yalnızca bu modu destekler.                                                                            |
| `SELINUX_MODE=managed`            | `sharelatex` konteynerini, Podman soketini kullanabilen ve başka hiçbir şeye erişemeyen `sharelatex_t` SELinux türüyle çalıştırır. `bin/podman-setup --apply` bunun için ilke modülünü kurar. Diğer modlar için [Toolkit ayarları](/tr/on-premises/configuration/overleaf-toolkit/toolkit-settings) sayfasına bakın. |

`DOCKER_SOCKET_PATH`'i olduğu gibi bırakın: `bin/podman-setup --apply` bir sonraki adımda onu Podman soketinize ayarlar.

<Warning>

`GIT_BRIDGE_ENABLED=false` olarak bırakın. Ayakaleaf Pro 6.3.4'te Git entegrasyonu Podman üzerinde çalışmaz, bkz. [Bilinen sınırlamalar](/tr/on-premises/installation/using-podman#known-limitations).

</Warning>
</Step>

<Step title="TeX Live imajlarını seçin">
`config/variables.env` dosyasını açın, `TEX_LIVE_DOCKER_IMAGE` ve `ALL_TEX_LIVE_DOCKER_IMAGES` önündeki `#` işaretini kaldırın ve kullanılacak TeX Live imajlarını listeleyin:

```bash title="config/variables.env" wrap
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
```

Liste boşsa `bin/up`, `Please configure ALL_TEX_LIVE_DOCKER_IMAGES` mesajıyla durur. `texlive-full` büyüktür; bir test sunucusu için çok daha küçük olan `ghcr.io/ayaka-notes/texlive-basic:2026.1` de işe yarar. Kullanılabilir imajlar için [Sandbox Derlemeleri](/tr/on-premises/configuration/overleaf-toolkit/sandboxed-compiles) sayfasına bakın.

`OVERLEAF_SITE_URL` gibi diğer değişkenleri [5. Örneğinizi kişiselleştirme](/tr/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance#required-environment-variables) bölümünde açıklandığı gibi ayarlayın. Varsayılan dinleme adresiyle `http://localhost:8080` kullanın.
</Step>
</Steps>
