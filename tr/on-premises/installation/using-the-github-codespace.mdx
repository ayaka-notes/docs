Ayakaleaf Pro'yu denemenin en kolay yolu GitHub Codespace kullanmaktır; burada tüm ortam değişkenleri önceden yapılandırılmıştır, böylece kutudan çıktığı gibi kullanabilirsiniz.

<Warning>

GitHub Codespaces ile Docker konteynerleri çalıştırdığınızda Codespace otomatik olarak kapanmaz ve **ücretlendirilmeye** devam eder. GitHub Codespaces faturalandırma kuralları için lütfen [github codespaces billing rules](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces) sayfasına bakın.

GitHub Codespaces'inizi yönetmek için lütfen [https://github.com/codespaces](https://github.com/codespaces) adresini ziyaret edin. Artık ihtiyacınız olmadığında lütfen Codespace'inizi zamanında silin.

</Warning>

Aşağıdaki özellikleri **önceden yapılandırdık**:

* [x] TeXLive **Basic** (2024-2026) ile korumalı alanda (sandbox) LaTeX derlemesi
* [x] Pandoc İçe/Dışa Aktarma (SaaS Platformundaki özellikler)
* [x] Python Betik Çalıştırıcı (SaaS Platformundaki özellikler)
* [x] Git-Bridge Desteği (Server Pro'daki özellikler)
* [x] Gelişmiş Kaynakça Arama (SaaS Platformundaki özellikler)
* [x] Yönetici Paneli (Genel Kullanıcı/Proje yönetimi)
* [x] Değişiklikleri İzleme (İnceleme ve Yorum Paneli ile)
* [x] Tam Proje Geçmişi (Geri Yükleme ve İndirme ile)
* [x] Symbol Palette (Server Pro/SaaS Platformundaki özellikler)

<Warning>

Standart GitHub Codespaces 32 GB depolama alanı sağlar. Bu, `texlive-full` kurulumumuz için yetersizdir. Tam imajı denemek için, büyük çalıştırıcılara (8 çekirdek+) sahip bir Codespace talebiyle GitHub destek kaydı oluşturun.

</Warning>

GitHub Sync, LDAP, OAuth, SSO, Zotero Entegrasyonu ve diğer özellikler bu deneme ortamında _**yapılandırılmamıştır**_. Bu özellikleri kendi dağıtımınızda nasıl yapılandıracağınıza ilişkin daha fazla ayrıntı için [toolkit ayarlarına](/tr/on-premises/configuration/overleaf-toolkit/toolkit-settings) bakabilirsiniz.

#### TeXLive Full İmajını Kullanma

8 çekirdek/64 GB GitHub Codespaces'e erişiminiz varsa, bu deneme ortamında TeXLive Full imajını kullanabilirsiniz. TeXLive Basic imajı yerine TeXLive Full imajını kullanmak için `toolkit/config/variables.env` dosyasında aşağıdaki ortam değişkenlerini değiştirebilirsiniz.

```dotenv wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1, ghcr.io/ayaka-notes/texlive-full:2024.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025, Texlive 2024
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```

Ortam değişkenlerini değiştirdikten sonra, değişiklikleri uygulamak için toolkit'i yeniden başlatmanız gerekir. Toolkit'i yeniden başlatmak için aşağıdaki komutu çalıştırabilirsiniz.

```bash
cd toolkit && bin/up -d
```
