Overleaf, Docker üzerinde çalışır. Şunları kurmanız gerekir:

* Docker Engine (Docker CE)
* Docker Compose eklentisi (`docker compose`, v2)

Bu adımlar güncel bir Ubuntu LTS sürümünü (20.04/22.04/24.04) hedefler.

<Warning>

`docker.io` paketini Ubuntu'nun varsayılan apt deposundan kurmaktan kaçının.\
Güncel bir Docker sürümü ve `docker compose` eklentisini edinmek için Docker'ın resmi deposunu kullanın.

</Warning>

Resmi belge şu adrestedir: [https://docs.docker.com/engine/install/ubuntu/](https://docs.docker.com/engine/install/ubuntu/).

<Steps>
<Step title="1) Eski/çakışan paketleri kaldırın (varsa)">
Docker daha önce başka bir kaynaktan kurulduysa önce onu kaldırın:

```bash wrap
sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-compose-v2 docker-doc podman-docker containerd runc | cut -f1)
```

Bazı paketler kurulu olmasa bile bu komutu çalıştırmak güvenlidir.
</Step>

<Step title="2) Docker'ın resmi apt deposunu ekleyin">
Ön koşulları kurun:

```bash
sudo apt update
sudo apt install -y ca-certificates curl
```

Docker GPG anahtarını ekleyin:

```bash wrap
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```

Depoyu ekleyin:

```bash wrap
# Add the repository to Apt sources:
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Signed-By: /etc/apt/keyrings/docker.asc
EOF

sudo apt update
```
</Step>

<Step title="3) Docker Engine + Compose eklentisini kurun">
Docker'ı ve Compose eklentisini kurun:

```bash wrap
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

Docker'ı sistem açılışında başlatın:

```bash
sudo systemctl enable --now docker
```
</Step>

<Step title="4) Kurulumu doğrulayın">
Bu komutlar hatasız çalışmalıdır:

```bash
docker --version
docker compose version
sudo docker run --rm hello-world
docker ps
```
</Step>

<Step title="5) (İsteğe bağlı) Docker'ı sudo olmadan çalıştırın">
Kullanıcınızı `docker` grubuna ekleyin:

```bash
sudo usermod -aG docker $USER
```

Ardından **oturumu kapatıp yeniden açın** veya şunu çalıştırın:

```bash
newgrp docker
```

Artık bu komut `sudo` olmadan çalışmalıdır:

```bash
docker ps
```

<Danger>

`docker` grubu, ana makinede root ile eşdeğer erişime sahiptir.\
Bu, tipik Overleaf kurulumları için beklenen bir durumdur ve özellikle Sandboxed Compiles özelliğini etkinleştirirseniz önem taşır.

</Danger>
</Step>
</Steps>
