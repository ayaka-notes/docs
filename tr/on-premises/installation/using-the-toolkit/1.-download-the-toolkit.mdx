### Toolkit'i indirme

Toolkit hem Server CE hem de Ayakaleaf Pro ile uyumludur ve önerilen kurulum yöntemidir. Toolkit'i kullanmak, Server CE ile kolayca başlamanızı ve gerektiğinde Ayakaleaf Pro'ya sorunsuzca yükseltmenizi sağlar.

<Info>

[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit), overleaf-pro imajını doğrudan ghcr üzerinden kullanacak şekilde değiştirilmiştir; TeX Live ise ayaka-notes tarafından sağlanır. Alternatif olarak resmi overleaf-toolkit'i de indirebilirsiniz.

</Info>

<Steps>
<Step title="Overleaf Toolkit deposunu klonlayın">
Toolkit'i kurmak için hedeflenen kurulum yoluna gitmeniz ve ardından şu komutla Overleaf Toolkit (@Ayaka-notes) GitHub deposunu klonlamanız gerekir:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
# official toolkit (Not Recommended)
# git clone https://github.com/overleaf/toolkit.git ./overleaf-toolkit
```

<Info>

Olası izin sorunlarını önlemek için Toolkit'i kullanıcınızın `$HOME` dizinine kurmanızı öneririz.

</Info>
</Step>

<Step title="Toolkit dizinine geçin">
Klonlama işleminin tamamlanmasını bekleyin, ardından yeni oluşturulan `overleaf-toolkit` dizinine geçelim:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
