### İşletim sistemleri {#operating-systems}

Paylaşılan sunucular ve üretim sunucuları için **Ubuntu** gibi **Debian tabanlı bir Linux** sistemi öneririz. Ayakaleaf Pro ayrıca [Docker Desktop ile macOS](/tr/on-premises/installation/using-docker-compose/macos) ve [WSL 2 ve Docker Desktop ile Windows](/tr/on-premises/installation/using-docker-compose/windows) üzerinde de çalışabilir. Üç platformun tümü Linux konteynerlerini ve aynı Toolkit'i kullanır; ana bilgisayarınızın işletim sistemine uygun kılavuzu izleyin.

<Danger>

Sandboxed Compiles kullanırken, uygulamanın Docker soketine root erişimi gerektirdiğini unutmamak **önemlidir**.

</Danger>

### Bağımlılıklar {#dependencies}

* Docker 25.0 ve 29
* MongoDB 7.0 ve 8.0
* Redis 6.2 ve 7.5

<Info>

Yukarıdaki bağımlılıkların ve diğer popüler ürünlerin kullanım ömrü sonu (End-of-Life, EOL) tarihlerini endoflife.date hizmetini kullanarak buradan takip edebilirsiniz: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

Farklı bir kurulum kullanacak şekilde yapılandırılmadıkça, Ayakaleaf Pro çalıştırılırken MongoDB ve Redis `docker compose` tarafından otomatik olarak çekilir.

</Info>

Toolkit aşağıdaki programlara bağlıdır:

* bash
* Docker

`docker compose` gereklidir ve genellikle Docker ile birlikte kurulur.

İşletim sisteminiz için mevcut olan en güncel Docker sürümünü kurmanızı öneririz.

Docker doğru şekilde kurulduktan sonra, aşağıdaki komutları hatasız çalıştırabilmeniz gerekir:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2 or later, such as v5)
docker compose version

# List the running Docker containers on your system
docker ps
```
