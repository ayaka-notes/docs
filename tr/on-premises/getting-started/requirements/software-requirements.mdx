### İşletim sistemleri

Overleaf'i çalıştırırken en iyi deneyim için **Ubuntu** gibi **Debian tabanlı** bir işletim sistemi kullanmanızı önemle tavsiye ederiz. Bu tercih, yazılımın geliştirme ortamıyla uyumludur ve Overleaf kullanıcılarının büyük çoğunluğu tarafından tercih edilen seçenektir.

<Danger>

Server Pro'yu Sandboxed Compiles ile kullanırken, uygulamanın Docker soketine root erişimi gerektirdiğini unutmamak **önemlidir**.

</Danger>

### Bağımlılıklar

* Docker 25.0 ve 29
* MongoDB 7.0 ve 8.0
* Redis 6.2 ve 7.5

<Info>

Yukarıdaki bağımlılıkların ve diğer popüler ürünlerin kullanım ömrü sonu (End-of-Life, EOL) tarihlerini endoflife.date hizmetini kullanarak buradan takip edebilirsiniz: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

Farklı bir kurulum kullanacak şekilde yapılandırılmadıkça, Server CE veya Server Pro çalıştırılırken MongoDB ve Redis `docker compose` tarafından otomatik olarak çekilir.

</Info>

Toolkit aşağıdaki programlara bağlıdır:

* bash
* Docker

`docker compose` gereklidir ve genellikle Docker ile birlikte kurulur.

İşletim sisteminiz için mevcut olan en güncel Docker sürümünü kurmanızı öneririz.

Docker doğru şekilde kurulduktan sonra, aşağıdaki komutları hatasız çalıştırabilmeniz gerekir:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2)
docker compose version

# List the running Docker containers on your system
docker ps
```
