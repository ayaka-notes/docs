Hizmetlerin günlüklerini görüntülemek için `bin/logs` betiğini kullanabilirsiniz.

Temel kullanım örnekleri:

```bash
# View the web service logs
bin/logs web

# Show help
bin/logs --help

# View logs for multiple services at once
bin/logs filestore docstore web clsi

# Follow log output (like tail -f)
bin/logs -f filestore docstore web clsi

# Limit the number of lines printed (default 50)
bin/logs -n 50 web

# Show all log lines
bin/logs -n all web

# Redirect output to a file
bin/logs -n all web > web.log
```

`bin/logs` betiğini şu hizmetlerin günlüklerini görüntülemek için kullanabilirsiniz: `clsi`, `contacts`, `docstore`, `document-updater`, `filestore`, `git-bridge`, `mongo`, `notifications`, `real-time`, `redis`, `spelling`, `tags`, `track-changes`, `web`, `web-api`, `history-v1`, `project-history`.

## Günlükleri kopyalama

Orijinal belgelere bakın: https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/logging#copying-logs

Günlük dosyalarını ana `sharelatex` kapsayıcısından yerel bilgisayarınıza kopyalayın:

```bash
docker cp sharelatex:/var/log/overleaf/{service-name}.log {service-name}.log
```

## Günlükleri kalıcı hâle getirme

Docker kapsayıcıları geçicidir; yani çalışma zamanında kapsayıcının içinde oluşturulan dosyalar/dizinler (günlük dosyaları dahil), kapsayıcı yeniden oluşturulduğunda (örneğin `bin/up` çalıştırıldığında) silinir. Günlük dosyalarını kapsayıcının yeniden oluşturulmaları arasında korumak için:

* Toolkit tarafından kullanılan `config/overleaf.rc` dosyasında `OVERLEAF_LOG_PATH` ortam değişkenini ayarlayın. Bu, ana makinede `sharelatex` kapsayıcısının içindeki günlük dizinine bind-mount edilecek dizin olmalıdır.
* Bunu değiştirip `bin/up -d` komutunu çalıştırdıktan sonra günlük dosyaları ana makinede kalıcı olarak saklanır ve doğrudan erişilebilir olur.

<Warning>

Bind-mount için kullanılan ana makine günlük dizininin sahibini `www-data` kullanıcısı (uid=33) olarak ayarlamalı ve izinlerin `drwxr-xr-x` (755) olduğundan emin olmalısınız.

Örnek:

```bash
chown 33:33 data/overleaf/logs
chmod 755 data/overleaf/logs
```

</Warning>
