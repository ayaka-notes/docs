### Başlık

Bu bölümde, şirket içi kurulumunuzun temel öğelerini nasıl kişiselleştireceğinizi ele alacağız. Site başlığını, gezinme bağlantılarını, üst bilgiyi, alt bilgiyi ve logoyu tercihlerinize göre özelleştirebilirsiniz.

### Site başlığı

Gezinme çubuğu başlığı `OVERLEAF_NAV_TITLE` ortam değişkeniyle özelleştirilebilir; logo ayarlanmamışsa bu metin gezinme çubuğunun sol üst köşesinde kullanılır.

```bash
# add to config/variables.env
OVERLEAF_NAV_TITLE=Our Overleaf Instance
```

## Logo

`OVERLEAF_HEADER_IMAGE_URL` ortam değişkenini ayarlayarak metin yerine özel bir logo ekleyebilirsiniz. Bu değer harici olarak barındırılan bir görsel dosyasını göstermelidir.

```bash title="config/variables.env"
# add to config/variables.env
OVERLEAF_HEADER_IMAGE_URL=https://mysite.somewhere.com/img/logo.png
```

#### Açık ve koyu tema logoları

6.3.0 sürümünden itibaren `OVERLEAF_HEADER_IMAGE_URL_LIGHT` ve `OVERLEAF_HEADER_IMAGE_URL_DARK` ortam değişkenleriyle açık ve koyu temalar için ayrı logolar ayarlayabilirsiniz. Her iki değer de harici olarak barındırılan bir görsel dosyasını göstermelidir.

```text
# add to config/variables.env
OVERLEAF_HEADER_IMAGE_URL_LIGHT=https://mysite.somewhere.com/img/logo-light.png
OVERLEAF_HEADER_IMAGE_URL_DARK=https://mysite.somewhere.com/img/logo-dark.png
```

<Info>

Değişkenlerden biri ayarlanmamışsa, ilgili tema `OVERLEAF_HEADER_IMAGE_URL` içinde ayarlanan logoya geri döner.

</Info>

## Üst bilgi gezinme bağlantıları

`OVERLEAF_HEADER_EXTRAS` ortam değişkenine nesnelerden oluşan bir JSON dizisi atanarak gezinme üst bilgisine ek gezinme öğeleri eklenebilir. Örneğin:

```json wrap
[\
  {\
    "text": "Some link",\
    "url": "http://example.com/somelink",\
    "class": "subdued",\
    "only_when_logged_out": true\
  },\
  {\
    "text": "Help",\
    "class": "subdued",\
    "dropdown": [\
      {\
        "text": "Documentation",\
        "url": "/learn"\
      },\
      {\
        "text": "Contact Admin",\
        "url": "http://example.com/contact"\
      }\
    ]\
  }\
]
```

Kaçış karakterleri uygulanmış JSON biçimini toolkit/variables.env dosyasına ekleyin:

```bash title="toolkit/variables.env" wrap
# add to toolkit/variables.env
OVERLEAF_HEADER_EXTRAS=[{"text":"Some link","url":"http://example.com/somelink","class":"subdued","only_when_logged_out":true},{"text":"Help","class":"subdued","dropdown":[{"text":"Documentation","url":"/learn"},{"text":"Contact Admin","url":"http://example.com/contact"}]}]
```

## Alt bilgiler

Hem soldaki hem de daha küçük olan sağdaki alt bilgiyi (`/project` gibi sayfalarda bulunur) `OVERLEAF_LEFT_FOOTER` ve `OVERLEAF_RIGHT_FOOTER` ortam değişkenleriyle özelleştirmek mümkündür. Her ikisi de eklenecek JSON nesnelerinden oluşan bir dizi bekler.

Her ikisi de eklenecek bir JSON dizisi bekler.

```json
[\
  {\
    "text": "This is an example text footer entry!"\
  },\
  {\
    "text": "This is an example URL footer link!", "url" : "/my-first-link.htm"\
  }\
]
```

<Info>

Yalnızca `text` kullanıldığında, değer ham metin olarak işleneceğinden HTML içermemelidir.

</Info>

Bu verinin çalışması için geçerli JSON olması ve ortam değişkeni olarak aktarılırken tırnak işaretlerinin kaçış karakteriyle yazılması gerekir.

```bash title="config/variables.env" wrap
# add to config/variables.env
OVERLEAF_LEFT_FOOTER=[{"text": "This is an example text footer entry!"}]
OVERLEAF_RIGHT_FOOTER=["text": "This is an example URL footer link!", "url" : "/my-first-link.htm"]
```

<Info>

JSON nesnesi, `text` ve `url` özelliklerine ek olarak ek özelleştirme için `class` ve `label` özelliklerini de kabul eder.

</Info>

### Bakım sayfası

Bakım sayfasında gösterilen mesajı `OVERLEAF_MAINTENANCE_MESSAGE` ortam değişkeniyle özelleştirebilirsiniz; bu metin, sayfa başlığının altındaki varsayılan mesajın yerini alır.

```text wrap
# add to config/variables.env
OVERLEAF_MAINTENANCE_MESSAGE=Our Overleaf Instance is down for maintenance and will be back shortly.
```

Bağlantı veya başka biçimlendirmeler eklemek için bunun yerine `OVERLEAF_MAINTENANCE_MESSAGE_HTML` kullanın. Her ikisi de ayarlanmışsa `OVERLEAF_MAINTENANCE_MESSAGE_HTML` önceliklidir.

```text wrap
# add to config/variables.env
OVERLEAF_MAINTENANCE_MESSAGE_HTML=Our Overleaf Instance is down for maintenance. For urgent requests, contact <a href="mailto:admin@example.com">admin@example.com</a>.
```

<Info>

`OVERLEAF_MAINTENANCE_MESSAGE` düz metin olarak işlenir, bu nedenle HTML **içermemelidir**. `OVERLEAF_MAINTENANCE_MESSAGE_HTML` ise kaçış uygulanmadan HTML olarak işlenir.

</Info>

Hiçbiri ayarlanmamışsa, varsayılan mesaj `OVERLEAF_STATUS_PAGE_URL` ayarlandığında durum sayfanıza bağlantı verir, ayarlanmadığında ise yönetici e-posta adresini gösterir.
