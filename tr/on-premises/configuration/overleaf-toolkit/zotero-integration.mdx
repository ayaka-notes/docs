### Zotero Entegrasyonunu Kurma

1. Bir Zotero OAuth istemcisi oluşturmak için [bu bağlantıyı](https://www.zotero.org/oauth/apps) açın (görselde gösterildiği gibi)
2. **Application Type** olarak **Browser** seçin
3. Callback URL'yi `${OVERLEAF_SITE_URL}/user/zotero/oauth/callback` olarak ayarlayın
4. `config/variables.env` dosyanızı yapılandırın

<Frame>
  <img src="/images/on-premises/image-41.png" alt="" width="375" />
</Frame>

```dotenv title="config/variables.env"
#################
#    Zotero     #
#################
# 'zotero' must be in ENABLED_LINKED_FILE_TYPES (set in develop/docker-compose.yml)
ENABLED_LINKED_FILE_TYPES=project_file,project_output_file,url,zotero

# From a Zotero OAuth client (register at https://www.zotero.org/oauth/apps)
# Application Type: Browser 
# Callback URL -> ${OVERLEAF_SITE_URL}/user/zotero/oauth/callback
ZOTERO_CLIENT_ID=
ZOTERO_CLIENT_SECRET=
# Encrypts the Zotero API key in mongo (set in dev to avoid writing a key file
# to /var/lib/overleaf/data, which the dev web container can't create)
# How to generate: `openssl rand -hex 32`
ZOTERO_CIPHER_PASSWORD=dev-zotero-cipher-password
# Optional: route the module's server-side Zotero requests (OAuth + API) through
# an HTTP proxy (must be reachable from the web container; same as github-sync)
# http://10.0.0.1:10808
# (Optional) ZOTERO_PROXY_URL=
```

### Notlar

<Warning>

Zotero'ya bağlı kaynakça dosyaları içeren mevcut bir kurulumu yeniden yayımlanan 6.3.0 sürümüne yükseltirken [Zotero / Mendeley geçiş talimatlarını](/tr/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention") izleyin. Yeni kurulumların bu geçişe ihtiyacı yoktur.

</Warning>

<Danger>

Ayakaleaf işbirliğine dayalı bir platform olduğundan, güvenliği artırmak için 6.3.0 sürümünden itibaren içe aktarılan dosyayı yalnızca Reference `bib` dosyasının asıl oluşturucusu güncelleyebilecektir.

</Danger>

Örneğin, proje sahibi Kullanıcı A'nın bağlantı paylaşımını etkinleştirdiğini ve projede kendi Zotero hesabına bağlı bir `test.bib` dosyası oluşturduğunu varsayalım. Başka bir kullanıcı, Kullanıcı B, projeye paylaşılan bağlantı üzerinden erişirse `test.bib` dosyasını okuyabilir ve indirebilir, ancak dosyayı güncellemesine veya Zotero'dan yeniden içe aktarmasına izin verilmez. Güncellemeleri yalnızca Reference dosyasının asıl oluşturucusu olan Kullanıcı A yapabilir. Başka bir deyişle, `.bib` dosyasını güncelleme izni yalnızca dosyanın asıl oluşturucusuna aittir.
