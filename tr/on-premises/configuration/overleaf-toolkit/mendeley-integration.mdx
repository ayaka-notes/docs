<Info>

Bu özellik [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/overleaf-pro) tarafından OAuth 2.0 desteğiyle sağlanır ve v6.3.0'dan itibaren kullanılabilir. Herhangi bir sorunla karşılaşırsanız geri bildirimlerinizi bekliyoruz.

</Info>

#### Mendeley Entegrasyonunu Kurma

1. Bir Mendeley OAuth uygulaması kaydetmek için [bu bağlantıya](https://dev.mendeley.com/myapps.html) gidin
2. **Redirect URL** değerini şu şekilde yapılandırın: `${OVERLEAF_SITE_URL}/user/mendeley/oauth/callback`
3. Uygulamanızın oluşturulan **ID** değerini (genellikle aşağıdaki `24061` gibi sayısaldır) ve **Secret** değerini not edin
4. `config/variables.env` dosyanızı düzenleyin&#x20;
5. Authorisation Flow değerini Elsevier olarak bırakın (önerildiği gibi)

```dotenv title="config/variables.env"
#################
#   Mendeley    #
#################
# 'mendeley' must be in ENABLED_LINKED_FILE_TYPES (keep 'zotero' too if you use both)
ENABLED_LINKED_FILE_TYPES=project_file,project_output_file,url,mendeley

# From a Mendeley OAuth application (register at https://dev.mendeley.com/myapps.html)
# Redirect URL -> ${OVERLEAF_SITE_URL}/user/mendeley/oauth/callback
MENDELEY_CLIENT_ID=
MENDELEY_CLIENT_SECRET=
# Encrypts the Mendeley OAuth tokens in mongo; if unset, a key file is generated
# in /var/lib/overleaf/data on first use
# How to generate: `openssl rand -hex 32`
MENDELEY_CIPHER_PASSWORD=
# Optional: route the module's server-side Mendeley requests (OAuth + API) through
# an HTTP proxy (must be reachable from the web container; same as github-sync)
# http://10.0.0.1:10808
# (Optional) MENDELEY_PROXY_URL=
```

<Info>

&#x20;`mendeley`, `ENABLED_LINKED_FILE_TYPES` içinde yer almalıdır (ikisini birlikte kullanıyorsanız `zotero`'yu da listede tutun). `MENDELEY_CLIENT_ID` ve `MENDELEY_CLIENT_SECRET` kayıtlı OAuth uygulamanızdan gelir. Şifreleme parolası, MongoDB'deki Mendeley OAuth belirteçlerini şifreler (`openssl rand -hex 32` ile bir tane oluşturun); bu olmadan ilk kullanımda veri biriminde bir anahtar dosyası oluşturulur. İsteğe bağlı olarak, sunucu tarafındaki Mendeley isteklerini (OAuth + API) web kapsayıcısından erişilebilen bir HTTP proxy üzerinden yönlendirmek için `MENDELEY_PROXY_URL` değerini ayarlayın.

</Info>

### Notlar

<Warning>

Mendeley'e bağlı kaynakça dosyaları bulunan mevcut bir kurulumu yeniden yayınlanan 6.3.0 sürümüne yükseltirken [Zotero / Mendeley geçiş talimatlarını](/tr/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention") izleyin. Yeni kurulumların bu geçişe ihtiyacı yoktur.

</Warning>

<Danger>

Ayakaleaf ortak çalışmaya dayalı bir platform olduğundan, güvenliği artırmak için 6.3.0 sürümünden itibaren içe aktarılan bir kaynakça `bib` dosyasını yalnızca onu ilk oluşturan kişi güncelleyebilecektir.

</Danger>

Örneğin, proje sahibi Kullanıcı A'nın bağlantı paylaşımını etkinleştirdiğini ve projede kendi Zotero hesabına bağlı bir `test.bib` dosyası oluşturduğunu varsayalım. Başka bir kullanıcı olan Kullanıcı B projeye paylaşılan bağlantı üzerinden erişirse, `test.bib` dosyasını yine okuyup indirebilir, ancak dosyayı Zotero'dan güncellemesine veya yeniden içe aktarmasına izin verilmez. Güncellemeleri yalnızca kaynakça dosyasını ilk oluşturan Kullanıcı A yapabilir. Başka bir deyişle, `.bib` dosyasını güncelleme izni yalnızca onu ilk oluşturan kişiye aittir.
