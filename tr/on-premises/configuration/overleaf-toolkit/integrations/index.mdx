Overleaf Import API dışında her entegrasyon varsayılan olarak kapalıdır. GitHub, GitLab, Gitea ve Dropbox Senkronizasyonu ile MCP sunucusu ayrıca [Git entegrasyonunu](/tr/on-premises/configuration/overleaf-toolkit/integrations/git-integration) gerektirir. Birini etkinleştirdikten sonra kapsayıcıları `bin/up -d` ile yeniden oluşturun.
