Her projenin bir MCP sunucusu vardır; böylece Claude Code, Codex, Cursor, VS Code veya Gemini CLI gibi yapay zekâ istemcileri proje üzerinde çalışabilir: dosyalarını okuyup düzenleyebilir, projeyi derleyebilir, LaTeX günlüğünü okuyabilir, PDF'i indirebilir ve yorumları yanıtlayabilir.

### Kurulum

MCP sunucusu Git entegrasyonuyla birlikte gelir: [git-bridge](/tr/on-premises/configuration/overleaf-toolkit/integrations/git-integration) özelliğini etkinleştirdiğinizde MCP sunucusu da kullanılabilir hâle gelir. Yapılandırmanız gereken başka bir şey yoktur.

### Bir yapay zekâ istemcisini bağlama

1. **Account Settings** bölümünde bir Git kimlik doğrulama belirteci oluşturun. Aynı belirteç hem MCP sunucusu hem de Git için kullanılır.
2. Düzenleyicide **Integrations** menüsünü açın ve **MCP server** seçeneğine tıklayın. Burada projenin MCP sunucusunun adresi, `https://<your-overleaf>/project/<project_id>/mcp`, ve sunucunun her yapay zekâ istemcisine nasıl ekleneceği gösterilir: komutu kopyalayın ve `<token>` kısmını kendi belirtecinizle değiştirin.

Belirteç, `Authorization: Bearer <token>` HTTP başlığı olarak gönderilir. Örneğin, Claude Code için komut şöyledir:

```bash
claude mcp add --transport http overleaf \
  https://<your-overleaf>/project/<project_id>/mcp \
  --header "Authorization: Bearer <token>"
```

### Kullanım

Bağlandıktan sonra yapay zekâ istemcisine isteğinizi sade bir dille iletin. Örneğin:

| Sizin isteğiniz | Yapay zekâ istemcisinin kullandığı |
| --- | --- |
| _Girişteki yazım hatalarını düzelt._ | `read_file`, `edit_file`: düzenlemeler düzenleyicide canlı olarak görünür |
| _Projeyi derle ve LaTeX hatalarını düzelt._ | `compile`, `get_compile_log`, `edit_file` |
| _Açık yorumları yanıtla, ardından çözüldü olarak işaretle._ | `list_comments`, `reply_to_comment`, `resolve_comment` |
| _XeLaTeX'e geç ve PDF'i indir._ | `update_settings`, `compile`, `get_output_file_link` |

### Araçlar

| Grup | Araçlar |
| --- | --- |
| Proje | `get_clone_info`, `get_settings`, `update_settings`, `list_versions` |
| Dosyalar | `list_files`, `read_file`, `edit_file`, `write_file`, `delete_file` |
| Derleme | `compile`, `get_compile_log`, `get_output_file_link`, `word_count` |
| Yorumlar | `list_comments`, `reply_to_comment`, `resolve_comment`, `reopen_comment` |

`edit_file` ve `write_file` ile yapılan düzenlemeler düzenleyicide canlı olarak görünür ve ortak çalışanların düzenlemeleriyle birleştirilir. Aynı anda çok sayıda dosya, ikili dosyalar veya yeniden adlandırmalar için yapay zekâ istemcisi projeyi Git ile klonlayıp push da yapabilir.

### İzinler

MCP sunucusu, Git'te olduğu gibi projenin paylaşım ayarlarına uyar:

* Projeyi görüntüleyebilen herkes projeyi okuyabilir, derleyebilir ve çıktısını indirebilir.
* Dosyalarını ve ayarlarını yalnızca sahip ve düzenleyiciler değiştirebilir.
* İnceleyiciler ayrıca yorumları yanıtlayabilir ve kendi başlattıkları yorumları çözüldü olarak işaretleyebilir veya yeniden açabilir.
* Bir bağlantıyla katılan görüntüleyiciler, düzenleyicide olduğu gibi yorumları göremez.

### Soru\&Cevap

<Accordion title="Düzenleyicide Integrations veya MCP server görmüyorum">

<strong>Yanıt:</strong> MCP sunucusunun kendine ait bir ortam değişkeni yoktur. `config/overleaf.rc` içindeki `GIT_BRIDGE_ENABLED=true` ile etkinleştirilir; bkz. [Git entegrasyonu](/tr/on-premises/configuration/overleaf-toolkit/integrations/git-integration). Değiştirdikten sonra `bin/up -d` komutunu çalıştırın. git-bridge olmadan düzenleyici, sol çubuğunda **Integrations** sekmesini göstermez.

</Accordion>
