Import API (`/docs` ve "Open in Ayakaleaf" düğmeleri, `open-in-overleaf` modülü) her Ayakaleaf Pro pod'unun **web** hizmetinde çalışır ve varsayılan olarak açıktır. URL ile verilen dosyalar aynı pod'daki linked-url-proxy üzerinden indirilir. Nasıl çağrılacağı [Overleaf İçe Aktarma API'si](/tr/on-premises/configuration/overleaf-toolkit/integrations/overleaf-import-api) sayfasında açıklanmıştır.

| | |
| --- | --- |
| Hizmet | web (`open-in-overleaf` modülü); indirmeler linked-url-proxy üzerinden |
| Dışarısı → Overleaf | tarayıcılar herhangi bir web sitesinden `GET` veya `POST ${OVERLEAF_SITE_URL}/docs` gönderir |
| Pod → dışarısı | `snip_uri` ve `zip_uri` indirmeleri, [Harici URL](/tr/on-premises/configuration/kubernetes/external-url) sayfasında açıklandığı şekilde sınırlandırılır |
| Durum | oturum açmamış bir ziyaretçinin isteği, oturum açana kadar Redis'te 10 dakika tutulur |
| Periyodik işler | yok |

### Yapılandırma

Açmak için hiçbir şey gerekmez. ConfigMap'teki ilgili ayarlar:

| Ayar | |
| --- | --- |
| `OVERLEAF_ALLOW_PUBLIC_ACCESS: "true"` | Oturum açmamış ziyaretçiler `/devs` sayfasını açabilir ve gönderdikleri istek oturum açana kadar tutulur, bkz. [Herkese Açık Erişim](/tr/on-premises/configuration/kubernetes/authentication/public-access). |
| `MAX_UPLOAD_SIZE` | Bir isteğin taşıyabileceği en büyük ZIP, MB cinsinden (varsayılan `50`). Ingress'iniz veya yük dengeleyiciniz de bu boyuttaki istek gövdelerini kabul etmelidir. |
| `OVERLEAF_LINKED_URL_*` | `snip_uri` ve `zip_uri` değerlerinin hangi adresleri gösterebileceği, bkz. [Harici URL](/tr/on-premises/configuration/kubernetes/external-url). |

### Birden fazla replika

Ek bir şey gerekmez. Oturum açmamış bir ziyaretçinin isteği Redis'te tutulur; böylece ziyaretçi oturum açtıktan sonra hangi replikaya ulaşırsa ulaşsın istek orada devam ettirilir.

### Kubernetes üzerinde test edildi

Tek replikalı Kubernetes 1.37 üzerinde, Import API için uçtan uca testlerimiz başarılı oldu (14 vaka): `/devs` sayfası ve örnek projesi, parçacıklar, tam belgeler, URL kodlu bağlantılar ve data URL'lerinden gelen dosyaların projelere dönüştürülmesi, proje olamayacak gönderimlerin reddedilmesi, dahili adreslerden indirmelerin reddedilmesi, oturum açmamış gönderimlerin ve bağlantıların oturum açma boyunca korunması ve `OVERLEAF_ALLOW_PUBLIC_ACCESS` ile oturum açmamış ziyaretçiler için `/devs` ve gönderilen bir parçacığın oturum açtıktan sonra bir kez devam ettirilmesi; son vaka HAProxy arkasında üç replikada da başarılı oluyor.
