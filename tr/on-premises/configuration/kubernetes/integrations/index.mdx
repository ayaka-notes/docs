Overleaf Import API dışında her entegrasyon varsayılan olarak kapalıdır. GitHub, GitLab, Gitea ve Dropbox Senkronizasyonu ile MCP sunucusu ayrıca [Git entegrasyonu](/tr/on-premises/configuration/kubernetes/integrations/git-integration) gerektirir. Birini ConfigMap'te veya Secret'ta açtıktan sonra replikaları `kubectl -n overleaf rollout restart` ile yeniden başlatın.
