Kubernetes dağıtımı, Toolkit ile aynı ortam değişkenlerini okur. Bir Toolkit sayfası "bunu `config/variables.env` dosyasına ekleyin" dediğinde, değeri `overleaf-env` ConfigMap'ine koyun; değer bir parola, anahtar veya token ise `overleaf-secrets` Secret'ına koyun. Ardından yeniden başlatın:

```bash
kubectl -n overleaf apply -f 30-config.yaml        # after editing the ConfigMap
kubectl -n overleaf patch secret overleaf-secrets --type merge \
  -p '{"stringData":{"GITHUB_TOKEN_CIPHER_PASSWORD":"'"$(openssl rand -hex 32)"'"}}'
kubectl -n overleaf rollout restart deployment/overleaf
```

`config/overleaf.rc` içindeki değerler ortam değişkenleri değil, Toolkit ayarlarıdır; bunların yerine neyin geçtiğini bu sayfanın sonundaki Soru\&Cevap bölümü açıklar.

### Sertifikalar ve diğer dosyalar

Bazı özellikler bir değer yerine bir dosya yolu alır: SAML sertifikaları (`OVERLEAF_SAML_IDP_CERT`, ...), LDAP CA'sı (`OVERLEAF_LDAP_TLS_OPTS_CA_PATH`) veya kendi barındırdığınız bir GitHub Enterprise, GitLab ya da Gitea için özel bir CA (`NODE_EXTRA_CA_CERTS`). Dosyaları bir Secret'a koyun ve onu Toolkit sayfalarının beklediği yere, `/var/lib/overleaf/certs` konumuna bağlayın:

```bash
kubectl -n overleaf create secret generic overleaf-certs --from-file=idp_cert.pem --from-file=ca.pem
```

```yaml title="40-overleaf.yaml (additions)"
          volumeMounts:
            # ...
            - name: certs
              mountPath: /var/lib/overleaf/certs
              readOnly: true
      volumes:
        # ...
        - name: certs
          secret:
            secretName: overleaf-certs
```

Ardından ConfigMap'te bunlara yollarıyla başvurun, örneğin `NODE_EXTRA_CA_CERTS: /var/lib/overleaf/certs/ca.pem`, ve yeniden başlatın.

<Warning>

<strong>Şifreleme parolaları.</strong> Kullandığınız özelliklerin tüm `*_CIPHER_PASSWORD` değerlerini Secret'ta ayarlayın. Aksi takdirde bazı özellikler ilk kullanımda veri biriminde bir anahtar dosyası oluşturur: tek replikada bu, birim kaybolana kadar çalışır; birden fazla replikada ise her replika farklı bir anahtarla şifreleme yapar.

</Warning>

### Soru\&Cevap

<Accordion title="`config/overleaf.rc` içindeki hangi Toolkit ayarlarına ihtiyacım var?">

<strong>Cevap:</strong> Hiçbiri Ayakaleaf Pro tarafından okunmaz. Kubernetes'teki karşılıkları:

| `config/overleaf.rc`                         | Kubernetes                                                        |
| -------------------------------------------- | ----------------------------------------------------------------- |
| `OVERLEAF_LISTEN_IP`, `OVERLEAF_PORT`        | Service (NodePort) veya ingress'iniz                              |
| `SIBLING_CONTAINERS_ENABLED`                 | ConfigMap'te `SANDBOXED_COMPILES*`, pod'da Docker soketi          |
| `GIT_BRIDGE_ENABLED`                         | [Git entegrasyonu](/tr/on-premises/configuration/kubernetes/integrations/git-integration)                             |
| `MONGO_ENABLED`, `REDIS_ENABLED`, `MONGO_URL`, `REDIS_HOST` | StatefulSet'ler veya yönetilen hizmetleriniz, `OVERLEAF_MONGO_URL` ve `OVERLEAF_REDIS_HOST` |
| `REDIS_AOF_PERSISTENCE`                      | `20-redis.yaml` içinde `--appendonly yes`                         |
| `NGINX_ENABLED`, `TLS_*`                     | ingress'iniz veya yük dengeleyiciniz                              |

</Accordion>
