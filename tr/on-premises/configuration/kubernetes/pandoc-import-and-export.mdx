Pandoc dönüştürmeleri, derlemeler gibi her Ayakaleaf Pro pod'unun **clsi** hizmeti tarafından çalıştırılır: clsi, düğümün Docker Engine'inden `PANDOC_IMAGE` imajından bir konteyner başlatmasını ister. **web** hizmeti içe ve dışa aktarma menülerini gösterir. Özelliğin ne yaptığı ve imajın nasıl oluşturulacağı [Pandoc ile İçe ve Dışa Aktarma](/tr/on-premises/configuration/overleaf-toolkit/pandoc-import-and-export) sayfasında açıklanmıştır.

| | |
| --- | --- |
| Hizmetler | web (menüler ve rotalar), clsi (dönüştürmeyi çalıştırır), her Ayakaleaf Pro pod'unda |
| Düğüm | Ayakaleaf Pro çalıştırabilen her düğümde Docker Engine ve `PANDOC_IMAGE` |
| Gereksinim | [Sandbox Derlemeleri](/tr/on-premises/configuration/kubernetes/sandboxed-compiles) |
| Periyodik işler | yok |

### Yapılandırma

<Steps>
<Step title="İmajı her düğümde Docker'a yükleyin">
İmajı [ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) deposunun `develop/pandoc` klasöründen bir kez oluşturun, ardından Ayakaleaf Pro çalıştırabilen her düğümde Docker'a yükleyin:

```bash
docker build -t overleaf-pandoc:local develop/pandoc
docker save overleaf-pandoc:local | ssh node-1 sudo docker load    # repeat for every node
```

Ya da düğümlerin erişebildiği bir kayıt defterine gönderin ve her düğümde `sudo docker pull` ile çekin. TeX Live imajlarında olduğu gibi, imaj yalnızca containerd'de değil **Docker**'da bulunmalıdır.
</Step>

<Step title="ConfigMap">
```yaml
  ENABLE_PANDOC_CONVERSIONS: "true"
  PANDOC_IMAGE: overleaf-pandoc:local
```

Hem web hem clsi `ENABLE_PANDOC_CONVERSIONS` değerini aynı ConfigMap'ten okur; bu nedenle Kubernetes'te farklı değerlere sahip olamazlar.
</Step>

<Step title="Uygulayın ve yeniden başlatın">
```bash
kubectl apply -f 30-config.yaml
kubectl -n overleaf rollout restart deployment/overleaf     # or statefulset/overleaf
```
</Step>
</Steps>

### Birden fazla replika

İmajın her düğümde bulunması dışında ek bir şey gerekmez: her replika kendi düğümünde dönüştürme yapar.

### Kubernetes üzerinde test edildi

`develop/pandoc` klasöründen oluşturulan ve `docker save | docker load` ile her düğümde Docker'a yüklenen imajla, tek replikalı Kubernetes 1.37 üzerinde, Pandoc için uçtan uca testlerimiz başarılı oldu (6 vaka): bir Markdown belgesini LaTeX projesi olarak içe aktarma, bozuk bir Word belgesi için gösterilen hata, Word (yeniden içe aktarılabilen), Markdown ve HTML olarak dışa aktarma ve `ENABLE_PANDOC_CONVERSIONS` olmadan menülerin gizlenmesi.
