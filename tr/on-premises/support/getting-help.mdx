### Doctor

Overleaf Toolkit, hata ayıklamaya yardımcı olan kullanışlı bir `doctor` betiğiyle birlikte gelir. `bin/doctor` komutunu çalıştırdığınızda betik, ana makine ortamınız, yapılandırmanız ve Toolkit'in ihtiyaç duyduğu bağımlılıklar hakkında bilgi yazdırır. Bu çıktı, Ayakaleaf Pro kurulumlarınızdaki sorunları teşhis etmemize de yardımcı olabilir.

<Info>

Overleaf Pro kullanıcıları [GitHub'da bir issue açabilir](https://github.com/ayaka-notes/overleaf/issues).

Mesajınıza `bin/doctor` betiğinin çıktısını eklemeniz iyi bir fikirdir.

</Info>


### Ana Makine Bilgileri

`Host Information` bölümü, Toolkit'i çalıştıran makine hakkında bilgi içerir (örneğin Linux dağıtımı ve sürümü).

<Accordion title="Ana Makine Bilgileri çıktısı örneği">

### Bağımlılıklar

`Dependencies` bölümü, Toolkit'in çalışması için gereken araçları listeler. Bir araç mevcutsa sürüm bilgisiyle birlikte `status: present` olarak listelenir. Eksikse `status: MISSING!` olarak listelenir ve `doctor` çıktısının sonuna bir uyarı eklenir.

<Accordion title="Bağımlılık çıktısı örneği (mevcut)">

```text
- docker
    - status: present
    - version info: Docker version 28.0.4, build b8034c0
```

</Accordion>

<Accordion title="Bağımlılık çıktısı örneği (eksik)">

```text
- docker
    - status: MISSING!
```

</Accordion>

Herhangi bir bağımlılık eksikse Toolkit neredeyse kesinlikle çalışmayacaktır.

### Yapılandırma

`Configuration` bölümü, `config/` dizinindeki dosyalar hakkında bilgi içerir. `config/overleaf.rc` için doctor bazı önemli değerleri yazdırır. Eksik dosyalar `status: MISSING!` olarak listelenir ve `doctor` çıktısının sonuna bir uyarı eklenir.

<Accordion title="Yapılandırma çıktısı örneği">

```text
====== Configuration ======
- config/version
    - status: present
    - version: 6.3.2
- config/overleaf.rc
    - status: present
    - values
        - OVERLEAF_DATA_PATH: /tmp/overleaf
        - SERVER_PRO: false
        - MONGO_ENABLED: false
        - REDIS_ENABLED: true
- config/variables.env
    - status: MISSING!
```

</Accordion>

Yukarıdaki örnekten notlar:

* `/tmp/overleaf` olarak ayarlanan `OVERLEAF_DATA_PATH`, önemli veriler için güvenli bir konum olmayabilir.
* `MONGO_ENABLED: false`, Toolkit'in kendi MongoDB'sini sağlamayacağı anlamına gelir; gerekirse `MONGO_URL` değerinin harici olarak yönetilen bir MongoDB'yi gösterdiğinden emin olun.
* Örnekte `config/variables.env` eksiktir.

### Uyarılar

`Warnings` bölümü, doctor betiğinin tespit ettiği sorunları özetler. Sorun yoksa bu bölüm bunu belirtir.

<Accordion title="Uyarılar çıktısı örneği">

```text
====== Warnings ======
- configuration file variables.env not found
- rc file, OVERLEAF_DATA_PATH not set
====== End =======
```

</Accordion>

### Soru\&Cevap

<Accordion title="`bin/doctor` çıktısındaki quay.io, Docker yapılandırması ve Perl yerel ayar mesajlarının düzeltilmesi gerekir mi?">

<strong>Yanıt:</strong> Hayır, üçü de yalnızca bilgilendirme amaçlıdır. `bin/doctor` yalnızca bir rapor yazdırır, `bin/up` komutunu durdurmaz.

* `logged in to quay.io: false` ve `Server Pro enabled, but not logged in to quay.io repository` uyarısı: bu denetim, Server Pro imajının özel bir quay.io kayıt defterinde bulunduğu resmi Toolkit'ten gelir. `SERVER_PRO=true` ile Toolkit herkese açık olan `ghcr.io/ayaka-notes/overleaf-pro` imajını çeker; bu nedenle oturum açmak gerekmez. Bu uyarıyı yok sayın.
* `grep: /root/.docker/config.json: No such file or directory` (veya başka bir ana dizin): quay.io denetimi bu dosyada `quay.io` ifadesini arar. Docker bu dosyayı yalnızca kaydedilecek ayarları olduğunda yazar, örneğin `docker login` sonrasında; bu nedenle birçok sunucuda bulunmaz. Gerekli değildir.
* `perl: warning: Setting locale failed`: Toolkit `perl` aracını yalnızca burada, `bin/doctor` içinde sürümünü yazdırmak için kullanır ve `LANG` veya `LC_ALL` ana makinede kurulu olmayan bir yerel ayarı belirttiğinde Perl uyarı verir. Sürüm yine de yazdırılır. Uyarıyı susturmak için bu değişkenleri `locale -a` tarafından listelenen bir yerel ayara, örneğin `C.UTF-8` değerine ayarlayın.

`Docker daemon is not running`, `docker not found`, `Docker Compose not found` gibi uyarıların veya `config/` içinde eksik bir dosyanın düzeltilmesi gerekir: Toolkit bunlar olmadan başlayamaz.

</Accordion>
