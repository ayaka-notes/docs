Mevcut bir TeX Live imajını yeni bir Dockerfile kullanarak genişletmek ve uygulamayı yeni imajı kullanacak şekilde yapılandırmak mümkündür.

Burada yeni paketlerin veya yazı tiplerinin kurulumu için bazı yönergeler sunuyoruz; ancak özel bir imajın yapılandırılması destek koşullarımız kapsamında değildir.

TeX Live imajları seyrek olarak güncellenir. Server Pro'yu yükseltirken özel imajları yeniden derlemenizi öneririz.

<Danger>

Aşağıdaki bölümler yalnızca Server Pro ve [Sandboxed Compiles](/tr/on-premises/configuration/overleaf-toolkit/sandboxed-compiles) için geçerlidir.

</Danger>

### Yeni paketleri kurma ve güncelleme

Tex Live paketlerini yönetmek için aşağıdaki örnekte olduğu gibi `tlmgr install` ve `tlmgr update` gibi `tlmgr` komutlarını kullanabilirsiniz:

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2023.1

RUN tlmgr update --force ebproof
```

### Eski bir TeX Live imajında `tlmgr` kullanma

Varsayılan olarak `tlmgr`, kaynakları en son TeX Live sürümünden indirir. Eski bir TeX Live imajına yama yaparken indirmelerin ilgili arşive yönlendirilmesi gerekir. Arşiv aynaları için [https://www.tug.org/historic/](https://www.tug.org/historic/) adresindeki listeye bakın.

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2022.1

RUN tlmgr option repository <MIRROR>/systems/texlive/<YEAR>/tlnet-final
# e.g. RUN tlmgr option repository ftp://tug.org/historic/systems/texlive/2022/tlnet-final

RUN tlmgr update --force ebproof
```

### Yeni yazı tipleri kurma

Bir Tex Live dağıtımına yeni yazı tipleri kurmak için farklı yöntemler vardır ve özel bir yazı tipini kurmak birkaç adım gerektirebilir. Resmi Tex Live belgelerindeki [TeX yazı tiplerini kurma talimatlarını](https://tug.org/fonts/fontinstall.html) incelemek muhtemelen iyi bir başlangıç noktasıdır.

Aşağıdaki `Dockerfile`, mevcut bir Tex Live 2022 imajı üzerine bir TrueType yazı tipi kurulumuna örnek gösterir:

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2022.1

COPY ./myfonts/*.ttf /usr/share/fonts/truetype/myfont/

# rebuild font information cache
RUN fc-cache
```

### Server Pro'yu yeni imajları kullanacak şekilde yapılandırma

Yeni imajı derlemek için `ghcr.io/ayaka-notes/texlive-full` adını ve özel bir etiket kullanın; örneğin:

```bash
docker build -t ghcr.io/ayaka-notes/texlive-full:2023.1-custom
```

Artık `TEX_LIVE_DOCKER_IMAGE` ve `ALL_TEX_LIVE_DOCKER_IMAGES` ortam değişkenlerini güncelleyerek Server Pro'yu yeni `2023.1-custom` imajını kullanacak şekilde yapılandırabiliriz:

```text wrap
TEX_LIVE_DOCKER_IMAGE: "ghcr.io/ayaka-notes/texlive-full:2023.1-custom"
ALL_TEX_LIVE_DOCKER_IMAGES: "ghcr.io/ayaka-notes/texlive-full:2023.1,ghcr.io/ayaka-notes/texlive-full:2023.1-custom"
```

Yukarıdaki örnekte yeni projeler varsayılan olarak yeni `2023.1-custom` imajını kullanacak şekilde ayarlanırken, `2023.1` gerektiğinde kullanılabilir durumda kalmaya devam eder.
