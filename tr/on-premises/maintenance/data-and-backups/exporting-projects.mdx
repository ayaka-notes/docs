---
title: Projeleri dışa aktarma
icon: file-export
---

Server Pro ve Community Edition `5.4.0` sürümüne, yöneticilerin tüm kullanıcı projelerini (**Deleted** ve **Trashed** klasörlerinde hâlâ görünenler dahil) diskteki bir dizine aktarmasına olanak tanıyan bir betik ekledik.

<Info>

Bu betiği çalıştırmanın çıktısı, kullanıcının proje panosundan tüm projelerin Zip dosyasını elle indirmekle aynıdır. Betik, dışa aktarımın projenin en son sürümünü içermesini sağlamak için indirmeye başlamadan önce bekleyen tüm değişiklikleri kaydeder (flush).

</Info>

### Sınırlamalar

Dışa aktarma betiğinin şu sınırlamaları vardır:

* TeX Live imaj adı veya derleyici gibi hiçbir proje ayarı dışa aktarılmaz. Bunların, proje kullanıcının hesabına yüklendiğinde ayarlanması gerekir.
* Dışa aktarılan projeler herhangi bir sürüm geçmişi içermez.
* Ortak çalışan bilgileri korunmaz. Projelerin yeniden paylaşılması gerekir. Bağlantıyla paylaşım kullanılıyorsa, Görüntüleme ve Düzenleme bağlantıları yeniden oluşturulur (öncekilerle aynı olmazlar).
* Yorumlar ve izlenen değişiklik bilgileri dışa aktarılmaz.
* Proje sohbet geçmişi dışa aktarılmaz.

<Danger>

Bu betik, tam bir sistem yedeğinin yerini alacak şekilde **tasarlanmamıştır**. Bir felaket kurtarma senaryosunda örneğinizi kurtarabilmenizi sağlamak için [tutarlı bir yedek](https://docs.overleaf.com/on-premises/maintenance/#performing-a-consistent-backup) almanızı **şiddetle** öneririz.

</Danger>

### **Bayraklar**

| Ad             | Açıklama                                                                        |
| -------------- | ------------------------------------------------------------------------------- |
| `--help`       | Yardımı göster                                                                  |
| `--user-id`    | Kullanıcı kimliği (`--export-all` veya `--project-id` kullanılmıyorsa zorunlu)   |
| `--project-id` | Tek bir projeyi dışa aktarır (`--user-id` veya `--export-all` ile **kullanılamaz**) |
| `--list`       | Kullanıcının projelerini listeler (`--output` ile **kullanılamaz**)             |
| `--output`     | Çıktı zip dosyası (tekli dışa aktarma işlemleri için)                           |
| `--export-all` | Tüm kullanıcıların projelerini dışa aktarır (`--output-dir` gerektirir)         |
| `--output-dir` | Tüm kullanıcıların dışa aktarma dosyalarının saklanacağı dizin                  |
| `--log-level`  | Desteklenen günlük düzeyleri: `trace`\|`debug`\|`info`\|`warn`\|`error`\|`fatal` |

### **Kullanım**

Tüm kullanıcıların projelerini dışa aktarmak için aşağıdaki komutu kullanın:

```bash wrap
# Overleaf Toolkit users
$ bin/docker-compose exec sharelatex /bin/bash -ce "cd /overleaf/services/web && node modules/server-ce-scripts/scripts/export-user-projects.mjs --export-all --output-dir=/var/lib/overleaf/data/exports"

# Legacy docker-compose.yml users
docker exec sharelatex /bin/bash -ce "cd /overleaf/services/web && node modules/server-ce-scripts/scripts/export-user-projects.mjs --export-all --output-dir=/var/lib/overleaf/data/exports"
```

<Info>

Server Pro veya Community Edition &lt;= 3.5.13 sürümünü çalıştırıyorsanız, yukarıdaki örneği **`export-legacy-user-projects.js`** betiğini kullanacak şekilde güncellemeniz gerekir.

</Info>

### **Tamamlanma**

Dışa aktarma tamamlandığında dosyalara, **docker-compose.yml** dosyanızda <strong>/var/lib/overleaf</strong> konumuna bind-mount edilen ana makine dizini üzerinden veya Toolkit kullanıyorsanız **config/overleaf.rc** dosyasındaki `OVERLEAF_DATA_PATH` ortam değişkeninde belirtilen dizin üzerinden erişebilirsiniz.

<Info>

Overleaf şu anda yinelenen proje adlarına izin verir. Bir kullanıcının projeleri arasında aynı ada sahip olanlar varsa, bu projeler yine de kullanıcının Zip dışa aktarımına eklenir, ancak arşiv açıldığında yalnızca bir sürüm bulunur. Linux'ta `unzip -B`, aynı ada sahip dosyaların üzerine yazmak yerine onları yedek dosyalar olarak yazar.

</Info>
