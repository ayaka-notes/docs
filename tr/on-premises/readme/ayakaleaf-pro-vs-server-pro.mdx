<Info>

Ayakaleaf Pro, Overleaf Community Edition'ın geliştirilmiş bir uygulamasıdır ve Server Pro'daki tüm premium özellikleri _**ücretsiz**_ sunar. [https://www.overleaf.com/](https://www.overleaf.com/) adresindeki Overleaf Common'ın aksine, derleme süresinde hiçbir sınırlamamız ve kullanıcı sayısı için hiçbir lisans gereksinimimiz yoktur; ayrıca kendi verilerinizi tamamen kendiniz barındırarak mutlak güvenlik sağlayabilirsiniz.

Overleaf Server Pro, resmi destekli, ticari ve kendi sunucunuzda barındırılan bir Overleaf dağıtımıdır. Server Pro hakkında daha fazla bilgi için [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud) sayfasını ziyaret edin.

</Info>

<Warning>

Overleaf Community Edition, **tüm** kullanıcıların güvenilir olduğu ortamlarda kullanılmak üzere tasarlanmıştır. Sandbox Compiles kullanılamadığından Community Edition, kullanıcıların yalıtılmasının gerektiği senaryolar için **uygun değildir**.

Sandbox olmadan LaTeX derlemeleri kapsayıcıyla aynı ayrıcalıklarla çalışır ve kapsayıcının dosya sistemine, ağına ve ortam değişkenlerine erişebilir. Bu, veri ifşası veya sistemin ele geçirilmesi riski oluşturur. Sandbox'sız derlemeler yalnızca tamamen güvenilir ortamlarda kullanılmalıdır; çok kullanıcılı veya üretim kurulumları için Sandbox Compiles şiddetle önerilir.

Sandbox Compiles hakkında daha fazla bilgi için [dokümantasyonumuza](/tr/on-premises/configuration/overleaf-toolkit/sandboxed-compiles) göz atın.

</Warning>

### Topluluk Desteği

Kendi sunucusunda barındırılan bir Overleaf örneği kullananlar için destek, topluluk tarafından GitHub [Issues](https://github.com/ayaka-notes/overleaf-pro/issues) üzerinden sağlanır.

Desteklenen bir sürümde kalmak için, aşağıdaki komutun çıktısını sürüm notlarında yayımlanan Image ID'leriyle karşılaştırarak hangi Overleaf sürümünü çalıştırdığınızı doğrulayabilirsiniz.

```bash
docker inspect --format '{{.Image}}' sharelatex | awk -F: '{print substr($2, 1, 12)}'
```
