### Konto

Når det gjelder administrasjon av egen konto, behandles **alle** brukere som vanlige brukere — `Site Admins` og `Template Users` får **ingen** ekstra tillatelser. Det finnes imidlertid begrensninger på hvilke handlinger vanlige brukere kan utføre, avhengig av hvordan de autentiserer seg.

#### Innstillinger

<strong>Autentiseringstyper: interne kontoer | SSO (SAML/LDAP)</strong>

| Handling | Interne kontoer | SSO (SAML/LDAP) |
| ----------------------------------------- | ----------------: | --------------: |
| Oppdatere kontoinformasjon | Ja | Nei |
| Endre passord | Ja | Nei |
| Generere autentiseringstokener for Git bridge | Ja | Ja |
| Slette autentiseringstokener for Git bridge | Ja | Ja |
| Administrere økter | Ja | Ja |

<Info>

Git Bridge-integrasjonen er **kun** tilgjengelig i Server Pro. Se [Server Pro vs. Community Edition](/no/on-premises/readme/ayakaleaf-pro-vs-server-pro) for mer informasjon.

</Info>

#### Dine økter

| Handling | Bruker |
| -------------------- | ---: |
| Tømme økter | Ja |
| Vise gjeldende økt | Ja |
| Vise andre økter | Ja |

### Editor-IDE

I Overleafs editor-IDE kan du ha én av følgende roller: `Project Owner`, `Editor`, `Reviewer`, `Viewer`, `Site Administrator` eller `Template User`.

<Info>

Server Pro og Community Edition støtter anonym **skrivebeskyttet** tilgang og **lese- og skrivetilgang** til prosjekter.

For mer informasjon om dette, se miljøvariablene `OVERLEAF_ALLOW_PUBLIC_ACCESS` og `OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` [her](/no/on-premises/configuration/overleaf-toolkit/environment-variables).

</Info>
