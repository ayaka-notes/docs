---
title: Migrere fra Server Pro til Group Professional
icon: rectangle-pro
noindex: true
---

Å bytte fra en selvdriftet Server Pro-instans til et nytt skybasert Overleaf Group Professional-abonnement er en stor endring, så for å gjøre prosessen så smidig som mulig har vi satt sammen følgende veiledning.

Generelt foreslår vi en overlappingsperiode på tre måneder som starter på fornyelsesdatoen din. Dette betyr at:

* Den eksisterende Server Pro-instansen og det nye Group Professional-abonnementet ditt vil begge være fullt aktive.
* Det tekniske teamet ditt kan sette av tid til å sette opp Group Professional-abonnementet og bestemme fremtiden for den lokale installasjonen av Server Pro.
* Viktigst av alt får brukerne god tid til å kopiere prosjektene sine over til den nye Overleaf Group Professional-plattformen.

Denne korte veiledningen tar deg gjennom de viktigste trinnene i migreringen. La oss komme i gang!

<Steps>
<Step title="Fase 1: Oppsett og konfigurasjon">
(Lenke: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-1-setup-and-configuration)

* Overleaf oppretter Group Professional-abonnementet ditt og legger til hovedadministratoren din.
* Gruppeadministratoren din vil kunne aktivere [Managed Usersarrow-up-right](https://docs.overleaf.com/groups/user-management/managed-user-accounts), konfigurere [Single Sign-On (SSO)arrow-up-right](https://docs.overleaf.com/groups/overleaf-group-single-sign-on/setting-up-group-sso) og [invitere sluttbrukernearrow-up-right](https://docs.overleaf.com/groups/user-management/how-to-add-and-remove-users).

<Warning>

Å aktivere Managed Users og implementere SSO er et obligatorisk trinn for samsvar med FedRAMP® LI-SaaS. Hvis organisasjonen din krever FedRAMP-samsvar, må du sette opp Managed Users og SSO før du inviterer sluttbrukere.

</Warning>
</Step>

<Step title="Fase 2: Brukermigrering og databehandling">
(Lenke: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-2-user-migration-and-data-management)

Dette er det primære migreringsvinduet og har følgende ansvarsområder:

#### Sluttbrukere

* Brukerne bør migrere alle prosjekter de ønsker å beholde, fra Server Pro-instansen til de nye kontoene sine på [overleaf.comarrow-up-right](http://overleaf.com/). Prosessen innebærer å [eksportere prosjekterarrow-up-right](https://www.overleaf.com/learn/how-to/Exporting_your_work_from_Overleaf) fra Server Pro og [laste dem opparrow-up-right](https://www.overleaf.com/learn/how-to/Uploading_a_project) til kontoen sin på [overleaf.comarrow-up-right](http://overleaf.com/). Hvis en bruker ikke allerede har en konto på [overleaf.comarrow-up-right](http://overleaf.com/), kan vedkommende registrere seg på [overleaf.com/registerarrow-up-right](http://overleaf.com/register).

<Warning>

Kun prosjektets kildekode (LaTeX- og binærfiler) overføres gjennom denne eksportprosedyren. Eksisterende prosjektinnstillinger, delingsinnstillinger, kommentarer, sporede endringer osv. blir IKKE overført. Brukerne må invitere samarbeidspartnerne sine på nytt etter migreringen.

</Warning>

#### Teknisk personale

* I denne fasen bør det tekniske teamet planlegge håndteringen av den lokale Server Pro-instansen og dataene i den etter migreringen.
* **Sikkerhetskopi av data:** Du kan eksportere alle prosjekter før avvikling for å lage et arkiv som gjør det mulig å hjelpe brukere som har glemt å migrere eller laste ned arbeidet sitt. Instruksjoner: https://docs.overleaf.com/on-premises/maintenance/data-and-backups/exporting-projects
* **Avvikling av Server Pro:** Etter at migreringsvinduet lukkes og lisensnøkkelen din er deaktivert, har du to hovedalternativer for selve Server Pro-instansen (se neste trinn).
</Step>

<Step title="Alternativer for avvikling av Server Pro">
<Steps>
<Step title="Avinstaller Server Pro fullstendig">
Avinstallering avvikler Server Pro og fjerner programvaren helt.
</Step>

<Step title="Bytt til Community Edition">
Et bytte bevarer databasen med brukere og prosjekter med full prosjekthistorikk ved å konvertere instansen fra Server Pro til Community Edition.
</Step>
</Steps>

<Info>

Community Edition inkluderer IKKE [Sandboxed Compilesarrow-up-right](https://docs.overleaf.com/on-premises#overview-of-server-pro-and-community-edition) eller [LDAP](/no/on-premises/configuration/overleaf-toolkit/authentication/ldap-authentication)/[SAML](/no/on-premises/configuration/overleaf-toolkit/authentication/saml-authentication). Hvis du må gå tilbake til innebygd autentisering (brukernavn/passord), se: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-to-ldap-or-saml#going-the-other-way-switching-from-ldap-saml-back-to-native-authentication

For en sammenligning av Server CE og Server Pro, se: https://docs.overleaf.com/on-premises/welcome/server-pro-vs.-community-edition

</Info>
</Step>

<Step title="Fase 3: Avvikling av Server Pro">
(Lenke: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-3-server-pro-decommission)

* Overleaf-teamet vil formelt deaktivere Server Pro-lisensnøkkelen din og sende en bekreftelse når dette er gjort.
* Utfør da én av avviklingshandlingene som er beskrevet ovenfor: avinstaller Server Pro fullstendig eller bytt til Community Edition.
</Step>
</Steps>

Ytterligere ressurser og lenker som er nevnt ovenfor, forblir uendret.
