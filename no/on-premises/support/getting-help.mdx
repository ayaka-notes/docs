### Doctor

Overleaf Toolkit leveres med et praktisk `doctor`-skript som hjelper med feilsøking. Kjør `bin/doctor`, så skriver skriptet ut informasjon om vertsmiljøet ditt, konfigurasjonen din og avhengighetene Toolkit trenger. Denne utdataen kan også hjelpe oss med å diagnostisere problemer i Ayakaleaf Pro-installasjonene dine.

<Info>

Brukere av Overleaf Pro kan [opprette en issue på GitHub](https://github.com/ayaka-notes/overleaf/issues).

Det er lurt å inkludere utdataen fra `bin/doctor`-skriptet i meldingen din.

</Info>

### Konsultere Doctor

Kjør doctor-skriptet:

```bash title="Run doctor"
bin/doctor
```

### Vertsinformasjon

Delen `Host Information` inneholder informasjon om maskinen som kjører Toolkit (for eksempel Linux-distribusjon og -versjon).

<Accordion title="Eksempel på utdata for Host Information">

```text
- Host Information
    - Linux
    - Output of 'lsb_release -a':
            No LSB modules are available.
            Distributor ID:	Ubuntu
            Description:	Ubuntu 22.04.5 LTS
            Release:	22.04
            Codename:	jammy
```

</Accordion>

### Avhengigheter

Delen `Dependencies` viser verktøyene som kreves for at Toolkit skal fungere. Hvis et verktøy finnes, vises det som `status: present` med versjonsinformasjon. Hvis det mangler, vises det som `status: MISSING!`, og en advarsel legges til nederst i utdataen fra `doctor`.

<Accordion title="Eksempel på utdata for avhengigheter (finnes)">

```text
- docker
    - status: present
    - version info: Docker version 28.0.4, build b8034c0
```

</Accordion>

<Accordion title="Eksempel på utdata for avhengigheter (mangler)">

```text
- docker
    - status: MISSING!
```

</Accordion>

Hvis noen avhengigheter mangler, vil Toolkit nesten helt sikkert ikke fungere.

### Konfigurasjon

Delen `Configuration` inneholder informasjon om filene i katalogen `config/`. For `config/overleaf.rc` skriver doctor ut noen sentrale verdier. Manglende filer vises som `status: MISSING!`, og en advarsel legges til nederst i utdataen fra `doctor`.

<Accordion title="Eksempel på utdata for Configuration">

```text
====== Configuration ======
- config/version
    - status: present
    - version: 5.4.0
- config/overleaf.rc
    - status: present
    - values
        - OVERLEAF_DATA_PATH: /tmp/overleaf
        - SERVER_PRO: false
        - MONGO_ENABLED: false
        - REDIS_ENABLED: true
- config/variables.env
    - status: MISSING!
```

</Accordion>

Merknader til eksempelet ovenfor:

* `OVERLEAF_DATA_PATH` satt til `/tmp/overleaf` er kanskje ikke et trygt sted for viktige data.
* `MONGO_ENABLED: false` betyr at Toolkit ikke vil klargjøre sin egen MongoDB; sørg for at `MONGO_URL` peker til en eksternt administrert MongoDB ved behov.
* `config/variables.env` mangler i eksempelet.

### Advarsler

Delen `Warnings` oppsummerer problemer som doctor-skriptet har oppdaget. Hvis det ikke finnes noen problemer, vil denne delen angi det.

<Accordion title="Eksempel på utdata for Warnings">

```text
====== Warnings ======
- configuration file variables.env not found
- rc file, OVERLEAF_DATA_PATH not set
====== End =======
```

</Accordion>
