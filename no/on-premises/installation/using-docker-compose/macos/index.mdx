I denne delen kjører vi Ayakaleaf Pro lokalt på Mac-en din med Docker Desktop og [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). Veiledningen bruker `http://localhost:8080`, lagrer dataene i hjemmemappen din og kompilerer med TeX Live 2026 i sandkassede containere.

Docker Desktop kjører applikasjonen, MongoDB, Redis og TeX Live-kompilatoren i en virtuell Linux-maskin. Du installerer ikke MongoDB, Redis eller MacTeX på selve macOS.

Bruk dette oppsettet til personlig bruk og lokal testing. For en delt tjeneste som alltid er på, anbefaler vi [Linux-veiledningen](/no/on-premises/installation/using-docker-compose/linux), med HTTPS, sikkerhetskopier og tilgangskontroll. Instansen er utilgjengelig mens Mac-en sover eller Docker Desktop er stoppet, se [Hold instansen tilgjengelig](/no/on-premises/installation/using-docker-compose/macos/6.-post-installation-tasks#keep-the-instance-available).

## Før du begynner {#before-you-start}

Du trenger:

* En macOS-versjon som støttes av [Docker Desktop for Mac](https://docs.docker.com/desktop/setup/install/mac-install/).
* Git, [Homebrew](https://brew.sh/) og GNU sed. Toolkit bruker GNU sed-alternativer som BSD sed som er innebygd i macOS, ikke godtar.
* Nok ressurser til både macOS og Docker. For en liten lokal instans kan du starte med 4 CPU-er og 8 GB minne tildelt Docker Desktop. Dette er et foreslått utgangspunkt, ikke et målt minimum.
* Minst 40 GB ledig lagringsplass for et fullt TeX Live-image, pluss plass til prosjektene dine. Sjekk både ledig plass på Mac-en og grensen for diskbruk i Docker Desktop. Start med én TeX Live-versjon: hver ekstra versjon trenger omtrent like mye plass til.

Applikasjons- og TeX Live-imagene publiseres for `arm64` og `amd64`. På Apple silicon lar du Docker velge det native ARM-imaget, og du skal ikke tvinge `platform: linux/amd64`.
