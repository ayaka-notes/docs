Ayakaleaf Pro kjører på Docker. På en Mac bruker du Docker Desktop, som kjører Docker-motoren i en virtuell Linux-maskin.

<Steps>
<Step title="Installer og start Docker Desktop">
Installer [Docker Desktop](https://docs.docker.com/desktop/setup/install/mac-install/)-versjonen for Mac-en din (Apple silicon eller Intel), åpne den og vent til motoren har startet. Du kan også starte den fra Terminal:

```bash
open -a Docker
```
</Step>

<Step title="Sjekk Docker-motoren">
Kjør disse kommandoene i Terminal:

```bash
docker context show
docker info
docker compose version
```

Konteksten skal peke til den lokale Docker Desktop-motoren, vanligvis `desktop-linux`. Hvis en annen kontekst er valgt, bytter du til Docker Desktop før du fortsetter:

```bash
docker context use desktop-linux
```

`docker info` må skrive ut en **Server**-seksjon. `docker --version` alene viser bare at klienten er installert.
</Step>

<Step title="Sjekk ressurser og fildeling">
I **Settings** i Docker Desktop sjekker du grensene for CPU, minne og disk mot [Før du begynner](/no/on-premises/installation/using-docker-compose/macos#before-you-start), og innstillingene for fildeling, se [Docker Desktop-innstillinger](https://docs.docker.com/desktop/settings-and-maintenance/settings/).

Denne veiledningen legger Toolkit under `/Users`, som Docker Desktop deler som standard. Hvis du bruker en annen plassering og `bin/up` mislykkes med `Mounts denied`, legger du til den mappen i fildelingen.
</Step>

<Step title="Sjekk Docker-socketen for sandkassede kompileringer">
Toolkit monterer `/var/run/docker.sock` inn i applikasjonen, slik at den kan starte en separat TeX Live-container for hver kompilering. Behold `DOCKER_SOCKET_PATH=/var/run/docker.sock` i `config/overleaf.rc`.

Docker CLI på macOS kan koble til via `~/.docker/run/docker.sock`. Det er klientendepunktet på Mac-en, ikke en grunn til å endre monteringskilden i Toolkit: kompilatoren trenger motorsocketen slik Linux-containere ser den.

Hvis `/var/run/docker.sock` mangler på Mac-en, slår du på **Allow the default Docker socket to be used** under **Settings → Advanced**, se [Dockers tillatelseskrav](https://docs.docker.com/desktop/setup/install/mac-permission-requirements/).

<Danger>

Ikke kjør `chmod 777` på socketen for å omgå feil. Tilgang til Docker-socketen tilsvarer root-tilgang til Docker-VM-en.

</Danger>
</Step>
</Steps>
