<Steps>
<Step title="Sjekk Git og Homebrew">
```bash
git --version
brew --version
```

Hvis macOS ber deg installere Command Line Tools når du kjører Git, installerer du dem først. Hvis Homebrew mangler, installerer du det med de [offisielle instruksjonene](https://brew.sh/).
</Step>

<Step title="Legg GNU sed på PATH">
Toolkit-skriptene bruker GNU sed-alternativer som BSD sed som er innebygd i macOS, avviser. Installer [GNU sed](https://formulae.brew.sh/formula/gnu-sed) og legg den først på `PATH` i denne terminalen:

```bash
brew install gnu-sed
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
sed --version
```

Den siste kommandoen skal skrive ut **GNU sed**.

Et alias som `alias sed=gsed` er ikke nok: Toolkit kjører Bash-skript, som ikke ser aliasene i det interaktive skallet ditt. Du trenger ikke å erstatte `/usr/bin/sed`.

Kjør linjen `export PATH=...` på nytt i hver nye terminal du bruker for Toolkit, eller legg den til i oppstartsfilen for skallet ditt etter Homebrews egen initialisering.
</Step>

<Step title="Klon Ayakaleaf Toolkit-repositoriet">
Velg en mappe som er varig. Unngå `/tmp`, flyttbare stasjoner og skysynkroniserte mapper som iCloud Drive for den aktive databasen og prosjektdataene. Denne veiledningen bruker `~/ayakaleaf-toolkit`:

```bash
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

<Warning>

Hvis mappen allerede inneholder en installasjon, bruker du den som den er, eller velger en annen mappe for en ny instans. Ikke initialiser en ny konfigurasjon over en eksisterende installasjon.

</Warning>
