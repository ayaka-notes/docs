Toolkit er det samme på macOS og Linux. Oppbyggingen, `config/`-mappen og `bin/`-kommandoene er beskrevet i [2. Bli kjent med Toolkit](/no/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) i Linux-veiledningen.

På macOS må du huske på tre forskjeller:

* Kjør skriptene fra en terminal der GNU sed kommer først på `PATH`, se [1. Last ned Toolkit](/no/on-premises/installation/using-docker-compose/macos/1.-download-the-toolkit).
* Start Docker Desktop før du kjører et skript som kommuniserer med Docker, for eksempel `bin/up`, `bin/start` eller `bin/docker-compose`.
* `bin/doctor` inneholder sjekker som er arvet fra den offisielle Overleaf Toolkit. Advarselen `This system seems to not be Linux` er forventet på macOS, og advarselen om at du ikke er logget inn på `quay.io`, gjelder ikke det offentlige imaget `ghcr.io/ayaka-notes/overleaf-pro`. Andre problemer i rapporten er fortsatt viktige.
