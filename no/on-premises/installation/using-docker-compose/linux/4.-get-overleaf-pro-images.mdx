---
title: 4. Hent Ayakaleaf Pro-images
icon: split
---

Ayakaleaf Pro er et gratis Docker-image på [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Du trenger ingen konto eller innlogging for å hente det. Images bygges for amd64 og arm64, og Docker velger det som passer til serveren din.

Åpne `config/overleaf.rc` og angi:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

Neste gang du kjører `bin/up`, laster Toolkit ned Ayakaleaf Pro-imaget og bruker det i stedet for den offisielle Overleaf Community Edition. Innstillingene dine i `config/` fortsetter å fungere.

<Accordion title="Kjører du allerede det offisielle Overleaf Toolkit (overleaf/toolkit)?">

Du trenger ikke å installere på nytt. Hent Ayakaleaf Pro-imaget:

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Legg deretter til en fil med navnet `docker-compose.override.yml` med følgende innhold i katalogen `overleaf-toolkit/config`:

```yml
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

Neste gang du kjører `bin/up`, bruker Toolkit Ayakaleaf Pro-imaget.

</Accordion>
