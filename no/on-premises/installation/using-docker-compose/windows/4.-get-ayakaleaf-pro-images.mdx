Ayakaleaf Pro er et gratis Docker-image på [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Du trenger ingen konto, ingen pålogging og ingen kommersiell Overleaf-lisens for å hente det.

Åpne `config/overleaf.rc` og sett:

```bash title="config/overleaf.rc"
SERVER_PRO=true
```

Neste gang du kjører `bin/up`, henter Toolkit `ghcr.io/ayaka-notes/overleaf-pro` i versjonen fra `config/version`, i stedet for den offisielle Overleaf Community Edition.

Imaget er bygget for `arm64` og `amd64`, og Docker velger det som passer til arkitekturen til Docker-motoren.
