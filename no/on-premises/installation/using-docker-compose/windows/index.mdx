I denne delen kjører vi Ayakaleaf Pro lokalt på Windows med WSL 2, Ubuntu, Docker Desktop og [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). Veiledningen bruker `http://localhost:8080`, lagrer data i Ubuntus hjemmemappe og aktiverer sandkassede kompileringer.

Applikasjonen, MongoDB, Redis og TeX Live kjører i Linux-containere som administreres av Docker Desktop. Kjør Toolkit-kommandoer i Ubuntu; åpne applikasjonen i nettleseren i Windows. [Trinn 0](/no/on-premises/installation/using-docker-compose/windows/0.-setup-wsl-and-docker-desktop) forklarer hvordan Windows- og Linux-delene henger sammen, og starter med å installere WSL.

Du kan bruke Windows for en lokal instans eller holde den kjørende kontinuerlig med tilgjengelighetsinnstillingene i trinn 6. For delte servere og produksjonsservere anbefaler vi [Linux-veiledningen](/no/on-premises/installation/using-docker-compose/linux), med HTTPS, sikkerhetskopier og tilgangskontroll. Dvale i Windows, avslutning av Docker Desktop og avslutning av WSL avbryter denne lokale instansen; se [Hold instansen tilgjengelig](/no/on-premises/installation/using-docker-compose/windows/6.-post-installation-tasks#keep-the-instance-available).

## Før du begynner {#before-you-start}

Du trenger:

* En Windows-versjon og prosessor som støttes av [Docker Desktop for Windows](https://docs.docker.com/desktop/setup/install/windows-install/), med maskinvarevirtualisering aktivert. Denne veiledningen bruker Windows 11 på x86-64.
* Tillatelse til å aktivere WSL og installere programvare. WSL må være versjon 2.1.5 eller nyere, med Ubuntu kjørende i WSL 2-modus.
* Nok minne til Windows og containerne. For en liten lokal instans er 4 CPU-er og 8 GB tilgjengelig for Docker et foreslått utgangspunkt, ikke et målt minimum.
* Ledig lagringsplass på Windows-disken som inneholder WSL- og Docker-data. Sett av minst 40 GB til et fullt TeX Live-oppsett pluss prosjektdata; basic-imaget i [trinn 5](/no/on-premises/installation/using-docker-compose/windows/5.-personalizing-your-instance) er mindre og egner seg for den første distribusjonstesten. Ekstra image-versjoner krever ekstra plass.
* Nettverkstilgang til GitHub, GitHub Container Registry (`ghcr.io`) og Docker Hub for å klone Toolkit og laste ned images.

**PowerShell**-blokker kjøres i Windows. **Bash**-blokker og `bin/`-kommandoer kjøres i Ubuntu med mindre annet er angitt. Ikke kjør Toolkit-skript i PowerShell eller Windows Git Bash.
