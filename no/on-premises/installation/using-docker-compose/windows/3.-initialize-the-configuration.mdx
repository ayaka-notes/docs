title: 3. Initialiser konfigurasjonen
description: Opprett Toolkit-konfigurasjonsfilene i Ubuntu på WSL 2 med bin/init.
icon: circle-play
---

Fra Toolkit-mappen i **Ubuntu** kjører du:

```bash
bin/init
```

`bin/init` oppretter tre filer:

| Fil | Formål |
| --- | --- |
| `config/overleaf.rc` | Containerinnstillinger, den publiserte porten og plasseringene for data |
| `config/variables.env` | Applikasjonsinnstillinger og hemmeligheter |
| `config/version` | Versjonen av applikasjonsimaget |

Den genererer også `OVERLEAF_INVITE_TOKEN_SECRET` i `config/variables.env`. Ta vare på den, og ikke publiser denne filen eller commit den til versjonskontroll.

Behold versjonen som Toolkit velger for en ny installasjon. For å endre versjonen av en eksisterende instans senere følger du [Oppgradere distribusjonen din](/no/on-premises/maintenance/upgrading-your-deployment).

<Info>

`bin/init` overskriver ikke eksisterende konfigurasjon. Hvis den rapporterer at filene allerede finnes, undersøker du dem før du fortsetter. Ta vare på `config/` og `data/` når du starter instansen på nytt eller oppgraderer den.

</Info>
