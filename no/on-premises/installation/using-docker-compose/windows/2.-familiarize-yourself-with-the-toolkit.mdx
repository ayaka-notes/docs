Toolkit er det samme som på Linux. Oppbyggingen, `config/`-mappen og `bin/`-kommandoene er beskrevet i [2. Bli kjent med Toolkit](/no/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) i Linux-veiledningen.

På Windows må du huske på disse forskjellene:

* Kjør `bin/`-kommandoer i **Ubuntu Bash**, fra `~/ayakaleaf-toolkit`. Kommandoer merket **PowerShell** kjøres i stedet i Windows.
* Start Docker Desktop og aktiver WSL Integration for Ubuntu før du bruker `bin/up`, `bin/start` eller `bin/docker-compose`.
* Behold konfigurasjonsfilene med Linux-linjeskift (LF). Rediger dem med `nano` i Ubuntu eller en editor som er koblet til WSL. CRLF-linjeskift kan gi Bash-feil.
* `bin/doctor` kjører Linux-sjekker i Ubuntu. Advarselen om at du ikke er logget inn på `quay.io`, gjelder ikke det offentlige imaget `ghcr.io/ayaka-notes/overleaf-pro`. Andre advarsler må du fortsatt ta hensyn til.

```bash
bin/doctor
```
