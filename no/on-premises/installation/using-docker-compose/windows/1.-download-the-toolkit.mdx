<Steps>
<Step title="Installer kommandolinjeverktøyene">
Kjør i **Ubuntu**, med Linux-passordet du opprettet i trinn 0:

```bash
sudo apt update
sudo apt install -y git ca-certificates curl perl gawk openssl
```

Ubuntu har allerede Bash, GNU sed og coreutils. I motsetning til macOS trenger det ikke Homebrew eller en separat installasjon av GNU sed.
</Step>

<Step title="Klon Ayakaleaf Toolkit-repositoriet">
Hold Toolkit og dataene i Ubuntus Linux-filsystem, under hjemmemappen din:

```bash
cd "$HOME"
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

Unngå `/mnt/c`, `/mnt/d`, OneDrive og midlertidige mapper for den aktive databasen og prosjektdataene. Stier i Linux-filsystemet gir tillatelsene og filsystematferden som containerne forventer, og unngår ekstra kostnader ved arbeid på tvers av filsystemer; se [Microsofts veiledning om filsystemer](https://learn.microsoft.com/en-us/windows/wsl/filesystems).

<Warning>

Hvis mappen allerede inneholder en installasjon, bruker du den som den er, eller velger en annen mappe for en ny instans. Ikke erstatt konfigurasjonen eller dataene til en eksisterende installasjon.

</Warning>
</Step>
</Steps>
