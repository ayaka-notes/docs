---
title: 5. Tilpasse instansen din
description: Angi porten, nettstedets URL og TeX Live-imaget, aktiver sandkassede kompileringer og start Ayakaleaf Pro på WSL 2.
icon: square-sliders
---

Kjør kommandoer og rediger filer i **Ubuntu**, fra `~/ayakaleaf-toolkit`.

<Steps>
<Step title="Containerinnstillinger">
Rediger de eksisterende oppføringene i `config/overleaf.rc`:

```bash title="config/overleaf.rc"
PROJECT_NAME=ayakaleaf-wsl
SERVER_PRO=true
OVERLEAF_LISTEN_IP=127.0.0.1
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
DOCKER_SOCKET_PATH=/var/run/docker.sock
```

Behold standardstiene for data og de medfølgende MongoDB- og Redis-tjenestene. Port `8080` er for den lokale nettleseren i Windows; binding til `127.0.0.1` holder den lokal. Sandkassede kompileringer bruker en separat Linux-container for hver kompilering, i stedet for å kjøre TeX inne i applikasjonscontaineren. Docker-socketen lar applikasjonen opprette disse containerne, og Toolkit leverer vertsstien for kompileringsdataene under `data/overleaf/data/compiles`.
</Step>

<Step title="Applikasjonsinnstillinger">
I `config/variables.env` setter du disse verdiene og erstatter eventuelle aktive oppføringer med samme navn:

```dotenv title="config/variables.env"
OVERLEAF_SITE_URL=http://localhost:8080
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES="TeX Live 2026"
```

Det fulle imaget inneholder pakkene og skriftene som trengs for et bredt spekter av prosjekter. Sett av minst 40 GB ledig lagringsplass til det og applikasjonen, pluss plass til prosjektdata og fremtidige oppdateringer.

For en rask distribusjonstest bruker du i stedet det mindre **basic**-imaget. Det er nok for den enkle artikkeltesten i trinn 6, men inneholder ikke hele pakke- og skriftsettet:

```dotenv
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-basic:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-basic:2026.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES="TeX Live 2026 Basic"
```

Velg ett av disse settene, uten dupliserte aktive nøkler. [Dockerfile](https://github.com/ayaka-notes/texlive-full/blob/main/texlive/2026/Dockerfile.basic) for basic-imaget inneholder `latexmk`, XeTeX og `fontspec`, men ikke `ctex` eller hele skriftsamlingen. En manglende LaTeX-pakke i basic betyr ikke i seg selv at det er et sandkasseproblem.

Generer en økthemmelighet:

```bash
openssl rand -hex 32
```

Legg til resultatet som `OVERLEAF_SESSION_SECRET` i `config/variables.env`. Ta også vare på den genererte hemmeligheten for invitasjonstokener. For en lokal instans uten e-post lar du SMTP-innstillingene og `OVERLEAF_EMAIL_FROM_ADDRESS` være uangitt.
</Step>

<Step title="Start instansen din">
```bash
bin/up -d
```

Toolkit starter MongoDB, initialiserer replikasettet, laster ned det valgte TeX Live-imaget og starter Redis og applikasjonen. Det kan se ut som om den stopper opp mens et stort image lastes ned. Ikke kjør en ny `bin/up` mens den første fortsatt arbeider.

Sjekk følgende i en annen Ubuntu-terminal:

```bash
cd "$HOME/ayakaleaf-toolkit"
bin/docker-compose ps
bin/docker-compose logs --tail=100 mongo
bin/docker-compose logs --tail=100 -f sharelatex
```

Trykk `Ctrl+C` for å slutte å følge loggene; frakoblede containere fortsetter å kjøre. Hvis oppstarten mislykkes ved MongoDB, følger du [MongoDB starter ikke](/no/on-premises/installation/using-docker-compose/windows/troubleshooting#mongodb-fails-to-start) før du prøver på nytt. Ikke slett datamappen for å tilbakestille en eksisterende installasjon.

Sjekk porten og siden for første kjøring:

```bash
bin/docker-compose port sharelatex 80
curl -I http://localhost:8080/launchpad
```

Porten skal være `127.0.0.1:8080`. Vent til applikasjonen er initialisert hvis HTTP-forespørselen først mislykkes.
</Step>

<Step title="Åpne instansen fra Windows">
I **nettleseren i Windows** åpner du [http://localhost:8080/launchpad](http://localhost:8080/launchpad). Bruk denne adressen også i Windows, i stedet for en midlertidig WSL-IP-adresse.

For å sjekke HTTP-tilgang fra Windows uavhengig av nettleseren kjører du i **PowerShell**:

```powershell
curl.exe -I http://localhost:8080/launchpad
```

Hvis Ubuntu når siden, men Windows ikke gjør det, se [Windows kan ikke åpne localhost](/no/on-premises/installation/using-docker-compose/windows/troubleshooting#windows-cannot-open-localhost).
</Step>
</Steps>
