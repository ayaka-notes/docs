Docker Compose på én enkelt server er den anbefalte måten å distribuere Ayakaleaf Pro på. Du kjører det via [Toolkit](https://github.com/ayaka-notes/toolkit): et sett med skript som omslutter `docker compose` og leser innstillingene dine fra én `config/`-mappe, slik at `bin/up` erstatter `docker compose up`.
