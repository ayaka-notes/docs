---
title: 2. Opprett navnerommet og hemmelighetene
description: Opprett navnerommet og hemmelighetene Ayakaleaf Pro trenger.
icon: key
---

Alt havner i navnerommet `overleaf`:

```bash
kubectl create namespace overleaf
```

Ayakaleaf Pro leser hemmelighetene sine fra miljøvariabler. Generer dem én gang og oppbevar dem i en Secret:

```bash wrap
HISTORY=$(openssl rand -hex 32)
kubectl -n overleaf create secret generic overleaf-secrets \
  --from-literal=OVERLEAF_INVITE_TOKEN_SECRET="$(openssl rand -base64 32)" \
  --from-literal=OVERLEAF_SESSION_SECRET="$(openssl rand -hex 32)" \
  --from-literal=WEB_API_PASSWORD="$(openssl rand -hex 32)" \
  --from-literal=STAGING_PASSWORD="$HISTORY" \
  --from-literal=V1_HISTORY_PASSWORD="$HISTORY" \
  --from-literal=CRYPTO_RANDOM="$(openssl rand -hex 32)" \
  --from-literal=OT_JWT_AUTH_KEY="$(openssl rand -hex 32)"
```

| Hemmelighet                                    | Hvorfor                                                                                                                                              |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_INVITE_TOKEN_SECRET`                 | Påkrevd. Uten den stopper poden med «Missing required secrets». Hvis du endrer den, blir ventende prosjektinvitasjoner ugyldige.                      |
| `OVERLEAF_SESSION_SECRET`                      | Signerer øktinformasjonskapslene. Uten den logges alle ut hver gang poden starter på nytt.                                                           |
| `WEB_API_PASSWORD`, `CRYPTO_RANDOM`, `OT_JWT_AUTH_KEY` | Interne hemmeligheter. Containeren genererer dem ved hver oppstart når de mangler; med mer enn én replika må alle replikaer dele dem. |
| `STAGING_PASSWORD` og `V1_HISTORY_PASSWORD`    | Intern historikkhemmelighet; begge må ha **samme** verdi.                                                                                            |

<Warning>

Ta sikkerhetskopi av Secret-en (`kubectl -n overleaf get secret overleaf-secrets -o yaml`) sammen med dataene dine. Funksjoner som krypterer tokener i MongoDB, trenger også sine egne krypteringspassord i denne Secret-en, for eksempel `GITHUB_TOKEN_CIPHER_PASSWORD` for [GitHub-synkronisering](/no/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation).

</Warning>
