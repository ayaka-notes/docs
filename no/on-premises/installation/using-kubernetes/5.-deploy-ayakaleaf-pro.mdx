```yaml title="40-overleaf.yaml" wrap
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: overleaf-data
  namespace: overleaf
spec:
  accessModes: [ReadWriteOnce]
  resources:
    requests:
      storage: 20Gi
---
apiVersion: apps/v1
kind: Deployment
metadata:
  name: overleaf
  namespace: overleaf
spec:
  replicas: 1
  strategy:
    type: Recreate          # one pod owns the data volume; never run two at once
  selector:
    matchLabels:
      app: overleaf
  template:
    metadata:
      labels:
        app: overleaf
    spec:
      terminationGracePeriodSeconds: 60   # time to flush pending edits, like the Toolkit
      # Keep the environment to what the ConfigMap and Secret set: no REDIS_PORT=tcp://... and the like
      enableServiceLinks: false
      containers:
        - name: sharelatex
          image: ghcr.io/ayaka-notes/overleaf-pro:6.3.2
          envFrom:
            - configMapRef:
                name: overleaf-env
            - secretRef:
                name: overleaf-secrets
          ports:
            - containerPort: 80
          readinessProbe:
            httpGet:
              path: /status
              port: 80
            periodSeconds: 10
          resources:
            requests:
              cpu: 500m
              memory: 1536Mi
            limits:
              memory: 3Gi
          volumeMounts:
            - name: data
              mountPath: /var/lib/overleaf
            - name: compiles
              mountPath: /var/lib/overleaf/data/compiles
            - name: output
              mountPath: /var/lib/overleaf/data/output
            - name: cache
              mountPath: /var/lib/overleaf/data/cache
            - name: docker-sock
              mountPath: /var/run/docker.sock
      volumes:
        - name: data
          persistentVolumeClaim:
            claimName: overleaf-data
        # Compile scratch space on the node; same paths as SANDBOXED_COMPILES_HOST_DIR_*
        - name: compiles
          hostPath:
            path: /srv/overleaf/compiles
            type: DirectoryOrCreate
        - name: output
          hostPath:
            path: /srv/overleaf/output
            type: DirectoryOrCreate
        - name: cache
          hostPath:
            path: /srv/overleaf/cache
            type: DirectoryOrCreate
        - name: docker-sock
          hostPath:
            path: /var/run/docker.sock
            type: Socket
---
apiVersion: v1
kind: Service
metadata:
  name: overleaf
  namespace: overleaf
spec:
  type: NodePort
  selector:
    app: overleaf
  ports:
    - name: http
      port: 80
      targetPort: 80
      nodePort: 30080
```

```bash
kubectl apply -f 40-overleaf.yaml
kubectl -n overleaf rollout status deployment/overleaf --timeout=10m
kubectl -n overleaf logs deployment/overleaf | grep -E 'Finished migrations|Missing required'
```

Den første oppstarten kjører databasemigreringene og tar et minutt eller to. Poden er klar når `/status` svarer; åpne deretter `OVERLEAF_SITE_URL`.

### Hvorfor manifestet ser slik ut

* <strong>Datavolum.</strong> Alt under `/var/lib/overleaf` (prosjektfiler, historikk, opplastinger) ligger på PVC-en. Dataene blir værende på én node med nodelokal lagring som local-path; med blokklagring over nettverket kan poden flytte mellom noder.
* <strong>Kompileringsvolumer og Docker-socketen.</strong> Ayakaleaf Pro ber nodens Docker om å starte en TeX Live-container og gir den prosjektets kompileringskatalog **via stien på noden**. Disse katalogene er derfor `hostPath`-volumer, og stiene deres gjentas i `SANDBOXED_COMPILES_HOST_DIR_*`. Innholdet er midlertidige data og trenger ingen sikkerhetskopi.
* <strong>`enableServiceLinks: false`.</strong> Kubernetes legger til variabler i Docker-stil for hver Service i navnerommet i hver pod: Service-en `redis` blir `REDIS_PORT=tcp://10.x.x.x:6379`, Service-en `git-bridge` `GIT_BRIDGE_PORT=tcp://...`. Noen Overleaf-tjenester leser variabler med disse navnene. I denne poden vinner innstillingene fra `OVERLEAF_REDIS_*` og ConfigMap-en, men git-bridge tar `GIT_BRIDGE_PORT` som sin port og stopper (se [Git-integrasjon](/no/on-premises/configuration/kubernetes/integrations/git-integration)). Når du slår av lenkene, begrenses miljøet til det du selv angir.
* <strong>`Recreate`.</strong> To poder må aldri bruke det samme datavolumet eller kjøre migreringer samtidig.
* <strong>Eksponering.</strong> NodePort-Service-en svarer på port `30080` på hver node. I produksjon setter du ingress-kontrolleren eller lastbalansereren din foran og avslutter TLS der; den må tillate WebSockets, tidsavbrudd for forespørsler på 10 minutter (lange kompileringer) og opplastinger på 50 MB, og sende videre `X-Forwarded-For` og `X-Forwarded-Proto`.
