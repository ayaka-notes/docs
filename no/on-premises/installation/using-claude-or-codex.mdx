Bruk Claude Code eller Codex til å planlegge og gjennomføre en distribusjon av Ayakaleaf Pro. Agenten kan søke i denne dokumentasjonen via MCP mens den jobber.

Agenten hjelper til med distribusjonen. Du er fortsatt ansvarlig for å gjennomgå kommandoer og beskytte påloggingsinformasjon.

### Før du starter

Klargjør en støttet Linux-server med SSH-tilgang. Gå gjennom [kravene](/no/on-premises/getting-started/requirements  "mention") før du fortsetter.

<Warning>

Ikke lim inn passord, private nøkler, tokens eller lisensnøkler i agent-prompter. Gå gjennom hver kommando før du kjører den, spesielt kommandoer som endrer filer, nettverk eller containere.

</Warning>

### Koble til dokumentasjonen

Legg til MCP-endepunktet for dokumentasjonen i den lokale agenten din.

<Tabs>
<Tab title="Claude Code">

```bash wrap
claude mcp add ayakaleaf-pro --scope user --transport http https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>

<Tab title="Codex">

```bash wrap
codex mcp add ayakaleaf-pro --url https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>
</Tabs>

Start en ny økt etter at du har lagt til serveren. Be agenten bekrefte at den kan søke i Ayakaleaf Pro-dokumentasjonen.

### Distribuere Ayakaleaf Pro

Åpne en terminal på distribusjonsserveren. Start Claude Code eller Codex der. Send deretter denne prompten:

```text wrap
Use the Ayakaleaf Pro documentation MCP server to guide this deployment.
First, inspect the requirements and installation guides.
Ask me for missing deployment details before making changes.
Use the Ayakaleaf Toolkit unless the documentation requires another approach.
Before configuring the instance, summarize relevant optional features.
Ask which features and integrations I want to enable.
Include TLS, sandboxed compiles, Git integration, external MongoDB or Redis,
SSO (OIDC, SAML, or LDAP), GitHub Synchronisation, Zotero, S3 storage,
email delivery, branding, and localization when relevant.
Explain each selected option's prerequisites, security impact, and configuration steps.
Keep unselected optional features disabled.
Show each command before running it.
Do not expose, store, or request secrets in chat.
After deployment, verify that the service is healthy and summarize the changes.
```

Agenten skal veilede deg gjennom oppsett av Docker, konfigurasjon av Toolkit, henting av image og oppstart. Følg veiledningen [using-the-toolkit](/no/on-premises/installation/using-the-toolkit  "mention") for den kanoniske arbeidsflyten.

### Velge valgfrie funksjoner

Be agenten anbefale bare funksjoner som passer til miljøet ditt. Typiske valg inkluderer:

* <strong>Tilgang og sikkerhet:</strong> TLS, sandboxed compiles og SSO med OIDC, SAML eller LDAP.
* <strong>Eksterne tjenester:</strong> MongoDB, Redis, S3-lagring og e-postlevering.
* <strong>Samarbeid:</strong> Git-integrasjon, GitHub Synchronisation og Zotero.

Agenten skal forklare avhengigheter før den redigerer konfigurasjonen. Gå gjennom [toolkit-settings.md](/no/on-premises/configuration/overleaf-toolkit/toolkit-settings  "mention") og [authentication](/no/on-premises/configuration/overleaf-toolkit/authentication  "mention") før du aktiverer integrasjoner i produksjon.

### Verifisere distribusjonen

Når agenten har fullført trinnene:

1. Bekreft at hver kommando ble fullført uten feil.
2. Åpne den konfigurerte Ayakaleaf Pro-URL-en i nettleseren.
3. Fullfør [6.-post-installation-tasks.md](/no/on-premises/installation/using-the-toolkit/6.-post-installation-tasks  "mention").

For en eksisterende Community Edition-installasjon bruker du veiledningen [migrate-from-existing.md](/no/on-premises/installation/migrate-from-existing  "mention") i stedet for en ny distribusjon.
