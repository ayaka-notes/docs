<Danger>

Følgende instruksjoner gjelder **kun** for installasjoner av **Community Edition**. Vi anbefaler sterkt at Ayakaleaf Pro-brukere aktiverer [Sandboxed Compiles](/no/on-premises/configuration/overleaf-toolkit/sandboxed-compiles), siden dette gir brukerne tilgang til nesten de samme TeX Live-imagene som brukes på [overleaf.com](https://www.overleaf.com), og i tillegg isolerer prosjektkompileringer fra hverandre for økt sikkerhet.

</Danger>

For å spare båndbredde leveres både Overleaf Community Edition- og Ayakaleaf Pro-imagene kun med en minimal installasjon av [TeX Live](https://www.tug.org/texlive/). Du kan installere flere pakker eller oppgradere til en komplett TeX Live-installasjon med kommandoen [tlmgr](https://www.tug.org/texlive/tlmgr.html) i `sharelatex`-containeren.

#### Komme inn i sharelatex-containeren

For å starte et skall i `sharelatex`-containeren kjører du

```bash
bin/shell
```

Du får en ledetekst som ser slik ut:

```bash
root@309b192d4030:/#
```

I instruksjonene nedenfor antar vi at du er inne i containeren.

#### Finne gjeldende TeX Live-versjon

TeX Live utgis hvert år rundt april. Fremgangsmåten for å bruke `tlmgr` er forskjellig avhengig av om du bruker gjeldende utgivelse eller en eldre. Du kan sjekke hvilken versjon av TeX Live du kjører med `tlmgr --version`. Denne installasjonen kjører for eksempel TeX Live 2021:

```bash
# tlmgr --version
tlmgr revision 59291 (2021-05-21 05:14:40 +0200)
tlmgr using installation: /usr/local/texlive/2021
TeX Live (https://tug.org/texlive) version 2021
```

<Info>

Gjeldende utgivelse av TeX Live finner du på [TeX Live-hjemmesiden](https://www.tug.org/texlive/).

</Info>

Hvis du kjører en eldre TeX Live-versjon, har du to alternativer. En ny versjon av Overleaf-Docker-imaget utgis vanligvis kort tid etter en TeX Live-utgivelse. Du kan enten vente på den og oppgradere installasjonen med skriptet `bin/upgrade`, eller, hvis du foretrekker å beholde den eldre TeX Live-utgivelsen, må du først be `tlmgr` om å bruke et historisk repository. Instruksjoner for dette finner du [her](https://www.tug.org/texlive/acquire.html#past).

#### Installere pakker

For å installere en komplett TeX Live-installasjon kjører du denne kommandoen i `sharelatex`-containeren:

```text
tlmgr install scheme-full
```

Du kan også installere enkeltpakker manuelt:

```bash
tlmgr install tikzlings tikzmarmots tikzducks
```

<Warning>

Fra og med utgivelse `3.3.0` er det igjen **påkrevd** å kjøre `tlmgr path add` etter hver bruk av `tlmgr install`, slik at alle binærfilene får riktige symbolske lenker i systemstien.

</Warning>

Mange flere kommandoer er tilgjengelige. Finn ut mer med:

```text
tlmgr help
```

Når du er ferdig, skriver du `exit` eller trykker Control-D for å avslutte skallet.

#### Lagre endringene

Endringene du nettopp har gjort, har endret `sharelatex`-containeren, men de er flyktige -- de går tapt hvis Docker Compose gjenoppretter containeren, for eksempel som en del av en konfigurasjonsoppdatering.

For å gjøre dem permanente bruker du `docker commit` til å lagre endringene i et nytt Docker-image:

```bash
cat config/version #5.2.1
docker commit sharelatex sharelatex/sharelatex:5.2.1-with-texlive-full
echo 5.2.1-with-texlive-full > config/version
```

Etter at endringene er committet, oppdaterer du `config/version` tilsvarende. Kjør deretter `bin/up` for å gjenopprette `sharelatex`-containeren.

<Danger>

Du må gjenta disse trinnene hver gang du [oppgraderer](https://github.com/overleaf/toolkit/blob/master/doc/upgrading.md) til en ny Overleaf-versjon.

</Danger>
