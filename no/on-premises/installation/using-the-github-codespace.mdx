Den enkleste måten å teste Ayakaleaf Pro på er å bruke GitHub Codespace, der alle miljøvariabler er forhåndskonfigurert slik at du kan bruke det rett ut av boksen.

<Warning>

Når du kjører Docker-containere i GitHub Codespaces, slås ikke Codespace av automatisk, og du blir fortsatt **fakturert**. For faktureringsreglene for GitHub Codespaces, se [faktureringsreglene for GitHub Codespaces](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces).

For å administrere dine GitHub Codespaces går du til [https://github.com/codespaces](https://github.com/codespaces). Når du ikke lenger trenger den, må du huske å slette Codespace-en din i tide.

</Warning>

Vi har **forhåndskonfigurert** følgende funksjoner:

* [x] Sandkassebasert LaTeX-kompilering med TeXLive **Basic** (2024-2026)
* [x] Pandoc-import/-eksport (funksjon i SaaS-plattformen)
* [x] Kjøring av Python-skript (funksjon i SaaS-plattformen)
* [x] Git-Bridge-støtte (funksjon i Server Pro)
* [x] Avansert referansesøk (funksjon i SaaS-plattformen)
* [x] Administrasjonspanel (global administrasjon av brukere/prosjekter)
* [x] Sporing av endringer (med gjennomgangs- og kommentarpanel)
* [x] Full prosjekthistorikk (med gjenoppretting og nedlasting)
* [x] Symbolpalett (funksjon i Server Pro/SaaS-plattformen)

<Warning>

Standard GitHub Codespaces har 32 GB lagringsplass. Dette er ikke nok for `texlive-full`-installasjonen vår. For å teste det fullstendige imaget sender du inn en supportforespørsel til GitHub om en Codespace med store runnere (8+ kjerner).

</Warning>

GitHub-synkronisering, LDAP, OAuth, SSO, Zotero-integrasjon og andre funksjoner er _**ikke konfigurert**_ i denne lekeplassen. Se [Toolkit-innstillingene](/no/on-premises/configuration/overleaf-toolkit/toolkit-settings) for mer informasjon om hvordan du konfigurerer disse funksjonene i din egen distribusjon.

<Steps>
<Step title="Opprett din GitHub Codespace">
Klikk på knappen nedenfor for å opprette din GitHub Codespace. Når det gjelder serverkonfigurasjon, er **2 kjerner med 8 GB RAM** vanligvis tilstrekkelig for testformål. Hvis du planlegger å bruke [**TeX Live Full**](https://github.com/ayaka-notes/texlive-full), anbefaler vi å velge en konfigurasjon med **8 kjerner og 64 GB**.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/ayakaleaf-pro-playground)
</Step>

<Step title="Initialiser Overleaf-instansen">
Når Codespace-en din er klar, kjører du følgende kommando i bash for å initialisere Overleaf-instansen.

```bash title="bash"

```

#### Bruke TeXLive Full-imaget

Hvis du har tilgang til GitHub Codespaces med 8 kjerner/64 GB, kan du bruke TeXLive Full-imaget i denne lekeplassen. Du kan endre følgende miljøvariabler i filen `toolkit/config/variables.env` for å bruke TeXLive Full-imaget i stedet for TeXLive Basic-imaget.

```dotenv wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1, ghcr.io/ayaka-notes/texlive-full:2024.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025, Texlive 2024
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```

Etter at du har endret miljøvariablene, må du starte Toolkit på nytt for å ta i bruk endringene. Du kan kjøre følgende kommando for å starte Toolkit på nytt.

```bash
cd toolkit && bin/up -d
```
