### Initialisere konfigurasjonen

La oss initialisere den nye serverens konfigurasjonsfiler med noen fornuftige standardverdier ved å kjøre det medfølgende skriptet `bin/init`.

```text title="Run initialization"
bin/init
```

Dette skriptet vil **ikke** overskrive eksisterende konfigurasjonsfiler.

La oss nå sjekke innholdet i katalogen `config/` med kommandoen `ls`:

```text title="List the config directory"
ls config
```

Hvis alt ble initialisert, skal du se tre konfigurasjonsfiler: `overleaf.rc`, `variables.env` og `version`. Dette er de viktigste konfigurasjonsfilene for serveren, og de lar deg tilpasse hvordan serveren fungerer og hvordan brukerne samhandler med instansen din.

| Navn            | Beskrivelse                                             |
| --------------- | ------------------------------------------------------- |
| `overleaf.rc`   | Hovedkonfigurasjonsfilen på øverste nivå.               |
| `variables.env` | Miljøvariabler som lastes inn i Docker-containeren.     |
| `version`       | Versjonen av Docker-imaget som skal brukes.             |

<Info>

Foreløpig er det nok å vite at disse filene finnes og hvor du finner dem. Senere i dokumentasjonen går vi gjennom hver fil mer detaljert og forklarer hvordan du kan tilpasse instansen din med dem. Hvis du vil hoppe videre, kan du se en fullstendig oversikt over disse konfigurasjonsfilene på [siden Filer og plasseringer](/no/on-premises/configuration/overleaf-toolkit/files-and-locations).

</Info>
