### Laste ned Toolkit

Du installerer Ayakaleaf Pro med **Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)), et sett med skript som kjører Overleaf i Docker for deg.

Som standard starter Toolkit den gratis offisielle Overleaf Community Edition (CE). [4. Hent Ayakaleaf Pro-images](/no/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images) bytter til Ayakaleaf Pro med én innstilling.

<Accordion title="Kjører du allerede det offisielle Overleaf Toolkit (overleaf/toolkit)?">

Du trenger ikke å installere på nytt. Behold installasjonen din og følg den siste delen av [4. Hent Ayakaleaf Pro-images](/no/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images).

</Accordion>

<Steps>
<Step title="Klon Ayakaleaf Toolkit-repositoriet">
For å installere Toolkit må du navigere til ønsket installasjonssti og deretter klone Ayakaleaf Toolkit-repositoriet med denne kommandoen:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
```

<Info>

For å unngå mulige problemer med tilganger anbefaler vi å installere Toolkit i brukerens `$HOME`-katalog.

</Info>
</Step>

<Step title="Gå inn i toolkit-katalogen">
Vent til kloningen er fullført, og bytt deretter til den nyopprettede katalogen `overleaf-toolkit`:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
