### Laste ned Toolkit

Toolkit er kompatibelt med både Server CE og Ayakaleaf Pro og er den anbefalte installasjonsmetoden. Med Toolkit kommer du enkelt i gang med Server CE og kan sømløst oppgradere til Ayakaleaf Pro ved behov.

<Info>

[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) er modifisert for å bruke overleaf-pro-imaget fra ghcr direkte, med TeX Live levert av ayaka-notes. Alternativt kan du laste ned det offisielle overleaf-toolkit.

</Info>

<Steps>
<Step title="Klon Overleaf Toolkit-repositoriet">
For å installere Toolkit må du navigere til ønsket installasjonssti og deretter klone GitHub-repositoriet Overleaf Toolkit (@Ayaka-notes) med denne kommandoen:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
# official toolkit (Not Recommended)
# git clone https://github.com/overleaf/toolkit.git ./overleaf-toolkit
```

<Info>

For å unngå mulige problemer med tilganger anbefaler vi å installere Toolkit i brukerens `$HOME`-katalog.

</Info>
</Step>

<Step title="Gå inn i toolkit-katalogen">
Vent til kloningen er fullført, og bytt deretter til den nyopprettede katalogen `overleaf-toolkit`:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
