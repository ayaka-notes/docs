---
title: 4. Hent Ayakaleaf Pro-images
icon: split
---

Ayakaleaf Pro distribueres som et Docker-image i [ghcr](https://github.com/ayaka-notes/overleaf-pro/pkgs/container/overleaf-pro/)-registeret, med **åpen tilgang** for alle. Vi tilbyr images for både amd64- og arm64-arkitekturer. Når du henter imaget, velges riktig image automatisk basert på systemarkitekturen din.

#### Brukere av Ayaka-notes Toolkit

Hvis du bruker [ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit), kan Ayakaleaf Pro brukes som en direkte erstatning for Community Edition, slik at du kan beholde eksisterende innstillinger og tilpasninger. Aktiver Pro i Toolkit ved å redigere `config/overleaf.rc` og sette miljøvariabelen `SERVER_PRO`:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

Neste gang du kjører `bin/up`, vil Toolkit automatisk laste ned og bruke Ayakaleaf Pro-imaget.

#### Brukere av det offisielle Toolkit

Hvis du bruker [overleaf/toolkit](https://github.com/overleaf/toolkit), kjører du følgende kommando for å hente et Pro-image:

```bash title="Pull Docker Images"
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Legg deretter til en fil med navnet `docker-compose.override.yml` med følgende innhold i katalogen `overleaf-toolkit/config`:

```yml title="docker-compose.override.yml"
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

Neste gang du kjører `bin/up`, vil Toolkit automatisk laste ned og bruke Ayakaleaf Pro-imaget.
