Overleaf kjører på Docker. Du må installere:

* Docker Engine (Docker CE)
* Docker Compose-pluginen (`docker compose`, v2)

Disse trinnene er beregnet på en nyere Ubuntu LTS (20.04/22.04/24.04).

<Warning>

Unngå å installere `docker.io` fra Ubuntus standard apt-repository.\
Bruk Dockers offisielle repository, slik at du får en nyere Docker-versjon og `docker compose`-pluginen.

</Warning>

Den offisielle dokumentasjonen finner du her: [https://docs.docker.com/engine/install/ubuntu/](https://docs.docker.com/engine/install/ubuntu/).

<Steps>
<Step title="1) Fjern gamle/motstridende pakker (hvis de finnes)">
Hvis Docker tidligere er installert fra en annen kilde, fjerner du det først:

```bash wrap
sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-compose-v2 docker-doc podman-docker containerd runc | cut -f1)
```

Denne kommandoen er trygg selv om noen av pakkene ikke er installert.
</Step>

<Step title="2) Legg til Dockers offisielle apt-repository">
Installer forutsetningene:

```bash
sudo apt update
sudo apt install -y ca-certificates curl
```

Legg til Dockers GPG-nøkkel:

```bash wrap
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```

Legg til repositoryet:

```bash wrap
# Add the repository to Apt sources:
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Signed-By: /etc/apt/keyrings/docker.asc
EOF

sudo apt update
```
</Step>

<Step title="3) Installer Docker Engine + Compose-pluginen">
Installer Docker og Compose-pluginen:

```bash wrap
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

Start Docker ved oppstart:

```bash
sudo systemctl enable --now docker
```
</Step>

<Step title="4) Kontroller installasjonen">
Disse kommandoene skal kjøre uten feil:

```bash
docker --version
docker compose version
sudo docker run --rm hello-world
docker ps
```
</Step>

<Step title="5) (Valgfritt) Kjør Docker uten sudo">
Legg til brukeren din i gruppen `docker`:

```bash
sudo usermod -aG docker $USER
```

Deretter **logger du ut og inn igjen**, eller kjører:

```bash
newgrp docker
```

Nå skal dette fungere uten `sudo`:

```bash
docker ps
```

<Danger>

Gruppen `docker` har tilgang tilsvarende root på verten.\
Dette er forventet for vanlige Overleaf-installasjoner, og særlig relevant hvis du aktiverer Sandboxed Compiles.

</Danger>
</Step>
</Steps>

### Neste trinn

Når Docker fungerer, fortsetter du med installasjonstrinnene for Toolkit i [Bruke Toolkit](/no/on-premises/installation/using-the-toolkit).
