title: 0. Klargjør verten
description: Sjekk operativsystemet og SELinux, og installer git, før du setter opp rootless Podman.

Du installerer ikke Podman for hånd: [2. Kjør podman-setup](/no/on-premises/installation/using-podman/2.-run-podman-setup) installerer det sammen med de andre pakkene det trenger. Her sjekker du bare verten og installerer `git`, som du trenger for å laste ned Toolkit.

<Steps>
<Step title="Sjekk operativsystemet og SELinux">
Logg inn som brukeren som skal kjøre Ayakaleaf Pro, ikke som `root`, og sjekk distribusjonen og SELinux-modusen:

```bash title="Check the host"
grep PRETTY_NAME /etc/os-release
getenforce
```

Du skal se RHEL, Rocky Linux, AlmaLinux eller CentOS Stream med versjon 9 eller nyere, og `Enforcing`:

```text
PRETTY_NAME="Rocky Linux 9.9 (Blue Onyx)"
Enforcing
```
</Step>

<Step title="Sjekk at du kan bruke sudo">
`bin/podman-setup --apply` installerer pakker og laster en SELinux-modul med `sudo`, og ber om passordet ditt når det trenger det:

```bash title="Check sudo"
sudo -v
```

Hvis dette feiler, ber du administratoren om å legge brukeren din til i gruppen `wheel`.
</Step>

<Step title="Installer git">
```bash title="Install git"
sudo dnf install -y git
```

<Warning>

Ikke installer Docker Engine på denne verten. Pakken `podman-docker`, som `bin/podman-setup` installerer, gir kommandoen `docker`, og Toolkit behandler verten som Podman så lenge kommandoen `podman` finnes.

</Warning>
</Step>
</Steps>
