### Opprett din første administratorkonto {#create-your-first-administrator-account}

Åpne [http://localhost:8080/launchpad](http://localhost:8080/launchpad), eller din `OVERLEAF_SITE_URL` etterfulgt av `/launchpad`, og registrer administratorkontoen. Herfra fungerer alt som med Docker: følg [6. Oppgaver etter installasjon](/no/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks) i Docker-veiledningen, og bruk port `8080` i `localhost`-lenkene der.

Opprett eksempelprosjektet og kompiler det. PDF-en viser at kompileringer kjører i TeX Live-containerne sine gjennom Podman. Slik ser du kompileringscontaineren:

```bash title="List the compile containers"
podman ps -a --filter name=project- --format "{{.Names}} {{.Image}} {{.Status}}"
```

### Bruk HTTPS {#use-https}

Toolkits [TLS-proxy](/no/on-premises/configuration/overleaf-toolkit/tls-proxy) fungerer på Podman: kjør `bin/init --tls`, og sett sertifikatet ditt og `NGINX_ENABLED=true` som beskrevet der. Den lytter på portene `80` og `443`, som rootless Podman ikke kan bruke som standard. Tillat uprivilegerte brukere å bruke porter fra `80` og oppover:

```bash title="Allow ports 80 and 443"
echo "net.ipv4.ip_unprivileged_port_start=80" | sudo tee /etc/sysctl.d/99-unprivileged-ports.conf
sudo sysctl --system
```

Dette lar alle brukere på serveren lytte på disse portene, så gjør det bare på en server som er dedikert til Ayakaleaf Pro. Åpne dem deretter i brannmuren:

```bash title="Open ports 80 and 443"
sudo firewall-cmd --permanent --add-port=80/tcp --add-port=443/tcp
sudo firewall-cmd --reload
```

Sett `OVERLEAF_SITE_URL` til `https://`-adressen din og kjør `bin/up -d`. Behold standardverdiene `NGINX_HTTP_PORT=80` og `TLS_PORT=443`: med andre porter fører omdirigeringen fra HTTP til HTTPS til feil port.

<Info>

La `OVERLEAF_LISTEN_IP` stå på `127.0.0.1` når du bruker TLS-proxyen, slik at port `8080` ikke kan nås fra andre datamaskiner.

</Info>

### Oppgrader {#upgrade}

Oppgrader med `bin/upgrade`, som beskrevet i [Oppgradere distribusjonen din](/no/on-premises/maintenance/upgrading-your-deployment). På Podman henter den også ut seccomp-profilen for den nye versjonen til `config/seccomp/<version>/` og oppdaterer `SECCOMP_PROFILE`:

```text
Over-writing config/version with 6.3.4
Set SECCOMP_PROFILE=/home/<user>/overleaf-toolkit/config/seccomp/6.3.4/clsi-profile.json in config/variables.env
```

Etter en oppgradering kjører du `bin/podman-setup` for å sjekke oppsettet.

### Endre SELinux-modusen {#change-the-selinux-mode}

`SELINUX_MODE` i `config/overleaf.rc` bestemmer hvordan SELinux begrenser `sharelatex`-containeren. `managed` er modusen disse sidene setter opp; de andre modusene er beskrevet i [Toolkit-innstillinger](/no/on-premises/configuration/overleaf-toolkit/toolkit-settings). Kjør `bin/up -d` etter at du har endret den.
