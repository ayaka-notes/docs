### Oversikt over Overleaf

Overleaf er en samarbeidsbasert LaTeX-editor som er populær blant forskere og tekniske team. Skyversjonen er tilgjengelig på [overleaf.com](https://www.overleaf.com/). Den tilbyr en fullverdig LaTeX-editor på nett. Overleaf Common (SaaS-versjonen) har imidlertid en rekke funksjonsbegrensninger, og du må finne deg i en _**kompileringstidsgrense på 10 sekunder**_ og dyre medlemsavgifter.

Selv om Overleaf tilbyr en åpen kildekode-versjon for fellesskapet (tilgjengelig på [GitHub: Overleaf](https://github.com/overleaf/overleaf)), har også den mange begrensninger, for eksempel:

<Warning>

Overleaf Community Edition er beregnet for bruk i miljøer der **alle** brukere er klarert. Community Edition er **ikke** egnet for scenarioer der brukere må isoleres fra hverandre, fordi Sandbox Compiles ikke er tilgjengelig.

Uten sandkasse kjører LaTeX-kompileringer med de samme rettighetene som containeren, noe som gir tilgang til containerens filsystem, nettverk og miljøvariabler. Dette skaper en risiko for dataeksponering eller kompromittering av systemet. Kompileringer uten sandkasse bør bare brukes i fullt klarerte miljøer; for flerbruker- eller produksjonsdistribusjoner anbefales Sandbox Compiles på det sterkeste.

For mer informasjon om Sandbox Compiles, se: [sandboxed-compiles.md](/no/on-premises/configuration/overleaf-toolkit/sandboxed-compiles  "mention")

</Warning>

### Informasjon og priser for Overleaf Server Pro

Overleaf-nettstedet tilbyr bare en inngang for å kontakte kundestøtte om Server Pro, så informasjonen om Server Pro er svært begrenset. Basert på informasjonen vi har samlet inn i fellesskapet, er **kvoten for Server Pro**:

* Du må kjøpe lisenser for _minst_ 10 personer.
* En lisens for 10 personer koster omtrent 3 477,61 €. (2024)
* For utdanning koster 20 brukere 2640 euro per år, 50 brukere 6050 euro og 100 brukere 9963 euro.
* Server Pro er bare tilgjengelig i utvalgte regioner (f.eks. ikke på fastlands-Kina).

Basert på informasjonen som er tilgjengelig i dag, ser Overleaf Server Pro ut til å koste rundt \$300 per bruker per år, med et minimumskjøp på 10 lisenser, noe som gjør det til et svært dyrt alternativ. Dessuten tilbyr Server Pro betydelig færre funksjoner enn Ayakaleaf Pro. Vi er dypt takknemlige overfor utviklerne i fellesskapet, hvis bidrag gjennom årene har gjort det mulig for oss å bygge Ayakaleaf Pro og til slutt overgå Overleaf Server Pro både i funksjonalitet og kapasitet.

De følgende offentlige registrene viser dokumenterte kjøp og priser for Overleaf Server Pro. Mindre amerikanske kontrakter tilsier årlige kostnader på omtrent \$320–\$370 per bruker. Store institusjonelle avtaler kan få lavere pris per bruker. For eksempel tilsvarer Max Planck-selskapets treårige avtale i snitt omtrent 51 € per bruker per år. Kontraktsvilkår, støtte og omfanget av distribusjonen kan variere. Disse registrene er ikke en offisiell prisliste fra Overleaf.

### Hvorfor Ayakaleaf Pro?

<Info>

Ayakaleaf Pro er _**ikke**_ tilknyttet Overleaf, Inc. eller morselskapet Digital Science. Det er heller _ikke Server Pro_ Edition, som er et kommersielt produkt fra Overleaf, Inc. [ayaka-notes](https://github.com/ayaka-notes) utvikler og vedlikeholder Ayakaleaf Pro som et uavhengig prosjekt.

</Info>

Ayakaleaf Pro er en forbedret implementering av Overleaf Community Edition som tilbyr _**alle**_ premiumfunksjonene fra Server Pro _**gratis**_. I motsetning til Overleaf Common, som er tilgjengelig på [https://www.overleaf.com/](https://www.overleaf.com/), eller den kommersielle utgaven Server Pro, har vi

* _**ingen begrensninger**_ på kompileringstid
* _**ingen lisenskrav**_ knyttet til antall brukere
* _**alle funksjoner**_ fra Server Pro låst opp
