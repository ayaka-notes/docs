## Importer et dokument {#import-a-document}

Dette oppretter et nytt LaTeX-prosjekt fra et Word-dokument (`.docx`) eller en Markdown-fil (`.md`). Prosjektets navn hentes fra filnavnet.

<Steps>
<Step title="Åpne importdialogen">
Klikk på **New project** på prosjektsiden. Under **Import** klikker du på **Word document** eller **Markdown document**.

<Frame caption="Menyen New project">
  <img src="/images/on-premises/word-import-menu.png" alt="Menyen New project med Word document og Markdown document under Import" />
</Frame>
</Step>

<Step title="Velg filen">
Klikk på **Select .docx file**, eller dra filen inn i dialogen. For Markdown heter knappen **Select .md file**. Importen starter med en gang.

<Frame caption="Velge et Word-dokument">
  <img src="/images/on-premises/word-import-dialog.png" alt="Dialogen Choose Word document med knappen Select .docx file" />
</Frame>
</Step>

<Step title="Begynn å redigere">
Det nye prosjektet åpnes med meldingen **Document ready for editing**. Klikk på **Start editing**.

<Frame caption="Importen er ferdig">
  <img src="/images/on-premises/word-import-ready.png" alt="Dialogen Document ready for editing med knappen Start editing" />
</Frame>
</Step>

<Step title="Kontroller resultatet">
Dokumentet ligger nå i `main.tex`, med overskriftene i filens disposisjon. Klikk på **Recompile** for å se PDF-en. Kontroller formateringen, særlig tabeller, figurer og sitater, som kan trenge redigering.

<Frame caption="Det importerte prosjektet">
  <img src="/images/on-premises/word-import-project.png" alt="Det importerte prosjektet i redigeringsprogrammet, med main.tex, filens disposisjon og den kompilerte PDF-en" />
</Frame>
</Step>
</Steps>

### Hvis importen mislykkes {#if-the-import-fails}

Hvis filen ikke kan konverteres, viser dialogen **Your document couldn't be imported**. Utvid **Conversion error details** for å se hvorfor. Ingen prosjekter opprettes.

<Frame caption="Et dokument som ikke kunne importeres">
  <img src="/images/on-premises/word-import-error.png" alt="Importdialogen med en feilmelding og Conversion error details" />
</Frame>

Dialogen tar bare imot typen du valgte. En `.md`-fil i Word-dialogen viser **You can only upload: .docx**.

## Eksporter et prosjekt {#export-a-project}

Åpne prosjektet, og klikk deretter på navnet øverst i redigeringsprogrammet. Klikk på ett av disse:

| Alternativ                              | Du får                                       |
| ----------------------------------- | --------------------------------------------- |
| <strong>Export as Word document (.docx)</strong> | En `.docx`-fil oppkalt etter prosjektet        |
| <strong>Export as Markdown (.md)</strong>        | En `.zip`-fil med `main.md`                  |
| <strong>Export as HTML (.html)</strong>          | En `.zip`-fil med `main.html`                |

Nedlastingen starter av seg selv. Konverteringen kan ikke gjengi all LaTeX-formatering, så kontroller resultatet.
