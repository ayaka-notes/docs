<Info>

Ayakaleaf Pro er en forbedret implementering av Overleaf Community Edition som tilbyr alle premiumfunksjonene fra Server Pro _**gratis**_. I motsetning til Overleaf Common, som er tilgjengelig på [https://www.overleaf.com/](https://www.overleaf.com/), har vi ingen begrensninger på kompileringstid og ingen lisenskrav knyttet til antall brukere, og du kan drifte dine egne data fullt ut selv, noe som sikrer absolutt sikkerhet.

Overleaf Server Pro er en kommersiell, selvdriftet distribusjon av Overleaf med offisiell støtte. For mer informasjon om Server Pro, se [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud).

</Info>

<Warning>

Overleaf Community Edition er beregnet for bruk i miljøer der **alle** brukere er klarert. Community Edition er **ikke** egnet for scenarioer der brukere må isoleres fra hverandre, fordi Sandbox Compiles ikke er tilgjengelig.

Uten sandkasse kjører LaTeX-kompileringer med de samme rettighetene som containeren, noe som gir tilgang til containerens filsystem, nettverk og miljøvariabler. Dette skaper en risiko for dataeksponering eller kompromittering av systemet. Kompileringer uten sandkasse bør bare brukes i fullt klarerte miljøer; for flerbruker- eller produksjonsdistribusjoner anbefales Sandbox Compiles på det sterkeste.

For mer informasjon om Sandbox Compiles, se [dokumentasjonen](/no/on-premises/configuration/overleaf-toolkit/sandboxed-compiles) vår.

</Warning>

### Støtte fra fellesskapet

For personer som bruker en selvdriftet Overleaf-instans, gis støtte av fellesskapet via GitHub [Issues](https://github.com/ayaka-notes/overleaf-pro/issues).

For å holde deg på et støttet spor kan du bekrefte hvilken versjon av Overleaf du kjører, ved å sammenligne utdataene fra kommandoen nedenfor med image-ID-ene som publiseres i utgivelsesnotatene.

```bash
docker inspect --format '{{.Image}}' sharelatex | awk -F: '{print substr($2, 1, 12)}'
```
