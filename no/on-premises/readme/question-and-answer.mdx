Her har vi samlet svar på noen vanlige spørsmål om Ayakaleaf Pro.

### Grunnleggende spørsmål

<Accordion title="Q01: Er Ayakaleaf Pro en gratis prøveversjon? Krever den en lisens?">

Nei. Ayakaleaf Pro er helt gratis å bruke. Det er ikke en prøveversjon og krever ingen lisens.

</Accordion>

<Accordion title="Q02: Inkluderer dere (ayakaleaf pro) alle funksjonene i Overleaf Server Pro?">

Ja. Ayakaleaf Pro inkluderer alle funksjonene i Overleaf Server Pro, inkludert Git-Bridge-integrasjon. Den inkluderer også utvalgte funksjoner fra SaaS-plattformen til Overleaf. Vi fortsetter å utvikle og forbedre Ayakaleaf Pro.

</Accordion>

<Accordion title="Q03: Hva koster Overleaf Server Pro?">

Overleaf Server Pro koster rundt \$300 per bruker per år. Det kreves minst 10 lisenser, så installasjoner starter på omtrent \$3,000 i året. Mindre offentlige kontrakter i USA viser årlige kostnader på rundt \$320–\$370 per bruker. Dette gjør Server Pro dyrt, særlig for mindre team. Se [#information-and-price-about-overleaf-server-pro](/no/on-premises#information-and-price-about-overleaf-server-pro  "mention") for dokumenterte kjøp og priser.

</Accordion>

<Accordion title="Q04: Hvorfor inkluderer ikke Overleaf Server Pro GitHub Sync eller AI-funksjoner?">

Overleaf Server Pro brukes ofte av offentlige organisasjoner. De installerer den i private nettverk og kontrollerer tilgangen strengt. For å beskytte sensitive data unngår de inkluderte funksjonene å utveksle data med tredjepartstjenester. Hvis du trenger GitHub Sync, AI eller lignende tilkoblede funksjoner, anbefaler Overleaf et abonnement på SaaS-plattformen sin.

</Accordion>

<Accordion title="Q05: Er Ayakaleaf Pro sikker og pålitelig?">

Ayakaleaf Pro er åpen kildekode. Vi gjennomgår koden med verktøy som Codex Security for å styrke sikkerheten og påliteligheten. Hvis du ikke aktiverer datasynkronisering med tredjeparter, blir dataene dine liggende på serveren din. Ayakaleaf Pro inneholder ingen telemetri som sender dataene dine andre steder.

</Accordion>

<Accordion title="Q06: Vil Ayakaleaf Pro bli vedlikeholdt på lang sikt?">

Vi vil gjøre vårt ytterste for å vedlikeholde dette prosjektet på lang sikt.

</Accordion>

<Accordion title="Q07: Er Ayakaleaf Pro i samsvar med regelverk og lisenser?">

Ayakaleaf Pro er en fork drevet av fellesskapet. Koden og de integrerte funksjonene kommer fra bidrag fra fellesskapet. Den er lisensiert under AGPL v3. Installasjoner kan overholde denne lisensen når de oppfyller kravene i den.

</Accordion>

<Accordion title="Q08: Hvorfor heter prosjektet Ayakaleaf Pro?">

Prosjektet het opprinnelig Overleaf Pro i 2024. Utviklingen ble satt på pause en periode og startet igjen sent i 2025. I første kvartal 2026 endret Overleaf navnet på sitt AI-aktiverte abonnement til Pro. Tilbakemeldinger fra fellesskapet påpekte også at navnet Overleaf Pro kunne skape risiko knyttet til varemerker og etterligning. Det kunne få brukere til å tro at prosjektet var offisielt.

Vi endret navnet på prosjektet til Ayakaleaf Pro for å unngå denne forvirringen. Navnet kan leses som «Ayaka-notes Overleaf Pro». Vedlikeholderen har bidratt til utviklingen i Overleaf-fellesskapet siden studietiden, for over fem år siden. Denne erfaringen underbygger vår forpliktelse til langsiktig vedlikehold.

</Accordion>

<Accordion title="Q09: Hva skiller Ayakaleaf Pro fra nyere AI-bygde LaTeX-editorer?">

Siden 2026 har fellesskapet for åpen kildekode lansert mange AI-bygde LaTeX-editorer, inkludert OpenAI Prism. Ayakaleaf Pro holder dataene og tjenestene dine på din egen server. Dette gir deg direkte kontroll over installasjonen og dataene dine.

Mange eksperimentelle editorer fra fellesskapet har ingen etablert plan for langsiktig vedlikehold. Tredjepartsplattformer for LaTeX-kompilering kan også slutte å fungere når brukerbasen eller inntektene er utilstrekkelige. Ayakaleaf Pro leverer all kildekode og lar deg drifte alle tjenester selv. Selv om vedlikeholdet skulle stoppe, kan din eksisterende selvdriftede tjeneste fortsette å kjøre.

</Accordion>

### LaTeX

<Accordion title="Q01: Er brukernes kompileringer av LaTeX-prosjekter isolert? Er Shell Escape aktivert?">

Når du aktiverer Sandbox Compiles, kjøres hver brukers kompilering i en separat Docker-container og er isolert fra andre brukeres kompileringer. Shell Escape er aktivert som standard for Sandbox Compiles.

</Accordion>

<Accordion title="Q02: Er Sandbox Compiles-imaget pålitelig? Kan kompileringen mislykkes?">

Vi har forbedret TeX Live Full-imaget vårt for Sandbox Compiles gjennom de siste tre årene. I de fleste tilfeller vil prosjekter som kompilerer på overleaf.com, også kompilere riktig med Ayakaleaf Pro. Hvis en nødvendig skrifttype ikke er tilgjengelig, kan du laste opp skrifttypen til prosjektet manuelt.

</Accordion>
