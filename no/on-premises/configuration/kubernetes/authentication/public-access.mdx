Gjestetilgang til delte prosjekter, offentlige sider og selvregistrering slås på med miljøvariabler som **web**-tjenesten leser; sanntidstjenesten betjener deretter gjester via sesjonen deres. Hva hver bryter åpner, er beskrevet i [Offentlig tilgang](/no/on-premises/configuration/overleaf-toolkit/authentication/public-access).

| | |
| --- | --- |
| Tjeneste | web (og real-time for gjester i editoren), i hver Ayakaleaf Pro-pod; leses når web starter |
| Pod → utsiden | SMTP-serveren, når registreringen sender aktiverings-e-poster |
| Tilstand | gjestetilgangstokener i sesjonen, hastighetsbegrensninger for registrering i Redis |
| Periodiske jobber | ingen |

### Konfigurasjon

Legg til bryterne du trenger, i ConfigMap-en `overleaf-env`:

```yaml title="30-config.yaml (additions)"
  # Guests open link-shared projects without an account
  OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING: "true"
  # Signed-out visitors may open /learn, /templates, /devs and view links
  OVERLEAF_ALLOW_PUBLIC_ACCESS: "true"
  # Self-registration: "true", or only some domains
  OVERLEAF_ALLOW_PUBLIC_REGISTRATION: "@example.com, @*.uni.example"
```

```bash
kubectl apply -f 30-config.yaml
kubectl -n overleaf rollout restart deployment/overleaf     # or statefulset/overleaf
```

Sett anførselstegn rundt alle verdier. Verdier som begynner med `@`, må stå i anførselstegn i YAML, ellers avviser `kubectl apply` filen.

Registrering begrenset til domener sender en aktiverings-e-post, så [E-postlevering](/no/on-premises/configuration/kubernetes/email-delivery) må fungere fra podene: legg SMTP-verten inn i ConfigMap-en og `OVERLEAF_EMAIL_SMTP_PASS` inn i Secret-en.

### Flere replikaer

Ingenting ekstra. En gjests tilgang til et prosjekt lagres i sesjonen i Redis, så editoren fungerer på den replikaen lastbalansereren velger.

### Testet på Kubernetes

På Kubernetes 1.37 består ende-til-ende-testene våre for offentlig tilgang: på én replika, selvregistrering med `OVERLEAF_ALLOW_PUBLIC_REGISTRATION` satt til `true`, til ett domene, til flere domener med jokertegn for underdomener og til `@*`, med aktiverings-e-posten for domenemodusene (43 tilfeller); utloggede besøkende på `/devs` og et innsendt kodeutdrag som beholdes gjennom innloggingen med `OVERLEAF_ALLOW_PUBLIC_ACCESS` (2 tilfeller); en utlogget gjest i et lenkedelt prosjekt med begge bryterne på (3 tilfeller); og på tre replikaer bak HAProxy, OIDC sammen med offentlig tilgang (1 tilfelle).
