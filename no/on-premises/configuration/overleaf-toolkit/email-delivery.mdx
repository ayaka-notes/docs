Overleaf støtter sending av e-post på to måter: Simple Mail Transfer Protocol (SMTP) og [Amazon Simple Email Service (SES)](https://aws.amazon.com/ses/). SMTP kan brukes hvis du har en e-postserver aktivert på localhost som lytter etter lokale tilkoblinger.

## Konfigurasjon

E-post konfigureres med følgende miljøvariabler.

#### Avsenderkonfigurasjon

| Navn                          | Beskrivelse                                                                                                                                          |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | <p>Avsenderadressen, f.eks. <a href="mailto:support@mycompany.com">`'support@mycompany.com'`</a><br /><br />- <strong>Påkrevd</strong>: ja</p> |
| `OVERLEAF_EMAIL_REPLY_TO`     | Svaradressen, f.eks. `'noreply@mycompany.com'`                                                                                                  |

#### SMTP

| Navn                                    | Beskrivelse                                                                                                                                                                                                                                                              |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST`              | Vertsnavnet eller IP-adressen det skal kobles til. Må være tilgjengelig fra Docker-containeren                                                                                                                                                                               |
| `OVERLEAF_EMAIL_SMTP_PORT`              | Porten det skal kobles til                                                                                                                                                                                                                                                   |
| `OVERLEAF_EMAIL_SMTP_SECURE`            | Hvis `true`, bruker tilkoblingen TLS ved tilkobling til serveren. Hvis `false` eller ikke satt, brukes TLS hvis serveren støtter `STARTTLS`-utvidelsen. I de fleste tilfeller setter du denne verdien til `true` hvis du kobler til port `465`. For port `587` eller `25` beholder du `false` |
| `OVERLEAF_EMAIL_SMTP_USER`              | Brukernavnet som skal brukes til autentisering mot SMTP-serveren                                                                                                                                                                                                 |
| `OVERLEAF_EMAIL_SMTP_PASS`              | Passordet som hører til SMTP-brukernavnet                                                                                                                                                                                                                           |
| `OVERLEAF_EMAIL_SMTP_TLS_REJECT_UNAUTH` | Hvis `false`, åpnes en tilkobling til TLS-serveren selv med selvsignert eller ugyldig TLS-sertifikat                                                                                                                                                                        |
| `OVERLEAF_EMAIL_SMTP_IGNORE_TLS`        | Når `true` og `OVERLEAF_EMAIL_SMTP_SECURE` er `false`, brukes ikke TLS selv om serveren støtter `STARTTLS`-utvidelsen                                                                                                                                            |
| `OVERLEAF_EMAIL_SMTP_NAME`              | Valgfritt vertsnavn for TLS-validering hvis `OVERLEAF_EMAIL_SMTP_HOST` er satt til en IP-adresse; standard er maskinens vertsnavn.                                                                                                                                        |
| `OVERLEAF_EMAIL_SMTP_LOGGER`            | Når `true`, skrives loggmeldinger til `web.log`.                                                                                                                                                                                                                        |

#### SMTP-grensesnittet til Amazon SES

Du kan lese mer om hvordan du bruker SMTP-grensesnittet til Amazon SES til å sende e-post [her](https://docs.aws.amazon.com/ses/latest/dg/send-email-smtp.html).

| Navn                       | Beskrivelse                                                                                |
| -------------------------- | ------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST` | Vertsnavnet eller IP-adressen det skal kobles til. Må være tilgjengelig fra Docker-containeren |
| `OVERLEAF_EMAIL_SMTP_PORT` | Porten det skal kobles til                                                                     |
| `OVERLEAF_EMAIL_SMTP_USER` | Brukernavnet som skal brukes til autentisering mot SMTP-serveren                   |
| `OVERLEAF_EMAIL_SMTP_PASS` | Passordet som hører til SMTP-brukernavnet                                             |

#### Amazon SES API

Du kan lese mer om hvordan du bruker Amazon SES API til å sende e-post [her](https://docs.aws.amazon.com/ses/latest/dg/send-email-api.html).

| Navn                                   | Beskrivelse                                 |
| -------------------------------------- | ------------------------------------------- |
| `OVERLEAF_EMAIL_AWS_SES_ACCESS_KEY_ID` | Tilgangsnøkkelen hvis du bruker AWS SES         |
| `OVERLEAF_EMAIL_AWS_SES_SECRET_KEY`    | Den hemmelige nøkkelen hvis du bruker AWS SES         |
| `OVERLEAF_EMAIL_AWS_SES_REGION`        | Hvis ikke satt, er standardregionen US-EAST-1 |

#### AWS SES med instansroller

| Navn                    | Beskrivelse                                                                                                                      |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_DRIVER` | Når denne er satt til `ses`, bruker e-postsystemet SES API-metoden og baserer seg på de konfigurerte instansrollene for å sende e-post. |

#### Tilpasning

| Navn                           | Beskrivelse                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_CUSTOM_EMAIL_FOOTER` | <p>Egendefinert HTML som legges til i alle e-poster, f.eks.<br /><br /><strong>Eksempel</strong>: `"<div>This system is run by department x </div> <div> If you have any questions please look at our faq <a href='`<a href="https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/https:/somwhere.com'%3Ehere&#x3C;/a%3E&#x3C;/div%3E">`https://somwhere.com'>here&#x3C;/a>&#x3C;/div>`</a>`"`</p> |
