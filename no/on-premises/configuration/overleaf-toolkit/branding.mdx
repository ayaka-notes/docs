### Topptekst

I denne delen går vi gjennom hvordan du tilpasser sentrale elementer i den lokale instansen din. Du kan tilpasse nettstedstittelen, navigasjonslenker, topptekst, bunntekst og logo etter eget ønske.

### Nettstedstittel

Tittelen i navigasjonslinjen kan tilpasses med miljøvariabelen `OVERLEAF_NAV_TITLE`. Denne teksten brukes øverst til venstre i navigasjonen hvis ingen logo er angitt.

```bash
# add to config/variables.env
OVERLEAF_NAV_TITLE=Our Overleaf Instance
```

## Logo

Du kan legge til en egendefinert logo i stedet for tekst ved å angi miljøvariabelen `OVERLEAF_HEADER_IMAGE_URL`. Verdien skal peke til en bildefil som ligger på en ekstern server.

```bash title="config/variables.env"
# add to config/variables.env
OVERLEAF_HEADER_IMAGE_URL=https://mysite.somewhere.com/img/logo.png
```

#### Logoer for lyst og mørkt tema

Fra versjon 6.3.0 kan du angi separate logoer for lyst og mørkt tema med miljøvariablene `OVERLEAF_HEADER_IMAGE_URL_LIGHT` og `OVERLEAF_HEADER_IMAGE_URL_DARK`. Begge verdiene skal peke til en bildefil som ligger på en ekstern server.

```text
# add to config/variables.env
OVERLEAF_HEADER_IMAGE_URL_LIGHT=https://mysite.somewhere.com/img/logo-light.png
OVERLEAF_HEADER_IMAGE_URL_DARK=https://mysite.somewhere.com/img/logo-dark.png
```

<Info>

Hvis en av variablene ikke er angitt, faller det aktuelle temaet tilbake til logoen som er angitt i `OVERLEAF_HEADER_IMAGE_URL`.

</Info>

## Navigasjonslenker i toppteksten

Ekstra navigasjonselementer kan legges til i navigasjonstoppteksten ved å sette miljøvariabelen `OVERLEAF_HEADER_EXTRAS` til en JSON-matrise med objekter. For eksempel:

```json wrap
[\
  {\
    "text": "Some link",\
    "url": "http://example.com/somelink",\
    "class": "subdued",\
    "only_when_logged_out": true\
  },\
  {\
    "text": "Help",\
    "class": "subdued",\
    "dropdown": [\
      {\
        "text": "Documentation",\
        "url": "/learn"\
      },\
      {\
        "text": "Contact Admin",\
        "url": "http://example.com/contact"\
      }\
    ]\
  }\
]
```

Legg til den escapede JSON-formen i toolkit/variables.env:

```bash title="toolkit/variables.env" wrap
# add to toolkit/variables.env
OVERLEAF_HEADER_EXTRAS=[{"text":"Some link","url":"http://example.com/somelink","class":"subdued","only_when_logged_out":true},{"text":"Help","class":"subdued","dropdown":[{"text":"Documentation","url":"/learn"},{"text":"Contact Admin","url":"http://example.com/contact"}]}]
```

## Bunntekster

Det er mulig å tilpasse både den venstre og den mindre høyre bunnteksten (som finnes på sider som `/project`) med miljøvariablene `OVERLEAF_LEFT_FOOTER` og `OVERLEAF_RIGHT_FOOTER`. Begge forventer en matrise med JSON-objekter som settes inn.

Begge forventer en JSON-matrise som settes inn.

```json
[\
  {\
    "text": "This is an example text footer entry!"\
  },\
  {\
    "text": "This is an example URL footer link!", "url" : "/my-first-link.htm"\
  }\
]
```

<Info>

Når du bare bruker `text`, må den ikke inneholde HTML, siden verdien gjengis som råtekst.

</Info>

Disse dataene må være gyldig JSON for å fungere, med anførselstegn escapet når de sendes inn som en miljøvariabel.

```bash title="config/variables.env" wrap
# add to config/variables.env
OVERLEAF_LEFT_FOOTER=[{"text": "This is an example text footer entry!"}]
OVERLEAF_RIGHT_FOOTER=["text": "This is an example URL footer link!", "url" : "/my-first-link.htm"]
```

<Info>

I tillegg til `text` og `url` godtar JSON-objektet også egenskapene `class` og `label` for ytterligere tilpasning.

</Info>

### Vedlikeholdsside

Du kan tilpasse meldingen som vises på vedlikeholdssiden med miljøvariabelen `OVERLEAF_MAINTENANCE_MESSAGE`. Denne teksten erstatter standardmeldingen under sidetittelen.

```text wrap
# add to config/variables.env
OVERLEAF_MAINTENANCE_MESSAGE=Our Overleaf Instance is down for maintenance and will be back shortly.
```

For å inkludere lenker eller annen formatering bruker du `OVERLEAF_MAINTENANCE_MESSAGE_HTML` i stedet. Hvis begge er angitt, har `OVERLEAF_MAINTENANCE_MESSAGE_HTML` forrang.

```text wrap
# add to config/variables.env
OVERLEAF_MAINTENANCE_MESSAGE_HTML=Our Overleaf Instance is down for maintenance. For urgent requests, contact <a href="mailto:admin@example.com">admin@example.com</a>.
```

<Info>

`OVERLEAF_MAINTENANCE_MESSAGE` gjengis som ren tekst, så den må **ikke** inneholde HTML. `OVERLEAF_MAINTENANCE_MESSAGE_HTML` gjengis som HTML uten escaping.

</Info>

Hvis ingen av dem er angitt, lenker standardmeldingen til statussiden din når `OVERLEAF_STATUS_PAGE_URL` er angitt, og viser administratorens e-postadresse når den ikke er det.
