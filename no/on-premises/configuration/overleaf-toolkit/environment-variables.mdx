Denne siden beskriver miljøvariablene som støttes i filen `config/variables.env` for Toolkit-distribusjoner.

Filen `config/variables.env` består av variabeldefinisjoner på formen `NAME=value`; linjer som begynner med `#`, behandles som kommentarer.

<Info>

Det er nødvendig å gjenopprette Docker-containerne ved å kjøre `bin/up` etter at du har endret noe i `overleaf.rc` eller `variables.env`.

</Info>

### Alle versjoner

Disse miljøvariablene er kompatible med Server CE og Server Pro og gir en enkel migreringsvei mellom disse to lokale versjonene. De kan også brukes både med Toolkit- og Docker Compose-distribusjoner.

<Info>

Tidligere hadde disse miljøvariablene prefikset `SHARELATEX_` i stedet for `OVERLEAF_`.

</Info>
