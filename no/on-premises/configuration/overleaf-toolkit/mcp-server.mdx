Hvert prosjekt har en MCP-server, slik at AI-klienter som Claude Code, Codex, Cursor, VS Code eller Gemini CLI kan arbeide med det: lese og redigere filene, kompilere prosjektet, lese LaTeX-loggen, laste ned PDF-en og svare på kommentarer.

<Info>

Denne funksjonen er utviklet av [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro). Den er introdusert fra og med v6.3.1.

</Info>

### Oppsett

MCP-serveren følger med Git-integrasjonen: aktiver [git-bridge](/no/on-premises/configuration/overleaf-toolkit/git-integration), så er MCP-serveren også tilgjengelig. Det er ikke noe annet å konfigurere.

### Koble til en AI-klient

1. Generer et Git-autentiseringstoken i **Account Settings**. Det samme tokenet brukes for MCP-serveren og for Git.
2. Åpne **Integrations** i editoren og klikk **MCP server**. Der vises adressen til prosjektets MCP-server, `https://<your-overleaf>/project/<project_id>/mcp`, og hvordan du legger den til i hver AI-klient: kopier kommandoen, og erstatt `<token>` med tokenet ditt.

### Bruk

Når klienten er tilkoblet, spør du AI-klienten med vanlige ord. For eksempel:

| Du spør | AI-klienten bruker |
| --- | --- |
| _Rett skrivefeilene i innledningen._ | `read_file`, `edit_file`: endringene vises i sanntid i editoren |
| _Kompiler prosjektet og rett LaTeX-feilene._ | `compile`, `get_compile_log`, `edit_file` |
| _Svar på de åpne kommentarene, og løs dem deretter._ | `list_comments`, `reply_to_comment`, `resolve_comment` |
| _Bytt til XeLaTeX og last ned PDF-en._ | `update_settings`, `compile`, `get_output_file_link` |

### Verktøy

| Gruppe | Verktøy |
| --- | --- |
| Prosjekt | `get_clone_info`, `get_settings`, `update_settings`, `list_versions` |
| Filer | `list_files`, `read_file`, `edit_file`, `write_file`, `delete_file` |
| Kompilering | `compile`, `get_compile_log`, `get_output_file_link`, `word_count` |
| Kommentarer | `list_comments`, `reply_to_comment`, `resolve_comment`, `reopen_comment` |

Endringer som gjøres med `edit_file` og `write_file`, vises i sanntid i editoren og slås sammen med endringene til samarbeidspartnere. For mange filer samtidig, binærfiler eller navneendringer kan AI-klienten også klone prosjektet med Git og pushe.

### Tillatelser

MCP-serveren følger prosjektets delingsinnstillinger, på samme måte som Git:

* Alle som kan se prosjektet, kan lese det, kompilere det og laste ned utdataene.
* Bare eieren og redaktører kan endre filene og innstillingene.
* Korrekturlesere kan også svare på kommentarer, og løse eller gjenåpne kommentarene de selv har startet.
* Brukere med lesetilgang som ble med via en lenke, kan ikke se kommentarene, på samme måte som i editoren.
