### Operativsystemer

For best mulig opplevelse når du kjører Overleaf, anbefaler vi sterkt å bruke et **Debian-basert** operativsystem, for eksempel **Ubuntu**. Dette valget samsvarer med programvarens utviklingsmiljø og er det foretrukne alternativet blant de fleste Overleaf-brukere.

<Danger>

Når du bruker Server Pro med Sandboxed Compiles, er det **viktig** å merke seg at applikasjonen krever root-tilgang til Docker-socketen.

</Danger>

### Avhengigheter

* Docker 25.0 og 29
* MongoDB 7.0 og 8.0
* Redis 6.2 og 7.5

<Info>

Du kan følge med på End-of-Life-datoer (EOL) for avhengighetene ovenfor og andre populære produkter med tjenesten endoflife.date her: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

MongoDB og Redis hentes automatisk av `docker compose` når du kjører Server CE eller Server Pro, med mindre det er konfigurert til å bruke en annen installasjon.

</Info>

Toolkit avhenger av følgende programmer:

* bash
* Docker

`docker compose` er påkrevd og installeres vanligvis sammen med Docker.

Vi anbefaler at du installerer den nyeste versjonen av Docker som er tilgjengelig for operativsystemet ditt.

Når Docker er riktig installert, skal du kunne kjøre disse kommandoene uten feil:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2)
docker compose version

# List the running Docker containers on your system
docker ps
```
