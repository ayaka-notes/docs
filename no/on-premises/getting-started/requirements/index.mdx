### Krav for installasjon av Server Pro og Community Edition

<Warning>

Vi anbefaler på det sterkeste at du kjører Server Pro på en nyere og stabil versjon av Ubuntu (f.eks. Ubuntu 24.04 i 2025–2026) med en nyere versjon av Docker. Det er mulig å kjøre Server Pro på andre systemer, men det gjør det mye vanskeligere for oss å tilby støtte for Ubuntu/Docker-oppsett som avviker fra standard. Vi kan heller ikke tilby støtte for problemer med selve Docker.

</Warning>
