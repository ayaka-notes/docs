Vi er stolte av å kunngjøre utgivelsen av Ayakaleaf Pro 6.2, den kraftigste og mest funksjonsrike LaTeX-editoren på nett i fellesskapet. En spesiell takk til yu-i-i og davrot for deres verdifulle bidrag. De forbedret GitHub Sync og introduserte Advanced Citation Search og Zotero-integrasjon.

### Merknader

* En ny påkrevd miljøvariabel, `OVERLEAF_INVITE_TOKEN_SECRET`, er innført. Du må generere den med: `openssl rand -base64 32` Hvis den ikke er konfigurert, vil Overleaf-instansen din ikke starte.
* Hvis du aktiverer GitHub Sync, må du konfigurere miljøvariabelen `GITHUB_TOKEN_CIPHER_PASSWORD`. Denne variabelen er påkrevd for å kryptere GitHub-tilgangstokener på en sikker måte. Uten den vil Overleaf-instansen din ikke starte.
* Lagt til en ny miljøvariabel, `DEFAULT_LATEX_COMPILER`, for å angi standardkompilatoren som brukes av nye prosjekter (pdflatex, latex, xelatex eller lualatex).
* Den nydesignede editoren er nå det eneste tilgjengelige alternativet.

### Endringer

Denne utgivelsen inneholder følgende forbedringer og nye funksjoner.

* `MAX_UPLOAD_SIZE` kan nå konfigureres i stedet for å være begrenset til **50 MB**.
* Rettet en omstartsløkke for containeren når sandboxed compiles var deaktivert.
* Innført eierbegrenset sletting av PAT for OAuth2.
* Rettet et problem med LDAP-import.

Funksjonene inkluderer:

* Lagt til en nettleserbasert Python-kjører.
* Lagt til Pandoc-støtte for import og eksport av Markdown, DOCX og andre formater.
* Lagt til GitHub Sync.
* Lagt til fullstendige kinesiske oversettelser.
* Lagt til Zotero-integrasjon.
* Lagt til `DEFAULT_LATEX_COMPILER`.

#### Funksjon 01: GitHub Sync

Hold LaTeX-prosjektene dine synkronisert med GitHub-repositorier for en sømløs utviklingsflyt. Push og pull endringer direkte fra editoren, samarbeid gjennom pull requests og integrer med eksisterende CI/CD-pipelines. Versjonskontroll gjør det enkelt å spore revisjoner, gjennomgå endringer og vedlikeholde reproduserbare akademiske eller tekniske dokumenter.

Se: [GitHub Synchronisation](/no/on-premises/configuration/overleaf-toolkit/github-synchronisation  "mention").

![](https://github.com/user-attachments/assets/5137e708-77cb-4fdf-b081-4aa04b4b762e)

#### Funksjon 02: Pandoc-import/-eksport

Importer Microsoft Word- og Markdown-dokumenter til fullt redigerbare LaTeX-prosjekter, eller eksporter LaTeX-prosjekter tilbake til Markdown og DOCX med ett klikk. Denne funksjonen, drevet av Pandoc, muliggjør sømløs samhandling mellom akademisk skriving, samarbeidsredigering og publiseringsflyter, samtidig som dokumentstrukturen bevares så godt som mulig.

Se: [Pandoc Import and Export](/no/on-premises/configuration/overleaf-toolkit/pandoc-import-and-export  "mention").

#### Funksjon 03: Avansert referansesøk

Søk etter og sett inn bibliografiske referanser fra flere akademiske databaser med intelligent filtrering og umiddelbar sitatstøtte. Finn artikler raskt, forhåndsvis metadata og bygg nøyaktige BibTeX-oppføringer uten å bytte mellom ulike forskningsnettsteder, noe som gjør litteraturgjennomgangen betydelig mer effektiv.

![bilde](https://github.com/user-attachments/assets/42e45b73-af4b-4d1f-81f4-9e116ba5d043)

#### Funksjon 04: Python-kjører

Kjør Python-kode direkte i prosjektet uten å forlate editoren. Perfekt for å generere figurer, behandle datasett, automatisere dokumentflyter eller kjøre reproduserbare forskningsskript. Resultatene kan integreres i LaTeX-dokumentene dine, slik at vitenskapelige beregninger og skriving blir en del av én samlet arbeidsflyt.

![bilde](https://github.com/user-attachments/assets/a4c314b3-fdb5-4836-aea7-12eeece5cd2f)

#### Funksjon 05: Zotero

Koble Zotero-biblioteket ditt direkte til skriveflyten og administrer referanser uten å forlate editoren. Søk i dine personlige Zotero-samlinger, sett inn sitater med ett klikk, og generer og synkroniser BibTeX-oppføringer automatisk. Denne integrasjonen holder bibliografien din oppdatert og effektiviserer litteraturhåndteringen for akademiske artikler, avhandlinger og tekniske dokumenter.

Se: [Zotero Integration](/no/on-premises/configuration/overleaf-toolkit/zotero-integration  "mention").
