Synkroniserer prosjekter med Dropbox: den har én Redis-jobbkø per bruker og en worker som sender Overleaf-endringer til Dropbox og spør Dropbox etter endringer. Bare web kaller den, for å legge jobber i kø og lese køstørrelser.

* <strong>Adresse:</strong> `http://third-party-datastore:3002`, innenfor Docker-nettverket
* <strong>Autentisering:</strong> ingen
* <strong>OpenAPI-fil:</strong> [`develop/hoppscotch/openapi/third-party-datastore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/third-party-datastore.yaml)
