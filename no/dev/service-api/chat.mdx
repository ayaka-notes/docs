Lagrer prosjektchatten og kommentartrådene (meldingene deres og løst-status) i Mongo-samlingene `rooms` og `messages`. Kalles av web via `ChatApiHandler`.

* <strong>Adresse:</strong> `http://chat:3010`, innenfor Docker-nettverket
* <strong>Autentisering:</strong> ingen
* <strong>OpenAPI-fil:</strong> [`develop/hoppscotch/openapi/chat.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/chat.yaml)
