Leverer filer fra objektlagring: malfiler (zip, pdf og forhåndsvisningsbildene deres) og, skrivebeskyttet, prosjekt- og globale blobber som history-v1 skriver. Kalles av web (modulen template-gallery, fil-URL-er for kompileringer) og av clsi, som laster ned binære prosjektfiler derfra.

* <strong>Adresse:</strong> `http://filestore:3009`, innenfor Docker-nettverket
* <strong>Autentisering:</strong> ingen
* <strong>OpenAPI-fil:</strong> [`develop/hoppscotch/openapi/filestore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/filestore.yaml)
