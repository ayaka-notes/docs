Lagrer hele historikken til hvert prosjekt: biter med endringer i Mongo eller Postgres og objektlagring, og filinnhold som blobber. project-history skriver endringer dit; web, project-history og git-bridge leser blobber, øyeblikksbilder og zip-filer derfra.

* <strong>Adresse:</strong> `http://history-v1:3100`, innenfor Docker-nettverket
* <strong>Autentisering:</strong> HTTP basic auth som `staging` med `STAGING_PASSWORD`, eller et JWT, avhengig av ruten.
* <strong>OpenAPI-fil:</strong> [`develop/hoppscotch/openapi/history-v1.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/history-v1.yaml)
