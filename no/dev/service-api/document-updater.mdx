Holder dokumentene som er åpne i editoren i Redis, bruker endringer på dem og skriver dem tilbake til Mongo via web. Kalles av web og real-time.

* <strong>Adresse:</strong> `http://document-updater:3003`, innenfor Docker-nettverket
* <strong>Autentisering:</strong> ingen
