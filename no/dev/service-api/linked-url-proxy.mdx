Henter en ekstern URL for web og strømmer svaret tilbake, og avviser interne adresser slik at brukere ikke når Docker-nettverket. Web sender URL-filer, Open in Overleaf-importer og AI-agentens web_fetch gjennom den.

* <strong>Adresse:</strong> `http://linked-url-proxy:3066`, innenfor Docker-nettverket
* <strong>Autentisering:</strong> ingen
* <strong>OpenAPI-fil:</strong> [`develop/hoppscotch/openapi/linked-url-proxy.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/linked-url-proxy.yaml)
