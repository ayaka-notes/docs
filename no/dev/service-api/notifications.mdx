Lagrer varslene som vises for brukere i prosjektlisten (for eksempel prosjektinvitasjoner) i Mongo-samlingen `notifications`. Web og third-party-datastore kaller den; den har ingen autentisering og kan bare nås innenfor Docker-nettverket.

* <strong>Adresse:</strong> `http://notifications:3042`, innenfor Docker-nettverket
* <strong>Autentisering:</strong> ingen
* <strong>OpenAPI-fil:</strong> [`develop/hoppscotch/openapi/notifications.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/notifications.yaml)
