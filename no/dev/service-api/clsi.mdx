CLSI (Common LaTeX Service Interface) kompilerer prosjekter, kjører SyncTeX og texcount på kompileringsutdataene og konverterer dokumenter med pandoc. Web kaller den; selve utdatafilene leveres av clsi-nginx, ikke av denne porten. Ingen autentisering: den kan bare nås innenfor Docker-nettverket.

* <strong>Adresse:</strong> `http://clsi:3013`, innenfor Docker-nettverket
* <strong>Autentisering:</strong> ingen
* <strong>OpenAPI-fil:</strong> [`develop/hoppscotch/openapi/clsi.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/clsi.yaml)
