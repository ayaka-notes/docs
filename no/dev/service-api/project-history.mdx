Setter hvert prosjekts endringer i kø i Redis, gjør dem om til historikkendringer og sender dem til history-v1; den lagrer også historikketiketter, resynkroniseringsstatus og feilposter i Mongo. Kalles av web, document-updater, history-v1 og server-ce-cronskriptene; den har ingen autentisering.

* <strong>Adresse:</strong> `http://project-history:3054`, innenfor Docker-nettverket
* <strong>Autentisering:</strong> ingen
* <strong>OpenAPI-fil:</strong> [`develop/hoppscotch/openapi/project-history.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/project-history.yaml)
