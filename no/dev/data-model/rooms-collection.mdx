`rooms` inneholder ett dokument per chatterom i et prosjekt: prosjektchatten eller én tråd med gjennomgangskommentarer. Bare chat-tjenesten skriver den, i `services/chat/app/js/Features/Threads/ThreadManager.js`. Det finnes ikke noe Mongoose-skjema. Meldingene i et rom ligger i samlingen [messages](/no/dev/data-model/messages-collection).

#### Felter {#fields}

| Felt | Type | Betydning | Kilde |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Rom-id. `messages.room_id` peker hit. | `ThreadManager.js:57-61` |
| `project_id` | ObjectId | Prosjektet rommet hører til. | `ThreadManager.js:43-54` |
| `thread_id` | ObjectId | Bare på kommentartråder: kommentarens id, den samme som `id` og `op.t` for kommentaren i `docs.ranges.comments` (se [docs](/no/dev/data-model/docs-collection)). Mangler på prosjektchattens rom. | `ThreadManager.js:38-55`, `services/docstore/app/js/RangeManager.js:54-57` |
| `resolved` | Object | Settes når tråden løses, og fjernes når den gjenåpnes. En tråd uten feltet er åpen. | `ThreadManager.js:94-123` |
| `resolved.user_id` | String | Id-en til brukeren som løste tråden. Lagres som en streng, ikke som ObjectId: forespørselens body sjekkes bare for gyldig id og konverteres ikke. | `ThreadManager.js:103`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:70` |
| `resolved.ts` | Date | Når tråden ble løst. | `ThreadManager.js:104` |

#### Merknader {#notes}

* Et prosjekt har høyst ett rom uten `thread_id`: prosjektchatten. Chat-tjenesten finner det med `thread_id: { $exists: false }` (`ThreadManager.js:38-45`).
* Løst-statusen til en kommentar finnes bare her. Docstore fjerner `op.resolved` før den lagrer områder (`services/docstore/app/js/RangeManager.js:59-61`).
* Etter en prosjektkopi finnes den samme `thread_id` i to prosjekter. Spør alltid på `project_id` og `thread_id` sammen, slik chat-tjenesten gjør.
* Rommene i et slettet prosjekt blir liggende til det slettede prosjektet utløper.
