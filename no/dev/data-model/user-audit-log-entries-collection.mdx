title: User Audit Log Entries-samlingen
icon: user-clock

`userAuditLogEntries` er revisjonsloggen for brukerkontoer: innlogginger, endringer av passord og e-post, tilknyttede kontoer og administratorhandlinger. Ett dokument er én hendelse på én konto. `web` eier den; skjemaet er `services/web/app/src/models/UserAuditLogEntry.mjs`, og kjernen skriver via `services/web/app/src/Features/User/UserAuditLogHandler.mjs`.
