---
title: OAuth Authorization Codes-samlingen
icon: lock-open
---

`oauthAuthorizationCodes` er ment for kodene i OAuth-flyten authorization code: ett dokument per kode, som en klient bytter mot et tilgangstoken. Skjemaet er `services/web/app/src/models/OauthAuthorizationCode.mjs`, og webmodulen `oauth2-server` har koden som ville skrevet til den. I Ayakaleaf Pro når ingenting den koden, så samlingen forblir tom (se Merknader).

#### Felter {#fields}

| Felt | Type | Betydning | Kilde |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Dokument-id. | `OauthAuthorizationCode.mjs:6` |
| `authorizationCode` | String | Selve koden, lagret som den er (ikke hashet). | `OauthAuthorizationCode.mjs:8`, `services/web/modules/oauth2-server/app/src/OAuth2Model.mjs:280` |
| `expiresAt` | Date | Slutten på gyldigheten. `getAuthorizationCode` avviser en kode etter dette, og TTL-indeksen sletter den. | `OauthAuthorizationCode.mjs:9`, `OAuth2Model.mjs:150-153,281` |
| `oauthApplication_id` | ObjectId | Klienten i [OAuth Applications](/no/dev/data-model/oauth-applications-collection) som ba om koden. | `OauthAuthorizationCode.mjs:10`, `OAuth2Model.mjs:275-284` |
| `redirectUri` | String | Forespørselens omdirigerings-URI. | `OauthAuthorizationCode.mjs:11`, `OAuth2Model.mjs:282` |
| `scope` | String | Forespurt scope. | `OauthAuthorizationCode.mjs:12`, `OAuth2Model.mjs:283` |
| `user_id` | ObjectId | Brukeren som ga koden. | `OauthAuthorizationCode.mjs:13`, `OAuth2Model.mjs:285` |
| `codeChallenge`, `codeChallengeMethod` | String | PKCE-challenge og metoden for den. | `OauthAuthorizationCode.mjs:14-15`, `OAuth2Model.mjs:286-287` |

#### Hvem skriver {#who-writes-it}

| Kode | Hva den gjør |
| ---- | ------------ |
| `OAuth2Model.mjs:274-300` (`saveAuthorizationCode`) | Setter inn en kode. Nås ikke, se Merknader. |
| `OAuth2Model.mjs:307-312` (`revokeAuthorizationCode`) | Sletter en kode når den er brukt. Nås ikke. |

#### Hvem leser {#who-reads-it}

| Kode | Hva den gjør |
| ---- | ------------ |
| `OAuth2Model.mjs:137-177` (`getAuthorizationCode`) | Laster en kode med tilhørende bruker og klient. Nås ikke. |

#### Indekser {#indexes}

| Navn | Nøkler | Alternativer | Migrering |
| ---- | ---- | ------- | --------- |
| `expiresAt_1` | `{ expiresAt: 1 }` | TTL, `expireAfterSeconds: 0`, delvis: `expiresAt` finnes | `20230406125632_oauth_tokens_ttl.mjs` |

Migreringene ligger i `tools/migrations/`. Den unike indeksen `authorizationCode_1` kommer bare fra migreringer merket `saas` og `server-pro`, som Community Edition ikke kjører.

#### Merknader {#notes}

* Modellmetodene over kalles bare av authorize- og token-håndtererne i `@node-oauth/oauth2-server`. Web bruker det biblioteket bare til å sjekke bearer-tokener (`services/web/app/src/Features/Authentication/AuthenticationController.mjs:409-450`), og ingen rute betjener `/oauth/authorize` eller `/oauth/token`, så ingen kode blir noen gang skrevet. Personlige tilgangstokener opprettes direkte, se [OAuth Access Tokens](/no/dev/data-model/oauth-access-tokens-collection).
