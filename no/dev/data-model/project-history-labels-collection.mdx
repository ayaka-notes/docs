title: Project-History-Labels-samlingen

`projectHistoryLabels` inneholder etikettene brukere setter på versjoner i History-visningen, ett dokument per etikett. project-history eier den og skriver den i `services/project-history/app/js/LabelsManager.js`; det finnes ikke noe Mongoose-skjema. Web når den bare gjennom project-history-API-et.

#### Felter {#fields}

| Felt | Type | Betydning | Kilde |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Etikett-id. | `LabelsManager.js:81-85` |
| `project_id` | ObjectId | Prosjektet. | `LabelsManager.js:73` |
| `comment` | String | Etikettteksten. | `LabelsManager.js:74` |
| `version` | Number | Prosjekthistorikkversjonen etiketten peker på. | `LabelsManager.js:75` |
| `created_at` | Date | Når etiketten ble laget; forespørselen kan sende sin egen tid, ellers er det nå. | `LabelsManager.js:70`, `76` |
| `user_id` | ObjectId | Hvem som laget etiketten. Utelates når forespørselen ikke har noen bruker. | `LabelsManager.js:78-80` |

#### Hvem skriver {#who-writes-it}

| Kode | Hva den gjør |
| ---- | ------------ |
| `services/project-history/app/js/LabelsManager.js:44-90` | `createLabel`: setter inn en etikett, for project-history `POST /project/:project_id/labels` (`services/project-history/app/js/HttpController.js:1134-1171`). Web kaller den når en bruker legger til en etikett, med brukerens id (`services/web/app/src/Features/History/HistoryController.mjs:529-546`). |
| `LabelsManager.js:113-126` | `deleteLabel`: sletter en etikett i prosjektet, for `DELETE /project/:project_id/labels/:label_id`. Web bruker den når prosjekteieren sletter en etikett (`HistoryController.mjs:649-670`). |
| `LabelsManager.js:92-111` | `deleteLabelForUser`: sletter en etikett bare hvis brukeren laget den, for `DELETE /project/:project_id/user/:user_id/labels/:label_id`. Web bruker den for alle andre. |
| `LabelsManager.js:128-143` | `transferLabels`: flytter alle etikettene til én bruker over til en annen, for `POST /user/:from_user/labels/transfer/:to_user` (`services/project-history/app/js/Router.js:52-55`). Ingenting i web kaller denne ruten. |
| `LabelsManager.js:7-25` | `cloneLabels`: kopierer et prosjekts etiketter til et annet prosjekt, for project-history `POST /project/:project_id/clone` (`HttpController.js:113`), som ingenting i web kaller. |

#### Merknader {#notes}

* Før project-history setter inn en etikett, behandler den prosjektets oppdateringer i køen og sjekker at history-v1 har en chunk for den versjonen, med mindre forespørselen sender `validate_exists: false` (`LabelsManager.js:53-59`, `173-195`; `HttpController.js:1109-1115`).
* Ingen kode sletter et prosjekts etiketter når prosjektet slettes: project-history `DELETE /project/:project_id` tømmer bare synkroniseringsstatusen og feilposten (`HttpController.js:1363-1396`), og ingen annen tjeneste rører denne samlingen.
