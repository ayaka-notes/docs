title: Spelling Preferences-samlingen
icon: spell-check

`spellingPreferences` inneholder hver brukers ordliste: ordene brukeren har lagt til via "Add to dictionary" i stavekontrollen i redigeringsprogrammet. Ett dokument per bruker. `web` eier den, uten Mongoose-skjema; koden er `services/web/app/src/Features/Spelling/LearnedWordsManager.mjs`.

#### Felter {#fields}

| Felt | Type | Betydning | Kilde |
| --- | --- | --- | --- |
| `_id` | ObjectId | Dokumentets id, opprettet av upserten. | `LearnedWordsManager.mjs:21-31` |
| `token` | String | Brukerens id. Til tross for navnet sender staverutene id-en til den innloggede brukeren (`SessionManager.getLoggedInUserId`). | `LearnedWordsManager.mjs:23` |
| `learnedWords` | Array of String | Ordene brukeren har lagt til. | `LearnedWordsManager.mjs:26` |

#### Hvem skriver {#who-writes-it}

| Kode | Hva den gjør |
| --- | --- |
| `LearnedWordsManager.mjs:13-32` (`learnWord`) | `POST /spelling/learn` (`services/web/app/src/router.mjs:1037-1041`, `services/web/app/src/Features/Spelling/SpellingController.mjs:45-58`): `$addToSet` av ordet, med upsert. Avviser når listen ville blitt større enn `Settings.maxDictionarySize` byte. |
| `LearnedWordsManager.mjs:38-47` (`unlearnWord`) | `POST /spelling/unlearn` (`router.mjs:1043-1047`, `SpellingController.mjs:66-79`): `$pull` av ordet. |
| `LearnedWordsManager.mjs:84-86` (`deleteUsersLearnedWords`) | Sletter dokumentet. Den eneste innpakningen, `SpellingHandler.deleteUserDictionary` (`services/web/app/src/Features/Spelling/SpellingHandler.mjs:24-26`), kalles ingen steder i web eller modulene. |

#### Hvem leser {#who-reads-it}
