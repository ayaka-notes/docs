title: Tokens-samlingen
icon: key
---

`tokens` inneholder engangstokener: hemmeligheten i en lenke som lar noen sette et passord. Ett dokument er ett token. Det finnes ingen Mongoose-modell; web skriver samlingen via `services/web/app/src/Features/Security/OneTimeTokenHandler.mjs` med den innebygde driveren.

#### Felter {#fields}

| Felt | Type | Betydning | Kilde |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Dokument-id. | `OneTimeTokenHandler.mjs:40` |
| `use` | String | Hva tokenet er til, se [Bruksområder](#uses) nedenfor. Hvert oppslag filtrerer på det. | `OneTimeTokenHandler.mjs:41` |
| `token` | String | Hemmeligheten i lenken: 32 tilfeldige byte som 64 hekstegn, lagret som det er. | `OneTimeTokenHandler.mjs:38,42` |
| `data` | Object | Hva tokenet står for; returneres når det brukes. | `OneTimeTokenHandler.mjs:43` |
| `data.user_id` | String | Brukerens id, skrevet som streng av hver kaller. | `services/web/app/src/Features/PasswordReset/PasswordResetHandler.mjs:27`, `services/web/app/src/Features/User/UserRegistrationHandler.mjs:117`, `services/web/modules/admin-tools/app/src/AdminUserManager.mjs:79` |
| `data.email` | String | Brukerens e-post da tokenet ble laget. En tilbakestilling av passord slår opp brukeren via denne primære e-posten (`PasswordResetHandler.mjs:66-70`). | samme som `data.user_id` |
| `createdAt` | Date | Tidspunkt for opprettelse. TTL-indeksen sletter tokenet 90 dager senere. | `OneTimeTokenHandler.mjs:36,44` |
| `expiresAt` | Date | `createdAt` pluss `expiresIn` sekunder: 1 time som standard, 1 uke for en aktiveringslenke. Oppslag ignorerer et token etter dette tidspunktet. | `OneTimeTokenHandler.mjs:35-37,45` |
| `peekCount` | Number | Hvor mange ganger tokenet er sett på uten å bli brukt. Hver `peekValueFromToken` legger til 1; ved 4 (`MAX_PEEKS`) slutter tokenet å virke. | `OneTimeTokenHandler.mjs:8-31,107` |
| `usedAt` | Date | Tidspunkt da tokenet ble brukt eller kansellert. Oppslag ignorerer et token som har det. | `OneTimeTokenHandler.mjs:51-104` |

| `use` | Funksjon | Utløper | Kode |
| ----- | ------- | ------ | ---- |
| `password` | E-post for tilbakestilling av passord, fra siden "glemt passord" | 1 time | `PasswordResetHandler.mjs:14-42` |

| `email_confirmation` | Lenke for å bekrefte e-post. Leses bare: ingenting i dette repoet lager slike tokener lenger, siden bekreftelsen nå sender en 6-sifret kode (`services/web/app/src/Features/User/UserEmailsConfirmationHandler.mjs:15-35`) | | `UserEmailsConfirmationHandler.mjs:12,37-66` |

#### Hvem skriver {#who-writes-it}

| Kode | Hva den gjør |
| ---- | ------------ |
| `OneTimeTokenHandler.mjs:34-49` (`getNewToken`) | Setter inn et token. Kallere: `PasswordResetHandler.mjs:28`, `UserRegistrationHandler.mjs:115-119`, `AdminUserManager.mjs:77-81`. |
| `OneTimeTokenHandler.mjs:8-32` (`peekValueFromToken`) | Returnerer `data` for et gyldig token og legger 1 til `peekCount`. Brukes når siden for tilbakestilling av passord åpnes (`services/web/app/src/Features/PasswordReset/PasswordResetController.mjs:195-208`), igjen når det nye passordet settes (`PasswordResetHandler.mjs:94-96`), og av e-postbekreftelsen (`UserEmailsConfirmationHandler.mjs:38-41`). |
| `OneTimeTokenHandler.mjs:75-88` (`expireToken`) | Setter `usedAt` på ett token: etter at et nytt passord er satt (`PasswordResetHandler.mjs:44-48,119`) eller en e-post er bekreftet (`UserEmailsConfirmationHandler.mjs:65`). |
| `OneTimeTokenHandler.mjs:90-104` (`expireAllTokensForUser`) | Setter `usedAt` på hvert åpne `password`-token for en bruker, når brukeren endrer passordet i innstillingene (`services/web/app/src/Features/User/UserController.mjs:146-149`) eller en administrator setter det i adminpanelet (`AdminUserManager.mjs:479-488`). |

#### Merknader {#notes}

* Et brukt eller utløpt token slettes ikke med en gang: det blir værende, med `usedAt` eller en passert `expiresAt`, til TTL-indeksen fjerner det 90 dager etter `createdAt`.
* `OneTimeTokenHandler` har også `getValueFromTokenAndExpire` (`OneTimeTokenHandler.mjs:51-73`), men ingenting kaller den.
