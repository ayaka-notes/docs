`tags` inneholder taggene (mappene) som en bruker sorterer prosjekter i på prosjektoversikten. Ett dokument er én tagg for én bruker. `web` eier den; skjemaet er `services/web/app/src/models/Tag.mjs`, og alle skrivinger går via `services/web/app/src/Features/Tags/TagsHandler.mjs`.

#### Felter {#fields}

| Felt | Type | Betydning | Kilde |
| --- | --- | --- | --- |
| `_id` | ObjectId | Taggens id, brukt i rutene `/tag/:tagId`. | `Tag.mjs:10` |
| `user_id` | String | Taggens eier. En vanlig streng, ikke en ObjectId, av historiske grunner. | `Tag.mjs:7-12` |
| `name` | String | Taggnavn, høyst 50 tegn (`MAX_TAG_LENGTH`). Unikt per bruker. | `Tag.mjs:13`, `TagsHandler.mjs:4` |
| `color` | String | Valgfri farge: en hex-kode som `#a1b2c3` eller en verdi `hsl(<n>, 70%, 45%)` (`TAG_COLOR_REGEX`). | `Tag.mjs:5`, `Tag.mjs:14-22` |
| `project_ids` | Array of String | Id-er for prosjektene i denne taggen, som strenger. | `Tag.mjs:23` |
| `__v` | Number | Mongoose-versjonsnøkkel, lagt til når `Tag.create` oppretter dokumentet. | `TagsHandler.mjs:27` |

Den samme migreringen opprettet også `user_id_1`; `tools/migrations/20231031164732_drop_redundant_indexes.mjs` fjerner den igjen, siden den sammensatte indeksen dekker den.

#### Merknader {#notes}

* Tagger er per bruker: to samarbeidspartnere på samme prosjekt har hver sine egne tagger for det.
* `user_id` og `project_ids` er strenger, så spør etter dem med streng-id-er, ikke ObjectId-er.
* Å slette en bruker (`services/web/app/src/Features/User/UserDeleter.mjs`) berører ikke `tags`.
