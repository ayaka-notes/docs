`oauthAccessTokens` inneholder bearer-tokenene som web godtar. I Ayakaleaf Pro er dette de personlige tilgangstokenene (Git-autentiseringstokener) som en bruker oppretter på siden for kontoinnstillinger og bruker for git-bridge og MCP-endepunktet. Ett dokument er ett token. Skjemaet er `services/web/app/src/models/OauthAccessToken.mjs`; webmodulen `oauth2-server` skriver samlingen, for det meste med den innebygde driveren.

#### Merknader {#notes}

* Å slette en bruker sletter ikke brukerens tokener. `UserDeleter` utløser hooken `cleanupPersonalAccessTokens` (`services/web/app/src/Features/User/UserDeleter.mjs:230-234`), men ingen modul lytter på den. Begge tokensjekkene avviser tokenene fordi brukeren er borte, og TTL-indeksen fjerner dem én dag etter `accessTokenExpiresAt`.
* Å suspendere en bruker avslutter bare øktene. Tokenene blir værende, og begge tokensjekkene avviser dem så lenge `users.suspended` er `true` (`OAuth2Model.mjs:51-54`, `OAuthPersonalAccessTokenManager.mjs:129-134`).
