`docSnapshots` inneholder kopier av et doc som document-updater tar rett før en redigering som slår sammen kommentarer eller sporede endringer. Bare document-updater skriver den, i `services/document-updater/app/js/SnapshotManager.js`. Web har en Mongoose-modell i `services/web/app/src/models/DocSnapshot.mjs`, men ingen kode bruker den.

#### Felter {#fields}

| Felt | Type | Betydning | Kilde |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Øyeblikksbildets id. | `SnapshotManager.js:24` |
| `project_id` | ObjectId | Prosjekt. | `SnapshotManager.js:19,26`, `DocSnapshot.mjs:7` |
| `doc_id` | ObjectId | Doc-et (`docs._id`). | `SnapshotManager.js:20,27`, `DocSnapshot.mjs:8` |
| `version` | Number | Doc-ets OT-versjon før redigeringen. | `SnapshotManager.js:28`, `services/document-updater/app/js/UpdateManager.js:132,264-271`, `DocSnapshot.mjs:9` |
| `lines` | Array of String | Doc-ets innhold før redigeringen. | `SnapshotManager.js:29`, `DocSnapshot.mjs:10` |
| `pathname` | String | Doc-ets sti i prosjektet på det tidspunktet. | `SnapshotManager.js:30`, `DocSnapshot.mjs:11` |
| `ranges` | Mixed | `comments` og `changes` før redigeringen, i samme form som `docs.ranges` (se [docs](/no/dev/data-model/docs-collection)). `id`, `op.t` og `metadata.user_id` gjøres om til ObjectId-er og `metadata.ts` til Date-er. | `SnapshotManager.js:31,41-68`, `DocSnapshot.mjs:12` |
| `ts` | Date | Når øyeblikksbildet ble tatt. TTL-indeksen sletter det 30 dager senere. | `SnapshotManager.js:32`, `DocSnapshot.mjs:13` |

#### Hvem skriver {#who-writes-it}

| Kode | Hva den gjør |
| ---- | ------------ |
| `UpdateManager.js:248-271` | Etter at document-updater har brukt en redigering, lagrer den doc-et slik det var før redigeringen hvis redigeringen slo sammen områder: flere områder ble tomme, eller mer enn ett område ble fjernet (`services/document-updater/app/js/RangesManager.js:104-106`). |
| `SnapshotManager.js:17-36` `recordSnapshot` | Setter inn øyeblikksbildet. |

#### Hvem leser {#who-reads-it}

Ingen kode leser den. Web-modellen er definert, men brukes ingen steder.

#### Merknader {#notes}

* Bare redigeringer som går gjennom `UpdateManager.applyUpdate` tar øyeblikksbilder. Redigeringer som `HistoryOTUpdateManager` håndterer gjør det ikke (`UpdateManager.js:74-77`).
* Det finnes ingen indeks på `doc_id`. Finn øyeblikksbildene til et doc med `project_id` og `ts`, og filtrer deretter på `doc_id`.
