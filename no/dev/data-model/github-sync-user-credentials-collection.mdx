---
title: GitHub Sync User Credentials-samlingen
icon: key
---

`githubSyncUserCredentials` inneholder ett dokument per bruker som har koblet en GitHub-konto for GitHub Sync. Den lagrer brukerens OAuth-tilgangstoken, kryptert. Samlingen hører til webmodulen `github-sync` (`services/web/modules/github-sync`). Skjemaet ligger i `services/web/modules/github-sync/app/models/githubSyncUserCredentials.mjs`, og all tilgang går gjennom `services/web/modules/github-sync/app/src/TokenManager.mjs`.

#### Felter {#fields}

| Felt | Type | Betydning | Kilde |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Settes av Mongoose når upserten setter inn. | |
| `userId` | ObjectId | Overleaf-brukeren. Påkrevd. Skjemaet sier `unique: true`, men ingen indeks bygges (se Indekser); upserten på `userId` holder ett dokument per bruker. | `githubSyncUserCredentials.mjs:8`, `TokenManager.mjs:44-48` |
| `github` | String | GitHub sitt OAuth-tilgangstoken, kryptert med `@overleaf/access-token-encryptor`. Passordet kommer fra `GITHUB_TOKEN_CIPHER_PASSWORD`; chifferetiketten er `GITHUB_TOKEN_CIPHER_LABEL`, standard `2026.3-v3`. Påkrevd. | `githubSyncUserCredentials.mjs:9`, `TokenManager.mjs:12-25` |
| `__v` | Number | Mongoose sin versjonsnøkkel. Skjemaet slår den ikke av. | Mongoose-standard |

Bare tilgangstokenet lagres: OAuth-callbacken beholder `access_token` fra svaret til GitHub (`services/web/modules/github-sync/app/src/GitHubApiClient.mjs:180-191`). Det finnes ingen oppdateringstoken eller utløpstid.

#### Hvem skriver {#who-writes-it}

| Kode | Hva den gjør |
| ---- | ------------ |
| `TokenManager.mjs:42-58` (`saveUserToken`) | Gjør upsert av brukerens krypterte token. Når brukeren kobler på nytt, tilbakekalles det erstattede tokenet hos GitHub i bakgrunnen. Kalles fra OAuth-callbacken (`services/web/modules/github-sync/app/src/GitHubSyncController.mjs:146`). |
| `TokenManager.mjs:61-76` (`removeUserToken`) | Tilbakekaller tokenet hos GitHub (så langt det går), og sletter deretter dokumentet. Kalles ved frakobling (`GitHubSyncController.mjs:167`) og når en slettet bruker utløper (`services/web/modules/github-sync/index.mjs:66-68`). |

#### Hvem leser {#who-reads-it}

| Kode | Hva den gjør |
| ---- | ------------ |
| `TokenManager.mjs:36-40` (`getUserToken`) | Dekrypterer tokenet for hvert kall til GitHub sitt API: `services/web/modules/github-sync/app/src/GitHubSyncHandler.mjs` (for eksempel `:27`) og `services/web/modules/github-sync/app/src/GitMerge.mjs:43`. Uten dokument, eller med et token som ikke kan dekrypteres, kaster den `InvalidTokenError`, og brukeren regnes som ikke koblet (`GitHubSyncHandler.mjs:25-37`). |
| `services/web/modules/admin-tools/app/src/AdminUserListManager.mjs:393` | Sjekker om brukeren har et dokument, for integrasjonene som vises i adminpanelet. |

#### Indekser {#indexes}

| Navn | Nøkler | Alternativer | Migrering |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

Mongoose `autoIndex` er slått av (`services/web/app/src/infrastructure/Mongoose.mjs:7`), så skjemaets `unique: true` på `userId` oppretter ingenting. `tools/migrations/20190912145011_create_githubSyncUserCredentials_indexes.mjs` (upstreams `user_id`) er bare merket `saas` og kjører ikke i CE.

#### Merknader {#notes}

* Å endre `GITHUB_TOKEN_CIPHER_PASSWORD` gjør de lagrede tokenene uleselige. Disse brukerne regnes da som ikke koblet til de kobler på nytt.
* En slettet bruker beholder dokumentet til brukeren utløper.
