---
title: Oppdatere i18n-oversettelser
icon: language
---

Det finnes en fil i `services/web/frontend/extracted-translations.json`, og Overleaf web bruker kun de uttrukne oversettelsene i denne filen.

Kjør følgende kommando for å oppdatere de uttrukne oversettelsene hvis du har lagt til innhold.

```bash
user ➜ ~/overleaf-pro/develop (server-pro) $ bin/shell webpack
root@432836260f8a:/overleaf/services/web# npm run extract-translations
```

Generelt bør du ikke redigere oversettelsesfilene. Bruk eksisterende oversettelser først, siden alle disse filene oppdateres fra Overleaf upstream eller fra et tredjeparts oversettelsesnettsted.
