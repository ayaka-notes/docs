Menyimpan notifikasi yang ditampilkan kepada pengguna di daftar proyek (misalnya undangan proyek) di koleksi Mongo `notifications`. Web dan third-party-datastore memanggilnya; tidak memiliki autentikasi dan hanya dapat dijangkau di dalam jaringan Docker.

* <strong>Alamat:</strong> `http://notifications:3042`, di dalam jaringan Docker
* <strong>Autentikasi:</strong> tidak ada
* <strong>File OpenAPI:</strong> [`develop/hoppscotch/openapi/notifications.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/notifications.yaml)
