CLSI (Common LaTeX Service Interface) mengompilasi proyek, menjalankan SyncTeX dan texcount pada keluaran kompilasi, dan mengonversi dokumen dengan pandoc. Web memanggilnya; file keluarannya sendiri disajikan oleh clsi-nginx, bukan oleh port ini. Tanpa autentikasi: hanya dapat dijangkau di dalam jaringan Docker.

* <strong>Alamat:</strong> `http://clsi:3013`, di dalam jaringan Docker
* <strong>Autentikasi:</strong> tidak ada
* <strong>File OpenAPI:</strong> [`develop/hoppscotch/openapi/clsi.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/clsi.yaml)
