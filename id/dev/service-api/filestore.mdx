Menyajikan file dari penyimpanan objek: file templat (zip, pdf, dan gambar pratinjaunya) dan, hanya-baca, blob proyek dan global yang ditulis history-v1. Dipanggil oleh web (modul template-gallery, URL file kompilasi) dan oleh clsi, yang mengunduh file biner proyek darinya.

* <strong>Alamat:</strong> `http://filestore:3009`, di dalam jaringan Docker
* <strong>Autentikasi:</strong> tidak ada
* <strong>File OpenAPI:</strong> [`develop/hoppscotch/openapi/filestore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/filestore.yaml)
