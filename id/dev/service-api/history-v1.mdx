Menyimpan riwayat lengkap setiap proyek: potongan perubahan di Mongo atau Postgres dan penyimpanan objek, serta isi file sebagai blob. project-history menulis perubahan ke sana; web, project-history, dan git-bridge membaca blob, snapshot, dan zip darinya.

* <strong>Alamat:</strong> `http://history-v1:3100`, di dalam jaringan Docker
* <strong>Autentikasi:</strong> HTTP basic auth sebagai `staging` dengan `STAGING_PASSWORD`, atau JWT, tergantung rutenya.
* <strong>File OpenAPI:</strong> [`develop/hoppscotch/openapi/history-v1.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/history-v1.yaml)
