Menyinkronkan proyek dengan Dropbox: menyimpan satu antrean pekerjaan Redis per pengguna dan worker yang mengirim perubahan Overleaf ke Dropbox serta memeriksa Dropbox untuk perubahan. Hanya web yang memanggilnya, untuk mengantrekan pekerjaan dan membaca ukuran antrean.

* <strong>Alamat:</strong> `http://third-party-datastore:3002`, di dalam jaringan Docker
* <strong>Autentikasi:</strong> tidak ada
* <strong>File OpenAPI:</strong> [`develop/hoppscotch/openapi/third-party-datastore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/third-party-datastore.yaml)
