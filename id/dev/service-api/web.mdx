API privat dari web, aplikasi utama Overleaf. Layanan lain (real-time, document-updater, project-history, third-party-datastore, git-bridge) dan skrip cron image Server CE memanggilnya. Rute ini hanya memerlukan HTTP basic auth, tanpa token CSRF: router privat dipasang sebelum router web, dan hanya router web yang menjalankan pemeriksaan CSRF. Dengan `BLOCK_CROSS_ORIGIN_REQUESTS=true` (nonaktif secara default), web mengembalikan 403 untuk setiap permintaan yang header `Origin`-nya tidak ada di `ALLOWED_ORIGINS` (default: URL situs). Browser mengirim `Origin` pada POST, jadi dengan pengaturan itu aktif, POST yang dikirim dari Hoppscotch di browser mendapat 403 kecuali melewati proxy Hoppscotch.

* <strong>Alamat:</strong> `http://web:3000`, di dalam jaringan Docker
* <strong>Autentikasi:</strong> HTTP basic auth dengan `WEB_API_USER` dan `WEB_API_PASSWORD`, kecuali untuk status, health, dan metrics. Rute git-bridge menggunakan token akses pribadi sebagai gantinya.
* <strong>File OpenAPI:</strong> [`develop/hoppscotch/openapi/web.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/web.yaml)
