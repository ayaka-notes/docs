Mengantrekan suntingan setiap proyek di Redis, mengubahnya menjadi perubahan riwayat, dan mengirimkannya ke history-v1; juga menyimpan label riwayat, status sinkronisasi ulang, dan catatan kegagalan di Mongo. Dipanggil oleh web, document-updater, history-v1, dan skrip cron server-ce; tidak memiliki autentikasi.

* <strong>Alamat:</strong> `http://project-history:3054`, di dalam jaringan Docker
* <strong>Autentikasi:</strong> tidak ada
