Overleaf berjalan sebagai beberapa layanan yang saling memanggil melalui HTTP di dalam jaringan Docker. Halaman di bagian ini menjelaskan API internal tersebut. Isinya berasal dari file OpenAPI di [`develop/hoppscotch/openapi/`](https://github.com/ayaka-notes/ayakaleaf-pro/tree/server-pro/develop/hoppscotch/openapi), yang ditulis berdasarkan kode setiap layanan.

Tidak satu pun API ini bersifat publik: semuanya hanya dapat dijangkau di dalam jaringan Docker, dan sebagian besar tidak memiliki autentikasi.

## Layanan {#services}

| Layanan | Alamat | Fungsinya |
| ------------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------------------ |
| [web](/id/dev/service-api/web)                                     | `http://web:3000`                   | Aplikasi utama. API privatnya dipanggil oleh layanan lain dan skrip cron image  |
| [document-updater](/id/dev/service-api/document-updater)           | `http://document-updater:3003`      | Menyimpan dokumen yang terbuka di editor di Redis, menerapkan suntingan, dan menuliskannya kembali ke Mongo         |
| [docstore](/id/dev/service-api/docstore)                           | `http://docstore:3016`              | Menyimpan setiap dokumen dari setiap proyek di koleksi Mongo `docs`                                 |
| [real-time](/id/dev/service-api/real-time)                         | `http://real-time:3026`             | Menangani koneksi socket.io editor dan meneruskan suntingan antara browser dan layanan          |
| [chat](/id/dev/service-api/chat)                                   | `http://chat:3010`                  | Menyimpan obrolan proyek dan utas komentar                                                  |
| [project-history](/id/dev/service-api/project-history)             | `http://project-history:3054`       | Mengubah suntingan dalam antrean menjadi perubahan riwayat dan mengirimkannya ke history-v1; menyimpan label               |
| [history-v1](/id/dev/service-api/history-v1)                       | `http://history-v1:3100`            | Menyimpan riwayat lengkap setiap proyek dan isi file sebagai blob                           |
| [filestore](/id/dev/service-api/filestore)                         | `http://filestore:3009`             | Menyajikan file templat dan, hanya-baca, blob yang ditulis history-v1                           |
| [clsi](/id/dev/service-api/clsi)                                   | `http://clsi:3013`                  | Mengompilasi proyek, menjalankan SyncTeX dan penghitungan kata, mengonversi dokumen                              |
| [notifications](/id/dev/service-api/notifications)                 | `http://notifications:3042`         | Menyimpan notifikasi yang ditampilkan di daftar proyek                                               |
| [linked-url-proxy](/id/dev/service-api/linked-url-proxy)           | `http://linked-url-proxy:3066`      | Mengambil URL eksternal untuk web dan menolak alamat internal                                     |
| [third-party-datastore](/id/dev/service-api/third-party-datastore) | `http://third-party-datastore:3002` | Menyinkronkan proyek dengan Dropbox melalui satu antrean pekerjaan per pengguna                                       |

## Autentikasi {#authentication}

* <strong>web:</strong> HTTP basic auth dengan `WEB_API_USER` dan `WEB_API_PASSWORD`. Rute git-bridge menggunakan token akses pribadi sebagai gantinya.
* <strong>history-v1:</strong> HTTP basic auth sebagai `staging` dengan `STAGING_PASSWORD`, atau JWT.
* <strong>Semua layanan lain:</strong> tidak ada.

## Mencobanya {#try-them}

Lingkungan pengembangan menjalankan [Hoppscotch](https://github.com/hoppscotch/hoppscotch) di `http://localhost:9170`, dengan proxy yang menjangkau layanan melalui alamat Docker-nya. [README](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/README.md#hoppscotch)-nya menunjukkan cara mengatur proxy dan mengimpor file OpenAPI.
