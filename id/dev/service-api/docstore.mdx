Menyimpan setiap dokumen (baris, versi, rentang) dari setiap proyek di koleksi Mongo `docs`, dan mengarsipkan dokumen ke penyimpanan objek jika backend diatur. Dipanggil oleh web; document-updater menjangkaunya melalui web.

* <strong>Alamat:</strong> `http://docstore:3016`, di dalam jaringan Docker
* <strong>Autentikasi:</strong> tidak ada
* <strong>File OpenAPI:</strong> [`develop/hoppscotch/openapi/docstore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/docstore.yaml)
