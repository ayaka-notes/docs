Mengambil URL eksternal untuk web dan mengalirkan jawabannya kembali, sambil menolak alamat internal agar pengguna tidak dapat menjangkau jaringan Docker. Web mengirim file URL, impor Open in Overleaf, dan web_fetch agen AI melaluinya.

* <strong>Alamat:</strong> `http://linked-url-proxy:3066`, di dalam jaringan Docker
* <strong>Autentikasi:</strong> tidak ada
* <strong>File OpenAPI:</strong> [`develop/hoppscotch/openapi/linked-url-proxy.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/linked-url-proxy.yaml)
