Menyimpan obrolan proyek dan utas komentar (pesan dan status terselesaikannya) di koleksi Mongo `rooms` dan `messages`. Dipanggil oleh web melalui `ChatApiHandler`.

* <strong>Alamat:</strong> `http://chat:3010`, di dalam jaringan Docker
* <strong>Autentikasi:</strong> tidak ada
* <strong>File OpenAPI:</strong> [`develop/hoppscotch/openapi/chat.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/chat.yaml)
