Untuk menghemat waktu dan membangun lingkungan pengembangan dengan cepat, kami menyediakan versi lain dari konfigurasi lingkungan pengembangan, yaitu GitHub Codespace.

## Tutorial Konfigurasi

<Steps>
<Step title="Membuat Codespaces">
Klik tombol berikut untuk membuat codespaces di cloud untuk pengembangan server-pro.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/ayakaleaf-pro)

Sangat disarankan untuk memilih **Machine Type** minimal **4-core**. Untuk tipe mesin yang lebih besar, Anda dapat mengajukan permintaan ke tim dukungan resmi GitHub dengan membuat tiket [di sini](https://support.github.com/contact?tags=rr-codespaces%2Ccat_codespaces).

<Frame>
  <img src="/images/dev/image.png" alt="" />
</Frame>
</Step>

<Step title="Menjalankan Skrip Setup">
Anda perlu menunggu dengan sabar hingga codespace selesai dibuat. Setelah Anda dapat mengakses Terminal, jalankan perintah berikut:

```text
cd develop/
bin/setup
```

<Frame>
  <img src="/images/dev/image-1.png" alt="" />
</Frame>

<Warning>

Skrip ini (`bin/setup`) memungkinkan Anda menyiapkan lingkungan pengembangan pada commit terbaru dari branch `server-pro` dalam waktu sesingkat mungkin. Skrip ini mungkin tidak berlaku untuk versi lama/branch lain.

Kami membangun image docker pengembangan setiap hari dengan [GitHub Action](https://github.com/ayaka-notes/ayakaleaf-pro/actions).

</Warning>
</Step>

<Step title="Mengakses Launchpad Anda">
Beralihlah ke tab port, Anda akan melihat daftar port web yang tersedia. Klik port `80`. Sekarang Anda akan melihat halaman launchpad.

<Frame>
  <img src="/images/dev/image-2.png" alt="" />
</Frame>

Anda akan melihat:

<Frame>
  <img src="/images/dev/image-3.png" alt="" />
</Frame>
</Step>

<Step title="Selamat Mengembangkan">
Sekarang waktunya untuk Anda! Mulailah membangun fitur hebat Anda. Anda perlu menjalankan perintah berikut untuk mengaktifkan tampilan realtime:

```bash title="bash" wrap
docker compose -f docker-compose.yml -f docker-compose.dev.yml -f ./docker-compose.image.yml up --no-deps --detach
```
</Step>
</Steps>
