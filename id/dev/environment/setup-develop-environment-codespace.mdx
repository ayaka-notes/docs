Untuk menghemat waktu dan membangun lingkungan pengembangan dengan cepat, kami menyediakan versi lain dari konfigurasi lingkungan pengembangan, yaitu GitHub Codespace.

## Tutorial Konfigurasi {#configuration-tutorial}

<Steps>
<Step title="Membuat Codespaces">
Klik tombol berikut untuk membuat codespaces di cloud untuk pengembangan server-pro.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/ayakaleaf-pro)

Sangat disarankan untuk memilih **Machine Type** minimal **4-core**. Untuk tipe mesin yang lebih besar, Anda dapat mengajukan permintaan ke tim dukungan resmi GitHub dengan membuat tiket [di sini](https://support.github.com/contact?tags=rr-codespaces%2Ccat_codespaces).

<Frame>
  <img src="/images/dev/image.png" alt="" />
</Frame>
</Step>

<Step title="Menjalankan Skrip Setup">
Anda perlu menunggu dengan sabar hingga codespace selesai dibuat. Setelah Anda dapat mengakses Terminal, jalankan perintah berikut:

```text
cd develop/
bin/setup
bin/i18n
```

`bin/setup` menarik image dan menjalankan layanan; lalu `bin/i18n` menerapkan terjemahan modul Ayakaleaf Pro, yang tidak ada di file locale yang di-commit, lihat [Memperbarui terjemahan i18n](/id/dev/environment/update-i18n-translations).

<Frame>
  <img src="/images/dev/image-1.png" alt="" />
</Frame>

<Warning>

Skrip ini (`bin/setup`) memungkinkan Anda menyiapkan lingkungan pengembangan pada commit terbaru dari branch `server-pro` dalam waktu sesingkat mungkin. Skrip ini mungkin tidak berlaku untuk versi lama/branch lain.

Kami membangun image docker pengembangan setiap hari dengan [GitHub Action](https://github.com/ayaka-notes/ayakaleaf-pro/actions).

</Warning>
</Step>

<Step title="Mengakses Launchpad Anda">
Beralih ke tab port, Anda akan melihat daftar port web yang tersedia. Klik port `80` (`OVERLEAF_PORT` di `develop/dev.rc`). Sekarang Anda akan melihat halaman launchpad. Mailpit, Grafana, Mongo Express, dan RedisInsight berada di path port yang sama (`/mailpit/`, `/grafana/`, `/mongo-express/`, dan `/redis-insight/`), dan menu **Dev tools** di situs menautkannya setelah Anda login. Konsol RustFS ada di 9001 dan Hoppscotch di 9170, lihat [Port](/id/dev/environment/setup-develop-environment-local#ports).

<Step title="Selamat Mengembangkan">
Sekarang giliran Anda! Mulailah membangun fitur hebat Anda. `bin/setup` sudah menjalankan setiap layanan dalam mode pengembangan (`node --watch`, sama seperti `bin/dev`), jadi perubahan kode langsung terlihat tanpa perintah lain.

Setelah mengubah `develop/dev.rc`, jalankan `bin/setup` lagi: perintah ini melewati `bin/docker-compose`, yang menambahkan file fitur yang aktif.

<Warning>

Jangan menjalankan layanan secara manual dengan `docker compose -f docker-compose.yml -f docker-compose.dev.yml -f docker-compose.image.yml up`. Perintah itu melewatkan file fitur dari `dev.rc`, sehingga `web`, `filestore`, dan `history-v1` dibuat ulang tanpa pengaturan RustFS dan kembali ke volume lokal, tempat riwayat dan file biner proyek Anda tidak ada.

</Warning>
</Step>
</Steps>
