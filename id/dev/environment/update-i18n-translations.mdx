---
title: Memperbarui Terjemahan i18n
icon: language
---

Frontend hanya memuat kunci terjemahan yang tercantum di `services/web/frontend/extracted-translations.json` (`services/web/frontend/translations-loader.js`). Backend dan templatenya membaca file lengkap di `services/web/locales/`.

Jalankan ini di direktori `develop` sekali setelah penyiapan pertama, dan lagi setelah menambahkan terjemahan atau berganti branch:

```bash
bin/i18n
```

`bin/i18n` melakukan dua hal:

1. Perintah ini mengembalikan `services/web/locales/*.json` ke file yang di-commit, lalu menerapkan patch locale seperti yang dilakukan build image: file dari folder `locales_patches/v*` tertinggi menggantikan locale, dan `locales_patches/added/*.json` digabungkan di atasnya, kunci demi kunci.
2. Perintah ini menjalankan `yarn run extract-translations` sebagai pengguna `node` di container `webpack`, yang menulis ulang `extracted-translations.json`. Jika image webpack belum ada, perintah ini lebih dulu menyinkronkan `yarn.lock` dengan `bin/sync` lalu membangun image.

Perintah ini memerlukan `jq` di host.

<Warning>

Perubahan yang dibuat `bin/i18n` pada `services/web/locales/*.json` hanya bersifat lokal. Jangan commit perubahan tersebut.

</Warning>

Gunakan kembali kunci yang sudah ada bila memungkinkan. File locale berasal dari Overleaf upstream atau situs terjemahan pihak ketiga, jadi jangan mengeditnya secara langsung. Kunci baru dimasukkan ke `services/web/locales/locales_patches/added/`, ke file setiap bahasa sekaligus (`en.json`, `zh-CN.json`, dan lainnya).
