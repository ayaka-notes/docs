---
title: Memperbarui Terjemahan i18n
icon: language
---

Terdapat sebuah file di `services/web/frontend/extracted-translations.json`; overleaf web hanya akan menggunakan terjemahan yang diekstrak di file ini.

Jalankan perintah berikut untuk memperbarui terjemahan yang diekstrak jika Anda telah menambahkan beberapa konten.

```bash
user ➜ ~/overleaf-pro/develop (server-pro) $ bin/shell webpack
root@432836260f8a:/overleaf/services/web# npm run extract-translations
```

Secara umum, mohon jangan menyunting file teks terjemahan; gunakan terjemahan yang sudah ada terlebih dahulu, karena semua file tersebut diperbarui dari upstream overleaf atau situs terjemahan pihak ketiga.
