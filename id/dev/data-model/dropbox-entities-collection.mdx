`dropboxEntities` menyimpan satu dokumen per file yang telah disalin sinkronisasi Dropbox antara sebuah proyek dan Dropbox milik satu pengguna, ditambah tombstone berumur pendek. Koleksi ini milik sinkronisasi Dropbox: third-party-datastore (`services/third-party-datastore/app/js/StateManager.mjs`) menulis dan membacanya, dan modul web `dropbox` (`services/web/modules/dropbox/app/src/DropboxHandler.mjs`) membersihkannya. Tidak ada skema Mongoose.

#### Field {#fields}

| Field | Tipe | Arti | Sumber |
| ----- | ---- | ---- | ------ |
| `_id` | ObjectId | Ditetapkan oleh driver saat penyisipan. | `StateManager.mjs:46,97` |
| `overleaf.userId` | ObjectId | Pengguna yang Dropbox-nya berisi file tersebut. Ditetapkan pada setiap dokumen. | `StateManager.mjs:48,98` |
| `overleaf.projectId` | ObjectId | Proyek dari doc atau file. Ditetapkan jika diketahui; tombstone tidak memilikinya. | `StateManager.mjs:49-51` |
| `overleaf.id` | ObjectId | `_id` doc atau file di `rootFolder` proyek. Ditetapkan jika diketahui. | `StateManager.mjs:52` |
| `overleaf.type` | String | `doc` atau `file`. Kode saat ini menulisnya tetapi tidak membacanya. | `StateManager.mjs:53`; nilai dari `services/web/app/src/Features/ThirdPartyDataStore/TpdsUpdateSender.mjs:35,96` dan `UpdateMerger.mjs:104,119` |
| `dropbox.id` | String | `id` file dalam metadata file Dropbox. Tidak ditetapkan pada tombstone. | `StateManager.mjs:56` |
| `dropbox.pathLower` | String | Path file di Dropbox, dalam huruf kecil dan tanpa garis miring di akhir. Diperbarui ketika file atau folder proyeknya dipindahkan. | `StateManager.mjs:14-16,57,91,99` |
| `dropbox.rev` | String | Revisi Dropbox pada sinkronisasi terakhir. Unggahan berikutnya mengirimkannya, sehingga file yang berubah di Dropbox tidak tertimpa. | `StateManager.mjs:58`, `JobProcessor.mjs:114-122` |
| `dropbox.contentHash` | String | Hash konten Dropbox pada sinkronisasi terakhir. File dalam daftar dengan hash yang sama dilewati, karena itu unggahan kita sendiri atau sudah diterapkan. | `StateManager.mjs:59`, `PullManager.mjs:147-149` |
| `tombstone` | Boolean | `true` menandai path yang dihapus atau dipindahkan sendiri oleh third-party-datastore di Dropbox. Ketika Dropbox melaporkan kembali penghapusan itu, penghapusan tersebut tidak diterapkan ke proyek. | `StateManager.mjs:100`, `PullManager.mjs:189-192` |
| `createdAt` | Date | Khusus tombstone: kapan dibuat. Pull yang selesai menghapus tombstone yang dibuat sebelum pull itu dimulai. | `StateManager.mjs:101,115-121` |

Tombstone hanya memiliki `overleaf.userId`, `dropbox.pathLower`, `tombstone`, dan `createdAt` (`StateManager.mjs:96-103`).

#### Catatan {#notes}

* Keunikan hanya berasal dari penghapusan sebelum setiap penyisipan di `recordEntity` (`StateManager.mjs:38-45`). Komentar di `StateManager.mjs:3-11` menyebut indeks unik; CE tidak memilikinya.
* Kueri berdasarkan pengguna dan path (`findEntityByPath`, `findTombstone`, `removeEntities`) hanya memakai indeks untuk `overleaf.userId`.
