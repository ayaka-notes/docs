---
title: Koleksi GitLab Sync User Credentials
icon: user-lock
---

`gitlabSyncUserCredentials` menyimpan satu dokumen per pengguna yang menautkan akun GitLab untuk GitLab Sync. Koleksi ini menyimpan token OAuth pengguna dalam bentuk terenkripsi. Koleksi ini milik modul web `gitlab-sync` (`services/web/modules/gitlab-sync`). Skemanya ada di `services/web/modules/gitlab-sync/app/models/gitlabSyncUserCredentials.mjs`, dan semua akses melalui `services/web/modules/gitlab-sync/app/src/TokenManager.mjs`.

#### Field {#fields}

| Field | Tipe | Arti | Sumber |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Diatur oleh Mongoose saat upsert menyisipkan dokumen. | |
| `userId` | ObjectId | Pengguna Overleaf. Wajib. Skema menyebut `unique: true`, tetapi tidak ada indeks yang dibuat (lihat Indeks); upsert berdasarkan `userId` menjaga satu dokumen per pengguna. | `gitlabSyncUserCredentials.mjs:8`, `TokenManager.mjs:88-95` |
| `gitlab` | String | JSON `{ accessToken, refreshToken, expiresAt }`, dienkripsi dengan `@overleaf/access-token-encryptor`. `expiresAt` dalam milidetik sejak epoch, atau `null`; `refreshToken` bisa `null`. Kata sandinya berasal dari `GITLAB_TOKEN_CIPHER_PASSWORD`; label cipher-nya `GITLAB_TOKEN_CIPHER_LABEL`, default `2026.10-v3`. Wajib. | `gitlabSyncUserCredentials.mjs:9-10`, `TokenManager.mjs:18-31`, `services/web/modules/gitlab-sync/app/src/GitLabApiClient.mjs:209-220` |
| `__v` | Number | Kunci versi Mongoose. Skema tidak menonaktifkannya. | Default Mongoose |

#### Siapa yang menulis {#who-writes-it}

| Kode | Fungsinya |
| ---- | ------------ |
| `TokenManager.mjs:88-95` (`saveUserToken`) | Melakukan upsert kredensial terenkripsi pengguna. |
| `TokenManager.mjs:99-108` (`linkUserToken`) | Menyimpan kredensial baru dari callback OAuth (`services/web/modules/gitlab-sync/app/src/GitLabSyncController.mjs:146`). Saat pengguna menautkan lagi, access token yang diganti dicabut di GitLab di latar belakang. |
| `TokenManager.mjs:53-78` (`refreshUserToken`) | Saat access token kurang dari 5 menit dari `expiresAt` (`:13,47-49`), ia mengambil token baru dengan refresh token dan menyimpannya (`:75`). Ia berjalan di bawah lock `gitlabSyncToken` per pengguna (`:15,54`), karena GitLab menghabiskan refresh token saat dipakai. |
| `TokenManager.mjs:111-126` (`removeUserToken`) | Mencabut access token di GitLab (sebisa mungkin), lalu menghapus dokumen. Dipanggil saat memutus tautan (`GitLabSyncController.mjs:173`) dan saat pengguna yang dihapus kedaluwarsa (`services/web/modules/gitlab-sync/index.mjs:56-58`). |

#### Siapa yang membaca {#who-reads-it}

| Kode | Fungsinya |
| ---- | ------------ |
| `TokenManager.mjs:41-45,81-85` (`getUserCredentials`, `getUserToken`) | Mendekripsi kredensial untuk setiap panggilan API GitLab, memperbaruinya lebih dulu bila token hampir kedaluwarsa: `services/web/modules/gitlab-sync/app/src/GitLabSyncHandler.mjs` (misalnya `:27`) dan `services/web/modules/gitlab-sync/app/src/GitMerge.mjs:52`. Tanpa dokumen, atau dengan kredensial yang tidak bisa didekripsi atau diperbarui, ia melempar `InvalidTokenError`, dan pengguna dianggap tidak tertaut (`GitLabSyncHandler.mjs:25-37`). |
| `services/web/modules/admin-tools/app/src/AdminUserListManager.mjs:394` | Memeriksa apakah pengguna punya dokumen, untuk integrasi yang ditampilkan di panel admin. |

#### Indeks {#indexes}

| Nama | Kunci | Opsi | Migrasi |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

`autoIndex` Mongoose dimatikan (`services/web/app/src/infrastructure/Mongoose.mjs:7`), jadi `unique: true` skema pada `userId` tidak membuat apa pun. Tidak ada migrasi yang membuat indeks untuk koleksi ini.

#### Catatan {#notes}

* Mengubah `GITLAB_TOKEN_CIPHER_PASSWORD` membuat kredensial yang tersimpan tidak terbaca. Pengguna tersebut lalu dianggap tidak tertaut sampai mereka menautkan lagi.
* Pengguna yang dihapus menyimpan dokumennya sampai pengguna itu kedaluwarsa.
