`oauthApplications` menyimpan klien OAuth yang dikenal web. Satu dokumen adalah satu klien. Di Ayakaleaf Pro, satu-satunya penulisnya adalah modul web `git-bridge`, yang membuat satu klien bernama `Overleaf Git Bridge` saat web dimulai. Skemanya adalah `services/web/app/src/models/OauthApplication.mjs`.

#### Field {#fields}

| Field | Tipe | Arti | Sumber |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Id dokumen klien. `oauthAccessTokens.oauthApplication_id` dan `oauthAuthorizationCodes.oauthApplication_id` menunjuk ke sini. | `OauthApplication.mjs:5` |
| `id` | String | Id klien: 64 huruf kecil dan angka acak. | `OauthApplication.mjs:7`, `services/web/modules/git-bridge/index.mjs:25` |
| `clientSecret` | String | Rahasia klien, ditulis sebagai `v1.` ditambah 32 karakter acak. Hanya `getClient` yang membacanya, dan tidak ada yang memanggil `getClient` (lihat Catatan). | `OauthApplication.mjs:8`, `git-bridge/index.mjs:26` |
| `grants` | Array of String | Jenis grant. Klien git-bridge memiliki `['password']`. Dikembalikan bersama klien saat token diperiksa (`services/web/modules/oauth2-server/app/src/OAuth2Model.mjs:67-72`). | `OauthApplication.mjs:9`, `git-bridge/index.mjs:27` |
| `name` | String | Nama klien. Modul git-bridge dan kode token akses pribadi menemukan klien lewat nama `Overleaf Git Bridge`. | `OauthApplication.mjs:10`, `git-bridge/index.mjs:15-16,28` |
| `redirectUris` | Array of String | URI pengalihan yang diizinkan. `[]` untuk klien git-bridge. | `OauthApplication.mjs:11`, `git-bridge/index.mjs:29` |
| `scopes` | Array of String | Scope yang boleh dipakai klien. `['git_bridge']` untuk klien git-bridge. | `OauthApplication.mjs:12`, `git-bridge/index.mjs:30` |
| `pkceEnabled` | Boolean | Hanya ada di skema: tidak ada kode di repositori ini yang menulisnya, dan hanya `getClient` yang tidak terpakai yang membacanya (`OAuth2Model.mjs:207`). | `OauthApplication.mjs:13` |

#### Siapa yang menulis {#who-writes-it}

| Kode | Fungsinya |
| ---- | ------------ |
| `git-bridge/index.mjs:9-35` (module `git-bridge`) | Saat `GIT_BRIDGE_ENABLED` bernilai `true`, membuat klien `Overleaf Git Bridge` ketika web dimulai jika belum ada klien dengan nama itu. |

#### Siapa yang membaca {#who-reads-it}

| Kode | Fungsinya |
| ---- | ------------ |
| `services/web/modules/oauth2-server/app/src/OAuthPersonalAccessTokenManager.mjs:53-61` (module `oauth2-server`) | Menemukan klien `Overleaf Git Bridge` lewat nama dan menyimpan `_id`-nya di setiap token akses pribadi baru. Tanpa klien ini, tidak ada token yang dibuat. |
| `OAuth2Model.mjs:31-39,67-72` (`getAccessToken`) | Memuat klien sebuah token lewat `oauthApplication_id` dan mengembalikan `id` serta `grants`-nya. |
| `OAuth2Model.mjs:185-209,241,275` (`getClient`, `saveToken`, `saveAuthorizationCode`) | Mencari klien berdasarkan `id`. Tidak pernah dijangkau di repositori ini, lihat Catatan. |

#### Indeks {#indexes}

Hanya indeks bawaan pada `_id`. Indeks unik `id_1` berasal dari migrasi bertag `saas` (`20190912145016_create_oauthApplications_indexes.mjs`) dan `server-pro` (`20230502180757_server_pro_oauth_indexes.mjs`), yang tidak dijalankan Community Edition.

#### Catatan {#notes}

* Web memakai `@node-oauth/oauth2-server` hanya untuk memeriksa token bearer (`server.authenticate` di `services/web/app/src/Features/Authentication/AuthenticationController.mjs:409-450`), yang hanya memanggil `getAccessToken` dan `verifyScope` milik model. Tidak ada rute yang melayani `/oauth/token` atau `/oauth/authorize`, sehingga `getClient`, `saveToken`, dan `saveAuthorizationCode` tidak pernah dipanggil.
* Modul mencari klien lewat nama lalu membuatnya, dan Community Edition tidak punya indeks unik pada `name` atau `id`. Jadi tidak ada yang mencegah klien kedua dengan nama yang sama. Kode yang membutuhkan klien mengambil klien mana pun yang dikembalikan `findOne`.
