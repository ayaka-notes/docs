`dropboxProjects` memetakan sebuah proyek ke foldernya di Dropbox milik satu pengguna. Proyek yang dibagikan dengan beberapa pengguna Dropbox memiliki satu dokumen per pengguna. Koleksi ini milik sinkronisasi Dropbox: third-party-datastore (`services/third-party-datastore/app/js/StateManager.mjs`) menulisnya, dan modul web `dropbox` (`services/web/modules/dropbox/app/src/DropboxHandler.mjs`) membaca serta membersihkannya. Tidak ada skema Mongoose.

| Field | Tipe | Arti | Sumber |
| ----- | ---- | ---- | ------ |
| `_id` | ObjectId | Ditetapkan oleh driver saat penyisipan. | `StateManager.mjs:144` |
| `userId` | ObjectId | Pengguna Overleaf yang Dropbox-nya berisi folder tersebut. | `StateManager.mjs:145` |
| `projectId` | ObjectId | Proyek yang disinkronkan ke folder tersebut. | `StateManager.mjs:146` |
| `dropboxId` | String | `id` folder dalam metadata folder Dropbox. | `StateManager.mjs:147`, `JobProcessor.mjs:82-87`, `PullManager.mjs:138` |
| `pathLower` | String | Path folder di Dropbox, dalam huruf kecil dan tanpa garis miring di akhir. Folder proyek berada di tingkat teratas, satu per proyek, misalnya `/thesis (1)` ketika Dropbox menomorinya di samping `Thesis` milik proyek lain. | `StateManager.mjs:14-16,148`, `PullManager.mjs:112-117` |

CE tidak memiliki indeks lain di sini. Indeks unik `projectId_userId_1` dan `userId_dropboxId_1` berasal dari `tools/migrations/20220815105500_create_dropboxProjects_index.mjs` dan `20220817120900_create_dropboxProjects_index.mjs`, yang hanya bertag `saas`, sehingga CE tidak pernah menjalankannya.

#### Catatan {#notes}

* Keunikan hanya berasal dari penghapusan sebelum setiap penyisipan di `setProjectFolder` (`StateManager.mjs:140-149`). Komentar di `StateManager.mjs:3-11` menyebut indeks unik; CE tidak memilikinya.
* Ketika pemetaan proyek dihapus, foldernya tetap ada di Dropbox. Suntingan di sana kemudian dibaca sebagai proyek baru, sama seperti folder yang dibuat di Dropbox (`DropboxHandler.mjs:148-149`).
* Proyek yang dihapus mempertahankan pemetaannya sampai kedaluwarsa, karena masih bisa dipulihkan (`index.mjs:52-53`).
* Kursor Dropbox `list_folder` milik pengguna tidak ada di sini. Kursor itu ada di `users.dropbox.cursor` (`StateManager.mjs:177-184`).
