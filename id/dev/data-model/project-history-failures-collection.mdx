---
title: Koleksi Project History Failures
icon: triangle-exclamation
---

`projectHistoryFailures` menyimpan satu dokumen per proyek yang pembaruan riwayatnya tidak dapat diproses project-history, atau yang sinkronisasi ulangnya telah dimulai. Dokumen dihapus lagi segera setelah pemrosesan berhasil. project-history menulisnya di `services/project-history/app/js/ErrorRecorder.js`; tipenya ada di `services/project-history/app/js/mongo-types.ts:3-24`. Web juga memiliki skema Mongoose untuknya (`services/web/app/src/models/ProjectHistoryFailure.mjs:5-19`), tetapi tidak ada kode web yang memakai model itu.

#### Catatan {#notes}

* Sebuah dokumen tetap ada sampai flush proyek berhasil atau proyek dihapus (`clearError` di atas), sehingga setiap dokumen menandai proyek yang flush atau sinkronisasi ulang terakhirnya belum berhasil.
* String error yang diawali `OError:` dikembalikan sebagai `Error:` (`ErrorRecorder.js:18-26`); nilai yang tersimpan tidak berubah.
