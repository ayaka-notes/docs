title: Koleksi Projects

`Project` merepresentasikan satu proyek LaTeX di Overleaf. Koleksi ini menyimpan metadata proyek, kepemilikan dan kontrol akses, struktur file, pengaturan kompilasi, serta status kolaborasi.

#### Identifikasi Inti & Metadata

* `_id`: ObjectId MongoDB unik yang mengidentifikasi proyek.
* `name`: Nama tampilan proyek.
* `description`: Deskripsi teks opsional untuk proyek.
* `active`: Menunjukkan apakah proyek sedang aktif.
* `version`: Versi skema internal atau format proyek.
* `trashed`: Daftar item yang dipindahkan ke tempat sampah (soft-delete).
* `deletedDocs`: Catatan dokumen yang telah dihapus secara permanen.

#### Kepemilikan & Kontrol Akses

* `owner_ref`: Referensi ke pengguna pemilik proyek.
* `collaberator_refs`: Pengguna dengan izin edit.
* `reviewer_refs`: Pengguna dengan akses tingkat reviewer.
* `readOnly_refs`: Pengguna dengan akses hanya-baca.
* `pendingEditor_refs` / `pendingReviewer_refs`: Undangan yang tertunda.

#### Akses Berbasis Token

* `tokens`: Registri token untuk tautan berbagi.
* `tokenAccessReadOnly_refs`: Token yang memberikan akses hanya-baca.
* `tokenAccessReadAndWrite_refs`: Token yang memberikan akses baca–tulis.

#### Pelacakan Aktivitas

* `lastUpdated`: Stempel waktu modifikasi terakhir.
* `lastUpdatedBy`: Pengguna yang melakukan pembaruan terakhir.
* `lastOpened`: Stempel waktu terakhir kali proyek dibuka.
* `deletedByExternalDataSource`: Apakah penghapusan dipicu oleh integrasi eksternal.

#### Struktur Proyek

Dokumen & Folder Root

* `rootDoc_id`: ObjectId dari dokumen LaTeX utama (biasanya `main.tex`).
* `rootFolder`: Representasi inline dari pohon file proyek.

Setiap entri folder berisi:

* `name` / `_id`: Nama dan pengenal folder.
* `docs`: Daftar dokumen sumber LaTeX beserta nama dan `_id`.
* `fileRefs`: Referensi file biner (gambar, file data), termasuk:
  * `name`: Nama file
  * `created`: Stempel waktu unggah
  * `rev`: Penghitung revisi
  * `hash`: Hash konten untuk deduplikasi
  * `linkedFileData`: Tautan penyimpanan eksternal (jika ada)
* `folders`: Subfolder bertingkat.

#### Pengaturan Kompilasi & Editor

* `compiler`: Mesin LaTeX yang dipilih (`pdflatex`, `xelatex`, `lualatex`, dll.).
* `spellCheckLanguage`: Bahasa pemeriksa ejaan untuk proyek ini.

#### Pengaturan Publik & Berbagi

* `publicAccesLevel`: Visibilitas proyek (`private`, `readOnly`, `public`, dll.).
* `collabratecUsers`: Pengguna yang ditautkan dari platform kolaborasi eksternal.

#### Ekstensi Khusus Overleaf

* `overleaf.history`:
  * `id`: Pengenal yang digunakan oleh layanan riwayat.
  * `display`: Apakah riwayat diaktifkan dan terlihat.

#### Pembuatan Versi Internal

* `__v`: Kunci versi internal Mongoose untuk kontrol konkurensi.
