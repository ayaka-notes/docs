`tags` menyimpan tag (folder) yang digunakan pengguna untuk mengelompokkan proyek di dasbor proyek. Satu dokumen adalah satu tag milik satu pengguna. Pemiliknya adalah `web`; skemanya `services/web/app/src/models/Tag.mjs`, dan semua penulisan melalui `services/web/app/src/Features/Tags/TagsHandler.mjs`.

#### Field {#fields}

| Field | Tipe | Arti | Sumber |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id tag, digunakan di rute `/tag/:tagId`. | `Tag.mjs:10` |
| `user_id` | String | Pemilik tag. String biasa, bukan ObjectId, karena alasan historis. | `Tag.mjs:7-12` |
| `name` | String | Nama tag, paling banyak 50 karakter (`MAX_TAG_LENGTH`). Unik per pengguna. | `Tag.mjs:13`, `TagsHandler.mjs:4` |
| `color` | String | Warna opsional: kode heksadesimal seperti `#a1b2c3` atau nilai `hsl(<n>, 70%, 45%)` (`TAG_COLOR_REGEX`). | `Tag.mjs:5`, `Tag.mjs:14-22` |
| `project_ids` | Array of String | Id proyek dalam tag ini, sebagai string. | `Tag.mjs:23` |
| `__v` | Number | Kunci versi Mongoose, ditambahkan saat `Tag.create` membuat dokumen. | `TagsHandler.mjs:27` |

Migrasi yang sama juga membuat `user_id_1`; `tools/migrations/20231031164732_drop_redundant_indexes.mjs` menghapusnya lagi karena indeks gabungan sudah mencakupnya.

#### Catatan {#notes}

* Tag bersifat per pengguna: dua kolaborator pada proyek yang sama masing-masing menyimpan tag mereka sendiri untuk proyek itu.
* `user_id` dan `project_ids` adalah string, jadi kueri keduanya dengan id string, bukan ObjectId.
* Menghapus pengguna (`services/web/app/src/Features/User/UserDeleter.mjs`) tidak menyentuh `tags`.
