title: Koleksi OAuth Authorization Codes
icon: lock-open
---

`oauthAuthorizationCodes` ditujukan untuk kode alur OAuth authorization code: satu dokumen per kode, yang ditukar klien dengan token akses. Skemanya adalah `services/web/app/src/models/OauthAuthorizationCode.mjs`, dan modul web `oauth2-server` berisi kode yang akan menulis ke sini. Di Ayakaleaf Pro tidak ada yang menjangkau kode itu, sehingga koleksi ini tetap kosong (lihat Catatan).

#### Field {#fields}

| Field | Tipe | Arti | Sumber |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Id dokumen. | `OauthAuthorizationCode.mjs:6` |
| `authorizationCode` | String | Kode itu sendiri, disimpan apa adanya (tidak di-hash). | `OauthAuthorizationCode.mjs:8`, `services/web/modules/oauth2-server/app/src/OAuth2Model.mjs:280` |
| `expiresAt` | Date | Akhir masa berlaku. Setelah itu `getAuthorizationCode` menolak kode, dan indeks TTL menghapusnya. | `OauthAuthorizationCode.mjs:9`, `OAuth2Model.mjs:150-153,281` |
| `oauthApplication_id` | ObjectId | Klien di [OAuth Applications](/id/dev/data-model/oauth-applications-collection) yang meminta kode. | `OauthAuthorizationCode.mjs:10`, `OAuth2Model.mjs:275-284` |
| `redirectUri` | String | URI pengalihan permintaan. | `OauthAuthorizationCode.mjs:11`, `OAuth2Model.mjs:282` |
| `scope` | String | Scope yang diminta. | `OauthAuthorizationCode.mjs:12`, `OAuth2Model.mjs:283` |
| `user_id` | ObjectId | Pengguna yang memberikan kode. | `OauthAuthorizationCode.mjs:13`, `OAuth2Model.mjs:285` |
| `codeChallenge`, `codeChallengeMethod` | String | Challenge PKCE dan metodenya. | `OauthAuthorizationCode.mjs:14-15`, `OAuth2Model.mjs:286-287` |

#### Siapa yang menulis {#who-writes-it}

| Kode | Fungsinya |
| ---- | ------------ |
| `OAuth2Model.mjs:274-300` (`saveAuthorizationCode`) | Menyisipkan kode. Tidak terjangkau, lihat Catatan. |
| `OAuth2Model.mjs:307-312` (`revokeAuthorizationCode`) | Menghapus kode setelah dipakai. Tidak terjangkau. |

#### Siapa yang membaca {#who-reads-it}

| Kode | Fungsinya |
| ---- | ------------ |
| `OAuth2Model.mjs:137-177` (`getAuthorizationCode`) | Memuat kode beserta pengguna dan kliennya. Tidak terjangkau. |

#### Indeks {#indexes}

| Nama | Kunci | Opsi | Migrasi |
| ---- | ---- | ------- | --------- |
| `expiresAt_1` | `{ expiresAt: 1 }` | TTL, `expireAfterSeconds: 0`, parsial: `expiresAt` ada | `20230406125632_oauth_tokens_ttl.mjs` |

Migrasi ada di `tools/migrations/`. Indeks unik `authorizationCode_1` hanya berasal dari migrasi bertag `saas` dan `server-pro`, yang tidak dijalankan Community Edition.

#### Catatan {#notes}

* Metode model di atas hanya dipanggil oleh handler authorize dan token dari `@node-oauth/oauth2-server`. Web memakai pustaka itu hanya untuk memeriksa token bearer (`services/web/app/src/Features/Authentication/AuthenticationController.mjs:409-450`), dan tidak ada rute yang melayani `/oauth/authorize` atau `/oauth/token`, sehingga tidak pernah ada kode yang ditulis. Token akses pribadi dibuat langsung, lihat [OAuth Access Tokens](/id/dev/data-model/oauth-access-tokens-collection).
