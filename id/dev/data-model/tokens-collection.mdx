title: Koleksi Tokens

`tokens` menyimpan token sekali pakai: rahasia di dalam tautan yang memungkinkan seseorang menetapkan kata sandi. Satu dokumen adalah satu token. Tidak ada model Mongoose; web menulis koleksi ini lewat `services/web/app/src/Features/Security/OneTimeTokenHandler.mjs` dengan driver native.

#### Field {#fields}

| Field | Tipe | Arti | Sumber |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Id dokumen. | `OneTimeTokenHandler.mjs:40` |
| `use` | String | Kegunaan token, lihat [Kegunaan](#uses) di bawah. Setiap pencarian memfilter field ini. | `OneTimeTokenHandler.mjs:41` |
| `token` | String | Rahasia di dalam tautan: 32 byte acak sebagai 64 karakter heksadesimal, disimpan apa adanya. | `OneTimeTokenHandler.mjs:38,42` |
| `data` | Object | Apa yang diwakili token; dikembalikan saat token dipakai. | `OneTimeTokenHandler.mjs:43` |
| `data.user_id` | String | Id pengguna, ditulis sebagai string oleh setiap pemanggil. | `services/web/app/src/Features/PasswordReset/PasswordResetHandler.mjs:27`, `services/web/app/src/Features/User/UserRegistrationHandler.mjs:117`, `services/web/modules/admin-tools/app/src/AdminUserManager.mjs:79` |
| `data.email` | String | Email pengguna saat token dibuat. Reset kata sandi mencari pengguna berdasarkan email utama ini (`PasswordResetHandler.mjs:66-70`). | sama seperti `data.user_id` |
| `createdAt` | Date | Waktu pembuatan. Indeks TTL menghapus token 90 hari kemudian. | `OneTimeTokenHandler.mjs:36,44` |
| `expiresAt` | Date | `createdAt` ditambah `expiresIn` detik: 1 jam secara bawaan, 1 minggu untuk tautan aktivasi. Pencarian mengabaikan token setelah waktu ini. | `OneTimeTokenHandler.mjs:35-37,45` |
| `peekCount` | Number | Berapa kali token dilihat tanpa dipakai. Setiap `peekValueFromToken` menambah 1; pada angka 4 (`MAX_PEEKS`) token berhenti berfungsi. | `OneTimeTokenHandler.mjs:8-31,107` |
| `usedAt` | Date | Waktu token dipakai atau dibatalkan. Pencarian mengabaikan token yang memilikinya. | `OneTimeTokenHandler.mjs:51-104` |

#### Kegunaan {#uses}

| `use` | Fitur | Kedaluwarsa | Kode |
| ----- | ------- | ------ | ---- |
| `password` | Email reset kata sandi, dari halaman "lupa kata sandi" | 1 jam | `PasswordResetHandler.mjs:14-42` |
| `password` | Tautan aktivasi: akun dibuat dengan kata sandi acak, lalu tautan untuk menetapkannya. Dipakai oleh pendaftaran publik (`services/web/modules/login-register/app/src/RegisterController.mjs:65`), halaman pendaftaran admin dari `user-activate` (`services/web/modules/user-activate/app/src/UserActivateController.mjs:27-30`), dan skrip `create-user` (`services/web/modules/server-ce-scripts/scripts/create-user.mjs:21`) | 1 minggu | `UserRegistrationHandler.mjs:97-130` |
| `password` | Tautan aktivasi atau reset kata sandi yang dikirim dari panel admin (modul `admin-tools`) | 1 minggu (aktivasi), 1 jam (reset) | `AdminUserManager.mjs:76-103,196-206` |
| `email_confirmation` | Tautan konfirmasi email. Hanya dibaca: tidak ada lagi kode di repositori ini yang membuat token seperti ini, karena konfirmasi kini mengirim kode 6 digit (`services/web/app/src/Features/User/UserEmailsConfirmationHandler.mjs:15-35`) | | `UserEmailsConfirmationHandler.mjs:12,37-66` |

#### Siapa yang menulis {#who-writes-it}

| Kode | Fungsinya |
| ---- | ------------ |
| `OneTimeTokenHandler.mjs:34-49` (`getNewToken`) | Menyisipkan token. Pemanggil: `PasswordResetHandler.mjs:28`, `UserRegistrationHandler.mjs:115-119`, `AdminUserManager.mjs:77-81`. |
| `OneTimeTokenHandler.mjs:8-32` (`peekValueFromToken`) | Mengembalikan `data` dari token yang valid dan menambah 1 pada `peekCount`. Dipakai saat halaman reset kata sandi dibuka (`services/web/app/src/Features/PasswordReset/PasswordResetController.mjs:195-208`), lagi saat kata sandi baru ditetapkan (`PasswordResetHandler.mjs:94-96`), dan oleh konfirmasi email (`UserEmailsConfirmationHandler.mjs:38-41`). |
| `OneTimeTokenHandler.mjs:75-88` (`expireToken`) | Mengisi `usedAt` pada satu token: setelah kata sandi baru ditetapkan (`PasswordResetHandler.mjs:44-48,119`) atau email dikonfirmasi (`UserEmailsConfirmationHandler.mjs:65`). |
| `OneTimeTokenHandler.mjs:90-104` (`expireAllTokensForUser`) | Mengisi `usedAt` pada setiap token `password` yang masih terbuka milik pengguna, saat pengguna mengubah kata sandi di pengaturan (`services/web/app/src/Features/User/UserController.mjs:146-149`) atau admin menetapkannya di panel admin (`AdminUserManager.mjs:479-488`). |

#### Siapa yang membaca {#who-reads-it}

| Kode | Fungsinya |
| ---- | ------------ |
| `PasswordResetHandler.mjs:50-70,94-119` | Mengubah token reset atau aktivasi menjadi pengguna, lalu menetapkan kata sandi. Halaman aktivasi `user-activate` hanya meneruskan token ke formulir ini. |
| `UserEmailsConfirmationHandler.mjs:37-66` | Mengonfirmasi email dari token `email_confirmation` milik pengguna yang sedang masuk. |

#### Catatan {#notes}

* Token yang sudah dipakai atau kedaluwarsa tidak langsung dihapus: token tetap ada, dengan `usedAt` atau `expiresAt` yang sudah lewat, sampai indeks TTL menghapusnya 90 hari setelah `createdAt`.
* `OneTimeTokenHandler` juga memiliki `getValueFromTokenAndExpire` (`OneTimeTokenHandler.mjs:51-73`), tetapi tidak ada yang memanggilnya.
