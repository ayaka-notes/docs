---
title: Koleksi GitHub Sync User Credentials
icon: key
---

`githubSyncUserCredentials` menyimpan satu dokumen per pengguna yang menautkan akun GitHub untuk GitHub Sync. Koleksi ini menyimpan access token OAuth pengguna dalam bentuk terenkripsi. Koleksi ini milik modul web `github-sync` (`services/web/modules/github-sync`). Skemanya ada di `services/web/modules/github-sync/app/models/githubSyncUserCredentials.mjs`, dan semua akses melalui `services/web/modules/github-sync/app/src/TokenManager.mjs`.

#### Field {#fields}

| Field | Tipe | Arti | Sumber |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Diatur oleh Mongoose saat upsert menyisipkan dokumen. | |
| `userId` | ObjectId | Pengguna Overleaf. Wajib. Skema menyebut `unique: true`, tetapi tidak ada indeks yang dibuat (lihat Indeks); upsert berdasarkan `userId` menjaga satu dokumen per pengguna. | `githubSyncUserCredentials.mjs:8`, `TokenManager.mjs:44-48` |
| `github` | String | Access token OAuth GitHub, dienkripsi dengan `@overleaf/access-token-encryptor`. Kata sandinya berasal dari `GITHUB_TOKEN_CIPHER_PASSWORD`; label cipher-nya `GITHUB_TOKEN_CIPHER_LABEL`, default `2026.3-v3`. Wajib. | `githubSyncUserCredentials.mjs:9`, `TokenManager.mjs:12-25` |
| `__v` | Number | Kunci versi Mongoose. Skema tidak menonaktifkannya. | Default Mongoose |

Hanya access token yang disimpan: callback OAuth menyimpan `access_token` dari jawaban GitHub (`services/web/modules/github-sync/app/src/GitHubApiClient.mjs:180-191`). Tidak ada refresh token atau masa berlaku.

#### Siapa yang menulis {#who-writes-it}

| Kode | Fungsinya |
| ---- | ------------ |
| `TokenManager.mjs:42-58` (`saveUserToken`) | Melakukan upsert token terenkripsi pengguna. Saat pengguna menautkan lagi, token yang diganti dicabut di GitHub di latar belakang. Dipanggil dari callback OAuth (`services/web/modules/github-sync/app/src/GitHubSyncController.mjs:146`). |
| `TokenManager.mjs:61-76` (`removeUserToken`) | Mencabut token di GitHub (sebisa mungkin), lalu menghapus dokumen. Dipanggil saat memutus tautan (`GitHubSyncController.mjs:167`) dan saat pengguna yang dihapus kedaluwarsa (`services/web/modules/github-sync/index.mjs:66-68`). |

#### Siapa yang membaca {#who-reads-it}

| Kode | Fungsinya |
| ---- | ------------ |
| `TokenManager.mjs:36-40` (`getUserToken`) | Mendekripsi token untuk setiap panggilan API GitHub: `services/web/modules/github-sync/app/src/GitHubSyncHandler.mjs` (misalnya `:27`) dan `services/web/modules/github-sync/app/src/GitMerge.mjs:43`. Tanpa dokumen, atau dengan token yang tidak bisa didekripsi, ia melempar `InvalidTokenError`, dan pengguna dianggap tidak tertaut (`GitHubSyncHandler.mjs:25-37`). |

#### Indeks {#indexes}

| Nama | Kunci | Opsi | Migrasi |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

`autoIndex` Mongoose dimatikan (`services/web/app/src/infrastructure/Mongoose.mjs:7`), jadi `unique: true` skema pada `userId` tidak membuat apa pun. `tools/migrations/20190912145011_create_githubSyncUserCredentials_indexes.mjs` (`user_id` dari upstream) hanya bertag `saas` dan tidak berjalan di CE.

#### Catatan {#notes}

* Mengubah `GITHUB_TOKEN_CIPHER_PASSWORD` membuat token yang tersimpan tidak terbaca. Pengguna tersebut lalu dianggap tidak tertaut sampai mereka menautkan lagi.
* Pengguna yang dihapus menyimpan dokumennya sampai pengguna itu kedaluwarsa.
