`messages` menyimpan satu dokumen per pesan: satu baris di chat proyek, atau komentar atau balasan di utas komentar tinjauan. Hanya layanan chat yang menulisnya, di `services/chat/app/js/Features/Messages/MessageManager.js`. Tidak ada skema Mongoose. Setiap pesan termasuk dalam sebuah room di koleksi [rooms](/id/dev/data-model/rooms-collection).

#### Field {#fields}

| Field | Tipe | Arti | Sumber |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Id pesan. | `MessageManager.js:13-14` |
| `room_id` | ObjectId | Room (`rooms._id`), bukan id proyek atau id utas. | `MessageManager.js:8,106-108` |
| `user_id` | ObjectId | Penulis. | `MessageManager.js:9,103-105` |
| `content` | String | Teks pesan, 1 sampai 10240 karakter (`MAX_MESSAGE_LENGTH`). | `MessageManager.js:7`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:3,12-15` |
| `timestamp` | Number | Kapan dikirim, dalam milidetik sejak 1970 (`Date.now()`), bukan Date. | `MessageManager.js:10`, `services/chat/app/js/Features/Messages/MessageHttpController.js:288` |
| `edited_at` | Number | Kapan terakhir disunting, dalam milidetik (`Date.now()`). Tidak ada jika tidak pernah disunting. | `MessageManager.js:65-69`, `MessageHttpController.js:189,213` |

#### Siapa yang menulis {#who-writes-it}

| Kode | Fungsinya |
| ---- | ------------ |
| `MessageManager.js:5-16` `createMessage` | Menyisipkan pesan (`MessageHttpController.js:275-294`). Web mengirim pesan chat proyek dari `services/web/app/src/Features/Chat/ChatController.mjs:32`, dan komentar dari modul track-changes (`services/web/modules/track-changes/app/src/TrackChangesController.mjs:95`) dan modul mcp-server (`services/web/modules/mcp-server/app/src/CommentTools.mjs:133`). |
| `MessageManager.js:51-72` `updateMessage` | Mengatur `content` dan `edited_at`. Jika id pengguna diberikan, hanya pesan pengguna itu yang cocok (`MessageManager.js:62-64`). Dipanggil dari `ChatController.mjs:135` dan `TrackChangesController.mjs:110`. |
| `MessageManager.js:74-80` `deleteMessage` | Menghapus satu pesan. Dipanggil dari `ChatController.mjs:105` dan `TrackChangesController.mjs:129`. |
| `MessageManager.js:39-49` `deleteAllMessagesInRoom(s)` | Menghapus pesan dari utas yang dihapus (`MessageHttpController.js:172-173`) atau dari seluruh proyek ketika proyek yang dihapus kedaluwarsa (`MessageHttpController.js:261-271`, dipanggil dari `services/web/app/src/Features/Project/ProjectDeleter.mjs:391`). |
| `MessageManager.js:115-127` `duplicateRoomToOtherRoom` | Menyalin `content`, `timestamp`, dan `user_id` dari setiap pesan ke room lain, tanpa `edited_at`. Dipakai ketika pemulihan riwayat menduplikasi utas (`MessageHttpController.js:316-342`) dan ketika proyek disalin bersama rentangnya (`MessageHttpController.js:344-357`). |

#### Catatan {#notes}

* Untuk menemukan pesan sebuah komentar, cari room-nya dulu berdasarkan `project_id` dan `thread_id`, lalu kueri `room_id`. Id komentar di doc adalah `thread_id`, bukan `room_id`.
* Teks yang ditunjuk komentar adalah `op.c` di `docs.ranges.comments`; diskusinya ada di sini.
