`githubSyncProjectStates` menyimpan satu dokumen per proyek yang ditautkan ke repositori GitHub: repositori mana, dan di mana sinkronisasi terakhir berhenti. Koleksi ini milik modul web `github-sync` (`services/web/modules/github-sync`). Skemanya ada di `services/web/modules/github-sync/app/models/githubSyncProjectStates.mjs`, dan semua akses melalui `services/web/modules/github-sync/app/src/SyncStateManager.mjs`.

#### Siapa yang menulis {#who-writes-it}

| Kode | Fungsinya |
| ---- | ------------ |
| `SyncStateManager.mjs:9-14` (`createProjectState`) | Membuat dokumen: setelah mengimpor repositori sebagai proyek baru (`services/web/modules/github-sync/app/src/GitHubSyncHandler.mjs:175-181`), atau setelah mengekspor proyek ke repositori baru (`GitHubSyncHandler.mjs:235-241`, hanya pemilik, ditolak bila sudah ditautkan). |
| `SyncStateManager.mjs:16-21` (`updateProjectState`) | `$set` untuk field yang berubah. `getMergeOverview` mengatur `mergeStatus: 'diverged'` ketika branch yang disinkronkan tidak lagi dibangun di atas `lastSyncCommit`: compare GitHub menjawab `diverged` atau `behind` (`GitHubApiClient.mjs:382-400`), atau commit-nya hilang dan pengguna dapat melakukan push (`GitHubSyncHandler.mjs:123,126-137`). Sinkronisasi (`services/web/modules/github-sync/app/src/GitMerge.mjs`) memajukan `lastSyncCommit`/`lastSyncVersion` saat berhasil (misalnya `:143,173,224`), mencatat konflik dengan `unmergedBranchName`, `unmergedBranchHead`, dan `conflictVersion` (`:207-213`), dan menghapusnya setelah konflik diselesaikan (`:250-257`). |
| `SyncStateManager.mjs:23-25` (`removeProjectState`) | Menghapus dokumen saat pemilik memutus tautan proyek (`GitHubSyncHandler.mjs:83-97`) dan saat proyek yang dihapus kedaluwarsa (`services/web/modules/github-sync/index.mjs:56-58`). |

#### Indeks {#indexes}

| Nama | Kunci | Opsi | Migrasi |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

`autoIndex` Mongoose dimatikan (`services/web/app/src/infrastructure/Mongoose.mjs:7`), jadi `unique: true` skema pada `projectId` tidak membuat apa pun. `tools/migrations/20190912145010_create_githubSyncProjectStates_indexes.mjs` (`project_id` dan `owner_id` dari upstream) hanya bertag `saas` dan tidak berjalan di CE.

#### Catatan {#notes}

* Sinkronisasi berjalan di bawah lock `gitSync` proyek (`GitMerge.mjs:17-24`). GitLab Sync dan Gitea Sync mengambil lock yang sama, sehingga hanya satu sinkronisasi yang berjalan per proyek pada satu waktu.
* Proyek yang dihapus menyimpan dokumennya sampai proyek itu kedaluwarsa.
* Token GitHub pengguna ada di [GitHub Sync User Credentials](/id/dev/data-model/github-sync-user-credentials-collection).
