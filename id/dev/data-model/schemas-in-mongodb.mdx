Di bagian ini, kita akan membahas model data Overleaf. Overleaf menggunakan MongoDB untuk persistensi data, dan satu-satunya nama database adalah `sharelatex`, yang juga merupakan pendahulu Overleaf.

Jika Anda belum menyiapkan Mongo Express untuk overleaf, sangat disarankan untuk melihat [setup-develop-tools.md](/id/dev/environment/setup-develop-tools  "mention") dan menyiapkan mongo Anda.

Setelah Mongo Express Anda siap, Anda dapat login ke [http://localhost:8081/](http://localhost:8081/) dengan kredensial `admin:pass`.
