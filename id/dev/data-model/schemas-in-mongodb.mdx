Di bagian ini, kita akan membahas model data Overleaf. Overleaf menggunakan MongoDB untuk persistensi data, dan satu-satunya nama database adalah `sharelatex`, yang juga merupakan pendahulu Overleaf.

Lingkungan pengembangan sudah menjalankan Mongo Express di samping Mongo (lihat [setup-develop-tools.md](/id/dev/environment/setup-develop-tools  "mention")). Buka [http://localhost:8081/](http://localhost:8081/) dan masuk dengan `admin:pass`.

<Frame>
  <img src="/images/dev/screenshot-1768810061206.png" alt="" />
</Frame>

Anda juga dapat membuka shell di kontainer Mongo dari direktori `develop`:

```bash
bin/docker-compose exec mongo mongosh sharelatex
```

#### Cara halaman-halaman ini ditulis {#how-the-pages-are-written}

* Setiap halaman mencantumkan field yang ditulis kode, beserta tipe, arti, dan baris kode yang menunjukkannya: baris skema Mongoose, atau tempat yang menulis field tersebut. Field yang hanya ditulis oleh migrasi, skrip, atau salah satu modul web menyebutkan hal itu.
* Banyak koleksi tidak memiliki skema Mongoose: layanan menulisnya dengan driver MongoDB.
* Indeks hanya dibuat oleh migrasi di `tools/migrations/`. CE menjalankan migrasi bertag `server-ce` setiap kali mulai (`server-ce/init_scripts/900_run_web_migrations.sh`); `autoIndex` Mongoose dinonaktifkan (`services/web/app/src/infrastructure/Mongoose.mjs:7`). Tabel indeks hanya mencantumkan apa yang akhirnya dimiliki instans CE.
* Teks doc ada di Mongo, tetapi isi lainnya tidak. Isi file disimpan sebagai blob dan riwayat sebagai chunk di bucket history-v1 (folder lokal, atau S3 / RustFS); doc yang terbuka berada di Redis sampai document-updater melakukan flush.

Database CE memiliki lebih banyak koleksi daripada ini. Banyak di antaranya dibuat kosong oleh migrasi indeksnya dan hanya digunakan di overleaf.com. Misalnya, tidak ada apa pun di CE atau modul kami yang menulis ke `splittests`, `samlLogs`, `notificationsPreferences`, `onboardingDataCollection`, atau `userfeatureusages` dalam penggunaan normal, sehingga koleksi tersebut tidak memiliki halaman.
