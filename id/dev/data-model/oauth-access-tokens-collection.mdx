`oauthAccessTokens` menyimpan token bearer yang diterima web. Di Ayakaleaf Pro, ini adalah token akses pribadi (token autentikasi Git) yang dibuat pengguna di halaman pengaturan akun dan dipakai untuk git-bridge serta endpoint MCP. Satu dokumen adalah satu token. Skemanya adalah `services/web/app/src/models/OauthAccessToken.mjs`; modul web `oauth2-server` menulis koleksi ini, sebagian besar dengan driver native.

#### Catatan {#notes}

* Menghapus pengguna tidak menghapus token-tokennya. `UserDeleter` memicu hook `cleanupPersonalAccessTokens` (`services/web/app/src/Features/User/UserDeleter.mjs:230-234`), tetapi tidak ada modul yang mendengarkannya. Kedua pemeriksaan token menolak token tersebut karena penggunanya sudah tidak ada, dan indeks TTL menghapusnya sehari setelah `accessTokenExpiresAt`.
* Menangguhkan pengguna hanya mengakhiri sesinya. Token tetap ada, dan kedua pemeriksaan token menolaknya selama `users.suspended` bernilai `true` (`OAuth2Model.mjs:51-54`, `OAuthPersonalAccessTokenManager.mjs:129-134`).
