title: Koleksi Spelling Preferences
icon: spell-check
---

`spellingPreferences` menyimpan kamus setiap pengguna: kata-kata yang ditambahkan pengguna melalui "Add to dictionary" di pemeriksa ejaan editor. Satu dokumen per pengguna. Pemiliknya adalah `web`, tanpa skema Mongoose; kodenya `services/web/app/src/Features/Spelling/LearnedWordsManager.mjs`.

#### Field {#fields}

| Field | Tipe | Arti | Sumber |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id dokumen, dibuat oleh upsert. | `LearnedWordsManager.mjs:21-31` |
| `token` | String | Id pengguna. Meskipun namanya begitu, rute ejaan meneruskan id pengguna yang sedang login (`SessionManager.getLoggedInUserId`). | `LearnedWordsManager.mjs:23` |
| `learnedWords` | Array of String | Kata-kata yang ditambahkan pengguna. | `LearnedWordsManager.mjs:26` |

#### Siapa yang menulis {#who-writes-it}

| Kode | Fungsinya |
| --- | --- |
| `LearnedWordsManager.mjs:13-32` (`learnWord`) | `POST /spelling/learn` (`services/web/app/src/router.mjs:1037-1041`, `services/web/app/src/Features/Spelling/SpellingController.mjs:45-58`): `$addToSet` kata tersebut, dengan upsert. Menolak jika daftar akan melebihi `Settings.maxDictionarySize` byte. |
| `LearnedWordsManager.mjs:38-47` (`unlearnWord`) | `POST /spelling/unlearn` (`router.mjs:1043-1047`, `SpellingController.mjs:66-79`): `$pull` kata tersebut. |
| `LearnedWordsManager.mjs:84-86` (`deleteUsersLearnedWords`) | Menghapus dokumen. Satu-satunya pembungkusnya, `SpellingHandler.deleteUserDictionary` (`services/web/app/src/Features/Spelling/SpellingHandler.mjs:24-26`), tidak dipanggil di mana pun di web atau modulnya. |

#### Catatan {#notes}

* Indeksnya tidak unik; upsert pada `token` menjaga satu dokumen per pengguna.
* Menghapus pengguna tidak menghapus dokumen ini.
