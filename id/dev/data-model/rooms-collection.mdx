`rooms` menyimpan satu dokumen per room chat sebuah proyek: chat proyek, atau satu utas komentar tinjauan. Hanya layanan chat yang menulisnya, di `services/chat/app/js/Features/Threads/ThreadManager.js`. Tidak ada skema Mongoose. Pesan-pesan sebuah room ada di koleksi [messages](/id/dev/data-model/messages-collection).

#### Field {#fields}

| Field | Tipe | Arti | Sumber |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Id room. `messages.room_id` menunjuk ke sini. | `ThreadManager.js:57-61` |
| `project_id` | ObjectId | Proyek tempat room berada. | `ThreadManager.js:43-54` |
| `thread_id` | ObjectId | Hanya pada utas komentar: id komentar, sama dengan `id` dan `op.t` dari komentar di `docs.ranges.comments` (lihat [docs](/id/dev/data-model/docs-collection)). Tidak ada pada room chat proyek. | `ThreadManager.js:38-55`, `services/docstore/app/js/RangeManager.js:54-57` |
| `resolved` | Object | Diatur saat utas diselesaikan, dihapus saat dibuka kembali. Utas tanpa field ini berstatus terbuka. | `ThreadManager.js:94-123` |
| `resolved.user_id` | String | Id pengguna yang menyelesaikan utas. Disimpan sebagai string, bukan ObjectId: body permintaan hanya diperiksa sebagai id yang valid, tidak dikonversi. | `ThreadManager.js:103`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:70` |
| `resolved.ts` | Date | Kapan utas diselesaikan. | `ThreadManager.js:104` |

#### Catatan {#notes}

* Sebuah proyek memiliki paling banyak satu room tanpa `thread_id`: chat proyek. Layanan chat menemukannya dengan `thread_id: { $exists: false }` (`ThreadManager.js:38-45`).
* Status selesai sebuah komentar hanya ada di sini. Docstore membuang `op.resolved` sebelum menyimpan rentang (`services/docstore/app/js/RangeManager.js:59-61`).
* Setelah proyek disalin, `thread_id` yang sama ada di dua proyek. Selalu kueri berdasarkan `project_id` dan `thread_id` bersama-sama, seperti yang dilakukan layanan chat.
* Room dari proyek yang dihapus tetap ada sampai proyek yang dihapus itu kedaluwarsa.
