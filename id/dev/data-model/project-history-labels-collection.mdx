---
title: Koleksi Project History Labels
icon: tag
---

`projectHistoryLabels` menyimpan label yang diberikan pengguna pada versi di tampilan History, satu dokumen per label. project-history pemiliknya dan menulisnya di `services/project-history/app/js/LabelsManager.js`; tidak ada skema Mongoose. Web hanya mengaksesnya melalui API project-history.

#### Field {#fields}

| Field | Tipe | Arti | Sumber |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Id label. | `LabelsManager.js:81-85` |
| `project_id` | ObjectId | Proyek. | `LabelsManager.js:73` |
| `comment` | String | Teks label. | `LabelsManager.js:74` |
| `version` | Number | Versi riwayat proyek yang ditunjuk label. | `LabelsManager.js:75` |
| `created_at` | Date | Kapan label dibuat; permintaan dapat mengirim waktunya sendiri, jika tidak maka waktu sekarang. | `LabelsManager.js:70`, `76` |
| `user_id` | ObjectId | Siapa yang membuat label. Dihilangkan jika permintaan tidak memiliki pengguna. | `LabelsManager.js:78-80` |

#### Siapa yang menulis {#who-writes-it}

| Kode | Fungsinya |
| ---- | ------------ |
| `services/project-history/app/js/LabelsManager.js:44-90` | `createLabel`: menyisipkan label, untuk project-history `POST /project/:project_id/labels` (`services/project-history/app/js/HttpController.js:1134-1171`). Web memanggilnya ketika pengguna menambahkan label, dengan id pengguna (`services/web/app/src/Features/History/HistoryController.mjs:529-546`). |
| `LabelsManager.js:113-126` | `deleteLabel`: menghapus label proyek, untuk `DELETE /project/:project_id/labels/:label_id`. Web memakainya ketika pemilik proyek menghapus label (`HistoryController.mjs:649-670`). |
| `LabelsManager.js:92-111` | `deleteLabelForUser`: menghapus label hanya jika pengguna yang membuatnya, untuk `DELETE /project/:project_id/user/:user_id/labels/:label_id`. Web memakainya untuk semua orang lain. |
| `LabelsManager.js:128-143` | `transferLabels`: memindahkan semua label dari satu pengguna ke pengguna lain, untuk `POST /user/:from_user/labels/transfer/:to_user` (`services/project-history/app/js/Router.js:52-55`). Tidak ada yang memanggil route ini di web. |
| `LabelsManager.js:7-25` | `cloneLabels`: menyalin label sebuah proyek ke proyek lain, untuk project-history `POST /project/:project_id/clone` (`HttpController.js:113`), yang tidak dipanggil oleh apa pun di web. |

#### Siapa yang membaca {#who-reads-it}

| Kode | Fungsinya |
| ---- | ------------ |
| `LabelsManager.js:27-42` | `getLabels`: semua label sebuah proyek, dikembalikan sebagai `{ id, comment, version, user_id, created_at }` (`LabelsManager.js:163-171`). Dipakai oleh `GET /project/:project_id/labels` (`HttpController.js:1076-1100`), yang dipanggil web untuk tampilan History sambil mengisi nama pengguna (`HistoryController.mjs:488-499`). |
| `services/project-history/app/js/SummarizedUpdatesManager.js:57` | Menambahkan label ke daftar pembaruan riwayat. |

#### Catatan {#notes}

* Sebelum menyisipkan label, project-history memproses pembaruan proyek yang mengantre dan memeriksa bahwa history-v1 memiliki chunk untuk versi itu, kecuali permintaan mengirim `validate_exists: false` (`LabelsManager.js:53-59`, `173-195`; `HttpController.js:1109-1115`).
* Tidak ada kode yang menghapus label proyek ketika proyek dihapus: project-history `DELETE /project/:project_id` hanya membersihkan status sinkronisasi dan catatan kegagalan (`HttpController.js:1363-1396`), dan tidak ada layanan lain yang menyentuh koleksi ini.
