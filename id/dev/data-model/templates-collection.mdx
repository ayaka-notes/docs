`templates` menyimpan satu dokumen per templat di galeri templat. File sebuah templat (zip proyek dan PDF) tidak ada di sini: file tersebut disimpan di filestore di bawah `template/<_id>/v/<version>/`. Koleksi ini milik modul web `template-gallery` (`services/web/modules/template-gallery`). Skemanya adalah model Mongoose `Template` di `services/web/modules/template-gallery/app/src/models/Template.mjs`; logikanya ada di `services/web/modules/template-gallery/app/src/TemplateGalleryManager.mjs` dan `TemplateGalleryHelper.mjs` di sebelahnya.

#### Siapa yang menulis {#who-writes-it}

| Kode | Fungsinya |
| ---- | ------------ |
| `TemplateGalleryManager.mjs:53-97` (`createTemplateFromProject`) | `POST /template/new/:Project_id`. Menyalin pengaturan proyek (`TemplateGalleryHelper.mjs:94-134`), mengunggah zip dan PDF ke filestore, lalu menyimpan. Jika nama sudah dipakai, ia menjawab dengan konflik, kecuali klien meminta untuk menimpa: dalam hal itu ia memperbarui templat tersebut dan menaikkan `version`-nya, lalu menghapus file versi sebelumnya. |
| `TemplateGalleryManager.mjs:21-47` (`editTemplate`) | `POST /template/:template_id/edit`. Menetapkan field yang dikirim ke dokumen, merender ulang `description` dan `author`, dan mengatur `lastUpdated`. Formulir penyuntingan mengirim field yang berubah di antara `name`, `license`, `category`, `language`, `authorMD`, dan `descriptionMD` (`services/web/modules/template-gallery/frontend/js/pages/template/util/api.ts:22-29`). |
| `TemplateGalleryHelper.mjs:186-222` (`deleteTemplateAssets`) | `DELETE /template/:template_id/delete` menghapus dokumen dan file versi yang ditentukan (`TemplateGalleryManager.mjs:49-51`). |

Hanya admin situs dan pengguna di `OVERLEAF_TEMPLATES_USER_ID` yang boleh memanggil ketiga rute ini (`services/web/modules/template-gallery/app/src/Router.mjs:55-62,70-84`, `PermissionsMiddleware.mjs:8-19`).

#### Indeks {#indexes}

| Nama | Kunci | Opsi | Migrasi |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | bawaan |

`autoIndex` Mongoose dinonaktifkan (`services/web/app/src/infrastructure/Mongoose.mjs:7`). `tools/migrations/20190912145030_create_templates_indexes.mjs` (`project_id`, `user_id`, `name` unik) diberi tag `server-pro` dan `saas`, sehingga tidak berjalan di CE, yang hanya menjalankan migrasi `server-ce` (`server-ce/init_scripts/900_run_web_migrations.sh`).

#### Catatan {#notes}

* Upstream memperlakukan `templates` sebagai koleksi usang dan menghapusnya di situsnya sendiri (`tools/migrations/20241002180623_drop_unused_collections.mjs`, bertag `saas`). Di Ayakaleaf Pro, modul galeri templat menggunakannya.
* Pengurutan berdasarkan nama menggunakan collation yang tidak membedakan huruf besar kecil, dan komentar di `TemplateGalleryManager.mjs:186-188` mencatat bahwa indeks `name` akan membutuhkan collation yang sama. CE tidak memiliki indeks `name`, sehingga Mongo mengurutkan di memori.
* Menghapus proyek sumber atau pemilik tidak menghapus templat.
