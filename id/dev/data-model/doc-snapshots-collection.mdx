`docSnapshots` menyimpan salinan doc yang diambil document-updater tepat sebelum suntingan yang meringkas komentar atau perubahan terlacak. Hanya document-updater yang menulisnya, di `services/document-updater/app/js/SnapshotManager.js`. Web memiliki model Mongoose di `services/web/app/src/models/DocSnapshot.mjs`, tetapi tidak ada kode yang memakainya.

#### Field {#fields}

| Field | Tipe | Arti | Sumber |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Id snapshot. | `SnapshotManager.js:24` |
| `project_id` | ObjectId | Proyek. | `SnapshotManager.js:19,26`, `DocSnapshot.mjs:7` |
| `doc_id` | ObjectId | Doc (`docs._id`). | `SnapshotManager.js:20,27`, `DocSnapshot.mjs:8` |
| `version` | Number | Versi OT doc sebelum suntingan. | `SnapshotManager.js:28`, `services/document-updater/app/js/UpdateManager.js:132,264-271`, `DocSnapshot.mjs:9` |
| `lines` | Array of String | Isi doc sebelum suntingan. | `SnapshotManager.js:29`, `DocSnapshot.mjs:10` |
| `pathname` | String | Path doc di proyek pada saat itu. | `SnapshotManager.js:30`, `DocSnapshot.mjs:11` |
| `ranges` | Mixed | `comments` dan `changes` sebelum suntingan, dengan bentuk yang sama seperti `docs.ranges` (lihat [docs](/id/dev/data-model/docs-collection)). `id`, `op.t`, dan `metadata.user_id` diubah menjadi ObjectId dan `metadata.ts` menjadi Date. | `SnapshotManager.js:31,41-68`, `DocSnapshot.mjs:12` |
| `ts` | Date | Kapan snapshot diambil. Indeks TTL menghapus snapshot 30 hari kemudian. | `SnapshotManager.js:32`, `DocSnapshot.mjs:13` |

#### Siapa yang menulis {#who-writes-it}

| Kode | Fungsinya |
| ---- | ------------ |
| `UpdateManager.js:248-271` | Setelah menerapkan suntingan, document-updater mencatat doc seperti sebelum suntingan jika suntingan itu meringkas rentang: lebih banyak rentang menjadi kosong, atau lebih dari satu rentang dihapus (`services/document-updater/app/js/RangesManager.js:104-106`). |
| `SnapshotManager.js:17-36` `recordSnapshot` | Menyisipkan snapshot. |

#### Siapa yang membaca {#who-reads-it}

Tidak ada kode yang membacanya. Model web didefinisikan tetapi tidak dipakai di mana pun.

#### Catatan {#notes}

* Hanya suntingan yang melewati `UpdateManager.applyUpdate` yang mengambil snapshot. Suntingan yang ditangani `HistoryOTUpdateManager` tidak (`UpdateManager.js:74-77`).
* Tidak ada indeks pada `doc_id`. Cari snapshot sebuah doc berdasarkan `project_id` dan `ts`, lalu filter berdasarkan `doc_id`.
