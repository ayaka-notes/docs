## Apa itu LaTeX?

LaTeX (diucapkan “_LEI_-tek” atau “_LA_-tek”) adalah alat untuk menata huruf (typesetting) dokumen yang terlihat profesional. Namun, cara kerja LaTeX cukup berbeda dari banyak aplikasi pembuat dokumen lain yang mungkin pernah Anda gunakan, seperti Microsoft Word atau LibreOffice Writer: alat-alat “[WYSIWYG](https://en.wikipedia.org/wiki/WYSIWYG)” tersebut menyediakan halaman interaktif bagi pengguna untuk mengetik dan menyunting teks serta menerapkan berbagai bentuk gaya. LaTeX bekerja dengan sangat berbeda: dokumen Anda adalah file teks biasa yang diselingi _perintah_ LaTeX yang digunakan untuk menyatakan hasil (tata letak) yang diinginkan. Untuk menghasilkan dokumen tertata yang dapat dilihat, file LaTeX Anda diproses oleh sebuah perangkat lunak yang disebut _mesin TeX_ (TeX engine), yang menggunakan perintah-perintah yang tertanam dalam file teks Anda untuk memandu dan mengendalikan proses penataan huruf, mengubah perintah LaTeX dan teks dokumen menjadi file PDF yang tertata secara profesional. Artinya, Anda hanya perlu fokus pada _isi_ dokumen Anda, dan komputer, melalui perintah LaTeX dan mesin TeX, akan mengurus _tampilan visual_ (format)-nya.

## Mengapa belajar LaTeX?

Berbagai argumen dapat diajukan untuk mendukung, atau menentang, belajar menggunakan LaTeX alih-alih aplikasi penulisan dokumen lainnya; namun pada akhirnya, ini adalah pilihan pribadi berdasarkan preferensi, kecocokan, dan kebutuhan dokumentasi.

Argumen yang mendukung LaTeX antara lain:

* dukungan untuk menata matematika yang sangat kompleks, tabel, dan konten teknis untuk ilmu-ilmu fisika;
* fasilitas untuk catatan kaki, rujukan silang, dan pengelolaan daftar pustaka;
* kemudahan menghasilkan elemen dokumen yang rumit atau membosankan seperti indeks, glosarium, daftar isi, dan daftar gambar;
* sangat dapat disesuaikan untuk produksi dokumen khusus berkat kemampuan pemrograman dan ekstensibilitas intrinsiknya melalui ribuan [paket tambahan gratis](https://www.ctan.org/pkg).

Secara keseluruhan, LaTeX memberi pengguna kendali yang sangat besar atas produksi dokumen yang ditata dengan standar yang sangat tinggi. Tentu saja, ada jenis dokumen atau publikasi di mana LaTeX kurang unggul, termasuk banyak desain halaman “bebas” yang biasa ditemukan pada publikasi bergaya majalah.

Salah satu manfaat penting LaTeX adalah pemisahan isi dokumen dari gaya dokumen: setelah Anda menulis isi dokumen, tampilannya dapat diubah dengan mudah. Demikian pula, Anda dapat membuat file LaTeX yang mendefinisikan tata letak/gaya jenis dokumen tertentu, dan file tersebut dapat digunakan sebagai _template_ untuk menstandarkan penulisan/produksi dokumen lain dengan jenis yang sama; misalnya, ini memungkinkan penerbit ilmiah membuat template artikel dalam LaTeX, yang digunakan penulis untuk menulis makalah yang akan diajukan ke jurnal. Overleaf memiliki [galeri berisi ribuan template](https://www.overleaf.com/gallery), yang mencakup beragam jenis dokumen—mulai dari artikel ilmiah, laporan, dan buku hingga CV dan presentasi. Karena template ini mendefinisikan tata letak dan gaya dokumen, penulis cukup membukanya di Overleaf—membuat proyek baru—lalu mulai menulis untuk menambahkan isinya.

## Menulis kode LaTeX pertama Anda

Langkah pertama adalah membuat proyek LaTeX baru. Anda dapat melakukannya di komputer Anda sendiri dengan membuat file `.tex` baru; atau, Anda dapat memulai proyek baru di Overleaf.

Mari kita mulai dengan contoh paling sederhana yang berfungsi, yang dapat dibuka langsung di Overleaf:

```latex
\documentclass{article}
\begin{document}
First document. This is a simple example, with no 
extra parameters or packages included.
\end{document}
```

[Buka contoh ini di Overleaf.](https://www.overleaf.com/docs?engine=pdflatex&snip%5Fname=Simplest+working+example+LaTeX+document&snip=%5Cdocumentclass%7Barticle%7D%0A%5Cbegin%7Bdocument%7D%0AFirst+document.+This+is+a+simple+example%2C+with+no+%0Aextra+parameters+or+packages+included.%0A%5Cend%7Bdocument%7D)

Contoh ini menghasilkan output berikut:

![Contoh dokumen](https://images.ctfassets.net/nrgyaltdicpt/5oBbZABsWEnHZpwhfvV2PD/95ba7d5496616b4f10dffe6fb90f578a/LL30Fig1-plain.svg)

Anda dapat melihat bahwa LaTeX secara otomatis membuat indentasi pada baris pertama paragraf, mengurus format tersebut untuk Anda. Mari kita lihat lebih dekat apa yang dilakukan setiap bagian kode kita.

Baris kode pertama, `\documentclass{article}`, mendeklarasikan jenis dokumen yang dikenal sebagai _class_-nya, yang mengendalikan tampilan keseluruhan dokumen. Jenis dokumen yang berbeda memerlukan class yang berbeda; misalnya, CV/resume akan memerlukan class yang berbeda dari makalah ilmiah yang mungkin menggunakan class standar LaTeX `article`. Jenis dokumen lain yang mungkin sedang Anda kerjakan bisa memerlukan class lain seperti `book` atau `report`. Untuk mendapatkan gambaran tentang banyaknya jenis class LaTeX yang tersedia, [kunjungi halaman terkait di CTAN (Comprehensive TeX Archive Network)](https://www.ctan.org/topic/class).

Setelah menetapkan class dokumen, isi kita, yang dikenal sebagai _body_ (badan) dokumen, ditulis di antara tag `\begin{document}` dan `\end{document}`. Setelah membuka contoh di atas, Anda dapat mengubah teksnya dan, setelah selesai, melihat PDF hasil penataan dengan _mengompilasi ulang dokumen_. ## Preamble sebuah dokumen

Tangkapan layar di atas menunjukkan Overleaf menyimpan dokumen LaTeX sebagai file bernama `main.tex`: ekstensi file `.tex`, berdasarkan konvensi, digunakan saat menamai file yang berisi kode LaTeX dokumen Anda.

Contoh sebelumnya menunjukkan bagaimana isi dokumen dimasukkan setelah perintah `\begin{document}`; namun, segala sesuatu di file `.tex` Anda yang muncul _sebelum_ titik tersebut disebut _preamble_, yang berfungsi sebagai bagian “pengaturan” dokumen. Di dalam preamble, Anda mendefinisikan class (jenis) dokumen beserta hal-hal spesifik seperti bahasa yang akan digunakan saat menulis dokumen; memuat _paket_ yang ingin Anda gunakan (lebih lanjut tentang ini [nanti](/id/texlive/latex-basics/learn-latex-in-30-minutes#Finding%5Fand%5Fusing%5FLaTeX%5Fpackages)), dan di sinilah Anda menerapkan jenis konfigurasi lainnya.

Preamble dokumen minimal mungkin terlihat seperti ini:

```latex
\documentclass[12pt, letterpaper]{article}
\usepackage{graphicx}
```

di mana `\documentclass[12pt, letterpaper]{article}` mendefinisikan class (jenis) dokumen secara keseluruhan. Parameter tambahan, yang harus dipisahkan dengan koma, dimasukkan dalam kurung siku (`[...]`) dan digunakan untuk mengonfigurasi instans class article ini; yaitu, pengaturan yang ingin kita gunakan untuk dokumen berbasis class `article` ini secara khusus.

Dalam contoh ini, kedua parameter melakukan hal berikut:

* `12pt` mengatur ukuran font
* `letterpaper` mengatur ukuran kertas

Tentu saja ukuran font lain, `9pt`, `11pt`, `12pt`, dapat digunakan, tetapi jika tidak ada yang ditentukan, ukuran default-nya adalah `10pt`. Untuk ukuran kertas, nilai lain yang mungkin adalah `a4paper` dan `legalpaper`. Untuk informasi lebih lanjut, lihat artikel tentang ukuran halaman dan margin.

Baris preamble

```latex
\usepackage{graphicx}
```

adalah contoh memuat paket eksternal (di sini, [graphicx](https://ctan.org/pkg/graphicx?lang=en)) untuk memperluas kemampuan LaTeX, sehingga memungkinkannya mengimpor file grafis eksternal. Paket LaTeX dibahas di bagian [Menemukan dan menggunakan paket LaTeX](/id/texlive/latex-basics/learn-latex-in-30-minutes#Finding%5Fand%5Fusing%5FLaTeX%5Fpackages).

## Menyertakan informasi judul, penulis, dan tanggal

Menambahkan judul, penulis, dan tanggal ke dokumen kita memerlukan tiga baris lagi di _preamble_ (_bukan_ di badan utama dokumen). Baris-baris tersebut adalah:

* `\title{My first LaTeX document}`: judul dokumen
* `\author{Hubert Farnsworth}`: di sini Anda menulis nama penulis dan, secara opsional, perintah `\thanks` di dalam kurung kurawal:
  * `\thanks{Funded by the Overleaf team.}`: dapat ditambahkan setelah nama penulis, di dalam kurung kurawal perintah `author`. Perintah ini akan menambahkan superskrip dan catatan kaki dengan teks di dalam kurung kurawal. Berguna jika Anda perlu berterima kasih kepada sebuah institusi dalam artikel Anda.
* `\date{August 2022}`: Anda dapat memasukkan tanggal secara manual atau menggunakan perintah `\today` untuk menata tanggal saat ini setiap kali dokumen dikompilasi

Dengan baris-baris ini ditambahkan, preamble Anda akan terlihat seperti ini:

```latex
\documentclass[12pt, letterpaper]{article}
\title{My first LaTeX document}
\author{Hubert Farnsworth\thanks{Funded by the Overleaf team.}}
\date{August 2022}
```

Untuk menata judul, penulis, dan tanggal, gunakan perintah `\maketitle` di dalam _body_ dokumen:

```latex
\begin{document}
\maketitle
We have now added a title, author and date to our first \LaTeX{} document!
\end{document}
```

Preamble dan body sekarang dapat digabungkan untuk menghasilkan dokumen lengkap yang dapat dibuka di Overleaf:

```latex
\documentclass[12pt, letterpaper]{article}
\title{My first LaTeX document}
\author{Hubert Farnsworth\thanks{Funded by the Overleaf team.}}
\date{August 2022}
\begin{document}
\maketitle
We have now added a title, author and date to our first \LaTeX{} document!
\end{document}
```

## Menambahkan komentar

LaTeX adalah salah satu bentuk “kode program”, tetapi yang khusus untuk penataan huruf dokumen; akibatnya, seperti kode yang ditulis dalam bahasa pemrograman lainnya, menyertakan komentar di dalam dokumen Anda bisa sangat berguna. Komentar LaTeX adalah bagian teks yang tidak akan ditata atau memengaruhi dokumen dengan cara apa pun—sering digunakan untuk menambahkan catatan “to do”; menyertakan catatan penjelasan; memberikan penjelasan sebaris untuk makro yang rumit, atau menonaktifkan (comment-out) baris/bagian kode LaTeX saat debugging.

Untuk membuat komentar di LaTeX, cukup tulis simbol `%` di awal baris, seperti yang ditunjukkan pada kode berikut yang menggunakan contoh di atas:

```latex
\documentclass[12pt, letterpaper]{article}
\title{My first LaTeX document}
\author{Hubert Farnsworth\thanks{Funded by the Overleaf team.}}
\date{August 2022}
\begin{document}
\maketitle
We have now added a title, author and date to our first \LaTeX{} document!

% This line here is a comment. It will not be typeset in the document.
\end{document}
```

[Buka contoh ini di Overleaf.](https://www.overleaf.com/docs?engine=pdflatex&snip%5Fname=My+first+LaTeX+document+with+a+comment&snip=%5Cdocumentclass%5B12pt%2C+letterpaper%5D%7Barticle%7D%0A%5Ctitle%7BMy+first+LaTeX+document%7D%0A%5Cauthor%7BHubert+Farnsworth%5Cthanks%7BFunded+by+the+Overleaf+team.%7D%7D%0A%5Cdate%7BAugust+2022%7D%0A%5Cbegin%7Bdocument%7D%0A%5Cmaketitle%0AWe+have+now+added+a+title%2C+author+and+date+to+our+first+%5CLaTeX%7B%7D+document%21%0A%0A%25+This+line+here+is+a+comment.+It+will+not+be+typeset+in+the+document.%0A%5Cend%7Bdocument%7D)

Contoh ini menghasilkan output yang identik dengan kode LaTeX sebelumnya yang tidak berisi komentar.

## Tebal, miring, dan garis bawah

Selanjutnya, sekarang kita akan melihat beberapa perintah format teks:

* **Tebal**: teks tebal di LaTeX ditata menggunakan perintah `\textbf{...}`.
* _Miring_: teks miring dihasilkan menggunakan perintah `\textit{...}`.
* Garis bawah: untuk memberi garis bawah pada teks, gunakan perintah `\underline{...}`.

Contoh berikut mendemonstrasikan perintah-perintah ini:

```latex
Some of the \textbf{greatest}
discoveries in \underline{science} 
were made by \textbf{\textit{accident}}.
```

[Buka contoh ini di Overleaf.](https://www.overleaf.com/docs?engine=pdflatex&snip%5Fname=First+example+with+formatted+text&snip=%5Cdocumentclass%5B12pt%2C+letterpaper%5D%7Barticle%7D%0A%5Ctitle%7BMy+first+LaTeX+document%7D%0A%5Cauthor%7BHubert+Farnsworth%5Cthanks%7BFunded+by+the+Overleaf+team.%7D%7D%0A%5Cdate%7BAugust+2022%7D%0A%5Cbegin%7Bdocument%7D%0A%5Cmaketitle%0ASome+of+the+%5Ctextbf%7Bgreatest%7D%0Adiscoveries+in+%5Cunderline%7Bscience%7D+%0Awere+made+by+%5Ctextbf%7B%5Ctextit%7Baccident%7D%7D.%0A%5Cend%7Bdocument%7D)

Contoh ini menghasilkan output berikut:

![Gambar yang menunjukkan teks berformat dalam dokumen LaTeX](https://images.ctfassets.net/nrgyaltdicpt/6vo15r0tLCByTpcvn1w2E8/8f14edc7ece1f10ce4ba2c76e1e58a56/LL30Fig3r-plain.svg)

Perintah lain yang sangat berguna adalah `\emph{_argument_}`, yang efeknya pada `_argument_` bergantung pada konteks. Di dalam teks normal, teks yang ditekankan akan dibuat miring, tetapi perilaku ini dibalik jika digunakan di dalam teks yang miring—lihat contoh berikut:


## Menambahkan gambar

Di bagian ini kita akan melihat cara menambahkan gambar ke dokumen LaTeX. Overleaf mendukung tiga cara untuk menyisipkan gambar:

1. Gunakan [tombol **Insert Figure**](https://learn.overleaf.com/learn/Kb/How_to_insert_figures_in_Overleaf#Using%5FInsert%5FFigure%5Fto%5Fadd%5Fa%5Ffigure%5Fto%5Fyour%5Fproject)(![Tombol Insert Figure pada toolbar editor](https://sharelatex-wiki-cdn-671420.cdn77.org/learn-scripts/images/a/a8/InsertFigureButton.png)), yang terletak di toolbar editor, untuk menyisipkan gambar ke **Visual Editor** atau **Code Editor**.
2. Salin dan tempel gambar ke **Visual Editor** atau **Code Editor**.
3. Gunakan **Code Editor** untuk menulis kode LaTeX yang menyisipkan grafis.

Opsi 1 dan 2 secara otomatis menghasilkan kode LaTeX yang diperlukan untuk menyisipkan gambar, tetapi di sini kita memperkenalkan opsi 3—perhatikan bahwa Anda perlu [mengunggah gambar-gambar tersebut](https://docs.overleaf.com/writing-and-editing/inserting-images) ke proyek Overleaf Anda. Contoh berikut mendemonstrasikan cara menyertakan gambar:

```latex
\documentclass{article}
\usepackage{graphicx} %LaTeX package to import graphics
\graphicspath{{images/}} %configuring the graphicx package
 
\begin{document}
The universe is immense and it seems to be homogeneous, 
on a large scale, everywhere we look.

% The \includegraphics command is 
% provided (implemented) by the 
% graphicx package
\includegraphics{universe}  
 
There's a picture of a galaxy above.
\end{document}
```

Mengimpor grafis ke dalam dokumen LaTeX memerlukan [_paket_ tambahan](/id/texlive/latex-basics/learn-latex-in-30-minutes#Finding%5Fand%5Fusing%5FLaTeX%5Fpackages) yang menyediakan perintah dan fitur yang diperlukan untuk menyertakan file grafis eksternal. Untuk menggunakan paket `graphicx`, sertakan baris berikut di preamble dokumen Overleaf Anda:

```latex
\usepackage{graphicx}
```

* Meskipun nama file lengkap, termasuk ekstensinya, diperbolehkan dalam perintah `\includegraphics`, praktik terbaiknya adalah menghilangkan ekstensi file karena hal itu akan membuat LaTeX mencari semua format yang didukung.
* Umumnya, nama file grafis tidak boleh berisi spasi atau beberapa titik; juga disarankan menggunakan huruf kecil untuk ekstensi file saat mengunggah file gambar ke Overleaf.

## Keterangan, label, dan rujukan

Gambar dapat diberi keterangan (caption), label, dan dirujuk menggunakan lingkungan `figure`, seperti yang ditunjukkan di bawah ini:

```latex
\documentclass{article}
\usepackage{graphicx}
\graphicspath{{images/}}
 
\begin{document}

\begin{figure}[h]
    \centering
    \includegraphics[width=0.75\textwidth]{mesh}
    \caption{A nice plot.}
    \label{fig:mesh1}
\end{figure}
 
As you can see in figure \ref{fig:mesh1}, the function grows near the origin. This example is on page \pageref{fig:mesh1}.

\end{document}
```

Contoh ini menghasilkan output berikut:

![Grafik yang menunjukkan penggunaan keterangan gambar di LaTeX](https://images.ctfassets.net/nrgyaltdicpt/4DkAWWkQqZP6QHU2EErogQ/9aa2371f2cde0f3f8bf22aa1c0b91789/LL30Fig6r-plain.svg)

Ada beberapa perintah penting dalam contoh ini:

* **`\includegraphics[width=0.75\textwidth]{mesh}`**: Bentuk `\includegraphics` ini menginstruksikan LaTeX untuk mengatur lebar gambar menjadi 75% dari lebar teks—yang nilainya disimpan dalam perintah `\textwidth`.
* **`\caption{A nice plot.}`**: Sesuai namanya, perintah ini mengatur keterangan gambar yang dapat ditempatkan di atas atau di bawah gambar. Jika Anda membuat daftar gambar, keterangan ini akan digunakan dalam daftar tersebut.
* **`\label{fig:mesh1}`**: Untuk merujuk gambar ini di dalam dokumen Anda, berikan label menggunakan perintah `\label`. Label digunakan untuk menghasilkan nomor bagi gambar dan, bersama dengan perintah berikutnya, memungkinkan Anda merujuknya.
* **`\ref{fig:mesh1}`**: Kode ini akan diganti dengan nomor yang sesuai dengan gambar yang dirujuk.

Gambar yang dimasukkan ke dalam dokumen LaTeX sebaiknya ditempatkan di dalam lingkungan `figure`, atau yang serupa, agar LaTeX dapat secara otomatis memosisikan gambar di lokasi yang sesuai dalam dokumen Anda.

Panduan lebih lanjut terdapat dalam artikel bantuan Overleaf berikut:

* Pemosisian Gambar
* [Menyisipkan Gambar](https://docs.overleaf.com/writing-and-editing/inserting-images)

## Membuat daftar di LaTeX

Anda dapat membuat berbagai jenis daftar menggunakan _lingkungan_ (environment), yang digunakan untuk membungkus kode LaTeX yang diperlukan untuk mengimplementasikan fitur penataan tertentu. Sebuah lingkungan dimulai dengan `\begin{_environment-name_}` dan diakhiri dengan `\end{_environment-name_}` di mana `_environment-name_` dapat berupa `figure`, `tabular`, atau salah satu jenis daftar: `itemize` untuk daftar tidak berurutan atau `enumerate` untuk daftar berurutan.

### Daftar tidak berurutan

Daftar tidak berurutan dihasilkan oleh lingkungan `itemize`. Setiap entri daftar harus diawali dengan perintah `\item`, seperti yang ditunjukkan di bawah ini:

```latex
\documentclass{article}
\begin{document}
\begin{itemize}
  \item The individual entries are indicated with a black dot, a so-called bullet.
  \item The text in the entries may be of any length.
\end{itemize}
\end{document}
```

## Menambahkan matematika ke LaTeX

### Bab dan bagian

Dokumen yang lebih panjang, terlepas dari perangkat lunak penulisannya, biasanya dibagi menjadi part, bab (chapter), bagian (section), subbagian (subsection), dan seterusnya. Sebagai contoh, dokumen yang dibuat menggunakan class `book` dapat dibagi menjadi part, bab, bagian, subbagian, dan seterusnya, tetapi class `letter` tidak menyediakan (mendukung) perintah apa pun untuk melakukan hal tersebut.

Nama-nama perintah pembagian bagian sebagian besar sudah cukup jelas; misalnya, `\chapter{First Chapter}` membuat bab baru berjudul `First Chapter`, `\section{Introduction}` menghasilkan bagian berjudul `Introduction`, dan seterusnya. Bagian dapat dibagi lagi menjadi `\subsection{...}` dan bahkan `\subsubsection{...}`. Penomoran bagian, subbagian, dan sebagainya dilakukan secara otomatis, tetapi dapat dinonaktifkan dengan menggunakan yang disebut _versi bertanda bintang_ dari perintah yang bersangkutan, yang memiliki tanda bintang (\*) di akhir, seperti `\section*{...}` dan `\subsection*{...}`.

_Secara keseluruhan_, class dokumen LaTeX menyediakan perintah pembagian bagian berikut, dengan masing-masing class mendukung subset yang relevan:

* `\part{part}`
* `\chapter{chapter}`
* `\section{section}`
* `\subsection{subsection}`
* `\subsubsection{subsubsection}`
* `\paragraph{paragraph}`
* `\subparagraph{subparagraph}`

Secara khusus, perintah `\part` dan `\chapter` hanya tersedia di class dokumen `report` dan `book`.

Kunjungi artikel Overleaf tentang bagian dan bab untuk informasi lebih lanjut tentang perintah struktur dokumen.

## Membuat tabel

Overleaf menyediakan tiga opsi untuk membuat tabel:

3. Menulis kode LaTeX untuk tabel di Code Editor.

Jika Anda baru mengenal LaTeX, menggunakan toolbar di **Visual Editor** (opsi 1) adalah cara yang bagus untuk memulai—Anda dapat beralih antara **Visual Editor** dan **Code Editor** untuk melihat kode di balik tabel.

Di sini, kita fokus pada opsi 3—metode paling fleksibel untuk membuat tabel—dan memberikan contoh-contoh yang mendemonstrasikan cara membuat tabel di LaTeX, termasuk penambahan garis (rule) dan keterangan. Seiring bertambahnya pengalaman Anda, lihat panduan terperinci kami tentang [cara membuat tabel menggunakan LaTeX](https://www.overleaf.com/learn/latex/Tables).

### Menambahkan garis tepi

Lingkungan `tabular` mendukung garis (rule) horizontal dan vertikal sebagai bagian dari tabel:

* untuk menambahkan garis horizontal, di atas dan di bawah baris, gunakan perintah `\hline`
* untuk menambahkan garis vertikal, di antara kolom, gunakan parameter garis vertikal `|`

Dalam contoh ini argumennya adalah `{|c|c|c|}` yang mendeklarasikan tiga kolom (rata tengah) yang masing-masing dipisahkan oleh garis vertikal; selain itu, kita menggunakan `\hline` untuk menempatkan garis horizontal di atas baris pertama dan di bawah baris terakhir:

```latex
\begin{center}
\begin{tabular}{|c|c|c|} 
 \hline
 cell1 & cell2 & cell3 \\ 
 cell4 & cell5 & cell6 \\ 
 cell7 & cell8 & cell9 \\ 
 \hline
\end{tabular}
\end{center}
```

## Menemukan dan menggunakan paket LaTeX

LaTeX tidak hanya memberikan kemampuan penataan huruf yang signifikan, tetapi juga menyediakan _kerangka kerja untuk ekstensibilitas_ melalui penggunaan _paket_ tambahan. Alih-alih mencoba menyediakan perintah dan fitur yang “berusaha melakukan segalanya”, LaTeX dirancang agar _dapat diperluas_, memungkinkan pengguna memuat kumpulan kode eksternal (paket) yang menyediakan kemampuan penataan yang lebih khusus atau memperluas fitur bawaan LaTeX—seperti penataan tabel. Seperti yang terlihat di bagian [Menambahkan gambar](/id/texlive/latex-basics/learn-latex-in-30-minutes#Adding%5Fimages), paket `graphicx` memperluas LaTeX dengan menyediakan perintah untuk mengimpor file grafis dan dimuat (di preamble) dengan menuliskan

```latex
\usepackage{graphicx}
```

### Memuat paket

Seperti disebutkan di atas, paket dimuat di preamble dokumen melalui perintah `\usepackage`, tetapi karena (banyak) paket LaTeX menyediakan sekumpulan _opsi_ yang dapat digunakan untuk mengonfigurasi perilakunya, perintah `\usepackage` sering kali terlihat seperti ini:

```latex
\usepackage[options]{somepackage}
```

Kurung siku “`[...]`” memberi tahu LaTeX kumpulan opsi mana yang harus diterapkan saat memuat `somepackage`. Di dalam kumpulan opsi yang diminta oleh pengguna, masing-masing opsi atau pengaturan biasanya dipisahkan dengan koma; misalnya, [paket geometry](https://ctan.org/pkg/geometry) menyediakan banyak opsi untuk mengonfigurasi tata letak halaman di LaTeX, sehingga penggunaan umum `geometry` mungkin terlihat seperti ini:

```latex
\usepackage[total={6.5in,8.75in},
top=1.2in, left=0.9in, includefoot]{geometry}
```

Paket `geometry` adalah salah satu contoh paket yang ditulis dan dikontribusikan oleh anggota komunitas LaTeX global dan tersedia secara gratis bagi siapa saja yang ingin menggunakannya.

Jika sebuah paket LaTeX tidak menyediakan opsi apa pun, atau pengguna ingin menggunakan nilai default dari opsi-opsi paket, paket tersebut akan dimuat seperti ini:

```latex
\usepackage{somepackage}
```

Saat Anda menulis `\usepackage[...]{somepackage}`, LaTeX mencari file yang sesuai bernama `_somepackage_.sty`, yang perlu dimuat dan diprosesnya—agar perintah-perintah paket tersedia dan mengeksekusi kode lain yang disediakan oleh paket tersebut. Jika LaTeX tidak dapat menemukan `_somepackage_.sty`, LaTeX akan berhenti dengan error, seperti yang ditunjukkan dalam contoh Overleaf berikut:

```latex
\documentclass[12pt, letterpaper]{article}
\usepackage{somepackage}% a NON-EXISTENT package
\begin{document}
This will fail!
\end{document}
```

### Paket yang tersedia di Overleaf: Mengenal TeX Live

Setahun sekali, sebuah _subset_ (besar) dari paket-paket yang di-host di CTAN, ditambah font terkait LaTeX dan perangkat lunak lainnya, dikumpulkan dan didistribusikan sebagai sistem yang disebut [TeX Live](https://tug.org/texlive/), yang dapat digunakan untuk menginstal pengaturan LaTeX Anda sendiri (lokal). Bahkan, [server Overleaf juga menggunakan TeX Live](https://www.overleaf.com/learn/latex/Overleaf_and_TeX_Live) dan diperbarui ketika versi baru TeX Live dirilis. Pembaruan TeX Live di Overleaf tidak dilakukan secara langsung, tetapi beberapa bulan setelah rilis, memberi kami waktu untuk melakukan uji kompatibilitas versi TeX Live baru dengan [ribuan template yang ada di galeri kami](https://www.overleaf.com/gallery). Sebagai contoh, berikut adalah [pengumuman upgrade TeX Live 2025](https://www.overleaf.com/blog/tex-live-2025-is-now-available) kami.

Meskipun TeX Live berisi _subset_ (besar) dari paket-paket CTAN, Anda mungkin menemukan paket menarik, seperti [igo untuk menata diagram Go](https://ctan.org/pkg/igo?lang=en), yang di-host di CTAN tetapi tidak disertakan dalam (didistribusikan oleh) TeX Live sehingga tidak tersedia di Overleaf. Beberapa paket yang di-host di CTAN bukan bagian dari TeX Live karena berbagai alasan: mungkin paketnya sudah usang, memiliki masalah lisensi, sangat baru (baru saja diunggah), atau memiliki ketergantungan platform, seperti berfungsi di Windows tetapi tidak di Linux.

Paket baru, dan pembaruan untuk paket yang sudah ada, diunggah ke CTAN sepanjang tahun, tetapi pembaruan TeX Live didistribusikan setiap tahun; akibatnya, paket yang terdapat dalam versi TeX Live saat ini tidak akan semutakhir paket yang di-host di CTAN. Karena server Overleaf menggunakan TeX Live, ada kemungkinan paket yang terinstal di server kami—yaitu, yang tersedia bagi pengguna kami—bukan versi terbaru yang tersedia di CTAN, tetapi secara umum hal ini kemungkinan besar tidak akan menimbulkan masalah.
