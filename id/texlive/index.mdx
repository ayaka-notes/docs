[TeX Live](https://www.tug.org/texlive/) adalah distribusi perangkat lunak gratis yang diterbitkan setiap tahun oleh [TeX Users Group](https://www.tug.org/). Distribusi ini menyediakan paket LaTeX, font, mesin TeX, dan berbagai alat perangkat lunak yang dibutuhkan untuk mendukung penataan huruf berbasis LaTeX di semua sistem operasi standar.

TeX Live adalah komponen penting dari Overleaf karena server kami menggunakannya untuk mengompilasi kode LaTeX Anda dan menghasilkan pratinjau PDF secara real-time. TeX Live juga memberi pengguna Overleaf akses mudah ke lebih dari 5.000 paket LaTeX yang terdapat dalam setiap rilis TeX Live.

Anda tidak terbatas untuk menggunakan versi TeX Live terbaru dalam mengompilasi proyek Anda karena server Overleaf menyediakan akses ke rilis TeX Live sebelumnya. Proyek dapat dengan mudah dialihkan untuk menggunakan versi TeX Live yang lebih lama — misalnya, karena masalah kompatibilitas paket.<br />
