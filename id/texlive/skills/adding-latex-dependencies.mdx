Jika proyek Anda memiliki file `.cls`, `.sty`, `.bst`, proses kompilasi Overleaf tidak akan dapat menemukan file-file tersebut kecuali file tersebut ditempatkan di tingkat teratas.

Namun, untuk merapikan proyek Anda, Anda mungkin ingin menempatkan file-file ini di dalam folder agar lebih mudah ditemukan dan agar tingkat teratas proyek Anda tidak berantakan.

Kabar baiknya, kita dapat menentukan direktori `TEXINPUTS` kustom menggunakan file `latexmkrc`, sehingga Overleaf tahu bahwa ia perlu mencari file paket di direktori tersebut.

Untuk melakukannya, misalkan Anda telah menempatkan file-file paket ini di folder bernama `tex/`; dan file gaya bibliografi di folder bernama `bst/`:

1. Klik "Add file" di bagian atas bilah samping Project.
2. Pilih "Blank file", dan simpan dengan nama file `latexmkrc` (jika belum ada).
3.  Masukkan baris berikut ke dalam `latexmkrc`:

    ```perl
    $ENV{'TEXINPUTS'}='./tex//:' . $ENV{'TEXINPUTS'}; 
    $ENV{'BSTINPUTS'}='./bst//:' . $ENV{'BSTINPUTS'};
    ```

    (atau ubah ke nama folder yang sesuai di proyek Anda)

Overleaf sekarang akan mencari di folder `tex/` terlebih dahulu sebelum mencari di `TEXINPUTS` sistem untuk menemukan file paket, dan di folder `bst/` terlebih dahulu sebelum mencari di `BSTINPUTS` sistem untuk menemukan file gaya bibliografi.

(Sumber: [https://tex.stackexchange.com/a/50847](https://tex.stackexchange.com/a/50847))

<Info>

File dokumen utama Anda dan file `latexmkrc` Anda harus tetap berada di tingkat teratas proyek, bukan di dalam folder.

</Info>
