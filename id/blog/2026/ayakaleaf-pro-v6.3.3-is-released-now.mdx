Kami sangat bangga mengumumkan rilis Overleaf Pro 6.3.3. Overleaf 6.3.3 upstream adalah rilis keamanan yang memperbarui Node.js dan paket yang terinstal, dan kami merilisnya bersama pratinjau awal panel admin baru, beberapa email per akun, MCP Server yang lebih lengkap, serta asisten AI yang lebih baik.

### Perubahan {#changes}

* Panel admin baru (pratinjau awal): halaman pengguna, proyek, dan template, log audit, serta sakelar fitur per pengguna.
* Beberapa email per akun (pratinjau awal).
* MCP Server: riwayat, perubahan terlacak, komentar, chat, dan pemindahan file.
* Asisten AI: OpenAI Responses API, serta lampiran PDF, membaca halaman web, dan chat panjang (pratinjau awal).
* Pendaftaran dan login: reCAPTCHA v2 dan daftar domain email untuk pendaftaran publik (pratinjau awal).
* Node.js 24.22.3 dan pembaruan paket: pembaruan keamanan di Overleaf 6.3.3 upstream.
* Perbaikan bug yang ditemukan oleh sistem pengujian E2E kami dan Internal Horizon Issue Investigation.

<Info>

Panel admin baru, beberapa email, lampiran asisten AI, dan opsi pendaftaran baru dirilis di 6.3.3 sebagai **pratinjau awal** untuk pengujian bertahap, dan akan dirilis resmi di v6.4.0. Perilakunya masih dapat berubah sebelum itu. Silakan laporkan masalah apa pun di [GitHub](https://github.com/ayaka-notes/ayakaleaf-pro/issues).

</Info>

#### Fitur 01: Panel Admin Baru (Pratinjau) {#feature-01-new-admin-panel-preview}

Menjalankan instance untuk laboratorium atau departemen selalu memunculkan pertanyaan yang sama setiap minggu: mengapa mahasiswa ini tidak bisa login, siapa yang memberi hak admin ke akun itu, ke mana perginya tesis tahun lalu. Panel admin baru memiliki satu daftar untuk semua pengguna dan satu untuk semua proyek, halaman untuk masing-masing, manajemen template, dan log audit. Admin dapat bertindak atas banyak pengguna sekaligus, menyalin tautan aktivasi dan kata sandi saat tidak ada email yang terkirim, serta mengaktifkan atau menonaktifkan fitur besar seperti Dropbox, Git, asisten AI, lacak perubahan, dan palet simbol untuk satu pengguna.

#### Fitur 02: Beberapa Email per Akun (Pratinjau) {#feature-02-multiple-emails-per-account-preview}

Pengguna menambahkan lebih banyak email ke akunnya dengan kode yang dikirim ke masing-masing alamat, dan dapat menjadikan alamat lain sebagai email utama, misalnya sebelum alamat universitas dicabut. Hanya email utama yang dapat login dan menerima reset kata sandi. Fitur ini aktif ketika instance dapat mengirim email.

Lihat [Beberapa email](/id/on-premises/user-guide/users/multiple-emails  "mention").

#### Fitur 03: MCP Server {#feature-03-mcp-server}

Klien AI seperti Claude Code, Codex, atau Cursor kini dapat menelusuri riwayat proyek dan memulihkan versi, meninjau perubahan terlacak, menjadikan suntingan mereka sendiri sebagai perubahan terlacak, mengomentari teks, membaca dan mengirim pesan chat, serta memindahkan atau mengganti nama file. MCP Server kini memiliki 33 alat, naik dari 17.

Lihat [MCP Server](/on-premises/user-guide/users/mcp-server  "mention").

#### Fitur 04: OpenAI Responses API {#feature-04-openai-responses-api}

Model penalaran OpenAI yang lebih baru, seperti gpt-6.x, menolak function tool di Chat Completions, sehingga asisten AI dan asisten error tidak dapat menggunakannya. Atur `AI_API_MODE=responses` untuk memanggil OpenAI Responses API sebagai gantinya. Lampiran dan kuota token tetap berfungsi seperti sebelumnya.

Lihat [Integrasi AI](/id/on-premises/configuration/overleaf-toolkit/integrations/ai-integration  "mention").

#### Fitur 05: Peningkatan Asisten AI (Pratinjau) {#feature-05-ai-assistant-improvements-preview}

Lampirkan file PDF hingga 2 MB di samping gambar, dengan `AI_PDF_MODEL` opsional untuk model yang dapat membacanya. Asisten membaca halaman web melalui proxy URL tertaut dan mengetahui tanggal hari ini saat mencari di web. Chat panjang diringkas dan output alat lama dipadatkan, sehingga chat dapat terus berjalan tanpa memenuhi konteks model.

Lihat [Asisten AI](/on-premises/user-guide/users/ai-assistant  "mention").

#### Fitur 06: Pendaftaran dan Login (Pratinjau) {#feature-06-sign-up-and-login-preview}

Atur `RECAPTCHA_SITE_KEY` dan `RECAPTCHA_SECRET_KEY` untuk melindungi login, login LDAP, pendaftaran, dan reset kata sandi dengan reCAPTCHA v2. `OVERLEAF_ALLOW_PUBLIC_REGISTRATION` kini menerima daftar domain email, seperti `@example.edu,@*.example.org`, atau `@*` untuk domain apa pun. Halaman login dan pendaftaran menampilkan formulirnya di dalam kartu.

Lihat [reCAPTCHA](/id/on-premises/configuration/overleaf-toolkit/authentication/recaptcha  "mention") dan [Akses Publik](/id/on-premises/configuration/overleaf-toolkit/authentication/public-access  "mention").

#### Perbaikan bug {#bug-fixes}

* **Panel admin**: admin yang telah dihapus tetap disebutkan dengan emailnya di log audit dan sebagai "Deleted by", dan ditampilkan sebagai "Deleted user" setelah dihapus permanen. Permintaan langsung untuk menonaktifkan, menghapus, atau menurunkan peran akun sendiri ditolak.
* **Asisten AI**: tanpa `AI_PDF_MODEL`, chat dengan file PDF dan gambar dikirim ke `AI_MODEL`, bukan ke model gambar yang mungkin tidak dapat membaca file PDF.
* **Galeri template**: suntingan hanya mengambil kolom formulir, dan kolom yang bukan teks dijawab dengan 400, bukan 500.
* **Git bridge**: perintah clone terpotong di tepi blok salinnya, bukan di tanda bacanya.

Lihat [catatan rilis 6.3.3](/id/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.3  "mention") untuk daftar lengkapnya.

#### Upgrade {#upgrade}

* Dari 6.3.2, 6.3.1, atau 6.3.0: tidak perlu migrasi. Tarik image baru dan mulai ulang.
* Dari 6.2.x atau sebelumnya dengan Zotero atau Mendeley yang digunakan: jalankan terlebih dahulu [migrasi Zotero / Mendeley](/id/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention") dari 6.3.0.
* Panel admin baru menggantikan yang lama. Beberapa email memerlukan pengiriman email; reCAPTCHA, daftar domain, dan `AI_API_MODE` hanya memerlukan variabel lingkungan baru.
