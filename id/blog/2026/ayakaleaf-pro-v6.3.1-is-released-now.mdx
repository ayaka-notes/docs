Dengan sangat bangga kami mengumumkan rilis Overleaf Pro 6.3.1, editor LaTeX online paling andal dan kaya fitur di komunitas. Rilis patch biasanya berarti segelintir perbaikan kecil. Rilis ini melangkah jauh lebih jauh: selain puluhan perbaikan bug, rilis ini menghadirkan lima fitur baru, dan menghubungkan proyek Anda dengan tempat-tempat yang sudah Anda gunakan untuk bekerja, mulai dari Dropbox dan GitLab hingga agen AI di terminal Anda.

### Perubahan

* Sinkronisasi Dropbox (pratinjau awal): jaga setiap proyek tetap sinkron dengan Dropbox Anda sendiri, dalam dua arah.
* Sinkronisasi GitLab (pratinjau awal): sinkronisasi dua arah dengan GitLab.com atau GitLab self-managed Anda.
* MCP Server: biarkan Claude Code, Codex, Cursor, VS Code, atau Gemini CLI bekerja langsung pada sebuah proyek.
* GitHub Enterprise: arahkan Sinkronisasi GitHub ke instance GitHub Enterprise Anda sendiri.
* Pengenalan Simbol Tulisan Tangan: gambar sebuah simbol, dapatkan perintah LaTeX-nya.
* `OVERLEAF_DISABLE_LOCAL_LOGIN`: sembunyikan login dengan email dan kata sandi sehingga pengguna hanya masuk dengan SSO.
* Perbaikan bug yang ditemukan oleh sistem pengujian E2E kami dan Internal Horizon Issue Investigation.
* Patch upstream Overleaf 6.3.1.

<Info>

Sinkronisasi Dropbox dan Sinkronisasi GitLab disertakan di 6.3.1 sebagai **pratinjau awal** untuk pengujian bertahap, dan akan dirilis secara resmi di v6.4.0. Konfigurasi dan perilakunya masih dapat berubah sebelum itu. Keduanya nonaktif secara default. Silakan laporkan masalah apa pun di [GitHub](https://github.com/ayaka-notes/ayakaleaf-pro/issues).

</Info>

#### Fitur 01: Sinkronisasi Dropbox (Pratinjau)

Sebagian orang tidak pernah ingin memikirkan Git. Mereka hanya ingin tesis mereka berupa folder di laptop, dan Sinkronisasi Dropbox memberikan persis hal itu. Setiap pengguna menautkan akun Dropbox mereka sendiri, dan proyek yang mereka miliki maupun yang dibagikan kepada mereka muncul di bawah `Apps/<your app name>/`. Sunting di Overleaf, dan perubahannya muncul di Dropbox. Sunting file secara lokal di editor favorit Anda, simpan, dan perubahannya kembali ke Overleaf melalui webhook yang ditandatangani.

Untuk admin: Git bridge harus diaktifkan. Buat aplikasi di Dropbox App Console, lalu atur `DROPBOX_ENABLED`, `DROPBOX_APP_KEY`, `DROPBOX_APP_SECRET`, `DROPBOX_APP_NAME`, dan `DROPBOX_TOKEN_CIPHER_PASSWORD`. `DROPBOX_SYNC_PROXY_URL` bersifat opsional, untuk server yang tidak dapat menjangkau Dropbox secara langsung. Kemudian buat indeks MongoDB yang dibutuhkan Sinkronisasi Dropbox, sekali saja, sebelum pengguna menautkan akun mereka.

Lihat [Sinkronisasi Dropbox](/id/on-premises/configuration/overleaf-toolkit/dropbox-synchronisation  "mention") untuk petunjuk penyiapan lengkap.

#### Fitur 02: Sinkronisasi GitLab (Pratinjau)

Sinkronisasi GitHub telah menjadi salah satu fitur yang paling disukai sejak 6.2, dan banyak universitas serta perusahaan menyimpan kode mereka di GitLab. Sinkronisasi GitLab bekerja dengan cara yang sama: tautkan akun Anda, impor repositori dari menu proyek baru, atau ekspor proyek ke proyek GitLab baru. Lalu lakukan push dan pull dari editor, dan merge melalui merge request.

Fitur ini berfungsi dengan GitLab.com dan GitLab self-managed 15.10 atau yang lebih baru. Atur `GITLAB_SYNC_ENABLED`, `GITLAB_SYNC_CLIENT_ID`, `GITLAB_SYNC_CLIENT_SECRET`, dan `GITLAB_TOKEN_CIPHER_PASSWORD`, serta `GITLAB_SYNC_URL` untuk instance self-managed.

Lihat [Sinkronisasi GitLab](/id/on-premises/configuration/overleaf-toolkit/gitlab-synchronisation  "mention") untuk petunjuk penyiapan lengkap.

#### Fitur 03: MCP Server

Di 6.3 kami menempatkan asisten AI di dalam editor. Di 6.3.1 kami membuka pintu ke arah sebaliknya: setiap proyek kini memiliki MCP server sendiri, sehingga agen AI yang sudah Anda gunakan dapat bekerja langsung pada makalah Anda. Minta Claude Code memperbaiki salah ketik di pendahuluan, minta Codex mengompilasi dan memperbaiki error LaTeX, atau minta Cursor menjawab komentar tinjauan yang masih terbuka. Agen membaca dan menyunting file secara langsung, sehingga Anda dan kolaborator melihat suntingannya muncul di editor saat ia mengetik. Agen juga dapat mengompilasi, membaca log, mengambil PDF, menghitung kata, dan menampilkan daftar versi.

Endpoint-nya adalah `/project/<project_id>/mcp`. Lakukan autentikasi dengan token Git yang sama yang Anda gunakan untuk `git clone`. Akses mengikuti pengaturan berbagi proyek, sehingga agen milik viewer dapat membaca tetapi tidak dapat menyunting, dan setiap tool dibatasi lajunya (rate limit). Tidak ada hal lain yang perlu dikonfigurasi: MCP server diaktifkan bersama dengan Git bridge.

Lihat [MCP Server](/id/on-premises/configuration/overleaf-toolkit/mcp-server  "mention") untuk cara menghubungkan setiap klien AI.

#### Fitur 04: GitHub Enterprise

Sinkronisasi GitHub tidak lagi terbatas pada github.com. Atur `GITHUB_SYNC_URL` ke GitHub Enterprise Server Anda, atau ke GitHub Enterprise Cloud dengan data residency (`GHE.com`), dan endpoint REST serta GraphQL akan diturunkan darinya. Jika instance Anda memiliki konfigurasi yang tidak biasa, timpa endpoint tersebut dengan `GITHUB_SYNC_API_URL` dan `GITHUB_SYNC_GRAPHQL_URL`. Biarkan tidak diatur, dan semuanya tetap menggunakan github.com.

Lihat [Sinkronisasi GitHub](/id/on-premises/configuration/overleaf-toolkit/github-synchronisation#github-enterprise  "mention") untuk detailnya.

#### Fitur 05: Pengenalan Simbol Tulisan Tangan

Anda tahu seperti apa bentuk simbolnya, tetapi tidak tahu namanya. Apakah itu `\varsigma` atau `\zeta`? `\models` atau `\vDash`? Alihkan palet simbol ke mode gambar, sketsakan simbol dengan mouse atau trackpad Anda, dan palet akan menyarankan perintah LaTeX yang cocok.

Pengenalan berjalan sepenuhnya di browser, dengan model yang dilatih oleh ayaka-notes, sehingga apa pun yang Anda gambar tidak meninggalkan perangkat Anda. Tombol mode gambar disembunyikan pada browser tanpa `OffscreenCanvas` (misalnya Safari 15).

#### Perbaikan bug

Rilis ini juga membawa daftar panjang perbaikan. Banyak di antaranya ditemukan oleh sistem pengujian E2E baru kami, yang kini menjalankan rangkaian pengujian untuk setiap modul setiap hari, dan oleh Internal Horizon Issue Investigation: setiap kali kami memperbaiki bug, kami menyisir seluruh basis kode untuk mencari bug serupa sebelum menutupnya.

* **Autentikasi**: akun lokal dapat mengatur dan mengubah kata sandinya pada instance SSO, dan pengguna OIDC tidak lagi dapat mengubah email mereka sendiri. Login LDAP, SAML, dan OIDC tidak lagi gagal ketika atribut nama memiliki beberapa nilai, dan logout SAML/OIDC berfungsi kembali.
* **Pengguna yang ditangguhkan**: menangguhkan pengguna kini mengakhiri sesi mereka dan menutup editor yang sedang mereka buka, serta token Git dan unduhan MCP mereka ditolak.
* **Sinkronisasi GitHub**: hanya pemilik yang dapat mengekspor proyek, suntingan yang dibuat saat pull tetap tertunda, file kosong disinkronkan, dan merge manual diverifikasi di GitHub.
* **Zotero / Mendeley**: Anda mendapatkan pesan untuk menautkan ulang ketika kredensial Anda berhenti berfungsi, dan referensi diindeks ulang setelah impor.
* **Layanan eksternal**: permintaan ke Zotero, Mendeley, GitHub, GitLab, dan pencarian web mendapatkan batas waktu koneksi 3 detik alih-alih 1 detik, sehingga jaringan yang lebih lambat tidak lagi gagal.
* **Tracked changes**: data tinjauan mencakup dokumen yang belum dimuat dan perubahan yang belum disimpan.
* **Panel admin**: memulihkan proyek yang terhapus, mengganti pemilik, dan mengedit pengguna berfungsi dengan benar, dan email yang gagal tidak lagi merusak pembuatan atau penghapusan akun.
* **Galeri templat**: pengurutan yang tidak valid mengembalikan 400 alih-alih 500, dan memublikasikan proyek tanpa file utama akan meminta file utama.

Lihat [catatan rilis 6.3.1](/id/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.1  "mention") untuk daftar lengkapnya.

#### Upgrade

* Dari 6.3.0: tidak diperlukan migrasi. Tarik image baru lalu mulai ulang.
* Dari 6.2.x atau sebelumnya dengan Zotero atau Mendeley yang digunakan: jalankan terlebih dahulu [migrasi Zotero / Mendeley](/id/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention") dari 6.3.0.
* Sinkronisasi Dropbox dan Sinkronisasi GitLab nonaktif secara default. Sinkronisasi GitLab hanya memerlukan variabel lingkungan baru. Sinkronisasi Dropbox juga memerlukan pembuatan indeks MongoDB-nya sekali, sebelum pengguna menautkan akun mereka: lihat [Membuat indeks database](/id/on-premises/configuration/overleaf-toolkit/dropbox-synchronisation#create-the-database-indexes  "mention").
