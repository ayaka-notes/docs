<Warning>

**Diperbarui 3 Oktober 2026:** Versi 6.3.0 telah dirilis ulang untuk mengatasi masalah integrasi AI Assistant, Zotero, dan Mendeley. Tarik image `6.3.0` terbaru saat melakukan upgrade. Instalasi yang sudah ada dengan file bibliografi tertaut Zotero atau Mendeley juga harus mengikuti [instruksi migrasi](/id/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention"). Instalasi baru tidak memerlukan migrasi ini.

</Warning>

Dengan sangat bangga kami mengumumkan rilis Overleaf Pro 6.3.0, editor LaTeX online paling andal dan kaya fitur di komunitas. Karena kami selalu berfokus pada peningkatan pengalaman pengguna, rilis ini membawa perubahan besar dan fitur-fitur luar biasa yang pasti akan Anda sukai, termasuk asisten AI dan integrasi referensi pihak ketiga.

### Perubahan

* AI Chat Assistant: Mengobrol dengan model AI melalui penyedia Anda sendiri, langsung di editor Anda.
* LaTeX Error Assistant: Dapatkan saran perbaikan dari AI untuk error kompilasi LaTeX.
* Integrasi Mendeley: Impor referensi dari Mendeley, serupa dengan Zotero.
* Open in Overleaf API: Menambahkan API untuk membuka konten di Overleaf.
* Galeri Templat: Menambahkan paginasi, pencarian, dan pengurutan di sisi server, sehingga galeri besar tidak lagi perlu memuat setiap templat di browser.
* Terjemahan: Memperbarui patch terjemahan untuk 6.3.0, termasuk teks antarmuka baru di seluruh bahasa yang didukung.
* Upstream Overleaf 6.3.0: Mencakup penyuntingan file dengan tab, logo header terpisah untuk tema terang dan gelap, serta pembaruan dependensi dan image dasar.
* Menambahkan `OVERLEAF_HEADER_IMAGE_URL_LIGHT` dan `OVERLEAF_HEADER_IMAGE_URL_DARK` untuk mendukung gambar logo header terpisah untuk tema terang dan gelap.
* File kini dapat dibuka di tab yang berbeda di editor.
* Pengambilan URL eksternal dan Open in Overleaf API kini mendukung proxy HTTP(S) melalui `OVERLEAF_LINKED_URL_OUTBOUND_PROXY`. Lihat [Outbound Proxy](/id/on-premises/configuration/overleaf-toolkit/external-url#outbound-proxy  "mention") untuk konfigurasinya.

#### Fitur 01: AI Assistant kini tersedia

AI Assistant berada di panel samping editor dan berkomunikasi dengan penyedia model yang Anda konfigurasikan. Tanyakan hal-hal yang biasa Anda tanyakan kepada rekan kerja: rapikan paragraf ini, apa fungsi makro ini, mengapa tabel saya tidak sejajar. Ia tidak menjawab secara membabi buta. Ia dapat membaca dan mencari file di proyek Anda, memeriksa diagnostik LaTeX, mengompilasi proyek, bahkan melihat halaman PDF yang telah dirender, sehingga jawabannya berasal dari dokumen Anda yang sebenarnya.

Ketika ingin mengubah sesuatu, ia menampilkan diff terlebih dahulu. Tidak ada yang ditulis sampai Anda menyetujuinya, sehingga makalah Anda tetap sepenuhnya milik Anda.

<img src="https://github.com/user-attachments/assets/ea4e0dad-3561-4726-b380-5d9dcfe29693" alt="Demo AI Chat dan Error Assistant" width="787" />

LaTeX Error Assistant hadir untuk momen larut malam yang sudah tidak asing lagi: error merah di log dan Anda tidak tahu apa artinya. Klik Suggest fix di samping error tersebut, lalu asisten akan membaca file penyebabnya dan mengusulkan perubahan sekecil mungkin yang seharusnya memperbaikinya, tanpa mengusik format lainnya. Jika terlihat benar, terapkan dengan satu klik dan kompilasi lagi. Jika perbaikan menyentuh paket, perintah, atau struktur dokumen, periksa sekilas terlebih dahulu.

<img src="https://github.com/user-attachments/assets/91b2aefb-c1e4-4e4a-a94d-9824865cdf29" alt="Contoh Penggunaan Error Assistant" width="787" />

Fitur AI dinonaktifkan secara default. Ayakaleaf Pro bekerja dengan endpoint apa pun yang kompatibel dengan OpenAI, baik itu OpenAI sendiri, gateway perusahaan Anda, maupun model yang Anda host sendiri.

Lihat [Integrasi AI](/id/on-premises/configuration/overleaf-toolkit/ai-integration  "mention") untuk konfigurasi penyedia, izin, kuota, dan layanan pencarian opsional.

#### Fitur 02: Open in Overleaf API

Jika Anda mengelola halaman kursus, pustaka templat, atau situs dokumentasi, kini Anda dapat memberi pembaca sebuah tombol yang langsung membawa mereka ke proyek yang siap digunakan. Fitur ini diaktifkan secara default. Kunjungi `your.overleaf.com/devs` untuk referensi lengkap dan contoh langsung.

<Frame>
  <img src="/images/blog/img-2fac54e7.png" alt="" />
</Frame>

Cukup sebuah tautan atau formulir kecil. Anda dapat mengirim cuplikan LaTeX (`snip` atau `encoded_snip`), dan fragmen tunggal akan dibungkus dalam dokumen minimal untuk Anda. Anda dapat menunjuk ke satu atau beberapa file jarak jauh dengan `snip_uri` (hingga 50 sekaligus), atau menyerahkan seluruh proyek sebagai ZIP dengan `zip_uri`. Parameter opsional menetapkan compiler (`engine`), dokumen utama (`main_document`), dan nama proyek (`name`). Konten tersebut terbuka sebagai proyek baru di instance Anda, siap untuk disunting dan dikompilasi. Jika pengunjung belum masuk, mereka akan login terlebih dahulu dan tetap diarahkan ke proyek baru mereka.

```html wrap
<a href="https://your.overleaf.com/docs?snip_uri=https://example.com/paper.tex&engine=xelatex">
  Open in Overleaf
</a>
```

#### Fitur 03: Integrasi Mendeley

Di versi 6.2 kami menambahkan Zotero, dan sejak itu pengguna Mendeley terus meminta hal yang sama. Tautkan akun Mendeley Anda, pilih pustaka atau grup, dan referensi Anda akan masuk sebagai file `.bib` yang dapat Anda segarkan kapan pun pustaka Anda berubah. Sama seperti di overleaf.com, dalam proyek bersama hanya orang yang mengimpor file tersebut yang dapat menyegarkannya.

Untuk admin: tambahkan `mendeley` ke `ENABLED_LINKED_FILE_TYPES` dan atur `MENDELEY_CLIENT_ID` serta `MENDELEY_CLIENT_SECRET` dari aplikasi pengembang Mendeley Anda.

Lihat [Integrasi Mendeley](/id/on-premises/configuration/overleaf-toolkit/mendeley-integration  "mention") untuk instruksi penyiapan lengkap.

#### Fitur 04: Paginasi Templat

Sebelumnya galeri memuat setiap templat ke browser dan mengurutkannya di sana. Tidak masalah untuk lima puluh templat, tetapi menyiksa untuk lima ribu. Kini paginasi, pencarian, dan pengurutan semuanya terjadi di MongoDB, dan browser hanya menerima halaman yang sedang Anda lihat.

Fitur ini berfungsi tanpa persiapan apa pun. Jika galeri Anda memiliki ribuan templat, indeks-indeks berikut akan menjaganya tetap cepat. Skrip ini aman dijalankan lebih dari sekali; ganti `mongo` dan `sharelatex` dengan nama container dan database Anda:

```bash
docker exec mongo mongosh sharelatex --quiet --eval '
db.templates.createIndex({category:1,lastUpdated:-1},{name:"category_1_lastUpdated_-1",background:true});
db.templates.createIndex({lastUpdated:-1},{name:"lastUpdated_-1",background:true});
db.templates.createIndex({category:1,name:1},{name:"category_1_name_1_ci",collation:{locale:"en",strength:2},background:true});
db.templates.createIndex({name:1},{name:"name_1_ci",collation:{locale:"en",strength:2},background:true});
'
```

Pertahankan `collation` pada kedua indeks `*_ci` persis seperti yang tertulis — galeri melakukan kueri dengan collation yang sama, dan MongoDB hanya menggunakan indeks yang cocok.

#### Lainnya

Untuk impor file eksternal, konfigurasikan `OVERLEAF_LINKED_URL_OUTBOUND_PROXY` agar menggunakan proxy HTTP(S), termasuk proxy yang di-host secara lokal. Pengaturan ini berlaku untuk file URL tertaut maupun sumber daya ZIP atau TeX jarak jauh yang diimpor melalui Open in Overleaf API. Lihat [URL Eksternal — Outbound Proxy](/id/on-premises/configuration/overleaf-toolkit/external-url#outbound-proxy  "mention") untuk penyiapan dan pembatasan akses jaringan.

* Menambahkan `OVERLEAF_HEADER_IMAGE_URL_LIGHT` dan `OVERLEAF_HEADER_IMAGE_URL_DARK` untuk mendukung gambar logo header terpisah untuk tema terang dan gelap.
* File kini dapat dibuka di tab yang berbeda di editor.
