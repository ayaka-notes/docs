Dengan bangga kami mengumumkan rilis Ayakaleaf Pro 6.2, editor LaTeX online paling andal dan kaya fitur di komunitas. Terima kasih khusus kepada yu-i-i dan davrot atas kontribusi berharga mereka. Mereka menyempurnakan GitHub Sync serta memperkenalkan Advanced Citation Search dan integrasi Zotero.

### Catatan

* Variabel lingkungan wajib baru `OVERLEAF_INVITE_TOKEN_SECRET` telah diperkenalkan; Anda harus membuatnya dengan: `openssl rand -base64 32` Jika variabel ini tidak dikonfigurasi, instance Overleaf Anda akan gagal dijalankan.
* Jika Anda mengaktifkan GitHub Sync, Anda harus mengonfigurasi variabel lingkungan `GITHUB_TOKEN_CIPHER_PASSWORD`. Variabel ini diperlukan untuk mengenkripsi token akses GitHub secara aman. Tanpanya, instance Overleaf Anda akan gagal dijalankan.
* Menambahkan variabel lingkungan baru `DEFAULT_LATEX_COMPILER` untuk menetapkan compiler default yang digunakan oleh proyek baru (pdflatex, latex, xelatex, atau lualatex).
* Editor yang didesain ulang kini menjadi satu-satunya opsi yang tersedia.

### Perubahan

Rilis ini mencakup peningkatan dan fitur baru berikut.

* `MAX_UPLOAD_SIZE` kini dapat dikonfigurasi alih-alih dibatasi hingga **50 MB**.
* Memperbaiki loop restart container ketika kompilasi sandbox dinonaktifkan.
* Menerapkan penghapusan PAT yang dibatasi pada pemiliknya untuk OAuth2.
* Memperbaiki masalah impor LDAP.

Fitur-fitur mencakup:

* Menambahkan Python runner berbasis browser.
* Menambahkan dukungan Pandoc untuk mengimpor dan mengekspor Markdown, DOCX, dan format lainnya.
* Menambahkan GitHub Sync.
* Menambahkan terjemahan bahasa Tionghoa yang lengkap.
* Menambahkan integrasi Zotero.
* Menambahkan `DEFAULT_LATEX_COMPILER`.

#### Fitur01: GitHub Sync

Jaga agar proyek LaTeX Anda tetap tersinkronisasi dengan repositori GitHub untuk alur kerja pengembangan yang mulus. Push dan pull perubahan langsung dari editor, berkolaborasi melalui pull request, dan integrasikan dengan pipeline CI/CD yang sudah ada. Kontrol versi memudahkan pelacakan revisi, peninjauan perubahan, dan pemeliharaan dokumen akademis atau teknis yang dapat direproduksi.

Lihat: [Sinkronisasi GitHub](/id/on-premises/configuration/overleaf-toolkit/github-synchronisation  "mention").

#### Fitur02: Impor/Ekspor Pandoc

Impor dokumen Microsoft Word dan Markdown menjadi proyek LaTeX yang sepenuhnya dapat diedit, atau ekspor proyek LaTeX kembali ke Markdown dan DOCX dengan satu klik. Didukung oleh Pandoc, fitur ini memungkinkan interoperabilitas yang mulus antara penulisan akademis, penyuntingan kolaboratif, dan alur kerja penerbitan sambil mempertahankan struktur dokumen sebisa mungkin.

Lihat: [Impor dan Ekspor Pandoc](/id/on-premises/configuration/overleaf-toolkit/pandoc-import-and-export  "mention").

#### Fitur03: Pencarian Referensi Lanjutan

Cari dan sisipkan referensi bibliografi dari berbagai basis data akademis dengan pemfilteran cerdas dan dukungan sitasi instan. Temukan makalah dengan cepat, pratinjau metadata, dan buat entri BibTeX yang akurat tanpa berpindah-pindah antar situs web riset, sehingga efisiensi tinjauan pustaka meningkat secara signifikan.

![image](https://github.com/user-attachments/assets/42e45b73-af4b-4d1f-81f4-9e116ba5d043)

#### Fitur04: Python Runner

Jalankan kode Python langsung di dalam proyek Anda tanpa meninggalkan editor. Sangat cocok untuk membuat gambar, memproses dataset, mengotomatiskan alur kerja dokumen, atau menjalankan skrip riset yang dapat direproduksi. Hasilnya dapat diintegrasikan ke dalam dokumen LaTeX Anda, menjadikan komputasi ilmiah dan penulisan bagian dari satu alur kerja terpadu.

![image](https://github.com/user-attachments/assets/a4c314b3-fdb5-4836-aea7-12eeece5cd2f)

#### Fitur05: Zotero

Hubungkan pustaka Zotero Anda langsung ke alur kerja penulisan dan kelola referensi tanpa meninggalkan editor. Cari koleksi Zotero pribadi Anda, sisipkan sitasi dengan satu klik, serta buat dan sinkronkan entri BibTeX secara otomatis. Integrasi ini menjaga daftar pustaka Anda tetap mutakhir, sehingga pengelolaan literatur untuk makalah akademis, tesis, dan dokumen teknis menjadi lebih efisien.

Lihat: [Integrasi Zotero](/id/on-premises/configuration/overleaf-toolkit/zotero-integration  "mention").
