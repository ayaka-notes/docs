---
title: Mengekspor proyek
icon: file-export
---

Di Server Pro dan Community Edition `5.4.0`, kami telah menyertakan skrip yang memungkinkan Administrator mengekspor semua proyek pengguna (termasuk yang masih terlihat di folder **Deleted** dan **Trashed**) ke sebuah direktori di disk.

<Info>

Hasil dari menjalankan skrip ini sama dengan mengunduh Zip semua proyek secara manual dari dasbor proyek pengguna. Skrip ini akan menyimpan (flush) setiap perubahan yang tertunda sebelum memulai unduhan untuk memastikan bahwa hasil ekspor berisi versi terbaru dari proyek.

</Info>

### Keterbatasan

Skrip ekspor memiliki keterbatasan berikut:

* Pengaturan proyek, seperti nama image TeX Live atau compiler, tidak diekspor. Pengaturan ini harus diatur ketika proyek diunggah ke akun pengguna.
* Proyek yang diekspor tidak berisi riwayat versi apa pun.
* Informasi kolaborator tidak dipertahankan. Proyek perlu dibagikan ulang. Jika menggunakan berbagi tautan, tautan View dan Edit akan dibuat ulang (tidak akan sama seperti sebelumnya).
* Komentar dan informasi perubahan yang dilacak (tracked changes) tidak akan diekspor.
* Riwayat obrolan proyek tidak akan diekspor.

<Danger>

Skrip ini **tidak** dirancang untuk menggantikan pencadangan sistem secara penuh. Untuk memastikan Anda dapat memulihkan instance Anda dalam skenario pemulihan bencana, kami **sangat** menyarankan untuk membuat [cadangan yang konsisten](https://docs.overleaf.com/on-premises/maintenance/#performing-a-consistent-backup).

</Danger>

### **Flag**

| Nama           | Deskripsi                                                                       |
| -------------- | ------------------------------------------------------------------------------- |
| `--help`       | Menampilkan bantuan                                                             |
| `--user-id`    | ID pengguna (wajib kecuali menggunakan `--export-all` atau `--project-id`)      |
| `--project-id` | Mengekspor satu proyek (**tidak dapat** digunakan bersama `--user-id` atau `--export-all`) |
| `--list`       | Menampilkan daftar proyek pengguna (**tidak dapat** digunakan bersama `--output`) |
| `--output`     | File zip keluaran (untuk operasi ekspor tunggal)                                |
| `--export-all` | Mengekspor proyek semua pengguna (memerlukan `--output-dir`)                    |
| `--output-dir` | Direktori untuk menyimpan file ekspor semua pengguna                            |
| `--log-level`  | Level log yang didukung: `trace`\|`debug`\|`info`\|`warn`\|`error`\|`fatal`     |

### **Penggunaan**

Gunakan perintah berikut untuk mengekspor proyek semua pengguna:

```bash wrap
# Overleaf Toolkit users
$ bin/docker-compose exec sharelatex /bin/bash -ce "cd /overleaf/services/web && node modules/server-ce-scripts/scripts/export-user-projects.mjs --export-all --output-dir=/var/lib/overleaf/data/exports"

# Legacy docker-compose.yml users
docker exec sharelatex /bin/bash -ce "cd /overleaf/services/web && node modules/server-ce-scripts/scripts/export-user-projects.mjs --export-all --output-dir=/var/lib/overleaf/data/exports"
```

<Info>

Jika Anda menjalankan Server Pro atau Community Edition &lt;= 3.5.13, Anda perlu memperbarui contoh di atas agar menggunakan skrip **`export-legacy-user-projects.js`**.

</Info>

### **Penyelesaian**

Setelah ekspor selesai, Anda dapat mengakses file-file tersebut melalui direktori pada host yang di-bind-mount ke <strong>/var/lib/overleaf</strong> di file **docker-compose.yml** Anda, atau melalui variabel lingkungan `OVERLEAF_DATA_PATH` di file **config/overleaf.rc** jika Anda menggunakan Toolkit.

<Info>

Overleaf saat ini mengizinkan nama proyek yang duplikat. Jika proyek pengguna memiliki duplikat, proyek-proyek tersebut tetap akan ditambahkan ke ekspor Zip pengguna, tetapi saat diekstrak, hanya satu versi yang akan ada. Di Linux, `unzip -B` akan menulis file dengan nama yang sama sebagai file cadangan alih-alih menimpanya.

</Info>
