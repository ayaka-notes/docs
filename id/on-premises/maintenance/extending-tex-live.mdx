Anda dapat memperluas image TeX Live yang sudah ada menggunakan Dockerfile baru dan mengonfigurasi aplikasi untuk menggunakan image baru tersebut.

Di sini kami memberikan beberapa panduan untuk menginstal paket atau font baru, tetapi konfigurasi image kustom tidak tercakup dalam ketentuan dukungan kami.

Image TeX Live jarang menerima pembaruan. Kami menyarankan untuk membangun ulang image kustom saat melakukan upgrade Server Pro.

<Danger>

Bagian-bagian berikut hanya berlaku untuk Server Pro dan [Sandboxed Compiles](/id/on-premises/configuration/overleaf-toolkit/sandboxed-compiles).

</Danger>

### Menginstal dan memperbarui paket baru

Anda dapat menggunakan perintah `tlmgr` seperti `tlmgr install` dan `tlmgr update` untuk mengelola paket Tex Live seperti pada contoh berikut:

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2023.1

RUN tlmgr update --force ebproof
```

### Menggunakan `tlmgr` pada image TeX Live yang lebih lama

Secara default, `tlmgr` mengunduh sumber daya dari rilis TeX Live terbaru. Saat menambal image TeX Live yang lebih lama, unduhan perlu dialihkan ke arsip yang sesuai. Lihat daftar di [https://www.tug.org/historic/](https://www.tug.org/historic/) untuk mirror arsip.

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2022.1

RUN tlmgr option repository <MIRROR>/systems/texlive/<YEAR>/tlnet-final
# e.g. RUN tlmgr option repository ftp://tug.org/historic/systems/texlive/2022/tlnet-final

RUN tlmgr update --force ebproof
```

### Menginstal font baru

Ada berbagai prosedur untuk menginstal font baru dalam distribusi Tex Live, dan menginstal font kustom mungkin memerlukan beberapa langkah. Memeriksa [instruksi untuk menginstal font TeX](https://tug.org/fonts/fontinstall.html) dalam dokumentasi resmi Tex Live mungkin merupakan titik awal yang baik.

`Dockerfile` berikut menunjukkan contoh menginstal font TrueType di atas image Tex Live 2022 yang sudah ada:

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2022.1

COPY ./myfonts/*.ttf /usr/share/fonts/truetype/myfont/

# rebuild font information cache
RUN fc-cache
```

### Mengonfigurasi Server Pro untuk menggunakan image baru

Gunakan nama `ghcr.io/ayaka-notes/texlive-full` dan tag kustom untuk membangun image baru, seperti:

```bash
docker build -t ghcr.io/ayaka-notes/texlive-full:2023.1-custom
```

Sekarang kita dapat mengonfigurasi Server Pro untuk menggunakan image `2023.1-custom` yang baru dengan memperbarui variabel lingkungan `TEX_LIVE_DOCKER_IMAGE` dan `ALL_TEX_LIVE_DOCKER_IMAGES`:

```text wrap
TEX_LIVE_DOCKER_IMAGE: "ghcr.io/ayaka-notes/texlive-full:2023.1-custom"
ALL_TEX_LIVE_DOCKER_IMAGES: "ghcr.io/ayaka-notes/texlive-full:2023.1,ghcr.io/ayaka-notes/texlive-full:2023.1-custom"
```

Pada contoh di atas, proyek baru diatur secara default untuk menggunakan image `2023.1-custom` yang baru, sementara `2023.1` tetap tersedia saat dibutuhkan.
