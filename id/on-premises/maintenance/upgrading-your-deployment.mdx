<Danger>

Penting untuk memastikan Anda membuat [backup yang konsisten](/id/on-premises/maintenance/data-and-backups#performing-a-consistent-backup) **sebelum** setiap upgrade versi mayor agar Anda dapat melakukan rollback jika diperlukan.

</Danger>

[ayakaleaf toolkit↗](https://github.com/ayaka-notes/toolkit) adalah repositori git, sehingga mudah untuk mendapatkan fitur Toolkit yang baru. Cukup jalankan perintah `bin/upgrade` dan ikuti petunjuk di layar.

Perlu dicatat bahwa versi image Docker (di `config/version`) dikelola secara terpisah dari pembaruan kode Toolkit. Memperbarui kode Toolkit **tidak** akan secara otomatis mengubah versi image Docker yang Anda jalankan. Artinya, dalam sebagian besar kasus, Anda dapat meng-upgrade versi Toolkit tanpa meng-upgrade deployment Anda.

#### Skrip `bin/upgrade`

Saat Anda menjalankan perintah `bin/upgrade`, skrip akan memeriksa apakah ada pembaruan yang tersedia untuk kode Toolkit, lalu menawarkan untuk memperbarui Toolkit Anda. Anda selalu dapat menolak upgrade ini, dan tidak ada yang akan berubah.

Jika Anda memilih untuk memperbarui kode Toolkit, skrip kemudian akan memeriksa apakah versi image Docker _default_ telah berubah, lalu menawarkan untuk meng-upgrade file versi lokal Anda (di `config/version`) agar sesuai dengan default yang baru.

Jika Anda memilih untuk beralih versi, skrip kemudian akan memandu Anda melalui proses mematikan layanan Docker, membuat backup, dan memulai ulang layanan Docker. File versi lama Anda akan disalin secara otomatis ke `config/__old-version`, untuk berjaga-jaga jika Anda perlu melakukan rollback ke versi image Docker tersebut.

<Info>

Untuk lingkungan air-gapped yang mengimpor image Docker secara manual, harap atur `PULL_BEFORE_UPGRADE=false` di file `config/overleaf.rc` Anda.

Silakan lihat [di sini](/id/on-premises/installation/air-gapped-offline-deployments) untuk informasi lebih lanjut tentang deployment di lingkungan air-gapped/offline.

</Info>

### Jalur upgrade

Jika Anda menjalankan Overleaf Community versi lama sebelum v6.0.0, lihat [dokumentasi resmi Overleaf](https://docs.overleaf.com/on-premises/maintenance/upgrading-your-deployment#upgrade-path) untuk menyelesaikan upgrade.
