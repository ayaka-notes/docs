### Persyaratan untuk menginstal Server Pro dan Community Edition

<Warning>

Kami sangat menyarankan Anda menjalankan Server Pro pada versi Ubuntu yang terbaru dan stabil (misalnya Ubuntu 24.04 pada 2025–2026) dengan versi Docker yang terbaru. Menjalankan Server Pro pada sistem lain dimungkinkan, tetapi akan jauh lebih sulit bagi kami untuk memberikan dukungan untuk penyiapan Ubuntu/Docker yang tidak standar. Kami juga tidak dapat memberikan dukungan untuk masalah pada Docker itu sendiri.

</Warning>
