### Sistem operasi

Untuk pengalaman terbaik saat menjalankan Overleaf, kami sangat menyarankan penggunaan sistem operasi **berbasis Debian**, seperti **Ubuntu**. Pilihan ini selaras dengan lingkungan pengembangan perangkat lunak tersebut dan merupakan opsi yang paling banyak dipilih oleh pengguna Overleaf.

<Danger>

Saat menggunakan Server Pro dengan Sandboxed Compiles, **penting** untuk diperhatikan bahwa aplikasi memerlukan akses root ke socket Docker.

</Danger>

### Dependensi

* Docker 25.0 dan 29
* MongoDB 7.0 dan 8.0
* Redis 6.2 dan 7.5

<Info>

Anda dapat memantau tanggal End-of-Life (EOL) untuk dependensi di atas, serta produk populer lainnya, menggunakan layanan endoflife.date di sini: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

MongoDB dan Redis secara otomatis di-pull oleh `docker compose` saat menjalankan Server CE atau Server Pro, kecuali dikonfigurasi untuk menggunakan instalasi lain.

</Info>

Toolkit bergantung pada program-program berikut:

* bash
* Docker

`docker compose` diperlukan dan umumnya sudah terinstal bersama Docker.

Kami menyarankan Anda menginstal versi Docker terbaru yang tersedia untuk sistem operasi Anda.

Setelah Docker terinstal dengan benar, Anda seharusnya dapat menjalankan perintah-perintah ini tanpa error:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2)
docker compose version

# List the running Docker containers on your system
docker ps
```
