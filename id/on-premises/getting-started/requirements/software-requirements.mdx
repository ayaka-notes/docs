### Sistem operasi {#operating-systems}

Kami menyarankan sistem **Linux berbasis Debian**, seperti **Ubuntu**, untuk server bersama dan server produksi. Ayakaleaf Pro juga dapat berjalan di [macOS dengan Docker Desktop](/id/on-premises/installation/using-docker-compose/macos) dan [Windows dengan WSL 2 dan Docker Desktop](/id/on-premises/installation/using-docker-compose/windows). Ketiga platform menggunakan kontainer Linux dan Toolkit yang sama; ikuti panduan untuk sistem operasi host Anda.

<Danger>

Saat menggunakan Sandboxed Compiles, **penting** untuk diperhatikan bahwa aplikasi memerlukan akses root ke socket Docker.

</Danger>

### Dependensi {#dependencies}

* Docker 25.0 dan 29
* MongoDB 7.0 dan 8.0
* Redis 6.2 dan 7.5

<Info>

Anda dapat memantau tanggal End-of-Life (EOL) untuk dependensi di atas, serta produk populer lainnya, menggunakan layanan endoflife.date di sini: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

MongoDB dan Redis secara otomatis di-pull oleh `docker compose` saat menjalankan Ayakaleaf Pro, kecuali dikonfigurasi untuk menggunakan instalasi lain.

</Info>

Toolkit bergantung pada program-program berikut:

* bash
* Docker

`docker compose` diperlukan dan umumnya sudah terinstal bersama Docker.

Kami menyarankan Anda menginstal versi Docker terbaru yang tersedia untuk sistem operasi Anda.

Setelah Docker terinstal dengan benar, Anda seharusnya dapat menjalankan perintah-perintah ini tanpa error:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2 or later, such as v5)
docker compose version

# List the running Docker containers on your system
docker ps
```
