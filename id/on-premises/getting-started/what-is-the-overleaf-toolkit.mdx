---
title: Apa itu Ayakaleaf Toolkit?
icon: toolbox
---

Ayakaleaf toolkit adalah metode deployment yang direkomendasikan untuk instalasi on-premises Community Edition dan Ayakaleaf Pro. Toolkit ini dirancang untuk bekerja pada lingkungan yang paling umum: satu server fisik atau mesin virtual. Toolkit menggunakan `docker compose` untuk mengelola kontainer Docker di server Anda dan menyediakan serangkaian skrip yang membungkus perintah `docker` untuk membantu aspek teknis dalam mengelola versi on-premises Overleaf.

#### Wrapper `bin/docker-compose`

Skrip `bin/docker-compose` adalah wrapper untuk `docker compose`. Skrip ini memuat konfigurasi dari direktori `config/`, sebelum memanggil `docker compose` dengan argumen apa pun yang diberikan ke skrip tersebut.

Anda dapat memperlakukan `bin/docker-compose` sebagai wrapper transparan untuk program `docker compose` yang terinstal di mesin Anda.

Contoh:

```bash title="Check running containers"
$ bin/docker-compose ps
```

#### Skrip bantu praktis

Selain `bin/docker-compose`, Toolkit menyediakan skrip praktis untuk membantu tugas-tugas umum:

* `bin/up`: pintasan untuk `bin/docker-compose up`
* `bin/start`: pintasan untuk `bin/docker-compose start`
* `bin/stop`: pintasan untuk `bin/docker-compose stop`
* `bin/shell`: memulai shell di dalam kontainer **sharelatex**
* `bin/doctor`: skrip yang digunakan untuk mengumpulkan informasi instalasi dan deployment. Lihat bagian "Memeriksa server Anda" di bawah
* `bin/mongo`: memulai shell di dalam kontainer **mongo** dan beralih ke database yang benar (**sharelatex**)
* `bin/backup-config`: membuat salinan (zip atau tar) dari konfigurasi Anda saat ini dan menyimpannya di direktori tujuan pilihan Anda
* `bin/logs`: melihat/mengikuti (tail) log layanan
* `bin/error-logs`: melihat/mengikuti (tail) log error layanan
* `bin/rename-env-vars-5-0`: skrip migrasi untuk memperbarui variabel lingkungan di **config/variables.env** (perubahan merek dari ShareLaTeX ke Overleaf)
* `bin/rename-rc-vars`: skrip migrasi untuk memperbarui variabel lingkungan di **config/overleaf.rc** (perubahan merek dari ShareLaTeX ke Overleaf)
* `bin/run-script`: skrip bantu untuk menyederhanakan menjalankan skrip yang tersimpan di dalam kontainer **sharelatex**
* `bin/upgrade`: membantu peningkatan instance. Skrip ini akan memeriksa pembaruan Toolkit (melalui git) dan menawarkan untuk menarik perubahan, memeriksa versi image Docker terbaru dan menawarkan untuk memperbaruinya. Skrip ini menyediakan konfirmasi langkah demi langkah, opsi untuk mencadangkan konfigurasi saat ini, dan menangani penghentian/memulai layanan Docker. Lihat Upgrading your deployment untuk informasi lebih lanjut: https://docs.overleaf.com/on-premises/maintenance/upgrading-your-deployment

<Info>

Jika Anda lebih suka menjalankan instance tanpa menempel ke log Docker, Anda dapat menjalankan `bin/up -d` untuk berjalan dalam mode detached.

</Info>

#### Memeriksa server Anda

Overleaf Toolkit menyertakan skrip praktis bernama `bin/doctor` yang menghasilkan laporan yang menunjukkan dependensi apa pun yang belum terpenuhi.

Sebelum melanjutkan, jalankan skrip `bin/doctor` dan periksa apakah semuanya berfungsi dengan benar:

```bash title="Run Overleaf Doctor"
bin/doctor
```
