title: Batasan proyek
icon: list-check
---

| Fitur | Batas |
| ----- | ----- |
| Batas waktu kompilasi | <strong>Default:</strong> 180 detik. Lihat [Memperbarui batas waktu kompilasi proyek](/id/on-premises/user-and-project-management/project-management) untuk informasi lebih lanjut tentang cara menyesuaikan nilai ini. |
| Jumlah maksimum file per proyek | 2000 |
| Ukuran maksimum materi yang dapat diedit per proyek | <strong>Default:</strong> 7 MB. Lihat [Variabel lingkungan](/id/on-premises/configuration/overleaf-toolkit/environment-variables) untuk informasi lebih lanjut tentang cara menyesuaikan nilai ini. |
| Ukuran maksimum satu file teks yang dapat diedit | 2 MB\* |
| Ukuran maksimum satu unggahan | 50 MB (dapat dikonfigurasi melalui `MAX_UPLOAD_SIZE`) |
| Ukuran maksimum .zip yang diunggah setelah diekstrak | 6 × `MAX_UPLOAD_SIZE` (300 MB secara default) |
| Ukuran maksimum proyek | Tidak terbatas† |
| Jumlah maksimum proyek | Tidak terbatas |

\* Beberapa file yang lebih besar mungkin tetap dapat diedit dalam keadaan tertentu. Namun, untuk memastikan file tetap dapat diedit, Anda sebaiknya membatasi ukurannya hingga 2 MB atau kurang.

† Tidak ada batas yang diberlakukan untuk total ukuran proyek. Namun, Anda mungkin menemui beberapa keterbatasan teknis saat bekerja dengan proyek yang sangat besar. Kami menyarankan ukuran proyek maksimum 500 MB, atau kurang dari 100 MB jika menggunakan [integrasi Git](https://www.overleaf.com/learn/how-to/Git_integration) kami. Proyek yang melebihi ukuran ini mungkin tetap berfungsi, tetapi tetap berada dalam batas ini akan memberikan pengalaman terbaik.
