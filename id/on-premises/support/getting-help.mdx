### The Doctor

Overleaf Toolkit dilengkapi dengan skrip `doctor` yang praktis untuk membantu proses debugging. Jalankan `bin/doctor` dan skrip akan mencetak informasi tentang lingkungan host Anda, konfigurasi Anda, dan dependensi yang dibutuhkan Toolkit. Output ini juga dapat membantu kami mendiagnosis masalah pada instalasi Ayakaleaf Pro Anda.

<Info>

Pengguna Overleaf Pro dapat [membuka issue di GitHub](https://github.com/ayaka-notes/overleaf/issues).

Sebaiknya sertakan output dari skrip `bin/doctor` dalam pesan Anda.

</Info>


### Informasi Host

Bagian `Host Information` berisi informasi tentang mesin yang menjalankan Toolkit (misalnya, distribusi dan rilis Linux).

<Accordion title="Contoh output Host Information">

```text

    - Linux
    - Output of 'lsb_release -a':
            No LSB modules are available.
            Distributor ID:	Ubuntu
            Description:	Ubuntu 22.04.5 LTS
            Release:	22.04
            Codename:	jammy
```

</Accordion>

### Dependensi

Bagian `Dependencies` mencantumkan alat-alat yang dibutuhkan agar Toolkit dapat berfungsi. Jika sebuah alat tersedia, alat tersebut akan dicantumkan sebagai `status: present` beserta info versinya. Jika tidak ada, alat tersebut akan dicantumkan sebagai `status: MISSING!` dan sebuah peringatan akan ditambahkan di bagian bawah output `doctor`.

<Accordion title="Contoh output Dependency (tersedia)">

```text
- docker
    - status: present
    - version info: Docker version 28.0.4, build b8034c0
```

</Accordion>

<Accordion title="Contoh output Dependency (tidak ada)">

```text
- docker
    - status: MISSING!
```

</Accordion>

Jika ada dependensi yang tidak tersedia, Toolkit hampir pasti tidak akan berfungsi.

### Konfigurasi

Bagian `Configuration` berisi informasi tentang file-file di direktori `config/`. Untuk `config/overleaf.rc`, doctor mencetak beberapa nilai penting. File yang tidak ada akan dicantumkan sebagai `status: MISSING!` dan sebuah peringatan akan ditambahkan di bagian bawah output `doctor`.

<Accordion title="Contoh output Configuration">

```text
====== Configuration ======
- config/version
    - status: present
    - version: 5.4.0
- config/overleaf.rc
    - status: present
    - values
        - OVERLEAF_DATA_PATH: /tmp/overleaf
        - SERVER_PRO: false
        - MONGO_ENABLED: false
        - REDIS_ENABLED: true
- config/variables.env
    - status: MISSING!
```

</Accordion>

Catatan dari contoh di atas:

* `OVERLEAF_DATA_PATH` yang diatur ke `/tmp/overleaf` mungkin bukan lokasi yang aman untuk data penting.
* `MONGO_ENABLED: false` berarti Toolkit tidak akan menyediakan MongoDB sendiri; pastikan `MONGO_URL` mengarah ke MongoDB yang dikelola secara eksternal jika diperlukan.
* `config/variables.env` tidak ada dalam contoh tersebut.

### Peringatan

Bagian `Warnings` merangkum masalah yang ditemukan oleh skrip doctor. Jika tidak ada masalah, bagian ini akan menunjukkannya.

<Accordion title="Contoh output Warnings">

```text
====== Warnings ======
- configuration file variables.env not found
- rc file, OVERLEAF_DATA_PATH not set
====== End =======
```

</Accordion>
