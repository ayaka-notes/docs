### Akun

Dari sudut pandang pengelolaan akun masing-masing, **semua** pengguna diperlakukan sebagai pengguna biasa — `Site Admins` dan `Template Users` **tidak** mendapatkan izin tambahan apa pun. Namun, ada batasan terhadap tindakan yang dapat dilakukan pengguna biasa berdasarkan cara mereka melakukan autentikasi.

#### Pengaturan

<strong>Jenis autentikasi: Akun Internal | SSO (SAML/LDAP)</strong>

| Tindakan | Akun Internal | SSO (SAML/LDAP) |
| ----------------------------------------- | ----------------: | --------------: |
| Memperbarui info akun | Ya | Tidak |
| Mengubah kata sandi | Ya | Tidak |
| Membuat token autentikasi Git bridge | Ya | Ya |
| Menghapus token autentikasi Git bridge | Ya | Ya |
| Mengelola sesi | Ya | Ya |

<Info>

Integrasi Git Bridge **hanya** tersedia di Server Pro. Lihat [Server Pro vs. Community Edition](/id/on-premises/readme/ayakaleaf-pro-vs-server-pro) untuk informasi lebih lanjut.

</Info>

#### Sesi Anda

| Tindakan | Pengguna |
| -------------------- | ---: |
| Menghapus sesi | Ya |
| Melihat sesi saat ini | Ya |
| Melihat sesi lainnya | Ya |

### IDE Editor

Dari sudut pandang IDE Editor Overleaf, Anda dapat memiliki salah satu peran berikut: `Project Owner`, `Editor`, `Reviewer`, `Viewer`, `Site Administrator`, atau `Template User`.

<Info>

Di Server Pro dan Community Edition, tersedia dukungan untuk memberikan akses anonim **hanya-baca** dan **baca-tulis** ke proyek.

Untuk informasi lebih lanjut, lihat variabel lingkungan `OVERLEAF_ALLOW_PUBLIC_ACCESS` dan `OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` [di sini](/id/on-premises/configuration/overleaf-toolkit/environment-variables).

</Info>
