## Migrasi nama pengguna

Dari sudut pandang login, pengenal utama seorang pengguna adalah alamat email mereka. Jika Anda bermigrasi dari autentikasi lokal ke SSO atau bermigrasi dari satu IdP ke IdP lain, Anda mungkin perlu memperbarui alamat email pengguna.

Untuk membantu hal ini, tersedia sebuah skrip yang akan memigrasikan email pengguna menggunakan file CSV dengan format berikut:

`oldEmail,newEmail`

Setelah melakukan beberapa pemeriksaan validasi, skrip akan melakukan iterasi melalui file CSV dan memperbarui alamat email pengguna dari `oldEmail` menjadi `newEmail`.

### **Validasi**

Sebelum menjalankan migrasi, `<csv_file>` akan diperiksa untuk memastikan bahwa:

* Untuk setiap baris, baik `oldEmail` maupun `newEmail` merupakan alamat email yang valid
* Tidak ada entri duplikat, misalnya, Anda tidak mencoba memperbarui pengguna yang berbeda ke alamat email baru yang sama, atau mencoba memperbarui akun pengguna yang sama dengan alamat email yang sudah digunakan

### **Penggunaan**

```bash wrap
docker cp <csv_file> sharelatex:/overleaf/services/web/<csv_file> docker exec sharelatex /bin/bash -c "cd /overleaf/services/web;node ./modules/server-ce-scripts/scripts/migrate-user-emails.js [--commit] [--continue|--ignore-missing] [--admin-id=ADMIN_USER_ID] <csv_file>"
```

### **Flag**

| Nama               | Deskripsi |
| ------------------ | --------- |
| `--commit`         | <p>Penyertaan flag `--commit` akan benar-benar menjalankan migrasi. Jika dihilangkan, migrasi akan berjalan dalam mode dry-run di mana tidak ada perubahan yang dibuat tetapi validasi tetap dilakukan.<br /><br /><strong>Default</strong>:`false`</p> |
| `--continue`       | Flag `--continue` akan melanjutkan proses migrasi jika alamat email pada sebuah akun pengguna sudah diperbarui |
| `--ignore-missing` | Flag `--ignore-missing` akan melanjutkan proses migrasi jika sebuah akun pengguna tidak ditemukan |
| `--admin-id`       | `--admin-id` harus diatur ke ID Administrator yang melakukan migrasi dan akan digunakan untuk entri log audit. Buka **Admin** > **Manage Users**, cari alamat email Anda, lalu klik hasil pertama untuk menemukan user-id Anda. |
| `<csv_file>`       | `<csv_file>` adalah file yang berisi alamat email lama dan baru |

### **Penyelesaian**

Saat menjalankan skrip migrasi, flag yang Anda pilih akan menentukan apakah sebuah error dicatat ke konsol lalu proses dilanjutkan, atau dicatat ke konsol lalu proses dihentikan. Jika skrip berhenti lebih awal karena error, skrip akan keluar dengan kode 1 untuk menandakan bahwa proses tidak berhasil.

Setelah migrasi selesai, skrip akan mencatat jumlah pembaruan yang berhasil, gagal, dan dilewati ke konsol. Jika migrasi berhasil diselesaikan, skrip akan keluar dengan kode 0.
