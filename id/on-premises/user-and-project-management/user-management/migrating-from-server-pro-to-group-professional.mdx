title: Migrasi dari Server Pro ke Group Professional
icon: rectangle-pro

---

Beralih dari instans Server Pro yang di-host sendiri ke langganan Overleaf Group Professional berbasis cloud yang baru merupakan perubahan besar, jadi untuk membuat proses ini selancar mungkin, kami telah menyusun panduan berikut.

Secara umum, kami mengusulkan periode tumpang tindih selama tiga bulan yang dimulai pada tanggal perpanjangan Anda. Ini berarti bahwa:

* Instans Server Pro Anda yang ada dan langganan Group Professional baru Anda akan sama-sama aktif sepenuhnya.
* Tim teknis Anda dapat menjadwalkan waktu untuk menyiapkan langganan Group Professional dan memutuskan masa depan penerapan Server Pro on-premises Anda.
* Yang terpenting, pengguna Anda akan memiliki waktu yang cukup untuk menyalin proyek mereka ke platform Overleaf Group Professional yang baru.

Panduan singkat ini akan memandu Anda melalui langkah-langkah utama untuk migrasi ini. Mari kita mulai!

<Steps>
<Step title="Fase 1: Penyiapan dan Konfigurasi">
(Tautan: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-1-setup-and-configuration)

* Overleaf akan membuat langganan Group Professional Anda dan menambahkan Lead Administrator Anda.
* Administrator grup Anda akan dapat mengaktifkan [Managed Usersarrow-up-right](https://docs.overleaf.com/groups/user-management/managed-user-accounts), mengonfigurasi [Single Sign-On (SSO)arrow-up-right](https://docs.overleaf.com/groups/overleaf-group-single-sign-on/setting-up-group-sso), dan [mengundang pengguna akhirarrow-up-right](https://docs.overleaf.com/groups/user-management/how-to-add-and-remove-users).

<Warning>

Mengaktifkan Managed Users dan menerapkan SSO merupakan langkah wajib untuk kepatuhan FedRAMP® LI-SaaS. Jika organisasi Anda memerlukan kepatuhan FedRAMP, siapkan Managed Users dan SSO sebelum mengundang pengguna akhir.

</Warning>
</Step>

<Step title="Fase 2: Migrasi Pengguna & Manajemen Data">
(Tautan: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-2-user-migration-and-data-management)

Ini adalah jendela migrasi utama dan memiliki tanggung jawab berikut:

#### Pengguna Akhir

* Pengguna sebaiknya memigrasikan proyek apa pun yang ingin mereka simpan dari instans Server Pro Anda ke akun baru mereka di [overleaf.comarrow-up-right](http://overleaf.com/). Prosesnya melibatkan [mengekspor proyekarrow-up-right](https://www.overleaf.com/learn/how-to/Exporting_your_work_from_Overleaf) dari Server Pro dan [mengunggahnyaarrow-up-right](https://www.overleaf.com/learn/how-to/Uploading_a_project) ke akun mereka di [overleaf.comarrow-up-right](http://overleaf.com/). Jika pengguna belum memiliki akun [overleaf.comarrow-up-right](http://overleaf.com/), mereka dapat mendaftar di [overleaf.com/registerarrow-up-right](http://overleaf.com/register).

<Warning>

Hanya kode sumber proyek (LaTeX dan file biner) yang akan ditransfer melalui prosedur ekspor ini. Pengaturan proyek, pengaturan berbagi, komentar, perubahan terlacak (tracked changes), dan sebagainya yang sudah ada TIDAK akan ditransfer. Pengguna perlu mengundang ulang kolaborator mereka setelah migrasi.

</Warning>

#### Staf Teknis

* Selama fase ini, tim teknis Anda sebaiknya merencanakan penanganan pascamigrasi untuk instans Server Pro on-premises Anda beserta datanya.
* **Pencadangan Data:** Anda dapat mengekspor semua proyek sebelum penonaktifan untuk membuat arsip yang memungkinkan Anda membantu pengguna yang mungkin lupa memigrasikan atau mengunduh pekerjaan mereka. Petunjuk: https://docs.overleaf.com/on-premises/maintenance/data-and-backups/exporting-projects
* **Penonaktifan Server Pro:** Setelah jendela migrasi ditutup dan kunci lisensi Anda dinonaktifkan, Anda memiliki dua opsi utama untuk instans Server Pro itu sendiri (lihat langkah berikutnya).
</Step>

<Step title="Opsi Penonaktifan Server Pro">
<Steps>
<Step title="Hapus Instalasi Server Pro Sepenuhnya">
Menghapus instalasi akan menonaktifkan Server Pro dan menghapus perangkat lunaknya sepenuhnya.
</Step>

<Step title="Beralih ke Community Edition">
Beralih akan mempertahankan database pengguna dan proyek beserta riwayat proyek lengkap dengan mengonversi instans dari Server Pro ke Community Edition.
</Step>
</Steps>

<Info>

Community Edition TIDAK menyertakan [Sandboxed Compilesarrow-up-right](https://docs.overleaf.com/on-premises#overview-of-server-pro-and-community-edition) maupun [LDAP](/id/on-premises/configuration/overleaf-toolkit/authentication/ldap-authentication)/[SAML](/id/on-premises/configuration/overleaf-toolkit/authentication/saml-authentication). Jika Anda perlu kembali ke autentikasi bawaan (nama pengguna/kata sandi), lihat: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-to-ldap-or-saml#going-the-other-way-switching-from-ldap-saml-back-to-native-authentication

Untuk perbandingan Server CE vs. Server Pro, lihat: https://docs.overleaf.com/on-premises/welcome/server-pro-vs.-community-edition

</Info>
</Step>

<Step title="Fase 3: Penonaktifan Server Pro">
(Tautan: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-3-server-pro-decommission)

* Tim Overleaf akan secara resmi menonaktifkan kunci lisensi Server Pro Anda dan akan mengirimkan konfirmasi setelah selesai.
* Pada saat itu, lakukan salah satu tindakan penonaktifan yang dijelaskan di atas: hapus instalasi Server Pro sepenuhnya atau beralih ke Community Edition.
</Step>
</Steps>
