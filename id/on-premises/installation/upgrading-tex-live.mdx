<Danger>

Instruksi berikut **hanya** berlaku untuk instalasi **Community Edition**. Kami sangat menyarankan agar pengguna Ayakaleaf Pro mengaktifkan [Sandboxed Compiles](/id/on-premises/configuration/overleaf-toolkit/sandboxed-compiles) karena fitur ini memberi pengguna akses ke image TeX Live yang hampir sama dengan yang digunakan di [overleaf.com](https://www.overleaf.com) serta menyediakan isolasi antar kompilasi proyek untuk keamanan yang lebih baik.

</Danger>

Untuk menghemat bandwidth, image Overleaf Community Edition maupun Ayakaleaf Pro hanya dilengkapi dengan instalasi minimal [TeX Live](https://www.tug.org/texlive/). Anda dapat menginstal lebih banyak paket atau melakukan upgrade ke instalasi TeX Live lengkap menggunakan perintah [tlmgr](https://www.tug.org/texlive/tlmgr.html) di dalam container `sharelatex`.

#### Masuk ke dalam container sharelatex

Untuk memulai shell di dalam container `sharelatex`, jalankan

```bash
bin/shell
```

Anda akan mendapatkan prompt yang terlihat seperti:

```bash
root@309b192d4030:/#
```

Pada instruksi berikut, kami mengasumsikan bahwa Anda berada di dalam container.

#### Menentukan versi TeX Live Anda saat ini

TeX Live dirilis setiap tahun sekitar bulan April. Langkah-langkah penggunaan `tlmgr` berbeda tergantung apakah Anda menggunakan rilis terkini atau rilis yang lebih lama. Anda dapat memeriksa versi TeX Live yang sedang Anda jalankan dengan `tlmgr --version`. Sebagai contoh, instalasi ini menjalankan TeX Live 2021:

```bash
# tlmgr --version
tlmgr revision 59291 (2021-05-21 05:14:40 +0200)
tlmgr using installation: /usr/local/texlive/2021
TeX Live (https://tug.org/texlive) version 2021
```

<Info>

Rilis TeX Live terkini dapat ditemukan di [beranda TeX Live](https://www.tug.org/texlive/).

</Info>

Jika Anda menjalankan versi TeX Live yang lebih lama, Anda memiliki dua pilihan. Versi baru image Docker Overleaf biasanya dirilis tidak lama setelah rilis TeX Live; Anda dapat menunggunya dan melakukan upgrade deployment Anda menggunakan skrip `bin/upgrade`, atau, jika Anda lebih suka mempertahankan rilis TeX Live yang lebih lama, Anda terlebih dahulu perlu memberi tahu `tlmgr` untuk menggunakan repositori historis. Anda dapat menemukan instruksinya [di sini](https://www.tug.org/texlive/acquire.html#past).

#### Menginstal paket

Untuk menginstal TeX Live secara lengkap, jalankan perintah ini di dalam container `sharelatex`:

```text
tlmgr install scheme-full
```

Anda juga dapat menginstal paket satu per satu secara manual:

```bash
tlmgr install tikzlings tikzmarmots tikzducks
```

<Warning>

Mulai rilis `3.3.0` dan seterusnya, menjalankan `tlmgr path add` kembali **diwajibkan** setelah setiap penggunaan `tlmgr install`, agar semua binary di-symlink dengan benar ke path sistem.

</Warning>

Masih banyak perintah lain yang tersedia. Pelajari lebih lanjut dengan:

```text
tlmgr help
```

Setelah selesai, ketik `exit` atau tekan Control-D untuk keluar dari shell.

#### Menyimpan perubahan Anda

Perubahan yang baru saja Anda buat telah mengubah container `sharelatex`, tetapi perubahan tersebut bersifat sementara -- perubahan akan hilang jika Docker Compose membuat ulang container, misalnya sebagai bagian dari pembaruan konfigurasi.

Untuk membuatnya persisten, gunakan `docker commit` untuk menyimpan perubahan ke image docker baru:

```bash
cat config/version #5.2.1
docker commit sharelatex sharelatex/sharelatex:5.2.1-with-texlive-full
echo 5.2.1-with-texlive-full > config/version
```

Setelah melakukan commit perubahan, perbarui `config/version` sesuai dengan itu. Kemudian jalankan `bin/up` untuk membuat ulang container `sharelatex`.

<Danger>

Anda perlu mengulangi langkah-langkah ini setiap kali Anda [melakukan upgrade](https://github.com/overleaf/toolkit/blob/master/doc/upgrading.md) ke versi Overleaf yang baru.

</Danger>
