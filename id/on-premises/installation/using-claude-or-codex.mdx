Gunakan Claude Code atau Codex untuk merencanakan dan menjalankan deployment Ayakaleaf Pro. Agen dapat mencari dokumentasi ini melalui MCP selama bekerja.

Agen membantu proses deployment. Anda tetap bertanggung jawab untuk meninjau perintah dan melindungi kredensial.

### Sebelum memulai

Siapkan server Linux yang didukung dengan akses SSH. Tinjau [persyaratan](/id/on-premises/getting-started/requirements  "mention") sebelum melanjutkan.

<Warning>

Jangan menempelkan kata sandi, private key, token, atau kunci lisensi ke dalam prompt agen. Tinjau setiap perintah sebelum menjalankannya, terutama perintah yang mengubah file, jaringan, atau container.

</Warning>

### Menghubungkan dokumentasi

Tambahkan endpoint MCP dokumentasi ke agen lokal Anda.

<Tabs>
<Tab title="Claude Code">

```bash wrap
claude mcp add ayakaleaf-pro --scope user --transport http https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>

<Tab title="Codex">

```bash wrap
codex mcp add ayakaleaf-pro --url https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>
</Tabs>

Mulai sesi baru setelah menambahkan server. Minta agen untuk mengonfirmasi bahwa ia dapat mencari dokumentasi Ayakaleaf Pro.

### Men-deploy Ayakaleaf Pro

Buka terminal di server deployment Anda. Jalankan Claude Code atau Codex di sana. Lalu kirim prompt ini:

```text wrap
Use the Ayakaleaf Pro documentation MCP server to guide this deployment.
First, inspect the requirements and installation guides.
Ask me for missing deployment details before making changes.
Use the Ayakaleaf Toolkit unless the documentation requires another approach.
Before configuring the instance, summarize relevant optional features.
Ask which features and integrations I want to enable.
Include TLS, sandboxed compiles, Git integration, external MongoDB or Redis,
SSO (OIDC, SAML, or LDAP), GitHub Synchronisation, Zotero, S3 storage,
email delivery, branding, and localization when relevant.
Explain each selected option's prerequisites, security impact, and configuration steps.
Keep unselected optional features disabled.
Show each command before running it.
Do not expose, store, or request secrets in chat.
After deployment, verify that the service is healthy and summarize the changes.
```

Agen akan memandu Anda melalui penyiapan Docker, konfigurasi Toolkit, pengambilan image, dan startup. Ikuti panduan [using-the-toolkit](/id/on-premises/installation/using-the-toolkit  "mention") untuk alur kerja standar.

### Memilih fitur opsional

Minta agen untuk hanya merekomendasikan fitur yang sesuai dengan lingkungan Anda. Pilihan umum meliputi:

* **Akses dan keamanan:** TLS, sandboxed compiles, dan SSO OIDC, SAML, atau LDAP.
* **Layanan eksternal:** MongoDB, Redis, penyimpanan S3, dan pengiriman email.
* **Kolaborasi:** Integrasi Git, GitHub Synchronisation, dan Zotero.

Agen harus menjelaskan dependensi sebelum menyunting konfigurasi. Tinjau [toolkit-settings.md](/id/on-premises/configuration/overleaf-toolkit/toolkit-settings  "mention") dan [authentication](/id/on-premises/configuration/overleaf-toolkit/authentication  "mention") sebelum mengaktifkan integrasi produksi.

### Memverifikasi deployment

Setelah agen menyelesaikan langkah-langkahnya:

1. Pastikan setiap perintah selesai tanpa error.
2. Buka URL Ayakaleaf Pro yang telah dikonfigurasi di browser Anda.
3. Selesaikan [6.-post-installation-tasks.md](/id/on-premises/installation/using-the-toolkit/6.-post-installation-tasks  "mention").

Untuk instalasi Community Edition yang sudah ada, gunakan panduan [migrate-from-existing.md](/id/on-premises/installation/migrate-from-existing  "mention") alih-alih deployment baru.
