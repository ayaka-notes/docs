### Buat akun administrator pertama Anda {#create-your-first-administrator-account}

Buka [http://localhost:8080/launchpad](http://localhost:8080/launchpad), atau `OVERLEAF_SITE_URL` Anda diikuti `/launchpad`, dan daftarkan akun administrator. Mulai dari sini semuanya bekerja seperti dengan Docker: ikuti [6. Tugas pasca-instalasi](/id/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks) dari panduan Docker, menggunakan port `8080` di tautan `localhost`-nya.

Buat proyek contoh dan kompilasi. PDF-nya menunjukkan bahwa kompilasi berjalan di container TeX Live melalui Podman. Untuk melihat container kompilasi:

```bash title="List the compile containers"
podman ps -a --filter name=project- --format "{{.Names}} {{.Image}} {{.Status}}"
```

### Gunakan HTTPS {#use-https}

[Proxy TLS](/id/on-premises/configuration/overleaf-toolkit/tls-proxy) milik Toolkit berfungsi di Podman: jalankan `bin/init --tls`, atur sertifikat Anda dan `NGINX_ENABLED=true` seperti yang dijelaskan di sana. Proxy ini mendengarkan port `80` dan `443`, yang secara default tidak boleh digunakan oleh Podman tanpa root. Izinkan pengguna tanpa hak istimewa menggunakan port mulai dari `80`:

```bash title="Allow ports 80 and 443"
echo "net.ipv4.ip_unprivileged_port_start=80" | sudo tee /etc/sysctl.d/99-unprivileged-ports.conf
sudo sysctl --system
```

Ini memungkinkan setiap pengguna di server mendengarkan port tersebut, jadi lakukan hanya di server yang didedikasikan untuk Ayakaleaf Pro. Lalu buka port-port tersebut di firewall:

```bash title="Open ports 80 and 443"
sudo firewall-cmd --permanent --add-port=80/tcp --add-port=443/tcp
sudo firewall-cmd --reload
```

Atur `OVERLEAF_SITE_URL` ke alamat `https://` Anda dan jalankan `bin/up -d`. Pertahankan default `NGINX_HTTP_PORT=80` dan `TLS_PORT=443`: dengan port lain, pengalihan dari HTTP ke HTTPS mengarah ke port yang salah.

<Info>

Biarkan `OVERLEAF_LISTEN_IP` di `127.0.0.1` saat Anda menggunakan proxy TLS, sehingga port `8080` tidak dapat dijangkau dari komputer lain.

</Info>

### Upgrade {#upgrade}

Upgrade dengan `bin/upgrade`, seperti yang dijelaskan di [Meng-upgrade deployment Anda](/id/on-premises/maintenance/upgrading-your-deployment). Di Podman, perintah ini juga mengekstrak profil seccomp versi baru ke `config/seccomp/<version>/` dan memperbarui `SECCOMP_PROFILE`:

```text
Over-writing config/version with 6.3.4
Set SECCOMP_PROFILE=/home/<user>/overleaf-toolkit/config/seccomp/6.3.4/clsi-profile.json in config/variables.env
```

Setelah upgrade, jalankan `bin/podman-setup` untuk memeriksa penyiapan.

### Ubah mode SELinux {#change-the-selinux-mode}

`SELINUX_MODE` di `config/overleaf.rc` menentukan cara SELinux membatasi container `sharelatex`. `managed` adalah mode yang disiapkan oleh halaman-halaman ini; mode lainnya dijelaskan di [Pengaturan Toolkit](/id/on-premises/configuration/overleaf-toolkit/toolkit-settings). Jalankan `bin/up -d` setelah mengubahnya.
