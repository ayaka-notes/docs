---
title: 1. Unduh dan inisialisasi Toolkit
description: Clone Ayakaleaf Toolkit, buat konfigurasi, dan atur untuk Ayakaleaf Pro di Podman.
icon: arrow-down-to-bracket
---

<Steps>
<Step title="Clone Toolkit">
Clone **Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)) ke direktori home Anda dan masuk ke dalamnya:

```bash title="Clone the Toolkit" wrap
git clone https://github.com/ayaka-notes/toolkit.git ~/overleaf-toolkit
cd ~/overleaf-toolkit
```

Jalankan semua perintah berikut dari direktori ini.
</Step>

<Step title="Buat konfigurasi">
```bash title="Run initialization"
bin/init
```

Perintah ini membuat `config/overleaf.rc`, `config/variables.env`, dan `config/version`, seperti yang dijelaskan di [3. Inisialisasi konfigurasi](/id/on-premises/installation/using-docker-compose/linux/3.-initialize-the-configuration) pada panduan Docker. `bin/init` belum membutuhkan Podman.
</Step>

<Step title="Atur config/overleaf.rc">
Buka `config/overleaf.rc` dan ubah baris-baris berikut:

```bash title="config/overleaf.rc"
SERVER_PRO=true
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
```

Lalu tambahkan baris ini di akhir file:

```bash title="config/overleaf.rc"
SELINUX_MODE=managed
```

| Pengaturan                        | Alasan                                                                                                                                                                                                      |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SERVER_PRO=true`                 | Menggunakan image Ayakaleaf Pro dari `ghcr.io`. Tidak perlu login.                                                                                                                                           |
| `OVERLEAF_PORT=8080`              | Podman tanpa root tidak dapat mendengarkan port di bawah `1024`. Port default `80` akan gagal.                                                                                                              |
| `SIBLING_CONTAINERS_ENABLED=true` | Menjalankan setiap kompilasi di container TeX Live-nya sendiri. Sudah `true` secara default; penyiapan Podman hanya mendukung mode ini.                                                                    |
| `SELINUX_MODE=managed`            | Menjalankan container `sharelatex` dengan tipe SELinux `sharelatex_t`, yang boleh menggunakan socket Podman dan tidak lebih. `bin/podman-setup --apply` menginstal modul kebijakan untuknya. Lihat [Pengaturan Toolkit](/id/on-premises/configuration/overleaf-toolkit/toolkit-settings) untuk mode lainnya. |

Biarkan `DOCKER_SOCKET_PATH` apa adanya: `bin/podman-setup --apply` mengaturnya ke socket Podman Anda di langkah berikutnya.

<Warning>

Biarkan `GIT_BRIDGE_ENABLED=false`. Di Ayakaleaf Pro 6.3.4, integrasi Git tidak berfungsi di Podman, lihat [Batasan yang diketahui](/id/on-premises/installation/using-podman#known-limitations).

</Warning>
</Step>

<Step title="Pilih image TeX Live">
Buka `config/variables.env`, hapus `#` di depan `TEX_LIVE_DOCKER_IMAGE` dan `ALL_TEX_LIVE_DOCKER_IMAGES`, dan cantumkan image TeX Live yang akan digunakan:

```bash title="config/variables.env" wrap
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
```

`bin/up` berhenti dengan `Please configure ALL_TEX_LIVE_DOCKER_IMAGES` jika daftarnya kosong. `texlive-full` berukuran besar; untuk server uji, `ghcr.io/ayaka-notes/texlive-basic:2026.1` yang jauh lebih kecil juga bisa digunakan. Lihat [Sandboxed Compiles](/id/on-premises/configuration/overleaf-toolkit/sandboxed-compiles) untuk image yang tersedia.

Atur variabel lainnya, seperti `OVERLEAF_SITE_URL`, seperti yang dijelaskan di [5. Menyesuaikan instance Anda](/id/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance#required-environment-variables). Dengan alamat listen default, gunakan `http://localhost:8080`.
</Step>
</Steps>
