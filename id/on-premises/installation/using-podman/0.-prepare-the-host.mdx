---
title: 0. Siapkan host
description: Periksa sistem operasi dan SELinux, lalu instal git, sebelum menyiapkan Podman tanpa root.
icon: server
---

Anda tidak menginstal Podman secara manual: [2. Jalankan podman-setup](/id/on-premises/installation/using-podman/2.-run-podman-setup) menginstalnya bersama paket lain yang dibutuhkan. Di sini Anda hanya memeriksa host dan menginstal `git`, yang Anda perlukan untuk mengunduh Toolkit.

<Steps>
<Step title="Periksa sistem operasi dan SELinux">
Masuk sebagai pengguna yang akan menjalankan Ayakaleaf Pro, bukan sebagai `root`, lalu periksa distribusi dan mode SELinux:

```bash title="Check the host"
grep PRETTY_NAME /etc/os-release
getenforce
```

Anda seharusnya melihat RHEL, Rocky Linux, AlmaLinux, atau CentOS Stream versi 9 atau yang lebih baru, dan `Enforcing`:

```text
PRETTY_NAME="Rocky Linux 9.9 (Blue Onyx)"
Enforcing
```
</Step>

<Step title="Periksa bahwa Anda dapat menggunakan sudo">
`bin/podman-setup --apply` menginstal paket dan memuat modul SELinux dengan `sudo`, dan meminta kata sandi Anda saat diperlukan:

```bash title="Check sudo"
sudo -v
```

Jika ini gagal, minta administrator Anda menambahkan pengguna Anda ke grup `wheel`.
</Step>

<Step title="Instal git">
```bash title="Install git"
sudo dnf install -y git
```

<Warning>

Jangan instal Docker Engine di host ini. Paket `podman-docker`, yang diinstal oleh `bin/podman-setup`, menyediakan perintah `docker`, dan Toolkit memperlakukan host sebagai Podman setiap kali perintah `podman` ada.

</Warning>
</Step>
</Steps>
