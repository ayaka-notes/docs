---
title: 3. Mulai Ayakaleaf Pro
description: Mulai Ayakaleaf Pro di Podman, verifikasi dengan podman-setup dan bin/doctor, dan jalankan kembali setelah reboot.
icon: circle-play
---

<Steps>
<Step title="Mulai container">
```bash title="Start Ayakaleaf Pro"
bin/up -d
```

Start pertama mengunduh image MongoDB, Redis, dan TeX Live, serta membuat direktori data di `data/`. Perintah ini mencetak peringatan bahwa dukungan Podman bersifat eksperimental.

<Info>

Start pertama juga dapat mencetak `MongoNetworkError: connect ECONNREFUSED 127.0.0.1:27017`. Toolkit menyiapkan replica set MongoDB saat MongoDB masih memulai, dan mencoba lagi hingga MongoDB merespons. Anda dapat mengabaikan baris ini.

</Info>

Setelah satu atau dua menit, periksa bahwa container berjalan:

```bash title="List the containers"
podman ps --format "{{.Names}} {{.Status}}"
```

```text
mongo Up 34 seconds (healthy)
redis Up 20 seconds
sharelatex Up 20 seconds
```
</Step>

<Step title="Periksa penyiapan lagi">
Sekarang direktori data sudah ada dan container `sharelatex` berjalan, `bin/podman-setup` dapat menyelesaikan pemeriksaannya:

```bash title="Check the setup"
bin/podman-setup
```

Skrip ini memeriksa pemilik direktori data yang baru dan menguji socket Podman dari dalam container `sharelatex`:

```text
====== Socket Connectivity ======
[✓] host → socket OK
[✓] container → socket OK

====== Data Directory Permissions ======
[✓] mongo data dir owned by 999
[✓] redis data dir owned by 999
[✓] overleaf data dir owned by 33
...
====== Summary ======
[✓] 27 passed  [!] 1 warnings  [✗] 0 failures
[!] Warnings:
[!] not logged in to quay.io
```

`container → socket OK` berarti Ayakaleaf Pro dapat memulai container kompilasi. Jika sebuah pemeriksaan gagal, jalankan `bin/podman-setup --apply`, lalu `bin/up -d`. Peringatan quay.io tidak berlaku untuk Ayakaleaf Pro, lihat [2. Jalankan podman-setup](/id/on-premises/installation/using-podman/2.-run-podman-setup).
</Step>

<Step title="Jalankan doctor">
```bash title="Run the doctor"
bin/doctor
```

Di Podman, laporan menampilkan runtime dan pengaturan keamanan:

```text
- Container Daemon
    - status: up
    - runtime: podman
    - server version: 5.8.5
    - socket: /run/user/1000/podman/podman.sock
    - DOCKER_HOST: unix:///run/user/1000/podman/podman.sock
    - host → socket: OK
    - container → socket: OK
- Security
    - SELinux: Enforcing
    - SELINUX_MODE: managed
    - SELINUX_LABEL: sharelatex_t
    - SELinux module: loaded (podman_socket_clsi)
    - SELinux rules: present
    - Seccomp profile: present
```

Peringatan `Server Pro enabled, but not logged in to quay.io repository` di bagian akhir adalah pemeriksaan quay.io yang sama, lihat [Mendapatkan bantuan](/id/on-premises/support/getting-help#q-and-a).
</Step>

<Step title="Mulai Ayakaleaf Pro setelah reboot">
Dengan Docker, daemon Docker memulai container kembali setelah reboot. Podman tanpa root tidak memiliki daemon: aktifkan layanan pengguna yang memulai container Anda saat server boot:

```bash title="Start the containers at boot"
systemctl --user enable podman-restart.service
```

Layanan ini memulai setiap container milik pengguna Anda yang kebijakan restart-nya `always`, yang diatur Toolkit untuk semua container-nya. Ini membutuhkan lingering, yang sudah diaktifkan oleh `bin/podman-setup --apply`. Tanpa layanan ini, jalankan `bin/up -d` setelah setiap reboot.
</Step>

<Step title="Buka port di firewall">
Secara default, instance hanya menerima koneksi dari server itu sendiri, di `http://localhost:8080`. Untuk membukanya dari komputer lain, atur `OVERLEAF_LISTEN_IP` di `config/overleaf.rc` dan `OVERLEAF_SITE_URL` di `config/variables.env` seperti yang dijelaskan di [5. Menyesuaikan instance Anda](/id/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance#listen-address-and-port), lalu jalankan `bin/up -d` lagi.

Tidak seperti Docker, Podman tanpa root tidak melewati firewall host. Jika `firewalld` berjalan, yang merupakan default di RHEL, buka port-nya:

```bash title="Open port 8080"
sudo firewall-cmd --permanent --add-port=8080/tcp
sudo firewall-cmd --reload
```

Di server cloud, izinkan juga port tersebut di security group penyedia. Gunakan HTTPS sebelum membuka instance ke internet, lihat [4. Tugas pasca-instalasi](/id/on-premises/installation/using-podman/4.-post-installation-tasks#use-https).
</Step>
</Steps>
