---
title: 2. Jalankan podman-setup
description: Biarkan bin/podman-setup memeriksa host serta menyiapkan Podman tanpa root, SELinux, dan profil seccomp.
icon: wand-magic-sparkles
---

`bin/podman-setup` memeriksa semua yang dibutuhkan Ayakaleaf Pro di Podman. Tanpa opsi, skrip ini hanya melaporkan; dengan `--apply`, skrip ini juga memperbaiki apa yang ditemukannya.

<Steps>
<Step title="Periksa host">
```bash title="Check only"
bin/podman-setup
```

Di host yang baru, sebagian besar pemeriksaan gagal, misalnya:

```text
====== Packages ======
[✗] podman not installed
[✗] podman-docker not installed
...
====== Summary ======
[✓] 7 passed  [!] 13 warnings  [✗] 4 failures
```
</Step>

<Step title="Terapkan perbaikan">
```bash title="Check and fix"
bin/podman-setup --apply
```

Jalankan di terminal: skrip ini meminta kata sandi `sudo` Anda untuk langkah-langkah tingkat sistem. Skrip ini juga mengunduh image Ayakaleaf Pro untuk mengekstrak profil seccomp-nya, yang memakan waktu beberapa menit pada kali pertama. Di akhir, skrip ini memeriksa host lagi:

```text
====== Summary ======
[✓] 23 passed  [!] 2 warnings  [✗] 0 failures
[!] Warnings remaining:
[!] not logged in to quay.io
[!] container → socket skipped (sharelatex not running)
```

Kedua peringatan tersebut wajar pada tahap ini:

* `not logged in to quay.io`: pemeriksaan ini berasal dari Toolkit resmi, tempat image Server Pro berada di registry privat. Image Ayakaleaf Pro bersifat publik di `ghcr.io` dan tidak memerlukan login, jadi abaikan saja. Peringatan ini tetap muncul setelah instalasi.
* `container → socket skipped (sharelatex not running)`: pengujian ini membutuhkan instance yang sedang berjalan. Anda menjalankan skrip ini lagi di [3. Mulai Ayakaleaf Pro](/id/on-premises/installation/using-podman/3.-start-ayakaleaf-pro).

Skrip keluar dengan `0` jika semua pemeriksaan lulus, `1` jika ada peringatan, dan `2` jika ada kegagalan. Karena peringatan quay.io, harapkan `1`.
</Step>
</Steps>

### Apa yang diubah skrip {#what-the-script-changes}

Dengan `--apply`, skrip dapat mengubah hal-hal berikut.

Tingkat sistem, dengan `sudo`:

* Menginstal `podman`, `podman-docker`, `git`, `curl`, `checkpolicy`, dan `policycoreutils` dengan `dnf`.
* Mengaktifkan lingering untuk pengguna Anda dengan `loginctl`, sehingga container Anda tetap berjalan setelah Anda logout.
* Membuat `/etc/containers/nodocker`, yang membungkam pesan "Emulate Docker CLI using podman".
* Memuat modul kebijakan SELinux `podman_socket_clsi`, saat `SELINUX_MODE=managed`.

Untuk pengguna Anda:

* Mengaktifkan layanan pengguna `podman.socket`, API yang kompatibel dengan Docker yang digunakan Ayakaleaf Pro untuk memulai kompilasi.
* Menginstal Docker Compose v2 dari GitHub ke `~/.local/bin/docker-compose`, dan menautkannya di `~/.docker/cli-plugins/`.
* Membuat Podman menggunakan Compose ini di `~/.config/containers/containers.conf`.
* Menambahkan alias `mongo` dan `redis` di `~/.config/containers/registries.conf.d/overleaf-toolkit.conf`, sehingga Podman tahu dari mana harus menarik nama image pendek ini.

Di Toolkit:

* Mengatur `DOCKER_SOCKET_PATH` dan `DOCKER_HOST` di `config/overleaf.rc` ke `/run/user/<uid>/podman/podman.sock`.
* Mengekstrak profil seccomp untuk kompilasi dari image Ayakaleaf Pro ke `config/seccomp/<version>/clsi-profile.json`, dan mengatur `SECCOMP_PROFILE` di `config/variables.env`. Tidak seperti Docker, Podman membutuhkan profil ini sebagai file di host.
* Membangun modul kebijakan SELinux di `config/selinux/`.
* Mengatur pemilik direktori data di `data/` dengan `podman unshare chown`, setelah direktori tersebut ada.

<Info>

Setiap perubahan berpasangan dengan satu pemeriksaan. Jika Anda mengubah sesuatu secara manual, misalnya di `config/overleaf.rc`, jalankan `bin/podman-setup` lagi untuk memverifikasinya.

</Info>
