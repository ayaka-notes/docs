### Migrasi dari Overleaf Community

#### Kasus 01: Dari Overleaf Toolkit

Jika Anda menggunakan Overleaf Toolkit resmi untuk Overleaf Community, cukup tambahkan file bernama `docker-compose.override.yml` dengan isi berikut atau yang serupa ke direktori `overleaf-toolkit/config`:

```yml title="docker-compose.override.yml"
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:X.x.x # change to specific version
```

Untuk memulai instance Anda, jalankan:

```bash
bin/up
```

Selesai! Semuanya sudah siap. Selanjutnya, Anda dapat memverifikasi bahwa instance Ayakaleaf Anda berjalan dengan benar dan Anda dapat mengakses antarmuka web. Setelah semuanya berfungsi, lanjutkan dengan langkah-langkah [konfigurasi](/id/on-premises/configuration/overleaf-toolkit) di bawah untuk mengaktifkan fitur-fitur lanjutan seperti:

* [sandboxed-compiles.md](/id/on-premises/configuration/overleaf-toolkit/sandboxed-compiles  "mention")
* [authentication](/id/on-premises/configuration/overleaf-toolkit/authentication  "mention")
* [github-synchronisation.md](/id/on-premises/configuration/overleaf-toolkit/github-synchronisation  "mention")
* [zotero-integration.md](/id/on-premises/configuration/overleaf-toolkit/zotero-integration  "mention")

#### Kasus 02: Dari File Docker Compose

Jika Anda menggunakan `docker-compose.yml` mandiri, migrasikan terlebih dahulu ke Overleaf Toolkit. Toolkit menyederhanakan instalasi on-premises, peningkatan versi, dan pemeliharaan.

Ikuti [docker-compose.yml-to-toolkit-migration.md](/id/on-premises/maintenance/docker-compose.yml-to-toolkit-migration  "mention") untuk mengonversi deployment Anda yang sudah ada. Pertahankan konfigurasi dan path volume data Anda saat ini selama migrasi ini.

Setelah deployment Toolkit berjalan, ikuti [#from-overleaf-toolkit](/id/on-premises/installation/migrate-from-existing#from-overleaf-toolkit  "mention") untuk mengganti image-nya ke Ayakaleaf Pro. Mulai instance dengan `bin/up`, lalu verifikasi bahwa Anda dapat mengakses antarmuka web.

### Migrasi dari Overleaf Server Pro

Jika Anda saat ini menjalankan instance [Overleaf Server Pro](https://www.overleaf.com/for/enterprises) berlisensi komersial dan ingin bermigrasi ke Ayakaleaf Pro, perlu diketahui bahwa migrasi mungkin memerlukan beberapa pekerjaan tambahan karena format data tertentu (`templates`) mungkin tidak sepenuhnya kompatibel. Namun, kami dengan senang hati akan membantu Anda. Silakan [buka issue](https://github.com/ayaka-notes/ayakaleaf-pro/issues) atau hubungi kami di [ayaka-notes@outlook.com](mailto:ayaka-notes@outlook.com), dan kami akan membantu Anda bermigrasi ke Ayakaleaf Pro secara gratis.

***

### Migrasi dari Overleaf CEP

Kami sering menerima pertanyaan dari pengguna tentang apakah mereka dapat bermigrasi dari [Overleaf CEP](https://github.com/yu-i-i/overleaf-cep) ke Ayakaleaf Pro. Dalam sebagian besar kasus, Overleaf CEP dan Ayakaleaf Pro menawarkan fungsionalitas yang secara umum setara dan tetap kompatibel secara data hingga versi 6.2.0. Kedua proyek dapat merilis fitur pada waktu yang berbeda; misalnya, kami dapat mengambil (cherry-pick) fitur dari Overleaf CEP, dan sebaliknya. Meskipun implementasi kami untuk fitur yang sama mungkin sedikit berbeda, umumnya tidak ada alasan kuat untuk bermigrasi.

Jika Anda tetap ingin bermigrasi ke atau mencoba Ayakaleaf Pro, silakan lihat: [#case-01-from-overleaf-toolkit](/id/on-premises/installation/migrate-from-existing#case-01-from-overleaf-toolkit  "mention"). Proses migrasinya sama.

***

### Migrasi dari Overleaf SaaS

Sayangnya, migrasi dari platform Overleaf SaaS ke instance Ayakaleaf Pro yang di-host sendiri bisa jauh lebih sulit. Saat ini, satu-satunya metode yang umum tersedia adalah mengunduh setiap proyek sebagai arsip ZIP lalu mengunggahnya ke instance Ayakaleaf Pro yang Anda host sendiri. Cara ini hanya memindahkan file proyek saat ini, yang berarti Anda akan _**kehilangan**_:

* Semua riwayat proyek dan revisi sebelumnya
* Semua komentar dan perubahan yang dilacak
* Semua metadata Git dan riwayat commit
* Semua tautan dan pengaturan sinkronisasi GitHub
* Semua tautan antara file BibTeX dan platform manajemen referensi pihak ketiga

***

### Migrasi dari Fork Overleaf Pihak Ketiga

Ayakaleaf Pro mungkin tidak mendukung fitur yang khusus untuk fork Overleaf pihak ketiga tertentu. Begitu sebuah fork menyimpang secara signifikan dari basis kode Overleaf upstream—atau memperkenalkan perubahan tanpa mempertahankan kompatibilitas upstream—menggabungkan rilis Overleaf berikutnya bisa menjadi sangat sulit. Anda masih dapat mencoba metode migrasi yang dijelaskan di atas, tetapi kompatibilitas tidak dijamin, dan kami mungkin tidak dapat memberikan bantuan atau dukungan teknis untuk migrasi dari fork yang tidak didukung.
