### Melihat-lihat

Setelah Anda memiliki salinan lokal Toolkit, mari kita lihat struktur repositori menggunakan perintah `ls`.

```bash title="Run this"
ls -l
```

<Info>

Perintah `ls -l` menampilkan daftar panjang yang terperinci dari isi sebuah direktori, beserta informasi file tambahan seperti izin, kepemilikan, dan ukuran.

</Info>

Jika semuanya berhasil di-clone, Anda akan melihat sesuatu seperti ini:

```text
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 bin
-rw-r--r-- 1 fry fry  6465 Aug 30 14:16 CHANGELOG.md
drwxr-xr-x 2 fry fry  4096 Sep  6 12:43 config
drwxr-xr-x 5 fry fry  4096 Aug 30 14:22 data
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 doc
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 lib
-rw-r--r-- 1 fry fry 34520 Aug 30 14:16 LICENSE
-rw-r--r-- 1 fry fry  1178 Aug 30 14:16 README.md
```

<Info>

Semua file konfigurasi milik pengguna berada di direktori `config/`. Direktori ini **dikecualikan** dari sistem kontrol revisi git, sehingga tidak akan berubah saat Toolkit diperbarui.

</Info>

## Tata letak repositori

| Nama     | Deskripsi |
| -------- | --------- |
| `bin`    | Folder ini berisi kumpulan skrip yang membantu Anda mengelola instans server Overleaf Anda. Anda dapat membaca lebih lanjut tentang skrip-skrip ini di bagian Perintah di bawah. |
| `config` | Folder ini berisi file konfigurasi lokal Anda sendiri. |
| `lib`    | Folder ini berisi file konfigurasi dasar yang digunakan oleh Toolkit. |
| `data`   | Secara default, folder ini berisi lokasi penyimpanan untuk MongoDb, Redis, dan Overleaf. Untuk informasi lebih lanjut, lihat bagian [Data persisten](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/files-and-locations#persistent-data) di bawah. |

<Warning>

Kami menyarankan untuk **tidak** mengubah file di luar folder `/config` secara langsung. Sebagai gantinya, jika Anda perlu melakukan perubahan, perubahan tersebut dapat dilakukan melalui variabel lingkungan yang diatur di **config/variables.env** atau **config/overleaf.rc**.\
Misalnya, untuk mengatur image layanan `mongo`, alih-alih mengedit `lib/docker-compose.mongo.yml` secara langsung, atur image menggunakan variabel lingkungan `MONGO_IMAGE` di `config/overleaf.rc`. Untuk informasi lebih lanjut, lihat halaman [Pengaturan Toolkit](/id/on-premises/configuration/overleaf-toolkit/toolkit-settings).

</Warning>

<Info>

Toolkit **tidak** akan mengubah data apa pun di direktori `config/` tanpa izin Anda.

</Info>
