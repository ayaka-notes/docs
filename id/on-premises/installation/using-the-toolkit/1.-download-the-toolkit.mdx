### Mengunduh Toolkit

Toolkit kompatibel dengan Server CE maupun Ayakaleaf Pro dan merupakan metode instalasi yang direkomendasikan. Menggunakan Toolkit memungkinkan Anda memulai dengan Server CE secara mudah dan melakukan upgrade ke Ayakaleaf Pro dengan mulus jika diperlukan.

<Info>

[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) telah dimodifikasi untuk menggunakan image overleaf-pro langsung dari ghcr, dengan TeX Live yang disediakan oleh ayaka-notes. Sebagai alternatif, Anda dapat mengunduh overleaf-toolkit resmi.

</Info>

<Steps>
<Step title="Clone repositori Overleaf Toolkit">
Untuk menginstal toolkit, Anda perlu berpindah ke path instalasi yang dituju lalu melakukan clone repositori GitHub Overleaf Toolkit (@Ayaka-notes) menggunakan perintah ini:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
# official toolkit (Not Recommended)
# git clone https://github.com/overleaf/toolkit.git ./overleaf-toolkit
```

<Info>

Untuk mencegah potensi masalah izin, kami menyarankan untuk menginstal Toolkit di direktori `$HOME` milik pengguna Anda.

</Info>
</Step>

<Step title="Pindah ke direktori toolkit">
Tunggu hingga proses cloning selesai, lalu mari berpindah ke direktori `overleaf-toolkit` yang baru dibuat:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
