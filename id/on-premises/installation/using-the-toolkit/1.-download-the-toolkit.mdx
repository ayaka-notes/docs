### Mengunduh Toolkit

Anda menginstal Ayakaleaf Pro dengan **Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)), sekumpulan skrip yang menjalankan Overleaf di Docker untuk Anda.

Secara default, Toolkit menjalankan Overleaf Community Edition (CE) resmi yang gratis. [4. Dapatkan Image Ayakaleaf Pro](/id/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images) mengalihkannya ke Ayakaleaf Pro dengan satu pengaturan.

<Accordion title="Sudah menjalankan Overleaf Toolkit resmi (overleaf/toolkit)?">

Anda tidak perlu menginstal ulang. Pertahankan instalasi Anda dan ikuti bagian terakhir dari [4. Dapatkan Image Ayakaleaf Pro](/id/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images).

</Accordion>

<Steps>
<Step title="Clone repositori Ayakaleaf Toolkit">
Untuk menginstal toolkit, Anda perlu berpindah ke path instalasi yang dituju lalu melakukan clone repositori Ayakaleaf Toolkit menggunakan perintah ini:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
```

<Info>

Untuk mencegah potensi masalah izin, kami menyarankan untuk menginstal Toolkit di direktori `$HOME` milik pengguna Anda.

</Info>
</Step>

<Step title="Pindah ke direktori toolkit">
Tunggu hingga proses cloning selesai, lalu mari berpindah ke direktori `overleaf-toolkit` yang baru dibuat:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
