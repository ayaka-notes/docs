[Toolkit](https://github.com/ayaka-notes/toolkit) adalah cara yang direkomendasikan untuk men-deploy instance Ayakaleaf Pro.

Di bagian ini kami akan memandu Anda mengunduh Toolkit dari GitHub, mengenal beberapa perintah Toolkit, dan mengonfigurasi beberapa pengaturan dasar. Di akhir halaman ini, Anda seharusnya sudah memiliki instance Overleaf on-premises yang berjalan.

<Info>

Secara default, instance hanya menerima koneksi dari server itu sendiri, di `http://localhost`. Untuk membukanya dari komputer lain atau pada port lain, atur `OVERLEAF_LISTEN_IP` dan `OVERLEAF_PORT` di `config/overleaf.rc`, seperti yang dijelaskan di [5. Menyesuaikan instance Anda](/id/on-premises/installation/using-the-toolkit/5.-personalizing-your-instance).

</Info>
