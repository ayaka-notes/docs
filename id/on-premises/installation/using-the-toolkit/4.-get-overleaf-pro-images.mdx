---
title: 4. Dapatkan Image Ayakaleaf Pro
icon: split
---

Ayakaleaf Pro didistribusikan sebagai image Docker di registry [ghcr](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/), dengan **akses terbuka** untuk siapa saja. Kami menyediakan image untuk arsitektur amd64 maupun arm64. Saat Anda menarik (pull) image, image yang sesuai akan dipilih secara otomatis berdasarkan arsitektur sistem Anda.

#### Pengguna Toolkit Ayaka-notes

Jika Anda menggunakan [ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit),  Ayakaleaf Pro dapat digunakan sebagai pengganti langsung (drop-in replacement) untuk Community Edition, sehingga Anda dapat menggunakan pengaturan dan kustomisasi yang sudah ada. Aktifkan Pro di Toolkit dengan mengedit `config/overleaf.rc` dan mengatur variabel lingkungan `SERVER_PRO`:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

Saat berikutnya Anda menjalankan `bin/up`, Toolkit akan secara otomatis mengunduh dan menggunakan image Ayakaleaf Pro.

#### Pengguna Toolkit Resmi

Jika Anda menggunakan [overleaf/toolkit](https://github.com/overleaf/toolkit), untuk mendapatkan image Pro, jalankan perintah berikut untuk menariknya:

```bash title="Pull Docker Images"
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Kemudian, tambahkan file bernama `docker-compose.override.yml` dengan konten berikut ke dalam direktori `overleaf-toolkit/config`:

```yml title="docker-compose.override.yml"
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

Saat berikutnya Anda menjalankan `bin/up`, Toolkit akan secara otomatis mengunduh dan menggunakan image Ayakaleaf Pro.
