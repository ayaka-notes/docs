---
title: 4. Dapatkan Image Ayakaleaf Pro
icon: split
---

Ayakaleaf Pro adalah image Docker gratis di [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Anda tidak memerlukan akun atau login untuk menariknya. Image dibangun untuk amd64 dan arm64, dan Docker memilih image yang sesuai dengan server Anda.

Buka `config/overleaf.rc` dan atur:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

Saat berikutnya Anda menjalankan `bin/up`, Toolkit mengunduh image Ayakaleaf Pro dan menggunakannya sebagai pengganti Overleaf Community Edition resmi. Pengaturan Anda di `config/` tetap berfungsi.

<Accordion title="Sudah menjalankan Overleaf Toolkit resmi (overleaf/toolkit)?">

Anda tidak perlu menginstal ulang. Tarik image Ayakaleaf Pro:

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Kemudian tambahkan file bernama `docker-compose.override.yml` dengan konten berikut ke dalam direktori `overleaf-toolkit/config`:

```yml
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

Saat berikutnya Anda menjalankan `bin/up`, Toolkit menggunakan image Ayakaleaf Pro.

</Accordion>
