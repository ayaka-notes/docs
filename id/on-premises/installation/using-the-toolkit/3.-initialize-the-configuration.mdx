### Menginisialisasi konfigurasi

Mari kita inisialisasi file konfigurasi server baru kita dengan beberapa nilai default yang wajar dengan menjalankan skrip bawaan `bin/init`.

```text title="Run initialization"
bin/init
```

Skrip ini **tidak** akan menimpa file konfigurasi yang sudah ada.

Sekarang mari kita periksa isi direktori `config/` menggunakan perintah `ls`:

```text title="List the config directory"
ls config
```

Jika semuanya berhasil diinisialisasi, Anda akan melihat tiga file konfigurasi: `overleaf.rc`, `variables.env`, dan `version`. Ini adalah file konfigurasi utama server yang memungkinkan Anda menyesuaikan cara server Anda beroperasi dan cara pengguna berinteraksi dengan instance Anda.

| Nama            | Deskripsi                                               |
| --------------- | ------------------------------------------------------- |
| `overleaf.rc`   | File konfigurasi tingkat atas yang utama.               |
| `variables.env` | Variabel lingkungan yang dimuat ke dalam kontainer Docker. |
| `version`       | Versi image Docker yang akan digunakan.                 |

<Info>

Untuk saat ini, cukup ketahui bahwa file-file ini ada dan di mana Anda dapat menemukannya. Nanti dalam dokumentasi ini kita akan membahas setiap file secara lebih rinci dan menjelaskan cara menyesuaikan instance Anda menggunakannya. Jika Anda ingin langsung melompat ke sana, Anda dapat melihat uraian lengkap file-file konfigurasi ini di [halaman File dan lokasi](/id/on-premises/configuration/overleaf-toolkit/files-and-locations).

</Info>
