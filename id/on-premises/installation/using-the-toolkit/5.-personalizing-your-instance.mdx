### Menyesuaikan instance Anda

Sebelum menjalankan instance Overleaf Anda untuk pertama kalinya, perbarui dua file konfigurasi dengan informasi khusus Anda:

| File                   | Dibaca oleh                                | Yang diatur di sini                                               |
| ---------------------- | ------------------------------------------ | ----------------------------------------------------------------- |
| `config/overleaf.rc`   | skrip Toolkit, seperti `bin/up`            | cara kontainer berjalan: `OVERLEAF_LISTEN_IP`, `OVERLEAF_PORT`, `SERVER_PRO`, path data |
| `config/variables.env` | aplikasi di dalam kontainer                | perilaku Overleaf: `OVERLEAF_SITE_URL`, email, image TeX Live |

<Steps>
<Step title="Sunting file variabel">
Buka `config/variables.env` di editor teks favorit Anda dan perbarui variabel lingkungan di bawah ini dengan nilai yang diperlukan.
</Step>

<Step title="Alamat dan port listen">
Secara default, Toolkit memublikasikan antarmuka web di `127.0.0.1:80`, sehingga hanya dapat dibuka dari browser di server itu sendiri. Komputer lain akan mendapatkan error "connection refused" atau "server not found". Untuk mengubahnya, edit `config/overleaf.rc`:

```bash title="config/overleaf.rc"
OVERLEAF_LISTEN_IP=0.0.0.0
OVERLEAF_PORT=8080
```

`OVERLEAF_LISTEN_IP` adalah alamat IP host tempat kontainer melakukan bind, dan `OVERLEAF_PORT` adalah port host. Bersama-sama keduanya membentuk pemetaan port Docker `OVERLEAF_LISTEN_IP:OVERLEAF_PORT:80`. Pilih nilai yang sesuai dengan penyiapan Anda:

| Penyiapan                                                                       | `OVERLEAF_LISTEN_IP`                  | `OVERLEAF_PORT`        | Buka di browser               |
| ------------------------------------------------------------------------------- | ------------------------------------- | ---------------------- | ----------------------------- |
| Hanya di mesin ini (default)                                                    | `127.0.0.1`                           | `80`                   | `http://localhost`            |
| Komputer lain di LAN atau internet terhubung secara langsung                    | `0.0.0.0`, atau salah satu IP server  | `80`, atau port bebas apa pun | `http://<server-ip>:<port>`   |
| Di belakang reverse proxy Anda sendiri (NGINX, Caddy, Cloudflare Tunnel) di host yang sama | `127.0.0.1`                | port bebas apa pun     | URL proxy tersebut            |
| Di belakang [TLS proxy](/id/on-premises/configuration/overleaf-toolkit/tls-proxy) Toolkit | `127.0.0.1`                 | `80`                   | `https://<your-domain>`       |

Jika port `80` sudah digunakan di host, misalnya oleh server web lain, atur `OVERLEAF_PORT` ke port bebas seperti `8080`. Jika tidak, `bin/up` akan gagal dengan `bind: address already in use`.

<Warning>

Port yang dipublikasikan oleh Docker melewati firewall host seperti `ufw` dan `firewalld`. Dengan `0.0.0.0`, instance dapat dijangkau dari setiap jaringan yang terhubung ke server. Pada server cloud, Anda juga perlu mengizinkan port tersebut di security group penyedia. Gunakan HTTPS sebelum mengekspos instance ke internet, lihat [TLS proxy](/id/on-premises/configuration/overleaf-toolkit/tls-proxy).

</Warning>

Anda dapat memulai dengan nilai default dan membuka instance di `localhost` terlebih dahulu. Untuk mengizinkan akses dari komputer lain nanti, ubah kedua variabel ini di `config/overleaf.rc` dan `OVERLEAF_SITE_URL` di `config/variables.env`, lalu jalankan `bin/up` lagi untuk membuat ulang kontainer.
</Step>

<Step title="Variabel lingkungan wajib">
Perbarui variabel berikut di `config/variables.env`:

| Nama                          | Deskripsi                                                                                                                                                    | Contoh                         |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| `OVERLEAF_SITE_URL`           | Alamat tempat instance Overleaf Anda tersedia secara publik. Nilai ini digunakan pada tautan publik dan saat terhubung melalui websocket, sehingga **harus dikonfigurasi dengan benar**! | `https://overleaf.lilliput.com` |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | Alamat email ini akan digunakan sebagai alamat `from` untuk semua email keluar.                                                                                 | `no-reply@lilliput.com`         |
| `OVERLEAF_ADMIN_EMAIL`        | Alamat email yang dapat digunakan pengguna untuk menghubungi pengelola situs.                                                                                          | `it-services@lilliput.com`      |

`OVERLEAF_SITE_URL` adalah alamat yang diketik pengguna di browser mereka, bukan alamat listen. Sertakan port jika bukan `80` (HTTP) atau `443` (HTTPS), misalnya `http://192.168.1.20:8080`. Jangan gunakan `http://0.0.0.0`. Jika `OVERLEAF_SITE_URL` tidak cocok dengan alamat di browser, editor gagal terhubung, dan tautan di email serta callback OAuth mengarah ke tempat yang salah.

Atur juga `OVERLEAF_SESSION_SECRET` ke nilai yang dibuat dengan `openssl rand -hex 32`. Tanpa variabel ini, setiap `bin/up` yang membuat ulang kontainer, dan setiap upgrade, akan membuat semua pengguna logout. Lihat Tanya Jawab di [Variabel Lingkungan](/id/on-premises/configuration/overleaf-toolkit/environment-variables).

Setelah Anda memperbarui variabel lingkungan ini, simpan dan keluar.
</Step>

<Step title="Menyiapkan Sandbox Compile">
Selanjutnya, konfigurasikan TeX Live Full untuk [sandboxed-compiles.md](/id/on-premises/configuration/overleaf-toolkit/sandboxed-compiles  "mention"). Buka `config/variables.env` dan perbarui variabel lingkungan berikut:

```dotenv title="config/variables.env" wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```
</Step>

<Step title="Menjalankan instance Anda">
Untuk menjalankan instance Anda, jalankan:

```text title="Start the instance"
bin/up
```

Perintah ini akan mengunduh image yang diperlukan termasuk texlive, membuat kontainer (menggunakan kustomisasi Anda), dan menjalankan instance. Anda akan melihat output log dari berbagai kontainer Docker.

Untuk menjalankannya lagi nanti (tanpa menampilkan output log), jalankan:

```text title="Start without attaching to logs"
bin/start
```
</Step>
</Steps>

<Info>

Toolkit menggunakan `docker compose` untuk mengelola kontainer Docker Overleaf. Toolkit menyediakan serangkaian skrip yang membungkus `docker compose` dan menangani sebagian besar detail untuk Anda.

</Info>

Jika semuanya berjalan lancar, Anda seharusnya dapat melihat halaman login instance Overleaf baru Anda dengan membuka [http://127.0.0.1/](http://127.0.0.1/) atau [http://localhost/](http://localhost/) di browser Anda. Jika Anda mengubah `OVERLEAF_LISTEN_IP` atau `OVERLEAF_PORT`, buka alamat dari tabel di langkah **Alamat dan port listen**, misalnya `http://<server-ip>:8080`.

Untuk memeriksa alamat dan port tempat antarmuka web dipublikasikan, jalankan:

```text title="Show the published port"
bin/docker-compose port sharelatex 80
```

Output-nya, misalnya `0.0.0.0:8080`, menunjukkan alamat IP host dan port yang digunakan. Jika menampilkan `127.0.0.1`, instance hanya dapat dijangkau dari server itu sendiri.

<Warning>

Bergantung pada konfigurasi jaringan Anda dan lokasi hosting instance Overleaf Anda, Anda mungkin perlu melakukan perubahan konfigurasi tambahan. Lihat pengaturan Toolkit untuk detail lebih lanjut: [toolkit-settings.md](/id/on-premises/configuration/overleaf-toolkit/toolkit-settings  "mention")

</Warning>
