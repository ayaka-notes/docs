Overleaf berjalan di atas Docker. Anda harus menginstal:

* Docker Engine (Docker CE)
* Plugin Docker Compose (`docker compose`, v2)

Langkah-langkah ini ditujukan untuk Ubuntu LTS terbaru (20.04/22.04/24.04).

<Warning>

Hindari menginstal `docker.io` dari repositori apt bawaan Ubuntu.\
Gunakan repositori resmi Docker agar Anda mendapatkan versi Docker terbaru dan plugin `docker compose`.

</Warning>

Dokumen resminya berasal dari: [https://docs.docker.com/engine/install/ubuntu/](https://docs.docker.com/engine/install/ubuntu/).

<Steps>
<Step title="1) Hapus paket lama/yang berkonflik (jika ada)">
Jika Docker sebelumnya diinstal dari sumber lain, hapus terlebih dahulu:

```bash wrap
sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-compose-v2 docker-doc podman-docker containerd runc | cut -f1)
```

Perintah ini aman dijalankan meskipun beberapa paket tidak terinstal.
</Step>

<Step title="2) Tambahkan repositori apt resmi Docker">
Instal prasyarat:

```bash
sudo apt update
sudo apt install -y ca-certificates curl
```

Tambahkan kunci GPG Docker:

```bash wrap
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```

Tambahkan repositori:

```bash wrap
# Add the repository to Apt sources:
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Signed-By: /etc/apt/keyrings/docker.asc
EOF

sudo apt update
```
</Step>

<Step title="3) Instal Docker Engine + plugin Compose">
Instal Docker dan plugin Compose:

```bash wrap
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

Jalankan Docker saat boot:

```bash
sudo systemctl enable --now docker
```
</Step>

<Step title="4) Verifikasi instalasi">
Perintah-perintah berikut seharusnya berjalan tanpa error:

```bash
docker --version
docker compose version
sudo docker run --rm hello-world
docker ps
```
</Step>

<Step title="5) (Opsional) Jalankan Docker tanpa sudo">
Tambahkan pengguna Anda ke grup `docker`:

```bash
sudo usermod -aG docker $USER
```

Kemudian **logout lalu login kembali**, atau jalankan:

```bash
newgrp docker
```

Sekarang perintah ini seharusnya berfungsi tanpa `sudo`:

```bash
docker ps
```

<Danger>

Grup `docker` memiliki akses yang setara dengan root pada host.\
Hal ini wajar untuk instalasi Overleaf pada umumnya, dan terutama relevan jika Anda mengaktifkan Sandboxed Compiles.

</Danger>
</Step>
</Steps>

### Langkah selanjutnya

Setelah Docker berfungsi, lanjutkan dengan langkah-langkah instalasi Toolkit di [Menggunakan Toolkit](/id/on-premises/installation/using-the-toolkit).
