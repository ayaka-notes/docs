<Steps>
<Step title="Instal tool command-line">
Jalankan di **Ubuntu**, menggunakan kata sandi Linux yang Anda buat di langkah 0:

```bash
sudo apt update
sudo apt install -y git ca-certificates curl perl gawk openssl
```

Ubuntu sudah menyediakan Bash, GNU sed, dan coreutils. Berbeda dengan macOS, Ubuntu tidak memerlukan Homebrew atau instalasi GNU sed terpisah.
</Step>

<Step title="Clone repositori Ayakaleaf Toolkit">
Simpan Toolkit dan datanya di filesystem Linux Ubuntu, di bawah direktori home Anda:

```bash
cd "$HOME"
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

Hindari `/mnt/c`, `/mnt/d`, OneDrive, dan direktori sementara untuk database dan data proyek yang aktif. Path filesystem Linux menyediakan izin dan perilaku filesystem yang diharapkan oleh kontainer, serta menghindari overhead lintas filesystem; lihat [panduan filesystem Microsoft](https://learn.microsoft.com/en-us/windows/wsl/filesystems).

<Warning>

Jika direktori tersebut sudah berisi instalasi, gunakan apa adanya, atau pilih direktori lain untuk instance baru. Jangan mengganti konfigurasi atau data deployment yang sudah ada.

</Warning>
</Step>
</Steps>
