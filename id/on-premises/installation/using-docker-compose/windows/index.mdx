Di bagian ini kita menjalankan Ayakaleaf Pro secara lokal di Windows dengan WSL 2, Ubuntu, Docker Desktop, dan [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). Panduan ini menggunakan `http://localhost:8080`, menyimpan data di direktori home Ubuntu, dan mengaktifkan sandboxed compiles.

Aplikasi, MongoDB, Redis, dan TeX Live berjalan di kontainer Linux yang dikelola oleh Docker Desktop. Jalankan perintah Toolkit di Ubuntu; buka aplikasi di browser Windows Anda. [Langkah 0](/id/on-premises/installation/using-docker-compose/windows/0.-setup-wsl-and-docker-desktop) menjelaskan bagaimana bagian Windows dan Linux saling terhubung, dimulai dari menginstal WSL.

Anda dapat menggunakan Windows untuk instance lokal atau menjaganya tetap berjalan terus-menerus dengan pengaturan ketersediaan di langkah 6. Untuk server bersama dan server produksi, kami merekomendasikan [panduan Linux](/id/on-premises/installation/using-docker-compose/linux), dengan HTTPS, backup, dan kontrol akses. Mode tidur Windows, penghentian Docker Desktop, dan penghentian WSL akan menginterupsi instance lokal ini; lihat [Menjaga instance tetap tersedia](/id/on-premises/installation/using-docker-compose/windows/6.-post-installation-tasks#keep-the-instance-available).

## Sebelum memulai {#before-you-start}

Anda memerlukan:

* Versi Windows dan prosesor yang didukung oleh [Docker Desktop for Windows](https://docs.docker.com/desktop/setup/install/windows-install/), dengan virtualisasi hardware diaktifkan. Panduan ini menggunakan Windows 11 di x86-64.
* Izin untuk mengaktifkan WSL dan menginstal perangkat lunak. WSL harus versi 2.1.5 atau lebih baru, dengan Ubuntu berjalan dalam mode WSL 2.
* Memori yang cukup untuk Windows dan kontainer. Untuk instance lokal kecil, 4 CPU dan memori 8 GB yang tersedia untuk Docker adalah titik awal yang disarankan, bukan batas minimum hasil pengukuran.
* Ruang penyimpanan kosong di disk Windows yang menyimpan data WSL dan Docker. Sediakan minimal 40 GB untuk penyiapan TeX Live lengkap ditambah data proyek; image basic di [langkah 5](/id/on-premises/installation/using-docker-compose/windows/5.-personalizing-your-instance) lebih kecil dan cocok untuk uji deployment awal. Versi image tambahan membutuhkan ruang tambahan.
* Akses jaringan ke GitHub, GitHub Container Registry (`ghcr.io`), dan Docker Hub untuk meng-clone Toolkit dan mengunduh image.

Blok **PowerShell** dijalankan di Windows. Blok **Bash** dan perintah `bin/` dijalankan di Ubuntu kecuali dinyatakan lain. Jangan menjalankan skrip Toolkit di PowerShell atau Git Bash Windows.
