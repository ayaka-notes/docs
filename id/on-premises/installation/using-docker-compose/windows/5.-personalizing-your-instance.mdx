---
title: 5. Menyesuaikan instance Anda
description: Atur port, URL situs, dan image TeX Live, aktifkan sandboxed compiles, dan jalankan Ayakaleaf Pro di WSL 2.
icon: square-sliders
---

Jalankan perintah dan edit file di **Ubuntu**, dari `~/ayakaleaf-toolkit`.

<Steps>
<Step title="Pengaturan kontainer">
Edit entri yang sudah ada di `config/overleaf.rc`:

```bash title="config/overleaf.rc"
PROJECT_NAME=ayakaleaf-wsl
SERVER_PRO=true
OVERLEAF_LISTEN_IP=127.0.0.1
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
DOCKER_SOCKET_PATH=/var/run/docker.sock
```

Pertahankan path data default serta layanan MongoDB dan Redis bawaan. Port `8080` digunakan untuk browser Windows lokal; bind ke `127.0.0.1` menjaganya tetap lokal. Sandboxed compiles menggunakan kontainer Linux terpisah untuk setiap kompilasi, alih-alih menjalankan TeX di dalam kontainer aplikasi. Socket Docker memungkinkan aplikasi membuat kontainer-kontainer tersebut, dan Toolkit menyediakan path host untuk data kompilasi di bawah `data/overleaf/data/compiles`.
</Step>

<Step title="Pengaturan aplikasi">
Di `config/variables.env`, atur nilai-nilai berikut, dan ganti entri aktif dengan nama yang sama:

```dotenv title="config/variables.env"
OVERLEAF_SITE_URL=http://localhost:8080
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES="TeX Live 2026"
```

Image full mencakup paket dan font yang diperlukan untuk berbagai jenis proyek. Sediakan ruang penyimpanan kosong minimal 40 GB untuk image ini dan aplikasi, ditambah ruang untuk data proyek dan pembaruan di masa mendatang.

Untuk uji deployment cepat, gunakan image **basic** yang lebih kecil sebagai gantinya. Image ini cukup untuk uji artikel sederhana di langkah 6, tetapi tidak mencakup set paket dan font lengkap:

```dotenv
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-basic:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-basic:2026.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES="TeX Live 2026 Basic"
```

Pilih salah satu set ini, tanpa key aktif yang duplikat. [Dockerfile](https://github.com/ayaka-notes/texlive-full/blob/main/texlive/2026/Dockerfile.basic) image basic mencakup `latexmk`, XeTeX, dan `fontspec`, tetapi tidak mencakup `ctex` atau koleksi font lengkap. Paket LaTeX yang tidak ada di image basic tidak dengan sendirinya menandakan masalah sandbox.

Buat session secret:

```bash
openssl rand -hex 32
```

Tambahkan hasilnya sebagai `OVERLEAF_SESSION_SECRET` di `config/variables.env`. Simpan juga secret invite-token yang telah dibuat. Untuk instance lokal tanpa email, biarkan pengaturan SMTP dan `OVERLEAF_EMAIL_FROM_ADDRESS` tidak diatur.
</Step>

<Step title="Jalankan instance Anda">
```bash
bin/up -d
```

Toolkit menjalankan MongoDB, menginisialisasi replica set-nya, mengunduh image TeX Live yang dipilih, lalu menjalankan Redis dan aplikasi. Proses ini mungkin tampak berhenti sejenak saat image berukuran besar sedang diunduh. Jangan menjalankan `bin/up` kedua selama yang pertama masih berjalan.

Di terminal Ubuntu lain, periksa:

```bash
cd "$HOME/ayakaleaf-toolkit"
bin/docker-compose ps
bin/docker-compose logs --tail=100 mongo
bin/docker-compose logs --tail=100 -f sharelatex
```

Tekan `Ctrl+C` untuk berhenti mengikuti log; kontainer yang berjalan di latar belakang tetap berjalan. Jika startup gagal di MongoDB, ikuti [MongoDB gagal dijalankan](/id/on-premises/installation/using-docker-compose/windows/troubleshooting#mongodb-fails-to-start) sebelum mencoba lagi. Jangan menghapus direktori datanya untuk me-reset instalasi yang sudah ada.

Periksa port dan halaman first-run:

```bash
bin/docker-compose port sharelatex 80
curl -I http://localhost:8080/launchpad
```

Port seharusnya `127.0.0.1:8080`. Tunggu inisialisasi aplikasi selesai jika permintaan HTTP awalnya gagal.
</Step>

<Step title="Buka instance dari Windows">
Di **browser Windows** Anda, buka [http://localhost:8080/launchpad](http://localhost:8080/launchpad). Gunakan alamat ini juga di Windows, bukan alamat IP WSL sementara.

Untuk memeriksa akses HTTP Windows secara terpisah dari browser, jalankan di **PowerShell**:

```powershell
curl.exe -I http://localhost:8080/launchpad
```

Jika Ubuntu dapat menjangkau halaman tetapi Windows tidak, lihat [Windows tidak dapat membuka localhost](/id/on-premises/installation/using-docker-compose/windows/troubleshooting#windows-cannot-open-localhost).
</Step>
</Steps>
