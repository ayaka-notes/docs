---
title: 4. Dapatkan Image Ayakaleaf Pro
description: Alihkan Toolkit di Ubuntu pada WSL 2 ke image publik Ayakaleaf Pro.
icon: split
---

Ayakaleaf Pro adalah image Docker gratis di [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Anda tidak memerlukan akun, login, atau lisensi komersial Overleaf untuk melakukan pull.

Buka `config/overleaf.rc` dan atur:

```bash title="config/overleaf.rc"
SERVER_PRO=true
```

Saat berikutnya Anda menjalankan `bin/up`, Toolkit akan melakukan pull `ghcr.io/ayaka-notes/overleaf-pro` dengan versi dari `config/version`, alih-alih Overleaf Community Edition resmi.

Image ini di-build untuk `arm64` dan `amd64`, dan Docker memilih yang sesuai dengan arsitektur engine Docker.
