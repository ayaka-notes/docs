Toolkit sama seperti di Linux. Tata letaknya, direktori `config/`, dan perintah `bin/` dijelaskan di [2. Kenali Toolkit](/id/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) pada panduan Linux.

Di Windows, perhatikan perbedaan berikut:

* Jalankan perintah `bin/` di **Ubuntu Bash**, dari `~/ayakaleaf-toolkit`. Perintah yang ditandai **PowerShell** dijalankan di Windows.
* Jalankan Docker Desktop dan aktifkan WSL Integration untuk Ubuntu sebelum menggunakan `bin/up`, `bin/start`, atau `bin/docker-compose`.
* Pertahankan file konfigurasi dengan akhir baris Linux (LF). Edit file tersebut dengan `nano` di Ubuntu atau editor yang terhubung ke WSL. Akhir baris CRLF dapat menyebabkan error Bash.
* `bin/doctor` menjalankan pemeriksaan Linux di dalam Ubuntu. Peringatan bahwa Anda belum login ke `quay.io` tidak berlaku untuk image publik `ghcr.io/ayaka-notes/overleaf-pro`. Peringatan lainnya tetap perlu diperhatikan.

```bash
bin/doctor
```
