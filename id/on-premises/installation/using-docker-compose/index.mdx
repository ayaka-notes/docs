Docker Compose di satu server adalah cara yang direkomendasikan untuk men-deploy Ayakaleaf Pro. Anda menjalankannya melalui [Toolkit](https://github.com/ayaka-notes/toolkit): sekumpulan skrip yang membungkus `docker compose` dan membaca pengaturan Anda dari satu direktori `config/`, sehingga `bin/up` menggantikan `docker compose up`.
