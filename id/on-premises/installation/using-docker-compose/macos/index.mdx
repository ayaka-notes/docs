Di bagian ini kita menjalankan Ayakaleaf Pro secara lokal di Mac Anda dengan Docker Desktop dan [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). Panduan ini menggunakan `http://localhost:8080`, menyimpan data di direktori home Anda, dan melakukan kompilasi dengan TeX Live 2026 di kontainer sandbox.

Docker Desktop menjalankan aplikasi, MongoDB, Redis, dan compiler TeX Live di mesin virtual Linux. Anda tidak perlu menginstal MongoDB, Redis, atau MacTeX di macOS itu sendiri.

Gunakan penyiapan ini untuk penggunaan pribadi dan pengujian lokal. Untuk layanan bersama yang selalu aktif, kami merekomendasikan [panduan Linux](/id/on-premises/installation/using-docker-compose/linux), dengan HTTPS, backup, dan kontrol akses. Instance tidak tersedia saat Mac dalam mode tidur atau Docker Desktop dihentikan, lihat [Menjaga instance tetap tersedia](/id/on-premises/installation/using-docker-compose/macos/6.-post-installation-tasks#keep-the-instance-available).

## Sebelum memulai {#before-you-start}

Anda memerlukan:

* Versi macOS yang didukung oleh [Docker Desktop for Mac](https://docs.docker.com/desktop/setup/install/mac-install/).
* Git, [Homebrew](https://brew.sh/), dan GNU sed. Toolkit menggunakan opsi GNU sed yang tidak diterima oleh BSD sed bawaan macOS.
* Sumber daya yang cukup untuk macOS dan Docker. Untuk instance lokal kecil, mulailah dengan 4 CPU dan memori 8 GB yang dialokasikan ke Docker Desktop. Ini adalah titik awal yang disarankan, bukan batas minimum hasil pengukuran.
* Ruang penyimpanan kosong minimal 40 GB untuk image TeX Live lengkap, ditambah ruang untuk proyek Anda. Periksa ruang kosong di Mac dan batas penggunaan disk Docker Desktop. Mulailah dengan satu versi TeX Live: setiap versi tambahan membutuhkan ruang yang kurang lebih sama besarnya.

Image aplikasi dan TeX Live dipublikasikan untuk `arm64` dan `amd64`. Di Apple silicon, biarkan Docker memilih image ARM native dan jangan memaksakan `platform: linux/amd64`.
