<Steps>
<Step title="Periksa Git dan Homebrew">
```bash
git --version
brew --version
```

Jika macOS meminta Anda menginstal Command Line Tools saat menjalankan Git, instal terlebih dahulu. Jika Homebrew belum ada, instal dengan [petunjuk resmi](https://brew.sh/).
</Step>

<Step title="Letakkan GNU sed di PATH">
Skrip Toolkit menggunakan opsi GNU sed yang ditolak oleh BSD sed bawaan macOS. Instal [GNU sed](https://formulae.brew.sh/formula/gnu-sed) dan letakkan di urutan pertama `PATH` di terminal ini:

```bash
brew install gnu-sed
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
sed --version
```

Perintah terakhir seharusnya menampilkan **GNU sed**.

Alias seperti `alias sed=gsed` tidak cukup: Toolkit menjalankan skrip Bash, yang tidak melihat alias dari shell interaktif Anda. Anda tidak perlu mengganti `/usr/bin/sed`.

Jalankan kembali baris `export PATH=...` di setiap terminal baru yang Anda gunakan untuk Toolkit, atau tambahkan ke file startup shell Anda setelah inisialisasi Homebrew.
</Step>

<Step title="Clone repositori Ayakaleaf Toolkit">
Pilih direktori yang persisten. Hindari `/tmp`, drive lepas-pasang, dan folder yang disinkronkan ke cloud seperti iCloud Drive untuk database dan data proyek yang aktif. Panduan ini menggunakan `~/ayakaleaf-toolkit`:

```bash
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

<Warning>

Jika direktori tersebut sudah berisi instalasi, gunakan apa adanya, atau pilih direktori lain untuk instance baru. Jangan menginisialisasi konfigurasi baru di atas deployment yang sudah ada.

</Warning>
</Step>
</Steps>
