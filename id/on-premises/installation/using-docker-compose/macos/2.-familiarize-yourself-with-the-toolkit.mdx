Toolkit sama saja di macOS dan Linux. Tata letaknya, direktori `config/`, dan perintah `bin/` dijelaskan di [2. Kenali Toolkit](/id/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) pada panduan Linux.

Di macOS, perhatikan tiga perbedaan berikut:

* Jalankan skrip dari terminal yang menempatkan GNU sed di urutan pertama `PATH`, lihat [1. Mengunduh Toolkit](/id/on-premises/installation/using-docker-compose/macos/1.-download-the-toolkit).
* Jalankan Docker Desktop sebelum Anda menjalankan skrip yang berkomunikasi dengan Docker, seperti `bin/up`, `bin/start`, atau `bin/docker-compose`.
* `bin/doctor` menyertakan pemeriksaan yang diwarisi dari Overleaf Toolkit resmi. Peringatan `This system seems to not be Linux` darinya memang wajar di macOS, dan peringatan bahwa Anda belum login ke `quay.io` tidak berlaku untuk image publik `ghcr.io/ayaka-notes/overleaf-pro`. Masalah lain dalam laporan tetap perlu diperhatikan.
