---
title: 3. Inisialisasi konfigurasi
description: Buat file konfigurasi Toolkit di Mac Anda dengan bin/init.
icon: circle-play
---

Dari direktori Toolkit, di terminal dengan GNU sed di `PATH`, jalankan:

```bash
bin/init
```

`bin/init` membuat tiga file:

| File | Fungsi |
| --- | --- |
| `config/overleaf.rc` | Pengaturan kontainer, port yang dipublikasikan, dan lokasi data |
| `config/variables.env` | Pengaturan aplikasi dan secret |
| `config/version` | Versi image aplikasi |

Perintah ini juga membuat `OVERLEAF_INVITE_TOKEN_SECRET` di `config/variables.env`. Simpan nilainya, dan jangan memublikasikan file ini atau meng-commit-nya ke version control.

Pertahankan versi yang dipilih Toolkit untuk instalasi baru. Untuk mengubah versi instance yang sudah ada di kemudian hari, ikuti [Meng-upgrade deployment Anda](/id/on-premises/maintenance/upgrading-your-deployment).

<Warning>

Jika `bin/init` berhenti dengan `sed: ... invalid command code`, perintah tersebut berjalan dengan BSD sed bawaan macOS. Proses yang gagal seperti ini dapat meninggalkan ketiga file di `config/` dengan `OVERLEAF_INVITE_TOKEN_SECRET` yang kosong, dan menjalankan `bin/init` lagi kemudian akan melaporkan `Config files already exist`. Lihat [Pemecahan masalah](/id/on-premises/installation/using-docker-compose/macos/troubleshooting#initialization-fails-with-invalid-command-code).

</Warning>
