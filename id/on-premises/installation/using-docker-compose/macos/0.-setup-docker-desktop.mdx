Ayakaleaf Pro berjalan di Docker. Di Mac, Anda menggunakan Docker Desktop, yang menjalankan engine Docker di mesin virtual Linux.

<Steps>
<Step title="Instal dan jalankan Docker Desktop">
Instal build [Docker Desktop](https://docs.docker.com/desktop/setup/install/mac-install/) untuk Mac Anda (Apple silicon atau Intel), buka, dan tunggu hingga engine berjalan. Anda juga dapat menjalankannya dari Terminal:

```bash
open -a Docker
```
</Step>

<Step title="Periksa engine Docker">
Jalankan perintah berikut di Terminal:

```bash
docker context show
docker info
docker compose version
```

Context harus mengarah ke engine Docker Desktop lokal Anda, biasanya `desktop-linux`. Jika context lain yang dipilih, beralihlah ke Docker Desktop sebelum melanjutkan:

```bash
docker context use desktop-linux
```

`docker info` harus menampilkan bagian **Server**. `docker --version` saja hanya menunjukkan bahwa client sudah terinstal.
</Step>

<Step title="Periksa sumber daya dan berbagi file">
Di **Settings** Docker Desktop, periksa batas CPU, memori, dan disk berdasarkan [Sebelum memulai](/id/on-premises/installation/using-docker-compose/macos#before-you-start), serta pengaturan berbagi file, lihat [pengaturan Docker Desktop](https://docs.docker.com/desktop/settings-and-maintenance/settings/).

Panduan ini menyimpan Toolkit di bawah `/Users`, yang dibagikan oleh Docker Desktop secara default. Jika Anda menggunakan lokasi lain dan `bin/up` gagal dengan `Mounts denied`, tambahkan direktori tersebut ke berbagi file.
</Step>

<Step title="Periksa socket Docker untuk sandboxed compiles">
Toolkit me-mount `/var/run/docker.sock` ke dalam aplikasi, agar aplikasi dapat menjalankan kontainer TeX Live terpisah untuk setiap kompilasi. Pertahankan `DOCKER_SOCKET_PATH=/var/run/docker.sock` di `config/overleaf.rc`.

Docker CLI di macOS mungkin terhubung melalui `~/.docker/run/docker.sock`. Itu adalah endpoint client di Mac, bukan alasan untuk mengubah sumber mount Toolkit: compiler memerlukan socket engine sebagaimana dilihat oleh kontainer Linux.

Jika `/var/run/docker.sock` tidak ada di Mac, aktifkan **Allow the default Docker socket to be used** di **Settings → Advanced**, lihat [persyaratan izin Docker](https://docs.docker.com/desktop/setup/install/mac-permission-requirements/).

<Danger>

Jangan jalankan `chmod 777` pada socket untuk mengatasi error. Akses ke socket Docker setara dengan akses root ke VM Docker.

</Danger>
</Step>
</Steps>
