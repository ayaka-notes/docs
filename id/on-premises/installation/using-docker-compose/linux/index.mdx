Di bagian ini kami akan memandu Anda menginstal Docker, mengunduh Toolkit dari GitHub, mengenal beberapa perintah Toolkit, dan mengonfigurasi beberapa pengaturan dasar. Di akhir bagian ini, Anda seharusnya sudah memiliki instance Overleaf on-premises yang berjalan.

Langkah-langkahnya ditujukan untuk Ubuntu LTS terbaru. Di distribusi lain, instal Docker Engine dan plugin Compose seperti yang dijelaskan di [dokumentasi Docker](https://docs.docker.com/engine/install/), lalu lanjutkan dengan [1. Mengunduh Toolkit](/id/on-premises/installation/using-docker-compose/linux/1.-download-the-toolkit).

<Info>

Secara default, instance hanya menerima koneksi dari server itu sendiri, di `http://localhost`. Untuk membukanya dari komputer lain atau pada port lain, atur `OVERLEAF_LISTEN_IP` dan `OVERLEAF_PORT` di `config/overleaf.rc`, seperti yang dijelaskan di [5. Menyesuaikan instance Anda](/id/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance).

</Info>
