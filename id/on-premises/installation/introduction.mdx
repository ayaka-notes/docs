Seperti Overleaf Server Pro, Ayakaleaf Pro kami hadir sebagai kontainer Docker dan merupakan pengganti langsung (drop-in replacement) yang juga menyertakan fitur-fitur seperti SSO melalui LDAP dan SAML2, keamanan yang lebih baik, lacak perubahan, komentar, versi TeX Live yang telah kami optimalkan, templat, dan panel administrasi.

* Jika Anda hanya ingin menguji fitur Ayakaleaf Pro atau mencoba demo, Anda dapat mengikuti tutorial [using-the-github-codespace.md](/id/on-premises/installation/using-the-github-codespace  "mention"). Lingkungan demo menggunakan instalasi TeX Live minimal, sehingga beberapa proyek Anda mungkin tidak berhasil dikompilasi.
* Jika Anda belum pernah men-deploy versi Overleaf apa pun sebelumnya, silakan lihat [Setup Docker](/id/on-premises/installation/setup-docker) untuk menginstal Docker Engine terlebih dahulu, lalu instal Overleaf [using-the-toolkit](/id/on-premises/installation/using-the-toolkit  "mention").
* Jika Anda sudah men-deploy Overleaf Community Edition, silakan lihat [migrate-from-existing.md](/id/on-premises/installation/migrate-from-existing  "mention") untuk bermigrasi ke Ayakaleaf Pro.
* Jika Anda lebih suka menggunakan agen seperti Claude atau Codex, Anda dapat melihat: [using-claude-or-codex.md](/id/on-premises/installation/using-claude-or-codex  "mention").
* Jika Anda perlu melakukan deployment di lingkungan offline atau air-gapped, silakan lihat: [air-gapped-offline-deployments.md](/id/on-premises/installation/air-gapped-offline-deployments  "mention").
* Jika Anda adalah pengguna Server Pro yang sudah ada, silakan buka issue untuk memberi tahu kami sebelum bermigrasi ke Ayakaleaf Pro, karena data templat disimpan dalam format yang sedikit berbeda. Kami dengan senang hati akan membantu Anda bermigrasi dari Server Pro ke Ayakaleaf Pro secara gratis.
* Jika suatu saat Anda bosan dengan Ayakaleaf Pro dan ingin kembali ke Overleaf Community Edition resmi, hal itu didukung sepenuhnya. Tidak ada data Anda yang akan hilang. Bagi pengguna Overleaf Toolkit resmi, cukup hapus file YAML override Anda. Bagi pengguna toolkit ayaka-notes, nonaktifkan opsi `SERVER_PRO`. Semuanya kemudian akan kembali ke Community Edition standar.

### Persyaratan perangkat keras

Kami telah melakukan pengujian dan menemukan bahwa jika Anda menjalankan Overleaf di server dengan 2 core dan RAM 2 GB, komponen intinya—yang sebagian besar berbasis Node.js—akan menggunakan sekitar 1 GB memori. Redis dan MongoDB mungkin memerlukan tambahan 0,5 GB, sementara menjalankan kontainer Docker sandbox untuk kompilasi dapat menggunakan 0,3 GB lagi. Artinya, server dengan 2 core dan 2 GB secara realistis hanya dapat menangani sekitar satu kompilasi bersamaan dalam satu waktu.

* Persyaratan perangkat keras minimum untuk menginstal Ayakaleaf Pro adalah CPU 2 core dan RAM 3 GB.
* Karena ukuran image TeX Live kami, diperlukan penyimpanan minimal 40 GB untuk mengaktifkan kompilasi sandbox.
* Jika Anda ingin menginstal seluruh image TeX Live dari 2020 hingga 2026, pastikan Anda memiliki ruang disk kosong minimal 150 GB.

Berikut beberapa konfigurasi perangkat keras yang disarankan untuk berbagai skenario penggunaan:

| Kasus Penggunaan                                             | Konfigurasi yang Disarankan                                                                            |
| ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Penggunaan pribadi, dengan kolaborasi sesekali          | 2 core CPU, RAM 4 GB, penyimpanan 80 GB                                                                 |
| Tim kecil, hingga 10 pengguna dengan kolaborasi ringan | 2 core CPU, RAM 8 GB, penyimpanan 256 GB                                                                |
| Tim berukuran sedang, hingga 100 pengguna                  | 4 core CPU, RAM 16 GB, penyimpanan 1 TB                                                                 |
| Deployment berskala besar atau universitas                | Deployment klaster terdistribusi dengan penyimpanan S3; silakan hubungi kami jika Anda memerlukan bantuan deployment |

### Persyaratan perangkat lunak

Untuk persyaratan perangkat lunak, kami menyarankan penggunaan versi Ubuntu yang terbaru dan stabil (misalnya Ubuntu 24.04 pada 2025–2026, Ubuntu 22.04 pada 2023–2024) bersama dengan versi stabil terbaru Docker.

<Info>

Stabilitas adalah yang utama: pilih Ubuntu LTS terbaru yang sudah dirilis cukup lama, bukan yang baru saja dirilis. Misalnya, per Oktober 2026, Ubuntu 26.04 tidak didukung: versi ini menggunakan kernel Linux 7.0, sedangkan MongoDB menolak berjalan pada kernel Linux 6.19 hingga 7.0.13 ([detail](https://www.mongodb.com/docs/manual/administration/production-notes/)), jadi silakan gunakan Ubuntu 24.04.

</Info>

Kami tidak menyarankan men-deploy Ayakaleaf Pro di Windows atau sistem operasi lain yang tidak didukung seperti CentOS, karena Anda mungkin akan menemui masalah kompatibilitas atau masalah tak terduga selama instalasi dan pengoperasian.

Namun, jika Anda ingin mencoba men-deploy Ayakaleaf Pro di sistem berbasis ARM atau macOS, kami mempersilakan Anda untuk berbagi pengalaman dan masukan dengan komunitas.

### Performa LaTeX

LaTeX adalah program single-threaded, artinya hanya dapat menggunakan satu core CPU dalam satu waktu. Saat mengompilasi satu dokumen, performa terutama dibatasi oleh kecepatan clock single-core CPU. Oleh karena itu, semakin cepat performa single-core CPU Anda, semakin cepat pula Anda dapat mengompilasi dokumen. Lebih banyak core CPU hanya bermanfaat ketika beberapa pengguna mengompilasi dokumen secara bersamaan.

Sebagai contoh, dengan [templat ThuThesis](https://www.overleaf.com/latex/templates/thuthesis-tsinghua-university-thesis-latex-template/cfwgcxtvkbsx), waktu kompilasi sekitar 6 detik pada Intel Core i9-14900K (5,6 GHz), sedangkan pada instance Azure Standard D2as v5 (2 vCPU, RAM 8 GiB) yang ditenagai AMD EPYC 7763 (3,2 GHz) dibutuhkan sekitar 13 detik.

Tentu saja, performa kompilasi sebenarnya bergantung pada konfigurasi perangkat keras Anda. Sebagian besar CPU server tidak berjalan pada kecepatan clock setinggi 14900K, sehingga Anda perlu menyeimbangkan antara biaya dan kecepatan kompilasi.

Selain itu, kami juga telah melakukan analisis mendalam tentang performa kompilasi LaTeX. Jika Anda tertarik, silakan lihat blog kami [Overleaf Benchmark: A Deep Research of Concurrent LaTeX Compilation in Overleaf (SaaS and Self-host)](/id/blog/2026/overleaf-benchmark  "mention").
