Cara termudah untuk mencoba Ayakaleaf Pro adalah dengan menggunakan GitHub Codespace, di mana semua variabel lingkungan sudah dikonfigurasi sebelumnya sehingga Anda dapat langsung menggunakannya.

<Warning>

Saat Anda menjalankan kontainer Docker menggunakan GitHub Codespaces, Codespace tidak akan mati secara otomatis dan akan terus **ditagih**. Untuk aturan penagihan GitHub Codespaces, silakan lihat [aturan penagihan github codespaces](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces).

Untuk mengelola GitHub Codespaces Anda, silakan kunjungi [https://github.com/codespaces](https://github.com/codespaces). Jika Anda tidak lagi membutuhkannya, segera hapus Codespace Anda.

</Warning>

Kami telah **mengonfigurasi sebelumnya** fitur-fitur berikut:

* [x] Kompilasi LaTeX dalam sandbox dengan TeXLive **Basic** (2024-2026)
* [x] Impor/Ekspor Pandoc (Fitur di Platform SaaS)
* [x] Python Script Runner (Fitur di Platform SaaS)
* [x] Dukungan Git-Bridge (Fitur di Server Pro)
* [x] Pencarian Referensi Lanjutan (Fitur di Platform SaaS)
* [x] Panel Admin (Manajemen Pengguna/Proyek global)
* [x] Track Changes (Dengan Panel Review dan Komentar)
* [x] Riwayat Proyek Lengkap (Dengan Pemulihan dan Unduhan)
* [x] Symbol Palette (Fitur di Server Pro/Platform SaaS)

<Warning>

GitHub Codespaces standar menyediakan penyimpanan 32 GB. Ini tidak cukup untuk instalasi `texlive-full` kami. Untuk mencoba image lengkap, ajukan tiket dukungan GitHub untuk mendapatkan Codespace dengan large runner (8 core+).

</Warning>

Sinkronisasi GitHub, LDAP, OAuth, SSO, Integrasi Zotero, dan fitur lainnya _**tidak dikonfigurasi**_ di playground ini. Anda dapat merujuk ke [pengaturan toolkit](/id/on-premises/configuration/overleaf-toolkit/toolkit-settings) untuk detail lebih lanjut tentang cara mengonfigurasi fitur-fitur ini di deployment Anda sendiri.

<Steps>
<Step title="Buat GitHub Codespace Anda">
Klik tombol berikut untuk membuat GitHub Codespace Anda. Dari segi konfigurasi server, **2 core dengan RAM 8 GB** umumnya sudah cukup untuk pengujian. Jika Anda berencana menggunakan [**TeX Live Full**](https://github.com/ayaka-notes/texlive-full), kami menyarankan memilih konfigurasi **8 core 64GB**.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/ayakaleaf-pro-playground)
</Step>

<Step title="Inisialisasi Instans Overleaf">
Setelah codespace Anda siap, jalankan perintah berikut di bash untuk menginisialisasi instans Overleaf Anda.

```bash title="bash"
./init.sh
```

#### Menggunakan Image TeXLive Full

Jika Anda memiliki akses ke GitHub Codespaces 8-core/64 GB, Anda dapat menggunakan image TeXLive Full di playground ini. Anda dapat mengubah variabel lingkungan berikut di file `toolkit/config/variables.env` untuk menggunakan image TeXLive Full alih-alih image TeXLive Basic.

```dotenv wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1, ghcr.io/ayaka-notes/texlive-full:2024.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025, Texlive 2024
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```

Setelah mengubah variabel lingkungan, Anda perlu memulai ulang toolkit agar perubahan diterapkan. Anda dapat menjalankan perintah berikut untuk memulai ulang toolkit.

```bash
cd toolkit && bin/up -d
```
