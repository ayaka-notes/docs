---
title: 2. Buat namespace dan secret
description: Buat namespace dan secret yang dibutuhkan Ayakaleaf Pro.
icon: key
---

Semuanya ditempatkan di namespace `overleaf`:

```bash
kubectl create namespace overleaf
```

Ayakaleaf Pro membaca secret-nya dari variabel lingkungan. Buat secret tersebut sekali dan simpan di sebuah Secret:

```bash wrap
HISTORY=$(openssl rand -hex 32)
kubectl -n overleaf create secret generic overleaf-secrets \
  --from-literal=OVERLEAF_INVITE_TOKEN_SECRET="$(openssl rand -base64 32)" \
  --from-literal=OVERLEAF_SESSION_SECRET="$(openssl rand -hex 32)" \
  --from-literal=WEB_API_PASSWORD="$(openssl rand -hex 32)" \
  --from-literal=STAGING_PASSWORD="$HISTORY" \
  --from-literal=V1_HISTORY_PASSWORD="$HISTORY" \
  --from-literal=CRYPTO_RANDOM="$(openssl rand -hex 32)" \
  --from-literal=OT_JWT_AUTH_KEY="$(openssl rand -hex 32)"
```

| Secret                                         | Alasan                                                                                                                                               |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_INVITE_TOKEN_SECRET`                 | Wajib. Tanpanya pod berhenti dengan "Missing required secrets". Mengubahnya membatalkan undangan proyek yang tertunda.                              |
| `OVERLEAF_SESSION_SECRET`                      | Menandatangani cookie sesi. Tanpanya, setiap kali pod dimulai ulang, semua orang akan keluar.                                                       |
| `WEB_API_PASSWORD`, `CRYPTO_RANDOM`, `OT_JWT_AUTH_KEY` | Secret internal. Kontainer membuatnya setiap kali dimulai jika tidak ada; dengan lebih dari satu replika, semua replika harus menggunakannya bersama. |
| `STAGING_PASSWORD` dan `V1_HISTORY_PASSWORD`   | Secret riwayat internal; keduanya harus memiliki nilai yang **sama**.                                                                                |

<Warning>

Cadangkan Secret tersebut (`kubectl -n overleaf get secret overleaf-secrets -o yaml`) bersama data Anda. Fitur yang mengenkripsi token di MongoDB juga memerlukan kata sandi cipher-nya sendiri di Secret ini, misalnya `GITHUB_TOKEN_CIPHER_PASSWORD` untuk [Sinkronisasi GitHub](/id/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation).

</Warning>
