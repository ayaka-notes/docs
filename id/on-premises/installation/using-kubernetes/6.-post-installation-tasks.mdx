### Membuat akun administrator pertama Anda

Buka `OVERLEAF_SITE_URL` diikuti `/launchpad`, misalnya `http://192.0.2.10:30080/launchpad`, dan daftarkan akun administrator seperti di [tugas pasca-instalasi Toolkit](/id/on-premises/installation/using-the-toolkit/6.-post-installation-tasks). Kemudian buat contoh proyek dan kompilasi.

Anda juga dapat membuat pengguna dari baris perintah:

```bash
kubectl -n overleaf exec deploy/overleaf -- bash -c \
  'cd /overleaf/services/web && node modules/server-ce-scripts/scripts/create-user.mjs --admin --email=admin@example.com'
```

Perintah ini mencetak tautan untuk mengatur kata sandi.

### Memeriksa bahwa kompilasi berjalan di sandbox

Kompilasi sebuah proyek, lalu periksa node yang menjalankan pod:

```bash
kubectl -n overleaf get pod -l app=overleaf -o wide   # NODE column
# on that node:
sudo docker ps -a --filter ancestor=ghcr.io/ayaka-notes/texlive-full:2026.1
ls -ln /srv/overleaf/compiles                          # owned by uid 33 (www-data)
```

Setiap kompilasi muncul sebagai kontainer berumur pendek bernama `project-<project id>-<user id>-...`.

### Log dan shell

| Toolkit          | Kubernetes                                                               |
| ---------------- | ------------------------------------------------------------------------ |
| `bin/logs web`   | `kubectl -n overleaf exec deploy/overleaf -- tail -f /var/log/overleaf/web.log` |
| `bin/shell`      | `kubectl -n overleaf exec -it deploy/overleaf -- bash`                    |
| `bin/up`         | `kubectl apply -f .` lalu `kubectl -n overleaf rollout restart deployment/overleaf` |

Kontainer menulis satu file log per layanan di `/var/log/overleaf/` (`web.log`, `clsi.log`, `real-time.log`, `document-updater.log`, ...); `kubectl logs` menampilkan output startup.

### Tanya Jawab

<Accordion title="Kompilasi gagal atau tidak pernah selesai.">

<strong>Jawaban:</strong> Periksa, di node yang menjalankan pod, bahwa Docker berjalan dan memiliki image yang disebutkan di `TEX_LIVE_DOCKER_IMAGE`, serta bahwa `SANDBOXED_COMPILES_HOST_DIR_*` sesuai dengan path `hostPath`. `/var/log/overleaf/clsi.log` di pod menyebutkan langkah yang gagal.

</Accordion>

<Accordion title="Pengguna keluar setiap kali pod dimulai ulang.">

<strong>Jawaban:</strong> `OVERLEAF_SESSION_SECRET` tidak ada di Secret `overleaf-secrets`, lihat [langkah 2](/id/on-premises/installation/using-kubernetes/2.-create-the-namespace-and-secrets).

</Accordion>
