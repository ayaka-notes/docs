[Toolkit](/id/on-premises/installation/using-docker-compose) adalah cara yang direkomendasikan untuk menjalankan Ayakaleaf Pro di satu server. Jika Anda sudah menjalankan klaster Kubernetes, bagian ini men-deploy kontainer yang sama di klaster tersebut dengan manifest `kubectl` biasa: tanpa image tambahan, tanpa Helm chart.

Di akhir bagian ini Anda akan memiliki satu instance Ayakaleaf Pro dengan sandboxed compiles, replica set MongoDB, dan Redis, semuanya di namespace `overleaf`. Untuk menjalankan beberapa instance di belakang load balancer, lanjutkan dengan [Penskalaan horizontal](/id/on-premises/configuration/kubernetes/horizontal-scaling) setelahnya.

<Info>

Dukungan Kubernetes masih eksperimental. Kami tidak menerbitkan Helm chart atau image khusus Kubernetes. Manifest di halaman-halaman ini adalah yang kami uji di Kubernetes 1.37 (kubeadm, containerd 2.4, flannel) dengan tiga node yang masing-masing memiliki 2 vCPU dan memori 4 GB. Sesuaikan penyimpanan, jaringan, dan ingress dengan klaster Anda.

</Info>

### Bagaimana komponen-komponennya saling terkait {#how-the-pieces-fit}

| Toolkit (satu server)                        | Kubernetes                                                                       |
| -------------------------------------------- | -------------------------------------------------------------------------------- |
| `config/variables.env`                       | ConfigMap `overleaf-env` dan Secret `overleaf-secrets`                           |
| Kontainer `sharelatex`                       | Deployment `overleaf` (satu pod yang menjalankan semua layanan Overleaf)         |
| Kontainer `mongo` dan `redis`                | StatefulSet `mongo` (replica set) dan `redis`, atau layanan terkelola Anda       |
| `~/overleaf-toolkit/data/overleaf`           | PersistentVolumeClaim `overleaf-data`                                            |
| Docker di host, digunakan untuk kompilasi    | Docker Engine di setiap node yang menjalankan Ayakaleaf Pro                      |
| `bin/up`, `bin/logs`, `bin/shell`            | `kubectl apply`, `kubectl logs`, `kubectl exec`                                  |

### Yang Anda butuhkan {#what-you-need}

* Klaster Kubernetes yang dapat Anda instali paket: setiap node yang mungkin menjalankan Ayakaleaf Pro memerlukan **Docker Engine**, karena kompilasi berjalan di kontainer TeX Live yang dimulai Ayakaleaf Pro melalui `/var/run/docker.sock` milik node. Lihat [0. Siapkan node](/id/on-premises/installation/using-kubernetes/0.-prepare-the-nodes).
* StorageClass default dengan volume `ReadWriteOnce`.
* `kubectl` dan `openssl` di workstation Anda.
