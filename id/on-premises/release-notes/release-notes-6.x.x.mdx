## Ayakaleaf Pro 6.3.0

**Tanggal rilis:** 2026.10.03 (rilis ulang; awalnya dirilis pada 2026.09.24)

Lihat: [https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.3.0](https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.3.0)

<Warning>

Ayakaleaf Pro 6.3.0 awalnya dirilis pada 24 September 2026. Rilis ulang ini mengatasi masalah pada integrasi AI Assistant, Zotero, dan Mendeley yang disebabkan oleh pembaruan upstream.

Versi yang dirilis sebelumnya tidak merusak data Anda. Tarik image `6.3.0` terbaru dan perbarui deployment Anda. **Instalasi yang sudah ada dengan file bibliografi tertaut Zotero atau Mendeley juga harus menjalankan migrasi di bawah ini.** Instalasi baru tidak memerlukan migrasi ini.

</Warning>

<Accordion title="Migrasi Zotero / Mendeley untuk instalasi yang sudah ada">

Saat memperbarui ke image 6.3.0 yang dirilis ulang, migrasikan metadata bibliografi tertaut Zotero/Mendeley yang sudah ada menggunakan skrip di bawah ini. Migrasi ini menyertai perbaikan `12031b8dfd`.

Migrasi ini mengganti nama `zoteroGroupId` / `mendeleyGroupId` menjadi `group_id`, mengganti nama `importedByUserId` menjadi `importer_id`, dan menghapus `importedByName`.

Cadangkan MongoDB dan hentikan aplikasi sebelum menjalankan migrasi. Biarkan MongoDB tetap berjalan. Buka shell-nya (ganti `mongo` dengan nama kontainer Anda):

```bash
docker exec -it mongo mongosh
```

Jalankan perintah berikut di `mongosh` (ganti `sharelatex` dengan nama database Anda):

```javascript
use sharelatex

(async () => {
  let updated = 0
  await db.projects.find({}, { rootFolder: 1 }).forEach(async project => {
    const changes = {}
    function visit(folders, path) {
      for (const [i, folder] of (folders || []).entries()) {
        const folderPath = `${path}.${i}`
        for (const [j, file] of (folder.fileRefs || []).entries()) {
          const data = { ...file.linkedFileData }
          if (!["zotero", "mendeley"].includes(data.provider)) continue
          const groupKey = `${data.provider}GroupId`
          if (![groupKey, "importedByUserId", "importedByName"].some(key => key in data)) continue
          for (const [oldKey, newKey] of [[groupKey, "group_id"], ["importedByUserId", "importer_id"]]) {
            if (data[oldKey] != null && data[oldKey] !== "") {
              const value = String(data[oldKey])
              if (newKey in data && data[newKey] !== value) {
                throw new Error(`Conflicting ${newKey}: project ${project._id}, file ${file._id}`)
              }
              data[newKey] = value
            }
            delete data[oldKey]
          }
          delete data.importedByName
          changes[`${folderPath}.fileRefs.${j}.linkedFileData`] = data
        }
        visit(folder.folders, `${folderPath}.folders`)
      }
    }
    visit(project.rootFolder, "rootFolder")
    if (!Object.keys(changes).length) return
    const result = await db.projects.updateOne(
      { _id: project._id, rootFolder: { $eq: project.rootFolder } },
      { $set: changes }
    )
    if (!result.matchedCount) throw new Error(`Project changed during migration: ${project._id}`)
    updated += result.modifiedCount
  })
  print(`Updated ${updated} project(s).`)
})()
```

Skrip ini mencakup folder bersarang dan hanya mengubah metadata Zotero/Mendeley. Skrip ini aman untuk dijalankan ulang: migrasi yang sudah selesai akan melaporkan `Updated 0 project(s).` pada eksekusi berikutnya. Jika skrip berhenti karena konflik, periksa proyek/file yang dilaporkan; proyek-proyek sebelumnya mungkin sudah dimigrasikan.

Jalankan aplikasi yang telah diperbarui, muat ulang editor, dan segarkan file bibliografi yang sudah ada sebagai pengimpor aslinya. Snapshot historis tidak ditulis ulang. Untuk menurunkan ke aplikasi lama, pulihkan cadangan MongoDB.

</Accordion>

Kami sangat bangga mengumumkan rilis Overleaf Pro 6.3.0, editor LaTeX online paling andal dan kaya fitur di komunitas. Karena kami selalu berfokus pada peningkatan pengalaman pengguna, rilis ini membawa perubahan besar dan fitur-fitur luar biasa yang pasti akan Anda sukai, termasuk asisten AI dan integrasi referensi pihak ketiga.

### Perubahan

* AI Chat Assistant: Mengobrol dengan model AI melalui penyedia Anda sendiri, langsung di editor Anda.
* LaTeX Error Assistant: Dapatkan saran perbaikan dari AI untuk error kompilasi LaTeX.
* Integrasi Mendeley: Impor referensi dari Mendeley, serupa dengan Zotero.
* Open in Overleaf API: Menambahkan API untuk membuka konten di Overleaf.
* Galeri Templat: Menambahkan paginasi, pencarian, dan pengurutan di sisi server, sehingga galeri berukuran besar tidak perlu lagi memuat setiap templat di browser.
* Terjemahan: Memperbarui patch terjemahan untuk 6.3.0, termasuk teks antarmuka baru di seluruh bahasa yang didukung.
* Upstream Overleaf 6.3.0: Mencakup penyuntingan file dengan tab, logo header terpisah untuk tema terang dan gelap, serta pembaruan dependensi dan image dasar.
* Menambahkan `OVERLEAF_HEADER_IMAGE_URL_LIGHT` dan `OVERLEAF_HEADER_IMAGE_URL_DARK` untuk mendukung gambar logo header terpisah untuk tema terang dan gelap.
* File kini dapat dibuka di tab yang berbeda di editor.
* Menambahkan dukungan untuk proxy HTTP(S) yang dapat dikonfigurasi, termasuk proxy yang di-host secara lokal, melalui `OVERLEAF_LINKED_URL_OUTBOUND_PROXY`, yang juga digunakan oleh Open in Overleaf API.

#### Fitur 04: Paginasi Templat

Galeri kini melakukan paginasi, pengurutan, dan pencarian di MongoDB. Fitur ini berfungsi tanpa persiapan apa pun; jika Anda memiliki ribuan templat, Anda tetap dapat menambahkan indeks berikut agar tetap cepat (aman untuk dijalankan ulang, `mongo`/`sharelatex` = nama kontainer dan database Anda):

```bash
docker exec mongo mongosh sharelatex --quiet --eval '
db.templates.createIndex({category:1,lastUpdated:-1},{name:"category_1_lastUpdated_-1",background:true});
db.templates.createIndex({lastUpdated:-1},{name:"lastUpdated_-1",background:true});
db.templates.createIndex({category:1,name:1},{name:"category_1_name_1_ci",collation:{locale:"en",strength:2},background:true});
db.templates.createIndex({name:1},{name:"name_1_ci",collation:{locale:"en",strength:2},background:true});
'
```

Pertahankan `collation` pada dua indeks `*_ci` seperti yang tertulis — galeri melakukan kueri dengan collation yang sama, dan MongoDB hanya menggunakan indeks yang cocok.

## Ayakaleaf Pro 6.2.2

**Tanggal rilis:** 2026.07.23

Lihat: [https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.2](https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.2)

### Perubahan

Menerapkan kembali (backport) patch hotfix resmi yang dirilis di Overleaf upstream `6.2.2` (di atas `6.2.1`):

* Menghentikan kebocoran secret token undangan proyek ke dalam log. Enkriptor token undangan mencatat konfigurasinya sendiri pada setiap enkripsi/dekripsi, termasuk kata sandi cipher yang diturunkan dari `OVERLEAF_INVITE_TOKEN_SECRET`.
* Memigrasikan email keluar dari klien AWS SES v1 yang sudah end-of-life ke SESv2. Instance yang dikonfigurasi dengan driver email `ses` bisa sama sekali gagal mengirim email; pengiriman kini dilakukan melalui `SESv2Client`.
* Menyembunyikan entri grup pada dropdown berbagi proyek di balik feature flag baru `group-link-sharing`, sehingga berbagi tautan grup tidak lagi ditawarkan pada instance yang tidak relevan.
* Memperbaiki modal berbagi proyek untuk kolaborator. Membukanya sebagai non-pemilik, atau dengan alur `sharing-updates` dinonaktifkan, mengirimkan permintaan yang selalu gagal dan memunculkan error "something went wrong".
* Menambahkan `scripts/flush_docs_with_pending_updates.js` ke document-updater, sebuah skrip pemeliharaan yang memulihkan dokumen dengan antrean `PendingUpdates` yang macet di Redis setelah proyeknya di-flush atau dihapus permanen. Mendukung `--dry-run` dan pemeriksaan keamanan `--estimated-docs`.
* Memperbarui dependensi: `multer` 2.2.0, `form-data` 2.5.6, `protobufjs` 7.6.3, `@grpc/grpc-js` 1.14.4.

Rilis ini juga menyertakan perbaikan dan peningkatan berikut dari Ayakaleaf Pro:

* Menambahkan terjemahan lengkap untuk 16 bahasa tambahan (cs, da, de, es, fi, fr, it, ja, ko, nl, no, pl, pt, ru, sv, tr), memperbaiki string yang belum diterjemahkan seperti halaman reset kata sandi. Memperbaiki [#38](https://github.com/ayaka-notes/ayakaleaf-pro/issues/38).
* Memperbaiki jumlah item pada tombol "show N more projects" di panel admin, yang menampilkan angka yang salah karena placeholder bentuk jamak tidak diteruskan dengan benar.
* Memperbaiki error validasi ekspor GitHub, yang kini ditampilkan melalui kunci i18n statis alih-alih pesan mentah, serta menghapus kunci error yang tidak lagi digunakan oleh modal GitHub Sync.

## Ayakaleaf Pro 6.2.0

**Tanggal rilis:** 2026.07.10

Kami bangga mengumumkan rilis Overleaf Pro 6.2.0, editor LaTeX online paling andal dan kaya fitur di komunitas. Terima kasih khusus kepada yu-i-i dan davrot atas kontribusi berharga mereka. Mereka menyempurnakan GitHub Sync serta memperkenalkan Advanced Citation Search dan integrasi Zotero.

### Catatan

<Warning>

* Variabel lingkungan wajib baru `OVERLEAF_INVITE_TOKEN_SECRET` telah diperkenalkan. Anda harus membuatnya dengan `openssl rand -base64 32`. Jika tidak dikonfigurasi, instance Overleaf Anda akan gagal dijalankan.
* Jika Anda mengaktifkan GitHub Sync, Anda harus mengonfigurasi variabel lingkungan `GITHUB_TOKEN_CIPHER_PASSWORD`. Variabel ini diperlukan untuk mengenkripsi token akses GitHub dengan aman. Tanpanya, instance Overleaf Anda akan gagal dijalankan.

</Warning>

* Menambahkan variabel lingkungan baru `DEFAULT_LATEX_COMPILER` untuk mengatur compiler default yang digunakan oleh proyek baru (`pdflatex`, `latex`, `xelatex`, atau `lualatex`).
* Editor yang didesain ulang kini menjadi satu-satunya opsi yang tersedia.

## Ayakaleaf Pro 6.0.0

**Tanggal rilis:** 2026.02.17

Rilis uji coba, lihat: [https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.0.0](https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.0.0)

Ini adalah rilis uji coba, sekaligus versi awal Overleaf Pro kami. Versi ini tidak berisi fitur apa pun dari Server Pro, sehingga hanya ditandai sebagai titik awal kami. Kami akan menambahkan fitur-fitur baru nanti, seperti panel admin dan git-bridge ...

Dalam rilis ini, kami memperkenalkan image Docker Overleaf untuk ARM. Anda dapat mencobanya jika memiliki Mac atau server berbasis ARM, tetapi beberapa fitur mungkin tidak berfungsi dengan baik (belum diuji).

### Image Docker

Anda dapat menemukan image Docker di sini: [https://github.com/ayaka-notes/overleaf-pro/pkgs/container/overleaf-pro](https://github.com/ayaka-notes/overleaf-pro/pkgs/container/overleaf-pro)

Untuk image multi-arsitektur, lihat [di sini](https://github.com/ayaka-notes/overleaf-pro/pkgs/container/overleaf-pro/691283454?tag=6.0.0).

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:6.0.0
```

### Migrasi file biner

Rilis baru ini mengurangi penggunaan penyimpanan file biner hingga setengahnya.

Migrasi online disertakan dalam versi `5.5`, sehingga downtime selama proses pembaruan dapat diminimalkan. Sebelum memperbarui ke Server Pro `v6`, pastikan Anda sudah menjalankan versi terbaru Server Pro `v5.5` ([Catatan Rilis 5.x.x](https://docs.overleaf.com/on-premises/release-notes/release-notes-5.x.x)) dan telah menjalankan migrasinya.

[Lihat petunjuk migrasi lengkap](https://docs.overleaf.com/on-premises/release-notes/release-notes-5.x.x/binary-files-migration).

### Pembaruan MongoDB ke v8

Rilis ini menaikkan versi MongoDB minimum menjadi `8.0`.

Jika Anda saat ini menggunakan MongoDB `v6` atau yang lebih lama, Anda perlu memperbarui versi satu versi mayor demi satu (`v6 → v7 → v8`).

<Warning>

Pastikan Anda memiliki cadangan [database](https://docs.overleaf.com/on-premises/maintenance/data-and-backups) **sebelum** memperbarui. Jika perlu melakukan roll-back, Anda harus memulihkan cadangan database tersebut.

</Warning>

Untuk petunjuk cara memperbarui MongoDB `v6 → v7 → v8`, lihat panduan langkah demi langkah kami [di sini](https://docs.overleaf.com/on-premises/maintenance/updating-mongodb#example-upgrading-mongodb-from-6.0-to-7.0-toolkit-users).

### Pembaruan Redis ke v7.4

Rilis ini juga menaikkan versi Redis minimum menjadi `7.4`.

Perbarui `REDIS_IMAGE` di `config/overleaf.rc` Anda menjadi `REDIS_IMAGE=7.4`.

### Fitur Baru

* Berbagi tautan kini dapat dinonaktifkan dengan `OVERLEAF_DISABLE_LINK_SHARING=true`.
* `OVERLEAF_MAINTENANCE_MESSAGE` dan `OVERLEAF_MAINTENANCE_MESSAGE_HTML` kini tersedia untuk menyesuaikan judul dan isi halaman Pemeliharaan.
* `OVERLEAF_USER_HARD_DELETION_DELAY` dan `OVERLEAF_PROJECT_HARD_DELETION_DELAY` dapat dikonfigurasi (dalam milidetik) untuk mengubah jeda kedaluwarsa pengguna/proyek yang dihapus (default 90 hari).

### Perbaikan bug

* Memperbaiki rendering footer yang berisi tautan.
* Meningkatkan pesan error pada error login SAML.
* Memperbaiki entri log audit yang tidak ditambahkan saat status admin pengguna diperbarui pada login SSO.
* Memperbaiki error panel Riwayat saat TLS diaktifkan di Redis.
* Kompilasi kini dapat dihentikan saat menggunakan kompilasi tanpa sandbox.

### Perubahan lainnya

* Semua tautan ke halaman status (diatur melalui `OVERLEAF_STATUS_PAGE_URL`) kini menggunakan `HTTPS` dan terbuka di tab browser baru.
