### Konfigurasi

Mulai versi 6.3.0, galeri melakukan paginasi, pencarian, dan pengurutan di sisi server. Tidak diperlukan migrasi. Untuk galeri berukuran besar, lihat [indeks MongoDB opsional](/id/on-premises/release-notes/release-notes-6.x.x#fitur-04-paginasi-templat  "mention") di catatan rilis.

Fitur Galeri Templat dikendalikan menggunakan variabel lingkungan berikut:

* `OVERLEAF_TEMPLATE_GALLERY`: Atur ke `true` untuk mengaktifkan Galeri Templat.
*   `OVERLEAF_TEMPLATE_CATEGORIES`: Daftar opsional berisi nol atau lebih kunci kategori templat yang dipisahkan spasi. Kunci yang valid meliputi:

    * _`academic-journal`_
    * _`book`_
    * _`presentation`_
    * _`poster`_
    * _`cv`_
    * _`homework`_
    * _`bibliography`_
    * _`calendar`_
    * _`formal-letter`_
    * _`report`_
    * _`thesis`_
    * _`newsletter`_

    Kunci khusus _`all`_ ditambahkan secara otomatis. Kunci ini mewakili kategori yang mencakup semua templat.

    Untuk setiap kunci kategori, variabel lingkungan opsional berikut dapat diatur:

    * `TEMPLATE_<KEY>_NAME`: Nama tampilan kategori templat.
    * `TEMPLATE_<KEY>_DESCRIPTION`: Deskripsi singkat kategori.

    Jika kunci kategori mengandung tanda hubung (`-`), ganti dengan garis bawah (`_`) pada nama variabel lingkungan.
* `ENABLE_CONVERSIONS`: Harus diatur ke `true` untuk mengaktifkan pembuatan thumbnail dan pratinjau templat.

### Izin untuk Menerbitkan

Admin dapat menerbitkan templat. Anda juga dapat menunjuk pengguna non-admin untuk mengelola templat pilihan yang ditampilkan di galeri lokal Anda di `/templates`.

Untuk melakukannya, Anda perlu mengatur variabel lingkungan `OVERLEAF_TEMPLATES_USER_ID` di `toolkit/config/variables.env` ke `ID` pengguna yang akan bertanggung jawab atas pengelolaan templat di instance Anda, misalnya:

```dotenv
OVERLEAF_TEMPLATES_USER_ID=56a8865231faeb5f07d69959
```

### Menerbitkan Templat

Untuk setiap templat yang ingin Anda unggah:

1. Buat proyek yang berisi kode sumber templat dan pastikan proyek tersebut dapat dikompilasi.
2. Di editor, pilih **File** > **Manage Template**.
3. Pada formulir yang muncul, masukkan detail templat:
   * _Title_ harus unik.
   * Kolom _Description_ mendukung format Markdown.
   * Kolom _Author_ menerima tautan berformat Markdown.

Setelah dikirim, detail templat dapat disunting, atau templat dapat dihapus melalui halaman Galeri Templat. Admin dan pengguna templat (`OVERLEAF_TEMPLATES_USER_ID`) dapat mengelola templat mana pun.

Berikut contohnya:

```dotenv wrap expandable
#################
#   TEMPLATES   #
#################

ENABLE_CONVERSIONS=true

OVERLEAF_TEMPLATE_GALLERY=true
OVERLEAF_TEMPLATE_CATEGORIES=academic-journal book presentation poster cv homework bibliography calendar formal-letter report thesis newsletter

TEMPLATE_ACADEMIC_JOURNAL_NAME=Journal articles
TEMPLATE_ACADEMIC_JOURNAL_DESCRIPTION=Templates for academic journal submissions, including formats for major publishers and preprint servers.

TEMPLATE_BIBLIOGRAPHY_NAME=Bibliographies
TEMPLATE_BIBLIOGRAPHY_DESCRIPTION=Styles for creating and managing bibliographies with BibTeX or BibLaTeX. Suitable for use in academic papers, theses, and reports.

TEMPLATE_BOOK_NAME=Books
TEMPLATE_BOOK_DESCRIPTION=Templates for writing books or long-form documents, including chapter structuring, front matter, and indexing.

TEMPLATE_CALENDAR_NAME=Calendars
TEMPLATE_CALENDAR_DESCRIPTION=Templates to create yearly, monthly, or weekly calendars. Useful for personal planners or event scheduling.

TEMPLATE_CV_NAME=CVs and résumés
TEMPLATE_CV_DESCRIPTION=Templates for CVs and résumés with various formats for academic, industry, and creative positions.

TEMPLATE_FORMAL_LETTER_NAME=Formal letters
TEMPLATE_FORMAL_LETTER_DESCRIPTION=Templates for professional letters, such as cover letters, recommendation letters, and official correspondence.

TEMPLATE_HOMEWORK_NAME=Assignments
TEMPLATE_HOMEWORK_DESCRIPTION=Templates for homework, coursework, and problem sets. Designed to be clean and well-structured for students and educators.

TEMPLATE_NEWSLETTER_NAME=Newsletters
TEMPLATE_NEWSLETTER_DESCRIPTION=Templates for creating newsletters with formats for academic, corporate, or community communications.

TEMPLATE_POSTER_NAME=Posters
TEMPLATE_POSTER_DESCRIPTION=Templates for scientific and academic posters, typically used in conferences and research presentations.

TEMPLATE_PRESENTATION_NAME=Presentations
```

### Memindahkan templat dari overleaf.com

Karena Overleaf Pro dirancang untuk bekerja secara offline, tidak ada cara otomatis untuk mengintegrasikan templat galeri [overleaf.com](https://www.overleaf.com/) ke instalasi on-premise Anda. Namun, hal ini dapat dilakukan secara manual untuk setiap templat.

Secara default, Overleaf Pro dikonfigurasi untuk menggunakan versi skema dasar TeXLive untuk kompilasi. Versi dasar ini ringan dan hanya berisi sebagian kecil paket LaTeX, sehingga kemungkinan besar akan menyebabkan error paket hilang bagi pengguna Anda saat mencoba menggunakan templat dari [overleaf.com](https://www.overleaf.com/) di instance on-premise lokal Anda.

Sayangnya, meskipun tidak ada cara otomatis untuk menginstal paket yang hilang, kami memiliki pengaturan yang dapat dikonfigurasi di Server Pro yang memungkinkan pengguna Anda mengompilasi proyek dengan akses ke lebih banyak paket, dan dengan cara yang lebih aman. Fitur ini disebut [Sandbox Compiles](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles) (juga dikenal sebagai Sibling Containers).

Untuk memastikan templat yang diunduh kompatibel dengan instance Server Pro on-premise Anda, kami sangat menyarankan Anda mengaktifkan [Sandbox Compiles](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles), karena fitur ini akan memberi pengguna Anda akses ke lingkungan TeX Live yang sama dengan di [overleaf.com](https://www.overleaf.com/). Image ini berisi paket dan font paling populer dan telah diuji dengan templat galeri kami.

Anda dapat menemukan informasi tambahan tentang cara mengonfigurasi versi TeX Live yang dapat dipilih pengguna di dalam proyek mereka, serta cara mengatur versi image TeX Live default untuk proyek baru, di bagian [Changing the TeX Live Image](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles#changing-the-tex-live-image) dalam dokumentasi kami.

1. Buka [Template Gallery](https://www.overleaf.com/latex/templates) di [overleaf.com](https://www.overleaf.com/) dan temukan templat yang diperlukan, misalnya [IEEE Photonics Journal Paper Template - Example Submission](https://www.overleaf.com/latex/examples/ieee-photonics-journal-paper-template-example-submission/bsfjjfkdsjds)
2. Klik tombol **Open as Template**
3. Klik menu proyek dan pilih **Download Source**
4. Selanjutnya, masuk ke akun Server Pro on-premise
5. Klik tombol **New Project** dari dasbor proyek dan pilih **Upload Project**
6. Klik tombol **Select a .zip file** dan pilih file zip templat yang telah diunduh

Pengguna kemudian dapat menggunakan templat yang baru diunggah ini di akun mereka sendiri, atau, sebagai pengguna templat, Anda dapat menerbitkannya agar dapat digunakan oleh pengguna lain.

### Tanya Jawab

<Accordion title="Apakah saya bisa menghapus proyek setelah menerbitkan templat terkait?">

<strong>Jawaban:</strong> Bisa, tetapi kami tidak menyarankannya. Saat Anda menerbitkan templat, kami mengambil snapshot proyek dan menyimpannya sebagai file zip pada saat penerbitan. Ini memastikan bahwa meskipun Anda menghapus proyek yang terkait dengan templat, templat tersebut tidak akan terpengaruh.

Namun, kami juga mencatat ProjectID yang terkait dengan templat ini, sehingga Anda dapat dengan mudah memperbarui templat di kemudian hari.

Jika Anda menghapus proyek terkait, Anda tidak akan melihat tombol "Admin: Source Project" di halaman detail templat (lihat gambar di bawah).

<Accordion title="Mengapa menerbitkan templat untuk beberapa proyek memakan waktu begitu lama?">

<strong>Jawaban:</strong> Saat Anda menerbitkan templat, kami menyimpan proyek sebagai file zip dan pdf, yang biasanya cepat. Namun, kami juga perlu membuat thumbnail untuk PDF agar dapat ditampilkan di detail templat.

Waktu pembuatan thumbnail biasanya bergantung pada isi halaman pertama PDF Anda. Untuk menyeimbangkan kualitas tampilan dan waktu konversi, kami memilih lebar menengah.

Namun, jika halaman pertama PDF berisi banyak teks, konversi thumbnail dapat memakan waktu 40 detik atau bahkan lebih, jadi harap bersabar. Berikut contoh poster berukuran besar yang akan membutuhkan waktu lebih lama.
