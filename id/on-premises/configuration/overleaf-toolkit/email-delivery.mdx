Overleaf mendukung pengiriman email melalui dua metode: Simple Mail Transfer Protocol (SMTP) dan [Amazon Simple Email Service (SES)](https://aws.amazon.com/ses/). SMTP dapat digunakan jika Anda memiliki server email yang aktif di localhost Anda dan mendengarkan koneksi lokal.

## Konfigurasi

Email dikonfigurasi menggunakan variabel lingkungan berikut.

#### Konfigurasi Pengirim

| Nama                          | Deskripsi                                                                                                                                            |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | <p>Alamat pengirim, misalnya <a href="mailto:support@mycompany.com">`'support@mycompany.com'`</a><br /><br />- <strong>Wajib</strong>: ya</p> |
| `OVERLEAF_EMAIL_REPLY_TO`     | Alamat balasan, misalnya `'noreply@mycompany.com'`                                                                                                  |

#### SMTP

| Nama                                    | Deskripsi                                                                                                                                                                                                                                                                |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST`              | Hostname atau alamat IP yang akan dihubungi. Harus dapat diakses dari kontainer Docker                                                                                                                                                                               |
| `OVERLEAF_EMAIL_SMTP_PORT`              | Port yang akan dihubungi                                                                                                                                                                                                                                                   |
| `OVERLEAF_EMAIL_SMTP_SECURE`            | Jika `true`, koneksi akan menggunakan TLS saat terhubung ke server. Jika `false` atau tidak diatur, TLS digunakan jika server mendukung ekstensi `STARTTLS`. Dalam sebagian besar kasus, atur nilai ini ke `true` jika Anda terhubung ke port `465`. Untuk port `587` atau `25`, biarkan `false` |
| `OVERLEAF_EMAIL_SMTP_USER`              | Nama pengguna yang digunakan untuk autentikasi ke server SMTP                                                                                                                                                                                                 |
| `OVERLEAF_EMAIL_SMTP_PASS`              | Kata sandi yang terkait dengan nama pengguna SMTP                                                                                                                                                                                                                           |
| `OVERLEAF_EMAIL_SMTP_TLS_REJECT_UNAUTH` | Jika `false`, koneksi ke server TLS dengan sertifikat TLS self-signed atau tidak valid tetap akan dibuka                                                                                                                                                                        |
| `OVERLEAF_EMAIL_SMTP_IGNORE_TLS`        | Jika `true` dan `OVERLEAF_EMAIL_SMTP_SECURE` bernilai `false`, TLS tidak digunakan meskipun server mendukung ekstensi `STARTTLS`                                                                                                                                            |
| `OVERLEAF_EMAIL_SMTP_NAME`              | Hostname opsional untuk validasi TLS jika `OVERLEAF_EMAIL_SMTP_HOST` diatur ke alamat IP; default-nya adalah hostname mesin.                                                                                                                                        |
| `OVERLEAF_EMAIL_SMTP_LOGGER`            | Jika `true`, pesan log akan dicetak ke `web.log`.                                                                                                                                                                                                                        |

#### Antarmuka SMTP Amazon SES

Anda dapat membaca lebih lanjut tentang penggunaan antarmuka SMTP Amazon SES untuk mengirim email [di sini](https://docs.aws.amazon.com/ses/latest/dg/send-email-smtp.html).

| Nama                       | Deskripsi                                                                                  |
| -------------------------- | ------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST` | Hostname atau alamat IP yang akan dihubungi. Harus dapat diakses dari kontainer Docker |
| `OVERLEAF_EMAIL_SMTP_PORT` | Port yang akan dihubungi                                                                     |
| `OVERLEAF_EMAIL_SMTP_USER` | Nama pengguna yang digunakan untuk autentikasi ke server SMTP                   |
| `OVERLEAF_EMAIL_SMTP_PASS` | Kata sandi yang terkait dengan nama pengguna SMTP                                             |

#### Amazon SES API

Anda dapat membaca lebih lanjut tentang penggunaan API Amazon SES untuk mengirim email [di sini](https://docs.aws.amazon.com/ses/latest/dg/send-email-api.html).

| Nama                                   | Deskripsi                                   |
| -------------------------------------- | ------------------------------------------- |
| `OVERLEAF_EMAIL_AWS_SES_ACCESS_KEY_ID` | Access key jika menggunakan AWS SES             |
| `OVERLEAF_EMAIL_AWS_SES_SECRET_KEY`    | Secret key jika menggunakan AWS SES             |
| `OVERLEAF_EMAIL_AWS_SES_REGION`        | Jika tidak diatur, region default-nya adalah US-EAST-1 |

#### AWS SES dengan Instance Role

| Nama                    | Deskripsi                                                                                                                        |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_DRIVER` | Jika diatur ke `ses`, sistem email akan menggunakan metode API SES dan mengandalkan instance role yang telah dikonfigurasi untuk mengirim email. |

#### Kustomisasi

| Nama                           | Deskripsi                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_CUSTOM_EMAIL_FOOTER` | <p>HTML kustom yang ditambahkan ke semua email, misalnya<br /><br /><strong>Contoh</strong>: `"<div>This system is run by department x </div> <div> If you have any questions please look at our faq <a href='`<a href="https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/https:/somwhere.com'%3Ehere&#x3C;/a%3E&#x3C;/div%3E">`https://somwhere.com'>here&#x3C;/a>&#x3C;/div>`</a>`"`</p> |
