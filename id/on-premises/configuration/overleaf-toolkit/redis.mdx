### Mengaktifkan autentikasi kata sandi

Jika Anda menggunakan layanan Redis eksternal dan perlu menyediakan kata sandi, Anda dapat melakukannya dengan mengatur variabel lingkungan `OVERLEAF_REDIS_PASS` dan `REDIS_PASSWORD` di file **config/variables.env** lalu menjalankan perintah `bin/up -d` untuk membuat ulang kontainer **sharelatex**.

Jika Anda menjalankan instance Redis lokal, Anda perlu mengonfigurasi layanan **redis** agar berjalan dengan autentikasi kata sandi. Setelah mengatur variabel lingkungan di atas, Anda juga perlu menyelesaikan langkah-langkah tambahan berikut:

Buat file **docker-compose.override.yml** di direktori <strong>config/</strong> dengan isi sebagai berikut:

```yaml title="config/docker-compose.override.yml"
services:
    redis:
        command: "redis-server --requirepass <YOUR-PASSWORD>"
```

<Warning>

Jika Anda mengaktifkan persistensi AOF, Anda perlu menambahkan `--appendonly yes` ke `command`.

</Warning>

Jalankan `bin/up -d` untuk membuat ulang kontainer.

### Mengaktifkan Persistensi Append-Only File

(Sumber asli: https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/redis#enabling-append-only-file-persistence)

Persistensi Redis AOF (Append-Only File) menyediakan cara yang andal untuk memastikan ketahanan data dengan mencatat setiap operasi tulis yang diterima server. Tidak seperti snapshot RDB, yang mengambil salinan dataset Anda pada titik waktu tertentu, AOF menyimpan catatan lengkap semua perubahan yang dilakukan pada data Anda.

<Info>

Menonaktifkan RDB bersifat opsional. Umumnya disarankan agar kedua metode persistensi digunakan bersamaan. Sebelum melakukan perubahan apa pun di lingkungan produksi, tinjau kelebihan dan kekurangan menjalankan AOF dan RDB secara bersamaan.

</Info>

Anda dapat membaca lebih lanjut tentang mengaktifkan persistensi AOF di Redis di sini: [https://redis.io/docs/latest/operate/oss\_and\_stack/management/persistence/#how-i-can-switch-to-aof-if-im-currently-using-dumprdb-snapshotsarrow-up-right](https://redis.io/docs/latest/operate/oss_and_stack/management/persistence/#how-i-can-switch-to-aof-if-im-currently-using-dumprdb-snapshotsarrow-up-right)

1. Jadwalkan jendela pemeliharaan untuk peningkatan ini.
2. Hentikan instance menggunakan `bin/stop` dan buat cadangan folder <strong>config/</strong> dan <strong>data/</strong>.
3. Jalankan `bin/up` untuk memulai instance
4. Jalankan perintah `docker exec -it redis sh`
5. Jalankan perintah `redis-cli` untuk membuka antarmuka baris perintah Redis
6. Di redis-cli, jalankan perintah `config set appendonly yes`
7. Sekarang Anda perlu menunggu proses AOF rewrite selesai menyimpan data. Anda dapat melakukannya dengan mengetik `INFO persistence` di redis-cli dan menunggu hingga `aof_rewrite_in_progress` dan `aof_rewrite_scheduled` bernilai `0`, serta memastikan bahwa `aof_last_bgrewrite_status` bernilai `ok`.
8. Keluar dari redis-cli dengan mengetik `exit` dan menekan tombol Enter
9. Keluar dari kontainer redis dengan mengetik `exit` dan menekan tombol Enter
10. Jalankan perintah `ls ./data/redis` dan pastikan Anda dapat melihat file **appendonly.aof**
11. Edit file **config/overleaf.rc** dan ubah variabel lingkungan `REDIS_AOF_PERSISTENCE` dari `false` menjadi `true`
12. Jalankan `bin/up -d` dan pastikan aplikasi berfungsi (editor proyek dan panel riwayat berfungsi dengan baik).
