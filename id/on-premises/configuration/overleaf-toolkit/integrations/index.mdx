Setiap integrasi dinonaktifkan secara default, kecuali Overleaf Import API. Sinkronisasi GitHub, GitLab, Gitea, dan Dropbox serta MCP server juga memerlukan [Integrasi Git](/id/on-premises/configuration/overleaf-toolkit/integrations/git-integration). Setelah mengaktifkan salah satunya, buat ulang container dengan `bin/up -d`.
