Setiap proyek memiliki MCP server, sehingga klien AI seperti Claude Code, Codex, Cursor, VS Code, atau Gemini CLI dapat bekerja pada proyek tersebut: membaca dan menyunting file-filenya, mengompilasinya, membaca log LaTeX, mengunduh PDF, dan menjawab komentar.

<Info>

Fitur ini dikembangkan oleh [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro). Fitur ini diperkenalkan sejak v6.3.1 dan versi selanjutnya.

</Info>

### Penyiapan

MCP server disertakan bersama integrasi Git: aktifkan [git-bridge](/id/on-premises/configuration/overleaf-toolkit/integrations/git-integration), dan MCP server juga akan tersedia. Tidak ada hal lain yang perlu dikonfigurasi.

### Menghubungkan klien AI

1. Di **Account Settings**, buat token autentikasi Git. Token yang sama digunakan untuk MCP server dan untuk Git.
2. Di editor, buka **Integrations** dan klik **MCP server**. Dialog ini menampilkan alamat MCP server proyek, `https://<your-overleaf>/project/<project_id>/mcp`, serta cara menambahkannya ke setiap klien AI: salin perintahnya, lalu ganti `<token>` dengan token Anda.

Token dikirim sebagai header HTTP `Authorization: Bearer <token>`. Misalnya, perintah untuk Claude Code adalah:

```bash
claude mcp add --transport http overleaf \
  https://<your-overleaf>/project/<project_id>/mcp \
  --header "Authorization: Bearer <token>"
```

### Penggunaan

Setelah terhubung, ajukan permintaan ke klien AI dengan bahasa sehari-hari. Contohnya:

| Anda meminta | Klien AI menggunakan |
| --- | --- |
| _Perbaiki salah ketik di bagian pendahuluan._ | `read_file`, `edit_file`: suntingan langsung terlihat di editor |
| _Kompilasi proyek dan perbaiki error LaTeX-nya._ | `compile`, `get_compile_log`, `edit_file` |
| _Jawab komentar yang masih terbuka, lalu selesaikan._ | `list_comments`, `reply_to_comment`, `resolve_comment` |
| _Beralih ke XeLaTeX dan unduh PDF-nya._ | `update_settings`, `compile`, `get_output_file_link` |

### Tools

| Grup | Tools |
| --- | --- |
| Proyek | `get_clone_info`, `get_settings`, `update_settings`, `list_versions` |
| File | `list_files`, `read_file`, `edit_file`, `write_file`, `delete_file` |
| Kompilasi | `compile`, `get_compile_log`, `get_output_file_link`, `word_count` |
| Komentar | `list_comments`, `reply_to_comment`, `resolve_comment`, `reopen_comment` |

Suntingan yang dibuat dengan `edit_file` dan `write_file` langsung terlihat di editor dan digabungkan dengan suntingan kolaborator. Untuk banyak file sekaligus, file biner, atau penggantian nama, klien AI juga dapat meng-clone proyek dengan Git lalu melakukan push.

### Izin

MCP server mengikuti pengaturan berbagi proyek, seperti Git:

* Semua orang yang dapat melihat proyek dapat membacanya, mengompilasinya, dan mengunduh hasilnya.
* Hanya pemilik dan editor yang dapat mengubah file dan pengaturannya.
* Peninjau juga dapat membalas komentar, serta menyelesaikan atau membuka kembali komentar yang mereka mulai.
* Pengguna dengan akses hanya-lihat yang bergabung melalui tautan tidak dapat melihat komentar, sama seperti di editor.

### Tanya Jawab

<Accordion title="Saya tidak melihat Integrations atau MCP server di editor">

<strong>Jawaban:</strong> MCP server tidak memiliki variabel lingkungan sendiri. MCP server diaktifkan dengan `GIT_BRIDGE_ENABLED=true` di `config/overleaf.rc`, lihat [Integrasi Git](/id/on-premises/configuration/overleaf-toolkit/integrations/git-integration). Setelah mengubahnya, jalankan `bin/up -d`. Tanpa git-bridge, editor tidak menampilkan tab **Integrations** di rail kirinya.

</Accordion>
