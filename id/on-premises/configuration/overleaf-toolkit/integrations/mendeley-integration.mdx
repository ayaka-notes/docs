#### Menyiapkan Integrasi Mendeley

1. Buka [tautan ini](https://dev.mendeley.com/myapps.html) untuk mendaftarkan aplikasi OAuth Mendeley
2. Konfigurasikan **Redirect URL** sebagai: `${OVERLEAF_SITE_URL}/user/mendeley/oauth/callback`
3. Catat **ID** (biasanya berupa angka seperti `24061` di bawah) dan **Secret** yang dihasilkan untuk aplikasi Anda
4. Ubah `config/variables.env` Anda&#x20;
5. Biarkan Authorisation Flow: Elsevier (sesuai rekomendasi)

</Frame>

```dotenv title="config/variables.env"
#################
#   Mendeley    #
#################
# 'mendeley' must be in ENABLED_LINKED_FILE_TYPES (keep 'zotero' too if you use both)
ENABLED_LINKED_FILE_TYPES=project_file,project_output_file,url,mendeley

# From a Mendeley OAuth application (register at https://dev.mendeley.com/myapps.html)
# Redirect URL -> ${OVERLEAF_SITE_URL}/user/mendeley/oauth/callback
MENDELEY_CLIENT_ID=
MENDELEY_CLIENT_SECRET=
# Encrypts the Mendeley OAuth tokens in mongo; if unset, a key file is generated
# in /var/lib/overleaf/data on first use
# How to generate: `openssl rand -hex 32`
MENDELEY_CIPHER_PASSWORD=
# Optional: route the module's server-side Mendeley requests (OAuth + API) through
# an HTTP proxy (must be reachable from the web container; same as github-sync)
# http://10.0.0.1:10808
# (Optional) MENDELEY_PROXY_URL=
```

<Info>

&#x20;`mendeley` harus disertakan dalam `ENABLED_LINKED_FILE_TYPES` (pertahankan juga `zotero` dalam daftar jika Anda menggunakan keduanya). `MENDELEY_CLIENT_ID` dan `MENDELEY_CLIENT_SECRET` berasal dari aplikasi OAuth yang Anda daftarkan. Cipher password mengenkripsi token OAuth Mendeley di MongoDB (buat dengan `openssl rand -hex 32`); tanpanya, file kunci akan dibuat di volume data saat pertama kali digunakan. Secara opsional, atur `MENDELEY_PROXY_URL` untuk mengarahkan permintaan Mendeley sisi server (OAuth + API) melalui proxy HTTP yang dapat diakses dari container web.

</Info>

### Catatan

<Warning>

Saat meng-upgrade instalasi yang sudah ada dengan file bibliografi tertaut Mendeley ke 6.3.0 yang dirilis ulang, ikuti [instruksi migrasi Zotero / Mendeley](/id/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention"). Instalasi baru tidak memerlukan migrasi ini.

</Warning>

<Danger>

Karena Ayakaleaf adalah platform kolaboratif, untuk meningkatkan keamanan, mulai versi 6.3.0, hanya pembuat asli file Referensi `bib` yang diizinkan untuk memperbarui file yang diimpor.

</Danger>

Misalnya, pemilik proyek, Pengguna A, mengaktifkan berbagi tautan dan membuat file `test.bib` di proyek, lalu menautkannya ke akun Zotero miliknya. Jika pengguna lain, Pengguna B, mengakses proyek melalui tautan bersama, Pengguna B tetap dapat membaca dan mengunduh `test.bib`, tetapi tidak diizinkan untuk memperbarui atau mengimpor ulang file tersebut dari Zotero. Hanya Pengguna A, sebagai pembuat asli file Referensi, yang dapat melakukan pembaruan. Dengan kata lain, hanya pembuat asli file `.bib` yang memiliki izin untuk memperbaruinya.
