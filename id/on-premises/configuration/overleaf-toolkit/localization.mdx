### Konfigurasi i18n Overleaf

<Info>

Dokumen ini menjelaskan cara mengonfigurasi internasionalisasi (i18n) untuk instance **Overleaf** yang di-host sendiri.

</Info>

Overleaf telah diterjemahkan ke dalam berbagai bahasa. Dengan konfigurasi yang sesuai, Anda dapat:

* Menjalankan instance Overleaf Anda dalam **satu bahasa tetap**, atau
* Mengaktifkan **beberapa bahasa**, sehingga pengguna dapat berganti bahasa secara dinamis, seperti di `www.overleaf.com`.

***

#### Konfigurasi Satu Bahasa

Bahasa situs dikonfigurasi menggunakan variabel lingkungan `OVERLEAF_SITE_LANGUAGE` (atau `SHARELATEX_SITE_LANGUAGE` untuk Overleaf versi **4.x dan sebelumnya**).

Kode bahasa yang didukung meliputi:

* `en` - Inggris (default)
* `es` - Spanyol
* `pt` - Portugis
* `de` - Jerman
* `fr` - Prancis
* `cs` - Ceko
* `nl` - Belanda
* `sv` - Swedia
* `it` - Italia
* `tr` - Turki
* `zh-CN` - Tionghoa (sederhana)
* `no` - Norwegia
* `da` - Denmark
* `ru` - Rusia
* `ko` - Korea
* `ja` - Jepang
* `pl` - Polandia
* `fi` - Finlandia

Bahasa Inggris adalah bahasa default. Untuk mengubah bahasa antarmuka (misalnya ke Tionghoa Sederhana), tambahkan baris berikut ke `config/variables.env`:

```bash title="config/variables.env"
OVERLEAF_SITE_LANGUAGE=zh-CN
```

Kemudian terapkan konfigurasinya:

```bash
bin/up
```

Setelah layanan dimulai ulang, bahasa antarmuka pada menu UI web akan mengikuti pengaturan baru.

#### Konfigurasi Beberapa Bahasa

Agar pengguna dapat **berganti bahasa tanpa harus keluar**, instance Overleaf Anda harus dikonfigurasi untuk menyajikan bahasa yang berbeda berdasarkan nama domain.

Bagian ini mengasumsikan:

* Domain utama Anda adalah `overleaftest.com`
* Anda memiliki **sertifikat TLS wildcard** (misalnya `*.overleaftest.com`)
* Anda **tidak menggunakan `localhost`** (karena tidak mendukung perutean bahasa berbasis subdomain)

Untuk pengujian lokal, Anda dapat menggunakan domain seperti `dev-overleaf.com`.

<Steps>
<Step title="Konfigurasi Proxy TLS (Nginx)">
Reverse proxy TLS Anda harus meneruskan header `Host` asli agar Overleaf dapat menentukan domain bahasa mana yang diakses pengguna.

Pastikan direktif berikut ada:

```nginx
proxy_set_header Host $host;
```

Berikut contoh konfigurasi Nginx:

```nginx
server {
    listen 443 ssl;
    server_name    _; # Catch all, see http://nginx.org/en/docs/http/server_names.html
    server_name *.overleaftest.com;
    ssl_certificate /etc/nginx/ssl/nginx.crt;
    ssl_certificate_key /etc/nginx/ssl/nginx.key;
    ssl_protocols               TLSv1 TLSv1.1 TLSv1.2;
    ssl_prefer_server_ciphers   on;
    # used cloudflares ciphers https://github.com/cloudflare/sslconfig/blob/master/conf
    ssl_ciphers EECDH+CHACHA20:EECDH+AES128:RSA+AES128:EECDH+AES256:RSA+AES256:EECDH+3DES:RSA+3DES:!MD5;

    # config to enable HSTS(HTTP Strict Transport Security) https://developer.mozilla.org/en-US/docs/Security/HTTP_Strict_Transport_Security
    # to avoid ssl stripping https://en.wikipedia.org/wiki/SSL_stripping#SSL_stripping	
    add_header Strict-Transport-Security "max-age=31536000; includeSubdomains;";
    server_tokens off;
    add_header X-Frame-Options SAMEORIGIN;
    add_header X-Content-Type-Options nosniff;
    client_max_body_size 50M;

    location / {
        proxy_pass http://localhost:5000; # change to whatever host/port the docker container is listening on.
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 3m;
        proxy_send_timeout 3m;
        
        # add this to your nginx conf
        proxy_set_header Host $host;
    }
}
```
</Step>

<Step title="Mengonfigurasi Domain Cookie">
Agar pengguna tidak keluar saat berganti bahasa, cookie harus dibagikan ke seluruh subdomain bahasa.

Tambahkan baris berikut ke `config/variables.env`:

```env title="config/variables.env"
# Note the leading dot
COOKIE_DOMAIN=.overleaftest.com
```

Ini memastikan cookie autentikasi berlaku untuk semua subdomain di bawah `overleaftest.com`.
</Step>

<Step title="Pemetaan Bahasa–Domain">
Selanjutnya, tentukan bagaimana kode bahasa dipetakan ke subdomain menggunakan\
`OVERLEAF_LANG_DOMAIN_MAPPING`.

#### Contoh Konfigurasi

```dotenv title="config/variables.env" wrap
OVERLEAF_LANG_DOMAIN_MAPPING='{"www": {"lngCode": "en","url": "https:\/\/www.overleaftest.com"},"cn": {"lngCode": "zh-CN","url": "https:\/\/cn.overleaftest.com"}}'
```

Dengan konfigurasi ini:

* `https://www.overleaftest.com` → antarmuka bahasa Inggris
* `https://cn.overleaftest.com` → antarmuka bahasa Tionghoa Sederhana

Anda dapat memperluas pemetaan ini dengan bahasa dan subdomain tambahan sesuai kebutuhan.
</Step>

<Step title="Mengalihkan Domain Apex">
Terakhir, alihkan domain apex (`overleaftest.com`) ke domain bahasa default (`www.overleaftest.com`).

```nginx
server{
    listen 80;
    server_name overleaftest.com;
    return 301 https://www.overleaftest.com$request_uri;
}

server {
    listen 443 ssl http2;
    server_name overleaftest.com;
    ssl_certificate     /path/to/fullchain.cer;
    ssl_certificate_key /path/to/overleaftest.com.key;
    return 301 https://www.overleaftest.com$request_uri;
}
```
</Step>
</Steps>
