Halaman ini menjelaskan variabel lingkungan yang didukung di file `config/variables.env` untuk deployment Toolkit.

File `config/variables.env` terdiri dari definisi variabel dalam bentuk `NAME=value`; baris yang diawali dengan `#` diperlakukan sebagai komentar.

<Info>

Anda perlu membuat ulang kontainer Docker setelah mengubah apa pun di `overleaf.rc` atau `variables.env` dengan menjalankan `bin/up`.

</Info>

### Semua versi

Variabel lingkungan ini kompatibel dengan Server CE dan Server Pro serta menyediakan jalur migrasi yang mudah di antara kedua versi on-premise tersebut. Variabel ini juga dapat digunakan pada deployment Toolkit maupun Docker Compose.

<Info>

Sebelumnya, variabel lingkungan ini diawali dengan `SHARELATEX_` alih-alih `OVERLEAF_`.

</Info>

<Info>

Pembatasan kata sandi dapat diberlakukan pada pengguna saat menggunakan sistem login Overleaf (akun lokal), bukan opsi SSO seperti LDAP. Untuk akun SSO, kebijakan kata sandi akan diberlakukan oleh penyedia identitas atau layanan direktori Anda, yang juga memungkinkan dukungan autentikasi multi-faktor.

</Info>
