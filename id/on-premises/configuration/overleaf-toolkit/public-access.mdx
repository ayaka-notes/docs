Anda dapat membuka instance Overleaf Anda untuk orang yang tidak memiliki akun dengan tiga cara:

* [Akses Proyek](/id/on-premises/configuration/overleaf-toolkit/public-access#project-access  "mention"): izinkan tamu membuka tautan proyek yang dibagikan tanpa masuk
* [Akses Halaman](/id/on-premises/configuration/overleaf-toolkit/public-access#page-access  "mention"): izinkan pengunjung yang belum masuk menjelajahi halaman seperti `/learn`, `/templates`, dan `/devs`
* [Pendaftaran Publik](/id/on-premises/configuration/overleaf-toolkit/public-access#public-registration  "mention"): izinkan pengguna mendaftar sendiri, opsional dibatasi pada domain email tertentu

### Akses Proyek

<Info>

Secara default, meskipun pengguna mendapatkan tautan berbagi proyek, mereka harus **masuk** terlebih dahulu sebelum dapat bergabung dalam sesi penyuntingan proyek kolaboratif.

</Info>

Untuk mengizinkan akses anonim ke proyek yang dibagikan melalui tautan, atur kedua variabel berikut:

```dotenv title="config/variables.env"
OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING=true
OVERLEAF_ALLOW_PUBLIC_ACCESS=true
```

`OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` mengaktifkan akses baca/tulis anonim pada proyek yang dibagikan melalui tautan.

`OVERLEAF_ALLOW_PUBLIC_ACCESS` mencegah pengguna yang belum terautentikasi dialihkan ke halaman login.

Buat ulang kontainer dengan `bin/up`. Kemudian buka URL berbagi tautan di jendela privat.

### Akses Halaman

Secara default (`OVERLEAF_ALLOW_PUBLIC_ACCESS` tidak diatur), **setiap** halaman kecuali halaman login dan pendaftaran akan mengalihkan pengunjung yang belum masuk ke halaman login. Ini termasuk halaman yang seharusnya publik, sehingga tautan ke halaman tersebut hanya berfungsi bagi pengguna yang sudah masuk.

Dengan `OVERLEAF_ALLOW_PUBLIC_ACCESS=true`, pengunjung yang belum masuk dapat membuka:

| Halaman                                                                  | Memerlukan                         |
| --------------------------------------------------------------------- | -------------------------------- |
| Bantuan LaTeX di `/learn` (lihat [adding-latex-user-help.md](/id/on-premises/configuration/overleaf-toolkit/adding-latex-user-help  "mention")) | `OVERLEAF_PROXY_LEARN=true`      |
| Galeri templat di `/templates`, halaman templat, pratinjau, dan unduhan ZIP (lihat [templates.md](/id/on-premises/configuration/overleaf-toolkit/templates  "mention")) | `OVERLEAF_TEMPLATE_GALLERY=true` |
| Halaman Overleaf Import API di `/devs` (lihat [overleaf-import-api.md](/id/on-premises/configuration/overleaf-toolkit/overleaf-import-api  "mention")) | —                                |

Pengaturan ini juga memungkinkan [Overleaf Import API](/id/on-premises/configuration/overleaf-toolkit/overleaf-import-api#signed-out-visitors  "mention") menyimpan kiriman formulir dari pengunjung yang belum masuk hingga mereka masuk.

Daftar proyek, editor, dan pembuatan proyek (termasuk dari templat atau melalui Import API) tetap memerlukan login.

### Pendaftaran Publik

Pendaftaran publik hanya tersedia di [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro).

<Danger>

Perlu diperhatikan bahwa setelah Anda mengaktifkan pendaftaran publik, **siapa pun** yang dapat mengakses instance Overleaf Anda dapat mendaftar sebagai pengguna.

Proses pendaftaran tidak memverifikasi alamat email, jadi gunakan fitur ini hanya di intranet atau lingkungan tepercaya, atau nonaktifkan saat Anda tidak lagi memerlukan pendaftaran.

</Danger>

Secara default, baik Community Edition maupun Overleaf Pro tidak mengizinkan pendaftaran publik.

Untuk mengaktifkannya, tambahkan baris ini ke `config/variables.env`:

```dotenv title="config/variables.env"
OVERLEAF_ALLOW_PUBLIC_REGISTRATION=true
```

Buat ulang kontainer dengan `bin/up`.

Kemudian klik **Sign up** atau kunjungi `/register`.

### Pendaftaran dengan Domain Terbatas

Pendaftaran publik dengan domain terbatas hanya tersedia di [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro).

Sebelum mengaktifkannya, konfigurasikan pengiriman email agar pengguna dapat menerima undangan dan notifikasi. Lihat [Pengiriman email](/id/on-premises/configuration/overleaf-toolkit/email-delivery).

Kemudian tambahkan baris berikut ke `config/variables.env`:

```dotenv title="config/variables.env" wrap
OVERLEAF_ALLOW_PUBLIC_REGISTRATION=@example.domain
```

`OVERLEAF_ALLOW_PUBLIC_REGISTRATION` dapat diatur ke:

* `true` untuk mengizinkan siapa pun yang dapat mengakses situs untuk mendaftar
* `@example.domain` untuk membatasi pendaftaran hanya untuk email di domain tersebut
