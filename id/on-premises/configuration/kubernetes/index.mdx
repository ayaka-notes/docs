Deployment Kubernetes membaca variabel lingkungan yang sama dengan Toolkit. Jika halaman Toolkit mengatakan "tambahkan ini ke `config/variables.env`", masukkan nilainya ke ConfigMap `overleaf-env`, atau ke Secret `overleaf-secrets` jika nilai tersebut berupa kata sandi, kunci, atau token. Lalu restart:

```bash
kubectl -n overleaf apply -f 30-config.yaml        # after editing the ConfigMap
kubectl -n overleaf patch secret overleaf-secrets --type merge \
  -p '{"stringData":{"GITHUB_TOKEN_CIPHER_PASSWORD":"'"$(openssl rand -hex 32)"'"}}'
kubectl -n overleaf rollout restart deployment/overleaf
```

Nilai di `config/overleaf.rc` adalah pengaturan Toolkit, bukan variabel lingkungan; Tanya Jawab di akhir halaman ini menjelaskan apa yang menggantikannya.

### Sertifikat dan file lainnya

Beberapa fitur menerima path file alih-alih nilai: sertifikat SAML (`OVERLEAF_SAML_IDP_CERT`, ...), CA LDAP (`OVERLEAF_LDAP_TLS_OPTS_CA_PATH`), atau CA privat untuk GitHub Enterprise, GitLab, atau Gitea yang di-host sendiri (`NODE_EXTRA_CA_CERTS`). Masukkan file tersebut ke dalam Secret dan mount di lokasi yang diharapkan oleh halaman Toolkit, yaitu `/var/lib/overleaf/certs`:

```bash
kubectl -n overleaf create secret generic overleaf-certs --from-file=idp_cert.pem --from-file=ca.pem
```

```yaml title="40-overleaf.yaml (additions)"
          volumeMounts:
            # ...
            - name: certs
              mountPath: /var/lib/overleaf/certs
              readOnly: true
      volumes:
        # ...
        - name: certs
          secret:
            secretName: overleaf-certs
```

Lalu rujuk file tersebut berdasarkan path-nya di ConfigMap, misalnya `NODE_EXTRA_CA_CERTS: /var/lib/overleaf/certs/ca.pem`, dan restart.

<Warning>

<strong>Cipher password.</strong> Atur setiap `*_CIPHER_PASSWORD` dari fitur yang Anda gunakan di Secret. Jika tidak, beberapa fitur akan membuat file kunci di volume data saat pertama kali digunakan: dengan satu replika hal itu berfungsi hingga volume hilang, dengan beberapa replika setiap replika akan mengenkripsi dengan kunci yang berbeda.

</Warning>
