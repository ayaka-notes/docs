Import API (`/docs` dan tombol "Open in Ayakaleaf", modul `open-in-overleaf`) berjalan di layanan **web** pada setiap pod Ayakaleaf Pro dan aktif secara default. File yang diberikan melalui URL diunduh melalui linked-url-proxy di pod yang sama. Cara memanggilnya dijelaskan di [Overleaf Import API](/id/on-premises/configuration/overleaf-toolkit/integrations/overleaf-import-api).

| | |
| --- | --- |
| Layanan | web (modul `open-in-overleaf`); unduhan melalui linked-url-proxy |
| Luar → Overleaf | browser melakukan `GET` atau `POST ${OVERLEAF_SITE_URL}/docs` dari situs web mana pun |
| Pod → luar | unduhan `snip_uri` dan `zip_uri`, dibatasi seperti dijelaskan di [URL Eksternal](/id/on-premises/configuration/kubernetes/external-url) |
| Status | permintaan pengunjung yang belum masuk, disimpan di Redis selama 10 menit hingga mereka masuk |
| Tugas berkala | tidak ada |

### Konfigurasi

Tidak ada yang perlu dilakukan untuk mengaktifkannya. Pengaturan terkait di ConfigMap:

| Pengaturan | |
| --- | --- |
| `OVERLEAF_ALLOW_PUBLIC_ACCESS: "true"` | Pengunjung yang belum masuk dapat membuka `/devs`, dan permintaan yang mereka kirim disimpan hingga mereka masuk, lihat [Akses Publik](/id/on-premises/configuration/kubernetes/authentication/public-access). |
| `MAX_UPLOAD_SIZE` | Ukuran ZIP terbesar yang dapat dibawa oleh sebuah permintaan, dalam MB (default `50`). Ingress atau load balancer Anda juga harus menerima body permintaan sebesar itu. |
| `OVERLEAF_LINKED_URL_*` | Alamat mana yang boleh dituju oleh `snip_uri` dan `zip_uri`, lihat [URL Eksternal](/id/on-premises/configuration/kubernetes/external-url). |

### Beberapa replika

Tidak ada yang perlu ditambahkan. Permintaan pengunjung yang belum masuk disimpan di Redis, sehingga dilanjutkan di replika mana pun yang dicapai pengunjung setelah masuk.

### Diuji di Kubernetes

Di Kubernetes 1.37 dengan satu replika, pengujian end-to-end kami untuk Import API lulus (14 kasus): halaman `/devs` dan contoh proyeknya, cuplikan, dokumen lengkap, tautan yang dienkode URL, dan file dari data URL yang diubah menjadi proyek, kiriman yang tidak dapat menjadi proyek ditolak, unduhan dari alamat internal ditolak, kiriman dan tautan dari pengunjung yang belum masuk dipertahankan melalui proses masuk, dan, dengan `OVERLEAF_ALLOW_PUBLIC_ACCESS`, `/devs` untuk pengunjung yang belum masuk serta cuplikan yang dikirim dilanjutkan sekali setelah masuk; kasus terakhir juga lulus pada tiga replika di belakang HAProxy.
