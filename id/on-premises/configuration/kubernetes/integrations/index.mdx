Setiap integrasi nonaktif secara default, kecuali Overleaf Import API. Sinkronisasi GitHub, GitLab, Gitea, dan Dropbox serta server MCP juga memerlukan [integrasi Git](/id/on-premises/configuration/kubernetes/integrations/git-integration). Setelah mengaktifkan salah satunya di ConfigMap atau Secret, mulai ulang replika dengan `kubectl -n overleaf rollout restart`.
