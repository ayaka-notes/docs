<Info>

Ayakaleaf Pro adalah implementasi yang disempurnakan dari Overleaf Community Edition, yang menawarkan semua fitur premium dari server pro secara _**gratis**_. Tidak seperti Overleaf Common yang tersedia di [https://www.overleaf.com/](https://www.overleaf.com/), kami tidak memiliki batasan waktu kompilasi, tidak ada persyaratan lisensi terkait jumlah pengguna, dan Anda dapat sepenuhnya meng-host data Anda sendiri, sehingga keamanannya terjamin sepenuhnya.

Overleaf Server Pro adalah deployment Overleaf komersial yang di-host sendiri, dengan dukungan resmi. Untuk informasi lebih lanjut tentang Server Pro, kunjungi [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud).

</Info>

<Warning>

Overleaf Community Edition ditujukan untuk digunakan di lingkungan di mana **semua** pengguna tepercaya. Community Edition **tidak** cocok untuk skenario yang memerlukan isolasi pengguna karena Sandbox Compiles tidak tersedia.

Tanpa sandboxing, kompilasi LaTeX berjalan dengan hak akses yang sama dengan container, sehingga dapat mengakses filesystem, jaringan, dan variabel lingkungannya. Hal ini menimbulkan risiko kebocoran data atau kompromi sistem. Kompilasi tanpa sandbox hanya boleh digunakan di lingkungan yang sepenuhnya tepercaya; untuk deployment multi-pengguna atau produksi, Sandbox Compiles sangat disarankan.

Untuk informasi lebih lanjut tentang Sandbox Compiles, lihat [dokumentasi](/id/on-premises/configuration/overleaf-toolkit/sandboxed-compiles) kami.

</Warning>

### Dukungan Komunitas

Bagi pengguna instance Overleaf yang di-host sendiri, dukungan diberikan oleh komunitas melalui GitHub [Issues](https://github.com/ayaka-notes/overleaf-pro/issues).

Agar tetap berada di jalur yang didukung, Anda dapat memastikan versi Overleaf yang sedang Anda jalankan dengan membandingkan output perintah di bawah ini dengan Image ID yang dipublikasikan di catatan rilis.

```bash
docker inspect --format '{{.Image}}' sharelatex | awk -F: '{print substr($2, 1, 12)}'
```
