Di sini, kami telah mengumpulkan jawaban atas beberapa pertanyaan yang sering diajukan tentang Ayakaleaf Pro.

### Pertanyaan Dasar

<Accordion title="Q01: Apakah Ayakaleaf Pro merupakan uji coba gratis? Apakah memerlukan lisensi?">

Tidak. Ayakaleaf Pro sepenuhnya gratis untuk digunakan. Ini bukan uji coba dan tidak memerlukan lisensi.

</Accordion>

<Accordion title="Q02: Apakah Anda (ayakaleaf pro) menyertakan semua fitur Overleaf Server Pro?">

Ya. Ayakaleaf Pro menyertakan semua fitur Overleaf Server Pro, termasuk integrasi Git-Bridge. Ayakaleaf Pro juga menyertakan fitur-fitur pilihan dari platform SaaS Overleaf. Kami terus mengembangkan dan menyempurnakan Ayakaleaf Pro.

</Accordion>

<Accordion title="Q03: Berapa biaya Overleaf Server Pro?">

Overleaf Server Pro berbiaya sekitar \$300 per pengguna setiap tahun. Diperlukan minimal 10 lisensi, sehingga penerapan dimulai dari kira-kira \$3.000 per tahun. Kontrak publik AS yang lebih kecil menunjukkan biaya tahunan sekitar \$320–\$370 per pengguna. Hal ini membuat Server Pro mahal, terutama bagi tim yang lebih kecil. Lihat [#information-and-price-about-overleaf-server-pro](/id/on-premises#information-and-price-about-overleaf-server-pro  "mention") untuk pembelian dan harga yang terdokumentasi.

</Accordion>

<Accordion title="Q04: Mengapa Overleaf Server Pro tidak menyertakan GitHub Sync atau fitur AI?">

Overleaf Server Pro umumnya digunakan oleh organisasi pemerintah. Mereka menerapkannya di jaringan privat dan mengontrol akses secara ketat. Untuk melindungi data sensitif, fitur-fitur yang disertakan menghindari pertukaran data dengan layanan pihak ketiga. Jika Anda memerlukan GitHub Sync, AI, atau fitur terhubung serupa, Overleaf menyarankan berlangganan platform SaaS-nya.

</Accordion>

<Accordion title="Q05: Apakah Ayakaleaf Pro aman dan andal?">

Ayakaleaf Pro bersifat open source. Kami meninjau kode dengan alat seperti Codex Security untuk memperkuat keamanan dan keandalannya. Jika Anda tidak mengaktifkan sinkronisasi data pihak ketiga, data Anda tetap berada di server Anda. Ayakaleaf Pro tidak berisi telemetri yang mengirim data Anda ke tempat lain.

</Accordion>

<Accordion title="Q06: Apakah Ayakaleaf Pro akan dipelihara dalam jangka panjang?">

Kami akan berupaya sebaik mungkin untuk memelihara proyek ini dalam jangka panjang.

</Accordion>

<Accordion title="Q07: Apakah Ayakaleaf Pro patuh terhadap lisensi?">

Ayakaleaf Pro adalah fork komunitas. Kode dan fitur terintegrasinya berasal dari kontribusi komunitas. Proyek ini dilisensikan di bawah AGPL v3. Penerapan dapat mematuhi lisensi ini apabila memenuhi persyaratannya.

</Accordion>

<Accordion title="Q08: Mengapa proyek ini bernama Ayakaleaf Pro?">

Proyek ini awalnya bernama Overleaf Pro pada tahun 2024. Pengembangan sempat terhenti, lalu dimulai kembali pada akhir 2025. Pada kuartal pertama 2026, Overleaf mengganti nama paket langganan berkemampuan AI miliknya menjadi Pro. Masukan dari komunitas juga mencatat bahwa nama Overleaf Pro dapat menimbulkan risiko merek dagang dan peniruan identitas. Nama tersebut dapat membuat pengguna mengira proyek ini resmi.

Kami mengganti nama proyek menjadi Ayakaleaf Pro untuk menghindari kebingungan tersebut. Nama ini dapat dibaca sebagai "Ayaka-notes Overleaf Pro." Pengelola proyek (Anda bisa memanggil saya ayaka!) telah berkontribusi pada pengembangan komunitas Overleaf sejak masa kuliahnya, lebih dari lima tahun yang lalu. Pengalaman ini mendukung komitmen kami terhadap pemeliharaan jangka panjang.

</Accordion>

<Accordion title="Q09: Apa yang membedakan Ayakaleaf Pro dari editor LaTeX baru yang dibangun dengan AI?">

Sejak 2026, komunitas open source telah merilis banyak editor LaTeX yang dibangun dengan AI, termasuk OpenAI Prism. Ayakaleaf Pro menyimpan data dan layanan Anda di server Anda sendiri. Ini memberi Anda kendali langsung atas penerapan dan data Anda.

Banyak editor komunitas eksperimental tidak memiliki rencana pemeliharaan jangka panjang yang mapan. Platform kompilasi LaTeX pihak ketiga juga dapat berhenti beroperasi ketika basis pengguna atau pendapatannya tidak mencukupi. Ayakaleaf Pro menyediakan seluruh kode sumber dan memungkinkan Anda meng-host sendiri setiap layanan. Bahkan jika pemeliharaan dihentikan, layanan self-hosted Anda yang sudah ada dapat terus berjalan.

</Accordion>

### Fitur

<Accordion title="Q01: Fitur apa saja yang ditawarkan Ayakaleaf Pro? Bisakah saya meminta fitur baru?">

Silakan periksa dokumentasi kami untuk daftar fitur terkini. Jika ada fitur yang ingin Anda tambahkan, jangan ragu untuk membuka issue (untuk permintaan fitur) di GitHub. Kami akan berupaya sebaik mungkin untuk mengimplementasikan fitur yang diminta, tetapi pengembangan membutuhkan waktu, dan kami tidak dapat menjamin bahwa setiap fitur akan segera tersedia.

</Accordion>

<Accordion title="Q02: Saya telah membuat beberapa fitur. Bisakah saya mengirimkan PR, dan apakah PR tersebut pasti diterima?">

Kontribusi sangat diterima, tetapi penerimaannya tidak dijamin. Kami mengevaluasi setiap PR berdasarkan dampaknya terhadap basis kode Overleaf yang mendasarinya, beban pemeliharaannya, dan nilai yang dibawanya bagi pengguna. Kami akan berupaya sebaik mungkin untuk menggabungkan dan memelihara kontribusi yang bernilai.

Namun, kami dapat menolak PR yang memperkenalkan perubahan berlebihan, berisi kode hasil AI yang tidak ditinjau atau kurang dipahami ("vibe coding"), atau menambahkan fitur yang akan sulit dipelihara dalam jangka panjang.

</Accordion>

<Accordion title="Q03: Bagaimana cara mengonfigurasi fitur tertentu?">

Kami umumnya memperbarui dokumentasi setiap kali merilis fitur baru. Silakan merujuk ke dokumentasi yang relevan untuk petunjuk penyiapan terperinci dan penjelasan tentang variabel lingkungan yang tersedia.

</Accordion>

<Accordion title="Q04: Pustaka Python apa saja yang dapat digunakan oleh Python Runner?">

Python Runner menjalankan Python di browser pengguna dengan [Pyodide](https://pyodide.org/) 0.29.3, bukan di server. Python Runner memuat paket yang diimpor oleh kode Anda dari [paket bawaan Pyodide](https://pyodide.org/en/0.29.3/usage/packages-in-pyodide.html), seperti NumPy, pandas, dan Matplotlib. Paket yang diinstal dengan `pip` dan paket lainnya tidak tersedia. Tidak ada yang perlu dikonfigurasi di server.

</Accordion>

<Accordion title="Q05: Apakah pemeriksaan ejaan dapat memeriksa bahasa Jepang atau Mandarin?">

Tidak. Pemeriksa ejaan tidak memiliki kamus untuk bahasa Jepang atau Mandarin, sehingga bahasa-bahasa ini tidak ada dalam daftar bahasa pemeriksaan ejaan. Pengguna dapat menonaktifkan pemeriksaan ejaan untuk sebuah proyek di pengaturan editor.

</Accordion>

### Penerapan

<Accordion title="Q01: Apakah Ayakaleaf Pro mendukung penerapan terdistribusi di k8s?">

Bagi sebagian besar pengguna, kami menyarankan penerapan menggunakan [Toolkit](/id/on-premises/installation/using-the-toolkit). Kami tidak menyarankan penerapan klaster berskala besar menggunakan Kubernetes atau platform serupa, karena dapat meningkatkan kompleksitas operasional dan upaya pemeliharaan secara signifikan.

</Accordion>

<Accordion title="Q02: Bagaimana cara memastikan ketersediaan saat melayani ribuan pengguna?">

Silakan merujuk ke panduan [penskalaan horizontal](/id/on-premises/maintenance/horizontal-scaling) kami. Anda dapat menerapkan beberapa instans Overleaf dan mengonfigurasi load balancer untuk mendistribusikan lalu lintas di antara instans-instans tersebut.

</Accordion>

<Accordion title="Q03: Bisakah Anda membantu saya melakukan penerapan atau migrasi?">

Jika Anda memiliki instans Overleaf Server Pro yang sudah ada, kami dengan senang hati akan membantu Anda bermigrasi ke Ayakaleaf Pro. Silakan hubungi kami melalui email atau issue.

</Accordion>

<Accordion title="Q04: Bisakah saya meng-host Ayakaleaf Pro di bawah sub-path URL, seperti `https://example.com/overleaf`?">

Tidak. Ayakaleaf Pro harus disajikan dari root sebuah domain. Gunakan domain atau subdomain khusus, seperti `https://overleaf.example.com`.

</Accordion>

<Accordion title="Q05: Bisakah saya menjalankan Ayakaleaf Pro di Windows atau macOS, atau tanpa Toolkit?">

Kami mendukung server Linux dengan [Toolkit](/id/on-premises/installation/using-the-toolkit). Docker Desktop di Windows, WSL2, atau macOS mungkin berfungsi, tetapi kami tidak mengujinya, lihat [Pemecahan Masalah](/id/on-premises/support/troubleshooting) untuk masalah MongoDB yang diketahui.

Kami tidak menyediakan `docker-compose.yml` mandiri. Untuk melihat konfigurasi Compose yang digunakan oleh Toolkit, jalankan `bin/docker-compose config` di direktori Toolkit.

</Accordion>

<Accordion title="Q06: Bagaimana cara menghapus instalasi Ayakaleaf Pro?">

Tidak ada skrip uninstall. Di direktori Toolkit:

1. Hentikan dan hapus kontainer dengan `bin/docker-compose down`.
2. Hapus data. Secara default, data berada di direktori `data/` milik Toolkit. Jika Anda mengubah `OVERLEAF_DATA_PATH`, `MONGO_DATA_PATH`, `REDIS_DATA_PATH`, atau `GIT_BRIDGE_DATA_PATH` di `config/overleaf.rc`, hapus juga direktori-direktori tersebut. Tindakan ini tidak dapat dibatalkan, jadi [cadangkan](/id/on-premises/maintenance/data-and-backups) terlebih dahulu jika Anda mungkin memerlukan datanya.
3. Hapus direktori Toolkit.
4. Hapus image Docker, yang dapat Anda lihat daftarnya dengan `docker images`: `ghcr.io/ayaka-notes/overleaf-pro`, image git-bridge, `mongo`, `redis`, dan image TeX Live.

</Accordion>

<Accordion title="Q07: Bagaimana cara menghentikan, menjalankan, atau memulai ulang Ayakaleaf Pro?">

Jalankan perintah berikut di direktori Toolkit:

* `bin/stop` menghentikan semua kontainer, `bin/start` menjalankannya kembali. Kontainer tetap disimpan, sehingga pengguna tetap login.
* `bin/up -d` membuat kontainer dan menjalankannya di latar belakang. Jalankan setelah mengubah `config/variables.env`, `config/overleaf.rc`, atau `config/version`: perintah ini membuat ulang kontainer yang konfigurasinya berubah, dan barulah perubahan tersebut berlaku. `bin/stop` dan `bin/start` tidak menerapkannya.
* `bin/docker-compose restart sharelatex` hanya memulai ulang kontainer Overleaf, tanpa menerapkan perubahan konfigurasi.

Jika pengguna logout setiap kali `bin/up` membuat ulang kontainer, atur `OVERLEAF_SESSION_SECRET`, lihat Tanya Jawab di [Variabel Lingkungan](/id/on-premises/configuration/overleaf-toolkit/environment-variables).

</Accordion>

<Accordion title="Q08: Di mana saya memasukkan URL callback OAuth?">

Di aplikasi yang Anda buat di penyedia, bukan di Ayakaleaf Pro. Tidak ada pengaturan callback di `config/variables.env` untuk integrasi mana pun: Ayakaleaf Pro membangun setiap URL callback dari `OVERLEAF_SITE_URL` dan mengirimkannya ke penyedia, yang akan menolaknya kecuali cocok dengan yang terdaftar untuk aplikasi tersebut. Jadi Anda hanya perlu mendaftarkannya di penyedia, dan mengatur `OVERLEAF_SITE_URL` ke alamat yang dibuka pengguna.

| Integrasi | Kolom di penyedia | Nilai |
| --- | --- | --- |
| [GitHub](/id/on-premises/configuration/overleaf-toolkit/github-synchronisation) | Authorization callback URL | `${OVERLEAF_SITE_URL}/user/github-sync/oauth2/callback` |
| [GitLab](/id/on-premises/configuration/overleaf-toolkit/gitlab-synchronisation) | Redirect URI | `${OVERLEAF_SITE_URL}/user/gitlab-sync/oauth2/callback` |
| [Gitea](/id/on-premises/configuration/overleaf-toolkit/gitea-synchronisation) | Redirect URIs | `${OVERLEAF_SITE_URL}/user/gitea-sync/oauth2/callback` |
| [Dropbox](/id/on-premises/configuration/overleaf-toolkit/dropbox-synchronisation) | Redirect URIs (klik **Add**) | `${OVERLEAF_SITE_URL}/user/dropbox/oauth/callback` |
| [Zotero](/id/on-premises/configuration/overleaf-toolkit/zotero-integration) | Callback URL | `${OVERLEAF_SITE_URL}/user/zotero/oauth/callback` |
| [Mendeley](/id/on-premises/configuration/overleaf-toolkit/mendeley-integration) | Redirect URL | `${OVERLEAF_SITE_URL}/user/mendeley/oauth/callback` |
| [Login OIDC](/id/on-premises/configuration/overleaf-toolkit/authentication/oidc-authentication) | Redirect URI | `${OVERLEAF_SITE_URL}/oidc/login/callback` |
| [Login SAML](/id/on-premises/configuration/overleaf-toolkit/authentication/saml-authentication) | ACS URL (Assertion Consumer Service) | `${OVERLEAF_SITE_URL}/saml/login/callback` |

Jika Anda mengubah `OVERLEAF_SITE_URL`, misalnya ke domain baru, perbarui juga URL di setiap penyedia, jika tidak penautan akan gagal.

</Accordion>

### LaTeX

<Accordion title="Q01: Apakah kompilasi proyek LaTeX pengguna terisolasi? Apakah Shell Escape diaktifkan?">

Saat Anda mengaktifkan Sandbox Compiles, kompilasi setiap pengguna berjalan di kontainer Docker terpisah dan terisolasi dari kompilasi pengguna lain. Shell Escape diaktifkan secara default untuk Sandbox Compiles.

</Accordion>

<Accordion title="Q02: Apakah image Sandbox Compiles andal? Dapatkah kompilasi gagal?">

Kami telah menyempurnakan image TeX Live Full kami untuk Sandbox Compiles selama tiga tahun terakhir. Dalam sebagian besar kasus, proyek yang berhasil dikompilasi di overleaf.com juga dapat dikompilasi dengan benar menggunakan Ayakaleaf Pro. Jika font yang diperlukan tidak tersedia, unggah font tersebut ke proyek Anda secara manual.

</Accordion>

<Accordion title="Q03: Proyek saya tidak dapat dikompilasi. Bisakah Anda membantu saya memecahkan masalahnya?">

Silakan unggah proyek Anda ke situs web resmi Overleaf, aktifkan berbagi tautan hanya-baca, dan sertakan tautan tersebut dalam issue GitHub.

Kami akan menyelidiki dan memperbaiki bug apa pun yang mencegah proyek dikompilasi di Ayakaleaf Pro jika proyek tersebut berhasil dikompilasi di situs web resmi Overleaf. Masalah kompilasi di luar cakupan ini tidak termasuk dalam dukungan kami.

</Accordion>
