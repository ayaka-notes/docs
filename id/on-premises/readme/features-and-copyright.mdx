Kami menghormati hak cipta, sehingga di sini kami mencantumkan semua fitur dan kode yang digunakan dalam proyek ini. Di halaman ini, kami memberikan informasi tentang fitur-fitur baru Ayakaleaf Pro beserta hak cipta kode terkait.

Kecuali dinyatakan lain, kami menggunakan Codex dari OpenAI untuk tinjauan kode dan tinjauan PR. Selama proses ini, kami telah memperbaiki banyak masalah keamanan, dan kami menyampaikan terima kasih yang tulus kepada mereka. Untuk detailnya, lihat [ayaka-notes/ayakaleaf-pro/pull](https://github.com/ayaka-notes/ayakaleaf-pro/pulls).

### Ikhtisar

Selama bertahun-tahun, banyak pengembang komunitas telah melakukan upaya besar untuk meningkatkan Overleaf Community Edition. Mereka adalah:

* [https://github.com/ertuil/overleaf](https://github.com/ertuil/overleaf)
* [https://github.com/AllanChain/lcpu-overleaf](https://github.com/AllanChain/lcpu-overleaf)
* [https://github.com/yu-i-i/overleaf-cep/](https://github.com/yu-i-i/overleaf-cep/)
* [https://github.com/ayaka-notes/overleaf](https://github.com/ayaka-notes/overleaf)
* [https://github.com/davrot/overleaf\_with\_admin\_extension](https://github.com/davrot/overleaf_with_admin_extension)
* [https://github.com/overleaf/overleaf/pull/1447](https://github.com/overleaf/overleaf/pull/1447) (integrasi GitHub)
* [https://github.com/overleaf/overleaf/pull/1385](https://github.com/overleaf/overleaf/pull/1385) (dukungan Typst)

Kami mungkin telah menggunakan kode terkait dalam proyek kami, dan kami ingin menyampaikan terima kasih kepada mereka.

#### Fitur 05: Panel Admin

<Warning>

Ketika sistem Anda memiliki 1000 pengguna atau proyek, panel admin hanya akan menampilkan 1000 pengguna atau proyek terbaru. Silakan gunakan panel pencarian untuk mencari pengguna atau proyek tertentu.

</Warning>

Fitur ini terutama dikembangkan oleh [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep). Kami memodifikasi sebagian kode untuk penyempurnaan, sehingga Anda dapat:

* Mencari pengguna melalui backend ketika Anda memiliki lebih dari 1000 pengguna.
* Mencari proyek melalui backend ketika Anda memiliki lebih dari 1000 proyek.
* Membuka proyek langsung dari panel admin proyek.
* Melihat dan menyesuaikan batas waktu kompilasi pengguna di panel admin.
* Mengatur ulang kata sandi pengguna langsung di panel admin.
* Penyempurnaan lainnya...

#### Fitur 17: Integrasi Pengelola Referensi

Fitur ini dikembangkan oleh [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro). Integrasi Zotero awalnya dikembangkan oleh [davrot](https://github.com/davrot) dan [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep); kami mengerjakannya ulang dengan OAuth dan menambahkan integrasi Mendeley (OAuth 2.0) di v6.3.0. Anda dapat:

* Menautkan akun Zotero dan Mendeley Anda di Pengaturan akun.
* Mengimpor pustaka pribadi atau pustaka grup Anda sebagai file `.bib` ke dalam proyek Anda.
* Menyegarkan file `.bib` yang diimpor kapan saja agar tetap mutakhir.

Lihat [Integrasi Zotero](/id/on-premises/configuration/overleaf-toolkit/zotero-integration) dan [Integrasi Mendeley](/id/on-premises/configuration/overleaf-toolkit/mendeley-integration) untuk penyiapan.

#### Fitur 18: API Open in Overleaf

Fitur ini dikembangkan oleh [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro), kompatibel dengan API "Open in Overleaf" dari overleaf.com. Anda dapat menambahkan tautan atau tombol "Open in Ayakaleaf" ke situs web, blog, atau pustaka templat Anda, sehingga pengunjung dapat membuka cuplikan LaTeX, file jarak jauh, atau proyek ZIP sebagai proyek baru di instans Anda dengan satu klik. Kunjungi `/devs` di instans Anda untuk detailnya, dan lihat [API Impor Overleaf](/id/on-premises/configuration/overleaf-toolkit/overleaf-import-api).
