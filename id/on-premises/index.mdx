### Ikhtisar Overleaf

Overleaf adalah editor LaTeX kolaboratif yang disukai para peneliti dan tim teknologi. Versi cloud-nya tersedia di [overleaf.com](https://www.overleaf.com/). Versi ini menyediakan editor LaTeX online dengan fitur lengkap. Namun, Overleaf Common (versi SaaS) memiliki banyak keterbatasan fitur, dan Anda harus menoleransi _**batas waktu kompilasi 10 detik**_ serta biaya keanggotaan yang mahal.

Meskipun Overleaf menawarkan versi komunitas open-source (tersedia di [GitHub: Overleaf](https://github.com/overleaf/overleaf)), versi tersebut juga memiliki banyak keterbatasan, misalnya:

<Warning>

Overleaf Community Edition ditujukan untuk digunakan di lingkungan di mana **semua** pengguna tepercaya. Community Edition **tidak** cocok untuk skenario yang memerlukan isolasi pengguna karena Sandbox Compiles tidak tersedia.

Tanpa sandboxing, kompilasi LaTeX berjalan dengan hak akses yang sama dengan container, sehingga dapat mengakses filesystem, jaringan, dan variabel lingkungannya. Hal ini menimbulkan risiko kebocoran data atau kompromi sistem. Kompilasi tanpa sandbox hanya boleh digunakan di lingkungan yang sepenuhnya tepercaya; untuk deployment multi-pengguna atau produksi, Sandbox Compiles sangat disarankan.

Untuk informasi lebih lanjut tentang Sandbox Compiles, lihat: [sandboxed-compiles.md](/id/on-premises/configuration/overleaf-toolkit/sandboxed-compiles  "mention")

</Warning>

### Informasi dan Harga Overleaf Server Pro

Situs web Overleaf hanya menyediakan pintu masuk untuk menghubungi dukungan terkait Server Pro, sehingga informasi tentang Server Pro sangat terbatas. Namun berdasarkan informasi yang kami kumpulkan dari komunitas, **ketentuan kuota untuk Server Pro adalah**:

* Anda perlu membeli lisensi untuk _setidaknya_ 10 orang.
* Lisensi untuk 10 orang berharga sekitar €3,477.61. (2024)
* Untuk pendidikan, 20 pengguna berharga 2640 Euro per tahun, 50 pengguna 6050 Euro, dan 100 pengguna 9963 Euro.
* Server Pro hanya tersedia di wilayah tertentu (misalnya, tidak termasuk Tiongkok daratan).

Berdasarkan informasi yang tersedia saat ini, Overleaf Server Pro tampaknya berharga sekitar \$300 per pengguna per tahun, dengan pembelian minimum 10 lisensi, menjadikannya pilihan yang sangat mahal. Selain itu, Server Pro menawarkan fitur yang jauh lebih sedikit dibandingkan Ayakaleaf Pro. Kami sangat berterima kasih kepada para pengembang komunitas yang kontribusinya selama bertahun-tahun memungkinkan kami membangun Ayakaleaf Pro dan pada akhirnya melampaui Overleaf Server Pro dalam hal fungsionalitas maupun kemampuan.

Catatan publik berikut menunjukkan pembelian dan harga Overleaf Server Pro yang terdokumentasi. Kontrak-kontrak AS yang lebih kecil menunjukkan biaya tahunan sekitar \$320–\$370 per pengguna. Perjanjian institusional besar dapat memperoleh harga per pengguna yang lebih rendah. Misalnya, perjanjian tiga tahun Max Planck Society rata-rata sekitar €51 per pengguna setiap tahun. Ketentuan kontrak, dukungan, dan cakupan deployment dapat berbeda. Catatan ini bukan daftar harga resmi Overleaf.

### Mengapa Ayakaleaf Pro?

<Info>

Ayakaleaf Pro _**tidak**_ berafiliasi dengan Overleaf, Inc. maupun perusahaan induknya, Digital Science. Ayakaleaf Pro juga _bukan_ Edisi _Server Pro_, yang merupakan produk komersial yang ditawarkan oleh Overleaf, Inc. [ayaka-notes](https://github.com/ayaka-notes) mengembangkan dan memelihara Ayakaleaf Pro sebagai proyek independen.

</Info>

Ayakaleaf Pro adalah implementasi yang disempurnakan dari Overleaf Community Edition, yang menawarkan _**semua**_ fitur premium dari server pro secara _**gratis**_. Tidak seperti Overleaf Common yang tersedia di [https://www.overleaf.com/](https://www.overleaf.com/), maupun edisi komersial server pro, kami memiliki

* _**tanpa batasan**_ waktu kompilasi
* _**tanpa persyaratan lisensi**_ terkait jumlah pengguna
* _**semua fitur**_ server pro yang terbuka
