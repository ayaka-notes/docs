Pasang tautan di situs web, blog, atau halaman kursus Anda. Siapa pun yang mengkliknya mendapatkan proyek baru miliknya sendiri dengan file Anda. Tidak ada yang perlu disiapkan.

Pengunjung memerlukan akun di instans Anda. Pengunjung yang belum masuk akan diarahkan ke halaman masuk terlebih dahulu, dan proyek terbuka setelah masuk.

Halaman fitur ini menggunakan nama Overleaf. Tautan atau tombol Anda sendiri boleh bertuliskan apa saja, misalnya **Open in Ayakaleaf**.

## Lihat contohnya {#see-the-examples}

Buka `/devs` di situs Anda, misalnya `https://ayakaleaf.example.com/devs`. Tidak ada menu yang menautkan ke halaman ini, jadi ketik alamatnya. Secara default, Anda harus masuk untuk melihatnya.

## Menautkan ke file di situs web Anda {#link-to-a-file-on-your-website}

<Steps>
<Step title="Susun tautannya">
Letakkan alamat file, yang sudah dienkode URL, setelah `/docs?snip_uri=`:

```text
https://ayakaleaf.example.com/docs?snip_uri=https%3A%2F%2Fexample.com%2Fmain.tex
```

Untuk proyek dalam zip, gunakan `zip_uri`:

```text
https://ayakaleaf.example.com/docs?zip_uri=https%3A%2F%2Fexample.com%2Fproject.zip
```

Instans Anda mengunduh file tersebut, jadi file harus dapat dijangkau melalui HTTP atau HTTPS. Alamat di jaringan privat ditolak, lihat [External URL](/id/on-premises/configuration/overleaf-toolkit/external-url).
</Step>

<Step title="Tambahkan ke halaman Anda">
```html
<a href="https://ayakaleaf.example.com/docs?snip_uri=https%3A%2F%2Fexample.com%2Fmain.tex">Open in Ayakaleaf</a>
```
</Step>

<Step title="Klik tautannya">
Proyek baru terbuka di editor, dengan satu file yang disimpan sebagai `main.tex`.

<Frame caption="Proyek yang dibuka dari tautan">
  <img src="/images/on-premises/open-in-overleaf-project.png" alt="Proyek Hello from a link di editor, dengan main.tex dan PDF-nya" />
</Frame>

Setiap klik membuat proyek lain. Proyek tersebut adalah salinan, sehingga perubahan pada file Anda selanjutnya tidak sampai ke sana.
</Step>
</Steps>

## Memasukkan file ke dalam tautan {#put-the-file-in-the-link}

Untuk file kecil, Anda tidak perlu meng-hosting apa pun: masukkan isinya ke dalam tautan sebagai data URL Base64. Di JavaScript:

```javascript
const tex = '\\documentclass{article}\n\\begin{document}\nHello from a link.\n\\end{document}\n'
const link = 'https://ayakaleaf.example.com/docs?' + new URLSearchParams({
  snip_uri: 'data:application/x-tex;base64,' + btoa(tex),
  name: 'Hello from a link',
})
```

`btoa` hanya menerima karakter Latin-1, jadi enkode teks lain sebagai UTF-8 terlebih dahulu. Untuk proyek dalam zip, gunakan `zip_uri` dan `data:application/zip;base64,`.

Tautan yang lebih panjang dari sekitar 8 KB ditolak dengan error **414 Request-URI Too Large**. Untuk yang lebih besar, hosting file tersebut atau gunakan [formulir](#use-a-button-instead-of-a-link).

## Memilih opsi {#choose-the-options}

Tambahkan parameter ini ke tautan, atau ke formulir sebagai field tersembunyi:

| Parameter                   | Fungsinya                                                                                                                 | Contoh                                            |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| `name`                      | Memberi nama proyek. Tanpa parameter ini, proyek zip mengambil nama dari `\title`-nya, dan selain itu bernama `Open in Overleaf project`. | `name=My%20notes`                                  |
| `engine`                    | Mengatur compiler: `latex_dvipdf`, `pdflatex`, `xelatex`, atau `lualatex`.                                                      | `engine=xelatex`                                   |
| `main_document`             | Mengatur file `.tex` utama, yang dibuka pertama kali.                                                                                | `main_document=thesis.tex`                         |
| `snip_uri[]`, `snip_name[]` | Mengimpor beberapa file, masing-masing dengan namanya sendiri, dalam urutan yang sama.                                                            | `snip_uri[]=.../a.tex&snip_name[]=a.tex`           |

File `.tex` tanpa `\documentclass` dibungkus dalam dokumen standar, sehingga langsung dapat dikompilasi:

```latex
\documentclass[12pt]{article}
\usepackage[english]{babel}
\usepackage{amsmath}
\usepackage{tikz}
\begin{document}
Your file
\end{document}
```

## Menggunakan tombol sebagai ganti tautan {#use-a-button-instead-of-a-link}

Formulir mengirim parameter yang sama dengan tautan:

```html
<form action="https://ayakaleaf.example.com/docs" method="post" target="_blank">
  <input type="hidden" name="snip_uri" value="https://example.com/main.tex">
  <input type="hidden" name="engine" value="xelatex">
  <button type="submit">Open in Ayakaleaf</button>
</form>
```

Untuk mengirim LaTeX itu sendiri, gunakan `snip` untuk teks biasa atau `encoded_snip` untuk teks yang telah melalui `encodeURIComponent`.

Formulir tidak selalu berfungsi, sehingga tautan adalah pilihan yang lebih baik kecuali file Anda terlalu panjang untuk tautan:

| Lokasi formulir                                     | Pengunjung sudah masuk            | Pengunjung belum masuk        |
| ----------------------------------------------------- | ------------------------------- | ------------------------------- |
| Di domain yang sama dengan instans Anda, atau subdomainnya   | Proyek terbuka               | Halaman masuk, tanpa proyek      |
| Di domain lain                                     | Halaman masuk, tanpa proyek      | Halaman masuk, tanpa proyek      |

Jika administrator Anda mengatur `OVERLEAF_ALLOW_PUBLIC_ACCESS=true`, proyek terbuka dalam semua kasus ini, setelah masuk jika perlu. Pengaturan itu juga membuka halaman lain bagi pengunjung yang belum masuk, lihat [Page Access](/id/on-premises/configuration/overleaf-toolkit/authentication/public-access#page-access).

Untuk hal lain yang dapat diatur administrator, lihat [Overleaf Import API](/id/on-premises/configuration/overleaf-toolkit/integrations/overleaf-import-api). Halaman `/devs` memiliki lebih banyak contoh.

## Jika proyek tidak terbuka {#if-the-project-does-not-open}

Halaman memberi tahu apa yang salah. **View the Overleaf API docs** membawa Anda ke `/devs`.

<Frame caption="Tautan yang tidak dapat digunakan instans">
  <img src="/images/on-premises/open-in-overleaf-error.png" alt="Halaman Open in Overleaf dengan pesan invalid url dan tombol View the Overleaf API docs" />
</Frame>

| Pesan                                      | Penyebab                                                 | Yang perlu dilakukan                                  |
| -------------------------------------------- | --------------------------------------------------- | ------------------------------------------- |
| `no snippet, snip_uri or zip_uri provided`   | Tautan tidak memiliki satu pun parameter ini                          | Periksa nama parameter                   |
| `invalid url: ...`                           | Alamat tidak diawali HTTP atau HTTPS       | Gunakan alamat HTTP atau HTTPS, atau data URL |
| `could not download ... (HTTP 404)`          | File tidak ada di alamat tersebut                     | Periksa alamatnya                           |
| `could not download ... (HTTP 403)`          | Alamat berada di jaringan privat                 | Hosting file di tempat yang boleh dijangkau instans Anda |
| `zip_uri did not resolve to a zip archive`   | File di `zip_uri` bukan file zip         | Periksa filenya                              |
| `invalid base64 data url`                    | Data URL rusak                             | Enkode ulang file dan enkode URL tautannya |
