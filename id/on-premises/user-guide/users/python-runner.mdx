Skrip Python berjalan di browser Anda, sehingga keluarannya langsung muncul di bawah editor. Tidak ada yang perlu disiapkan.

<Steps>
<Step title="Buat skrip">
Di pohon file, klik ikon **New file**. Masukkan nama yang diakhiri `.py` lalu klik **Create**.

<Frame caption="File Python baru">
  <img src="/images/on-premises/python-runner-new-file.png" alt="Dialog Add Files dengan nama analysis.py" />
</Frame>

Tombol **Run** dan panel keluaran muncul di bawah editor. Pertama kali, tombol tetap nonaktif selama Python dimuat.
</Step>

<Step title="Jalankan">
Tulis kode Anda lalu klik **Run**. Apa yang dicetak skrip muncul di panel keluaran. Anda tidak perlu menyimpan terlebih dahulu.

File yang ditulis skrip masuk ke proyek Anda. Sebuah pesan memberi tahu file mana, misalnya **results.txt saved to your project**, dan file tersebut muncul di pohon file.

<Frame caption="Keluaran dan file yang tersimpan">
  <img src="/images/on-premises/python-runner-output.png" alt="Skrip di editor, keluaran cetaknya di bawah, dan pesan results.txt saved to your project" />
</Frame>
</Step>

<Step title="Hentikan skrip">
Saat skrip berjalan, **Run** berubah menjadi **Stop**. Klik untuk menghentikan skrip. Panel keluaran diakhiri dengan **Execution interrupted**.

<Frame caption="Skrip yang sedang berjalan">
  <img src="/images/on-premises/python-runner-stop.png" alt="Tombol Stop dan keluaran skrip yang sedang berjalan" />
</Frame>
</Step>
</Steps>

## Menggunakan gambar di dokumen Anda {#use-a-figure-in-your-document}

Plot tidak memiliki jendela untuk ditampilkan, jadi simpan ke file. Contoh:

```python
import matplotlib.pyplot as plt

plt.plot([1, 2, 3], [1, 4, 9])
plt.savefig("figure.png")
```

`figure.png` muncul di proyek Anda, siap untuk `\includegraphics{figure.png}`.

<Frame caption="Plot yang tersimpan">
  <img src="/images/on-premises/python-runner-figure.png" alt="figure.png terbuka di editor, dengan pesan figure.png saved to your project" />
</Frame>

## Membaca file proyek Anda {#read-your-project’s-files}

Skrip dapat membuka file proyek Anda berdasarkan path-nya:

```python
print(open("results.txt").read())
```

## Jika terjadi masalah {#if-something-goes-wrong}

<strong>Skrip memunculkan error.</strong> Error muncul berwarna merah di panel keluaran, setelah semua yang dicetak skrip sebelumnya.

<Frame caption="Error dalam skrip">
  <img src="/images/on-premises/python-runner-error.png" alt="Teks tercetak diikuti traceback berwarna merah" />
</Frame>

<strong>`ModuleNotFoundError: No module named ...`.</strong> Hanya paket bawaan Pyodide yang tersedia, dan paket yang dipasang dengan `pip` tidak dapat digunakan. NumPy dan Matplotlib termasuk yang tersedia, dan pesan tersebut menautkan ke [daftar lengkap](https://pyodide.org/en/stable/usage/packages-in-pyodide.html).

<Frame caption="Paket yang tidak tersedia">
  <img src="/images/on-premises/python-runner-missing-package.png" alt="ModuleNotFoundError di panel keluaran" />
</Frame>
