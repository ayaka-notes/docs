Pencarian referensi menelusuri semua file `.bib` di proyek Anda, sehingga Anda dapat menemukan referensi tanpa mengingat kunci kutipannya. Tidak ada yang perlu disiapkan.

Proyek Anda memerlukan setidaknya satu file `.bib`. Anda dapat mengunggahnya, atau mengimpor pustaka dari [Zotero](/id/on-premises/user-guide/users/zotero-integration) atau [Mendeley](/id/on-premises/user-guide/users/mendeley-integration).

## Menyisipkan kutipan {#insert-a-citation}

<Steps>
<Step title="Mulai kutipan">
Di file `.tex`, ketik `\cite{`. Editor menambahkan kurung kurawal penutup. Di bawah kursor, Anda melihat kunci kutipan dan kotak biru, **Open advanced reference search**.

<Frame caption="Kotak biru di bawah kutipan">
  <img src="/images/on-premises/reference-search-hint.png" alt="Editor dengan \cite{}, daftar kunci kutipan, dan kotak biru dengan tombol Search" />
</Frame>

Tombol **Insert citation** di bilah alat, serta **Insert** lalu **Citation**, juga memulai `\cite{}` untuk Anda. Kotak ini juga muncul untuk perintah kutipan lain, seperti `\citep`, `\autocite`, `\parencite`, dan `\textcite`.
</Step>

<Step title="Buka pencarian">
Klik **Search** di kotak biru, atau tekan Ctrl+Space di antara kurung kurawal. Dialog menampilkan setiap entri dengan judul, kunci kutipan, penulis, jurnal, dan tahunnya.

<Frame caption="Semua entri proyek">
  <img src="/images/on-premises/reference-search-dialog.png" alt="Dialog Search the .bib files in this project yang menampilkan lima entri" />
</Frame>
</Step>

<Step title="Temukan entri">
Ketik di kotak pencarian. Pencarian dilakukan pada kunci kutipan, penulis, judul, jurnal, dan tahun, serta menyorot yang ditemukan. Setiap kata harus cocok, jadi `turing 1936` menemukan makalah Turing tahun 1936. Bidang lain, seperti penerbit, tidak dicari.

<Frame caption="Mencari berdasarkan penulis dan tahun">
  <img src="/images/on-premises/reference-search-filter.png" alt="Kotak pencarian berisi turing 1936 dan satu entri dengan kecocokan berwarna merah" />
</Frame>
</Step>

<Step title="Pilih satu entri atau lebih">
Klik sebuah entri. Entri berubah hijau dan kuncinya muncul di atas daftar. Untuk menambahkan yang lain, klik entri tersebut atau cari lagi: pilihan Anda tetap tersimpan. Untuk menghapus satu entri, klik lagi entri itu atau klik <strong>×</strong> di samping kuncinya.

<Frame caption="Dua entri dipilih">
  <img src="/images/on-premises/reference-search-selected.png" alt="Kunci knuth1984 dan einstein1905 di atas daftar dan entrinya berwarna hijau" />
</Frame>
</Step>

<Step title="Klik Insert">
Kunci muncul di antara kurung kurawal, dipisahkan dengan koma. Jika dokumen Anda belum memiliki daftar pustaka, tambahkan baris berikut sebelum `\end{document}`, menggunakan nama file `.bib` Anda tanpa ekstensi:

```latex
\bibliographystyle{plain}
\bibliography{refs,more}
```

Klik **Recompile**. Referensi muncul di PDF.

<Frame caption="Kutipan yang dikompilasi">
  <img src="/images/on-premises/reference-search-compiled.png" alt="Editor dengan \cite{knuth1984, einstein1905} dan PDF dengan kedua referensi" />
</Frame>
</Step>
</Steps>

Pencarian bekerja dengan cara yang sama di editor **Visual**.

## Mengubah kutipan {#change-a-citation}

<strong>Menambahkan referensi:</strong> letakkan kursor di antara kurung kurawal kutipan yang ada dan buka pencarian. **Insert** menambahkan kunci baru setelah kunci yang sudah ada.

<strong>Mengganti referensi:</strong> pilih kunci di editor, lalu tekan Ctrl+Space. Kunci muncul di atas daftar dan tombol kini bertuliskan **Replace**. Hapus yang tidak Anda inginkan, tambahkan yang lain, lalu klik **Replace**. Kunci yang tidak ada di file `.bib` mana pun tetap ada sampai Anda menghapusnya.

<Frame caption="Mengganti kunci yang dipilih">
  <img src="/images/on-premises/reference-search-replace.png" alt="Dialog dengan knuth1984, missing2000, dan turing1936 di atas daftar serta tombol Replace" />
</Frame>

## Menggunakan keyboard {#use-the-keyboard}

| Tombol | Fungsinya |
| --- | ------------ |
| **Panah bawah** | Berpindah dari kotak pencarian ke daftar, lalu turun di daftar |
| **Panah atas** | Naik di daftar |
| **Spasi** | Memilih entri, atau menghapusnya dari pilihan Anda |
| **Enter** | Menyisipkan pilihan Anda, saat Anda berada di daftar |
| **Tab** | Berpindah antara kotak pencarian, daftar, dan tombol |
| **Esc** | Menutup dialog tanpa mengubah apa pun |

## Asal entri {#where-the-entries-come-from}

Pencarian mencakup setiap file `.bib` di proyek, termasuk file yang diimpor dari Zotero atau Mendeley. Saat Anda mengedit file `.bib`, pencarian berikutnya menemukan entri baru.

## Jika terjadi masalah {#if-something-goes-wrong}

| Yang Anda lihat | Penyebab | Yang harus dilakukan |
| ------------ | --- | ---------- |
| Daftar di dialog kosong | Proyek tidak memiliki file `.bib` | Unggah atau buat satu |
| Tidak ada kotak biru, dan Ctrl+Space menampilkan perintah LaTeX | Kursor tidak berada di antara kurung kurawal kutipan | Klik di antara kurung kurawal |
| Ctrl+Space tidak melakukan apa pun | Komputer Anda menggunakan pintasan ini untuk hal lain | Klik **Search** di kotak biru |
| Entri tidak ditemukan | Pencarian hanya mencakup kunci, penulis, judul, jurnal, dan tahun | Cari berdasarkan salah satu bidang tersebut |
