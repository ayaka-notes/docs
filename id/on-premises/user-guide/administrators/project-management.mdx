## Menemukan proyek {#find-a-project}

Ketik di **Search by project name, ID, owner or link**. Tautan dapat berupa alamat proyek atau salah satu tautan berbaginya. Gunakan filter **Status** untuk mempersempit daftar. Klik **Title** atau **Last modified** untuk mengurutkan.

Proyek yang dihapus tidak muncul di hasil. Jika pencarian Anda juga cocok dengan proyek yang dihapus, sebuah baris di atas tabel akan memberitahukannya, misalnya **Found 1 matching deleted projects**. Klik **Display deleted projects** untuk melihatnya.

## Status proyek {#project-status}

Setiap proyek memiliki satu status, dan filter **Status** menunjukkan berapa banyak proyek di setiap status.

<Frame caption="Filter Status">
  <img src="/images/on-premises/project-management-status-filter.png" alt="Filter Status dengan All, Active, Archived, Trashed, dan Deleted" />
</Frame>

| Status | Artinya |
| --- | --- |
| **All** | Semua proyek yang tidak dihapus. |
| **Active** | Keadaan normal. |
| **Archived** | Pemilik mengarsipkannya. Proyek masih utuh dan dapat dikembalikan. |
| **Trashed** | Pemilik memindahkannya ke tempat sampah. Proyek masih utuh dan dapat dikembalikan. |
| **Deleted** | Dihapus oleh pemilik dari tempat sampah, oleh administrator, atau bersama akun pemilik. Hanya administrator yang dapat mengembalikannya. |

Proyek melewati status secara bertahap:

1. **Active, Archived, dan Trashed** dipilih oleh pemilik di halaman proyeknya sendiri. Pemilik selalu dapat kembali. **Restore** dari tempat sampah selalu mengarah ke Active, meskipun proyek sebelumnya diarsipkan.
2. **Deleted** adalah tahap berikutnya. Pemilik hanya dapat menghapus dari tempat sampah; administrator dapat menghapus dari salah satu dari ketiganya.
3. **Restore** mengembalikan proyek yang dihapus sebagai **Active**, apa pun status sebelumnya, dan namanya mendapat `(Restored)` di akhir. Hanya administrator yang dapat melakukannya. Jika akun pemilik juga dihapus, pulihkan akunnya terlebih dahulu: jika tidak, dialog menyatakan **The owner of this project is deleted: restore the owner first**.
4. **Delete permanently** adalah tahap terakhir dan tidak dapat dibatalkan. Selain itu, proyek yang dihapus tetap ada sampai Anda menghapusnya, kecuali instans menetapkan [`ENABLE_CRON_RESOURCE_DELETION`](/id/on-premises/configuration/overleaf-toolkit/environment-variables), yang menghapusnya setelah 90 hari.

<Info>

Status hanya mengikuti pemilik. Saat kolaborator mengarsipkan proyek bersama atau memindahkannya ke tempat sampah, proyek hanya berpindah di halaman proyek kolaborator itu, dan status di sini tetap sama.

</Info>

## Tindakan pada proyek {#actions-on-a-project}

| Ikon | Tindakan | Fungsinya |
| --- | --- | --- |
| Buka | **Open Project** | Membuka proyek di editor, di tab baru. |
| Folder | **Change project owner** | Memberikan proyek kepada pengguna lain. |
| Tempat sampah | **Delete** | Memindahkan proyek ke **Deleted**. |
| Panah | **Restore** | Mengembalikan proyek yang dihapus. Hanya untuk proyek yang dihapus. |
| Tempat sampah dicoret | **Delete permanently** | Menghapus proyek yang dihapus secara permanen. Hanya untuk proyek yang dihapus. |

### Mengubah pemilik {#change-the-owner}

Klik ikon folder, ketik nama atau email, pilih pengguna, lalu klik **Change project owner**. Dialog memperingatkan bahwa tindakan ini tidak dapat dibatalkan, dan bahwa pemilik baru akan diberi tahu dan dapat mengubah pengaturan akses proyek. Akun yang dinonaktifkan tidak ditawarkan. Jika Anda mengubah teks setelah memilih, pilihan dibatalkan: pilih pengguna lagi.

<Frame caption="Mengubah pemilik proyek">
  <img src="/images/on-premises/project-management-change-owner.png" alt="Dialog Change project owner dengan peringatan dan pemilik baru yang dipilih" />
</Frame>

Untuk memindahkan semua proyek pengguna sekaligus, lihat [Mentransfer proyek pengguna](/id/on-premises/user-guide/administrators/user-management#transfer-a-users-projects).

### Menghapus, memulihkan, atau menghapus permanen {#delete-restore-or-permanently-delete}

Klik ikon tempat sampah, lalu **Delete**. Untuk menemukan proyek lagi, pilih **Deleted** di filter **Status**.

<Frame caption="Proyek yang dihapus">
  <img src="/images/on-premises/project-management-deleted.png" alt="Proyek yang dihapus di daftar dengan ikon Restore dan Delete permanently" />
</Frame>

Klik ikon panah, lalu **Restore**, untuk mengembalikannya, atau tempat sampah dicoret, lalu **Delete permanently**, untuk menghapusnya.

<Frame caption="Menghapus proyek secara permanen">
  <img src="/images/on-premises/project-management-purge.png" alt="Dialog Delete permanently yang memperingatkan bahwa tindakan tidak dapat dibatalkan" />
</Frame>

### Mengubah beberapa proyek sekaligus {#change-several-projects-at-once}

Centang proyek di daftar. Tombol muncul di samping pencarian: **Download**, **Change project owner**, dan **Delete**. **Download** menyimpan proyek yang dipilih dalam satu file `.zip`. Dengan **Change project owner**, pemilik saat ini dari proyek yang dicentang tidak dapat dipilih. Di tampilan **Deleted**, tombolnya adalah **Restore** dan **Delete permanently**.

<Frame caption="Tindakan massal">
  <img src="/images/on-premises/project-management-bulk.png" alt="Dua proyek yang dicentang dan tombol Download, Change project owner, dan Delete" />
</Frame>

## Halaman proyek {#the-project-page}

Klik judul proyek untuk membuka halamannya. Di bagian atas ada ikon untuk mengedit, membuka, mengunduh, dan menghapus proyek. Halaman ini memiliki lima tab.

### Ringkasan {#overview}

Detail dan pengaturan proyek. Klik ikon pensil untuk mengubah **Name**, **Link sharing**, **Compiler**, **TeX Live version**, dan **Main document**, atau untuk mengklik **Change project owner**. Lalu klik **Save**.

<Frame caption="Mengedit proyek">
  <img src="/images/on-premises/project-management-edit.png" alt="Tab Overview dalam mode edit" />
</Frame>

### Pohon file {#file-tree}

File dan folder proyek, hanya baca.

<Frame caption="File proyek">
  <img src="/images/on-premises/project-management-files.png" alt="Tab File tree yang mencantumkan frog.jpg, main.tex, dan file bib yang dipulihkan" />
</Frame>

### Anggota {#members}

Siapa yang memiliki akses: pemilik, kolaborator, dan undangan yang tertunda. Klik ikon pensil untuk mengubahnya:

* Pilih **Editor**, **Reviewer**, atau **Viewer** untuk kolaborator. Perubahan langsung berlaku.
* Klik tempat sampah di samping kolaborator, lalu **Remove access**.
* Untuk undangan yang tertunda, klik amplop untuk **Resend invite**, atau tempat sampah untuk **Revoke Invite**.

Klik **Done** setelah selesai. Pemilik tidak dapat diubah di sini: gunakan **Change project owner** di tab **Overview**.

<Frame caption="Mengubah anggota proyek">
  <img src="/images/on-premises/project-management-members.png" alt="Tab Members dalam mode edit dengan menu peran, undangan tertunda, dan ikon tindakan" />
</Frame>

### File yang dihapus {#deleted-files}

File yang dihapus dari proyek. Klik ikon panah di samping file, lalu **Restore file**. Salinan dengan tanggal di namanya dimasukkan ke folder root proyek, dan baris tersebut menampilkan namanya. File yang dihapus tetap ada di daftar.

Salinan muncul di tab **File tree** setelah Anda memuat ulang halaman.

<Frame caption="File yang dipulihkan">
  <img src="/images/on-premises/project-management-deleted-files.png" alt="Tab Deleted files yang menampilkan sample.bib dan nama salinan yang dipulihkan" />
</Frame>

### Log audit {#audit-logs}

Apa yang terjadi pada proyek ini: tanggal, operasi, siapa yang melakukannya, alamat IP, dan detail. Cari di dalamnya, atau filter berdasarkan **Operation**.

<Frame caption="Log audit proyek">
