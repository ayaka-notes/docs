يسعدنا أن نعلن عن إصدار Ayakaleaf Pro 6.2، محرر LaTeX عبر الإنترنت الأقوى والأغنى بالميزات في المجتمع. شكر خاص لـ yu-i-i وdavrot على مساهماتهما القيّمة؛ فقد حسّنا GitHub Sync وقدّما البحث المتقدم عن الاستشهادات (Advanced Citation Search) والتكامل مع Zotero.

### ملاحظات

* أُضيف متغير بيئة جديد إلزامي هو `OVERLEAF_INVITE_TOKEN_SECRET`، ويجب عليك إنشاؤه باستخدام: `openssl rand -base64 32` وإذا لم يُضبط، فسيفشل مثيل Overleaf في البدء.
* إذا فعّلت GitHub Sync، فيجب عليك ضبط متغير البيئة `GITHUB_TOKEN_CIPHER_PASSWORD`. هذا المتغير مطلوب لتشفير رموز الوصول إلى GitHub بشكل آمن. وبدونه، سيفشل مثيل Overleaf في البدء.
* أُضيف متغير بيئة جديد `DEFAULT_LATEX_COMPILER` لتعيين المترجم الافتراضي الذي تستخدمه المشاريع الجديدة (pdflatex أو latex أو xelatex أو lualatex).
* أصبح المحرر المعاد تصميمه الخيار الوحيد المتاح الآن.

### التغييرات

يتضمن هذا الإصدار التحسينات والميزات الجديدة التالية.

* أصبح `MAX_UPLOAD_SIZE` قابلًا للإعداد الآن بدلًا من أن يكون محدودًا بـ **50 MB**.
* إصلاح حلقة إعادة تشغيل الحاوية عند تعطيل sandboxed compiles.
* فرض حذف رموز PAT ضمن نطاق المالك في OAuth2.
* إصلاح مشكلة في استيراد LDAP.

وتشمل الميزات:

* إضافة مشغّل Python يعمل في المتصفح.
* إضافة دعم Pandoc لاستيراد وتصدير Markdown وDOCX وصيغ أخرى.
* إضافة GitHub Sync.
* إضافة ترجمات صينية كاملة.
* إضافة التكامل مع Zotero.
* إضافة `DEFAULT_LATEX_COMPILER`.

#### الميزة 01: GitHub Sync

حافظ على مزامنة مشاريع LaTeX الخاصة بك مع مستودعات GitHub لسير عمل تطوير سلس. ادفع التغييرات واسحبها مباشرةً من المحرر، وتعاون عبر طلبات السحب (pull requests)، وتكامل مع خطوط CI/CD الحالية. يسهّل التحكم في الإصدارات تتبع المراجعات ومراجعة التغييرات والحفاظ على وثائق أكاديمية أو تقنية قابلة لإعادة الإنتاج.

راجع: [GitHub Synchronisation](/ar/on-premises/configuration/overleaf-toolkit/github-synchronisation  "mention").

#### الميزة 02: الاستيراد/التصدير عبر Pandoc

استورد مستندات Microsoft Word وMarkdown إلى مشاريع LaTeX قابلة للتحرير بالكامل، أو صدّر مشاريع LaTeX مرة أخرى إلى Markdown وDOCX بنقرة واحدة. تعمل هذه الميزة بتقنية Pandoc، وتتيح قابلية تشغيل بينية سلسة بين الكتابة الأكاديمية والتحرير التعاوني وسير عمل النشر، مع الحفاظ على بنية المستند قدر الإمكان.

راجع: [الاستيراد والتصدير عبر Pandoc](/ar/on-premises/configuration/overleaf-toolkit/pandoc-import-and-export  "mention").

#### الميزة 03: البحث المتقدم عن المراجع

ابحث عن المراجع الببليوغرافية وأدرجها من قواعد بيانات أكاديمية متعددة مع تصفية ذكية ودعم فوري للاستشهادات. اكتشف الأوراق البحثية بسرعة، واستعرض بياناتها الوصفية، وأنشئ مدخلات BibTeX دقيقة دون التنقل بين مواقع بحثية مختلفة، مما يحسّن كفاءة مراجعة الأدبيات بشكل كبير.

![صورة](https://github.com/user-attachments/assets/42e45b73-af4b-4d1f-81f4-9e116ba5d043)

#### الميزة 04: مشغّل Python

نفّذ شيفرة Python مباشرةً داخل مشروعك دون مغادرة المحرر. مثالي لإنشاء الأشكال، ومعالجة مجموعات البيانات، وأتمتة سير عمل المستندات، أو تشغيل سكربتات بحثية قابلة لإعادة الإنتاج. يمكن دمج النتائج في مستندات LaTeX الخاصة بك، مما يجعل الحوسبة العلمية والكتابة جزءًا من سير عمل موحد.

![صورة](https://github.com/user-attachments/assets/a4c314b3-fdb5-4836-aea7-12eeece5cd2f)

#### الميزة 05: Zotero

اربط مكتبة Zotero الخاصة بك مباشرةً بسير عمل الكتابة، وأدِر المراجع دون مغادرة المحرر. ابحث في مجموعات Zotero الشخصية، وأدرج الاستشهادات بنقرة واحدة، وأنشئ مدخلات BibTeX وزامنها تلقائيًا. يحافظ هذا التكامل على تحديث قائمة مراجعك، مما يبسّط إدارة الأدبيات للأوراق الأكاديمية والأطروحات والوثائق التقنية.

راجع: [التكامل مع Zotero](/ar/on-premises/configuration/overleaf-toolkit/zotero-integration  "mention").
