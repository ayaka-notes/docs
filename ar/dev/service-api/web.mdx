واجهة برمجة خاصة لـ web، تطبيق Overleaf الرئيسي. تستدعيها الخدمات الأخرى (real-time وdocument-updater وproject-history وthird-party-datastore وgit-bridge) وبرامج cron في صورة Server CE. لا تحتاج هذه المسارات إلا إلى مصادقة HTTP الأساسية، دون رمز CSRF: إذ يُركّب الموجّه الخاص قبل موجّه web، ولا يجري فحص CSRF إلا موجّه web. مع `BLOCK_CROSS_ORIGIN_REQUESTS=true` (معطّل افتراضيًا) تعيد web الرمز 403 لأي طلب لا يكون رأس `Origin` فيه ضمن `ALLOWED_ORIGINS` (الافتراضي: عنوان الموقع). ترسل المتصفحات `Origin` مع طلبات POST، لذا عند تفعيل هذا الخيار تتلقى طلبات POST المرسلة من Hoppscotch في المتصفح الرمز 403 ما لم تمرّ عبر وكيل Hoppscotch.

* <strong>العنوان:</strong> `http://web:3000`, داخل شبكة Docker
* <strong>المصادقة:</strong> مصادقة HTTP الأساسية باستخدام `WEB_API_USER` و`WEB_API_PASSWORD`، باستثناء status وhealth وmetrics. تستخدم مسارات git-bridge رمز وصول شخصيًا بدلًا من ذلك.
* <strong>ملف OpenAPI:</strong> [`develop/hoppscotch/openapi/web.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/web.yaml)
