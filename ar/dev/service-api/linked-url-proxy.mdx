تجلب عنوان URL خارجيًا لصالح web وتبثّ الاستجابة مرة أخرى، وترفض العناوين الداخلية حتى لا يصل المستخدمون إلى شبكة Docker. تمرّر web عبرها ملفات URL وعمليات استيراد Open in Overleaf وweb_fetch الخاص بوكيل الذكاء الاصطناعي.

* <strong>العنوان:</strong> `http://linked-url-proxy:3066`, داخل شبكة Docker
* <strong>المصادقة:</strong> لا شيء
* <strong>ملف OpenAPI:</strong> [`develop/hoppscotch/openapi/linked-url-proxy.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/linked-url-proxy.yaml)
