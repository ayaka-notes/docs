تترجم CLSI ‏(Common LaTeX Service Interface) المشاريع، وتشغّل SyncTeX وtexcount على ناتج الترجمة، وتحوّل المستندات باستخدام pandoc. تستدعيها web؛ أما ملفات الناتج نفسها فيقدّمها clsi-nginx لا هذا المنفذ. لا مصادقة: لا يمكن الوصول إليها إلا من داخل شبكة Docker.

* <strong>العنوان:</strong> `http://clsi:3013`, داخل شبكة Docker
* <strong>المصادقة:</strong> لا شيء
* <strong>ملف OpenAPI:</strong> [`develop/hoppscotch/openapi/clsi.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/clsi.yaml)
