تخزّن كل مستند (الأسطر والإصدار والنطاقات) لكل مشروع في مجموعة Mongo ‏`docs`، وتؤرشف المستندات في تخزين الكائنات عند ضبط واجهة خلفية. تستدعيها web؛ ويصل إليها document-updater عبر web.

* <strong>العنوان:</strong> `http://docstore:3016`, داخل شبكة Docker
* <strong>المصادقة:</strong> لا شيء
* <strong>ملف OpenAPI:</strong> [`develop/hoppscotch/openapi/docstore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/docstore.yaml)
