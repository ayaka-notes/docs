تخزّن السجل الكامل لكل مشروع: أجزاء التغييرات في Mongo أو Postgres وتخزين الكائنات، ومحتوى الملفات ككائنات blob. يكتب project-history التغييرات إليها؛ وتقرأ منها web وproject-history وgit-bridge كائنات blob واللقطات وملفات zip.

* <strong>العنوان:</strong> `http://history-v1:3100`, داخل شبكة Docker
* <strong>المصادقة:</strong> مصادقة HTTP الأساسية باسم `staging` مع `STAGING_PASSWORD`، أو JWT، بحسب المسار.
* <strong>ملف OpenAPI:</strong> [`develop/hoppscotch/openapi/history-v1.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/history-v1.yaml)
