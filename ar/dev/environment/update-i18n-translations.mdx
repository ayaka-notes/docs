---
title: تحديث ترجمات i18n
icon: language
---

يوجد ملف في `services/web/frontend/extracted-translations.json`، ولن تستخدم واجهة Overleaf على الويب سوى الترجمات المستخرجة الموجودة في هذا الملف.

شغّل الأمر التالي لتحديث الترجمات المستخرجة إذا أضفت بعض المحتوى.

```bash
user ➜ ~/overleaf-pro/develop (server-pro) $ bin/shell webpack
root@432836260f8a:/overleaf/services/web# npm run extract-translations
```

بشكل عام، يُرجى عدم تعديل ملفات نصوص الترجمة، واستخدم الترجمات الموجودة أولًا، لأن جميع هذه الملفات تُحدَّث من مستودع Overleaf الأصلي أو من موقع ترجمة تابع لجهة خارجية.
