---
title: مجموعة OAuth Authorization Codes
icon: lock-open
---

صُمّمت `oauthAuthorizationCodes` لرموز تدفق OAuth authorization code: مستند واحد لكل رمز، يستبدله العميل برمز وصول. المخطط موجود في `services/web/app/src/models/OauthAuthorizationCode.mjs`، والشيفرة التي كانت ستكتب فيها موجودة في وحدة web `oauth2-server`. في Ayakaleaf Pro لا يصل أي شيء إلى تلك الشيفرة، لذا تبقى المجموعة فارغة (انظر الملاحظات).

#### الحقول {#fields}

| الحقل | النوع | المعنى | المصدر |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | معرّف المستند. | `OauthAuthorizationCode.mjs:6` |
| `authorizationCode` | String | الرمز نفسه، يُخزَّن كما هو (من دون تجزئة). | `OauthAuthorizationCode.mjs:8`, `services/web/modules/oauth2-server/app/src/OAuth2Model.mjs:280` |
| `expiresAt` | Date | نهاية الصلاحية. بعدها يرفض `getAuthorizationCode` الرمز، ويحذفه فهرس TTL. | `OauthAuthorizationCode.mjs:9`, `OAuth2Model.mjs:150-153,281` |
| `oauthApplication_id` | ObjectId | العميل في [OAuth Applications](/ar/dev/data-model/oauth-applications-collection) الذي طلب الرمز. | `OauthAuthorizationCode.mjs:10`, `OAuth2Model.mjs:275-284` |
| `redirectUri` | String | عنوان URI لإعادة التوجيه في الطلب. | `OauthAuthorizationCode.mjs:11`, `OAuth2Model.mjs:282` |
| `scope` | String | النطاق المطلوب. | `OauthAuthorizationCode.mjs:12`, `OAuth2Model.mjs:283` |
| `user_id` | ObjectId | المستخدم الذي منح الرمز. | `OauthAuthorizationCode.mjs:13`, `OAuth2Model.mjs:285` |
| `codeChallenge`, `codeChallengeMethod` | String | تحدي PKCE وطريقته. | `OauthAuthorizationCode.mjs:14-15`, `OAuth2Model.mjs:286-287` |

#### من يكتب فيها {#who-writes-it}

| الشيفرة | ما تفعله |
| ---- | ------------ |
| `OAuth2Model.mjs:274-300` (`saveAuthorizationCode`) | تُدرج رمزاً. لا يُوصل إليها، انظر الملاحظات. |
| `OAuth2Model.mjs:307-312` (`revokeAuthorizationCode`) | تحذف الرمز بعد استخدامه. لا يُوصل إليها. |

#### من يقرأ منها {#who-reads-it}

| الشيفرة | ما تفعله |
| ---- | ------------ |
| `OAuth2Model.mjs:137-177` (`getAuthorizationCode`) | تحمّل الرمز مع مستخدمه وعميله. لا يُوصل إليها. |

#### الفهارس {#indexes}

| الاسم | المفاتيح | الخيارات | الترحيل |
| ---- | ---- | ------- | --------- |
| `expiresAt_1` | `{ expiresAt: 1 }` | TTL، `expireAfterSeconds: 0`، جزئي: `expiresAt` موجود | `20230406125632_oauth_tokens_ttl.mjs` |

الترحيلات موجودة في `tools/migrations/`. يأتي الفهرس الفريد `authorizationCode_1` فقط من ترحيلات موسومة بـ `saas` و`server-pro`، ولا يشغّلها Community Edition.

#### ملاحظات {#notes}

* لا تستدعي طرق النموذج أعلاه إلا معالجات authorize وtoken في `@node-oauth/oauth2-server`. يستخدم web هذه المكتبة للتحقق من رموز bearer فقط (`services/web/app/src/Features/Authentication/AuthenticationController.mjs:409-450`)، ولا يوجد مسار يخدم `/oauth/authorize` أو `/oauth/token`، لذا لا يُكتب أي رمز أبداً. تُنشأ رموز الوصول الشخصية مباشرة، انظر [OAuth Access Tokens](/ar/dev/data-model/oauth-access-tokens-collection).
