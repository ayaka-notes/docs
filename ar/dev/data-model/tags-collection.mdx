---
title: مجموعة الوسوم (Tags)
icon: tags
---

`tags` تحفظ الوسوم (المجلدات) التي يصنّف فيها المستخدم مشاريعه في لوحة المشاريع. كل مستند هو وسم واحد لمستخدم واحد. المالك هو `web`؛ المخطط هو `services/web/app/src/models/Tag.mjs`، وكل عمليات الكتابة تمر عبر `services/web/app/src/Features/Tags/TagsHandler.mjs`.

#### الحقول {#fields}

| الحقل | النوع | المعنى | المصدر |
| --- | --- | --- | --- |
| `_id` | ObjectId | معرّف الوسم، ويُستخدم في المسارات `/tag/:tagId`. | `Tag.mjs:10` |
| `user_id` | String | مالك الوسم. سلسلة نصية عادية وليست ObjectId، لأسباب تاريخية. | `Tag.mjs:7-12` |
| `name` | String | اسم الوسم، 50 حرفًا على الأكثر (`MAX_TAG_LENGTH`). فريد لكل مستخدم. | `Tag.mjs:13`, `TagsHandler.mjs:4` |
| `color` | String | لون اختياري: رمز ست عشري مثل `#a1b2c3` أو قيمة `hsl(<n>, 70%, 45%)` (`TAG_COLOR_REGEX`). | `Tag.mjs:5`, `Tag.mjs:14-22` |
| `project_ids` | Array of String | معرّفات المشاريع في هذا الوسم، كسلاسل نصية. | `Tag.mjs:23` |
| `__v` | Number | مفتاح إصدار Mongoose، يُضاف عندما ينشئ `Tag.create` المستند. | `TagsHandler.mjs:27` |

#### ملاحظات {#notes}

* الوسوم خاصة بكل مستخدم: يحتفظ كل من متعاونَين على المشروع نفسه بوسومه الخاصة له.
* `user_id` و`project_ids` سلاسل نصية، لذا استعلم عنها بمعرّفات نصية لا بـ ObjectId.
* حذف مستخدم (`services/web/app/src/Features/User/UserDeleter.mjs`) لا يمس `tags`.
