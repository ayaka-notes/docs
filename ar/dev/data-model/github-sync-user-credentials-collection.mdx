title: مجموعة GitHub Sync User Credentials
icon: key
---

تحتفظ `githubSyncUserCredentials` بمستند واحد لكل مستخدم ربط حساب GitHub من أجل GitHub Sync. وهي تخزّن رمز وصول OAuth الخاص بالمستخدم مشفّرًا. تنتمي المجموعة إلى وحدة الويب `github-sync` (`services/web/modules/github-sync`). المخطط موجود في `services/web/modules/github-sync/app/models/githubSyncUserCredentials.mjs`، وكل وصول يمر عبر `services/web/modules/github-sync/app/src/TokenManager.mjs`.

#### الحقول {#fields}

| الحقل | النوع | المعنى | المصدر |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | يضبطه Mongoose عندما يُدرج الـ upsert المستند. | |
| `userId` | ObjectId | مستخدم Overleaf. مطلوب. يذكر المخطط `unique: true`، لكن لا يُبنى أي فهرس (انظر الفهارس)؛ ويحافظ الـ upsert حسب `userId` على مستند واحد لكل مستخدم. | `githubSyncUserCredentials.mjs:8`, `TokenManager.mjs:44-48` |
| `github` | String | رمز وصول OAuth الخاص بـ GitHub، مشفّر باستخدام `@overleaf/access-token-encryptor`. تأتي كلمة المرور من `GITHUB_TOKEN_CIPHER_PASSWORD`؛ وتسمية التشفير هي `GITHUB_TOKEN_CIPHER_LABEL`، والافتراضي `2026.3-v3`. مطلوب. | `githubSyncUserCredentials.mjs:9`, `TokenManager.mjs:12-25` |
| `__v` | Number | مفتاح الإصدار في Mongoose. لا يعطّله المخطط. | افتراضي في Mongoose |

يُخزَّن رمز الوصول فقط: تحتفظ دالة رد نداء OAuth بـ `access_token` من استجابة GitHub (`services/web/modules/github-sync/app/src/GitHubApiClient.mjs:180-191`). لا يوجد رمز تحديث ولا وقت انتهاء.

#### من يكتب فيها {#who-writes-it}

| الشيفرة | ما تفعله |
| ---- | ------------ |
| `TokenManager.mjs:42-58` (`saveUserToken`) | تُجري upsert للرمز المشفّر الخاص بالمستخدم. عندما يعيد المستخدم الربط، يُلغى الرمز المستبدَل لدى GitHub في الخلفية. تُستدعى من رد نداء OAuth (`services/web/modules/github-sync/app/src/GitHubSyncController.mjs:146`). |
| `TokenManager.mjs:61-76` (`removeUserToken`) | تُلغي الرمز لدى GitHub (بأفضل جهد)، ثم تحذف المستند. تُستدعى عند إلغاء الربط (`GitHubSyncController.mjs:167`) وعندما تنتهي صلاحية مستخدم محذوف (`services/web/modules/github-sync/index.mjs:66-68`). |

#### من يقرأ منها {#who-reads-it}

| الشيفرة | ما تفعله |
| ---- | ------------ |
| `TokenManager.mjs:36-40` (`getUserToken`) | تفك تشفير الرمز لكل استدعاء لواجهة GitHub البرمجية: `services/web/modules/github-sync/app/src/GitHubSyncHandler.mjs` (مثل `:27`) و`services/web/modules/github-sync/app/src/GitMerge.mjs:43`. عند عدم وجود مستند، أو وجود رمز لا يمكن فك تشفيره، ترمي `InvalidTokenError`، ويُعدّ المستخدم غير مرتبط (`GitHubSyncHandler.mjs:25-37`). |
| `services/web/modules/admin-tools/app/src/AdminUserListManager.mjs:393` | تتحقق مما إذا كان لدى المستخدم مستند، من أجل التكاملات المعروضة في لوحة الإدارة. |

#### الفهارس {#indexes}

| الاسم | المفاتيح | الخيارات | الترحيل |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

الخيار `autoIndex` في Mongoose معطّل (`services/web/app/src/infrastructure/Mongoose.mjs:7`)، لذا لا ينشئ `unique: true` في المخطط على `userId` أي شيء. يحمل `tools/migrations/20190912145011_create_githubSyncUserCredentials_indexes.mjs` (`user_id` من upstream) الوسم `saas` فقط ولا يعمل في CE.

#### ملاحظات {#notes}

* تغيير `GITHUB_TOKEN_CIPHER_PASSWORD` يجعل الرموز المخزّنة غير قابلة للقراءة. ويُعدّ هؤلاء المستخدمون حينها غير مرتبطين حتى يعيدوا الربط.
* يحتفظ المستخدم المحذوف بالمستند حتى تنتهي صلاحيته.
