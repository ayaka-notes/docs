---
title: مجموعة Project History Labels
icon: tag
---

تحتفظ `projectHistoryLabels` بالتسميات التي يضعها المستخدمون على الإصدارات في عرض History، مستند واحد لكل تسمية. تملكها project-history وتكتبها في `services/project-history/app/js/LabelsManager.js`؛ لا يوجد مخطط Mongoose. لا يصل إليها web إلا عبر واجهة project-history البرمجية.

#### الحقول {#fields}

| الحقل | النوع | المعنى | المصدر |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | معرّف التسمية. | `LabelsManager.js:81-85` |
| `project_id` | ObjectId | المشروع. | `LabelsManager.js:73` |
| `comment` | String | نص التسمية. | `LabelsManager.js:74` |
| `version` | Number | إصدار سجل المشروع الذي تشير إليه التسمية. | `LabelsManager.js:75` |
| `created_at` | Date | وقت إنشاء التسمية؛ يمكن للطلب تمرير وقته الخاص، وإلا فالوقت الحالي. | `LabelsManager.js:70`, `76` |
| `user_id` | ObjectId | من أنشأ التسمية. يُحذف عندما لا يحتوي الطلب على مستخدم. | `LabelsManager.js:78-80` |

#### من يكتبها {#who-writes-it}

| الكود | ماذا يفعل |
| ---- | ------------ |
| `services/project-history/app/js/LabelsManager.js:44-90` | `createLabel`: يُدرج تسمية، لمسار project-history `POST /project/:project_id/labels` (`services/project-history/app/js/HttpController.js:1134-1171`). يستدعيه web عندما يضيف مستخدم تسمية، مع معرّف المستخدم (`services/web/app/src/Features/History/HistoryController.mjs:529-546`). |
| `LabelsManager.js:113-126` | `deleteLabel`: يحذف تسمية من المشروع، لـ `DELETE /project/:project_id/labels/:label_id`. يستخدمه web عندما يحذف مالك المشروع تسمية (`HistoryController.mjs:649-670`). |
| `LabelsManager.js:92-111` | `deleteLabelForUser`: يحذف تسمية فقط إن كان المستخدم هو من أنشأها، لـ `DELETE /project/:project_id/user/:user_id/labels/:label_id`. يستخدمه web لكل من سواه. |
| `LabelsManager.js:128-143` | `transferLabels`: ينقل كل تسميات مستخدم إلى مستخدم آخر، لـ `POST /user/:from_user/labels/transfer/:to_user` (`services/project-history/app/js/Router.js:52-55`). لا شيء في web يستدعي هذا المسار. |
| `LabelsManager.js:7-25` | `cloneLabels`: ينسخ تسميات مشروع إلى مشروع آخر، لمسار project-history `POST /project/:project_id/clone` (`HttpController.js:113`)، الذي لا يستدعيه شيء في web. |

#### من يقرؤها {#who-reads-it}

| الكود | ماذا يفعل |
| ---- | ------------ |
| `LabelsManager.js:27-42` | `getLabels`: كل تسميات المشروع، تُعاد بالشكل `{ id, comment, version, user_id, created_at }` (`LabelsManager.js:163-171`). يستخدمها `GET /project/:project_id/labels` (`HttpController.js:1076-1100`)، الذي يستدعيه web لعرض History ويملأ أسماء المستخدمين (`HistoryController.mjs:488-499`). |
| `services/project-history/app/js/SummarizedUpdatesManager.js:57` | يضيف التسميات إلى قائمة تحديثات السجل. |

#### ملاحظات {#notes}

* قبل إدراج تسمية، تعالج project-history التحديثات المصطفة للمشروع وتتحقق من أن لدى history-v1 قطعة chunk لذلك الإصدار، ما لم يرسل الطلب `validate_exists: false` (`LabelsManager.js:53-59`، `173-195`؛ `HttpController.js:1109-1115`).
* لا يحذف أي كود تسميات المشروع عند حذفه: لا يمسح project-history `DELETE /project/:project_id` إلا حالة المزامنة وسجل الفشل (`HttpController.js:1363-1396`)، ولا تمس أي خدمة أخرى هذه المجموعة.
