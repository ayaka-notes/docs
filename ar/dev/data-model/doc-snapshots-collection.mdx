تحتفظ `docSnapshots` بنسخ من مستند يلتقطها document-updater قبل تعديلٍ يطوي التعليقات أو التغييرات المتتبَّعة مباشرة. لا يكتب فيها إلا document-updater، في `services/document-updater/app/js/SnapshotManager.js`. لدى web نموذج Mongoose في `services/web/app/src/models/DocSnapshot.mjs`، لكن لا يستخدمه أي كود.

#### الحقول {#fields}

| الحقل | النوع | المعنى | المصدر |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | معرّف اللقطة. | `SnapshotManager.js:24` |
| `project_id` | ObjectId | المشروع. | `SnapshotManager.js:19,26`, `DocSnapshot.mjs:7` |
| `doc_id` | ObjectId | المستند (`docs._id`). | `SnapshotManager.js:20,27`, `DocSnapshot.mjs:8` |
| `version` | Number | إصدار OT للمستند قبل التعديل. | `SnapshotManager.js:28`, `services/document-updater/app/js/UpdateManager.js:132,264-271`, `DocSnapshot.mjs:9` |
| `lines` | Array of String | محتوى المستند قبل التعديل. | `SnapshotManager.js:29`, `DocSnapshot.mjs:10` |
| `pathname` | String | مسار المستند في المشروع في ذلك الوقت. | `SnapshotManager.js:30`, `DocSnapshot.mjs:11` |
| `ranges` | Mixed | `comments` و`changes` قبل التعديل، بالبنية نفسها التي لـ `docs.ranges` (راجع [docs](/ar/dev/data-model/docs-collection)). تُحوَّل `id` و`op.t` و`metadata.user_id` إلى ObjectId و`metadata.ts` إلى Date. | `SnapshotManager.js:31,41-68`, `DocSnapshot.mjs:12` |
| `ts` | Date | وقت التقاط اللقطة. يحذف فهرس TTL اللقطة بعد 30 يومًا. | `SnapshotManager.js:32`, `DocSnapshot.mjs:13` |

#### من يكتبها {#who-writes-it}

| الكود | ماذا يفعل |
| ---- | ------------ |
| `UpdateManager.js:248-271` | بعد أن يطبّق document-updater تعديلًا، يسجّل المستند كما كان قبل التعديل إذا طوى التعديل نطاقات: أصبحت نطاقات أكثر فارغة، أو أُزيل أكثر من نطاق واحد (`services/document-updater/app/js/RangesManager.js:104-106`). |
| `SnapshotManager.js:17-36` `recordSnapshot` | يُدرج اللقطة. |

#### من يقرؤها {#who-reads-it}

لا يقرؤها أي كود. نموذج web معرَّف لكنه غير مستخدم في أي مكان.

#### ملاحظات {#notes}

* لا تلتقط اللقطات إلا التعديلات التي تمر عبر `UpdateManager.applyUpdate`. التعديلات التي يعالجها `HistoryOTUpdateManager` لا تلتقطها (`UpdateManager.js:74-77`).
* لا يوجد فهرس على `doc_id`. ابحث عن لقطات مستند باستخدام `project_id` و`ts`، ثم صفِّ حسب `doc_id`.
