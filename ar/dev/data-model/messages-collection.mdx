تحتفظ `messages` بمستند واحد لكل رسالة: سطر في دردشة المشروع، أو تعليق أو ردّ في سلسلة تعليقات المراجعة. لا تكتب فيها إلا خدمة chat، في `services/chat/app/js/Features/Messages/MessageManager.js`. لا يوجد مخطط Mongoose. تنتمي كل رسالة إلى غرفة في مجموعة [rooms](/ar/dev/data-model/rooms-collection).

#### الحقول {#fields}

| الحقل | النوع | المعنى | المصدر |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | معرّف الرسالة. | `MessageManager.js:13-14` |
| `room_id` | ObjectId | الغرفة (`rooms._id`)، وليس معرّف المشروع ولا معرّف السلسلة. | `MessageManager.js:8,106-108` |
| `user_id` | ObjectId | الكاتب. | `MessageManager.js:9,103-105` |
| `content` | String | نص الرسالة، من 1 إلى 10240 حرفًا (`MAX_MESSAGE_LENGTH`). | `MessageManager.js:7`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:3,12-15` |
| `timestamp` | Number | وقت الإرسال بالمللي ثانية منذ 1970 (`Date.now()`)، وليس Date. | `MessageManager.js:10`, `services/chat/app/js/Features/Messages/MessageHttpController.js:288` |
| `edited_at` | Number | وقت آخر تعديل بالمللي ثانية (`Date.now()`). غير موجود إن لم تُعدَّل قط. | `MessageManager.js:65-69`, `MessageHttpController.js:189,213` |

#### من يكتبها {#who-writes-it}

| الكود | ماذا يفعل |
| ---- | ------------ |
| `MessageManager.js:5-16` `createMessage` | يُدرج رسالة (`MessageHttpController.js:275-294`). يرسل web رسائل دردشة المشروع من `services/web/app/src/Features/Chat/ChatController.mjs:32`، والتعليقات من وحدة track-changes (`services/web/modules/track-changes/app/src/TrackChangesController.mjs:95`) ووحدة mcp-server (`services/web/modules/mcp-server/app/src/CommentTools.mjs:133`). |
| `MessageManager.js:51-72` `updateMessage` | يضبط `content` و`edited_at`. عند تمرير معرّف مستخدم، لا تطابق إلا رسالة ذلك المستخدم (`MessageManager.js:62-64`). يُستدعى من `ChatController.mjs:135` و`TrackChangesController.mjs:110`. |
| `MessageManager.js:74-80` `deleteMessage` | يحذف رسالة واحدة. يُستدعى من `ChatController.mjs:105` و`TrackChangesController.mjs:129`. |
| `MessageManager.js:39-49` `deleteAllMessagesInRoom(s)` | يحذف رسائل سلسلة محذوفة (`MessageHttpController.js:172-173`) أو رسائل مشروع كامل عند انتهاء صلاحية مشروع محذوف (`MessageHttpController.js:261-271`، يُستدعى من `services/web/app/src/Features/Project/ProjectDeleter.mjs:391`). |
| `MessageManager.js:115-127` `duplicateRoomToOtherRoom` | ينسخ `content` و`timestamp` و`user_id` لكل رسالة إلى غرفة أخرى، دون `edited_at`. يُستخدم عندما تكرّر استعادة السجل سلسلةً (`MessageHttpController.js:316-342`)، وعند نسخ مشروع مع نطاقاته (`MessageHttpController.js:344-357`). |

#### من يقرؤها {#who-reads-it}

| الكود | ماذا يفعل |
| ---- | ------------ |
| `MessageManager.js:18-29` `getMessages` | الأحدث أولًا، بحد أقصى `limit` (الافتراضي 50) أقدم من `before` (قيمة `timestamp`). يُستخدم لدردشة المشروع (`ChatController.mjs:80`). |
| `MessageManager.js:31-37` `findAllMessagesInRooms` | جميع رسائل بعض الغرف، لقائمة السلاسل في لوحة المراجعة (`TrackChangesController.mjs:82`) ووحدة mcp-server (`CommentTools.mjs:83`) واستعادة السجل (`services/web/app/src/Features/History/RestoreManager.mjs:259`). يتحقق web أيضًا من أول رسالة في السلسلة كي لا يغيّر المراجع إلا السلاسل التي بدأها (`services/web/app/src/Features/Authorization/AuthorizationManager.mjs:409-411`). |
| `MessageManager.js:90-100` `getMessage` | رسالة واحدة. يتحقق web من `user_id` الخاص بها قبل أن يعدّل المستخدم رسالته أو يحذفها (`services/web/app/src/Features/Authorization/AuthorizationMiddleware.mjs:253-257`، `TrackChangesController.mjs:124-125`). |

#### ملاحظات {#notes}

* للعثور على رسائل تعليق، ابحث أولًا عن الغرفة باستخدام `project_id` و`thread_id`، ثم استعلم عن `room_id`. معرّف التعليق في المستند هو `thread_id`، وليس `room_id`.
* النص الذي يشير إليه التعليق هو `op.c` في `docs.ranges.comments`؛ أما النقاش فهنا.
