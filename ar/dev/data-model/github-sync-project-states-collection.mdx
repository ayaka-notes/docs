تحتفظ `githubSyncProjectStates` بمستند واحد لكل مشروع مرتبط بمستودع GitHub: أي مستودع هو، وأين توقفت آخر مزامنة. تنتمي المجموعة إلى وحدة الويب `github-sync` (`services/web/modules/github-sync`). المخطط موجود في `services/web/modules/github-sync/app/models/githubSyncProjectStates.mjs`، وكل وصول يمر عبر `services/web/modules/github-sync/app/src/SyncStateManager.mjs`.

| الحقل | النوع | المعنى | المصدر |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | يضبطه Mongoose عند الإنشاء. | |
| `projectId` | ObjectId | المشروع المرتبط. مطلوب. يذكر المخطط `unique: true`، لكن لا يُبنى أي فهرس (انظر الفهارس). | `githubSyncProjectStates.mjs:8` |
| `repoFullName` | String | المستودع بصيغة `owner/name` (قيمة `full_name` في GitHub). مطلوب. | `githubSyncProjectStates.mjs:9` |

#### من يكتب فيها {#who-writes-it}

| الشيفرة | ما تفعله |
| ---- | ------------ |
| `SyncStateManager.mjs:9-14` (`createProjectState`) | تنشئ المستند: بعد استيراد مستودع كمشروع جديد (`services/web/modules/github-sync/app/src/GitHubSyncHandler.mjs:175-181`)، أو بعد تصدير مشروع إلى مستودع جديد (`GitHubSyncHandler.mjs:235-241`، للمالك فقط، ويُرفض إذا كان مرتبطًا بالفعل). |
| `SyncStateManager.mjs:16-21` (`updateProjectState`) | `$set` للحقول المتغيرة. تضبط `getMergeOverview` القيمة `mergeStatus: 'diverged'` عندما لا يعود الفرع المُزامَن مبنيًا على `lastSyncCommit`: تُجيب مقارنة GitHub بـ `diverged` أو `behind` (`GitHubApiClient.mjs:382-400`)، أو يكون الإيداع قد اختفى ويستطيع المستخدم الدفع (`GitHubSyncHandler.mjs:123,126-137`). عند نجاح المزامنة (`services/web/modules/github-sync/app/src/GitMerge.mjs`) تُحرّك `lastSyncCommit`/`lastSyncVersion` (مثل `:143,173,224`)، وتسجّل التعارض في `unmergedBranchName` و`unmergedBranchHead` و`conflictVersion` (`:207-213`)، وتمسحها بعد حلّه (`:250-257`). |
| `SyncStateManager.mjs:23-25` (`removeProjectState`) | تحذف المستند عندما يلغي المالك ربط المشروع (`GitHubSyncHandler.mjs:83-97`) وعندما تنتهي صلاحية مشروع محذوف (`services/web/modules/github-sync/index.mjs:56-58`). |

#### الفهارس {#indexes}

| الاسم | المفاتيح | الخيارات | الترحيل |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

الخيار `autoIndex` في Mongoose معطّل (`services/web/app/src/infrastructure/Mongoose.mjs:7`)، لذا لا ينشئ `unique: true` في المخطط على `projectId` أي شيء. يحمل `tools/migrations/20190912145010_create_githubSyncProjectStates_indexes.mjs` (`project_id` و`owner_id` من upstream) الوسم `saas` فقط ولا يعمل في CE.

#### ملاحظات {#notes}

* تعمل المزامنة تحت قفل `gitSync` الخاص بالمشروع (`GitMerge.mjs:17-24`). يأخذ GitLab Sync وGitea Sync القفل نفسه، لذا لا تعمل إلا مزامنة واحدة لكل مشروع في الوقت نفسه.
* يحتفظ المشروع المحذوف بمستنده حتى تنتهي صلاحيته.
* رمز GitHub الخاص بالمستخدم موجود في [GitHub Sync User Credentials](/ar/dev/data-model/github-sync-user-credentials-collection).
