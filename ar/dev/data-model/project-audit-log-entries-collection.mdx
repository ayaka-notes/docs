`projectAuditLogEntries` هي سجل تدقيق المشاريع: المشاركة، والدعوات، ونقل الملكية، والتنزيلات، وإجراءات المسؤولين. كل مستند هو حدث واحد في مشروع واحد. المالك هو `web`؛ المخطط هو `services/web/app/src/models/ProjectAuditLogEntry.mjs`، وتكتب النواة عبر `services/web/app/src/Features/Project/ProjectAuditLogHandler.mjs`.

| الحقل | النوع | المعنى | المصدر |

| `projectId` | ObjectId | المشروع الذي يخصه الحدث. | `ProjectAuditLogEntry.mjs:6` |
| `operation` | String | ما حدث، باسم بصيغة kebab-case مثل `send-invite` (انظر الجدول أدناه). | `ProjectAuditLogEntry.mjs:8` |
