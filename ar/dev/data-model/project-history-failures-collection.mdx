---
title: مجموعة Project History Failures
icon: triangle-exclamation
---

تحتفظ `projectHistoryFailures` بمستند واحد لكل مشروع لم تتمكن project-history من معالجة تحديثات سجله، أو بدأت له إعادة مزامنة. يُحذف المستند مجددًا بمجرد نجاح المعالجة. تكتبها project-history في `services/project-history/app/js/ErrorRecorder.js`؛ ونوعها في `services/project-history/app/js/mongo-types.ts:3-24`. لدى web أيضًا مخطط Mongoose لها (`services/web/app/src/models/ProjectHistoryFailure.mjs:5-19`)، لكن لا يستخدم أي كود في web هذا النموذج.

#### ملاحظات {#notes}

* يبقى المستند حتى ينجح flush للمشروع أو يُحذف المشروع (`clearError` أعلاه)، لذا يشير كل مستند إلى مشروع لم ينجح آخر flush أو إعادة مزامنة له بعد.
* سلاسل الأخطاء التي تبدأ بـ `OError:` تُعاد بالشكل `Error:` (`ErrorRecorder.js:18-26`)؛ ولا تتغير القيمة المخزّنة.
