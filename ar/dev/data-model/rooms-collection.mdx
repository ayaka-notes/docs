تحتفظ `rooms` بمستند واحد لكل غرفة دردشة في المشروع: دردشة المشروع، أو سلسلة تعليقات مراجعة واحدة. لا تكتب فيها إلا خدمة chat، في `services/chat/app/js/Features/Threads/ThreadManager.js`. لا يوجد مخطط Mongoose. رسائل الغرفة موجودة في مجموعة [messages](/ar/dev/data-model/messages-collection).

#### الحقول {#fields}

| الحقل | النوع | المعنى | المصدر |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | معرّف الغرفة. يشير `messages.room_id` إلى هنا. | `ThreadManager.js:57-61` |
| `project_id` | ObjectId | المشروع الذي تنتمي إليه الغرفة. | `ThreadManager.js:43-54` |
| `thread_id` | ObjectId | في سلاسل التعليقات فقط: معرّف التعليق، وهو نفسه `id` و`op.t` للتعليق في `docs.ranges.comments` (راجع [docs](/ar/dev/data-model/docs-collection)). غير موجود في غرفة دردشة المشروع. | `ThreadManager.js:38-55`, `services/docstore/app/js/RangeManager.js:54-57` |
| `resolved` | Object | يُضبط عند حل السلسلة، ويُزال عند إعادة فتحها. السلسلة التي لا تحتوي عليه مفتوحة. | `ThreadManager.js:94-123` |
| `resolved.user_id` | String | معرّف المستخدم الذي حلّ السلسلة. يُخزَّن كسلسلة نصية لا كـ ObjectId: يُتحقق فقط من أن جسم الطلب معرّف صالح، ولا يُحوَّل. | `ThreadManager.js:103`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:70` |
| `resolved.ts` | Date | وقت حل السلسلة. | `ThreadManager.js:104` |

#### ملاحظات {#notes}

* للمشروع غرفة واحدة على الأكثر بلا `thread_id`: دردشة المشروع. تجدها خدمة chat باستخدام `thread_id: { $exists: false }` (`ThreadManager.js:38-45`).
* حالة الحل للتعليق موجودة هنا فقط. يزيل Docstore `op.resolved` قبل حفظ النطاقات (`services/docstore/app/js/RangeManager.js:59-61`).
* بعد نسخ مشروع، يوجد `thread_id` نفسه في مشروعين. استعلم دائمًا باستخدام `project_id` و`thread_id` معًا، كما تفعل خدمة chat.
* تبقى غرف المشروع المحذوف حتى تنتهي صلاحية المشروع المحذوف.
