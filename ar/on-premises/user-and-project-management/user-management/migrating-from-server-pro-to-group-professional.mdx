---
title: الترحيل من Server Pro إلى Group Professional
icon: rectangle-pro
noindex: true
---

يُعد الانتقال من نسخة Server Pro مستضافة ذاتيًا إلى اشتراك Overleaf Group Professional جديد قائم على السحابة تغييرًا كبيرًا، لذا أعددنا الإرشادات التالية لجعل هذه العملية سلسة قدر الإمكان.

بشكل عام، نقترح فترة تداخل مدتها ثلاثة أشهر تبدأ من تاريخ التجديد. وهذا يعني ما يلي:

* ستكون نسخة Server Pro الحالية واشتراك Group Professional الجديد نشطين بالكامل في الوقت نفسه.
* يمكن لفريقك التقني جدولة وقت لإعداد اشتراك Group Professional واتخاذ قرار بشأن مستقبل نشر Server Pro المحلي لديكم.
* والأهم من ذلك، سيحظى مستخدموك بوقت كافٍ لنسخ مشاريعهم إلى منصة Overleaf Group Professional الجديدة.

سيرشدك هذا الدليل السريع خلال الخطوات الرئيسية لهذا الترحيل. لنبدأ!

<Steps>
<Step title="المرحلة 1: الإعداد والتهيئة">
(الرابط: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-1-setup-and-configuration)

* ستنشئ Overleaf اشتراك Group Professional الخاص بك وتضيف المسؤول الرئيسي (Lead Administrator).
* سيتمكن مسؤول المجموعة من تفعيل [المستخدمين المُدارين (Managed Users)](https://docs.overleaf.com/groups/user-management/managed-user-accounts)، وتهيئة [تسجيل الدخول الموحّد (SSO)](https://docs.overleaf.com/groups/overleaf-group-single-sign-on/setting-up-group-sso)، و[دعوة المستخدمين النهائيين](https://docs.overleaf.com/groups/user-management/how-to-add-and-remove-users).

<Warning>

يُعد تفعيل Managed Users وتطبيق SSO خطوة مطلوبة للامتثال لـ FedRAMP® LI-SaaS. إذا كانت مؤسستك تتطلب الامتثال لـ FedRAMP، فقم بإعداد Managed Users وSSO قبل دعوة المستخدمين النهائيين.

</Warning>
</Step>

<Step title="المرحلة 2: ترحيل المستخدمين وإدارة البيانات">
(الرابط: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-2-user-migration-and-data-management)

هذه هي نافذة الترحيل الرئيسية، وتتضمن المسؤوليات التالية:

#### المستخدمون النهائيون

* يجب على المستخدمين ترحيل أي مشاريع يرغبون في الاحتفاظ بها من نسخة Server Pro إلى حساباتهم الجديدة على [overleaf.com](http://overleaf.com/). تتضمن العملية [تصدير المشاريع](https://www.overleaf.com/learn/how-to/Exporting_your_work_from_Overleaf) من Server Pro و[رفعها](https://www.overleaf.com/learn/how-to/Uploading_a_project) إلى حساباتهم على [overleaf.com](http://overleaf.com/). إذا لم يكن لدى المستخدم حساب على [overleaf.com](http://overleaf.com/) بالفعل، فيمكنه التسجيل على [overleaf.com/register](http://overleaf.com/register).

<Warning>

لن يُنقل عبر إجراء التصدير هذا سوى الشيفرة المصدرية للمشروع (ملفات LaTeX والملفات الثنائية). لن تُنقل أي إعدادات حالية للمشروع أو إعدادات المشاركة أو التعليقات أو التغييرات المتعقَّبة وما إلى ذلك. سيحتاج المستخدمون إلى إعادة دعوة المتعاونين معهم بعد الترحيل.

</Warning>

#### الفريق التقني

* خلال هذه المرحلة، يجب على فريقك التقني التخطيط لكيفية التعامل مع نسخة Server Pro المحلية وبياناتها بعد الترحيل.
* <strong>النسخ الاحتياطي للبيانات:</strong> يمكنك تصدير جميع المشاريع قبل إيقاف التشغيل لإنشاء أرشيف يتيح لك مساعدة المستخدمين الذين ربما نسوا ترحيل أعمالهم أو تنزيلها. التعليمات: https://docs.overleaf.com/on-premises/maintenance/data-and-backups/exporting-projects
* <strong>إيقاف تشغيل Server Pro:</strong> بعد انتهاء نافذة الترحيل وتعطيل مفتاح الترخيص، يكون لديك خياران رئيسيان بالنسبة لنسخة Server Pro نفسها (انظر الخطوات التالية).
</Step>

<Step title="خيارات إيقاف تشغيل Server Pro">
<Steps>
<Step title="إلغاء تثبيت Server Pro بالكامل">
يؤدي إلغاء التثبيت إلى إيقاف تشغيل Server Pro وإزالة البرنامج بالكامل.
</Step>

<Step title="التحويل إلى Community Edition">
يحافظ التحويل على قاعدة بيانات المستخدمين والمشاريع مع سجل المشاريع الكامل، وذلك بتحويل النسخة من Server Pro إلى Community Edition.
</Step>
</Steps>

<Info>

لا يتضمن Community Edition ميزة [الترجمة المعزولة (Sandboxed Compiles)](https://docs.overleaf.com/on-premises#overview-of-server-pro-and-community-edition) ولا [LDAP](/ar/on-premises/configuration/overleaf-toolkit/authentication/ldap-authentication)/[SAML](/ar/on-premises/configuration/overleaf-toolkit/authentication/saml-authentication). إذا احتجت إلى العودة إلى المصادقة الأصلية (اسم المستخدم/كلمة المرور)، فراجع: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-to-ldap-or-saml#going-the-other-way-switching-from-ldap-saml-back-to-native-authentication

للاطلاع على مقارنة بين Server CE وServer Pro، راجع: https://docs.overleaf.com/on-premises/welcome/server-pro-vs.-community-edition

</Info>
</Step>

<Step title="المرحلة 3: إيقاف تشغيل Server Pro">
(الرابط: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-3-server-pro-decommission)

* سيقوم فريق Overleaf بإلغاء تفعيل مفتاح ترخيص Server Pro رسميًا، وسيرسل تأكيدًا عند الانتهاء.
* عند ذلك، نفّذ أحد إجراءات إيقاف التشغيل الموضحة أعلاه: إلغاء تثبيت Server Pro بالكامل أو التحويل إلى Community Edition.
</Step>
</Steps>

تبقى الموارد الإضافية والروابط المشار إليها أعلاه دون تغيير.
