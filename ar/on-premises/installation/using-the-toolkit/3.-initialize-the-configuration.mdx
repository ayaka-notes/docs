### تهيئة الإعدادات

لنُهيّئ ملفات إعدادات الخادم الجديد بقيم افتراضية معقولة عبر تشغيل السكربت المرفق `bin/init`.

```text title="Run initialization"
bin/init
```

لن يقوم هذا السكربت **بالكتابة فوق** أي ملفات إعدادات موجودة.

لنتحقق الآن من محتويات المجلد `config/` باستخدام الأمر `ls`:

```text title="List the config directory"
ls config
```

إذا تمت التهيئة بنجاح، فستظهر لك ثلاثة ملفات إعدادات: `overleaf.rc` و`variables.env` و`version`. هذه هي ملفات الإعدادات الرئيسية للخادم، وتتيح لك تخصيص طريقة عمل الخادم وكيفية تفاعل المستخدمين مع المثيل الخاص بك.

| الاسم            | الوصف                                             |
| --------------- | ------------------------------------------------------- |
| `overleaf.rc`   | ملف الإعدادات الرئيسي ذو المستوى الأعلى.                  |
| `variables.env` | متغيرات البيئة التي تُحمَّل داخل حاوية Docker. |
| `version`       | إصدار صورة Docker المراد استخدامه.                 |

<Info>

يكفي في الوقت الحالي أن تعرف أن هذه الملفات موجودة وأين تجدها. وسنتناول لاحقًا في الوثائق كل ملف منها بمزيد من التفصيل، ونشرح كيف يمكنك تخصيص المثيل الخاص بك باستخدامها. وإذا أردت الانتقال مباشرة، يمكنك الاطلاع على شرح كامل لملفات الإعدادات هذه في [صفحة الملفات والمواقع](/ar/on-premises/configuration/overleaf-toolkit/files-and-locations).

</Info>
