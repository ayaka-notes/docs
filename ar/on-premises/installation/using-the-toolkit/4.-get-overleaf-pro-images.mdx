---
title: 4. الحصول على صور Ayakaleaf Pro
icon: split
---

يُوزَّع Ayakaleaf Pro على شكل صورة Docker في سجل [ghcr](https://github.com/ayaka-notes/overleaf-pro/pkgs/container/overleaf-pro/)، وهو **متاح للجميع**. نوفّر صورًا لمعماريتي amd64 وarm64. عند سحب الصورة، سيتم اختيار الصورة المناسبة تلقائيًا بناءً على معمارية نظامك.

#### مستخدمو Ayaka-notes Toolkit

إذا كنت تستخدم [ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)، فيمكن استخدام Ayakaleaf Pro بديلًا مباشرًا لـ Community Edition، بحيث يمكنك الاحتفاظ بإعداداتك وتخصيصاتك الحالية. فعّل Pro في الـ Toolkit بتحرير `config/overleaf.rc` وتعيين متغير البيئة `SERVER_PRO`:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

في المرة التالية التي تشغّل فيها `bin/up`، سيقوم الـ Toolkit تلقائيًا بتنزيل صورة Ayakaleaf Pro واستخدامها.

#### مستخدمو الـ Toolkit الرسمي

إذا كنت تستخدم [overleaf/toolkit](https://github.com/overleaf/toolkit)، فللحصول على صورة Pro شغّل الأمر التالي لسحبها:

```bash title="Pull Docker Images"
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

بعد ذلك، أضف ملفًا باسم `docker-compose.override.yml` بالمحتوى التالي إلى المجلد `overleaf-toolkit/config`:

```yml title="docker-compose.override.yml"
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

في المرة التالية التي تشغّل فيها `bin/up`، سيقوم الـ Toolkit تلقائيًا بتنزيل صورة Ayakaleaf Pro واستخدامها.
