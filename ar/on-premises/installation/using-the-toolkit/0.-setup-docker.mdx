يعمل Overleaf على Docker. يجب عليك تثبيت:

* Docker Engine (Docker CE)
* إضافة Docker Compose (`docker compose`، الإصدار v2)

تستهدف هذه الخطوات إصدارًا حديثًا من Ubuntu LTS (20.04/22.04/24.04).

<Warning>

تجنّب تثبيت `docker.io` من مستودع apt الافتراضي في Ubuntu.\
استخدم مستودع Docker الرسمي حتى تحصل على إصدار حديث من Docker وعلى إضافة `docker compose`.

</Warning>

الوثائق الرسمية مأخوذة من: [https://docs.docker.com/engine/install/ubuntu/](https://docs.docker.com/engine/install/ubuntu/).

<Steps>
<Step title="1) إزالة الحزم القديمة أو المتعارضة (إن وُجدت)">
إذا كان Docker مثبّتًا سابقًا من مصدر آخر، فأزله أولًا:

```bash wrap
sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-compose-v2 docker-doc podman-docker containerd runc | cut -f1)
```

هذا الأمر آمن حتى لو لم تكن بعض الحزم مثبّتة.
</Step>

<Step title="2) إضافة مستودع apt الرسمي لـ Docker">
ثبّت المتطلبات المسبقة:

```bash
sudo apt update
sudo apt install -y ca-certificates curl
```

أضف مفتاح GPG الخاص بـ Docker:

```bash wrap
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```

أضف المستودع:

```bash wrap
# Add the repository to Apt sources:
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Signed-By: /etc/apt/keyrings/docker.asc
EOF

sudo apt update
```
</Step>

<Step title="3) تثبيت Docker Engine وإضافة Compose">
ثبّت Docker وإضافة Compose:

```bash wrap
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

شغّل Docker تلقائيًا عند الإقلاع:

```bash
sudo systemctl enable --now docker
```
</Step>

<Step title="4) التحقق من التثبيت">
يجب أن تعمل هذه الأوامر دون أخطاء:

```bash
docker --version
docker compose version
sudo docker run --rm hello-world
docker ps
```
</Step>

<Step title="5) (اختياري) تشغيل Docker دون sudo">
أضف المستخدم الخاص بك إلى المجموعة `docker`:

```bash
sudo usermod -aG docker $USER
```

ثم **سجّل الخروج وأعد تسجيل الدخول**، أو شغّل:

```bash
newgrp docker
```

يُفترض الآن أن يعمل هذا الأمر دون `sudo`:

```bash
docker ps
```

<Danger>

تمنح المجموعة `docker` صلاحيات مكافئة لصلاحيات الجذر (root) على المضيف.\
وهذا أمر متوقع في عمليات تثبيت Overleaf المعتادة، ويكتسب أهمية خاصة إذا فعّلت الترجمة المعزولة (Sandboxed Compiles).

</Danger>
</Step>
</Steps>

### الخطوة التالية

بعد أن يعمل Docker، تابع خطوات تثبيت Toolkit في [استخدام Toolkit](/ar/on-premises/installation/using-the-toolkit).
