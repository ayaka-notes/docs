### تنزيل Toolkit

يتوافق Toolkit مع كلٍّ من Server CE و Ayakaleaf Pro، وهو طريقة التثبيت الموصى بها. يتيح لك استخدام Toolkit البدء بسهولة مع Server CE والترقية بسلاسة إلى Ayakaleaf Pro عند الحاجة.

<Info>

تم تعديل [ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) لاستخدام صورة overleaf-pro من ghcr مباشرةً، مع توفير TeX Live من قِبل ayaka-notes. وبدلًا من ذلك، يمكنك تنزيل overleaf-toolkit الرسمي.

</Info>

<Steps>
<Step title="استنساخ مستودع Overleaf Toolkit">
لتثبيت Toolkit، ستحتاج إلى الانتقال إلى مسار التثبيت المقصود ثم استنساخ مستودع GitHub الخاص بـ Overleaf Toolkit (@Ayaka-notes) باستخدام هذا الأمر:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
# official toolkit (Not Recommended)
# git clone https://github.com/overleaf/toolkit.git ./overleaf-toolkit
```

<Info>

لتجنب أي مشكلات محتملة في الأذونات، نوصي بتثبيت Toolkit في المجلد `$HOME` الخاص بالمستخدم.

</Info>
</Step>

<Step title="الانتقال إلى مجلد Toolkit">
انتظر حتى تكتمل عملية الاستنساخ، ثم انتقل إلى المجلد `overleaf-toolkit` الذي تم إنشاؤه حديثًا:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
