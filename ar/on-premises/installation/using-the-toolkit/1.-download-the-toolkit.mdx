### تنزيل Toolkit

تثبّت Ayakaleaf Pro باستخدام **Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit))، وهو مجموعة من السكربتات التي تشغّل Overleaf في Docker نيابةً عنك.

افتراضيًا، يشغّل Toolkit إصدار Overleaf Community Edition (CE) الرسمي المجاني. وتوضّح صفحة [4. الحصول على صور Ayakaleaf Pro](/ar/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images) كيفية التبديل إلى Ayakaleaf Pro بإعداد واحد.

<Accordion title="هل تشغّل بالفعل Overleaf Toolkit الرسمي (overleaf/toolkit)؟">

لا تحتاج إلى إعادة التثبيت. احتفظ بتثبيتك واتبع الجزء الأخير من [4. الحصول على صور Ayakaleaf Pro](/ar/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images).

</Accordion>

<Steps>
<Step title="استنساخ مستودع Ayakaleaf Toolkit">
لتثبيت Toolkit، ستحتاج إلى الانتقال إلى مسار التثبيت المقصود ثم استنساخ مستودع Ayakaleaf Toolkit باستخدام هذا الأمر:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
```

<Info>

لتجنب أي مشكلات محتملة في الأذونات، نوصي بتثبيت Toolkit في المجلد `$HOME` الخاص بالمستخدم.

</Info>
</Step>

<Step title="الانتقال إلى مجلد Toolkit">
انتظر حتى تكتمل عملية الاستنساخ، ثم انتقل إلى المجلد `overleaf-toolkit` الذي تم إنشاؤه حديثًا:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
