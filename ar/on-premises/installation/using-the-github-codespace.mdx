أسهل طريقة لتجربة Ayakaleaf Pro هي استخدام GitHub Codespace، حيث تكون جميع متغيرات البيئة مُكوَّنة مسبقًا لضمان إمكانية استخدامه مباشرةً دون أي إعداد.

<Warning>

عند تشغيل حاويات Docker باستخدام GitHub Codespaces، لن يتوقف Codespace تلقائيًا وسيستمر **احتساب التكلفة** عليه. لمعرفة قواعد الفوترة في GitHub Codespaces، يُرجى الرجوع إلى [قواعد فوترة github codespaces](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces).

لإدارة GitHub Codespaces الخاصة بك، يُرجى زيارة [https://github.com/codespaces](https://github.com/codespaces). وعندما لا تعود بحاجة إليه، يُرجى حذف Codespace في الوقت المناسب.

</Warning>

لقد قمنا **مسبقًا بتكوين** الميزات التالية:

* [x] ترجمة LaTeX في بيئة معزولة باستخدام TeXLive **Basic** (2024-2026)
* [x] الاستيراد/التصدير عبر Pandoc (من ميزات منصة SaaS)
* [x] مشغّل سكربتات Python (من ميزات منصة SaaS)
* [x] دعم Git-Bridge (من ميزات Server Pro)
* [x] البحث المتقدم في المراجع (من ميزات منصة SaaS)
* [x] لوحة الإدارة (إدارة شاملة للمستخدمين والمشاريع)
* [x] تتبع التغييرات (مع لوحة المراجعة والتعليقات)
* [x] سجل المشروع الكامل (مع الاستعادة والتنزيل)
* [x] لوحة الرموز (من ميزات Server Pro/منصة SaaS)

<Warning>

توفر GitHub Codespaces القياسية مساحة تخزين قدرها 32 جيجابايت. وهذا غير كافٍ لتثبيت `texlive-full`. لتجربة الصورة الكاملة، قدّم تذكرة دعم إلى GitHub للحصول على Codespace بمشغّلات كبيرة (8 أنوية أو أكثر).

</Warning>

ميزات المزامنة مع GitHub وLDAP وOAuth وSSO والتكامل مع Zotero وغيرها _**غير مُكوَّنة**_ في بيئة التجربة هذه. يمكنك الرجوع إلى [إعدادات toolkit](/ar/on-premises/configuration/overleaf-toolkit/toolkit-settings) لمزيد من التفاصيل حول كيفية تكوين هذه الميزات في عملية النشر الخاصة بك.

<Steps>
<Step title="أنشئ GitHub Codespace الخاص بك">

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/ayakaleaf-pro-playground)


#### استخدام صورة TeXLive الكاملة

إذا كان لديك وصول إلى GitHub Codespaces بـ 8 أنوية/64 جيجابايت، فيمكنك استخدام صورة TeXLive Full في بيئة التجربة هذه. يمكنك تغيير متغيرات البيئة التالية في ملف `toolkit/config/variables.env` لاستخدام صورة TeXLive Full بدلًا من صورة TeXLive Basic.

```dotenv wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1, ghcr.io/ayaka-notes/texlive-full:2024.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025, Texlive 2024
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```

بعد تغيير متغيرات البيئة، تحتاج إلى إعادة تشغيل toolkit لتطبيق التغييرات. يمكنك تشغيل الأمر التالي لإعادة تشغيل toolkit.

```bash
cd toolkit && bin/up -d
```
