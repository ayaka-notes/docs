---
title: 4. الحصول على صور Ayakaleaf Pro
icon: split
---

Ayakaleaf Pro هو صورة Docker مجانية على [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). لا تحتاج إلى حساب أو تسجيل دخول لسحبها. تُبنى الصور لمعماريتي amd64 وarm64، ويختار Docker الصورة المطابقة لخادمك.

افتح `config/overleaf.rc` واضبط:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

في المرة التالية التي تشغّل فيها `bin/up`، ينزّل Toolkit صورة Ayakaleaf Pro ويستخدمها بدلًا من إصدار Overleaf Community Edition الرسمي. وتظل إعداداتك في `config/` تعمل كما هي.

<Accordion title="هل تشغّل بالفعل Overleaf Toolkit الرسمي (overleaf/toolkit)؟">

لا تحتاج إلى إعادة التثبيت. اسحب صورة Ayakaleaf Pro:

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

بعد ذلك، أضف ملفًا باسم `docker-compose.override.yml` بالمحتوى التالي إلى المجلد `overleaf-toolkit/config`:

```yml
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

في المرة التالية التي تشغّل فيها `bin/up`، يستخدم Toolkit صورة Ayakaleaf Pro.

</Accordion>
