يُعدّ Docker Compose على خادم واحد الطريقة الموصى بها لنشر Ayakaleaf Pro. تشغّله عبر [Toolkit](https://github.com/ayaka-notes/toolkit): وهو مجموعة من السكربتات التي تغلّف `docker compose` وتقرأ إعداداتك من مجلد `config/` واحد، لذا يحل `bin/up` محل `docker compose up`.
