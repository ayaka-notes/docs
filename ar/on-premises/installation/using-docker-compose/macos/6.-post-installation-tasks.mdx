### أنشئ حساب المسؤول وأول مشروع {#create-the-administrator-and-a-first-project}

افتح [http://localhost:8080/launchpad](http://localhost:8080/launchpad)، وأنشئ أول حساب مسؤول وسجّل الدخول. ثم اتبع [6. مهام ما بعد التثبيت](/ar/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks) ضمن دليل Linux، مع استخدام المنفذ `8080` في عناوين URL الواردة في أمثلته.

### تحقّق من الترجمة {#verify-compilation}

إن فتح صفحة تسجيل الدخول لا يثبت أن حاويات المترجم المنفصلة وعمليات تركيب البيانات الخاصة بها تعمل. أنشئ مشروعًا فارغًا وترجم ملف `main.tex` هذا:

```latex
\documentclass{article}
\begin{document}
Ayakaleaf Pro on macOS.
\end{document}
```

يجب أن تعرض معاينة PDF النص. إذا لزم الأمر، اختر TeX Live 2026 في إعدادات المشروع.

لمشروع يحتوي على نص صيني، اختر **XeLaTeX** مترجمًا واختبر:

```latex
\documentclass{ctexart}
\begin{document}
你好，Ayakaleaf Pro。
\end{document}
```

### تحقّق من استمرارية البيانات {#verify-persistence}

```bash
bin/stop
bin/start
```

أعد فتح المشروع وترجمه مجددًا. يجب أن يبقى حسابك والمصدر وملفات المشروع موجودة. مع المسارات الافتراضية، توجد البيانات الحية في مجلد `data/` الخاص بـ Toolkit على جهاز Mac.

### إبقاء النسخة متاحة {#keep-the-instance-available}

عندما يدخل جهاز Mac في وضع السكون، يعلّق macOS الآلة الافتراضية لـ Docker Desktop مع كل الحاويات الموجودة فيها: لا يستطيع أحد فتح النسخة، وتتوقف أي عملية ترجمة جارية حتى يستيقظ الجهاز. سكون النظام وحده هو المهم. ويمكن أن تنطفئ الشاشة.

إذا كان أشخاص آخرون يستخدمون النسخة، أو تركت مهام طويلة قيد التشغيل، فأبقِ جهاز Mac موصولًا بالكهرباء وامنع السكون التلقائي، راجع [ضبط إعدادات السكون والتنبيه على جهاز Mac](https://support.apple.com/guide/mac-help/set-sleep-and-wake-settings-mchle41a6ccd/mac):

| جهاز Mac | الإعداد |
| --- | --- |
| Mac مكتبي (Mac mini وiMac وMac Studio وMac Pro) | **System Settings → Energy**: فعّل **Prevent automatic sleeping when the display is off** |
| MacBook | **System Settings → Battery → Options**: فعّل **Prevent automatic sleeping on power adapter when the display is off**. لا ينطبق هذا إلا أثناء توصيل محوّل الطاقة، وما زال إغلاق الغطاء يضع MacBook في وضع السكون |

لإبقاء جهاز Mac مستيقظًا لفترة فقط، شغّل `caffeinate -i` في نافذة Terminal بدلًا من ذلك. فهو يمنع السكون عند الخمول حتى تضغط `Ctrl+C` أو تغلق النافذة.

Docker Desktop تطبيق يعمل في جلسة المستخدم. لاستعادة النسخة بعد إعادة التشغيل، فعّل **Start Docker Desktop when you sign in to your computer** في **Settings → General** الخاصة بـ Docker Desktop. تستخدم حاويات Toolkit السياسة `restart: always`، لذا يشغّلها Docker مجددًا بمجرد تشغيل Docker Desktop، دون `bin/up`. وتبقى النسخة متوقفة حتى يسجّل أحدهم الدخول إلى جهاز Mac بعد إعادة التشغيل.

<Info>

يستهلك جهاز Mac الذي يبقى مستيقظًا طاقة أكبر. لخدمة يجب أن تكون متاحة دائمًا، نوصي بخادم Linux، راجع [Linux](/ar/on-premises/installation/using-docker-compose/linux).

</Info>

### الاستخدام اليومي {#daily-use}

افتح Docker Desktop قبل إدارة النسخة. في طرفية جديدة:

```bash
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
cd "$HOME/ayakaleaf-toolkit"
```

| المهمة | الأمر |
| --- | --- |
| تشغيل الحاويات الموجودة | `bin/start` |
| إيقاف الحاويات مع الاحتفاظ بالبيانات | `bin/stop` |
| تطبيق تغييرات الإعدادات | `bin/up -d` |
| التحقق من الحالة | `bin/docker-compose ps` |
| قراءة سجلات بدء التشغيل | `bin/docker-compose logs --tail=100 sharelatex` |
| قراءة سجلات المترجم | `bin/logs -f clsi` |

لا يطبّق `bin/start` التغييرات في `config/`: شغّل `bin/up -d` بعد تعديل الإعدادات. احتفظ بـ `config/` و`data/`، واتبع [البيانات والنسخ الاحتياطية](/ar/on-premises/maintenance/data-and-backups) قبل الترقية أو قبل نقل التثبيت. إن نسخ ملفات قاعدة البيانات أثناء كتابة MongoDB إليها لا يُعدّ نسخة احتياطية متسقة.

أبقِ النسخة على `127.0.0.1` للاستخدام المحلي. لخدمة أجهزة كمبيوتر أخرى، اضبط عنوان الاستماع وعنوان URL للموقع وHTTPS عن قصد، راجع [5. تخصيص نسختك](/ar/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance) ضمن دليل Linux.

إذا لم يعمل شيء ما، فراجع [استكشاف الأخطاء وإصلاحها](/ar/on-premises/installation/using-docker-compose/macos/troubleshooting).
