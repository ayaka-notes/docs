---
title: 3. تهيئة الإعدادات
description: أنشئ ملفات إعدادات Toolkit على جهاز Mac باستخدام bin/init.
icon: circle-play
---

من مجلد Toolkit، وفي طرفية يوجد فيها GNU sed ضمن `PATH`، شغّل:

```bash
bin/init
```

ينشئ `bin/init` ثلاثة ملفات:

| الملف | الغرض |
| --- | --- |
| `config/overleaf.rc` | إعدادات الحاويات، والمنفذ المنشور، ومواقع البيانات |
| `config/variables.env` | إعدادات التطبيق والأسرار |
| `config/version` | إصدار صورة التطبيق |

كما يولّد `OVERLEAF_INVITE_TOKEN_SECRET` في `config/variables.env`. احتفظ به، ولا تنشر هذا الملف ولا تودعه في نظام التحكم في الإصدارات.

أبقِ على الإصدار الذي يختاره Toolkit لتثبيت جديد. لتغيير إصدار نسخة قائمة لاحقًا، اتبع [ترقية النشر](/ar/on-premises/maintenance/upgrading-your-deployment).

<Warning>

إذا توقف `bin/init` مع `sed: ... invalid command code`، فهذا يعني أنه عمل باستخدام BSD sed الخاص بـ macOS. قد يترك تشغيل فاشل كهذا الملفات الثلاثة في `config/` مع قيمة فارغة لـ `OVERLEAF_INVITE_TOKEN_SECRET`، ثم يُبلغ تشغيل `bin/init` مجددًا عن `Config files already exist`. راجع [استكشاف الأخطاء وإصلاحها](/ar/on-premises/installation/using-docker-compose/macos/troubleshooting#initialization-fails-with-invalid-command-code).

</Warning>
