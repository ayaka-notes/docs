في هذا القسم نشغّل Ayakaleaf Pro محليًا على جهاز Mac باستخدام Docker Desktop و[Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). يستخدم الدليل `http://localhost:8080`، ويحتفظ بالبيانات في مجلدك الرئيسي، ويترجم باستخدام TeX Live 2026 داخل حاويات معزولة.

يشغّل Docker Desktop التطبيق وMongoDB وRedis ومترجم TeX Live داخل آلة Linux افتراضية. لا تثبّت MongoDB أو Redis أو MacTeX على macOS نفسه.

استخدم هذا الإعداد للاستخدام الشخصي والاختبار المحلي. لخدمة مشتركة تعمل باستمرار، نوصي بـ[دليل Linux](/ar/on-premises/installation/using-docker-compose/linux)، مع HTTPS والنسخ الاحتياطية والتحكم في الوصول. تكون النسخة غير متاحة أثناء سكون جهاز Mac أو توقف Docker Desktop، راجع [إبقاء النسخة متاحة](/ar/on-premises/installation/using-docker-compose/macos/6.-post-installation-tasks#keep-the-instance-available).

## قبل أن تبدأ {#before-you-start}

تحتاج إلى:

* إصدار macOS يدعمه [Docker Desktop for Mac](https://docs.docker.com/desktop/setup/install/mac-install/).
* Git و[Homebrew](https://brew.sh/) وGNU sed. يستخدم Toolkit خيارات GNU sed التي لا يقبلها BSD sed المدمج في macOS.
* موارد كافية لكل من macOS وDocker. لنسخة محلية صغيرة، ابدأ بتخصيص 4 أنوية معالج و8 GB من الذاكرة لـ Docker Desktop. هذه نقطة بداية مقترحة، وليست حدًا أدنى مُقاسًا.
* ما لا يقل عن 40 GB من المساحة الحرة لصورة TeX Live كاملة، بالإضافة إلى مساحة لمشاريعك. تحقّق من المساحة الحرة على جهاز Mac ومن حد استخدام القرص في Docker Desktop. ابدأ بإصدار واحد من TeX Live: فكل إصدار إضافي يحتاج إلى مساحة مماثلة تقريبًا.

صور التطبيق وTeX Live منشورة لـ `arm64` و`amd64`. على Apple silicon، دع Docker يختار صورة ARM الأصلية ولا تفرض `platform: linux/amd64`.
