<Steps>
<Step title="تحقّق من Git وHomebrew">
```bash
git --version
brew --version
```

إذا طلب منك macOS تثبيت Command Line Tools عند تشغيل Git، فثبّتها أولًا. إذا لم يكن Homebrew مثبّتًا، فثبّته باتباع [التعليمات الرسمية](https://brew.sh/).
</Step>

<Step title="ضع GNU sed في PATH">
تستخدم سكربتات Toolkit خيارات GNU sed التي يرفضها BSD sed المدمج في macOS. ثبّت [GNU sed](https://formulae.brew.sh/formula/gnu-sed) وضعه أولًا في `PATH` في هذه الطرفية:

```bash
brew install gnu-sed
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
sed --version
```

يجب أن يطبع الأمر الأخير **GNU sed**.

لا يكفي اسم مستعار مثل `alias sed=gsed`: إذ يشغّل Toolkit سكربتات Bash، وهي لا ترى الأسماء المستعارة الخاصة بصدفتك التفاعلية. ولا تحتاج إلى استبدال `/usr/bin/sed`.

شغّل سطر `export PATH=...` مجددًا في كل طرفية جديدة تستخدمها مع Toolkit، أو أضفه إلى ملف بدء تشغيل الصدفة بعد التهيئة الخاصة بـ Homebrew.
</Step>

<Step title="استنسخ مستودع Ayakaleaf Toolkit">
اختر مجلدًا دائمًا. تجنّب `/tmp` ومحركات الأقراص القابلة للإزالة والمجلدات المتزامنة مع السحابة مثل iCloud Drive لقاعدة البيانات الحية وبيانات المشاريع. يستخدم هذا الدليل `~/ayakaleaf-toolkit`:

```bash
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

<Warning>

إذا كان المجلد يحتوي بالفعل على تثبيت، فاستخدمه كما هو، أو اختر مجلدًا آخر لنسخة جديدة. لا تهيّئ إعدادات جديدة فوق نشر قائم.

</Warning>
</Step>
</Steps>
