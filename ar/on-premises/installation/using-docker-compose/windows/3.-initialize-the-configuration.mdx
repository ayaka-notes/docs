---
title: 3. تهيئة الإعدادات
description: أنشئ ملفات إعدادات Toolkit في Ubuntu على WSL 2 باستخدام bin/init.
icon: circle-play
---

من مجلد Toolkit في **Ubuntu**، شغّل:

```bash
bin/init
```

ينشئ `bin/init` ثلاثة ملفات:

| الملف | الغرض |
| --- | --- |
| `config/overleaf.rc` | إعدادات الحاويات، والمنفذ المنشور، ومواقع البيانات |
| `config/variables.env` | إعدادات التطبيق والأسرار |
| `config/version` | إصدار صورة التطبيق |

كما يولّد `OVERLEAF_INVITE_TOKEN_SECRET` في `config/variables.env`. احتفظ به، ولا تنشر هذا الملف ولا تودعه في نظام التحكم في الإصدارات.

أبقِ على الإصدار الذي يختاره Toolkit لتثبيت جديد. لتغيير إصدار نسخة قائمة لاحقًا، اتبع [ترقية النشر](/ar/on-premises/maintenance/upgrading-your-deployment).

<Info>

لا يستبدل `bin/init` الإعدادات الموجودة. إذا أبلغ بأن الملفات موجودة بالفعل، فافحصها قبل المتابعة. احتفظ بـ `config/` و`data/` عند إعادة تشغيل النسخة أو ترقيتها.

</Info>
