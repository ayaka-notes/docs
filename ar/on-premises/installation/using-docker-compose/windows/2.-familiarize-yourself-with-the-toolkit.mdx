الـ Toolkit هو نفسه كما على Linux. بنيته ومجلد `config/` وأوامر `bin/` موصوفة في [2. تعرّف على الـ Toolkit](/ar/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) ضمن دليل Linux.

على Windows، ضع في اعتبارك هذه الاختلافات:

* شغّل أوامر `bin/` في **Ubuntu Bash**، من `~/ayakaleaf-toolkit`. أما الأوامر المميزة بـ **PowerShell** فتُشغَّل في Windows.
* شغّل Docker Desktop وفعّل WSL Integration لـ Ubuntu قبل استخدام `bin/up` أو `bin/start` أو `bin/docker-compose`.
* احتفظ بملفات الإعدادات بنهايات أسطر Linux ‏(LF). حرّرها باستخدام `nano` في Ubuntu أو بمحرر متصل بـ WSL. قد تسبب نهايات الأسطر CRLF أخطاء في Bash.
* يشغّل `bin/doctor` عمليات تحقق خاصة بـ Linux داخل Ubuntu. التحذير المتعلق بعدم تسجيل الدخول إلى `quay.io` لا ينطبق على الصورة العامة `ghcr.io/ayaka-notes/overleaf-pro`. أما التحذيرات الأخرى فما زالت تحتاج إلى اهتمام.

```bash
bin/doctor
```
