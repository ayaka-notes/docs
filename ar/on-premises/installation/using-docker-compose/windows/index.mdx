في هذا القسم نشغّل Ayakaleaf Pro محليًا على Windows باستخدام WSL 2 وUbuntu وDocker Desktop و[Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). يستخدم الدليل `http://localhost:8080`، ويحتفظ بالبيانات في المجلد الرئيسي لـ Ubuntu، ويفعّل Sandboxed Compiles.

يعمل التطبيق وMongoDB وRedis وTeX Live في حاويات Linux يديرها Docker Desktop. شغّل أوامر Toolkit في Ubuntu؛ وافتح التطبيق في متصفح Windows. توضّح [الخطوة 0](/ar/on-premises/installation/using-docker-compose/windows/0.-setup-wsl-and-docker-desktop) كيف تتكامل أجزاء Windows وLinux معًا، وتبدأ من تثبيت WSL.

يمكنك استخدام Windows لنسخة محلية أو إبقاؤها قيد التشغيل باستمرار باستخدام إعدادات التوافر في الخطوة 6. للخوادم المشتركة وخوادم الإنتاج، نوصي بـ[دليل Linux](/ar/on-premises/installation/using-docker-compose/linux)، مع HTTPS والنسخ الاحتياطية والتحكم في الوصول. يؤدي سكون Windows وإيقاف Docker Desktop وإيقاف WSL إلى مقاطعة هذه النسخة المحلية؛ راجع [إبقاء النسخة متاحة](/ar/on-premises/installation/using-docker-compose/windows/6.-post-installation-tasks#keep-the-instance-available).

## قبل أن تبدأ {#before-you-start}

تحتاج إلى:

* إصدار Windows ومعالج يدعمهما [Docker Desktop for Windows](https://docs.docker.com/desktop/setup/install/windows-install/)، مع تفعيل المحاكاة الافتراضية للعتاد (hardware virtualization). يستخدم هذا الدليل Windows 11 على x86-64.
* صلاحية تفعيل WSL وتثبيت البرامج. يجب أن يكون إصدار WSL هو 2.1.5 أو أحدث، مع تشغيل Ubuntu في وضع WSL 2.
* ذاكرة كافية لـ Windows والحاويات. لنسخة محلية صغيرة، تُعدّ 4 أنوية معالج و8 GB متاحة لـ Docker نقطة بداية مقترحة، وليست حدًا أدنى مُقاسًا.
* مساحة تخزين حرة على قرص Windows الذي يحتوي على بيانات WSL وDocker. خصّص ما لا يقل عن 40 GB لإعداد TeX Live كامل بالإضافة إلى بيانات المشاريع؛ أما الصورة الأساسية في [الخطوة 5](/ar/on-premises/installation/using-docker-compose/windows/5.-personalizing-your-instance) فهي أصغر ومناسبة لاختبار النشر الأولي. تحتاج إصدارات الصور الإضافية إلى مساحة إضافية.
* وصول شبكي إلى GitHub وGitHub Container Registry (`ghcr.io`) وDocker Hub لاستنساخ Toolkit وتنزيل الصور.

تُشغَّل كتل **PowerShell** في Windows. أما كتل **Bash** وأوامر `bin/` فتُشغَّل في Ubuntu ما لم يُذكر خلاف ذلك. لا تشغّل سكربتات Toolkit في PowerShell أو في Windows Git Bash.
