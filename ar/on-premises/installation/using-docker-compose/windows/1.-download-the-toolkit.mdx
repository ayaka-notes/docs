<Steps>
<Step title="ثبّت أدوات سطر الأوامر">
شغّل في **Ubuntu**، مستخدمًا كلمة مرور Linux التي أنشأتها في الخطوة 0:

```bash
sudo apt update
sudo apt install -y git ca-certificates curl perl gawk openssl
```

يوفّر Ubuntu بالفعل Bash وGNU sed وcoreutils. وعلى عكس macOS، لا يحتاج إلى Homebrew أو إلى تثبيت منفصل لـ GNU sed.
</Step>

<Step title="استنسخ مستودع Ayakaleaf Toolkit">
احتفظ بـ Toolkit وبياناته في نظام ملفات Linux الخاص بـ Ubuntu، ضمن مجلدك الرئيسي:

```bash
cd "$HOME"
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

تجنّب `/mnt/c` و`/mnt/d` وOneDrive والمجلدات المؤقتة لقاعدة البيانات الحية وبيانات المشاريع. توفّر مسارات نظام ملفات Linux الأذونات وسلوك نظام الملفات الذي تتوقعه الحاويات، وتتجنب الحمل الإضافي الناتج عن العمل عبر أنظمة ملفات مختلفة؛ راجع [إرشادات Microsoft حول أنظمة الملفات](https://learn.microsoft.com/en-us/windows/wsl/filesystems).

<Warning>

إذا كان المجلد يحتوي بالفعل على تثبيت، فاستخدمه كما هو، أو اختر مجلدًا آخر لنسخة جديدة. لا تستبدل إعدادات أو بيانات نشر قائم.

</Warning>
</Step>
</Steps>
