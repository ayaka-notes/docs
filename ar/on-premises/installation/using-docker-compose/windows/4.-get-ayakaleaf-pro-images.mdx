---
title: 4. الحصول على صور Ayakaleaf Pro
description: بدّل Toolkit في Ubuntu على WSL 2 إلى صورة Ayakaleaf Pro العامة.
icon: split
---

Ayakaleaf Pro صورة Docker مجانية على [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). لا تحتاج إلى حساب أو تسجيل دخول أو ترخيص Overleaf تجاري لسحبها.

افتح `config/overleaf.rc` واضبط:

```bash title="config/overleaf.rc"
SERVER_PRO=true
```

في المرة التالية التي تشغّل فيها `bin/up`، يسحب Toolkit الصورة `ghcr.io/ayaka-notes/overleaf-pro` بالإصدار المحدد في `config/version`، بدلًا من Overleaf Community Edition الرسمي.

الصورة مبنية لـ `arm64` و`amd64`، ويختار Docker الصورة المطابقة لبنية محرك Docker.
