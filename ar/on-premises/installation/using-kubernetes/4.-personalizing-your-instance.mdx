---
title: 4. تخصيص المثيل الخاص بك
description: ضع إعداداتك في الـ ConfigMap الذي يحلّ محل config/variables.env.

---

يحلّ الـ ConfigMap المسمّى `overleaf-env` محل الملف `config/variables.env` الخاص بـ Toolkit: إذ يوضع هنا كل متغيّر بيئة من [توثيق Toolkit](/ar/on-premises/configuration/overleaf-toolkit/environment-variables)، بينما توضع الأسرار في الـ Secret من [الخطوة 2](/ar/on-premises/installation/using-kubernetes/2.-create-the-namespace-and-secrets).

```yaml title="30-config.yaml" wrap
apiVersion: v1
kind: ConfigMap
metadata:
  name: overleaf-env
  namespace: overleaf
data:
  OVERLEAF_APP_NAME: Ayakaleaf Pro
  OVERLEAF_SITE_URL: http://192.0.2.10:30080      # the address users open; https://... behind TLS
  OVERLEAF_ADMIN_EMAIL: admin@example.com
  # Emails: add the sender and the SMTP server together, see Email delivery
  # All members, so that the driver finds the primary even when mongo-0 is down
  OVERLEAF_MONGO_URL: mongodb://mongo-0.mongo:27017,mongo-1.mongo:27017,mongo-2.mongo:27017/sharelatex?replicaSet=overleaf
  OVERLEAF_REDIS_HOST: redis
  REDIS_HOST: redis
  ENABLED_LINKED_FILE_TYPES: project_file,project_output_file,url
  ENABLE_CONVERSIONS: "true"
  EMAIL_CONFIRMATION_DISABLED: "true"
  # Requests arrive from kube-proxy or your ingress controller, inside the pod network
  OVERLEAF_TRUSTED_PROXY_IPS: loopback,10.244.0.0/16
  # Sandboxed compiles. The HOST_DIR paths are paths ON THE NODE: the hostPath volumes that
  # the Deployment mounts at /var/lib/overleaf/data/{compiles,output,cache}.
  SANDBOXED_COMPILES: "true"
  SANDBOXED_COMPILES_SIBLING_CONTAINERS: "true"
  DOCKER_RUNNER: "true"
  SANDBOXED_COMPILES_HOST_DIR_COMPILES: /srv/overleaf/compiles
  SANDBOXED_COMPILES_HOST_DIR_OUTPUT: /srv/overleaf/output
  SANDBOXED_COMPILES_HOST_DIR_CACHE: /srv/overleaf/cache
  # Each image must be pulled into Docker on every node that can run Ayakaleaf Pro (step 0)
  ALL_TEX_LIVE_DOCKER_IMAGES: ghcr.io/ayaka-notes/texlive-full:2026.1
  ALL_TEX_LIVE_DOCKER_IMAGE_NAMES: TeX Live 2026
  TEX_LIVE_DOCKER_IMAGE: ghcr.io/ayaka-notes/texlive-full:2026.1
```

```bash
kubectl apply -f 30-config.yaml
```

| المتغيّر                                | اضبطه على                                                                                                                                                       |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_SITE_URL`                     | عنوان URL الذي يكتبه المستخدمون في المتصفح. مع منفذ NodePort من [الخطوة 5](/ar/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro)، عنوان IP لأي عقدة والمنفذ `30080`؛ أما خلف ingress أو موازن أحمال، فعنوان URL الخاص به. |
| `OVERLEAF_MONGO_URL`                    | مجموعة النسخ المتماثلة (replica set) الخاصة بك. استخدم `?replicaSet=` مع الاسم المحدّد في `rs.initiate`.                                                                                         |
| `OVERLEAF_REDIS_HOST` و`REDIS_HOST`  | كلاهما، على الـ Service الخاصة بـ Redis.                                                                                                                                    |
| `OVERLEAF_TRUSTED_PROXY_IPS`            | `loopback` بالإضافة إلى الشبكات التي تتصل منها الوكلاء لديك. ‏`10.244.0.0/16` هي شبكة الـ pods في flannel؛ استخدم نطاق CIDR الخاص بالـ pods في العنقود لديك.                               |
| `SANDBOXED_COMPILES_HOST_DIR_*`         | مسارات وحدات تخزين الترجمة على العقدة. يجب أن تطابق وحدات التخزين `hostPath` في [الخطوة 5](/ar/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro).                                       |

خلف HTTPS، اضبط أيضًا `OVERLEAF_SECURE_COOKIE: "true"`، راجع [وكيل TLS](/ar/on-premises/configuration/overleaf-toolkit/tls-proxy).

<Info>

لا يصل الـ ConfigMap المعدَّل إلى الـ pods قيد التشغيل إلا بعد إعادة التشغيل: `kubectl -n overleaf rollout restart deployment/overleaf`.

</Info>
