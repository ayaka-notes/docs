يُعدّ [Toolkit](/ar/on-premises/installation/using-docker-compose) الطريقة الموصى بها لتشغيل Ayakaleaf Pro على خادم واحد. أما إذا كنت تشغّل بالفعل عنقود Kubernetes، فإن هذا القسم ينشر الحاوية نفسها عليه باستخدام ملفات manifest عادية عبر `kubectl`: دون أي صورة إضافية، ودون أي Helm chart.

بنهاية هذا القسم سيكون لديك مثيل واحد من Ayakaleaf Pro مع الترجمة المعزولة، ومجموعة نسخ متماثلة (replica set) من MongoDB، وRedis، وكلها في مساحة الأسماء (namespace) ‏`overleaf`. لتشغيل عدة مثيلات خلف موازن أحمال، تابع بعد ذلك مع [التوسّع الأفقي](/ar/on-premises/configuration/kubernetes/horizontal-scaling).

<Info>

دعم Kubernetes تجريبي. نحن لا ننشر Helm chart ولا صورًا خاصة بـ Kubernetes. ملفات manifest الواردة في هذه الصفحات هي التي اختبرناها على Kubernetes 1.37 ‏(kubeadm، وcontainerd 2.4، وflannel) مع ثلاث عقد، لكلٍّ منها 2 vCPU و4 GB من الذاكرة. كيّف التخزين والشبكات والـ ingress وفقًا للعنقود لديك.

</Info>

### كيف تتكامل الأجزاء {#how-the-pieces-fit}

| Toolkit (خادم واحد)                         | Kubernetes                                                               |
| -------------------------------------------- | ------------------------------------------------------------------------ |
| `config/variables.env`                       | ConfigMap ‏`overleaf-env` وSecret ‏`overleaf-secrets`                   |
| الحاوية `sharelatex`                       | Deployment ‏`overleaf` (pod واحد يشغّل كل خدمات Overleaf)            |
| الحاويتان `mongo` و`redis`               | StatefulSets ‏`mongo` (مجموعة نسخ متماثلة) و`redis`، أو خدماتك المُدارة |
| `~/overleaf-toolkit/data/overleaf`           | PersistentVolumeClaim ‏`overleaf-data`                                    |
| Docker على المضيف، المستخدم لعمليات الترجمة        | Docker Engine على كل عقدة تشغّل Ayakaleaf Pro                      |
| `bin/up`، `bin/logs`، `bin/shell`            | `kubectl apply`، `kubectl logs`، `kubectl exec`                          |

### ما تحتاج إليه {#what-you-need}

* عنقود Kubernetes يمكنك تثبيت الحزم عليه: تحتاج كل عقدة قد تشغّل Ayakaleaf Pro إلى **Docker Engine**، لأن عمليات الترجمة تجري داخل حاويات TeX Live يشغّلها Ayakaleaf Pro عبر `/var/run/docker.sock` الخاص بالعقدة. راجع [0. تجهيز العقد](/ar/on-premises/installation/using-kubernetes/0.-prepare-the-nodes).
* StorageClass افتراضي مع وحدات تخزين `ReadWriteOnce`.
* `kubectl` و`openssl` على محطة العمل لديك.
