description: استنسخ Ayakaleaf Toolkit وأنشئ الإعدادات واضبطها لتشغيل Ayakaleaf Pro على Podman.

---

<Steps>
<Step title="استنسخ Toolkit">
استنسخ **Ayakaleaf Toolkit** ‏([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)) إلى مجلدك الرئيسي وانتقل إليه:

```bash title="Clone the Toolkit" wrap
git clone https://github.com/ayaka-notes/toolkit.git ~/overleaf-toolkit
cd ~/overleaf-toolkit
```

شغّل كل الأوامر التالية من هذا المجلد.
</Step>

<Step title="أنشئ الإعدادات">
```bash title="Run initialization"
bin/init
```

ينشئ هذا الملفات `config/overleaf.rc` و`config/variables.env` و`config/version`، كما هو موضح في [3. تهيئة الإعدادات](/ar/on-premises/installation/using-docker-compose/linux/3.-initialize-the-configuration) من دليل Docker. لا يحتاج `bin/init` إلى Podman بعد.
</Step>

<Step title="اضبط config/overleaf.rc">
افتح `config/overleaf.rc` وغيّر هذه الأسطر:

```bash title="config/overleaf.rc"
SERVER_PRO=true
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
```

ثم أضف هذا السطر في نهاية الملف:

```bash title="config/overleaf.rc"
SELINUX_MODE=managed
```

| الإعداد                           | السبب                                                                                                                                                                                                       |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SERVER_PRO=true`                 | يستخدم صورة Ayakaleaf Pro من `ghcr.io`. لا حاجة لتسجيل الدخول.                                                                                                                                               |
| `OVERLEAF_PORT=8080`              | لا يستطيع Podman بدون root الاستماع على المنافذ الأقل من `1024`. يفشل المنفذ الافتراضي `80`.                                                                                                                    |
| `SIBLING_CONTAINERS_ENABLED=true` | يشغّل كل عملية ترجمة في حاوية TeX Live خاصة بها. القيمة `true` افتراضيًا بالفعل؛ إعداد Podman يدعم هذا الوضع فقط.                                                                                                |
| `SELINUX_MODE=managed`            | يشغّل الحاوية `sharelatex` بنوع SELinux ‏`sharelatex_t`، الذي يُسمح له باستخدام مقبس Podman ولا شيء غيره. يثبّت `bin/podman-setup --apply` وحدة السياسة الخاصة به. راجع [إعدادات Toolkit](/ar/on-premises/configuration/overleaf-toolkit/toolkit-settings) للأوضاع الأخرى. |

اترك `DOCKER_SOCKET_PATH` كما هو: يضبطه `bin/podman-setup --apply` على مقبس Podman الخاص بك في الخطوة التالية.

<Warning>

أبقِ `GIT_BRIDGE_ENABLED=false`. في Ayakaleaf Pro 6.3.4 لا يعمل تكامل Git على Podman، راجع [القيود المعروفة](/ar/on-premises/installation/using-podman#known-limitations).

</Warning>
</Step>

<Step title="اختر صور TeX Live">
افتح `config/variables.env`، واحذف `#` من أمام `TEX_LIVE_DOCKER_IMAGE` و`ALL_TEX_LIVE_DOCKER_IMAGES`، واذكر صور TeX Live التي ستستخدمها:

```bash title="config/variables.env" wrap
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
```

يتوقف `bin/up` برسالة `Please configure ALL_TEX_LIVE_DOCKER_IMAGES` إذا كانت القائمة فارغة. الصورة `texlive-full` كبيرة؛ لخادم اختبار تعمل أيضًا الصورة الأصغر بكثير `ghcr.io/ayaka-notes/texlive-basic:2026.1`. راجع [الترجمة المعزولة](/ar/on-premises/configuration/overleaf-toolkit/sandboxed-compiles) للصور المتاحة.

اضبط المتغيرات الأخرى، مثل `OVERLEAF_SITE_URL`، كما هو موضح في [5. تخصيص نسختك](/ar/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance#required-environment-variables). مع عنوان الاستماع الافتراضي، استخدم `http://localhost:8080`.
</Step>
</Steps>
