---
title: 0. تجهيز المضيف
description: تحقق من نظام التشغيل وSELinux وثبّت git قبل إعداد Podman بدون root.
icon: server
---

لا تثبّت Podman يدويًا: تثبّته الخطوة [2. تشغيل podman-setup](/ar/on-premises/installation/using-podman/2.-run-podman-setup) مع الحزم الأخرى التي يحتاجها. هنا تتحقق من المضيف فقط وتثبّت `git`، الذي تحتاجه لتنزيل Toolkit.

<Steps>
<Step title="تحقق من نظام التشغيل وSELinux">
سجّل الدخول بالمستخدم الذي سيشغّل Ayakaleaf Pro، وليس بصفة `root`، ثم تحقق من التوزيعة ووضع SELinux:

```bash title="Check the host"
grep PRETTY_NAME /etc/os-release
getenforce
```

يجب أن ترى RHEL أو Rocky Linux أو AlmaLinux أو CentOS Stream بالإصدار 9 أو أحدث، و`Enforcing`:

```text
PRETTY_NAME="Rocky Linux 9.9 (Blue Onyx)"
Enforcing
```
</Step>

<Step title="تحقق من أنك تستطيع استخدام sudo">
يثبّت `bin/podman-setup --apply` الحزم ويحمّل وحدة SELinux باستخدام `sudo`، ويطلب كلمة مرورك عند الحاجة:

```bash title="Check sudo"
sudo -v
```

إذا فشل ذلك، فاطلب من المسؤول إضافة مستخدمك إلى المجموعة `wheel`.
</Step>

<Step title="ثبّت git">
```bash title="Install git"
sudo dnf install -y git
```

<Warning>

لا تثبّت Docker Engine على هذا المضيف. توفر الحزمة `podman-docker`، التي يثبّتها `bin/podman-setup`، الأمر `docker`، ويعامل Toolkit المضيف على أنه Podman متى وُجد الأمر `podman`.

</Warning>
</Step>
</Steps>
