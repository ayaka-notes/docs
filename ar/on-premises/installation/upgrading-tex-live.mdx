<Danger>

تنطبق التعليمات التالية **فقط** على تثبيتات **Community Edition**. نوصي بشدة مستخدمي Ayakaleaf Pro بتفعيل [الترجمة المعزولة (Sandboxed Compiles)](/ar/on-premises/configuration/overleaf-toolkit/sandboxed-compiles)، إذ توفّر للمستخدمين الوصول إلى صور TeX Live مطابقة تقريبًا لتلك المستخدمة على [overleaf.com](https://www.overleaf.com)، إضافةً إلى توفير العزل بين عمليات ترجمة المشاريع لتعزيز الأمان.

</Danger>

لتوفير عرض النطاق، تأتي صور Overleaf Community Edition و Ayakaleaf Pro مع تثبيت أدنى فقط من [TeX Live](https://www.tug.org/texlive/). يمكنك تثبيت المزيد من الحزم أو الترقية إلى تثبيت كامل لـ TeX Live باستخدام الأمر [tlmgr](https://www.tug.org/texlive/tlmgr.html) داخل الحاوية `sharelatex`.

#### الدخول إلى حاوية sharelatex

لبدء صدفة (shell) داخل الحاوية `sharelatex`، شغّل

```bash
bin/shell
```

سيظهر لك موجّه يبدو هكذا:

```bash
root@309b192d4030:/#
```

في التعليمات التالية، سنفترض أنك داخل الحاوية.

#### تحديد إصدار TeX Live الحالي

يصدر TeX Live كل عام في حوالي شهر أبريل. وتختلف خطوات استخدام `tlmgr` بحسب ما إذا كنت تستخدم الإصدار الحالي أو إصدارًا أقدم. يمكنك التحقق من إصدار TeX Live الذي تشغّله باستخدام `tlmgr --version`. على سبيل المثال، يشغّل هذا التثبيت TeX Live 2021:

```bash
# tlmgr --version
tlmgr revision 59291 (2021-05-21 05:14:40 +0200)
tlmgr using installation: /usr/local/texlive/2021
TeX Live (https://tug.org/texlive) version 2021
```

<Info>

يمكن العثور على الإصدار الحالي من TeX Live في [الصفحة الرئيسية لـ TeX Live](https://www.tug.org/texlive/).

</Info>

إذا كنت تشغّل إصدارًا أقدم من TeX Live، فلديك خياران. عادةً ما يصدر إصدار جديد من صورة Overleaf Docker بعد فترة قصيرة من إصدار TeX Live، لذا يمكنك إما انتظاره وترقية نشرك باستخدام السكربت `bin/upgrade`، أو إذا كنت تفضّل الاحتفاظ بإصدار TeX Live الأقدم، فستحتاج أولًا إلى إخبار `tlmgr` باستخدام مستودع تاريخي. ستجد تعليمات القيام بذلك [هنا](https://www.tug.org/texlive/acquire.html#past).

#### تثبيت الحزم

لتثبيت TeX Live كاملًا، شغّل هذا الأمر داخل الحاوية `sharelatex`:

```text
tlmgr install scheme-full
```

يمكنك أيضًا تثبيت حزم منفردة يدويًا:

```bash
tlmgr install tikzlings tikzmarmots tikzducks
```

<Warning>

بدءًا من الإصدار `3.3.0` فصاعدًا، أصبح تشغيل `tlmgr path add` **مطلوبًا** مجددًا بعد كل استخدام لـ `tlmgr install`، وذلك لإنشاء الروابط الرمزية لجميع الملفات التنفيذية في مسار النظام بشكل صحيح.

</Warning>

تتوفر أوامر أخرى كثيرة. اعرف المزيد باستخدام:

```text
tlmgr help
```

عند الانتهاء، اكتب `exit` أو اضغط Control-D للخروج من الصدفة.

#### حفظ تغييراتك

التغييرات التي أجريتها للتو عدّلت الحاوية `sharelatex`، لكنها مؤقتة -- وستُفقد إذا أعاد Docker Compose إنشاء الحاوية، على سبيل المثال كجزء من تحديث الإعدادات.

لجعلها دائمة، استخدم `docker commit` لحفظ التغييرات في صورة Docker جديدة:

```bash
cat config/version #5.2.1
docker commit sharelatex sharelatex/sharelatex:5.2.1-with-texlive-full
echo 5.2.1-with-texlive-full > config/version
```

بعد حفظ التغييرات، حدّث `config/version` وفقًا لذلك. ثم شغّل `bin/up` لإعادة إنشاء الحاوية `sharelatex`.

<Danger>

ستحتاج إلى تكرار هذه الخطوات في كل مرة [تقوم فيها بالترقية](https://github.com/overleaf/toolkit/blob/master/doc/upgrading.md) إلى إصدار جديد من Overleaf.

</Danger>
