### أنظمة التشغيل

للحصول على أفضل تجربة عند تشغيل Overleaf، نوصي بشدة باستخدام نظام تشغيل **قائم على Debian**، مثل **Ubuntu**. يتوافق هذا الخيار مع بيئة تطوير البرنامج، وهو الخيار المفضّل لدى غالبية مستخدمي Overleaf.

<Danger>

عند استخدام Server Pro مع Sandboxed Compiles، من **المهم** ملاحظة أن التطبيق يتطلب صلاحيات root للوصول إلى Docker socket.

</Danger>

### الاعتماديات

* Docker 25.0 و 29
* MongoDB 7.0 و 8.0
* Redis 6.2 و 7.5

<Info>

يمكنك تتبّع تواريخ انتهاء الدعم (EOL) للاعتماديات المذكورة أعلاه ولمنتجات شائعة أخرى باستخدام خدمة end of life.date من هنا: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

يتم سحب MongoDB و Redis تلقائيًا بواسطة `docker compose` عند تشغيل Server CE أو Server Pro، ما لم يتم إعدادهما لاستخدام تثبيت مختلف.

</Info>

تعتمد Toolkit على البرامج التالية:

* bash
* Docker

الأمر `docker compose` مطلوب، وعادةً ما يُثبَّت مع Docker.

نوصي بتثبيت أحدث إصدار من Docker متاح لنظام التشغيل لديك.

بعد تثبيت Docker بشكل صحيح، يجب أن تتمكن من تشغيل هذه الأوامر دون أخطاء:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2)
docker compose version

# List the running Docker containers on your system
docker ps
```
