### أنظمة التشغيل {#operating-systems}

نوصي بنظام **Linux قائم على Debian**، مثل **Ubuntu**، للخوادم المشتركة وخوادم الإنتاج. يمكن تشغيل Ayakaleaf Pro أيضًا على [macOS باستخدام Docker Desktop](/ar/on-premises/installation/using-docker-compose/macos) وعلى [Windows باستخدام WSL 2 وDocker Desktop](/ar/on-premises/installation/using-docker-compose/windows). تستخدم المنصات الثلاث حاويات Linux وToolkit نفسه؛ اتبع الدليل الخاص بنظام تشغيل المضيف لديك.

<Danger>

عند استخدام Sandboxed Compiles، من **المهم** ملاحظة أن التطبيق يتطلب صلاحيات root للوصول إلى Docker socket.

</Danger>

### الاعتماديات {#dependencies}

* Docker 25.0 و 29
* MongoDB 7.0 و 8.0
* Redis 6.2 و 7.5

<Info>

يمكنك تتبّع تواريخ انتهاء الدعم (EOL) للاعتماديات المذكورة أعلاه ولمنتجات شائعة أخرى باستخدام خدمة end of life.date من هنا: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

يتم سحب MongoDB و Redis تلقائيًا بواسطة `docker compose` عند تشغيل Ayakaleaf Pro، ما لم يتم إعدادهما لاستخدام تثبيت مختلف.

</Info>

تعتمد Toolkit على البرامج التالية:

* bash
* Docker

الأمر `docker compose` مطلوب، وعادةً ما يُثبَّت مع Docker.

نوصي بتثبيت أحدث إصدار من Docker متاح لنظام التشغيل لديك.

بعد تثبيت Docker بشكل صحيح، يجب أن تتمكن من تشغيل هذه الأوامر دون أخطاء:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2 or later, such as v5)
docker compose version

# List the running Docker containers on your system
docker ps
```
