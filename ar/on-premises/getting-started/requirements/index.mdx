### متطلبات تثبيت Server Pro وCommunity Edition

<Warning>

نوصي بشدة بتشغيل Server Pro على إصدار حديث ومستقر من Ubuntu (مثل Ubuntu 24.04 في 2025–2026) مع إصدار حديث من Docker. يمكن تشغيل Server Pro على أنظمة أخرى، لكن ذلك سيجعل تقديم الدعم لإعدادات Ubuntu/Docker غير الافتراضية أصعب بكثير علينا. كما لا يمكننا تقديم الدعم للمشكلات المتعلقة بـ Docker نفسه.

</Warning>
