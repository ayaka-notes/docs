اعمل على مشروع من جهاز الكمبيوتر الخاص بك باستخدام Git. لا تنتقل التغييرات إلا عند تشغيل `git pull` أو `git push`.

<Info>

يجب على المسؤول تفعيل [تكامل Git](/ar/on-premises/configuration/overleaf-toolkit/integrations/git-integration) أولًا.

</Info>

## إنشاء رمز {#create-a-token}

يسجّل Git الدخول باستخدام رمز مصادقة Git، وليس بكلمة مرور حسابك.

<Steps>
<Step title="افتح إعدادات حسابك">
انقر على **Account**، ثم **Account settings**. ضمن **Git integration**، انقر على **Generate token**. بعد أن يصبح لديك رمز، يصبح اسم هذا الزر **Add another token**.

<Frame caption="تكامل Git في إعدادات الحساب">
  <img src="/images/on-premises/git-integration-settings.png" alt="قسم Git integration في إعدادات الحساب مع زر Generate token" />
</Frame>
</Step>

<Step title="انسخ الرمز">
انقر على **Copy** واحفظ الرمز في مكان آمن. لن تراه إلا مرة واحدة. ثم انقر على **Close**.

<Frame caption="رمزك الجديد">
  <img src="/images/on-premises/git-integration-token.png" alt="مربع حوار رمز مصادقة Git مع زر Copy" />
</Frame>
</Step>

<Step title="تحقّق من الرمز">
تعرض القائمة الآن بداية الرمز، ووقت إنشائه، وآخر وقت استُخدم فيه. تنتهي صلاحيته بعد سنة واحدة. يمكنك امتلاك ما يصل إلى 10 رموز.

<Frame caption="رموزك">
  <img src="/images/on-premises/git-integration-tokens.png" alt="قائمة الرموز وفيها رمز واحد" />
</Frame>
</Step>
</Steps>

## استنساخ مشروع {#clone-a-project}

<Steps>
<Step title="افتح تكامل Git في المحرر">
افتح المشروع. في الشريط الأيسر، انقر على **Integrations**، ثم **Git integration**.

<Frame caption="لوحة Integrations">
  <img src="/images/on-premises/git-integration-panel.png" alt="لوحة Integrations مع بطاقة Git integration" />
</Frame>
</Step>

<Step title="انسخ الأمر">
يعرض مربع الحوار **Clone with Git** الأمر، مع عنوان موقعك ومعرّف المشروع. انقر على **Copy**. إذا لم يكن لديك رمز بعد، يفتح **Go to settings** إعدادات حسابك في علامة تبويب جديدة.

<Frame caption="أمر الاستنساخ">
  <img src="/images/on-premises/git-integration-clone.png" alt="مربع الحوار Clone with Git مع الأمر git clone" />
</Frame>
</Step>

<Step title="شغّله">
الصق الأمر في الطرفية. عندما يطلب Git كلمة مرور، الصق رمزك.

```text
$ git clone https://git@<your-site>/git/<project-id>
Cloning into '<project-id>'...
Password for 'https://git@<your-site>': <your-token>
```

يحتوي الآن مجلد يحمل اسم معرّف المشروع على ملفات المشروع، على الفرع `main`. لاختيار اسم المجلد، أضفه في نهاية الأمر.
</Step>
</Steps>

يطلب Git الرمز في كل مرة يتصل فيها بالموقع. لكي يتذكّره، فعّل credential helper: يطلبه Git مرة أخرى، ثم يحتفظ بالرمز. يحفظ الـ helper ‏`store` الرمز دون تشفير في `~/.git-credentials`.

```bash
git config --global credential.helper store
```

## سحب التغييرات من المحرر {#pull-changes-from-the-editor}

داخل المجلد، شغّل:

```bash
git pull
```

يسرد Git الملفات التي تغيّرت. تصل التغييرات التي أُجريت في المحرر على شكل commits باسم `Update on Overleaf.`.

```text
Updating db007e3..c3e6332
Fast-forward
 main.tex | 2 +-
 1 file changed, 1 insertion(+), 1 deletion(-)
```

## دفع تغييراتك {#push-your-changes}

نفّذ commit لتغييراتك، ثم ادفعها:

```bash
git add main.tex
git commit -m "Add a line from Git"
git push
```

يعرض السطر الأخير من المخرجات الفرع الذي تقدّم:

```text
   53aca61..db007e3  main -> main
```

تظهر التغييرات في المحرر، ويتحدّث المحرر المفتوح من تلقاء نفسه. تظهر الملفات والمجلدات الجديدة وعمليات إعادة التسمية في شجرة الملفات. في **History**، يُوسَم تغييرك بـ <strong>You (via Git)</strong>. لا تظهر رسالة الـ commit هناك.

<Frame caption="عملية push في سجل المشروع">
  <img src="/images/on-premises/git-integration-history.png" alt="سجل المشروع يعرض السطر المدفوع، موسومًا بـ You (via Git)" />
</Frame>

### إذا رفض Git عملية الدفع {#if-git-refuses-your-push}

إذا تغيّر المشروع في هذه الأثناء، يرفض Git عملية الدفع:

```text
 ! [rejected]        main -> main (fetch first)
```

اجلب تلك التغييرات أولًا، ثم ادفع مرة أخرى:

```bash
git pull --no-rebase --no-edit
git push
```

قد يتوقف `git pull` العادي بالرسالة `fatal: Need to specify how to reconcile divergent branches.` يعالج الخيار `--no-rebase` أعلاه ذلك: فهو يدمج الجانبين.

إذا تغيّرت الأسطر نفسها في الجانبين، يتوقف pull بالرسالة `CONFLICT (content): Merge conflict in main.tex`. أصلح الملف، ثم شغّل:

```bash
git add main.tex
git commit -m "Merge the changes from the editor"
git push
```

هناك أمران لا يقبلهما الموقع:

* الفروع الأخرى: `! [remote rejected] feature -> feature (wrong branch)`. لا يوجد سوى `main`، لذا ادفع عملك إليه.
* الدفع القسري: `! [remote rejected] main -> main (forced push prohibited)`. بدلًا من ذلك، ضع تغييراتك فوق `main` الحالي.

### إذا أظهر Git الرسالة Authentication failed {#if-git-says-authentication-failed}

```text
remote: Enter your Git authentication token when prompted for a password.
fatal: Authentication failed for 'https://<your-site>/git/<project-id>/'
```

الرمز خاطئ أو محذوف، أو أنك أدخلت كلمة مرور حسابك. أنشئ رمزًا جديدًا إذا لم يعد لديك، لأنه لا يمكنك عرض رمز موجود مرة أخرى.

## حذف رمز {#delete-a-token}

في **Account settings**، ضمن **Git integration**، انقر على أيقونة الحذف بجوار الرمز، ثم **Delete** في مربع الحوار. منذ ذلك الحين، يرد Git على هذا الرمز بـ `Authentication failed`.
