اربط مشروعًا بمستودع على GitHub. تنتقل التغييرات في الاتجاهين، ولا يحدث ذلك إلا عند النقر على **Sync**: لا شيء يُزامَن من تلقاء نفسه.

<Info>

إذا لم تجد خيار GitHub في **Account settings** أو في المحرر، فاطلب من المسؤول تفعيل [المزامنة مع GitHub](/ar/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation).

</Info>

## ربط حسابك على GitHub {#link-your-github-account}

تفعل ذلك مرة واحدة.

<Steps>
<Step title="افتح إعدادات حسابك">
انقر على **Account**، ثم **Account settings**. مرّر إلى **GitHub** وانقر على **Link**.

<Frame caption="GitHub في إعدادات الحساب">
  <img src="/images/on-premises/github-sync-link.png" alt="قسم GitHub في إعدادات الحساب مع زر Link" />
</Frame>
</Step>

<Step title="امنح التفويض على GitHub">
يُفتح GitHub. سجّل الدخول إذا طُلب منك ذلك، ثم امنح التطبيق التفويض.
</Step>

<Step title="تحقّق من الربط">
تعود إلى إعدادات الحساب، ويظهر على الزر الآن **Unlink**.

<Frame caption="حسابك على GitHub مرتبط">
  <img src="/images/on-premises/github-sync-linked.png" alt="قسم GitHub في إعدادات الحساب مع زر Unlink" />
</Frame>
</Step>
</Steps>

إذا لم يكن حسابك مرتبطًا بعد، يطلب منك **Import from GitHub** وبطاقة **GitHub** في المحرر ربطه أولًا. انقر على **Link to your GitHub account**. ستصل أيضًا إلى إعدادات الحساب، في علامة تبويب جديدة إذا بدأت من المحرر. ثم ارجع وابدأ من جديد.

<Frame caption="الرسالة عندما لا يكون حسابك مرتبطًا">
  <img src="/images/on-premises/github-sync-link-prompt.png" alt="مربع الحوار Import from GitHub مع زر Link to your GitHub account" />
</Frame>

## استيراد مستودع {#import-a-repository}

ينشئ هذا مشروعًا جديدًا من مستودع على GitHub، مرتبطًا به مسبقًا.

<Steps>
<Step title="افتح مربع حوار الاستيراد">
في صفحة المشاريع، انقر على **New project**، ثم **Import from GitHub**.

<Frame caption="قائمة New project">
  <img src="/images/on-premises/github-sync-new-project-menu.png" alt="قائمة New project مع Import from GitHub" />
</Frame>

<Info>

يظهر **New project** بعد أن يصبح لديك مشروع. لا تحتوي قائمة **Create a new project** في صفحة الترحيب على خيار الاستيراد، لذا أنشئ مشروعًا فارغًا أولًا.

</Info>
</Step>

<Step title="اختر المستودع">
انقر على **Import to Overleaf** بجوار المستودع. تتضمن القائمة مستودعاتك ومستودعات مؤسساتك.

<Frame caption="مستودعاتك على GitHub">
  <img src="/images/on-premises/github-sync-import.png" alt="مربع الحوار Import from GitHub يعرض أربعة مستودعات" />
</Frame>

إذا كان مستودع إحدى المؤسسات مفقودًا، فانقر على <strong>Can't see what you're looking for?</strong> للاطلاع على مساعدة GitHub حول الموافقة على التطبيق لتلك المؤسسة.
</Step>

<Step title="تحقّق من المشروع">
يُفتح المشروع الجديد مع ملفات المستودع.

<Frame caption="المشروع المستورد">
  <img src="/images/on-premises/github-sync-imported.png" alt="المحرر يعرض المشروع المستورد مع ملفاته وملف PDF المُجمَّع" />
</Frame>
</Step>
</Steps>

## تصدير مشروع إلى مستودع جديد {#export-a-project-to-a-new-repository}

ينشئ هذا مستودعًا من مشروع تملكه ويربطهما معًا. لا يمكن ربط المشروع إلا بهذه الطريقة أو بالاستيراد: لا يمكنك ربطه بمستودع موجود بالفعل.

<Steps>
<Step title="افتح GitHub في المحرر">
افتح المشروع. في الشريط الأيسر، انقر على **Integrations**، ثم **GitHub**.

<Frame caption="لوحة Integrations">
  <img src="/images/on-premises/github-sync-integrations.png" alt="لوحة Integrations مع بطاقة GitHub" />
</Frame>
</Step>

<Step title="املأ بيانات المستودع">
اختر **Owner**، ويمكن أن يكون أنت أو إحدى مؤسساتك. يبدأ **Repository Name** باسم المشروع. الوصف اختياري، و**Private** محدد افتراضيًا. انقر على **Create a GitHub repository**.

<Frame caption="Export Project to GitHub">
  <img src="/images/on-premises/github-sync-export.png" alt="نموذج Export Project to GitHub بعد ملئه" />
</Frame>
</Step>

<Step title="تحقّق من الربط">
يعرض مربع الحوار الآن **This project is linked to** واسم المستودع.

<Frame caption="المشروع مرتبط">
  <img src="/images/on-premises/github-sync-exported.png" alt="مربع الحوار Sync with GitHub بعد التصدير" />
</Frame>
</Step>
</Steps>

## المزامنة {#sync}

<Steps>
<Step title="افتح مربع حوار المزامنة">
افتح مشروعًا مرتبطًا. في الشريط الأيسر، انقر على **Integrations**، ثم **GitHub**.

يسرد **Recent commits in GitHub** ما سيدخل إلى المشروع.

<Frame caption="commit جديد ينتظر على GitHub">
  <img src="/images/on-premises/github-sync-new-commits.png" alt="مربع الحوار Sync with GitHub يعرض commit جديدًا واحدًا" />
</Frame>
</Step>

<Step title="صِف تغييراتك">
إذا غيّرت شيئًا في المشروع، يظهر مربع لرسالة الـ commit. وهو اختياري: إذا تركته فارغًا، يكون اسم الـ commit هو `Updates from Overleaf`.

<Frame caption="رسالة الـ commit لتغييراتك">
  <img src="/images/on-premises/github-sync-commit-message.png" alt="مربع الحوار Sync with GitHub مع رسالة commit مكتوبة" />
</Frame>
</Step>

<Step title="انقر على Sync">
انقر على **Sync**. تدخل الـ commits الجديدة من GitHub إلى المشروع، وتذهب تغييراتك إلى الفرع الافتراضي في المستودع. إذا غيّر الجانبان أشياء مختلفة، تُدمج لك تلقائيًا.
</Step>

<Step title="تحقّق من النتيجة">
يعرض مربع الحوار <strong>No new commits in GitHub since last merge.</strong> ويختفي مربع رسالة الـ commit. الملفات في المحرر والـ commits على GitHub محدّثة.

<Frame caption="كل شيء متزامن">
  <img src="/images/on-premises/github-sync-done.png" alt="مربع الحوار Sync with GitHub بعد المزامنة، بلا commits جديدة" />
</Frame>
</Step>
</Steps>

### إذا تغيّرت الأسطر نفسها في الجانبين {#if-the-same-lines-changed-on-both-sides}

يخبرك مربع الحوار بأنه تعذّر دمج التغييرات، ويذكر فرعًا جديدًا، `overleaf-YYYY-MM-DD-HHMMSS`، يحتوي على تغييراتك.

<Frame caption="تعارض">
  <img src="/images/on-premises/github-sync-conflict.png" alt="مربع الحوار Sync with GitHub مع تحذير من تعارض في الدمج" />
</Frame>

1. ادمج ذلك الفرع في الفرع الافتراضي على GitHub أو باستخدام Git. يمكنك إغلاق مربع الحوار في هذه الأثناء: فهو يعرض الرسالة نفسها عند فتحه مرة أخرى.
2. انقر على **I have manually merged. Continue**. تدخل النتيجة المدموجة إلى المشروع.
3. يبقى الفرع على GitHub. احذفه عندما لا تعود بحاجة إليه.

## إلغاء ربط مشروع {#unlink-a-project}

افعل ذلك عندما لا تعود تريد مزامنة المشروع. لا يستطيع ذلك إلا مالك المشروع.

<Steps>
<Step title="انقر على Unlink">
في مربع حوار المزامنة، انقر على **Unlink**.
</Step>

<Step title="أكّد">
انقر على **Confirm**. الملاحظة المتعلقة بالاشتراك لا تمنعك من ربط المشروع مرة أخرى.

<Frame caption="تأكيد إلغاء الربط">
  <img src="/images/on-premises/github-sync-unlink-project.png" alt="مربع الحوار Sync with GitHub يطلب تأكيد إلغاء الربط" />
</Frame>
</Step>

<Step title="تحقّق من النتيجة">
يعرض مربع الحوار الآن **Export Project to GitHub**. يحتفظ كل من المشروع والمستودع بمحتواه. للمزامنة مرة أخرى، صدّر المشروع إلى مستودع جديد، أو استورد المستودع إلى مشروع جديد.
</Step>
</Steps>

## إلغاء ربط حسابك على GitHub {#unlink-your-github-account}

في **Account settings**، ضمن **GitHub**، انقر على **Unlink**، ثم انقر على **Unlink** مرة أخرى في مربع الحوار.

<Frame caption="إلغاء ربط حسابك">
  <img src="/images/on-premises/github-sync-unlink-account.png" alt="مربع الحوار Unlink GitHub Account" />
</Frame>

تبقى مشاريعك مرتبطة بمستودعاتها. لا يمكنك مزامنتها حتى تربط حسابك مرة أخرى.

<Info>

لمعرفة من يمكنه فعل ماذا في مشروع مشترك، راجع [من يمكنه الربط والمزامنة](/ar/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation#who-can-link-and-sync). يربط كل متعاون يجري المزامنة حسابه الخاص على GitHub.

</Info>
