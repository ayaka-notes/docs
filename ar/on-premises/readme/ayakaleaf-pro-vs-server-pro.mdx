<Info>

Ayakaleaf Pro تطبيق محسّن لـ Overleaf Community Edition، يقدم جميع ميزات Server Pro _**المدفوعة مجانًا**_. وعلى عكس Overleaf Common المتاح على [https://www.overleaf.com/](https://www.overleaf.com/)، لا توجد لدينا قيود على وقت الترجمة، ولا متطلبات ترخيص مرتبطة بعدد المستخدمين، ويمكنك استضافة بياناتك ذاتيًا بالكامل، مما يضمن أمانًا مطلقًا.

Overleaf Server Pro هو نشر تجاري لـ Overleaf مستضاف ذاتيًا، مع دعم رسمي. لمزيد من المعلومات حول Server Pro، تفضّل بزيارة [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud).

</Info>

<Warning>

صُمّم Overleaf Community Edition للاستخدام في البيئات التي يكون فيها **جميع** المستخدمين موثوقين. ولا يُعدّ Community Edition مناسبًا للسيناريوهات التي تتطلب عزل المستخدمين، نظرًا لعدم توفر Sandbox Compiles فيه.

بدون العزل (sandboxing)، تعمل عمليات ترجمة LaTeX بصلاحيات الحاوية نفسها، مما يتيح الوصول إلى نظام ملفاتها وشبكتها ومتغيرات بيئتها. وهذا يخلق خطر كشف البيانات أو اختراق النظام. لا ينبغي استخدام عمليات الترجمة غير المعزولة إلا في بيئات موثوقة تمامًا؛ أما في عمليات النشر متعددة المستخدمين أو بيئات الإنتاج، فيُوصى بشدة باستخدام Sandbox Compiles.

لمزيد من المعلومات حول Sandbox Compiles، اطّلع على [وثائقنا](/ar/on-premises/configuration/overleaf-toolkit/sandboxed-compiles).

</Warning>

### دعم المجتمع

بالنسبة لمن يستخدمون مثيل Overleaf مستضافًا ذاتيًا، يقدّم المجتمع الدعم عبر [Issues](https://github.com/ayaka-notes/ayakaleaf-pro/issues) على GitHub.

للبقاء على مسار مدعوم، يمكنك التأكد من إصدار Overleaf الذي تشغّله بمقارنة مخرجات الأمر أدناه مع معرّفات الصور (Image ID) المنشورة في ملاحظات الإصدار.

```bash
docker inspect --format '{{.Image}}' sharelatex | awk -F: '{print substr($2, 1, 12)}'
```
