title: التكاملات
description: اربط نشرًا قائمًا على Kubernetes بـ Git وGitHub وGitLab وGitea وDropbox ومديري المراجع وخدمات الذكاء الاصطناعي ومواقع أخرى.
icon: puzzle-piece
---

كل تكامل معطّل افتراضيًا، باستثناء Overleaf Import API. كما تتطلب المزامنة مع GitHub وGitLab وGitea وDropbox وخادم MCP [تكامل Git](/ar/on-premises/configuration/kubernetes/integrations/git-integration). بعد تفعيل أحدها في الـ ConfigMap أو الـ Secret، أعد تشغيل النسخ المتماثلة باستخدام `kubectl -n overleaf rollout restart`.
