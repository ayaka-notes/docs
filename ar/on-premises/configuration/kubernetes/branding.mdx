تعرض خدمة **web** العنوان والشعار وروابط الترويسة والتذييلات وصفحة الصيانة استنادًا إلى متغيرات البيئة. كل إعداد وصيغته موضّحان في [العلامة التجارية](/ar/on-premises/configuration/overleaf-toolkit/branding)؛ وعلى Kubernetes توضع هذه الإعدادات في الـ ConfigMap.

| | |
| --- | --- |
| الخدمة | web، في كل Pod من Pods ‏Ayakaleaf Pro؛ تُقرأ عند بدء تشغيل web |
| الشبكة | لا شيء: الشعارات عناوين URL يحمّلها المتصفح |
| المهام الدورية | لا توجد (تفحص خدمة web ملف الصيانة كل 5 ثوانٍ، راجع أدناه) |

### الإعداد

```yaml title="30-config.yaml (additions)" wrap
  OVERLEAF_NAV_TITLE: Our Overleaf Instance
  OVERLEAF_HEADER_IMAGE_URL: https://example.com/img/logo.png
  OVERLEAF_HEADER_EXTRAS: '[{"text":"Help","url":"https://example.com/help","class":"subdued"}]'
  OVERLEAF_LEFT_FOOTER: '[{"text":"Run by the IT department"}]'
  OVERLEAF_RIGHT_FOOTER: '[{"text":"Imprint","url":"https://example.com/imprint"}]'
  OVERLEAF_MAINTENANCE_MESSAGE: Our Overleaf Instance is down for maintenance and will be back shortly.
```

```bash
kubectl apply -f 30-config.yaml
kubectl -n overleaf rollout restart deployment/overleaf     # or statefulset/overleaf
```

ضع قيم JSON بين علامتي اقتباس مفردتين، كما في المثال أعلاه، حتى يحتفظ بها YAML سلسلةً نصية واحدة. يُتجاهَل JSON غير الصالح في `OVERLEAF_HEADER_EXTRAS` أو في التذييلات، ولا يُسجَّل إلا عند بدء التشغيل.

### وضع الصيانة

تُعرض صفحة الصيانة ما دام الملف `/etc/overleaf/site_status` في الحاوية يحتوي على `closed`. لكل Pod نسخته الخاصة من هذا الملف، ويبدأ أي Pod جديد أو مُعاد تشغيله في حالة مفتوحة. لإغلاق الموقع، اكتب الملف في كل Pod:

```bash
for p in $(kubectl -n overleaf get pod -l app=overleaf -o name); do   # app=overleaf-ha for several replicas
  kubectl -n overleaf exec "$p" -- sh -c 'echo closed > /etc/overleaf/site_status'
done
```

اكتب `open` بالطريقة نفسها لإنهائه. تلتقط الـ Pods التغيير خلال 5 ثوانٍ.

يعمل خيار **Close Editor** في لوحة الإدارة بطريقة مختلفة: فهو يغلق المحرر فقط في النسخة المتماثلة التي خدمت طلب المسؤول، وتعيد تلك النسخة فتحه عند إعادة تشغيلها. مع عدة نسخ متماثلة، استخدم الملف كما هو موضح أعلاه بدلًا من ذلك.

### الاختبار على Kubernetes

على Kubernetes 1.37: مع الإعدادات أعلاه في الـ ConfigMap، عرضت الصفحات `OVERLEAF_NAV_TITLE` والتذييل الأيسر، وبعد تسجيل الدخول، الرابط من `OVERLEAF_HEADER_EXTRAS` (تُخفي صفحات تسجيل الدخول روابط الترويسة). أدت كتابة `closed` في `/etc/overleaf/site_status` لـ Pod واحد إلى عرض صفحة الصيانة مع `OVERLEAF_MAINTENANCE_MESSAGE` على ذلك الـ Pod فقط، وأنهت كتابة `open` ذلك خلال ثوانٍ. ومع ثلاث نسخ متماثلة، أغلق خيار Close Editor في لوحة الإدارة المحرر فقط على النسخة المتماثلة التي خدمت المسؤول، بينما بقيت النسختان الأخريان مفتوحتين.
