يدعم Overleaf إرسال البريد الإلكتروني بطريقتين: بروتوكول نقل البريد البسيط (SMTP) و[Amazon Simple Email Service (SES)](https://aws.amazon.com/ses/). يمكن استخدام SMTP إذا كان لديك خادم بريد مفعَّل على localhost يستمع للاتصالات المحلية.

## التكوين

يُكوَّن البريد الإلكتروني باستخدام متغيرات البيئة التالية.

#### تكوين المُرسِل

| الاسم                          | الوصف |
| ----------------------------- | ----------- |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | <p>عنوان المُرسِل، مثل <a href="mailto:support@mycompany.com">`'support@mycompany.com'`</a><br /><br />- <strong>مطلوب</strong>: نعم</p> |
| `OVERLEAF_EMAIL_REPLY_TO`     | عنوان الرد، مثل `'noreply@mycompany.com'` |

#### SMTP

| الاسم                                    | الوصف |
| --------------------------------------- | ----------- |
| `OVERLEAF_EMAIL_SMTP_HOST`              | اسم المضيف أو عنوان IP المراد الاتصال به. يجب أن يكون قابلًا للوصول من حاوية Docker |
| `OVERLEAF_EMAIL_SMTP_PORT`              | المنفذ المراد الاتصال به |
| `OVERLEAF_EMAIL_SMTP_SECURE`            | إذا كانت القيمة `true` فسيستخدم الاتصال TLS عند الاتصال بالخادم. إذا كانت `false` أو لم تُضبط، فسيُستخدم TLS إذا كان الخادم يدعم امتداد `STARTTLS`. في معظم الحالات اضبط هذه القيمة على `true` إذا كنت تتصل بالمنفذ `465`. أما للمنفذ `587` أو `25` فأبقها `false` |
| `OVERLEAF_EMAIL_SMTP_USER`              | اسم المستخدم الذي يجب استخدامه للمصادقة مع خادم SMTP |
| `OVERLEAF_EMAIL_SMTP_PASS`              | كلمة المرور المرتبطة باسم مستخدم SMTP |
| `OVERLEAF_EMAIL_SMTP_TLS_REJECT_UNAUTH` | إذا كانت القيمة `false` فسيُفتح اتصال بخادم TLS حتى لو كانت شهادة TLS موقَّعة ذاتيًا أو غير صالحة |
| `OVERLEAF_EMAIL_SMTP_IGNORE_TLS`        | عندما تكون القيمة `true` وتكون `OVERLEAF_EMAIL_SMTP_SECURE` هي `false`، فلن يُستخدم TLS حتى لو كان الخادم يدعم امتداد `STARTTLS` |
| `OVERLEAF_EMAIL_SMTP_NAME`              | اسم مضيف اختياري للتحقق من TLS إذا ضُبط `OVERLEAF_EMAIL_SMTP_HOST` على عنوان IP، والقيمة الافتراضية هي اسم مضيف الجهاز. |
| `OVERLEAF_EMAIL_SMTP_LOGGER`            | عندما تكون القيمة `true` تُطبع رسائل السجل في `web.log`. |

#### واجهة SMTP في Amazon SES

يمكنك قراءة المزيد حول استخدام واجهة SMTP في Amazon SES لإرسال البريد الإلكتروني [هنا](https://docs.aws.amazon.com/ses/latest/dg/send-email-smtp.html).

| الاسم                       | الوصف |
| -------------------------- | ----------- |
| `OVERLEAF_EMAIL_SMTP_HOST` | اسم المضيف أو عنوان IP المراد الاتصال به. يجب أن يكون قابلًا للوصول من حاوية Docker |
| `OVERLEAF_EMAIL_SMTP_PORT` | المنفذ المراد الاتصال به |
| `OVERLEAF_EMAIL_SMTP_USER` | اسم المستخدم الذي يجب استخدامه للمصادقة مع خادم SMTP |
| `OVERLEAF_EMAIL_SMTP_PASS` | كلمة المرور المرتبطة باسم مستخدم SMTP |

#### واجهة API في Amazon SES

يمكنك قراءة المزيد حول استخدام واجهة API في Amazon SES لإرسال البريد الإلكتروني [هنا](https://docs.aws.amazon.com/ses/latest/dg/send-email-api.html).

| الاسم                                   | الوصف |
| -------------------------------------- | ----------- |
| `OVERLEAF_EMAIL_AWS_SES_ACCESS_KEY_ID` | مفتاح الوصول (access key) عند استخدام AWS SES |
| `OVERLEAF_EMAIL_AWS_SES_SECRET_KEY`    | المفتاح السري (secret key) عند استخدام AWS SES |
| `OVERLEAF_EMAIL_AWS_SES_REGION`        | إذا لم تُضبط، فالمنطقة الافتراضية هي US-EAST-1 |

#### AWS SES مع أدوار المثيلات (Instance Roles)

| الاسم                    | الوصف |
| ----------------------- | ----------- |
| `OVERLEAF_EMAIL_DRIVER` | عند ضبط هذه القيمة على `ses`، سيستخدم نظام البريد طريقة SES API ويعتمد على أدوار المثيلات المكوَّنة لإرسال البريد الإلكتروني. |

#### التخصيص

| الاسم                           | الوصف |
| ------------------------------ | ----------- |
| `OVERLEAF_CUSTOM_EMAIL_FOOTER` | <p>HTML مخصص يُلحَق بجميع رسائل البريد الإلكتروني. مثلًا:<br /><br /><strong>مثال</strong>: `"<div>This system is run by department x </div> <div> If you have any questions please look at our faq <a href='`<a href="https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/https:/somwhere.com'%3Ehere&#x3C;/a%3E&#x3C;/div%3E">`https://somwhere.com'>here&#x3C;/a>&#x3C;/div>`</a>`"`</p> |
