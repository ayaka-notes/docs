يمتلك كل مشروع خادم MCP خاصًا به، بحيث يمكن لعملاء الذكاء الاصطناعي مثل Claude Code و Codex و Cursor و VS Code و Gemini CLI العمل عليه: قراءة ملفاته وتعديلها، وترجمته، وقراءة سجل LaTeX، وتنزيل ملف PDF، والرد على التعليقات.

<Info>

طُوّرت هذه الميزة بواسطة [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro). وهي متاحة بدءًا من الإصدار v6.3.1 وما بعده.

### الإعداد

يأتي خادم MCP مع التكامل مع Git: فعّل [git-bridge](/ar/on-premises/configuration/overleaf-toolkit/git-integration)، وسيصبح خادم MCP متاحًا أيضًا. لا يوجد أي شيء آخر لتكوينه.

### ربط عميل ذكاء اصطناعي

1. في **Account Settings**، أنشئ رمز مصادقة Git (token). يُستخدم الرمز نفسه لخادم MCP ولـ Git.
2. في المحرر، افتح **Integrations** وانقر على **MCP server**. تعرض النافذة عنوان خادم MCP الخاص بالمشروع، `https://<your-overleaf>/project/<project_id>/mcp`، وطريقة إضافته إلى كل عميل ذكاء اصطناعي: انسخ الأمر، واستبدل `<token>` بالرمز الخاص بك.

### الاستخدام

بمجرد الاتصال، اطلب من عميل الذكاء الاصطناعي ما تريد بكلمات بسيطة. على سبيل المثال:

| ما تطلبه | ما يستخدمه عميل الذكاء الاصطناعي |
| --- | --- |
| _أصلح الأخطاء الإملائية في المقدمة._ | `read_file` و `edit_file`: تظهر التعديلات مباشرةً في المحرر |
| _ترجم المشروع وأصلح أخطاء LaTeX._ | `compile` و `get_compile_log` و `edit_file` |
| _أجب عن التعليقات المفتوحة، ثم احسمها._ | `list_comments` و `reply_to_comment` و `resolve_comment` |
| _بدّل إلى XeLaTeX ونزّل ملف PDF._ | `update_settings` و `compile` و `get_output_file_link` |

### الأدوات

| المجموعة | الأدوات |
| --- | --- |
| المشروع | `get_clone_info` و `get_settings` و `update_settings` و `list_versions` |
| الملفات | `list_files` و `read_file` و `edit_file` و `write_file` و `delete_file` |
| الترجمة | `compile` و `get_compile_log` و `get_output_file_link` و `word_count` |
| التعليقات | `list_comments` و `reply_to_comment` و `resolve_comment` و `reopen_comment` |

تظهر التعديلات التي تُجرى باستخدام `edit_file` و `write_file` مباشرةً في المحرر وتُدمج مع تعديلات المتعاونين. وبالنسبة إلى ملفات كثيرة دفعة واحدة، أو الملفات الثنائية، أو عمليات إعادة التسمية، يمكن لعميل الذكاء الاصطناعي أيضًا استنساخ المشروع باستخدام Git ثم الدفع (push).

### الصلاحيات

يتبع خادم MCP إعدادات مشاركة المشروع، تمامًا مثل Git:

* يمكن لكل من يستطيع عرض المشروع قراءته وترجمته وتنزيل مخرجاته.
* لا يمكن إلا للمالك والمحررين تغيير ملفاته وإعداداته.
* يمكن للمراجعين أيضًا الرد على التعليقات، وحسم التعليقات التي بدأوها أو إعادة فتحها.
* لا يمكن للمشاهدين الذين انضموا عبر رابط رؤية التعليقات، كما هو الحال في المحرر.
