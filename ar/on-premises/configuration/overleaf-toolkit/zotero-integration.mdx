### إعداد التكامل مع Zotero

1. افتح [هذا الرابط](https://www.zotero.org/oauth/apps) لإنشاء عميل Zotero OAuth (كما هو موضح في الصورة)
2. اختر **Application Type**: **Browser**
3. اضبط عنوان رد الاتصال (Callback URL) ليكون `${OVERLEAF_SITE_URL}/user/zotero/oauth/callback`
4. اضبط الملف `config/variables.env` الخاص بك

<Frame>
  <img src="/images/on-premises/image-41.png" alt="" width="375" />
</Frame>

```dotenv title="config/variables.env"
#################
#    Zotero     #
#################
# 'zotero' must be in ENABLED_LINKED_FILE_TYPES (set in develop/docker-compose.yml)
ENABLED_LINKED_FILE_TYPES=project_file,project_output_file,url,zotero

# From a Zotero OAuth client (register at https://www.zotero.org/oauth/apps)
# Application Type: Browser 
# Callback URL -> ${OVERLEAF_SITE_URL}/user/zotero/oauth/callback
ZOTERO_CLIENT_ID=
ZOTERO_CLIENT_SECRET=
# Encrypts the Zotero API key in mongo (set in dev to avoid writing a key file
# to /var/lib/overleaf/data, which the dev web container can't create)
# How to generate: `openssl rand -hex 32`
ZOTERO_CIPHER_PASSWORD=dev-zotero-cipher-password
# Optional: route the module's server-side Zotero requests (OAuth + API) through
# an HTTP proxy (must be reachable from the web container; same as github-sync)
# http://10.0.0.1:10808
# (Optional) ZOTERO_PROXY_URL=
```

### ملاحظات

<Warning>

عند ترقية تثبيت موجود يحتوي على ملفات مراجع مرتبطة بـ Zotero إلى الإصدار 6.3.0 المُعاد إصداره، اتبع [تعليمات ترحيل Zotero / Mendeley](/ar/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention"). لا تحتاج التثبيتات الجديدة إلى هذا الترحيل.

</Warning>

<Danger>

نظرًا لأن Ayakaleaf منصة تعاونية، ولتحسين الأمان، بدءًا من الإصدار 6.3.0 لن يُسمح إلا للمنشئ الأصلي لملف المراجع `bib` بتحديث الملف المستورد.

</Danger>

على سبيل المثال، لنفترض أن مالك المشروع، المستخدم A، فعّل المشاركة عبر الرابط وأنشأ ملف `test.bib` في المشروع، وربطه بحساب Zotero الخاص به. إذا وصل مستخدم آخر، المستخدم B، إلى المشروع عبر الرابط المشترك، فسيظل بإمكان المستخدم B قراءة `test.bib` وتنزيله، لكن لن يُسمح له بتحديث الملف أو إعادة استيراده من Zotero. وحده المستخدم A، بصفته المنشئ الأصلي لملف المراجع، يمكنه إجراء التحديثات. وبعبارة أخرى، لا يملك صلاحية تحديث ملف `.bib` سوى منشئه الأصلي.
