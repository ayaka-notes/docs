### إعداد i18 في Overleaf

<Info>

يصف هذا المستند كيفية إعداد التدويل (i18n) لنسخة **Overleaf** مستضافة ذاتيًا.

</Info>

تُرجمت Overleaf إلى لغات متعددة. ومع الإعداد المناسب، يمكنك:

* تشغيل نسخة Overleaf الخاصة بك **بلغة واحدة ثابتة**، أو
* تفعيل **لغات متعددة**، مما يتيح للمستخدمين تبديل اللغة ديناميكيًا، على غرار `www.overleaf.com`.

***

#### إعداد لغة واحدة

تُضبط لغة الموقع باستخدام متغير البيئة `OVERLEAF_SITE_LANGUAGE` (أو `SHARELATEX_SITE_LANGUAGE` لإصدارات Overleaf **4.x والأقدم**).

تشمل رموز اللغات المدعومة:

* `en` - الإنجليزية (الافتراضية)
* `es` - الإسبانية
* `pt` - البرتغالية
* `de` - الألمانية
* `fr` - الفرنسية
* `cs` - التشيكية
* `nl` - الهولندية
* `sv` - السويدية
* `it` - الإيطالية
* `tr` - التركية
* `zh-CN` - الصينية (المبسطة)
* `no` - النرويجية
* `da` - الدنماركية
* `ru` - الروسية
* `ko` - الكورية
* `ja` - اليابانية
* `pl` - البولندية
* `fi` - الفنلندية

الإنجليزية هي اللغة الافتراضية. لتغيير لغة الواجهة (على سبيل المثال، إلى الصينية المبسطة)، أضف السطر التالي إلى `config/variables.env`:

```bash title="config/variables.env"
OVERLEAF_SITE_LANGUAGE=zh-CN
```

ثم طبّق الإعداد:

```bash
bin/up
```

بعد إعادة تشغيل الخدمات، يُفترض أن تعكس لغة الواجهة في قوائم واجهة الويب الإعداد الجديد.

#### إعداد لغات متعددة

للسماح للمستخدمين **بتبديل اللغة دون تسجيل الخروج**، يجب إعداد نسخة Overleaf لتقديم لغات مختلفة بناءً على أسماء النطاقات.

يفترض هذا القسم ما يلي:

* نطاقك الأساسي هو `overleaftest.com`
* لديك **شهادة TLS عامة (wildcard)** (مثل `*.overleaftest.com`)
* أنك **لا تستخدم `localhost`** (لأنه لا يدعم توجيه اللغات المعتمد على النطاقات الفرعية)

للاختبار المحلي، يمكنك استخدام نطاق مثل `dev-overleaf.com`.

<Steps>
<Step title="إعداد وكيل TLS (Nginx)">
يجب أن يمرّر الوكيل العكسي لـ TLS ترويسة `Host` الأصلية حتى تتمكن Overleaf من تحديد نطاق اللغة الذي وصل إليه المستخدم.

تأكد من وجود التوجيه التالي:

```nginx
proxy_set_header Host $host;
```

فيما يلي مثال على إعداد Nginx:

```nginx
server {
    listen 443 ssl;
    server_name    _; # Catch all, see http://nginx.org/en/docs/http/server_names.html
    server_name *.overleaftest.com;
    ssl_certificate /etc/nginx/ssl/nginx.crt;
    ssl_certificate_key /etc/nginx/ssl/nginx.key;
    ssl_protocols               TLSv1 TLSv1.1 TLSv1.2;
    ssl_prefer_server_ciphers   on;
    # used cloudflares ciphers https://github.com/cloudflare/sslconfig/blob/master/conf
    ssl_ciphers EECDH+CHACHA20:EECDH+AES128:RSA+AES128:EECDH+AES256:RSA+AES256:EECDH+3DES:RSA+3DES:!MD5;

    # config to enable HSTS(HTTP Strict Transport Security) https://developer.mozilla.org/en-US/docs/Security/HTTP_Strict_Transport_Security
    # to avoid ssl stripping https://en.wikipedia.org/wiki/SSL_stripping#SSL_stripping	
    add_header Strict-Transport-Security "max-age=31536000; includeSubdomains;";
    server_tokens off;
    add_header X-Frame-Options SAMEORIGIN;
    add_header X-Content-Type-Options nosniff;
    client_max_body_size 50M;

    location / {
        proxy_pass http://localhost:5000; # change to whatever host/port the docker container is listening on.
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 3m;
        proxy_send_timeout 3m;
        
        # add this to your nginx conf
        proxy_set_header Host $host;
    }
}
```
</Step>

<Step title="إعداد نطاق ملفات تعريف الارتباط">
لمنع تسجيل خروج المستخدمين عند تبديل اللغة، يجب مشاركة ملفات تعريف الارتباط (cookies) عبر النطاقات الفرعية للغات.

أضف السطر التالي إلى `config/variables.env`:

```env title="config/variables.env"
# Note the leading dot
COOKIE_DOMAIN=.overleaftest.com
```

يضمن ذلك أن تكون ملفات تعريف الارتباط الخاصة بالمصادقة صالحة لجميع النطاقات الفرعية ضمن `overleaftest.com`.
</Step>

<Step title="ربط اللغات بالنطاقات">
بعد ذلك، حدّد كيفية ربط رموز اللغات بالنطاقات الفرعية باستخدام\
`OVERLEAF_LANG_DOMAIN_MAPPING`.

#### مثال على الإعداد

```dotenv title="config/variables.env" wrap
OVERLEAF_LANG_DOMAIN_MAPPING='{"www": {"lngCode": "en","url": "https:\/\/www.overleaftest.com"},"cn": {"lngCode": "zh-CN","url": "https:\/\/cn.overleaftest.com"}}'
```

مع هذا الإعداد:

* `https://www.overleaftest.com` ← واجهة باللغة الإنجليزية
* `https://cn.overleaftest.com` ← واجهة باللغة الصينية المبسطة

يمكنك توسيع هذا الربط بلغات ونطاقات فرعية إضافية حسب الحاجة.
</Step>

<Step title="إعادة توجيه النطاق الأساسي">
أخيرًا، أعد توجيه النطاق الأساسي (`overleaftest.com`) إلى نطاق اللغة الافتراضية (`www.overleaftest.com`).

```nginx
server{
    listen 80;
    server_name overleaftest.com;
    return 301 https://www.overleaftest.com$request_uri;
}

server {
    listen 443 ssl http2;
    server_name overleaftest.com;
    ssl_certificate     /path/to/fullchain.cer;
    ssl_certificate_key /path/to/overleaftest.com.key;
    return 301 https://www.overleaftest.com$request_uri;
}
```
</Step>
</Steps>
