توفّر هذه الإمكانية [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) مع دعم OAuth 2.0، وهي متاحة بدءًا من v6.3.0. نرحّب بملاحظاتك إذا واجهت أي مشكلات.

</Info>

#### إعداد التكامل مع Mendeley

1. انتقل إلى [هذا الرابط](https://dev.mendeley.com/myapps.html) لتسجيل تطبيق Mendeley OAuth
2. اضبط **Redirect URL** على: `${OVERLEAF_SITE_URL}/user/mendeley/oauth/callback`
3. دوّن **ID** المُنشأ (يكون عادةً رقميًا مثل `24061` كما في الصورة أدناه) و**Secret** الخاصين بتطبيقك
4. عدّل ملف `config/variables.env` لديك&#x20;
5. أبقِ على Authorisation Flow: Elsevier (كما هو موصى به)

```dotenv title="config/variables.env"
#################
#   Mendeley    #
#################
# 'mendeley' must be in ENABLED_LINKED_FILE_TYPES (keep 'zotero' too if you use both)
ENABLED_LINKED_FILE_TYPES=project_file,project_output_file,url,mendeley

# From a Mendeley OAuth application (register at https://dev.mendeley.com/myapps.html)
# Redirect URL -> ${OVERLEAF_SITE_URL}/user/mendeley/oauth/callback
MENDELEY_CLIENT_ID=
MENDELEY_CLIENT_SECRET=
# Encrypts the Mendeley OAuth tokens in mongo; if unset, a key file is generated
# in /var/lib/overleaf/data on first use
# How to generate: `openssl rand -hex 32`
MENDELEY_CIPHER_PASSWORD=
# Optional: route the module's server-side Mendeley requests (OAuth + API) through
# an HTTP proxy (must be reachable from the web container; same as github-sync)
# http://10.0.0.1:10808
# (Optional) MENDELEY_PROXY_URL=
```

<Info>

&#x20;يجب تضمين `mendeley` في `ENABLED_LINKED_FILE_TYPES` (وأبقِ `zotero` في القائمة أيضًا إذا كنت تستخدم كليهما). تأتي قيمتا `MENDELEY_CLIENT_ID` و`MENDELEY_CLIENT_SECRET` من تطبيق OAuth الذي سجّلته. تُستخدم كلمة مرور التشفير لتشفير رموز Mendeley OAuth في MongoDB (أنشئ واحدة عبر `openssl rand -hex 32`)؛ وبدونها يُنشأ ملف مفتاح في وحدة تخزين البيانات عند أول استخدام. اختياريًا، اضبط `MENDELEY_PROXY_URL` لتوجيه طلبات Mendeley من جهة الخادم (OAuth + API) عبر وكيل HTTP يمكن الوصول إليه من حاوية web.

</Info>

### ملاحظات

<Warning>

عند ترقية تثبيت موجود يحتوي على ملفات مراجع مرتبطة بـ Mendeley إلى الإصدار 6.3.0 المُعاد إصداره، اتبع [تعليمات ترحيل Zotero / Mendeley](/ar/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention"). لا تحتاج التثبيتات الجديدة إلى هذا الترحيل.

</Warning>

<Danger>

نظرًا لأن Ayakaleaf منصة تعاونية، ولتحسين الأمان، بدءًا من الإصدار 6.3.0، لن يُسمح بتحديث الملف المستورد إلا للمنشئ الأصلي لملف المراجع `bib`.

</Danger>

على سبيل المثال، لنفترض أن مالك المشروع، المستخدم A، فعّل المشاركة عبر الرابط وأنشأ ملف `test.bib` في المشروع، وربطه بحساب Zotero الخاص به. إذا وصل مستخدم آخر، المستخدم B، إلى المشروع عبر الرابط المشترك، فسيظل بإمكان المستخدم B قراءة `test.bib` وتنزيله، لكن لن يُسمح له بتحديث الملف أو إعادة استيراده من Zotero. وحده المستخدم A، بصفته المنشئ الأصلي لملف المراجع، يمكنه إجراء التحديثات. وبعبارة أخرى، لا يملك صلاحية تحديث ملف `.bib` إلا منشئه الأصلي.
