كل تكامل معطّل افتراضيًا، باستثناء واجهة استيراد Overleaf البرمجية (Overleaf Import API). تحتاج المزامنة مع GitHub وGitLab وGitea وDropbox وخادم MCP أيضًا إلى [التكامل مع Git](/ar/on-premises/configuration/overleaf-toolkit/integrations/git-integration). بعد تفعيل أحدها، أعد إنشاء الحاويات باستخدام `bin/up -d`.
