### الترويسة

في هذا القسم، سنشرح كيفية تخصيص العناصر الأساسية في نسختك المحلية. يمكنك تخصيص عنوان الموقع وروابط التنقل والترويسة والتذييل والشعار وفقًا لتفضيلاتك.

### عنوان الموقع

يمكن تخصيص عنوان شريط التنقل باستخدام متغير البيئة `OVERLEAF_NAV_TITLE`، ويُستخدم هذا النص في الزاوية العلوية اليسرى من شريط التنقل إذا لم يتم تعيين شعار.

```bash
# add to config/variables.env
OVERLEAF_NAV_TITLE=Our Overleaf Instance
```

## الشعار

يمكنك إضافة شعار مخصص بدلًا من استخدام النص عبر تعيين متغير البيئة `OVERLEAF_HEADER_IMAGE_URL`. يجب أن تشير هذه القيمة إلى ملف صورة مستضاف خارجيًا.

```bash title="config/variables.env"
# add to config/variables.env
OVERLEAF_HEADER_IMAGE_URL=https://mysite.somewhere.com/img/logo.png
```

#### شعارات السمة الفاتحة والداكنة

بدءًا من الإصدار 6.3.0، يمكنك تعيين شعارات منفصلة للسمتين الفاتحة والداكنة باستخدام متغيري البيئة `OVERLEAF_HEADER_IMAGE_URL_LIGHT` و `OVERLEAF_HEADER_IMAGE_URL_DARK`. يجب أن تشير كلتا القيمتين إلى ملف صورة مستضاف خارجيًا.

```text
# add to config/variables.env
OVERLEAF_HEADER_IMAGE_URL_LIGHT=https://mysite.somewhere.com/img/logo-light.png
OVERLEAF_HEADER_IMAGE_URL_DARK=https://mysite.somewhere.com/img/logo-dark.png
```

<Info>

إذا لم يتم تعيين أيٍّ من المتغيرين، فستعود تلك السمة إلى استخدام الشعار المحدد في `OVERLEAF_HEADER_IMAGE_URL`.

</Info>

## روابط التنقل في الترويسة

يمكن إضافة عناصر تنقل إضافية إلى ترويسة التنقل عبر تعيين متغير البيئة `OVERLEAF_HEADER_EXTRAS` إلى مصفوفة JSON من الكائنات. على سبيل المثال:

```json wrap
[\
  {\
    "text": "Some link",\
    "url": "http://example.com/somelink",\
    "class": "subdued",\
    "only_when_logged_out": true\
  },\
  {\
    "text": "Help",\
    "class": "subdued",\
    "dropdown": [\
      {\
        "text": "Documentation",\
        "url": "/learn"\
      },\
      {\
        "text": "Contact Admin",\
        "url": "http://example.com/contact"\
      }\
    ]\
  }\
]
```

أضف صيغة JSON المُهرَّبة إلى toolkit/variables.env:

```bash title="toolkit/variables.env" wrap
# add to toolkit/variables.env
OVERLEAF_HEADER_EXTRAS=[{"text":"Some link","url":"http://example.com/somelink","class":"subdued","only_when_logged_out":true},{"text":"Help","class":"subdued","dropdown":[{"text":"Documentation","url":"/learn"},{"text":"Contact Admin","url":"http://example.com/contact"}]}]
```

## التذييلات

يمكن تخصيص كلٍّ من التذييل الأيسر والتذييل الأيمن الأصغر (الموجودين في صفحات مثل `/project`) باستخدام متغيري البيئة `OVERLEAF_LEFT_FOOTER` و `OVERLEAF_RIGHT_FOOTER`. ويتوقع كلاهما مصفوفة من كائنات JSON سيتم إدراجها.

ويتوقع كلاهما مصفوفة JSON سيتم إدراجها.

```json
[\
  {\
    "text": "This is an example text footer entry!"\
  },\
  {\
    "text": "This is an example URL footer link!", "url" : "/my-first-link.htm"\
  }\
]
```

<Info>

عند استخدام `text` فقط، يجب ألا يحتوي على HTML لأن القيمة ستُعرض كنص خام.

</Info>

يجب أن تكون هذه البيانات JSON صالحًا كي تعمل، مع تهريب علامات الاقتباس عند تمريرها كمتغير بيئة.

```bash title="config/variables.env" wrap
# add to config/variables.env
OVERLEAF_LEFT_FOOTER=[{"text": "This is an example text footer entry!"}]
OVERLEAF_RIGHT_FOOTER=["text": "This is an example URL footer link!", "url" : "/my-first-link.htm"]
```

<Info>

بالإضافة إلى `text` و `url`، يقبل كائن JSON أيضًا الخاصيتين `class` و `label` لمزيد من التخصيص.

</Info>

### صفحة الصيانة

يمكنك تخصيص الرسالة المعروضة في صفحة الصيانة باستخدام متغير البيئة `OVERLEAF_MAINTENANCE_MESSAGE`، ويحل هذا النص محل الرسالة الافتراضية أسفل عنوان الصفحة.

```text wrap
# add to config/variables.env
OVERLEAF_MAINTENANCE_MESSAGE=Our Overleaf Instance is down for maintenance and will be back shortly.
```

لتضمين روابط أو تنسيقات أخرى، استخدم `OVERLEAF_MAINTENANCE_MESSAGE_HTML` بدلًا من ذلك. إذا تم تعيين كليهما، فإن `OVERLEAF_MAINTENANCE_MESSAGE_HTML` تكون له الأولوية.

```text wrap
# add to config/variables.env
OVERLEAF_MAINTENANCE_MESSAGE_HTML=Our Overleaf Instance is down for maintenance. For urgent requests, contact <a href="mailto:admin@example.com">admin@example.com</a>.
```

<Info>

يُعرض `OVERLEAF_MAINTENANCE_MESSAGE` كنص عادي، لذا يجب **ألا** يحتوي على HTML. أما `OVERLEAF_MAINTENANCE_MESSAGE_HTML` فيُعرض كـ HTML دون تهريب.

</Info>

إذا لم يتم تعيين أيٍّ منهما، فإن الرسالة الافتراضية ترتبط بصفحة الحالة الخاصة بك عند تعيين `OVERLEAF_STATUS_PAGE_URL`، وتعرض عنوان البريد الإلكتروني للمسؤول عندما لا يكون معيّنًا.
