Setzen Sie einen Link auf Ihre Website, Ihren Blog oder Ihre Kursseite. Jeder, der darauf klickt, erhält ein eigenes neues Projekt mit Ihren Dateien. Sie müssen nichts einrichten.

Besucher benötigen ein Konto auf Ihrer Instanz. Ein nicht angemeldeter Besucher gelangt zuerst zur Anmeldeseite, und das Projekt öffnet sich nach der Anmeldung.

Die Seiten dieser Funktion verwenden den Namen Overleaf. Ihr eigener Link oder Ihre Schaltfläche kann beliebigen Text tragen, etwa **Open in Ayakaleaf**.

## Beispiele ansehen {#see-the-examples}

Öffnen Sie `/devs` auf Ihrer Website, zum Beispiel `https://ayakaleaf.example.com/devs`. Kein Menü verlinkt auf diese Seite, geben Sie die Adresse also selbst ein. Standardmäßig müssen Sie angemeldet sein, um sie zu sehen.

## Auf eine Datei auf Ihrer Website verlinken {#link-to-a-file-on-your-website}

<Steps>
<Step title="Link erstellen">
Setzen Sie die URL-codierte Adresse der Datei hinter `/docs?snip_uri=`:

```text
https://ayakaleaf.example.com/docs?snip_uri=https%3A%2F%2Fexample.com%2Fmain.tex
```

Für ein gezipptes Projekt verwenden Sie `zip_uri`:

```text
https://ayakaleaf.example.com/docs?zip_uri=https%3A%2F%2Fexample.com%2Fproject.zip
```

Ihre Instanz lädt die Datei herunter, daher muss sie über HTTP oder HTTPS erreichbar sein. Adressen in einem privaten Netzwerk werden abgelehnt, siehe [External URL](/de/on-premises/configuration/overleaf-toolkit/external-url).
</Step>

<Step title="Zur Seite hinzufügen">
```html
<a href="https://ayakaleaf.example.com/docs?snip_uri=https%3A%2F%2Fexample.com%2Fmain.tex">Open in Ayakaleaf</a>
```
</Step>

<Step title="Darauf klicken">
Das neue Projekt öffnet sich im Editor, mit einer einzigen Datei, gespeichert als `main.tex`.

<Frame caption="Ein über einen Link geöffnetes Projekt">
  <img src="/images/on-premises/open-in-overleaf-project.png" alt="Das Projekt Hello from a link im Editor, mit main.tex und seinem PDF" />
</Frame>

Jeder Klick erstellt ein weiteres Projekt. Das Projekt ist eine Kopie, spätere Änderungen an Ihrer Datei erreichen es also nicht.
</Step>
</Steps>

## Die Datei in den Link packen {#put-the-file-in-the-link}

Für eine kleine Datei müssen Sie nichts hosten: Packen Sie ihren Inhalt als Base64-Data-URL in den Link. In JavaScript:

```javascript
const tex = '\\documentclass{article}\n\\begin{document}\nHello from a link.\n\\end{document}\n'
const link = 'https://ayakaleaf.example.com/docs?' + new URLSearchParams({
  snip_uri: 'data:application/x-tex;base64,' + btoa(tex),
  name: 'Hello from a link',
})
```

`btoa` akzeptiert nur Latin-1-Zeichen, codieren Sie anderen Text also zuerst als UTF-8. Für ein gezipptes Projekt verwenden Sie `zip_uri` und `data:application/zip;base64,`.

Ein Link, der länger als etwa 8 KB ist, wird mit dem Fehler **414 Request-URI Too Large** abgelehnt. Für alles Größere hosten Sie die Datei oder verwenden Sie ein [Formular](#use-a-button-instead-of-a-link).

## Optionen wählen {#choose-the-options}

Fügen Sie diese dem Link hinzu oder dem Formular als versteckte Felder:

| Parameter                   | Was er bewirkt                                                                                                                 | Beispiel                                            |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| `name`                      | Benennt das Projekt. Ohne ihn übernimmt ein gezipptes Projekt den Namen aus seinem `\title`, alles andere heißt `Open in Overleaf project`. | `name=My%20notes`                                  |
| `engine`                    | Legt den Compiler fest: `latex_dvipdf`, `pdflatex`, `xelatex` oder `lualatex`.                                                      | `engine=xelatex`                                   |
| `main_document`             | Legt die Haupt-`.tex`-Datei fest, die zuerst geöffnet wird.                                                                                | `main_document=thesis.tex`                         |
| `snip_uri[]`, `snip_name[]` | Importiert mehrere Dateien, jede mit eigenem Namen, in derselben Reihenfolge.                                                            | `snip_uri[]=.../a.tex&snip_name[]=a.tex`           |

Eine `.tex`-Datei ohne `\documentclass` wird in ein Standarddokument eingebettet, sodass sie sofort kompiliert:

```latex
\documentclass[12pt]{article}
\usepackage[english]{babel}
\usepackage{amsmath}
\usepackage{tikz}
\begin{document}
Your file
\end{document}
```

## Eine Schaltfläche statt eines Links verwenden {#use-a-button-instead-of-a-link}

Ein Formular sendet dieselben Parameter wie ein Link:

```html
<form action="https://ayakaleaf.example.com/docs" method="post" target="_blank">
  <input type="hidden" name="snip_uri" value="https://example.com/main.tex">
  <input type="hidden" name="engine" value="xelatex">
  <button type="submit">Open in Ayakaleaf</button>
</form>
```

Um das LaTeX selbst zu senden, verwenden Sie `snip` für reinen Text oder `encoded_snip` für Text, der durch `encodeURIComponent` gelaufen ist.

Ein Formular funktioniert nicht immer, deshalb ist ein Link die bessere Wahl, es sei denn, Ihre Datei ist zu lang dafür:

| Wo sich das Formular befindet                                     | Besucher ist angemeldet            | Besucher ist nicht angemeldet        |
| ----------------------------------------------------- | ------------------------------- | ------------------------------- |
| Auf derselben Domain wie Ihre Instanz oder einer Subdomain   | Das Projekt öffnet sich               | Anmeldeseite, kein Projekt      |
| Auf einer anderen Domain                                     | Anmeldeseite, kein Projekt      | Anmeldeseite, kein Projekt      |

Wenn Ihr Administrator `OVERLEAF_ALLOW_PUBLIC_ACCESS=true` setzt, öffnet sich das Projekt in all diesen Fällen, bei Bedarf nach der Anmeldung. Diese Einstellung öffnet auch andere Seiten für abgemeldete Besucher, siehe [Page Access](/de/on-premises/configuration/overleaf-toolkit/authentication/public-access#page-access).

Was Administratoren sonst noch einstellen können, finden Sie unter [Overleaf Import API](/de/on-premises/configuration/overleaf-toolkit/integrations/overleaf-import-api). Die Seite `/devs` enthält weitere Beispiele.

## Wenn sich das Projekt nicht öffnet {#if-the-project-does-not-open}

Die Seite sagt, was schiefgelaufen ist. **View the Overleaf API docs** führt Sie zu `/devs`.

<Frame caption="Ein Link, den die Instanz nicht verwenden kann">
  <img src="/images/on-premises/open-in-overleaf-error.png" alt="Die Seite Open in Overleaf mit der Meldung invalid url und der Schaltfläche View the Overleaf API docs" />
</Frame>

| Meldung                                      | Warum                                                 | Was zu tun ist                                  |
| -------------------------------------------- | --------------------------------------------------- | ------------------------------------------- |
| `no snippet, snip_uri or zip_uri provided`   | Der Link enthält keinen dieser Parameter                          | Parameternamen prüfen                   |
| `invalid url: ...`                           | Die Adresse beginnt nicht mit HTTP oder HTTPS       | Eine HTTP- oder HTTPS-Adresse oder eine Data-URL verwenden |
| `could not download ... (HTTP 404)`          | Unter dieser Adresse liegt die Datei nicht                     | Adresse prüfen                           |
| `could not download ... (HTTP 403)`          | Die Adresse liegt in einem privaten Netzwerk                 | Die Datei dort hosten, wo Ihre Instanz sie erreichen darf |
| `zip_uri did not resolve to a zip archive`   | Die Datei hinter `zip_uri` ist keine ZIP-Datei         | Datei prüfen                              |
| `invalid base64 data url`                    | Die Data-URL ist beschädigt                             | Datei neu codieren und den Link URL-codieren |
