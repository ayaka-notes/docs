## Ein Projekt finden {#find-a-project}

Tippen Sie in **Search by project name, ID, owner or link**. Ein Link kann die Adresse des Projekts oder einer seiner Freigabelinks sein. Verwenden Sie den Filter **Status**, um die Liste einzugrenzen. Klicken Sie zum Sortieren auf **Title** oder **Last modified**.

Gelöschte Projekte erscheinen nicht in den Ergebnissen. Wenn Ihre Suche auch auf ein gelöschtes Projekt passt, weist eine Zeile über der Tabelle darauf hin, zum Beispiel **Found 1 matching deleted projects**. Klicken Sie auf **Display deleted projects**, um sie anzuzeigen.

## Projektstatus {#project-status}

Jedes Projekt hat einen Status, und der Filter **Status** zeigt, wie viele Projekte jeder Status hat.

<Frame caption="Der Filter Status">
  <img src="/images/on-premises/project-management-status-filter.png" alt="Der Filter Status mit All, Active, Archived, Trashed und Deleted" />
</Frame>

| Status | Bedeutung |
| --- | --- |
| **All** | Jedes Projekt, das nicht gelöscht ist. |
| **Active** | Der normale Zustand. |
| **Archived** | Der Eigentümer hat es archiviert. Das Projekt ist unverändert und kann zurückgeholt werden. |
| **Trashed** | Der Eigentümer hat es in den Papierkorb verschoben. Das Projekt ist unverändert und kann zurückgeholt werden. |
| **Deleted** | Vom Eigentümer aus dem Papierkorb gelöscht, von einem Administrator gelöscht oder zusammen mit dem Konto des Eigentümers gelöscht. Nur ein Administrator kann es zurückholen. |

Ein Projekt durchläuft die Status in Stufen:

1. **Active, Archived und Trashed** wählt der Eigentümer auf seiner eigenen Projektseite. Der Eigentümer kann jederzeit zurückwechseln. **Restore** aus dem Papierkorb führt immer zu Active, auch wenn das Projekt vorher archiviert war.
2. **Deleted** ist die nächste Stufe. Der Eigentümer kann nur aus dem Papierkorb löschen; ein Administrator kann aus jedem der drei Status löschen.
3. **Restore** holt ein gelöschtes Projekt unabhängig von seinem vorherigen Status als **Active** zurück, und sein Name erhält am Ende `(Restored)`. Nur ein Administrator kann das tun. Wenn auch das Konto des Eigentümers gelöscht ist, stellen Sie zuerst das Konto wieder her: Andernfalls meldet der Dialog **The owner of this project is deleted: restore the owner first**.
4. **Delete permanently** ist die letzte Stufe und kann nicht rückgängig gemacht werden. Ansonsten bleiben gelöschte Projekte erhalten, bis Sie sie entfernen, es sei denn, die Instanz setzt [`ENABLE_CRON_RESOURCE_DELETION`](/de/on-premises/configuration/overleaf-toolkit/environment-variables), wodurch sie nach 90 Tagen entfernt werden.

<Info>

Der Status richtet sich nur nach dem Eigentümer. Wenn ein Mitarbeiter ein geteiltes Projekt archiviert oder in den Papierkorb verschiebt, ändert sich das nur auf seiner eigenen Projektseite, und der Status hier bleibt gleich.

</Info>

## Aktionen für ein Projekt {#actions-on-a-project}

| Symbol | Aktion | Wirkung |
| --- | --- | --- |
| Öffnen | **Open Project** | Öffnet das Projekt im Editor in einem neuen Tab. |
| Ordner | **Change project owner** | Übergibt das Projekt an einen anderen Benutzer. |
| Papierkorb | **Delete** | Verschiebt das Projekt nach **Deleted**. |
| Pfeil | **Restore** | Holt ein gelöschtes Projekt zurück. Nur für gelöschte Projekte. |
| Durchgestrichener Papierkorb | **Delete permanently** | Entfernt ein gelöschtes Projekt endgültig. Nur für gelöschte Projekte. |

### Den Eigentümer ändern {#change-the-owner}

Klicken Sie auf das Ordnersymbol, geben Sie einen Namen oder eine E-Mail-Adresse ein, wählen Sie den Benutzer aus und klicken Sie dann auf **Change project owner**. Der Dialog warnt, dass dies nicht rückgängig gemacht werden kann und dass der neue Eigentümer benachrichtigt wird und die Zugriffseinstellungen des Projekts ändern kann. Deaktivierte Konten werden nicht angeboten. Wenn Sie den Text nach der Auswahl ändern, wird die Auswahl aufgehoben: Wählen Sie den Benutzer erneut aus.

<Frame caption="Den Eigentümer eines Projekts ändern">
  <img src="/images/on-premises/project-management-change-owner.png" alt="Der Dialog Change project owner mit einer Warnung und einem ausgewählten neuen Eigentümer" />
</Frame>

Wie Sie alle Projekte eines Benutzers auf einmal verschieben, lesen Sie unter [Die Projekte eines Benutzers übertragen](/de/on-premises/user-guide/administrators/user-management#transfer-a-users-projects).

### Löschen, wiederherstellen oder endgültig löschen {#delete-restore-or-permanently-delete}

Klicken Sie auf das Papierkorbsymbol und dann auf **Delete**. Um das Projekt wiederzufinden, wählen Sie im Filter **Status** die Option **Deleted**.

<Frame caption="Ein gelöschtes Projekt">
  <img src="/images/on-premises/project-management-deleted.png" alt="Ein gelöschtes Projekt in der Liste mit den Symbolen Restore und Delete permanently" />
</Frame>

Klicken Sie auf das Pfeilsymbol und dann auf **Restore**, um es zurückzuholen, oder auf den durchgestrichenen Papierkorb und dann auf **Delete permanently**, um es zu entfernen.

<Frame caption="Ein Projekt endgültig löschen">
  <img src="/images/on-premises/project-management-purge.png" alt="Der Dialog Delete permanently mit der Warnung, dass die Aktion nicht rückgängig gemacht werden kann" />
</Frame>

### Mehrere Projekte auf einmal ändern {#change-several-projects-at-once}

Markieren Sie die Projekte in der Liste. Neben der Suche erscheinen Schaltflächen: **Download**, **Change project owner** und **Delete**. **Download** speichert die ausgewählten Projekte in einer `.zip`-Datei. Bei **Change project owner** können die aktuellen Eigentümer der markierten Projekte nicht ausgewählt werden. In der Ansicht **Deleted** lauten die Schaltflächen **Restore** und **Delete permanently**.

<Frame caption="Massenaktionen">
  <img src="/images/on-premises/project-management-bulk.png" alt="Zwei markierte Projekte und die Schaltflächen Download, Change project owner und Delete" />
</Frame>

## Die Projektseite {#the-project-page}

Klicken Sie auf den Titel eines Projekts, um seine Seite zu öffnen. Oben befinden sich die Symbole zum Bearbeiten, Öffnen, Herunterladen und Löschen des Projekts. Die Seite hat fünf Tabs.

### Übersicht {#overview}

Die Details und Einstellungen des Projekts. Klicken Sie auf das Stiftsymbol, um **Name**, **Link sharing**, **Compiler**, **TeX Live version** und **Main document** zu ändern oder auf **Change project owner** zu klicken. Klicken Sie dann auf **Save**.

<Frame caption="Ein Projekt bearbeiten">
  <img src="/images/on-premises/project-management-edit.png" alt="Der Tab Overview im Bearbeitungsmodus" />
</Frame>

### Dateibaum {#file-tree}

Die Dateien und Ordner des Projekts, schreibgeschützt.

<Frame caption="Die Dateien eines Projekts">
  <img src="/images/on-premises/project-management-files.png" alt="Der Tab File tree mit frog.jpg, main.tex und einer wiederhergestellten bib-Datei" />
</Frame>

### Mitglieder {#members}

Wer Zugriff hat: der Eigentümer, die Mitarbeiter und die ausstehenden Einladungen. Klicken Sie auf das Stiftsymbol, um sie zu ändern:

* Wählen Sie **Editor**, **Reviewer** oder **Viewer** für einen Mitarbeiter. Die Änderung gilt sofort.
* Klicken Sie neben einem Mitarbeiter auf den Papierkorb und dann auf **Remove access**.
* Klicken Sie bei einer ausstehenden Einladung auf den Umschlag für **Resend invite** oder auf den Papierkorb für **Revoke Invite**.

Klicken Sie auf **Done**, wenn Sie fertig sind. Der Eigentümer kann hier nicht geändert werden: Verwenden Sie **Change project owner** auf dem Tab **Overview**.

<Frame caption="Die Mitglieder eines Projekts ändern">
  <img src="/images/on-premises/project-management-members.png" alt="Der Tab Members im Bearbeitungsmodus mit einem Rollenmenü, einer ausstehenden Einladung und den Aktionssymbolen" />
</Frame>

### Gelöschte Dateien {#deleted-files}

Aus dem Projekt entfernte Dateien. Klicken Sie neben einer Datei auf das Pfeilsymbol und dann auf **Restore file**. Eine Kopie mit dem Datum im Namen wird im Stammordner des Projekts abgelegt, und die Zeile zeigt ihren Namen. Die gelöschte Datei bleibt in der Liste.

Die Kopie erscheint auf dem Tab **File tree**, nachdem Sie die Seite neu geladen haben.

<Frame caption="Eine wiederhergestellte Datei">
  <img src="/images/on-premises/project-management-deleted-files.png" alt="Der Tab Deleted files mit sample.bib und dem Namen seiner wiederhergestellten Kopie" />
</Frame>

### Audit-Protokolle {#audit-logs}

Was mit diesem Projekt passiert ist: das Datum, der Vorgang, wer ihn ausgeführt hat, die IP-Adresse und Details. Durchsuchen Sie sie oder filtern Sie nach **Operation**.
