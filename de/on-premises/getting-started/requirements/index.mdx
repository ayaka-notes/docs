### Anforderungen für die Installation von Server Pro und Community Edition

<Warning>

Wir empfehlen dringend, Server Pro auf einer aktuellen und stabilen Ubuntu-Version (z. B. Ubuntu 24.04 in 2025–2026) mit einer aktuellen Docker-Version zu betreiben. Der Betrieb von Server Pro auf anderen Systemen ist möglich, erschwert es uns jedoch erheblich, Support für nicht standardmäßige Ubuntu/Docker-Setups zu leisten. Zudem können wir keinen Support für Probleme mit Docker selbst anbieten.

</Warning>
