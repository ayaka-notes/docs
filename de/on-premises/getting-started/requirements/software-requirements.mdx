### Betriebssysteme {#operating-systems}

Für gemeinsam genutzte und produktive Server empfehlen wir ein **Debian-basiertes Linux**-System wie **Ubuntu**. Ayakaleaf Pro läuft auch unter [macOS mit Docker Desktop](/de/on-premises/installation/using-docker-compose/macos) und [Windows mit WSL 2 und Docker Desktop](/de/on-premises/installation/using-docker-compose/windows). Alle drei Plattformen verwenden Linux-Container und dasselbe Toolkit; folgen Sie der Anleitung für das Betriebssystem Ihres Hosts.

<Danger>

Bei der Verwendung von Sandboxed Compiles ist **wichtig** zu beachten, dass die Anwendung Root-Zugriff auf den Docker-Socket benötigt.

</Danger>

### Abhängigkeiten {#dependencies}

* Docker 25.0 und 29
* MongoDB 7.0 und 8.0
* Redis 6.2 und 7.5

<Info>

Die End-of-Life-Termine (EOL) für die oben genannten Abhängigkeiten und andere verbreitete Produkte können Sie über den Dienst endoflife.date verfolgen: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

MongoDB und Redis werden beim Ausführen von Ayakaleaf Pro automatisch von `docker compose` heruntergeladen, sofern nicht eine andere Installation konfiguriert ist.

</Info>

Das Toolkit benötigt die folgenden Programme:

* bash
* Docker

`docker compose` ist erforderlich und wird in der Regel zusammen mit Docker installiert.

Wir empfehlen, die neueste für Ihr Betriebssystem verfügbare Docker-Version zu installieren.

Sobald Docker korrekt installiert ist, sollten Sie diese Befehle fehlerfrei ausführen können:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2 or later, such as v5)
docker compose version

# List the running Docker containers on your system
docker ps
```
