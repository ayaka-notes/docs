### Betriebssysteme

Für den bestmöglichen Betrieb von Overleaf empfehlen wir dringend ein **Debian-basiertes** Betriebssystem wie **Ubuntu**. Diese Wahl entspricht der Entwicklungsumgebung der Software und wird von der Mehrheit der Overleaf-Nutzer bevorzugt.

<Danger>

Bei Verwendung von Server Pro mit Sandboxed Compiles ist **unbedingt** zu beachten, dass die Anwendung Root-Zugriff auf den Docker-Socket benötigt.

</Danger>

### Abhängigkeiten

* Docker 25.0 und 29
* MongoDB 7.0 und 8.0
* Redis 6.2 und 7.5

<Info>

Die End-of-Life-Daten (EOL) der oben genannten Abhängigkeiten und anderer verbreiteter Produkte können Sie über den Dienst endoflife.date verfolgen: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

MongoDB und Redis werden beim Betrieb von Server CE oder Server Pro automatisch von `docker compose` heruntergeladen, sofern keine andere Installation konfiguriert ist.

</Info>

Das Toolkit benötigt die folgenden Programme:

* bash
* Docker

`docker compose` ist erforderlich und wird in der Regel zusammen mit Docker installiert.

Wir empfehlen, die neueste für Ihr Betriebssystem verfügbare Docker-Version zu installieren.

Sobald Docker korrekt installiert ist, sollten Sie die folgenden Befehle ohne Fehler ausführen können:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2)
docker compose version

# List the running Docker containers on your system
docker ps
```
