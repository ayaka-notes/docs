### Konto

Bei der Verwaltung des eigenen Kontos werden **alle** Benutzer als reguläre Benutzer behandelt – `Site Admins` und `Template Users` erhalten **keine** zusätzlichen Berechtigungen. Es gibt jedoch Einschränkungen, welche Aktionen reguläre Benutzer je nach Authentifizierungsart ausführen können.

#### Einstellungen

**Authentifizierungsarten: Interne Konten | SSO (SAML/LDAP)**

| Aktion | Interne Konten | SSO (SAML/LDAP) |
| ----------------------------------------- | ----------------: | --------------: |
| Kontoinformationen aktualisieren | Ja | Nein |
| Passwort ändern | Ja | Nein |
| Git-Bridge-Authentifizierungstokens generieren | Ja | Ja |
| Git-Bridge-Authentifizierungstokens löschen | Ja | Ja |
| Sitzungen verwalten | Ja | Ja |

<Info>

Die Git-Bridge-Integration ist **nur** in Server Pro verfügbar. Weitere Informationen finden Sie unter [Server Pro vs. Community Edition](/de/on-premises/readme/ayakaleaf-pro-vs-server-pro).

</Info>

#### Ihre Sitzungen

| Aktion | Benutzer |
| -------------------- | ---: |
| Sitzungen löschen | Ja |
| Aktuelle Sitzung anzeigen | Ja |
| Andere Sitzungen anzeigen | Ja |

### Editor-IDE

In der Overleaf-Editor-IDE können Sie eine der folgenden Rollen haben: `Project Owner`, `Editor`, `Reviewer`, `Viewer`, `Site Administrator` oder `Template User`.

<Info>

Server Pro und die Community Edition unterstützen anonymen **Nur-Lese**- und **Lese-/Schreib**-Zugriff auf Projekte.

Weitere Informationen dazu finden Sie [hier](/de/on-premises/configuration/overleaf-toolkit/environment-variables) bei den Umgebungsvariablen `OVERLEAF_ALLOW_PUBLIC_ACCESS` und `OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING`.

</Info>
