title: Projektlimits
icon: list-check
---

| Funktion                                          | Limit                                                                                                                                                                   |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Kompilier-Timeout                                  | **Standard:** 180 Sekunden. Weitere Informationen zum Anpassen dieses Werts finden Sie unter [Kompilier-Timeout für Projekte aktualisieren](/de/on-premises/user-and-project-management/project-management). |
| Maximale Anzahl an Dateien pro Projekt              | 2000                                                                                                                                                                    |
| Maximale Größe des bearbeitbaren Materials pro Projekt    | **Standard:** 7 MB. Weitere Informationen zum Anpassen dieses Werts finden Sie unter [Umgebungsvariablen](/de/on-premises/configuration/overleaf-toolkit/environment-variables).           |
| Maximale Größe einer einzelnen bearbeitbaren Textdatei | 2 MB\*                                                                                                                                                                  |
| Maximale Größe eines einzelnen Uploads             | 50 MB (konfigurierbar über `MAX_UPLOAD_SIZE`)                                                                                                                              |
| Maximale unkomprimierte Größe einer hochgeladenen .zip-Datei    | 6 × `MAX_UPLOAD_SIZE` (standardmäßig 300 MB)                                                                                                                               |
| Maximale Projektgröße                          | Unbegrenzt†                                                                                                                                                              |
| Maximale Anzahl an Projekten                       | Unbegrenzt                                                                                                                                                               |

\* Einige größere Dateien können unter bestimmten Umständen bearbeitbar bleiben. Um jedoch sicherzustellen, dass eine Datei bearbeitbar bleibt, sollten Sie ihre Größe auf höchstens 2 MB begrenzen.

† Für die Gesamtgröße eines Projekts gibt es kein erzwungenes Limit. Bei sehr großen Projekten können Sie jedoch auf technische Einschränkungen stoßen. Wir empfehlen eine maximale Projektgröße von 500 MB bzw. weniger als 100 MB, wenn Sie unsere [Git-Integration](https://www.overleaf.com/learn/how-to/Git_integration) verwenden. Größere Projekte können funktionieren, aber innerhalb dieser Grenzen erzielen Sie die besten Ergebnisse.
