---
title: Projektlimits
icon: list-check
---

| Funktion                                          | Limit                                                                                                                                                                   |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Kompilierungs-Timeout                                  | <strong>Standard:</strong> 180 Sekunden. Weitere Informationen zum Anpassen dieses Wertes finden Sie unter [Kompilierungs-Timeout für Projekte aktualisieren](/de/on-premises/user-and-project-management/project-management). |
| Maximale Anzahl an Dateien pro Projekt              | 2000                                                                                                                                                                    |
| Maximale Größe des bearbeitbaren Materials pro Projekt    | <strong>Standard:</strong> 7 MB. Weitere Informationen zum Anpassen dieses Wertes finden Sie unter [Umgebungsvariablen](/de/on-premises/configuration/overleaf-toolkit/environment-variables).           |
| Maximale Größe einer einzelnen bearbeitbaren Textdatei | 2 MB\*                                                                                                                                                                  |
| Maximale Größe eines einzelnen Uploads             | 50 MB (konfigurierbar über `MAX_UPLOAD_SIZE`)                                                                                                                              |
| Maximale unkomprimierte Größe einer hochgeladenen .zip-Datei    | 6 × `MAX_UPLOAD_SIZE` (standardmäßig 300 MB)                                                                                                                               |
| Maximale Projektgröße                          | Unbegrenzt†                                                                                                                                                              |
| Maximale Anzahl an Projekten                       | Unbegrenzt                                                                                                                                                               |

\* Einige größere Dateien können unter bestimmten Umständen bearbeitbar bleiben. Um jedoch sicherzustellen, dass eine Datei bearbeitbar bleibt, sollten Sie ihre Größe auf höchstens 2 MB begrenzen.

† Es gibt keine erzwungene Begrenzung der gesamten Projektgröße. Bei sehr großen Projekten können jedoch technische Einschränkungen auftreten. Wir empfehlen eine maximale Projektgröße von 500 MB bzw. weniger als 100 MB, wenn Sie unsere [Git-Integration](https://www.overleaf.com/learn/how-to/Git_integration) verwenden. Projekte oberhalb dieser Größen können funktionieren, aber wenn Sie innerhalb dieser Grenzen bleiben, erzielen Sie die beste Erfahrung.
