Am einfachsten testen Sie Ayakaleaf Pro mit GitHub Codespace: Dort sind alle Umgebungsvariablen vorkonfiguriert, sodass Sie es sofort nutzen können.

<Warning>

Wenn Sie Docker-Container in GitHub Codespaces ausführen, wird der Codespace nicht automatisch heruntergefahren und weiterhin **abgerechnet**. Die Abrechnungsregeln für GitHub Codespaces finden Sie unter [GitHub-Codespaces-Abrechnungsregeln](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces).

Um Ihre GitHub Codespaces zu verwalten, besuchen Sie [https://github.com/codespaces](https://github.com/codespaces). Wenn Sie Ihren Codespace nicht mehr benötigen, löschen Sie ihn bitte rechtzeitig.

</Warning>

Folgende Funktionen haben wir **vorkonfiguriert**:

* [x] Sandbox-LaTeX-Kompilierung mit TeX Live **Basic** (2024–2026)
* [x] Pandoc-Import/-Export (Funktion der SaaS-Plattform)
* [x] Python-Skriptausführung (Funktion der SaaS-Plattform)
* [x] Git-Bridge-Unterstützung (Funktion von Server Pro)
* [x] Erweiterte Literatursuche (Funktion der SaaS-Plattform)
* [x] Admin-Panel (globale Verwaltung von Benutzern/Projekten)
* [x] Änderungsverfolgung (mit Review- und Kommentar-Panel)
* [x] Vollständiger Projektverlauf (mit Wiederherstellen und Herunterladen)
* [x] Symbolpalette (Funktion von Server Pro/SaaS-Plattform)

<Warning>

Standardmäßige GitHub Codespaces bieten 32 GB Speicherplatz. Das reicht für unsere `texlive-full`-Installation nicht aus. Um das vollständige Image zu testen, reichen Sie ein GitHub-Support-Ticket für einen Codespace mit großen Runnern (8+ Kerne) ein.

</Warning>

GitHub Sync, LDAP, OAuth, SSO, die Zotero-Integration und weitere Funktionen sind in diesem Playground _**nicht konfiguriert**_. Weitere Details zur Konfiguration dieser Funktionen in Ihrem eigenen Deployment finden Sie in den [Toolkit-Einstellungen](/de/on-premises/configuration/overleaf-toolkit/toolkit-settings).

Klicken Sie auf die folgende Schaltfläche, um Ihren GitHub Codespace zu erstellen. Was die Serverkonfiguration betrifft, reichen **2 Kerne mit 8 GB RAM** für einen Test in der Regel aus. ```

#### TeX Live Full Image verwenden

Wenn Sie Zugriff auf GitHub Codespaces mit 8 Kernen/64 GB haben, können Sie in diesem Playground das TeX Live Full Image verwenden. Ändern Sie dazu die folgenden Umgebungsvariablen in der Datei `toolkit/config/variables.env`, um das TeX Live Full Image anstelle des TeX Live Basic Image zu verwenden.

```dotenv wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1, ghcr.io/ayaka-notes/texlive-full:2024.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025, Texlive 2024
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```

Nach dem Ändern der Umgebungsvariablen müssen Sie das Toolkit neu starten, damit die Änderungen wirksam werden. Führen Sie dazu den folgenden Befehl aus.

```bash
cd toolkit && bin/up -d
```
