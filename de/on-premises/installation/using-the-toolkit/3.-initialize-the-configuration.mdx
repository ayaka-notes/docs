### Initialisieren der Konfiguration

Initialisieren wir die Konfigurationsdateien unseres neuen Servers mit sinnvollen Standardwerten, indem wir das mitgelieferte Skript `bin/init` ausführen.

```text title="Run initialization"
bin/init
```

Dieses Skript überschreibt **keine** vorhandenen Konfigurationsdateien.

Prüfen wir nun mit dem Befehl `ls` den Inhalt des Verzeichnisses `config/`:

```text title="List the config directory"
ls config
```

Wenn alles erfolgreich initialisiert wurde, sollten Sie drei Konfigurationsdateien sehen: `overleaf.rc`, `variables.env` und `version`. Dies sind die wichtigsten Serverkonfigurationsdateien, mit denen Sie anpassen können, wie Ihr Server arbeitet und wie Ihre Benutzer mit Ihrer Instanz interagieren.

| Name            | Beschreibung                                            |
| --------------- | ------------------------------------------------------- |
| `overleaf.rc`   | Die zentrale Konfigurationsdatei der obersten Ebene.    |
| `variables.env` | Umgebungsvariablen, die in den Docker-Container geladen werden. |
| `version`       | Die Version des zu verwendenden Docker-Images.          |

<Info>

Vorerst genügt es zu wissen, dass diese Dateien existieren und wo Sie sie finden. Später in der Dokumentation gehen wir jede Datei im Detail durch und erklären, wie Sie Ihre Instanz damit anpassen können. Wenn Sie vorspringen möchten, finden Sie eine vollständige Aufschlüsselung dieser Konfigurationsdateien auf der Seite [Dateien und Speicherorte](/de/on-premises/configuration/overleaf-toolkit/files-and-locations).

</Info>
