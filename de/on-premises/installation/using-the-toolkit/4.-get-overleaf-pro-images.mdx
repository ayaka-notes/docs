title: 4. Ayakaleaf Pro-Images beziehen
icon: split
---

Ayakaleaf Pro ist ein kostenloses Docker-Image in der [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Zum Pullen benötigen Sie weder ein Konto noch eine Anmeldung. Die Images werden für amd64 und arm64 gebaut, und Docker wählt automatisch das passende für Ihren Server aus.

Öffnen Sie `config/overleaf.rc` und setzen Sie:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

Beim nächsten Ausführen von `bin/up` lädt das Toolkit das Ayakaleaf Pro-Image herunter und verwendet es anstelle der offiziellen Overleaf Community Edition. Ihre Einstellungen in `config/` funktionieren weiterhin.

<Accordion title="Sie verwenden bereits das offizielle Overleaf Toolkit (overleaf/toolkit)?">

Sie müssen nichts neu installieren. Pullen Sie das Ayakaleaf Pro-Image:

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Fügen Sie anschließend im Verzeichnis `overleaf-toolkit/config` eine Datei namens `docker-compose.override.yml` mit folgendem Inhalt hinzu:

```yml
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

Beim nächsten Ausführen von `bin/up` verwendet das Toolkit das Ayakaleaf Pro-Image.

</Accordion>
