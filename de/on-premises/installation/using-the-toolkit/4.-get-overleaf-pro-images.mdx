---
title: 4. Ayakaleaf Pro-Images beziehen
icon: split
---

Ayakaleaf Pro wird als Docker-Image über die [ghcr](https://github.com/ayaka-notes/overleaf-pro/pkgs/container/overleaf-pro/)-Registry verteilt und ist für alle **frei zugänglich**. Wir stellen Images für die Architekturen amd64 und arm64 bereit. Beim Pullen des Images wird automatisch das passende Image für Ihre Systemarchitektur ausgewählt.

#### Nutzer des Ayaka-notes Toolkit

Wenn Sie [ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) verwenden, kann Ayakaleaf Pro als direkter Ersatz für die Community Edition eingesetzt werden, sodass Sie Ihre bestehenden Einstellungen und Anpassungen weiter verwenden können. Aktivieren Sie Pro im Toolkit, indem Sie `config/overleaf.rc` bearbeiten und die Umgebungsvariable `SERVER_PRO` setzen:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

Beim nächsten Ausführen von `bin/up` lädt das Toolkit automatisch das Ayakaleaf Pro-Image herunter und verwendet es.

#### Nutzer des offiziellen Toolkit

Wenn Sie [overleaf/toolkit](https://github.com/overleaf/toolkit) verwenden, führen Sie den folgenden Befehl aus, um ein Pro-Image zu pullen:

```bash title="Pull Docker Images"
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Legen Sie anschließend im Verzeichnis `overleaf-toolkit/config` eine Datei namens `docker-compose.override.yml` mit folgendem Inhalt an:

```yml title="docker-compose.override.yml"
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

Beim nächsten Ausführen von `bin/up` lädt das Toolkit automatisch das Ayakaleaf Pro-Image herunter und verwendet es.
