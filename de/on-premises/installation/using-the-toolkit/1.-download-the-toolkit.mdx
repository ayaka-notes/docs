### Toolkit herunterladen

Sie installieren Ayakaleaf Pro mit dem **Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)), einer Sammlung von Skripten, die Overleaf für Sie in Docker ausführt.

Standardmäßig startet das Toolkit die kostenlose offizielle Overleaf Community Edition (CE). [4. Ayakaleaf Pro-Images beziehen](/de/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images) stellt es mit einer einzigen Einstellung auf Ayakaleaf Pro um.

<Accordion title="Sie verwenden bereits das offizielle Overleaf Toolkit (overleaf/toolkit)?">

Sie müssen nichts neu installieren. Behalten Sie Ihre Installation bei und folgen Sie dem letzten Teil von [4. Ayakaleaf Pro-Images beziehen](/de/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images).

</Accordion>

<Steps>
<Step title="Ayakaleaf Toolkit-Repository klonen">
Um das Toolkit zu installieren, wechseln Sie in den gewünschten Installationspfad und klonen anschließend das Repository des Ayakaleaf Toolkit mit diesem Befehl:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
```

<Info>

Um mögliche Berechtigungsprobleme zu vermeiden, empfehlen wir, das Toolkit im `$HOME`-Verzeichnis Ihres Benutzers zu installieren.

</Info>
</Step>

<Step title="In das Toolkit-Verzeichnis wechseln">
Warten Sie, bis der Klonvorgang abgeschlossen ist, und wechseln Sie dann in das neu erstellte Verzeichnis `overleaf-toolkit`:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
