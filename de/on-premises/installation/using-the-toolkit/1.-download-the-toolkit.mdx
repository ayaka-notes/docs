### Das Toolkit herunterladen

Das Toolkit ist sowohl mit Server CE als auch mit Ayakaleaf Pro kompatibel und ist die empfohlene Installationsmethode. Mit dem Toolkit können Sie ganz einfach mit Server CE starten und bei Bedarf nahtlos auf Ayakaleaf Pro upgraden.

<Info>

[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) wurde so angepasst, dass es das overleaf-pro-Image direkt von ghcr verwendet, wobei TeX Live von ayaka-notes bereitgestellt wird. Alternativ können Sie das offizielle overleaf-toolkit herunterladen.

</Info>

<Steps>
<Step title="Das Overleaf-Toolkit-Repository klonen">
Um das Toolkit zu installieren, wechseln Sie in den gewünschten Installationspfad und klonen dann das GitHub-Repository des Overleaf Toolkit (@Ayaka-notes) mit diesem Befehl:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
# official toolkit (Not Recommended)
# git clone https://github.com/overleaf/toolkit.git ./overleaf-toolkit
```

<Info>

Um mögliche Berechtigungsprobleme zu vermeiden, empfehlen wir, das Toolkit im `$HOME`-Verzeichnis Ihres Benutzers zu installieren.

</Info>
</Step>

<Step title="In das Toolkit-Verzeichnis wechseln">
Warten Sie, bis der Klonvorgang abgeschlossen ist, und wechseln Sie dann in das neu erstellte Verzeichnis `overleaf-toolkit`:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
