Das [Toolkit](https://github.com/ayaka-notes/toolkit) ist die empfohlene Methode zur Bereitstellung von Ayakaleaf Pro-Instanzen.

In diesem Abschnitt führen wir Sie durch das Herunterladen des Toolkits von GitHub, machen Sie mit einigen Befehlen des Toolkits vertraut und konfigurieren einige grundlegende Einstellungen. Am Ende dieser Seite sollten Sie eine laufende On-Premises-Instanz von Overleaf haben.
