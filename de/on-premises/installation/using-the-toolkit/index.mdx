Das [Toolkit](https://github.com/ayaka-notes/toolkit) ist die empfohlene Methode zur Bereitstellung von Ayakaleaf Pro-Instanzen.

In diesem Abschnitt führen wir Sie durch das Herunterladen des Toolkit von GitHub, machen Sie mit einigen Befehlen des Toolkit vertraut und konfigurieren einige grundlegende Einstellungen. Am Ende dieser Seite sollten Sie eine laufende On-Premises-Instanz von Overleaf haben.

<Info>

Standardmäßig akzeptiert die Instanz nur Verbindungen vom Server selbst unter `http://localhost`. Um sie von anderen Computern oder über einen anderen Port zu öffnen, setzen Sie `OVERLEAF_LISTEN_IP` und `OVERLEAF_PORT` in `config/overleaf.rc`, wie unter [5. Ihre Instanz personalisieren](/de/on-premises/installation/using-the-toolkit/5.-personalizing-your-instance) beschrieben.

</Info>
