### Ein erster Überblick

Da Sie nun eine lokale Kopie des Toolkit haben, sehen wir uns mit dem Befehl `ls` die Struktur des Repositorys an.

```bash title="Run this"
ls -l
```

<Info>

Der Befehl `ls -l` zeigt eine ausführliche Langliste des Verzeichnisinhalts an und liefert zusätzliche Dateiinformationen wie Berechtigungen, Eigentümer und Größe.

</Info>

Wenn alles erfolgreich geklont wurde, sollten Sie etwa Folgendes sehen:

```text
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 bin
-rw-r--r-- 1 fry fry  6465 Aug 30 14:16 CHANGELOG.md
drwxr-xr-x 2 fry fry  4096 Sep  6 12:43 config
drwxr-xr-x 5 fry fry  4096 Aug 30 14:22 data
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 doc
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 lib
-rw-r--r-- 1 fry fry 34520 Aug 30 14:16 LICENSE
-rw-r--r-- 1 fry fry  1178 Aug 30 14:16 README.md
```

<Info>

Alle benutzereigenen Konfigurationsdateien befinden sich im Verzeichnis `config/`. Dieses Verzeichnis ist von der Git-Versionsverwaltung **ausgeschlossen** und wird daher bei einer Aktualisierung des Toolkit nicht verändert.

</Info>

## Aufbau des Repositorys

| Name     | Beschreibung                                                                                                                                                                                                                                               |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `bin`    | Dieser Ordner enthält eine Sammlung von Skripten, mit denen Sie Ihre Overleaf-Serverinstanz verwalten. Mehr über diese Skripte erfahren Sie im Abschnitt „Befehle“ weiter unten.                                                                                     |
| `config` | Dieser Ordner enthält Ihre eigenen lokalen Konfigurationsdateien.                                                                                                                                                                                                  |
| `lib`    | Dieser Ordner enthält die vom Toolkit verwendeten Basis-Konfigurationsdateien.                                                                                                                                                                                        |
| `data`   | Standardmäßig enthält dieser Ordner den Speicherort für MongoDb, Redis und Overleaf. Weitere Informationen finden Sie im Abschnitt [Persistente Daten](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/files-and-locations#persistent-data) weiter unten. |

<Warning>

Wir empfehlen, Dateien außerhalb des Ordners `/config` **nicht** direkt zu ändern. Notwendige Änderungen können stattdessen über Umgebungsvariablen in **config/variables.env** oder **config/overleaf.rc** vorgenommen werden.\
Um beispielsweise das Image des Dienstes `mongo` festzulegen, bearbeiten Sie nicht direkt `lib/docker-compose.mongo.yml`, sondern setzen das Image über die Umgebungsvariable `MONGO_IMAGE` in `config/overleaf.rc`. Weitere Informationen finden Sie auf der Seite [Toolkit-Einstellungen](/de/on-premises/configuration/overleaf-toolkit/toolkit-settings).

</Warning>

<Info>

Das Toolkit ändert **keine** Daten im Verzeichnis `config/` ohne Ihre Zustimmung.

</Info>
