### Ihr erstes Administratorkonto erstellen

Öffnen Sie in einem Browser [http://localhost/launchpad](http://localhost/launchpad). Sie sollten ein Formular mit Feldern für E-Mail-Adresse und Passwort sehen. Geben Sie die Zugangsdaten ein, die Sie für das Administratorkonto verwenden möchten, und klicken Sie dann auf **Register**.

<Info>

Passwörter müssen mindestens 8 Zeichen (höchstens 72) lang sein, dürfen keine E-Mail-Adressen enthalten oder E-Mail-Adressen zu ähnlich sein und dürfen nur gültige Zeichen enthalten.

</Info>

![Overleaf Launchpad](/images/on-premises/image.jpg)

Klicken Sie dann auf den Link, um zur Anmeldeseite zu gelangen ([http://localhost/login](http://localhost/login)). Geben Sie die Zugangsdaten ein. Sobald Sie angemeldet sind, sehen Sie die Willkommensseite.

![Willkommensseite von Overleaf](/images/on-premises/image-1.jpg)

Klicken Sie auf die grüne Schaltfläche unten auf der Seite, um mit Overleaf zu beginnen.

### Ihr erstes Beispielprojekt erstellen

Öffnen Sie [http://localhost/project](http://localhost/project) in Ihrem Browser. Dort sehen Sie eine Schaltfläche, über die Sie Ihr erstes Projekt erstellen können.

![Willkommen bei Overleaf!](/images/on-premises/image-2.jpg)

Klicken Sie auf diese Schaltfläche, wählen Sie **Example Project** und folgen Sie den Anweisungen auf dem Bildschirm.

Sie werden zum neuen Projekt weitergeleitet, wo Sie einen Texteditor und eine PDF-Vorschau sehen.

![Overleaf-Editor](/images/on-premises/image-3.jpg)

Zum Abschluss können Sie auf das **Home**-Symbol klicken, um zu Ihrer Projektseite zurückzukehren.
