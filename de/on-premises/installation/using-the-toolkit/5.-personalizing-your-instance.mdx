### Ihre Instanz personalisieren

Bevor Sie Ihre Overleaf-Instanz zum ersten Mal starten, ergänzen Sie die Konfigurationsdatei `config/variables.env` mit Ihren individuellen Angaben.

<Steps>
<Step title="Die Variablendatei bearbeiten">
Öffnen Sie `config/variables.env` in Ihrem bevorzugten Texteditor und setzen Sie die unten aufgeführten Umgebungsvariablen auf die erforderlichen Werte.
</Step>

<Step title="Erforderliche Umgebungsvariablen">
Aktualisieren Sie die folgenden Variablen in `config/variables.env`:

| Name                          | Beschreibung                                                                                                                                                   | Beispiel                        |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| `OVERLEAF_SITE_URL`           | Die Adresse, unter der Ihre Overleaf-Instanz öffentlich erreichbar ist. Sie wird in öffentlichen Links und bei Verbindungen über Websockets verwendet und **muss daher korrekt konfiguriert sein**! | `https://overleaf.lilliput.com` |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | Diese E-Mail-Adresse wird als `from`-Adresse für alle ausgehenden E-Mails verwendet.                                                                           | `no-reply@lilliput.com`         |
| `OVERLEAF_ADMIN_EMAIL`        | Die E-Mail-Adresse, unter der Benutzer die für den Betrieb der Website verantwortliche Person erreichen können.                                                 | `it-services@lilliput.com`      |

Wenn Sie diese Umgebungsvariablen aktualisiert haben, speichern Sie die Datei und schließen Sie den Editor.
</Step>

<Step title="Sandbox-Kompilierung einrichten">
Konfigurieren Sie als Nächstes TeX Live Full für [sandboxed-compiles.md](/de/on-premises/configuration/overleaf-toolkit/sandboxed-compiles  "mention"). Öffnen Sie `config/variables.env` und aktualisieren Sie die folgenden Umgebungsvariablen:

```dotenv title="config/variables.env" wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```
</Step>

<Step title="Ihre Instanz starten">
Um Ihre Instanz zu starten, führen Sie Folgendes aus:

```text title="Start the instance"
bin/up
```

Dieser Befehl lädt die benötigten Images einschließlich texlive herunter, erstellt die Container (mit Ihren Anpassungen) und startet die Instanz. Sie sollten Log-Ausgaben der verschiedenen Docker-Container sehen.

Um sie später erneut zu starten (ohne an die Log-Ausgabe angehängt zu werden), führen Sie Folgendes aus:

```text title="Start without attaching to logs"
bin/start
```
</Step>
</Steps>

<Info>

Das Toolkit verwendet `docker compose`, um die Overleaf-Docker-Container zu verwalten. Es stellt eine Reihe von Skripten bereit, die `docker compose` kapseln und sich um die meisten Details für Sie kümmern.

</Info>

Wenn alles funktioniert, sollten Sie die Anmeldeseite Ihrer neuen Overleaf-Instanz sehen, indem Sie in Ihrem Browser [http://127.0.0.1/](http://127.0.0.1/) oder [http://localhost/](http://localhost/) aufrufen.

<Warning>

Je nach Ihrer Netzwerkkonfiguration und dem Hosting-Ort Ihrer Overleaf-Instanz sind möglicherweise zusätzliche Konfigurationsänderungen erforderlich. Weitere Details finden Sie in den Toolkit-Einstellungen: [toolkit-settings.md](/de/on-premises/configuration/overleaf-toolkit/toolkit-settings  "mention")

</Warning>
