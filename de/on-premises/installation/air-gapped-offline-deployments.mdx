---
title: Air-Gapped-/Offline-Bereitstellungen
description: Stellen Sie Ayakaleaf Pro offline bereit, indem Sie Docker-Images exportieren, übertragen und laden.
icon: block-brick
---

Grundsätzlich raten wir davon ab, Ayakaleaf Pro in einer Offline-Umgebung bereitzustellen, da viele Funktionen, etwa GitHub Sync und die Zotero-Integration, eine Internetverbindung erfordern.

Wenn Sie offline arbeiten möchten, ist die Registry `ghcr.io` möglicherweise nicht immer erreichbar, um die benötigten `ayakaleaf-pro`- und TeX Live-Images herunterzuladen. Das ist kein Problem, denn Docker bietet Werkzeuge zum Exportieren und Importieren von Images, die Ihnen bei einer Offline-/Air-Gapped-Bereitstellung helfen.

Grob gesagt laden Sie die benötigten Images auf ein Gerät mit Internetverbindung herunter, exportieren sie auf ein tragbares Speichermedium (oder übertragen sie per SCP/Rsync) und importieren sie auf dem Air-Gapped-Server.

Dazu müssen Sie die folgenden Schritte ausführen:

* Laden Sie alle benötigten Images (`overleaf-pro`, `git-bridge`, `mongo`, `redis` sowie alle erforderlichen [TeX Live-Images](/de/on-premises/configuration/overleaf-toolkit/sandboxed-compiles#available-tex-live-images) für die Verwendung mit [Sandboxed Compiles](/de/on-premises/configuration/overleaf-toolkit/sandboxed-compiles)) auf einem Rechner mit Internetverbindung herunter
  * `docker pull ghcr.io/ayaka-notes/overleaf-pro:6.3.2`
  * `docker pull ghcr.io/ayaka-notes/overleaf-pro/git-bridge:6.3.2` (der Tag muss mit dem von `overleaf-pro` übereinstimmen)
  * `docker pull mongo:8.0` (bitte durch die tatsächliche Version ersetzen)
  * `docker pull redis:7.4` (bitte durch die tatsächliche Version ersetzen)
  * `docker pull ghcr.io/ayaka-notes/texlive-full:2024.1` (bitte durch die tatsächliche Version ersetzen)
* Exportieren Sie anschließend **jedes** der heruntergeladenen Images in eine .tar-Datei. Zum Beispiel: `docker save ghcr.io/ayaka-notes/overleaf-pro:6.3.2 > overleaf-pro:6.3.2.tar`
* Übertragen Sie die `.tar`-Dateien mit einer Methode Ihrer Wahl vom Rechner mit Internetverbindung auf den Offline-/Air-Gapped-Server
* Laden Sie für jede .tar-Datei das Image mit dem Befehl `docker load` aus der Datei. Zum Beispiel: `docker load < overleaf-pro:6.3.2.tar`
* Führen Sie abschließend den Befehl `docker images` aus, um zu prüfen und zu bestätigen, dass die Images erfolgreich geladen wurden und verfügbar sind

<Danger>

Standardmäßig versucht das Toolkit beim Ausführen des Befehls `bin/up`, jedes der über `ALL_TEX_LIVE_DOCKER_IMAGES` in `config/variables.env` festgelegten TeX Live-Images automatisch herunterzuladen. Da Ihre Bereitstellung air-gapped ist, schlägt dies fehl – Sie können das verhindern, indem Sie `SIBLING_CONTAINERS_PULL=false` in `config/overleaf.rc` setzen.

</Danger>
