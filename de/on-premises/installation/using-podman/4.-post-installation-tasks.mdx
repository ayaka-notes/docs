### Erstellen Sie Ihr erstes Administratorkonto {#create-your-first-administrator-account}

Öffnen Sie [http://localhost:8080/launchpad](http://localhost:8080/launchpad) oder Ihre `OVERLEAF_SITE_URL` gefolgt von `/launchpad` und registrieren Sie das Administratorkonto. Ab hier funktioniert alles wie mit Docker: Folgen Sie [6. Aufgaben nach der Installation](/de/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks) der Docker-Anleitung und verwenden Sie in deren `localhost`-Links den Port `8080`.

Erstellen Sie das Beispielprojekt und kompilieren Sie es. Das PDF zeigt, dass Kompilierungen über Podman in ihren TeX-Live-Containern laufen. So sehen Sie den Kompilierungscontainer:

```bash title="List the compile containers"
podman ps -a --filter name=project- --format "{{.Names}} {{.Image}} {{.Status}}"
```

### HTTPS verwenden {#use-https}

Der [TLS-Proxy](/de/on-premises/configuration/overleaf-toolkit/tls-proxy) des Toolkit funktioniert auf Podman: Führen Sie `bin/init --tls` aus und setzen Sie Ihr Zertifikat und `NGINX_ENABLED=true` wie dort beschrieben. Er lauscht auf den Ports `80` und `443`, die Rootless Podman standardmäßig nicht verwenden darf. Erlauben Sie Benutzern ohne Root-Rechte die Verwendung von Ports ab `80`:

```bash title="Allow ports 80 and 443"
echo "net.ipv4.ip_unprivileged_port_start=80" | sudo tee /etc/sysctl.d/99-unprivileged-ports.conf
sudo sysctl --system
```

Damit kann jeder Benutzer auf dem Server auf diesen Ports lauschen, tun Sie dies also nur auf einem Server, der ausschließlich für Ayakaleaf Pro bestimmt ist. Öffnen Sie die Ports dann in der Firewall:

```bash title="Open ports 80 and 443"
sudo firewall-cmd --permanent --add-port=80/tcp --add-port=443/tcp
sudo firewall-cmd --reload
```

Setzen Sie `OVERLEAF_SITE_URL` auf Ihre `https://`-Adresse und führen Sie `bin/up -d` aus. Behalten Sie die Standardwerte `NGINX_HTTP_PORT=80` und `TLS_PORT=443` bei: Mit anderen Ports führt die Weiterleitung von HTTP zu HTTPS auf den falschen Port.

<Info>

Belassen Sie `OVERLEAF_LISTEN_IP` auf `127.0.0.1`, wenn Sie den TLS-Proxy verwenden, damit Port `8080` von anderen Computern aus nicht erreichbar ist.

</Info>

### Aktualisieren {#upgrade}

Aktualisieren Sie mit `bin/upgrade`, wie in [Ihr Deployment aktualisieren](/de/on-premises/maintenance/upgrading-your-deployment) beschrieben. Auf Podman extrahiert es außerdem das Seccomp-Profil der neuen Version nach `config/seccomp/<version>/` und aktualisiert `SECCOMP_PROFILE`:

```text
Over-writing config/version with 6.3.4
Set SECCOMP_PROFILE=/home/<user>/overleaf-toolkit/config/seccomp/6.3.4/clsi-profile.json in config/variables.env
```

Führen Sie nach einem Update `bin/podman-setup` aus, um die Einrichtung zu prüfen.

### SELinux-Modus ändern {#change-the-selinux-mode}

`SELINUX_MODE` in `config/overleaf.rc` legt fest, wie SELinux den Container `sharelatex` einschränkt. `managed` ist der Modus, den diese Seiten einrichten; die anderen Modi sind unter [Toolkit-Einstellungen](/de/on-premises/configuration/overleaf-toolkit/toolkit-settings) beschrieben. Führen Sie nach einer Änderung `bin/up -d` aus.
