title: 0. Host vorbereiten
description: Prüfen Sie Betriebssystem und SELinux und installieren Sie git, bevor Sie Rootless Podman einrichten.

Sie installieren Podman nicht von Hand: [2. podman-setup ausführen](/de/on-premises/installation/using-podman/2.-run-podman-setup) installiert es zusammen mit den anderen benötigten Paketen. Hier prüfen Sie nur den Host und installieren `git`, das Sie zum Herunterladen des Toolkit benötigen.

<Steps>
<Step title="Betriebssystem und SELinux prüfen">
Melden Sie sich als der Benutzer an, der Ayakaleaf Pro ausführen wird, nicht als `root`, und prüfen Sie die Distribution und den SELinux-Modus:

```bash title="Check the host"
grep PRETTY_NAME /etc/os-release
getenforce
```

Sie sollten RHEL, Rocky Linux, AlmaLinux oder CentOS Stream mit Version 9 oder neuer sowie `Enforcing` sehen:

```text
PRETTY_NAME="Rocky Linux 9.9 (Blue Onyx)"
Enforcing
```
</Step>

<Step title="Prüfen, ob Sie sudo verwenden können">
`bin/podman-setup --apply` installiert Pakete und lädt ein SELinux-Modul mit `sudo` und fragt bei Bedarf nach Ihrem Passwort:

```bash title="Check sudo"
sudo -v
```

Wenn dies fehlschlägt, bitten Sie Ihren Administrator, Ihren Benutzer zur Gruppe `wheel` hinzuzufügen.
</Step>

<Step title="git installieren">
```bash title="Install git"
sudo dnf install -y git
```

<Warning>

Installieren Sie auf diesem Host keine Docker Engine. Das Paket `podman-docker`, das `bin/podman-setup` installiert, stellt den Befehl `docker` bereit, und das Toolkit behandelt den Host als Podman, sobald der Befehl `podman` vorhanden ist.

</Warning>
</Step>
</Steps>
