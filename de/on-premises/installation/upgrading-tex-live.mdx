---
title: TeX Live aktualisieren
description: Aktualisieren Sie TeX Live oder installieren Sie Pakete in einer Overleaf-Community-Edition-Bereitstellung.
icon: square-up
---

<Danger>

Die folgenden Anweisungen gelten **nur** für Installationen der **Community Edition**. Wir empfehlen Nutzern von Ayakaleaf Pro dringend, [Sandboxed Compiles](/de/on-premises/configuration/overleaf-toolkit/sandboxed-compiles) zu aktivieren, da dies Zugriff auf nahezu dieselben TeX-Live-Images bietet, die auf [overleaf.com](https://www.overleaf.com) verwendet werden, und zudem für mehr Sicherheit die Kompilierungen der Projekte voneinander isoliert.

</Danger>

Um Bandbreite zu sparen, enthalten sowohl die Images der Overleaf Community Edition als auch von Ayakaleaf Pro nur eine minimale Installation von [TeX Live](https://www.tug.org/texlive/). Mit dem Befehl [tlmgr](https://www.tug.org/texlive/tlmgr.html) im Container `sharelatex` können Sie weitere Pakete installieren oder auf eine vollständige TeX-Live-Installation upgraden.

#### In den sharelatex-Container gelangen

Um eine Shell im Container `sharelatex` zu starten, führen Sie Folgendes aus:

```bash
bin/shell
```

Sie erhalten eine Eingabeaufforderung, die etwa so aussieht:

```bash
root@309b192d4030:/#
```

In den folgenden Anweisungen gehen wir davon aus, dass Sie sich im Container befinden.

#### Ihre aktuelle TeX-Live-Version ermitteln

TeX Live wird jedes Jahr etwa im April veröffentlicht. Die Schritte zur Verwendung von `tlmgr` unterscheiden sich je nachdem, ob Sie die aktuelle oder eine ältere Version verwenden. Mit `tlmgr --version` können Sie prüfen, welche TeX-Live-Version Sie verwenden. Diese Installation läuft beispielsweise mit TeX Live 2021:

```bash
# tlmgr --version
tlmgr revision 59291 (2021-05-21 05:14:40 +0200)
tlmgr using installation: /usr/local/texlive/2021
TeX Live (https://tug.org/texlive) version 2021
```

<Info>

Die aktuelle Version von TeX Live finden Sie auf [der TeX-Live-Homepage](https://www.tug.org/texlive/).

</Info>

Wenn Sie eine ältere TeX-Live-Version verwenden, haben Sie zwei Möglichkeiten. Eine neue Version des Overleaf-Docker-Images erscheint in der Regel kurz nach einer TeX-Live-Veröffentlichung. Sie können entweder darauf warten und Ihre Bereitstellung mit dem Skript `bin/upgrade` aktualisieren, oder – wenn Sie die ältere TeX-Live-Version beibehalten möchten – `tlmgr` zunächst anweisen, ein historisches Repository zu verwenden. Eine Anleitung dazu finden Sie [hier](https://www.tug.org/texlive/acquire.html#past).

#### Pakete installieren

Um eine vollständige TeX-Live-Installation zu installieren, führen Sie diesen Befehl im Container `sharelatex` aus:

```text
tlmgr install scheme-full
```

Sie können auch einzelne Pakete manuell installieren:

```bash
tlmgr install tikzlings tikzmarmots tikzducks
```

<Warning>

Ab Version `3.3.0` ist es wieder **erforderlich**, nach jeder Verwendung von `tlmgr install` den Befehl `tlmgr path add` auszuführen, damit alle Binärdateien korrekt per Symlink in den Systempfad eingebunden werden.

</Warning>

Es stehen viele weitere Befehle zur Verfügung. Mehr dazu erfahren Sie mit:

```text
tlmgr help
```

Wenn Sie fertig sind, geben Sie `exit` ein oder drücken Sie Strg-D, um die Shell zu verlassen.

#### Ihre Änderungen speichern

Die soeben vorgenommenen Änderungen haben den Container `sharelatex` verändert, sind aber flüchtig – sie gehen verloren, wenn Docker Compose den Container neu erstellt, z. B. im Rahmen einer Konfigurationsänderung.

Um sie dauerhaft zu machen, speichern Sie die Änderungen mit `docker commit` in einem neuen Docker-Image:

```bash
cat config/version #5.2.1
docker commit sharelatex sharelatex/sharelatex:5.2.1-with-texlive-full
echo 5.2.1-with-texlive-full > config/version
```

Passen Sie nach dem Commit der Änderungen `config/version` entsprechend an. Führen Sie dann `bin/up` aus, um den Container `sharelatex` neu zu erstellen.

<Danger>

Sie müssen diese Schritte jedes Mal wiederholen, wenn Sie ein [Upgrade](https://github.com/overleaf/toolkit/blob/master/doc/upgrading.md) auf eine neue Overleaf-Version durchführen.

</Danger>
