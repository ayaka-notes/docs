Docker Compose auf einem einzelnen Server ist die empfohlene Methode zur Bereitstellung von Ayakaleaf Pro. Sie betreiben es über das [Toolkit](https://github.com/ayaka-notes/toolkit): eine Sammlung von Skripten, die `docker compose` kapseln und Ihre Einstellungen aus einem einzigen `config/`-Verzeichnis lesen, sodass `bin/up` an die Stelle von `docker compose up` tritt.
