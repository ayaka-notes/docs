Ayakaleaf Pro ist ein kostenloses Docker-Image in der [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Sie benötigen kein Konto, keine Anmeldung und keine kommerzielle Overleaf-Lizenz, um es herunterzuladen.

Öffnen Sie `config/overleaf.rc` und setzen Sie:

```bash title="config/overleaf.rc"
SERVER_PRO=true
```

Beim nächsten Ausführen von `bin/up` lädt das Toolkit `ghcr.io/ayaka-notes/overleaf-pro` in der Version aus `config/version` herunter, statt der offiziellen Overleaf Community Edition.

Das Image wird für `arm64` und `amd64` gebaut, und Docker wählt dasjenige, das zur Architektur der Docker-Engine passt.
