---
title: 3. Konfiguration initialisieren
description: Erstellen Sie die Konfigurationsdateien des Toolkit in Ubuntu unter WSL 2 mit bin/init.
icon: circle-play
---

Führen Sie im Toolkit-Verzeichnis in **Ubuntu** Folgendes aus:

```bash
bin/init
```

`bin/init` erstellt drei Dateien:

| Datei | Zweck |
| --- | --- |
| `config/overleaf.rc` | Container-Einstellungen, der veröffentlichte Port und die Speicherorte der Daten |
| `config/variables.env` | Anwendungseinstellungen und Secrets |
| `config/version` | Die Version des Anwendungs-Images |

Außerdem erzeugt es `OVERLEAF_INVITE_TOKEN_SECRET` in `config/variables.env`. Bewahren Sie es auf, und veröffentlichen Sie diese Datei nicht und committen Sie sie nicht in die Versionsverwaltung.

Behalten Sie die Version bei, die das Toolkit für eine Neuinstallation auswählt. Um die Version einer bestehenden Instanz später zu ändern, folgen Sie [Ihr Deployment aktualisieren](/de/on-premises/maintenance/upgrading-your-deployment).

<Info>

`bin/init` überschreibt keine vorhandene Konfiguration. Wenn es meldet, dass Dateien bereits existieren, prüfen Sie diese, bevor Sie fortfahren. Bewahren Sie `config/` und `data/` auf, wenn Sie die Instanz neu starten oder aktualisieren.

</Info>
