In diesem Abschnitt betreiben wir Ayakaleaf Pro lokal unter Windows mit WSL 2, Ubuntu, Docker Desktop und dem [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). Die Anleitung verwendet `http://localhost:8080`, speichert die Daten im Home-Verzeichnis von Ubuntu und aktiviert Sandboxed Compiles.

Die Anwendung, MongoDB, Redis und TeX Live laufen in Linux-Containern, die von Docker Desktop verwaltet werden. Führen Sie die Toolkit-Befehle in Ubuntu aus; öffnen Sie die Anwendung in Ihrem Windows-Browser. [Schritt 0](/de/on-premises/installation/using-docker-compose/windows/0.-setup-wsl-and-docker-desktop) erklärt, wie die Windows- und Linux-Teile zusammenspielen, und beginnt mit der Installation von WSL.

Sie können Windows für eine lokale Instanz verwenden oder sie mit den Verfügbarkeitseinstellungen aus Schritt 6 dauerhaft laufen lassen. Für gemeinsam genutzte und produktive Server empfehlen wir die [Linux-Anleitung](/de/on-premises/installation/using-docker-compose/linux) mit HTTPS, Backups und Zugriffskontrolle. Der Windows-Energiesparmodus, das Beenden von Docker Desktop und das Herunterfahren von WSL unterbrechen diese lokale Instanz; siehe [Die Instanz verfügbar halten](/de/on-premises/installation/using-docker-compose/windows/6.-post-installation-tasks#keep-the-instance-available).

## Bevor Sie beginnen {#before-you-start}

Sie benötigen:

* Eine Windows-Version und einen Prozessor, die von [Docker Desktop for Windows](https://docs.docker.com/desktop/setup/install/windows-install/) unterstützt werden, mit aktivierter Hardware-Virtualisierung. Diese Anleitung verwendet Windows 11 auf x86-64.
* Die Berechtigung, WSL zu aktivieren und Software zu installieren. WSL muss Version 2.1.5 oder neuer sein, und Ubuntu muss im WSL 2-Modus laufen.
* Genügend Arbeitsspeicher für Windows und die Container. Für eine kleine lokale Instanz sind 4 CPUs und 8 GB für Docker verfügbarer Arbeitsspeicher ein empfohlener Ausgangspunkt, kein gemessenes Minimum.
* Freien Speicherplatz auf dem Windows-Laufwerk, auf dem die WSL- und Docker-Daten liegen. Planen Sie mindestens 40 GB für ein vollständiges TeX Live-Setup plus Projektdaten ein; das Basis-Image in [Schritt 5](/de/on-premises/installation/using-docker-compose/windows/5.-personalizing-your-instance) ist kleiner und eignet sich für den ersten Bereitstellungstest. Zusätzliche Image-Versionen benötigen zusätzlichen Platz.
* Netzwerkzugriff auf GitHub, die GitHub Container Registry (`ghcr.io`) und Docker Hub, um das Toolkit zu klonen und Images herunterzuladen.

**PowerShell**-Blöcke werden in Windows ausgeführt. **Bash**-Blöcke und `bin/`-Befehle werden in Ubuntu ausgeführt, sofern nicht anders angegeben. Führen Sie Toolkit-Skripte nicht in PowerShell oder Windows Git Bash aus.
