Das Toolkit ist dasselbe wie unter Linux. Sein Aufbau, das Verzeichnis `config/` und die Befehle in `bin/` werden in [2. Machen Sie sich mit dem Toolkit vertraut](/de/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) der Linux-Anleitung beschrieben.

Beachten Sie unter Windows diese Unterschiede:

* Führen Sie `bin/`-Befehle in **Ubuntu Bash** aus, und zwar aus `~/ayakaleaf-toolkit`. Mit **PowerShell** gekennzeichnete Befehle werden stattdessen in Windows ausgeführt.
* Starten Sie Docker Desktop und aktivieren Sie die WSL Integration für Ubuntu, bevor Sie `bin/up`, `bin/start` oder `bin/docker-compose` verwenden.
* Behalten Sie für Konfigurationsdateien Linux-Zeilenenden (LF) bei. Bearbeiten Sie sie mit `nano` in Ubuntu oder einem mit WSL verbundenen Editor. CRLF-Zeilenenden können Bash-Fehler verursachen.
* `bin/doctor` führt innerhalb von Ubuntu Linux-Prüfungen aus. Seine Warnung, dass Sie nicht bei `quay.io` angemeldet sind, gilt nicht für das öffentliche Image `ghcr.io/ayaka-notes/overleaf-pro`. Andere Warnungen erfordern weiterhin Aufmerksamkeit.

```bash
bin/doctor
```
