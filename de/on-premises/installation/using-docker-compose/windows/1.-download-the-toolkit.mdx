<Steps>
<Step title="Die Kommandozeilen-Tools installieren">
Führen Sie in **Ubuntu** Folgendes aus und verwenden Sie dabei das Linux-Passwort, das Sie in Schritt 0 erstellt haben:

```bash
sudo apt update
sudo apt install -y git ca-certificates curl perl gawk openssl
```

Ubuntu bringt Bash, GNU sed und coreutils bereits mit. Anders als macOS benötigt es weder Homebrew noch eine separate GNU-sed-Installation.
</Step>

<Step title="Das Repository des Ayakaleaf Toolkit klonen">
Bewahren Sie das Toolkit und seine Daten im Linux-Dateisystem von Ubuntu unter Ihrem Home-Verzeichnis auf:

```bash
cd "$HOME"
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

Vermeiden Sie für die laufende Datenbank und die Projektdaten `/mnt/c`, `/mnt/d`, OneDrive und temporäre Verzeichnisse. Pfade im Linux-Dateisystem bieten die Berechtigungen und das Dateisystemverhalten, das die Container erwarten, und vermeiden den Overhead zwischen Dateisystemen; siehe [Microsofts Hinweise zu Dateisystemen](https://learn.microsoft.com/en-us/windows/wsl/filesystems).

<Warning>

Wenn das Verzeichnis bereits eine Installation enthält, verwenden Sie sie unverändert oder wählen Sie für eine neue Instanz ein anderes Verzeichnis. Ersetzen Sie nicht die Konfiguration oder die Daten einer bestehenden Bereitstellung.

</Warning>
</Step>
</Steps>
