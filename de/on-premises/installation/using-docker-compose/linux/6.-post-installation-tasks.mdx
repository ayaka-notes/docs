### Ihr erstes Administratorkonto erstellen {#creating-your-first-administrator-account}

Öffnen Sie in einem Browser [http://localhost/launchpad](http://localhost/launchpad). Wenn Sie `OVERLEAF_LISTEN_IP` oder `OVERLEAF_PORT` geändert haben, verwenden Sie stattdessen Ihre `OVERLEAF_SITE_URL`, zum Beispiel `http://192.168.1.20:8080/launchpad`. Dasselbe gilt für die anderen `localhost`-Links auf dieser Seite. Sie sollten ein Formular mit Feldern für E-Mail-Adresse und Passwort sehen. Geben Sie dort die Zugangsdaten ein, die Sie für das Administratorkonto verwenden möchten, und klicken Sie dann auf **Register**.

<Info>

Passwörter müssen mindestens 8 Zeichen (höchstens 72) lang sein, dürfen keine E-Mail-Adressen enthalten oder diesen zu ähnlich sein und dürfen nur gültige Zeichen enthalten.

</Info>

![Das erste Administratorkonto im Launchpad erstellen](/images/on-premises/post-installation-launchpad.png)

Sie werden anschließend zur Anmeldeseite weitergeleitet ([http://localhost/login](http://localhost/login)). Geben Sie die Zugangsdaten ein. Sobald Sie angemeldet sind, sehen Sie erneut das Launchpad, nun mit den Statusprüfungen.

![Statusprüfungen im Launchpad nach der Anmeldung](/images/on-premises/post-installation-status-checks.png)

Klicken Sie auf den grünen Button unten auf der Seite, um Overleaf zu verwenden.

### Ihr erstes Beispielprojekt erstellen {#creating-your-first-example-project}

Öffnen Sie [http://localhost/project](http://localhost/project) in Ihrem Browser. Sie sehen dort einen Button, über den Sie Ihr erstes Projekt erstellen können.

![Menü zum Erstellen eines neuen Projekts](/images/on-premises/post-installation-create-project.png)

Klicken Sie auf diesen Button, wählen Sie **Example project** und folgen Sie den Anweisungen auf dem Bildschirm.

Sie werden zum neuen Projekt weitergeleitet, wo Sie einen Texteditor und eine PDF-Vorschau sehen.

![Das Beispielprojekt im Editor](/images/on-premises/post-installation-editor.png)

Zum Abschluss können Sie auf das Overleaf-Logo oben links klicken, um zu Ihrer Projektseite zurückzukehren.
