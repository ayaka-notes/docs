In diesem Abschnitt führen wir Sie durch die Installation von Docker und das Herunterladen des Toolkit von GitHub, machen Sie mit einigen Befehlen des Toolkit vertraut und konfigurieren einige grundlegende Einstellungen. Am Ende dieses Abschnitts sollten Sie eine laufende On-Premises-Instanz von Overleaf haben.

Die Schritte richten sich an ein aktuelles Ubuntu LTS. Installieren Sie auf einer anderen Distribution Docker Engine und das Compose-Plugin wie in der [Docker-Dokumentation](https://docs.docker.com/engine/install/) beschrieben und fahren Sie dann mit [1. Toolkit herunterladen](/de/on-premises/installation/using-docker-compose/linux/1.-download-the-toolkit) fort.

<Info>

Standardmäßig akzeptiert die Instanz nur Verbindungen vom Server selbst unter `http://localhost`. Um sie von anderen Computern oder über einen anderen Port zu öffnen, setzen Sie `OVERLEAF_LISTEN_IP` und `OVERLEAF_PORT` in `config/overleaf.rc`, wie unter [5. Ihre Instanz personalisieren](/de/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance) beschrieben.

</Info>
