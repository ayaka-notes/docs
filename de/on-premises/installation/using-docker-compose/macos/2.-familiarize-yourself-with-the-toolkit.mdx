Das Toolkit ist unter macOS und Linux dasselbe. Sein Aufbau, das Verzeichnis `config/` und die Befehle in `bin/` werden in [2. Machen Sie sich mit dem Toolkit vertraut](/de/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) der Linux-Anleitung beschrieben.

Beachten Sie unter macOS drei Unterschiede:

* Führen Sie die Skripte in einem Terminal aus, in dem GNU sed an erster Stelle im `PATH` steht, siehe [1. Toolkit herunterladen](/de/on-premises/installation/using-docker-compose/macos/1.-download-the-toolkit).
* Starten Sie Docker Desktop, bevor Sie ein Skript ausführen, das mit Docker kommuniziert, etwa `bin/up`, `bin/start` oder `bin/docker-compose`.
* `bin/doctor` enthält Prüfungen, die aus dem offiziellen Overleaf Toolkit übernommen wurden. Seine Warnung `This system seems to not be Linux` ist unter macOS zu erwarten, und seine Warnung, dass Sie nicht bei `quay.io` angemeldet sind, gilt nicht für das öffentliche Image `ghcr.io/ayaka-notes/overleaf-pro`. Andere Probleme im Bericht sind weiterhin relevant.
