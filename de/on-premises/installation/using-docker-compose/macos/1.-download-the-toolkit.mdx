description: Installieren Sie GNU sed und klonen Sie das Ayakaleaf Toolkit auf Ihren Mac.

<Steps>
<Step title="Git und Homebrew prüfen">
```bash
git --version
brew --version
```

Wenn macOS Sie beim Ausführen von Git auffordert, die Command Line Tools zu installieren, installieren Sie diese zuerst. Falls Homebrew fehlt, installieren Sie es gemäß der [offiziellen Anleitung](https://brew.sh/).
</Step>

<Step title="GNU sed in den PATH aufnehmen">
Die Skripte des Toolkit verwenden GNU-sed-Optionen, die das in macOS integrierte BSD sed ablehnt. Installieren Sie [GNU sed](https://formulae.brew.sh/formula/gnu-sed) und setzen Sie es in diesem Terminal an den Anfang des `PATH`:

```bash
brew install gnu-sed
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
sed --version
```

Der letzte Befehl sollte **GNU sed** ausgeben.

Ein Alias wie `alias sed=gsed` reicht nicht aus: Das Toolkit führt Bash-Skripte aus, die die Aliase Ihrer interaktiven Shell nicht sehen. Sie müssen `/usr/bin/sed` nicht ersetzen.

Führen Sie die Zeile `export PATH=...` in jedem neuen Terminal, das Sie für das Toolkit verwenden, erneut aus, oder fügen Sie sie nach der Initialisierung von Homebrew in Ihre Shell-Startdatei ein.
</Step>

<Step title="Das Repository des Ayakaleaf Toolkit klonen">
Wählen Sie ein dauerhaftes Verzeichnis. Vermeiden Sie für die laufende Datenbank und die Projektdaten `/tmp`, Wechseldatenträger und cloud-synchronisierte Ordner wie iCloud Drive. Diese Anleitung verwendet `~/ayakaleaf-toolkit`:

```bash
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

<Warning>

Wenn das Verzeichnis bereits eine Installation enthält, verwenden Sie sie unverändert oder wählen Sie für eine neue Instanz ein anderes Verzeichnis. Initialisieren Sie keine neue Konfiguration über einer bestehenden Bereitstellung.

</Warning>
</Step>
</Steps>
