---
title: 2. Namespace und Secrets erstellen
description: Den Namespace und die Secrets erstellen, die Ayakaleaf Pro benötigt.
icon: key
---

Alles kommt in den Namespace `overleaf`:

```bash
kubectl create namespace overleaf
```

Ayakaleaf Pro liest seine Secrets aus Umgebungsvariablen. Erzeugen Sie sie einmal und bewahren Sie sie in einem Secret auf:

```bash wrap
HISTORY=$(openssl rand -hex 32)
kubectl -n overleaf create secret generic overleaf-secrets \
  --from-literal=OVERLEAF_INVITE_TOKEN_SECRET="$(openssl rand -base64 32)" \
  --from-literal=OVERLEAF_SESSION_SECRET="$(openssl rand -hex 32)" \
  --from-literal=WEB_API_PASSWORD="$(openssl rand -hex 32)" \
  --from-literal=STAGING_PASSWORD="$HISTORY" \
  --from-literal=V1_HISTORY_PASSWORD="$HISTORY" \
  --from-literal=CRYPTO_RANDOM="$(openssl rand -hex 32)" \
  --from-literal=OT_JWT_AUTH_KEY="$(openssl rand -hex 32)"
```

| Secret                                         | Warum                                                                                                                                                |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_INVITE_TOKEN_SECRET`                 | Erforderlich. Ohne dieses Secret stoppt der Pod mit "Missing required secrets". Eine Änderung macht ausstehende Projekteinladungen ungültig.          |
| `OVERLEAF_SESSION_SECRET`                      | Signiert die Sitzungs-Cookies. Ohne dieses Secret meldet jeder Neustart des Pods alle Benutzer ab.                                                   |
| `WEB_API_PASSWORD`, `CRYPTO_RANDOM`, `OT_JWT_AUTH_KEY` | Interne Secrets. Der Container erzeugt sie bei jedem Start, wenn sie fehlen; bei mehr als einem Replikat müssen alle Replikate sie gemeinsam nutzen. |
| `STAGING_PASSWORD` und `V1_HISTORY_PASSWORD`   | Internes Verlaufs-Secret; beide müssen **denselben** Wert haben.                                                                                     |

<Warning>

Sichern Sie das Secret (`kubectl -n overleaf get secret overleaf-secrets -o yaml`) zusammen mit Ihren Daten. Funktionen, die Token in MongoDB verschlüsseln, benötigen ebenfalls eigene Verschlüsselungspasswörter in diesem Secret, zum Beispiel `GITHUB_TOKEN_CIPHER_PASSWORD` für die [GitHub-Synchronisierung](/de/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation).

</Warning>
