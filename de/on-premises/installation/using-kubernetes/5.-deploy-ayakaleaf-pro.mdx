```yaml title="40-overleaf.yaml" wrap
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: overleaf-data
  namespace: overleaf
spec:
  accessModes: [ReadWriteOnce]
  resources:
    requests:
      storage: 20Gi
---
apiVersion: apps/v1
kind: Deployment
metadata:
  name: overleaf
  namespace: overleaf
spec:
  replicas: 1
  strategy:
    type: Recreate          # one pod owns the data volume; never run two at once
  selector:
    matchLabels:
      app: overleaf
  template:
    metadata:
      labels:
        app: overleaf
    spec:
      terminationGracePeriodSeconds: 60   # time to flush pending edits, like the Toolkit
      # Keep the environment to what the ConfigMap and Secret set: no REDIS_PORT=tcp://... and the like
      enableServiceLinks: false
      containers:
        - name: sharelatex
          image: ghcr.io/ayaka-notes/overleaf-pro:6.3.2
          envFrom:
            - configMapRef:
                name: overleaf-env
            - secretRef:
                name: overleaf-secrets
          ports:
            - containerPort: 80
          readinessProbe:
            httpGet:
              path: /status
              port: 80
            periodSeconds: 10
          resources:
            requests:
              cpu: 500m
              memory: 1536Mi
            limits:
              memory: 3Gi
          volumeMounts:
            - name: data
              mountPath: /var/lib/overleaf
            - name: compiles
              mountPath: /var/lib/overleaf/data/compiles
            - name: output
              mountPath: /var/lib/overleaf/data/output
            - name: cache
              mountPath: /var/lib/overleaf/data/cache
            - name: docker-sock
              mountPath: /var/run/docker.sock
      volumes:
        - name: data
          persistentVolumeClaim:
            claimName: overleaf-data
        # Compile scratch space on the node; same paths as SANDBOXED_COMPILES_HOST_DIR_*
        - name: compiles
          hostPath:
            path: /srv/overleaf/compiles
            type: DirectoryOrCreate
        - name: output
          hostPath:
            path: /srv/overleaf/output
            type: DirectoryOrCreate
        - name: cache
          hostPath:
            path: /srv/overleaf/cache
            type: DirectoryOrCreate
        - name: docker-sock
          hostPath:
            path: /var/run/docker.sock
            type: Socket
---
apiVersion: v1
kind: Service
metadata:
  name: overleaf
  namespace: overleaf
spec:
  type: NodePort
  selector:
    app: overleaf
  ports:
    - name: http
      port: 80
      targetPort: 80
      nodePort: 30080
```

```bash
kubectl apply -f 40-overleaf.yaml
kubectl -n overleaf rollout status deployment/overleaf --timeout=10m
kubectl -n overleaf logs deployment/overleaf | grep -E 'Finished migrations|Missing required'
```

Der erste Start führt die Datenbankmigrationen aus und dauert ein bis zwei Minuten. Der Pod ist bereit, wenn `/status` antwortet; öffnen Sie dann `OVERLEAF_SITE_URL`.

### Warum das Manifest so aussieht

* <strong>Daten-Volume.</strong> Alles unter `/var/lib/overleaf` (Projektdateien, Verlauf, Uploads) liegt auf dem PVC. Mit knotenlokalem Speicher wie local-path bleiben die Daten auf einem Knoten; mit Netzwerk-Blockspeicher kann der Pod zwischen Knoten wechseln.
* <strong>Kompilierungs-Volumes und der Docker-Socket.</strong> Ayakaleaf Pro weist den Docker des Knotens an, einen TeX Live-Container zu starten, und übergibt ihm das Kompilierungsverzeichnis des Projekts **über dessen Pfad auf dem Knoten**. Diese Verzeichnisse sind daher `hostPath`-Volumes, und ihre Pfade werden in `SANDBOXED_COMPILES_HOST_DIR_*` wiederholt. Ihr Inhalt sind temporäre Daten, die keine Sicherung benötigen.
* <strong>`enableServiceLinks: false`.</strong> Kubernetes fügt jedem Pod Variablen im Docker-Stil für jeden Service des Namespace hinzu: Aus dem Service `redis` wird `REDIS_PORT=tcp://10.x.x.x:6379`, aus dem Service `git-bridge` `GIT_BRIDGE_PORT=tcp://...`. Einige Overleaf-Dienste lesen Variablen mit diesen Namen. In diesem Pod haben die Einstellungen aus `OVERLEAF_REDIS_*` und der ConfigMap Vorrang, aber git-bridge übernimmt `GIT_BRIDGE_PORT` als Port und stoppt (siehe [Git-Integration](/de/on-premises/configuration/kubernetes/integrations/git-integration)). Das Deaktivieren der Links beschränkt die Umgebung auf das, was Sie festlegen.
* <strong>`Recreate`.</strong> Zwei Pods dürfen nie dasselbe Daten-Volume verwenden oder gleichzeitig Migrationen ausführen.
* <strong>Bereitstellung nach außen.</strong> Der NodePort-Service antwortet auf Port `30080` jedes Knotens. Schalten Sie in der Produktion Ihren Ingress-Controller oder Load Balancer davor und terminieren Sie TLS dort; er muss WebSockets, Anfrage-Timeouts von 10 Minuten (lange Kompilierungen) und Uploads von 50 MB zulassen sowie `X-Forwarded-For` und `X-Forwarded-Proto` weitergeben.
