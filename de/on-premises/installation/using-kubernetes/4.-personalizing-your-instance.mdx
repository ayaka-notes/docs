---
title: 4. Ihre Instanz personalisieren
description: Legen Sie Ihre Einstellungen in der ConfigMap ab, die config/variables.env ersetzt.
icon: square-sliders
---

Die ConfigMap `overleaf-env` tritt an die Stelle von `config/variables.env` des Toolkits: Jede Umgebungsvariable aus der [Toolkit-Dokumentation](/de/on-premises/configuration/overleaf-toolkit/environment-variables) gehört hierher, und Secrets gehören in das Secret aus [Schritt 2](/de/on-premises/installation/using-kubernetes/2.-create-the-namespace-and-secrets).

```yaml title="30-config.yaml" wrap
apiVersion: v1
kind: ConfigMap
metadata:
  name: overleaf-env
  namespace: overleaf
data:
  OVERLEAF_APP_NAME: Ayakaleaf Pro
  OVERLEAF_SITE_URL: http://192.0.2.10:30080      # the address users open; https://... behind TLS
  OVERLEAF_ADMIN_EMAIL: admin@example.com
  # Emails: add the sender and the SMTP server together, see Email delivery
  # All members, so that the driver finds the primary even when mongo-0 is down
  OVERLEAF_MONGO_URL: mongodb://mongo-0.mongo:27017,mongo-1.mongo:27017,mongo-2.mongo:27017/sharelatex?replicaSet=overleaf
  OVERLEAF_REDIS_HOST: redis
  REDIS_HOST: redis
  ENABLED_LINKED_FILE_TYPES: project_file,project_output_file,url
  ENABLE_CONVERSIONS: "true"
  EMAIL_CONFIRMATION_DISABLED: "true"
  # Requests arrive from kube-proxy or your ingress controller, inside the pod network
  OVERLEAF_TRUSTED_PROXY_IPS: loopback,10.244.0.0/16
  # Sandboxed compiles. The HOST_DIR paths are paths ON THE NODE: the hostPath volumes that
  # the Deployment mounts at /var/lib/overleaf/data/{compiles,output,cache}.
  SANDBOXED_COMPILES: "true"
  SANDBOXED_COMPILES_SIBLING_CONTAINERS: "true"
  DOCKER_RUNNER: "true"
  SANDBOXED_COMPILES_HOST_DIR_COMPILES: /srv/overleaf/compiles
  SANDBOXED_COMPILES_HOST_DIR_OUTPUT: /srv/overleaf/output
  SANDBOXED_COMPILES_HOST_DIR_CACHE: /srv/overleaf/cache
  # Each image must be pulled into Docker on every node that can run Ayakaleaf Pro (step 0)
  ALL_TEX_LIVE_DOCKER_IMAGES: ghcr.io/ayaka-notes/texlive-full:2026.1
  ALL_TEX_LIVE_DOCKER_IMAGE_NAMES: TeX Live 2026
  TEX_LIVE_DOCKER_IMAGE: ghcr.io/ayaka-notes/texlive-full:2026.1
```

```bash
kubectl apply -f 30-config.yaml
```

| Variable                                | Wert                                                                                                                                                            |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_SITE_URL`                     | Die URL, die Benutzer im Browser eingeben. Mit dem NodePort aus [Schritt 5](/de/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro) die IP eines beliebigen Knotens und Port `30080`; hinter einem Ingress oder Load Balancer dessen URL. |
| `OVERLEAF_MONGO_URL`                    | Ihr Replikatset. Verwenden Sie `?replicaSet=` mit dem Namen aus `rs.initiate`.                                                                                 |
| `OVERLEAF_REDIS_HOST` und `REDIS_HOST`  | Beide auf den Redis-Service.                                                                                                                                   |
| `OVERLEAF_TRUSTED_PROXY_IPS`            | `loopback` plus die Netzwerke, aus denen sich Ihre Proxys verbinden. `10.244.0.0/16` ist das Pod-Netzwerk von flannel; verwenden Sie das Pod-CIDR Ihres Clusters. |
| `SANDBOXED_COMPILES_HOST_DIR_*`         | Die Knotenpfade der Kompilierungs-Volumes. Sie müssen mit den `hostPath`-Volumes in [Schritt 5](/de/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro) übereinstimmen. |

Hinter HTTPS setzen Sie außerdem `OVERLEAF_SECURE_COOKIE: "true"`, siehe [TLS-Proxy](/de/on-premises/configuration/overleaf-toolkit/tls-proxy).

<Info>

Eine geänderte ConfigMap erreicht laufende Pods erst nach einem Neustart: `kubectl -n overleaf rollout restart deployment/overleaf`.

</Info>
