Overleaf läuft auf Docker. Sie müssen Folgendes installieren:

* Docker Engine (Docker CE)
* Docker Compose-Plugin (`docker compose`, v2)

Diese Schritte richten sich an eine aktuelle Ubuntu-LTS-Version (20.04/22.04/24.04).

<Warning>

Vermeiden Sie die Installation von `docker.io` aus dem Standard-apt-Repository von Ubuntu.\
Verwenden Sie das offizielle Docker-Repository, damit Sie eine aktuelle Docker-Version und das `docker compose`-Plugin erhalten.

</Warning>

Die offizielle Dokumentation finden Sie unter: [https://docs.docker.com/engine/install/ubuntu/](https://docs.docker.com/engine/install/ubuntu/).

<Steps>
<Step title="1) Alte/konfliktverursachende Pakete entfernen (falls vorhanden)">
Wenn Docker zuvor aus einer anderen Quelle installiert wurde, entfernen Sie es zuerst:

```bash wrap
sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-compose-v2 docker-doc podman-docker containerd runc | cut -f1)
```

Dieser Befehl ist auch dann sicher, wenn einige Pakete nicht installiert sind.
</Step>

<Step title="2) Offizielles apt-Repository von Docker hinzufügen">
Installieren Sie die Voraussetzungen:

```bash
sudo apt update
sudo apt install -y ca-certificates curl
```

Fügen Sie den Docker-GPG-Schlüssel hinzu:

```bash wrap
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```

Fügen Sie das Repository hinzu:

```bash wrap
# Add the repository to Apt sources:
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Signed-By: /etc/apt/keyrings/docker.asc
EOF

sudo apt update
```
</Step>

<Step title="3) Docker Engine + Compose-Plugin installieren">
Installieren Sie Docker und das Compose-Plugin:

```bash wrap
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

Starten Sie Docker beim Systemstart:

```bash
sudo systemctl enable --now docker
```
</Step>

<Step title="4) Installation überprüfen">
Diese Befehle sollten ohne Fehler ausgeführt werden:

```bash
docker --version
docker compose version
sudo docker run --rm hello-world
docker ps
```
</Step>

<Step title="5) (Optional) Docker ohne sudo ausführen">
Fügen Sie Ihren Benutzer zur Gruppe `docker` hinzu:

```bash
sudo usermod -aG docker $USER
```

Melden Sie sich anschließend **ab und wieder an**, oder führen Sie Folgendes aus:

```bash
newgrp docker
```

Nun sollte dies ohne `sudo` funktionieren:

```bash
docker ps
```

<Danger>

Die Gruppe `docker` hat auf dem Host Zugriffsrechte, die root entsprechen.\
Das ist bei typischen Overleaf-Installationen so vorgesehen und besonders relevant, wenn Sie Sandboxed Compiles aktivieren.

</Danger>
</Step>
</Steps>
