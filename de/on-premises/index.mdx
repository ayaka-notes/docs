### Überblick über Overleaf

Overleaf ist ein kollaborativer LaTeX-Editor, der bei Forschenden und Tech-Teams sehr beliebt ist. Die Cloud-Version ist unter [overleaf.com](https://www.overleaf.com/) verfügbar und bietet einen voll ausgestatteten Online-LaTeX-Editor. Overleaf Common (SaaS-Version) unterliegt jedoch zahlreichen Funktionseinschränkungen, und Sie müssen ein _**Kompilierungszeitlimit von 10 Sekunden**_ sowie teure Mitgliedsgebühren in Kauf nehmen.

Overleaf bietet zwar eine Open-Source-Community-Version an (verfügbar auf [GitHub: Overleaf](https://github.com/overleaf/overleaf)), diese hat jedoch ebenfalls viele Einschränkungen, zum Beispiel:

<Warning>

Die Overleaf Community Edition ist für Umgebungen gedacht, in denen **allen** Benutzern vertraut wird. Die Community Edition ist **nicht** für Szenarien geeignet, in denen eine Isolation der Benutzer erforderlich ist, da Sandbox Compiles nicht verfügbar sind.

Ohne Sandboxing laufen LaTeX-Kompilierungen mit denselben Rechten wie der Container und haben Zugriff auf dessen Dateisystem, Netzwerk und Umgebungsvariablen. Dies birgt das Risiko einer Datenoffenlegung oder einer Kompromittierung des Systems. Kompilierungen ohne Sandbox sollten nur in vollständig vertrauenswürdigen Umgebungen verwendet werden; für Mehrbenutzer- oder Produktionsumgebungen werden Sandbox Compiles dringend empfohlen.

Weitere Informationen zu Sandbox Compiles finden Sie unter: [sandboxed-compiles.md](/de/on-premises/configuration/overleaf-toolkit/sandboxed-compiles  "mention")

</Warning>

### Informationen und Preise zu Overleaf Server Pro

Die Overleaf-Website bietet für Server Pro lediglich eine Möglichkeit zur Kontaktaufnahme mit dem Support, daher sind Informationen zu Server Pro sehr begrenzt. Basierend auf den in der Community gesammelten Informationen gelten für **Server Pro folgende Konditionen**:

* Sie müssen Lizenzen für _mindestens_ 10 Personen erwerben.
* Eine Lizenz für 10 Personen kostet etwa 3.477,61 €. (2024)
* Für Bildungseinrichtungen kosten 20 Benutzer 2640 Euro pro Jahr, 50 Benutzer 6050 Euro und 100 Benutzer 9963 Euro.
* Server Pro ist nur in ausgewählten Regionen verfügbar (z. B. nicht in Festlandchina).

Nach den derzeit verfügbaren Informationen kostet Overleaf Server Pro etwa \$300 pro Benutzer und Jahr bei einer Mindestabnahme von 10 Lizenzen und ist damit eine sehr teure Option. Zudem bietet Server Pro deutlich weniger Funktionen als Ayakaleaf Pro. Wir sind den Community-Entwicklern zutiefst dankbar, deren Beiträge über die Jahre es uns ermöglicht haben, Ayakaleaf Pro zu entwickeln und Overleaf Server Pro sowohl in Funktionalität als auch in Leistungsfähigkeit zu übertreffen.

Die folgenden öffentlichen Aufzeichnungen dokumentieren Käufe und Preise von Overleaf Server Pro. Kleinere US-Verträge weisen jährliche Kosten von etwa \$320–\$370 pro Benutzer aus. Große institutionelle Vereinbarungen können niedrigere Preise pro Benutzer erhalten. So liegt die dreijährige Vereinbarung der Max-Planck-Gesellschaft im Durchschnitt bei etwa 51 € pro Benutzer und Jahr. Vertragsbedingungen, Support und Umfang des Deployments können abweichen. Diese Aufzeichnungen sind keine offizielle Preisliste von Overleaf.

### Warum Ayakaleaf Pro?

<Info>

Ayakaleaf Pro steht in _**keiner**_ Verbindung zu Overleaf, Inc. oder deren Muttergesellschaft Digital Science. Es ist auch _nicht die Server Pro_ Edition, ein kommerzielles Produkt von Overleaf, Inc. [ayaka-notes](https://github.com/ayaka-notes) entwickelt und pflegt Ayakaleaf Pro als unabhängiges Projekt.

</Info>

Ayakaleaf Pro ist eine erweiterte Implementierung der Overleaf Community Edition und bietet _**alle**_ Premium-Funktionen von Server Pro _**kostenlos**_. Im Gegensatz zu Overleaf Common unter [https://www.overleaf.com/](https://www.overleaf.com/) oder der kommerziellen Edition Server Pro gibt es bei uns

* _**keine Begrenzung**_ der Kompilierungszeit
* _**keine Lizenzpflicht**_ in Abhängigkeit von der Anzahl der Benutzer
* _**alle Funktionen**_ von Server Pro freigeschaltet
