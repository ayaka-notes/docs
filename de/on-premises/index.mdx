### Überblick über Overleaf

Overleaf ist ein kollaborativer LaTeX-Editor, der bei Forschenden und Tech-Teams sehr beliebt ist. Die Cloud-Version ist unter [overleaf.com](https://www.overleaf.com/) verfügbar und bietet einen voll ausgestatteten Online-LaTeX-Editor. Overleaf Common (die SaaS-Version) unterliegt jedoch zahlreichen Funktionseinschränkungen, und Sie müssen ein _**Kompilierungszeitlimit von 10 Sekunden**_ sowie teure Mitgliedsgebühren in Kauf nehmen.

Overleaf bietet zwar eine Open-Source-Community-Version an (verfügbar auf [GitHub: Overleaf](https://github.com/overleaf/overleaf)), doch auch diese hat viele Einschränkungen, zum Beispiel:

<Warning>

Die Overleaf Community Edition ist für Umgebungen gedacht, in denen **allen** Nutzern vertraut wird. Die Community Edition ist **nicht** für Szenarien geeignet, in denen eine Isolation der Nutzer erforderlich ist, da Sandbox Compiles nicht verfügbar sind.

Ohne Sandboxing laufen LaTeX-Kompilierungen mit denselben Rechten wie der Container und haben Zugriff auf dessen Dateisystem, Netzwerk und Umgebungsvariablen. Das birgt das Risiko einer Offenlegung von Daten oder einer Kompromittierung des Systems. Kompilierungen ohne Sandbox sollten nur in vollständig vertrauenswürdigen Umgebungen eingesetzt werden; für Mehrbenutzer- oder Produktionsbereitstellungen werden Sandbox Compiles dringend empfohlen.

Weitere Informationen zu Sandbox Compiles finden Sie unter: [sandboxed-compiles.md](/de/on-premises/configuration/overleaf-toolkit/sandboxed-compiles  "mention")

</Warning>

### Informationen und Preise zu Overleaf Server Pro

Die Overleaf-Website bietet für Server Pro lediglich eine Kontaktmöglichkeit zum Support, daher sind Informationen über Server Pro sehr begrenzt. Basierend auf den Informationen, die wir in der Community gesammelt haben, gelten für **Server Pro folgende Konditionen**:

* Sie müssen Lizenzen für _mindestens_ 10 Personen erwerben.
* Eine Lizenz für 10 Personen kostet etwa 3.477,61 €. (2024)
* Im Bildungsbereich kosten 20 Nutzer 2.640 Euro pro Jahr, 50 Nutzer 6.050 Euro und 100 Nutzer 9.963 Euro.
* Server Pro ist nur in ausgewählten Regionen erhältlich (z. B. nicht in Festlandchina).

Nach den derzeit verfügbaren Informationen kostet Overleaf Server Pro etwa \$300 pro Nutzer und Jahr bei einer Mindestabnahme von 10 Lizenzen – eine sehr teure Option. Zudem bietet Server Pro deutlich weniger Funktionen als Ayakaleaf Pro. Wir sind den Community-Entwicklern zutiefst dankbar, deren Beiträge über die Jahre es uns ermöglicht haben, Ayakaleaf Pro zu entwickeln und Overleaf Server Pro sowohl in Funktionalität als auch in Leistungsfähigkeit letztlich zu übertreffen.

Die folgenden öffentlichen Aufzeichnungen dokumentieren Käufe und Preise von Overleaf Server Pro. Kleinere US-Verträge deuten auf jährliche Kosten von etwa \$320–\$370 pro Nutzer hin. Große institutionelle Vereinbarungen können niedrigere Preise pro Nutzer erhalten. So liegt beispielsweise die dreijährige Vereinbarung der Max-Planck-Gesellschaft bei durchschnittlich etwa 51 € pro Nutzer und Jahr. Vertragsbedingungen, Support und Bereitstellungsumfang können variieren. Diese Aufzeichnungen sind keine offizielle Preisliste von Overleaf.

### Warum Ayakaleaf Pro?

<Info>

Ayakaleaf Pro steht in _**keiner**_ Verbindung zu Overleaf, Inc. oder dessen Muttergesellschaft Digital Science. Es ist auch _nicht die Server Pro_ Edition, ein kommerzielles Produkt von Overleaf, Inc. [ayaka-notes](https://github.com/ayaka-notes) entwickelt und pflegt Ayakaleaf Pro als unabhängiges Projekt.

</Info>

Ayakaleaf Pro ist eine erweiterte Implementierung der Overleaf Community Edition und bietet _**alle**_ Premium-Funktionen von Server Pro _**kostenlos**_. Anders als bei Overleaf Common unter [https://www.overleaf.com/](https://www.overleaf.com/) oder der kommerziellen Edition Server Pro gibt es bei uns

* _**keine Begrenzung**_ der Kompilierungszeit
* _**keine Lizenzpflicht**_ in Abhängigkeit von der Nutzerzahl
* _**alle Funktionen**_ von Server Pro freigeschaltet
