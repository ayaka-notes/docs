description: Die minimale und maximale Länge lokaler Passwörter in einem Kubernetes-Deployment festlegen.
icon: key
---

Der **web**-Dienst prüft lokale Passwörter, wenn Benutzer sich registrieren oder ein Passwort festlegen oder ändern. SSO-Anmeldungen (LDAP, SAML, OIDC) sind nicht betroffen; deren Passwörter sind Sache des Identitätsanbieters. Siehe [Passwortbeschränkungen](/de/on-premises/configuration/overleaf-toolkit/authentication/password-restrictions) für das Toolkit.

| | |
| --- | --- |
| Dienst | web, in jedem Ayakaleaf-Pro-Pod; beim Start von web gelesen |
| Netzwerk | keines |
| Periodische Jobs | keine |

### Konfiguration

Fügen Sie Folgendes zur ConfigMap `overleaf-env` hinzu und starten Sie neu:

```yaml title="30-config.yaml (additions)"
  OVERLEAF_PASSWORD_VALIDATION_MIN_LENGTH: "12"
  OVERLEAF_PASSWORD_VALIDATION_MAX_LENGTH: "72"
```

```bash
kubectl apply -f 30-config.yaml
kubectl -n overleaf rollout restart deployment/overleaf     # or statefulset/overleaf
```

| Variable | Standard | |
| --- | --- | --- |
| `OVERLEAF_PASSWORD_VALIDATION_MIN_LENGTH` | `8` | Kürzestes akzeptiertes Passwort. |
| `OVERLEAF_PASSWORD_VALIDATION_MAX_LENGTH` | `72` | Längstes akzeptiertes Passwort; Werte über `72` werden als `72` behandelt. |

Setzen Sie die Zahlen in Anführungszeichen: Eine ConfigMap enthält nur Zeichenketten.

<Warning>

`OVERLEAF_PASSWORD_VALIDATION_PATTERN` wird gelesen, aber nicht durchgesetzt: Ein Passwort, das nicht dazu passt, wird akzeptiert. Es gelten nur die Längenbeschränkungen.

</Warning>

### Mehrere Replikate

Nichts weiter: Jedes Replikat liest dieselbe ConfigMap.

### Getestet auf Kubernetes

Auf Kubernetes 1.37 mit einem Replikat sowie `OVERLEAF_PASSWORD_VALIDATION_MIN_LENGTH: "12"` und `OVERLEAF_PASSWORD_VALIDATION_PATTERN: aA$3` in der ConfigMap lehnte die Aktivierung eines neuen Kontos ein Passwort mit 10 Zeichen ab und akzeptierte ein Passwort mit 20 Zeichen aus ausschließlich Kleinbuchstaben, das das Muster abgelehnt hätte. Unsere End-to-End-Tests für die Registrierung lehnen außerdem mit den Standardwerten `123456` als zu kurz ab.
