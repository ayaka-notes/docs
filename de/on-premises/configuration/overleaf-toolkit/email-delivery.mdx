Overleaf unterstützt den E-Mail-Versand über zwei Methoden: Simple Mail Transfer Protocol (SMTP) und [Amazon Simple Email Service (SES)](https://aws.amazon.com/ses/). SMTP kann verwendet werden, wenn auf Ihrem localhost ein E-Mail-Server läuft, der auf lokale Verbindungen wartet.

## Konfiguration

E-Mail wird über die folgenden Umgebungsvariablen konfiguriert.

#### Absenderkonfiguration

| Name                          | Beschreibung                                                                                                                                         |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | <p>Die Absenderadresse, z. B. <a href="mailto:support@mycompany.com">`'support@mycompany.com'`</a><br /><br />- <strong>Erforderlich</strong>: ja</p> |
| `OVERLEAF_EMAIL_REPLY_TO`     | Die Antwortadresse, z. B. `'noreply@mycompany.com'`                                                                                                  |

#### SMTP

| Name                                    | Beschreibung                                                                                                                                                                                                                                                             |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST`              | Der Hostname oder die IP-Adresse, zu der eine Verbindung hergestellt werden soll. Muss vom Docker-Container aus erreichbar sein                                                                                                                                         |
| `OVERLEAF_EMAIL_SMTP_PORT`              | Der Port, zu dem eine Verbindung hergestellt werden soll                                                                                                                                                                                                                 |
| `OVERLEAF_EMAIL_SMTP_SECURE`            | Bei `true` verwendet die Verbindung TLS beim Verbinden mit dem Server. Bei `false` oder wenn nicht gesetzt, wird TLS verwendet, sofern der Server die Erweiterung `STARTTLS` unterstützt. In den meisten Fällen setzen Sie diesen Wert auf `true`, wenn Sie sich mit Port `465` verbinden. Für Port `587` oder `25` belassen Sie ihn auf `false` |
| `OVERLEAF_EMAIL_SMTP_USER`              | Der Benutzername, mit dem sich am SMTP-Server authentifiziert werden soll                                                                                                                                                                                                |
| `OVERLEAF_EMAIL_SMTP_PASS`              | Das zum SMTP-Benutzernamen gehörende Passwort                                                                                                                                                                                                                            |
| `OVERLEAF_EMAIL_SMTP_TLS_REJECT_UNAUTH` | Bei `false` wird auch eine Verbindung zu einem TLS-Server mit selbstsigniertem oder ungültigem TLS-Zertifikat hergestellt                                                                                                                                               |
| `OVERLEAF_EMAIL_SMTP_IGNORE_TLS`        | Wenn `true` und `OVERLEAF_EMAIL_SMTP_SECURE` auf `false` gesetzt ist, wird TLS nicht verwendet, selbst wenn der Server die Erweiterung `STARTTLS` unterstützt                                                                                                           |
| `OVERLEAF_EMAIL_SMTP_NAME`              | Optionaler Hostname für die TLS-Validierung, falls `OVERLEAF_EMAIL_SMTP_HOST` auf eine IP-Adresse gesetzt wurde; standardmäßig der Hostname des Rechners.                                                                                                              |
| `OVERLEAF_EMAIL_SMTP_LOGGER`            | Bei `true` werden Log-Meldungen in `web.log` ausgegeben.                                                                                                                                                                                                                 |

#### Amazon-SES-SMTP-Schnittstelle

Mehr über den E-Mail-Versand über die Amazon-SES-SMTP-Schnittstelle erfahren Sie [hier](https://docs.aws.amazon.com/ses/latest/dg/send-email-smtp.html).

| Name                       | Beschreibung                                                                               |
| -------------------------- | ------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST` | Der Hostname oder die IP-Adresse, zu der eine Verbindung hergestellt werden soll. Muss vom Docker-Container aus erreichbar sein |
| `OVERLEAF_EMAIL_SMTP_PORT` | Der Port, zu dem eine Verbindung hergestellt werden soll                                   |
| `OVERLEAF_EMAIL_SMTP_USER` | Der Benutzername, mit dem sich am SMTP-Server authentifiziert werden soll                  |
| `OVERLEAF_EMAIL_SMTP_PASS` | Das zum SMTP-Benutzernamen gehörende Passwort                                              |

#### Amazon SES API

Mehr über den E-Mail-Versand über die Amazon SES API erfahren Sie [hier](https://docs.aws.amazon.com/ses/latest/dg/send-email-api.html).

| Name                                   | Beschreibung                                    |
| -------------------------------------- | ----------------------------------------------- |
| `OVERLEAF_EMAIL_AWS_SES_ACCESS_KEY_ID` | Der Access Key bei Verwendung von AWS SES       |
| `OVERLEAF_EMAIL_AWS_SES_SECRET_KEY`    | Der Secret Key bei Verwendung von AWS SES       |
| `OVERLEAF_EMAIL_AWS_SES_REGION`        | Wenn nicht gesetzt, ist die Standardregion US-EAST-1 |

#### AWS SES mit Instanzrollen

| Name                    | Beschreibung                                                                                                                     |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_DRIVER` | Wenn dieser Wert auf `ses` gesetzt ist, verwendet das E-Mail-System die SES-API-Methode und nutzt die konfigurierten Instanzrollen zum Versenden von E-Mails. |
