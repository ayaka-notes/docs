Sie können Ihre Overleaf-Instanz auf drei Arten für Personen ohne Konto öffnen:

* [Projektzugriff](/de/on-premises/configuration/overleaf-toolkit/public-access#project-access  "mention"): Gäste können einen geteilten Projektlink öffnen, ohne sich anzumelden
* [Seitenzugriff](/de/on-premises/configuration/overleaf-toolkit/public-access#page-access  "mention"): Abgemeldete Besucher können Seiten wie `/learn`, `/templates` und `/devs` aufrufen
* [Öffentliche Registrierung](/de/on-premises/configuration/overleaf-toolkit/public-access#public-registration  "mention"): Benutzer können sich selbst registrieren, optional beschränkt auf eine E-Mail-Domain

### Project Access

<Info>

Standardmäßig muss sich ein Benutzer, selbst wenn er einen Freigabelink für ein Projekt erhält, erst **anmelden**, bevor er an der gemeinsamen Bearbeitung des Projekts teilnehmen kann.

</Info>

Um anonymen Zugriff auf per Link geteilte Projekte zu erlauben, setzen Sie beide der folgenden Variablen:

```dotenv title="config/variables.env"
OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING=true
OVERLEAF_ALLOW_PUBLIC_ACCESS=true
```

`OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` aktiviert anonymes Lesen/Schreiben für per Link geteilte Projekte.

`OVERLEAF_ALLOW_PUBLIC_ACCESS` verhindert, dass nicht authentifizierte Benutzer auf die Anmeldeseite umgeleitet werden.

Erstellen Sie die Container mit `bin/up` neu. Öffnen Sie anschließend eine Link-Freigabe-URL in einem privaten Fenster.

### Page Access

Standardmäßig (wenn `OVERLEAF_ALLOW_PUBLIC_ACCESS` nicht gesetzt ist) leitet **jede** Seite außer der Anmelde- und der Registrierungsseite abgemeldete Besucher auf die Anmeldeseite um. Das betrifft auch Seiten, die eigentlich öffentlich sein sollen, sodass Links darauf nur für bereits angemeldete Benutzer funktionieren.

Mit `OVERLEAF_ALLOW_PUBLIC_ACCESS=true` können abgemeldete Besucher Folgendes öffnen:

| Seite                                                                 | Voraussetzung                    |
| --------------------------------------------------------------------- | -------------------------------- |
| LaTeX-Hilfe unter `/learn` (siehe [adding-latex-user-help.md](/de/on-premises/configuration/overleaf-toolkit/adding-latex-user-help  "mention")) | `OVERLEAF_PROXY_LEARN=true`      |
| Die Vorlagengalerie unter `/templates`, Vorlagenseiten, Vorschauen und ZIP-Downloads (siehe [templates.md](/de/on-premises/configuration/overleaf-toolkit/templates  "mention")) | `OVERLEAF_TEMPLATE_GALLERY=true` |
| Die Seite der Overleaf Import API unter `/devs` (siehe [overleaf-import-api.md](/de/on-premises/configuration/overleaf-toolkit/overleaf-import-api  "mention")) | —                                |

Außerdem kann die [Overleaf Import API](/de/on-premises/configuration/overleaf-toolkit/overleaf-import-api#signed-out-visitors  "mention") ein Formular, das ein abgemeldeter Besucher abgeschickt hat, aufbewahren, bis er sich angemeldet hat.

Die Projektliste, der Editor und das Erstellen von Projekten (auch aus einer Vorlage oder über die Import API) erfordern weiterhin eine Anmeldung.

### Public Registration

Die öffentliche Registrierung ist nur in [ayaka-notes/overleaf-pro](https://github.com/ayaka-notes/overleaf-pro) verfügbar.

<Danger>

Bitte beachten Sie: Sobald Sie die öffentliche Registrierung aktivieren, kann sich **jeder**, der Zugriff auf Ihre Overleaf-Instanz hat, als Benutzer registrieren.

Bei der Registrierung werden E-Mail-Adressen nicht verifiziert. Verwenden Sie sie daher nur in einem Intranet oder einer vertrauenswürdigen Umgebung, oder deaktivieren Sie sie, wenn Sie die Registrierung nicht mehr benötigen.

</Danger>

Standardmäßig erlauben weder die Community Edition noch Overleaf Pro eine öffentliche Registrierung.

Um sie zu aktivieren, fügen Sie Folgendes zu `config/variables.env` hinzu:

```dotenv title="config/variables.env"
OVERLEAF_ALLOW_PUBLIC_REGISTRATION=true
```

Erstellen Sie die Container mit `bin/up` neu.

Klicken Sie dann auf **Sign up** oder rufen Sie `/register` auf.

### Registrierung mit eingeschränkter Domain

Die öffentliche Registrierung mit Domain-Beschränkung ist nur in [ayaka-notes/overleaf-pro](https://github.com/ayaka-notes/overleaf-pro) verfügbar.

Konfigurieren Sie vor der Aktivierung den E-Mail-Versand, damit Benutzer Einladungen und Benachrichtigungen erhalten können. Siehe [E-Mail-Versand](/de/on-premises/configuration/overleaf-toolkit/email-delivery).

Fügen Sie dann die folgende Zeile zu `config/variables.env` hinzu:

```dotenv title="config/variables.env" wrap
OVERLEAF_ALLOW_PUBLIC_REGISTRATION=@example.domain
```

`OVERLEAF_ALLOW_PUBLIC_REGISTRATION` kann folgende Werte haben:

* `true`, damit sich jeder registrieren kann, der die Website erreicht
* `@example.domain`, um die Registrierung auf E-Mail-Adressen dieser Domain zu beschränken
