Jedes Projekt hat einen MCP-Server, sodass KI-Clients wie Claude Code, Codex, Cursor, VS Code oder Gemini CLI daran arbeiten können: seine Dateien lesen und bearbeiten, es kompilieren, das LaTeX-Log lesen, das PDF herunterladen und Kommentare beantworten.

<Info>

Diese Funktion wurde von [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) entwickelt. Sie ist ab v6.3.1 verfügbar.

</Info>

### Einrichtung

Der MCP-Server ist Teil der Git-Integration: Aktivieren Sie [git-bridge](/de/on-premises/configuration/overleaf-toolkit/git-integration), dann ist auch der MCP-Server verfügbar. Weitere Konfiguration ist nicht erforderlich.

### Einen KI-Client verbinden

1. Erzeugen Sie in den **Kontoeinstellungen** ein Git-Authentifizierungstoken. Dasselbe Token wird für den MCP-Server und für Git verwendet.
2. Öffnen Sie im Editor **Integrations** und klicken Sie auf **MCP server**. Dort werden die Adresse des MCP-Servers des Projekts, `https://<your-overleaf>/project/<project_id>/mcp`, sowie die Anleitung zum Hinzufügen zu jedem KI-Client angezeigt: Kopieren Sie den Befehl und ersetzen Sie `<token>` durch Ihr Token.

### Verwendung

Sobald die Verbindung steht, formulieren Sie Ihre Anfragen an den KI-Client in normaler Sprache. Zum Beispiel:

| Ihre Anfrage | Der KI-Client verwendet |
| --- | --- |
| _Korrigiere die Tippfehler in der Einleitung._ | `read_file`, `edit_file`: Die Änderungen erscheinen live im Editor |
| _Kompiliere das Projekt und behebe die LaTeX-Fehler._ | `compile`, `get_compile_log`, `edit_file` |
| _Beantworte die offenen Kommentare und schließe sie dann._ | `list_comments`, `reply_to_comment`, `resolve_comment` |
| _Wechsle zu XeLaTeX und lade das PDF herunter._ | `update_settings`, `compile`, `get_output_file_link` |

### Tools

| Gruppe | Tools |
| --- | --- |
| Projekt | `get_clone_info`, `get_settings`, `update_settings`, `list_versions` |
| Dateien | `list_files`, `read_file`, `edit_file`, `write_file`, `delete_file` |
| Kompilierung | `compile`, `get_compile_log`, `get_output_file_link`, `word_count` |
| Kommentare | `list_comments`, `reply_to_comment`, `resolve_comment`, `reopen_comment` |

Mit `edit_file` und `write_file` vorgenommene Änderungen erscheinen live im Editor und werden mit denen der Mitarbeitenden zusammengeführt. Für viele Dateien auf einmal, Binärdateien oder Umbenennungen kann der KI-Client das Projekt auch mit Git klonen und pushen.

### Berechtigungen

Der MCP-Server folgt wie Git den Freigabeeinstellungen des Projekts:

* Alle, die das Projekt ansehen können, können es lesen, kompilieren und seine Ausgabe herunterladen.
* Nur der Besitzer und Mitarbeitende mit Bearbeitungsrechten können seine Dateien und Einstellungen ändern.
* Reviewer können außerdem auf Kommentare antworten und die von ihnen begonnenen Kommentare schließen oder wieder öffnen.
* Betrachter, die über einen Link beigetreten sind, können die Kommentare nicht sehen, genau wie im Editor.
