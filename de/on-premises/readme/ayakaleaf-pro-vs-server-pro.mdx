<Info>

Ayakaleaf Pro ist eine erweiterte Implementierung der Overleaf Community Edition und bietet alle Premium-Funktionen von Server Pro _**kostenlos**_. Im Gegensatz zu Overleaf Common unter [https://www.overleaf.com/](https://www.overleaf.com/) gibt es bei uns keine Begrenzung der Kompilierungszeit und keine Lizenzpflicht in Abhängigkeit von der Anzahl der Benutzer, und Sie können Ihre Daten vollständig selbst hosten und so absolute Sicherheit gewährleisten.

Overleaf Server Pro ist ein kommerzielles, selbst gehostetes Deployment von Overleaf mit offiziellem Support. Weitere Informationen zu Server Pro finden Sie unter [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud).

</Info>

<Warning>

Die Overleaf Community Edition ist für Umgebungen gedacht, in denen **allen** Benutzern vertraut wird. Die Community Edition ist **nicht** für Szenarien geeignet, in denen eine Isolation der Benutzer erforderlich ist, da Sandbox Compiles nicht verfügbar sind.

Ohne Sandboxing laufen LaTeX-Kompilierungen mit denselben Rechten wie der Container und haben Zugriff auf dessen Dateisystem, Netzwerk und Umgebungsvariablen. Dies birgt das Risiko einer Datenoffenlegung oder einer Kompromittierung des Systems. Kompilierungen ohne Sandbox sollten nur in vollständig vertrauenswürdigen Umgebungen verwendet werden; für Mehrbenutzer- oder Produktionsumgebungen werden Sandbox Compiles dringend empfohlen.

Weitere Informationen zu Sandbox Compiles finden Sie in unserer [Dokumentation](/de/on-premises/configuration/overleaf-toolkit/sandboxed-compiles).

</Warning>

### Community-Support

Für Benutzer einer selbst gehosteten Overleaf-Instanz wird Support von der Community über GitHub [Issues](https://github.com/ayaka-notes/overleaf-pro/issues) geleistet.

Um auf einer unterstützten Version zu bleiben, können Sie überprüfen, welche Overleaf-Version Sie verwenden, indem Sie die Ausgabe des folgenden Befehls mit den in den Versionshinweisen veröffentlichten Image-IDs vergleichen.

```bash
docker inspect --format '{{.Image}}' sharelatex | awk -F: '{print substr($2, 1, 12)}'
```
