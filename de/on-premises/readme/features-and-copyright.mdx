Wir respektieren das Urheberrecht und führen daher hier alle Funktionen und den in diesem Projekt verwendeten Code auf. Auf dieser Seite finden Sie Informationen zu den neuen Funktionen von Ayakaleaf Pro und zu den Urheberrechten des zugehörigen Codes.

Sofern nicht anders angegeben, verwenden wir Codex von OpenAI für Code-Reviews und PR-Reviews. Dabei haben wir viele Sicherheitsprobleme behoben, wofür wir unseren aufrichtigen Dank aussprechen. Details finden Sie unter [ayaka-notes/ayakaleaf-pro/pull](https://github.com/ayaka-notes/ayakaleaf-pro/pulls).

### Überblick {#overview}

Im Laufe der Jahre haben viele Entwickler aus der Community erhebliche Anstrengungen unternommen, um die Overleaf Community Edition zu verbessern. Dazu gehören:

* [https://github.com/ertuil/overleaf](https://github.com/ertuil/overleaf)
* [https://github.com/AllanChain/lcpu-overleaf](https://github.com/AllanChain/lcpu-overleaf)

* [https://github.com/davrot/overleaf\_with\_admin\_extension](https://github.com/davrot/overleaf_with_admin_extension)

#### Funktion 05: Admin-Panel {#features-05-admin-panel}

<Warning>

Wenn Ihr System 1000 Benutzer oder Projekte hat, zeigt das Admin-Panel nur die neuesten 1000 Benutzer bzw. Projekte an. Bitte verwenden Sie das Suchfeld, um nach bestimmten Benutzern oder Projekten zu suchen.

</Warning>

Diese Funktion wurde hauptsächlich von [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep) entwickelt. Wir haben einigen Code zur Verbesserung angepasst, sodass Sie:

* Benutzer über das Backend suchen können, wenn Sie mehr als 1000 Benutzer haben.
* Projekte über das Backend suchen können, wenn Sie mehr als 1000 Projekte haben.
* Projekte direkt im Projekt-Admin-Panel öffnen können.
* Das Kompilierzeitlimit von Benutzern im Admin-Panel anzeigen und anpassen können.
* Das Passwort von Benutzern direkt im Admin-Panel zurücksetzen können.
* Weitere Verbesserungen ...

#### Funktion 13: Python Runner {#features-13-python-runner}

Diese Funktion wurde offiziell von Overleaf entwickelt. Sie können Python-Skripte in Ihrem Browser ausführen.

Sie ist integriert und erfordert keine Konfiguration: Öffnen Sie eine `.py`-Datei in einem Projekt und klicken Sie auf **Run**. Das Skript läuft mit Pyodide im Browser des Benutzers, daher stehen nur die integrierten Pakete von Pyodide zur Verfügung.

* Der Ausgabebereich unter dem Editor zeigt, was das Skript ausgibt (die letzten 100 Zeilen). Klicken Sie auf **Stop**, um einen Lauf abzubrechen. Jeder Lauf startet ein neues Python, sodass nichts vom vorherigen Lauf übernommen wird.
* Vor jedem Lauf werden die Textdateien des Projekts in den Arbeitsordner des Skripts kopiert, sodass das Skript sie über ihren Projektpfad öffnen kann, z. B. `open('data/results.csv')`. Binärdateien wie Bilder und PDFs werden nicht kopiert.
* Dateien, die das Skript in diesen Ordner schreibt, werden bei erfolgreichem Lauf unter demselben Pfad im Projekt gespeichert und ersetzen dabei eine gleichnamige Datei. Ein fehlgeschlagener Lauf speichert nichts. Ein Lauf darf bis zu 50 Dateien speichern, mit höchstens 50 MB pro Datei und 100 MB insgesamt.
* Matplotlib hat keine Anzeige: Speichern Sie Diagramme mit `plt.savefig('figure.png')` und binden Sie das Bild anschließend in Ihr LaTeX-Dokument ein.
* Pyodide und seine Pakete (wie NumPy, pandas, SciPy und Matplotlib) werden von Ihrer Instanz bereitgestellt, daher benötigt der Browser keinen Internetzugang. Mit pip installierte Pakete können nicht verwendet werden.

#### Funktion 17: Integration von Literaturverwaltungen {#features-17-reference-manager-integration}

Diese Funktion wurde von [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) entwickelt. Die Zotero-Integration wurde ursprünglich von [davrot](https://github.com/davrot) und [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep) entwickelt; wir haben sie in v6.3.0 mit OAuth überarbeitet und eine Mendeley-Integration (OAuth 2.0) hinzugefügt. Sie können:

* Ihre Zotero- und Mendeley-Konten in den Kontoeinstellungen verknüpfen.
* Ihre persönliche Bibliothek oder eine Gruppenbibliothek als `.bib`-Datei in Ihr Projekt importieren.
* Die importierte `.bib`-Datei jederzeit aktualisieren, um sie auf dem neuesten Stand zu halten.

Informationen zur Einrichtung finden Sie unter [Zotero-Integration](/de/on-premises/configuration/overleaf-toolkit/integrations/zotero-integration) und [Mendeley-Integration](/de/on-premises/configuration/overleaf-toolkit/integrations/mendeley-integration).

#### Funktion 18: Open-in-Overleaf-API {#features-18-open-in-overleaf-api}

Diese Funktion wurde von [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) entwickelt und ist mit der „Open in Overleaf“-API von overleaf.com kompatibel. Sie können Ihrer Website, Ihrem Blog oder Ihrer Vorlagenbibliothek einen „Open in Ayakaleaf“-Link oder -Button hinzufügen, sodass Besucher ein LaTeX-Snippet, eine entfernte Datei oder ein ZIP-Projekt mit einem Klick als neues Projekt in Ihrer Instanz öffnen können. Details finden Sie unter `/devs` auf Ihrer Instanz sowie unter [Overleaf-Import-API](/de/on-premises/configuration/overleaf-toolkit/integrations/overleaf-import-api).

#### Funktion 20: Dropbox-Synchronisierung {#features-20-dropbox-sync}

Diese Funktion wurde von [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) als Early Preview in v6.3.1 entwickelt (offizielle Veröffentlichung in v6.4.0), wie die Dropbox-Synchronisierung auf overleaf.com. Sobald ein Benutzer sein Dropbox-Konto verknüpft, erscheint jedes seiner Projekte als Ordner in seiner Dropbox: Änderungen in Overleaf werden an Dropbox gesendet, und in Dropbox vorgenommene Änderungen gelangen zurück zu Overleaf. Informationen zur Einrichtung finden Sie unter [Dropbox-Synchronisierung](/de/on-premises/configuration/overleaf-toolkit/integrations/dropbox-synchronisation).
