Hier haben wir Antworten auf einige häufig gestellte Fragen zu Ayakaleaf Pro zusammengestellt.

### Grundlegende Fragen

<Accordion title="Q01: Ist Ayakaleaf Pro eine kostenlose Testversion? Wird eine Lizenz benötigt?">

Nein. Ayakaleaf Pro ist vollständig kostenlos nutzbar. Es handelt sich nicht um eine Testversion, und es wird keine Lizenz benötigt.

</Accordion>

<Accordion title="Q02: Enthält Ayakaleaf Pro alle Funktionen von Overleaf Server Pro?">

Ja. Ayakaleaf Pro enthält alle Funktionen von Overleaf Server Pro, einschließlich der Git-Bridge-Integration. Außerdem enthält es ausgewählte Funktionen der Overleaf-SaaS-Plattform. Wir entwickeln Ayakaleaf Pro kontinuierlich weiter und verbessern es.

</Accordion>

<Accordion title="Q03: Wie viel kostet Overleaf Server Pro?">

Overleaf Server Pro kostet etwa \$300 pro Benutzer und Jahr. Es sind mindestens 10 Lizenzen erforderlich, sodass Deployments bei rund \$3.000 jährlich beginnen. Kleinere öffentliche Aufträge in den USA weisen jährliche Kosten von etwa \$320–\$370 pro Benutzer aus. Damit ist Server Pro teuer, insbesondere für kleinere Teams. Dokumentierte Käufe und Preise finden Sie unter [#information-and-price-about-overleaf-server-pro](/de/on-premises#information-and-price-about-overleaf-server-pro  "mention").

</Accordion>

<Accordion title="Q04: Warum enthält Overleaf Server Pro weder GitHub Sync noch KI-Funktionen?">

Overleaf Server Pro wird häufig von Behörden eingesetzt. Diese betreiben es in privaten Netzwerken und kontrollieren den Zugriff streng. Um sensible Daten zu schützen, vermeiden die enthaltenen Funktionen jeden Datenaustausch mit Diensten von Drittanbietern. Wenn Sie GitHub Sync, KI oder ähnliche vernetzte Funktionen benötigen, empfiehlt Overleaf ein Abonnement seiner SaaS-Plattform.

</Accordion>

<Accordion title="Q05: Ist Ayakaleaf Pro sicher und zuverlässig?">

Ayakaleaf Pro ist Open Source. Wir prüfen den Code mit Werkzeugen wie Codex Security, um Sicherheit und Zuverlässigkeit zu stärken. Wenn Sie keine Datensynchronisierung mit Drittanbietern aktivieren, bleiben Ihre Daten auf Ihrem Server. Ayakaleaf Pro enthält keine Telemetrie, die Ihre Daten an andere Stellen sendet.

</Accordion>

<Accordion title="Q06: Wird Ayakaleaf Pro langfristig gepflegt?">

Wir werden alles daransetzen, dieses Projekt langfristig zu pflegen.

</Accordion>

<Accordion title="Q07: Ist Ayakaleaf Pro lizenzkonform?">

Ayakaleaf Pro ist ein Community-Fork. Sein Code und die integrierten Funktionen stammen aus Beiträgen der Community. Es steht unter der AGPL v3. Deployments sind mit dieser Lizenz konform, wenn sie deren Anforderungen erfüllen.

</Accordion>

<Accordion title="Q08: Warum heißt das Projekt Ayakaleaf Pro?">

Das Projekt hieß ursprünglich im Jahr 2024 Overleaf Pro. Die Entwicklung ruhte eine Zeit lang und wurde Ende 2025 wieder aufgenommen. Im ersten Quartal 2026 benannte Overleaf seinen KI-fähigen Abonnementplan in Pro um. Zudem wies die Community darauf hin, dass der Name Overleaf Pro Risiken in Bezug auf Markenrecht und Verwechslung mit sich bringen könnte. Nutzer könnten annehmen, es handle sich um ein offizielles Projekt.

Wir haben das Projekt in Ayakaleaf Pro umbenannt, um diese Verwechslung zu vermeiden. Der Name lässt sich als „Ayaka-notes Overleaf Pro“ lesen. Der Maintainer trägt seit seiner Studienzeit, vor über fünf Jahren, zur Entwicklung der Overleaf-Community bei. Diese Erfahrung untermauert unser Bekenntnis zur langfristigen Pflege.

</Accordion>

<Accordion title="Q09: Was unterscheidet Ayakaleaf Pro von neueren, mit KI entwickelten LaTeX-Editoren?">

Seit 2026 hat die Open-Source-Community viele mit KI entwickelte LaTeX-Editoren veröffentlicht, darunter OpenAI Prism. Ayakaleaf Pro hält Ihre Daten und Dienste auf Ihrem eigenen Server. So behalten Sie die direkte Kontrolle über Ihr Deployment und Ihre Daten.

Viele experimentelle Community-Editoren haben keinen etablierten langfristigen Wartungsplan. Auch LaTeX-Kompilierungsplattformen von Drittanbietern können den Betrieb einstellen, wenn ihre Nutzerbasis oder ihre Einnahmen nicht ausreichen. Ayakaleaf Pro liefert den gesamten Quellcode und ermöglicht es Ihnen, jeden Dienst selbst zu hosten. Selbst wenn die Wartung eingestellt würde, könnte Ihr bestehender selbst gehosteter Dienst weiterlaufen.

</Accordion>

### LaTeX

<Accordion title="Q01: Sind die LaTeX-Kompilierungen der Benutzer voneinander isoliert? Ist Shell Escape aktiviert?">

Wenn Sie Sandbox Compiles aktivieren, läuft die Kompilierung jedes Benutzers in einem separaten Docker-Container und ist von den Kompilierungen anderer Benutzer isoliert. Shell Escape ist bei Sandbox Compiles standardmäßig aktiviert.

</Accordion>

<Accordion title="Q02: Ist das Sandbox-Compiles-Image zuverlässig? Kann die Kompilierung fehlschlagen?">

Wir haben unser TeX Live Full-Image für Sandbox Compiles in den letzten drei Jahren verbessert. In den meisten Fällen lassen sich Projekte, die auf overleaf.com kompilieren, auch mit Ayakaleaf Pro korrekt kompilieren. Wenn eine benötigte Schriftart nicht verfügbar ist, laden Sie diese Schriftart manuell in Ihr Projekt hoch.

</Accordion>
