Wir freuen uns, die Veröffentlichung von Ayakaleaf Pro 6.2 bekanntzugeben – des leistungsstärksten und funktionsreichsten Online-LaTeX-Editors der Community. Ein besonderer Dank geht an yu-i-i und davrot für ihre wertvollen Beiträge. Sie haben GitHub Sync verbessert sowie die erweiterte Literatursuche (Advanced Citation Search) und die Zotero-Integration eingeführt.

### Hinweise

* Eine neue, erforderliche Umgebungsvariable `OVERLEAF_INVITE_TOKEN_SECRET` wurde eingeführt. Sie müssen sie mit `openssl rand -base64 32` generieren. Ist sie nicht konfiguriert, startet Ihre Overleaf-Instanz nicht.
* Wenn Sie GitHub Sync aktivieren, müssen Sie die Umgebungsvariable `GITHUB_TOKEN_CIPHER_PASSWORD` konfigurieren. Diese Variable ist erforderlich, um GitHub-Zugriffstokens sicher zu verschlüsseln. Ohne sie startet Ihre Overleaf-Instanz nicht.
* Neue Umgebungsvariable `DEFAULT_LATEX_COMPILER` hinzugefügt, mit der der Standard-Compiler für neue Projekte festgelegt wird (pdflatex, latex, xelatex oder lualatex).
* Der neu gestaltete Editor ist jetzt die einzige verfügbare Option.

### Änderungen

Dieses Release enthält die folgenden Verbesserungen und neuen Funktionen.

* `MAX_UPLOAD_SIZE` ist jetzt konfigurierbar, statt auf **50 MB** begrenzt zu sein.
* Eine Container-Neustartschleife bei deaktivierten Sandboxed Compiles wurde behoben.
* Das Löschen von PATs für OAuth2 ist jetzt auf den Eigentümer beschränkt.
* Ein Problem beim LDAP-Import wurde behoben.

Neue Funktionen:

* Browserbasierter Python Runner hinzugefügt.
* Pandoc-Unterstützung für den Import und Export von Markdown, DOCX und anderen Formaten hinzugefügt.
* GitHub Sync hinzugefügt.
* Vollständige chinesische Übersetzungen hinzugefügt.
* Zotero-Integration hinzugefügt.
* `DEFAULT_LATEX_COMPILER` hinzugefügt.

#### Funktion 01: GitHub Sync

Halten Sie Ihre LaTeX-Projekte mit GitHub-Repositories synchron und profitieren Sie von einem nahtlosen Entwicklungsworkflow. Pushen und pullen Sie Änderungen direkt aus dem Editor, arbeiten Sie über Pull Requests zusammen und integrieren Sie bestehende CI/CD-Pipelines. Die Versionskontrolle erleichtert es, Revisionen nachzuverfolgen, Änderungen zu prüfen und reproduzierbare wissenschaftliche oder technische Dokumente zu pflegen.

Siehe: [GitHub Synchronisation](/de/on-premises/configuration/overleaf-toolkit/github-synchronisation  "mention").

![](https://github.com/user-attachments/assets/5137e708-77cb-4fdf-b081-4aa04b4b762e)

#### Funktion 02: Pandoc-Import/-Export

Importieren Sie Microsoft-Word- und Markdown-Dokumente in vollständig bearbeitbare LaTeX-Projekte oder exportieren Sie LaTeX-Projekte mit einem Klick zurück nach Markdown und DOCX. Diese auf Pandoc basierende Funktion ermöglicht eine nahtlose Interoperabilität zwischen wissenschaftlichem Schreiben, kollaborativer Bearbeitung und Publikations-Workflows und erhält dabei die Dokumentstruktur so weit wie möglich.

Siehe: [Pandoc Import and Export](/de/on-premises/configuration/overleaf-toolkit/pandoc-import-and-export  "mention").

#### Funktion 03: Erweiterte Literatursuche

Durchsuchen Sie mehrere wissenschaftliche Datenbanken nach Literaturangaben und fügen Sie diese mit intelligenter Filterung und sofortiger Zitierunterstützung ein. Finden Sie schnell Publikationen, sehen Sie sich Metadaten in der Vorschau an und erstellen Sie präzise BibTeX-Einträge, ohne zwischen verschiedenen Recherche-Websites wechseln zu müssen – das steigert die Effizienz der Literaturrecherche erheblich.

![Bild](https://github.com/user-attachments/assets/42e45b73-af4b-4d1f-81f4-9e116ba5d043)

#### Funktion 04: Python Runner

Führen Sie Python-Code direkt in Ihrem Projekt aus, ohne den Editor zu verlassen. Ideal zum Erzeugen von Abbildungen, Verarbeiten von Datensätzen, Automatisieren von Dokument-Workflows oder Ausführen reproduzierbarer Forschungsskripte. Die Ergebnisse lassen sich in Ihre LaTeX-Dokumente integrieren, sodass wissenschaftliches Rechnen und Schreiben Teil eines einheitlichen Workflows werden.

![Bild](https://github.com/user-attachments/assets/a4c314b3-fdb5-4836-aea7-12eeece5cd2f)

#### Funktion 05: Zotero

Verbinden Sie Ihre Zotero-Bibliothek direkt mit Ihrem Schreib-Workflow und verwalten Sie Literaturangaben, ohne den Editor zu verlassen. Durchsuchen Sie Ihre persönlichen Zotero-Sammlungen, fügen Sie Zitate mit einem Klick ein und lassen Sie BibTeX-Einträge automatisch erzeugen und synchronisieren. Diese Integration hält Ihr Literaturverzeichnis aktuell und vereinfacht die Literaturverwaltung für wissenschaftliche Arbeiten, Abschlussarbeiten und technische Dokumente.

Siehe: [Zotero Integration](/de/on-premises/configuration/overleaf-toolkit/zotero-integration  "mention").
