Reiht die Änderungen jedes Projekts in Redis ein, wandelt sie in Verlaufsänderungen um und sendet sie an history-v1; außerdem speichert es Verlaufslabels, den Resync-Status und Fehlerdatensätze in Mongo. Wird von web, document-updater, history-v1 und den server-ce-Cron-Skripten aufgerufen; es hat keine Authentifizierung.

* <strong>Adresse:</strong> `http://project-history:3054`, innerhalb des Docker-Netzwerks
* <strong>Authentifizierung:</strong> keine
* <strong>OpenAPI-Datei:</strong> [`develop/hoppscotch/openapi/project-history.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/project-history.yaml)
