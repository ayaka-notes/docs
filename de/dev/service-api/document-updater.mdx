Hält die im Editor geöffneten Dokumente in Redis, wendet Änderungen auf sie an und schreibt sie über web zurück nach Mongo. Wird von web und real-time aufgerufen.

* <strong>Adresse:</strong> `http://document-updater:3003`, innerhalb des Docker-Netzwerks
* <strong>Authentifizierung:</strong> keine
* <strong>OpenAPI-Datei:</strong> [`develop/hoppscotch/openapi/document-updater.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/document-updater.yaml)
