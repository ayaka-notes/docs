title: linked-url-proxy
icon: link
---

Ruft für web eine externe URL ab und streamt die Antwort zurück. Interne Adressen lehnt er ab, damit Benutzer das Docker-Netzwerk nicht erreichen können. Web leitet URL-Dateien, Open-in-Overleaf-Importe und den web_fetch des KI-Agenten darüber.

* <strong>Adresse:</strong> `http://linked-url-proxy:3066`, innerhalb des Docker-Netzwerks
* <strong>Authentifizierung:</strong> keine
* <strong>OpenAPI-Datei:</strong> [`develop/hoppscotch/openapi/linked-url-proxy.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/linked-url-proxy.yaml)
