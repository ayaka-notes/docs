Speichert den Projekt-Chat und die Kommentar-Threads (ihre Nachrichten und den Status „erledigt“) in den Mongo-Collections `rooms` und `messages`. Wird von web über `ChatApiHandler` aufgerufen.

* <strong>Adresse:</strong> `http://chat:3010`, innerhalb des Docker-Netzwerks
* <strong>Authentifizierung:</strong> keine
* <strong>OpenAPI-Datei:</strong> [`develop/hoppscotch/openapi/chat.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/chat.yaml)
