Synchronisiert Projekte mit Dropbox: Es hält pro Benutzer eine Redis-Job-Warteschlange und einen Worker, der Overleaf-Änderungen an Dropbox sendet und Dropbox nach Änderungen abfragt. Nur web ruft es auf, um Jobs einzureihen und Warteschlangengrößen zu lesen.

* <strong>Adresse:</strong> `http://third-party-datastore:3002`, innerhalb des Docker-Netzwerks
* <strong>Authentifizierung:</strong> keine
* <strong>OpenAPI-Datei:</strong> [`develop/hoppscotch/openapi/third-party-datastore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/third-party-datastore.yaml)
