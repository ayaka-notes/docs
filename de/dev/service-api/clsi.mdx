CLSI (Common LaTeX Service Interface) kompiliert Projekte, führt SyncTeX und texcount auf der Kompilierungsausgabe aus und konvertiert Dokumente mit pandoc. Web ruft es auf; die Ausgabedateien selbst werden von clsi-nginx ausgeliefert, nicht über diesen Port. Keine Authentifizierung: Es ist nur innerhalb des Docker-Netzwerks erreichbar.

* <strong>Adresse:</strong> `http://clsi:3013`, innerhalb des Docker-Netzwerks
* <strong>Authentifizierung:</strong> keine
* <strong>OpenAPI-Datei:</strong> [`develop/hoppscotch/openapi/clsi.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/clsi.yaml)
