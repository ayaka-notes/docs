title: docstore
icon: database
---

Speichert jedes Dokument (Zeilen, Version, Ranges) jedes Projekts in der Mongo-Collection `docs` und archiviert Dokumente in einem Objektspeicher, wenn ein Backend gesetzt ist. Wird von web aufgerufen; document-updater erreicht es über web.

* <strong>Adresse:</strong> `http://docstore:3016`, innerhalb des Docker-Netzwerks
* <strong>Authentifizierung:</strong> keine
* <strong>OpenAPI-Datei:</strong> [`develop/hoppscotch/openapi/docstore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/docstore.yaml)
