Liefert Dateien aus dem Objektspeicher aus: Vorlagendateien (zip, pdf und ihre Vorschaubilder) und, nur lesend, die Projekt- und globalen Blobs, die history-v1 schreibt. Wird von web (Modul template-gallery, Datei-URLs der Kompilierung) und von clsi aufgerufen, das binäre Projektdateien von dort herunterlädt.

* <strong>Adresse:</strong> `http://filestore:3009`, innerhalb des Docker-Netzwerks
* <strong>Authentifizierung:</strong> keine
* <strong>OpenAPI-Datei:</strong> [`develop/hoppscotch/openapi/filestore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/filestore.yaml)
