---
title: i18n-Übersetzungen aktualisieren
icon: language
---

Unter `services/web/frontend/extracted-translations.json` gibt es eine Datei; Overleaf Web verwendet ausschließlich die in dieser Datei extrahierten Übersetzungen.

Führen Sie den folgenden Befehl aus, um die extrahierten Übersetzungen zu aktualisieren, wenn Sie Inhalte hinzugefügt haben.

```bash
user ➜ ~/overleaf-pro/develop (server-pro) $ bin/shell webpack
root@432836260f8a:/overleaf/services/web# npm run extract-translations
```

Bearbeiten Sie die Übersetzungs-Textdateien bitte grundsätzlich nicht, sondern verwenden Sie zuerst vorhandene Einträge, da all diese Dateien aus dem Overleaf-Upstream oder von Übersetzungsplattformen Dritter aktualisiert werden.
