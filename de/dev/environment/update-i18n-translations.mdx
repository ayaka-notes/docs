---
title: i18n-Übersetzungen aktualisieren
icon: language
---

Es gibt die Datei `services/web/frontend/extracted-translations.json`. Overleaf Web verwendet ausschließlich die in dieser Datei extrahierten Übersetzungen.

Führen Sie den folgenden Befehl aus, um die extrahierten Übersetzungen zu aktualisieren, wenn Sie Inhalte hinzugefügt haben.

```bash
user ➜ ~/overleaf-pro/develop (server-pro) $ bin/shell webpack
root@432836260f8a:/overleaf/services/web# npm run extract-translations
```

Bitte bearbeiten Sie die Übersetzungs-Textdateien grundsätzlich nicht, sondern verwenden Sie zunächst vorhandene Einträge, da alle diese Dateien aus dem Overleaf-Upstream oder von einer Übersetzungsplattform eines Drittanbieters aktualisiert werden.
