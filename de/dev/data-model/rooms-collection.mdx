`rooms` enthält ein Dokument pro Chatraum eines Projekts: den Projekt-Chat oder einen Review-Kommentar-Thread. Nur der Chat-Dienst schreibt sie, in `services/chat/app/js/Features/Threads/ThreadManager.js`. Es gibt kein Mongoose-Schema. Die Nachrichten eines Raums liegen in der Collection [messages](/de/dev/data-model/messages-collection).

#### Felder {#fields}

| Feld | Typ | Bedeutung | Quelle |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Raum-ID. `messages.room_id` verweist hierher. | `ThreadManager.js:57-61` |
| `project_id` | ObjectId | Projekt, zu dem der Raum gehört. | `ThreadManager.js:43-54` |
| `thread_id` | ObjectId | Nur bei Kommentar-Threads: die ID des Kommentars, identisch mit `id` und `op.t` des Kommentars in `docs.ranges.comments` (siehe [docs](/de/dev/data-model/docs-collection)). Fehlt beim Projekt-Chat-Raum. | `ThreadManager.js:38-55`, `services/docstore/app/js/RangeManager.js:54-57` |
| `resolved` | Object | Wird gesetzt, wenn der Thread gelöst wird, und entfernt, wenn er wieder geöffnet wird. Ein Thread ohne dieses Feld ist offen. | `ThreadManager.js:94-123` |
| `resolved.user_id` | String | ID des Benutzers, der den Thread gelöst hat. Als String gespeichert, nicht als ObjectId: Der Request-Body wird nur auf eine gültige ID geprüft, nicht umgewandelt. | `ThreadManager.js:103`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:70` |
| `resolved.ts` | Date | Zeitpunkt, zu dem der Thread gelöst wurde. | `ThreadManager.js:104` |

#### Hinweise {#notes}

* Ein Projekt hat höchstens einen Raum ohne `thread_id`: den Projekt-Chat. Der Chat-Dienst findet ihn mit `thread_id: { $exists: false }` (`ThreadManager.js:38-45`).
* Der Gelöst-Status eines Kommentars liegt nur hier. Docstore entfernt `op.resolved`, bevor er Bereiche speichert (`services/docstore/app/js/RangeManager.js:59-61`).
* Nach einer Projektkopie existiert dieselbe `thread_id` in zwei Projekten. Fragen Sie immer `project_id` und `thread_id` zusammen ab, wie es der Chat-Dienst tut.
* Räume eines gelöschten Projekts bleiben erhalten, bis das gelöschte Projekt abläuft.
