`contacts` merkt sich, mit welchen Benutzern ein Benutzer zusammengearbeitet hat, damit der Teilen-Dialog sie vorschlagen kann. Ein Dokument pro Benutzer. `web` ist Eigentümer, ohne Mongoose-Schema; der Code ist `services/web/app/src/Features/Contacts/ContactManager.mjs`.

#### Felder {#fields}

| Feld | Typ | Bedeutung | Quelle |
| ---- | --- | --------- | ------ |
| `_id` | ObjectId | Dokument-ID, vom Upsert angelegt. | `ContactManager.mjs:5-12` |
| `user_id` | ObjectId | Der Benutzer, dem diese Kontakte gehören. Ein Dokument pro Benutzer. | `ContactManager.mjs:6` |
| `contacts` | Object | Map mit der Benutzer-ID des Kontakts (als String) als Schlüssel. | `ContactManager.mjs:8-9` |
| `contacts.<userId>.n` | Number | Wie oft die beiden Benutzer zusammengebracht wurden. | `ContactManager.mjs:8` |
| `contacts.<userId>.ts` | Date | Wann das zuletzt geschah. | `ContactManager.mjs:9` |

#### Wer schreibt {#who-writes-it}

| Code | Was er tut |
| ---- | ---------- |
| `ContactManager.mjs:4-13` (`touchContact`), `:23-28` (`addContact`) | Upsert der Dokumente beider Benutzer: `$inc` auf `n`, `$set` von `ts`. |
| `services/web/app/src/Features/Collaborators/CollaboratorsHandler.mjs:155-157` | `addUserIdToProject` ruft `addContact` auf, wenn ihm der hinzufügende Benutzer übergeben wird: bei einer angenommenen Einladung (Einladender und Eingeladener, `services/web/app/src/Features/Collaborators/CollaboratorsInviteHandler.mjs:199-205`) und bei einer Eigentumsübertragung (neuer und bisheriger Eigentümer, `services/web/app/src/Features/Collaborators/OwnershipTransferHandler.mjs:138-144`). Der Beitritt über einen Freigabelink übergibt keinen hinzufügenden Benutzer (`services/web/app/src/Features/TokenAccess/TokenAccessController.mjs:386-388`, `:632-634`) und legt daher keinen Kontakt an. |

#### Hinweise {#notes}

* Kontakte gelten in beide Richtungen: Wird B zum Projekt von A hinzugefügt, wird B ein Kontakt von A und A ein Kontakt von B.
* Nichts entfernt einen Kontakt oder das Dokument, nicht einmal beim Löschen eines Benutzers.
