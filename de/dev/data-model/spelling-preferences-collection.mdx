`spellingPreferences` enthält das Wörterbuch jedes Benutzers: die Wörter, die der Benutzer über "Add to dictionary" in der Rechtschreibprüfung des Editors hinzugefügt hat. Ein Dokument pro Benutzer. `web` ist Eigentümer, ohne Mongoose-Schema; der Code ist `services/web/app/src/Features/Spelling/LearnedWordsManager.mjs`.

#### Felder {#fields}

| Feld | Typ | Bedeutung | Quelle |
| ---- | --- | --------- | ------ |
| `_id` | ObjectId | Dokument-ID, vom Upsert angelegt. | `LearnedWordsManager.mjs:21-31` |
| `token` | String | Die ID des Benutzers. Die Rechtschreib-Routen übergeben trotz des Namens die ID des angemeldeten Benutzers (`SessionManager.getLoggedInUserId`). | `LearnedWordsManager.mjs:23` |
| `learnedWords` | Array of String | Die vom Benutzer hinzugefügten Wörter. | `LearnedWordsManager.mjs:26` |

#### Wer schreibt {#who-writes-it}

| Code | Was er tut |
| ---- | ---------- |
| `LearnedWordsManager.mjs:13-32` (`learnWord`) | `POST /spelling/learn` (`services/web/app/src/router.mjs:1037-1041`, `services/web/app/src/Features/Spelling/SpellingController.mjs:45-58`): `$addToSet` des Worts, mit Upsert. Lehnt ab, wenn die Liste über `Settings.maxDictionarySize` Bytes wachsen würde. |
| `LearnedWordsManager.mjs:38-47` (`unlearnWord`) | `POST /spelling/unlearn` (`router.mjs:1043-1047`, `SpellingController.mjs:66-79`): `$pull` des Worts. |
| `LearnedWordsManager.mjs:84-86` (`deleteUsersLearnedWords`) | Löscht das Dokument. Sein einziger Wrapper, `SpellingHandler.deleteUserDictionary` (`services/web/app/src/Features/Spelling/SpellingHandler.mjs:24-26`), hat keinen Aufrufer in web oder seinen Modulen. |

#### Wer liest {#who-reads-it}

| Code | Was er tut |
| ---- | ---------- |
| `LearnedWordsManager.mjs:52-67` (`getLearnedWords`) | Gibt die Wörter ohne Duplikate zurück. |
| `services/web/app/src/Features/Project/ProjectController.mjs:671` | Sendet das Wörterbuch an den Editor, wenn ein Projekt geöffnet wird (`SpellingHandler.getUserDictionary`). |

#### Hinweise {#notes}

* Der Index ist nicht eindeutig; das Upsert auf `token` hält ein Dokument pro Benutzer.
* Das Löschen eines Benutzers löscht dieses Dokument nicht.
