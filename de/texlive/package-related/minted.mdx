Dieser Artikel zeigt, wie Sie mit dem [Paket `minted`](https://ctan.org/pkg/minted?lang=en) Quellcode von Programmiersprachen in einem LaTeX-Dokument formatieren und hervorheben. Wir beginnen mit einem Beispiel:

```latex
\documentclass{article}
\usepackage{minted}
\begin{document}
\begin{minted}{python}
import numpy as np
    
def incmatrix(genl1,genl2):
    m = len(genl1)
    n = len(genl2)
    M = None #to become the incidence matrix
    VT = np.zeros((n*m,1), int)  #dummy variable
    
    #compute the bitwise xor matrix
    M1 = bitxormatrix(genl1)
    M2 = np.triu(bitxormatrix(genl2),1) 

    for i in range(m-1):
        for j in range(i+1, m):
            [r,c] = np.where(M2 == M1[i,j])
            for k in range(len(r)):
                VT[(i)*n + r[k]] = 1;
                VT[(i)*n + c[k]] = 1;
                VT[(j)*n + r[k]] = 1;
                VT[(j)*n + c[k]] = 1;
                
                if M is None:
                    M = np.copy(VT)
                else:
                    M = np.concatenate((M, VT), 1)
                
                VT = np.zeros((n*m,1), int)
    
    return M
\end{minted}
\end{document}
```

Hier gibt es zwei wichtige Befehle. In der Präambel wird das Paket importiert mit

```latex
\usepackage{minted}
```

Anschließend begrenzen die Tags `\begin{minted}{python}` und `\end{minted}` eine Umgebung, die den Text unverändert in einer Schrift mit fester Zeichenbreite ausgibt und Kommentare, Schlüsselwörter und Funktionen farbig hervorhebt. Der Parameter `python` ist die Programmiersprache, in der der Quellcode geschrieben ist. `minted` unterstützt über 150 Programmier- und Auszeichnungssprachen sowie Konfigurationsdateien; eine Liste der unterstützten Sprachen finden Sie im [Referenzhandbuch](https://www.overleaf.com/learn/latex/Code_Highlighting_with_minted#Reference_guide).

**Hinweis**: Damit `minted` mit Ihrer _lokalen_ LaTeX-Distribution funktioniert, muss ein zusätzliches Programm namens [Pygments](https://pygments.org/) installiert sein. [Overleaf](https://www.overleaf.com/) erspart Ihnen die Installation und das Ausführen spezieller Befehle zum Kompilieren Ihres Dokuments – auf Overleaf funktionieren Dokumente, die `minted` verwenden, "out of the box".

### Grundlegende Verwendung

Wie das folgende Beispiel zeigt, lässt sich die Umgebung `minted` so konfigurieren, dass die visuelle Darstellung des gesetzten Codes angepasst wird. Hier verwendet die Umgebung `minted` mehrere durch Kommas getrennte Parameter der Form `key=value`:

```latex
\documentclass{article}
\usepackage{minted}
\usepackage{xcolor} % to access the named colour LightGray
\definecolor{LightGray}{gray}{0.9}
\begin{document}
\begin{minted}
[
frame=lines,
framesep=2mm,
baselinestretch=1.2,
bgcolor=LightGray,
fontsize=\footnotesize,
linenos
]
{python}
import numpy as np
    
def incmatrix(genl1,genl2):
    m = len(genl1)
    n = len(genl2)
    M = None #to become the incidence matrix
    VT = np.zeros((n*m,1), int)  #dummy variable
    
    #compute the bitwise xor matrix
    M1 = bitxormatrix(genl1)
    M2 = np.triu(bitxormatrix(genl2),1) 

    for i in range(m-1):
        for j in range(i+1, m):
            [r,c] = np.where(M2 == M1[i,j])
            for k in range(len(r)):
                VT[(i)*n + r[k]] = 1;
                VT[(i)*n + c[k]] = 1;
                VT[(j)*n + r[k]] = 1;
                VT[(j)*n + c[k]] = 1;
                
                if M is None:
                    M = np.copy(VT)
                else:
                    M = np.concatenate((M, VT), 1)
                
                VT = np.zeros((n*m,1), int)
    
    return M
\end{minted}
\end{document}
```

<p style={{ textAlign: "center" }}><img src="https://sharelatex-wiki-cdn-671420.c.cdn77.org/learn-scripts/images/f/ff/OLV2minted2.png" alt="Beispiel für die Formatierung von mit dem Paket minted gesetztem Code" /></p>

Die in diesem Beispiel verwendeten Parameter sind:

* `frame=lines`: zeichnet zwei Linien, eine oberhalb und eine unterhalb des Codes, um ihn einzurahmen. Weitere mögliche Werte sind `leftline`, `topline`, `bottomline` und `single`.
* `framesep=2mm`: der Abstand zum Rahmen wird auf 2 mm gesetzt. Andere [Längeneinheiten](https://www.overleaf.com/learn/latex/Lengths_in_LaTeX) können ebenfalls verwendet werden.
* `baselinestretch=1.2`: der Zeilenabstand des Codes wird auf 1,2 gesetzt.
* `bgcolor=LightGray`: die Hintergrundfarbe wird auf `LightGray` gesetzt. Dafür müssen Sie das Paket `xcolor` importieren. Mehr über die Arbeit mit Farben erfahren Sie unter [Using colours in LaTeX](https://www.overleaf.com/learn/latex/Using_colours_in_LaTeX).
* `fontsize=\footnotesize`: die Schriftgröße wird auf `footnotesize` gesetzt. Jede andere [Schriftgröße](https://www.overleaf.com/learn/latex/Font_sizes_and_kinds%23Reference_guide) kann ebenfalls eingestellt werden.
* `linenos`: aktiviert Zeilennummern.

Weitere nützliche Optionen sind:

* `mathescape`: aktiviert den Mathematikmodus in Code-Kommentaren.
* `rulecolor`: ändert die Farbe des Rahmens.
* `showspaces`: aktiviert ein Sonderzeichen, um Leerzeichen sichtbar zu machen.

### Code aus einer Datei einbinden

Code ist üblicherweise in einer Quelldatei gespeichert. Daher ist ein Befehl, der Code automatisch aus einer Datei importiert, sehr praktisch, wie das folgende Beispiel zeigt:

```latex
\documentclass{article}
\usepackage{minted}
\title{Importing files using minted}
\begin{document}
The next code will be directly imported from a file:

\inputminted{octave}{BitXorMatrix.m}
\end{document}
```

Dieses Beispiel erzeugt die folgende Ausgabe:

<img src="https://sharelatex-wiki-cdn-671420.c.cdn77.org/learn-scripts/images/c/c8/OLV2mintedinput.png" alt="Mit minted eine Code-Datei importieren" height="392" width="600" />

Der Befehl `\inputminted{octave}{BitXorMatrix.m}` importiert den Code aus der Datei `BitXorMatrix.m`; der Parameter `octave` teilt LaTeX die Programmiersprache des Codes mit. Dieser Befehl kann zwei zusätzliche Parameter annehmen, um nur einen Teil der Datei zu importieren. Um beispielsweise den Code von Zeile 2 bis Zeile 12 zu importieren, lautet der Befehl:

```latex
\inputminted[firstline=2, lastline=12]{octave}{BitXorMatrix.m}
```

### Einzeiliger Code

Wenn Sie nur eine einzelne Codezeile einfügen müssen, erledigt das der Befehl `\mint`, dessen Syntax im nächsten Beispiel gezeigt wird.

```latex wrap
One-line code formatting also works with \texttt{minted}. For example, a small fragment of HTML like this:
\mint{html}|<h2>Something <b>here</b></h2>|
\noindent can be formatted correctly.
```

Dieses Beispiel erzeugt die folgende Ausgabe:

<img src="https://sharelatex-wiki-cdn-671420.c.cdn77.org/learn-scripts/images/d/d9/OLV2mintedHTML.png" alt="Beispiel für einzeiligen Code mit minted" height="112" width="600" />

Der Parameter in geschweiften Klammern legt die Programmiersprache fest (in diesem Fall die Auszeichnungssprache `html`), wobei der eigentlich zu formatierende Text durch das Zeichen '|' begrenzt wird.

### Probleme mit selbst gehostetem Overleaf

Wenn Sie Sandboxed Compiles verwenden und Overleaf auf einem eigenen Overleaf-Server bereitstellen, funktioniert minted möglicherweise nicht richtig. Ausführliche Informationen finden Sie unter [issues/131](https://github.com/yu-i-i/overleaf-cep/issues/131). Damit minted funktioniert, müssen Sie das ARM-Instruktionsprofil und einige Systemaufrufe aktivieren.
