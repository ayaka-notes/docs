[TeX Live](https://www.tug.org/texlive/) ist eine freie Softwaredistribution, die jährlich von der [TeX Users Group](https://www.tug.org/) veröffentlicht wird. Sie stellt die LaTeX-Pakete, Schriften, TeX-Engines und zahlreiche Softwarewerkzeuge bereit, die für LaTeX-basierten Textsatz auf allen gängigen Betriebssystemen benötigt werden.

TeX Live ist ein wichtiger Bestandteil von Overleaf, da unsere Server es verwenden, um Ihren LaTeX-Code zu kompilieren und die Echtzeit-PDF-Vorschau zu erzeugen. Außerdem bietet es den Nutzern von Overleaf einfachen Zugriff auf über 5.000 LaTeX-Pakete, die in jeder TeX-Live-Version enthalten sind.

Sie sind nicht auf die neueste Version von TeX Live beschränkt, um Ihre Projekte zu kompilieren, da die Server von Overleaf Zugriff auf frühere TeX-Live-Versionen bieten. Projekte können ganz einfach auf eine ältere Version von TeX Live umgestellt werden – beispielsweise aufgrund von Problemen mit der Paketkompatibilität.<br />
