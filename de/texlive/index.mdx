[TeX Live](https://www.tug.org/texlive/) ist eine freie Software-Distribution, die jährlich von der [TeX Users Group](https://www.tug.org/) veröffentlicht wird. Sie stellt die LaTeX-Pakete, Schriften, TeX-Engines und zahlreiche Software-Werkzeuge bereit, die für LaTeX-basierten Textsatz auf allen gängigen Betriebssystemen benötigt werden.

TeX Live ist ein wichtiger Bestandteil von Overleaf, da unsere Server damit Ihren LaTeX-Code kompilieren und die PDF-Vorschau in Echtzeit erzeugen. Außerdem erhalten die Nutzerinnen und Nutzer von Overleaf damit einfachen Zugriff auf über 5.000 LaTeX-Pakete, die in jeder TeX Live-Version enthalten sind.

Sie sind nicht darauf beschränkt, Ihre Projekte mit der neuesten Version von TeX Live zu kompilieren, da die Server von Overleaf Zugriff auf frühere TeX Live-Versionen bieten. Projekte lassen sich einfach auf eine ältere Version von TeX Live umstellen – zum Beispiel bei Problemen mit der Paketkompatibilität.<br />
