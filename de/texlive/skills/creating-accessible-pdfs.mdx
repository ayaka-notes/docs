Im Laufe der Zeit haben Weiterentwicklungen bei der PDF-Erstellung barrierefreie PDFs möglich gemacht. Fortschritte wie das [LaTeX Tagging Project](https://latex3.github.io/tagging-project/documentation/) haben dafür gesorgt, dass auch LaTeX-basierte PDFs barrierefrei sein können, und die Verbesserungen gehen weiter.

<Check>

Insbesondere die Veröffentlichung von [TeX Live 2025](https://www.overleaf.com/blog/tex-live-2025-is-now-available) macht diesen Prozess in Overleaf möglich. Beachten Sie, dass bei Verwendung von MathML **LuaLaTeX** als Compiler empfohlen wird.

Wie Sie die Einstellungen Ihres Projekts entsprechend anpassen, erfahren Sie unter [Compiler und TeX Live-Version ändern](https://docs.overleaf.com/getting-started/recompiling-your-project/selecting-a-tex-live-version-and-latex-compiler).

</Check>

Unser Ansatz orientiert sich weitgehend an der [Anleitung für barrierefreie PDFs](https://latex3.github.io/tagging-project/documentation/usage-instructions) des LaTeX Project, in der Sie weitere Details zu den folgenden Themen finden.

<Warning>

Beachten Sie, dass die Umsetzung dieser Praktiken nicht garantiert, dass jedes Element Ihres Projekts barrierefrei ist – weitere Informationen finden Sie im FAQ-Abschnitt dieser Seite.

</Warning>

### <Icon icon="tag" /> Tagging

Im Kern ist PDF-Tagging ein Prozess, der automatisch eine „Struktur“ erzeugt, die von Screenreadern leicht erkannt wird und sowohl heute als auch künftig besser durchsuchbar ist. Dabei wird die bereits durch Ihren LaTeX-Code definierte Struktur genutzt, sodass der Screenreader zwischen Elementen wie Überschriften, Fließtext, Abbildungen und Gleichungen unterscheiden kann.

TeX Live 2025 unterstützt automatische PDF-Tags vollständig über die Deklaration `\DocumentMetaData`. Fügen Sie diese Deklaration vor `\documentclass` ein. Für die Tagging-Funktionen sind zwei Schlüssel dieser Deklaration besonders wichtig: `tagging` und `tagging-setup`.

#### **`tagging`**

Stellen Sie sicher, dass Tagging aktiviert ist, indem Sie den Schlüssel `tagging` auf `on` setzen.

```latex wrap expandable
\DocumentMetadata{tagging=on}
```

#### **`tagging-setup`**

Legen Sie fest, wie Ihr Dokument getaggt wird, indem Sie den Wert des Schlüssels `tagging-setup` ändern.

```latex wrap expandable
\DocumentMetadata{tagging=on,tagging-setup={math/setup=mathml-SE}}
```

<Info>

In diesem Beispiel haben wir \`math/setup=mathml-SE\` für das Tagging mit MathML-Strukturelementen verwendet; der Schlüssel kann jedoch auf jeden Wert gesetzt werden, den \[\`\tagpdfsetup\`]\(https://ctan.math.washington.edu/tex-archive/macros/latex/contrib/tagpdf/tagpdf.pdf) unterstützt.

</Info>

### <Icon icon="text-size" /> Beschreibungen

Zusätzlich zum automatischen Tagging müssen Sie möglicherweise auch Beschreibungen des Inhalts der Elemente hinzufügen, insbesondere wenn Ihr Dokument Bilder und/oder Tabellen enthält.

#### <Icon icon="image" /> Bilder

In Overleaf lassen sich wichtige Bildbeschreibungen ganz einfach hinzufügen; sie können auch helfen, den Kontext bestimmter Bilder beim Lesen des LaTeX-Codes zu verstehen. Sie müssen lediglich bei jedem `\includegraphics` die passende Option für die Bildbeschreibung angeben. Für die Barrierefreiheit werden drei Hauptarten von Bildern unterschieden: Bilder, die Alternativtext (Alt-Text) benötigen, Artefakte und Bilder, die tatsächlichem Text entsprechen.

**Alt-Text**

Durch Alternativtext erhält ein Bild eine Beschreibung, die als textbasierter Ersatz für das Visuelle dienen kann. Verwenden Sie den Schlüssel `alt` und geben Sie einen Textwert an.

```latex title="Alt text example" wrap
\includegraphics[width=0.25\linewidth,alt={Macro photo of a green frog's head and hands}]{frog.jpg}
```

**Artefakte**

Wenn ein Bild nicht von einem Screenreader erfasst werden muss (d. h. wenn es rein dekorativ ist), kennzeichnen Sie es als Artefakt. Verwenden Sie den Schlüssel `artifact`, ohne einen Wert zuzuweisen.

```latex title="Artifact example" wrap
\includegraphics[artifact]{.jpg}
```

**Tatsächlicher Text**

Wenn ein Bild ausschließlich ein Unicode-Zeichen darstellt, geben Sie das entsprechende Textzeichen an. Verwenden Sie den Schlüssel `actualtext` und weisen Sie ihm ein einzelnes Zeichen zu (ohne Klammern).

```latex title="Actual text example" wrap
\includegraphics[actualtext=B]{.jpg}
```

#### <Icon icon="table" /> Tabellen

Tabellen enthalten zwar in der Regel Text, dennoch ist es wichtig, dass dieser Text den richtigen Bestandteilen der Tabelle zugeordnet ist. Fügen Sie `\tagpdfsetup` vor Ihrer `tabular`-Umgebung oder in der Präambel ein, um die Einrichtung der Tabellen in Ihrem Overleaf-Projekt zu beginnen. Für die Barrierefreiheit werden zwei Hauptarten von Tabellen unterschieden: Datentabellen und Präsentationstabellen.

**Datentabellen**

Wenn eine Tabelle mindestens eine Kopfzeile hat, legen Sie fest, welche Zeilen Kopfzeilen sind. Verwenden Sie den Schlüssel `table/header-rows` und geben Sie eine Folge von Zahlen an, die den Positionen der Kopfzeilen entsprechen.

```latex title="Data table example"
\tagpdfsetup{table/header-rows={1}}
\begin{tabular}{l|r}
Item & Quantity \\\hline
Widgets & 42 \\
Gadgets & 13
\end{tabular}
```

**Präsentationstabellen**

Wenn eine Tabelle von einem Screenreader nicht als Tabelle interpretiert werden soll, kennzeichnen Sie sie als Präsentationstabelle. Verwenden Sie den Schlüssel `table/tagging=presentation`.

```latex title="Presentation table example"
\tagpdfsetup{table/tagging=presentation}
\begin{tabular}{cc}
\textbullet & \textbullet \\
''' & '''
\end{tabular}
```

### <Icon icon="comments-question" /> FAQs

<Accordion title="Gibt es Werkzeuge, mit denen ich prüfen kann, ob mein Dokument barrierefrei ist?">

Ja, es gibt mehrere externe Werkzeuge, darunter [veraPDF](https://verapdf.org/), die PDF/A-Teile und Konformitätsstufen validieren können. Außerdem können Sie ein Werkzeug wie [WebAIM](https://webaim.org/) verwenden, um das Kontrastverhältnis zwischen zwei Farben zu berechnen.

</Accordion>

<Accordion title="Sind die Pakete in meinem Overleaf-Projekt mit diesen Funktionen kompatibel?">

Sie können die [Statusliste der Pakete](https://latex3.github.io/tagging-project/tagging-status/) des LaTeX Tagging Project heranziehen.

</Accordion>

<Accordion title="Kann ich weiterhin `beamer` verwenden? Gibt es andere Pakete für Präsentationen?">

Die Verwendung von `beamer` unterliegt Einschränkungen; sehen Sie sich die experimentelle [Klasse `ltx-talk`](https://ctan.org/pkg/ltx-talk) an.

</Accordion>

<Accordion title="Ist der Overleaf-Editor barrierefrei?">

Ja. Als Webanwendung nutzt Overleaf die Barrierefreiheitsfunktionen moderner Webbrowser, die regelmäßig von Barrierefreiheitsexperten bewertet werden. Unser zuletzt erstelltes [Voluntary Product Accessibility Template (VPAT)](https://www.overleaf.com/for/customers/vpat) belegt die Konformität mit den Web Content Accessibility Guidelines (WCAG) 2.2, Stufe AA.

</Accordion>

<Accordion title="Können mit Overleaf erstellte PDFs die Anforderungen von Title II des Americans with Disability Act (ADA) und der harmonisierten Europäischen Norm für Barrierefreiheit (EN 301 549) erfüllen?">

Ja. Die Gesetzgebung in den USA und Europa verlangt, dass PDFs WCAG 2.1 AA erfüllen. Um WCAG 2.1 AA zu erfüllen, muss ein PDF ein getaggtes PDF sein. Die Unterstützung für das Taggen von PDFs ist in TeX Live 2025 enthalten.

</Accordion>

<Accordion title="Können mit Overleaf erstellte PDFs den Standard PDF/UA-1 erfüllen?">

Ja. Das Tagging Project des LaTeX Project ist speziell darauf ausgelegt, die von PDF/UA-1 (und dem kommenden PDF/UA-2) geforderten Struktur-Tags zu erzeugen. Wer die aktuellen Tagging-Empfehlungen des LaTeX Project befolgt, erstellt praktisch ein „PDF/UA-fähiges“ Dokument – der beste Weg, die von der Gesetzgebung in den USA und Europa vorgeschriebene WCAG-2.1-AA-Anforderung zu erfüllen.

</Accordion>

<Accordion title="Wie stelle ich meinen Compiler auf LuaLaTeX um?">

Die Umstellung auf LuaLaTeX, die vom Team des LaTeX Tagging Project empfohlene LaTeX-Kompilierungs-Engine, ist ganz einfach. Der Standard-Compiler in Overleaf ist zwar PDFLaTeX, Sie können aber [in Ihren Projekteinstellungen zu LuaLaTeX wechseln](https://docs.overleaf.com/getting-started/recompiling-your-project/selecting-a-tex-live-version-and-latex-compiler).

</Accordion>

<Accordion title="Wo kann ich die neueste Version von TeX Live auswählen?">

Die neueste Version erhalten Sie über [Overleaf Labs](https://www.overleaf.com/labs/participate), das Zugriff auf das „Rolling TeX Live“-Image in Overleaf bietet, einschließlich der neuesten Unterstützung für PDF-Tagging. Diese experimentelle TeX Live-Version dient vor allem dazu, Änderungen an TeX Live und Paketen zu testen und neue Barrierefreiheitsfunktionen vorab zu erproben, bevor sie in unser jährliches TeX Live-Release aufgenommen werden.

Die meisten PDF-Tagging-Funktionen sind im Standard-Image [TeX Live 2025](https://www.overleaf.com/blog/tex-live-2025-is-now-available) verfügbar.

</Accordion>
