---
title: i18n-käännösten päivittäminen
icon: language
---

Tiedostossa `services/web/frontend/extracted-translations.json` on poimitut käännökset, ja Overleafin web-palvelu käyttää vain tässä tiedostossa olevia käännöksiä.

Jos olet lisännyt sisältöä, päivitä poimitut käännökset suorittamalla seuraava komento.

```bash
user ➜ ~/overleaf-pro/develop (server-pro) $ bin/shell webpack
root@432836260f8a:/overleaf/services/web# npm run extract-translations
```

Älä yleensä muokkaa käännöstekstitiedostoja, vaan käytä ensisijaisesti olemassa olevia käännöksiä, sillä kaikki nämä tiedostot päivitetään Overleafin upstream-versiosta tai kolmannen osapuolen käännössivustolta.
