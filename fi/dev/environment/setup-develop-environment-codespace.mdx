Säästääksesi aikaa ja rakentaaksesi kehitysympäristön nopeasti tarjoamme kehitysympäristön konfiguraatiosta toisen version, joka perustuu GitHub Codespaceen.

## Määritysopas

<Steps>
<Step title="Luo Codespaces">
Napsauta seuraavaa painiketta luodaksesi pilvipohjaisen codespacen server-pro-kehitystä varten.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/overleaf-pro)

Suosittelemme valitsemaan **koneen tyypiksi** (Machine Type) vähintään **4-core**. Suurempia konetyyppejä varten voit lähettää pyynnön GitHubin viralliselle tukitiimille avaamalla tukipyynnön [täällä](https://support.github.com/contact?tags=rr-codespaces%2Ccat_codespaces).

<Frame>
  <img src="/images/dev/image.png" alt="" />
</Frame>
</Step>

<Step title="Käynnistä asennusskripti">
Joudut odottamaan kärsivällisesti, kunnes codespace on luotu. Kun pääset käyttämään päätettä, suorita seuraava komento:

```text
cd develop/
bin/setup
```

<Frame>
  <img src="/images/dev/image-1.png" alt="" />
</Frame>

<Warning>

Tämän skriptin (`bin/setup`) avulla voit määrittää kehitysympäristön `server-pro`-haaran uusimman commitin pohjalta mahdollisimman lyhyessä ajassa. Se ei välttämättä sovellu vanhemmille versioille tai muille haaroille.

Rakennamme kehityskäyttöön tarkoitetun Docker-imagen joka päivä [GitHub Actionin](https://github.com/ayaka-notes/overleaf-pro/actions) avulla.

</Warning>
</Step>

<Step title="Avaa Launchpad">
Siirry porttivälilehdelle, jossa näet luettelon käytettävissä olevista web-porteista. Napsauta porttia `80`. Sinun pitäisi nyt nähdä launchpad-sivu.

<Frame>
  <img src="/images/dev/image-2.png" alt="" />
</Frame>

Näet seuraavan:

<Frame>
  <img src="/images/dev/image-3.png" alt="" />
</Frame>
</Step>

<Step title="Nauti kehittämisestä">
Nyt on sinun vuorosi! Ala rakentaa upeaa ominaisuuttasi. Reaaliaikaisen näytön käyttöön ottamiseksi sinun on suoritettava seuraava komento:

```bash title="bash" wrap
docker compose -f docker-compose.yml -f docker-compose.dev.yml -f ./docker-compose.image.yml up --no-deps --detach
```
</Step>
</Steps>
