## Suositellut kehitystyökalut

Nämä valinnaiset palvelut eivät ole välttämättömiä Overleafin ajamiseen, mutta niitä suositellaan vahvasti kehitykseen, virheenjäljitykseen ja tarkasteluun paikallisen kehityksen aikana.

* **Hoppscotch** on kevyt, Postmanin kaltainen API-testaustyökalu, joka toimii selaimessa ja on erittäin kätevä kehityksessä.
  * Käyttöliittymä: [http://localhost:3000](http://localhost:3000/)
  * Välityspalvelin (CORS-rajoitusten ohittamiseen): [http://localhost:9159](http://localhost:9159/)
* **RedisInsight** tarjoaa visuaalisen käyttöliittymän Redis-datan tarkasteluun. Käyttöliittymä on saatavilla osoitteessa: [http://localhost:5540](http://localhost:5540/)
* **Mongo Express** on verkkopohjainen käyttöliittymä MongoDB:lle. Voit käyttää sitä osoitteessa [http://localhost:8081](http://localhost:8081/) **tunnuksilla**: `admin:pass`

Lisää seuraava tiedostoon `docker-compose.yml`:

<Accordion title="develop/docker-compose.yml">

```yml title="develop/docker-compose.yml"
# services: 
  # Overleaf Dev Containers
  # ...
  
  # Add those for your development
  # API debug
  hoppscotch-frontend:
    image: hoppscotch/hoppscotch-frontend:latest
    ports:
      - "3000:3000"

  hoppscotch-proxy:
    image: hoppscotch/proxyscotch:latest
    environment:
      - PORT=9159
    ports:
      - "9159:9159"

  # Redis-insight
  redis-insight:
    image: redislabs/redisinsight:latest
    ports:
      - "5540:5540"
    depends_on:
      - redis
    volumes:
      - ./data/redis-insight:/data

  # mongo-express
  # basicAuth credentials are "admin:pass"
  mongo-express:
    image: mongo-express
    ports:
      - "8081:8081"
    environment:
      ME_CONFIG_MONGODB_SERVER: mongo
```

</Accordion>

#### CSRF-ongelmat

<Warning>

Jos luot **POST**-pyynnön Postmanilla tai muulla virheenjäljitystyökalulla, saatat huomata, että kirjautuminen on **estetty** ja syynä on 401-virhe. Tämä johtuu siitä, että Overleaf on suojattu **CSRF**-tarkistuksella.

</Warning>

  <img src="/images/dev/image-9.png" alt="" />

Jotta voit käsitellä tämän Overleaf-kehityksessä, sinun on määritettävä CSRF-tunniste. Tässä on yksityiskohtainen ohje.

<Steps>
<Step title="Lisää esipyyntö">
Lisää seuraava koodi kohtaan Pre-Request

<Frame>
  <img src="/images/dev/image-11.png" alt="" />
</Frame>

Skripti on seuraava:

```js wrap
pm.sendRequest("http://web:3000/dev/csrf", function (err, res) {
    if (err) {
        console.log(err);
        return;
    }

    // 1) Save CSRF token (/dev/csrf)
    const token = res.text().trim();
    pw.env.set("csrftoken", token);
    console.log("csrftoken =", token);

    const setCookieHeader = (res.headers || []).find(h => h.key?.toLowerCase() === "set-cookie")?.value;
    console.log("set-cookie =", setCookieHeader);

    if (!setCookieHeader) return;

    const cookiePair = setCookieHeader.split(";")[0].trim(); // overleaf.sid=...
    pw.env.set("cookie_header", cookiePair);
    console.log("cookie_header =", cookiePair);
});
```
</Step>

<Step title="Lisää pyyntöotsakkeet">
Sinun on lisättävä seuraavat otsakkeet:

| Otsakkeen nimi | Otsakkeen arvo      |
| -------------- | ------------------- |
| Content-Type   | `application/json`  |
| X-Csrf-Token   | `<<csrftoken>>`     |
| Cookie         | `<<cookie_header>>` |

<Frame>
  <img src="/images/dev/image-12.png" alt="" />
</Frame>
</Step>

<Step title="Kirjaudu sisään API-työkaluilla">
Nyt voit kirjautua sisään käyttäjänimelläsi ja salasanallasi.

```json5
{
  "_csrf": "<<csrftoken>>",
  "email": "admin@overleaf.com",
  "password": "xxxxxx"
}
```

Alla on vastaus, kun syötät väärän käyttäjänimen tai salasanan.
