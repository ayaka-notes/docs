## Suositellut kehitystyökalut {#develop-tools-recommended}

Näitä valinnaisia palveluja ei tarvita Overleafin ajamiseen, mutta ne auttavat paljon kehityksessä, virheenkorjauksessa ja datan tutkimisessa. Ne kaikki kuuluvat kehitysympäristöön, joten `docker-compose.yml`-tiedostoon ei tarvitse lisätä mitään. Kun olet kirjautunut sivustolle, sen navigointipalkin **Dev tools** -valikko linkittää niihin työkaluihin, joita sivusto tarjoaa omissa poluissaan.

| Työkalu | Osoite | Määritelty |
| --- | --- | --- |
| **Grafana**, jokaisen palvelun tila, mittarit ja lokit | [http://localhost/grafana/](http://localhost/grafana/) | `develop/grafana/docker-compose.yml`, käytössä, kun `GRAFANA_ENABLED=true` tiedostossa `develop/dev.rc` (oletus) |
| **Mailpit**, postilaatikko jokaiselle sivuston lähettämälle sähköpostille | [http://localhost/mailpit/](http://localhost/mailpit/) | `develop/mail/docker-compose.yml`, käytössä, kun `MAILPIT_ENABLED=true` (oletus) |
| **Mongo Express**, käyttöliittymä MongoDB:lle | [http://localhost/mongo-express/](http://localhost/mongo-express/) | `develop/docker-compose.yml`, aina käytössä |
| **RedisInsight**, käyttöliittymä Redis-datalle | [http://localhost/redis-insight/](http://localhost/redis-insight/) | `develop/docker-compose.yml`, aina käytössä |
| **Hoppscotch**, selainpohjainen API-asiakas, joka muistuttaa Postmania | [http://localhost:9170](http://localhost:9170/) (`HOPPSCOTCH_PORT`) | `develop/hoppscotch/docker-compose.yml`, käytössä, kun `HOPPSCOTCH_ENABLED=true` (oletus) |

<Warning>

Missään näistä työkaluista ei ole kirjautumista: Grafanan anonyymit käyttäjät ovat sen ylläpitäjiä, ja Mongo Express voi muuttaa mitä tahansa dokumenttia. Sivusto, Hoppscotch, Mongo Express (8081) ja RedisInsight (5540) kuuntelevat vain isäntäkoneen osoitetta `127.0.0.1`, joten muut koneet eivät tavoita niitä.

</Warning>

### Grafana {#grafana}

Sivusto tarjoaa Grafanan polussa `/grafana/` webpack-dev-serverin kautta, joten se ei tarvitse omaa porttia. Sen **Overleaf Develop** -kansiossa on nämä kojelaudat:

| Kojelauta | Mitä se näyttää |
| --- | --- |
| All services (etusivu) | Jokaisen palvelun tila, isäntäkoneen mittarit, kuorma ja lokit. Palvelun napsauttaminen avaa sen kojelaudan |
| Server | Isäntäkoneen suoritin, kuorma, muisti, levy ja verkko sekä clsi:n käännökset |
| Errors | Virhelokit, 5xx- ja 4xx-vastaukset, yleisimmät virheilmoitukset ja epäonnistuvat reitit |
| Data flow | Muokkauksen kulku: document-updater ja Redis, project-history, history-v1, Mongo, objektitallennus |
| Containers | Jokaisen kontin tila, suoritin, muisti, verkko ja levy, hiekkalaatikkokäännökset mukaan lukien |
| Yksi palvelua kohti | Node.js-palvelut, git-bridge (JVM), mongo ja redis |

Prometheus kerää palvelujen `/metrics`-tiedot sekä `mongodb-exporter`-, `redis-exporter`-, `cadvisor`- ja `node-exporter`-palvelut; Alloy lähettää projektin jokaisen kontin lokit Lokiin, josta kojelautojen suodattimet **Log search**, **Service** ja **Log level** lukevat ne. Niiden data on vain konteissa, joten konttien uudelleenluonti tyhjentää sen. cAdvisor toimii etuoikeutettuna ja lukee isäntäkoneen hakemistot `/` ja `/sys`, Docker-datan ja containerd-socketin vain luku -tilassa; node-exporter lukee isäntäkoneen hakemiston `/`.

Kojelaudat generoidaan: muuta tiedostoa `develop/grafana/make-dashboards` ja suorita se JSON-tiedostojen muokkaamisen sijaan.

### Mailpit {#mailpit}

Kun `MAILPIT_ENABLED=true`, `web` lähettää jokaisen sähköpostin Mailpitiin oikean postipalvelimen sijaan, ja sähköpostin vahvistus on käytössä (`EMAIL_CONFIRMATION_DISABLED=false`). Aktivointilinkkejä, projektikutsuja, salasanan palautuksia ja vahvistuskoodeja voi silloin seurata postilaatikosta.

### Hoppscotchin käyttöönotto {#setup-hoppscotch}

#### API-pyyntöjen välitys {#proxy-api-request}

Hoppscotch lähettää pyynnöt selaimesta, joka ei tavoita palveluja niiden Docker-nimillä. Sen välityspalvelin Proxyscotch toimii Docker-verkossa, ja sitä tarjotaan Hoppscotchin osoitteen polussa `/proxy`. Avaa [http://localhost:9170](http://localhost:9170/), siirry kohtaan Settings → Interceptor, valitse **Proxy** ja aseta Proxy URL -arvoksi `http://localhost:9170/proxy`. Asetus säilyy selaimessa.

#### Palvelujen API:en tuominen {#import-the-service-apis}

`develop/hoppscotch/openapi/` sisältää OpenAPI-tiedoston jokaisen palvelun sisäisestä API:sta. Avaa Hoppscotchissa Collections → Import → Import from File ja valitse kaikki tiedostot kerralla. Jokaisesta tiedostosta tulee kokoelma, jonka pyynnöt menevät palvelun Docker-osoitteeseen. Samat tiedostot näytetään osiossa [Palvelujen API](/fi/dev/service-api/overview).

#### CSRF-ongelmat {#csrf-problems}

<Warning>

Jos luot **POST**-pyynnön Postmanilla tai muulla virheenjäljitystyökalulla, saatat huomata, että kirjautuminen on **estetty** ja syynä on 403-virhe. Tämä johtuu siitä, että Overleaf on suojattu **CSRF**-tarkistuksella.

</Warning>

<Frame>
  <img src="/images/dev/image-8.png" alt="" />
</Frame>

Konsolissa saatat nähdä:

<Frame>
  <img src="/images/dev/image-9.png" alt="" />
</Frame>

Jotta voit käsitellä tämän Overleaf-kehityksessä, sinun on määritettävä CSRF-tunniste. Tässä on yksityiskohtainen ohje.

<Steps>
<Step title="Lisää esipyyntö">
Lisää seuraava koodi kohtaan Pre-Request

<Frame>
  <img src="/images/dev/image-10.png" alt="" />
</Frame>

Skripti on seuraava:

```js wrap
pm.sendRequest("http://web:3000/dev/csrf", function (err, res) {
    if (err) {
        console.log(err);
        return;
    }

    // 1) Save CSRF token (/dev/csrf)
    const token = res.text().trim();
    pw.env.set("csrftoken", token);
    console.log("csrftoken =", token);

    const setCookieHeader = (res.headers || []).find(h => h.key?.toLowerCase() === "set-cookie")?.value;
    console.log("set-cookie =", setCookieHeader);

    if (!setCookieHeader) return;

    const cookiePair = setCookieHeader.split(";")[0].trim(); // overleaf.sid=...
    pw.env.set("cookie_header", cookiePair);
    console.log("cookie_header =", cookiePair);
});
```
</Step>

<Step title="Lisää pyyntöotsakkeet">
Sinun on lisättävä seuraavat otsakkeet:

| Otsakkeen nimi | Otsakkeen arvo      |
| -------------- | ------------------- |
| Content-Type   | `application/json`  |
| X-Csrf-Token   | `<<csrftoken>>`     |
| Cookie         | `<<cookie_header>>` |

<Frame>
  <img src="/images/dev/image-11.png" alt="" />
</Frame>
</Step>

<Step title="Kirjaudu sisään API-työkaluilla">
Nyt voit kirjautua sisään käyttäjänimelläsi ja salasanallasi.

```json5
{
  "_csrf": "<<csrftoken>>",
  "email": "admin@overleaf.com",
  "password": "xxxxxx"
}
```

Alla on vastaus, kun syötät väärän käyttäjänimen tai salasanan.

</Frame>
</Step>
</Steps>
