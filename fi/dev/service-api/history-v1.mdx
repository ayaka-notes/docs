Tallentaa jokaisen projektin koko historian: muutospalat Mongoon tai Postgresiin ja objektitallennukseen sekä tiedostojen sisällön blobeina. project-history kirjoittaa siihen muutoksia; web, project-history ja git-bridge lukevat siitä blobeja, tilannevedoksia ja zip-tiedostoja.

* <strong>Osoite:</strong> `http://history-v1:3100`, Docker-verkon sisällä
* <strong>Todennus:</strong> HTTP basic -todennus käyttäjänä `staging` salasanalla `STAGING_PASSWORD` tai JWT reitistä riippuen.
* <strong>OpenAPI-tiedosto:</strong> [`develop/hoppscotch/openapi/history-v1.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/history-v1.yaml)
