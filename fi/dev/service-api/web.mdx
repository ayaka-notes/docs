webin, Overleafin pääsovelluksen, yksityinen API. Muut palvelut (real-time, document-updater, project-history, third-party-datastore, git-bridge) ja Server CE -imagen cron-skriptit kutsuvat sitä. Nämä reitit vaativat vain HTTP basic -todennuksen, ei CSRF-tunnusta: yksityinen reititin liitetään ennen web-reititintä, ja vain web-reititin tekee CSRF-tarkistuksen. Kun `BLOCK_CROSS_ORIGIN_REQUESTS=true` (oletuksena pois), web palauttaa 403 jokaiselle pyynnölle, jonka `Origin`-otsake ei ole listassa `ALLOWED_ORIGINS` (oletus: sivuston URL). Selaimet lähettävät `Origin`-otsakkeen POST-pyynnöissä, joten asetuksen ollessa päällä selaimen Hoppscotchista lähetetyt POST-pyynnöt saavat 403:n, elleivät ne kulje Hoppscotch-välityspalvelimen kautta.

* <strong>Osoite:</strong> `http://web:3000`, Docker-verkon sisällä
* <strong>Todennus:</strong> HTTP basic -todennus muuttujilla `WEB_API_USER` ja `WEB_API_PASSWORD`, paitsi status-, health- ja metrics-reiteillä. git-bridge-reitit käyttävät sen sijaan henkilökohtaista käyttötunnusta.
* <strong>OpenAPI-tiedosto:</strong> [`develop/hoppscotch/openapi/web.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/web.yaml)
