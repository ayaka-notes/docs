Ylläpitää editorin socket.io-yhteyksiä ja välittää muokkauksia ja tapahtumia selainten, webin ja document-updaterin välillä. Tämä tiedosto kattaa vain sen HTTP-reitit; polun `/socket.io/1/` socket.io-protokollaa ei kuvata.

* <strong>Osoite:</strong> `http://real-time:3026`, Docker-verkon sisällä
* <strong>Todennus:</strong> ei mitään
* <strong>OpenAPI-tiedosto:</strong> [`develop/hoppscotch/openapi/real-time.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/real-time.yaml)
