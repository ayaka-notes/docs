Tarjoilee tiedostoja objektitallennuksesta: mallitiedostot (zip, pdf ja niiden esikatselukuvat) sekä vain luku -tilassa history-v1:n kirjoittamat projekti- ja globaalit blobit. Sitä kutsuvat web (template-gallery-moduuli, käännösten tiedosto-URL:t) ja clsi, joka lataa siitä projektin binääritiedostot.

* <strong>Osoite:</strong> `http://filestore:3009`, Docker-verkon sisällä
* <strong>Todennus:</strong> ei mitään
* <strong>OpenAPI-tiedosto:</strong> [`develop/hoppscotch/openapi/filestore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/filestore.yaml)
