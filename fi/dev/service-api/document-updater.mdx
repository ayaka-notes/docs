Pitää editorissa avoinna olevat dokumentit Redisissä, soveltaa niihin muokkaukset ja kirjoittaa ne takaisin Mongoon webin kautta. web ja real-time kutsuvat sitä.

* <strong>Osoite:</strong> `http://document-updater:3003`, Docker-verkon sisällä
* <strong>Todennus:</strong> ei mitään
* <strong>OpenAPI-tiedosto:</strong> [`develop/hoppscotch/openapi/document-updater.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/document-updater.yaml)
