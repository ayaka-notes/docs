Tallentaa projektin chatin ja kommenttiketjut (niiden viestit ja ratkaistu-tilan) Mongo-kokoelmiin `rooms` ja `messages`. web kutsuu sitä `ChatApiHandler`-käsittelijän kautta.

* <strong>Osoite:</strong> `http://chat:3010`, Docker-verkon sisällä
* <strong>Todennus:</strong> ei mitään
* <strong>OpenAPI-tiedosto:</strong> [`develop/hoppscotch/openapi/chat.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/chat.yaml)
