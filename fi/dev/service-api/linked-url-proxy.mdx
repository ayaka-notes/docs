Hakee ulkoisen URL-osoitteen webille ja suoratoistaa vastauksen takaisin, ja hylkää sisäiset osoitteet, jotta käyttäjät eivät pääse Docker-verkkoon. web ohjaa sen kautta URL-tiedostot, Open in Overleaf -tuonnit ja tekoälyagentin web_fetchin.

* <strong>Osoite:</strong> `http://linked-url-proxy:3066`, Docker-verkon sisällä
* <strong>Todennus:</strong> ei mitään
* <strong>OpenAPI-tiedosto:</strong> [`develop/hoppscotch/openapi/linked-url-proxy.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/linked-url-proxy.yaml)
