Tallentaa jokaisen projektin jokaisen dokumentin (rivit, versio, alueet) Mongo-kokoelmaan `docs` ja arkistoi dokumentit objektitallennukseen, kun taustajärjestelmä on asetettu. web kutsuu sitä; document-updater käyttää sitä webin kautta.

* <strong>Osoite:</strong> `http://docstore:3016`, Docker-verkon sisällä
* <strong>Todennus:</strong> ei mitään
* <strong>OpenAPI-tiedosto:</strong> [`develop/hoppscotch/openapi/docstore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/docstore.yaml)
