Overleaf toimii useina palveluina, jotka kutsuvat toisiaan HTTP:n kautta Docker-verkon sisällä. Tämän osion sivut kuvaavat näitä sisäisiä API-rajapintoja. Ne perustuvat hakemiston [`develop/hoppscotch/openapi/`](https://github.com/ayaka-notes/ayakaleaf-pro/tree/server-pro/develop/hoppscotch/openapi) OpenAPI-tiedostoihin, jotka on kirjoitettu kunkin palvelun koodin pohjalta.

Mikään näistä API-rajapinnoista ei ole julkinen: niihin pääsee vain Docker-verkon sisältä, eikä useimmissa ole todennusta.

## Palvelut {#services}

| Palvelu | Osoite | Mitä se tekee |
| ------------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------------------ |
| [web](/fi/dev/service-api/web)                                     | `http://web:3000`                   | Pääsovellus. Sen yksityistä API:a kutsuvat muut palvelut ja imagen cron-skriptit  |
| [document-updater](/fi/dev/service-api/document-updater)           | `http://document-updater:3003`      | Pitää editorissa avoinna olevat dokumentit Redisissä, soveltaa muokkaukset ja kirjoittaa ne takaisin Mongoon         |
| [docstore](/fi/dev/service-api/docstore)                           | `http://docstore:3016`              | Tallentaa jokaisen projektin jokaisen dokumentin Mongo-kokoelmaan `docs`                                 |
| [real-time](/fi/dev/service-api/real-time)                         | `http://real-time:3026`             | Ylläpitää editorin socket.io-yhteyksiä ja välittää muokkauksia selainten ja palvelujen välillä          |
| [chat](/fi/dev/service-api/chat)                                   | `http://chat:3010`                  | Tallentaa projektin chatin ja kommenttiketjut                                                  |
| [project-history](/fi/dev/service-api/project-history)             | `http://project-history:3054`       | Muuttaa jonossa olevat muokkaukset historiamuutoksiksi ja lähettää ne history-v1:lle; säilyttää tunnisteet               |
| [history-v1](/fi/dev/service-api/history-v1)                       | `http://history-v1:3100`            | Tallentaa jokaisen projektin koko historian ja tiedostojen sisällön blobeina                           |
| [filestore](/fi/dev/service-api/filestore)                         | `http://filestore:3009`             | Tarjoilee mallitiedostot ja vain luku -tilassa history-v1:n kirjoittamat blobit                           |
| [clsi](/fi/dev/service-api/clsi)                                   | `http://clsi:3013`                  | Kääntää projektit, ajaa SyncTeX:n ja sanalaskennan, muuntaa asiakirjoja                              |
| [notifications](/fi/dev/service-api/notifications)                 | `http://notifications:3042`         | Tallentaa projektiluettelossa näytettävät ilmoitukset                                               |
| [linked-url-proxy](/fi/dev/service-api/linked-url-proxy)           | `http://linked-url-proxy:3066`      | Hakee ulkoisia URL-osoitteita webille ja hylkää sisäiset osoitteet                                     |
| [third-party-datastore](/fi/dev/service-api/third-party-datastore) | `http://third-party-datastore:3002` | Synkronoi projekteja Dropboxin kanssa yhden käyttäjäkohtaisen työjonon kautta                                       |

## Todennus {#authentication}

* <strong>web:</strong> HTTP basic -todennus muuttujilla `WEB_API_USER` ja `WEB_API_PASSWORD`. git-bridge-reitit käyttävät sen sijaan henkilökohtaista käyttötunnusta.
* <strong>history-v1:</strong> HTTP basic -todennus käyttäjänä `staging` salasanalla `STAGING_PASSWORD` tai JWT.
* <strong>Kaikki muut palvelut:</strong> ei mitään.

## Kokeile niitä {#try-them}

Kehitysympäristö ajaa [Hoppscotchia](https://github.com/hoppscotch/hoppscotch) osoitteessa `http://localhost:9170` välityspalvelimen kanssa, joka tavoittaa palvelut niiden Docker-osoitteilla. Sen [README](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/README.md#hoppscotch) näyttää, miten välityspalvelin asetetaan ja OpenAPI-tiedostot tuodaan.
