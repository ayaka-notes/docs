CLSI (Common LaTeX Service Interface) kääntää projektit, ajaa SyncTeX:n ja texcountin käännöksen tulosteelle ja muuntaa asiakirjoja pandocilla. web kutsuu sitä; tulostetiedostot tarjoilee clsi-nginx, ei tämä portti. Ei todennusta: siihen pääsee vain Docker-verkon sisältä.

* <strong>Osoite:</strong> `http://clsi:3013`, Docker-verkon sisällä
* <strong>Todennus:</strong> ei mitään
* <strong>OpenAPI-tiedosto:</strong> [`develop/hoppscotch/openapi/clsi.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/clsi.yaml)
