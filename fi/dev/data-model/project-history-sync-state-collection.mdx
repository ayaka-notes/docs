---
title: Project History Sync State -kokoelma
icon: rotate
---

`projectHistorySyncState` sisältää yhden dokumentin jokaista uudelleensynkronoitua projektia kohden: käynnissä olevan tai viimeisimmän uudelleensynkronoinnin tilan, kun project-history rakentaa projektin historian uudelleen siitä, mitä webissä ja docstoressa on. Kokoelman omistaa project-history, eikä sillä ole Mongoose-skeemaa; koodi on luokka `SyncState` apufunktioineen tiedostossa `services/project-history/app/js/SyncManager.js`.

#### Kuka kirjoittaa {#who-writes-it}

| Koodi | Mitä se tekee |
| ---- | ------------ |
| `services/project-history/app/js/SyncManager.js:195-249` | `setResyncState`: tilan upsert. Kutsutaan, kun uudelleensynkronointi alkaa (`SyncManager.js:163`), ja kun project-history käsittelee uudelleensynkronoinnin päivityksiä (`services/project-history/app/js/UpdatesProcessor.js:637`, `784`). |
| `SyncManager.js:257-266` | `_recordStuckClearInSyncState`: laskee tyhjennetyn jumittuneen uudelleensynkronoinnin. |
| `SyncManager.js:251-255` | `clearResyncState`: poistaa dokumentin kovan uudelleensynkronoinnin alussa (`SyncManager.js:87`), project-historyn reitissä `DELETE /project/:project_id` (`services/project-history/app/js/HttpController.js:1363-1396`) ja kun pelkän rakenteen uudelleensynkronointi täytyy aloittaa alusta (`SyncManager.js:705-716`). |
| `SyncManager.js:273-289` | `clearResyncStateIfAllAfter`: poistaa päättyneen tilan, jonka koko historia on tiettyä päivämäärää uudempi. Mikään hakemistossa `app/js` ei kutsu sitä. |
| `SyncManager.js:171-181` | `cloneResyncState`: kopioi tilan toiseen projektiin project-historyn reittiä `POST /project/:project_id/clone` varten (`HttpController.js:57`, `124`), jota mikään webissä ei kutsu. |

Uudelleensynkronoinnin käynnistää project-historyn `POST /project/:project_id/resync` (`HttpController.js:950-994`), uudelleenyritysten cron-työt (`services/project-history/app/js/RetryManager.js:156-179`, `server-ce/config/crontab-history`) ja project-history itse, kun päivitysten käsittely tarvitsee sitä (`UpdatesProcessor.js:75`, `224`).

#### Huomautukset {#notes}

* Uudelleensynkronointi on käynnissä niin kauan kuin `resyncProjectStructure` on `true` tai `resyncDocContents` ei ole tyhjä (`SyncManager.js:565-567`). Sitä pidetään jumittuneena 4 tunnin jälkeen ja pysyvästi jumittuneena 5 tyhjennyksen jälkeen (`SyncManager.js:43-44`, `569-585`).
* Kun uudelleensynkronointi päättyy, project-history asettaa projektiin myös kentän `overleaf.history.lastResyncedAt` (`SyncManager.js:239-248`).
