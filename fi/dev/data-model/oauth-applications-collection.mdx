title: OAuth Applications -kokoelma

`oauthApplications` sisältää OAuth-asiakkaat, jotka web tuntee. Yksi dokumentti on yksi asiakas. Ayakaleaf Prossa siihen kirjoittaa vain web-moduuli `git-bridge`, joka luo webin käynnistyessä yhden asiakkaan nimeltä `Overleaf Git Bridge`. Skeema on `services/web/app/src/models/OauthApplication.mjs`.

#### Kentät {#fields}

| Kenttä | Tyyppi | Merkitys | Lähde |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Asiakasdokumentin id. `oauthAccessTokens.oauthApplication_id` ja `oauthAuthorizationCodes.oauthApplication_id` viittaavat siihen. | `OauthApplication.mjs:5` |
| `id` | String | Asiakkaan id: 64 satunnaista pientä kirjainta ja numeroa. | `OauthApplication.mjs:7`, `services/web/modules/git-bridge/index.mjs:25` |
| `clientSecret` | String | Asiakkaan salaisuus, kirjoitettuna muodossa `v1.` ja 32 satunnaista merkkiä. Vain `getClient` lukee sen, eikä mikään kutsu `getClient`-funktiota (katso Huomautukset). | `OauthApplication.mjs:8`, `git-bridge/index.mjs:26` |
| `grants` | Array of String | Grant-tyypit. Git-bridge-asiakkaalla on `['password']`. Palautetaan asiakkaan mukana, kun token tarkistetaan (`services/web/modules/oauth2-server/app/src/OAuth2Model.mjs:67-72`). | `OauthApplication.mjs:9`, `git-bridge/index.mjs:27` |
| `name` | String | Asiakkaan nimi. Git-bridge-moduuli ja henkilökohtaisten käyttötunnusten koodi löytävät asiakkaan nimellä `Overleaf Git Bridge`. | `OauthApplication.mjs:10`, `git-bridge/index.mjs:15-16,28` |
| `redirectUris` | Array of String | Sallitut uudelleenohjaus-URI:t. Git-bridge-asiakkaalla `[]`. | `OauthApplication.mjs:11`, `git-bridge/index.mjs:29` |
| `scopes` | Array of String | Scopet, joita asiakas saa käyttää. Git-bridge-asiakkaalla `['git_bridge']`. | `OauthApplication.mjs:12`, `git-bridge/index.mjs:30` |
| `pkceEnabled` | Boolean | Vain skeemassa: mikään tämän repositorion koodi ei kirjoita sitä, ja vain käyttämätön `getClient` lukee sen (`OAuth2Model.mjs:207`). | `OauthApplication.mjs:13` |

#### Kuka kirjoittaa {#who-writes-it}

| Koodi | Mitä se tekee |
| ---- | ------------ |
| `git-bridge/index.mjs:9-35` (module `git-bridge`) | Kun `GIT_BRIDGE_ENABLED` on `true`, luo webin käynnistyessä asiakkaan `Overleaf Git Bridge`, jos sen nimistä asiakasta ei vielä ole. |

#### Kuka lukee {#who-reads-it}

| Koodi | Mitä se tekee |
| ---- | ------------ |
| `services/web/modules/oauth2-server/app/src/OAuthPersonalAccessTokenManager.mjs:53-61` (module `oauth2-server`) | Etsii asiakkaan `Overleaf Git Bridge` nimellä ja tallentaa sen `_id`:n jokaiseen uuteen henkilökohtaiseen käyttötunnukseen. Ilman asiakasta tunnusta ei luoda. |
| `OAuth2Model.mjs:31-39,67-72` (`getAccessToken`) | Lataa tokenin asiakkaan `oauthApplication_id`:n kautta ja palauttaa sen `id`:n ja `grants`-kentän. |
| `OAuth2Model.mjs:185-209,241,275` (`getClient`, `saveToken`, `saveAuthorizationCode`) | Hakevat asiakkaita `id`:n perusteella. Niihin ei koskaan päädytä tässä repositoriossa, katso Huomautukset. |

#### Indeksit {#indexes}

Vain oletusindeksi kentällä `_id`. Yksilöllinen indeksi `id_1` tulee migraatioista, joilla on tagit `saas` (`20190912145016_create_oauthApplications_indexes.mjs`) ja `server-pro` (`20230502180757_server_pro_oauth_indexes.mjs`), eikä Community Edition aja niitä.

#### Huomautukset {#notes}

* Web käyttää `@node-oauth/oauth2-server`-kirjastoa vain bearer-tokenien tarkistamiseen (`server.authenticate` tiedostossa `services/web/app/src/Features/Authentication/AuthenticationController.mjs:409-450`), mikä kutsuu vain mallin funktioita `getAccessToken` ja `verifyScope`. Mikään reitti ei palvele osoitteita `/oauth/token` tai `/oauth/authorize`, joten `getClient`, `saveToken` ja `saveAuthorizationCode` eivät koskaan tule kutsutuiksi.
* Moduuli etsii asiakkaan nimellä ja luo sen sitten, eikä Community Editionissa ole yksilöllistä indeksiä kentille `name` tai `id`. Mikään ei siis estä toista samannimistä asiakasta. Asiakasta tarvitseva koodi ottaa sen, jonka `findOne` palauttaa.
