---
title: GitHub Sync User Credentials -kokoelma
icon: key
---

`githubSyncUserCredentials` sisältää yhden dokumentin jokaista käyttäjää kohden, joka on linkittänyt GitHub-tilin GitHub Syncia varten. Se tallentaa käyttäjän OAuth-käyttötunnisteen salattuna. Kokoelma kuuluu web-moduuliin `github-sync` (`services/web/modules/github-sync`). Skeema on tiedostossa `services/web/modules/github-sync/app/models/githubSyncUserCredentials.mjs`, ja kaikki käyttö kulkee `services/web/modules/github-sync/app/src/TokenManager.mjs` kautta.

#### Kentät {#fields}

| Kenttä | Tyyppi | Merkitys | Lähde |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Mongoose asettaa, kun upsert lisää dokumentin. | |
| `userId` | ObjectId | Overleaf-käyttäjä. Pakollinen. Skeemassa lukee `unique: true`, mutta indeksiä ei rakenneta (katso Indeksit); upsert `userId`-kentän mukaan pitää yhden dokumentin käyttäjää kohden. | `githubSyncUserCredentials.mjs:8`, `TokenManager.mjs:44-48` |
| `github` | String | GitHubin OAuth-käyttötunniste, salattu `@overleaf/access-token-encryptor`-kirjastolla. Salasana tulee muuttujasta `GITHUB_TOKEN_CIPHER_PASSWORD`; salauksen tunniste on `GITHUB_TOKEN_CIPHER_LABEL`, oletus `2026.3-v3`. Pakollinen. | `githubSyncUserCredentials.mjs:9`, `TokenManager.mjs:12-25` |
| `__v` | Number | Mongoosen versioavain. Skeema ei poista sitä käytöstä. | Mongoosen oletus |

Vain käyttötunniste tallennetaan: OAuth-callback säilyttää GitHubin vastauksesta kentän `access_token` (`services/web/modules/github-sync/app/src/GitHubApiClient.mjs:180-191`). Päivitystunnistetta tai vanhenemisaikaa ei ole.

#### Kuka kirjoittaa {#who-writes-it}

| Koodi | Mitä se tekee |
| ---- | ------------ |
| `TokenManager.mjs:42-58` (`saveUserToken`) | Tekee upsertin käyttäjän salatusta tunnisteesta. Kun käyttäjä linkittää uudelleen, korvattu tunniste mitätöidään GitHubissa taustalla. Kutsutaan OAuth-callbackista (`services/web/modules/github-sync/app/src/GitHubSyncController.mjs:146`). |
| `TokenManager.mjs:61-76` (`removeUserToken`) | Mitätöi tunnisteen GitHubissa (parhaan kyvyn mukaan) ja poistaa sitten dokumentin. Kutsutaan linkityksen poistossa (`GitHubSyncController.mjs:167`) ja kun poistettu käyttäjä vanhenee (`services/web/modules/github-sync/index.mjs:66-68`). |

#### Kuka lukee {#who-reads-it}

| Koodi | Mitä se tekee |
| ---- | ------------ |
| `TokenManager.mjs:36-40` (`getUserToken`) | Purkaa tunnisteen salauksen jokaista GitHubin API-kutsua varten: `services/web/modules/github-sync/app/src/GitHubSyncHandler.mjs` (esimerkiksi `:27`) ja `services/web/modules/github-sync/app/src/GitMerge.mjs:43`. Ilman dokumenttia tai jos tunnisteen salausta ei voi purkaa, se heittää `InvalidTokenError`, ja käyttäjä katsotaan linkittämättömäksi (`GitHubSyncHandler.mjs:25-37`). |
| `services/web/modules/admin-tools/app/src/AdminUserListManager.mjs:393` | Tarkistaa, onko käyttäjällä dokumentti, hallintapaneelissa näytettäviä integraatioita varten. |

#### Indeksit {#indexes}

| Nimi | Avaimet | Asetukset | Migraatio |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

Mongoosen `autoIndex` on pois päältä (`services/web/app/src/infrastructure/Mongoose.mjs:7`), joten skeeman `unique: true` kentässä `userId` ei luo mitään. `tools/migrations/20190912145011_create_githubSyncUserCredentials_indexes.mjs` (upstreamin `user_id`) on merkitty vain tagilla `saas` eikä aja CE:ssä.

#### Huomautukset {#notes}

* Muuttujan `GITHUB_TOKEN_CIPHER_PASSWORD` muuttaminen tekee tallennetuista tunnisteista lukukelvottomia. Nämä käyttäjät katsotaan silloin linkittämättömiksi, kunnes he linkittävät uudelleen.
* Poistettu käyttäjä säilyttää dokumentin, kunnes käyttäjä vanhenee.
