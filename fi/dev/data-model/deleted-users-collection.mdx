---
title: Deleted Users -kokoelma
icon: user-xmark
---

`deletedUsers` säilyttää käyttäjätilin sen poistamisen jälkeen: yksi dokumentti jokaista poistettua tiliä kohden, ja siinä kopio koko käyttäjädokumentista sekä tieto siitä, kuka tilin poisti. Web kirjoittaa kokoelman tiedostossa `services/web/app/src/Features/User/UserDeleter.mjs`; skeema on `services/web/app/src/models/DeletedUser.mjs`. Kun lopullisen poiston viive on kulunut, vanhentumiskäsittely poistaa käyttäjän kopion, mutta tietue, jossa on `deleterData`, säilyy.

Käyttäjän poistaminen poistaa myös käyttäjän omistamat projektit; ne päätyvät kokoelmaan [Deleted Projects -kokoelma](/fi/dev/data-model/deleted-projects-collection) syyllä `account-deletion`.

#### Kuka kirjoittaa {#who-writes-it}

| Koodi | Mitä se tekee |
| ---- | ------------ |
| `UserDeleter.mjs:37-80` (`deleteUser`) | Lisää tarkastuslokimerkinnän `delete-account`, siivoaa käyttäjän ja laukaisee koukun `deleteUser`, tekee tietueelle upsertin (`_createDeletedUser`, `UserDeleter.mjs:192-213`), poistaa käyttäjän projektit, lähettää tietoturvavaroitussähköpostin, ellei sitä ohiteta, ja poistaa `users`-dokumentin. Kutsujat: tilin asetussivu (`services/web/app/src/Features/User/UserController.mjs:280-284`), hallintapaneeli (`services/web/modules/admin-tools/app/src/AdminUserManager.mjs:604-612`) ja `delete-user`-skripti (`delete-user.mjs:40-45`). |
| `UserDeleter.mjs:93-115` (`expireDeletedUser`) | Laukaisee koukun `expireDeletedUser`, poistaa käyttäjän perehdytystiedot ja poistaa sitten kentät `user` ja `deleterData.deleterIpAddress`. |
| `UserDeleter.mjs:117-161` (`expireDeletedUsersAfterDuration`) | Vanhentaa jokaisen viivettä vanhemman tietueen ja poistaa käyttäjän `userAuditLogEntries`-merkinnät. Reitti `POST /internal/expire-deleted-users-after-duration` (`services/web/app/src/router.mjs:847-851`), jota Community Editionin cron kutsuu joka tunti minuutilla 15, kun `ENABLE_CRON_RESOURCE_DELETION` on `true` (`server-ce/cron/delete-users.sh:10-23`, `server-ce/config/crontab-deletion:2`). Yksi käyttäjä: `POST /internal/users/:userId/expire` (`router.mjs:857-861`). |
| `AdminUserManager.mjs:630-649` (`purgeDeletedUser`, moduuli `admin-tools`) | Purge hallintapaneelissa: suorittaa `expireDeletedUser`-toiminnon ja poistaa käyttäjän tarkastuslokimerkinnät. |
| `AdminUserManager.mjs:651-696` (`restoreDeletedUser`, moduuli `admin-tools`) | Palautus hallintapaneelissa: luo `users`-dokumentin uudelleen kentästä `user` (hylätään, jos sähköpostiosoite on varattu), poistaa tietueen ja palauttaa tilin mukana poistetut projektit. |

#### Huomautukset {#notes}

* Moduulit, jotka kuuntelevat tapahtumaa `expireDeletedUser`, poistavat omat tietonsa käyttäjästä: `dropbox` (`services/web/modules/dropbox/index.mjs:62`), `github-sync` (`services/web/modules/github-sync/index.mjs:66`), `gitlab-sync` (`services/web/modules/gitlab-sync/index.mjs:56`) ja `gitea-sync` (`services/web/modules/gitea-sync/index.mjs:56`).
* Vanhentunutta tietuetta ei koskaan poisteta: `deleterData` säilyy pysyvästi, vain `user` ja IP-osoite poistetaan.
* Käyttäjän henkilökohtaisia käyttötunnuksia ei poisteta tilin mukana, katso [OAuth Access Tokens -kokoelma](/fi/dev/data-model/oauth-access-tokens-collection).
* Mongoose antaa myös kentälle `deleterData` oman `_id`:n, jota mikään ei lue.
