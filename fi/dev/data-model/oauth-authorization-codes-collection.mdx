---
title: OAuth Authorization Codes -kokoelma
icon: lock-open
---

`oauthAuthorizationCodes` on tarkoitettu OAuthin authorization code -kulun koodeille: yksi dokumentti koodia kohden, jonka asiakas vaihtaa käyttötunnukseen. Skeema on `services/web/app/src/models/OauthAuthorizationCode.mjs`, ja web-moduulissa `oauth2-server` on koodi, joka kirjoittaisi siihen. Ayakaleaf Prossa mikään ei päädy tähän koodiin, joten kokoelma pysyy tyhjänä (katso Huomautukset).

#### Kentät {#fields}

| Kenttä | Tyyppi | Merkitys | Lähde |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Dokumentin id. | `OauthAuthorizationCode.mjs:6` |
| `authorizationCode` | String | Itse koodi, tallennettuna sellaisenaan (ei tiivistettynä). | `OauthAuthorizationCode.mjs:8`, `services/web/modules/oauth2-server/app/src/OAuth2Model.mjs:280` |
| `expiresAt` | Date | Voimassaolon loppu. Sen jälkeen `getAuthorizationCode` hylkää koodin, ja TTL-indeksi poistaa sen. | `OauthAuthorizationCode.mjs:9`, `OAuth2Model.mjs:150-153,281` |
| `oauthApplication_id` | ObjectId | Koodia pyytänyt asiakas kokoelmassa [OAuth Applications](/fi/dev/data-model/oauth-applications-collection). | `OauthAuthorizationCode.mjs:10`, `OAuth2Model.mjs:275-284` |
| `redirectUri` | String | Pyynnön uudelleenohjaus-URI. | `OauthAuthorizationCode.mjs:11`, `OAuth2Model.mjs:282` |
| `scope` | String | Pyydetty scope. | `OauthAuthorizationCode.mjs:12`, `OAuth2Model.mjs:283` |
| `user_id` | ObjectId | Käyttäjä, joka myönsi koodin. | `OauthAuthorizationCode.mjs:13`, `OAuth2Model.mjs:285` |
| `codeChallenge`, `codeChallengeMethod` | String | PKCE-challenge ja sen menetelmä. | `OauthAuthorizationCode.mjs:14-15`, `OAuth2Model.mjs:286-287` |

#### Kuka kirjoittaa {#who-writes-it}

| Koodi | Mitä se tekee |
| ---- | ------------ |
| `OAuth2Model.mjs:274-300` (`saveAuthorizationCode`) | Lisää koodin. Siihen ei päädytä, katso Huomautukset. |
| `OAuth2Model.mjs:307-312` (`revokeAuthorizationCode`) | Poistaa koodin, kun sitä on käytetty. Siihen ei päädytä. |

#### Kuka lukee {#who-reads-it}

| Koodi | Mitä se tekee |
| ---- | ------------ |
| `OAuth2Model.mjs:137-177` (`getAuthorizationCode`) | Lataa koodin käyttäjineen ja asiakkaineen. Siihen ei päädytä. |

#### Indeksit {#indexes}

| Nimi | Avaimet | Asetukset | Migraatio |
| ---- | ---- | ------- | --------- |
| `expiresAt_1` | `{ expiresAt: 1 }` | TTL, `expireAfterSeconds: 0`, osittainen: `expiresAt` on olemassa | `20230406125632_oauth_tokens_ttl.mjs` |

Migraatiot ovat hakemistossa `tools/migrations/`. Yksilöllinen indeksi `authorizationCode_1` tulee vain migraatioista, joilla on tagit `saas` ja `server-pro`, eikä Community Edition aja niitä.

#### Huomautukset {#notes}

* Yllä olevia mallin metodeja kutsuvat vain kirjaston `@node-oauth/oauth2-server` authorize- ja token-käsittelijät. Web käyttää kirjastoa vain bearer-tokenien tarkistamiseen (`services/web/app/src/Features/Authentication/AuthenticationController.mjs:409-450`), eikä mikään reitti palvele osoitteita `/oauth/authorize` tai `/oauth/token`, joten koodia ei koskaan kirjoiteta. Henkilökohtaiset käyttötunnukset luodaan suoraan, katso [OAuth Access Tokens](/fi/dev/data-model/oauth-access-tokens-collection).
