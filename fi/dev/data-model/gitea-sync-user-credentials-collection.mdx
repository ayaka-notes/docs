---
title: Gitea Sync User Credentials -kokoelma
icon: lock
---

`giteaSyncUserCredentials` sisältää yhden dokumentin jokaista käyttäjää kohden, joka on linkittänyt Gitea-tilin Gitea Syncia varten. Se tallentaa käyttäjän OAuth-tunnisteet salattuina. Kokoelma kuuluu web-moduuliin `gitea-sync` (`services/web/modules/gitea-sync`). Skeema on tiedostossa `services/web/modules/gitea-sync/app/models/giteaSyncUserCredentials.mjs`, ja kaikki käyttö kulkee `services/web/modules/gitea-sync/app/src/TokenManager.mjs` kautta.

#### Kentät {#fields}

| Kenttä | Tyyppi | Merkitys | Lähde |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Mongoose asettaa, kun upsert lisää dokumentin. | |
| `userId` | ObjectId | Overleaf-käyttäjä. Pakollinen. Skeemassa lukee `unique: true`, mutta indeksiä ei rakenneta (katso Indeksit); upsert `userId`-kentän mukaan pitää yhden dokumentin käyttäjää kohden. | `giteaSyncUserCredentials.mjs:8`, `TokenManager.mjs:89-96` |
| `gitea` | String | JSON `{ accessToken, refreshToken, expiresAt }`, salattu `@overleaf/access-token-encryptor`-kirjastolla. `expiresAt` on millisekunteina epochista tai `null`; `refreshToken` voi olla `null`. Salasana tulee muuttujasta `GITEA_TOKEN_CIPHER_PASSWORD`; salauksen tunniste on `GITEA_TOKEN_CIPHER_LABEL`, oletus `2026.10-v3`. Pakollinen. | `giteaSyncUserCredentials.mjs:9-10`, `TokenManager.mjs:17-30`, `services/web/modules/gitea-sync/app/src/GiteaApiClient.mjs:198-209` |
| `__v` | Number | Mongoosen versioavain. Skeema ei poista sitä käytöstä. | Mongoosen oletus |

#### Kuka kirjoittaa {#who-writes-it}

| Koodi | Mitä se tekee |
| ---- | ------------ |
| `TokenManager.mjs:89-96` (`saveUserToken`) | Tekee upsertin käyttäjän salatuista tunnistetiedoista. Kutsutaan OAuth-callbackista (`services/web/modules/gitea-sync/app/src/GiteaSyncController.mjs:146`). Toisin kuin GitLab Syncissa, uudelleenlinkitys ei mitätöi korvattua tunnistetta. |
| `TokenManager.mjs:53-79` (`refreshUserToken`) | Kun käyttötunnisteen `expiresAt`-aikaan on alle 5 minuuttia (`:12`), se hakee päivitystunnisteella uudet tunnisteet ja tallentaa ne (`:76`). Se ajetaan käyttäjäkohtaisen lukon `giteaSyncToken` alla (`:14,54`), koska Gitea korvaa päivitystunnisteen käytössä. |
| `TokenManager.mjs:100-102` (`removeUserToken`) | Poistaa dokumentin. Gitealla ei ole APIa OAuth-tunnisteen mitätöintiin, joten käyttäjä peruu valtuutuksen Giteassa (`:98-99`). Kutsutaan linkityksen poistossa (`GiteaSyncController.mjs:173`) ja kun poistettu käyttäjä vanhenee (`services/web/modules/gitea-sync/index.mjs:56-58`). |

#### Kuka lukee {#who-reads-it}

| Koodi | Mitä se tekee |
| ---- | ------------ |
| `TokenManager.mjs:40-44,82-86` (`getUserCredentials`, `getUserToken`) | Purkaa tunnistetietojen salauksen jokaista Gitea:n API-kutsua varten ja päivittää ne ensin, jos tunniste on vanhenemassa: `services/web/modules/gitea-sync/app/src/GiteaSyncHandler.mjs` (esimerkiksi `:27`) ja `services/web/modules/gitea-sync/app/src/GitMerge.mjs:52`. Ilman dokumenttia tai jos tunnistetietojen salausta ei voi purkaa tai niitä ei voi päivittää, se heittää `InvalidTokenError`, ja käyttäjä katsotaan linkittämättömäksi (`GiteaSyncHandler.mjs:25-37`). |
| `services/web/modules/admin-tools/app/src/AdminUserListManager.mjs:395` | Tarkistaa, onko käyttäjällä dokumentti, hallintapaneelissa näytettäviä integraatioita varten. |

#### Indeksit {#indexes}

| Nimi | Avaimet | Asetukset | Migraatio |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

Mongoosen `autoIndex` on pois päältä (`services/web/app/src/infrastructure/Mongoose.mjs:7`), joten skeeman `unique: true` kentässä `userId` ei luo mitään. Mikään migraatio ei luo indeksejä tälle kokoelmalle.

#### Huomautukset {#notes}

* Muuttujan `GITEA_TOKEN_CIPHER_PASSWORD` muuttaminen tekee tallennetuista tunnistetiedoista lukukelvottomia. Nämä käyttäjät katsotaan silloin linkittämättömiksi, kunnes he linkittävät uudelleen.
* Poistettu käyttäjä säilyttää dokumentin, kunnes käyttäjä vanhenee.
