title: Doc-Snapshots-kokoelma
icon: camera
---

`docSnapshots` sisältää kopioita dokumentista, jotka document-updater ottaa juuri ennen muokkausta, joka tiivistää kommentteja tai seurattuja muutoksia. Vain document-updater kirjoittaa siihen, tiedostossa `services/document-updater/app/js/SnapshotManager.js`. Webillä on Mongoose-malli tiedostossa `services/web/app/src/models/DocSnapshot.mjs`, mutta mikään koodi ei käytä sitä.

#### Kentät {#fields}

| Kenttä | Tyyppi | Merkitys | Lähde |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Tilannevedoksen tunniste. | `SnapshotManager.js:24` |
| `project_id` | ObjectId | Projekti. | `SnapshotManager.js:19,26`, `DocSnapshot.mjs:7` |
| `doc_id` | ObjectId | Dokumentti (`docs._id`). | `SnapshotManager.js:20,27`, `DocSnapshot.mjs:8` |
| `version` | Number | Dokumentin OT-versio ennen muokkausta. | `SnapshotManager.js:28`, `services/document-updater/app/js/UpdateManager.js:132,264-271`, `DocSnapshot.mjs:9` |
| `lines` | Array of String | Dokumentin sisältö ennen muokkausta. | `SnapshotManager.js:29`, `DocSnapshot.mjs:10` |
| `pathname` | String | Dokumentin polku projektissa sillä hetkellä. | `SnapshotManager.js:30`, `DocSnapshot.mjs:11` |
| `ranges` | Mixed | `comments` ja `changes` ennen muokkausta, samassa muodossa kuin `docs.ranges` (katso [docs](/fi/dev/data-model/docs-collection)). `id`, `op.t` ja `metadata.user_id` muunnetaan ObjectId-arvoiksi ja `metadata.ts` Date-arvoksi. | `SnapshotManager.js:31,41-68`, `DocSnapshot.mjs:12` |
| `ts` | Date | Milloin tilannevedos otettiin. TTL-indeksi poistaa sen 30 päivän kuluttua. | `SnapshotManager.js:32`, `DocSnapshot.mjs:13` |

#### Kuka kirjoittaa {#who-writes-it}

| Koodi | Mitä se tekee |
| ---- | ------------ |
| `UpdateManager.js:248-271` | Sovellettuaan muokkauksen document-updater tallentaa dokumentin muokkausta edeltävässä tilassa, jos muokkaus tiivisti alueita: tyhjiä alueita tuli lisää tai useampi kuin yksi alue poistettiin (`services/document-updater/app/js/RangesManager.js:104-106`). |
| `SnapshotManager.js:17-36` `recordSnapshot` | Lisää tilannevedoksen. |

#### Kuka lukee {#who-reads-it}

Mikään koodi ei lue sitä. Web-malli on määritelty, mutta sitä ei käytetä missään.

#### Huomautuksia {#notes}

* Vain `UpdateManager.applyUpdate`:n kautta kulkevat muokkaukset ottavat tilannevedoksia. `HistoryOTUpdateManager`:n käsittelemät muokkaukset eivät ota (`UpdateManager.js:74-77`).
* Kentällä `doc_id` ei ole indeksiä. Hae dokumentin tilannevedokset kentillä `project_id` ja `ts` ja suodata sitten kentällä `doc_id`.
