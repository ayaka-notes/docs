---
title: Dropbox Entities -kokoelma
icon: file-arrow-up
---

`dropboxEntities` sisältää yhden dokumentin jokaista tiedostoa kohden, jonka Dropbox-synkronointi on kopioinut projektin ja yhden käyttäjän Dropboxin välillä, sekä lyhytikäisiä tombstone-merkintöjä. Kokoelma kuuluu Dropbox-synkronointiin: third-party-datastore (`services/third-party-datastore/app/js/StateManager.mjs`) kirjoittaa ja lukee sen, ja `dropbox`-verkkomoduuli (`services/web/modules/dropbox/app/src/DropboxHandler.mjs`) tyhjentää sen. Mongoose-skeemaa ei ole.

#### Kentät {#fields}

| Kenttä | Tyyppi | Merkitys | Lähde |
| ------ | ------ | -------- | ----- |
| `_id` | ObjectId | Ajuri asettaa lisäyksen yhteydessä. | `StateManager.mjs:46,97` |
| `overleaf.userId` | ObjectId | Käyttäjä, jonka Dropboxissa tiedosto on. Asetetaan jokaiseen dokumenttiin. | `StateManager.mjs:48,98` |
| `overleaf.projectId` | ObjectId | Docin tai tiedoston projekti. Asetetaan, kun se tiedetään; tombstone-merkinnöillä sitä ei ole. | `StateManager.mjs:49-51` |
| `overleaf.id` | ObjectId | Docin tai tiedoston `_id` projektin `rootFolder`-kansiossa. Asetetaan, kun se tiedetään. | `StateManager.mjs:52` |
| `overleaf.type` | String | `doc` tai `file`. Nykyinen koodi kirjoittaa sen mutta ei lue sitä. | `StateManager.mjs:53`; arvot lähteistä `services/web/app/src/Features/ThirdPartyDataStore/TpdsUpdateSender.mjs:35,96` ja `UpdateMerger.mjs:104,119` |
| `dropbox.id` | String | Tiedoston `id` Dropboxin tiedostometatiedoissa. Ei asetettu tombstone-merkinnöille. | `StateManager.mjs:56` |
| `dropbox.pathLower` | String | Tiedoston polku Dropboxissa pienillä kirjaimilla ja ilman loppukauttaviivaa. Päivitetään, kun tiedosto tai sen projektikansio siirretään. | `StateManager.mjs:14-16,57,91,99` |
| `dropbox.rev` | String | Dropbox-revisio viimeisimmässä synkronoinnissa. Seuraava lataus lähettää sen, jotta Dropboxissa muuttunutta tiedostoa ei korvata. | `StateManager.mjs:58`, `JobProcessor.mjs:114-122` |
| `dropbox.contentHash` | String | Dropboxin sisältötiiviste viimeisimmässä synkronoinnissa. Listattu tiedosto, jolla on sama tiiviste, ohitetaan, koska se on oma latauksemme tai jo sovellettu. | `StateManager.mjs:59`, `PullManager.mjs:147-149` |
| `tombstone` | Boolean | `true` merkitsee polun, jonka third-party-datastore itse poisti tai siirsi pois Dropboxissa. Kun Dropbox ilmoittaa poistosta takaisin, sitä ei sovelleta projektiin. | `StateManager.mjs:100`, `PullManager.mjs:189-192` |
| `createdAt` | Date | Vain tombstone-merkinnät: milloin se luotiin. Valmistunut pull poistaa ennen sen alkua luodut tombstone-merkinnät. | `StateManager.mjs:101,115-121` |

Tombstone-merkinnällä on vain `overleaf.userId`, `dropbox.pathLower`, `tombstone` ja `createdAt` (`StateManager.mjs:96-103`).

#### Kuka kirjoittaa sen {#who-writes-it}

| Koodi | Mitä se tekee |
| ----- | ------------- |
| `services/third-party-datastore/app/js/StateManager.mjs:35-62` (`recordEntity`) | Poistaa käyttäjän dokumentit, joilla on sama `dropbox.id`, `dropbox.pathLower` tai `overleaf.id`, ja lisää sitten uuden tilan. |
| `services/third-party-datastore/app/js/JobProcessor.mjs:102-134` (`addEntity`) | Tallentaa docin tai tiedoston sen jälkeen, kun se on ladattu Overleafista Dropboxiin (`:125-133`). |
| `services/third-party-datastore/app/js/PullManager.mjs:142-177` (`applyFile`) | Tallentaa Dropbox-tiedoston sen jälkeen, kun web on soveltanut sen projektiin (`:168-176`). |
| `StateManager.mjs:80-94` (`moveEntities`) | Kirjoittaa `dropbox.pathLower`-arvon uudelleen siirretyn polun alla: projektin uudelleennimeäminen (`JobProcessor.mjs:195`) ja tiedoston tai kansion siirto (`JobProcessor.mjs:239`). |
| `StateManager.mjs:96-103` (`addTombstone`) | Poiston (`JobProcessor.mjs:153`), projektin uudelleennimeämisen (`:202`) tai siirron (`:240`) jälkeen Dropboxissa. |
| `StateManager.mjs:72-78` (`removeEntities`) | Poistaa merkinnät polussa ja sen alla tombstone-merkintöjä lukuun ottamatta: poiston jälkeen Overleafista (`JobProcessor.mjs:152`) tai Dropboxissa (`PullManager.mjs:206`). |
| `StateManager.mjs:115-121` (`clearTombstones`) | Pullin lopussa (`PullManager.mjs:31,69`). |
| `StateManager.mjs:186-190` (`removeUserState`), kutsutaan kohdasta `services/third-party-datastore/app/js/QueueWorker.mjs:43` | Poistaa kaikki käyttäjän dokumentit, kun third-party-datastore irrottaa tilin, jota se ei enää voi käyttää. |
| `DropboxHandler.mjs:142-146` (`removeUserState`) | Poistaa kaikki käyttäjän dokumentit linkitettäessä (`:125`), linkitystä purettaessa (`:183`) ja kun poistettu käyttäjä vanhenee (`services/web/modules/dropbox/index.mjs:62-64`). |
| `DropboxHandler.mjs:150-154` (`removeProjectState`) | Poistaa projektin dokumentit, kun poistettu projekti vanhenee (`index.mjs:54-56`). |

#### Kuka lukee sen {#who-reads-it}

| Koodi | Mitä se tekee |
| ----- | ------------- |
| `StateManager.mjs:64-70` (`findEntityByPath`) | Hakee `dropbox.rev`-arvon ennen latausta (`JobProcessor.mjs:114`) ja `dropbox.contentHash`-arvon ennen Dropbox-tiedoston soveltamista (`PullManager.mjs:147`). |
| `StateManager.mjs:106-112` (`findTombstone`) | Tarkistaa ilmoitetun poiston polussa tai jossakin sen yläpoluista (`PullManager.mjs:189`). |
| `StateManager.mjs:160-175` (`getSyncedPaths`) | Listaa synkronoitujen tiedostojen polut kursorin nollauksen jälkeen, jotta listauksesta puuttuva tiedosto katsotaan poistetuksi (`PullManager.mjs:74-85`). |

Migraatioilla `20220811111800_create_dropboxEntities_index.mjs` ja `20220825160708_recreate_dropboxEntities.mjs` on vain `saas`-tunniste, joten CE:ssä ei ole niiden yksilöllisiä indeksejä kentille `(overleaf.userId, dropbox.id)` ja `(overleaf.userId, overleaf.id)` eikä niiden hajautettua indeksiä kentälle `dropbox.pathLower`.

#### Huomautukset {#notes}

* Yksilöllisyys perustuu vain poistoon ennen jokaista lisäystä `recordEntity`-funktiossa (`StateManager.mjs:38-45`). Kohdan `StateManager.mjs:3-11` kommentti mainitsee yksilölliset indeksit; CE:ssä niitä ei ole.
* Käyttäjän ja polun mukaiset kyselyt (`findEntityByPath`, `findTombstone`, `removeEntities`) käyttävät indeksiä vain kentälle `overleaf.userId`.
