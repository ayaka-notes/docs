`tags` sisältää tunnisteet (kansiot), joihin käyttäjä lajittelee projekteja projektinäkymässä. Yksi dokumentti on yhden käyttäjän yksi tunniste. Omistaja on `web`; skeema on `services/web/app/src/models/Tag.mjs`, ja kaikki kirjoitukset kulkevat tiedoston `services/web/app/src/Features/Tags/TagsHandler.mjs` kautta.

#### Kentät {#fields}

| Kenttä | Tyyppi | Merkitys | Lähde |
| --- | --- | --- | --- |
| `_id` | ObjectId | Tunnisteen id, jota käytetään reiteissä `/tag/:tagId`. | `Tag.mjs:10` |
| `user_id` | String | Tunnisteen omistaja. Historiallisista syistä tavallinen merkkijono, ei ObjectId. | `Tag.mjs:7-12` |
| `name` | String | Tunnisteen nimi, enintään 50 merkkiä (`MAX_TAG_LENGTH`). Yksilöllinen käyttäjäkohtaisesti. | `Tag.mjs:13`, `TagsHandler.mjs:4` |
| `color` | String | Valinnainen väri: heksakoodi kuten `#a1b2c3` tai arvo `hsl(<n>, 70%, 45%)` (`TAG_COLOR_REGEX`). | `Tag.mjs:5`, `Tag.mjs:14-22` |
| `project_ids` | Array of String | Tunnisteen projektien id:t merkkijonoina. | `Tag.mjs:23` |
| `__v` | Number | Mongoosen versioavain, joka lisätään, kun `Tag.create` luo dokumentin. | `TagsHandler.mjs:27` |

#### Kuka kirjoittaa {#who-writes-it}

| Koodi | Mitä se tekee |
| --- | --- |
| `TagsHandler.mjs:18-35` (`createTag`) | `POST /tag` (`services/web/app/src/router.mjs:873-874`). Jos nimi on jo käytössä, palauttaa olemassa olevan tunnisteen. |
| `TagsHandler.mjs:37-70` (`renameTag`, `editTag`) | `POST /tag/:tagId/rename` ja `/tag/:tagId/edit` (`router.mjs:879-886`): asettavat kentän `name` tai kentät `name` ja `color`. |
| `TagsHandler.mjs:72-77` (`deleteTag`) | `DELETE /tag/:tagId` (`router.mjs:891-892`). |
| `TagsHandler.mjs:79-113` | Lisää tai poistaa yhden tai useamman projektin (`$addToSet` / `$pull` / `$pullAll` kentälle `project_ids`), reitit `router.mjs:897-916`. |
| `TagsHandler.mjs:124-128` (`removeProjectFromAllTags`) | Kutsutaan jokaiselle jäsenelle, kun projekti poistetaan (`services/web/app/src/Features/Project/ProjectDeleter.mjs:236-238`) ja kun käyttäjä poistetaan projektista tai poistuu siitä (`services/web/app/src/Features/Collaborators/CollaboratorsController.mjs:621`). |
| `TagsHandler.mjs:130-134` (`addProjectToTags`) | Lisää kopioidun projektin samoihin tunnisteisiin kuin alkuperäisen (`services/web/app/src/Features/Project/ProjectDuplicator.mjs:190-194`). |
| `services/web/modules/server-ce-scripts/scripts/rename-tag.mjs:20-23` | Ylläpitäjän skripti, joka nimeää yhden käyttäjän tunnisteen uudelleen suoraan Mongossa. |

#### Indeksit {#indexes}

| Nimi | Avaimet | Asetukset | Migraatio |
| --- | --- | --- | --- |
| `user_id_1_name_1` | `{ user_id: 1, name: 1 }` | unique | `tools/migrations/20190912145029_create_tags_indexes.mjs` |

Sama migraatio loi myös indeksin `user_id_1`; `tools/migrations/20231031164732_drop_redundant_indexes.mjs` poistaa sen uudelleen, koska yhdistelmäindeksi kattaa sen.

#### Huomioita {#notes}

* Tunnisteet ovat käyttäjäkohtaisia: saman projektin kahdella yhteistyökumppanilla on kummallakin omat tunnisteensa sille.
* `user_id` ja `project_ids` ovat merkkijonoja, joten kysy niitä merkkijono-id:illä, ei ObjectId:illä.
* Käyttäjän poistaminen (`services/web/app/src/Features/User/UserDeleter.mjs`) ei koske kokoelmaan `tags`.
