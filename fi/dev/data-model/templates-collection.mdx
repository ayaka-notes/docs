---
title: Templates -kokoelma
icon: book-open
---

`templates` sisältää yhden dokumentin jokaista mallipohjagallerian mallipohjaa kohden. Mallipohjan tiedostot (projektin zip ja PDF) eivät ole täällä: ne säilytetään filestoressa polussa `template/<_id>/v/<version>/`. Kokoelma kuuluu web-moduuliin `template-gallery` (`services/web/modules/template-gallery`). Skeema on Mongoose-malli `Template` tiedostossa `services/web/modules/template-gallery/app/src/models/Template.mjs`; logiikka on tiedostossa `services/web/modules/template-gallery/app/src/TemplateGalleryManager.mjs` ja sen vieressä olevassa `TemplateGalleryHelper.mjs`-tiedostossa.

#### Kuka kirjoittaa {#who-writes-it}

| Koodi | Mitä se tekee |
| ---- | ------------ |
| `TemplateGalleryManager.mjs:53-97` (`createTemplateFromProject`) | `POST /template/new/:Project_id`. Kopioi projektin asetukset (`TemplateGalleryHelper.mjs:94-134`), lataa zipin ja PDF:n filestoreen ja tallentaa. Jos nimi on varattu, se vastaa ristiriidalla, ellei asiakas pyytänyt korvaamista: silloin se päivittää kyseisen mallipohjan ja kasvattaa sen `version`-arvoa ja poistaa sitten edellisen version tiedostot. |
| `TemplateGalleryManager.mjs:21-47` (`editTemplate`) | `POST /template/:template_id/edit`. Asettaa lähetetyt kentät dokumenttiin, renderöi kentät `description` ja `author` uudelleen ja asettaa kentän `lastUpdated`. Muokkauslomake lähettää muuttuneet kentät joukosta `name`, `license`, `category`, `language`, `authorMD` ja `descriptionMD` (`services/web/modules/template-gallery/frontend/js/pages/template/util/api.ts:22-29`). |
| `TemplateGalleryHelper.mjs:186-222` (`deleteTemplateAssets`) | `DELETE /template/:template_id/delete` poistaa dokumentin ja annetun version tiedostot (`TemplateGalleryManager.mjs:49-51`). |

Vain sivuston ylläpitäjät ja käyttäjä kohdassa `OVERLEAF_TEMPLATES_USER_ID` voivat kutsua näitä kolmea reittiä (`services/web/modules/template-gallery/app/src/Router.mjs:55-62,70-84`, `PermissionsMiddleware.mjs:8-19`).

#### Kuka lukee {#who-reads-it}

| Koodi | Mitä se tekee |
| ---- | ------------ |
| `TemplateGalleryManager.mjs:158-183` (`getTemplate`) | Etsii yhden mallipohjan kentän `_id` tai `name` perusteella mallipohjasivulle ja reitille `GET /api/template` (`services/web/modules/template-gallery/app/src/TemplateGalleryController.mjs:210-232`). Jos `project_id` osoittaa projektiin, jota ei enää ole, vastaus jättää sen pois; dokumenttia ei muuteta. |
| `TemplateGalleryManager.mjs:190-236` (`getCategoryTemplates`) | `GET /api/templates`: yksi kategorian sivu, haku kentistä `name`, `authorMD` ja `descriptionMD`, lajiteltuna kentän `lastUpdated` tai `name` mukaan (kirjainkoosta riippumatta). |
| `TemplateGalleryHelper.mjs:64-80` (`canUserOverrideTemplate`) | Lukee kentän `owner` nimetäkseen omistajan ristiriitailmoituksessa. |

#### Indeksit {#indexes}

| Nimi | Avaimet | Asetukset | Migraatio |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | oletus |

Mongoosen `autoIndex` on pois päältä (`services/web/app/src/infrastructure/Mongoose.mjs:7`). `tools/migrations/20190912145030_create_templates_indexes.mjs` (yksilölliset `project_id`, `user_id`, `name`) on merkitty tunnisteilla `server-pro` ja `saas`, joten sitä ei ajeta CE:ssä, joka ajaa vain `server-ce`-migraatiot (`server-ce/init_scripts/900_run_web_migrations.sh`).

#### Huomautukset {#notes}

* Upstream pitää kokoelmaa `templates` vanhentuneena ja poistaa sen omalta sivustoltaan (`tools/migrations/20241002180623_drop_unused_collections.mjs`, merkitty `saas`). Ayakaleaf Prossa mallipohjagalleriamoduuli käyttää sitä.
* Nimen mukaan lajittelu käyttää kirjainkoosta riippumatonta lajittelujärjestystä, ja kohdan `TemplateGalleryManager.mjs:186-188` kommentti huomauttaa, että `name`-indeksi tarvitsisi saman. CE:ssä ei ole `name`-indeksiä, joten Mongo lajittelee muistissa.
* Lähdeprojektin tai omistajan poistaminen ei poista mallipohjaa.
