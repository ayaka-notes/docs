---
title: Messages-kokoelma
icon: message
---

`messages` sisältää yhden dokumentin viestiä kohden: rivin projektin chatissa tai kommentin tai vastauksen arvioinnin kommenttiketjussa. Vain chat-palvelu kirjoittaa siihen, tiedostossa `services/chat/app/js/Features/Messages/MessageManager.js`. Mongoose-skeemaa ei ole. Jokainen viesti kuuluu kokoelman [rooms](/fi/dev/data-model/rooms-collection) huoneeseen.

#### Kentät {#fields}

| Kenttä | Tyyppi | Merkitys | Lähde |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Viestin tunniste. | `MessageManager.js:13-14` |
| `room_id` | ObjectId | Huone (`rooms._id`), ei projektin eikä ketjun tunniste. | `MessageManager.js:8,106-108` |
| `user_id` | ObjectId | Kirjoittaja. | `MessageManager.js:9,103-105` |
| `content` | String | Viestin teksti, 1–10240 merkkiä (`MAX_MESSAGE_LENGTH`). | `MessageManager.js:7`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:3,12-15` |
| `timestamp` | Number | Lähetysaika millisekunteina vuodesta 1970 (`Date.now()`), ei Date. | `MessageManager.js:10`, `services/chat/app/js/Features/Messages/MessageHttpController.js:288` |
| `edited_at` | Number | Viimeisimmän muokkauksen aika millisekunteina (`Date.now()`). Puuttuu, jos viestiä ei ole koskaan muokattu. | `MessageManager.js:65-69`, `MessageHttpController.js:189,213` |

#### Kuka kirjoittaa {#who-writes-it}

| Koodi | Mitä se tekee |
| ---- | ------------ |
| `MessageManager.js:5-16` `createMessage` | Lisää viestin (`MessageHttpController.js:275-294`). Web lähettää projektin chat-viestit tiedostosta `services/web/app/src/Features/Chat/ChatController.mjs:32` ja kommentit track-changes-moduulista (`services/web/modules/track-changes/app/src/TrackChangesController.mjs:95`) ja mcp-server-moduulista (`services/web/modules/mcp-server/app/src/CommentTools.mjs:133`). |
| `MessageManager.js:51-72` `updateMessage` | Asettaa kentät `content` ja `edited_at`. Kun käyttäjätunniste annetaan, vain kyseisen käyttäjän viesti täsmää (`MessageManager.js:62-64`). Kutsutaan tiedostoista `ChatController.mjs:135` ja `TrackChangesController.mjs:110`. |
| `MessageManager.js:74-80` `deleteMessage` | Poistaa yhden viestin. Kutsutaan tiedostoista `ChatController.mjs:105` ja `TrackChangesController.mjs:129`. |
| `MessageManager.js:39-49` `deleteAllMessagesInRoom(s)` | Poistaa poistetun ketjun viestit (`MessageHttpController.js:172-173`) tai koko projektin viestit, kun poistettu projekti vanhenee (`MessageHttpController.js:261-271`, kutsutaan tiedostosta `services/web/app/src/Features/Project/ProjectDeleter.mjs:391`). |
| `MessageManager.js:115-127` `duplicateRoomToOtherRoom` | Kopioi jokaisen viestin kentät `content`, `timestamp` ja `user_id` toiseen huoneeseen ilman kenttää `edited_at`. Käytetään, kun historian palautus monistaa ketjun (`MessageHttpController.js:316-342`), ja kun projekti kopioidaan alueineen (`MessageHttpController.js:344-357`). |

#### Kuka lukee {#who-reads-it}

| Koodi | Mitä se tekee |
| ---- | ------------ |
| `MessageManager.js:18-29` `getMessages` | Uusimmat ensin, enintään `limit` (oletus 50), arvoa `before` (`timestamp`) vanhemmat. Käytetään projektin chatissa (`ChatController.mjs:80`). |
| `MessageManager.js:31-37` `findAllMessagesInRooms` | Joidenkin huoneiden kaikki viestit arviointipaneelin ketjuluetteloa (`TrackChangesController.mjs:82`), mcp-server-moduulia (`CommentTools.mjs:83`) ja historian palautusta (`services/web/app/src/Features/History/RestoreManager.mjs:259`) varten. Web tarkistaa myös ketjun ensimmäisen viestin, jotta arvioija voi muuttaa vain itse aloittamiaan ketjuja (`services/web/app/src/Features/Authorization/AuthorizationManager.mjs:409-411`). |
| `MessageManager.js:90-100` `getMessage` | Yksi viesti. Web tarkistaa sen kentän `user_id` ennen kuin käyttäjä muokkaa tai poistaa oman viestinsä (`services/web/app/src/Features/Authorization/AuthorizationMiddleware.mjs:253-257`, `TrackChangesController.mjs:124-125`). |

#### Huomautuksia {#notes}

* Löytääksesi kommentin viestit hae ensin huone kentillä `project_id` ja `thread_id`, ja tee sitten kysely kentällä `room_id`. Kommentin tunniste dokumentissa on `thread_id`, ei `room_id`.
* Teksti, johon kommentti osoittaa, on `op.c` kentässä `docs.ranges.comments`; keskustelu on täällä.
