---
title: GitLab Sync User Credentials -kokoelma
icon: user-lock
---

`gitlabSyncUserCredentials` sisältää yhden dokumentin jokaista käyttäjää kohden, joka on linkittänyt GitLab-tilin GitLab Syncia varten. Se tallentaa käyttäjän OAuth-tunnisteet salattuina. Kokoelma kuuluu web-moduuliin `gitlab-sync` (`services/web/modules/gitlab-sync`). Skeema on tiedostossa `services/web/modules/gitlab-sync/app/models/gitlabSyncUserCredentials.mjs`, ja kaikki käyttö kulkee `services/web/modules/gitlab-sync/app/src/TokenManager.mjs` kautta.

#### Kentät {#fields}

| Kenttä | Tyyppi | Merkitys | Lähde |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Mongoose asettaa, kun upsert lisää dokumentin. | |
| `userId` | ObjectId | Overleaf-käyttäjä. Pakollinen. Skeemassa lukee `unique: true`, mutta indeksiä ei rakenneta (katso Indeksit); upsert `userId`-kentän mukaan pitää yhden dokumentin käyttäjää kohden. | `gitlabSyncUserCredentials.mjs:8`, `TokenManager.mjs:88-95` |
| `gitlab` | String | JSON `{ accessToken, refreshToken, expiresAt }`, salattu `@overleaf/access-token-encryptor`-kirjastolla. `expiresAt` on millisekunteina epochista tai `null`; `refreshToken` voi olla `null`. Salasana tulee muuttujasta `GITLAB_TOKEN_CIPHER_PASSWORD`; salauksen tunniste on `GITLAB_TOKEN_CIPHER_LABEL`, oletus `2026.10-v3`. Pakollinen. | `gitlabSyncUserCredentials.mjs:9-10`, `TokenManager.mjs:18-31`, `services/web/modules/gitlab-sync/app/src/GitLabApiClient.mjs:209-220` |
| `__v` | Number | Mongoosen versioavain. Skeema ei poista sitä käytöstä. | Mongoosen oletus |

#### Kuka kirjoittaa {#who-writes-it}

| Koodi | Mitä se tekee |
| ---- | ------------ |
| `TokenManager.mjs:88-95` (`saveUserToken`) | Tekee upsertin käyttäjän salatuista tunnistetiedoista. |
| `TokenManager.mjs:99-108` (`linkUserToken`) | Tallentaa OAuth-callbackista saadut uudet tunnistetiedot (`services/web/modules/gitlab-sync/app/src/GitLabSyncController.mjs:146`). Kun käyttäjä linkittää uudelleen, korvattu käyttötunniste mitätöidään GitLabissa taustalla. |
| `TokenManager.mjs:53-78` (`refreshUserToken`) | Kun käyttötunnisteen `expiresAt`-aikaan on alle 5 minuuttia (`:13,47-49`), se hakee päivitystunnisteella uudet tunnisteet ja tallentaa ne (`:75`). Se ajetaan käyttäjäkohtaisen lukon `gitlabSyncToken` alla (`:15,54`), koska GitLab kuluttaa päivitystunnisteen käytössä. |
| `TokenManager.mjs:111-126` (`removeUserToken`) | Mitätöi käyttötunnisteen GitLabissa (parhaan kyvyn mukaan) ja poistaa sitten dokumentin. Kutsutaan linkityksen poistossa (`GitLabSyncController.mjs:173`) ja kun poistettu käyttäjä vanhenee (`services/web/modules/gitlab-sync/index.mjs:56-58`). |

#### Kuka lukee {#who-reads-it}

| Koodi | Mitä se tekee |
| ---- | ------------ |
| `TokenManager.mjs:41-45,81-85` (`getUserCredentials`, `getUserToken`) | Purkaa tunnistetietojen salauksen jokaista GitLab:n API-kutsua varten ja päivittää ne ensin, jos tunniste on vanhenemassa: `services/web/modules/gitlab-sync/app/src/GitLabSyncHandler.mjs` (esimerkiksi `:27`) ja `services/web/modules/gitlab-sync/app/src/GitMerge.mjs:52`. Ilman dokumenttia tai jos tunnistetietojen salausta ei voi purkaa tai niitä ei voi päivittää, se heittää `InvalidTokenError`, ja käyttäjä katsotaan linkittämättömäksi (`GitLabSyncHandler.mjs:25-37`). |
| `services/web/modules/admin-tools/app/src/AdminUserListManager.mjs:394` | Tarkistaa, onko käyttäjällä dokumentti, hallintapaneelissa näytettäviä integraatioita varten. |

#### Indeksit {#indexes}

| Nimi | Avaimet | Asetukset | Migraatio |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

Mongoosen `autoIndex` on pois päältä (`services/web/app/src/infrastructure/Mongoose.mjs:7`), joten skeeman `unique: true` kentässä `userId` ei luo mitään. Mikään migraatio ei luo indeksejä tälle kokoelmalle.

#### Huomautukset {#notes}

* Muuttujan `GITLAB_TOKEN_CIPHER_PASSWORD` muuttaminen tekee tallennetuista tunnistetiedoista lukukelvottomia. Nämä käyttäjät katsotaan silloin linkittämättömiksi, kunnes he linkittävät uudelleen.
* Poistettu käyttäjä säilyttää dokumentin, kunnes käyttäjä vanhenee.
