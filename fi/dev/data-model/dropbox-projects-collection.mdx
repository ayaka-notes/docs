title: Dropbox Projects -kokoelma
icon: folder-open
---

`dropboxProjects` yhdistää projektin sen kansioon yhden käyttäjän Dropboxissa. Projektilla, joka on jaettu usealle Dropbox-käyttäjälle, on yksi dokumentti käyttäjää kohden. Kokoelma kuuluu Dropbox-synkronointiin: third-party-datastore (`services/third-party-datastore/app/js/StateManager.mjs`) kirjoittaa sen, ja `dropbox`-verkkomoduuli (`services/web/modules/dropbox/app/src/DropboxHandler.mjs`) lukee ja tyhjentää sen. Mongoose-skeemaa ei ole.

#### Kentät {#fields}

| Kenttä | Tyyppi | Merkitys | Lähde |
| ------ | ------ | -------- | ----- |
| `_id` | ObjectId | Ajuri asettaa lisäyksen yhteydessä. | `StateManager.mjs:144` |
| `userId` | ObjectId | Overleaf-käyttäjä, jonka Dropboxissa kansio on. | `StateManager.mjs:145` |
| `projectId` | ObjectId | Kansioon synkronoitava projekti. | `StateManager.mjs:146` |
| `dropboxId` | String | Kansion `id` Dropboxin kansiometatiedoissa. | `StateManager.mjs:147`, `JobProcessor.mjs:82-87`, `PullManager.mjs:138` |
| `pathLower` | String | Kansion polku Dropboxissa pienillä kirjaimilla ja ilman loppukauttaviivaa. Projektikansiot ovat ylimmällä tasolla, yksi projektia kohden, esimerkiksi `/thesis (1)`, kun Dropbox numeroi sen toisen projektin `Thesis`-kansion viereen. | `StateManager.mjs:14-16,148`, `PullManager.mjs:112-117` |

#### Huomautukset {#notes}

* Yksilöllisyys perustuu vain poistoon ennen jokaista lisäystä `setProjectFolder`-funktiossa (`StateManager.mjs:140-149`). Kohdan `StateManager.mjs:3-11` kommentti mainitsee yksilölliset indeksit; CE:ssä niitä ei ole.
* Kun projektin yhdistäminen poistetaan, sen kansio jää Dropboxiin. Siellä tehty muokkaus luetaan silloin uutena projektina, kuten Dropboxissa luodun kansion kohdalla (`DropboxHandler.mjs:148-149`).
* Poistettu projekti säilyttää yhdistämisensä vanhenemiseen asti, koska se voidaan vielä palauttaa (`index.mjs:52-53`).
* Käyttäjän Dropbox-kursori `list_folder` ei ole täällä. Se on `users.dropbox.cursor` (`StateManager.mjs:177-184`).
