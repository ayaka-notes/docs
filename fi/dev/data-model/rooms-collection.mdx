`rooms` sisältää yhden dokumentin projektin jokaista chat-huonetta kohden: projektin chatin tai yhden arvioinnin kommenttiketjun. Vain chat-palvelu kirjoittaa siihen, tiedostossa `services/chat/app/js/Features/Threads/ThreadManager.js`. Mongoose-skeemaa ei ole. Huoneen viestit ovat kokoelmassa [messages](/fi/dev/data-model/messages-collection).

#### Kentät {#fields}

| Kenttä | Tyyppi | Merkitys | Lähde |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Huoneen tunniste. `messages.room_id` osoittaa tähän. | `ThreadManager.js:57-61` |
| `project_id` | ObjectId | Projekti, johon huone kuuluu. | `ThreadManager.js:43-54` |
| `thread_id` | ObjectId | Vain kommenttiketjuissa: kommentin tunniste, sama kuin kommentin `id` ja `op.t` kentässä `docs.ranges.comments` (katso [docs](/fi/dev/data-model/docs-collection)). Puuttuu projektin chat-huoneesta. | `ThreadManager.js:38-55`, `services/docstore/app/js/RangeManager.js:54-57` |
| `resolved` | Object | Asetetaan, kun ketju ratkaistaan, ja poistetaan, kun se avataan uudelleen. Ketju ilman tätä kenttää on avoin. | `ThreadManager.js:94-123` |
| `resolved.user_id` | String | Ketjun ratkaisseen käyttäjän tunniste. Tallennetaan merkkijonona, ei ObjectId-arvona: pyynnön runko tarkistetaan vain kelvolliseksi tunnisteeksi, sitä ei muunneta. | `ThreadManager.js:103`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:70` |
| `resolved.ts` | Date | Milloin ketju ratkaistiin. | `ThreadManager.js:104` |

#### Huomautuksia {#notes}

* Projektilla on enintään yksi huone ilman kenttää `thread_id`: projektin chat. Chat-palvelu löytää sen ehdolla `thread_id: { $exists: false }` (`ThreadManager.js:38-45`).
* Kommentin ratkaisutila on vain täällä. Docstore poistaa kentän `op.resolved` ennen alueiden tallentamista (`services/docstore/app/js/RangeManager.js:59-61`).
* Projektin kopioinnin jälkeen sama `thread_id` on kahdessa projektissa. Tee kysely aina kentillä `project_id` ja `thread_id` yhdessä, kuten chat-palvelu tekee.
* Poistetun projektin huoneet säilyvät, kunnes poistettu projekti vanhenee.
