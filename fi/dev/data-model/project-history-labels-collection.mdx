`projectHistoryLabels` sisältää tunnisteet, joita käyttäjät lisäävät versioihin History-näkymässä, yksi dokumentti tunnistetta kohden. Sen omistaa project-history, joka kirjoittaa sen tiedostossa `services/project-history/app/js/LabelsManager.js`; Mongoose-skeemaa ei ole. Web käyttää sitä vain project-historyn API:n kautta.

#### Kentät {#fields}

| Kenttä | Tyyppi | Merkitys | Lähde |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Tunnisteen ID. | `LabelsManager.js:81-85` |
| `project_id` | ObjectId | Projekti. | `LabelsManager.js:73` |
| `comment` | String | Tunnisteen teksti. | `LabelsManager.js:74` |
| `version` | Number | Projektihistorian versio, johon tunniste osoittaa. | `LabelsManager.js:75` |
| `created_at` | Date | Milloin tunniste luotiin; pyyntö voi välittää oman aikansa, muuten käytetään nykyhetkeä. | `LabelsManager.js:70`, `76` |
| `user_id` | ObjectId | Kuka tunnisteen loi. Jätetään pois, jos pyynnössä ei ole käyttäjää. | `LabelsManager.js:78-80` |

#### Kuka kirjoittaa {#who-writes-it}

| Koodi | Mitä se tekee |
| ---- | ------------ |
| `services/project-history/app/js/LabelsManager.js:44-90` | `createLabel`: lisää tunnisteen, project-historyn reitille `POST /project/:project_id/labels` (`services/project-history/app/js/HttpController.js:1134-1171`). Web kutsuu sitä käyttäjän tunnisteella, kun käyttäjä lisää tunnisteen (`services/web/app/src/Features/History/HistoryController.mjs:529-546`). |
| `LabelsManager.js:113-126` | `deleteLabel`: poistaa projektin tunnisteen, reitille `DELETE /project/:project_id/labels/:label_id`. Web käyttää sitä, kun projektin omistaja poistaa tunnisteen (`HistoryController.mjs:649-670`). |
| `LabelsManager.js:92-111` | `deleteLabelForUser`: poistaa tunnisteen vain, jos käyttäjä on luonut sen, reitille `DELETE /project/:project_id/user/:user_id/labels/:label_id`. Web käyttää sitä kaikille muille. |
| `LabelsManager.js:128-143` | `transferLabels`: siirtää yhden käyttäjän kaikki tunnisteet toiselle, reitille `POST /user/:from_user/labels/transfer/:to_user` (`services/project-history/app/js/Router.js:52-55`). Mikään webissä ei kutsu tätä reittiä. |
| `LabelsManager.js:7-25` | `cloneLabels`: kopioi projektin tunnisteet toiseen projektiin, project-historyn reitille `POST /project/:project_id/clone` (`HttpController.js:113`), jota mikään webissä ei kutsu. |

#### Kuka lukee {#who-reads-it}

| Koodi | Mitä se tekee |
| ---- | ------------ |
| `LabelsManager.js:27-42` | `getLabels`: projektin kaikki tunnisteet muodossa `{ id, comment, version, user_id, created_at }` (`LabelsManager.js:163-171`). Käyttää `GET /project/:project_id/labels` (`HttpController.js:1076-1100`), jota web kutsuu History-näkymää varten ja täydentää käyttäjänimet (`HistoryController.mjs:488-499`). |
| `services/project-history/app/js/SummarizedUpdatesManager.js:57` | Lisää tunnisteet historiapäivitysten luetteloon. |

#### Huomautuksia {#notes}

* Ennen tunnisteen lisäämistä project-history käsittelee projektin jonossa olevat päivitykset ja tarkistaa, että history-v1:ssä on chunk kyseiselle versiolle, ellei pyyntö lähetä arvoa `validate_exists: false` (`LabelsManager.js:53-59`, `173-195`; `HttpController.js:1109-1115`).
* Mikään koodi ei poista projektin tunnisteita, kun projekti poistetaan: project-history `DELETE /project/:project_id` tyhjentää vain synkronointitilan ja virhetietueen (`HttpController.js:1363-1396`), eikä mikään muu palvelu koske tähän kokoelmaan.
