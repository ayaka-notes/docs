`spellingPreferences` sisältää jokaisen käyttäjän sanaston: sanat, jotka käyttäjä on lisännyt editorin oikoluvussa valinnalla "Add to dictionary". Yksi dokumentti käyttäjää kohden. Omistaja on `web`, eikä Mongoose-skeemaa ole; koodi on `services/web/app/src/Features/Spelling/LearnedWordsManager.mjs`.

#### Kentät {#fields}

| Kenttä | Tyyppi | Merkitys | Lähde |
| --- | --- | --- | --- |
| `_id` | ObjectId | Dokumentin id, jonka upsert luo. | `LearnedWordsManager.mjs:21-31` |
| `token` | String | Käyttäjän id. Nimestään huolimatta oikolukureitit välittävät kirjautuneen käyttäjän id:n (`SessionManager.getLoggedInUserId`). | `LearnedWordsManager.mjs:23` |
| `learnedWords` | Array of String | Käyttäjän lisäämät sanat. | `LearnedWordsManager.mjs:26` |

#### Kuka kirjoittaa {#who-writes-it}

| Koodi | Mitä se tekee |
| --- | --- |
| `LearnedWordsManager.mjs:13-32` (`learnWord`) | `POST /spelling/learn` (`services/web/app/src/router.mjs:1037-1041`, `services/web/app/src/Features/Spelling/SpellingController.mjs:45-58`): `$addToSet` sanalle upsertin kanssa. Hylkää, jos luettelo kasvaisi yli `Settings.maxDictionarySize` tavun. |
| `LearnedWordsManager.mjs:38-47` (`unlearnWord`) | `POST /spelling/unlearn` (`router.mjs:1043-1047`, `SpellingController.mjs:66-79`): `$pull` sanalle. |
| `LearnedWordsManager.mjs:84-86` (`deleteUsersLearnedWords`) | Poistaa dokumentin. Sen ainoaa käärettä, `SpellingHandler.deleteUserDictionary` (`services/web/app/src/Features/Spelling/SpellingHandler.mjs:24-26`), ei kutsuta missään webissä tai sen moduuleissa. |

#### Kuka lukee {#who-reads-it}

| Koodi | Mitä se tekee |
| --- | --- |
| `LearnedWordsManager.mjs:52-67` (`getLearnedWords`) | Palauttaa sanat ilman kaksoiskappaleita. |
| `services/web/app/src/Features/Project/ProjectController.mjs:671` | Lähettää sanaston editorille, kun projekti avataan (`SpellingHandler.getUserDictionary`). |

#### Huomioita {#notes}

* Indeksi ei ole yksilöivä; upsert kentälle `token` säilyttää yhden dokumentin käyttäjää kohden.
* Käyttäjän poistaminen ei poista tätä dokumenttia.
