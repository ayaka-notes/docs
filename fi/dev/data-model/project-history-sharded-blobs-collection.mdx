---
title: Project-History-Sharded-Blobs-kokoelma
icon: cubes-stacked
---

`projectHistoryShardedBlobs` sisältää blob-tietueet, jotka eivät mahtuneet kokoelmaan [projectHistoryBlobs](/dev/data-model/project-history-blobs-collection): kun hash-etuliitteen ämpärissä on siellä jo 8 tietuetta, seuraavat tulevat tänne. Projektilla on tässä enintään 16 dokumenttia, yksi kutakin hashin ensimmäistä heksanumeroa kohden. Mongoose-skeemaa ei ole; history-v1 kirjoittaa sen tiedostossa `services/history-v1/storage/lib/blob_store/mongo.js` (rakenne kuvattu kohdassa `mongo.js:1-16`).

#### Kentät {#fields}

| Kenttä | Tyyppi | Merkitys | Lähde |
| ----- | ---- | ------- | ------ |
| `_id` | Binary | 13 tavua: projektin historiatunniste, `0`, ja sirpaleen numero heksana luettuna (`<history id>0<digit>`). Sirpaleen numero on hashin ensimmäinen heksanumero. | `mongo.js:439-453` |
| `blobs` | Object | Blob-tietueet ämpäreihin ryhmiteltyinä. Ämpärin avain on hashin heksanumerot 2–4. | `mongo.js:439-443` |
| `blobs.<bcd>` | Array of Object | Ämpärin tietueet. Koodi ei rajoita sen kokoa. | `mongo.js:399-407` |
| `blobs.<bcd>[].h` | Binary | Hash, 20 tavua, kuten kokoelmassa projectHistoryBlobs. | `mongo.js:472` |
| `blobs.<bcd>[].b` | Number | Sisällön pituus tavuina. | `mongo.js:473` |
| `blobs.<bcd>[].s` | Number | Sisällön pituus tekstinä; `null`, kun sisältö ei ole muokattavaa tekstiä. | `mongo.js:474` |

#### Kuka kirjoittaa {#who-writes-it}

| Koodi | Mitä se tekee |
| ---- | ------------ |
| `services/history-v1/storage/lib/blob_store/mongo.js:399-407` | `insertRecordSharded`: upsert ehdolla `$addToSet` ämpäriin. Kutsutaan funktiosta `insertBlob`, kun ämpäri kokoelmassa projectHistoryBlobs on täynnä (`mongo.js:387-389`). |
| `mongo.js:75-103` | `clone`: kopioi projektin sirpaleet toiseen historiatunnisteeseen, history-v1:n reitille `POST /projects/:project_id/clone`, jota mikään webissä ei kutsu. |
| `mongo.js:413-422` | `deleteBlobs`: poistaa projektin kaikki sirpaleet yhdessä sen projectHistoryBlobs-dokumentin kanssa, history-v1:n reitillä `DELETE /projects/:project_id`. |

#### Kuka lukee {#who-reads-it}

| Koodi | Mitä se tekee |
| ---- | ------------ |
| `mongo.js:144-157` | `findBlobSharded`: yksi blob, jota haetaan vain, kun sen ämpärissä kokoelmassa projectHistoryBlobs on 8 tietuetta eikä se ole niiden joukossa (`mongo.js:127-131`). |
| `mongo.js:217-260` | `findBlobsSharded`: blobit, joita `findBlobs` ei löytänyt kokoelmasta projectHistoryBlobs (`mongo.js:202-206`). |
| `mongo.js:285-306` | `getProjectBlobs`: projektin kaikki sirpaleet. |
| `mongo.js:337-361` | `getProjectBlobsBatch`: useiden projektien kaikki sirpaleet, blob-tilastojen reittiä varten. |

#### Indeksit {#indexes}

Vain oletusindeksi `_id`. Mikään migraatio hakemistossa `tools/migrations/` ei lisää indeksiä.

#### Huomautuksia {#notes}

* Yhden projektin sirpaleet ovat vierekkäin `_id`-järjestyksessä, joten koodi löytää ne `_id`-välillä arvosta `<history id>00` arvoon `<history id>0f` (`mongo.js:75-80`, `287-295`).
* Kokoelma syntyy vasta, kun jollakin projektilla on yli 8 blobia, joilla on sama kolmen numeron hash-etuliite, joten pienellä instanssilla sitä ei välttämättä ole lainkaan.
