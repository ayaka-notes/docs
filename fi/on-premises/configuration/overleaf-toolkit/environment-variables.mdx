Tällä sivulla kuvataan ympäristömuuttujat, joita Toolkit-käyttöönotoissa tuetaan tiedostossa `config/variables.env`.

Tiedosto `config/variables.env` koostuu muuttujamäärittelyistä muodossa `NAME=value`; `#`-merkillä alkavat rivit käsitellään kommentteina.

<Info>

Docker-kontit on luotava uudelleen suorittamalla `bin/up` aina, kun muutat jotain tiedostossa `overleaf.rc` tai `variables.env`.

</Info>

### Kaikki versiot

Nämä ympäristömuuttujat ovat yhteensopivia Server CE:n ja Server Pron kanssa, ja ne tarjoavat helpon siirtymäpolun näiden kahden paikallisen version välillä. Niitä voidaan käyttää sekä Toolkit- että Docker Compose -käyttöönotoissa.

<Info>

Aiemmin näiden ympäristömuuttujien etuliite oli `SHARELATEX_` eikä `OVERLEAF_`.

</Info>

<Info>

Käyttäjille on mahdollista asettaa salasanarajoituksia, kun käytetään Overleafin omaa kirjautumisjärjestelmää (paikalliset tilit) eikä SSO-vaihtoehtoa, kuten LDAP:ia. SSO-tileillä salasanakäytännöt valvoo identiteetintarjoajasi tai hakemistopalvelusi, mikä mahdollistaa lisäksi monivaiheisen todennuksen tuen.

</Info>
