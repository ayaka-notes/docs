### Zotero-integraation määrittäminen

1. Avaa [tämä linkki](https://www.zotero.org/oauth/apps) ja luo Zotero OAuth -asiakas (kuten kuvassa)
2. Valitse **Application Type**: **Browser**
3. Aseta Callback URL -osoitteeksi `${OVERLEAF_SITE_URL}/user/zotero/oauth/callback`
4. Määritä tiedosto `config/variables.env`

<Frame>
  <img src="/images/on-premises/image-41.png" alt="" width="375" />
</Frame>

```dotenv title="config/variables.env"
#################
#    Zotero     #
#################
# 'zotero' must be in ENABLED_LINKED_FILE_TYPES (set in develop/docker-compose.yml)
ENABLED_LINKED_FILE_TYPES=project_file,project_output_file,url,zotero

# From a Zotero OAuth client (register at https://www.zotero.org/oauth/apps)
# Application Type: Browser 
# Callback URL -> ${OVERLEAF_SITE_URL}/user/zotero/oauth/callback
ZOTERO_CLIENT_ID=
ZOTERO_CLIENT_SECRET=
# Encrypts the Zotero API key in mongo (set in dev to avoid writing a key file
# to /var/lib/overleaf/data, which the dev web container can't create)
# How to generate: `openssl rand -hex 32`
ZOTERO_CIPHER_PASSWORD=dev-zotero-cipher-password
# Optional: route the module's server-side Zotero requests (OAuth + API) through
# an HTTP proxy (must be reachable from the web container; same as github-sync)
# http://10.0.0.1:10808
# (Optional) ZOTERO_PROXY_URL=
```

### Huomautuksia

<Warning>

Kun päivität olemassa olevaa asennusta, jossa on Zoteroon linkitettyjä lähdeluettelotiedostoja, uudelleenjulkaistuun versioon 6.3.0, noudata [Zotero / Mendeley -siirto-ohjeita](/fi/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention"). Uudet asennukset eivät tarvitse tätä siirtoa.

</Warning>

<Danger>

Koska Ayakaleaf on yhteistyöalusta, tietoturvan parantamiseksi versiosta 6.3.0 alkaen vain viite-`bib`-tiedoston alkuperäinen luoja saa päivittää tuotua tiedostoa.

</Danger>

Oletetaan esimerkiksi, että projektin omistaja, käyttäjä A, ottaa linkin jakamisen käyttöön ja luo projektiin `test.bib`-tiedoston, jonka hän linkittää omaan Zotero-tiliinsä. Jos toinen käyttäjä, käyttäjä B, avaa projektin jaetun linkin kautta, käyttäjä B voi edelleen lukea ja ladata `test.bib`-tiedoston, mutta hän ei saa päivittää tiedostoa tai tuoda sitä uudelleen Zoterosta. Vain käyttäjä A viitetiedoston alkuperäisenä luojana voi tehdä päivityksiä. Toisin sanoen vain `.bib`-tiedoston alkuperäisellä luojalla on oikeus päivittää sitä.
