Jokaisella projektilla on MCP-palvelin, joten tekoälyasiakkaat, kuten Claude Code, Codex, Cursor, VS Code tai Gemini CLI, voivat työskennellä sen parissa: lukea ja muokata sen tiedostoja, kääntää sen, lukea LaTeX-lokin, ladata PDF:n ja vastata kommentteihin.

<Info>

Tämän ominaisuuden on kehittänyt [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro). Se on otettu käyttöön versiosta v6.4.0 alkaen.

</Info>

### Määrittäminen

MCP-palvelin tulee Git-integraation mukana: ota [git-bridge](/fi/on-premises/configuration/overleaf-toolkit/git-integration) käyttöön, niin myös MCP-palvelin on käytettävissä. Muuta määritettävää ei ole.

### Tekoälyasiakkaan yhdistäminen

1. Luo **Account Settings** -kohdassa Git-todennustunnus. Samaa tunnusta käytetään sekä MCP-palvelimelle että Gitille.
2. Avaa editorissa **Integrations** ja napsauta **MCP server**. Siinä näkyy projektin MCP-palvelimen osoite `https://<your-overleaf>/project/<project_id>/mcp` sekä ohjeet sen lisäämiseksi kuhunkin tekoälyasiakkaaseen: kopioi komento ja korvaa `<token>` omalla tunnuksellasi.

### Käyttö

Kun yhteys on muodostettu, pyydä tekoälyasiakasta tavallisin sanoin. Esimerkiksi:

| Pyydät | Tekoälyasiakas käyttää |
| --- | --- |
| _Korjaa johdannon kirjoitusvirheet._ | `read_file`, `edit_file`: muokkaukset näkyvät reaaliaikaisesti editorissa |
| _Käännä projekti ja korjaa LaTeX-virheet._ | `compile`, `get_compile_log`, `edit_file` |
| _Vastaa avoimiin kommentteihin ja ratkaise ne sitten._ | `list_comments`, `reply_to_comment`, `resolve_comment` |
| _Vaihda XeLaTeXiin ja lataa PDF._ | `update_settings`, `compile`, `get_output_file_link` |

### Työkalut

| Ryhmä | Työkalut |
| --- | --- |
| Projekti | `get_clone_info`, `get_settings`, `update_settings`, `list_versions` |
| Tiedostot | `list_files`, `read_file`, `edit_file`, `write_file`, `delete_file` |
| Kääntäminen | `compile`, `get_compile_log`, `get_output_file_link`, `word_count` |
| Kommentit | `list_comments`, `reply_to_comment`, `resolve_comment`, `reopen_comment` |

Työkaluilla `edit_file` ja `write_file` tehdyt muokkaukset näkyvät reaaliaikaisesti editorissa ja yhdistyvät yhteistyökumppaneiden muokkauksiin. Kun kyse on useista tiedostoista kerralla, binaaritiedostoista tai uudelleennimeämisistä, tekoälyasiakas voi myös kloonata projektin Gitillä ja pushata muutokset.

### Käyttöoikeudet

MCP-palvelin noudattaa projektin jakoasetuksia samoin kuin Git:

* Kaikki, jotka voivat tarkastella projektia, voivat lukea sitä, kääntää sen ja ladata sen tulosteet.
* Vain omistaja ja muokkaajat voivat muuttaa sen tiedostoja ja asetuksia.
* Arvioijat voivat lisäksi vastata kommentteihin sekä ratkaista tai avata uudelleen aloittamansa kommentit.
* Linkin kautta liittyneet katselijat eivät näe kommentteja, kuten ei editorissakaan.
