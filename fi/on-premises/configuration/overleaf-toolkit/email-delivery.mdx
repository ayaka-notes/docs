Overleaf tukee sähköpostin lähettämistä kahdella tavalla: Simple Mail Transfer Protocol (SMTP) ja [Amazon Simple Email Service (SES)](https://aws.amazon.com/ses/). SMTP:tä voidaan käyttää, jos localhostissa on käytössä sähköpostipalvelin, joka kuuntelee paikallisia yhteyksiä.

## Useita sähköpostiosoitteita tiliä kohden {#several-emails-per-account}

<Info>

Tämän ominaisuuden on kehittänyt [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro), ja se on saatavilla versiosta v6.4.0 alkaen.

</Info>

Kun sähköposti on määritetty, asetussivu näyttää tilin sähköpostiosoitteet yksittäisen sähköpostikentän sijaan. Käyttäjät lisäävät sähköpostiosoitteen syöttämällä siihen lähetetyn 6-numeroisen koodin ja painavat **Make primary** siirtääkseen tilinsä siihen. Näin tilin voi säilyttää, kun osoite poistuu käytöstä, kuten yliopiston osoite valmistumisen jälkeen. [Käyttöopas](/fi/on-premises/user-guide/users/multiple-emails) sisältää vaiheet kuvakaappauksineen.

* Vain ensisijainen sähköpostiosoite voi kirjautua ja saada salasanan palautuksia. Toissijainen sähköpostiosoite ei tee kumpaakaan, joten jollekulle toiselle uudelleen annettu osoite ei voi kaapata tiliä.
* Paina **Make primary** ennen kuin vanha postilaatikko suljetaan. Sen jälkeen ylläpitäjän on vaihdettava sähköpostiosoite kohdassa **Admin → Manage Users**.
* Vanha ensisijainen sähköpostiosoite, jota ei koskaan vahvistettu, poistetaan, kun toisesta osoitteesta tulee ensisijainen. Vahvistettu osoite jää toissijaiseksi, kunnes käyttäjä poistaa sen.
* **Make primary** hylätään, kun LDAP tai SAML on käytössä, koska nämä tilit eivät voisi kirjautua uudella sähköpostiosoitteella. Katso [Tilit ja salasanat](/fi/on-premises/configuration/overleaf-toolkit/authentication#accounts-and-passwords).
* Ilman sähköpostiasetuksia yksittäinen sähköpostikenttä säilyy.

## Määritys {#configuration}

Sähköposti määritetään seuraavilla ympäristömuuttujilla.

#### Lähettäjän määritys {#sender-configuration}

| Nimi                          | Kuvaus                                                                                                                                               |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | <p>Lähettäjän osoite, esim. <a href="mailto:support@mycompany.com">`'support@mycompany.com'`</a><br /><br />- <strong>Pakollinen</strong>: kyllä</p> |
| `OVERLEAF_EMAIL_REPLY_TO`     | Vastausosoite, esim. `'noreply@mycompany.com'`                                                                                                  |

#### SMTP {#smtp}

| Nimi                                    | Kuvaus                                                                                                                                                                                                                                                                   |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST`              | Isäntänimi tai IP-osoite, johon yhdistetään. Sen on oltava tavoitettavissa Docker-kontista                                                                                                                                                                               |
| `OVERLEAF_EMAIL_SMTP_PORT`              | Portti, johon yhdistetään                                                                                                                                                                                                                                                   |
| `OVERLEAF_EMAIL_SMTP_SECURE`            | Jos `true`, yhteys käyttää TLS:ää palvelimeen yhdistettäessä. Jos `false` tai asettamaton, TLS:ää käytetään, jos palvelin tukee `STARTTLS`-laajennusta. Useimmissa tapauksissa aseta arvoksi `true`, jos yhdistät porttiin `465`. Porteille `587` tai `25` pidä arvona `false` |
| `OVERLEAF_EMAIL_SMTP_USER`              | Käyttäjänimi, jolla todennetaan SMTP-palvelimelle                                                                                                                                                                                                 |
| `OVERLEAF_EMAIL_SMTP_PASS`              | SMTP-käyttäjänimeen liittyvä salasana                                                                                                                                                                                                                           |
| `OVERLEAF_EMAIL_SMTP_TLS_REJECT_UNAUTH` | Jos `false`, yhteys voidaan avata TLS-palvelimeen, jolla on itse allekirjoitettu tai virheellinen TLS-varmenne                                                                                                                                                                        |
| `OVERLEAF_EMAIL_SMTP_IGNORE_TLS`        | Kun arvo on `true` ja `OVERLEAF_EMAIL_SMTP_SECURE` on `false`, TLS:ää ei käytetä, vaikka palvelin tukisi `STARTTLS`-laajennusta                                                                                                                                            |
| `OVERLEAF_EMAIL_SMTP_NAME`              | Valinnainen isäntänimi TLS-validointia varten, jos `OVERLEAF_EMAIL_SMTP_HOST` on asetettu IP-osoitteeksi; oletuksena koneen isäntänimi.                                                                                                                                        |
| `OVERLEAF_EMAIL_SMTP_LOGGER`            | Kun arvo on `true`, lokiviestit tulostetaan tiedostoon `web.log`.                                                                                                                                                                                                                        |

#### Amazon SES:n SMTP-rajapinta {#amazon-ses-smtp-interface}

Lisätietoja sähköpostin lähettämisestä Amazon SES:n SMTP-rajapinnalla löydät [täältä](https://docs.aws.amazon.com/ses/latest/dg/send-email-smtp.html).

| Nimi                       | Kuvaus                                                                                     |
| -------------------------- | ------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST` | Isäntänimi tai IP-osoite, johon yhdistetään. Sen on oltava tavoitettavissa Docker-kontista |
| `OVERLEAF_EMAIL_SMTP_PORT` | Portti, johon yhdistetään                                                                     |
| `OVERLEAF_EMAIL_SMTP_USER` | Käyttäjänimi, jolla todennetaan SMTP-palvelimelle                   |
| `OVERLEAF_EMAIL_SMTP_PASS` | SMTP-käyttäjänimeen liittyvä salasana                                             |

#### Amazon SES API {#amazon-ses-api}

Lisätietoja sähköpostin lähettämisestä Amazon SES API:lla löydät [täältä](https://docs.aws.amazon.com/ses/latest/dg/send-email-api.html).

| Nimi                                   | Kuvaus                                      |
| -------------------------------------- | ------------------------------------------- |
| `OVERLEAF_EMAIL_AWS_SES_ACCESS_KEY_ID` | AWS SES:ää käytettäessä pääsyavain            |
| `OVERLEAF_EMAIL_AWS_SES_SECRET_KEY`    | AWS SES:ää käytettäessä salainen avain            |
| `OVERLEAF_EMAIL_AWS_SES_REGION`        | Jos ei asetettu, oletusalue on US-EAST-1 |

#### AWS SES instanssirooleilla {#aws-ses-with-instance-roles}

| Nimi                    | Kuvaus                                                                                                                           |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_DRIVER` | Kun arvoksi asetetaan `ses`, sähköpostijärjestelmä käyttää SES API -menetelmää ja luottaa määritettyihin instanssirooleihin sähköpostin lähettämisessä. |

#### Mukauttaminen {#customisation}

| Nimi                           | Kuvaus                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_CUSTOM_EMAIL_FOOTER` | <p>Mukautettu HTML, joka liitetään kaikkiin sähköposteihin, esim.<br /><br /><strong>Esimerkki</strong>: `"<div>This system is run by department x </div> <div> If you have any questions please look at our faq <a href='https://somwhere.com'>here</a></div>"`</p> |
