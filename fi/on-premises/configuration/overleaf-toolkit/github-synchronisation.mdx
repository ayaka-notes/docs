### GitHub-synkronoinnin määrittäminen

<Warning>

Sinun on otettava [git-bridge](/fi/on-premises/configuration/overleaf-toolkit/git-integration) käyttöön ennen GitHub-synkronoinnin käyttämistä.

```dotenv title="config/overleaf.rc"
GIT_BRIDGE_ENABLED=true
```

</Warning>

Siirry [kehittäjäasetuksiin](https://github.com/settings/developers) luodaksesi GitHub OAuth -sovelluksen ja kopioi sen `CLIENT_ID` ja `SECRET`.

**Huomautus**: OAuth-takaisinkutsun URL-osoitteesi on: `${OVERLEAF_SITE_URL}/user/github-sync/oauth2/callback`.

Lisää sitten seuraavat asetukset Overleafin ympäristömuuttujatiedostoihin.

```dotenv title="config/variables.env" wrap
# used to encrypt the user's GitHub access token.
# How to generate: `openssl rand -hex 32`
GITHUB_TOKEN_CIPHER_PASSWORD=0123456789ABCDEFG # changed to yours

# Github Sync Settings
GITHUB_SYNC_ENABLED=true
GITHUB_SYNC_CLIENT_ID=
GITHUB_SYNC_CLIENT_SECRET=

# OAuth callback is: ${OVERLEAF_SITE_URL}/user/github-sync/oauth2/callback
# (Optional) GITHUB_SYNC_PROXY_URL=http://10.0.0.1:10808
```

<Warning>

Varmista ennen GitHub OAuth -takaisinkutsun URL-osoitteen määrittämistä, että `OVERLEAF_SITE_URL` on asetettu oikein.

</Warning>

Jos olet Manner-Kiinassa, sinun on ehkä määritettävä välityspalvelin GitHubin käyttämiseksi. Aseta seuraava ympäristömuuttuja: `GITHUB_SYNC_PROXY_URL=http://10.0.0.1:10808`.

<Warning>

Älä käytä välityspalvelimen isäntänä osoitetta `127.0.0.1`. Jos välityspalvelin toimii isäntäpalvelimella, käytä palvelimen lähiverkon IP-osoitetta (kuten `192.168.1.xx`) ja varmista, että välityspalvelin on määritetty hyväksymään yhteydet lähiverkon laitteista.

</Warning>
