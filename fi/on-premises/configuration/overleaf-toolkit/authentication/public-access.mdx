Voit avata Overleaf-instanssisi ihmisille, joilla ei ole käyttäjätiliä, kolmella tavalla:

* [Projektien käyttö](/fi/on-premises/configuration/overleaf-toolkit/public-access#project-access  "mention"): anna vieraiden avata jaettu projektilinkki kirjautumatta sisään
* [Sivujen käyttö](/fi/on-premises/configuration/overleaf-toolkit/public-access#page-access  "mention"): anna uloskirjautuneiden vierailijoiden selata sivuja, kuten `/learn`, `/templates` ja `/devs`
* [Julkinen rekisteröityminen](/fi/on-premises/configuration/overleaf-toolkit/public-access#public-registration  "mention"): anna käyttäjien rekisteröityä itse, valinnaisesti aktivointisähköpostin kanssa ja sähköpostiverkkotunnuksiin rajattuna

### Projektien käyttö

<Info>

Oletusarvoisesti käyttäjän on **kirjauduttava sisään** ennen kuin hän voi liittyä yhteiseen projektin muokkausistuntoon, vaikka hänellä olisi projektin jakolinkki.

</Info>

Salliaksesi anonyymin pääsyn linkillä jaettuihin projekteihin aseta molemmat alla olevat muuttujat:

```dotenv title="config/variables.env"
OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING=true
OVERLEAF_ALLOW_PUBLIC_ACCESS=true
```

`OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` sallii anonyymin luku- ja kirjoitusoikeuden linkillä jaettuihin projekteihin.

`OVERLEAF_ALLOW_PUBLIC_ACCESS` estää todentamattomien käyttäjien ohjaamisen kirjautumissivulle.

Luo kontit uudelleen komennolla `bin/up`. Avaa sitten linkkijaon URL-osoite yksityisessä selainikkunassa.

### Sivujen käyttö

Oletusarvoisesti (kun `OVERLEAF_ALLOW_PUBLIC_ACCESS` ei ole asetettu) **jokainen** sivu kirjautumis- ja rekisteröitymissivuja lukuun ottamatta ohjaa uloskirjautuneet vierailijat kirjautumissivulle. Tämä koskee myös sivuja, jotka on tarkoitettu julkisiksi, joten niille johtavat linkit toimivat vain jo sisäänkirjautuneille käyttäjille.

Kun `OVERLEAF_ALLOW_PUBLIC_ACCESS=true`, uloskirjautuneet vierailijat voivat avata:

| Sivu                                                                  | Edellyttää                       |
| --------------------------------------------------------------------- | -------------------------------- |
| LaTeX-ohjeet osoitteessa `/learn` (katso [adding-latex-user-help.md](/fi/on-premises/configuration/overleaf-toolkit/adding-latex-user-help  "mention")) | `OVERLEAF_PROXY_LEARN=true`      |
| Mallivalikoiman osoitteessa `/templates`, mallisivut, esikatselut ja ZIP-lataukset (katso [templates.md](/fi/on-premises/configuration/overleaf-toolkit/templates  "mention")) | `OVERLEAF_TEMPLATE_GALLERY=true` |
| Overleaf Import API -sivun osoitteessa `/devs` (katso [overleaf-import-api.md](/fi/on-premises/configuration/overleaf-toolkit/overleaf-import-api  "mention")) | —                                |

Se myös mahdollistaa sen, että [Overleaf Import API](/fi/on-premises/configuration/overleaf-toolkit/overleaf-import-api#signed-out-visitors  "mention") säilyttää uloskirjautuneen vierailijan lomakelähetyksen, kunnes tämä on kirjautunut sisään.

Projektiluettelo, editori ja projektien luominen (myös mallista tai Import API:n kautta) edellyttävät edelleen kirjautumista.

### Julkinen rekisteröityminen

Julkinen rekisteröityminen on saatavilla vain [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro)-versiossa.

<Danger>

Huomaa, että kun otat julkisen rekisteröitymisen käyttöön, **kuka tahansa**, jolla on pääsy Overleaf-instanssiisi, voi rekisteröityä käyttäjäksi.

Arvolla `true` rekisteröitymisprosessi ei vahvista sähköpostiosoitteita, joten käytä sitä vain intranetissä tai luotetussa ympäristössä, tai käytä sen sijaan [rekisteröitymistä aktivointisähköpostilla](/fi/on-premises/configuration/overleaf-toolkit/public-access#registration-with-activation-email).

Älä käytä arvoa `true` instanssissa, jossa on OIDC: kuka tahansa voisi rekisteröityä kollegan sähköpostiosoitteella ennen kollegan ensimmäistä OIDC-kirjautumista, jolloin kollega linkitettäisiin kyseiseen tiliin. Käytä [rekisteröitymistä aktivointisähköpostilla](/fi/on-premises/configuration/overleaf-toolkit/public-access#registration-with-activation-email) tai älä salli julkista rekisteröitymistä lainkaan, katso [Tilit ja salasanat](/fi/on-premises/configuration/overleaf-toolkit/authentication#accounts-and-passwords).

</Danger>

Oletusarvoisesti julkinen rekisteröityminen ei ole sallittu Community Editionissa eikä Overleaf Prossa.

Ottaaksesi sen käyttöön lisää tämä tiedostoon `config/variables.env`:

```dotenv title="config/variables.env"
OVERLEAF_ALLOW_PUBLIC_REGISTRATION=true
```

Luo kontit uudelleen komennolla `bin/up`.

Napsauta sitten **Sign up** tai siirry osoitteeseen `/register`.

### Rekisteröityminen aktivointisähköpostilla

Rekisteröityminen aktivointisähköpostilla on saatavilla vain [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro)-versiossa. Käyttäjät rekisteröityvät pelkällä sähköpostiosoitteellaan ja asettavat salasanansa aktivointisähköpostin linkin kautta, joten vain osoitteen omistaja voi käyttää tiliä. Verkkotunnusluettelo ja jokerimerkit edellyttävät versiota v6.4.0 tai uudempaa; aiemmat versiot hyväksyvät vain yhden verkkotunnuksen, kuten `@example.com`.

Ennen kuin otat tämän käyttöön, määritä sähköpostin toimitus, muuten käyttäjät eivät koskaan saa aktivointisähköpostia. Katso [Sähköpostin toimitus](/fi/on-premises/configuration/overleaf-toolkit/email-delivery).

Lisää sitten seuraava rivi tiedostoon `config/variables.env`:

```dotenv title="config/variables.env" wrap
OVERLEAF_ALLOW_PUBLIC_REGISTRATION=@example.com,@*.example.org
```

`OVERLEAF_ALLOW_PUBLIC_REGISTRATION` voidaan asettaa arvoon:

| Arvo                          | Kuka voi rekisteröityä                                | Sähköposti vahvistetaan |
| ----------------------------- | ----------------------------------------------------- | :---------------------: |
| `true`                        | Kuka tahansa, sähköpostiosoitteella ja salasanalla    |           Ei            |
| `@example.com`                | Verkkotunnuksen `example.com` osoitteet               |          Kyllä          |
| `@*.example.org`              | Aliverkkotunnusten, kuten `cs.example.org`, osoitteet, ei itse `example.org` |          Kyllä          |
| `@example.com,@*.example.org` | Mikä tahansa luetelluista, pilkuilla erotettuina      |          Kyllä          |
| `@*`                          | Kuka tahansa                                          |          Kyllä          |

Verkkotunnukset täsmäytetään kirjainkoosta riippumatta. Salliaksesi verkkotunnuksen ja sen aliverkkotunnukset luettele molemmat: `@example.org,@*.example.org`.

### Q\&A

<Accordion title="Mitä uloskirjautunut muokkaaja voi tehdä kommenteille?">

<strong>Vastaus:</strong> Uloskirjautunut käyttäjä, joka avaa projektin sen muokkauslinkin kautta, saa samat oikeudet kuin muokkaaja, lukuun ottamatta toimintoja, jotka tallentavat tekijänsä:

| Toiminto                                          | Uloskirjautunut muokkaaja |
| ------------------------------------------------- | ------------------------: |
| Tekstin muokkaaminen, kommenttien ja seurattujen muutosten tarkastelu |      Kyllä |
| Seurattujen muutosten hyväksyminen, muokkaustilan vaihtaminen |            Kyllä |
| Kommentin tai koko keskusteluketjun poistaminen   |                     Kyllä |
| Kommentin lisääminen, siihen vastaaminen tai sen muokkaaminen |              Ei |
| Kommentin ratkaiseminen tai avaaminen uudelleen   |                        Ei |

Arviointipaneeli näyttää heille edelleen **Resolve**-painikkeen, mutta ratkaiseminen epäonnistuu virheilmoitukseen.

Projektin katselulinkin kautta avaavat käyttäjät eivät näe kommentteja lainkaan, katso [Roolit ja käyttöoikeudet](/fi/on-premises/user-and-project-management/roles-and-permissions#collaborating).

</Accordion>
