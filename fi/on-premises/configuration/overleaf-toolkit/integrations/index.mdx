Jokainen integraatio on oletuksena pois päältä Overleaf Import API:a lukuun ottamatta. GitHub-, GitLab-, Gitea- ja Dropbox-synkronointi sekä MCP-palvelin vaativat lisäksi [Git-integraation](/fi/on-premises/configuration/overleaf-toolkit/integrations/git-integration). Kun olet ottanut integraation käyttöön, luo kontit uudelleen komennolla `bin/up -d`.
