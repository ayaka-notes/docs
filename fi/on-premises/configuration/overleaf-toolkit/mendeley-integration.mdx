<Info>

Tämän ominaisuuden tarjoaa [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/overleaf-pro) OAuth 2.0 -tuella, ja se on saatavilla versiosta v6.3.0 alkaen. Otamme mielellämme vastaan palautetta, jos kohtaat ongelmia.

</Info>

#### Mendeley-integraation määrittäminen

1. Rekisteröi Mendeley OAuth -sovellus [tämän linkin](https://dev.mendeley.com/myapps.html) kautta
2. Määritä **Redirect URL** -arvoksi: `${OVERLEAF_SITE_URL}/user/mendeley/oauth/callback`
3. Ota talteen sovelluksesi luotu **ID** (yleensä numeerinen, kuten alla `24061`) ja **Secret**
4. Muokkaa tiedostoa `config/variables.env`&#x20;
5. Pidä valintana Authorisation Flow: Elsevier (suositeltu)

</Frame>

```dotenv title="config/variables.env"
#################
#   Mendeley    #
#################
# 'mendeley' must be in ENABLED_LINKED_FILE_TYPES (keep 'zotero' too if you use both)
ENABLED_LINKED_FILE_TYPES=project_file,project_output_file,url,mendeley

# From a Mendeley OAuth application (register at https://dev.mendeley.com/myapps.html)
# Redirect URL -> ${OVERLEAF_SITE_URL}/user/mendeley/oauth/callback
MENDELEY_CLIENT_ID=
MENDELEY_CLIENT_SECRET=
# Encrypts the Mendeley OAuth tokens in mongo; if unset, a key file is generated
# in /var/lib/overleaf/data on first use
# How to generate: `openssl rand -hex 32`
MENDELEY_CIPHER_PASSWORD=
# Optional: route the module's server-side Mendeley requests (OAuth + API) through
# an HTTP proxy (must be reachable from the web container; same as github-sync)
# http://10.0.0.1:10808
# (Optional) MENDELEY_PROXY_URL=
```

<Info>

&#x20;`mendeley` on lisättävä muuttujaan `ENABLED_LINKED_FILE_TYPES` (pidä myös `zotero` luettelossa, jos käytät molempia). `MENDELEY_CLIENT_ID` ja `MENDELEY_CLIENT_SECRET` saadaan rekisteröimästäsi OAuth-sovelluksesta. Salaussalasana salaa Mendeleyn OAuth-tunnisteet MongoDB:ssä (luo se komennolla `openssl rand -hex 32`); ilman sitä avaintiedosto luodaan datataltioon ensimmäisellä käyttökerralla. Voit halutessasi asettaa `MENDELEY_PROXY_URL`-muuttujan, jolloin palvelinpuolen Mendeley-pyynnöt (OAuth + API) ohjataan web-kontista saavutettavan HTTP-välityspalvelimen kautta.

</Info>

### Huomautuksia

<Warning>

Kun päivität olemassa olevaa asennusta, jossa on Mendeleyhin linkitettyjä lähdeluettelotiedostoja, uudelleenjulkaistuun versioon 6.3.0, noudata [Zotero- / Mendeley-siirto-ohjeita](/fi/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention"). Uudet asennukset eivät tarvitse tätä siirtoa.

</Warning>

<Danger>

Koska Ayakaleaf on yhteistyöalusta, tietoturvan parantamiseksi versiosta 6.3.0 alkaen vain viite-`bib`-tiedoston alkuperäinen luoja saa päivittää tuodun tiedoston.

</Danger>

Oletetaan esimerkiksi, että projektin omistaja, käyttäjä A, ottaa linkkijaon käyttöön ja luo projektiin `test.bib`-tiedoston, jonka hän linkittää omaan Zotero-tiliinsä. Jos toinen käyttäjä, käyttäjä B, avaa projektin jaetun linkin kautta, käyttäjä B voi edelleen lukea ja ladata `test.bib`-tiedoston, mutta hän ei saa päivittää tiedostoa tai tuoda sitä uudelleen Zoterosta. Vain käyttäjä A viitetiedoston alkuperäisenä luojana voi tehdä päivityksiä. Toisin sanoen vain `.bib`-tiedoston alkuperäisellä luojalla on oikeus päivittää sitä.
