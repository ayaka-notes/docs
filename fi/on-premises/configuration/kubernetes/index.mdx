Kubernetes-käyttöönotto lukee samat ympäristömuuttujat kuin Toolkit. Kun Toolkit-sivu sanoo ”lisää tämä tiedostoon `config/variables.env`”, vie arvo ConfigMapiin `overleaf-env`, tai Secretiin `overleaf-secrets`, kun kyseessä on salasana, avain tai tunniste. Käynnistä sitten uudelleen:

```bash
kubectl -n overleaf apply -f 30-config.yaml        # after editing the ConfigMap
kubectl -n overleaf patch secret overleaf-secrets --type merge \
  -p '{"stringData":{"GITHUB_TOKEN_CIPHER_PASSWORD":"'"$(openssl rand -hex 32)"'"}}'
kubectl -n overleaf rollout restart deployment/overleaf
```

Tiedoston `config/overleaf.rc` arvot ovat Toolkitin asetuksia, eivät ympäristömuuttujia; tämän sivun lopussa olevat kysymykset ja vastaukset kertovat, mikä ne korvaa.

### Varmenteet ja muut tiedostot

Jotkin ominaisuudet ottavat arvon sijaan tiedostopolun: SAML-varmenteet (`OVERLEAF_SAML_IDP_CERT`, ...), LDAP:n CA (`OVERLEAF_LDAP_TLS_OPTS_CA_PATH`) tai yksityinen CA itse isännöidylle GitHub Enterpriselle, GitLabille tai Gitealle (`NODE_EXTRA_CA_CERTS`). Vie tiedostot Secretiin ja liitä se sinne, missä Toolkit-sivut odottavat niitä, eli polkuun `/var/lib/overleaf/certs`:

```bash
kubectl -n overleaf create secret generic overleaf-certs --from-file=idp_cert.pem --from-file=ca.pem
```

```yaml title="40-overleaf.yaml (additions)"
          volumeMounts:
            # ...
            - name: certs
              mountPath: /var/lib/overleaf/certs
              readOnly: true
      volumes:
        # ...
        - name: certs
          secret:
            secretName: overleaf-certs
```

Viittaa niihin sitten polulla ConfigMapissa, esimerkiksi `NODE_EXTRA_CA_CERTS: /var/lib/overleaf/certs/ca.pem`, ja käynnistä uudelleen.

<Warning>

<strong>Salaussalasanat.</strong> Aseta Secretiin jokainen käyttämiesi ominaisuuksien `*_CIPHER_PASSWORD`. Muuten jotkin ominaisuudet luovat avaintiedoston datataltiolle ensimmäisellä käyttökerralla: yhdellä replikalla tämä toimii, kunnes taltio menetetään, mutta useilla replikoilla kukin replika salaisi eri avaimella.

</Warning>

### Kysymyksiä ja vastauksia

<Accordion title="Mitä Toolkitin asetuksia tiedostosta `config/overleaf.rc` tarvitsen?">

<strong>Vastaus:</strong> Ayakaleaf Pro ei lue niistä yhtäkään. Niiden Kubernetes-vastineet:

| `config/overleaf.rc`                         | Kubernetes                                                        |
| -------------------------------------------- | ----------------------------------------------------------------- |
| `OVERLEAF_LISTEN_IP`, `OVERLEAF_PORT`        | Service (NodePort) tai ingress                                    |
| `SIBLING_CONTAINERS_ENABLED`                 | `SANDBOXED_COMPILES*` ConfigMapissa, Docker-socket podissa        |
| `GIT_BRIDGE_ENABLED`                         | [Git-integraatio](/fi/on-premises/configuration/kubernetes/integrations/git-integration)                          |
| `MONGO_ENABLED`, `REDIS_ENABLED`, `MONGO_URL`, `REDIS_HOST` | StatefulSetit tai hallinnoidut palvelusi, `OVERLEAF_MONGO_URL` ja `OVERLEAF_REDIS_HOST` |
| `REDIS_AOF_PERSISTENCE`                      | `--appendonly yes` tiedostossa `20-redis.yaml`                    |
| `NGINX_ENABLED`, `TLS_*`                     | ingress tai kuormantasaaja                                        |

</Accordion>
