**web**-palvelu tarkistaa paikalliset salasanat, kun käyttäjät rekisteröityvät, asettavat tai vaihtavat salasanan. Tämä ei vaikuta SSO-kirjautumisiin (LDAP, SAML, OIDC); niiden salasanat ovat identiteetintarjoajan vastuulla. Toolkitin ohjeet ovat sivulla [Salasanarajoitukset](/fi/on-premises/configuration/overleaf-toolkit/authentication/password-restrictions).

| | |
| --- | --- |
| Palvelu | web, jokaisessa Ayakaleaf Pro -podissa; luetaan, kun web käynnistyy |
| Verkko | ei mitään |
| Ajastetut tehtävät | ei mitään |

### Konfiguraatio

Lisää ConfigMapiin `overleaf-env` ja käynnistä uudelleen:

```yaml title="30-config.yaml (additions)"
  OVERLEAF_PASSWORD_VALIDATION_MIN_LENGTH: "12"
  OVERLEAF_PASSWORD_VALIDATION_MAX_LENGTH: "72"
```

```bash
kubectl apply -f 30-config.yaml
kubectl -n overleaf rollout restart deployment/overleaf     # or statefulset/overleaf
```

| Muuttuja | Oletus | |
| --- | --- | --- |
| `OVERLEAF_PASSWORD_VALIDATION_MIN_LENGTH` | `8` | Lyhin hyväksytty salasana. |
| `OVERLEAF_PASSWORD_VALIDATION_MAX_LENGTH` | `72` | Pisin hyväksytty salasana; arvoja yli `72` käsitellään arvona `72`. |

Lainausmerkitse numerot: ConfigMap sisältää vain merkkijonoja.

<Warning>

`OVERLEAF_PASSWORD_VALIDATION_PATTERN` luetaan, mutta sitä ei valvota: salasana, joka ei vastaa sitä, hyväksytään. Vain pituusrajat ovat voimassa.

</Warning>

### Useita replikoita

Mitään ylimääräistä ei tarvita: jokainen replika lukee saman ConfigMapin.

### Testattu Kubernetesissa

Kubernetes 1.37:ssä yhdellä replikalla, kun ConfigMapissa oli `OVERLEAF_PASSWORD_VALIDATION_MIN_LENGTH: "12"` ja `OVERLEAF_PASSWORD_VALIDATION_PATTERN: aA$3`, uuden tilin aktivointi hylkäsi 10 merkin salasanan ja hyväksyi 20 merkin salasanan, joka koostui pelkistä pienistä kirjaimista ja jonka kaava olisi hylännyt. Rekisteröitymisen päästä päähän -testimme hylkäävät myös salasanan `123456` liian lyhyenä oletusasetuksilla.
