## Käyttäjätunnusten siirto

Kirjautumisen kannalta käyttäjän ensisijainen tunniste on hänen sähköpostiosoitteensa. Jos siirryt paikallisesta todennuksesta SSO:hon tai vaihdat identiteetintarjoajasta (IdP) toiseen, saatat joutua päivittämään käyttäjien sähköpostiosoitteet.

Tätä varten tarjolla on skripti, joka siirtää käyttäjien sähköpostiosoitteet CSV-tiedoston avulla. Tiedoston muoto on seuraava:

`oldEmail,newEmail`

Tehtyään joitakin tarkistuksia skripti käy CSV-tiedoston läpi ja päivittää käyttäjien sähköpostiosoitteet arvosta `oldEmail` arvoon `newEmail`.

### **Tarkistukset**

Ennen siirron suorittamista `<csv_file>` tarkistetaan sen varmistamiseksi, että:

* Jokaisella rivillä sekä `oldEmail` että `newEmail` ovat kelvollisia sähköpostiosoitteita
* Päällekkäisiä merkintöjä ei ole, eli et esimerkiksi yritä päivittää eri käyttäjiä samaan uuteen sähköpostiosoitteeseen tai päivittää samaa käyttäjätiliä jo käytössä olevalla sähköpostiosoitteella

### **Käyttö**

```bash wrap
docker cp <csv_file> sharelatex:/overleaf/services/web/<csv_file> docker exec sharelatex /bin/bash -c "cd /overleaf/services/web;node ./modules/server-ce-scripts/scripts/migrate-user-emails.js [--commit] [--continue|--ignore-missing] [--admin-id=ADMIN_USER_ID] <csv_file>"
```

### **Liput**

| Nimi               | Kuvaus                                                                                                                                                                                                                                                           |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--commit`         | <p>`--commit`-lipun lisääminen suorittaa siirron todella. Jos lippu jätetään pois, siirto tehdään kuivaharjoitustilassa, jossa muutoksia ei tehdä, mutta tarkistukset suoritetaan silti.<br /><br /><strong>Oletus</strong>:`false`</p> |
| `--continue`       | `--continue`-lippu jatkaa siirtoprosessia, jos käyttäjätilin sähköpostiosoite on jo päivitetty                                                                                                                                                                   |
| `--ignore-missing` | `--ignore-missing`-lippu jatkaa siirtoprosessia, jos käyttäjätiliä ei löytynyt                                                                                                                                                                                   |
| `--admin-id`       | `--admin-id` tulee asettaa siirron suorittavan ylläpitäjän tunnukseksi, ja sitä käytetään valvontalokin merkinnöissä. Löydät käyttäjätunnuksesi (user-id) siirtymällä kohtaan **Admin** > **Manage Users**, hakemalla sähköpostiosoitteellasi ja napsauttamalla ensimmäistä tulosta. |
| `<csv_file>`       | `<csv_file>` on tiedosto, joka sisältää vanhat ja uudet sähköpostiosoitteet                                                                                                                                                                                      |

### **Päättyminen**

Siirtoskriptin suorituksen aikana valitsemasi liput määräävät, kirjataanko virhe konsoliin ja jatketaanko suoritusta, vai kirjataanko virhe konsoliin ja lopetetaanko suoritus. Jos skripti päättyy ennenaikaisesti virheen vuoksi, se palauttaa poistumiskoodin 1 merkiksi epäonnistumisesta.

Siirron valmistuttua skripti kirjaa konsoliin onnistuneiden, epäonnistuneiden ja ohitettujen päivitysten määrän. Jos siirto onnistuu, skripti palauttaa poistumiskoodin 0.
