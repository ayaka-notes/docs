title: Siirtyminen Server Prosta Group Professionaliin
icon: rectangle-pro

Siirtyminen itse isännöidystä Server Pro -instanssista uuteen pilvipohjaiseen Overleaf Group Professional -tilaukseen on suuri muutos, joten olemme koonneet seuraavat ohjeet, jotta prosessi sujuisi mahdollisimman vaivattomasti.

Yleisesti ehdotamme kolmen kuukauden päällekkäisyysjaksoa, joka alkaa uusimispäivästäsi. Tämä tarkoittaa, että:

* Nykyinen Server Pro -instanssisi ja uusi Group Professional -tilauksesi ovat molemmat täysin käytössä.
* Tekninen tiimisi voi varata aikaa Group Professional -tilauksen käyttöönottoon ja päättää omassa ympäristössä toimivan Server Pro -käyttöönoton tulevaisuudesta.
* Mikä tärkeintä, käyttäjilläsi on runsaasti aikaa kopioida projektinsa uudelle Overleaf Group Professional -alustalle.

Tämä pikaopas käy läpi siirron keskeiset vaiheet. Aloitetaan!

<Steps>
<Step title="Vaihe 1: Käyttöönotto ja määritys">
(Linkki: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-1-setup-and-configuration)

* Overleaf luo Group Professional -tilauksesi ja lisää pääylläpitäjäsi.
* Ryhmäsi ylläpitäjä voi ottaa käyttöön [hallinnoidut käyttäjät](https://docs.overleaf.com/groups/user-management/managed-user-accounts), määrittää [kertakirjautumisen (SSO)](https://docs.overleaf.com/groups/overleaf-group-single-sign-on/setting-up-group-sso) ja [kutsua loppukäyttäjät](https://docs.overleaf.com/groups/user-management/how-to-add-and-remove-users).

<Warning>

Hallinnoitujen käyttäjien käyttöönotto ja SSO:n toteuttaminen ovat pakollisia vaiheita FedRAMP® LI-SaaS -vaatimustenmukaisuuden kannalta. Jos organisaatiosi edellyttää FedRAMP-vaatimustenmukaisuutta, määritä hallinnoidut käyttäjät ja SSO ennen loppukäyttäjien kutsumista.

</Warning>
</Step>

<Step title="Vaihe 2: Käyttäjien siirto ja tietojen hallinta">
(Linkki: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-2-user-migration-and-data-management)

Tämä on varsinainen siirtoikkuna, ja siihen liittyvät seuraavat vastuut:

#### Loppukäyttäjät

* Käyttäjien tulee siirtää kaikki projektit, jotka he haluavat säilyttää, Server Pro -instanssistasi uusille tileilleen osoitteessa [overleaf.com](http://overleaf.com/). Prosessissa [viedään projektit](https://www.overleaf.com/learn/how-to/Exporting_your_work_from_Overleaf) Server Prosta ja [ladataan ne](https://www.overleaf.com/learn/how-to/Uploading_a_project) omalle tilille osoitteessa [overleaf.com](http://overleaf.com/). Jos käyttäjällä ei vielä ole [overleaf.com](http://overleaf.com/)-tiliä, hän voi rekisteröityä osoitteessa [overleaf.com/register](http://overleaf.com/register).

<Warning>

Tämä vientimenettely siirtää vain projektin lähdekoodin (LaTeX- ja binääritiedostot). Olemassa olevia projektiasetuksia, jakoasetuksia, kommentteja, seurattuja muutoksia jne. EI siirretä. Käyttäjien on kutsuttava yhteistyökumppaninsa uudelleen siirron jälkeen.

</Warning>

#### Tekninen henkilöstö

* Tämän vaiheen aikana teknisen tiimisi tulee suunnitella, miten omassa ympäristössä toimivaa Server Pro -instanssia ja sen tietoja käsitellään siirron jälkeen.
* <strong>Tietojen varmuuskopiointi:</strong> Voit viedä kaikki projektit ennen käytöstä poistamista ja luoda arkiston, jonka avulla voit auttaa käyttäjiä, jotka ovat ehkä unohtaneet siirtää tai ladata työnsä. Ohjeet: https://docs.overleaf.com/on-premises/maintenance/data-and-backups/exporting-projects
* <strong>Server Pron käytöstä poistaminen:</strong> Kun siirtoikkuna sulkeutuu ja lisenssiavaimesi poistetaan käytöstä, sinulla on kaksi päävaihtoehtoa itse Server Pro -instanssin suhteen (katso seuraava vaihe).
</Step>

<Step title="Server Pron käytöstä poistamisen vaihtoehdot">
<Steps>
<Step title="Poista Server Pro kokonaan">
Asennuksen poistaminen poistaa Server Pron käytöstä ja poistaa ohjelmiston kokonaan.
</Step>

<Step title="Vaihda Community Editioniin">
Vaihtaminen säilyttää käyttäjien ja projektien tietokannan sekä koko projektihistorian muuntamalla instanssin Server Prosta Community Editioniksi.
</Step>
</Steps>

<Info>

Community Edition EI sisällä [hiekkalaatikoituja käännöksiä](https://docs.overleaf.com/on-premises#overview-of-server-pro-and-community-edition) eikä [LDAP](/fi/on-premises/configuration/overleaf-toolkit/authentication/ldap-authentication)/[SAML](/fi/on-premises/configuration/overleaf-toolkit/authentication/saml-authentication)-tukea. Jos sinun on palattava natiiviin todennukseen (käyttäjätunnus/salasana), katso: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-to-ldap-or-saml#going-the-other-way-switching-from-ldap-saml-back-to-native-authentication

Server CE:n ja Server Pron vertailu: https://docs.overleaf.com/on-premises/welcome/server-pro-vs.-community-edition

</Info>
</Step>

<Step title="Vaihe 3: Server Pron käytöstä poistaminen">
(Linkki: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-3-server-pro-decommission)

* Overleaf-tiimi poistaa Server Pro -lisenssiavaimesi virallisesti käytöstä ja lähettää vahvistuksen, kun tämä on tehty.
* Suorita tässä vaiheessa jokin yllä kuvatuista käytöstä poistamisen toimenpiteistä: poista Server Pro kokonaan tai vaihda Community Editioniin.
</Step>
</Steps>

Yllä mainitut lisäresurssit ja linkit säilyvät ennallaan.
