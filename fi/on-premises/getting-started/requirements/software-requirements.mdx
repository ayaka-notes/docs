### Käyttöjärjestelmät

Parhaan kokemuksen saavuttamiseksi Overleafia käytettäessä suosittelemme vahvasti **Debian-pohjaista** käyttöjärjestelmää, kuten **Ubuntua**. Tämä valinta vastaa ohjelmiston kehitysympäristöä, ja se on suurimman osan Overleafin käyttäjistä suosima vaihtoehto.

<Danger>

Kun käytät Server Prota Sandboxed Compiles -toiminnon kanssa, on **tärkeää** huomata, että sovellus vaatii root-oikeudet Docker-sockettiin.

</Danger>

### Riippuvuudet

* Docker 25.0 ja 29
* MongoDB 7.0 ja 8.0
* Redis 6.2 ja 7.5

<Info>

Voit seurata yllä mainittujen riippuvuuksien ja muiden suosittujen tuotteiden tuen päättymispäiviä (End-of-Life, EOL) endoflife.date-palvelussa: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

`docker compose` noutaa MongoDB:n ja Redisin automaattisesti, kun Server CE:tä tai Server Prota ajetaan, ellei toisen asennuksen käyttöä ole määritetty.

</Info>

Toolkit on riippuvainen seuraavista ohjelmista:

* bash
* Docker

`docker compose` on pakollinen, ja se asennetaan yleensä Dockerin mukana.

Suosittelemme asentamaan uusimman käyttöjärjestelmällesi saatavilla olevan Docker-version.

Kun Docker on asennettu oikein, sinun pitäisi pystyä ajamaan nämä komennot ilman virheitä:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2)
docker compose version

# List the running Docker containers on your system
docker ps
```
