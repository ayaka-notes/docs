### Server Pron ja Community Editionin asennusvaatimukset

<Warning>

Suosittelemme vahvasti, että ajat Server Prota tuoreella ja vakaalla Ubuntu-versiolla (esim. Ubuntu 24.04 vuosina 2025–2026) ja tuoreella Docker-versiolla. Server Pron ajaminen muilla järjestelmillä on mahdollista, mutta tukemme tarjoaminen muille kuin oletusarvoisille Ubuntu/Docker-kokoonpanoille on silloin huomattavasti vaikeampaa. Emme myöskään voi tarjota tukea itse Dockeriin liittyviin ongelmiin.

</Warning>
