Lisää linkki verkkosivustollesi, blogiisi tai kurssisivullesi. Jokainen, joka napsauttaa sitä, saa oman uuden projektin, jossa ovat tiedostosi. Mitään ei tarvitse määrittää.

Vierailijat tarvitsevat tilin instanssissasi. Kirjautumaton vierailija ohjataan ensin kirjautumissivulle, ja projekti avautuu kirjautumisen jälkeen.

Tämän ominaisuuden sivuilla käytetään nimeä Overleaf. Oma linkkisi tai painikkeesi voi sanoa mitä tahansa, esimerkiksi **Open in Ayakaleaf**.

## Katso esimerkit {#see-the-examples}

Avaa sivustollasi `/devs`, esimerkiksi `https://ayakaleaf.example.com/devs`. Mikään valikko ei linkitä tälle sivulle, joten kirjoita osoite itse. Oletuksena sinun on oltava kirjautuneena nähdäksesi sen.

## Linkki verkkosivustosi tiedostoon {#link-to-a-file-on-your-website}

<Steps>
<Step title="Muodosta linkki">
Lisää tiedoston URL-koodattu osoite `/docs?snip_uri=`-osan perään:

```text
https://ayakaleaf.example.com/docs?snip_uri=https%3A%2F%2Fexample.com%2Fmain.tex
```

Pakatulle projektille käytä `zip_uri`:

```text
https://ayakaleaf.example.com/docs?zip_uri=https%3A%2F%2Fexample.com%2Fproject.zip
```

Instanssisi lataa tiedoston, joten sen on oltava saatavilla HTTP:n tai HTTPS:n kautta. Yksityisverkon osoitteet hylätään, katso [External URL](/fi/on-premises/configuration/overleaf-toolkit/external-url).
</Step>

<Step title="Lisää se sivullesi">
```html
<a href="https://ayakaleaf.example.com/docs?snip_uri=https%3A%2F%2Fexample.com%2Fmain.tex">Open in Ayakaleaf</a>
```
</Step>

<Step title="Napsauta sitä">
Uusi projekti avautuu editorissa, ja siinä on yksi tiedosto tallennettuna nimellä `main.tex`.

<Frame caption="Linkistä avattu projekti">
  <img src="/images/on-premises/open-in-overleaf-project.png" alt="Projekti Hello from a link editorissa, jossa main.tex ja sen PDF" />
</Frame>

Jokainen napsautus luo uuden projektin. Projekti on kopio, joten tiedostoosi myöhemmin tehdyt muutokset eivät päädy siihen.
</Step>
</Steps>

## Tiedoston lisääminen linkkiin {#put-the-file-in-the-link}

Pientä tiedostoa varten sinun ei tarvitse isännöidä mitään: lisää sen sisältö linkkiin Base64-data-URL:nä. JavaScriptissä:

```javascript
const tex = '\\documentclass{article}\n\\begin{document}\nHello from a link.\n\\end{document}\n'
const link = 'https://ayakaleaf.example.com/docs?' + new URLSearchParams({
  snip_uri: 'data:application/x-tex;base64,' + btoa(tex),
  name: 'Hello from a link',
})
```

`btoa` hyväksyy vain Latin-1-merkit, joten koodaa muu teksti ensin UTF-8:ksi. Pakatulle projektille käytä `zip_uri` ja `data:application/zip;base64,`.

Noin 8 kt:tä pidempi linkki hylätään virheellä **414 Request-URI Too Large**. Suuremmille sisällöille isännöi tiedosto tai käytä [lomaketta](#use-a-button-instead-of-a-link).

## Asetusten valitseminen {#choose-the-options}

Lisää nämä linkkiin tai lomakkeeseen piilokenttinä:

| Parametri                   | Mitä se tekee                                                                                                                 | Esimerkki                                            |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| `name`                      | Nimeää projektin. Ilman sitä pakattu projekti saa nimensä `\title`-kentästään, ja kaikki muu on nimeltään `Open in Overleaf project`. | `name=My%20notes`                                  |
| `engine`                    | Asettaa kääntäjän: `latex_dvipdf`, `pdflatex`, `xelatex` tai `lualatex`.                                                      | `engine=xelatex`                                   |
| `main_document`             | Asettaa päätiedoston `.tex`, joka avautuu ensimmäisenä.                                                                                | `main_document=thesis.tex`                         |
| `snip_uri[]`, `snip_name[]` | Tuo useita tiedostoja, kukin omalla nimellään, samassa järjestyksessä.                                                            | `snip_uri[]=.../a.tex&snip_name[]=a.tex`           |

`.tex`-tiedosto ilman `\documentclass`-määritystä kääritään vakiodokumenttiin, joten se kääntyy heti:

```latex
\documentclass[12pt]{article}
\usepackage[english]{babel}
\usepackage{amsmath}
\usepackage{tikz}
\begin{document}
Your file
\end{document}
```

## Painikkeen käyttäminen linkin sijaan {#use-a-button-instead-of-a-link}

Lomake lähettää samat parametrit kuin linkki:

```html
<form action="https://ayakaleaf.example.com/docs" method="post" target="_blank">
  <input type="hidden" name="snip_uri" value="https://example.com/main.tex">
  <input type="hidden" name="engine" value="xelatex">
  <button type="submit">Open in Ayakaleaf</button>
</form>
```

Jos haluat lähettää itse LaTeX-koodin, käytä `snip` tavalliselle tekstille tai `encoded_snip` tekstille, joka on käsitelty `encodeURIComponent`-funktiolla.

Lomake ei aina toimi, joten linkki on parempi valinta, ellei tiedostosi ole liian pitkä siihen:

| Missä lomake on                                     | Vierailija on kirjautunut            | Vierailija ei ole kirjautunut        |
| ----------------------------------------------------- | ------------------------------- | ------------------------------- |
| Samassa verkkotunnuksessa kuin instanssisi tai sen aliverkkotunnuksessa   | Projekti avautuu               | Kirjautumissivu, ei projektia      |
| Toisessa verkkotunnuksessa                                     | Kirjautumissivu, ei projektia      | Kirjautumissivu, ei projektia      |

Jos ylläpitäjä asettaa `OVERLEAF_ALLOW_PUBLIC_ACCESS=true`, projekti avautuu kaikissa näissä tapauksissa, tarvittaessa kirjautumisen jälkeen. Asetus avaa myös muita sivuja kirjautumattomille vierailijoille, katso [Page Access](/fi/on-premises/configuration/overleaf-toolkit/authentication/public-access#page-access).

Muut ylläpitäjien määritettävissä olevat asiat löydät sivulta [Overleaf Import API](/fi/on-premises/configuration/overleaf-toolkit/integrations/overleaf-import-api). Sivulla `/devs` on lisää esimerkkejä.

## Jos projekti ei avaudu {#if-the-project-does-not-open}

Sivu kertoo, mikä meni vikaan. **View the Overleaf API docs** vie sivulle `/devs`.

<Frame caption="Linkki, jota instanssi ei voi käyttää">
  <img src="/images/on-premises/open-in-overleaf-error.png" alt="Open in Overleaf -sivu, jossa viesti invalid url ja View the Overleaf API docs -painike" />
</Frame>

| Viesti                                      | Miksi                                                 | Mitä tehdä                                  |
| -------------------------------------------- | --------------------------------------------------- | ------------------------------------------- |
| `no snippet, snip_uri or zip_uri provided`   | Linkissä ei ole mitään näistä                          | Tarkista parametrien nimet                   |
| `invalid url: ...`                           | Osoite ei ala HTTP:llä tai HTTPS:llä       | Käytä HTTP- tai HTTPS-osoitetta tai data-URL:ää |
| `could not download ... (HTTP 404)`          | Tiedosto ei ole kyseisessä osoitteessa                     | Tarkista osoite                           |
| `could not download ... (HTTP 403)`          | Osoite on yksityisverkossa                 | Isännöi tiedosto paikassa, johon instanssisi saa yhteyden |
| `zip_uri did not resolve to a zip archive`   | `zip_uri`-osoitteen takana oleva tiedosto ei ole zip-tiedosto         | Tarkista tiedosto                              |
| `invalid base64 data url`                    | Data-URL on vioittunut                             | Koodaa tiedosto uudelleen ja URL-koodaa linkki |
