## Dokumentin tuominen {#import-a-document}

Tämä luo uuden LaTeX-projektin Word-dokumentista (`.docx`) tai Markdown-tiedostosta (`.md`). Projektin nimi tulee tiedoston nimestä.

<Steps>
<Step title="Avaa tuontivalintaikkuna">
Napsauta projektisivulla **New project**. Napsauta **Import**-kohdassa **Word document** tai **Markdown document**.

<Frame caption="New project -valikko">
  <img src="/images/on-premises/word-import-menu.png" alt="New project -valikko, jossa Import-kohdassa Word document ja Markdown document" />
</Frame>
</Step>

<Step title="Valitse tiedosto">
Napsauta **Select .docx file** tai vedä tiedosto valintaikkunaan. Markdownille painike on **Select .md file**. Tuonti alkaa heti.

<Frame caption="Word-dokumentin valitseminen">
  <img src="/images/on-premises/word-import-dialog.png" alt="Choose Word document -valintaikkuna ja Select .docx file -painike" />
</Frame>
</Step>

<Step title="Aloita muokkaaminen">
Uusi projekti avautuu viestin **Document ready for editing** kanssa. Napsauta **Start editing**.

<Frame caption="Tuonti on valmis">
  <img src="/images/on-premises/word-import-ready.png" alt="Document ready for editing -valintaikkuna ja Start editing -painike" />
</Frame>
</Step>

<Step title="Tarkista tulos">
Dokumentti on nyt tiedostossa `main.tex`, ja sen otsikot näkyvät tiedoston jäsennyksessä. Napsauta **Recompile** nähdäksesi PDF:n. Tarkista muotoilu, erityisesti taulukot, kuvat ja lähdeviitteet, jotka voivat vaatia muokkausta.

<Frame caption="Tuotu projekti">
  <img src="/images/on-premises/word-import-project.png" alt="Tuotu projekti editorissa: main.tex, tiedoston jäsennys ja käännetty PDF" />
</Frame>
</Step>
</Steps>

### Jos tuonti epäonnistuu {#if-the-import-fails}

Jos tiedostoa ei voi muuntaa, valintaikkunassa lukee **Your document couldn't be imported**. Laajenna **Conversion error details** nähdäksesi syyn. Projektia ei luoda.

<Frame caption="Dokumentti, jota ei voitu tuoda">
  <img src="/images/on-premises/word-import-error.png" alt="Tuontivalintaikkuna, jossa virheilmoitus ja Conversion error details" />
</Frame>

Valintaikkuna hyväksyy vain valitsemasi tyypin. `.md`-tiedosto Word-valintaikkunassa näyttää viestin **You can only upload: .docx**.

## Projektin vieminen {#export-a-project}

Avaa projekti ja napsauta sen nimeä editorin yläosassa. Napsauta jotakin näistä:

| Vaihtoehto                              | Saat                                       |
| ----------------------------------- | --------------------------------------------- |
| <strong>Export as Word document (.docx)</strong> | Projektin mukaan nimetyn `.docx`-tiedoston        |
| <strong>Export as Markdown (.md)</strong>        | `.zip`-tiedoston, jossa on `main.md`                  |
| <strong>Export as HTML (.html)</strong>          | `.zip`-tiedoston, jossa on `main.html`                |

Lataus alkaa itsestään. Muunnos ei pysty toistamaan kaikkea LaTeX-muotoilua, joten tarkista tulos.
