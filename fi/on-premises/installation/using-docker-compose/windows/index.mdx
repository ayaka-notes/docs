Tässä osiossa ajamme Ayakaleaf Prota paikallisesti Windowsissa WSL 2:n, Ubuntun, Docker Desktopin ja [Ayakaleaf Toolkitin](https://github.com/ayaka-notes/toolkit) avulla. Opas käyttää osoitetta `http://localhost:8080`, säilyttää datan Ubuntun kotihakemistossa ja ottaa hiekkalaatikkokäännökset käyttöön.

Sovellus, MongoDB, Redis ja TeX Live toimivat Docker Desktopin hallinnoimissa Linux-konteissa. Aja Toolkitin komennot Ubuntussa; avaa sovellus Windows-selaimessasi. [Vaihe 0](/fi/on-premises/installation/using-docker-compose/windows/0.-setup-wsl-and-docker-desktop) selittää, miten Windows- ja Linux-osat sopivat yhteen, ja aloittaa WSL:n asentamisesta.

Voit käyttää Windowsia paikalliseen instanssiin tai pitää sen jatkuvasti käynnissä vaiheen 6 saatavuusasetuksilla. Jaetuille ja tuotantopalvelimille suosittelemme [Linux-opasta](/fi/on-premises/installation/using-docker-compose/linux) HTTPS:n, varmuuskopioiden ja käyttöoikeuksien hallinnan kanssa. Windowsin lepotila, Docker Desktopin sammutus ja WSL:n sammutus keskeyttävät tämän paikallisen instanssin; katso [Pidä instanssi saatavilla](/fi/on-premises/installation/using-docker-compose/windows/6.-post-installation-tasks#keep-the-instance-available).

## Ennen aloittamista {#before-you-start}

Tarvitset:

* Windows-version ja suorittimen, joita [Docker Desktop for Windows](https://docs.docker.com/desktop/setup/install/windows-install/) tukee, ja laitteistovirtualisoinnin käyttöön otettuna. Tämä opas käyttää Windows 11:tä x86-64-arkkitehtuurilla.
* Oikeudet ottaa WSL käyttöön ja asentaa ohjelmistoja. WSL:n on oltava versio 2.1.5 tai uudempi, ja Ubuntun on toimittava WSL 2 -tilassa.
* Riittävästi muistia Windowsille ja konteille. Pientä paikallista instanssia varten Dockerin käytettävissä olevat 4 suoritinta ja 8 Gt ovat suositeltu lähtökohta, eivät mitattu vähimmäisvaatimus.
* Vapaata tallennustilaa Windows-levyllä, jolla WSL:n ja Dockerin data on. Varaa vähintään 40 Gt täydelle TeX Live -kokoonpanolle sekä projektidatalle; [vaiheen 5](/fi/on-premises/installation/using-docker-compose/windows/5.-personalizing-your-instance) basic-image on pienempi ja sopii ensimmäiseen käyttöönottotestiin. Lisäimageversiot tarvitsevat lisää tilaa.
* Verkkoyhteyden GitHubiin, GitHub Container Registryyn (`ghcr.io`) ja Docker Hubiin Toolkitin kloonaamista ja imagejen lataamista varten.

**PowerShell**-lohkot ajetaan Windowsissa. **Bash**-lohkot ja `bin/`-komennot ajetaan Ubuntussa, ellei toisin mainita. Älä aja Toolkitin skriptejä PowerShellissä tai Windowsin Git Bashissa.
