Ayakaleaf Pro on maksuton Docker-image [GitHub Container Registryssä (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Sen hakemiseen ei tarvita tiliä, kirjautumista eikä kaupallista Overleaf-lisenssiä.

Avaa `config/overleaf.rc` ja aseta:

```bash title="config/overleaf.rc"
SERVER_PRO=true
```

Kun seuraavan kerran suoritat `bin/up`, Toolkit hakee `ghcr.io/ayaka-notes/overleaf-pro` -imagen tiedoston `config/version` mukaisessa versiossa virallisen Overleaf Community Editionin sijaan.

Image on rakennettu `arm64`- ja `amd64`-arkkitehtuureille, ja Docker valitsee Docker-moottorin arkkitehtuuria vastaavan.
