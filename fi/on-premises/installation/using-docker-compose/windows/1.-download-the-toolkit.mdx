title: 1. Lataa Toolkit
description: Asenna komentorivin riippuvuudet ja kloonaa Ayakaleaf Toolkit WSL 2:n Ubuntussa.

---

<Steps>
<Step title="Asenna komentorivityökalut">
Suorita **Ubuntussa** käyttäen vaiheessa 0 luomaasi Linux-salasanaa:

```bash
sudo apt update
sudo apt install -y git ca-certificates curl perl gawk openssl
```

Ubuntu sisältää jo Bashin, GNU sedin ja coreutilsin. Toisin kuin macOS, se ei tarvitse Homebrew'ta eikä erillistä GNU sed -asennusta.
</Step>

<Step title="Kloonaa Ayakaleaf Toolkit -repositorio">
Pidä Toolkit ja sen data Ubuntun Linux-tiedostojärjestelmässä kotihakemistosi alla:

```bash
cd "$HOME"
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

Vältä elävän tietokannan ja projektidatan säilyttämistä hakemistoissa `/mnt/c` ja `/mnt/d`, OneDrivessa ja väliaikaishakemistoissa. Linux-tiedostojärjestelmän polut tarjoavat konttien odottamat käyttöoikeudet ja tiedostojärjestelmän toiminnan sekä välttävät tiedostojärjestelmien välisen ylikuorman; katso [Microsoftin tiedostojärjestelmäohjeet](https://learn.microsoft.com/en-us/windows/wsl/filesystems).

<Warning>

Jos hakemistossa on jo asennus, käytä sitä sellaisenaan tai valitse uudelle instanssille toinen hakemisto. Älä korvaa olemassa olevan käyttöönoton määrityksiä tai dataa.

</Warning>
</Step>
</Steps>
