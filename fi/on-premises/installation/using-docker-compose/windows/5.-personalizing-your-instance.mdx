---
title: 5. Instanssin mukauttaminen
description: Aseta portti, sivuston URL ja TeX Live -image, ota hiekkalaatikkokäännökset käyttöön ja käynnistä Ayakaleaf Pro WSL 2:ssa.
icon: square-sliders
---

Suorita komennot ja muokkaa tiedostoja **Ubuntussa** hakemistossa `~/ayakaleaf-toolkit`.

<Steps>
<Step title="Kontin asetukset">
Muokkaa olemassa olevia merkintöjä tiedostossa `config/overleaf.rc`:

```bash title="config/overleaf.rc"
PROJECT_NAME=ayakaleaf-wsl
SERVER_PRO=true
OVERLEAF_LISTEN_IP=127.0.0.1
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
DOCKER_SOCKET_PATH=/var/run/docker.sock
```

Pidä oletusarvoiset datapolut sekä mukana tulevat MongoDB- ja Redis-palvelut. Portti `8080` on paikallista Windows-selainta varten; sitominen osoitteeseen `127.0.0.1` pitää sen paikallisena. Hiekkalaatikkokäännökset käyttävät jokaista käännöstä varten erillistä Linux-konttia sen sijaan, että TeX ajettaisiin sovelluskontin sisällä. Docker-socketin avulla sovellus voi luoda nämä kontit, ja Toolkit antaa käännösdatalle isäntäpolun hakemistossa `data/overleaf/data/compiles`.
</Step>

<Step title="Sovelluksen asetukset">
Aseta tiedostossa `config/variables.env` nämä arvot ja korvaa samannimiset aktiiviset merkinnät:

```dotenv title="config/variables.env"
OVERLEAF_SITE_URL=http://localhost:8080
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES="TeX Live 2026"
```

Täysi image sisältää paketit ja fontit, joita laaja joukko projekteja tarvitsee. Varaa sille ja sovellukselle vähintään 40 Gt vapaata tallennustilaa sekä tilaa projektidatalle ja tuleville päivityksille.

Nopeaa käyttöönottotestiä varten käytä sen sijaan pienempää **basic**-imagea. Se riittää vaiheen 6 yksinkertaiseen article-testiin, mutta ei sisällä täyttä paketti- ja fonttivalikoimaa:

```dotenv
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-basic:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-basic:2026.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES="TeX Live 2026 Basic"
```

Valitse yksi näistä joukoista ilman päällekkäisiä aktiivisia avaimia. Basic-imagen [Dockerfile](https://github.com/ayaka-notes/texlive-full/blob/main/texlive/2026/Dockerfile.basic) sisältää `latexmk`:n, XeTeXin ja `fontspec`:n, mutta ei `ctex`:iä eikä täyttä fonttikokoelmaa. Basic-imagesta puuttuva LaTeX-paketti ei sinänsä viittaa hiekkalaatikko-ongelmaan.

Luo istuntosalaisuus:

```bash
openssl rand -hex 32
```

Lisää tulos tiedostoon `config/variables.env` arvoksi `OVERLEAF_SESSION_SECRET`. Säilytä myös luotu kutsutunnuksen salaisuus. Paikallisessa instanssissa ilman sähköpostia jätä SMTP-asetukset ja `OVERLEAF_EMAIL_FROM_ADDRESS` asettamatta.
</Step>

<Step title="Käynnistä instanssi">
```bash
bin/up -d
```

Toolkit käynnistää MongoDB:n, alustaa sen replica setin, lataa valitun TeX Live -imagen ja käynnistää Redisin ja sovelluksen. Se voi vaikuttaa pysähtyneeltä, kun suurta imagea ladataan. Älä aja toista `bin/up`-komentoa, kun ensimmäinen on vielä kesken.

Tarkista toisessa Ubuntu-päätteessä:

```bash
cd "$HOME/ayakaleaf-toolkit"
bin/docker-compose ps
bin/docker-compose logs --tail=100 mongo
bin/docker-compose logs --tail=100 -f sharelatex
```

Lopeta lokien seuraaminen painamalla `Ctrl+C`; taustalla ajettavat kontit jäävät käyntiin. Jos käynnistys epäonnistuu MongoDB:n kohdalla, noudata kohtaa [MongoDB ei käynnisty](/fi/on-premises/installation/using-docker-compose/windows/troubleshooting#mongodb-fails-to-start) ennen uutta yritystä. Älä poista sen datahakemistoa olemassa olevan asennuksen nollaamiseksi.

Tarkista portti ja ensimmäisen käynnistyksen sivu:

```bash
bin/docker-compose port sharelatex 80
curl -I http://localhost:8080/launchpad
```

Portin pitäisi olla `127.0.0.1:8080`. Odota sovelluksen alustusta, jos HTTP-pyyntö epäonnistuu aluksi.
</Step>

<Step title="Avaa instanssi Windowsista">
Avaa **Windows-selaimessasi** [http://localhost:8080/launchpad](http://localhost:8080/launchpad). Käytä tätä osoitetta myös Windowsissa väliaikaisen WSL-IP-osoitteen sijaan.

Jos haluat tarkistaa Windowsin HTTP-yhteyden selaimesta erillään, suorita **PowerShellissä**:

```powershell
curl.exe -I http://localhost:8080/launchpad
```

Jos Ubuntu tavoittaa sivun mutta Windows ei, katso [Windows ei pysty avaamaan localhostia](/fi/on-premises/installation/using-docker-compose/windows/troubleshooting#windows-cannot-open-localhost).
</Step>
</Steps>
