Suorita **Ubuntussa** Toolkit-hakemistossa:

```bash
bin/init
```

`bin/init` luo kolme tiedostoa:

| Tiedosto | Tarkoitus |
| --- | --- |
| `config/overleaf.rc` | Kontin asetukset, julkaistu portti ja datan sijainnit |
| `config/variables.env` | Sovelluksen asetukset ja salaisuudet |
| `config/version` | Sovellusimagen versio |

Se myös luo `OVERLEAF_INVITE_TOKEN_SECRET`-arvon tiedostoon `config/variables.env`. Säilytä se, äläkä julkaise tätä tiedostoa tai tallenna sitä versionhallintaan.

Pidä versio, jonka Toolkit valitsee uudelle asennukselle. Jos haluat myöhemmin vaihtaa olemassa olevan instanssin versiota, noudata sivua [Käyttöönoton päivittäminen](/fi/on-premises/maintenance/upgrading-your-deployment).

<Info>

`bin/init` ei korvaa olemassa olevia määrityksiä. Jos se ilmoittaa, että tiedostot ovat jo olemassa, tarkastele niitä ennen kuin jatkat. Säilytä `config/` ja `data/`, kun käynnistät instanssin uudelleen tai päivität sen.

</Info>
