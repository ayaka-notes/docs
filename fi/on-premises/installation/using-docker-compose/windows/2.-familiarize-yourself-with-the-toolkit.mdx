Toolkit on sama kuin Linuxissa. Sen rakenne, `config/`-hakemisto ja `bin/`-komennot kuvataan Linux-oppaan sivulla [2. Tutustu Toolkitiin](/fi/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit).

Windowsissa on pidettävä mielessä nämä erot:

* Aja `bin/`-komennot **Ubuntun Bashissa** hakemistossa `~/ayakaleaf-toolkit`. **PowerShell**-merkityt komennot ajetaan sen sijaan Windowsissa.
* Käynnistä Docker Desktop ja ota Ubuntun WSL Integration käyttöön ennen kuin käytät komentoja `bin/up`, `bin/start` tai `bin/docker-compose`.
* Pidä määritystiedostoissa Linuxin rivinvaihdot (LF). Muokkaa niitä Ubuntun `nano`-editorilla tai WSL:ään yhdistetyllä editorilla. CRLF-rivinvaihdot voivat aiheuttaa Bash-virheitä.
* `bin/doctor` ajaa Linux-tarkistuksia Ubuntussa. Sen varoitus siitä, ettei `quay.io`-palveluun ole kirjauduttu, ei koske julkista `ghcr.io/ayaka-notes/overleaf-pro` -imagea. Muut varoitukset vaativat silti huomiota.

```bash
bin/doctor
```
