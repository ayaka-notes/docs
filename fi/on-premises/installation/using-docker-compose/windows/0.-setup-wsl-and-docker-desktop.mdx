Ayakaleaf Pro käyttää Linux-kontteja. Asenna Windowsissa Docker Desktop sen WSL 2 -taustajärjestelmän kanssa ja aja Toolkitin skriptit Ubuntussa.

WSL 2 tarjoaa Linux-ytimen. Docker Desktop hallinnoi Docker-moottoria omassa `docker-desktop`-ympäristössään; **WSL Integration** -asetuksen käyttöönotto antaa Ubuntun Docker CLI:n kommunikoida kyseisen moottorin kanssa. Toolkit käynnistää sitten sovelluksen, MongoDB:n ja Redisin kontteina. Kun hiekkalaatikkokäännökset ovat käytössä, sovellus käyttää moottorin Docker-socketia erillisen TeX Live -kontin käynnistämiseen jokaista käännöstä varten. Et tarvitse MongoDB:n, Redisin tai TeX Liven Windows-asennuksia.

<Steps>
<Step title="Asenna WSL 2 ja Ubuntu">
Avaa Windowsissa **PowerShell järjestelmänvalvojana** ja suorita:

```powershell
wsl --install -d Ubuntu
```

Käynnistä Windows uudelleen, jos sitä pyydetään. Avaa **Ubuntu** Käynnistä-valikosta ja luo Linux-käyttäjänimi ja -salasana. Tämä on Ubuntun `sudo`-tili; se on erillinen Windows-kirjautumisestasi.

Päivitä WSL ja tarkista jakelu takaisin **PowerShellissä**:

```powershell
wsl --update
wsl --version
wsl --list --verbose
```

Ubuntu-rivillä on näyttävä **VERSION 2**. Jos siinä näkyy 1, käytä luettelossa näkyvää jakelun tarkkaa nimeä:

```powershell
wsl --set-version Ubuntu 2
```

Docker vaatii WSL:n version **2.1.5 tai uudemman**; komennon `wsl --version` näyttämä WSL-ohjelmiston versio ja jakelun **VERSION 2** -sarake ovat eri tarkistuksia. Jos asennus epäonnistuu, katso [asennuksen vianmääritys](/fi/on-premises/installation/using-docker-compose/windows/troubleshooting#wsl-or-docker-reports-that-virtualization-is-unavailable) ja [Microsoftin asennusohjeet](https://learn.microsoft.com/en-us/windows/wsl/install), ja ota laitteistovirtualisointi käyttöön BIOS/UEFI-asetuksissa, jos WSL ilmoittaa, ettei se ole käytettävissä.
</Step>

<Step title="Asenna ja käynnistä Docker Desktop">
Lataa suorittimellesi sopiva [Docker Desktop for Windows](https://docs.docker.com/desktop/setup/install/windows-install/) ja suorita asennusohjelma. Käytä **WSL 2** -taustajärjestelmää, jos sitä tarjotaan. Avaa **Docker Desktop** Windowsin Käynnistä-valikosta ja odota, että moottori käynnistyy.

Ota Docker Desktopin kohdassa **Settings → General** käyttöön **Use WSL 2 based engine**, jos vaihtoehto näkyy. Ota kohdassa **Settings → Resources → WSL Integration** integraatio käyttöön **Ubuntulle** ja valitse sitten **Apply** tai **Apply & restart**. Jos Ubuntu ei ole oletusjakelusi, ota sen oma kytkin käyttöön erikseen.

Jos WSL Integration puuttuu, tarkista, että Docker Desktop käyttää **Linux-kontteja**. Katso [Dockerin WSL 2 -taustajärjestelmän opas](https://docs.docker.com/desktop/features/wsl/).

Käytä tässä oppaassa Docker Desktopin integraatiota. Toisen Docker Enginen asentaminen komennolla `apt install docker.io` tai `dockerd`:n käynnistäminen Ubuntussa luo erillisen kokoonpanon ja voi aiheuttaa ristiriitoja. Jos käytät jo Engineä Ubuntussa, noudata Dockerin siirto-ohjeita ennen vaihtamista; säilytä olemassa oleva sovellusdata ja varmuuskopiot.
</Step>

<Step title="Tarkista Docker Ubuntusta">
Avaa **Ubuntu**-pääte. Suorita siellä nämä komennot ilman `sudo`a:

```bash
docker version
docker compose version
docker ps
```

Komennon `docker version` on näytettävä sekä **Client** että **Server**. Tyhjä konttiluettelo on normaali uudessa asennuksessa. Pelkkä `docker --version` ei todista, että moottori on käynnissä.

Jos `docker` ei ole käytettävissä tai ei saa yhteyttä, avaa Ubuntu uudelleen WSL Integrationin käyttöönoton jälkeen ja tarkista, että Docker Desktop on käynnissä. Katso [Vianmääritys](/fi/on-premises/installation/using-docker-compose/windows/troubleshooting#docker-is-unavailable-in-ubuntu).
</Step>

<Step title="Tarkista resurssit ja Docker-socket">
Tarkista Dockerin näkemät resurssit:

```bash
docker info --format 'CPUs={{.NCPU}} Memory={{.MemTotal}} Kernel={{.KernelVersion}}'
df -h "$HOME"
ls -l /var/run/docker.sock
```

Pientä paikallista instanssia varten Dockerin käytettävissä olevat 4 suoritinta ja 8 Gt muistia ovat suositeltu lähtökohta, eivät mitattu vähimmäisvaatimus. Jätä riittävästi muistia myös Windowsille. WSL 2 -taustajärjestelmää käytettäessä resurssirajoja hallitaan [WSL-asetusten](https://learn.microsoft.com/en-us/windows/wsl/wsl-config) kautta eikä Macin Docker Desktopin resurssiliukusäätimillä. Muutokset, jotka vaativat komennon `wsl --shutdown`, keskeyttävät kaikki käynnissä olevat WSL-jakelut ja Docker-kuormat; tee ne ennen instanssin käynnistämistä.

Jätä `DOCKER_SOCKET_PATH=/var/run/docker.sock` Toolkitin määrityksiin. Sovellus tarvitsee tämän moottorin socketin hiekkalaatikkokäännöksiä varten. Älä muuta sen käyttöoikeuksia arvoon `777` yhteysvirheiden korjaamiseksi; palauta sen sijaan Docker Desktopin integraatio.
</Step>
</Steps>
