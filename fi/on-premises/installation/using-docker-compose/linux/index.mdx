Tässä osiossa opastamme sinut asentamaan Dockerin, lataamaan Toolkitin GitHubista, tutustumaan joihinkin Toolkitin komentoihin ja määrittämään joitakin perusasetuksia. Tämän osion lopussa sinulla pitäisi olla käynnissä oleva paikallinen Overleaf-instanssi.

Vaiheet on tarkoitettu tuoreelle Ubuntu LTS -versiolle. Jos käytät toista jakelua, asenna Docker Engine ja Compose-liitännäinen [Dockerin dokumentaation](https://docs.docker.com/engine/install/) mukaisesti ja jatka sitten vaiheeseen [1. Lataa Toolkit](/fi/on-premises/installation/using-docker-compose/linux/1.-download-the-toolkit).

<Info>

Oletuksena instanssi hyväksyy yhteyksiä vain itse palvelimelta osoitteessa `http://localhost`. Jos haluat avata sen muilta tietokoneilta tai toisessa portissa, aseta `OVERLEAF_LISTEN_IP` ja `OVERLEAF_PORT` tiedostoon `config/overleaf.rc`, kuten sivulla [5. Instanssin mukauttaminen](/fi/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance) kuvataan.

</Info>
