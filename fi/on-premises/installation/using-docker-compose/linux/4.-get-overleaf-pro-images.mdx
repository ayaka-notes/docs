---
title: 4. Hanki Ayakaleaf Pro -imaget
icon: split
---

Ayakaleaf Pro on maksuton Docker-image [GitHub Container Registryssä (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Sen hakemiseen ei tarvita tiliä eikä kirjautumista. Imaget on rakennettu amd64- ja arm64-arkkitehtuureille, ja Docker valitsee palvelimeesi sopivan.

Avaa `config/overleaf.rc` ja aseta:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

Kun seuraavan kerran suoritat `bin/up`, Toolkit lataa Ayakaleaf Pro -imagen ja käyttää sitä virallisen Overleaf Community Editionin sijaan. Hakemiston `config/` asetuksesi toimivat edelleen.

<Accordion title="Käytätkö jo virallista Overleaf Toolkitia (overleaf/toolkit)?">

Sinun ei tarvitse asentaa uudelleen. Hae Ayakaleaf Pro -image:

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Lisää sitten hakemistoon `overleaf-toolkit/config` tiedosto nimeltä `docker-compose.override.yml`, jonka sisältö on seuraava:

```yml
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

Kun seuraavan kerran suoritat `bin/up`, Toolkit käyttää Ayakaleaf Pro -imagea.

</Accordion>
