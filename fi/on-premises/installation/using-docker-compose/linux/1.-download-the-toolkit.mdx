### Toolkitin lataaminen {#downloading-the-toolkit}

Ayakaleaf Pro asennetaan **Ayakaleaf Toolkitilla** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)), joka on joukko skriptejä, jotka ajavat Overleafia puolestasi Dockerissa.

Oletuksena Toolkit käynnistää maksuttoman virallisen Overleaf Community Editionin (CE). [4. Hanki Ayakaleaf Pro -imaget](/fi/on-premises/installation/using-docker-compose/linux/4.-get-overleaf-pro-images) vaihtaa sen Ayakaleaf Pro -versioon yhdellä asetuksella.

<Accordion title="Käytätkö jo virallista Overleaf Toolkitia (overleaf/toolkit)?">

Sinun ei tarvitse asentaa uudelleen. Säilytä asennuksesi ja noudata sivun [4. Hanki Ayakaleaf Pro -imaget](/fi/on-premises/installation/using-docker-compose/linux/4.-get-overleaf-pro-images) viimeistä osaa.

</Accordion>

<Steps>
<Step title="Kloonaa Ayakaleaf Toolkit -repositorio">
Asentaaksesi toolkitin siirry haluamaasi asennuspolkuun ja kloonaa Ayakaleaf Toolkit -repositorio tällä komennolla:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
```

<Info>

Mahdollisten käyttöoikeusongelmien välttämiseksi suosittelemme asentamaan Toolkitin käyttäjäsi `$HOME`-hakemistoon.

</Info>
</Step>

<Step title="Siirry toolkit-hakemistoon">
Odota, että kloonaus on valmis, ja siirry sitten juuri luotuun `overleaf-toolkit`-hakemistoon:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
