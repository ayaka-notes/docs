Docker Compose yhdellä palvelimella on suositeltu tapa ottaa Ayakaleaf Pro käyttöön. Ajat sitä [Toolkitin](https://github.com/ayaka-notes/toolkit) kautta: se on joukko skriptejä, jotka käärivät `docker compose` -komennon ja lukevat asetuksesi yhdestä `config/`-hakemistosta, joten `bin/up` korvaa komennon `docker compose up`.
