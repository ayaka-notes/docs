### Ylläpitäjän ja ensimmäisen projektin luominen {#create-the-administrator-and-a-first-project}

Avaa [http://localhost:8080/launchpad](http://localhost:8080/launchpad), luo ensimmäinen ylläpitäjätili ja kirjaudu sisään. Noudata sitten Linux-oppaan sivua [6. Asennuksen jälkeiset tehtävät](/fi/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks) ja käytä sen esimerkki-URL-osoitteissa porttia `8080`.

### Käännöksen varmistaminen {#verify-compilation}

Avautuva kirjautumissivu ei todista, että erilliset kääntäjäkontit ja niiden dataliitokset toimivat. Luo tyhjä projekti ja käännä tämä `main.tex`:

```latex
\documentclass{article}
\begin{document}
Ayakaleaf Pro on macOS.
\end{document}
```

PDF-esikatselun pitäisi näyttää teksti. Valitse tarvittaessa TeX Live 2026 projektin asetuksista.

Jos projektissa on kiinalaista tekstiä, valitse kääntäjäksi **XeLaTeX** ja testaa:

```latex
\documentclass{ctexart}
\begin{document}
你好，Ayakaleaf Pro。
\end{document}
```

### Pysyvyyden varmistaminen {#verify-persistence}

```bash
bin/stop
bin/start
```

Avaa projekti uudelleen ja käännä se taas. Tilisi, lähdekoodi ja projektin tiedostot pitäisi olla yhä tallessa. Oletuspoluilla elävä data on Toolkitin `data/`-hakemistossa Macillasi.

### Pidä instanssi saatavilla {#keep-the-instance-available}

Kun Mac on lepotilassa, macOS keskeyttää Docker Desktopin virtuaalikoneen ja kaikki sen kontit: kukaan ei voi avata instanssia, ja käynnissä oleva käännös pysähtyy, kunnes Mac herää. Vain järjestelmän lepotilalla on merkitystä. Näyttö saa sammua.

Jos instanssia käyttävät muutkin tai jätät pitkiä tehtäviä käyntiin, pidä Mac verkkovirrassa ja estä automaattinen lepotila, katso [Macin lepo- ja herätysasetusten määrittäminen](https://support.apple.com/guide/mac-help/set-sleep-and-wake-settings-mchle41a6ccd/mac):

| Mac | Asetus |
| --- | --- |
| Pöytä-Mac (Mac mini, iMac, Mac Studio, Mac Pro) | **System Settings → Energy**: ota käyttöön **Prevent automatic sleeping when the display is off** |
| MacBook | **System Settings → Battery → Options**: ota käyttöön **Prevent automatic sleeping on power adapter when the display is off**. Tämä on voimassa vain, kun virtalähde on kytkettynä, ja kannen sulkeminen asettaa MacBookin silti lepotilaan |

Jos haluat pitää Macin hereillä vain hetken, suorita sen sijaan `caffeinate -i` Pääte-ikkunassa. Se estää lepotilan joutokäynnillä, kunnes painat `Ctrl+C` tai suljet ikkunan.

Docker Desktop on käyttäjäistuntosi sovellus. Jotta instanssi palaa käyttöön uudelleenkäynnistyksen jälkeen, ota käyttöön **Start Docker Desktop when you sign in to your computer** Docker Desktopin kohdassa **Settings → General**. Toolkitin kontit käyttävät asetusta `restart: always`, joten Docker käynnistää ne uudelleen heti, kun Docker Desktop on käynnissä, ilman `bin/up`-komentoa. Instanssi pysyy alhaalla, kunnes joku kirjautuu Maciin uudelleenkäynnistyksen jälkeen.

<Info>

Hereillä pysyvä Mac kuluttaa enemmän virtaa. Palvelulle, jonka on oltava aina tavoitettavissa, suosittelemme Linux-palvelinta, katso [Linux](/fi/on-premises/installation/using-docker-compose/linux).

</Info>

### Päivittäinen käyttö {#daily-use}

Avaa Docker Desktop ennen kuin hallinnoit instanssia. Uudessa päätteessä:

```bash
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
cd "$HOME/ayakaleaf-toolkit"
```

| Tehtävä | Komento |
| --- | --- |
| Käynnistä olemassa olevat kontit | `bin/start` |
| Pysäytä kontit ja säilytä data | `bin/stop` |
| Ota määritysmuutokset käyttöön | `bin/up -d` |
| Tarkista tila | `bin/docker-compose ps` |
| Lue käynnistyslokit | `bin/docker-compose logs --tail=100 sharelatex` |
| Lue kääntäjän lokit | `bin/logs -f clsi` |

`bin/start` ei ota käyttöön hakemiston `config/` muutoksia: suorita `bin/up -d` muokattuasi määrityksiä. Säilytä `config/` ja `data/`, ja noudata sivua [Data ja varmuuskopiot](/fi/on-premises/maintenance/data-and-backups) ennen päivitystä tai asennuksen siirtämistä. Tietokantatiedostojen kopioiminen MongoDB:n kirjoittaessa niihin ei ole johdonmukainen varmuuskopio.

Pidä instanssi osoitteessa `127.0.0.1` paikallista käyttöä varten. Jos haluat palvella muita tietokoneita, aseta kuunteluosoite, sivuston URL ja HTTPS tietoisesti, katso Linux-oppaan sivu [5. Instanssin mukauttaminen](/fi/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance).

Jos jokin ei toimi, katso [Vianmääritys](/fi/on-premises/installation/using-docker-compose/macos/troubleshooting).
