---
title: 3. Alusta konfiguraatio
description: Luo Toolkitin määritystiedostot Macillasi komennolla bin/init.
icon: circle-play
---

Suorita Toolkit-hakemistossa, päätteessä jossa GNU sed on `PATH`-muuttujassa:

```bash
bin/init
```

`bin/init` luo kolme tiedostoa:

| Tiedosto | Tarkoitus |
| --- | --- |
| `config/overleaf.rc` | Kontin asetukset, julkaistu portti ja datan sijainnit |
| `config/variables.env` | Sovelluksen asetukset ja salaisuudet |
| `config/version` | Sovellusimagen versio |

Se myös luo `OVERLEAF_INVITE_TOKEN_SECRET`-arvon tiedostoon `config/variables.env`. Säilytä se, äläkä julkaise tätä tiedostoa tai tallenna sitä versionhallintaan.

Pidä versio, jonka Toolkit valitsee uudelle asennukselle. Jos haluat myöhemmin vaihtaa olemassa olevan instanssin versiota, noudata sivua [Käyttöönoton päivittäminen](/fi/on-premises/maintenance/upgrading-your-deployment).

<Warning>

Jos `bin/init` pysähtyy virheeseen `sed: ... invalid command code`, se ajettiin macOS:n BSD sedillä. Tällainen epäonnistunut ajo voi jättää kaikki kolme tiedostoa hakemistoon `config/` tyhjällä `OVERLEAF_INVITE_TOKEN_SECRET`-arvolla, ja `bin/init`-komennon uudelleenajo ilmoittaa silloin `Config files already exist`. Katso [Vianmääritys](/fi/on-premises/installation/using-docker-compose/macos/troubleshooting#initialization-fails-with-invalid-command-code).

</Warning>
