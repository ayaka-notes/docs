Tässä osiossa ajamme Ayakaleaf Prota paikallisesti Macillasi Docker Desktopin ja [Ayakaleaf Toolkitin](https://github.com/ayaka-notes/toolkit) avulla. Opas käyttää osoitetta `http://localhost:8080`, säilyttää datan kotihakemistossasi ja kääntää TeX Live 2026:lla hiekkalaatikkokonteissa.

Docker Desktop ajaa sovellusta, MongoDB:tä, Redisiä ja TeX Live -kääntäjää Linux-virtuaalikoneessa. Et asenna MongoDB:tä, Redisiä tai MacTeX:iä itse macOS:ään.

Käytä tätä kokoonpanoa henkilökohtaiseen käyttöön ja paikalliseen testaukseen. Jatkuvasti käynnissä olevaa jaettua palvelua varten suosittelemme [Linux-opasta](/fi/on-premises/installation/using-docker-compose/linux) HTTPS:n, varmuuskopioiden ja käyttöoikeuksien hallinnan kanssa. Instanssi ei ole käytettävissä, kun Mac on lepotilassa tai Docker Desktop on pysäytetty, katso [Pidä instanssi saatavilla](/fi/on-premises/installation/using-docker-compose/macos/6.-post-installation-tasks#keep-the-instance-available).

## Ennen aloittamista {#before-you-start}

Tarvitset:

* macOS-version, jota [Docker Desktop for Mac](https://docs.docker.com/desktop/setup/install/mac-install/) tukee.
* Gitin, [Homebrew'n](https://brew.sh/) ja GNU sedin. Toolkit käyttää GNU sedin valitsimia, joita macOS:n sisäänrakennettu BSD sed ei hyväksy.
* Riittävästi resursseja sekä macOS:lle että Dockerille. Pientä paikallista instanssia varten aloita varaamalla Docker Desktopille 4 suoritinta ja 8 Gt muistia. Tämä on suositeltu lähtökohta, ei mitattu vähimmäisvaatimus.
* Vähintään 40 Gt vapaata tallennustilaa täydelle TeX Live -imagelle sekä tilaa projekteillesi. Tarkista sekä Macin vapaa tila että Docker Desktopin levynkäyttöraja. Aloita yhdellä TeX Live -versiolla: jokainen lisäversio tarvitsee suunnilleen saman verran tilaa lisää.

Sovellus- ja TeX Live -imaget julkaistaan `arm64`- ja `amd64`-arkkitehtuureille. Anna Apple siliconilla Dockerin valita natiivi ARM-image, äläkä pakota asetusta `platform: linux/amd64`.
