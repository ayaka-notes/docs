<Steps>
<Step title="Tarkista Git ja Homebrew">
```bash
git --version
brew --version
```

Jos macOS pyytää sinua asentamaan Command Line Tools -työkalut, kun suoritat Gitin, asenna ne ensin. Jos Homebrew puuttuu, asenna se [virallisten ohjeiden](https://brew.sh/) mukaisesti.
</Step>

<Step title="Lisää GNU sed PATH-muuttujaan">
Toolkitin skriptit käyttävät GNU sedin valitsimia, joita macOS:n sisäänrakennettu BSD sed ei hyväksy. Asenna [GNU sed](https://formulae.brew.sh/formula/gnu-sed) ja aseta se `PATH`-muuttujan ensimmäiseksi tässä päätteessä:

```bash
brew install gnu-sed
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
sed --version
```

Viimeisen komennon pitäisi tulostaa **GNU sed**.

Alias, kuten `alias sed=gsed`, ei riitä: Toolkit ajaa Bash-skriptejä, jotka eivät näe interaktiivisen komentotulkkisi aliaksia. Sinun ei tarvitse korvata tiedostoa `/usr/bin/sed`.

Suorita `export PATH=...` -rivi uudelleen jokaisessa uudessa päätteessä, jota käytät Toolkitin kanssa, tai lisää se komentotulkkisi käynnistystiedostoon Homebrew'n oman alustuksen jälkeen.
</Step>

<Step title="Kloonaa Ayakaleaf Toolkit -repositorio">
Valitse pysyvä hakemisto. Vältä elävän tietokannan ja projektidatan säilyttämistä hakemistossa `/tmp`, siirrettävillä asemilla ja pilveen synkronoiduissa kansioissa, kuten iCloud Drivessa. Tässä oppaassa käytetään hakemistoa `~/ayakaleaf-toolkit`:

```bash
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

<Warning>

Jos hakemistossa on jo asennus, käytä sitä sellaisenaan tai valitse uudelle instanssille toinen hakemisto. Älä alusta uutta konfiguraatiota olemassa olevan käyttöönoton päälle.

</Warning>

</Steps>
