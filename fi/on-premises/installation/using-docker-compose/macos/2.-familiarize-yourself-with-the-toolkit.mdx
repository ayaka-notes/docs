Toolkit on sama macOS:ssä ja Linuxissa. Sen rakenne, `config/`-hakemisto ja `bin/`-komennot kuvataan Linux-oppaan sivulla [2. Tutustu Toolkitiin](/fi/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit).

macOS:ssä on pidettävä mielessä kolme eroa:

* Aja skriptit päätteestä, jossa GNU sed on `PATH`-muuttujan ensimmäisenä, katso [1. Lataa Toolkit](/fi/on-premises/installation/using-docker-compose/macos/1.-download-the-toolkit).
* Käynnistä Docker Desktop ennen kuin ajat skriptin, joka kommunikoi Dockerin kanssa, kuten `bin/up`, `bin/start` tai `bin/docker-compose`.
* `bin/doctor` sisältää virallisesta Overleaf Toolkitista perittyjä tarkistuksia. Sen varoitus `This system seems to not be Linux` on macOS:ssä odotettu, eikä sen varoitus siitä, ettei `quay.io`-palveluun ole kirjauduttu, koske julkista `ghcr.io/ayaka-notes/overleaf-pro` -imagea. Raportin muilla ongelmilla on silti merkitystä.
