Ayakaleaf Pro toimii Dockerin päällä. Macilla käytetään Docker Desktopia, joka ajaa Docker-moottoria Linux-virtuaalikoneessa.

<Steps>
<Step title="Asenna ja käynnistä Docker Desktop">
Asenna Maciisi sopiva [Docker Desktop](https://docs.docker.com/desktop/setup/install/mac-install/) -versio (Apple silicon tai Intel), avaa se ja odota, kunnes moottori on käynnistynyt. Voit käynnistää sen myös Päätteestä:

```bash
open -a Docker
```
</Step>

<Step title="Tarkista Docker-moottori">
Suorita nämä komennot Päätteessä:

```bash
docker context show
docker info
docker compose version
```

Kontekstin pitäisi osoittaa paikalliseen Docker Desktop -moottoriin, tavallisesti `desktop-linux`. Jos valittuna on jokin muu konteksti, vaihda Docker Desktopiin ennen kuin jatkat:

```bash
docker context use desktop-linux
```

Komennon `docker info` on tulostettava **Server**-osio. Pelkkä `docker --version` näyttää vain, että asiakasohjelma on asennettu.
</Step>

<Step title="Tarkista resurssit ja tiedostojen jakaminen">
Tarkista Docker Desktopin **Settings**-asetuksista suoritin-, muisti- ja levyrajat sivun [Ennen aloittamista](/fi/on-premises/installation/using-docker-compose/macos#before-you-start) mukaisesti sekä tiedostojen jakamisen asetukset, katso [Docker Desktopin asetukset](https://docs.docker.com/desktop/settings-and-maintenance/settings/).

Tässä oppaassa Toolkit pidetään hakemistossa `/Users`, jonka Docker Desktop jakaa oletuksena. Jos käytät muuta sijaintia ja `bin/up` epäonnistuu virheeseen `Mounts denied`, lisää kyseinen hakemisto tiedostojen jakamiseen.
</Step>

<Step title="Tarkista Docker-socket hiekkalaatikkokäännöksiä varten">
Toolkit liittää `/var/run/docker.sock`-socketin sovellukseen, jotta se voi käynnistää erillisen TeX Live -kontin jokaista käännöstä varten. Pidä `DOCKER_SOCKET_PATH=/var/run/docker.sock` tiedostossa `config/overleaf.rc`.

Macin Docker CLI saattaa muodostaa yhteyden socketin `~/.docker/run/docker.sock` kautta. Se on Macin asiakaspäätepiste, eikä se ole syy muuttaa Toolkitin liitoksen lähdettä: kääntäjä tarvitsee moottorin socketin sellaisena kuin Linux-kontit sen näkevät.

Jos `/var/run/docker.sock` puuttuu Macilta, ota käyttöön **Allow the default Docker socket to be used** kohdassa **Settings → Advanced**, katso [Dockerin käyttöoikeusvaatimukset](https://docs.docker.com/desktop/setup/install/mac-permission-requirements/).

<Danger>

Älä suorita socketille `chmod 777` virheiden kiertämiseksi. Pääsy Docker-socketiin vastaa root-oikeuksia Docker-virtuaalikoneeseen.

</Danger>
</Step>
</Steps>
