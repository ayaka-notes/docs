### Luo ensimmäinen ylläpitäjätilisi {#create-your-first-administrator-account}

Avaa [http://localhost:8080/launchpad](http://localhost:8080/launchpad) tai oma `OVERLEAF_SITE_URL`-osoitteesi, jonka perässä on `/launchpad`, ja rekisteröi ylläpitäjätili. Tästä eteenpäin kaikki toimii kuten Dockerissa: noudata Docker-oppaan kohtaa [6. Asennuksen jälkeiset tehtävät](/fi/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks) ja käytä sen `localhost`-linkeissä porttia `8080`.

Luo esimerkkiprojekti ja käännä se. PDF osoittaa, että käännökset ajetaan TeX Live -konteissaan Podmanin kautta. Käännöskontin näet näin:

```bash title="List the compile containers"
podman ps -a --filter name=project- --format "{{.Names}} {{.Image}} {{.Status}}"
```

### Käytä HTTPS:ää {#use-https}

Toolkitin [TLS-välityspalvelin](/fi/on-premises/configuration/overleaf-toolkit/tls-proxy) toimii Podmanissa: aja `bin/init --tls` ja aseta varmenteesi ja `NGINX_ENABLED=true` siellä kuvatulla tavalla. Se kuuntelee portteja `80` ja `443`, joita rootless Podman ei oletuksena saa käyttää. Salli tavallisten käyttäjien käyttää portteja `80`:stä alkaen:

```bash title="Allow ports 80 and 443"
echo "net.ipv4.ip_unprivileged_port_start=80" | sudo tee /etc/sysctl.d/99-unprivileged-ports.conf
sudo sysctl --system
```

Tämä antaa jokaisen palvelimen käyttäjän kuunnella näitä portteja, joten tee näin vain palvelimella, joka on omistettu Ayakaleaf Prolle. Avaa ne sitten palomuurissa:

```bash title="Open ports 80 and 443"
sudo firewall-cmd --permanent --add-port=80/tcp --add-port=443/tcp
sudo firewall-cmd --reload
```

Aseta `OVERLEAF_SITE_URL` `https://`-osoitteeseesi ja aja `bin/up -d`. Pidä oletusarvot `NGINX_HTTP_PORT=80` ja `TLS_PORT=443`: muilla porteilla uudelleenohjaus HTTP:stä HTTPS:ään johtaa väärään porttiin.

<Info>

Jätä `OVERLEAF_LISTEN_IP` arvoon `127.0.0.1`, kun käytät TLS-välityspalvelinta, jotta porttiin `8080` ei pääse muilta tietokoneilta.

</Info>

### Päivitys {#upgrade}

Päivitä komennolla `bin/upgrade`, kuten sivulla [Käyttöönoton päivittäminen](/fi/on-premises/maintenance/upgrading-your-deployment) kuvataan. Podmanissa se myös purkaa uuden version seccomp-profiilin hakemistoon `config/seccomp/<version>/` ja päivittää muuttujan `SECCOMP_PROFILE`:

```text
Over-writing config/version with 6.3.4
Set SECCOMP_PROFILE=/home/<user>/overleaf-toolkit/config/seccomp/6.3.4/clsi-profile.json in config/variables.env
```

Aja päivityksen jälkeen `bin/podman-setup` tarkistaaksesi asennuksen.

### SELinux-tilan vaihtaminen {#change-the-selinux-mode}

`SELINUX_MODE` tiedostossa `config/overleaf.rc` määrää, miten SELinux rajoittaa `sharelatex`-konttia. `managed` on tila, jonka nämä sivut määrittävät; muut tilat on kuvattu sivulla [Toolkit-asetukset](/fi/on-premises/configuration/overleaf-toolkit/toolkit-settings). Aja `bin/up -d` sen muuttamisen jälkeen.
