---
title: 1. Lataa ja alusta Toolkit
description: Kloonaa Ayakaleaf Toolkit, luo konfiguraatio ja määritä se Ayakaleaf Prolle Podmanissa.
icon: arrow-down-to-bracket
---

<Steps>
<Step title="Kloonaa Toolkit">
Kloonaa **Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)) kotihakemistoosi ja siirry siihen:

```bash title="Clone the Toolkit" wrap
git clone https://github.com/ayaka-notes/toolkit.git ~/overleaf-toolkit
cd ~/overleaf-toolkit
```

Aja kaikki seuraavat komennot tässä hakemistossa.
</Step>

<Step title="Luo konfiguraatio">
```bash title="Run initialization"
bin/init
```

Tämä luo tiedostot `config/overleaf.rc`, `config/variables.env` ja `config/version`, kuten Docker-oppaan kohdassa [3. Alusta konfiguraatio](/fi/on-premises/installation/using-docker-compose/linux/3.-initialize-the-configuration) kuvataan. `bin/init` ei vielä tarvitse Podmania.
</Step>

<Step title="Määritä config/overleaf.rc">
Avaa `config/overleaf.rc` ja muuta nämä rivit:

```bash title="config/overleaf.rc"
SERVER_PRO=true
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
```

Lisää sitten tämä rivi tiedoston loppuun:

```bash title="config/overleaf.rc"
SELINUX_MODE=managed
```

| Asetus                            | Miksi                                                                                                                                                                                                       |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SERVER_PRO=true`                 | Käyttää Ayakaleaf Pro -imagea osoitteesta `ghcr.io`. Kirjautumista ei tarvita.                                                                                                                              |
| `OVERLEAF_PORT=8080`              | Rootless Podman ei voi kuunnella portteja alle `1024`. Oletusportti `80` epäonnistuu.                                                                                                                       |
| `SIBLING_CONTAINERS_ENABLED=true` | Ajaa jokaisen käännöksen omassa TeX Live -kontissaan. Oletuksena jo `true`; Podman-asennus tukee vain tätä tilaa.                                                                                           |
| `SELINUX_MODE=managed`            | Ajaa `sharelatex`-kontin SELinux-tyypillä `sharelatex_t`, joka saa käyttää Podman-socketia eikä mitään muuta. `bin/podman-setup --apply` asentaa sille käytäntömoduulin. Muut tilat on kuvattu sivulla [Toolkit-asetukset](/fi/on-premises/configuration/overleaf-toolkit/toolkit-settings). |

Jätä `DOCKER_SOCKET_PATH` ennalleen: `bin/podman-setup --apply` asettaa sen Podman-socketiisi seuraavassa vaiheessa.

<Warning>

Pidä `GIT_BRIDGE_ENABLED=false`. Ayakaleaf Pro 6.3.4:ssä Git-integraatio ei toimi Podmanissa, katso [Tunnetut rajoitukset](/fi/on-premises/installation/using-podman#known-limitations).

</Warning>
</Step>

<Step title="Valitse TeX Live -imaget">
Avaa `config/variables.env`, poista `#` muuttujien `TEX_LIVE_DOCKER_IMAGE` ja `ALL_TEX_LIVE_DOCKER_IMAGES` edestä ja luettele käytettävät TeX Live -imaget:

```bash title="config/variables.env" wrap
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
```

`bin/up` pysähtyy viestiin `Please configure ALL_TEX_LIVE_DOCKER_IMAGES`, jos luettelo on tyhjä. `texlive-full` on suuri; testipalvelimelle käy myös paljon pienempi `ghcr.io/ayaka-notes/texlive-basic:2026.1`. Saatavilla olevat imaget löytyvät sivulta [Hiekkalaatikkokäännökset](/fi/on-premises/configuration/overleaf-toolkit/sandboxed-compiles).

Aseta muut muuttujat, kuten `OVERLEAF_SITE_URL`, kuten kohdassa [5. Instanssin mukauttaminen](/fi/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance#required-environment-variables) kuvataan. Oletuskuunteluosoitteella käytä osoitetta `http://localhost:8080`.
</Step>
</Steps>
