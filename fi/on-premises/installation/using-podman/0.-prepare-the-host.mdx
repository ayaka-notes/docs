---
title: 0. Valmistele isäntäkone
description: Tarkista käyttöjärjestelmä ja SELinux ja asenna git ennen rootless Podmanin käyttöönottoa.
icon: server
---

Podmania ei asenneta käsin: [2. Aja podman-setup](/fi/on-premises/installation/using-podman/2.-run-podman-setup) asentaa sen muiden tarvitsemiensa pakettien kanssa. Tässä vaiheessa tarkistat vain isäntäkoneen ja asennat `git`-ohjelman, jota tarvitset Toolkitin lataamiseen.

<Steps>
<Step title="Tarkista käyttöjärjestelmä ja SELinux">
Kirjaudu sisään käyttäjänä, joka ajaa Ayakaleaf Pron, ei `root`-käyttäjänä, ja tarkista jakelu ja SELinux-tila:

```bash title="Check the host"
grep PRETTY_NAME /etc/os-release
getenforce
```

Sinun pitäisi nähdä RHEL, Rocky Linux, AlmaLinux tai CentOS Stream versiona 9 tai uudempana sekä `Enforcing`:

```text
PRETTY_NAME="Rocky Linux 9.9 (Blue Onyx)"
Enforcing
```
</Step>

<Step title="Tarkista, että voit käyttää sudoa">
`bin/podman-setup --apply` asentaa paketteja ja lataa SELinux-moduulin `sudo`-komennolla ja kysyy salasanaasi tarvittaessa:

```bash title="Check sudo"
sudo -v
```

Jos tämä epäonnistuu, pyydä ylläpitäjää lisäämään käyttäjäsi `wheel`-ryhmään.
</Step>

<Step title="Asenna git">
```bash title="Install git"
sudo dnf install -y git
```

<Warning>

Älä asenna Docker Engineä tälle isäntäkoneelle. `bin/podman-setup`-skriptin asentama paketti `podman-docker` tarjoaa `docker`-komennon, ja Toolkit käsittelee isäntää Podman-isäntänä aina, kun `podman`-komento on olemassa.

</Warning>
</Step>
</Steps>
