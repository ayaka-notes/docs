Käytä Claude Codea tai Codexia Ayakaleaf Pron käyttöönoton suunnitteluun ja toteuttamiseen. Agentti voi hakea tästä dokumentaatiosta MCP:n kautta työskennellessään.

Agentti avustaa käyttöönotossa. Sinä olet edelleen vastuussa komentojen tarkistamisesta ja tunnistetietojen suojaamisesta.

### Ennen kuin aloitat

Valmistele tuettu Linux-palvelin, johon on SSH-yhteys. Tutustu [vaatimuksiin](/fi/on-premises/getting-started/requirements  "mention") ennen kuin jatkat.

<Warning>

Älä liitä salasanoja, yksityisiä avaimia, tunnisteita tai lisenssiavaimia agentin kehotteisiin. Tarkista jokainen komento ennen sen suorittamista, erityisesti komennot, jotka muokkaavat tiedostoja, verkkoja tai kontteja.

</Warning>

### Dokumentaation yhdistäminen

Lisää dokumentaation MCP-päätepiste paikalliseen agenttiisi.

<Tabs>
<Tab title="Claude Code">

```bash wrap
claude mcp add ayakaleaf-pro --scope user --transport http https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>

<Tab title="Codex">

```bash wrap
codex mcp add ayakaleaf-pro --url https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>
</Tabs>

Aloita uusi istunto palvelimen lisäämisen jälkeen. Pyydä agenttia vahvistamaan, että se pystyy hakemaan Ayakaleaf Pron dokumentaatiosta.

### Ayakaleaf Pron käyttöönotto

Avaa pääte käyttöönottopalvelimellasi. Käynnistä siellä Claude Code tai Codex. Lähetä sitten tämä kehote:

```text wrap
Use the Ayakaleaf Pro documentation MCP server to guide this deployment.
First, inspect the requirements and installation guides.
Ask me for missing deployment details before making changes.
Use the Ayakaleaf Toolkit unless the documentation requires another approach.
Before configuring the instance, summarize relevant optional features.
Ask which features and integrations I want to enable.
Include TLS, sandboxed compiles, Git integration, external MongoDB or Redis,
SSO (OIDC, SAML, or LDAP), GitHub Synchronisation, Zotero, S3 storage,
email delivery, branding, and localization when relevant.
Explain each selected option's prerequisites, security impact, and configuration steps.
Keep unselected optional features disabled.
Show each command before running it.
Do not expose, store, or request secrets in chat.
After deployment, verify that the service is healthy and summarize the changes.
```

Agentin pitäisi opastaa sinut Dockerin asennuksen, Toolkitin määrityksen, kuvan noutamisen ja käynnistyksen läpi. Noudata virallista työnkulkua varten [using-the-toolkit](/fi/on-premises/installation/using-the-toolkit  "mention") -opasta.

### Valinnaisten ominaisuuksien valitseminen

Pyydä agenttia suosittelemaan vain ympäristöösi sopivia ominaisuuksia. Tyypillisiä valintoja ovat:

* **Pääsy ja tietoturva:** TLS, hiekkalaatikoidut käännökset sekä OIDC-, SAML- tai LDAP-SSO.
* **Ulkoiset palvelut:** MongoDB, Redis, S3-tallennus ja sähköpostin lähetys.
* **Yhteistyö:** Git-integraatio, GitHub-synkronointi ja Zotero.

Agentin tulee selittää riippuvuudet ennen määritysten muokkaamista. Tutustu sivuihin [toolkit-settings.md](/fi/on-premises/configuration/overleaf-toolkit/toolkit-settings  "mention") ja [authentication](/fi/on-premises/configuration/overleaf-toolkit/authentication  "mention") ennen tuotantointegraatioiden käyttöönottoa.

### Käyttöönoton tarkistaminen

Kun agentti on suorittanut vaiheet:

1. Varmista, että jokainen komento suoritettiin ilman virheitä.
2. Avaa määritetty Ayakaleaf Pron URL-osoite selaimessa.
3. Suorita [6.-post-installation-tasks.md](/fi/on-premises/installation/using-the-toolkit/6.-post-installation-tasks  "mention").

Jos sinulla on olemassa oleva Community Edition -asennus, käytä uuden käyttöönoton sijaan [migrate-from-existing.md](/fi/on-premises/installation/migrate-from-existing  "mention") -opasta.
