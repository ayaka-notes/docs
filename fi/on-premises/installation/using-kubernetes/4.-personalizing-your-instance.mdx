ConfigMap `overleaf-env` korvaa Toolkitin tiedoston `config/variables.env`: jokainen [Toolkit-dokumentaation](/fi/on-premises/configuration/overleaf-toolkit/environment-variables) ympäristömuuttuja tulee tänne, ja salaisuudet menevät [vaiheen 2](/fi/on-premises/installation/using-kubernetes/2.-create-the-namespace-and-secrets) Secretiin.

```yaml title="30-config.yaml" wrap
apiVersion: v1
kind: ConfigMap
metadata:
  name: overleaf-env
  namespace: overleaf
data:
  OVERLEAF_APP_NAME: Ayakaleaf Pro
  OVERLEAF_SITE_URL: http://192.0.2.10:30080      # the address users open; https://... behind TLS
  OVERLEAF_ADMIN_EMAIL: admin@example.com
  # Emails: add the sender and the SMTP server together, see Email delivery
  # All members, so that the driver finds the primary even when mongo-0 is down
  OVERLEAF_MONGO_URL: mongodb://mongo-0.mongo:27017,mongo-1.mongo:27017,mongo-2.mongo:27017/sharelatex?replicaSet=overleaf
  OVERLEAF_REDIS_HOST: redis
  REDIS_HOST: redis
  ENABLED_LINKED_FILE_TYPES: project_file,project_output_file,url
  ENABLE_CONVERSIONS: "true"
  EMAIL_CONFIRMATION_DISABLED: "true"
  # Requests arrive from kube-proxy or your ingress controller, inside the pod network
  OVERLEAF_TRUSTED_PROXY_IPS: loopback,10.244.0.0/16
  # Sandboxed compiles. The HOST_DIR paths are paths ON THE NODE: the hostPath volumes that
  # the Deployment mounts at /var/lib/overleaf/data/{compiles,output,cache}.
  SANDBOXED_COMPILES: "true"
  SANDBOXED_COMPILES_SIBLING_CONTAINERS: "true"
  DOCKER_RUNNER: "true"
  SANDBOXED_COMPILES_HOST_DIR_COMPILES: /srv/overleaf/compiles
  SANDBOXED_COMPILES_HOST_DIR_OUTPUT: /srv/overleaf/output
  SANDBOXED_COMPILES_HOST_DIR_CACHE: /srv/overleaf/cache
  # Each image must be pulled into Docker on every node that can run Ayakaleaf Pro (step 0)
  ALL_TEX_LIVE_DOCKER_IMAGES: ghcr.io/ayaka-notes/texlive-full:2026.1
  ALL_TEX_LIVE_DOCKER_IMAGE_NAMES: TeX Live 2026
  TEX_LIVE_DOCKER_IMAGE: ghcr.io/ayaka-notes/texlive-full:2026.1
```

```bash
kubectl apply -f 30-config.yaml
```

| Muuttuja                                | Aseta arvoksi                                                                                                                                                       |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_SITE_URL`                     | URL-osoite, jonka käyttäjät kirjoittavat selaimeen. [Vaiheen 5](/fi/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro) NodePortilla minkä tahansa solmun IP-osoite ja portti `30080`; ingressin tai kuormantasaajan takana sen URL-osoite. |
| `OVERLEAF_MONGO_URL`                    | Replikajoukkosi. Käytä `?replicaSet=`-parametria `rs.initiate`-kutsun nimellä.                                                                                         |
| `OVERLEAF_REDIS_HOST` ja `REDIS_HOST`  | Molemmat Redis-Serviceen.                                                                                                                                    |
| `OVERLEAF_TRUSTED_PROXY_IPS`            | `loopback` sekä verkot, joista välityspalvelimesi muodostavat yhteyden. `10.244.0.0/16` on flannelin pod-verkko; käytä klusterisi pod-CIDR:ää.                               |
| `SANDBOXED_COMPILES_HOST_DIR_*`         | Käännöstaltioiden polut solmulla. Niiden on vastattava [vaiheen 5](/fi/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro) `hostPath`-taltioita.                                       |

HTTPS:n takana aseta myös `OVERLEAF_SECURE_COOKIE: "true"`, katso [TLS-välityspalvelin](/fi/on-premises/configuration/overleaf-toolkit/tls-proxy).

<Info>

Muutettu ConfigMap tavoittaa käynnissä olevat podit vasta uudelleenkäynnistyksen jälkeen: `kubectl -n overleaf rollout restart deployment/overleaf`.

</Info>
