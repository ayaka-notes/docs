### Ensimmäisen ylläpitäjätilin luominen {#creating-your-first-administrator-account}

Avaa `OVERLEAF_SITE_URL` ja sen perään `/launchpad`, esimerkiksi `http://192.0.2.10:30080/launchpad`, ja rekisteröi ylläpitäjätili kuten [Toolkitin asennuksen jälkeisissä tehtävissä](/fi/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks). Luo sitten esimerkkiprojekti ja käännä se.

Voit myös luoda käyttäjiä komentoriviltä:

```bash
kubectl -n overleaf exec deploy/overleaf -- bash -c \
  'cd /overleaf/services/web && node modules/server-ce-scripts/scripts/create-user.mjs --admin --email=admin@example.com'
```

Se tulostaa linkin, jolla salasana asetetaan.

### Hiekkalaatikkokäännösten tarkistaminen {#checking-that-compiles-are-sandboxed}

Käännä projekti ja tarkastele sitten solmua, jolla podi toimii:

```bash
kubectl -n overleaf get pod -l app=overleaf -o wide   # NODE column
# on that node:
sudo docker ps -a --filter ancestor=ghcr.io/ayaka-notes/texlive-full:2026.1
ls -ln /srv/overleaf/compiles                          # owned by uid 33 (www-data)
```

Jokainen käännös näkyy lyhytikäisenä konttina, jonka nimi on `project-<project id>-<user id>-...`.

### Lokit ja komentotulkki {#logs-and-a-shell}

| Toolkit          | Kubernetes                                                               |
| ---------------- | ------------------------------------------------------------------------ |
| `bin/logs web`   | `kubectl -n overleaf exec deploy/overleaf -- tail -f /var/log/overleaf/web.log` |
| `bin/shell`      | `kubectl -n overleaf exec -it deploy/overleaf -- bash`                    |
| `bin/up`         | `kubectl apply -f .` ja sitten `kubectl -n overleaf rollout restart deployment/overleaf` |

Kontti kirjoittaa yhden lokitiedoston palvelua kohden hakemistoon `/var/log/overleaf/` (`web.log`, `clsi.log`, `real-time.log`, `document-updater.log`, ...); `kubectl logs` näyttää käynnistystulosteen.

### Kysymyksiä ja vastauksia {#q&a}

<Accordion title="Käännös epäonnistuu tai ei koskaan valmistu.">

<strong>Vastaus:</strong> Tarkista podia ajavalla solmulla, että Docker on käynnissä ja että siinä on `TEX_LIVE_DOCKER_IMAGE`-asetuksessa nimetty image, ja että `SANDBOXED_COMPILES_HOST_DIR_*` vastaavat `hostPath`-polkuja. Podin tiedosto `/var/log/overleaf/clsi.log` kertoo, mikä vaihe epäonnistuu.

</Accordion>

<Accordion title="Käyttäjät kirjataan ulos jokaisen podin uudelleenkäynnistyksen jälkeen.">

<strong>Vastaus:</strong> `OVERLEAF_SESSION_SECRET` puuttuu Secretistä `overleaf-secrets`, katso [vaihe 2](/fi/on-premises/installation/using-kubernetes/2.-create-the-namespace-and-secrets).

</Accordion>
