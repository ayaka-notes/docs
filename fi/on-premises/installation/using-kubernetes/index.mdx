[Toolkit](/fi/on-premises/installation/using-the-toolkit) on suositeltu tapa ajaa Ayakaleaf Prota yhdellä palvelimella. Jos sinulla on jo Kubernetes-klusteri, tämä osio ottaa saman kontin käyttöön siinä pelkillä `kubectl`-manifesteilla: ei erillistä imagea, ei Helm-kaaviota.

Tämän osion lopussa sinulla on yksi Ayakaleaf Pro -instanssi hiekkalaatikkokäännöksillä, MongoDB-replikajoukolla ja Redisillä, kaikki nimiavaruudessa `overleaf`. Jos haluat ajaa useita instansseja kuormantasaajan takana, jatka sen jälkeen sivulle [Horisontaalinen skaalaus](/fi/on-premises/configuration/kubernetes/horizontal-scaling).

<Info>

Kubernetes-tuki on kokeellinen. Emme julkaise Helm-kaaviota emmekä Kubernetes-kohtaisia imageja. Näiden sivujen manifestit ovat ne, jotka testasimme Kubernetes 1.37:ssä (kubeadm, containerd 2.4, flannel) kolmella solmulla, joissa kussakin on 2 vCPU:ta ja 4 Gt muistia. Mukauta tallennustila, verkko ja ingress klusterillesi.

</Info>

### Miten osat sopivat yhteen

| Toolkit (yksi palvelin)                         | Kubernetes                                                               |
| -------------------------------------------- | ------------------------------------------------------------------------ |
| `config/variables.env`                       | ConfigMap `overleaf-env` ja Secret `overleaf-secrets`                   |
| `sharelatex`-kontti                       | Deployment `overleaf` (yksi podi, joka ajaa kaikkia Overleaf-palveluita)            |
| `mongo`- ja `redis`-kontit               | StatefulSetit `mongo` (replikajoukko) ja `redis` tai hallitut palvelusi |
| `~/overleaf-toolkit/data/overleaf`           | PersistentVolumeClaim `overleaf-data`                                    |
| Isäntäkoneen Docker, jota käytetään käännöksiin        | Docker Engine jokaisella solmulla, joka ajaa Ayakaleaf Prota                      |
| `bin/up`, `bin/logs`, `bin/shell`            | `kubectl apply`, `kubectl logs`, `kubectl exec`                          |

### Mitä tarvitset

* Kubernetes-klusterin, johon voit asentaa paketteja: jokainen solmu, joka voi ajaa Ayakaleaf Prota, tarvitsee **Docker Enginen**, koska käännökset suoritetaan TeX Live -konteissa, jotka Ayakaleaf Pro käynnistää solmun `/var/run/docker.sock`-socketin kautta. Katso [0. Solmujen valmistelu](/fi/on-premises/installation/using-kubernetes/0.-prepare-the-nodes).
* Oletus-StorageClassin, jossa on `ReadWriteOnce`-taltioita.
* `kubectl`- ja `openssl`-työkalut työasemallasi.
