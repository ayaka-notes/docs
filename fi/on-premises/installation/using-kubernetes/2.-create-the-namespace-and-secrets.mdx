---
title: 2. Luo nimiavaruus ja salaisuudet
description: Luo nimiavaruus ja Ayakaleaf Pron tarvitsemat salaisuudet.
icon: key
---

Kaikki sijoitetaan nimiavaruuteen `overleaf`:

```bash
kubectl create namespace overleaf
```

Ayakaleaf Pro lukee salaisuutensa ympäristömuuttujista. Luo ne kerran ja säilytä ne Secretissä:

```bash wrap
HISTORY=$(openssl rand -hex 32)
kubectl -n overleaf create secret generic overleaf-secrets \
  --from-literal=OVERLEAF_INVITE_TOKEN_SECRET="$(openssl rand -base64 32)" \
  --from-literal=OVERLEAF_SESSION_SECRET="$(openssl rand -hex 32)" \
  --from-literal=WEB_API_PASSWORD="$(openssl rand -hex 32)" \
  --from-literal=STAGING_PASSWORD="$HISTORY" \
  --from-literal=V1_HISTORY_PASSWORD="$HISTORY" \
  --from-literal=CRYPTO_RANDOM="$(openssl rand -hex 32)" \
  --from-literal=OT_JWT_AUTH_KEY="$(openssl rand -hex 32)"
```

| Salaisuus                                         | Miksi                                                                                                                                                  |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_INVITE_TOKEN_SECRET`                 | Pakollinen. Ilman sitä podi pysähtyy virheeseen ”Missing required secrets”. Sen muuttaminen mitätöi odottavat projektikutsut.                                 |
| `OVERLEAF_SESSION_SECRET`                      | Allekirjoittaa istuntoevästeet. Ilman sitä jokainen podin uudelleenkäynnistys kirjaa kaikki ulos.                                                                 |
| `WEB_API_PASSWORD`, `CRYPTO_RANDOM`, `OT_JWT_AUTH_KEY` | Sisäisiä salaisuuksia. Kontti luo ne jokaisella käynnistyksellä, jos ne puuttuvat; useammalla kuin yhdellä replikalla kaikkien replikoiden on jaettava ne. |
| `STAGING_PASSWORD` ja `V1_HISTORY_PASSWORD`   | Sisäinen historiasalaisuus; molemmilla on oltava **sama** arvo.                                                                                           |

<Warning>

Varmuuskopioi Secret (`kubectl -n overleaf get secret overleaf-secrets -o yaml`) tietojesi kanssa. Ominaisuudet, jotka salaavat tunnuksia MongoDB:ssä, tarvitsevat myös omat salausavainsalasanansa tähän Secretiin, esimerkiksi `GITHUB_TOKEN_CIPHER_PASSWORD` [GitHub-synkronointia](/fi/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation) varten.

</Warning>
