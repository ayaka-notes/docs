Helpoin tapa kokeilla Ayakaleaf Prota on käyttää GitHub Codespacea, jossa kaikki ympäristömuuttujat on valmiiksi määritetty, joten voit käyttää sitä heti.

<Warning>

Kun ajat Docker-kontteja GitHub Codespacesissa, Codespace ei sammu automaattisesti, vaan siitä **laskutetaan** edelleen. GitHub Codespacesin laskutussäännöt löydät sivulta [github codespaces billing rules](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces).

Voit hallita GitHub Codespacejasi osoitteessa [https://github.com/codespaces](https://github.com/codespaces). Kun et enää tarvitse Codespacea, poista se ajoissa.

</Warning>

Olemme **valmiiksi määrittäneet** seuraavat ominaisuudet:

* [x] Hiekkalaatikossa tehtävä LaTeX-kääntäminen TeXLive **Basic** -versiolla (2024–2026)
* [x] Pandoc-tuonti/-vienti (SaaS-alustan ominaisuus)
* [x] Python-skriptien suoritus (SaaS-alustan ominaisuus)
* [x] Git-Bridge-tuki (Server Pron ominaisuus)
* [x] Edistynyt lähdeviitehaku (SaaS-alustan ominaisuus)
* [x] Ylläpitopaneeli (kaikkien käyttäjien/projektien hallinta)
* [x] Muutosten seuranta (arviointi- ja kommenttipaneelilla)
* [x] Täysi projektihistoria (palautus ja lataus)
* [x] Symbolipaletti (Server Pron/SaaS-alustan ominaisuus)

<Warning>

Tavalliset GitHub Codespacet tarjoavat 32 Gt tallennustilaa. Se ei riitä `texlive-full`-asennuksellemme. Jos haluat kokeilla täyttä imagea, lähetä GitHubin tukeen pyyntö Codespacesta, jossa on suuret ajoympäristöt (8+ ydintä).

</Warning>

GitHub Sync, LDAP, OAuth, SSO, Zotero-integraatio ja muut ominaisuudet ovat tässä kokeiluympäristössä _**määrittämättä**_. Katso [Toolkit-asetuksista](/fi/on-premises/configuration/overleaf-toolkit/toolkit-settings) lisätietoja näiden ominaisuuksien määrittämisestä omaan käyttöönottoosi.

<Steps>
<Step title="Luo GitHub Codespace">
Napsauta seuraavaa painiketta luodaksesi GitHub Codespacen. Palvelinkokoonpanoksi **2 ydintä ja 8 Gt RAM-muistia** riittää yleensä testikäyttöön. Jos aiot käyttää [**TeX Live Full**](https://github.com/ayaka-notes/texlive-full) -imagea, suosittelemme valitsemaan kokoonpanon, jossa on **8 ydintä ja 64 Gt**.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/ayakaleaf-pro-playground)
</Step>

<Step title="Alusta Overleaf-instanssi">
Kun Codespace on valmis, aja seuraava komento bash-komentotulkissa alustaaksesi Overleaf-instanssin.

```bash title="bash"

```

#### TeXLive Full -imagen käyttäminen

Jos käytössäsi on 8 ytimen/64 Gt:n GitHub Codespace, voit käyttää tässä kokeiluympäristössä TeXLive Full -imagea. Muuta seuraavat ympäristömuuttujat tiedostossa `toolkit/config/variables.env`, jotta TeXLive Basic -imagen sijaan käytetään TeXLive Full -imagea.

```dotenv wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1, ghcr.io/ayaka-notes/texlive-full:2024.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025, Texlive 2024
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```

Ympäristömuuttujien muuttamisen jälkeen Toolkit on käynnistettävä uudelleen, jotta muutokset tulevat voimaan. Voit käynnistää Toolkitin uudelleen seuraavalla komennolla.

```bash
cd toolkit && bin/up -d
```
