<Danger>

Seuraavat ohjeet koskevat **vain** **Community Edition** -asennuksia. Suosittelemme vahvasti, että Ayakaleaf Pro -käyttäjämme ottavat käyttöön [hiekkalaatikoidut käännökset (Sandboxed Compiles)](/fi/on-premises/configuration/overleaf-toolkit/sandboxed-compiles), koska ne antavat käyttäjille pääsyn lähes samoihin TeX Live -imageihin, joita käytetään [overleaf.com](https://www.overleaf.com)-palvelussa, ja eristävät projektien käännökset toisistaan tietoturvan parantamiseksi.

</Danger>

Kaistanleveyden säästämiseksi sekä Overleaf Community Edition- että Ayakaleaf Pro -imageissa on vain [TeX Liven](https://www.tug.org/texlive/) minimaalinen asennus. Voit asentaa lisää paketteja tai päivittää täydelliseen TeX Live -asennukseen käyttämällä [tlmgr](https://www.tug.org/texlive/tlmgr.html)-komentoa `sharelatex`-kontissa.

#### Pääsy sharelatex-kontin sisälle

Käynnistä komentotulkki `sharelatex`-kontin sisällä suorittamalla

```bash
bin/shell
```

Saat kehotteen, joka näyttää tältä:

```bash
root@309b192d4030:/#
```

Seuraavissa ohjeissa oletamme, että olet kontin sisällä.

#### Nykyisen TeX Live -version selvittäminen

TeX Live julkaistaan joka vuosi huhtikuun tienoilla. `tlmgr`:n käyttövaiheet vaihtelevat sen mukaan, käytätkö nykyistä vai vanhempaa julkaisua. Voit tarkistaa käyttämäsi TeX Live -version komennolla `tlmgr --version`. Esimerkiksi tämä asennus käyttää TeX Live 2021:tä:

```bash
# tlmgr --version
tlmgr revision 59291 (2021-05-21 05:14:40 +0200)
tlmgr using installation: /usr/local/texlive/2021
TeX Live (https://tug.org/texlive) version 2021
```

<Info>

TeX Liven nykyinen julkaisu löytyy [TeX Liven kotisivulta](https://www.tug.org/texlive/).

</Info>

Jos käytät vanhempaa TeX Live -versiota, sinulla on kaksi vaihtoehtoa. Overleafin Docker-imagesta julkaistaan yleensä uusi versio pian TeX Live -julkaisun jälkeen. Voit joko odottaa sitä ja päivittää käyttöönottosi `bin/upgrade`-skriptillä, tai jos haluat pitää vanhemman TeX Live -julkaisun, sinun on ensin määritettävä `tlmgr` käyttämään historiallista repositoriota. Ohjeet tähän löydät [täältä](https://www.tug.org/texlive/acquire.html#past).

#### Pakettien asentaminen

Asenna täydellinen TeX Live -asennus suorittamalla tämä komento `sharelatex`-kontin sisällä:

```text
tlmgr install scheme-full
```

Voit myös asentaa yksittäisiä paketteja manuaalisesti:

```bash
tlmgr install tikzlings tikzmarmots tikzducks
```

<Warning>

Julkaisusta `3.3.0` alkaen `tlmgr path add` on taas **pakko** suorittaa jokaisen `tlmgr install` -käyttökerran jälkeen, jotta kaikki binäärit linkitetään symbolisesti oikein järjestelmäpolkuun.

</Warning>

Komentoja on saatavilla paljon enemmän. Lisätietoja saat komennolla:

```text
tlmgr help
```

Kun olet valmis, kirjoita `exit` tai paina Control-D poistuaksesi komentotulkista.

#### Muutosten tallentaminen

Juuri tekemäsi muutokset ovat muuttaneet `sharelatex`-konttia, mutta ne ovat väliaikaisia -- ne menetetään, jos Docker Compose luo kontin uudelleen, esimerkiksi konfiguraation päivittämisen yhteydessä.

Tehdäksesi niistä pysyviä tallenna muutokset uuteen Docker-imageen komennolla `docker commit`:

```bash
cat config/version #5.2.1
docker commit sharelatex sharelatex/sharelatex:5.2.1-with-texlive-full
echo 5.2.1-with-texlive-full > config/version
```

Kun olet tallentanut muutokset, päivitä `config/version` vastaavasti. Suorita sitten `bin/up` luodaksesi `sharelatex`-kontin uudelleen.

<Danger>

Sinun on toistettava nämä vaiheet aina, kun [päivität](https://github.com/overleaf/toolkit/blob/master/doc/upgrading.md) uuteen Overleaf-versioon.

</Danger>
