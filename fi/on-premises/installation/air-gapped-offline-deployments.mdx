---
title: Eristetyt/offline-käyttöönotot
description: Ota Ayakaleaf Pro käyttöön offline-tilassa viemällä, siirtämällä ja lataamalla Docker-imaget.
icon: block-brick
---

Yleisesti ottaen emme suosittele Ayakaleaf Pron käyttöönottoa offline-ympäristössä, koska monet sen ominaisuuksista, kuten GitHub Sync ja Zotero-integraatio, vaativat internetyhteyden.

Jos haluat työskennellä offline-tilassa, `ghcr.io`-rekisteriin ei välttämättä aina saada yhteyttä tarvittavien `ayakaleaf-pro`- ja TeX Live -imagejen noutamiseksi. Tämä ei ole ongelma, sillä Docker tarjoaa työkaluja imagejen vientiin ja tuontiin, jotka auttavat offline-/eristetyssä käyttöönotossa.

Yleisellä tasolla lataat tarvittavat imaget laitteella, jolla on internetyhteys, viet ne siirrettävälle tallennusvälineelle (tai siirrät ne SCP:n/Rsyncin avulla) ja tuot ne eristetylle palvelimelle.

Tätä varten sinun on suoritettava seuraavat vaiheet:

* Nouda kaikki tarvittavat imaget ( `overleaf-pro`, `git-bridge`, `mongo`, `redis` + kaikki tarvittavat [TeX Live -imaget](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles#available-tex-live-images) käytettäväksi [Sandboxed Compiles](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles) -toiminnon kanssa) koneella, jolla on internetyhteys
  * `docker pull ghcr.io/ayaka-notes/overleaf-pro:6.3.0`
  * `docker pull ghcr.io/ayaka-notes/overleaf-pro/git-bridge:6.3.0` (tagin on oltava sama kuin `overleaf-pro`-imagella)
  * `docker pull mongo:8.0` (vaihda todelliseen versioon)
  * `docker pull redis:7.4` (vaihda todelliseen versioon)
  * `docker pull ghcr.io/ayaka-notes/texlive-full:2024.1` (vaihda todelliseen versioon)
* Jokainen noudettu image on tämän jälkeen vietävä .tar-tiedostoon. Esimerkiksi `docker save ghcr.io/ayaka-notes/overleaf-pro:6.3.0 > overleaf-pro:6.3.0.tar`
* Siirrä `.tar`-tiedostot haluamallasi tavalla internetyhteydellä varustetulta koneelta offline-/eristetylle palvelimelle
* Lataa jokaisesta .tar-tiedostosta image `docker load` -komennolla. Esimerkiksi `docker load < overleaf-pro:6.3.0.tar`
* Aja lopuksi `docker images` -komento tarkistaaksesi, että imagejen lataus onnistui ja että ne ovat käytettävissä

<Danger>

Oletusarvoisesti, kun ajat `bin/up`-komennon, Toolkit yrittää automaattisesti noutaa jokaisen `config/variables.env`-tiedoston `ALL_TEX_LIVE_DOCKER_IMAGES`-muuttujassa määritetyn TeX Live -imagen. Koska käyttöönottosi on eristetty, tämä epäonnistuu – voit estää sen asettamalla `SIBLING_CONTAINERS_PULL=false` tiedostossa `config/overleaf.rc`.

</Danger>
