### Toolkitin lataaminen

Toolkit on yhteensopiva sekä Server CE:n että Ayakaleaf Pron kanssa, ja se on suositeltu asennustapa. Toolkitin avulla pääset helposti alkuun Server CE:n kanssa ja voit tarvittaessa päivittää saumattomasti Ayakaleaf Pro -versioon.

<Info>

[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) on muokattu käyttämään overleaf-pro-imagea suoraan ghcr:stä, ja TeX Liven tarjoaa ayaka-notes. Vaihtoehtoisesti voit ladata virallisen overleaf-toolkitin.

</Info>

<Steps>
<Step title="Kloonaa Overleaf Toolkit -repositorio">
Asentaaksesi toolkitin siirry haluamaasi asennuspolkuun ja kloonaa Overleaf Toolkit (@Ayaka-notes) -GitHub-repositorio tällä komennolla:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
# official toolkit (Not Recommended)
# git clone https://github.com/overleaf/toolkit.git ./overleaf-toolkit
```

<Info>

Mahdollisten käyttöoikeusongelmien välttämiseksi suosittelemme asentamaan Toolkitin käyttäjäsi `$HOME`-hakemistoon.

</Info>
</Step>

<Step title="Siirry toolkit-hakemistoon">
Odota, että kloonaus on valmis, ja siirry sitten juuri luotuun `overleaf-toolkit`-hakemistoon:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
