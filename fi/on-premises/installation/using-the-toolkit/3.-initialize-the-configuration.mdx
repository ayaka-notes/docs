### Konfiguraation alustaminen

Alustetaan uuden palvelimen konfiguraatiotiedostot järkevillä oletusarvoilla suorittamalla mukana tuleva `bin/init`-skripti.

```text title="Run initialization"
bin/init
```

Tämä skripti **ei** korvaa olemassa olevia konfiguraatiotiedostoja.

Tarkistetaan nyt `config/`-hakemiston sisältö `ls`-komennolla:

```text title="List the config directory"
ls config
```

Jos kaikki alustettiin onnistuneesti, sinun pitäisi nähdä kolme konfiguraatiotiedostoa: `overleaf.rc`, `variables.env` ja `version`. Nämä ovat palvelimen pääkonfiguraatiotiedostot, joiden avulla voit mukauttaa palvelimesi toimintaa ja sitä, miten käyttäjäsi käyttävät instanssiasi.

| Nimi            | Kuvaus                                                  |
| --------------- | ------------------------------------------------------- |
| `overleaf.rc`   | Ylimmän tason pääkonfiguraatiotiedosto, jota Toolkitin skriptit lukevat. Se määrittää, miten kontit ajetaan, esimerkiksi kuunteluosoitteen ja portin (`OVERLEAF_LISTEN_IP`, oletus `127.0.0.1`, ja `OVERLEAF_PORT`, oletus `80`). |
| `variables.env` | Docker-konttiin ladattavat ympäristömuuttujat. Ne määrittävät, miten Overleaf toimii, esimerkiksi `OVERLEAF_SITE_URL`. |
| `version`       | Käytettävän Docker-imagen versio.                       |

<Info>

Toistaiseksi riittää tietää, että nämä tiedostot ovat olemassa ja mistä ne löytyvät. Myöhemmin dokumentaatiossa käymme jokaisen tiedoston läpi tarkemmin ja selitämme, miten voit mukauttaa instanssiasi niiden avulla. Jos haluat hypätä eteenpäin, löydät näiden konfiguraatiotiedostojen täydellisen erittelyn [Tiedostot ja sijainnit -sivulta](/fi/on-premises/configuration/overleaf-toolkit/files-and-locations).

</Info>
