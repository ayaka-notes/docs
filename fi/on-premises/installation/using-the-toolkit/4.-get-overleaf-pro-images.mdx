---
title: 4. Hanki Ayakaleaf Pro -imaget
icon: split
---

Ayakaleaf Pro jaetaan Docker-imagena [ghcr](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/)-rekisterissä, ja se on **vapaasti kaikkien saatavilla**. Tarjoamme imaget sekä amd64- että arm64-arkkitehtuureille. Kun haet imagen, oikea image valitaan automaattisesti järjestelmäsi arkkitehtuurin perusteella.

#### Ayaka-notes Toolkitin käyttäjät

Jos käytät [ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)-työkalupakkia, Ayakaleaf Prota voi käyttää suorana korvaajana Community Editionille, joten voit hyödyntää olemassa olevia asetuksiasi ja mukautuksiasi. Ota Pro käyttöön Toolkitissa muokkaamalla tiedostoa `config/overleaf.rc` ja asettamalla ympäristömuuttuja `SERVER_PRO`:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

Kun seuraavan kerran suoritat `bin/up`, Toolkit lataa ja ottaa käyttöön Ayakaleaf Pro -imagen automaattisesti.

#### Virallisen Toolkitin käyttäjät

Jos käytät [overleaf/toolkit](https://github.com/overleaf/toolkit)-työkalupakkia, hae Pro-image suorittamalla seuraava komento:

```bash title="Pull Docker Images"
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Lisää sitten hakemistoon `overleaf-toolkit/config` tiedosto nimeltä `docker-compose.override.yml`, jonka sisältö on seuraava:

```yml title="docker-compose.override.yml"
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

Kun seuraavan kerran suoritat `bin/up`, Toolkit lataa ja ottaa käyttöön Ayakaleaf Pro -imagen automaattisesti.
