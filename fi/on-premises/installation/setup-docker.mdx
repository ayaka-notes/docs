Overleaf toimii Dockerin päällä. Sinun on asennettava:

* Docker Engine (Docker CE)
* Docker Compose -liitännäinen (`docker compose`, v2)

Nämä vaiheet on tarkoitettu tuoreelle Ubuntu LTS -versiolle (20.04/22.04/24.04).

<Warning>

Vältä `docker.io`-paketin asentamista Ubuntun oletusarvoisesta apt-repositoriosta.\
Käytä Dockerin virallista repositoriota, jotta saat tuoreen Docker-version ja `docker compose` -liitännäisen.

</Warning>

Virallinen dokumentaatio löytyy osoitteesta: [https://docs.docker.com/engine/install/ubuntu/](https://docs.docker.com/engine/install/ubuntu/).

<Steps>
<Step title="1) Poista vanhat tai ristiriitaiset paketit (jos olemassa)">
Jos Docker on aiemmin asennettu jostain muusta lähteestä, poista se ensin:

```bash wrap
sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-compose-v2 docker-doc podman-docker containerd runc | cut -f1)
```

Komento on turvallinen, vaikka osa paketeista ei olisi asennettuna.
</Step>

<Step title="2) Lisää Dockerin virallinen apt-repositorio">
Asenna esivaatimukset:

```bash
sudo apt update
sudo apt install -y ca-certificates curl
```

Lisää Dockerin GPG-avain:

```bash wrap
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```

Lisää repositorio:

```bash wrap
# Add the repository to Apt sources:
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Signed-By: /etc/apt/keyrings/docker.asc
EOF

sudo apt update
```
</Step>

<Step title="3) Asenna Docker Engine ja Compose-liitännäinen">
Asenna Docker ja Compose-liitännäinen:

```bash wrap
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

Käynnistä Docker automaattisesti järjestelmän käynnistyessä:

```bash
sudo systemctl enable --now docker
```
</Step>

<Step title="4) Tarkista asennus">
Näiden komentojen pitäisi toimia ilman virheitä:

```bash
docker --version
docker compose version
sudo docker run --rm hello-world
docker ps
```
</Step>

<Step title="5) (Valinnainen) Aja Dockeria ilman sudoa">
Lisää käyttäjäsi `docker`-ryhmään:

```bash
sudo usermod -aG docker $USER
```

**Kirjaudu sitten ulos ja takaisin sisään** tai suorita:

```bash
newgrp docker
```

Nyt tämän pitäisi toimia ilman `sudo`a:

```bash
docker ps
```

<Danger>

`docker`-ryhmällä on isäntäkoneella root-oikeuksia vastaava pääsy.\
Tämä on odotettua tyypillisissä Overleaf-asennuksissa, ja se on erityisen merkityksellistä, jos otat Sandboxed Compiles -ominaisuuden käyttöön.

</Danger>
</Step>
</Steps>
