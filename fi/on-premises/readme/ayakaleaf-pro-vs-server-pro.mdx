---
title: Overleaf Server Pro vs. Ayakaleaf Pro
description: Overleaf Server Pro ja Ayakaleaf Pro Edition ovat molemmat paikallisesti asennettavia Overleaf-versioita. Mitä eroja niillä on?
icon: scale-balanced
---

<Info>

Ayakaleaf Pro on Overleaf Community Editionin laajennettu toteutus, joka tarjoaa kaikki Server Pron premium-ominaisuudet _**ilmaiseksi**_. Toisin kuin osoitteessa [https://www.overleaf.com/](https://www.overleaf.com/) saatavilla olevassa Overleaf Commonissa, meillä ei ole käännösaikarajoituksia eikä käyttäjämäärään liittyviä lisenssivaatimuksia, ja voit isännöidä omat tietosi täysin itse, mikä takaa ehdottoman tietoturvan.

Overleaf Server Pro on kaupallinen, itse isännöitävä Overleaf-käyttöönotto, jolla on virallinen tuki. Lisätietoja Server Prosta löydät sivulta [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud).

</Info>

<Warning>

Overleaf Community Edition on tarkoitettu käytettäväksi ympäristöissä, joissa **kaikkiin** käyttäjiin luotetaan. Community Edition **ei** sovellu tilanteisiin, joissa käyttäjät on eristettävä toisistaan, koska Sandbox Compiles -ominaisuus ei ole käytettävissä.

Ilman hiekkalaatikkoa LaTeX-käännökset suoritetaan samoilla oikeuksilla kuin kontti, jolloin niillä on pääsy kontin tiedostojärjestelmään, verkkoon ja ympäristömuuttujiin. Tämä aiheuttaa tietovuodon tai järjestelmän vaarantumisen riskin. Hiekkalaatikottomia käännöksiä tulisi käyttää vain täysin luotetuissa ympäristöissä; monen käyttäjän tai tuotantokäytön asennuksissa Sandbox Compiles -ominaisuutta suositellaan vahvasti.

Lisätietoja Sandbox Compiles -ominaisuudesta löydät [dokumentaatiostamme](/fi/on-premises/configuration/overleaf-toolkit/sandboxed-compiles).

</Warning>

### Yhteisön tuki

Itse isännöityä Overleaf-instanssia käyttäville tukea tarjoaa yhteisö GitHubin [Issues](https://github.com/ayaka-notes/overleaf-pro/issues)-osion kautta.

Pysyäksesi tuetulla versiolla voit tarkistaa käyttämäsi Overleaf-version vertaamalla alla olevan komennon tulostetta julkaisutiedoissa julkaistuihin Image ID -tunnisteisiin.

```bash
docker inspect --format '{{.Image}}' sharelatex | awk -F: '{print substr($2, 1, 12)}'
```
