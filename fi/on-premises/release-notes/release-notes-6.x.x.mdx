## Ayakaleaf Pro 6.3.0

<strong>Julkaisupäivä:</strong> 2026.10.03 (uudelleenjulkaisu; alun perin julkaistu 2026.09.24)

Katso: [https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.3.0](https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.3.0)

<Warning>

Ayakaleaf Pro 6.3.0 julkaistiin alun perin 24. syyskuuta 2026. Tämä uudelleenjulkaisu korjaa ylävirran päivitysten aiheuttamat ongelmat AI Assistant-, Zotero- ja Mendeley-integraatioissa.

Aiemmin julkaistu versio ei vahingoita tietojasi. Nouda uusin `6.3.0`-image ja päivitä käyttöönottosi. <strong>Olemassa olevissa asennuksissa, joissa on Zoteroon tai Mendeleyhin linkitettyjä lähdeluettelotiedostoja, on myös ajettava alla oleva siirto.</strong> Uudet asennukset eivät tarvitse tätä siirtoa.

</Warning>

<Accordion title="Zotero-/Mendeley-siirto olemassa oleville asennuksille">

Kun päivität uudelleenjulkaistuun 6.3.0-imageen, siirrä olemassa olevien Zoteroon/Mendeleyhin linkitettyjen lähdeluettelotiedostojen metatiedot alla olevalla skriptillä. Tämä siirto liittyy korjaukseen `12031b8dfd`.

Se nimeää `zoteroGroupId` / `mendeleyGroupId` uudelleen muotoon `group_id`, nimeää `importedByUserId` uudelleen muotoon `importer_id` ja poistaa kentän `importedByName`.

Varmuuskopioi MongoDB ja pysäytä sovellus ennen siirron ajamista. Pidä MongoDB käynnissä. Avaa sen komentotulkki (korvaa `mongo` konttisi nimellä):

```bash
docker exec -it mongo mongosh
```

Aja seuraava `mongosh`-komentotulkissa (korvaa `sharelatex` tietokantasi nimellä):

```javascript
use sharelatex

(async () => {
  let updated = 0
  await db.projects.find({}, { rootFolder: 1 }).forEach(async project => {
    const changes = {}
    function visit(folders, path) {
      for (const [i, folder] of (folders || []).entries()) {
        const folderPath = `${path}.${i}`
        for (const [j, file] of (folder.fileRefs || []).entries()) {
          const data = { ...file.linkedFileData }
          if (!["zotero", "mendeley"].includes(data.provider)) continue
          const groupKey = `${data.provider}GroupId`
          if (![groupKey, "importedByUserId", "importedByName"].some(key => key in data)) continue
          for (const [oldKey, newKey] of [[groupKey, "group_id"], ["importedByUserId", "importer_id"]]) {
            if (data[oldKey] != null && data[oldKey] !== "") {
              const value = String(data[oldKey])
              if (newKey in data && data[newKey] !== value) {
                throw new Error(`Conflicting ${newKey}: project ${project._id}, file ${file._id}`)
              }
              data[newKey] = value
            }
            delete data[oldKey]
          }
          delete data.importedByName
          changes[`${folderPath}.fileRefs.${j}.linkedFileData`] = data
        }
        visit(folder.folders, `${folderPath}.folders`)
      }
    }
    visit(project.rootFolder, "rootFolder")
    if (!Object.keys(changes).length) return
    const result = await db.projects.updateOne(
      { _id: project._id, rootFolder: { $eq: project.rootFolder } },
      { $set: changes }
    )
    if (!result.matchedCount) throw new Error(`Project changed during migration: ${project._id}`)
    updated += result.modifiedCount
  })
  print(`Updated ${updated} project(s).`)
})()
```

Skripti käsittelee myös sisäkkäiset kansiot ja muuttaa vain Zoteron/Mendeleyn metatietoja. Sen voi turvallisesti ajaa uudelleen: valmis siirto raportoi seuraavalla ajokerralla `Updated 0 project(s).`. Jos se pysähtyy ristiriitaan, tarkista raportoitu projekti/tiedosto; aiemmat projektit on ehkä jo siirretty.

Käynnistä päivitetty sovellus, lataa editori uudelleen ja päivitä olemassa oleva lähdeluettelotiedosto sen alkuperäisenä tuojana. Historiallisia tilannevedoksia ei kirjoiteta uudelleen. Palataksesi vanhaan sovellukseen palauta MongoDB-varmuuskopio.

Olemme erittäin ylpeitä voidessamme julkistaa Overleaf Pro 6.3.0:n, yhteisön tehokkaimman ja monipuolisimman verkkopohjaisen LaTeX-editorin. Koska olemme aina keskittyneet käyttäjiemme kokemuksen parantamiseen, tämä julkaisu tuo valtavia muutoksia ja upeita ominaisuuksia, joista tulet varmasti pitämään, mukaan lukien tekoälyavustajan ja kolmansien osapuolten viitepalveluiden integraation.

### Muutokset

* AI Chat Assistant: Keskustele tekoälymallin kanssa oman palveluntarjoajasi kautta suoraan editorissasi.
* LaTeX Error Assistant: Saat tekoälyn ehdottamia korjauksia LaTeX-käännösvirheisiin.
* Mendeley-integraatio: Tuo viitteitä Mendeleystä samaan tapaan kuin Zoterosta.
* Open in Overleaf API: Lisätty API sisällön avaamiseen Overleafissa.
* Mallivalikoima: Lisätty palvelinpuolen sivutus, haku ja lajittelu, joten suurten valikoimien ei enää tarvitse ladata jokaista mallia selaimeen.
* Käännökset: Päivitetty 6.3.0:n käännöspaikat, mukaan lukien uudet käyttöliittymätekstit kaikilla tuetuilla kielillä.
* Ylävirran Overleaf 6.3.0: Sisältää välilehdillä tapahtuvan tiedostojen muokkauksen, erilliset ylätunnisteen logot vaalealle ja tummalle teemalle sekä riippuvuuksien ja perusimagen päivitykset.
* Lisätty `OVERLEAF_HEADER_IMAGE_URL_LIGHT` ja `OVERLEAF_HEADER_IMAGE_URL_DARK` erillisten ylätunnisteen logokuvien tukemiseksi vaalealle ja tummalle teemalle.
* Tiedostot voidaan nyt avata editorissa eri välilehdille.
* Lisätty tuki määritettäville HTTP(S)-välityspalvelimille, mukaan lukien paikallisesti ylläpidetyt välityspalvelimet, muuttujalla `OVERLEAF_LINKED_URL_OUTBOUND_PROXY`, jota käyttää myös Open in Overleaf API.

#### Ominaisuus 04: Mallien sivutus

Valikoima sivuttaa, lajittelee ja hakee nyt MongoDB:ssä. Se toimii ilman valmisteluja; jos malleja on tuhansia, voit silti lisätä nämä indeksit pitääksesi sen nopeana (turvallista ajaa uudelleen, `mongo`/`sharelatex` = konttisi ja tietokantasi nimet):

```bash
docker exec mongo mongosh sharelatex --quiet --eval '
db.templates.createIndex({category:1,lastUpdated:-1},{name:"category_1_lastUpdated_-1",background:true});
db.templates.createIndex({lastUpdated:-1},{name:"lastUpdated_-1",background:true});
db.templates.createIndex({category:1,name:1},{name:"category_1_name_1_ci",collation:{locale:"en",strength:2},background:true});
db.templates.createIndex({name:1},{name:"name_1_ci",collation:{locale:"en",strength:2},background:true});
'
```

Säilytä kahden `*_ci`-indeksin `collation` sellaisenaan – valikoima tekee kyselyt samalla collationilla, ja MongoDB käyttää vain vastaavaa indeksiä.

## Ayakaleaf Pro 6.2.2

<strong>Julkaisupäivä:</strong> 2026.07.23

Katso: [https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.2](https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.2)

### Muutokset

Taaksepäin siirretty ylävirran Overleafin `6.2.2`-versiossa julkaistut viralliset pikakorjaukset (`6.2.1`:n päälle):

* Projektikutsun token-salaisuus ei enää vuoda lokeihin. Kutsutokenien salaaja kirjasi omat määrityksensä jokaisella salaus- ja purkukerralla, mukaan lukien `OVERLEAF_INVITE_TOKEN_SECRET`-muuttujasta johdetut salasanat.
* Lähtevä sähköposti siirretty tukensa päättäneestä AWS SES v1 -asiakkaasta SESv2:een. `ses`-sähköpostiajurilla määritetyt instanssit eivät välttämättä pystyneet lähettämään sähköpostia lainkaan; lähetys kulkee nyt `SESv2Client`-asiakkaan kautta.
* Projektin jakamisen pudotusvalikon ryhmämerkinnät on asetettu uuden `group-link-sharing`-ominaisuuslipun taakse, joten ryhmälinkkijakoa ei enää tarjota instansseissa, joissa se ei ole sovellettavissa.
* Korjattu projektin jakamisikkuna yhteistyökumppaneille. Sen avaaminen muuna kuin omistajana tai `sharing-updates`-kulun ollessa pois käytöstä lähetti pyynnön, joka epäonnistui aina ja näytti "something went wrong" -virheen.
* Lisätty document-updateriin `scripts/flush_docs_with_pending_updates.js`, ylläpitoskripti, joka palauttaa asiakirjat, joiden `PendingUpdates`-jono on jäänyt jumiin Redisiin sen jälkeen, kun niiden projekti on tyhjennetty tai poistettu pysyvästi. Tukee valintaa `--dry-run` ja `--estimated-docs`-turvatarkistusta.
* Päivitetyt riippuvuudet: `multer` 2.2.0, `form-data` 2.5.6, `protobufjs` 7.6.3, `@grpc/grpc-js` 1.14.4.

Tämä julkaisu sisältää myös seuraavat Ayakaleaf Pron korjaukset ja parannukset:

* Lisätty täydelliset käännökset 16 uudelle kielelle (cs, da, de, es, fi, fr, it, ja, ko, nl, no, pl, pt, ru, sv, tr), mikä korjaa kääntämättömät merkkijonot, kuten salasanan palautussivun. Korjaa [#38](https://github.com/ayaka-notes/ayakaleaf-pro/issues/38).
* Korjattu hallintapaneelin "show N more projects" -painikkeen kohdemäärä, joka näytti väärän luvun, koska monikon paikkamerkkiä ei välitetty oikein.
* Korjattu GitHub-viennin validointivirheet, jotka näytetään nyt staattisten i18n-avainten kautta raakaviestien sijaan, ja poistettu virheavaimet, joita GitHub Sync -ikkuna ei enää käytä.

## Ayakaleaf Pro 6.2.0

<strong>Julkaisupäivä:</strong> 2026.07.10

Katso: [https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.0](https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.0)

Olemme ylpeitä voidessamme julkistaa Overleaf Pro 6.2.0:n, yhteisön tehokkaimman ja monipuolisimman verkkopohjaisen LaTeX-editorin. Erityiskiitokset yu-i-i:lle ja davrotille arvokkaista panoksista. He paransivat GitHub Synciä ja toivat mukaan edistyneen viitehaun sekä Zotero-integraation.

### Huomautukset

<Warning>

* Käyttöön on otettu uusi pakollinen ympäristömuuttuja `OVERLEAF_INVITE_TOKEN_SECRET`. Sinun on luotava se komennolla `openssl rand -base64 32`. Jos sitä ei ole määritetty, Overleaf-instanssisi ei käynnisty.
* Jos otat GitHub Syncin käyttöön, sinun on määritettävä ympäristömuuttuja `GITHUB_TOKEN_CIPHER_PASSWORD`. Tätä muuttujaa tarvitaan GitHub-käyttöoikeustunnusten turvalliseen salaamiseen. Ilman sitä Overleaf-instanssisi ei käynnisty.

</Warning>

* Lisätty uusi ympäristömuuttuja `DEFAULT_LATEX_COMPILER` uusien projektien oletuskääntäjän asettamiseen (joko `pdflatex`, `latex`, `xelatex` tai `lualatex`).
* Uudistettu editori on nyt ainoa käytettävissä oleva vaihtoehto.

### Muutokset

Tämä julkaisu sisältää seuraavat parannukset ja uudet ominaisuudet.

* `MAX_UPLOAD_SIZE` on nyt määritettävissä sen sijaan, että se olisi rajattu **50 Mt:hen**.
* Korjattu kontin uudelleenkäynnistyssilmukka, kun hiekkalaatikoidut käännökset olivat pois käytöstä.
* OAuth2:n PAT-tunnusten poisto on rajattu omistajaan.
* Korjattu LDAP-tuonnin ongelma.

Ominaisuuksia ovat:

* Lisätty selainpohjainen Python-suoritusympäristö.
* Lisätty Pandoc-tuki Markdown-, DOCX- ja muiden muotojen tuontiin ja vientiin.
* Lisätty GitHub Sync.
* Lisätty täydelliset kiinankieliset käännökset.
* Lisätty Zotero-integraatio.
* Lisätty `DEFAULT_LATEX_COMPILER`.

## Ayakaleaf Pro 6.0.0

Tässä julkaisussa olemme ottaneet käyttöön Overleafin Docker-imagen ARM-arkkitehtuurille. Voit kokeilla sitä, jos sinulla on Mac tai ARM-pohjainen palvelin, mutta jotkin ominaisuudet eivät välttämättä toimi kunnolla (ei vielä testattu).

### Docker-image

Docker-image löytyy täältä: [https://github.com/ayaka-notes/overleaf-pro/pkgs/container/overleaf-pro](https://github.com/ayaka-notes/overleaf-pro/pkgs/container/overleaf-pro)

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:6.0.0
```

### Binääritiedostojen siirto

Tämä uusi julkaisu puolittaa binääritiedostojen tallennustilan käytön.

Versioon `5.5` sisältyy online-siirto, joka mahdollistaa mahdollisimman lyhyen käyttökatkon päivityksen yhteydessä. Ennen päivittämistä Server Pron versioon `v6` varmista, että käytössäsi on jo Server Pron uusin `v5.5`-versio ([Release Notes 5.x.x](https://docs.overleaf.com/on-premises/release-notes/release-notes-5.x.x)) ja että olet ajanut siirron.

[Katso täydelliset siirto-ohjeet](https://docs.overleaf.com/on-premises/release-notes/release-notes-5.x.x/binary-files-migration).

### MongoDB:n päivitys versioon v8

Tämä julkaisu nostaa MongoDB:n vähimmäisversioksi `8.0`.

Jos käytät tällä hetkellä MongoDB:n versiota `v6` tai vanhempaa, sinun on päivitettävä yksi pääversio kerrallaan (`v6 → v7 → v8`).

<Warning>

Varmista, että sinulla on [tietokannan](https://docs.overleaf.com/on-premises/maintenance/data-and-backups) varmuuskopio **ennen** päivittämistä. Jos joudut palaamaan aiempaan versioon, sinun on palautettava tietokannan varmuuskopio.

</Warning>

Ohjeet MongoDB:n päivittämiseen `v6 → v7 → v8` löydät vaiheittaisesta oppaastamme [täältä](https://docs.overleaf.com/on-premises/maintenance/updating-mongodb#example-upgrading-mongodb-from-6.0-to-7.0-toolkit-users).

### Redisin päivitys versioon v7.4

Tämä julkaisu nostaa myös Redisin vähimmäisversioksi `7.4`.

Päivitä `config/overleaf.rc`-tiedoston `REDIS_IMAGE`-arvoksi `REDIS_IMAGE=7.4`.

### Uudet ominaisuudet

* Linkkijako voidaan nyt poistaa käytöstä asetuksella `OVERLEAF_DISABLE_LINK_SHARING=true`.
* `OVERLEAF_MAINTENANCE_MESSAGE` ja `OVERLEAF_MAINTENANCE_MESSAGE_HTML` ovat nyt käytettävissä huoltosivun otsikon ja sisällön mukauttamiseen.
* `OVERLEAF_USER_HARD_DELETION_DELAY` ja `OVERLEAF_PROJECT_HARD_DELETION_DELAY` voidaan määrittää (millisekunteina) poistettujen käyttäjien/projektien vanhenemisviiveen muuttamiseksi (oletus 90 päivää).

### Virhekorjaukset

* Korjattu linkkejä sisältävän alatunnisteen renderöinti.
* Parannettu SAML-kirjautumisvirheiden virheilmoituksia.
* Korjattu puuttuva auditointilokimerkintä, kun käyttäjän ylläpitäjätila päivitetään SSO-kirjautumisen yhteydessä.
* Korjattu historiapaneelin virheet, kun TLS on käytössä Redisissä.
* Käännökset voidaan nyt pysäyttää käytettäessä hiekkalaatikoimattomia käännöksiä.

### Muut muutokset

* Kaikki tilasivulle johtavat linkit (asetetaan muuttujalla `OVERLEAF_STATUS_PAGE_URL`) käyttävät nyt `HTTPS`-protokollaa ja avautuvat uuteen selainvälilehteen.
