### Doctor

Overleaf Toolkitin mukana tulee kätevä `doctor`-skripti vianmäärityksen avuksi. Suorita `bin/doctor`, niin skripti tulostaa tietoja isäntäympäristöstäsi, konfiguraatiostasi ja Toolkitin tarvitsemista riippuvuuksista. Tämä tuloste voi myös auttaa meitä diagnosoimaan Ayakaleaf Pro -asennustesi ongelmia.

<Info>

Overleaf Pron käyttäjät voivat [avata issuen GitHubissa](https://github.com/ayaka-notes/overleaf/issues).

On hyvä idea liittää viestiisi `bin/doctor`-skriptin tuloste.

</Info>

### Doctorin konsultointi

Suorita doctor-skripti:

```bash title="Run doctor"
bin/doctor
```

### Isäntäkoneen tiedot

`Host Information` -osio sisältää tietoja Toolkitia ajavasta koneesta (esimerkiksi Linux-jakelu ja sen versio).

<Accordion title="Esimerkki Host Information -tulosteesta">

```text
- Host Information
    - Linux
    - Output of 'lsb_release -a':
            No LSB modules are available.
            Distributor ID:	Ubuntu
            Description:	Ubuntu 22.04.5 LTS
            Release:	22.04
            Codename:	jammy
```

</Accordion>

### Riippuvuudet

`Dependencies`-osiossa luetellaan työkalut, joita Toolkit tarvitsee toimiakseen. Jos työkalu on asennettu, se näytetään muodossa `status: present` versiotietoineen. Jos se puuttuu, se näytetään muodossa `status: MISSING!`, ja `doctor`-tulosteen loppuun lisätään varoitus.

<Accordion title="Esimerkki Dependency-tulosteesta (asennettu)">

```text
- docker
    - status: present
    - version info: Docker version 28.0.4, build b8034c0
```

</Accordion>

<Accordion title="Esimerkki Dependency-tulosteesta (puuttuu)">

```text
- docker
    - status: MISSING!
```

</Accordion>

Jos riippuvuuksia puuttuu, Toolkit ei lähes varmasti toimi.

### Konfiguraatio

`Configuration`-osio sisältää tietoja `config/`-hakemiston tiedostoista. Tiedostosta `config/overleaf.rc` doctor tulostaa joitakin keskeisiä arvoja. Puuttuvat tiedostot näytetään muodossa `status: MISSING!`, ja `doctor`-tulosteen loppuun lisätään varoitus.

<Accordion title="Esimerkki Configuration-tulosteesta">

```text
====== Configuration ======
- config/version
    - status: present
    - version: 5.4.0
- config/overleaf.rc
    - status: present
    - values
        - OVERLEAF_DATA_PATH: /tmp/overleaf
        - SERVER_PRO: false
        - MONGO_ENABLED: false
        - REDIS_ENABLED: true
- config/variables.env
    - status: MISSING!
```

</Accordion>

Huomioita yllä olevasta esimerkistä:

* `OVERLEAF_DATA_PATH`, jonka arvo on `/tmp/overleaf`, ei välttämättä ole turvallinen sijainti tärkeälle datalle.
* `MONGO_ENABLED: false` tarkoittaa, että Toolkit ei luo omaa MongoDB:tä; varmista tarvittaessa, että `MONGO_URL` osoittaa ulkoisesti hallinnoituun MongoDB:hen.
* `config/variables.env` puuttuu esimerkissä.

### Varoitukset

`Warnings`-osio tiivistää doctor-skriptin havaitsemat ongelmat. Jos ongelmia ei ole, osio ilmoittaa siitä.

<Accordion title="Esimerkki Warnings-tulosteesta">

```text
====== Warnings ======
- configuration file variables.env not found
- rc file, OVERLEAF_DATA_PATH not set
====== End =======
```

</Accordion>
