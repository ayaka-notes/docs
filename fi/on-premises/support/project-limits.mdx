---
title: Projektien rajoitukset
icon: list-check
---

| Ominaisuus                                       | Rajoitus                                                                                                                                                                |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Käännöksen aikakatkaisu                          | **Oletus:** 180 sekuntia. Lisätietoja arvon mukauttamisesta on kohdassa [Projektin käännöksen aikakatkaisun päivittäminen](/fi/on-premises/user-and-project-management/project-management). |
| Tiedostojen enimmäismäärä projektia kohden       | 2000                                                                                                                                                                    |
| Muokattavan materiaalin enimmäiskoko projektia kohden | **Oletus:** 7 Mt. Lisätietoja arvon mukauttamisesta on kohdassa [Ympäristömuuttujat](/fi/on-premises/configuration/overleaf-toolkit/environment-variables). |
| Yksittäisen muokattavan tekstitiedoston enimmäiskoko | 2 Mt\*                                                                                                                                                              |
| Yksittäisen latauksen enimmäiskoko               | 50 Mt (määritettävissä muuttujalla `MAX_UPLOAD_SIZE`)                                                                                                                   |
| Ladatun .zip-tiedoston enimmäiskoko purettuna    | 6 × `MAX_UPLOAD_SIZE` (oletuksena 300 Mt)                                                                                                                               |
| Projektin enimmäiskoko                           | Rajoittamaton†                                                                                                                                                          |
| Projektien enimmäismäärä                         | Rajoittamaton                                                                                                                                                           |

\* Jotkin suuremmat tiedostot voivat tietyissä tilanteissa pysyä muokattavina. Jotta tiedosto varmasti pysyy muokattavana, sen koko kannattaa rajoittaa enintään 2 megatavuun.

† Projektin kokonaiskoolle ei ole pakotettua rajaa. Hyvin suurten projektien kanssa saatat kuitenkin törmätä teknisiin rajoituksiin. Suosittelemme projektin enimmäiskooksi 500 Mt, tai alle 100 Mt, jos käytät [Git-integraatiotamme](https://www.overleaf.com/learn/how-to/Git_integration). Näitä suuremmat projektit voivat toimia, mutta paras käyttökokemus saavutetaan pysymällä näissä rajoissa.
