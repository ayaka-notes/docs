### Overleafin yleiskatsaus

Overleaf on yhteiskäyttöinen LaTeX-editori, josta tutkijat ja teknologiatiimit pitävät. Sen pilviversio on saatavilla osoitteessa [overleaf.com](https://www.overleaf.com/). Se tarjoaa täysiverisen verkossa toimivan LaTeX-editorin. Overleaf Commonissa (SaaS-versiossa) on kuitenkin lukuisia ominaisuusrajoituksia, ja sinun on hyväksyttävä _**10 sekunnin käännösaikaraja**_ sekä kalliit jäsenmaksut.

Vaikka Overleaf tarjoaa avoimen lähdekoodin yhteisöversion (saatavilla osoitteessa [GitHub: Overleaf](https://github.com/overleaf/overleaf)), myös siinä on monia rajoituksia, esimerkiksi:

<Warning>

Overleaf Community Edition on tarkoitettu käytettäväksi ympäristöissä, joissa **kaikkiin** käyttäjiin luotetaan. Community Edition **ei** sovellu tilanteisiin, joissa käyttäjät on eristettävä toisistaan, koska Sandbox Compiles -ominaisuus ei ole käytettävissä.

Ilman hiekkalaatikkoa LaTeX-käännökset suoritetaan samoilla oikeuksilla kuin kontti, jolloin niillä on pääsy kontin tiedostojärjestelmään, verkkoon ja ympäristömuuttujiin. Tämä aiheuttaa tietovuodon tai järjestelmän vaarantumisen riskin. Hiekkalaatikottomia käännöksiä tulisi käyttää vain täysin luotetuissa ympäristöissä; monen käyttäjän tai tuotantokäytön asennuksissa Sandbox Compiles -ominaisuutta suositellaan vahvasti.

Lisätietoja Sandbox Compiles -ominaisuudesta: [sandboxed-compiles.md](/fi/on-premises/configuration/overleaf-toolkit/sandboxed-compiles  "mention")

</Warning>

### Tietoa Overleaf Server Prosta ja sen hinnasta

Overleafin verkkosivustolla on vain yhteydenottokanava Server Pron tukeen, joten tietoa Server Prosta on hyvin rajallisesti. Yhteisöstä keräämiemme tietojen perusteella **Server Pron hinnoittelu on seuraava**:

* Lisenssejä on ostettava _vähintään_ 10 henkilölle.
* 10 henkilön lisenssi maksaa noin 3 477,61 €. (2024)
* Koulutuskäytössä 20 käyttäjää maksaa 2640 euroa vuodessa, 50 käyttäjää 6050 euroa ja 100 käyttäjää 9963 euroa.
* Server Pro on saatavilla vain tietyillä alueilla (esim. ei Manner-Kiinassa).

Tällä hetkellä saatavilla olevien tietojen perusteella Overleaf Server Pro näyttää maksavan noin \$300 käyttäjää kohden vuodessa, ja vähimmäisostos on 10 lisenssiä, mikä tekee siitä erittäin kalliin vaihtoehdon. Lisäksi Server Pro tarjoaa huomattavasti vähemmän ominaisuuksia kuin Ayakaleaf Pro. Olemme syvästi kiitollisia yhteisön kehittäjille, joiden vuosien mittaiset panokset ovat mahdollistaneet Ayakaleaf Pron rakentamisen ja sen, että se lopulta ohittaa Overleaf Server Pron sekä toiminnallisuudeltaan että kyvyiltään.

Seuraavat julkiset tiedot osoittavat dokumentoituja Overleaf Server Pro -hankintoja ja hintoja. Pienemmät yhdysvaltalaiset sopimukset viittaavat noin \$320–\$370:n vuosikustannuksiin käyttäjää kohden. Suuret instituutiosopimukset voivat saada edullisemman käyttäjäkohtaisen hinnan. Esimerkiksi Max Planck -seuran kolmivuotisessa sopimuksessa hinta on keskimäärin noin 51 € käyttäjää kohden vuodessa. Sopimusehdot, tuki ja käyttöönoton laajuus voivat vaihdella. Nämä tiedot eivät ole Overleafin virallinen hinnasto.

### Miksi Ayakaleaf Pro?

<Info>

Ayakaleaf Pro _**ei**_ ole sidoksissa Overleaf, Inc.:iin tai sen emoyhtiöön Digital Scienceen. Se _ei myöskään ole Server Pro_ -versio, joka on Overleaf, Inc.:n tarjoama kaupallinen tuote. [ayaka-notes](https://github.com/ayaka-notes) kehittää ja ylläpitää Ayakaleaf Prota itsenäisenä projektina.

</Info>

Ayakaleaf Pro on Overleaf Community Editionin laajennettu toteutus, joka tarjoaa _**kaikki**_ Server Pron premium-ominaisuudet _**ilmaiseksi**_. Toisin kuin osoitteessa [https://www.overleaf.com/](https://www.overleaf.com/) saatavilla olevassa Overleaf Commonissa tai kaupallisessa Server Pro -versiossa, meillä on

* _**ei rajoituksia**_ käännösajalle
* _**ei lisenssivaatimuksia**_ käyttäjämäärälle
* _**kaikki Server Pron ominaisuudet**_ avattuina
