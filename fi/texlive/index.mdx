[TeX Live](https://www.tug.org/texlive/) on ilmainen ohjelmistojakelu, jonka [TeX Users Group](https://www.tug.org/) julkaisee vuosittain. Se sisältää LaTeX-paketit, fontit, TeX-moottorit ja lukuisia ohjelmistotyökaluja, joita tarvitaan LaTeX-pohjaiseen ladontaan kaikissa yleisissä käyttöjärjestelmissä.

TeX Live on Overleafin tärkeä osa, koska palvelimemme käyttävät sitä LaTeX-koodisi kääntämiseen ja reaaliaikaisen PDF-esikatselun luomiseen. Se tarjoaa Overleafin käyttäjille myös helpon pääsyn yli 5 000 LaTeX-pakettiin, jotka sisältyvät jokaiseen TeX Live -julkaisuun.

Projektiesi kääntäminen ei rajoitu TeX Liven uusimpaan versioon, koska Overleafin palvelimet tarjoavat pääsyn myös aiempiin TeX Live -julkaisuihin. Projektit voidaan helposti vaihtaa käyttämään aiempaa TeX Live -versiota — esimerkiksi pakettien yhteensopivuusongelmien vuoksi.<br />
