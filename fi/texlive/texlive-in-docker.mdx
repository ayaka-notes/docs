### Docker

Docker tarjoaa kevyen ja siirrettävän tavan paketoida ja ajaa sovelluksia eristetyissä konteissa. Kun sovellus paketoidaan yhdessä kaikkien tarvittavien riippuvuuksien kanssa, kontti takaa yhdenmukaisen toiminnan eri koneilla, kannettavista tietokoneista tuotantopalvelimiin.

TeX Live on tehokas, mutta suuri ja herkkä järjestelmätason eroille. Kun TeX Live paketoidaan Docker-imageen, LaTeX-työkaluketjusta tulee ennustettava, toistettava ja helposti jaettava.

Jotkin TeX Live -paketit kuitenkin tarvitsevat pääsyn komentotulkkiin. Tietoturvasyistä kontin tulisi toimia rajoitetussa ympäristössä, joka estää käyttäjiä suorittamasta mielivaltaisia komentotulkin komentoja (esimerkiksi `\write18`:n tai shell escapen kautta). Tämä eristys suojaa isäntäjärjestelmää ja estää tahattoman pääsyn kontin taustalla olevaan tiedostojärjestelmään tai työkaluihin, kuten `bash`.

### TeXLive Full -versio

[TeXLive-Full@ayaka-notes](https://github.com/ayaka-notes/texlive-full/) on täysin varusteltu **TeXLive Docker -image**, joka on suunniteltu hiekkalaatikoituun LaTeX-kääntämiseen [Ayakaleaf Prossa](https://github.com/ayaka-notes/ayakaleaf-pro), [Overleaf CEP:ssä](https://github.com/yu-i-i/overleaf-cep) tai itsenäisissä LaTeX-käännösympäristöissä.

Tämän imagen tavoitteena on tarjota lähes täydellinen TeXLive-jakelu, johon on esiasennettu yleiset fontit ja työkalut, jotta puuttuvista paketeista tai fonteista johtuvat käännösvirheet voidaan minimoida. Huomautus: Tämä Docker-image **ei sisällä** mitään sharelatex/overleaf-komponentteja. Sitä käytetään Overleafin/Overleaf Pron käännöksiin.

#### Ominaisuudet:

* 🚀 Tukee sekä x86\_64- että arm64-palvelinarkkitehtuureja
* 📦 Täydellinen ja optimoitu TeXLive-asennus
* 🧩 Esiasennetut yleiset fontit ja apuohjelmat
* 🐳 Valmis käytettäväksi Dockerin ja Docker Composen kanssa
* 🧪 Testattu Overleaf Server Pron / Overleaf Pron kanssa
* 🔄 Päivitetään säännöllisesti uusimpien TeXLive-julkaisujen mukaan
* 🏷 Useita TeXLive-versiotageja (2020 – uusin)
* 🧑‍🔬 Knitr-tuki R-koodille LaTeX-dokumenteissa

### Käyttö Ayakaleaf Prossa

Ayaka-notesin TeX Live Full on suunniteltu erityisesti [ayakaleaf-prota](https://github.com/ayaka-notes/ayakaleaf-pro) varten. Jos olet [toolkitin käyttäjä](https://github.com/overleaf/toolkit), voit lisätä seuraavat ympäristömuuttujat tiedostoon `config/variables.env`.

Esimerkiksi:

```dotenv title="config/variables.env" wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```

### TeX Live -versiot

GitHub Actionin ansiosta voimme rakentaa kaikki tex-imaget rinnakkain. Niihin kuuluvat:

* `ghcr.io/ayaka-notes/texlive-full:2026.1` (myös tag `latest`)
* `ghcr.io/ayaka-notes/texlive-full:2025.1`
* `ghcr.io/ayaka-notes/texlive-full:2024.1`
* `ghcr.io/ayaka-notes/texlive-full:2023.1`
* `ghcr.io/ayaka-notes/texlive-full:2022.1`
* `ghcr.io/ayaka-notes/texlive-full:2021.1`
* `ghcr.io/ayaka-notes/texlive-full:2020.1`
* `ghcr.io/ayaka-notes/texlive-full:base`

Käytämme peiliarkistoa sivustolta [texlive info](https://texlive.info/tlnet-archive/), joka sisältää lähes kaikki texlive-imaget vuosilta 1996–2025. Overleafin Dockerfilen ansiosta voimme myös rakentaa tämän projektin nopeammin.

> Miksi TeX Live 2019:ää ja sitä vanhempia versioita ei tueta?
>
> Näiden vanhojen imagejen ylläpitäminen on erittäin vaikeaa. Lisäksi [texlive.info](https://texlive.info/)-sivusto ei tarjoa tietoja ennen vuotta 2019 julkaistuista TeX Live -versioista, joten emme pysty rakentamaan imageja näille versioille. Jos tarvitset tietyn vanhan version, avaa issue ja kerro meille.

### Sisältyvät komponentit

Docker-image sisältää seuraavat paketit.

* Kaikki TeXLive-paketit (kyseiseltä vuodelta)
* R-paketit (vain valitut)
* fontconfig inkscape pandoc python3-pygments wget python3
* gnupg gnuplot perl-modules perl ca-certificates
* ghostscript qpdf r-base-core tar

Docker-image sisältää seuraavat fontit.

* [Google Fonts](https://fonts.google.com/)
* [Microsoft msttcorefonts](https://packages.ubuntu.com/jammy/ttf-mscorefonts-installer)
* [Overleafin tukemat fontit](https://www.overleaf.com/learn/latex/Questions/Which_OTF_or_TTF_fonts_are_supported_via_fontspec%3F)

<Warning>

Varmista, että kyseisiä fontteja saa käyttää kaupallisesti. Emme ole **vastuussa** mistään oikeudellisista ongelmista, jotka aiheutuvat fonttien virheellisestä käytöstä. Lataamalla imagen hyväksyt tämän automaattisesti.

</Warning>

### Ongelmat

<Accordion title="Ongelma 01: Fonttivälimuistin puuttumisongelma">

Kun Overleaf kääntää LaTeX-projektia ja jokin fontti puuttuu, **käännös saattaa kestää pitkään**. Tämä johtuu siitä, että fontin puuttuessa texlive yrittää **rakentaa koko fonttivälimuistin uudelleen**. Tämä on aikaa vievä prosessi.

Imagessamme fonttivälimuisti on rakennettu valmiiksi; korjasimme ongelman [tällä commitilla](https://github.com/ayaka-notes/texlive-full/commit/0cb66b0dc8b82be628cf6999cfd659d9784e132f)

</Accordion>

<Accordion title="Ongelma 02: SyncTeX on erittäin hidas">

Kun käytät tätä imagea sharelatexissa, saatat huomata, että SyncTeX on erittäin hidas.

Katso: [https://github.com/overleaf/overleaf/issues/1150](https://github.com/overleaf/overleaf/issues/1150) – poista vain HTTP 2.0 käytöstä.

</Accordion>

<Accordion title="Ongelma 03: Uudelleenkäännösvirhe virallisella Texlive-imagella">

Jos käytät Docker Hubin virallista texlive-imagea `texlive/texlive`, saatat huomata, että projektia uudelleen käännettäessä tulee virhe. Imagessamme tämä ongelma on kuitenkin korjattu, koska käytämme uusinta Ubuntu-perusimagea ja asennamme kaikki riippuvuudet Ubuntun virallisesta repositoriosta.

</Accordion>

### Muita teknisiä huomioita

Kun rakennat texlive-imagea (ennen vuotta 2019), sinun on ehkä kiinnitettävä huomiota seuraaviin ongelmiin:

* Ennen texlive 2017:ää tuetaan vain `http`/`ftp`-protokollia, joten `https`:ää ei voi käyttää lataamiseen, ellet muokkaa `peal`-skriptiä.
* Ennen vuotta 2015 tarjolla on vain sha256-tiedosto, joten sha512:ta ei voi käyttää tarkistukseen.
