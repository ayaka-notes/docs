S hrdostí oznamujeme vydání Ayakaleaf Pro 6.2, nejvýkonnějšího a funkčně nejbohatšího online editoru LaTeXu v komunitě. Zvláštní poděkování patří yu-i-i a davrot za jejich cenné příspěvky. Vylepšili GitHub Sync a přidali pokročilé vyhledávání citací (Advanced Citation Search) a integraci se Zoterem.

### Poznámky

* Byla zavedena nová povinná proměnná prostředí `OVERLEAF_INVITE_TOKEN_SECRET`, kterou musíte vygenerovat pomocí: `openssl rand -base64 32`. Pokud není nakonfigurována, vaše instance Overleafu se nespustí.
* Pokud povolíte GitHub Sync, musíte nakonfigurovat proměnnou prostředí `GITHUB_TOKEN_CIPHER_PASSWORD`. Tato proměnná je nutná k bezpečnému šifrování přístupových tokenů GitHubu. Bez ní se vaše instance Overleafu nespustí.
* Přidána nová proměnná prostředí `DEFAULT_LATEX_COMPILER` pro nastavení výchozího kompilátoru pro nové projekty (pdflatex, latex, xelatex nebo lualatex).
* Přepracovaný editor je nyní jedinou dostupnou možností.

### Změny

Toto vydání obsahuje následující vylepšení a nové funkce.

* `MAX_UPLOAD_SIZE` je nyní konfigurovatelné, místo aby bylo omezeno na **50 MB**.
* Opravena smyčka restartů kontejneru při vypnutých sandboxed compiles.
* Vynuceno mazání PAT omezené na vlastníka pro OAuth2.
* Opraven problém s importem z LDAP.

Nové funkce zahrnují:

* Přidán spouštěč Pythonu běžící v prohlížeči.
* Přidána podpora Pandocu pro import a export Markdownu, DOCX a dalších formátů.
* Přidán GitHub Sync.
* Přidány kompletní čínské překlady.
* Přidána integrace se Zoterem.
* Přidáno `DEFAULT_LATEX_COMPILER`.

#### Funkce 01: GitHub Sync

Udržujte své projekty LaTeXu synchronizované s repozitáři na GitHubu pro plynulý vývojový workflow. Odesílejte a stahujte změny přímo z editoru, spolupracujte prostřednictvím pull requestů a integrujte se stávajícími CI/CD pipeline. Správa verzí usnadňuje sledování revizí, kontrolu změn a udržování reprodukovatelných akademických či technických dokumentů.

Viz: [GitHub Synchronisation](/cs/on-premises/configuration/overleaf-toolkit/github-synchronisation  "mention").

![](https://github.com/user-attachments/assets/5137e708-77cb-4fdf-b081-4aa04b4b762e)

#### Funkce 02: Import/export přes Pandoc

Importujte dokumenty Microsoft Word a Markdown do plně upravitelných projektů LaTeXu nebo jedním kliknutím exportujte projekty LaTeXu zpět do Markdownu a DOCX. Tato funkce postavená na Pandocu umožňuje plynulou interoperabilitu mezi akademickým psaním, společnými úpravami a publikačními procesy, přičemž co nejvíce zachovává strukturu dokumentu.

Viz: [Import a export přes Pandoc](/cs/on-premises/configuration/overleaf-toolkit/pandoc-import-and-export  "mention").

#### Funkce 03: Pokročilé vyhledávání referencí

Vyhledávejte a vkládejte bibliografické reference z více akademických databází s inteligentním filtrováním a okamžitou podporou citací. Rychle objevujte články, prohlížejte metadata a vytvářejte přesné záznamy BibTeX bez přepínání mezi různými výzkumnými weby, což výrazně zvyšuje efektivitu rešerše literatury.

![obrázek](https://github.com/user-attachments/assets/42e45b73-af4b-4d1f-81f4-9e116ba5d043)

#### Funkce 04: Python Runner

Spouštějte kód v Pythonu přímo ve svém projektu, aniž byste opustili editor. Ideální pro generování obrázků, zpracování datových sad, automatizaci práce s dokumenty nebo spouštění reprodukovatelných výzkumných skriptů. Výsledky lze začlenit do dokumentů LaTeXu, takže vědecké výpočty a psaní se stávají součástí jednotného workflow.

![obrázek](https://github.com/user-attachments/assets/a4c314b3-fdb5-4836-aea7-12eeece5cd2f)

#### Funkce 05: Zotero

Propojte svou knihovnu Zotero přímo s procesem psaní a spravujte reference bez opuštění editoru. Prohledávejte své osobní kolekce Zotero, vkládejte citace jedním kliknutím a automaticky generujte a synchronizujte záznamy BibTeX. Tato integrace udržuje vaši bibliografii aktuální a zjednodušuje správu literatury pro odborné články, závěrečné práce a technické dokumenty.

Viz: [Integrace Zotero](/cs/on-premises/configuration/overleaf-toolkit/zotero-integration  "mention").
