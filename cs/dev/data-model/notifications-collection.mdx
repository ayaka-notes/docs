`notifications` uchovává upozornění zobrazená v horní části nástěnky projektů uživatele. Jeden dokument je jedno upozornění pro jednoho uživatele, identifikované svým `key`. S kolekcí přímo pracuje jen služba `notifications` (`services/notifications/app/js/Notifications.js`); `web` a `third-party-datastore` volají její HTTP API. Schéma Mongoose neexistuje.

#### Pole {#fields}

| Pole | Typ | Význam | Zdroj |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id upozornění. `web` podle tohoto id označí upozornění jako přečtené. | `Notifications.js:58-65` |
| `user_id` | ObjectId | Uživatel, který upozornění vidí. | `Notifications.js:26` |
| `key` | String | Identifikuje upozornění, například `project-invite-<inviteId>`. Upsert udržuje jeden dokument na `user_id` a `key`; jedinečný index neexistuje. | `Notifications.js:27`, `:51-55` |
| `templateKey` | String | Které upozornění frontend vykreslí. Odstraní se, když je upozornění přečteno nebo zavřeno; dokument zůstává. | `Notifications.js:29`, `:63`, `:72`, `:78` |
| `messageOpts` | Object | Hodnoty pro text upozornění podle `templateKey` (u pozvánky do projektu: `userName`, `projectName`, `projectId`, `token`). Odstraní se, když uživatel upozornění zavře podle id. | `Notifications.js:28`, `:63` |
| `expires` | Date | Volitelné. Index TTL dokument po tomto čase smaže. | `Notifications.js:35-50` |

`NotificationsBuilder.mjs` sestavuje také klíče pro skupinové pozvánky, institucionální příslušnost, předplatná a staré ladicí projekty. Jejich volající jsou v kódu předplatných a institucí a kontrola starých ladicích projektů běží jen při `isSaas` (`services/web/app/src/Features/Project/ProjectListController.mjs:234-236`).

#### Poznámky {#notes}

* Přečtené upozornění se nesmaže: zmizí jen `templateKey`. Protože dokument stále obsahuje klíč, pozdější `addNotification` bez `forceCreate` pro stejný klíč nic neudělá (`Notifications.js:21-24`).
* Trasy `/key/:key` pracují jen s klíčem, napříč všemi uživateli (`Notifications.js:76-100`).
* Pokud `web` nemá `apis.notifications.url`, upozornění nevytváří ani nečte (`NotificationsHandler.mjs:17`, `:41`).
