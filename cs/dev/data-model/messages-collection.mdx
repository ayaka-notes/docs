`messages` uchovává jeden dokument na zprávu: řádek v chatu projektu, nebo komentář či odpověď ve vlákně komentářů revize. Zapisuje do ní pouze služba chat, v `services/chat/app/js/Features/Messages/MessageManager.js`. Schéma Mongoose neexistuje. Každá zpráva patří do místnosti v kolekci [rooms](/cs/dev/data-model/rooms-collection).

#### Pole {#fields}

| Pole | Typ | Význam | Zdroj |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | ID zprávy. | `MessageManager.js:13-14` |
| `room_id` | ObjectId | Místnost (`rooms._id`), nikoli ID projektu ani ID vlákna. | `MessageManager.js:8,106-108` |
| `user_id` | ObjectId | Autor. | `MessageManager.js:9,103-105` |
| `content` | String | Text zprávy, 1 až 10240 znaků (`MAX_MESSAGE_LENGTH`). | `MessageManager.js:7`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:3,12-15` |
| `timestamp` | Number | Čas odeslání v milisekundách od roku 1970 (`Date.now()`), nikoli Date. | `MessageManager.js:10`, `services/chat/app/js/Features/Messages/MessageHttpController.js:288` |
| `edited_at` | Number | Čas poslední úpravy v milisekundách (`Date.now()`). Chybí, pokud zpráva nebyla nikdy upravena. | `MessageManager.js:65-69`, `MessageHttpController.js:189,213` |

#### Kdo zapisuje {#who-writes-it}

| Kód | Co dělá |
| ---- | ------------ |
| `MessageManager.js:5-16` `createMessage` | Vloží zprávu (`MessageHttpController.js:275-294`). Web posílá zprávy chatu projektu z `services/web/app/src/Features/Chat/ChatController.mjs:32` a komentáře z modulu track-changes (`services/web/modules/track-changes/app/src/TrackChangesController.mjs:95`) a modulu mcp-server (`services/web/modules/mcp-server/app/src/CommentTools.mjs:133`). |
| `MessageManager.js:51-72` `updateMessage` | Nastaví `content` a `edited_at`. Je-li zadáno ID uživatele, odpovídá jen zpráva tohoto uživatele (`MessageManager.js:62-64`). Volá se z `ChatController.mjs:135` a `TrackChangesController.mjs:110`. |
| `MessageManager.js:74-80` `deleteMessage` | Smaže jednu zprávu. Volá se z `ChatController.mjs:105` a `TrackChangesController.mjs:129`. |
| `MessageManager.js:39-49` `deleteAllMessagesInRoom(s)` | Smaže zprávy smazaného vlákna (`MessageHttpController.js:172-173`) nebo celého projektu, když vyprší smazaný projekt (`MessageHttpController.js:261-271`, volá se z `services/web/app/src/Features/Project/ProjectDeleter.mjs:391`). |
| `MessageManager.js:115-127` `duplicateRoomToOtherRoom` | Zkopíruje `content`, `timestamp` a `user_id` každé zprávy do jiné místnosti, bez `edited_at`. Používá se, když obnovení historie duplikuje vlákno (`MessageHttpController.js:316-342`), a když se projekt kopíruje i s rozsahy (`MessageHttpController.js:344-357`). |

#### Kdo čte {#who-reads-it}

| Kód | Co dělá |
| ---- | ------------ |
| `MessageManager.js:18-29` `getMessages` | Nejnovější první, nejvýše `limit` (výchozí 50) starších než `before` (hodnota `timestamp`). Používá se pro chat projektu (`ChatController.mjs:80`). |
| `MessageManager.js:31-37` `findAllMessagesInRooms` | Všechny zprávy několika místností, pro seznam vláken panelu revizí (`TrackChangesController.mjs:82`), modul mcp-server (`CommentTools.mjs:83`) a obnovení historie (`services/web/app/src/Features/History/RestoreManager.mjs:259`). Web také kontroluje první zprávu vlákna, aby recenzent mohl měnit jen vlákna, která sám založil (`services/web/app/src/Features/Authorization/AuthorizationManager.mjs:409-411`). |
| `MessageManager.js:90-100` `getMessage` | Jedna zpráva. Web kontroluje její `user_id`, než uživatel upraví nebo smaže svou vlastní zprávu (`services/web/app/src/Features/Authorization/AuthorizationMiddleware.mjs:253-257`, `TrackChangesController.mjs:124-125`). |

#### Poznámky {#notes}

* Chcete-li najít zprávy komentáře, nejprve vyhledejte místnost podle `project_id` a `thread_id`, pak dotazujte `room_id`. ID komentáře v dokumentu je `thread_id`, ne `room_id`.
* Text, na který komentář ukazuje, je `op.c` v `docs.ranges.comments`; diskuse je zde.
