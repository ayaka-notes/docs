title: Kolekce GitHub Sync User Credentials
icon: key
---

`githubSyncUserCredentials` uchovává jeden dokument pro každého uživatele, který propojil účet GitHub pro GitHub Sync. Ukládá zašifrovaný přístupový token OAuth uživatele. Kolekce patří do webového modulu `github-sync` (`services/web/modules/github-sync`). Schéma je v `services/web/modules/github-sync/app/models/githubSyncUserCredentials.mjs` a veškerý přístup prochází přes `services/web/modules/github-sync/app/src/TokenManager.mjs`.

#### Pole {#fields}

| Pole | Typ | Význam | Zdroj |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Nastavuje Mongoose, když upsert vkládá. | |
| `userId` | ObjectId | Uživatel Overleafu. Povinné. Schéma uvádí `unique: true`, ale žádný index se nevytváří (viz Indexy); upsert podle `userId` udržuje jeden dokument na uživatele. | `githubSyncUserCredentials.mjs:8`, `TokenManager.mjs:44-48` |
| `github` | String | Přístupový token OAuth GitHubu, zašifrovaný pomocí `@overleaf/access-token-encryptor`. Heslo pochází z `GITHUB_TOKEN_CIPHER_PASSWORD`; štítek šifry je `GITHUB_TOKEN_CIPHER_LABEL`, výchozí `2026.3-v3`. Povinné. | `githubSyncUserCredentials.mjs:9`, `TokenManager.mjs:12-25` |
| `__v` | Number | Klíč verze Mongoose. Schéma ho nevypíná. | Výchozí v Mongoose |

Ukládá se jen přístupový token: callback OAuth si z odpovědi GitHubu ponechá `access_token` (`services/web/modules/github-sync/app/src/GitHubApiClient.mjs:180-191`). Není žádný obnovovací token ani expirace.

#### Kdo zapisuje {#who-writes-it}

| Kód | Co dělá |
| ---- | ------------ |
| `TokenManager.mjs:42-58` (`saveUserToken`) | Provede upsert zašifrovaného tokenu uživatele. Když uživatel propojí účet znovu, nahrazený token se na pozadí v GitHubu odvolá. Volá se z callbacku OAuth (`services/web/modules/github-sync/app/src/GitHubSyncController.mjs:146`). |
| `TokenManager.mjs:61-76` (`removeUserToken`) | Odvolá token v GitHubu (podle možností) a pak smaže dokument. Volá se při zrušení propojení (`GitHubSyncController.mjs:167`) a když vyprší smazaný uživatel (`services/web/modules/github-sync/index.mjs:66-68`). |

#### Kdo čte {#who-reads-it}

| Kód | Co dělá |
| ---- | ------------ |
| `TokenManager.mjs:36-40` (`getUserToken`) | Dešifruje token pro každé volání API GitHubu: `services/web/modules/github-sync/app/src/GitHubSyncHandler.mjs` (například `:27`) a `services/web/modules/github-sync/app/src/GitMerge.mjs:43`. Bez dokumentu nebo s tokenem, který nejde dešifrovat, vyhodí `InvalidTokenError` a uživatel se počítá jako nepropojený (`GitHubSyncHandler.mjs:25-37`). |
| `services/web/modules/admin-tools/app/src/AdminUserListManager.mjs:393` | Kontroluje, zda má uživatel dokument, pro integrace zobrazené v administrátorském panelu. |

#### Indexy {#indexes}

| Název | Klíče | Volby | Migrace |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

`autoIndex` v Mongoose je vypnutý (`services/web/app/src/infrastructure/Mongoose.mjs:7`), takže `unique: true` ze schématu na `userId` nic nevytvoří. `tools/migrations/20190912145011_create_githubSyncUserCredentials_indexes.mjs` (`user_id` z upstreamu) má jen štítek `saas` a v CE se nespouští.

#### Poznámky {#notes}

* Změna `GITHUB_TOKEN_CIPHER_PASSWORD` učiní uložené tokeny nečitelnými. Tito uživatelé se pak počítají jako nepropojení, dokud účet znovu nepropojí.
* Smazaný uživatel si ponechá dokument, dokud nevyprší.
