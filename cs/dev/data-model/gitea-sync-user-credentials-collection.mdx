---
title: Kolekce Gitea Sync User Credentials
icon: lock
---

`giteaSyncUserCredentials` uchovává jeden dokument pro každého uživatele, který propojil účet Gitea pro Gitea Sync. Ukládá zašifrované tokeny OAuth uživatele. Kolekce patří do webového modulu `gitea-sync` (`services/web/modules/gitea-sync`). Schéma je v `services/web/modules/gitea-sync/app/models/giteaSyncUserCredentials.mjs` a veškerý přístup prochází přes `services/web/modules/gitea-sync/app/src/TokenManager.mjs`.

#### Pole {#fields}

| Pole | Typ | Význam | Zdroj |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Nastavuje Mongoose, když upsert vkládá. | |
| `userId` | ObjectId | Uživatel Overleafu. Povinné. Schéma uvádí `unique: true`, ale žádný index se nevytváří (viz Indexy); upsert podle `userId` udržuje jeden dokument na uživatele. | `giteaSyncUserCredentials.mjs:8`, `TokenManager.mjs:89-96` |
| `gitea` | String | JSON `{ accessToken, refreshToken, expiresAt }`, zašifrovaný pomocí `@overleaf/access-token-encryptor`. `expiresAt` je v milisekundách od epochy, nebo `null`; `refreshToken` může být `null`. Heslo pochází z `GITEA_TOKEN_CIPHER_PASSWORD`; štítek šifry je `GITEA_TOKEN_CIPHER_LABEL`, výchozí `2026.10-v3`. Povinné. | `giteaSyncUserCredentials.mjs:9-10`, `TokenManager.mjs:17-30`, `services/web/modules/gitea-sync/app/src/GiteaApiClient.mjs:198-209` |
| `__v` | Number | Klíč verze Mongoose. Schéma ho nevypíná. | Výchozí v Mongoose |

#### Kdo zapisuje {#who-writes-it}

| Kód | Co dělá |
| ---- | ------------ |
| `TokenManager.mjs:89-96` (`saveUserToken`) | Provede upsert zašifrovaných přihlašovacích údajů uživatele. Volá se z callbacku OAuth (`services/web/modules/gitea-sync/app/src/GiteaSyncController.mjs:146`). Na rozdíl od GitLab Sync opětovné propojení nahrazený token neodvolá. |
| `TokenManager.mjs:53-79` (`refreshUserToken`) | Když do `expiresAt` přístupového tokenu zbývá méně než 5 minut (`:12`), získá pomocí obnovovacího tokenu nové tokeny a uloží je (`:76`). Běží pod zámkem `giteaSyncToken` pro každého uživatele (`:14,54`), protože Gitea obnovovací token při použití nahradí. |
| `TokenManager.mjs:100-102` (`removeUserToken`) | Smaže dokument. Gitea nemá API pro odvolání tokenu OAuth, takže uživatel odvolá oprávnění v Gitea (`:98-99`). Volá se při zrušení propojení (`GiteaSyncController.mjs:173`) a když vyprší smazaný uživatel (`services/web/modules/gitea-sync/index.mjs:56-58`). |

#### Kdo čte {#who-reads-it}

| Kód | Co dělá |
| ---- | ------------ |
| `TokenManager.mjs:40-44,82-86` (`getUserCredentials`, `getUserToken`) | Dešifruje přihlašovací údaje pro každé volání API Gitea a předtím je obnoví, když token brzy vyprší: `services/web/modules/gitea-sync/app/src/GiteaSyncHandler.mjs` (například `:27`) a `services/web/modules/gitea-sync/app/src/GitMerge.mjs:52`. Bez dokumentu nebo s údaji, které nejde dešifrovat ani obnovit, vyhodí `InvalidTokenError` a uživatel se počítá jako nepropojený (`GiteaSyncHandler.mjs:25-37`). |
| `services/web/modules/admin-tools/app/src/AdminUserListManager.mjs:395` | Kontroluje, zda má uživatel dokument, pro integrace zobrazené v administrátorském panelu. |

#### Indexy {#indexes}

| Název | Klíče | Volby | Migrace |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

`autoIndex` v Mongoose je vypnutý (`services/web/app/src/infrastructure/Mongoose.mjs:7`), takže `unique: true` ze schématu na `userId` nic nevytvoří. Žádná migrace pro tuto kolekci nevytváří indexy.

#### Poznámky {#notes}

* Změna `GITEA_TOKEN_CIPHER_PASSWORD` učiní uložené přihlašovací údaje nečitelnými. Tito uživatelé se pak počítají jako nepropojení, dokud účet znovu nepropojí.
* Smazaný uživatel si ponechá dokument, dokud nevyprší.
