`tokens` obsahuje jednorázové tokeny: tajemství v odkazu, přes který si někdo může nastavit heslo. Jeden dokument je jeden token. Neexistuje model Mongoose; web zapisuje kolekci přes `services/web/app/src/Features/Security/OneTimeTokenHandler.mjs` nativním ovladačem.

#### Pole {#fields}

| Pole | Typ | Význam | Zdroj |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Id dokumentu. | `OneTimeTokenHandler.mjs:40` |
| `use` | String | K čemu token slouží, viz [Použití](#uses) níže. Každé vyhledávání podle něj filtruje. | `OneTimeTokenHandler.mjs:41` |
| `token` | String | Tajemství v odkazu: 32 náhodných bajtů jako 64 šestnáctkových znaků, uložené tak, jak je. | `OneTimeTokenHandler.mjs:38,42` |
| `data` | Object | Co token zastupuje; vrací se při jeho použití. | `OneTimeTokenHandler.mjs:43` |
| `data.user_id` | String | Id uživatele, každý volající ho zapisuje jako řetězec. | `services/web/app/src/Features/PasswordReset/PasswordResetHandler.mjs:27`, `services/web/app/src/Features/User/UserRegistrationHandler.mjs:117`, `services/web/modules/admin-tools/app/src/AdminUserManager.mjs:79` |
| `data.email` | String | E-mail uživatele v okamžiku vytvoření tokenu. Obnovení hesla hledá uživatele podle tohoto hlavního e-mailu (`PasswordResetHandler.mjs:66-70`). | stejně jako `data.user_id` |
| `createdAt` | Date | Čas vytvoření. TTL index token smaže o 90 dní později. | `OneTimeTokenHandler.mjs:36,44` |
| `expiresAt` | Date | `createdAt` plus `expiresIn` sekund: výchozí 1 hodina, 1 týden u aktivačního odkazu. Po tomto čase vyhledávání token ignorují. | `OneTimeTokenHandler.mjs:35-37,45` |
| `peekCount` | Number | Kolikrát byl token zobrazen, aniž by byl použit. Každé `peekValueFromToken` přičte 1; při 4 (`MAX_PEEKS`) token přestane fungovat. | `OneTimeTokenHandler.mjs:8-31,107` |
| `usedAt` | Date | Čas, kdy byl token použit nebo zrušen. Vyhledávání ignorují token, který ho má. | `OneTimeTokenHandler.mjs:51-104` |

#### Použití {#uses}

| `use` | Funkce | Platnost | Kód |
| ----- | ------- | ------ | ---- |
| `password` | E-mail pro obnovení hesla ze stránky „zapomenuté heslo“ | 1 hodina | `PasswordResetHandler.mjs:14-42` |
| `password` | Aktivační odkaz: účet vytvořený s náhodným heslem a pak odkaz pro nastavení vlastního. Používá ho veřejná registrace (`services/web/modules/login-register/app/src/RegisterController.mjs:65`), administrátorská registrační stránka `user-activate` (`services/web/modules/user-activate/app/src/UserActivateController.mjs:27-30`) a skript `create-user` (`services/web/modules/server-ce-scripts/scripts/create-user.mjs:21`) | 1 týden | `UserRegistrationHandler.mjs:97-130` |
| `password` | Aktivační odkaz nebo odkaz pro obnovení hesla odeslaný z administračního panelu (modul `admin-tools`) | 1 týden (aktivace), 1 hodina (obnovení) | `AdminUserManager.mjs:76-103,196-206` |
| `email_confirmation` | Odkaz pro potvrzení e-mailu. Pouze se čte: nic v tomto repozitáři už takové tokeny nevytváří, protože potvrzení nyní posílá 6místný kód (`services/web/app/src/Features/User/UserEmailsConfirmationHandler.mjs:15-35`) | | `UserEmailsConfirmationHandler.mjs:12,37-66` |

#### Kdo zapisuje {#who-writes-it}

| Kód | Co dělá |
| ---- | ------------ |
| `OneTimeTokenHandler.mjs:34-49` (`getNewToken`) | Vloží token. Volající: `PasswordResetHandler.mjs:28`, `UserRegistrationHandler.mjs:115-119`, `AdminUserManager.mjs:77-81`. |
| `OneTimeTokenHandler.mjs:8-32` (`peekValueFromToken`) | Vrátí `data` platného tokenu a přičte 1 k `peekCount`. Používá se při otevření stránky pro obnovení hesla (`services/web/app/src/Features/PasswordReset/PasswordResetController.mjs:195-208`), znovu při nastavení nového hesla (`PasswordResetHandler.mjs:94-96`) a při potvrzení e-mailu (`UserEmailsConfirmationHandler.mjs:38-41`). |
| `OneTimeTokenHandler.mjs:75-88` (`expireToken`) | Nastaví `usedAt` u jednoho tokenu: po nastavení nového hesla (`PasswordResetHandler.mjs:44-48,119`) nebo potvrzení e-mailu (`UserEmailsConfirmationHandler.mjs:65`). |
| `OneTimeTokenHandler.mjs:90-104` (`expireAllTokensForUser`) | Nastaví `usedAt` u všech otevřených tokenů `password` uživatele, když uživatel změní heslo v nastavení (`services/web/app/src/Features/User/UserController.mjs:146-149`) nebo ho administrátor nastaví v administračním panelu (`AdminUserManager.mjs:479-488`). |

#### Kdo čte {#who-reads-it}

| Kód | Co dělá |
| ---- | ------------ |
| `PasswordResetHandler.mjs:50-70,94-119` | Z tokenu pro obnovení nebo aktivaci zjistí uživatele a pak nastaví heslo. Aktivační stránka `user-activate` jen předá token tomuto formuláři. |
| `UserEmailsConfirmationHandler.mjs:37-66` | Potvrdí e-mail z tokenu `email_confirmation` přihlášeného uživatele. |
| `AdminUserManager.mjs:213-223` (module `admin-tools`) | Najde otevřený aktivační token uživatele, aby v administračním panelu znovu zobrazil aktivační odkaz. Čte `db.tokens` přímo. |

#### Poznámky {#notes}

* Použitý nebo prošlý token se nesmaže hned: zůstane s `usedAt` nebo minulým `expiresAt`, dokud ho TTL index neodstraní 90 dní po `createdAt`.
* `OneTimeTokenHandler` má také `getValueFromTokenAndExpire` (`OneTimeTokenHandler.mjs:51-73`), ale nic ho nevolá.
