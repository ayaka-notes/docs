`docSnapshots` uchovává kopie dokumentu, které document-updater pořizuje těsně před úpravou, jež sbalí komentáře nebo sledované změny. Zapisuje do ní pouze document-updater, v `services/document-updater/app/js/SnapshotManager.js`. Web má model Mongoose v `services/web/app/src/models/DocSnapshot.mjs`, ale žádný kód ho nepoužívá.

#### Pole {#fields}

| Pole | Typ | Význam | Zdroj |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | ID snímku. | `SnapshotManager.js:24` |
| `project_id` | ObjectId | Projekt. | `SnapshotManager.js:19,26`, `DocSnapshot.mjs:7` |
| `doc_id` | ObjectId | Dokument (`docs._id`). | `SnapshotManager.js:20,27`, `DocSnapshot.mjs:8` |
| `version` | Number | OT verze dokumentu před úpravou. | `SnapshotManager.js:28`, `services/document-updater/app/js/UpdateManager.js:132,264-271`, `DocSnapshot.mjs:9` |
| `lines` | Array of String | Obsah dokumentu před úpravou. | `SnapshotManager.js:29`, `DocSnapshot.mjs:10` |
| `pathname` | String | Cesta k dokumentu v projektu v daném okamžiku. | `SnapshotManager.js:30`, `DocSnapshot.mjs:11` |
| `ranges` | Mixed | `comments` a `changes` před úpravou, ve stejném tvaru jako `docs.ranges` (viz [docs](/cs/dev/data-model/docs-collection)). `id`, `op.t` a `metadata.user_id` se převádějí na ObjectId a `metadata.ts` na Date. | `SnapshotManager.js:31,41-68`, `DocSnapshot.mjs:12` |
| `ts` | Date | Kdy byl snímek pořízen. TTL index snímek po 30 dnech smaže. | `SnapshotManager.js:32`, `DocSnapshot.mjs:13` |

#### Kdo zapisuje {#who-writes-it}

| Kód | Co dělá |
| ---- | ------------ |
| `UpdateManager.js:248-271` | Po použití úpravy document-updater zaznamená dokument ve stavu před úpravou, pokud úprava sbalila rozsahy: prázdných rozsahů přibylo, nebo byl odstraněn více než jeden rozsah (`services/document-updater/app/js/RangesManager.js:104-106`). |
| `SnapshotManager.js:17-36` `recordSnapshot` | Vloží snímek. |

#### Kdo čte {#who-reads-it}

Žádný kód ji nečte. Model ve web je definován, ale nikde se nepoužívá.

#### Poznámky {#notes}

* Snímky pořizují jen úpravy, které procházejí přes `UpdateManager.applyUpdate`. Úpravy zpracované `HistoryOTUpdateManager` je nepořizují (`UpdateManager.js:74-77`).
* Na `doc_id` není index. Snímky dokumentu hledejte podle `project_id` a `ts` a pak filtrujte podle `doc_id`.
