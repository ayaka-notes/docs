`githubSyncProjectStates` uchovává jeden dokument pro každý projekt propojený s repozitářem GitHub: o jaký repozitář jde a kde skončila poslední synchronizace. Kolekce patří do webového modulu `github-sync` (`services/web/modules/github-sync`). Schéma je v `services/web/modules/github-sync/app/models/githubSyncProjectStates.mjs` a veškerý přístup prochází přes `services/web/modules/github-sync/app/src/SyncStateManager.mjs`.

#### Kdo zapisuje {#who-writes-it}

| Kód | Co dělá |
| ---- | ------------ |
| `SyncStateManager.mjs:9-14` (`createProjectState`) | Vytvoří dokument: po importu repozitáře jako nového projektu (`services/web/modules/github-sync/app/src/GitHubSyncHandler.mjs:175-181`) nebo po exportu projektu do nového repozitáře (`GitHubSyncHandler.mjs:235-241`, jen vlastník, odmítnuto, pokud už je propojen). |
| `SyncStateManager.mjs:16-21` (`updateProjectState`) | `$set` změněných polí. `getMergeOverview` nastaví `mergeStatus: 'diverged'`, když synchronizovaná větev už nestaví na `lastSyncCommit`: compare v GitHubu odpoví `diverged` nebo `behind` (`GitHubApiClient.mjs:382-400`), nebo commit zmizel a uživatel může pushovat (`GitHubSyncHandler.mjs:123,126-137`). Synchronizace (`services/web/modules/github-sync/app/src/GitMerge.mjs`) při úspěchu posune `lastSyncCommit`/`lastSyncVersion` (například `:143,173,224`), zaznamená konflikt pomocí `unmergedBranchName`, `unmergedBranchHead` a `conflictVersion` (`:207-213`) a po jeho vyřešení je vymaže (`:250-257`). |
| `SyncStateManager.mjs:23-25` (`removeProjectState`) | Smaže dokument, když vlastník zruší propojení projektu (`GitHubSyncHandler.mjs:83-97`) a když vyprší smazaný projekt (`services/web/modules/github-sync/index.mjs:56-58`). |

#### Indexy {#indexes}

| Název | Klíče | Volby | Migrace |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

`autoIndex` v Mongoose je vypnutý (`services/web/app/src/infrastructure/Mongoose.mjs:7`), takže `unique: true` ze schématu na `projectId` nic nevytvoří. `tools/migrations/20190912145010_create_githubSyncProjectStates_indexes.mjs` (`project_id` a `owner_id` z upstreamu) má jen štítek `saas` a v CE se nespouští.

#### Poznámky {#notes}

* Synchronizace běží pod zámkem projektu `gitSync` (`GitMerge.mjs:17-24`). GitLab Sync a Gitea Sync berou stejný zámek, takže pro projekt běží vždy jen jedna synchronizace.
* Smazaný projekt si ponechá svůj dokument, dokud nevyprší.
* Token GitHub uživatele je v [GitHub Sync User Credentials](/cs/dev/data-model/github-sync-user-credentials-collection).
