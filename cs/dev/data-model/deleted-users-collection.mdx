---
title: Kolekce Deleted Users
icon: user-xmark
---

`deletedUsers` uchovává uživatelský účet po jeho smazání: jeden dokument na každý smazaný účet, s kopií celého dokumentu uživatele a informací, kdo jej smazal. Web kolekci zapisuje v `services/web/app/src/Features/User/UserDeleter.mjs`; schéma je `services/web/app/src/models/DeletedUser.mjs`. Po uplynutí lhůty pro trvalé smazání proces vypršení odstraní kopii uživatele, ale záznam s `deleterData` zůstane.

Smazání uživatele smaže také projekty, které vlastní; ty se dostanou do [Kolekce Deleted Projects](/cs/dev/data-model/deleted-projects-collection) s důvodem `account-deletion`.

#### Kdo zapisuje {#who-writes-it}

| Kód | Co dělá |
| ---- | ------------ |
| `UserDeleter.mjs:37-80` (`deleteUser`) | Přidá záznam auditního protokolu `delete-account`, vyčistí uživatele a spustí hook `deleteUser`, provede upsert záznamu (`_createDeletedUser`, `UserDeleter.mjs:192-213`), smaže projekty uživatele, odešle bezpečnostní upozornění e-mailem, pokud se nevynechá, a smaže dokument `users`. Volající: stránka nastavení účtu (`services/web/app/src/Features/User/UserController.mjs:280-284`), administrátorský panel (`services/web/modules/admin-tools/app/src/AdminUserManager.mjs:604-612`) a skript `delete-user` (`delete-user.mjs:40-45`). |
| `UserDeleter.mjs:93-115` (`expireDeletedUser`) | Spustí hook `expireDeletedUser`, smaže onboardingová data uživatele a pak odstraní `user` a `deleterData.deleterIpAddress`. |
| `UserDeleter.mjs:117-161` (`expireDeletedUsersAfterDuration`) | Nechá vypršet každý záznam starší než lhůta a smaže `userAuditLogEntries` uživatele. | `AdminUserManager.mjs:630-649` (`purgeDeletedUser`, modul `admin-tools`) | Purge v administrátorském panelu: spustí `expireDeletedUser` a smaže záznamy auditního protokolu uživatele. |
| `AdminUserManager.mjs:651-696` (`restoreDeletedUser`, modul `admin-tools`) | Obnovení v administrátorském panelu: znovu vytvoří dokument `users` z `user` (odmítne, pokud je e-mail obsazený), smaže záznam a obnoví projekty smazané spolu s účtem. |

#### Poznámky {#notes}

* Moduly, které naslouchají `expireDeletedUser`, mažou svá vlastní data uživatele: `dropbox` (`services/web/modules/dropbox/index.mjs:62`), `github-sync` (`services/web/modules/github-sync/index.mjs:66`), `gitlab-sync` (`services/web/modules/gitlab-sync/index.mjs:56`) a `gitea-sync` (`services/web/modules/gitea-sync/index.mjs:56`).
* Záznam, který vypršel, se nikdy nesmaže: `deleterData` zůstává natrvalo, odstraní se jen `user` a IP adresa.
* Osobní přístupové tokeny uživatele se se smazáním účtu nemažou, viz [Kolekce OAuth Access Tokens](/cs/dev/data-model/oauth-access-tokens-collection).
* Mongoose přidělí `deleterData` také vlastní `_id`, které nic nečte.
