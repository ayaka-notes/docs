`rooms` uchovává jeden dokument na chatovací místnost projektu: chat projektu, nebo jedno vlákno komentářů revize. Zapisuje do ní pouze služba chat, v `services/chat/app/js/Features/Threads/ThreadManager.js`. Schéma Mongoose neexistuje. Zprávy místnosti jsou v kolekci [messages](/cs/dev/data-model/messages-collection).

#### Pole {#fields}

| Pole | Typ | Význam | Zdroj |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | ID místnosti. Ukazuje sem `messages.room_id`. | `ThreadManager.js:57-61` |
| `project_id` | ObjectId | Projekt, do kterého místnost patří. | `ThreadManager.js:43-54` |
| `thread_id` | ObjectId | Pouze u vláken komentářů: ID komentáře, shodné s `id` a `op.t` komentáře v `docs.ranges.comments` (viz [docs](/cs/dev/data-model/docs-collection)). U místnosti chatu projektu chybí. | `ThreadManager.js:38-55`, `services/docstore/app/js/RangeManager.js:54-57` |
| `resolved` | Object | Nastaví se, když je vlákno vyřešeno, a odstraní se, když je znovu otevřeno. Vlákno bez tohoto pole je otevřené. | `ThreadManager.js:94-123` |
| `resolved.user_id` | String | ID uživatele, který vlákno vyřešil. Ukládá se jako řetězec, ne jako ObjectId: tělo požadavku se pouze kontroluje, zda jde o platné ID, a nepřevádí se. | `ThreadManager.js:103`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:70` |
| `resolved.ts` | Date | Kdy bylo vlákno vyřešeno. | `ThreadManager.js:104` |

#### Poznámky {#notes}

* Projekt má nejvýše jednu místnost bez `thread_id`: chat projektu. Služba chat ji najde pomocí `thread_id: { $exists: false }` (`ThreadManager.js:38-45`).
* Stav vyřešení komentáře je uložen pouze zde. Docstore před uložením rozsahů odstraní `op.resolved` (`services/docstore/app/js/RangeManager.js:59-61`).
* Po zkopírování projektu existuje stejné `thread_id` ve dvou projektech. Vždy se dotazujte na `project_id` a `thread_id` společně, stejně jako služba chat.
* Místnosti smazaného projektu zůstávají, dokud smazaný projekt nevyprší.
