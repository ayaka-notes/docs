---
title: Kolekce Dropbox Entities
icon: file-arrow-up
---

`dropboxEntities` uchovává jeden dokument na každý soubor, který synchronizace s Dropboxem zkopírovala mezi projektem a Dropboxem jednoho uživatele, a navíc krátkodobé tombstony. Kolekce patří k synchronizaci s Dropboxem: third-party-datastore (`services/third-party-datastore/app/js/StateManager.mjs`) ji zapisuje a čte a webový modul `dropbox` (`services/web/modules/dropbox/app/src/DropboxHandler.mjs`) ji maže. Neexistuje žádné schéma Mongoose.

#### Pole {#fields}

| Pole | Typ | Význam | Zdroj |
| ---- | --- | ------ | ----- |
| `_id` | ObjectId | Nastavuje ovladač při vložení. | `StateManager.mjs:46,97` |
| `overleaf.userId` | ObjectId | Uživatel, v jehož Dropboxu soubor je. Nastaveno v každém dokumentu. | `StateManager.mjs:48,98` |
| `overleaf.projectId` | ObjectId | Projekt docu nebo souboru. Nastaveno, je-li známo; tombstony jej nemají. | `StateManager.mjs:49-51` |
| `overleaf.id` | ObjectId | `_id` docu nebo souboru v `rootFolder` projektu. Nastaveno, je-li známo. | `StateManager.mjs:52` |
| `overleaf.type` | String | `doc` nebo `file`. Současný kód jej zapisuje, ale nečte. | `StateManager.mjs:53`; hodnoty z `services/web/app/src/Features/ThirdPartyDataStore/TpdsUpdateSender.mjs:35,96` a `UpdateMerger.mjs:104,119` |
| `dropbox.id` | String | `id` souboru v metadatech souboru Dropboxu. U tombstonů není nastaveno. | `StateManager.mjs:56` |
| `dropbox.pathLower` | String | Cesta k souboru v Dropboxu, malými písmeny a bez koncového lomítka. Aktualizuje se, když se soubor nebo složka jeho projektu přesune. | `StateManager.mjs:14-16,57,91,99` |
| `dropbox.rev` | String | Revize Dropboxu při poslední synchronizaci. Další nahrání ji odešle, aby se soubor změněný v Dropboxu nepřepsal. | `StateManager.mjs:58`, `JobProcessor.mjs:114-122` |
| `dropbox.contentHash` | String | Hash obsahu Dropboxu při poslední synchronizaci. Soubor ve výpisu se stejným hashem se přeskočí, protože jde o naše vlastní nahrání nebo už byl použit. | `StateManager.mjs:59`, `PullManager.mjs:147-149` |
| `tombstone` | Boolean | `true` označuje cestu, kterou third-party-datastore sám v Dropboxu smazal nebo přesunul jinam. Když Dropbox toto smazání nahlásí zpět, na projekt se nepoužije. | `StateManager.mjs:100`, `PullManager.mjs:189-192` |
| `createdAt` | Date | Pouze tombstony: kdy byl vytvořen. Dokončený pull odstraní tombstony vytvořené před jeho začátkem. | `StateManager.mjs:101,115-121` |

Tombstone má pouze `overleaf.userId`, `dropbox.pathLower`, `tombstone` a `createdAt` (`StateManager.mjs:96-103`).

#### Kdo ji zapisuje {#who-writes-it}

| Kód | Co dělá |
| --- | ------- |
| `services/third-party-datastore/app/js/StateManager.mjs:35-62` (`recordEntity`) | Smaže dokumenty uživatele se stejným `dropbox.id`, `dropbox.pathLower` nebo `overleaf.id` a poté vloží nový stav. |
| `services/third-party-datastore/app/js/JobProcessor.mjs:102-134` (`addEntity`) | Zaznamená doc nebo soubor po nahrání z Overleafu do Dropboxu (`:125-133`). |
| `services/third-party-datastore/app/js/PullManager.mjs:142-177` (`applyFile`) | Zaznamená soubor z Dropboxu poté, co jej web použil na projekt (`:168-176`). |
| `StateManager.mjs:80-94` (`moveEntities`) | Přepíše `dropbox.pathLower` pod přesunutou cestou: přejmenování projektu (`JobProcessor.mjs:195`) a přesun souboru nebo složky (`JobProcessor.mjs:239`). |
| `StateManager.mjs:96-103` (`addTombstone`) | Po smazání (`JobProcessor.mjs:153`), přejmenování projektu (`:202`) nebo přesunu (`:240`) v Dropboxu. |
| `StateManager.mjs:72-78` (`removeEntities`) | Smaže záznamy na cestě a pod ní, kromě tombstonů: po smazání z Overleafu (`JobProcessor.mjs:152`) nebo v Dropboxu (`PullManager.mjs:206`). |
| `StateManager.mjs:115-121` (`clearTombstones`) | Na konci pullu (`PullManager.mjs:31,69`). |
| `StateManager.mjs:186-190` (`removeUserState`), volané z `services/third-party-datastore/app/js/QueueWorker.mjs:43` | Smaže všechny dokumenty uživatele, když third-party-datastore odpojí účet, který už nemůže používat. |
| `DropboxHandler.mjs:142-146` (`removeUserState`) | Smaže všechny dokumenty uživatele při propojení (`:125`), při odpojení (`:183`) a když vyprší smazaný uživatel (`services/web/modules/dropbox/index.mjs:62-64`). |
| `DropboxHandler.mjs:150-154` (`removeProjectState`) | Smaže dokumenty projektu, když vyprší smazaný projekt (`index.mjs:54-56`). |

#### Kdo ji čte {#who-reads-it}

| Kód | Co dělá |
| --- | ------- |
| `StateManager.mjs:64-70` (`findEntityByPath`) | Získá `dropbox.rev` před nahráním (`JobProcessor.mjs:114`) a `dropbox.contentHash` před použitím souboru z Dropboxu (`PullManager.mjs:147`). |
| `StateManager.mjs:106-112` (`findTombstone`) | Zkontroluje nahlášené smazání na cestě nebo na některé z jejích nadřazených cest (`PullManager.mjs:189`). |
| `StateManager.mjs:160-175` (`getSyncedPaths`) | Vypíše cesty synchronizovaných souborů po resetu kurzoru, aby se soubor chybějící ve výpisu považoval za smazaný (`PullManager.mjs:74-85`). |

#### Indexy {#indexes}

| Název | Klíče | Volby | Migrace |
| ----- | ----- | ----- | ------- |
| `_id_` | `_id: 1` | | default |
| `overleaf_userId_1_overleaf_projectId_1` | `overleaf.userId: 1, overleaf.projectId: 1` | | `tools/migrations/20250130104049_create_dropboxEntities_userId_projectId_index.mjs` |

`20220811111800_create_dropboxEntities_index.mjs` a `20220825160708_recreate_dropboxEntities.mjs` mají pouze štítek `saas`, takže CE nemá jejich unikátní indexy na `(overleaf.userId, dropbox.id)` a `(overleaf.userId, overleaf.id)` ani jejich hashovaný index na `dropbox.pathLower`.

#### Poznámky {#notes}

* Unikátnost zajišťuje pouze mazání před každým vložením v `recordEntity` (`StateManager.mjs:38-45`). Komentář v `StateManager.mjs:3-11` zmiňuje unikátní indexy; CE je nemá.
* Dotazy podle uživatele a cesty (`findEntityByPath`, `findTombstone`, `removeEntities`) používají index pouze pro `overleaf.userId`.
