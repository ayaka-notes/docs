---
title: Kolekce Deleted Projects
icon: trash-can
---

`deletedProjects` uchovává projekt po jeho smazání: jeden dokument na každý smazaný projekt, s kopií celého dokumentu projektu a informací, kdo jej smazal. Web kolekci zapisuje v `services/web/app/src/Features/Project/ProjectDeleter.mjs`; schéma je `services/web/app/src/models/DeletedProject.mjs`. Po uplynutí lhůty pro trvalé smazání proces vypršení zničí data projektu a vyprázdní `project`, ale záznam s `deleterData` zůstane.

Projekt v koši tu není: přesunutí do koše jen přidá uživatele do `trashed` projektu, viz [Kolekce Projects](/cs/dev/data-model/projects-collection).

#### Kdo zapisuje {#who-writes-it}

| Kód | Co dělá |
| ---- | ------------ |
| `ProjectDeleter.mjs:189-293` (`deleteProject`) | Provede flush projektu, archivuje jeho docs mimo Mongo, odebere jej ze štítků, provede upsert záznamu a smaže dokument `projects`. |
| `ProjectDeleter.mjs:295-342` (`undeleteProject`) | Znovu vloží projekt pod názvem `<name> (Restored)` (jedinečným pro vlastníka) a už nearchivovaný, pak smaže záznam. Selže s `project_too_old_to_restore`, jakmile je `project` `null`. Volá se z administrátorského panelu: obnovení jednoho projektu (`AdminProjectManager.mjs:497-515`) nebo obnovení smazaného uživatele s projekty smazanými spolu s účtem (`services/web/modules/admin-tools/app/src/AdminUserManager.mjs:678-689`). |
| `ProjectDeleter.mjs:344-416` (`expireDeletedProject`) | Zničí docs, historii, chat a auditní protokol projektu a spustí hook `projectExpired`, pak nastaví `project` a `deleterData.deleterIpAddress` na `null`. Pokud projekt znovu existuje, smaže jen zastaralý záznam. |
| `ProjectDeleter.mjs:97-146` (`expireDeletedProjectsAfterDuration`) | Nechá vypršet dávku záznamů starších než lhůta. Trasa `POST /internal/expire-deleted-projects-after-duration` (`services/web/app/src/router.mjs:842-846`), kterou cron Community Edition volá každou hodinu ve 20. minutě, když je `ENABLE_CRON_RESOURCE_DELETION` `true` (`server-ce/cron/delete-projects.sh:10-23`, `server-ce/config/crontab-deletion:3`). #### Poznámky {#notes}

* Moduly, které naslouchají `projectExpired`, mažou svá vlastní data projektu: `git-bridge` (`services/web/modules/git-bridge/index.mjs:37`), `github-sync` (`services/web/modules/github-sync/index.mjs:56`), `gitlab-sync` (`services/web/modules/gitlab-sync/index.mjs:46`), `gitea-sync` (`services/web/modules/gitea-sync/index.mjs:46`) a `dropbox` (`services/web/modules/dropbox/index.mjs:54`).
* Záznam, který vypršel, se nikdy nesmaže: `deleterData` zůstává natrvalo, vyprázdní se jen `project` a IP adresa.
* Mongoose přidělí `deleterData` také vlastní `_id`, které nic nečte.
