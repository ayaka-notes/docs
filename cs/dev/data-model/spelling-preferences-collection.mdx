title: Kolekce Spelling Preferences
icon: spell-check
---

`spellingPreferences` uchovává slovník každého uživatele: slova, která uživatel přidal přes "Add to dictionary" v kontrole pravopisu editoru. Jeden dokument na uživatele. Vlastníkem je `web`, bez schématu Mongoose; kód je `services/web/app/src/Features/Spelling/LearnedWordsManager.mjs`.

#### Pole {#fields}

| Pole | Typ | Význam | Zdroj |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id dokumentu, vytvořené upsertem. | `LearnedWordsManager.mjs:21-31` |
| `token` | String | Id uživatele. Navzdory názvu předávají trasy pravopisu id přihlášeného uživatele (`SessionManager.getLoggedInUserId`). | `LearnedWordsManager.mjs:23` |
| `learnedWords` | Array of String | Slova, která uživatel přidal. | `LearnedWordsManager.mjs:26` |

#### Kdo zapisuje {#who-writes-it}

| Kód | Co dělá |
| --- | --- |
| `LearnedWordsManager.mjs:13-32` (`learnWord`) | `POST /spelling/learn` (`services/web/app/src/router.mjs:1037-1041`, `services/web/app/src/Features/Spelling/SpellingController.mjs:45-58`): `$addToSet` slova s upsertem. Odmítne, pokud by seznam přesáhl `Settings.maxDictionarySize` bajtů. |
| `LearnedWordsManager.mjs:38-47` (`unlearnWord`) | `POST /spelling/unlearn` (`router.mjs:1043-1047`, `SpellingController.mjs:66-79`): `$pull` slova. |
| `LearnedWordsManager.mjs:84-86` (`deleteUsersLearnedWords`) | Smaže dokument. Jeho jediný obal, `SpellingHandler.deleteUserDictionary` (`services/web/app/src/Features/Spelling/SpellingHandler.mjs:24-26`), nikdo ve web ani v jeho modulech nevolá. |

#### Kdo čte {#who-reads-it}

| Kód | Co dělá |
| --- | --- |
| `LearnedWordsManager.mjs:52-67` (`getLearnedWords`) | Vrací slova bez duplicit. |
| `services/web/app/src/Features/Project/ProjectController.mjs:671` | Při otevření projektu posílá slovník do editoru (`SpellingHandler.getUserDictionary`). |

#### Poznámky {#notes}

* Index není jedinečný; upsert podle `token` udržuje jeden dokument na uživatele.
* Smazání uživatele tento dokument nesmaže.
