---
title: Kolekce Project History Labels
icon: tag
---

`projectHistoryLabels` uchovává štítky, které uživatelé přidávají k verzím v zobrazení History, jeden dokument na štítek. Vlastní ji project-history a zapisuje ji v `services/project-history/app/js/LabelsManager.js`; schéma Mongoose neexistuje. Web k ní přistupuje jen přes API project-history.

#### Pole {#fields}

| Pole | Typ | Význam | Zdroj |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | ID štítku. | `LabelsManager.js:81-85` |
| `project_id` | ObjectId | Projekt. | `LabelsManager.js:73` |
| `comment` | String | Text štítku. | `LabelsManager.js:74` |
| `version` | Number | Verze historie projektu, na kterou štítek ukazuje. | `LabelsManager.js:75` |
| `created_at` | Date | Kdy byl štítek vytvořen; požadavek může předat vlastní čas, jinak se použije aktuální. | `LabelsManager.js:70`, `76` |
| `user_id` | ObjectId | Kdo štítek vytvořil. Vynecháno, pokud požadavek nemá uživatele. | `LabelsManager.js:78-80` |

#### Kdo zapisuje {#who-writes-it}

| Kód | Co dělá |
| ---- | ------------ |
| `services/project-history/app/js/LabelsManager.js:44-90` | `createLabel`: vloží štítek, pro project-history `POST /project/:project_id/labels` (`services/project-history/app/js/HttpController.js:1134-1171`). Web ho volá, když uživatel přidá štítek, s ID uživatele (`services/web/app/src/Features/History/HistoryController.mjs:529-546`). |
| `LabelsManager.js:113-126` | `deleteLabel`: smaže štítek projektu, pro `DELETE /project/:project_id/labels/:label_id`. Web ho používá, když vlastník projektu smaže štítek (`HistoryController.mjs:649-670`). |
| `LabelsManager.js:92-111` | `deleteLabelForUser`: smaže štítek, jen pokud ho vytvořil daný uživatel, pro `DELETE /project/:project_id/user/:user_id/labels/:label_id`. Web ho používá pro všechny ostatní. |
| `LabelsManager.js:128-143` | `transferLabels`: přesune všechny štítky jednoho uživatele na jiného, pro `POST /user/:from_user/labels/transfer/:to_user` (`services/project-history/app/js/Router.js:52-55`). Nic ve web tuto routu nevolá. |
| `LabelsManager.js:7-25` | `cloneLabels`: zkopíruje štítky projektu do jiného projektu, pro project-history `POST /project/:project_id/clone` (`HttpController.js:113`), kterou nic ve web nevolá. |

#### Kdo čte {#who-reads-it}

| Kód | Co dělá |
| ---- | ------------ |
| `LabelsManager.js:27-42` | `getLabels`: všechny štítky projektu, vrácené jako `{ id, comment, version, user_id, created_at }` (`LabelsManager.js:163-171`). Používá ho `GET /project/:project_id/labels` (`HttpController.js:1076-1100`), které web volá pro zobrazení History a doplňuje jména uživatelů (`HistoryController.mjs:488-499`). |
| `services/project-history/app/js/SummarizedUpdatesManager.js:57` | Přidá štítky do seznamu aktualizací historie. |

#### Poznámky {#notes}

* Před vložením štítku project-history zpracuje aktualizace projektu ve frontě a ověří, že history-v1 má chunk pro danou verzi, pokud požadavek nepošle `validate_exists: false` (`LabelsManager.js:53-59`, `173-195`; `HttpController.js:1109-1115`).
* Žádný kód nemaže štítky projektu při jeho smazání: project-history `DELETE /project/:project_id` vymaže jen stav synchronizace a záznam o selhání (`HttpController.js:1363-1396`) a žádná jiná služba se této kolekce nedotýká.
