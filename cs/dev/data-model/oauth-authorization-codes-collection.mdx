---
title: Kolekce OAuth Authorization Codes
icon: lock-open
---

`oauthAuthorizationCodes` je určena pro kódy toku OAuth authorization code: jeden dokument na kód, který klient vymění za přístupový token. Schéma je `services/web/app/src/models/OauthAuthorizationCode.mjs` a webový modul `oauth2-server` obsahuje kód, který by do ní zapisoval. V Ayakaleaf Pro se k tomuto kódu nic nedostane, takže kolekce zůstává prázdná (viz Poznámky).

#### Pole {#fields}

| Pole | Typ | Význam | Zdroj |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Id dokumentu. | `OauthAuthorizationCode.mjs:6` |
| `authorizationCode` | String | Samotný kód, uložený tak, jak je (bez hashe). | `OauthAuthorizationCode.mjs:8`, `services/web/modules/oauth2-server/app/src/OAuth2Model.mjs:280` |
| `expiresAt` | Date | Konec platnosti. Po něm `getAuthorizationCode` kód odmítne a TTL index ho smaže. | `OauthAuthorizationCode.mjs:9`, `OAuth2Model.mjs:150-153,281` |
| `oauthApplication_id` | ObjectId | Klient v [OAuth Applications](/cs/dev/data-model/oauth-applications-collection), který o kód požádal. | `OauthAuthorizationCode.mjs:10`, `OAuth2Model.mjs:275-284` |
| `redirectUri` | String | URI přesměrování požadavku. | `OauthAuthorizationCode.mjs:11`, `OAuth2Model.mjs:282` |
| `scope` | String | Požadovaný scope. | `OauthAuthorizationCode.mjs:12`, `OAuth2Model.mjs:283` |
| `user_id` | ObjectId | Uživatel, který kód udělil. | `OauthAuthorizationCode.mjs:13`, `OAuth2Model.mjs:285` |
| `codeChallenge`, `codeChallengeMethod` | String | PKCE challenge a jeho metoda. | `OauthAuthorizationCode.mjs:14-15`, `OAuth2Model.mjs:286-287` |

#### Kdo zapisuje {#who-writes-it}

| Kód | Co dělá |
| ---- | ------------ |
| `OAuth2Model.mjs:274-300` (`saveAuthorizationCode`) | Vloží kód. Nikdy se nevolá, viz Poznámky. |
| `OAuth2Model.mjs:307-312` (`revokeAuthorizationCode`) | Smaže kód po jeho použití. Nikdy se nevolá. |

#### Kdo čte {#who-reads-it}

| Kód | Co dělá |
| ---- | ------------ |
| `OAuth2Model.mjs:137-177` (`getAuthorizationCode`) | Načte kód s jeho uživatelem a klientem. Nikdy se nevolá. |

#### Indexy {#indexes}

| Název | Klíče | Volby | Migrace |
| ---- | ---- | ------- | --------- |
| `expiresAt_1` | `{ expiresAt: 1 }` | TTL, `expireAfterSeconds: 0`, částečný: `expiresAt` existuje | `20230406125632_oauth_tokens_ttl.mjs` |

Migrace jsou v `tools/migrations/`. Unikátní index `authorizationCode_1` pochází jen z migrací se štítky `saas` a `server-pro`, které Community Edition nespouští.

#### Poznámky {#notes}

* Výše uvedené metody modelu volají jen handlery authorize a token z `@node-oauth/oauth2-server`. Web tuto knihovnu používá jen ke kontrole tokenů bearer (`services/web/app/src/Features/Authentication/AuthenticationController.mjs:409-450`) a žádná trasa neobsluhuje `/oauth/authorize` ani `/oauth/token`, takže se nikdy nezapíše žádný kód. Osobní přístupové tokeny se vytvářejí přímo, viz [OAuth Access Tokens](/cs/dev/data-model/oauth-access-tokens-collection).
