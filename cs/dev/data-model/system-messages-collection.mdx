---
title: Kolekce System Messages
icon: bullhorn
---

`systemmessages` uchovává bannery pro celý web, které administrátor zveřejní pro všechny přihlášené uživatele. Jeden dokument je jedna zpráva. Vlastníkem je `web`; schéma je `services/web/app/src/models/SystemMessage.mjs` a kód je `services/web/app/src/Features/SystemMessages/SystemMessageManager.mjs`.

#### Pole {#fields}

| Pole | Typ | Význam | Zdroj |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id zprávy. Prohlížeč si podle tohoto id pamatuje, které zprávy uživatel zavřel (`services/web/frontend/js/shared/components/system-message.tsx:10`). | `SystemMessage.mjs:5` |
| `content` | String | Text zprávy, výchozí `''`. | `SystemMessage.mjs:7` |
| `__v` | Number | Klíč verze Mongoose, přidaný pomocí `message.save()`. | `SystemMessageManager.mjs:29-30` |

#### Kdo zapisuje {#who-writes-it}

| Kód | Co dělá |
| --- | --- |
| `SystemMessageManager.mjs:28-33` (`createMessage`) | `POST /admin/messages` (`services/web/app/src/router.mjs:1150-1152`, `services/web/app/src/Features/ServerAdmin/AdminController.mjs:151-159`): přidá jednu zprávu. |
| `SystemMessageManager.mjs:22-26` (`clearMessages`) | `POST /admin/messages/clear` (`router.mjs:1155-1157`, `AdminController.mjs:161-168`): smaže všechny zprávy. Jednotlivou zprávu smazat nelze. |

#### Kdo čte {#who-reads-it}

| Kód | Co dělá |
| --- | --- |
| `SystemMessageManager.mjs:50-65` | Každý proces `web` drží všechny zprávy v paměti a znovu je načítá každých 20 až 30 sekund a hned po vlastním vytvoření nebo vymazání. |
| `services/web/app/src/Features/SystemMessages/SystemMessageController.mjs:6-24` | `GET /system/messages` (`router.mjs:331`): vrací přihlášeným uživatelům zprávy z mezipaměti. Dokud je web zavřený (`siteIsOpen` je false), vrací místo nich pevné upozornění, které není uloženo v Mongo. |
| `AdminController.mjs:83-84` | Stránka `/admin` vypisuje zprávy přímo z Mongo. |

#### Indexy {#indexes}

Žádná migrace nevytváří index na `systemmessages`; existuje jen výchozí index `_id`.

#### Poznámky {#notes}

* Je-li nastaveno `notifyOnSystemMessageChanges`, vytvoření nebo vymazání se zveřejní také v kanálu Redis `refresh-system-messages`, takže ostatní procesy `web` hned znovu načtou zprávy (`SystemMessageManager.mjs:9`, `:35-48`, `:75-87`). Bez tohoto nastavení změnu převezmou při příštím plánovaném načtení.
