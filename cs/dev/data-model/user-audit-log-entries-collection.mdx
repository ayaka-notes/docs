`userAuditLogEntries` je auditní protokol uživatelských účtů: přihlášení, změny hesla a e-mailu, propojené účty a akce administrátorů. Jeden dokument je jedna událost na jednom účtu. Vlastníkem je `web`; schéma je `services/web/app/src/models/UserAuditLogEntry.mjs` a jádro zapisuje přes `services/web/app/src/Features/User/UserAuditLogHandler.mjs`.

| `userId_1_timestamp_-1` | `{ userId: 1, timestamp: -1 }` | | `tools/migrations/20251117093546_add_timestamp_to_userAuditLogEntries.mjs` |

`tools/migrations/20220929193200_add_auditLog_indexes.mjs` nejprve vytvořila `user_id_1` na `{ userId: 1 }`; `20251117093546` jej nahrazuje složeným indexem. Schéma označuje `userId` a `managedSubscriptionId` pomocí `index: true`, ale automatické indexování Mongoose je vypnuté (`services/web/app/src/infrastructure/Mongoose.mjs:7`), takže indexy vytvářejí jen výše uvedené migrace. Migrace indexu `managedSubscriptionId` má jen štítek `saas`.

#### Poznámky {#notes}

* Záznamy díky indexu TTL vyprší 2,5 roku po `timestamp`.
