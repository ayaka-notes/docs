---
title: Kolekce Project History Sharded Blobs
icon: cubes-stacked
---

`projectHistoryShardedBlobs` uchovává záznamy blobů, které se nevešly do [projectHistoryBlobs](/dev/data-model/project-history-blobs-collection): když má kbelík pro prefix hashe už 8 záznamů, další jdou sem. Projekt zde má nejvýše 16 dokumentů, jeden na první šestnáctkovou číslici hashe. Schéma Mongoose neexistuje; history-v1 ji zapisuje v `services/history-v1/storage/lib/blob_store/mongo.js` (uspořádání popsáno v `mongo.js:1-16`).

#### Pole {#fields}

| Pole | Typ | Význam | Zdroj |
| ----- | ---- | ------- | ------ |
| `_id` | Binary | 13 bajtů: ID historie projektu, `0`, a číslice shardu, čtená šestnáctkově (`<history id>0<digit>`). Číslice shardu je první šestnáctková číslice hashe. | `mongo.js:439-453` |
| `blobs` | Object | Záznamy blobů seskupené do kbelíků. Klíčem kbelíku jsou šestnáctkové číslice 2 až 4 hashe. | `mongo.js:439-443` |
| `blobs.<bcd>` | Array of Object | Záznamy kbelíku. Kód neomezuje jeho velikost. | `mongo.js:399-407` |
| `blobs.<bcd>[].h` | Binary | Hash, 20 bajtů, stejně jako v projectHistoryBlobs. | `mongo.js:472` |
| `blobs.<bcd>[].b` | Number | Délka obsahu v bajtech. | `mongo.js:473` |
| `blobs.<bcd>[].s` | Number | Délka obsahu jako textu; `null`, když obsah není upravitelný text. | `mongo.js:474` |

#### Kdo zapisuje {#who-writes-it}

| Kód | Co dělá |
| ---- | ------------ |
| `services/history-v1/storage/lib/blob_store/mongo.js:399-407` | `insertRecordSharded`: upsert s `$addToSet` do kbelíku. Volá ho `insertBlob`, když je kbelík v projectHistoryBlobs plný (`mongo.js:387-389`). |
| `mongo.js:75-103` | `clone`: zkopíruje shardy projektu na jiné ID historie, pro history-v1 `POST /projects/:project_id/clone`, kterou nic ve web nevolá. |
| `mongo.js:413-422` | `deleteBlobs`: smaže všechny shardy projektu spolu s jeho dokumentem projectHistoryBlobs, při history-v1 `DELETE /projects/:project_id`. |

#### Kdo čte {#who-reads-it}

| Kód | Co dělá |
| ---- | ------------ |
| `mongo.js:144-157` | `findBlobSharded`: jeden blob, hledaný jen tehdy, když jeho kbelík v projectHistoryBlobs má 8 záznamů a neobsahuje ho (`mongo.js:127-131`). |
| `mongo.js:217-260` | `findBlobsSharded`: bloby, které `findBlobs` nenašla v projectHistoryBlobs (`mongo.js:202-206`). |
| `mongo.js:285-306` | `getProjectBlobs`: všechny shardy projektu. |
| `mongo.js:337-361` | `getProjectBlobsBatch`: všechny shardy několika projektů, pro routu statistik blobů. |

#### Indexy {#indexes}

Pouze výchozí index `_id`. Žádná migrace v `tools/migrations/` index nepřidává.

#### Poznámky {#notes}

* Shardy jednoho projektu leží vedle sebe v pořadí `_id`, takže je kód najde rozsahem `_id` od `<history id>00` do `<history id>0f` (`mongo.js:75-80`, `287-295`).
* Kolekce se objeví až tehdy, když nějaký projekt má více než 8 blobů se stejným trojmístným prefixem hashe, takže malá instance ji nemusí mít vůbec.
