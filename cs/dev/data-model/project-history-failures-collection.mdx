`projectHistoryFailures` uchovává jeden dokument na projekt, jehož aktualizace historie project-history nedokázala zpracovat nebo pro který spustila resynchronizaci. Jakmile zpracování projde, dokument se znovu smaže. project-history ji zapisuje v `services/project-history/app/js/ErrorRecorder.js`; její typ je v `services/project-history/app/js/mongo-types.ts:3-24`. Web pro ni má také schéma Mongoose (`services/web/app/src/models/ProjectHistoryFailure.mjs:5-19`), ale žádný kód ve web tento model nepoužívá.

#### Poznámky {#notes}

* Dokument zůstává, dokud flush projektu neuspěje nebo projekt není smazán (`clearError` výše), takže každý dokument označuje projekt, jehož poslední flush nebo resynchronizace zatím neuspěly.
* Chybové řetězce začínající `OError:` se vracejí jako `Error:` (`ErrorRecorder.js:18-26`); uložená hodnota se nemění.
