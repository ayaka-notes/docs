`tags` uchovává štítky (složky), do kterých uživatel třídí projekty na nástěnce projektů. Jeden dokument je jeden štítek jednoho uživatele. Vlastníkem je `web`; schéma je `services/web/app/src/models/Tag.mjs` a všechny zápisy procházejí přes `services/web/app/src/Features/Tags/TagsHandler.mjs`.

#### Pole {#fields}

| Pole | Typ | Význam | Zdroj |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id štítku, používá se v trasách `/tag/:tagId`. | `Tag.mjs:10` |
| `user_id` | String | Vlastník štítku. Z historických důvodů prostý řetězec, ne ObjectId. | `Tag.mjs:7-12` |
| `name` | String | Název štítku, nejvýše 50 znaků (`MAX_TAG_LENGTH`). Jedinečný pro každého uživatele. | `Tag.mjs:13`, `TagsHandler.mjs:4` |
| `color` | String | Volitelná barva: šestnáctkový kód jako `#a1b2c3` nebo hodnota `hsl(<n>, 70%, 45%)` (`TAG_COLOR_REGEX`). | `Tag.mjs:5`, `Tag.mjs:14-22` |
| `project_ids` | Array of String | Id projektů v tomto štítku jako řetězce. | `Tag.mjs:23` |
| `__v` | Number | Klíč verze Mongoose, přidaný, když `Tag.create` vytvoří dokument. | `TagsHandler.mjs:27` |

| Název | Klíče | Volby | Migrace |
| --- | --- | --- | --- |

Stejná migrace vytvořila také `user_id_1`; `tools/migrations/20231031164732_drop_redundant_indexes.mjs` jej znovu odstraní, protože jej pokrývá složený index.

#### Poznámky {#notes}

* Štítky patří jednotlivým uživatelům: dva spolupracovníci na stejném projektu mají každý své vlastní štítky.
* `user_id` a `project_ids` jsou řetězce, proto je dotazujte řetězcovými id, ne ObjectId.
* Smazání uživatele (`services/web/app/src/Features/User/UserDeleter.mjs`) se `tags` nedotkne.
