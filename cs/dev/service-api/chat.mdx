Ukládá chat projektu a vlákna komentářů (jejich zprávy a stav vyřešení) do kolekcí Mongo `rooms` a `messages`. Volá ho web přes `ChatApiHandler`.

* <strong>Adresa:</strong> `http://chat:3010`, uvnitř sítě Docker
* <strong>Ověřování:</strong> žádné
* <strong>Soubor OpenAPI:</strong> [`develop/hoppscotch/openapi/chat.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/chat.yaml)
