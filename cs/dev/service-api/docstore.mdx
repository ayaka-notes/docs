title: docstore
icon: database
---

Ukládá každý dokument (řádky, verzi, rozsahy) každého projektu do kolekce Mongo `docs` a archivuje dokumenty do objektového úložiště, pokud je nastaven backend. Volá ho web; document-updater se k němu dostává přes web.

* <strong>Adresa:</strong> `http://docstore:3016`, uvnitř sítě Docker
* <strong>Ověřování:</strong> žádné
* <strong>Soubor OpenAPI:</strong> [`develop/hoppscotch/openapi/docstore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/docstore.yaml)
