Ukládá úplnou historii každého projektu: bloky změn v Mongu nebo Postgresu a objektovém úložišti a obsah souborů jako bloby. project-history do něj zapisuje změny; web, project-history a git-bridge z něj čtou bloby, snímky a soubory zip.

* <strong>Adresa:</strong> `http://history-v1:3100`, uvnitř sítě Docker
* <strong>Ověřování:</strong> HTTP basic auth jako `staging` s `STAGING_PASSWORD`, nebo JWT, podle trasy.
* <strong>Soubor OpenAPI:</strong> [`develop/hoppscotch/openapi/history-v1.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/history-v1.yaml)
