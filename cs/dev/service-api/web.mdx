Soukromé API webu, hlavní aplikace Overleaf. Volají ho ostatní služby (real-time, document-updater, project-history, third-party-datastore, git-bridge) a cron skripty image Server CE. Tyto trasy vyžadují jen HTTP basic auth, žádný CSRF token: soukromý router je připojen před webovým routerem a kontrolu CSRF provádí jen webový router. S `BLOCK_CROSS_ORIGIN_REQUESTS=true` (ve výchozím stavu vypnuto) vrací web 403 pro každý požadavek, jehož hlavička `Origin` není v `ALLOWED_ORIGINS` (výchozí: URL webu). Prohlížeče posílají `Origin` u POST, takže s tímto přepínačem zapnutým dostanou POST požadavky odeslané z Hoppscotche v prohlížeči 403, pokud nejdou přes proxy Hoppscotche.

* <strong>Adresa:</strong> `http://web:3000`, uvnitř sítě Docker
* <strong>Ověřování:</strong> HTTP basic auth s `WEB_API_USER` a `WEB_API_PASSWORD`, kromě status, health a metrics. Trasy git-bridge místo toho používají osobní přístupový token.
* <strong>Soubor OpenAPI:</strong> [`develop/hoppscotch/openapi/web.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/web.yaml)
