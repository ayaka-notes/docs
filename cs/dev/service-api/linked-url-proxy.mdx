Načítá pro web externí URL a streamuje odpověď zpět, přičemž odmítá interní adresy, aby se uživatelé nedostali do sítě Docker. Web přes něj posílá soubory URL, importy Open in Overleaf a web_fetch agenta AI.

* <strong>Adresa:</strong> `http://linked-url-proxy:3066`, uvnitř sítě Docker
* <strong>Ověřování:</strong> žádné
* <strong>Soubor OpenAPI:</strong> [`develop/hoppscotch/openapi/linked-url-proxy.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/linked-url-proxy.yaml)
