Poskytuje soubory z objektového úložiště: soubory šablon (zip, pdf a jejich náhledové obrázky) a, pouze pro čtení, projektové a globální bloby, které zapisuje history-v1. Volají ho web (modul template-gallery, URL souborů kompilace) a clsi, které z něj stahuje binární soubory projektu.

* <strong>Adresa:</strong> `http://filestore:3009`, uvnitř sítě Docker
* <strong>Ověřování:</strong> žádné
* <strong>Soubor OpenAPI:</strong> [`develop/hoppscotch/openapi/filestore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/filestore.yaml)
