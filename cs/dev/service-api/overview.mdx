Overleaf běží jako několik služeb, které se navzájem volají přes HTTP uvnitř sítě Docker. Stránky v této části popisují tato interní API. Vycházejí ze souborů OpenAPI v [`develop/hoppscotch/openapi/`](https://github.com/ayaka-notes/ayakaleaf-pro/tree/server-pro/develop/hoppscotch/openapi), které jsou napsány podle kódu jednotlivých služeb.

Žádné z těchto API není veřejné: jsou dostupná jen uvnitř sítě Docker a většina z nich nemá ověřování.

## Služby {#services}

| Služba | Adresa | Co dělá |
| ------------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------------------ |
| [web](/cs/dev/service-api/web)                                     | `http://web:3000`                   | Hlavní aplikace. Její soukromé API volají ostatní služby a cron skripty image  |
| [document-updater](/cs/dev/service-api/document-updater)           | `http://document-updater:3003`      | Drží dokumenty otevřené v editoru v Redisu, aplikuje úpravy a zapisuje je zpět do Monga         |
| [docstore](/cs/dev/service-api/docstore)                           | `http://docstore:3016`              | Ukládá každý dokument každého projektu do kolekce Mongo `docs`                                 |
| [real-time](/cs/dev/service-api/real-time)                         | `http://real-time:3026`             | Drží socket.io spojení editoru a předává úpravy mezi prohlížeči a službami          |
| [chat](/cs/dev/service-api/chat)                                   | `http://chat:3010`                  | Ukládá chat projektu a vlákna komentářů                                                  |
| [project-history](/cs/dev/service-api/project-history)             | `http://project-history:3054`       | Převádí úpravy z fronty na změny historie a posílá je do history-v1; uchovává štítky               |
| [history-v1](/cs/dev/service-api/history-v1)                       | `http://history-v1:3100`            | Ukládá úplnou historii každého projektu a obsah souborů jako bloby                           |
| [filestore](/cs/dev/service-api/filestore)                         | `http://filestore:3009`             | Poskytuje soubory šablon a, pouze pro čtení, bloby zapsané history-v1                           |
| [clsi](/cs/dev/service-api/clsi)                                   | `http://clsi:3013`                  | Kompiluje projekty, spouští SyncTeX a počítání slov, převádí dokumenty                              |
| [notifications](/cs/dev/service-api/notifications)                 | `http://notifications:3042`         | Ukládá oznámení zobrazovaná v seznamu projektů                                               |
| [linked-url-proxy](/cs/dev/service-api/linked-url-proxy)           | `http://linked-url-proxy:3066`      | Načítá externí URL pro web a odmítá interní adresy                                     |
| [third-party-datastore](/cs/dev/service-api/third-party-datastore) | `http://third-party-datastore:3002` | Synchronizuje projekty s Dropboxem přes jednu frontu úloh na uživatele                                       |

## Ověřování {#authentication}

* <strong>web:</strong> HTTP basic auth s `WEB_API_USER` a `WEB_API_PASSWORD`. Trasy git-bridge místo toho používají osobní přístupový token.
* <strong>history-v1:</strong> HTTP basic auth jako `staging` s `STAGING_PASSWORD`, nebo JWT.
* <strong>Všechny ostatní služby:</strong> žádné.

## Vyzkoušejte je {#try-them}

Vývojové prostředí spouští [Hoppscotch](https://github.com/hoppscotch/hoppscotch) na `http://localhost:9170` s proxy, která se ke službám dostane přes jejich adresy v Dockeru. Jeho [README](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/README.md#hoppscotch) ukazuje, jak nastavit proxy a importovat soubory OpenAPI.
