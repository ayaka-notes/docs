## Doporučené vývojové nástroje

Tyto volitelné služby nejsou ke spuštění Overleafu potřeba, ale pro vývoj, ladění a kontrolu během lokálního vývoje je důrazně doporučujeme.

* **Hoppscotch** je odlehčený nástroj pro testování API podobný Postmanu, který ale běží v prohlížeči a je pro vývoj velmi pohodlný.
  * Frontend: [http://localhost:3000](http://localhost:3000/)
  * Proxy (pro obejití CORS): [http://localhost:9159](http://localhost:9159/)
* **RedisInsight** poskytuje vizuální rozhraní pro prohlížení dat v Redisu. Rozhraní je dostupné na: [http://localhost:5540](http://localhost:5540/)
* **Mongo Express** je webové rozhraní pro MongoDB. Můžete navštívit [http://localhost:8081](http://localhost:8081/) s **přihlašovacími údaji**: `admin:pass`

Přidejte prosím do svého `docker-compose.yml` následující:

<Accordion title="develop/docker-compose.yml">

```yml title="develop/docker-compose.yml"
# services: 
  # Overleaf Dev Containers
  # ...
  
  # Add those for your development
  # API debug
  hoppscotch-frontend:
    image: hoppscotch/hoppscotch-frontend:latest
    ports:
      - "3000:3000"

  hoppscotch-proxy:
    image: hoppscotch/proxyscotch:latest
    environment:
      - PORT=9159
    ports:
      - "9159:9159"

  # Redis-insight
  redis-insight:
    image: redislabs/redisinsight:latest
    ports:
      - "5540:5540"
    depends_on:
      - redis
    volumes:
      - ./data/redis-insight:/data

  # mongo-express
  # basicAuth credentials are "admin:pass"
  mongo-express:
    image: mongo-express
    ports:
      - "8081:8081"
    environment:
      ME_CONFIG_MONGODB_SERVER: mongo
```

</Accordion>

### Nastavení Hoppscotch

#### Proxy pro požadavky API

Pro nastavení Hoppscotch navštivte [http://localhost:3000](http://localhost:3000/) a přejděte na kartu nastavení. Musíte nastavit `Proxy` na [http://localhost:9159](http://localhost:9159/), aby vaše ladicí nástroje mohly komunikovat s interními sítěmi kontejnerů.

#### Problémy s CSRF

<Warning>

Pokud pomocí Postmanu nebo jiných ladicích nástrojů vytvoříte požadavek **POST**, můžete zjistit, že přihlášení je **zakázáno** a příčinou je chyba 401. Je to proto, že Overleaf je chráněn ověřováním **CSRF**.

</Warning>

  <img src="/images/dev/image-9.png" alt="" />
</Frame>

Abyste to při vývoji Overleafu vyřešili, musíte nastavit CSRF token. Zde je podrobný návod.

<Steps>
<Step title="Přidání Pre-Request skriptu">
Přidejte následující kód do Pre-Request

<Frame>
  <img src="/images/dev/image-11.png" alt="" />
</Frame>

Skript je následující:

```js wrap
pm.sendRequest("http://web:3000/dev/csrf", function (err, res) {
    if (err) {
        console.log(err);
        return;
    }

    // 1) Save CSRF token (/dev/csrf)
    const token = res.text().trim();
    pw.env.set("csrftoken", token);
    console.log("csrftoken =", token);

    const setCookieHeader = (res.headers || []).find(h => h.key?.toLowerCase() === "set-cookie")?.value;
    console.log("set-cookie =", setCookieHeader);

    if (!setCookieHeader) return;

    const cookiePair = setCookieHeader.split(";")[0].trim(); // overleaf.sid=...
    pw.env.set("cookie_header", cookiePair);
    console.log("cookie_header =", cookiePair);
});
```
</Step>

<Step title="Přidání hlaviček požadavku">
Musíte přidat následující hlavičky:

| Název hlavičky | Hodnota hlavičky    |
| -------------- | ------------------- |
| Content-Type   | `application/json`  |
| X-Csrf-Token   | `<<csrftoken>>`     |
| Cookie         | `<<cookie_header>>` |

<Frame>
  <img src="/images/dev/image-12.png" alt="" />
</Frame>
</Step>

<Step title="Přihlášení pomocí nástrojů API">
Nyní se můžete přihlásit pomocí svého uživatelského jména a hesla.

```json5
{
  "_csrf": "<<csrftoken>>",
  "email": "admin@overleaf.com",
  "password": "xxxxxx"
}
```

Takto vypadá odpověď, když zadáte nesprávné uživatelské jméno nebo heslo.
