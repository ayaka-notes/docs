## Doporučené vývojové nástroje {#develop-tools-recommended}

Tyto volitelné služby nejsou k běhu Overleaf potřeba, ale velmi pomáhají při vývoji, ladění a zkoumání dat. Všechny jsou součástí vývojového prostředí, takže do `docker-compose.yml` není třeba nic přidávat. Jakmile se přihlásíte na web, menu **Dev tools** v jeho navigační liště odkazuje na nástroje, které web poskytuje na vlastních cestách.

| Nástroj | Adresa | Definováno v |
| --- | --- | --- |
| **Grafana**, stav, metriky a logy každé služby | [http://localhost/grafana/](http://localhost/grafana/) | `develop/grafana/docker-compose.yml`, zapnuto při `GRAFANA_ENABLED=true` v `develop/dev.rc` (výchozí) |
| **Mailpit**, schránka pro každý e-mail, který web odešle | [http://localhost/mailpit/](http://localhost/mailpit/) | `develop/mail/docker-compose.yml`, zapnuto při `MAILPIT_ENABLED=true` (výchozí) |
| **Mongo Express**, rozhraní pro MongoDB | [http://localhost/mongo-express/](http://localhost/mongo-express/) | `develop/docker-compose.yml`, vždy zapnuto |
| **RedisInsight**, rozhraní pro data Redis | [http://localhost/redis-insight/](http://localhost/redis-insight/) | `develop/docker-compose.yml`, vždy zapnuto |
| **Hoppscotch**, prohlížečový API klient podobný Postmanu | [http://localhost:9170](http://localhost:9170/) (`HOPPSCOTCH_PORT`) | `develop/hoppscotch/docker-compose.yml`, zapnuto při `HOPPSCOTCH_ENABLED=true` (výchozí) |

<Warning>

Žádný z těchto nástrojů nemá přihlášení: anonymní uživatelé Grafany jsou jejími administrátory a Mongo Express může změnit jakýkoli dokument. Web, Hoppscotch, Mongo Express (8081) a RedisInsight (5540) naslouchají pouze na `127.0.0.1` hostitele, takže ostatní hostitelé se k nim nedostanou.

</Warning>

### Grafana {#grafana}

Grafanu poskytuje web na `/grafana/` přes webpack-dev-server, takže nepotřebuje vlastní port. Její složka **Overleaf Develop** obsahuje tyto dashboardy:

| Dashboard | Co zobrazuje |
| --- | --- |
| All services (domů) | Stav každé služby, ukazatele hostitele, zátěž a logy. Kliknutím na službu otevřete její dashboard |
| Server | CPU, zátěž, paměť, disk a síť hostitele a kompilace clsi |
| Errors | Chybové logy, odpovědi 5xx a 4xx, nejčastější chybové zprávy a selhávající routy |
| Data flow | Cesta úpravy: document-updater a Redis, project-history, history-v1, Mongo, objektové úložiště |
| Containers | Stav každého kontejneru, CPU, paměť, síť a disk, včetně kompilací v sandboxu |
| Jeden na službu | Služby Node.js, git-bridge (JVM), mongo a redis |

Prometheus sbírá `/metrics` služeb, `mongodb-exporter`, `redis-exporter`, `cadvisor` a `node-exporter`; Alloy posílá logy každého kontejneru projektu do Loki, kde je čtou filtry **Log search**, **Service** a **Log level** dashboardů. Jejich data jsou jen v kontejnerech, takže se při jejich opětovném vytvoření vymažou. cAdvisor běží privilegovaně a jen pro čtení čte `/`, `/sys`, data Dockeru a socket containerd hostitele; node-exporter čte `/` hostitele.

Dashboardy se generují: místo úprav souborů JSON změňte `develop/grafana/make-dashboards` a spusťte ho.

### Mailpit {#mailpit}

S `MAILPIT_ENABLED=true` posílá `web` každý e-mail do Mailpitu místo skutečného poštovního serveru a potvrzování e-mailů je zapnuté (`EMAIL_CONFIRMATION_DISABLED=false`). Aktivační odkazy, pozvánky do projektů, obnovení hesla a potvrzovací kódy pak můžete otevírat ze schránky.

### Nastavení Hoppscotch {#setup-hoppscotch}

#### Proxy pro požadavky API {#proxy-api-request}

Hoppscotch posílá požadavky z prohlížeče, který služby podle jejich jmen v Dockeru nedosáhne. Jeho proxy, Proxyscotch, běží uvnitř sítě Dockeru a je poskytována na `/proxy` adresy Hoppscotch. Otevřete [http://localhost:9170](http://localhost:9170/), přejděte do Settings → Interceptor, zvolte **Proxy** a nastavte Proxy URL na `http://localhost:9170/proxy`. Nastavení zůstane v prohlížeči.

#### Import API služeb {#import-the-service-apis}

`develop/hoppscotch/openapi/` obsahuje soubor OpenAPI pro interní API každé služby. V Hoppscotch otevřete Collections → Import → Import from File a vyberte všechny soubory najednou. Z každého souboru se stane kolekce, jejíž požadavky jdou na adresu služby v Dockeru. Stejné soubory jsou zobrazeny v sekci [API služeb](/cs/dev/service-api/overview).

#### Problémy s CSRF {#csrf-problems}

<Warning>

Pokud pomocí Postmanu nebo jiných ladicích nástrojů vytvoříte požadavek **POST**, můžete zjistit, že přihlášení je **zakázáno** a příčinou je chyba 403. Je to proto, že Overleaf je chráněn ověřováním **CSRF**.

</Warning>

<Frame>
  <img src="/images/dev/image-8.png" alt="" />
</Frame>

V konzoli můžete vidět:

<Frame>
  <img src="/images/dev/image-9.png" alt="" />
</Frame>

Abyste to při vývoji Overleafu vyřešili, musíte nastavit CSRF token. Zde je podrobný návod.

<Steps>
<Step title="Přidání Pre-Request skriptu">
Přidejte následující kód do Pre-Request

<Frame>
  <img src="/images/dev/image-10.png" alt="" />
</Frame>

Skript je následující:

```js wrap
pm.sendRequest("http://web:3000/dev/csrf", function (err, res) {
    if (err) {
        console.log(err);
        return;
    }

    // 1) Save CSRF token (/dev/csrf)
    const token = res.text().trim();
    pw.env.set("csrftoken", token);
    console.log("csrftoken =", token);

    const setCookieHeader = (res.headers || []).find(h => h.key?.toLowerCase() === "set-cookie")?.value;
    console.log("set-cookie =", setCookieHeader);

    if (!setCookieHeader) return;

    const cookiePair = setCookieHeader.split(";")[0].trim(); // overleaf.sid=...
    pw.env.set("cookie_header", cookiePair);
    console.log("cookie_header =", cookiePair);
});
```
</Step>

<Step title="Přidání hlaviček požadavku">
Musíte přidat následující hlavičky:

| Název hlavičky | Hodnota hlavičky    |
| -------------- | ------------------- |
| Content-Type   | `application/json`  |
| X-Csrf-Token   | `<<csrftoken>>`     |
| Cookie         | `<<cookie_header>>` |

<Frame>
  <img src="/images/dev/image-11.png" alt="" />
</Frame>
</Step>

<Step title="Přihlášení pomocí nástrojů API">
Nyní se můžete přihlásit pomocí svého uživatelského jména a hesla.

```json5
{
  "_csrf": "<<csrftoken>>",
  "email": "admin@overleaf.com",
  "password": "xxxxxx"
}
```

Takto vypadá odpověď, když zadáte nesprávné uživatelské jméno nebo heslo.

<Frame>
  <img src="/images/dev/image-12.png" alt="" />
</Frame>
</Step>
</Steps>
