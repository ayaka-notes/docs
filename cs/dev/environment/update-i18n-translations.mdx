---
title: Aktualizace překladů i18n
icon: language
---

V souboru `services/web/frontend/extracted-translations.json` se nacházejí extrahované překlady a webová aplikace Overleafu používá pouze překlady uvedené v tomto souboru.

Pokud jste přidali nějaký obsah, spusťte následující příkaz pro aktualizaci extrahovaných překladů.

```bash
user ➜ ~/overleaf-pro/develop (server-pro) $ bin/shell webpack
root@432836260f8a:/overleaf/services/web# npm run extract-translations
```

Obecně prosím needitujte textové soubory s překlady a přednostně používejte ty existující, protože všechny tyto soubory se aktualizují z upstreamu Overleafu nebo z překladatelské služby třetí strany.
