Abyste ušetřili čas a mohli vývojové prostředí rychle sestavit, nabízíme ještě jednu variantu konfigurace vývojového prostředí, a to GitHub Codespace.

## Návod ke konfiguraci

<Steps>
<Step title="Vytvoření Codespaces">
Kliknutím na následující tlačítko vytvoříte cloudový codespace pro vývoj server-pro.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/ayakaleaf-pro)

Doporučujeme zvolit **Machine Type** alespoň **4-core**. O větší typ stroje můžete požádat oficiální tým podpory GitHubu založením tiketu [zde](https://support.github.com/contact?tags=rr-codespaces%2Ccat_codespaces).

<Frame>
  <img src="/images/dev/image.png" alt="" />
</Frame>
</Step>

<Step title="Spuštění instalačního skriptu">
Než se codespace vytvoří, budete muset trpělivě počkat. Jakmile budete mít přístup k terminálu, spusťte následující příkaz:

```text
cd develop/
bin/setup
```

<Frame>
  <img src="/images/dev/image-1.png" alt="" />
</Frame>

<Warning>

Tento skript (`bin/setup`) vám umožní v co nejkratším čase nastavit vývojové prostředí na nejnovějším commitu větve `server-pro`. Nemusí být použitelný pro starší verze či jiné větve.

Vývojový Docker image sestavujeme každý den pomocí [GitHub Action](https://github.com/ayaka-notes/ayakaleaf-pro/actions).

</Warning>
</Step>

<Step title="Přístup k Launchpadu">
Přepněte na kartu portů, kde uvidíte seznam dostupných webových portů. Klikněte na port `80`. Nyní byste měli vidět stránku launchpadu.

<Frame>
  <img src="/images/dev/image-2.png" alt="" />
</Frame>

Uvidíte:

<Frame>
  <img src="/images/dev/image-3.png" alt="" />
</Frame>
</Step>

<Step title="Užijte si vývoj">
Teď je čas pro vás! Začněte vytvářet svou skvělou funkci. Pro zapnutí zobrazování změn v reálném čase je třeba spustit následující příkaz:

```bash title="bash" wrap
docker compose -f docker-compose.yml -f docker-compose.dev.yml -f ./docker-compose.image.yml up --no-deps --detach
```
</Step>
</Steps>
