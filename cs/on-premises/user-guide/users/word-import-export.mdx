## Import dokumentu {#import-a-document}

Tímto vytvoříte nový projekt LaTeX z dokumentu Word (`.docx`) nebo souboru Markdown (`.md`). Název projektu se převezme z názvu souboru.

<Steps>
<Step title="Otevřete dialog importu">
Na stránce projektů klikněte na **New project**. V části **Import** klikněte na **Word document** nebo **Markdown document**.

<Frame caption="Nabídka New project">
  <img src="/images/on-premises/word-import-menu.png" alt="Nabídka New project s položkami Word document a Markdown document v části Import" />
</Frame>
</Step>

<Step title="Vyberte soubor">
Klikněte na **Select .docx file** nebo soubor přetáhněte do dialogu. Pro Markdown se tlačítko jmenuje **Select .md file**. Import začne okamžitě.

<Frame caption="Výběr dokumentu Word">
  <img src="/images/on-premises/word-import-dialog.png" alt="Dialog Choose Word document s tlačítkem Select .docx file" />
</Frame>
</Step>

<Step title="Začněte upravovat">
Nový projekt se otevře se zprávou **Document ready for editing**. Klikněte na **Start editing**.

<Frame caption="Import je dokončen">
  <img src="/images/on-premises/word-import-ready.png" alt="Dialog Document ready for editing s tlačítkem Start editing" />
</Frame>
</Step>

<Step title="Zkontrolujte výsledek">
Dokument je teď v `main.tex` a jeho nadpisy jsou v osnově souboru. Kliknutím na **Recompile** zobrazíte PDF. Zkontrolujte formátování, zejména tabulky, obrázky a citace, které mohou vyžadovat úpravy.

<Frame caption="Importovaný projekt">
  <img src="/images/on-premises/word-import-project.png" alt="Importovaný projekt v editoru s main.tex, osnovou souboru a zkompilovaným PDF" />
</Frame>
</Step>
</Steps>

### Pokud import selže {#if-the-import-fails}

Pokud soubor nelze převést, dialog zobrazí **Your document couldn't be imported**. Rozbalením **Conversion error details** zjistíte proč. Žádný projekt se nevytvoří.

<Frame caption="Dokument, který nešlo importovat">
  <img src="/images/on-premises/word-import-error.png" alt="Dialog importu s chybovou zprávou a Conversion error details" />
</Frame>

Dialog přijímá jen zvolený typ. Soubor `.md` v dialogu pro Word zobrazí **You can only upload: .docx**.

## Export projektu {#export-a-project}

Otevřete projekt a klikněte na jeho název v horní části editoru. Klikněte na jednu z těchto možností:

| Možnost                              | Získáte                                       |
| ----------------------------------- | --------------------------------------------- |
| <strong>Export as Word document (.docx)</strong> | Soubor `.docx` pojmenovaný podle projektu        |
| <strong>Export as Markdown (.md)</strong>        | Soubor `.zip` s `main.md`                  |
| <strong>Export as HTML (.html)</strong>          | Soubor `.zip` s `main.html`                |

Stahování začne samo. Převod nedokáže zachovat veškeré formátování LaTeX, proto výsledek zkontrolujte.
