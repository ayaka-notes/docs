### Doktor

Overleaf Toolkit obsahuje praktický skript `doctor`, který pomáhá s laděním. Spusťte `bin/doctor` a skript vypíše informace o vašem hostitelském prostředí, vaší konfiguraci a závislostech, které Toolkit potřebuje. Tento výstup nám také může pomoci diagnostikovat problémy s vašimi instalacemi Ayakaleaf Pro.

<Info>

Uživatelé Overleaf Pro mohou [založit issue na GitHubu](https://github.com/ayaka-notes/overleaf/issues).

Je dobré do zprávy přiložit výstup skriptu `bin/doctor`.

</Info>

### Konzultace s Doktorem

```bash title="Run doctor"
bin/doctor
```

### Informace o hostiteli

Sekce `Host Information` obsahuje informace o stroji, na kterém Toolkit běží (například distribuci a vydání Linuxu).

<Accordion title="Příklad výstupu Host Information">

```text
- Host Information
    - Linux
    - Output of 'lsb_release -a':
            No LSB modules are available.
            Distributor ID:	Ubuntu
            Description:	Ubuntu 22.04.5 LTS
            Release:	22.04
            Codename:	jammy
```

</Accordion>

### Závislosti

Sekce `Dependencies` uvádí nástroje, které Toolkit ke své činnosti potřebuje. Pokud je nástroj k dispozici, bude uveden jako `status: present` spolu s informací o verzi. Pokud chybí, bude uveden jako `status: MISSING!` a na konec výstupu `doctor` se přidá varování.

<Accordion title="Příklad výstupu závislosti (k dispozici)">

```text
- docker
    - status: present
    - version info: Docker version 28.0.4, build b8034c0
```

</Accordion>

<Accordion title="Příklad výstupu závislosti (chybí)">

```text
- docker
    - status: MISSING!
```

</Accordion>

Pokud některé závislosti chybí, Toolkit téměř jistě nebude fungovat.

### Konfigurace

Sekce `Configuration` obsahuje informace o souborech v adresáři `config/`. Pro `config/overleaf.rc` vypíše doctor některé klíčové hodnoty. Chybějící soubory budou uvedeny jako `status: MISSING!` a na konec výstupu `doctor` se přidá varování.

<Accordion title="Příklad výstupu Configuration">

```text
====== Configuration ======
- config/version
    - status: present
    - version: 5.4.0
- config/overleaf.rc
    - status: present
    - values
        - OVERLEAF_DATA_PATH: /tmp/overleaf
        - SERVER_PRO: false
        - MONGO_ENABLED: false
        - REDIS_ENABLED: true
- config/variables.env
    - status: MISSING!
```

</Accordion>

Poznámky k výše uvedenému příkladu:

* `OVERLEAF_DATA_PATH` nastavená na `/tmp/overleaf` nemusí být bezpečným umístěním pro důležitá data.
* `MONGO_ENABLED: false` znamená, že Toolkit nezřídí vlastní MongoDB; v případě potřeby zajistěte, aby `MONGO_URL` odkazovala na externě spravovanou MongoDB.
* V příkladu chybí `config/variables.env`.

### Varování

Sekce `Warnings` shrnuje problémy zjištěné skriptem doctor. Pokud žádné problémy nejsou, tato sekce to uvede.

<Accordion title="Příklad výstupu Warnings">

```text
====== Warnings ======
- configuration file variables.env not found
- rc file, OVERLEAF_DATA_PATH not set
====== End =======
```

</Accordion>
