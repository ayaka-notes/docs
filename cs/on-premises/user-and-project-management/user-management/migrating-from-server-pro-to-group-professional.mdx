---
title: Migrace ze Server Pro na Group Professional
icon: rectangle-pro
noindex: true
---

Přechod z vlastní hostované instance Server Pro na nové cloudové předplatné Overleaf Group Professional je velká změna, a proto jsme připravili následující pokyny, aby tento proces proběhl co nejhladčeji.

Obecně navrhujeme tříměsíční období souběhu, které začíná datem vašeho obnovení. To znamená, že:

* Vaše stávající instance Server Pro i vaše nové předplatné Group Professional budou plně aktivní.
* Váš technický tým si může naplánovat čas na nastavení předplatného Group Professional a rozhodnout o budoucnosti vašeho on-premises nasazení Server Pro.
* A co je nejdůležitější, vaši uživatelé budou mít dostatek času na zkopírování svých projektů na novou platformu Overleaf Group Professional.

Tento stručný návod vás provede klíčovými kroky této migrace. Pojďme začít!

<Steps>
<Step title="Fáze 1: Nastavení a konfigurace">
(Odkaz: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-1-setup-and-configuration)

* Overleaf vytvoří vaše předplatné Group Professional a přidá vašeho hlavního administrátora.
* Váš skupinový administrátor bude moci zapnout [spravované uživatele (Managed Users)arrow-up-right](https://docs.overleaf.com/groups/user-management/managed-user-accounts), nakonfigurovat [jednotné přihlašování (SSO)arrow-up-right](https://docs.overleaf.com/groups/overleaf-group-single-sign-on/setting-up-group-sso) a [pozvat koncové uživatelearrow-up-right](https://docs.overleaf.com/groups/user-management/how-to-add-and-remove-users).

<Warning>

Zapnutí spravovaných uživatelů a zavedení SSO je povinným krokem pro soulad s FedRAMP® LI-SaaS. Pokud vaše organizace vyžaduje soulad s FedRAMP, nastavte spravované uživatele a SSO ještě před pozváním koncových uživatelů.

</Warning>
</Step>

<Step title="Fáze 2: Migrace uživatelů a správa dat">
(Odkaz: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-2-user-migration-and-data-management)

Toto je hlavní období migrace s následujícími povinnostmi:

#### Koncoví uživatelé

* Uživatelé by měli převést všechny projekty, které si chtějí ponechat, z vaší instance Server Pro do svých nových účtů na [overleaf.comarrow-up-right](http://overleaf.com/). Postup spočívá v [exportu projektůarrow-up-right](https://www.overleaf.com/learn/how-to/Exporting_your_work_from_Overleaf) ze Server Pro a jejich [nahráníarrow-up-right](https://www.overleaf.com/learn/how-to/Uploading_a_project) do účtu na [overleaf.comarrow-up-right](http://overleaf.com/). Pokud uživatel ještě nemá účet na [overleaf.comarrow-up-right](http://overleaf.com/), může se zaregistrovat na [overleaf.com/registerarrow-up-right](http://overleaf.com/register).

<Warning>

Tímto exportem se přenese pouze zdrojový kód projektu (LaTeX a binární soubory). Stávající nastavení projektu, nastavení sdílení, komentáře, sledované změny atd. se NEPŘENESOU. Uživatelé budou muset po migraci znovu pozvat své spolupracovníky.

</Warning>

#### Technický personál

* Během této fáze by měl váš technický tým naplánovat, jak po migraci naložit s on-premises instancí Server Pro a jejími daty.
* <strong>Záloha dat:</strong> Před vyřazením z provozu můžete exportovat všechny projekty a vytvořit archiv, díky kterému budete moci pomoci uživatelům, kteří zapomněli svou práci převést nebo stáhnout. Pokyny: https://docs.overleaf.com/on-premises/maintenance/data-and-backups/exporting-projects
* <strong>Vyřazení Server Pro z provozu:</strong> Po skončení období migrace a deaktivaci vašeho licenčního klíče máte pro samotnou instanci Server Pro dvě hlavní možnosti (viz další krok).
</Step>

<Step title="Možnosti vyřazení Server Pro z provozu">
<Steps>
<Step title="Úplná odinstalace Server Pro">
Odinstalací vyřadíte Server Pro z provozu a software zcela odstraníte.
</Step>

<Step title="Přechod na Community Edition">
Přechod zachová databázi uživatelů a projektů včetně úplné historie projektů tím, že instanci převede ze Server Pro na Community Edition.
</Step>
</Steps>

<Info>

Community Edition NEOBSAHUJE [izolované kompilace (Sandboxed Compiles)arrow-up-right](https://docs.overleaf.com/on-premises#overview-of-server-pro-and-community-edition) ani [LDAP](/cs/on-premises/configuration/overleaf-toolkit/authentication/ldap-authentication)/[SAML](/cs/on-premises/configuration/overleaf-toolkit/authentication/saml-authentication). Pokud se potřebujete vrátit k nativnímu ověřování (uživatelské jméno/heslo), viz: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-to-ldap-or-saml#going-the-other-way-switching-from-ldap-saml-back-to-native-authentication

Srovnání Server CE a Server Pro najdete zde: https://docs.overleaf.com/on-premises/welcome/server-pro-vs.-community-edition

</Info>
</Step>

<Step title="Fáze 3: Vyřazení Server Pro z provozu">
(Odkaz: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-3-server-pro-decommission)

* Tým Overleaf formálně deaktivuje váš licenční klíč Server Pro a po dokončení zašle potvrzení.
* V tu chvíli proveďte jednu z výše popsaných akcí vyřazení z provozu: úplně odinstalujte Server Pro, nebo přejděte na Community Edition.
</Step>
</Steps>

Další zdroje a odkazy uvedené výše zůstávají beze změny.
