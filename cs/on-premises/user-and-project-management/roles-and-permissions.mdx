### Účet

Z hlediska správy vlastního účtu jsou **všichni** uživatelé považováni za běžné uživatele – `Site Admins` ani `Template Users` **nezískávají** žádná další oprávnění. Existují však omezení akcí, které mohou běžní uživatelé provádět, v závislosti na způsobu jejich ověřování.

#### Nastavení

<strong>Typy ověřování: Interní účty | SSO (SAML/LDAP)</strong>

| Akce                                      | Interní účty | SSO (SAML/LDAP) |
| ----------------------------------------- | -----------: | --------------: |
| Aktualizace informací o účtu              |          Ano |              Ne |
| Změna hesla                               |          Ano |              Ne |
| Generování ověřovacích tokenů Git bridge  |          Ano |             Ano |
| Smazání ověřovacích tokenů Git bridge     |          Ano |             Ano |
| Správa relací                             |          Ano |             Ano |

<Info>

Integrace Git Bridge je k dispozici **pouze** v Server Pro. Další informace najdete v části [Server Pro vs. Community Edition](/cs/on-premises/readme/ayakaleaf-pro-vs-server-pro).

</Info>

### IDE editoru

Z hlediska IDE editoru Overleaf můžete mít jednu z následujících rolí: `Project Owner`, `Editor`, `Reviewer`, `Viewer`, `Site Administrator` nebo `Template User`.

<Info>

Server Pro a Community Edition podporují poskytování anonymního přístupu k projektům **pouze pro čtení** a **pro čtení i zápis**.

Další informace najdete u proměnných prostředí `OVERLEAF_ALLOW_PUBLIC_ACCESS` a `OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` [zde](/cs/on-premises/configuration/overleaf-toolkit/environment-variables).

</Info>
