title: Overleaf Server Pro vs. Ayakaleaf Pro

icon: scale-balanced
---

<Info>

Ayakaleaf Pro je rozšířená implementace Overleaf Community Edition, která nabízí všechny prémiové funkce ze Server Pro _**zdarma**_. Na rozdíl od Overleaf Common dostupného na [https://www.overleaf.com/](https://www.overleaf.com/) u nás neplatí žádná omezení doby kompilace ani licenční požadavky na počet uživatelů a svá data můžete plně hostovat sami, což zajišťuje absolutní bezpečnost.

Overleaf Server Pro je komerční self-hosted nasazení Overleafu s oficiální podporou. Více informací o Server Pro najdete na stránce [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud).

</Info>

<Warning>

Overleaf Community Edition je určena pro prostředí, ve kterých jsou **všichni** uživatelé důvěryhodní. Community Edition **není** vhodná pro scénáře, kde je vyžadována izolace uživatelů, protože Sandbox Compiles nejsou k dispozici.

Bez sandboxingu běží kompilace LaTeXu se stejnými oprávněními jako kontejner, což umožňuje přístup k jeho souborovému systému, síti a proměnným prostředí. To vytváří riziko úniku dat nebo kompromitace systému. Kompilace bez sandboxu by se měly používat pouze v plně důvěryhodných prostředích; pro víceuživatelská nebo produkční nasazení se Sandbox Compiles důrazně doporučují.

Další informace o Sandbox Compiles najdete v naší [dokumentaci](/cs/on-premises/configuration/overleaf-toolkit/sandboxed-compiles).

</Warning>

### Komunitní podpora

Uživatelům self-hosted instance Overleafu poskytuje podporu komunita prostřednictvím [Issues](https://github.com/ayaka-notes/overleaf-pro/issues) na GitHubu.

Abyste zůstali na podporované verzi, můžete si ověřit, jakou verzi Overleafu provozujete, porovnáním výstupu níže uvedeného příkazu s Image ID zveřejněnými v poznámkách k vydání.

```bash
docker inspect --format '{{.Image}}' sharelatex | awk -F: '{print substr($2, 1, 12)}'
```
