### Nastavení integrace se Zotero

1. Otevřete [tento odkaz](https://www.zotero.org/oauth/apps) a vytvořte klienta Zotero OAuth (jak ukazuje obrázek)
2. Zvolte **Application Type**: **Browser**
3. Nastavte Callback URL na `${OVERLEAF_SITE_URL}/user/zotero/oauth/callback`
4. Nakonfigurujte svůj soubor `config/variables.env`

<Frame>
  <img src="/images/on-premises/image-41.png" alt="" width="375" />
</Frame>

```dotenv title="config/variables.env"
#################
#    Zotero     #
#################
# 'zotero' must be in ENABLED_LINKED_FILE_TYPES (set in develop/docker-compose.yml)
ENABLED_LINKED_FILE_TYPES=project_file,project_output_file,url,zotero

# From a Zotero OAuth client (register at https://www.zotero.org/oauth/apps)
# Application Type: Browser 
# Callback URL -> ${OVERLEAF_SITE_URL}/user/zotero/oauth/callback
ZOTERO_CLIENT_ID=
ZOTERO_CLIENT_SECRET=
# Encrypts the Zotero API key in mongo (set in dev to avoid writing a key file
# to /var/lib/overleaf/data, which the dev web container can't create)
# How to generate: `openssl rand -hex 32`
ZOTERO_CIPHER_PASSWORD=dev-zotero-cipher-password
# Optional: route the module's server-side Zotero requests (OAuth + API) through
# an HTTP proxy (must be reachable from the web container; same as github-sync)
# http://10.0.0.1:10808
# (Optional) ZOTERO_PROXY_URL=
```

### Poznámky

<Warning>

Při upgradu existující instalace se soubory bibliografie propojenými se Zotero na znovu vydanou verzi 6.3.0 postupujte podle [pokynů k migraci Zotero / Mendeley](/cs/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention"). Nové instalace tuto migraci nepotřebují.

</Warning>

<Danger>

Protože Ayakaleaf je platforma pro spolupráci, bude z bezpečnostních důvodů od verze 6.3.0 aktualizovat importovaný referenční soubor `bib` smět pouze jeho původní tvůrce.

</Danger>

Předpokládejme například, že vlastník projektu, uživatel A, povolí sdílení odkazem a vytvoří v projektu soubor `test.bib`, který propojí se svým vlastním účtem Zotero. Pokud k projektu přistoupí přes sdílený odkaz jiný uživatel, uživatel B, bude moci soubor `test.bib` číst a stahovat, ale nebude jej smět aktualizovat ani znovu importovat ze Zotero. Aktualizace může provádět pouze uživatel A jakožto původní tvůrce referenčního souboru. Jinými slovy, oprávnění aktualizovat soubor `.bib` má pouze jeho původní tvůrce.
