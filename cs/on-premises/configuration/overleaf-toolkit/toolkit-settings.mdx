Tato stránka popisuje proměnné prostředí podporované v souboru `config/overleaf.rc` pro nasazení pomocí Toolkitu.

Soubor `config/overleaf.rc` se skládá z definic proměnných ve tvaru `NAME=value`. Řádky začínající znakem `#` jsou považovány za komentáře.

<Info>

Po jakékoli změně v `overleaf.rc` nebo `variables.env` je nutné znovu vytvořit kontejnery Docker spuštěním `bin/up`.

</Info>

## Kontejner

### `sharelatex`

| Název                        | Popis                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PROJECT_NAME`               | <p>Nastavuje hodnotu příznaku `--project-name` předávaného do `docker-compose`. To je užitečné při provozu více instancí Overleafu na jednom hostiteli, protože každá instance může mít jiný název projektu.<br /><br />- <strong>Výchozí</strong>: `overleaf`</p>                                                                                                                                                                                                                                                 |
| `OVERLEAF_IMAGE_NAME`        | <p>Docker image používaný aplikačním kontejnerem Server Pro/CE. Jde pouze o název Docker image; tag Docker image se načítá z `config/version`.<br /><br />- <strong>Výchozí:</strong><br />- Server Pro: `quay.io/sharelatex/sharelatex-pro`<br />- Community Edition: `sharelatex/sharelatex`</p>                                                                                                                                                                                                 |
| `SERVER_PRO`                 | <p>Pokud je nastaveno na `true`, Toolkit použije image Server Pro (`quay.io/sharelatex/sharelatex-pro`) místo výchozího image Server CE (`sharelatex/sharelatex`).<br /><br />- <strong>Výchozí</strong>: `false`</p>                                                                                                                                                                                                                                                                   |
| `GIT_BRIDGE_ENABLED`         | <p>Nastavením na `true` povolíte funkci git-bridge (pouze Server Pro). Další informace najdete v uživatelské dokumentaci <a href="https://www.overleaf.com/learn/how-to/Git_integration">https://www.overleaf.com/learn/how-to/Git_integration</a>.<br /><br />- <strong>Výchozí:</strong> `false`</p>                                                                                                                                                                                                                        |
| `GIT_BRIDGE_IMAGE`           | <p>Docker image používaný kontejnerem git-bridge (pouze Server Pro). Jde pouze o název Docker image; tag Docker image se načítá z `config/version`.<br /><br />- <strong>Výchozí:</strong> `quay.io/sharelatex/git-bridge`</p>                                                                                                                                                                                                                                                                              |
| `GIT_BRIDGE_DATA_PATH`       | Nastavuje cestu k adresáři, který bude připojen do kontejneru `git-bridge` (pouze Server Pro) a používán k ukládání git repozitářů. Může jít o úplnou cestu (začínající `/`) nebo o cestu relativní vůči základnímu adresáři Toolkitu.                                                                                                                                                                                                                                                                                     |
| `GIT_BRIDGE_LOG_LEVEL`       | <p>Konfiguruje úroveň logování kontejneru `git-bridge`. Dostupné úrovně: `TRACE`, `DEBUG`, `INFO`, `WARN`, `ERROR`.<br /><br />- <strong>Výchozí:</strong> `INFO`</p>                                                                                                                                                                                                                                                                                       |
| `SIBLING_CONTAINERS_ENABLED` | <p>Pokud je nastaveno na `true`, Toolkit použije techniku <strong>Sibling Containers</strong> pro kompilaci projektů v oddělených sandboxech, s vlastním kontejnerem Docker pro každý projekt. Další informace najdete v dokumentaci &#x3C;server-pro-only-configuration/sandboxed-compiles>.<br /><br />- <strong>Vyžaduje:</strong> `SERVER_PRO=true`<br />- <strong>Výchozí:</strong> `true`</p>                                                                                                    |
| `SIBLING_CONTAINERS_PULL`    | <p>Pokud je nastaveno na `true`, Toolkit při použití příkazu `bin/up` automaticky stáhne všechny images TeX Live nastavené pomocí `ALL_TEX_LIVE_DOCKER_IMAGES` v souboru <strong>config/variables.env</strong>.<br /><br />- <strong>Výchozí:</strong> `true`</p>                                                                                                                                                                                                                                      |
| `DOCKER_SOCKET_PATH`         | <p>Nastavuje cestu k socketu Dockeru na hostitelském počítači (počítači, na kterém běží Toolkit). Pokud je `SIBLING_CONTAINERS_ENABLED` nastaveno na `true`, socket bude připojen do kontejneru, aby kompilační služba mohla na hostiteli spouštět nové kontejnery Docker.<br /><br />- <strong>Vyžaduje:</strong> `SIBLING_CONTAINERS_ENABLED=true`<br />- <strong>Výchozí:</strong> `/var/run/docker.sock`</p>                                                                                               |
| `OVERLEAF_DATA_PATH`         | <p>Nastavuje cestu k adresáři, který bude připojen do hlavního kontejneru `sharelatex` a používán k ukládání dat kompilace. Může jít o úplnou cestu (začínající `/`) nebo o cestu relativní vůči základnímu adresáři Toolkitu.<br /><br />- <strong>Výchozí:</strong> `data/overleaf`</p>                                                                                                                                                                                                               |
| `OVERLEAF_LISTEN_IP`         | <p>Nastavuje IP adresu (adresy) hostitele, na kterou se kontejner naváže. Pokud je například nastaveno `0.0.0.0`, webové rozhraní bude dostupné na libovolné IP adrese hostitele. Pro přímý přístup ke kontejneru musí být hodnota `OVERLEAF_LISTEN_IP` nastavena na vaši veřejnou IP adresu. Nastavení `OVERLEAF_LISTEN_IP` na `0.0.0.0` nebo na externí IP adresu hostitele obvykle způsobí chyby při použití společně s .<br /><br />- <strong>Výchozí:</strong> `127.0.0.1`</p> |
| `OVERLEAF_PORT`              | <p>Nastavuje port hostitele, na který se kontejner naváže. Pokud je například nastaveno `8099` a `OVERLEAF_LISTEN_IP` je nastaveno na `127.0.0.1`, webové rozhraní bude dostupné na `http://localhost:8099`.<br /><br />- <strong>Výchozí:</strong> `80`</p>                                                                                                                                                                                                                        |
| `OVERLEAF_LOG_PATH`          | <p>Nastavuje cestu k adresáři, který bude připojen do hlavního kontejneru `sharelatex` a používán ke zpřístupnění aplikačních logů na hostiteli Dockeru. Může jít o úplnou cestu (začínající `/`) nebo o cestu relativní vůči základnímu adresáři Toolkitu. Odstraněním této položky konfigurace bind-mount zakážete. Pokud není nastaveno, logy budou při opětovném vytvoření kontejneru zahozeny.<br /><br />Informace o logování viz .<br /><br />- <strong>Výchozí:</strong> nenastaveno</p>                                 |

### `mongo`

| Název             | Popis                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `MONGO_ENABLED`   | <p>Pokud je nastaveno na `true`, Toolkit vytvoří kontejner MongoDB, který bude hostovat databázi. Pokud je nastaveno na `false`, tento kontejner se nevytvoří a systém místo něj použije databázi MongoDB určenou pomocí `MONGO_URL`.<br /><br />- <strong>Výchozí</strong>: `true`</p>                                                                                                                                 |
| `MONGO_URL`       | <p>Určuje URL pro připojení k MongoDB, která se použije, když je `MONGO_ENABLED` nastaveno na `false`.<br /><br />- <strong>Výchozí</strong>: nenastaveno</p>                                                                                                                                                                                                                                                                                                           |
| `MONGO_DATA_PATH` | <p>Nastavuje cestu k adresáři, který bude připojen do kontejneru `mongo` a používán k ukládání databáze MongoDB. Může jít o úplnou cestu (začínající `/`) nebo o cestu relativní vůči základnímu adresáři toolkitu. Tato volba ovlivňuje pouze lokální kontejner `mongo`, který se vytváří, když je `MONGO_ENABLED` nastaveno na `true`.<br /><br />- <strong>Výchozí</strong>: `data/mongo`</p> |
| `MONGO_IMAGE`     | <p>Docker image používaný kontejnerem MongoDB. Jde pouze o název Docker image; tag Docker image patří do `MONGO_VERSION` (viz níže).<br /><br />- <strong>Výchozí:</strong> `mongo`</p>                                                                                                                                                                                                                             |
| `MONGO_VERSION`   | <p>Verze MongoDB používaná kontejnerem MongoDB. Hodnota musí začínat hlavní verzí MongoDB a tečkou, např. `6.0` nebo `6.0-with-suffix`.<br /><br />- <strong>Výchozí:</strong> `6.0`</p>                                                                                                                                                                                                                             |

### `nginx`

| Název                  | Popis                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `NGINX_ENABLED`        | <p>Pokud je nastaveno na `true`, Toolkit vytvoří kontejner NGINX, který bude fungovat jako TLS proxy.<br /><br />- <strong>Výchozí</strong>: `false`</p>                                                                                                                                                                                                                                                                                                                                 |
| `NGINX_CONFIG_PATH`    | <p>Cesta ke konfiguračnímu souboru NGINX, který se použije pro TLS proxy.<br /><br />- <strong>Výchozí</strong>: `config/nginx/nginx.conf`</p>                                                                                                                                                                                                                                                                                                                                                            |
| `NGINX_TLS_LISTEN_IP`  | <p>Nastavuje IP adresu (adresy) hostitele, na kterou se kontejner TLS proxy naváže pro HTTPS. Pokud je například nastaveno `0.0.0.0`, webové rozhraní HTTPS bude dostupné na libovolné IP adrese hostitele. Obvykle by mělo být nastaveno na externí IP adresu hostitele.<br /><br />- <strong>Výchozí</strong>: `127.0.1.1`</p>                                                                                                                                                       |
| `NGINX_HTTP_LISTEN_IP` | <p>Nastavuje IP adresu (adresy) hostitele, na kterou se kontejner TLS proxy naváže pro přesměrování HTTP. Pokud je například nastaveno `127.0.1.1`, HTTP připojení na `127.0.1.1` budou přesměrována na webové rozhraní HTTPS. Obvykle by mělo být nastaveno na externí IP adresu hostitele. Nenastavujte `0.0.0.0`, protože to obvykle způsobí konflikt s `OVERLEAF_LISTEN_IP`.<br /><br />- <strong>Výchozí</strong>: `127.0.1.1`</p> |
| `NGINX_HTTP_PORT`      | <p>Nastavuje port hostitele, na který se kontejner TLS proxy naváže pro HTTP.<br /><br />- <strong>Výchozí</strong>: `80`</p>                                                                                                                                                                                                                                                                                                                                                                  |
| `TLS_PORT`             | <p>Nastavuje port hostitele, na který se kontejner TLS proxy naváže pro HTTPS.<br /><br />- <strong>Výchozí</strong>: `443`</p>                                                                                                                                                                                                                                                                                                                                                                |
| `TLS_PRIVATE_KEY_PATH` | <p>Cesta k privátnímu klíči, který se použije pro TLS proxy.<br /><br />- <strong>Výchozí</strong>: `config/nginx/certs/overleaf_key.pem`</p>                                                                                                                                                                                                                                                                                                                                                      |
| `TLS_CERTIFICATE_PATH` | <p>Cesta k veřejnému certifikátu, který se použije pro TLS proxy.<br /><br />- <strong>Výchozí</strong>: `config/nginx/certs/overleaf_certificate.pem`</p>                                                                                                                                                                                                                                                                                                                                       |
