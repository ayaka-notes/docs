Tato stránka popisuje proměnné prostředí, které jsou podporovány v souboru `config/variables.env` při nasazení pomocí Toolkitu.

Soubor `config/variables.env` se skládá z definic proměnných ve tvaru `NAME=value`; řádky začínající znakem `#` jsou považovány za komentáře.

<Info>

Po jakékoli změně v `overleaf.rc` nebo `variables.env` je nutné znovu vytvořit Docker kontejnery spuštěním `bin/up`.

</Info>

### Všechny verze

Tyto proměnné prostředí jsou kompatibilní se Server CE i Server Pro a umožňují snadnou migraci mezi těmito dvěma on-premise verzemi. Lze je také používat jak při nasazení pomocí Toolkitu, tak pomocí Docker Compose.

<Info>

Dříve měly tyto proměnné prostředí místo předpony `OVERLEAF_` předponu `SHARELATEX_`.

</Info>

<Info>

Při použití přihlašovacího systému Overleafu (lokální účty), nikoli SSO možnosti jako LDAP, je možné uživatelům vynutit omezení hesel. U SSO účtů vynucuje zásady hesel váš poskytovatel identity nebo adresářová služba, což navíc umožňuje podporu vícefaktorové autentizace.

</Info>
