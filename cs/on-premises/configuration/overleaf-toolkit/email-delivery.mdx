Overleaf podporuje odesílání e-mailů dvěma způsoby: pomocí protokolu Simple Mail Transfer Protocol (SMTP) a [Amazon Simple Email Service (SES)](https://aws.amazon.com/ses/). SMTP lze použít, pokud máte na svém localhostu zapnutý e-mailový server, který naslouchá lokálním připojením.

## Konfigurace

E-mail se konfiguruje pomocí následujících proměnných prostředí.

#### Konfigurace odesílatele

| Název                         | Popis                                                                                                                                                |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | <p>Adresa odesílatele, např. <a href="mailto:support@mycompany.com">`'support@mycompany.com'`</a><br /><br />- <strong>Povinné</strong>: ano</p> |
| `OVERLEAF_EMAIL_REPLY_TO`     | Adresa pro odpověď, např. `'noreply@mycompany.com'`                                                                                                  |

#### SMTP

| Název                                   | Popis                                                                                                                                                                                                                                                                    |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST`              | Název hostitele nebo IP adresa, ke které se připojit. Musí být dostupná z kontejneru Docker                                                                                                                                                                              |
| `OVERLEAF_EMAIL_SMTP_PORT`              | Port, ke kterému se připojit                                                                                                                                                                                                                                             |
| `OVERLEAF_EMAIL_SMTP_SECURE`            | Pokud je `true`, připojení k serveru použije TLS. Pokud je `false` nebo není nastaveno, TLS se použije, pokud server podporuje rozšíření `STARTTLS`. Ve většině případů nastavte tuto hodnotu na `true`, pokud se připojujete k portu `465`. Pro port `587` nebo `25` ponechte `false` |
| `OVERLEAF_EMAIL_SMTP_USER`              | Uživatelské jméno, které se má použít k ověření vůči SMTP serveru                                                                                                                                                                                                        |
| `OVERLEAF_EMAIL_SMTP_PASS`              | Heslo přidružené k uživatelskému jménu SMTP                                                                                                                                                                                                                              |
| `OVERLEAF_EMAIL_SMTP_TLS_REJECT_UNAUTH` | Pokud je `false`, umožní připojení k TLS serveru se self-signed nebo neplatným TLS certifikátem                                                                                                                                                                          |
| `OVERLEAF_EMAIL_SMTP_IGNORE_TLS`        | Pokud je `true` a `OVERLEAF_EMAIL_SMTP_SECURE` je `false`, TLS se nepoužije, ani když server podporuje rozšíření `STARTTLS`                                                                                                                                             |
| `OVERLEAF_EMAIL_SMTP_NAME`              | Volitelný název hostitele pro ověření TLS, pokud byl `OVERLEAF_EMAIL_SMTP_HOST` nastaven na IP adresu; výchozí hodnotou je název hostitele počítače.                                                                                                                    |
| `OVERLEAF_EMAIL_SMTP_LOGGER`            | Pokud je `true`, vypisuje logovací zprávy do `web.log`.                                                                                                                                                                                                                  |

#### Rozhraní SMTP služby Amazon SES

Více o odesílání e-mailů pomocí rozhraní SMTP služby Amazon SES si můžete přečíst [zde](https://docs.aws.amazon.com/ses/latest/dg/send-email-smtp.html).

| Název                      | Popis                                                                                      |
| -------------------------- | ------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST` | Název hostitele nebo IP adresa, ke které se připojit. Musí být dostupná z kontejneru Docker |
| `OVERLEAF_EMAIL_SMTP_PORT` | Port, ke kterému se připojit                                                               |
| `OVERLEAF_EMAIL_SMTP_USER` | Uživatelské jméno, které se má použít k ověření vůči SMTP serveru                          |
| `OVERLEAF_EMAIL_SMTP_PASS` | Heslo přidružené k uživatelskému jménu SMTP                                                |

#### Amazon SES API

Více o odesílání e-mailů pomocí Amazon SES API si můžete přečíst [zde](https://docs.aws.amazon.com/ses/latest/dg/send-email-api.html).

| Název                                  | Popis                                       |
| -------------------------------------- | ------------------------------------------- |
| `OVERLEAF_EMAIL_AWS_SES_ACCESS_KEY_ID` | Přístupový klíč při použití AWS SES         |
| `OVERLEAF_EMAIL_AWS_SES_SECRET_KEY`    | Tajný klíč při použití AWS SES              |
| `OVERLEAF_EMAIL_AWS_SES_REGION`        | Pokud není nastaveno, výchozí region je US-EAST-1 |

#### AWS SES s rolemi instance

| Název                   | Popis                                                                                                                            |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_DRIVER` | Pokud je nastaveno na `ses`, e-mailový systém použije metodu SES API a k odesílání e-mailů se spolehne na nakonfigurované role instance. |
