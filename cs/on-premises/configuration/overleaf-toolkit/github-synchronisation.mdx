### Nastavení synchronizace s GitHubem

<Warning>

Před použitím synchronizace s GitHubem musíte nejprve povolit [git-bridge](/cs/on-premises/configuration/overleaf-toolkit/git-integration).

```dotenv title="config/overleaf.rc"
GIT_BRIDGE_ENABLED=true
```

</Warning>

Navštivte [nastavení pro vývojáře](https://github.com/settings/developers), vytvořte svou GitHub OAuth aplikaci a zkopírujte její `CLIENT_ID` a `SECRET`.

**Poznámka**: vaše OAuth callback URL je: `${OVERLEAF_SITE_URL}/user/github-sync/oauth2/callback`.

Poté přidejte následující nastavení do souborů s proměnnými prostředí Overleafu.

```dotenv title="config/variables.env" wrap
# used to encrypt the user's GitHub access token.
# How to generate: `openssl rand -hex 32`
GITHUB_TOKEN_CIPHER_PASSWORD=0123456789ABCDEFG # changed to yours

# Github Sync Settings
GITHUB_SYNC_ENABLED=true
GITHUB_SYNC_CLIENT_ID=
GITHUB_SYNC_CLIENT_SECRET=

# OAuth callback is: ${OVERLEAF_SITE_URL}/user/github-sync/oauth2/callback
# (Optional) GITHUB_SYNC_PROXY_URL=http://10.0.0.1:10808
```

<Warning>

Před konfigurací OAuth callback URL na GitHubu se ujistěte, že je `OVERLEAF_SITE_URL` nastaveno správně.

</Warning>

Pokud se nacházíte v pevninské Číně, možná budete muset pro přístup ke GitHubu nakonfigurovat proxy. Nastavte následující proměnnou prostředí: `GITHUB_SYNC_PROXY_URL=http://10.0.0.1:10808`.

<Warning>

Jako hostitele proxy nepoužívejte `127.0.0.1`. Pokud proxy běží na hostitelském serveru, použijte LAN IP adresu serveru (např. `192.168.1.xx`) a ujistěte se, že je proxy nakonfigurována tak, aby přijímala připojení ze zařízení v místní síti.

</Warning>
