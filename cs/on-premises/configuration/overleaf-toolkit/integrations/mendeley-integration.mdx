<Info>

Tuto funkci poskytuje [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) s podporou OAuth 2.0 a je dostupná od verze v6.3.0. Pokud narazíte na jakékoli problémy, uvítáme vaši zpětnou vazbu.

</Info>

#### Nastavení integrace Mendeley

1. Přejděte na [tento odkaz](https://dev.mendeley.com/myapps.html) a zaregistrujte OAuth aplikaci Mendeley
2. Nastavte **Redirect URL** na: `${OVERLEAF_SITE_URL}/user/mendeley/oauth/callback`
3. Poznamenejte si vygenerované **ID** (obvykle číselné, např. `24061` jako níže) a **Secret** vaší aplikace
4. Upravte svůj soubor `config/variables.env`&#x20;
5. Ponechte Authorisation Flow: Elsevier (doporučeno)

<Frame>

</Frame>

```dotenv title="config/variables.env"
#################
#   Mendeley    #
#################
# 'mendeley' must be in ENABLED_LINKED_FILE_TYPES (keep 'zotero' too if you use both)
ENABLED_LINKED_FILE_TYPES=project_file,project_output_file,url,mendeley

# From a Mendeley OAuth application (register at https://dev.mendeley.com/myapps.html)
# Redirect URL -> ${OVERLEAF_SITE_URL}/user/mendeley/oauth/callback
MENDELEY_CLIENT_ID=
MENDELEY_CLIENT_SECRET=
# Encrypts the Mendeley OAuth tokens in mongo; if unset, a key file is generated
# in /var/lib/overleaf/data on first use
# How to generate: `openssl rand -hex 32`
MENDELEY_CIPHER_PASSWORD=
# Optional: route the module's server-side Mendeley requests (OAuth + API) through
# an HTTP proxy (must be reachable from the web container; same as github-sync)
# http://10.0.0.1:10808
# (Optional) MENDELEY_PROXY_URL=
```

<Info>

&#x20;`mendeley` musí být uveden v `ENABLED_LINKED_FILE_TYPES` (pokud používáte obojí, ponechte v seznamu i `zotero`). `MENDELEY_CLIENT_ID` a `MENDELEY_CLIENT_SECRET` získáte ze své zaregistrované OAuth aplikace. Heslo pro šifrování (cipher password) šifruje OAuth tokeny Mendeley v MongoDB (vygenerujte jej pomocí `openssl rand -hex 32`); bez něj se při prvním použití vygeneruje soubor s klíčem v datovém svazku. Volitelně můžete nastavit `MENDELEY_PROXY_URL`, aby byly serverové požadavky na Mendeley (OAuth + API) směrovány přes HTTP proxy dostupnou z webového kontejneru.

</Info>

### Poznámky

<Warning>

Při upgradu existující instalace s propojenými bibliografickými soubory Mendeley na znovu vydanou verzi 6.3.0 postupujte podle [pokynů k migraci Zotero / Mendeley](/cs/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention"). Nové instalace tuto migraci nepotřebují.

</Warning>

<Danger>

Protože Ayakaleaf je platforma pro spolupráci, z důvodu zvýšení bezpečnosti bude od verze 6.3.0 aktualizovat importovaný soubor referencí `bib` oprávněn pouze jeho původní tvůrce.

</Danger>

Předpokládejme například, že vlastník projektu, uživatel A, povolí sdílení odkazem a vytvoří v projektu soubor `test.bib`, který propojí se svým vlastním účtem Zotero. Pokud k projektu přistoupí přes sdílený odkaz jiný uživatel, uživatel B, bude moci `test.bib` stále číst a stahovat, ale nebude mu dovoleno soubor aktualizovat ani znovu importovat ze Zotera. Aktualizace může provádět pouze uživatel A jako původní tvůrce souboru referencí. Jinými slovy, oprávnění soubor `.bib` aktualizovat má pouze jeho původní tvůrce.
