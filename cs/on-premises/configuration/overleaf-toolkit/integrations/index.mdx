Všechny integrace jsou ve výchozím stavu vypnuté, s výjimkou Overleaf Import API. Synchronizace s GitHubem, GitLabem, Gitea a Dropboxem a také MCP server navíc vyžadují [integraci s Gitem](/cs/on-premises/configuration/overleaf-toolkit/integrations/git-integration). Po zapnutí některé z nich znovu vytvořte kontejnery pomocí `bin/up -d`.
