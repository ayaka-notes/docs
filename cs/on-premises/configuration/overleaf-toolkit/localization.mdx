### Konfigurace i18n v Overleafu

<Info>

Tento dokument popisuje, jak nakonfigurovat internacionalizaci (i18n) pro self-hosted instanci **Overleafu**.

</Info>

Overleaf byl přeložen do mnoha jazyků. S vhodnou konfigurací můžete:

* Provozovat instanci Overleafu v **jediném pevně daném jazyce**, nebo
* Povolit **více jazyků** a umožnit uživatelům dynamicky přepínat jazyk, podobně jako na `www.overleaf.com`.

***

#### Konfigurace jednoho jazyka

Jazyk webu se nastavuje pomocí proměnné prostředí `OVERLEAF_SITE_LANGUAGE` (nebo `SHARELATEX_SITE_LANGUAGE` pro Overleaf ve verzích **4.x a starších**).

Podporované kódy jazyků:

* `en` - angličtina (výchozí)
* `es` - španělština
* `pt` - portugalština
* `de` - němčina
* `fr` - francouzština
* `cs` - čeština
* `nl` - nizozemština
* `sv` - švédština
* `it` - italština
* `tr` - turečtina
* `zh-CN` - čínština (zjednodušená)
* `no` - norština
* `da` - dánština
* `ru` - ruština
* `ko` - korejština
* `ja` - japonština
* `pl` - polština
* `fi` - finština

Výchozím jazykem je angličtina. Chcete-li změnit jazyk rozhraní (například na zjednodušenou čínštinu), přidejte do `config/variables.env` následující řádek:

```bash title="config/variables.env"
OVERLEAF_SITE_LANGUAGE=zh-CN
```

Poté konfiguraci použijte:

```bash
bin/up
```

Po restartu služeb by se nové nastavení mělo projevit v jazyce nabídek webového rozhraní.

#### Konfigurace více jazyků

Aby uživatelé mohli **přepínat jazyky bez odhlášení**, musí být vaše instance Overleafu nakonfigurována tak, aby obsluhovala různé jazyky podle názvů domén.

Tato část předpokládá, že:

* Vaše primární doména je `overleaftest.com`
* Máte **wildcard certifikát TLS** (např. `*.overleaftest.com`)
* **Nepoužíváte `localhost`** (protože ten nepodporuje směrování jazyků podle subdomén)

Pro lokální testování můžete použít doménu jako `dev-overleaf.com`.

<Steps>
<Step title="Konfigurace TLS proxy (Nginx)">
Vaše reverzní TLS proxy musí předávat původní hlavičku `Host`, aby Overleaf mohl určit, na kterou jazykovou doménu uživatel přistoupil.

Ujistěte se, že je přítomna následující direktiva:

```nginx
proxy_set_header Host $host;
```

Zde je příklad konfigurace Nginx:

```nginx
server {
    listen 443 ssl;
    server_name    _; # Catch all, see http://nginx.org/en/docs/http/server_names.html
    server_name *.overleaftest.com;
    ssl_certificate /etc/nginx/ssl/nginx.crt;
    ssl_certificate_key /etc/nginx/ssl/nginx.key;
    ssl_protocols               TLSv1 TLSv1.1 TLSv1.2;
    ssl_prefer_server_ciphers   on;
    # used cloudflares ciphers https://github.com/cloudflare/sslconfig/blob/master/conf
    ssl_ciphers EECDH+CHACHA20:EECDH+AES128:RSA+AES128:EECDH+AES256:RSA+AES256:EECDH+3DES:RSA+3DES:!MD5;

    # config to enable HSTS(HTTP Strict Transport Security) https://developer.mozilla.org/en-US/docs/Security/HTTP_Strict_Transport_Security
    # to avoid ssl stripping https://en.wikipedia.org/wiki/SSL_stripping#SSL_stripping	
    add_header Strict-Transport-Security "max-age=31536000; includeSubdomains;";
    server_tokens off;
    add_header X-Frame-Options SAMEORIGIN;
    add_header X-Content-Type-Options nosniff;
    client_max_body_size 50M;

    location / {
        proxy_pass http://localhost:5000; # change to whatever host/port the docker container is listening on.
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 3m;
        proxy_send_timeout 3m;
        
        # add this to your nginx conf
        proxy_set_header Host $host;
    }
}
```
</Step>

<Step title="Konfigurace domény cookies">
Aby se uživatelé při přepínání jazyků neodhlašovali, musí být cookies sdíleny napříč jazykovými subdoménami.

Přidejte do `config/variables.env` následující řádek:

```env title="config/variables.env"
# Note the leading dot
COOKIE_DOMAIN=.overleaftest.com
```

Tím zajistíte, že ověřovací cookies budou platné pro všechny subdomény pod `overleaftest.com`.
</Step>

<Step title="Mapování jazyků na domény">
Dále definujte, jak se kódy jazyků mapují na subdomény, pomocí\
`OVERLEAF_LANG_DOMAIN_MAPPING`.

#### Příklad konfigurace

```dotenv title="config/variables.env" wrap
OVERLEAF_LANG_DOMAIN_MAPPING='{"www": {"lngCode": "en","url": "https:\/\/www.overleaftest.com"},"cn": {"lngCode": "zh-CN","url": "https:\/\/cn.overleaftest.com"}}'
```

S touto konfigurací:

* `https://www.overleaftest.com` → anglické rozhraní
* `https://cn.overleaftest.com` → rozhraní ve zjednodušené čínštině

Toto mapování můžete podle potřeby rozšířit o další jazyky a subdomény.
</Step>

<Step title="Přesměrování hlavní domény">
Nakonec přesměrujte hlavní doménu (`overleaftest.com`) na doménu výchozího jazyka (`www.overleaftest.com`).

```nginx
server{
    listen 80;
    server_name overleaftest.com;
    return 301 https://www.overleaftest.com$request_uri;
}

server {
    listen 443 ssl http2;
    server_name overleaftest.com;
    ssl_certificate     /path/to/fullchain.cer;
    ssl_certificate_key /path/to/overleaftest.com.key;
    return 301 https://www.overleaftest.com$request_uri;
}
```
</Step>
</Steps>
