### Funkce „Overleaf Import API“

Od verze Ayakaleaf Pro v6.3 můžete vytvářet odkazy, které importují soubor LaTeX nebo zazipovaný projekt z URL a otevřou jej ve vaší vlastní instanci Ayakaleaf, podobně jako [API „Open in Overleaf“](https://cn.overleaf.com/devs) od Overleafu.

Tato funkce je ve výchozím nastavení zapnutá; podrobnou stránku s pokyny zobrazíte jednoduše návštěvou `your.overleaf.com/devs`.

<Info>

Stránka `/devs` vyžaduje přihlášení, pokud není nastaveno `OVERLEAF_ALLOW_PUBLIC_ACCESS=true`, viz [Signed-out visitors](/cs/on-premises/configuration/overleaf-toolkit/overleaf-import-api#signed-out-visitors  "mention").

</Info>

Pokud například hostujete soubor LaTeX na `https://example.com/main.tex` nebo celý projekt na `https://example.com/project.zip`, můžete vytvořit odkaz, který jej importuje do vaší vlastní instance Ayakaleaf Pro a otevře nový projekt:

<Tabs>
<Tab title="Soubor LaTeX">

```text wrap
https://ayakaleaf.example.com/docs?snip_uri=https%3A%2F%2Fexample.com%2Fmain.tex
```

</Tab>

<Tab title="Projekt ZIP">

```text wrap
https://ayakaleaf.example.com/docs?snip_uri=https%3A%2F%2Fexample.com%2Fproject.zip
```

</Tab>
</Tabs>

Nahraďte `ayakaleaf.example.com` doménou své instance.

#### Otevření projektu LaTeX v Ayakaleaf Pro

Od verze Ayakaleaf Pro v6.3 můžete vytvořit odkaz, který importuje soubor LaTeX nebo zazipovaný projekt do vaší vlastní instance Ayakaleaf Pro. Když někdo odkaz otevře, Ayakaleaf Pro vytvoří ze zadaného souboru nový projekt a otevře jej v editoru.

Odkaz směrujte na endpoint `/docs` vaší instance:

| Parametr        | Popis | Příklad |
| --------------- | ----- | ------- |
| `snip_uri`      | URL souboru LaTeX k importu. Přijímá se i jeden soubor ZIP, ale pro projekty použijte `zip_uri`. | `https://example.com/main.tex` |
| `zip_uri`       | URL zazipovaného projektu LaTeX k importu. | `https://example.com/project.zip` |
| `snip_uri[]`    | Import více souborů opakováním tohoto parametru. | `snip_uri[]=.../main.tex&snip_uri[]=.../refs.bib` |
| `snip_name[]`   | Nastaví název souboru pro každý `snip_uri[]` ve stejném pořadí. | `snip_name[]=main.tex` |
| `engine`        | Nastaví kompilátor: `latex_dvipdf`, `pdflatex`, `xelatex` nebo `lualatex`. | `engine=xelatex` |
| `main_document` | Nastaví hlavní soubor `.tex` v importovaném projektu. | `main_document=main.tex` |
| `name`          | Nastaví název nového projektu. Přijímá se také `project_name`. | `name=My%20Project` |

Pokud jsou například vaše soubory hostovány na `example.com`, tyto odkazy je importují do instance Ayakaleaf Pro hostované na `ayakaleaf.example.com` .

#### Import projektu pomocí Base64

Soubor LaTeX nebo zazipovaný projekt můžete vložit přímo do odkazu „Open in Ayakaleaf“ jako datovou URL ve formátu Base64. Díky tomu můžete vytvořit importní odkaz, aniž byste soubor hostovali na samostatné URL.

| Obsah               | Parametr   | Formát datové URL |
| ------------------- | ---------- | ----------------- |
| Soubor LaTeX        | `snip_uri` | `data:application/x-tex;base64,<base64-encoded-tex>` |
| Zazipovaný projekt  | `zip_uri`  | `data:application/zip;base64,<base64-encoded-zip>` |

Chcete-li importovat projekt ZIP, zakódujte soubor ZIP do Base64 a předejte jej místo toho přes `zip_uri`. Při sestavování kteréhokoli z odkazů použijte na celou datovou URL funkci `encodeURIComponent`. U velkých projektů použijte hostovanou URL souboru ZIP, protože limity délky URL v prohlížeči a na serveru mohou odkazy Base64 učinit nepraktickými.

#### Přidání tlačítka „Open in Ayakaleaf“

Pomocí formuláře HTML můžete importovat soubor, když návštěvník klikne na tlačítko. Formulář odešlete na endpoint `/docs` vaší instance s `method="post"`.

Pro hostovaný soubor LaTeX:

```text
<form action="https://ayakaleaf.example.com/docs" method="post" target="_blank">
  <input type="hidden" name="snip_uri" value="https://example.com/main.tex">
  <input type="hidden" name="engine" value="xelatex">
  <button type="submit">Open in Ayakaleaf</button>
</form>
```

Chcete-li importovat zazipovaný projekt, nahraďte `snip_uri` parametrem `zip_uri` a nasměrujte jej na soubor ZIP. Zdrojový kód LaTeX můžete také odeslat přímo pomocí `snip` pro surový text nebo `encoded_snip` pro text kódovaný pro URL.

Nahraďte `ayakaleaf.example.com` doménou své instance. Pokud má vaše instance zapnuté blokování požadavků z jiných původů (cross-origin), přidejte web, na kterém je formulář hostován, do `ALLOWED_ORIGINS`.

#### Nepřihlášení návštěvníci

Nový projekt se vytváří v účtu návštěvníka, takže se návštěvník musí přihlásit. Jak se k tomu nepřihlášený návštěvník dostane, závisí na způsobu odeslání importu:

* **Odkazy** (`GET /docs?...`) fungují na každé instanci: návštěvník je přesměrován na přihlašovací stránku a import pokračuje po přihlášení.
* **Formuláře** (`POST /docs`) vyžadují pro nepřihlášené návštěvníky `OVERLEAF_ALLOW_PUBLIC_ACCESS=true`. Odeslaná data se pak uchovávají 10 minut, dokud se návštěvník nepřihlásí, a použijí se jednou.

<Warning>

Ve výchozím nastavení (`OVERLEAF_ALLOW_PUBLIC_ACCESS` není nastaveno) je formulář odeslaný nepřihlášeným návštěvníkem přesměrován na přihlašovací stránku dříve, než jej Ayakaleaf Pro přečte, a odeslaná data se ztratí: po přihlášení návštěvník uvidí _no snippet, snip\_uri or zip\_uri provided_. Použijte odkazy, požádejte návštěvníky, aby se nejprve přihlásili, nebo zapněte veřejný přístup, viz [Page Access](/cs/on-premises/configuration/overleaf-toolkit/public-access#page-access  "mention").

</Warning>

<Accordion title="Jaké zdroje ZIP nebo TeX mohu importovat?">

Ayakaleaf Pro používá ke stahování externích zdrojů mikroslužbu `linked-url-proxy` (používanou hlavně pro [external-url.md](/cs/on-premises/configuration/overleaf-toolkit/external-url  "mention")). Obecně lze importovat jakýkoli veřejně přístupný zdroj ZIP nebo TeX dostupný přes internet. Zdroje hostované v privátních nebo interních sítích jsou z bezpečnostních důvodů blokovány.

Od znovu vydané verze Ayakaleaf Pro 6.3.0 (3. října 2026) můžete pro stahování externích zdrojů ZIP a TeX nakonfigurovat HTTP(S) proxy pomocí `OVERLEAF_LINKED_URL_OUTBOUND_PROXY`. Konfiguraci a omezení síťového přístupu popisuje [Outbound Proxy](/cs/on-premises/configuration/overleaf-toolkit/external-url#outbound-proxy  "mention").

</Accordion>
