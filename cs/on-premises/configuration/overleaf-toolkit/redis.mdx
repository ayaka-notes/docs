### Povolení ověřování heslem

Pokud používáte externí službu Redis a potřebujete zadat heslo, můžete to udělat nastavením proměnných prostředí `OVERLEAF_REDIS_PASS` a `REDIS_PASSWORD` v souboru **config/variables.env** a spuštěním příkazu `bin/up -d`, který znovu vytvoří kontejner **sharelatex**.

Pokud provozujete lokální instanci Redisu, budete muset nakonfigurovat službu **redis** tak, aby se spouštěla s ověřováním heslem. Po nastavení výše uvedených proměnných prostředí budete muset provést také tyto další kroky:

Vytvořte v adresáři <strong>config/</strong> soubor **docker-compose.override.yml** s následujícím obsahem:

```yaml title="config/docker-compose.override.yml"
services:
    redis:
        command: "redis-server --requirepass <YOUR-PASSWORD>"
```

<Warning>

Pokud máte povolenou perzistenci AOF, budete muset do `command` přidat `--appendonly yes`.

</Warning>

Spusťte `bin/up -d`, aby se kontejnery znovu vytvořily.

### Povolení perzistence Append-Only File

(Originál: https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/redis#enabling-append-only-file-persistence)

Perzistence Redis AOF (Append-Only File) poskytuje spolehlivý způsob, jak zajistit trvanlivost dat, protože zaznamenává každou zápisovou operaci přijatou serverem. Na rozdíl od snímků RDB, které pořizují kopie datové sady k určitému okamžiku, AOF uchovává úplný záznam všech změn provedených v datech.

<Info>

Vypnutí RDB je volitelné. Obecně se doporučuje používat obě metody perzistence společně. Než v produkci provedete jakékoli změny, zvažte výhody a nevýhody souběžného provozu AOF a RDB.

</Info>

Více o povolení perzistence AOF v Redisu si můžete přečíst zde: [https://redis.io/docs/latest/operate/oss\_and\_stack/management/persistence/#how-i-can-switch-to-aof-if-im-currently-using-dumprdb-snapshotsarrow-up-right](https://redis.io/docs/latest/operate/oss_and_stack/management/persistence/#how-i-can-switch-to-aof-if-im-currently-using-dumprdb-snapshotsarrow-up-right)

1. Naplánujte okno údržby pro upgrade.
2. Zastavte instanci pomocí `bin/stop` a zálohujte složky <strong>config/</strong> a <strong>data/</strong>.
3. Spusťte instanci pomocí `bin/up`
4. Spusťte příkaz `docker exec -it redis sh`
5. Spusťte příkaz `redis-cli`, který otevře rozhraní příkazové řádky Redisu
6. V redis-cli spusťte příkaz `config set appendonly yes`
7. Nyní musíte počkat, až přepis AOF dokončí ukládání dat. Můžete to provést tak, že do redis-cli zadáte `INFO persistence` a počkáte, až `aof_rewrite_in_progress` a `aof_rewrite_scheduled` budou mít hodnotu `0`, a ověříte, že `aof_last_bgrewrite_status` má hodnotu `ok`.
8. Ukončete redis-cli zadáním `exit` a stisknutím klávesy Enter
9. Opusťte kontejner redis zadáním `exit` a stisknutím klávesy Enter
10. Spusťte příkaz `ls ./data/redis` a ověřte, že vidíte soubor **appendonly.aof**
11. Upravte soubor **config/overleaf.rc** a změňte proměnnou prostředí `REDIS_AOF_PERSISTENCE` z `false` na `true`
12. Spusťte `bin/up -d` a ověřte, že aplikace funguje (editor projektu a panel historie jsou funkční).
