### Záhlaví

V této sekci si ukážeme, jak přizpůsobit klíčové prvky vaší on-premises instance. Název webu, navigační odkazy, záhlaví, zápatí i logo si můžete upravit podle svých představ.

### Název webu

Název v navigační liště lze upravit pomocí proměnné prostředí `OVERLEAF_NAV_TITLE`. Tento text se zobrazuje v levém horním rohu navigace, pokud není nastaveno logo.

```bash
# add to config/variables.env
OVERLEAF_NAV_TITLE=Our Overleaf Instance
```

## Logo

Místo textu můžete přidat vlastní logo nastavením proměnné prostředí `OVERLEAF_HEADER_IMAGE_URL`. Tato hodnota by měla odkazovat na externě hostovaný soubor s obrázkem.

```bash title="config/variables.env"
# add to config/variables.env
OVERLEAF_HEADER_IMAGE_URL=https://mysite.somewhere.com/img/logo.png
```

#### Loga pro světlý a tmavý motiv

Od verze 6.3.0 můžete pomocí proměnných prostředí `OVERLEAF_HEADER_IMAGE_URL_LIGHT` a `OVERLEAF_HEADER_IMAGE_URL_DARK` nastavit samostatná loga pro světlý a tmavý motiv. Obě hodnoty by měly odkazovat na externě hostovaný soubor s obrázkem.

```text
# add to config/variables.env
OVERLEAF_HEADER_IMAGE_URL_LIGHT=https://mysite.somewhere.com/img/logo-light.png
OVERLEAF_HEADER_IMAGE_URL_DARK=https://mysite.somewhere.com/img/logo-dark.png
```

<Info>

Pokud některá z proměnných není nastavena, použije daný motiv jako náhradu logo nastavené v `OVERLEAF_HEADER_IMAGE_URL`.

</Info>

## Navigační odkazy v záhlaví

Do navigačního záhlaví lze přidat další položky nastavením proměnné prostředí `OVERLEAF_HEADER_EXTRAS` na pole objektů ve formátu JSON. Například:

```json wrap
[\
  {\
    "text": "Some link",\
    "url": "http://example.com/somelink",\
    "class": "subdued",\
    "only_when_logged_out": true\
  },\
  {\
    "text": "Help",\
    "class": "subdued",\
    "dropdown": [\
      {\
        "text": "Documentation",\
        "url": "/learn"\
      },\
      {\
        "text": "Contact Admin",\
        "url": "http://example.com/contact"\
      }\
    ]\
  }\
]
```

Přidejte escapovanou podobu JSON do souboru toolkit/variables.env:

```bash title="toolkit/variables.env" wrap
# add to toolkit/variables.env
OVERLEAF_HEADER_EXTRAS=[{"text":"Some link","url":"http://example.com/somelink","class":"subdued","only_when_logged_out":true},{"text":"Help","class":"subdued","dropdown":[{"text":"Documentation","url":"/learn"},{"text":"Contact Admin","url":"http://example.com/contact"}]}]
```

## Zápatí

Levé i menší pravé zápatí (zobrazované na stránkách jako `/project`) lze upravit pomocí proměnných prostředí `OVERLEAF_LEFT_FOOTER` a `OVERLEAF_RIGHT_FOOTER`. Obě očekávají pole objektů JSON, které se vloží do stránky.

Obě očekávají pole JSON, které se vloží do stránky.

```json
[\
  {\
    "text": "This is an example text footer entry!"\
  },\
  {\
    "text": "This is an example URL footer link!", "url" : "/my-first-link.htm"\
  }\
]
```

<Info>

Při použití samotného `text` nesmí hodnota obsahovat HTML, protože se vykreslí jako prostý text.

</Info>

Aby to fungovalo, musí jít o platný JSON, přičemž při předávání jako proměnná prostředí je nutné uvozovky escapovat.

```bash title="config/variables.env" wrap
# add to config/variables.env
OVERLEAF_LEFT_FOOTER=[{"text": "This is an example text footer entry!"}]
OVERLEAF_RIGHT_FOOTER=["text": "This is an example URL footer link!", "url" : "/my-first-link.htm"]
```

<Info>

Kromě `text` a `url` přijímá objekt JSON pro další přizpůsobení také vlastnosti `class` a `label`.

</Info>

### Stránka údržby

Zprávu zobrazenou na stránce údržby můžete upravit pomocí proměnné prostředí `OVERLEAF_MAINTENANCE_MESSAGE`. Tento text nahradí výchozí zprávu pod nadpisem stránky.

```text wrap
# add to config/variables.env
OVERLEAF_MAINTENANCE_MESSAGE=Our Overleaf Instance is down for maintenance and will be back shortly.
```

Chcete-li zahrnout odkazy nebo jiné formátování, použijte místo toho `OVERLEAF_MAINTENANCE_MESSAGE_HTML`. Pokud jsou nastaveny obě proměnné, má přednost `OVERLEAF_MAINTENANCE_MESSAGE_HTML`.

```text wrap
# add to config/variables.env
OVERLEAF_MAINTENANCE_MESSAGE_HTML=Our Overleaf Instance is down for maintenance. For urgent requests, contact <a href="mailto:admin@example.com">admin@example.com</a>.
```

<Info>

`OVERLEAF_MAINTENANCE_MESSAGE` se vykresluje jako prostý text, takže **nesmí** obsahovat HTML. `OVERLEAF_MAINTENANCE_MESSAGE_HTML` se vykresluje jako HTML bez escapování.

</Info>

Pokud není nastavena ani jedna z nich, výchozí zpráva odkazuje na vaši stavovou stránku, je-li nastavena `OVERLEAF_STATUS_PAGE_URL`, a v opačném případě zobrazí e-mailovou adresu správce.
