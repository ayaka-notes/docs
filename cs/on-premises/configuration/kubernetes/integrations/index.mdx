Každá integrace je ve výchozím nastavení vypnutá, s výjimkou Overleaf Import API. Synchronizace s GitHubem, GitLabem, Gitea a Dropboxem a MCP server navíc vyžadují [integraci s Gitem](/cs/on-premises/configuration/kubernetes/integrations/git-integration). Po zapnutí integrace v ConfigMapu nebo v Secretu restartujte repliky pomocí `kubectl -n overleaf rollout restart`.
