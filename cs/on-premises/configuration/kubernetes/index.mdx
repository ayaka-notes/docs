Nasazení na Kubernetes čte stejné proměnné prostředí jako Toolkit. Kde stránka o Toolkitu říká „přidejte to do `config/variables.env`“, vložte hodnotu do ConfigMapy `overleaf-env`, nebo do Secretu `overleaf-secrets`, pokud jde o heslo, klíč nebo token. Poté restartujte:

```bash
kubectl -n overleaf apply -f 30-config.yaml        # after editing the ConfigMap
kubectl -n overleaf patch secret overleaf-secrets --type merge \
  -p '{"stringData":{"GITHUB_TOKEN_CIPHER_PASSWORD":"'"$(openssl rand -hex 32)"'"}}'
kubectl -n overleaf rollout restart deployment/overleaf
```

Hodnoty v `config/overleaf.rc` jsou nastavení Toolkitu, nikoli proměnné prostředí; co je nahrazuje, uvádí část Otázky a odpovědi na konci této stránky.

### Certifikáty a další soubory

Některé funkce místo hodnoty přijímají cestu k souboru: certifikáty SAML (`OVERLEAF_SAML_IDP_CERT`, ...), CA serveru LDAP (`OVERLEAF_LDAP_TLS_OPTS_CA_PATH`) nebo soukromou CA pro self-hosted GitHub Enterprise, GitLab nebo Gitea (`NODE_EXTRA_CA_CERTS`). Vložte soubory do Secretu a připojte ho tam, kde je stránky o Toolkitu očekávají, do `/var/lib/overleaf/certs`:

```bash
kubectl -n overleaf create secret generic overleaf-certs --from-file=idp_cert.pem --from-file=ca.pem
```

```yaml title="40-overleaf.yaml (additions)"
          volumeMounts:
            # ...
            - name: certs
              mountPath: /var/lib/overleaf/certs
              readOnly: true
      volumes:
        # ...
        - name: certs
          secret:
            secretName: overleaf-certs
```

Poté na ně v ConfigMapě odkažte cestou, například `NODE_EXTRA_CA_CERTS: /var/lib/overleaf/certs/ca.pem`, a restartujte.

<Warning>

<strong>Šifrovací hesla.</strong> Nastavte v Secretu všechna `*_CIPHER_PASSWORD` funkcí, které používáte. Některé funkce jinak při prvním použití vygenerují soubor s klíčem v datovém svazku: s jednou replikou to funguje, dokud svazek nepřijde nazmar, s více replikami by každá replika šifrovala jiným klíčem.

</Warning>

### Otázky a odpovědi

<Accordion title="Která nastavení Toolkitu z `config/overleaf.rc` potřebuji?">

<strong>Odpověď:</strong> Ayakaleaf Pro žádné z nich nečte. Jejich protějšky v Kubernetes:

| `config/overleaf.rc`                         | Kubernetes                                                        |
| -------------------------------------------- | ----------------------------------------------------------------- |
| `OVERLEAF_LISTEN_IP`, `OVERLEAF_PORT`        | Service (NodePort) nebo váš ingress                               |
| `SIBLING_CONTAINERS_ENABLED`                 | `SANDBOXED_COMPILES*` v ConfigMapě, socket Dockeru v podu         |
| `GIT_BRIDGE_ENABLED`                         | [Integrace s Gitem](/cs/on-premises/configuration/kubernetes/integrations/git-integration)                             |
| `MONGO_ENABLED`, `REDIS_ENABLED`, `MONGO_URL`, `REDIS_HOST` | StatefulSety nebo vaše spravované služby, `OVERLEAF_MONGO_URL` a `OVERLEAF_REDIS_HOST` |
| `REDIS_AOF_PERSISTENCE`                      | `--appendonly yes` v `20-redis.yaml`                              |
| `NGINX_ENABLED`, `TLS_*`                     | váš ingress nebo load balancer                                    |

</Accordion>
