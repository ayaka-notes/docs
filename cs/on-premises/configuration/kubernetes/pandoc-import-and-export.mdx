Převody přes Pandoc spouští služba **clsi** každého podu Ayakaleaf Pro, stejně jako kompilace: clsi požádá Docker Engine uzlu o spuštění kontejneru z `PANDOC_IMAGE`. Služba **web** zobrazuje nabídky importu a exportu. Co funkce dělá a jak sestavit obraz, je popsáno v části [Import a export přes Pandoc](/cs/on-premises/configuration/overleaf-toolkit/pandoc-import-and-export).

| | |
| --- | --- |
| Služby | web (nabídky a routy), clsi (provádí převod), v každém podu Ayakaleaf Pro |
| Uzel | Docker Engine a `PANDOC_IMAGE` na každém uzlu, na kterém může běžet Ayakaleaf Pro |
| Vyžaduje | [Sandboxed Compiles](/cs/on-premises/configuration/kubernetes/sandboxed-compiles) |
| Periodické úlohy | žádné |

### Konfigurace

<Steps>
<Step title="Nahrajte obraz do Dockeru na každém uzlu">
Sestavte obraz jednou ze složky `develop/pandoc` repozitáře [ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) a poté jej načtěte do Dockeru na každém uzlu, na kterém může běžet Ayakaleaf Pro:

```bash
docker build -t overleaf-pandoc:local develop/pandoc
docker save overleaf-pandoc:local | ssh node-1 sudo docker load    # repeat for every node
```

Nebo jej nahrajte do registru, na který uzly dosáhnou, a na každém uzlu jej stáhněte pomocí `sudo docker pull`. Stejně jako u obrazů TeX Live musí být v **Dockeru**, nejen v containerd.
</Step>

<Step title="ConfigMap">
```yaml
  ENABLE_PANDOC_CONVERSIONS: "true"
  PANDOC_IMAGE: overleaf-pandoc:local
```

Web i clsi čtou `ENABLE_PANDOC_CONVERSIONS` ze stejného ConfigMapu, takže se na Kubernetes nemohou rozcházet.
</Step>

<Step title="Použití a restart">
```bash
kubectl apply -f 30-config.yaml
kubectl -n overleaf rollout restart deployment/overleaf     # or statefulset/overleaf
```
</Step>
</Steps>

### Více replik

Kromě toho, že obraz musí být na každém uzlu, nic dalšího: každá replika převádí na svém vlastním uzlu.

### Testováno na Kubernetes

S obrazem sestaveným z `develop/pandoc` a načteným do Dockeru na každém uzlu pomocí `docker save | docker load`, na Kubernetes 1.37 s jednou replikou, procházejí naše end-to-end testy Pandocu (6 případů): import dokumentu Markdown jako projektu LaTeX, chyba zobrazená pro poškozený dokument Word, export do Wordu (který se znovu importuje), Markdownu a HTML a nabídky skryté bez `ENABLE_PANDOC_CONVERSIONS`.
