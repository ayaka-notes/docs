title: Export projektů

Do Server Pro a Community Edition `5.4.0` jsme přidali skript, který administrátorům umožňuje exportovat všechny uživatelské projekty (včetně těch, které jsou stále viditelné ve složkách **Deleted** a **Trashed**) do adresáře na disku.

<Info>

Výstup tohoto skriptu je stejný jako při ručním stažení ZIP archivu všech projektů z přehledu projektů uživatele. Skript před zahájením stahování zapíše všechny čekající změny, aby export obsahoval nejnovější verzi projektu.

</Info>

### Omezení

Exportní skript má následující omezení:

* Neexportují se žádná nastavení projektu, jako je název image TeX Live nebo kompilátor. Ta je nutné nastavit při nahrání projektu do účtu uživatele.
* Exportované projekty neobsahují žádnou historii verzí.
* Informace o spolupracovnících se nezachovávají. Projekty bude nutné znovu sdílet. Pokud se používá sdílení odkazem, odkazy pro zobrazení a úpravy budou vygenerovány znovu (nebudou stejné jako dříve).
* Komentáře a informace o sledovaných změnách se neexportují.
* Historie chatu projektu se neexportuje.

<Danger>

Tento skript **není** určen jako náhrada úplné zálohy systému. Abyste mohli instanci obnovit v případě havárie, **důrazně** doporučujeme pořídit [konzistentní zálohu](https://docs.overleaf.com/on-premises/maintenance/#performing-a-consistent-backup).

</Danger>

### **Přepínače**

| Název          | Popis                                                                            |
| -------------- | -------------------------------------------------------------------------------- |
| `--help`       | Zobrazí nápovědu                                                                 |
| `--user-id`    | ID uživatele (povinné, pokud se nepoužívá `--export-all` nebo `--project-id`)    |
| `--project-id` | Exportuje jeden projekt (**nelze** použít s `--user-id` ani `--export-all`)      |
| `--list`       | Vypíše projekty uživatele (**nelze** použít s `--output`)                        |
| `--output`     | Výstupní ZIP soubor (pro jednotlivé exporty)                                     |
| `--export-all` | Exportuje projekty všech uživatelů (vyžaduje `--output-dir`)                     |
| `--output-dir` | Adresář pro uložení exportních souborů všech uživatelů                           |
| `--log-level`  | Podporované úrovně logování: `trace`\|`debug`\|`info`\|`warn`\|`error`\|`fatal`  |

### **Použití**

Pro export projektů všech uživatelů použijte následující příkaz:

```bash wrap
# Overleaf Toolkit users
$ bin/docker-compose exec sharelatex /bin/bash -ce "cd /overleaf/services/web && node modules/server-ce-scripts/scripts/export-user-projects.mjs --export-all --output-dir=/var/lib/overleaf/data/exports"

# Legacy docker-compose.yml users
docker exec sharelatex /bin/bash -ce "cd /overleaf/services/web && node modules/server-ce-scripts/scripts/export-user-projects.mjs --export-all --output-dir=/var/lib/overleaf/data/exports"
```

<Info>

Pokud používáte Server Pro nebo Community Edition &lt;= 3.5.13, budete muset výše uvedený příklad upravit tak, aby používal skript **`export-legacy-user-projects.js`**.

</Info>

### **Dokončení**

Po dokončení exportu můžete k souborům přistupovat přes adresář na hostiteli, který je připojen (bind mount) do **/var/lib/overleaf** v souboru **docker-compose.yml**, nebo přes proměnnou prostředí `OVERLEAF_DATA_PATH` v souboru **config/overleaf.rc**, pokud používáte Toolkit.

<Info>

Overleaf v současnosti povoluje duplicitní názvy projektů. Pokud uživatel má projekty s duplicitním názvem, budou do jeho ZIP exportu přidány, ale po rozbalení bude přítomna pouze jedna verze. V Linuxu `unzip -B` zapíše soubory se stejným názvem jako záložní soubory, místo aby je přepsal.

</Info>
