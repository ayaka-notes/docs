Existující image TeX Live je možné rozšířit pomocí nového Dockerfile a nakonfigurovat aplikaci tak, aby nový image používala.

Zde nabízíme několik pokynů k instalaci nových balíčků nebo fontů, konfigurace vlastního image však není pokryta našimi podmínkami podpory.

Image TeX Live se aktualizují jen zřídka. Doporučujeme vlastní image znovu sestavit při upgradu Server Pro.

<Danger>

Následující sekce se týkají pouze Server Pro a [Sandboxed Compiles](/cs/on-premises/configuration/overleaf-toolkit/sandboxed-compiles).

</Danger>

### Instalace a aktualizace nových balíčků

Ke správě balíčků TeX Live můžete používat příkazy `tlmgr`, například `tlmgr install` a `tlmgr update`, jako v následujícím příkladu:

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2023.1

RUN tlmgr update --force ebproof
```

### Použití `tlmgr` ve starším image TeX Live

Ve výchozím nastavení stahuje `tlmgr` prostředky z nejnovějšího vydání TeX Live. Při úpravách staršího image TeX Live je nutné přepnout stahování na příslušný archiv. Seznam zrcadel archivů najdete na [https://www.tug.org/historic/](https://www.tug.org/historic/).

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2022.1

RUN tlmgr option repository <MIRROR>/systems/texlive/<YEAR>/tlnet-final
# e.g. RUN tlmgr option repository ftp://tug.org/historic/systems/texlive/2022/tlnet-final

RUN tlmgr update --force ebproof
```

### Instalace nových fontů

Existují různé postupy, jak do distribuce TeX Live nainstalovat nové fonty, a instalace vlastního fontu může vyžadovat několik kroků. Dobrým výchozím bodem jsou pravděpodobně [pokyny k instalaci TeXových fontů](https://tug.org/fonts/fontinstall.html) v oficiální dokumentaci TeX Live.

Následující `Dockerfile` ukazuje příklad instalace fontu TrueType nad existující image TeX Live 2022:

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2022.1

COPY ./myfonts/*.ttf /usr/share/fonts/truetype/myfont/

# rebuild font information cache
RUN fc-cache
```

### Konfigurace Server Pro pro použití nových image

K sestavení nového image použijte název `ghcr.io/ayaka-notes/texlive-full` a vlastní tag, například:

```bash
docker build -t ghcr.io/ayaka-notes/texlive-full:2023.1-custom
```

Nyní můžeme Server Pro nakonfigurovat tak, aby používal nový image `2023.1-custom`, a to aktualizací proměnných prostředí `TEX_LIVE_DOCKER_IMAGE` a `ALL_TEX_LIVE_DOCKER_IMAGES`:

```text wrap
TEX_LIVE_DOCKER_IMAGE: "ghcr.io/ayaka-notes/texlive-full:2023.1-custom"
ALL_TEX_LIVE_DOCKER_IMAGES: "ghcr.io/ayaka-notes/texlive-full:2023.1,ghcr.io/ayaka-notes/texlive-full:2023.1-custom"
```

Ve výše uvedeném příkladu jsou nové projekty ve výchozím nastavení nastaveny na používání nového image `2023.1-custom`, zatímco `2023.1` zůstává k dispozici pro případ potřeby.
