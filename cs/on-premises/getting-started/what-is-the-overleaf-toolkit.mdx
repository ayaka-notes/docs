---
title: Co je Ayakaleaf Toolkit?
icon: toolbox
---

Ayakaleaf toolkit je doporučený způsob nasazení pro on-premises instalace Community Edition a Ayakaleaf Pro. Byl navržen pro nejběžnější prostředí: jeden fyzický server nebo virtuální stroj. Toolkit používá `docker compose` ke správě Docker kontejnerů vašeho serveru a poskytuje sadu skriptů, které obalují příkazy `docker` a pomáhají s technickou stránkou správy on-premises verze Overleafu.

#### Obal `bin/docker-compose`

Skript `bin/docker-compose` je obalem kolem `docker compose`. Načte konfiguraci z adresáře `config/` a poté spustí `docker compose` se všemi argumenty, které byly skriptu předány.

S `bin/docker-compose` můžete zacházet jako s transparentním obalem programu `docker compose` nainstalovaného na vašem stroji.

Příklad:

```bash title="Check running containers"
$ bin/docker-compose ps
```

#### Pomocné skripty

Kromě `bin/docker-compose` poskytuje Toolkit praktické skripty, které pomáhají s běžnými úkoly:

* `bin/up`: zkratka pro `bin/docker-compose up`
* `bin/start`: zkratka pro `bin/docker-compose start`
* `bin/stop`: zkratka pro `bin/docker-compose stop`
* `bin/shell`: spustí shell uvnitř kontejneru **sharelatex**
* `bin/doctor`: skript pro shromáždění informací o instalaci a nasazení. Viz část „Kontrola serveru“ níže
* `bin/mongo`: spustí shell uvnitř kontejneru **mongo** a přepne se do správné databáze (**sharelatex**)
* `bin/backup-config`: vytvoří kopii (zip nebo tar) vaší aktuální konfigurace a uloží ji do zvoleného cílového adresáře
* `bin/logs`: zobrazení/sledování logů služeb
* `bin/error-logs`: zobrazení/sledování chybových logů služeb
* `bin/rename-env-vars-5-0`: migrační skript pro aktualizaci proměnných prostředí v **config/variables.env** (přejmenování ze ShareLaTeX na Overleaf)
* `bin/rename-rc-vars`: migrační skript pro aktualizaci proměnných prostředí v **config/overleaf.rc** (přejmenování ze ShareLaTeX na Overleaf)
* `bin/run-script`: pomocník, který zjednodušuje spouštění skriptů uložených v kontejneru **sharelatex**
* `bin/upgrade`: pomáhá s upgradem instance. Skript zkontroluje aktualizace Toolkitu (přes git) a nabídne stažení změn, zkontroluje nejnovější verzi Docker image a nabídne její aktualizaci. Poskytuje potvrzování krok za krokem, možnost zálohovat aktuální konfiguraci a zajišťuje zastavení/spuštění služeb Dockeru. Více informací najdete v části Upgrade nasazení: https://docs.overleaf.com/on-premises/maintenance/upgrading-your-deployment

<Info>

Pokud chcete instanci provozovat bez připojení k logům Dockeru, můžete ji spustit v odpojeném režimu pomocí `bin/up -d`.

</Info>

#### Kontrola serveru

Overleaf Toolkit obsahuje užitečný skript `bin/doctor`, který vytvoří zprávu upozorňující na jakékoli nesplněné závislosti.

Než budete pokračovat, spusťte skript `bin/doctor` a zkontrolujte, že vše funguje správně:

```bash title="Run Overleaf Doctor"
bin/doctor
```
