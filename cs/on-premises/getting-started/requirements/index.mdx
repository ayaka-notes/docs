### Požadavky na instalaci Server Pro a Community Edition

<Warning>

Důrazně doporučujeme provozovat Server Pro na aktuální a stabilní verzi Ubuntu (např. Ubuntu 24.04 v letech 2025–2026) s aktuální verzí Dockeru. Provozování Server Pro na jiných systémech je možné, ale výrazně nám to ztíží poskytování podpory pro nestandardní konfigurace Ubuntu/Dockeru. Rovněž nemůžeme poskytovat podporu pro problémy se samotným Dockerem.

</Warning>
