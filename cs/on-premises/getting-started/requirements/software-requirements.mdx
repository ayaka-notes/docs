### Operační systémy

Pro nejlepší zkušenost s provozem Overleafu důrazně doporučujeme používat operační systém založený na **Debianu**, například **Ubuntu**. Tato volba odpovídá vývojovému prostředí softwaru a je preferovanou možností většiny uživatelů Overleafu.

<Danger>

Při používání Server Pro se Sandboxed Compiles je **důležité** mít na paměti, že aplikace vyžaduje přístup root k socketu Dockeru.

</Danger>

### Závislosti

* Docker 25.0 a 29
* MongoDB 7.0 a 8.0
* Redis 6.2 a 7.5

<Info>

Data konce životnosti (EOL) výše uvedených závislostí a dalších oblíbených produktů můžete sledovat pomocí služby endoflife.date zde: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

MongoDB a Redis stahuje při spuštění Server CE nebo Server Pro automaticky `docker compose`, pokud není nakonfigurováno použití jiné instalace.

</Info>

Toolkit závisí na následujících programech:

* bash
* Docker

`docker compose` je vyžadován a obvykle se instaluje spolu s Dockerem.

Doporučujeme nainstalovat nejnovější verzi Dockeru dostupnou pro váš operační systém.

Jakmile je Docker správně nainstalován, měli byste být schopni spustit tyto příkazy bez chyby:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2)
docker compose version

# List the running Docker containers on your system
docker ps
```
