### Operační systémy {#operating-systems}

Pro sdílené a produkční servery doporučujeme systém **Linux založený na Debianu**, například **Ubuntu**. Ayakaleaf Pro lze provozovat také na [macOS s Docker Desktop](/cs/on-premises/installation/using-docker-compose/macos) a na [Windows s WSL 2 a Docker Desktop](/cs/on-premises/installation/using-docker-compose/windows). Všechny tři platformy používají linuxové kontejnery a stejný Toolkit; postupujte podle návodu pro operační systém vašeho hostitele.

<Danger>

Při používání Sandboxed Compiles je **důležité** mít na paměti, že aplikace vyžaduje přístup root k socketu Dockeru.

</Danger>

### Závislosti {#dependencies}

* Docker 25.0 a 29
* MongoDB 7.0 a 8.0
* Redis 6.2 a 7.5

<Info>

Data konce životnosti (EOL) výše uvedených závislostí a dalších oblíbených produktů můžete sledovat pomocí služby endoflife.date zde: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

MongoDB a Redis stahuje při spuštění Ayakaleaf Pro automaticky `docker compose`, pokud není nakonfigurováno použití jiné instalace.

</Info>

Toolkit závisí na následujících programech:

* bash
* Docker

`docker compose` je vyžadován a obvykle se instaluje spolu s Dockerem.

Doporučujeme nainstalovat nejnovější verzi Dockeru dostupnou pro váš operační systém.

Jakmile je Docker správně nainstalován, měli byste být schopni spustit tyto příkazy bez chyby:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2 or later, such as v5)
docker compose version

# List the running Docker containers on your system
docker ps
```
