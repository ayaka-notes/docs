Nejjednodušší způsob, jak vyzkoušet náš Ayakaleaf Pro, je použít GitHub Codespace, kde jsou všechny proměnné prostředí předem nakonfigurovány, takže jej můžete používat ihned po spuštění.

<Warning>

Když spouštíte kontejnery Docker pomocí GitHub Codespaces, Codespace se automaticky nevypne a bude se vám nadále **účtovat**. Pravidla účtování GitHub Codespaces najdete v [pravidlech účtování github codespaces](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces).

Své GitHub Codespaces můžete spravovat na [https://github.com/codespaces](https://github.com/codespaces). Jakmile Codespace již nepotřebujete, včas jej smažte.

</Warning>

Následující funkce máme **předem nakonfigurované**:

* [x] Izolovaná (sandboxed) kompilace LaTeXu s TeXLive **Basic** (2024–2026)
* [x] Import/export pomocí Pandoc (funkce SaaS platformy)
* [x] Spouštění skriptů v Pythonu (funkce SaaS platformy)
* [x] Podpora Git-Bridge (funkce Server Pro)
* [x] Pokročilé vyhledávání referencí (funkce SaaS platformy)
* [x] Administrátorský panel (globální správa uživatelů/projektů)
* [x] Sledování změn (s panelem pro revize a komentáře)
* [x] Úplná historie projektu (s obnovením a stažením)
* [x] Symbol Palette (funkce Server Pro/SaaS platformy)

<Warning>

Standardní GitHub Codespaces poskytují 32 GB úložiště. To pro naši instalaci `texlive-full` nestačí. Chcete-li vyzkoušet úplný image, požádejte prostřednictvím tiketu podpory GitHubu o Codespace s velkými runnery (8+ jader).

</Warning>

Synchronizace s GitHubem, LDAP, OAuth, SSO, integrace Zotero a další funkce v tomto testovacím prostředí _**nejsou nakonfigurovány**_. Podrobnosti o konfiguraci těchto funkcí ve vlastním nasazení najdete v [nastavení toolkitu](/cs/on-premises/configuration/overleaf-toolkit/toolkit-settings).

<Steps>
<Step title="Vytvoření GitHub Codespace">
Kliknutím na následující tlačítko vytvoříte svůj GitHub Codespace. Pokud jde o konfiguraci serveru, pro testování obvykle stačí **2 jádra a 8 GB RAM**. Pokud plánujete používat [**TeX Live Full**](https://github.com/ayaka-notes/texlive-full), doporučujeme zvolit konfiguraci s **8 jádry a 64 GB**.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/ayakaleaf-pro-playground)

Jakmile je váš codespace připraven, spusťte v bashi následující příkaz pro inicializaci instance Overleafu.

```bash title="bash"

```

#### Použití image TeXLive Full

Pokud máte přístup ke GitHub Codespaces s 8 jádry/64 GB, můžete v tomto testovacím prostředí použít image TeXLive Full. Chcete-li místo image TeXLive Basic použít TeXLive Full, změňte následující proměnné prostředí v souboru `toolkit/config/variables.env`.

```dotenv wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1, ghcr.io/ayaka-notes/texlive-full:2024.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025, Texlive 2024
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```

Po změně proměnných prostředí je nutné toolkit restartovat, aby se změny projevily. Toolkit restartujete následujícím příkazem.

```bash
cd toolkit && bin/up -d
```
