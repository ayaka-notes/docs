<Danger>

Následující pokyny se týkají **pouze** instalací **Community Edition**. Uživatelům Ayakaleaf Pro důrazně doporučujeme povolit [Sandboxed Compiles](/cs/on-premises/configuration/overleaf-toolkit/sandboxed-compiles), protože tak uživatelé získají přístup k téměř stejným image TeX Live, jaké se používají na [overleaf.com](https://www.overleaf.com), a navíc se tím zajistí izolace mezi kompilacemi projektů pro vyšší bezpečnost.

</Danger>

Kvůli úspoře přenosového pásma obsahují image Overleaf Community Edition i Ayakaleaf Pro pouze minimální instalaci [TeX Live](https://www.tug.org/texlive/). Další balíčky můžete nainstalovat nebo provést upgrade na úplnou instalaci TeX Live pomocí příkazu [tlmgr](https://www.tug.org/texlive/tlmgr.html) v kontejneru `sharelatex`.

#### Vstup do kontejneru sharelatex

Chcete-li spustit shell uvnitř kontejneru `sharelatex`, spusťte

```bash
bin/shell
```

Zobrazí se výzva, která vypadá takto:

```bash
root@309b192d4030:/#
```

V následujících pokynech předpokládáme, že se nacházíte uvnitř kontejneru.

#### Zjištění aktuální verze TeX Live

TeX Live vychází každý rok přibližně v dubnu. Postup při používání `tlmgr` se liší podle toho, zda používáte aktuální vydání, nebo starší. Kterou verzi TeX Live používáte, zjistíte příkazem `tlmgr --version`. Tato instalace například používá TeX Live 2021:

```bash
# tlmgr --version
tlmgr revision 59291 (2021-05-21 05:14:40 +0200)
tlmgr using installation: /usr/local/texlive/2021
TeX Live (https://tug.org/texlive) version 2021
```

<Info>

Aktuální vydání TeX Live najdete na [domovské stránce TeX Live](https://www.tug.org/texlive/).

</Info>

Pokud používáte starší verzi TeX Live, máte dvě možnosti. Nová verze Docker image Overleaf obvykle vychází krátce po vydání TeX Live, takže na ni můžete počkat a upgradovat své nasazení pomocí skriptu `bin/upgrade`. Pokud si naopak chcete ponechat starší vydání TeX Live, musíte nejprve nastavit `tlmgr` tak, aby používal historický repozitář. Návod, jak to udělat, najdete [zde](https://www.tug.org/texlive/acquire.html#past).

#### Instalace balíčků

Chcete-li nainstalovat úplnou instalaci TeX Live, spusťte uvnitř kontejneru `sharelatex` tento příkaz:

```text
tlmgr install scheme-full
```

Jednotlivé balíčky můžete nainstalovat také ručně:

```bash
tlmgr install tikzlings tikzmarmots tikzducks
```

<Warning>

Od vydání `3.3.0` je po každém použití `tlmgr install` opět **nutné** spustit `tlmgr path add`, aby se všechny binární soubory správně symbolicky propojily do systémové cesty.

</Warning>

K dispozici je mnoho dalších příkazů. Více se dozvíte pomocí:

```text
tlmgr help
```

Až budete hotovi, zadejte `exit` nebo stiskněte Control-D a shell ukončete.

#### Uložení změn

Provedené změny upravily kontejner `sharelatex`, jsou však dočasné -- ztratí se, pokud Docker Compose kontejner znovu vytvoří, například při aktualizaci konfigurace.

Aby byly trvalé, uložte změny do nového Docker image pomocí `docker commit`:

```bash
cat config/version #5.2.1
docker commit sharelatex sharelatex/sharelatex:5.2.1-with-texlive-full
echo 5.2.1-with-texlive-full > config/version
```

Po commitnutí změn odpovídajícím způsobem aktualizujte `config/version`. Poté spusťte `bin/up`, aby se kontejner `sharelatex` znovu vytvořil.

<Danger>

Tyto kroky budete muset zopakovat při každém [upgradu](https://github.com/overleaf/toolkit/blob/master/doc/upgrading.md) na novou verzi Overleaf.

</Danger>
