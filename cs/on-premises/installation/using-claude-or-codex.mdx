K naplánování a provedení nasazení Ayakaleaf Pro použijte Claude Code nebo Codex. Agent může během práce prohledávat tuto dokumentaci přes MCP.

Agent vám s nasazením pomáhá. Odpovědnost za kontrolu příkazů a ochranu přihlašovacích údajů však zůstává na vás.

### Než začnete

Připravte si podporovaný linuxový server s přístupem přes SSH. Než budete pokračovat, projděte si [požadavky](/cs/on-premises/getting-started/requirements  "mention").

<Warning>

Do promptů pro agenta nevkládejte hesla, privátní klíče, tokeny ani licenční klíče. Každý příkaz před spuštěním zkontrolujte, zejména příkazy, které mění soubory, sítě nebo kontejnery.

</Warning>

### Připojení dokumentace

Přidejte MCP endpoint dokumentace do svého lokálního agenta.

<Tabs>
<Tab title="Claude Code">

```bash wrap
claude mcp add ayakaleaf-pro --scope user --transport http https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>

<Tab title="Codex">

```bash wrap
codex mcp add ayakaleaf-pro --url https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>
</Tabs>

Po přidání serveru zahajte novou relaci. Požádejte agenta, aby potvrdil, že dokáže prohledávat dokumentaci Ayakaleaf Pro.

### Nasazení Ayakaleaf Pro

Otevřete terminál na svém serveru pro nasazení. Spusťte tam Claude Code nebo Codex. Poté odešlete tento prompt:

```text wrap
Use the Ayakaleaf Pro documentation MCP server to guide this deployment.
First, inspect the requirements and installation guides.
Ask me for missing deployment details before making changes.
Use the Ayakaleaf Toolkit unless the documentation requires another approach.
Before configuring the instance, summarize relevant optional features.
Ask which features and integrations I want to enable.
Include TLS, sandboxed compiles, Git integration, external MongoDB or Redis,
SSO (OIDC, SAML, or LDAP), GitHub Synchronisation, Zotero, S3 storage,
email delivery, branding, and localization when relevant.
Explain each selected option's prerequisites, security impact, and configuration steps.
Keep unselected optional features disabled.
Show each command before running it.
Do not expose, store, or request secrets in chat.
After deployment, verify that the service is healthy and summarize the changes.
```

Agent by vás měl provést nastavením Dockeru, konfigurací Toolkitu, stažením image a spuštěním. Kanonický postup najdete v návodu [using-the-toolkit](/cs/on-premises/installation/using-the-toolkit  "mention").

### Výběr volitelných funkcí

Požádejte agenta, aby doporučil pouze funkce, které odpovídají vašemu prostředí. Typické volby zahrnují:

* **Přístup a zabezpečení:** TLS, kompilace v sandboxu a SSO přes OIDC, SAML nebo LDAP.
* **Externí služby:** MongoDB, Redis, úložiště S3 a doručování e-mailů.
* **Spolupráce:** integrace Git, GitHub Synchronisation a Zotero.

Agent by měl před úpravou konfigurace vysvětlit závislosti. Před povolením produkčních integrací si projděte [toolkit-settings.md](/cs/on-premises/configuration/overleaf-toolkit/toolkit-settings  "mention") a [authentication](/cs/on-premises/configuration/overleaf-toolkit/authentication  "mention").

### Ověření nasazení

Poté, co agent dokončí jednotlivé kroky:

1. Potvrďte, že všechny příkazy proběhly bez chyb.
2. Otevřete v prohlížeči nakonfigurovanou URL Ayakaleaf Pro.
3. Dokončete [6.-post-installation-tasks.md](/cs/on-premises/installation/using-the-toolkit/6.-post-installation-tasks  "mention").

U existující instalace Community Edition použijte místo nového nasazení návod [migrate-from-existing.md](/cs/on-premises/installation/migrate-from-existing  "mention").
