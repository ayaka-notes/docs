### Vytvoření prvního administrátorského účtu {#creating-your-first-administrator-account}

Otevřete `OVERLEAF_SITE_URL` následované `/launchpad`, například `http://192.0.2.10:30080/launchpad`, a zaregistrujte administrátorský účet stejně jako v [úlohách po instalaci v Toolkitu](/cs/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks). Poté vytvořte ukázkový projekt a zkompilujte jej.

Uživatele můžete vytvářet také z příkazového řádku:

```bash
kubectl -n overleaf exec deploy/overleaf -- bash -c \
  'cd /overleaf/services/web && node modules/server-ce-scripts/scripts/create-user.mjs --admin --email=admin@example.com'
```

Vypíše odkaz, pomocí kterého se nastaví heslo.

### Kontrola, že kompilace běží v sandboxu {#checking-that-compiles-are-sandboxed}

Zkompilujte projekt a poté se podívejte na uzel, na kterém pod běží:

```bash
kubectl -n overleaf get pod -l app=overleaf -o wide   # NODE column
# on that node:
sudo docker ps -a --filter ancestor=ghcr.io/ayaka-notes/texlive-full:2026.1
ls -ln /srv/overleaf/compiles                          # owned by uid 33 (www-data)
```

Každá kompilace se zobrazí jako krátce žijící kontejner s názvem `project-<project id>-<user id>-...`.

### Logy a shell {#logs-and-a-shell}

| Toolkit          | Kubernetes                                                               |
| ---------------- | ------------------------------------------------------------------------ |
| `bin/logs web`   | `kubectl -n overleaf exec deploy/overleaf -- tail -f /var/log/overleaf/web.log` |
| `bin/shell`      | `kubectl -n overleaf exec -it deploy/overleaf -- bash`                    |
| `bin/up`         | `kubectl apply -f .` a poté `kubectl -n overleaf rollout restart deployment/overleaf` |

Kontejner zapisuje jeden soubor logu pro každou službu do `/var/log/overleaf/` (`web.log`, `clsi.log`, `real-time.log`, `document-updater.log`, ...); `kubectl logs` zobrazuje výstup při startu.

### Q\&A {#q&a}

<Accordion title="Kompilace selže nebo nikdy neskončí.">

<strong>Odpověď:</strong> Na uzlu, na kterém pod běží, zkontrolujte, že Docker běží a má obraz uvedený v `TEX_LIVE_DOCKER_IMAGE` a že `SANDBOXED_COMPILES_HOST_DIR_*` odpovídají cestám `hostPath`. `/var/log/overleaf/clsi.log` v podu uvádí krok, který selhal.

</Accordion>

<Accordion title="Uživatelé jsou po každém restartu podu odhlášeni.">

<strong>Odpověď:</strong> V Secretu `overleaf-secrets` chybí `OVERLEAF_SESSION_SECRET`, viz [krok 2](/cs/on-premises/installation/using-kubernetes/2.-create-the-namespace-and-secrets).

</Accordion>
