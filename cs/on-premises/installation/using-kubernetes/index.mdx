[Toolkit](/cs/on-premises/installation/using-docker-compose) je doporučený způsob, jak provozovat Ayakaleaf Pro na jednom serveru. Pokud již cluster Kubernetes provozujete, tato sekce na něm nasadí stejný kontejner pomocí čistých manifestů `kubectl`: žádný další obraz, žádný Helm chart.

Na konci této sekce budete mít jednu instanci Ayakaleaf Pro se sandboxed compiles, replica set MongoDB a Redis, vše v namespace `overleaf`. Chcete-li poté provozovat více instancí za load balancerem, pokračujte [horizontálním škálováním](/cs/on-premises/configuration/kubernetes/horizontal-scaling).

<Info>

Podpora Kubernetes je experimentální. Nepublikujeme Helm chart ani obrazy specifické pro Kubernetes. Manifesty na těchto stránkách jsou ty, které jsme testovali na Kubernetes 1.37 (kubeadm, containerd 2.4, flannel) se třemi uzly, každý se 2 vCPU a 4 GB paměti. Úložiště, síť a ingress přizpůsobte svému clusteru.

</Info>

### Jak do sebe části zapadají {#how-the-pieces-fit}

| Toolkit (jeden server)                       | Kubernetes                                                               |
| -------------------------------------------- | ------------------------------------------------------------------------ |
| `config/variables.env`                       | ConfigMap `overleaf-env` a Secret `overleaf-secrets`                     |
| kontejner `sharelatex`                       | Deployment `overleaf` (jeden pod, ve kterém běží všechny služby Overleafu) |
| kontejnery `mongo` a `redis`                 | StatefulSety `mongo` (replica set) a `redis`, nebo vaše spravované služby |
| `~/overleaf-toolkit/data/overleaf`           | PersistentVolumeClaim `overleaf-data`                                    |
| Docker na hostiteli, používaný pro kompilace | Docker Engine na každém uzlu, na kterém běží Ayakaleaf Pro               |
| `bin/up`, `bin/logs`, `bin/shell`            | `kubectl apply`, `kubectl logs`, `kubectl exec`                          |

### Co potřebujete {#what-you-need}

* Cluster Kubernetes, na který můžete instalovat balíčky: každý uzel, na kterém může běžet Ayakaleaf Pro, potřebuje **Docker Engine**, protože kompilace běží v kontejnerech TeX Live, které Ayakaleaf Pro spouští přes `/var/run/docker.sock` uzlu. Viz [0. Příprava uzlů](/cs/on-premises/installation/using-kubernetes/0.-prepare-the-nodes).
* Výchozí StorageClass se svazky `ReadWriteOnce`.
* `kubectl` a `openssl` na vaší pracovní stanici.
