---
title: 2. Vytvoření namespace a tajných klíčů
description: Vytvořte namespace a tajné klíče, které Ayakaleaf Pro potřebuje.
icon: key
---

Vše patří do namespace `overleaf`:

```bash
kubectl create namespace overleaf
```

Ayakaleaf Pro čte své tajné klíče z proměnných prostředí. Vygenerujte je jednou a uložte je do Secretu:

```bash wrap
HISTORY=$(openssl rand -hex 32)
kubectl -n overleaf create secret generic overleaf-secrets \
  --from-literal=OVERLEAF_INVITE_TOKEN_SECRET="$(openssl rand -base64 32)" \
  --from-literal=OVERLEAF_SESSION_SECRET="$(openssl rand -hex 32)" \
  --from-literal=WEB_API_PASSWORD="$(openssl rand -hex 32)" \
  --from-literal=STAGING_PASSWORD="$HISTORY" \
  --from-literal=V1_HISTORY_PASSWORD="$HISTORY" \
  --from-literal=CRYPTO_RANDOM="$(openssl rand -hex 32)" \
  --from-literal=OT_JWT_AUTH_KEY="$(openssl rand -hex 32)"
```

| Tajný klíč                                     | Proč                                                                                                                                                 |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_INVITE_TOKEN_SECRET`                 | Povinný. Bez něj se pod zastaví s chybou „Missing required secrets“. Jeho změna zneplatní čekající pozvánky do projektů.                              |
| `OVERLEAF_SESSION_SECRET`                      | Podepisuje session cookies. Bez něj každý restart podu všechny odhlásí.                                                                               |
| `WEB_API_PASSWORD`, `CRYPTO_RANDOM`, `OT_JWT_AUTH_KEY` | Interní tajné klíče. Pokud chybí, kontejner je vygeneruje při každém startu; při více než jedné replice je musí všechny repliky sdílet.        |
| `STAGING_PASSWORD` a `V1_HISTORY_PASSWORD`     | Interní tajný klíč historie; oba musí mít **stejnou** hodnotu.                                                                                        |

<Warning>

Zálohujte Secret (`kubectl -n overleaf get secret overleaf-secrets -o yaml`) spolu se svými daty. Funkce, které šifrují tokeny v MongoDB, potřebují v tomto Secretu také svá vlastní šifrovací hesla, například `GITHUB_TOKEN_CIPHER_PASSWORD` pro [synchronizaci s GitHubem](/cs/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation).

</Warning>
