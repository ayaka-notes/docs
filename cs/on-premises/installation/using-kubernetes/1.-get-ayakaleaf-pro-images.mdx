Kubernetes spouští stejné obrazy jako Toolkit. Samostatný obraz pro Kubernetes neexistuje.

| Obraz                                                | Používá jej                                                             |
| ---------------------------------------------------- | ----------------------------------------------------------------------- |
| `ghcr.io/ayaka-notes/overleaf-pro:6.3.2`             | Deployment `overleaf`                                                   |
| `ghcr.io/ayaka-notes/overleaf-pro/git-bridge:6.3.2`  | [Integrace s Gitem](/cs/on-premises/configuration/kubernetes/integrations/git-integration) (volitelné), stejný tag jako výše |
| `ghcr.io/ayaka-notes/texlive-*`                      | kompilace, stažené do Dockeru na uzlech v [kroku 0](/cs/on-premises/installation/using-kubernetes/0.-prepare-the-nodes) |

Obrazy jsou veřejně dostupné na [ghcr.io](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/) pro amd64 a arm64, takže je kubelet může stáhnout bez přihlašovacích údajů.

<Warning>

Vždy používejte tag verze, například `6.3.2`, nikoli `latest`. Upgrady spouštějí migrace databáze a musí se řídit postupem [Upgrade na Kubernetes](/cs/on-premises/maintenance/upgrading-on-kubernetes); pohyblivý tag by pod upgradoval pokaždé, když je přeplánován.

</Warning>

### Q\&A

<Accordion title="Naše uzly se nedostanou na ghcr.io. Co máme dělat?">

<strong>Odpověď:</strong> Zkopírujte obrazy do registru, na který uzly dosáhnou, a v manifestech použijte tento název, například:

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:6.3.2
docker tag ghcr.io/ayaka-notes/overleaf-pro:6.3.2 registry.example.com/ayakaleaf/overleaf-pro:6.3.2
docker push registry.example.com/ayakaleaf/overleaf-pro:6.3.2
```

Pro registr bez TLS potřebuje containerd na každém uzlu soubor `/etc/containerd/certs.d/<registry>/hosts.toml` se `server = "http://<registry>"` a `config_path` nastavené jako v [kroku 0](/cs/on-premises/installation/using-kubernetes/0.-prepare-the-nodes). Docker sám pushuje přes čisté HTTP pouze na `localhost`, proto pushujte přes `localhost:<port>` na hostiteli registru, nebo registr přidejte do `insecure-registries`.

</Accordion>
