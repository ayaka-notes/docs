Ayakaleaf Pro běží v Dockeru. Na Macu používáte Docker Desktop, který spouští engine Dockeru ve virtuálním počítači s Linuxem.

<Steps>
<Step title="Nainstalujte a spusťte Docker Desktop">
Nainstalujte sestavení [Docker Desktop](https://docs.docker.com/desktop/setup/install/mac-install/) pro svůj Mac (Apple silicon nebo Intel), otevřete jej a počkejte, až se engine spustí. Můžete jej spustit také z Terminálu:

```bash
open -a Docker
```
</Step>

<Step title="Zkontrolujte engine Dockeru">
Spusťte v Terminálu tyto příkazy:

```bash
docker context show
docker info
docker compose version
```

Kontext by měl ukazovat na váš lokální engine Docker Desktop, obvykle `desktop-linux`. Pokud je vybrán jiný kontext, přepněte se před pokračováním na Docker Desktop:

```bash
docker context use desktop-linux
```

`docker info` musí vypsat sekci **Server**. Samotný `docker --version` ukazuje pouze to, že je nainstalován klient.
</Step>

<Step title="Zkontrolujte prostředky a sdílení souborů">
V **Settings** aplikace Docker Desktop zkontrolujte limity CPU, paměti a disku podle části [Než začnete](/cs/on-premises/installation/using-docker-compose/macos#before-you-start) a nastavení sdílení souborů, viz [nastavení Docker Desktop](https://docs.docker.com/desktop/settings-and-maintenance/settings/).

Tento návod ukládá Toolkit pod `/Users`, který Docker Desktop ve výchozím nastavení sdílí. Pokud použijete jiné umístění a `bin/up` selže s `Mounts denied`, přidejte tento adresář do sdílení souborů.
</Step>

<Step title="Zkontrolujte Docker socket pro Sandboxed Compiles">
Toolkit připojuje `/var/run/docker.sock` do aplikace, aby mohla pro každou kompilaci spustit samostatný kontejner TeX Live. Ponechte v `config/overleaf.rc` nastavení `DOCKER_SOCKET_PATH=/var/run/docker.sock`.

Docker CLI na macOS se může připojovat přes `~/.docker/run/docker.sock`. To je koncový bod klienta na Macu, nikoli důvod měnit zdroj připojení v Toolkitu: kompilátor potřebuje socket enginu tak, jak jej vidí linuxové kontejnery.

Pokud na Macu `/var/run/docker.sock` chybí, zapněte **Allow the default Docker socket to be used** v **Settings → Advanced**, viz [požadavky Dockeru na oprávnění](https://docs.docker.com/desktop/setup/install/mac-permission-requirements/).

<Danger>

Nespouštějte na socketu `chmod 777`, abyste obešli chyby. Přístup k Docker socketu odpovídá přístupu roota k virtuálnímu počítači Dockeru.

</Danger>
</Step>
</Steps>
