V této sekci spustíme Ayakaleaf Pro lokálně na vašem Macu pomocí Docker Desktop a [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). Návod používá `http://localhost:8080`, ukládá data do vašeho domovského adresáře a kompiluje pomocí TeX Live 2026 v izolovaných (sandboxed) kontejnerech.

Docker Desktop spouští aplikaci, MongoDB, Redis a kompilátor TeX Live ve virtuálním počítači s Linuxem. MongoDB, Redis ani MacTeX do samotného macOS neinstalujete.

Toto nastavení používejte pro osobní použití a lokální testování. Pro trvale dostupnou sdílenou službu doporučujeme [návod pro Linux](/cs/on-premises/installation/using-docker-compose/linux) s HTTPS, zálohami a řízením přístupu. Instance není dostupná, když Mac spí nebo je Docker Desktop zastavený, viz [Zajištění dostupnosti instance](/cs/on-premises/installation/using-docker-compose/macos/6.-post-installation-tasks#keep-the-instance-available).

## Než začnete {#before-you-start}

Potřebujete:

* Verzi macOS podporovanou [Docker Desktop pro Mac](https://docs.docker.com/desktop/setup/install/mac-install/).
* Git, [Homebrew](https://brew.sh/) a GNU sed. Toolkit používá volby GNU sed, které BSD sed vestavěný v macOS nepřijímá.
* Dostatek prostředků pro macOS i Docker. Pro malou lokální instanci začněte se 4 CPU a 8 GB paměti přidělenými Docker Desktop. Jde o doporučený výchozí bod, nikoli o změřené minimum.
* Alespoň 40 GB volného místa pro plný image TeX Live a k tomu místo pro vaše projekty. Zkontrolujte volné místo na Macu i limit využití disku v Docker Desktop. Začněte s jednou verzí TeX Live: každá další verze potřebuje přibližně stejně místa navíc.

Image aplikace a TeX Live jsou publikovány pro `arm64` i `amd64`. Na Apple silicon nechte Docker vybrat nativní ARM image a nevynucujte `platform: linux/amd64`.
