<Steps>
<Step title="Zkontrolujte Git a Homebrew">
```bash
git --version
brew --version
```

Pokud vás macOS při spuštění Gitu vyzve k instalaci Command Line Tools, nejprve je nainstalujte. Pokud Homebrew chybí, nainstalujte jej podle [oficiálních pokynů](https://brew.sh/).
</Step>

<Step title="Přidejte GNU sed do PATH">
Skripty Toolkitu používají volby GNU sed, které BSD sed vestavěný v macOS odmítá. Nainstalujte [GNU sed](https://formulae.brew.sh/formula/gnu-sed) a v tomto terminálu jej umístěte na první místo v `PATH`:

```bash
brew install gnu-sed
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
sed --version
```

Poslední příkaz by měl vypsat **GNU sed**.

Alias jako `alias sed=gsed` nestačí: Toolkit spouští skripty Bash, které aliasy vašeho interaktivního shellu nevidí. `/usr/bin/sed` nahrazovat nemusíte.

Řádek `export PATH=...` spusťte znovu v každém novém terminálu, který pro Toolkit používáte, nebo jej přidejte do spouštěcího souboru svého shellu za vlastní inicializaci Homebrew.
</Step>

<Step title="Naklonujte repozitář Ayakaleaf Toolkit">
Zvolte adresář, který přetrvá. Pro živou databázi a data projektů se vyhněte `/tmp`, vyměnitelným diskům a složkám synchronizovaným s cloudem, jako je iCloud Drive. Tento návod používá `~/ayakaleaf-toolkit`:

```bash
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

<Warning>

Pokud adresář již obsahuje instalaci, použijte ji tak, jak je, nebo pro novou instanci zvolte jiný adresář. Neinicializujte novou konfiguraci přes existující nasazení.

</Warning>
