### Vytvoření administrátora a prvního projektu {#create-the-administrator-and-a-first-project}

Otevřete [http://localhost:8080/launchpad](http://localhost:8080/launchpad), vytvořte první administrátorský účet a přihlaste se. Poté postupujte podle kroku [6. Úlohy po instalaci](/cs/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks) návodu pro Linux a v jeho ukázkových URL použijte port `8080`.

### Ověření kompilace {#verify-compilation}

To, že se otevře přihlašovací stránka, ještě nedokazuje, že fungují samostatné kompilační kontejnery a jejich připojená data. Vytvořte prázdný projekt a zkompilujte tento `main.tex`:

```latex
\documentclass{article}
\begin{document}
Ayakaleaf Pro on macOS.
\end{document}
```

Náhled PDF by měl zobrazit text. V případě potřeby vyberte v nastavení projektu TeX Live 2026.

U projektu s čínským textem vyberte jako kompilátor **XeLaTeX** a otestujte:

```latex
\documentclass{ctexart}
\begin{document}
你好，Ayakaleaf Pro。
\end{document}
```

### Ověření trvalosti dat {#verify-persistence}

```bash
bin/stop
bin/start
```

Znovu otevřete projekt a zkompilujte jej. Váš účet, zdrojový kód i soubory projektu by tam měly stále být. Při výchozích cestách jsou živá data v adresáři `data/` Toolkitu na vašem Macu.

### Zajištění dostupnosti instance {#keep-the-instance-available}

Když Mac spí, macOS uspí virtuální počítač Docker Desktop se všemi kontejnery v něm: instanci nikdo nemůže otevřít a probíhající kompilace se zastaví, dokud se Mac neprobudí. Záleží pouze na spánku systému. Displej se vypnout může.

Pokud instanci používají další lidé nebo necháváte běžet dlouhé úlohy, nechte Mac připojený k napájení a zabraňte automatickému spánku, viz [Nastavení spánku a probouzení na Macu](https://support.apple.com/guide/mac-help/set-sleep-and-wake-settings-mchle41a6ccd/mac):

| Mac | Nastavení |
| --- | --- |
| Stolní Mac (Mac mini, iMac, Mac Studio, Mac Pro) | **System Settings → Energy**: zapněte **Prevent automatic sleeping when the display is off** |
| MacBook | **System Settings → Battery → Options**: zapněte **Prevent automatic sleeping on power adapter when the display is off**. Platí to jen tehdy, když je připojen napájecí adaptér, a zavření víka MacBook stále uspí |

Chcete-li Mac udržet vzhůru jen na nějakou dobu, spusťte místo toho v okně Terminálu `caffeinate -i`. Zabrání uspání při nečinnosti, dokud nestisknete `Ctrl+C` nebo okno nezavřete.

Docker Desktop je aplikace ve vaší uživatelské relaci. Aby byla instance po restartu opět k dispozici, zapněte v Docker Desktop v **Settings → General** volbu **Start Docker Desktop when you sign in to your computer**. Kontejnery Toolkitu používají `restart: always`, takže je Docker po spuštění Docker Desktop znovu spustí i bez `bin/up`. Dokud se po restartu nikdo k Macu nepřihlásí, instance zůstává nedostupná.

<Info>

Mac, který zůstává vzhůru, spotřebovává více energie. Pro službu, která musí být vždy dostupná, doporučujeme linuxový server, viz [Linux](/cs/on-premises/installation/using-docker-compose/linux).

</Info>

### Každodenní používání {#daily-use}

Než začnete instanci spravovat, otevřete Docker Desktop. V novém terminálu:

```bash
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
cd "$HOME/ayakaleaf-toolkit"
```

| Úloha | Příkaz |
| --- | --- |
| Spustit existující kontejnery | `bin/start` |
| Zastavit kontejnery a zachovat data | `bin/stop` |
| Použít změny konfigurace | `bin/up -d` |
| Zkontrolovat stav | `bin/docker-compose ps` |
| Číst logy spouštění | `bin/docker-compose logs --tail=100 sharelatex` |
| Číst logy kompilátoru | `bin/logs -f clsi` |

`bin/start` nepoužije změny v `config/`: po úpravě konfigurace spusťte `bin/up -d`. Uchovejte `config/` a `data/` a před upgradem nebo přesunem instalace postupujte podle návodu [Data a zálohy](/cs/on-premises/maintenance/data-and-backups). Kopírování databázových souborů, zatímco do nich MongoDB zapisuje, není konzistentní záloha.

Pro lokální použití ponechte instanci na `127.0.0.1`. Chcete-li obsluhovat další počítače, nastavte adresu naslouchání, URL webu a HTTPS záměrně, viz krok [5. Přizpůsobení instance](/cs/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance) návodu pro Linux.

Pokud něco nefunguje, viz [Řešení problémů](/cs/on-premises/installation/using-docker-compose/macos/troubleshooting).
