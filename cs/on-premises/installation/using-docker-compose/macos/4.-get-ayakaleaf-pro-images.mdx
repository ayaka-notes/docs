Ayakaleaf Pro je bezplatný Docker image v [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). K jeho stažení nepotřebujete účet, přihlášení ani komerční licenci Overleaf.

Otevřete `config/overleaf.rc` a nastavte:

```bash title="config/overleaf.rc"
SERVER_PRO=true
```

Při příštím spuštění `bin/up` Toolkit stáhne `ghcr.io/ayaka-notes/overleaf-pro` ve verzi uvedené v `config/version` namísto oficiální edice Overleaf Community Edition.

Image je sestaven pro `arm64` i `amd64` a Docker vybere ten, který odpovídá vašemu Macu. Na Apple silicon nepřidávejte do override `platform: linux/amd64`: image by pak běžel v emulaci.
