### Inicializace konfigurace {#initializing-the-configuration}

Inicializujme konfigurační soubory našeho nového serveru s rozumnými výchozími hodnotami spuštěním přiloženého skriptu `bin/init`.

```text title="Run initialization"
bin/init
```

Tento skript **nepřepíše** žádné existující konfigurační soubory.

Nyní zkontrolujme obsah adresáře `config/` pomocí příkazu `ls`:

```text title="List the config directory"
ls config
```

Pokud vše proběhlo úspěšně, měli byste vidět tři konfigurační soubory: `config/overleaf.rc`, `config/variables.env` a `config/version`. Jde o hlavní konfigurační soubory serveru, které vám umožňují přizpůsobit, jak váš server funguje a jak uživatelé s vaší instancí pracují.

| Název           | Popis                                                   |
| --------------- | ------------------------------------------------------- |
| `config/overleaf.rc`   | Hlavní konfigurační soubor nejvyšší úrovně, který čtou skripty Toolkitu. Určuje, jak kontejnery běží, například adresu a port, na kterých naslouchají (`OVERLEAF_LISTEN_IP`, výchozí `127.0.0.1`, a `OVERLEAF_PORT`, výchozí `80`). |
| `config/variables.env` | Proměnné prostředí načítané do Docker kontejneru. Určují, jak se Overleaf chová, například `OVERLEAF_SITE_URL`. |
| `config/version`       | Verze Docker image, která se má použít.                 |

Vygeneruje také `OVERLEAF_INVITE_TOKEN_SECRET` v `config/variables.env`. Uchovejte ho a tento soubor nezveřejňujte ani necommitujte do správy verzí.

<Info>

Prozatím stačí vědět, že tyto soubory existují a kde je najdete. Později v dokumentaci si každý z nich projdeme podrobněji a vysvětlíme, jak pomocí nich můžete svou instanci přizpůsobit. Pokud chcete přeskočit dopředu, úplný přehled těchto konfiguračních souborů najdete na [stránce Soubory a umístění](/cs/on-premises/configuration/overleaf-toolkit/files-and-locations).

</Info>
