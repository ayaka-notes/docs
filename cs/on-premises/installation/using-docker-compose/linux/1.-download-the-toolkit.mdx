### Stažení Toolkitu {#downloading-the-toolkit}

Ayakaleaf Pro se instaluje pomocí **Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)), sady skriptů, které za vás spouštějí Overleaf v Dockeru.

Ve výchozím nastavení Toolkit spouští bezplatnou oficiální edici Overleaf Community Edition (CE). Krok [4. Získání obrazů Ayakaleaf Pro](/cs/on-premises/installation/using-docker-compose/linux/4.-get-overleaf-pro-images) jej jediným nastavením přepne na Ayakaleaf Pro.

<Accordion title="Už provozujete oficiální Overleaf Toolkit (overleaf/toolkit)?">

Nemusíte nic přeinstalovávat. Ponechte svou instalaci a postupujte podle poslední části kroku [4. Získání obrazů Ayakaleaf Pro](/cs/on-premises/installation/using-docker-compose/linux/4.-get-overleaf-pro-images).

</Accordion>

<Steps>
<Step title="Naklonujte repozitář Ayakaleaf Toolkit">
Chcete-li Toolkit nainstalovat, přejděte do zamýšleného instalačního adresáře a poté naklonujte repozitář Ayakaleaf Toolkit tímto příkazem:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
```

<Info>

Abyste předešli případným problémům s oprávněními, doporučujeme instalovat Toolkit do adresáře `$HOME` vašeho uživatele.

</Info>
</Step>

<Step title="Přejděte do adresáře toolkitu">
Počkejte, až se klonování dokončí, a poté se přepněte do nově vytvořeného adresáře `overleaf-toolkit`:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
