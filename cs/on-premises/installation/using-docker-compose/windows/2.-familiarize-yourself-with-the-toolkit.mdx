Toolkit je stejný jako na Linuxu. Jeho struktura, adresář `config/` a příkazy v `bin/` jsou popsány v kroku [2. Seznamte se s Toolkitem](/cs/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) návodu pro Linux.

Ve Windows mějte na paměti tyto rozdíly:

* Příkazy `bin/` spouštějte v **Ubuntu Bash** z adresáře `~/ayakaleaf-toolkit`. Příkazy označené **PowerShell** se naopak spouštějí ve Windows.
* Než použijete `bin/up`, `bin/start` nebo `bin/docker-compose`, spusťte Docker Desktop a zapněte WSL Integration pro Ubuntu.
* Konfigurační soubory uchovávejte s linuxovými konci řádků (LF). Upravujte je pomocí `nano` v Ubuntu nebo v editoru připojeném k WSL. Konce řádků CRLF mohou způsobit chyby v Bash.
* `bin/doctor` spouští linuxové kontroly uvnitř Ubuntu. Jeho varování o nepřihlášení do `quay.io` se netýká veřejného image `ghcr.io/ayaka-notes/overleaf-pro`. Ostatní varování stále vyžadují pozornost.

```bash
bin/doctor
```
