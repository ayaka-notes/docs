---
title: 5. Přizpůsobení instance
description: Nastavte port, URL webu a image TeX Live, zapněte Sandboxed Compiles a spusťte Ayakaleaf Pro na WSL 2.

---

Příkazy spouštějte a soubory upravujte v **Ubuntu** z adresáře `~/ayakaleaf-toolkit`.

<Steps>
<Step title="Nastavení kontejnerů">
Upravte existující položky v `config/overleaf.rc`:

```bash title="config/overleaf.rc"
PROJECT_NAME=ayakaleaf-wsl
SERVER_PRO=true
OVERLEAF_LISTEN_IP=127.0.0.1
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
DOCKER_SOCKET_PATH=/var/run/docker.sock
```

Ponechte výchozí cesty k datům a přibalené služby MongoDB a Redis. Port `8080` je určen pro lokální prohlížeč ve Windows; navázání na `127.0.0.1` jej udržuje lokální. Sandboxed Compiles používají pro každou kompilaci samostatný linuxový kontejner, místo aby TeX běžel uvnitř kontejneru aplikace. Docker socket umožňuje aplikaci tyto kontejnery vytvářet a Toolkit dodává cestu na hostiteli pro data kompilace v `data/overleaf/data/compiles`.
</Step>

<Step title="Nastavení aplikace">
V `config/variables.env` nastavte tyto hodnoty a nahraďte jimi případné aktivní položky se stejnými názvy:

```dotenv title="config/variables.env"
OVERLEAF_SITE_URL=http://localhost:8080
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES="TeX Live 2026"
```

Plný image obsahuje balíčky a písma potřebná pro širokou škálu projektů. Počítejte pro něj a pro aplikaci s alespoň 40 GB volného místa a k tomu s místem pro data projektů a budoucí aktualizace.

Pro rychlý test nasazení použijte místo toho menší image **basic**. Pro jednoduchý test článku v kroku 6 stačí, ale neobsahuje plnou sadu balíčků a písem:

```dotenv
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-basic:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-basic:2026.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES="TeX Live 2026 Basic"
```

Vyberte jednu z těchto sad, bez duplicitních aktivních klíčů. [Dockerfile](https://github.com/ayaka-notes/texlive-full/blob/main/texlive/2026/Dockerfile.basic) image basic obsahuje `latexmk`, XeTeX a `fontspec`, ale ne `ctex` ani plnou kolekci písem. Chybějící balíček LaTeXu v image basic sám o sobě neznamená problém se sandboxem.

Vygenerujte tajný klíč relace:

```bash
openssl rand -hex 32
```

Výsledek přidejte jako `OVERLEAF_SESSION_SECRET` do `config/variables.env`. Uschovejte také vygenerovaný tajný klíč pro tokeny pozvánek. Pro lokální instanci bez e-mailu ponechte nastavení SMTP a `OVERLEAF_EMAIL_FROM_ADDRESS` nenastavené.
</Step>

<Step title="Spusťte instanci">
```bash
bin/up -d
```

Toolkit spustí MongoDB, inicializuje jeho replica set, stáhne vybraný image TeX Live a spustí Redis a aplikaci. Během stahování velkého image se může zdát, že se zastavil. Nespouštějte druhý `bin/up`, dokud první stále pracuje.

V jiném terminálu Ubuntu zkontrolujte:

```bash
cd "$HOME/ayakaleaf-toolkit"
bin/docker-compose ps
bin/docker-compose logs --tail=100 mongo
bin/docker-compose logs --tail=100 -f sharelatex
```

Stisknutím `Ctrl+C` sledování logů ukončíte; odpojené kontejnery poběží dál. Pokud spuštění selže u MongoDB, postupujte před dalším pokusem podle části [MongoDB se nespustí](/cs/on-premises/installation/using-docker-compose/windows/troubleshooting#mongodb-fails-to-start). Nemažte jeho datový adresář, abyste resetovali existující instalaci.

Zkontrolujte port a stránku prvního spuštění:

```bash
bin/docker-compose port sharelatex 80
curl -I http://localhost:8080/launchpad
```

Port by měl být `127.0.0.1:8080`. Pokud HTTP požadavek zpočátku selže, počkejte na inicializaci aplikace.
</Step>

<Step title="Otevřete instanci z Windows">
V **prohlížeči ve Windows** otevřete [http://localhost:8080/launchpad](http://localhost:8080/launchpad). I ve Windows používejte tuto adresu, nikoli dočasnou IP adresu WSL.

Chcete-li přístup HTTP z Windows ověřit odděleně od prohlížeče, spusťte v **PowerShellu**:

```powershell
curl.exe -I http://localhost:8080/launchpad
```

Pokud Ubuntu stránku otevře, ale Windows ne, viz [Windows nemohou otevřít localhost](/cs/on-premises/installation/using-docker-compose/windows/troubleshooting#windows-cannot-open-localhost).
</Step>
</Steps>
