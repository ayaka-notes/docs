---
title: 3. Inicializace konfigurace
description: Vytvořte konfigurační soubory Toolkitu v Ubuntu na WSL 2 pomocí bin/init.
icon: circle-play
---

V adresáři Toolkitu v **Ubuntu** spusťte:

```bash
bin/init
```

`bin/init` vytvoří tři soubory:

| Soubor | Účel |
| --- | --- |
| `config/overleaf.rc` | Nastavení kontejnerů, publikovaný port a umístění dat |
| `config/variables.env` | Nastavení aplikace a tajné klíče |
| `config/version` | Verze image aplikace |

Zároveň vygeneruje `OVERLEAF_INVITE_TOKEN_SECRET` v `config/variables.env`. Uschovejte jej a tento soubor nezveřejňujte ani jej necommitujte do správy verzí.

Ponechte verzi, kterou Toolkit pro novou instalaci vybere. Chcete-li později změnit verzi existující instance, postupujte podle návodu [Upgrade nasazení](/cs/on-premises/maintenance/upgrading-your-deployment).

<Info>

`bin/init` nepřepisuje existující konfiguraci. Pokud hlásí, že soubory již existují, před pokračováním je zkontrolujte. Při restartu nebo upgradu instance zachovejte `config/` a `data/`.

</Info>
