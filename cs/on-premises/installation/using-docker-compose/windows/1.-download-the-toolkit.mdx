<Steps>
<Step title="Nainstalujte nástroje příkazové řádky">
Spusťte v **Ubuntu** s použitím linuxového hesla, které jste vytvořili v kroku 0:

```bash
sudo apt update
sudo apt install -y git ca-certificates curl perl gawk openssl
```

Ubuntu již obsahuje Bash, GNU sed a coreutils. Na rozdíl od macOS nepotřebuje Homebrew ani samostatnou instalaci GNU sed.
</Step>

<Step title="Naklonujte repozitář Ayakaleaf Toolkit">
Uchovávejte Toolkit a jeho data v linuxovém souborovém systému Ubuntu, ve svém domovském adresáři:

```bash
cd "$HOME"
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

Pro živou databázi a data projektů se vyhněte `/mnt/c`, `/mnt/d`, OneDrive a dočasným adresářům. Cesty v linuxovém souborovém systému poskytují oprávnění a chování souborového systému, které kontejnery očekávají, a vyhýbají se režii mezi souborovými systémy; viz [doporučení Microsoftu k souborovým systémům](https://learn.microsoft.com/en-us/windows/wsl/filesystems).

<Warning>

Pokud adresář již obsahuje instalaci, použijte ji tak, jak je, nebo pro novou instanci zvolte jiný adresář. Nenahrazujte konfiguraci ani data existujícího nasazení.

</Warning>
