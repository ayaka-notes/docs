V této sekci spustíme Ayakaleaf Pro lokálně na Windows pomocí WSL 2, Ubuntu, Docker Desktop a [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). Návod používá `http://localhost:8080`, ukládá data do domovského adresáře Ubuntu a zapíná Sandboxed Compiles.

Aplikace, MongoDB, Redis a TeX Live běží v linuxových kontejnerech spravovaných Docker Desktop. Příkazy Toolkitu spouštějte v Ubuntu; aplikaci otevírejte v prohlížeči ve Windows. [Krok 0](/cs/on-premises/installation/using-docker-compose/windows/0.-setup-wsl-and-docker-desktop) vysvětluje, jak do sebe části Windows a Linuxu zapadají, a začíná instalací WSL.

Windows můžete použít pro lokální instanci nebo ji nechat běžet nepřetržitě pomocí nastavení dostupnosti v kroku 6. Pro sdílené a produkční servery doporučujeme [návod pro Linux](/cs/on-premises/installation/using-docker-compose/linux) s HTTPS, zálohami a řízením přístupu. Spánek Windows, vypnutí Docker Desktop a vypnutí WSL tuto lokální instanci přeruší; viz [Zajištění dostupnosti instance](/cs/on-premises/installation/using-docker-compose/windows/6.-post-installation-tasks#keep-the-instance-available).

## Než začnete {#before-you-start}

Potřebujete:

* Verzi Windows a procesor podporované [Docker Desktop pro Windows](https://docs.docker.com/desktop/setup/install/windows-install/) se zapnutou hardwarovou virtualizací. Tento návod používá Windows 11 na x86-64.
* Oprávnění zapnout WSL a instalovat software. WSL musí být ve verzi 2.1.5 nebo novější a Ubuntu musí běžet v režimu WSL 2.
* Dostatek paměti pro Windows i kontejnery. Pro malou lokální instanci jsou 4 CPU a 8 GB dostupné pro Docker doporučeným výchozím bodem, nikoli změřeným minimem.
* Volné místo na disku Windows, na kterém jsou data WSL a Dockeru. Počítejte alespoň se 40 GB pro plné nastavení TeX Live a data projektů; základní image v [kroku 5](/cs/on-premises/installation/using-docker-compose/windows/5.-personalizing-your-instance) je menší a hodí se pro úvodní test nasazení. Další verze image potřebují další místo.
* Síťový přístup ke GitHubu, GitHub Container Registry (`ghcr.io`) a Docker Hubu pro naklonování Toolkitu a stažení image.

Bloky **PowerShell** se spouštějí ve Windows. Bloky **Bash** a příkazy `bin/` se spouštějí v Ubuntu, pokud není uvedeno jinak. Nespouštějte skripty Toolkitu v PowerShellu ani v Git Bash pro Windows.
