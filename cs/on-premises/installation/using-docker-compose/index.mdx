Docker Compose na jednom serveru je doporučený způsob nasazení Ayakaleaf Pro. Spouštíte jej prostřednictvím [Toolkitu](https://github.com/ayaka-notes/toolkit): sady skriptů, které obalují `docker compose` a načítají vaše nastavení z jednoho adresáře `config/`, takže `bin/up` nahrazuje `docker compose up`.
