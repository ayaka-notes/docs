---
title: Nasazení v izolovaném/offline prostředí
description: Nasaďte Ayakaleaf Pro offline exportem, přenosem a načtením Docker image.
icon: block-brick
---

Obecně nedoporučujeme nasazovat Ayakaleaf Pro v offline prostředí, protože mnoho jeho funkcí, například GitHub Sync a integrace se Zoterem, vyžaduje připojení k internetu.

Pokud chcete pracovat offline, nemusí být vždy možné dosáhnout na registr `ghcr.io` a stáhnout potřebné image `ayakaleaf-pro` a TeX Live. To není problém, protože Docker poskytuje nástroje pro export a import image, které vám s offline/izolovaným nasazením pomohou.

Zjednodušeně řečeno: potřebné image stáhnete na zařízení s připojením k internetu, exportujete je na přenosné zařízení (nebo je přenesete pomocí SCP/Rsync) a importujete je na izolovaný server.

K tomu je potřeba provést následující kroky:

* Na počítači s připojením k internetu stáhněte všechny potřebné image ( `overleaf-pro`, `git-bridge`, `mongo`, `redis` + případné potřebné [image TeX Live](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles#available-tex-live-images) pro použití se [Sandboxed Compiles](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles))
  * `docker pull ghcr.io/ayaka-notes/overleaf-pro:6.3.0`
  * `docker pull ghcr.io/ayaka-notes/overleaf-pro/git-bridge:6.3.0` (tag musí být stejný jako u `overleaf-pro`)
  * `docker pull mongo:8.0` (změňte prosím na skutečnou verzi)
  * `docker pull redis:7.4` (změňte prosím na skutečnou verzi)
  * `docker pull ghcr.io/ayaka-notes/texlive-full:2024.1` (změňte prosím na skutečnou verzi)
* **Každý** ze stažených image pak musíte exportovat do souboru .tar. Například `docker save ghcr.io/ayaka-notes/overleaf-pro:6.3.0 > overleaf-pro:6.3.0.tar`
* Libovolnou metodou přeneste soubory `.tar` z počítače připojeného k internetu na offline/izolovaný server
* Pro každý soubor .tar použijte příkaz `docker load` k načtení image ze souboru .tar. Například `docker load < overleaf-pro:6.3.0.tar`
* Nakonec spusťte příkaz `docker images` a ověřte, že se image úspěšně načetly a jsou k dispozici

<Danger>

Ve výchozím nastavení se Toolkit při spuštění příkazu `bin/up` pokusí automaticky stáhnout každý z image TeX Live nastavených pomocí `ALL_TEX_LIVE_DOCKER_IMAGES` v `config/variables.env`. Protože je vaše nasazení izolované, selže to -- tomu můžete zabránit nastavením `SIBLING_CONTAINERS_PULL=false` v `config/overleaf.rc`.

</Danger>
