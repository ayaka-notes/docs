---
title: 0. Příprava hostitele
description: Před nastavením rootless Podmanu zkontrolujte operační systém a SELinux a nainstalujte git.
icon: server
---

Podman neinstalujete ručně: krok [2. Spuštění podman-setup](/cs/on-premises/installation/using-podman/2.-run-podman-setup) jej nainstaluje spolu s dalšími potřebnými balíčky. Zde pouze zkontrolujete hostitele a nainstalujete `git`, který potřebujete ke stažení Toolkitu.

<Steps>
<Step title="Kontrola operačního systému a SELinuxu">
Přihlaste se jako uživatel, který bude spouštět Ayakaleaf Pro, nikoli jako `root`, a zkontrolujte distribuci a režim SELinuxu:

```bash title="Check the host"
grep PRETTY_NAME /etc/os-release
getenforce
```

Měli byste vidět RHEL, Rocky Linux, AlmaLinux nebo CentOS Stream ve verzi 9 či novější a `Enforcing`:

```text
PRETTY_NAME="Rocky Linux 9.9 (Blue Onyx)"
Enforcing
```
</Step>

<Step title="Kontrola, že můžete používat sudo">
`bin/podman-setup --apply` instaluje balíčky a načítá modul SELinuxu pomocí `sudo` a v případě potřeby se zeptá na vaše heslo:

```bash title="Check sudo"
sudo -v
```

Pokud to selže, požádejte správce, aby přidal vašeho uživatele do skupiny `wheel`.
</Step>

<Step title="Instalace gitu">
```bash title="Install git"
sudo dnf install -y git
```

<Warning>

Na tohoto hostitele neinstalujte Docker Engine. Balíček `podman-docker`, který instaluje `bin/podman-setup`, poskytuje příkaz `docker` a Toolkit považuje hostitele za Podman vždy, když existuje příkaz `podman`.

</Warning>
</Step>
</Steps>
