<Steps>
<Step title="Klonování Toolkitu">
Naklonujte **Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)) do domovského adresáře a přejděte do něj:

```bash title="Clone the Toolkit" wrap
git clone https://github.com/ayaka-notes/toolkit.git ~/overleaf-toolkit
cd ~/overleaf-toolkit
```

Všechny další příkazy spouštějte z tohoto adresáře.
</Step>

<Step title="Vytvoření konfigurace">
```bash title="Run initialization"
bin/init
```

Tím se vytvoří `config/overleaf.rc`, `config/variables.env` a `config/version`, jak je popsáno v kroku [3. Inicializace konfigurace](/cs/on-premises/installation/using-docker-compose/linux/3.-initialize-the-configuration) průvodce pro Docker. `bin/init` zatím Podman nepotřebuje.
</Step>

<Step title="Nastavení config/overleaf.rc">
Otevřete `config/overleaf.rc` a změňte tyto řádky:

```bash title="config/overleaf.rc"
SERVER_PRO=true
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
```

Poté na konec souboru přidejte tento řádek:

```bash title="config/overleaf.rc"
SELINUX_MODE=managed
```

| Nastavení                         | Proč                                                                                                                                                                                                         |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `SERVER_PRO=true`                 | Používá obraz Ayakaleaf Pro z `ghcr.io`. Přihlášení není potřeba.                                                                                                                                            |
| `OVERLEAF_PORT=8080`              | Rootless Podman nemůže naslouchat na portech pod `1024`. Výchozí port `80` selže.                                                                                                                             |
| `SIBLING_CONTAINERS_ENABLED=true` | Spouští každou kompilaci ve vlastním kontejneru TeX Live. Ve výchozím stavu už `true`; nastavení Podmanu podporuje pouze tento režim.                                                                        |
| `SELINUX_MODE=managed`            | Spouští kontejner `sharelatex` s typem SELinuxu `sharelatex_t`, který smí používat socket Podmanu a nic dalšího. `bin/podman-setup --apply` pro něj nainstaluje modul politiky. Další režimy najdete v části [Nastavení Toolkitu](/cs/on-premises/configuration/overleaf-toolkit/toolkit-settings). |

`DOCKER_SOCKET_PATH` ponechte beze změny: `bin/podman-setup --apply` jej v dalším kroku nastaví na váš socket Podmanu.

<Warning>

Ponechte `GIT_BRIDGE_ENABLED=false`. V Ayakaleaf Pro 6.3.4 integrace s Gitem na Podmanu nefunguje, viz [Známá omezení](/cs/on-premises/installation/using-podman#known-limitations).

</Warning>
</Step>

<Step title="Výběr obrazů TeX Live">
Otevřete `config/variables.env`, odstraňte `#` před `TEX_LIVE_DOCKER_IMAGE` a `ALL_TEX_LIVE_DOCKER_IMAGES` a uveďte obrazy TeX Live, které chcete používat:

```bash title="config/variables.env" wrap
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
```

Pokud je seznam prázdný, `bin/up` se zastaví se zprávou `Please configure ALL_TEX_LIVE_DOCKER_IMAGES`. Obraz `texlive-full` je velký; pro testovací server postačí i mnohem menší `ghcr.io/ayaka-notes/texlive-basic:2026.1`. Dostupné obrazy najdete v části [Sandboxed Compiles](/cs/on-premises/configuration/overleaf-toolkit/sandboxed-compiles).

Nastavte další proměnné, například `OVERLEAF_SITE_URL`, jak je popsáno v kroku [5. Přizpůsobení instance](/cs/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance#required-environment-variables). S výchozí adresou naslouchání použijte `http://localhost:8080`.
</Step>
</Steps>
