### Stažení Toolkitu

Toolkit je kompatibilní se Server CE i s Ayakaleaf Pro a je doporučeným způsobem instalace. Díky Toolkitu můžete se Server CE snadno začít a v případě potřeby plynule přejít na Ayakaleaf Pro.

<Info>

[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) je upraven tak, aby přímo používal image overleaf-pro z ghcr, přičemž TeX Live poskytuje ayaka-notes. Alternativně si můžete stáhnout oficiální overleaf-toolkit.

</Info>

<Steps>
<Step title="Naklonujte repozitář Overleaf Toolkit">
Chcete-li Toolkit nainstalovat, přejděte do zamýšleného instalačního adresáře a poté naklonujte GitHub repozitář Overleaf Toolkit (@Ayaka-notes) tímto příkazem:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
# official toolkit (Not Recommended)
# git clone https://github.com/overleaf/toolkit.git ./overleaf-toolkit
```

<Info>

Abyste předešli případným problémům s oprávněními, doporučujeme instalovat Toolkit do adresáře `$HOME` vašeho uživatele.

</Info>
</Step>

<Step title="Přejděte do adresáře toolkitu">
Počkejte, až se klonování dokončí, a poté se přepněte do nově vytvořeného adresáře `overleaf-toolkit`:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
