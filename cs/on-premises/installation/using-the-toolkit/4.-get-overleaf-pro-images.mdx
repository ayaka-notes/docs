---
title: 4. Získání obrazů Ayakaleaf Pro
icon: split
---

Ayakaleaf Pro je bezplatný Docker obraz v [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Ke stažení nepotřebujete účet ani přihlášení. Obrazy jsou sestavovány pro amd64 i arm64 a Docker vybere ten, který odpovídá vašemu serveru.

Otevřete `config/overleaf.rc` a nastavte:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

Při příštím spuštění `bin/up` Toolkit stáhne obraz Ayakaleaf Pro a použije jej místo oficiální edice Overleaf Community Edition. Vaše nastavení v `config/` budou nadále fungovat.

<Accordion title="Už provozujete oficiální Overleaf Toolkit (overleaf/toolkit)?">

Nemusíte nic přeinstalovávat. Stáhněte obraz Ayakaleaf Pro:

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Poté do adresáře `overleaf-toolkit/config` přidejte soubor s názvem `docker-compose.override.yml` s následujícím obsahem:

```yml
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

Při příštím spuštění `bin/up` Toolkit použije obraz Ayakaleaf Pro.

</Accordion>
