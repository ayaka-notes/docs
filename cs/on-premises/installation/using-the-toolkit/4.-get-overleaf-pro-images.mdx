---
title: 4. Získání obrazů Ayakaleaf Pro
icon: split
---

Ayakaleaf Pro je distribuován jako Docker obraz v registru [ghcr](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/) a je **volně přístupný** komukoli. Poskytujeme obrazy pro architektury amd64 i arm64. Při stahování obrazu se automaticky vybere ten správný podle architektury vašeho systému.

#### Uživatelé Ayaka-notes Toolkit

Pokud používáte [ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit), lze Ayakaleaf Pro použít jako přímou náhradu Community Edition, takže můžete zachovat svá stávající nastavení a úpravy. Pro v Toolkitu zapnete úpravou souboru `config/overleaf.rc` a nastavením proměnné prostředí `SERVER_PRO`:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

Při příštím spuštění `bin/up` Toolkit automaticky stáhne a použije obraz Ayakaleaf Pro.

#### Uživatelé oficiálního Toolkitu

Pokud používáte [overleaf/toolkit](https://github.com/overleaf/toolkit), získáte obraz Pro stažením pomocí následujícího příkazu:

```bash title="Pull Docker Images"
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Poté do adresáře `overleaf-toolkit/config` přidejte soubor s názvem `docker-compose.override.yml` s následujícím obsahem:

```yml title="docker-compose.override.yml"
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

Při příštím spuštění `bin/up` Toolkit automaticky stáhne a použije obraz Ayakaleaf Pro.
