### Inicializace konfigurace

Inicializujme konfigurační soubory našeho nového serveru s rozumnými výchozími hodnotami spuštěním přiloženého skriptu `bin/init`.

```text title="Run initialization"
bin/init
```

Tento skript **nepřepíše** žádné existující konfigurační soubory.

Nyní zkontrolujme obsah adresáře `config/` pomocí příkazu `ls`:

```text title="List the config directory"
ls config
```

Pokud vše proběhlo úspěšně, měli byste vidět tři konfigurační soubory: `overleaf.rc`, `variables.env` a `version`. Jde o hlavní konfigurační soubory serveru, které vám umožňují přizpůsobit, jak váš server funguje a jak uživatelé s vaší instancí pracují.

| Název           | Popis                                                   |
| --------------- | ------------------------------------------------------- |
| `overleaf.rc`   | Hlavní konfigurační soubor nejvyšší úrovně.             |
| `variables.env` | Proměnné prostředí načítané do Docker kontejneru.       |
| `version`       | Verze Docker image, která se má použít.                 |

<Info>

Prozatím stačí vědět, že tyto soubory existují a kde je najdete. Později v dokumentaci si každý z nich projdeme podrobněji a vysvětlíme, jak pomocí nich můžete svou instanci přizpůsobit. Pokud chcete přeskočit dopředu, úplný přehled těchto konfiguračních souborů najdete na [stránce Soubory a umístění](/cs/on-premises/configuration/overleaf-toolkit/files-and-locations).

</Info>
