Overleaf běží na Dockeru. Musíte nainstalovat:

* Docker Engine (Docker CE)
* Plugin Docker Compose (`docker compose`, v2)

Tyto kroky jsou určeny pro aktuální Ubuntu LTS (20.04/22.04/24.04).

<Warning>

Neinstalujte `docker.io` z výchozího apt repozitáře Ubuntu.\
Použijte oficiální repozitář Dockeru, abyste získali aktuální verzi Dockeru a plugin `docker compose`.

</Warning>

Oficiální dokumentace pochází z: [https://docs.docker.com/engine/install/ubuntu/](https://docs.docker.com/engine/install/ubuntu/).

<Steps>
<Step title="1) Odstranění starých/konfliktních balíčků (jsou-li přítomny)">
Pokud byl Docker dříve nainstalován z jiného zdroje, nejprve jej odstraňte:

```bash wrap
sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-compose-v2 docker-doc podman-docker containerd runc | cut -f1)
```

Tento příkaz je bezpečný, i když některé balíčky nejsou nainstalovány.
</Step>

<Step title="2) Přidání oficiálního apt repozitáře Dockeru">
Nainstalujte potřebné závislosti:

```bash
sudo apt update
sudo apt install -y ca-certificates curl
```

Přidejte GPG klíč Dockeru:

```bash wrap
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```

Přidejte repozitář:

```bash wrap
# Add the repository to Apt sources:
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Signed-By: /etc/apt/keyrings/docker.asc
EOF

sudo apt update
```
</Step>

<Step title="3) Instalace Docker Engine a pluginu Compose">
Nainstalujte Docker a plugin Compose:

```bash wrap
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

Nastavte spouštění Dockeru při startu systému:

```bash
sudo systemctl enable --now docker
```
</Step>

<Step title="4) Ověření instalace">
Tyto příkazy by měly proběhnout bez chyb:

```bash
docker --version
docker compose version
sudo docker run --rm hello-world
docker ps
```
</Step>

<Step title="5) (Volitelné) Spouštění Dockeru bez sudo">
Přidejte svého uživatele do skupiny `docker`:

```bash
sudo usermod -aG docker $USER
```

Poté se **odhlaste a znovu přihlaste**, nebo spusťte:

```bash
newgrp docker
```

Nyní by mělo fungovat i bez `sudo`:

```bash
docker ps
```

<Danger>

Skupina `docker` má na hostiteli přístup ekvivalentní uživateli root.\
To je u běžných instalací Overleafu očekávané a obzvláště důležité, pokud povolíte Sandboxed Compiles.

</Danger>
</Step>
</Steps>
