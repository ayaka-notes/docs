### Rozhlédněte se

Nyní, když máte místní kopii Toolkitu, se podívejme na strukturu repozitáře pomocí příkazu `ls`.

```bash title="Run this"
ls -l
```

<Info>

Příkaz `ls -l` zobrazí podrobný dlouhý výpis obsahu adresáře s dalšími informacemi o souborech, jako jsou oprávnění, vlastnictví a velikost.

</Info>

Pokud se vše úspěšně naklonovalo, měli byste vidět něco takového:

```text
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 bin
-rw-r--r-- 1 fry fry  6465 Aug 30 14:16 CHANGELOG.md
drwxr-xr-x 2 fry fry  4096 Sep  6 12:43 config
drwxr-xr-x 5 fry fry  4096 Aug 30 14:22 data
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 doc
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 lib
-rw-r--r-- 1 fry fry 34520 Aug 30 14:16 LICENSE
-rw-r--r-- 1 fry fry  1178 Aug 30 14:16 README.md
```

<Info>

Všechny konfigurační soubory vlastněné uživatelem se nacházejí v adresáři `config/`. Tento adresář je **vyloučen** ze systému správy revizí git, takže se při aktualizaci Toolkitu nezmění.

</Info>

## Struktura repozitáře

| Název    | Popis |
| -------- | ----- |
| `bin`    | Tato složka obsahuje sadu skriptů, které vám pomáhají spravovat vaši instanci serveru Overleaf. Více o těchto skriptech si můžete přečíst v části Příkazy níže. |
| `config` | Tato složka obsahuje vaše vlastní místní konfigurační soubory. |
| `lib`    | Tato složka obsahuje základní konfigurační soubory používané Toolkitem. |
| `data`   | Ve výchozím nastavení tato složka obsahuje úložiště pro MongoDb, Redis a Overleaf. Více informací najdete v části [Trvalá data](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/files-and-locations#persistent-data) níže. |

<Warning>

Doporučujeme **neměnit** soubory mimo složku `/config` přímo. Pokud potřebujete provést změny, můžete je místo toho provést pomocí proměnných prostředí nastavených buď v **config/variables.env**, nebo v **config/overleaf.rc**.\
Chcete-li například nastavit obraz služby `mongo`, neupravujte přímo `lib/docker-compose.mongo.yml`, ale nastavte obraz pomocí proměnné prostředí `MONGO_IMAGE` v `config/overleaf.rc`. Více informací najdete na stránce [Nastavení Toolkitu](/cs/on-premises/configuration/overleaf-toolkit/toolkit-settings).

</Warning>

<Info>

Toolkit **nezmění** žádná data v adresáři `config/` bez vašeho svolení.

</Info>
