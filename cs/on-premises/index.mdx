### Přehled Overleafu

Overleaf je kolaborativní editor LaTeXu, který si oblíbili výzkumníci i technické týmy. Jeho cloudová verze je dostupná na [overleaf.com](https://www.overleaf.com/). Nabízí plnohodnotný online editor LaTeXu. Overleaf Common (verze SaaS) má však řadu omezení funkcí a musíte se smířit s _**10sekundovým limitem doby kompilace**_ a drahými členskými poplatky.

Přestože Overleaf nabízí open-source komunitní verzi (dostupnou na [GitHub: Overleaf](https://github.com/overleaf/overleaf)), i ta má mnoho omezení, například:

<Warning>

Overleaf Community Edition je určena pro prostředí, ve kterých jsou **všichni** uživatelé důvěryhodní. Community Edition **není** vhodná pro scénáře, kde je vyžadována izolace uživatelů, protože Sandbox Compiles nejsou k dispozici.

Bez sandboxingu běží kompilace LaTeXu se stejnými oprávněními jako kontejner, což umožňuje přístup k jeho souborovému systému, síti a proměnným prostředí. To vytváří riziko úniku dat nebo kompromitace systému. Kompilace bez sandboxu by se měly používat pouze v plně důvěryhodných prostředích; pro víceuživatelská nebo produkční nasazení se Sandbox Compiles důrazně doporučují.

Další informace o Sandbox Compiles najdete zde: [sandboxed-compiles.md](/cs/on-premises/configuration/overleaf-toolkit/sandboxed-compiles  "mention")

</Warning>

### Informace a ceny Overleaf Server Pro

Web Overleafu poskytuje pro Server Pro pouze možnost kontaktovat podporu, takže informací o Server Pro je velmi málo. Na základě informací, které jsme shromáždili v komunitě, však **platí pro Server Pro tyto podmínky**:

* Musíte zakoupit licence pro _alespoň_ 10 osob.
* Licence pro 10 osob stojí přibližně 3 477,61 €. (2024)
* Pro vzdělávací instituce stojí 20 uživatelů 2 640 EUR ročně, 50 uživatelů 6 050 EUR a 100 uživatelů 9 963 EUR.
* Server Pro je dostupný pouze ve vybraných regionech (např. s výjimkou pevninské Číny).

Podle aktuálně dostupných informací se zdá, že Overleaf Server Pro stojí přibližně \$300 na uživatele a rok při minimálním nákupu 10 licencí, což z něj činí velmi drahou možnost. Server Pro navíc nabízí výrazně méně funkcí než Ayakaleaf Pro. Jsme hluboce vděční komunitním vývojářům, jejichž příspěvky v průběhu let nám umožnily vytvořit Ayakaleaf Pro a nakonec překonat Overleaf Server Pro co do funkcí i možností.

### Proč Ayakaleaf Pro?

<Info>

Ayakaleaf Pro _**není**_ přidružen ke společnosti Overleaf, Inc. ani k její mateřské společnosti Digital Science. Nejde ani o edici _Server Pro_, což je komerční produkt nabízený společností Overleaf, Inc. Ayakaleaf Pro vyvíjí a udržuje [ayaka-notes](https://github.com/ayaka-notes) jako nezávislý projekt.

</Info>

Ayakaleaf Pro je rozšířená implementace Overleaf Community Edition, která nabízí _**všechny**_ prémiové funkce ze Server Pro _**zdarma**_. Na rozdíl od Overleaf Common dostupného na [https://www.overleaf.com/](https://www.overleaf.com/) nebo komerční edice Server Pro u nás platí:

* _**žádná omezení**_ doby kompilace
* _**žádné licenční**_ požadavky na počet uživatelů
* _**všechny funkce**_ ze Server Pro odemčeny
