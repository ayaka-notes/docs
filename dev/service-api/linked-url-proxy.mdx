title: linked-url-proxy
icon: link
---

Fetches an external URL for web and streams the answer back, refusing internal addresses so that users cannot reach the Docker network. Web sends URL files, Open in Overleaf imports and the AI agent's web_fetch through it.

* <strong>Address:</strong> `http://linked-url-proxy:3066`, inside the Docker network
* <strong>Authentication:</strong> none
* <strong>OpenAPI file:</strong> [`develop/hoppscotch/openapi/linked-url-proxy.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/linked-url-proxy.yaml)
