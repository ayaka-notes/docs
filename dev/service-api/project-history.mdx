Queues the edits of each project in Redis, turns them into history changes and sends them to history-v1; it also keeps history labels, resync state and failure records in Mongo. Called by web, document-updater, history-v1 and the server-ce cron scripts; it has no authentication.

* <strong>Address:</strong> `http://project-history:3054`, inside the Docker network
* <strong>Authentication:</strong> none
* <strong>OpenAPI file:</strong> [`develop/hoppscotch/openapi/project-history.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/project-history.yaml)
