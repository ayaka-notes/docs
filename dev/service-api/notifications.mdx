Stores the notifications shown to users on the project list (for example project invites) in Mongo's `notifications` collection. Web and third-party-datastore call it; it has no auth and is reachable only inside the Docker network.

* <strong>Address:</strong> `http://notifications:3042`, inside the Docker network
* <strong>Authentication:</strong> none
* <strong>OpenAPI file:</strong> [`develop/hoppscotch/openapi/notifications.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/notifications.yaml)
