Serves files from object storage: template files (zip, pdf and their preview images) and, read-only, the project and global blobs that history-v1 writes. Called by web (template-gallery module, compile file URLs) and by clsi, which downloads binary project files from it.

* <strong>Address:</strong> `http://filestore:3009`, inside the Docker network
* <strong>Authentication:</strong> none
* <strong>OpenAPI file:</strong> [`develop/hoppscotch/openapi/filestore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/filestore.yaml)
