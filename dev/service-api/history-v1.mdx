Stores the full history of every project: chunks of changes in Mongo or Postgres and object storage, and file content as blobs. project-history writes changes to it; web, project-history and git-bridge read blobs, snapshots and zips from it.

* <strong>Address:</strong> `http://history-v1:3100`, inside the Docker network
* <strong>Authentication:</strong> HTTP basic auth as `staging` with `STAGING_PASSWORD`, or a JWT, depending on the route.
* <strong>OpenAPI file:</strong> [`develop/hoppscotch/openapi/history-v1.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/history-v1.yaml)
