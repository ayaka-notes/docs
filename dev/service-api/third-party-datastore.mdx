Syncs projects with Dropbox: it keeps one Redis job queue per user and a worker that sends Overleaf changes to Dropbox and polls Dropbox for changes. Only web calls it, to enqueue jobs and read queue sizes.

* <strong>Address:</strong> `http://third-party-datastore:3002`, inside the Docker network
* <strong>Authentication:</strong> none
* <strong>OpenAPI file:</strong> [`develop/hoppscotch/openapi/third-party-datastore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/third-party-datastore.yaml)
