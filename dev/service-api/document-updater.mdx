title: document-updater
icon: file-pen

Holds the docs that are open in the editor in Redis, applies edits to them and flushes them back to Mongo through web. Called by web and real-time.

* <strong>Address:</strong> `http://document-updater:3003`, inside the Docker network
* <strong>Authentication:</strong> none
* <strong>OpenAPI file:</strong> [`develop/hoppscotch/openapi/document-updater.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/document-updater.yaml)
