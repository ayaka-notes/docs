---
title: docstore
icon: database
---

Stores every doc (lines, version, ranges) of every project in the Mongo `docs` collection, and archives docs to object storage when a backend is set. Called by web; document-updater reaches it through web.

* <strong>Address:</strong> `http://docstore:3016`, inside the Docker network
* <strong>Authentication:</strong> none
* <strong>OpenAPI file:</strong> [`develop/hoppscotch/openapi/docstore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/docstore.yaml)
