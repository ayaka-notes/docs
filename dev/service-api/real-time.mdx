Holds the editor's socket.io connections and relays edits and events between browsers, web and document-updater. This file covers its HTTP routes only; the socket.io protocol under `/socket.io/1/` is not described.

* <strong>Address:</strong> `http://real-time:3026`, inside the Docker network
* <strong>Authentication:</strong> none
