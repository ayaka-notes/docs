CLSI (Common LaTeX Service Interface) compiles projects, runs SyncTeX and texcount on the compile output, and converts documents with pandoc. Web calls it; the output files themselves are served by clsi-nginx, not by this port. No auth: it is reachable only inside the Docker network.

* <strong>Address:</strong> `http://clsi:3013`, inside the Docker network
* <strong>Authentication:</strong> none
* <strong>OpenAPI file:</strong> [`develop/hoppscotch/openapi/clsi.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/clsi.yaml)
