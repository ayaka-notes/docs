Stores the project chat and the comment threads (their messages and resolved state) in the Mongo `rooms` and `messages` collections. Called by web through `ChatApiHandler`.

* <strong>Address:</strong> `http://chat:3010`, inside the Docker network
* <strong>Authentication:</strong> none
* <strong>OpenAPI file:</strong> [`develop/hoppscotch/openapi/chat.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/chat.yaml)
