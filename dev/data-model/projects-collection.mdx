`projects` holds one document per project: name, owner and members, sharing, the file tree and project settings. The text of the docs is not here (see [Docs Collection](/dev/data-model/docs-collection)), and binary files live in the history-v1 blob store under their `hash`. The schema is `services/web/app/src/models/Project.mjs`, with the file tree in `Folder.mjs`, `File.mjs` and `Doc.mjs` next to it.

In the Source column, `Project.mjs:N` is a line of that schema, other bare file names are under `services/web/app/src/Features/`, and `modules/...` is under `services/web/`. Line numbers are from `server-pro` at the time of writing.

#### Notes

* Mongoose `autoIndex` is off (`services/web/app/src/infrastructure/Mongoose.mjs:7`): the `index` options in the schema only exist because the migrations above create them.
* The migration `20250620152657_ensure_collaborator_arrays` sets missing `collaberator_refs`, `pendingEditor_refs`, `pendingReviewer_refs`, `readOnly_refs` and `reviewer_refs` to `[]`.
* Deleting a project moves the document into `deletedProjects` (see [Deleted Projects Collection](/dev/data-model/deleted-projects-collection)).
