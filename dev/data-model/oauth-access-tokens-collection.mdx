---
title: OAuth Access Tokens Collection
icon: ticket
---

`oauthAccessTokens` holds the bearer tokens that web accepts. In Ayakaleaf Pro these are the personal access tokens (Git authentication tokens) that a user creates on the account settings page and uses for git-bridge and the MCP endpoint. One document is one token. The schema is `services/web/app/src/models/OauthAccessToken.mjs`; the `oauth2-server` web module writes the collection, mostly with the native driver.

#### Who Writes It

| Code | What it does |
| ---- | ------------ |
| `OAuthPersonalAccessTokenManager.mjs:53-88` (`createToken`) | Inserts a personal access token. Route `POST /oauth/personal-access-tokens` (`services/web/modules/oauth2-server/app/src/OAuthPersonalAccessTokenRouter.mjs:22-27`) needs the `gitBridge` feature of the user and allows 10 tokens per user (`OAuthPersonalAccessTokenController.mjs:7,34-38`). |
| `OAuthPersonalAccessTokenManager.mjs:90-105` (`removeToken`) | Deletes one token of the user. Route `DELETE /oauth/personal-access-tokens/:token_id` (`OAuthPersonalAccessTokenRouter.mjs:29-32`). |
| `OAuthPersonalAccessTokenManager.mjs:136-140`, `OAuth2Model.mjs:58-61` | Set `lastUsedAt` after a successful check. |

#### Who Reads It

| Code | What it does |
| ---- | ------------ |
| `OAuthPersonalAccessTokenManager.mjs:107-144` (`verifyToken`) | Checks a token by its hash for `GET /oauth/token/info` (`OAuthPersonalAccessTokenRouter.mjs:11-15`), which git-bridge calls on git clone and push (`services/git-bridge/src/main/java/uk/ac/ic/wlgitbridge/server/Oauth2Filter.java:285`). Rejects an expired token and the token of a suspended or deleted user. |
| `OAuth2Model.mjs:31-82` (`getAccessToken`) | Checks a bearer token for `AuthenticationController.requireOauth('git_bridge')` (`services/web/app/src/Features/Authentication/AuthenticationController.mjs:409-450`): the git-bridge API routes (`services/web/modules/git-bridge/app/src/GitBridgeRouter.mjs:33-59`) and the MCP endpoint (`services/web/modules/mcp-server/app/src/McpRouter.mjs:16-22`). Rejects an expired token and the token of a suspended or deleted user. |
| `OAuthPersonalAccessTokenManager.mjs:13-50` (`listTokens`, `getUserTokenNums`) | Lists the tokens of a user for the settings page (`GET /oauth/personal-access-tokens`) and counts them for the limit. |
| `AdminUserListManager.mjs:388-400` (module `admin-tools`) | Shows the token prefixes of a user in the admin panel. |

#### Notes

* Deleting a user does not delete their tokens. `UserDeleter` fires the hook `cleanupPersonalAccessTokens` (`services/web/app/src/Features/User/UserDeleter.mjs:230-234`), but no module listens to it. Both token checks reject the tokens because the user is gone, and the TTL index removes them a day after `accessTokenExpiresAt`.
* Suspending a user ends the sessions only; the tokens stay, and both token checks reject them while `users.suspended` is `true` (`OAuth2Model.mjs:51-54`, `OAuthPersonalAccessTokenManager.mjs:129-134`).
