---
title: Project History Sync State Collection
icon: rotate
---

`projectHistorySyncState` holds one document per project that has been resynced: the state of the current or last resync, when project-history rebuilds a project's history from what web and docstore hold. It is owned by project-history and has no Mongoose schema; the code is the `SyncState` class and its helpers in `services/project-history/app/js/SyncManager.js`.

#### Who Writes It

| Code | What it does |
| ---- | ------------ |
| `services/project-history/app/js/SyncManager.js:195-249` | `setResyncState`: upsert of the state. Called when a resync starts (`SyncManager.js:163`) and while project-history processes the resync updates (`services/project-history/app/js/UpdatesProcessor.js:637`, `784`). |
| `SyncManager.js:257-266` | `_recordStuckClearInSyncState`: counts a stuck resync that is cleared. |
| `SyncManager.js:251-255` | `clearResyncState`: deletes the document, at the start of a hard resync (`SyncManager.js:87`), on project-history `DELETE /project/:project_id` (`services/project-history/app/js/HttpController.js:1363-1396`), and when a structure-only resync has to start over (`SyncManager.js:705-716`). |
| `SyncManager.js:273-289` | `clearResyncStateIfAllAfter`: deletes a finished state whose history is all newer than a date. Nothing in `app/js` calls it. |
| `SyncManager.js:171-181` | `cloneResyncState`: copies the state to another project, for project-history `POST /project/:project_id/clone` (`HttpController.js:57`, `124`), which nothing in web calls. |

A resync is started by project-history `POST /project/:project_id/resync` (`HttpController.js:950-994`), by the retry cron jobs (`services/project-history/app/js/RetryManager.js:156-179`, `server-ce/config/crontab-history`), and by project-history itself when processing updates needs one (`UpdatesProcessor.js:75`, `224`).

#### Who Reads It

| `HttpController.js:533-545` | `GET /project/:project_id/resync-pending`: whether a resync is running or stuck. |
| `HttpController.js:563-585` | `GET /project/:project_id/debug-info`: the sync state with the failure record. |

#### Notes

* A resync is running while `resyncProjectStructure` is `true` or `resyncDocContents` is not empty (`SyncManager.js:565-567`). It counts as stuck after 4 hours, and as permanently stuck after 5 clears (`SyncManager.js:43-44`, `569-585`).
* When a resync finishes, project-history also sets `overleaf.history.lastResyncedAt` on the project (`SyncManager.js:239-248`).
