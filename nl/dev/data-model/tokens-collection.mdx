---
title: Tokens-collectie
icon: key
---

`tokens` bevat eenmalige tokens: het geheim in een link waarmee iemand een wachtwoord kan instellen. Eén document is één token. Er is geen Mongoose-model; web schrijft de collectie via `services/web/app/src/Features/Security/OneTimeTokenHandler.mjs` met de native driver.

#### Velden {#fields}

| Veld | Type | Betekenis | Bron |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Document-id. | `OneTimeTokenHandler.mjs:40` |
| `use` | String | Waarvoor het token dient, zie [Gebruik](#uses) hieronder. Elke zoekopdracht filtert erop. | `OneTimeTokenHandler.mjs:41` |
| `token` | String | Het geheim in de link: 32 willekeurige bytes als 64 hextekens, ongewijzigd opgeslagen. | `OneTimeTokenHandler.mjs:38,42` |
| `data` | Object | Waar het token voor staat; wordt teruggegeven als het wordt gebruikt. | `OneTimeTokenHandler.mjs:43` |
| `data.user_id` | String | Id van de gebruiker, door elke aanroeper als string geschreven. | `services/web/app/src/Features/PasswordReset/PasswordResetHandler.mjs:27`, `services/web/app/src/Features/User/UserRegistrationHandler.mjs:117`, `services/web/modules/admin-tools/app/src/AdminUserManager.mjs:79` |
| `data.email` | String | E-mailadres van de gebruiker toen het token werd gemaakt. Een wachtwoordreset zoekt de gebruiker op via dit primaire e-mailadres (`PasswordResetHandler.mjs:66-70`). | zelfde als `data.user_id` |
| `createdAt` | Date | Tijdstip van aanmaken. De TTL-index verwijdert het token 90 dagen later. | `OneTimeTokenHandler.mjs:36,44` |
| `expiresAt` | Date | `createdAt` plus `expiresIn` seconden: standaard 1 uur, 1 week voor een activatielink. Zoekopdrachten negeren een token na dit tijdstip. | `OneTimeTokenHandler.mjs:35-37,45` |
| `peekCount` | Number | Hoe vaak het token is bekeken zonder te worden gebruikt. Elke `peekValueFromToken` telt 1 op; bij 4 (`MAX_PEEKS`) werkt het token niet meer. | `OneTimeTokenHandler.mjs:8-31,107` |
| `usedAt` | Date | Tijdstip waarop het token is gebruikt of geannuleerd. Zoekopdrachten negeren een token dat dit veld heeft. | `OneTimeTokenHandler.mjs:51-104` |

#### Gebruik {#uses}

| `use` | Functie | Verloopt na | Code |
| ----- | ------- | ------ | ---- |
| `password` | E-mail voor wachtwoordreset, vanaf de pagina "wachtwoord vergeten" | 1 uur | `PasswordResetHandler.mjs:14-42` |
| `password` | Activatielink: een account met een willekeurig wachtwoord, daarna een link om er een in te stellen. Gebruikt door openbare registratie (`services/web/modules/login-register/app/src/RegisterController.mjs:65`), de beheerdersregistratiepagina van `user-activate` (`services/web/modules/user-activate/app/src/UserActivateController.mjs:27-30`) en het script `create-user` (`services/web/modules/server-ce-scripts/scripts/create-user.mjs:21`) | 1 week | `UserRegistrationHandler.mjs:97-130` |
| `password` | Activatie- of wachtwoordresetlink verzonden vanuit het beheerpaneel (module `admin-tools`) | 1 week (activatie), 1 uur (reset) | `AdminUserManager.mjs:76-103,196-206` |
| `email_confirmation` | Link om een e-mailadres te bevestigen. Wordt alleen gelezen: niets in deze repository maakt zulke tokens nog aan, omdat de bevestiging nu een code van 6 cijfers stuurt (`services/web/app/src/Features/User/UserEmailsConfirmationHandler.mjs:15-35`) | | `UserEmailsConfirmationHandler.mjs:12,37-66` |

#### Wie schrijft {#who-writes-it}

| Code | Wat het doet |
| ---- | ------------ |
| `OneTimeTokenHandler.mjs:34-49` (`getNewToken`) | Voegt een token toe. Aanroepers: `PasswordResetHandler.mjs:28`, `UserRegistrationHandler.mjs:115-119`, `AdminUserManager.mjs:77-81`. |
| `OneTimeTokenHandler.mjs:8-32` (`peekValueFromToken`) | Geeft `data` van een geldig token terug en telt 1 op bij `peekCount`. Gebruikt bij het openen van de wachtwoordresetpagina (`services/web/app/src/Features/PasswordReset/PasswordResetController.mjs:195-208`), opnieuw bij het instellen van het nieuwe wachtwoord (`PasswordResetHandler.mjs:94-96`) en door de e-mailbevestiging (`UserEmailsConfirmationHandler.mjs:38-41`). |
| `OneTimeTokenHandler.mjs:75-88` (`expireToken`) | Zet `usedAt` op één token: nadat een nieuw wachtwoord is ingesteld (`PasswordResetHandler.mjs:44-48,119`) of een e-mailadres is bevestigd (`UserEmailsConfirmationHandler.mjs:65`). |
| `OneTimeTokenHandler.mjs:90-104` (`expireAllTokensForUser`) | Zet `usedAt` op elk open `password`-token van een gebruiker, wanneer de gebruiker het wachtwoord in de instellingen wijzigt (`services/web/app/src/Features/User/UserController.mjs:146-149`) of een beheerder het in het beheerpaneel instelt (`AdminUserManager.mjs:479-488`). |

#### Wie leest {#who-reads-it}

| Code | Wat het doet |
| ---- | ------------ |
| `PasswordResetHandler.mjs:50-70,94-119` | Zet een reset- of activatietoken om in de gebruiker en stelt dan het wachtwoord in. De activatiepagina van `user-activate` geeft het token alleen door aan dit formulier. |
| `UserEmailsConfirmationHandler.mjs:37-66` | Bevestigt een e-mailadres met een `email_confirmation`-token van de ingelogde gebruiker. |
| `AdminUserManager.mjs:213-223` (module `admin-tools`) | Zoekt het open activatietoken van een gebruiker om de activatielink opnieuw in het beheerpaneel te tonen. Leest `db.tokens` direct. |

#### Opmerkingen {#notes}

* Een gebruikt of verlopen token wordt niet meteen verwijderd: het blijft, met `usedAt` of een verstreken `expiresAt`, totdat de TTL-index het 90 dagen na `createdAt` verwijdert.
* `OneTimeTokenHandler` heeft ook `getValueFromTokenAndExpire` (`OneTimeTokenHandler.mjs:51-73`), maar niets roept het aan.
