`migrations` houdt bij welke databasemigraties zijn uitgevoerd. Eén document is één migratie uit `tools/migrations/`. Het wordt geschreven door de adapter van de migratietool [east](https://github.com/okv/east), `tools/migrations/lib/adapter.mjs`, niet door een draaiende dienst.

#### Velden {#fields}

| Veld | Type | Betekenis | Bron |
| --- | --- | --- | --- |
| `_id` | ObjectId | Document-id. | `adapter.mjs:103` |
| `name` | String | Bestandsnaam van de migratie zonder extensie, bijvoorbeeld `20190912145029_create_tags_indexes`. | `adapter.mjs:104` |
| `migratedAt` | Date | Wanneer de migratie klaar was. | `adapter.mjs:105` |

#### Wie schrijft {#who-writes-it}

| Code | Wat het doet |
| --- | --- |
| `adapter.mjs:101-107` (`markExecuted`) | Voegt een document in nadat een migratie is uitgevoerd. |
| `adapter.mjs:109-114` (`unmarkExecuted`) | Verwijdert het weer wanneer een migratie wordt teruggedraaid. |

CE voert bij elke containerstart `yarn run migrations migrate -t server-ce` uit (`server-ce/init_scripts/900_run_web_migrations.sh:4-12`; `-t server-pro` als `OVERLEAF_IS_SERVER_PRO=true`). Alleen migraties waarvan de `tags` die omgeving bevatten worden uitgevoerd, dus alleen die krijgen hier een document.

#### Wie leest {#who-reads-it}

| Code | Wat het doet |
| --- | --- |
| `adapter.mjs:72-99` (`getExecutedMigrationNames`) | east slaat elke migratie over waarvan de naam hier al staat. |
| `tools/migrations/lib/helpers.mjs:67-75` (`assertDependency`) | Een migratie die vereist dat een andere eerst is uitgevoerd, geeft een fout wanneer die naam ontbreekt. |

#### Indexen {#indexes}

| Naam | Sleutels | Opties | Migratie |
| --- | --- | --- | --- |
| `name_1` | `{ name: 1 }` | unique | `tools/migrations/20190720165251_create_migrations.mjs` |

#### Opmerkingen {#notes}

* Als je een document verwijdert, wordt die migratie bij de volgende containerstart opnieuw uitgevoerd, mits de tags overeenkomen.
* Met een extra Mongo-cluster (`mongo.auxUrl`) worden migraties met de tag `auxiliary` in plaats daarvan vastgelegd in de collectie `migrations` van dat cluster (`adapter.mjs:8-15`, `:64-70`). `mongo.auxUrl` komt uit `MONGO_AUX_CONNECTION_STRING` (`tools/migrations/config/settings.defaults.js:19`), dat standaard niet is ingesteld.
