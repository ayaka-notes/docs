title: System Messages-collectie
icon: bullhorn
---

`systemmessages` bevat de sitebrede banners die een beheerder plaatst voor alle ingelogde gebruikers. Eén document is één bericht. `web` is de eigenaar; het schema is `services/web/app/src/models/SystemMessage.mjs` en de code is `services/web/app/src/Features/SystemMessages/SystemMessageManager.mjs`.

#### Velden {#fields}

| Veld | Type | Betekenis | Bron |
| --- | --- | --- | --- |
| `_id` | ObjectId | Bericht-id. De browser onthoudt via deze id welke berichten de gebruiker heeft gesloten (`services/web/frontend/js/shared/components/system-message.tsx:10`). | `SystemMessage.mjs:5` |
| `content` | String | Berichttekst, standaard `''`. | `SystemMessage.mjs:7` |
| `__v` | Number | Mongoose-versiesleutel, toegevoegd door `message.save()`. | `SystemMessageManager.mjs:29-30` |

#### Wie schrijft {#who-writes-it}

| Code | Wat het doet |
| --- | --- |
| `SystemMessageManager.mjs:28-33` (`createMessage`) | `POST /admin/messages` (`services/web/app/src/router.mjs:1150-1152`, `services/web/app/src/Features/ServerAdmin/AdminController.mjs:151-159`): voegt één bericht toe. |
| `SystemMessageManager.mjs:22-26` (`clearMessages`) | `POST /admin/messages/clear` (`router.mjs:1155-1157`, `AdminController.mjs:161-168`): verwijdert alle berichten. Eén enkel bericht verwijderen is niet mogelijk. |

#### Wie leest {#who-reads-it}

| Code | Wat het doet |
| --- | --- |
| `SystemMessageManager.mjs:50-65` | Elk `web`-proces houdt alle berichten in het geheugen en laadt ze elke 20 tot 30 seconden opnieuw, en direct na het eigen aanmaken of wissen. |
| `services/web/app/src/Features/SystemMessages/SystemMessageController.mjs:6-24` | `GET /system/messages` (`router.mjs:331`): geeft de gecachte berichten terug aan ingelogde gebruikers. Zolang de site gesloten is (`siteIsOpen` false), geeft het in plaats daarvan een vaste melding terug, die niet in Mongo is opgeslagen. |
| `AdminController.mjs:83-84` | De pagina `/admin` toont de berichten rechtstreeks uit Mongo. |

#### Indexen {#indexes}

Geen enkele migratie maakt een index op `systemmessages` aan; alleen de standaardindex `_id` bestaat.

#### Opmerkingen {#notes}

* Als `notifyOnSystemMessageChanges` is ingesteld, wordt een aanmaak of wissing ook gepubliceerd op het Redis-kanaal `refresh-system-messages`, zodat andere `web`-processen direct opnieuw laden (`SystemMessageManager.mjs:9`, `:35-48`, `:75-87`). Zonder deze instelling pikken ze de wijziging op bij hun volgende geplande herlaadbeurt.
