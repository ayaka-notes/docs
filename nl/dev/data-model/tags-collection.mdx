`tags` bevat de tags (mappen) waarin een gebruiker projecten indeelt op het projectdashboard. Eén document is één tag van één gebruiker. `web` is de eigenaar; het schema is `services/web/app/src/models/Tag.mjs`, en alle schrijfacties lopen via `services/web/app/src/Features/Tags/TagsHandler.mjs`.

#### Velden {#fields}

| Veld | Type | Betekenis | Bron |
| --- | --- | --- | --- |
| `_id` | ObjectId | Tag-id, gebruikt in de routes `/tag/:tagId`. | `Tag.mjs:10` |
| `user_id` | String | Eigenaar van de tag. Om historische redenen een gewone string, geen ObjectId. | `Tag.mjs:7-12` |
| `name` | String | Tagnaam, maximaal 50 tekens (`MAX_TAG_LENGTH`). Uniek per gebruiker. | `Tag.mjs:13`, `TagsHandler.mjs:4` |
| `color` | String | Optionele kleur: een hexcode zoals `#a1b2c3` of een waarde `hsl(<n>, 70%, 45%)` (`TAG_COLOR_REGEX`). | `Tag.mjs:5`, `Tag.mjs:14-22` |
| `project_ids` | Array of String | Id's van de projecten in deze tag, als strings. | `Tag.mjs:23` |
| `__v` | Number | Mongoose-versiesleutel, toegevoegd wanneer `Tag.create` het document aanmaakt. | `TagsHandler.mjs:27` |

#### Opmerkingen {#notes}

* Tags zijn per gebruiker: twee medewerkers aan hetzelfde project houden elk hun eigen tags ervoor.
* `user_id` en `project_ids` zijn strings, dus zoek erop met string-id's, niet met ObjectIds.
* Het verwijderen van een gebruiker (`services/web/app/src/Features/User/UserDeleter.mjs`) raakt `tags` niet aan.
