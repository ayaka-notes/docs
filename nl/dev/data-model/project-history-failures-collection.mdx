`projectHistoryFailures` bevat één document per project waarvan project-history de geschiedenisupdates niet kon verwerken, of waarvoor het een resync heeft gestart. Het document wordt weer verwijderd zodra de verwerking lukt. project-history schrijft het in `services/project-history/app/js/ErrorRecorder.js`; het type staat in `services/project-history/app/js/mongo-types.ts:3-24`. Web heeft er ook een Mongoose-schema voor (`services/web/app/src/models/ProjectHistoryFailure.mjs:5-19`), maar geen enkele web-code gebruikt dat model.

#### Opmerkingen {#notes}

* Een document blijft bestaan totdat een flush van het project slaagt of het project wordt verwijderd (`clearError` hierboven), dus elk document markeert een project waarvan de laatste flush of resync nog niet is geslaagd.
* Foutstrings die beginnen met `OError:` worden teruggegeven als `Error:` (`ErrorRecorder.js:18-26`); de opgeslagen waarde verandert niet.
