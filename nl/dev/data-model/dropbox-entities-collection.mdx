title: Dropbox Entities-collectie
icon: file-arrow-up

`dropboxEntities` bevat één document per bestand dat Dropbox-synchronisatie heeft gekopieerd tussen een project en de Dropbox van één gebruiker, plus kortlevende tombstones. De collectie hoort bij Dropbox-synchronisatie: third-party-datastore (`services/third-party-datastore/app/js/StateManager.mjs`) schrijft en leest haar, en de webmodule `dropbox` (`services/web/modules/dropbox/app/src/DropboxHandler.mjs`) wist haar. Er is geen Mongoose-schema.

#### Velden {#fields}

| Veld | Type | Betekenis | Bron |
| ---- | ---- | --------- | ---- |
| `_id` | ObjectId | Door de driver ingesteld bij het invoegen. | `StateManager.mjs:46,97` |
| `overleaf.userId` | ObjectId | De gebruiker in wiens Dropbox het bestand staat. Op elk document ingesteld. | `StateManager.mjs:48,98` |
| `overleaf.projectId` | ObjectId | Het project van de doc of het bestand. Ingesteld wanneer bekend; tombstones hebben er geen. | `StateManager.mjs:49-51` |
| `overleaf.id` | ObjectId | De `_id` van de doc of het bestand in de `rootFolder` van het project. Ingesteld wanneer bekend. | `StateManager.mjs:52` |
| `overleaf.type` | String | `doc` of `file`. De huidige code schrijft het maar leest het niet. | `StateManager.mjs:53`; waarden uit `services/web/app/src/Features/ThirdPartyDataStore/TpdsUpdateSender.mjs:35,96` en `UpdateMerger.mjs:104,119` |
| `dropbox.id` | String | De `id` van het bestand in de Dropbox-bestandsmetadata. Niet ingesteld op tombstones. | `StateManager.mjs:56` |
| `dropbox.pathLower` | String | Het pad van het bestand in Dropbox, in kleine letters en zonder afsluitende schuine streep. Bijgewerkt wanneer het bestand of de projectmap wordt verplaatst. | `StateManager.mjs:14-16,57,91,99` |
| `dropbox.rev` | String | De Dropbox-revisie bij de laatste synchronisatie. De volgende upload stuurt haar mee, zodat een bestand dat in Dropbox is gewijzigd niet wordt overschreven. | `StateManager.mjs:58`, `JobProcessor.mjs:114-122` |
| `dropbox.contentHash` | String | De Dropbox-inhoudshash bij de laatste synchronisatie. Een vermeld bestand met dezelfde hash wordt overgeslagen, omdat het onze eigen upload is of al is toegepast. | `StateManager.mjs:59`, `PullManager.mjs:147-149` |
| `tombstone` | Boolean | `true` markeert een pad dat third-party-datastore zelf in Dropbox heeft verwijderd of weggezet. Wanneer Dropbox die verwijdering terugmeldt, wordt die niet op het project toegepast. | `StateManager.mjs:100`, `PullManager.mjs:189-192` |
| `createdAt` | Date | Alleen tombstones: wanneer hij is aangemaakt. Een voltooide pull verwijdert de tombstones die vóór de start ervan zijn aangemaakt. | `StateManager.mjs:101,115-121` |

Een tombstone heeft alleen `overleaf.userId`, `dropbox.pathLower`, `tombstone` en `createdAt` (`StateManager.mjs:96-103`).

#### Wie haar schrijft {#who-writes-it}

| Code | Wat het doet |
| ---- | ------------ |
| `services/third-party-datastore/app/js/StateManager.mjs:35-62` (`recordEntity`) | Verwijdert de documenten van de gebruiker met dezelfde `dropbox.id`, `dropbox.pathLower` of `overleaf.id` en voegt daarna de nieuwe status in. |
| `services/third-party-datastore/app/js/JobProcessor.mjs:102-134` (`addEntity`) | Legt een doc of bestand vast na het uploaden van Overleaf naar Dropbox (`:125-133`). |
| `services/third-party-datastore/app/js/PullManager.mjs:142-177` (`applyFile`) | Legt een Dropbox-bestand vast nadat web het op het project heeft toegepast (`:168-176`). |
| `StateManager.mjs:80-94` (`moveEntities`) | Herschrijft `dropbox.pathLower` onder een verplaatst pad: projecthernoeming (`JobProcessor.mjs:195`) en verplaatsing van een bestand of map (`JobProcessor.mjs:239`). |
| `StateManager.mjs:96-103` (`addTombstone`) | Na een verwijdering (`JobProcessor.mjs:153`), een projecthernoeming (`:202`) of een verplaatsing (`:240`) in Dropbox. |
| `StateManager.mjs:72-78` (`removeEntities`) | Verwijdert de items op en onder een pad, behalve tombstones: na een verwijdering vanuit Overleaf (`JobProcessor.mjs:152`) of in Dropbox (`PullManager.mjs:206`). |
| `StateManager.mjs:115-121` (`clearTombstones`) | Aan het einde van een pull (`PullManager.mjs:31,69`). |
| `StateManager.mjs:186-190` (`removeUserState`), aangeroepen vanuit `services/third-party-datastore/app/js/QueueWorker.mjs:43` | Verwijdert alle documenten van de gebruiker wanneer third-party-datastore een account ontkoppelt dat het niet meer kan gebruiken. |
| `DropboxHandler.mjs:142-146` (`removeUserState`) | Verwijdert alle documenten van de gebruiker bij koppelen (`:125`), bij ontkoppelen (`:183`) en wanneer een verwijderde gebruiker verloopt (`services/web/modules/dropbox/index.mjs:62-64`). |
| `DropboxHandler.mjs:150-154` (`removeProjectState`) | Verwijdert de documenten van het project wanneer een verwijderd project verloopt (`index.mjs:54-56`). |

#### Wie haar leest {#who-reads-it}

| Code | Wat het doet |
| ---- | ------------ |
| `StateManager.mjs:64-70` (`findEntityByPath`) | Haalt `dropbox.rev` op vóór een upload (`JobProcessor.mjs:114`) en `dropbox.contentHash` vóór het toepassen van een Dropbox-bestand (`PullManager.mjs:147`). |
| `StateManager.mjs:106-112` (`findTombstone`) | Controleert een gemelde verwijdering op het pad of op een van de bovenliggende paden (`PullManager.mjs:189`). |
| `StateManager.mjs:160-175` (`getSyncedPaths`) | Somt de gesynchroniseerde bestandspaden op na een cursorreset, zodat een bestand dat in de lijst ontbreekt als verwijderd geldt (`PullManager.mjs:74-85`). |

#### Opmerkingen {#notes}

* Uniciteit komt alleen van het verwijderen vóór elke invoeging in `recordEntity` (`StateManager.mjs:38-45`). Het commentaar in `StateManager.mjs:3-11` noemt unieke indexen; CE heeft die niet.
* Query's op gebruiker en pad (`findEntityByPath`, `findTombstone`, `removeEntities`) gebruiken de index alleen voor `overleaf.userId`.
