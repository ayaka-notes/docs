---
title: GitLab Sync User Credentials-collectie
icon: user-lock
---

`gitlabSyncUserCredentials` bevat één document per gebruiker die een GitLab-account voor GitLab Sync heeft gekoppeld. Het slaat de OAuth-tokens van de gebruiker versleuteld op. De collectie hoort bij de webmodule `gitlab-sync` (`services/web/modules/gitlab-sync`). Het schema staat in `services/web/modules/gitlab-sync/app/models/gitlabSyncUserCredentials.mjs`, en alle toegang loopt via `services/web/modules/gitlab-sync/app/src/TokenManager.mjs`.

#### Velden {#fields}

| Veld | Type | Betekenis | Bron |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Door Mongoose ingesteld als de upsert invoegt. | |
| `userId` | ObjectId | De Overleaf-gebruiker. Verplicht. Het schema zegt `unique: true`, maar er wordt geen index gebouwd (zie Indexen); de upsert op `userId` houdt één document per gebruiker. | `gitlabSyncUserCredentials.mjs:8`, `TokenManager.mjs:88-95` |
| `gitlab` | String | De JSON `{ accessToken, refreshToken, expiresAt }`, versleuteld met `@overleaf/access-token-encryptor`. `expiresAt` is in milliseconden sinds de epoch, of `null`; `refreshToken` kan `null` zijn. Het wachtwoord komt uit `GITLAB_TOKEN_CIPHER_PASSWORD`; het cipherlabel is `GITLAB_TOKEN_CIPHER_LABEL`, standaard `2026.10-v3`. Verplicht. | `gitlabSyncUserCredentials.mjs:9-10`, `TokenManager.mjs:18-31`, `services/web/modules/gitlab-sync/app/src/GitLabApiClient.mjs:209-220` |
| `__v` | Number | De versiesleutel van Mongoose. Het schema schakelt die niet uit. | Mongoose-standaard |

#### Wie schrijft {#who-writes-it}

| Code | Wat het doet |
| ---- | ------------ |
| `TokenManager.mjs:88-95` (`saveUserToken`) | Upsert de versleutelde inloggegevens voor de gebruiker. |
| `TokenManager.mjs:99-108` (`linkUserToken`) | Slaat nieuwe inloggegevens uit de OAuth-callback op (`services/web/modules/gitlab-sync/app/src/GitLabSyncController.mjs:146`). Als de gebruiker opnieuw koppelt, wordt het vervangen toegangstoken op de achtergrond bij GitLab ingetrokken. |
| `TokenManager.mjs:53-78` (`refreshUserToken`) | Als het toegangstoken minder dan 5 minuten van `expiresAt` af is (`:13,47-49`), haalt het met het refreshtoken nieuwe tokens op en slaat die op (`:75`). Het draait per gebruiker onder de lock `gitlabSyncToken` (`:15,54`), omdat GitLab een refreshtoken bij gebruik verbruikt. |
| `TokenManager.mjs:111-126` (`removeUserToken`) | Trekt het toegangstoken in bij GitLab (naar beste vermogen) en verwijdert dan het document. Aangeroepen bij ontkoppelen (`GitLabSyncController.mjs:173`) en als een verwijderde gebruiker verloopt (`services/web/modules/gitlab-sync/index.mjs:56-58`). |

#### Wie leest {#who-reads-it}

| Code | Wat het doet |
| ---- | ------------ |
| `TokenManager.mjs:41-45,81-85` (`getUserCredentials`, `getUserToken`) | Ontsleutelt de inloggegevens voor elke aanroep van de GitLab-API en vernieuwt ze eerst als het token bijna verloopt: `services/web/modules/gitlab-sync/app/src/GitLabSyncHandler.mjs` (bijvoorbeeld `:27`) en `services/web/modules/gitlab-sync/app/src/GitMerge.mjs:52`. Zonder document, of met inloggegevens die niet te ontsleutelen of te vernieuwen zijn, gooit het `InvalidTokenError` en geldt de gebruiker als niet gekoppeld (`GitLabSyncHandler.mjs:25-37`). |
| `services/web/modules/admin-tools/app/src/AdminUserListManager.mjs:394` | Controleert of de gebruiker een document heeft, voor de integraties die in het beheerpaneel worden getoond. |

#### Indexen {#indexes}

| Naam | Sleutels | Opties | Migratie |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

Mongoose `autoIndex` staat uit (`services/web/app/src/infrastructure/Mongoose.mjs:7`), dus de `unique: true` van het schema op `userId` maakt niets aan. Geen enkele migratie maakt indexen aan voor deze collectie.

#### Opmerkingen {#notes}

* Het wijzigen van `GITLAB_TOKEN_CIPHER_PASSWORD` maakt de opgeslagen inloggegevens onleesbaar. Die gebruikers gelden dan als niet gekoppeld tot ze opnieuw koppelen.
* Een verwijderde gebruiker houdt het document tot de gebruiker verloopt.
