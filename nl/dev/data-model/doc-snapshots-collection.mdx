`docSnapshots` bevat kopieën van een doc die document-updater maakt vlak voor een bewerking die opmerkingen of bijgehouden wijzigingen samenvouwt. Alleen document-updater schrijft erin, in `services/document-updater/app/js/SnapshotManager.js`. Web heeft een Mongoose-model in `services/web/app/src/models/DocSnapshot.mjs`, maar geen enkele code gebruikt het.

#### Velden {#fields}

| Veld | Type | Betekenis | Bron |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Snapshot-id. | `SnapshotManager.js:24` |
| `project_id` | ObjectId | Project. | `SnapshotManager.js:19,26`, `DocSnapshot.mjs:7` |
| `doc_id` | ObjectId | Het doc (`docs._id`). | `SnapshotManager.js:20,27`, `DocSnapshot.mjs:8` |
| `version` | Number | OT-versie van het doc vóór de bewerking. | `SnapshotManager.js:28`, `services/document-updater/app/js/UpdateManager.js:132,264-271`, `DocSnapshot.mjs:9` |
| `lines` | Array of String | Inhoud van het doc vóór de bewerking. | `SnapshotManager.js:29`, `DocSnapshot.mjs:10` |
| `pathname` | String | Pad van het doc in het project op dat moment. | `SnapshotManager.js:30`, `DocSnapshot.mjs:11` |
| `ranges` | Mixed | `comments` en `changes` vóór de bewerking, in dezelfde vorm als `docs.ranges` (zie [docs](/nl/dev/data-model/docs-collection)). `id`, `op.t` en `metadata.user_id` worden omgezet in ObjectIds en `metadata.ts` in Dates. | `SnapshotManager.js:31,41-68`, `DocSnapshot.mjs:12` |
| `ts` | Date | Wanneer de snapshot is gemaakt. De TTL-index verwijdert de snapshot 30 dagen later. | `SnapshotManager.js:32`, `DocSnapshot.mjs:13` |

#### Wie schrijft het {#who-writes-it}

| Code | Wat het doet |
| ---- | ------------ |
| `UpdateManager.js:248-271` | Nadat document-updater een bewerking heeft toegepast, legt hij het doc vast zoals het vóór de bewerking was als de bewerking bereiken samenvouwde: meer bereiken werden leeg, of meer dan één bereik werd verwijderd (`services/document-updater/app/js/RangesManager.js:104-106`). |
| `SnapshotManager.js:17-36` `recordSnapshot` | Voegt de snapshot in. |

#### Wie leest het {#who-reads-it}

Geen enkele code leest het. Het web-model is gedefinieerd, maar wordt nergens gebruikt.

#### Opmerkingen {#notes}

* Alleen bewerkingen die via `UpdateManager.applyUpdate` lopen maken snapshots. Bewerkingen die `HistoryOTUpdateManager` afhandelt doen dat niet (`UpdateManager.js:74-77`).
* Er is geen index op `doc_id`. Zoek de snapshots van een doc op `project_id` en `ts` en filter daarna op `doc_id`.
