icon: spell-check

`spellingPreferences` bevat het woordenboek van elke gebruiker: de woorden die de gebruiker heeft toegevoegd via "Add to dictionary" in de spellingcontrole van de editor. Eén document per gebruiker. `web` is de eigenaar, zonder Mongoose-schema; de code is `services/web/app/src/Features/Spelling/LearnedWordsManager.mjs`.

#### Velden {#fields}

| Veld | Type | Betekenis | Bron |
| --- | --- | --- | --- |
| `_id` | ObjectId | Document-id, aangemaakt door de upsert. | `LearnedWordsManager.mjs:21-31` |
| `token` | String | De id van de gebruiker. Ondanks de naam geven de spellingroutes de id van de ingelogde gebruiker door (`SessionManager.getLoggedInUserId`). | `LearnedWordsManager.mjs:23` |
| `learnedWords` | Array of String | De woorden die de gebruiker heeft toegevoegd. | `LearnedWordsManager.mjs:26` |

#### Wie schrijft {#who-writes-it}

| Code | Wat het doet |
| --- | --- |
| `LearnedWordsManager.mjs:13-32` (`learnWord`) | `POST /spelling/learn` (`services/web/app/src/router.mjs:1037-1041`, `services/web/app/src/Features/Spelling/SpellingController.mjs:45-58`): `$addToSet` van het woord, met upsert. Weigert wanneer de lijst groter zou worden dan `Settings.maxDictionarySize` bytes. |
| `LearnedWordsManager.mjs:38-47` (`unlearnWord`) | `POST /spelling/unlearn` (`router.mjs:1043-1047`, `SpellingController.mjs:66-79`): `$pull` van het woord. |
| `LearnedWordsManager.mjs:84-86` (`deleteUsersLearnedWords`) | Verwijdert het document. De enige wrapper, `SpellingHandler.deleteUserDictionary` (`services/web/app/src/Features/Spelling/SpellingHandler.mjs:24-26`), wordt nergens aangeroepen in web of zijn modules. |

#### Wie leest {#who-reads-it}

| Code | Wat het doet |
| --- | --- |
| `LearnedWordsManager.mjs:52-67` (`getLearnedWords`) | Geeft de woorden zonder duplicaten terug. |
| `services/web/app/src/Features/Project/ProjectController.mjs:671` | Stuurt het woordenboek naar de editor wanneer een project wordt geopend (`SpellingHandler.getUserDictionary`). |

#### Opmerkingen {#notes}

* De index is niet uniek; de upsert op `token` houdt één document per gebruiker.
* Het verwijderen van een gebruiker verwijdert dit document niet.
