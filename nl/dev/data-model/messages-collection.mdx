icon: message

`messages` bevat één document per bericht: een regel in de projectchat, of een opmerking of antwoord in een reviewopmerkingenthread. Alleen de chatservice schrijft erin, in `services/chat/app/js/Features/Messages/MessageManager.js`. Er is geen Mongoose-schema. Elk bericht hoort bij een ruimte in de collectie [rooms](/nl/dev/data-model/rooms-collection).

#### Velden {#fields}

| Veld | Type | Betekenis | Bron |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Bericht-id. | `MessageManager.js:13-14` |
| `room_id` | ObjectId | De ruimte (`rooms._id`), niet de project-id of de thread-id. | `MessageManager.js:8,106-108` |
| `user_id` | ObjectId | Auteur. | `MessageManager.js:9,103-105` |
| `content` | String | Tekst van het bericht, 1 tot 10240 tekens (`MAX_MESSAGE_LENGTH`). | `MessageManager.js:7`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:3,12-15` |
| `timestamp` | Number | Wanneer het is verzonden, in milliseconden sinds 1970 (`Date.now()`), geen Date. | `MessageManager.js:10`, `services/chat/app/js/Features/Messages/MessageHttpController.js:288` |
| `edited_at` | Number | Wanneer het voor het laatst is bewerkt, in milliseconden (`Date.now()`). Ontbreekt als het nooit is bewerkt. | `MessageManager.js:65-69`, `MessageHttpController.js:189,213` |

#### Wie schrijft het {#who-writes-it}

| Code | Wat het doet |
| ---- | ------------ |
| `MessageManager.js:5-16` `createMessage` | Voegt een bericht in (`MessageHttpController.js:275-294`). Web stuurt projectchatberichten vanuit `services/web/app/src/Features/Chat/ChatController.mjs:32`, en opmerkingen vanuit de track-changes-module (`services/web/modules/track-changes/app/src/TrackChangesController.mjs:95`) en de mcp-server-module (`services/web/modules/mcp-server/app/src/CommentTools.mjs:133`). |
| `MessageManager.js:51-72` `updateMessage` | Stelt `content` en `edited_at` in. Als een gebruikers-id is opgegeven, komt alleen het bericht van die gebruiker overeen (`MessageManager.js:62-64`). Aangeroepen vanuit `ChatController.mjs:135` en `TrackChangesController.mjs:110`. |
| `MessageManager.js:74-80` `deleteMessage` | Verwijdert één bericht. Aangeroepen vanuit `ChatController.mjs:105` en `TrackChangesController.mjs:129`. |
| `MessageManager.js:39-49` `deleteAllMessagesInRoom(s)` | Verwijdert de berichten van een verwijderde thread (`MessageHttpController.js:172-173`) of van een heel project wanneer een verwijderd project verloopt (`MessageHttpController.js:261-271`, aangeroepen vanuit `services/web/app/src/Features/Project/ProjectDeleter.mjs:391`). |
| `MessageManager.js:115-127` `duplicateRoomToOtherRoom` | Kopieert `content`, `timestamp` en `user_id` van elk bericht naar een andere ruimte, zonder `edited_at`. Gebruikt wanneer een geschiedenisherstel een thread dupliceert (`MessageHttpController.js:316-342`) en wanneer een project met zijn bereiken wordt gekopieerd (`MessageHttpController.js:344-357`). |

#### Wie leest het {#who-reads-it}

| Code | Wat het doet |
| ---- | ------------ |
| `MessageManager.js:18-29` `getMessages` | Nieuwste eerst, hoogstens `limit` (standaard 50) ouder dan `before` (een `timestamp`). Gebruikt voor de projectchat (`ChatController.mjs:80`). |
| `MessageManager.js:31-37` `findAllMessagesInRooms` | Alle berichten van enkele ruimtes, voor de threadlijst van het reviewpaneel (`TrackChangesController.mjs:82`), de mcp-server-module (`CommentTools.mjs:83`) en geschiedenisherstel (`services/web/app/src/Features/History/RestoreManager.mjs:259`). Web controleert ook het eerste bericht van een thread, zodat een reviewer alleen threads kan wijzigen die hij zelf is gestart (`services/web/app/src/Features/Authorization/AuthorizationManager.mjs:409-411`). |
| `MessageManager.js:90-100` `getMessage` | Eén bericht. Web controleert de `user_id` ervan voordat een gebruiker zijn eigen bericht bewerkt of verwijdert (`services/web/app/src/Features/Authorization/AuthorizationMiddleware.mjs:253-257`, `TrackChangesController.mjs:124-125`). |

#### Opmerkingen {#notes}

* Om de berichten van een opmerking te vinden, zoekt u eerst de ruimte op `project_id` en `thread_id` en vraagt u daarna `room_id` op. De opmerking-id in het doc is de `thread_id`, niet de `room_id`.
* De tekst waarnaar een opmerking verwijst is `op.c` in `docs.ranges.comments`; de discussie staat hier.
