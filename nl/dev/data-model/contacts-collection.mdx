`contacts` onthoudt met welke gebruikers een gebruiker heeft samengewerkt, zodat het deeldialoogvenster hen kan voorstellen. Eén document per gebruiker. `web` is de eigenaar, zonder Mongoose-schema; de code is `services/web/app/src/Features/Contacts/ContactManager.mjs`.

#### Velden {#fields}

| Veld | Type | Betekenis | Bron |
| --- | --- | --- | --- |
| `_id` | ObjectId | Document-id, aangemaakt door de upsert. | `ContactManager.mjs:5-12` |
| `user_id` | ObjectId | De gebruiker van wie deze contacten zijn. Eén document per gebruiker. | `ContactManager.mjs:6` |
| `contacts` | Object | Map met de gebruikers-id van het contact (als string) als sleutel. | `ContactManager.mjs:8-9` |
| `contacts.<userId>.n` | Number | Hoe vaak de twee gebruikers met elkaar in contact zijn gebracht. | `ContactManager.mjs:8` |
| `contacts.<userId>.ts` | Date | Wanneer dat voor het laatst gebeurde. | `ContactManager.mjs:9` |

#### Wie schrijft {#who-writes-it}

| Code | Wat het doet |
| --- | --- |
| `ContactManager.mjs:4-13` (`touchContact`), `:23-28` (`addContact`) | Upsert van de documenten van beide gebruikers: `$inc` op `n`, `$set` van `ts`. |
| `services/web/app/src/Features/Collaborators/CollaboratorsHandler.mjs:155-157` | `addUserIdToProject` roept `addContact` aan wanneer het de toevoegende gebruiker meekrijgt: bij een geaccepteerde uitnodiging (uitnodiger en genodigde, `services/web/app/src/Features/Collaborators/CollaboratorsInviteHandler.mjs:199-205`) en bij een eigendomsoverdracht (nieuwe en vorige eigenaar, `services/web/app/src/Features/Collaborators/OwnershipTransferHandler.mjs:138-144`). Deelnemen via een deellink geeft geen toevoegende gebruiker mee (`services/web/app/src/Features/TokenAccess/TokenAccessController.mjs:386-388`, `:632-634`), dus er wordt geen contact toegevoegd. |

#### Opmerkingen {#notes}

* Contacten werken in beide richtingen: B toevoegen aan het project van A maakt B een contact van A en A een contact van B.
* Niets verwijdert een contact of het document, zelfs niet wanneer een gebruiker wordt verwijderd.
