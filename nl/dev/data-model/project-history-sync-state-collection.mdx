---
title: Project History Sync State-collectie
icon: rotate
---

`projectHistorySyncState` bevat één document per project dat opnieuw is gesynchroniseerd: de toestand van de huidige of laatste resync, waarbij project-history de geschiedenis van een project opnieuw opbouwt uit wat web en docstore bevatten. De collectie is van project-history en heeft geen Mongoose-schema; de code is de klasse `SyncState` en de hulpfuncties ervan in `services/project-history/app/js/SyncManager.js`.

#### Wie schrijft {#who-writes-it}

| Code | Wat het doet |
| ---- | ------------ |
| `services/project-history/app/js/SyncManager.js:195-249` | `setResyncState`: upsert van de toestand. Aangeroepen wanneer een resync start (`SyncManager.js:163`) en terwijl project-history de resyncupdates verwerkt (`services/project-history/app/js/UpdatesProcessor.js:637`, `784`). |
| `SyncManager.js:257-266` | `_recordStuckClearInSyncState`: telt een vastgelopen resync die wordt gewist. |
| `SyncManager.js:251-255` | `clearResyncState`: verwijdert het document, aan het begin van een harde resync (`SyncManager.js:87`), bij project-history `DELETE /project/:project_id` (`services/project-history/app/js/HttpController.js:1363-1396`) en wanneer een resync van alleen de structuur opnieuw moet beginnen (`SyncManager.js:705-716`). |
| `SyncManager.js:273-289` | `clearResyncStateIfAllAfter`: verwijdert een voltooide toestand waarvan de hele geschiedenis nieuwer is dan een datum. Niets in `app/js` roept het aan. |
| `SyncManager.js:171-181` | `cloneResyncState`: kopieert de toestand naar een ander project, voor project-history `POST /project/:project_id/clone` (`HttpController.js:57`, `124`), dat niets in web aanroept. |

Een resync wordt gestart door project-history `POST /project/:project_id/resync` (`HttpController.js:950-994`), door de cronjobs voor nieuwe pogingen (`services/project-history/app/js/RetryManager.js:156-179`, `server-ce/config/crontab-history`) en door project-history zelf wanneer de verwerking van updates er een nodig heeft (`UpdatesProcessor.js:75`, `224`).

#### Opmerkingen {#notes}

* Een resync loopt zolang `resyncProjectStructure` `true` is of `resyncDocContents` niet leeg is (`SyncManager.js:565-567`). Na 4 uur geldt hij als vastgelopen, en na 5 wisacties als permanent vastgelopen (`SyncManager.js:43-44`, `569-585`).
* Wanneer een resync klaar is, stelt project-history ook `overleaf.history.lastResyncedAt` in op het project (`SyncManager.js:239-248`).
