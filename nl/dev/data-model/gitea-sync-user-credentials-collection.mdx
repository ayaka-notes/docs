---
title: Gitea Sync User Credentials-collectie
icon: lock
---

`giteaSyncUserCredentials` bevat één document per gebruiker die een Gitea-account voor Gitea Sync heeft gekoppeld. Het slaat de OAuth-tokens van de gebruiker versleuteld op. De collectie hoort bij de webmodule `gitea-sync` (`services/web/modules/gitea-sync`). Het schema staat in `services/web/modules/gitea-sync/app/models/giteaSyncUserCredentials.mjs`, en alle toegang loopt via `services/web/modules/gitea-sync/app/src/TokenManager.mjs`.

#### Velden {#fields}

| Veld | Type | Betekenis | Bron |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Door Mongoose ingesteld als de upsert invoegt. | |
| `userId` | ObjectId | De Overleaf-gebruiker. Verplicht. Het schema zegt `unique: true`, maar er wordt geen index gebouwd (zie Indexen); de upsert op `userId` houdt één document per gebruiker. | `giteaSyncUserCredentials.mjs:8`, `TokenManager.mjs:89-96` |
| `gitea` | String | De JSON `{ accessToken, refreshToken, expiresAt }`, versleuteld met `@overleaf/access-token-encryptor`. `expiresAt` is in milliseconden sinds de epoch, of `null`; `refreshToken` kan `null` zijn. Het wachtwoord komt uit `GITEA_TOKEN_CIPHER_PASSWORD`; het cipherlabel is `GITEA_TOKEN_CIPHER_LABEL`, standaard `2026.10-v3`. Verplicht. | `giteaSyncUserCredentials.mjs:9-10`, `TokenManager.mjs:17-30`, `services/web/modules/gitea-sync/app/src/GiteaApiClient.mjs:198-209` |
| `__v` | Number | De versiesleutel van Mongoose. Het schema schakelt die niet uit. | Mongoose-standaard |

#### Wie schrijft {#who-writes-it}

| Code | Wat het doet |
| ---- | ------------ |
| `TokenManager.mjs:89-96` (`saveUserToken`) | Upsert de versleutelde inloggegevens voor de gebruiker. Aangeroepen vanuit de OAuth-callback (`services/web/modules/gitea-sync/app/src/GiteaSyncController.mjs:146`). Anders dan bij GitLab Sync trekt opnieuw koppelen het vervangen token niet in. |
| `TokenManager.mjs:53-79` (`refreshUserToken`) | Als het toegangstoken minder dan 5 minuten van `expiresAt` af is (`:12`), haalt het met het refreshtoken nieuwe tokens op en slaat die op (`:76`). Het draait per gebruiker onder de lock `giteaSyncToken` (`:14,54`), omdat Gitea het refreshtoken bij gebruik vervangt. |
| `TokenManager.mjs:100-102` (`removeUserToken`) | Verwijdert het document. Gitea heeft geen API om een OAuth-token in te trekken, dus de gebruiker trekt de toestemming in Gitea in (`:98-99`). Aangeroepen bij ontkoppelen (`GiteaSyncController.mjs:173`) en als een verwijderde gebruiker verloopt (`services/web/modules/gitea-sync/index.mjs:56-58`). |

#### Wie leest {#who-reads-it}

| Code | Wat het doet |
| ---- | ------------ |
| `TokenManager.mjs:40-44,82-86` (`getUserCredentials`, `getUserToken`) | Ontsleutelt de inloggegevens voor elke aanroep van de Gitea-API en vernieuwt ze eerst als het token bijna verloopt: `services/web/modules/gitea-sync/app/src/GiteaSyncHandler.mjs` (bijvoorbeeld `:27`) en `services/web/modules/gitea-sync/app/src/GitMerge.mjs:52`. Zonder document, of met inloggegevens die niet te ontsleutelen of te vernieuwen zijn, gooit het `InvalidTokenError` en geldt de gebruiker als niet gekoppeld (`GiteaSyncHandler.mjs:25-37`). |
| `services/web/modules/admin-tools/app/src/AdminUserListManager.mjs:395` | Controleert of de gebruiker een document heeft, voor de integraties die in het beheerpaneel worden getoond. |

#### Indexen {#indexes}

| Naam | Sleutels | Opties | Migratie |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

Mongoose `autoIndex` staat uit (`services/web/app/src/infrastructure/Mongoose.mjs:7`), dus de `unique: true` van het schema op `userId` maakt niets aan. Geen enkele migratie maakt indexen aan voor deze collectie.

#### Opmerkingen {#notes}

* Het wijzigen van `GITEA_TOKEN_CIPHER_PASSWORD` maakt de opgeslagen inloggegevens onleesbaar. Die gebruikers gelden dan als niet gekoppeld tot ze opnieuw koppelen.
* Een verwijderde gebruiker houdt het document tot de gebruiker verloopt.
