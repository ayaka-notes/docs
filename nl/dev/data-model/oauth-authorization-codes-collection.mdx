title: OAuth Authorization Codes-collectie
icon: lock-open

`oauthAuthorizationCodes` is bedoeld voor de codes van de OAuth-authorization-code-flow: één document per code, die een client inwisselt voor een toegangstoken. Het schema is `services/web/app/src/models/OauthAuthorizationCode.mjs`, en de webmodule `oauth2-server` bevat de code die erin zou schrijven. In Ayakaleaf Pro bereikt niets die code, dus de collectie blijft leeg (zie Opmerkingen).

#### Velden {#fields}

| Veld | Type | Betekenis | Bron |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Document-id. | `OauthAuthorizationCode.mjs:6` |
| `authorizationCode` | String | De code zelf, ongewijzigd opgeslagen (niet gehasht). | `OauthAuthorizationCode.mjs:8`, `services/web/modules/oauth2-server/app/src/OAuth2Model.mjs:280` |
| `expiresAt` | Date | Einde van de geldigheid. `getAuthorizationCode` weigert een code daarna, en de TTL-index verwijdert hem. | `OauthAuthorizationCode.mjs:9`, `OAuth2Model.mjs:150-153,281` |
| `oauthApplication_id` | ObjectId | Client in [OAuth Applications](/nl/dev/data-model/oauth-applications-collection) die de code heeft aangevraagd. | `OauthAuthorizationCode.mjs:10`, `OAuth2Model.mjs:275-284` |
| `redirectUri` | String | Redirect-URI van het verzoek. | `OauthAuthorizationCode.mjs:11`, `OAuth2Model.mjs:282` |
| `scope` | String | Aangevraagde scope. | `OauthAuthorizationCode.mjs:12`, `OAuth2Model.mjs:283` |
| `user_id` | ObjectId | Gebruiker die de code heeft verleend. | `OauthAuthorizationCode.mjs:13`, `OAuth2Model.mjs:285` |
| `codeChallenge`, `codeChallengeMethod` | String | PKCE-challenge en de methode ervan. | `OauthAuthorizationCode.mjs:14-15`, `OAuth2Model.mjs:286-287` |

#### Wie schrijft {#who-writes-it}

| Code | Wat het doet |
| ---- | ------------ |
| `OAuth2Model.mjs:274-300` (`saveAuthorizationCode`) | Voegt een code toe. Wordt niet bereikt, zie Opmerkingen. |
| `OAuth2Model.mjs:307-312` (`revokeAuthorizationCode`) | Verwijdert een code zodra die gebruikt is. Wordt niet bereikt. |

#### Wie leest {#who-reads-it}

| Code | Wat het doet |
| ---- | ------------ |
| `OAuth2Model.mjs:137-177` (`getAuthorizationCode`) | Laadt een code met de bijbehorende gebruiker en client. Wordt niet bereikt. |

#### Indexen {#indexes}

| Naam | Sleutels | Opties | Migratie |
| ---- | ---- | ------- | --------- |
| `expiresAt_1` | `{ expiresAt: 1 }` | TTL, `expireAfterSeconds: 0`, gedeeltelijk: `expiresAt` bestaat | `20230406125632_oauth_tokens_ttl.mjs` |

De migraties staan in `tools/migrations/`. De unieke index `authorizationCode_1` komt alleen uit migraties met de tags `saas` en `server-pro`, die Community Edition niet uitvoert.

#### Opmerkingen {#notes}

* De modelmethoden hierboven worden alleen aangeroepen door de authorize- en token-handlers van `@node-oauth/oauth2-server`. Web gebruikt die bibliotheek alleen om bearer-tokens te controleren (`services/web/app/src/Features/Authentication/AuthenticationController.mjs:409-450`), en geen route bedient `/oauth/authorize` of `/oauth/token`. Er wordt dus nooit een code geschreven. Persoonlijke toegangstokens worden direct aangemaakt, zie [OAuth Access Tokens](/nl/dev/data-model/oauth-access-tokens-collection).
