---
title: GitHub Sync User Credentials-collectie
icon: key
---

`githubSyncUserCredentials` bevat één document per gebruiker die een GitHub-account voor GitHub Sync heeft gekoppeld. Het slaat het OAuth-toegangstoken van de gebruiker versleuteld op. De collectie hoort bij de webmodule `github-sync` (`services/web/modules/github-sync`). Het schema staat in `services/web/modules/github-sync/app/models/githubSyncUserCredentials.mjs`, en alle toegang loopt via `services/web/modules/github-sync/app/src/TokenManager.mjs`.

#### Velden {#fields}

| Veld | Type | Betekenis | Bron |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Door Mongoose ingesteld als de upsert invoegt. | |
| `userId` | ObjectId | De Overleaf-gebruiker. Verplicht. Het schema zegt `unique: true`, maar er wordt geen index gebouwd (zie Indexen); de upsert op `userId` houdt één document per gebruiker. | `githubSyncUserCredentials.mjs:8`, `TokenManager.mjs:44-48` |
| `github` | String | Het GitHub OAuth-toegangstoken, versleuteld met `@overleaf/access-token-encryptor`. Het wachtwoord komt uit `GITHUB_TOKEN_CIPHER_PASSWORD`; het cipherlabel is `GITHUB_TOKEN_CIPHER_LABEL`, standaard `2026.3-v3`. Verplicht. | `githubSyncUserCredentials.mjs:9`, `TokenManager.mjs:12-25` |
| `__v` | Number | De versiesleutel van Mongoose. Het schema schakelt die niet uit. | Mongoose-standaard |

Alleen het toegangstoken wordt opgeslagen: de OAuth-callback bewaart `access_token` uit het antwoord van GitHub (`services/web/modules/github-sync/app/src/GitHubApiClient.mjs:180-191`). Er is geen refreshtoken of vervaltijd.

#### Wie schrijft {#who-writes-it}

| Code | Wat het doet |
| ---- | ------------ |
| `TokenManager.mjs:42-58` (`saveUserToken`) | Upsert het versleutelde token voor de gebruiker. Als de gebruiker opnieuw koppelt, wordt het vervangen token op de achtergrond bij GitHub ingetrokken. Aangeroepen vanuit de OAuth-callback (`services/web/modules/github-sync/app/src/GitHubSyncController.mjs:146`). |
| `TokenManager.mjs:61-76` (`removeUserToken`) | Trekt het token in bij GitHub (naar beste vermogen) en verwijdert dan het document. Aangeroepen bij ontkoppelen (`GitHubSyncController.mjs:167`) en als een verwijderde gebruiker verloopt (`services/web/modules/github-sync/index.mjs:66-68`). |

#### Wie leest {#who-reads-it}

| Code | Wat het doet |
| ---- | ------------ |
| `TokenManager.mjs:36-40` (`getUserToken`) | Ontsleutelt het token voor elke aanroep van de GitHub-API: `services/web/modules/github-sync/app/src/GitHubSyncHandler.mjs` (bijvoorbeeld `:27`) en `services/web/modules/github-sync/app/src/GitMerge.mjs:43`. Zonder document, of met een token dat niet te ontsleutelen is, gooit het `InvalidTokenError` en geldt de gebruiker als niet gekoppeld (`GitHubSyncHandler.mjs:25-37`). |
| `services/web/modules/admin-tools/app/src/AdminUserListManager.mjs:393` | Controleert of de gebruiker een document heeft, voor de integraties die in het beheerpaneel worden getoond. |

#### Indexen {#indexes}

| Naam | Sleutels | Opties | Migratie |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

Mongoose `autoIndex` staat uit (`services/web/app/src/infrastructure/Mongoose.mjs:7`), dus de `unique: true` van het schema op `userId` maakt niets aan. `tools/migrations/20190912145011_create_githubSyncUserCredentials_indexes.mjs` (`user_id` van upstream) heeft alleen de tag `saas` en draait niet in CE.

#### Opmerkingen {#notes}

* Het wijzigen van `GITHUB_TOKEN_CIPHER_PASSWORD` maakt de opgeslagen tokens onleesbaar. Die gebruikers gelden dan als niet gekoppeld tot ze opnieuw koppelen.
* Een verwijderde gebruiker houdt het document tot de gebruiker verloopt.
