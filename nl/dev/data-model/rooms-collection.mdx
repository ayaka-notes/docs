`rooms` bevat één document per chatruimte van een project: de projectchat of één thread met reviewopmerkingen. Alleen de chatservice schrijft erin, in `services/chat/app/js/Features/Threads/ThreadManager.js`. Er is geen Mongoose-schema. De berichten van een ruimte staan in de collectie [messages](/nl/dev/data-model/messages-collection).

#### Velden {#fields}

| Veld | Type | Betekenis | Bron |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Ruimte-id. `messages.room_id` verwijst hiernaar. | `ThreadManager.js:57-61` |
| `project_id` | ObjectId | Project waartoe de ruimte behoort. | `ThreadManager.js:43-54` |
| `thread_id` | ObjectId | Alleen bij opmerkingenthreads: de id van de opmerking, gelijk aan `id` en `op.t` van de opmerking in `docs.ranges.comments` (zie [docs](/nl/dev/data-model/docs-collection)). Ontbreekt bij de projectchatruimte. | `ThreadManager.js:38-55`, `services/docstore/app/js/RangeManager.js:54-57` |
| `resolved` | Object | Wordt gezet wanneer de thread is opgelost en verwijderd wanneer deze opnieuw wordt geopend. Een thread zonder dit veld is open. | `ThreadManager.js:94-123` |
| `resolved.user_id` | String | Id van de gebruiker die de thread heeft opgelost. Opgeslagen als string, niet als ObjectId: de request-body wordt alleen gecontroleerd op een geldige id, niet omgezet. | `ThreadManager.js:103`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:70` |
| `resolved.ts` | Date | Wanneer de thread is opgelost. | `ThreadManager.js:104` |

#### Opmerkingen {#notes}

* Een project heeft hoogstens één ruimte zonder `thread_id`: de projectchat. De chatservice vindt die met `thread_id: { $exists: false }` (`ThreadManager.js:38-45`).
* De opgeloste status van een opmerking staat alleen hier. Docstore verwijdert `op.resolved` voordat het bereiken opslaat (`services/docstore/app/js/RangeManager.js:59-61`).
* Na een projectkopie bestaat dezelfde `thread_id` in twee projecten. Zoek altijd op `project_id` en `thread_id` samen, zoals de chatservice doet.
* Ruimtes van een verwijderd project blijven bestaan totdat het verwijderde project verloopt.
