`projectAuditLogEntries` is het auditlogboek van projecten: delen, uitnodigingen, eigendomsoverdrachten, downloads en beheeracties. Eén document is één gebeurtenis op één project. `web` is de eigenaar; het schema is `services/web/app/src/models/ProjectAuditLogEntry.mjs`, en de kern schrijft via `services/web/app/src/Features/Project/ProjectAuditLogHandler.mjs`.

`tools/migrations/20220929193200_add_auditLog_indexes.mjs` maakte eerst `project_id_1` op `{ projectId: 1 }` aan; `20250912102601` vervangt die door de samengestelde index. De markeringen `index: true` van het schema worden niet toegepast, omdat automatisch indexeren door Mongoose uit staat (`services/web/app/src/infrastructure/Mongoose.mjs:7`). De indexmigratie voor `managedSubscriptionId` heeft alleen de tag `saas`.

#### Opmerkingen {#notes}

* Vermeldingen verlopen via de TTL-index 2,5 jaar na `timestamp`, en alle vermeldingen van een project verdwijnen wanneer het record van het verwijderde project verloopt.
