title: User Audit Log Entries-collectie
icon: user-clock

`userAuditLogEntries` is het auditlogboek van gebruikersaccounts: aanmeldingen, wijzigingen van wachtwoord en e-mailadres, gekoppelde accounts en beheeracties. Eén document is één gebeurtenis op één account. `web` is de eigenaar; het schema is `services/web/app/src/models/UserAuditLogEntry.mjs`, en de kern schrijft via `services/web/app/src/Features/User/UserAuditLogHandler.mjs`.

| Veld | Type | Betekenis | Bron |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id van de vermelding. | `UserAuditLogEntry.mjs:4` |
| `userId` | ObjectId | Het account waarop de gebeurtenis betrekking heeft. | `UserAuditLogEntry.mjs:6` |
| `operation` | String | Wat er gebeurde, een naam in kebab-case zoals `login` (zie de tabel hieronder). | `UserAuditLogEntry.mjs:11` |

Het schema markeert `userId` en `managedSubscriptionId` met `index: true`, maar automatisch indexeren door Mongoose staat uit (`services/web/app/src/infrastructure/Mongoose.mjs:7`), dus alleen de migraties hierboven maken indexen aan. De indexmigratie voor `managedSubscriptionId` heeft alleen de tag `saas`.

#### Opmerkingen {#notes}

* Vermeldingen verlopen via de TTL-index 2,5 jaar na `timestamp`.
