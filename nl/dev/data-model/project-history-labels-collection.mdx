`projectHistoryLabels` bevat de labels die gebruikers in de History-weergave op versies zetten, één document per label. project-history is eigenaar en schrijft het in `services/project-history/app/js/LabelsManager.js`; er is geen Mongoose-schema. Web benadert het alleen via de project-history-API.

#### Velden {#fields}

| Veld | Type | Betekenis | Bron |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Label-id. | `LabelsManager.js:81-85` |
| `project_id` | ObjectId | Het project. | `LabelsManager.js:73` |
| `comment` | String | De labeltekst. | `LabelsManager.js:74` |
| `version` | Number | De projectgeschiedenisversie waarnaar het label verwijst. | `LabelsManager.js:75` |
| `created_at` | Date | Wanneer het label is gemaakt; de request kan een eigen tijd meegeven, anders is het nu. | `LabelsManager.js:70`, `76` |
| `user_id` | ObjectId | Wie het label heeft gemaakt. Weggelaten als de request geen gebruiker heeft. | `LabelsManager.js:78-80` |

#### Wie schrijft het {#who-writes-it}

| Code | Wat het doet |
| ---- | ------------ |
| `services/project-history/app/js/LabelsManager.js:44-90` | `createLabel`: voegt een label in, voor project-history `POST /project/:project_id/labels` (`services/project-history/app/js/HttpController.js:1134-1171`). Web roept het aan wanneer een gebruiker een label toevoegt, met de id van de gebruiker (`services/web/app/src/Features/History/HistoryController.mjs:529-546`). |
| `LabelsManager.js:113-126` | `deleteLabel`: verwijdert een label van het project, voor `DELETE /project/:project_id/labels/:label_id`. Web gebruikt het wanneer de projecteigenaar een label verwijdert (`HistoryController.mjs:649-670`). |
| `LabelsManager.js:92-111` | `deleteLabelForUser`: verwijdert een label alleen als de gebruiker het heeft gemaakt, voor `DELETE /project/:project_id/user/:user_id/labels/:label_id`. Web gebruikt het voor iedereen anders. |
| `LabelsManager.js:128-143` | `transferLabels`: verplaatst alle labels van één gebruiker naar een andere, voor `POST /user/:from_user/labels/transfer/:to_user` (`services/project-history/app/js/Router.js:52-55`). Niets in web roept deze route aan. |
| `LabelsManager.js:7-25` | `cloneLabels`: kopieert de labels van een project naar een ander project, voor project-history `POST /project/:project_id/clone` (`HttpController.js:113`), dat niets in web aanroept. |

#### Wie leest het {#who-reads-it}

| Code | Wat het doet |
| ---- | ------------ |
| `LabelsManager.js:27-42` | `getLabels`: alle labels van een project, teruggegeven als `{ id, comment, version, user_id, created_at }` (`LabelsManager.js:163-171`). Gebruikt door `GET /project/:project_id/labels` (`HttpController.js:1076-1100`), dat web aanroept voor de History-weergave en waarbij het gebruikersnamen invult (`HistoryController.mjs:488-499`). |
| `services/project-history/app/js/SummarizedUpdatesManager.js:57` | Voegt de labels toe aan de lijst met geschiedenisupdates. |

#### Opmerkingen {#notes}

* Voordat project-history een label invoegt, verwerkt het de wachtende updates van het project en controleert het of history-v1 een chunk voor die versie heeft, tenzij de request `validate_exists: false` meestuurt (`LabelsManager.js:53-59`, `173-195`; `HttpController.js:1109-1115`).
* Geen code verwijdert de labels van een project wanneer het project wordt verwijderd: project-history `DELETE /project/:project_id` wist alleen de synchronisatiestatus en het foutrecord (`HttpController.js:1363-1396`), en geen andere service raakt deze collectie aan.
