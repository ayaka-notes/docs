Haalt een externe URL op voor web en streamt het antwoord terug, waarbij interne adressen worden geweigerd zodat gebruikers het Docker-netwerk niet kunnen bereiken. Web stuurt URL-bestanden, Open in Overleaf-imports en de web_fetch van de AI-agent erdoorheen.

* <strong>Adres:</strong> `http://linked-url-proxy:3066`, binnen het Docker-netwerk
* <strong>Authenticatie:</strong> geen
* <strong>OpenAPI-bestand:</strong> [`develop/hoppscotch/openapi/linked-url-proxy.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/linked-url-proxy.yaml)
