Houdt de documenten die in de editor open zijn in Redis, past bewerkingen erop toe en schrijft ze via web terug naar Mongo. Wordt aangeroepen door web en real-time.

* <strong>Adres:</strong> `http://document-updater:3003`, binnen het Docker-netwerk
* <strong>Authenticatie:</strong> geen
* <strong>OpenAPI-bestand:</strong> [`develop/hoppscotch/openapi/document-updater.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/document-updater.yaml)
