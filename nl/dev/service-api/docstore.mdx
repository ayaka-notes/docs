title: docstore
icon: database
---

Slaat elk document (regels, versie, ranges) van elk project op in de Mongo-collectie `docs` en archiveert documenten naar objectopslag wanneer er een backend is ingesteld. Wordt door web aangeroepen; document-updater bereikt het via web.

* <strong>Adres:</strong> `http://docstore:3016`, binnen het Docker-netwerk
* <strong>Authenticatie:</strong> geen
* <strong>OpenAPI-bestand:</strong> [`develop/hoppscotch/openapi/docstore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/docstore.yaml)
