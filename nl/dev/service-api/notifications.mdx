Slaat de meldingen die gebruikers in de projectenlijst zien (bijvoorbeeld projectuitnodigingen) op in de Mongo-collectie `notifications`. Web en third-party-datastore roepen het aan; het heeft geen authenticatie en is alleen bereikbaar binnen het Docker-netwerk.

* <strong>Adres:</strong> `http://notifications:3042`, binnen het Docker-netwerk
* <strong>Authenticatie:</strong> geen
* <strong>OpenAPI-bestand:</strong> [`develop/hoppscotch/openapi/notifications.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/notifications.yaml)
