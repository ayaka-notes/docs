Slaat de projectchat en de commentaarthreads (hun berichten en opgeloste status) op in de Mongo-collecties `rooms` en `messages`. Wordt door web aangeroepen via `ChatApiHandler`.

* <strong>Adres:</strong> `http://chat:3010`, binnen het Docker-netwerk
* <strong>Authenticatie:</strong> geen
* <strong>OpenAPI-bestand:</strong> [`develop/hoppscotch/openapi/chat.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/chat.yaml)
