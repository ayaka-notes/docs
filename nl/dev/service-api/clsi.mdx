CLSI (Common LaTeX Service Interface) compileert projecten, voert SyncTeX en texcount uit op de compilatie-uitvoer en converteert documenten met pandoc. Web roept het aan; de uitvoerbestanden zelf worden geleverd door clsi-nginx, niet via deze poort. Geen authenticatie: het is alleen bereikbaar binnen het Docker-netwerk.

* <strong>Adres:</strong> `http://clsi:3013`, binnen het Docker-netwerk
* <strong>Authenticatie:</strong> geen
* <strong>OpenAPI-bestand:</strong> [`develop/hoppscotch/openapi/clsi.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/clsi.yaml)
