Er is een bestand `services/web/frontend/extracted-translations.json`; Overleaf web gebruikt alleen de geëxtraheerde vertalingen uit dit bestand.

Voer de volgende opdracht uit om de geëxtraheerde vertalingen bij te werken als je inhoud hebt toegevoegd.

```bash
user ➜ ~/overleaf-pro/develop (server-pro) $ bin/shell webpack
root@432836260f8a:/overleaf/services/web# npm run extract-translations
```

Bewerk de vertaalbestanden in principe niet zelf en gebruik bij voorkeur bestaande vertalingen, omdat al deze bestanden worden bijgewerkt vanuit de Overleaf-upstream of vanaf een externe vertaalsite.
