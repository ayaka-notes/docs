Om tijd te besparen en de ontwikkelomgeving snel op te bouwen, bieden we een alternatieve configuratie van de ontwikkelomgeving aan: GitHub Codespace.

## Configuratiehandleiding

<Steps>
<Step title="Codespaces aanmaken">
Klik op de volgende knop om een codespace in de cloud aan te maken voor de ontwikkeling van server-pro.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/ayakaleaf-pro)

We raden aan een **Machine Type** van minimaal **4-core** te kiezen. Voor grotere machinetypes kun je een verzoek indienen bij het officiële ondersteuningsteam van GitHub door [hier](https://support.github.com/contact?tags=rr-codespaces%2Ccat_codespaces) een ticket aan te maken.

<Frame>
  <img src="/images/dev/image.png" alt="" />
</Frame>
</Step>

<Step title="Setupscript starten">
Je moet geduldig wachten tot de codespace is aangemaakt. Zodra je toegang hebt tot je terminal, voer je de volgende opdracht uit:

```text
cd develop/
bin/setup
```

<Frame>
  <img src="/images/dev/image-1.png" alt="" />
</Frame>

<Warning>

Met dit script (`bin/setup`) kun je de ontwikkelomgeving in zo kort mogelijke tijd opzetten op basis van de nieuwste commit van de branch `server-pro`. Het is mogelijk niet bruikbaar voor oudere versies of andere branches.

We bouwen elke dag een Docker-image voor ontwikkeling met [GitHub Action](https://github.com/ayaka-notes/ayakaleaf-pro/actions).

</Warning>
</Step>

<Step title="Je launchpad openen">
Ga naar het tabblad Ports; je ziet daar een lijst met beschikbare webpoorten. Klik op de poort `80`. Je zou nu de launchpad-pagina moeten zien.

<Frame>
  <img src="/images/dev/image-2.png" alt="" />
</Frame>

Je ziet dan:

<Frame>
  <img src="/images/dev/image-3.png" alt="" />
</Frame>
</Step>

<Step title="Veel plezier met ontwikkelen">
Nu is het jouw beurt! Begin met het bouwen van je geweldige feature. Voer de volgende opdracht uit om realtime weergave in te schakelen:

```bash title="bash" wrap
docker compose -f docker-compose.yml -f docker-compose.dev.yml -f ./docker-compose.image.yml up --no-deps --detach
```
</Step>
</Steps>
