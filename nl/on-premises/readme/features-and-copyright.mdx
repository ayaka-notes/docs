We respecteren auteursrecht en vermelden daarom hier alle functies en de code die in dit project wordt gebruikt. Op deze pagina geven we informatie over de nieuwe functies van Ayakaleaf Pro en de bijbehorende auteursrechten op de code.

Tenzij anders vermeld, gebruiken we Codex van OpenAI voor codereview en PR-review. Daarbij hebben we veel beveiligingsproblemen opgelost, waarvoor we hen oprecht dankbaar zijn. Zie [ayaka-notes/ayakaleaf-pro/pull](https://github.com/ayaka-notes/ayakaleaf-pro/pulls) voor meer details.

### Overzicht

In de loop der jaren hebben veel ontwikkelaars uit de community zich flink ingespannen om de Overleaf Community Edition te verbeteren. Het gaat om:

* [https://github.com/ertuil/overleaf](https://github.com/ertuil/overleaf)
* [https://github.com/AllanChain/lcpu-overleaf](https://github.com/AllanChain/lcpu-overleaf)
* [https://github.com/yu-i-i/overleaf-cep/](https://github.com/yu-i-i/overleaf-cep/)
* [https://github.com/ayaka-notes/overleaf](https://github.com/ayaka-notes/overleaf)
* [https://github.com/davrot/overleaf\_with\_admin\_extension](https://github.com/davrot/overleaf_with_admin_extension)
* [https://github.com/overleaf/overleaf/pull/1447](https://github.com/overleaf/overleaf/pull/1447) (GitHub-integratie)
* [https://github.com/overleaf/overleaf/pull/1385](https://github.com/overleaf/overleaf/pull/1385) (Typst-ondersteuning)

Mogelijk hebben we gerelateerde code in ons project gebruikt, en daarvoor willen we hen graag bedanken.

#### Functie 01: Sjabloonsysteem

Deze functie is voornamelijk ontwikkeld door [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep). We hebben een deel van de code aangepast ter verbetering, zodat je:

* Sjablonen direct op de sjabloonpagina's kunt downloaden.
* Het project kunt openen dat bij het sjabloon hoort.
* Omslagafbeeldingen van hogere kwaliteit kunt genereren (en in kortere tijd).

#### Functie 05: Beheerpaneel

<Warning>

Wanneer je systeem 1000 gebruikers of projecten heeft, toont het beheerpaneel alleen de nieuwste 1000 gebruikers of projecten. Gebruik het zoekpaneel om naar specifieke gebruikers of projecten te zoeken.

</Warning>

Deze functie is voornamelijk ontwikkeld door [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep). We hebben een deel van de code aangepast ter verbetering, zodat je:

* Via de backend gebruikers kunt zoeken wanneer je meer dan 1000 gebruikers hebt.
* Via de backend projecten kunt zoeken wanneer je meer dan 1000 projecten hebt.
* Projecten direct vanuit het projectbeheerpaneel kunt openen.
* De compileertijdlimiet van gebruikers in het beheerpaneel kunt bekijken en aanpassen.
* Het wachtwoord van gebruikers direct in het beheerpaneel kunt resetten.
* Overige verbeteringen...

#### Functie 17: Integratie met referentiebeheerders

Deze functie is ontwikkeld door [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro). De Zotero-integratie werd oorspronkelijk ontwikkeld door [davrot](https://github.com/davrot) en [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep); wij hebben deze opnieuw opgebouwd met OAuth en in v6.3.0 de Mendeley-integratie (OAuth 2.0) toegevoegd. Je kunt:

* Je Zotero- en Mendeley-accounts koppelen in de accountinstellingen.
* Je persoonlijke bibliotheek of een groepsbibliotheek als `.bib`-bestand in je project importeren.
* Het geïmporteerde `.bib`-bestand op elk moment vernieuwen om het up-to-date te houden.

Zie [Zotero-integratie](/nl/on-premises/configuration/overleaf-toolkit/zotero-integration) en [Mendeley-integratie](/nl/on-premises/configuration/overleaf-toolkit/mendeley-integration) voor de installatie.

#### Functie 18: Open in Overleaf API

Deze functie is ontwikkeld door [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) en is compatibel met de "Open in Overleaf"-API van overleaf.com. Je kunt een "Open in Ayakaleaf"-link of -knop toevoegen aan je website, blog of sjabloonbibliotheek, zodat bezoekers met één klik een LaTeX-fragment, een extern bestand of een ZIP-project als nieuw project in je instantie kunnen openen. Bezoek `/devs` op je instantie voor details en zie [Overleaf Import API](/nl/on-premises/configuration/overleaf-toolkit/overleaf-import-api).
