title: Overleaf Server Pro vs. Ayakaleaf Pro
description: Overleaf Server Pro en Ayakaleaf Pro Edition zijn allebei on-premises versies van Overleaf. Maar wat zijn de verschillen?
icon: scale-balanced
---

<Info>

Ayakaleaf Pro is een uitgebreide implementatie van Overleaf Community Edition die alle premiumfuncties van Server Pro _**gratis**_ aanbiedt. In tegenstelling tot Overleaf Common op [https://www.overleaf.com/](https://www.overleaf.com/) hebben wij geen beperkingen op de compilatietijd en geen licentie-eisen voor het aantal gebruikers, en kun je je eigen gegevens volledig zelf hosten, wat absolute veiligheid garandeert.

Overleaf Server Pro is een commerciële, zelf gehoste deployment van Overleaf met officiële support. Ga voor meer informatie over Server Pro naar [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud).

</Info>

<Warning>

Overleaf Community Edition is bedoeld voor gebruik in omgevingen waarin **alle** gebruikers worden vertrouwd. Community Edition is **niet** geschikt voor scenario's waarin isolatie van gebruikers vereist is, omdat Sandbox Compiles niet beschikbaar zijn.

Zonder sandboxing draaien LaTeX-compilaties met dezelfde rechten als de container, waardoor ze toegang hebben tot het bestandssysteem, het netwerk en de omgevingsvariabelen ervan. Dit brengt het risico van gegevenslekken of systeemcompromittering met zich mee. Compilaties zonder sandbox mogen alleen worden gebruikt in volledig vertrouwde omgevingen; voor deployments met meerdere gebruikers of in productie worden Sandbox Compiles sterk aanbevolen.

Bekijk voor meer informatie over Sandbox Compiles onze [documentatie](/nl/on-premises/configuration/overleaf-toolkit/sandboxed-compiles).

</Warning>

### Communitysupport

Voor wie een zelf gehoste Overleaf-instantie gebruikt, wordt support geboden door de community via GitHub [Issues](https://github.com/ayaka-notes/overleaf-pro/issues).

Om op een ondersteunde versie te blijven, kun je controleren welke versie van Overleaf je draait door de uitvoer van de onderstaande opdracht te vergelijken met de Image ID's die in de release notes zijn gepubliceerd.

```bash
docker inspect --format '{{.Image}}' sharelatex | awk -F: '{print substr($2, 1, 12)}'
```
