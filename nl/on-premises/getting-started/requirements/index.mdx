### Vereisten voor het installeren van Server Pro en Community Edition

<Warning>

We raden sterk aan om Server Pro te draaien op een recente en stabiele versie van Ubuntu (bijv. Ubuntu 24.04 in 2025–2026) met een recente versie van Docker. Server Pro op andere systemen draaien is mogelijk, maar maakt het voor ons veel moeilijker om ondersteuning te bieden voor niet-standaard Ubuntu/Docker-opstellingen. We kunnen ook geen ondersteuning bieden voor problemen met Docker zelf.

</Warning>
