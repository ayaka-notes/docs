### Besturingssystemen

Voor de beste ervaring bij het draaien van Overleaf raden we sterk aan een **op Debian gebaseerd** besturingssysteem te gebruiken, zoals **Ubuntu**. Deze keuze sluit aan bij de ontwikkelomgeving van de software en is de voorkeursoptie van het merendeel van de Overleaf-gebruikers.

<Danger>

Bij gebruik van Server Pro met Sandboxed Compiles is het **belangrijk** om te weten dat de applicatie root-toegang tot de Docker-socket vereist.

</Danger>

### Afhankelijkheden

* Docker 25.0 en 29
* MongoDB 7.0 en 8.0
* Redis 6.2 en 7.5

<Info>

U kunt de End-of-Life-datums (EOL) van de bovenstaande afhankelijkheden en andere populaire producten volgen via de dienst endoflife.date: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

MongoDB en Redis worden automatisch door `docker compose` gepulld wanneer u Server CE of Server Pro draait, tenzij geconfigureerd om een andere installatie te gebruiken.

</Info>

De Toolkit is afhankelijk van de volgende programma's:

* bash
* Docker

`docker compose` is vereist en wordt doorgaans samen met Docker geïnstalleerd.

We raden aan de meest recente versie van Docker te installeren die beschikbaar is voor uw besturingssysteem.

Zodra Docker correct is geïnstalleerd, zou u deze opdrachten zonder fouten moeten kunnen uitvoeren:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2)
docker compose version

# List the running Docker containers on your system
docker ps
```
