### Besturingssystemen {#operating-systems}

Voor gedeelde servers en productieservers raden we een **op Debian gebaseerd Linux**-systeem aan, zoals **Ubuntu**. Ayakaleaf Pro kan ook draaien op [macOS met Docker Desktop](/nl/on-premises/installation/using-docker-compose/macos) en [Windows met WSL 2 en Docker Desktop](/nl/on-premises/installation/using-docker-compose/windows). Alle drie de platforms gebruiken Linux-containers en dezelfde Toolkit; volg de handleiding voor het besturingssysteem van uw host.

<Danger>

Bij gebruik van Sandboxed Compiles is het **belangrijk** om te weten dat de applicatie root-toegang tot de Docker-socket vereist.

</Danger>

### Afhankelijkheden {#dependencies}

* Docker 25.0 en 29
* MongoDB 7.0 en 8.0
* Redis 6.2 en 7.5

<Info>

U kunt de End-of-Life-datums (EOL) van de bovenstaande afhankelijkheden en andere populaire producten volgen via de dienst endoflife.date: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

MongoDB en Redis worden automatisch door `docker compose` gepulld wanneer u Ayakaleaf Pro draait, tenzij geconfigureerd om een andere installatie te gebruiken.

</Info>

De Toolkit is afhankelijk van de volgende programma's:

* bash
* Docker

`docker compose` is vereist en wordt doorgaans samen met Docker geïnstalleerd.

We raden aan de meest recente versie van Docker te installeren die beschikbaar is voor uw besturingssysteem.

Zodra Docker correct is geïnstalleerd, zou u deze opdrachten zonder fouten moeten kunnen uitvoeren:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2 or later, such as v5)
docker compose version

# List the running Docker containers on your system
docker ps
```
