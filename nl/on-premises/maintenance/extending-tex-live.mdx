Het is mogelijk een bestaande TeX Live-image uit te breiden met een nieuw Dockerfile en de applicatie te configureren om de nieuwe image te gebruiken.

Hier volgen enkele richtlijnen voor het installeren van nieuwe pakketten of lettertypen.

De TeX Live-images worden niet vaak bijgewerkt. We raden aan eigen images opnieuw te bouwen wanneer je Ayakaleaf Pro upgradet.

<Danger>

De volgende secties zijn alleen van toepassing op [Sandboxed Compiles](/nl/on-premises/configuration/overleaf-toolkit/sandboxed-compiles).

</Danger>

### Nieuwe pakketten installeren en bijwerken

Je kunt `tlmgr`-opdrachten zoals `tlmgr install` en `tlmgr update` gebruiken om TeX Live-pakketten te beheren, zoals in het volgende voorbeeld:

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2023.1

RUN tlmgr update --force ebproof
```

### `tlmgr` gebruiken in een oudere TeX Live-image

Standaard downloadt `tlmgr` resources van de nieuwste TeX Live-release. Bij het patchen van een oudere TeX Live-image moeten de downloads worden omgezet naar het bijbehorende archief. Zie de lijst op [https://www.tug.org/historic/](https://www.tug.org/historic/) voor mirrors van archieven.

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2022.1

RUN tlmgr option repository <MIRROR>/systems/texlive/<YEAR>/tlnet-final
# e.g. RUN tlmgr option repository ftp://tug.org/historic/systems/texlive/2022/tlnet-final

RUN tlmgr update --force ebproof
```

### Nieuwe lettertypen installeren

Er zijn verschillende procedures om nieuwe lettertypen in een TeX Live-distributie te installeren, en het installeren van een eigen lettertype kan meerdere stappen vergen. De [instructies voor het installeren van TeX-lettertypen](https://tug.org/fonts/fontinstall.html) in de officiële TeX Live-documentatie zijn waarschijnlijk een goed startpunt.

Het volgende `Dockerfile` toont een voorbeeld van het installeren van een TrueType-lettertype bovenop een bestaande TeX Live 2022-image:

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2022.1

COPY ./myfonts/*.ttf /usr/share/fonts/truetype/myfont/

# rebuild font information cache
RUN fc-cache
```

### Ayakaleaf Pro configureren om de nieuwe images te gebruiken

Gebruik de naam `ghcr.io/ayaka-notes/texlive-full` en een eigen tag om de nieuwe image te bouwen, bijvoorbeeld:

```bash
docker build -t ghcr.io/ayaka-notes/texlive-full:2023.1-custom .
```

Nu kunnen we Ayakaleaf Pro configureren om de nieuwe image `2023.1-custom` te gebruiken door de omgevingsvariabelen `TEX_LIVE_DOCKER_IMAGE`, `ALL_TEX_LIVE_DOCKER_IMAGES` en `ALL_TEX_LIVE_DOCKER_IMAGE_NAMES` bij te werken (de namen zijn optioneel en volgen de volgorde van de images):

```text wrap
TEX_LIVE_DOCKER_IMAGE: "ghcr.io/ayaka-notes/texlive-full:2023.1-custom"
ALL_TEX_LIVE_DOCKER_IMAGES: "ghcr.io/ayaka-notes/texlive-full:2023.1,ghcr.io/ayaka-notes/texlive-full:2023.1-custom"
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES: "TeX Live 2023,TeX Live 2023 custom"
```

In het bovenstaande voorbeeld gebruiken nieuwe projecten standaard de nieuwe image `2023.1-custom`, terwijl `2023.1` beschikbaar blijft voor wanneer die nodig is.

De eigen image bestaat alleen op je host, dus `bin/up` kan deze niet ophalen. Stel `SIBLING_CONTAINERS_PULL=false` in in `config/overleaf.rc` (haal de andere images zelf op met `docker pull`) en voer daarna `bin/up -d` uit om de nieuwe instellingen toe te passen.

### Vragen en antwoorden

<Accordion title="Moet ik Chinese lettertypen installeren om Chinese documenten met XeLaTeX te compileren?">

<strong>Antwoord:</strong> Nee, niet met de `texlive-full`-images. Deze bevatten de Chinese TeX Live-pakketten (`ctex`, `xeCJK`) met de Fandol-lettertypen, en de Noto CJK-lettertypen (bijvoorbeeld `Noto Serif CJK SC`). Stel de compiler van het project in de editorinstellingen in op XeLaTeX en compileer, bijvoorbeeld:

```latex
\documentclass{ctexart}
\begin{document}
你好，世界！
\end{document}
```

Om Noto te gebruiken in plaats van Fandol voeg je `\setCJKmainfont{Noto Serif CJK SC}` toe. Er is geen `latexmkrc` nodig. Bouw voor andere lettertypen een eigen image zoals beschreven in [Nieuwe lettertypen installeren](#installing-new-fonts).

</Accordion>
