## Een document importeren {#import-a-document}

Hiermee maakt u een nieuw LaTeX-project van een Word-document (`.docx`) of een Markdown-bestand (`.md`). De naam van het project komt van de bestandsnaam.

<Steps>
<Step title="Het importvenster openen">
Klik op de projectenpagina op **New project**. Klik onder **Import** op **Word document** of **Markdown document**.

<Frame caption="Het menu New project">
  <img src="/images/on-premises/word-import-menu.png" alt="Het menu New project met Word document en Markdown document onder Import" />
</Frame>
</Step>

<Step title="Het bestand kiezen">
Klik op **Select .docx file** of sleep het bestand naar het venster. Voor Markdown heet de knop **Select .md file**. De import begint meteen.

<Frame caption="Een Word-document kiezen">
  <img src="/images/on-premises/word-import-dialog.png" alt="Het venster Choose Word document met de knop Select .docx file" />
</Frame>
</Step>

<Step title="Beginnen met bewerken">
Het nieuwe project opent met de melding **Document ready for editing**. Klik op **Start editing**.

<Frame caption="De import is voltooid">
  <img src="/images/on-premises/word-import-ready.png" alt="Het venster Document ready for editing met de knop Start editing" />
</Frame>
</Step>

<Step title="Het resultaat controleren">
Het document staat nu in `main.tex`, met de koppen in het bestandsoverzicht. Klik op **Recompile** om de PDF te zien. Controleer de opmaak, vooral tabellen, figuren en citaten, die mogelijk aangepast moeten worden.

<Frame caption="Het geïmporteerde project">
  <img src="/images/on-premises/word-import-project.png" alt="Het geïmporteerde project in de editor, met main.tex, het bestandsoverzicht en de gecompileerde PDF" />
</Frame>
</Step>
</Steps>

### Als de import mislukt {#if-the-import-fails}

Als het bestand niet kan worden omgezet, toont het venster **Your document couldn't be imported**. Klap **Conversion error details** open om te zien waarom. Er wordt geen project gemaakt.

<Frame caption="Een document dat niet kon worden geïmporteerd">
  <img src="/images/on-premises/word-import-error.png" alt="Het importvenster met een foutmelding en Conversion error details" />
</Frame>

Het venster accepteert alleen het type dat u hebt gekozen. Een `.md`-bestand in het Word-venster toont **You can only upload: .docx**.

## Een project exporteren {#export-a-project}

Open het project en klik bovenaan de editor op de naam ervan. Klik op een van deze opties:

| Optie                              | U krijgt                                       |
| ----------------------------------- | --------------------------------------------- |
| <strong>Export as Word document (.docx)</strong> | Een `.docx`-bestand met de naam van het project        |
| <strong>Export as Markdown (.md)</strong>        | Een `.zip`-bestand met `main.md`                  |
| <strong>Export as HTML (.html)</strong>          | Een `.zip`-bestand met `main.html`                |

De download start vanzelf. De omzetting kan niet alle LaTeX-opmaak weergeven, dus controleer het resultaat.
