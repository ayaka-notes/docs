Python-scripts draaien in uw browser, dus de uitvoer verschijnt direct onder de editor. U hoeft niets in te stellen.

<Steps>
<Step title="Een script maken">
Klik in de bestandsstructuur op het pictogram **New file**. Voer een naam in die eindigt op `.py` en klik op **Create**.

<Frame caption="Een nieuw Python-bestand">
  <img src="/images/on-premises/python-runner-new-file.png" alt="Het dialoogvenster Add Files met de naam analysis.py" />
</Frame>

De knop **Run** en een uitvoerpaneel verschijnen onder de editor. De eerste keer blijft de knop uitgeschakeld terwijl Python laadt.
</Step>

<Step title="Het uitvoeren">
Schrijf uw code en klik op **Run**. Wat het script afdrukt, verschijnt in het uitvoerpaneel. U hoeft niet eerst op te slaan.

Bestanden die het script schrijft, komen in uw project terecht. Een melding vertelt u welke, bijvoorbeeld **results.txt saved to your project**, en het bestand verschijnt in de bestandsstructuur.

<Frame caption="De uitvoer en een opgeslagen bestand">
  <img src="/images/on-premises/python-runner-output.png" alt="Een script in de editor, de afgedrukte uitvoer eronder en de melding results.txt saved to your project" />
</Frame>
</Step>

<Step title="Een script stoppen">
Terwijl een script draait, wordt **Run** **Stop**. Klik erop om het script te onderbreken. Het uitvoerpaneel eindigt met **Execution interrupted**.

<Frame caption="Een draaiend script">
  <img src="/images/on-premises/python-runner-stop.png" alt="De knop Stop en de uitvoer van een draaiend script" />
</Frame>
</Step>
</Steps>

## Een figuur in uw document gebruiken {#use-a-figure-in-your-document}

Grafieken hebben geen venster om in te verschijnen, dus sla ze op in een bestand. Bijvoorbeeld:

```python
import matplotlib.pyplot as plt

plt.plot([1, 2, 3], [1, 4, 9])
plt.savefig("figure.png")
```

`figure.png` verschijnt in uw project, klaar voor `\includegraphics{figure.png}`.

<Frame caption="Een opgeslagen grafiek">
  <img src="/images/on-premises/python-runner-figure.png" alt="figure.png geopend in de editor, met de melding figure.png saved to your project" />
</Frame>

## De bestanden van uw project lezen {#read-your-project’s-files}

Een script kan de bestanden van uw project openen via hun pad:

```python
print(open("results.txt").read())
```

## Als er iets misgaat {#if-something-goes-wrong}

<strong>Het script geeft een fout.</strong> De fout verschijnt in rood in het uitvoerpaneel, na alles wat het script daarvoor heeft afgedrukt.

<Frame caption="Een fout in een script">
  <img src="/images/on-premises/python-runner-error.png" alt="Afgedrukte tekst gevolgd door een traceback in rood" />
</Frame>

<strong>`ModuleNotFoundError: No module named ...`.</strong> Alleen de pakketten die in Pyodide zijn ingebouwd zijn beschikbaar, en pakketten die met `pip` zijn geïnstalleerd kunnen niet worden gebruikt. NumPy en Matplotlib horen bij de beschikbare pakketten, en de melding linkt naar de [volledige lijst](https://pyodide.org/en/stable/usage/packages-in-pyodide.html).

<Frame caption="Een pakket dat niet beschikbaar is">

</Frame>
