Plaats een link op uw website, blog of cursuspagina. Iedereen die erop klikt, krijgt een eigen nieuw project met uw bestanden. U hoeft niets in te stellen.

Bezoekers hebben een account op uw instantie nodig. Een bezoeker die niet is ingelogd, gaat eerst naar de inlogpagina, en het project opent na het inloggen.

De pagina's van deze functie gebruiken de naam Overleaf. Uw eigen link of knop kan elke tekst bevatten, zoals **Open in Ayakaleaf**.

## De voorbeelden bekijken {#see-the-examples}

Open `/devs` op uw site, bijvoorbeeld `https://ayakaleaf.example.com/devs`. Geen enkel menu linkt naar deze pagina, dus typ het adres zelf. Standaard moet u ingelogd zijn om de pagina te zien.

## Naar een bestand op uw website linken {#link-to-a-file-on-your-website}

<Steps>
<Step title="De link opbouwen">
Zet het URL-gecodeerde adres van het bestand na `/docs?snip_uri=`:

```text
https://ayakaleaf.example.com/docs?snip_uri=https%3A%2F%2Fexample.com%2Fmain.tex
```

Gebruik voor een gezipt project `zip_uri`:

```text
https://ayakaleaf.example.com/docs?zip_uri=https%3A%2F%2Fexample.com%2Fproject.zip
```

Uw instantie downloadt het bestand, dus het moet bereikbaar zijn via HTTP of HTTPS. Adressen in een privénetwerk worden geweigerd, zie [External URL](/nl/on-premises/configuration/overleaf-toolkit/external-url).
</Step>

<Step title="Aan uw pagina toevoegen">
```html
<a href="https://ayakaleaf.example.com/docs?snip_uri=https%3A%2F%2Fexample.com%2Fmain.tex">Open in Ayakaleaf</a>
```
</Step>

<Step title="Erop klikken">
Het nieuwe project opent in de editor, met één bestand opgeslagen als `main.tex`.

<Frame caption="Een project geopend via een link">
  <img src="/images/on-premises/open-in-overleaf-project.png" alt="Het project Hello from a link in de editor, met main.tex en de PDF" />
</Frame>

Elke klik maakt een ander project. Het project is een kopie, dus latere wijzigingen in uw bestand komen er niet in terecht.
</Step>
</Steps>

## Het bestand in de link zetten {#put-the-file-in-the-link}

Voor een klein bestand hoeft u niets te hosten: zet de inhoud als Base64-data-URL in de link. In JavaScript:

```javascript
const tex = '\\documentclass{article}\n\\begin{document}\nHello from a link.\n\\end{document}\n'
const link = 'https://ayakaleaf.example.com/docs?' + new URLSearchParams({
  snip_uri: 'data:application/x-tex;base64,' + btoa(tex),
  name: 'Hello from a link',
})
```

`btoa` accepteert alleen Latin-1-tekens, dus codeer andere tekst eerst als UTF-8. Gebruik voor een gezipt project `zip_uri` en `data:application/zip;base64,`.

Een link langer dan ongeveer 8 KB wordt geweigerd met de fout **414 Request-URI Too Large**. Host voor iets groters het bestand of gebruik een [formulier](#use-a-button-instead-of-a-link).

## De opties kiezen {#choose-the-options}

Voeg deze toe aan de link, of aan het formulier als verborgen velden:

| Parameter                   | Wat het doet                                                                                                                 | Voorbeeld                                            |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| `name`                      | Geeft het project een naam. Zonder deze parameter krijgt een gezipt project de naam uit zijn `\title`, al het andere heet `Open in Overleaf project`. | `name=My%20notes`                                  |
| `engine`                    | Stelt de compiler in: `latex_dvipdf`, `pdflatex`, `xelatex` of `lualatex`.                                                      | `engine=xelatex`                                   |
| `main_document`             | Stelt het hoofdbestand `.tex` in, dat als eerste opent.                                                                                | `main_document=thesis.tex`                         |
| `snip_uri[]`, `snip_name[]` | Importeert meerdere bestanden, elk met een eigen naam, in dezelfde volgorde.                                                            | `snip_uri[]=.../a.tex&snip_name[]=a.tex`           |

Een `.tex`-bestand zonder `\documentclass` wordt in een standaarddocument verpakt, zodat het meteen compileert:

```latex
\documentclass[12pt]{article}
\usepackage[english]{babel}
\usepackage{amsmath}
\usepackage{tikz}
\begin{document}
Your file
\end{document}
```

## Een knop gebruiken in plaats van een link {#use-a-button-instead-of-a-link}

Een formulier stuurt dezelfde parameters als een link:

```html
<form action="https://ayakaleaf.example.com/docs" method="post" target="_blank">
  <input type="hidden" name="snip_uri" value="https://example.com/main.tex">
  <input type="hidden" name="engine" value="xelatex">
  <button type="submit">Open in Ayakaleaf</button>
</form>
```

Om de LaTeX zelf te versturen, gebruikt u `snip` voor platte tekst of `encoded_snip` voor tekst die door `encodeURIComponent` is gehaald.

Een formulier werkt niet altijd. Daarom is een link de betere keuze, tenzij uw bestand er te lang voor is:

| Waar het formulier staat                                     | Bezoeker is ingelogd            | Bezoeker is niet ingelogd        |
| ----------------------------------------------------- | ------------------------------- | ------------------------------- |
| Op hetzelfde domein als uw instantie, of een subdomein   | Het project opent               | Inlogpagina, geen project      |
| Op een ander domein                                     | Inlogpagina, geen project      | Inlogpagina, geen project      |

Als uw beheerder `OVERLEAF_ALLOW_PUBLIC_ACCESS=true` instelt, opent het project in al deze gevallen, zo nodig na het inloggen. Die instelling opent ook andere pagina's voor uitgelogde bezoekers, zie [Page Access](/nl/on-premises/configuration/overleaf-toolkit/authentication/public-access#page-access).

Zie [Overleaf Import API](/nl/on-premises/configuration/overleaf-toolkit/integrations/overleaf-import-api) voor wat beheerders verder kunnen instellen. De pagina `/devs` bevat meer voorbeelden.

## Als het project niet opent {#if-the-project-does-not-open}

De pagina vertelt wat er misging. **View the Overleaf API docs** brengt u naar `/devs`.

<Frame caption="Een link die de instantie niet kan gebruiken">
  <img src="/images/on-premises/open-in-overleaf-error.png" alt="De pagina Open in Overleaf met de melding invalid url en de knop View the Overleaf API docs" />
</Frame>

| Melding                                      | Waarom                                                 | Wat te doen                                  |
| -------------------------------------------- | --------------------------------------------------- | ------------------------------------------- |
| `no snippet, snip_uri or zip_uri provided`   | De link bevat geen van deze parameters                          | Controleer de parameternamen                   |
| `invalid url: ...`                           | Het adres begint niet met HTTP of HTTPS       | Gebruik een HTTP- of HTTPS-adres, of een data-URL |
| `could not download ... (HTTP 404)`          | Het bestand staat niet op dat adres                     | Controleer het adres                           |
| `could not download ... (HTTP 403)`          | Het adres ligt in een privénetwerk                 | Host het bestand waar uw instantie het mag bereiken |
| `zip_uri did not resolve to a zip archive`   | Het bestand achter `zip_uri` is geen zip-bestand         | Controleer het bestand                              |
| `invalid base64 data url`                    | De data-URL is beschadigd                             | Codeer het bestand opnieuw en URL-codeer de link |
