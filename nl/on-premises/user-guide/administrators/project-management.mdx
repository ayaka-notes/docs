## Een project vinden {#find-a-project}

Typ in **Search by project name, ID, owner or link**. Een link kan het adres van het project zijn of een van de deellinks. Gebruik het filter **Status** om de lijst te beperken. Klik op **Title** of **Last modified** om te sorteren.

Verwijderde projecten verschijnen niet in de resultaten. Als je zoekopdracht ook een verwijderd project vindt, meldt een regel boven de tabel dat, bijvoorbeeld **Found 1 matching deleted projects**. Klik op **Display deleted projects** om ze te zien.

## Projectstatus {#project-status}

Elk project heeft één status, en het filter **Status** toont hoeveel projecten elke status heeft.

<Frame caption="Het filter Status">
  <img src="/images/on-premises/project-management-status-filter.png" alt="Het filter Status met All, Active, Archived, Trashed en Deleted" />
</Frame>

| Status | Betekenis |
| --- | --- |
| **All** | Elk project dat niet is verwijderd. |
| **Active** | De normale toestand. |
| **Archived** | De eigenaar heeft het gearchiveerd. Het project is intact en kan worden teruggehaald. |
| **Trashed** | De eigenaar heeft het naar de prullenbak verplaatst. Het project is intact en kan worden teruggehaald. |
| **Deleted** | Verwijderd door de eigenaar uit de prullenbak, door een beheerder of samen met het account van de eigenaar. Alleen een beheerder kan het terughalen. |

Een project doorloopt de statussen in fasen:

1. **Active, Archived en Trashed** kiest de eigenaar op de eigen projectpagina. De eigenaar kan altijd terug. **Restore** uit de prullenbak leidt altijd naar Active, ook als het project eerder gearchiveerd was.
2. **Deleted** is de volgende fase. De eigenaar kan alleen uit de prullenbak verwijderen; een beheerder kan vanuit elk van de drie verwijderen.
3. **Restore** haalt een verwijderd project terug als **Active**, ongeacht de vorige status, en de naam krijgt `(Restored)` aan het eind. Alleen een beheerder kan dit doen. Als ook het account van de eigenaar is verwijderd, herstel dan eerst het account: anders meldt het dialoogvenster **The owner of this project is deleted: restore the owner first**.
4. **Delete permanently** is de laatste fase en kan niet ongedaan worden gemaakt. Verder blijven verwijderde projecten bestaan totdat je ze verwijdert, tenzij de instantie [`ENABLE_CRON_RESOURCE_DELETION`](/nl/on-premises/configuration/overleaf-toolkit/environment-variables) instelt, die ze na 90 dagen verwijdert.

<Info>

De status volgt alleen de eigenaar. Wanneer een medewerker een gedeeld project archiveert of naar de prullenbak verplaatst, verschuift het alleen op diens eigen projectpagina, en blijft de status hier gelijk.

</Info>

## Acties voor een project {#actions-on-a-project}

| Pictogram | Actie | Wat het doet |
| --- | --- | --- |
| Openen | **Open Project** | Opent het project in de editor, in een nieuw tabblad. |
| Map | **Change project owner** | Geeft het project aan een andere gebruiker. |
| Prullenbak | **Delete** | Verplaatst het project naar **Deleted**. |
| Pijl | **Restore** | Haalt een verwijderd project terug. Alleen voor verwijderde projecten. |
| Doorgestreepte prullenbak | **Delete permanently** | Verwijdert een verwijderd project definitief. Alleen voor verwijderde projecten. |

### De eigenaar wijzigen {#change-the-owner}

Klik op het mappictogram, typ een naam of e-mailadres, kies de gebruiker en klik op **Change project owner**. Het dialoogvenster waarschuwt dat dit niet ongedaan kan worden gemaakt en dat de nieuwe eigenaar een melding krijgt en de toegangsinstellingen van het project kan wijzigen. Uitgeschakelde accounts worden niet aangeboden. Als je de tekst wijzigt na het kiezen, wordt de keuze geannuleerd: kies de gebruiker opnieuw.

<Frame caption="De eigenaar van een project wijzigen">
  <img src="/images/on-premises/project-management-change-owner.png" alt="Het dialoogvenster Change project owner met een waarschuwing en een gekozen nieuwe eigenaar" />

Zie [De projecten van een gebruiker overdragen](/nl/on-premises/user-guide/administrators/user-management#transfer-a-users-projects) om alle projecten van een gebruiker in één keer te verplaatsen.

### Verwijderen, herstellen of definitief verwijderen {#delete-restore-or-permanently-delete}

Klik op het prullenbakpictogram en daarna op **Delete**. Kies **Deleted** in het filter **Status** om het project terug te vinden.

<Frame caption="Een verwijderd project">
  <img src="/images/on-premises/project-management-deleted.png" alt="Een verwijderd project in de lijst met de pictogrammen Restore en Delete permanently" />
</Frame>

Klik op het pijlpictogram en daarna op **Restore** om het terug te halen, of op de doorgestreepte prullenbak en daarna op **Delete permanently** om het te verwijderen.

<Frame caption="Een project definitief verwijderen">
  <img src="/images/on-premises/project-management-purge.png" alt="Het dialoogvenster Delete permanently dat waarschuwt dat de actie niet ongedaan kan worden gemaakt" />
</Frame>

### Meerdere projecten tegelijk wijzigen {#change-several-projects-at-once}

Vink de projecten in de lijst aan. Naast de zoekbalk verschijnen knoppen: **Download**, **Change project owner** en **Delete**. **Download** slaat de geselecteerde projecten op in één `.zip`-bestand. Bij **Change project owner** kunnen de huidige eigenaren van de aangevinkte projecten niet worden gekozen. In de weergave **Deleted** zijn de knoppen **Restore** en **Delete permanently**.

<Frame caption="Bulkacties">
  <img src="/images/on-premises/project-management-bulk.png" alt="Twee aangevinkte projecten en de knoppen Download, Change project owner en Delete" />
</Frame>

## De projectpagina {#the-project-page}

Klik op de titel van een project om de pagina te openen. Bovenaan staan de pictogrammen om het project te bewerken, openen, downloaden en verwijderen. De pagina heeft vijf tabbladen.

### Overzicht {#overview}

De gegevens en instellingen van het project. Klik op het potloodpictogram om **Name**, **Link sharing**, **Compiler**, **TeX Live version** en **Main document** te wijzigen, of om op **Change project owner** te klikken. Klik daarna op **Save**.

<Frame caption="Een project bewerken">
  <img src="/images/on-premises/project-management-edit.png" alt="Het tabblad Overview in bewerkingsmodus" />
</Frame>

### Bestandsstructuur {#file-tree}

De bestanden en mappen van het project, alleen-lezen.

<Frame caption="De bestanden van een project">
  <img src="/images/on-premises/project-management-files.png" alt="Het tabblad File tree met frog.jpg, main.tex en een hersteld bib-bestand" />
</Frame>

### Leden {#members}

Wie toegang heeft: de eigenaar, de medewerkers en de openstaande uitnodigingen. Klik op het potloodpictogram om ze te wijzigen:

* Kies **Editor**, **Reviewer** of **Viewer** voor een medewerker. De wijziging geldt direct.
* Klik op de prullenbak naast een medewerker en daarna op **Remove access**.
* Klik bij een openstaande uitnodiging op de envelop voor **Resend invite**, of op de prullenbak voor **Revoke Invite**.

Klik op **Done** als je klaar bent. De eigenaar kan hier niet worden gewijzigd: gebruik **Change project owner** op het tabblad **Overview**.

<Frame caption="De leden van een project wijzigen">
  <img src="/images/on-premises/project-management-members.png" alt="Het tabblad Members in bewerkingsmodus met een rolmenu, een openstaande uitnodiging en de actiepictogrammen" />
</Frame>

### Verwijderde bestanden {#deleted-files}

Bestanden die uit het project zijn verwijderd. Klik op het pijlpictogram naast een bestand en daarna op **Restore file**. Een kopie met de datum in de naam komt in de hoofdmap van het project, en de rij toont de naam. Het verwijderde bestand blijft in de lijst staan.

De kopie verschijnt op het tabblad **File tree** nadat je de pagina opnieuw hebt geladen.

</Frame>
