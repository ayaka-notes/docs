Overleaf draait op Docker. Je moet het volgende installeren:

* Docker Engine (Docker CE)
* Docker Compose-plugin (`docker compose`, v2)

Deze stappen zijn bedoeld voor een recente Ubuntu LTS (20.04/22.04/24.04).

<Warning>

Installeer `docker.io` niet uit de standaard apt-repository van Ubuntu.\
Gebruik de officiële repository van Docker, zodat je een recente Docker-versie en de `docker compose`-plugin krijgt.

</Warning>

De officiële documentatie is te vinden op: [https://docs.docker.com/engine/install/ubuntu/](https://docs.docker.com/engine/install/ubuntu/).

<Steps>
<Step title="1) Oude/conflicterende pakketten verwijderen (indien aanwezig)">
Als Docker eerder vanuit een andere bron is geïnstalleerd, verwijder het dan eerst:

```bash wrap
sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-compose-v2 docker-doc podman-docker containerd runc | cut -f1)
```

Dit commando is veilig, ook als sommige pakketten niet zijn geïnstalleerd.
</Step>

<Step title="2) De officiële apt-repository van Docker toevoegen">
Installeer de vereisten:

```bash
sudo apt update
sudo apt install -y ca-certificates curl
```

Voeg de GPG-sleutel van Docker toe:

```bash wrap
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```

Voeg de repository toe:

```bash wrap
# Add the repository to Apt sources:
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Signed-By: /etc/apt/keyrings/docker.asc
EOF

sudo apt update
```
</Step>

<Step title="3) Docker Engine + Compose-plugin installeren">
Installeer Docker en de Compose-plugin:

```bash wrap
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

Start Docker automatisch bij het opstarten:

```bash
sudo systemctl enable --now docker
```
</Step>

<Step title="4) De installatie controleren">
Deze commando's zouden zonder fouten moeten worden uitgevoerd:

```bash
docker --version
docker compose version
sudo docker run --rm hello-world
docker ps
```
</Step>

<Step title="5) (Optioneel) Docker zonder sudo uitvoeren">
Voeg je gebruiker toe aan de groep `docker`:

```bash
sudo usermod -aG docker $USER
```

**Log daarna uit en weer in**, of voer het volgende uit:

```bash
newgrp docker
```

Nu zou dit zonder `sudo` moeten werken:

```bash
docker ps
```

<Danger>

De groep `docker` heeft toegang op root-niveau tot de host.\
Dit is gebruikelijk bij typische Overleaf-installaties, en vooral relevant als je Sandboxed Compiles inschakelt.

</Danger>
</Step>
</Steps>

### Volgende stap

Zodra Docker werkt, ga je verder met de installatiestappen van de Toolkit in [De Toolkit gebruiken](/nl/on-premises/installation/using-the-toolkit).
