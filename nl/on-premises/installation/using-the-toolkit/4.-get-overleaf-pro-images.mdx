---
title: 4. Ayakaleaf Pro-images ophalen
icon: split
---

Ayakaleaf Pro is een gratis Docker-image op [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Je hebt geen account of login nodig om de image op te halen. Images worden gebouwd voor amd64 en arm64, en Docker kiest automatisch de image die bij je server past.

Open `config/overleaf.rc` en stel in:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

De volgende keer dat je `bin/up` uitvoert, downloadt de Toolkit de Ayakaleaf Pro-image en gebruikt deze in plaats van de officiële Overleaf Community Edition. Je instellingen in `config/` blijven werken.

<Accordion title="Gebruik je al de officiële Overleaf Toolkit (overleaf/toolkit)?">

Je hoeft niet opnieuw te installeren. Haal de Ayakaleaf Pro-image op:

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Voeg vervolgens een bestand met de naam `docker-compose.override.yml` met de volgende inhoud toe aan de map `overleaf-toolkit/config`:

```yml
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

De volgende keer dat je `bin/up` uitvoert, gebruikt de Toolkit de Ayakaleaf Pro-image.

</Accordion>
