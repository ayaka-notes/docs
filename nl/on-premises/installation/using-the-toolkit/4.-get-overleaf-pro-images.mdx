---
title: 4. Ayakaleaf Pro-images ophalen
icon: split
---

Ayakaleaf Pro wordt verspreid als Docker-image via de [ghcr](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/)-registry, met **open toegang** voor iedereen. We bieden images voor zowel amd64- als arm64-architecturen. Wanneer je de image ophaalt, wordt automatisch de juiste image geselecteerd op basis van je systeemarchitectuur.

#### Gebruikers van de Ayaka-notes Toolkit

Als je [ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) gebruikt, kan Ayakaleaf Pro worden gebruikt als directe vervanging voor de Community Edition, zodat je je bestaande instellingen en aanpassingen kunt blijven gebruiken. Schakel Pro in de Toolkit in door `config/overleaf.rc` te bewerken en de omgevingsvariabele `SERVER_PRO` in te stellen:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

De volgende keer dat je `bin/up` uitvoert, downloadt en gebruikt de Toolkit automatisch de Ayakaleaf Pro-image.

#### Gebruikers van de officiële Toolkit

Als je [overleaf/toolkit](https://github.com/overleaf/toolkit) gebruikt, voer dan de volgende opdracht uit om een Pro-image op te halen:

```bash title="Pull Docker Images"
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Voeg vervolgens een bestand met de naam `docker-compose.override.yml` met de volgende inhoud toe aan de map `overleaf-toolkit/config`:

```yml title="docker-compose.override.yml"
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

De volgende keer dat je `bin/up` uitvoert, downloadt en gebruikt de Toolkit automatisch de Ayakaleaf Pro-image.
