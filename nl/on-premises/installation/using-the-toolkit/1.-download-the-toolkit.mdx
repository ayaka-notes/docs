### De Toolkit downloaden

De Toolkit is compatibel met zowel Server CE als Ayakaleaf Pro en is de aanbevolen installatiemethode. Met de Toolkit kun je eenvoudig aan de slag met Server CE en indien nodig naadloos upgraden naar Ayakaleaf Pro.

<Info>

[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) is aangepast om de overleaf-pro-image rechtstreeks van ghcr te gebruiken, met TeX Live geleverd door ayaka-notes. Je kunt ook de officiële overleaf-toolkit downloaden.

</Info>

<Steps>
<Step title="De Overleaf Toolkit-repository klonen">
Om de toolkit te installeren, navigeer je naar het gewenste installatiepad en kloon je vervolgens de GitHub-repository van de Overleaf Toolkit (@Ayaka-notes) met deze opdracht:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
# official toolkit (Not Recommended)
# git clone https://github.com/overleaf/toolkit.git ./overleaf-toolkit
```

<Info>

Om mogelijke problemen met rechten te voorkomen, raden we aan de Toolkit te installeren in de `$HOME`-map van je gebruiker.

</Info>
</Step>

<Step title="Naar de toolkit-map gaan">
Wacht tot het klonen is voltooid en ga dan naar de zojuist aangemaakte map `overleaf-toolkit`:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
