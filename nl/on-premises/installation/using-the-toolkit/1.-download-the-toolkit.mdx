### De Toolkit downloaden

Je installeert Ayakaleaf Pro met de **Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)), een set scripts die Overleaf voor je in Docker draait.

Standaard start de Toolkit de gratis officiële Overleaf Community Edition (CE). Met [4. Ayakaleaf Pro-images ophalen](/nl/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images) schakel je met één instelling over naar Ayakaleaf Pro.

<Accordion title="Gebruik je al de officiële Overleaf Toolkit (overleaf/toolkit)?">

Je hoeft niet opnieuw te installeren. Behoud je installatie en volg het laatste deel van [4. Ayakaleaf Pro-images ophalen](/nl/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images).

</Accordion>

<Steps>
<Step title="De Ayakaleaf Toolkit-repository klonen">
Om de toolkit te installeren, navigeer je naar het gewenste installatiepad en kloon je vervolgens de repository van de Ayakaleaf Toolkit met deze opdracht:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
```

<Info>

Om mogelijke problemen met rechten te voorkomen, raden we aan de Toolkit te installeren in de `$HOME`-map van je gebruiker.

</Info>
</Step>

<Step title="Naar de toolkit-map gaan">
Wacht tot het klonen is voltooid en ga dan naar de zojuist aangemaakte map `overleaf-toolkit`:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
