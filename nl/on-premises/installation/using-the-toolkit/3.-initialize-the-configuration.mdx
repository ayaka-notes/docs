### De configuratie initialiseren

Laten we de configuratiebestanden van onze nieuwe server initialiseren met enkele verstandige standaardwaarden door het meegeleverde script `bin/init` uit te voeren.

```text title="Run initialization"
bin/init
```

Dit script overschrijft **geen** bestaande configuratiebestanden.

Laten we nu de inhoud van de map `config/` bekijken met het commando `ls`:

```text title="List the config directory"
ls config
```

Als alles met succes is geïnitialiseerd, zou je drie configuratiebestanden moeten zien: `overleaf.rc`, `variables.env` en `version`. Dit zijn de belangrijkste configuratiebestanden van de server, waarmee je kunt aanpassen hoe je server werkt en hoe je gebruikers met je instantie omgaan.

| Naam            | Beschrijving                                            |
| --------------- | ------------------------------------------------------- |
| `overleaf.rc`   | Het belangrijkste configuratiebestand op topniveau.     |
| `variables.env` | Omgevingsvariabelen die in de Docker-container worden geladen. |
| `version`       | De versie van de Docker-image die moet worden gebruikt. |

<Info>

Voor nu is het voldoende om te weten dat deze bestanden bestaan en waar je ze kunt vinden. Verderop in de documentatie bespreken we elk bestand in meer detail en leggen we uit hoe je je instantie ermee kunt aanpassen. Als je alvast vooruit wilt kijken, vind je een volledig overzicht van deze configuratiebestanden op de [pagina Bestanden en locaties](/nl/on-premises/configuration/overleaf-toolkit/files-and-locations).

</Info>
