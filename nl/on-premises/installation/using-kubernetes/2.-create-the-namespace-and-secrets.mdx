---
title: 2. De namespace en secrets aanmaken
description: Maak de namespace en de secrets aan die Ayakaleaf Pro nodig heeft.
icon: key
---

Alles komt in de namespace `overleaf`:

```bash
kubectl create namespace overleaf
```

Ayakaleaf Pro leest zijn secrets uit omgevingsvariabelen. Genereer ze één keer en bewaar ze in een Secret:

```bash wrap
HISTORY=$(openssl rand -hex 32)
kubectl -n overleaf create secret generic overleaf-secrets \
  --from-literal=OVERLEAF_INVITE_TOKEN_SECRET="$(openssl rand -base64 32)" \
  --from-literal=OVERLEAF_SESSION_SECRET="$(openssl rand -hex 32)" \
  --from-literal=WEB_API_PASSWORD="$(openssl rand -hex 32)" \
  --from-literal=STAGING_PASSWORD="$HISTORY" \
  --from-literal=V1_HISTORY_PASSWORD="$HISTORY" \
  --from-literal=CRYPTO_RANDOM="$(openssl rand -hex 32)" \
  --from-literal=OT_JWT_AUTH_KEY="$(openssl rand -hex 32)"
```

| Secret                                         | Waarom                                                                                                                                               |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_INVITE_TOKEN_SECRET`                 | Vereist. Zonder deze secret stopt de pod met "Missing required secrets". Als je deze wijzigt, worden openstaande projectuitnodigingen ongeldig.       |
| `OVERLEAF_SESSION_SECRET`                      | Ondertekent de sessiecookies. Zonder deze secret wordt iedereen bij elke herstart van de pod uitgelogd.                                              |
| `WEB_API_PASSWORD`, `CRYPTO_RANDOM`, `OT_JWT_AUTH_KEY` | Interne secrets. De container genereert ze bij elke start wanneer ze ontbreken; met meer dan één replica moeten alle replica's ze delen.     |
| `STAGING_PASSWORD` en `V1_HISTORY_PASSWORD`    | Interne geschiedenissecret; beide moeten **dezelfde** waarde hebben.                                                                                 |

<Warning>

Maak samen met je gegevens een back-up van de Secret (`kubectl -n overleaf get secret overleaf-secrets -o yaml`). Functies die tokens in MongoDB versleutelen, hebben ook hun eigen versleutelingswachtwoorden in deze Secret nodig, bijvoorbeeld `GITHUB_TOKEN_CIPHER_PASSWORD` voor [GitHub-synchronisatie](/nl/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation).

</Warning>
