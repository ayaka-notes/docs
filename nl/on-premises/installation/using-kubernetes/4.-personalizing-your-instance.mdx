---
title: 4. Je instantie personaliseren
description: Zet je instellingen in de ConfigMap die config/variables.env vervangt.
icon: square-sliders
---

De ConfigMap `overleaf-env` neemt de plaats in van `config/variables.env` van de Toolkit: elke omgevingsvariabele uit de [Toolkit-documentatie](/nl/on-premises/configuration/overleaf-toolkit/environment-variables) komt hier, en secrets gaan in de Secret uit [stap 2](/nl/on-premises/installation/using-kubernetes/2.-create-the-namespace-and-secrets).

```yaml title="30-config.yaml" wrap
apiVersion: v1
kind: ConfigMap
metadata:
  name: overleaf-env
  namespace: overleaf
data:
  OVERLEAF_APP_NAME: Ayakaleaf Pro
  OVERLEAF_SITE_URL: http://192.0.2.10:30080      # the address users open; https://... behind TLS
  OVERLEAF_ADMIN_EMAIL: admin@example.com
  # Emails: add the sender and the SMTP server together, see Email delivery
  # All members, so that the driver finds the primary even when mongo-0 is down
  OVERLEAF_MONGO_URL: mongodb://mongo-0.mongo:27017,mongo-1.mongo:27017,mongo-2.mongo:27017/sharelatex?replicaSet=overleaf
  OVERLEAF_REDIS_HOST: redis
  REDIS_HOST: redis
  ENABLED_LINKED_FILE_TYPES: project_file,project_output_file,url
  ENABLE_CONVERSIONS: "true"
  EMAIL_CONFIRMATION_DISABLED: "true"
  # Requests arrive from kube-proxy or your ingress controller, inside the pod network
  OVERLEAF_TRUSTED_PROXY_IPS: loopback,10.244.0.0/16
  # Sandboxed compiles. The HOST_DIR paths are paths ON THE NODE: the hostPath volumes that
  # the Deployment mounts at /var/lib/overleaf/data/{compiles,output,cache}.
  SANDBOXED_COMPILES: "true"
  SANDBOXED_COMPILES_SIBLING_CONTAINERS: "true"
  DOCKER_RUNNER: "true"
  SANDBOXED_COMPILES_HOST_DIR_COMPILES: /srv/overleaf/compiles
  SANDBOXED_COMPILES_HOST_DIR_OUTPUT: /srv/overleaf/output
  SANDBOXED_COMPILES_HOST_DIR_CACHE: /srv/overleaf/cache
  # Each image must be pulled into Docker on every node that can run Ayakaleaf Pro (step 0)
  ALL_TEX_LIVE_DOCKER_IMAGES: ghcr.io/ayaka-notes/texlive-full:2026.1
  ALL_TEX_LIVE_DOCKER_IMAGE_NAMES: TeX Live 2026
  TEX_LIVE_DOCKER_IMAGE: ghcr.io/ayaka-notes/texlive-full:2026.1
```

```bash
kubectl apply -f 30-config.yaml
```

| Variabele                               | Stel in op                                                                                                                                                      |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_SITE_URL`                     | De URL die gebruikers in de browser intypen. Met de NodePort uit [stap 5](/nl/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro): het IP-adres van een willekeurige node en poort `30080`; achter een ingress of load balancer: de URL daarvan. |
| `OVERLEAF_MONGO_URL`                    | Je replicaset. Gebruik `?replicaSet=` met de naam uit `rs.initiate`.                                                                                            |
| `OVERLEAF_REDIS_HOST` en `REDIS_HOST`   | Beide naar de Redis-Service.                                                                                                                                    |
| `OVERLEAF_TRUSTED_PROXY_IPS`            | `loopback` plus de netwerken waarvandaan je proxy's verbinding maken. `10.244.0.0/16` is het podnetwerk van flannel; gebruik de pod-CIDR van je cluster.         |
| `SANDBOXED_COMPILES_HOST_DIR_*`         | De nodepaden van de compilevolumes. Ze moeten overeenkomen met de `hostPath`-volumes in [stap 5](/nl/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro). |

Stel achter HTTPS ook `OVERLEAF_SECURE_COOKIE: "true"` in, zie [TLS-proxy](/nl/on-premises/configuration/overleaf-toolkit/tls-proxy).

<Info>

Een gewijzigde ConfigMap bereikt draaiende pods pas na een herstart: `kubectl -n overleaf rollout restart deployment/overleaf`.

</Info>
