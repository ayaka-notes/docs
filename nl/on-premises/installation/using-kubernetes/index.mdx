De [Toolkit](/nl/on-premises/installation/using-the-toolkit) is de aanbevolen manier om Ayakaleaf Pro op één server te draaien. Als je al een Kubernetes-cluster draait, deployt deze sectie dezelfde container daarop met gewone `kubectl`-manifests: geen extra image, geen Helm-chart.

Aan het einde van deze sectie heb je één Ayakaleaf Pro-instantie met sandboxed compiles, een MongoDB-replicaset en Redis, allemaal in de namespace `overleaf`. Om daarna meerdere instanties achter een load balancer te draaien, ga je verder met [Horizontaal schalen](/nl/on-premises/configuration/kubernetes/horizontal-scaling).

<Info>

Ondersteuning voor Kubernetes is experimenteel. We publiceren geen Helm-chart of Kubernetes-specifieke images. De manifests op deze pagina's zijn de manifests die we hebben getest op Kubernetes 1.37 (kubeadm, containerd 2.4, flannel) met drie nodes van elk 2 vCPU's en 4 GB geheugen. Pas opslag, netwerk en ingress aan je cluster aan.

</Info>

### Hoe de onderdelen samenhangen

| Toolkit (één server)                         | Kubernetes                                                               |
| -------------------------------------------- | ------------------------------------------------------------------------ |
| `config/variables.env`                       | ConfigMap `overleaf-env` en Secret `overleaf-secrets`                    |
| container `sharelatex`                       | Deployment `overleaf` (één pod die alle Overleaf-services draait)        |
| containers `mongo` en `redis`                | StatefulSets `mongo` (replicaset) en `redis`, of je beheerde diensten    |
| `~/overleaf-toolkit/data/overleaf`           | PersistentVolumeClaim `overleaf-data`                                    |
| Docker op de host, gebruikt voor compilaties | Docker Engine op elke node die Ayakaleaf Pro draait                      |
| `bin/up`, `bin/logs`, `bin/shell`            | `kubectl apply`, `kubectl logs`, `kubectl exec`                          |

### Wat je nodig hebt

* Een Kubernetes-cluster waarop je pakketten kunt installeren: elke node die Ayakaleaf Pro kan draaien, heeft **Docker Engine** nodig, omdat compilaties draaien in TeX Live-containers die Ayakaleaf Pro start via de `/var/run/docker.sock` van de node. Zie [0. De nodes voorbereiden](/nl/on-premises/installation/using-kubernetes/0.-prepare-the-nodes).
* Een standaard-StorageClass met `ReadWriteOnce`-volumes.
* `kubectl` en `openssl` op je werkstation.
