### Je eerste beheerdersaccount aanmaken

Open `OVERLEAF_SITE_URL` gevolgd door `/launchpad`, bijvoorbeeld `http://192.0.2.10:30080/launchpad`, en registreer het beheerdersaccount zoals in de [taken na de installatie van de Toolkit](/nl/on-premises/installation/using-the-toolkit/6.-post-installation-tasks). Maak daarna een voorbeeldproject aan en compileer het.

Je kunt ook gebruikers aanmaken vanaf de opdrachtregel:

```bash
kubectl -n overleaf exec deploy/overleaf -- bash -c \
  'cd /overleaf/services/web && node modules/server-ce-scripts/scripts/create-user.mjs --admin --email=admin@example.com'
```

Dit toont een link waarmee het wachtwoord wordt ingesteld.

### Controleren of compilaties in een sandbox draaien

Compileer een project en kijk daarna op de node waarop de pod draait:

```bash
kubectl -n overleaf get pod -l app=overleaf -o wide   # NODE column
# on that node:
sudo docker ps -a --filter ancestor=ghcr.io/ayaka-notes/texlive-full:2026.1
ls -ln /srv/overleaf/compiles                          # owned by uid 33 (www-data)
```

Elke compilatie verschijnt als een kortlevende container met de naam `project-<project id>-<user id>-...`.

### Logs en een shell

| Toolkit          | Kubernetes                                                               |
| ---------------- | ------------------------------------------------------------------------ |
| `bin/logs web`   | `kubectl -n overleaf exec deploy/overleaf -- tail -f /var/log/overleaf/web.log` |
| `bin/shell`      | `kubectl -n overleaf exec -it deploy/overleaf -- bash`                    |
| `bin/up`         | `kubectl apply -f .` en daarna `kubectl -n overleaf rollout restart deployment/overleaf` |

De container schrijft per service één logbestand in `/var/log/overleaf/` (`web.log`, `clsi.log`, `real-time.log`, `document-updater.log`, ...); `kubectl logs` toont de opstartuitvoer.

### Q\&A

<Accordion title="De compilatie mislukt of wordt nooit voltooid.">

<strong>Antwoord:</strong> Controleer op de node waarop de pod draait of Docker actief is en de image heeft die in `TEX_LIVE_DOCKER_IMAGE` wordt genoemd, en of `SANDBOXED_COMPILES_HOST_DIR_*` overeenkomen met de `hostPath`-paden. `/var/log/overleaf/clsi.log` in de pod noemt de stap die mislukt.

</Accordion>

<Accordion title="Gebruikers worden na elke herstart van de pod uitgelogd.">

<strong>Antwoord:</strong> `OVERLEAF_SESSION_SECRET` ontbreekt in de Secret `overleaf-secrets`, zie [stap 2](/nl/on-premises/installation/using-kubernetes/2.-create-the-namespace-and-secrets).

</Accordion>
