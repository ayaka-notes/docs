---
title: 1. De Toolkit downloaden en initialiseren
description: Kloon de Ayakaleaf Toolkit, maak de configuratie aan en stel die in voor Ayakaleaf Pro op Podman.
icon: arrow-down-to-bracket
---

<Steps>
<Step title="De Toolkit klonen">
Kloon de **Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)) in je thuismap en ga erin:

```bash title="Clone the Toolkit" wrap
git clone https://github.com/ayaka-notes/toolkit.git ~/overleaf-toolkit
cd ~/overleaf-toolkit
```

Voer alle volgende commando's uit vanuit deze map.
</Step>

<Step title="De configuratie aanmaken">
```bash title="Run initialization"
bin/init
```

Dit maakt `config/overleaf.rc`, `config/variables.env` en `config/version` aan, zoals beschreven in [3. De configuratie initialiseren](/nl/on-premises/installation/using-docker-compose/linux/3.-initialize-the-configuration) van de Docker-handleiding. `bin/init` heeft Podman nog niet nodig.
</Step>

<Step title="config/overleaf.rc instellen">
Open `config/overleaf.rc` en wijzig deze regels:

```bash title="config/overleaf.rc"
SERVER_PRO=true
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
```

Voeg daarna deze regel toe aan het einde van het bestand:

```bash title="config/overleaf.rc"
SELINUX_MODE=managed
```

| Instelling                        | Waarom                                                                                                                                                                                                       |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `SERVER_PRO=true`                 | Gebruikt de Ayakaleaf Pro-image van `ghcr.io`. Inloggen is niet nodig.                                                                                                                                        |
| `OVERLEAF_PORT=8080`              | Rootless Podman kan niet luisteren op poorten onder `1024`. De standaardpoort `80` mislukt.                                                                                                                   |
| `SIBLING_CONTAINERS_ENABLED=true` | Draait elke compilatie in een eigen TeX Live-container. Staat standaard al op `true`; de Podman-setup ondersteunt alleen deze modus.                                                                          |
| `SELINUX_MODE=managed`            | Draait de container `sharelatex` met het SELinux-type `sharelatex_t`, dat de Podman-socket mag gebruiken en verder niets. `bin/podman-setup --apply` installeert er de beleidsmodule voor. Zie [Toolkit-instellingen](/nl/on-premises/configuration/overleaf-toolkit/toolkit-settings) voor de andere modi. |

Laat `DOCKER_SOCKET_PATH` zoals het is: `bin/podman-setup --apply` stelt het in de volgende stap in op je Podman-socket.

<Warning>

Laat `GIT_BRIDGE_ENABLED=false` staan. In Ayakaleaf Pro 6.3.4 werkt de Git-integratie niet op Podman, zie [Bekende beperkingen](/nl/on-premises/installation/using-podman#known-limitations).

</Warning>
</Step>

<Step title="De TeX Live-images kiezen">
Open `config/variables.env`, verwijder de `#` voor `TEX_LIVE_DOCKER_IMAGE` en `ALL_TEX_LIVE_DOCKER_IMAGES`, en geef de TeX Live-images op die je wilt gebruiken:

```bash title="config/variables.env" wrap
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
```

`bin/up` stopt met `Please configure ALL_TEX_LIVE_DOCKER_IMAGES` als de lijst leeg is. `texlive-full` is groot; voor een testserver werkt ook de veel kleinere `ghcr.io/ayaka-notes/texlive-basic:2026.1`. Zie [Sandboxed Compiles](/nl/on-premises/configuration/overleaf-toolkit/sandboxed-compiles) voor de beschikbare images.

Stel de andere variabelen in, zoals `OVERLEAF_SITE_URL`, zoals beschreven in [5. Uw instantie personaliseren](/nl/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance#required-environment-variables). Gebruik met het standaard luisteradres `http://localhost:8080`.
</Step>
</Steps>
