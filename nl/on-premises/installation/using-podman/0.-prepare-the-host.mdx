title: 0. De host voorbereiden
description: Controleer het besturingssysteem en SELinux en installeer git voordat je rootless Podman instelt.

Je installeert Podman niet met de hand: [2. podman-setup uitvoeren](/nl/on-premises/installation/using-podman/2.-run-podman-setup) installeert het samen met de andere pakketten die het nodig heeft. Hier controleer je alleen de host en installeer je `git`, dat je nodig hebt om de Toolkit te downloaden.

<Steps>
<Step title="Het besturingssysteem en SELinux controleren">
Log in als de gebruiker die Ayakaleaf Pro gaat draaien, niet als `root`, en controleer de distributie en de SELinux-modus:

```bash title="Check the host"
grep PRETTY_NAME /etc/os-release
getenforce
```

Je zou RHEL, Rocky Linux, AlmaLinux of CentOS Stream met versie 9 of later moeten zien, en `Enforcing`:

```text
PRETTY_NAME="Rocky Linux 9.9 (Blue Onyx)"
Enforcing
```
</Step>

<Step title="Controleren of je sudo kunt gebruiken">
`bin/podman-setup --apply` installeert pakketten en laadt een SELinux-module met `sudo`, en vraagt om je wachtwoord wanneer dat nodig is:

```bash title="Check sudo"
sudo -v
```

Als dit mislukt, vraag dan je beheerder om je gebruiker toe te voegen aan de groep `wheel`.
</Step>

<Step title="git installeren">
```bash title="Install git"
sudo dnf install -y git
```

<Warning>

Installeer geen Docker Engine op deze host. Het pakket `podman-docker`, dat `bin/podman-setup` installeert, levert het commando `docker`, en de Toolkit behandelt de host als Podman zodra het commando `podman` bestaat.

</Warning>
</Step>
</Steps>
