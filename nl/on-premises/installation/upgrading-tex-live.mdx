<Danger>

De volgende instructies zijn **alleen** van toepassing op installaties van de **Community Edition**. We raden gebruikers van Ayakaleaf Pro sterk aan [Sandboxed Compiles](/nl/on-premises/configuration/overleaf-toolkit/sandboxed-compiles) in te schakelen, omdat gebruikers dan toegang krijgen tot vrijwel dezelfde TeX Live-images als op [overleaf.com](https://www.overleaf.com) en compilaties van projecten van elkaar worden geïsoleerd voor betere beveiliging.

</Danger>

Om bandbreedte te besparen, bevatten zowel de Overleaf Community Edition- als de Ayakaleaf Pro-images slechts een minimale installatie van [TeX Live](https://www.tug.org/texlive/). Je kunt meer pakketten installeren of upgraden naar een volledige TeX Live-installatie met de opdracht [tlmgr](https://www.tug.org/texlive/tlmgr.html) in de container `sharelatex`.

#### Toegang krijgen tot de sharelatex-container

Voer het volgende uit om een shell te starten in de container `sharelatex`:

```bash
bin/shell
```

Je krijgt dan een prompt die er zo uitziet:

```bash
root@309b192d4030:/#
```

In de volgende instructies gaan we ervan uit dat je je in de container bevindt.

#### Je huidige TeX Live-versie bepalen

TeX Live wordt elk jaar rond april uitgebracht. De stappen voor het gebruik van `tlmgr` verschillen afhankelijk van of je de huidige of een oudere release gebruikt. Met `tlmgr --version` kun je controleren welke versie van TeX Live je gebruikt. Deze installatie draait bijvoorbeeld TeX Live 2021:

```bash
# tlmgr --version
tlmgr revision 59291 (2021-05-21 05:14:40 +0200)
tlmgr using installation: /usr/local/texlive/2021
TeX Live (https://tug.org/texlive) version 2021
```

<Info>

De huidige release van TeX Live vind je op [de homepage van TeX Live](https://www.tug.org/texlive/).

</Info>

Als je een oudere TeX Live-versie gebruikt, heb je twee opties. Een nieuwe versie van de Overleaf Docker-image verschijnt meestal kort na een TeX Live-release. Je kunt daarop wachten en je implementatie upgraden met het script `bin/upgrade`, of, als je liever de oudere TeX Live-release behoudt, moet je `tlmgr` eerst opdragen een historische repository te gebruiken. Instructies daarvoor vind je [hier](https://www.tug.org/texlive/acquire.html#past).

#### Pakketten installeren

Voer deze opdracht uit in de container `sharelatex` om een volledige TeX Live-installatie te installeren:

```text
tlmgr install scheme-full
```

Je kunt ook afzonderlijke pakketten handmatig installeren:

```bash
tlmgr install tikzlings tikzmarmots tikzducks
```

<Warning>

Vanaf release `3.3.0` is het uitvoeren van `tlmgr path add` na elk gebruik van `tlmgr install` weer **vereist**, zodat alle binaire bestanden correct via symlinks in het systeempad worden opgenomen.

</Warning>

Er zijn nog veel meer opdrachten beschikbaar. Meer informatie vind je met:

```text
tlmgr help
```

Als je klaar bent, typ je `exit` of druk je op Control-D om de shell af te sluiten.

#### Je wijzigingen opslaan

De wijzigingen die je zojuist hebt aangebracht, hebben de container `sharelatex` gewijzigd, maar ze zijn tijdelijk: ze gaan verloren als Docker Compose de container opnieuw aanmaakt, bijvoorbeeld bij het bijwerken van de configuratie.

Gebruik `docker commit` om ze persistent te maken en de wijzigingen op te slaan in een nieuwe Docker-image:

```bash
cat config/version #5.2.1
docker commit sharelatex sharelatex/sharelatex:5.2.1-with-texlive-full
echo 5.2.1-with-texlive-full > config/version
```

Werk na het committen van de wijzigingen `config/version` dienovereenkomstig bij. Voer vervolgens `bin/up` uit om de container `sharelatex` opnieuw aan te maken.

<Danger>

Je moet deze stappen herhalen elke keer dat je [upgradet](https://github.com/overleaf/toolkit/blob/master/doc/upgrading.md) naar een nieuwe versie van Overleaf.

</Danger>
