Gebruik Claude Code of Codex om een deployment van Ayakaleaf Pro te plannen en uit te voeren. De agent kan tijdens het werk via MCP in deze documentatie zoeken.

De agent helpt bij de deployment. Jij blijft verantwoordelijk voor het controleren van opdrachten en het beschermen van inloggegevens.

### Voordat je begint

Zorg voor een ondersteunde Linux-server met SSH-toegang. Bekijk de [vereisten](/nl/on-premises/getting-started/requirements  "mention") voordat je verdergaat.

<Warning>

Plak geen wachtwoorden, privésleutels, tokens of licentiesleutels in prompts voor de agent. Controleer elke opdracht voordat je deze uitvoert, vooral opdrachten die bestanden, netwerken of containers wijzigen.

</Warning>

### De documentatie verbinden

Voeg het MCP-endpoint van de documentatie toe aan je lokale agent.

<Tabs>
<Tab title="Claude Code">

```bash wrap
claude mcp add ayakaleaf-pro --scope user --transport http https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>

<Tab title="Codex">

```bash wrap
codex mcp add ayakaleaf-pro --url https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>
</Tabs>

Start een nieuwe sessie nadat je de server hebt toegevoegd. Vraag de agent te bevestigen dat hij in de documentatie van Ayakaleaf Pro kan zoeken.

### Ayakaleaf Pro deployen

Open een terminal op je deploymentserver. Start daar Claude Code of Codex. Stuur vervolgens deze prompt:

```text wrap
Use the Ayakaleaf Pro documentation MCP server to guide this deployment.
First, inspect the requirements and installation guides.
Ask me for missing deployment details before making changes.
Use the Ayakaleaf Toolkit unless the documentation requires another approach.
Before configuring the instance, summarize relevant optional features.
Ask which features and integrations I want to enable.
Include TLS, sandboxed compiles, Git integration, external MongoDB or Redis,
SSO (OIDC, SAML, or LDAP), GitHub Synchronisation, Zotero, S3 storage,
email delivery, branding, and localization when relevant.
Explain each selected option's prerequisites, security impact, and configuration steps.
Keep unselected optional features disabled.
Show each command before running it.
Do not expose, store, or request secrets in chat.
After deployment, verify that the service is healthy and summarize the changes.
```

De agent zou je moeten begeleiden bij de Docker-installatie, de configuratie van de Toolkit, het ophalen van images en het opstarten. Volg de handleiding [using-the-toolkit](/nl/on-premises/installation/using-the-toolkit  "mention") voor de standaardwerkwijze.

### Optionele functies kiezen

Vraag de agent alleen functies aan te bevelen die bij je omgeving passen. Gebruikelijke keuzes zijn:

* <strong>Toegang en beveiliging:</strong> TLS, sandboxed compiles en SSO via OIDC, SAML of LDAP.
* <strong>Externe services:</strong> MongoDB, Redis, S3-opslag en e-mailbezorging.
* <strong>Samenwerking:</strong> Git-integratie, GitHub Synchronisation en Zotero.

De agent moet afhankelijkheden uitleggen voordat hij de configuratie bewerkt. Bekijk [toolkit-settings.md](/nl/on-premises/configuration/overleaf-toolkit/toolkit-settings  "mention") en [authentication](/nl/on-premises/configuration/overleaf-toolkit/authentication  "mention") voordat je integraties in productie inschakelt.

### De deployment verifiëren

Nadat de agent de stappen heeft voltooid:

1. Controleer of elke opdracht zonder fouten is voltooid.
2. Open de geconfigureerde Ayakaleaf Pro-URL in je browser.
3. Voer de [6.-post-installation-tasks.md](/nl/on-premises/installation/using-the-toolkit/6.-post-installation-tasks  "mention") uit.

Gebruik voor een bestaande Community Edition-installatie de handleiding [migrate-from-existing.md](/nl/on-premises/installation/migrate-from-existing  "mention") in plaats van een nieuwe deployment.
