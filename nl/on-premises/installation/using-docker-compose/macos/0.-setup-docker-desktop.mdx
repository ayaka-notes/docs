Ayakaleaf Pro draait op Docker. Op een Mac gebruik je Docker Desktop, dat de Docker-engine in een virtuele Linux-machine draait.

<Steps>
<Step title="Docker Desktop installeren en starten">
Installeer de [Docker Desktop](https://docs.docker.com/desktop/setup/install/mac-install/)-build voor je Mac (Apple silicon of Intel), open het en wacht tot de engine is gestart. Je kunt het ook vanuit Terminal starten:

```bash
open -a Docker
```
</Step>

<Step title="De Docker-engine controleren">
Voer deze commando's uit in Terminal:

```bash
docker context show
docker info
docker compose version
```

De context moet naar je lokale Docker Desktop-engine wijzen, normaal `desktop-linux`. Als er een andere context is geselecteerd, schakel dan over naar Docker Desktop voordat je verdergaat:

```bash
docker context use desktop-linux
```

`docker info` moet een **Server**-sectie afdrukken. `docker --version` alleen laat slechts zien dat de client is geïnstalleerd.
</Step>

<Step title="Resources en het delen van bestanden controleren">
Controleer in Docker Desktop onder **Settings** de limieten voor CPU, geheugen en schijf aan de hand van [Voordat je begint](/nl/on-premises/installation/using-docker-compose/macos#before-you-start), en de instellingen voor het delen van bestanden; zie [Docker Desktop settings](https://docs.docker.com/desktop/settings-and-maintenance/settings/).

Deze handleiding plaatst de Toolkit onder `/Users`, dat Docker Desktop standaard deelt. Als je een andere locatie gebruikt en `bin/up` mislukt met `Mounts denied`, voeg die map dan toe aan het delen van bestanden.
</Step>

<Step title="De Docker-socket voor sandbox-compilaties controleren">
De Toolkit mount `/var/run/docker.sock` in de applicatie, zodat die voor elke compilatie een aparte TeX Live-container kan starten. Houd `DOCKER_SOCKET_PATH=/var/run/docker.sock` aan in `config/overleaf.rc`.

De Docker CLI op macOS kan verbinding maken via `~/.docker/run/docker.sock`. Dat is het client-eindpunt op de Mac, geen reden om de mountbron van de Toolkit te wijzigen: de compiler heeft de engine-socket nodig zoals Linux-containers die zien.

Als `/var/run/docker.sock` ontbreekt op de Mac, schakel dan **Allow the default Docker socket to be used** in onder **Settings → Advanced**; zie de [machtigingsvereisten van Docker](https://docs.docker.com/desktop/setup/install/mac-permission-requirements/).

<Danger>

Voer geen `chmod 777` uit op de socket om fouten te omzeilen. Toegang tot de Docker-socket staat gelijk aan root-toegang tot de Docker-VM.

</Danger>
</Step>
</Steps>
