### De beheerder en een eerste project aanmaken {#create-the-administrator-and-a-first-project}

Open [http://localhost:8080/launchpad](http://localhost:8080/launchpad), maak het eerste beheerdersaccount aan en log in. Volg daarna [6. Taken na de installatie](/nl/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks) van de Linux-handleiding, met poort `8080` in de voorbeeld-URL's.

### Compilatie controleren {#verify-compilation}

Een inlogpagina die opent, bewijst niet dat de aparte compilercontainers en hun gegevensmounts werken. Maak een leeg project aan en compileer deze `main.tex`:

```latex
\documentclass{article}
\begin{document}
Ayakaleaf Pro on macOS.
\end{document}
```

Het PDF-voorbeeld moet de tekst tonen. Selecteer zo nodig TeX Live 2026 in de projectinstellingen.

Selecteer voor een project met Chinese tekst **XeLaTeX** als compiler en test:

```latex
\documentclass{ctexart}
\begin{document}
你好，Ayakaleaf Pro。
\end{document}
```

### Persistentie controleren {#verify-persistence}

```bash
bin/stop
bin/start
```

Open het project opnieuw en compileer het nogmaals. Je account, de broncode en de projectbestanden moeten er nog zijn. Met de standaardpaden staan de live gegevens in de map `data/` van de Toolkit op je Mac.

### De instantie beschikbaar houden {#keep-the-instance-available}

Terwijl de Mac slaapt, schort macOS de virtuele machine van Docker Desktop op, met alle containers erin: niemand kan de instantie openen, en een lopende compilatie stopt tot de Mac weer wakker wordt. Alleen de systeemslaapstand telt. Het beeldscherm mag uitgaan.

Als andere mensen de instantie gebruiken, of als je lange taken laat lopen, houd de Mac dan aan de stroom en voorkom automatische slaapstand; zie [Set sleep and wake settings for your Mac](https://support.apple.com/guide/mac-help/set-sleep-and-wake-settings-mchle41a6ccd/mac):

| Mac | Instelling |
| --- | --- |
| Desktop-Mac (Mac mini, iMac, Mac Studio, Mac Pro) | **Systeeminstellingen → Energie**: schakel **Voorkom automatische sluimerstand wanneer het beeldscherm uit is** in |
| MacBook | **Systeeminstellingen → Batterij → Opties**: schakel **Voorkom automatische sluimerstand op lichtnetadapter wanneer het beeldscherm uit is** in. Dit geldt alleen zolang de lichtnetadapter is aangesloten, en het sluiten van het deksel zet de MacBook nog steeds in de sluimerstand |

Om de Mac maar een tijdje wakker te houden, voer je in plaats daarvan `caffeinate -i` uit in een Terminal-venster. Dit voorkomt sluimerstand bij inactiviteit totdat je op `Ctrl+C` drukt of het venster sluit.

Docker Desktop is een app in je gebruikerssessie. Om de instantie na een herstart terug te hebben, schakel je **Start Docker Desktop when you sign in to your computer** in onder **Settings → General** in Docker Desktop. De containers van de Toolkit gebruiken `restart: always`, dus Docker start ze opnieuw zodra Docker Desktop draait, zonder `bin/up`. Totdat iemand zich na een herstart op de Mac aanmeldt, blijft de instantie offline.

<Info>

Een Mac die wakker blijft, verbruikt meer stroom. Voor een service die altijd bereikbaar moet zijn, raden we een Linux-server aan; zie [Linux](/nl/on-premises/installation/using-docker-compose/linux).

</Info>

### Dagelijks gebruik {#daily-use}

Open Docker Desktop voordat je de instantie beheert. In een nieuwe terminal:

```bash
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
cd "$HOME/ayakaleaf-toolkit"
```

| Taak | Commando |
| --- | --- |
| De bestaande containers starten | `bin/start` |
| De containers stoppen en de gegevens behouden | `bin/stop` |
| Configuratiewijzigingen toepassen | `bin/up -d` |
| De status controleren | `bin/docker-compose ps` |
| De opstartlogs lezen | `bin/docker-compose logs --tail=100 sharelatex` |
| De compilerlogs lezen | `bin/logs -f clsi` |

`bin/start` past geen wijzigingen in `config/` toe: voer `bin/up -d` uit nadat je de configuratie hebt bewerkt. Bewaar `config/` en `data/`, en volg [Gegevens en back-ups](/nl/on-premises/maintenance/data-and-backups) vóór een upgrade of voordat je de installatie verplaatst. De databasebestanden kopiëren terwijl MongoDB ernaar schrijft, is geen consistente back-up.

Houd de instantie voor lokaal gebruik op `127.0.0.1`. Om andere computers te bedienen, stel je het luisteradres, de site-URL en HTTPS bewust in; zie [5. Uw instantie personaliseren](/nl/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance) van de Linux-handleiding.

Als iets niet werkt, zie [Probleemoplossing](/nl/on-premises/installation/using-docker-compose/macos/troubleshooting).
