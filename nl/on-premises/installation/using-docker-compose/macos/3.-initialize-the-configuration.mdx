---
title: 3. De configuratie initialiseren
description: Maak de configuratiebestanden van de Toolkit aan op je Mac met bin/init.
icon: circle-play
---

Voer vanuit de Toolkit-map, in een terminal met GNU sed op het `PATH`, het volgende uit:

```bash
bin/init
```

`bin/init` maakt drie bestanden aan:

| Bestand | Doel |
| --- | --- |
| `config/overleaf.rc` | Containerinstellingen, de gepubliceerde poort en de gegevenslocaties |
| `config/variables.env` | Applicatie-instellingen en geheimen |
| `config/version` | De versie van de applicatie-image |

Het genereert ook `OVERLEAF_INVITE_TOKEN_SECRET` in `config/variables.env`. Bewaar het, en publiceer dit bestand niet en commit het niet naar versiebeheer.

Behoud de versie die de Toolkit voor een nieuwe installatie selecteert. Volg [Je deployment upgraden](/nl/on-premises/maintenance/upgrading-your-deployment) om later de versie van een bestaande instantie te wijzigen.

<Warning>

Als `bin/init` stopt met `sed: ... invalid command code`, is het uitgevoerd met de BSD sed van macOS. Zo'n mislukte run kan alle drie de bestanden in `config/` achterlaten met een lege `OVERLEAF_INVITE_TOKEN_SECRET`, en als je `bin/init` dan opnieuw uitvoert, meldt het `Config files already exist`. Zie [Probleemoplossing](/nl/on-premises/installation/using-docker-compose/macos/troubleshooting#initialization-fails-with-invalid-command-code).

</Warning>
