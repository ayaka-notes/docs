In deze sectie draaien we Ayakaleaf Pro lokaal op je Mac met Docker Desktop en de [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). De handleiding gebruikt `http://localhost:8080`, bewaart de gegevens in je thuismap en compileert met TeX Live 2026 in sandboxcontainers.

Docker Desktop draait de applicatie, MongoDB, Redis en de TeX Live-compiler in een virtuele Linux-machine. Je installeert MongoDB, Redis of MacTeX niet op macOS zelf.

Gebruik deze opzet voor persoonlijk gebruik en lokaal testen. Voor een gedeelde service die altijd beschikbaar is, raden we de [Linux-handleiding](/nl/on-premises/installation/using-docker-compose/linux) aan, met HTTPS, back-ups en toegangscontrole. De instantie is niet beschikbaar terwijl de Mac slaapt of Docker Desktop is gestopt; zie [De instantie beschikbaar houden](/nl/on-premises/installation/using-docker-compose/macos/6.-post-installation-tasks#keep-the-instance-available).

## Voordat je begint {#before-you-start}

Je hebt nodig:

* Een macOS-versie die wordt ondersteund door [Docker Desktop for Mac](https://docs.docker.com/desktop/setup/install/mac-install/).
* Git, [Homebrew](https://brew.sh/) en GNU sed. De Toolkit gebruikt GNU sed-opties die de in macOS ingebouwde BSD sed niet accepteert.
* Voldoende resources voor zowel macOS als Docker. Begin voor een kleine lokale instantie met 4 CPU's en 8 GB geheugen toegewezen aan Docker Desktop. Dit is een voorgesteld startpunt, geen gemeten minimum.
* Minstens 40 GB vrije opslag voor een volledige TeX Live-image, plus ruimte voor je projecten. Controleer zowel de vrije ruimte op de Mac als de limiet voor schijfgebruik van Docker Desktop. Begin met één TeX Live-versie: elke extra versie vraagt ongeveer evenveel ruimte.

De applicatie- en TeX Live-images worden gepubliceerd voor `arm64` en `amd64`. Laat Docker op Apple silicon de native ARM-image kiezen en forceer `platform: linux/amd64` niet.
