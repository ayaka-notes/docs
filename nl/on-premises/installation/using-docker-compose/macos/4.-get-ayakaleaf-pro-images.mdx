Ayakaleaf Pro is een gratis Docker-image op [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Je hebt geen account, login of commerciële Overleaf-licentie nodig om de image op te halen.

Open `config/overleaf.rc` en stel in:

```bash title="config/overleaf.rc"
SERVER_PRO=true
```

De volgende keer dat je `bin/up` uitvoert, haalt de Toolkit `ghcr.io/ayaka-notes/overleaf-pro` op in de versie uit `config/version`, in plaats van de officiële Overleaf Community Edition.

De image is gebouwd voor `arm64` en `amd64`, en Docker kiest degene die bij je Mac past. Voeg op Apple silicon geen `platform: linux/amd64` toe in een override: de image zou dan onder emulatie draaien.
