De Toolkit is hetzelfde op macOS en Linux. De indeling, de map `config/` en de `bin/`-commando's worden beschreven in [2. Maak kennis met de Toolkit](/nl/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) van de Linux-handleiding.

Houd op macOS rekening met drie verschillen:

* Voer de scripts uit vanuit een terminal waarin GNU sed vooraan op het `PATH` staat; zie [1. De Toolkit downloaden](/nl/on-premises/installation/using-docker-compose/macos/1.-download-the-toolkit).
* Start Docker Desktop voordat je een script uitvoert dat met Docker communiceert, zoals `bin/up`, `bin/start` of `bin/docker-compose`.
* `bin/doctor` bevat controles die zijn overgenomen van de officiële Overleaf Toolkit. De waarschuwing `This system seems to not be Linux` is op macOS te verwachten, en de waarschuwing dat je niet bent ingelogd bij `quay.io` is niet van toepassing op de openbare image `ghcr.io/ayaka-notes/overleaf-pro`. Andere problemen in het rapport blijven wel relevant.
