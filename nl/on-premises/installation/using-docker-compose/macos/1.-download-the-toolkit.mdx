<Steps>
<Step title="Git en Homebrew controleren">
```bash
git --version
brew --version
```

Als macOS je vraagt de Command Line Tools te installeren wanneer je Git uitvoert, installeer die dan eerst. Als Homebrew ontbreekt, installeer het dan met de [officiële instructies](https://brew.sh/).
</Step>

<Step title="GNU sed op het PATH zetten">
De Toolkit-scripts gebruiken GNU sed-opties die de in macOS ingebouwde BSD sed weigert. Installeer [GNU sed](https://formulae.brew.sh/formula/gnu-sed) en zet het in deze terminal vooraan op het `PATH`:

```bash
brew install gnu-sed
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
sed --version
```

Het laatste commando moet **GNU sed** afdrukken.

Een alias zoals `alias sed=gsed` is niet genoeg: de Toolkit voert Bash-scripts uit, die de aliassen van je interactieve shell niet zien. Je hoeft `/usr/bin/sed` niet te vervangen.

Voer de regel `export PATH=...` opnieuw uit in elke nieuwe terminal die je voor de Toolkit gebruikt, of voeg hem toe aan het opstartbestand van je shell, na de eigen initialisatie van Homebrew.
</Step>

<Step title="De Ayakaleaf Toolkit-repository klonen">
Kies een map die blijft bestaan. Vermijd `/tmp`, verwisselbare schijven en met de cloud gesynchroniseerde mappen zoals iCloud Drive voor de live database en projectgegevens. Deze handleiding gebruikt `~/ayakaleaf-toolkit`:

```bash
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

<Warning>

Als de map al een installatie bevat, gebruik die dan zoals ze is, of kies een andere map voor een nieuwe instantie. Initialiseer geen nieuwe configuratie over een bestaande deployment heen.

</Warning>
</Step>
</Steps>
