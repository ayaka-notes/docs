In deze sectie begeleiden we je bij het installeren van Docker en het downloaden van de Toolkit van GitHub, maak je kennis met enkele commando's van de Toolkit en configureer je enkele basisinstellingen. Aan het einde van deze sectie zou je een draaiende on-premises instantie van Overleaf moeten hebben.

De stappen zijn bedoeld voor een recente Ubuntu LTS. Installeer op een andere distributie Docker Engine en de Compose-plugin zoals beschreven in de [documentatie van Docker](https://docs.docker.com/engine/install/) en ga daarna verder met [1. De Toolkit downloaden](/nl/on-premises/installation/using-docker-compose/linux/1.-download-the-toolkit).

<Info>

Standaard accepteert de instantie alleen verbindingen vanaf de server zelf, op `http://localhost`. Om deze vanaf andere computers of op een andere poort te openen, stel je `OVERLEAF_LISTEN_IP` en `OVERLEAF_PORT` in in `config/overleaf.rc`, zoals beschreven in [5. Uw instantie personaliseren](/nl/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance).

</Info>
