De Toolkit is dezelfde als op Linux. De indeling, de map `config/` en de `bin/`-commando's worden beschreven in [2. Maak kennis met de Toolkit](/nl/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) van de Linux-handleiding.

Houd op Windows rekening met deze verschillen:

* Voer `bin/`-commando's uit in **Ubuntu Bash**, vanuit `~/ayakaleaf-toolkit`. Commando's gemarkeerd met **PowerShell** voer je in plaats daarvan uit in Windows.
* Start Docker Desktop en schakel de WSL Integration van Ubuntu in voordat je `bin/up`, `bin/start` of `bin/docker-compose` gebruikt.
* Houd configuratiebestanden met Linux-regeleinden (LF). Bewerk ze met `nano` in Ubuntu of met een editor die met WSL is verbonden. CRLF-regeleinden kunnen Bash-fouten veroorzaken.
* `bin/doctor` voert Linux-controles uit binnen Ubuntu. De waarschuwing dat je niet bent ingelogd bij `quay.io` is niet van toepassing op de openbare image `ghcr.io/ayaka-notes/overleaf-pro`. Andere waarschuwingen verdienen nog steeds aandacht.

```bash
bin/doctor
```
