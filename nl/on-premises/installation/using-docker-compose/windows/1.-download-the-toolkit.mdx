<Steps>
<Step title="De commandoregeltools installeren">
Voer uit in **Ubuntu**, met het Linux-wachtwoord dat je in stap 0 hebt aangemaakt:

```bash
sudo apt update
sudo apt install -y git ca-certificates curl perl gawk openssl
```

Ubuntu levert al Bash, GNU sed en coreutils mee. Anders dan macOS heeft het geen Homebrew of aparte GNU sed-installatie nodig.
</Step>

<Step title="De Ayakaleaf Toolkit-repository klonen">
Bewaar de Toolkit en de gegevens ervan in het Linux-bestandssysteem van Ubuntu, onder je thuismap:

```bash
cd "$HOME"
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

Vermijd `/mnt/c`, `/mnt/d`, OneDrive en tijdelijke mappen voor de live database en projectgegevens. Paden in het Linux-bestandssysteem bieden de rechten en het bestandssysteemgedrag dat de containers verwachten, en vermijden overhead tussen bestandssystemen; zie de [richtlijnen van Microsoft voor bestandssystemen](https://learn.microsoft.com/en-us/windows/wsl/filesystems).

<Warning>

Als de map al een installatie bevat, gebruik die dan zoals ze is, of kies een andere map voor een nieuwe instantie. Vervang de configuratie of gegevens van een bestaande deployment niet.

</Warning>
</Step>
</Steps>
