---
title: 3. De configuratie initialiseren
description: Maak de configuratiebestanden van de Toolkit aan in Ubuntu op WSL 2 met bin/init.
icon: circle-play
---

Voer vanuit de Toolkit-map in **Ubuntu** het volgende uit:

```bash
bin/init
```

`bin/init` maakt drie bestanden aan:

| Bestand | Doel |
| --- | --- |
| `config/overleaf.rc` | Containerinstellingen, de gepubliceerde poort en de gegevenslocaties |
| `config/variables.env` | Applicatie-instellingen en geheimen |
| `config/version` | De versie van de applicatie-image |

Het genereert ook `OVERLEAF_INVITE_TOKEN_SECRET` in `config/variables.env`. Bewaar het, en publiceer dit bestand niet en commit het niet naar versiebeheer.

Behoud de versie die de Toolkit voor een nieuwe installatie selecteert. Volg [Je deployment upgraden](/nl/on-premises/maintenance/upgrading-your-deployment) om later de versie van een bestaande instantie te wijzigen.

<Info>

`bin/init` overschrijft geen bestaande configuratie. Als het meldt dat bestanden al bestaan, bekijk ze dan voordat je verdergaat. Bewaar `config/` en `data/` wanneer je de instantie herstart of upgradet.

</Info>
