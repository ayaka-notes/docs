In deze sectie draaien we Ayakaleaf Pro lokaal op Windows met WSL 2, Ubuntu, Docker Desktop en de [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). De handleiding gebruikt `http://localhost:8080`, bewaart de gegevens in de thuismap van Ubuntu en schakelt sandbox-compilaties in.

De applicatie, MongoDB, Redis en TeX Live draaien in Linux-containers die door Docker Desktop worden beheerd. Voer Toolkit-commando's uit in Ubuntu; open de applicatie in je Windows-browser. [Stap 0](/nl/on-premises/installation/using-docker-compose/windows/0.-setup-wsl-and-docker-desktop) legt uit hoe de Windows- en Linux-onderdelen samenwerken en begint met het installeren van WSL.

Je kunt Windows gebruiken voor een lokale instantie, of die continu laten draaien met de beschikbaarheidsinstellingen in stap 6. Voor gedeelde servers en productieservers raden we de [Linux-handleiding](/nl/on-premises/installation/using-docker-compose/linux) aan, met HTTPS, back-ups en toegangscontrole. De slaapstand van Windows, het afsluiten van Docker Desktop en het afsluiten van WSL onderbreken deze lokale instantie; zie [De instantie beschikbaar houden](/nl/on-premises/installation/using-docker-compose/windows/6.-post-installation-tasks#keep-the-instance-available).

## Voordat je begint {#before-you-start}

Je hebt nodig:

* Een Windows-versie en processor die worden ondersteund door [Docker Desktop for Windows](https://docs.docker.com/desktop/setup/install/windows-install/), met hardwarevirtualisatie ingeschakeld. Deze handleiding gebruikt Windows 11 op x86-64.
* Toestemming om WSL in te schakelen en software te installeren. WSL moet versie 2.1.5 of hoger zijn, met Ubuntu in WSL 2-modus.
* Voldoende geheugen voor Windows en de containers. Voor een kleine lokale instantie zijn 4 CPU's en 8 GB beschikbaar voor Docker een voorgesteld startpunt, geen gemeten minimum.
* Vrije opslag op de Windows-schijf met de WSL- en Docker-gegevens. Reken op minstens 40 GB voor een volledige TeX Live-installatie plus projectgegevens; de basic-image in [stap 5](/nl/on-premises/installation/using-docker-compose/windows/5.-personalizing-your-instance) is kleiner en geschikt voor de eerste implementatietest. Extra imageversies vragen extra ruimte.
* Netwerktoegang tot GitHub, GitHub Container Registry (`ghcr.io`) en Docker Hub om de Toolkit te klonen en images te downloaden.

**PowerShell**-blokken voer je uit in Windows. **Bash**-blokken en `bin/`-commando's voer je uit in Ubuntu, tenzij anders vermeld. Voer Toolkit-scripts niet uit in PowerShell of Windows Git Bash.
