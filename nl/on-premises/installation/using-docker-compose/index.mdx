Docker Compose op één server is de aanbevolen manier om Ayakaleaf Pro te implementeren. Je gebruikt het via de [Toolkit](https://github.com/ayaka-notes/toolkit): een set scripts die `docker compose` omhullen en je instellingen uit één `config/`-map lezen, zodat `bin/up` de plaats inneemt van `docker compose up`.
