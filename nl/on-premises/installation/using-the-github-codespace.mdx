De eenvoudigste manier om Ayakaleaf Pro te testen is via GitHub Codespace, waar alle omgevingsvariabelen vooraf zijn geconfigureerd, zodat je het direct kunt gebruiken.

<Warning>

Wanneer je Docker-containers draait met GitHub Codespaces, wordt de Codespace niet automatisch afgesloten en blijven er **kosten** in rekening worden gebracht. Raadpleeg voor de factureringsregels van GitHub Codespaces de [factureringsregels van GitHub Codespaces](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces).

Ga naar [https://github.com/codespaces](https://github.com/codespaces) om je GitHub Codespaces te beheren. Verwijder je Codespace tijdig wanneer je deze niet meer nodig hebt.

</Warning>

We hebben de volgende functies **vooraf geconfigureerd**:

* [x] LaTeX-compilatie in een sandbox met TeXLive **Basic** (2024-2026)
* [x] Pandoc-import/-export (functie van het SaaS-platform)
* [x] Python-scripts uitvoeren (functie van het SaaS-platform)
* [x] Ondersteuning voor Git-Bridge (functie van Server Pro)
* [x] Geavanceerd zoeken naar referenties (functie van het SaaS-platform)
* [x] Beheerpaneel (globaal beheer van gebruikers/projecten)
* [x] Wijzigingen bijhouden (met review- en opmerkingenpaneel)
* [x] Volledige projectgeschiedenis (met herstellen en downloaden)
* [x] Symbolenpalet (functie van Server Pro/SaaS-platform)

<Warning>

Standaard GitHub Codespaces bieden 32 GB opslag. Dat is onvoldoende voor onze `texlive-full`-installatie. Om de volledige image te testen, dien je een supportticket bij GitHub in voor een Codespace met grote runners (8+ cores).

</Warning>

GitHub Sync, LDAP, OAuth, SSO, Zotero-integratie en andere functies zijn in deze playground _**niet geconfigureerd**_. Raadpleeg de [Toolkit-instellingen](/nl/on-premises/configuration/overleaf-toolkit/toolkit-settings) voor meer informatie over het configureren van deze functies in je eigen implementatie.

#### De volledige TeXLive-image gebruiken

Als je toegang hebt tot GitHub Codespaces met 8 cores/64 GB, kun je in deze playground de volledige TeXLive-image gebruiken. Je kunt de volgende omgevingsvariabelen in het bestand `toolkit/config/variables.env` wijzigen om de TeXLive Full-image te gebruiken in plaats van de TeXLive Basic-image.

```dotenv wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1, ghcr.io/ayaka-notes/texlive-full:2024.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025, Texlive 2024
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```

Na het wijzigen van de omgevingsvariabelen moet je de Toolkit herstarten om de wijzigingen toe te passen. Voer de volgende opdracht uit om de Toolkit te herstarten.

```bash
cd toolkit && bin/up -d
```
