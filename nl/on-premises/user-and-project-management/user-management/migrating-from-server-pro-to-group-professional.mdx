Overstappen van een zelfgehoste Server Pro-instantie naar een nieuw cloudgebaseerd Overleaf Group Professional-abonnement is een grote verandering. Om dit proces zo soepel mogelijk te laten verlopen, hebben we de volgende richtlijnen opgesteld.

Over het algemeen stellen we een overlapperiode van drie maanden voor, te beginnen op je verlengingsdatum. Dit betekent dat:

* Je bestaande Server Pro-instantie en je nieuwe Group Professional-abonnement allebei volledig actief zijn.
* Je technische team tijd kan inplannen om het Group Professional-abonnement in te richten en te beslissen over de toekomst van je on-premises implementatie van Server Pro.
* Het allerbelangrijkste: je gebruikers ruim de tijd hebben om hun projecten naar het nieuwe Overleaf Group Professional-platform te kopiëren.

Deze korte handleiding leidt je door de belangrijkste stappen van deze migratie. Laten we beginnen!

<Steps>
<Step title="Fase 1: Inrichting en configuratie">
(Link: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-1-setup-and-configuration)

* Overleaf maakt je Group Professional-abonnement aan en voegt je hoofdbeheerder (Lead Administrator) toe.
* Je groepsbeheerder kan [Managed Users](https://docs.overleaf.com/groups/user-management/managed-user-accounts) inschakelen, [Single Sign-On (SSO)](https://docs.overleaf.com/groups/overleaf-group-single-sign-on/setting-up-group-sso) configureren en [de eindgebruikers uitnodigen](https://docs.overleaf.com/groups/user-management/how-to-add-and-remove-users).

<Warning>

Het inschakelen van Managed Users en het implementeren van SSO is een verplichte stap voor naleving van FedRAMP® LI-SaaS. Als je organisatie FedRAMP-naleving vereist, richt Managed Users en SSO dan in voordat je eindgebruikers uitnodigt.

</Warning>
</Step>

<Step title="Fase 2: Gebruikersmigratie en gegevensbeheer">
(Link: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-2-user-migration-and-data-management)

Dit is het primaire migratievenster, met de volgende verantwoordelijkheden:

#### Eindgebruikers

* Gebruikers moeten alle projecten die ze willen behouden van je Server Pro-instantie migreren naar hun nieuwe accounts op [overleaf.com](http://overleaf.com/). Dit proces bestaat uit het [exporteren van projecten](https://www.overleaf.com/learn/how-to/Exporting_your_work_from_Overleaf) uit Server Pro en het [uploaden ervan](https://www.overleaf.com/learn/how-to/Uploading_a_project) naar hun account op [overleaf.com](http://overleaf.com/). Als een gebruiker nog geen account op [overleaf.com](http://overleaf.com/) heeft, kan deze zich registreren op [overleaf.com/register](http://overleaf.com/register).

<Warning>

Alleen de broncode van het project (LaTeX- en binaire bestanden) wordt via deze exportprocedure overgezet. Bestaande projectinstellingen, deelinstellingen, opmerkingen, bijgehouden wijzigingen enz. worden NIET overgezet. Gebruikers moeten hun samenwerkers na de migratie opnieuw uitnodigen.

</Warning>

#### Technisch personeel

* Tijdens deze fase moet je technische team plannen hoe na de migratie wordt omgegaan met je on-premises Server Pro-instantie en de bijbehorende gegevens.
* **Back-up van gegevens:** Je kunt vóór de uitfasering alle projecten exporteren om een archief te maken, zodat je gebruikers kunt helpen die zijn vergeten hun werk te migreren of te downloaden. Instructies: https://docs.overleaf.com/on-premises/maintenance/data-and-backups/exporting-projects
* **Uitfasering van Server Pro:** Nadat het migratievenster is gesloten en je licentiesleutel is uitgeschakeld, heb je twee hoofdopties voor de Server Pro-instantie zelf (zie de volgende stappen).
</Step>

<Step title="Opties voor het uitfaseren van Server Pro">
<Steps>
<Step title="Server Pro volledig verwijderen">
Bij het verwijderen wordt Server Pro uitgefaseerd en wordt de software volledig verwijderd.
</Step>

<Step title="Overstappen naar Community Edition">
Bij het overstappen blijft de database met gebruikers en projecten, inclusief de volledige projectgeschiedenis, behouden doordat de instantie wordt omgezet van Server Pro naar Community Edition.
</Step>
</Steps>

<Info>

De Community Edition bevat GEEN [Sandboxed Compiles](https://docs.overleaf.com/on-premises#overview-of-server-pro-and-community-edition) en ook geen [LDAP](/nl/on-premises/configuration/overleaf-toolkit/authentication/ldap-authentication)/[SAML](/nl/on-premises/configuration/overleaf-toolkit/authentication/saml-authentication). Als je moet terugkeren naar native authenticatie (gebruikersnaam/wachtwoord), zie dan: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-to-ldap-or-saml#going-the-other-way-switching-from-ldap-saml-back-to-native-authentication

Voor een vergelijking van Server CE en Server Pro, zie: https://docs.overleaf.com/on-premises/welcome/server-pro-vs.-community-edition

</Info>
</Step>

<Step title="Fase 3: Uitfasering van Server Pro">
(Link: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-3-server-pro-decommission)

* Het Overleaf-team deactiveert je Server Pro-licentiesleutel formeel en stuurt een bevestiging zodra dit is voltooid.
* Voer op dat moment een van de hierboven beschreven uitfaseringsacties uit: Server Pro volledig verwijderen of overstappen naar Community Edition.
</Step>
</Steps>

Aanvullende bronnen en hierboven genoemde links blijven ongewijzigd.
