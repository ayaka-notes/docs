### Account

Wat het beheer van hun eigen account betreft, worden **alle** gebruikers als gewone gebruikers behandeld — `Site Admins` en `Template Users` krijgen **geen** extra rechten. Er gelden echter beperkingen voor de acties die gewone gebruikers kunnen uitvoeren, afhankelijk van hoe ze zich authenticeren.

#### Instellingen

**Authenticatietypen: interne accounts | SSO (SAML/LDAP)**

| Actie | Interne accounts | SSO (SAML/LDAP) |
| ----------------------------------------- | ----------------: | --------------: |
| Accountgegevens bijwerken | Ja | Nee |
| Wachtwoord wijzigen | Ja | Nee |
| Git bridge-authenticatietokens genereren | Ja | Ja |
| Git bridge-authenticatietokens verwijderen | Ja | Ja |
| Sessies beheren | Ja | Ja |

<Info>

De Git Bridge-integratie is **alleen** beschikbaar in Server Pro. Bekijk [Server Pro vs. Community Edition](/nl/on-premises/readme/ayakaleaf-pro-vs-server-pro) voor meer informatie.

</Info>

#### Je sessies

| -------------------- | ---: |
| Sessies wissen | Ja |
| Huidige sessie bekijken | Ja |
| Andere sessies bekijken | Ja |
