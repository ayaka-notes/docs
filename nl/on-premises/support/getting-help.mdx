### De Doctor

De Overleaf Toolkit wordt geleverd met een handig `doctor`-script dat helpt bij het debuggen. Voer `bin/doctor` uit en het script toont informatie over je hostomgeving, je configuratie en de afhankelijkheden die de Toolkit nodig heeft. Deze uitvoer kan ons ook helpen problemen met je Ayakaleaf Pro-installaties te diagnosticeren.

<Info>

Gebruikers van Overleaf Pro kunnen [een issue openen op GitHub](https://github.com/ayaka-notes/overleaf/issues).

Het is een goed idee om de uitvoer van het script `bin/doctor` in je bericht op te nemen.

</Info>

### De Doctor raadplegen

Voer het doctor-script uit:

```bash title="Run doctor"
bin/doctor
```

### Hostinformatie

De sectie `Host Information` bevat informatie over de machine waarop de Toolkit draait (bijvoorbeeld de Linux-distributie en release).

<Accordion title="Voorbeeld van uitvoer van Host Information">

```text
- Host Information
    - Linux
    - Output of 'lsb_release -a':
            No LSB modules are available.
            Distributor ID:	Ubuntu
            Description:	Ubuntu 22.04.5 LTS
            Release:	22.04
            Codename:	jammy
```

</Accordion>

### Afhankelijkheden

De sectie `Dependencies` toont de tools die nodig zijn om de Toolkit te laten werken. Als een tool aanwezig is, wordt deze vermeld als `status: present` met versie-informatie. Als deze ontbreekt, wordt deze vermeld als `status: MISSING!` en wordt er onderaan de `doctor`-uitvoer een waarschuwing toegevoegd.

<Accordion title="Voorbeeld van uitvoer van Dependencies (aanwezig)">

```text
- docker
    - status: present
    - version info: Docker version 28.0.4, build b8034c0
```

</Accordion>

<Accordion title="Voorbeeld van uitvoer van Dependencies (ontbrekend)">

```text
- docker
    - status: MISSING!
```

</Accordion>

Als er afhankelijkheden ontbreken, werkt de Toolkit vrijwel zeker niet.

### Configuratie

De sectie `Configuration` bevat informatie over bestanden in de map `config/`. Voor `config/overleaf.rc` toont de doctor enkele belangrijke waarden. Ontbrekende bestanden worden vermeld als `status: MISSING!` en er wordt onderaan de `doctor`-uitvoer een waarschuwing toegevoegd.

<Accordion title="Voorbeeld van uitvoer van Configuration">

```text
====== Configuration ======
- config/version
    - status: present
    - version: 5.4.0
- config/overleaf.rc
    - status: present
    - values
        - OVERLEAF_DATA_PATH: /tmp/overleaf
        - SERVER_PRO: false
        - MONGO_ENABLED: false
        - REDIS_ENABLED: true
- config/variables.env
    - status: MISSING!
```

</Accordion>

Opmerkingen bij het bovenstaande voorbeeld:

* `OVERLEAF_DATA_PATH` ingesteld op `/tmp/overleaf` is mogelijk geen veilige locatie voor belangrijke gegevens.
* `MONGO_ENABLED: false` betekent dat de Toolkit geen eigen MongoDB inricht; zorg er zo nodig voor dat `MONGO_URL` naar een extern beheerde MongoDB verwijst.
* `config/variables.env` ontbreekt in het voorbeeld.

### Waarschuwingen

De sectie `Warnings` vat de problemen samen die door het doctor-script zijn gevonden. Als er geen problemen zijn, wordt dat in deze sectie aangegeven.

<Accordion title="Voorbeeld van uitvoer van Warnings">

```text
====== Warnings ======
- configuration file variables.env not found
- rc file, OVERLEAF_DATA_PATH not set
====== End =======
```

</Accordion>
