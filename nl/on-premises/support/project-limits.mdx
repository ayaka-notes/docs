---
title: Projectlimieten
icon: list-check
---

| Functie                                          | Limiet                                                                                                                                                                  |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Time-out voor compileren                         | **Standaard:** 180 seconden. Zie [De compileertime-out van projecten bijwerken](/nl/on-premises/user-and-project-management/project-management) voor meer informatie over het aanpassen van deze waarde. |
| Maximaal aantal bestanden per project            | 2000                                                                                                                                                                    |
| Maximale grootte van bewerkbaar materiaal per project | **Standaard:** 7 MB. Zie [Omgevingsvariabelen](/nl/on-premises/configuration/overleaf-toolkit/environment-variables) voor meer informatie over het aanpassen van deze waarde. |
| Maximale grootte van een afzonderlijk bewerkbaar tekstbestand | 2 MB\*                                                                                                                                                      |
| Maximale grootte van een afzonderlijke upload    | 50 MB (configureerbaar via `MAX_UPLOAD_SIZE`)                                                                                                                           |
| Maximale ongecomprimeerde grootte van een geüpload .zip-bestand | 6 × `MAX_UPLOAD_SIZE` (standaard 300 MB)                                                                                                                  |
| Maximale projectgrootte                          | Onbeperkt†                                                                                                                                                              |
| Maximaal aantal projecten                        | Onbeperkt                                                                                                                                                               |

\* Sommige grotere bestanden kunnen onder bepaalde omstandigheden bewerkbaar blijven. Om er zeker van te zijn dat een bestand bewerkbaar blijft, kun je de grootte echter het beste beperken tot 2 MB of minder.

† Er geldt geen afgedwongen limiet voor de totale projectgrootte. Je kunt echter tegen technische beperkingen aanlopen bij het werken met zeer grote projecten. We raden een maximale projectgrootte van 500 MB aan, of minder dan 100 MB als je onze [Git-integratie](https://www.overleaf.com/learn/how-to/Git_integration) gebruikt. Projecten boven deze groottes kunnen werken, maar binnen deze limieten blijven geeft je de beste ervaring.
