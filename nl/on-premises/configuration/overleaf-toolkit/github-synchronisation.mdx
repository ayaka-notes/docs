### GitHub-synchronisatie instellen

<Warning>

Je moet eerst [git-bridge](/nl/on-premises/configuration/overleaf-toolkit/git-integration) inschakelen voordat je GitHub-synchronisatie kunt gebruiken.

```dotenv title="config/overleaf.rc"
GIT_BRIDGE_ENABLED=true
```

</Warning>

Ga naar de [ontwikkelaarsinstellingen](https://github.com/settings/developers) om je GitHub OAuth-applicatie aan te maken en kopieer je `CLIENT_ID` en `SECRET`.

**Opmerking**: je OAuth-callback-URL is: `${OVERLEAF_SITE_URL}/user/github-sync/oauth2/callback`.

Voeg vervolgens de volgende instellingen toe aan je Overleaf-omgevingsvariabelenbestanden.

```dotenv title="config/variables.env" wrap
# used to encrypt the user's GitHub access token.
# How to generate: `openssl rand -hex 32`
GITHUB_TOKEN_CIPHER_PASSWORD=0123456789ABCDEFG # changed to yours

# Github Sync Settings
GITHUB_SYNC_ENABLED=true
GITHUB_SYNC_CLIENT_ID=
GITHUB_SYNC_CLIENT_SECRET=

# OAuth callback is: ${OVERLEAF_SITE_URL}/user/github-sync/oauth2/callback
# (Optional) GITHUB_SYNC_PROXY_URL=http://10.0.0.1:10808
```

<Warning>

Zorg ervoor dat `OVERLEAF_SITE_URL` correct is ingesteld voordat je de GitHub OAuth-callback-URL configureert.

</Warning>

Als je je in een regio met beperkte netwerktoegang bevindt, moet je mogelijk een proxy configureren om GitHub te bereiken. Stel de volgende omgevingsvariabele in: `GITHUB_SYNC_PROXY_URL=http://10.0.0.1:10808`. Zorg ervoor dat je gebruik van een proxy voldoet aan de lokale wet- en regelgeving.

<Warning>

`GITHUB_SYNC_PROXY_URL` moet een standaard HTTP/HTTPS-forwardproxy zijn (bijvoorbeeld de HTTP-poort van Clash). GitHub-downloadmirrors zoals `gh-proxy.org` worden niet ondersteund.

</Warning>

<Warning>

Gebruik `127.0.0.1` niet als proxyhost. Als de proxy op de hostserver draait, gebruik dan het LAN-IP-adres van de server (zoals `192.168.1.xx`) en zorg ervoor dat de proxy is geconfigureerd om verbindingen van apparaten in het lokale netwerk te accepteren.

</Warning>
