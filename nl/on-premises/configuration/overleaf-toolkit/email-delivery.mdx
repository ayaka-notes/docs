Overleaf ondersteunt het verzenden van e-mail via twee methoden: Simple Mail Transfer Protocol (SMTP) en [Amazon Simple Email Service (SES)](https://aws.amazon.com/ses/). SMTP kan worden gebruikt als je op je localhost een e-mailserver hebt ingeschakeld die luistert naar lokale verbindingen.

## Configuratie

E-mail wordt geconfigureerd met de volgende omgevingsvariabelen.

#### Afzenderconfiguratie

| Naam                          | Beschrijving                                                                                                                                         |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | <p>Het afzenderadres, bijv. <a href="mailto:support@mycompany.com">`'support@mycompany.com'`</a><br /><br />- <strong>Verplicht</strong>: ja</p> |
| `OVERLEAF_EMAIL_REPLY_TO`     | Het antwoordadres, bijv. `'noreply@mycompany.com'`                                                                                                  |

#### SMTP

| Naam                                    | Beschrijving                                                                                                                                                                                                                                                             |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST`              | De hostnaam of het IP-adres waarmee verbinding wordt gemaakt. Moet bereikbaar zijn vanuit de Docker-container                                                                                                                                                                               |
| `OVERLEAF_EMAIL_SMTP_PORT`              | De poort waarmee verbinding wordt gemaakt                                                                                                                                                                                                                                                   |
| `OVERLEAF_EMAIL_SMTP_SECURE`            | Bij `true` gebruikt de verbinding TLS bij het verbinden met de server. Bij `false` of niet ingesteld wordt TLS gebruikt als de server de extensie `STARTTLS` ondersteunt. Stel deze waarde in de meeste gevallen in op `true` als je verbinding maakt met poort `465`. Laat deze voor poort `587` of `25` op `false` staan |
| `OVERLEAF_EMAIL_SMTP_USER`              | De gebruikersnaam die moet worden gebruikt om te authenticeren bij de SMTP-server                                                                                                                                                                                                 |
| `OVERLEAF_EMAIL_SMTP_PASS`              | Het wachtwoord dat bij de SMTP-gebruikersnaam hoort                                                                                                                                                                                                                           |
| `OVERLEAF_EMAIL_SMTP_TLS_REJECT_UNAUTH` | Bij `false` wordt een verbinding geopend met een TLS-server met een zelfondertekend of ongeldig TLS-certificaat                                                                                                                                                                        |
| `OVERLEAF_EMAIL_SMTP_IGNORE_TLS`        | Wanneer dit `true` is en `OVERLEAF_EMAIL_SMTP_SECURE` `false` is, wordt TLS niet gebruikt, zelfs niet als de server de extensie `STARTTLS` ondersteunt                                                                                                                                            |
| `OVERLEAF_EMAIL_SMTP_NAME`              | Optionele hostnaam voor TLS-validatie als `OVERLEAF_EMAIL_SMTP_HOST` is ingesteld op een IP-adres; standaard de hostnaam van de machine.                                                                                                                                        |
| `OVERLEAF_EMAIL_SMTP_LOGGER`            | Bij `true` worden logberichten naar `web.log` geschreven.                                                                                                                                                                                                                        |

#### SMTP-interface van Amazon SES

Je kunt [hier](https://docs.aws.amazon.com/ses/latest/dg/send-email-smtp.html) meer lezen over het verzenden van e-mail via de SMTP-interface van Amazon SES.

| Naam                       | Beschrijving                                                                               |
| -------------------------- | ------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST` | De hostnaam of het IP-adres waarmee verbinding wordt gemaakt. Moet bereikbaar zijn vanuit de Docker-container |
| `OVERLEAF_EMAIL_SMTP_PORT` | De poort waarmee verbinding wordt gemaakt                                                                     |
| `OVERLEAF_EMAIL_SMTP_USER` | De gebruikersnaam die moet worden gebruikt om te authenticeren bij de SMTP-server                   |
| `OVERLEAF_EMAIL_SMTP_PASS` | Het wachtwoord dat bij de SMTP-gebruikersnaam hoort                                             |

#### Amazon SES API

Je kunt [hier](https://docs.aws.amazon.com/ses/latest/dg/send-email-api.html) meer lezen over het verzenden van e-mail via de Amazon SES API.

| Naam                                   | Beschrijving                                |
| -------------------------------------- | ------------------------------------------- |
| `OVERLEAF_EMAIL_AWS_SES_ACCESS_KEY_ID` | De access key bij gebruik van AWS SES       |
| `OVERLEAF_EMAIL_AWS_SES_SECRET_KEY`    | De secret key bij gebruik van AWS SES       |
| `OVERLEAF_EMAIL_AWS_SES_REGION`        | Indien niet ingesteld, is de standaardregio US-EAST-1 |

#### AWS SES met instance roles

| Naam                    | Beschrijving                                                                                                                     |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_DRIVER` | Wanneer dit is ingesteld op `ses`, gebruikt het e-mailsysteem de SES API-methode en vertrouwt het op de geconfigureerde instance roles om e-mail te verzenden. |

#### Aanpassing

| Naam                           | Beschrijving                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_CUSTOM_EMAIL_FOOTER` | <p>Aangepaste HTML die aan alle e-mails wordt toegevoegd, bijv.<br /><br /><strong>Voorbeeld</strong>: `"<div>This system is run by department x </div> <div> If you have any questions please look at our faq <a href='`<a href="https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/https:/somwhere.com'%3Ehere&#x3C;/a%3E&#x3C;/div%3E">`https://somwhere.com'>here&#x3C;/a>&#x3C;/div>`</a>`"`</p> |
