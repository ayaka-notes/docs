Elk project heeft een MCP-server, zodat AI-clients zoals Claude Code, Codex, Cursor, VS Code of Gemini CLI eraan kunnen werken: de bestanden lezen en bewerken, het project compileren, het LaTeX-logboek lezen, de pdf downloaden en op opmerkingen reageren.

<Info>

Deze functie is ontwikkeld door [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro). Ze is geïntroduceerd in v6.3.1 en latere versies.

</Info>

### Instellen

De MCP-server hoort bij de Git-integratie: schakel [git-bridge](/nl/on-premises/configuration/overleaf-toolkit/git-integration) in, en de MCP-server is ook beschikbaar. Verder hoef je niets te configureren.

### Een AI-client verbinden

1. Genereer in de **accountinstellingen** een Git-authenticatietoken. Hetzelfde token wordt gebruikt voor de MCP-server en voor Git.
2. Open in de editor **Integraties** en klik op **MCP-server**. Daar zie je het adres van de MCP-server van het project, `https://<your-overleaf>/project/<project_id>/mcp`, en hoe je deze aan elke AI-client toevoegt: kopieer de opdracht en vervang `<token>` door je token.

### Gebruik

Zodra de verbinding er is, vraag je de AI-client in gewone taal wat je wilt. Bijvoorbeeld:

| Je vraagt | De AI-client gebruikt |
| --- | --- |
| _Verbeter de typfouten in de inleiding._ | `read_file`, `edit_file`: de wijzigingen verschijnen live in de editor |
| _Compileer het project en los de LaTeX-fouten op._ | `compile`, `get_compile_log`, `edit_file` |
| _Beantwoord de openstaande opmerkingen en markeer ze daarna als opgelost._ | `list_comments`, `reply_to_comment`, `resolve_comment` |
| _Schakel over naar XeLaTeX en download de pdf._ | `update_settings`, `compile`, `get_output_file_link` |

### Tools

| Groep | Tools |
| --- | --- |
| Project | `get_clone_info`, `get_settings`, `update_settings`, `list_versions` |
| Bestanden | `list_files`, `read_file`, `edit_file`, `write_file`, `delete_file` |
| Compileren | `compile`, `get_compile_log`, `get_output_file_link`, `word_count` |
| Opmerkingen | `list_comments`, `reply_to_comment`, `resolve_comment`, `reopen_comment` |

Bewerkingen met `edit_file` en `write_file` verschijnen live in de editor en worden samengevoegd met die van medewerkers. Voor veel bestanden tegelijk, binaire bestanden of hernoemingen kan de AI-client het project ook met Git klonen en pushen.

### Rechten

De MCP-server volgt de deelinstellingen van het project, net als Git:

* Iedereen die het project kan bekijken, kan het lezen, compileren en de uitvoer downloaden.
* Alleen de eigenaar en bewerkers kunnen de bestanden en instellingen wijzigen.
* Reviewers kunnen ook op opmerkingen reageren, en de opmerkingen die ze zelf zijn begonnen oplossen of heropenen.
* Kijkers die via een link zijn toegetreden, kunnen de opmerkingen niet zien, net als in de editor.
