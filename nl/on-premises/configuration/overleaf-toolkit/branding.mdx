### Header

In deze sectie behandelen we hoe je belangrijke elementen van je on-premises-instantie kunt personaliseren. Je kunt de sitetitel, navigatielinks, header, footer en het logo naar wens aanpassen.

### Sitetitel

De titel van de navigatiebalk kan worden aangepast met de omgevingsvariabele `OVERLEAF_NAV_TITLE`; deze tekst wordt linksboven in de navigatie gebruikt als er geen logo is ingesteld.

```bash
# add to config/variables.env
OVERLEAF_NAV_TITLE=Our Overleaf Instance
```

## Logo

Je kunt een eigen logo toevoegen in plaats van tekst door de omgevingsvariabele `OVERLEAF_HEADER_IMAGE_URL` in te stellen. Deze waarde moet verwijzen naar een extern gehost afbeeldingsbestand.

```bash title="config/variables.env"
# add to config/variables.env
OVERLEAF_HEADER_IMAGE_URL=https://mysite.somewhere.com/img/logo.png
```

#### Logo's voor licht en donker thema

Vanaf versie 6.3.0 kun je afzonderlijke logo's instellen voor het lichte en het donkere thema met de omgevingsvariabelen `OVERLEAF_HEADER_IMAGE_URL_LIGHT` en `OVERLEAF_HEADER_IMAGE_URL_DARK`. Beide waarden moeten verwijzen naar een extern gehost afbeeldingsbestand.

```text
# add to config/variables.env
OVERLEAF_HEADER_IMAGE_URL_LIGHT=https://mysite.somewhere.com/img/logo-light.png
OVERLEAF_HEADER_IMAGE_URL_DARK=https://mysite.somewhere.com/img/logo-dark.png
```

<Info>

Als een van beide variabelen niet is ingesteld, valt dat thema terug op het logo dat in `OVERLEAF_HEADER_IMAGE_URL` is ingesteld.

</Info>

## Navigatielinks in de header

Extra navigatie-items kunnen aan de navigatieheader worden toegevoegd door de omgevingsvariabele `OVERLEAF_HEADER_EXTRAS` in te stellen op een JSON-array met objecten. Bijvoorbeeld:

```json wrap
[\
  {\
    "text": "Some link",\
    "url": "http://example.com/somelink",\
    "class": "subdued",\
    "only_when_logged_out": true\
  },\
  {\
    "text": "Help",\
    "class": "subdued",\
    "dropdown": [\
      {\
        "text": "Documentation",\
        "url": "/learn"\
      },\
      {\
        "text": "Contact Admin",\
        "url": "http://example.com/contact"\
      }\
    ]\
  }\
]
```

Voeg de geëscapete JSON-vorm toe aan toolkit/variables.env:

```bash title="toolkit/variables.env" wrap
# add to toolkit/variables.env
OVERLEAF_HEADER_EXTRAS=[{"text":"Some link","url":"http://example.com/somelink","class":"subdued","only_when_logged_out":true},{"text":"Help","class":"subdued","dropdown":[{"text":"Documentation","url":"/learn"},{"text":"Contact Admin","url":"http://example.com/contact"}]}]
```

## Footers

Je kunt zowel de linker als de kleinere rechter footer (te vinden op pagina's zoals `/project`) aanpassen met de omgevingsvariabelen `OVERLEAF_LEFT_FOOTER` en `OVERLEAF_RIGHT_FOOTER`. Beide verwachten een array met JSON-objecten die wordt ingevoegd.

Beide verwachten een JSON-array die wordt ingevoegd.

```json
[\
  {\
    "text": "This is an example text footer entry!"\
  },\
  {\
    "text": "This is an example URL footer link!", "url" : "/my-first-link.htm"\
  }\
]
```

<Info>

Wanneer je alleen `text` gebruikt, mag deze geen HTML bevatten, omdat de waarde als ruwe tekst wordt weergegeven.

</Info>

Deze gegevens moeten geldige JSON zijn om te werken, met geëscapete aanhalingstekens wanneer ze als omgevingsvariabele worden doorgegeven.

```bash title="config/variables.env" wrap
# add to config/variables.env
OVERLEAF_LEFT_FOOTER=[{"text": "This is an example text footer entry!"}]
OVERLEAF_RIGHT_FOOTER=["text": "This is an example URL footer link!", "url" : "/my-first-link.htm"]
```

<Info>

Naast `text` en `url` accepteert het JSON-object ook de eigenschappen `class` en `label` voor verdere aanpassing.

</Info>

### Onderhoudspagina

Je kunt het bericht op de onderhoudspagina aanpassen met de omgevingsvariabele `OVERLEAF_MAINTENANCE_MESSAGE`; deze tekst vervangt het standaardbericht onder de paginatitel.

```text wrap
# add to config/variables.env
OVERLEAF_MAINTENANCE_MESSAGE=Our Overleaf Instance is down for maintenance and will be back shortly.
```

Gebruik in plaats daarvan `OVERLEAF_MAINTENANCE_MESSAGE_HTML` om links of andere opmaak op te nemen. Als beide zijn ingesteld, heeft `OVERLEAF_MAINTENANCE_MESSAGE_HTML` voorrang.

```text wrap
# add to config/variables.env
OVERLEAF_MAINTENANCE_MESSAGE_HTML=Our Overleaf Instance is down for maintenance. For urgent requests, contact <a href="mailto:admin@example.com">admin@example.com</a>.
```

<Info>

`OVERLEAF_MAINTENANCE_MESSAGE` wordt als platte tekst weergegeven en mag dus **geen** HTML bevatten. `OVERLEAF_MAINTENANCE_MESSAGE_HTML` wordt zonder escaping als HTML weergegeven.

</Info>

Als geen van beide is ingesteld, linkt het standaardbericht naar je statuspagina wanneer `OVERLEAF_STATUS_PAGE_URL` is ingesteld, en toont het anders het e-mailadres van de beheerder.
