### Обзор Overleaf

Overleaf — совместный редактор LaTeX, который любят исследователи и технические команды. Его облачная версия доступна на [overleaf.com](https://www.overleaf.com/). Она предоставляет полнофункциональный онлайн-редактор LaTeX. Однако Overleaf Common (SaaS-версия) имеет множество функциональных ограничений, и вам придётся мириться с _**10-секундным лимитом времени компиляции**_ и дорогой подпиской.

Хотя Overleaf предлагает открытую Community-версию (доступна на [GitHub: Overleaf](https://github.com/overleaf/overleaf)), у неё тоже много ограничений, например:

<Warning>

Overleaf Community Edition предназначена для использования в средах, где **все** пользователи являются доверенными. Community Edition **не** подходит для сценариев, требующих изоляции пользователей, поскольку в ней недоступны Sandbox Compiles (изолированные компиляции).

Без изоляции компиляция LaTeX выполняется с теми же привилегиями, что и контейнер, что даёт доступ к его файловой системе, сети и переменным окружения. Это создаёт риск утечки данных или компрометации системы. Компиляцию без изоляции следует использовать только в полностью доверенных средах; для многопользовательских или production-развёртываний настоятельно рекомендуется использовать Sandbox Compiles.

Подробнее о Sandbox Compiles см.: [sandboxed-compiles.md](/ru/on-premises/configuration/overleaf-toolkit/sandboxed-compiles  "mention")

</Warning>

### Информация о Overleaf Server Pro и его стоимости

На сайте Overleaf есть только форма для связи с отделом продаж по Server Pro, поэтому информации о Server Pro очень мало. Но, по данным, собранным в сообществе, **условия для Server Pro таковы**:

* Необходимо приобрести лицензии _минимум_ на 10 человек.
* Лицензия на 10 человек стоит около €3 477,61 (2024).
* Для образовательных учреждений 20 пользователей стоят 2640 евро в год, 50 пользователей — 6050 евро, 100 пользователей — 9963 евро.
* Server Pro доступен только в отдельных регионах (например, недоступен в материковом Китае).

Судя по доступной на сегодня информации, Overleaf Server Pro стоит около \$300 на пользователя в год при минимальной покупке 10 лицензий, что делает его очень дорогим вариантом. Более того, Server Pro предлагает значительно меньше функций, чем Ayakaleaf Pro. Мы глубоко благодарны разработчикам сообщества, чей многолетний вклад позволил нам создать Ayakaleaf Pro и в итоге превзойти Overleaf Server Pro как по функциональности, так и по возможностям.

### Почему Ayakaleaf Pro?

<Info>

Ayakaleaf Pro _**не**_ связан с Overleaf, Inc. или её материнской компанией Digital Science. Это также _не редакция Server Pro_ — коммерческий продукт Overleaf, Inc. [ayaka-notes](https://github.com/ayaka-notes) разрабатывает и поддерживает Ayakaleaf Pro как независимый проект.

</Info>

Ayakaleaf Pro — расширенная реализация Overleaf Community Edition, предлагающая _**все**_ премиум-функции Server Pro _**бесплатно**_. В отличие от Overleaf Common, доступного на [https://www.overleaf.com/](https://www.overleaf.com/), или коммерческой редакции Server Pro, у нас:

* _**нет ограничений**_ на время компиляции
* _**нет лицензионных**_ требований к количеству пользователей
* _**все функции**_ Server Pro разблокированы
