---
title: Ограничения проектов
icon: list-check
---

| Функция                                          | Ограничение                                                                                                                                                             |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Тайм-аут компиляции                              | **По умолчанию:** 180 секунд. Сведения о настройке этого значения см. в разделе [Изменение тайм-аута компиляции проекта](/ru/on-premises/user-and-project-management/project-management). |
| Максимальное количество файлов в проекте         | 2000                                                                                                                                                                    |
| Максимальный объём редактируемых материалов в проекте | **По умолчанию:** 7 МБ. Сведения о настройке этого значения см. в разделе [Переменные окружения](/ru/on-premises/configuration/overleaf-toolkit/environment-variables). |
| Максимальный размер отдельного редактируемого текстового файла | 2 МБ\*                                                                                                                                                    |
| Максимальный размер одной загрузки               | 50 МБ (настраивается через `MAX_UPLOAD_SIZE`)                                                                                                                           |
| Максимальный размер загружаемого .zip после распаковки | 6 × `MAX_UPLOAD_SIZE` (по умолчанию 300 МБ)                                                                                                                      |
| Максимальный размер проекта                      | Не ограничен†                                                                                                                                                           |
| Максимальное количество проектов                 | Не ограничено                                                                                                                                                           |

\* В некоторых случаях файлы большего размера могут оставаться редактируемыми. Однако, чтобы файл гарантированно оставался редактируемым, ограничьте его размер 2 МБ.

† Общий размер проекта принудительно не ограничивается. Однако при работе с очень большими проектами вы можете столкнуться с некоторыми техническими ограничениями. Мы рекомендуем, чтобы размер проекта не превышал 500 МБ, или 100 МБ при использовании нашей [интеграции с Git](https://www.overleaf.com/learn/how-to/Git_integration). Проекты большего размера могут работать, но соблюдение этих ограничений обеспечит наилучший опыт работы.
