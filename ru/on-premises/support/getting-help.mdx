### Doctor

Overleaf Toolkit включает удобный скрипт `doctor`, помогающий при отладке. Запустите `bin/doctor`, и скрипт выведет сведения о хост-окружении, вашей конфигурации и зависимостях, необходимых Toolkit. Этот вывод также поможет нам диагностировать проблемы в ваших установках Ayakaleaf Pro.

<Info>

Пользователи Overleaf Pro могут [создать issue на GitHub](https://github.com/ayaka-notes/overleaf/issues).

Рекомендуем приложить к сообщению вывод скрипта `bin/doctor`.

</Info>

### Консультация с Doctor

Запустите скрипт doctor:

```bash title="Run doctor"
bin/doctor
```

### Информация о хосте

Раздел `Host Information` содержит сведения о машине, на которой работает Toolkit (например, дистрибутив Linux и его выпуск).

<Accordion title="Пример вывода Host Information">

```text
- Host Information
    - Linux
    - Output of 'lsb_release -a':
            No LSB modules are available.
            Distributor ID:	Ubuntu
            Description:	Ubuntu 22.04.5 LTS
            Release:	22.04
            Codename:	jammy
```

</Accordion>

### Зависимости

В разделе `Dependencies` перечислены инструменты, необходимые для работы Toolkit. Если инструмент установлен, он будет отмечен как `status: present` с информацией о версии. Если он отсутствует, он будет отмечен как `status: MISSING!`, а в конец вывода `doctor` будет добавлено предупреждение.

<Accordion title="Пример вывода зависимости (установлена)">

```text
- docker
    - status: present
    - version info: Docker version 28.0.4, build b8034c0
```

</Accordion>

<Accordion title="Пример вывода зависимости (отсутствует)">

```text
- docker
    - status: MISSING!
```

</Accordion>

Если какие-либо зависимости отсутствуют, Toolkit почти наверняка не будет работать.

### Конфигурация

Раздел `Configuration` содержит сведения о файлах в каталоге `config/`. Для `config/overleaf.rc` doctor выводит некоторые ключевые значения. Отсутствующие файлы будут отмечены как `status: MISSING!`, а в конец вывода `doctor` будет добавлено предупреждение.

<Accordion title="Пример вывода Configuration">

```text
====== Configuration ======
- config/version
    - status: present
    - version: 5.4.0
- config/overleaf.rc
    - status: present
    - values
        - OVERLEAF_DATA_PATH: /tmp/overleaf
        - SERVER_PRO: false
        - MONGO_ENABLED: false
        - REDIS_ENABLED: true
- config/variables.env
    - status: MISSING!
```

</Accordion>

Замечания к приведённому примеру:

* `OVERLEAF_DATA_PATH`, равный `/tmp/overleaf`, может быть небезопасным местом для хранения важных данных.
* `MONGO_ENABLED: false` означает, что Toolkit не будет разворачивать собственную MongoDB; при необходимости убедитесь, что `MONGO_URL` указывает на внешнюю MongoDB.
* В этом примере отсутствует `config/variables.env`.

### Предупреждения

Раздел `Warnings` содержит сводку проблем, обнаруженных скриптом doctor. Если проблем нет, это будет указано в данном разделе.

<Accordion title="Пример вывода Warnings">

```text
====== Warnings ======
- configuration file variables.env not found
- rc file, OVERLEAF_DATA_PATH not set
====== End =======
```

</Accordion>
