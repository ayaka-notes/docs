Развёртывание на Kubernetes считывает те же переменные окружения, что и Toolkit. Там, где на странице Toolkit сказано «добавьте это в `config/variables.env`», поместите значение в ConfigMap `overleaf-env` или в Secret `overleaf-secrets`, если это пароль, ключ или токен. Затем выполните перезапуск:

```bash
kubectl -n overleaf apply -f 30-config.yaml        # after editing the ConfigMap
kubectl -n overleaf patch secret overleaf-secrets --type merge \
  -p '{"stringData":{"GITHUB_TOKEN_CIPHER_PASSWORD":"'"$(openssl rand -hex 32)"'"}}'
kubectl -n overleaf rollout restart deployment/overleaf
```

Значения в `config/overleaf.rc` — это настройки Toolkit, а не переменные окружения; чем они заменяются, описано в разделе «Вопросы и ответы» в конце этой страницы.

### Сертификаты и другие файлы

Некоторые функции принимают путь к файлу вместо значения: сертификаты SAML (`OVERLEAF_SAML_IDP_CERT`, ...), CA для LDAP (`OVERLEAF_LDAP_TLS_OPTS_CA_PATH`) или частный CA для самостоятельно размещённого GitHub Enterprise, GitLab или Gitea (`NODE_EXTRA_CA_CERTS`). Поместите файлы в Secret и смонтируйте его туда, где их ожидают страницы Toolkit, — в `/var/lib/overleaf/certs`:

```bash
kubectl -n overleaf create secret generic overleaf-certs --from-file=idp_cert.pem --from-file=ca.pem
```

```yaml title="40-overleaf.yaml (additions)"
          volumeMounts:
            # ...
            - name: certs
              mountPath: /var/lib/overleaf/certs
              readOnly: true
      volumes:
        # ...
        - name: certs
          secret:
            secretName: overleaf-certs
```

Затем укажите пути к ним в ConfigMap, например `NODE_EXTRA_CA_CERTS: /var/lib/overleaf/certs/ca.pem`, и выполните перезапуск.

<Warning>

<strong>Пароли шифрования.</strong> Задайте в Secret все `*_CIPHER_PASSWORD` для используемых функций. В противном случае некоторые функции при первом использовании создают файл ключа на томе данных: с одной репликой это работает до потери тома, а при нескольких репликах каждая реплика шифровала бы данные своим ключом.

</Warning>

### Вопросы и ответы

<Accordion title="Какие настройки Toolkit из `config/overleaf.rc` мне нужны?">

<strong>Ответ:</strong> Ayakaleaf Pro не считывает ни одну из них. Их аналоги в Kubernetes:

| `config/overleaf.rc`                         | Kubernetes                                                        |
| -------------------------------------------- | ----------------------------------------------------------------- |
| `OVERLEAF_LISTEN_IP`, `OVERLEAF_PORT`        | Service (NodePort) или ваш ingress                                |
| `SIBLING_CONTAINERS_ENABLED`                 | `SANDBOXED_COMPILES*` в ConfigMap, сокет Docker в поде            |
| `GIT_BRIDGE_ENABLED`                         | [Интеграция с Git](/ru/on-premises/configuration/kubernetes/integrations/git-integration)                          |
| `MONGO_ENABLED`, `REDIS_ENABLED`, `MONGO_URL`, `REDIS_HOST` | StatefulSet-ы или ваши управляемые сервисы, `OVERLEAF_MONGO_URL` и `OVERLEAF_REDIS_HOST` |
| `REDIS_AOF_PERSISTENCE`                      | `--appendonly yes` в `20-redis.yaml`                              |
| `NGINX_ENABLED`, `TLS_*`                     | ваш ingress или балансировщик нагрузки                            |

</Accordion>
