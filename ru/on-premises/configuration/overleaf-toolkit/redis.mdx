### Включение аутентификации по паролю

Если вы используете внешний сервис Redis и вам нужно указать пароль, задайте переменные окружения `OVERLEAF_REDIS_PASS` и `REDIS_PASSWORD` в файле **config/variables.env** и выполните команду `bin/up -d`, чтобы пересоздать контейнер **sharelatex**.

Если вы используете локальный экземпляр Redis, необходимо настроить запуск сервиса **redis** с аутентификацией по паролю. После установки указанных выше переменных окружения выполните также следующие дополнительные шаги:

Создайте в каталоге **config/** файл **docker-compose.override.yml** со следующим содержимым:

```yaml title="config/docker-compose.override.yml"
services:
    redis:
        command: "redis-server --requirepass <YOUR-PASSWORD>"
```

<Warning>

Если у вас включено AOF-сохранение, необходимо добавить `--appendonly yes` в `command`.

</Warning>

Выполните `bin/up -d`, чтобы пересоздать контейнеры.

### Включение сохранения в режиме Append-Only File

(Оригинал: https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/redis#enabling-append-only-file-persistence)

Режим сохранения Redis AOF (Append-Only File) обеспечивает надёжную сохранность данных, записывая в журнал каждую операцию записи, полученную сервером. В отличие от снимков RDB, которые создают копии набора данных на определённый момент времени, AOF хранит полную запись всех изменений данных.

<Info>

Отключать RDB не обязательно. Как правило, рекомендуется использовать оба метода сохранения одновременно. Прежде чем вносить изменения в рабочей среде, изучите преимущества и недостатки совместного использования AOF и RDB.

</Info>

Подробнее о включении AOF-сохранения в Redis можно прочитать здесь: [https://redis.io/docs/latest/operate/oss\_and\_stack/management/persistence/#how-i-can-switch-to-aof-if-im-currently-using-dumprdb-snapshotsarrow-up-right](https://redis.io/docs/latest/operate/oss_and_stack/management/persistence/#how-i-can-switch-to-aof-if-im-currently-using-dumprdb-snapshotsarrow-up-right)

1. Запланируйте окно обслуживания для обновления.
2. Остановите экземпляр с помощью `bin/stop` и создайте резервную копию папок **config/** и **data/**.
3. Выполните `bin/up`, чтобы запустить экземпляр
4. Выполните команду `docker exec -it redis sh`
5. Выполните команду `redis-cli`, чтобы открыть интерфейс командной строки Redis
6. В redis-cli выполните команду `config set appendonly yes`
7. Теперь нужно дождаться, пока перезапись AOF завершит сохранение данных. Для этого введите в redis-cli `INFO persistence` и дождитесь, пока `aof_rewrite_in_progress` и `aof_rewrite_scheduled` станут равны `0`, а затем убедитесь, что `aof_last_bgrewrite_status` имеет значение `ok`.
8. Выйдите из redis-cli, введя `exit` и нажав клавишу Enter
9. Выйдите из контейнера redis, введя `exit` и нажав клавишу Enter
10. ​Выполните команду `ls ./data/redis` и убедитесь, что файл **appendonly.aof** присутствует
11. Отредактируйте файл **config/overleaf.rc** и измените значение переменной окружения `REDIS_AOF_PERSISTENCE` с `false` на `true`
12. Выполните `bin/up -d` и убедитесь, что приложение работает (редактор проектов и панель истории функционируют).
