### Настройка i18n в Overleaf

<Info>

В этом документе описано, как настроить интернационализацию (i18n) для самостоятельно размещаемого экземпляра **Overleaf**.

</Info>

Overleaf переведён на множество языков. При соответствующей настройке вы можете:

* Запустить экземпляр Overleaf на **одном фиксированном языке**, или
* Включить **несколько языков**, позволив пользователям динамически переключаться между ними, как на `www.overleaf.com`.

***

#### Настройка одного языка

Язык сайта задаётся переменной окружения `OVERLEAF_SITE_LANGUAGE` (или `SHARELATEX_SITE_LANGUAGE` для версий Overleaf **4.x и более ранних**).

Поддерживаемые коды языков:

* `en` - английский (по умолчанию)
* `es` - испанский
* `pt` - португальский
* `de` - немецкий
* `fr` - французский
* `cs` - чешский
* `nl` - нидерландский
* `sv` - шведский
* `it` - итальянский
* `tr` - турецкий
* `zh-CN` - китайский (упрощённый)
* `no` - норвежский
* `da` - датский
* `ru` - русский
* `ko` - корейский
* `ja` - японский
* `pl` - польский
* `fi` - финский

Английский — язык по умолчанию. Чтобы изменить язык интерфейса (например, на упрощённый китайский), добавьте следующую строку в `config/variables.env`:

```bash title="config/variables.env"
OVERLEAF_SITE_LANGUAGE=zh-CN
```

Затем примените конфигурацию:

```bash
bin/up
```

После перезапуска сервисов язык меню веб-интерфейса должен соответствовать новой настройке.

#### Настройка нескольких языков

Чтобы пользователи могли **переключать языки без выхода из системы**, ваш экземпляр Overleaf должен быть настроен на выдачу разных языков в зависимости от доменного имени.

В этом разделе предполагается, что:

* Ваш основной домен — `overleaftest.com`
* У вас есть **wildcard-сертификат TLS** (например, `*.overleaftest.com`)
* Вы **не используете `localhost`** (так как он не поддерживает маршрутизацию языков на основе поддоменов)

Для локального тестирования можно использовать домен вроде `dev-overleaf.com`.

<Steps>
<Step title="Настройка TLS-прокси (Nginx)">
Ваш обратный TLS-прокси должен передавать исходный заголовок `Host`, чтобы Overleaf мог определить, к какому языковому домену обратился пользователь.

Убедитесь, что присутствует следующая директива:

```nginx
proxy_set_header Host $host;
```

Пример конфигурации Nginx:

```nginx
server {
    listen 443 ssl;
    server_name    _; # Catch all, see http://nginx.org/en/docs/http/server_names.html
    server_name *.overleaftest.com;
    ssl_certificate /etc/nginx/ssl/nginx.crt;
    ssl_certificate_key /etc/nginx/ssl/nginx.key;
    ssl_protocols               TLSv1 TLSv1.1 TLSv1.2;
    ssl_prefer_server_ciphers   on;
    # used cloudflares ciphers https://github.com/cloudflare/sslconfig/blob/master/conf
    ssl_ciphers EECDH+CHACHA20:EECDH+AES128:RSA+AES128:EECDH+AES256:RSA+AES256:EECDH+3DES:RSA+3DES:!MD5;

    # config to enable HSTS(HTTP Strict Transport Security) https://developer.mozilla.org/en-US/docs/Security/HTTP_Strict_Transport_Security
    # to avoid ssl stripping https://en.wikipedia.org/wiki/SSL_stripping#SSL_stripping	
    add_header Strict-Transport-Security "max-age=31536000; includeSubdomains;";
    server_tokens off;
    add_header X-Frame-Options SAMEORIGIN;
    add_header X-Content-Type-Options nosniff;
    client_max_body_size 50M;

    location / {
        proxy_pass http://localhost:5000; # change to whatever host/port the docker container is listening on.
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 3m;
        proxy_send_timeout 3m;
        
        # add this to your nginx conf
        proxy_set_header Host $host;
    }
}
```
</Step>

<Step title="Настройка домена cookie">
Чтобы пользователи не выходили из системы при переключении языков, cookie должны быть общими для всех языковых поддоменов.

Добавьте следующую строку в `config/variables.env`:

```env title="config/variables.env"
# Note the leading dot
COOKIE_DOMAIN=.overleaftest.com
```

Это гарантирует, что cookie аутентификации действительны для всех поддоменов `overleaftest.com`.
</Step>

<Step title="Сопоставление языков и доменов">
Далее задайте сопоставление кодов языков и поддоменов с помощью\
`OVERLEAF_LANG_DOMAIN_MAPPING`.

#### Пример конфигурации

```dotenv title="config/variables.env" wrap
OVERLEAF_LANG_DOMAIN_MAPPING='{"www": {"lngCode": "en","url": "https:\/\/www.overleaftest.com"},"cn": {"lngCode": "zh-CN","url": "https:\/\/cn.overleaftest.com"}}'
```

При такой конфигурации:

* `https://www.overleaftest.com` → английский интерфейс
* `https://cn.overleaftest.com` → интерфейс на упрощённом китайском

При необходимости это сопоставление можно расширить, добавив другие языки и поддомены.
</Step>

<Step title="Перенаправление корневого домена">
Наконец, настройте перенаправление с корневого домена (`overleaftest.com`) на домен языка по умолчанию (`www.overleaftest.com`).

```nginx
server{
    listen 80;
    server_name overleaftest.com;
    return 301 https://www.overleaftest.com$request_uri;
}

server {
    listen 443 ssl http2;
    server_name overleaftest.com;
    ssl_certificate     /path/to/fullchain.cer;
    ssl_certificate_key /path/to/overleaftest.com.key;
    return 301 https://www.overleaftest.com$request_uri;
}
```
</Step>
</Steps>
