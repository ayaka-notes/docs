---
title: Ограничения паролей
icon: key
---

При использовании встроенной системы входа Overleaf для аутентификации можно задать ограничения для паролей учётных записей пользователей.

<Info>

Задать ограничения паролей для входа через SSO (LDAP/SAML 2.0) **невозможно**. Их необходимо настраивать в вашем поставщике удостоверений (IdP).

</Info>

Чтобы включить ограничения паролей, задайте соответствующие переменные окружения в файле `config/variables.env` в Toolkit.

| Название                                  | Описание | По умолчанию |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------: |
| `OVERLEAF_PASSWORD_VALIDATION_MIN_LENGTH` | **Минимально** допустимая длина. | `8` |
| `OVERLEAF_PASSWORD_VALIDATION_MAX_LENGTH` | **Максимально** допустимая длина. | `72` |
| `OVERLEAF_PASSWORD_VALIDATION_PATTERN`    | <p>Используется для проверки <strong>сложности</strong> пароля:</p><ul><li>`abc123` – пароль должен содержать 3 буквы и 3 цифры и быть длиной не менее 6 символов</li><li>`aA` – пароль должен содержать строчные и заглавные буквы и быть длиной 2 символа</li><li>`ab$3` – пароль должен содержать буквы, цифры и символы и быть длиной 4 символа</li><li>Существует 4 группы символов: буквы, ЗАГЛАВНЫЕ буквы, цифры, символы. Всё, что не является ни буквой, ни цифрой, считается символом.</li></ul> | — |
