У каждого проекта есть MCP-сервер, поэтому ИИ-клиенты, такие как Claude Code, Codex, Cursor, VS Code или Gemini CLI, могут работать над ним: читать и редактировать его файлы, компилировать проект, читать журнал LaTeX, скачивать PDF и отвечать на комментарии.

<Info>

Эта функция разработана в [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro). Она доступна начиная с версии v6.3.1.

</Info>

### Настройка

MCP-сервер входит в состав интеграции с Git: включите [git-bridge](/ru/on-premises/configuration/overleaf-toolkit/git-integration), и MCP-сервер тоже станет доступен. Больше ничего настраивать не нужно.

### Подключение ИИ-клиента

1. В **настройках учётной записи** (**Account Settings**) создайте токен аутентификации Git. Один и тот же токен используется и для MCP-сервера, и для Git.
2. В редакторе откройте **Integrations** и нажмите **MCP server**. Там показан адрес MCP-сервера проекта, `https://<your-overleaf>/project/<project_id>/mcp`, и способ добавить его в каждый ИИ-клиент: скопируйте команду и замените `<token>` своим токеном.

### Использование

После подключения обращайтесь к ИИ-клиенту обычными словами. Например:

| Ваш запрос | Что использует ИИ-клиент |
| --- | --- |
| _Исправь опечатки во введении._ | `read_file`, `edit_file`: правки сразу отображаются в редакторе |
| _Скомпилируй проект и исправь ошибки LaTeX._ | `compile`, `get_compile_log`, `edit_file` |
| _Ответь на открытые комментарии, затем отметь их как решённые._ | `list_comments`, `reply_to_comment`, `resolve_comment` |
| _Переключись на XeLaTeX и скачай PDF._ | `update_settings`, `compile`, `get_output_file_link` |

### Инструменты

| Группа | Инструменты |
| --- | --- |
| Проект | `get_clone_info`, `get_settings`, `update_settings`, `list_versions` |
| Файлы | `list_files`, `read_file`, `edit_file`, `write_file`, `delete_file` |
| Компиляция | `compile`, `get_compile_log`, `get_output_file_link`, `word_count` |
| Комментарии | `list_comments`, `reply_to_comment`, `resolve_comment`, `reopen_comment` |

Правки, внесённые с помощью `edit_file` и `write_file`, сразу отображаются в редакторе и объединяются с правками соавторов. Для изменения сразу многих файлов, работы с бинарными файлами или переименований ИИ-клиент также может клонировать проект с помощью Git и выполнить push.

### Права доступа

MCP-сервер, как и Git, следует настройкам совместного доступа к проекту:

* Все, кто может просматривать проект, могут читать его, компилировать и скачивать результаты компиляции.
* Изменять файлы и настройки проекта могут только владелец и редакторы.
* Рецензенты также могут отвечать на комментарии, а также отмечать как решённые или повторно открывать начатые ими комментарии.
* Пользователи с правами на просмотр, присоединившиеся по ссылке, не видят комментарии, как и в редакторе.
