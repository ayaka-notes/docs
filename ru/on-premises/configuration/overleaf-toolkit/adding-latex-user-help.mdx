title: Добавление справки по LaTeX для пользователей
icon: graduation-cap
---

Вы можете открыть доступ к страницам [Learn](https://www.overleaf.com/learn) от Overleaf в вашем экземпляре Overleaf Pro: просто добавьте `OVERLEAF_PROXY_LEARN=true` в файл `config/variables.env` в Toolkit и выполните команду `bin/up`.

Это позволит пользователям получать доступ к актуальной документации и учебным материалам, нажав кнопку **Documentation** в меню навигации, не покидая ваш экземпляр.

<Info>

По умолчанию открыть `/learn` могут только вошедшие в систему пользователи. Чтобы сделать страницу доступной для посетителей без входа, также установите `OVERLEAF_ALLOW_PUBLIC_ACCESS=true`, см. [Page Access](/ru/on-premises/configuration/overleaf-toolkit/public-access#page-access  "mention").

</Info>

<Info>

Для развёртываний с Docker Compose необходимо добавить переменную окружения `OVERLEAF_PROXY_LEARN: true` в раздел **environment** сервиса `sharelatex` в файле `docker-compose.yml`.

</Info>

<Info>

Вашему развёртыванию Server Pro потребуется доступ в интернет, чтобы выполнять внешние `GET`-запросы к [https://learn.sharelatex.com](https://docs.overleaf.com/on-premises/welcome).

</Info>

<Danger>

При первом включении этой опции и перезапуске Docker-контейнера Overleaf системе необходимо загрузить соответствующую Wiki, что может занять 5 минут или больше. Только после завершения загрузки вы сможете увидеть страницу входа Overleaf.

</Danger>
