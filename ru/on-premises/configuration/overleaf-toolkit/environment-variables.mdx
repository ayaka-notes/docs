На этой странице описаны переменные окружения, поддерживаемые в файле `config/variables.env` для развёртываний с помощью Toolkit.

Файл `config/variables.env` состоит из определений переменных вида `NAME=value`; строки, начинающиеся с `#`, считаются комментариями.

<Info>

После любых изменений в `overleaf.rc` или `variables.env` необходимо пересоздать Docker-контейнеры, выполнив `bin/up`.

</Info>

### Все версии

Эти переменные окружения совместимы с Server CE и Server Pro и обеспечивают простой путь миграции между этими двумя локальными версиями. Их также можно использовать как в развёртываниях с Toolkit, так и в развёртываниях с Docker Compose.

<Info>

Ранее эти переменные окружения имели префикс `SHARELATEX_` вместо `OVERLEAF_`.

</Info>

<Info>

При использовании системы входа Overleaf (локальных учётных записей), а не варианта SSO, такого как LDAP, можно применять к пользователям ограничения на пароли. Для учётных записей SSO политики паролей применяются вашим поставщиком удостоверений или службой каталогов, что дополнительно позволяет поддерживать многофакторную аутентификацию.

</Info>
