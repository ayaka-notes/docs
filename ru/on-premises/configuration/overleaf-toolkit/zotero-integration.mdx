### Настройка интеграции с Zotero

1. Откройте [эту ссылку](https://www.zotero.org/oauth/apps), чтобы создать OAuth-клиент Zotero (как показано на изображении)
2. Выберите **Application Type**: **Browser**
3. Укажите Callback URL: `${OVERLEAF_SITE_URL}/user/zotero/oauth/callback`
4. Настройте файл `config/variables.env`

<Frame>
  <img src="/images/on-premises/image-41.png" alt="" width="375" />
</Frame>

```dotenv title="config/variables.env"
#################
#    Zotero     #
#################
# 'zotero' must be in ENABLED_LINKED_FILE_TYPES (set in develop/docker-compose.yml)
ENABLED_LINKED_FILE_TYPES=project_file,project_output_file,url,zotero

# From a Zotero OAuth client (register at https://www.zotero.org/oauth/apps)
# Application Type: Browser 
# Callback URL -> ${OVERLEAF_SITE_URL}/user/zotero/oauth/callback
ZOTERO_CLIENT_ID=
ZOTERO_CLIENT_SECRET=
# Encrypts the Zotero API key in mongo (set in dev to avoid writing a key file
# to /var/lib/overleaf/data, which the dev web container can't create)
# How to generate: `openssl rand -hex 32`
ZOTERO_CIPHER_PASSWORD=dev-zotero-cipher-password
# Optional: route the module's server-side Zotero requests (OAuth + API) through
# an HTTP proxy (must be reachable from the web container; same as github-sync)
# http://10.0.0.1:10808
# (Optional) ZOTERO_PROXY_URL=
```

### Примечания

<Warning>

При обновлении существующей установки со связанными файлами библиографии Zotero до повторно выпущенной версии 6.3.0 следуйте [инструкциям по миграции Zotero / Mendeley](/ru/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention"). Для новых установок эта миграция не требуется.

</Warning>

<Danger>

Поскольку Ayakaleaf — платформа для совместной работы, в целях повышения безопасности, начиная с версии 6.3.0, обновлять импортированный файл библиографии `bib` может только его первоначальный создатель.

</Danger>

Например, предположим, что владелец проекта, пользователь A, включает доступ по ссылке и создаёт в проекте файл `test.bib`, связывая его со своей учётной записью Zotero. Если другой пользователь, пользователь B, откроет проект по общей ссылке, он по-прежнему сможет читать и скачивать `test.bib`, но не сможет обновлять файл или повторно импортировать его из Zotero. Выполнять обновления может только пользователь A как первоначальный создатель файла библиографии. Иными словами, право на обновление файла `.bib` есть только у его первоначального создателя.
