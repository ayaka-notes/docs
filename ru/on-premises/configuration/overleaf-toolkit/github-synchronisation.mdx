### Настройка синхронизации с GitHub

<Warning>

Перед использованием синхронизации с GitHub необходимо сначала включить [git-bridge](/ru/on-premises/configuration/overleaf-toolkit/git-integration).

```dotenv title="config/overleaf.rc"
GIT_BRIDGE_ENABLED=true
```

</Warning>

Перейдите в [настройки разработчика](https://github.com/settings/developers), чтобы создать OAuth-приложение GitHub, и скопируйте ваши `CLIENT_ID` и `SECRET`.

**Примечание**: ваш URL обратного вызова OAuth: `${OVERLEAF_SITE_URL}/user/github-sync/oauth2/callback`.

Затем добавьте следующие настройки в файлы переменных окружения Overleaf.

```dotenv title="config/variables.env" wrap
# used to encrypt the user's GitHub access token.
# How to generate: `openssl rand -hex 32`
GITHUB_TOKEN_CIPHER_PASSWORD=0123456789ABCDEFG # changed to yours

# Github Sync Settings
GITHUB_SYNC_ENABLED=true
GITHUB_SYNC_CLIENT_ID=
GITHUB_SYNC_CLIENT_SECRET=

# OAuth callback is: ${OVERLEAF_SITE_URL}/user/github-sync/oauth2/callback
# (Optional) GITHUB_SYNC_PROXY_URL=http://10.0.0.1:10808
```

<Warning>

Перед настройкой URL обратного вызова OAuth в GitHub убедитесь, что `OVERLEAF_SITE_URL` задан правильно.

</Warning>

Если вы находитесь в материковом Китае, для доступа к GitHub может потребоваться прокси. Задайте следующую переменную окружения: `GITHUB_SYNC_PROXY_URL=http://10.0.0.1:10808`.

<Warning>

Не используйте `127.0.0.1` в качестве хоста прокси. Если прокси работает на хост-сервере, используйте IP-адрес сервера в локальной сети (например, `192.168.1.xx`) и убедитесь, что прокси настроен на приём подключений от устройств локальной сети.

</Warning>
