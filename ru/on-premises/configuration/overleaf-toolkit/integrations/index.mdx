Все интеграции по умолчанию отключены, кроме Overleaf Import API. Для синхронизации с GitHub, GitLab, Gitea и Dropbox, а также для MCP-сервера также требуется [интеграция с Git](/ru/on-premises/configuration/overleaf-toolkit/integrations/git-integration). После включения интеграции пересоздайте контейнеры командой `bin/up -d`.
