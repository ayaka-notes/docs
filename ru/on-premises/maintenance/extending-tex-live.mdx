Существующий образ TeX Live можно расширить с помощью нового Dockerfile и настроить приложение на использование нового образа.

Ниже приведены рекомендации по установке новых пакетов или шрифтов.

Образы TeX Live обновляются нечасто. Мы рекомендуем пересобирать пользовательские образы при обновлении Ayakaleaf Pro.

<Danger>

Следующие разделы относятся только к [Sandboxed Compiles](/ru/on-premises/configuration/overleaf-toolkit/sandboxed-compiles).

</Danger>

### Установка и обновление пакетов

Для управления пакетами TeX Live можно использовать команды `tlmgr`, такие как `tlmgr install` и `tlmgr update`, как показано в следующем примере:

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2023.1

RUN tlmgr update --force ebproof
```

### Использование `tlmgr` в более старом образе TeX Live

По умолчанию `tlmgr` загружает ресурсы из последнего выпуска TeX Live. При доработке более старого образа TeX Live загрузку необходимо переключить на соответствующий архив. Список зеркал архивов приведён на странице [https://www.tug.org/historic/](https://www.tug.org/historic/).

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2022.1

RUN tlmgr option repository <MIRROR>/systems/texlive/<YEAR>/tlnet-final
# e.g. RUN tlmgr option repository ftp://tug.org/historic/systems/texlive/2022/tlnet-final

RUN tlmgr update --force ebproof
```

### Установка новых шрифтов

Существуют разные способы установки новых шрифтов в дистрибутив TeX Live, и установка пользовательского шрифта может потребовать нескольких шагов. Хорошей отправной точкой, вероятно, станут [инструкции по установке шрифтов TeX](https://tug.org/fonts/fontinstall.html) в официальной документации TeX Live.

Следующий `Dockerfile` показывает пример установки шрифта TrueType поверх существующего образа TeX Live 2022:

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2022.1

COPY ./myfonts/*.ttf /usr/share/fonts/truetype/myfont/

# rebuild font information cache
RUN fc-cache
```

### Настройка Ayakaleaf Pro на использование новых образов

Соберите новый образ, используя имя `ghcr.io/ayaka-notes/texlive-full` и собственный тег, например:

```bash
docker build -t ghcr.io/ayaka-notes/texlive-full:2023.1-custom .
```

Теперь можно настроить Ayakaleaf Pro на использование нового образа `2023.1-custom`, обновив переменные окружения `TEX_LIVE_DOCKER_IMAGE`, `ALL_TEX_LIVE_DOCKER_IMAGES` и `ALL_TEX_LIVE_DOCKER_IMAGE_NAMES` (имена необязательны и следуют в том же порядке, что и образы):

```text wrap
TEX_LIVE_DOCKER_IMAGE: "ghcr.io/ayaka-notes/texlive-full:2023.1-custom"
ALL_TEX_LIVE_DOCKER_IMAGES: "ghcr.io/ayaka-notes/texlive-full:2023.1,ghcr.io/ayaka-notes/texlive-full:2023.1-custom"
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES: "TeX Live 2023,TeX Live 2023 custom"
```

В приведённом примере новые проекты по умолчанию будут использовать новый образ `2023.1-custom`, а образ `2023.1` по-прежнему останется доступным при необходимости.

Пользовательский образ существует только на вашем хосте, поэтому `bin/up` не может его загрузить. Задайте `SIBLING_CONTAINERS_PULL=false` в `config/overleaf.rc` (остальные образы загружайте самостоятельно командой `docker pull`), затем выполните `bin/up -d`, чтобы применить новые настройки.

### Вопросы и ответы

<Accordion title="Нужно ли устанавливать китайские шрифты, чтобы компилировать китайские документы с XeLaTeX?">

<strong>Ответ:</strong> Нет, при использовании образов `texlive-full` — не нужно. Они включают китайские пакеты TeX Live (`ctex`, `xeCJK`) со шрифтами Fandol, а также шрифты Noto CJK (например, `Noto Serif CJK SC`). Выберите XeLaTeX в качестве компилятора проекта в настройках редактора и выполните компиляцию, например:

```latex
\documentclass{ctexart}
\begin{document}
你好，世界！
\end{document}
```

Чтобы использовать Noto вместо Fandol, добавьте `\setCJKmainfont{Noto Serif CJK SC}`. Файл `latexmkrc` не нужен. Для других шрифтов соберите собственный образ, как показано в разделе [Установка новых шрифтов](#installing-new-fonts).

</Accordion>
