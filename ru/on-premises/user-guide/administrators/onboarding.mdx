Выполните это один раз сразу после [установки](/ru/on-premises/installation/introduction). На этой странице используется вход по паролю, заданный по умолчанию.

<Steps>
<Step id="open-the-launchpad" title="Откройте launchpad">
Откройте `/launchpad` на своём экземпляре, например `http://localhost/launchpad`. Вы увидите **Create the first Admin account**.

Форма доступна только до тех пор, пока не создан первый администратор. После этого посетители без входа перенаправляются на страницу входа.
</Step>

<Step id="create-the-administrator-account" title="Создайте учётную запись администратора">
Введите адрес электронной почты и пароль, затем нажмите **Register**.

<Frame caption="Первая учётная запись администратора">
  <img src="/images/on-premises/onboarding-launchpad-filled.png" alt="Форма launchpad, заполненная адресом admin@example.com" />
</Frame>

Если пароль отклонён, над формой появляется сообщение, и учётная запись не создаётся.

<Frame caption="Отклонённый пароль">
  <img src="/images/on-premises/onboarding-password-error.png" alt="Сообщение password is too short над формой launchpad" />
</Frame>

| Сообщение                                  | Значение                                                                                                                                                                  |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `password is too short`                    | Меньше 8 символов.                                                                                                                                                        |
| `password is too long`                     | Больше 72 символов.                                                                                                                                                       |
| `password contains an invalid character`   | Допустимы буквы `a-z` и `A-Z`, цифры и `@#$%^&*()-_=+[]{};:<>/?!£€.,`. Пробелы, буквы с диакритикой и нелатинские буквы недопустимы.                                     |
| `password contains part of email address`  | Пароль содержит адрес почты или часть до `@` либо сам является частью адреса. Для `admin@example.com` отклоняются и `admin-7Tq9-demo`, и `example.com`.                  |
| `password is too similar to email address` | Пароль слишком похож на адрес почты, например `adm1n@example.c0m`.                                                                                                       |

По умолчанию заглавные буквы, цифры и символы не обязательны. Чтобы изменить ограничения длины, см. [Ограничения паролей](/ru/on-premises/configuration/overleaf-toolkit/authentication/password-restrictions).
</Step>

<Step id="log-in" title="Войдите">
После **Register** откроется страница входа. Введите тот же адрес и пароль, затем нажмите **Login**.

<Frame caption="Вход с новой учётной записью">
  <img src="/images/on-premises/onboarding-login.png" alt="Страница входа, заполненная адресом admin@example.com" />
</Frame>

Вы снова на launchpad, теперь с разделом **Status Checks**.
</Step>

<Step id="check-the-instance" title="Проверьте экземпляр">
`websockets` должен показывать **OK**.

Чтобы проверить почту, введите свой адрес в **Send a test email**, нажмите **Send** и проверьте входящие.

<Frame caption="Проверки состояния и тестовое письмо">
  <img src="/images/on-premises/onboarding-launchpad-checks.png" alt="Launchpad с websockets OK, формой тестового письма с надписью Email Sent и двумя кнопками внизу" />
</Frame>

<Warning>

**Email Sent** не доказывает, что письмо покинуло сервер. Без [доставки почты](/ru/on-premises/configuration/overleaf-toolkit/email-delivery) страница показывает тот же текст, но ничего не приходит.

</Warning>

**Start Using** _название вашего сайта_ открывает ваши проекты. **Go To Admin Panel** открывает инструменты сайта, см. [Базовое управление](/on-premises/user-guide/administrators/basic-management).
</Step>

<Step id="create-the-first-user" title="Создайте первого пользователя">
В верхнем меню нажмите **Admin**, затем **Manage Users**.

<Frame caption="Меню Admin">
  <img src="/images/on-premises/onboarding-admin-menu.png" alt="Меню Admin с пунктами Manage Site, Manage Users и Project/Object Lookup" />
</Frame>

Нажмите **Create account**.

<Frame caption="Список пользователей">
  <img src="/images/on-premises/onboarding-user-list.png" alt="Список пользователей с администратором и кнопкой Create account" />
</Frame>

Введите адрес почты пользователя. **First name** и **Last name** необязательны. Отмечайте **Admin** только для ещё одного администратора. Нажмите **Create**.

<Frame caption="Диалог Create account">
  <img src="/images/on-premises/onboarding-create-account.png" alt="Диалог Create account, заполненный адресом user@example.com" />
</Frame>

Затем диалог показывает новую учётную запись и ссылку активации, которая действует 7 дней:

* **Email Sent** означает, что письмо активации отправлено.
* <strong>No email was sent. Copy the link and pass it on.</strong> означает, что письмо не отправлено, например потому что [доставка почты](/ru/on-premises/configuration/overleaf-toolkit/email-delivery) не настроена.

<Frame caption="Новая учётная запись и её ссылка активации">
  <img src="/images/on-premises/onboarding-account-created.png" alt="Диалог Create account для Demo User с предупреждением, что письмо не отправлено, ссылкой, значком копирования и Expires in 7 days" />
</Frame>

Нажмите **Close**. Учётная запись появится в списке со статусом **Pending**.

<Frame caption="Новая учётная запись остаётся Pending до первого входа">
  <img src="/images/on-premises/onboarding-user-pending.png" alt="Список пользователей с Demo User в статусе Pending" />
</Frame>
</Step>

<Step id="give-the-user-access" title="Предоставьте пользователю доступ">
**Если доставка почты настроена**, пользователь получает письмо активации со ссылкой **Set password**. Ссылка открывает эту страницу. Пользователь вводит пароль, нажимает **Activate** и попадает на страницу проектов. Действуют правила для паролей, описанные выше.

<Frame caption="Что видит пользователь после перехода по ссылке">
  <img src="/images/on-premises/onboarding-activate.png" alt="Страница активации с просьбой задать пароль" />
</Frame>

**Если доставки почты нет**, передайте ссылку сами. Нажмите значок копирования в диалоге после **Create** и отправьте ссылку пользователю, который задаст пароль, как описано выше.

Если вы закрыли диалог или срок действия ссылки истёк, нажмите значок конверта в строке пользователя в **Manage Users**, затем **Send activation email**. Диалог покажет новую ссылку, которая действует 7 дней.

<Frame caption="Новая ссылка активации">
  <img src="/images/on-premises/onboarding-activation-link.png" alt="Диалог Send activation email для Demo User с предупреждением, что письмо не отправлено, ссылкой, значком копирования и Expires in 7 days" />
</Frame>

Вы также можете задать пароль сами. В **Manage Users** нажмите имя пользователя, затем значок карандаша. Введите **New password** и нажмите **Save**. Передайте пароль пользователю, который входит на `/login`.

<Frame caption="Установка пароля на вкладке Account">
  <img src="/images/on-premises/onboarding-set-password.png" alt="Вкладка Account пользователя в режиме редактирования с заполненным полем New password" />
</Frame>
</Step>

<Step id="confirm-it-worked" title="Убедитесь, что всё работает">
После первого входа пользователя статус в **Manage Users** меняется на **Active**.

<Frame caption="Пользователь вошёл">
  <img src="/images/on-premises/onboarding-user-active.png" alt="Список пользователей с Demo User в статусе Active" />
</Frame>
</Step>
</Steps>

<Info>

По умолчанию **Sign up** не создаёт учётные записи: страница просит посетителей связаться с адресом из `OVERLEAF_ADMIN_EMAIL`. Чтобы разрешить самостоятельную регистрацию, см. [Публичный доступ](/ru/on-premises/configuration/overleaf-toolkit/authentication/public-access).

</Info>
