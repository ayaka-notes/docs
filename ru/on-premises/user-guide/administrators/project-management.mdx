## Найти проект {#find-a-project}

Введите текст в **Search by project name, ID, owner or link**. Ссылкой может быть адрес проекта или одна из его ссылок для совместного доступа. Чтобы сузить список, используйте фильтр **Status**. Для сортировки нажмите **Title** или **Last modified**.

Удалённые проекты не попадают в результаты. Если поиск совпадает и с удалённым проектом, над таблицей появляется строка об этом, например **Found 1 matching deleted projects**. Нажмите **Display deleted projects**, чтобы их увидеть.

## Статус проекта {#project-status}

У каждого проекта один статус, а фильтр **Status** показывает, сколько проектов в каждом из них.

<Frame caption="Фильтр Status">
  <img src="/images/on-premises/project-management-status-filter.png" alt="Фильтр Status с вариантами All, Active, Archived, Trashed и Deleted" />
</Frame>

| Статус | Что означает |
| --- | --- |
| **All** | Все проекты, которые не удалены. |
| **Active** | Обычное состояние. |
| **Archived** | Владелец заархивировал проект. Проект цел, и его можно вернуть. |
| **Trashed** | Владелец переместил проект в корзину. Проект цел, и его можно вернуть. |
| **Deleted** | Удалён владельцем из корзины, администратором или вместе с учётной записью владельца. Вернуть его может только администратор. |

Проект проходит статусы поэтапно:

1. **Active, Archived и Trashed** выбирает владелец на своей странице проектов. Владелец всегда может вернуться назад. **Restore** из корзины всегда ведёт в Active, даже если проект до этого был заархивирован.
2. **Deleted** является следующим этапом. Владелец может удалить проект только из корзины; администратор может удалить его из любого из трёх статусов.
3. **Restore** возвращает удалённый проект в статус **Active**, каким бы ни был его прежний статус, а к его имени в конце добавляется `(Restored)`. Это может сделать только администратор. Если учётная запись владельца тоже удалена, сначала восстановите её: иначе диалог сообщит **The owner of this project is deleted: restore the owner first**.
4. **Delete permanently** является последним этапом, и его нельзя отменить. В остальных случаях удалённые проекты хранятся, пока вы их не удалите, если только в экземпляре не задана [`ENABLE_CRON_RESOURCE_DELETION`](/ru/on-premises/configuration/overleaf-toolkit/environment-variables), которая удаляет их через 90 дней.

<Info>

Статус зависит только от владельца. Когда соавтор архивирует общий проект или перемещает его в корзину, проект перемещается только на странице проектов этого соавтора, а статус здесь не меняется.

</Info>

## Действия с проектом {#actions-on-a-project}

| Значок | Действие | Что делает |
| --- | --- | --- |
| Открыть | **Open Project** | Открывает проект в редакторе в новой вкладке. |
| Папка | **Change project owner** | Передаёт проект другому пользователю. |
| Корзина | **Delete** | Переводит проект в **Deleted**. |
| Стрелка | **Restore** | Возвращает удалённый проект. Только для удалённых проектов. |
| Перечёркнутая корзина | **Delete permanently** | Окончательно удаляет удалённый проект. Только для удалённых проектов. |

### Сменить владельца {#change-the-owner}

Нажмите значок папки, введите имя или адрес почты, выберите пользователя, затем нажмите **Change project owner**. Диалог предупреждает, что это действие нельзя отменить и что новый владелец получит уведомление и сможет менять настройки доступа к проекту. Отключённые учётные записи не предлагаются. Если после выбора изменить текст, выбор сбрасывается: выберите пользователя снова.

  <img src="/images/on-premises/project-management-change-owner.png" alt="Диалог Change project owner с предупреждением и выбранным новым владельцем" />

Чтобы перенести сразу все проекты пользователя, см. [Передать проекты пользователя](/ru/on-premises/user-guide/administrators/user-management#transfer-a-users-projects).

### Удалить, восстановить или удалить окончательно {#delete-restore-or-permanently-delete}

Нажмите значок корзины, затем **Delete**. Чтобы снова найти проект, выберите **Deleted** в фильтре **Status**.

<Frame caption="Удалённый проект">
  <img src="/images/on-premises/project-management-deleted.png" alt="Удалённый проект в списке со значками Restore и Delete permanently" />
</Frame>

Нажмите значок стрелки, затем **Restore**, чтобы вернуть проект, или перечёркнутую корзину, затем **Delete permanently**, чтобы удалить его.

<Frame caption="Окончательное удаление проекта">
  <img src="/images/on-premises/project-management-purge.png" alt="Диалог Delete permanently с предупреждением, что действие нельзя отменить" />
</Frame>

### Изменить несколько проектов сразу {#change-several-projects-at-once}

Отметьте проекты в списке. Рядом с поиском появятся кнопки **Download**, **Change project owner** и **Delete**. **Download** сохраняет выбранные проекты в один файл `.zip`. В **Change project owner** нельзя выбрать текущих владельцев отмеченных проектов. В представлении **Deleted** кнопки называются **Restore** и **Delete permanently**.

<Frame caption="Массовые действия">

</Frame>

## Страница проекта {#the-project-page}

Нажмите название проекта, чтобы открыть его страницу. Вверху находятся значки для редактирования, открытия, скачивания и удаления проекта. На странице пять вкладок.

### Обзор {#overview}

Сведения о проекте и его настройки. Нажмите значок карандаша, чтобы изменить **Name**, **Link sharing**, **Compiler**, **TeX Live version** и **Main document** или нажать **Change project owner**. Затем нажмите **Save**.

### Участники {#members}

У кого есть доступ: владелец, соавторы и ожидающие приглашения. Нажмите значок карандаша, чтобы изменить их:

* Выберите **Editor**, **Reviewer** или **Viewer** для соавтора. Изменение применяется сразу.
* Нажмите корзину рядом с соавтором, затем **Remove access**.
* Для ожидающего приглашения нажмите конверт, чтобы выполнить **Resend invite**, или корзину, чтобы выполнить **Revoke Invite**.

Закончив, нажмите **Done**. Владельца здесь сменить нельзя: используйте **Change project owner** на вкладке **Overview**.

</Frame>

### Удалённые файлы {#deleted-files}

Файлы, удалённые из проекта. Нажмите значок стрелки рядом с файлом, затем **Restore file**. Копия с датой в имени помещается в корневую папку проекта, а в строке отображается её имя. Удалённый файл остаётся в списке.

Копия появится на вкладке **File tree** после перезагрузки страницы.
