Поиск литературы просматривает все файлы `.bib` вашего проекта, поэтому источник можно найти, не помня его ключ цитирования. Ничего настраивать не нужно.

В проекте должен быть хотя бы один файл `.bib`. Можно загрузить его или импортировать библиотеку из [Zotero](/ru/on-premises/user-guide/users/zotero-integration) или [Mendeley](/ru/on-premises/user-guide/users/mendeley-integration).

## Вставить цитату {#insert-a-citation}

<Steps>
<Step title="Начните цитату">
В файле `.tex` введите `\cite{`. Редактор добавит закрывающую скобку. Под курсором появятся ключи цитирования и синее поле **Open advanced reference search**.

<Frame caption="Синее поле под цитатой">
  <img src="/images/on-premises/reference-search-hint.png" alt="Редактор с \cite{}, списком ключей цитирования и синим полем с кнопкой Search" />
</Frame>

Кнопка **Insert citation** на панели инструментов, а также **Insert**, затем **Citation**, тоже начинают `\cite{}` за вас. Поле появляется и для других команд цитирования, например `\citep`, `\autocite`, `\parencite` и `\textcite`.
</Step>

<Step title="Откройте поиск">
Нажмите **Search** в синем поле или нажмите Ctrl+Space между фигурными скобками. В диалоге перечислены все записи с названием, ключом цитирования, автором, журналом и годом.

<Frame caption="Все записи проекта">
  <img src="/images/on-premises/reference-search-dialog.png" alt="Диалог Search the .bib files in this project с пятью записями" />
</Frame>
</Step>

<Step title="Найдите запись">
Введите текст в поле поиска. Поиск идёт по ключу цитирования, автору, названию, журналу и году, а найденное выделяется. Совпасть должно каждое слово, поэтому `turing 1936` находит статью Тьюринга 1936 года. Другие поля, например издатель, не просматриваются.

<Frame caption="Поиск по автору и году">
  <img src="/images/on-premises/reference-search-filter.png" alt="Поле поиска с turing 1936 и одна запись с совпадениями, выделенными красным" />
</Frame>
</Step>

<Step title="Выберите одну или несколько записей">
Нажмите на запись. Она станет зелёной, а её ключ появится над списком. Чтобы добавить ещё одну, нажмите на неё или выполните поиск снова: выбранное сохраняется. Чтобы убрать запись, нажмите на неё ещё раз или на <strong>×</strong> рядом с её ключом.

<Frame caption="Две выбранные записи">
  <img src="/images/on-premises/reference-search-selected.png" alt="Ключи knuth1984 и einstein1905 над списком и их записи, выделенные зелёным" />
</Frame>
</Step>

<Step title="Нажмите Insert">
Ключи появятся между фигурными скобками через запятую. Если в документе ещё нет списка литературы, добавьте эти строки перед `\end{document}`, указав имена файлов `.bib` без расширения:

```latex
\bibliographystyle{plain}
\bibliography{refs,more}
```

Нажмите **Recompile**. Источники появятся в PDF.

<Frame caption="Скомпилированная цитата">
  <img src="/images/on-premises/reference-search-compiled.png" alt="Редактор с \cite{knuth1984, einstein1905} и PDF с обоими источниками" />
</Frame>
</Step>
</Steps>

В редакторе **Visual** поиск работает так же.

## Изменить цитату {#change-a-citation}

<strong>Добавить источник:</strong> поставьте курсор между фигурными скобками существующей цитаты и откройте поиск. **Insert** добавит новые ключи после уже имеющихся.

<strong>Заменить источники:</strong> выделите ключи в редакторе и нажмите Ctrl+Space. Ключи появятся над списком, а на кнопке будет написано **Replace**. Уберите ненужные, добавьте другие и нажмите **Replace**. Ключ, которого нет ни в одном файле `.bib`, остаётся, пока вы его не уберёте.

</Frame>

## Работа с клавиатурой {#use-the-keyboard}

| Клавиша | Действие |
| --- | ------------ |
| **Стрелка вниз** | Переходит из поля поиска в список, затем вниз по списку |
| **Стрелка вверх** | Перемещает вверх по списку |
| **Пробел** | Выбирает запись или убирает её из выбранного |
| **Enter** | Вставляет выбранное, когда вы находитесь в списке |
| **Tab** | Переключает между полем поиска, списком и кнопками |
| **Esc** | Закрывает диалог без изменений |

## Откуда берутся записи {#where-the-entries-come-from}

Поиск охватывает все файлы `.bib` проекта, включая импортированные из Zotero или Mendeley. Когда вы редактируете файл `.bib`, следующий поиск находит новые записи.

## Если что-то пошло не так {#if-something-goes-wrong}

| Что вы видите | Причина | Что сделать |
| ------------ | --- | ---------- |
| Список в диалоге пуст | В проекте нет файла `.bib` | Загрузите или создайте его |
| Нет синего поля, а Ctrl+Space показывает команды LaTeX | Курсор находится не между фигурными скобками цитаты | Щёлкните между скобками |
| Ctrl+Space ничего не делает | Компьютер использует это сочетание для другого | Нажмите **Search** в синем поле |
| Запись не находится | Поиск охватывает только ключ, автора, название, журнал и год | Ищите по одному из этих полей |
