## Импорт документа {#import-a-document}

Так вы создаёте новый проект LaTeX из документа Word (`.docx`) или файла Markdown (`.md`). Имя проекта берётся из имени файла.

<Steps>
<Step title="Откройте диалог импорта">
На странице проектов нажмите **New project**. В разделе **Import** нажмите **Word document** или **Markdown document**.

<Frame caption="Меню New project">
  <img src="/images/on-premises/word-import-menu.png" alt="Меню New project с пунктами Word document и Markdown document в разделе Import" />
</Frame>
</Step>

<Step title="Выберите файл">
Нажмите **Select .docx file** или перетащите файл в диалог. Для Markdown кнопка называется **Select .md file**. Импорт начинается сразу.

<Frame caption="Выбор документа Word">
  <img src="/images/on-premises/word-import-dialog.png" alt="Диалог Choose Word document с кнопкой Select .docx file" />
</Frame>
</Step>

<Step title="Начните редактирование">
Новый проект открывается с сообщением **Document ready for editing**. Нажмите **Start editing**.

<Frame caption="Импорт завершён">
  <img src="/images/on-premises/word-import-ready.png" alt="Диалог Document ready for editing с кнопкой Start editing" />
</Frame>
</Step>

<Step title="Проверьте результат">
Теперь документ находится в `main.tex`, а его заголовки видны в структуре файла. Нажмите **Recompile**, чтобы увидеть PDF. Проверьте оформление, особенно таблицы, рисунки и ссылки на литературу, которые могут потребовать правки.

<Frame caption="Импортированный проект">
  <img src="/images/on-premises/word-import-project.png" alt="Импортированный проект в редакторе с main.tex, структурой файла и скомпилированным PDF" />
</Frame>
</Step>
</Steps>

### Если импорт не удался {#if-the-import-fails}

Если файл не удаётся преобразовать, диалог показывает **Your document couldn't be imported**. Разверните **Conversion error details**, чтобы узнать причину. Проект не создаётся.

<Frame caption="Документ, который не удалось импортировать">
  <img src="/images/on-premises/word-import-error.png" alt="Диалог импорта с сообщением об ошибке и Conversion error details" />
</Frame>

Диалог принимает только выбранный тип. Файл `.md` в диалоге Word вызывает сообщение **You can only upload: .docx**.

## Экспорт проекта {#export-a-project}

Откройте проект и нажмите на его имя в верхней части редактора. Выберите один из вариантов:

| Вариант                              | Что вы получите                                       |
| ----------------------------------- | --------------------------------------------- |
| <strong>Export as Word document (.docx)</strong> | Файл `.docx` с именем проекта        |
| <strong>Export as Markdown (.md)</strong>        | Файл `.zip` с `main.md`                  |
| <strong>Export as HTML (.html)</strong>          | Файл `.zip` с `main.html`                |

Загрузка начинается сама. Преобразование не может воспроизвести всё форматирование LaTeX, поэтому проверьте результат.
