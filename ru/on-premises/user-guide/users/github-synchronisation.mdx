Подключите проект к репозиторию GitHub. Изменения передаются в обе стороны и только тогда, когда вы нажимаете **Sync**: ничего не синхронизируется само по себе.

<Info>

Если вы не видите параметра GitHub в **Account settings** или в редакторе, попросите администратора включить [синхронизацию с GitHub](/ru/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation).

</Info>

## Привязка учётной записи GitHub {#link-your-github-account}

Это делается один раз.

<Steps>
<Step title="Откройте настройки учётной записи">
Нажмите **Account**, затем **Account settings**. Прокрутите до **GitHub** и нажмите **Link**.

<Frame caption="GitHub в настройках учётной записи">
  <img src="/images/on-premises/github-sync-link.png" alt="Раздел GitHub в настройках учётной записи с кнопкой Link" />
</Frame>
</Step>

<Step title="Авторизуйтесь на GitHub">
Откроется GitHub. Войдите, если потребуется, затем авторизуйте приложение.
</Step>

<Step title="Проверьте привязку">
Вы вернётесь в настройки учётной записи, а на кнопке теперь написано **Unlink**.

<Frame caption="Ваша учётная запись GitHub привязана">
  <img src="/images/on-premises/github-sync-linked.png" alt="Раздел GitHub в настройках учётной записи с кнопкой Unlink" />
</Frame>
</Step>
</Steps>

Если ваша учётная запись ещё не привязана, **Import from GitHub** и карточка **GitHub** в редакторе сначала попросят её привязать. Нажмите **Link to your GitHub account**. Вы также окажетесь в настройках учётной записи, в новой вкладке, если начали в редакторе. Затем вернитесь и начните заново.

<Frame caption="Подсказка, если учётная запись не привязана">
  <img src="/images/on-premises/github-sync-link-prompt.png" alt="Диалоговое окно Import from GitHub с кнопкой Link to your GitHub account" />
</Frame>

## Импорт репозитория {#import-a-repository}

Так создаётся новый проект из репозитория GitHub, уже привязанный к нему.

<Steps>
<Step title="Откройте диалог импорта">
На странице проектов нажмите **New project**, затем **Import from GitHub**.

<Frame caption="Меню New project">
  <img src="/images/on-premises/github-sync-new-project-menu.png" alt="Меню New project с пунктом Import from GitHub" />
</Frame>

<Info>

**New project** появляется, когда у вас есть хотя бы один проект. В меню **Create a new project** на приветственной странице нет импорта, поэтому сначала создайте пустой проект.

</Info>
</Step>

<Step title="Выберите репозиторий">
Нажмите **Import to Overleaf** рядом с репозиторием. В списке есть ваши репозитории и репозитории ваших организаций.

<Frame caption="Ваши репозитории GitHub">
  <img src="/images/on-premises/github-sync-import.png" alt="Диалоговое окно Import from GitHub со списком из четырёх репозиториев" />
</Frame>

Если репозитория организации нет в списке, нажмите <strong>Can't see what you're looking for?</strong>, чтобы открыть справку GitHub об одобрении приложения для этой организации.
</Step>

<Step title="Проверьте проект">
Новый проект откроется с файлами репозитория.

<Frame caption="Импортированный проект">
  <img src="/images/on-premises/github-sync-imported.png" alt="Редактор с импортированным проектом, его файлами и скомпилированным PDF" />
</Frame>
</Step>
</Steps>

## Экспорт проекта в новый репозиторий {#export-a-project-to-a-new-repository}

Так из проекта, владельцем которого вы являетесь, создаётся репозиторий, и они связываются. Проект можно привязать только этим способом или импортом: привязать его к уже существующему репозиторию нельзя.

<Steps>
<Step title="Откройте GitHub в редакторе">
Откройте проект. На левой панели нажмите **Integrations**, затем **GitHub**.

<Frame caption="Панель Integrations">
  <img src="/images/on-premises/github-sync-integrations.png" alt="Панель Integrations с карточкой GitHub" />
</Frame>
</Step>

<Step title="Заполните данные репозитория">
Выберите **Owner**: это можете быть вы или одна из ваших организаций. **Repository Name** изначально совпадает с именем проекта. Описание необязательно, а **Private** выбрано по умолчанию. Нажмите **Create a GitHub repository**.

<Frame caption="Export Project to GitHub">
  <img src="/images/on-premises/github-sync-export.png" alt="Заполненная форма Export Project to GitHub" />
</Frame>
</Step>

<Step title="Проверьте привязку">
В диалоговом окне теперь написано **This project is linked to** и указан репозиторий.

<Frame caption="Проект привязан">
  <img src="/images/on-premises/github-sync-exported.png" alt="Диалоговое окно Sync with GitHub после экспорта" />
</Frame>
</Step>
</Steps>

## Синхронизация {#sync}

<Steps>
<Step title="Откройте диалог синхронизации">
Откройте привязанный проект. На левой панели нажмите **Integrations**, затем **GitHub**.

**Recent commits in GitHub** перечисляет то, что попадёт в проект.

<Frame caption="Новый коммит ожидает в GitHub">
  <img src="/images/on-premises/github-sync-new-commits.png" alt="Диалоговое окно Sync with GitHub с одним новым коммитом" />
</Frame>
</Step>

<Step title="Опишите свои изменения">
Если вы что-то изменили в проекте, появится поле для сообщения коммита. Оно необязательно: если оставить его пустым, коммит будет называться `Updates from Overleaf`.

<Frame caption="Сообщение коммита для ваших изменений">
  <img src="/images/on-premises/github-sync-commit-message.png" alt="Диалоговое окно Sync with GitHub с заполненным сообщением коммита" />
</Frame>
</Step>

<Step title="Нажмите Sync">
Нажмите **Sync**. Новые коммиты из GitHub попадают в проект, а ваши изменения отправляются в ветку репозитория по умолчанию. Если обе стороны изменили разные места, изменения объединяются автоматически.
</Step>

<Step title="Проверьте результат">
В диалоговом окне появится <strong>No new commits in GitHub since last merge.</strong>, а поле сообщения коммита исчезнет. Файлы в редакторе и коммиты на GitHub актуальны.

<Frame caption="Всё синхронизировано">
  <img src="/images/on-premises/github-sync-done.png" alt="Диалоговое окно Sync with GitHub после синхронизации, без новых коммитов" />
</Frame>
</Step>
</Steps>

### Если одни и те же строки изменились с обеих сторон {#if-the-same-lines-changed-on-both-sides}

Диалоговое окно сообщает, что изменения не удалось объединить, и называет новую ветку `overleaf-YYYY-MM-DD-HHMMSS`, в которой находятся ваши изменения.

<Frame caption="Конфликт">
  <img src="/images/on-premises/github-sync-conflict.png" alt="Диалоговое окно Sync with GitHub с предупреждением о конфликте слияния" />
</Frame>

1. Объедините эту ветку с веткой по умолчанию на GitHub или с помощью Git. Тем временем диалог можно закрыть: при повторном открытии он покажет то же сообщение.
2. Нажмите **I have manually merged. Continue**. Объединённый результат попадёт в проект.
3. Ветка остаётся на GitHub. Удалите её, когда она станет не нужна.

## Отвязка проекта {#unlink-a-project}

Сделайте это, если больше не хотите синхронизировать проект. Это может сделать только владелец проекта.

<Steps>
<Step title="Нажмите Unlink">
В диалоге синхронизации нажмите **Unlink**.
</Step>

<Step title="Подтвердите">
Нажмите **Confirm**. Примечание о подписке не мешает снова привязать проект.

<Frame caption="Подтверждение отвязки">
  <img src="/images/on-premises/github-sync-unlink-project.png" alt="Диалоговое окно Sync with GitHub с запросом подтвердить отвязку" />
</Frame>
</Step>

<Step title="Проверьте результат">
Теперь в диалоговом окне отображается **Export Project to GitHub**. И проект, и репозиторий сохраняют своё содержимое. Чтобы снова синхронизировать, экспортируйте проект в новый репозиторий или импортируйте репозиторий в новый проект.
</Step>
</Steps>

## Отвязка учётной записи GitHub {#unlink-your-github-account}

В **Account settings**, в разделе **GitHub**, нажмите **Unlink**, затем ещё раз **Unlink** в диалоговом окне.

<Frame caption="Отвязка учётной записи">
  <img src="/images/on-premises/github-sync-unlink-account.png" alt="Диалоговое окно Unlink GitHub Account" />
</Frame>

Ваши проекты остаются привязанными к своим репозиториям. Синхронизировать их нельзя, пока вы снова не привяжете учётную запись.

<Info>

О том, кто что может делать в общем проекте, см. [Кто может привязывать и синхронизировать](/ru/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation#who-can-link-and-sync). Каждый соавтор, который выполняет синхронизацию, привязывает свою учётную запись GitHub.

</Info>
