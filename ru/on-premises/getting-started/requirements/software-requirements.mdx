### Операционные системы {#operating-systems}

Для общих и рабочих (production) серверов мы рекомендуем систему **Linux на базе Debian**, например **Ubuntu**. Ayakaleaf Pro также может работать на [macOS с Docker Desktop](/ru/on-premises/installation/using-docker-compose/macos) и [Windows с WSL 2 и Docker Desktop](/ru/on-premises/installation/using-docker-compose/windows). Все три платформы используют Linux-контейнеры и один и тот же Toolkit; следуйте руководству для операционной системы вашего хоста.

<Danger>

При использовании изолированной компиляции (Sandboxed Compiles) **важно** учитывать, что приложению требуется root-доступ к Docker-сокету.

</Danger>

### Зависимости {#dependencies}

* Docker 25.0 и 29
* MongoDB 7.0 и 8.0
* Redis 6.2 и 7.5

<Info>

Даты окончания поддержки (End-of-Life, EOL) для перечисленных выше зависимостей и других популярных продуктов можно отслеживать с помощью сервиса endoflife.date: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

MongoDB и Redis автоматически загружаются `docker compose` при запуске Ayakaleaf Pro, если не настроено использование другой установки.

</Info>

Toolkit зависит от следующих программ:

* bash
* Docker

Требуется `docker compose`, который обычно устанавливается вместе с Docker.

Рекомендуем установить самую новую версию Docker, доступную для вашей операционной системы.

После корректной установки Docker следующие команды должны выполняться без ошибок:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2 or later, such as v5)
docker compose version

# List the running Docker containers on your system
docker ps
```
