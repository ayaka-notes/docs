### Операционные системы

Для наилучшей работы Overleaf настоятельно рекомендуем использовать операционную систему **на базе Debian**, например **Ubuntu**. Этот выбор соответствует среде разработки программного обеспечения и является предпочтительным для большинства пользователей Overleaf.

<Danger>

При использовании Server Pro с изолированной компиляцией (Sandboxed Compiles) **важно** учитывать, что приложению требуется root-доступ к Docker-сокету.

</Danger>

### Зависимости

* Docker 25.0 и 29
* MongoDB 7.0 и 8.0
* Redis 6.2 и 7.5

<Info>

Даты окончания поддержки (End-of-Life, EOL) для перечисленных выше зависимостей и других популярных продуктов можно отслеживать с помощью сервиса endoflife.date: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

MongoDB и Redis автоматически загружаются `docker compose` при запуске Server CE или Server Pro, если не настроено использование другой установки.

</Info>

Toolkit зависит от следующих программ:

* bash
* Docker

Требуется `docker compose`, который обычно устанавливается вместе с Docker.

Рекомендуем установить самую новую версию Docker, доступную для вашей операционной системы.

После корректной установки Docker следующие команды должны выполняться без ошибок:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2)
docker compose version

# List the running Docker containers on your system
docker ps
```
