### Требования для установки Server Pro и Community Edition

<Warning>

Мы настоятельно рекомендуем запускать Server Pro на свежей стабильной версии Ubuntu (например, Ubuntu 24.04 в 2025–2026 гг.) с актуальной версией Docker. Запуск Server Pro на других системах возможен, но нам будет значительно сложнее оказывать поддержку для нестандартных конфигураций Ubuntu/Docker. Мы также не можем оказывать поддержку по проблемам, связанным с самим Docker.

</Warning>
