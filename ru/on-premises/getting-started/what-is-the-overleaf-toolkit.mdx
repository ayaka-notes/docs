---
title: Что такое Ayakaleaf Toolkit?
icon: toolbox
---

Ayakaleaf Toolkit — рекомендуемый способ локального развёртывания Community Edition и Ayakaleaf Pro. Он рассчитан на наиболее распространённую среду: один физический сервер или виртуальную машину. Toolkit использует `docker compose` для управления Docker-контейнерами сервера и предоставляет набор скриптов-обёрток над командами `docker`, которые помогают с технической стороной управления локальной версией Overleaf.

#### Обёртка `bin/docker-compose`

Скрипт `bin/docker-compose` — это обёртка над `docker compose`. Он загружает конфигурацию из каталога `config/`, а затем вызывает `docker compose` с аргументами, переданными скрипту.

`bin/docker-compose` можно рассматривать как прозрачную обёртку над программой `docker compose`, установленной на вашей машине.

Пример:

```bash title="Check running containers"
$ bin/docker-compose ps
```

#### Вспомогательные скрипты

Помимо `bin/docker-compose`, Toolkit предоставляет удобные скрипты для решения типовых задач:

* `bin/up`: сокращение для `bin/docker-compose up`
* `bin/start`: сокращение для `bin/docker-compose start`
* `bin/stop`: сокращение для `bin/docker-compose stop`
* `bin/shell`: запускает оболочку внутри контейнера **sharelatex**
* `bin/doctor`: скрипт для сбора информации об установке и развёртывании. См. раздел «Проверка сервера» ниже
* `bin/mongo`: запускает оболочку внутри контейнера **mongo** и переключается на нужную базу данных (**sharelatex**)
* `bin/backup-config`: создаёт копию (zip или tar) текущей конфигурации и сохраняет её в выбранный вами каталог
* `bin/logs`: просмотр/отслеживание логов сервисов
* `bin/error-logs`: просмотр/отслеживание логов ошибок сервисов
* `bin/rename-env-vars-5-0`: скрипт миграции для обновления переменных окружения в **config/variables.env** (ребрендинг с ShareLaTeX на Overleaf)
* `bin/rename-rc-vars`: скрипт миграции для обновления переменных окружения в **config/overleaf.rc** (ребрендинг с ShareLaTeX на Overleaf)
* `bin/run-script`: вспомогательный скрипт, упрощающий запуск скриптов, хранящихся в контейнере **sharelatex**
* `bin/upgrade`: помогает обновлять экземпляр. Скрипт проверяет наличие обновлений Toolkit (через git) и предлагает загрузить изменения, проверяет последнюю версию Docker-образа и предлагает обновить её. Он запрашивает подтверждение на каждом шаге, предлагает создать резервную копию текущей конфигурации и берёт на себя остановку и запуск сервисов Docker. Подробнее см. «Обновление развёртывания»: https://docs.overleaf.com/on-premises/maintenance/upgrading-your-deployment

<Info>

Если вы предпочитаете запускать экземпляр без подключения к логам Docker, выполните `bin/up -d`, чтобы запустить его в фоновом режиме.

</Info>

#### Проверка сервера

Overleaf Toolkit включает удобный скрипт `bin/doctor`, который формирует отчёт с указанием всех неудовлетворённых зависимостей.

Прежде чем продолжить, запустите скрипт `bin/doctor` и убедитесь, что всё работает правильно:

```bash title="Run Overleaf Doctor"
bin/doctor
```
