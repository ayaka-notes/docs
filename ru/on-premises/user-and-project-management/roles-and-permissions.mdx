### Учётная запись

С точки зрения управления собственной учётной записью **все** пользователи считаются обычными пользователями — `Site Admins` и `Template Users` **не** получают дополнительных прав. Однако существуют ограничения на действия обычных пользователей в зависимости от способа их аутентификации.

#### Настройки

<strong>Типы аутентификации: внутренние учётные записи | SSO (SAML/LDAP)</strong>

| Действие | Внутренние учётные записи | SSO (SAML/LDAP) |
| ----------------------------------------- | ----------------: | --------------: |
| Обновление данных учётной записи | Да | Нет |
| Смена пароля | Да | Нет |
| Создание токенов аутентификации Git bridge | Да | Да |
| Удаление токенов аутентификации Git bridge | Да | Да |
| Управление сеансами | Да | Да |

<Info>

Интеграция Git Bridge доступна **только** в Server Pro. Подробнее см. [Server Pro vs. Community Edition](/ru/on-premises/readme/ayakaleaf-pro-vs-server-pro).

</Info>

#### Ваши сеансы

| -------------------- | ---: |
| Очистка сеансов | Да |
| Просмотр текущего сеанса | Да |
| Просмотр других сеансов | Да |

### IDE редактора

С точки зрения IDE редактора Overleaf у вас может быть одна из следующих ролей: `Project Owner`, `Editor`, `Reviewer`, `Viewer`, `Site Administrator` или `Template User`.

<Info>

В Server Pro и Community Edition поддерживается предоставление анонимного доступа к проектам **только для чтения** и **для чтения и записи**.

Подробнее см. описание переменных окружения `OVERLEAF_ALLOW_PUBLIC_ACCESS` и `OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` [здесь](/ru/on-premises/configuration/overleaf-toolkit/environment-variables).

</Info>
