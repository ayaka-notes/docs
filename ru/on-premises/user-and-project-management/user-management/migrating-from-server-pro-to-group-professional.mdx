---

Переход с самостоятельно размещённого экземпляра Server Pro на новую облачную подписку Overleaf Group Professional — это серьёзное изменение, поэтому, чтобы сделать этот процесс максимально гладким, мы подготовили следующие рекомендации.

Как правило, мы предлагаем трёхмесячный переходный период, начинающийся с даты продления. Это означает, что:

* Ваш существующий экземпляр Server Pro и новая подписка Group Professional будут полностью активны одновременно.
* Ваша техническая команда сможет запланировать время для настройки подписки Group Professional и принять решение о дальнейшей судьбе локального развёртывания Server Pro.
* И самое главное, у ваших пользователей будет достаточно времени, чтобы перенести свои проекты на новую платформу Overleaf Group Professional.

Это краткое руководство проведёт вас через основные этапы миграции. Давайте начнём!

<Steps>
<Step title="Этап 1: подготовка и настройка">
(Ссылка: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-1-setup-and-configuration)

* Overleaf создаст вашу подписку Group Professional и добавит ведущего администратора.
* Администратор группы сможет включить [управляемых пользователей (Managed Users)arrow-up-right](https://docs.overleaf.com/groups/user-management/managed-user-accounts), настроить [единый вход (SSO)arrow-up-right](https://docs.overleaf.com/groups/overleaf-group-single-sign-on/setting-up-group-sso) и [пригласить конечных пользователейarrow-up-right](https://docs.overleaf.com/groups/user-management/how-to-add-and-remove-users).

<Warning>

Включение управляемых пользователей и внедрение SSO являются обязательными шагами для соответствия требованиям FedRAMP® LI-SaaS. Если вашей организации требуется соответствие FedRAMP, настройте управляемых пользователей и SSO до приглашения конечных пользователей.

</Warning>
</Step>

<Step title="Этап 2: миграция пользователей и управление данными">
(Ссылка: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-2-user-migration-and-data-management)

Это основной период миграции, на котором распределяются следующие обязанности:

#### Конечные пользователи

* Пользователи должны перенести все проекты, которые хотят сохранить, из вашего экземпляра Server Pro в свои новые учётные записи на [overleaf.comarrow-up-right](http://overleaf.com/). Для этого нужно [экспортировать проектыarrow-up-right](https://www.overleaf.com/learn/how-to/Exporting_your_work_from_Overleaf) из Server Pro и [загрузить ихarrow-up-right](https://www.overleaf.com/learn/how-to/Uploading_a_project) в свою учётную запись на [overleaf.comarrow-up-right](http://overleaf.com/). Если у пользователя ещё нет учётной записи [overleaf.comarrow-up-right](http://overleaf.com/), он может зарегистрироваться на [overleaf.com/registerarrow-up-right](http://overleaf.com/register).

<Warning>

При таком экспорте переносится только исходный код проекта (файлы LaTeX и двоичные файлы). Существующие настройки проекта, настройки общего доступа, комментарии, отслеживаемые изменения и т. д. НЕ переносятся. После миграции пользователям потребуется повторно пригласить своих соавторов.

</Warning>

#### Технический персонал

* На этом этапе ваша техническая команда должна спланировать, что делать с локальным экземпляром Server Pro и его данными после миграции.
* <strong>Резервное копирование данных:</strong> перед выводом из эксплуатации можно экспортировать все проекты, чтобы создать архив, который позволит помочь пользователям, забывшим перенести или скачать свою работу. Инструкции: https://docs.overleaf.com/on-premises/maintenance/data-and-backups/exporting-projects
* <strong>Вывод Server Pro из эксплуатации:</strong> после завершения периода миграции и отключения вашего лицензионного ключа у вас есть два основных варианта действий с самим экземпляром Server Pro (см. следующий шаг).
</Step>

<Step title="Варианты вывода Server Pro из эксплуатации">
<Steps>
<Step title="Полностью удалить Server Pro">
Удаление выводит Server Pro из эксплуатации и полностью удаляет программное обеспечение.
</Step>

<Step title="Перейти на Community Edition">
Переход сохраняет базу данных пользователей и проектов с полной историей проектов за счёт преобразования экземпляра из Server Pro в Community Edition.
</Step>
</Steps>

<Info>

Community Edition НЕ включает [изолированную компиляцию (Sandboxed Compiles)arrow-up-right](https://docs.overleaf.com/on-premises#overview-of-server-pro-and-community-edition), а также [LDAP](/ru/on-premises/configuration/overleaf-toolkit/authentication/ldap-authentication)/[SAML](/ru/on-premises/configuration/overleaf-toolkit/authentication/saml-authentication). Если вам нужно вернуться к встроенной аутентификации (имя пользователя/пароль), см.: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-to-ldap-or-saml#going-the-other-way-switching-from-ldap-saml-back-to-native-authentication

Сравнение Server CE и Server Pro см.: https://docs.overleaf.com/on-premises/welcome/server-pro-vs.-community-edition

</Info>
</Step>

<Step title="Этап 3: вывод Server Pro из эксплуатации">
(Ссылка: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-3-server-pro-decommission)

* Команда Overleaf официально деактивирует ваш лицензионный ключ Server Pro и пришлёт подтверждение по завершении.
* После этого выполните одно из описанных выше действий по выводу из эксплуатации: полностью удалите Server Pro или перейдите на Community Edition.
</Step>
</Steps>

Дополнительные ресурсы и ссылки, упомянутые выше, остаются без изменений.
