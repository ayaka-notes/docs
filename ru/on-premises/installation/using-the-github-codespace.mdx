Самый простой способ протестировать Ayakaleaf Pro — воспользоваться GitHub Codespace, где все переменные окружения уже предварительно настроены, чтобы всё работало «из коробки».

<Warning>

При запуске Docker-контейнеров в GitHub Codespaces Codespace не завершает работу автоматически, и за него продолжает **взиматься плата**. Правила тарификации GitHub Codespaces см. в [правилах оплаты GitHub Codespaces](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces).

Для управления своими GitHub Codespaces перейдите на [https://github.com/codespaces](https://github.com/codespaces). Когда Codespace больше не нужен, своевременно удалите его.

</Warning>

Мы **предварительно настроили** следующие функции:

* [x] Изолированная компиляция LaTeX с TeXLive **Basic** (2024–2026)
* [x] Импорт/экспорт через Pandoc (функция SaaS-платформы)
* [x] Запуск скриптов Python (функция SaaS-платформы)
* [x] Поддержка Git-Bridge (функция Server Pro)
* [x] Расширенный поиск по библиографии (функция SaaS-платформы)
* [x] Панель администратора (глобальное управление пользователями и проектами)
* [x] Отслеживание изменений (с панелью рецензирования и комментариев)
* [x] Полная история проекта (с восстановлением и скачиванием)
* [x] Палитра символов (функция Server Pro / SaaS-платформы)

<Warning>

Стандартные GitHub Codespaces предоставляют 32 ГБ дискового пространства. Этого недостаточно для установки `texlive-full`. Чтобы протестировать полный образ, отправьте в поддержку GitHub запрос на Codespace с большими раннерами (8+ ядер).

</Warning>

Синхронизация с GitHub, LDAP, OAuth, SSO, интеграция с Zotero и другие функции в этой песочнице _**не настроены**_. Подробнее о настройке этих функций в собственном развёртывании см. в [настройках Toolkit](/ru/on-premises/configuration/overleaf-toolkit/toolkit-settings).

<Steps>
<Step title="Создайте GitHub Codespace">
Нажмите кнопку ниже, чтобы создать GitHub Codespace. Что касается конфигурации сервера, для тестирования обычно достаточно **2 ядер и 8 ГБ ОЗУ**. Если вы планируете использовать [**TeX Live Full**](https://github.com/ayaka-notes/texlive-full), рекомендуем выбрать конфигурацию с **8 ядрами и 64 ГБ**.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/ayakaleaf-pro-playground)
</Step>

```bash title="bash"

```

#### Использование образа TeXLive Full

Если у вас есть доступ к GitHub Codespaces с 8 ядрами и 64 ГБ, в этой песочнице можно использовать образ TeXLive Full. Чтобы использовать образ TeXLive Full вместо TeXLive Basic, измените следующие переменные окружения в файле `toolkit/config/variables.env`.

```dotenv wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1, ghcr.io/ayaka-notes/texlive-full:2024.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025, Texlive 2024
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```

После изменения переменных окружения необходимо перезапустить Toolkit, чтобы применить изменения. Для этого выполните следующую команду.

```bash
cd toolkit && bin/up -d
```
