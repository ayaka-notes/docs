Используйте Claude Code или Codex, чтобы спланировать и выполнить развёртывание Ayakaleaf Pro. В процессе работы агент может искать информацию в этой документации через MCP.

Агент помогает с развёртыванием, но ответственность за проверку команд и защиту учётных данных остаётся на вас.

### Перед началом

Подготовьте поддерживаемый Linux-сервер с доступом по SSH. Прежде чем продолжить, ознакомьтесь с [требованиями](/ru/on-premises/getting-started/requirements  "mention").

<Warning>

Не вставляйте пароли, закрытые ключи, токены или лицензионные ключи в промпты агента. Проверяйте каждую команду перед её выполнением, особенно команды, изменяющие файлы, сети или контейнеры.

</Warning>

### Подключение документации

Добавьте MCP-эндпоинт документации в своего локального агента.

<Tabs>
<Tab title="Claude Code">

```bash wrap
claude mcp add ayakaleaf-pro --scope user --transport http https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>

<Tab title="Codex">

```bash wrap
codex mcp add ayakaleaf-pro --url https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>
</Tabs>

После добавления сервера начните новый сеанс. Попросите агента подтвердить, что он может искать в документации Ayakaleaf Pro.

### Развёртывание Ayakaleaf Pro

Откройте терминал на сервере развёртывания. Запустите там Claude Code или Codex. Затем отправьте следующий промпт:

```text wrap
Use the Ayakaleaf Pro documentation MCP server to guide this deployment.
First, inspect the requirements and installation guides.
Ask me for missing deployment details before making changes.
Use the Ayakaleaf Toolkit unless the documentation requires another approach.
Before configuring the instance, summarize relevant optional features.
Ask which features and integrations I want to enable.
Include TLS, sandboxed compiles, Git integration, external MongoDB or Redis,
SSO (OIDC, SAML, or LDAP), GitHub Synchronisation, Zotero, S3 storage,
email delivery, branding, and localization when relevant.
Explain each selected option's prerequisites, security impact, and configuration steps.
Keep unselected optional features disabled.
Show each command before running it.
Do not expose, store, or request secrets in chat.
After deployment, verify that the service is healthy and summarize the changes.
```

Агент должен провести вас через установку Docker, настройку Toolkit, получение образов и запуск. Эталонный порядок действий описан в руководстве [using-the-toolkit](/ru/on-premises/installation/using-the-toolkit  "mention").

### Выбор дополнительных функций

Попросите агента рекомендовать только те функции, которые подходят для вашей среды. Типичные варианты:

* <strong>Доступ и безопасность:</strong> TLS, изолированные компиляции (sandboxed compiles) и SSO через OIDC, SAML или LDAP.
* <strong>Внешние сервисы:</strong> MongoDB, Redis, хранилище S3 и отправка электронной почты.
* <strong>Совместная работа:</strong> интеграция с Git, GitHub Synchronisation и Zotero.

Перед изменением конфигурации агент должен объяснить зависимости. Прежде чем включать интеграции в production, ознакомьтесь с [toolkit-settings.md](/ru/on-premises/configuration/overleaf-toolkit/toolkit-settings  "mention") и [authentication](/ru/on-premises/configuration/overleaf-toolkit/authentication  "mention").

### Проверка развёртывания

После того как агент выполнит все шаги:

1. Убедитесь, что все команды завершились без ошибок.
2. Откройте в браузере настроенный URL Ayakaleaf Pro.
3. Выполните [6.-post-installation-tasks.md](/ru/on-premises/installation/using-the-toolkit/6.-post-installation-tasks  "mention").

Если у вас уже есть установка Community Edition, вместо нового развёртывания воспользуйтесь руководством [migrate-from-existing.md](/ru/on-premises/installation/migrate-from-existing  "mention").
