<Steps>
<Step title="Проверьте Git и Homebrew">
```bash
git --version
brew --version
```

Если при запуске Git macOS предложит установить Command Line Tools, сначала установите их. Если Homebrew отсутствует, установите его по [официальной инструкции](https://brew.sh/).
</Step>

<Step title="Добавьте GNU sed в PATH">
Скрипты Toolkit используют параметры GNU sed, которые отклоняет встроенный в macOS BSD sed. Установите [GNU sed](https://formulae.brew.sh/formula/gnu-sed) и поставьте его первым в `PATH` в этом терминале:

```bash
brew install gnu-sed
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
sed --version
```

Последняя команда должна вывести **GNU sed**.

Псевдонима вроде `alias sed=gsed` недостаточно: Toolkit запускает Bash-скрипты, которые не видят псевдонимов вашей интерактивной оболочки. Заменять `/usr/bin/sed` не нужно.

Выполняйте строку `export PATH=...` заново в каждом новом терминале, который вы используете для Toolkit, или добавьте её в файл запуска оболочки после инициализации самого Homebrew.
</Step>

<Step title="Клонируйте репозиторий Ayakaleaf Toolkit">
Выберите постоянный каталог. Для рабочей базы данных и данных проектов избегайте `/tmp`, съёмных дисков и папок с облачной синхронизацией, таких как iCloud Drive. В этом руководстве используется `~/ayakaleaf-toolkit`:

```bash
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

<Warning>

Если в каталоге уже есть установка, используйте её как есть или выберите другой каталог для нового экземпляра. Не инициализируйте новую конфигурацию поверх существующего развертывания.

</Warning>
</Step>
</Steps>
