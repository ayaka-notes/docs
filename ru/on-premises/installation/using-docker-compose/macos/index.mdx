В этом разделе мы запустим Ayakaleaf Pro локально на вашем Mac с помощью Docker Desktop и [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). В руководстве используется адрес `http://localhost:8080`, данные хранятся в вашем домашнем каталоге, а компиляция выполняется с TeX Live 2026 в изолированных контейнерах.

Docker Desktop запускает приложение, MongoDB, Redis и компилятор TeX Live в виртуальной машине Linux. Устанавливать MongoDB, Redis или MacTeX в самой macOS не нужно.

Используйте эту конфигурацию для личного использования и локального тестирования. Для постоянно работающего общего сервиса мы рекомендуем [руководство для Linux](/ru/on-premises/installation/using-docker-compose/linux) с HTTPS, резервным копированием и управлением доступом. Экземпляр недоступен, пока Mac находится в спящем режиме или Docker Desktop остановлен, см. раздел [Обеспечение доступности экземпляра](/ru/on-premises/installation/using-docker-compose/macos/6.-post-installation-tasks#keep-the-instance-available).

## Прежде чем начать {#before-you-start}

Вам понадобится:

* Версия macOS, поддерживаемая [Docker Desktop for Mac](https://docs.docker.com/desktop/setup/install/mac-install/).
* Git, [Homebrew](https://brew.sh/) и GNU sed. Toolkit использует параметры GNU sed, которые не принимает встроенный в macOS BSD sed.
* Достаточно ресурсов и для macOS, и для Docker. Для небольшого локального экземпляра начните с 4 CPU и 8 ГБ памяти, выделенных Docker Desktop. Это рекомендуемая отправная точка, а не измеренный минимум.
* Не менее 40 ГБ свободного места для полного образа TeX Live, а также место для ваших проектов. Проверьте и свободное место на Mac, и лимит использования диска в Docker Desktop. Начните с одной версии TeX Live: каждая дополнительная версия требует примерно столько же места.

Образы приложения и TeX Live публикуются для `arm64` и `amd64`. На Apple silicon позвольте Docker выбрать нативный образ ARM и не задавайте принудительно `platform: linux/amd64`.
