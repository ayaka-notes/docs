---
title: 3. Инициализация конфигурации
description: Создайте конфигурационные файлы Toolkit на Mac с помощью bin/init.
icon: circle-play
---

В каталоге Toolkit, в терминале с GNU sed в `PATH`, выполните:

```bash
bin/init
```

`bin/init` создаёт три файла:

| Файл | Назначение |
| --- | --- |
| `config/overleaf.rc` | Настройки контейнеров, публикуемый порт и расположение данных |
| `config/variables.env` | Настройки приложения и секреты |
| `config/version` | Версия образа приложения |

Кроме того, он генерирует `OVERLEAF_INVITE_TOKEN_SECRET` в `config/variables.env`. Сохраните его и не публикуйте этот файл и не добавляйте его в систему контроля версий.

Оставьте версию, которую Toolkit выбирает для новой установки. Чтобы позже изменить версию существующего экземпляра, следуйте разделу [Обновление развертывания](/ru/on-premises/maintenance/upgrading-your-deployment).

<Warning>

Если `bin/init` останавливается с ошибкой `sed: ... invalid command code`, значит, он был запущен с BSD sed из macOS. После такого неудачного запуска в `config/` могут остаться все три файла с пустым `OVERLEAF_INVITE_TOKEN_SECRET`, и повторный запуск `bin/init` сообщает `Config files already exist`. См. раздел [Устранение неполадок](/ru/on-premises/installation/using-docker-compose/macos/troubleshooting#initialization-fails-with-invalid-command-code).

</Warning>
