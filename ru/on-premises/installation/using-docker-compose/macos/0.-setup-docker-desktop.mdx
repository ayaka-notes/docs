Ayakaleaf Pro работает в Docker. На Mac используется Docker Desktop, который запускает движок Docker в виртуальной машине Linux.

<Steps>
<Step title="Установите и запустите Docker Desktop">
Установите сборку [Docker Desktop](https://docs.docker.com/desktop/setup/install/mac-install/) для вашего Mac (Apple silicon или Intel), откройте её и дождитесь запуска движка. Его также можно запустить из Терминала:

```bash
open -a Docker
```
</Step>

<Step title="Проверьте движок Docker">
Выполните в Терминале следующие команды:

```bash
docker context show
docker info
docker compose version
```

Контекст должен указывать на ваш локальный движок Docker Desktop, обычно `desktop-linux`. Если выбран другой контекст, переключитесь на Docker Desktop, прежде чем продолжить:

```bash
docker context use desktop-linux
```

`docker info` должна вывести раздел **Server**. Одна лишь команда `docker --version` показывает только то, что установлен клиент.
</Step>

<Step title="Проверьте ресурсы и общий доступ к файлам">
В разделе **Settings** Docker Desktop сверьте лимиты CPU, памяти и диска с разделом [Прежде чем начать](/ru/on-premises/installation/using-docker-compose/macos#before-you-start), а также проверьте настройки общего доступа к файлам, см. [настройки Docker Desktop](https://docs.docker.com/desktop/settings-and-maintenance/settings/).

В этом руководстве Toolkit хранится в `/Users`, к которому Docker Desktop по умолчанию предоставляет общий доступ. Если вы используете другое расположение и `bin/up` завершается ошибкой `Mounts denied`, добавьте этот каталог в общий доступ к файлам.
</Step>

<Step title="Проверьте сокет Docker для изолированных компиляций">
Toolkit монтирует `/var/run/docker.sock` в приложение, чтобы оно могло запускать отдельный контейнер TeX Live для каждой компиляции. Оставьте `DOCKER_SOCKET_PATH=/var/run/docker.sock` в `config/overleaf.rc`.

Docker CLI в macOS может подключаться через `~/.docker/run/docker.sock`. Это клиентская точка подключения на Mac, а не повод менять источник монтирования в Toolkit: компилятору нужен сокет движка в том виде, в каком его видят Linux-контейнеры.

Если `/var/run/docker.sock` на Mac отсутствует, включите **Allow the default Docker socket to be used** в разделе **Settings → Advanced**, см. [требования Docker к разрешениям](https://docs.docker.com/desktop/setup/install/mac-permission-requirements/).

<Danger>

Не выполняйте `chmod 777` для сокета, чтобы обойти ошибки. Доступ к сокету Docker равнозначен root-доступу к виртуальной машине Docker.

</Danger>
</Step>
</Steps>
