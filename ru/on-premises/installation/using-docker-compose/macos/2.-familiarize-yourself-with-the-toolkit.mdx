Toolkit одинаков в macOS и Linux. Его структура, каталог `config/` и команды `bin/` описаны в разделе [2. Знакомство с Toolkit](/ru/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) руководства для Linux.

В macOS помните о трёх отличиях:

* Запускайте скрипты из терминала, в котором GNU sed стоит первым в `PATH`, см. [1. Загрузка Toolkit](/ru/on-premises/installation/using-docker-compose/macos/1.-download-the-toolkit).
* Запускайте Docker Desktop, прежде чем выполнять скрипт, который обращается к Docker, например `bin/up`, `bin/start` или `bin/docker-compose`.
* `bin/doctor` содержит проверки, унаследованные от официального Overleaf Toolkit. Его предупреждение `This system seems to not be Linux` в macOS ожидаемо, а предупреждение об отсутствии входа в `quay.io` не относится к публичному образу `ghcr.io/ayaka-notes/overleaf-pro`. Остальные проблемы в отчёте по-прежнему важны.
