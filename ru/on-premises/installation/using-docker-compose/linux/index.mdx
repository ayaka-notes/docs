В этом разделе мы проведём вас через установку Docker, загрузку Toolkit с GitHub, знакомство с некоторыми командами Toolkit и настройку некоторых базовых параметров. К концу этого раздела у вас должен работать локальный (on-premises) экземпляр Overleaf.

Шаги рассчитаны на свежую LTS-версию Ubuntu. В другом дистрибутиве установите Docker Engine и плагин Compose, как описано в [документации Docker](https://docs.docker.com/engine/install/), а затем переходите к разделу [1. Загрузка Toolkit](/ru/on-premises/installation/using-docker-compose/linux/1.-download-the-toolkit).

<Info>

По умолчанию экземпляр принимает подключения только с самого сервера, по адресу `http://localhost`. Чтобы открыть его с других компьютеров или на другом порту, задайте `OVERLEAF_LISTEN_IP` и `OVERLEAF_PORT` в `config/overleaf.rc`, как описано в разделе [5. Персонализация экземпляра](/ru/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance).

</Info>
