### Инициализация конфигурации {#initializing-the-configuration}

Инициализируем конфигурационные файлы нового сервера разумными значениями по умолчанию, запустив входящий в комплект скрипт `bin/init`.

```text title="Run initialization"
bin/init
```

Этот скрипт **не** перезаписывает существующие конфигурационные файлы.

Теперь проверим содержимое каталога `config/` с помощью команды `ls`:

```text title="List the config directory"
ls config
```

Если инициализация прошла успешно, вы увидите три конфигурационных файла: `config/overleaf.rc`, `config/variables.env` и `config/version`. Это основные конфигурационные файлы сервера, которые позволяют настроить работу сервера и взаимодействие пользователей с вашим экземпляром.

| Имя             | Описание                                                |
| --------------- | ------------------------------------------------------- |
| `config/overleaf.rc`   | Основной конфигурационный файл верхнего уровня, который читают скрипты Toolkit. Он определяет, как запускаются контейнеры, например адрес и порт для прослушивания (`OVERLEAF_LISTEN_IP`, по умолчанию `127.0.0.1`, и `OVERLEAF_PORT`, по умолчанию `80`). |
| `config/variables.env` | Переменные окружения, загружаемые в Docker-контейнер. Они определяют поведение Overleaf, например `OVERLEAF_SITE_URL`. |
| `config/version`       | Версия используемого Docker-образа.                     |

Также генерируется `OVERLEAF_INVITE_TOKEN_SECRET` в `config/variables.env`. Сохраните его и не публикуйте этот файл и не добавляйте его в систему контроля версий.

<Info>

Пока достаточно знать, что эти файлы существуют и где их найти. Далее в документации мы подробно разберём каждый из файлов и объясним, как с их помощью настроить ваш экземпляр. Если хотите забежать вперёд, полное описание этих конфигурационных файлов приведено на [странице «Файлы и расположение»](/ru/on-premises/configuration/overleaf-toolkit/files-and-locations).

</Info>
