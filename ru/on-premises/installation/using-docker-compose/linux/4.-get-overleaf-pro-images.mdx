---
title: 4. Получение образов Ayakaleaf Pro
icon: split
---

Ayakaleaf Pro — это бесплатный образ Docker в [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Для его загрузки не нужны ни учётная запись, ни вход в систему. Образы собираются для amd64 и arm64, и Docker выбирает тот, который подходит для вашего сервера.

Откройте `config/overleaf.rc` и задайте:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

При следующем запуске `bin/up` Toolkit загрузит образ Ayakaleaf Pro и будет использовать его вместо официальной редакции Overleaf Community Edition. Ваши настройки в `config/` продолжат работать.

<Accordion title="Вы уже используете официальный Overleaf Toolkit (overleaf/toolkit)?">

Переустанавливать ничего не нужно. Загрузите образ Ayakaleaf Pro:

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Затем добавьте в каталог `overleaf-toolkit/config` файл с именем `docker-compose.override.yml` со следующим содержимым:

```yml
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

При следующем запуске `bin/up` Toolkit будет использовать образ Ayakaleaf Pro.

</Accordion>
