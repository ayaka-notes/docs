<Steps>
<Step title="Установите инструменты командной строки">
Выполните в **Ubuntu**, используя пароль Linux, созданный на шаге 0:

```bash
sudo apt update
sudo apt install -y git ca-certificates curl perl gawk openssl
```

В Ubuntu уже есть Bash, GNU sed и coreutils. В отличие от macOS, здесь не нужны Homebrew или отдельная установка GNU sed.
</Step>

<Step title="Клонируйте репозиторий Ayakaleaf Toolkit">
Храните Toolkit и его данные в файловой системе Linux в Ubuntu, в вашем домашнем каталоге:

```bash
cd "$HOME"
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

Для рабочей базы данных и данных проектов избегайте `/mnt/c`, `/mnt/d`, OneDrive и временных каталогов. Пути в файловой системе Linux обеспечивают права доступа и поведение файловой системы, которых ожидают контейнеры, и позволяют избежать накладных расходов при работе между файловыми системами; см. [рекомендации Microsoft по файловым системам](https://learn.microsoft.com/en-us/windows/wsl/filesystems).

<Warning>

Если в каталоге уже есть установка, используйте её как есть или выберите другой каталог для нового экземпляра. Не заменяйте конфигурацию или данные существующего развертывания.

</Warning>
</Step>
</Steps>
