В этом разделе мы запустим Ayakaleaf Pro локально в Windows с помощью WSL 2, Ubuntu, Docker Desktop и [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). В руководстве используется адрес `http://localhost:8080`, данные хранятся в домашнем каталоге Ubuntu, и включены изолированные компиляции.

Приложение, MongoDB, Redis и TeX Live работают в Linux-контейнерах под управлением Docker Desktop. Команды Toolkit выполняйте в Ubuntu, а приложение открывайте в браузере Windows. В [шаге 0](/ru/on-premises/installation/using-docker-compose/windows/0.-setup-wsl-and-docker-desktop) объясняется, как сочетаются компоненты Windows и Linux, и описание начинается с установки WSL.

Windows можно использовать для локального экземпляра или держать его постоянно запущенным с помощью настроек доступности из шага 6. Для общих и рабочих (production) серверов мы рекомендуем [руководство для Linux](/ru/on-premises/installation/using-docker-compose/linux) с HTTPS, резервным копированием и управлением доступом. Спящий режим Windows, завершение работы Docker Desktop и завершение работы WSL прерывают работу этого локального экземпляра; см. раздел [Обеспечение доступности экземпляра](/ru/on-premises/installation/using-docker-compose/windows/6.-post-installation-tasks#keep-the-instance-available).

## Прежде чем начать {#before-you-start}

Вам понадобится:

* Версия Windows и процессор, поддерживаемые [Docker Desktop for Windows](https://docs.docker.com/desktop/setup/install/windows-install/), с включённой аппаратной виртуализацией. В этом руководстве используется Windows 11 на x86-64.
* Права на включение WSL и установку программного обеспечения. WSL должна быть версии 2.1.5 или новее, а Ubuntu — работать в режиме WSL 2.
* Достаточно памяти для Windows и контейнеров. Для небольшого локального экземпляра 4 CPU и 8 ГБ, доступные Docker, — рекомендуемая отправная точка, а не измеренный минимум.
* Свободное место на диске Windows, где хранятся данные WSL и Docker. Заложите не менее 40 ГБ для полной конфигурации TeX Live и данных проектов; базовый образ из [шага 5](/ru/on-premises/installation/using-docker-compose/windows/5.-personalizing-your-instance) меньше и подходит для первоначальной проверки развертывания. Дополнительные версии образов требуют дополнительного места.
* Сетевой доступ к GitHub, GitHub Container Registry (`ghcr.io`) и Docker Hub, чтобы клонировать Toolkit и загружать образы.

Блоки **PowerShell** выполняются в Windows. Блоки **Bash** и команды `bin/` выполняются в Ubuntu, если не указано иное. Не запускайте скрипты Toolkit в PowerShell или Windows Git Bash.
