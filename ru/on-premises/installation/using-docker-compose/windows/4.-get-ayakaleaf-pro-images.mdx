Ayakaleaf Pro — бесплатный Docker-образ в [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Чтобы загрузить его, не нужны ни учётная запись, ни вход, ни коммерческая лицензия Overleaf.

Откройте `config/overleaf.rc` и задайте:

```bash title="config/overleaf.rc"
SERVER_PRO=true
```

При следующем запуске `bin/up` Toolkit загрузит `ghcr.io/ayaka-notes/overleaf-pro` в версии из `config/version` вместо официальной Overleaf Community Edition.

Образ собран для `arm64` и `amd64`, и Docker выбирает тот, который соответствует архитектуре движка Docker.
