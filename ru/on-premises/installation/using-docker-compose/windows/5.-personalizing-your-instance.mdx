Выполняйте команды и редактируйте файлы в **Ubuntu**, в каталоге `~/ayakaleaf-toolkit`.

<Steps>
<Step title="Настройки контейнеров">
Измените существующие записи в `config/overleaf.rc`:

```bash title="config/overleaf.rc"
PROJECT_NAME=ayakaleaf-wsl
SERVER_PRO=true
OVERLEAF_LISTEN_IP=127.0.0.1
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
DOCKER_SOCKET_PATH=/var/run/docker.sock
```

Оставьте пути к данным по умолчанию и входящие в комплект сервисы MongoDB и Redis. Порт `8080` предназначен для локального браузера Windows; привязка к `127.0.0.1` делает его доступным только локально. Изолированные компиляции используют отдельный Linux-контейнер для каждой компиляции, а не запускают TeX внутри контейнера приложения. Сокет Docker позволяет приложению создавать эти контейнеры, а Toolkit предоставляет путь на хосте для данных компиляции в `data/overleaf/data/compiles`.
</Step>

<Step title="Настройки приложения">
В `config/variables.env` задайте следующие значения, заменив все активные записи с теми же именами:

```dotenv title="config/variables.env"
OVERLEAF_SITE_URL=http://localhost:8080
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES="TeX Live 2026"
```

Полный образ включает пакеты и шрифты, необходимые для широкого круга проектов. Заложите не менее 40 ГБ свободного места для него и приложения, а также место для данных проектов и будущих обновлений.

Для быстрой проверки развертывания используйте вместо него меньший **базовый** (basic) образ. Его достаточно для проверки с простой статьёй на шаге 6, но он не содержит полного набора пакетов и шрифтов:

```dotenv
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-basic:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-basic:2026.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES="TeX Live 2026 Basic"
```

Выберите один из этих наборов, без дублирующихся активных ключей. [Dockerfile](https://github.com/ayaka-notes/texlive-full/blob/main/texlive/2026/Dockerfile.basic) базового образа включает `latexmk`, XeTeX и `fontspec`, но не `ctex` и не полную коллекцию шрифтов. Отсутствие пакета LaTeX в базовом образе само по себе не указывает на проблему с песочницей.

Сгенерируйте секрет сеанса:

```bash
openssl rand -hex 32
```

Добавьте результат как `OVERLEAF_SESSION_SECRET` в `config/variables.env`. Также сохраните сгенерированный секрет токенов приглашений. Для локального экземпляра без электронной почты не задавайте настройки SMTP и `OVERLEAF_EMAIL_FROM_ADDRESS`.
</Step>

<Step title="Запустите экземпляр">
```bash
bin/up -d
```

Toolkit запускает MongoDB, инициализирует её набор реплик, загружает выбранный образ TeX Live и запускает Redis и приложение. Во время загрузки большого образа может показаться, что процесс остановился. Не запускайте второй `bin/up`, пока первый ещё работает.

В другом терминале Ubuntu проверьте:

```bash
cd "$HOME/ayakaleaf-toolkit"
bin/docker-compose ps
bin/docker-compose logs --tail=100 mongo
bin/docker-compose logs --tail=100 -f sharelatex
```

Нажмите `Ctrl+C`, чтобы прекратить просмотр журналов; контейнеры, запущенные в фоновом режиме, продолжат работать. Если запуск завершается ошибкой на MongoDB, выполните шаги из раздела [MongoDB не запускается](/ru/on-premises/installation/using-docker-compose/windows/troubleshooting#mongodb-fails-to-start), прежде чем повторять попытку. Не удаляйте её каталог данных, чтобы сбросить существующую установку.

Проверьте порт и страницу первого запуска:

```bash
bin/docker-compose port sharelatex 80
curl -I http://localhost:8080/launchpad
```

Порт должен быть `127.0.0.1:8080`. Если HTTP-запрос сначала завершается ошибкой, дождитесь окончания инициализации приложения.
</Step>

<Step title="Откройте экземпляр из Windows">
В **браузере Windows** откройте [http://localhost:8080/launchpad](http://localhost:8080/launchpad). Используйте этот адрес и в Windows, а не временный IP-адрес WSL.

Чтобы проверить HTTP-доступ из Windows отдельно от браузера, выполните в **PowerShell**:

```powershell
curl.exe -I http://localhost:8080/launchpad
```

Если Ubuntu может открыть страницу, а Windows — нет, см. раздел [Windows не может открыть localhost](/ru/on-premises/installation/using-docker-compose/windows/troubleshooting#windows-cannot-open-localhost).
</Step>
</Steps>
