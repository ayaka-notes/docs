---
title: 3. Инициализация конфигурации
description: Создайте конфигурационные файлы Toolkit в Ubuntu на WSL 2 с помощью bin/init.
icon: circle-play
---

В каталоге Toolkit в **Ubuntu** выполните:

```bash
bin/init
```

`bin/init` создаёт три файла:

| Файл | Назначение |
| --- | --- |
| `config/overleaf.rc` | Настройки контейнеров, публикуемый порт и расположение данных |
| `config/variables.env` | Настройки приложения и секреты |
| `config/version` | Версия образа приложения |

Кроме того, он генерирует `OVERLEAF_INVITE_TOKEN_SECRET` в `config/variables.env`. Сохраните его и не публикуйте этот файл и не добавляйте его в систему контроля версий.

Оставьте версию, которую Toolkit выбирает для новой установки. Чтобы позже изменить версию существующего экземпляра, следуйте разделу [Обновление развертывания](/ru/on-premises/maintenance/upgrading-your-deployment).

<Info>

`bin/init` не перезаписывает существующую конфигурацию. Если он сообщает, что файлы уже существуют, изучите их, прежде чем продолжить. Сохраняйте `config/` и `data/` при перезапуске или обновлении экземпляра.

</Info>
