Toolkit такой же, как в Linux. Его структура, каталог `config/` и команды `bin/` описаны в разделе [2. Знакомство с Toolkit](/ru/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) руководства для Linux.

В Windows помните о следующих отличиях:

* Выполняйте команды `bin/` в **Ubuntu Bash** из каталога `~/ayakaleaf-toolkit`. Команды, помеченные как **PowerShell**, выполняются в Windows.
* Запустите Docker Desktop и включите WSL Integration для Ubuntu, прежде чем использовать `bin/up`, `bin/start` или `bin/docker-compose`.
* Сохраняйте конфигурационные файлы с окончаниями строк Linux (LF). Редактируйте их с помощью `nano` в Ubuntu или в редакторе, подключённом к WSL. Окончания строк CRLF могут вызывать ошибки Bash.
* `bin/doctor` выполняет проверки Linux внутри Ubuntu. Его предупреждение об отсутствии входа в `quay.io` не относится к публичному образу `ghcr.io/ayaka-notes/overleaf-pro`. На остальные предупреждения по-прежнему нужно обращать внимание.

```bash
bin/doctor
```
