Docker Compose на одном сервере — рекомендуемый способ развертывания Ayakaleaf Pro. Вы запускаете его через [Toolkit](https://github.com/ayaka-notes/toolkit): набор скриптов, которые служат обёрткой для `docker compose` и читают ваши настройки из одного каталога `config/`, поэтому `bin/up` заменяет `docker compose up`.
