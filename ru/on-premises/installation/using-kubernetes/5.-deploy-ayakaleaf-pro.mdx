```yaml title="40-overleaf.yaml" wrap
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: overleaf-data
  namespace: overleaf
spec:
  accessModes: [ReadWriteOnce]
  resources:
    requests:
      storage: 20Gi
---
apiVersion: apps/v1
kind: Deployment
metadata:
  name: overleaf
  namespace: overleaf
spec:
  replicas: 1
  strategy:
    type: Recreate          # one pod owns the data volume; never run two at once
  selector:
    matchLabels:
      app: overleaf
  template:
    metadata:
      labels:
        app: overleaf
    spec:
      terminationGracePeriodSeconds: 60   # time to flush pending edits, like the Toolkit
      # Keep the environment to what the ConfigMap and Secret set: no REDIS_PORT=tcp://... and the like
      enableServiceLinks: false
      containers:
        - name: sharelatex
          image: ghcr.io/ayaka-notes/overleaf-pro:6.3.2
          envFrom:
            - configMapRef:
                name: overleaf-env
            - secretRef:
                name: overleaf-secrets
          ports:
            - containerPort: 80
          readinessProbe:
            httpGet:
              path: /status
              port: 80
            periodSeconds: 10
          resources:
            requests:
              cpu: 500m
              memory: 1536Mi
            limits:
              memory: 3Gi
          volumeMounts:
            - name: data
              mountPath: /var/lib/overleaf
            - name: compiles
              mountPath: /var/lib/overleaf/data/compiles
            - name: output
              mountPath: /var/lib/overleaf/data/output
            - name: cache
              mountPath: /var/lib/overleaf/data/cache
            - name: docker-sock
              mountPath: /var/run/docker.sock
      volumes:
        - name: data
          persistentVolumeClaim:
            claimName: overleaf-data
        # Compile scratch space on the node; same paths as SANDBOXED_COMPILES_HOST_DIR_*
        - name: compiles
          hostPath:
            path: /srv/overleaf/compiles
            type: DirectoryOrCreate
        - name: output
          hostPath:
            path: /srv/overleaf/output
            type: DirectoryOrCreate
        - name: cache
          hostPath:
            path: /srv/overleaf/cache
            type: DirectoryOrCreate
        - name: docker-sock
          hostPath:
            path: /var/run/docker.sock
            type: Socket
---
apiVersion: v1
kind: Service
metadata:
  name: overleaf
  namespace: overleaf
spec:
  type: NodePort
  selector:
    app: overleaf
  ports:
    - name: http
      port: 80
      targetPort: 80
      nodePort: 30080
```

```bash
kubectl apply -f 40-overleaf.yaml
kubectl -n overleaf rollout status deployment/overleaf --timeout=10m
kubectl -n overleaf logs deployment/overleaf | grep -E 'Finished migrations|Missing required'
```

Первый запуск выполняет миграции базы данных и занимает минуту-две. Под готов, когда отвечает `/status`; после этого откройте `OVERLEAF_SITE_URL`.

### Почему манифест выглядит именно так

* <strong>Том данных.</strong> Всё, что находится в `/var/lib/overleaf` (файлы проектов, история, загрузки), хранится на PVC. С локальным хранилищем узла, таким как local-path, данные остаются на одном узле; с сетевым блочным хранилищем под может перемещаться между узлами.
* <strong>Тома компиляции и сокет Docker.</strong> Ayakaleaf Pro просит Docker узла запустить контейнер TeX Live и передаёт ему каталог компиляции проекта **по его пути на узле**. Поэтому эти каталоги — тома `hostPath`, а их пути повторяются в `SANDBOXED_COMPILES_HOST_DIR_*`. Их содержимое — временные данные, которым не нужно резервное копирование.
* <strong>`enableServiceLinks: false`.</strong> Kubernetes добавляет в каждый под переменные в стиле Docker для каждого Service пространства имён: Service `redis` превращается в `REDIS_PORT=tcp://10.x.x.x:6379`, Service `git-bridge` — в `GIT_BRIDGE_PORT=tcp://...`. Некоторые сервисы Overleaf читают переменные с такими именами. В этом поде побеждают настройки из `OVERLEAF_REDIS_*` и ConfigMap, но git-bridge принимает `GIT_BRIDGE_PORT` за свой порт и останавливается (см. [Интеграция с Git](/ru/on-premises/configuration/kubernetes/integrations/git-integration)). Отключение этих ссылок оставляет в окружении только то, что задали вы.
* <strong>`Recreate`.</strong> Два пода никогда не должны использовать один и тот же том данных или одновременно выполнять миграции.
* <strong>Публикация.</strong> Service типа NodePort отвечает на порту `30080` каждого узла. В продакшене поставьте перед ним ваш ingress-контроллер или балансировщик нагрузки и завершайте TLS там; он должен пропускать WebSocket, допускать тайм-ауты запросов в 10 минут (долгие компиляции) и загрузки размером 50 МБ, а также передавать `X-Forwarded-For` и `X-Forwarded-Proto`.
