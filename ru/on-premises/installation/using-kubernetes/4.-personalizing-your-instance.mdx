ConfigMap `overleaf-env` заменяет `config/variables.env` из Toolkit: сюда помещаются все переменные окружения из [документации Toolkit](/ru/on-premises/configuration/overleaf-toolkit/environment-variables), а секреты — в Secret из [шага 2](/ru/on-premises/installation/using-kubernetes/2.-create-the-namespace-and-secrets).

```yaml title="30-config.yaml" wrap
apiVersion: v1
kind: ConfigMap
metadata:
  name: overleaf-env
  namespace: overleaf
data:
  OVERLEAF_APP_NAME: Ayakaleaf Pro
  OVERLEAF_SITE_URL: http://192.0.2.10:30080      # the address users open; https://... behind TLS
  OVERLEAF_ADMIN_EMAIL: admin@example.com
  # Emails: add the sender and the SMTP server together, see Email delivery
  # All members, so that the driver finds the primary even when mongo-0 is down
  OVERLEAF_MONGO_URL: mongodb://mongo-0.mongo:27017,mongo-1.mongo:27017,mongo-2.mongo:27017/sharelatex?replicaSet=overleaf
  OVERLEAF_REDIS_HOST: redis
  REDIS_HOST: redis
  ENABLED_LINKED_FILE_TYPES: project_file,project_output_file,url
  ENABLE_CONVERSIONS: "true"
  EMAIL_CONFIRMATION_DISABLED: "true"
  # Requests arrive from kube-proxy or your ingress controller, inside the pod network
  OVERLEAF_TRUSTED_PROXY_IPS: loopback,10.244.0.0/16
  # Sandboxed compiles. The HOST_DIR paths are paths ON THE NODE: the hostPath volumes that
  # the Deployment mounts at /var/lib/overleaf/data/{compiles,output,cache}.
  SANDBOXED_COMPILES: "true"
  SANDBOXED_COMPILES_SIBLING_CONTAINERS: "true"
  DOCKER_RUNNER: "true"
  SANDBOXED_COMPILES_HOST_DIR_COMPILES: /srv/overleaf/compiles
  SANDBOXED_COMPILES_HOST_DIR_OUTPUT: /srv/overleaf/output
  SANDBOXED_COMPILES_HOST_DIR_CACHE: /srv/overleaf/cache
  # Each image must be pulled into Docker on every node that can run Ayakaleaf Pro (step 0)
  ALL_TEX_LIVE_DOCKER_IMAGES: ghcr.io/ayaka-notes/texlive-full:2026.1
  ALL_TEX_LIVE_DOCKER_IMAGE_NAMES: TeX Live 2026
  TEX_LIVE_DOCKER_IMAGE: ghcr.io/ayaka-notes/texlive-full:2026.1
```

```bash
kubectl apply -f 30-config.yaml
```

| Переменная                              | Значение                                                                                                                                                        |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_SITE_URL`                     | URL, который пользователи вводят в браузере. С NodePort из [шага 5](/ru/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro) — IP-адрес любого узла и порт `30080`; за ingress или балансировщиком нагрузки — его URL. |
| `OVERLEAF_MONGO_URL`                    | Ваш набор реплик. Используйте `?replicaSet=` с именем из `rs.initiate`.                                                                                        |
| `OVERLEAF_REDIS_HOST` и `REDIS_HOST`    | Обе — на Service Redis.                                                                                                                                        |
| `OVERLEAF_TRUSTED_PROXY_IPS`            | `loopback` плюс сети, из которых подключаются ваши прокси. `10.244.0.0/16` — сеть подов flannel; используйте CIDR подов вашего кластера.                       |
| `SANDBOXED_COMPILES_HOST_DIR_*`         | Пути на узле к томам компиляции. Они должны совпадать с томами `hostPath` из [шага 5](/ru/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro).  |

При работе за HTTPS также задайте `OVERLEAF_SECURE_COOKIE: "true"`, см. [TLS-прокси](/ru/on-premises/configuration/overleaf-toolkit/tls-proxy).

<Info>

Изменённый ConfigMap попадает в работающие поды только после перезапуска: `kubectl -n overleaf rollout restart deployment/overleaf`.

</Info>
