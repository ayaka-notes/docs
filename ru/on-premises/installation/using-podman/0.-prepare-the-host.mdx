---
title: 0. Подготовка хоста
description: Проверьте операционную систему и SELinux и установите git перед настройкой rootless Podman.
icon: server
---

Устанавливать Podman вручную не нужно: шаг [2. Запуск podman-setup](/ru/on-premises/installation/using-podman/2.-run-podman-setup) устанавливает его вместе с другими необходимыми пакетами. Здесь вы только проверяете хост и устанавливаете `git`, который нужен для загрузки Toolkit.

<Steps>
<Step title="Проверка операционной системы и SELinux">
Войдите в систему под пользователем, который будет запускать Ayakaleaf Pro, а не под `root`, и проверьте дистрибутив и режим SELinux:

```bash title="Check the host"
grep PRETTY_NAME /etc/os-release
getenforce
```

Вы должны увидеть RHEL, Rocky Linux, AlmaLinux или CentOS Stream версии 9 или новее и `Enforcing`:

```text
PRETTY_NAME="Rocky Linux 9.9 (Blue Onyx)"
Enforcing
```
</Step>

<Step title="Проверка доступа к sudo">
`bin/podman-setup --apply` устанавливает пакеты и загружает модуль SELinux через `sudo` и запрашивает ваш пароль, когда это нужно:

```bash title="Check sudo"
sudo -v
```

Если команда завершается ошибкой, попросите администратора добавить вашего пользователя в группу `wheel`.
</Step>

<Step title="Установка git">
```bash title="Install git"
sudo dnf install -y git
```

<Warning>

Не устанавливайте Docker Engine на этот хост. Пакет `podman-docker`, который устанавливает `bin/podman-setup`, предоставляет команду `docker`, а Toolkit считает хост хостом Podman, если существует команда `podman`.

</Warning>
</Step>
</Steps>
