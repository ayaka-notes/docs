### Создание первой учётной записи администратора {#create-your-first-administrator-account}

Откройте [http://localhost:8080/launchpad](http://localhost:8080/launchpad) или ваш `OVERLEAF_SITE_URL` с `/launchpad` на конце и зарегистрируйте учётную запись администратора. Дальше всё работает так же, как с Docker: следуйте шагу [6. Действия после установки](/ru/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks) руководства по Docker, используя порт `8080` в его ссылках на `localhost`.

Создайте пример проекта и скомпилируйте его. Появление PDF показывает, что компиляция выполняется в контейнерах TeX Live через Podman. Чтобы увидеть контейнер компиляции:

```bash title="List the compile containers"
podman ps -a --filter name=project- --format "{{.Names}} {{.Image}} {{.Status}}"
```

### Использование HTTPS {#use-https}

[TLS-прокси](/ru/on-premises/configuration/overleaf-toolkit/tls-proxy) из Toolkit работает на Podman: выполните `bin/init --tls`, укажите сертификат и `NGINX_ENABLED=true`, как описано там. Прокси слушает порты `80` и `443`, которые rootless Podman по умолчанию использовать не может. Разрешите непривилегированным пользователям использовать порты начиная с `80`:

```bash title="Allow ports 80 and 443"
echo "net.ipv4.ip_unprivileged_port_start=80" | sudo tee /etc/sysctl.d/99-unprivileged-ports.conf
sudo sysctl --system
```

Это позволяет любому пользователю сервера слушать эти порты, поэтому делайте так только на сервере, выделенном под Ayakaleaf Pro. Затем откройте их в брандмауэре:

```bash title="Open ports 80 and 443"
sudo firewall-cmd --permanent --add-port=80/tcp --add-port=443/tcp
sudo firewall-cmd --reload
```

Задайте в `OVERLEAF_SITE_URL` ваш адрес `https://` и выполните `bin/up -d`. Оставьте значения по умолчанию `NGINX_HTTP_PORT=80` и `TLS_PORT=443`: с другими портами перенаправление с HTTP на HTTPS ведёт на неверный порт.

<Info>

При использовании TLS-прокси оставьте `OVERLEAF_LISTEN_IP` равным `127.0.0.1`, чтобы порт `8080` был недоступен с других компьютеров.

</Info>

### Обновление {#upgrade}

Обновляйте экземпляр с помощью `bin/upgrade`, как описано в разделе [Обновление развёртывания](/ru/on-premises/maintenance/upgrading-your-deployment). На Podman эта команда также извлекает профиль seccomp новой версии в `config/seccomp/<version>/` и обновляет `SECCOMP_PROFILE`:

```text
Over-writing config/version with 6.3.4
Set SECCOMP_PROFILE=/home/<user>/overleaf-toolkit/config/seccomp/6.3.4/clsi-profile.json in config/variables.env
```

После обновления выполните `bin/podman-setup`, чтобы проверить настройку.

### Изменение режима SELinux {#change-the-selinux-mode}

`SELINUX_MODE` в `config/overleaf.rc` определяет, как SELinux ограничивает контейнер `sharelatex`. На этих страницах настраивается режим `managed`; остальные режимы описаны в разделе [Настройки Toolkit](/ru/on-premises/configuration/overleaf-toolkit/toolkit-settings). После изменения выполните `bin/up -d`.
