<Steps>
<Step title="Клонирование Toolkit">
Клонируйте **Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)) в домашний каталог и перейдите в него:

```bash title="Clone the Toolkit" wrap
git clone https://github.com/ayaka-notes/toolkit.git ~/overleaf-toolkit
cd ~/overleaf-toolkit
```

Выполняйте все последующие команды из этого каталога.
</Step>

<Step title="Создание конфигурации">
```bash title="Run initialization"
bin/init
```

Эта команда создаёт `config/overleaf.rc`, `config/variables.env` и `config/version`, как описано в шаге [3. Инициализация конфигурации](/ru/on-premises/installation/using-docker-compose/linux/3.-initialize-the-configuration) руководства по Docker. Для `bin/init` Podman пока не нужен.
</Step>

<Step title="Настройка config/overleaf.rc">
Откройте `config/overleaf.rc` и измените эти строки:

```bash title="config/overleaf.rc"
SERVER_PRO=true
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
```

Затем добавьте эту строку в конец файла:

```bash title="config/overleaf.rc"
SELINUX_MODE=managed
```

| Параметр                          | Зачем                                                                                                                                                                                                        |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `SERVER_PRO=true`                 | Использует образ Ayakaleaf Pro из `ghcr.io`. Вход в реестр не нужен.                                                                                                                                          |
| `OVERLEAF_PORT=8080`              | Rootless Podman не может слушать порты ниже `1024`. Порт по умолчанию `80` не работает.                                                                                                                       |
| `SIBLING_CONTAINERS_ENABLED=true` | Запускает каждую компиляцию в отдельном контейнере TeX Live. По умолчанию уже `true`; настройка Podman поддерживает только этот режим.                                                                        |
| `SELINUX_MODE=managed`            | Запускает контейнер `sharelatex` с типом SELinux `sharelatex_t`, которому разрешено использовать сокет Podman и ничего больше. `bin/podman-setup --apply` устанавливает для него модуль политики. Другие режимы описаны в разделе [Настройки Toolkit](/ru/on-premises/configuration/overleaf-toolkit/toolkit-settings). |

Оставьте `DOCKER_SOCKET_PATH` без изменений: на следующем шаге `bin/podman-setup --apply` укажет в нём ваш сокет Podman.

<Warning>

Оставьте `GIT_BRIDGE_ENABLED=false`. В Ayakaleaf Pro 6.3.4 интеграция с Git на Podman не работает, см. [Известные ограничения](/ru/on-premises/installation/using-podman#known-limitations).

</Warning>
</Step>

<Step title="Выбор образов TeX Live">
Откройте `config/variables.env`, удалите `#` перед `TEX_LIVE_DOCKER_IMAGE` и `ALL_TEX_LIVE_DOCKER_IMAGES` и перечислите образы TeX Live, которые нужно использовать:

```bash title="config/variables.env" wrap
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
```

Если список пуст, `bin/up` останавливается с сообщением `Please configure ALL_TEX_LIVE_DOCKER_IMAGES`. Образ `texlive-full` большой; для тестового сервера подойдёт и гораздо меньший `ghcr.io/ayaka-notes/texlive-basic:2026.1`. Доступные образы перечислены в разделе [Изолированная компиляция](/ru/on-premises/configuration/overleaf-toolkit/sandboxed-compiles).

Задайте остальные переменные, например `OVERLEAF_SITE_URL`, как описано в шаге [5. Персонализация экземпляра](/ru/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance#required-environment-variables). С адресом прослушивания по умолчанию используйте `http://localhost:8080`.
</Step>
</Steps>
