Overleaf работает на Docker. Необходимо установить:

* Docker Engine (Docker CE)
* Плагин Docker Compose (`docker compose`, v2)

Эти шаги рассчитаны на актуальные версии Ubuntu LTS (20.04/22.04/24.04).

<Warning>

Не устанавливайте `docker.io` из стандартного apt-репозитория Ubuntu.\
Используйте официальный репозиторий Docker, чтобы получить свежую версию Docker и плагин `docker compose`.

</Warning>

Официальная документация: [https://docs.docker.com/engine/install/ubuntu/](https://docs.docker.com/engine/install/ubuntu/).

<Steps>
<Step title="1) Удалите старые/конфликтующие пакеты (если есть)">
Если Docker ранее был установлен из другого источника, сначала удалите его:

```bash wrap
sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-compose-v2 docker-doc podman-docker containerd runc | cut -f1)
```

Эта команда безопасна, даже если некоторые пакеты не установлены.
</Step>

<Step title="2) Добавьте официальный apt-репозиторий Docker">
Установите необходимые компоненты:

```bash
sudo apt update
sudo apt install -y ca-certificates curl
```

Добавьте GPG-ключ Docker:

```bash wrap
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```

Добавьте репозиторий:

```bash wrap
# Add the repository to Apt sources:
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Signed-By: /etc/apt/keyrings/docker.asc
EOF

sudo apt update
```
</Step>

<Step title="3) Установите Docker Engine и плагин Compose">
Установите Docker и плагин Compose:

```bash wrap
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

Включите автозапуск Docker при загрузке системы:

```bash
sudo systemctl enable --now docker
```
</Step>

<Step title="4) Проверьте установку">
Эти команды должны выполняться без ошибок:

```bash
docker --version
docker compose version
sudo docker run --rm hello-world
docker ps
```
</Step>

<Step title="5) (Необязательно) Запуск Docker без sudo">
Добавьте своего пользователя в группу `docker`:

```bash
sudo usermod -aG docker $USER
```

Затем **выйдите из системы и войдите снова** или выполните:

```bash
newgrp docker
```

Теперь эта команда должна работать без `sudo`:

```bash
docker ps
```

<Danger>

Группа `docker` даёт доступ к хосту, эквивалентный правам root.\
Это ожидаемо для типичных установок Overleaf и особенно важно, если вы включаете Sandboxed Compiles.

</Danger>
</Step>
</Steps>
