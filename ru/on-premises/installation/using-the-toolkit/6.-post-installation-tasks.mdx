### Создание первой учётной записи администратора

Откройте в браузере [http://localhost/launchpad](http://localhost/launchpad). Вы увидите форму с полями для адреса электронной почты и пароля. Введите учётные данные, которые хотите использовать для учётной записи администратора, и нажмите **Register**.

<Info>

Пароль должен содержать не менее 8 символов (и не более 72), не может содержать адрес электронной почты или быть слишком похожим на него и должен состоять только из допустимых символов.

</Info>

![Overleaf Launchpad](/images/on-premises/image.jpg)

Затем перейдите по ссылке на страницу входа ([http://localhost/login](http://localhost/login)). Введите учётные данные. После входа вы увидите страницу приветствия.

![Страница приветствия Overleaf](/images/on-premises/image-1.jpg)

Нажмите зелёную кнопку внизу страницы, чтобы начать работу с Overleaf.

### Создание первого примера проекта

Откройте в браузере [http://localhost/project](http://localhost/project) — вы увидите кнопку с предложением создать первый проект.

![Добро пожаловать в Overleaf!](/images/on-premises/image-2.jpg)

Нажмите эту кнопку, выберите **Example Project** и следуйте инструкциям на экране.

Откроется новый проект с текстовым редактором и предварительным просмотром PDF.

![Редактор Overleaf](/images/on-premises/image-3.jpg)

В завершение нажмите значок **Home**, чтобы вернуться на страницу проектов.
