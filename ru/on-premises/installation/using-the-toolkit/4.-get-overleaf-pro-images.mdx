---
title: 4. Получение образов Ayakaleaf Pro
icon: split
---

Ayakaleaf Pro распространяется в виде образа Docker в реестре [ghcr](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/) с **открытым доступом** для всех. Мы предоставляем образы для архитектур amd64 и arm64. При загрузке образа подходящий вариант выбирается автоматически в зависимости от архитектуры вашей системы.

#### Пользователи Toolkit от Ayaka-notes

Если вы используете [ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit), Ayakaleaf Pro можно использовать как прямую замену Community Edition, сохранив существующие настройки и доработки. Включите Pro в Toolkit, отредактировав `config/overleaf.rc` и задав переменную окружения `SERVER_PRO`:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

При следующем запуске `bin/up` Toolkit автоматически загрузит и будет использовать образ Ayakaleaf Pro.

#### Пользователи официального Toolkit

Если вы используете [overleaf/toolkit](https://github.com/overleaf/toolkit), для получения образа Pro выполните следующую команду:

```bash title="Pull Docker Images"
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Затем добавьте в каталог `overleaf-toolkit/config` файл с именем `docker-compose.override.yml` со следующим содержимым:

```yml title="docker-compose.override.yml"
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

При следующем запуске `bin/up` Toolkit автоматически загрузит и будет использовать образ Ayakaleaf Pro.
