### Загрузка Toolkit

Ayakaleaf Pro устанавливается с помощью **Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)) — набора скриптов, который запускает Overleaf в Docker за вас.

По умолчанию Toolkit запускает бесплатную официальную редакцию Overleaf Community Edition (CE). В разделе [4. Получение образов Ayakaleaf Pro](/ru/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images) описано, как переключить его на Ayakaleaf Pro одной настройкой.

<Accordion title="Вы уже используете официальный Overleaf Toolkit (overleaf/toolkit)?">

Переустанавливать ничего не нужно. Сохраните свою установку и выполните действия из последней части раздела [4. Получение образов Ayakaleaf Pro](/ru/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images).

</Accordion>

<Steps>
<Step title="Клонирование репозитория Ayakaleaf Toolkit">
Чтобы установить Toolkit, перейдите в каталог, куда планируете выполнить установку, и клонируйте репозиторий Ayakaleaf Toolkit с помощью этой команды:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
```

<Info>

Чтобы избежать возможных проблем с правами доступа, мы рекомендуем устанавливать Toolkit в домашний каталог пользователя `$HOME`.

</Info>
</Step>

<Step title="Переход в каталог Toolkit">
Дождитесь завершения клонирования, а затем перейдите в только что созданный каталог `overleaf-toolkit`:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
