### Загрузка Toolkit

Toolkit совместим как с Server CE, так и с Ayakaleaf Pro и является рекомендуемым способом установки. С помощью Toolkit вы сможете легко начать работу с Server CE и при необходимости беспрепятственно перейти на Ayakaleaf Pro.

<Info>

[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) изменён так, чтобы напрямую использовать образ overleaf-pro из ghcr, а TeX Live предоставляется ayaka-notes. В качестве альтернативы вы можете загрузить официальный overleaf-toolkit.

</Info>

<Steps>
<Step title="Клонирование репозитория Overleaf Toolkit">
Чтобы установить Toolkit, перейдите в каталог, куда планируете выполнить установку, и клонируйте GitHub-репозиторий Overleaf Toolkit (@Ayaka-notes) с помощью этой команды:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
# official toolkit (Not Recommended)
# git clone https://github.com/overleaf/toolkit.git ./overleaf-toolkit
```

<Info>

Чтобы избежать возможных проблем с правами доступа, мы рекомендуем устанавливать Toolkit в домашний каталог пользователя `$HOME`.

</Info>
</Step>

<Step title="Переход в каталог Toolkit">
Дождитесь завершения клонирования, а затем перейдите в только что созданный каталог `overleaf-toolkit`:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
