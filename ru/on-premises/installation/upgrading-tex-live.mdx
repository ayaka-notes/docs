<Danger>

Следующие инструкции относятся **только** к установкам **Community Edition**. Мы настоятельно рекомендуем пользователям Ayakaleaf Pro включить [Sandboxed Compiles](/ru/on-premises/configuration/overleaf-toolkit/sandboxed-compiles): это даёт пользователям доступ практически к тем же образам TeX Live, что используются на [overleaf.com](https://www.overleaf.com), а также изолирует компиляции проектов друг от друга для повышения безопасности.

</Danger>

Для экономии трафика образы Overleaf Community Edition и Ayakaleaf Pro поставляются с минимальной установкой [TeX Live](https://www.tug.org/texlive/). Вы можете установить дополнительные пакеты или перейти на полную установку TeX Live с помощью команды [tlmgr](https://www.tug.org/texlive/tlmgr.html) в контейнере `sharelatex`.

#### Вход в контейнер sharelatex

Чтобы запустить оболочку внутри контейнера `sharelatex`, выполните

```bash
bin/shell
```

Вы увидите приглашение следующего вида:

```bash
root@309b192d4030:/#
```

В дальнейших инструкциях предполагается, что вы находитесь внутри контейнера.

#### Определение текущей версии TeX Live

TeX Live выпускается ежегодно примерно в апреле. Порядок работы с `tlmgr` различается в зависимости от того, используете ли вы текущий выпуск или более старый. Проверить, какая версия TeX Live у вас установлена, можно командой `tlmgr --version`. Например, в этой установке используется TeX Live 2021:

```bash
# tlmgr --version
tlmgr revision 59291 (2021-05-21 05:14:40 +0200)
tlmgr using installation: /usr/local/texlive/2021
TeX Live (https://tug.org/texlive) version 2021
```

<Info>

Текущий выпуск TeX Live можно узнать на [домашней странице TeX Live](https://www.tug.org/texlive/).

</Info>

Если у вас более старая версия TeX Live, есть два варианта. Новая версия Docker-образа Overleaf обычно выходит вскоре после выпуска TeX Live: вы можете дождаться её и обновить развёртывание с помощью скрипта `bin/upgrade` либо, если вы предпочитаете остаться на старом выпуске TeX Live, сначала указать `tlmgr` использовать исторический репозиторий. Инструкции для этого находятся [здесь](https://www.tug.org/texlive/acquire.html#past).

#### Установка пакетов

Чтобы выполнить полную установку TeX Live, выполните внутри контейнера `sharelatex` следующую команду:

```text
tlmgr install scheme-full
```

Также можно установить отдельные пакеты вручную:

```bash
tlmgr install tikzlings tikzmarmots tikzducks
```

<Warning>

Начиная с выпуска `3.3.0`, после каждого использования `tlmgr install` снова **необходимо** выполнять `tlmgr path add`, чтобы корректно создать символические ссылки на все исполняемые файлы в системном пути.

</Warning>

Доступно и множество других команд. Подробнее о них можно узнать с помощью:

```text
tlmgr help
```

Когда закончите, введите `exit` или нажмите Control-D, чтобы выйти из оболочки.

#### Сохранение изменений

Внесённые изменения затронули контейнер `sharelatex`, но они временные — они будут потеряны, если Docker Compose пересоздаст контейнер, например при обновлении конфигурации.

Чтобы сделать их постоянными, сохраните изменения в новый Docker-образ с помощью `docker commit`:

```bash
cat config/version #5.2.1
docker commit sharelatex sharelatex/sharelatex:5.2.1-with-texlive-full
echo 5.2.1-with-texlive-full > config/version
```

После сохранения изменений обновите соответствующим образом файл `config/version`. Затем выполните `bin/up`, чтобы пересоздать контейнер `sharelatex`.

<Danger>

Эти шаги придётся повторять при каждом [обновлении](https://github.com/overleaf/toolkit/blob/master/doc/upgrading.md) до новой версии Overleaf.

</Danger>
