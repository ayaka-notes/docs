<Info>

Ayakaleaf Pro — расширенная реализация Overleaf Community Edition, предлагающая все премиум-функции Server Pro _**бесплатно**_. В отличие от Overleaf Common, доступного на [https://www.overleaf.com/](https://www.overleaf.com/), у нас нет ограничений на время компиляции и лицензионных требований к количеству пользователей, а свои данные вы можете полностью размещать самостоятельно, обеспечивая абсолютную безопасность.

Overleaf Server Pro — коммерческая самостоятельно размещаемая версия Overleaf с официальной поддержкой. Подробнее о Server Pro см. на странице [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud).

</Info>

<Warning>

Overleaf Community Edition предназначена для использования в средах, где **все** пользователи являются доверенными. Community Edition **не** подходит для сценариев, требующих изоляции пользователей, поскольку в ней недоступны Sandbox Compiles (изолированные компиляции).

Без изоляции компиляция LaTeX выполняется с теми же привилегиями, что и контейнер, что даёт доступ к его файловой системе, сети и переменным окружения. Это создаёт риск утечки данных или компрометации системы. Компиляцию без изоляции следует использовать только в полностью доверенных средах; для многопользовательских или production-развёртываний настоятельно рекомендуется использовать Sandbox Compiles.

Подробнее о Sandbox Compiles см. в нашей [документации](/ru/on-premises/configuration/overleaf-toolkit/sandboxed-compiles).

</Warning>

### Поддержка сообщества

Пользователям самостоятельно размещённых экземпляров Overleaf поддержку оказывает сообщество через [Issues](https://github.com/ayaka-notes/ayakaleaf-pro/issues) на GitHub.

Чтобы оставаться на поддерживаемой версии, вы можете проверить, какая версия Overleaf у вас запущена, сравнив вывод приведённой ниже команды с Image ID, опубликованными в примечаниях к выпускам.

```bash
docker inspect --format '{{.Image}}' sharelatex | awk -F: '{print substr($2, 1, 12)}'
```
