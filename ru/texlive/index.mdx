[TeX Live](https://www.tug.org/texlive/) — это свободный программный дистрибутив, ежегодно выпускаемый [TeX Users Group](https://www.tug.org/). Он содержит пакеты LaTeX, шрифты, движки TeX и множество программных инструментов, необходимых для вёрстки на основе LaTeX во всех стандартных операционных системах.

TeX Live — важный компонент Overleaf, поскольку наши серверы используют его для компиляции вашего кода LaTeX и формирования PDF-предпросмотра в реальном времени. Кроме того, он даёт пользователям Overleaf простой доступ к более чем 5000 пакетов LaTeX, входящих в каждый выпуск TeX Live.

Вы не ограничены последней версией TeX Live при компиляции проектов, поскольку серверы Overleaf предоставляют доступ и к предыдущим выпускам TeX Live. Проект можно легко переключить на более раннюю версию TeX Live — например, из-за проблем с совместимостью пакетов.<br />
