title: docstore

Хранит каждый документ (строки, версию, диапазоны) каждого проекта в коллекции Mongo `docs` и архивирует документы в объектное хранилище, если задан бэкенд. Вызывается web; document-updater обращается к нему через web.

* <strong>Адрес:</strong> `http://docstore:3016`, внутри сети Docker
* <strong>Аутентификация:</strong> нет
* <strong>Файл OpenAPI:</strong> [`develop/hoppscotch/openapi/docstore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/docstore.yaml)
