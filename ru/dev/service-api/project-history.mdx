Ставит правки каждого проекта в очередь в Redis, превращает их в изменения истории и отправляет в history-v1; также хранит в Mongo метки истории, состояние ресинхронизации и записи об ошибках. Вызывается web, document-updater, history-v1 и cron-скриптами server-ce; аутентификации нет.

* <strong>Адрес:</strong> `http://project-history:3054`, внутри сети Docker
* <strong>Аутентификация:</strong> нет
* <strong>Файл OpenAPI:</strong> [`develop/hoppscotch/openapi/project-history.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/project-history.yaml)
