Хранит уведомления, которые пользователи видят в списке проектов (например, приглашения в проекты), в коллекции Mongo `notifications`. Его вызывают web и third-party-datastore; аутентификации нет, доступен только внутри сети Docker.

* <strong>Адрес:</strong> `http://notifications:3042`, внутри сети Docker
* <strong>Аутентификация:</strong> нет
* <strong>Файл OpenAPI:</strong> [`develop/hoppscotch/openapi/notifications.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/notifications.yaml)
