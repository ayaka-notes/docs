Отдаёт файлы из объектного хранилища: файлы шаблонов (zip, pdf и их изображения предпросмотра) и, только для чтения, проектные и глобальные блобы, которые записывает history-v1. Вызывается web (модуль template-gallery, URL файлов компиляции) и clsi, который скачивает из него бинарные файлы проекта.

* <strong>Адрес:</strong> `http://filestore:3009`, внутри сети Docker
* <strong>Аутентификация:</strong> нет
* <strong>Файл OpenAPI:</strong> [`develop/hoppscotch/openapi/filestore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/filestore.yaml)
