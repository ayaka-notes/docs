Хранит чат проекта и ветки комментариев (их сообщения и статус «решено») в коллекциях Mongo `rooms` и `messages`. Вызывается web через `ChatApiHandler`.

* <strong>Адрес:</strong> `http://chat:3010`, внутри сети Docker
* <strong>Аутентификация:</strong> нет
* <strong>Файл OpenAPI:</strong> [`develop/hoppscotch/openapi/chat.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/chat.yaml)
