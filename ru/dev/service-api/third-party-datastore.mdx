Синхронизирует проекты с Dropbox: держит по одной очереди заданий Redis на пользователя и воркер, который отправляет изменения Overleaf в Dropbox и опрашивает Dropbox на предмет изменений. Вызывает его только web, чтобы ставить задания в очередь и читать размеры очередей.

* <strong>Адрес:</strong> `http://third-party-datastore:3002`, внутри сети Docker
* <strong>Аутентификация:</strong> нет
* <strong>Файл OpenAPI:</strong> [`develop/hoppscotch/openapi/third-party-datastore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/third-party-datastore.yaml)
