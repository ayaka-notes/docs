Хранит полную историю каждого проекта: фрагменты изменений в Mongo или Postgres и объектном хранилище, а содержимое файлов в виде блобов. project-history записывает в него изменения; web, project-history и git-bridge читают из него блобы, снимки и zip-архивы.

* <strong>Адрес:</strong> `http://history-v1:3100`, внутри сети Docker
* <strong>Аутентификация:</strong> HTTP basic auth от имени `staging` с `STAGING_PASSWORD` или JWT, в зависимости от маршрута.
* <strong>Файл OpenAPI:</strong> [`develop/hoppscotch/openapi/history-v1.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/history-v1.yaml)
