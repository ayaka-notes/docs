CLSI (Common LaTeX Service Interface) компилирует проекты, запускает SyncTeX и texcount над результатом компиляции и конвертирует документы с помощью pandoc. Его вызывает web; сами выходные файлы отдаёт clsi-nginx, а не этот порт. Без аутентификации: он доступен только внутри сети Docker.

* <strong>Адрес:</strong> `http://clsi:3013`, внутри сети Docker
* <strong>Аутентификация:</strong> нет
* <strong>Файл OpenAPI:</strong> [`develop/hoppscotch/openapi/clsi.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/clsi.yaml)
