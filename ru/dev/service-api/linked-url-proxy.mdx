Загружает внешний URL для web и передаёт ответ потоком обратно, отклоняя внутренние адреса, чтобы пользователи не могли попасть в сеть Docker. Через него web отправляет URL-файлы, импорт Open in Overleaf и web_fetch ИИ-агента.

* <strong>Адрес:</strong> `http://linked-url-proxy:3066`, внутри сети Docker
* <strong>Аутентификация:</strong> нет
* <strong>Файл OpenAPI:</strong> [`develop/hoppscotch/openapi/linked-url-proxy.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/linked-url-proxy.yaml)
