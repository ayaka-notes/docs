Приватный API web, основного приложения Overleaf. Его вызывают другие сервисы (real-time, document-updater, project-history, third-party-datastore, git-bridge) и cron-скрипты образа Server CE. Этим маршрутам нужна только HTTP basic auth, без CSRF-токена: приватный роутер подключается раньше веб-роутера, и проверку CSRF выполняет только веб-роутер. При `BLOCK_CROSS_ORIGIN_REQUESTS=true` (по умолчанию выключено) web возвращает 403 на любой запрос, заголовок `Origin` которого не входит в `ALLOWED_ORIGINS` (по умолчанию: URL сайта). Браузеры отправляют `Origin` в POST-запросах, поэтому при включённом параметре POST-запросы из Hoppscotch в браузере получают 403, если не идут через прокси Hoppscotch.

* <strong>Адрес:</strong> `http://web:3000`, внутри сети Docker
* <strong>Аутентификация:</strong> HTTP basic auth с `WEB_API_USER` и `WEB_API_PASSWORD`, кроме status, health и metrics. Маршруты git-bridge вместо этого используют персональный токен доступа.
* <strong>Файл OpenAPI:</strong> [`develop/hoppscotch/openapi/web.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/web.yaml)
