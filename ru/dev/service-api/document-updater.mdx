Держит открытые в редакторе документы в Redis, применяет к ним правки и через web записывает их обратно в Mongo. Вызывается web и real-time.

* <strong>Адрес:</strong> `http://document-updater:3003`, внутри сети Docker
* <strong>Аутентификация:</strong> нет
* <strong>Файл OpenAPI:</strong> [`develop/hoppscotch/openapi/document-updater.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/document-updater.yaml)
