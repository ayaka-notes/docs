Overleaf работает как набор сервисов, которые вызывают друг друга по HTTP внутри сети Docker. Страницы этого раздела описывают эти внутренние API. Они основаны на файлах OpenAPI в [`develop/hoppscotch/openapi/`](https://github.com/ayaka-notes/ayakaleaf-pro/tree/server-pro/develop/hoppscotch/openapi), написанных по коду каждого сервиса.

Ни один из этих API не является публичным: они доступны только внутри сети Docker, и у большинства нет аутентификации.

## Сервисы {#services}

| Сервис | Адрес | Что делает |
| ------------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------------------ |
| [web](/ru/dev/service-api/web)                                     | `http://web:3000`                   | Основное приложение. Его приватный API вызывают другие сервисы и cron-скрипты образа  |
| [document-updater](/ru/dev/service-api/document-updater)           | `http://document-updater:3003`      | Держит открытые в редакторе документы в Redis, применяет правки и записывает их обратно в Mongo         |
| [docstore](/ru/dev/service-api/docstore)                           | `http://docstore:3016`              | Хранит каждый документ каждого проекта в коллекции Mongo `docs`                                 |
| [real-time](/ru/dev/service-api/real-time)                         | `http://real-time:3026`             | Держит socket.io-соединения редактора и пересылает правки между браузерами и сервисами          |
| [chat](/ru/dev/service-api/chat)                                   | `http://chat:3010`                  | Хранит чат проекта и ветки комментариев                                                  |
| [project-history](/ru/dev/service-api/project-history)             | `http://project-history:3054`       | Превращает правки из очереди в изменения истории и отправляет их в history-v1; хранит метки               |
| [history-v1](/ru/dev/service-api/history-v1)                       | `http://history-v1:3100`            | Хранит полную историю каждого проекта и содержимое файлов в виде блобов                           |
| [filestore](/ru/dev/service-api/filestore)                         | `http://filestore:3009`             | Отдаёт файлы шаблонов и, только для чтения, блобы, записанные history-v1                           |
| [clsi](/ru/dev/service-api/clsi)                                   | `http://clsi:3013`                  | Компилирует проекты, запускает SyncTeX и подсчёт слов, конвертирует документы                              |
| [notifications](/ru/dev/service-api/notifications)                 | `http://notifications:3042`         | Хранит уведомления, показываемые в списке проектов                                               |
| [linked-url-proxy](/ru/dev/service-api/linked-url-proxy)           | `http://linked-url-proxy:3066`      | Загружает внешние URL для web и отклоняет внутренние адреса                                     |
| [third-party-datastore](/ru/dev/service-api/third-party-datastore) | `http://third-party-datastore:3002` | Синхронизирует проекты с Dropbox через одну очередь заданий на пользователя                                       |

## Аутентификация {#authentication}

* <strong>web:</strong> HTTP basic auth с `WEB_API_USER` и `WEB_API_PASSWORD`. Маршруты git-bridge вместо этого используют персональный токен доступа.
* <strong>history-v1:</strong> HTTP basic auth от имени `staging` с `STAGING_PASSWORD` или JWT.
* <strong>Все остальные сервисы:</strong> нет.

## Попробовать {#try-them}

Среда разработки запускает [Hoppscotch](https://github.com/hoppscotch/hoppscotch) на `http://localhost:9170` с прокси, который обращается к сервисам по их адресам в Docker. В её [README](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/README.md#hoppscotch) описано, как настроить прокси и импортировать файлы OpenAPI.
