`Project` представляет отдельный проект LaTeX в Overleaf. В нём хранятся метаданные проекта, сведения о владельце и управлении доступом, файловая структура, настройки компиляции и состояние совместной работы.

#### Основная идентификация и метаданные

* `_id`: уникальный MongoDB ObjectId, идентифицирующий проект.
* `name`: отображаемое имя проекта.
* `description`: необязательное текстовое описание проекта.
* `active`: указывает, активен ли проект в данный момент.
* `version`: внутренняя версия схемы или формата проекта.
* `trashed`: список элементов, перемещённых в корзину (мягкое удаление).
* `deletedDocs`: записи о безвозвратно удалённых документах.

#### Владение и управление доступом

* `owner_ref`: ссылка на пользователя, владеющего проектом.
* `collaberator_refs`: пользователи с правами на редактирование.
* `reviewer_refs`: пользователи с доступом уровня рецензента.
* `readOnly_refs`: пользователи с доступом только для чтения.
* `pendingEditor_refs` / `pendingReviewer_refs`: ожидающие приглашения.

#### Доступ на основе токенов

* `tokens`: реестр токенов для общих ссылок.
* `tokenAccessReadOnly_refs`: токены, предоставляющие доступ только для чтения.
* `tokenAccessReadAndWrite_refs`: токены, предоставляющие доступ на чтение и запись.

#### Отслеживание активности

* `lastUpdated`: временная метка последнего изменения.
* `lastUpdatedBy`: пользователь, выполнивший последнее изменение.
* `lastOpened`: временная метка последнего открытия проекта.
* `deletedByExternalDataSource`: было ли удаление инициировано внешней интеграцией.

#### Структура проекта

Корневой документ и папка

* `rootDoc_id`: ObjectId основного входного документа LaTeX (обычно `main.tex`).
* `rootFolder`: встроенное представление дерева файлов проекта.

Каждая запись папки содержит:

* `name` / `_id`: имя и идентификатор папки.
* `docs`: список исходных документов LaTeX с именем и `_id`.
* `fileRefs`: ссылки на бинарные файлы (изображения, файлы данных), включая:
  * `name`: имя файла
  * `created`: временная метка загрузки
  * `rev`: счётчик ревизий
  * `hash`: хеш содержимого для дедупликации
  * `linkedFileData`: связь с внешним хранилищем (если есть)
* `folders`: вложенные подпапки.

#### Настройки компиляции и редактора

* `compiler`: выбранный движок LaTeX (`pdflatex`, `xelatex`, `lualatex` и т. д.).
* `spellCheckLanguage`: язык проверки орфографии для этого проекта.

#### Настройки публичного доступа и совместного использования

* `publicAccesLevel`: видимость проекта (`private`, `readOnly`, `public` и т. д.).
* `collabratecUsers`: связанные пользователи из внешних платформ для совместной работы.

#### Расширения, специфичные для Overleaf

* `overleaf.history`:
  * `id`: идентификатор, используемый сервисом истории.
  * `display`: включена ли история и отображается ли она.

#### Внутреннее версионирование

* `__v`: внутренний ключ версии Mongoose для управления параллельным доступом.
