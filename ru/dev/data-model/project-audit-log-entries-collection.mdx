`projectAuditLogEntries` представляет собой журнал аудита проектов: общий доступ, приглашения, передача владения, скачивания и действия администраторов. Каждый документ описывает одно событие в одном проекте. Владельцем является `web`; схема: `services/web/app/src/models/ProjectAuditLogEntry.mjs`, а ядро записывает через `services/web/app/src/Features/Project/ProjectAuditLogHandler.mjs`.

#### Индексы {#indexes}

| Имя | Ключи | Параметры | Миграция |
| --- | --- | --- | --- |
| `timestamp_1` | `{ timestamp: 1 }` | TTL, `expireAfterSeconds: 78840000` (2,5 года) | `tools/migrations/20220913105500_create_auditLog_indexes.mjs` |
| `projectId_1_timestamp_-1` | `{ projectId: 1, timestamp: -1 }` | | `tools/migrations/20250912102601_add_timestamp_to_projectAuditLogEntries_index.mjs` |

`tools/migrations/20220929193200_add_auditLog_indexes.mjs` сначала создала `project_id_1` по `{ projectId: 1 }`; `20250912102601` заменяет его составным индексом. Пометки `index: true` в схеме не применяются, поскольку автоматическое создание индексов в Mongoose отключено (`services/web/app/src/infrastructure/Mongoose.mjs:7`). Миграция индекса `managedSubscriptionId` имеет только тег `saas`.

#### Примечания {#notes}

* Записи истекают через 2,5 года после `timestamp` благодаря TTL-индексу, а все записи проекта исчезают, когда истекает срок хранения записи о его удалении.
