---
title: Коллекция Project History Sharded Blobs
icon: cubes-stacked
---

`projectHistoryShardedBlobs` хранит записи blob, которые не поместились в [projectHistoryBlobs](/dev/data-model/project-history-blobs-collection): когда в корзине для префикса хеша там уже 8 записей, следующие попадают сюда. У проекта здесь не больше 16 документов, по одному на первую шестнадцатеричную цифру хеша. Схемы Mongoose нет; history-v1 пишет её в `services/history-v1/storage/lib/blob_store/mongo.js` (структура описана в `mongo.js:1-16`).

#### Поля {#fields}

| Поле | Тип | Значение | Источник |
| ----- | ---- | ------- | ------ |
| `_id` | Binary | 13 байт: идентификатор истории проекта, `0`, и цифра шарда, читаемая как шестнадцатеричная (`<history id>0<digit>`). Цифра шарда — первая шестнадцатеричная цифра хеша. | `mongo.js:439-453` |
| `blobs` | Object | Записи blob, сгруппированные в корзины. Ключ корзины — шестнадцатеричные цифры хеша со 2-й по 4-ю. | `mongo.js:439-443` |
| `blobs.<bcd>` | Array of Object | Записи корзины. Код не ограничивает её размер. | `mongo.js:399-407` |
| `blobs.<bcd>[].h` | Binary | Хеш, 20 байт, как в projectHistoryBlobs. | `mongo.js:472` |
| `blobs.<bcd>[].b` | Number | Длина содержимого в байтах. | `mongo.js:473` |
| `blobs.<bcd>[].s` | Number | Длина содержимого как текста; `null`, если содержимое не является редактируемым текстом. | `mongo.js:474` |

#### Кто пишет {#who-writes-it}

| Код | Что делает |
| ---- | ------------ |
| `services/history-v1/storage/lib/blob_store/mongo.js:399-407` | `insertRecordSharded`: upsert с `$addToSet` в корзину. Вызывается `insertBlob`, когда корзина в projectHistoryBlobs заполнена (`mongo.js:387-389`). |
| `mongo.js:75-103` | `clone`: копирует шарды проекта на другой идентификатор истории, для history-v1 `POST /projects/:project_id/clone`, который ничто в web не вызывает. |
| `mongo.js:413-422` | `deleteBlobs`: удаляет все шарды проекта вместе с его документом projectHistoryBlobs, при history-v1 `DELETE /projects/:project_id`. |

#### Кто читает {#who-reads-it}

| Код | Что делает |
| ---- | ------------ |
| `mongo.js:144-157` | `findBlobSharded`: один blob; ищется, только когда его корзина в projectHistoryBlobs содержит 8 записей и в ней его нет (`mongo.js:127-131`). |
| `mongo.js:217-260` | `findBlobsSharded`: blob, которые `findBlobs` не нашёл в projectHistoryBlobs (`mongo.js:202-206`). |
| `mongo.js:285-306` | `getProjectBlobs`: все шарды проекта. |
| `mongo.js:337-361` | `getProjectBlobsBatch`: все шарды нескольких проектов, для маршрута статистики blob. |

#### Индексы {#indexes}

Только индекс `_id` по умолчанию. Ни одна миграция в `tools/migrations/` не добавляет индекс.

#### Примечания {#notes}

* Шарды одного проекта лежат рядом в порядке `_id`, поэтому код находит их диапазоном `_id` от `<history id>00` до `<history id>0f` (`mongo.js:75-80`, `287-295`).
* Коллекция появляется, только когда у какого-то проекта больше 8 blob с одинаковым трёхзначным префиксом хеша, поэтому на небольшом инстансе её может не быть вовсе.
