---
title: Коллекция GitHub Sync User Credentials
icon: key
---

`githubSyncUserCredentials` хранит по одному документу на каждого пользователя, который связал учётную запись GitHub для GitHub Sync. В нём хранится OAuth-токен доступа пользователя в зашифрованном виде. Коллекция относится к веб-модулю `github-sync` (`services/web/modules/github-sync`). Схема находится в `services/web/modules/github-sync/app/models/githubSyncUserCredentials.mjs`, а весь доступ идёт через `services/web/modules/github-sync/app/src/TokenManager.mjs`.

#### Поля {#fields}

| Поле | Тип | Значение | Источник |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Задаётся Mongoose, когда upsert вставляет документ. | |
| `userId` | ObjectId | Пользователь Overleaf. Обязательное. В схеме указано `unique: true`, но индекс не создаётся (см. «Индексы»); upsert по `userId` сохраняет один документ на пользователя. | `githubSyncUserCredentials.mjs:8`, `TokenManager.mjs:44-48` |
| `github` | String | OAuth-токен доступа GitHub, зашифрованный с помощью `@overleaf/access-token-encryptor`. Пароль берётся из `GITHUB_TOKEN_CIPHER_PASSWORD`; метка шифра `GITHUB_TOKEN_CIPHER_LABEL`, по умолчанию `2026.3-v3`. Обязательное. | `githubSyncUserCredentials.mjs:9`, `TokenManager.mjs:12-25` |
| `__v` | Number | Ключ версии Mongoose. Схема его не отключает. | По умолчанию в Mongoose |

Хранится только токен доступа: OAuth-колбэк берёт из ответа GitHub только `access_token` (`services/web/modules/github-sync/app/src/GitHubApiClient.mjs:180-191`). Токена обновления и срока действия нет.

#### Кто пишет {#who-writes-it}

| Код | Что делает |
| ---- | ------------ |
| `TokenManager.mjs:42-58` (`saveUserToken`) | Делает upsert зашифрованного токена пользователя. Когда пользователь связывает учётную запись заново, заменённый токен отзывается в GitHub в фоне. Вызывается из OAuth-колбэка (`services/web/modules/github-sync/app/src/GitHubSyncController.mjs:146`). |
| `TokenManager.mjs:61-76` (`removeUserToken`) | Отзывает токен в GitHub (по возможности), затем удаляет документ. Вызывается при отвязке (`GitHubSyncController.mjs:167`) и когда истекает срок удалённого пользователя (`services/web/modules/github-sync/index.mjs:66-68`). |

#### Кто читает {#who-reads-it}

| Код | Что делает |
| ---- | ------------ |
| `TokenManager.mjs:36-40` (`getUserToken`) | Расшифровывает токен для каждого вызова API GitHub: `services/web/modules/github-sync/app/src/GitHubSyncHandler.mjs` (например, `:27`) и `services/web/modules/github-sync/app/src/GitMerge.mjs:43`. Если документа нет или токен не удаётся расшифровать, выбрасывает `InvalidTokenError`, и пользователь считается несвязанным (`GitHubSyncHandler.mjs:25-37`). |
| `services/web/modules/admin-tools/app/src/AdminUserListManager.mjs:393` | Проверяет, есть ли у пользователя документ, для интеграций, показываемых в панели администратора. |

#### Индексы {#indexes}

| Имя | Ключи | Параметры | Миграция |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

`autoIndex` в Mongoose выключен (`services/web/app/src/infrastructure/Mongoose.mjs:7`), поэтому `unique: true` из схемы на `userId` ничего не создаёт. `tools/migrations/20190912145011_create_githubSyncUserCredentials_indexes.mjs` (`user_id` из upstream) помечена только тегом `saas` и в CE не запускается.

#### Примечания {#notes}

* Смена `GITHUB_TOKEN_CIPHER_PASSWORD` делает сохранённые токены нечитаемыми. Такие пользователи считаются несвязанными, пока не свяжут учётную запись заново.
* Удалённый пользователь сохраняет документ, пока не истечёт его срок.
