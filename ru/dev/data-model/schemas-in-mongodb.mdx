В этом разделе мы рассмотрим модель данных Overleaf. Overleaf использует MongoDB для хранения данных; единственная база данных называется `sharelatex` — так назывался предшественник Overleaf.

Если вы ещё не настроили Mongo Express для Overleaf, настоятельно рекомендуем ознакомиться с [setup-develop-tools.md](/ru/dev/environment/setup-develop-tools  "mention") и настроить Mongo.

После настройки Mongo Express вы можете войти по адресу [http://localhost:8081/](http://localhost:8081/) с учётными данными `admin:pass`.
