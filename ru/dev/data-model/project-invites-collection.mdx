---
title: Коллекция Project Invites
icon: envelope-open-text
---

`projectInvites` хранит приглашения, которые владелец проекта отправляет из окна общего доступа. Один документ соответствует одному приглашению на один адрес email. Документ удаляется, когда приглашение принято или отозвано, либо Mongo удаляет его по истечении срока. Схема находится в `services/web/app/src/models/ProjectInvite.mjs`, а пишет в коллекцию `services/web/app/src/Features/Collaborators/CollaboratorsInviteHandler.mjs`.

Приглашение никого не делает участником. Участники хранятся в массивах `*_refs` проекта, см. [Коллекция Projects](/ru/dev/data-model/projects-collection).

#### Поля {#fields}

| Поле | Тип | Значение | Источник |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Id приглашения. Уведомление о приглашении для существующего пользователя использует ключ `project-invite-<_id>` (`services/web/app/src/Features/Notifications/NotificationsBuilder.mjs:102`). | `ProjectInvite.mjs:14` |
| `email` | String | Адрес, на который отправлено приглашение. При отзыве приглашения для пользователя его сравнивают с подтверждёнными адресами пользователя (`CollaboratorsInviteHandler.mjs:103-116`). Не задаётся для приглашения по ссылке общего доступа. | `ProjectInvite.mjs:16`, `CollaboratorsInviteHandler.mjs:84` |
| `tokenHmac` | String | HMAC-SHA256 (ключ `overleaf-token-invite`) токена из ссылки приглашения. Исходный токен есть только в письме и уведомлении; при поиске токен из URL хешируется и сравнивается с этим полем. | `ProjectInvite.mjs:18`, `services/web/app/src/Features/Collaborators/CollaboratorsInviteHelper.mjs:11-15`, `CollaboratorsInviteHandler.mjs:82,256` |
| `encryptedToken` | String | Только для приглашений по ссылке общего доступа: токен, зашифрованный с `Settings.projectInviteEncryptorOptions`, чтобы владелец мог снова увидеть ссылку (`services/web/app/src/Features/Collaborators/CollaboratorsInviteController.mjs:606-611`). | `ProjectInvite.mjs:17`, `CollaboratorsInviteHelper.mjs:30-47`, `CollaboratorsInviteHandler.mjs:255-258` |
| `sendingUserId` | ObjectId | Пользователь, отправивший приглашение. При принятии передаётся как пользователь, добавивший нового участника (`CollaboratorsInviteHandler.mjs:199-205`). Не задаётся для приглашения по ссылке общего доступа. | `ProjectInvite.mjs:19`, `CollaboratorsInviteHandler.mjs:86` |
| `projectId` | ObjectId | Проект, к которому относится приглашение. | `ProjectInvite.mjs:20`, `CollaboratorsInviteHandler.mjs:87` |

Приглашение по ссылке общего доступа может также содержать `false`, то есть отсутствие доступа. | `ProjectInvite.mjs:21-25`, `CollaboratorsInviteHandler.mjs:88` |
| `createdAt` | Date | Задаётся значением по умолчанию из схемы при сохранении приглашения. | `ProjectInvite.mjs:26` |
| `expires` | Date | Значение по умолчанию из схемы: через 30 дней после создания. TTL-индекс удаляет приглашение примерно через 10 секунд после этого времени. `null` для приглашения по ссылке общего доступа, которое никогда не истекает. | `ProjectInvite.mjs:6-12,27-31`, `CollaboratorsInviteHandler.mjs:264` |
| `reusable` | Boolean | `false` для приглашения по email, которое удаляется при принятии (`CollaboratorsInviteHandler.mjs:207-220`). `true` для приглашения по ссылке общего доступа, которое остаётся. | `ProjectInvite.mjs:32`, `CollaboratorsInviteHandler.mjs:89,263` |
| `subscriptionId` | ObjectId | Только для приглашений по ссылке общего доступа: групповая подписка, участники которой могут принять ссылку (`CollaboratorsInviteController.mjs:490-501`). | `ProjectInvite.mjs:33`, `CollaboratorsInviteHandler.mjs:262` |

#### Примечания {#notes}

* Если при принятии приглашения `readAndWrite` или `review` в проекте не осталось свободных мест для редакторов, пользователь присоединяется только с правом чтения и попадает в `pendingEditor_refs` или `pendingReviewer_refs` проекта (`CollaboratorsInviteHandler.mjs:162-205`).
* Старые приглашения хранили исходный токен в поле `token`. Миграция `20240524135408_add_token_hmac_project_invite_tokens.mjs` добавила `tokenHmac`, а `20240531082910_remove_project_invite_tokens.mjs` удалила `token`.
* Ничто не удаляет приглашения удалённого проекта; они остаются, пока их не удалит TTL-индекс.
