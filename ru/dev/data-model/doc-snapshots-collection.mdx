`docSnapshots` хранит копии документа, которые document-updater делает непосредственно перед правкой, сворачивающей комментарии или отслеживаемые изменения. Пишет в неё только document-updater, в `services/document-updater/app/js/SnapshotManager.js`. В web есть модель Mongoose в `services/web/app/src/models/DocSnapshot.mjs`, но её не использует никакой код.

#### Поля {#fields}

| Поле | Тип | Значение | Источник |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Идентификатор снимка. | `SnapshotManager.js:24` |
| `project_id` | ObjectId | Проект. | `SnapshotManager.js:19,26`, `DocSnapshot.mjs:7` |
| `doc_id` | ObjectId | Документ (`docs._id`). | `SnapshotManager.js:20,27`, `DocSnapshot.mjs:8` |
| `version` | Number | OT-версия документа до правки. | `SnapshotManager.js:28`, `services/document-updater/app/js/UpdateManager.js:132,264-271`, `DocSnapshot.mjs:9` |
| `lines` | Array of String | Содержимое документа до правки. | `SnapshotManager.js:29`, `DocSnapshot.mjs:10` |
| `pathname` | String | Путь к документу в проекте на тот момент. | `SnapshotManager.js:30`, `DocSnapshot.mjs:11` |
| `ranges` | Mixed | `comments` и `changes` до правки, в той же форме, что и `docs.ranges` (см. [docs](/ru/dev/data-model/docs-collection)). `id`, `op.t` и `metadata.user_id` преобразуются в ObjectId, а `metadata.ts` в Date. | `SnapshotManager.js:31,41-68`, `DocSnapshot.mjs:12` |
| `ts` | Date | Когда был сделан снимок. TTL-индекс удаляет снимок через 30 дней. | `SnapshotManager.js:32`, `DocSnapshot.mjs:13` |

#### Кто пишет {#who-writes-it}

| Код | Что делает |
| ---- | ------------ |
| `UpdateManager.js:248-271` | Применив правку, document-updater сохраняет документ в состоянии до правки, если правка свернула диапазоны: пустых диапазонов стало больше или было удалено больше одного диапазона (`services/document-updater/app/js/RangesManager.js:104-106`). |
| `SnapshotManager.js:17-36` `recordSnapshot` | Вставляет снимок. |

#### Кто читает {#who-reads-it}

Никакой код её не читает. Модель web определена, но нигде не используется.

#### Примечания {#notes}

* Снимки делают только правки, проходящие через `UpdateManager.applyUpdate`. Правки, которые обрабатывает `HistoryOTUpdateManager`, их не делают (`UpdateManager.js:74-77`).
* Индекса по `doc_id` нет. Ищите снимки документа по `project_id` и `ts`, затем фильтруйте по `doc_id`.
