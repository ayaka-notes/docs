---
title: Коллекция OAuth Authorization Codes
icon: lock-open
---

`oauthAuthorizationCodes` предназначена для кодов потока OAuth authorization code: один документ на код, который клиент обменивает на токен доступа. Схема находится в `services/web/app/src/models/OauthAuthorizationCode.mjs`, а код, который писал бы в неё, есть в веб-модуле `oauth2-server`. В Ayakaleaf Pro до этого кода ничего не доходит, поэтому коллекция остаётся пустой (см. Примечания).

#### Поля {#fields}

| Поле | Тип | Значение | Источник |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Id документа. | `OauthAuthorizationCode.mjs:6` |
| `authorizationCode` | String | Сам код, хранится как есть (без хеширования). | `OauthAuthorizationCode.mjs:8`, `services/web/modules/oauth2-server/app/src/OAuth2Model.mjs:280` |
| `expiresAt` | Date | Конец срока действия. После него `getAuthorizationCode` отклоняет код, а TTL-индекс удаляет его. | `OauthAuthorizationCode.mjs:9`, `OAuth2Model.mjs:150-153,281` |
| `oauthApplication_id` | ObjectId | Клиент в [OAuth Applications](/ru/dev/data-model/oauth-applications-collection), запросивший код. | `OauthAuthorizationCode.mjs:10`, `OAuth2Model.mjs:275-284` |
| `redirectUri` | String | URI перенаправления запроса. | `OauthAuthorizationCode.mjs:11`, `OAuth2Model.mjs:282` |
| `scope` | String | Запрошенный scope. | `OauthAuthorizationCode.mjs:12`, `OAuth2Model.mjs:283` |
| `user_id` | ObjectId | Пользователь, выдавший код. | `OauthAuthorizationCode.mjs:13`, `OAuth2Model.mjs:285` |
| `codeChallenge`, `codeChallengeMethod` | String | PKCE challenge и его метод. | `OauthAuthorizationCode.mjs:14-15`, `OAuth2Model.mjs:286-287` |

#### Кто пишет {#who-writes-it}

| Код | Что делает |
| ---- | ------------ |
| `OAuth2Model.mjs:274-300` (`saveAuthorizationCode`) | Вставляет код. Не вызывается, см. Примечания. |
| `OAuth2Model.mjs:307-312` (`revokeAuthorizationCode`) | Удаляет код после использования. Не вызывается. |

#### Кто читает {#who-reads-it}

| Код | Что делает |
| ---- | ------------ |
| `OAuth2Model.mjs:137-177` (`getAuthorizationCode`) | Загружает код вместе с пользователем и клиентом. Не вызывается. |

#### Индексы {#indexes}

| Имя | Ключи | Параметры | Миграция |
| ---- | ---- | ------- | --------- |
| `expiresAt_1` | `{ expiresAt: 1 }` | TTL, `expireAfterSeconds: 0`, частичный: `expiresAt` существует | `20230406125632_oauth_tokens_ttl.mjs` |

Миграции находятся в `tools/migrations/`. Уникальный индекс `authorizationCode_1` создают только миграции с тегами `saas` и `server-pro`, которые Community Edition не запускает.

#### Примечания {#notes}

* Перечисленные методы модели вызывают только обработчики authorize и token из `@node-oauth/oauth2-server`. Web использует эту библиотеку только для проверки bearer-токенов (`services/web/app/src/Features/Authentication/AuthenticationController.mjs:409-450`), и ни один маршрут не обслуживает `/oauth/authorize` или `/oauth/token`, поэтому код никогда не записывается. Персональные токены доступа создаются напрямую, см. [OAuth Access Tokens](/ru/dev/data-model/oauth-access-tokens-collection).
