title: Коллекция tags
icon: tags
---

`tags` хранит теги (папки), по которым пользователь раскладывает проекты на панели проектов. Каждый документ описывает один тег одного пользователя. Владельцем является `web`; схема: `services/web/app/src/models/Tag.mjs`, а все записи проходят через `services/web/app/src/Features/Tags/TagsHandler.mjs`.

#### Поля {#fields}

| Поле | Тип | Значение | Источник |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id тега, используется в маршрутах `/tag/:tagId`. | `Tag.mjs:10` |
| `user_id` | String | Владелец тега. Обычная строка, а не ObjectId, по историческим причинам. | `Tag.mjs:7-12` |
| `name` | String | Имя тега, не более 50 символов (`MAX_TAG_LENGTH`). Уникально в пределах пользователя. | `Tag.mjs:13`, `TagsHandler.mjs:4` |
| `color` | String | Необязательный цвет: шестнадцатеричный код вроде `#a1b2c3` или значение `hsl(<n>, 70%, 45%)` (`TAG_COLOR_REGEX`). | `Tag.mjs:5`, `Tag.mjs:14-22` |
| `project_ids` | Array of String | Id проектов в этом теге, в виде строк. | `Tag.mjs:23` |
| `__v` | Number | Ключ версии Mongoose, добавляется, когда `Tag.create` создаёт документ. | `TagsHandler.mjs:27` |

#### Кто записывает {#who-writes-it}

| Код | Что делает |
| --- | --- |
| `TagsHandler.mjs:18-35` (`createTag`) | `POST /tag` (`services/web/app/src/router.mjs:873-874`). При повторяющемся имени возвращает существующий тег. |
| `TagsHandler.mjs:37-70` (`renameTag`, `editTag`) | `POST /tag/:tagId/rename` и `/tag/:tagId/edit` (`router.mjs:879-886`): задают `name` либо `name` и `color`. |
| `TagsHandler.mjs:72-77` (`deleteTag`) | `DELETE /tag/:tagId` (`router.mjs:891-892`). |
| `TagsHandler.mjs:79-113` | Добавляет или удаляет один или несколько проектов (`$addToSet` / `$pull` / `$pullAll` для `project_ids`), маршруты `router.mjs:897-916`. |
| `TagsHandler.mjs:124-128` (`removeProjectFromAllTags`) | Вызывается для каждого участника при удалении проекта (`services/web/app/src/Features/Project/ProjectDeleter.mjs:236-238`) и когда пользователя удаляют из проекта или он покидает его (`services/web/app/src/Features/Collaborators/CollaboratorsController.mjs:621`). |
| `TagsHandler.mjs:130-134` (`addProjectToTags`) | Помещает скопированный проект в те же теги, что и оригинал (`services/web/app/src/Features/Project/ProjectDuplicator.mjs:190-194`). |
| `services/web/modules/server-ce-scripts/scripts/rename-tag.mjs:20-23` | Скрипт администратора, который переименовывает тег одного пользователя прямо в Mongo. |

#### Кто читает {#who-reads-it}

| Код | Что делает |
| --- | --- |
| `TagsHandler.mjs:6-8` (`getAllTags`) | Панель проектов (`services/web/app/src/Features/Project/ProjectListController.mjs:313`, `:747`), `GET /tag` и закрытый API `GET /user/:userId/tag` (`router.mjs:863-869`). |
| `TagsHandler.mjs:14-16` (`getTagsForProject`) | Теги открытого проекта в редакторе (`services/web/app/src/Features/Project/ProjectController.mjs:672`). |
| `TagsHandler.mjs:10-12` (`countTagsForProject`) | Подсчёт для аналитики при копировании проекта (`ProjectDuplicator.mjs:98`). |

#### Индексы {#indexes}

| Имя | Ключи | Параметры | Миграция |
| --- | --- | --- | --- |
| `user_id_1_name_1` | `{ user_id: 1, name: 1 }` | unique | `tools/migrations/20190912145029_create_tags_indexes.mjs` |

Та же миграция создала и `user_id_1`; `tools/migrations/20231031164732_drop_redundant_indexes.mjs` снова удаляет его, поскольку составной индекс его покрывает.

#### Примечания {#notes}

* Теги принадлежат конкретному пользователю: два соавтора одного проекта хранят для него каждый свои теги.
* `user_id` и `project_ids` являются строками, поэтому запрашивайте их по строковым id, а не по ObjectId.
* Удаление пользователя (`services/web/app/src/Features/User/UserDeleter.mjs`) не затрагивает `tags`.
