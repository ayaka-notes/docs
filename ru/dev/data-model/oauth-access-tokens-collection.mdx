---
title: Коллекция OAuth Access Tokens
icon: ticket
---

`oauthAccessTokens` хранит bearer-токены, которые принимает web. В Ayakaleaf Pro это персональные токены доступа (токены аутентификации Git), которые пользователь создаёт на странице настроек аккаунта и использует для git-bridge и эндпоинта MCP. Один документ соответствует одному токену. Схема находится в `services/web/app/src/models/OauthAccessToken.mjs`; в коллекцию пишет веб-модуль `oauth2-server`, в основном через нативный драйвер.

#### Кто пишет {#who-writes-it}

| Код | Что делает |
| ---- | ------------ |
| `OAuthPersonalAccessTokenManager.mjs:53-88` (`createToken`) | Вставляет персональный токен доступа. Маршрут `POST /oauth/personal-access-tokens` (`services/web/modules/oauth2-server/app/src/OAuthPersonalAccessTokenRouter.mjs:22-27`) требует у пользователя функцию `gitBridge` и разрешает 10 токенов на пользователя (`OAuthPersonalAccessTokenController.mjs:7,34-38`). |
| `OAuthPersonalAccessTokenManager.mjs:90-105` (`removeToken`) | Удаляет один токен пользователя. Маршрут `DELETE /oauth/personal-access-tokens/:token_id` (`OAuthPersonalAccessTokenRouter.mjs:29-32`). |
| `OAuthPersonalAccessTokenManager.mjs:136-140`, `OAuth2Model.mjs:58-61` | Устанавливают `lastUsedAt` после успешной проверки. |

#### Примечания {#notes}

* Удаление пользователя не удаляет его токены. `UserDeleter` вызывает хук `cleanupPersonalAccessTokens` (`services/web/app/src/Features/User/UserDeleter.mjs:230-234`), но ни один модуль его не слушает. Обе проверки токена отклоняют такие токены, потому что пользователя больше нет, а TTL-индекс удаляет их через день после `accessTokenExpiresAt`.
* Блокировка пользователя завершает только сессии. Токены остаются, и обе проверки токена отклоняют их, пока `users.suspended` равно `true` (`OAuth2Model.mjs:51-54`, `OAuthPersonalAccessTokenManager.mjs:129-134`).
