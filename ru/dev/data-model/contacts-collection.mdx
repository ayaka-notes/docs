`contacts` запоминает, с какими пользователями работал пользователь, чтобы диалог общего доступа мог их предлагать. Один документ на пользователя. Владельцем является `web`, схемы Mongoose нет; код: `services/web/app/src/Features/Contacts/ContactManager.mjs`.

#### Поля {#fields}

| Поле | Тип | Значение | Источник |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id документа, создаётся при upsert. | `ContactManager.mjs:5-12` |
| `user_id` | ObjectId | Пользователь, которому принадлежат эти контакты. Один документ на пользователя. | `ContactManager.mjs:6` |
| `contacts` | Object | Словарь с id пользователя-контакта (строкой) в качестве ключа. | `ContactManager.mjs:8-9` |
| `contacts.<userId>.n` | Number | Сколько раз два пользователя были сведены вместе. | `ContactManager.mjs:8` |
| `contacts.<userId>.ts` | Date | Когда это произошло в последний раз. | `ContactManager.mjs:9` |

#### Кто записывает {#who-writes-it}

| Код | Что делает |
| --- | --- |
| `ContactManager.mjs:4-13` (`touchContact`), `:23-28` (`addContact`) | Выполняет upsert документов обоих пользователей: `$inc` для `n`, `$set` для `ts`. |
| `services/web/app/src/Features/Collaborators/CollaboratorsHandler.mjs:155-157` | `addUserIdToProject` вызывает `addContact`, когда ему передан добавляющий пользователь: при принятии приглашения (пригласивший и приглашённый, `services/web/app/src/Features/Collaborators/CollaboratorsInviteHandler.mjs:199-205`) и при передаче владения (новый и прежний владелец, `services/web/app/src/Features/Collaborators/OwnershipTransferHandler.mjs:138-144`). При входе по ссылке общего доступа добавляющий пользователь не передаётся (`services/web/app/src/Features/TokenAccess/TokenAccessController.mjs:386-388`, `:632-634`), поэтому контакт не добавляется. |

#### Кто читает {#who-reads-it}

| Код | Что делает |
| --- | --- |
| `ContactManager.mjs:15-21`, `:30-42` | `getContactIds`: сортирует по `n`, затем по `ts`, оба по убыванию. |
| `services/web/app/src/Features/Contacts/ContactController.mjs:19-59` | `GET /user/contacts` (`services/web/app/src/Features/Contacts/ContactRouter.mjs:22-26`): возвращает первые 50 в виде пользователей, без временных аккаунтов, плюс то, что модули добавляют через хук `getContacts`. |

#### Примечания {#notes}

* Контакты взаимны: добавление B в проект A делает B контактом A, а A становится контактом B.
* Ничто не удаляет контакт или документ, даже удаление пользователя.
