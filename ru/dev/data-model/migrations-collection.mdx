---
title: Коллекция migrations
icon: list-check
---

`migrations` фиксирует, какие миграции базы данных уже выполнены. Каждый документ описывает одну миграцию из `tools/migrations/`. Его записывает адаптер инструмента миграций [east](https://github.com/okv/east), `tools/migrations/lib/adapter.mjs`, а не работающий сервис.

#### Поля {#fields}

| Поле | Тип | Значение | Источник |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id документа. | `adapter.mjs:103` |
| `name` | String | Имя файла миграции без расширения, например `20190912145029_create_tags_indexes`. | `adapter.mjs:104` |
| `migratedAt` | Date | Когда миграция завершилась. | `adapter.mjs:105` |

#### Кто записывает {#who-writes-it}

| Код | Что делает |
| --- | --- |
| `adapter.mjs:101-107` (`markExecuted`) | Вставляет документ после выполнения миграции. |
| `adapter.mjs:109-114` (`unmarkExecuted`) | Снова удаляет его при откате миграции. |

CE выполняет `yarn run migrations migrate -t server-ce` при каждом запуске контейнера (`server-ce/init_scripts/900_run_web_migrations.sh:4-12`; `-t server-pro`, если `OVERLEAF_IS_SERVER_PRO=true`). Выполняются только миграции, в `tags` которых есть это окружение, поэтому только они получают здесь документ.

#### Кто читает {#who-reads-it}

| Код | Что делает |
| --- | --- |
| `adapter.mjs:72-99` (`getExecutedMigrationNames`) | east пропускает каждую миграцию, имя которой уже есть здесь. |
| `tools/migrations/lib/helpers.mjs:67-75` (`assertDependency`) | Миграция, которой нужно, чтобы другая была выполнена раньше, выбрасывает ошибку, если этого имени нет. |

#### Индексы {#indexes}

| Имя | Ключи | Параметры | Миграция |
| --- | --- | --- | --- |
| `name_1` | `{ name: 1 }` | unique | `tools/migrations/20190720165251_create_migrations.mjs` |

#### Примечания {#notes}

* Если удалить документ, эта миграция снова выполнится при следующем запуске контейнера, если её теги подходят.
* При дополнительном кластере Mongo (`mongo.auxUrl`) миграции с тегом `auxiliary` записываются вместо этого в коллекцию `migrations` того кластера (`adapter.mjs:8-15`, `:64-70`). `mongo.auxUrl` берётся из `MONGO_AUX_CONNECTION_STRING` (`tools/migrations/config/settings.defaults.js:19`), который по умолчанию не задан.
