title: Коллекция Messages
icon: message
---

`messages` хранит по одному документу на сообщение: строку в чате проекта или комментарий либо ответ в ветке комментариев рецензирования. Пишет в неё только сервис chat, в `services/chat/app/js/Features/Messages/MessageManager.js`. Схемы Mongoose нет. Каждое сообщение принадлежит комнате из коллекции [rooms](/ru/dev/data-model/rooms-collection).

#### Поля {#fields}

| Поле | Тип | Значение | Источник |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Идентификатор сообщения. | `MessageManager.js:13-14` |
| `room_id` | ObjectId | Комната (`rooms._id`), а не идентификатор проекта или ветки. | `MessageManager.js:8,106-108` |
| `user_id` | ObjectId | Автор. | `MessageManager.js:9,103-105` |
| `content` | String | Текст сообщения, от 1 до 10240 символов (`MAX_MESSAGE_LENGTH`). | `MessageManager.js:7`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:3,12-15` |
| `timestamp` | Number | Время отправки в миллисекундах с 1970 года (`Date.now()`), не Date. | `MessageManager.js:10`, `services/chat/app/js/Features/Messages/MessageHttpController.js:288` |
| `edited_at` | Number | Время последнего редактирования в миллисекундах (`Date.now()`). Отсутствует, если сообщение не редактировалось. | `MessageManager.js:65-69`, `MessageHttpController.js:189,213` |

#### Кто пишет {#who-writes-it}

| Код | Что делает |
| ---- | ------------ |
| `MessageManager.js:5-16` `createMessage` | Вставляет сообщение (`MessageHttpController.js:275-294`). Web отправляет сообщения чата проекта из `services/web/app/src/Features/Chat/ChatController.mjs:32`, а комментарии из модуля track-changes (`services/web/modules/track-changes/app/src/TrackChangesController.mjs:95`) и модуля mcp-server (`services/web/modules/mcp-server/app/src/CommentTools.mjs:133`). |
| `MessageManager.js:51-72` `updateMessage` | Устанавливает `content` и `edited_at`. Если передан идентификатор пользователя, совпадает только сообщение этого пользователя (`MessageManager.js:62-64`). Вызывается из `ChatController.mjs:135` и `TrackChangesController.mjs:110`. |
| `MessageManager.js:74-80` `deleteMessage` | Удаляет одно сообщение. Вызывается из `ChatController.mjs:105` и `TrackChangesController.mjs:129`. |
| `MessageManager.js:39-49` `deleteAllMessagesInRoom(s)` | Удаляет сообщения удалённой ветки (`MessageHttpController.js:172-173`) или всего проекта, когда истекает срок удалённого проекта (`MessageHttpController.js:261-271`, вызывается из `services/web/app/src/Features/Project/ProjectDeleter.mjs:391`). |
| `MessageManager.js:115-127` `duplicateRoomToOtherRoom` | Копирует `content`, `timestamp` и `user_id` каждого сообщения в другую комнату, без `edited_at`. Используется, когда восстановление истории дублирует ветку (`MessageHttpController.js:316-342`), и когда проект копируется вместе с диапазонами (`MessageHttpController.js:344-357`). |

#### Кто читает {#who-reads-it}

| Код | Что делает |
| ---- | ------------ |
| `MessageManager.js:18-29` `getMessages` | Сначала новые, не более `limit` (по умолчанию 50) старше `before` (значение `timestamp`). Используется для чата проекта (`ChatController.mjs:80`). |
| `MessageManager.js:31-37` `findAllMessagesInRooms` | Все сообщения нескольких комнат: для списка веток панели рецензирования (`TrackChangesController.mjs:82`), модуля mcp-server (`CommentTools.mjs:83`) и восстановления истории (`services/web/app/src/Features/History/RestoreManager.mjs:259`). Web также проверяет первое сообщение ветки, чтобы рецензент мог менять только начатые им ветки (`services/web/app/src/Features/Authorization/AuthorizationManager.mjs:409-411`). |
| `MessageManager.js:90-100` `getMessage` | Одно сообщение. Web проверяет его `user_id`, прежде чем пользователь отредактирует или удалит своё сообщение (`services/web/app/src/Features/Authorization/AuthorizationMiddleware.mjs:253-257`, `TrackChangesController.mjs:124-125`). |

#### Примечания {#notes}

* Чтобы найти сообщения комментария, сначала найдите комнату по `project_id` и `thread_id`, затем выполните запрос по `room_id`. Идентификатор комментария в документе — это `thread_id`, а не `room_id`.
* Текст, на который указывает комментарий, находится в `op.c` внутри `docs.ranges.comments`; обсуждение хранится здесь.
