title: Коллекция spellingPreferences
icon: spell-check
---

`spellingPreferences` хранит словарь каждого пользователя: слова, которые пользователь добавил через "Add to dictionary" в проверке орфографии редактора. Один документ на пользователя. Владельцем является `web`, схемы Mongoose нет; код: `services/web/app/src/Features/Spelling/LearnedWordsManager.mjs`.

#### Поля {#fields}

| Поле | Тип | Значение | Источник |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id документа, создаётся при upsert. | `LearnedWordsManager.mjs:21-31` |
| `token` | String | Id пользователя. Вопреки названию, маршруты орфографии передают id вошедшего пользователя (`SessionManager.getLoggedInUserId`). | `LearnedWordsManager.mjs:23` |
| `learnedWords` | Array of String | Слова, добавленные пользователем. | `LearnedWordsManager.mjs:26` |

#### Кто записывает {#who-writes-it}

| Код | Что делает |
| --- | --- |
| `LearnedWordsManager.mjs:13-32` (`learnWord`) | `POST /spelling/learn` (`services/web/app/src/router.mjs:1037-1041`, `services/web/app/src/Features/Spelling/SpellingController.mjs:45-58`): `$addToSet` слова с upsert. Отказывает, если список превысит `Settings.maxDictionarySize` байт. |
| `LearnedWordsManager.mjs:38-47` (`unlearnWord`) | `POST /spelling/unlearn` (`router.mjs:1043-1047`, `SpellingController.mjs:66-79`): `$pull` слова. |
| `LearnedWordsManager.mjs:84-86` (`deleteUsersLearnedWords`) | Удаляет документ. Его единственную обёртку, `SpellingHandler.deleteUserDictionary` (`services/web/app/src/Features/Spelling/SpellingHandler.mjs:24-26`), никто не вызывает ни в web, ни в его модулях. |

#### Кто читает {#who-reads-it}

| Код | Что делает |
| --- | --- |
| `LearnedWordsManager.mjs:52-67` (`getLearnedWords`) | Возвращает слова без дубликатов. |
| `services/web/app/src/Features/Project/ProjectController.mjs:671` | Отправляет словарь в редактор при открытии проекта (`SpellingHandler.getUserDictionary`). |

#### Индексы {#indexes}

| Имя | Ключи | Параметры | Миграция |
| --- | --- | --- | --- |
| `token` | `{ token: 1 }` | | `tools/migrations/20190912145027_create_spellingPreferences_indexes.mjs` |

#### Примечания {#notes}

* Индекс не уникальный; upsert по `token` сохраняет один документ на пользователя.
* Удаление пользователя не удаляет этот документ.
