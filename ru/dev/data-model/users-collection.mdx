`users` хранит по одному документу на учётную запись: данные для входа, профиль, настройки редактора, функции и активность. Схема находится в `services/web/app/src/models/User.mjs`; большинство записей проходит через `services/web/app/src/Features/User/UserUpdater.mjs`. В столбце «Источник» `User.mjs:N` означает строку этой схемы, остальные имена файлов без пути находятся в `services/web/app/src/Features/`, а `modules/...` находится в `services/web/`. Номера строк взяты из `server-pro` на момент написания.

#### Флаги функций и ограничения (`features`) {#feature-flags-&-limits-features}

`features` является результатом вычисления, и редактировать его вручную не нужно. `FeaturesUpdater` начинает с `Settings.defaultFeatures`, объединяет каждую неистёкшую запись `featuresOverrides` и записывает результат вместе с `featuresUpdatedAt` (`FeaturesUpdater.mjs:220-300`, `UserFeaturesUpdater.mjs:10-24`). Рабочий образ задаёт по умолчанию `collaborators`, `dropbox`, `versioning`, `compileTimeout`, `compileGroup`, `trackChanges` и `references` (`server-ce/config/settings.js:301-309`); остальные ключи остаются незаданными.

В Ayakaleaf Pro панель администратора отключает функции для отдельных пользователей. Модуль `admin-tools` хранит их как запись `featuresOverrides` с `note: 'admin-panel'` (`modules/admin-tools/app/src/AdminFeatures.mjs:13-30`), а модуль `instance-features` считает незаданный ключ включённым (`modules/instance-features/app/src/UserFeatures.mjs:12-14`).

| Поле | Тип | Значение | Источник |
| ----- | ---- | ------- | ------ |
| `features.collaborators` | Number | Максимум соавторов в проекте, `-1` = без ограничений. | `User.mjs:119` |
| `features.versioning` | Boolean | История. | `User.mjs:123` |
| `features.dropbox` / `github` / `gitlab` / `gitea` / `gitBridge` | Boolean | Синхронизация с Dropbox, синхронизация с GitHub, GitLab и Gitea, а также доступ через Git. * `autoIndex` в Mongoose отключён (`services/web/app/src/infrastructure/Mongoose.mjs:7`), поэтому индексы создают только перечисленные выше миграции.
