---
title: Коллекция Project History Labels
icon: tag
---

`projectHistoryLabels` хранит метки, которые пользователи ставят на версии в представлении History, по одному документу на метку. Владелец коллекции — project-history, он пишет её в `services/project-history/app/js/LabelsManager.js`; схемы Mongoose нет. Web обращается к ней только через API project-history.

#### Поля {#fields}

| Поле | Тип | Значение | Источник |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Идентификатор метки. | `LabelsManager.js:81-85` |
| `project_id` | ObjectId | Проект. | `LabelsManager.js:73` |
| `comment` | String | Текст метки. | `LabelsManager.js:74` |
| `version` | Number | Версия истории проекта, на которую указывает метка. | `LabelsManager.js:75` |
| `created_at` | Date | Когда создана метка; запрос может передать своё время, иначе берётся текущее. | `LabelsManager.js:70`, `76` |
| `user_id` | ObjectId | Кто создал метку. Отсутствует, если в запросе нет пользователя. | `LabelsManager.js:78-80` |

#### Кто пишет {#who-writes-it}

| Код | Что делает |
| ---- | ------------ |
| `services/project-history/app/js/LabelsManager.js:44-90` | `createLabel`: вставляет метку, для project-history `POST /project/:project_id/labels` (`services/project-history/app/js/HttpController.js:1134-1171`). Web вызывает его, когда пользователь добавляет метку, с идентификатором пользователя (`services/web/app/src/Features/History/HistoryController.mjs:529-546`). |
| `LabelsManager.js:113-126` | `deleteLabel`: удаляет метку проекта, для `DELETE /project/:project_id/labels/:label_id`. Web использует его, когда владелец проекта удаляет метку (`HistoryController.mjs:649-670`). |
| `LabelsManager.js:92-111` | `deleteLabelForUser`: удаляет метку, только если её создал этот пользователь, для `DELETE /project/:project_id/user/:user_id/labels/:label_id`. Web использует его для всех остальных. |
| `LabelsManager.js:128-143` | `transferLabels`: переносит все метки одного пользователя другому, для `POST /user/:from_user/labels/transfer/:to_user` (`services/project-history/app/js/Router.js:52-55`). Ничто в web не вызывает этот маршрут. |
| `LabelsManager.js:7-25` | `cloneLabels`: копирует метки проекта в другой проект, для project-history `POST /project/:project_id/clone` (`HttpController.js:113`), который ничто в web не вызывает. |

#### Кто читает {#who-reads-it}

| Код | Что делает |
| ---- | ------------ |
| `LabelsManager.js:27-42` | `getLabels`: все метки проекта, возвращаются как `{ id, comment, version, user_id, created_at }` (`LabelsManager.js:163-171`). Используется `GET /project/:project_id/labels` (`HttpController.js:1076-1100`), который web вызывает для представления History, дополняя имена пользователей (`HistoryController.mjs:488-499`). |
| `services/project-history/app/js/SummarizedUpdatesManager.js:57` | Добавляет метки в список обновлений истории. |

#### Примечания {#notes}

* Перед вставкой метки project-history обрабатывает обновления проекта в очереди и проверяет, что в history-v1 есть chunk для этой версии, если только запрос не передаёт `validate_exists: false` (`LabelsManager.js:53-59`, `173-195`; `HttpController.js:1109-1115`).
* Никакой код не удаляет метки проекта при удалении проекта: project-history `DELETE /project/:project_id` очищает только состояние синхронизации и запись о сбое (`HttpController.js:1363-1396`), а другие сервисы эту коллекцию не трогают.
