---
title: Обновление переводов i18n
icon: language
---

В репозитории есть файл `services/web/frontend/extracted-translations.json`; веб-интерфейс Overleaf использует только извлечённые переводы из этого файла.

Если вы добавили новый контент, выполните следующую команду, чтобы обновить извлечённые переводы.

```bash
user ➜ ~/overleaf-pro/develop (server-pro) $ bin/shell webpack
root@432836260f8a:/overleaf/services/web# npm run extract-translations
```

Как правило, не редактируйте текстовые файлы переводов — в первую очередь используйте уже существующие строки, поскольку все эти файлы обновляются из upstream-репозитория Overleaf или со сторонней платформы переводов.
