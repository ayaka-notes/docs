---
title: Обновление переводов i18n
icon: language
---

Фронтенд загружает только ключи переводов, перечисленные в `services/web/frontend/extracted-translations.json` (`services/web/frontend/translations-loader.js`). Бэкенд и его шаблоны читают полные файлы из `services/web/locales/`.

Выполните это в каталоге `develop` один раз после первоначальной настройки и снова после добавления перевода или смены ветки:

```bash
bin/i18n
```

`bin/i18n` делает две вещи:

1. Сбрасывает `services/web/locales/*.json` к закоммиченным файлам, а затем применяет патчи локалей так же, как это делают сборки образа: файлы из старшей папки `locales_patches/v*` заменяют локали, а `locales_patches/added/*.json` объединяются поверх, ключ за ключом.
2. Запускает `yarn run extract-translations` от имени пользователя `node` в контейнере `webpack`, что перезаписывает `extracted-translations.json`. Если образа webpack нет, сначала синхронизирует `yarn.lock` с помощью `bin/sync` и собирает образ.

Требуется `jq` на хосте.

<Warning>

Изменения, которые `bin/i18n` вносит в `services/web/locales/*.json`, только локальные. Не коммитьте их.

</Warning>

По возможности используйте существующий ключ. Файлы локалей приходят из upstream Overleaf или со стороннего сайта переводов, поэтому не редактируйте их напрямую. Новый ключ добавляется в `services/web/locales/locales_patches/added/`, сразу в файл каждого языка (`en.json`, `zh-CN.json` и остальные).
