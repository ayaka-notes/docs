<strong>Обновлено 3 октября 2026 г.:</strong> версия 6.3.0 была выпущена повторно, чтобы устранить проблемы с AI Assistant и интеграциями Zotero и Mendeley. При обновлении загрузите последний образ `6.3.0`. В существующих установках со связанными файлами библиографии Zotero или Mendeley также необходимо выполнить [инструкции по миграции](/ru/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention"). Для новых установок эта миграция не требуется.

</Warning>

Мы с большой гордостью объявляем о выпуске Overleaf Pro 6.3.0 — самого мощного и функционального онлайн-редактора LaTeX в сообществе. Мы всегда стремились улучшать опыт наших пользователей, и этот выпуск приносит масштабные изменения и замечательные функции, которые вам точно понравятся, включая ИИ-ассистента и интеграцию со сторонними менеджерами библиографии.

### Изменения

* AI Chat Assistant: общайтесь с ИИ-моделью через собственного провайдера прямо в редакторе.
* LaTeX Error Assistant: получайте предложенные ИИ исправления ошибок компиляции LaTeX.
* Интеграция с Mendeley: импортируйте библиографические ссылки из Mendeley так же, как из Zotero.
* Open in Overleaf API: добавлен API для открытия контента в Overleaf.
* Галерея шаблонов: добавлены серверная пагинация, поиск и сортировка, так что большим галереям больше не нужно загружать все шаблоны в браузер.
* Переводы: обновлены патчи переводов для 6.3.0, включая новые тексты интерфейса на всех поддерживаемых языках.
* Upstream Overleaf 6.3.0: включает редактирование файлов во вкладках, отдельные логотипы в шапке для светлой и тёмной тем, а также обновления зависимостей и базового образа.
* Добавлены `OVERLEAF_HEADER_IMAGE_URL_LIGHT` и `OVERLEAF_HEADER_IMAGE_URL_DARK` для поддержки отдельных логотипов в шапке для светлой и тёмной тем.
* Теперь файлы можно открывать в разных вкладках редактора.
* Загрузка по внешним URL и Open in Overleaf API теперь поддерживают HTTP(S)-прокси через `OVERLEAF_LINKED_URL_OUTBOUND_PROXY`. Настройка описана в разделе [Outbound Proxy](/ru/on-premises/configuration/overleaf-toolkit/external-url#outbound-proxy  "mention").

#### Функция 01: AI Assistant уже доступен

AI Assistant находится на боковой панели редактора и взаимодействует с настроенным вами провайдером моделей. Спрашивайте его о том же, о чём спросили бы коллегу: сделай этот абзац лаконичнее, что делает этот макрос, почему моя таблица не выравнивается. Он не отвечает вслепую: он может читать файлы проекта и искать по ним, проверять диагностику LaTeX, компилировать проект и даже просматривать отрисованные страницы PDF, поэтому его ответы основаны на вашем реальном документе.

Если ассистент хочет что-то изменить, он сначала показывает diff. Ничего не записывается без вашего одобрения, так что статья остаётся вашей.

<img src="https://github.com/user-attachments/assets/ea4e0dad-3561-4726-b380-5d9dcfe29693" alt="Демонстрация AI Chat и Error Assistant" width="787" />

LaTeX Error Assistant создан для знакомой ночной ситуации: в логе красная ошибка, и непонятно, что она означает. Нажмите Suggest fix рядом с ошибкой — ассистент прочитает вызвавший её файл и предложит минимальное изменение, которое должно её исправить, не затрагивая остальное форматирование. Если исправление выглядит правильным, примените его одним щелчком и скомпилируйте снова. Если исправление затрагивает пакеты, команды или структуру документа, сначала бегло его просмотрите.

<img src="https://github.com/user-attachments/assets/91b2aefb-c1e4-4e4a-a94d-9824865cdf29" alt="Пример использования Error Assistant" width="787" />

Функции ИИ по умолчанию отключены. Ayakaleaf Pro работает с любым OpenAI-совместимым эндпоинтом — будь то сам OpenAI, шлюз вашей компании или модель, размещённая у вас.

Настройка провайдеров, разрешений, квот и дополнительных поисковых сервисов описана в разделе [AI Integration](/ru/on-premises/configuration/overleaf-toolkit/ai-integration  "mention").

#### Функция 02: Open in Overleaf API

Если вы ведёте страницу курса, библиотеку шаблонов или сайт документации, теперь вы можете дать читателям кнопку, которая сразу открывает готовый к работе проект. Эта функция включена по умолчанию. Полный справочник и живые примеры доступны по адресу `your.overleaf.com/devs`.

<Frame>
  <img src="/images/blog/img-2fac54e7.png" alt="" />
</Frame>

Достаточно ссылки или небольшой формы. Можно отправить фрагмент LaTeX (`snip` или `encoded_snip`), причём голый фрагмент будет автоматически обёрнут в минимальный документ. Можно указать один или несколько удалённых файлов через `snip_uri` (до 50 за раз) или передать целый проект в виде ZIP через `zip_uri`. Необязательные параметры задают компилятор (`engine`), основной документ (`main_document`) и имя проекта (`name`). Контент открывается как новый проект в вашем экземпляре, готовый к редактированию и компиляции. Если посетитель ещё не вошёл в систему, он сначала входит, а затем всё равно попадает в свой новый проект.

```html wrap
<a href="https://your.overleaf.com/docs?snip_uri=https://example.com/paper.tex&engine=xelatex">
  Open in Overleaf
</a>
```

#### Функция 03: интеграция с Mendeley

В 6.2 мы добавили Zotero, и с тех пор пользователи Mendeley просили о том же. Привяжите свою учётную запись Mendeley, выберите библиотеку или группу — и ваши ссылки будут импортированы в виде файла `.bib`, который можно обновлять при каждом изменении библиотеки. Как и на overleaf.com, в общем проекте обновлять файл может только тот, кто его импортировал.

Для администраторов: добавьте `mendeley` в `ENABLED_LINKED_FILE_TYPES` и задайте `MENDELEY_CLIENT_ID` и `MENDELEY_CLIENT_SECRET` из вашего приложения разработчика Mendeley.

Полные инструкции по настройке см. в разделе [Mendeley Integration](/ru/on-premises/configuration/overleaf-toolkit/mendeley-integration  "mention").

#### Функция 04: пагинация шаблонов

Раньше галерея загружала все шаблоны в браузер и сортировала их там. Для пятидесяти шаблонов это нормально, для пяти тысяч — мучительно. Теперь пагинация, поиск и сортировка выполняются в MongoDB, а браузер получает только просматриваемую страницу.

Всё работает без какой-либо подготовки. Если в вашей галерее тысячи шаблонов, следующие индексы помогут сохранить её быстродействие. Скрипт безопасно запускать повторно; замените `mongo` и `sharelatex` именами своего контейнера и базы данных:

```bash
docker exec mongo mongosh sharelatex --quiet --eval '
db.templates.createIndex({category:1,lastUpdated:-1},{name:"category_1_lastUpdated_-1",background:true});
db.templates.createIndex({lastUpdated:-1},{name:"lastUpdated_-1",background:true});
db.templates.createIndex({category:1,name:1},{name:"category_1_name_1_ci",collation:{locale:"en",strength:2},background:true});
db.templates.createIndex({name:1},{name:"name_1_ci",collation:{locale:"en",strength:2},background:true});
'
```

Оставьте `collation` в двух индексах `*_ci` в точности как написано — галерея выполняет запросы с той же collation, а MongoDB использует только соответствующий индекс.

#### Прочее

Для импорта внешних файлов настройте `OVERLEAF_LINKED_URL_OUTBOUND_PROXY`, чтобы использовать HTTP(S)-прокси, в том числе локально размещённый. Этот параметр применяется как к файлам по связанным URL, так и к удалённым ресурсам ZIP или TeX, импортируемым через Open in Overleaf API. Настройка и ограничения сетевого доступа описаны в разделе [External URL — Outbound Proxy](/ru/on-premises/configuration/overleaf-toolkit/external-url#outbound-proxy  "mention").

* Добавлены `OVERLEAF_HEADER_IMAGE_URL_LIGHT` и `OVERLEAF_HEADER_IMAGE_URL_DARK` для поддержки отдельных логотипов в шапке для светлой и тёмной тем.
* Теперь файлы можно открывать в разных вкладках редактора.
