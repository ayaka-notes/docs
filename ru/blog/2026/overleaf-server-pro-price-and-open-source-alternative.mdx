Уже много лет пользователи Overleaf Community Edition проявляют большой интерес к Overleaf Server Pro, поскольку у Overleaf CE слишком много ограничений, например:

* Без изоляции (sandboxing) компиляция LaTeX выполняется с теми же привилегиями, что и контейнер.
* Нет поддержки переключения версий TeX Live. Каждую версию приходится устанавливать вручную.
* Нет отслеживания изменений, из-за чего совместное написание и комментирование становятся довольно сложными.
* Нет интеграции с Git, из-за чего пользователям локального LaTeX трудно присоединяться к совместным проектам.

Однако найти понятную и достоверную информацию о ценах было сложно. На сайте Overleaf единственный вариант — связаться с отделом продаж. Похоже, что Server Pro недоступен для прямой покупки отдельными пользователями. С помощью поисковых систем нам удалось найти некоторую информацию о ценах.

По информации, собранной нами в сообществе, **условия для Server Pro таковы**:

* Необходимо приобрести лицензии _как минимум_ на 10 человек.
* Лицензия на 10 человек стоит около 3 477,61 €. (в 2024 году)
* Для образовательных учреждений: 20 пользователей — 2640 евро в год, 50 пользователей — 6050 евро, 100 пользователей — 9963 евро.
* Server Pro доступен только в отдельных регионах (например, за исключением материкового Китая).

Позднее, в 2026 году, мы с помощью ChatGPT Search нашли ещё несколько организаций, которые приобрели Overleaf Server Pro.

Судя по всему, Overleaf Server Pro стоит около \$300 за пользователя в год. Небольшие контракты в США указывают на годовую стоимость примерно \$320–\$370 за пользователя. Крупные институциональные соглашения могут предусматривать более низкую цену за пользователя. Например, трёхлетнее соглашение Общества Макса Планка в среднем обходится примерно в 51 € за пользователя в год. Условия контрактов, поддержка и масштаб развертывания могут отличаться. Эти записи не являются официальным прайс-листом Overleaf.

Тем не менее разработчики из сообщества годами работали над тем, чтобы восполнить недостающие функции Community Edition. Мы рекомендуем Ayakaleaf Pro — один из самых полных форков Overleaf, доступных на сегодняшний день. Ниже приведено сравнение функций.

### Создать онлайн-редактор LaTeX? Не так-то просто!

С начала 2026 года альтернативы Overleaf появляются чуть ли не каждый месяц — с помощью агентов для написания кода, таких как Claude или Codex. OpenAI тоже представила свой [Prism](https://prism.openai.com/) — продукт для научного письма на LaTeX.

Хотя многие активно продвигают тезис о том, что Overleaf мёртв, а Prism станет лучшим бесплатным редактором LaTeX, по нашему мнению, Prism всё ещё далёк от зрелого продукта.

На скриншоте ниже — обсуждение Prism в сообществе OpenAI. В большинстве комментариев Prism описывают как продукт с большим количеством ошибок, ещё не готовый к регулярному использованию.

<Frame>
  <img src="/images/blog/img-36568b5f.png" alt="" />
</Frame>

<strong>Создать надёжный онлайн-редактор LaTeX — задача далеко не простая.</strong> Наши наблюдения показывают, что Prism выделяет песочницу при открытии проекта и держит её запущенной — вероятно, потому, что Codex остаётся доступным в фоновом режиме. Это позволяет Codex быстро отвечать, когда пользователь начинает диалог с ИИ. В наших тестах каждой песочнице выделялось примерно 5 vCPU, 6 ГБ памяти и 64 ГБ дискового пространства.

Такая архитектура может создавать значительные вычислительные издержки, когда тысячи пользователей одновременно редактируют проекты LaTeX. Ayakaleaf использует другой подход: песочница создаётся только при запросе компиляции. Каждая компиляция ограничена 1 vCPU и 1 ГБ памяти, а после её завершения песочница уничтожается. Это значительно снижает постоянное потребление ресурсов и делает планирование мощностей для крупных развертываний более предсказуемым.

В более широком смысле Prism показывает, насколько сложно по-прежнему совмещать возможности ИИ с надёжной онлайн-средой разработки — даже при доступе к мощным моделям и зрелой экосистеме программного обеспечения с открытым исходным кодом. ИИ может улучшить пользовательский опыт, но не заменяет грамотную системную инженерию. В конечном счёте пользователи полагаются на сервисы, которые надёжны, предсказуемы и стабильны.

### Почему Ayakaleaf Pro?

**Ayakaleaf Pro** — это форк Overleaf Community Edition, который привносит в самостоятельно размещаемые развертывания функции уровня Server Pro и SaaS — без необходимости покупать лицензию на каждого пользователя. Он синхронизируется с исходной кодовой базой Overleaf, поэтому вы получаете тот же привычный редактор и рабочий процесс, а также:

* Изолированную компиляцию LaTeX
* Несколько версий TeX Live
* Отслеживание изменений и комментирование
* Интеграцию с Git и GitHub
* SSO и панель администратора
* Управление частными шаблонами
* Zotero и расширенный поиск по библиографии
* Импорт/экспорт через Pandoc
* Python Script Runner
* Отсутствие платы за лицензию на пользователя

Наша цель — обеспечить более полноценный опыт самостоятельно размещаемого Overleaf без лицензии Server Pro и без подписки на SaaS. Ayakaleaf Pro сохраняет привычный рабочий процесс Overleaf и совместимость с исходным проектом, добавляя функции для совместной работы, администрирования, интеграций и безопасной компиляции.

### Почему мы продолжаем изобретать велосипед?

Здесь стоит задать более общий вопрос: _**если зрелый проект с открытым исходным кодом уже решает большинство сложных задач, почему так часто возникает желание переписать его с нуля**_?&#x20;

Повторная реализация редактора, слоя совместной работы в реальном времени, конвейера компиляции и многолетних исправлений пограничных случаев обходится чрезвычайно дорого — и значительная часть этих усилий уходит на повторное открытие проблем, которые исходный проект давно решил. Как правило, расширить прочную основу и вернуть недостающие части в проект — более практичное инженерное решение.

На самом деле я хочу сказать вот что:

> _В эпоху ИИ людям нравится хвастаться._

«Я создал свой собственный Overleaf» звучит гораздо внушительнее, чем «Я добавил несколько функций в Overleaf», — поэтому люди предпочитают рассказывать именно такую историю. Именно поэтому новый «ИИ-редактор LaTeX», кажется, появляется каждый месяц.

Но в действительности эти переписанные с помощью ИИ проекты и близко не достигают той надёжности и зрелости, которые даёт десятилетие проверки в реальных условиях, как у Overleaf. Дайте им два месяца — и их авторы забросят свой редактор, как рождественскую игрушку в феврале. Поверьте мне.
