Мы с гордостью объявляем о выпуске Ayakaleaf Pro 6.2 — самого мощного и функционального онлайн-редактора LaTeX в сообществе. Особая благодарность yu-i-i и davrot за их ценный вклад: они улучшили GitHub Sync и добавили расширенный поиск цитат (Advanced Citation Search) и интеграцию с Zotero.

### Примечания

* Добавлена новая обязательная переменная окружения `OVERLEAF_INVITE_TOKEN_SECRET`; её необходимо сгенерировать командой `openssl rand -base64 32`. Если она не настроена, экземпляр Overleaf не запустится.
* Если вы включаете GitHub Sync, необходимо настроить переменную окружения `GITHUB_TOKEN_CIPHER_PASSWORD`. Она нужна для безопасного шифрования токенов доступа GitHub. Без неё экземпляр Overleaf не запустится.
* Добавлена новая переменная окружения `DEFAULT_LATEX_COMPILER` для выбора компилятора по умолчанию для новых проектов (pdflatex, latex, xelatex или lualatex).
* Обновлённый редактор теперь является единственным доступным вариантом.

### Изменения

Этот выпуск включает следующие улучшения и новые функции.

* `MAX_UPLOAD_SIZE` теперь настраивается и больше не ограничен **50 МБ**.
* Исправлен цикл перезапуска контейнера при отключённых изолированных компиляциях.
* Для OAuth2 введено удаление PAT только в пределах владельца.
* Исправлена проблема с импортом LDAP.

Новые функции:

* Добавлен запуск Python в браузере.
* Добавлена поддержка Pandoc для импорта и экспорта Markdown, DOCX и других форматов.
* Добавлен GitHub Sync.
* Добавлен полный перевод на китайский язык.
* Добавлена интеграция с Zotero.
* Добавлена `DEFAULT_LATEX_COMPILER`.

#### Функция 01: GitHub Sync

Синхронизируйте свои проекты LaTeX с репозиториями GitHub для бесшовного рабочего процесса. Отправляйте и получайте изменения прямо из редактора, работайте совместно через pull request'ы и интегрируйтесь с существующими конвейерами CI/CD. Контроль версий упрощает отслеживание правок, просмотр изменений и поддержку воспроизводимости научных и технических документов.

См.: [GitHub Synchronisation](/ru/on-premises/configuration/overleaf-toolkit/github-synchronisation  "mention").

#### Функция 02: импорт и экспорт через Pandoc

Импортируйте документы Microsoft Word и Markdown в полностью редактируемые проекты LaTeX или экспортируйте проекты LaTeX обратно в Markdown и DOCX одним щелчком. Эта функция на базе Pandoc обеспечивает бесшовную совместимость между академическим письмом, совместным редактированием и издательскими процессами, максимально сохраняя структуру документа.

См.: [Pandoc Import and Export](/ru/on-premises/configuration/overleaf-toolkit/pandoc-import-and-export  "mention").

#### Функция 03: расширенный поиск библиографических ссылок

Ищите и вставляйте библиографические ссылки из нескольких академических баз данных с интеллектуальной фильтрацией и мгновенной поддержкой цитирования. Быстро находите статьи, просматривайте метаданные и создавайте точные записи BibTeX, не переключаясь между разными исследовательскими сайтами, — это значительно повышает эффективность работы с литературой.

![image](https://github.com/user-attachments/assets/42e45b73-af4b-4d1f-81f4-9e116ba5d043)

#### Функция 04: запуск Python

Выполняйте код Python прямо в проекте, не выходя из редактора. Отлично подходит для построения графиков, обработки наборов данных, автоматизации работы с документами или запуска воспроизводимых исследовательских скриптов. Результаты можно интегрировать в документы LaTeX, объединяя научные вычисления и написание текста в единый рабочий процесс.

![image](https://github.com/user-attachments/assets/a4c314b3-fdb5-4836-aea7-12eeece5cd2f)

#### Функция 05: Zotero

Подключите свою библиотеку Zotero непосредственно к рабочему процессу написания и управляйте ссылками, не выходя из редактора. Ищите в своих коллекциях Zotero, вставляйте цитаты одним щелчком, автоматически создавайте и синхронизируйте записи BibTeX. Эта интеграция поддерживает библиографию в актуальном состоянии и упрощает управление литературой для научных статей, диссертаций и технических документов.

См.: [Zotero Integration](/ru/on-premises/configuration/overleaf-toolkit/zotero-integration  "mention").
