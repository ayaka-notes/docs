## Qu'est-ce que LaTeX ?

LaTeX (prononcé « _LÈ_-tek » ou « _LA_-tek ») est un outil permettant de composer des documents d'aspect professionnel. Toutefois, le mode de fonctionnement de LaTeX est très différent de celui de nombreuses autres applications de production de documents que vous avez peut-être utilisées, comme Microsoft Word ou LibreOffice Writer : ces outils « [WYSIWYG](https://en.wikipedia.org/wiki/WYSIWYG) » offrent aux utilisateurs une page interactive dans laquelle ils saisissent et modifient leur texte et appliquent diverses formes de mise en forme. LaTeX fonctionne très différemment : votre document est un fichier texte brut parsemé de _commandes_ LaTeX qui expriment le résultat (composé) souhaité. Pour produire un document composé visible, votre fichier LaTeX est traité par un logiciel appelé _moteur TeX_, qui utilise les commandes intégrées dans votre fichier texte pour guider et contrôler le processus de composition, en convertissant les commandes LaTeX et le texte du document en un fichier PDF composé de façon professionnelle. Cela signifie que vous n'avez qu'à vous concentrer sur le _contenu_ de votre document, et l'ordinateur, via les commandes LaTeX et le moteur TeX, se charge de l'_apparence visuelle_ (la mise en forme).

## Pourquoi apprendre LaTeX ?

Divers arguments peuvent être avancés pour ou contre l'apprentissage de LaTeX plutôt que d'autres applications de rédaction de documents ; mais, en fin de compte, il s'agit d'un choix personnel fondé sur les préférences, les affinités et les exigences documentaires.

Parmi les arguments en faveur de LaTeX :

* la prise en charge de la composition de mathématiques extrêmement complexes, de tableaux et de contenus techniques pour les sciences physiques ;
* des fonctionnalités pour les notes de bas de page, les renvois et la gestion des bibliographies ;
* la facilité de production d'éléments de document complexes ou fastidieux, tels que les index, les glossaires, les tables des matières et les listes de figures ;
* une grande capacité de personnalisation pour la production de documents sur mesure, grâce à sa programmabilité intrinsèque et à son extensibilité via des milliers de [packages complémentaires gratuits](https://www.ctan.org/pkg).

Dans l'ensemble, LaTeX offre aux utilisateurs un contrôle très poussé sur la production de documents composés selon des normes de qualité extrêmement élevées. Bien sûr, il existe des types de documents ou de publications pour lesquels LaTeX n'excelle pas, notamment de nombreuses mises en page « libres » que l'on trouve généralement dans les publications de type magazine.

Un avantage important de LaTeX est la séparation entre le contenu et le style du document : une fois le contenu rédigé, son apparence peut être modifiée facilement. De même, vous pouvez créer un fichier LaTeX qui définit la mise en page et le style d'un type de document particulier, et ce fichier peut servir de _modèle_ pour normaliser la rédaction et la production d'autres documents de ce type ; par exemple, cela permet aux éditeurs scientifiques de créer en LaTeX des modèles d'articles que les auteurs utilisent pour rédiger les articles qu'ils soumettent aux revues. Overleaf dispose d'une [galerie contenant des milliers de modèles](https://www.overleaf.com/gallery), couvrant une gamme considérable de types de documents — des articles scientifiques, rapports et livres jusqu'aux CV et présentations. Comme ces modèles définissent la mise en page et le style du document, les auteurs n'ont qu'à les ouvrir dans Overleaf — en créant un nouveau projet — et à commencer à écrire pour y ajouter leur contenu.

## Écrire votre premier code LaTeX

La première étape consiste à créer un nouveau projet LaTeX. Vous pouvez le faire sur votre propre ordinateur en créant un nouveau fichier `.tex` ; vous pouvez aussi démarrer un nouveau projet dans Overleaf.

Commençons par l'exemple fonctionnel le plus simple, qui peut être ouvert directement dans Overleaf :

```latex
\documentclass{article}
\begin{document}
First document. This is a simple example, with no 
extra parameters or packages included.
\end{document}
```

Vous pouvez constater que LaTeX a automatiquement indenté la première ligne du paragraphe, en se chargeant de cette mise en forme à votre place. Examinons de plus près le rôle de chaque partie de notre code.

La première ligne de code, `\documentclass{article}`, déclare le type de document, appelé sa _classe_, qui contrôle l'apparence générale du document. Différents types de documents nécessitent différentes classes ; par exemple, un CV nécessitera une classe différente de celle d'un article scientifique, qui pourrait utiliser la classe LaTeX standard `article`. D'autres types de documents sur lesquels vous travaillez peuvent nécessiter des classes différentes, comme `book` ou `report`. Pour avoir une idée des nombreux types de classes LaTeX disponibles, [consultez la page correspondante sur CTAN (Comprehensive TeX Archive Network)](https://www.ctan.org/topic/class).

Une fois la classe du document définie, notre contenu, appelé le _corps_ du document, est écrit entre les balises `\begin{document}` et `\end{document}`. ## Le préambule d'un document

La capture d'écran ci-dessus montre Overleaf stockant un document LaTeX dans un fichier nommé `main.tex` : l'extension de fichier `.tex` est, par convention, utilisée pour nommer les fichiers contenant le code LaTeX de votre document.

L'exemple précédent a montré comment le contenu du document était saisi après la commande `\begin{document}` ; cependant, tout ce qui figure dans votre fichier `.tex` _avant_ ce point est appelé le _préambule_, qui sert de section de « configuration » du document. Dans le préambule, vous définissez la classe (le type) du document ainsi que des éléments spécifiques tels que les langues utilisées pour rédiger le document ; vous y chargez les _packages_ que vous souhaitez utiliser (nous y reviendrons [plus loin](/fr/texlive/latex-basics/learn-latex-in-30-minutes#Finding%5Fand%5Fusing%5FLaTeX%5Fpackages)), et c'est là que vous appliquez d'autres types de configuration.

Un préambule de document minimal pourrait ressembler à ceci :

```latex
\documentclass[12pt, letterpaper]{article}
\usepackage{graphicx}
```

où `\documentclass[12pt, letterpaper]{article}` définit la classe (le type) générale du document. Des paramètres supplémentaires, qui doivent être séparés par des virgules, sont placés entre crochets (`[...]`) et servent à configurer cette instance de la classe article ; c'est-à-dire les réglages que nous souhaitons utiliser pour ce document particulier basé sur la classe `article`.

Dans cet exemple, les deux paramètres ont l'effet suivant :

* `12pt` définit la taille de la police
* `letterpaper` définit le format du papier

Bien entendu, d'autres tailles de police, `9pt`, `11pt`, `12pt`, peuvent être utilisées, mais si aucune n'est spécifiée, la taille par défaut est `10pt`. Pour le format du papier, d'autres valeurs possibles sont `a4paper` et `legalpaper`. Pour plus d'informations, consultez l'article sur le format de page et les marges.

La ligne de préambule

```latex
\usepackage{graphicx}
```

est un exemple de chargement d'un package externe (ici, [graphicx](https://ctan.org/pkg/graphicx?lang=en)) pour étendre les capacités de LaTeX, en lui permettant d'importer des fichiers graphiques externes. Les packages LaTeX sont présentés dans la section [Trouver et utiliser des packages LaTeX](/fr/texlive/latex-basics/learn-latex-in-30-minutes#Finding%5Fand%5Fusing%5FLaTeX%5Fpackages).

## Ajouter le titre, l'auteur et la date

Pour ajouter un titre, un auteur et une date à notre document, il faut trois lignes supplémentaires dans le _préambule_ (_et non_ dans le corps principal du document). Ces lignes sont :

* `\title{My first LaTeX document}` : le titre du document
* `\author{Hubert Farnsworth}` : vous y écrivez le nom du ou des auteurs et, éventuellement, la commande `\thanks` entre les accolades :
  * `\thanks{Funded by the Overleaf team.}` : peut être ajoutée après le nom de l'auteur, à l'intérieur des accolades de la commande `author`. Elle ajoute un exposant et une note de bas de page contenant le texte entre les accolades. Utile si vous devez remercier une institution dans votre article.
* `\date{August 2022}` : vous pouvez saisir la date manuellement ou utiliser la commande `\today` pour composer la date du jour à chaque compilation du document

Une fois ces lignes ajoutées, votre préambule devrait ressembler à ceci :

```latex
\documentclass[12pt, letterpaper]{article}
\title{My first LaTeX document}
\author{Hubert Farnsworth\thanks{Funded by the Overleaf team.}}
\date{August 2022}
```

Pour composer le titre, l'auteur et la date, utilisez la commande `\maketitle` dans le _corps_ du document :

```latex
\begin{document}
\maketitle
We have now added a title, author and date to our first \LaTeX{} document!
\end{document}
```

Le préambule et le corps peuvent maintenant être combinés pour produire un document complet, qui peut être ouvert dans Overleaf :

```latex
\documentclass[12pt, letterpaper]{article}
\title{My first LaTeX document}
\author{Hubert Farnsworth\thanks{Funded by the Overleaf team.}}
\date{August 2022}
\begin{document}
\maketitle
We have now added a title, author and date to our first \LaTeX{} document!
\end{document}
```

## Ajouter des commentaires

LaTeX est une forme de « code de programme », mais spécialisée dans la composition de documents ; par conséquent, comme pour du code écrit dans n'importe quel autre langage de programmation, il peut être très utile d'inclure des commentaires dans votre document. Un commentaire LaTeX est une portion de texte qui ne sera pas composée et n'affectera en rien le document — souvent utilisée pour ajouter des notes « à faire », inclure des notes explicatives, fournir des explications en ligne de macros délicates ou mettre en commentaire des lignes ou sections de code LaTeX lors du débogage.

Pour écrire un commentaire en LaTeX, il suffit de placer un symbole `%` au début de la ligne, comme le montre le code suivant, qui reprend l'exemple ci-dessus :

```latex
\documentclass[12pt, letterpaper]{article}
\title{My first LaTeX document}
\author{Hubert Farnsworth\thanks{Funded by the Overleaf team.}}
\date{August 2022}
\begin{document}
\maketitle
We have now added a title, author and date to our first \LaTeX{} document!

% This line here is a comment. It will not be typeset in the document.
\end{document}
```

[Ouvrir cet exemple dans Overleaf.](https://www.overleaf.com/docs?engine=pdflatex&snip%5Fname=My+first+LaTeX+document+with+a+comment&snip=%5Cdocumentclass%5B12pt%2C+letterpaper%5D%7Barticle%7D%0A%5Ctitle%7BMy+first+LaTeX+document%7D%0A%5Cauthor%7BHubert+Farnsworth%5Cthanks%7BFunded+by+the+Overleaf+team.%7D%7D%0A%5Cdate%7BAugust+2022%7D%0A%5Cbegin%7Bdocument%7D%0A%5Cmaketitle%0AWe+have+now+added+a+title%2C+author+and+date+to+our+first+%5CLaTeX%7B%7D+document%21%0A%0A%25+This+line+here+is+a+comment.+It+will+not+be+typeset+in+the+document.%0A%5Cend%7Bdocument%7D)

Cet exemple produit un résultat identique à celui du code LaTeX précédent, qui ne contenait pas le commentaire.

## Gras, italique et soulignement

Examinons maintenant quelques commandes de mise en forme du texte :

* **Gras** : le texte en gras est composé en LaTeX à l'aide de la commande `\textbf{...}`.
* _Italique_ : le texte en italique est produit à l'aide de la commande `\textit{...}`.
* Soulignement : pour souligner du texte, utilisez la commande `\underline{...}`.

L'exemple suivant illustre ces commandes :

```latex
Some of the \textbf{greatest}
discoveries in \underline{science} 
were made by \textbf{\textit{accident}}.
```

## Ajouter des images

Dans cette section, nous verrons comment ajouter des images à un document LaTeX. Overleaf prend en charge trois façons d'insérer des images :

1. Utilisez le [bouton **Insert Figure**](https://learn.overleaf.com/learn/Kb/How_to_insert_figures_in_Overleaf#Using%5FInsert%5FFigure%5Fto%5Fadd%5Fa%5Ffigure%5Fto%5Fyour%5Fproject)(![Le bouton Insert Figure de la barre d'outils de l'éditeur](https://sharelatex-wiki-cdn-671420.cdn77.org/learn-scripts/images/a/a8/InsertFigureButton.png)), situé dans la barre d'outils de l'éditeur, pour insérer une image dans le **Visual Editor** ou le **Code Editor**.
2. Copiez et collez une image dans le **Visual Editor** ou le **Code Editor**.
3. Utilisez le **Code Editor** pour écrire le code LaTeX qui insère un graphique.

Les options 1 et 2 génèrent automatiquement le code LaTeX nécessaire à l'insertion des images, mais nous présentons ici l'option 3 — notez que vous devrez [téléverser ces images](https://docs.overleaf.com/writing-and-editing/inserting-images) dans votre projet Overleaf. L'exemple suivant montre comment inclure une image :

```latex
\documentclass{article}
\usepackage{graphicx} %LaTeX package to import graphics
\graphicspath{{images/}} %configuring the graphicx package
 
\begin{document}
The universe is immense and it seems to be homogeneous, 
on a large scale, everywhere we look.

% The \includegraphics command is 
% provided (implemented) by the 
% graphicx package
\includegraphics{universe}  
 
There's a picture of a galaxy above.
\end{document}
```

L'importation de graphiques dans un document LaTeX nécessite [un _package_ complémentaire](/fr/texlive/latex-basics/learn-latex-in-30-minutes#Finding%5Fand%5Fusing%5FLaTeX%5Fpackages) qui fournit les commandes et fonctionnalités nécessaires pour inclure des fichiers graphiques externes. Pour utiliser le package `graphicx`, ajoutez la ligne suivante dans le préambule de votre document Overleaf :

```latex

```

Dans notre exemple, la commande `\graphicspath{{images/}}` indique à LaTeX que les images sont conservées dans un dossier nommé `images`, situé dans le répertoire courant :

* Bien que le nom de fichier complet, extension comprise, soit autorisé dans la commande `\includegraphics`, il est considéré comme une bonne pratique d'omettre l'extension, car LaTeX recherchera alors tous les formats pris en charge.

## Légendes, étiquettes et références

Les images peuvent être légendées, étiquetées et référencées au moyen de l'environnement `figure`, comme ci-dessous :

```latex
\documentclass{article}
\usepackage{graphicx}
\graphicspath{{images/}}
 
\begin{document}

\begin{figure}[h]
    \centering
    \includegraphics[width=0.75\textwidth]{mesh}
    \caption{A nice plot.}
    \label{fig:mesh1}
\end{figure}
 
As you can see in figure \ref{fig:mesh1}, the function grows near the origin. This example is on page \pageref{fig:mesh1}.

\end{document}
```

[Ouvrir cet exemple d'image dans Overleaf.](https://www.overleaf.com/project/new/template/25519?id=107980830&templateName=Example+using+image+captions+in+LaTeX&latexEngine=pdflatex&texImage=texlive-full%3A2022.1&mainFile=)

Cet exemple produit le résultat suivant :

![Graphique montrant l'utilisation de légendes de figures dans LaTeX](https://images.ctfassets.net/nrgyaltdicpt/4DkAWWkQqZP6QHU2EErogQ/9aa2371f2cde0f3f8bf22aa1c0b91789/LL30Fig6r-plain.svg)

Cet exemple contient plusieurs commandes dignes d'intérêt :

* **`\includegraphics[width=0.75\textwidth]{mesh}`** : cette forme de `\includegraphics` indique à LaTeX de fixer la largeur de la figure à 75 % de la largeur du texte — dont la valeur est stockée dans la commande `\textwidth`.
* **`\caption{A nice plot.}`** : comme son nom l'indique, cette commande définit la légende de la figure, qui peut être placée au-dessus ou en dessous de celle-ci. Si vous créez une liste des figures, cette légende y sera utilisée.
* **`\label{fig:mesh1}`** : pour faire référence à cette image dans votre document, vous lui attribuez une étiquette à l'aide de la commande `\label`. L'étiquette sert à générer un numéro pour l'image et, combinée à la commande suivante, vous permettra d'y faire référence.
* **`\ref{fig:mesh1}`** : ce code sera remplacé par le numéro correspondant à la figure référencée.

Les images intégrées à un document LaTeX doivent être placées dans un environnement `figure`, ou similaire, afin que LaTeX puisse positionner automatiquement l'image à un emplacement approprié de votre document.

## Créer des listes en LaTeX

Vous pouvez créer différents types de listes à l'aide d'_environnements_, qui servent à encapsuler le code LaTeX nécessaire à la mise en œuvre d'une fonctionnalité de composition spécifique. Un environnement commence par `\begin{_environment-name_}` et se termine par `\end{_environment-name_}`, où `_environment-name_` peut être `figure`, `tabular` ou l'un des types de listes : `itemize` pour les listes non ordonnées ou `enumerate` pour les listes ordonnées.

### Listes non ordonnées

Les listes non ordonnées sont produites par l'environnement `itemize`. Chaque élément de la liste doit être précédé de la commande `\item`, comme ci-dessous :

```latex
\documentclass{article}
\begin{document}
\begin{itemize}
  \item The individual entries are indicated with a black dot, a so-called bullet.
  \item The text in the entries may be of any length.
\end{itemize}
```

## Ajouter des mathématiques en LaTeX

L'un des principaux avantages de LaTeX est la facilité avec laquelle il permet d'écrire des expressions mathématiques. LaTeX propose deux modes d'écriture pour composer des mathématiques :

* le mode mathématique _en ligne_ (inline), utilisé pour écrire des formules qui font partie d'un paragraphe
* le mode mathématique _hors texte_ (display), utilisé pour écrire des expressions qui ne font pas partie d'un texte ou d'un paragraphe et qui sont composées sur des lignes séparées

### Mode mathématique en ligne

Voyons un exemple du mode mathématique en ligne :

```latex
\documentclass[12pt, letterpaper]{article}
\begin{document}
In physics, the mass-energy equivalence is stated 
by the equation $E=mc^2$, discovered in 1905 by Albert Einstein.
\end{document}
```

### Chapitres et sections

Les documents plus longs, quel que soit le logiciel de rédaction, sont généralement découpés en parties, chapitres, sections, sous-sections, etc. LaTeX fournit également des commandes de structuration de document, mais les commandes disponibles, et leur implémentation (ce qu'elles font), peuvent dépendre de la classe de document utilisée. Par exemple, les documents créés avec la classe `book` peuvent être découpés en parties, chapitres, sections, sous-sections, etc., tandis que la classe `letter` ne fournit (ne prend en charge) aucune commande pour cela.

L'exemple suivant présente les commandes utilisées pour structurer un document basé sur la classe `book` :

```latex
\documentclass{book}
\begin{document}

\chapter{First Chapter}

\section{Introduction}

This is the first section.

Lorem  ipsum  dolor  sit  amet,  consectetuer  adipiscing  
elit. Etiam  lobortisfacilisis sem.  Nullam nec mi et 
neque pharetra sollicitudin.  Praesent imperdietmi nec ante. 
Donec ullamcorper, felis non sodales...

\section{Second Section}

Lorem ipsum dolor sit amet, consectetuer adipiscing elit.  
Etiam lobortis facilisissem.  Nullam nec mi et neque pharetra 
sollicitudin.  Praesent imperdiet mi necante...

\subsection{First Subsection}
Praesent imperdietmi nec ante. Donec ullamcorper, felis non sodales...

\section*{Unnumbered Section}
Lorem ipsum dolor sit amet, consectetuer adipiscing elit.  
Etiam lobortis facilisissem...
\end{document}
```

Les noms des commandes de sectionnement sont pour la plupart explicites ; par exemple, `\chapter{First Chapter}` crée un nouveau chapitre intitulé `First Chapter`, `\section{Introduction}` produit une section intitulée `Introduction`, et ainsi de suite. Les sections peuvent être subdivisées en `\subsection{...}`, voire en `\subsubsection{...}`. La numérotation des sections, sous-sections, etc. est automatique, mais peut être désactivée en utilisant la _version étoilée_ de la commande appropriée, qui se termine par un astérisque (\*), comme `\section*{...}` et `\subsection*{...}`.

_Dans leur ensemble_, les classes de documents LaTeX fournissent les commandes de sectionnement suivantes, chaque classe prenant en charge un sous-ensemble pertinent :

* `\part{part}`
* `\chapter{chapter}`
* `\section{section}`
* `\subsection{subsection}`
* `\subsubsection{subsubsection}`
* `\paragraph{paragraph}`
* `\subparagraph{subparagraph}`

En particulier, les commandes `\part` et `\chapter` ne sont disponibles que dans les classes de documents `report` et `book`.

## Créer des tableaux

Overleaf propose trois options pour créer des tableaux :

1. Utiliser le [bouton **Insert Table**](https://www.overleaf.com/learn/how-to/How_to_insert_tables_in_Overleaf%23inserttable#Using%5FInsert%5FTable%5Fto%5Fcreate%5Fa%5Ftable%5Fin%5Fyour%5Fproject) de la barre d'outils du **Visual Editor** (ou du **Code Editor**).
2. [Copier et coller un tableau](https://www.overleaf.com/learn/how-to/How_to_paste_formatted_content_into_Overleaf%23pastingtables) depuis un autre document en utilisant le **Visual Editor**.
3. Écrire le code LaTeX du tableau dans le Code Editor.

Si vous débutez avec LaTeX, utiliser la barre d'outils du **Visual Editor** (option 1) est un excellent moyen de commencer — vous pouvez basculer entre le **Visual Editor** et le **Code Editor** pour voir le code qui se cache derrière le tableau.

Ici, nous nous concentrons sur l'option 3 — la méthode la plus souple pour créer des tableaux — et fournissons des exemples qui montrent comment créer des tableaux en LaTeX, y compris l'ajout de lignes (filets) et de légendes. À mesure que vous gagnez en expérience, consultez nos conseils détaillés sur [la création de tableaux avec LaTeX](https://www.overleaf.com/learn/latex/Tables).

### Créer un tableau simple en LaTeX

Commençons par un exemple montrant comment composer un tableau simple :

```latex
\begin{center}
\begin{tabular}{c c c}
 cell1 & cell2 & cell3 \\ 
 cell4 & cell5 & cell6 \\  
 cell7 & cell8 & cell9    
\end{tabular}
\end{center}
```

L'environnement `tabular` est la méthode LaTeX par défaut pour créer des tableaux. Vous devez fournir un paramètre à cet environnement, ici `{c c c}`, qui indique à LaTeX qu'il y aura trois colonnes et que le texte de chacune doit être centré. Vous pouvez également utiliser `r` pour aligner le texte à droite et `l` pour l'aligner à gauche. Le symbole d'alignement `&` sert à délimiter les cellules individuelles d'une ligne du tableau. Pour terminer une ligne du tableau, utilisez la commande de _nouvelle ligne_ `\\`. Notre tableau est placé dans un environnement `center` afin d'être centré dans la largeur du texte de la page.

### Ajouter des bordures

L'environnement `tabular` prend en charge des lignes (filets) horizontales et verticales dans le tableau :

* pour ajouter des filets horizontaux au-dessus et en dessous des lignes, utilisez la commande `\hline`
* pour ajouter des filets verticaux entre les colonnes, utilisez le paramètre de ligne verticale `|`

Dans cet exemple, l'argument est `{|c|c|c|}`, qui déclare trois colonnes (centrées) séparées chacune par une ligne verticale (filet) ; en outre, nous utilisons `\hline` pour placer un filet horizontal au-dessus de la première ligne et en dessous de la dernière :

```latex
\begin{center}
\begin{tabular}{|c|c|c|} 
 \hline
 cell1 & cell2 & cell3 \\ 
 cell4 & cell5 & cell6 \\ 
 cell7 & cell8 & cell9 \\ 
 \hline
\end{tabular}
\end{center}
```

### Légendes, étiquettes et références

Vous pouvez légender et référencer des tableaux de la même manière que des images. La seule différence est qu'au lieu de l'environnement **`figure`**, vous utilisez l'environnement **`table`**.

Le tableau \ref\{table:data\} montre comment ajouter une légende à un tableau et y faire référence.

```latex
\begin{table}[h!]
\centering
\begin{tabular}{||c c c c||} 
 \hline
 Col1 & Col2 & Col2 & Col3 \\ [0.5ex] 
 \hline\hline
 1 & 6 & 87837 & 787 \\ 
 2 & 7 & 78 & 5415 \\
 3 & 545 & 778 & 7507 \\
 4 & 545 & 18744 & 7560 \\
 5 & 88 & 788 & 6344 \\ [1ex] 
 \hline
\end{tabular}
\caption{Table to test captions and labels.}
\label{table:data}
\end{table}
```

## Trouver et utiliser des packages LaTeX

LaTeX offre non seulement d'importantes capacités de composition, mais fournit aussi un _cadre d'extensibilité_ grâce à l'utilisation de _packages_ complémentaires. Plutôt que d'essayer de fournir des commandes et des fonctionnalités qui « font tout », LaTeX est conçu pour être _extensible_ : les utilisateurs peuvent charger des ensembles de code externes (packages) qui offrent des capacités de composition plus spécialisées ou étendent les fonctionnalités intégrées de LaTeX — comme la composition de tableaux. Comme nous l'avons vu dans la section [Ajouter des images](/fr/texlive/latex-basics/learn-latex-in-30-minutes#Adding%5Fimages), le package `graphicx` étend LaTeX en fournissant des commandes pour importer des fichiers graphiques ; il a été chargé (dans le préambule) en écrivant

```latex
\usepackage{graphicx}
```

### Charger des packages

Comme indiqué ci-dessus, les packages sont chargés dans le préambule du document via la commande `\usepackage` ; mais comme (de nombreux) packages LaTeX proposent un ensemble d'_options_ permettant de configurer leur comportement, la commande `\usepackage` ressemble souvent à ceci :

```latex
\usepackage[options]{somepackage}
```

Les crochets « `[...]` » indiquent à LaTeX quel ensemble d'options appliquer lors du chargement de `somepackage`. Dans l'ensemble d'options demandé par l'utilisateur, les options ou réglages individuels sont généralement séparés par une virgule ; par exemple, le [package geometry](https://ctan.org/pkg/geometry) propose de nombreuses options pour configurer la mise en page dans LaTeX, et une utilisation typique de `geometry` pourrait ressembler à ceci :

```latex
\usepackage[total={6.5in,8.75in},
top=1.2in, left=0.9in, includefoot]{geometry}
```

Le package `geometry` est un exemple de package écrit et proposé par des membres de la communauté LaTeX mondiale, et mis gratuitement à la disposition de tous ceux qui souhaitent l'utiliser.

Si un package LaTeX ne propose aucune option, ou si l'utilisateur souhaite utiliser les valeurs par défaut des options d'un package, il se charge ainsi :

```latex
\usepackage{somepackage}
```

Lorsque vous écrivez `\usepackage[...]{somepackage}`, LaTeX recherche un fichier correspondant nommé `_somepackage_.sty`, qu'il doit charger et traiter — afin de rendre disponibles les commandes du package et d'exécuter tout autre code fourni par ce package. Si LaTeX ne trouve pas `_somepackage_.sty`, il s'arrête avec une erreur, comme le montre l'exemple Overleaf suivant :

```latex
\documentclass[12pt, letterpaper]{article}
\usepackage{somepackage}% a NON-EXISTENT package
\begin{document}
This will fail!
\end{document}
```

### Trouver des informations sur les packages : CTAN

Les packages sont distribués via le [Comprehensive TeX Archive Network](https://www.ctan.org/), généralement appelé CTAN, qui, au moment de la rédaction, héberge 6287 packages provenant de 2881 contributeurs. CTAN [se décrit](https://www.ctan.org/ctan) comme

> ... un ensemble de sites Internet répartis dans le monde entier qui proposent en téléchargement du matériel lié à TEX.

Vous pouvez parcourir CTAN à la recherche de packages utiles, par exemple :

* [par thème](https://www.ctan.org/topics/cloud)
* [par ordre alphabétique](https://www.ctan.org/pkg) (utile si vous connaissez le nom du package)

Vous pouvez également utiliser la [fonction de recherche](https://www.ctan.org/pkg) (en haut de la page).

### Packages disponibles sur Overleaf : présentation de TeX Live

Une fois par an, un (vaste) _sous-ensemble_ des packages hébergés sur CTAN, ainsi que des polices liées à LaTeX et d'autres logiciels, est rassemblé et distribué sous la forme d'un système appelé [TeX Live](https://tug.org/texlive/), qui peut servir à installer votre propre environnement LaTeX (local). En fait, [les serveurs d'Overleaf utilisent également TeX Live](https://www.overleaf.com/learn/latex/Overleaf_and_TeX_Live) et sont mis à jour lors de la publication d'une nouvelle version de TeX Live. Les mises à jour de TeX Live sur Overleaf ne sont pas immédiates mais interviennent quelques mois après la publication, ce qui nous laisse le temps de tester la compatibilité de la nouvelle version de TeX Live avec les [milliers de modèles de notre galerie](https://www.overleaf.com/gallery). Voici par exemple notre [annonce de la mise à niveau vers TeX Live 2025](https://www.overleaf.com/blog/tex-live-2025-is-now-available).

Bien que TeX Live contienne un (vaste) _sous-ensemble_ des packages de CTAN, il est possible de trouver un package intéressant, comme [igo pour composer des diagrammes de go](https://ctan.org/pkg/igo?lang=en), qui est hébergé sur CTAN mais n'est pas inclus dans (distribué par) TeX Live, et donc indisponible sur Overleaf. Certains packages hébergés sur CTAN ne font pas partie de TeX Live pour diverses raisons : un package peut être obsolète, présenter des problèmes de licence, être très récent (téléversé récemment) ou dépendre d'une plateforme, par exemple fonctionner sous Windows mais pas sous Linux.

De nouveaux packages, ainsi que des mises à jour de packages existants, sont téléversés sur CTAN tout au long de l'année, mais les mises à jour de TeX Live sont distribuées une fois par an ; par conséquent, les packages contenus dans la version actuelle de TeX Live ne seront pas aussi à jour que ceux hébergés sur CTAN. Comme les serveurs d'Overleaf utilisent TeX Live, il est possible que les packages installés sur nos serveurs — c'est-à-dire ceux mis à la disposition de nos utilisateurs — ne soient pas les toutes dernières versions disponibles sur CTAN, mais, en général, cela ne devrait pas poser de problème.
