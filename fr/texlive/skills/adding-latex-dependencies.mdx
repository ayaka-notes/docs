Si votre projet contient des fichiers `.cls`, `.sty` ou `.bst`, le processus de compilation d'Overleaf ne pourra pas les trouver, sauf s'ils sont placés à la racine du projet.

Cependant, pour organiser votre projet, vous souhaiterez peut-être ranger ces fichiers dans des dossiers afin de les retrouver plus facilement et de ne pas encombrer la racine de votre projet.

Bonne nouvelle : il est possible de spécifier des répertoires `TEXINPUTS` personnalisés à l'aide du fichier `latexmkrc`, afin qu'Overleaf sache qu'il doit rechercher les fichiers de packages dans ce répertoire.

Pour cela, supposons que vous ayez placé ces fichiers de packages dans un dossier nommé `tex/`, et les fichiers de style bibliographique dans un dossier nommé `bst/` :

1. Cliquez sur « Add file » en haut de la barre latérale du projet.
2. Sélectionnez « Blank file » et enregistrez le fichier sous le nom `latexmkrc` (s'il n'existe pas déjà).
3.  Ajoutez les lignes suivantes dans `latexmkrc` :

    ```perl
    $ENV{'TEXINPUTS'}='./tex//:' . $ENV{'TEXINPUTS'}; 
    $ENV{'BSTINPUTS'}='./bst//:' . $ENV{'BSTINPUTS'};
    ```

    (ou remplacez-les par les noms de dossiers correspondants dans votre projet)

Overleaf recherchera désormais d'abord dans le dossier `tex/` avant le `TEXINPUTS` du système pour trouver les fichiers de packages, et d'abord dans le dossier `bst/` avant le `BSTINPUTS` du système pour trouver les fichiers de style bibliographique.

(Source : [https://tex.stackexchange.com/a/50847](https://tex.stackexchange.com/a/50847))

<Info>

Votre fichier de document principal et votre fichier `latexmkrc` doivent rester à la racine de votre projet, et non dans un dossier.

</Info>
