[TeX Live](https://www.tug.org/texlive/) est une distribution de logiciels libres publiée chaque année par le [TeX Users Group](https://www.tug.org/). Elle fournit les packages LaTeX, les polices, les moteurs TeX et de nombreux outils logiciels nécessaires à la composition typographique basée sur LaTeX sur tous les systèmes d'exploitation courants.

TeX Live est un composant important d'Overleaf, car nos serveurs l'utilisent pour compiler votre code LaTeX et générer l'aperçu PDF en temps réel. Elle offre également aux utilisateurs d'Overleaf un accès facile à plus de 5 000 packages LaTeX inclus dans chaque version de TeX Live.

Vous n'êtes pas obligé d'utiliser la dernière version de TeX Live pour compiler vos projets, car les serveurs d'Overleaf donnent accès aux versions antérieures de TeX Live. Les projets peuvent facilement être basculés vers une version plus ancienne de TeX Live — par exemple en raison de problèmes de compatibilité de packages.<br />
