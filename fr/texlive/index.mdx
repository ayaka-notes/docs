[TeX Live](https://www.tug.org/texlive/) est une distribution de logiciels libres publiée chaque année par le [TeX Users Group](https://www.tug.org/). Elle fournit les paquets LaTeX, les polices, les moteurs TeX et de nombreux outils logiciels nécessaires à la composition typographique avec LaTeX sur tous les systèmes d'exploitation courants.

TeX Live est un composant essentiel d'Overleaf, car nos serveurs l'utilisent pour compiler votre code LaTeX et générer l'aperçu PDF en temps réel. Il offre également aux utilisateurs d'Overleaf un accès facile à plus de 5 000 paquets LaTeX inclus dans chaque version de TeX Live.

Vous n'êtes pas obligé d'utiliser la dernière version de TeX Live pour compiler vos projets, car les serveurs d'Overleaf donnent accès aux versions précédentes de TeX Live. Les projets peuvent facilement être configurés pour utiliser une version antérieure de TeX Live, par exemple en raison de problèmes de compatibilité de paquets.<br />
