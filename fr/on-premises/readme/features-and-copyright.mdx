Nous respectons le droit d'auteur : nous listons donc ici toutes les fonctionnalités et le code utilisés dans ce projet. Cette page présente les nouvelles fonctionnalités d'Ayakaleaf Pro ainsi que les droits d'auteur du code associé.

Sauf indication contraire, nous utilisons Codex d'OpenAI pour la revue de code et la revue des PR. Ce processus nous a permis de corriger de nombreux problèmes de sécurité, et nous lui en sommes sincèrement reconnaissants. Pour plus de détails, voir [ayaka-notes/ayakaleaf-pro/pull](https://github.com/ayaka-notes/ayakaleaf-pro/pulls).

### Vue d'ensemble

Au fil des années, de nombreux développeurs de la communauté ont fourni des efforts considérables pour améliorer l'édition communautaire d'Overleaf. Les voici :

* [https://github.com/ertuil/overleaf](https://github.com/ertuil/overleaf)
* [https://github.com/AllanChain/lcpu-overleaf](https://github.com/AllanChain/lcpu-overleaf)
* [https://github.com/yu-i-i/overleaf-cep/](https://github.com/yu-i-i/overleaf-cep/)
* [https://github.com/ayaka-notes/overleaf](https://github.com/ayaka-notes/overleaf)
* [https://github.com/davrot/overleaf\_with\_admin\_extension](https://github.com/davrot/overleaf_with_admin_extension)
* [https://github.com/overleaf/overleaf/pull/1447](https://github.com/overleaf/overleaf/pull/1447) (intégration GitHub)
* [https://github.com/overleaf/overleaf/pull/1385](https://github.com/overleaf/overleaf/pull/1385) (prise en charge de Typst)

Nous avons pu utiliser du code issu de ces projets, et nous tenons à leur exprimer notre gratitude.

#### Fonctionnalité 01 : système de modèles

Cette fonctionnalité est principalement développée par [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep). Nous avons modifié une partie du code pour l'améliorer, afin que vous puissiez :

* Télécharger les modèles directement depuis les pages de modèles.
* Ouvrir le projet correspondant au modèle.
* Générer des images de couverture de meilleure qualité (et plus rapidement).

Cette fonctionnalité est développée par [ayaka-notes/overleaf-pro](https://github.com/ayaka-notes/overleaf-pro). Overleaf fournit un composant officiel appelé git-bridge, disponible [ici](https://github.com/overleaf/overleaf/tree/main/services/git-bridge).

Nous avons simplement implémenté un connecteur entre git-bridge et Overleaf, identique à ce qu'Overleaf fait sur sa plateforme SaaS.

#### Fonctionnalité 05 : panneau d'administration

<Warning>

Lorsque votre système compte 1000 utilisateurs ou projets, le panneau d'administration n'affiche que les 1000 utilisateurs ou projets les plus récents. Utilisez le panneau de recherche pour trouver des utilisateurs ou des projets précis.

</Warning>

Cette fonctionnalité est principalement développée par [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep). Nous avons modifié une partie du code pour l'améliorer, afin que vous puissiez :

* Rechercher des utilisateurs côté serveur lorsque vous en avez plus de 1000.
* Rechercher des projets côté serveur lorsque vous en avez plus de 1000.
* Ouvrir des projets directement depuis le panneau d'administration des projets.
* Consulter et ajuster la limite de durée de compilation d'un utilisateur dans le panneau d'administration.
* Réinitialiser le mot de passe d'un utilisateur directement depuis le panneau d'administration.
* Autres améliorations...

Nous utilisons GitHub Actions pour construire et publier des images Docker pour les architectures x86 et arm. Lorsque vous téléchargez l'image, l'architecture appropriée est automatiquement sélectionnée en fonction de votre système.

* ouvrir l'inscription à toute personne ayant accès à votre Overleaf

#### Fonctionnalité 11 : wiki Learn

Cette fonctionnalité est développée par [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro). Vous pouvez consulter la dernière version du wiki Learn d'Overleaf, mais nous ne détenons aucun droit d'auteur sur ces documents ! Nous les téléchargeons simplement depuis le serveur d'Overleaf la première fois que vous activez cette fonctionnalité, puis les mettons à jour périodiquement.

#### Fonctionnalité 16 : chat IA et assistant d'erreurs LaTeX

Ayakaleaf Pro intègre un assistant IA capable d'utiliser les documents de votre projet et la sélection en cours comme contexte pour répondre à vos questions et proposer des modifications que vous pouvez relire, tandis que l'assistant d'erreurs propose un correctif ciblé lorsque vous sélectionnez une erreur de compilation LaTeX.
