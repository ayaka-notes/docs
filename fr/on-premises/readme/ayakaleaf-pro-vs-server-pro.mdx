title: Overleaf Server Pro vs Ayakaleaf Pro
description: Overleaf Server Pro et Ayakaleaf Pro Edition sont toutes deux des versions sur site d'Overleaf. Mais quelles sont les différences ?

<Info>

Ayakaleaf Pro est une implémentation améliorée d'Overleaf Community Edition, offrant gratuitement toutes les fonctionnalités _**premium**_ de Server Pro. Contrairement à Overleaf Common, disponible sur [https://www.overleaf.com/](https://www.overleaf.com/), nous n'imposons aucune limite de temps de compilation ni aucune licence selon le nombre d'utilisateurs, et vous pouvez héberger entièrement vos propres données, pour une sécurité absolue.

Overleaf Server Pro est un déploiement commercial et auto-hébergé d'Overleaf, avec support officiel. Pour plus d'informations sur Server Pro, consultez [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud).

</Info>

<Warning>

Overleaf Community Edition est destinée aux environnements dans lesquels **tous** les utilisateurs sont dignes de confiance. Community Edition n'est **pas** adaptée aux scénarios nécessitant l'isolation des utilisateurs, car les compilations en sandbox (Sandbox Compiles) n'y sont pas disponibles.

Sans sandbox, les compilations LaTeX s'exécutent avec les mêmes privilèges que le conteneur, ce qui donne accès à son système de fichiers, à son réseau et à ses variables d'environnement. Cela crée un risque d'exposition des données ou de compromission du système. Les compilations hors sandbox ne doivent être utilisées que dans des environnements entièrement dignes de confiance ; pour les déploiements multi-utilisateurs ou de production, les compilations en sandbox sont fortement recommandées.

Pour plus d'informations sur les compilations en sandbox, consultez notre [documentation](/fr/on-premises/configuration/overleaf-toolkit/sandboxed-compiles).

</Warning>

### Support communautaire

Pour les personnes utilisant une instance Overleaf auto-hébergée, le support est assuré par la communauté via les [Issues](https://github.com/ayaka-notes/ayakaleaf-pro/issues) GitHub.

Pour rester sur une version prise en charge, vous pouvez vérifier quelle version d'Overleaf vous exécutez en comparant la sortie de la commande ci-dessous avec les identifiants d'image (Image ID) publiés dans les notes de version.

```bash
docker inspect --format '{{.Image}}' sharelatex | awk -F: '{print substr($2, 1, 12)}'
```
