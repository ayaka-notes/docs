<Info>

Ayakaleaf Pro est une implémentation améliorée d'Overleaf Community Edition, qui offre toutes les fonctionnalités premium de Server Pro _**gratuitement**_. Contrairement à Overleaf Common, disponible sur [https://www.overleaf.com/](https://www.overleaf.com/), nous n'imposons aucune limite de temps de compilation ni aucune licence liée au nombre d'utilisateurs, et vous pouvez héberger entièrement vos propres données, pour une sécurité absolue.

Overleaf Server Pro est un déploiement auto-hébergé commercial d'Overleaf, avec un support officiel. Pour plus d'informations sur Server Pro, consultez [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud).

</Info>

<Warning>

Overleaf Community Edition est destinée aux environnements dans lesquels **tous** les utilisateurs sont de confiance. Community Edition **n'est pas** adaptée aux scénarios qui exigent l'isolation des utilisateurs, car les Sandbox Compiles n'y sont pas disponibles.

Sans sandbox, les compilations LaTeX s'exécutent avec les mêmes privilèges que le conteneur, ce qui donne accès à son système de fichiers, à son réseau et à ses variables d'environnement. Cela crée un risque d'exposition des données ou de compromission du système. Les compilations hors sandbox ne doivent être utilisées que dans des environnements entièrement de confiance ; pour les déploiements multi-utilisateurs ou de production, les Sandbox Compiles sont fortement recommandées.

Pour plus d'informations sur les Sandbox Compiles, consultez notre [documentation](/fr/on-premises/configuration/overleaf-toolkit/sandboxed-compiles).

</Warning>

### Support communautaire

Pour les personnes qui utilisent une instance Overleaf auto-hébergée, le support est assuré par la communauté via les [Issues](https://github.com/ayaka-notes/overleaf-pro/issues) GitHub.

Pour rester sur une version prise en charge, vous pouvez vérifier quelle version d'Overleaf vous exécutez en comparant la sortie de la commande ci-dessous avec les Image ID publiés dans les notes de version.

```bash
docker inspect --format '{{.Image}}' sharelatex | awk -F: '{print substr($2, 1, 12)}'
```
