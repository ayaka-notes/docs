Nous avons rassemblé ici les réponses à quelques questions fréquentes sur Ayakaleaf Pro.

### Questions de base

<Accordion title="Q01 : Ayakaleaf Pro est-il une version d'essai gratuite ? Nécessite-t-il une licence ?">

Non. Ayakaleaf Pro est entièrement gratuit. Il ne s'agit pas d'une version d'essai et aucune licence n'est requise.

</Accordion>

<Accordion title="Q02 : Ayakaleaf Pro inclut-il toutes les fonctionnalités d'Overleaf Server Pro ?">

Oui. Ayakaleaf Pro inclut toutes les fonctionnalités d'Overleaf Server Pro, y compris l'intégration Git-Bridge. Il inclut également une sélection de fonctionnalités de la plateforme SaaS d'Overleaf. Nous continuons à développer et à améliorer Ayakaleaf Pro.

</Accordion>

<Accordion title="Q03 : Combien coûte Overleaf Server Pro ?">

Overleaf Server Pro coûte environ 300 \$ par utilisateur et par an. Il nécessite au moins 10 licences, si bien que les déploiements commencent à environ 3 000 \$ par an. Des contrats publics américains de plus petite taille font état de coûts annuels d'environ 320 à 370 \$ par utilisateur. Server Pro est donc onéreux, en particulier pour les petites équipes. Consultez [#information-and-price-about-overleaf-server-pro](/fr/on-premises#information-and-price-about-overleaf-server-pro  "mention") pour des achats et tarifs documentés.

</Accordion>

<Accordion title="Q04 : Pourquoi Overleaf Server Pro n'inclut-il pas la synchronisation GitHub ni les fonctionnalités d'IA ?">

Overleaf Server Pro est couramment utilisé par des organismes publics. Ils le déploient sur des réseaux privés et en contrôlent strictement l'accès. Pour protéger les données sensibles, ses fonctionnalités évitent tout échange de données avec des services tiers. Si vous avez besoin de la synchronisation GitHub, de l'IA ou de fonctionnalités connectées similaires, Overleaf recommande un abonnement à sa plateforme SaaS.

</Accordion>

<Accordion title="Q05 : Ayakaleaf Pro est-il sûr et fiable ?">

Ayakaleaf Pro est open source. Nous examinons le code avec des outils tels que Codex Security afin de renforcer sa sécurité et sa fiabilité. Si vous n'activez pas la synchronisation de données avec des tiers, vos données restent sur votre serveur. Ayakaleaf Pro ne contient aucune télémétrie envoyant vos données ailleurs.

</Accordion>

<Accordion title="Q06 : Ayakaleaf Pro sera-t-il maintenu sur le long terme ?">

Nous ferons tout notre possible pour maintenir ce projet sur le long terme.

</Accordion>

<Accordion title="Q07 : Ayakaleaf Pro est-il conforme ?">

Ayakaleaf Pro est un fork communautaire. Son code et ses fonctionnalités intégrées proviennent de contributions de la communauté. Il est distribué sous licence AGPL v3. Les déploiements peuvent être conformes à cette licence dès lors qu'ils en respectent les exigences.

</Accordion>

<Accordion title="Q08 : Pourquoi le projet s'appelle-t-il Ayakaleaf Pro ?">

Le projet s'appelait à l'origine Overleaf Pro, en 2024. Son développement a été interrompu pendant un temps, puis a repris fin 2025. Au premier trimestre 2026, Overleaf a renommé Pro son offre d'abonnement intégrant l'IA. Des retours de la communauté ont également souligné que le nom Overleaf Pro pouvait créer des risques en matière de marque et d'usurpation d'identité, en laissant penser aux utilisateurs que le projet était officiel.

Nous avons renommé le projet Ayakaleaf Pro pour éviter cette confusion. Le nom peut se lire « Ayaka-notes Overleaf Pro ». Le mainteneur contribue au développement communautaire d'Overleaf depuis ses années d'études, il y a plus de cinq ans. Cette expérience appuie notre engagement de maintenance sur le long terme.

</Accordion>

<Accordion title="Q09 : Qu'est-ce qui distingue Ayakaleaf Pro des nouveaux éditeurs LaTeX conçus avec l'IA ?">

Depuis 2026, la communauté open source a publié de nombreux éditeurs LaTeX conçus avec l'IA, dont OpenAI Prism. Ayakaleaf Pro conserve vos données et vos services sur votre propre serveur, ce qui vous donne un contrôle direct sur votre déploiement et vos données.

De nombreux éditeurs communautaires expérimentaux n'ont pas de plan de maintenance à long terme établi. Les plateformes tierces de compilation LaTeX peuvent également cesser leur activité lorsque leur base d'utilisateurs ou leurs revenus sont insuffisants. Ayakaleaf Pro fournit l'intégralité du code source et vous permet d'auto-héberger chaque service. Même si la maintenance s'arrêtait, votre service auto-hébergé existant pourrait continuer à fonctionner.

</Accordion>

### LaTeX

<Accordion title="Q01 : Les compilations des projets LaTeX des utilisateurs sont-elles isolées ? Shell Escape est-il activé ?">

Lorsque vous activez les compilations en sandbox (Sandbox Compiles), la compilation de chaque utilisateur s'exécute dans un conteneur Docker distinct et est isolée des compilations des autres utilisateurs. Shell Escape est activé par défaut pour les compilations en sandbox.

</Accordion>

<Accordion title="Q02 : L'image des compilations en sandbox est-elle fiable ? La compilation peut-elle échouer ?">

Nous avons amélioré notre image TeX Live Full pour les compilations en sandbox au cours des trois dernières années. Dans la plupart des cas, les projets qui compilent sur overleaf.com compilent également correctement avec Ayakaleaf Pro. Si une police requise n'est pas disponible, téléversez-la manuellement dans votre projet.

</Accordion>
