### Comprendre les numéros de version d'Overleaf

Overleaf utilise des numéros de version de type sémantique, sous la forme **6.X.y**.

* **6.X** représente la série de versions majeures. Lorsqu'une nouvelle version **6.X.0** est publiée, elle devient la référence de cette génération.
* **y** représente les mises à jour correctives au sein d'une même série majeure. Les versions suivantes (par exemple **6.X.1**, **6.X.2**, …) sont généralement des mises à jour de maintenance construites sur **6.X.0**, contenant des corrections de bugs, des correctifs de sécurité et de petites améliorations plutôt que des évolutions fonctionnelles majeures.

### Version d'Ayakaleaf Pro

Les numéros de version d'Ayakaleaf Pro sont **entièrement alignés** sur les versions officielles d'Overleaf. Sauf indication contraire, toutes les versions publiées sont des images de l'édition Pro complète.

Nous alignons strictement nos versions sur l'édition communautaire d'Overleaf. Cela vous permet d'utiliser les plugins Overleaf open source. Nous ne modifions pas les interfaces centrales d'Overleaf. Par conséquent, tout plugin compatible avec la version `A.X.y` de l'édition communautaire est entièrement compatible avec Ayakaleaf Pro `A.X.y`.
