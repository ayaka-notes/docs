## Importer un document {#import-a-document}

Cette opération crée un nouveau projet LaTeX à partir d'un document Word (`.docx`) ou d'un fichier Markdown (`.md`). Le nom du projet provient du nom du fichier.

<Steps>
<Step title="Ouvrir la boîte de dialogue d'import">
Sur la page des projets, cliquez sur **New project**. Sous **Import**, cliquez sur **Word document** ou **Markdown document**.

<Frame caption="Le menu New project">
  <img src="/images/on-premises/word-import-menu.png" alt="Le menu New project avec Word document et Markdown document sous Import" />
</Frame>
</Step>

<Step title="Choisir le fichier">
Cliquez sur **Select .docx file**, ou faites glisser le fichier dans la boîte de dialogue. Pour Markdown, le bouton est **Select .md file**. L'import démarre immédiatement.

<Frame caption="Choix d'un document Word">
  <img src="/images/on-premises/word-import-dialog.png" alt="La boîte de dialogue Choose Word document avec le bouton Select .docx file" />
</Frame>
</Step>

<Step title="Commencer à modifier">
Le nouveau projet s'ouvre avec le message **Document ready for editing**. Cliquez sur **Start editing**.

<Frame caption="L'import est terminé">
  <img src="/images/on-premises/word-import-ready.png" alt="La boîte de dialogue Document ready for editing avec le bouton Start editing" />
</Frame>
</Step>

<Step title="Vérifier le résultat">
Le document se trouve maintenant dans `main.tex`, avec ses titres dans le plan du fichier. Cliquez sur **Recompile** pour voir le PDF. Vérifiez la mise en forme, en particulier les tableaux, les figures et les citations, qui peuvent nécessiter des retouches.

<Frame caption="Le projet importé">
  <img src="/images/on-premises/word-import-project.png" alt="Le projet importé dans l'éditeur, avec main.tex, le plan du fichier et le PDF compilé" />
</Frame>
</Step>
</Steps>

### Si l'import échoue {#if-the-import-fails}

Si le fichier ne peut pas être converti, la boîte de dialogue affiche **Your document couldn't be imported**. Développez **Conversion error details** pour voir pourquoi. Aucun projet n'est créé.

<Frame caption="Un document qui n'a pas pu être importé">
  <img src="/images/on-premises/word-import-error.png" alt="La boîte de dialogue d'import avec un message d'erreur et Conversion error details" />
</Frame>

La boîte de dialogue n'accepte que le type choisi. Un fichier `.md` dans la boîte de dialogue Word affiche **You can only upload: .docx**.

## Exporter un projet {#export-a-project}

Ouvrez le projet, puis cliquez sur son nom en haut de l'éditeur. Cliquez sur l'une de ces options :

| Option                              | Vous obtenez                                       |
| ----------------------------------- | --------------------------------------------- |
| <strong>Export as Word document (.docx)</strong> | Un fichier `.docx` portant le nom du projet        |
| <strong>Export as Markdown (.md)</strong>        | Un fichier `.zip` contenant `main.md`                  |
| <strong>Export as HTML (.html)</strong>          | Un fichier `.zip` contenant `main.html`                |

Le téléchargement démarre automatiquement. La conversion ne peut pas reproduire toute la mise en forme LaTeX, vérifiez donc le résultat.
