## Trouver un projet {#find-a-project}

Saisissez du texte dans **Search by project name, ID, owner or link**. Un lien peut être l'adresse du projet ou l'un de ses liens de partage. Utilisez le filtre **Status** pour affiner la liste. Cliquez sur **Title** ou **Last modified** pour trier.

Les projets supprimés n'apparaissent pas dans les résultats. Si votre recherche correspond aussi à un projet supprimé, une ligne au-dessus du tableau l'indique, par exemple **Found 1 matching deleted projects**. Cliquez sur **Display deleted projects** pour les voir.

## Statut d'un projet {#project-status}

Chaque projet a un statut, et le filtre **Status** indique combien de projets ont chaque statut.

<Frame caption="Le filtre Status">
  <img src="/images/on-premises/project-management-status-filter.png" alt="Le filtre Status avec All, Active, Archived, Trashed et Deleted" />
</Frame>

| Statut | Signification |
| --- | --- |
| **All** | Tous les projets qui ne sont pas supprimés. |
| **Active** | L'état normal. |
| **Archived** | Le propriétaire l'a archivé. Le projet est intact et peut être récupéré. |
| **Trashed** | Le propriétaire l'a mis à la corbeille. Le projet est intact et peut être récupéré. |
| **Deleted** | Supprimé par le propriétaire depuis la corbeille, par un administrateur, ou avec le compte du propriétaire. Seul un administrateur peut le récupérer. |

Un projet passe par les statuts par étapes :

1. **Active, Archived et Trashed** sont choisis par le propriétaire sur sa propre page de projets. Le propriétaire peut toujours revenir en arrière. **Restore** depuis la corbeille ramène toujours à Active, même si le projet était archivé auparavant.
2. **Deleted** est l'étape suivante. Le propriétaire ne peut supprimer que depuis la corbeille ; un administrateur peut supprimer depuis n'importe lequel des trois.
3. **Restore** ramène un projet supprimé en **Active**, quel que soit son statut précédent, et son nom reçoit `(Restored)` à la fin. Seul un administrateur peut le faire. Si le compte du propriétaire est lui aussi supprimé, restaurez d'abord le compte : sinon la boîte de dialogue indique **The owner of this project is deleted: restore the owner first**.
4. **Delete permanently** est la dernière étape et ne peut pas être annulée. Sinon, les projets supprimés restent jusqu'à ce que vous les retiriez, sauf si l'instance définit [`ENABLE_CRON_RESOURCE_DELETION`](/fr/on-premises/configuration/overleaf-toolkit/environment-variables), qui les retire après 90 jours.

<Info>

Le statut suit uniquement le propriétaire. Lorsqu'un collaborateur archive un projet partagé ou le met à la corbeille, le projet ne se déplace que sur sa propre page de projets, et le statut ici reste inchangé.

</Info>

## Actions sur un projet {#actions-on-a-project}

| Icône | Action | Effet |
| --- | --- | --- |
| Ouvrir | **Open Project** | Ouvre le projet dans l'éditeur, dans un nouvel onglet. |
| Dossier | **Change project owner** | Donne le projet à un autre utilisateur. |
| Corbeille | **Delete** | Déplace le projet vers **Deleted**. |
| Flèche | **Restore** | Récupère un projet supprimé. Uniquement pour les projets supprimés. |
| Corbeille barrée | **Delete permanently** | Retire définitivement un projet supprimé. Uniquement pour les projets supprimés. |

### Changer le propriétaire {#change-the-owner}

Cliquez sur l'icône de dossier, saisissez un nom ou une adresse e-mail, choisissez l'utilisateur, puis cliquez sur **Change project owner**. La boîte de dialogue avertit que cette action est irréversible et que le nouveau propriétaire sera averti et pourra modifier les paramètres d'accès du projet. Les comptes désactivés ne sont pas proposés. Si vous modifiez le texte après avoir choisi, le choix est annulé : choisissez à nouveau l'utilisateur.

<Frame caption="Changer le propriétaire d'un projet">
  <img src="/images/on-premises/project-management-change-owner.png" alt="La boîte de dialogue Change project owner avec un avertissement et un nouveau propriétaire choisi" />

Pour déplacer tous les projets d'un utilisateur en une fois, consultez [Transférer les projets d'un utilisateur](/fr/on-premises/user-guide/administrators/user-management#transfer-a-users-projects).

### Supprimer, restaurer ou supprimer définitivement {#delete-restore-or-permanently-delete}

Cliquez sur l'icône de corbeille, puis sur **Delete**. Pour retrouver le projet, choisissez **Deleted** dans le filtre **Status**.

<Frame caption="Un projet supprimé">
  <img src="/images/on-premises/project-management-deleted.png" alt="Un projet supprimé dans la liste avec les icônes Restore et Delete permanently" />
</Frame>

Cliquez sur l'icône de flèche, puis sur **Restore**, pour le récupérer, ou sur la corbeille barrée, puis sur **Delete permanently**, pour le retirer.

<Frame caption="Supprimer définitivement un projet">
  <img src="/images/on-premises/project-management-purge.png" alt="La boîte de dialogue Delete permanently avertissant que l'action est irréversible" />
</Frame>

### Modifier plusieurs projets à la fois {#change-several-projects-at-once}

Cochez les projets dans la liste. Des boutons apparaissent à côté de la recherche : **Download**, **Change project owner** et **Delete**. **Download** enregistre les projets sélectionnés dans un seul fichier `.zip`. Avec **Change project owner**, les propriétaires actuels des projets cochés ne peuvent pas être choisis. Dans la vue **Deleted**, les boutons sont **Restore** et **Delete permanently**.

<Frame caption="Actions groupées">
  <img src="/images/on-premises/project-management-bulk.png" alt="Deux projets cochés et les boutons Download, Change project owner et Delete" />
</Frame>

## La page du projet {#the-project-page}

Cliquez sur le titre d'un projet pour ouvrir sa page. En haut se trouvent les icônes pour modifier, ouvrir, télécharger et supprimer le projet. Elle comporte cinq onglets.

### Vue d'ensemble {#overview}

Les détails et paramètres du projet. Cliquez sur l'icône de crayon pour modifier **Name**, **Link sharing**, **Compiler**, **TeX Live version** et **Main document**, ou pour cliquer sur **Change project owner**. Cliquez ensuite sur **Save**.

<Frame caption="Modifier un projet">
  <img src="/images/on-premises/project-management-edit.png" alt="L'onglet Overview en mode édition" />
</Frame>

### Arborescence des fichiers {#file-tree}

Les fichiers et dossiers du projet, en lecture seule.

<Frame caption="Les fichiers d'un projet">
  <img src="/images/on-premises/project-management-files.png" alt="L'onglet File tree listant frog.jpg, main.tex et un fichier bib restauré" />
</Frame>

### Membres {#members}

Qui a accès : le propriétaire, les collaborateurs et les invitations en attente. Cliquez sur l'icône de crayon pour les modifier :

* Choisissez **Editor**, **Reviewer** ou **Viewer** pour un collaborateur. La modification s'applique immédiatement.
* Cliquez sur la corbeille à côté d'un collaborateur, puis sur **Remove access**.
* Pour une invitation en attente, cliquez sur l'enveloppe pour **Resend invite**, ou sur la corbeille pour **Revoke Invite**.

Cliquez sur **Done** quand vous avez terminé. Le propriétaire ne peut pas être changé ici : utilisez **Change project owner** dans l'onglet **Overview**.

<Frame caption="Modifier les membres d'un projet">
  <img src="/images/on-premises/project-management-members.png" alt="L'onglet Members en mode édition avec un menu de rôle, une invitation en attente et les icônes d'action" />
</Frame>

### Fichiers supprimés {#deleted-files}

Les fichiers retirés du projet. Cliquez sur l'icône de flèche à côté d'un fichier, puis sur **Restore file**. Une copie portant la date dans son nom est placée dans le dossier racine du projet, et la ligne affiche son nom. Le fichier supprimé reste dans la liste.

La copie apparaît dans l'onglet **File tree** après le rechargement de la page.

Ce qui est arrivé à ce projet : la date, l'opération, qui l'a effectuée, l'adresse IP et les détails. Faites une recherche ou filtrez par **Operation**.
