---
title: 4. Personnaliser votre instance
description: Placez vos paramètres dans le ConfigMap qui remplace config/variables.env.
icon: square-sliders
---

Le ConfigMap `overleaf-env` remplace le fichier `config/variables.env` du Toolkit : chaque variable d'environnement de la [documentation du Toolkit](/fr/on-premises/configuration/overleaf-toolkit/environment-variables) se place ici, et les secrets vont dans le Secret de l'[étape 2](/fr/on-premises/installation/using-kubernetes/2.-create-the-namespace-and-secrets).

```yaml title="30-config.yaml" wrap
apiVersion: v1
kind: ConfigMap
metadata:
  name: overleaf-env
  namespace: overleaf
data:
  OVERLEAF_APP_NAME: Ayakaleaf Pro
  OVERLEAF_SITE_URL: http://192.0.2.10:30080      # the address users open; https://... behind TLS
  OVERLEAF_ADMIN_EMAIL: admin@example.com
  # Emails: add the sender and the SMTP server together, see Email delivery
  # All members, so that the driver finds the primary even when mongo-0 is down
  OVERLEAF_MONGO_URL: mongodb://mongo-0.mongo:27017,mongo-1.mongo:27017,mongo-2.mongo:27017/sharelatex?replicaSet=overleaf
  OVERLEAF_REDIS_HOST: redis
  REDIS_HOST: redis
  ENABLED_LINKED_FILE_TYPES: project_file,project_output_file,url
  ENABLE_CONVERSIONS: "true"
  EMAIL_CONFIRMATION_DISABLED: "true"
  # Requests arrive from kube-proxy or your ingress controller, inside the pod network
  OVERLEAF_TRUSTED_PROXY_IPS: loopback,10.244.0.0/16
  # Sandboxed compiles. The HOST_DIR paths are paths ON THE NODE: the hostPath volumes that
  # the Deployment mounts at /var/lib/overleaf/data/{compiles,output,cache}.
  SANDBOXED_COMPILES: "true"
  SANDBOXED_COMPILES_SIBLING_CONTAINERS: "true"
  DOCKER_RUNNER: "true"
  SANDBOXED_COMPILES_HOST_DIR_COMPILES: /srv/overleaf/compiles
  SANDBOXED_COMPILES_HOST_DIR_OUTPUT: /srv/overleaf/output
  SANDBOXED_COMPILES_HOST_DIR_CACHE: /srv/overleaf/cache
  # Each image must be pulled into Docker on every node that can run Ayakaleaf Pro (step 0)
  ALL_TEX_LIVE_DOCKER_IMAGES: ghcr.io/ayaka-notes/texlive-full:2026.1
  ALL_TEX_LIVE_DOCKER_IMAGE_NAMES: TeX Live 2026
  TEX_LIVE_DOCKER_IMAGE: ghcr.io/ayaka-notes/texlive-full:2026.1
```

```bash
kubectl apply -f 30-config.yaml
```

| Variable                                | Valeur à définir                                                                                                                                                |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_SITE_URL`                     | L'URL que les utilisateurs saisissent dans le navigateur. Avec le NodePort de l'[étape 5](/fr/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro), l'IP de n'importe quel nœud et le port `30080` ; derrière un ingress ou un équilibreur de charge, son URL. |
| `OVERLEAF_MONGO_URL`                    | Votre replica set. Utilisez `?replicaSet=` avec le nom indiqué dans `rs.initiate`.                                                                              |
| `OVERLEAF_REDIS_HOST` et `REDIS_HOST`   | Les deux, vers le Service Redis.                                                                                                                                |
| `OVERLEAF_TRUSTED_PROXY_IPS`            | `loopback` plus les réseaux depuis lesquels vos proxys se connectent. `10.244.0.0/16` est le réseau de pods de flannel ; utilisez le CIDR de pods de votre cluster. |
| `SANDBOXED_COMPILES_HOST_DIR_*`         | Les chemins sur le nœud des volumes de compilation. Ils doivent correspondre aux volumes `hostPath` de l'[étape 5](/fr/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro). |

Derrière HTTPS, définissez également `OVERLEAF_SECURE_COOKIE: "true"`, voir [Proxy TLS](/fr/on-premises/configuration/overleaf-toolkit/tls-proxy).

<Info>

Un ConfigMap modifié n'atteint les pods en cours d'exécution qu'après un redémarrage : `kubectl -n overleaf rollout restart deployment/overleaf`.

</Info>
