Le moyen le plus simple de tester Ayakaleaf Pro est d'utiliser GitHub Codespace, où toutes les variables d'environnement sont préconfigurées pour que vous puissiez l'utiliser immédiatement.

<Warning>

Lorsque vous exécutez des conteneurs Docker avec GitHub Codespaces, le Codespace ne s'arrête pas automatiquement et continue d'être **facturé**. Pour les règles de facturation de GitHub Codespaces, consultez les [règles de facturation de GitHub Codespaces](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces).

Pour gérer vos GitHub Codespaces, rendez-vous sur [https://github.com/codespaces](https://github.com/codespaces). Lorsque vous n'en avez plus besoin, pensez à supprimer votre Codespace rapidement.

</Warning>

Nous avons **préconfiguré** les fonctionnalités suivantes :

* [x] Compilation LaTeX en sandbox avec TeX Live **Basic** (2024-2026)
* [x] Import/export Pandoc (fonctionnalité de la plateforme SaaS)
* [x] Exécution de scripts Python (fonctionnalité de la plateforme SaaS)
* [x] Prise en charge de Git-Bridge (fonctionnalité de Server Pro)
* [x] Recherche avancée de références (fonctionnalité de la plateforme SaaS)
* [x] Panneau d'administration (gestion globale des utilisateurs et des projets)
* [x] Suivi des modifications (avec panneau de relecture et de commentaires)
* [x] Historique complet du projet (avec restauration et téléchargement)
* [x] Palette de symboles (fonctionnalité de Server Pro/de la plateforme SaaS)

<Warning>

Les GitHub Codespaces standard offrent 32 Go de stockage, ce qui est insuffisant pour notre installation `texlive-full`. Pour tester l'image complète, ouvrez un ticket auprès du support GitHub afin d'obtenir un Codespace avec de grands runners (8 cœurs ou plus).

</Warning>

La synchronisation GitHub, LDAP, OAuth, le SSO, l'intégration Zotero et d'autres fonctionnalités ne sont _**pas configurés**_ dans cet environnement de test. Consultez les [paramètres du Toolkit](/fr/on-premises/configuration/overleaf-toolkit/toolkit-settings) pour savoir comment configurer ces fonctionnalités dans votre propre déploiement.

#### Utiliser l'image TeX Live Full

Si vous avez accès à des GitHub Codespaces à 8 cœurs/64 Go, vous pouvez utiliser l'image TeX Live Full dans cet environnement de test. Modifiez les variables d'environnement suivantes dans le fichier `toolkit/config/variables.env` pour utiliser l'image TeX Live Full au lieu de l'image TeX Live Basic.

```dotenv wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1, ghcr.io/ayaka-notes/texlive-full:2024.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025, Texlive 2024
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```

Après avoir modifié les variables d'environnement, vous devez redémarrer le Toolkit pour appliquer les changements. Exécutez la commande suivante pour redémarrer le Toolkit.

```bash
cd toolkit && bin/up -d
```
