Overleaf fonctionne sur Docker. Vous devez installer :

* Docker Engine (Docker CE)
* Le plugin Docker Compose (`docker compose`, v2)

Ces étapes s'appliquent à une version LTS récente d'Ubuntu (20.04/22.04/24.04).

<Warning>

Évitez d'installer `docker.io` depuis le dépôt apt par défaut d'Ubuntu.\
Utilisez le dépôt officiel de Docker afin d'obtenir une version récente de Docker ainsi que le plugin `docker compose`.

</Warning>

La documentation officielle se trouve ici : [https://docs.docker.com/engine/install/ubuntu/](https://docs.docker.com/engine/install/ubuntu/).

<Steps>
<Step title="1) Supprimer les paquets anciens ou en conflit (le cas échéant)">
Si Docker a été installé précédemment depuis une autre source, supprimez-le d'abord :

```bash wrap
sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-compose-v2 docker-doc podman-docker containerd runc | cut -f1)
```

Cette commande est sans danger même si certains paquets ne sont pas installés.
</Step>

<Step title="2) Ajouter le dépôt apt officiel de Docker">
Installez les prérequis :

```bash
sudo apt update
sudo apt install -y ca-certificates curl
```

Ajoutez la clé GPG de Docker :

```bash wrap
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```

Ajoutez le dépôt :

```bash wrap
# Add the repository to Apt sources:
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Signed-By: /etc/apt/keyrings/docker.asc
EOF

sudo apt update
```
</Step>

<Step title="3) Installer Docker Engine et le plugin Compose">
Installez Docker et le plugin Compose :

```bash wrap
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

Lancez Docker au démarrage :

```bash
sudo systemctl enable --now docker
```
</Step>

<Step title="4) Vérifier l'installation">
Ces commandes doivent s'exécuter sans erreur :

```bash
docker --version
docker compose version
sudo docker run --rm hello-world
docker ps
```
</Step>

<Step title="5) (Facultatif) Exécuter Docker sans sudo">
Ajoutez votre utilisateur au groupe `docker` :

```bash
sudo usermod -aG docker $USER
```

Puis **déconnectez-vous et reconnectez-vous**, ou exécutez :

```bash
newgrp docker
```

La commande suivante devrait alors fonctionner sans `sudo` :

```bash
docker ps
```

<Danger>

Le groupe `docker` dispose d'un accès équivalent à root sur l'hôte.\
C'est normal pour les installations Overleaf classiques, et particulièrement pertinent si vous activez les Sandboxed Compiles.

</Danger>
</Step>
</Steps>

### Étape suivante

Une fois Docker fonctionnel, poursuivez avec les étapes d'installation du Toolkit dans [Utiliser le Toolkit](/fr/on-premises/installation/using-the-toolkit).
