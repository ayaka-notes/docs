### Créer votre premier compte administrateur {#create-your-first-administrator-account}

Ouvrez [http://localhost:8080/launchpad](http://localhost:8080/launchpad), ou votre `OVERLEAF_SITE_URL` suivie de `/launchpad`, et enregistrez le compte administrateur. À partir de là, tout fonctionne comme avec Docker : suivez [6. Tâches post-installation](/fr/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks) du guide Docker, en utilisant le port `8080` dans ses liens `localhost`.

Créez le projet d'exemple et compilez-le. Le PDF montre que les compilations s'exécutent dans leurs conteneurs TeX Live via Podman. Pour voir le conteneur de compilation :

```bash title="List the compile containers"
podman ps -a --filter name=project- --format "{{.Names}} {{.Image}} {{.Status}}"
```

### Utiliser HTTPS {#use-https}

Le [proxy TLS](/fr/on-premises/configuration/overleaf-toolkit/tls-proxy) du Toolkit fonctionne sur Podman : exécutez `bin/init --tls`, puis définissez votre certificat et `NGINX_ENABLED=true` comme décrit sur cette page. Il écoute sur les ports `80` et `443`, que Podman rootless ne peut pas utiliser par défaut. Autorisez les utilisateurs non privilégiés à utiliser les ports à partir de `80` :

```bash title="Allow ports 80 and 443"
echo "net.ipv4.ip_unprivileged_port_start=80" | sudo tee /etc/sysctl.d/99-unprivileged-ports.conf
sudo sysctl --system
```

Cela permet à tous les utilisateurs du serveur d'écouter sur ces ports ; ne le faites donc que sur un serveur dédié à Ayakaleaf Pro. Ouvrez-les ensuite dans le pare-feu :

```bash title="Open ports 80 and 443"
sudo firewall-cmd --permanent --add-port=80/tcp --add-port=443/tcp
sudo firewall-cmd --reload
```

Définissez `OVERLEAF_SITE_URL` sur votre adresse `https://` et exécutez `bin/up -d`. Conservez les valeurs par défaut `NGINX_HTTP_PORT=80` et `TLS_PORT=443` : avec d'autres ports, la redirection de HTTP vers HTTPS mène au mauvais port.

<Info>

Laissez `OVERLEAF_LISTEN_IP` sur `127.0.0.1` lorsque vous utilisez le proxy TLS, afin que le port `8080` ne soit pas accessible depuis d'autres ordinateurs.

</Info>

### Mettre à niveau {#upgrade}

Mettez à niveau avec `bin/upgrade`, comme décrit dans [Mettre à niveau votre déploiement](/fr/on-premises/maintenance/upgrading-your-deployment). Sur Podman, il extrait aussi le profil seccomp de la nouvelle version dans `config/seccomp/<version>/` et met à jour `SECCOMP_PROFILE` :

```text
Over-writing config/version with 6.3.4
Set SECCOMP_PROFILE=/home/<user>/overleaf-toolkit/config/seccomp/6.3.4/clsi-profile.json in config/variables.env
```

Après une mise à niveau, exécutez `bin/podman-setup` pour vérifier la configuration.

### Changer le mode SELinux {#change-the-selinux-mode}

`SELINUX_MODE` dans `config/overleaf.rc` définit la façon dont SELinux confine le conteneur `sharelatex`. `managed` est le mode que ces pages configurent ; les autres modes sont décrits dans [Paramètres du Toolkit](/fr/on-premises/configuration/overleaf-toolkit/toolkit-settings). Exécutez `bin/up -d` après l'avoir modifié.
