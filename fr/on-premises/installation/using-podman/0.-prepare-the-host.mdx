---
title: 0. Préparer l'hôte
description: Vérifiez le système d'exploitation et SELinux, et installez git, avant de configurer Podman rootless.
icon: server
---

Vous n'installez pas Podman à la main : [2. Exécuter podman-setup](/fr/on-premises/installation/using-podman/2.-run-podman-setup) l'installe avec les autres paquets nécessaires. Ici, vous vérifiez seulement l'hôte et installez `git`, dont vous avez besoin pour télécharger le Toolkit.

<Steps>
<Step title="Vérifier le système d'exploitation et SELinux">
Connectez-vous avec l'utilisateur qui exécutera Ayakaleaf Pro, et non en tant que `root`, puis vérifiez la distribution et le mode SELinux :

```bash title="Check the host"
grep PRETTY_NAME /etc/os-release
getenforce
```

Vous devriez voir RHEL, Rocky Linux, AlmaLinux ou CentOS Stream en version 9 ou ultérieure, ainsi que `Enforcing` :

```text
PRETTY_NAME="Rocky Linux 9.9 (Blue Onyx)"
Enforcing
```
</Step>

<Step title="Vérifier que vous pouvez utiliser sudo">
`bin/podman-setup --apply` installe des paquets et charge un module SELinux avec `sudo`, et vous demande votre mot de passe lorsqu'il en a besoin :

```bash title="Check sudo"
sudo -v
```

Si cela échoue, demandez à votre administrateur d'ajouter votre utilisateur au groupe `wheel`.
</Step>

<Step title="Installer git">
```bash title="Install git"
sudo dnf install -y git
```

<Warning>

N'installez pas Docker Engine sur cet hôte. Le paquet `podman-docker`, que `bin/podman-setup` installe, fournit la commande `docker`, et le Toolkit considère l'hôte comme un hôte Podman dès que la commande `podman` existe.

</Warning>
</Step>
</Steps>
