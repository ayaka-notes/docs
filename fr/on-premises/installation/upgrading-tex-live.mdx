title: Mettre à niveau TeX Live
description: Mettez à niveau TeX Live ou installez des paquets dans un déploiement Overleaf Community Edition.

<Danger>

Les instructions suivantes s'appliquent **uniquement** aux installations **Community Edition**. Nous recommandons vivement aux utilisateurs d'Ayakaleaf Pro d'activer les [compilations en bac à sable (Sandboxed Compiles)](/fr/on-premises/configuration/overleaf-toolkit/sandboxed-compiles), qui donnent accès à des images TeX Live presque identiques à celles utilisées sur [overleaf.com](https://www.overleaf.com) tout en isolant les compilations des projets les unes des autres pour une sécurité renforcée.

</Danger>

Pour économiser de la bande passante, les images Overleaf Community Edition et Ayakaleaf Pro ne contiennent qu'une installation minimale de [TeX Live](https://www.tug.org/texlive/). Vous pouvez installer davantage de paquets ou passer à une installation complète de TeX Live à l'aide de la commande [tlmgr](https://www.tug.org/texlive/tlmgr.html) dans le conteneur `sharelatex`.

#### Accéder au conteneur sharelatex

Pour démarrer un shell dans le conteneur `sharelatex`, exécutez

```bash
bin/shell
```

Vous obtiendrez une invite de commande semblable à :

```bash
root@309b192d4030:/#
```

Dans les instructions suivantes, nous supposons que vous êtes dans le conteneur.

#### Déterminer votre version actuelle de TeX Live

TeX Live est publié chaque année aux alentours du mois d'avril. Les étapes d'utilisation de `tlmgr` diffèrent selon que vous utilisez la version actuelle ou une version plus ancienne. Vous pouvez vérifier quelle version de TeX Live vous utilisez avec `tlmgr --version`. Par exemple, cette installation utilise TeX Live 2021 :

```bash
# tlmgr --version
tlmgr revision 59291 (2021-05-21 05:14:40 +0200)
tlmgr using installation: /usr/local/texlive/2021
TeX Live (https://tug.org/texlive) version 2021
```

<Info>

La version actuelle de TeX Live est indiquée sur [la page d'accueil de TeX Live](https://www.tug.org/texlive/).

</Info>

Si vous utilisez une version plus ancienne de TeX Live, deux options s'offrent à vous. Une nouvelle version de l'image Docker d'Overleaf est généralement publiée peu après chaque version de TeX Live : vous pouvez l'attendre et mettre à niveau votre déploiement avec le script `bin/upgrade`, ou, si vous préférez conserver l'ancienne version de TeX Live, vous devrez d'abord indiquer à `tlmgr` d'utiliser un dépôt historique. Vous trouverez les instructions correspondantes [ici](https://www.tug.org/texlive/acquire.html#past).

#### Installer des paquets

Pour installer une distribution TeX Live complète, exécutez cette commande dans le conteneur `sharelatex` :

```text
tlmgr install scheme-full
```

Vous pouvez également installer des paquets individuellement :

```bash
tlmgr install tikzlings tikzmarmots tikzducks
```

<Warning>

À partir de la version `3.3.0`, il est de nouveau **nécessaire** d'exécuter `tlmgr path add` après chaque utilisation de `tlmgr install`, afin de créer correctement les liens symboliques de tous les binaires dans le chemin système.

</Warning>

De nombreuses autres commandes sont disponibles. Pour en savoir plus :

```text
tlmgr help
```

Lorsque vous avez terminé, tapez `exit` ou appuyez sur Ctrl-D pour quitter le shell.

#### Enregistrer vos modifications

Les modifications que vous venez d'effectuer ont modifié le conteneur `sharelatex`, mais elles sont éphémères : elles seront perdues si Docker Compose recrée le conteneur, par exemple lors d'une mise à jour de la configuration.

Pour les rendre persistantes, utilisez `docker commit` afin d'enregistrer les modifications dans une nouvelle image Docker :

```bash
cat config/version #5.2.1
docker commit sharelatex sharelatex/sharelatex:5.2.1-with-texlive-full
echo 5.2.1-with-texlive-full > config/version
```

Après avoir enregistré les modifications, mettez à jour `config/version` en conséquence. Exécutez ensuite `bin/up` pour recréer le conteneur `sharelatex`.

<Danger>

Vous devrez répéter ces étapes à chaque [mise à niveau](https://github.com/overleaf/toolkit/blob/master/doc/upgrading.md) vers une nouvelle version d'Overleaf.

</Danger>
