### Initialisation de la configuration

Initialisons les fichiers de configuration de notre nouveau serveur avec des valeurs par défaut raisonnables en exécutant le script fourni `bin/init`.

```text title="Run initialization"
bin/init
```

Ce script n'écrasera **aucun** fichier de configuration existant.

Vérifions maintenant le contenu du répertoire `config/` à l'aide de la commande `ls` :

```text title="List the config directory"
ls config
```

Si l'initialisation s'est bien déroulée, vous devriez voir trois fichiers de configuration : `overleaf.rc`, `variables.env` et `version`. Ce sont les principaux fichiers de configuration du serveur ; ils vous permettent de personnaliser le fonctionnement de votre serveur et la manière dont vos utilisateurs interagissent avec votre instance.

| Nom             | Description                                             |
| --------------- | ------------------------------------------------------- |
| `overleaf.rc`   | Le fichier de configuration principal de premier niveau. |
| `variables.env` | Variables d'environnement chargées dans le conteneur Docker. |
| `version`       | La version de l'image Docker à utiliser.                |

<Info>

Pour l'instant, il suffit de savoir que ces fichiers existent et où les trouver. Plus loin dans la documentation, nous examinerons chacun de ces fichiers en détail et expliquerons comment les utiliser pour personnaliser votre instance. Si vous souhaitez aller plus vite, vous trouverez une description complète de ces fichiers de configuration sur la [page Fichiers et emplacements](/fr/on-premises/configuration/overleaf-toolkit/files-and-locations).

</Info>
