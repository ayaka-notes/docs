---
title: 4. Obtenir les images Ayakaleaf Pro
icon: split
---

Ayakaleaf Pro est une image Docker gratuite disponible sur [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Vous n'avez besoin ni de compte ni de connexion pour la récupérer. Les images sont construites pour amd64 et arm64, et Docker choisit celle qui correspond à votre serveur.

Ouvrez `config/overleaf.rc` et définissez :

```text title="config/overleaf.rc"
SERVER_PRO=true
```

La prochaine fois que vous exécuterez `bin/up`, le Toolkit téléchargera l'image Ayakaleaf Pro et l'utilisera à la place de l'édition communautaire officielle d'Overleaf (Community Edition). Vos paramètres dans `config/` continuent de fonctionner.

<Accordion title="Vous utilisez déjà le Toolkit officiel d'Overleaf (overleaf/toolkit) ?">

Inutile de réinstaller. Récupérez l'image Ayakaleaf Pro :

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Ajoutez ensuite un fichier nommé `docker-compose.override.yml` avec le contenu suivant dans le répertoire `overleaf-toolkit/config` :

```yml
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

La prochaine fois que vous exécuterez `bin/up`, le Toolkit utilisera l'image Ayakaleaf Pro.

</Accordion>
