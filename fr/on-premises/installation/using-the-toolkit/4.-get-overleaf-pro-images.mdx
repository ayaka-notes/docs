---
title: 4. Obtenir les images Ayakaleaf Pro
icon: split
---

Ayakaleaf Pro est distribué sous forme d'image Docker sur le registre [ghcr](https://github.com/ayaka-notes/overleaf-pro/pkgs/container/overleaf-pro/), en **libre accès** pour tous. Nous fournissons des images pour les architectures amd64 et arm64. Lorsque vous récupérez l'image, la version appropriée est automatiquement sélectionnée en fonction de l'architecture de votre système.

#### Utilisateurs du Toolkit Ayaka-notes

Si vous utilisez [ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit), Ayakaleaf Pro peut remplacer directement la Community Edition, ce qui vous permet de conserver vos paramètres et personnalisations existants. Activez Pro dans le Toolkit en modifiant `config/overleaf.rc` et en définissant la variable d'environnement `SERVER_PRO` :

```text title="config/overleaf.rc"
SERVER_PRO=true
```

La prochaine fois que vous exécuterez `bin/up`, le Toolkit téléchargera et utilisera automatiquement l'image Ayakaleaf Pro.

#### Utilisateurs du Toolkit officiel

Si vous utilisez [overleaf/toolkit](https://github.com/overleaf/toolkit), exécutez la commande suivante pour récupérer une image Pro :

```bash title="Pull Docker Images"
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Ajoutez ensuite un fichier nommé `docker-compose.override.yml` avec le contenu suivant dans le répertoire `overleaf-toolkit/config` :

```yml title="docker-compose.override.yml"
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

La prochaine fois que vous exécuterez `bin/up`, le Toolkit téléchargera et utilisera automatiquement l'image Ayakaleaf Pro.
