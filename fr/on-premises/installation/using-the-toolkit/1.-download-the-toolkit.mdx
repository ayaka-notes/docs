### Télécharger le Toolkit

Vous installez Ayakaleaf Pro avec l'**Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)), un ensemble de scripts qui exécute Overleaf dans Docker pour vous.

Par défaut, le Toolkit démarre l'édition communautaire officielle et gratuite d'Overleaf (Community Edition, CE). [4. Obtenir les images Ayakaleaf Pro](/fr/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images) le fait passer à Ayakaleaf Pro avec un seul paramètre.

<Accordion title="Vous utilisez déjà le Toolkit officiel d'Overleaf (overleaf/toolkit) ?">

Inutile de réinstaller. Conservez votre installation et suivez la dernière partie de [4. Obtenir les images Ayakaleaf Pro](/fr/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images).

</Accordion>

<Steps>
<Step title="Cloner le dépôt Ayakaleaf Toolkit">
Pour installer le Toolkit, placez-vous dans le répertoire d'installation souhaité, puis clonez le dépôt Ayakaleaf Toolkit avec cette commande :

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
```

<Info>

Pour éviter tout problème de permissions, nous vous recommandons d'installer le Toolkit dans le répertoire `$HOME` de votre utilisateur.

</Info>
</Step>

<Step title="Se placer dans le répertoire du Toolkit">
Attendez la fin du clonage, puis placez-vous dans le répertoire `overleaf-toolkit` nouvellement créé :

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
