### Télécharger le Toolkit

Le Toolkit est compatible à la fois avec Server CE et Ayakaleaf Pro, et constitue la méthode d'installation recommandée. Le Toolkit vous permet de démarrer facilement avec Server CE et de passer en toute transparence à Ayakaleaf Pro si nécessaire.

<Info>

[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) est modifié pour utiliser directement l'image overleaf-pro depuis ghcr, avec TeX Live fourni par ayaka-notes. Vous pouvez aussi télécharger l'overleaf-toolkit officiel.

</Info>

<Steps>
<Step title="Cloner le dépôt Overleaf Toolkit">
Pour installer le Toolkit, placez-vous dans le répertoire d'installation souhaité, puis clonez le dépôt GitHub Overleaf Toolkit (@Ayaka-notes) avec cette commande :

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
# official toolkit (Not Recommended)
# git clone https://github.com/overleaf/toolkit.git ./overleaf-toolkit
```

<Info>

Pour éviter tout problème de permissions, nous vous recommandons d'installer le Toolkit dans le répertoire `$HOME` de votre utilisateur.

</Info>
</Step>

<Step title="Se placer dans le répertoire du Toolkit">
Attendez la fin du clonage, puis placez-vous dans le répertoire `overleaf-toolkit` nouvellement créé :

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
