### Personnaliser votre instance

Avant de démarrer votre instance Overleaf pour la première fois, mettez à jour le fichier de configuration `config/variables.env` avec vos informations personnalisées.

<Steps>
<Step title="Modifier le fichier de variables">
Ouvrez `config/variables.env` dans votre éditeur de texte préféré et mettez à jour les variables d'environnement ci-dessous avec les valeurs requises.
</Step>

<Step title="Variables d'environnement requises">
Mettez à jour les variables suivantes dans `config/variables.env` :

| Nom                          | Description                                                                                                                                                    | Exemple                         |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| `OVERLEAF_SITE_URL`           | L'adresse à laquelle votre instance Overleaf est accessible publiquement. Elle est utilisée dans les liens publics et lors des connexions via websockets ; elle **doit donc être correctement configurée** ! | `https://overleaf.lilliput.com` |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | Cette adresse e-mail sera utilisée comme adresse d'expéditeur (`from`) pour tous les e-mails sortants.                                                                                 | `no-reply@lilliput.com`         |
| `OVERLEAF_ADMIN_EMAIL`        | L'adresse e-mail à laquelle les utilisateurs peuvent joindre la personne qui gère le site.                                                                                          | `it-services@lilliput.com`      |

Une fois ces variables d'environnement mises à jour, enregistrez et quittez.
</Step>

<Step title="Configurer la compilation en sandbox">
Configurez ensuite TeX Live Full pour les [sandboxed-compiles.md](/fr/on-premises/configuration/overleaf-toolkit/sandboxed-compiles  "mention"). Ouvrez `config/variables.env` et mettez à jour les variables d'environnement suivantes :

```dotenv title="config/variables.env" wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```
</Step>

<Step title="Démarrer votre instance">
Pour démarrer votre instance, exécutez :

```text title="Start the instance"
bin/up
```

Cette commande télécharge les images requises, y compris TeX Live, crée les conteneurs (avec vos personnalisations) et démarre l'instance. Vous devriez voir s'afficher les journaux des différents conteneurs Docker.

Pour les redémarrer plus tard (sans vous attacher à la sortie des journaux), exécutez :

```text title="Start without attaching to logs"
bin/start
```
</Step>
</Steps>

<Info>

Le Toolkit utilise `docker compose` pour gérer les conteneurs Docker d'Overleaf. Il fournit un ensemble de scripts qui encapsulent `docker compose` et s'occupent de la plupart des détails à votre place.

</Info>

Si tout se passe bien, vous devriez pouvoir afficher la page de connexion de votre nouvelle instance Overleaf en accédant à [http://127.0.0.1/](http://127.0.0.1/) ou [http://localhost/](http://localhost/) dans votre navigateur.

<Warning>

Selon votre configuration réseau et l'endroit où votre instance Overleaf est hébergée, vous devrez peut-être effectuer des modifications de configuration supplémentaires. Consultez les paramètres du Toolkit pour plus de détails : [toolkit-settings.md](/fr/on-premises/configuration/overleaf-toolkit/toolkit-settings  "mention")

</Warning>
