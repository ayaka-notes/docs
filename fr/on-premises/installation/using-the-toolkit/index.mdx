Le [Toolkit](https://github.com/ayaka-notes/toolkit) est la méthode recommandée pour déployer des instances Ayakaleaf Pro.

Dans cette section, nous vous guiderons pour télécharger le Toolkit depuis GitHub, vous familiariser avec certaines de ses commandes et configurer quelques paramètres de base. À la fin de cette page, vous devriez disposer d'une instance Overleaf sur site opérationnelle.
