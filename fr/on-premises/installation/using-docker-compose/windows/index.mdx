Dans cette section, nous exécutons Ayakaleaf Pro en local sous Windows avec WSL 2, Ubuntu, Docker Desktop et l'[Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). Le guide utilise `http://localhost:8080`, conserve les données dans le répertoire personnel d'Ubuntu et active les compilations en sandbox.

L'application, MongoDB, Redis et TeX Live s'exécutent dans des conteneurs Linux gérés par Docker Desktop. Exécutez les commandes du Toolkit dans Ubuntu ; ouvrez l'application dans votre navigateur Windows. L'[étape 0](/fr/on-premises/installation/using-docker-compose/windows/0.-setup-wsl-and-docker-desktop) explique comment les parties Windows et Linux s'articulent et commence par l'installation de WSL.

Vous pouvez utiliser Windows pour une instance locale ou la faire fonctionner en continu grâce aux paramètres de disponibilité de l'étape 6. Pour les serveurs partagés et de production, nous recommandons le [guide Linux](/fr/on-premises/installation/using-docker-compose/linux), avec HTTPS, des sauvegardes et un contrôle d'accès. La mise en veille de Windows, l'arrêt de Docker Desktop et l'arrêt de WSL interrompent cette instance locale ; voir [Garder l'instance disponible](/fr/on-premises/installation/using-docker-compose/windows/6.-post-installation-tasks#keep-the-instance-available).

## Avant de commencer {#before-you-start}

Vous avez besoin de :

* Une version de Windows et un processeur pris en charge par [Docker Desktop pour Windows](https://docs.docker.com/desktop/setup/install/windows-install/), avec la virtualisation matérielle activée. Ce guide utilise Windows 11 sur x86-64.
* L'autorisation d'activer WSL et d'installer des logiciels. WSL doit être en version 2.1.5 ou ultérieure, avec Ubuntu fonctionnant en mode WSL 2.
* Suffisamment de mémoire pour Windows et les conteneurs. Pour une petite instance locale, 4 processeurs et 8 Go disponibles pour Docker constituent un point de départ suggéré, et non un minimum mesuré.
* De l'espace de stockage libre sur le disque Windows qui contient les données de WSL et de Docker. Prévoyez au moins 40 Go pour une installation TeX Live complète plus les données des projets ; l'image basic de l'[étape 5](/fr/on-premises/installation/using-docker-compose/windows/5.-personalizing-your-instance) est plus petite et convient au test de déploiement initial. Les versions d'image supplémentaires nécessitent davantage d'espace.
* Un accès réseau à GitHub, à GitHub Container Registry (`ghcr.io`) et à Docker Hub pour cloner le Toolkit et télécharger les images.

Les blocs **PowerShell** s'exécutent dans Windows. Les blocs **Bash** et les commandes `bin/` s'exécutent dans Ubuntu, sauf indication contraire. N'exécutez pas les scripts du Toolkit dans PowerShell ni dans Git Bash pour Windows.
