<Steps>
<Step title="Installer les outils en ligne de commande">
Exécutez dans **Ubuntu**, avec le mot de passe Linux créé à l'étape 0 :

```bash
sudo apt update
sudo apt install -y git ca-certificates curl perl gawk openssl
```

Ubuntu fournit déjà Bash, GNU sed et coreutils. Contrairement à macOS, il n'a besoin ni de Homebrew ni d'une installation distincte de GNU sed.
</Step>

<Step title="Cloner le dépôt de l'Ayakaleaf Toolkit">
Conservez le Toolkit et ses données dans le système de fichiers Linux d'Ubuntu, sous votre répertoire personnel :

```bash
cd "$HOME"
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

Évitez `/mnt/c`, `/mnt/d`, OneDrive et les répertoires temporaires pour la base de données et les données de projet actives. Les chemins du système de fichiers Linux offrent les permissions et le comportement de système de fichiers attendus par les conteneurs, et évitent le surcoût lié au passage entre systèmes de fichiers ; consultez les [recommandations de Microsoft sur les systèmes de fichiers](https://learn.microsoft.com/en-us/windows/wsl/filesystems).

<Warning>

Si le répertoire contient déjà une installation, utilisez-la telle quelle, ou choisissez un autre répertoire pour une nouvelle instance. Ne remplacez pas la configuration ou les données d'un déploiement existant.

</Warning>
</Step>
</Steps>
