title: 4. Obtenir les images Ayakaleaf Pro
description: Dans Ubuntu sous WSL 2, basculez le Toolkit vers l'image publique Ayakaleaf Pro.

---

Ayakaleaf Pro est une image Docker gratuite disponible sur [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Vous n'avez besoin ni d'un compte, ni d'une connexion, ni d'une licence commerciale Overleaf pour la récupérer.

Ouvrez `config/overleaf.rc` et définissez :

```bash title="config/overleaf.rc"
SERVER_PRO=true
```

La prochaine fois que vous exécuterez `bin/up`, le Toolkit récupérera `ghcr.io/ayaka-notes/overleaf-pro` dans la version indiquée dans `config/version`, au lieu de l'Overleaf Community Edition officielle.

L'image est construite pour `arm64` et `amd64`, et Docker choisit celle qui correspond à l'architecture du moteur Docker.
