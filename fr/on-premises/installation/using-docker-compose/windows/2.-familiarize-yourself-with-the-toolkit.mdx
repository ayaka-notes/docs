Le Toolkit est le même que sous Linux. Son organisation, le répertoire `config/` et les commandes `bin/` sont décrits dans [2. Familiarisez-vous avec le Toolkit](/fr/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) du guide Linux.

Sous Windows, gardez ces différences à l'esprit :

* Exécutez les commandes `bin/` dans **Ubuntu Bash**, depuis `~/ayakaleaf-toolkit`. Les commandes marquées **PowerShell** s'exécutent au contraire dans Windows.
* Démarrez Docker Desktop et activez la WSL Integration d'Ubuntu avant d'utiliser `bin/up`, `bin/start` ou `bin/docker-compose`.
* Conservez des fins de ligne Linux (LF) dans les fichiers de configuration. Modifiez-les avec `nano` dans Ubuntu ou avec un éditeur connecté à WSL. Les fins de ligne CRLF peuvent provoquer des erreurs Bash.
* `bin/doctor` exécute des vérifications Linux dans Ubuntu. Son avertissement indiquant que vous n'êtes pas connecté à `quay.io` ne s'applique pas à l'image publique `ghcr.io/ayaka-notes/overleaf-pro`. Les autres avertissements méritent toujours votre attention.

```bash
bin/doctor
```
