<Steps>
<Step title="Vérifier Git et Homebrew">
```bash
git --version
brew --version
```

Si macOS vous propose d'installer les Command Line Tools lorsque vous exécutez Git, installez-les d'abord. Si Homebrew est absent, installez-le en suivant les [instructions officielles](https://brew.sh/).
</Step>

<Step title="Placer GNU sed dans le PATH">
Les scripts du Toolkit utilisent des options de GNU sed que le sed BSD intégré à macOS refuse. Installez [GNU sed](https://formulae.brew.sh/formula/gnu-sed) et placez-le en premier dans le `PATH` de ce terminal :

```bash
brew install gnu-sed
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
sed --version
```

La dernière commande doit afficher **GNU sed**.

Un alias tel que `alias sed=gsed` ne suffit pas : le Toolkit exécute des scripts Bash, qui ne voient pas les alias de votre shell interactif. Vous n'avez pas besoin de remplacer `/usr/bin/sed`.

Exécutez à nouveau la ligne `export PATH=...` dans chaque nouveau terminal que vous utilisez pour le Toolkit, ou ajoutez-la à votre fichier de démarrage du shell après l'initialisation propre à Homebrew.
</Step>

<Step title="Cloner le dépôt de l'Ayakaleaf Toolkit">
Choisissez un répertoire persistant. Évitez `/tmp`, les disques amovibles et les dossiers synchronisés avec le cloud, comme iCloud Drive, pour la base de données et les données de projet actives. Ce guide utilise `~/ayakaleaf-toolkit` :

```bash
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

<Warning>

Si le répertoire contient déjà une installation, utilisez-la telle quelle, ou choisissez un autre répertoire pour une nouvelle instance. N'initialisez pas une nouvelle configuration par-dessus un déploiement existant.

</Warning>

</Steps>
