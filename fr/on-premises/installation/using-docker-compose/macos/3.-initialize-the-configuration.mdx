---
title: 3. Initialiser la configuration
description: Créez les fichiers de configuration du Toolkit sur votre Mac avec bin/init.
icon: circle-play
---

Depuis le répertoire du Toolkit, dans un terminal où GNU sed figure dans le `PATH`, exécutez :

```bash
bin/init
```

`bin/init` crée trois fichiers :

| Fichier | Rôle |
| --- | --- |
| `config/overleaf.rc` | Paramètres des conteneurs, port publié et emplacements des données |
| `config/variables.env` | Paramètres de l'application et secrets |
| `config/version` | Version de l'image de l'application |

Il génère également `OVERLEAF_INVITE_TOKEN_SECRET` dans `config/variables.env`. Conservez-le, et ne publiez pas ce fichier ni ne le versionnez.

Conservez la version que le Toolkit sélectionne pour une nouvelle installation. Pour changer ultérieurement la version d'une instance existante, suivez [Mettre à niveau votre déploiement](/fr/on-premises/maintenance/upgrading-your-deployment).

<Warning>

Si `bin/init` s'arrête avec `sed: ... invalid command code`, il a été exécuté avec le sed BSD de macOS. Une telle exécution ratée peut laisser les trois fichiers dans `config/` avec un `OVERLEAF_INVITE_TOKEN_SECRET` vide, et une nouvelle exécution de `bin/init` signale alors `Config files already exist`. Consultez [Dépannage](/fr/on-premises/installation/using-docker-compose/macos/troubleshooting#initialization-fails-with-invalid-command-code).

</Warning>
