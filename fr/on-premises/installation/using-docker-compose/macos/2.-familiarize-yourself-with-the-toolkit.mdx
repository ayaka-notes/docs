Le Toolkit est le même sous macOS et sous Linux. Son organisation, le répertoire `config/` et les commandes `bin/` sont décrits dans [2. Familiarisez-vous avec le Toolkit](/fr/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) du guide Linux.

Sous macOS, gardez trois différences à l'esprit :

* Exécutez les scripts depuis un terminal où GNU sed figure en premier dans le `PATH`, voir [1. Télécharger le Toolkit](/fr/on-premises/installation/using-docker-compose/macos/1.-download-the-toolkit).
* Démarrez Docker Desktop avant d'exécuter un script qui communique avec Docker, comme `bin/up`, `bin/start` ou `bin/docker-compose`.
* `bin/doctor` comprend des vérifications héritées de l'Overleaf Toolkit officiel. Son avertissement `This system seems to not be Linux` est attendu sous macOS, et son avertissement indiquant que vous n'êtes pas connecté à `quay.io` ne s'applique pas à l'image publique `ghcr.io/ayaka-notes/overleaf-pro`. Les autres problèmes signalés dans le rapport restent importants.
