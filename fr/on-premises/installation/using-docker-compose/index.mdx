Docker Compose sur un seul serveur est la méthode recommandée pour déployer Ayakaleaf Pro. Vous l'exécutez via le [Toolkit](https://github.com/ayaka-notes/toolkit) : un ensemble de scripts qui encapsulent `docker compose` et lisent vos paramètres depuis un unique répertoire `config/`, de sorte que `bin/up` remplace `docker compose up`.

Choisissez le guide correspondant à la machine qui exécute Docker :
