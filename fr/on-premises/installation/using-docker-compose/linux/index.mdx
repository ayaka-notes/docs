Dans cette section, nous vous guiderons pour installer Docker, télécharger le Toolkit depuis GitHub, vous familiariser avec certaines de ses commandes et configurer quelques paramètres de base. À la fin de cette section, vous devriez disposer d'une instance Overleaf sur site opérationnelle.

Les étapes ciblent une version LTS récente d'Ubuntu. Sur une autre distribution, installez Docker Engine et le plugin Compose comme décrit dans la [documentation de Docker](https://docs.docker.com/engine/install/), puis poursuivez avec [1. Télécharger le Toolkit](/fr/on-premises/installation/using-docker-compose/linux/1.-download-the-toolkit).

<Info>

Par défaut, l'instance n'accepte que les connexions provenant du serveur lui-même, sur `http://localhost`. Pour l'ouvrir depuis d'autres ordinateurs ou sur un autre port, définissez `OVERLEAF_LISTEN_IP` et `OVERLEAF_PORT` dans `config/overleaf.rc`, comme décrit dans [5. Personnaliser votre instance](/fr/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance).

</Info>
