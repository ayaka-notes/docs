### Présentation d'Overleaf

Overleaf est un éditeur LaTeX collaboratif apprécié des chercheurs et des équipes techniques. Sa version cloud est disponible sur [overleaf.com](https://www.overleaf.com/). Il propose un éditeur LaTeX en ligne complet. Cependant, Overleaf Common (version SaaS) présente de nombreuses limitations fonctionnelles, et vous devez vous accommoder d'une _**limite de temps de compilation de 10 secondes**_ et d'abonnements coûteux.

Bien qu'Overleaf propose une version communautaire open source (disponible sur [GitHub : Overleaf](https://github.com/overleaf/overleaf)), celle-ci présente également de nombreuses limitations, par exemple :

<Warning>

Overleaf Community Edition est destinée aux environnements dans lesquels **tous** les utilisateurs sont dignes de confiance. Community Edition n'est **pas** adaptée aux scénarios nécessitant l'isolation des utilisateurs, car les compilations en sandbox (Sandbox Compiles) n'y sont pas disponibles.

Sans sandbox, les compilations LaTeX s'exécutent avec les mêmes privilèges que le conteneur, ce qui donne accès à son système de fichiers, à son réseau et à ses variables d'environnement. Cela crée un risque d'exposition des données ou de compromission du système. Les compilations hors sandbox ne doivent être utilisées que dans des environnements entièrement dignes de confiance ; pour les déploiements multi-utilisateurs ou de production, les compilations en sandbox sont fortement recommandées.

Pour plus d'informations sur les compilations en sandbox, voir : [sandboxed-compiles.md](/fr/on-premises/configuration/overleaf-toolkit/sandboxed-compiles  "mention")

</Warning>

### Informations et tarifs d'Overleaf Server Pro

Le site web d'Overleaf ne propose qu'un point d'entrée pour contacter le support concernant Server Pro ; les informations sur Server Pro sont donc très limitées. Mais d'après les informations que nous avons recueillies dans la communauté, les **conditions de Server Pro sont** :

* Vous devez acheter des licences pour _au moins_ 10 personnes.
* Une licence pour 10 personnes coûte environ 3 477,61 €. (2024)
* Pour l'enseignement, 20 utilisateurs coûtent 2 640 € par an, 50 utilisateurs 6 050 € et 100 utilisateurs 9 963 €.
* Server Pro n'est disponible que dans certaines régions (par exemple, pas en Chine continentale).

D'après les informations actuellement disponibles, Overleaf Server Pro semble coûter environ 300 \$ par utilisateur et par an, avec un achat minimum de 10 licences, ce qui en fait une option très coûteuse. De plus, Server Pro offre nettement moins de fonctionnalités qu'Ayakaleaf Pro. Nous sommes profondément reconnaissants envers les développeurs de la communauté dont les contributions au fil des années nous ont permis de construire Ayakaleaf Pro et, au final, de surpasser Overleaf Server Pro en fonctionnalités comme en capacités.

Les registres publics suivants présentent des achats et des tarifs documentés d'Overleaf Server Pro. Les contrats américains de plus petite taille indiquent des coûts annuels d'environ 320 à 370 \$ par utilisateur. Les grands accords institutionnels peuvent bénéficier de tarifs par utilisateur plus bas. Par exemple, l'accord de trois ans de la Société Max Planck revient en moyenne à environ 51 € par utilisateur et par an. Les conditions contractuelles, le support et le périmètre de déploiement peuvent varier. Ces registres ne constituent pas une grille tarifaire officielle d'Overleaf.

### Pourquoi Ayakaleaf Pro ?

<Info>

Ayakaleaf Pro n'est _**pas**_ affilié à Overleaf, Inc. ni à sa société mère, Digital Science. Ce n'est pas non plus l'édition _Server Pro_, qui est un produit commercial proposé par Overleaf, Inc. [ayaka-notes](https://github.com/ayaka-notes) développe et maintient Ayakaleaf Pro en tant que projet indépendant.

</Info>

Ayakaleaf Pro est une implémentation améliorée d'Overleaf Community Edition, offrant _**toutes**_ les fonctionnalités _**premium gratuitement**_, issues de Server Pro. Contrairement à Overleaf Common, disponible sur [https://www.overleaf.com/](https://www.overleaf.com/), ou à l'édition commerciale Server Pro, nous avons :

* _**aucune limitation**_ du temps de compilation
* _**aucune licence**_ requise selon le nombre d'utilisateurs
* _**toutes les fonctionnalités**_ de Server Pro débloquées
