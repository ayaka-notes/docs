### Compte

En ce qui concerne la gestion de leur propre compte, **tous** les utilisateurs sont traités comme des utilisateurs ordinaires — les `Site Admins` et les `Template Users` ne disposent d'**aucune** autorisation supplémentaire. Il existe toutefois des restrictions sur les actions que les utilisateurs ordinaires peuvent effectuer selon leur mode d'authentification.

#### Paramètres

**Types d'authentification : comptes internes | SSO (SAML/LDAP)**

| Action | Comptes internes | SSO (SAML/LDAP) |
| ----------------------------------------- | ----------------: | --------------: |
| Mettre à jour les informations du compte | Oui | Non |
| Changer le mot de passe | Oui | Non |
| Générer des jetons d'authentification Git bridge | Oui | Oui |
| Supprimer des jetons d'authentification Git bridge | Oui | Oui |
| Gérer les sessions | Oui | Oui |

<Info>

L'intégration Git Bridge est disponible **uniquement** dans Server Pro. Consultez la page [Server Pro vs. Community Edition](/fr/on-premises/readme/ayakaleaf-pro-vs-server-pro) pour plus d'informations.

</Info>

#### Vos sessions

| -------------------- | ---: |
| Effacer les sessions | Oui |
| Voir la session en cours | Oui |
| Voir les autres sessions | Oui |

### IDE de l'éditeur

Du point de vue de l'IDE de l'éditeur Overleaf, vous pouvez avoir l'un des rôles suivants : `Project Owner`, `Editor`, `Reviewer`, `Viewer`, `Site Administrator` ou `Template User`.

<Info>

Server Pro et Community Edition permettent de fournir un accès anonyme aux projets en **lecture seule** et en **lecture-écriture**.

Pour plus d'informations à ce sujet, consultez les variables d'environnement `OVERLEAF_ALLOW_PUBLIC_ACCESS` et `OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` [ici](/fr/on-premises/configuration/overleaf-toolkit/environment-variables).

</Info>
