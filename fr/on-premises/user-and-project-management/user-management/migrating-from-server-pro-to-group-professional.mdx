title: Migrer de Server Pro vers Group Professional

---

Passer d'une instance Server Pro auto-hébergée à un nouvel abonnement Overleaf Group Professional dans le cloud est un changement important ; pour que ce processus se déroule le plus facilement possible, nous avons rassemblé les recommandations suivantes.

En général, nous proposons une période de chevauchement de trois mois à compter de votre date de renouvellement. Cela signifie que :

* Votre instance Server Pro existante et votre nouvel abonnement Group Professional seront tous deux pleinement actifs.
* Votre équipe technique peut planifier le temps nécessaire pour configurer l'abonnement Group Professional et décider de l'avenir de votre déploiement sur site de Server Pro.
* Surtout, vos utilisateurs disposeront de tout le temps nécessaire pour copier leurs projets vers la nouvelle plateforme Overleaf Group Professional.

Ce guide rapide vous accompagne dans les étapes clés de cette migration. C'est parti !

<Steps>
<Step title="Phase 1 : Installation et configuration">
(Lien : https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-1-setup-and-configuration)

* Overleaf créera votre abonnement Group Professional et ajoutera votre administrateur principal.
* L'administrateur de votre groupe pourra activer les [utilisateurs gérés (Managed Users)arrow-up-right](https://docs.overleaf.com/groups/user-management/managed-user-accounts), configurer l'[authentification unique (SSO)arrow-up-right](https://docs.overleaf.com/groups/overleaf-group-single-sign-on/setting-up-group-sso) et [inviter les utilisateurs finauxarrow-up-right](https://docs.overleaf.com/groups/user-management/how-to-add-and-remove-users).

<Warning>

L'activation des utilisateurs gérés et la mise en place du SSO sont des étapes obligatoires pour la conformité FedRAMP® LI-SaaS. Si votre organisation exige la conformité FedRAMP, configurez les utilisateurs gérés et le SSO avant d'inviter les utilisateurs finaux.

</Warning>
</Step>

<Step title="Phase 2 : Migration des utilisateurs et gestion des données">
(Lien : https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-2-user-migration-and-data-management)

Il s'agit de la principale fenêtre de migration, avec les responsabilités suivantes :

#### Utilisateurs finaux

* Les utilisateurs doivent migrer les projets qu'ils souhaitent conserver depuis votre instance Server Pro vers leurs nouveaux comptes sur [overleaf.comarrow-up-right](http://overleaf.com/). Le processus consiste à [exporter les projetsarrow-up-right](https://www.overleaf.com/learn/how-to/Exporting_your_work_from_Overleaf) depuis Server Pro puis à [les téléverserarrow-up-right](https://www.overleaf.com/learn/how-to/Uploading_a_project) sur leur compte [overleaf.comarrow-up-right](http://overleaf.com/). Si un utilisateur n'a pas encore de compte [overleaf.comarrow-up-right](http://overleaf.com/), il peut s'inscrire sur [overleaf.com/registerarrow-up-right](http://overleaf.com/register).

<Warning>

Seul le code source des projets (fichiers LaTeX et binaires) sera transféré par cette procédure d'export. Les paramètres de projet existants, les paramètres de partage, les commentaires, les modifications suivies, etc. ne seront PAS transférés. Les utilisateurs devront réinviter leurs collaborateurs après la migration.

</Warning>

#### Équipe technique

* Pendant cette phase, votre équipe technique doit planifier le traitement post-migration de votre instance Server Pro sur site et de ses données.
* **Sauvegarde des données :** vous pouvez exporter tous les projets avant la mise hors service afin de créer une archive vous permettant d'aider les utilisateurs qui auraient oublié de migrer ou de télécharger leur travail. Instructions : https://docs.overleaf.com/on-premises/maintenance/data-and-backups/exporting-projects
* **Mise hors service de Server Pro :** une fois la fenêtre de migration close et votre clé de licence désactivée, deux options principales s'offrent à vous pour l'instance Server Pro elle-même (voir l'étape suivante).
</Step>

<Step title="Options de mise hors service de Server Pro">
<Steps>
<Step title="Désinstaller complètement Server Pro">
La désinstallation met Server Pro hors service et supprime entièrement le logiciel.
</Step>

<Step title="Passer à la Community Edition">
Ce changement conserve la base de données des utilisateurs et des projets, avec l'historique complet des projets, en convertissant l'instance de Server Pro en Community Edition.
</Step>
</Steps>

<Info>

La Community Edition n'inclut PAS les [compilations en sandboxarrow-up-right](https://docs.overleaf.com/on-premises#overview-of-server-pro-and-community-edition), ni [LDAP](/fr/on-premises/configuration/overleaf-toolkit/authentication/ldap-authentication)/[SAML](/fr/on-premises/configuration/overleaf-toolkit/authentication/saml-authentication). Si vous devez revenir à l'authentification native (nom d'utilisateur/mot de passe), voir : https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-to-ldap-or-saml#going-the-other-way-switching-from-ldap-saml-back-to-native-authentication

Pour une comparaison entre Server CE et Server Pro, voir : https://docs.overleaf.com/on-premises/welcome/server-pro-vs.-community-edition

</Info>
</Step>

<Step title="Phase 3 : Mise hors service de Server Pro">
(Lien : https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-3-server-pro-decommission)

* L'équipe Overleaf désactivera officiellement votre clé de licence Server Pro et vous enverra une confirmation une fois l'opération terminée.
* À ce stade, effectuez l'une des actions de mise hors service décrites ci-dessus : désinstaller complètement Server Pro ou passer à la Community Edition.
</Step>
</Steps>

Les ressources et liens supplémentaires mentionnés ci-dessus restent inchangés.
