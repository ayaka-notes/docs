Chaque projet dispose d'un serveur MCP, afin que des clients IA tels que Claude Code, Codex, Cursor, VS Code ou Gemini CLI puissent travailler dessus : lire et modifier ses fichiers, le compiler, lire le journal LaTeX, télécharger le PDF et répondre aux commentaires.

<Info>

Cette fonctionnalité est développée par [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro). Elle est disponible à partir de la v6.3.1.

</Info>

### Configuration

Le serveur MCP est fourni avec l'intégration Git : activez [git-bridge](/fr/on-premises/configuration/overleaf-toolkit/git-integration), et le serveur MCP est également disponible. Il n'y a rien d'autre à configurer.

### Connecter un client IA

1. Dans les **paramètres du compte**, générez un jeton d'authentification Git. Le même jeton est utilisé pour le serveur MCP et pour Git.
2. Dans l'éditeur, ouvrez **Intégrations** et cliquez sur **Serveur MCP**. La boîte de dialogue affiche l'adresse du serveur MCP du projet, `https://<your-overleaf>/project/<project_id>/mcp`, ainsi que la manière de l'ajouter à chaque client IA : copiez la commande et remplacez `<token>` par votre jeton.

### Utilisation

Une fois connecté, formulez vos demandes au client IA en langage courant. Par exemple :

| Vous demandez | Le client IA utilise |
| --- | --- |
| _Corrige les fautes de frappe dans l'introduction._ | `read_file`, `edit_file` : les modifications s'affichent en direct dans l'éditeur |
| _Compile le projet et corrige les erreurs LaTeX._ | `compile`, `get_compile_log`, `edit_file` |
| _Réponds aux commentaires ouverts, puis résous-les._ | `list_comments`, `reply_to_comment`, `resolve_comment` |
| _Passe à XeLaTeX et télécharge le PDF._ | `update_settings`, `compile`, `get_output_file_link` |

### Outils

| Groupe | Outils |
| --- | --- |
| Projet | `get_clone_info`, `get_settings`, `update_settings`, `list_versions` |
| Fichiers | `list_files`, `read_file`, `edit_file`, `write_file`, `delete_file` |
| Compilation | `compile`, `get_compile_log`, `get_output_file_link`, `word_count` |
| Commentaires | `list_comments`, `reply_to_comment`, `resolve_comment`, `reopen_comment` |

Les modifications effectuées avec `edit_file` et `write_file` s'affichent en direct dans l'éditeur et sont fusionnées avec celles des collaborateurs. Pour de nombreux fichiers à la fois, des fichiers binaires ou des renommages, le client IA peut aussi cloner le projet avec Git et pousser ses modifications.

### Autorisations

Le serveur MCP respecte les paramètres de partage du projet, comme Git :

* Toute personne pouvant consulter le projet peut le lire, le compiler et télécharger ses fichiers de sortie.
* Seuls le propriétaire et les éditeurs peuvent modifier ses fichiers et ses paramètres.
* Les relecteurs peuvent également répondre aux commentaires, et résoudre ou rouvrir les commentaires qu'ils ont lancés.
* Les lecteurs ayant rejoint le projet via un lien ne peuvent pas voir les commentaires, comme dans l'éditeur.

### Questions/réponses

<Accordion title="Je ne vois ni Integrations ni le serveur MCP dans l'éditeur">

<strong>Réponse :</strong> Le serveur MCP n'a pas de variable d'environnement propre. Il est activé avec `GIT_BRIDGE_ENABLED=true` dans `config/overleaf.rc`, voir [Intégration Git](/fr/on-premises/configuration/overleaf-toolkit/git-integration). Après l'avoir modifiée, exécutez `bin/up -d`. Sans le git-bridge, l'éditeur n'affiche pas l'onglet **Integrations** dans sa barre latérale gauche.

</Accordion>
