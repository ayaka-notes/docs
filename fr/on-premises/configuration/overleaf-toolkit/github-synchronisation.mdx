### Configurer la synchronisation GitHub

<Warning>

Vous devez d'abord activer [git-bridge](/fr/on-premises/configuration/overleaf-toolkit/git-integration) avant d'utiliser la synchronisation GitHub.

```dotenv title="config/overleaf.rc"
GIT_BRIDGE_ENABLED=true
```

</Warning>

Rendez-vous dans les [paramètres développeur](https://github.com/settings/developers) pour créer votre application OAuth GitHub, puis copiez votre `CLIENT_ID` et votre `SECRET`.

**Remarque** : votre URL de callback OAuth est : `${OVERLEAF_SITE_URL}/user/github-sync/oauth2/callback`.

Ajoutez ensuite les paramètres suivants à vos fichiers de variables d'environnement Overleaf.

```dotenv title="config/variables.env" wrap
# used to encrypt the user's GitHub access token.
# How to generate: `openssl rand -hex 32`
GITHUB_TOKEN_CIPHER_PASSWORD=0123456789ABCDEFG # changed to yours

# Github Sync Settings
GITHUB_SYNC_ENABLED=true
GITHUB_SYNC_CLIENT_ID=
GITHUB_SYNC_CLIENT_SECRET=

# OAuth callback is: ${OVERLEAF_SITE_URL}/user/github-sync/oauth2/callback
# (Optional) GITHUB_SYNC_PROXY_URL=http://10.0.0.1:10808
```

<Warning>

Avant de configurer l'URL de callback OAuth GitHub, assurez-vous que `OVERLEAF_SITE_URL` est correctement défini.

</Warning>

Si vous vous trouvez en Chine continentale, vous devrez peut-être configurer un proxy pour accéder à GitHub. Définissez la variable d'environnement suivante : `GITHUB_SYNC_PROXY_URL=http://10.0.0.1:10808`.

<Warning>

N'utilisez pas `127.0.0.1` comme hôte du proxy. Si le proxy s'exécute sur le serveur hôte, utilisez l'adresse IP LAN du serveur (par exemple `192.168.1.xx`) et assurez-vous que le proxy est configuré pour accepter les connexions des appareils du réseau local.

</Warning>
