### Configurer l'intégration Zotero

1. Ouvrez [ce lien](https://www.zotero.org/oauth/apps) pour créer un client OAuth Zotero (comme le montre l'image)
2. Choisissez **Application Type** : **Browser**
3. Définissez l'URL de rappel (Callback URL) sur `${OVERLEAF_SITE_URL}/user/zotero/oauth/callback`
4. Configurez votre `config/variables.env`

<Frame>
  <img src="/images/on-premises/image-41.png" alt="" width="375" />
</Frame>

```dotenv title="config/variables.env"
#################
#    Zotero     #
#################
# 'zotero' must be in ENABLED_LINKED_FILE_TYPES (set in develop/docker-compose.yml)
ENABLED_LINKED_FILE_TYPES=project_file,project_output_file,url,zotero

# From a Zotero OAuth client (register at https://www.zotero.org/oauth/apps)
# Application Type: Browser 
# Callback URL -> ${OVERLEAF_SITE_URL}/user/zotero/oauth/callback
ZOTERO_CLIENT_ID=
ZOTERO_CLIENT_SECRET=
# Encrypts the Zotero API key in mongo (set in dev to avoid writing a key file
# to /var/lib/overleaf/data, which the dev web container can't create)
# How to generate: `openssl rand -hex 32`
ZOTERO_CIPHER_PASSWORD=dev-zotero-cipher-password
# Optional: route the module's server-side Zotero requests (OAuth + API) through
# an HTTP proxy (must be reachable from the web container; same as github-sync)
# http://10.0.0.1:10808
# (Optional) ZOTERO_PROXY_URL=
```

### Remarques

<Warning>

Lors de la mise à niveau vers la version 6.3.0 republiée d'une installation existante comportant des fichiers de bibliographie liés à Zotero, suivez les [instructions de migration Zotero / Mendeley](/fr/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention"). Les nouvelles installations n'ont pas besoin de cette migration.

</Warning>

<Danger>

Ayakaleaf étant une plateforme collaborative, afin de renforcer la sécurité, à partir de la version 6.3.0, seul le créateur d'origine d'un fichier de références `bib` est autorisé à mettre à jour le fichier importé.

</Danger>

Par exemple, supposons que le propriétaire du projet, l'utilisateur A, active le partage par lien et crée dans le projet un fichier `test.bib` lié à son propre compte Zotero. Si un autre utilisateur, l'utilisateur B, accède au projet via le lien partagé, il pourra toujours lire et télécharger `test.bib`, mais ne sera pas autorisé à mettre à jour ni à réimporter le fichier depuis Zotero. Seul l'utilisateur A, en tant que créateur d'origine du fichier de références, peut effectuer des mises à jour. Autrement dit, seul le créateur d'origine du fichier `.bib` a l'autorisation de le mettre à jour.
