Overleaf prend en charge l'envoi d'e-mails selon deux méthodes : Simple Mail Transfer Protocol (SMTP) et [Amazon Simple Email Service (SES)](https://aws.amazon.com/ses/). SMTP peut être utilisé si un serveur de messagerie est activé sur votre localhost et écoute les connexions locales.

## Configuration

L'envoi d'e-mails se configure à l'aide des variables d'environnement suivantes.

#### Configuration de l'expéditeur

| Nom                           | Description                                                                                                                                          |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | <p>L'adresse d'expédition, par ex. <a href="mailto:support@mycompany.com">`'support@mycompany.com'`</a><br /><br />- <strong>Obligatoire</strong> : oui</p> |
| `OVERLEAF_EMAIL_REPLY_TO`     | L'adresse de réponse, par ex. `'noreply@mycompany.com'`                                                                                                  |

#### SMTP

| Nom                                     | Description                                                                                                                                                                                                                                                              |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST`              | Le nom d'hôte ou l'adresse IP auquel se connecter. Doit être accessible depuis le conteneur Docker                                                                                                                                                                               |
| `OVERLEAF_EMAIL_SMTP_PORT`              | Le port auquel se connecter                                                                                                                                                                                                                                                   |
| `OVERLEAF_EMAIL_SMTP_SECURE`            | Si `true`, la connexion au serveur utilise TLS. Si `false` ou non défini, TLS est utilisé si le serveur prend en charge l'extension `STARTTLS`. Dans la plupart des cas, définissez cette valeur sur `true` si vous vous connectez au port `465`. Pour les ports `587` ou `25`, conservez `false` |
| `OVERLEAF_EMAIL_SMTP_USER`              | Le nom d'utilisateur à utiliser pour s'authentifier auprès du serveur SMTP                                                                                                                                                                                                 |
| `OVERLEAF_EMAIL_SMTP_PASS`              | Le mot de passe associé au nom d'utilisateur SMTP                                                                                                                                                                                                                           |
| `OVERLEAF_EMAIL_SMTP_TLS_REJECT_UNAUTH` | Si `false`, une connexion peut être ouverte vers un serveur TLS dont le certificat TLS est auto-signé ou invalide                                                                                                                                                                        |
| `OVERLEAF_EMAIL_SMTP_IGNORE_TLS`        | Lorsque cette valeur est `true` et que `OVERLEAF_EMAIL_SMTP_SECURE` vaut `false`, TLS n'est pas utilisé même si le serveur prend en charge l'extension `STARTTLS`                                                                                                                                            |
| `OVERLEAF_EMAIL_SMTP_NAME`              | Nom d'hôte facultatif pour la validation TLS si `OVERLEAF_EMAIL_SMTP_HOST` est défini sur une adresse IP ; par défaut, le nom d'hôte de la machine.                                                                                                                                        |
| `OVERLEAF_EMAIL_SMTP_LOGGER`            | Lorsque cette valeur est `true`, les messages de journalisation sont écrits dans `web.log`.                                                                                                                                                                                                                        |

#### Interface SMTP d'Amazon SES

Pour en savoir plus sur l'utilisation de l'interface SMTP d'Amazon SES pour envoyer des e-mails, cliquez [ici](https://docs.aws.amazon.com/ses/latest/dg/send-email-smtp.html).

| Nom                        | Description                                                                                |
| -------------------------- | ------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST` | Le nom d'hôte ou l'adresse IP auquel se connecter. Doit être accessible depuis le conteneur Docker |
| `OVERLEAF_EMAIL_SMTP_PORT` | Le port auquel se connecter                                                                     |
| `OVERLEAF_EMAIL_SMTP_USER` | Le nom d'utilisateur à utiliser pour s'authentifier auprès du serveur SMTP                   |
| `OVERLEAF_EMAIL_SMTP_PASS` | Le mot de passe associé au nom d'utilisateur SMTP                                             |

#### API Amazon SES

Pour en savoir plus sur l'utilisation de l'API Amazon SES pour envoyer des e-mails, cliquez [ici](https://docs.aws.amazon.com/ses/latest/dg/send-email-api.html).

| Nom                                    | Description                                 |
| -------------------------------------- | ------------------------------------------- |
| `OVERLEAF_EMAIL_AWS_SES_ACCESS_KEY_ID` | La clé d'accès, si vous utilisez AWS SES             |
| `OVERLEAF_EMAIL_AWS_SES_SECRET_KEY`    | La clé secrète, si vous utilisez AWS SES             |
| `OVERLEAF_EMAIL_AWS_SES_REGION`        | Si elle n'est pas définie, la région par défaut est US-EAST-1 |

#### AWS SES avec des rôles d'instance

| Nom                     | Description                                                                                                                      |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_DRIVER` | Lorsque cette valeur est `ses`, le système de messagerie utilise la méthode de l'API SES et s'appuie sur les rôles d'instance configurés pour envoyer les e-mails. |

#### Personnalisation

| Nom                            | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_CUSTOM_EMAIL_FOOTER` | <p>HTML personnalisé ajouté à la fin de tous les e-mails, par ex.<br /><br /><strong>Exemple</strong> : `"<div>This system is run by department x </div> <div> If you have any questions please look at our faq <a href='`<a href="https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/https:/somwhere.com'%3Ehere&#x3C;/a%3E&#x3C;/div%3E">`https://somwhere.com'>here&#x3C;/a>&#x3C;/div>`</a>`"`</p> |
