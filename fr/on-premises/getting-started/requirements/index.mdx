Lisez attentivement cette section avant de procéder à toute installation d'Overleaf.

### Prérequis pour l'installation de Server Pro et de Community Edition

<Warning>

Nous vous recommandons vivement d'exécuter Server Pro sur une version récente et stable d'Ubuntu (par exemple Ubuntu 24.04 en 2025–2026) avec une version récente de Docker. Il est possible d'exécuter Server Pro sur d'autres systèmes, mais il nous sera alors beaucoup plus difficile d'assurer le support des configurations Ubuntu/Docker non standard. Nous ne pouvons pas non plus assurer le support des problèmes liés à Docker lui-même.

</Warning>
