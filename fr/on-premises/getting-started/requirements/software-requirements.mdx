### Systèmes d'exploitation {#operating-systems}

Nous recommandons un système **Linux basé sur Debian**, comme **Ubuntu**, pour les serveurs partagés et de production. Ayakaleaf Pro peut également fonctionner sur [macOS avec Docker Desktop](/fr/on-premises/installation/using-docker-compose/macos) et sur [Windows avec WSL 2 et Docker Desktop](/fr/on-premises/installation/using-docker-compose/windows). Ces trois plateformes utilisent des conteneurs Linux et le même Toolkit ; suivez le guide correspondant au système d'exploitation de votre hôte.

<Danger>

Lorsque vous utilisez les compilations en sandbox (Sandboxed Compiles), il est **important** de noter que l'application nécessite un accès root au socket Docker.

</Danger>

### Dépendances {#dependencies}

* Docker 25.0 et 29
* MongoDB 7.0 et 8.0
* Redis 6.2 et 7.5

<Info>

Vous pouvez suivre les dates de fin de vie (EOL) des dépendances ci-dessus et d'autres produits populaires grâce au service endoflife.date : [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

MongoDB et Redis sont automatiquement téléchargés par `docker compose` lors de l'exécution d'Ayakaleaf Pro, sauf si une autre installation est configurée.

</Info>

Le Toolkit dépend des programmes suivants :

* bash
* Docker

`docker compose` est requis et est généralement installé avec Docker.

Nous vous recommandons d'installer la version la plus récente de Docker disponible pour votre système d'exploitation.

Une fois Docker correctement installé, vous devriez pouvoir exécuter ces commandes sans erreur :

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2 or later, such as v5)
docker compose version

# List the running Docker containers on your system
docker ps
```
