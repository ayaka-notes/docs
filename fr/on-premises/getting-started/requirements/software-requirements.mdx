### Systèmes d'exploitation

Pour une expérience optimale avec Overleaf, nous vous recommandons vivement d'utiliser un système d'exploitation **basé sur Debian**, comme **Ubuntu**. Ce choix correspond à l'environnement de développement du logiciel et constitue l'option privilégiée par la majorité des utilisateurs d'Overleaf.

<Danger>

Lorsque vous utilisez Server Pro avec les compilations en sandbox (Sandboxed Compiles), il est **important** de noter que l'application nécessite un accès root au socket Docker.

</Danger>

### Dépendances

* Docker 25.0 et 29
* MongoDB 7.0 et 8.0
* Redis 6.2 et 7.5

<Info>

Vous pouvez suivre les dates de fin de vie (EOL) des dépendances ci-dessus et d'autres produits populaires grâce au service endoflife.date : [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

MongoDB et Redis sont automatiquement téléchargés par `docker compose` lors de l'exécution de Server CE ou Server Pro, sauf si une autre installation est configurée.

</Info>

Le Toolkit dépend des programmes suivants :

* bash
* Docker

`docker compose` est requis et est généralement installé avec Docker.

Nous vous recommandons d'installer la version la plus récente de Docker disponible pour votre système d'exploitation.

Une fois Docker correctement installé, vous devriez pouvoir exécuter ces commandes sans erreur :

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2)
docker compose version

# List the running Docker containers on your system
docker ps
```
