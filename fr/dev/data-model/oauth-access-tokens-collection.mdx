title: Collection OAuth Access Tokens
icon: ticket
---

`oauthAccessTokens` contient les jetons bearer que web accepte. Dans Ayakaleaf Pro, ce sont les jetons d'accès personnels (jetons d'authentification Git) qu'un utilisateur crée sur la page des paramètres du compte et utilise pour git-bridge et le point de terminaison MCP. Un document correspond à un jeton. Le schéma est `services/web/app/src/models/OauthAccessToken.mjs` ; le module web `oauth2-server` écrit la collection, surtout avec le pilote natif.

#### Remarques {#notes}

* Supprimer un utilisateur ne supprime pas ses jetons. `UserDeleter` déclenche le hook `cleanupPersonalAccessTokens` (`services/web/app/src/Features/User/UserDeleter.mjs:230-234`), mais aucun module ne l'écoute. Les deux vérifications de jeton rejettent les jetons parce que l'utilisateur n'existe plus, et l'index TTL les supprime un jour après `accessTokenExpiresAt`.
* Suspendre un utilisateur ne met fin qu'aux sessions. Les jetons restent, et les deux vérifications de jeton les rejettent tant que `users.suspended` vaut `true` (`OAuth2Model.mjs:51-54`, `OAuthPersonalAccessTokenManager.mjs:129-134`).
