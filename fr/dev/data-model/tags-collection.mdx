`tags` contient les tags (dossiers) dans lesquels un utilisateur range ses projets sur le tableau de bord des projets. Un document correspond à un tag d'un utilisateur. `web` en est propriétaire ; le schéma est `services/web/app/src/models/Tag.mjs`, et toutes les écritures passent par `services/web/app/src/Features/Tags/TagsHandler.mjs`.

#### Champs {#fields}

| Champ | Type | Signification | Source |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id du tag, utilisé dans les routes `/tag/:tagId`. | `Tag.mjs:10` |
| `user_id` | String | Propriétaire du tag. Une simple chaîne, pas un ObjectId, pour des raisons historiques. | `Tag.mjs:7-12` |
| `name` | String | Nom du tag, 50 caractères au maximum (`MAX_TAG_LENGTH`). Unique par utilisateur. | `Tag.mjs:13`, `TagsHandler.mjs:4` |
| `color` | String | Couleur facultative : un code hexadécimal comme `#a1b2c3` ou une valeur `hsl(<n>, 70%, 45%)` (`TAG_COLOR_REGEX`). | `Tag.mjs:5`, `Tag.mjs:14-22` |
| `project_ids` | Array of String | Ids des projets de ce tag, sous forme de chaînes. | `Tag.mjs:23` |
| `__v` | Number | Clé de version Mongoose, ajoutée lorsque `Tag.create` crée le document. | `TagsHandler.mjs:27` |

#### Remarques {#notes}

* Les tags sont propres à chaque utilisateur : deux collaborateurs d'un même projet gardent chacun leurs propres tags pour celui-ci.
* `user_id` et `project_ids` sont des chaînes : interrogez-les avec des ids sous forme de chaînes, pas avec des ObjectId.
* La suppression d'un utilisateur (`services/web/app/src/Features/User/UserDeleter.mjs`) ne touche pas `tags`.
