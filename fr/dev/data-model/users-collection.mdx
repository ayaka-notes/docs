`users` contient un document par compte. Il stocke les données de connexion, le profil, les paramètres de l'éditeur, les fonctionnalités et l'activité. Le schéma est `services/web/app/src/models/User.mjs` ; la plupart des écritures passent par `services/web/app/src/Features/User/UserUpdater.mjs`. Dans la colonne Source, `User.mjs:N` est une ligne de ce schéma, les autres noms de fichiers sans chemin se trouvent sous `services/web/app/src/Features/`, et `modules/...` se trouve sous `services/web/`. Les numéros de ligne proviennent de `server-pro` au moment de la rédaction.

#### Indicateurs de fonctionnalités et limites (`features`) {#feature-flags-&-limits-features}

`features` est le résultat d'un calcul, pas quelque chose à modifier à la main. `FeaturesUpdater` part de `Settings.defaultFeatures`, fusionne chaque entrée de `featuresOverrides` qui n'a pas expiré et écrit le résultat avec `featuresUpdatedAt` (`FeaturesUpdater.mjs:220-300`, `UserFeaturesUpdater.mjs:10-24`). L'image de production définit `collaborators`, `dropbox`, `versioning`, `compileTimeout`, `compileGroup`, `trackChanges` et `references` comme valeurs par défaut (`server-ce/config/settings.js:301-309`) ; les autres clés restent non définies.

Dans Ayakaleaf Pro, le panneau d'administration désactive des fonctionnalités par utilisateur. Le module `admin-tools` les stocke sous forme d'entrée `featuresOverrides` avec `note: 'admin-panel'` (`modules/admin-tools/app/src/AdminFeatures.mjs:13-30`), et le module `instance-features` traite une clé non définie comme activée (`modules/instance-features/app/src/UserFeatures.mjs:12-14`).

#### Remarques {#notes}

* `autoIndex` de Mongoose est désactivé (`services/web/app/src/infrastructure/Mongoose.mjs:7`), donc seules les migrations ci-dessus créent des index.
* La suppression d'un utilisateur déplace le document entier dans `deletedUsers` (voir [Deleted Users Collection](/dev/data-model/deleted-users-collection)).
