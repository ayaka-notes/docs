`migrations` enregistre les migrations de base de données qui ont été exécutées. Un document correspond à une migration de `tools/migrations/`. Il est écrit par l'adaptateur de l'outil de migration [east](https://github.com/okv/east), `tools/migrations/lib/adapter.mjs`, et non par un service en cours d'exécution.

#### Champs {#fields}

| Champ | Type | Signification | Source |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id du document. | `adapter.mjs:103` |
| `name` | String | Nom de fichier de la migration sans l'extension, par exemple `20190912145029_create_tags_indexes`. | `adapter.mjs:104` |
| `migratedAt` | Date | Date de fin de la migration. | `adapter.mjs:105` |

#### Qui l'écrit {#who-writes-it}

| Code | Ce qu'il fait |
| --- | --- |
| `adapter.mjs:101-107` (`markExecuted`) | Insère un document après l'exécution d'une migration. |
| `adapter.mjs:109-114` (`unmarkExecuted`) | Le supprime à nouveau lorsqu'une migration est annulée. |

CE exécute `yarn run migrations migrate -t server-ce` à chaque démarrage du conteneur (`server-ce/init_scripts/900_run_web_migrations.sh:4-12` ; `-t server-pro` lorsque `OVERLEAF_IS_SERVER_PRO=true`). Seules les migrations dont les `tags` incluent cet environnement s'exécutent, donc seules celles-ci obtiennent un document ici.

#### Qui la lit {#who-reads-it}

| Code | Ce qu'il fait |
| --- | --- |
| `adapter.mjs:72-99` (`getExecutedMigrationNames`) | east ignore toute migration dont le nom figure déjà ici. |
| `tools/migrations/lib/helpers.mjs:67-75` (`assertDependency`) | Une migration qui nécessite qu'une autre ait été exécutée avant lève une erreur lorsque ce nom est absent. |

#### Index {#indexes}

| Nom | Clés | Options | Migration |
| --- | --- | --- | --- |
| `name_1` | `{ name: 1 }` | unique | `tools/migrations/20190720165251_create_migrations.mjs` |

#### Remarques {#notes}

* Supprimer un document fait réexécuter cette migration au prochain démarrage du conteneur, si ses tags correspondent.
* Avec un cluster Mongo auxiliaire (`mongo.auxUrl`), les migrations étiquetées `auxiliary` sont enregistrées à la place dans la collection `migrations` de ce cluster (`adapter.mjs:8-15`, `:64-70`). `mongo.auxUrl` provient de `MONGO_AUX_CONNECTION_STRING` (`tools/migrations/config/settings.defaults.js:19`), qui n'est pas défini par défaut.
