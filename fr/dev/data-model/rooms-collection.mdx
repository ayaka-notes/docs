`rooms` contient un document par salon de discussion d’un projet : le chat du projet, ou un fil de commentaires de relecture. Seul le service chat l’écrit, dans `services/chat/app/js/Features/Threads/ThreadManager.js`. Il n’y a pas de schéma Mongoose. Les messages d’un salon se trouvent dans la collection [messages](/fr/dev/data-model/messages-collection).

#### Champs {#fields}

| Champ | Type | Signification | Source |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Identifiant du salon. `messages.room_id` pointe ici. | `ThreadManager.js:57-61` |
| `project_id` | ObjectId | Projet auquel appartient le salon. | `ThreadManager.js:43-54` |
| `thread_id` | ObjectId | Uniquement sur les fils de commentaires : l’identifiant du commentaire, identique à `id` et `op.t` du commentaire dans `docs.ranges.comments` (voir [docs](/fr/dev/data-model/docs-collection)). Absent sur le salon du chat du projet. | `ThreadManager.js:38-55`, `services/docstore/app/js/RangeManager.js:54-57` |
| `resolved` | Object | Défini lorsque le fil est résolu, supprimé lorsqu’il est rouvert. Un fil sans ce champ est ouvert. | `ThreadManager.js:94-123` |
| `resolved.user_id` | String | Identifiant de l’utilisateur qui a résolu le fil. Stocké sous forme de chaîne, pas d’ObjectId : le corps de la requête est seulement vérifié comme identifiant valide, pas converti. | `ThreadManager.js:103`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:70` |
| `resolved.ts` | Date | Date à laquelle le fil a été résolu. | `ThreadManager.js:104` |

#### Remarques {#notes}

* Un projet a au plus un salon sans `thread_id` : le chat du projet. Le service chat le trouve avec `thread_id: { $exists: false }` (`ThreadManager.js:38-45`).
* L’état résolu d’un commentaire n’existe qu’ici. Docstore retire `op.resolved` avant d’enregistrer les plages (`services/docstore/app/js/RangeManager.js:59-61`).
* Après la copie d’un projet, le même `thread_id` existe dans deux projets. Interrogez toujours `project_id` et `thread_id` ensemble, comme le fait le service chat.
* Les salons d’un projet supprimé restent jusqu’à l’expiration du projet supprimé.
