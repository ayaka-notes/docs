`contacts` mémorise avec quels utilisateurs un utilisateur a travaillé, afin que la boîte de dialogue de partage puisse les suggérer. Un document par utilisateur. `web` en est propriétaire, sans schéma Mongoose ; le code est `services/web/app/src/Features/Contacts/ContactManager.mjs`.

#### Champs {#fields}

| Champ | Type | Signification | Source |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id du document, créé par l'upsert. | `ContactManager.mjs:5-12` |
| `user_id` | ObjectId | L'utilisateur à qui appartiennent ces contacts. Un document par utilisateur. | `ContactManager.mjs:6` |
| `contacts` | Object | Table indexée par l'id utilisateur du contact (sous forme de chaîne). | `ContactManager.mjs:8-9` |
| `contacts.<userId>.n` | Number | Nombre de fois où les deux utilisateurs ont été mis en relation. | `ContactManager.mjs:8` |
| `contacts.<userId>.ts` | Date | Date de la dernière fois. | `ContactManager.mjs:9` |

#### Qui l'écrit {#who-writes-it}

| Code | Ce qu'il fait |
| --- | --- |
| `ContactManager.mjs:4-13` (`touchContact`), `:23-28` (`addContact`) | Upsert des documents des deux utilisateurs : `$inc` sur `n`, `$set` de `ts`. |
| `services/web/app/src/Features/Collaborators/CollaboratorsHandler.mjs:155-157` | `addUserIdToProject` appelle `addContact` lorsqu'on lui fournit l'utilisateur qui ajoute : une invitation acceptée (l'invitant et l'invité, `services/web/app/src/Features/Collaborators/CollaboratorsInviteHandler.mjs:199-205`) et un transfert de propriété (nouveau et ancien propriétaire, `services/web/app/src/Features/Collaborators/OwnershipTransferHandler.mjs:138-144`). Rejoindre via un lien de partage ne fournit pas d'utilisateur qui ajoute (`services/web/app/src/Features/TokenAccess/TokenAccessController.mjs:386-388`, `:632-634`), donc aucun contact n'est ajouté. |

#### Qui la lit {#who-reads-it}

| Code | Ce qu'il fait |

| `services/web/app/src/Features/Contacts/ContactController.mjs:19-59` | `GET /user/contacts` (`services/web/app/src/Features/Contacts/ContactRouter.mjs:22-26`): renvoie les 50 premiers sous forme d'utilisateurs, sans les comptes provisoires, plus ce que les modules ajoutent via le hook `getContacts`. |

#### Remarques {#notes}

* Les contacts sont réciproques : ajouter B au projet de A fait de B un contact de A et de A un contact de B.
* Rien ne supprime un contact ou le document, pas même la suppression d'un utilisateur.
