`projectAuditLogEntries` est le journal d'audit des projets : partage, invitations, transferts de propriété, téléchargements et actions d'administration. Un document correspond à un événement sur un projet. `web` en est propriétaire ; le schéma est `services/web/app/src/models/ProjectAuditLogEntry.mjs`, et le cœur écrit via `services/web/app/src/Features/Project/ProjectAuditLogHandler.mjs`.

`tools/migrations/20220929193200_add_auditLog_indexes.mjs` a d'abord créé `project_id_1` sur `{ projectId: 1 }` ; `20250912102601` le remplace par l'index composé. Les marques `index: true` du schéma ne sont pas appliquées, car l'indexation automatique de Mongoose est désactivée (`services/web/app/src/infrastructure/Mongoose.mjs:7`). La migration de l'index `managedSubscriptionId` porte uniquement le tag `saas`.

#### Remarques {#notes}

* Les entrées expirent 2,5 ans après `timestamp` grâce à l'index TTL, et toutes les entrées d'un projet disparaissent lorsque son enregistrement de projet supprimé expire.
