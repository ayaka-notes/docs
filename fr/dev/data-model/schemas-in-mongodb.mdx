Dans cette section, nous allons présenter le modèle de données d'Overleaf. Overleaf utilise MongoDB pour la persistance des données ; l'unique base de données s'appelle `sharelatex`, du nom du prédécesseur d'Overleaf.

Si vous n'avez pas encore configuré Mongo Express pour Overleaf, nous vous recommandons vivement de consulter [setup-develop-tools.md](/fr/dev/environment/setup-develop-tools  "mention") et de configurer votre MongoDB.

Une fois Mongo Express configuré, vous pouvez vous connecter à [http://localhost:8081/](http://localhost:8081/) avec les identifiants `admin:pass`.
