title: Collection Project Invites
icon: envelope-open-text
---

`projectInvites` contient les invitations qu'un propriétaire de projet envoie depuis la boîte de dialogue de partage. Un document correspond à une invitation pour une adresse e-mail. Il est supprimé quand l'invitation est acceptée ou révoquée, ou par Mongo quand elle expire. Le schéma est `services/web/app/src/models/ProjectInvite.mjs`, et `services/web/app/src/Features/Collaborators/CollaboratorsInviteHandler.mjs` l'écrit.

Une invitation ne fait de personne un membre. Les membres se trouvent dans les tableaux `*_refs` d'un projet, voir [Collection Projects](/fr/dev/data-model/projects-collection).

#### Remarques {#notes}

* Si le projet n'a plus de place d'éditeur quand une invitation `readAndWrite` ou `review` est acceptée, l'utilisateur rejoint en lecture seule et figure dans `pendingEditor_refs` ou `pendingReviewer_refs` du projet (`CollaboratorsInviteHandler.mjs:162-205`).
* Les anciennes invitations stockaient le jeton en clair dans un champ `token`. La migration `20240524135408_add_token_hmac_project_invite_tokens.mjs` a ajouté `tokenHmac` et `20240531082910_remove_project_invite_tokens.mjs` a supprimé `token`.
* Rien ne supprime les invitations d'un projet supprimé ; elles restent jusqu'à ce que l'index TTL les supprime.
