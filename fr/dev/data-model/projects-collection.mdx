`Project` représente un projet LaTeX unique dans Overleaf. Il stocke les métadonnées du projet, la propriété et le contrôle d'accès, la structure des fichiers, les paramètres de compilation et l'état de la collaboration.

#### Identification et métadonnées principales

* `_id` : ObjectId MongoDB unique identifiant le projet.
* `name` : nom d'affichage du projet.
* `description` : description textuelle facultative du projet.
* `active` : indique si le projet est actuellement actif.
* `version` : version interne du schéma ou du format de projet.
* `trashed` : liste des éléments déplacés dans la corbeille (suppression logique).
* `deletedDocs` : enregistrements des documents supprimés définitivement.

#### Propriété et contrôle d'accès

* `owner_ref` : référence à l'utilisateur propriétaire du projet.
* `collaberator_refs` : utilisateurs disposant de droits de modification.
* `reviewer_refs` : utilisateurs disposant d'un accès de niveau relecteur.
* `readOnly_refs` : utilisateurs disposant d'un accès en lecture seule.
* `pendingEditor_refs` / `pendingReviewer_refs` : invitations en attente.

#### Accès par jeton

* `tokens` : registre des jetons pour les liens partagés.
* `tokenAccessReadOnly_refs` : jetons accordant un accès en lecture seule.
* `tokenAccessReadAndWrite_refs` : jetons accordant un accès en lecture et écriture.

#### Suivi de l'activité

* `lastUpdated` : horodatage de la modification la plus récente.
* `lastUpdatedBy` : utilisateur ayant effectué la dernière mise à jour.
* `lastOpened` : horodatage de la dernière ouverture du projet.
* `deletedByExternalDataSource` : indique si la suppression a été déclenchée par une intégration externe.

#### Structure du projet

Document racine et dossier racine

* `rootDoc_id` : ObjectId du document LaTeX principal (généralement `main.tex`).
* `rootFolder` : représentation intégrée de l'arborescence des fichiers du projet.

Chaque entrée de dossier contient :

* `name` / `_id` : nom et identifiant du dossier.
* `docs` : liste des documents sources LaTeX avec leur nom et leur `_id`.
* `fileRefs` : références aux fichiers binaires (images, fichiers de données), comprenant :
  * `name` : nom du fichier
  * `created` : horodatage du téléversement
  * `rev` : compteur de révisions
  * `hash` : hachage du contenu pour la déduplication
  * `linkedFileData` : liaison vers un stockage externe (le cas échéant)
* `folders` : sous-dossiers imbriqués.

#### Paramètres de compilation et de l'éditeur

* `compiler` : moteur LaTeX sélectionné (`pdflatex`, `xelatex`, `lualatex`, etc.).
* `spellCheckLanguage` : langue du correcteur orthographique pour ce projet.

#### Paramètres publics et de partage

* `publicAccesLevel` : visibilité du projet (`private`, `readOnly`, `public`, etc.).
* `collabratecUsers` : utilisateurs liés provenant de plateformes de collaboration externes.

#### Extensions propres à Overleaf

* `overleaf.history` :
  * `id` : identifiant utilisé par le service d'historique.
  * `display` : indique si l'historique est activé et visible.

#### Gestion interne des versions

* `__v` : clé de version interne de Mongoose pour le contrôle de la concurrence.
