---
title: Collection Project History Labels
icon: tag
---

`projectHistoryLabels` contient les libellés que les utilisateurs posent sur des versions dans la vue Historique, un document par libellé. project-history en est propriétaire et l’écrit dans `services/project-history/app/js/LabelsManager.js` ; il n’y a pas de schéma Mongoose. Web n’y accède que via l’API de project-history.

#### Champs {#fields}

| Champ | Type | Signification | Source |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Identifiant du libellé. | `LabelsManager.js:81-85` |
| `project_id` | ObjectId | Le projet. | `LabelsManager.js:73` |
| `comment` | String | Le texte du libellé. | `LabelsManager.js:74` |
| `version` | Number | La version de l’historique du projet visée par le libellé. | `LabelsManager.js:75` |
| `created_at` | Date | Date de création du libellé ; la requête peut fournir sa propre heure, sinon c’est maintenant. | `LabelsManager.js:70`, `76` |
| `user_id` | ObjectId | Auteur du libellé. Omis lorsque la requête n’a pas d’utilisateur. | `LabelsManager.js:78-80` |

#### Qui l’écrit {#who-writes-it}

| Code | Ce qu’il fait |
| ---- | ------------ |
| `services/project-history/app/js/LabelsManager.js:44-90` | `createLabel` : insère un libellé, pour project-history `POST /project/:project_id/labels` (`services/project-history/app/js/HttpController.js:1134-1171`). Web l’appelle lorsqu’un utilisateur ajoute un libellé, avec l’identifiant de l’utilisateur (`services/web/app/src/Features/History/HistoryController.mjs:529-546`). |
| `LabelsManager.js:113-126` | `deleteLabel` : supprime un libellé du projet, pour `DELETE /project/:project_id/labels/:label_id`. Web l’utilise lorsque le propriétaire du projet supprime un libellé (`HistoryController.mjs:649-670`). |
| `LabelsManager.js:92-111` | `deleteLabelForUser` : supprime un libellé uniquement si l’utilisateur l’a créé, pour `DELETE /project/:project_id/user/:user_id/labels/:label_id`. Web l’utilise pour tous les autres. |
| `LabelsManager.js:128-143` | `transferLabels` : transfère tous les libellés d’un utilisateur à un autre, pour `POST /user/:from_user/labels/transfer/:to_user` (`services/project-history/app/js/Router.js:52-55`). Rien dans web n’appelle cette route. |
| `LabelsManager.js:7-25` | `cloneLabels` : copie les libellés d’un projet vers un autre projet, pour project-history `POST /project/:project_id/clone` (`HttpController.js:113`), que rien dans web n’appelle. |

#### Remarques {#notes}

* Avant d’insérer un libellé, project-history traite les mises à jour en attente du projet et vérifie que history-v1 possède un chunk pour cette version, sauf si la requête envoie `validate_exists: false` (`LabelsManager.js:53-59`, `173-195` ; `HttpController.js:1109-1115`).
* Aucun code ne supprime les libellés d’un projet lorsque le projet est supprimé : project-history `DELETE /project/:project_id` efface seulement l’état de synchronisation et l’enregistrement d’échec (`HttpController.js:1363-1396`), et aucun autre service ne touche cette collection.
