`userAuditLogEntries` est le journal d'audit des comptes utilisateurs : connexions, changements de mot de passe et d'e-mail, comptes associés et actions d'administration. Un document correspond à un événement sur un compte. `web` en est propriétaire ; le schéma est `services/web/app/src/models/UserAuditLogEntry.mjs`, et le cœur écrit via `services/web/app/src/Features/User/UserAuditLogHandler.mjs`.

`tools/migrations/20220929193200_add_auditLog_indexes.mjs` a d'abord créé `user_id_1` sur `{ userId: 1 }` ; `20251117093546` le remplace par l'index composé. Le schéma marque `userId` et `managedSubscriptionId` avec `index: true`, mais l'indexation automatique de Mongoose est désactivée (`services/web/app/src/infrastructure/Mongoose.mjs:7`), donc seules les migrations ci-dessus créent des index. La migration de l'index `managedSubscriptionId` porte uniquement le tag `saas`.

#### Remarques {#notes}

* Les entrées expirent 2,5 ans après `timestamp` grâce à l'index TTL.
