`spellingPreferences` contient le dictionnaire de chaque utilisateur : les mots que l'utilisateur a ajoutés via "Add to dictionary" dans le correcteur orthographique de l'éditeur. Un document par utilisateur. `web` en est propriétaire, sans schéma Mongoose ; le code est `services/web/app/src/Features/Spelling/LearnedWordsManager.mjs`.

#### Champs {#fields}

| Champ | Type | Signification | Source |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id du document, créé par l'upsert. | `LearnedWordsManager.mjs:21-31` |
| `token` | String | L'id de l'utilisateur. Malgré le nom, les routes d'orthographe transmettent l'id de l'utilisateur connecté (`SessionManager.getLoggedInUserId`). | `LearnedWordsManager.mjs:23` |
| `learnedWords` | Array of String | Les mots ajoutés par l'utilisateur. | `LearnedWordsManager.mjs:26` |

#### Qui l'écrit {#who-writes-it}

| Code | Ce qu'il fait |
| --- | --- |
| `LearnedWordsManager.mjs:13-32` (`learnWord`) | `POST /spelling/learn` (`services/web/app/src/router.mjs:1037-1041`, `services/web/app/src/Features/Spelling/SpellingController.mjs:45-58`): `$addToSet` du mot, avec upsert. Refuse lorsque la liste dépasserait `Settings.maxDictionarySize` octets. |
| `LearnedWordsManager.mjs:38-47` (`unlearnWord`) | `POST /spelling/unlearn` (`router.mjs:1043-1047`, `SpellingController.mjs:66-79`): `$pull` du mot. |
| `LearnedWordsManager.mjs:84-86` (`deleteUsersLearnedWords`) | Supprime le document. Son seul wrapper, `SpellingHandler.deleteUserDictionary` (`services/web/app/src/Features/Spelling/SpellingHandler.mjs:24-26`), n'a aucun appelant dans web ni dans ses modules. |

#### Qui la lit {#who-reads-it}

| Code | Ce qu'il fait |
| --- | --- |
| `LearnedWordsManager.mjs:52-67` (`getLearnedWords`) | Renvoie les mots sans doublons. |
| `services/web/app/src/Features/Project/ProjectController.mjs:671` | Envoie le dictionnaire à l'éditeur à l'ouverture d'un projet (`SpellingHandler.getUserDictionary`). |

* La suppression d'un utilisateur ne supprime pas ce document.
