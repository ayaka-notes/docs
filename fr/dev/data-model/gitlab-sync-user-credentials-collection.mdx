---
title: Collection GitLab Sync User Credentials
icon: user-lock
---

`gitlabSyncUserCredentials` contient un document par utilisateur ayant lié un compte GitLab pour GitLab Sync. Elle stocke les jetons OAuth de l'utilisateur, chiffrés. La collection appartient au module web `gitlab-sync` (`services/web/modules/gitlab-sync`). Le schéma se trouve dans `services/web/modules/gitlab-sync/app/models/gitlabSyncUserCredentials.mjs`, et tout accès passe par `services/web/modules/gitlab-sync/app/src/TokenManager.mjs`.

#### Champs {#fields}

| Champ | Type | Signification | Source |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Défini par Mongoose quand l'upsert insère. | |
| `userId` | ObjectId | L'utilisateur Overleaf. Obligatoire. Le schéma indique `unique: true`, mais aucun index n'est créé (voir Index) ; l'upsert par `userId` conserve un document par utilisateur. | `gitlabSyncUserCredentials.mjs:8`, `TokenManager.mjs:88-95` |
| `gitlab` | String | Le JSON `{ accessToken, refreshToken, expiresAt }`, chiffré avec `@overleaf/access-token-encryptor`. `expiresAt` est en millisecondes depuis l'epoch, ou `null` ; `refreshToken` peut valoir `null`. Le mot de passe vient de `GITLAB_TOKEN_CIPHER_PASSWORD` ; le libellé de chiffrement est `GITLAB_TOKEN_CIPHER_LABEL`, par défaut `2026.10-v3`. Obligatoire. | `gitlabSyncUserCredentials.mjs:9-10`, `TokenManager.mjs:18-31`, `services/web/modules/gitlab-sync/app/src/GitLabApiClient.mjs:209-220` |
| `__v` | Number | La clé de version Mongoose. Le schéma ne la désactive pas. | Valeur par défaut de Mongoose |

#### Qui l'écrit {#who-writes-it}

| Code | Ce qu'il fait |
| ---- | ------------ |
| `TokenManager.mjs:88-95` (`saveUserToken`) | Fait un upsert des identifiants chiffrés de l'utilisateur. |
| `TokenManager.mjs:99-108` (`linkUserToken`) | Enregistre les nouveaux identifiants issus du callback OAuth (`services/web/modules/gitlab-sync/app/src/GitLabSyncController.mjs:146`). Quand l'utilisateur lie à nouveau son compte, le jeton d'accès remplacé est révoqué chez GitLab en arrière-plan. |
| `TokenManager.mjs:53-78` (`refreshUserToken`) | Quand le jeton d'accès est à moins de 5 minutes de `expiresAt` (`:13,47-49`), il obtient de nouveaux jetons avec le jeton de rafraîchissement et les enregistre (`:75`). Il s'exécute sous le verrou `gitlabSyncToken` par utilisateur (`:15,54`), car GitLab consomme un jeton de rafraîchissement à son utilisation. |
| `TokenManager.mjs:111-126` (`removeUserToken`) | Révoque le jeton d'accès chez GitLab (au mieux), puis supprime le document. Appelé lors de la dissociation (`GitLabSyncController.mjs:173`) et quand un utilisateur supprimé expire (`services/web/modules/gitlab-sync/index.mjs:56-58`). |

#### Qui la lit {#who-reads-it}

| Code | Ce qu'il fait |
| ---- | ------------ |
| `TokenManager.mjs:41-45,81-85` (`getUserCredentials`, `getUserToken`) | Déchiffre les identifiants pour chaque appel à l'API GitLab, en les rafraîchissant d'abord quand le jeton est sur le point d'expirer : `services/web/modules/gitlab-sync/app/src/GitLabSyncHandler.mjs` (par exemple `:27`) et `services/web/modules/gitlab-sync/app/src/GitMerge.mjs:52`. Sans document, ou avec des identifiants impossibles à déchiffrer ou à rafraîchir, il lève `InvalidTokenError`, et l'utilisateur est considéré comme non lié (`GitLabSyncHandler.mjs:25-37`). |
| `services/web/modules/admin-tools/app/src/AdminUserListManager.mjs:394` | Vérifie si l'utilisateur a un document, pour les intégrations affichées dans le panneau d'administration. |

#### Index {#indexes}

| Nom | Clés | Options | Migration |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

L'`autoIndex` de Mongoose est désactivé (`services/web/app/src/infrastructure/Mongoose.mjs:7`), donc le `unique: true` du schéma sur `userId` ne crée rien. Aucune migration ne crée d'index pour cette collection.

#### Remarques {#notes}

* Modifier `GITLAB_TOKEN_CIPHER_PASSWORD` rend les identifiants stockés illisibles. Ces utilisateurs sont alors considérés comme non liés jusqu'à ce qu'ils lient à nouveau leur compte.
* Un utilisateur supprimé conserve le document jusqu'à son expiration.
