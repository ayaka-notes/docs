title: Collection Tokens
icon: key
---

`tokens` contient les jetons à usage unique : le secret contenu dans un lien qui permet à quelqu'un de définir un mot de passe. Un document correspond à un jeton. Il n'y a pas de modèle Mongoose ; web écrit la collection via `services/web/app/src/Features/Security/OneTimeTokenHandler.mjs` avec le pilote natif.

#### Champs {#fields}

| `usedAt` | Date | Date à laquelle le jeton a été utilisé ou annulé. Les recherches ignorent un jeton qui en a une. | `OneTimeTokenHandler.mjs:51-104` |

#### Qui écrit {#who-writes-it}

| Code | Rôle |
| ---- | ------------ |
| `OneTimeTokenHandler.mjs:34-49` (`getNewToken`) | Insère un jeton. Appelants : `PasswordResetHandler.mjs:28`, `UserRegistrationHandler.mjs:115-119`, `AdminUserManager.mjs:77-81`. |
| `OneTimeTokenHandler.mjs:8-32` (`peekValueFromToken`) | Renvoie `data` d'un jeton valide et ajoute 1 à `peekCount`. Utilisé à l'ouverture de la page de réinitialisation du mot de passe (`services/web/app/src/Features/PasswordReset/PasswordResetController.mjs:195-208`), de nouveau lors de la définition du nouveau mot de passe (`PasswordResetHandler.mjs:94-96`), et par la confirmation d'e-mail (`UserEmailsConfirmationHandler.mjs:38-41`). |
| `OneTimeTokenHandler.mjs:75-88` (`expireToken`) | Définit `usedAt` sur un jeton : après la définition d'un nouveau mot de passe (`PasswordResetHandler.mjs:44-48,119`) ou la confirmation d'une adresse e-mail (`UserEmailsConfirmationHandler.mjs:65`). |
| `OneTimeTokenHandler.mjs:90-104` (`expireAllTokensForUser`) | Définit `usedAt` sur chaque jeton `password` ouvert d'un utilisateur, quand l'utilisateur change son mot de passe dans les paramètres (`services/web/app/src/Features/User/UserController.mjs:146-149`) ou qu'un administrateur le définit dans le panneau d'administration (`AdminUserManager.mjs:479-488`). |

#### Remarques {#notes}

* Un jeton utilisé ou expiré n'est pas supprimé tout de suite : il reste, avec `usedAt` ou un `expiresAt` passé, jusqu'à ce que l'index TTL le supprime 90 jours après `createdAt`.
* `OneTimeTokenHandler` possède aussi `getValueFromTokenAndExpire` (`OneTimeTokenHandler.mjs:51-73`), mais rien ne l'appelle.
