CLSI (Common LaTeX Service Interface) compile les projets, exécute SyncTeX et texcount sur la sortie de compilation et convertit des documents avec pandoc. Web l'appelle ; les fichiers de sortie eux-mêmes sont servis par clsi-nginx, pas par ce port. Pas d'authentification : il n'est accessible que dans le réseau Docker.

* <strong>Adresse :</strong> `http://clsi:3013`, dans le réseau Docker
* <strong>Authentification :</strong> aucune
* <strong>Fichier OpenAPI :</strong> [`develop/hoppscotch/openapi/clsi.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/clsi.yaml)
