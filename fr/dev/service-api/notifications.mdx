Stocke les notifications affichées aux utilisateurs dans la liste des projets (par exemple les invitations à un projet) dans la collection Mongo `notifications`. Web et third-party-datastore l'appellent ; il n'a pas d'authentification et n'est accessible que dans le réseau Docker.

* <strong>Adresse :</strong> `http://notifications:3042`, dans le réseau Docker
* <strong>Authentification :</strong> aucune
* <strong>Fichier OpenAPI :</strong> [`develop/hoppscotch/openapi/notifications.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/notifications.yaml)
