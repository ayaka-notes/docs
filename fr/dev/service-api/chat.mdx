Stocke le chat du projet et les fils de commentaires (leurs messages et leur état résolu) dans les collections Mongo `rooms` et `messages`. Appelé par web via `ChatApiHandler`.

* <strong>Adresse :</strong> `http://chat:3010`, dans le réseau Docker
* <strong>Authentification :</strong> aucune
* <strong>Fichier OpenAPI :</strong> [`develop/hoppscotch/openapi/chat.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/chat.yaml)
