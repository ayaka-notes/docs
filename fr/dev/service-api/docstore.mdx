title: docstore
icon: database
---

Stocke chaque document (lignes, version, plages) de chaque projet dans la collection Mongo `docs`, et archive les documents dans un stockage objet lorsqu'un backend est défini. Appelé par web ; document-updater y accède via web.

* <strong>Adresse :</strong> `http://docstore:3016`, dans le réseau Docker
* <strong>Authentification :</strong> aucune
* <strong>Fichier OpenAPI :</strong> [`develop/hoppscotch/openapi/docstore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/docstore.yaml)
