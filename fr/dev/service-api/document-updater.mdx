Conserve dans Redis les documents ouverts dans l'éditeur, leur applique les modifications et les réécrit dans Mongo via web. Appelé par web et real-time.

* <strong>Adresse :</strong> `http://document-updater:3003`, dans le réseau Docker
* <strong>Authentification :</strong> aucune
* <strong>Fichier OpenAPI :</strong> [`develop/hoppscotch/openapi/document-updater.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/document-updater.yaml)
