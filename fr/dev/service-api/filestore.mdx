Sert des fichiers depuis le stockage objet : les fichiers de modèles (zip, pdf et leurs images d'aperçu) et, en lecture seule, les blobs de projet et globaux écrits par history-v1. Appelé par web (module template-gallery, URL des fichiers de compilation) et par clsi, qui y télécharge les fichiers binaires des projets.

* <strong>Adresse :</strong> `http://filestore:3009`, dans le réseau Docker
* <strong>Authentification :</strong> aucune
* <strong>Fichier OpenAPI :</strong> [`develop/hoppscotch/openapi/filestore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/filestore.yaml)
