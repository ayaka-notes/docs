Met en file d'attente dans Redis les modifications de chaque projet, les transforme en modifications d'historique et les envoie à history-v1 ; il conserve aussi les étiquettes d'historique, l'état de resynchronisation et les enregistrements d'échec dans Mongo. Appelé par web, document-updater, history-v1 et les scripts cron de server-ce ; il n'a pas d'authentification.

* <strong>Adresse :</strong> `http://project-history:3054`, dans le réseau Docker
* <strong>Authentification :</strong> aucune
* <strong>Fichier OpenAPI :</strong> [`develop/hoppscotch/openapi/project-history.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/project-history.yaml)
