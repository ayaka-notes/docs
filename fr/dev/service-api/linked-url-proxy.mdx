title: linked-url-proxy
icon: link
---

Récupère une URL externe pour web et renvoie la réponse en flux, en refusant les adresses internes afin que les utilisateurs ne puissent pas atteindre le réseau Docker. Web y fait passer les fichiers URL, les imports Open in Overleaf et le web_fetch de l'agent IA.

* <strong>Adresse :</strong> `http://linked-url-proxy:3066`, dans le réseau Docker
* <strong>Authentification :</strong> aucune
* <strong>Fichier OpenAPI :</strong> [`develop/hoppscotch/openapi/linked-url-proxy.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/linked-url-proxy.yaml)
