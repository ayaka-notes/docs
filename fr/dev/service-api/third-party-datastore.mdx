Synchronise les projets avec Dropbox : il tient une file de tâches Redis par utilisateur et un worker qui envoie les modifications d'Overleaf à Dropbox et interroge Dropbox pour détecter les modifications. Seul web l'appelle, pour ajouter des tâches et lire la taille des files.

* <strong>Adresse :</strong> `http://third-party-datastore:3002`, dans le réseau Docker
* <strong>Authentification :</strong> aucune
* <strong>Fichier OpenAPI :</strong> [`develop/hoppscotch/openapi/third-party-datastore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/third-party-datastore.yaml)
