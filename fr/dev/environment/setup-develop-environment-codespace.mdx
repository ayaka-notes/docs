Pour gagner du temps et mettre en place rapidement l'environnement de développement, nous proposons une autre version de la configuration de l'environnement de développement : GitHub Codespace.

## Tutoriel de configuration

<Steps>
<Step title="Créer un Codespace">
Cliquez sur le bouton suivant pour créer un codespace cloud destiné au développement de server-pro.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/overleaf-pro)

Il est recommandé de choisir un **Machine Type** d'au moins **4-core**. Pour un type de machine plus puissant, vous pouvez adresser une demande à l'équipe de support officielle de GitHub en ouvrant un ticket [ici](https://support.github.com/contact?tags=rr-codespaces%2Ccat_codespaces).

<Frame>
  <img src="/images/dev/image.png" alt="" />
</Frame>
</Step>

<Step title="Lancer le script de configuration">
Vous devrez patienter le temps que le codespace soit créé. Une fois que vous avez accès à votre terminal, exécutez la commande suivante :

```text
cd develop/
bin/setup
```

<Frame>
  <img src="/images/dev/image-1.png" alt="" />
</Frame>

<Warning>

Ce script (`bin/setup`) vous permet de configurer l'environnement de développement sur le dernier commit de la branche `server-pro` dans les meilleurs délais. Il peut ne pas convenir aux versions plus anciennes ou à d'autres branches.

Nous construisons chaque jour l'image Docker de développement avec [GitHub Action](https://github.com/ayaka-notes/overleaf-pro/actions).

</Warning>
</Step>

<Step title="Accéder à votre Launchpad">
Passez à l'onglet des ports : vous verrez la liste des ports web disponibles. Cliquez sur celui portant le numéro `80`. La page Launchpad devrait maintenant s'afficher.

<Frame>
  <img src="/images/dev/image-2.png" alt="" />
</Frame>

Vous verrez :

<Frame>
  <img src="/images/dev/image-3.png" alt="" />
</Frame>
</Step>

<Step title="Bon développement">
C'est maintenant à vous de jouer ! Commencez à développer vos superbes fonctionnalités. Vous devez exécuter la commande suivante pour activer l'affichage en temps réel :

```bash title="bash" wrap
docker compose -f docker-compose.yml -f docker-compose.dev.yml -f ./docker-compose.image.yml up --no-deps --detach
```
</Step>
</Steps>
