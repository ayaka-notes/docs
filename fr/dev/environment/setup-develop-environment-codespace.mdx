Pour gagner du temps et mettre en place rapidement l'environnement de développement, nous proposons une autre version de la configuration de l'environnement de développement : GitHub Codespace.

## Tutoriel de configuration

<Steps>
<Step title="Créer un Codespace">
Cliquez sur le bouton suivant pour créer un Codespace dans le cloud pour le développement de server-pro.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/ayakaleaf-pro)

Il est recommandé de choisir un **type de machine** d'au moins **4 cœurs**. Pour un type de machine plus puissant, vous pouvez en faire la demande auprès de l'équipe de support officielle de GitHub en ouvrant un ticket [ici](https://support.github.com/contact?tags=rr-codespaces%2Ccat_codespaces).

<Frame>
  <img src="/images/dev/image.png" alt="" />
</Frame>
</Step>

<Step title="Lancer le script de configuration">
Vous devrez patienter le temps que le Codespace soit créé. Une fois que vous avez accès à votre terminal, exécutez la commande suivante :

```text
cd develop/
bin/setup
```

<Frame>
  <img src="/images/dev/image-1.png" alt="" />
</Frame>

<Warning>

Ce script (`bin/setup`) vous permet de configurer l'environnement de développement sur le dernier commit de la branche `server-pro` en un minimum de temps. Il peut ne pas convenir aux versions plus anciennes ou aux autres branches.

Nous construisons chaque jour l'image Docker de développement avec [GitHub Action](https://github.com/ayaka-notes/ayakaleaf-pro/actions).

</Warning>
</Step>

<Step title="Accéder à votre Launchpad">
Passez à l'onglet des ports : vous verrez la liste des ports web disponibles. Cliquez sur celui portant le numéro `80`. La page Launchpad devrait alors s'afficher.

<Frame>
  <img src="/images/dev/image-2.png" alt="" />
</Frame>

Vous verrez :

<Frame>
  <img src="/images/dev/image-3.png" alt="" />
</Frame>
</Step>

<Step title="Bon développement">
C'est maintenant à vous de jouer ! Commencez à développer vos fonctionnalités. Vous devez exécuter la commande suivante pour activer l'affichage en temps réel :

```bash title="bash" wrap
docker compose -f docker-compose.yml -f docker-compose.dev.yml -f ./docker-compose.image.yml up --no-deps --detach
```
</Step>
</Steps>
