---
title: Mettre à jour les traductions i18n
icon: language
---

Le fichier `services/web/frontend/extracted-translations.json` contient les traductions extraites ; l'application web d'Overleaf n'utilise que les traductions extraites présentes dans ce fichier.

Exécutez la commande suivante pour mettre à jour les traductions extraites si vous avez ajouté du contenu.

```bash
user ➜ ~/overleaf-pro/develop (server-pro) $ bin/shell webpack
root@432836260f8a:/overleaf/services/web# npm run extract-translations
```

En règle générale, ne modifiez pas les fichiers de traduction et utilisez d'abord les traductions existantes, car tous ces fichiers sont mis à jour à partir de l'Overleaf amont ou d'un site de traduction tiers.
