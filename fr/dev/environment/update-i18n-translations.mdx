---
title: Mettre à jour les traductions i18n
icon: language
---

Le fichier `services/web/frontend/extracted-translations.json` existe, et le service web d'Overleaf n'utilise que les traductions extraites présentes dans ce fichier.

Exécutez la commande suivante pour mettre à jour les traductions extraites si vous avez ajouté du contenu.

```bash
user ➜ ~/overleaf-pro/develop (server-pro) $ bin/shell webpack
root@432836260f8a:/overleaf/services/web# npm run extract-translations
```

De manière générale, évitez de modifier les fichiers texte de traduction et réutilisez d'abord les traductions existantes, car tous ces fichiers sont mis à jour depuis le dépôt amont d'Overleaf ou depuis un site de traduction tiers.
