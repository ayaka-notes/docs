### <Icon icon="docker" iconType="brands" /> $\TeX$ Live dans Docker, construit par @Ayaka-Notes

Overleaf utilise des conteneurs **Docker** pour compiler vos projets $\LaTeX$. Votre projet est compilé dans une sandbox Docker isolée, ce qui garantit une **sécurité** absolue.

Nous fournissons donc une image $\TeX$ Live (de 2019 à la plus récente) qui permet de passer librement d'une version à l'autre, avec toutes les polices et tous les paquets $\LaTeX$.
