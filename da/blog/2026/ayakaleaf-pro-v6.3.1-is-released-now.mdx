Vi er meget stolte af at kunne annoncere udgivelsen af Overleaf Pro 6.3.1, den mest kraftfulde og funktionsrige online LaTeX-editor i fællesskabet. En patch-udgivelse betyder som regel en håndfuld små rettelser. Denne går meget længere: ud over snesevis af fejlrettelser bringer den fem nye funktioner, og den forbinder dine projekter med de steder, hvor du allerede arbejder, fra Dropbox og GitLab til AI-agenten i din terminal.

### Ændringer

* Dropbox-synkronisering (tidlig forhåndsversion): hold hvert projekt synkroniseret med din egen Dropbox i begge retninger.
* GitLab-synkronisering (tidlig forhåndsversion): tovejssynkronisering med GitLab.com eller din selvadministrerede GitLab.
* MCP-server: lad Claude Code, Codex, Cursor, VS Code eller Gemini CLI arbejde direkte på et projekt.
* GitHub Enterprise: peg GitHub-synkronisering mod din egen GitHub Enterprise-instans.
* Genkendelse af håndtegnede symboler: tegn et symbol, og få LaTeX-kommandoen.
* `OVERLEAF_DISABLE_LOCAL_LOGIN`: skjul login med e-mail og adgangskode, så brugerne kun logger ind med SSO.
* Fejlrettelser fundet af vores E2E-testsystem og Internal Horizon Issue Investigation.
* Upstream Overleaf 6.3.1-patches.

<Info>

Dropbox-synkronisering og GitLab-synkronisering leveres i 6.3.1 som **tidlige forhåndsversioner** til gradvis test og vil blive officielt udgivet i v6.4.0. Deres konfiguration og adfærd kan stadig ændre sig inden da. Begge er slået fra som standard. Rapportér venligst eventuelle problemer på [GitHub](https://github.com/ayaka-notes/ayakaleaf-pro/issues).

</Info>

#### Funktion 01: Dropbox-synkronisering (forhåndsversion)

Nogle mennesker vil aldrig tænke på Git. De vil bare have, at deres afhandling er en mappe på deres bærbare, og det er præcis, hvad Dropbox-synkronisering giver dem. Hver bruger tilknytter sin egen Dropbox-konto, og de projekter, brugeren ejer eller har fået delt, vises under `Apps/<your app name>/`. Redigér i Overleaf, og ændringen dukker op i Dropbox. Redigér filen lokalt i din foretrukne editor, gem den, og ændringen kommer tilbage til Overleaf via en signeret webhook.

For administratorer: Git bridge skal være aktiveret. Opret en app i Dropbox App Console, og sæt derefter `DROPBOX_ENABLED`, `DROPBOX_APP_KEY`, `DROPBOX_APP_SECRET`, `DROPBOX_APP_NAME` og `DROPBOX_TOKEN_CIPHER_PASSWORD`. `DROPBOX_SYNC_PROXY_URL` er valgfri og beregnet til servere, der ikke kan nå Dropbox direkte. Opret derefter de MongoDB-indekser, som Dropbox-synkronisering har brug for, én gang, før brugerne tilknytter deres konti.

Se [Dropbox-synkronisering](/da/on-premises/configuration/overleaf-toolkit/dropbox-synchronisation  "mention") for den fulde opsætningsvejledning.

#### Funktion 02: GitLab-synkronisering (forhåndsversion)

GitHub-synkronisering har været en af vores mest elskede funktioner siden 6.2, og mange universiteter og virksomheder opbevarer i stedet deres kode på GitLab. GitLab-synkronisering fungerer på samme måde: tilknyt din konto, importér et repository fra menuen for nyt projekt, eller eksportér et projekt til et nyt GitLab-projekt. Push og pull derefter fra editoren, og merge via merge requests.

Det fungerer med GitLab.com og med selvadministreret GitLab 15.10 eller nyere. Sæt `GITLAB_SYNC_ENABLED`, `GITLAB_SYNC_CLIENT_ID`, `GITLAB_SYNC_CLIENT_SECRET` og `GITLAB_TOKEN_CIPHER_PASSWORD` samt `GITLAB_SYNC_URL` for en selvadministreret instans.

Se [GitLab-synkronisering](/da/on-premises/configuration/overleaf-toolkit/gitlab-synchronisation  "mention") for den fulde opsætningsvejledning.

#### Funktion 03: MCP-server

I 6.3 satte vi en AI-assistent ind i editoren. I 6.3.1 åbner vi døren den anden vej: hvert projekt har nu sin egen MCP-server, så den AI-agent, du allerede bruger, kan arbejde direkte på din artikel. Bed Claude Code om at rette tastefejlene i indledningen, bed Codex om at kompilere og rette LaTeX-fejlene, eller bed Cursor om at besvare de åbne gennemsynskommentarer. Agenten læser og redigerer filer live, så du og dine samarbejdspartnere ser dens redigeringer dukke op i editoren, mens den skriver. Den kan også kompilere, læse loggen, hente PDF'en, tælle ord og vise versioner.

Endpointet er `/project/<project_id>/mcp`. Godkend med det samme Git-token, som du bruger til `git clone`. Adgangen følger projektets delingsindstillinger, så en viewers agent kan læse, men ikke redigere, og hvert værktøj er hastighedsbegrænset. Der er intet andet at konfigurere: MCP-serveren aktiveres sammen med Git bridge.

Se [MCP-server](/da/on-premises/configuration/overleaf-toolkit/mcp-server  "mention") for, hvordan du forbinder hver AI-klient.

#### Funktion 04: GitHub Enterprise

GitHub-synkronisering er ikke længere begrænset til github.com. Sæt `GITHUB_SYNC_URL` til din GitHub Enterprise Server eller til GitHub Enterprise Cloud med dataresidens (`GHE.com`), så udledes REST- og GraphQL-endpoints ud fra den. Hvis din instans gør noget usædvanligt, kan du tilsidesætte dem med `GITHUB_SYNC_API_URL` og `GITHUB_SYNC_GRAPHQL_URL`. Lad dem være usat, så forbliver alt på github.com.

Se [GitHub-synkronisering](/da/on-premises/configuration/overleaf-toolkit/github-synchronisation#github-enterprise  "mention") for detaljer.

#### Funktion 05: Genkendelse af håndtegnede symboler

Du ved, hvordan symbolet ser ud, men ikke hvad det hedder. Er det `\varsigma` eller `\zeta`? `\models` eller `\vDash`? Skift symbolpaletten til tegnetilstand, skitsér symbolet med din mus eller dit trackpad, og paletten foreslår de matchende LaTeX-kommandoer.

Genkendelsen kører helt i browseren med en model trænet af ayaka-notes, så intet af det, du tegner, forlader din maskine. Tegneknappen er skjult i browsere uden `OffscreenCanvas` (f.eks. Safari 15).

#### Fejlrettelser

Denne udgivelse bringer også en lang liste af rettelser. Mange af dem blev fundet af vores nye E2E-testsystem, som nu dagligt kører testsuiter for hvert modul, og af Internal Horizon Issue Investigation: hver gang vi retter en fejl, gennemsøger vi hele kodebasen for lignende fejl, før vi lukker den.

* **Godkendelse**: lokale konti kan angive og ændre deres adgangskode på SSO-instanser, og OIDC-brugere kan ikke længere ændre deres egen e-mail. LDAP-, SAML- og OIDC-login mislykkes ikke længere, når en navneattribut har flere værdier, og SAML/OIDC-logout virker igen.
* **Suspenderede brugere**: suspendering af en bruger afslutter nu brugerens sessioner og lukker brugerens åbne editorer, og brugerens Git-tokens og MCP-downloads afvises.
* **GitHub-synkronisering**: kun ejeren kan eksportere et projekt, redigeringer foretaget under pull forbliver afventende, tomme filer synkroniseres, og manuelle merges verificeres på GitHub.
* **Zotero / Mendeley**: du får en besked om gentilknytning, når dine loginoplysninger holder op med at virke, og referencer genindekseres efter en import.
* **Eksterne tjenester**: forespørgsler til Zotero, Mendeley, GitHub, GitLab og websøgning får en forbindelsestimeout på 3 s i stedet for 1 s, så langsommere netværk ikke længere fejler.
* **Sporede ændringer**: gennemsynsdata omfatter ikke-indlæste dokumenter og ikke-gemte ændringer.
* **Administrationspanel**: gendannelse af slettede projekter, ændring af ejere og redigering af brugere fungerer korrekt, og en mislykket e-mail ødelægger ikke længere oprettelse eller sletning af konti.
* **Skabelongalleri**: en ugyldig sortering returnerer 400 i stedet for 500, og udgivelse af et projekt uden en hovedfil beder om en.

Se [udgivelsesnoterne for 6.3.1](/da/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.1  "mention") for den fulde liste.

#### Opgradering

* Fra 6.3.0: ingen migrering er nødvendig. Hent det nye image, og genstart.
* Fra 6.2.x eller tidligere med Zotero eller Mendeley i brug: kør først [Zotero-/Mendeley-migreringen](/da/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention") fra 6.3.0.
* Dropbox-synkronisering og GitLab-synkronisering er slået fra som standard. GitLab-synkronisering kræver kun nye miljøvariabler. Dropbox-synkronisering kræver desuden, at dens MongoDB-indekser oprettes én gang, før brugerne tilknytter deres konti: se [Opret databaseindekserne](/da/on-premises/configuration/overleaf-toolkit/dropbox-synchronisation#create-the-database-indexes  "mention").
