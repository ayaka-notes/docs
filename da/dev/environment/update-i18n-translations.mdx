---
title: Opdater i18n-oversættelser
icon: language
---

Der findes en fil i `services/web/frontend/extracted-translations.json`, og Overleaf web bruger kun de udtrukne oversættelser i denne fil.

Kør følgende kommando for at opdatere de udtrukne oversættelser, hvis du har tilføjet noget indhold.

```bash
user ➜ ~/overleaf-pro/develop (server-pro) $ bin/shell webpack
root@432836260f8a:/overleaf/services/web# npm run extract-translations
```

Generelt bør du ikke redigere oversættelsesfilerne, men i første omgang bruge eksisterende oversættelser, da alle disse filer opdateres fra Overleaf upstream eller fra et tredjeparts oversættelseswebsted.
