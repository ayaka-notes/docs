`spellingPreferences` indeholder hver brugers ordbog: de ord, brugeren har tilføjet via "Add to dictionary" i editorens stavekontrol. Ét dokument pr. bruger. `web` ejer den, uden Mongoose-skema; koden er `services/web/app/src/Features/Spelling/LearnedWordsManager.mjs`.

#### Felter {#fields}

| Felt | Type | Betydning | Kilde |
| --- | --- | --- | --- |
| `_id` | ObjectId | Dokumentets id, oprettet af upsert'en. | `LearnedWordsManager.mjs:21-31` |
| `token` | String | Brugerens id. Trods navnet sender staveruterne id'et for den indloggede bruger (`SessionManager.getLoggedInUserId`). | `LearnedWordsManager.mjs:23` |
| `learnedWords` | Array of String | De ord, brugeren har tilføjet. | `LearnedWordsManager.mjs:26` |

#### Hvem skriver {#who-writes-it}

| Kode | Hvad den gør |
| --- | --- |
| `LearnedWordsManager.mjs:13-32` (`learnWord`) | `POST /spelling/learn` (`services/web/app/src/router.mjs:1037-1041`, `services/web/app/src/Features/Spelling/SpellingController.mjs:45-58`): `$addToSet` af ordet, med upsert. Afviser, når listen ville blive større end `Settings.maxDictionarySize` byte. |
| `LearnedWordsManager.mjs:38-47` (`unlearnWord`) | `POST /spelling/unlearn` (`router.mjs:1043-1047`, `SpellingController.mjs:66-79`): `$pull` af ordet. |
| `LearnedWordsManager.mjs:84-86` (`deleteUsersLearnedWords`) | Sletter dokumentet. Dens eneste wrapper, `SpellingHandler.deleteUserDictionary` (`services/web/app/src/Features/Spelling/SpellingHandler.mjs:24-26`), kaldes ingen steder i web eller dens moduler. |

#### Hvem læser {#who-reads-it}

| Kode | Hvad den gør |
| --- | --- |
| `LearnedWordsManager.mjs:52-67` (`getLearnedWords`) | Returnerer ordene uden dubletter. |
| `services/web/app/src/Features/Project/ProjectController.mjs:671` | Sender ordbogen til editoren, når et projekt åbnes (`SpellingHandler.getUserDictionary`). |

* Sletning af en bruger sletter ikke dette dokument.
