`projectHistoryLabels` indeholder de etiketter, brugere sætter på versioner i History-visningen, ét dokument pr. etiket. project-history ejer den og skriver den i `services/project-history/app/js/LabelsManager.js`; der er intet Mongoose-skema. Web tilgår den kun gennem project-history-API'et.

#### Felter {#fields}

| Felt | Type | Betydning | Kilde |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Etikettens id. | `LabelsManager.js:81-85` |
| `project_id` | ObjectId | Projektet. | `LabelsManager.js:73` |
| `comment` | String | Etikettens tekst. | `LabelsManager.js:74` |
| `version` | Number | Den version af projekthistorikken, som etiketten peger på. | `LabelsManager.js:75` |
| `created_at` | Date | Hvornår etiketten blev oprettet; anmodningen kan sende sit eget tidspunkt, ellers er det nu. | `LabelsManager.js:70`, `76` |
| `user_id` | ObjectId | Hvem der oprettede etiketten. Udelades, når anmodningen ikke har nogen bruger. | `LabelsManager.js:78-80` |

#### Hvem skriver {#who-writes-it}

| Kode | Hvad den gør |
| ---- | ------------ |
| `services/project-history/app/js/LabelsManager.js:44-90` | `createLabel`: indsætter en etiket, til project-history `POST /project/:project_id/labels` (`services/project-history/app/js/HttpController.js:1134-1171`). Web kalder den, når en bruger tilføjer en etiket, med brugerens id (`services/web/app/src/Features/History/HistoryController.mjs:529-546`). |
| `LabelsManager.js:113-126` | `deleteLabel`: sletter en etiket i projektet, til `DELETE /project/:project_id/labels/:label_id`. Web bruger den, når projektejeren sletter en etiket (`HistoryController.mjs:649-670`). |
| `LabelsManager.js:92-111` | `deleteLabelForUser`: sletter kun en etiket, hvis brugeren oprettede den, til `DELETE /project/:project_id/user/:user_id/labels/:label_id`. Web bruger den til alle andre. |
| `LabelsManager.js:128-143` | `transferLabels`: flytter alle etiketter fra én bruger til en anden, til `POST /user/:from_user/labels/transfer/:to_user` (`services/project-history/app/js/Router.js:52-55`). Intet i web kalder denne rute. |
| `LabelsManager.js:7-25` | `cloneLabels`: kopierer et projekts etiketter til et andet projekt, til project-history `POST /project/:project_id/clone` (`HttpController.js:113`), som intet i web kalder. |

#### Hvem læser {#who-reads-it}

| Kode | Hvad den gør |
| ---- | ------------ |
| `LabelsManager.js:27-42` | `getLabels`: alle etiketter i et projekt, returneret som `{ id, comment, version, user_id, created_at }` (`LabelsManager.js:163-171`). Bruges af `GET /project/:project_id/labels` (`HttpController.js:1076-1100`), som web kalder til History-visningen og udfylder brugernavne (`HistoryController.mjs:488-499`). |
| `services/project-history/app/js/SummarizedUpdatesManager.js:57` | Tilføjer etiketterne til listen over historikopdateringer. |

#### Bemærkninger {#notes}

* Før project-history indsætter en etiket, behandler den projektets opdateringer i køen og tjekker, at history-v1 har en chunk til den version, medmindre anmodningen sender `validate_exists: false` (`LabelsManager.js:53-59`, `173-195`; `HttpController.js:1109-1115`).
* Ingen kode sletter et projekts etiketter, når projektet slettes: project-history `DELETE /project/:project_id` rydder kun synkroniseringsstatus og fejlpost (`HttpController.js:1363-1396`), og ingen anden tjeneste rører denne samling.
