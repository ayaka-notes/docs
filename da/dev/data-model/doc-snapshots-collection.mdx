`docSnapshots` indeholder kopier af et doc, som document-updater tager lige før en redigering, der folder kommentarer eller sporede ændringer sammen. Kun document-updater skriver den, i `services/document-updater/app/js/SnapshotManager.js`. Web har en Mongoose-model i `services/web/app/src/models/DocSnapshot.mjs`, men ingen kode bruger den.

#### Felter {#fields}

| Felt | Type | Betydning | Kilde |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Snapshottets id. | `SnapshotManager.js:24` |
| `project_id` | ObjectId | Projekt. | `SnapshotManager.js:19,26`, `DocSnapshot.mjs:7` |
| `doc_id` | ObjectId | Doc'et (`docs._id`). | `SnapshotManager.js:20,27`, `DocSnapshot.mjs:8` |
| `version` | Number | Doc'ets OT-version før redigeringen. | `SnapshotManager.js:28`, `services/document-updater/app/js/UpdateManager.js:132,264-271`, `DocSnapshot.mjs:9` |
| `lines` | Array of String | Doc'ets indhold før redigeringen. | `SnapshotManager.js:29`, `DocSnapshot.mjs:10` |
| `pathname` | String | Doc'ets sti i projektet på det tidspunkt. | `SnapshotManager.js:30`, `DocSnapshot.mjs:11` |
| `ranges` | Mixed | `comments` og `changes` før redigeringen, i samme form som `docs.ranges` (se [docs](/da/dev/data-model/docs-collection)). `id`, `op.t` og `metadata.user_id` omdannes til ObjectIds og `metadata.ts` til Dates. | `SnapshotManager.js:31,41-68`, `DocSnapshot.mjs:12` |
| `ts` | Date | Hvornår snapshottet blev taget. TTL-indekset sletter det 30 dage senere. | `SnapshotManager.js:32`, `DocSnapshot.mjs:13` |

#### Hvem skriver {#who-writes-it}

| Kode | Hvad den gør |
| ---- | ------------ |
| `UpdateManager.js:248-271` | Når document-updater har anvendt en redigering, gemmer den doc'et, som det var før redigeringen, hvis redigeringen foldede områder sammen: flere områder blev tomme, eller mere end ét område blev fjernet (`services/document-updater/app/js/RangesManager.js:104-106`). |
| `SnapshotManager.js:17-36` `recordSnapshot` | Indsætter snapshottet. |

#### Hvem læser {#who-reads-it}

Ingen kode læser den. Web-modellen er defineret, men bruges ingen steder.

#### Bemærkninger {#notes}

* Kun redigeringer, der går gennem `UpdateManager.applyUpdate`, tager snapshots. Redigeringer, som `HistoryOTUpdateManager` håndterer, gør ikke (`UpdateManager.js:74-77`).
* Der er intet indeks på `doc_id`. Find et docs snapshots via `project_id` og `ts`, og filtrer derefter på `doc_id`.
