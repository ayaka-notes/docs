`oauthApplications` indeholder de OAuth-klienter, som web kender. Ét dokument er én klient. I Ayakaleaf Pro skriver kun webmodulet `git-bridge` til den: det opretter én klient med navnet `Overleaf Git Bridge`, når web starter. Skemaet er `services/web/app/src/models/OauthApplication.mjs`.

#### Felter {#fields}

| Felt | Type | Betydning | Kilde |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Klientdokumentets id. `oauthAccessTokens.oauthApplication_id` og `oauthAuthorizationCodes.oauthApplication_id` peger på det. | `OauthApplication.mjs:5` |
| `id` | String | Klient-id: 64 tilfældige små bogstaver og cifre. | `OauthApplication.mjs:7`, `services/web/modules/git-bridge/index.mjs:25` |
| `clientSecret` | String | Klienthemmelighed, skrevet som `v1.` plus 32 tilfældige tegn. Kun `getClient` læser den, og intet kalder `getClient` (se Bemærkninger). | `OauthApplication.mjs:8`, `git-bridge/index.mjs:26` |
| `grants` | Array of String | Granttyper. Git-bridge-klienten har `['password']`. Returneres med klienten, når et token kontrolleres (`services/web/modules/oauth2-server/app/src/OAuth2Model.mjs:67-72`). | `OauthApplication.mjs:9`, `git-bridge/index.mjs:27` |
| `name` | String | Klientens navn. Git-bridge-modulet og koden til personlige adgangstokens finder klienten via navnet `Overleaf Git Bridge`. | `OauthApplication.mjs:10`, `git-bridge/index.mjs:15-16,28` |
| `redirectUris` | Array of String | Tilladte omdirigerings-URI'er. `[]` for git-bridge-klienten. | `OauthApplication.mjs:11`, `git-bridge/index.mjs:29` |
| `scopes` | Array of String | Scopes, som klienten må bruge. `['git_bridge']` for git-bridge-klienten. | `OauthApplication.mjs:12`, `git-bridge/index.mjs:30` |
| `pkceEnabled` | Boolean | Kun i skemaet: ingen kode i dette repo skriver det, og kun den ubrugte `getClient` læser det (`OAuth2Model.mjs:207`). | `OauthApplication.mjs:13` |

#### Hvem skriver {#who-writes-it}

| Kode | Hvad den gør |
| ---- | ------------ |
| `git-bridge/index.mjs:9-35` (module `git-bridge`) | Når `GIT_BRIDGE_ENABLED` er `true`, opretter det klienten `Overleaf Git Bridge`, når web starter, hvis der ikke findes en klient med det navn. |

#### Hvem læser {#who-reads-it}

| Kode | Hvad den gør |
| ---- | ------------ |
| `services/web/modules/oauth2-server/app/src/OAuthPersonalAccessTokenManager.mjs:53-61` (module `oauth2-server`) | Finder klienten `Overleaf Git Bridge` via navnet og gemmer dens `_id` i hvert nyt personligt adgangstoken. Uden klienten oprettes intet token. |
| `OAuth2Model.mjs:31-39,67-72` (`getAccessToken`) | Indlæser klienten for et token via `oauthApplication_id` og returnerer dens `id` og `grants`. |
| `OAuth2Model.mjs:185-209,241,275` (`getClient`, `saveToken`, `saveAuthorizationCode`) | Slår klienter op via `id`. Nås aldrig i dette repo, se Bemærkninger. |

#### Indekser {#indexes}

Kun standardindekset på `_id`. Det unikke indeks `id_1` kommer fra migreringer mærket `saas` (`20190912145016_create_oauthApplications_indexes.mjs`) og `server-pro` (`20230502180757_server_pro_oauth_indexes.mjs`), som Community Edition ikke kører.

#### Bemærkninger {#notes}

* Web bruger kun `@node-oauth/oauth2-server` til at kontrollere bearer-tokens (`server.authenticate` i `services/web/app/src/Features/Authentication/AuthenticationController.mjs:409-450`), som kun kalder modellens `getAccessToken` og `verifyScope`. Ingen route betjener `/oauth/token` eller `/oauth/authorize`, så `getClient`, `saveToken` og `saveAuthorizationCode` kaldes aldrig.
* Modulet slår klienten op via navnet og opretter den derefter, og Community Edition har intet unikt indeks på `name` eller `id`. Intet forhindrer derfor en anden klient med samme navn. Kode, der har brug for klienten, tager den, som `findOne` returnerer.
