`rooms` indeholder ét dokument pr. chatrum i et projekt: projektchatten eller én tråd med gennemgangskommentarer. Kun chat-tjenesten skriver den, i `services/chat/app/js/Features/Threads/ThreadManager.js`. Der er intet Mongoose-skema. Et rums beskeder ligger i samlingen [messages](/da/dev/data-model/messages-collection).

#### Felter {#fields}

| Felt | Type | Betydning | Kilde |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Rummets id. `messages.room_id` peger hertil. | `ThreadManager.js:57-61` |
| `project_id` | ObjectId | Projektet, som rummet hører til. | `ThreadManager.js:43-54` |
| `thread_id` | ObjectId | Kun på kommentartråde: kommentarens id, det samme som `id` og `op.t` for kommentaren i `docs.ranges.comments` (se [docs](/da/dev/data-model/docs-collection)). Mangler på projektchattens rum. | `ThreadManager.js:38-55`, `services/docstore/app/js/RangeManager.js:54-57` |
| `resolved` | Object | Sættes, når tråden løses, og fjernes, når den genåbnes. En tråd uden feltet er åben. | `ThreadManager.js:94-123` |
| `resolved.user_id` | String | Id på brugeren, der løste tråden. Gemmes som en streng, ikke som ObjectId: anmodningens body kontrolleres kun for et gyldigt id og konverteres ikke. | `ThreadManager.js:103`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:70` |
| `resolved.ts` | Date | Hvornår tråden blev løst. | `ThreadManager.js:104` |

#### Bemærkninger {#notes}

* Et projekt har højst ét rum uden `thread_id`: projektchatten. Chat-tjenesten finder det med `thread_id: { $exists: false }` (`ThreadManager.js:38-45`).
* En kommentars løst-status findes kun her. Docstore fjerner `op.resolved`, før den gemmer områder (`services/docstore/app/js/RangeManager.js:59-61`).
* Efter en projektkopi findes det samme `thread_id` i to projekter. Forespørg altid på `project_id` og `thread_id` sammen, som chat-tjenesten gør.
* Rummene i et slettet projekt bliver liggende, indtil det slettede projekt udløber.
