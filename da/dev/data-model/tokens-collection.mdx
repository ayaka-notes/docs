---
title: Tokens-samlingen
icon: key
---

`tokens` indeholder engangstokens: hemmeligheden i et link, der lader nogen angive en adgangskode. Ét dokument er ét token. Der er ingen Mongoose-model; web skriver samlingen via `services/web/app/src/Features/Security/OneTimeTokenHandler.mjs` med den indbyggede driver.

#### Felter {#fields}

| Felt | Type | Betydning | Kilde |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Dokument-id. | `OneTimeTokenHandler.mjs:40` |
| `use` | String | Hvad tokenet er til, se [Anvendelser](#uses) nedenfor. Hvert opslag filtrerer på det. | `OneTimeTokenHandler.mjs:41` |
| `token` | String | Hemmeligheden i linket: 32 tilfældige bytes som 64 hextegn, gemt som det er. | `OneTimeTokenHandler.mjs:38,42` |
| `data` | Object | Hvad tokenet står for; returneres, når det bruges. | `OneTimeTokenHandler.mjs:43` |
| `data.user_id` | String | Brugerens id, skrevet som streng af hver kalder. | `services/web/app/src/Features/PasswordReset/PasswordResetHandler.mjs:27`, `services/web/app/src/Features/User/UserRegistrationHandler.mjs:117`, `services/web/modules/admin-tools/app/src/AdminUserManager.mjs:79` |
| `data.email` | String | Brugerens e-mail, da tokenet blev oprettet. En nulstilling af adgangskode slår brugeren op via denne primære e-mail (`PasswordResetHandler.mjs:66-70`). | samme som `data.user_id` |
| `createdAt` | Date | Oprettelsestidspunkt. TTL-indekset sletter tokenet 90 dage senere. | `OneTimeTokenHandler.mjs:36,44` |
| `expiresAt` | Date | `createdAt` plus `expiresIn` sekunder: 1 time som standard, 1 uge for et aktiveringslink. Opslag ignorerer et token efter dette tidspunkt. | `OneTimeTokenHandler.mjs:35-37,45` |
| `peekCount` | Number | Hvor mange gange tokenet er blevet set uden at blive brugt. Hver `peekValueFromToken` lægger 1 til; ved 4 (`MAX_PEEKS`) holder tokenet op med at virke. | `OneTimeTokenHandler.mjs:8-31,107` |
| `usedAt` | Date | Tidspunkt, hvor tokenet blev brugt eller annulleret. Opslag ignorerer et token, der har det. | `OneTimeTokenHandler.mjs:51-104` |

#### Anvendelser {#uses}

| `use` | Funktion | Udløber | Kode |
| ----- | ------- | ------ | ---- |
| `password` | E-mail til nulstilling af adgangskode fra siden "glemt adgangskode" | 1 time | `PasswordResetHandler.mjs:14-42` |
| `password` | Aktiveringslink: en konto oprettet med en tilfældig adgangskode, derefter et link til at angive en. Bruges af offentlig registrering (`services/web/modules/login-register/app/src/RegisterController.mjs:65`), adminregistreringssiden i `user-activate` (`services/web/modules/user-activate/app/src/UserActivateController.mjs:27-30`) og scriptet `create-user` (`services/web/modules/server-ce-scripts/scripts/create-user.mjs:21`) | 1 uge | `UserRegistrationHandler.mjs:97-130` |
| `password` | Aktiverings- eller nulstillingslink sendt fra adminpanelet (modulet `admin-tools`) | 1 uge (aktivering), 1 time (nulstilling) | `AdminUserManager.mjs:76-103,196-206` |
| `email_confirmation` | Link til bekræftelse af e-mail. Læses kun: intet i dette repo opretter længere sådanne tokens, da bekræftelsen nu sender en 6-cifret kode (`services/web/app/src/Features/User/UserEmailsConfirmationHandler.mjs:15-35`) | | `UserEmailsConfirmationHandler.mjs:12,37-66` |

#### Hvem skriver {#who-writes-it}

| Kode | Hvad den gør |
| ---- | ------------ |
| `OneTimeTokenHandler.mjs:34-49` (`getNewToken`) | Indsætter et token. Kaldere: `PasswordResetHandler.mjs:28`, `UserRegistrationHandler.mjs:115-119`, `AdminUserManager.mjs:77-81`. |
| `OneTimeTokenHandler.mjs:8-32` (`peekValueFromToken`) | Returnerer `data` for et gyldigt token og lægger 1 til `peekCount`. Bruges, når siden til nulstilling af adgangskode åbnes (`services/web/app/src/Features/PasswordReset/PasswordResetController.mjs:195-208`), igen når den nye adgangskode angives (`PasswordResetHandler.mjs:94-96`), og af e-mailbekræftelsen (`UserEmailsConfirmationHandler.mjs:38-41`). |
| `OneTimeTokenHandler.mjs:75-88` (`expireToken`) | Sætter `usedAt` på ét token: efter at en ny adgangskode er angivet (`PasswordResetHandler.mjs:44-48,119`) eller en e-mail er bekræftet (`UserEmailsConfirmationHandler.mjs:65`). |
| `OneTimeTokenHandler.mjs:90-104` (`expireAllTokensForUser`) | Sætter `usedAt` på hvert åbent `password`-token for en bruger, når brugeren ændrer adgangskoden i indstillingerne (`services/web/app/src/Features/User/UserController.mjs:146-149`) eller en administrator angiver den i adminpanelet (`AdminUserManager.mjs:479-488`). |

#### Bemærkninger {#notes}

* Et brugt eller udløbet token slettes ikke med det samme: det bliver, med `usedAt` eller en passeret `expiresAt`, indtil TTL-indekset fjerner det 90 dage efter `createdAt`.
* `OneTimeTokenHandler` har også `getValueFromTokenAndExpire` (`OneTimeTokenHandler.mjs:51-73`), men intet kalder den.
