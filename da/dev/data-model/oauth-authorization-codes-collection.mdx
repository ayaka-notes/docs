title: OAuth Authorization Codes-samlingen
icon: lock-open
---

`oauthAuthorizationCodes` er beregnet til koderne i OAuth-flowet authorization code: ét dokument pr. kode, som en klient bytter til et adgangstoken. Skemaet er `services/web/app/src/models/OauthAuthorizationCode.mjs`, og webmodulet `oauth2-server` har den kode, der ville skrive til den. I Ayakaleaf Pro når intet den kode, så samlingen forbliver tom (se Bemærkninger).

#### Felter {#fields}

| Felt | Type | Betydning | Kilde |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Dokument-id. | `OauthAuthorizationCode.mjs:6` |
| `authorizationCode` | String | Selve koden, gemt som den er (ikke hashet). | `OauthAuthorizationCode.mjs:8`, `services/web/modules/oauth2-server/app/src/OAuth2Model.mjs:280` |
| `expiresAt` | Date | Gyldighedens slutning. `getAuthorizationCode` afviser en kode derefter, og TTL-indekset sletter den. | `OauthAuthorizationCode.mjs:9`, `OAuth2Model.mjs:150-153,281` |
| `oauthApplication_id` | ObjectId | Klienten i [OAuth Applications](/da/dev/data-model/oauth-applications-collection), der bad om koden. | `OauthAuthorizationCode.mjs:10`, `OAuth2Model.mjs:275-284` |
| `redirectUri` | String | Anmodningens omdirigerings-URI. | `OauthAuthorizationCode.mjs:11`, `OAuth2Model.mjs:282` |
| `scope` | String | Anmodet scope. | `OauthAuthorizationCode.mjs:12`, `OAuth2Model.mjs:283` |
| `user_id` | ObjectId | Brugeren, der gav koden. | `OauthAuthorizationCode.mjs:13`, `OAuth2Model.mjs:285` |
| `codeChallenge`, `codeChallengeMethod` | String | PKCE-challenge og dens metode. | `OauthAuthorizationCode.mjs:14-15`, `OAuth2Model.mjs:286-287` |

#### Hvem skriver {#who-writes-it}

| Kode | Hvad den gør |
| ---- | ------------ |
| `OAuth2Model.mjs:274-300` (`saveAuthorizationCode`) | Indsætter en kode. Nås ikke, se Bemærkninger. |
| `OAuth2Model.mjs:307-312` (`revokeAuthorizationCode`) | Sletter en kode, når den er brugt. Nås ikke. |

#### Hvem læser {#who-reads-it}

| Kode | Hvad den gør |
| ---- | ------------ |
| `OAuth2Model.mjs:137-177` (`getAuthorizationCode`) | Indlæser en kode med dens bruger og klient. Nås ikke. |

#### Indekser {#indexes}

| Navn | Nøgler | Indstillinger | Migrering |
| ---- | ---- | ------- | --------- |
| `expiresAt_1` | `{ expiresAt: 1 }` | TTL, `expireAfterSeconds: 0`, delvist: `expiresAt` findes | `20230406125632_oauth_tokens_ttl.mjs` |

Migreringerne ligger i `tools/migrations/`. Det unikke indeks `authorizationCode_1` kommer kun fra migreringer mærket `saas` og `server-pro`, som Community Edition ikke kører.

#### Bemærkninger {#notes}

* Modelmetoderne ovenfor kaldes kun af authorize- og token-handlerne i `@node-oauth/oauth2-server`. Web bruger kun biblioteket til at kontrollere bearer-tokens (`services/web/app/src/Features/Authentication/AuthenticationController.mjs:409-450`), og ingen route betjener `/oauth/authorize` eller `/oauth/token`, så der skrives aldrig nogen kode. Personlige adgangstokens oprettes direkte, se [OAuth Access Tokens](/da/dev/data-model/oauth-access-tokens-collection).
