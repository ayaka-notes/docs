`tags` indeholder de tags (mapper), som en bruger sorterer projekter i på projektoversigten. Et dokument er ét tag for én bruger. `web` ejer den; skemaet er `services/web/app/src/models/Tag.mjs`, og alle skrivninger går gennem `services/web/app/src/Features/Tags/TagsHandler.mjs`.

#### Felter {#fields}

| Felt | Type | Betydning | Kilde |
| --- | --- | --- | --- |
| `_id` | ObjectId | Taggets id, bruges i ruterne `/tag/:tagId`. | `Tag.mjs:10` |
| `user_id` | String | Taggets ejer. En almindelig streng, ikke et ObjectId, af historiske årsager. | `Tag.mjs:7-12` |
| `name` | String | Taggets navn, højst 50 tegn (`MAX_TAG_LENGTH`). Unikt pr. bruger. | `Tag.mjs:13`, `TagsHandler.mjs:4` |
| `color` | String | Valgfri farve: en hexkode som `#a1b2c3` eller en værdi `hsl(<n>, 70%, 45%)` (`TAG_COLOR_REGEX`). | `Tag.mjs:5`, `Tag.mjs:14-22` |
| `project_ids` | Array of String | Id'er for projekterne i dette tag, som strenge. | `Tag.mjs:23` |
| `__v` | Number | Mongoose-versionsnøgle, tilføjet når `Tag.create` opretter dokumentet. | `TagsHandler.mjs:27` |

Den samme migrering oprettede også `user_id_1`; `tools/migrations/20231031164732_drop_redundant_indexes.mjs` fjerner det igen, da det sammensatte indeks dækker det.

#### Bemærkninger {#notes}

* Tags er pr. bruger: to samarbejdspartnere på samme projekt har hver deres egne tags til det.
* `user_id` og `project_ids` er strenge, så forespørg dem med streng-id'er, ikke ObjectId'er.
* Sletning af en bruger (`services/web/app/src/Features/User/UserDeleter.mjs`) rører ikke `tags`.
