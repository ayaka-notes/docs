Gemmer projektchatten og kommentartrådene (deres beskeder og løst-status) i Mongo-samlingerne `rooms` og `messages`. Kaldes af web via `ChatApiHandler`.

* <strong>Godkendelse:</strong> ingen
* <strong>OpenAPI-fil:</strong> [`develop/hoppscotch/openapi/chat.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/chat.yaml)
