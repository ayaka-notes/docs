Leverer filer fra objektlager: skabelonfiler (zip, pdf og deres forhåndsvisningsbilleder) og, skrivebeskyttet, de projekt- og globale blobs, som history-v1 skriver. Kaldes af web (modulet template-gallery, fil-URL'er for kompileringer) og af clsi, der henter binære projektfiler derfra.

* <strong>Adresse:</strong> `http://filestore:3009`, inden for Docker-netværket
* <strong>Godkendelse:</strong> ingen
* <strong>OpenAPI-fil:</strong> [`develop/hoppscotch/openapi/filestore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/filestore.yaml)
