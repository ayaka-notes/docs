Gemmer hele historikken for hvert projekt: bidder af ændringer i Mongo eller Postgres og objektlager samt filindhold som blobs. project-history skriver ændringer dertil; web, project-history og git-bridge læser blobs, snapshots og zip-filer derfra.

* <strong>Adresse:</strong> `http://history-v1:3100`, inden for Docker-netværket
* <strong>Godkendelse:</strong> HTTP basic auth som `staging` med `STAGING_PASSWORD` eller et JWT, afhængigt af ruten.
* <strong>OpenAPI-fil:</strong> [`develop/hoppscotch/openapi/history-v1.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/history-v1.yaml)
