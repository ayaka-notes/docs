Henter en ekstern URL for web og streamer svaret tilbage og afviser interne adresser, så brugere ikke kan nå Docker-netværket. Web sender URL-filer, Open in Overleaf-importer og AI-agentens web_fetch igennem den.

* <strong>Adresse:</strong> `http://linked-url-proxy:3066`, inden for Docker-netværket
* <strong>Godkendelse:</strong> ingen
* <strong>OpenAPI-fil:</strong> [`develop/hoppscotch/openapi/linked-url-proxy.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/linked-url-proxy.yaml)
