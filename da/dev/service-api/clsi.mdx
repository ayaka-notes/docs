CLSI (Common LaTeX Service Interface) kompilerer projekter, kører SyncTeX og texcount på kompileringsoutputtet og konverterer dokumenter med pandoc. Web kalder den; selve outputfilerne leveres af clsi-nginx, ikke af denne port. Ingen godkendelse: den kan kun nås inden for Docker-netværket.

* <strong>Adresse:</strong> `http://clsi:3013`, inden for Docker-netværket
* <strong>Godkendelse:</strong> ingen
* <strong>OpenAPI-fil:</strong> [`develop/hoppscotch/openapi/clsi.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/clsi.yaml)
