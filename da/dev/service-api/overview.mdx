Overleaf kører som flere tjenester, der kalder hinanden over HTTP inden for Docker-netværket. Siderne i dette afsnit beskriver disse interne API'er. De stammer fra OpenAPI-filerne i [`develop/hoppscotch/openapi/`](https://github.com/ayaka-notes/ayakaleaf-pro/tree/server-pro/develop/hoppscotch/openapi), som er skrevet ud fra koden til hver tjeneste.

Ingen af disse API'er er offentlige: de kan kun nås inden for Docker-netværket, og de fleste har ingen godkendelse.

## Tjenester {#services}

| Tjeneste | Adresse | Hvad den gør |
| ------------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------------------ |
| [web](/da/dev/service-api/web)                                     | `http://web:3000`                   | Hovedappen. Dens private API kaldes af de andre tjenester og imagets cronscripts  |
| [document-updater](/da/dev/service-api/document-updater)           | `http://document-updater:3003`      | Holder de dokumenter, der er åbne i editoren, i Redis, anvender ændringer og skriver dem tilbage til Mongo         |
| [docstore](/da/dev/service-api/docstore)                           | `http://docstore:3016`              | Gemmer hvert dokument i hvert projekt i Mongo-samlingen `docs`                                 |
| [real-time](/da/dev/service-api/real-time)                         | `http://real-time:3026`             | Holder editorens socket.io-forbindelser og videresender ændringer mellem browsere og tjenester          |
| [chat](/da/dev/service-api/chat)                                   | `http://chat:3010`                  | Gemmer projektchatten og kommentartrådene                                                  |
| [project-history](/da/dev/service-api/project-history)             | `http://project-history:3054`       | Omdanner ændringer i kø til historikændringer og sender dem til history-v1; gemmer etiketter               |
| [history-v1](/da/dev/service-api/history-v1)                       | `http://history-v1:3100`            | Gemmer hele historikken for hvert projekt og filindholdet som blobs                           |
| [filestore](/da/dev/service-api/filestore)                         | `http://filestore:3009`             | Leverer skabelonfiler og, skrivebeskyttet, de blobs, som history-v1 skriver                           |
| [clsi](/da/dev/service-api/clsi)                                   | `http://clsi:3013`                  | Kompilerer projekter, kører SyncTeX og ordtælling, konverterer dokumenter                              |
| [notifications](/da/dev/service-api/notifications)                 | `http://notifications:3042`         | Gemmer de notifikationer, der vises i projektlisten                                               |
| [linked-url-proxy](/da/dev/service-api/linked-url-proxy)           | `http://linked-url-proxy:3066`      | Henter eksterne URL'er for web og afviser interne adresser                                     |
| [third-party-datastore](/da/dev/service-api/third-party-datastore) | `http://third-party-datastore:3002` | Synkroniserer projekter med Dropbox via én jobkø pr. bruger                                       |

## Godkendelse {#authentication}

* <strong>web:</strong> HTTP basic auth med `WEB_API_USER` og `WEB_API_PASSWORD`. git-bridge-ruterne bruger i stedet et personligt adgangstoken.
* <strong>history-v1:</strong> HTTP basic auth som `staging` med `STAGING_PASSWORD` eller et JWT.
* <strong>Alle andre tjenester:</strong> ingen.

## Prøv dem {#try-them}

Udviklingsmiljøet kører [Hoppscotch](https://github.com/hoppscotch/hoppscotch) på `http://localhost:9170` med en proxy, der når tjenesterne via deres Docker-adresser. Dens [README](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/README.md#hoppscotch) viser, hvordan du opsætter proxyen og importerer OpenAPI-filerne.
