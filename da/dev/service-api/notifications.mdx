Gemmer de notifikationer, brugere ser i projektlisten (for eksempel projektinvitationer), i Mongo-samlingen `notifications`. Web og third-party-datastore kalder den; den har ingen godkendelse og kan kun nås inden for Docker-netværket.

* <strong>Adresse:</strong> `http://notifications:3042`, inden for Docker-netværket
* <strong>Godkendelse:</strong> ingen
* <strong>OpenAPI-fil:</strong> [`develop/hoppscotch/openapi/notifications.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/notifications.yaml)
