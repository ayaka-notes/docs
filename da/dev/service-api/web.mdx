Privat API for web, Overleafs hovedapp. Andre tjenester (real-time, document-updater, project-history, third-party-datastore, git-bridge) og cronscripts i Server CE-imaget kalder den. Disse ruter kræver kun HTTP basic auth, intet CSRF-token: den private router monteres før web-routeren, og kun web-routeren kører CSRF-kontrollen. Med `BLOCK_CROSS_ORIGIN_REQUESTS=true` (slået fra som standard) returnerer web 403 for enhver anmodning, hvis `Origin`-header ikke er i `ALLOWED_ORIGINS` (standard: sidens URL). Browsere sender `Origin` ved POST, så med denne indstilling slået til får POST-anmodninger fra Hoppscotch i browseren 403, medmindre de går gennem Hoppscotch-proxyen.

* <strong>Adresse:</strong> `http://web:3000`, inden for Docker-netværket
* <strong>Godkendelse:</strong> HTTP basic auth med `WEB_API_USER` og `WEB_API_PASSWORD`, undtagen for status, health og metrics. git-bridge-ruterne bruger i stedet et personligt adgangstoken.
* <strong>OpenAPI-fil:</strong> [`develop/hoppscotch/openapi/web.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/web.yaml)
