Se: [https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.3.0](https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.3.0)

<Warning>

Ayakaleaf Pro 6.3.0 blev oprindeligt udgivet den 24. september 2026. Denne genudgivelse løser problemer med integrationerne til AI Assistant, Zotero og Mendeley, som var forårsaget af upstream-opdateringer.

Hent det nyeste `6.3.0`-image, og opgrader din installation. <strong>Eksisterende installationer med tilknyttede bibliografifiler fra Zotero eller Mendeley skal også køre migreringen nedenfor.</strong> Nye installationer har ikke brug for denne migrering.

</Warning>

<Accordion title="Zotero-/Mendeley-migrering for eksisterende installationer">

Når du opgraderer til det genudgivne 6.3.0-image, skal du migrere eksisterende metadata for tilknyttede Zotero-/Mendeley-bibliografier med scriptet nedenfor. Denne migrering hører til rettelsen `12031b8dfd`.

Den omdøber `zoteroGroupId` / `mendeleyGroupId` til `group_id`, omdøber `importedByUserId` til `importer_id` og fjerner `importedByName`.

Sikkerhedskopier MongoDB, og stop applikationen, før du kører migreringen. Lad MongoDB køre. Åbn dens shell (erstat `mongo` med navnet på din container):

```bash
docker exec -it mongo mongosh
```

Kør følgende i `mongosh` (erstat `sharelatex` med navnet på din database):

```javascript
use sharelatex

(async () => {
  let updated = 0
  await db.projects.find({}, { rootFolder: 1 }).forEach(async project => {
    const changes = {}
    function visit(folders, path) {
      for (const [i, folder] of (folders || []).entries()) {
        const folderPath = `${path}.${i}`
        for (const [j, file] of (folder.fileRefs || []).entries()) {
          const data = { ...file.linkedFileData }
          if (!["zotero", "mendeley"].includes(data.provider)) continue
          const groupKey = `${data.provider}GroupId`
          if (![groupKey, "importedByUserId", "importedByName"].some(key => key in data)) continue
          for (const [oldKey, newKey] of [[groupKey, "group_id"], ["importedByUserId", "importer_id"]]) {
            if (data[oldKey] != null && data[oldKey] !== "") {
              const value = String(data[oldKey])
              if (newKey in data && data[newKey] !== value) {
                throw new Error(`Conflicting ${newKey}: project ${project._id}, file ${file._id}`)
              }
              data[newKey] = value
            }
            delete data[oldKey]
          }
          delete data.importedByName
          changes[`${folderPath}.fileRefs.${j}.linkedFileData`] = data
        }
        visit(folder.folders, `${folderPath}.folders`)
      }
    }
    visit(project.rootFolder, "rootFolder")
    if (!Object.keys(changes).length) return
    const result = await db.projects.updateOne(
      { _id: project._id, rootFolder: { $eq: project.rootFolder } },
      { $set: changes }
    )
    if (!result.matchedCount) throw new Error(`Project changed during migration: ${project._id}`)
    updated += result.modifiedCount
  })
  print(`Updated ${updated} project(s).`)
})()
```

Scriptet omfatter indlejrede mapper og ændrer kun Zotero-/Mendeley-metadata. Det er sikkert at køre igen: en gennemført migrering rapporterer `Updated 0 project(s).` ved næste kørsel. Hvis det stopper med en konflikt, skal du undersøge det rapporterede projekt/den rapporterede fil; tidligere projekter kan allerede være migreret.

Start den opdaterede applikation, genindlæs editoren, og opdater en eksisterende bibliografifil som dens oprindelige importør. Historiske øjebliksbilleder omskrives ikke. For at nedgradere til den gamle applikation skal du gendanne MongoDB-sikkerhedskopien.

</Accordion>

Vi er meget stolte over at kunne annoncere udgivelsen af Overleaf Pro 6.3.0, den mest kraftfulde og funktionsrige online LaTeX-editor i fællesskabet. Da vi altid har fokuseret på at forbedre vores brugeres oplevelse, bringer denne udgivelse store ændringer og fantastiske funktioner, som du helt sikkert vil elske, herunder en AI-assistent og integration med referenceværktøjer fra tredjeparter.

### Ændringer

* AI Chat Assistant: Chat med en AI-model via din egen udbyder direkte i din editor.
* LaTeX Error Assistant: Få AI-foreslåede rettelser til LaTeX-kompileringsfejl.
* Mendeley-integration: Importer referencer fra Mendeley på samme måde som fra Zotero.
* Open in Overleaf API: Tilføjet en API til at åbne indhold i Overleaf.
* Skabelongalleri: Tilføjet sideinddeling, søgning og sortering på serversiden, så store gallerier ikke længere behøver at indlæse alle skabeloner i browseren.
* Oversættelser: Opdaterede oversættelsespatches til 6.3.0, herunder ny brugerfladetekst på tværs af de understøttede sprog.
* Upstream Overleaf 6.3.0: Omfatter redigering af filer i faner, separate header-logoer til lyst og mørkt tema samt opdateringer af afhængigheder og basisimage.
* Tilføjet `OVERLEAF_HEADER_IMAGE_URL_LIGHT` og `OVERLEAF_HEADER_IMAGE_URL_DARK` for at understøtte separate header-logobilleder til lyst og mørkt tema.
* Filer kan nu åbnes i forskellige faner i editoren.
* Tilføjet understøttelse af konfigurerbare HTTP(S)-proxyer, herunder lokalt hostede proxyer, via `OVERLEAF_LINKED_URL_OUTBOUND_PROXY`, som også bruges af Open in Overleaf API.

#### Feature 04: Template Pagination

Galleriet foretager nu sideinddeling, sortering og søgning i MongoDB. Det fungerer uden nogen forberedelse; med tusindvis af skabeloner kan du stadig tilføje disse indekser for at holde det hurtigt (sikkert at køre igen, `mongo`/`sharelatex` = navnene på din container og database):

```bash
docker exec mongo mongosh sharelatex --quiet --eval '
db.templates.createIndex({category:1,lastUpdated:-1},{name:"category_1_lastUpdated_-1",background:true});
db.templates.createIndex({lastUpdated:-1},{name:"lastUpdated_-1",background:true});
db.templates.createIndex({category:1,name:1},{name:"category_1_name_1_ci",collation:{locale:"en",strength:2},background:true});
db.templates.createIndex({name:1},{name:"name_1_ci",collation:{locale:"en",strength:2},background:true});
'
```

Bevar `collation` på de to `*_ci`-indekser præcis som skrevet — galleriet forespørger med den samme collation, og MongoDB bruger kun et indeks, der matcher.

## Ayakaleaf Pro 6.2.2

<strong>Udgivelsesdato:</strong> 2026.07.23

Se: [https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.2](https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.2)

### Ændringer

Backport af de officielle hotfix-patches, der blev leveret i upstream Overleaf `6.2.2` (oven på `6.2.1`):

* Stop lækage af hemmeligheden for projektinvitationstokens til logfilerne. Krypteringen af invitationstokens loggede sin egen konfiguration ved hver kryptering/dekryptering, hvilket omfattede de krypteringsadgangskoder, der er afledt af `OVERLEAF_INVITE_TOKEN_SECRET`.
* Migrer udgående e-mail fra den udfasede AWS SES v1-klient til SESv2. Instanser, der var konfigureret med e-maildriveren `ses`, kunne helt undlade at sende e-mail; afsendelse går nu gennem `SESv2Client`.
* Gruppeposterne i rullemenuen til projektdeling er nu skjult bag det nye feature-flag `group-link-sharing`, så deling via gruppelinks ikke længere tilbydes på instanser, hvor det ikke er relevant.
* Ret dialogen til projektdeling for samarbejdspartnere. Når den blev åbnet af en anden end ejeren, eller når `sharing-updates`-flowet var deaktiveret, blev der sendt en forespørgsel, der altid mislykkedes og viste fejlen "something went wrong".
* Tilføj `scripts/flush_docs_with_pending_updates.js` til document-updater, et vedligeholdelsesscript, der gendanner dokumenter, som har en fastlåst `PendingUpdates`-kø i Redis, efter at deres projekt er blevet tømt eller permanent slettet. Understøtter `--dry-run` og en `--estimated-docs`-sikkerhedskontrol.
* Opdater afhængigheder: `multer` 2.2.0, `form-data` 2.5.6, `protobufjs` 7.6.3, `@grpc/grpc-js` 1.14.4.

Denne udgivelse indeholder også følgende rettelser og forbedringer fra Ayakaleaf Pro:

* Tilføj fulde oversættelser til 16 yderligere sprog (cs, da, de, es, fi, fr, it, ja, ko, nl, no, pl, pt, ru, sv, tr), hvilket retter uoversatte tekster som f.eks. siden til nulstilling af adgangskode. Retter [#38](https://github.com/ayaka-notes/ayakaleaf-pro/issues/38).
* Ret antallet i knappen "show N more projects" i administrationspanelet, som viste det forkerte tal, fordi pladsholderen for flertal ikke blev videregivet korrekt.
* Ret valideringsfejl ved GitHub-eksport, som nu vises via statiske i18n-nøgler i stedet for rå beskeder, og fjern de fejlnøgler, som GitHub Sync-dialogen ikke længere bruger.

## Ayakaleaf Pro 6.2.0

<strong>Udgivelsesdato:</strong> 2026.07.10

Se: [https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.0](https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.0)

Vi er stolte over at kunne annoncere udgivelsen af Overleaf Pro 6.2.0, den mest kraftfulde og funktionsrige online LaTeX-editor i fællesskabet. En særlig tak til yu-i-i og davrot for deres værdifulde bidrag. De har forbedret GitHub Sync og introduceret avanceret citationssøgning og Zotero-integration.

### Bemærkninger

<Warning>

* En ny påkrævet miljøvariabel `OVERLEAF_INVITE_TOKEN_SECRET` er blevet introduceret. Du skal generere den med `openssl rand -base64 32`. Hvis den ikke er konfigureret, vil din Overleaf-instans ikke kunne starte.
* Hvis du aktiverer GitHub Sync, skal du konfigurere miljøvariablen `GITHUB_TOKEN_CIPHER_PASSWORD`. Denne variabel er nødvendig for at kryptere GitHub-adgangstokens sikkert. Uden den vil din Overleaf-instans ikke kunne starte.

</Warning>

* Tilføjet en ny miljøvariabel `DEFAULT_LATEX_COMPILER` til at angive den standardcompiler, som nye projekter bruger (enten `pdflatex`, `latex`, `xelatex` eller `lualatex`).
* Den nydesignede editor er nu den eneste tilgængelige mulighed.

### Ændringer

Denne udgivelse indeholder følgende forbedringer og nye funktioner.

* `MAX_UPLOAD_SIZE` kan nu konfigureres i stedet for at være begrænset til **50 MB**.
* Rettet en genstartsløkke for containeren, når sandboxede kompileringer var deaktiveret.
* Håndhævet ejerafgrænset sletning af PAT for OAuth2.
* Rettet et problem med LDAP-import.

Funktionerne omfatter:

* Tilføjet en browserbaseret Python-kører.
* Tilføjet Pandoc-understøttelse til import og eksport af Markdown, DOCX og andre formater.
* Tilføjet GitHub Sync.
* Tilføjet fuldstændige kinesiske oversættelser.
* Tilføjet Zotero-integration.
* Tilføjet `DEFAULT_LATEX_COMPILER`.

## Ayakaleaf Pro 6.0.1

</Info>

## Ayakaleaf Pro 6.0.0

<strong>Udgivelsesdato:</strong> 2026.02.17

Testudgivelse, se: [https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.0.0](https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.0.0)

Dette er en testudgivelse og samtidig vores første version af Overleaf Pro. Denne version indeholder ingen funktioner fra Server Pro, så den markerer kun vores udgangspunkt. Vi tilføjer nye funktioner senere, såsom administrationspanel og git-bridge ...

I denne udgivelse har vi introduceret Overleaf-Docker-imaget til ARM. Du kan prøve det, hvis du har en Mac eller en ARM-baseret server, men nogle funktioner fungerer muligvis ikke godt (endnu ikke testet).

### Docker-image

Du kan finde Docker-imaget her: [https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro)

For multi-arch-imaget, se [her](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/691283454?tag=6.0.0).

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:6.0.0
```

### Migrering af binære filer

Denne nye udgivelse halverer lagerforbruget for binære filer.

En online-migrering er inkluderet i version `5.5`, hvilket giver minimal nedetid som en del af opgraderingen. Før du opgraderer til Server Pro `v6`, skal du sikre dig, at du allerede kører den nyeste version af Server Pro `v5.5` ([Release Notes 5.x.x](https://docs.overleaf.com/on-premises/release-notes/release-notes-5.x.x)) og har kørt migreringen.

[Se den fulde migreringsvejledning](https://docs.overleaf.com/on-premises/release-notes/release-notes-5.x.x/binary-files-migration).

### Opgradering af MongoDB til v8

Denne udgivelse hæver minimumsversionen af MongoDB til `8.0`.

Hvis du i øjeblikket bruger MongoDB `v6` eller tidligere, skal du opdatere én hovedversion ad gangen (`v6 → v7 → v8`).

<Warning>

Sørg for at have en sikkerhedskopi af [databasen](https://docs.overleaf.com/on-premises/maintenance/data-and-backups), **før** du opgraderer. Ved tilbagerulning skal du gendanne databasesikkerhedskopien.

</Warning>

For vejledning i at opgradere MongoDB `v6 → v7 → v8` kan du se vores trin-for-trin-guide [her](https://docs.overleaf.com/on-premises/maintenance/updating-mongodb#example-upgrading-mongodb-from-6.0-to-7.0-toolkit-users).

### Opgradering af Redis til v7.4

Denne udgivelse hæver også minimumsversionen af Redis til `7.4`.

Opdater din `REDIS_IMAGE` i din `config/overleaf.rc` til `REDIS_IMAGE=7.4`.

### Nye funktioner

* Linkdeling kan nu deaktiveres med `OVERLEAF_DISABLE_LINK_SHARING=true`.
* `OVERLEAF_MAINTENANCE_MESSAGE` og `OVERLEAF_MAINTENANCE_MESSAGE_HTML` er nu tilgængelige til at tilpasse titlen og indholdet af vedligeholdelsessiden.
* `OVERLEAF_USER_HARD_DELETION_DELAY` og `OVERLEAF_PROJECT_HARD_DELETION_DELAY` kan konfigureres (i millisekunder) for at ændre udløbsforsinkelsen for slettede brugere/projekter (standard er 90 dage).

### Fejlrettelser

* Rettet visningen af sidefoden med links.
* Forbedrede fejlmeddelelser ved SAML-loginfejl.
* Rettet, at der ikke blev tilføjet en post i revisionsloggen, når en brugers administratorstatus blev opdateret ved SSO-login.
* Rettet fejl i historikpanelet, når TLS er aktiveret i Redis.
* Kompileringer kan nu stoppes, når der bruges ikke-sandboxede kompileringer.

### Andre ændringer

* Alle links til statussiden (angivet via `OVERLEAF_STATUS_PAGE_URL`) bruger nu `HTTPS` og åbnes i en ny browserfane.
