Her har vi samlet svar på nogle ofte stillede spørgsmål om Ayakaleaf Pro.

### Grundlæggende spørgsmål

<Accordion title="Q01: Er Ayakaleaf Pro en gratis prøveversion? Kræver det en licens?">

Nej. Ayakaleaf Pro er helt gratis at bruge. Det er ikke en prøveversion og kræver ingen licens.

</Accordion>

<Accordion title="Q02: Indeholder I (Ayakaleaf Pro) alle funktionerne fra Overleaf Server Pro?">

Ja. Ayakaleaf Pro indeholder alle funktionerne fra Overleaf Server Pro, herunder Git-Bridge-integration. Det indeholder også udvalgte funktioner fra Overleafs SaaS-platform. Vi fortsætter med at udvikle og forbedre Ayakaleaf Pro.

</Accordion>

<Accordion title="Q03: Hvad koster Overleaf Server Pro?">

Overleaf Server Pro koster omkring \$300 pr. bruger om året. Det kræver mindst 10 licenser, så installationer starter ved cirka \$3.000 om året. Mindre offentlige amerikanske kontrakter viser årlige omkostninger på omkring \$320–\$370 pr. bruger. Det gør Server Pro dyrt, især for mindre teams. Se [#information-and-price-about-overleaf-server-pro](/da/on-premises#information-and-price-about-overleaf-server-pro  "mention") for dokumenterede køb og priser.

</Accordion>

<Accordion title="Q04: Hvorfor indeholder Overleaf Server Pro ikke GitHub Sync eller AI-funktioner?">

Overleaf Server Pro bruges ofte af offentlige myndigheder. De installerer det på private netværk og kontrollerer adgangen nøje. For at beskytte følsomme data undgår de inkluderede funktioner at udveksle data med tredjepartstjenester. Hvis du har brug for GitHub Sync, AI eller lignende tilsluttede funktioner, anbefaler Overleaf et abonnement på deres SaaS-platform.

</Accordion>

<Accordion title="Q05: Er Ayakaleaf Pro sikkert og pålideligt?">

Ayakaleaf Pro er open source. Vi gennemgår koden med værktøjer som Codex Security for at styrke sikkerheden og pålideligheden. Hvis du ikke aktiverer datasynkronisering med tredjeparter, forbliver dine data på din server. Ayakaleaf Pro indeholder ingen telemetri, der sender dine data andre steder hen.

</Accordion>

<Accordion title="Q06: Vil Ayakaleaf Pro blive vedligeholdt på lang sigt?">

Vi vil gøre alt, hvad vi kan, for at vedligeholde dette projekt på lang sigt.

</Accordion>

<Accordion title="Q07: Overholder Ayakaleaf Pro reglerne?">

Ayakaleaf Pro er en fællesskabsfork. Koden og de integrerede funktioner stammer fra bidrag fra fællesskabet. Det er licenseret under AGPL v3. Installationer kan overholde denne licens, når de opfylder dens krav.

</Accordion>

<Accordion title="Q08: Hvorfor hedder projektet Ayakaleaf Pro?">

Projektet hed oprindeligt Overleaf Pro i 2024. Udviklingen blev sat på pause i en periode og genoptaget i slutningen af 2025. I første kvartal af 2026 omdøbte Overleaf sin AI-aktiverede abonnementsplan til Pro. Feedback fra fællesskabet påpegede også, at navnet Overleaf Pro kunne medføre risiko for varemærkekrænkelse og forveksling. Det kunne få brugerne til at tro, at projektet var officielt.

Vi omdøbte projektet til Ayakaleaf Pro for at undgå denne forvirring. Navnet kan læses som "Ayaka-notes Overleaf Pro". Vedligeholderen (du kan kalde mig ayaka!) har bidraget til udviklingen af Overleaf-fællesskabet siden studietiden, for over fem år siden. Denne erfaring understøtter vores forpligtelse til langsigtet vedligeholdelse.

</Accordion>

<Accordion title="Q09: Hvad adskiller Ayakaleaf Pro fra nyere AI-byggede LaTeX-editorer?">

Siden 2026 har open source-fællesskabet udgivet mange AI-byggede LaTeX-editorer, herunder OpenAI Prism. Ayakaleaf Pro holder dine data og tjenester på din egen server. Det giver dig direkte kontrol over din installation og dine data.

Mange eksperimentelle fællesskabseditorer har ingen etableret plan for langsigtet vedligeholdelse. Tredjepartsplatforme til LaTeX-kompilering kan også lukke, hvis deres brugerbase eller indtægter er utilstrækkelige. Ayakaleaf Pro leverer al kildekode og lader dig selv hoste alle tjenester. Selv hvis vedligeholdelsen ophørte, ville din eksisterende selvhostede tjeneste kunne fortsætte med at køre.

</Accordion>

### Funktioner

<Accordion title="Q01: Hvilke funktioner tilbyder Ayakaleaf Pro? Kan jeg anmode om en ny funktion?">

Se vores dokumentation for den aktuelle liste over funktioner. Hvis der er en funktion, du gerne vil have os til at tilføje, er du velkommen til at oprette et issue (som funktionsanmodning) på GitHub. Vi gør vores bedste for at implementere de ønskede funktioner, men udvikling tager tid, og vi kan ikke garantere, at alle funktioner bliver leveret med det samme.

</Accordion>

<Accordion title="Q02: Jeg har bygget nogle funktioner. Kan jeg indsende en PR, og er det garanteret, at den bliver accepteret?">

Bidrag er velkomne, men accept er ikke garanteret. Vi vurderer hver PR ud fra dens indvirkning på den underliggende Overleaf-kodebase, den vedligeholdelsesbyrde den medfører, og den værdi den giver brugerne. Vi gør vores bedste for at merge og vedligeholde værdifulde bidrag.

Vi kan dog afvise PR'er, der indfører for omfattende ændringer, består af ugennemgået eller dårligt forstået AI-genereret kode ("vibe coding"), eller tilføjer funktioner, der ville være svære at vedligeholde over tid.

</Accordion>

<Accordion title="Q03: Hvordan konfigurerer jeg en bestemt funktion?">

Vi opdaterer generelt dokumentationen, hver gang vi udgiver en ny funktion. Se den relevante dokumentation for detaljerede opsætningsvejledninger og forklaringer af de tilgængelige miljøvariabler.

</Accordion>

### Installation

<Accordion title="Q01: Understøtter Ayakaleaf Pro distribueret installation i k8s?">

For de fleste brugere anbefaler vi installation med [Toolkit](/da/on-premises/installation/using-the-toolkit). Vi anbefaler ikke storskala-klyngeinstallationer med Kubernetes eller lignende platforme, da de kan øge den driftsmæssige kompleksitet og vedligeholdelsesindsatsen betydeligt.

</Accordion>

<Accordion title="Q02: Hvordan kan jeg sikre tilgængelighed, når jeg betjener tusindvis af brugere?">

Se vores vejledning om [horisontal skalering](/da/on-premises/maintenance/horizontal-scaling). Du kan installere flere Overleaf-instanser og konfigurere en load balancer til at fordele trafikken mellem dem.

</Accordion>

<Accordion title="Q03: Kan I hjælpe mig med installation eller migrering?">

Hvis du har en eksisterende Overleaf Server Pro-instans, hjælper vi gerne med at migrere til Ayakaleaf Pro. Kontakt os via e-mail eller issues.

</Accordion>

### LaTeX

<Accordion title="Q01: Er brugernes LaTeX-projektkompileringer isolerede? Er Shell Escape aktiveret?">

Når du aktiverer Sandbox Compiles, kører hver brugers kompilering i en separat Docker-container og er isoleret fra andre brugeres kompileringer. Shell Escape er som standard aktiveret for Sandbox Compiles.

</Accordion>

<Accordion title="Q02: Er Sandbox Compiles-imaget pålideligt? Kan kompileringen mislykkes?">

Vi har forbedret vores TeX Live Full-image til Sandbox Compiles gennem de seneste tre år. I de fleste tilfælde kompilerer projekter, der kompilerer på overleaf.com, også korrekt med Ayakaleaf Pro. Hvis en nødvendig skrifttype ikke er tilgængelig, skal du uploade skrifttypen til dit projekt manuelt.

</Accordion>

<Accordion title="Q03: Mit projekt vil ikke kompilere. Kan I hjælpe mig med at fejlfinde det?">

Upload dit projekt til Overleafs officielle websted, aktivér deling via skrivebeskyttet link, og inkluder linket i et GitHub-issue.

Vi undersøger og retter alle fejl, der forhindrer et projekt i at kompilere i Ayakaleaf Pro, når det kompilerer korrekt på Overleafs officielle websted. Kompileringsproblemer uden for dette område er ikke dækket af vores support.

</Accordion>
