<Info>

Ayakaleaf Pro er en forbedret implementering af Overleaf Community Edition, der tilbyder alle Server Pro-funktioner _**gratis**_. I modsætning til Overleaf Common, der er tilgængelig på [https://www.overleaf.com/](https://www.overleaf.com/), har vi ingen begrænsninger på kompileringstid og ingen licenskrav til antallet af brugere, og du kan selvhoste dine egne data fuldt ud, hvilket sikrer absolut sikkerhed.

Overleaf Server Pro er en kommerciel, selvhostet udgave af Overleaf med officiel support. For mere information om Server Pro, besøg [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud).

</Info>

<Warning>

Overleaf Community Edition er beregnet til brug i miljøer, hvor **alle** brugere er betroede. Community Edition er **ikke** egnet til scenarier, hvor isolation af brugere er påkrævet, da Sandbox Compiles ikke er tilgængelige.

Uden sandboxing kører LaTeX-kompileringer med de samme rettigheder som containeren, hvilket giver adgang til dens filsystem, netværk og miljøvariabler. Dette skaber en risiko for dataeksponering eller kompromittering af systemet. Kompileringer uden sandbox bør kun bruges i fuldt betroede miljøer; til installationer med flere brugere eller i produktion anbefales Sandbox Compiles kraftigt.

For mere information om Sandbox Compiles, se vores [dokumentation](/da/on-premises/configuration/overleaf-toolkit/sandboxed-compiles).

</Warning>

### Community-support

For personer, der bruger en selvhostet Overleaf-instans, ydes support af fællesskabet via GitHub [Issues](https://github.com/ayaka-notes/overleaf-pro/issues).

For at forblive på et understøttet spor kan du bekræfte, hvilken version af Overleaf du kører, ved at sammenligne outputtet af kommandoen nedenfor med de image-id'er, der er offentliggjort i udgivelsesnoterne.

```bash
docker inspect --format '{{.Image}}' sharelatex | awk -F: '{print substr($2, 1, 12)}'
```
