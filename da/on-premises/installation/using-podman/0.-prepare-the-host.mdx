---
title: 0. Forbered værten
description: Tjek styresystemet og SELinux, og installer git, før du sætter rootless Podman op.
icon: server
---

Du installerer ikke Podman manuelt: [2. Kør podman-setup](/da/on-premises/installation/using-podman/2.-run-podman-setup) installerer det sammen med de andre pakker, det har brug for. Her tjekker du kun værten og installerer `git`, som du skal bruge til at downloade Toolkit.

<Steps>
<Step title="Tjek styresystemet og SELinux">
Log ind som den bruger, der skal køre Ayakaleaf Pro, ikke som `root`, og tjek distributionen og SELinux-tilstanden:

```bash title="Check the host"
grep PRETTY_NAME /etc/os-release
getenforce
```

Du bør se RHEL, Rocky Linux, AlmaLinux eller CentOS Stream i version 9 eller nyere, og `Enforcing`:

```text
PRETTY_NAME="Rocky Linux 9.9 (Blue Onyx)"
Enforcing
```
</Step>

<Step title="Tjek, at du kan bruge sudo">
`bin/podman-setup --apply` installerer pakker og indlæser et SELinux-modul med `sudo` og beder om din adgangskode, når det er nødvendigt:

```bash title="Check sudo"
sudo -v
```

Hvis det fejler, så bed din administrator om at tilføje din bruger til gruppen `wheel`.
</Step>

<Step title="Installer git">
```bash title="Install git"
sudo dnf install -y git
```

<Warning>

Installer ikke Docker Engine på denne vært. Pakken `podman-docker`, som `bin/podman-setup` installerer, leverer kommandoen `docker`, og Toolkit behandler værten som Podman, så snart kommandoen `podman` findes.

</Warning>
</Step>
</Steps>
