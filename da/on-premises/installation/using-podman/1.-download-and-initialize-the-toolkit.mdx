---
title: 1. Download og initialiser Toolkit
description: Klon Ayakaleaf Toolkit, opret konfigurationen og sæt den op til Ayakaleaf Pro på Podman.
icon: arrow-down-to-bracket
---

<Steps>
<Step title="Klon Toolkit">
Klon **Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)) til din hjemmemappe, og skift til den:

```bash title="Clone the Toolkit" wrap
git clone https://github.com/ayaka-notes/toolkit.git ~/overleaf-toolkit
cd ~/overleaf-toolkit
```

Kør alle de følgende kommandoer fra denne mappe.
</Step>

<Step title="Opret konfigurationen">
```bash title="Run initialization"
bin/init
```

Dette opretter `config/overleaf.rc`, `config/variables.env` og `config/version`, som beskrevet i [3. Initialiser konfigurationen](/da/on-premises/installation/using-docker-compose/linux/3.-initialize-the-configuration) i Docker-vejledningen. `bin/init` har endnu ikke brug for Podman.
</Step>

<Step title="Opsæt config/overleaf.rc">
Åbn `config/overleaf.rc`, og ret disse linjer:

```bash title="config/overleaf.rc"
SERVER_PRO=true
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
```

Tilføj derefter denne linje i slutningen af filen:

```bash title="config/overleaf.rc"
SELINUX_MODE=managed
```

| Indstilling                       | Hvorfor                                                                                                                                                                                                     |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SERVER_PRO=true`                 | Bruger Ayakaleaf Pro-imaget fra `ghcr.io`. Der kræves intet login.                                                                                                                                           |
| `OVERLEAF_PORT=8080`              | Rootless Podman kan ikke lytte på porte under `1024`. Standardporten `80` fejler.                                                                                                                           |
| `SIBLING_CONTAINERS_ENABLED=true` | Kører hver kompilering i sin egen TeX Live-container. Allerede `true` som standard; Podman-opsætningen understøtter kun denne tilstand.                                                                     |
| `SELINUX_MODE=managed`            | Kører `sharelatex`-containeren med SELinux-typen `sharelatex_t`, som må bruge Podman-socketten og intet andet. `bin/podman-setup --apply` installerer politikmodulet til den. Se [Toolkit-indstillinger](/da/on-premises/configuration/overleaf-toolkit/toolkit-settings) for de andre tilstande. |

Lad `DOCKER_SOCKET_PATH` være, som den er: `bin/podman-setup --apply` sætter den til din Podman-socket i næste trin.

<Warning>

Behold `GIT_BRIDGE_ENABLED=false`. I Ayakaleaf Pro 6.3.4 virker Git-integrationen ikke på Podman, se [Kendte begrænsninger](/da/on-premises/installation/using-podman#known-limitations).

</Warning>
</Step>

<Step title="Vælg TeX Live-images">
Åbn `config/variables.env`, fjern `#` foran `TEX_LIVE_DOCKER_IMAGE` og `ALL_TEX_LIVE_DOCKER_IMAGES`, og angiv de TeX Live-images, der skal bruges:

```bash title="config/variables.env" wrap
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
```

`bin/up` stopper med `Please configure ALL_TEX_LIVE_DOCKER_IMAGES`, hvis listen er tom. `texlive-full` er stort; til en testserver virker det meget mindre `ghcr.io/ayaka-notes/texlive-basic:2026.1` også. Se [Sandboxed Compiles](/da/on-premises/configuration/overleaf-toolkit/sandboxed-compiles) for de tilgængelige images.

Sæt de andre variabler, såsom `OVERLEAF_SITE_URL`, som beskrevet i [5. Tilpasning af din instans](/da/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance#required-environment-variables). Med standardlytteadressen skal du bruge `http://localhost:8080`.
</Step>
</Steps>
