Toolkit er det samme som på Linux. Dets struktur, mappen `config/` og `bin/`-kommandoerne er beskrevet i [2. Bliv fortrolig med Toolkit](/da/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) i Linux-vejledningen.

På Windows skal du huske disse forskelle:

* Kør `bin/`-kommandoer i **Ubuntu Bash** fra `~/ayakaleaf-toolkit`. Kommandoer, der er markeret med **PowerShell**, køres i stedet i Windows.
* Start Docker Desktop, og aktiver Ubuntus WSL Integration, før du bruger `bin/up`, `bin/start` eller `bin/docker-compose`.
* Behold konfigurationsfiler med Linux-linjeskift (LF). Rediger dem med `nano` i Ubuntu eller en editor, der er forbundet til WSL. CRLF-linjeskift kan give Bash-fejl.
* `bin/doctor` kører Linux-kontroller i Ubuntu. Dens advarsel om, at du ikke er logget ind på `quay.io`, gælder ikke for det offentlige `ghcr.io/ayaka-notes/overleaf-pro`-image. Andre advarsler kræver stadig opmærksomhed.

```bash
bin/doctor
```
