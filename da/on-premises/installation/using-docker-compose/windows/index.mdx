I dette afsnit kører vi Ayakaleaf Pro lokalt på Windows med WSL 2, Ubuntu, Docker Desktop og [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). Vejledningen bruger `http://localhost:8080`, gemmer data i Ubuntus hjemmemappe og aktiverer sandboxed compiles.

Applikationen, MongoDB, Redis og TeX Live kører i Linux-containere, der administreres af Docker Desktop. Kør Toolkit-kommandoer i Ubuntu; åbn applikationen i din Windows-browser. [Trin 0](/da/on-premises/installation/using-docker-compose/windows/0.-setup-wsl-and-docker-desktop) forklarer, hvordan Windows- og Linux-delene hænger sammen, og starter med installation af WSL.

Du kan bruge Windows til en lokal instans eller holde den kørende hele tiden med tilgængelighedsindstillingerne i trin 6. Til delte servere og produktionsservere anbefaler vi [Linux-vejledningen](/da/on-premises/installation/using-docker-compose/linux) med HTTPS, sikkerhedskopier og adgangskontrol. Windows-dvale, nedlukning af Docker Desktop og nedlukning af WSL afbryder denne lokale instans; se [Hold instansen tilgængelig](/da/on-premises/installation/using-docker-compose/windows/6.-post-installation-tasks#keep-the-instance-available).

## Før du starter {#before-you-start}

Du skal bruge:

* En Windows-version og en processor, der understøttes af [Docker Desktop for Windows](https://docs.docker.com/desktop/setup/install/windows-install/), med hardwarevirtualisering aktiveret. Denne vejledning bruger Windows 11 på x86-64.
* Tilladelse til at aktivere WSL og installere software. WSL skal være version 2.1.5 eller nyere, og Ubuntu skal køre i WSL 2-tilstand.
* Nok hukommelse til Windows og containerne. Til en lille lokal instans er 4 CPU'er og 8 GB tilgængeligt for Docker et foreslået udgangspunkt, ikke et målt minimum.
* Ledig lagerplads på den Windows-disk, der indeholder WSL- og Docker-data. Afsæt mindst 40 GB til en fuld TeX Live-opsætning plus projektdata; basic-imaget i [trin 5](/da/on-premises/installation/using-docker-compose/windows/5.-personalizing-your-instance) er mindre og egnet til den første udrulningstest. Yderligere image-versioner kræver yderligere plads.
* Netværksadgang til GitHub, GitHub Container Registry (`ghcr.io`) og Docker Hub for at klone Toolkit og downloade images.

**PowerShell**-blokke køres i Windows. **Bash**-blokke og `bin/`-kommandoer køres i Ubuntu, medmindre andet er angivet. Kør ikke Toolkit-scripts i PowerShell eller Windows Git Bash.
