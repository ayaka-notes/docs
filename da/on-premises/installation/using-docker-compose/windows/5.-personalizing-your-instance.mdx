---
title: 5. Tilpasning af din instans
description: Angiv port, site-URL og TeX Live-image, aktiver sandboxed compiles, og start Ayakaleaf Pro på WSL 2.
icon: square-sliders
---

Kør kommandoer og rediger filer i **Ubuntu** fra `~/ayakaleaf-toolkit`.

<Steps>
<Step title="Containerindstillinger">
Rediger de eksisterende poster i `config/overleaf.rc`:

```bash title="config/overleaf.rc"
PROJECT_NAME=ayakaleaf-wsl
SERVER_PRO=true
OVERLEAF_LISTEN_IP=127.0.0.1
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
DOCKER_SOCKET_PATH=/var/run/docker.sock
```

Behold standardstierne til data og de medfølgende MongoDB- og Redis-tjenester. Port `8080` er til den lokale Windows-browser; binding til `127.0.0.1` holder den lokal. Sandboxed compiles bruger en separat Linux-container til hver kompilering i stedet for at køre TeX inde i applikationscontaineren. Docker-socket'en lader applikationen oprette disse containere, og Toolkit leverer værtsstien til kompileringsdataene under `data/overleaf/data/compiles`.
</Step>

<Step title="Applikationsindstillinger">
Sæt disse værdier i `config/variables.env`, og erstat eventuelle aktive poster med de samme navne:

```dotenv title="config/variables.env"
OVERLEAF_SITE_URL=http://localhost:8080
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES="TeX Live 2026"
```

Det fulde image indeholder de pakker og skrifttyper, der kræves til en bred vifte af projekter. Afsæt mindst 40 GB ledig lagerplads til det og applikationen plus plads til projektdata og fremtidige opdateringer.

Til en hurtig udrulningstest kan du i stedet bruge det mindre **basic**-image. Det er nok til den simple artikeltest i trin 6, men indeholder ikke det fulde sæt af pakker og skrifttyper:

```dotenv
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-basic:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-basic:2026.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES="TeX Live 2026 Basic"
```

Vælg ét af disse sæt uden dublerede aktive nøgler. Basic-imagets [Dockerfile](https://github.com/ayaka-notes/texlive-full/blob/main/texlive/2026/Dockerfile.basic) indeholder `latexmk`, XeTeX og `fontspec`, men ikke `ctex` eller den fulde skrifttypesamling. En manglende LaTeX-pakke i basic er ikke i sig selv tegn på et sandbox-problem.

Generér en sessionshemmelighed:

```bash
openssl rand -hex 32
```

Tilføj resultatet som `OVERLEAF_SESSION_SECRET` i `config/variables.env`. Behold også den genererede invite-token-hemmelighed. For en lokal instans uden e-mail skal du lade SMTP-indstillingerne og `OVERLEAF_EMAIL_FROM_ADDRESS` være usat.
</Step>

<Step title="Start din instans">
```bash
bin/up -d
```

Toolkit starter MongoDB, initialiserer dens replica set, downloader det valgte TeX Live-image og starter Redis og applikationen. Den kan se ud til at holde pause, mens et stort image downloades. Kør ikke en ny `bin/up`, mens den første stadig arbejder.

Kontrollér i en anden Ubuntu-terminal:

```bash
cd "$HOME/ayakaleaf-toolkit"
bin/docker-compose ps
bin/docker-compose logs --tail=100 mongo
bin/docker-compose logs --tail=100 -f sharelatex
```

Tryk på `Ctrl+C` for at stoppe med at følge loggene; frakoblede containere bliver ved med at køre. Hvis opstarten mislykkes ved MongoDB, skal du følge [MongoDB starter ikke](/da/on-premises/installation/using-docker-compose/windows/troubleshooting#mongodb-fails-to-start), før du prøver igen. Slet ikke dens datamappe for at nulstille en eksisterende installation.

Kontrollér porten og siden til første kørsel:

```bash
bin/docker-compose port sharelatex 80
curl -I http://localhost:8080/launchpad
```

Porten skal være `127.0.0.1:8080`. Vent på, at applikationen er initialiseret, hvis HTTP-forespørgslen først mislykkes.
</Step>

<Step title="Åbn instansen fra Windows">
Åbn [http://localhost:8080/launchpad](http://localhost:8080/launchpad) i din **Windows-browser**. Brug også denne adresse i Windows i stedet for en midlertidig WSL-IP-adresse.

For at kontrollere HTTP-adgang fra Windows uafhængigt af browseren skal du køre følgende i **PowerShell**:

```powershell
curl.exe -I http://localhost:8080/launchpad
```

Hvis Ubuntu kan nå siden, men Windows ikke kan, kan du se [Windows kan ikke åbne localhost](/da/on-premises/installation/using-docker-compose/windows/troubleshooting#windows-cannot-open-localhost).
</Step>
</Steps>
