<Steps>
<Step title="Installer kommandolinjeværktøjerne">
Kør i **Ubuntu** med den Linux-adgangskode, du oprettede i trin 0:

```bash
sudo apt update
sudo apt install -y git ca-certificates curl perl gawk openssl
```

Ubuntu leverer allerede Bash, GNU sed og coreutils. I modsætning til macOS kræver det ikke Homebrew eller en separat installation af GNU sed.
</Step>

<Step title="Klon Ayakaleaf Toolkit-repositoriet">
Placer Toolkit og dets data i Ubuntus Linux-filsystem under din hjemmemappe:

```bash
cd "$HOME"
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

Undgå `/mnt/c`, `/mnt/d`, OneDrive og midlertidige mapper til den aktive database og projektdataene. Stier i Linux-filsystemet giver de tilladelser og den filsystemadfærd, som containerne forventer, og undgår overhead på tværs af filsystemer; se [Microsofts vejledning om filsystemer](https://learn.microsoft.com/en-us/windows/wsl/filesystems).

<Warning>

Hvis mappen allerede indeholder en installation, skal du bruge den, som den er, eller vælge en anden mappe til en ny instans. Erstat ikke en eksisterende udrulnings konfiguration eller data.

</Warning>
</Step>
</Steps>
