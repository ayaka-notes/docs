### Opret administratoren og et første projekt {#create-the-administrator-and-a-first-project}

Åbn [http://localhost:8080/launchpad](http://localhost:8080/launchpad), opret den første administratorkonto, og log ind. Følg derefter [6. Opgaver efter installationen](/da/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks) i Linux-vejledningen, og brug port `8080` i dens eksempel-URL'er.

### Kontrollér kompilering {#verify-compilation}

At en loginside åbner, beviser ikke, at de separate kompileringscontainere og deres data-mounts virker. Opret et tomt projekt, og kompilér denne `main.tex`:

```latex
\documentclass{article}
\begin{document}
Ayakaleaf Pro on macOS.
\end{document}
```

PDF-forhåndsvisningen skal vise teksten. Vælg om nødvendigt TeX Live 2026 i projektindstillingerne.

For et projekt med kinesisk tekst skal du vælge **XeLaTeX** som kompilator og teste:

```latex
\documentclass{ctexart}
\begin{document}
你好，Ayakaleaf Pro。
\end{document}
```

### Kontrollér persistens {#verify-persistence}

```bash
bin/stop
bin/start
```

Åbn projektet igen, og kompilér det igen. Din konto, kildekoden og projektfilerne skal stadig være der. Med standardstierne ligger de aktive data i Toolkits `data/`-mappe på din Mac.

### Hold instansen tilgængelig {#keep-the-instance-available}

Mens Mac'en er i dvale, suspenderer macOS Docker Desktops virtuelle maskine med alle containere i den: ingen kan åbne instansen, og en kompilering, der kører, stopper, indtil Mac'en vågner. Kun systemdvale har betydning. Skærmen må gerne slukke.

Hvis andre bruger instansen, eller du lader lange opgaver køre, skal du holde Mac'en tilsluttet strøm og forhindre automatisk dvale; se [Indstil dvale- og vågneindstillinger på din Mac](https://support.apple.com/guide/mac-help/set-sleep-and-wake-settings-mchle41a6ccd/mac):

| Mac | Indstilling |
| --- | --- |
| Stationær Mac (Mac mini, iMac, Mac Studio, Mac Pro) | **System Settings → Energy**: slå **Prevent automatic sleeping when the display is off** til |
| MacBook | **System Settings → Battery → Options**: slå **Prevent automatic sleeping on power adapter when the display is off** til. Dette gælder kun, mens strømadapteren er tilsluttet, og hvis du lukker låget, går MacBook'en stadig i dvale |

Hvis Mac'en kun skal holdes vågen i et stykke tid, kan du i stedet køre `caffeinate -i` i et Terminal-vindue. Det forhindrer dvale ved inaktivitet, indtil du trykker på `Ctrl+C` eller lukker vinduet.

Docker Desktop er en app i din brugersession. For at få instansen tilbage efter en genstart skal du slå **Start Docker Desktop when you sign in to your computer** til under **Settings → General** i Docker Desktop. Toolkits containere bruger `restart: always`, så Docker starter dem igen, når Docker Desktop kører, uden `bin/up`. Indtil nogen logger ind på Mac'en efter en genstart, forbliver instansen nede.

<Info>

En Mac, der holdes vågen, bruger mere strøm. Til en tjeneste, der altid skal kunne nås, anbefaler vi en Linux-server; se [Linux](/da/on-premises/installation/using-docker-compose/linux).

</Info>

### Daglig brug {#daily-use}

Åbn Docker Desktop, før du administrerer instansen. I en ny terminal:

```bash
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
cd "$HOME/ayakaleaf-toolkit"
```

| Opgave | Kommando |
| --- | --- |
| Start de eksisterende containere | `bin/start` |
| Stop containerne, og behold dataene | `bin/stop` |
| Anvend konfigurationsændringer | `bin/up -d` |
| Kontrollér status | `bin/docker-compose ps` |
| Læs opstartsloggene | `bin/docker-compose logs --tail=100 sharelatex` |
| Læs kompilatorens logge | `bin/logs -f clsi` |

`bin/start` anvender ikke ændringer i `config/`: kør `bin/up -d`, når du har redigeret konfigurationen. Behold `config/` og `data/`, og følg [Data og sikkerhedskopier](/da/on-premises/maintenance/data-and-backups) før en opgradering, eller før du flytter installationen. At kopiere databasefilerne, mens MongoDB skriver til dem, er ikke en konsistent sikkerhedskopi.

Behold instansen på `127.0.0.1` til lokal brug. For at betjene andre computere skal du bevidst angive lytteadresse, site-URL og HTTPS; se [5. Tilpasning af din instans](/da/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance) i Linux-vejledningen.

Hvis noget ikke virker, kan du se [Fejlfinding](/da/on-premises/installation/using-docker-compose/macos/troubleshooting).
