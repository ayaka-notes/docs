I dette afsnit kører vi Ayakaleaf Pro lokalt på din Mac med Docker Desktop og [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). Vejledningen bruger `http://localhost:8080`, gemmer dataene i din hjemmemappe og kompilerer med TeX Live 2026 i sandboxede containere.

Docker Desktop kører applikationen, MongoDB, Redis og TeX Live-kompilatoren i en virtuel Linux-maskine. Du installerer ikke MongoDB, Redis eller MacTeX på selve macOS.

Brug denne opsætning til personlig brug og lokal test. Til en delt tjeneste, der altid er tilgængelig, anbefaler vi [Linux-vejledningen](/da/on-premises/installation/using-docker-compose/linux) med HTTPS, sikkerhedskopier og adgangskontrol. Instansen er utilgængelig, mens Mac'en er i dvale, eller Docker Desktop er stoppet; se [Hold instansen tilgængelig](/da/on-premises/installation/using-docker-compose/macos/6.-post-installation-tasks#keep-the-instance-available).

## Før du starter {#before-you-start}

Du skal bruge:

* En macOS-version, der understøttes af [Docker Desktop for Mac](https://docs.docker.com/desktop/setup/install/mac-install/).
* Git, [Homebrew](https://brew.sh/) og GNU sed. Toolkit bruger GNU sed-indstillinger, som den BSD sed, der er indbygget i macOS, ikke accepterer.
* Nok ressourcer til både macOS og Docker. Til en lille lokal instans kan du starte med 4 CPU'er og 8 GB hukommelse tildelt Docker Desktop. Dette er et foreslået udgangspunkt, ikke et målt minimum.
* Mindst 40 GB ledig lagerplads til et fuldt TeX Live-image plus plads til dine projekter. Kontrollér både den ledige plads på Mac'en og Docker Desktops grænse for diskforbrug. Start med én TeX Live-version: hver ekstra version kræver omtrent lige så meget plads igen.

Applikations- og TeX Live-images udgives til `arm64` og `amd64`. På Apple silicon skal du lade Docker vælge det native ARM-image og ikke gennemtvinge `platform: linux/amd64`.
