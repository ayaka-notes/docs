<Steps>
<Step title="Kontrollér Git og Homebrew">
```bash
git --version
brew --version
```

Hvis macOS beder dig om at installere Command Line Tools, når du kører Git, skal du installere dem først. Hvis Homebrew mangler, kan du installere det med den [officielle vejledning](https://brew.sh/).
</Step>

<Step title="Sæt GNU sed på PATH">
Toolkit-scriptene bruger GNU sed-indstillinger, som den BSD sed, der er indbygget i macOS, afviser. Installer [GNU sed](https://formulae.brew.sh/formula/gnu-sed), og sæt den først på `PATH` i denne terminal:

```bash
brew install gnu-sed
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
sed --version
```

Den sidste kommando skal udskrive **GNU sed**.

Et alias som `alias sed=gsed` er ikke nok: Toolkit kører Bash-scripts, som ikke ser aliasserne i din interaktive shell. Du behøver ikke at erstatte `/usr/bin/sed`.

Kør linjen `export PATH=...` igen i hver ny terminal, du bruger til Toolkit, eller tilføj den til din shells opstartsfil efter Homebrews egen initialisering.
</Step>

<Step title="Klon Ayakaleaf Toolkit-repositoriet">
Vælg en mappe, der bevares. Undgå `/tmp`, flytbare drev og cloudsynkroniserede mapper som iCloud Drive til den aktive database og projektdataene. Denne vejledning bruger `~/ayakaleaf-toolkit`:

```bash
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

<Warning>

Hvis mappen allerede indeholder en installation, skal du bruge den, som den er, eller vælge en anden mappe til en ny instans. Initialiser ikke en ny konfiguration oven på en eksisterende udrulning.

</Warning>
