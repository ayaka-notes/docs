Ayakaleaf Pro kører på Docker. På en Mac bruger du Docker Desktop, som kører Docker-enginen i en virtuel Linux-maskine.

<Steps>
<Step title="Installer og start Docker Desktop">
Installer den version af [Docker Desktop](https://docs.docker.com/desktop/setup/install/mac-install/), der passer til din Mac (Apple silicon eller Intel), åbn den, og vent, til enginen er startet. Du kan også starte den fra Terminal:

```bash
open -a Docker
```
</Step>

<Step title="Kontrollér Docker-enginen">
Kør disse kommandoer i Terminal:

```bash
docker context show
docker info
docker compose version
```

Konteksten skal pege på din lokale Docker Desktop-engine, normalt `desktop-linux`. Hvis en anden kontekst er valgt, skal du skifte til Docker Desktop, før du fortsætter:

```bash
docker context use desktop-linux
```

`docker info` skal udskrive en **Server**-sektion. `docker --version` alene viser kun, at klienten er installeret.
</Step>

<Step title="Kontrollér ressourcer og fildeling">
Under **Settings** i Docker Desktop skal du kontrollere grænserne for CPU, hukommelse og disk i forhold til [Før du starter](/da/on-premises/installation/using-docker-compose/macos#before-you-start) samt indstillingerne for fildeling; se [Docker Desktop settings](https://docs.docker.com/desktop/settings-and-maintenance/settings/).

Denne vejledning placerer Toolkit under `/Users`, som Docker Desktop deler som standard. Hvis du bruger en anden placering, og `bin/up` mislykkes med `Mounts denied`, skal du tilføje den mappe til fildelingen.
</Step>

<Step title="Kontrollér Docker-socket til sandboxed compiles">
Toolkit monterer `/var/run/docker.sock` i applikationen, så den kan starte en separat TeX Live-container til hver kompilering. Behold `DOCKER_SOCKET_PATH=/var/run/docker.sock` i `config/overleaf.rc`.

Docker CLI på macOS kan forbinde via `~/.docker/run/docker.sock`. Det er klientens endpoint på Mac'en og ikke en grund til at ændre Toolkits mount-kilde: kompilatoren har brug for engine-socket'en, som Linux-containere ser den.

Hvis `/var/run/docker.sock` mangler på Mac'en, skal du slå **Allow the default Docker socket to be used** til under **Settings → Advanced**; se [Dockers krav til tilladelser](https://docs.docker.com/desktop/setup/install/mac-permission-requirements/).

<Danger>

Kør ikke `chmod 777` på socket'en for at omgå fejl. Adgang til Docker-socket'en svarer til root-adgang til Docker-VM'en.

</Danger>
</Step>
</Steps>
