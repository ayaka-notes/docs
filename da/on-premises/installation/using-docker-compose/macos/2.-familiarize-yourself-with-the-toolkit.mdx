Toolkit er det samme på macOS og Linux. Dets struktur, mappen `config/` og `bin/`-kommandoerne er beskrevet i [2. Bliv fortrolig med Toolkit](/da/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) i Linux-vejledningen.

På macOS skal du huske tre forskelle:

* Kør scriptene fra en terminal, hvor GNU sed står først på `PATH`; se [1. Download Toolkit](/da/on-premises/installation/using-docker-compose/macos/1.-download-the-toolkit).
* Start Docker Desktop, før du kører et script, der taler med Docker, såsom `bin/up`, `bin/start` eller `bin/docker-compose`.
* `bin/doctor` indeholder kontroller, der er arvet fra det officielle Overleaf Toolkit. Dens advarsel `This system seems to not be Linux` er forventet på macOS, og dens advarsel om, at du ikke er logget ind på `quay.io`, gælder ikke for det offentlige `ghcr.io/ayaka-notes/overleaf-pro`-image. Andre problemer i rapporten har stadig betydning.
