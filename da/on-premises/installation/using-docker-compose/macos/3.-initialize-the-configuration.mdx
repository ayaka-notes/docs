---
title: 3. Initialiser konfigurationen
description: Opret Toolkits konfigurationsfiler på din Mac med bin/init.
icon: circle-play
---

Kør følgende fra Toolkit-mappen i en terminal med GNU sed på `PATH`:

```bash
bin/init
```

`bin/init` opretter tre filer:

| Fil | Formål |
| --- | --- |
| `config/overleaf.rc` | Containerindstillinger, den publicerede port og dataplaceringerne |
| `config/variables.env` | Applikationsindstillinger og hemmeligheder |
| `config/version` | Versionen af applikationsimaget |

Den genererer også `OVERLEAF_INVITE_TOKEN_SECRET` i `config/variables.env`. Behold den, og offentliggør ikke denne fil, og commit den ikke til versionsstyring.

Behold den version, som Toolkit vælger til en ny installation. For senere at ændre versionen af en eksisterende instans skal du følge [Opgradering af din udrulning](/da/on-premises/maintenance/upgrading-your-deployment).

<Warning>

Hvis `bin/init` stopper med `sed: ... invalid command code`, kørte den med macOS' BSD sed. En sådan mislykket kørsel kan efterlade alle tre filer i `config/` med en tom `OVERLEAF_INVITE_TOKEN_SECRET`, og hvis du kører `bin/init` igen, rapporterer den `Config files already exist`. Se [Fejlfinding](/da/on-premises/installation/using-docker-compose/macos/troubleshooting#initialization-fails-with-invalid-command-code).

</Warning>
