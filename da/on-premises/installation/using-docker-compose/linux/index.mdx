I dette afsnit guider vi dig gennem installation af Docker, download af Toolkit fra GitHub, hjælper dig med at blive fortrolig med nogle af Toolkits kommandoer og konfigurerer nogle grundlæggende indstillinger. Ved slutningen af dette afsnit bør du have en kørende on-premises-instans af Overleaf.

Trinene er rettet mod en nyere Ubuntu LTS. På en anden distribution skal du installere Docker Engine og Compose-pluginet som beskrevet i [Dockers dokumentation](https://docs.docker.com/engine/install/) og derefter fortsætte med [1. Download Toolkit](/da/on-premises/installation/using-docker-compose/linux/1.-download-the-toolkit).

<Info>

Som standard accepterer instansen kun forbindelser fra selve serveren på `http://localhost`. For at åbne den fra andre computere eller på en anden port skal du sætte `OVERLEAF_LISTEN_IP` og `OVERLEAF_PORT` i `config/overleaf.rc` som beskrevet i [5. Tilpasning af din instans](/da/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance).

</Info>
