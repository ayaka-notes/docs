Docker Compose på en enkelt server er den anbefalede måde at udrulle Ayakaleaf Pro på. Du kører det via [Toolkit](https://github.com/ayaka-notes/toolkit): en samling scripts, der omslutter `docker compose` og læser dine indstillinger fra én `config/`-mappe, så `bin/up` erstatter `docker compose up`.
