Brug Claude Code eller Codex til at planlægge og gennemføre en udrulning af Ayakaleaf Pro. Agenten kan søge i denne dokumentation via MCP, mens den arbejder.

Agenten hjælper med udrulningen. Du er fortsat ansvarlig for at gennemgå kommandoer og beskytte legitimationsoplysninger.

### Før du starter

Klargør en understøttet Linux-server med SSH-adgang. Gennemgå [kravene](/da/on-premises/getting-started/requirements  "mention"), før du fortsætter.

<Warning>

Indsæt ikke adgangskoder, private nøgler, tokens eller licensnøgler i agentprompts. Gennemgå hver kommando, før du kører den, især kommandoer, der ændrer filer, netværk eller containere.

</Warning>

### Forbind dokumentationen

Tilføj dokumentationens MCP-endpoint til din lokale agent.

<Tabs>
<Tab title="Claude Code">

```bash wrap
claude mcp add ayakaleaf-pro --scope user --transport http https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>

<Tab title="Codex">

```bash wrap
codex mcp add ayakaleaf-pro --url https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>
</Tabs>

Start en ny session, når du har tilføjet serveren. Bed agenten om at bekræfte, at den kan søge i Ayakaleaf Pro-dokumentationen.

### Udrul Ayakaleaf Pro

Åbn en terminal på din udrulningsserver. Start Claude Code eller Codex der. Send derefter denne prompt:

```text wrap
Use the Ayakaleaf Pro documentation MCP server to guide this deployment.
First, inspect the requirements and installation guides.
Ask me for missing deployment details before making changes.
Use the Ayakaleaf Toolkit unless the documentation requires another approach.
Before configuring the instance, summarize relevant optional features.
Ask which features and integrations I want to enable.
Include TLS, sandboxed compiles, Git integration, external MongoDB or Redis,
SSO (OIDC, SAML, or LDAP), GitHub Synchronisation, Zotero, S3 storage,
email delivery, branding, and localization when relevant.
Explain each selected option's prerequisites, security impact, and configuration steps.
Keep unselected optional features disabled.
Show each command before running it.
Do not expose, store, or request secrets in chat.
After deployment, verify that the service is healthy and summarize the changes.
```

Agenten bør guide dig gennem opsætning af Docker, konfiguration af Toolkit, hentning af images og opstart. Følg vejledningen [using-the-toolkit](/da/on-premises/installation/using-the-toolkit  "mention") for den officielle arbejdsgang.

### Vælg valgfrie funktioner

Bed agenten om kun at anbefale funktioner, der passer til dit miljø. Typiske valg omfatter:

* **Adgang og sikkerhed:** TLS, sandboxed compiles og SSO via OIDC, SAML eller LDAP.
* **Eksterne tjenester:** MongoDB, Redis, S3-lagring og afsendelse af e-mail.
* **Samarbejde:** Git-integration, GitHub-synkronisering og Zotero.

Agenten bør forklare afhængigheder, før den redigerer konfigurationen. Gennemgå [toolkit-settings.md](/da/on-premises/configuration/overleaf-toolkit/toolkit-settings  "mention") og [godkendelse](/da/on-premises/configuration/overleaf-toolkit/authentication  "mention"), før du aktiverer integrationer i produktion.

### Verificer udrulningen

Når agenten har gennemført trinnene:

1. Bekræft, at hver kommando blev gennemført uden fejl.
2. Åbn den konfigurerede Ayakaleaf Pro-URL i din browser.
3. Gennemfør [6.-post-installation-tasks.md](/da/on-premises/installation/using-the-toolkit/6.-post-installation-tasks  "mention").

For en eksisterende Community Edition-installation skal du bruge vejledningen [migrate-from-existing.md](/da/on-premises/installation/migrate-from-existing  "mention") i stedet for en ny udrulning.
