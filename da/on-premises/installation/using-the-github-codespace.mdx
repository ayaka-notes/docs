Den nemmeste måde at teste vores Ayakaleaf Pro på er at bruge GitHub Codespace, hvor alle miljøvariabler er forudkonfigureret, så du kan bruge det direkte ud af boksen.

<Warning>

Når du kører Docker-containere med GitHub Codespaces, lukker Codespace ikke automatisk ned og bliver ved med at blive **faktureret**. Se [GitHub Codespaces' faktureringsregler](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces) for reglerne for fakturering af GitHub Codespaces.

Gå til [https://github.com/codespaces](https://github.com/codespaces) for at administrere dine GitHub Codespaces. Når du ikke længere har brug for det, så slet dit Codespace i tide.

</Warning>

Vi har **forudkonfigureret** følgende funktioner:

* [x] LaTeX-kompilering i sandbox med TeXLive **Basic** (2024-2026)
* [x] Pandoc-import/-eksport (funktion fra SaaS-platformen)
* [x] Python-scriptkørsel (funktion fra SaaS-platformen)
* [x] Git-Bridge-understøttelse (funktion fra Server Pro)
* [x] Avanceret referencesøgning (funktion fra SaaS-platformen)
* [x] Administrationspanel (global administration af brugere/projekter)
* [x] Sporing af ændringer (med gennemgangs- og kommentarpanel)
* [x] Fuld projekthistorik (med gendannelse og download)
* [x] Symbolpalet (funktion fra Server Pro/SaaS-platformen)

<Warning>

Standard-GitHub Codespaces har 32 GB lagerplads. Det er ikke nok til vores `texlive-full`-installation. For at teste det fulde image skal du oprette en supportsag hos GitHub om et Codespace med store runners (8+ kerner).

</Warning>

GitHub-synkronisering, LDAP, OAuth, SSO, Zotero-integration og andre funktioner er _**ikke konfigureret**_ i denne playground. Se [Toolkit-indstillinger](/da/on-premises/configuration/overleaf-toolkit/toolkit-settings) for flere detaljer om, hvordan du konfigurerer disse funktioner i din egen udrulning.

#### Brug TeXLive Full-imaget

Hvis du har adgang til GitHub Codespaces med 8 kerner/64 GB, kan du bruge TeXLive Full-imaget i denne playground. Du kan ændre følgende miljøvariabler i filen `toolkit/config/variables.env` for at bruge TeXLive Full-imaget i stedet for TeXLive Basic-imaget.

```dotenv wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1, ghcr.io/ayaka-notes/texlive-full:2024.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025, Texlive 2024
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```

Når du har ændret miljøvariablerne, skal du genstarte toolkittet for at anvende ændringerne. Du kan køre følgende kommando for at genstarte toolkittet.

```bash
cd toolkit && bin/up -d
```
