### Oprettelse af din første administratorkonto

Åbn `OVERLEAF_SITE_URL` efterfulgt af `/launchpad`, for eksempel `http://192.0.2.10:30080/launchpad`, og registrér administratorkontoen som under [Toolkit'ets opgaver efter installationen](/da/on-premises/installation/using-the-toolkit/6.-post-installation-tasks). Opret derefter et eksempelprojekt, og kompilér det.

Du kan også oprette brugere fra kommandolinjen:

```bash
kubectl -n overleaf exec deploy/overleaf -- bash -c \
  'cd /overleaf/services/web && node modules/server-ce-scripts/scripts/create-user.mjs --admin --email=admin@example.com'
```

Den udskriver et link, der sætter adgangskoden.

### Kontrol af, at kompileringer er sandboxede

Kompilér et projekt, og se derefter på den node, der kører poden:

```bash
kubectl -n overleaf get pod -l app=overleaf -o wide   # NODE column
# on that node:
sudo docker ps -a --filter ancestor=ghcr.io/ayaka-notes/texlive-full:2026.1
ls -ln /srv/overleaf/compiles                          # owned by uid 33 (www-data)
```

Hver kompilering vises som en kortlivet container med navnet `project-<project id>-<user id>-...`.

### Logs og en shell

| Toolkit          | Kubernetes                                                               |
| ---------------- | ------------------------------------------------------------------------ |
| `bin/logs web`   | `kubectl -n overleaf exec deploy/overleaf -- tail -f /var/log/overleaf/web.log` |
| `bin/shell`      | `kubectl -n overleaf exec -it deploy/overleaf -- bash`                    |
| `bin/up`         | `kubectl apply -f .` og derefter `kubectl -n overleaf rollout restart deployment/overleaf` |

Containeren skriver én logfil pr. tjeneste i `/var/log/overleaf/` (`web.log`, `clsi.log`, `real-time.log`, `document-updater.log`, ...); `kubectl logs` viser opstartsoutputtet.

### Spørgsmål og svar

<Accordion title="Kompileringen mislykkes eller bliver aldrig færdig.">

<strong>Svar:</strong> Kontrollér på den node, der kører poden, at Docker kører og har det image, der er angivet i `TEX_LIVE_DOCKER_IMAGE`, og at `SANDBOXED_COMPILES_HOST_DIR_*` svarer til `hostPath`-stierne. `/var/log/overleaf/clsi.log` i poden angiver det trin, der fejler.

</Accordion>

<Accordion title="Brugerne logges ud efter hver genstart af poden.">

<strong>Svar:</strong> `OVERLEAF_SESSION_SECRET` mangler i Secret'et `overleaf-secrets`, se [trin 2](/da/on-premises/installation/using-kubernetes/2.-create-the-namespace-and-secrets).

</Accordion>
