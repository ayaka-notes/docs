title: 4. Tilpasning af din instans
description: Læg dine indstillinger i det ConfigMap, der erstatter config/variables.env.

---

ConfigMap'et `overleaf-env` træder i stedet for Toolkit'ets `config/variables.env`: alle miljøvariabler fra [Toolkit-dokumentationen](/da/on-premises/configuration/overleaf-toolkit/environment-variables) lægges her, og secrets lægges i Secret'et fra [trin 2](/da/on-premises/installation/using-kubernetes/2.-create-the-namespace-and-secrets).

```yaml title="30-config.yaml" wrap
apiVersion: v1
kind: ConfigMap
metadata:
  name: overleaf-env
  namespace: overleaf
data:
  OVERLEAF_APP_NAME: Ayakaleaf Pro
  OVERLEAF_SITE_URL: http://192.0.2.10:30080      # the address users open; https://... behind TLS
  OVERLEAF_ADMIN_EMAIL: admin@example.com
  # Emails: add the sender and the SMTP server together, see Email delivery
  # All members, so that the driver finds the primary even when mongo-0 is down
  OVERLEAF_MONGO_URL: mongodb://mongo-0.mongo:27017,mongo-1.mongo:27017,mongo-2.mongo:27017/sharelatex?replicaSet=overleaf
  OVERLEAF_REDIS_HOST: redis
  REDIS_HOST: redis
  ENABLED_LINKED_FILE_TYPES: project_file,project_output_file,url
  ENABLE_CONVERSIONS: "true"
  EMAIL_CONFIRMATION_DISABLED: "true"
  # Requests arrive from kube-proxy or your ingress controller, inside the pod network
  OVERLEAF_TRUSTED_PROXY_IPS: loopback,10.244.0.0/16
  # Sandboxed compiles. The HOST_DIR paths are paths ON THE NODE: the hostPath volumes that
  # the Deployment mounts at /var/lib/overleaf/data/{compiles,output,cache}.
  SANDBOXED_COMPILES: "true"
  SANDBOXED_COMPILES_SIBLING_CONTAINERS: "true"
  DOCKER_RUNNER: "true"
  SANDBOXED_COMPILES_HOST_DIR_COMPILES: /srv/overleaf/compiles
  SANDBOXED_COMPILES_HOST_DIR_OUTPUT: /srv/overleaf/output
  SANDBOXED_COMPILES_HOST_DIR_CACHE: /srv/overleaf/cache
  # Each image must be pulled into Docker on every node that can run Ayakaleaf Pro (step 0)
  ALL_TEX_LIVE_DOCKER_IMAGES: ghcr.io/ayaka-notes/texlive-full:2026.1
  ALL_TEX_LIVE_DOCKER_IMAGE_NAMES: TeX Live 2026
  TEX_LIVE_DOCKER_IMAGE: ghcr.io/ayaka-notes/texlive-full:2026.1
```

```bash
kubectl apply -f 30-config.yaml
```

| Variabel                                | Sæt den til                                                                                                                                                     |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_SITE_URL`                     | Den URL, brugerne skriver i browseren. Med NodePort fra [trin 5](/da/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro) en vilkårlig nodes IP og port `30080`; bag en ingress eller load balancer dens URL. |
| `OVERLEAF_MONGO_URL`                    | Dit replikasæt. Brug `?replicaSet=` med navnet fra `rs.initiate`.                                                                                              |
| `OVERLEAF_REDIS_HOST` og `REDIS_HOST`   | Begge til Redis-Service'en.                                                                                                                                    |
| `OVERLEAF_TRUSTED_PROXY_IPS`            | `loopback` plus de netværk, dine proxyer forbinder fra. `10.244.0.0/16` er flannels pod-netværk; brug dit clusters pod-CIDR.                                  |
| `SANDBOXED_COMPILES_HOST_DIR_*`         | Nodestierne til kompileringsvolumes. De skal svare til `hostPath`-volumes i [trin 5](/da/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro).   |

Bag HTTPS skal du også sætte `OVERLEAF_SECURE_COOKIE: "true"`, se [TLS-proxy](/da/on-premises/configuration/overleaf-toolkit/tls-proxy).

<Info>

Et ændret ConfigMap når først kørende pods efter en genstart: `kubectl -n overleaf rollout restart deployment/overleaf`.

</Info>
