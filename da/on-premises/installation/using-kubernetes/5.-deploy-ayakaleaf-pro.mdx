```yaml title="40-overleaf.yaml" wrap
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: overleaf-data
  namespace: overleaf
spec:
  accessModes: [ReadWriteOnce]
  resources:
    requests:
      storage: 20Gi
---
apiVersion: apps/v1
kind: Deployment
metadata:
  name: overleaf
  namespace: overleaf
spec:
  replicas: 1
  strategy:
    type: Recreate          # one pod owns the data volume; never run two at once
  selector:
    matchLabels:
      app: overleaf
  template:
    metadata:
      labels:
        app: overleaf
    spec:
      terminationGracePeriodSeconds: 60   # time to flush pending edits, like the Toolkit
      # Keep the environment to what the ConfigMap and Secret set: no REDIS_PORT=tcp://... and the like
      enableServiceLinks: false
      containers:
        - name: sharelatex
          image: ghcr.io/ayaka-notes/overleaf-pro:6.3.2
          envFrom:
            - configMapRef:
                name: overleaf-env
            - secretRef:
                name: overleaf-secrets
          ports:
            - containerPort: 80
          readinessProbe:
            httpGet:
              path: /status
              port: 80
            periodSeconds: 10
          resources:
            requests:
              cpu: 500m
              memory: 1536Mi
            limits:
              memory: 3Gi
          volumeMounts:
            - name: data
              mountPath: /var/lib/overleaf
            - name: compiles
              mountPath: /var/lib/overleaf/data/compiles
            - name: output
              mountPath: /var/lib/overleaf/data/output
            - name: cache
              mountPath: /var/lib/overleaf/data/cache
            - name: docker-sock
              mountPath: /var/run/docker.sock
      volumes:
        - name: data
          persistentVolumeClaim:
            claimName: overleaf-data
        # Compile scratch space on the node; same paths as SANDBOXED_COMPILES_HOST_DIR_*
        - name: compiles
          hostPath:
            path: /srv/overleaf/compiles
            type: DirectoryOrCreate
        - name: output
          hostPath:
            path: /srv/overleaf/output
            type: DirectoryOrCreate
        - name: cache
          hostPath:
            path: /srv/overleaf/cache
            type: DirectoryOrCreate
        - name: docker-sock
          hostPath:
            path: /var/run/docker.sock
            type: Socket
---
apiVersion: v1
kind: Service
metadata:
  name: overleaf
  namespace: overleaf
spec:
  type: NodePort
  selector:
    app: overleaf
  ports:
    - name: http
      port: 80
      targetPort: 80
      nodePort: 30080
```

```bash
kubectl apply -f 40-overleaf.yaml
kubectl -n overleaf rollout status deployment/overleaf --timeout=10m
kubectl -n overleaf logs deployment/overleaf | grep -E 'Finished migrations|Missing required'
```

Den første start kører databasemigreringerne og tager et minut eller to. Poden er klar, når `/status` svarer; åbn derefter `OVERLEAF_SITE_URL`.

### Hvorfor manifestet ser sådan ud

* <strong>Datavolume.</strong> Alt under `/var/lib/overleaf` (projektfiler, historik, uploads) ligger på PVC'en. Dataene bliver på én node med nodelokal lagring såsom local-path; med netværksbaseret bloklagring kan poden flytte mellem noder.
* <strong>Kompileringsvolumes og Docker-socketen.</strong> Ayakaleaf Pro beder nodens Docker om at starte en TeX Live-container og giver den projektets kompileringsmappe **via dens sti på noden**. Disse mapper er derfor `hostPath`-volumes, og deres stier gentages i `SANDBOXED_COMPILES_HOST_DIR_*`. Deres indhold er midlertidige data og kræver ingen sikkerhedskopi.
* <strong>`enableServiceLinks: false`.</strong> Kubernetes tilføjer variabler i Docker-stil for hver Service i namespacet til hver pod: Service'en `redis` bliver til `REDIS_PORT=tcp://10.x.x.x:6379`, Service'en `git-bridge` til `GIT_BRIDGE_PORT=tcp://...`. Nogle Overleaf-tjenester læser variabler med disse navne. I denne pod vinder indstillingerne fra `OVERLEAF_REDIS_*` og ConfigMap'et, men git-bridge tager `GIT_BRIDGE_PORT` som sin port og stopper (se [Git-integration](/da/on-premises/configuration/kubernetes/integrations/git-integration)). Når linkene slås fra, begrænses miljøet til det, du selv sætter.
* <strong>`Recreate`.</strong> To pods må aldrig bruge det samme datavolume eller køre migreringer på samme tid.
* <strong>Eksponering.</strong> NodePort-Service'en svarer på port `30080` på hver node. I produktion skal du placere din ingress controller eller load balancer foran og terminere TLS der; den skal tillade WebSockets, request-timeouts på 10 minutter (lange kompileringer) og uploads på 50 MB og videregive `X-Forwarded-For` og `X-Forwarded-Proto`.
