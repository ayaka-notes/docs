---
title: 2. Opret namespacet og secrets
description: Opret namespacet og de secrets, som Ayakaleaf Pro har brug for.
icon: key
---

Alt lægges i namespacet `overleaf`:

```bash
kubectl create namespace overleaf
```

Ayakaleaf Pro læser sine secrets fra miljøvariabler. Generér dem én gang, og gem dem i et Secret:

```bash wrap
HISTORY=$(openssl rand -hex 32)
kubectl -n overleaf create secret generic overleaf-secrets \
  --from-literal=OVERLEAF_INVITE_TOKEN_SECRET="$(openssl rand -base64 32)" \
  --from-literal=OVERLEAF_SESSION_SECRET="$(openssl rand -hex 32)" \
  --from-literal=WEB_API_PASSWORD="$(openssl rand -hex 32)" \
  --from-literal=STAGING_PASSWORD="$HISTORY" \
  --from-literal=V1_HISTORY_PASSWORD="$HISTORY" \
  --from-literal=CRYPTO_RANDOM="$(openssl rand -hex 32)" \
  --from-literal=OT_JWT_AUTH_KEY="$(openssl rand -hex 32)"
```

| Secret                                         | Hvorfor                                                                                                                                              |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_INVITE_TOKEN_SECRET`                 | Påkrævet. Uden den stopper poden med »Missing required secrets«. Hvis den ændres, bliver ventende projektinvitationer ugyldige.                      |
| `OVERLEAF_SESSION_SECRET`                      | Signerer sessionscookies. Uden den logges alle ud ved hver genstart af poden.                                                                        |
| `WEB_API_PASSWORD`, `CRYPTO_RANDOM`, `OT_JWT_AUTH_KEY` | Interne secrets. Containeren genererer dem ved hver start, når de mangler; med mere end én replika skal alle replikaer dele dem.               |
| `STAGING_PASSWORD` og `V1_HISTORY_PASSWORD`    | Internt historik-secret; begge skal have den **samme** værdi.                                                                                        |

<Warning>

Sikkerhedskopiér Secret'et (`kubectl -n overleaf get secret overleaf-secrets -o yaml`) sammen med dine data. Funktioner, der krypterer tokens i MongoDB, kræver også deres egne cipher-adgangskoder i dette Secret, for eksempel `GITHUB_TOKEN_CIPHER_PASSWORD` til [GitHub-synkronisering](/da/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation).

</Warning>
