Overleaf kører på Docker. Du skal installere:

* Docker Engine (Docker CE)
* Docker Compose-pluginet (`docker compose`, v2)

Disse trin er rettet mod en nyere Ubuntu LTS (20.04/22.04/24.04).

<Warning>

Undgå at installere `docker.io` fra Ubuntus standard-apt-repository.\
Brug Dockers officielle repository, så du får en nyere Docker-version og `docker compose`-pluginet.

</Warning>

Den officielle dokumentation findes her: [https://docs.docker.com/engine/install/ubuntu/](https://docs.docker.com/engine/install/ubuntu/).

<Steps>
<Step title="1) Fjern gamle/modstridende pakker (hvis de findes)">
Hvis Docker tidligere er blevet installeret fra en anden kilde, skal du fjerne det først:

```bash wrap
sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-compose-v2 docker-doc podman-docker containerd runc | cut -f1)
```

Denne kommando er sikker at køre, selvom nogle af pakkerne ikke er installeret.
</Step>

<Step title="2) Tilføj Dockers officielle apt-repository">
Installer forudsætningerne:

```bash
sudo apt update
sudo apt install -y ca-certificates curl
```

Tilføj Dockers GPG-nøgle:

```bash wrap
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```

Tilføj repositoriet:

```bash wrap
# Add the repository to Apt sources:
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Signed-By: /etc/apt/keyrings/docker.asc
EOF

sudo apt update
```
</Step>

<Step title="3) Installer Docker Engine + Compose-pluginet">
Installer Docker og Compose-pluginet:

```bash wrap
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

Start Docker ved opstart:

```bash
sudo systemctl enable --now docker
```
</Step>

<Step title="4) Kontrollér installationen">
Disse kommandoer bør køre uden fejl:

```bash
docker --version
docker compose version
sudo docker run --rm hello-world
docker ps
```
</Step>

<Step title="5) (Valgfrit) Kør Docker uden sudo">
Tilføj din bruger til gruppen `docker`:

```bash
sudo usermod -aG docker $USER
```

**Log derefter ud og ind igen**, eller kør:

```bash
newgrp docker
```

Nu burde dette virke uden `sudo`:

```bash
docker ps
```

<Danger>

Gruppen `docker` har adgang svarende til root på værten.\
Dette er forventet for typiske Overleaf-installationer og er særligt relevant, hvis du aktiverer Sandboxed Compiles.

</Danger>
</Step>
</Steps>

### Næste trin

Når Docker fungerer, kan du fortsætte med installationstrinnene for Toolkit under [Brug af Toolkit](/da/on-premises/installation/using-the-toolkit).
