### Initialisering af konfigurationen

Lad os initialisere vores nye servers konfigurationsfiler med nogle fornuftige standardværdier ved at køre det medfølgende script `bin/init`.

```text title="Run initialization"
bin/init
```

Dette script overskriver **ikke** eksisterende konfigurationsfiler.

Lad os nu se på indholdet af mappen `config/` med kommandoen `ls`:

```text title="List the config directory"
ls config
```

Hvis alt blev initialiseret korrekt, bør du se tre konfigurationsfiler: `overleaf.rc`, `variables.env` og `version`. Disse er serverens primære konfigurationsfiler og giver dig mulighed for at tilpasse, hvordan din server fungerer, og hvordan dine brugere interagerer med din instans.

| Navn            | Beskrivelse                                             |
| --------------- | ------------------------------------------------------- |
| `overleaf.rc`   | Den primære konfigurationsfil på øverste niveau.        |
| `variables.env` | Miljøvariabler, der indlæses i Docker-containeren.      |
| `version`       | Versionen af det Docker-image, der skal bruges.         |

<Info>

Indtil videre er det nok at vide, at disse filer findes, og hvor du kan finde dem. Senere i dokumentationen gennemgår vi hver fil mere detaljeret og forklarer, hvordan du kan tilpasse din instans med dem. Hvis du vil springe frem, kan du se en komplet gennemgang af disse konfigurationsfiler på siden [Filer og placeringer](/da/on-premises/configuration/overleaf-toolkit/files-and-locations).

</Info>
