### Download af Toolkit

Toolkit er kompatibel med både Server CE og Ayakaleaf Pro og er den anbefalede installationsmetode. Med Toolkit kan du nemt komme i gang med Server CE og problemfrit opgradere til Ayakaleaf Pro, hvis det bliver nødvendigt.

<Info>

[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) er tilpasset til at bruge overleaf-pro-imaget direkte fra ghcr, med TeX Live leveret af ayaka-notes. Alternativt kan du downloade det officielle overleaf-toolkit.

</Info>

<Steps>
<Step title="Klon Overleaf Toolkit-repositoriet">
For at installere Toolkit skal du navigere til den ønskede installationssti og derefter klone GitHub-repositoriet Overleaf Toolkit (@Ayaka-notes) med denne kommando:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
# official toolkit (Not Recommended)
# git clone https://github.com/overleaf/toolkit.git ./overleaf-toolkit
```

<Info>

For at undgå potentielle problemer med rettigheder anbefaler vi, at Toolkit installeres i din brugers `$HOME`-mappe.

</Info>
</Step>

<Step title="Skift til toolkit-mappen">
Vent på, at kloningen er færdig, og skift derefter til den nyoprettede `overleaf-toolkit`-mappe:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
