### Download af Toolkit

Du installerer Ayakaleaf Pro med **Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)), en samling scripts, der kører Overleaf i Docker for dig.

Som standard starter Toolkit den gratis officielle Overleaf Community Edition (CE). [4. Hent Ayakaleaf Pro-images](/da/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images) skifter den til Ayakaleaf Pro med én indstilling.

<Accordion title="Kører du allerede det officielle Overleaf Toolkit (overleaf/toolkit)?">

Du behøver ikke at geninstallere. Behold din installation, og følg den sidste del af [4. Hent Ayakaleaf Pro-images](/da/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images).

</Accordion>

<Steps>
<Step title="Klon Ayakaleaf Toolkit-repositoriet">
For at installere Toolkit skal du navigere til den ønskede installationssti og derefter klone Ayakaleaf Toolkit-repositoriet med denne kommando:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
```

<Info>

For at undgå potentielle problemer med rettigheder anbefaler vi, at Toolkit installeres i din brugers `$HOME`-mappe.

</Info>
</Step>

<Step title="Skift til toolkit-mappen">
Vent på, at kloningen er færdig, og skift derefter til den nyoprettede `overleaf-toolkit`-mappe:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
