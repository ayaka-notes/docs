<Danger>

Følgende vejledning gælder **kun** for installationer af **Community Edition**. Vi anbefaler kraftigt, at vores Ayakaleaf Pro-brugere aktiverer [Sandboxed Compiles](/da/on-premises/configuration/overleaf-toolkit/sandboxed-compiles), da det giver brugerne adgang til næsten de samme TeX Live-images, som bruges på [overleaf.com](https://www.overleaf.com), og samtidig isolerer projektkompileringer fra hinanden for øget sikkerhed.

</Danger>

For at spare båndbredde leveres både Overleaf Community Edition- og Ayakaleaf Pro-imagesene kun med en minimal installation af [TeX Live](https://www.tug.org/texlive/). Du kan installere flere pakker eller opgradere til en komplet TeX Live-installation ved hjælp af kommandoen [tlmgr](https://www.tug.org/texlive/tlmgr.html) i `sharelatex`-containeren.

#### Adgang til sharelatex-containeren

For at starte en shell i `sharelatex`-containeren skal du køre

```bash
bin/shell
```

Du får en prompt, der ser sådan ud:

```bash
root@309b192d4030:/#
```

I den følgende vejledning antager vi, at du befinder dig i containeren.

#### Bestemmelse af din nuværende TeX Live-version

TeX Live udgives hvert år omkring april. Fremgangsmåden for at bruge `tlmgr` er forskellig, afhængigt af om du bruger den aktuelle udgave eller en ældre. Du kan se, hvilken version af TeX Live du kører, med `tlmgr --version`. For eksempel kører denne installation TeX Live 2021:

```bash
# tlmgr --version
tlmgr revision 59291 (2021-05-21 05:14:40 +0200)
tlmgr using installation: /usr/local/texlive/2021
TeX Live (https://tug.org/texlive) version 2021
```

<Info>

Den aktuelle udgave af TeX Live kan findes på [TeX Lives hjemmeside](https://www.tug.org/texlive/).

</Info>

Hvis du kører en ældre version af TeX Live, har du to muligheder. En ny version af Overleaf Docker-imaget udgives normalt kort efter en TeX Live-udgivelse. Du kan enten vente på den og opgradere din installation med scriptet `bin/upgrade`, eller, hvis du foretrækker at beholde den ældre TeX Live-udgave, skal du først fortælle `tlmgr`, at den skal bruge et historisk repository. Du finder vejledning til dette [her](https://www.tug.org/texlive/acquire.html#past).

#### Installation af pakker

For at installere en komplet TeX Live-installation skal du køre denne kommando i `sharelatex`-containeren:

```text
tlmgr install scheme-full
```

Du kan også installere enkelte pakker manuelt:

```bash
tlmgr install tikzlings tikzmarmots tikzducks
```

<Warning>

Fra udgave `3.3.0` og frem er det igen **påkrævet** at køre `tlmgr path add` efter hver brug af `tlmgr install` for at oprette korrekte symlinks for alle binære filer i systemstien.

</Warning>

Der findes mange flere kommandoer. Få mere at vide med:

```text
tlmgr help
```

Når du er færdig, skal du skrive `exit` eller trykke på Control-D for at forlade shellen.

#### Gemning af dine ændringer

De ændringer, du lige har foretaget, har ændret `sharelatex`-containeren, men de er midlertidige -- de går tabt, hvis Docker Compose genopretter containeren, f.eks. i forbindelse med en opdatering af konfigurationen.

For at gøre dem permanente skal du bruge `docker commit` til at gemme ændringerne i et nyt Docker-image:

```bash
cat config/version #5.2.1
docker commit sharelatex sharelatex/sharelatex:5.2.1-with-texlive-full
echo 5.2.1-with-texlive-full > config/version
```

Efter at have committet ændringerne skal du opdatere `config/version` tilsvarende. Kør derefter `bin/up` for at genoprette `sharelatex`-containeren.

<Danger>

Du skal gentage disse trin, hver gang du [opgraderer](https://github.com/overleaf/toolkit/blob/master/doc/upgrading.md) til en ny version af Overleaf.

</Danger>
