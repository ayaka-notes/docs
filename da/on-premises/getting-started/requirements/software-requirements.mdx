### Operativsystemer

For den bedste oplevelse med Overleaf anbefaler vi kraftigt et **Debian-baseret** operativsystem, såsom **Ubuntu**. Dette valg stemmer overens med softwarens udviklingsmiljø og er den foretrukne løsning blandt størstedelen af Overleaf-brugerne.

<Danger>

Når du bruger Server Pro med Sandboxed Compiles, er det **vigtigt** at være opmærksom på, at applikationen kræver root-adgang til Docker-socket'en.

</Danger>

### Afhængigheder

* Docker 25.0 og 29
* MongoDB 7.0 og 8.0
* Redis 6.2 og 7.5

<Info>

Du kan følge End-of-Life-datoer (EOL) for ovenstående afhængigheder og andre populære produkter via tjenesten endoflife.date her: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

MongoDB og Redis hentes automatisk af `docker compose`, når du kører Server CE eller Server Pro, medmindre de er konfigureret til at bruge en anden installation.

</Info>

Toolkit afhænger af følgende programmer:

* bash
* Docker

`docker compose` er påkrævet og installeres normalt sammen med Docker.

Vi anbefaler, at du installerer den nyeste version af Docker, der er tilgængelig til dit operativsystem.

Når Docker er korrekt installeret, bør du kunne køre disse kommandoer uden fejl:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2)
docker compose version

# List the running Docker containers on your system
docker ps
```
