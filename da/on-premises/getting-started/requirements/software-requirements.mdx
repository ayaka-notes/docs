### Operativsystemer {#operating-systems}

Vi anbefaler et **Debian-baseret Linux**-system, såsom **Ubuntu**, til delte servere og produktionsservere. Ayakaleaf Pro kan også køre på [macOS med Docker Desktop](/da/on-premises/installation/using-docker-compose/macos) og [Windows med WSL 2 og Docker Desktop](/da/on-premises/installation/using-docker-compose/windows). Alle tre platforme bruger Linux-containere og det samme Toolkit; følg vejledningen for værtens operativsystem.

<Danger>

Når du bruger Sandboxed Compiles, er det **vigtigt** at være opmærksom på, at applikationen kræver root-adgang til Docker-socket'en.

</Danger>

### Afhængigheder {#dependencies}

* Docker 25.0 og 29
* MongoDB 7.0 og 8.0
* Redis 6.2 og 7.5

<Info>

Du kan følge End-of-Life-datoer (EOL) for ovenstående afhængigheder og andre populære produkter via tjenesten endoflife.date her: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

MongoDB og Redis hentes automatisk af `docker compose`, når du kører Ayakaleaf Pro, medmindre de er konfigureret til at bruge en anden installation.

</Info>

Toolkit afhænger af følgende programmer:

* bash
* Docker

`docker compose` er påkrævet og installeres normalt sammen med Docker.

Vi anbefaler, at du installerer den nyeste version af Docker, der er tilgængelig til dit operativsystem.

Når Docker er korrekt installeret, bør du kunne køre disse kommandoer uden fejl:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2 or later, such as v5)
docker compose version

# List the running Docker containers on your system
docker ps
```
