### Krav til installation af Server Pro og Community Edition

<Warning>

Vi anbefaler kraftigt, at du kører Server Pro på en nyere og stabil version af Ubuntu (f.eks. Ubuntu 24.04 i 2025–2026) med en nyere version af Docker. Det er muligt at køre Server Pro på andre systemer, men det gør det meget sværere for os at tilbyde support til Ubuntu/Docker-opsætninger, der afviger fra standarden. Vi kan heller ikke tilbyde support til problemer med selve Docker.

</Warning>
