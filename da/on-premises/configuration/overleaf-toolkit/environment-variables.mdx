Denne side beskriver de miljøvariabler, der understøttes i filen `config/variables.env` ved Toolkit-udrulninger.

Filen `config/variables.env` består af variabeldefinitioner på formen `NAME=value`; linjer, der begynder med `#`, behandles som kommentarer.

<Info>

Det er nødvendigt at genskabe Docker-containerne ved at køre `bin/up`, når du har ændret noget i `overleaf.rc` eller `variables.env`.

</Info>

### Alle versioner

Disse miljøvariabler er kompatible med Server CE og Server Pro og giver en nem migreringsvej mellem disse to on-premises-versioner. De kan også bruges med både Toolkit- og Docker Compose-udrulninger.

<Info>

Tidligere havde disse miljøvariabler præfikset `SHARELATEX_` i stedet for `OVERLEAF_`.

</Info>

<Info>

Det er muligt at håndhæve adgangskodekrav for brugere, når der bruges Overleafs loginsystem (lokale konti) og ikke en SSO-løsning som LDAP. For SSO-konti håndhæves adgangskodepolitikker af din identitetsudbyder eller katalogtjeneste, som desuden kan understøtte multifaktorgodkendelse.

</Info>
