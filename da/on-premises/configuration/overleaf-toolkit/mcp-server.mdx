Hvert projekt har en MCP-server, så AI-klienter som Claude Code, Codex, Cursor, VS Code eller Gemini CLI kan arbejde på det: læse og redigere dets filer, kompilere det, læse LaTeX-loggen, downloade PDF'en og besvare kommentarer.

<Info>

Denne funktion er udviklet af [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro). Den er introduceret i v6.3.1 og senere.

</Info>

### Opsætning

MCP-serveren følger med Git-integrationen: aktivér [git-bridge](/da/on-premises/configuration/overleaf-toolkit/git-integration), så er MCP-serveren også tilgængelig. Der er intet andet at konfigurere.

### Forbind en AI-klient

1. Generér et Git-godkendelsestoken under **Account Settings**. Det samme token bruges til MCP-serveren og til Git.
2. Åbn **Integrations** i editoren, og klik på **MCP server**. Her vises adressen på projektets MCP-server, `https://<your-overleaf>/project/<project_id>/mcp`, og hvordan du tilføjer den til hver AI-klient: kopiér kommandoen, og erstat `<token>` med dit token.

### Brug

Når forbindelsen er oprettet, kan du bede AI-klienten om ting med almindelige ord. For eksempel:

| Du beder om | AI-klienten bruger |
| --- | --- |
| _Ret stavefejlene i indledningen._ | `read_file`, `edit_file`: redigeringerne vises live i editoren |
| _Kompilér projektet, og ret LaTeX-fejlene._ | `compile`, `get_compile_log`, `edit_file` |
| _Besvar de åbne kommentarer, og markér dem derefter som løst._ | `list_comments`, `reply_to_comment`, `resolve_comment` |
| _Skift til XeLaTeX, og download PDF'en._ | `update_settings`, `compile`, `get_output_file_link` |

### Værktøjer

| Gruppe | Værktøjer |
| --- | --- |
| Projekt | `get_clone_info`, `get_settings`, `update_settings`, `list_versions` |
| Filer | `list_files`, `read_file`, `edit_file`, `write_file`, `delete_file` |
| Kompilering | `compile`, `get_compile_log`, `get_output_file_link`, `word_count` |
| Kommentarer | `list_comments`, `reply_to_comment`, `resolve_comment`, `reopen_comment` |

Redigeringer foretaget med `edit_file` og `write_file` vises live i editoren og flettes sammen med samarbejdspartnernes redigeringer. Til mange filer på én gang, binære filer eller omdøbninger kan AI-klienten også klone projektet med Git og pushe.

### Tilladelser

MCP-serveren følger projektets delingsindstillinger, ligesom Git:

* Alle, der kan se projektet, kan læse det, kompilere det og downloade dets output.
* Kun ejeren og redaktører kan ændre dets filer og indstillinger.
* Korrekturlæsere kan også svare på kommentarer samt markere de kommentarer, de selv har startet, som løst eller genåbne dem.
* Seere, der har fået adgang via et link, kan ikke se kommentarerne, ligesom i editoren.

### Spørgsmål og svar

<Accordion title="Jeg kan ikke se Integrations eller MCP server i editoren">

<strong>Svar:</strong> MCP-serveren har ingen egen miljøvariabel. Den aktiveres med `GIT_BRIDGE_ENABLED=true` i `config/overleaf.rc`, se [Git-integration](/da/on-premises/configuration/overleaf-toolkit/git-integration). Kør `bin/up -d`, når du har ændret den. Uden git-bridge viser editoren ikke fanen **Integrations** i sit venstre panel.

</Accordion>
