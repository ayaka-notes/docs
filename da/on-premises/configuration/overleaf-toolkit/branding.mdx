### Header

I dette afsnit gennemgår vi, hvordan du tilpasser centrale elementer i din lokale instans. Du kan tilpasse sidens titel, navigationslinks, header, footer og logo efter dine præferencer.

### Sidens titel

Titlen i navigationslinjen kan tilpasses med miljøvariablen `OVERLEAF_NAV_TITLE`. Denne tekst bruges i navigationens øverste venstre hjørne, hvis der ikke er angivet et logo.

```bash
# add to config/variables.env
OVERLEAF_NAV_TITLE=Our Overleaf Instance
```

## Logo

Du kan tilføje et brugerdefineret logo i stedet for tekst ved at angive miljøvariablen `OVERLEAF_HEADER_IMAGE_URL`. Værdien skal pege på en eksternt hostet billedfil.

```bash title="config/variables.env"
# add to config/variables.env
OVERLEAF_HEADER_IMAGE_URL=https://mysite.somewhere.com/img/logo.png
```

#### Logoer til lyst og mørkt tema

Fra version 6.3.0 kan du angive separate logoer til det lyse og det mørke tema med miljøvariablerne `OVERLEAF_HEADER_IMAGE_URL_LIGHT` og `OVERLEAF_HEADER_IMAGE_URL_DARK`. Begge værdier skal pege på en eksternt hostet billedfil.

```text
# add to config/variables.env
OVERLEAF_HEADER_IMAGE_URL_LIGHT=https://mysite.somewhere.com/img/logo-light.png
OVERLEAF_HEADER_IMAGE_URL_DARK=https://mysite.somewhere.com/img/logo-dark.png
```

<Info>

Hvis en af variablerne ikke er angivet, falder det pågældende tema tilbage til logoet angivet i `OVERLEAF_HEADER_IMAGE_URL`.

</Info>

## Navigationslinks i headeren

Ekstra navigationspunkter kan tilføjes til navigationsheaderen ved at sætte miljøvariablen `OVERLEAF_HEADER_EXTRAS` til et JSON-array af objekter. For eksempel:

```json wrap
[\
  {\
    "text": "Some link",\
    "url": "http://example.com/somelink",\
    "class": "subdued",\
    "only_when_logged_out": true\
  },\
  {\
    "text": "Help",\
    "class": "subdued",\
    "dropdown": [\
      {\
        "text": "Documentation",\
        "url": "/learn"\
      },\
      {\
        "text": "Contact Admin",\
        "url": "http://example.com/contact"\
      }\
    ]\
  }\
]
```

Tilføj den escapede JSON-form til toolkit/variables.env:

```bash title="toolkit/variables.env" wrap
# add to toolkit/variables.env
OVERLEAF_HEADER_EXTRAS=[{"text":"Some link","url":"http://example.com/somelink","class":"subdued","only_when_logged_out":true},{"text":"Help","class":"subdued","dropdown":[{"text":"Documentation","url":"/learn"},{"text":"Contact Admin","url":"http://example.com/contact"}]}]
```

## Footers

Det er muligt at tilpasse både den venstre og den mindre højre footer (som findes på sider som `/project`) ved hjælp af miljøvariablerne `OVERLEAF_LEFT_FOOTER` og `OVERLEAF_RIGHT_FOOTER`. Begge forventer et array af JSON-objekter, som bliver indsat.

Begge forventer et JSON-array, som bliver indsat.

```json
[\
  {\
    "text": "This is an example text footer entry!"\
  },\
  {\
    "text": "This is an example URL footer link!", "url" : "/my-first-link.htm"\
  }\
]
```

<Info>

Når kun `text` bruges, må værdien ikke indeholde HTML, da den bliver vist som rå tekst.

</Info>

Disse data skal være gyldig JSON for at virke, med escapede anførselstegn, når de videregives som en miljøvariabel.

```bash title="config/variables.env" wrap
# add to config/variables.env
OVERLEAF_LEFT_FOOTER=[{"text": "This is an example text footer entry!"}]
OVERLEAF_RIGHT_FOOTER=["text": "This is an example URL footer link!", "url" : "/my-first-link.htm"]
```

<Info>

Ud over `text` og `url` accepterer JSON-objektet også egenskaberne `class` og `label` til yderligere tilpasning.

</Info>

### Vedligeholdelsesside

Du kan tilpasse beskeden, der vises på vedligeholdelsessiden, med miljøvariablen `OVERLEAF_MAINTENANCE_MESSAGE`. Denne tekst erstatter standardbeskeden under sidens titel.

```text wrap
# add to config/variables.env
OVERLEAF_MAINTENANCE_MESSAGE=Our Overleaf Instance is down for maintenance and will be back shortly.
```

Hvis du vil inkludere links eller anden formatering, skal du i stedet bruge `OVERLEAF_MAINTENANCE_MESSAGE_HTML`. Hvis begge er angivet, har `OVERLEAF_MAINTENANCE_MESSAGE_HTML` forrang.

```text wrap
# add to config/variables.env
OVERLEAF_MAINTENANCE_MESSAGE_HTML=Our Overleaf Instance is down for maintenance. For urgent requests, contact <a href="mailto:admin@example.com">admin@example.com</a>.
```

<Info>

`OVERLEAF_MAINTENANCE_MESSAGE` vises som almindelig tekst, så den må **ikke** indeholde HTML. `OVERLEAF_MAINTENANCE_MESSAGE_HTML` vises som HTML uden escaping.

</Info>

Hvis ingen af dem er angivet, linker standardbeskeden til din statusside, når `OVERLEAF_STATUS_PAGE_URL` er angivet, og viser administratorens e-mailadresse, når den ikke er.
