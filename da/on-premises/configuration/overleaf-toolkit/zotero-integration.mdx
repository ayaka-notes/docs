### Opsætning af Zotero-integration

1. Åbn [dette link](https://www.zotero.org/oauth/apps) for at oprette en Zotero OAuth-klient (som vist på billedet)
2. Vælg **Application Type**: **Browser**
3. Angiv Callback URL til din `${OVERLEAF_SITE_URL}/user/zotero/oauth/callback`
4. Konfigurer din `config/variables.env`

<Frame>
  <img src="/images/on-premises/image-41.png" alt="" width="375" />
</Frame>

```dotenv title="config/variables.env"
#################
#    Zotero     #
#################
# 'zotero' must be in ENABLED_LINKED_FILE_TYPES (set in develop/docker-compose.yml)
ENABLED_LINKED_FILE_TYPES=project_file,project_output_file,url,zotero

# From a Zotero OAuth client (register at https://www.zotero.org/oauth/apps)
# Application Type: Browser 
# Callback URL -> ${OVERLEAF_SITE_URL}/user/zotero/oauth/callback
ZOTERO_CLIENT_ID=
ZOTERO_CLIENT_SECRET=
# Encrypts the Zotero API key in mongo (set in dev to avoid writing a key file
# to /var/lib/overleaf/data, which the dev web container can't create)
# How to generate: `openssl rand -hex 32`
ZOTERO_CIPHER_PASSWORD=dev-zotero-cipher-password
# Optional: route the module's server-side Zotero requests (OAuth + API) through
# an HTTP proxy (must be reachable from the web container; same as github-sync)
# http://10.0.0.1:10808
# (Optional) ZOTERO_PROXY_URL=
```

### Bemærkninger

<Warning>

Når du opgraderer en eksisterende installation med Zotero-linkede bibliografifiler til den genudgivne 6.3.0, skal du følge [migreringsvejledningen for Zotero / Mendeley](/da/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention"). Nye installationer har ikke brug for denne migrering.

</Warning>

<Danger>

Da Ayakaleaf er en samarbejdsplatform, vil det af sikkerhedshensyn fra version 6.3.0 kun være den oprindelige opretter af en reference-`bib`-fil, der har lov til at opdatere den importerede fil.

</Danger>

Antag for eksempel, at projektejeren, bruger A, aktiverer linkdeling og opretter en `test.bib`-fil i projektet, som er linket til vedkommendes egen Zotero-konto. Hvis en anden bruger, bruger B, får adgang til projektet via det delte link, vil bruger B stadig kunne læse og downloade `test.bib`, men vil ikke have lov til at opdatere eller genimportere filen fra Zotero. Kun bruger A, som den oprindelige opretter af referencefilen, kan foretage opdateringer. Med andre ord er det kun den oprindelige opretter af `.bib`-filen, der har tilladelse til at opdatere den.
