Import API'et (`/docs` og knapperne »Open in Ayakaleaf«, modulet `open-in-overleaf`) kører i **web**-tjenesten i hver Ayakaleaf Pro-pod og er slået til som standard. Filer, der angives via URL, downloades gennem linked-url-proxy i den samme pod. Hvordan det kaldes, er beskrevet under [Overleaf Import API](/da/on-premises/configuration/overleaf-toolkit/integrations/overleaf-import-api).

| | |
| --- | --- |
| Tjeneste | web (modulet `open-in-overleaf`); downloader gennem linked-url-proxy |
| Udefra → Overleaf | browsere sender `GET` eller `POST ${OVERLEAF_SITE_URL}/docs` fra et hvilket som helst websted |
| Pod → udefra | downloads fra `snip_uri` og `zip_uri`, begrænset som beskrevet under [Ekstern URL](/da/on-premises/configuration/kubernetes/external-url) |
| Tilstand | en udlogget besøgendes forespørgsel, gemt i Redis i 10 minutter, indtil vedkommende logger ind |
| Periodiske job | ingen |

### Konfiguration

Der kræves intet for at slå det til. Relaterede indstillinger i ConfigMap'et:

| Indstilling | |
| --- | --- |
| `OVERLEAF_ALLOW_PUBLIC_ACCESS: "true"` | Udloggede besøgende kan åbne `/devs`, og en forespørgsel, de sender, gemmes, indtil de logger ind, se [Offentlig adgang](/da/on-premises/configuration/kubernetes/authentication/public-access). |
| `MAX_UPLOAD_SIZE` | Største ZIP-fil, en forespørgsel må indeholde, i MB (standard `50`). Din ingress eller load balancer skal også acceptere request bodies af den størrelse. |
| `OVERLEAF_LINKED_URL_*` | Hvilke adresser `snip_uri` og `zip_uri` må pege på, se [Ekstern URL](/da/on-premises/configuration/kubernetes/external-url). |

### Flere replikaer

Intet ekstra. En udlogget besøgendes forespørgsel gemmes i Redis, så den genoptages på den replika, den besøgende når frem til efter at have logget ind.

### Testet på Kubernetes

På Kubernetes 1.37 med én replika består vores end-to-end-tests for Import API'et (14 tilfælde): siden `/devs` og dens eksempelprojekt, uddrag, komplette dokumenter, URL-kodede links og filer fra data-URL'er, der omdannes til projekter, afvisning af indsendelser, der ikke kan blive til et projekt, afvisning af downloads fra interne adresser, udloggede indsendelser og links, der bevares gennem login, og, med `OVERLEAF_ALLOW_PUBLIC_ACCESS`, `/devs` for udloggede besøgende og et indsendt uddrag, der genoptages én gang efter login; det sidste tilfælde består også på tre replikaer bag HAProxy.
