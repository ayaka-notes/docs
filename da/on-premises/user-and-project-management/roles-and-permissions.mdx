### Konto

Med hensyn til administration af deres egen konto behandles **alle** brugere som almindelige brugere — `Site Admins` og `Template Users` får **ikke** yderligere rettigheder. Der er dog begrænsninger på, hvilke handlinger almindelige brugere kan udføre, afhængigt af hvordan de godkendes.

#### Indstillinger

**Godkendelsestyper: Interne konti | SSO (SAML/LDAP)**

| Handling                                     | Interne konti | SSO (SAML/LDAP) |
| -------------------------------------------- | ------------: | --------------: |
| Opdater kontooplysninger                     |            Ja |             Nej |
| Skift adgangskode                            |            Ja |             Nej |
| Generér godkendelsestokens til Git bridge    |            Ja |              Ja |
| Slet godkendelsestokens til Git bridge       |            Ja |              Ja |
| Administrer sessioner                        |            Ja |              Ja |

<Info>

Git Bridge-integrationen er **kun** tilgængelig i Server Pro. Se [Server Pro vs. Community Edition](/da/on-premises/readme/ayakaleaf-pro-vs-server-pro) for flere oplysninger.

</Info>

#### Dine sessioner

| Handling                   | Bruger |
| -------------------------- | -----: |
| Ryd sessioner              |     Ja |
| Vis aktuel session         |     Ja |
| Vis andre sessioner        |     Ja |

### Editor-IDE

Med hensyn til Overleaf Editor-IDE'en kan du have en af følgende roller: `Project Owner`, `Editor`, `Reviewer`, `Viewer`, `Site Administrator` eller `Template User`.

<Info>

I Server Pro og Community Edition er der understøttelse af anonym **skrivebeskyttet** adgang og **læse- og skriveadgang** til projekter.

Se miljøvariablerne `OVERLEAF_ALLOW_PUBLIC_ACCESS` og `OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` [her](/da/on-premises/configuration/overleaf-toolkit/environment-variables) for flere oplysninger.

</Info>
