---
title: Migrering fra Server Pro til Group Professional
icon: rectangle-pro
noindex: true
---

At skifte fra en selvhostet Server Pro-instans til et nyt cloudbaseret Overleaf Group Professional-abonnement er en stor ændring, så for at gøre processen så gnidningsfri som muligt har vi samlet følgende vejledning.

Generelt foreslår vi en overlapningsperiode på tre måneder, der starter på din fornyelsesdato. Det betyder, at:

* Både din eksisterende Server Pro-instans og dit nye Group Professional-abonnement vil være fuldt aktive.
* Dit tekniske team kan planlægge tid til at sætte Group Professional-abonnementet op og beslutte, hvad der skal ske med jeres on-premises-installation af Server Pro.
* Vigtigst af alt får dine brugere rigelig tid til at kopiere deres projekter over til den nye Overleaf Group Professional-platform.

Denne korte vejledning fører dig gennem de vigtigste trin i migreringen. Lad os komme i gang!

<Steps>
<Step title="Fase 1: Opsætning og konfiguration">
(Link: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-1-setup-and-configuration)

* Overleaf opretter dit Group Professional-abonnement og tilføjer din ledende administrator.
* Din gruppeadministrator kan aktivere [Managed Usersarrow-up-right](https://docs.overleaf.com/groups/user-management/managed-user-accounts), konfigurere [Single Sign-On (SSO)arrow-up-right](https://docs.overleaf.com/groups/overleaf-group-single-sign-on/setting-up-group-sso) og [invitere slutbrugerearrow-up-right](https://docs.overleaf.com/groups/user-management/how-to-add-and-remove-users).

<Warning>

Aktivering af Managed Users og implementering af SSO er et påkrævet trin for overholdelse af FedRAMP® LI-SaaS. Hvis din organisation kræver overholdelse af FedRAMP, skal du opsætte Managed Users og SSO, før du inviterer slutbrugere.

</Warning>
</Step>

<Step title="Fase 2: Brugermigrering og datahåndtering">
(Link: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-2-user-migration-and-data-management)

Dette er det primære migreringsvindue med følgende ansvarsområder:

#### Slutbrugere

* Brugerne bør migrere de projekter, de ønsker at beholde, fra jeres Server Pro-instans til deres nye konti på [overleaf.comarrow-up-right](http://overleaf.com/). Processen består i at [eksportere projekterarrow-up-right](https://www.overleaf.com/learn/how-to/Exporting_your_work_from_Overleaf) fra Server Pro og [uploade demarrow-up-right](https://www.overleaf.com/learn/how-to/Uploading_a_project) til deres konto på [overleaf.comarrow-up-right](http://overleaf.com/). Hvis en bruger ikke allerede har en konto på [overleaf.comarrow-up-right](http://overleaf.com/), kan vedkommende registrere sig på [overleaf.com/registerarrow-up-right](http://overleaf.com/register).

<Warning>

Kun projektets kildekode (LaTeX- og binære filer) overføres via denne eksportprocedure. Eksisterende projektindstillinger, delingsindstillinger, kommentarer, sporede ændringer osv. overføres IKKE. Brugerne skal invitere deres samarbejdspartnere igen efter migreringen.

</Warning>

#### Teknisk personale

* I denne fase bør dit tekniske team planlægge, hvordan jeres on-premises Server Pro-instans og dens data skal håndteres efter migreringen.
* **Sikkerhedskopiering af data:** Du kan eksportere alle projekter før nedlukningen for at oprette et arkiv, så du kan hjælpe brugere, der har glemt at migrere eller downloade deres arbejde. Vejledning: https://docs.overleaf.com/on-premises/maintenance/data-and-backups/exporting-projects
* **Nedlukning af Server Pro:** Når migreringsvinduet er lukket, og din licensnøgle er deaktiveret, har du to hovedmuligheder for selve Server Pro-instansen (se næste trin).
</Step>

<Step title="Muligheder for nedlukning af Server Pro">
<Steps>
<Step title="Afinstaller Server Pro fuldstændigt">
Afinstallation lukker Server Pro ned og fjerner softwaren helt.
</Step>

<Step title="Skift til Community Edition">
Et skift bevarer databasen med brugere og projekter med fuld projekthistorik ved at konvertere instansen fra Server Pro til Community Edition.
</Step>
</Steps>

<Info>

Community Edition indeholder IKKE [Sandboxed Compilesarrow-up-right](https://docs.overleaf.com/on-premises#overview-of-server-pro-and-community-edition) eller [LDAP](/da/on-premises/configuration/overleaf-toolkit/authentication/ldap-authentication)/[SAML](/da/on-premises/configuration/overleaf-toolkit/authentication/saml-authentication). Hvis du har brug for at vende tilbage til indbygget godkendelse (brugernavn/adgangskode), se: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-to-ldap-or-saml#going-the-other-way-switching-from-ldap-saml-back-to-native-authentication

En sammenligning af Server CE og Server Pro findes her: https://docs.overleaf.com/on-premises/welcome/server-pro-vs.-community-edition

</Info>
</Step>

<Step title="Fase 3: Nedlukning af Server Pro">
(Link: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-3-server-pro-decommission)

* Overleaf-teamet deaktiverer formelt din Server Pro-licensnøgle og sender en bekræftelse, når det er sket.
* På det tidspunkt skal du udføre en af de nedlukningshandlinger, der er beskrevet ovenfor: afinstallere Server Pro fuldstændigt eller skifte til Community Edition.
</Step>
</Steps>

Yderligere ressourcer og links, der henvises til ovenfor, er uændrede.
