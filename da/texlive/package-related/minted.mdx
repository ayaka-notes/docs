Denne artikel viser, hvordan du bruger [`minted`-pakken](https://ctan.org/pkg/minted?lang=en) til at formatere og fremhæve kildekode i programmeringssprog i et LaTeX-dokument. Vi starter med et eksempel:

```latex
\documentclass{article}
\usepackage{minted}
\begin{document}
\begin{minted}{python}
import numpy as np
    
def incmatrix(genl1,genl2):
    m = len(genl1)
    n = len(genl2)
    M = None #to become the incidence matrix
    VT = np.zeros((n*m,1), int)  #dummy variable
    
    #compute the bitwise xor matrix
    M1 = bitxormatrix(genl1)
    M2 = np.triu(bitxormatrix(genl2),1) 

    for i in range(m-1):
        for j in range(i+1, m):
            [r,c] = np.where(M2 == M1[i,j])
            for k in range(len(r)):
                VT[(i)*n + r[k]] = 1;
                VT[(i)*n + c[k]] = 1;
                VT[(j)*n + r[k]] = 1;
                VT[(j)*n + c[k]] = 1;
                
                if M is None:
                    M = np.copy(VT)
                else:
                    M = np.concatenate((M, VT), 1)
                
                VT = np.zeros((n*m,1), int)
    
    return M
\end{minted}
\end{document}
```

Dette eksempel giver følgende output:

<p style={{ textAlign: "center" }}><img src="https://sharelatex-wiki-cdn-671420.c.cdn77.org/learn-scripts/images/f/f0/OLV2minted.png" alt="Eksempel, der viser outputtet fra minted-pakken" /></p>

Der er to vigtige kommandoer her. I præamblen importeres pakken ved at skrive

```latex
\usepackage{minted}
```

derefter afgrænser mærkerne `\begin{minted}{python}` og `\end{minted}` et miljø, der udskriver teksten ordret med en skrifttype med fast bredde og samtidig farvelægger kommentarer, nøgleord og funktioner. Parameteren `python` er det programmeringssprog, kildekoden er skrevet i. `minted` understøtter over 150 programmerings- og markupsprog samt konfigurationsfiler; se [referencevejledningen](https://www.overleaf.com/learn/latex/Code_Highlighting_with_minted#Reference_guide) for en liste over understøttede sprog.

**Bemærk**: For at `minted` kan fungere med din _lokale_ LaTeX-distribution, skal et ekstra program kaldet [Pygments](https://pygments.org/) være installeret. [Overleaf](https://www.overleaf.com/) kan spare dig for besværet med at installere det og køre særlige kommandoer for at kompilere dit dokument — på Overleaf fungerer dokumenter, der bruger `minted`, "direkte ud af boksen".

### Grundlæggende brug

Som vist i det følgende eksempel kan `minted`-miljøet konfigureres til at ændre den visuelle præsentation af den typesatte kode. Her bruger `minted`-miljøet flere kommaseparerede parametre på formen `key=value`:

```latex
\documentclass{article}
\usepackage{minted}
\usepackage{xcolor} % to access the named colour LightGray
\definecolor{LightGray}{gray}{0.9}
\begin{document}
\begin{minted}
[
frame=lines,
framesep=2mm,
baselinestretch=1.2,
bgcolor=LightGray,
fontsize=\footnotesize,
linenos
]
{python}
import numpy as np
    
def incmatrix(genl1,genl2):
    m = len(genl1)
    n = len(genl2)
    M = None #to become the incidence matrix
    VT = np.zeros((n*m,1), int)  #dummy variable
    
    #compute the bitwise xor matrix
    M1 = bitxormatrix(genl1)
    M2 = np.triu(bitxormatrix(genl2),1) 

    for i in range(m-1):
        for j in range(i+1, m):
            [r,c] = np.where(M2 == M1[i,j])
            for k in range(len(r)):
                VT[(i)*n + r[k]] = 1;
                VT[(i)*n + c[k]] = 1;
                VT[(j)*n + r[k]] = 1;
                VT[(j)*n + c[k]] = 1;
                
                if M is None:
                    M = np.copy(VT)
                else:
                    M = np.concatenate((M, VT), 1)
                
                VT = np.zeros((n*m,1), int)
    
    return M
\end{minted}
\end{document}
```

Dette eksempel giver følgende output:

<p style={{ textAlign: "center" }}><img src="https://sharelatex-wiki-cdn-671420.c.cdn77.org/learn-scripts/images/f/ff/OLV2minted2.png" alt="Eksempel på formatering af typesat kode fra minted-pakken" /></p>

Parametrene, der bruges i dette eksempel, er:

* `frame=lines`: tegner to linjer, én over og én under koden, som en ramme. Andre mulige værdier er `leftline`, `topline`, `bottomline` og `single`.
* `framesep=2mm`: afstanden til rammen sættes til 2mm. Andre [længdeenheder](https://www.overleaf.com/learn/latex/Lengths_in_LaTeX) kan bruges.
* `baselinestretch=1.2`: kodens linjeafstand sættes til 1.2.
* `bgcolor=LightGray`: baggrundsfarven sættes til `LightGray`. Du skal importere pakken `xcolor`, for at dette virker. Se [Using colours in LaTeX](https://www.overleaf.com/learn/latex/Using_colours_in_LaTeX) for at lære mere om at arbejde med farver.
* `fontsize=\footnotesize`: skriftstørrelsen sættes til `footnotesize`. Enhver anden [skriftstørrelse](https://www.overleaf.com/learn/latex/Font_sizes_and_kinds%23Reference_guide) kan angives.
* `linenos`: aktiverer linjenumre.

Andre indstillinger, der kan være nyttige, er:

* `mathescape`: aktiverer matematiktilstand i kodekommentarer.
* `rulecolor`: ændrer rammens farve.
* `showspaces`: aktiverer et særligt tegn, der gør mellemrum synlige.

### Indsættelse af kode fra en fil

Kode gemmes normalt i en kildefil, så en kommando, der automatisk importerer kode fra en fil, er meget praktisk, som vist i følgende eksempel:

```latex
\documentclass{article}
\usepackage{minted}
\title{Importing files using minted}
\begin{document}
The next code will be directly imported from a file:

\inputminted{octave}{BitXorMatrix.m}
\end{document}
```

Dette eksempel giver følgende output:

<img src="https://sharelatex-wiki-cdn-671420.c.cdn77.org/learn-scripts/images/c/c8/OLV2mintedinput.png" alt="Brug af minted til at importere en kodefil" height="392" width="600" />

Kommandoen `\inputminted{octave}{BitXorMatrix.m}` importerer koden fra filen `BitXorMatrix.m`, og parameteren `octave` fortæller LaTeX, hvilket programmeringssprog koden er skrevet i. Kommandoen kan tage to ekstra parametre, så kun en del af filen importeres; for eksempel bliver kommandoen sådan for at importere kode fra linje 2 til linje 12:

```latex
\inputminted[firstline=2, lastline=12]{octave}{BitXorMatrix.m}
```

### Kode på én linje

Hvis du kun skal indsætte én linje kode, klarer kommandoen `\mint`, hvis syntaks vises i næste eksempel, opgaven.

```latex wrap
One-line code formatting also works with \texttt{minted}. For example, a small fragment of HTML like this:
\mint{html}|<h2>Something <b>here</b></h2>|
\noindent can be formatted correctly.
```

Dette eksempel giver følgende output:

<img src="https://sharelatex-wiki-cdn-671420.c.cdn77.org/learn-scripts/images/d/d9/OLV2mintedHTML.png" alt="Eksempel på kode på én linje med minted" height="112" width="600" />

Parameteren i krøllede parenteser angiver programmeringssproget (i dette tilfælde markupsproget `html`), og den faktiske tekst, der skal formateres, afgrænses af tegnet '|'.

### Problemer med selvhostet Overleaf

Hvis du bruger sandboxet kompilering og samtidig en Overleaf-server til at udrulle Overleaf, fungerer minted muligvis ikke godt. For detaljerede oplysninger, se: [issues/131](https://github.com/yu-i-i/overleaf-cep/issues/131). Du skal aktivere arm-instruktionsprofilen og visse systemkald, for at minted kan fungere.
