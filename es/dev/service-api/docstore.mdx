title: docstore
icon: database
---

Guarda cada documento (líneas, versión, rangos) de cada proyecto en la colección de Mongo `docs` y archiva documentos en almacenamiento de objetos cuando hay un backend configurado. Web lo llama; document-updater accede a él a través de web.

* <strong>Dirección:</strong> `http://docstore:3016`, dentro de la red de Docker
* <strong>Autenticación:</strong> ninguna
* <strong>Archivo OpenAPI:</strong> [`develop/hoppscotch/openapi/docstore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/docstore.yaml)
