Pone en cola en Redis las ediciones de cada proyecto, las convierte en cambios de historial y las envía a history-v1; también guarda en Mongo las etiquetas de historial, el estado de resincronización y los registros de errores. Lo llaman web, document-updater, history-v1 y los scripts cron de server-ce; no tiene autenticación.

* <strong>Dirección:</strong> `http://project-history:3054`, dentro de la red de Docker
* <strong>Autenticación:</strong> ninguna
* <strong>Archivo OpenAPI:</strong> [`develop/hoppscotch/openapi/project-history.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/project-history.yaml)
