Sirve archivos desde el almacenamiento de objetos: archivos de plantillas (zip, pdf y sus imágenes de vista previa) y, en solo lectura, los blobs de proyecto y globales que escribe history-v1. Lo llaman web (módulo template-gallery, URL de archivos de compilación) y clsi, que descarga de él los archivos binarios del proyecto.

* <strong>Dirección:</strong> `http://filestore:3009`, dentro de la red de Docker
* <strong>Autenticación:</strong> ninguna
* <strong>Archivo OpenAPI:</strong> [`develop/hoppscotch/openapi/filestore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/filestore.yaml)
