Guarda el chat del proyecto y los hilos de comentarios (sus mensajes y su estado de resuelto) en las colecciones de Mongo `rooms` y `messages`. Web lo llama mediante `ChatApiHandler`.

* <strong>Dirección:</strong> `http://chat:3010`, dentro de la red de Docker
* <strong>Autenticación:</strong> ninguna
* <strong>Archivo OpenAPI:</strong> [`develop/hoppscotch/openapi/chat.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/chat.yaml)
