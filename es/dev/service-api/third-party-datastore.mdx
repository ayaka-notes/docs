title: third-party-datastore
icon: cloud-arrow-up

Sincroniza proyectos con Dropbox: mantiene una cola de trabajos de Redis por usuario y un worker que envía los cambios de Overleaf a Dropbox y consulta Dropbox en busca de cambios. Solo web lo llama, para encolar trabajos y leer el tamaño de las colas.

* <strong>Dirección:</strong> `http://third-party-datastore:3002`, dentro de la red de Docker
* <strong>Autenticación:</strong> ninguna
* <strong>Archivo OpenAPI:</strong> [`develop/hoppscotch/openapi/third-party-datastore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/third-party-datastore.yaml)
