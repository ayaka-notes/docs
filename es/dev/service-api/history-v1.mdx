Guarda el historial completo de cada proyecto: bloques de cambios en Mongo o Postgres y en almacenamiento de objetos, y el contenido de los archivos como blobs. project-history escribe cambios en él; web, project-history y git-bridge leen de él blobs, instantáneas y zips.

* <strong>Dirección:</strong> `http://history-v1:3100`, dentro de la red de Docker
* <strong>Autenticación:</strong> autenticación HTTP básica como `staging` con `STAGING_PASSWORD`, o un JWT, según la ruta.
* <strong>Archivo OpenAPI:</strong> [`develop/hoppscotch/openapi/history-v1.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/history-v1.yaml)
