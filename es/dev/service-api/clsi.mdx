CLSI (Common LaTeX Service Interface) compila proyectos, ejecuta SyncTeX y texcount sobre la salida de compilación y convierte documentos con pandoc. Web lo llama; los archivos de salida los sirve clsi-nginx, no este puerto. Sin autenticación: solo es accesible dentro de la red de Docker.

* <strong>Dirección:</strong> `http://clsi:3013`, dentro de la red de Docker
* <strong>Autenticación:</strong> ninguna
* <strong>Archivo OpenAPI:</strong> [`develop/hoppscotch/openapi/clsi.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/clsi.yaml)
