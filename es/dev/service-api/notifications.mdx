Guarda las notificaciones que se muestran a los usuarios en la lista de proyectos (por ejemplo, invitaciones a proyectos) en la colección de Mongo `notifications`. Lo llaman web y third-party-datastore; no tiene autenticación y solo es accesible dentro de la red de Docker.

* <strong>Dirección:</strong> `http://notifications:3042`, dentro de la red de Docker
* <strong>Autenticación:</strong> ninguna
* <strong>Archivo OpenAPI:</strong> [`develop/hoppscotch/openapi/notifications.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/notifications.yaml)
