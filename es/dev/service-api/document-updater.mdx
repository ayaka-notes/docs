Mantiene en Redis los documentos abiertos en el editor, les aplica las ediciones y los vuelve a escribir en Mongo a través de web. Lo llaman web y real-time.

* <strong>Dirección:</strong> `http://document-updater:3003`, dentro de la red de Docker
* <strong>Autenticación:</strong> ninguna
* <strong>Archivo OpenAPI:</strong> [`develop/hoppscotch/openapi/document-updater.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/document-updater.yaml)
