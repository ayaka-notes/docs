title: linked-url-proxy
icon: link
---

Obtiene una URL externa para web y devuelve la respuesta en streaming, rechazando direcciones internas para que los usuarios no puedan acceder a la red de Docker. Web envía a través de él los archivos URL, las importaciones de Open in Overleaf y el web_fetch del agente de IA.

* <strong>Dirección:</strong> `http://linked-url-proxy:3066`, dentro de la red de Docker
* <strong>Autenticación:</strong> ninguna
* <strong>Archivo OpenAPI:</strong> [`develop/hoppscotch/openapi/linked-url-proxy.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/linked-url-proxy.yaml)
