En nuestro entorno de desarrollo usamos [goauthentik](https://goauthentik.io/) como ejemplo para probar LDAP, SAML y OIDC con Overleaf, ya que ofrece los métodos de autenticación más completos.

### Instalación

Para configurar [goauthentik](https://goauthentik.io/), puedes consultar el tutorial de [esta página](https://docs.goauthentik.io/install-config/install/docker-compose/). Te recomendamos encarecidamente crear un directorio nuevo para [goauthentik](https://goauthentik.io/).

```bash title="bash" wrap
# (Optional) mkdir ~/authentik && cd ~/authentik
wget https://docs.goauthentik.io/docker-compose.yml
echo "PG_PASS=$(openssl rand -base64 36 | tr -d '\n')" >> .env
echo "AUTHENTIK_SECRET_KEY=$(openssl rand -base64 60 | tr -d '\n')" >> .env
echo "AUTHENTIK_ERROR_REPORTING__ENABLED=true" >> .env
```

A continuación, conecta los siguientes servicios a la red de desarrollo de Overleaf; presta atención al bloque de código de la sección gris.

```text title="authentik/docker-compose.yml" wrap expandable
services:
  postgresql:
    env_file:
    - .env
    environment:
      POSTGRES_DB: ${PG_DB:-authentik}
      POSTGRES_PASSWORD: ${PG_PASS:?database password required}
      POSTGRES_USER: ${PG_USER:-authentik}
    healthcheck:
      interval: 30s
      retries: 5
      start_period: 20s
      test:
      - CMD-SHELL
      - pg_isready -d $${POSTGRES_DB} -U $${POSTGRES_USER}
      timeout: 5s
    image: docker.io/library/postgres:16-alpine
    restart: unless-stopped
    volumes:
    - database:/var/lib/postgresql/data
    networks:
      - overleaf
  server:
    command: server
    depends_on:
      postgresql:
        condition: service_healthy
    env_file:
    - .env
    environment:
      AUTHENTIK_POSTGRESQL__HOST: postgresql
      AUTHENTIK_POSTGRESQL__NAME: ${PG_DB:-authentik}
      AUTHENTIK_POSTGRESQL__PASSWORD: ${PG_PASS}
      AUTHENTIK_POSTGRESQL__USER: ${PG_USER:-authentik}
      AUTHENTIK_SECRET_KEY: ${AUTHENTIK_SECRET_KEY:?secret key required}
    image: ${AUTHENTIK_IMAGE:-ghcr.io/goauthentik/server}:${AUTHENTIK_TAG:-2025.12.4}
    ports:
    - ${COMPOSE_PORT_HTTP:-9000}:9000
    - ${COMPOSE_PORT_HTTPS:-9443}:9443
    restart: unless-stopped
    volumes:
    - ./data:/data
    - ./custom-templates:/templates
    networks:
      - overleaf
  worker:
    command: worker
    depends_on:
      postgresql:
        condition: service_healthy
    env_file:
    - .env
    environment:
      AUTHENTIK_POSTGRESQL__HOST: postgresql
      AUTHENTIK_POSTGRESQL__NAME: ${PG_DB:-authentik}
      AUTHENTIK_POSTGRESQL__PASSWORD: ${PG_PASS}
      AUTHENTIK_POSTGRESQL__USER: ${PG_USER:-authentik}
      AUTHENTIK_SECRET_KEY: ${AUTHENTIK_SECRET_KEY:?secret key required}
    image: ${AUTHENTIK_IMAGE:-ghcr.io/goauthentik/server}:${AUTHENTIK_TAG:-2025.12.4}
    restart: unless-stopped
    user: root
    volumes:
    - /var/run/docker.sock:/var/run/docker.sock
    - ./data:/data
    - ./certs:/certs
    - ./custom-templates:/templates
    networks:
      - overleaf
volumes:
  database:
    driver: local
networks:
  overleaf:
    external: true
    name: develop_default
```

Ahora puedes ejecutar `docker compose up -d` para iniciar todos los contenedores. Para comprobar si authentik se ha conectado correctamente a Overleaf, puedes entrar en un contenedor de desarrollo de Overleaf y ejecutar

```text
zzq ➜ ~/overleaf-pro (server-pro) $ cd develop/ && bin/shell web
node@1ed855be997c:/overleaf/services/web$ curl http://server:9000/login  
<!DOCTYPE html>
```

Con esto, todo debería funcionar. Abre el navegador y utiliza la URL completa (`http://<your server's IP or hostname>:9000/if/flow/initial-setup/`), incluida la barra final. Allí se te pedirá que establezcas una contraseña para el usuario `akadmin` (el usuario predeterminado).
