---
title: Actualizar las traducciones i18n
icon: language
---

Existe un archivo en `services/web/frontend/extracted-translations.json`; la aplicación web de Overleaf solo usará las traducciones extraídas en este archivo.

Ejecuta el siguiente comando para actualizar las traducciones extraídas si has añadido contenido.

```bash
user ➜ ~/overleaf-pro/develop (server-pro) $ bin/shell webpack
root@432836260f8a:/overleaf/services/web# npm run extract-translations
```

En general, no edites los archivos de texto de traducción; usa primero las existentes, ya que todos esos archivos se actualizan desde el upstream de Overleaf o desde un sitio de traducción de terceros.
