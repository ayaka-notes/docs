---
title: Colección GitLab Sync User Credentials
icon: user-lock
---

`gitlabSyncUserCredentials` contiene un documento por cada usuario que vinculó una cuenta de GitLab para GitLab Sync. Guarda los tokens OAuth del usuario, cifrados. Pertenece al módulo web `gitlab-sync` (`services/web/modules/gitlab-sync`). El esquema está en `services/web/modules/gitlab-sync/app/models/gitlabSyncUserCredentials.mjs`, y todo el acceso pasa por `services/web/modules/gitlab-sync/app/src/TokenManager.mjs`.

#### Campos {#fields}

| Campo | Tipo | Significado | Fuente |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Lo establece Mongoose cuando el upsert inserta. | |
| `userId` | ObjectId | El usuario de Overleaf. Obligatorio. El esquema indica `unique: true`, pero no se crea ningún índice (ver Índices); el upsert por `userId` mantiene un documento por usuario. | `gitlabSyncUserCredentials.mjs:8`, `TokenManager.mjs:88-95` |
| `gitlab` | String | El JSON `{ accessToken, refreshToken, expiresAt }`, cifrado con `@overleaf/access-token-encryptor`. `expiresAt` está en milisegundos desde la época Unix, o es `null`; `refreshToken` puede ser `null`. La contraseña viene de `GITLAB_TOKEN_CIPHER_PASSWORD`; la etiqueta de cifrado es `GITLAB_TOKEN_CIPHER_LABEL`, por defecto `2026.10-v3`. Obligatorio. | `gitlabSyncUserCredentials.mjs:9-10`, `TokenManager.mjs:18-31`, `services/web/modules/gitlab-sync/app/src/GitLabApiClient.mjs:209-220` |
| `__v` | Number | La clave de versión de Mongoose. El esquema no la desactiva. | Valor predeterminado de Mongoose |

#### Quién la escribe {#who-writes-it}

| Código | Qué hace |
| ---- | ------------ |
| `TokenManager.mjs:88-95` (`saveUserToken`) | Hace un upsert de las credenciales cifradas del usuario. |
| `TokenManager.mjs:99-108` (`linkUserToken`) | Guarda las credenciales nuevas del callback de OAuth (`services/web/modules/gitlab-sync/app/src/GitLabSyncController.mjs:146`). Cuando el usuario vuelve a vincular la cuenta, el token de acceso reemplazado se revoca en GitLab en segundo plano. |
| `TokenManager.mjs:53-78` (`refreshUserToken`) | Cuando faltan menos de 5 minutos para el `expiresAt` del token de acceso (`:13,47-49`), obtiene tokens nuevos con el token de actualización y los guarda (`:75`). Se ejecuta bajo el bloqueo `gitlabSyncToken` por usuario (`:15,54`), porque GitLab gasta un token de actualización al usarlo. |
| `TokenManager.mjs:111-126` (`removeUserToken`) | Revoca el token de acceso en GitLab (en la medida de lo posible) y luego elimina el documento. Se llama al desvincular (`GitLabSyncController.mjs:173`) y cuando caduca un usuario eliminado (`services/web/modules/gitlab-sync/index.mjs:56-58`). |

#### Quién la lee {#who-reads-it}

| Código | Qué hace |
| ---- | ------------ |
| `TokenManager.mjs:41-45,81-85` (`getUserCredentials`, `getUserToken`) | Descifra las credenciales para cada llamada a la API de GitLab, actualizándolas primero cuando el token está a punto de caducar: `services/web/modules/gitlab-sync/app/src/GitLabSyncHandler.mjs` (por ejemplo `:27`) y `services/web/modules/gitlab-sync/app/src/GitMerge.mjs:52`. Sin documento, o con credenciales que no se pueden descifrar ni actualizar, lanza `InvalidTokenError`, y el usuario cuenta como no vinculado (`GitLabSyncHandler.mjs:25-37`). |
| `services/web/modules/admin-tools/app/src/AdminUserListManager.mjs:394` | Comprueba si el usuario tiene un documento, para las integraciones que se muestran en el panel de administración. |

#### Índices {#indexes}

| Nombre | Claves | Opciones | Migración |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

El `autoIndex` de Mongoose está desactivado (`services/web/app/src/infrastructure/Mongoose.mjs:7`), así que el `unique: true` del esquema en `userId` no crea nada. Ninguna migración crea índices para esta colección.

#### Notas {#notes}

* Cambiar `GITLAB_TOKEN_CIPHER_PASSWORD` hace ilegibles las credenciales guardadas. Esos usuarios cuentan entonces como no vinculados hasta que vuelvan a vincular la cuenta.
* Un usuario eliminado conserva el documento hasta que caduca.
