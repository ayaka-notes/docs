En esta sección analizaremos el modelo de datos de Overleaf. Overleaf usa MongoDB para la persistencia de datos; la única base de datos se llama `sharelatex`, que es también el nombre del predecesor de Overleaf.

Si aún no has configurado Mongo Express para Overleaf, te recomendamos encarecidamente consultar [setup-develop-tools.md](/es/dev/environment/setup-develop-tools  "mention") y configurar tu Mongo.

Una vez configurado Mongo Express, puedes iniciar sesión en [http://localhost:8081/](http://localhost:8081/) con las credenciales `admin:pass`.
