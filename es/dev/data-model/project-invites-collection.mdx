---
title: Colección Project Invites
icon: envelope-open-text
---

`projectInvites` contiene las invitaciones que el propietario de un proyecto envía desde el diálogo de compartir. Un documento es una invitación a una dirección de correo. Se borra cuando la invitación se acepta o se revoca, o lo borra Mongo cuando caduca. El esquema es `services/web/app/src/models/ProjectInvite.mjs`, y lo escribe `services/web/app/src/Features/Collaborators/CollaboratorsInviteHandler.mjs`.

Una invitación no convierte a nadie en miembro. Los miembros están en los arrays `*_refs` de un proyecto, ver [Colección Projects](/es/dev/data-model/projects-collection).

#### Notas {#notes}

* Si el proyecto no tiene ninguna plaza de editor libre cuando se acepta una invitación `readAndWrite` o `review`, el usuario se une con acceso de solo lectura y figura en `pendingEditor_refs` o `pendingReviewer_refs` del proyecto (`CollaboratorsInviteHandler.mjs:162-205`).
* Las invitaciones antiguas guardaban el token en claro en un campo `token`. La migración `20240524135408_add_token_hmac_project_invite_tokens.mjs` añadió `tokenHmac` y `20240531082910_remove_project_invite_tokens.mjs` eliminó `token`.
* Nada borra las invitaciones de un proyecto eliminado; permanecen hasta que el índice TTL las elimina.
