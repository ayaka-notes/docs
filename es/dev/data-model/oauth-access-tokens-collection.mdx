---
title: Colección OAuth Access Tokens
icon: ticket
---

`oauthAccessTokens` contiene los tokens bearer que acepta web. En Ayakaleaf Pro son los tokens de acceso personal (tokens de autenticación de Git) que un usuario crea en la página de configuración de la cuenta y usa para git-bridge y el endpoint MCP. Un documento es un token. El esquema es `services/web/app/src/models/OauthAccessToken.mjs`; el módulo web `oauth2-server` escribe la colección, sobre todo con el driver nativo.

#### Quién escribe {#who-writes-it}

| Código | Qué hace |
| ---- | ------------ |
| `OAuthPersonalAccessTokenManager.mjs:53-88` (`createToken`) | Inserta un token de acceso personal. La ruta `POST /oauth/personal-access-tokens` (`services/web/modules/oauth2-server/app/src/OAuthPersonalAccessTokenRouter.mjs:22-27`) requiere la funcionalidad `gitBridge` del usuario y permite 10 tokens por usuario (`OAuthPersonalAccessTokenController.mjs:7,34-38`). |
| `OAuthPersonalAccessTokenManager.mjs:90-105` (`removeToken`) | Borra un token del usuario. Ruta `DELETE /oauth/personal-access-tokens/:token_id` (`OAuthPersonalAccessTokenRouter.mjs:29-32`). |
| `OAuthPersonalAccessTokenManager.mjs:136-140`, `OAuth2Model.mjs:58-61` | Establecen `lastUsedAt` tras una comprobación correcta. |

#### Notas {#notes}

* Eliminar un usuario no borra sus tokens. `UserDeleter` dispara el hook `cleanupPersonalAccessTokens` (`services/web/app/src/Features/User/UserDeleter.mjs:230-234`), pero ningún módulo lo escucha. Ambas comprobaciones de token rechazan los tokens porque el usuario ya no existe, y el índice TTL los elimina un día después de `accessTokenExpiresAt`.
* Suspender un usuario solo cierra sus sesiones. Los tokens se quedan, y ambas comprobaciones de token los rechazan mientras `users.suspended` sea `true` (`OAuth2Model.mjs:51-54`, `OAuthPersonalAccessTokenManager.mjs:129-134`).
