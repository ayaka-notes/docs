`templates` contiene un documento por plantilla de la galería de plantillas. Los archivos de una plantilla (el zip del proyecto y el PDF) no están aquí: se guardan en filestore bajo `template/<_id>/v/<version>/`. La colección pertenece al módulo web `template-gallery` (`services/web/modules/template-gallery`). El esquema es el modelo de Mongoose `Template` en `services/web/modules/template-gallery/app/src/models/Template.mjs`; la lógica está en `services/web/modules/template-gallery/app/src/TemplateGalleryManager.mjs` y en `TemplateGalleryHelper.mjs`, junto a él.

#### Campos {#fields}

| Campo | Tipo | Significado | Origen |
| ----- | ---- | ------- | ------ |

| `name` | String | El título. Obligatorio, 150 caracteres como máximo. | `category` | String | El enlace de la categoría, `/templates/<key>`, donde `<key>` es uno de `OVERLEAF_TEMPLATE_CATEGORIES` o `all`. Obligatorio. | `Template.mjs:8`, `services/web/modules/template-gallery/index.mjs:17-31`, `TemplateGalleryManager.mjs:206` |

#### Quién escribe {#who-writes-it}

| Código | Qué hace |
| ---- | ------------ |
| `TemplateGalleryManager.mjs:53-97` (`createTemplateFromProject`) | `POST /template/new/:Project_id`. Copia la configuración del proyecto (`TemplateGalleryHelper.mjs:94-134`), sube el zip y el PDF a filestore y guarda. Si el nombre está en uso, responde con un conflicto, salvo que el cliente haya pedido sobrescribir: entonces actualiza esa plantilla y aumenta su `version`, y luego elimina los archivos de la versión anterior. |
| `TemplateGalleryManager.mjs:21-47` (`editTemplate`) | `POST /template/:template_id/edit`. Asigna los campos enviados al documento, vuelve a generar `description` y `author` y establece `lastUpdated`. El formulario de edición envía los campos modificados entre `name`, `license`, `category`, `language`, `authorMD` y `descriptionMD` (`services/web/modules/template-gallery/frontend/js/pages/template/util/api.ts:22-29`). |
| `TemplateGalleryHelper.mjs:186-222` (`deleteTemplateAssets`) | `DELETE /template/:template_id/delete` elimina el documento y los archivos de la versión indicada (`TemplateGalleryManager.mjs:49-51`). |

Solo los administradores del sitio y el usuario de `OVERLEAF_TEMPLATES_USER_ID` pueden llamar a estas tres rutas (`services/web/modules/template-gallery/app/src/Router.mjs:55-62,70-84`, `PermissionsMiddleware.mjs:8-19`).

#### Quién lee {#who-reads-it}

| Código | Qué hace |
| ---- | ------------ |
| `TemplateGalleryManager.mjs:158-183` (`getTemplate`) | Encuentra una plantilla por `_id` o `name` para la página de la plantilla y para `GET /api/template` (`services/web/modules/template-gallery/app/src/TemplateGalleryController.mjs:210-232`). Si `project_id` apunta a un proyecto que ya no existe, la respuesta lo omite; el documento no se modifica. |
| `TemplateGalleryManager.mjs:190-236` (`getCategoryTemplates`) | `GET /api/templates`: una página de una categoría, con búsqueda en `name`, `authorMD` y `descriptionMD`, ordenada por `lastUpdated` o por `name` (sin distinguir mayúsculas y minúsculas). |
| `TemplateGalleryHelper.mjs:64-80` (`canUserOverrideTemplate`) | Lee `owner` para nombrar al propietario en el mensaje de conflicto. |

#### Índices {#indexes}

| Nombre | Claves | Opciones | Migración |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | predeterminado |

`autoIndex` de Mongoose está desactivado (`services/web/app/src/infrastructure/Mongoose.mjs:7`). `tools/migrations/20190912145030_create_templates_indexes.mjs` (`project_id`, `user_id`, `name` únicos) está etiquetada `server-pro` y `saas`, así que no se ejecuta en CE, que solo ejecuta las migraciones `server-ce` (`server-ce/init_scripts/900_run_web_migrations.sh`).

#### Notas {#notes}

* El proyecto original trata `templates` como una colección obsoleta y la elimina en su propio sitio (`tools/migrations/20241002180623_drop_unused_collections.mjs`, etiquetada `saas`). En Ayakaleaf Pro, el módulo de la galería de plantillas la usa.
* Ordenar por nombre usa una intercalación que no distingue mayúsculas y minúsculas, y el comentario de `TemplateGalleryManager.mjs:186-188` señala que un índice de `name` necesitaría la misma. CE no tiene índice de `name`, así que Mongo ordena en memoria.
* Eliminar el proyecto de origen o el propietario no elimina la plantilla.
