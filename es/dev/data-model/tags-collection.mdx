`tags` guarda las etiquetas (carpetas) en las que un usuario organiza los proyectos en el panel de proyectos. Un documento es una etiqueta de un usuario. `web` es su propietario; el esquema es `services/web/app/src/models/Tag.mjs`, y todas las escrituras pasan por `services/web/app/src/Features/Tags/TagsHandler.mjs`.

#### Campos {#fields}

| Campo | Tipo | Significado | Fuente |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id de la etiqueta, usado en las rutas `/tag/:tagId`. | `Tag.mjs:10` |
| `user_id` | String | Propietario de la etiqueta. Una cadena simple, no un ObjectId, por motivos heredados. | `Tag.mjs:7-12` |
| `name` | String | Nombre de la etiqueta, de 50 caracteres como máximo (`MAX_TAG_LENGTH`). Único por usuario. | `Tag.mjs:13`, `TagsHandler.mjs:4` |
| `color` | String | Color opcional: un código hexadecimal como `#a1b2c3` o un valor `hsl(<n>, 70%, 45%)` (`TAG_COLOR_REGEX`). | `Tag.mjs:5`, `Tag.mjs:14-22` |
| `project_ids` | Array of String | Ids de los proyectos de esta etiqueta, como cadenas. | `Tag.mjs:23` |
| `__v` | Number | Clave de versión de Mongoose, añadida cuando `Tag.create` crea el documento. | `TagsHandler.mjs:27` |

#### Quién escribe {#who-writes-it}

| Código | Qué hace |
| --- | --- |
| `TagsHandler.mjs:18-35` (`createTag`) | `POST /tag` (`services/web/app/src/router.mjs:873-874`). Si el nombre está duplicado, devuelve la etiqueta existente. |
| `TagsHandler.mjs:37-70` (`renameTag`, `editTag`) | `POST /tag/:tagId/rename` y `/tag/:tagId/edit` (`router.mjs:879-886`): establecen `name`, o `name` y `color`. |
| `TagsHandler.mjs:72-77` (`deleteTag`) | `DELETE /tag/:tagId` (`router.mjs:891-892`). |
| `TagsHandler.mjs:79-113` | Añade o quita uno o varios proyectos (`$addToSet` / `$pull` / `$pullAll` sobre `project_ids`), rutas `router.mjs:897-916`. |
| `TagsHandler.mjs:124-128` (`removeProjectFromAllTags`) | Se llama para cada miembro cuando se elimina un proyecto (`services/web/app/src/Features/Project/ProjectDeleter.mjs:236-238`) y cuando un usuario es retirado de un proyecto o lo abandona (`services/web/app/src/Features/Collaborators/CollaboratorsController.mjs:621`). |
| `TagsHandler.mjs:130-134` (`addProjectToTags`) | Coloca un proyecto copiado en las mismas etiquetas que el original (`services/web/app/src/Features/Project/ProjectDuplicator.mjs:190-194`). |
| `services/web/modules/server-ce-scripts/scripts/rename-tag.mjs:20-23` | Script de administración que renombra una etiqueta de un usuario directamente en Mongo. |

#### Notas {#notes}

* Las etiquetas son por usuario: dos colaboradores del mismo proyecto mantienen cada uno sus propias etiquetas para él.
* `user_id` y `project_ids` son cadenas, así que consúltalos con ids de tipo cadena, no con ObjectId.
* Eliminar un usuario (`services/web/app/src/Features/User/UserDeleter.mjs`) no modifica `tags`.
