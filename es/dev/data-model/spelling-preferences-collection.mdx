`spellingPreferences` guarda el diccionario de cada usuario: las palabras que el usuario añadió mediante "Add to dictionary" en el corrector ortográfico del editor. Un documento por usuario. `web` es su propietario, sin esquema de Mongoose; el código es `services/web/app/src/Features/Spelling/LearnedWordsManager.mjs`.

#### Campos {#fields}

| Campo | Tipo | Significado | Fuente |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id del documento, creado por el upsert. | `LearnedWordsManager.mjs:21-31` |
| `token` | String | El id del usuario. A pesar del nombre, las rutas de ortografía pasan el id del usuario conectado (`SessionManager.getLoggedInUserId`). | `LearnedWordsManager.mjs:23` |
| `learnedWords` | Array of String | Las palabras que añadió el usuario. | `LearnedWordsManager.mjs:26` |

#### Quién escribe {#who-writes-it}

| Código | Qué hace |
| --- | --- |
| `LearnedWordsManager.mjs:13-32` (`learnWord`) | `POST /spelling/learn` (`services/web/app/src/router.mjs:1037-1041`, `services/web/app/src/Features/Spelling/SpellingController.mjs:45-58`): `$addToSet` de la palabra, con upsert. Se rechaza cuando la lista superaría `Settings.maxDictionarySize` bytes. |
| `LearnedWordsManager.mjs:38-47` (`unlearnWord`) | `POST /spelling/unlearn` (`router.mjs:1043-1047`, `SpellingController.mjs:66-79`): `$pull` de la palabra. |
| `LearnedWordsManager.mjs:84-86` (`deleteUsersLearnedWords`) | Elimina el documento. Su único envoltorio, `SpellingHandler.deleteUserDictionary` (`services/web/app/src/Features/Spelling/SpellingHandler.mjs:24-26`), no tiene ningún llamador en web ni en sus módulos. |

#### Quién lee {#who-reads-it}

| Código | Qué hace |
| --- | --- |
| `LearnedWordsManager.mjs:52-67` (`getLearnedWords`) | Devuelve las palabras sin duplicados. |
| `services/web/app/src/Features/Project/ProjectController.mjs:671` | Envía el diccionario al editor cuando se abre un proyecto (`SpellingHandler.getUserDictionary`). |
