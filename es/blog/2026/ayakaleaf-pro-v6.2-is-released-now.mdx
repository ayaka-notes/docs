Nos enorgullece anunciar el lanzamiento de Ayakaleaf Pro 6.2, el editor de LaTeX en línea más potente y completo de la comunidad. Un agradecimiento especial a yu-i-i y davrot por sus valiosas contribuciones. Mejoraron GitHub Sync e introdujeron la búsqueda avanzada de citas y la integración con Zotero.

### Notas

* Se ha introducido una nueva variable de entorno obligatoria, `OVERLEAF_INVITE_TOKEN_SECRET`; debes generarla con: `openssl rand -base64 32`. Si no está configurada, tu instancia de Overleaf no podrá iniciarse.
* Si habilitas GitHub Sync, debes configurar la variable de entorno `GITHUB_TOKEN_CIPHER_PASSWORD`. Esta variable es necesaria para cifrar de forma segura los tokens de acceso de GitHub. Sin ella, tu instancia de Overleaf no podrá iniciarse.
* Se ha añadido una nueva variable de entorno `DEFAULT_LATEX_COMPILER` para establecer el compilador predeterminado que usan los proyectos nuevos (pdflatex, latex, xelatex o lualatex).
* El editor rediseñado es ahora la única opción disponible.

### Cambios

Esta versión incluye las siguientes mejoras y nuevas funciones.

* `MAX_UPLOAD_SIZE` ahora es configurable en lugar de estar limitado a **50 MB**.
* Se ha corregido un bucle de reinicio del contenedor cuando las compilaciones aisladas (sandboxed compiles) estaban deshabilitadas.
* Se ha impuesto que la eliminación de PAT esté limitada al propietario para OAuth2.
* Se ha corregido un problema de importación de LDAP.

Las nuevas funciones incluyen:

* Se ha añadido un ejecutor de Python basado en el navegador.
* Se ha añadido compatibilidad con Pandoc para importar y exportar Markdown, DOCX y otros formatos.
* Se ha añadido GitHub Sync.
* Se han añadido traducciones completas al chino.
* Se ha añadido la integración con Zotero.
* Se ha añadido `DEFAULT_LATEX_COMPILER`.

#### Función 01: GitHub Sync

Mantén tus proyectos de LaTeX sincronizados con repositorios de GitHub para un flujo de trabajo de desarrollo fluido. Envía y recibe cambios directamente desde el editor, colabora mediante pull requests e intégrate con los pipelines de CI/CD existentes. El control de versiones facilita el seguimiento de revisiones, la revisión de cambios y el mantenimiento de documentos académicos o técnicos reproducibles.

Consulta: [Sincronización con GitHub](/es/on-premises/configuration/overleaf-toolkit/github-synchronisation  "mention").

#### Función 02: Importación/exportación con Pandoc

Importa documentos de Microsoft Word y Markdown como proyectos de LaTeX totalmente editables, o exporta proyectos de LaTeX de vuelta a Markdown y DOCX con un solo clic. Impulsada por Pandoc, esta función permite una interoperabilidad fluida entre la escritura académica, la edición colaborativa y los flujos de publicación, preservando la estructura del documento en la medida de lo posible.

Consulta: [Importación y exportación con Pandoc](/es/on-premises/configuration/overleaf-toolkit/pandoc-import-and-export  "mention").

#### Función 03: Búsqueda avanzada de referencias

Busca e inserta referencias bibliográficas de múltiples bases de datos académicas con filtrado inteligente y soporte instantáneo de citas. Descubre artículos rápidamente, previsualiza metadatos y crea entradas BibTeX precisas sin tener que cambiar entre distintos sitios web de investigación, lo que mejora notablemente la eficiencia de la revisión bibliográfica.

![imagen](https://github.com/user-attachments/assets/42e45b73-af4b-4d1f-81f4-9e116ba5d043)

#### Función 04: Ejecutor de Python

Ejecuta código Python directamente dentro de tu proyecto sin salir del editor. Perfecto para generar figuras, procesar conjuntos de datos, automatizar flujos de trabajo de documentos o ejecutar scripts de investigación reproducibles. Los resultados pueden integrarse en tus documentos LaTeX, haciendo que la computación científica y la escritura formen parte de un flujo de trabajo unificado.

![imagen](https://github.com/user-attachments/assets/a4c314b3-fdb5-4836-aea7-12eeece5cd2f)

#### Función 05: Zotero

Conecta tu biblioteca de Zotero directamente a tu flujo de escritura y gestiona las referencias sin salir del editor. Busca en tus colecciones personales de Zotero, inserta citas con un solo clic y genera y sincroniza automáticamente las entradas BibTeX. Esta integración mantiene tu bibliografía actualizada y agiliza la gestión bibliográfica de artículos académicos, tesis y documentos técnicos.

Consulta: [Integración con Zotero](/es/on-premises/configuration/overleaf-toolkit/zotero-integration  "mention").
