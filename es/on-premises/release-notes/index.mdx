### Cómo entender los números de versión de Overleaf

Overleaf utiliza números de versión de estilo semántico con el formato **6.X.y**.

* **6.X** representa la serie de versiones principales. Cuando se publica una nueva versión **6.X.0**, esta se convierte en la base de esa generación.
* **y** representa las actualizaciones de parche dentro de la misma serie principal. Las versiones posteriores (por ejemplo **6.X.1**, **6.X.2**, …) suelen ser actualizaciones de mantenimiento construidas sobre **6.X.0**, que contienen correcciones de errores, correcciones de seguridad y pequeñas mejoras en lugar de grandes cambios de funcionalidad.

### Versión de Ayakaleaf Pro

Los números de versión de Ayakaleaf Pro están **totalmente alineados** con las versiones oficiales de Overleaf. Salvo que se indique lo contrario, todas las versiones publicadas son imágenes de la edición Pro con todas las funcionalidades.

Alineamos estrictamente nuestras versiones con Overleaf Community Edition. Esto te permite usar plugins de Overleaf de código abierto. No modificamos las interfaces principales de Overleaf. Por lo tanto, cualquier plugin compatible con la versión `A.X.y` correspondiente de Community Edition es totalmente compatible con Ayakaleaf Pro `A.X.y`.
