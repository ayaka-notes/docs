---
title: ¿Qué es el Ayakaleaf Toolkit?
icon: toolbox
---

El Ayakaleaf Toolkit es el método de despliegue recomendado para instalaciones locales de Community Edition y Ayakaleaf Pro, y se ha diseñado para funcionar en el entorno más común: un único servidor físico o máquina virtual. El Toolkit usa `docker compose` para gestionar los contenedores de Docker de tu servidor y ofrece un conjunto de scripts que envuelven comandos de `docker` para ayudarte con la parte más técnica de la gestión de una versión local de Overleaf.

#### El wrapper `bin/docker-compose`

El script `bin/docker-compose` es un wrapper de `docker compose`. Carga la configuración del directorio `config/` antes de invocar `docker compose` con los argumentos que se hayan pasado al script.

Puedes tratar `bin/docker-compose` como un wrapper transparente del programa `docker compose` instalado en tu máquina.

Ejemplo:

```bash title="Check running containers"
$ bin/docker-compose ps
```

#### Scripts auxiliares

Además de `bin/docker-compose`, el Toolkit ofrece scripts prácticos para ayudarte con tareas habituales:

* `bin/up`: atajo de `bin/docker-compose up`
* `bin/start`: atajo de `bin/docker-compose start`
* `bin/stop`: atajo de `bin/docker-compose stop`
* `bin/shell`: inicia una shell dentro del contenedor **sharelatex**
* `bin/doctor`: script que recopila información sobre la instalación y el despliegue. Consulta la sección "Comprobar tu servidor" más abajo
* `bin/mongo`: inicia una shell dentro del contenedor **mongo** y cambia a la base de datos correcta (**sharelatex**)
* `bin/backup-config`: crea una copia (zip o tar) de tu configuración actual y la guarda en el directorio de destino que elijas
* `bin/logs`: ver/seguir los registros de los servicios
* `bin/error-logs`: ver/seguir los registros de errores de los servicios
* `bin/rename-env-vars-5-0`: script de migración para actualizar las variables de entorno en **config/variables.env** (cambio de marca de ShareLaTeX a Overleaf)
* `bin/rename-rc-vars`: script de migración para actualizar las variables de entorno en **config/overleaf.rc** (cambio de marca de ShareLaTeX a Overleaf)
* `bin/run-script`: utilidad para simplificar la ejecución de scripts almacenados dentro del contenedor **sharelatex**
* `bin/upgrade`: ayuda con las actualizaciones de la instancia. El script comprobará si hay actualizaciones del Toolkit (mediante git) y ofrecerá descargar los cambios, comprobará la última versión de la imagen de Docker y ofrecerá actualizarla. Proporciona confirmación paso a paso, la opción de hacer una copia de seguridad de la configuración actual y se encarga de detener e iniciar los servicios de Docker. Consulta Actualizar tu despliegue para más información: https://docs.overleaf.com/on-premises/maintenance/upgrading-your-deployment

<Info>

Si prefieres ejecutar tu instancia sin conectarte a los registros de Docker, puedes ejecutar `bin/up -d` para usar el modo desacoplado (detached).

</Info>

#### Comprobar tu servidor

El Overleaf Toolkit incluye un práctico script llamado `bin/doctor` que genera un informe señalando cualquier dependencia no satisfecha.

Antes de continuar, ejecuta el script `bin/doctor` y comprueba que todo funciona correctamente:

```bash title="Run Overleaf Doctor"
bin/doctor
```
