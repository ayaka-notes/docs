Recomendamos que el administrador local de tu instancia de Overleaf tenga:

* [x] Conocimientos generales de administración de sistemas informáticos
* [x] Familiaridad con las herramientas de línea de comandos de Linux
* [x] Conocimientos generales de redes y capacidad para resolver problemas
* [x] Experiencia haciendo copias de seguridad y restaurando sistemas en producción
* [x] Experiencia ejecutando aplicaciones con Docker (es un plus)
* [x] Experiencia coordinando ventanas de mantenimiento para actualizar sistemas en producción

Hemos comprobado que los administradores locales con estos conocimientos son capaces de ofrecer la mejor experiencia a los usuarios de Overleaf en tu organización.
