### Sistemas operativos {#operating-systems}

Recomendamos un sistema **Linux basado en Debian**, como **Ubuntu**, para servidores compartidos y de producción. Ayakaleaf Pro también puede ejecutarse en [macOS con Docker Desktop](/es/on-premises/installation/using-docker-compose/macos) y en [Windows con WSL 2 y Docker Desktop](/es/on-premises/installation/using-docker-compose/windows). Las tres plataformas usan contenedores Linux y el mismo Toolkit; sigue la guía correspondiente al sistema operativo de tu host.

<Danger>

Al usar Sandboxed Compiles, es **importante** tener en cuenta que la aplicación requiere acceso root al socket de Docker.

</Danger>

### Dependencias {#dependencies}

* Docker 25.0 y 29
* MongoDB 7.0 y 8.0
* Redis 6.2 y 7.5

<Info>

Puedes consultar las fechas de fin de vida (EOL) de las dependencias anteriores y de otros productos populares mediante el servicio endoflife.date aquí: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

`docker compose` descarga automáticamente MongoDB y Redis al ejecutar Ayakaleaf Pro, a menos que se configure para usar una instalación diferente.

</Info>

El Toolkit depende de los siguientes programas:

* bash
* Docker

`docker compose` es obligatorio y normalmente se instala junto con Docker.

Te recomendamos instalar la versión más reciente de Docker disponible para tu sistema operativo.

Una vez instalado Docker correctamente, deberías poder ejecutar estos comandos sin errores:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2 or later, such as v5)
docker compose version

# List the running Docker containers on your system
docker ps
```
