### Sistemas operativos

Para obtener la mejor experiencia al ejecutar Overleaf, te recomendamos encarecidamente usar un sistema operativo **basado en Debian**, como **Ubuntu**. Esta opción coincide con el entorno de desarrollo del software y es la preferida por la mayoría de los usuarios de Overleaf.

<Danger>

Al usar Server Pro con Sandboxed Compiles, es **importante** tener en cuenta que la aplicación requiere acceso root al socket de Docker.

</Danger>

### Dependencias

* Docker 25.0 y 29
* MongoDB 7.0 y 8.0
* Redis 6.2 y 7.5

<Info>

Puedes consultar las fechas de fin de vida (EOL) de las dependencias anteriores y de otros productos populares mediante el servicio endoflife.date: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

`docker compose` descarga automáticamente MongoDB y Redis al ejecutar Server CE o Server Pro, salvo que se configure para usar otra instalación.

</Info>

El Toolkit depende de los siguientes programas:

* bash
* Docker

Se requiere `docker compose`, que normalmente se instala junto con Docker.

Te recomendamos instalar la versión más reciente de Docker disponible para tu sistema operativo.

Una vez que Docker esté instalado correctamente, deberías poder ejecutar estos comandos sin errores:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2)
docker compose version

# List the running Docker containers on your system
docker ps
```
