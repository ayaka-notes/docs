Coloque un enlace en su sitio web, blog o página de curso. Cualquiera que haga clic en él obtiene un nuevo proyecto propio con sus archivos. No hace falta configurar nada.

Los visitantes necesitan una cuenta en su instancia. Un visitante que no ha iniciado sesión va primero a la página de inicio de sesión, y el proyecto se abre después de iniciarla.

Las páginas de esta función usan el nombre Overleaf. Su propio enlace o botón puede decir lo que quiera, por ejemplo **Open in Ayakaleaf**.

## Ver los ejemplos {#see-the-examples}

Abra `/devs` en su sitio, por ejemplo `https://ayakaleaf.example.com/devs`. Ningún menú enlaza a esta página, así que escriba la dirección. De forma predeterminada, debe haber iniciado sesión para verla.

## Enlazar a un archivo de su sitio web {#link-to-a-file-on-your-website}

<Steps>
<Step title="Construir el enlace">
Ponga la dirección del archivo, codificada como URL, después de `/docs?snip_uri=`:

```text
https://ayakaleaf.example.com/docs?snip_uri=https%3A%2F%2Fexample.com%2Fmain.tex
```

Para un proyecto comprimido, use `zip_uri`:

```text
https://ayakaleaf.example.com/docs?zip_uri=https%3A%2F%2Fexample.com%2Fproject.zip
```

Su instancia descarga el archivo, por lo que debe ser accesible por HTTP o HTTPS. Las direcciones de una red privada se rechazan; consulte [External URL](/es/on-premises/configuration/overleaf-toolkit/external-url).
</Step>

<Step title="Añadirlo a su página">
```html
<a href="https://ayakaleaf.example.com/docs?snip_uri=https%3A%2F%2Fexample.com%2Fmain.tex">Open in Ayakaleaf</a>
```
</Step>

<Step title="Hacer clic">
El nuevo proyecto se abre en el editor, con un único archivo guardado como `main.tex`.

<Frame caption="Un proyecto abierto desde un enlace">
  <img src="/images/on-premises/open-in-overleaf-project.png" alt="El proyecto Hello from a link en el editor, con main.tex y su PDF" />
</Frame>

Cada clic crea otro proyecto. El proyecto es una copia, así que los cambios posteriores en su archivo no le llegan.
</Step>
</Steps>

## Poner el archivo en el enlace {#put-the-file-in-the-link}

Para un archivo pequeño no necesita alojar nada: ponga su contenido en el enlace como una URL de datos Base64. En JavaScript:

```javascript
const tex = '\\documentclass{article}\n\\begin{document}\nHello from a link.\n\\end{document}\n'
const link = 'https://ayakaleaf.example.com/docs?' + new URLSearchParams({
  snip_uri: 'data:application/x-tex;base64,' + btoa(tex),
  name: 'Hello from a link',
})
```

`btoa` solo acepta caracteres Latin-1, así que codifique primero cualquier otro texto como UTF-8. Para un proyecto comprimido, use `zip_uri` y `data:application/zip;base64,`.

Un enlace de más de unos 8 KB se rechaza con el error **414 Request-URI Too Large**. Para algo más grande, aloje el archivo o use un [formulario](#use-a-button-instead-of-a-link).

## Elegir las opciones {#choose-the-options}

Añada estos parámetros al enlace, o al formulario como campos ocultos:

| Parámetro                   | Qué hace                                                                                                                 | Ejemplo                                            |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| `name`                      | Pone nombre al proyecto. Sin él, un proyecto comprimido toma el nombre de su `\title`, y cualquier otro se llama `Open in Overleaf project`. | `name=My%20notes`                                  |
| `engine`                    | Establece el compilador: `latex_dvipdf`, `pdflatex`, `xelatex` o `lualatex`.                                                      | `engine=xelatex`                                   |
| `main_document`             | Establece el archivo `.tex` principal, que se abre primero.                                                                                | `main_document=thesis.tex`                         |
| `snip_uri[]`, `snip_name[]` | Importa varios archivos, cada uno con su propio nombre, en el mismo orden.                                                            | `snip_uri[]=.../a.tex&snip_name[]=a.tex`           |

Un archivo `.tex` sin `\documentclass` se envuelve en un documento estándar, así que compila de inmediato:

```latex
\documentclass[12pt]{article}
\usepackage[english]{babel}
\usepackage{amsmath}
\usepackage{tikz}
\begin{document}
Your file
\end{document}
```

## Usar un botón en lugar de un enlace {#use-a-button-instead-of-a-link}

Un formulario envía los mismos parámetros que un enlace:

```html
<form action="https://ayakaleaf.example.com/docs" method="post" target="_blank">
  <input type="hidden" name="snip_uri" value="https://example.com/main.tex">
  <input type="hidden" name="engine" value="xelatex">
  <button type="submit">Open in Ayakaleaf</button>
</form>
```

Para enviar el propio LaTeX, use `snip` para texto sin formato o `encoded_snip` para texto pasado por `encodeURIComponent`.

Un formulario no siempre funciona, por eso un enlace es la mejor opción salvo que su archivo sea demasiado largo para caber en uno:

| Dónde está el formulario                                     | El visitante ha iniciado sesión            | El visitante no ha iniciado sesión        |
| ----------------------------------------------------- | ------------------------------- | ------------------------------- |
| En el mismo dominio que su instancia, o en un subdominio   | El proyecto se abre               | Página de inicio de sesión, sin proyecto      |
| En otro dominio                                     | Página de inicio de sesión, sin proyecto      | Página de inicio de sesión, sin proyecto      |

Si su administrador establece `OVERLEAF_ALLOW_PUBLIC_ACCESS=true`, el proyecto se abre en todos estos casos, tras iniciar sesión si es necesario. Ese ajuste también abre otras páginas a los visitantes sin sesión; consulte [Page Access](/es/on-premises/configuration/overleaf-toolkit/authentication/public-access#page-access).

Para el resto de lo que pueden configurar los administradores, consulte [Overleaf Import API](/es/on-premises/configuration/overleaf-toolkit/integrations/overleaf-import-api). La página `/devs` tiene más ejemplos.

## Si el proyecto no se abre {#if-the-project-does-not-open}

La página indica qué salió mal. **View the Overleaf API docs** le lleva a `/devs`.

<Frame caption="Un enlace que la instancia no puede usar">
  <img src="/images/on-premises/open-in-overleaf-error.png" alt="La página Open in Overleaf con el mensaje invalid url y el botón View the Overleaf API docs" />
</Frame>

| Mensaje                                      | Motivo                                                 | Qué hacer                                  |
| -------------------------------------------- | --------------------------------------------------- | ------------------------------------------- |
| `no snippet, snip_uri or zip_uri provided`   | El enlace no tiene ninguno de estos parámetros                          | Revise los nombres de los parámetros                   |
| `invalid url: ...`                           | La dirección no empieza por HTTP o HTTPS       | Use una dirección HTTP o HTTPS, o una URL de datos |
| `could not download ... (HTTP 404)`          | El archivo no está en esa dirección                     | Revise la dirección                           |
| `could not download ... (HTTP 403)`          | La dirección está en una red privada                 | Aloje el archivo donde su instancia pueda acceder a él |
| `zip_uri did not resolve to a zip archive`   | El archivo de `zip_uri` no es un archivo zip         | Revise el archivo                              |
| `invalid base64 data url`                    | La URL de datos está dañada                             | Vuelva a codificar el archivo y codifique el enlace como URL |
