Usa Claude Code o Codex para planificar y ejecutar un despliegue de Ayakaleaf Pro. El agente puede buscar en esta documentación mediante MCP mientras trabaja.

El agente te ayuda con el despliegue. Tú sigues siendo responsable de revisar los comandos y proteger las credenciales.

### Antes de empezar

Prepara un servidor Linux compatible con acceso SSH. Revisa los [requisitos](/es/on-premises/getting-started/requirements  "mention") antes de continuar.

<Warning>

No pegues contraseñas, claves privadas, tokens ni claves de licencia en los prompts del agente. Revisa cada comando antes de ejecutarlo, especialmente los que modifican archivos, redes o contenedores.

</Warning>

### Conectar la documentación

Añade el endpoint MCP de la documentación a tu agente local.

<Tabs>
<Tab title="Claude Code">

```bash wrap
claude mcp add ayakaleaf-pro --scope user --transport http https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>

<Tab title="Codex">

```bash wrap
codex mcp add ayakaleaf-pro --url https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>
</Tabs>

Inicia una nueva sesión después de añadir el servidor. Pide al agente que confirme que puede buscar en la documentación de Ayakaleaf Pro.

### Desplegar Ayakaleaf Pro

Abre una terminal en tu servidor de despliegue. Inicia Claude Code o Codex allí. A continuación, envía este prompt:

```text wrap
Use the Ayakaleaf Pro documentation MCP server to guide this deployment.
First, inspect the requirements and installation guides.
Ask me for missing deployment details before making changes.
Use the Ayakaleaf Toolkit unless the documentation requires another approach.
Before configuring the instance, summarize relevant optional features.
Ask which features and integrations I want to enable.
Include TLS, sandboxed compiles, Git integration, external MongoDB or Redis,
SSO (OIDC, SAML, or LDAP), GitHub Synchronisation, Zotero, S3 storage,
email delivery, branding, and localization when relevant.
Explain each selected option's prerequisites, security impact, and configuration steps.
Keep unselected optional features disabled.
Show each command before running it.
Do not expose, store, or request secrets in chat.
After deployment, verify that the service is healthy and summarize the changes.
```

El agente debería guiarte a través de la configuración de Docker, la configuración del Toolkit, la descarga de imágenes y el arranque. Sigue la guía [using-the-toolkit](/es/on-premises/installation/using-the-toolkit  "mention") para el flujo de trabajo canónico.

### Elegir funciones opcionales

Pide al agente que te recomiende solo las funciones que se adapten a tu entorno. Las opciones habituales incluyen:

* <strong>Acceso y seguridad:</strong> TLS, compilaciones aisladas (sandboxed compiles) y SSO mediante OIDC, SAML o LDAP.
* <strong>Servicios externos:</strong> MongoDB, Redis, almacenamiento S3 y envío de correo electrónico.
* <strong>Colaboración:</strong> integración con Git, sincronización con GitHub y Zotero.

El agente debería explicar las dependencias antes de editar la configuración. Revisa [toolkit-settings.md](/es/on-premises/configuration/overleaf-toolkit/toolkit-settings  "mention") y [authentication](/es/on-premises/configuration/overleaf-toolkit/authentication  "mention") antes de habilitar integraciones en producción.

### Verificar el despliegue

Cuando el agente complete los pasos:

1. Confirma que todos los comandos se completaron sin errores.
2. Abre en tu navegador la URL configurada de Ayakaleaf Pro.
3. Completa las [6.-post-installation-tasks.md](/es/on-premises/installation/using-the-toolkit/6.-post-installation-tasks  "mention").

Para una instalación existente de Community Edition, usa la guía [migrate-from-existing.md](/es/on-premises/installation/migrate-from-existing  "mention") en lugar de un despliegue nuevo.
