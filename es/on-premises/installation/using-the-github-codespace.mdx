La forma más sencilla de probar Ayakaleaf Pro es usar GitHub Codespace, donde todas las variables de entorno están preconfiguradas para que pueda utilizarlo de inmediato.

<Warning>

Cuando ejecuta contenedores Docker con GitHub Codespaces, el Codespace no se apaga automáticamente y se le seguirá **facturando**. Para conocer las reglas de facturación de GitHub Codespaces, consulte las [reglas de facturación de GitHub Codespaces](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces).

Para gestionar sus GitHub Codespaces, visite [https://github.com/codespaces](https://github.com/codespaces). Cuando ya no lo necesite, elimine su Codespace a tiempo.

</Warning>

Hemos **preconfigurado** las siguientes funciones:

* [x] Compilación de LaTeX en sandbox con TeXLive **Basic** (2024-2026)
* [x] Importación/exportación con Pandoc (funciones de la plataforma SaaS)
* [x] Ejecutor de scripts de Python (funciones de la plataforma SaaS)
* [x] Compatibilidad con Git-Bridge (funciones de Server Pro)
* [x] Búsqueda avanzada de referencias (funciones de la plataforma SaaS)
* [x] Panel de administración (gestión global de usuarios/proyectos)
* [x] Control de cambios (con panel de revisión y comentarios)
* [x] Historial completo del proyecto (con restauración y descarga)
* [x] Symbol Palette (funciones de Server Pro/plataforma SaaS)

<Warning>

Los GitHub Codespaces estándar ofrecen 32 GB de almacenamiento, lo que no es suficiente para nuestra instalación de `texlive-full`. Para probar la imagen completa, envíe una solicitud al soporte de GitHub para obtener un Codespace con runners grandes (8 núcleos o más).

</Warning>

GitHub Sync, LDAP, OAuth, SSO, la integración con Zotero y otras funciones _**no están configuradas**_ en este entorno de pruebas. Puede consultar la [configuración del toolkit](/es/on-premises/configuration/overleaf-toolkit/toolkit-settings) para obtener más detalles sobre cómo configurar estas funciones en su propia implementación.

Si tiene previsto usar [**TeX Live Full**](https://github.com/ayaka-notes/texlive-full), le recomendamos elegir una configuración de **8 núcleos y 64 GB**.

```bash title="bash"

```

#### Usar la imagen TeXLive Full

Si tiene acceso a GitHub Codespaces de 8 núcleos/64 GB, puede usar la imagen TeXLive Full en este entorno de pruebas. Puede modificar las siguientes variables de entorno en el archivo `toolkit/config/variables.env` para usar la imagen TeXLive Full en lugar de la imagen TeXLive Basic.

```dotenv wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1, ghcr.io/ayaka-notes/texlive-full:2024.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025, Texlive 2024
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```

Después de cambiar las variables de entorno, debe reiniciar el toolkit para aplicar los cambios. Puede ejecutar el siguiente comando para reiniciarlo.

```bash
cd toolkit && bin/up -d
```
