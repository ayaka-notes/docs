La forma más sencilla de probar Ayakaleaf Pro es usar GitHub Codespace, donde todas las variables de entorno están preconfiguradas para que puedas usarlo nada más empezar.

<Warning>

Cuando ejecutas contenedores de Docker con GitHub Codespaces, el Codespace no se apagará automáticamente y se te seguirá **facturando**. Para conocer las reglas de facturación de GitHub Codespaces, consulta las [reglas de facturación de GitHub Codespaces](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces).

Para gestionar tus GitHub Codespaces, visita [https://github.com/codespaces](https://github.com/codespaces). Cuando ya no lo necesites, elimina tu Codespace a tiempo.

</Warning>

Hemos **preconfigurado** las siguientes funciones:

* [x] Compilación de LaTeX en sandbox con TeXLive **Basic** (2024-2026)
* [x] Importación/exportación con Pandoc (funciones de la plataforma SaaS)
* [x] Ejecutor de scripts de Python (funciones de la plataforma SaaS)
* [x] Compatibilidad con Git-Bridge (funciones de Server Pro)
* [x] Búsqueda avanzada de referencias (funciones de la plataforma SaaS)
* [x] Panel de administración (gestión global de usuarios y proyectos)
* [x] Control de cambios (con panel de revisión y comentarios)
* [x] Historial completo del proyecto (con restauración y descarga)
* [x] Paleta de símbolos (funciones de Server Pro/plataforma SaaS)

<Warning>

Los GitHub Codespaces estándar ofrecen 32 GB de almacenamiento. Esto es insuficiente para nuestra instalación de `texlive-full`. Para probar la imagen completa, envía una solicitud de soporte a GitHub para obtener un Codespace con runners grandes (8 núcleos o más).

</Warning>

La sincronización con GitHub, LDAP, OAuth, SSO, la integración con Zotero y otras funciones _**no están configuradas**_ en este entorno de pruebas. Puedes consultar la [configuración del Toolkit](/es/on-premises/configuration/overleaf-toolkit/toolkit-settings) para obtener más detalles sobre cómo configurar estas funciones en tu propio despliegue.

Haz clic en el siguiente botón para crear tu GitHub Codespace. En cuanto a la configuración del servidor, **2 núcleos con 8 GB de RAM** suelen ser suficientes para una prueba. Si piensas usar [**TeX Live Full**](https://github.com/ayaka-notes/texlive-full), te recomendamos elegir una configuración de **8 núcleos y 64 GB**.

[![Abrir en GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/ayakaleaf-pro-playground)

Cuando tu codespace esté listo, ejecuta el siguiente comando en tu terminal bash para inicializar tu instancia de Overleaf.

```bash title="bash"

```

#### Usar la imagen TeXLive Full

Si tienes acceso a GitHub Codespaces de 8 núcleos y 64 GB, puedes usar la imagen TeXLive Full en este entorno de pruebas. Puedes cambiar las siguientes variables de entorno en el archivo `toolkit/config/variables.env` para usar la imagen TeXLive Full en lugar de la imagen TeXLive Basic.

```dotenv wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1, ghcr.io/ayaka-notes/texlive-full:2024.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025, Texlive 2024
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```

Después de cambiar las variables de entorno, debes reiniciar el Toolkit para aplicar los cambios. Puedes ejecutar el siguiente comando para reiniciarlo.

```bash
cd toolkit && bin/up -d
```
