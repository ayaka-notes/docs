---
title: 4. Obtener las imágenes de Ayakaleaf Pro
icon: split
---

Ayakaleaf Pro se distribuye como una imagen de Docker en el registro [ghcr](https://github.com/ayaka-notes/overleaf-pro/pkgs/container/overleaf-pro/), con **acceso abierto** para cualquier persona. Proporcionamos imágenes para las arquitecturas amd64 y arm64. Al descargar la imagen, se seleccionará automáticamente la adecuada según la arquitectura de tu sistema.

#### Usuarios del Toolkit de ayaka-notes

Si utilizas [ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit), Ayakaleaf Pro puede usarse como reemplazo directo de la Community Edition, por lo que puedes conservar tu configuración y personalizaciones existentes. Habilita Pro en el Toolkit editando `config/overleaf.rc` y estableciendo la variable de entorno `SERVER_PRO`:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

La próxima vez que ejecutes `bin/up`, el Toolkit descargará y utilizará automáticamente la imagen de Ayakaleaf Pro.

#### Usuarios del Toolkit oficial

Si utilizas [overleaf/toolkit](https://github.com/overleaf/toolkit), para obtener una imagen Pro, ejecuta el siguiente comando para descargarla:

```bash title="Pull Docker Images"
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

A continuación, añade un archivo llamado `docker-compose.override.yml` con el siguiente contenido en el directorio `overleaf-toolkit/config`:

```yml title="docker-compose.override.yml"
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

La próxima vez que ejecutes `bin/up`, el Toolkit descargará y utilizará automáticamente la imagen de Ayakaleaf Pro.
