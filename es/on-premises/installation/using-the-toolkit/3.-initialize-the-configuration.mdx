### Inicialización de la configuración

Inicialicemos los archivos de configuración de nuestro nuevo servidor con unos valores predeterminados razonables ejecutando el script incluido `bin/init`.

```text title="Run initialization"
bin/init
```

Este script **no** sobrescribirá ningún archivo de configuración existente.

Ahora comprobemos el contenido del directorio `config/` con el comando `ls`:

```text title="List the config directory"
ls config
```

Si todo se inicializó correctamente, deberías ver tres archivos de configuración: `overleaf.rc`, `variables.env` y `version`. Son los archivos de configuración principales del servidor y te permiten personalizar cómo funciona tu servidor y cómo interactúan los usuarios con tu instancia.

| Nombre          | Descripción                                                     |
| --------------- | --------------------------------------------------------------- |
| `overleaf.rc`   | El archivo de configuración principal de nivel superior.        |
| `variables.env` | Variables de entorno que se cargan en el contenedor de Docker.  |
| `version`       | La versión de la imagen de Docker que se utilizará.             |

<Info>

Por ahora basta con saber que estos archivos existen y dónde encontrarlos. Más adelante en la documentación repasaremos cada uno de ellos con más detalle y explicaremos cómo puedes personalizar tu instancia con ellos. Si quieres adelantarte, puedes ver un desglose completo de estos archivos de configuración en la [página de archivos y ubicaciones](/es/on-premises/configuration/overleaf-toolkit/files-and-locations).

</Info>
