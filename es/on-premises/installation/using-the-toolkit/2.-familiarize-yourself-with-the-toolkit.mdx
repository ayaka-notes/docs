### Echando un vistazo

Ahora que tienes una copia local del Toolkit, echemos un vistazo a la estructura del repositorio con el comando `ls`.

```bash title="Run this"
ls -l
```

<Info>

El comando `ls -l` muestra una vista detallada en formato largo del contenido de un directorio, con información adicional de los archivos, como permisos, propietario y tamaño.

</Info>

Si todo se ha clonado correctamente, deberías ver algo como esto:

```text
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 bin
-rw-r--r-- 1 fry fry  6465 Aug 30 14:16 CHANGELOG.md
drwxr-xr-x 2 fry fry  4096 Sep  6 12:43 config
drwxr-xr-x 5 fry fry  4096 Aug 30 14:22 data
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 doc
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 lib
-rw-r--r-- 1 fry fry 34520 Aug 30 14:16 LICENSE
-rw-r--r-- 1 fry fry  1178 Aug 30 14:16 README.md
```

<Info>

Todos los archivos de configuración propios del usuario se encuentran en el directorio `config/`. Este directorio está **excluido** del sistema de control de versiones git, por lo que no se modificará al actualizar el Toolkit.

</Info>

## Estructura del repositorio

| Nombre   | Descripción                                                                                                                                                                                                                                               |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `bin`    | Esta carpeta contiene una colección de scripts que te ayudan a gestionar tu instancia del servidor de Overleaf. Puedes leer más sobre estos scripts en la sección Comandos más abajo.                                                                     |
| `config` | Esta carpeta contiene tus propios archivos de configuración locales.                                                                                                                                                                                      |
| `lib`    | Esta carpeta contiene los archivos de configuración base que utiliza el Toolkit.                                                                                                                                                                          |
| `data`   | Por defecto, esta carpeta contiene la ubicación de almacenamiento de MongoDb, Redis y Overleaf. Para más información, consulta la sección [Datos persistentes](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/files-and-locations#persistent-data) más abajo. |

<Warning>

Recomendamos **no** modificar directamente los archivos fuera de la carpeta `/config`. Si necesitas hacer cambios, puedes realizarlos mediante variables de entorno definidas en **config/variables.env** o en **config/overleaf.rc**.\
Por ejemplo, para establecer la imagen del servicio `mongo`, en lugar de editar directamente `lib/docker-compose.mongo.yml`, establece la imagen mediante la variable de entorno `MONGO_IMAGE` en `config/overleaf.rc`. Para más información, consulta la página [Ajustes del Toolkit](/es/on-premises/configuration/overleaf-toolkit/toolkit-settings).

</Warning>

<Info>

El Toolkit **no** modificará ningún dato del directorio `config/` sin tu permiso.

</Info>
