El [Toolkit](https://github.com/ayaka-notes/toolkit) es la forma recomendada de desplegar instancias de Ayakaleaf Pro.

En esta sección te guiaremos para descargar el Toolkit desde GitHub, familiarizarte con algunos de sus comandos y configurar algunos ajustes básicos. Al final de esta página deberías tener en funcionamiento una instancia local de Overleaf.
