### Descargar el Toolkit

El Toolkit es compatible tanto con Server CE como con Ayakaleaf Pro y es el método de instalación recomendado. Usar el Toolkit te permitirá empezar fácilmente con Server CE y actualizar sin problemas a Ayakaleaf Pro si es necesario.

<Info>

[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) está modificado para usar directamente la imagen overleaf-pro de ghcr, con TeX Live proporcionado por ayaka-notes. Como alternativa, puedes descargar el overleaf-toolkit oficial.

</Info>

<Steps>
<Step title="Clonar el repositorio de Overleaf Toolkit">
Para instalar el toolkit, tendrás que ir a la ruta de instalación deseada y clonar el repositorio de GitHub de Overleaf Toolkit (@Ayaka-notes) con este comando:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
# official toolkit (Not Recommended)
# git clone https://github.com/overleaf/toolkit.git ./overleaf-toolkit
```

<Info>

Para evitar posibles problemas de permisos, recomendamos instalar el Toolkit en el directorio `$HOME` de tu usuario.

</Info>
</Step>

<Step title="Entrar en el directorio del toolkit">
Espera a que termine el proceso de clonado y luego cambia al directorio `overleaf-toolkit` recién creado:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
