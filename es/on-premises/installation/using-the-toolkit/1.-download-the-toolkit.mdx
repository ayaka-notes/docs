### Descargar el Toolkit

Ayakaleaf Pro se instala con el **Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)), un conjunto de scripts que ejecuta Overleaf en Docker por ti.

De forma predeterminada, el Toolkit inicia la Community Edition (CE) oficial y gratuita de Overleaf. [4. Obtener las imágenes de Ayakaleaf Pro](/es/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images) lo cambia a Ayakaleaf Pro con un solo ajuste.

<Accordion title="¿Ya usas el Overleaf Toolkit oficial (overleaf/toolkit)?">

No necesitas reinstalar. Conserva tu instalación y sigue la última parte de [4. Obtener las imágenes de Ayakaleaf Pro](/es/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images).

</Accordion>

<Steps>
<Step title="Clonar el repositorio de Ayakaleaf Toolkit">
Para instalar el toolkit, tendrás que ir a la ruta de instalación deseada y clonar el repositorio de Ayakaleaf Toolkit con este comando:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
```

<Info>

Para evitar posibles problemas de permisos, recomendamos instalar el Toolkit en el directorio `$HOME` de tu usuario.

</Info>
</Step>

<Step title="Entrar en el directorio del toolkit">
Espera a que termine el proceso de clonado y luego cambia al directorio `overleaf-toolkit` recién creado:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
