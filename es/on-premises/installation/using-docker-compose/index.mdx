Docker Compose en un único servidor es la forma recomendada de desplegar Ayakaleaf Pro. Lo ejecutas a través del [Toolkit](https://github.com/ayaka-notes/toolkit): un conjunto de scripts que envuelven `docker compose` y leen tu configuración de un único directorio `config/`, de modo que `bin/up` sustituye a `docker compose up`.

Elige la guía correspondiente a la máquina que ejecuta Docker:
