Ayakaleaf Pro se ejecuta sobre Docker. En un Mac se usa Docker Desktop, que ejecuta el motor de Docker en una máquina virtual Linux.

<Steps>
<Step title="Instalar e iniciar Docker Desktop">
Instala la versión de [Docker Desktop](https://docs.docker.com/desktop/setup/install/mac-install/) para tu Mac (Apple silicon o Intel), ábrela y espera a que el motor se haya iniciado. También puedes iniciarlo desde Terminal:

```bash
open -a Docker
```
</Step>

<Step title="Comprobar el motor de Docker">
Ejecuta estos comandos en Terminal:

```bash
docker context show
docker info
docker compose version
```

El contexto debe apuntar a tu motor local de Docker Desktop, normalmente `desktop-linux`. Si hay otro contexto seleccionado, cambia a Docker Desktop antes de continuar:

```bash
docker context use desktop-linux
```

`docker info` debe mostrar una sección **Server**. `docker --version` por sí solo solo muestra que el cliente está instalado.
</Step>

<Step title="Comprobar los recursos y el uso compartido de archivos">
En **Settings** de Docker Desktop, comprueba los límites de CPU, memoria y disco frente a [Antes de empezar](/es/on-premises/installation/using-docker-compose/macos#before-you-start), y la configuración de uso compartido de archivos; consulta [la configuración de Docker Desktop](https://docs.docker.com/desktop/settings-and-maintenance/settings/).

Esta guía mantiene el Toolkit en `/Users`, que Docker Desktop comparte de forma predeterminada. Si usas otra ubicación y `bin/up` falla con `Mounts denied`, añade ese directorio al uso compartido de archivos.
</Step>

<Step title="Comprobar el socket de Docker para la compilación en sandbox">
El Toolkit monta `/var/run/docker.sock` en la aplicación para que pueda iniciar un contenedor de TeX Live independiente para cada compilación. Mantén `DOCKER_SOCKET_PATH=/var/run/docker.sock` en `config/overleaf.rc`.

Es posible que la CLI de Docker en macOS se conecte a través de `~/.docker/run/docker.sock`. Ese es el punto de conexión del cliente en el Mac, no un motivo para cambiar el origen del montaje del Toolkit: el compilador necesita el socket del motor tal como lo ven los contenedores Linux.

Si `/var/run/docker.sock` no existe en el Mac, activa **Allow the default Docker socket to be used** en **Settings → Advanced**; consulta [los requisitos de permisos de Docker](https://docs.docker.com/desktop/setup/install/mac-permission-requirements/).

<Danger>

No ejecutes `chmod 777` sobre el socket para sortear errores. El acceso al socket de Docker equivale a acceso root a la máquina virtual de Docker.

</Danger>
</Step>
</Steps>
