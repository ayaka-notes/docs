En esta sección ejecutamos Ayakaleaf Pro localmente en tu Mac con Docker Desktop y el [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). La guía usa `http://localhost:8080`, guarda los datos en tu directorio personal y compila con TeX Live 2026 en contenedores aislados (sandbox).

Docker Desktop ejecuta la aplicación, MongoDB, Redis y el compilador de TeX Live en una máquina virtual Linux. No instalas MongoDB, Redis ni MacTeX en el propio macOS.

Usa esta configuración para uso personal y pruebas locales. Para un servicio compartido siempre activo, recomendamos la [guía de Linux](/es/on-premises/installation/using-docker-compose/linux), con HTTPS, copias de seguridad y control de acceso. La instancia no está disponible mientras el Mac está en reposo o Docker Desktop está detenido; consulta [Mantener la instancia disponible](/es/on-premises/installation/using-docker-compose/macos/6.-post-installation-tasks#keep-the-instance-available).

## Antes de empezar {#before-you-start}

Necesitas:

* Una versión de macOS compatible con [Docker Desktop para Mac](https://docs.docker.com/desktop/setup/install/mac-install/).
* Git, [Homebrew](https://brew.sh/) y GNU sed. El Toolkit usa opciones de GNU sed que el sed BSD integrado en macOS no acepta.
* Recursos suficientes tanto para macOS como para Docker. Para una instancia local pequeña, empieza asignando 4 CPU y 8 GB de memoria a Docker Desktop. Es un punto de partida sugerido, no un mínimo medido.
* Al menos 40 GB de almacenamiento libre para una imagen completa de TeX Live, más espacio para tus proyectos. Comprueba tanto el espacio libre del Mac como el límite de uso de disco de Docker Desktop. Empieza con una sola versión de TeX Live: cada versión adicional necesita aproximadamente otro tanto de espacio.

Las imágenes de la aplicación y de TeX Live se publican para `arm64` y `amd64`. En Apple silicon, deja que Docker elija la imagen ARM nativa y no fuerces `platform: linux/amd64`.
