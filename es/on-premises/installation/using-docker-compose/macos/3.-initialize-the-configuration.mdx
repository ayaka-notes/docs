---
title: 3. Inicializar la configuración
description: Crea los archivos de configuración del Toolkit en tu Mac con bin/init.
icon: circle-play
---

Desde el directorio del Toolkit, en un terminal con GNU sed en el `PATH`, ejecuta:

```bash
bin/init
```

`bin/init` crea tres archivos:

| Archivo | Finalidad |
| --- | --- |
| `config/overleaf.rc` | Ajustes del contenedor, el puerto publicado y las ubicaciones de los datos |
| `config/variables.env` | Ajustes de la aplicación y secretos |
| `config/version` | La versión de la imagen de la aplicación |

También genera `OVERLEAF_INVITE_TOKEN_SECRET` en `config/variables.env`. Consérvalo, y no publiques este archivo ni lo incluyas en el control de versiones.

Mantén la versión que el Toolkit selecciona para una instalación nueva. Para cambiar más adelante la versión de una instancia existente, sigue [Actualizar tu despliegue](/es/on-premises/maintenance/upgrading-your-deployment).

<Warning>

Si `bin/init` se detiene con `sed: ... invalid command code`, se ejecutó con el sed BSD de macOS. Una ejecución fallida así puede dejar los tres archivos de `config/` con un `OVERLEAF_INVITE_TOKEN_SECRET` vacío, y al volver a ejecutar `bin/init` se informa de `Config files already exist`. Consulta [Solución de problemas](/es/on-premises/installation/using-docker-compose/macos/troubleshooting#initialization-fails-with-invalid-command-code).

</Warning>
