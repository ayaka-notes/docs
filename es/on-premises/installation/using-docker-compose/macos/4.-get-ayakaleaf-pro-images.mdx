---
title: 4. Obtener las imágenes de Ayakaleaf Pro
description: Cambia el Toolkit de tu Mac a la imagen pública de Ayakaleaf Pro.
icon: split
---

Ayakaleaf Pro es una imagen Docker gratuita en [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). No necesitas una cuenta, iniciar sesión ni una licencia comercial de Overleaf para descargarla.

Abre `config/overleaf.rc` y establece:

```bash title="config/overleaf.rc"
SERVER_PRO=true
```

La próxima vez que ejecutes `bin/up`, el Toolkit descargará `ghcr.io/ayaka-notes/overleaf-pro` en la versión indicada en `config/version`, en lugar de la Community Edition oficial de Overleaf.

La imagen se compila para `arm64` y `amd64`, y Docker elige la que corresponde a tu Mac. En Apple silicon, no añadas `platform: linux/amd64` en un override: la imagen se ejecutaría entonces mediante emulación.
