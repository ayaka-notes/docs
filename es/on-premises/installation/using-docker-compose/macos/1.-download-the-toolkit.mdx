<Steps>
<Step title="Comprobar Git y Homebrew">
```bash
git --version
brew --version
```

Si macOS te pide que instales las Command Line Tools al ejecutar Git, instálalas primero. Si falta Homebrew, instálalo con las [instrucciones oficiales](https://brew.sh/).
</Step>

<Step title="Poner GNU sed en el PATH">
Los scripts del Toolkit usan opciones de GNU sed que el sed BSD integrado en macOS rechaza. Instala [GNU sed](https://formulae.brew.sh/formula/gnu-sed) y ponlo en primer lugar en el `PATH` de este terminal:

```bash
brew install gnu-sed
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
sed --version
```

El último comando debería mostrar **GNU sed**.

Un alias como `alias sed=gsed` no basta: el Toolkit ejecuta scripts de Bash, que no ven los alias de tu shell interactivo. No necesitas sustituir `/usr/bin/sed`.

Vuelve a ejecutar la línea `export PATH=...` en cada terminal nuevo que uses para el Toolkit, o añádela a tu archivo de inicio del shell después de la propia inicialización de Homebrew.
</Step>

<Step title="Clonar el repositorio del Ayakaleaf Toolkit">
Elige un directorio persistente. Evita `/tmp`, las unidades extraíbles y las carpetas sincronizadas con la nube, como iCloud Drive, para la base de datos en uso y los datos de los proyectos. Esta guía usa `~/ayakaleaf-toolkit`:

```bash
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

<Warning>

Si el directorio ya contiene una instalación, úsala tal como está o elige otro directorio para una instancia nueva. No inicialices una configuración nueva sobre un despliegue existente.

</Warning>
</Step>
</Steps>
