---
title: 3. Inicializar la configuración
description: Crea los archivos de configuración del Toolkit en Ubuntu sobre WSL 2 con bin/init.
icon: circle-play
---

Desde el directorio del Toolkit en **Ubuntu**, ejecuta:

```bash
bin/init
```

`bin/init` crea tres archivos:

| Archivo | Finalidad |
| --- | --- |
| `config/overleaf.rc` | Ajustes del contenedor, el puerto publicado y las ubicaciones de los datos |
| `config/variables.env` | Ajustes de la aplicación y secretos |
| `config/version` | La versión de la imagen de la aplicación |

También genera `OVERLEAF_INVITE_TOKEN_SECRET` en `config/variables.env`. Consérvalo, y no publiques este archivo ni lo incluyas en el control de versiones.

Mantén la versión que el Toolkit selecciona para una instalación nueva. Para cambiar más adelante la versión de una instancia existente, sigue [Actualizar tu despliegue](/es/on-premises/maintenance/upgrading-your-deployment).

<Info>

`bin/init` no sobrescribe la configuración existente. Si informa de que los archivos ya existen, revísalos antes de continuar. Conserva `config/` y `data/` al reiniciar o actualizar la instancia.

</Info>
