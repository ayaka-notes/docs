En esta sección ejecutamos Ayakaleaf Pro localmente en Windows con WSL 2, Ubuntu, Docker Desktop y el [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). La guía usa `http://localhost:8080`, guarda los datos en el directorio personal de Ubuntu y habilita la compilación en sandbox.

La aplicación, MongoDB, Redis y TeX Live se ejecutan en contenedores Linux gestionados por Docker Desktop. Ejecuta los comandos del Toolkit en Ubuntu; abre la aplicación en tu navegador de Windows. El [paso 0](/es/on-premises/installation/using-docker-compose/windows/0.-setup-wsl-and-docker-desktop) explica cómo encajan las partes de Windows y de Linux, y empieza por la instalación de WSL.

Puedes usar Windows para una instancia local o mantenerla en funcionamiento de forma continua con los ajustes de disponibilidad del paso 6. Para servidores compartidos y de producción, recomendamos la [guía de Linux](/es/on-premises/installation/using-docker-compose/linux), con HTTPS, copias de seguridad y control de acceso. La suspensión de Windows, el cierre de Docker Desktop y el apagado de WSL interrumpen esta instancia local; consulta [Mantener la instancia disponible](/es/on-premises/installation/using-docker-compose/windows/6.-post-installation-tasks#keep-the-instance-available).

## Antes de empezar {#before-you-start}

Necesitas:

* Una versión de Windows y un procesador compatibles con [Docker Desktop para Windows](https://docs.docker.com/desktop/setup/install/windows-install/), con la virtualización por hardware activada. Esta guía usa Windows 11 en x86-64.
* Permiso para habilitar WSL e instalar software. WSL debe ser la versión 2.1.5 o posterior, con Ubuntu ejecutándose en modo WSL 2.
* Memoria suficiente para Windows y los contenedores. Para una instancia local pequeña, 4 CPU y 8 GB disponibles para Docker son un punto de partida sugerido, no un mínimo medido.
* Almacenamiento libre en el disco de Windows que contiene los datos de WSL y Docker. Reserva al menos 40 GB para una configuración completa de TeX Live más los datos de los proyectos; la imagen basic del [paso 5](/es/on-premises/installation/using-docker-compose/windows/5.-personalizing-your-instance) es más pequeña y adecuada para la prueba inicial del despliegue. Las versiones de imagen adicionales necesitan espacio adicional.
* Acceso de red a GitHub, GitHub Container Registry (`ghcr.io`) y Docker Hub para clonar el Toolkit y descargar las imágenes.

Los bloques de **PowerShell** se ejecutan en Windows. Los bloques de **Bash** y los comandos de `bin/` se ejecutan en Ubuntu, salvo que se indique lo contrario. No ejecutes los scripts del Toolkit en PowerShell ni en Git Bash de Windows.
