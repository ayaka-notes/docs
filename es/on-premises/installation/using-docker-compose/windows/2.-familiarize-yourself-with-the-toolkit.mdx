El Toolkit es el mismo que en Linux. Su estructura, el directorio `config/` y los comandos de `bin/` se describen en [2. Familiarízate con el Toolkit](/es/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) de la guía de Linux.

En Windows, ten en cuenta estas diferencias:

* Ejecuta los comandos de `bin/` en **Ubuntu Bash**, desde `~/ayakaleaf-toolkit`. Los comandos marcados como **PowerShell** se ejecutan en cambio en Windows.
* Inicia Docker Desktop y habilita la WSL Integration de Ubuntu antes de usar `bin/up`, `bin/start` o `bin/docker-compose`.
* Mantén los archivos de configuración con finales de línea de Linux (LF). Edítalos con `nano` en Ubuntu o con un editor conectado a WSL. Los finales de línea CRLF pueden provocar errores de Bash.
* `bin/doctor` ejecuta comprobaciones de Linux dentro de Ubuntu. Su advertencia sobre no haber iniciado sesión en `quay.io` no se aplica a la imagen pública `ghcr.io/ayaka-notes/overleaf-pro`. Las demás advertencias siguen requiriendo atención.

```bash
bin/doctor
```
