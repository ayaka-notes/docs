<Steps>
<Step title="Instalar las herramientas de línea de comandos">
Ejecuta en **Ubuntu**, usando la contraseña de Linux que creaste en el paso 0:

```bash
sudo apt update
sudo apt install -y git ca-certificates curl perl gawk openssl
```

Ubuntu ya incluye Bash, GNU sed y coreutils. A diferencia de macOS, no necesita Homebrew ni una instalación separada de GNU sed.
</Step>

<Step title="Clonar el repositorio del Ayakaleaf Toolkit">
Mantén el Toolkit y sus datos en el sistema de archivos Linux de Ubuntu, dentro de tu directorio personal:

```bash
cd "$HOME"
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

Evita `/mnt/c`, `/mnt/d`, OneDrive y los directorios temporales para la base de datos en uso y los datos de los proyectos. Las rutas del sistema de archivos Linux proporcionan los permisos y el comportamiento del sistema de archivos que esperan los contenedores, y evitan la sobrecarga entre sistemas de archivos; consulta [las indicaciones de Microsoft sobre sistemas de archivos](https://learn.microsoft.com/en-us/windows/wsl/filesystems).

<Warning>

Si el directorio ya contiene una instalación, úsala tal como está o elige otro directorio para una instancia nueva. No sustituyas la configuración ni los datos de un despliegue existente.

</Warning>
</Step>
</Steps>
