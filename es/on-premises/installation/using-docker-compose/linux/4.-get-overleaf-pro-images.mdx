---
title: 4. Obtener las imágenes de Ayakaleaf Pro
icon: split
---

Ayakaleaf Pro es una imagen de Docker gratuita en [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). No necesitas una cuenta ni iniciar sesión para descargarla. Las imágenes se compilan para amd64 y arm64, y Docker elige la que corresponde a tu servidor.

Abre `config/overleaf.rc` y establece:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

La próxima vez que ejecutes `bin/up`, el Toolkit descargará la imagen de Ayakaleaf Pro y la usará en lugar de la Community Edition oficial de Overleaf. Tus ajustes de `config/` siguen funcionando.

<Accordion title="¿Ya usas el Overleaf Toolkit oficial (overleaf/toolkit)?">

No necesitas reinstalar. Descarga la imagen de Ayakaleaf Pro:

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Después, añade un archivo llamado `docker-compose.override.yml` con el siguiente contenido en el directorio `overleaf-toolkit/config`:

```yml
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

La próxima vez que ejecutes `bin/up`, el Toolkit usará la imagen de Ayakaleaf Pro.

</Accordion>
