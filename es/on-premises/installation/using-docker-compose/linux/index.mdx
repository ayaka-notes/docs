En esta sección te guiaremos para instalar Docker, descargar el Toolkit desde GitHub, familiarizarte con algunos de los comandos del Toolkit y configurar algunos ajustes básicos. Al final de esta sección deberías tener en funcionamiento una instancia local de Overleaf.

Los pasos están pensados para una versión reciente de Ubuntu LTS. En otra distribución, instala Docker Engine y el plugin Compose como se describe en la [documentación de Docker](https://docs.docker.com/engine/install/) y, a continuación, continúa con [1. Descargar el Toolkit](/es/on-premises/installation/using-docker-compose/linux/1.-download-the-toolkit).

<Info>

De forma predeterminada, la instancia solo acepta conexiones desde el propio servidor, en `http://localhost`. Para abrirla desde otros equipos o en otro puerto, establece `OVERLEAF_LISTEN_IP` y `OVERLEAF_PORT` en `config/overleaf.rc`, como se describe en [5. Personalizar tu instancia](/es/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance).

</Info>
