---
title: Despliegues aislados/sin conexión
description: Despliega Ayakaleaf Pro sin conexión exportando, transfiriendo y cargando imágenes de Docker.
icon: block-brick
---

En general, no recomendamos desplegar Ayakaleaf Pro en un entorno sin conexión, ya que muchas de sus funciones, como GitHub Sync y la integración con Zotero, requieren conexión a Internet.

Si quieres trabajar sin conexión, puede que no siempre sea posible acceder al registro `ghcr.io` para descargar las imágenes necesarias de `ayakaleaf-pro` y de TeX Live. Esto no es un problema, ya que Docker proporciona herramientas para exportar e importar imágenes que te ayudarán con un despliegue sin conexión/aislado (air-gapped).

A grandes rasgos, descargarás las imágenes necesarias en un dispositivo con conexión a Internet, las exportarás a un dispositivo portátil (o las transferirás mediante SCP/Rsync) y las importarás en el servidor aislado.

Para ello, debes completar los siguientes pasos:

* Descarga todas las imágenes necesarias (`overleaf-pro`, `git-bridge`, `mongo`, `redis` + cualquier [imagen de TeX Live](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles#available-tex-live-images) necesaria para usar con [Sandboxed Compiles](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles)) en una máquina con conexión a Internet
  * `docker pull ghcr.io/ayaka-notes/overleaf-pro:6.1.2`
  * `docker pull quay.io/sharelatex/git-bridge:6.1.2` (la etiqueta debe ser la misma que la de `overleaf-pro`)
  * `docker pull mongo:6` (cámbiala por la versión real)
  * `docker pull redis:6.2` (cámbiala por la versión real)
  * `docker pull ghcr.io/ayaka-notes/texlive-full:2024.1` (cámbiala por la versión real)
* A continuación, debes exportar **cada una** de las imágenes descargadas a un archivo .tar. Por ejemplo, `docker save ghcr.io/ayaka-notes/overleaf-pro:6.1.2 > overleaf-pro:6.1.2.tar`
* Con el método que prefieras, transfiere los archivos `.tar` desde tu máquina conectada a Internet al servidor sin conexión/aislado
* Para cada archivo .tar, usa el comando `docker load` para cargar la imagen desde el archivo .tar. Por ejemplo, `docker load < overleaf-pro:6.1.2.tar`
* Por último, ejecuta el comando `docker images` para ver/confirmar que las imágenes se han cargado correctamente y están disponibles

<Danger>

De forma predeterminada, al ejecutar el comando `bin/up`, el Toolkit intentará descargar automáticamente cada una de las imágenes de TeX Live definidas mediante `ALL_TEX_LIVE_DOCKER_IMAGES` en `config/variables.env`. Como tu despliegue está aislado, esto fallará; puedes evitarlo usando `SIBLING_CONTAINERS_PULL=false` en `config/overleaf.rc`.

</Danger>
