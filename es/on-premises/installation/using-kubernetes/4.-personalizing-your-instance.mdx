---
title: 4. Personalizar tu instancia
description: Pon tus ajustes en el ConfigMap que sustituye a config/variables.env.
icon: square-sliders
---

El ConfigMap `overleaf-env` ocupa el lugar del `config/variables.env` del Toolkit: todas las variables de entorno de la [documentación del Toolkit](/es/on-premises/configuration/overleaf-toolkit/environment-variables) van aquí, y los secretos van en el Secret del [paso 2](/es/on-premises/installation/using-kubernetes/2.-create-the-namespace-and-secrets).

```yaml title="30-config.yaml" wrap
apiVersion: v1
kind: ConfigMap
metadata:
  name: overleaf-env
  namespace: overleaf
data:
  OVERLEAF_APP_NAME: Ayakaleaf Pro
  OVERLEAF_SITE_URL: http://192.0.2.10:30080      # the address users open; https://... behind TLS
  OVERLEAF_ADMIN_EMAIL: admin@example.com
  # Emails: add the sender and the SMTP server together, see Email delivery
  # All members, so that the driver finds the primary even when mongo-0 is down
  OVERLEAF_MONGO_URL: mongodb://mongo-0.mongo:27017,mongo-1.mongo:27017,mongo-2.mongo:27017/sharelatex?replicaSet=overleaf
  OVERLEAF_REDIS_HOST: redis
  REDIS_HOST: redis
  ENABLED_LINKED_FILE_TYPES: project_file,project_output_file,url
  ENABLE_CONVERSIONS: "true"
  EMAIL_CONFIRMATION_DISABLED: "true"
  # Requests arrive from kube-proxy or your ingress controller, inside the pod network
  OVERLEAF_TRUSTED_PROXY_IPS: loopback,10.244.0.0/16
  # Sandboxed compiles. The HOST_DIR paths are paths ON THE NODE: the hostPath volumes that
  # the Deployment mounts at /var/lib/overleaf/data/{compiles,output,cache}.
  SANDBOXED_COMPILES: "true"
  SANDBOXED_COMPILES_SIBLING_CONTAINERS: "true"
  DOCKER_RUNNER: "true"
  SANDBOXED_COMPILES_HOST_DIR_COMPILES: /srv/overleaf/compiles
  SANDBOXED_COMPILES_HOST_DIR_OUTPUT: /srv/overleaf/output
  SANDBOXED_COMPILES_HOST_DIR_CACHE: /srv/overleaf/cache
  # Each image must be pulled into Docker on every node that can run Ayakaleaf Pro (step 0)
  ALL_TEX_LIVE_DOCKER_IMAGES: ghcr.io/ayaka-notes/texlive-full:2026.1
  ALL_TEX_LIVE_DOCKER_IMAGE_NAMES: TeX Live 2026
  TEX_LIVE_DOCKER_IMAGE: ghcr.io/ayaka-notes/texlive-full:2026.1
```

```bash
kubectl apply -f 30-config.yaml
```

| Variable                                | Valor                                                                                                                                                           |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_SITE_URL`                     | La URL que los usuarios escriben en el navegador. Con el NodePort del [paso 5](/es/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro), la IP de cualquier nodo y el puerto `30080`; detrás de un ingress o un balanceador de carga, su URL. |
| `OVERLEAF_MONGO_URL`                    | Tu replica set. Usa `?replicaSet=` con el nombre de `rs.initiate`.                                                                                             |
| `OVERLEAF_REDIS_HOST` y `REDIS_HOST`    | Ambas, al Service de Redis.                                                                                                                                    |
| `OVERLEAF_TRUSTED_PROXY_IPS`            | `loopback` más las redes desde las que se conectan tus proxies. `10.244.0.0/16` es la red de pods de flannel; usa el CIDR de pods de tu clúster.              |
| `SANDBOXED_COMPILES_HOST_DIR_*`         | Las rutas en el nodo de los volúmenes de compilación. Deben coincidir con los volúmenes `hostPath` del [paso 5](/es/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro). |

Detrás de HTTPS, establece también `OVERLEAF_SECURE_COOKIE: "true"`; consulta [Proxy TLS](/es/on-premises/configuration/overleaf-toolkit/tls-proxy).

<Info>

Un ConfigMap modificado solo llega a los pods en ejecución tras un reinicio: `kubectl -n overleaf rollout restart deployment/overleaf`.

</Info>
