---
title: 0. Preparar el host
description: Comprueba el sistema operativo y SELinux, e instala git, antes de configurar Podman rootless.
icon: server
---

No instalas Podman a mano: [2. Ejecutar podman-setup](/es/on-premises/installation/using-podman/2.-run-podman-setup) lo instala junto con los demás paquetes que necesita. Aquí solo compruebas el host e instalas `git`, que necesitas para descargar el Toolkit.

<Steps>
<Step title="Comprobar el sistema operativo y SELinux">
Inicia sesión con el usuario que ejecutará Ayakaleaf Pro, no como `root`, y comprueba la distribución y el modo de SELinux:

```bash title="Check the host"
grep PRETTY_NAME /etc/os-release
getenforce
```

Deberías ver RHEL, Rocky Linux, AlmaLinux o CentOS Stream con la versión 9 o posterior, y `Enforcing`:

```text
PRETTY_NAME="Rocky Linux 9.9 (Blue Onyx)"
Enforcing
```
</Step>

<Step title="Comprobar que puedes usar sudo">
`bin/podman-setup --apply` instala paquetes y carga un módulo de SELinux con `sudo`, y te pide la contraseña cuando la necesita:

```bash title="Check sudo"
sudo -v
```

Si esto falla, pide a tu administrador que añada tu usuario al grupo `wheel`.
</Step>

<Step title="Instalar git">
```bash title="Install git"
sudo dnf install -y git
```

<Warning>

No instales Docker Engine en este host. El paquete `podman-docker`, que instala `bin/podman-setup`, proporciona el comando `docker`, y el Toolkit trata el host como Podman siempre que exista el comando `podman`.

</Warning>
</Step>
</Steps>
