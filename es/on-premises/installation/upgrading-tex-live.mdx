---
title: Actualizar TeX Live
description: Actualiza TeX Live o instala paquetes en un despliegue de Overleaf Community Edition.
icon: square-up
---

<Danger>

Las siguientes instrucciones se aplican **solo** a instalaciones de **Community Edition**. Recomendamos encarecidamente a nuestros usuarios de Ayakaleaf Pro que habiliten [Sandboxed Compiles](/es/on-premises/configuration/overleaf-toolkit/sandboxed-compiles), ya que esto proporciona a los usuarios acceso a prácticamente las mismas imágenes de TeX Live que se usan en [overleaf.com](https://www.overleaf.com), además de aislar las compilaciones de los proyectos para una mayor seguridad.

</Danger>

Para ahorrar ancho de banda, tanto la imagen de Overleaf Community Edition como la de Ayakaleaf Pro incluyen solo una instalación mínima de [TeX Live](https://www.tug.org/texlive/). Puedes instalar más paquetes o actualizar a una instalación completa de TeX Live usando el comando [tlmgr](https://www.tug.org/texlive/tlmgr.html) en el contenedor `sharelatex`.

#### Entrar en el contenedor sharelatex

Para abrir una shell dentro del contenedor `sharelatex`, ejecuta

```bash
bin/shell
```

Obtendrás un prompt similar a este:

```bash
root@309b192d4030:/#
```

En las siguientes instrucciones, supondremos que estás dentro del contenedor.

#### Determinar tu versión actual de TeX Live

TeX Live se publica cada año alrededor del mes de abril. Los pasos para usar `tlmgr` difieren según uses la versión actual o una anterior. Puedes comprobar qué versión de TeX Live estás ejecutando con `tlmgr --version`. Por ejemplo, esta instalación ejecuta TeX Live 2021:

```bash
# tlmgr --version
tlmgr revision 59291 (2021-05-21 05:14:40 +0200)
tlmgr using installation: /usr/local/texlive/2021
TeX Live (https://tug.org/texlive) version 2021
```

<Info>

La versión actual de TeX Live se puede consultar en [la página principal de TeX Live](https://www.tug.org/texlive/).

</Info>

Si estás ejecutando una versión antigua de TeX Live, tienes dos opciones. Normalmente se publica una nueva versión de la imagen Docker de Overleaf poco después de cada versión de TeX Live: puedes esperar a que salga y actualizar tu despliegue con el script `bin/upgrade` o, si prefieres mantener la versión antigua de TeX Live, primero tendrás que indicar a `tlmgr` que use un repositorio histórico. Encontrarás las instrucciones para hacerlo [aquí](https://www.tug.org/texlive/acquire.html#past).

#### Instalar paquetes

Para instalar TeX Live completo, ejecuta este comando dentro del contenedor `sharelatex`:

```text
tlmgr install scheme-full
```

También puedes instalar paquetes individuales manualmente:

```bash
tlmgr install tikzlings tikzmarmots tikzducks
```

<Warning>

A partir de la versión `3.3.0`, vuelve a ser **obligatorio** ejecutar `tlmgr path add` después de cada uso de `tlmgr install`, para crear correctamente los enlaces simbólicos de todos los binarios en la ruta del sistema.

</Warning>

Hay muchos más comandos disponibles. Descubre más con:

```text
tlmgr help
```

Cuando termines, escribe `exit` o pulsa Control-D para salir de la shell.

#### Guardar tus cambios

Los cambios que acabas de hacer han modificado el contenedor `sharelatex`, pero son efímeros: se perderán si Docker Compose vuelve a crear el contenedor, por ejemplo al actualizar la configuración.

Para hacerlos persistentes, usa `docker commit` para guardar los cambios en una nueva imagen Docker:

```bash
cat config/version #5.2.1
docker commit sharelatex sharelatex/sharelatex:5.2.1-with-texlive-full
echo 5.2.1-with-texlive-full > config/version
```

Después de hacer commit de los cambios, actualiza `config/version` en consecuencia. Luego ejecuta `bin/up` para volver a crear el contenedor `sharelatex`.

<Danger>

Tendrás que repetir estos pasos cada vez que [actualices](https://github.com/overleaf/toolkit/blob/master/doc/upgrading.md) a una nueva versión de Overleaf.

</Danger>
