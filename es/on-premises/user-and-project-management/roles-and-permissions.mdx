### Cuenta

En lo que respecta a la gestión de su propia cuenta, **todos** los usuarios se tratan como usuarios normales: los `Site Admins` y los `Template Users` **no** obtienen permisos adicionales. No obstante, existen restricciones sobre las acciones que pueden realizar los usuarios normales en función de cómo se autentican.

#### Configuración

**Tipos de autenticación: cuentas internas | SSO (SAML/LDAP)**

| Acción | Cuentas internas | SSO (SAML/LDAP) |
| ----------------------------------------- | ----------------: | --------------: |
| Actualizar la información de la cuenta | Sí | No |
| Cambiar la contraseña | Sí | No |
| Generar tokens de autenticación de Git bridge | Sí | Sí |
| Eliminar tokens de autenticación de Git bridge | Sí | Sí |
| Gestionar sesiones | Sí | Sí |

<Info>

La integración con Git Bridge **solo** está disponible en Server Pro. Consulte [Server Pro frente a Community Edition](/es/on-premises/readme/ayakaleaf-pro-vs-server-pro) para obtener más información.

</Info>

#### Sus sesiones

| Acción | Usuario |
| -------------------- | ---: |
| Borrar sesiones | Sí |
| Ver la sesión actual | Sí |
| Ver otras sesiones | Sí |

### IDE del editor

En lo que respecta al IDE del editor de Overleaf, puede tener uno de los siguientes roles: `Project Owner`, `Editor`, `Reviewer`, `Viewer`, `Site Administrator` o `Template User`.

<Info>

Server Pro y Community Edition permiten proporcionar acceso anónimo de **solo lectura** y de **lectura y escritura** a los proyectos.

Para obtener más información, consulte las variables de entorno `OVERLEAF_ALLOW_PUBLIC_ACCESS` y `OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` [aquí](/es/on-premises/configuration/overleaf-toolkit/environment-variables).

</Info>
