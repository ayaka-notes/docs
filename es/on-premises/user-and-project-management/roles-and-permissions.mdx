### Cuenta

En lo que respecta a la gestión de su propia cuenta, **todos** los usuarios se tratan como usuarios normales: los `Site Admins` y los `Template Users` **no** obtienen permisos adicionales. Sin embargo, existen restricciones sobre las acciones que pueden realizar los usuarios normales según cómo se autentiquen.

#### Configuración

<strong>Tipos de autenticación: cuentas internas | SSO (SAML/LDAP)</strong>

| Acción                                    | Cuentas internas | SSO (SAML/LDAP) |
| ----------------------------------------- | ----------------: | --------------: |
| Actualizar la información de la cuenta                       |               Sí |              No |
| Cambiar la contraseña                           |               Sí |              No |
| Generar tokens de autenticación de Git bridge |               Sí |             Sí |
| Eliminar tokens de autenticación de Git bridge   |               Sí |             Sí |
| Gestionar sesiones                           |               Sí |             Sí |

<Info>

La integración con Git Bridge **solo** está disponible en Server Pro. Consulta [Server Pro frente a Community Edition](/es/on-premises/readme/ayakaleaf-pro-vs-server-pro) para más información.

</Info>

#### Tus sesiones

| -------------------- | ---: |
| Borrar sesiones       |  Sí |
| Ver la sesión actual |  Sí |
| Ver otras sesiones  |  Sí |

### IDE del editor

Desde el punto de vista del IDE del editor de Overleaf, puedes tener uno de los siguientes roles: `Project Owner`, `Editor`, `Reviewer`, `Viewer`, `Site Administrator` o `Template User`.

<Info>

En Server Pro y Community Edition se admite el acceso anónimo de **solo lectura** y de **lectura y escritura** a los proyectos.

Para más información, consulta las variables de entorno `OVERLEAF_ALLOW_PUBLIC_ACCESS` y `OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` [aquí](/es/on-premises/configuration/overleaf-toolkit/environment-variables).

</Info>
