---
title: Migrar de Server Pro a Group Professional
icon: rectangle-pro
noindex: true
---

Pasar de una instancia autoalojada de Server Pro a una nueva suscripción en la nube de Overleaf Group Professional es un cambio importante, por lo que, para que este proceso sea lo más fluido posible, hemos preparado las siguientes indicaciones.

En general, proponemos un periodo de solapamiento de tres meses a partir de la fecha de renovación. Esto significa que:

* Tu instancia actual de Server Pro y tu nueva suscripción de Group Professional estarán ambas plenamente activas.
* Tu equipo técnico podrá planificar el tiempo necesario para configurar la suscripción de Group Professional y decidir el futuro de tu despliegue local de Server Pro.
* Y, lo más importante, tus usuarios tendrán tiempo de sobra para copiar sus proyectos a la nueva plataforma Overleaf Group Professional.

Esta guía rápida te guiará por los pasos clave de esta migración. ¡Empecemos!

<Steps>
<Step title="Fase 1: Instalación y configuración">
(Enlace: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-1-setup-and-configuration)

* Overleaf creará tu suscripción de Group Professional y añadirá a tu administrador principal.
* Tu administrador de grupo podrá habilitar [Managed Users](https://docs.overleaf.com/groups/user-management/managed-user-accounts), configurar el [inicio de sesión único (SSO)](https://docs.overleaf.com/groups/overleaf-group-single-sign-on/setting-up-group-sso) e [invitar a los usuarios finales](https://docs.overleaf.com/groups/user-management/how-to-add-and-remove-users).

<Warning>

Habilitar Managed Users e implantar SSO es un paso obligatorio para el cumplimiento de FedRAMP® LI-SaaS. Si tu organización requiere el cumplimiento de FedRAMP, configura Managed Users y SSO antes de invitar a los usuarios finales.

</Warning>
</Step>

<Step title="Fase 2: Migración de usuarios y gestión de datos">
(Enlace: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-2-user-migration-and-data-management)

Esta es la ventana principal de migración y conlleva las siguientes responsabilidades:

#### Usuarios finales

* Los usuarios deben migrar los proyectos que quieran conservar de tu instancia de Server Pro a sus nuevas cuentas en [overleaf.com](http://overleaf.com/). El proceso consiste en [exportar los proyectos](https://www.overleaf.com/learn/how-to/Exporting_your_work_from_Overleaf) desde Server Pro y [subirlos](https://www.overleaf.com/learn/how-to/Uploading_a_project) a su cuenta en [overleaf.com](http://overleaf.com/). Si un usuario aún no tiene una cuenta de [overleaf.com](http://overleaf.com/), puede registrarse en [overleaf.com/register](http://overleaf.com/register).

<Warning>

Mediante este procedimiento de exportación solo se transferirá el código fuente del proyecto (archivos LaTeX y binarios). La configuración existente de los proyectos, la configuración de uso compartido, los comentarios, los cambios registrados, etc. NO se transferirán. Los usuarios tendrán que volver a invitar a sus colaboradores tras la migración.

</Warning>

#### Personal técnico

* Durante esta fase, tu equipo técnico debe planificar cómo gestionar tu instancia local de Server Pro y sus datos tras la migración.
* **Copia de seguridad de los datos:** puedes exportar todos los proyectos antes de dar de baja la instancia para crear un archivo que te permita ayudar a los usuarios que hayan olvidado migrar o descargar su trabajo. Instrucciones: https://docs.overleaf.com/on-premises/maintenance/data-and-backups/exporting-projects
* **Retirada de Server Pro:** una vez cerrada la ventana de migración y deshabilitada tu clave de licencia, tienes dos opciones principales para la propia instancia de Server Pro (consulta el siguiente paso).
</Step>

<Step title="Opciones para retirar Server Pro">
<Steps>
<Step title="Desinstalar Server Pro por completo">
La desinstalación retira Server Pro y elimina el software por completo.
</Step>

<Step title="Cambiar a Community Edition">
El cambio conserva la base de datos de usuarios y proyectos con el historial completo de proyectos, convirtiendo la instancia de Server Pro en Community Edition.
</Step>
</Steps>

<Info>

La Community Edition NO incluye [Sandboxed Compiles](https://docs.overleaf.com/on-premises#overview-of-server-pro-and-community-edition) ni [LDAP](/es/on-premises/configuration/overleaf-toolkit/authentication/ldap-authentication)/[SAML](/es/on-premises/configuration/overleaf-toolkit/authentication/saml-authentication). Si necesitas volver a la autenticación nativa (usuario/contraseña), consulta: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-to-ldap-or-saml#going-the-other-way-switching-from-ldap-saml-back-to-native-authentication

Para ver una comparación entre Server CE y Server Pro, consulta: https://docs.overleaf.com/on-premises/welcome/server-pro-vs.-community-edition

</Info>
</Step>

<Step title="Fase 3: Retirada de Server Pro">
(Enlace: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-3-server-pro-decommission)

* El equipo de Overleaf desactivará formalmente tu clave de licencia de Server Pro y te enviará una confirmación cuando haya terminado.
* En ese momento, realiza una de las acciones de retirada descritas arriba: desinstalar Server Pro por completo o cambiar a Community Edition.
</Step>
</Steps>

Los recursos adicionales y los enlaces mencionados arriba se mantienen sin cambios.
