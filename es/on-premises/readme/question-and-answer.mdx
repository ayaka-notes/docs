Aquí hemos recopilado las respuestas a algunas preguntas frecuentes sobre Ayakaleaf Pro.

### Preguntas básicas

<Accordion title="P01: ¿Es Ayakaleaf Pro una versión de prueba gratuita? ¿Requiere licencia?">

No. Ayakaleaf Pro es completamente gratuito. No es una versión de prueba y no requiere licencia.

</Accordion>

<Accordion title="P02: ¿Incluye Ayakaleaf Pro todas las funcionalidades de Overleaf Server Pro?">

Sí. Ayakaleaf Pro incluye todas las funcionalidades de Overleaf Server Pro, incluida la integración con Git-Bridge. También incluye funcionalidades seleccionadas de la plataforma SaaS de Overleaf. Seguimos desarrollando y mejorando Ayakaleaf Pro.

</Accordion>

<Accordion title="P03: ¿Cuánto cuesta Overleaf Server Pro?">

Overleaf Server Pro cuesta alrededor de \$300 por usuario al año. Requiere al menos 10 licencias, por lo que los despliegues parten de unos \$3.000 anuales. Los contratos públicos más pequeños en EE. UU. muestran costes anuales de unos \$320–\$370 por usuario. Esto hace que Server Pro sea caro, sobre todo para equipos pequeños. Consulta [#information-and-price-about-overleaf-server-pro](/es/on-premises#information-and-price-about-overleaf-server-pro  "mention") para ver compras y precios documentados.

</Accordion>

<Accordion title="P04: ¿Por qué Overleaf Server Pro no incluye GitHub Sync ni funcionalidades de IA?">

Overleaf Server Pro lo utilizan habitualmente organizaciones gubernamentales. Lo despliegan en redes privadas y controlan estrictamente el acceso. Para proteger los datos sensibles, sus funcionalidades incluidas evitan intercambiar datos con servicios de terceros. Si necesitas GitHub Sync, IA u otras funcionalidades conectadas similares, Overleaf recomienda suscribirse a su plataforma SaaS.

</Accordion>

<Accordion title="P05: ¿Es Ayakaleaf Pro seguro y fiable?">

Ayakaleaf Pro es de código abierto. Revisamos el código con herramientas como Codex Security para reforzar su seguridad y fiabilidad. Si no habilitas la sincronización de datos con terceros, tus datos permanecen en tu servidor. Ayakaleaf Pro no contiene telemetría que envíe tus datos a otro lugar.

</Accordion>

<Accordion title="P06: ¿Se mantendrá Ayakaleaf Pro a largo plazo?">

Haremos todo lo posible por mantener este proyecto a largo plazo.

</Accordion>

<Accordion title="P07: ¿Cumple Ayakaleaf Pro con la normativa de licencias?">

Ayakaleaf Pro es un fork de la comunidad. Su código y sus funcionalidades integradas proceden de contribuciones de la comunidad. Está publicado bajo la licencia AGPL v3. Los despliegues pueden cumplir con esta licencia siempre que satisfagan sus requisitos.

</Accordion>

<Accordion title="P08: ¿Por qué el proyecto se llama Ayakaleaf Pro?">

El proyecto se llamaba originalmente Overleaf Pro en 2024. El desarrollo se detuvo durante un tiempo y se reanudó a finales de 2025. En el primer trimestre de 2026, Overleaf renombró como Pro su plan de suscripción con IA. Los comentarios de la comunidad también señalaron que el nombre Overleaf Pro podía generar riesgos de marca registrada y de suplantación, ya que podía hacer creer a los usuarios que el proyecto era oficial.

Renombramos el proyecto como Ayakaleaf Pro para evitar esa confusión. El nombre puede leerse como "Ayaka-notes Overleaf Pro". El responsable del mantenimiento contribuye al desarrollo comunitario de Overleaf desde su etapa de estudiante, hace más de cinco años. Esta experiencia respalda nuestro compromiso de mantenimiento a largo plazo.

</Accordion>

<Accordion title="P09: ¿Qué distingue a Ayakaleaf Pro de los nuevos editores de LaTeX creados con IA?">

Desde 2026, la comunidad de código abierto ha publicado muchos editores de LaTeX creados con IA, incluido OpenAI Prism. Ayakaleaf Pro mantiene tus datos y servicios en tu propio servidor. Esto te da control directo sobre tu despliegue y tus datos.

Muchos editores experimentales de la comunidad no tienen un plan de mantenimiento a largo plazo consolidado. Las plataformas de compilación de LaTeX de terceros también pueden dejar de funcionar cuando su base de usuarios o sus ingresos son insuficientes. Ayakaleaf Pro entrega todo el código fuente y te permite alojar tú mismo todos los servicios. Incluso si el mantenimiento se detuviera, tu servicio autoalojado existente podría seguir funcionando.

</Accordion>

### LaTeX

<Accordion title="P01: ¿Están aisladas las compilaciones de los proyectos LaTeX de los usuarios? ¿Está habilitado Shell Escape?">

Cuando habilitas Sandbox Compiles, la compilación de cada usuario se ejecuta en un contenedor Docker independiente y queda aislada de las compilaciones de los demás usuarios. Shell Escape está habilitado por defecto en Sandbox Compiles.

</Accordion>

<Accordion title="P02: ¿Es fiable la imagen de Sandbox Compiles? ¿Puede fallar la compilación?">

Durante los últimos tres años hemos mejorado nuestra imagen TeX Live Full para Sandbox Compiles. En la mayoría de los casos, los proyectos que compilan en overleaf.com también compilan correctamente con Ayakaleaf Pro. Si falta una fuente necesaria, súbela manualmente a tu proyecto.

</Accordion>
