<Info>

Ayakaleaf Pro es una implementación mejorada de Overleaf Community Edition que ofrece todas las funciones _**premium de forma gratuita**_ de Server Pro. A diferencia de Overleaf Common, disponible en [https://www.overleaf.com/](https://www.overleaf.com/), no tenemos límites de tiempo de compilación ni requisitos de licencia según el número de usuarios, y puedes alojar tú mismo todos tus datos, garantizando una seguridad absoluta.

Overleaf Server Pro es un despliegue comercial y autoalojado de Overleaf, con soporte oficial. Para obtener más información sobre Server Pro, visita [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud).

</Info>

<Warning>

Overleaf Community Edition está pensada para usarse en entornos en los que se confía en **todos** los usuarios. Community Edition **no** es adecuada para escenarios en los que se requiere aislamiento entre usuarios, ya que las compilaciones aisladas (Sandbox Compiles) no están disponibles.

Sin aislamiento, las compilaciones de LaTeX se ejecutan con los mismos privilegios que el contenedor, lo que permite acceder a su sistema de archivos, su red y sus variables de entorno. Esto crea un riesgo de exposición de datos o de compromiso del sistema. Las compilaciones sin aislamiento solo deben usarse en entornos de total confianza; para despliegues multiusuario o de producción, se recomiendan encarecidamente las Sandbox Compiles.

Para obtener más información sobre las Sandbox Compiles, consulta nuestra [documentación](/es/on-premises/configuration/overleaf-toolkit/sandboxed-compiles).

</Warning>

### Soporte de la comunidad

Para quienes usan una instancia autoalojada de Overleaf, el soporte lo proporciona la comunidad a través de las [Issues](https://github.com/ayaka-notes/ayakaleaf-pro/issues) de GitHub.

Para mantenerte en una versión con soporte, puedes confirmar qué versión de Overleaf estás ejecutando comparando la salida del siguiente comando con los ID de imagen publicados en las notas de la versión.

```bash
docker inspect --format '{{.Image}}' sharelatex | awk -F: '{print substr($2, 1, 12)}'
```
