Respetamos los derechos de autor, por lo que aquí enumeramos todas las funcionalidades y el código utilizado en este proyecto. En esta página ofrecemos información sobre las nuevas funcionalidades de Ayakaleaf Pro y los derechos de autor del código relacionado.

Salvo que se indique lo contrario, usamos Codex de OpenAI para la revisión de código y de PR. Durante este proceso corregimos muchos problemas de seguridad, por lo que les expresamos nuestro más sincero agradecimiento. Para más detalles, consulta [ayaka-notes/ayakaleaf-pro/pull](https://github.com/ayaka-notes/ayakaleaf-pro/pulls).

### Descripción general

A lo largo de los años, muchos desarrolladores de la comunidad han hecho grandes esfuerzos para mejorar Overleaf Community Edition. Son los siguientes:

* [https://github.com/ertuil/overleaf](https://github.com/ertuil/overleaf)
* [https://github.com/AllanChain/lcpu-overleaf](https://github.com/AllanChain/lcpu-overleaf)
* [https://github.com/yu-i-i/overleaf-cep/](https://github.com/yu-i-i/overleaf-cep/)
* [https://github.com/ayaka-notes/overleaf](https://github.com/ayaka-notes/overleaf)
* [https://github.com/davrot/overleaf\_with\_admin\_extension](https://github.com/davrot/overleaf_with_admin_extension)
* [https://github.com/overleaf/overleaf/pull/1447](https://github.com/overleaf/overleaf/pull/1447) (integración con GitHub)
* [https://github.com/overleaf/overleaf/pull/1385](https://github.com/overleaf/overleaf/pull/1385) (compatibilidad con Typst)

Es posible que hayamos usado código relacionado en nuestro proyecto, y queremos expresarles nuestro agradecimiento.

* Descargar plantillas directamente desde las páginas de plantillas.
* Abrir el proyecto correspondiente a la plantilla.
* Convertir a imágenes de portada de mayor calidad (y en menos tiempo).

#### Funcionalidad 05: panel de administración

<Warning>

Cuando tu sistema tiene 1000 usuarios o proyectos, el panel de administración solo mostrará los 1000 usuarios o proyectos más recientes. Usa el panel de búsqueda para buscar usuarios o proyectos concretos.

</Warning>

Esta funcionalidad la ha desarrollado principalmente [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep). Modificamos parte del código para mejorarla, de modo que puedes:

* Buscar usuarios mediante el backend cuando tienes más de 1000 usuarios.
* Buscar proyectos mediante el backend cuando tienes más de 1000 proyectos.
* Abrir proyectos directamente desde el panel de administración de proyectos.
* Ver y ajustar el límite de tiempo de compilación de un usuario desde el panel de administración.
* Restablecer la contraseña de un usuario directamente desde el panel de administración.
* Otras mejoras...

#### Funcionalidad 13: ejecutor de Python

Esta funcionalidad la ha desarrollado Overleaf oficialmente. Puedes ejecutar scripts de Python en tu navegador.

Está integrada y no necesita configuración: abre un archivo `.py` en un proyecto y haz clic en **Run**. El script se ejecuta con Pyodide en el navegador del usuario, por lo que solo están disponibles los paquetes integrados de Pyodide.

* El panel de salida, debajo del editor, muestra lo que imprime el script (las últimas 100 líneas). Haz clic en **Stop** para interrumpir una ejecución. Cada ejecución inicia un Python nuevo, por lo que nada se conserva de la ejecución anterior.
* Antes de cada ejecución, los archivos de texto del proyecto se copian en la carpeta de trabajo del script, de modo que el script puede abrirlos por su ruta en el proyecto, p. ej., `open('data/results.csv')`. Los archivos binarios, como imágenes y PDF, no se copian.
* Los archivos que el script escribe en esa carpeta se guardan en el proyecto en la misma ruta cuando la ejecución tiene éxito, sustituyendo cualquier archivo con el mismo nombre. Una ejecución fallida no guarda nada. Una ejecución puede guardar hasta 50 archivos, 50 MB por archivo y 100 MB en total.
* Matplotlib no tiene pantalla: guarda los gráficos con `plt.savefig('figure.png')` y, después, incluye la imagen en tu documento LaTeX.
* Pyodide y sus paquetes (como NumPy, pandas, SciPy y Matplotlib) los sirve tu instancia, por lo que el navegador no necesita acceso a internet. No se pueden usar paquetes instalados con pip.

#### Funcionalidad 17: integración con gestores de referencias

Esta funcionalidad la ha desarrollado [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro). La integración con Zotero la desarrollaron inicialmente [davrot](https://github.com/davrot) y [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep); la rehicimos con OAuth y añadimos la integración con Mendeley (OAuth 2.0) en la v6.3.0. Puedes:

* Vincular tus cuentas de Zotero y Mendeley en la configuración de la cuenta.
* Importar tu biblioteca personal o una biblioteca de grupo como archivo `.bib` en tu proyecto.
* Actualizar el archivo `.bib` importado en cualquier momento para mantenerlo al día.

Consulta [Integración con Zotero](/es/on-premises/configuration/overleaf-toolkit/integrations/zotero-integration) e [Integración con Mendeley](/es/on-premises/configuration/overleaf-toolkit/integrations/mendeley-integration) para la configuración.

#### Funcionalidad 18: API Open in Overleaf

Esta funcionalidad la ha desarrollado [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) y es compatible con la API "Open in Overleaf" de overleaf.com. Puedes añadir un enlace o botón "Open in Ayakaleaf" a tu sitio web, blog o biblioteca de plantillas, para que los visitantes puedan abrir con un solo clic un fragmento de LaTeX, un archivo remoto o un proyecto ZIP como nuevo proyecto en tu instancia. Visita `/devs` en tu instancia para obtener más detalles y consulta [API de importación de Overleaf](/es/on-premises/configuration/overleaf-toolkit/integrations/overleaf-import-api).

#### Funcionalidad 19: sincronización con GitLab

Esta funcionalidad la ha desarrollado [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) en la v6.3.1 como versión preliminar (publicación oficial en la v6.4.0). Al igual que con la sincronización con GitHub, puedes vincular un proyecto a un repositorio de GitLab.com o de tu GitLab autogestionado, hacer push de commits desde Overleaf y fusionar commits desde GitLab. Consulta [Sincronización con GitLab](/es/on-premises/configuration/overleaf-toolkit/integrations/gitlab-synchronisation) para la configuración.

#### Funcionalidad 20: sincronización con Dropbox

Esta funcionalidad la ha desarrollado [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) en la v6.3.1 como versión preliminar (publicación oficial en la v6.4.0), como la sincronización con Dropbox de overleaf.com. Cuando un usuario vincula su cuenta de Dropbox, cada uno de sus proyectos aparece como una carpeta en su Dropbox: los cambios en Overleaf se envían a Dropbox y los cambios hechos en Dropbox vuelven a Overleaf. Consulta [Sincronización con Dropbox](/es/on-premises/configuration/overleaf-toolkit/integrations/dropbox-synchronisation) para la configuración.

#### Funcionalidad 21: servidor MCP

Esta funcionalidad la ha desarrollado [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) en la v6.3.1. Cada proyecto tiene un servidor MCP, de modo que clientes de IA como Claude Code, Codex, Cursor, VS Code o Gemini CLI pueden leer y editar sus archivos en tiempo real, compilarlo, leer el registro de LaTeX, descargar el PDF y responder a los comentarios. Consulta [Servidor MCP](/es/on-premises/configuration/overleaf-toolkit/integrations/mcp-server) para la configuración.
