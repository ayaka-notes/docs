La API de importación (`/docs` y los botones "Open in Ayakaleaf", el módulo `open-in-overleaf`) se ejecuta en el servicio **web** de cada pod de Ayakaleaf Pro y está activada por defecto. Los archivos indicados mediante URL se descargan a través de linked-url-proxy en el mismo pod. Cómo llamarla se describe en [API de importación de Overleaf](/es/on-premises/configuration/overleaf-toolkit/integrations/overleaf-import-api).

| | |
| --- | --- |
| Servicio | web (módulo `open-in-overleaf`); descargas a través de linked-url-proxy |
| Exterior → Overleaf | los navegadores hacen `GET` o `POST ${OVERLEAF_SITE_URL}/docs` desde cualquier sitio web |
| Pod → exterior | descargas de `snip_uri` y `zip_uri`, limitadas como se describe en [URL externa](/es/on-premises/configuration/kubernetes/external-url) |
| Estado | la petición de un visitante sin sesión iniciada, guardada en Redis durante 10 minutos hasta que inicia sesión |
| Tareas periódicas | ninguna |

### Configuración

No hace falta nada para activarla. Ajustes relacionados en el ConfigMap:

| Ajuste | |
| --- | --- |
| `OVERLEAF_ALLOW_PUBLIC_ACCESS: "true"` | Los visitantes sin sesión iniciada pueden abrir `/devs`, y una petición que envíen se guarda hasta que inicien sesión; consulta [Acceso público](/es/on-premises/configuration/kubernetes/authentication/public-access). |
| `MAX_UPLOAD_SIZE` | El ZIP más grande que puede incluir una petición, en MB (por defecto `50`). Tu ingress o balanceador de carga también debe aceptar cuerpos de petición de ese tamaño. |
| `OVERLEAF_LINKED_URL_*` | A qué direcciones pueden apuntar `snip_uri` y `zip_uri`; consulta [URL externa](/es/on-premises/configuration/kubernetes/external-url). |

### Varias réplicas

No hace falta nada más. La petición de un visitante sin sesión iniciada se guarda en Redis, por lo que se reanuda en la réplica a la que llegue el visitante después de iniciar sesión.

### Probado en Kubernetes

En Kubernetes 1.37 con una réplica, nuestras pruebas de extremo a extremo de la API de importación se superan (14 casos): la página `/devs` y su proyecto de ejemplo, fragmentos, documentos completos, enlaces codificados como URL y archivos de URL de datos convertidos en proyectos, envíos que no pueden convertirse en proyecto rechazados, descargas desde direcciones internas rechazadas, envíos y enlaces sin sesión iniciada conservados a través del inicio de sesión y, con `OVERLEAF_ALLOW_PUBLIC_ACCESS`, `/devs` para visitantes sin sesión iniciada y un fragmento enviado reanudado una vez tras iniciar sesión; el último caso también se supera con tres réplicas detrás de HAProxy.
