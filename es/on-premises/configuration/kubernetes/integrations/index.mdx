icon: puzzle-piece

Cada integración está desactivada por defecto, salvo la API de importación de Overleaf. La sincronización con GitHub, GitLab, Gitea y Dropbox y el servidor MCP también necesitan la [integración con Git](/es/on-premises/configuration/kubernetes/integrations/git-integration). Después de activar una en el ConfigMap o en el Secret, reinicia las réplicas con `kubectl -n overleaf rollout restart`.
