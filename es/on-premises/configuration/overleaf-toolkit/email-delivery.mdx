Overleaf admite el envío de correo electrónico mediante dos métodos: Simple Mail Transfer Protocol (SMTP) y [Amazon Simple Email Service (SES)](https://aws.amazon.com/ses/). Puedes usar SMTP si tienes un servidor de correo habilitado en tu localhost que escuche conexiones locales.

## Configuración

El correo electrónico se configura mediante las siguientes variables de entorno.

#### Configuración del remitente

| Nombre                          | Descripción                                                                                                                                          |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | <p>La dirección del remitente, p. ej. <a href="mailto:support@mycompany.com">`'support@mycompany.com'`</a><br /><br />- <strong>Obligatoria</strong>: sí</p> |
| `OVERLEAF_EMAIL_REPLY_TO`     | La dirección de respuesta, p. ej. `'noreply@mycompany.com'`                                                                                                  |

#### SMTP

| Nombre                                    | Descripción                                                                                                                                                                                                                                                              |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST`              | El nombre de host o la dirección IP a la que conectarse. Debe ser accesible desde el contenedor de Docker                                                                                                                                                                               |
| `OVERLEAF_EMAIL_SMTP_PORT`              | El puerto al que conectarse                                                                                                                                                                                                                                                   |
| `OVERLEAF_EMAIL_SMTP_SECURE`            | Si es `true`, la conexión usará TLS al conectarse al servidor. Si es `false` o no está definida, se usa TLS si el servidor admite la extensión `STARTTLS`. En la mayoría de los casos, establece este valor en `true` si te conectas al puerto `465`. Para los puertos `587` o `25`, mantenlo en `false` |
| `OVERLEAF_EMAIL_SMTP_USER`              | El nombre de usuario que se debe usar para autenticarse en el servidor SMTP                                                                                                                                                                                                 |
| `OVERLEAF_EMAIL_SMTP_PASS`              | La contraseña asociada al nombre de usuario SMTP                                                                                                                                                                                                                           |
| `OVERLEAF_EMAIL_SMTP_TLS_REJECT_UNAUTH` | Si es `false`, permite abrir una conexión con un servidor TLS que tenga un certificado TLS autofirmado o no válido                                                                                                                                                                        |
| `OVERLEAF_EMAIL_SMTP_IGNORE_TLS`        | Cuando es `true` y `OVERLEAF_EMAIL_SMTP_SECURE` es `false`, no se usa TLS aunque el servidor admita la extensión `STARTTLS`                                                                                                                                            |
| `OVERLEAF_EMAIL_SMTP_NAME`              | Nombre de host opcional para la validación TLS si `OVERLEAF_EMAIL_SMTP_HOST` se ha establecido en una dirección IP; de forma predeterminada es el nombre de host de la máquina.                                                                                                                                        |
| `OVERLEAF_EMAIL_SMTP_LOGGER`            | Cuando es `true`, escribe mensajes de registro en `web.log`.                                                                                                                                                                                                                        |

#### Interfaz SMTP de Amazon SES

Puedes obtener más información sobre el uso de la interfaz SMTP de Amazon SES para enviar correo electrónico [aquí](https://docs.aws.amazon.com/ses/latest/dg/send-email-smtp.html).

| Nombre                       | Descripción                                                                                |
| -------------------------- | ------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST` | El nombre de host o la dirección IP a la que conectarse. Debe ser accesible desde el contenedor de Docker |
| `OVERLEAF_EMAIL_SMTP_PORT` | El puerto al que conectarse                                                                     |
| `OVERLEAF_EMAIL_SMTP_USER` | El nombre de usuario que se debe usar para autenticarse en el servidor SMTP                   |
| `OVERLEAF_EMAIL_SMTP_PASS` | La contraseña asociada al nombre de usuario SMTP                                             |

#### API de Amazon SES

Puedes obtener más información sobre el uso de la API de Amazon SES para enviar correo electrónico [aquí](https://docs.aws.amazon.com/ses/latest/dg/send-email-api.html).

| Nombre                                   | Descripción                                 |
| -------------------------------------- | ------------------------------------------- |
| `OVERLEAF_EMAIL_AWS_SES_ACCESS_KEY_ID` | La clave de acceso, si usas AWS SES             |
| `OVERLEAF_EMAIL_AWS_SES_SECRET_KEY`    | La clave secreta, si usas AWS SES             |
| `OVERLEAF_EMAIL_AWS_SES_REGION`        | Si no se define, la región predeterminada es US-EAST-1 |

#### AWS SES con roles de instancia

| Nombre                    | Descripción                                                                                                                      |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_DRIVER` | Cuando se establece en `ses`, el sistema de correo usará el método de la API de SES y se basará en los roles de instancia configurados para enviar correo electrónico. |

#### Personalización

| Nombre                           | Descripción                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_CUSTOM_EMAIL_FOOTER` | <p>HTML personalizado que se añade al final de todos los correos electrónicos, p. ej.<br /><br /><strong>Ejemplo</strong>: `"<div>This system is run by department x </div> <div> If you have any questions please look at our faq <a href='`<a href="https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/https:/somwhere.com'%3Ehere&#x3C;/a%3E&#x3C;/div%3E">`https://somwhere.com'>here&#x3C;/a>&#x3C;/div>`</a>`"`</p> |
