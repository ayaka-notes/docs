Puedes usar el script `bin/logs` para ver los registros de los servicios.

Ejemplos de uso básico:

```bash
# View the web service logs
bin/logs web

# Show help
bin/logs --help

# View logs for multiple services at once
bin/logs filestore docstore web clsi

# Follow log output (like tail -f)
bin/logs -f filestore docstore web clsi

# Limit the number of lines printed (default 50)
bin/logs -n 50 web

# Show all log lines
bin/logs -n all web

# Redirect output to a file
bin/logs -n all web > web.log
```

Puedes usar el script `bin/logs` para ver los registros de los siguientes servicios: `clsi`, `contacts`, `docstore`, `document-updater`, `filestore`, `git-bridge`, `mongo`, `notifications`, `real-time`, `redis`, `spelling`, `tags`, `track-changes`, `web`, `web-api`, `history-v1`, `project-history`.

## Copiar registros

Consulta la documentación original: https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/logging#copying-logs

Copia los archivos de registro del contenedor principal `sharelatex` a tu equipo local:

```bash
docker cp sharelatex:/var/log/overleaf/{service-name}.log {service-name}.log
```

## Conservar los registros

Los contenedores de Docker son efímeros, lo que significa que los archivos y directorios creados dentro del contenedor durante la ejecución (incluidos los archivos de registro) se descartarán si el contenedor se vuelve a crear (por ejemplo, al ejecutar `bin/up`). Para conservar los archivos de registro entre recreaciones del contenedor:

* Establece la variable de entorno `OVERLEAF_LOG_PATH` en el archivo `config/overleaf.rc` que usa el Toolkit. Debe ser el directorio del host que se montará (bind-mount) en el directorio de registros dentro del contenedor `sharelatex`.
* Tras cambiar esto y ejecutar `bin/up -d`, los archivos de registro se conservarán en el host y serán accesibles directamente.

<Warning>

Debes asignar como propietario del directorio de registros del host usado para el bind-mount al usuario `www-data` (uid=33) y asegurarte de que los permisos sean `drwxr-xr-x` (755).

Ejemplo:

```bash
chown 33:33 data/overleaf/logs
chmod 755 data/overleaf/logs
```

</Warning>
