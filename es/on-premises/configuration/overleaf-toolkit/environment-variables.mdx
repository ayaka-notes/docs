Esta página describe las variables de entorno admitidas en el archivo `config/variables.env` para los despliegues con el Toolkit.

El archivo `config/variables.env` consta de definiciones de variables con el formato `NAME=value`; las líneas que empiezan por `#` se tratan como comentarios.

<Info>

Es necesario volver a crear los contenedores de Docker después de cambiar cualquier cosa en `overleaf.rc` o `variables.env`, ejecutando `bin/up`.

</Info>

### Todas las versiones

Estas variables de entorno son compatibles con Server CE y Server Pro y ofrecen una vía de migración sencilla entre estas dos versiones locales. También pueden usarse tanto en despliegues con el Toolkit como con Docker Compose.

<Info>

Anteriormente, estas variables de entorno tenían el prefijo `SHARELATEX_` en lugar de `OVERLEAF_`.

</Info>

| `OVERLEAF_TRUSTED_PROXY_IPS`                                           | <p>Si no se define, el valor predeterminado es `loopback`. Si la configuras manualmente, además de tus IP de confianza debes incluir `loopback` (o `127.0.0.1`), que confía en la instancia de nginx que se ejecuta dentro del contenedor <strong>sharelatex</strong>. Solo se aceptan direcciones IP y rangos CIDR: no añadas nombres de host como `localhost`; de lo contrario, Overleaf no se iniciará y devolverá `502 Bad Gateway`.<br /><br />Si utilizas una subred de `172.16.0.0/12` (la subred predeterminada de las redes de Docker) para tu red habitual, establece `OVERLEAF_TRUSTED_PROXY_IPS=loopback,<network>` en tu `config/variables.env`, donde `<network>` es el valor de `IPAM -> Config -> Subnet` en `docker inspect overleaf_default`, p. ej., `OVERLEAF_TRUSTED_PROXY_IPS=loopback,172.19.0.0/16`. Ten en cuenta que establecer esta opción no desactiva en modo alguno la autenticación ni la seguridad. Esta opción es necesaria si tus usuarios pretenden hacer públicos sus proyectos y que usuarios no autenticados puedan verlos.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING`                      | Si se establece en `true`, permite que los usuarios anónimos vean y editen proyectos compartidos mediante la función de [uso compartido por enlace](https://www.overleaf.com/blog/integration-update-link-sharing-2017-11-27).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `OVERLEAF_DISABLE_LINK_SHARING`                                        | Desactiva la función de [uso compartido por enlace](https://www.overleaf.com/blog/integration-update-link-sharing-2017-11-27).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `EMAIL_CONFIRMATION_DISABLED`                                          | Si se establece en `true`, no se mostrará el banner que solicita la confirmación del correo electrónico.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |

<Info>

Es posible aplicar restricciones de contraseña a los usuarios cuando se utiliza el sistema de inicio de sesión de Overleaf (cuentas locales), no una opción de SSO como LDAP. En las cuentas SSO, las políticas de contraseñas las aplicará tu proveedor de identidad o servicio de directorio, lo que además permite la autenticación multifactor.

</Info>
