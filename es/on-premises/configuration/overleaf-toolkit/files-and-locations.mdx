Esta página describe los archivos de configuración que utiliza el Toolkit para configurar tu despliegue local de Overleaf.

### Datos persistentes

El Overleaf Toolkit necesita almacenar datos persistentes, como los archivos necesarios para compilar proyectos LaTeX y el contenido de la base de datos MongoDB. Para ello, se montan algunos directorios de la máquina anfitriona en los contenedores Docker y se escriben los datos en esos directorios.

#### Directorios de datos

El contenedor `sharelatex` necesita un directorio en el que almacenar los datos relacionados con las compilaciones de LaTeX. Este directorio se configura con la variable `OVERLEAF_DATA_PATH` en `config/overleaf.rc`.

El contenedor `mongo`, si está habilitado, necesita un directorio en el que almacenar sus archivos de base de datos, y lo mismo ocurre con el contenedor `redis`. Estos directorios también se pueden configurar en `config/overleaf.rc`.

#### Permisos de archivos

Como Docker se ejecuta como `root`, los directorios de datos acabarán siendo propiedad del usuario `root`, aunque el Toolkit lo utilice un usuario que no sea root. Esto no es un problema, pero conviene tenerlo en cuenta si piensas modificar los datos persistentes desde fuera de los contenedores.

### Ubicación de los archivos de configuración

Todos los archivos de configuración propiedad del usuario se encuentran en el directorio `config/`.

Este directorio está **excluido** del sistema de control de versiones git, por lo que no se modificará al actualizar el código del Toolkit. El Toolkit **no** modificará ningún dato del directorio `config/` sin tu permiso.

<Info>

Los cambios en los archivos de configuración no se aplicarán automáticamente a los contenedores existentes, aunque el contenedor se detenga y se reinicie (con `bin/stop` y `bin/start`). Para aplicar los cambios, ejecuta `bin/up` y, en segundo plano, `docker compose` aplicará automáticamente los cambios de configuración a un nuevo contenedor. (O ejecuta `bin/up -d` si prefieres no adjuntarte a los logs de Docker).

</Info>

### El archivo `overleaf.rc`

El archivo `config/overleaf.rc` contiene los ajustes de configuración de nivel superior más importantes que utiliza el Toolkit. Contiene instrucciones que asignan variables con el formato: `VARIABLE_NAME=value`

Para ver un desglose de todas las opciones de configuración disponibles, consulta nuestra sección de ajustes.

### El archivo `variables.env`

El archivo `config/variables.env` contiene variables de entorno que se cargan en el contenedor `sharelatex` y se usan para configurar los microservicios de Overleaf. Entre ellas se incluyen el nombre de la aplicación, tal como se muestra en el encabezado de la interfaz web, los ajustes para el envío de correos electrónicos y otros ajustes premium, como el SSO para usar con Server Pro.

Para ver un desglose de todas las variables de entorno disponibles, consulta la sección [Variables de entorno](/es/on-premises/configuration/overleaf-toolkit/environment-variables).

### El archivo `version`

El archivo `config/version` contiene el número de versión de la imagen Docker que se usará para crear la instancia en ejecución de tu servidor Overleaf.

<Info>

Los cambios en estos archivos de configuración no se aplicarán automáticamente a los contenedores existentes, aunque el contenedor se detenga y se reinicie (con `bin/stop` y `bin/start`). Para aplicar los cambios, ejecuta `bin/up` y el Toolkit creará automáticamente un nuevo contenedor con los cambios de configuración aplicados.

</Info>

### El archivo `docker-compose.override.yml`

Si existe, el archivo `config/docker-compose.override.yml` se incluirá en la invocación de `docker compose`. Esto es útil para sobrescribir la configuración específica de Docker Compose.

Consulta la [documentación de docker-compose](https://docs.docker.com/compose/extends/#adding-and-overriding-configuration) para obtener más detalles.
