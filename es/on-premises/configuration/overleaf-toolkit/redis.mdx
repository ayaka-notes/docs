### Habilitar la autenticación por contraseña

Si usas un servicio de Redis externo y necesitas proporcionar una contraseña, puedes hacerlo estableciendo las variables de entorno `OVERLEAF_REDIS_PASS` y `REDIS_PASSWORD` en el archivo **config/variables.env** y ejecutando el comando `bin/up -d` para recrear el contenedor **sharelatex**.

Si ejecutas una instancia local de Redis, tendrás que configurar el servicio **redis** para que se inicie con autenticación por contraseña. Después de establecer las variables de entorno anteriores, también tendrás que completar estos pasos adicionales:

Crea un archivo **docker-compose.override.yml** en el directorio **config/** con el siguiente contenido:

```yaml title="config/docker-compose.override.yml"
services:
    redis:
        command: "redis-server --requirepass <YOUR-PASSWORD>"
```

<Warning>

Si tienes habilitada la persistencia AOF, tendrás que añadir `--appendonly yes` al `command`.

</Warning>

Ejecuta `bin/up -d` para recrear los contenedores.

### Habilitar la persistencia Append-Only File

(Original: https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/redis#enabling-append-only-file-persistence)

La persistencia AOF (Append-Only File) de Redis ofrece una forma robusta de garantizar la durabilidad de los datos registrando cada operación de escritura recibida por el servidor. A diferencia de las instantáneas RDB, que toman copias de tu conjunto de datos en un momento determinado, AOF mantiene un registro completo de todos los cambios realizados en tus datos.

<Info>

Deshabilitar RDB es opcional. Por lo general, se recomienda usar ambos métodos de persistencia a la vez. Antes de hacer cambios en producción, revisa las ventajas y desventajas de ejecutar AOF y RDB juntos.

</Info>

Puedes leer más sobre cómo habilitar la persistencia AOF en Redis aquí: [https://redis.io/docs/latest/operate/oss\_and\_stack/management/persistence/#how-i-can-switch-to-aof-if-im-currently-using-dumprdb-snapshotsarrow-up-right](https://redis.io/docs/latest/operate/oss_and_stack/management/persistence/#how-i-can-switch-to-aof-if-im-currently-using-dumprdb-snapshotsarrow-up-right)

1. Programa una ventana de mantenimiento para la actualización.
2. Detén la instancia con `bin/stop` y haz una copia de seguridad de las carpetas **config/** y **data/**.
3. Ejecuta `bin/up` para iniciar la instancia
4. Ejecuta el comando `docker exec -it redis sh`
5. Ejecuta el comando `redis-cli` para abrir la interfaz de línea de comandos de Redis
6. En redis-cli, ejecuta el comando `config set appendonly yes`
7. Ahora tendrás que esperar a que la reescritura AOF termine de persistir los datos. Para ello, escribe `INFO persistence` en redis-cli y espera a que `aof_rewrite_in_progress` y `aof_rewrite_scheduled` sean `0`, y verifica que `aof_last_bgrewrite_status` sea `ok`.
8. Sal de redis-cli escribiendo `exit` y pulsando la tecla Intro
9. Sal del contenedor de redis escribiendo `exit` y pulsando la tecla Intro
10. Ejecuta el comando `ls ./data/redis` y confirma que puedes ver el archivo **appendonly.aof**
11. Edita el archivo **config/overleaf.rc** y cambia la variable de entorno `REDIS_AOF_PERSISTENCE` de `false` a `true`
12. Ejecuta `bin/up -d` y asegúrate de que la aplicación funciona (el editor de proyectos y el panel de historial funcionan correctamente).
