<Info>

Esta funcionalidad la proporciona [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/overleaf-pro) con compatibilidad con OAuth 2.0 y está disponible a partir de la v6.3.0. Agradecemos tus comentarios si encuentras algún problema.

</Info>

#### Configurar la integración con Mendeley

1. Ve a [este enlace](https://dev.mendeley.com/myapps.html) para registrar una aplicación OAuth de Mendeley
2. Configura la **Redirect URL** como: `${OVERLEAF_SITE_URL}/user/mendeley/oauth/callback`
3. Anota el **ID** generado (normalmente numérico, como `24061` en el ejemplo) y el **Secret** de tu aplicación
4. Modifica tu `config/variables.env`&#x20;
5. Mantén el flujo de autorización Elsevier (recomendado)

<Frame>
  <img src="/images/on-premises/image-44.png" alt="" />
</Frame>

```dotenv title="config/variables.env"
#################
#   Mendeley    #
#################
# 'mendeley' must be in ENABLED_LINKED_FILE_TYPES (keep 'zotero' too if you use both)
ENABLED_LINKED_FILE_TYPES=project_file,project_output_file,url,mendeley

# From a Mendeley OAuth application (register at https://dev.mendeley.com/myapps.html)
# Redirect URL -> ${OVERLEAF_SITE_URL}/user/mendeley/oauth/callback
MENDELEY_CLIENT_ID=
MENDELEY_CLIENT_SECRET=
# Encrypts the Mendeley OAuth tokens in mongo; if unset, a key file is generated
# in /var/lib/overleaf/data on first use
# How to generate: `openssl rand -hex 32`
MENDELEY_CIPHER_PASSWORD=
# Optional: route the module's server-side Mendeley requests (OAuth + API) through
# an HTTP proxy (must be reachable from the web container; same as github-sync)
# http://10.0.0.1:10808
# (Optional) MENDELEY_PROXY_URL=
```

<Info>

&#x20;`mendeley` debe estar incluido en `ENABLED_LINKED_FILE_TYPES` (mantén también `zotero` en la lista si usas ambos). `MENDELEY_CLIENT_ID` y `MENDELEY_CLIENT_SECRET` proceden de la aplicación OAuth que has registrado. La contraseña de cifrado cifra los tokens OAuth de Mendeley en MongoDB (genera una con `openssl rand -hex 32`); si no se define, se genera un archivo de clave en el volumen de datos la primera vez que se usa. Opcionalmente, define `MENDELEY_PROXY_URL` para enrutar las solicitudes a Mendeley del lado del servidor (OAuth + API) a través de un proxy HTTP accesible desde el contenedor web.

</Info>

### Notas

<Warning>

Al actualizar a la versión 6.3.0 republicada una instalación existente que tenga archivos de bibliografía vinculados a Mendeley, sigue las [instrucciones de migración de Zotero / Mendeley](/es/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention"). Las instalaciones nuevas no necesitan esta migración.

</Warning>

<Danger>

Dado que Ayakaleaf es una plataforma colaborativa, para mejorar la seguridad, a partir de la versión 6.3.0 solo el creador original de un archivo de referencias `bib` podrá actualizar el archivo importado.

</Danger>

Por ejemplo, supongamos que el propietario del proyecto, el usuario A, habilita el uso compartido mediante enlace y crea un archivo `test.bib` en el proyecto, vinculado a su propia cuenta de Zotero. Si otro usuario, el usuario B, accede al proyecto a través del enlace compartido, podrá seguir leyendo y descargando `test.bib`, pero no podrá actualizar ni volver a importar el archivo desde Zotero. Solo el usuario A, como creador original del archivo de referencias, puede realizar actualizaciones. Es decir, solo el creador original del archivo `.bib` tiene permiso para actualizarlo.
