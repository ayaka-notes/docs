---
title: Restricciones de contraseña
icon: key
---

Es posible aplicar restricciones de contraseña a las cuentas de usuario cuando se utiliza el sistema de inicio de sesión nativo de Overleaf para la autenticación.

<Info>

**No** es posible aplicar restricciones de contraseña a los inicios de sesión SSO (LDAP/SAML 2.0). Estas deben configurarse en su proveedor de identidad (IdP).

</Info>

Para habilitar las restricciones de contraseña, defina las variables de entorno correspondientes en el archivo `config/variables.env` del Toolkit.

| Nombre                                    | Descripción | Valor predeterminado |
| ----------------------------------------- | ----------- | -------------------: |
| `OVERLEAF_PASSWORD_VALIDATION_MIN_LENGTH` | La longitud **mínima** requerida. | `8` |
| `OVERLEAF_PASSWORD_VALIDATION_MAX_LENGTH` | La longitud **máxima** permitida. | `72` |
| `OVERLEAF_PASSWORD_VALIDATION_PATTERN`    | <p>Se utiliza para validar la <strong>robustez</strong> de la contraseña:</p><ul><li>`abc123`: la contraseña debe contener 3 letras y 3 números y tener al menos 6 caracteres</li><li>`aA`: la contraseña debe contener letras minúsculas y mayúsculas y tener 2 caracteres</li><li>`ab$3`: debe contener letras, dígitos y símbolos y tener 4 caracteres</li><li>Hay 4 grupos de caracteres: letras, letras MAYÚSCULAS, dígitos y símbolos. Todo lo que no sea una letra ni un dígito se considera un símbolo.</li></ul> | — |
