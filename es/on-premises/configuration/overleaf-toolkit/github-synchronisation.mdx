### Configurar la sincronización con GitHub

<Warning>

Debe habilitar [git-bridge](/es/on-premises/configuration/overleaf-toolkit/git-integration) antes de utilizar la sincronización con GitHub.

```dotenv title="config/overleaf.rc"
GIT_BRIDGE_ENABLED=true
```

</Warning>

Visite la [configuración de desarrollador](https://github.com/settings/developers) para crear su aplicación OAuth de GitHub y copie su `CLIENT_ID` y su `SECRET`.

**Nota**: su URL de callback de OAuth es: `${OVERLEAF_SITE_URL}/user/github-sync/oauth2/callback`.

A continuación, añada la siguiente configuración a sus archivos de variables de entorno de Overleaf.

```dotenv title="config/variables.env" wrap
# used to encrypt the user's GitHub access token.
# How to generate: `openssl rand -hex 32`
GITHUB_TOKEN_CIPHER_PASSWORD=0123456789ABCDEFG # changed to yours

# Github Sync Settings
GITHUB_SYNC_ENABLED=true
GITHUB_SYNC_CLIENT_ID=
GITHUB_SYNC_CLIENT_SECRET=

# OAuth callback is: ${OVERLEAF_SITE_URL}/user/github-sync/oauth2/callback
# (Optional) GITHUB_SYNC_PROXY_URL=http://10.0.0.1:10808
```

<Warning>

Antes de configurar la URL de callback de OAuth de GitHub, asegúrese de que `OVERLEAF_SITE_URL` esté configurada correctamente.

</Warning>

Si se encuentra en China continental, es posible que necesite configurar un proxy para acceder a GitHub. Defina la siguiente variable de entorno: `GITHUB_SYNC_PROXY_URL=http://10.0.0.1:10808`.

<Warning>

No utilice `127.0.0.1` como host del proxy. Si el proxy se ejecuta en el servidor host, utilice la dirección IP de la LAN del servidor (por ejemplo, `192.168.1.xx`) y asegúrese de que el proxy esté configurado para aceptar conexiones de los dispositivos de la red local.

</Warning>
