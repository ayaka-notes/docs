Todas las integraciones están desactivadas de forma predeterminada, excepto la API de importación de Overleaf. La sincronización con GitHub, GitLab, Gitea y Dropbox, así como el servidor MCP, también requieren la [integración con Git](/es/on-premises/configuration/overleaf-toolkit/integrations/git-integration). Después de activar una, vuelve a crear los contenedores con `bin/up -d`.
