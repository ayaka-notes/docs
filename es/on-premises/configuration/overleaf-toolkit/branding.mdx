### Encabezado

En esta sección veremos cómo personalizar los elementos clave de tu instancia on-premises. Puedes personalizar el título del sitio, los enlaces de navegación, el encabezado, el pie de página y el logotipo según tus preferencias.

### Título del sitio

El título de la barra de navegación se puede personalizar con la variable de entorno `OVERLEAF_NAV_TITLE`; este texto se usa en la esquina superior izquierda de la navegación si no se ha definido ningún logotipo.

```bash
# add to config/variables.env
OVERLEAF_NAV_TITLE=Our Overleaf Instance
```

## Logotipo

Puedes añadir un logotipo personalizado en lugar de usar texto definiendo la variable de entorno `OVERLEAF_HEADER_IMAGE_URL`. Este valor debe apuntar a un archivo de imagen alojado externamente.

```bash title="config/variables.env"
# add to config/variables.env
OVERLEAF_HEADER_IMAGE_URL=https://mysite.somewhere.com/img/logo.png
```

#### Logotipos para los temas claro y oscuro

A partir de la versión 6.3.0, puedes definir logotipos distintos para los temas claro y oscuro con las variables de entorno `OVERLEAF_HEADER_IMAGE_URL_LIGHT` y `OVERLEAF_HEADER_IMAGE_URL_DARK`. Ambos valores deben apuntar a un archivo de imagen alojado externamente.

```text
# add to config/variables.env
OVERLEAF_HEADER_IMAGE_URL_LIGHT=https://mysite.somewhere.com/img/logo-light.png
OVERLEAF_HEADER_IMAGE_URL_DARK=https://mysite.somewhere.com/img/logo-dark.png
```

<Info>

Si alguna de las variables no está definida, ese tema usará como alternativa el logotipo definido en `OVERLEAF_HEADER_IMAGE_URL`.

</Info>

## Enlaces de navegación del encabezado

Se pueden añadir elementos de navegación adicionales al encabezado definiendo la variable de entorno `OVERLEAF_HEADER_EXTRAS` como un array JSON de objetos. Por ejemplo:

```json wrap
[\
  {\
    "text": "Some link",\
    "url": "http://example.com/somelink",\
    "class": "subdued",\
    "only_when_logged_out": true\
  },\
  {\
    "text": "Help",\
    "class": "subdued",\
    "dropdown": [\
      {\
        "text": "Documentation",\
        "url": "/learn"\
      },\
      {\
        "text": "Contact Admin",\
        "url": "http://example.com/contact"\
      }\
    ]\
  }\
]
```

Añade la forma JSON escapada a toolkit/variables.env:

```bash title="toolkit/variables.env" wrap
# add to toolkit/variables.env
OVERLEAF_HEADER_EXTRAS=[{"text":"Some link","url":"http://example.com/somelink","class":"subdued","only_when_logged_out":true},{"text":"Help","class":"subdued","dropdown":[{"text":"Documentation","url":"/learn"},{"text":"Contact Admin","url":"http://example.com/contact"}]}]
```

## Pies de página

Es posible personalizar tanto el pie de página izquierdo como el derecho, más pequeño (presente en páginas como `/project`), usando las variables de entorno `OVERLEAF_LEFT_FOOTER` y `OVERLEAF_RIGHT_FOOTER`. Ambas esperan un array de objetos JSON que se insertarán.

Ambas esperan un array JSON que se insertará.

```json
[\
  {\
    "text": "This is an example text footer entry!"\
  },\
  {\
    "text": "This is an example URL footer link!", "url" : "/my-first-link.htm"\
  }\
]
```

<Info>

Cuando solo se usa `text`, no debe contener HTML, ya que el valor se mostrará como texto sin formato.

</Info>

Estos datos deben ser JSON válido para funcionar, con las comillas escapadas cuando se pasan como variable de entorno.

```bash title="config/variables.env" wrap
# add to config/variables.env
OVERLEAF_LEFT_FOOTER=[{"text": "This is an example text footer entry!"}]
OVERLEAF_RIGHT_FOOTER=["text": "This is an example URL footer link!", "url" : "/my-first-link.htm"]
```

<Info>

Además de `text` y `url`, el objeto JSON también acepta las propiedades `class` y `label` para una personalización adicional.

</Info>

### Página de mantenimiento

Puedes personalizar el mensaje que se muestra en la página de mantenimiento con la variable de entorno `OVERLEAF_MAINTENANCE_MESSAGE`; este texto sustituye al mensaje predeterminado que aparece bajo el título de la página.

```text wrap
# add to config/variables.env
OVERLEAF_MAINTENANCE_MESSAGE=Our Overleaf Instance is down for maintenance and will be back shortly.
```

Para incluir enlaces u otro formato, usa en su lugar `OVERLEAF_MAINTENANCE_MESSAGE_HTML`. Si ambas están definidas, `OVERLEAF_MAINTENANCE_MESSAGE_HTML` tiene prioridad.

```text wrap
# add to config/variables.env
OVERLEAF_MAINTENANCE_MESSAGE_HTML=Our Overleaf Instance is down for maintenance. For urgent requests, contact <a href="mailto:admin@example.com">admin@example.com</a>.
```

<Info>

`OVERLEAF_MAINTENANCE_MESSAGE` se muestra como texto sin formato, por lo que **no** debe contener HTML. `OVERLEAF_MAINTENANCE_MESSAGE_HTML` se muestra como HTML sin escapar.

</Info>

Si ninguna de las dos está definida, el mensaje predeterminado enlaza a tu página de estado cuando `OVERLEAF_STATUS_PAGE_URL` está definida, y muestra la dirección de correo del administrador cuando no lo está.
