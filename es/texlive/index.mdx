[TeX Live](https://www.tug.org/texlive/) es una distribución de software libre publicada anualmente por el [TeX Users Group](https://www.tug.org/). Proporciona los paquetes de LaTeX, las fuentes, los motores de TeX y numerosas herramientas de software necesarias para la composición tipográfica basada en LaTeX en todos los sistemas operativos habituales.

TeX Live es un componente importante de Overleaf porque nuestros servidores lo utilizan para compilar tu código LaTeX y generar la vista previa del PDF en tiempo real. Además, ofrece a los usuarios de Overleaf un acceso sencillo a más de 5000 paquetes de LaTeX incluidos en cada versión de TeX Live.

No estás limitado a usar la última versión de TeX Live para compilar tus proyectos, ya que los servidores de Overleaf dan acceso a versiones anteriores de TeX Live. Los proyectos pueden cambiarse fácilmente para usar una versión anterior de TeX Live, por ejemplo, debido a problemas de compatibilidad de paquetes.<br />
