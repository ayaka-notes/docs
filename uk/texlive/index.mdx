[TeX Live](https://www.tug.org/texlive/) — це вільний дистрибутив програмного забезпечення, який щороку випускає [TeX Users Group](https://www.tug.org/). Він містить пакети LaTeX, шрифти, рушії TeX і численні програмні інструменти, необхідні для верстки на основі LaTeX у всіх поширених операційних системах.

TeX Live — важливий компонент Overleaf, адже наші сервери використовують його для компіляції вашого коду LaTeX і створення PDF-попереднього перегляду в реальному часі. Він також надає користувачам Overleaf зручний доступ до понад 5000 пакетів LaTeX, що входять до кожного випуску TeX Live.

Ви не обмежені найновішою версією TeX Live для компіляції своїх проєктів, оскільки сервери Overleaf надають доступ і до попередніх випусків TeX Live. Проєкти можна легко перевести на використання ранішої версії TeX Live — наприклад, через проблеми із сумісністю пакетів.<br />
