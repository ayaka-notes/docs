### Doctor

Overleaf Toolkit постачається зі зручним скриптом `doctor`, що допомагає в налагодженні. Запустіть `bin/doctor`, і скрипт виведе інформацію про ваше хост-середовище, вашу конфігурацію та залежності, потрібні Toolkit. Цей вивід також може допомогти нам діагностувати проблеми з вашими інсталяціями Ayakaleaf Pro.

<Info>

Користувачі Overleaf Pro можуть [створити issue на GitHub](https://github.com/ayaka-notes/overleaf/issues).

Варто додати до свого повідомлення вивід скрипта `bin/doctor`.

</Info>

### Консультація з Doctor

Запустіть скрипт doctor:

```bash title="Run doctor"
bin/doctor
```

Ви побачите вивід, подібний до наведеного нижче прикладу.

### Інформація про хост

Розділ `Host Information` містить відомості про машину, на якій працює Toolkit (наприклад, дистрибутив і випуск Linux).

<Accordion title="Приклад виводу Host Information">

```text
- Host Information
    - Linux
    - Output of 'lsb_release -a':
            No LSB modules are available.
            Distributor ID:	Ubuntu
            Description:	Ubuntu 22.04.5 LTS
            Release:	22.04
            Codename:	jammy
```

</Accordion>

### Залежності

Розділ `Dependencies` містить перелік інструментів, необхідних для роботи Toolkit. Якщо інструмент наявний, його буде позначено як `status: present` з інформацією про версію. Якщо він відсутній, його буде позначено як `status: MISSING!`, а внизу виводу `doctor` з'явиться попередження.

<Accordion title="Приклад виводу Dependency (наявний)">

```text
- docker
    - status: present
    - version info: Docker version 28.0.4, build b8034c0
```

</Accordion>

<Accordion title="Приклад виводу Dependency (відсутній)">

```text
- docker
    - status: MISSING!
```

</Accordion>

Якщо якихось залежностей бракує, Toolkit майже напевно не працюватиме.

### Конфігурація

Розділ `Configuration` містить відомості про файли в каталозі `config/`. Для `config/overleaf.rc` doctor виводить деякі ключові значення. Відсутні файли буде позначено як `status: MISSING!`, а внизу виводу `doctor` з'явиться попередження.

<Accordion title="Приклад виводу Configuration">

```text
====== Configuration ======
- config/version
    - status: present
    - version: 5.4.0
- config/overleaf.rc
    - status: present
    - values
        - OVERLEAF_DATA_PATH: /tmp/overleaf
        - SERVER_PRO: false
        - MONGO_ENABLED: false
        - REDIS_ENABLED: true
- config/variables.env
    - status: MISSING!
```

</Accordion>

Примітки до наведеного прикладу:

* `OVERLEAF_DATA_PATH`, встановлений у `/tmp/overleaf`, може бути небезпечним розташуванням для важливих даних.
* `MONGO_ENABLED: false` означає, що Toolkit не розгортатиме власну MongoDB; за потреби переконайтеся, що `MONGO_URL` вказує на зовнішньо керовану MongoDB.
* У прикладі відсутній `config/variables.env`.

### Попередження

Розділ `Warnings` підсумовує проблеми, виявлені скриптом doctor. Якщо проблем немає, цей розділ про це повідомить.

<Accordion title="Приклад виводу Warnings">

```text
====== Warnings ======
- configuration file variables.env not found
- rc file, OVERLEAF_DATA_PATH not set
====== End =======
```

</Accordion>
