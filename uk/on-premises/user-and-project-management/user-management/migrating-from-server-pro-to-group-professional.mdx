title: Перехід із Server Pro на Group Professional
icon: rectangle-pro
noindex: true
---

Перехід із самостійно розміщеного екземпляра Server Pro на нову хмарну підписку Overleaf Group Professional — це значна зміна, тому, щоб зробити цей процес якомога плавнішим, ми підготували наведені нижче рекомендації.

Загалом ми пропонуємо тримісячний перехідний період, що починається з дати поновлення. Це означає, що:

* Ваш наявний екземпляр Server Pro і нова підписка Group Professional будуть повністю активні одночасно.
* Ваша технічна команда зможе запланувати час для налаштування підписки Group Professional і вирішити майбутнє вашого локального розгортання Server Pro.
* Найважливіше — ваші користувачі матимуть достатньо часу, щоб скопіювати свої проєкти на нову платформу Overleaf Group Professional.

Цей короткий посібник проведе вас через ключові кроки міграції. Почнімо!

<Steps>
<Step title="Етап 1: Налаштування та конфігурація">
(Посилання: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-1-setup-and-configuration)

* Overleaf створить вашу підписку Group Professional і додасть вашого головного адміністратора.
* Адміністратор вашої групи зможе ввімкнути [Managed Usersarrow-up-right](https://docs.overleaf.com/groups/user-management/managed-user-accounts), налаштувати [єдиний вхід (SSO)arrow-up-right](https://docs.overleaf.com/groups/overleaf-group-single-sign-on/setting-up-group-sso) та [запросити кінцевих користувачівarrow-up-right](https://docs.overleaf.com/groups/user-management/how-to-add-and-remove-users).

<Warning>

Увімкнення Managed Users і впровадження SSO є обов'язковим кроком для відповідності FedRAMP® LI-SaaS. Якщо вашій організації потрібна відповідність FedRAMP, налаштуйте Managed Users і SSO до того, як запрошувати кінцевих користувачів.

</Warning>
</Step>

<Step title="Етап 2: Міграція користувачів і керування даними">
(Посилання: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-2-user-migration-and-data-management)

Це основний період міграції з такими обов'язками:

#### Кінцеві користувачі

* Користувачі мають перенести всі проєкти, які хочуть зберегти, з вашого екземпляра Server Pro до своїх нових облікових записів на [overleaf.comarrow-up-right](http://overleaf.com/). Процес полягає в [експорті проєктівarrow-up-right](https://www.overleaf.com/learn/how-to/Exporting_your_work_from_Overleaf) із Server Pro та їх [завантаженніarrow-up-right](https://www.overleaf.com/learn/how-to/Uploading_a_project) до свого облікового запису на [overleaf.comarrow-up-right](http://overleaf.com/). Якщо користувач ще не має облікового запису [overleaf.comarrow-up-right](http://overleaf.com/), він може зареєструватися на [overleaf.com/registerarrow-up-right](http://overleaf.com/register).

<Warning>

Під час цієї процедури експорту буде перенесено лише вихідний код проєкту (LaTeX і двійкові файли). Наявні налаштування проєкту, налаштування спільного доступу, коментарі, відстежувані зміни тощо НЕ буде перенесено. Після міграції користувачам потрібно буде повторно запросити своїх співавторів.

</Warning>

#### Технічний персонал

* На цьому етапі ваша технічна команда має спланувати, що робити з локальним екземпляром Server Pro та його даними після міграції.
* <strong>Резервне копіювання даних:</strong> перед виведенням з експлуатації можна експортувати всі проєкти, щоб створити архів, який дозволить допомогти користувачам, які могли забути перенести або завантажити свою роботу. Інструкції: https://docs.overleaf.com/on-premises/maintenance/data-and-backups/exporting-projects
* <strong>Виведення Server Pro з експлуатації:</strong> після завершення періоду міграції та вимкнення вашого ліцензійного ключа у вас є два основні варіанти щодо самого екземпляра Server Pro (див. наступний крок).
</Step>

<Step title="Варіанти виведення Server Pro з експлуатації">
<Steps>
<Step title="Повністю видалити Server Pro">
Видалення виведе Server Pro з експлуатації та повністю вилучить програмне забезпечення.
</Step>

<Step title="Перейти на Community Edition">
Перехід зберігає базу даних користувачів і проєктів із повною історією проєктів шляхом перетворення екземпляра з Server Pro на Community Edition.
</Step>
</Steps>

<Info>

Community Edition НЕ містить [Sandboxed Compilesarrow-up-right](https://docs.overleaf.com/on-premises#overview-of-server-pro-and-community-edition), а також [LDAP](/uk/on-premises/configuration/overleaf-toolkit/authentication/ldap-authentication)/[SAML](/uk/on-premises/configuration/overleaf-toolkit/authentication/saml-authentication). Якщо вам потрібно повернутися до вбудованої автентифікації (ім'я користувача/пароль), див.: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-to-ldap-or-saml#going-the-other-way-switching-from-ldap-saml-back-to-native-authentication

Порівняння Server CE і Server Pro див.: https://docs.overleaf.com/on-premises/welcome/server-pro-vs.-community-edition

</Info>
</Step>

<Step title="Етап 3: Виведення Server Pro з експлуатації">
(Посилання: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-3-server-pro-decommission)

* Команда Overleaf офіційно деактивує ваш ліцензійний ключ Server Pro і надішле підтвердження після завершення.
* Після цього виконайте одну з описаних вище дій із виведення з експлуатації: повністю видаліть Server Pro або перейдіть на Community Edition.
</Step>
</Steps>

Додаткові ресурси та посилання, згадані вище, залишаються без змін.
