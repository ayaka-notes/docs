Під'єднайте проєкт до репозиторію GitHub. Зміни передаються в обидва боки і лише тоді, коли ви натискаєте **Sync**: нічого не синхронізується саме собою.

<Info>

Якщо ви не бачите параметра GitHub в **Account settings** або в редакторі, попросіть адміністратора увімкнути [синхронізацію з GitHub](/uk/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation).

</Info>

## Прив'язка облікового запису GitHub {#link-your-github-account}

Це робиться один раз.

<Steps>
<Step title="Відкрийте налаштування облікового запису">
Натисніть **Account**, потім **Account settings**. Прокрутіть до **GitHub** і натисніть **Link**.

<Frame caption="GitHub у налаштуваннях облікового запису">
  <img src="/images/on-premises/github-sync-link.png" alt="Розділ GitHub у налаштуваннях облікового запису з кнопкою Link" />
</Frame>
</Step>

<Step title="Авторизуйтеся на GitHub">
Відкриється GitHub. Увійдіть, якщо буде потрібно, потім авторизуйте застосунок.
</Step>

<Step title="Перевірте прив'язку">
Ви повернетеся до налаштувань облікового запису, а на кнопці тепер написано **Unlink**.

<Frame caption="Ваш обліковий запис GitHub прив'язано">
  <img src="/images/on-premises/github-sync-linked.png" alt="Розділ GitHub у налаштуваннях облікового запису з кнопкою Unlink" />
</Frame>
</Step>
</Steps>

Якщо ваш обліковий запис ще не прив'язано, **Import from GitHub** і картка **GitHub** у редакторі спершу попросять його прив'язати. Натисніть **Link to your GitHub account**. Ви також опинитеся в налаштуваннях облікового запису, у новій вкладці, якщо почали в редакторі. Потім поверніться й почніть знову.

<Frame caption="Підказка, якщо обліковий запис не прив'язано">
  <img src="/images/on-premises/github-sync-link-prompt.png" alt="Діалогове вікно Import from GitHub з кнопкою Link to your GitHub account" />
</Frame>

## Імпорт репозиторію {#import-a-repository}

Так створюється новий проєкт із репозиторію GitHub, уже прив'язаний до нього.

<Steps>
<Step title="Відкрийте діалог імпорту">
На сторінці проєктів натисніть **New project**, потім **Import from GitHub**.

<Frame caption="Меню New project">
  <img src="/images/on-premises/github-sync-new-project-menu.png" alt="Меню New project з пунктом Import from GitHub" />
</Frame>

<Info>

**New project** з'являється, коли у вас є хоча б один проєкт. У меню **Create a new project** на сторінці привітання немає імпорту, тож спершу створіть порожній проєкт.

</Info>
</Step>

<Step title="Виберіть репозиторій">
Натисніть **Import to Overleaf** поруч із репозиторієм. У списку є ваші репозиторії та репозиторії ваших організацій.

<Frame caption="Ваші репозиторії GitHub">
  <img src="/images/on-premises/github-sync-import.png" alt="Діалогове вікно Import from GitHub зі списком із чотирьох репозиторіїв" />
</Frame>

Якщо репозиторію організації немає в списку, натисніть <strong>Can't see what you're looking for?</strong>, щоб відкрити довідку GitHub про схвалення застосунку для цієї організації.
</Step>

<Step title="Перевірте проєкт">
Новий проєкт відкриється з файлами репозиторію.

<Frame caption="Імпортований проєкт">
  <img src="/images/on-premises/github-sync-imported.png" alt="Редактор з імпортованим проєктом, його файлами та скомпільованим PDF" />
</Frame>
</Step>
</Steps>

## Експорт проєкту в новий репозиторій {#export-a-project-to-a-new-repository}

Так із проєкту, власником якого ви є, створюється репозиторій, і вони прив'язуються. Проєкт можна прив'язати лише цим способом або імпортом: прив'язати його до вже наявного репозиторію не можна.

<Steps>
<Step title="Відкрийте GitHub у редакторі">
Відкрийте проєкт. На лівій панелі натисніть **Integrations**, потім **GitHub**.

<Frame caption="Панель Integrations">
  <img src="/images/on-premises/github-sync-integrations.png" alt="Панель Integrations з карткою GitHub" />
</Frame>
</Step>

<Step title="Заповніть дані репозиторію">
Виберіть **Owner**: це можете бути ви або одна з ваших організацій. **Repository Name** спочатку збігається з назвою проєкту. Опис необов'язковий, а **Private** вибрано за замовчуванням. Натисніть **Create a GitHub repository**.

<Frame caption="Export Project to GitHub">
  <img src="/images/on-premises/github-sync-export.png" alt="Заповнена форма Export Project to GitHub" />
</Frame>
</Step>

<Step title="Перевірте прив'язку">
У діалоговому вікні тепер написано **This project is linked to** і вказано репозиторій.

<Frame caption="Проєкт прив'язано">
  <img src="/images/on-premises/github-sync-exported.png" alt="Діалогове вікно Sync with GitHub після експорту" />
</Frame>
</Step>
</Steps>

## Синхронізація {#sync}

<Steps>
<Step title="Відкрийте діалог синхронізації">
Відкрийте прив'язаний проєкт. На лівій панелі натисніть **Integrations**, потім **GitHub**.

**Recent commits in GitHub** перелічує те, що потрапить у проєкт.

<Frame caption="Новий коміт очікує в GitHub">
  <img src="/images/on-premises/github-sync-new-commits.png" alt="Діалогове вікно Sync with GitHub з одним новим комітом" />
</Frame>
</Step>

<Step title="Опишіть свої зміни">
Якщо ви щось змінили в проєкті, з'явиться поле для повідомлення коміту. Воно необов'язкове: якщо залишити його порожнім, коміт називатиметься `Updates from Overleaf`.

<Frame caption="Повідомлення коміту для ваших змін">
  <img src="/images/on-premises/github-sync-commit-message.png" alt="Діалогове вікно Sync with GitHub із заповненим повідомленням коміту" />
</Frame>
</Step>

<Step title="Натисніть Sync">
Натисніть **Sync**. Нові коміти з GitHub потрапляють у проєкт, а ваші зміни надсилаються до гілки репозиторію за замовчуванням. Якщо обидві сторони змінили різні місця, зміни об'єднуються автоматично.
</Step>

<Step title="Перевірте результат">
У діалоговому вікні з'явиться <strong>No new commits in GitHub since last merge.</strong>, а поле повідомлення коміту зникне. Файли в редакторі та коміти на GitHub актуальні.

<Frame caption="Усе синхронізовано">
  <img src="/images/on-premises/github-sync-done.png" alt="Діалогове вікно Sync with GitHub після синхронізації, без нових комітів" />
</Frame>
</Step>
</Steps>

### Якщо ті самі рядки змінилися з обох боків {#if-the-same-lines-changed-on-both-sides}

Діалогове вікно повідомляє, що зміни не вдалося об'єднати, і називає нову гілку `overleaf-YYYY-MM-DD-HHMMSS`, у якій містяться ваші зміни.

<Frame caption="Конфлікт">
  <img src="/images/on-premises/github-sync-conflict.png" alt="Діалогове вікно Sync with GitHub з попередженням про конфлікт злиття" />
</Frame>

1. Об'єднайте цю гілку з гілкою за замовчуванням на GitHub або за допомогою Git. Тим часом діалог можна закрити: під час повторного відкриття він покаже те саме повідомлення.
2. Натисніть **I have manually merged. Continue**. Об'єднаний результат потрапить у проєкт.
3. Гілка залишається на GitHub. Видаліть її, коли вона стане непотрібною.

## Відв'язування проєкту {#unlink-a-project}

Зробіть це, якщо більше не хочете синхронізувати проєкт. Це може зробити лише власник проєкту.

<Steps>
<Step title="Натисніть Unlink">
У діалозі синхронізації натисніть **Unlink**.
</Step>

<Step title="Підтвердьте">
Натисніть **Confirm**. Примітка про підписку не заважає знову прив'язати проєкт.

<Frame caption="Підтвердження відв'язування">
  <img src="/images/on-premises/github-sync-unlink-project.png" alt="Діалогове вікно Sync with GitHub із запитом підтвердити відв'язування" />
</Frame>
</Step>

<Step title="Перевірте результат">
Тепер у діалоговому вікні відображається **Export Project to GitHub**. І проєкт, і репозиторій зберігають свій вміст. Щоб знову синхронізувати, експортуйте проєкт у новий репозиторій або імпортуйте репозиторій у новий проєкт.
</Step>
</Steps>

## Відв'язування облікового запису GitHub {#unlink-your-github-account}

В **Account settings**, у розділі **GitHub**, натисніть **Unlink**, потім ще раз **Unlink** у діалоговому вікні.

<Frame caption="Відв'язування облікового запису">
  <img src="/images/on-premises/github-sync-unlink-account.png" alt="Діалогове вікно Unlink GitHub Account" />
</Frame>

Ваші проєкти залишаються прив'язаними до своїх репозиторіїв. Синхронізувати їх не можна, доки ви знову не прив'яжете обліковий запис.

<Info>

Про те, хто що може робити в спільному проєкті, див. [Хто може прив'язувати й синхронізувати](/uk/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation#who-can-link-and-sync). Кожен співавтор, який синхронізує, прив'язує власний обліковий запис GitHub.

</Info>
