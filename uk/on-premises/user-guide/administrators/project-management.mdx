## Знайти проєкт {#find-a-project}

Введіть текст у **Search by project name, ID, owner or link**. Посиланням може бути адреса проєкту або одне з його посилань для спільного доступу. Щоб звузити список, використовуйте фільтр **Status**. Для сортування натисніть **Title** або **Last modified**.

Видалені проєкти не потрапляють у результати. Якщо пошук збігається й з видаленим проєктом, над таблицею з'являється рядок про це, наприклад **Found 1 matching deleted projects**. Натисніть **Display deleted projects**, щоб їх побачити.

## Статус проєкту {#project-status}

Кожен проєкт має один статус, а фільтр **Status** показує, скільки проєктів у кожному з них.

<Frame caption="Фільтр Status">
  <img src="/images/on-premises/project-management-status-filter.png" alt="Фільтр Status із варіантами All, Active, Archived, Trashed і Deleted" />
</Frame>

| Статус | Що означає |
| --- | --- |
| **All** | Усі проєкти, які не видалено. |
| **Active** | Звичайний стан. |
| **Archived** | Власник заархівував проєкт. Проєкт цілий, і його можна повернути. |
| **Trashed** | Власник перемістив проєкт до кошика. Проєкт цілий, і його можна повернути. |
| **Deleted** | Видалений власником із кошика, адміністратором або разом з обліковим записом власника. Повернути його може лише адміністратор. |

Проєкт проходить статуси поетапно:

1. **Active, Archived і Trashed** обирає власник на своїй сторінці проєктів. Власник завжди може повернутися назад. **Restore** із кошика завжди веде до Active, навіть якщо проєкт перед тим був заархівований.
2. **Deleted** є наступним етапом. Власник може видалити проєкт лише з кошика; адміністратор може видалити його з будь-якого з трьох статусів.
3. **Restore** повертає видалений проєкт у статус **Active**, яким би не був його попередній статус, а до його назви в кінці додається `(Restored)`. Це може зробити лише адміністратор. Якщо обліковий запис власника теж видалено, спочатку відновіть його: інакше діалог повідомить **The owner of this project is deleted: restore the owner first**.
4. **Delete permanently** є останнім етапом, і його не можна скасувати. В інших випадках видалені проєкти зберігаються, доки ви їх не видалите, якщо тільки в екземплярі не задано [`ENABLE_CRON_RESOURCE_DELETION`](/uk/on-premises/configuration/overleaf-toolkit/environment-variables), яка видаляє їх через 90 днів.

<Info>

Статус залежить лише від власника. Коли співавтор архівує спільний проєкт або переміщує його до кошика, проєкт переміщується лише на сторінці проєктів цього співавтора, а статус тут не змінюється.

</Info>

## Дії з проєктом {#actions-on-a-project}

| Значок | Дія | Що робить |
| --- | --- | --- |
| Відкрити | **Open Project** | Відкриває проєкт у редакторі в новій вкладці. |
| Папка | **Change project owner** | Передає проєкт іншому користувачеві. |
| Кошик | **Delete** | Переводить проєкт у **Deleted**. |
| Стрілка | **Restore** | Повертає видалений проєкт. Лише для видалених проєктів. |
| Перекреслений кошик | **Delete permanently** | Остаточно видаляє видалений проєкт. Лише для видалених проєктів. |

### Змінити власника {#change-the-owner}

Натисніть значок папки, введіть ім'я або адресу пошти, виберіть користувача, потім натисніть **Change project owner**. Діалог попереджає, що цю дію не можна скасувати і що новий власник отримає сповіщення та зможе змінювати налаштування доступу до проєкту. Вимкнені облікові записи не пропонуються. Якщо після вибору змінити текст, вибір скасовується: виберіть користувача знову.

  <img src="/images/on-premises/project-management-change-owner.png" alt="Діалог Change project owner із попередженням і вибраним новим власником" />
</Frame>

Щоб перенести одразу всі проєкти користувача, див. [Передати проєкти користувача](/uk/on-premises/user-guide/administrators/user-management#transfer-a-users-projects).

### Видалити, відновити або видалити остаточно {#delete-restore-or-permanently-delete}

Натисніть значок кошика, потім **Delete**. Щоб знову знайти проєкт, виберіть **Deleted** у фільтрі **Status**.

<Frame caption="Видалений проєкт">
  <img src="/images/on-premises/project-management-deleted.png" alt="Видалений проєкт у списку зі значками Restore і Delete permanently" />
</Frame>

Натисніть значок стрілки, потім **Restore**, щоб повернути проєкт, або перекреслений кошик, потім **Delete permanently**, щоб видалити його.

<Frame caption="Остаточне видалення проєкту">
  <img src="/images/on-premises/project-management-purge.png" alt="Діалог Delete permanently з попередженням, що дію не можна скасувати" />
</Frame>

### Змінити кілька проєктів одночасно {#change-several-projects-at-once}

Позначте проєкти у списку. Поруч із пошуком з'являться кнопки **Download**, **Change project owner** і **Delete**. **Download** зберігає вибрані проєкти в один файл `.zip`. У **Change project owner** не можна вибрати поточних власників позначених проєктів. У поданні **Deleted** кнопки називаються **Restore** і **Delete permanently**.

## Сторінка проєкту {#the-project-page}

Натисніть назву проєкту, щоб відкрити його сторінку. Угорі є значки для редагування, відкриття, завантаження та видалення проєкту. На сторінці п'ять вкладок.

### Огляд {#overview}

Відомості про проєкт і його налаштування. Натисніть значок олівця, щоб змінити **Name**, **Link sharing**, **Compiler**, **TeX Live version** і **Main document** або натиснути **Change project owner**. Потім натисніть **Save**.

<Frame caption="Редагування проєкту">
  <img src="/images/on-premises/project-management-edit.png" alt="Вкладка Overview у режимі редагування" />
</Frame>

### Дерево файлів {#file-tree}

Файли й папки проєкту, лише для читання.

<Frame caption="Файли проєкту">
  <img src="/images/on-premises/project-management-files.png" alt="Вкладка File tree зі списком frog.jpg, main.tex і відновленого bib-файлу" />
</Frame>

### Учасники {#members}

Хто має доступ: власник, співавтори та запрошення, що очікують. Натисніть значок олівця, щоб змінити їх:

* Виберіть **Editor**, **Reviewer** або **Viewer** для співавтора. Зміна застосовується одразу.
* Натисніть кошик поруч зі співавтором, потім **Remove access**.
* Для запрошення, що очікує, натисніть конверт, щоб виконати **Resend invite**, або кошик, щоб виконати **Revoke Invite**.

Завершивши, натисніть **Done**. Власника тут змінити не можна: використовуйте **Change project owner** на вкладці **Overview**.

<Frame caption="Зміна учасників проєкту">
  <img src="/images/on-premises/project-management-members.png" alt="Вкладка Members у режимі редагування з меню ролей, запрошенням, що очікує, і значками дій" />
</Frame>

### Видалені файли {#deleted-files}

Файли, видалені з проєкту. Натисніть значок стрілки поруч із файлом, потім **Restore file**. Копія з датою в імені потрапляє до кореневої папки проєкту, а в рядку відображається її ім'я. Видалений файл залишається у списку.

Копія з'явиться на вкладці **File tree** після перезавантаження сторінки.
