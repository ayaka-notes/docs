<Info>

Ayakaleaf Pro — це розширена реалізація Overleaf Community Edition, що пропонує всі функції Server Pro як _**безкоштовні преміум-можливості**_. На відміну від загальнодоступного Overleaf на [https://www.overleaf.com/](https://www.overleaf.com/), у нас немає обмежень на час компіляції чи ліцензійних обмежень на кількість користувачів, і ви можете повністю самостійно розміщувати власні дані, що гарантує абсолютну безпеку.

Overleaf Server Pro — це комерційне самостійно розміщене розгортання Overleaf з офіційною підтримкою. Докладніше про Server Pro дивіться на сторінці [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud).

</Info>

<Warning>

Overleaf Community Edition призначено для використання в середовищах, де **всі** користувачі є довіреними. Community Edition **не** підходить для сценаріїв, які потребують ізоляції користувачів, оскільки в ній недоступна функція Sandbox Compiles.

Без ізоляції компіляції LaTeX виконуються з тими самими привілеями, що й контейнер, і мають доступ до його файлової системи, мережі та змінних середовища. Це створює ризик витоку даних або компрометації системи. Неізольовані компіляції слід використовувати лише в повністю довірених середовищах; для багатокористувацьких і виробничих розгортань настійно рекомендується Sandbox Compiles.

Докладніше про Sandbox Compiles читайте в нашій [документації](/uk/on-premises/configuration/overleaf-toolkit/sandboxed-compiles).

</Warning>

### Підтримка спільноти

Користувачам самостійно розміщених екземплярів Overleaf підтримку надає спільнота через [Issues](https://github.com/ayaka-notes/ayakaleaf-pro/issues) на GitHub.

Щоб залишатися на підтримуваній версії, ви можете перевірити, яку версію Overleaf використовуєте, порівнявши вивід наведеної нижче команди з ідентифікаторами образів (Image ID), опублікованими в примітках до випусків.

```bash
docker inspect --format '{{.Image}}' sharelatex | awk -F: '{print substr($2, 1, 12)}'
```
