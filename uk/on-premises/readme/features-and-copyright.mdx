Ми поважаємо авторські права, тому перелічуємо тут усі функції та код, використаний у цьому проєкті. На цій сторінці наведено інформацію про нові функції Ayakaleaf Pro та пов'язані авторські права на код.

Якщо не зазначено інше, для перевірки коду та PR ми використовуємо Codex від OpenAI. У цьому процесі ми виправили багато проблем безпеки і щиро дякуємо їм за це. Докладніше див. [ayaka-notes/ayakaleaf-pro/pull](https://github.com/ayaka-notes/ayakaleaf-pro/pulls).

### Огляд

Протягом багатьох років чимало розробників зі спільноти доклали значних зусиль для покращення Overleaf Community Edition. Серед них:

* [https://github.com/ertuil/overleaf](https://github.com/ertuil/overleaf)
* [https://github.com/AllanChain/lcpu-overleaf](https://github.com/AllanChain/lcpu-overleaf)
* [https://github.com/yu-i-i/overleaf-cep/](https://github.com/yu-i-i/overleaf-cep/)
* [https://github.com/ayaka-notes/overleaf](https://github.com/ayaka-notes/overleaf)
* [https://github.com/davrot/overleaf\_with\_admin\_extension](https://github.com/davrot/overleaf_with_admin_extension)
* [https://github.com/overleaf/overleaf/pull/1447](https://github.com/overleaf/overleaf/pull/1447) (інтеграція з GitHub)
* [https://github.com/overleaf/overleaf/pull/1385](https://github.com/overleaf/overleaf/pull/1385) (підтримка Typst)

Можливо, ми використали відповідний код у нашому проєкті, і хочемо висловити їм свою вдячність.

#### Функція 01: система шаблонів

Цю функцію переважно розроблено в [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep). Ми змінили частину коду для покращення, тож ви можете:

* Завантажувати шаблони безпосередньо зі сторінок шаблонів.
* Відкривати проєкт, що відповідає шаблону.
* Отримувати обкладинки вищої якості (і за коротший час).

#### Функція 05: панель адміністратора

<Warning>

Якщо у вашій системі 1000 користувачів або проєктів, панель адміністратора відображатиме лише останні 1000 користувачів або проєктів. Для пошуку конкретних користувачів чи проєктів скористайтеся панеллю пошуку.

</Warning>

Цю функцію переважно розроблено в [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep). Ми змінили частину коду для покращення, тож ви можете:

* Шукати користувачів через бекенд, якщо їх більше 1000.
* Шукати проєкти через бекенд, якщо їх більше 1000.
* Відкривати проєкти безпосередньо з панелі адміністрування проєктів.
* Переглядати й змінювати ліміт часу компіляції користувача в панелі адміністратора.
* Скидати пароль користувача безпосередньо в панелі адміністратора.
* Інші покращення...

#### Функція 11: Learn Wiki

Цю функцію розроблено в [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro). Ви можете переглядати найновішу версію Learn Wiki від Overleaf, але ми не володіємо жодними авторськими правами на ці документи! Ми лише завантажуємо їх із сервера Overleaf під час першого ввімкнення цієї функції та періодично оновлюємо.
