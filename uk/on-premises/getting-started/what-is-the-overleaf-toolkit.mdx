---
title: Що таке Ayakaleaf Toolkit?
icon: toolbox
---

Ayakaleaf Toolkit — рекомендований спосіб розгортання локальних інсталяцій Community Edition та Ayakaleaf Pro. Його розроблено для найпоширенішого середовища: одного фізичного сервера або віртуальної машини. Toolkit використовує `docker compose` для керування контейнерами Docker вашого сервера й надає набір скриптів-обгорток над командами `docker`, які допомагають із технічнішими аспектами керування локальною версією Overleaf.

#### Обгортка `bin/docker-compose`

Скрипт `bin/docker-compose` — це обгортка навколо `docker compose`. Він завантажує конфігурацію з каталогу `config/`, після чого викликає `docker compose` з тими аргументами, які було передано скрипту.

Можна вважати `bin/docker-compose` прозорою обгорткою для програми `docker compose`, встановленої на вашій машині.

Приклад:

```bash title="Check running containers"
$ bin/docker-compose ps
```

#### Допоміжні скрипти

Окрім `bin/docker-compose`, Toolkit надає зручні скрипти для виконання поширених завдань:

* `bin/up`: скорочення для `bin/docker-compose up`
* `bin/start`: скорочення для `bin/docker-compose start`
* `bin/stop`: скорочення для `bin/docker-compose stop`
* `bin/shell`: запускає оболонку всередині контейнера **sharelatex**
* `bin/doctor`: скрипт для збирання інформації про інсталяцію та розгортання. Див. розділ «Перевірка сервера» нижче
* `bin/mongo`: запускає оболонку всередині контейнера **mongo** і перемикається на потрібну базу даних (**sharelatex**)
* `bin/backup-config`: створює копію (zip або tar) поточної конфігурації та зберігає її у вибраному вами цільовому каталозі
* `bin/logs`: перегляд/відстеження журналів сервісів
* `bin/error-logs`: перегляд/відстеження журналів помилок сервісів
* `bin/rename-env-vars-5-0`: скрипт міграції для оновлення змінних середовища в **config/variables.env** (ребрендинг з ShareLaTeX на Overleaf)
* `bin/rename-rc-vars`: скрипт міграції для оновлення змінних середовища в **config/overleaf.rc** (ребрендинг з ShareLaTeX на Overleaf)
* `bin/run-script`: допоміжний засіб, що спрощує запуск скриптів, які зберігаються в контейнері **sharelatex**
* `bin/upgrade`: допомагає з оновленням екземпляра. Скрипт перевіряє наявність оновлень Toolkit (через git) і пропонує завантажити зміни, перевіряє останню версію образу Docker і пропонує оновити його. Він передбачає покрокове підтвердження, можливість створити резервну копію поточної конфігурації та сам зупиняє й запускає сервіси Docker. Докладніше див. Upgrading your deployment: https://docs.overleaf.com/on-premises/maintenance/upgrading-your-deployment

<Info>

Якщо ви бажаєте запускати екземпляр без під'єднання до журналів Docker, виконайте `bin/up -d`, щоб запустити його у фоновому режимі (detached mode).

</Info>

#### Перевірка сервера

Overleaf Toolkit містить зручний скрипт `bin/doctor`, який створює звіт із зазначенням будь-яких незадоволених залежностей.

Перш ніж продовжити, запустіть скрипт `bin/doctor` і переконайтеся, що все працює правильно:

```bash title="Run Overleaf Doctor"
bin/doctor
```
