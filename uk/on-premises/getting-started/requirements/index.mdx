### Вимоги до встановлення Server Pro та Community Edition

<Warning>

Ми наполегливо рекомендуємо запускати Server Pro на сучасній стабільній версії Ubuntu (наприклад, Ubuntu 24.04 у 2025–2026 роках) з актуальною версією Docker. Запуск Server Pro на інших системах можливий, але нам буде значно складніше надавати підтримку для нестандартних конфігурацій Ubuntu/Docker. Ми також не можемо надавати підтримку щодо проблем із самим Docker.

</Warning>
