### Операційні системи {#operating-systems}

Для спільних і продакшн-серверів ми рекомендуємо систему **Linux на основі Debian**, наприклад **Ubuntu**. Ayakaleaf Pro також може працювати на [macOS з Docker Desktop](/uk/on-premises/installation/using-docker-compose/macos) і [Windows з WSL 2 та Docker Desktop](/uk/on-premises/installation/using-docker-compose/windows). Усі три платформи використовують Linux-контейнери й той самий Toolkit; дотримуйтеся посібника для операційної системи вашого хоста.

<Danger>

Під час використання Sandboxed Compiles **важливо** пам'ятати, що застосунку потрібен root-доступ до сокета Docker.

</Danger>

### Залежності {#dependencies}

* Docker 25.0 і 29
* MongoDB 7.0 і 8.0
* Redis 6.2 і 7.5

<Info>

Відстежувати дати завершення підтримки (End-of-Life, EOL) для наведених вище залежностей та інших популярних продуктів можна за допомогою сервісу endoflife.date: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

MongoDB і Redis автоматично завантажуються `docker compose` під час запуску Ayakaleaf Pro, якщо не налаштовано використання іншої інсталяції.

</Info>

Toolkit залежить від таких програм:

* bash
* Docker

`docker compose` є обов'язковим і зазвичай встановлюється разом із Docker.

Рекомендуємо встановити найновішу версію Docker, доступну для вашої операційної системи.

Після коректного встановлення Docker ви маєте змогу виконати ці команди без помилок:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2 or later, such as v5)
docker compose version

# List the running Docker containers on your system
docker ps
```
