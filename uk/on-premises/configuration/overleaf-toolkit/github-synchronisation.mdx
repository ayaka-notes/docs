### Налаштування синхронізації з GitHub

<Warning>

Перед використанням синхронізації з GitHub потрібно спершу ввімкнути [git-bridge](/uk/on-premises/configuration/overleaf-toolkit/git-integration).

```dotenv title="config/overleaf.rc"
GIT_BRIDGE_ENABLED=true
```

</Warning>

Перейдіть до [налаштувань розробника](https://github.com/settings/developers), щоб створити свій застосунок GitHub OAuth, і скопіюйте `CLIENT_ID` та `SECRET`.

**Примітки**: ваша URL-адреса зворотного виклику OAuth: `${OVERLEAF_SITE_URL}/user/github-sync/oauth2/callback`.

Потім додайте наведені нижче налаштування до файлів змінних середовища Overleaf.

```dotenv title="config/variables.env" wrap
# used to encrypt the user's GitHub access token.
# How to generate: `openssl rand -hex 32`
GITHUB_TOKEN_CIPHER_PASSWORD=0123456789ABCDEFG # changed to yours

# Github Sync Settings
GITHUB_SYNC_ENABLED=true
GITHUB_SYNC_CLIENT_ID=
GITHUB_SYNC_CLIENT_SECRET=

# OAuth callback is: ${OVERLEAF_SITE_URL}/user/github-sync/oauth2/callback
# (Optional) GITHUB_SYNC_PROXY_URL=http://10.0.0.1:10808
```

<Warning>

Перш ніж налаштовувати URL-адресу зворотного виклику GitHub OAuth, переконайтеся, що `OVERLEAF_SITE_URL` задано правильно.

</Warning>

Якщо ви перебуваєте в регіоні з обмеженим доступом до мережі, вам може знадобитися налаштувати проксі для доступу до GitHub. Встановіть таку змінну середовища: `GITHUB_SYNC_PROXY_URL=http://10.0.0.1:10808`. Переконайтеся, що використання проксі відповідає місцевому законодавству та нормативним актам.

<Warning>

`GITHUB_SYNC_PROXY_URL` має бути стандартним прямим HTTP/HTTPS-проксі (наприклад, HTTP-порт Clash). Дзеркала для завантаження з GitHub, як-от `gh-proxy.org`, не підтримуються.

</Warning>

<Warning>

Не використовуйте `127.0.0.1` як хост проксі. Якщо проксі працює на хост-сервері, використовуйте LAN IP-адресу сервера (наприклад, `192.168.1.xx`) і переконайтеся, що проксі налаштовано на прийом з'єднань від пристроїв у локальній мережі.

</Warning>
