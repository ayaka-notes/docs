---
title: Додавання довідки LaTeX для користувачів
icon: graduation-cap
---

Ви можете ввімкнути доступ до сторінок [Learn](https://www.overleaf.com/learn) від Overleaf у своєму екземплярі Overleaf Pro, просто додавши `OVERLEAF_PROXY_LEARN=true` до файлу `config/variables.env` у Toolkit і виконавши команду `bin/up`.

Це дає змогу користувачам отримувати доступ до актуальної документації та навчальних матеріалів, натиснувши кнопку **Documentation** у навігаційному меню, не залишаючи вашого екземпляра.

<Info>

За замовчуванням відкрити `/learn` можуть лише користувачі, які увійшли в систему. Щоб зробити сторінки доступними для відвідувачів, які не ввійшли, також встановіть `OVERLEAF_ALLOW_PUBLIC_ACCESS=true`, див. [Page Access](/uk/on-premises/configuration/overleaf-toolkit/public-access#page-access  "mention").

</Info>

<Info>

Для розгортань через Docker Compose потрібно додати змінну середовища `OVERLEAF_PROXY_LEARN: true` до розділу **environment** служби `sharelatex` у файлі `docker-compose.yml`.

</Info>

<Info>

Вашому розгортанню Server Pro потрібен доступ до інтернету, щоб виконувати зовнішні запити `GET` до [https://learn.sharelatex.com](https://docs.overleaf.com/on-premises/welcome).

</Info>

<Danger>

Коли ви вперше вмикаєте цей параметр і перезапускаєте Docker з Overleaf, система має завантажити відповідну Wiki, що може тривати 5 хвилин або довше. Лише після завершення завантаження ви зможете побачити сторінку входу Overleaf.

</Danger>
