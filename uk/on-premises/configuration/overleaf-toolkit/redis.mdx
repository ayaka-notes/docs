### Увімкнення автентифікації за паролем

Якщо ви використовуєте зовнішній сервіс Redis і потрібно вказати пароль, задайте змінні середовища `OVERLEAF_REDIS_PASS` і `REDIS_PASSWORD` у файлі **config/variables.env** та виконайте команду `bin/up -d`, щоб перестворити контейнер **sharelatex**.

Якщо ви запускаєте локальний екземпляр Redis, потрібно налаштувати сервіс **redis** так, щоб він запускався з автентифікацією за паролем. Після встановлення наведених вище змінних середовища виконайте ще такі кроки:

Створіть файл **docker-compose.override.yml** у каталозі <strong>config/</strong> з таким вмістом:

```yaml title="config/docker-compose.override.yml"
services:
    redis:
        command: "redis-server --requirepass <YOUR-PASSWORD>"
```

<Warning>

Якщо у вас увімкнено персистентність AOF, потрібно додати `--appendonly yes` до `command`.

</Warning>

Виконайте `bin/up -d`, щоб перестворити контейнери.

### Увімкнення персистентності Append-Only File

(Оригінал: https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/redis#enabling-append-only-file-persistence)

Персистентність Redis AOF (Append-Only File) забезпечує надійну збереженість даних завдяки журналюванню кожної операції запису, яку отримує сервер. На відміну від знімків RDB, що створюють копії набору даних на певний момент часу, AOF зберігає повний запис усіх змін ваших даних.

<Info>

Вимкнення RDB необов'язкове. Загалом рекомендується використовувати обидва методи персистентності разом. Перш ніж вносити будь-які зміни в продуктивному середовищі, ознайомтеся з перевагами та недоліками одночасного використання AOF і RDB.

</Info>

Докладніше про ввімкнення персистентності AOF у Redis можна прочитати тут: [https://redis.io/docs/latest/operate/oss\_and\_stack/management/persistence/#how-i-can-switch-to-aof-if-im-currently-using-dumprdb-snapshotsarrow-up-right](https://redis.io/docs/latest/operate/oss_and_stack/management/persistence/#how-i-can-switch-to-aof-if-im-currently-using-dumprdb-snapshotsarrow-up-right)

1. Заплануйте вікно обслуговування для оновлення.
2. Зупиніть екземпляр за допомогою `bin/stop` і створіть резервну копію тек <strong>config/</strong> і <strong>data/</strong>.
3. Виконайте `bin/up`, щоб запустити екземпляр
4. Виконайте команду `docker exec -it redis sh`
5. Виконайте команду `redis-cli`, щоб відкрити інтерфейс командного рядка Redis
6. У redis-cli виконайте команду `config set appendonly yes`
7. Тепер потрібно дочекатися, поки перезапис AOF завершить збереження даних. Для цього введіть `INFO persistence` у redis-cli і дочекайтеся, поки `aof_rewrite_in_progress` і `aof_rewrite_scheduled` стануть `0`, а також переконайтеся, що `aof_last_bgrewrite_status` має значення `ok`.
8. Вийдіть із redis-cli, ввівши `exit` і натиснувши клавішу Enter
9. Вийдіть із контейнера redis, ввівши `exit` і натиснувши клавішу Enter
10. Виконайте команду `ls ./data/redis` і переконайтеся, що бачите файл **appendonly.aof**
11. Відредагуйте файл **config/overleaf.rc** і змініть значення змінної середовища `REDIS_AOF_PERSISTENCE` з `false` на `true`
12. Виконайте `bin/up -d` і переконайтеся, що застосунок працює (редактор проєктів і панель історії функціонують).
