### Налаштування інтеграції із Zotero

1. Відкрийте [це посилання](https://www.zotero.org/oauth/apps), щоб створити OAuth-клієнт Zotero (як показано на зображенні)
2. Виберіть **Application Type**: **Browser**
3. Укажіть Callback URL у вигляді `${OVERLEAF_SITE_URL}/user/zotero/oauth/callback`
4. Налаштуйте свій `config/variables.env`

<Frame>
  <img src="/images/on-premises/image-41.png" alt="" width="375" />
</Frame>

```dotenv title="config/variables.env"
#################
#    Zotero     #
#################
# 'zotero' must be in ENABLED_LINKED_FILE_TYPES (set in develop/docker-compose.yml)
ENABLED_LINKED_FILE_TYPES=project_file,project_output_file,url,zotero

# From a Zotero OAuth client (register at https://www.zotero.org/oauth/apps)
# Application Type: Browser 
# Callback URL -> ${OVERLEAF_SITE_URL}/user/zotero/oauth/callback
ZOTERO_CLIENT_ID=
ZOTERO_CLIENT_SECRET=
# Encrypts the Zotero API key in mongo (set in dev to avoid writing a key file
# to /var/lib/overleaf/data, which the dev web container can't create)
# How to generate: `openssl rand -hex 32`
ZOTERO_CIPHER_PASSWORD=dev-zotero-cipher-password
# Optional: route the module's server-side Zotero requests (OAuth + API) through
# an HTTP proxy (must be reachable from the web container; same as github-sync)
# http://10.0.0.1:10808
# (Optional) ZOTERO_PROXY_URL=
```

### Примітки

<Warning>

Під час оновлення наявної інсталяції, що містить пов'язані файли бібліографії Zotero, до перевипущеної версії 6.3.0 дотримуйтеся [інструкцій з міграції Zotero / Mendeley](/uk/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention"). Для нових інсталяцій ця міграція не потрібна.

</Warning>

<Danger>

Оскільки Ayakaleaf — це платформа для спільної роботи, з метою підвищення безпеки, починаючи з версії 6.3.0, оновлювати імпортований файл `bib` із посиланнями зможе лише його початковий автор.

</Danger>

Наприклад, припустімо, що власник проєкту, Користувач A, вмикає спільний доступ за посиланням і створює в проєкті файл `test.bib`, пов'язуючи його зі своїм обліковим записом Zotero. Якщо інший користувач, Користувач B, отримає доступ до проєкту через спільне посилання, він зможе читати й завантажувати `test.bib`, але не зможе оновити або повторно імпортувати файл із Zotero. Виконувати оновлення може лише Користувач A як початковий автор файлу з посиланнями. Інакше кажучи, право оновлювати файл `.bib` має лише його початковий автор.
