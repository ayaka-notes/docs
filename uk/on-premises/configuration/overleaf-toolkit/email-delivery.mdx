Overleaf підтримує надсилання електронної пошти двома способами: через Simple Mail Transfer Protocol (SMTP) та [Amazon Simple Email Service (SES)](https://aws.amazon.com/ses/). SMTP можна використовувати, якщо на вашому localhost увімкнено поштовий сервер, який прослуховує локальні з'єднання.

## Кілька адрес електронної пошти в одному обліковому записі {#several-emails-per-account}

<Info>

Цю функцію розроблено [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro), вона доступна починаючи з v6.4.0.

</Info>

Коли пошту налаштовано, сторінка налаштувань показує список адрес електронної пошти облікового запису замість єдиного поля. Користувачі додають адресу, вводячи 6-значний код, надісланий на неї, і натискають **Make primary**, щоб перенести на неї обліковий запис. Так можна зберегти обліковий запис, коли адресу буде відкликано, наприклад університетську після випуску. У [посібнику користувача](/uk/on-premises/user-guide/users/multiple-emails) є кроки зі знімками екрана.

* Входити й отримувати скидання пароля може лише основна адреса. Додаткова адреса не робить ні того, ні іншого, тому адреса, передана комусь іншому, не може захопити обліковий запис.
* Натисніть **Make primary** до того, як стару поштову скриньку закриють. Після цього адресу має змінювати адміністратор у **Admin → Manage Users**.
* Стара основна адреса, яку так і не підтвердили, видаляється, коли основною стає інша адреса. Підтверджена залишається додатковою, доки користувач її не видалить.
* **Make primary** відхиляється, якщо ввімкнено LDAP або SAML, бо такі облікові записи не змогли б увійти з новою адресою. Див. [Облікові записи та паролі](/uk/on-premises/configuration/overleaf-toolkit/authentication#accounts-and-passwords).
* Без налаштувань пошти залишається єдине поле адреси електронної пошти.

## Налаштування {#configuration}

Електронна пошта налаштовується за допомогою наведених нижче змінних середовища.

#### Налаштування відправника {#sender-configuration}

| Назва                         | Опис                                                                                                                                                 |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | <p>Адреса відправника, напр. <a href="mailto:support@mycompany.com">`'support@mycompany.com'`</a><br /><br />- <strong>Обов'язково</strong>: так</p> |
| `OVERLEAF_EMAIL_REPLY_TO`     | Адреса для відповіді, напр. `'noreply@mycompany.com'`                                                                                                 |

#### SMTP {#smtp}

| Назва                                   | Опис                                                                                                                                                                                                                                                                     |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST`              | Ім'я хоста або IP-адреса для підключення. Має бути доступним із контейнера Docker                                                                                                                                                                                       |
| `OVERLEAF_EMAIL_SMTP_PORT`              | Порт для підключення                                                                                                                                                                                                                                                     |
| `OVERLEAF_EMAIL_SMTP_SECURE`            | Якщо `true`, з'єднання використовуватиме TLS під час підключення до сервера. Якщо `false` або не задано, TLS використовується, якщо сервер підтримує розширення `STARTTLS`. У більшості випадків встановлюйте `true`, якщо підключаєтеся до порту `465`. Для порту `587` або `25` залиште `false` |
| `OVERLEAF_EMAIL_SMTP_USER`              | Ім'я користувача для автентифікації на SMTP-сервері                                                                                                                                                                                                                      |
| `OVERLEAF_EMAIL_SMTP_PASS`              | Пароль, пов'язаний з іменем користувача SMTP                                                                                                                                                                                                                             |
| `OVERLEAF_EMAIL_SMTP_TLS_REJECT_UNAUTH` | Якщо `false`, дозволяє відкривати з'єднання з TLS-сервером із самопідписаним або недійсним TLS-сертифікатом                                                                                                                                                            |
| `OVERLEAF_EMAIL_SMTP_IGNORE_TLS`        | Якщо `true`, а `OVERLEAF_EMAIL_SMTP_SECURE` має значення `false`, TLS не використовується, навіть якщо сервер підтримує розширення `STARTTLS`                                                                                                                         |
| `OVERLEAF_EMAIL_SMTP_NAME`              | Необов'язкове ім'я хоста для перевірки TLS, якщо `OVERLEAF_EMAIL_SMTP_HOST` задано як IP-адресу; за замовчуванням — ім'я хоста машини.                                                                                                                                  |
| `OVERLEAF_EMAIL_SMTP_LOGGER`            | Якщо `true`, повідомлення журналу виводяться у `web.log`.                                                                                                                                                                                                             |

#### Інтерфейс Amazon SES SMTP {#amazon-ses-smtp-interface}

Докладніше про використання інтерфейсу Amazon SES SMTP для надсилання пошти можна прочитати [тут](https://docs.aws.amazon.com/ses/latest/dg/send-email-smtp.html).

| Назва                      | Опис                                                                                       |
| -------------------------- | ------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST` | Ім'я хоста або IP-адреса для підключення. Має бути доступним із контейнера Docker           |
| `OVERLEAF_EMAIL_SMTP_PORT` | Порт для підключення                                                                       |
| `OVERLEAF_EMAIL_SMTP_USER` | Ім'я користувача для автентифікації на SMTP-сервері                                        |
| `OVERLEAF_EMAIL_SMTP_PASS` | Пароль, пов'язаний з іменем користувача SMTP                                               |

#### Amazon SES API {#amazon-ses-api}

Докладніше про використання Amazon SES API для надсилання пошти можна прочитати [тут](https://docs.aws.amazon.com/ses/latest/dg/send-email-api.html).

| Назва                                  | Опис                                        |
| -------------------------------------- | ------------------------------------------- |
| `OVERLEAF_EMAIL_AWS_SES_ACCESS_KEY_ID` | Ключ доступу, якщо використовується AWS SES |
| `OVERLEAF_EMAIL_AWS_SES_SECRET_KEY`    | Секретний ключ, якщо використовується AWS SES |
| `OVERLEAF_EMAIL_AWS_SES_REGION`        | Якщо не задано, регіон за замовчуванням — US-EAST-1 |

#### AWS SES з ролями екземпляра {#aws-ses-with-instance-roles}

| Назва                   | Опис                                                                                                                             |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_DRIVER` | Якщо встановлено `ses`, поштова система використовуватиме метод SES API і покладатиметься на налаштовані ролі екземпляра для надсилання пошти. |

#### Налаштування вигляду {#customisation}

| Назва                          | Опис                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_CUSTOM_EMAIL_FOOTER` | <p>Користувацький HTML, який додається до всіх листів, напр.<br /><br /><strong>Приклад</strong>: `"<div>This system is run by department x </div> <div> If you have any questions please look at our faq <a href='https://somwhere.com'>here</a></div>"`</p> |
