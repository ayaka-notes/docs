### Налаштування i18n в Overleaf

<Info>

У цьому документі описано, як налаштувати інтернаціоналізацію (i18n) для самостійно розгорнутого екземпляра **Overleaf**.

</Info>

Overleaf перекладено багатьма мовами. За відповідного налаштування ви можете:

* Запустити свій екземпляр Overleaf **однією фіксованою мовою**, або
* Увімкнути **кілька мов**, дозволивши користувачам динамічно перемикати мову, як на `www.overleaf.com`.

***

#### Налаштування однієї мови

Мова сайту налаштовується за допомогою змінної середовища `OVERLEAF_SITE_LANGUAGE` (або `SHARELATEX_SITE_LANGUAGE` для версій Overleaf **4.x і старіших**).

Підтримувані коди мов:

* `en` - англійська (за замовчуванням)
* `es` - іспанська
* `pt` - португальська
* `de` - німецька
* `fr` - французька
* `cs` - чеська
* `nl` - нідерландська
* `sv` - шведська
* `it` - італійська
* `tr` - турецька
* `zh-CN` - китайська (спрощена)
* `no` - норвезька
* `da` - данська
* `ru` - російська
* `ko` - корейська
* `ja` - японська
* `pl` - польська
* `fi` - фінська

Англійська є мовою за замовчуванням. Щоб змінити мову інтерфейсу (наприклад, на спрощену китайську), додайте такий рядок до `config/variables.env`:

```bash title="config/variables.env"
OVERLEAF_SITE_LANGUAGE=zh-CN
```

Потім застосуйте конфігурацію:

```bash
bin/up
```

Після перезапуску сервісів мова меню вебінтерфейсу має відповідати новому налаштуванню.

#### Налаштування кількох мов

Щоб користувачі могли **перемикати мову без виходу з облікового запису**, ваш екземпляр Overleaf має бути налаштований на обслуговування різних мов залежно від доменних імен.

У цьому розділі припускається, що:

* Ваш основний домен — `overleaftest.com`
* У вас є **wildcard-сертифікат TLS** (наприклад, `*.overleaftest.com`)
* Ви **не використовуєте `localhost`** (оскільки він не підтримує маршрутизацію мов на основі піддоменів)

Для локального тестування можна використати домен на кшталт `dev-overleaf.com`.

<Steps>
<Step title="Налаштування TLS-проксі (Nginx)">
Ваш зворотний TLS-проксі має передавати оригінальний заголовок `Host`, щоб Overleaf міг визначити, до якого мовного домену звернувся користувач.

Переконайтеся, що присутня така директива:

```nginx
proxy_set_header Host $host;
```

Ось приклад конфігурації Nginx:

```nginx
server {
    listen 443 ssl;
    server_name    _; # Catch all, see http://nginx.org/en/docs/http/server_names.html
    server_name *.overleaftest.com;
    ssl_certificate /etc/nginx/ssl/nginx.crt;
    ssl_certificate_key /etc/nginx/ssl/nginx.key;
    ssl_protocols               TLSv1 TLSv1.1 TLSv1.2;
    ssl_prefer_server_ciphers   on;
    # used cloudflares ciphers https://github.com/cloudflare/sslconfig/blob/master/conf
    ssl_ciphers EECDH+CHACHA20:EECDH+AES128:RSA+AES128:EECDH+AES256:RSA+AES256:EECDH+3DES:RSA+3DES:!MD5;

    # config to enable HSTS(HTTP Strict Transport Security) https://developer.mozilla.org/en-US/docs/Security/HTTP_Strict_Transport_Security
    # to avoid ssl stripping https://en.wikipedia.org/wiki/SSL_stripping#SSL_stripping	
    add_header Strict-Transport-Security "max-age=31536000; includeSubdomains;";
    server_tokens off;
    add_header X-Frame-Options SAMEORIGIN;
    add_header X-Content-Type-Options nosniff;
    client_max_body_size 50M;

    location / {
        proxy_pass http://localhost:5000; # change to whatever host/port the docker container is listening on.
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 3m;
        proxy_send_timeout 3m;
        
        # add this to your nginx conf
        proxy_set_header Host $host;
    }
}
```
</Step>

<Step title="Налаштування домену cookie">
Щоб користувачі не виходили з облікового запису під час перемикання мови, файли cookie мають бути спільними для всіх мовних піддоменів.

Додайте такий рядок до `config/variables.env`:

```env title="config/variables.env"
# Note the leading dot
COOKIE_DOMAIN=.overleaftest.com
```

Це гарантує, що cookie автентифікації будуть дійсними для всіх піддоменів `overleaftest.com`.
</Step>

<Step title="Зіставлення мов і доменів">
Далі визначте, як коди мов зіставляються з піддоменами, за допомогою\
`OVERLEAF_LANG_DOMAIN_MAPPING`.

#### Приклад конфігурації

```dotenv title="config/variables.env" wrap
OVERLEAF_LANG_DOMAIN_MAPPING='{"www": {"lngCode": "en","url": "https:\/\/www.overleaftest.com"},"cn": {"lngCode": "zh-CN","url": "https:\/\/cn.overleaftest.com"}}'
```

За такої конфігурації:

* `https://www.overleaftest.com` → англійський інтерфейс
* `https://cn.overleaftest.com` → інтерфейс спрощеною китайською

За потреби це зіставлення можна розширити додатковими мовами та піддоменами.
</Step>

<Step title="Перенаправлення кореневого домену">
Нарешті, перенаправте кореневий домен (`overleaftest.com`) на домен мови за замовчуванням (`www.overleaftest.com`).

```nginx
server{
    listen 80;
    server_name overleaftest.com;
    return 301 https://www.overleaftest.com$request_uri;
}

server {
    listen 443 ssl http2;
    server_name overleaftest.com;
    ssl_certificate     /path/to/fullchain.cer;
    ssl_certificate_key /path/to/overleaftest.com.key;
    return 301 https://www.overleaftest.com$request_uri;
}
```
</Step>
</Steps>
