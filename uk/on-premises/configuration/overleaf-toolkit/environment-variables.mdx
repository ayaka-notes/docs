---
title: Змінні середовища
icon: seedling
---

На цій сторінці описано змінні середовища, які підтримуються у файлі `config/variables.env` для розгортань через Toolkit.

Файл `config/variables.env` складається з визначень змінних у формі `NAME=value`; рядки, що починаються з `#`, вважаються коментарями.

<Info>

Після будь-якої зміни в `overleaf.rc` або `variables.env` необхідно перестворити контейнери Docker, виконавши `bin/up`.

</Info>

### Усі версії

Ці змінні середовища сумісні з Server CE і Server Pro та забезпечують простий шлях міграції між цими двома локальними версіями. Їх також можна використовувати як для розгортань через Toolkit, так і через Docker Compose.

<Info>

Раніше ці змінні середовища мали префікс `SHARELATEX_` замість `OVERLEAF_`.

</Info>

<Info>

Можна запровадити обмеження паролів для користувачів, коли використовується система входу Overleaf (локальні облікові записи), а не SSO, як-от LDAP. Для облікових записів SSO політики паролів застосовуватиме ваш постачальник ідентичності або служба каталогів, що додатково дає змогу підтримувати багатофакторну автентифікацію.

</Info>
