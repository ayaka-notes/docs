<Info>

Цю можливість надає [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/overleaf-pro) з підтримкою OAuth 2.0; вона доступна починаючи з v6.3.0. Якщо ви зіткнетеся з проблемами, будемо раді вашим відгукам.

</Info>

#### Налаштування інтеграції з Mendeley

1. Перейдіть за [цим посиланням](https://dev.mendeley.com/myapps.html), щоб зареєструвати OAuth-застосунок Mendeley
2. Налаштуйте **Redirect URL** так: `${OVERLEAF_SITE_URL}/user/mendeley/oauth/callback`
3. Запишіть згенеровані **ID** (зазвичай числовий, наприклад `24061`, як показано нижче) і **Secret** вашого застосунку
4. Змініть свій `config/variables.env`&#x20;
5. Залиште Authorisation Flow: Elsevier (як рекомендовано)

```dotenv title="config/variables.env"
#################
#   Mendeley    #
#################
# 'mendeley' must be in ENABLED_LINKED_FILE_TYPES (keep 'zotero' too if you use both)
ENABLED_LINKED_FILE_TYPES=project_file,project_output_file,url,mendeley

# From a Mendeley OAuth application (register at https://dev.mendeley.com/myapps.html)
# Redirect URL -> ${OVERLEAF_SITE_URL}/user/mendeley/oauth/callback
MENDELEY_CLIENT_ID=
MENDELEY_CLIENT_SECRET=
# Encrypts the Mendeley OAuth tokens in mongo; if unset, a key file is generated
# in /var/lib/overleaf/data on first use
# How to generate: `openssl rand -hex 32`
MENDELEY_CIPHER_PASSWORD=
# Optional: route the module's server-side Mendeley requests (OAuth + API) through
# an HTTP proxy (must be reachable from the web container; same as github-sync)
# http://10.0.0.1:10808
# (Optional) MENDELEY_PROXY_URL=
```

<Info>

&#x20;`mendeley` має бути включено до `ENABLED_LINKED_FILE_TYPES` (залиште в списку також `zotero`, якщо використовуєте обидва). `MENDELEY_CLIENT_ID` і `MENDELEY_CLIENT_SECRET` беруться з вашого зареєстрованого OAuth-застосунку. Пароль шифрування (cipher password) шифрує OAuth-токени Mendeley у MongoDB (згенеруйте його за допомогою `openssl rand -hex 32`); без нього під час першого використання у томі даних буде згенеровано файл ключа. За бажанням задайте `MENDELEY_PROXY_URL`, щоб спрямовувати серверні запити до Mendeley (OAuth + API) через HTTP-проксі, доступний з вебконтейнера.

</Info>

### Примітки

<Warning>

Під час оновлення наявної інсталяції з пов'язаними файлами бібліографії Mendeley до повторно випущеної версії 6.3.0 дотримуйтеся [інструкцій з міграції Zotero / Mendeley](/uk/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention"). Новим інсталяціям ця міграція не потрібна.

</Warning>

<Danger>

Оскільки Ayakaleaf — це платформа для спільної роботи, з метою підвищення безпеки, починаючи з версії 6.3.0, оновлювати імпортований файл бібліографії `bib` дозволено лише його початковому творцеві.

</Danger>

Наприклад, припустімо, що власник проєкту, користувач A, вмикає спільний доступ за посиланням і створює в проєкті файл `test.bib`, пов'язуючи його зі своїм обліковим записом Zotero. Якщо інший користувач, B, отримає доступ до проєкту через спільне посилання, він і надалі зможе читати й завантажувати `test.bib`, але не зможе оновлювати чи повторно імпортувати файл із Zotero. Виконувати оновлення може лише користувач A як початковий творець файлу бібліографії. Іншими словами, право оновлювати файл `.bib` має лише його початковий творець.
