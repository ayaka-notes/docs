---
title: Ізольовані/офлайн-розгортання
description: Розгорніть Ayakaleaf Pro офлайн, експортувавши, перенісши та завантаживши образи Docker.
icon: block-brick
---

Загалом ми не рекомендуємо розгортати Ayakaleaf Pro в офлайн-середовищі, оскільки багато його функцій, як-от GitHub Sync та інтеграція з Zotero, потребують підключення до інтернету.

Якщо ви хочете працювати офлайн, звернутися до реєстру `ghcr.io`, щоб завантажити потрібні образи `ayakaleaf-pro` і TeX Live, може бути не завжди можливо. Це не проблема, оскільки Docker надає інструменти для експорту та імпорту образів, які допоможуть вам з офлайн/ізольованим (air-gapped) розгортанням.

Загалом ви завантажите потрібні образи на пристрої з доступом до інтернету, експортуєте їх на портативний носій (або перенесете за допомогою SCP/Rsync) та імпортуєте на ізольований сервер.

Для цього потрібно виконати такі кроки:

* Завантажте всі потрібні образи ( `overleaf-pro`, `git-bridge`, `mongo`, `redis` + усі потрібні [образи TeX Live](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles#available-tex-live-images) для використання з [Sandboxed Compiles](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles)) на машині з доступом до інтернету
  * `docker pull ghcr.io/ayaka-notes/overleaf-pro:6.3.0`
  * `docker pull ghcr.io/ayaka-notes/overleaf-pro/git-bridge:6.3.0` (тег має збігатися з тегом `overleaf-pro`)
  * `docker pull mongo:8.0` (замініть на реальну версію)
  * `docker pull redis:7.4` (замініть на реальну версію)
  * `docker pull ghcr.io/ayaka-notes/texlive-full:2024.1` (замініть на реальну версію)
* Потім **кожен** із завантажених образів потрібно експортувати у файл .tar. Наприклад, `docker save ghcr.io/ayaka-notes/overleaf-pro:6.3.0 > overleaf-pro:6.3.0.tar`
* У зручний для вас спосіб перенесіть файли `.tar` з машини з доступом до інтернету на офлайн/ізольований сервер
* Для кожного файлу .tar скористайтеся командою `docker load`, щоб завантажити образ із файлу .tar. Наприклад, `docker load < overleaf-pro:6.3.0.tar`
* Нарешті, виконайте команду `docker images`, щоб переглянути/підтвердити, що образи успішно завантажено й вони доступні

<Danger>

За замовчуванням під час виконання команди `bin/up` Toolkit намагатиметься автоматично завантажити кожен з образів TeX Live, заданих через `ALL_TEX_LIVE_DOCKER_IMAGES` у `config/variables.env`. Оскільки ваше розгортання ізольоване, це завершиться помилкою — запобігти цьому можна, встановивши `SIBLING_CONTAINERS_PULL=false` у `config/overleaf.rc`.

</Danger>
