Використовуйте Claude Code або Codex, щоб спланувати й виконати розгортання Ayakaleaf Pro. Під час роботи агент може шукати інформацію в цій документації через MCP.

Агент допомагає з розгортанням, але відповідальність за перевірку команд і захист облікових даних лишається на вас.

### Перед початком

Підготуйте підтримуваний Linux-сервер із доступом через SSH. Перш ніж продовжити, ознайомтеся з [вимогами](/uk/on-premises/getting-started/requirements  "mention").

<Warning>

Не вставляйте в запити до агента паролі, приватні ключі, токени чи ліцензійні ключі. Перевіряйте кожну команду перед її виконанням, особливо команди, які змінюють файли, мережі чи контейнери.

</Warning>

### Під'єднання документації

Додайте MCP-ендпоінт документації до свого локального агента.

<Tabs>
<Tab title="Claude Code">

```bash wrap
claude mcp add ayakaleaf-pro --scope user --transport http https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>

<Tab title="Codex">

```bash wrap
codex mcp add ayakaleaf-pro --url https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>
</Tabs>

Після додавання сервера розпочніть новий сеанс. Попросіть агента підтвердити, що він може шукати в документації Ayakaleaf Pro.

### Розгортання Ayakaleaf Pro

Відкрийте термінал на сервері, де виконуватиметься розгортання, і запустіть там Claude Code або Codex. Потім надішліть такий запит:

```text wrap
Use the Ayakaleaf Pro documentation MCP server to guide this deployment.
First, inspect the requirements and installation guides.
Ask me for missing deployment details before making changes.
Use the Ayakaleaf Toolkit unless the documentation requires another approach.
Before configuring the instance, summarize relevant optional features.
Ask which features and integrations I want to enable.
Include TLS, sandboxed compiles, Git integration, external MongoDB or Redis,
SSO (OIDC, SAML, or LDAP), GitHub Synchronisation, Zotero, S3 storage,
email delivery, branding, and localization when relevant.
Explain each selected option's prerequisites, security impact, and configuration steps.
Keep unselected optional features disabled.
Show each command before running it.
Do not expose, store, or request secrets in chat.
After deployment, verify that the service is healthy and summarize the changes.
```

Агент має провести вас через налаштування Docker, конфігурацію Toolkit, отримання образу та запуск. Еталонний порядок дій описано в посібнику [using-the-toolkit](/uk/on-premises/installation/using-the-toolkit  "mention").

### Вибір додаткових функцій

Попросіть агента рекомендувати лише ті функції, які підходять для вашого середовища. Типові варіанти:

* <strong>Доступ і безпека:</strong> TLS, ізольована компіляція (sandboxed compiles) та SSO через OIDC, SAML або LDAP.
* <strong>Зовнішні сервіси:</strong> MongoDB, Redis, сховище S3 і надсилання електронної пошти.
* <strong>Спільна робота:</strong> інтеграція з Git, синхронізація з GitHub і Zotero.

Перш ніж змінювати конфігурацію, агент має пояснити залежності. Перед увімкненням інтеграцій у виробничому середовищі ознайомтеся з [toolkit-settings.md](/uk/on-premises/configuration/overleaf-toolkit/toolkit-settings  "mention") і [authentication](/uk/on-premises/configuration/overleaf-toolkit/authentication  "mention").

### Перевірка розгортання

Коли агент виконає всі кроки:

1. Переконайтеся, що кожна команда завершилася без помилок.
2. Відкрийте налаштовану URL-адресу Ayakaleaf Pro у браузері.
3. Виконайте [6.-post-installation-tasks.md](/uk/on-premises/installation/using-the-toolkit/6.-post-installation-tasks  "mention").

Якщо у вас уже є інсталяція Community Edition, замість нового розгортання скористайтеся посібником [migrate-from-existing.md](/uk/on-premises/installation/migrate-from-existing  "mention").
