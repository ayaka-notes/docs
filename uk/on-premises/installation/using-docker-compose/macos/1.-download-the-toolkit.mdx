<Steps>
<Step title="Перевірте Git і Homebrew">
```bash
git --version
brew --version
```

Якщо під час запуску Git macOS пропонує встановити Command Line Tools, спершу встановіть їх. Якщо Homebrew відсутній, встановіть його за [офіційними інструкціями](https://brew.sh/).
</Step>

<Step title="Додайте GNU sed до PATH">
Скрипти Toolkit використовують параметри GNU sed, які вбудований у macOS BSD sed відхиляє. Встановіть [GNU sed](https://formulae.brew.sh/formula/gnu-sed) і поставте його першим у `PATH` у цьому терміналі:

```bash
brew install gnu-sed
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
sed --version
```

Остання команда має вивести **GNU sed**.

Псевдоніма на кшталт `alias sed=gsed` недостатньо: Toolkit запускає Bash-скрипти, які не бачать псевдонімів вашої інтерактивної оболонки. Замінювати `/usr/bin/sed` не потрібно.

Виконуйте рядок `export PATH=...` знову в кожному новому терміналі, який ви використовуєте для Toolkit, або додайте його до файлу запуску своєї оболонки після власної ініціалізації Homebrew.
</Step>

<Step title="Клонуйте репозиторій Ayakaleaf Toolkit">
Виберіть каталог, який зберігатиметься постійно. Для робочої бази даних і даних проєктів уникайте `/tmp`, знімних дисків і тек, що синхронізуються з хмарою, як-от iCloud Drive. Цей посібник використовує `~/ayakaleaf-toolkit`:

```bash
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

<Warning>

Якщо каталог уже містить інсталяцію, використовуйте її як є або виберіть інший каталог для нового екземпляра. Не ініціалізуйте нову конфігурацію поверх наявного розгортання.

</Warning>
</Step>
</Steps>
