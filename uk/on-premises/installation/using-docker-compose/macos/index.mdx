У цьому розділі ми запускаємо Ayakaleaf Pro локально на вашому Mac за допомогою Docker Desktop і [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). Посібник використовує `http://localhost:8080`, зберігає дані у вашому домашньому каталозі й компілює за допомогою TeX Live 2026 в ізольованих контейнерах.

Docker Desktop запускає застосунок, MongoDB, Redis і компілятор TeX Live у віртуальній машині Linux. Вам не потрібно встановлювати MongoDB, Redis чи MacTeX у самій macOS.

Використовуйте це налаштування для особистого користування та локального тестування. Для спільного сервісу, який працює постійно, ми рекомендуємо [посібник для Linux](/uk/on-premises/installation/using-docker-compose/linux) з HTTPS, резервним копіюванням і контролем доступу. Екземпляр недоступний, поки Mac перебуває в режимі сну або Docker Desktop зупинено, див. [Підтримання доступності екземпляра](/uk/on-premises/installation/using-docker-compose/macos/6.-post-installation-tasks#keep-the-instance-available).

## Перш ніж почати {#before-you-start}

Вам знадобляться:

* Версія macOS, яку підтримує [Docker Desktop for Mac](https://docs.docker.com/desktop/setup/install/mac-install/).
* Git, [Homebrew](https://brew.sh/) і GNU sed. Toolkit використовує параметри GNU sed, яких не приймає вбудований у macOS BSD sed.
* Достатньо ресурсів і для macOS, і для Docker. Для невеликого локального екземпляра почніть із 4 CPU і 8 ГБ пам'яті, виділених Docker Desktop. Це рекомендована відправна точка, а не виміряний мінімум.
* Щонайменше 40 ГБ вільного місця для повного образу TeX Live, а також місце для ваших проєктів. Перевірте як вільне місце на Mac, так і ліміт використання диска в Docker Desktop. Почніть з однієї версії TeX Live: кожна додаткова версія потребує приблизно стільки ж місця.

Образи застосунку та TeX Live публікуються для `arm64` і `amd64`. На Apple silicon дозвольте Docker вибрати нативний ARM-образ і не примушуйте `platform: linux/amd64`.
