Ayakaleaf Pro працює на Docker. На Mac використовується Docker Desktop, який запускає рушій Docker у віртуальній машині Linux.

<Steps>
<Step title="Встановіть і запустіть Docker Desktop">
Встановіть збірку [Docker Desktop](https://docs.docker.com/desktop/setup/install/mac-install/) для свого Mac (Apple silicon або Intel), відкрийте її та дочекайтеся запуску рушія. Також його можна запустити з Terminal:

```bash
open -a Docker
```
</Step>

<Step title="Перевірте рушій Docker">
Виконайте ці команди в Terminal:

```bash
docker context show
docker info
docker compose version
```

Контекст має вказувати на ваш локальний рушій Docker Desktop, зазвичай `desktop-linux`. Якщо вибрано інший контекст, перед продовженням перемкніться на Docker Desktop:

```bash
docker context use desktop-linux
```

`docker info` має вивести розділ **Server**. Сама лише команда `docker --version` показує тільки те, що клієнт встановлено.
</Step>

<Step title="Перевірте ресурси та спільний доступ до файлів">
У **Settings** Docker Desktop порівняйте ліміти CPU, пам'яті та диска з вимогами з розділу [Перш ніж почати](/uk/on-premises/installation/using-docker-compose/macos#before-you-start), а також перевірте налаштування спільного доступу до файлів, див. [Docker Desktop settings](https://docs.docker.com/desktop/settings-and-maintenance/settings/).

Цей посібник розміщує Toolkit у `/Users`, до якого Docker Desktop надає спільний доступ за замовчуванням. Якщо ви використовуєте інше розташування і `bin/up` завершується помилкою `Mounts denied`, додайте цей каталог до спільного доступу до файлів.
</Step>

<Step title="Перевірте сокет Docker для ізольованої компіляції">
Toolkit монтує `/var/run/docker.sock` у застосунок, щоб той міг запускати окремий контейнер TeX Live для кожної компіляції. Залиште `DOCKER_SOCKET_PATH=/var/run/docker.sock` у `config/overleaf.rc`.

Docker CLI на macOS може підключатися через `~/.docker/run/docker.sock`. Це кінцева точка клієнта на Mac, а не привід змінювати джерело монтування в Toolkit: компілятору потрібен сокет рушія в тому вигляді, в якому його бачать Linux-контейнери.

Якщо `/var/run/docker.sock` на Mac відсутній, увімкніть **Allow the default Docker socket to be used** у **Settings → Advanced**, див. [вимоги Docker до дозволів](https://docs.docker.com/desktop/setup/install/mac-permission-requirements/).

<Danger>

Не виконуйте `chmod 777` для сокета, щоб обійти помилки. Доступ до сокета Docker еквівалентний root-доступу до віртуальної машини Docker.

</Danger>
</Step>
</Steps>
