Ayakaleaf Pro — безкоштовний Docker-образ у [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Щоб завантажити його, не потрібні ні обліковий запис, ні вхід, ні комерційна ліцензія Overleaf.

Відкрийте `config/overleaf.rc` і задайте:

```bash title="config/overleaf.rc"
SERVER_PRO=true
```

Під час наступного запуску `bin/up` Toolkit завантажить `ghcr.io/ayaka-notes/overleaf-pro` у версії з `config/version` замість офіційної Overleaf Community Edition.

Образ зібрано для `arm64` і `amd64`, і Docker вибирає той, що відповідає вашому Mac. На Apple silicon не додавайте `platform: linux/amd64` у перевизначенні: тоді образ працюватиме в режимі емуляції.
