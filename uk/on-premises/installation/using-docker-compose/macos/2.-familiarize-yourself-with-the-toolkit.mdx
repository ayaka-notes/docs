Toolkit однаковий у macOS і Linux. Його структуру, каталог `config/` і команди `bin/` описано в розділі [2. Ознайомлення з Toolkit](/uk/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) посібника для Linux.

У macOS пам'ятайте про три відмінності:

* Запускайте скрипти з термінала, де GNU sed стоїть першим у `PATH`, див. [1. Завантаження Toolkit](/uk/on-premises/installation/using-docker-compose/macos/1.-download-the-toolkit).
* Запустіть Docker Desktop, перш ніж виконувати скрипт, який звертається до Docker, як-от `bin/up`, `bin/start` або `bin/docker-compose`.
* `bin/doctor` містить перевірки, успадковані від офіційного Overleaf Toolkit. Його попередження `This system seems to not be Linux` в macOS очікуване, а попередження про те, що ви не ввійшли в `quay.io`, не стосується публічного образу `ghcr.io/ayaka-notes/overleaf-pro`. Інші проблеми у звіті все ж важливі.
