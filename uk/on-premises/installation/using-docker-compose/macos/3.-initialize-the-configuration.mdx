---
title: 3. Ініціалізація конфігурації
description: Створіть конфігураційні файли Toolkit на своєму Mac за допомогою bin/init.
icon: circle-play
---

У каталозі Toolkit, у терміналі з GNU sed у `PATH`, виконайте:

```bash
bin/init
```

`bin/init` створює три файли:

| Файл | Призначення |
| --- | --- |
| `config/overleaf.rc` | Налаштування контейнера, опублікований порт і розташування даних |
| `config/variables.env` | Налаштування застосунку та секрети |
| `config/version` | Версія образу застосунку |

Також він генерує `OVERLEAF_INVITE_TOKEN_SECRET` у `config/variables.env`. Збережіть його й не публікуйте цей файл і не додавайте його до системи контролю версій.

Залиште версію, яку Toolkit вибирає для нової інсталяції. Щоб пізніше змінити версію наявного екземпляра, дотримуйтеся інструкцій з розділу [Оновлення розгортання](/uk/on-premises/maintenance/upgrading-your-deployment).

<Warning>

Якщо `bin/init` зупиняється з помилкою `sed: ... invalid command code`, його було запущено з BSD sed з macOS. Такий невдалий запуск може залишити всі три файли в `config/` з порожнім `OVERLEAF_INVITE_TOKEN_SECRET`, і повторний запуск `bin/init` тоді повідомляє `Config files already exist`. Див. [Усунення несправностей](/uk/on-premises/installation/using-docker-compose/macos/troubleshooting#initialization-fails-with-invalid-command-code).

</Warning>
