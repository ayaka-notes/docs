---
title: 4. Отримання образів Ayakaleaf Pro
icon: split
---

Ayakaleaf Pro — це безкоштовний образ Docker у [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/). Для його завантаження не потрібні ні обліковий запис, ні вхід. Образи зібрано для amd64 і arm64, і Docker вибирає той, що відповідає вашому серверу.

Відкрийте `config/overleaf.rc` і встановіть:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

Під час наступного запуску `bin/up` Toolkit завантажить образ Ayakaleaf Pro і використовуватиме його замість офіційної Overleaf Community Edition. Ваші налаштування в `config/` і далі працюватимуть.

<Accordion title="Уже використовуєте офіційний Overleaf Toolkit (overleaf/toolkit)?">

Перевстановлювати не потрібно. Завантажте образ Ayakaleaf Pro:

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Потім додайте до каталогу `overleaf-toolkit/config` файл з назвою `docker-compose.override.yml` з таким вмістом:

```yml
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

Під час наступного запуску `bin/up` Toolkit використовуватиме образ Ayakaleaf Pro.

</Accordion>
