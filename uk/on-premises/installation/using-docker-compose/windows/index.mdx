У цьому розділі ми запускаємо Ayakaleaf Pro локально у Windows за допомогою WSL 2, Ubuntu, Docker Desktop і [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit). Посібник використовує `http://localhost:8080`, зберігає дані в домашньому каталозі Ubuntu й вмикає ізольовану компіляцію.

Застосунок, MongoDB, Redis і TeX Live працюють у Linux-контейнерах під керуванням Docker Desktop. Виконуйте команди Toolkit в Ubuntu, а застосунок відкривайте у браузері Windows. У [кроці 0](/uk/on-premises/installation/using-docker-compose/windows/0.-setup-wsl-and-docker-desktop) пояснено, як поєднуються частини Windows і Linux, і він починається зі встановлення WSL.

Ви можете використовувати Windows для локального екземпляра або тримати його постійно запущеним за допомогою налаштувань доступності з кроку 6. Для спільних і продакшн-серверів ми рекомендуємо [посібник для Linux](/uk/on-premises/installation/using-docker-compose/linux) з HTTPS, резервним копіюванням і контролем доступу. Сплячий режим Windows, завершення роботи Docker Desktop і завершення роботи WSL переривають роботу цього локального екземпляра; див. [Підтримання доступності екземпляра](/uk/on-premises/installation/using-docker-compose/windows/6.-post-installation-tasks#keep-the-instance-available).

## Перш ніж почати {#before-you-start}

Вам знадобляться:

* Версія Windows і процесор, які підтримує [Docker Desktop for Windows](https://docs.docker.com/desktop/setup/install/windows-install/), з увімкненою апаратною віртуалізацією. Цей посібник використовує Windows 11 на x86-64.
* Дозвіл на ввімкнення WSL і встановлення програмного забезпечення. WSL має бути версії 2.1.5 або новішої, а Ubuntu має працювати в режимі WSL 2.
* Достатньо пам'яті для Windows і контейнерів. Для невеликого локального екземпляра 4 CPU і 8 ГБ, доступні Docker, — це рекомендована відправна точка, а не виміряний мінімум.
* Вільне місце на диску Windows, де зберігаються дані WSL і Docker. Передбачте щонайменше 40 ГБ для повного налаштування TeX Live разом із даними проєктів; базовий образ із [кроку 5](/uk/on-premises/installation/using-docker-compose/windows/5.-personalizing-your-instance) менший і підходить для початкової перевірки розгортання. Додаткові версії образів потребують додаткового місця.
* Мережевий доступ до GitHub, GitHub Container Registry (`ghcr.io`) і Docker Hub, щоб клонувати Toolkit і завантажувати образи.

Блоки **PowerShell** виконуються у Windows. Блоки **Bash** і команди `bin/` виконуються в Ubuntu, якщо не зазначено інше. Не запускайте скрипти Toolkit у PowerShell чи Windows Git Bash.
