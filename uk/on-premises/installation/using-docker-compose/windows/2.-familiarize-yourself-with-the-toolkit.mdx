Toolkit такий самий, як і в Linux. Його структуру, каталог `config/` і команди `bin/` описано в розділі [2. Ознайомлення з Toolkit](/uk/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) посібника для Linux.

У Windows пам'ятайте про такі відмінності:

* Виконуйте команди `bin/` в **Ubuntu Bash** з каталогу `~/ayakaleaf-toolkit`. Команди, позначені як **PowerShell**, натомість виконуються у Windows.
* Запустіть Docker Desktop і ввімкніть WSL Integration для Ubuntu, перш ніж використовувати `bin/up`, `bin/start` або `bin/docker-compose`.
* Зберігайте конфігураційні файли із закінченнями рядків Linux (LF). Редагуйте їх за допомогою `nano` в Ubuntu або в редакторі, підключеному до WSL. Закінчення рядків CRLF можуть спричиняти помилки Bash.
* `bin/doctor` виконує перевірки Linux всередині Ubuntu. Його попередження про те, що ви не ввійшли в `quay.io`, не стосується публічного образу `ghcr.io/ayaka-notes/overleaf-pro`. Інші попередження все ж потребують уваги.

```bash
bin/doctor
```
