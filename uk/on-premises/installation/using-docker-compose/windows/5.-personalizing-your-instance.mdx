description: Задайте порт, URL сайту та образ TeX Live, увімкніть ізольовану компіляцію і запустіть Ayakaleaf Pro на WSL 2.

Виконуйте команди й редагуйте файли в **Ubuntu**, у каталозі `~/ayakaleaf-toolkit`.

<Steps>
<Step title="Налаштування контейнера">
Відредагуйте наявні записи в `config/overleaf.rc`:

```bash title="config/overleaf.rc"
PROJECT_NAME=ayakaleaf-wsl
SERVER_PRO=true
OVERLEAF_LISTEN_IP=127.0.0.1
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
DOCKER_SOCKET_PATH=/var/run/docker.sock
```

Залиште шляхи до даних за замовчуванням і вбудовані сервіси MongoDB та Redis. Порт `8080` призначено для локального браузера Windows; прив'язка до `127.0.0.1` залишає його локальним. Ізольована компіляція використовує окремий Linux-контейнер для кожної компіляції замість запуску TeX всередині контейнера застосунку. Сокет Docker дає змогу застосунку створювати ці контейнери, а Toolkit надає шлях на хості для даних компіляції в `data/overleaf/data/compiles`.
</Step>

<Step title="Налаштування застосунку">
У `config/variables.env` задайте ці значення, замінивши всі активні записи з такими самими назвами:

```dotenv title="config/variables.env"
OVERLEAF_SITE_URL=http://localhost:8080
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES="TeX Live 2026"
```

Повний образ містить пакети та шрифти, потрібні для широкого кола проєктів. Передбачте для нього й застосунку щонайменше 40 ГБ вільного місця, а також місце для даних проєктів і майбутніх оновлень.

Для швидкої перевірки розгортання натомість використайте менший **базовий** образ. Його достатньо для перевірки простої статті в кроці 6, але він не містить повного набору пакетів і шрифтів:

```dotenv
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-basic:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-basic:2026.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES="TeX Live 2026 Basic"
```

Виберіть один із цих наборів, без дублювання активних ключів. [Dockerfile](https://github.com/ayaka-notes/texlive-full/blob/main/texlive/2026/Dockerfile.basic) базового образу містить `latexmk`, XeTeX і `fontspec`, але не `ctex` чи повну колекцію шрифтів. Відсутність пакета LaTeX у базовому образі сама по собі не вказує на проблему з ізоляцією.

Згенеруйте секрет сеансу:

```bash
openssl rand -hex 32
```

Додайте результат як `OVERLEAF_SESSION_SECRET` у `config/variables.env`. Також збережіть згенерований секрет для токенів запрошень. Для локального екземпляра без електронної пошти не задавайте налаштування SMTP та `OVERLEAF_EMAIL_FROM_ADDRESS`.
</Step>

<Step title="Запустіть свій екземпляр">
```bash
bin/up -d
```

Toolkit запускає MongoDB, ініціалізує її набір реплік, завантажує вибраний образ TeX Live, а потім запускає Redis і застосунок. Під час завантаження великого образу може здаватися, що процес зупинився. Не запускайте другий `bin/up`, поки перший ще працює.

В іншому терміналі Ubuntu перевірте:

```bash
cd "$HOME/ayakaleaf-toolkit"
bin/docker-compose ps
bin/docker-compose logs --tail=100 mongo
bin/docker-compose logs --tail=100 -f sharelatex
```

Натисніть `Ctrl+C`, щоб припинити стежити за журналами; контейнери, запущені у фоновому режимі, продовжать працювати. Якщо запуск зупиняється на MongoDB, перед повторною спробою виконайте кроки з розділу [MongoDB не запускається](/uk/on-premises/installation/using-docker-compose/windows/troubleshooting#mongodb-fails-to-start). Не видаляйте її каталог даних, щоб скинути наявну інсталяцію.

Перевірте порт і сторінку першого запуску:

```bash
bin/docker-compose port sharelatex 80
curl -I http://localhost:8080/launchpad
```

Порт має бути `127.0.0.1:8080`. Якщо HTTP-запит спершу не вдається, дочекайтеся завершення ініціалізації застосунку.
</Step>

<Step title="Відкрийте екземпляр з Windows">
У **браузері Windows** відкрийте [http://localhost:8080/launchpad](http://localhost:8080/launchpad). Використовуйте цю адресу і у Windows, а не тимчасову IP-адресу WSL.

Щоб перевірити HTTP-доступ з Windows окремо від браузера, виконайте в **PowerShell**:

```powershell
curl.exe -I http://localhost:8080/launchpad
```

Якщо Ubuntu може відкрити сторінку, а Windows — ні, див. [Windows не може відкрити localhost](/uk/on-premises/installation/using-docker-compose/windows/troubleshooting#windows-cannot-open-localhost).
</Step>
</Steps>
