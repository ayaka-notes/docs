<Steps>
<Step title="Встановіть інструменти командного рядка">
Виконайте в **Ubuntu**, використовуючи пароль Linux, створений у кроці 0:

```bash
sudo apt update
sudo apt install -y git ca-certificates curl perl gawk openssl
```

Ubuntu вже містить Bash, GNU sed і coreutils. На відміну від macOS, тут не потрібні ні Homebrew, ні окреме встановлення GNU sed.
</Step>

<Step title="Клонуйте репозиторій Ayakaleaf Toolkit">
Тримайте Toolkit і його дані у файловій системі Linux в Ubuntu, у своєму домашньому каталозі:

```bash
cd "$HOME"
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

Для робочої бази даних і даних проєктів уникайте `/mnt/c`, `/mnt/d`, OneDrive і тимчасових каталогів. Шляхи файлової системи Linux забезпечують дозволи й поведінку файлової системи, на які розраховують контейнери, і дають змогу уникнути накладних витрат між файловими системами; див. [рекомендації Microsoft щодо файлових систем](https://learn.microsoft.com/en-us/windows/wsl/filesystems).

<Warning>

Якщо каталог уже містить інсталяцію, використовуйте її як є або виберіть інший каталог для нового екземпляра. Не замінюйте конфігурацію чи дані наявного розгортання.

</Warning>
</Step>
</Steps>
