Docker Compose на одному сервері — рекомендований спосіб розгортання Ayakaleaf Pro. Ви запускаєте його через [Toolkit](https://github.com/ayaka-notes/toolkit): набір скриптів, які обгортають `docker compose` і зчитують ваші налаштування з одного каталогу `config/`, тож `bin/up` замінює `docker compose up`.
