Найпростіший спосіб випробувати наш Ayakaleaf Pro — скористатися GitHub Codespace, де всі змінні середовища попередньо налаштовано, тож усе працює одразу.

<Warning>

Коли ви запускаєте контейнери Docker у GitHub Codespaces, Codespace не вимикається автоматично і продовжує **тарифікуватися**. Правила тарифікації GitHub Codespaces див. у [правилах тарифікації github codespaces](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces).

Щоб керувати своїми GitHub Codespaces, перейдіть на [https://github.com/codespaces](https://github.com/codespaces). Коли Codespace більше не потрібен, своєчасно видаліть його.

</Warning>

Ми **попередньо налаштували** такі функції:

* [x] Компіляція LaTeX у пісочниці з TeXLive **Basic** (2024-2026)
* [x] Імпорт/експорт через Pandoc (функції SaaS-платформи)
* [x] Запуск Python-скриптів (функції SaaS-платформи)
* [x] Підтримка Git-Bridge (функції Server Pro)
* [x] Розширений пошук посилань (функції SaaS-платформи)
* [x] Панель адміністратора (глобальне керування користувачами/проєктами)
* [x] Відстеження змін (з панеллю рецензування та коментарів)
* [x] Повна історія проєкту (з відновленням і завантаженням)
* [x] Палітра символів (функції Server Pro/SaaS-платформи)

<Warning>

Стандартні GitHub Codespaces надають 32 ГБ сховища. Цього недостатньо для встановлення `texlive-full`. Щоб випробувати повний образ, створіть запит до підтримки GitHub на Codespace з великими раннерами (8+ ядер).

</Warning>

Синхронізацію з GitHub, LDAP, OAuth, SSO, інтеграцію з Zotero та інші функції в цьому тестовому середовищі _**не налаштовано**_. Докладніше про налаштування цих функцій у власному розгортанні див. у [налаштуваннях toolkit](/uk/on-premises/configuration/overleaf-toolkit/toolkit-settings).

<Steps>
<Step title="Створіть свій GitHub Codespace">
Натисніть кнопку нижче, щоб створити свій GitHub Codespace. Щодо конфігурації сервера, для тестування зазвичай достатньо **2 ядер і 8 ГБ оперативної пам'яті**. Якщо ви плануєте використовувати [**TeX Live Full**](https://github.com/ayaka-notes/texlive-full), радимо вибрати конфігурацію з **8 ядрами та 64 ГБ**.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/ayakaleaf-pro-playground)
</Step>

<Step title="Ініціалізуйте екземпляр Overleaf">
Коли ваш codespace буде готовий, виконайте в bash наведену нижче команду, щоб ініціалізувати екземпляр Overleaf.

```bash title="bash"

```

#### Використання повного образу TeXLive

Якщо у вас є доступ до GitHub Codespaces з 8 ядрами/64 ГБ, у цьому тестовому середовищі можна використовувати повний образ TeXLive. Змініть наведені нижче змінні середовища у файлі `toolkit/config/variables.env`, щоб використовувати образ TeXLive Full замість TeXLive Basic.

```dotenv wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1, ghcr.io/ayaka-notes/texlive-full:2024.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025, Texlive 2024
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```

Після зміни змінних середовища потрібно перезапустити toolkit, щоб застосувати зміни. Для перезапуску toolkit можна виконати таку команду.

```bash
cd toolkit && bin/up -d
```
