---
title: 0. Підготовка хоста
description: Перевірте операційну систему та SELinux і встановіть git перед налаштуванням rootless Podman.
icon: server
---

Встановлювати Podman вручну не потрібно: крок [2. Запуск podman-setup](/uk/on-premises/installation/using-podman/2.-run-podman-setup) встановлює його разом з іншими потрібними пакетами. Тут ви лише перевіряєте хост і встановлюєте `git`, потрібний для завантаження Toolkit.

<Steps>
<Step title="Перевірка операційної системи та SELinux">
Увійдіть у систему як користувач, який запускатиме Ayakaleaf Pro, а не як `root`, і перевірте дистрибутив і режим SELinux:

```bash title="Check the host"
grep PRETTY_NAME /etc/os-release
getenforce
```

Ви маєте побачити RHEL, Rocky Linux, AlmaLinux або CentOS Stream версії 9 чи новішої та `Enforcing`:

```text
PRETTY_NAME="Rocky Linux 9.9 (Blue Onyx)"
Enforcing
```
</Step>

<Step title="Перевірка доступу до sudo">
`bin/podman-setup --apply` встановлює пакети й завантажує модуль SELinux через `sudo` та запитує ваш пароль, коли це потрібно:

```bash title="Check sudo"
sudo -v
```

Якщо команда завершується помилкою, попросіть адміністратора додати вашого користувача до групи `wheel`.
</Step>

<Step title="Встановлення git">
```bash title="Install git"
sudo dnf install -y git
```

<Warning>

Не встановлюйте Docker Engine на цей хост. Пакет `podman-docker`, який встановлює `bin/podman-setup`, надає команду `docker`, а Toolkit вважає хост хостом Podman, щойно існує команда `podman`.

</Warning>
</Step>
</Steps>
