### Ініціалізація конфігурації

Ініціалізуймо конфігураційні файли нового сервера з розумними значеннями за замовчуванням, запустивши вбудований скрипт `bin/init`.

```text title="Run initialization"
bin/init
```

Цей скрипт **не** перезаписує жодних наявних конфігураційних файлів.

Тепер перевірмо вміст каталогу `config/` за допомогою команди `ls`:

```text title="List the config directory"
ls config
```

Якщо ініціалізація пройшла успішно, ви побачите три конфігураційні файли: `overleaf.rc`, `variables.env` і `version`. Це основні конфігураційні файли сервера, які дають змогу налаштувати роботу сервера та взаємодію користувачів із вашим екземпляром.

| Назва           | Опис                                                    |
| --------------- | ------------------------------------------------------- |
| `overleaf.rc`   | Основний конфігураційний файл верхнього рівня.          |
| `variables.env` | Змінні середовища, що завантажуються в контейнер Docker. |
| `version`       | Версія образу Docker, яку слід використовувати.         |

<Info>

Поки що достатньо знати, що ці файли існують і де їх знайти. Далі в документації ми детальніше розглянемо кожен файл і пояснимо, як за їх допомогою налаштувати ваш екземпляр. Якщо хочете забігти наперед, повний опис цих конфігураційних файлів наведено на сторінці [Files and locations](/uk/on-premises/configuration/overleaf-toolkit/files-and-locations).

</Info>
