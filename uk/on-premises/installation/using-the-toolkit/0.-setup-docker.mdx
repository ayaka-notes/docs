Overleaf працює на Docker. Потрібно встановити:

* Docker Engine (Docker CE)
* Плагін Docker Compose (`docker compose`, v2)

Ці кроки розраховані на актуальну Ubuntu LTS (20.04/22.04/24.04).

<Warning>

Не встановлюйте `docker.io` зі стандартного apt-репозиторію Ubuntu.\
Використовуйте офіційний репозиторій Docker, щоб отримати свіжу версію Docker і плагін `docker compose`.

</Warning>

Офіційна документація: [https://docs.docker.com/engine/install/ubuntu/](https://docs.docker.com/engine/install/ubuntu/).

<Steps>
<Step title="1) Видаліть старі/конфліктні пакети (якщо є)">
Якщо Docker раніше встановлювали з іншого джерела, спершу видаліть його:

```bash wrap
sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-compose-v2 docker-doc podman-docker containerd runc | cut -f1)
```

Ця команда безпечна, навіть якщо деякі пакети не встановлені.
</Step>

<Step title="2) Додайте офіційний apt-репозиторій Docker">
Встановіть передумови:

```bash
sudo apt update
sudo apt install -y ca-certificates curl
```

Додайте GPG-ключ Docker:

```bash wrap
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```

Додайте репозиторій:

```bash wrap
# Add the repository to Apt sources:
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Signed-By: /etc/apt/keyrings/docker.asc
EOF

sudo apt update
```
</Step>

<Step title="3) Встановіть Docker Engine + плагін Compose">
Встановіть Docker і плагін Compose:

```bash wrap
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

Увімкніть автозапуск Docker під час завантаження системи:

```bash
sudo systemctl enable --now docker
```
</Step>

<Step title="4) Перевірте інсталяцію">
Ці команди мають виконатися без помилок:

```bash
docker --version
docker compose version
sudo docker run --rm hello-world
docker ps
```
</Step>

<Step title="5) (Необов'язково) Запуск Docker без sudo">
Додайте свого користувача до групи `docker`:

```bash
sudo usermod -aG docker $USER
```

Потім **вийдіть із системи та увійдіть знову** або виконайте:

```bash
newgrp docker
```

Тепер це має працювати без `sudo`:

```bash
docker ps
```

<Danger>

Група `docker` має доступ до хоста, еквівалентний root.\
Це очікувано для типових інсталяцій Overleaf і особливо актуально, якщо ви вмикаєте ізольовану компіляцію.

</Danger>
</Step>
</Steps>
