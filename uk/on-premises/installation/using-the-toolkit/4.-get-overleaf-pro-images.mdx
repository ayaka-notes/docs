---
title: 4. Отримання образів Ayakaleaf Pro
icon: split
---

Ayakaleaf Pro розповсюджується як образ Docker у реєстрі [ghcr](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/) з **відкритим доступом** для всіх. Ми надаємо образи для архітектур amd64 і arm64. Під час завантаження образу відповідний варіант буде автоматично вибрано залежно від архітектури вашої системи.

#### Користувачі Ayaka-notes Toolkit

Якщо ви використовуєте [ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit), Ayakaleaf Pro можна застосувати як пряму заміну Community Edition, тож ви зможете використовувати наявні налаштування та кастомізації. Увімкніть Pro у Toolkit, відредагувавши `config/overleaf.rc` і встановивши змінну середовища `SERVER_PRO`:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

Під час наступного запуску `bin/up` Toolkit автоматично завантажить і використовуватиме образ Ayakaleaf Pro.

#### Користувачі офіційного Toolkit

Якщо ви використовуєте [overleaf/toolkit](https://github.com/overleaf/toolkit), щоб отримати образ Pro, виконайте таку команду:

```bash title="Pull Docker Images"
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

Потім додайте до каталогу `overleaf-toolkit/config` файл з назвою `docker-compose.override.yml` з таким вмістом:

```yml title="docker-compose.override.yml"
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

Під час наступного запуску `bin/up` Toolkit автоматично завантажить і використовуватиме образ Ayakaleaf Pro.
