### Завантаження Toolkit

Ayakaleaf Pro встановлюється за допомогою **Ayakaleaf Toolkit** ([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)) — набору скриптів, які запускають Overleaf у Docker за вас.

За замовчуванням Toolkit запускає безкоштовну офіційну Overleaf Community Edition (CE). Розділ [4. Отримання образів Ayakaleaf Pro](/uk/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images) перемикає його на Ayakaleaf Pro одним параметром.

<Accordion title="Уже використовуєте офіційний Overleaf Toolkit (overleaf/toolkit)?">

Перевстановлювати не потрібно. Залиште свою інсталяцію та виконайте останню частину розділу [4. Отримання образів Ayakaleaf Pro](/uk/on-premises/installation/using-the-toolkit/4.-get-overleaf-pro-images).

</Accordion>

<Steps>
<Step title="Клонуйте репозиторій Ayakaleaf Toolkit">
Щоб встановити toolkit, перейдіть до потрібного каталогу встановлення та клонуйте репозиторій Ayakaleaf Toolkit за допомогою цієї команди:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
```

<Info>

Щоб уникнути можливих проблем із правами доступу, рекомендуємо встановлювати Toolkit у каталог `$HOME` вашого користувача.

</Info>
</Step>

<Step title="Перейдіть до каталогу toolkit">
Дочекайтеся завершення клонування, а потім перейдіть до щойно створеного каталогу `overleaf-toolkit`:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
