### Завантаження Toolkit

Toolkit сумісний як із Server CE, так і з Ayakaleaf Pro, і є рекомендованим способом встановлення. Використання Toolkit дає змогу легко почати роботу з Server CE і за потреби безперешкодно перейти на Ayakaleaf Pro.

<Info>

[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) змінено так, щоб він використовував образ overleaf-pro безпосередньо з ghcr, а TeX Live надається ayaka-notes. Як альтернативу можна завантажити офіційний overleaf-toolkit.

</Info>

<Steps>
<Step title="Клонуйте репозиторій Overleaf Toolkit">
Щоб встановити toolkit, перейдіть до потрібного каталогу встановлення та клонуйте GitHub-репозиторій Overleaf Toolkit (@Ayaka-notes) за допомогою цієї команди:

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
# official toolkit (Not Recommended)
# git clone https://github.com/overleaf/toolkit.git ./overleaf-toolkit
```

<Info>

Щоб уникнути можливих проблем із правами доступу, рекомендуємо встановлювати Toolkit у каталог `$HOME` вашого користувача.

</Info>
</Step>

<Step title="Перейдіть до каталогу toolkit">
Дочекайтеся завершення клонування, а потім перейдіть до щойно створеного каталогу `overleaf-toolkit`:

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
