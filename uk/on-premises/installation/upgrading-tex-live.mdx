<Danger>

Наведені нижче інструкції стосуються **лише** інсталяцій **Community Edition**. Ми наполегливо рекомендуємо користувачам Ayakaleaf Pro увімкнути [Sandboxed Compiles](/uk/on-premises/configuration/overleaf-toolkit/sandboxed-compiles), оскільки це надає доступ майже до тих самих образів TeX Live, що використовуються на [overleaf.com](https://www.overleaf.com), а також забезпечує ізоляцію між компіляціями проєктів для підвищення безпеки.

</Danger>

Щоб заощадити трафік, образи Overleaf Community Edition і Ayakaleaf Pro містять лише мінімальну інсталяцію [TeX Live](https://www.tug.org/texlive/). Ви можете встановити більше пакетів або оновитися до повної інсталяції TeX Live за допомогою команди [tlmgr](https://www.tug.org/texlive/tlmgr.html) у контейнері `sharelatex`.

#### Вхід у контейнер sharelatex

Щоб запустити оболонку всередині контейнера `sharelatex`, виконайте

```bash
bin/shell
```

Ви побачите запрошення такого вигляду:

```bash
root@309b192d4030:/#
```

У наведених нижче інструкціях ми припускаємо, що ви перебуваєте всередині контейнера.

#### Визначення поточної версії TeX Live

TeX Live випускається щороку приблизно у квітні. Кроки використання `tlmgr` відрізняються залежно від того, чи використовуєте ви поточний випуск, чи старіший. Перевірити, яку версію TeX Live ви використовуєте, можна за допомогою `tlmgr --version`. Наприклад, ця інсталяція працює на TeX Live 2021:

```bash
# tlmgr --version
tlmgr revision 59291 (2021-05-21 05:14:40 +0200)
tlmgr using installation: /usr/local/texlive/2021
TeX Live (https://tug.org/texlive) version 2021
```

<Info>

Поточний випуск TeX Live можна знайти на [домашній сторінці TeX Live](https://www.tug.org/texlive/).

</Info>

Якщо у вас старіша версія TeX Live, є два варіанти. Нова версія Docker-образу Overleaf зазвичай виходить невдовзі після випуску TeX Live, тож ви можете дочекатися її та оновити своє розгортання за допомогою скрипта `bin/upgrade`, або, якщо бажаєте залишитися на старішому випуску TeX Live, спершу потрібно вказати `tlmgr` використовувати історичний репозиторій. Інструкції щодо цього можна знайти [тут](https://www.tug.org/texlive/acquire.html#past).

#### Встановлення пакетів

Щоб отримати повну інсталяцію TeX Live, виконайте цю команду всередині контейнера `sharelatex`:

```text
tlmgr install scheme-full
```

Також можна встановлювати окремі пакети вручну:

```bash
tlmgr install tikzlings tikzmarmots tikzducks
```

<Warning>

Починаючи з випуску `3.3.0`, після кожного використання `tlmgr install` знову **необхідно** виконувати `tlmgr path add`, щоб правильно створити символьні посилання на всі виконувані файли в системному шляху.

</Warning>

Доступно ще багато інших команд. Дізнатися більше можна так:

```text
tlmgr help
```

Коли закінчите, введіть `exit` або натисніть Control-D, щоб вийти з оболонки.

#### Збереження змін

Щойно внесені зміни змінили контейнер `sharelatex`, але вони тимчасові — їх буде втрачено, якщо Docker Compose перестворить контейнер, наприклад під час оновлення конфігурації.

Щоб зробити їх постійними, скористайтеся `docker commit` і збережіть зміни в новий Docker-образ:

```bash
cat config/version #5.2.1
docker commit sharelatex sharelatex/sharelatex:5.2.1-with-texlive-full
echo 5.2.1-with-texlive-full > config/version
```

Після фіксації змін відповідно оновіть `config/version`. Потім виконайте `bin/up`, щоб перестворити контейнер `sharelatex`.

<Danger>

Ці кроки доведеться повторювати щоразу, коли ви [оновлюєтеся](https://github.com/overleaf/toolkit/blob/master/doc/upgrading.md) до нової версії Overleaf.

</Danger>
