[Toolkit](/uk/on-premises/installation/using-docker-compose) — рекомендований спосіб запуску Ayakaleaf Pro на одному сервері. Якщо у вас уже є кластер Kubernetes, у цьому розділі той самий контейнер розгортається в ньому за допомогою звичайних маніфестів `kubectl`: без додаткового образу, без Helm-чарту.

Наприкінці цього розділу у вас буде один екземпляр Ayakaleaf Pro з ізольованою компіляцією, набір реплік MongoDB і Redis — усе в просторі імен `overleaf`. Щоб запустити кілька екземплярів за балансувальником навантаження, після цього перейдіть до розділу [Горизонтальне масштабування](/uk/on-premises/configuration/kubernetes/horizontal-scaling).

<Info>

Підтримка Kubernetes експериментальна. Ми не публікуємо Helm-чарт чи образи, специфічні для Kubernetes. Маніфести на цих сторінках — ті, які ми перевірили на Kubernetes 1.37 (kubeadm, containerd 2.4, flannel) із трьома вузлами по 2 vCPU і 4 ГБ пам'яті кожен. Адаптуйте сховище, мережу та ingress під свій кластер.

</Info>

### Як поєднуються компоненти {#how-the-pieces-fit}

| Toolkit (один сервер)                        | Kubernetes                                                               |
| -------------------------------------------- | ------------------------------------------------------------------------ |
| `config/variables.env`                       | ConfigMap `overleaf-env` і Secret `overleaf-secrets`                     |
| контейнер `sharelatex`                       | Deployment `overleaf` (один под, у якому працюють усі служби Overleaf)   |
| контейнери `mongo` і `redis`                 | StatefulSet `mongo` (набір реплік) і `redis` або ваші керовані сервіси   |
| `~/overleaf-toolkit/data/overleaf`           | PersistentVolumeClaim `overleaf-data`                                    |
| Docker на хості, що використовується для компіляцій | Docker Engine на кожному вузлі, де працює Ayakaleaf Pro           |
| `bin/up`, `bin/logs`, `bin/shell`            | `kubectl apply`, `kubectl logs`, `kubectl exec`                          |

### Що вам потрібно {#what-you-need}

* Кластер Kubernetes, на вузли якого можна встановлювати пакети: кожному вузлу, на якому може працювати Ayakaleaf Pro, потрібен **Docker Engine**, бо компіляції виконуються в контейнерах TeX Live, які Ayakaleaf Pro запускає через `/var/run/docker.sock` вузла. Див. [0. Підготовка вузлів](/uk/on-premises/installation/using-kubernetes/0.-prepare-the-nodes).
* StorageClass за замовчуванням із томами `ReadWriteOnce`.
* `kubectl` і `openssl` на вашій робочій станції.
