description: Внесіть свої налаштування в ConfigMap, який замінює config/variables.env.

---

ConfigMap `overleaf-env` займає місце `config/variables.env` з Toolkit: сюди потрапляє кожна змінна середовища з [документації Toolkit](/uk/on-premises/configuration/overleaf-toolkit/environment-variables), а секрети — у Secret з [кроку 2](/uk/on-premises/installation/using-kubernetes/2.-create-the-namespace-and-secrets).

```yaml title="30-config.yaml" wrap
apiVersion: v1
kind: ConfigMap
metadata:
  name: overleaf-env
  namespace: overleaf
data:
  OVERLEAF_APP_NAME: Ayakaleaf Pro
  OVERLEAF_SITE_URL: http://192.0.2.10:30080      # the address users open; https://... behind TLS
  OVERLEAF_ADMIN_EMAIL: admin@example.com
  # Emails: add the sender and the SMTP server together, see Email delivery
  # All members, so that the driver finds the primary even when mongo-0 is down
  OVERLEAF_MONGO_URL: mongodb://mongo-0.mongo:27017,mongo-1.mongo:27017,mongo-2.mongo:27017/sharelatex?replicaSet=overleaf
  OVERLEAF_REDIS_HOST: redis
  REDIS_HOST: redis
  ENABLED_LINKED_FILE_TYPES: project_file,project_output_file,url
  ENABLE_CONVERSIONS: "true"
  EMAIL_CONFIRMATION_DISABLED: "true"
  # Requests arrive from kube-proxy or your ingress controller, inside the pod network
  OVERLEAF_TRUSTED_PROXY_IPS: loopback,10.244.0.0/16
  # Sandboxed compiles. The HOST_DIR paths are paths ON THE NODE: the hostPath volumes that
  # the Deployment mounts at /var/lib/overleaf/data/{compiles,output,cache}.
  SANDBOXED_COMPILES: "true"
  SANDBOXED_COMPILES_SIBLING_CONTAINERS: "true"
  DOCKER_RUNNER: "true"
  SANDBOXED_COMPILES_HOST_DIR_COMPILES: /srv/overleaf/compiles
  SANDBOXED_COMPILES_HOST_DIR_OUTPUT: /srv/overleaf/output
  SANDBOXED_COMPILES_HOST_DIR_CACHE: /srv/overleaf/cache
  # Each image must be pulled into Docker on every node that can run Ayakaleaf Pro (step 0)
  ALL_TEX_LIVE_DOCKER_IMAGES: ghcr.io/ayaka-notes/texlive-full:2026.1
  ALL_TEX_LIVE_DOCKER_IMAGE_NAMES: TeX Live 2026
  TEX_LIVE_DOCKER_IMAGE: ghcr.io/ayaka-notes/texlive-full:2026.1
```

```bash
kubectl apply -f 30-config.yaml
```

| Змінна                                  | Значення                                                                                                                                                        |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_SITE_URL`                     | URL-адреса, яку користувачі вводять у браузері. З NodePort з [кроку 5](/uk/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro) — IP-адреса будь-якого вузла та порт `30080`; за ingress чи балансувальником навантаження — його URL-адреса. |
| `OVERLEAF_MONGO_URL`                    | Ваш набір реплік. Використовуйте `?replicaSet=` з іменем із `rs.initiate`.                                                                                     |
| `OVERLEAF_REDIS_HOST` і `REDIS_HOST`    | Обидві — на Service Redis.                                                                                                                                     |
| `OVERLEAF_TRUSTED_PROXY_IPS`            | `loopback` плюс мережі, з яких підключаються ваші проксі. `10.244.0.0/16` — мережа подів flannel; використовуйте CIDR подів вашого кластера.                  |
| `SANDBOXED_COMPILES_HOST_DIR_*`         | Шляхи на вузлі до томів компіляції. Вони мають збігатися з томами `hostPath` на [кроці 5](/uk/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro). |

За HTTPS також встановіть `OVERLEAF_SECURE_COOKIE: "true"`, див. [TLS-проксі](/uk/on-premises/configuration/overleaf-toolkit/tls-proxy).

<Info>

Змінений ConfigMap потрапляє в запущені поди лише після перезапуску: `kubectl -n overleaf rollout restart deployment/overleaf`.

</Info>
