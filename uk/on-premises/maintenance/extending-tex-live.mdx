Наявний образ TeX Live можна розширити за допомогою нового Dockerfile і налаштувати застосунок на використання нового образу.

Тут ми наводимо деякі рекомендації щодо встановлення нових пакетів або шрифтів, проте налаштування власного образу не входить до умов нашої підтримки.

Образи TeX Live оновлюються нечасто. Радимо перезбирати власні образи під час оновлення Server Pro.

<Danger>

Наведені нижче розділи стосуються лише Server Pro та [Sandboxed Compiles](/uk/on-premises/configuration/overleaf-toolkit/sandboxed-compiles).

</Danger>

### Встановлення та оновлення нових пакетів

Для керування пакетами Tex Live можна використовувати команди `tlmgr`, як-от `tlmgr install` і `tlmgr update`, як у наведеному прикладі:

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2023.1

RUN tlmgr update --force ebproof
```

### Використання `tlmgr` у старішому образі TeX Live

За замовчуванням `tlmgr` завантажує ресурси з останнього випуску TeX Live. Під час внесення змін у старіший образ TeX Live завантаження потрібно переключити на відповідний архів. Список дзеркал архівів дивіться на [https://www.tug.org/historic/](https://www.tug.org/historic/).

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2022.1

RUN tlmgr option repository <MIRROR>/systems/texlive/<YEAR>/tlnet-final
# e.g. RUN tlmgr option repository ftp://tug.org/historic/systems/texlive/2022/tlnet-final

RUN tlmgr update --force ebproof
```

### Встановлення нових шрифтів

Існують різні процедури встановлення нових шрифтів у дистрибутив Tex Live, і встановлення власного шрифту може вимагати кількох кроків. Ймовірно, хорошою відправною точкою буде ознайомлення з [інструкціями зі встановлення шрифтів TeX](https://tug.org/fonts/fontinstall.html) в офіційній документації Tex Live.

Наведений нижче `Dockerfile` показує приклад встановлення шрифту TrueType поверх наявного образу Tex Live 2022:

```dockerfile
FROM ghcr.io/ayaka-notes/texlive-full:2022.1

COPY ./myfonts/*.ttf /usr/share/fonts/truetype/myfont/

# rebuild font information cache
RUN fc-cache
```

### Налаштування Server Pro на використання нових образів

Для збирання нового образу використовуйте назву `ghcr.io/ayaka-notes/texlive-full` і власний тег, наприклад:

```bash
docker build -t ghcr.io/ayaka-notes/texlive-full:2023.1-custom
```

Тепер можна налаштувати Server Pro на використання нового образу `2023.1-custom`, оновивши змінні середовища `TEX_LIVE_DOCKER_IMAGE` і `ALL_TEX_LIVE_DOCKER_IMAGES`:

```text wrap
TEX_LIVE_DOCKER_IMAGE: "ghcr.io/ayaka-notes/texlive-full:2023.1-custom"
ALL_TEX_LIVE_DOCKER_IMAGES: "ghcr.io/ayaka-notes/texlive-full:2023.1,ghcr.io/ayaka-notes/texlive-full:2023.1-custom"
```

У наведеному прикладі нові проєкти за замовчуванням використовуватимуть новий образ `2023.1-custom`, а `2023.1` і далі залишається доступним, коли він знадобиться.
