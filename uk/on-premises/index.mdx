### Огляд Overleaf

Overleaf — це редактор LaTeX для спільної роботи, який полюбляють дослідники та технічні команди. Його хмарна версія доступна на [overleaf.com](https://www.overleaf.com/). Вона надає повнофункціональний онлайн-редактор LaTeX. Однак Overleaf Common (SaaS-версія) має численні функціональні обмеження, і вам доводиться миритися з _**10-секундним обмеженням часу компіляції**_ та дорогими членськими внесками.

Хоча Overleaf пропонує відкриту версію для спільноти (доступну на [GitHub: Overleaf](https://github.com/overleaf/overleaf)), вона також має багато обмежень, наприклад:

<Warning>

Overleaf Community Edition призначено для використання в середовищах, де **всі** користувачі є довіреними. Community Edition **не** підходить для сценаріїв, які потребують ізоляції користувачів, оскільки в ній недоступна функція Sandbox Compiles.

Без ізоляції компіляції LaTeX виконуються з тими самими привілеями, що й контейнер, і мають доступ до його файлової системи, мережі та змінних середовища. Це створює ризик витоку даних або компрометації системи. Неізольовані компіляції слід використовувати лише в повністю довірених середовищах; для багатокористувацьких і виробничих розгортань настійно рекомендується Sandbox Compiles.

Докладніше про Sandbox Compiles дивіться: [sandboxed-compiles.md](/uk/on-premises/configuration/overleaf-toolkit/sandboxed-compiles  "mention")

</Warning>

### Інформація та ціни на Overleaf Server Pro

На вебсайті Overleaf є лише форма для зв'язку зі службою підтримки щодо Server Pro, тому інформації про Server Pro дуже мало. Але, за даними, зібраними нами в спільноті, **умови для Server Pro такі**:

* Потрібно придбати ліцензії _щонайменше_ на 10 осіб.
* Ліцензія на 10 осіб коштує приблизно €3 477,61. (2024)
* Для освітніх закладів 20 користувачів коштують 2640 євро на рік, 50 користувачів — 6050 євро, а 100 користувачів — 9963 євро.
* Server Pro доступний лише в окремих регіонах (наприклад, за винятком материкового Китаю).

Згідно з наявною на сьогодні інформацією, Overleaf Server Pro коштує приблизно \$300 на користувача на рік за мінімальної покупки 10 ліцензій, що робить його дуже дорогим варіантом. Крім того, Server Pro пропонує значно менше функцій, ніж Ayakaleaf Pro. Ми щиро вдячні розробникам зі спільноти, чий багаторічний внесок дав нам змогу створити Ayakaleaf Pro і зрештою перевершити Overleaf Server Pro як за функціональністю, так і за можливостями.

Наведені нижче публічні записи містять задокументовані закупівлі та ціни Overleaf Server Pro. Невеликі контракти в США вказують на річну вартість приблизно \$320–\$370 на користувача. Великі інституційні угоди можуть передбачати нижчу ціну на користувача. Наприклад, трирічна угода Товариства Макса Планка в середньому становить близько €51 на користувача на рік. Умови контрактів, підтримка та обсяг розгортання можуть відрізнятися. Ці записи не є офіційним прайс-листом Overleaf.

### Чому Ayakaleaf Pro?

<Info>

Ayakaleaf Pro _**не**_ пов'язаний з Overleaf, Inc. чи її материнською компанією Digital Science. Це також _не редакція Server Pro_, яка є комерційним продуктом Overleaf, Inc. [ayaka-notes](https://github.com/ayaka-notes) розробляє та підтримує Ayakaleaf Pro як незалежний проєкт.

</Info>

Ayakaleaf Pro — це розширена реалізація Overleaf Community Edition, що пропонує _**всі**_ функції Server Pro як _**безкоштовні преміум-можливості**_. На відміну від загальнодоступного Overleaf на [https://www.overleaf.com/](https://www.overleaf.com/) або комерційної редакції Server Pro, у нас:

* _**немає обмежень**_ на час компіляції
* _**немає ліцензійних**_ обмежень на кількість користувачів
* _**всі функції**_ Server Pro розблоковано
