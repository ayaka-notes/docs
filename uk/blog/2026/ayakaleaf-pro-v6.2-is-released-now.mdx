З гордістю оголошуємо про випуск Ayakaleaf Pro 6.2 — найпотужнішого та найфункціональнішого онлайн-редактора LaTeX у спільноті. Особлива подяка yu-i-i та davrot за їхній цінний внесок: вони вдосконалили GitHub Sync і додали розширений пошук цитувань та інтеграцію з Zotero.

### Примітки

* Запроваджено нову обов'язкову змінну середовища `OVERLEAF_INVITE_TOKEN_SECRET`; її потрібно згенерувати командою `openssl rand -base64 32`. Якщо її не налаштовано, ваш екземпляр Overleaf не запуститься.
* Якщо ви вмикаєте GitHub Sync, необхідно налаштувати змінну середовища `GITHUB_TOKEN_CIPHER_PASSWORD`. Ця змінна потрібна для безпечного шифрування токенів доступу GitHub. Без неї ваш екземпляр Overleaf не запуститься.
* Додано нову змінну середовища `DEFAULT_LATEX_COMPILER` для задання типового компілятора нових проєктів (pdflatex, latex, xelatex або lualatex).
* Оновлений редактор тепер є єдиним доступним варіантом.

### Зміни

Цей випуск містить такі вдосконалення та нові функції.

* `MAX_UPLOAD_SIZE` тепер можна налаштовувати, а не обмежено значенням **50 MB**.
* Виправлено циклічний перезапуск контейнера, коли ізольовану компіляцію (sandboxed compiles) було вимкнено.
* Для OAuth2 запроваджено видалення PAT лише в межах власника.
* Виправлено проблему з імпортом LDAP.

Нові функції:

* Додано запуск Python у браузері.
* Додано підтримку Pandoc для імпорту й експорту Markdown, DOCX та інших форматів.
* Додано GitHub Sync.
* Додано повний китайський переклад.
* Додано інтеграцію з Zotero.
* Додано `DEFAULT_LATEX_COMPILER`.

#### Функція 01: GitHub Sync

Синхронізуйте свої проєкти LaTeX з репозиторіями GitHub для безперебійного робочого процесу. Надсилайте й отримуйте зміни безпосередньо з редактора, співпрацюйте через pull request-и та інтегруйтеся з наявними конвеєрами CI/CD. Система контролю версій полегшує відстеження редакцій, перегляд змін і підтримку відтворюваності наукових чи технічних документів.

Дивіться: [Синхронізація з GitHub](/uk/on-premises/configuration/overleaf-toolkit/github-synchronisation  "mention").

#### Функція 02: імпорт/експорт через Pandoc

Імпортуйте документи Microsoft Word і Markdown у повністю редаговані проєкти LaTeX або експортуйте проєкти LaTeX назад у Markdown і DOCX одним клацанням. Ця функція на основі Pandoc забезпечує безшовну сумісність між науковим письмом, спільним редагуванням і видавничими процесами, максимально зберігаючи структуру документа.

Дивіться: [Імпорт і експорт через Pandoc](/uk/on-premises/configuration/overleaf-toolkit/pandoc-import-and-export  "mention").

#### Функція 03: розширений пошук джерел

Шукайте та вставляйте бібліографічні посилання з кількох наукових баз даних з інтелектуальною фільтрацією та миттєвою підтримкою цитування. Швидко знаходьте статті, переглядайте метадані й створюйте точні записи BibTeX без перемикання між різними дослідницькими вебсайтами, що значно підвищує ефективність огляду літератури.

#### Функція 04: запуск Python

Виконуйте код Python безпосередньо у своєму проєкті, не виходячи з редактора. Чудово підходить для створення рисунків, обробки наборів даних, автоматизації роботи з документами чи запуску відтворюваних дослідницьких скриптів. Результати можна інтегрувати у ваші документи LaTeX, об'єднуючи наукові обчислення та написання тексту в єдиний робочий процес.

![зображення](https://github.com/user-attachments/assets/a4c314b3-fdb5-4836-aea7-12eeece5cd2f)

#### Функція 05: Zotero

Під'єднайте свою бібліотеку Zotero безпосередньо до робочого процесу написання й керуйте джерелами, не виходячи з редактора. Шукайте у своїх особистих колекціях Zotero, вставляйте цитування одним клацанням і автоматично генеруйте та синхронізуйте записи BibTeX. Ця інтеграція підтримує вашу бібліографію в актуальному стані, спрощуючи керування літературою для наукових статей, дисертацій і технічних документів.

Дивіться: [Інтеграція з Zotero](/uk/on-premises/configuration/overleaf-toolkit/zotero-integration  "mention").
