Віддає файли з об'єктного сховища: файли шаблонів (zip, pdf і їхні зображення попереднього перегляду) та, лише для читання, проєктні й глобальні блоби, які записує history-v1. Викликається web (модуль template-gallery, URL файлів компіляції) і clsi, який завантажує з нього бінарні файли проєкту.

* <strong>Адреса:</strong> `http://filestore:3009`, всередині мережі Docker
* <strong>Автентифікація:</strong> немає
* <strong>Файл OpenAPI:</strong> [`develop/hoppscotch/openapi/filestore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/filestore.yaml)
