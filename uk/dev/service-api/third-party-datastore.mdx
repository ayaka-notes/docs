Синхронізує проєкти з Dropbox: тримає по одній черзі завдань Redis на користувача та воркер, який надсилає зміни Overleaf у Dropbox і опитує Dropbox щодо змін. Викликає його лише web, щоб ставити завдання в чергу й читати розміри черг.

* <strong>Адреса:</strong> `http://third-party-datastore:3002`, всередині мережі Docker
* <strong>Автентифікація:</strong> немає
* <strong>Файл OpenAPI:</strong> [`develop/hoppscotch/openapi/third-party-datastore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/third-party-datastore.yaml)
