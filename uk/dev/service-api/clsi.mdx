CLSI (Common LaTeX Service Interface) компілює проєкти, запускає SyncTeX і texcount над результатом компіляції та конвертує документи за допомогою pandoc. Його викликає web; самі вихідні файли віддає clsi-nginx, а не цей порт. Без автентифікації: доступний лише всередині мережі Docker.

* <strong>Адреса:</strong> `http://clsi:3013`, всередині мережі Docker
* <strong>Автентифікація:</strong> немає
* <strong>Файл OpenAPI:</strong> [`develop/hoppscotch/openapi/clsi.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/clsi.yaml)
