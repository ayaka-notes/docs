Зберігає сповіщення, які користувачі бачать у списку проєктів (наприклад, запрошення до проєктів), у колекції Mongo `notifications`. Його викликають web і third-party-datastore; автентифікації немає, доступний лише всередині мережі Docker.

* <strong>Адреса:</strong> `http://notifications:3042`, всередині мережі Docker
* <strong>Автентифікація:</strong> немає
* <strong>Файл OpenAPI:</strong> [`develop/hoppscotch/openapi/notifications.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/notifications.yaml)
