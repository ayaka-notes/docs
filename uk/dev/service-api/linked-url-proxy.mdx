Завантажує зовнішній URL для web і передає відповідь потоком назад, відхиляючи внутрішні адреси, щоб користувачі не могли потрапити в мережу Docker. Через нього web надсилає URL-файли, імпорт Open in Overleaf і web_fetch ШІ-агента.

* <strong>Адреса:</strong> `http://linked-url-proxy:3066`, всередині мережі Docker
* <strong>Автентифікація:</strong> немає
* <strong>Файл OpenAPI:</strong> [`develop/hoppscotch/openapi/linked-url-proxy.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/linked-url-proxy.yaml)
