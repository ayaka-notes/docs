Зберігає чат проєкту та гілки коментарів (їхні повідомлення й статус «вирішено») у колекціях Mongo `rooms` і `messages`. Викликається web через `ChatApiHandler`.

* <strong>Адреса:</strong> `http://chat:3010`, всередині мережі Docker
* <strong>Автентифікація:</strong> немає
* <strong>Файл OpenAPI:</strong> [`develop/hoppscotch/openapi/chat.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/chat.yaml)
