Зберігає кожен документ (рядки, версію, діапазони) кожного проєкту в колекції Mongo `docs` і архівує документи в об'єктне сховище, якщо задано бекенд. Викликається web; document-updater звертається до нього через web.

* <strong>Адреса:</strong> `http://docstore:3016`, всередині мережі Docker
* <strong>Автентифікація:</strong> немає
* <strong>Файл OpenAPI:</strong> [`develop/hoppscotch/openapi/docstore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/docstore.yaml)
