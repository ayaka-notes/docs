Зберігає повну історію кожного проєкту: фрагменти змін у Mongo або Postgres та об'єктному сховищі, а вміст файлів у вигляді блобів. project-history записує до нього зміни; web, project-history і git-bridge читають із нього блоби, знімки та zip-архіви.

* <strong>Адреса:</strong> `http://history-v1:3100`, всередині мережі Docker
* <strong>Автентифікація:</strong> HTTP basic auth від імені `staging` з `STAGING_PASSWORD` або JWT, залежно від маршруту.
* <strong>Файл OpenAPI:</strong> [`develop/hoppscotch/openapi/history-v1.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/history-v1.yaml)
