---
title: Оновлення перекладів i18n
icon: language
---

Існує файл `services/web/frontend/extracted-translations.json`; вебзастосунок Overleaf використовує лише витягнуті переклади з цього файлу.

Якщо ви додали новий вміст, виконайте таку команду, щоб оновити витягнуті переклади.

```bash
user ➜ ~/overleaf-pro/develop (server-pro) $ bin/shell webpack
root@432836260f8a:/overleaf/services/web# npm run extract-translations
```

Загалом, будь ласка, не редагуйте текстові файли перекладів і насамперед використовуйте наявні рядки, оскільки всі ці файли оновлюються з upstream-репозиторію Overleaf або зі сторонніх сайтів перекладу.
