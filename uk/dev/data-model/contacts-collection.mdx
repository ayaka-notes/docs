`contacts` запам'ятовує, з якими користувачами працював користувач, щоб діалог спільного доступу міг їх пропонувати. Один документ на користувача. Власником є `web`, схеми Mongoose немає; код: `services/web/app/src/Features/Contacts/ContactManager.mjs`.

#### Поля {#fields}

| Поле | Тип | Значення | Джерело |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id документа, створюється під час upsert. | `ContactManager.mjs:5-12` |
| `user_id` | ObjectId | Користувач, якому належать ці контакти. Один документ на користувача. | `ContactManager.mjs:6` |
| `contacts` | Object | Словник, ключем якого є id користувача-контакту (рядком). | `ContactManager.mjs:8-9` |
| `contacts.<userId>.n` | Number | Скільки разів двох користувачів було зведено разом. | `ContactManager.mjs:8` |
| `contacts.<userId>.ts` | Date | Коли це сталося востаннє. | `ContactManager.mjs:9` |

#### Хто записує {#who-writes-it}

| Код | Що робить |
| --- | --- |
| `ContactManager.mjs:4-13` (`touchContact`), `:23-28` (`addContact`) | Виконує upsert документів обох користувачів: `$inc` для `n`, `$set` для `ts`. |
| `services/web/app/src/Features/Collaborators/CollaboratorsHandler.mjs:155-157` | `addUserIdToProject` викликає `addContact`, коли йому передано користувача, що додає: під час прийняття запрошення (той, хто запросив, і запрошений, `services/web/app/src/Features/Collaborators/CollaboratorsInviteHandler.mjs:199-205`) і під час передавання власності (новий і попередній власник, `services/web/app/src/Features/Collaborators/OwnershipTransferHandler.mjs:138-144`). Приєднання за посиланням спільного доступу не передає користувача, що додає (`services/web/app/src/Features/TokenAccess/TokenAccessController.mjs:386-388`, `:632-634`), тому контакт не додається. |

#### Хто читає {#who-reads-it}

| Код | Що робить |

| `ContactManager.mjs:15-21`, `:30-42` | `getContactIds`: сортує за `n`, потім за `ts`, обидва за спаданням. |
| `services/web/app/src/Features/Contacts/ContactController.mjs:19-59` | `GET /user/contacts` (`services/web/app/src/Features/Contacts/ContactRouter.mjs:22-26`): повертає перші 50 як користувачів, без тимчасових облікових записів, а також те, що модулі додають через хук `getContacts`. |

#### Примітки {#notes}

* Контакти взаємні: додавання B до проєкту A робить B контактом A, а A стає контактом B.
* Ніщо не видаляє контакт чи документ, навіть видалення користувача.
