---
title: Колекція Project History Sharded Blobs
icon: cubes-stacked
---

`projectHistoryShardedBlobs` зберігає записи blob, які не вмістилися в [projectHistoryBlobs](/dev/data-model/project-history-blobs-collection): коли кошик для префікса хешу там уже має 8 записів, наступні потрапляють сюди. Проєкт має тут щонайбільше 16 документів, по одному на першу шістнадцяткову цифру хешу. Схеми Mongoose немає; history-v1 записує її в `services/history-v1/storage/lib/blob_store/mongo.js` (структуру описано в `mongo.js:1-16`).

#### Поля {#fields}

| Поле | Тип | Значення | Джерело |
| ----- | ---- | ------- | ------ |
| `_id` | Binary | 13 байтів: ідентифікатор історії проєкту, `0`, і цифра шарда, що читається як шістнадцяткова (`<history id>0<digit>`). Цифра шарда — перша шістнадцяткова цифра хешу. | `mongo.js:439-453` |
| `blobs` | Object | Записи blob, згруповані в кошики. Ключ кошика — шістнадцяткові цифри хешу з 2-ї по 4-ту. | `mongo.js:439-443` |
| `blobs.<bcd>` | Array of Object | Записи кошика. Код не обмежує його розмір. | `mongo.js:399-407` |
| `blobs.<bcd>[].h` | Binary | Хеш, 20 байтів, як у projectHistoryBlobs. | `mongo.js:472` |
| `blobs.<bcd>[].b` | Number | Довжина вмісту в байтах. | `mongo.js:473` |
| `blobs.<bcd>[].s` | Number | Довжина вмісту як тексту; `null`, якщо вміст не є редагованим текстом. | `mongo.js:474` |

#### Хто записує {#who-writes-it}

| Код | Що робить |
| ---- | ------------ |
| `services/history-v1/storage/lib/blob_store/mongo.js:399-407` | `insertRecordSharded`: upsert з `$addToSet` у кошик. Викликається `insertBlob`, коли кошик у projectHistoryBlobs заповнений (`mongo.js:387-389`). |
| `mongo.js:75-103` | `clone`: копіює шарди проєкту на інший ідентифікатор історії, для history-v1 `POST /projects/:project_id/clone`, який ніщо у web не викликає. |
| `mongo.js:413-422` | `deleteBlobs`: видаляє всі шарди проєкту разом із його документом projectHistoryBlobs, під час history-v1 `DELETE /projects/:project_id`. |

#### Хто читає {#who-reads-it}

| Код | Що робить |
| ---- | ------------ |
| `mongo.js:144-157` | `findBlobSharded`: один blob; шукається, лише коли його кошик у projectHistoryBlobs має 8 записів і не містить його (`mongo.js:127-131`). |
| `mongo.js:217-260` | `findBlobsSharded`: blob, які `findBlobs` не знайшов у projectHistoryBlobs (`mongo.js:202-206`). |
| `mongo.js:285-306` | `getProjectBlobs`: усі шарди проєкту. |
| `mongo.js:337-361` | `getProjectBlobsBatch`: усі шарди кількох проєктів, для маршруту статистики blob. |

#### Індекси {#indexes}

Лише типовий індекс `_id`. Жодна міграція в `tools/migrations/` не додає індексу.

#### Примітки {#notes}

* Шарди одного проєкту лежать поруч у порядку `_id`, тож код знаходить їх діапазоном `_id` від `<history id>00` до `<history id>0f` (`mongo.js:75-80`, `287-295`).
* Колекція з’являється лише тоді, коли в якогось проєкту понад 8 blob з однаковим тризначним префіксом хешу, тож на невеликому екземплярі її може не бути зовсім.
