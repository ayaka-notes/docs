title: Колекція Project Invites

`projectInvites` зберігає запрошення, які власник проєкту надсилає з вікна спільного доступу. Один документ відповідає одному запрошенню на одну адресу email. Документ видаляється, коли запрошення прийнято або відкликано, або Mongo видаляє його після закінчення строку. Схема: `services/web/app/src/models/ProjectInvite.mjs`, а записує її `services/web/app/src/Features/Collaborators/CollaboratorsInviteHandler.mjs`.

Запрошення нікого не робить учасником. Учасники зберігаються в масивах `*_refs` проєкту, див. [Колекція Projects](/uk/dev/data-model/projects-collection).

| `email` | String | Адреса, на яку надіслано запрошення. Під час відкликання запрошення для користувача її порівнюють із підтвердженими адресами користувача (`CollaboratorsInviteHandler.mjs:103-116`). Не задається для запрошення за посиланням спільного доступу. | `ProjectInvite.mjs:16`, `CollaboratorsInviteHandler.mjs:84` |
| `tokenHmac` | String | HMAC-SHA256 (ключ `overleaf-token-invite`) токена з посилання запрошення. #### Примітки {#notes}

* Якщо під час прийняття запрошення `readAndWrite` або `review` у проєкті не залишилося вільних місць для редакторів, користувач приєднується лише з правом читання і потрапляє до `pendingEditor_refs` або `pendingReviewer_refs` проєкту (`CollaboratorsInviteHandler.mjs:162-205`).
* Старі запрошення зберігали вихідний токен у полі `token`. Міграція `20240524135408_add_token_hmac_project_invite_tokens.mjs` додала `tokenHmac`, а `20240531082910_remove_project_invite_tokens.mjs` видалила `token`.
* Ніщо не видаляє запрошення видаленого проєкту; вони залишаються, доки їх не видалить TTL-індекс.
