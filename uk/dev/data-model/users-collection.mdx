title: Колекція Users

---

`User` представляє окремий обліковий запис користувача в системі Overleaf. Він зберігає дані автентифікації, прапорці функцій, налаштування редактора, права доступу та метадані активності.

#### Основна ідентичність і автентифікація

* `_id`: унікальний MongoDB ObjectId користувача.
* `email` / `emails`: основна електронна адреса та історичні записи адрес.
* `hashedPassword`: пароль, хешований BCrypt, що використовується для локальної автентифікації.
* `first_name` / `last_name`: поля імені в профілі користувача.
* `role` / `isAdmin` / `adminRoles`: прапорці ролі та адміністративних привілеїв.
* `twoFactorAuthentication`: конфігурація двофакторної автентифікації (якщо ввімкнено).
* `samlIdentifiers` / `thirdPartyIdentifiers`: прив'язки до зовнішніх постачальників ідентичності.

#### Стан і життєвий цикл облікового запису

* `signUpDate`: часова позначка створення облікового запису.
* `holdingAccount`: чи очікує обліковий запис підтвердження або чи він обмежений.
* `must_reconfirm`: вказує, чи має користувач повторно підтвердити свою електронну адресу.
* `lastPrimaryEmailCheck`: час останньої перевірки основної електронної адреси.

#### Відстеження входів і активності

* `lastLoginIp`: IP-адреса останнього успішного входу.
* `loginCount`: загальна кількість успішних входів.
* `loginEpoch`: внутрішній лічильник сеансів входу.
* `lastLoggedIn`: часова позначка останнього входу.
* `lastActive`: часова позначка останньої зафіксованої активності.
* `lastFailedLogin`: часова позначка останньої невдалої спроби входу.

#### Налаштування редактора (`ace`)

Визначає налаштування користувача для онлайн-редактора:

* `theme` / `overallTheme`: тема редактора та інтерфейсу.
* `fontSize`: розмір шрифту редактора.
* `autoComplete`, `autoPairDelimiters`: функції допомоги під час редагування.
* `spellCheckLanguage`: мова перевірки орфографії.
* `pdfViewer`: вибраний бекенд для перегляду PDF.
* `syntaxValidation`, `mathPreview`, `breadcrumbs`: функції UX редактора.
* `enableNewEditor`: чи ввімкнено новий інтерфейс редактора.

#### Прапорці функцій і обмеження (`features`)

Керує доступністю функцій для користувача:

* `collaborators`: максимальна кількість співавторів (`-1` = без обмежень).
* `versioning`, `trackChanges`: функції історії та відстеження змін.
* `dropbox`, `github`, `gitBridge`: доступність зовнішніх інтеграцій.
* `compileTimeout`: максимальний час компіляції (у секундах).
* `compileGroup`: призначена група ресурсів компіляції.
* `aiErrorAssistant`: прапорець ШІ-помічника для помилок компіляції.

#### Контроль доступу та права персоналу (`staffAccess`)

Визначає детальні права доступу для персоналу або видавців:

* Права на метрики та керування для видавців, установ, груп, адміністраторів і експериментів.

#### Реєстрація та інтеграції

* `enrollment.sso`: пов'язані реєстрації SSO.
* `refProviders`: інтеграції з постачальниками бібліографічних посилань.
* `writefull`: стан облікового запису помічника з письма Writefull.
* `dsMobileApp`: конфігурація мобільного застосунку (якщо є).

#### Програми та експерименти

* `alphaProgram` / `betaProgram` / `labsProgram`: участь у програмах раннього доступу.
* `labsExperiments`: увімкнені експериментальні функції.
* `awareOfV2`: чи ознайомився користувач із редактором V2.

#### Реферали та навчальні посібники

* `referal_id`, `refered_users`, `refered_user_count`: відстеження рефералів.
* `completedTutorials`: прогрес проходження вступних посібників і посібників з функцій.
