---
title: Колекція System Messages
icon: bullhorn
---

`systemmessages` зберігає банери для всього сайту, які адміністратор публікує для всіх користувачів, що увійшли. Кожен документ описує одне повідомлення. Власником є `web`; схема: `services/web/app/src/models/SystemMessage.mjs`, код: `services/web/app/src/Features/SystemMessages/SystemMessageManager.mjs`.

#### Поля {#fields}

| Поле | Тип | Значення | Джерело |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id повідомлення. За цим id браузер запам'ятовує, які повідомлення користувач закрив (`services/web/frontend/js/shared/components/system-message.tsx:10`). | `SystemMessage.mjs:5` |
| `content` | String | Текст повідомлення, за замовчуванням `''`. | `SystemMessage.mjs:7` |
| `__v` | Number | Ключ версії Mongoose, додається `message.save()`. | `SystemMessageManager.mjs:29-30` |

#### Хто записує {#who-writes-it}

| Код | Що робить |
| --- | --- |
| `SystemMessageManager.mjs:28-33` (`createMessage`) | `POST /admin/messages` (`services/web/app/src/router.mjs:1150-1152`, `services/web/app/src/Features/ServerAdmin/AdminController.mjs:151-159`): додає одне повідомлення. |
| `SystemMessageManager.mjs:22-26` (`clearMessages`) | `POST /admin/messages/clear` (`router.mjs:1155-1157`, `AdminController.mjs:161-168`): видаляє всі повідомлення. Видалити лише одне неможливо. |

#### Хто читає {#who-reads-it}

| Код | Що робить |
| --- | --- |
| `SystemMessageManager.mjs:50-65` | Кожен процес `web` тримає всі повідомлення в пам'яті й перезавантажує їх кожні 20-30 секунд, а також одразу після власного створення чи очищення. |
| `services/web/app/src/Features/SystemMessages/SystemMessageController.mjs:6-24` | `GET /system/messages` (`router.mjs:331`): повертає кешовані повідомлення користувачам, що увійшли. Поки сайт закритий (`siteIsOpen` дорівнює false), натомість повертає фіксоване сповіщення, яке не зберігається в Mongo. |
| `AdminController.mjs:83-84` | Сторінка `/admin` виводить повідомлення безпосередньо з Mongo. |

#### Індекси {#indexes}

Жодна міграція не створює індекс для `systemmessages`; існує лише типовий індекс `_id`.

#### Примітки {#notes}

* Якщо задано `notifyOnSystemMessageChanges`, створення чи очищення також публікується в канал Redis `refresh-system-messages`, і інші процеси `web` одразу перезавантажують повідомлення (`SystemMessageManager.mjs:9`, `:35-48`, `:75-87`). Без цього вони підхоплять зміну під час наступного планового перезавантаження.
