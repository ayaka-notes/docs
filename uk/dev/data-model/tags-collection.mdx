`tags` зберігає теги (папки), за якими користувач розкладає проєкти на панелі проєктів. Кожен документ описує один тег одного користувача. Власником є `web`; схема: `services/web/app/src/models/Tag.mjs`, а всі записи проходять через `services/web/app/src/Features/Tags/TagsHandler.mjs`.

#### Поля {#fields}

| Поле | Тип | Значення | Джерело |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id тегу, використовується в маршрутах `/tag/:tagId`. | `Tag.mjs:10` |
| `user_id` | String | Власник тегу. Звичайний рядок, а не ObjectId, з історичних причин. | `Tag.mjs:7-12` |
| `name` | String | Назва тегу, не більше 50 символів (`MAX_TAG_LENGTH`). Унікальна в межах користувача. | `Tag.mjs:13`, `TagsHandler.mjs:4` |
| `color` | String | Необов'язковий колір: шістнадцятковий код на кшталт `#a1b2c3` або значення `hsl(<n>, 70%, 45%)` (`TAG_COLOR_REGEX`). | `Tag.mjs:5`, `Tag.mjs:14-22` |
| `project_ids` | Array of String | Id проєктів у цьому тегу, у вигляді рядків. | `Tag.mjs:23` |
| `__v` | Number | Ключ версії Mongoose, додається, коли `Tag.create` створює документ. | `TagsHandler.mjs:27` |

#### Індекси {#indexes}

| Назва | Ключі | Параметри | Міграція |
| --- | --- | --- | --- |
| `user_id_1_name_1` | `{ user_id: 1, name: 1 }` | unique | `tools/migrations/20190912145029_create_tags_indexes.mjs` |

Та сама міграція створила й `user_id_1`; `tools/migrations/20231031164732_drop_redundant_indexes.mjs` знову видаляє його, бо складений індекс його покриває.

#### Примітки {#notes}

* Теги належать окремому користувачу: два співавтори одного проєкту зберігають для нього кожен свої теги.
* `user_id` і `project_ids` є рядками, тому запитуйте їх за рядковими id, а не за ObjectId.
* Видалення користувача (`services/web/app/src/Features/User/UserDeleter.mjs`) не зачіпає `tags`.
