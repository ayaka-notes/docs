---
title: Колекція Project History Labels
icon: tag
---

`projectHistoryLabels` зберігає мітки, які користувачі ставлять на версії в поданні History, по одному документу на мітку. Власник колекції — project-history, він записує її в `services/project-history/app/js/LabelsManager.js`; схеми Mongoose немає. Web звертається до неї лише через API project-history.

#### Поля {#fields}

| Поле | Тип | Значення | Джерело |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Ідентифікатор мітки. | `LabelsManager.js:81-85` |
| `project_id` | ObjectId | Проєкт. | `LabelsManager.js:73` |
| `comment` | String | Текст мітки. | `LabelsManager.js:74` |
| `version` | Number | Версія історії проєкту, на яку вказує мітка. | `LabelsManager.js:75` |
| `created_at` | Date | Коли створено мітку; запит може передати власний час, інакше береться поточний. | `LabelsManager.js:70`, `76` |
| `user_id` | ObjectId | Хто створив мітку. Відсутнє, якщо в запиті немає користувача. | `LabelsManager.js:78-80` |

#### Хто записує {#who-writes-it}

| Код | Що робить |
| ---- | ------------ |
| `services/project-history/app/js/LabelsManager.js:44-90` | `createLabel`: вставляє мітку, для project-history `POST /project/:project_id/labels` (`services/project-history/app/js/HttpController.js:1134-1171`). Web викликає його, коли користувач додає мітку, з ідентифікатором користувача (`services/web/app/src/Features/History/HistoryController.mjs:529-546`). |
| `LabelsManager.js:113-126` | `deleteLabel`: видаляє мітку проєкту, для `DELETE /project/:project_id/labels/:label_id`. Web використовує його, коли власник проєкту видаляє мітку (`HistoryController.mjs:649-670`). |
| `LabelsManager.js:92-111` | `deleteLabelForUser`: видаляє мітку, лише якщо її створив цей користувач, для `DELETE /project/:project_id/user/:user_id/labels/:label_id`. Web використовує його для всіх інших. |
| `LabelsManager.js:128-143` | `transferLabels`: переносить усі мітки одного користувача іншому, для `POST /user/:from_user/labels/transfer/:to_user` (`services/project-history/app/js/Router.js:52-55`). Ніщо у web не викликає цей маршрут. |
| `LabelsManager.js:7-25` | `cloneLabels`: копіює мітки проєкту в інший проєкт, для project-history `POST /project/:project_id/clone` (`HttpController.js:113`), який ніщо у web не викликає. |

#### Хто читає {#who-reads-it}

| Код | Що робить |
| ---- | ------------ |
| `LabelsManager.js:27-42` | `getLabels`: усі мітки проєкту, повертаються як `{ id, comment, version, user_id, created_at }` (`LabelsManager.js:163-171`). Використовується `GET /project/:project_id/labels` (`HttpController.js:1076-1100`), який web викликає для подання History, доповнюючи імена користувачів (`HistoryController.mjs:488-499`). |
| `services/project-history/app/js/SummarizedUpdatesManager.js:57` | Додає мітки до списку оновлень історії. |

#### Примітки {#notes}

* Перед вставкою мітки project-history обробляє оновлення проєкту в черзі та перевіряє, що history-v1 має chunk для цієї версії, якщо тільки запит не передає `validate_exists: false` (`LabelsManager.js:53-59`, `173-195`; `HttpController.js:1109-1115`).
* Жоден код не видаляє мітки проєкту під час видалення проєкту: project-history `DELETE /project/:project_id` очищає лише стан синхронізації та запис про збій (`HttpController.js:1363-1396`), а інші сервіси цієї колекції не торкаються.
