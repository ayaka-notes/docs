title: Колекція Messages

`messages` зберігає по одному документу на повідомлення: рядок у чаті проєкту або коментар чи відповідь у гілці коментарів рецензування. Записує в неї лише сервіс chat, у `services/chat/app/js/Features/Messages/MessageManager.js`. Схеми Mongoose немає. Кожне повідомлення належить кімнаті з колекції [rooms](/uk/dev/data-model/rooms-collection).

#### Поля {#fields}

| Поле | Тип | Значення | Джерело |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Ідентифікатор повідомлення. | `MessageManager.js:13-14` |
| `room_id` | ObjectId | Кімната (`rooms._id`), а не ідентифікатор проєкту чи гілки. | `MessageManager.js:8,106-108` |
| `user_id` | ObjectId | Автор. | `MessageManager.js:9,103-105` |
| `content` | String | Текст повідомлення, від 1 до 10240 символів (`MAX_MESSAGE_LENGTH`). | `MessageManager.js:7`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:3,12-15` |
| `timestamp` | Number | Час надсилання в мілісекундах від 1970 року (`Date.now()`), не Date. | `MessageManager.js:10`, `services/chat/app/js/Features/Messages/MessageHttpController.js:288` |
| `edited_at` | Number | Час останнього редагування в мілісекундах (`Date.now()`). Відсутній, якщо повідомлення не редагували. | `MessageManager.js:65-69`, `MessageHttpController.js:189,213` |

#### Хто записує {#who-writes-it}

| Код | Що робить |
| ---- | ------------ |
| `MessageManager.js:5-16` `createMessage` | Вставляє повідомлення (`MessageHttpController.js:275-294`). Web надсилає повідомлення чату проєкту з `services/web/app/src/Features/Chat/ChatController.mjs:32`, а коментарі з модуля track-changes (`services/web/modules/track-changes/app/src/TrackChangesController.mjs:95`) і модуля mcp-server (`services/web/modules/mcp-server/app/src/CommentTools.mjs:133`). |
| `MessageManager.js:51-72` `updateMessage` | Встановлює `content` і `edited_at`. Якщо передано ідентифікатор користувача, збігається лише повідомлення цього користувача (`MessageManager.js:62-64`). Викликається з `ChatController.mjs:135` і `TrackChangesController.mjs:110`. |
| `MessageManager.js:74-80` `deleteMessage` | Видаляє одне повідомлення. Викликається з `ChatController.mjs:105` і `TrackChangesController.mjs:129`. |
| `MessageManager.js:39-49` `deleteAllMessagesInRoom(s)` | Видаляє повідомлення видаленої гілки (`MessageHttpController.js:172-173`) або всього проєкту, коли спливає термін видаленого проєкту (`MessageHttpController.js:261-271`, викликається з `services/web/app/src/Features/Project/ProjectDeleter.mjs:391`). |
| `MessageManager.js:115-127` `duplicateRoomToOtherRoom` | Копіює `content`, `timestamp` і `user_id` кожного повідомлення в іншу кімнату, без `edited_at`. Використовується, коли відновлення історії дублює гілку (`MessageHttpController.js:316-342`), і коли проєкт копіюється разом із діапазонами (`MessageHttpController.js:344-357`). |

#### Хто читає {#who-reads-it}

| Код | Що робить |
| ---- | ------------ |
| `MessageManager.js:18-29` `getMessages` | Спочатку нові, не більше `limit` (за замовчуванням 50), старші за `before` (значення `timestamp`). Використовується для чату проєкту (`ChatController.mjs:80`). |
| `MessageManager.js:31-37` `findAllMessagesInRooms` | Усі повідомлення кількох кімнат: для списку гілок панелі рецензування (`TrackChangesController.mjs:82`), модуля mcp-server (`CommentTools.mjs:83`) і відновлення історії (`services/web/app/src/Features/History/RestoreManager.mjs:259`). Web також перевіряє перше повідомлення гілки, щоб рецензент міг змінювати лише гілки, які він почав (`services/web/app/src/Features/Authorization/AuthorizationManager.mjs:409-411`). |
| `MessageManager.js:90-100` `getMessage` | Одне повідомлення. Web перевіряє його `user_id`, перш ніж користувач відредагує або видалить своє повідомлення (`services/web/app/src/Features/Authorization/AuthorizationMiddleware.mjs:253-257`, `TrackChangesController.mjs:124-125`). |

#### Примітки {#notes}

* Щоб знайти повідомлення коментаря, спочатку знайдіть кімнату за `project_id` і `thread_id`, потім виконайте запит за `room_id`. Ідентифікатор коментаря в документі — це `thread_id`, а не `room_id`.
* Текст, на який вказує коментар, — це `op.c` у `docs.ranges.comments`; обговорення зберігається тут.
