title: Колекція Projects
icon: rectangle-vertical-history
---

`Project` представляє окремий LaTeX-проєкт в Overleaf. Він зберігає метадані проєкту, інформацію про власника та керування доступом, файлову структуру, налаштування компіляції та стан спільної роботи.

#### Основна ідентифікація та метадані

* `_id`: унікальний MongoDB ObjectId, що ідентифікує проєкт.
* `name`: відображувана назва проєкту.
* `description`: необов'язковий текстовий опис проєкту.
* `active`: показує, чи проєкт наразі активний.
* `version`: внутрішня версія схеми або формату проєкту.
* `trashed`: список елементів, переміщених до кошика (м'яке видалення).
* `deletedDocs`: записи про остаточно видалені документи.

#### Власність і керування доступом

* `owner_ref`: посилання на користувача, якому належить проєкт.
* `collaberator_refs`: користувачі з правами редагування.
* `reviewer_refs`: користувачі з доступом рівня рецензента.
* `readOnly_refs`: користувачі з доступом лише для читання.
* `pendingEditor_refs` / `pendingReviewer_refs`: очікувані запрошення.

#### Доступ на основі токенів

* `tokens`: реєстр токенів для спільних посилань.
* `tokenAccessReadOnly_refs`: токени, що надають доступ лише для читання.
* `tokenAccessReadAndWrite_refs`: токени, що надають доступ для читання й запису.

#### Відстеження активності

* `lastUpdated`: позначка часу останньої зміни.
* `lastUpdatedBy`: користувач, який виконав останнє оновлення.
* `lastOpened`: позначка часу, коли проєкт востаннє відкривали.
* `deletedByExternalDataSource`: чи було видалення ініційоване зовнішньою інтеграцією.

#### Структура проєкту

Кореневий документ і папка

* `rootDoc_id`: ObjectId головного вхідного LaTeX-документа (зазвичай `main.tex`).
* `rootFolder`: вбудоване представлення файлового дерева проєкту.

Кожен запис папки містить:

* `name` / `_id`: назву та ідентифікатор папки.
* `docs`: список вихідних LaTeX-документів з назвою та `_id`.
* `fileRefs`: посилання на бінарні файли (зображення, файли даних), зокрема:
  * `name`: ім'я файлу
  * `created`: позначка часу завантаження
  * `rev`: лічильник ревізій
  * `hash`: хеш вмісту для дедуплікації
  * `linkedFileData`: зв'язок із зовнішнім сховищем (якщо є)
* `folders`: вкладені підпапки.

#### Налаштування компіляції та редактора

* `compiler`: вибраний рушій LaTeX (`pdflatex`, `xelatex`, `lualatex` тощо).
* `spellCheckLanguage`: мова перевірки орфографії для цього проєкту.

#### Налаштування публічності та спільного доступу

* `publicAccesLevel`: видимість проєкту (`private`, `readOnly`, `public` тощо).
* `collabratecUsers`: пов'язані користувачі із зовнішніх платформ для спільної роботи.

#### Специфічні розширення Overleaf

* `overleaf.history`:
  * `id`: ідентифікатор, який використовує служба історії.
  * `display`: чи увімкнена та видима історія.

#### Внутрішнє версіонування

* `__v`: внутрішній ключ версії Mongoose для керування паралельним доступом.
