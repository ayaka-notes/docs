---
title: Колекція Spelling Preferences
icon: spell-check
---

`spellingPreferences` зберігає словник кожного користувача: слова, які користувач додав через "Add to dictionary" у перевірці правопису редактора. Один документ на користувача. Власником є `web`, схеми Mongoose немає; код: `services/web/app/src/Features/Spelling/LearnedWordsManager.mjs`.

#### Поля {#fields}

| Поле | Тип | Значення | Джерело |
| --- | --- | --- | --- |
| `_id` | ObjectId | Id документа, створюється під час upsert. | `LearnedWordsManager.mjs:21-31` |
| `token` | String | Id користувача. Попри назву, маршрути правопису передають id користувача, що увійшов (`SessionManager.getLoggedInUserId`). | `LearnedWordsManager.mjs:23` |
| `learnedWords` | Array of String | Слова, які додав користувач. | `LearnedWordsManager.mjs:26` |

#### Хто записує {#who-writes-it}

| Код | Що робить |
| --- | --- |
| `LearnedWordsManager.mjs:13-32` (`learnWord`) | `POST /spelling/learn` (`services/web/app/src/router.mjs:1037-1041`, `services/web/app/src/Features/Spelling/SpellingController.mjs:45-58`): `$addToSet` слова з upsert. Відмовляє, якщо список перевищить `Settings.maxDictionarySize` байтів. |
| `LearnedWordsManager.mjs:38-47` (`unlearnWord`) | `POST /spelling/unlearn` (`router.mjs:1043-1047`, `SpellingController.mjs:66-79`): `$pull` слова. |
| `LearnedWordsManager.mjs:84-86` (`deleteUsersLearnedWords`) | Видаляє документ. Його єдину обгортку, `SpellingHandler.deleteUserDictionary` (`services/web/app/src/Features/Spelling/SpellingHandler.mjs:24-26`), ніхто не викликає ні в web, ні в його модулях. |

#### Хто читає {#who-reads-it}

| Код | Що робить |
| --- | --- |
| `LearnedWordsManager.mjs:52-67` (`getLearnedWords`) | Повертає слова без дублікатів. |
| `services/web/app/src/Features/Project/ProjectController.mjs:671` | Надсилає словник у редактор під час відкриття проєкту (`SpellingHandler.getUserDictionary`). |

#### Примітки {#notes}

* Індекс не унікальний; upsert за `token` зберігає один документ на користувача.
* Видалення користувача не видаляє цей документ.
