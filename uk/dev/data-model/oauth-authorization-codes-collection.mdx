---
title: Колекція OAuth Authorization Codes
icon: lock-open
---

`oauthAuthorizationCodes` призначена для кодів потоку OAuth authorization code: один документ на код, який клієнт обмінює на токен доступу. Схема: `services/web/app/src/models/OauthAuthorizationCode.mjs`, а код, що писав би до неї, є у вебмодулі `oauth2-server`. В Ayakaleaf Pro до цього коду нічого не доходить, тому колекція залишається порожньою (див. Примітки).

#### Поля {#fields}

| Поле | Тип | Значення | Джерело |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | Id документа. | `OauthAuthorizationCode.mjs:6` |
| `authorizationCode` | String | Сам код, зберігається як є (без хешування). | `OauthAuthorizationCode.mjs:8`, `services/web/modules/oauth2-server/app/src/OAuth2Model.mjs:280` |
| `expiresAt` | Date | Кінець строку дії. Після нього `getAuthorizationCode` відхиляє код, а TTL-індекс видаляє його. | `OauthAuthorizationCode.mjs:9`, `OAuth2Model.mjs:150-153,281` |
| `oauthApplication_id` | ObjectId | Клієнт в [OAuth Applications](/uk/dev/data-model/oauth-applications-collection), який запросив код. | `OauthAuthorizationCode.mjs:10`, `OAuth2Model.mjs:275-284` |
| `redirectUri` | String | URI переспрямування запиту. | `OauthAuthorizationCode.mjs:11`, `OAuth2Model.mjs:282` |
| `scope` | String | Запитаний scope. | `OauthAuthorizationCode.mjs:12`, `OAuth2Model.mjs:283` |
| `user_id` | ObjectId | Користувач, який надав код. | `OauthAuthorizationCode.mjs:13`, `OAuth2Model.mjs:285` |
| `codeChallenge`, `codeChallengeMethod` | String | PKCE challenge і його метод. | `OauthAuthorizationCode.mjs:14-15`, `OAuth2Model.mjs:286-287` |

#### Хто записує {#who-writes-it}

| Код | Що робить |
| ---- | ------------ |
| `OAuth2Model.mjs:274-300` (`saveAuthorizationCode`) | Вставляє код. Не викликається, див. Примітки. |
| `OAuth2Model.mjs:307-312` (`revokeAuthorizationCode`) | Видаляє код після використання. Не викликається. |

#### Хто читає {#who-reads-it}

| Код | Що робить |
| ---- | ------------ |
| `OAuth2Model.mjs:137-177` (`getAuthorizationCode`) | Завантажує код разом із користувачем і клієнтом. Не викликається. |

#### Індекси {#indexes}

| Назва | Ключі | Параметри | Міграція |
| ---- | ---- | ------- | --------- |
| `expiresAt_1` | `{ expiresAt: 1 }` | TTL, `expireAfterSeconds: 0`, частковий: `expiresAt` існує | `20230406125632_oauth_tokens_ttl.mjs` |

Міграції містяться в `tools/migrations/`. Унікальний індекс `authorizationCode_1` створюють лише міграції з тегами `saas` і `server-pro`, які Community Edition не запускає.

#### Примітки {#notes}

* Наведені методи моделі викликають лише обробники authorize і token з `@node-oauth/oauth2-server`. Web використовує цю бібліотеку лише для перевірки bearer-токенів (`services/web/app/src/Features/Authentication/AuthenticationController.mjs:409-450`), і жоден маршрут не обслуговує `/oauth/authorize` або `/oauth/token`, тому код ніколи не записується. Персональні токени доступу створюються напряму, див. [OAuth Access Tokens](/uk/dev/data-model/oauth-access-tokens-collection).
