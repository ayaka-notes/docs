多年来，许多使用 Overleaf 社区版的用户都对 Overleaf Server Pro 表现出浓厚兴趣。因为 Overleaf CE 存在太多限制，例如：

* 没有沙盒机制，LaTeX 编译以与容器相同的权限运行。
* 不支持切换 TeX Live 版本，每个版本都需要手动安装。
* 没有修订追踪（track changes），协作写作和评论相当困难。
* 没有 Git 集成，本地 LaTeX 用户很难加入协作项目。

然而，清晰可靠的价格信息一直很难找到。在 Overleaf 的官网上，唯一的选项就是联系销售。Server Pro 似乎并不向个人用户直接出售。借助搜索引擎，我们找到了一些价格信息。

根据我们在社区中收集到的信息，**Server Pro 的报价为**：

* 你需要购买 _至少_ 10 人的许可证。
* 10 人许可证的价格约为 €3,477.61（2024 年）。
* 对于教育机构，20 用户每年 2640 欧元，50 用户 6050 欧元，100 用户 9963 欧元。
* Server Pro 仅在部分地区提供（例如不包括中国大陆）。

2026 年晚些时候，我们使用 ChatGPT Search 找到了更多购买过 Overleaf Server Pro 的机构。

Overleaf Server Pro 的价格似乎约为每用户每年 \$300。美国的一些较小合同显示，每用户每年的费用大约为 \$320–\$370。大型机构协议可以获得更低的单用户价格。例如，马克斯·普朗克学会（Max Planck Society）的三年期协议平均每用户每年约 €51。合同条款、支持服务和部署范围可能有所不同。这些记录并非 Overleaf 官方价目表。

### 构建在线 LaTeX 编辑器？并不简单！

自 2026 年初以来，借助 Claude 或 Codex 等代码智能体，几乎每个月都能看到一个新的 Overleaf 替代品。OpenAI 也推出了他们的 [Prism](https://prism.openai.com/)，一款面向科研 LaTeX 写作的产品。

尽管许多人大肆宣扬"Overleaf 已死、Prism 将成为最好的免费 LaTeX 编辑器"，但我们发现 Prism 距离成熟产品还有很长的路要走。

<strong>构建一个可靠的在线 LaTeX 编辑器远非易事。</strong> 根据我们的观察，Prism 会在打开项目时创建一个沙盒并保持其运行，这很可能是因为 Codex 需要在后台保持可用。这样当用户开始 AI 对话时，Codex 就能快速响应。在我们的测试中，每个沙盒大约分配了 5 个 vCPU、6 GB 内存和 64 GB 磁盘空间。

当成千上万的用户同时编辑 LaTeX 项目时，这种架构可能会带来可观的计算开销。Ayakaleaf 采用了不同的方式：仅在请求编译时才创建沙盒。每次编译限制为 1 个 vCPU 和 1 GB 内存，编译完成后沙盒即被销毁。这显著减少了持续性的资源消耗，也让大规模部署的容量规划更加可预测。

更广泛地说，Prism 说明了即使拥有强大的模型和成熟的开源软件生态，要将 AI 能力与可靠的在线开发环境结合起来仍然十分困难。AI 可以改善体验，但无法替代扎实的系统工程。归根结底，用户依赖的是可靠、可预测且稳定的服务。

### 为什么选择 Ayakaleaf Pro？

**Ayakaleaf Pro** 是 Overleaf 社区版的一个分支，它为自托管部署带来了 Server Pro 级别和 SaaS 级别的功能——无需按用户购买许可证。它与上游 Overleaf 代码库保持同步，因此你可以获得熟悉的编辑器和工作流程，此外还有：

* 沙盒化 LaTeX 编译
* 多个 TeX Live 版本
* 修订追踪与评论
* Git 与 GitHub 集成
* SSO 与管理面板
* 私有模板管理
* Zotero 与高级参考文献搜索
* Pandoc 导入/导出
* Python 脚本运行器
* 无按用户收取的许可费用

我们的目标是提供更完整的自托管 Overleaf 体验——无需 Server Pro 许可证或 SaaS 订阅。Ayakaleaf Pro 保留了熟悉的 Overleaf 工作流程和上游兼容性，同时增加了协作、管理、集成和安全编译等功能。

### 为什么我们总在重复造轮子？

有一个更宏观的问题值得思考：_**当一个成熟的开源项目已经解决了大部分难题时，为什么人们的第一反应往往是从头重写**_？

重新实现一个编辑器、一个实时协作层、一条编译流水线，以及多年积累下来的各种边界情况修复，成本极其高昂——而且其中大部分精力都花在重新发现原项目早已解决的问题上。在大多数情况下，在坚实的基础上进行扩展，并将缺失的部分贡献回去，才是更务实的工程选择。

我真正想说的是：

> _在 AI 时代，人们热衷于炫耀。_

"我自己做了一个 Overleaf"听起来远比"我给 Overleaf 加了一些功能"更令人印象深刻——所以人们更愿意讲前一个故事。这也是为什么似乎每个月都会冒出一个新的"AI LaTeX 编辑器"。

但实际上，这些借助 AI 重写的产品，远远达不到像 Overleaf 这样经过十年真实环境实战检验所带来的可靠性和成熟度。给它们两个月时间，它们就会像二月里的圣诞玩具一样被抛弃。相信我。
