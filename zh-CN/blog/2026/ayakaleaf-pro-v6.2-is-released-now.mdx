我们很自豪地宣布 Ayakaleaf Pro 6.2 正式发布，这是社区中功能最强大、最丰富的在线 LaTeX 编辑器。特别感谢 yu-i-i 和 davrot 的宝贵贡献。他们增强了 GitHub 同步功能，并引入了高级引用搜索和 Zotero 集成。

### 注意事项

* 新增了必需的环境变量 `OVERLEAF_INVITE_TOKEN_SECRET`，你必须使用以下命令生成它：`openssl rand -base64 32`。如果未配置，你的 Overleaf 实例将无法启动。
* 如果启用 GitHub 同步，你必须配置 `GITHUB_TOKEN_CIPHER_PASSWORD` 环境变量。该变量用于安全地加密 GitHub 访问令牌。没有它，你的 Overleaf 实例将无法启动。
* 新增了 `DEFAULT_LATEX_COMPILER` 环境变量，用于设置新项目使用的默认编译器（pdflatex、latex、xelatex 或 lualatex）。
* 重新设计的编辑器现在是唯一可用的选项。

### 变更

本次发布包含以下改进和新功能。

* `MAX_UPLOAD_SIZE` 现在可以配置，不再限制为 **50 MB**。
* 修复了禁用沙盒编译时容器反复重启的问题。
* 对 OAuth2 强制执行仅限所有者删除 PAT。
* 修复了 LDAP 导入问题。

新功能包括：

* 新增基于浏览器的 Python 运行器。
* 新增 Pandoc 支持，可导入和导出 Markdown、DOCX 及其他格式。
* 新增 GitHub 同步。
* 新增完整的中文翻译。
* 新增 Zotero 集成。
* 新增 `DEFAULT_LATEX_COMPILER`。

#### 功能 01：GitHub 同步

让你的 LaTeX 项目与 GitHub 仓库保持同步，实现无缝的开发工作流。直接在编辑器中推送和拉取更改，通过 Pull Request 进行协作，并与现有的 CI/CD 流水线集成。版本控制让你可以轻松跟踪修订、审查更改，并维护可复现的学术或技术文档。

参见：[GitHub 同步](/zh-CN/on-premises/configuration/overleaf-toolkit/github-synchronisation  "mention")。

![](https://github.com/user-attachments/assets/5137e708-77cb-4fdf-b081-4aa04b4b762e)

#### 功能 02：Pandoc 导入/导出

将 Microsoft Word 和 Markdown 文档导入为完全可编辑的 LaTeX 项目，或一键将 LaTeX 项目导出为 Markdown 和 DOCX。该功能由 Pandoc 驱动，可在学术写作、协作编辑和出版工作流之间实现无缝互通，同时尽可能保留文档结构。

参见：[Pandoc 导入和导出](/zh-CN/on-premises/configuration/overleaf-toolkit/pandoc-import-and-export  "mention")。

<img src="https://github.com/user-attachments/assets/085a94a0-c673-46fe-9da4-7a5a68e46589" alt="" width="563" />

#### 功能 03：高级文献搜索

通过智能筛选和即时引用支持，从多个学术数据库中搜索并插入参考文献。快速发现论文、预览元数据并构建准确的 BibTeX 条目，无需在不同的研究网站之间切换，显著提升文献综述效率。

![image](https://github.com/user-attachments/assets/42e45b73-af4b-4d1f-81f4-9e116ba5d043)

#### 功能 04：Python 运行器

无需离开编辑器，直接在项目中执行 Python 代码。非常适合生成图表、处理数据集、自动化文档工作流或运行可复现的研究脚本。结果可以集成到你的 LaTeX 文档中，让科学计算与写作成为统一的工作流。

![image](https://github.com/user-attachments/assets/a4c314b3-fdb5-4836-aea7-12eeece5cd2f)

#### 功能 05：Zotero

将你的 Zotero 文献库直接连接到写作工作流中，无需离开编辑器即可管理参考文献。搜索你的个人 Zotero 收藏，一键插入引用，并自动生成和同步 BibTeX 条目。此集成可使你的参考文献保持最新，简化学术论文、学位论文和技术文档的文献管理。

参见：[Zotero 集成](/zh-CN/on-premises/configuration/overleaf-toolkit/zotero-integration  "mention")。
