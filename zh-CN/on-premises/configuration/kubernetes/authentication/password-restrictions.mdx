---
title: 密码限制
description: 在 Kubernetes 部署中设置本地密码的最小和最大长度。
icon: key
---

当用户注册、设置或更改密码时，**web** 服务会检查本地密码。SSO 登录（LDAP、SAML、OIDC）不受影响；它们的密码由身份提供商负责。有关 Toolkit 的说明，请参见[密码限制](/zh-CN/on-premises/configuration/overleaf-toolkit/authentication/password-restrictions)。

| | |
| --- | --- |
| 服务 | web，位于每个 Ayakaleaf Pro Pod 中；在 web 启动时读取 |
| 网络 | 无 |
| 定期任务 | 无 |

### 配置

添加到 ConfigMap `overleaf-env` 并重启：

```yaml title="30-config.yaml (additions)"
  OVERLEAF_PASSWORD_VALIDATION_MIN_LENGTH: "12"
  OVERLEAF_PASSWORD_VALIDATION_MAX_LENGTH: "72"
```

```bash
kubectl apply -f 30-config.yaml
kubectl -n overleaf rollout restart deployment/overleaf     # or statefulset/overleaf
```

| 变量 | 默认值 | |
| --- | --- | --- |
| `OVERLEAF_PASSWORD_VALIDATION_MIN_LENGTH` | `8` | 接受的最短密码长度。 |
| `OVERLEAF_PASSWORD_VALIDATION_MAX_LENGTH` | `72` | 接受的最长密码长度；大于 `72` 的值按 `72` 处理。 |

请为数字加上引号：ConfigMap 只能保存字符串。

<Warning>

`OVERLEAF_PASSWORD_VALIDATION_PATTERN` 会被读取但不会被强制执行：不匹配该模式的密码也会被接受。只有长度限制生效。

</Warning>

### 多个副本

无需额外操作：每个副本读取的都是同一个 ConfigMap。

### 在 Kubernetes 上的测试

在 Kubernetes 1.37 上使用一个副本，并在 ConfigMap 中设置 `OVERLEAF_PASSWORD_VALIDATION_MIN_LENGTH: "12"` 和 `OVERLEAF_PASSWORD_VALIDATION_PATTERN: aA$3`，激活新账户时拒绝了一个 10 个字符的密码，并接受了一个仅由小写字母组成的 20 个字符的密码，而该模式本应拒绝这个密码。在默认设置下，我们针对注册的端到端测试也会以过短为由拒绝 `123456`。
