### 配置

从 6.3.0 开始，模板库在服务端执行分页、搜索和排序，无需进行迁移。对于大型模板库，请参阅发行说明中的[可选 MongoDB 索引](/zh-CN/on-premises/release-notes/release-notes-6.x.x#feature-04-template-pagination  "mention")。

模板库功能通过以下环境变量控制：

* `OVERLEAF_TEMPLATE_GALLERY`：设为 `true` 以启用模板库。
*   `OVERLEAF_TEMPLATE_CATEGORIES`：可选，以空白字符分隔的零个或多个模板分类键。有效的键包括：

    * _`academic-journal`_
    * _`book`_
    * _`presentation`_
    * _`poster`_
    * _`cv`_
    * _`homework`_
    * _`bibliography`_
    * _`calendar`_
    * _`formal-letter`_
    * _`report`_
    * _`thesis`_
    * _`newsletter`_

    特殊键 _`all`_ 会被自动追加，它代表包含所有模板的分类。

    对于每个分类键，可以设置以下可选环境变量：

    * `TEMPLATE_<KEY>_NAME`：模板分类的显示名称。
    * `TEMPLATE_<KEY>_DESCRIPTION`：分类的简短描述。

    如果分类键中包含连字符（`-`），请在环境变量名称中将其替换为下划线（`_`）。
* `ENABLE_CONVERSIONS`：必须设为 `true` 才能为模板生成缩略图和预览。

### 发布权限

管理员可以发布模板。你也可以指定一名非管理员用户来管理本地模板库 `/templates` 中展示的精选模板。

为此，你需要在 `toolkit/config/variables.env` 中将环境变量 `OVERLEAF_TEMPLATES_USER_ID` 设置为负责实例内模板管理的用户的 `ID`，例如：

```dotenv
OVERLEAF_TEMPLATES_USER_ID=56a8865231faeb5f07d69959
```

### 发布模板

对于每个要上传的模板：

1. 创建一个包含模板源代码的项目，并确保它能够成功编译。
2. 在编辑器中，选择 **File** > **Manage Template**。
3. 在弹出的表单中，填写模板详情：
   * _Title_（标题）必须唯一。
   * _Description_（描述）字段支持 Markdown 格式。
   * _Author_（作者）字段接受 Markdown 格式的链接。

提交后，可以通过模板库页面编辑模板详情或删除模板。管理员和模板用户（`OVERLEAF_TEMPLATES_USER_ID`）可以管理任意模板。

示例如下：

```dotenv wrap expandable
#################
#   TEMPLATES   #
#################

OVERLEAF_TEMPLATE_GALLERY=true
OVERLEAF_TEMPLATE_CATEGORIES=academic-journal book presentation poster cv homework bibliography calendar formal-letter report thesis newsletter

TEMPLATE_ACADEMIC_JOURNAL_NAME=Journal articles
TEMPLATE_ACADEMIC_JOURNAL_DESCRIPTION=Templates for academic journal submissions, including formats for major publishers and preprint servers.

TEMPLATE_BIBLIOGRAPHY_NAME=Bibliographies
TEMPLATE_BIBLIOGRAPHY_DESCRIPTION=Styles for creating and managing bibliographies with BibTeX or BibLaTeX. Suitable for use in academic papers, theses, and reports.

TEMPLATE_BOOK_NAME=Books
TEMPLATE_BOOK_DESCRIPTION=Templates for writing books or long-form documents, including chapter structuring, front matter, and indexing.

TEMPLATE_CALENDAR_NAME=Calendars
TEMPLATE_CALENDAR_DESCRIPTION=Templates to create yearly, monthly, or weekly calendars. Useful for personal planners or event scheduling.

TEMPLATE_CV_NAME=CVs and résumés
TEMPLATE_CV_DESCRIPTION=Templates for CVs and résumés with various formats for academic, industry, and creative positions.

TEMPLATE_FORMAL_LETTER_NAME=Formal letters
TEMPLATE_FORMAL_LETTER_DESCRIPTION=Templates for professional letters, such as cover letters, recommendation letters, and official correspondence.

TEMPLATE_HOMEWORK_NAME=Assignments
TEMPLATE_HOMEWORK_DESCRIPTION=Templates for homework, coursework, and problem sets. Designed to be clean and well-structured for students and educators.

TEMPLATE_NEWSLETTER_NAME=Newsletters
TEMPLATE_NEWSLETTER_DESCRIPTION=Templates for creating newsletters with formats for academic, corporate, or community communications.

TEMPLATE_POSTER_NAME=Posters
TEMPLATE_POSTER_DESCRIPTION=Templates for scientific and academic posters, typically used in conferences and research presentations.

TEMPLATE_PRESENTATION_NAME=Presentations
```

### 从 overleaf.com 迁移模板

由于 Overleaf Pro 的架构设计支持离线运行，因此没有自动化的方式将 [overleaf.com](https://www.overleaf.com/) 模板库中的模板集成到你的本地部署中，不过可以逐个模板手动完成这项工作。

默认情况下，Overleaf Pro 配置为使用 basic scheme 版本的 TeXLive 进行编译。这个基础版本很轻量，只包含非常有限的 LaTeX 宏包子集，因此当用户尝试在本地实例上使用来自 [overleaf.com](https://www.overleaf.com/) 的模板时，很可能会遇到缺少宏包的错误。

遗憾的是，虽然没有自动安装缺失宏包的方法，但 Server Pro 提供了一个可配置的设置，允许用户以更安全的方式编译项目并使用更多的宏包。该功能称为[沙箱编译](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles)（也称为兄弟容器，Sibling Containers）。

为确保下载的模板与你的本地 Server Pro 实例兼容，我们强烈建议你启用[沙箱编译](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles)，因为该功能可为用户提供与 [overleaf.com](https://www.overleaf.com/) 相同的 TeX Live 环境。这些镜像包含最常用的宏包和字体，并且已经针对我们模板库中的模板进行过测试。

关于如何配置用户在项目中可选择的 TeX Live 版本，以及如何为新项目设置默认的 TeX Live 镜像版本，可参阅我们文档中的[更换 TeX Live 镜像](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/server-pro-only-configuration/sandboxed-compiles#changing-the-tex-live-image)一节。

1. 前往 [overleaf.com](https://www.overleaf.com/) 上的[模板库](https://www.overleaf.com/latex/templates)，找到所需的模板，例如 [IEEE Photonics Journal Paper Template - Example Submission](https://www.overleaf.com/latex/examples/ieee-photonics-journal-paper-template-example-submission/bsfjjfkdsjds)
2. 点击 **Open as Template** 按钮
3. 点击项目菜单并选择 **Download Source**
4. 接下来，登录本地 Server Pro 账户
5. 在项目面板中点击 **New Project** 按钮，然后选择 **Upload Project**
6. 点击 **Select a .zip file** 按钮，选择下载的模板 zip 文件

之后，用户即可在自己的账户中使用这个新上传的模板；或者，作为模板用户，你可以将其发布供其他用户使用。

### 常见问题

<Accordion title="发布对应的模板后，我可以删除该项目吗？">

**回答：** 可以，但我们不建议这样做。发布模板时，我们会对项目创建快照，并将发布时的项目保存为 zip 文件。这样即使你删除了模板对应的项目，模板也不会受到影响。

不过，我们还会记录与该模板关联的 ProjectID，以便你将来更新模板。

如果你删除了对应的项目，将不会在模板详情页面上看到 "Admin: Source Project" 按钮（见下图）。

<Accordion title="为什么有些项目发布模板需要很长时间？">

**回答：** 发布模板时，我们会将项目保存为 zip 和 pdf 文件，这通常很快。但我们还需要为 PDF 生成缩略图，以便在模板详情中显示。

缩略图的生成时间通常取决于 PDF 第一页的内容。为了在显示质量和转换时间之间取得平衡，我们选择了一个适中的宽度。

不过，如果 PDF 的第一页包含大量文字，转换缩略图可能需要 40 秒甚至更长时间，请耐心等待。下面是一个大型海报的示例，它会花费更长的时间。
