---
title: 集成
description: 将你的实例连接到 Git、GitHub、GitLab、Gitea、Dropbox、文献管理工具、AI 服务及其他网站。
icon: puzzle-piece
---

除 Overleaf 导入 API 外，每项集成默认均处于关闭状态。GitHub、GitLab、Gitea 和 Dropbox 同步以及 MCP 服务器还需要启用 [Git 集成](/zh-CN/on-premises/configuration/overleaf-toolkit/integrations/git-integration)。开启某项集成后，请使用 `bin/up -d` 重新创建容器。
