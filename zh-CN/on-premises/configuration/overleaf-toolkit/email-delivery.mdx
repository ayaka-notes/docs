Overleaf 支持通过两种方式发送邮件：简单邮件传输协议（SMTP）和 [Amazon Simple Email Service (SES)](https://aws.amazon.com/ses/)。如果您的本机上启用了监听本地连接的邮件服务器，则可以使用 SMTP。

## 配置

邮件通过以下环境变量进行配置。

#### 发件人配置

| 名称                            | 描述                                                                                                                                                   |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | <p>发件人地址，例如 <a href="mailto:support@mycompany.com">`'support@mycompany.com'`</a><br /><br />- <strong>必填</strong>：是</p>                              |
| `OVERLEAF_EMAIL_REPLY_TO`     | 回复地址，例如 `'noreply@mycompany.com'`                                                                                                                    |

#### SMTP

| 名称                                      | 描述                                                                                                                                                                                                                                                                       |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST`              | 要连接的主机名或 IP 地址。必须能从 Docker 容器内访问                                                                                                                                                                                                                                         |
| `OVERLEAF_EMAIL_SMTP_PORT`              | 要连接的端口                                                                                                                                                                                                                                                                   |
| `OVERLEAF_EMAIL_SMTP_SECURE`            | 若为 `true`，连接服务器时将使用 TLS。若为 `false` 或未设置，则仅当服务器支持 `STARTTLS` 扩展时才使用 TLS。大多数情况下，如果连接的是 `465` 端口，请将此值设为 `true`；对于 `587` 或 `25` 端口，请保持为 `false`                                                                                                                              |
| `OVERLEAF_EMAIL_SMTP_USER`              | 用于向 SMTP 服务器进行身份验证的用户名                                                                                                                                                                                                                                                   |
| `OVERLEAF_EMAIL_SMTP_PASS`              | 与 SMTP 用户名对应的密码                                                                                                                                                                                                                                                          |
| `OVERLEAF_EMAIL_SMTP_TLS_REJECT_UNAUTH` | 若为 `false`，则允许连接使用自签名或无效 TLS 证书的 TLS 服务器                                                                                                                                                                                                                                 |
| `OVERLEAF_EMAIL_SMTP_IGNORE_TLS`        | 当此值为 `true` 且 `OVERLEAF_EMAIL_SMTP_SECURE` 为 `false` 时，即使服务器支持 `STARTTLS` 扩展也不使用 TLS                                                                                                                                                                                     |
| `OVERLEAF_EMAIL_SMTP_NAME`              | 当 `OVERLEAF_EMAIL_SMTP_HOST` 设置为 IP 地址时，用于 TLS 验证的可选主机名，默认为本机主机名。                                                                                                                                                                                                        |
| `OVERLEAF_EMAIL_SMTP_LOGGER`            | 若为 `true`，则将日志信息输出到 `web.log`。                                                                                                                                                                                                                                           |

#### Amazon SES SMTP 接口

有关使用 Amazon SES SMTP 接口发送邮件的更多信息，请参阅[此处](https://docs.aws.amazon.com/ses/latest/dg/send-email-smtp.html)。

| 名称                         | 描述                                                                                         |
| -------------------------- | ------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST` | 要连接的主机名或 IP 地址。必须能从 Docker 容器内访问                                                           |
| `OVERLEAF_EMAIL_SMTP_PORT` | 要连接的端口                                                                                     |
| `OVERLEAF_EMAIL_SMTP_USER` | 用于向 SMTP 服务器进行身份验证的用户名                                                                     |
| `OVERLEAF_EMAIL_SMTP_PASS` | 与 SMTP 用户名对应的密码                                                                            |

#### Amazon SES API

有关使用 Amazon SES API 发送邮件的更多信息，请参阅[此处](https://docs.aws.amazon.com/ses/latest/dg/send-email-api.html)。

| 名称                                     | 描述                                          |
| -------------------------------------- | ------------------------------------------- |
| `OVERLEAF_EMAIL_AWS_SES_ACCESS_KEY_ID` | 使用 AWS SES 时的访问密钥（access key）               |
| `OVERLEAF_EMAIL_AWS_SES_SECRET_KEY`    | 使用 AWS SES 时的私密密钥（secret key）               |
| `OVERLEAF_EMAIL_AWS_SES_REGION`        | 如果未设置，默认区域为 US-EAST-1                       |

#### 使用实例角色的 AWS SES

| 名称                      | 描述                                                                                                                               |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_DRIVER` | 当此值设置为 `ses` 时，邮件系统将使用 SES API 方式，并依赖已配置的实例角色发送邮件。                                                                               |

#### 自定义

| 名称                             | 描述                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_CUSTOM_EMAIL_FOOTER` | <p>附加到所有邮件末尾的自定义 HTML，例如：<br /><br /><strong>示例</strong>: `"<div>This system is run by department x </div> <div> If you have any questions please look at our faq <a href='`<a href="https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/https:/somwhere.com'%3Ehere&#x3C;/a%3E&#x3C;/div%3E">`https://somwhere.com'>here&#x3C;/a>&#x3C;/div>`</a>`"`</p>                                                                                                           |
