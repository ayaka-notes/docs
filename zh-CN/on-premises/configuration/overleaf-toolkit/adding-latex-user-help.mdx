---
title: 添加 LaTeX 用户帮助
icon: graduation-cap
---

只需在 Toolkit 的 `config/variables.env` 文件中添加 `OVERLEAF_PROXY_LEARN=true` 并运行 `bin/up` 命令，即可在您的 Overleaf Pro 实例中启用对 Overleaf [Learn](https://www.overleaf.com/learn) 页面的访问。

这样，用户只需点击导航菜单中的 **Documentation** 按钮，即可在不离开您实例的情况下访问最新的文档和学习资源。

<Info>

默认情况下，只有已登录用户才能打开 `/learn`。若要让未登录的访客也能访问，还需设置 `OVERLEAF_ALLOW_PUBLIC_ACCESS=true`，参见 [页面访问](/zh-CN/on-premises/configuration/overleaf-toolkit/public-access#page-access  "mention")。

</Info>

<Info>

对于 Docker Compose 部署，您需要在 `docker-compose.yml` 文件中 `sharelatex` 服务的 **environment** 部分添加环境变量 `OVERLEAF_PROXY_LEARN: true`。

</Info>

<Info>

您的 Server Pro 部署需要能够访问互联网，以便向 [https://learn.sharelatex.com](https://docs.overleaf.com/on-premises/welcome) 发起外部 `GET` 请求。

</Info>

<Danger>

首次启用此选项并重启 Overleaf Docker 时，系统需要下载相关的 Wiki，这可能需要 5 分钟或更长时间。只有下载完成后，您才能正常看到 Overleaf 登录页面。

</Danger>
