### Doctor 脚本

Overleaf Toolkit 附带了一个便捷的 `doctor` 脚本来帮助调试。运行 `bin/doctor`，该脚本会打印有关宿主机环境、配置以及 Toolkit 所需依赖项的信息。这些输出也能帮助我们诊断你的 Ayakaleaf Pro 安装中的问题。

<Info>

Overleaf Pro 用户可以[在 GitHub 上提交 issue](https://github.com/ayaka-notes/overleaf/issues)。

建议在你的消息中附上 `bin/doctor` 脚本的输出。

</Info>

### 使用 Doctor 诊断

运行 doctor 脚本：

```bash title="Run doctor"
bin/doctor
```

### 主机信息

`Host Information` 部分包含运行 Toolkit 的机器的信息（例如 Linux 发行版和版本）。

<Accordion title="主机信息输出示例">

```text
- Host Information
    - Linux
    - Output of 'lsb_release -a':
            No LSB modules are available.
            Distributor ID:	Ubuntu
            Description:	Ubuntu 22.04.5 LTS
            Release:	22.04
            Codename:	jammy
```

</Accordion>

### 依赖项

`Dependencies` 部分列出了 Toolkit 运行所需的工具。如果某个工具存在，它将显示为 `status: present` 并附带版本信息。如果缺失，它将显示为 `status: MISSING!`，并且 `doctor` 输出的底部会添加一条警告。

<Accordion title="依赖项输出示例（存在）">

```text
- docker
    - status: present
    - version info: Docker version 28.0.4, build b8034c0
```

</Accordion>

<Accordion title="依赖项输出示例（缺失）">

```text
- docker
    - status: MISSING!
```

</Accordion>

如果缺少任何依赖项，Toolkit 几乎肯定无法正常工作。

### 配置

`Configuration` 部分包含 `config/` 目录中文件的信息。对于 `config/overleaf.rc`，doctor 会打印一些关键值。缺失的文件将显示为 `status: MISSING!`，并且 `doctor` 输出的底部会添加一条警告。

<Accordion title="配置输出示例">

```text
====== Configuration ======
- config/version
    - status: present
    - version: 5.4.0
- config/overleaf.rc
    - status: present
    - values
        - OVERLEAF_DATA_PATH: /tmp/overleaf
        - SERVER_PRO: false
        - MONGO_ENABLED: false
        - REDIS_ENABLED: true
- config/variables.env
    - status: MISSING!
```

</Accordion>

关于上述示例的说明：

* 将 `OVERLEAF_DATA_PATH` 设置为 `/tmp/overleaf` 对于重要数据而言可能不是安全的位置。
* `MONGO_ENABLED: false` 表示 Toolkit 不会自行配置 MongoDB；如有需要，请确保 `MONGO_URL` 指向外部管理的 MongoDB。
* 示例中缺少 `config/variables.env`。

### 警告

`Warnings` 部分汇总了 doctor 脚本发现的问题。如果没有问题，该部分会予以说明。

<Accordion title="警告输出示例">

```text
====== Warnings ======
- configuration file variables.env not found
- rc file, OVERLEAF_DATA_PATH not set
====== End =======
```

</Accordion>
