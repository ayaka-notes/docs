---
title: 项目限制
icon: list-check
---

| 功能                         | 限制 |
| ---------------------------- | ---- |
| 编译超时                     | <strong>默认：</strong> 180 秒。有关自定义此值的更多信息，请参阅[更新项目编译超时](/zh-CN/on-premises/user-and-project-management/project-management)。 |
| 每个项目的最大文件数         | 2000 |
| 每个项目可编辑内容的最大大小 | <strong>默认：</strong> 7 MB。有关自定义此值的更多信息，请参阅[环境变量](/zh-CN/on-premises/configuration/overleaf-toolkit/environment-variables)。 |
| 单个可编辑文本文件的最大大小 | 2 MB\* |
| 单次上传的最大大小           | 50 MB（可通过 `MAX_UPLOAD_SIZE` 配置） |
| 上传的 .zip 文件解压后的最大大小 | 6 × `MAX_UPLOAD_SIZE`（默认为 300 MB） |
| 项目的最大大小               | 无限制† |
| 项目的最大数量               | 无限制 |

\* 在某些情况下，一些较大的文件可能仍然可以编辑。但是，为确保文件始终可编辑，你应将其大小限制在 2 MB 或以下。

† 项目总大小没有强制限制。但是，在处理非常大的项目时，你可能会遇到一些技术限制。我们建议项目最大不超过 500 MB；如果使用我们的 [Git 集成](https://www.overleaf.com/learn/how-to/Git_integration)，则建议小于 100 MB。超过这些大小的项目也可能正常工作，但保持在这些限制之内可以获得最佳体验。
