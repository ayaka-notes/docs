---
title: 什么是 Ayakaleaf Toolkit？
icon: toolbox
---

Ayakaleaf Toolkit 是社区版和 Ayakaleaf Pro 本地化部署的推荐部署方式，它专为最常见的环境而设计：单台物理服务器或虚拟机。Toolkit 使用 `docker compose` 管理服务器上的 Docker 容器，并提供一组封装了 `docker` 命令的脚本，帮助您处理管理本地化 Overleaf 时较为技术性的工作。

#### `bin/docker-compose` 封装脚本

`bin/docker-compose` 脚本是对 `docker compose` 的封装。它会先从 `config/` 目录加载配置，然后使用传递给脚本的参数调用 `docker compose`。

您可以将 `bin/docker-compose` 视为机器上已安装的 `docker compose` 程序的透明封装。

示例：

```bash title="Check running containers"
$ bin/docker-compose ps
```

#### 便捷辅助脚本

除了 `bin/docker-compose` 之外，Toolkit 还提供了一些便捷脚本来协助完成常见任务：

* `bin/up`：`bin/docker-compose up` 的快捷方式
* `bin/start`：`bin/docker-compose start` 的快捷方式
* `bin/stop`：`bin/docker-compose stop` 的快捷方式
* `bin/shell`：在 **sharelatex** 容器内启动一个 shell
* `bin/doctor`：用于收集安装和部署信息的脚本。请参阅下方的“检查您的服务器”一节
* `bin/mongo`：在 **mongo** 容器内启动一个 shell，并切换到正确的数据库（**sharelatex**）
* `bin/backup-config`：创建当前配置的副本（zip 或 tar），并将其存储到您选择的目标目录中
* `bin/logs`：查看/跟踪服务日志
* `bin/error-logs`：查看/跟踪服务错误日志
* `bin/rename-env-vars-5-0`：迁移脚本，用于更新 **config/variables.env** 中的环境变量（从 ShareLaTeX 更名为 Overleaf）
* `bin/rename-rc-vars`：迁移脚本，用于更新 **config/overleaf.rc** 中的环境变量（从 ShareLaTeX 更名为 Overleaf）
* `bin/run-script`：辅助脚本，用于简化运行存储在 **sharelatex** 容器中的脚本
* `bin/upgrade`：协助进行实例升级。该脚本会（通过 git）检查 Toolkit 更新并提示拉取更改，检查最新的 Docker 镜像版本并提示更新。它提供逐步确认、备份当前配置的选项，并负责停止/启动 Docker 服务。更多信息请参阅升级您的部署：https://docs.overleaf.com/on-premises/maintenance/upgrading-your-deployment

<Info>

如果您希望在不附加到 Docker 日志的情况下运行实例，可以运行 `bin/up -d` 以分离模式运行。

</Info>

#### 检查您的服务器

Overleaf Toolkit 包含一个名为 `bin/doctor` 的实用脚本，它会生成一份报告，指出任何未满足的依赖项。

在继续之前，请运行 `bin/doctor` 脚本，检查一切是否正常：

```bash title="Run Overleaf Doctor"
bin/doctor
```
