### 安装 Server Pro 和 Community Edition 的要求

<Warning>

我们强烈建议您在较新且稳定的 Ubuntu 版本（例如 2025–2026 年的 Ubuntu 24.04）上，搭配较新版本的 Docker 运行 Server Pro。在其他系统上运行 Server Pro 也是可行的，但对于非默认的 Ubuntu/Docker 环境，我们将很难提供支持。此外，我们也无法为 Docker 本身的问题提供支持。

</Warning>
