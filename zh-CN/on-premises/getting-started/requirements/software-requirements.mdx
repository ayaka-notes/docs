### 操作系统 {#operating-systems}

对于共享服务器和生产服务器，我们推荐使用**基于 Debian 的 Linux** 系统，例如 **Ubuntu**。Ayakaleaf Pro 也可以运行在[使用 Docker Desktop 的 macOS](/zh-CN/on-premises/installation/using-docker-compose/macos) 和[使用 WSL 2 与 Docker Desktop 的 Windows](/zh-CN/on-premises/installation/using-docker-compose/windows) 上。这三个平台都使用 Linux 容器和同一个 Toolkit；请按照与你的主机操作系统对应的指南操作。

<Danger>

在使用沙盒编译（Sandboxed Compiles）时，**需要注意**该应用程序需要对 Docker 套接字的 root 访问权限。

</Danger>

### 依赖项 {#dependencies}

* Docker 25.0 和 29
* MongoDB 7.0 和 8.0
* Redis 6.2 和 7.5

<Info>

你可以使用 endoflife.date 服务跟踪上述依赖项及其他常用产品的生命周期结束（EOL）日期：[https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

运行 Ayakaleaf Pro 时，MongoDB 和 Redis 会由 `docker compose` 自动拉取，除非你配置为使用其他安装。

</Info>

Toolkit 依赖以下程序：

* bash
* Docker

`docker compose` 是必需的，它通常会随 Docker 一起安装。

我们建议你安装适用于你的操作系统的最新版本 Docker。

正确安装 Docker 后，你应该能够无错误地运行以下命令：

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2 or later, such as v5)
docker compose version

# List the running Docker containers on your system
docker ps
```
