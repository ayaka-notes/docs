### 操作系统

为了在运行 Overleaf 时获得最佳体验，我们强烈建议使用**基于 Debian** 的操作系统，例如 **Ubuntu**。这一选择与该软件的开发环境保持一致，也是大多数 Overleaf 用户的首选。

<Danger>

在使用带有沙箱编译功能的 Server Pro 时，**需要特别注意**该应用需要以 root 权限访问 Docker 套接字。

</Danger>

### 依赖项

* Docker 25.0 和 29
* MongoDB 7.0 和 8.0
* Redis 6.2 和 7.5

<Info>

你可以通过 endoflife.date 服务跟踪上述依赖项及其他流行产品的生命周期终止（EOL）日期：[https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

运行 Server CE 或 Server Pro 时，`docker compose` 会自动拉取 MongoDB 和 Redis，除非你配置为使用其他安装。

</Info>

Toolkit 依赖以下程序：

* bash
* Docker

`docker compose` 是必需的，通常会随 Docker 一起安装。

我们建议你安装适用于你的操作系统的最新版 Docker。

正确安装 Docker 后，你应该能够无错误地运行以下命令：

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2)
docker compose version

# List the running Docker containers on your system
docker ps
```
