### 下载 Toolkit {#downloading-the-toolkit}

你需要使用 **Ayakaleaf Toolkit**（[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)）安装 Ayakaleaf Pro。它是一组脚本，可以帮你在 Docker 中运行 Overleaf。

默认情况下，Toolkit 会启动免费的官方 Overleaf 社区版（CE）。在 [4. 获取 Ayakaleaf Pro 镜像](/zh-CN/on-premises/installation/using-docker-compose/linux/4.-get-overleaf-pro-images) 中，只需一项设置即可将其切换为 Ayakaleaf Pro。

<Accordion title="已经在运行官方 Overleaf Toolkit（overleaf/toolkit）？">

你无需重新安装。保留现有安装，并按照 [4. 获取 Ayakaleaf Pro 镜像](/zh-CN/on-premises/installation/using-docker-compose/linux/4.-get-overleaf-pro-images) 的最后一部分操作即可。

</Accordion>

<Steps>
<Step title="克隆 Ayakaleaf Toolkit 仓库">
要安装 Toolkit，请进入目标安装路径，然后使用以下命令克隆 Ayakaleaf Toolkit 仓库：

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
```

<Info>

为避免潜在的权限问题，我们建议将 Toolkit 安装在你用户的 `$HOME` 目录中。

</Info>
</Step>

<Step title="进入 Toolkit 目录">
等待克隆完成后，切换到新创建的 `overleaf-toolkit` 目录：

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
