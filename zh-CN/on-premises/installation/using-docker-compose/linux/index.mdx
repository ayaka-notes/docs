在本节中，我们将指导你安装 Docker、从 GitHub 下载 Toolkit、熟悉 Toolkit 的一些命令，并配置一些基本设置。完成本节后，你应该就拥有了一个正在运行的本地部署 Overleaf 实例。

这些步骤针对较新的 Ubuntu LTS 版本。如果使用其他发行版，请按照 [Docker 文档](https://docs.docker.com/engine/install/)中的说明安装 Docker Engine 和 Compose 插件，然后继续阅读 [1. 下载 Toolkit](/zh-CN/on-premises/installation/using-docker-compose/linux/1.-download-the-toolkit)。

<Info>

默认情况下，实例只接受来自服务器本身的连接，地址为 `http://localhost`。要从其他计算机或通过其他端口访问它，请在 `config/overleaf.rc` 中设置 `OVERLEAF_LISTEN_IP` 和 `OVERLEAF_PORT`，详见 [5. 个性化你的实例](/zh-CN/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance)。

</Info>
