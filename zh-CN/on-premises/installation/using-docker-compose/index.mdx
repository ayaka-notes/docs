在单台服务器上使用 Docker Compose 是部署 Ayakaleaf Pro 的推荐方式。你需要通过 [Toolkit](https://github.com/ayaka-notes/toolkit) 来运行它：这是一组封装了 `docker compose` 的脚本，会从同一个 `config/` 目录读取你的设置，因此 `bin/up` 取代了 `docker compose up`。
