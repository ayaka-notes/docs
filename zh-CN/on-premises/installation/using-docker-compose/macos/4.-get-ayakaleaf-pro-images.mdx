---
title: 4. 获取 Ayakaleaf Pro 镜像
description: 将 Mac 上的 Toolkit 切换为公开的 Ayakaleaf Pro 镜像。
icon: split
---

Ayakaleaf Pro 是 [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/) 上的一个免费 Docker 镜像。拉取它不需要账户、登录或商业 Overleaf 许可证。

打开 `config/overleaf.rc` 并设置：

```bash title="config/overleaf.rc"
SERVER_PRO=true
```

下次运行 `bin/up` 时，Toolkit 会拉取 `config/version` 中指定版本的 `ghcr.io/ayaka-notes/overleaf-pro`，而不是官方的 Overleaf 社区版。

该镜像针对 `arm64` 和 `amd64` 构建，Docker 会选择与你的 Mac 匹配的版本。在 Apple 芯片上，不要在覆盖配置中添加 `platform: linux/amd64`：否则镜像将在模拟环境下运行。
