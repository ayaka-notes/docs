description: 为 Mac 上的本地实例设置端口、站点 URL 和 TeX Live 镜像，检查 Docker 虚拟机内核，并启动 Ayakaleaf Pro。

<Steps>
<Step title="容器设置">
在 `config/overleaf.rc` 中编辑以下已有条目：

```bash title="config/overleaf.rc"
PROJECT_NAME=ayakaleaf-macos
SERVER_PRO=true
OVERLEAF_LISTEN_IP=127.0.0.1
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
DOCKER_SOCKET_PATH=/var/run/docker.sock
```

保留默认的数据路径以及内置的 MongoDB 和 Redis 服务。设置 `OVERLEAF_LISTEN_IP=127.0.0.1` 后，只有这台 Mac 上的浏览器才能打开该实例。
</Step>

<Step title="应用程序设置">
在 `config/variables.env` 中设置以下值，替换任何同名的已启用条目：

```dotenv title="config/variables.env"
OVERLEAF_SITE_URL=http://localhost:8080
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES="TeX Live 2026"
```

生成一个会话密钥：

```bash
openssl rand -hex 32
```

将结果作为 `OVERLEAF_SESSION_SECRET` 添加到 `config/variables.env` 中。如果不设置它，每次重新创建容器的 `bin/up` 都会让所有用户退出登录，请参阅[环境变量](/zh-CN/on-premises/configuration/overleaf-toolkit/environment-variables)。

对于不使用邮件的本地实例，请不要设置 SMTP 相关设置和 `OVERLEAF_EMAIL_FROM_ADDRESS`。Git Bridge、外部身份验证和其他集成可以稍后通过各自的[配置页面](/zh-CN/on-premises/configuration/overleaf-toolkit)添加。
</Step>

<Step id="check-the-docker-vms-linux-kernel" title="检查 Docker 虚拟机的 Linux 内核">
MongoDB 运行在 Docker Desktop 虚拟机的 Linux 内核上，而不是 macOS 上。请在首次启动之前检查其版本：

```bash
docker info --format '{{.KernelVersion}}'
```

MongoDB 记录了与 Linux 内核 **6.19 至 7.0.13** 的不兼容问题，这也会影响 Docker 中的 MongoDB。解决方法是使用 **7.0.14 或更高版本**的内核，它会随 Docker Desktop 更新一同提供，请参阅 [MongoDB 的生产环境说明](https://www.mongodb.com/docs/manual/administration/production-notes/)。

如果你的 Docker 虚拟机使用的是受影响的内核，请将以下内容添加到 `config/docker-compose.override.yml`，并与其中已有的 `services` 合并：

```yaml title="config/docker-compose.override.yml"
services:
  mongo:
    environment:
      GLIBC_TUNABLES: glibc.pthread.rseq=1
```

<Warning>

一旦有修复后的内核可用，请及时更新。如果你的内核不在受影响的范围内，则无需此变通方法。

</Warning>
</Step>

<Step title="启动你的实例">
在 Toolkit 目录中运行：

```bash
bin/up -d
```

Toolkit 会初始化 MongoDB 的副本集，拉取 TeX Live 镜像并启动应用程序。首次下载需要一些时间。要跟踪进度：

```bash
bin/docker-compose ps
bin/docker-compose logs --tail=100 -f sharelatex
```

按 `Ctrl+C` 停止跟踪日志。容器会继续运行。

检查发布的端口和首次运行页面：

```bash
bin/docker-compose port sharelatex 80
curl -I http://localhost:8080/launchpad
```

端口应为 `127.0.0.1:8080`。
</Step>
</Steps>
