<Steps>
<Step title="检查 Git 和 Homebrew">
```bash
git --version
brew --version
```

如果运行 Git 时 macOS 要求你安装 Command Line Tools，请先安装它们。如果缺少 Homebrew，请按照[官方说明](https://brew.sh/)进行安装。
</Step>

<Step title="将 GNU sed 放到 PATH 中">
Toolkit 脚本使用了 macOS 内置的 BSD sed 会拒绝的 GNU sed 选项。请安装 [GNU sed](https://formulae.brew.sh/formula/gnu-sed)，并在当前终端中将其放在 `PATH` 的最前面：

```bash
brew install gnu-sed
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
sed --version
```

最后一条命令应输出 **GNU sed**。

仅设置 `alias sed=gsed` 这样的别名是不够的：Toolkit 运行的是 Bash 脚本，这些脚本看不到你交互式 shell 中的别名。你无需替换 `/usr/bin/sed`。

在每个用于运行 Toolkit 的新终端中，都需要再次运行 `export PATH=...` 这一行，或者将其添加到你的 shell 启动文件中，放在 Homebrew 自身的初始化之后。
</Step>

<Step title="克隆 Ayakaleaf Toolkit 仓库">
请选择一个持久保存的目录。不要将实时数据库和项目数据放在 `/tmp`、可移动驱动器或 iCloud Drive 等云同步文件夹中。本指南使用 `~/ayakaleaf-toolkit`：

```bash
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

<Warning>

如果该目录中已经存在一个安装，请按原样使用它，或为新实例选择另一个目录。不要在现有部署之上初始化新的配置。

</Warning>
</Step>
</Steps>
