---
title: 3. 初始化配置
description: 在 Mac 上使用 bin/init 创建 Toolkit 配置文件。
icon: circle-play
---

在 Toolkit 目录中，在 GNU sed 位于 `PATH` 中的终端里运行：

```bash
bin/init
```

`bin/init` 会创建三个文件：

| 文件 | 用途 |
| --- | --- |
| `config/overleaf.rc` | 容器设置、发布的端口和数据位置 |
| `config/variables.env` | 应用程序设置和密钥 |
| `config/version` | 应用程序镜像版本 |

它还会在 `config/variables.env` 中生成 `OVERLEAF_INVITE_TOKEN_SECRET`。请保留它，不要公开此文件，也不要将其提交到版本控制系统中。

对于新安装，请保留 Toolkit 所选择的版本。如果以后要更改现有实例的版本，请按照[升级你的部署](/zh-CN/on-premises/maintenance/upgrading-your-deployment)操作。

<Warning>

如果 `bin/init` 因 `sed: ... invalid command code` 而停止，说明它是使用 macOS 的 BSD sed 运行的。这样一次失败的运行可能会在 `config/` 中留下全部三个文件，且 `OVERLEAF_INVITE_TOKEN_SECRET` 为空，此时再次运行 `bin/init` 会报告 `Config files already exist`。请参阅[故障排除](/zh-CN/on-premises/installation/using-docker-compose/macos/troubleshooting#initialization-fails-with-invalid-command-code)。

</Warning>
