在本节中，我们将使用 WSL 2、Ubuntu、Docker Desktop 和 [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit) 在 Windows 上本地运行 Ayakaleaf Pro。本指南使用 `http://localhost:8080`，将数据保存在 Ubuntu 的主目录中，并启用沙盒编译。

应用程序、MongoDB、Redis 和 TeX Live 运行在由 Docker Desktop 管理的 Linux 容器中。请在 Ubuntu 中运行 Toolkit 命令，在 Windows 浏览器中打开应用程序。[第 0 步](/zh-CN/on-premises/installation/using-docker-compose/windows/0.-setup-wsl-and-docker-desktop)解释了 Windows 和 Linux 部分如何协同工作，并从安装 WSL 开始。

你可以在 Windows 上运行本地实例，也可以通过第 6 步中的可用性设置让它持续运行。对于共享服务器和生产服务器，我们推荐使用 [Linux 指南](/zh-CN/on-premises/installation/using-docker-compose/linux)，并配置 HTTPS、备份和访问控制。Windows 睡眠、Docker Desktop 关闭和 WSL 关闭都会中断此本地实例；请参阅[保持实例可用](/zh-CN/on-premises/installation/using-docker-compose/windows/6.-post-installation-tasks#keep-the-instance-available)。

## 开始之前 {#before-you-start}

你需要：

* [Docker Desktop for Windows](https://docs.docker.com/desktop/setup/install/windows-install/) 所支持的 Windows 版本和处理器，并已启用硬件虚拟化。本指南使用 x86-64 上的 Windows 11。
* 启用 WSL 和安装软件的权限。WSL 必须为 2.1.5 或更高版本，并且 Ubuntu 以 WSL 2 模式运行。
* 足够同时供 Windows 和容器使用的内存。对于小型本地实例，为 Docker 提供 4 个 CPU 和 8 GB 内存只是一个建议的起点，而不是经过测量的最低要求。
* 存放 WSL 和 Docker 数据的 Windows 磁盘上有足够的可用存储空间。完整的 TeX Live 环境加上项目数据至少需要 40 GB；[第 5 步](/zh-CN/on-premises/installation/using-docker-compose/windows/5.-personalizing-your-instance)中的 basic 镜像更小，适合用于初次部署测试。每增加一个镜像版本都需要额外的空间。
* 能够访问 GitHub、GitHub Container Registry（`ghcr.io`）和 Docker Hub 的网络，以便克隆 Toolkit 和下载镜像。

**PowerShell** 代码块在 Windows 中运行。除非另有说明，**Bash** 代码块和 `bin/` 命令都在 Ubuntu 中运行。不要在 PowerShell 或 Windows Git Bash 中运行 Toolkit 脚本。
