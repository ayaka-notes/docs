Toolkit 与 Linux 上的完全相同。其目录结构、`config/` 目录和 `bin/` 命令已在 Linux 指南的 [2. 熟悉 Toolkit](/zh-CN/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit) 中介绍。

在 Windows 上，请注意以下不同之处：

* 请在 **Ubuntu Bash** 中，从 `~/ayakaleaf-toolkit` 目录运行 `bin/` 命令。标记为 **PowerShell** 的命令则在 Windows 中运行。
* 在使用 `bin/up`、`bin/start` 或 `bin/docker-compose` 之前，请先启动 Docker Desktop 并为 Ubuntu 启用 WSL Integration。
* 配置文件请保持 Linux 换行符（LF）。请在 Ubuntu 中使用 `nano` 或连接到 WSL 的编辑器来编辑它们。CRLF 换行符可能导致 Bash 错误。
* `bin/doctor` 会在 Ubuntu 中运行 Linux 检查。其中关于未登录 `quay.io` 的警告不适用于公开的 `ghcr.io/ayaka-notes/overleaf-pro` 镜像。其他警告仍需处理。

```bash
bin/doctor
```
