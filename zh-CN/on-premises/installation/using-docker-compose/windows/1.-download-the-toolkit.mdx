---
title: 1. 下载 Toolkit
description: 在 WSL 2 的 Ubuntu 中安装命令行依赖并克隆 Ayakaleaf Toolkit。
icon: arrow-down-to-bracket
---

<Steps>
<Step title="安装命令行工具">
在 **Ubuntu** 中运行以下命令，并使用你在第 0 步中创建的 Linux 密码：

```bash
sudo apt update
sudo apt install -y git ca-certificates curl perl gawk openssl
```

Ubuntu 已经自带 Bash、GNU sed 和 coreutils。与 macOS 不同，它不需要 Homebrew，也不需要单独安装 GNU sed。
</Step>

<Step title="克隆 Ayakaleaf Toolkit 仓库">
请将 Toolkit 及其数据保存在 Ubuntu 的 Linux 文件系统中，放在你的主目录下：

```bash
cd "$HOME"
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

不要将实时数据库和项目数据放在 `/mnt/c`、`/mnt/d`、OneDrive 或临时目录中。Linux 文件系统路径能提供容器所期望的权限和文件系统行为，并避免跨文件系统带来的开销；请参阅 [Microsoft 的文件系统指南](https://learn.microsoft.com/en-us/windows/wsl/filesystems)。

<Warning>

如果该目录中已经存在一个安装，请按原样使用它，或为新实例选择另一个目录。不要替换现有部署的配置或数据。

</Warning>
</Step>
</Steps>
