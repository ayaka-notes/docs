---
title: 4. 获取 Ayakaleaf Pro 镜像
icon: split
---

Ayakaleaf Pro 是发布在 [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/) 上的免费 Docker 镜像。拉取该镜像无需账户，也无需登录。镜像针对 amd64 和 arm64 架构构建，Docker 会自动选择与你的服务器匹配的镜像。

打开 `config/overleaf.rc` 并设置：

```text title="config/overleaf.rc"
SERVER_PRO=true
```

下次运行 `bin/up` 时，Toolkit 会下载 Ayakaleaf Pro 镜像，并用它代替官方的 Overleaf 社区版。你在 `config/` 中的设置将继续有效。

<Accordion title="已经在运行官方 Overleaf Toolkit（overleaf/toolkit）？">

你无需重新安装。拉取 Ayakaleaf Pro 镜像：

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

然后在 `overleaf-toolkit/config` 目录中添加一个名为 `docker-compose.override.yml` 的文件，内容如下：

```yml
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

下次运行 `bin/up` 时，Toolkit 会使用 Ayakaleaf Pro 镜像。

</Accordion>
