---
title: 4. 获取 Ayakaleaf Pro 镜像
icon: split
---

Ayakaleaf Pro 以 Docker 镜像的形式发布在 [ghcr](https://github.com/ayaka-notes/overleaf-pro/pkgs/container/overleaf-pro/) 镜像仓库中，任何人都可以**公开访问**。我们同时提供 amd64 和 arm64 架构的镜像。拉取镜像时，系统会根据你的系统架构自动选择合适的镜像。

#### Ayaka-notes Toolkit 用户

如果你使用的是 [ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)，Ayakaleaf Pro 可以直接替换社区版使用，因此你可以沿用现有的设置和自定义配置。要在 Toolkit 中启用 Pro，请编辑 `config/overleaf.rc` 并设置 `SERVER_PRO` 环境变量：

```text title="config/overleaf.rc"
SERVER_PRO=true
```

下次运行 `bin/up` 时，Toolkit 会自动下载并使用 Ayakaleaf Pro 镜像。

#### 官方 Toolkit 用户

如果你使用的是 [overleaf/toolkit](https://github.com/overleaf/toolkit)，要获取 Pro 镜像，请运行以下命令进行拉取：

```bash title="Pull Docker Images"
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

然后，在 `overleaf-toolkit/config` 目录中添加一个名为 `docker-compose.override.yml` 的文件，内容如下：

```yml title="docker-compose.override.yml"
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

下次运行 `bin/up` 时，Toolkit 会自动下载并使用 Ayakaleaf Pro 镜像。
