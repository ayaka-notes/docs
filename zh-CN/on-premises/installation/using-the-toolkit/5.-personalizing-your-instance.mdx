### 个性化你的实例

在首次启动 Overleaf 实例之前，请在 `config/variables.env` 配置文件中填入你的自定义信息。

<Steps>
<Step title="编辑变量文件">
用你喜欢的文本编辑器打开 `config/variables.env`，并为下列环境变量填入所需的值。
</Step>

<Step title="必需的环境变量">
更新 `config/variables.env` 中的以下变量：

| 名称                          | 描述                                                                                                                                                    | 示例                         |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| `OVERLEAF_SITE_URL`           | 你的 Overleaf 实例对外公开访问的地址。它用于公开链接以及 WebSocket 连接，因此**必须正确配置**！ | `https://overleaf.lilliput.com` |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | 该邮箱地址将用作所有外发邮件的 `from` 地址。                                                                                 | `no-reply@lilliput.com`         |
| `OVERLEAF_ADMIN_EMAIL`        | 用户可以通过该邮箱地址联系站点运维人员。                                                                                          | `it-services@lilliput.com`      |

更新这些环境变量后，保存并退出。
</Step>

<Step title="配置沙箱编译">
接下来，为 [sandboxed-compiles.md](/zh-CN/on-premises/configuration/overleaf-toolkit/sandboxed-compiles  "mention") 配置 TeX Live Full。打开 `config/variables.env` 并更新以下环境变量：

```dotenv title="config/variables.env" wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```
</Step>

<Step title="启动你的实例">
运行以下命令启动实例：

```text title="Start the instance"
bin/up
```

该命令会下载所需的镜像（包括 texlive），创建容器（使用你的自定义配置）并启动实例。你应该能看到来自各个 Docker 容器的日志输出。

之后如需再次启动（且不附加到日志输出），请运行：

```text title="Start without attaching to logs"
bin/start
```
</Step>
</Steps>

<Info>

Toolkit 使用 `docker compose` 来管理 Overleaf 的 Docker 容器。Toolkit 提供了一组封装 `docker compose` 的脚本，会替你处理大部分细节。

</Info>

如果一切顺利，你应该可以在浏览器中访问 [http://127.0.0.1/](http://127.0.0.1/) 或 [http://localhost/](http://localhost/)，看到新 Overleaf 实例的登录页面。

<Warning>

根据你的网络配置以及 Overleaf 实例的托管位置，你可能需要进行额外的配置更改。更多详情请参阅 Toolkit 设置：[toolkit-settings.md](/zh-CN/on-premises/configuration/overleaf-toolkit/toolkit-settings  "mention")

</Warning>
