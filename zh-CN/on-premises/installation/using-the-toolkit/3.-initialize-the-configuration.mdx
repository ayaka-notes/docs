### 初始化配置

让我们运行随附的 `bin/init` 脚本，用一些合理的默认值来初始化新服务器的配置文件。

```text title="Run initialization"
bin/init
```

该脚本**不会**覆盖任何已有的配置文件。

现在，让我们使用 `ls` 命令查看 `config/` 目录的内容：

```text title="List the config directory"
ls config
```

如果一切初始化成功，您应该会看到三个配置文件：`overleaf.rc`、`variables.env` 和 `version`。这些是服务器的主要配置文件，可用于自定义服务器的运行方式以及用户与实例的交互方式。

| 名称            | 描述                                                    |
| --------------- | ------------------------------------------------------- |
| `overleaf.rc`   | 主顶层配置文件。                                        |
| `variables.env` | 加载到 Docker 容器中的环境变量。                        |
| `version`       | 要使用的 Docker 镜像版本。                              |

<Info>

目前，您只需知道这些文件的存在及其位置即可。在后续文档中，我们将详细介绍每个文件，并说明如何使用它们来自定义您的实例。如果您想提前了解，可以在[文件和位置页面](/zh-CN/on-premises/configuration/overleaf-toolkit/files-and-locations)查看这些配置文件的完整说明。

</Info>
