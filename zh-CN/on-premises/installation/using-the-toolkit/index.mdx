[Toolkit](https://github.com/ayaka-notes/toolkit) 是部署 Ayakaleaf Pro 实例的推荐方式。

在本节中，我们将指导你从 GitHub 下载 Toolkit，熟悉 Toolkit 的一些命令，并配置一些基本设置。完成本页内容后，你应该就拥有一个正在运行的本地 Overleaf 实例了。

<Info>

默认情况下，实例只接受来自服务器本身的连接，地址为 `http://localhost`。若要从其他计算机或通过其他端口访问，请在 `config/overleaf.rc` 中设置 `OVERLEAF_LISTEN_IP` 和 `OVERLEAF_PORT`，详见 [5. 个性化你的实例](/zh-CN/on-premises/installation/using-the-toolkit/5.-personalizing-your-instance)。

</Info>
