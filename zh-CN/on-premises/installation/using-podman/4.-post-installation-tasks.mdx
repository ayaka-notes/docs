### 创建你的第一个管理员账户 {#create-your-first-administrator-account}

打开 [http://localhost:8080/launchpad](http://localhost:8080/launchpad)，或者你的 `OVERLEAF_SITE_URL` 加上 `/launchpad`，注册管理员账户。从这里开始，一切都与 Docker 相同：按照 Docker 指南中的 [6. 安装后任务](/zh-CN/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks) 操作，并在其中的 `localhost` 链接里使用端口 `8080`。

创建示例项目并编译它。生成的 PDF 表明编译通过 Podman 在 TeX Live 容器中运行。要查看编译容器：

```bash title="List the compile containers"
podman ps -a --filter name=project- --format "{{.Names}} {{.Image}} {{.Status}}"
```

### 使用 HTTPS {#use-https}

Toolkit 的 [TLS 代理](/zh-CN/on-premises/configuration/overleaf-toolkit/tls-proxy) 可以在 Podman 上使用：运行 `bin/init --tls`，并按照该页面的说明设置证书和 `NGINX_ENABLED=true`。它监听端口 `80` 和 `443`，而 rootless Podman 默认不能使用这些端口。允许非特权用户使用从 `80` 开始的端口：

```bash title="Allow ports 80 and 443"
echo "net.ipv4.ip_unprivileged_port_start=80" | sudo tee /etc/sysctl.d/99-unprivileged-ports.conf
sudo sysctl --system
```

这会让服务器上的每个用户都能监听这些端口，因此只应在专用于 Ayakaleaf Pro 的服务器上这样做。然后在防火墙中开放这些端口：

```bash title="Open ports 80 and 443"
sudo firewall-cmd --permanent --add-port=80/tcp --add-port=443/tcp
sudo firewall-cmd --reload
```

将 `OVERLEAF_SITE_URL` 设置为你的 `https://` 地址，然后运行 `bin/up -d`。保持默认的 `NGINX_HTTP_PORT=80` 和 `TLS_PORT=443`：使用其他端口时，从 HTTP 到 HTTPS 的重定向会指向错误的端口。

<Info>

使用 TLS 代理时，请将 `OVERLEAF_LISTEN_IP` 保持为 `127.0.0.1`，这样其他计算机就无法访问端口 `8080`。

</Info>

### 升级 {#upgrade}

使用 `bin/upgrade` 升级，详见 [升级你的部署](/zh-CN/on-premises/maintenance/upgrading-your-deployment)。在 Podman 上，它还会把新版本的 seccomp 配置文件提取到 `config/seccomp/<version>/`，并更新 `SECCOMP_PROFILE`：

```text
Over-writing config/version with 6.3.4
Set SECCOMP_PROFILE=/home/<user>/overleaf-toolkit/config/seccomp/6.3.4/clsi-profile.json in config/variables.env
```

升级后，运行 `bin/podman-setup` 检查设置。

### 更改 SELinux 模式 {#change-the-selinux-mode}

`config/overleaf.rc` 中的 `SELINUX_MODE` 决定 SELinux 如何限制 `sharelatex` 容器。这些页面设置的是 `managed`；其他模式请参阅 [Toolkit 设置](/zh-CN/on-premises/configuration/overleaf-toolkit/toolkit-settings)。更改后请运行 `bin/up -d`。
