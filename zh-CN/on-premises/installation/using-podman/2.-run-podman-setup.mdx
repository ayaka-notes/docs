---
title: 2. 运行 podman-setup
description: 让 bin/podman-setup 检查主机，并设置 rootless Podman、SELinux 和 seccomp 配置文件。
icon: wand-magic-sparkles
---

`bin/podman-setup` 会检查 Ayakaleaf Pro 在 Podman 上所需的一切。不带选项时它只报告结果；带上 `--apply` 时，它还会修复发现的问题。

<Steps>
<Step title="检查主机">
```bash title="Check only"
bin/podman-setup
```

在全新的主机上，大多数检查都会失败，例如：

```text
====== Packages ======
[✗] podman not installed
[✗] podman-docker not installed
...
====== Summary ======
[✓] 7 passed  [!] 13 warnings  [✗] 4 failures
```
</Step>

<Step title="应用修复">
```bash title="Check and fix"
bin/podman-setup --apply
```

请在终端中运行它：执行系统级步骤时，它会询问你的 `sudo` 密码。它还会下载 Ayakaleaf Pro 镜像以提取其中的 seccomp 配置文件，第一次运行需要几分钟。最后，它会再次检查主机：

```text
====== Summary ======
[✓] 23 passed  [!] 2 warnings  [✗] 0 failures
[!] Warnings remaining:
[!] not logged in to quay.io
[!] container → socket skipped (sharelatex not running)
```

此时出现这两个警告都是正常的：

* `not logged in to quay.io`：这项检查来自官方 Toolkit，在那里 Server Pro 镜像位于私有镜像仓库中。Ayakaleaf Pro 镜像在 `ghcr.io` 上公开提供，无需登录，因此可以忽略它。安装完成后它也会一直存在。
* `container → socket skipped (sharelatex not running)`：这项测试需要正在运行的实例。你将在 [3. 启动 Ayakaleaf Pro](/zh-CN/on-premises/installation/using-podman/3.-start-ayakaleaf-pro) 中再次运行该脚本。

所有检查通过时脚本以 `0` 退出，有警告时以 `1` 退出，有失败时以 `2` 退出。由于 quay.io 警告，预期结果是 `1`。
</Step>
</Steps>

### 脚本会更改什么 {#what-the-script-changes}

使用 `--apply` 时，脚本可能会更改以下内容。

系统级，通过 `sudo`：

* 使用 `dnf` 安装 `podman`、`podman-docker`、`git`、`curl`、`checkpolicy` 和 `policycoreutils`。
* 使用 `loginctl` 为你的用户启用 lingering，这样你注销后容器仍会继续运行。
* 创建 `/etc/containers/nodocker`，用于屏蔽 "Emulate Docker CLI using podman" 消息。
* 当 `SELINUX_MODE=managed` 时，加载 SELinux 策略模块 `podman_socket_clsi`。

针对你的用户：

* 启用用户服务 `podman.socket`，即 Ayakaleaf Pro 用来启动编译的 Docker 兼容 API。
* 从 GitHub 安装 Docker Compose v2 到 `~/.local/bin/docker-compose`，并在 `~/.docker/cli-plugins/` 中创建链接。
* 在 `~/.config/containers/containers.conf` 中让 Podman 使用这个 Compose。
* 在 `~/.config/containers/registries.conf.d/overleaf-toolkit.conf` 中添加别名 `mongo` 和 `redis`，让 Podman 知道从哪里拉取这些短镜像名。

在 Toolkit 中：

* 将 `config/overleaf.rc` 中的 `DOCKER_SOCKET_PATH` 和 `DOCKER_HOST` 设置为 `/run/user/<uid>/podman/podman.sock`。
* 从 Ayakaleaf Pro 镜像中提取编译用的 seccomp 配置文件到 `config/seccomp/<version>/clsi-profile.json`，并在 `config/variables.env` 中设置 `SECCOMP_PROFILE`。与 Docker 不同，Podman 需要把这个配置文件作为主机上的文件。
* 在 `config/selinux/` 中构建 SELinux 策略模块。
* 在 `data/` 中的数据目录创建后，使用 `podman unshare chown` 设置它们的所有者。

<Info>

每项更改都对应一项检查。如果你手动更改了某些内容，例如 `config/overleaf.rc` 中的设置，请再次运行 `bin/podman-setup` 进行验证。

</Info>
