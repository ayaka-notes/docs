### 账户

在管理自己账户方面，**所有**用户都被视为普通用户——`Site Admins` 和 `Template Users` **不会**获得任何额外权限。不过，普通用户可执行的操作会因其身份验证方式而受到限制。

#### 设置

<strong>身份验证类型：内部账户 | SSO（SAML/LDAP）</strong>

| 操作 | 内部账户 | SSO（SAML/LDAP） |
| ----------------------------------------- | ----------------: | --------------: |
| 更新账户信息 | 是 | 否 |
| 修改密码 | 是 | 否 |
| 生成 Git bridge 身份验证令牌 | 是 | 是 |
| 删除 Git bridge 身份验证令牌 | 是 | 是 |
| 管理会话 | 是 | 是 |

<Info>

Git Bridge 集成**仅**在 Server Pro 中可用。更多信息请查看 [Server Pro 与 Community Edition 对比](/zh-CN/on-premises/readme/ayakaleaf-pro-vs-server-pro)。

</Info>

#### 你的会话

| 操作 | 用户 |
| -------------------- | ---: |
| 清除会话 | 是 |
| 查看当前会话 | 是 |
| 查看其他会话 | 是 |

### 编辑器 IDE

在 Overleaf 编辑器 IDE 中，你可能是以下角色之一：`Project Owner`、`Editor`、`Reviewer`、`Viewer`、`Site Administrator` 或 `Template User`。

<Info>

Server Pro 和 Community Edition 支持为项目提供匿名的**只读**和**读写**访问。

更多信息请查看[此处](/zh-CN/on-premises/configuration/overleaf-toolkit/environment-variables)的 `OVERLEAF_ALLOW_PUBLIC_ACCESS` 和 `OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` 环境变量。

</Info>
