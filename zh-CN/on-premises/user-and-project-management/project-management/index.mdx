### 查看项目审计日志

管理员可以查看每个项目的**审计日志（Audit Log）**。该审计日志会显示各类事件，例如链接共享在私有/基于令牌之间切换的时间、邀请发送/接受的时间，以及用户通过令牌加入项目的时间。管理员可以通过 **Your Instance** -> **Admin** -> **Manage Users** 按项目查看这些日志，然后：

* 搜索该用户
* 点击 **Projects** 选项卡
* 选择一个项目
* 点击 (i) 图标
* 点击 **Audit Log** 选项卡

如果项目通过电子邮件地址与指定的协作者共享，那么在接收者加入后，他们将连同其权限一起列在共享（Share）对话框中，项目所有者可以看到。管理员通过管理面板查看该项目的 Project Info 选项卡时，也会显示这些信息。

### 恢复已删除的文档

1. 使用管理员凭据登录
2. 点击 **Admin** 并选择 **Manage Users**
3. 在搜索框中输入要为其恢复文档的用户的电子邮件地址
4. 在返回的结果列表中点击其电子邮件地址，打开其用户信息页面
5. 点击 **Projects** 选项卡，并使用搜索框搜索该项目
6. 点击项目名称旁边的信息图标，打开 **Project Info**
7. 点击 **Deleted Docs** 选项卡
8. 点击已删除文档旁边的 **Undelete** 按钮，将其恢复到用户的项目中。

恢复的文件将采用以下格式：`FILENAME-TIMESTAMP.EXTENSION`。例如，`main.tex` 的恢复版本将被恢复到项目根目录，文件名为 `main-2024-02-23-130441542.tex`。

### 转移项目所有权

Server Pro 的管理面板为每个项目提供了专门的页面。您可以在 "/admin/user" 上搜索用户，然后进入其 **Projects** 选项卡，在列表中找到该项目并点击信息图标；也可以使用已知的项目 ID 直接访问 [**https://your-instance-url/admin/project/**](https://your-instance-url/admin/project/) 页面。在项目信息页面上，您可以找到 **Transfer Ownership** 按钮，点击后会打开一个对话框，您可以在其中指定任意用户作为新的所有者。新所有者不必是该项目的现有协作者。

<Info>

请注意，在所有权转移过程中，原所有者将被添加为对该项目具有读写权限的协作者。

</Info>

### 更新项目编译超时

项目的默认编译超时目前设置为 180 秒。可以更改此值，需要分两步进行。

首先，编辑 **config/variables.env** 文件，添加 `COMPILE_TIMEOUT` 环境变量，并将其值设置为所需的超时时间（以秒为单位）。例如，`COMPILE_TIMEOUT=300` 表示 5 分钟。

<Danger>

将超时设置为超过 10 分钟没有意义。如果这样做，您很可能会在应用程序的其他组件中遇到超时。

</Danger>

完成此更改后，您需要运行 `bin/up -d` 命令重新创建 **sharelatex** 容器。

设置此环境变量只会更新新用户的超时值，**不会**追溯应用于现有用户，因为该值是在首次创建用户时写入的。

要调整现有用户的超时，您需要修改数据库中的每条用户记录。我们建议在执行此操作时务必谨慎，并建议在进行任何更改之前先做一份一致性备份。

有关执行备份的信息，请参阅[这里](/zh-CN/on-premises/maintenance/data-and-backups)。

要更新所有现有用户的编译超时值，您需要在 Docker 主机上运行以下 shell 命令：

```bash wrap
echo 'db.users.updateMany({}, {$set: {"features.compileTimeout": <value>}})' | docker exec -i mongo mongosh --quiet localhost/sharelatex
```

您需要将上述查询中的 `<value>` 替换为所需的超时值（以秒为单位）。

命令完成后，您应该会看到一条确认信息，其中包含已修改的记录数。然后，您可以输入 exit 并按回车键返回主机 shell。

### 跟踪项目访问

可以使用以下命令查看谁在何时加载了项目：

```bash wrap
docker exec sharelatex bash -c 'grep "join project request" /var/log/overleaf/web.log'
```

这将同时提供 `timestamp`、`user_id` 和 `project_id`。
