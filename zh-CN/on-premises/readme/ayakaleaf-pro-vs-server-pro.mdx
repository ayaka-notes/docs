<Info>

Ayakaleaf Pro 是 Overleaf Community Edition 的增强实现，_**免费**_ 提供 Server Pro 的全部 _**高级**_ 功能。与 [https://www.overleaf.com/](https://www.overleaf.com/) 上的 Overleaf Common 不同，我们没有编译时间限制，对用户数量没有许可证要求，并且你可以完全自托管自己的数据，确保绝对安全。

Overleaf Server Pro 是 Overleaf 的商业自托管部署版本，提供官方支持。有关 Server Pro 的更多信息，请访问 [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud)。

</Info>

<Warning>

Overleaf Community Edition 旨在用于**所有**用户都受信任的环境。由于不支持沙盒编译，Community Edition **不**适用于需要隔离用户的场景。

如果没有沙盒，LaTeX 编译将以与容器相同的权限运行，从而可以访问容器的文件系统、网络和环境变量。这会带来数据泄露或系统被入侵的风险。非沙盒编译只应在完全受信任的环境中使用；对于多用户或生产环境部署，强烈建议使用沙盒编译。

有关沙盒编译的更多信息，请查看我们的[文档](/zh-CN/on-premises/configuration/overleaf-toolkit/sandboxed-compiles)。

</Warning>

### 社区支持

对于使用自托管 Overleaf 实例的用户，社区通过 GitHub [Issues](https://github.com/ayaka-notes/overleaf-pro/issues) 提供支持。

为了保持在受支持的版本上，你可以将以下命令的输出与发布说明中公布的镜像 ID 进行比较，以确认你正在运行的 Overleaf 版本。

```bash
docker inspect --format '{{.Image}}' sharelatex | awk -F: '{print substr($2, 1, 12)}'
```
