我们尊重版权，因此在此列出本项目中使用的所有功能和代码。本页介绍 Ayakaleaf Pro 的新功能及相关代码的版权信息。

除非另有说明，我们使用 OpenAI 的 Codex 进行代码审查和 PR 审查。在此过程中，我们修复了许多安全问题，在此向他们致以诚挚的感谢。详情请参阅 [ayaka-notes/ayakaleaf-pro/pull](https://github.com/ayaka-notes/ayakaleaf-pro/pulls)。

### 概览

多年来，许多社区开发者为改进 Overleaf 社区版付出了大量努力。他们是：

* [https://github.com/ertuil/overleaf](https://github.com/ertuil/overleaf)
* [https://github.com/AllanChain/lcpu-overleaf](https://github.com/AllanChain/lcpu-overleaf)
* [https://github.com/yu-i-i/overleaf-cep/](https://github.com/yu-i-i/overleaf-cep/)
* [https://github.com/ayaka-notes/overleaf](https://github.com/ayaka-notes/overleaf)
* [https://github.com/davrot/overleaf\_with\_admin\_extension](https://github.com/davrot/overleaf_with_admin_extension)
* [https://github.com/overleaf/overleaf/pull/1447](https://github.com/overleaf/overleaf/pull/1447)（GitHub 集成）
* [https://github.com/overleaf/overleaf/pull/1385](https://github.com/overleaf/overleaf/pull/1385)（Typst 支持）

我们可能在项目中使用了相关代码，在此向他们表示感谢。

#### 功能 01：模板系统

此功能主要由 [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep) 开发。我们修改了部分代码以进行增强，使你可以：

* 直接在模板页面下载模板。
* 打开模板对应的项目。
* 转换出更高质量的封面图片（且耗时更短）。

此功能由 [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) 开发。Overleaf 提供了一个名为 git-bridge 的官方组件，可在[这里](https://github.com/overleaf/overleaf/tree/main/services/git-bridge)获取。

我们只是实现了 git-bridge 与 Overleaf 之间的连接器，这与 Overleaf 在其 SaaS 平台上的做法相同。

#### 功能 05：管理面板

<Warning>

当你的系统中有 1000 个用户或项目时，管理面板只会显示最新的 1000 个用户或项目。请使用搜索面板搜索特定的用户或项目。

</Warning>

此功能主要由 [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep) 开发。我们修改了部分代码以进行增强，使你可以：

* 当用户超过 1000 个时，通过后端搜索用户。
* 当项目超过 1000 个时，通过后端搜索项目。
* 直接在项目管理面板中打开项目。
* 在管理面板中查看和调整用户的编译时间限制。
* 直接在管理面板中重置用户密码。
* 其他增强……

#### 功能 16：AI 聊天与 LaTeX 错误助手

Ayakaleaf Pro 带来了 AI 助手和错误助手：AI 助手可以将你的项目文档和当前选中内容作为上下文来回答问题，并提出修改建议供你审阅；而当你选中某个 LaTeX 编译错误时，错误助手会提出有针对性的修复方案。

#### 功能 17：文献管理器集成

此功能由 [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) 开发。Zotero 集成最初由 [davrot](https://github.com/davrot) 和 [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep) 开发；我们在 v6.3.0 中基于 OAuth 对其进行了重构，并新增了 Mendeley 集成（OAuth 2.0）。你可以：

* 在账户设置中关联你的 Zotero 和 Mendeley 账户。
* 将你的个人文献库或群组文献库作为 `.bib` 文件导入到项目中。
* 随时刷新导入的 `.bib` 文件，使其保持最新。

有关设置方法，请参阅 [Zotero 集成](/zh-CN/on-premises/configuration/overleaf-toolkit/zotero-integration) 和 [Mendeley 集成](/zh-CN/on-premises/configuration/overleaf-toolkit/mendeley-integration)。

#### 功能 18：Open in Overleaf API

此功能由 [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) 开发，兼容 overleaf.com 的“Open in Overleaf” API。你可以在你的网站、博客或模板库中添加“Open in Ayakaleaf”链接或按钮，访问者只需点击一下，即可将 LaTeX 代码片段、远程文件或 ZIP 项目作为新项目在你的实例中打开。详情请访问你实例上的 `/devs`，并参阅 [Overleaf Import API](/zh-CN/on-premises/configuration/overleaf-toolkit/overleaf-import-api)。
