我们尊重版权，因此在此列出本项目中使用的所有功能和代码。本页介绍 Ayakaleaf Pro 的新功能以及相关代码的版权信息。

除非另有说明，我们使用 OpenAI 的 Codex 进行代码审查和 PR 审查。在此过程中，我们修复了许多安全问题，并向他们致以诚挚的感谢。详情请参阅 [ayaka-notes/ayakaleaf-pro/pull](https://github.com/ayaka-notes/ayakaleaf-pro/pulls)。

### 概述

多年来，许多社区开发者为改进 Overleaf 社区版付出了巨大努力。他们是：

* [https://github.com/ertuil/overleaf](https://github.com/ertuil/overleaf)
* [https://github.com/AllanChain/lcpu-overleaf](https://github.com/AllanChain/lcpu-overleaf)
* [https://github.com/yu-i-i/overleaf-cep/](https://github.com/yu-i-i/overleaf-cep/)
* [https://github.com/ayaka-notes/overleaf](https://github.com/ayaka-notes/overleaf)
* [https://github.com/davrot/overleaf\_with\_admin\_extension](https://github.com/davrot/overleaf_with_admin_extension)
* [https://github.com/overleaf/overleaf/pull/1447](https://github.com/overleaf/overleaf/pull/1447)（GitHub 集成）
* [https://github.com/overleaf/overleaf/pull/1385](https://github.com/overleaf/overleaf/pull/1385)（Typst 支持）

我们的项目中可能使用了相关代码，在此向他们表示感谢。

#### 功能 01：模板系统

此功能主要由 [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep) 开发。我们修改了部分代码以进行增强，使您可以：

* 直接在模板页面下载模板。
* 打开模板对应的项目。
* 转换出更高质量的封面图片（且耗时更短）。

#### 功能 03：​Git 集成​

此功能由 [ayaka-notes/overleaf-pro](https://github.com/ayaka-notes/overleaf-pro) 开发。Overleaf 提供了一个名为 git-bridge 的官方组件，可在[此处](https://github.com/overleaf/overleaf/tree/main/services/git-bridge)获取。

我们只是实现了 git-bridge 与 Overleaf 之间的连接器，这与 Overleaf 在其 SaaS 平台上的做法相同。

#### 功能 05：管理面板

<Warning>

当您的系统中有 1000 个用户或项目时，管理面板只会显示最新的 1000 个用户或项目。请使用搜索面板搜索特定的用户或项目。

</Warning>

此功能主要由 [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep) 开发。我们修改了部分代码以进行增强，使您可以：

* 在用户超过 1000 个时通过后端搜索用户。
* 在项目超过 1000 个时通过后端搜索项目。
* 直接在项目管理面板中打开项目。
* 在管理面板中查看和调整用户的编译时间限制。
* 直接在管理面板中重置用户密码。
* 其他增强功能……

#### 功能 07：外部 URL

此功能主要由 [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep) 开发。CEP 实现了一个名为 linked-url-proxy 的外部服务，可在域名/IP 限制下安全地获取外部文件。

此功能主要由 [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep) 开发。CEP 实现了一个子模块，将 passport 与 Overleaf Web 认证连接起来。

我们使用 GitHub Actions 为 x86 和 arm 架构构建并发布 Docker 镜像。下载镜像时，系统会根据您的环境自动选择合适的架构。

#### 功能 10：自助注册

此功能由 [ayaka-notes/overleaf-pro](https://github.com/ayaka-notes/overleaf-pro) 开发。您可以：

* 限制只有特定域名的用户才能注册
* 向所有能够访问您 Overleaf 的人开放注册

此功能由 [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) 开发。您可以查看来自 Overleaf 的最新 Learn Wiki，但我们不拥有这些文档的任何版权！我们只是在您首次启用此功能时从 Overleaf 服务器下载这些文档，并定期更新。

#### 功能 16：AI 聊天与 LaTeX 错误助手

Ayakaleaf Pro 带来了 AI 助手和错误助手：AI 助手可以将您的项目文档和当前选区作为上下文来回答问题，并提出修改建议供您审阅；而当您选中某个 LaTeX 编译错误时，错误助手会给出有针对性的修复方案。
