我们在此汇总了一些关于 Ayakaleaf Pro 的常见问题解答。

### 基础问题

<Accordion title="Q01：Ayakaleaf Pro 是免费试用版吗？需要许可证吗？">

不是。Ayakaleaf Pro 完全免费使用。它不是试用版，也不需要任何许可证。

</Accordion>

<Accordion title="Q02：Ayakaleaf Pro 是否包含 Overleaf Server Pro 的全部功能？">

是的。Ayakaleaf Pro 包含 Overleaf Server Pro 的全部功能，包括 Git-Bridge 集成。它还包含来自 Overleaf SaaS 平台的部分精选功能。我们会持续开发和改进 Ayakaleaf Pro。

</Accordion>

<Accordion title="Q03：Overleaf Server Pro 的价格是多少？">

Overleaf Server Pro 的费用约为每位用户每年 \$300。它要求至少购买 10 个许可证，因此部署起价约为每年 \$3,000。美国一些规模较小的公开合同显示，年费用约为每位用户 \$320–\$370。这使得 Server Pro 价格昂贵，对小型团队而言尤其如此。有关已记录的采购和价格信息，请参阅 [#information-and-price-about-overleaf-server-pro](/zh-CN/on-premises#information-and-price-about-overleaf-server-pro  "mention")。

</Accordion>

<Accordion title="Q04：为什么 Overleaf Server Pro 不包含 GitHub 同步或 AI 功能？">

Overleaf Server Pro 通常被政府机构使用。他们将其部署在私有网络中，并严格控制访问。为保护敏感数据，其内置功能会避免与第三方服务交换数据。如果您需要 GitHub 同步、AI 或类似的联网功能，Overleaf 建议订阅其 SaaS 平台。

</Accordion>

<Accordion title="Q05：Ayakaleaf Pro 安全可靠吗？">

Ayakaleaf Pro 是开源的。我们使用 Codex Security 等工具审查代码，以增强其安全性和可靠性。如果您不启用第三方数据同步，您的数据将始终保留在您的服务器上。Ayakaleaf Pro 不包含任何会将您的数据发送到其他地方的遥测功能。

</Accordion>

<Accordion title="Q06：Ayakaleaf Pro 会长期维护吗？">

我们将尽一切努力长期维护本项目。

</Accordion>

<Accordion title="Q07：Ayakaleaf Pro 合规吗？">

Ayakaleaf Pro 是一个社区分支。其代码和集成功能均来自社区贡献。它采用 AGPL v3 许可证。只要满足该许可证的要求，部署即可符合该许可证。

</Accordion>

<Accordion title="Q08：为什么项目名为 Ayakaleaf Pro？">

该项目最初于 2024 年命名为 Overleaf Pro。开发曾暂停一段时间，随后在 2025 年底重新启动。2026 年第一季度，Overleaf 将其支持 AI 的订阅计划更名为 Pro。社区反馈也指出，Overleaf Pro 这个名称可能带来商标和冒充方面的风险，可能让用户误以为该项目是官方项目。

为避免这种混淆，我们将项目更名为 Ayakaleaf Pro。这个名称可以理解为"Ayaka-notes Overleaf Pro"。维护者从五年多前的学生时代起就一直为 Overleaf 社区开发做出贡献。这段经历为我们的长期维护承诺提供了保障。

</Accordion>

<Accordion title="Q09：Ayakaleaf Pro 与新兴的 AI 构建的 LaTeX 编辑器有何不同？">

自 2026 年以来，开源社区发布了许多 AI 构建的 LaTeX 编辑器，包括 OpenAI Prism。Ayakaleaf Pro 将您的数据和服务保留在您自己的服务器上，让您能够直接掌控自己的部署和数据。

许多实验性的社区编辑器并没有成熟的长期维护计划。第三方 LaTeX 编译平台也可能在用户群或收入不足时停止运营。Ayakaleaf Pro 提供全部源代码，并允许您自托管所有服务。即使维护停止，您现有的自托管服务也可以继续运行。

</Accordion>

### LaTeX

<Accordion title="Q01：用户的 LaTeX 项目编译是否相互隔离？是否启用了 Shell Escape？">

启用沙盒编译（Sandbox Compiles）后，每个用户的编译都在单独的 Docker 容器中运行，并与其他用户的编译相互隔离。沙盒编译默认启用 Shell Escape。

</Accordion>

<Accordion title="Q02：沙盒编译镜像可靠吗？编译会失败吗？">

在过去三年中，我们不断改进用于沙盒编译的 TeX Live Full 镜像。在大多数情况下，能在 overleaf.com 上编译的项目也能在 Ayakaleaf Pro 中正确编译。如果缺少所需的字体，请手动将该字体上传到您的项目中。

</Accordion>
