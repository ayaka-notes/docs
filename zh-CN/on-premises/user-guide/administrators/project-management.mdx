## 查找项目 {#find-a-project}

在 **Search by project name, ID, owner or link** 中输入内容。链接可以是项目地址，也可以是它的某个共享链接。使用 **Status** 筛选器缩小列表范围。点击 **Title** 或 **Last modified** 进行排序。

已删除的项目不会出现在结果中。如果你的搜索也匹配到已删除的项目，表格上方会有一行提示，例如 **Found 1 matching deleted projects**。点击 **Display deleted projects** 即可查看。

## 项目状态 {#project-status}

每个项目都有一个状态，**Status** 筛选器会显示每种状态下的项目数量。

<Frame caption="Status 筛选器">
  <img src="/images/on-premises/project-management-status-filter.png" alt="包含 All、Active、Archived、Trashed 和 Deleted 的 Status 筛选器" />
</Frame>

| 状态 | 含义 |
| --- | --- |
| **All** | 所有未删除的项目。 |
| **Active** | 正常状态。 |
| **Archived** | 所有者已将其归档。项目完好无损，可以恢复。 |
| **Trashed** | 所有者已将其移入回收站。项目完好无损，可以恢复。 |
| **Deleted** | 由所有者从回收站中删除、由管理员删除，或随所有者账号一起删除。只有管理员可以恢复。 |

项目会分阶段经历这些状态：

1. **Active、Archived 和 Trashed** 由所有者在自己的项目页面中选择。所有者随时可以改回来。从回收站 **Restore** 总是回到 Active，即使项目之前是归档状态。
2. **Deleted** 是下一阶段。所有者只能从回收站中删除；管理员可以从这三种状态中的任何一种删除。
3. **Restore** 会把已删除的项目恢复为 **Active**，无论其之前是什么状态，并且项目名称末尾会加上 `(Restored)`。只有管理员可以执行此操作。如果所有者的账号也已删除，请先恢复账号：否则对话框会显示 **The owner of this project is deleted: restore the owner first**。
4. **Delete permanently** 是最后阶段，无法撤销。除此之外，已删除的项目会一直保留，直到你将其移除，除非实例设置了 [`ENABLE_CRON_RESOURCE_DELETION`](/zh-CN/on-premises/configuration/overleaf-toolkit/environment-variables)，该设置会在 90 天后移除它们。

<Info>

状态只跟随所有者。当协作者归档共享项目或将其移入回收站时，项目只在协作者自己的项目页面中移动，这里的状态保持不变。

</Info>

## 项目操作 {#actions-on-a-project}

| 图标 | 操作 | 作用 |
| --- | --- | --- |
| 打开 | **Open Project** | 在新标签页的编辑器中打开项目。 |
| 文件夹 | **Change project owner** | 把项目转给另一个用户。 |
| 垃圾桶 | **Delete** | 把项目移到 **Deleted**。 |
| 箭头 | **Restore** | 恢复已删除的项目。仅适用于已删除的项目。 |
| 带叉的垃圾桶 | **Delete permanently** | 彻底移除已删除的项目。仅适用于已删除的项目。 |

### 更改所有者 {#change-the-owner}

点击文件夹图标，输入姓名或邮箱，选择用户，然后点击 **Change project owner**。对话框会提示此操作无法撤销，新所有者会收到通知并可以修改项目的访问设置。已停用的账号不会出现在选项中。如果选择后又修改了文字，选择会被取消：请重新选择用户。

<Frame caption="更改项目的所有者">
  <img src="/images/on-premises/project-management-change-owner.png" alt="显示警告并已选择新所有者的 Change project owner 对话框" />
</Frame>

要一次性转移某个用户的所有项目，请参阅[转移用户的项目](/zh-CN/on-premises/user-guide/administrators/user-management#transfer-a-users-projects)。

### 删除、恢复或永久删除 {#delete-restore-or-permanently-delete}

点击垃圾桶图标，然后点击 **Delete**。要再次找到该项目，请在 **Status** 筛选器中选择 **Deleted**。

<Frame caption="已删除的项目">
  <img src="/images/on-premises/project-management-deleted.png" alt="列表中一个带有 Restore 和 Delete permanently 图标的已删除项目" />
</Frame>

点击箭头图标再点击 **Restore** 可恢复项目；点击带叉的垃圾桶再点击 **Delete permanently** 可将其移除。

<Frame caption="永久删除项目">
  <img src="/images/on-premises/project-management-purge.png" alt="提示该操作无法撤销的 Delete permanently 对话框" />
</Frame>

### 批量修改项目 {#change-several-projects-at-once}

在列表中勾选项目。搜索框旁会出现按钮：**Download**、**Change project owner** 和 **Delete**。**Download** 会把所选项目保存为一个 `.zip` 文件。使用 **Change project owner** 时，无法选择所勾选项目的当前所有者。在 **Deleted** 视图中，按钮为 **Restore** 和 **Delete permanently**。

<Frame caption="批量操作">
  <img src="/images/on-premises/project-management-bulk.png" alt="两个已勾选的项目以及 Download、Change project owner 和 Delete 按钮" />
</Frame>

## 项目页面 {#the-project-page}

点击项目标题即可打开其页面。顶部是用于编辑、打开、下载和删除项目的图标。页面有五个标签页。

### 概览 {#overview}

项目的详细信息和设置。点击铅笔图标可修改 **Name**、**Link sharing**、**Compiler**、**TeX Live version** 和 **Main document**，或点击 **Change project owner**。然后点击 **Save**。

<Frame caption="编辑项目">
  <img src="/images/on-premises/project-management-edit.png" alt="处于编辑模式的 Overview 标签页" />
</Frame>

### 文件树 {#file-tree}

项目的文件和文件夹，只读。

<Frame caption="项目的文件">
  <img src="/images/on-premises/project-management-files.png" alt="列出 frog.jpg、main.tex 和一个已恢复的 bib 文件的 File tree 标签页" />
</Frame>

### 成员 {#members}

谁有访问权限：所有者、协作者和待处理的邀请。点击铅笔图标进行修改：

* 为协作者选择 **Editor**、**Reviewer** 或 **Viewer**。更改会立即生效。
* 点击协作者旁边的垃圾桶，然后点击 **Remove access**。
* 对于待处理的邀请，点击信封图标可 **Resend invite**，点击垃圾桶可 **Revoke Invite**。

完成后点击 **Done**。此处无法更改所有者：请使用 **Overview** 标签页上的 **Change project owner**。

<Frame caption="修改项目的成员">
  <img src="/images/on-premises/project-management-members.png" alt="处于编辑模式的 Members 标签页，包含角色菜单、一个待处理的邀请和操作图标" />
</Frame>

### 已删除的文件 {#deleted-files}

从项目中移除的文件。点击文件旁边的箭头图标，然后点击 **Restore file**。一个名称中带日期的副本会放入项目根目录，该行会显示副本的名称。已删除的文件仍保留在列表中。

刷新页面后，副本会出现在 **File tree** 标签页中。

<Frame caption="已恢复的文件">
  <img src="/images/on-premises/project-management-deleted-files.png" alt="显示 sample.bib 及其恢复副本名称的 Deleted files 标签页" />
</Frame>
