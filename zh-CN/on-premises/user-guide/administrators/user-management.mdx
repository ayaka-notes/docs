你自己的账户标有 **You**，其操作显示为灰色：你不能停用或删除自己。

## 查找用户 {#find-a-user}

在 **Search by name, email or ID** 中输入内容。也可以输入全名，例如 `Carol Novak`，搜索还能通过用户的任一[辅助邮箱](/zh-CN/on-premises/user-guide/users/multiple-emails)找到该用户。要缩小列表范围，请使用 **Login**、**Role** 和 **Status** 列的筛选器。点击 **Name**、**Sign up** 或 **Last logged in** 进行排序。

<Frame caption="搜索用户">
  <img src="/images/on-premises/user-management-search.png" alt="按搜索词 carol 筛选后的用户列表" />
</Frame>

已删除的账户不会出现在结果中。如果你的搜索也匹配到已删除的账户，表格上方会有一行提示，例如 **Found 1 matching deleted users**。点击 **Display deleted users** 即可查看。

<Frame caption="匹配到已删除账户的搜索">
  <img src="/images/on-premises/user-management-deleted-hint.png" alt="没有结果的搜索，以及 Found 1 matching deleted users, Display deleted users 这一行" />
</Frame>

## 用户状态 {#user-status}

每个账户都恰好有一种状态，**Status** 筛选器会显示每种状态的账户数量。将鼠标悬停在问号上可查看其定义。

<Frame caption="Status 筛选器">
  <img src="/images/on-premises/user-management-status-tooltip.png" alt="显示 Active 提示信息的 Status 筛选器" />
</Frame>

| 状态 | 含义 | 能否登录 |
| --- | --- | --- |
| **All** | 所有未被删除的账户。下面四种状态（Active + Pending + Inactive + Disabled）之和等于这个数字。 | |
| **Active** | 在过去 12 个月内登录过或打开过项目。 | 是 |
| **Pending** | 从未登录：通常是管理员创建的账户，或通过激活邮件注册、用户尚未激活的账户。使用密码注册的账户无需激活，首次登录时即变为 Active。 | 是 |
| **Inactive** | 以前登录过，但在过去 12 个月内没有登录或打开项目。 | 是 |
| **Disabled** | 管理员停用了该账户。登录会进入 **Your account is suspended** 页面。 | 否 |
| **Deleted user** | 该账户已被管理员或用户本人删除。它不计入 **All**，在你选择此筛选器之前一直隐藏。登录时会提示邮箱或密码不正确。 | 否 |

账户按以下方式在状态之间切换：

* **Pending、Active 和 Inactive** 取决于账户的使用情况，因此你无法设置它们。用户一登录，Inactive 账户就会变为 Active。
* **Enable** 和 **Restore** 不会恢复之前的状态。状态取决于最近一次登录：从未登录过的账户会重新变为 Pending。已停用的账户在 **Restore** 后仍为 **Disabled**。
* **Delete permanently** 无法撤销。除此之外，已删除的账户会一直保留，直到你将其移除，除非实例设置了 [`ENABLE_CRON_RESOURCE_DELETION`](/zh-CN/on-premises/configuration/overleaf-toolkit/environment-variables)，该设置会在 90 天后移除它们。

### License 选项卡中的活跃用户 {#active-users-on-the-license-tab}

**License** 选项卡和 **Active** 状态显示的数字可能不同，因为它们统计的内容不同。**License** 选项卡统计 Server Pro 许可证所覆盖的用户，其定义见 Overleaf 的 [Understanding license usage](https://docs.overleaf.com/on-premises/user-and-project-management/understanding-license-usage)："any user who logs in and accesses a project is considered an active user by the system"，以及 "An active user is defined as someone who has opened a project on your Server Pro instance in the last 12 months."。登录过但没有打开任何项目的用户在列表中为 **Active**，但不计入许可证。打开过项目、之后被停用的用户计入许可证，但在列表中为 **Disabled**。

## 对用户执行的操作 {#actions-on-a-user}

**Actions** 列中的图标与用户页面顶部的图标相同。

| 图标 | 操作 | 作用 |
| --- | --- | --- |
| 信封 | **Send activation email** | 针对从未登录的账户：生成新的激活链接。 |
| 带箭头的锁 | **Send reset link** | 针对已登录过的账户：生成新的密码重置链接。 |
| 文件夹 | **Transfer this user's projects** | 将该用户拥有的所有项目转给另一位用户。 |
| 圆圈 | **Disable** | 阻止用户登录。 |
| 播放 | **Enable** | 允许已停用的用户重新登录。 |
| 垃圾桶 | **Delete account** | 将账户移到 **Deleted user**。 |
| 箭头 | **Restore** | 恢复已删除的账户。仅适用于已删除的账户。 |
| 带叉的垃圾桶 | **Delete permanently** | 永久移除已删除的账户。仅适用于已删除的账户。 |

每个操作都会在一个标明该账户的对话框中要求确认。

### 发送激活或重置链接 {#send-an-activation-or-reset-link}

根据账户是否登录过，它会显示这两个图标之一。对于已停用的账户、没有本地密码的账户（例如 SSO 账户）以及你自己的账户，该图标显示为灰色。

点击图标，然后点击同名按钮。对话框会保持打开并显示链接：

* **Email Sent** 表示邮件已发出。
* <strong>No email was sent. Copy the link and pass it on.</strong> 表示未配置[邮件发送](/zh-CN/on-premises/configuration/overleaf-toolkit/email-delivery)或邮件发送失败。点击复制图标，自行将链接发给用户。

激活链接 7 天后过期，重置链接 1 小时后过期。用户打开链接并设置密码。使用激活链接后会进入其项目列表，使用重置链接后则需登录。

<Frame caption="未配置邮件发送的实例上的重置链接">
  <img src="/images/on-premises/user-management-reset-link.png" alt="Carol Novak 的 Send reset link 对话框，显示未发送邮件的警告、链接、复制图标和 Expires in 1 hour" />
</Frame>

### 停用或启用账户 {#disable-or-enable-an-account}

点击圆圈图标，然后点击 **Disable**。状态变为 **Disabled**，用户将无法再登录。要撤销，请点击播放图标，然后点击 **Enable**。

<Frame caption="停用账户">
  <img src="/images/on-premises/user-management-disable.png" alt="标明 Dave Okafor 的 Disable 对话框" />
</Frame>

### 转移用户的项目 {#transfer-a-user’s-projects}

点击文件夹图标。在 **Select a new owner for this user's projects** 下输入姓名或邮箱，选择用户，然后点击 **Transfer this user's projects**。这些项目的 **Owner** 会在[项目管理](/zh-CN/on-premises/user-guide/administrators/project-management)中发生变化。

已停用的账户不会作为新所有者出现在候选中。如果选择后又修改了文字，选择会被取消：请重新选择用户。

<Frame caption="转移用户的所有项目">
  <img src="/images/on-premises/user-management-transfer.png" alt="已选择 Carol Novak 作为新所有者的转移对话框" />
</Frame>

### 删除账户 {#delete-an-account}

点击垃圾桶图标。有两个选项可用，默认都不勾选：

* **Notify the user about the account deletion** 会给用户发送一封邮件。
* **Transfer this user's projects** 让你先为项目选择新的所有者。项目在新所有者名下保持活跃。

点击 **Delete account**。如果不转移项目，项目会随账户一起被删除，并进入[项目管理](/zh-CN/on-premises/user-guide/administrators/project-management#project-status)中的 **Deleted** 状态。

<Frame caption="删除账户并转移其项目">
  <img src="/images/on-premises/user-management-delete.png" alt="勾选了两个选项并选择了新所有者的 Delete account 对话框" />
</Frame>

### 恢复或永久删除账户 {#restore-or-permanently-delete-an-account}

在 **Status** 筛选器中选择 **Deleted user**，或在搜索后点击 **Display deleted users**。

<Frame caption="已删除的账户">
  <img src="/images/on-premises/user-management-deleted-list.png" alt="已删除用户列表，带有 Restore 和 Delete permanently 图标" />
</Frame>

* **Restore** 会恢复该账户。已停用的账户仍保持停用。随账户一起删除的项目也会恢复，每个项目的名称末尾会加上 `(Restored)`。用户自己删除的项目仍保持删除状态。
* **Delete permanently** 会移除该账户。对话框会警告此操作无法撤销。

<Frame caption="永久删除账户">
  <img src="/images/on-premises/user-management-purge.png" alt="警告操作无法撤销的 Delete permanently 对话框" />
</Frame>

### 一次修改多个账户 {#change-several-accounts-at-once}

在列表中勾选账户。**Create account** 旁会出现按钮：**Send activation email**、**Transfer this user's projects**、**Disable**、**Enable**、**Make admin**、**Remove admin** 和 **Delete account**。列表底部会显示已选择的账户数量。在你确认之前，对话框会列出这些账户。

<Frame caption="批量操作">
  <img src="/images/on-premises/user-management-bulk.png" alt="勾选了两个账户，列表上方显示批量操作按钮，信封按钮为灰色" />
</Frame>

除非所有勾选的账户都是 **Pending**，否则 **Send activation email** 显示为灰色。此时对话框会为每个账户显示一个链接。没有批量重置链接。

<Frame caption="每个账户一个激活链接">
  <img src="/images/on-premises/user-management-bulk-links.png" alt="Send activation email 对话框，显示 Hana Ito 和 Erin Silva 各自的链接以及 Expires in 7 days" />
</Frame>

## 用户页面 {#the-user-page}

点击用户的姓名即可打开其页面。该页面有六个选项卡。

### Account {#account}

账户的详细信息。要修改，请点击铅笔图标，编辑字段，然后点击 **Save**。你可以修改邮箱、姓名和密码，并打开或关闭 **Admin**。

如果用户添加了[更多邮箱](/zh-CN/on-premises/user-guide/users/multiple-emails)，它们会列在 **Emails** 下。编辑时，**Remove** 会从账户中移除辅助邮箱，之后其他账户就可以使用该地址。

<Frame caption="有两个邮箱的账户">
  <img src="/images/on-premises/user-management-secondary-email.png" alt="正在编辑的 Account 选项卡，包含一个主邮箱和一个带 Remove 按钮的辅助邮箱" />
</Frame>

入门设置中的[密码规则](/zh-CN/on-premises/user-guide/administrators/onboarding#create-the-administrator-account)同样适用。如何把密码交给用户由你决定。若要让用户自行设置，请改为[发送重置链接](/zh-CN/on-premises/user-guide/administrators/user-management#send-an-activation-or-reset-link)。

<Frame caption="编辑账户">
  <img src="/images/on-premises/user-management-edit.png" alt="处于编辑模式的 Account 选项卡" />
</Frame>

### Projects {#projects}

该用户拥有的项目，搜索、**Status** 筛选器和操作都与[项目管理](/zh-CN/on-premises/user-guide/administrators/project-management)中相同。

<Frame caption="用户的项目">
  <img src="/images/on-premises/user-management-projects.png" alt="用户的 Projects 选项卡" />
</Frame>

### Features {#features}

该账户启用的功能：协作、编译超时、集成和 AI。要修改，请点击铅笔图标，更改数值，然后点击 **Save**。对于 **Collaborators per project**，`-1` 表示不限。**Compile timeout** 以秒为单位，范围为 1 到 600。

在你自己的账户上，铅笔图标和 **AI usage** 的 **Reset** 显示为灰色。在 **Account** 选项卡中，你仍可以修改自己的邮箱、姓名和密码。

<Frame caption="用户的功能">
  <img src="/images/on-premises/user-management-features.png" alt="处于编辑模式的 Features 选项卡" />
</Frame>

### Integrations {#integrations}

用户的 Git 访问令牌以及其关联的账户。此选项卡为只读。

<Frame caption="用户的集成">
  <img src="/images/on-premises/user-management-integrations.png" alt="Integrations 选项卡，其中 GitHub、GitLab 和 Gitea 被勾选为已关联" />
</Frame>

### Audit logs {#audit-logs}

该账户发生过的事情：日期、操作、执行者、IP 地址和详细信息。可以搜索，或按 **Operation** 筛选。你对账户执行的操作会以你为发起者显示在这里。

<Frame caption="用户的审计日志">
  <img src="/images/on-premises/user-management-audit.png" alt="Audit logs 选项卡，列出用户的登录记录和管理员所做的功能更改" />
</Frame>

### Sessions {#sessions}

用户在哪些地方处于登录状态。点击 **Clear sessions** 并确认，即可让其在所有地方退出登录。之后该选项卡会显示 **Sessions cleared**。

<Frame caption="用户的会话">
  <img src="/images/on-premises/user-management-sessions.png" alt="Sessions 选项卡，显示一个会话和 Clear sessions 按钮" />
