## 导入文档 {#import-a-document}

此操作会从 Word 文档（`.docx`）或 Markdown 文件（`.md`）创建一个新的 LaTeX 项目。项目名称取自文件名。

<Steps>
<Step title="打开导入对话框">
在项目页面上，点击 **New project**。在 **Import** 下，点击 **Word document** 或 **Markdown document**。

<Frame caption="New project 菜单">
  <img src="/images/on-premises/word-import-menu.png" alt="New project 菜单，Import 下有 Word document 和 Markdown document" />
</Frame>
</Step>

<Step title="选择文件">
点击 **Select .docx file**，或将文件拖入对话框。对于 Markdown，按钮为 **Select .md file**。导入会立即开始。

<Frame caption="选择 Word 文档">
  <img src="/images/on-premises/word-import-dialog.png" alt="带有 Select .docx file 按钮的 Choose Word document 对话框" />
</Frame>
</Step>

<Step title="开始编辑">
新项目打开时会显示消息 **Document ready for editing**。点击 **Start editing**。

<Frame caption="导入已完成">
  <img src="/images/on-premises/word-import-ready.png" alt="带有 Start editing 按钮的 Document ready for editing 对话框" />
</Frame>
</Step>

<Step title="检查结果">
文档现在位于 `main.tex` 中，其标题显示在文件大纲中。点击 **Recompile** 查看 PDF。请检查样式，尤其是表格、图片和引用，它们可能需要编辑。

<Frame caption="导入的项目">
  <img src="/images/on-premises/word-import-project.png" alt="编辑器中导入的项目，包含 main.tex、文件大纲和编译后的 PDF" />
</Frame>
</Step>
</Steps>

### 如果导入失败 {#if-the-import-fails}

如果文件无法转换，对话框会显示 **Your document couldn't be imported**。展开 **Conversion error details** 查看原因。不会创建项目。

<Frame caption="无法导入的文档">
  <img src="/images/on-premises/word-import-error.png" alt="带有错误消息和 Conversion error details 的导入对话框" />
</Frame>

对话框只接受你所选的类型。在 Word 对话框中选择 `.md` 文件会显示 **You can only upload: .docx**。

## 导出项目 {#export-a-project}

打开项目，然后点击编辑器顶部的项目名称。点击以下选项之一：

| 选项                              | 你会得到                                       |
| ----------------------------------- | --------------------------------------------- |
| <strong>Export as Word document (.docx)</strong> | 以项目命名的 `.docx` 文件        |
| <strong>Export as Markdown (.md)</strong>        | 包含 `main.md` 的 `.zip` 文件                  |
| <strong>Export as HTML (.html)</strong>          | 包含 `main.html` 的 `.zip` 文件                |

下载会自动开始。转换无法还原所有 LaTeX 格式，因此请检查结果。

  <img src="/images/on-premises/word-export-menu.png" alt="项目名称下的菜单，包含三个 Export 选项" />
</Frame>
