### Overleaf 概述

Overleaf 是一款深受研究人员和技术团队喜爱的协作式 LaTeX 编辑器。其云端版本可在 [overleaf.com](https://www.overleaf.com/) 上使用，提供功能完整的在线 LaTeX 编辑器。然而，Overleaf Common（SaaS 版本）存在诸多功能限制，你不得不忍受 _**10 秒的编译时间限制**_ 和昂贵的会员费用。

虽然 Overleaf 提供了开源的社区版（可在 [GitHub: Overleaf](https://github.com/overleaf/overleaf) 上获取），但它同样存在许多限制，例如：

<Warning>

Overleaf Community Edition 旨在用于**所有**用户都受信任的环境。由于不支持沙盒编译，Community Edition **不**适用于需要隔离用户的场景。

如果没有沙盒，LaTeX 编译将以与容器相同的权限运行，从而可以访问容器的文件系统、网络和环境变量。这会带来数据泄露或系统被入侵的风险。非沙盒编译只应在完全受信任的环境中使用；对于多用户或生产环境部署，强烈建议使用沙盒编译。

有关沙盒编译的更多信息，请参见：[sandboxed-compiles.md](/zh-CN/on-premises/configuration/overleaf-toolkit/sandboxed-compiles  "mention")

</Warning>

### Overleaf Server Pro 的信息与价格

Overleaf 网站仅提供了联系 Server Pro 支持的入口，因此关于 Server Pro 的信息非常有限。但根据我们在社区中收集到的信息，**Server Pro 的报价如下**：

* 你需要购买_至少_ 10 人的许可证。
* 10 人许可证的费用约为 €3,477.61。（2024 年）
* 教育版方面，20 名用户每年 2640 欧元，50 名用户 6050 欧元，100 名用户 9963 欧元。
* Server Pro 仅在部分地区提供（例如不包括中国大陆）。

根据目前可获得的信息，Overleaf Server Pro 的费用约为每用户每年 \$300，且最少需购买 10 个许可证，是一个非常昂贵的选择。此外，Server Pro 提供的功能远少于 Ayakaleaf Pro。我们由衷感谢社区开发者多年来的贡献，正是他们让我们得以构建 Ayakaleaf Pro，并最终在功能和能力上超越 Overleaf Server Pro。

### 为什么选择 Ayakaleaf Pro？

<Info>

Ayakaleaf Pro 与 Overleaf, Inc. 及其母公司 Digital Science _**没有**_ 任何关联。它也 _不是 Server Pro_ 版本（Server Pro 是 Overleaf, Inc. 提供的商业产品）。[ayaka-notes](https://github.com/ayaka-notes) 作为独立项目开发和维护 Ayakaleaf Pro。

</Info>

Ayakaleaf Pro 是 Overleaf Community Edition 的增强实现，_**免费**_ 提供 Server Pro 的 _**全部高级**_ 功能。与 [https://www.overleaf.com/](https://www.overleaf.com/) 上的 Overleaf Common 或商业版 Server Pro 不同，我们：

* 编译时间 _**没有限制**_
* 用户数量 _**无需许可证**_
* 解锁 Server Pro 的 _**全部功能**_
