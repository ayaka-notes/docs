## 什么是 LaTeX？

LaTeX（读作“_LAY_-tek”或“_LAH_-tek”）是一种用于排版具有专业外观的文档的工具。不过，LaTeX 的工作方式与你可能用过的许多其他文档制作应用程序（例如 Microsoft Word 或 LibreOffice Writer）截然不同：那些“[所见即所得（WYSIWYG）](https://en.wikipedia.org/wiki/WYSIWYG)”工具为用户提供一个交互式页面，用户在其中输入和编辑文本，并应用各种样式。LaTeX 的工作方式则完全不同：你的文档是一个纯文本文件，其中穿插着用于表达预期（排版）结果的 LaTeX _命令_。为了生成可见的排版文档，LaTeX 文件需要由一个名为 _TeX 引擎_的软件进行处理，该引擎利用嵌入在文本文件中的命令来引导和控制排版过程，将 LaTeX 命令和文档文本转换为专业排版的 PDF 文件。这意味着你只需专注于文档的_内容_，而计算机会通过 LaTeX 命令和 TeX 引擎处理文档的_视觉外观_（格式）。

## 为什么要学习 LaTeX？

关于是否应该学习使用 LaTeX 而不是其他文档编写应用程序，支持和反对的理由都有很多；但归根结底，这是基于个人偏好、习惯以及文档需求的个人选择。

支持使用 LaTeX 的理由包括：

* 支持排版极其复杂的数学公式、表格以及自然科学领域的技术内容；
* 提供脚注、交叉引用和参考文献管理功能；
* 可以轻松生成复杂或繁琐的文档元素，例如索引、术语表、目录、图片列表；
* 由于其固有的可编程性以及数千个[免费附加宏包](https://www.ctan.org/pkg)带来的可扩展性，可以高度定制以满足特定的文档制作需求。

总的来说，LaTeX 让用户能够高度掌控文档的制作过程，并以极高的标准进行排版。当然，也有一些类型的文档或出版物并非 LaTeX 的强项，包括杂志类出版物中常见的许多“自由形式”页面设计。

LaTeX 的一大重要优势是将文档内容与文档样式分离：写完文档内容后，可以轻松更改其外观。同样，你可以创建一个定义特定文档类型布局/样式的 LaTeX 文件，并将该文件用作_模板_，以规范该类型其他文档的编写/制作；例如，科学出版商可以借此创建 LaTeX 文章模板，供作者撰写投稿论文。Overleaf 拥有一个[包含数千个模板的模板库](https://www.overleaf.com/gallery)，涵盖了种类繁多的文档类型——从科学论文、报告和书籍到简历和演示文稿，应有尽有。由于这些模板定义了文档的布局和样式，作者只需在 Overleaf 中打开模板（创建一个新项目），即可开始撰写内容。

## 编写你的第一段 LaTeX

第一步是创建一个新的 LaTeX 项目。你可以在自己的计算机上创建一个新的 `.tex` 文件；也可以在 Overleaf 中新建一个项目。

让我们从最简单的可运行示例开始，它可以直接在 Overleaf 中打开：

```latex
\documentclass{article}
\begin{document}
First document. This is a simple example, with no 
extra parameters or packages included.
\end{document}
```

## 文档的导言区

上面的截图显示，Overleaf 将 LaTeX 文档存储为名为 `main.tex` 的文件：按照惯例，包含文档 LaTeX 代码的文件使用 `.tex` 扩展名。

上一个示例展示了文档内容是在 `\begin{document}` 命令之后输入的；而 `.tex` 文件中位于该命令_之前_的所有内容称为_导言区_，它充当文档的“设置”部分。在导言区中，你可以定义文档类（类型）以及撰写文档时使用的语言等具体内容；加载你想使用的_宏包_（[稍后](/zh-CN/texlive/latex-basics/learn-latex-in-30-minutes#Finding%5Fand%5Fusing%5FLaTeX%5Fpackages)会详细介绍）；也可以在这里进行其他类型的配置。

一个最简的文档导言区可能如下所示：

```latex
\documentclass[12pt, letterpaper]{article}
\usepackage{graphicx}
```

其中 `\documentclass[12pt, letterpaper]{article}` 定义了文档的整体类（类型）。附加参数必须用逗号分隔，并放在方括号（`[...]`）中，用于配置该 article 类的实例；也就是说，这些是我们希望用于这份基于 `article` 类的特定文档的设置。

在此示例中，两个参数的作用如下：

* `12pt` 设置字号
* `letterpaper` 设置纸张大小

当然也可以使用其他字号，如 `9pt`、`11pt`、`12pt`，但如果未指定，默认字号为 `10pt`。至于纸张大小，其他可选值有 `a4paper` 和 `legalpaper`。更多信息请参阅关于页面大小和页边距的文章。

导言区中的这一行

```latex
\usepackage{graphicx}
```

是加载外部宏包（此处为 [graphicx](https://ctan.org/pkg/graphicx?lang=en)）以扩展 LaTeX 功能的示例，它使 LaTeX 能够导入外部图形文件。LaTeX 宏包将在[查找和使用 LaTeX 宏包](/zh-CN/texlive/latex-basics/learn-latex-in-30-minutes#Finding%5Fand%5Fusing%5FLaTeX%5Fpackages)一节中讨论。

## 添加标题、作者和日期信息

要为文档添加标题、作者和日期，需要在_导言区_（_而不是_文档正文）中再添加三行。这三行是：

* `\title{My first LaTeX document}`：文档标题
* `\author{Hubert Farnsworth}`：在这里写上作者姓名，还可以选择在花括号内使用 `\thanks` 命令：
  * `\thanks{Funded by the Overleaf team.}`：可以添加在作者姓名之后、`author` 命令的花括号内。它会添加一个上标，以及一个包含花括号内文本的脚注。如果你需要在文章中感谢某个机构，这会很有用。
* `\date{August 2022}`：你可以手动输入日期，也可以使用 `\today` 命令，在每次编译文档时排版当前日期

添加这些行后，你的导言区应如下所示：

```latex
\documentclass[12pt, letterpaper]{article}
\title{My first LaTeX document}
\author{Hubert Farnsworth\thanks{Funded by the Overleaf team.}}
\date{August 2022}
```

要排版标题、作者和日期，请在文档_正文_中使用 `\maketitle` 命令：

```latex
\begin{document}
\maketitle
We have now added a title, author and date to our first \LaTeX{} document!
\end{document}
```

现在可以将导言区和正文组合起来，生成一份可以在 Overleaf 中打开的完整文档：

```latex
\documentclass[12pt, letterpaper]{article}
\title{My first LaTeX document}
\author{Hubert Farnsworth\thanks{Funded by the Overleaf team.}}
\date{August 2022}
\begin{document}
\maketitle
We have now added a title, author and date to our first \LaTeX{} document!
\end{document}
```

## 添加注释

LaTeX 是一种“程序代码”，只不过专门用于文档排版；因此，与用其他任何编程语言编写的代码一样，在文档中添加注释会非常有用。LaTeX 注释是一段不会被排版、也不会以任何方式影响文档的文本——通常用于添加“待办”备注、加入说明性注解、对复杂的宏进行行内解释，或在调试时注释掉 LaTeX 代码的某些行/段落。

要在 LaTeX 中添加注释，只需在行首写一个 `%` 符号，如下面基于上例的代码所示：

```latex
\documentclass[12pt, letterpaper]{article}
\title{My first LaTeX document}
\author{Hubert Farnsworth\thanks{Funded by the Overleaf team.}}
\date{August 2022}
\begin{document}
\maketitle
We have now added a title, author and date to our first \LaTeX{} document!

% This line here is a comment. It will not be typeset in the document.
\end{document}
```

[在 Overleaf 中打开此示例。](https://www.overleaf.com/docs?engine=pdflatex&snip%5Fname=My+first+LaTeX+document+with+a+comment&snip=%5Cdocumentclass%5B12pt%2C+letterpaper%5D%7Barticle%7D%0A%5Ctitle%7BMy+first+LaTeX+document%7D%0A%5Cauthor%7BHubert+Farnsworth%5Cthanks%7BFunded+by+the+Overleaf+team.%7D%7D%0A%5Cdate%7BAugust+2022%7D%0A%5Cbegin%7Bdocument%7D%0A%5Cmaketitle%0AWe+have+now+added+a+title%2C+author+and+date+to+our+first+%5CLaTeX%7B%7D+document%21%0A%0A%25+This+line+here+is+a+comment.+It+will+not+be+typeset+in+the+document.%0A%5Cend%7Bdocument%7D)

此示例生成的输出与之前不含注释的 LaTeX 代码完全相同。

## 粗体、斜体和下划线

接下来，我们来看一些文本格式命令：

* **粗体**：在 LaTeX 中使用 `\textbf{...}` 命令排版粗体文本。
* _斜体_：使用 `\textit{...}` 命令生成斜体文本。
* 下划线：使用 `\underline{...}` 命令为文本添加下划线。

下一个示例演示了这些命令：

```latex
Some of the \textbf{greatest}
discoveries in \underline{science} 
were made by \textbf{\textit{accident}}.
```

## 添加图片

本节我们将介绍如何向 LaTeX 文档添加图片。Overleaf 支持三种插入图片的方式：

1. 使用编辑器工具栏上的 [**Insert Figure** 按钮](https://learn.overleaf.com/learn/Kb/How_to_insert_figures_in_Overleaf#Using%5FInsert%5FFigure%5Fto%5Fadd%5Fa%5Ffigure%5Fto%5Fyour%5Fproject)（![编辑器工具栏上的 Insert Figure 按钮](https://sharelatex-wiki-cdn-671420.cdn77.org/learn-scripts/images/a/a8/InsertFigureButton.png)），将图片插入 **Visual Editor** 或 **Code Editor**。
2. 将图片复制并粘贴到 **Visual Editor** 或 **Code Editor** 中。
3. 使用 **Code Editor** 编写插入图形的 LaTeX 代码。

方式 1 和 2 会自动生成插入图片所需的 LaTeX 代码，这里我们介绍方式 3——请注意，你需要将这些图片[上传](https://docs.overleaf.com/writing-and-editing/inserting-images)到你的 Overleaf 项目中。下面的示例演示了如何插入图片：

```latex
\documentclass{article}
\usepackage{graphicx} %LaTeX package to import graphics
\graphicspath{{images/}} %configuring the graphicx package
 
\begin{document}
The universe is immense and it seems to be homogeneous, 
on a large scale, everywhere we look.

% The \includegraphics command is 
% provided (implemented) by the 
% graphicx package
\includegraphics{universe}  
 
There's a picture of a galaxy above.
\end{document}
```

将图形导入 LaTeX 文档需要一个[附加_宏包_](/zh-CN/texlive/latex-basics/learn-latex-in-30-minutes#Finding%5Fand%5Fusing%5FLaTeX%5Fpackages)，它提供插入外部图形文件所需的命令和功能。上面的示例加载了 [graphicx 宏包](https://ctan.org/pkg/graphicx?lang=en)，该宏包提供了许多命令，其中包括用于导入图形的 `\includegraphics{...}` 和用于告知 LaTeX 图形所在位置的 `\graphicspath{...}`。

## 图题、标签和引用

借助 `figure` 环境，可以为图片添加图题（caption）、标签并进行引用，如下所示：

```latex
\documentclass{article}
\usepackage{graphicx}
\graphicspath{{images/}}
 
\begin{document}

\begin{figure}[h]
    \centering
    \includegraphics[width=0.75\textwidth]{mesh}
    \caption{A nice plot.}
    \label{fig:mesh1}
\end{figure}
 
As you can see in figure \ref{fig:mesh1}, the function grows near the origin. This example is on page \pageref{fig:mesh1}.

\end{document}
```

此示例生成如下输出：

![展示在 LaTeX 中使用图题的图形](https://images.ctfassets.net/nrgyaltdicpt/4DkAWWkQqZP6QHU2EErogQ/9aa2371f2cde0f3f8bf22aa1c0b91789/LL30Fig6r-plain.svg)

该示例中有几个值得注意的命令：

* **`\includegraphics[width=0.75\textwidth]{mesh}`**：这种形式的 `\includegraphics` 指示 LaTeX 将图片宽度设置为文本宽度的 75%——文本宽度的值存储在 `\textwidth` 命令中。
* **`\caption{A nice plot.}`**：顾名思义，此命令设置图题，图题可以放在图片的上方或下方。如果你创建图片列表，该图题将用于列表中。
* **`\label{fig:mesh1}`**：要在文档中引用此图片，需要使用 `\label` 命令为其指定标签。该标签用于为图片生成编号，并与下一个命令结合使用，以便你引用它。
* **`\ref{fig:mesh1}`**：这段代码将被替换为所引用图片对应的编号。

插入 LaTeX 文档的图片应放在 `figure` 环境或类似环境中，以便 LaTeX 能自动将图片放置在文档中的合适位置。

## 在 LaTeX 中创建列表

你可以使用_环境_创建不同类型的列表。环境用于封装实现特定排版功能所需的 LaTeX 代码。环境以 `\begin{_environment-name_}` 开始，以 `\end{_environment-name_}` 结束，其中 `_environment-name_` 可以是 `figure`、`tabular`，或者是列表类型之一：`itemize` 用于无序列表，`enumerate` 用于有序列表。

### 无序列表

无序列表由 `itemize` 环境生成。每个列表项前面都必须加上 `\item` 命令，如下所示：

```latex
\documentclass{article}
\begin{document}
\begin{itemize}
  \item The individual entries are indicated with a black dot, a so-called bullet.
  \item The text in the entries may be of any length.
\end{itemize}
\end{document}
```

## 在 LaTeX 中添加数学公式

LaTeX 的主要优势之一是可以轻松编写数学表达式。LaTeX 提供两种用于排版数学内容的书写模式：

* _行内_（inline）数学模式，用于书写作为段落一部分的公式
* _行间_（display）数学模式，用于书写不属于文本或段落、单独成行排版的表达式

```latex
In physics, the mass-energy equivalence is stated
```

分节命令的名称大多一目了然；例如，`\chapter{First Chapter}` 创建一个标题为 `First Chapter` 的新章，`\section{Introduction}` 生成一个标题为 `Introduction` 的节，以此类推。节还可以进一步细分为 `\subsection{...}` 甚至 `\subsubsection{...}`。节、小节等的编号是自动生成的，但可以通过使用相应命令的所谓_星号版本_（即在命令末尾加上星号 (\*)）来禁用编号，例如 `\section*{...}` 和 `\subsection*{...}`。

_总体而言_，LaTeX 文档类提供以下分节命令，各个具体的类分别支持其中相关的子集：

* `\part{part}`
* `\chapter{chapter}`
* `\section{section}`
* `\subsection{subsection}`
* `\subsubsection{subsubsection}`
* `\paragraph{paragraph}`
* `\subparagraph{subparagraph}`

特别地，`\part` 和 `\chapter` 命令仅在 `report` 和 `book` 文档类中可用。

有关文档结构命令的更多信息，请访问 Overleaf 关于节和章的文章。

## 创建表格

Overleaf 提供三种创建表格的方式：

1. 使用 **Visual Editor**（或 **Code Editor**）工具栏中的 [**Insert Table** 按钮](https://www.overleaf.com/learn/how-to/How_to_insert_tables_in_Overleaf%23inserttable#Using%5FInsert%5FTable%5Fto%5Fcreate%5Fa%5Ftable%5Fin%5Fyour%5Fproject)。

3. 在 Code Editor 中编写表格的 LaTeX 代码。

如果你是 LaTeX 新手，使用 **Visual Editor** 中的工具栏（方式 1）是一个很好的入门方法——你可以在 **Visual Editor** 和 **Code Editor** 之间切换，查看表格背后的代码。

### 添加边框

`tabular` 环境支持将水平线和垂直线（表格线）作为表格的一部分：

* 要在行的上方和下方添加水平线，请使用 `\hline` 命令
* 要在列之间添加垂直线，请使用竖线参数 `|`

```latex
\begin{center}
\begin{tabular}{|c|c|c|} 
 \hline
 cell1 & cell2 & cell3 \\ 
 cell4 & cell5 & cell6 \\ 
 cell7 & cell8 & cell9 \\ 
 \hline
\end{tabular}
\end{center}
```

## 查找和使用 LaTeX 宏包

LaTeX 不仅提供了强大的排版能力，还通过附加_宏包_提供了一个_可扩展框架_。LaTeX 并不试图提供“包罗万象”的命令和功能，而是被设计为_可扩展的_，允许用户加载外部代码（宏包），以提供更专业的排版功能或扩展 LaTeX 的内置功能——例如排版表格。正如在[添加图片](/zh-CN/texlive/latex-basics/learn-latex-in-30-minutes#Adding%5Fimages)一节中所见，`graphicx` 宏包通过提供导入图形文件的命令扩展了 LaTeX，它是通过在导言区中写入以下内容加载的：

```latex
\usepackage{graphicx}
```

### 加载宏包

如上所述，宏包是通过 `\usepackage` 命令在文档导言区中加载的；但由于（许多）LaTeX 宏包都提供了一组可用于配置其行为的_选项_，因此 `\usepackage` 命令通常如下所示：

```latex
\usepackage[options]{somepackage}
```

方括号“`[...]`”告诉 LaTeX 在加载 `somepackage` 时应用哪些选项。在用户请求的选项集中，各个选项或设置通常用逗号分隔；例如，[geometry 宏包](https://ctan.org/pkg/geometry)提供了许多用于配置 LaTeX 页面布局的选项，因此 `geometry` 的典型用法可能如下所示：

```latex
\usepackage[total={6.5in,8.75in},
top=1.2in, left=0.9in, includefoot]{geometry}
```

`geometry` 宏包是由全球 LaTeX 社区成员编写和贡献、并免费提供给所有人使用的宏包之一。

如果某个 LaTeX 宏包不提供任何选项，或者用户希望使用宏包选项的默认值，则可以这样加载：

```latex
\usepackage{somepackage}
```

当你写下 `\usepackage[...]{somepackage}` 时，LaTeX 会查找一个名为 `_somepackage_.sty` 的对应文件，并需要加载和处理该文件——以便使宏包命令可用，并执行该宏包提供的其他代码。如果 LaTeX 找不到 `_somepackage_.sty`，它将报错并终止，如下面的 Overleaf 示例所示：

```latex
\documentclass[12pt, letterpaper]{article}
\usepackage{somepackage}% a NON-EXISTENT package
\begin{document}
This will fail!
\end{document}
```

### Overleaf 上可用的宏包：TeX Live 简介

每年，CTAN 上托管的宏包中的一个（很大的）_子集_，连同 LaTeX 相关的字体和其他软件，会被整理并作为一个名为 [TeX Live](https://tug.org/texlive/) 的系统发布，你可以用它在本地搭建自己的 LaTeX 环境。事实上，[Overleaf 的服务器也使用 TeX Live](https://www.overleaf.com/learn/latex/Overleaf_and_TeX_Live)，并会在 TeX Live 新版本发布时进行更新。Overleaf 的 TeX Live 更新并不是即时的，而是在新版本发布几个月后进行，这样我们就有时间针对[模板库中的数千个模板](https://www.overleaf.com/gallery)测试新版 TeX Live 的兼容性。例如，这是我们的 [TeX Live 2025 升级公告](https://www.overleaf.com/blog/tex-live-2025-is-now-available)。

虽然 TeX Live 包含了 CTAN 宏包中的一个（很大的）_子集_，但你仍可能发现一些有趣的宏包，例如[用于排版围棋棋谱的 igo](https://ctan.org/pkg/igo?lang=en)，它托管在 CTAN 上，但未包含在 TeX Live 中（未由 TeX Live 分发），因此在 Overleaf 上不可用。CTAN 上托管的某些宏包未被纳入 TeX Live 的原因有很多：可能宏包已经过时、存在许可问题、非常新（最近才上传），或者存在平台依赖性，例如只能在 Windows 上运行而不能在 Linux 上运行。

新宏包以及现有宏包的更新全年都会上传到 CTAN，但 TeX Live 的更新每年只发布一次；因此，当前版本 TeX Live 中包含的宏包不会像 CTAN 上托管的那样新。由于 Overleaf 的服务器使用 TeX Live，安装在我们服务器上的宏包（即用户可以使用的宏包）可能不是 CTAN 上提供的最新版本，但一般来说，这不太可能造成问题。
