## 什么是 LaTeX？

LaTeX（读作"_LAY_-tek"或"_LAH_-tek"）是一种用于排版专业外观文档的工具。不过，LaTeX 的工作方式与你可能用过的许多其他文档制作应用（例如 Microsoft Word 或 LibreOffice Writer）截然不同：那些"[所见即所得（WYSIWYG）](https://en.wikipedia.org/wiki/WYSIWYG)"工具为用户提供一个交互式页面，用户在其中输入和编辑文本并应用各种样式。LaTeX 的工作方式则完全不同：你的文档是一个纯文本文件，其中穿插着用于表达所需（排版）结果的 LaTeX _命令_。为了生成可见的排版文档，你的 LaTeX 文件需要由一个称为 _TeX 引擎_的软件进行处理，该引擎利用文本文件中嵌入的命令来引导和控制排版过程，将 LaTeX 命令和文档文本转换为专业排版的 PDF 文件。这意味着你只需专注于文档的_内容_，而计算机会通过 LaTeX 命令和 TeX 引擎负责处理文档的_视觉外观_（格式）。

## 为什么要学习 LaTeX？

关于是否应学习使用 LaTeX 而非其他文档创作应用，支持和反对的理由都有不少；但归根结底，这是一种基于个人偏好、习惯以及文档需求的个人选择。

支持使用 LaTeX 的理由包括：

* 支持排版极其复杂的数学公式、表格以及物理科学领域的技术内容；
* 提供脚注、交叉引用和参考文献管理功能；
* 可以轻松生成复杂或繁琐的文档元素，例如索引、术语表、目录、图片列表等；
* 由于其固有的可编程性以及通过数千个[免费附加宏包](https://www.ctan.org/pkg)实现的可扩展性，可高度定制以满足特定的文档制作需求。

总体而言，LaTeX 让用户能够高度掌控文档的制作过程，并以极高的标准进行排版。当然，也有一些类型的文档或出版物并不是 LaTeX 的强项，例如杂志类出版物中常见的许多"自由排版"页面设计。

LaTeX 的一个重要优点是将文档内容与文档样式分离：一旦写好了文档内容，就可以轻松更改其外观。同样，你可以创建一个定义特定文档类型布局/样式的 LaTeX 文件，并将该文件用作_模板_，以规范该类型其他文档的撰写/制作。例如，科学出版商可以借此用 LaTeX 创建论文模板，供作者撰写向期刊投稿的论文。Overleaf 拥有一个[包含数千个模板的模板库](https://www.overleaf.com/gallery)，涵盖极其广泛的文档类型——从科学论文、报告和书籍到简历和演示文稿，应有尽有。由于这些模板定义了文档的布局和样式，作者只需在 Overleaf 中打开它们（从而创建一个新项目），即可开始撰写内容。

## 编写你的第一段 LaTeX

第一步是创建一个新的 LaTeX 项目。你可以在自己的计算机上创建一个新的 `.tex` 文件；也可以在 Overleaf 中新建一个项目。

让我们从最简单的可运行示例开始，它可以直接在 Overleaf 中打开：

```latex
\documentclass{article}
\begin{document}
First document. This is a simple example, with no 
extra parameters or packages included.
\end{document}
```

第一行代码 `\documentclass{article}` 声明了文档的类型，称为文档_类_（class），它控制着文档的整体外观。不同类型的文档需要不同的文档类；例如，简历所需的文档类与科学论文不同，后者可能使用标准的 LaTeX `article` 类。你正在处理的其他类型文档可能需要不同的文档类，例如 `book` 或 `report`。要了解可用的众多 LaTeX 文档类，请[访问 CTAN（Comprehensive TeX Archive Network）上的相关页面](https://www.ctan.org/topic/class)。

设置好文档类之后，我们的内容（称为文档的_正文_）写在 `\begin{document}` 和 `\end{document}` 标签之间。打开上面的示例后，你可以修改文本，完成后通过_重新编译文档_来查看生成的排版 PDF。在 Overleaf 中，只需点击 **Recompile** 即可，如以下简短视频片段所示：

## 文档的导言区

上面的截图显示 Overleaf 将 LaTeX 文档存储为名为 `main.tex` 的文件：按照惯例，包含文档 LaTeX 代码的文件使用 `.tex` 扩展名命名。

前面的示例展示了如何在 `\begin{document}` 命令之后输入文档内容；而 `.tex` 文件中出现在该位置_之前_的所有内容称为_导言区_，它相当于文档的"设置"部分。在导言区中，你可以定义文档类（类型）以及诸如撰写文档所用语言等具体设置；加载你想使用的_宏包_（[稍后](/zh-CN/texlive/latex-basics/learn-latex-in-30-minutes#Finding%5Fand%5Fusing%5FLaTeX%5Fpackages)将详细介绍），也可以在这里进行其他类型的配置。

一个最简单的文档导言区可能如下所示：

```latex
\documentclass[12pt, letterpaper]{article}
\usepackage{graphicx}
```

其中 `\documentclass[12pt, letterpaper]{article}` 定义了文档的整体类（类型）。附加参数写在方括号（`[...]`）中，必须用逗号分隔，用于配置该 article 类的这一实例，即我们希望为这个基于 `article` 类的特定文档使用的设置。

在本例中，这两个参数的作用如下：

* `12pt` 设置字号
* `letterpaper` 设置纸张大小

当然，也可以使用 `9pt`、`11pt`、`12pt` 等其他字号；如果未指定，默认字号为 `10pt`。至于纸张大小，其他可选值有 `a4paper` 和 `legalpaper`。更多信息请参阅关于页面尺寸和页边距的文章。

导言区中的这一行

```latex
\usepackage{graphicx}
```

是加载外部宏包（这里是 [graphicx](https://ctan.org/pkg/graphicx?lang=en)）以扩展 LaTeX 功能的一个示例，它使 LaTeX 能够导入外部图形文件。LaTeX 宏包将在[查找和使用 LaTeX 宏包](/zh-CN/texlive/latex-basics/learn-latex-in-30-minutes#Finding%5Fand%5Fusing%5FLaTeX%5Fpackages)一节中讨论。

## 添加标题、作者和日期信息

要为文档添加标题、作者和日期，需要在_导言区_（而_不是_文档正文）中再添加三行。这三行是：

* `\title{My first LaTeX document}`：文档标题
* `\author{Hubert Farnsworth}`：在这里写上作者姓名，并可选择在花括号内使用 `\thanks` 命令：
  * `\thanks{Funded by the Overleaf team.}`：可以添加在 `author` 命令花括号内的作者姓名之后。它会添加一个上标，并生成一个包含花括号内文本的脚注。如果你需要在文章中感谢某个机构，这会很有用。
* `\date{August 2022}`：你可以手动输入日期，也可以使用 `\today` 命令，在每次编译文档时排版当前日期

添加这些行之后，你的导言区应该类似于：

```latex
\documentclass[12pt, letterpaper]{article}
\title{My first LaTeX document}
\author{Hubert Farnsworth\thanks{Funded by the Overleaf team.}}
\date{August 2022}
```

要排版标题、作者和日期，请在文档_正文_中使用 `\maketitle` 命令：

```latex
\begin{document}
\maketitle
We have now added a title, author and date to our first \LaTeX{} document!
\end{document}
```

现在可以将导言区和正文组合成一个完整的文档，并在 Overleaf 中打开：

```latex
\documentclass[12pt, letterpaper]{article}
\title{My first LaTeX document}
\author{Hubert Farnsworth\thanks{Funded by the Overleaf team.}}
\date{August 2022}
\begin{document}
\maketitle
We have now added a title, author and date to our first \LaTeX{} document!
\end{document}
```

## 添加注释

LaTeX 是一种"程序代码"，只不过专门用于文档排版；因此，与用任何其他编程语言编写的代码一样，在文档中添加注释会非常有用。LaTeX 注释是一段不会被排版、也不会以任何方式影响文档的文本——通常用于添加"待办"笔记、加入说明性注解、对复杂宏进行行内解释，或在调试时注释掉某些 LaTeX 代码行/段落。

要在 LaTeX 中添加注释，只需在行首写一个 `%` 符号，如以下基于上例的代码所示：

```latex
\documentclass[12pt, letterpaper]{article}
\title{My first LaTeX document}
\author{Hubert Farnsworth\thanks{Funded by the Overleaf team.}}
\date{August 2022}
\begin{document}
\maketitle
We have now added a title, author and date to our first \LaTeX{} document!

% This line here is a comment. It will not be typeset in the document.
\end{document}
```

[在 Overleaf 中打开此示例。](https://www.overleaf.com/docs?engine=pdflatex&snip%5Fname=My+first+LaTeX+document+with+a+comment&snip=%5Cdocumentclass%5B12pt%2C+letterpaper%5D%7Barticle%7D%0A%5Ctitle%7BMy+first+LaTeX+document%7D%0A%5Cauthor%7BHubert+Farnsworth%5Cthanks%7BFunded+by+the+Overleaf+team.%7D%7D%0A%5Cdate%7BAugust+2022%7D%0A%5Cbegin%7Bdocument%7D%0A%5Cmaketitle%0AWe+have+now+added+a+title%2C+author+and+date+to+our+first+%5CLaTeX%7B%7D+document%21%0A%0A%25+This+line+here+is+a+comment.+It+will+not+be+typeset+in+the+document.%0A%5Cend%7Bdocument%7D)

该示例生成的输出与之前不含注释的 LaTeX 代码完全相同。

## 粗体、斜体和下划线

接下来，我们来看一些文本格式命令：

* **粗体**：LaTeX 中的粗体文本使用 `\textbf{...}` 命令排版。
* _斜体_：斜体文本使用 `\textit{...}` 命令生成。
* 下划线：要为文本添加下划线，请使用 `\underline{...}` 命令。

下一个示例演示了这些命令：

```latex
Some of the \textbf{greatest}
discoveries in \underline{science} 
were made by \textbf{\textit{accident}}.
```

## 添加图片

本节将介绍如何向 LaTeX 文档添加图片。Overleaf 支持三种插入图片的方式：

1. 使用编辑器工具栏上的 [**Insert Figure** 按钮](https://learn.overleaf.com/learn/Kb/How_to_insert_figures_in_Overleaf#Using%5FInsert%5FFigure%5Fto%5Fadd%5Fa%5Ffigure%5Fto%5Fyour%5Fproject)（![编辑器工具栏上的 Insert Figure 按钮](https://sharelatex-wiki-cdn-671420.cdn77.org/learn-scripts/images/a/a8/InsertFigureButton.png)），将图片插入 **Visual Editor** 或 **Code Editor**。
2. 将图片复制并粘贴到 **Visual Editor** 或 **Code Editor** 中。
3. 使用 **Code Editor** 编写插入图形的 LaTeX 代码。

方式 1 和 2 会自动生成插入图片所需的 LaTeX 代码，这里我们介绍方式 3——请注意，你需要将这些图片[上传](https://docs.overleaf.com/writing-and-editing/inserting-images)到你的 Overleaf 项目中。以下示例演示了如何插入图片：

```latex
\documentclass{article}
\usepackage{graphicx} %LaTeX package to import graphics
\graphicspath{{images/}} %configuring the graphicx package
 
\begin{document}
The universe is immense and it seems to be homogeneous, 
on a large scale, everywhere we look.

% The \includegraphics command is 
% provided (implemented) by the 
% graphicx package
\includegraphics{universe}  
 
There's a picture of a galaxy above.
\end{document}
```

向 LaTeX 文档导入图形需要一个[附加_宏包_](/zh-CN/texlive/latex-basics/learn-latex-in-30-minutes#Finding%5Fand%5Fusing%5FLaTeX%5Fpackages)，它提供插入外部图形文件所需的命令和功能。上例加载了 [graphicx 宏包](https://ctan.org/pkg/graphicx?lang=en)，该宏包提供了众多命令，其中包括用于导入图形的 `\includegraphics{...}` 和用于告知 LaTeX 图形所在位置的 `\graphicspath{...}`。


有关 LaTeX 宏包的更多信息，请参阅本教程末尾的[查找和使用 LaTeX 宏包](/zh-CN/texlive/latex-basics/learn-latex-in-30-minutes#Finding%5Fand%5Fusing%5FLaTeX%5Fpackages)一节。

## 图注、标签和引用

可以通过 `figure` 环境为图片添加图注、标签和引用，如下所示：

```latex
\documentclass{article}
\usepackage{graphicx}
\graphicspath{{images/}}
 
\begin{document}

\begin{figure}[h]
    \centering
    \includegraphics[width=0.75\textwidth]{mesh}
    \caption{A nice plot.}
    \label{fig:mesh1}
\end{figure}
 
As you can see in figure \ref{fig:mesh1}, the function grows near the origin. This example is on page \pageref{fig:mesh1}.

\end{document}
```

该示例生成的输出如下：

![展示在 LaTeX 中使用图注的图形](https://images.ctfassets.net/nrgyaltdicpt/4DkAWWkQqZP6QHU2EErogQ/9aa2371f2cde0f3f8bf22aa1c0b91789/LL30Fig6r-plain.svg)

示例中有几个值得注意的命令：

* **`\includegraphics[width=0.75\textwidth]{mesh}`**：这种形式的 `\includegraphics` 指示 LaTeX 将图片宽度设置为文本宽度的 75%——文本宽度的值保存在 `\textwidth` 命令中。
* **`\caption{A nice plot.}`**：顾名思义，该命令设置图注，图注可以放在图片的上方或下方。如果你创建了图片列表，该图注将被用于列表中。
* **`\label{fig:mesh1}`**：要在文档中引用这张图片，需要使用 `\label` 命令为其指定一个标签。该标签用于为图片生成编号，并配合下一个命令让你能够引用它。
* **`\ref{fig:mesh1}`**：这段代码将被替换为所引用图片对应的编号。

插入 LaTeX 文档中的图片应放在 `figure` 环境或类似环境中，以便 LaTeX 能够自动将图片放置在文档中的合适位置。

* [插入图片](https://docs.overleaf.com/writing-and-editing/inserting-images)

## 在 LaTeX 中创建列表

你可以使用_环境_创建不同类型的列表，环境用于封装实现特定排版功能所需的 LaTeX 代码。环境以 `\begin{_environment-name_}` 开始，以 `\end{_environment-name_}` 结束，其中 `_environment-name_` 可以是 `figure`、`tabular`，或者是某种列表类型：用于无序列表的 `itemize` 或用于有序列表的 `enumerate`。

### 无序列表

无序列表由 `itemize` 环境生成。每个列表项之前都必须加上 `\item` 命令，如下所示：

```latex
\documentclass{article}
\begin{document}
\begin{itemize}
  \item The individual entries are indicated with a black dot, a so-called bullet.
  \item The text in the entries may be of any length.
\end{itemize}
\end{document}
```

## 在 LaTeX 中添加数学公式

LaTeX 的主要优势之一是可以轻松地编写数学表达式。LaTeX 提供两种用于排版数学公式的书写模式：

* _行内_数学模式，用于书写作为段落一部分的公式
* _行间_（display）数学模式，用于书写不属于文本或段落、而是单独成行排版的表达式

### 行内数学模式

我们来看一个行内数学模式的示例：

```latex

In physics, the mass-energy equivalence is stated 
by the equation $E=mc^2$, discovered in 1905 by Albert Einstein.
\end{document}
```

### 章和节

无论使用何种写作软件，较长的文档通常都会被划分为部分、章、节、小节等。LaTeX 也提供了文档结构命令，但可用的命令及其实现（作用）可能取决于所使用的文档类。例如，使用 `book` 类创建的文档可以划分为部分、章、节、小节等，而 `letter` 类则不提供（不支持）任何此类命令。

```latex

\section{Second Section}

sollicitudin.  Praesent imperdiet mi necante...

\section*{Unnumbered Section}
```

章节命令的名称大多不言自明；例如，`\chapter{First Chapter}` 创建一个标题为 `First Chapter` 的新章，`\section{Introduction}` 生成一个标题为 `Introduction` 的节，依此类推。节还可以进一步划分为 `\subsection{...}`，甚至 `\subsubsection{...}`。节、小节等的编号是自动生成的，但可以通过使用相应命令的所谓_带星号版本_（即末尾带有星号 (\*) 的命令，例如 `\section*{...}` 和 `\subsection*{...}`）来禁用编号。

_总体而言_，LaTeX 文档类提供以下章节命令，具体的文档类各自支持其中相关的子集：

* `\part{part}`
* `\chapter{chapter}`
* `\section{section}`
* `\subsection{subsection}`
* `\subsubsection{subsubsection}`
* `\paragraph{paragraph}`
* `\subparagraph{subparagraph}`

特别地，`\part` 和 `\chapter` 命令仅在 `report` 和 `book` 文档类中可用。

有关文档结构命令的更多信息，请访问 Overleaf 关于节和章的文章。

## 创建表格

Overleaf 提供三种创建表格的方式：

1. 使用 **Visual Editor**（或 **Code Editor**）工具栏中的 [**Insert Table** 按钮](https://www.overleaf.com/learn/how-to/How_to_insert_tables_in_Overleaf%23inserttable#Using%5FInsert%5FTable%5Fto%5Fcreate%5Fa%5Ftable%5Fin%5Fyour%5Fproject)。

### 添加边框

`tabular` 环境支持在表格中使用水平线和垂直线（表线）：

* 要在行的上方和下方添加水平线，请使用 `\hline` 命令
* 要在列之间添加垂直线，请使用竖线参数 `|`

在本例中，参数为 `{|c|c|c|}`，它声明了三个（居中的）列，各列之间以垂直线（表线）分隔；此外，我们使用 `\hline` 在第一行上方和最后一行下方各放置一条水平线：

```latex
\begin{center}
\begin{tabular}{|c|c|c|} 
 \hline
 cell1 & cell2 & cell3 \\ 
 cell4 & cell5 & cell6 \\ 
 cell7 & cell8 & cell9 \\ 
 \hline
\end{tabular}
\end{center}
```

## 查找和使用 LaTeX 宏包

LaTeX 不仅具备强大的排版能力，还通过附加_宏包_提供了一个_可扩展框架_。LaTeX 并不试图提供"包揽一切"的命令和功能，而是被设计为_可扩展_的，允许用户加载外部代码集（宏包），以提供更专业的排版功能，或扩展 LaTeX 的内置功能（例如表格排版）。正如在[添加图片](/zh-CN/texlive/latex-basics/learn-latex-in-30-minutes#Adding%5Fimages)一节中所见，`graphicx` 宏包通过提供导入图形文件的命令来扩展 LaTeX，并通过在导言区中写入以下语句来加载

```latex
\usepackage{graphicx}
```

### 加载宏包

如上所述，宏包是在文档导言区中通过 `\usepackage` 命令加载的。但由于（许多）LaTeX 宏包提供了一组可用于配置其行为的_选项_，因此 `\usepackage` 命令通常如下所示：

```latex
\usepackage[options]{somepackage}
```

方括号"`[...]`"告诉 LaTeX 在加载 `somepackage` 时应用哪组选项。在用户指定的选项集中，各个选项或设置通常以逗号分隔；例如，[geometry 宏包](https://ctan.org/pkg/geometry)提供了许多用于配置 LaTeX 页面布局的选项，因此 `geometry` 的典型用法可能如下所示：

```latex
\usepackage[total={6.5in,8.75in},
top=1.2in, left=0.9in, includefoot]{geometry}
```

`geometry` 宏包是由全球 LaTeX 社区成员编写并贡献、免费提供给任何想使用它的人的宏包之一。

如果某个 LaTeX 宏包不提供任何选项，或者用户希望使用宏包选项的默认值，则可以像这样加载它：

```latex
\usepackage{somepackage}
```

当你写下 `\usepackage[...]{somepackage}` 时，LaTeX 会查找一个名为 `_somepackage_.sty` 的对应文件，并对其进行加载和处理——以使宏包命令可用，并执行该宏包提供的其他代码。如果 LaTeX 找不到 `_somepackage_.sty`，就会报错并终止，如以下 Overleaf 示例所示：

```latex
\documentclass[12pt, letterpaper]{article}
\usepackage{somepackage}% a NON-EXISTENT package
\begin{document}
This will fail!
\end{document}
```

### Overleaf 上可用的宏包：TeX Live 简介

每年，CTAN 上托管的宏包中的一个（庞大的）_子集_，连同 LaTeX 相关字体和其他软件，会被整理并作为一个名为 [TeX Live](https://tug.org/texlive/) 的系统发布，你可以用它来安装自己的（本地）LaTeX 环境。事实上，[Overleaf 的服务器也使用 TeX Live](https://www.overleaf.com/learn/latex/Overleaf_and_TeX_Live)，并会在 TeX Live 新版本发布时进行更新。Overleaf 的 TeX Live 更新并不是即时的，而是在发布后几个月进行，这让我们有时间使用[模板库中的数千个模板](https://www.overleaf.com/gallery)对新版 TeX Live 进行兼容性测试。例如，这是我们的 [TeX Live 2025 升级公告](https://www.overleaf.com/blog/tex-live-2025-is-now-available)。

虽然 TeX Live 包含了 CTAN 宏包的一个（庞大的）_子集_，但你仍可能发现某些有趣的宏包，例如[用于排版围棋棋谱的 igo](https://ctan.org/pkg/igo?lang=en)，它托管在 CTAN 上，却未包含在 TeX Live 中（未由其分发），因此在 Overleaf 上不可用。CTAN 上托管的某些宏包由于各种原因未被纳入 TeX Live：可能是宏包已过时、存在许可问题、非常新（最近才上传），或存在平台依赖（例如只能在 Windows 而不能在 Linux 上运行）。

新的宏包以及现有宏包的更新全年都会上传到 CTAN，但 TeX Live 的更新每年才发布一次；因此，当前版本 TeX Live 中包含的宏包不会像 CTAN 上托管的那样新。由于 Overleaf 的服务器使用 TeX Live，我们服务器上安装的宏包（即用户可用的宏包）可能不是 CTAN 上的最新版本，但一般来说，这不太可能造成问题。
