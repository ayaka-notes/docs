随着时间的推移，PDF 生成能力的不断更新使 PDF 无障碍成为可能。[LaTeX Tagging Project](https://latex3.github.io/tagging-project/documentation/) 等方面的进展使基于 LaTeX 生成的 PDF 也能够实现无障碍，相关改进仍在持续进行中。

<Check>

尤其是 [TeX Live 2025](https://www.overleaf.com/blog/tex-live-2025-is-now-available) 的发布，使这一流程在 Overleaf 中成为可能。请注意，使用 MathML 时推荐使用 **LuaLaTeX** 编译器。

您可以通过了解如何[更改编译器和 TeX Live 版本](https://docs.overleaf.com/getting-started/recompiling-your-project/selecting-a-tex-live-version-and-latex-compiler)，确保项目设置正确。

</Check>

我们的方法主要参考了 LaTeX Project 的[无障碍 PDF 说明](https://latex3.github.io/tagging-project/documentation/usage-instructions)，您可以查阅该说明，了解以下主题的更多细节。

<Warning>

请注意，采用这些做法并不能保证项目中的每个元素都是无障碍的——更多信息请参阅本页的常见问题部分。

</Warning>

### <Icon icon="tag" /> 标记

从本质上讲，PDF 标记（tagging）是一个自动创建"结构"的过程，这种结构易于被屏幕阅读器识别，并且无论现在还是将来都更便于搜索。它利用 LaTeX 代码中已定义的结构，使屏幕阅读器能够区分标题、正文、图形和公式等元素。

TeX Live 2025 通过 `\DocumentMetaData` 声明全面支持自动 PDF 标记。请在 `\documentclass` 之前添加此声明。该声明中有两个影响标记功能的重要键：`tagging` 和 `tagging-setup`。

#### **`tagging`**

将 `tagging` 键设置为 `on`，以确保启用标记。

```latex wrap expandable
\DocumentMetadata{tagging=on}
```

#### **`tagging-setup`**

通过更改 `tagging-setup` 键的值，配置文档的标记方式。

```latex wrap expandable
\DocumentMetadata{tagging=on,tagging-setup={math/setup=mathml-SE}}
```

<Info>

在此示例中，我们使用 \`math/setup=mathml-SE\` 进行 MathML 结构元素标记，但也可以将其设置为 \[\`\tagpdfsetup\`]\(https://ctan.math.washington.edu/tex-archive/macros/latex/contrib/tagpdf/tagpdf.pdf) 支持的任意值。

</Info>

### <Icon icon="text-size" /> 描述

除了自动标记之外，您可能还需要为元素的内容添加描述，尤其是当文档中包含图像和/或表格时。

#### <Icon icon="image" /> 图像

在 Overleaf 中为图像添加关键描述非常简单，这在查阅 LaTeX 代码时也有助于理解某些图像的上下文。您只需在每个 `\includegraphics` 实例中添加相应的图像描述选项即可。从无障碍的角度，需要区分三种主要的图像类型：需要替代（alt）文本的图像、装饰性元素（artifact），以及对应实际文本的图像。

**替代文本**

为图像添加替代文本，可以确保图片拥有一段描述，作为视觉内容的文本替代。使用 `alt` 键并输入文本值。

```latex title="Alt text example" wrap
\includegraphics[width=0.25\linewidth,alt={Macro photo of a green frog's head and hands}]{frog.jpg}
```

**装饰性元素**

如果某个图像不需要被屏幕阅读器读取（即纯粹用于装饰），请将该图像标记为装饰性元素（artifact）。使用 `artifact` 键，无需赋值。

```latex title="Artifact example" wrap
\includegraphics[artifact]{.jpg}
```

**实际文本**

如果某个图像仅仅是一个 Unicode 字符的图片，请提供对应的文本字符。使用 `actualtext` 键，并为其赋一个字符（不带括号）。

```latex title="Actual text example" wrap
\includegraphics[actualtext=B]{.jpg}
```

#### <Icon icon="table" /> 表格

虽然表格通常带有文本，但仍需确保文本与表格的正确部分相关联。在 `tabular` 之前或导言区中添加 `\tagpdfsetup`，开始为 Overleaf 项目中的表格进行设置。从无障碍的角度，需要区分两种主要的表格类型：数据表格和展示表格。

**数据表格**

如果表格至少有一个表头行，请指定哪些行是表头行。使用 `table/header-rows` 键，并输入与表头行位置相对应的一系列数字。

```latex title="Data table example"
\tagpdfsetup{table/header-rows={1}}
\begin{tabular}{l|r}
Item & Quantity \\\hline
Widgets & 42 \\
Gadgets & 13
\end{tabular}
```

**展示表格**

如果表格不应被屏幕阅读器解读为表格，请将其标记为展示表格。使用 `table/tagging=presentation` 键。

```latex title="Presentation table example"
\tagpdfsetup{table/tagging=presentation}
\begin{tabular}{cc}
\textbullet & \textbullet \\
''' & '''
\end{tabular}
```

### <Icon icon="comments-question" /> 常见问题

<Accordion title="是否有工具可以帮助验证我的文档是否无障碍？">

有的，有多种外部工具（包括 [veraPDF](https://verapdf.org/)）可以验证 PDF/A 的部分和一致性级别。此外，您还可以使用 [WebAIM](https://webaim.org/) 等工具计算两种颜色之间的对比度。

</Accordion>

<Accordion title="我的 Overleaf 项目中的宏包与这些功能兼容吗？">

您可以参考 LaTeX Tagging Project 的[宏包状态列表](https://latex3.github.io/tagging-project/tagging-status/)。

</Accordion>

<Accordion title="我还能使用 `beamer` 吗？是否有其他可用于演示文稿的宏包？">

使用 `beamer` 存在一些限制；可以了解一下实验性的 [`ltx-talk` 文档类](https://ctan.org/pkg/ltx-talk)。

</Accordion>

<Accordion title="Overleaf 编辑器是无障碍的吗？">

是的。作为一款 Web 应用程序，Overleaf 利用了现代 Web 浏览器的无障碍特性和功能，这些特性和功能会定期接受无障碍专家的评估。我们最新完成的[自愿产品无障碍模板（VPAT）](https://www.overleaf.com/for/customers/vpat)表明，Overleaf 符合 Web 内容无障碍指南（WCAG）2.2 AA 级标准。

</Accordion>

<Accordion title="Overleaf 生成的 PDF 能否满足《美国残疾人法案》（ADA）第二章以及欧洲统一无障碍标准（EN 301 549）的要求？">

可以。美国和欧洲的法律要求 PDF 符合 WCAG 2.1 AA 标准。要符合 WCAG 2.1 AA，PDF 必须是带标记的 PDF。TeX Live 2025 提供了对 PDF 标记的支持。

</Accordion>

<Accordion title="Overleaf 生成的 PDF 能否符合 PDF/UA-1 标准？">

可以。LaTeX Project 的 Tagging Project 专门用于生成 PDF/UA-1（以及即将推出的 PDF/UA-2）所要求的结构标记。如果用户遵循 LaTeX Project 当前的标记建议，实际上就是在构建一个"PDF/UA 就绪"的文档，这是满足美国和欧洲法律所要求的 WCAG 2.1 AA 法定要求的最有力方式。

</Accordion>

<Accordion title="如何将编译器切换为 LuaLaTeX？">

切换到 LuaLaTeX 非常简单，它是 LaTeX 标记项目团队推荐的 LaTeX 编译引擎。虽然 Overleaf 中的默认编译器是 PDFLaTeX，但您可以[在项目设置中切换到 LuaLaTeX](https://docs.overleaf.com/getting-started/recompiling-your-project/selecting-a-tex-live-version-and-latex-compiler)。

</Accordion>

<Accordion title="在哪里可以选择最新版本的 TeX Live？">

您可以在 [Overleaf Labs](https://www.overleaf.com/labs/participate) 中获取最新版本，它提供了 Overleaf 中的"滚动 TeX Live"（rolling TeX Live）镜像，包括最新的 PDF 标记支持。这个实验性的 TeX Live 版本主要用于测试 TeX Live 和宏包的更改，并在新的无障碍功能被纳入我们每年的 TeX Live 发行版之前提供预览。

大多数 PDF 标记功能在标准的 [TeX Live 2025](https://www.overleaf.com/blog/tex-live-2025-is-now-available) 镜像中均可使用。

</Accordion>
