[TeX Live](https://www.tug.org/texlive/) 是由 [TeX 用户组（TeX Users Group）](https://www.tug.org/)每年发布的免费软件发行版。它提供了在所有常见操作系统上支持基于 LaTeX 的排版所需的 LaTeX 宏包、字体、TeX 引擎以及大量软件工具。

TeX Live 是 Overleaf 的重要组成部分，因为我们的服务器使用它来编译你的 LaTeX 代码并生成实时 PDF 预览。它还让 Overleaf 用户能够轻松使用每个 TeX Live 版本中包含的 5,000 多个 LaTeX 宏包。

你并不局限于使用最新版本的 TeX Live 来编译项目，因为 Overleaf 的服务器也提供以往的 TeX Live 版本。项目可以轻松切换为使用较早版本的 TeX Live——例如，在遇到宏包兼容性问题时。<br />
