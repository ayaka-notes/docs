为了节省时间并快速搭建开发环境，我们提供了另一种开发环境配置方案，即 GitHub Codespace。

## 配置教程

<Steps>
<Step title="创建 Codespaces">
点击下面的按钮，创建用于 server-pro 开发的云端 codespaces。

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ayaka-notes/overleaf-pro)

建议选择至少 **4 核**的 **Machine Type**。如需更大的机器类型，可以[在此](https://support.github.com/contact?tags=rr-codespaces%2Ccat_codespaces)提交工单，向 GitHub 官方支持团队申请。

<Frame>
  <img src="/images/dev/image.png" alt="" />
</Frame>
</Step>

<Step title="运行安装脚本">
请耐心等待 codespace 创建完成。能够访问终端后，运行以下命令：

```text
cd develop/
bin/setup
```

<Frame>
  <img src="/images/dev/image-1.png" alt="" />
</Frame>

<Warning>

该脚本（`bin/setup`）可让你在最短时间内基于 `server-pro` 分支的最新提交搭建开发环境。它可能不适用于旧版本或其他分支。

我们每天通过 [GitHub Action](https://github.com/ayaka-notes/overleaf-pro/actions) 构建开发用 Docker 镜像。

</Warning>
</Step>

<Step title="访问 Launchpad">
切换到端口（port）标签页，你会看到可用的 Web 端口列表。点击 `80` 端口，此时应能看到 Launchpad 页面。

<Frame>
  <img src="/images/dev/image-2.png" alt="" />
</Frame>

你将看到：

<Frame>
  <img src="/images/dev/image-3.png" alt="" />
</Frame>
</Step>

<Step title="开始开发">
现在，属于你的时间到了！开始构建你的精彩功能吧。你需要运行以下命令来启用实时显示：

```bash title="bash" wrap
docker compose -f docker-compose.yml -f docker-compose.dev.yml -f ./docker-compose.image.yml up --no-deps --detach
```
</Step>
</Steps>
