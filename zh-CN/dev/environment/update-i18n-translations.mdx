---
title: 更新 i18n 翻译
icon: language
---

`services/web/frontend/extracted-translations.json` 中有一个文件，Overleaf Web 只会使用该文件中提取出的翻译。

如果你添加了某些内容，请运行以下命令来更新提取的翻译。

```bash
user ➜ ~/overleaf-pro/develop (server-pro) $ bin/shell webpack
root@432836260f8a:/overleaf/services/web# npm run extract-translations
```

一般情况下，请不要编辑翻译文本文件，请优先使用已有的翻译，因为这些文件都是从 Overleaf 上游或第三方翻译网站更新而来的。
