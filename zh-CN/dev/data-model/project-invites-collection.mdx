title: Project Invites 集合

`projectInvites` 保存项目所有者从共享对话框发出的邀请。一个文档对应发往一个邮箱地址的一份邀请。邀请被接受或撤销时，文档会被删除；邀请过期时，Mongo 也会将其删除。Schema 位于 `services/web/app/src/models/ProjectInvite.mjs`，由 `services/web/app/src/Features/Collaborators/CollaboratorsInviteHandler.mjs` 写入。

邀请不会让任何人成为成员。成员保存在项目的 `*_refs` 数组中，见 [Projects 集合](/zh-CN/dev/data-model/projects-collection)。

#### 说明 {#notes}

* 如果接受 `readAndWrite` 或 `review` 邀请时项目已没有空余的编辑者名额，用户会以只读身份加入，并列在项目的 `pendingEditor_refs` 或 `pendingReviewer_refs` 中（`CollaboratorsInviteHandler.mjs:162-205`）。
* 旧版邀请把明文令牌存放在 `token` 字段中。迁移 `20240524135408_add_token_hmac_project_invite_tokens.mjs` 添加了 `tokenHmac`，`20240531082910_remove_project_invite_tokens.mjs` 删除了 `token`。
* 没有任何代码会删除已删除项目的邀请；它们会一直保留，直到被 TTL 索引移除。
