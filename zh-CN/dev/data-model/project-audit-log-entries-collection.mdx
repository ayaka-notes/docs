`projectAuditLogEntries` 是项目的审计日志：共享、邀请、所有权转移、下载以及管理员操作。一个文档是一个项目上的一个事件。由 `web` 负责；schema 为 `services/web/app/src/models/ProjectAuditLogEntry.mjs`，核心代码通过 `services/web/app/src/Features/Project/ProjectAuditLogHandler.mjs` 写入。

`tools/migrations/20220929193200_add_auditLog_indexes.mjs` 最初在 `{ projectId: 1 }` 上创建了 `project_id_1`；`20250912102601` 用复合索引替换了它。由于 Mongoose 自动索引已关闭（`services/web/app/src/infrastructure/Mongoose.mjs:7`），schema 中的 `index: true` 标记不会生效。`managedSubscriptionId` 的索引迁移只带 `saas` 标签。

#### 说明 {#notes}

* 条目通过 TTL 索引在 `timestamp` 之后 2.5 年过期；项目的已删除记录过期时，该项目的所有条目也会一并删除。
