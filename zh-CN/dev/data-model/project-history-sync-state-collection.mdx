title: Project History Sync State 集合
icon: rotate
---

`projectHistorySyncState` 中每个经过重新同步的项目一个文档：当前或最近一次重新同步的状态。重新同步是指 project-history 根据 web 和 docstore 中保存的内容重建项目历史。该集合归 project-history 所有，没有 Mongoose schema；代码是 `services/project-history/app/js/SyncManager.js` 中的 `SyncState` 类及其辅助函数。

| ---- | ------------ |

#### 说明 {#notes}

* 只要 `resyncProjectStructure` 为 `true` 或 `resyncDocContents` 不为空，重新同步就处于运行中（`SyncManager.js:565-567`）。超过 4 小时视为卡住，清除 5 次后视为永久卡住（`SyncManager.js:43-44`, `569-585`）。
* 重新同步完成时，project-history 还会在项目上设置 `overleaf.history.lastResyncedAt`（`SyncManager.js:239-248`）。
