---
title: Project History Labels 集合
icon: tag
---

`projectHistoryLabels` 保存用户在历史视图中给版本加上的标签，每个标签一个文档。它归 project-history 所有，并由其在 `services/project-history/app/js/LabelsManager.js` 中写入；没有 Mongoose schema。Web 只通过 project-history API 访问它。

#### 字段 {#fields}

| 字段 | 类型 | 含义 | 来源 |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | 标签 ID。 | `LabelsManager.js:81-85` |
| `project_id` | ObjectId | 项目。 | `LabelsManager.js:73` |
| `comment` | String | 标签文本。 | `LabelsManager.js:74` |
| `version` | Number | 标签指向的项目历史版本。 | `LabelsManager.js:75` |
| `created_at` | Date | 创建标签的时间；请求可以传入自己的时间，否则使用当前时间。 | `LabelsManager.js:70`, `76` |
| `user_id` | ObjectId | 创建标签的用户。请求中没有用户时省略。 | `LabelsManager.js:78-80` |

#### 写入方 {#who-writes-it}

| 代码 | 作用 |
| ---- | ------------ |
| `services/project-history/app/js/LabelsManager.js:44-90` | `createLabel`：插入一个标签，用于 project-history `POST /project/:project_id/labels`（`services/project-history/app/js/HttpController.js:1134-1171`）。用户添加标签时，Web 会带上用户 ID 调用它（`services/web/app/src/Features/History/HistoryController.mjs:529-546`）。 |
| `LabelsManager.js:113-126` | `deleteLabel`：删除项目的一个标签，用于 `DELETE /project/:project_id/labels/:label_id`。项目所有者删除标签时，Web 使用它（`HistoryController.mjs:649-670`）。 |
| `LabelsManager.js:92-111` | `deleteLabelForUser`：仅当标签由该用户创建时才删除，用于 `DELETE /project/:project_id/user/:user_id/labels/:label_id`。其他所有人删除标签时，Web 使用它。 |
| `LabelsManager.js:128-143` | `transferLabels`：把一个用户的所有标签转移给另一个用户，用于 `POST /user/:from_user/labels/transfer/:to_user`（`services/project-history/app/js/Router.js:52-55`）。Web 中没有任何代码调用这个路由。 |
| `LabelsManager.js:7-25` | `cloneLabels`：把一个项目的标签复制到另一个项目，用于 project-history `POST /project/:project_id/clone`（`HttpController.js:113`），Web 中没有任何代码调用它。 |

#### 读取方 {#who-reads-it}

| 代码 | 作用 |
| ---- | ------------ |
| `LabelsManager.js:27-42` | `getLabels`：项目的所有标签，以 `{ id, comment, version, user_id, created_at }` 的形式返回（`LabelsManager.js:163-171`）。由 `GET /project/:project_id/labels` 使用（`HttpController.js:1076-1100`），Web 为历史视图调用它并填入用户名（`HistoryController.mjs:488-499`）。 |
| `services/project-history/app/js/SummarizedUpdatesManager.js:57` | 把标签加入历史更新列表。 |

#### 说明 {#notes}

* 插入标签之前，project-history 会处理该项目排队中的更新，并检查 history-v1 中是否有该版本的 chunk，除非请求发送了 `validate_exists: false`（`LabelsManager.js:53-59`、`173-195`；`HttpController.js:1109-1115`）。
* 删除项目时，没有代码会删除其标签：project-history `DELETE /project/:project_id` 只清除同步状态和失败记录（`HttpController.js:1363-1396`），其他服务也不会碰这个集合。
