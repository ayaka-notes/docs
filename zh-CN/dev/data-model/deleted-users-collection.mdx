title: Deleted Users 集合
icon: user-xmark
---

`deletedUsers` 在用户账户被删除后保留该账户：每个被删除的账户一个文档，包含整个用户文档的副本以及删除者。Web 在 `services/web/app/src/Features/User/UserDeleter.mjs` 中写入它；schema 是 `services/web/app/src/models/DeletedUser.mjs`。硬删除延迟过后，过期处理会移除用户副本，但带有 `deleterData` 的记录会保留下来。

删除用户也会删除该用户拥有的项目；它们以原因 `account-deletion` 进入 [Deleted Projects 集合](/zh-CN/dev/data-model/deleted-projects-collection)。

#### 说明 {#notes}

* 监听 `expireDeletedUser` 的模块会删除它们自己保存的该用户数据：`dropbox`（`services/web/modules/dropbox/index.mjs:62`）、`github-sync`（`services/web/modules/github-sync/index.mjs:66`）、`gitlab-sync`（`services/web/modules/gitlab-sync/index.mjs:56`）和 `gitea-sync`（`services/web/modules/gitea-sync/index.mjs:56`）。
* 过期的记录永远不会被删除：`deleterData` 会永久保留，只有 `user` 和 IP 地址会被移除。
* 用户的个人访问令牌不会随账户一起删除，参见 [OAuth Access Tokens 集合](/zh-CN/dev/data-model/oauth-access-tokens-collection)。
* Mongoose 还会给 `deleterData` 分配它自己的 `_id`，没有任何代码读取它。
