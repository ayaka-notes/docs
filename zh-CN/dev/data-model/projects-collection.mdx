`Project` 表示 Overleaf 中的单个 LaTeX 项目。它存储项目元数据、所有权与访问控制、文件结构、编译设置以及协作状态。

#### 核心标识与元数据

* `_id`：标识项目的唯一 MongoDB ObjectId。
* `name`：项目显示名称。
* `description`：项目的可选文字描述。
* `active`：指示项目当前是否处于活动状态。
* `version`：内部 schema 或项目格式版本。
* `trashed`：已移入回收站（软删除）的条目列表。
* `deletedDocs`：已永久删除文档的记录。

#### 所有权与访问控制

* `owner_ref`：对拥有该项目的用户的引用。
* `collaberator_refs`：拥有编辑权限的用户。
* `reviewer_refs`：拥有审阅者级别访问权限的用户。
* `readOnly_refs`：拥有只读访问权限的用户。
* `pendingEditor_refs` / `pendingReviewer_refs`：待处理的邀请。

#### 基于令牌的访问

* `tokens`：共享链接的令牌注册表。
* `tokenAccessReadOnly_refs`：授予只读访问权限的令牌。
* `tokenAccessReadAndWrite_refs`：授予读写访问权限的令牌。

#### 活动跟踪

* `lastUpdated`：最近一次修改的时间戳。
* `lastUpdatedBy`：执行最近一次更新的用户。
* `lastOpened`：项目最近一次被打开的时间戳。
* `deletedByExternalDataSource`：删除是否由外部集成触发。

#### 项目结构

根文档与文件夹

* `rootDoc_id`：LaTeX 主入口文档（通常为 `main.tex`）的 ObjectId。
* `rootFolder`：项目文件树的内联表示。

每个文件夹条目包含：

* `name` / `_id`：文件夹名称和标识符。
* `docs`：LaTeX 源文档列表，包含名称和 `_id`。
* `fileRefs`：二进制文件引用（图片、数据文件），包括：
  * `name`：文件名
  * `created`：上传时间戳
  * `rev`：修订计数器
  * `hash`：用于去重的内容哈希
  * `linkedFileData`：外部存储关联（如有）
* `folders`：嵌套的子文件夹。

#### 编译与编辑器设置

* `compiler`：所选的 LaTeX 引擎（`pdflatex`、`xelatex`、`lualatex` 等）。
* `spellCheckLanguage`：该项目的拼写检查语言。

#### 公开与共享设置

* `publicAccesLevel`：项目可见性（`private`、`readOnly`、`public` 等）。
* `collabratecUsers`：来自外部协作平台的关联用户。

#### Overleaf 特有扩展

* `overleaf.history`：
  * `id`：历史服务使用的标识符。
  * `display`：历史记录是否启用并可见。

#### 内部版本控制

* `__v`：用于并发控制的 Mongoose 内部版本键。
