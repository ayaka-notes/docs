---
title: OAuth Access Tokens 集合
icon: ticket
---

`oauthAccessTokens` 保存 web 接受的 bearer 令牌。在 Ayakaleaf Pro 中，这些是用户在账户设置页面创建、用于 git-bridge 和 MCP 端点的个人访问令牌（Git 身份验证令牌）。一个文档对应一个令牌。Schema 位于 `services/web/app/src/models/OauthAccessToken.mjs`；web 模块 `oauth2-server` 写入该集合，大多通过原生驱动。

#### 写入方 {#who-writes-it}

| 代码 | 作用 |
| ---- | ------------ |
| `OAuthPersonalAccessTokenManager.mjs:53-88` (`createToken`) | 插入个人访问令牌。路由 `POST /oauth/personal-access-tokens`（`services/web/modules/oauth2-server/app/src/OAuthPersonalAccessTokenRouter.mjs:22-27`）要求用户具备 `gitBridge` 功能，并且每个用户最多 10 个令牌（`OAuthPersonalAccessTokenController.mjs:7,34-38`）。 |
| `OAuthPersonalAccessTokenManager.mjs:90-105` (`removeToken`) | 删除用户的一个令牌。路由 `DELETE /oauth/personal-access-tokens/:token_id`（`OAuthPersonalAccessTokenRouter.mjs:29-32`）。 |
| `OAuthPersonalAccessTokenManager.mjs:136-140`, `OAuth2Model.mjs:58-61` | 校验成功后设置 `lastUsedAt`。 |

#### 说明 {#notes}

* 删除用户不会删除其令牌。`UserDeleter` 会触发 `cleanupPersonalAccessTokens` 钩子（`services/web/app/src/Features/User/UserDeleter.mjs:230-234`），但没有模块监听它。由于用户已不存在，两种令牌校验都会拒绝这些令牌，TTL 索引会在 `accessTokenExpiresAt` 之后一天将其移除。
* 停用用户只会结束其会话。令牌仍然保留，只要 `users.suspended` 为 `true`，两种令牌校验都会拒绝它们（`OAuth2Model.mjs:51-54`, `OAuthPersonalAccessTokenManager.mjs:129-134`）。
