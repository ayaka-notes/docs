CLSI（Common LaTeX Service Interface）负责编译项目，对编译输出运行 SyncTeX 和 texcount，并用 pandoc 转换文档。由 web 调用；输出文件本身由 clsi-nginx 提供，而不是这个端口。没有认证：只能在 Docker 网络内访问。

* <strong>地址：</strong> `http://clsi:3013`, 位于 Docker 网络内
* <strong>认证：</strong>无
* <strong>OpenAPI 文件：</strong> [`develop/hoppscotch/openapi/clsi.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/clsi.yaml)
