为 web 获取外部 URL 并将响应以流的形式返回，同时拒绝内部地址，使用户无法访问 Docker 网络。web 通过它发送 URL 文件、Open in Overleaf 导入以及 AI 智能体的 web_fetch。

* <strong>地址：</strong> `http://linked-url-proxy:3066`, 位于 Docker 网络内
* <strong>认证：</strong>无
* <strong>OpenAPI 文件：</strong> [`develop/hoppscotch/openapi/linked-url-proxy.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/linked-url-proxy.yaml)
