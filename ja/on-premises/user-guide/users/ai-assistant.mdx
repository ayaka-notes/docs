title: AI アシスタント
description: エディターでプロジェクトについて質問し、アシスタントが提案する編集を確認して、適用または却下します。
icon: sparkles
---

アシスタントは、開いているプロジェクトを対象に動作します。ドキュメントを読んで編集を提案し、あなたが各編集を適用または却下します。スクリーンショットの回答は一例です。得られる回答は、サイトで使っているモデルによって異なります。

<Info>

左のバーに **AI assistant** が表示されない場合は、管理者に [AI 連携](/ja/on-premises/configuration/overleaf-toolkit/integrations/ai-integration)を参照してもらってください。

</Info>

## チャットを始める {#start-a-chat}

<Steps>
<Step title="アシスタントを開く">
エディターの左のバーで **AI assistant** をクリックします。エディターの横にパネルが開きます。
</Step>

<Step title="規約に同意する">
初回は、パネルに AI 機能の規約が表示されます。**Accept and continue** をクリックします。この操作は一度だけで、[エラーアシスタント](/ja/on-premises/user-guide/users/error-assistant)にも適用されます。

<Frame caption="一度だけ表示される規約">
  <img src="/images/on-premises/ai-assistant-consent.png" alt="規約と Accept and continue ボタンが表示された AI assistant パネル" />
</Frame>
</Step>

<Step title="質問する">
<strong>What would you like to do?</strong> に入力して Enter キーを押すか、矢印をクリックします。**Start a chat** の下の提案をクリックすることもできます。提案はチャットごとに変わり、直前のコンパイルにエラーがある場合は **Fix the compile errors** も加わります。

<Frame caption="空のチャット">
  <img src="/images/on-premises/ai-assistant-start.png" alt="Start a chat の下の提案とメッセージボックスがあるパネル" />
</Frame>
</Step>

<Step title="回答を読む">
アシスタントが行ったことは、**Read line 15-16 of main.tex** のような行としてボックスに表示され、ステップが終わるとチェックマークが付きます。その後に回答が続きます。モデルが推論を共有している場合は、**Reasoned for 1 s** をクリックすると読めます。

<Frame caption="質問とその回答">
  <img src="/images/on-premises/ai-assistant-answer.png" alt="質問、Reasoned for 1 s と Read line 15-16 of main.tex を含むボックス、および回答" />
</Frame>
</Step>
</Steps>

## 選択した行について質問する {#ask-about-selected-lines}

エディターで行を選択します。メッセージボックスの上に `main.tex: 16` のようなラベルが表示され、選択したテキストがメッセージと一緒に送られます。空のチャットでは、提案が **Make it shorter** のように選択内容に関するものに変わります。

<Frame caption="選択した行">
  <img src="/images/on-premises/ai-assistant-selection.png" alt="エディターで選択した行、メッセージボックスの main.tex: 16 ラベル、選択内容に関する提案" />
</Frame>

## 提案された編集を確認する {#review-a-suggested-edit}

編集は、適用するまでドキュメントに反映されません。

<Steps>
<Step title="提案を読む">
**Edit line 16** というボックスに、理由、行番号、変更内容が表示されます。古いテキストには取り消し線が引かれ、新しいテキストは強調表示されます。ドキュメントはまだ変更されていません。**Show result** は新しいテキストだけを表示し、**Show diff** で元の表示に戻ります。

<Frame caption="判断を待っている編集">
  <img src="/images/on-premises/ai-assistant-edit.png" alt="Show result、Reject、Apply がある Edit line 16 ボックスと、エディターの変更されていない行" />
</Frame>
</Step>

<Step title="適用する">
**Apply** をクリックします。変更がエディターに反映され、ボックスにチェックマークが付き、アシスタントは作業を続けます。編集が別のドキュメントにある場合は、そのドキュメントが開きます。

<Frame caption="編集が適用された状態">
  <img src="/images/on-premises/ai-assistant-applied.png" alt="チェックマークと Undo ボタンがある Edit line 16 ボックスと、エディターの変更された行" />
</Frame>
</Step>

<Step title="気が変わったら元に戻す">
**Undo** は変更をドキュメントから取り除き、**Apply** で再び反映します。どちらの操作もアシスタントには伝わりません。
</Step>
</Steps>

### 編集を却下する {#reject-an-edit}

**Reject** をクリックします。ドキュメントはそのままで、ボックスに <strong>The user declined this edit.</strong> と表示され、アシスタントは却下されたことを把握したうえで作業を続けます。ボタンはなくなるため、その編集をもう一度得るには改めて依頼してください。

判断せずに新しいメッセージを書くと、編集は適用されず、ボックスにそのことが表示されます。

<Frame caption="却下した編集と、判断しなかった編集">
  <img src="/images/on-premises/ai-assistant-rejected.png" alt="バツ印が付いた 2 つの Edit line 13 ボックス。1 つは却下、もう 1 つは未判断" />
</Frame>

## アシスタントがプロジェクトでできること {#what-the-assistant-can-do-in-a-project}

判断を待つのは編集だけです。その他のステップは、アシスタントが実行した時点ですぐに実行されます。

| チャットに表示される行 | 内容 |
| -------------------- | ------------ |
| **Read line 15-16 of main.tex** | ドキュメントの行を読みます |
| **Find “schedule” in main.tex** | ドキュメント内のテキストを探します |
| **List the project files** | プロジェクトのファイルを一覧表示します |
| **Create appendix.tex** | 空のドキュメントを作成して開きます |
| **Edit line 16** | 編集を提案します (上記参照) |
| **Compile** | プロジェクトをコンパイルします |
| **Check the compile log** | 直前のコンパイルのエラーと警告を読みます |
| **Look at PDF page 1** | PDF のページをチャットに表示します |
| **Read the PDF structure** | PDF の構造を読みます |
| **Switch to xelatex** | **Settings** と同様に、プロジェクトのコンパイラーを変更します |
| <strong>Search the web for “...”</strong> | ウェブを検索します |
| <strong>Search the help pages for “...”</strong> | ヘルプページを検索します |

<Frame caption="新しいファイルと、別のドキュメントでの編集">
  <img src="/images/on-premises/ai-assistant-new-file.png" alt="Create appendix.tex の行、エディターで開いた新しいファイル、判断を待っている編集" />
</Frame>

<Frame caption="コンパイルと PDF のページ">
  <img src="/images/on-premises/ai-assistant-compile.png" alt="Compile と Look at PDF page 1 の行、およびチャットに表示されたページ" />
</Frame>

検索の行には、見つかった結果の件数が表示されます。クリックすると一覧が表示されます。検索が使えるかどうかはサイトによって異なります。[オプションの検索サービス](/ja/on-premises/configuration/overleaf-toolkit/integrations/ai-integration#optional-search-services)を参照してください。

<Frame caption="検索結果">
  <img src="/images/on-premises/ai-assistant-search.png" alt="2 件の結果を表示するように開いた Search the web の行" />
</Frame>

**Fix the compile errors** の提案は、ログを確認して見つかった問題を修正するようアシスタントに依頼します。修正は、確認用の編集として届きます。

## 画像や PDF を添付する {#attach-an-image-or-a-pdf}

メッセージボックスで画像アイコン **Attach image or PDF** をクリックし、ファイルを選びます。ファイル名がテキストの上に表示されます。メッセージを書いて送信します。

<Frame caption="メッセージに添付したファイル">
  <img src="/images/on-premises/ai-assistant-attach.png" alt="sketch.png が添付され、メッセージが入力されたメッセージボックス" />
</Frame>

パネルは、それ以外のファイルを <strong>Only images and PDF files can be attached.</strong> で、大きなファイルを <strong>Files must be smaller than 2 MB.</strong> で拒否します。

## アシスタントを停止する {#stop-the-assistant}

アシスタントの作業中は、メッセージボックスの矢印が **Stop** ボタンに変わります。クリックします。実行中のステップは <strong>Stopped by the user.</strong> で終わり、再びメッセージを書くまで何も起こりません。

<Frame caption="Stop ボタン">
  <img src="/images/on-premises/ai-assistant-stop.png" alt="Stop ボタンがあるメッセージボックス" />
</Frame>

## アシスタントが自動で止まった場合 {#if-the-assistant-stops-by-itself}

アシスタントが 1 つのメッセージで実行できるステップ数には上限があります。上限に達すると、パネルに <strong>The assistant used all the steps it may take for one message. Reply to let it carry on.</strong> と表示されます。`Go on` などと返信すると続行します。

<Frame caption="ステップの上限">
  <img src="/images/on-premises/ai-assistant-step-limit.png" alt="アシスタントがすべてのステップを使い切ったという通知" />
</Frame>

パネルに **Something’s gone wrong** と表示された場合、リクエストは失敗しています。メッセージを送り直すか、**Start new chat** をクリックしてください。

## パネルを移動してやり直す {#move-the-panel-and-start-over}

パネルの上部には次のボタンがあります。

* **Start new chat** はパネルをクリアします。過去のチャットの一覧はありません。ページを再読み込みしてもチャットはクリアされます。
* **Move to the right** はパネルを PDF の右側に移動し、ファイルツリーを使っている間も開いたままにします。**Move to the left** で元に戻ります。チャットは残ります。
* **Close** はパネルを非表示にします。左のバーの **AI assistant** をクリックすると、チャットが残った状態で再表示されます。

<Frame caption="右側のパネル">
  <img src="/images/on-premises/ai-assistant-right.png" alt="PDF の右側に AI assistant パネルがあるエディター" />
</Frame>

## トークン使用量 {#token-usage}

アシスタントは、使用したトークン数を表示しません。サイトに上限が設定されていて上限に達すると、次のメッセージには回答が返りません。パネルに **Usage limit reached** と、再びチャットできるまでの時間が表示され、メッセージボックスはグレー表示になります。

<Frame caption="上限に達した状態">
  <img src="/images/on-premises/ai-assistant-usage-limit.png" alt="グレー表示のメッセージボックスの上にある Usage limit reached の通知" />
</Frame>

新しいチャットでも同じ通知が表示されます。再読み込みするとボックスは元どおりに見えますが、次のメッセージでもやはり通知が表示されます。[エラーアシスタント](/ja/on-premises/user-guide/users/error-assistant)も同じ上限にカウントされ、ログエントリに **Usage limit reached** と表示されます。

上限は管理者が設定します。[使用量とリセット](/ja/on-premises/configuration/overleaf-toolkit/integrations/ai-integration#usage-and-reset)を参照してください。
