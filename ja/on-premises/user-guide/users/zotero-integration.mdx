Zotero ライブラリを `.bib` ファイルとしてプロジェクトにインポートし、いつもどおりそこから引用します。このファイルはコピーです。**Refresh** をクリックしたときだけ変更されます。

<Info>

**Account settings** に Zotero のオプションが表示されない場合は、管理者に [Zotero 連携](/ja/on-premises/configuration/overleaf-toolkit/integrations/zotero-integration)を有効にするよう依頼してください。

</Info>

## Zotero アカウントをリンクする {#link-your-zotero-account}

この操作は一度だけ行います。

<Steps>
<Step title="アカウント設定を開く">
**Account**、**Account settings** の順にクリックします。**Reference managers** で **Zotero** を見つけ、**Link to Zotero** をクリックします。

<Frame caption="アカウント設定の Zotero">
  <img src="/images/on-premises/zotero-link.png" alt="Link to Zotero ボタンがあるアカウント設定の Zotero セクション" />
</Frame>

エディターの **Integrations** パネルにある **Zotero** カードからも、同じタブで同じ場所に移動できます。

<Frame caption="Integrations パネル">
  <img src="/images/on-premises/zotero-integrations.png" alt="Zotero カードがある Integrations パネル" />
</Frame>
</Step>

<Step title="Zotero で承認する">
Zotero が開きます。求められたらサインインし、アプリケーションを承認します。ライブラリとグループの読み取りだけを求めるため、Zotero の内容は一切変更できません。
</Step>

<Step title="リンクを確認する">
アカウント設定に戻ります。緑色のメッセージに **Reference manager linked** と表示され、ボタンが **Unlink** に変わります。

<Frame caption="Zotero アカウントがリンクされた状態">
  <img src="/images/on-premises/zotero-linked.png" alt="緑色のメッセージと Unlink ボタンがあるアカウント設定の Zotero セクション" />
</Frame>
</Step>
</Steps>

Zotero でアクセスを許可しなかった場合、同じセクションに **Sorry, something went wrong** と表示されます。**Link to Zotero** をクリックしてやり直してください。

## ライブラリからファイルを作成する {#create-a-file-from-your-library}

<Steps>
<Step title="Add files ダイアログを開く">
プロジェクトを開きます。ファイルツリーで **New file**、**From Zotero** の順にクリックします。この項目はアカウントをリンクした後にだけ表示されます。
</Step>

<Step title="ファイル名とライブラリを選ぶ">
**File Name** の初期値は `zotero.bib` です。拡張子 `.bib` は残してください。拡張子がないとプレビューが表示されず、`\cite` も `\bibliography` もエントリを見つけられません。

**Library** の初期値は **My Library** で、グループライブラリも一覧表示されます。1 つのファイルには 1 つのライブラリが入ります。

<Frame caption="個人ライブラリからのファイル">
  <img src="/images/on-premises/zotero-new-file.png" alt="zotero.bib と My Library が指定された Add files ダイアログの From Zotero タブ" />
</Frame>
</Step>

<Step title="Create をクリックする">
ダイアログが閉じ、ファイルがファイルツリーに表示されます。クリックすると、インポート日時とエントリが表示されます。エディターで編集することはできません。

<Frame caption="インポートされたファイル">
  <img src="/images/on-premises/zotero-file.png" alt="Refresh ボタンとともにエディターで開いたインポート済みの zotero.bib" />
</Frame>

**Create** を押しても何も起きないように見える場合は、同じ名前のファイルがすでに存在します。別の名前を選んでください。
</Step>
</Steps>

### グループライブラリをインポートする {#import-a-group-library}

別のファイル名で同じ手順を繰り返し、**Library** でグループを選びます。1 つのプロジェクトにこうしたファイルを複数置けます。

<Frame caption="グループライブラリからのファイル">
  <img src="/images/on-premises/zotero-group.png" alt="ファイル名 reading-group.bib とライブラリ Reading group が指定された From Zotero タブ" />
</Frame>

## ファイルから引用する {#cite-from-the-file}

<Steps>
<Step title="引用を始める">
`.tex` ファイルで `\cite{` と入力します。プロジェクト内のすべての `.bib` ファイルのエントリが一覧表示されます。1 つクリックすると挿入されます。

<Frame caption="インポートしたファイルのエントリ">
  <img src="/images/on-premises/zotero-cite.png" alt="引用の下に引用キーを一覧表示するエディター" />
</Frame>
</Step>

<Step title="またはタイトルや著者で検索する">
一覧の下の **Search** をクリックするか、波括弧の中で Ctrl+Space を押します。入力して絞り込み、1 つ以上のエントリをクリックしてから **Insert** をクリックします。

<Frame caption="参考文献検索">
  <img src="/images/on-premises/zotero-search.png" alt="エントリが 1 つ選択された Search the .bib files in this project ダイアログ" />
</Frame>
</Step>

<Step title="参考文献リストを追加する">
`\end{document}` の前に次の行を追加します。ファイル名は `.bib` を除き、カンマで区切ります。

```latex
\bibliographystyle{plain}
\bibliography{reading-group,zotero}
```

**Recompile** をクリックします。参考文献が PDF に表示されます。

<Frame caption="コンパイルされた参考文献">
  <img src="/images/on-premises/zotero-compiled.png" alt="引用と参考文献リストがあるエディターと、参考文献が 1 件あるコンパイル済み PDF" />
</Frame>
</Step>
</Steps>

インポートしたファイルは **Settings** の **References**、**Main bibliography file for this project** には表示されません。そのため、プロジェクトに他の `.bib` ファイルがない場合、この一覧は空のままです。それでもこれらのファイルから引用できます。

<Frame caption="一覧が空なのは想定どおりです">
  <img src="/images/on-premises/zotero-settings-references.png" alt="空で無効になった一覧があるプロジェクト設定の References タブ" />
</Frame>

## ファイルを更新する {#refresh-the-file}

Zotero ライブラリの変更は自動ではプロジェクトに反映されず、コンパイルしても取得されません。

<Steps>
<Step title="ファイルを開く">
ファイルツリーで、インポートしたファイルをクリックします。
</Step>

<Step title="Refresh をクリックする">
作成時に選んだライブラリから、ファイル全体が再インポートされます。新しいエントリが追加され、削除されたエントリは消えます。上部の時刻が変わります。

<Frame caption="更新されたファイル">
  <img src="/images/on-premises/zotero-refresh.png" alt="新しいエントリと新しいインポート時刻がある更新済みの zotero.bib" />
</Frame>
</Step>

<Step title="再コンパイルする">
新しいエントリはすぐに `\cite{` の一覧に表示されます。**Recompile** をクリックして PDF を更新します。
</Step>
</Steps>

ファイルはそれぞれ個別に更新されます。グループのファイルは別途更新してください。共有プロジェクトで誰がファイルを更新できるかは、[管理者向けの注意事項](/on-premises/configuration/overleaf-toolkit/integrations/zotero-integration#notes)を参照してください。

## Zotero アカウントのリンクを解除する {#unlink-your-zotero-account}

**Account settings** の **Zotero** で **Unlink** をクリックし、ダイアログでもう一度 **Unlink** をクリックします。ボタンは再び **Link to Zotero** になります。

<Frame caption="アカウントのリンクを解除する">
  <img src="/images/on-premises/zotero-unlink.png" alt="Unlink Zotero Account ダイアログ" />
</Frame>

インポートしたファイルはプロジェクトに残り、引き続きコンパイルできます。**Add files** ダイアログから **From Zotero** がなくなり、アカウントを再度リンクするまで **Refresh** はエラーを表示します。

<Frame caption="アカウントをリンクせずに更新した場合">
  <img src="/images/on-premises/zotero-relink-error.png" alt="Could not load references from Zotero, please re-link your account and try again というエラーが表示されたインポート済みファイル" />
</Frame>

再度リンクすると、同じファイルで **Refresh** が使えるようになります。

## 問題が発生した場合 {#if-something-goes-wrong}

**Add files** ダイアログに **Could not load references from Zotero, please re-link your account and try again** または **There was an error accessing your Zotero data** と表示される場合: Zotero でアクセス権を取り消したなどの理由で、Overleaf がライブラリを読み取れなくなっています。**Account settings** で **Unlink**、**Link to Zotero** の順にクリックしてください。それまでは **Create** も失敗し、自分のプロジェクトであっても **The project that contains this file is not shared with you** というメッセージが表示されます。

<Frame caption="Overleaf がライブラリを読み取れない状態">
  <img src="/images/on-premises/zotero-access-error.png" alt="両方のエラーメッセージが表示された From Zotero タブ" />
</Frame>

**Refresh** をクリックしたときに **The remote service produced an error** と表示される場合: Zotero へのリクエストが失敗しました。ファイルの内容はそのまま残ります。しばらくしてから再度 **Refresh** をクリックしてください。
