参考文献検索はプロジェクト内のすべての `.bib` ファイルを対象にするため、引用キーを覚えていなくても参考文献を見つけられます。設定は不要です。

プロジェクトには少なくとも 1 つの `.bib` ファイルが必要です。アップロードするか、[Zotero](/ja/on-premises/user-guide/users/zotero-integration) または [Mendeley](/ja/on-premises/user-guide/users/mendeley-integration) からライブラリをインポートしてください。

## 引用を挿入する {#insert-a-citation}

<Steps>
<Step title="引用を始める">
`.tex` ファイルで `\cite{` と入力します。エディターが閉じ波括弧を追加します。カーソルの下に引用キーと青いボックス **Open advanced reference search** が表示されます。

<Frame caption="引用の下の青いボックス">
  <img src="/images/on-premises/reference-search-hint.png" alt="\cite{} と引用キーの一覧、Search ボタンがある青いボックスが表示されたエディター" />
</Frame>

ツールバーの **Insert citation** ボタンや、**Insert**、**Citation** の順に選ぶ操作でも `\cite{}` が入力されます。このボックスは `\citep`、`\autocite`、`\parencite`、`\textcite` など他の引用コマンドでも表示されます。
</Step>

<Step title="検索を開く">
青いボックスの **Search** をクリックするか、波括弧の間で Ctrl+Space を押します。ダイアログにすべてのエントリが、タイトル、引用キー、著者、ジャーナル、年とともに一覧表示されます。

<Frame caption="プロジェクトのすべてのエントリ">
  <img src="/images/on-premises/reference-search-dialog.png" alt="5 件のエントリを一覧表示する Search the .bib files in this project ダイアログ" />
</Frame>
</Step>

<Step title="エントリを見つける">
検索ボックスに入力します。引用キー、著者、タイトル、ジャーナル、年を対象に検索し、一致した部分を強調表示します。すべての単語が一致する必要があるため、`turing 1936` で Turing の 1936 年の論文が見つかります。出版社など他のフィールドは検索されません。

<Frame caption="著者と年で検索">
  <img src="/images/on-premises/reference-search-filter.png" alt="turing 1936 と入力された検索ボックスと、一致部分が赤く表示されたエントリ" />
</Frame>
</Step>

<Step title="1 つ以上のエントリを選ぶ">
エントリをクリックします。緑色になり、そのキーが一覧の上に表示されます。別のエントリを追加するにはそれをクリックするか、もう一度検索します。選んだものは残ります。外すには、もう一度クリックするか、キーの横の <strong>×</strong> をクリックします。

<Frame caption="2 件を選んだ状態">
  <img src="/images/on-premises/reference-search-selected.png" alt="一覧の上のキー knuth1984 と einstein1905、緑色で表示されたそれらのエントリ" />
</Frame>
</Step>

<Step title="Insert をクリックする">
キーがカンマ区切りで波括弧の間に入ります。ドキュメントにまだ参考文献リストがない場合は、`\end{document}` の前に次の行を追加します。`.bib` ファイルの名前は拡張子を除いて指定します。

```latex
\bibliographystyle{plain}
\bibliography{refs,more}
```

**Recompile** をクリックします。参考文献が PDF に表示されます。

<Frame caption="コンパイルされた引用">
  <img src="/images/on-premises/reference-search-compiled.png" alt="\cite{knuth1984, einstein1905} があるエディターと、両方の参考文献がある PDF" />
</Frame>
</Step>
</Steps>

**Visual** エディターでも検索は同じように使えます。

## 引用を変更する {#change-a-citation}

<strong>参考文献を追加する:</strong> 既存の引用の波括弧の間にカーソルを置き、検索を開きます。**Insert** は既存のキーの後に新しいキーを追加します。

<strong>参考文献を置き換える:</strong> エディターでキーを選択し、Ctrl+Space を押します。キーが一覧の上に表示され、ボタンが **Replace** に変わります。不要なキーを外し、別のキーを追加してから **Replace** をクリックします。どの `.bib` ファイルにもないキーは、外すまで残ります。

<Frame caption="選択したキーを置き換える">
  <img src="/images/on-premises/reference-search-replace.png" alt="一覧の上に knuth1984、missing2000、turing1936 があり、Replace ボタンがあるダイアログ" />
</Frame>

## キーボードを使う {#use-the-keyboard}

| キー | 動作 |
| --- | ------------ |
| **下矢印** | 検索ボックスから一覧に移り、一覧を下に移動します |
| **上矢印** | 一覧を上に移動します |
| **Space** | エントリを選ぶ、または選択から外します |
| **Enter** | 一覧にいるとき、選んだものを挿入します |
| **Tab** | 検索ボックス、一覧、ボタンの間を移動します |
| **Esc** | 何も変更せずにダイアログを閉じます |

## エントリの取得元 {#where-the-entries-come-from}

検索はプロジェクト内のすべての `.bib` ファイルが対象で、Zotero や Mendeley からインポートしたファイルも含まれます。`.bib` ファイルを編集すると、次の検索で新しいエントリが見つかります。

## 問題が発生した場合 {#if-something-goes-wrong}

| 表示される内容 | 理由 | 対処 |
| ------------ | --- | ---------- |
| ダイアログの一覧が空 | プロジェクトに `.bib` ファイルがない | アップロードするか作成します |
| 青いボックスがなく、Ctrl+Space で LaTeX コマンドが一覧表示される | カーソルが引用の波括弧の間にない | 波括弧の間をクリックします |
| Ctrl+Space を押しても何も起きない | コンピューターがこのショートカットを別の用途に使っている | 青いボックスの **Search** をクリックします |
| エントリが見つからない | 検索対象はキー、著者、タイトル、ジャーナル、年だけ | これらのいずれかで検索します |
