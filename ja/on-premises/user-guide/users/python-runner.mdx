Python スクリプトはブラウザー内で実行されるため、出力はエディターのすぐ下に表示されます。設定は何も必要ありません。

<Steps>
<Step title="スクリプトを作成する">
ファイルツリーで **New file** アイコンをクリックします。`.py` で終わる名前を入力し、**Create** をクリックします。

<Frame caption="新しい Python ファイル">
  <img src="/images/on-premises/python-runner-new-file.png" alt="名前 analysis.py が入力された Add Files ダイアログ" />
</Frame>

エディターの下に **Run** ボタンと出力ペインが表示されます。初回は、Python の読み込み中はボタンが無効のままです。
</Step>

<Step title="実行する">
コードを書いて **Run** をクリックします。スクリプトが出力した内容が出力ペインに表示されます。事前に保存する必要はありません。

スクリプトが書き出したファイルはプロジェクトに保存されます。どのファイルかはメッセージで通知されます（例: **results.txt saved to your project**）。ファイルはファイルツリーにも表示されます。

<Frame caption="出力と保存されたファイル">
  <img src="/images/on-premises/python-runner-output.png" alt="エディター内のスクリプト、その下に出力、そしてメッセージ results.txt saved to your project" />
</Frame>
</Step>

<Step title="スクリプトを停止する">
スクリプトの実行中は、**Run** が **Stop** に変わります。クリックするとスクリプトが中断されます。出力ペインの最後に **Execution interrupted** と表示されます。

<Frame caption="実行中のスクリプト">
  <img src="/images/on-premises/python-runner-stop.png" alt="Stop ボタンと実行中のスクリプトの出力" />
</Frame>
</Step>
</Steps>

## ドキュメントで図を使う {#use-a-figure-in-your-document}

プロットを表示するウィンドウはないため、ファイルに保存します。例:

```python
import matplotlib.pyplot as plt

plt.plot([1, 2, 3], [1, 4, 9])
plt.savefig("figure.png")
```

`figure.png` がプロジェクトに追加され、そのまま `\includegraphics{figure.png}` で使えます。

<Frame caption="保存されたプロット">
  <img src="/images/on-premises/python-runner-figure.png" alt="エディターで開いた figure.png と、メッセージ figure.png saved to your project" />
</Frame>

## プロジェクトのファイルを読み込む {#read-your-project’s-files}

スクリプトはパスを指定してプロジェクトのファイルを開けます:

```python
print(open("results.txt").read())
```

## 問題が起きたとき {#if-something-goes-wrong}

<strong>スクリプトがエラーを発生させた。</strong>エラーは出力ペインに赤色で、スクリプトがそれまでに出力した内容の後に表示されます。

<Frame caption="スクリプトのエラー">
  <img src="/images/on-premises/python-runner-error.png" alt="出力されたテキストの後に赤色のトレースバック" />
</Frame>

<strong>`ModuleNotFoundError: No module named ...`。</strong>使用できるのは Pyodide に組み込まれたパッケージだけで、`pip` でインストールしたパッケージは使えません。NumPy と Matplotlib は利用可能で、メッセージには[完全な一覧](https://pyodide.org/en/stable/usage/packages-in-pyodide.html)へのリンクがあります。

<Frame caption="利用できないパッケージ">
  <img src="/images/on-premises/python-runner-missing-package.png" alt="出力ペインに表示された ModuleNotFoundError" />
</Frame>
