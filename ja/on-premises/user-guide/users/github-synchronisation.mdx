プロジェクトを GitHub リポジトリに接続します。変更は双方向に、**Sync** をクリックしたときにのみ反映されます。自動的に同期されるものはありません。

<Info>

**Account settings** やエディターに GitHub のオプションが表示されない場合は、管理者に [GitHub 同期](/ja/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation) を有効にするよう依頼してください。

</Info>

## GitHub アカウントをリンクする {#link-your-github-account}

これは一度だけ行います。

<Steps>
<Step title="アカウント設定を開く">
**Account**、続いて **Account settings** をクリックします。**GitHub** までスクロールし、**Link** をクリックします。

<Frame caption="アカウント設定の GitHub">
  <img src="/images/on-premises/github-sync-link.png" alt="Link ボタンがあるアカウント設定の GitHub セクション" />
</Frame>
</Step>

<Step title="GitHub で承認する">
GitHub が開きます。求められたらサインインし、アプリケーションを承認します。
</Step>

<Step title="リンクを確認する">
アカウント設定に戻り、ボタンが **Unlink** に変わっています。

<Frame caption="GitHub アカウントがリンクされた状態">
  <img src="/images/on-premises/github-sync-linked.png" alt="Unlink ボタンがあるアカウント設定の GitHub セクション" />
</Frame>
</Step>
</Steps>

アカウントがまだリンクされていない場合、**Import from GitHub** とエディターの **GitHub** カードは、まずリンクするよう求めます。**Link to your GitHub account** をクリックします。この場合もアカウント設定に移動し、エディターから始めた場合は新しいタブで開きます。その後、元の画面に戻ってやり直してください。

<Frame caption="アカウントがリンクされていないときの案内">
  <img src="/images/on-premises/github-sync-link-prompt.png" alt="Link to your GitHub account ボタンがある Import from GitHub ダイアログ" />
</Frame>

## リポジトリをインポートする {#import-a-repository}

GitHub リポジトリから、そのリポジトリにリンク済みの新しいプロジェクトを作成します。

<Steps>
<Step title="インポートダイアログを開く">
プロジェクトページで **New project**、続いて **Import from GitHub** をクリックします。

<Frame caption="New project メニュー">
  <img src="/images/on-premises/github-sync-new-project-menu.png" alt="Import from GitHub がある New project メニュー" />
</Frame>

<Info>

**New project** は、プロジェクトを 1 つ以上持つと表示されます。ウェルカムページの **Create a new project** メニューにはインポートがないため、先に空のプロジェクトを作成してください。

</Info>
</Step>

<Step title="リポジトリを選ぶ">
リポジトリの横にある **Import to Overleaf** をクリックします。一覧には、自分のリポジトリと所属する Organization のリポジトリが含まれます。

<Frame caption="GitHub リポジトリ">
  <img src="/images/on-premises/github-sync-import.png" alt="4 つのリポジトリが一覧表示された Import from GitHub ダイアログ" />
</Frame>

Organization のリポジトリが見つからない場合は、<strong>Can't see what you're looking for?</strong> をクリックして、その Organization でアプリケーションを承認する方法についての GitHub のヘルプを確認してください。
</Step>

<Step title="プロジェクトを確認する">
新しいプロジェクトが、リポジトリのファイルとともに開きます。

<Frame caption="インポートされたプロジェクト">
  <img src="/images/on-premises/github-sync-imported.png" alt="インポートされたプロジェクトのファイルとコンパイル済み PDF を表示したエディター" />
</Frame>
</Step>
</Steps>

## プロジェクトを新しいリポジトリにエクスポートする {#export-a-project-to-a-new-repository}

自分が所有するプロジェクトからリポジトリを作成し、両者をリンクします。プロジェクトをリンクできるのは、この方法かインポートだけです。既存のリポジトリにはリンクできません。

<Steps>
<Step title="エディターで GitHub を開く">
プロジェクトを開きます。左側のバーで **Integrations**、続いて **GitHub** をクリックします。

<Frame caption="Integrations パネル">
  <img src="/images/on-premises/github-sync-integrations.png" alt="GitHub カードがある Integrations パネル" />
</Frame>
</Step>

<Step title="リポジトリ情報を入力する">
**Owner** を選びます。自分自身か、所属する Organization のいずれかです。**Repository Name** の初期値はプロジェクト名です。説明は任意で、**Private** が既定で選択されています。**Create a GitHub repository** をクリックします。

<Frame caption="Export Project to GitHub">
  <img src="/images/on-premises/github-sync-export.png" alt="入力済みの Export Project to GitHub フォーム" />
</Frame>
</Step>

<Step title="リンクを確認する">
ダイアログに **This project is linked to** とリポジトリ名が表示されます。

<Frame caption="プロジェクトがリンクされた状態">
  <img src="/images/on-premises/github-sync-exported.png" alt="エクスポート後の Sync with GitHub ダイアログ" />
</Frame>
</Step>
</Steps>

## 同期する {#sync}

<Steps>
<Step title="同期ダイアログを開く">
リンク済みのプロジェクトを開きます。左側のバーで **Integrations**、続いて **GitHub** をクリックします。

**Recent commits in GitHub** に、プロジェクトに取り込まれる内容が一覧表示されます。

<Frame caption="GitHub で待機中の新しいコミット">
  <img src="/images/on-premises/github-sync-new-commits.png" alt="新しいコミットが 1 つ表示された Sync with GitHub ダイアログ" />
</Frame>
</Step>

<Step title="変更内容を記述する">
プロジェクトで何かを変更した場合、コミットメッセージの入力欄が表示されます。入力は任意で、空欄のままにするとコミット名は `Updates from Overleaf` になります。

<Frame caption="変更のコミットメッセージ">
  <img src="/images/on-premises/github-sync-commit-message.png" alt="コミットメッセージが入力された Sync with GitHub ダイアログ" />
</Frame>
</Step>

<Step title="Sync をクリックする">
**Sync** をクリックします。GitHub の新しいコミットがプロジェクトに取り込まれ、あなたの変更はリポジトリの既定ブランチに送られます。両側で異なる部分が変更されていれば、自動的にマージされます。
</Step>

<Step title="結果を確認する">
ダイアログに <strong>No new commits in GitHub since last merge.</strong> と表示され、コミットメッセージの入力欄が消えます。エディターのファイルと GitHub のコミットは最新の状態です。

<Frame caption="すべて同期済み">
  <img src="/images/on-premises/github-sync-done.png" alt="同期後、新しいコミットがない Sync with GitHub ダイアログ" />
</Frame>
</Step>
</Steps>

### 両側で同じ行が変更された場合 {#if-the-same-lines-changed-on-both-sides}

ダイアログに、変更をマージできなかったことと、あなたの変更を保持する新しいブランチ `overleaf-YYYY-MM-DD-HHMMSS` の名前が表示されます。

<Frame caption="コンフリクト">
  <img src="/images/on-premises/github-sync-conflict.png" alt="マージコンフリクトの警告が表示された Sync with GitHub ダイアログ" />
</Frame>

1. GitHub 上または Git で、そのブランチを既定ブランチにマージします。その間ダイアログを閉じてもかまいません。もう一度開くと同じメッセージが表示されます。
2. **I have manually merged. Continue** をクリックします。マージされた結果がプロジェクトに取り込まれます。
3. ブランチは GitHub に残ります。不要になったら削除してください。

## プロジェクトのリンクを解除する {#unlink-a-project}

プロジェクトの同期をやめたいときに行います。これを行えるのはプロジェクトの所有者だけです。

<Steps>
<Step title="Unlink をクリックする">
同期ダイアログで **Unlink** をクリックします。
</Step>

<Step title="確認する">
**Confirm** をクリックします。サブスクリプションに関する注記があっても、プロジェクトを再度リンクすることはできます。

<Frame caption="リンク解除の確認">
  <img src="/images/on-premises/github-sync-unlink-project.png" alt="リンク解除の確認を求める Sync with GitHub ダイアログ" />
</Frame>
</Step>

<Step title="結果を確認する">
ダイアログに **Export Project to GitHub** が表示されます。プロジェクトとリポジトリはどちらも内容を保持します。再び同期するには、プロジェクトを新しいリポジトリにエクスポートするか、リポジトリを新しいプロジェクトにインポートします。
</Step>
</Steps>

## GitHub アカウントのリンクを解除する {#unlink-your-github-account}

**Account settings** の **GitHub** で **Unlink** をクリックし、ダイアログでもう一度 **Unlink** をクリックします。

<Frame caption="アカウントのリンクを解除する">
  <img src="/images/on-premises/github-sync-unlink-account.png" alt="Unlink GitHub Account ダイアログ" />
</Frame>

プロジェクトはそれぞれのリポジトリにリンクされたままです。アカウントを再度リンクするまで、同期はできません。

<Info>

共有プロジェクトで誰が何をできるかについては、[リンクと同期ができるユーザー](/ja/on-premises/configuration/overleaf-toolkit/integrations/github-synchronisation#who-can-link-and-sync) を参照してください。同期する共同編集者は、それぞれ自分の GitHub アカウントをリンクします。

</Info>
