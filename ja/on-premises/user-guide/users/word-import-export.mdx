## ドキュメントをインポートする {#import-a-document}

Word ドキュメント（`.docx`）または Markdown ファイル（`.md`）から新しい LaTeX プロジェクトを作成します。プロジェクト名はファイル名から付けられます。

<Steps>
<Step title="インポートダイアログを開く">
プロジェクトページで **New project** をクリックします。**Import** の下で **Word document** または **Markdown document** をクリックします。

<Frame caption="New project メニュー">
  <img src="/images/on-premises/word-import-menu.png" alt="Import の下に Word document と Markdown document がある New project メニュー" />
</Frame>
</Step>

<Step title="ファイルを選ぶ">
**Select .docx file** をクリックするか、ファイルをダイアログにドラッグします。Markdown の場合、ボタンは **Select .md file** です。インポートはすぐに始まります。

<Frame caption="Word ドキュメントの選択">
  <img src="/images/on-premises/word-import-dialog.png" alt="Select .docx file ボタンのある Choose Word document ダイアログ" />
</Frame>
</Step>

<Step title="編集を始める">
新しいプロジェクトが開き、**Document ready for editing** というメッセージが表示されます。**Start editing** をクリックします。

<Frame caption="インポートの完了">
  <img src="/images/on-premises/word-import-ready.png" alt="Start editing ボタンのある Document ready for editing ダイアログ" />
</Frame>
</Step>

<Step title="結果を確認する">
ドキュメントは `main.tex` に入り、見出しはファイルアウトラインに表示されます。**Recompile** をクリックして PDF を確認します。スタイル、特に表、図、引用は編集が必要な場合があるので確認してください。

<Frame caption="インポートされたプロジェクト">
  <img src="/images/on-premises/word-import-project.png" alt="main.tex、ファイルアウトライン、コンパイルされた PDF を含む、エディター内のインポートされたプロジェクト" />
</Frame>
</Step>
</Steps>

### インポートに失敗した場合 {#if-the-import-fails}

ファイルを変換できない場合、ダイアログに **Your document couldn't be imported** と表示されます。**Conversion error details** を展開すると理由がわかります。プロジェクトは作成されません。

<Frame caption="インポートできなかったドキュメント">
  <img src="/images/on-premises/word-import-error.png" alt="エラーメッセージと Conversion error details が表示されたインポートダイアログ" />
</Frame>

ダイアログは選んだ種類のファイルしか受け付けません。Word のダイアログで `.md` ファイルを選ぶと **You can only upload: .docx** と表示されます。

## プロジェクトをエクスポートする {#export-a-project}

プロジェクトを開き、エディター上部のプロジェクト名をクリックします。次のいずれかをクリックします:

| オプション                              | 得られるもの                                       |
| ----------------------------------- | --------------------------------------------- |
| <strong>Export as Word document (.docx)</strong> | プロジェクト名の `.docx` ファイル        |
| <strong>Export as Markdown (.md)</strong>        | `main.md` を含む `.zip` ファイル                  |
| <strong>Export as HTML (.html)</strong>          | `main.html` を含む `.zip` ファイル                |

ダウンロードは自動的に始まります。変換ではすべての LaTeX の書式を再現できないため、結果を確認してください。

</Frame>
