---
title: Gitea 同期
description: Gitea アカウントをリンクし、プロジェクトをインポートまたはエクスポートし、変更を双方向に同期し、リンクを解除します。
icon: mug-hot
---

プロジェクトを Gitea リポジトリに接続します。変更は双方向に、**Sync** をクリックしたときにのみ反映されます。自動的に同期されるものはありません。

<Info>

まず管理者が [Gitea 同期](/ja/on-premises/configuration/overleaf-toolkit/integrations/gitea-synchronisation) を有効にする必要があります。

</Info>

## Gitea アカウントをリンクする {#link-your-gitea-account}

これは一度だけ行います。

<Steps>
<Step title="アカウント設定を開く">
**Account**、続いて **Account settings** をクリックします。**Project synchronisation** の下で **Gitea** を探し、**Link** をクリックします。

<Frame caption="アカウント設定の Gitea">
  <img src="/images/on-premises/gitea-sync-link.png" alt="Link ボタンがあるアカウント設定の Gitea セクション" />
</Frame>
</Step>

<Step title="Gitea で承認する">
Gitea が開きます。求められたらサインインし、アプリケーションを承認します。
</Step>

<Step title="リンクを確認する">
アカウント設定に戻ります。Gitea アカウントがリンクされたことを示す緑色のメッセージが表示され、ボタンが **Unlink** に変わっています。

<Frame caption="Gitea アカウントがリンクされた状態">
  <img src="/images/on-premises/gitea-sync-linked.png" alt="Unlink ボタンがあるアカウント設定の Gitea セクション" />
</Frame>
</Step>
</Steps>

アカウントがまだリンクされていない場合、**Import from Gitea** とエディターの **Gitea** カードは、まずリンクするよう求めます。**Link to your Gitea account** をクリックします。この場合もアカウント設定に移動し、エディターから始めた場合は新しいタブで開きます。その後、元の画面に戻ってやり直してください。

<Frame caption="アカウントがリンクされていないときの案内">
  <img src="/images/on-premises/gitea-sync-link-prompt.png" alt="Link to your Gitea account ボタンがある Import from Gitea ダイアログ" />
</Frame>

## リポジトリをインポートする {#import-a-repository}

Gitea リポジトリから、そのリポジトリにリンク済みの新しいプロジェクトを作成します。

<Steps>
<Step title="インポートダイアログを開く">
プロジェクトページで **New project**、続いて **Import from Gitea** をクリックします。

<Frame caption="New project メニュー">
  <img src="/images/on-premises/gitea-sync-new-project-menu.png" alt="Import from Gitea がある New project メニュー" />
</Frame>
</Step>

<Step title="リポジトリを選ぶ">
リポジトリの横にある **Import to Overleaf** をクリックします。一覧には、自分のリポジトリと所属する Organization のリポジトリが含まれます。空のリポジトリは表示されません。少なくとも 1 つのコミットが必要です。

<Frame caption="Gitea リポジトリ">
  <img src="/images/on-premises/gitea-sync-import.png" alt="4 つのリポジトリが一覧表示された Import from Gitea ダイアログ" />
</Frame>
</Step>

<Step title="プロジェクトを確認する">
新しいプロジェクトが、リポジトリのファイルとともに開きます。

<Frame caption="インポートされたプロジェクト">
  <img src="/images/on-premises/gitea-sync-imported.png" alt="インポートされたプロジェクトのファイルとコンパイル済み PDF を表示したエディター" />
</Frame>
</Step>
</Steps>

## プロジェクトを新しいリポジトリにエクスポートする {#export-a-project-to-a-new-repository}

プロジェクトからリポジトリを作成し、両者をリンクします。プロジェクトをリンクできるのは、この方法かインポートだけです。既存のリポジトリにはリンクできません。

<Steps>
<Step title="エディターで Gitea を開く">
プロジェクトを開きます。左側のバーで **Integrations**、続いて **Gitea** をクリックします。

<Frame caption="Integrations パネル">
  <img src="/images/on-premises/gitea-sync-integrations.png" alt="Gitea カードがある Integrations パネル" />
</Frame>
</Step>

<Step title="リポジトリ情報を入力する">
**Owner** を選びます。自分自身か、所属する Organization のいずれかです。Organization を選ぶと、この欄の名前は **Organization** になります。**Repository Name** の初期値はプロジェクト名です。Gitea は空白を受け付けないため、名前に空白が含まれている場合は変更してください。説明は任意で、**Private** が既定で選択されています。**Create a Gitea repository** をクリックします。

<Frame caption="Export Project to Gitea">
  <img src="/images/on-premises/gitea-sync-export.png" alt="入力済みの Export Project to Gitea フォーム" />
</Frame>

名前に空白が含まれているか、すでに使われている場合、ダイアログに <strong>Please check that the repository name is valid, and that you have permission to create the repository.</strong> と表示されます。名前を変更して、もう一度ボタンをクリックしてください。
</Step>

<Step title="リンクを確認する">
ダイアログに **This project is linked to** とリポジトリ名が表示されます。

<Frame caption="プロジェクトがリンクされた状態">
  <img src="/images/on-premises/gitea-sync-exported.png" alt="エクスポート後の Sync with Gitea ダイアログ" />
</Frame>
</Step>
</Steps>

## 同期する {#sync}

<Steps>
<Step title="同期ダイアログを開く">
リンク済みのプロジェクトを開きます。左側のバーで **Integrations**、続いて **Gitea** をクリックします。

**Recent commits in Gitea** に、プロジェクトに取り込まれる内容が一覧表示されます。

<Frame caption="Gitea で待機中の新しいコミット">
  <img src="/images/on-premises/gitea-sync-new-commits.png" alt="新しいコミットが 1 つ表示された Sync with Gitea ダイアログ" />
</Frame>
</Step>

<Step title="変更内容を記述する">
プロジェクトで何かを変更した場合、コミットメッセージの入力欄が表示されます。入力は任意で、空欄のままにするとコミット名は `Updates from Overleaf` になります。

<Frame caption="変更のコミットメッセージ">
  <img src="/images/on-premises/gitea-sync-commit-message.png" alt="コミットメッセージが入力された Sync with Gitea ダイアログ" />
</Frame>
</Step>

<Step title="Sync をクリックする">
**Sync** をクリックします。Gitea の新しいコミットがプロジェクトに取り込まれ、あなたの変更はリポジトリの既定ブランチに送られます。両側で異なる部分が変更されていれば、プルリクエストを通じて自動的にマージされます。このプルリクエストは記録として Gitea に残ります。
</Step>

<Step title="結果を確認する">
ダイアログに <strong>No new commits in Gitea since last merge.</strong> と表示され、コミットメッセージの入力欄が消えます。エディターのファイルと Gitea のコミットは最新の状態です。

<Frame caption="すべて同期済み">
  <img src="/images/on-premises/gitea-sync-done.png" alt="同期後、新しいコミットがない Sync with Gitea ダイアログ" />
</Frame>
</Step>
</Steps>

### 両側で同じ行が変更された場合 {#if-the-same-lines-changed-on-both-sides}

ダイアログに、変更をマージできなかったことと、あなたの変更を保持する新しいブランチ `overleaf-YYYY-MM-DD-HHMMSS` の名前が表示されます。Overleaf は、そのブランチから Gitea 上にプルリクエストも作成します。

<Frame caption="コンフリクト">
  <img src="/images/on-premises/gitea-sync-conflict.png" alt="マージコンフリクトの警告が表示された Sync with Gitea ダイアログ" />
</Frame>

1.  Git でそのブランチを既定ブランチにマージし、コンフリクトを解消します。その間ダイアログを閉じてもかまいません。もう一度開くと同じメッセージが表示されます。

    ```bash
    git clone <repository-address>
    cd <repository-name>
    git merge origin/overleaf-YYYY-MM-DD-HHMMSS
    # fix the conflict in the file Git names
    git add <file>
    git commit
    git push
    ```
2. **I have manually merged. Continue** をクリックします。マージされた結果がプロジェクトに取り込まれます。ブランチをマージする前にクリックした場合、ダイアログはそのままです。
3. ブランチは Gitea に残り、そのプルリクエストも開いたままです。不要になったら、プルリクエストを閉じてブランチを削除してください。

コンフリクトする行がなくても、ブランチ保護ルールがプルリクエストを保留した場合（承認が必要な場合など）、同じダイアログが表示されます。ルールが許可したら、Gitea でプルリクエストをマージし、**I have manually merged. Continue** をクリックします。[Gitea との同期の仕組み](/ja/on-premises/configuration/overleaf-toolkit/integrations/gitea-synchronisation#how-syncing-works-with-gitea) を参照してください。

## プロジェクトのリンクを解除する {#unlink-a-project}

プロジェクトの同期をやめたいときに行います。

<Steps>
<Step title="Unlink をクリックする">
同期ダイアログで **Unlink** をクリックします。
</Step>

<Step title="確認する">
**Confirm** をクリックします。これはリンクを解除するだけです。警告に記載されている、自分が所有するリポジトリへの接続は、解除後に選べるオプションであり、今すぐ行われるものではありません。

<Frame caption="リンク解除の確認">
  <img src="/images/on-premises/gitea-sync-unlink-project.png" alt="リンク解除の確認を求める Sync with Gitea ダイアログ" />
</Frame>
</Step>

<Step title="結果を確認する">
ダイアログに **Export Project to Gitea** が表示されます。プロジェクトとリポジトリはどちらも内容を保持します。再び同期するには、プロジェクトを新しいリポジトリにエクスポートするか、リポジトリを新しいプロジェクトにインポートします。
</Step>
</Steps>

## Gitea アカウントのリンクを解除する {#unlink-your-gitea-account}

**Account settings** の **Gitea** で **Unlink** をクリックし、ダイアログでもう一度 **Unlink** をクリックします。

<Frame caption="アカウントのリンクを解除する">
  <img src="/images/on-premises/gitea-sync-unlink-account.png" alt="Unlink Gitea Account ダイアログ" />
</Frame>

プロジェクトはそれぞれのリポジトリにリンクされたままです。アカウントを再度リンクするまで、同期はできません。

<Info>

共有プロジェクトで誰が何をできるかについては、[リンクと同期ができるユーザー](/ja/on-premises/configuration/overleaf-toolkit/integrations/gitea-synchronisation#who-can-link-and-sync) を参照してください。

</Info>
