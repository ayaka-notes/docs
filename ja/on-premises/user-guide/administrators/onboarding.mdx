---
title: 初期設定
description: 最初の管理者を作成し、インスタンスを確認して、最初のユーザーを追加します。
icon: user-plus
---

[インストール](/ja/on-premises/installation/introduction)の直後に一度だけ実行してください。このページではデフォルトのパスワードログインを使用します。

<Steps>
<Step id="open-the-launchpad" title="launchpad を開く">
インスタンスで `/launchpad` を開きます（例: `http://localhost/launchpad`）。**Create the first Admin account** が表示されます。

このフォームは最初の管理者が作成されるまでしか表示されません。その後、ログインしていない訪問者はログインページに送られます。
</Step>

<Step id="create-the-administrator-account" title="管理者アカウントを作成する">
メールアドレスとパスワードを入力し、**Register** をクリックします。

<Frame caption="最初の管理者アカウント">
  <img src="/images/on-premises/onboarding-launchpad-filled.png" alt="admin@example.com が入力された launchpad フォーム" />
</Frame>

パスワードが拒否されると、フォームの上にメッセージが表示され、アカウントは作成されません。

<Frame caption="拒否されたパスワード">
  <img src="/images/on-premises/onboarding-password-error.png" alt="launchpad フォームの上に表示されたメッセージ password is too short" />
</Frame>

| メッセージ                                 | 意味                                                                                                                                                       |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `password is too short`                    | 8 文字未満です。                                                                                                                                           |
| `password is too long`                     | 72 文字を超えています。                                                                                                                                    |
| `password contains an invalid character`   | 使用できるのは英字 `a-z` と `A-Z`、数字、および `@#$%^&*()-_=+[]{};:<>/?!£€.,` です。スペース、アクセント付き文字、ラテン文字以外の文字は使用できません。 |
| `password contains part of email address`  | メールアドレスまたは `@` より前の部分を含んでいるか、メールアドレスの一部になっています。`admin@example.com` の場合、`admin-7Tq9-demo` も `example.com` も拒否されます。 |
| `password is too similar to email address` | メールアドレスに似すぎています（例: `adm1n@example.c0m`）。                                                                                               |

デフォルトでは、大文字、数字、記号は必須ではありません。長さの制限を変更するには、[パスワードの制限](/ja/on-premises/configuration/overleaf-toolkit/authentication/password-restrictions)を参照してください。
</Step>

<Step id="log-in" title="ログインする">
**Register** の後はログインページが表示されます。同じメールアドレスとパスワードを入力し、**Login** をクリックします。

<Frame caption="新しいアカウントでログインする">
  <img src="/images/on-premises/onboarding-login.png" alt="admin@example.com が入力されたログインページ" />
</Frame>

launchpad に戻り、今度は **Status Checks** が表示されます。
</Step>

<Step id="check-the-instance" title="インスタンスを確認する">
`websockets` に **OK** と表示されているはずです。

メールをテストするには、**Send a test email** にアドレスを入力して **Send** をクリックし、受信トレイを確認します。

<Frame caption="ステータスチェックとテストメール">
  <img src="/images/on-premises/onboarding-launchpad-checks.png" alt="websockets が OK、テストメールフォームに Email Sent が表示され、下部に 2 つのボタンがある launchpad" />
</Frame>

<Warning>

**Email Sent** は、メッセージがサーバーから送信されたことを証明するものではありません。[メール配信](/ja/on-premises/configuration/overleaf-toolkit/email-delivery)が設定されていない場合も同じテキストが表示され、メールは届きません。

</Warning>

**Start Using** _サイト名_ をクリックするとプロジェクトが開きます。**Go To Admin Panel** をクリックするとサイトツールが開きます。[基本管理](/on-premises/user-guide/administrators/basic-management)を参照してください。
</Step>

<Step id="create-the-first-user" title="最初のユーザーを作成する">
上部メニューで **Admin** をクリックし、**Manage Users** をクリックします。

<Frame caption="Admin メニュー">
  <img src="/images/on-premises/onboarding-admin-menu.png" alt="Manage Site、Manage Users、Project/Object Lookup がある Admin メニュー" />
</Frame>

**Create account** をクリックします。

<Frame caption="ユーザー一覧">
  <img src="/images/on-premises/onboarding-user-list.png" alt="管理者と Create account ボタンがあるユーザー一覧" />
</Frame>

ユーザーのメールアドレスを入力します。**First name** と **Last name** は任意です。**Admin** は別の管理者を作成する場合にのみチェックします。**Create** をクリックします。

<Frame caption="Create account ダイアログ">
  <img src="/images/on-premises/onboarding-create-account.png" alt="user@example.com が入力された Create account ダイアログ" />
</Frame>

ダイアログに新しいアカウントと有効化リンクが表示されます。リンクの有効期限は 7 日です。

* **Email Sent** は、有効化メールが送信されたことを意味します。
* <strong>No email was sent. Copy the link and pass it on.</strong> は、メールが送信されなかったことを意味します。たとえば[メール配信](/ja/on-premises/configuration/overleaf-toolkit/email-delivery)が設定されていない場合です。

<Frame caption="新しいアカウントとその有効化リンク">
  <img src="/images/on-premises/onboarding-account-created.png" alt="メールが送信されなかったという警告、リンク、コピーアイコン、Expires in 7 days が表示された Demo User の Create account ダイアログ" />
</Frame>

**Close** をクリックします。アカウントは **Pending** ステータスで一覧に表示されます。

<Frame caption="新しいアカウントは初回ログインまで Pending のまま">
  <img src="/images/on-premises/onboarding-user-pending.png" alt="Demo User が Pending ステータスのユーザー一覧" />
</Frame>
</Step>

<Step id="give-the-user-access" title="ユーザーにアクセス権を渡す">
**メール配信が設定されている場合**、ユーザーには **Set password** リンク付きの有効化メールが届きます。リンクを開くと次のページが表示されます。ユーザーはパスワードを入力して **Activate** をクリックし、プロジェクトページに移動します。上記のパスワードルールが適用されます。

<Frame caption="リンクを開いたときにユーザーに表示される画面">
  <img src="/images/on-premises/onboarding-activate.png" alt="ユーザーにパスワードの設定を求める有効化ページ" />
</Frame>

**メール配信が設定されていない場合**は、リンクを自分で渡します。**Create** の後のダイアログでコピーアイコンをクリックし、リンクをユーザーに送ります。ユーザーは上記と同じ方法でパスワードを設定します。

ダイアログを閉じてしまった場合やリンクの有効期限が切れた場合は、**Manage Users** でユーザーの行にある封筒アイコンをクリックし、**Send activation email** をクリックします。ダイアログに新しいリンクが表示されます。有効期限は 7 日です。

<Frame caption="新しい有効化リンク">
  <img src="/images/on-premises/onboarding-activation-link.png" alt="メールが送信されなかったという警告、リンク、コピーアイコン、Expires in 7 days が表示された Demo User の Send activation email ダイアログ" />
</Frame>

パスワードを自分で設定することもできます。**Manage Users** でユーザー名をクリックし、鉛筆アイコンをクリックします。**New password** を入力して **Save** をクリックします。パスワードをユーザーに伝えると、ユーザーは `/login` でログインできます。

<Frame caption="Account タブでパスワードを設定する">
  <img src="/images/on-premises/onboarding-set-password.png" alt="New password フィールドが入力された、編集モードのユーザーの Account タブ" />
</Frame>
</Step>

<Step id="confirm-it-worked" title="正しく完了したか確認する">
ユーザーが初めてログインすると、**Manage Users** のステータスが **Active** に変わります。

<Frame caption="ユーザーがログインした">
  <img src="/images/on-premises/onboarding-user-active.png" alt="Demo User が Active ステータスのユーザー一覧" />
</Frame>
</Step>
</Steps>

<Info>

デフォルトでは、**Sign up** でアカウントは作成されません。このページでは、訪問者に `OVERLEAF_ADMIN_EMAIL` のアドレスへ連絡するよう案内します。ユーザー自身が登録できるようにするには、[パブリックアクセス](/ja/on-premises/configuration/overleaf-toolkit/authentication/public-access)を参照してください。

</Info>
