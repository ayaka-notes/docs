自分のアカウントには **You** と表示され、その操作はグレー表示になります。自分自身を無効化したり削除したりすることはできません。

## ユーザーを検索する {#find-a-user}

**Search by name, email or ID** に入力します。`Carol Novak` のようなフルネームも使え、ユーザーの [セカンダリメールアドレス](/ja/on-premises/user-guide/users/multiple-emails) のいずれでも検索できます。一覧を絞り込むには、**Login**、**Role**、**Status** 列のフィルターを使います。並べ替えるには **Name**、**Sign up**、**Last logged in** をクリックします。

<Frame caption="ユーザーの検索">
  <img src="/images/on-premises/user-management-search.png" alt="検索語 carol で絞り込んだユーザー一覧" />
</Frame>

削除されたアカウントは結果に表示されません。検索が削除済みアカウントにも一致した場合は、表の上に **Found 1 matching deleted users** のような行が表示されます。**Display deleted users** をクリックすると表示されます。

</Frame>

## ユーザーのステータス {#user-status}

すべてのアカウントはステータスを 1 つだけ持ち、**Status** フィルターには各ステータスのアカウント数が表示されます。疑問符にカーソルを合わせると定義を確認できます。

<Frame caption="Status フィルター">
  <img src="/images/on-premises/user-management-status-tooltip.png" alt="Active のツールチップが表示された Status フィルター" />
</Frame>

| ステータス | 意味 | ログイン可否 |
| --- | --- | --- |
| **All** | 削除されていないすべてのアカウント。下の 4 つのステータス（Active + Pending + Inactive + Disabled）の合計がこの数になります。 | |
| **Active** | 過去 12 か月以内にログインしたか、プロジェクトを開いた。 | 可 |
| **Pending** | 一度もログインしていない。通常は、管理者が作成したアカウント、またはアクティベーションメールで登録され、ユーザーがまだアクティベートしていないアカウントです。パスワードで登録したアカウントはアクティベーション不要で、初回ログイン時に Active になります。 | 可 |
| **Inactive** | 以前ログインしたことはあるが、過去 12 か月間ログインもプロジェクトを開くこともしていない。 | 可 |
| **Disabled** | 管理者がアカウントを無効化した。ログインすると **Your account is suspended** ページが表示されます。 | 不可 |
| **Deleted user** | 管理者またはユーザー本人がアカウントを削除した。**All** には含まれず、このフィルターを選ぶまで非表示です。ログインすると、メールアドレスまたはパスワードが正しくないと表示されます。 | 不可 |

アカウントのステータスは次のように変わります。

* **Pending、Active、Inactive** はアカウントの利用状況に従うため、設定することはできません。Inactive のアカウントは、ユーザーがログインするとすぐに Active になります。
* **Enable** と **Restore** は以前のステータスを戻すわけではありません。ステータスは最後のログインで決まります。一度もログインしていないアカウントは再び Pending になります。無効化されたアカウントは **Restore** の後も **Disabled** のままです。
* **Delete permanently** は元に戻せません。それ以外の場合、削除されたアカウントは自分で削除するまで残ります。ただし、インスタンスで [`ENABLE_CRON_RESOURCE_DELETION`](/ja/on-premises/configuration/overleaf-toolkit/environment-variables) を設定している場合は 90 日後に削除されます。

### License タブのアクティブユーザー {#active-users-on-the-license-tab}

**License** タブと **Active** ステータスは数える対象が異なるため、異なる数を示すことがあります。**License** タブは、Overleaf が [Understanding license usage](https://docs.overleaf.com/on-premises/user-and-project-management/understanding-license-usage) で定義するとおり、Server Pro ライセンスの対象となるユーザーを数えます。"any user who logs in and accesses a project is considered an active user by the system"、"An active user is defined as someone who has opened a project on your Server Pro instance in the last 12 months." ログインしたがプロジェクトを開いていないユーザーは一覧では **Active** ですが、ライセンスには数えられません。プロジェクトを開いた後に無効化されたユーザーはライセンスに数えられますが、一覧では **Disabled** です。

## ユーザーに対する操作 {#actions-on-a-user}

**Actions** 列のアイコンは、ユーザーのページ上部にあるアイコンと同じです。

| アイコン | 操作 | 内容 |
| --- | --- | --- |
| 封筒 | **Send activation email** | 一度もログインしていないアカウント向け: 新しいアクティベーションリンク。 |
| 矢印付きの鍵 | **Send reset link** | ログインしたことのあるアカウント向け: 新しいパスワードリセットリンク。 |
| フォルダー | **Transfer this user's projects** | ユーザーが所有するすべてのプロジェクトを別のユーザーに渡します。 |
| 丸 | **Disable** | ユーザーのログインを止めます。 |
| 再生 | **Enable** | 無効化されたユーザーが再びログインできるようにします。 |
| ゴミ箱 | **Delete account** | アカウントを **Deleted user** に移します。 |
| 矢印 | **Restore** | 削除されたアカウントを戻します。削除済みアカウントのみ。 |
| 斜線付きのゴミ箱 | **Delete permanently** | 削除されたアカウントを完全に削除します。削除済みアカウントのみ。 |

どの操作も、アカウント名を示すダイアログで確認を求めます。

### アクティベーションリンクまたはリセットリンクを送信する {#send-an-activation-or-reset-link}

アカウントには、ログインしたことがあるかどうかに応じて、この 2 つのアイコンのいずれかが表示されます。無効化されたアカウント、SSO アカウントなどローカルパスワードのないアカウント、および自分のアカウントでは、アイコンはグレー表示になります。

アイコンをクリックし、同じ名前のボタンをクリックします。ダイアログは開いたままで、リンクが表示されます。

* **Email Sent** は、メールが送信されたことを意味します。
* <strong>No email was sent. Copy the link and pass it on.</strong> は、[メール配信](/ja/on-premises/configuration/overleaf-toolkit/email-delivery) が設定されていないか、メール送信に失敗したことを意味します。コピーアイコンをクリックし、ユーザーにリンクを自分で送ってください。

アクティベーションリンクは 7 日、リセットリンクは 1 時間で期限切れになります。ユーザーはリンクを開いてパスワードを設定します。アクティベーションリンクの後は自分のプロジェクトに移動し、リセットリンクの後はログインします。

<Frame caption="メール配信のないインスタンスでのリセットリンク">
  <img src="/images/on-premises/user-management-reset-link.png" alt="Carol Novak の Send reset link ダイアログ。メールが送信されなかったという警告、リンク、コピーアイコン、Expires in 1 hour が表示されている" />
</Frame>

### アカウントを無効化または有効化する {#disable-or-enable-an-account}

丸のアイコンをクリックし、**Disable** をクリックします。ステータスが **Disabled** に変わり、ユーザーはログインできなくなります。元に戻すには、再生アイコンをクリックし、**Enable** をクリックします。

<Frame caption="アカウントの無効化">
  <img src="/images/on-premises/user-management-disable.png" alt="Dave Okafor を示す Disable ダイアログ" />
</Frame>

### ユーザーのプロジェクトを移管する {#transfer-a-user’s-projects}

フォルダーアイコンをクリックします。**Select a new owner for this user's projects** に名前またはメールアドレスを入力し、ユーザーを選んで **Transfer this user's projects** をクリックします。それらのプロジェクトの **Owner** は [プロジェクト管理](/on-premises/user-guide/administrators/project-management) で変わります。

無効化されたアカウントは新しい所有者の候補に表示されません。選択した後にテキストを変更すると選択は取り消されるので、もう一度ユーザーを選んでください。

<Frame caption="ユーザーのすべてのプロジェクトの移管">
  <img src="/images/on-premises/user-management-transfer.png" alt="新しい所有者として Carol Novak が選ばれた移管ダイアログ" />
</Frame>

### アカウントを削除する {#delete-an-account}

ゴミ箱アイコンをクリックします。2 つのオプションがあり、デフォルトではどちらも選択されていません。

* **Notify the user about the account deletion** はユーザーにメールを送ります。
* **Transfer this user's projects** では、先にプロジェクトの新しい所有者を選べます。プロジェクトは新しい所有者のもとで有効なままです。

**Delete account** をクリックします。プロジェクトを移管しない場合、プロジェクトはアカウントとともに削除され、[プロジェクト管理](/on-premises/user-guide/administrators/project-management#project-status) の **Deleted** ステータスに移ります。

<Frame caption="アカウントを削除してプロジェクトを移管する">
  <img src="/images/on-premises/user-management-delete.png" alt="両方のオプションにチェックが入り、新しい所有者が選ばれた Delete account ダイアログ" />
</Frame>

### アカウントを復元または完全に削除する {#restore-or-permanently-delete-an-account}

**Status** フィルターで **Deleted user** を選ぶか、検索後に **Display deleted users** をクリックします。

<Frame caption="削除されたアカウント">
  <img src="/images/on-premises/user-management-deleted-list.png" alt="Restore と Delete permanently のアイコンがある削除済みユーザーの一覧" />
</Frame>

* **Restore** はアカウントを戻します。無効化されたアカウントは無効なままです。アカウントとともに削除されたプロジェクトも戻り、それぞれの名前の末尾に `(Restored)` が付きます。ユーザーが自分で削除していたプロジェクトは削除されたままです。
* **Delete permanently** はアカウントを削除します。ダイアログには元に戻せないという警告が表示されます。

<Frame caption="アカウントの完全削除">
  <img src="/images/on-premises/user-management-purge.png" alt="操作は元に戻せないと警告する Delete permanently ダイアログ" />
</Frame>

### 複数のアカウントをまとめて変更する {#change-several-accounts-at-once}

一覧でアカウントにチェックを入れます。**Create account** の横にボタンが表示されます: **Send activation email**、**Transfer this user's projects**、**Disable**、**Enable**、**Make admin**、**Remove admin**、**Delete account**。一覧の下部には選択中のアカウント数が表示されます。確認の前に、ダイアログに対象のアカウントが一覧表示されます。

<Frame caption="一括操作">
  <img src="/images/on-premises/user-management-bulk.png" alt="2 つのアカウントにチェックが入り、一覧の上に一括操作ボタンが表示され、封筒がグレー表示になっている" />
</Frame>

チェックを入れたアカウントがすべて **Pending** でない限り、**Send activation email** はグレー表示です。その場合、ダイアログにはアカウントごとに 1 つのリンクが表示されます。一括のリセットリンクはありません。

<Frame caption="アカウントごとに 1 つのアクティベーションリンク">
  <img src="/images/on-premises/user-management-bulk-links.png" alt="Hana Ito と Erin Silva のリンクと Expires in 7 days が表示された Send activation email ダイアログ" />
</Frame>

## ユーザーページ {#the-user-page}

ユーザーの名前をクリックすると、そのユーザーのページが開きます。ページには 6 つのタブがあります。

### Account {#account}

アカウントの詳細です。変更するには、鉛筆アイコンをクリックしてフィールドを編集し、**Save** をクリックします。メールアドレス、名前、パスワードを変更でき、**Admin** をオンまたはオフにできます。

ユーザーが [メールアドレスを追加](/ja/on-premises/user-guide/users/multiple-emails) している場合は、**Emails** の下に一覧表示されます。編集中に **Remove** を押すとセカンダリメールアドレスがアカウントから外れ、別のアカウントがそのアドレスを使えるようになります。

<Frame caption="メールアドレスが 2 つあるアカウント">
  <img src="/images/on-premises/user-management-secondary-email.png" alt="編集中の Account タブ。プライマリメールアドレスと、Remove ボタン付きのセカンダリメールアドレスがある" />
</Frame>

初期設定の [パスワードのルール](/on-premises/user-guide/administrators/onboarding#create-the-administrator-account) が適用されます。パスワードをユーザーに伝えるのはあなたの役目です。ユーザー自身に選ばせるには、代わりに [リセットリンクを送信](/ja/on-premises/user-guide/administrators/user-management#send-an-activation-or-reset-link) してください。

<Frame caption="アカウントの編集">
  <img src="/images/on-premises/user-management-edit.png" alt="編集モードの Account タブ" />
</Frame>

### Projects {#projects}

このユーザーが所有するプロジェクトです。[プロジェクト管理](/on-premises/user-guide/administrators/project-management) と同じ検索、**Status** フィルター、操作が使えます。

<Frame caption="ユーザーのプロジェクト">
  <img src="/images/on-premises/user-management-projects.png" alt="ユーザーの Projects タブ" />
</Frame>

### Features {#features}

このアカウントで有効になっている機能です: 共同編集、コンパイルのタイムアウト、連携、AI。変更するには、鉛筆アイコンをクリックし、値を変えて **Save** をクリックします。**Collaborators per project** の `-1` は無制限を意味します。**Compile timeout** は秒単位で、1 から 600 です。

自分のアカウントでは、鉛筆と **AI usage** の **Reset** はグレー表示になります。**Account** タブでは、自分のメールアドレス、名前、パスワードを変更できます。

<Frame caption="ユーザーの機能">
  <img src="/images/on-premises/user-management-features.png" alt="編集モードの Features タブ" />
</Frame>

### Integrations {#integrations}

ユーザーの Git アクセストークンと、連携したアカウントです。このタブは読み取り専用です。

<Frame caption="ユーザーの連携">
  <img src="/images/on-premises/user-management-integrations.png" alt="GitHub、GitLab、Gitea が連携済みとしてチェックされた Integrations タブ" />
</Frame>

### Audit logs {#audit-logs}

このアカウントで起きたこと: 日付、操作、実行者、IP アドレス、詳細です。検索したり、**Operation** で絞り込んだりできます。あなたがアカウントに対して行った操作は、あなたを実行者としてここに表示されます。

<Frame caption="ユーザーの監査ログ">
  <img src="/images/on-premises/user-management-audit.png" alt="ユーザーのログインと管理者による機能変更が並ぶ Audit logs タブ" />
</Frame>

### Sessions {#sessions}

ユーザーがログインしている場所です。**Clear sessions** をクリックして確認すると、すべての場所からログアウトさせます。その後、タブには **Sessions cleared** と表示されます。

<Frame caption="ユーザーのセッション">
  <img src="/images/on-premises/user-management-sessions.png" alt="セッションが 1 つと Clear sessions ボタンがある Sessions タブ" />
</Frame>
