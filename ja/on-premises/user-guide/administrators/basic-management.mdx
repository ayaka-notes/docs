**Admin** をクリックし、**Manage Site** をクリックします。**Admin Panel** には **System Messages**、**Open Sockets**、**Open/Close Editor** の 3 つのタブがあります。

## システムメッセージ {#system-messages}

システムメッセージは、**Projects** ページとエディターの上部に表示される青いバナーです。すべてのユーザーに表示されます。

### メッセージを投稿する {#post-a-message}

**Message** にテキストを入力し、**Post Message** をクリックします。タブには現在表示中のメッセージが一覧表示されます。

<Frame caption="投稿された 2 件のメッセージ">
  <img src="/images/on-premises/basic-management-posted.png" alt="Message フィールド、Post Message ボタン、Clear all messages ボタンの上に投稿済みの 2 件のメッセージが並ぶ System Messages タブ" />
</Frame>

<Frame caption="ユーザーに表示される内容">
  <img src="/images/on-premises/basic-management-user-projects.png" alt="上部に 2 件のメッセージが青いバナーとして表示されたユーザーの Projects ページ" />
</Frame>

* ユーザーは <strong>×</strong> でメッセージを閉じることができます。そのブラウザーでは閉じたままになります。
* すでに開いているページは 15 分ごとに新しいメッセージを確認します。ページを再読み込みするとすぐに表示されます。

### メッセージを削除する {#remove-messages}

**Clear all messages** はすべてのメッセージを一度に削除し、確認は求めません。メッセージを 1 件だけ削除することはできません。

## 開いているソケット {#open-sockets}

Web サービスがこの時点で開いている送信接続を表示する診断ビューです。誰がオンラインかは表示されません。ユーザーがエディターを使用中でも、一覧が空になることがあります。

## メンテナンスのためにエディターを閉じる {#close-the-editor-for-maintenance}

**Open/Close Editor** タブを使用します。ボタンは確認なしですぐに動作し、タブにはエディターが閉じているかどうかは表示されません。確認するには **Projects** をクリックします。閉じている間は **Maintenance** ページが表示されます。

<Frame caption="Open/Close Editor タブ">
  <img src="/images/on-premises/basic-management-open-close.png" alt="Close Editor、Disconnect all users、Reopen Editor ボタンがある Open/Close Editor タブ" />
</Frame>

<Steps>
<Step id="tell-your-users" title="ユーザーに知らせる">
メンテナンスの時間を書いて[メッセージを投稿](/ja/on-premises/user-guide/administrators/basic-management#post-a-message)します。
</Step>

<Step id="click-close-editor" title="Close Editor をクリックする">
名前に反して、これはサイトのほぼ全体を閉じます。管理パネル以外のすべてのページに **Maintenance** が表示されます。**Projects**、**Account Settings**、**Templates**、ログインページも含まれます。**Manage Users** と **Project/Object Lookup** は引き続き動作します。

<Frame caption="エディターが閉じている間にユーザーに表示される内容">
  <img src="/images/on-premises/basic-management-closed-page.png" alt="インスタンスが現在メンテナンス中であることを示す Maintenance ページ" />
</Frame>

すでにエディターを開いているユーザーは接続されたままです。入力を続けることができ、変更も保持されますが、**Recompile** は **Server Error** で終了します。

このページのテキストを変更するには、[メンテナンスページ](/ja/on-premises/configuration/overleaf-toolkit/branding#maintenance-page)を参照してください。
</Step>

<Step id="click-disconnect-all-users" title="Disconnect all users をクリックする">
エディターを使用中のユーザーには **Please wait** ダイアログが表示され、10 秒からカウントダウンします。その後ページが更新され、**Maintenance** が表示されます。

<Frame caption="エディターを使用中のユーザーに表示される内容">
  <img src="/images/on-premises/basic-management-disconnect-dialog.png" alt="エディターが 8 秒後に自動で更新されることを示す Please wait ダイアログとその背後のエディター" />
</Frame>

先にエディターを閉じてください。そうしないと、更新後にユーザーがそのままエディターに戻ってしまいます。
</Step>

<Step id="do-the-maintenance-then-click-reopen-editor" title="メンテナンスを行い、Reopen Editor をクリックする">
すべてのページがすぐに再び動作します。ユーザーはページを再読み込みして作業を続けます。
</Step>
</Steps>

<Warning>

ログインページも閉じるため、エディターを再開するまではサインインしたままにしてください。締め出された場合はインスタンスを再起動してください。閉じた状態はメモリ上にのみ保持されるため、再起動するとエディターが再び開きます。

</Warning>

<Info>

複数のレプリカがある Kubernetes では、**Close Editor** はリクエストを処理したレプリカだけを閉じます。代わりに[メンテナンスモード](/ja/on-premises/configuration/kubernetes/branding#maintenance-mode)を使用してください。

</Info>
