## プロジェクトを探す {#find-a-project}

**Search by project name, ID, owner or link** に入力します。リンクにはプロジェクトのアドレスか共有リンクのいずれかを使用できます。一覧を絞り込むには **Status** フィルターを使用します。並べ替えるには **Title** または **Last modified** をクリックします。

削除済みのプロジェクトは結果に表示されません。検索条件が削除済みのプロジェクトにも一致する場合は、表の上にその旨が表示されます（例: **Found 1 matching deleted projects**）。表示するには **Display deleted projects** をクリックします。

## プロジェクトのステータス {#project-status}

各プロジェクトには 1 つのステータスがあり、**Status** フィルターには各ステータスのプロジェクト数が表示されます。

<Frame caption="Status フィルター">
  <img src="/images/on-premises/project-management-status-filter.png" alt="All、Active、Archived、Trashed、Deleted がある Status フィルター" />
</Frame>

| ステータス | 意味 |
| --- | --- |
| **All** | 削除されていないすべてのプロジェクト。 |
| **Active** | 通常の状態。 |
| **Archived** | オーナーがアーカイブしました。プロジェクトはそのまま残っており、元に戻せます。 |
| **Trashed** | オーナーがゴミ箱に移動しました。プロジェクトはそのまま残っており、元に戻せます。 |
| **Deleted** | オーナーがゴミ箱から削除したか、管理者が削除したか、オーナーのアカウントとともに削除されました。元に戻せるのは管理者だけです。 |

プロジェクトは段階的にステータスを移動します。

1. **Active、Archived、Trashed** は、オーナーが自分のプロジェクトページで選択します。オーナーはいつでも元に戻せます。ゴミ箱からの **Restore** は、以前アーカイブされていた場合でも常に Active に戻ります。
2. **Deleted** は次の段階です。オーナーはゴミ箱からのみ削除できます。管理者は 3 つのどの状態からでも削除できます。
3. **Restore** は、以前のステータスに関係なく削除済みのプロジェクトを **Active** として戻し、名前の末尾に `(Restored)` が付きます。これを行えるのは管理者だけです。オーナーのアカウントも削除されている場合は、先にアカウントを復元してください。そうしないと、ダイアログに **The owner of this project is deleted: restore the owner first** と表示されます。
4. **Delete permanently** は最後の段階で、元に戻せません。それ以外の場合、削除済みのプロジェクトは削除するまで残ります。ただし、インスタンスで [`ENABLE_CRON_RESOURCE_DELETION`](/ja/on-premises/configuration/overleaf-toolkit/environment-variables) が設定されている場合は 90 日後に削除されます。

<Info>

ステータスはオーナーにのみ従います。共同編集者が共有プロジェクトをアーカイブしたりゴミ箱に移動したりしても、移動するのはその共同編集者自身のプロジェクトページ上だけで、ここでのステータスは変わりません。

</Info>

## プロジェクトに対する操作 {#actions-on-a-project}

| アイコン | 操作 | 内容 |
| --- | --- | --- |
| 開く | **Open Project** | 新しいタブのエディターでプロジェクトを開きます。 |
| フォルダー | **Change project owner** | プロジェクトを別のユーザーに渡します。 |
| ゴミ箱 | **Delete** | プロジェクトを **Deleted** に移動します。 |
| 矢印 | **Restore** | 削除済みのプロジェクトを戻します。削除済みのプロジェクトのみ。 |
| バツ印付きのゴミ箱 | **Delete permanently** | 削除済みのプロジェクトを完全に削除します。削除済みのプロジェクトのみ。 |

### オーナーを変更する {#change-the-owner}

フォルダーアイコンをクリックし、名前またはメールアドレスを入力してユーザーを選び、**Change project owner** をクリックします。ダイアログには、この操作は元に戻せないこと、新しいオーナーに通知が届き、プロジェクトのアクセス設定を変更できることが表示されます。無効化されたアカウントは候補に表示されません。選択後にテキストを変更すると選択は取り消されるため、もう一度ユーザーを選んでください。

<Frame caption="プロジェクトのオーナーを変更する">
  <img src="/images/on-premises/project-management-change-owner.png" alt="警告と選択済みの新しいオーナーが表示された Change project owner ダイアログ" />
</Frame>

ユーザーのすべてのプロジェクトを一度に移すには、[ユーザーのプロジェクトを移管する](/ja/on-premises/user-guide/administrators/user-management#transfer-a-users-projects)を参照してください。

### 削除、復元、完全削除 {#delete-restore-or-permanently-delete}

ゴミ箱アイコンをクリックし、**Delete** をクリックします。プロジェクトを再び見つけるには、**Status** フィルターで **Deleted** を選択します。

<Frame caption="削除済みのプロジェクト">
  <img src="/images/on-premises/project-management-deleted.png" alt="Restore と Delete permanently のアイコンがある一覧内の削除済みプロジェクト" />
</Frame>

戻すには矢印アイコンをクリックしてから **Restore** を、削除するにはバツ印付きのゴミ箱をクリックしてから **Delete permanently** をクリックします。

<Frame caption="プロジェクトを完全に削除する">
  <img src="/images/on-premises/project-management-purge.png" alt="操作を元に戻せないことを警告する Delete permanently ダイアログ" />
</Frame>

### 複数のプロジェクトを一度に変更する {#change-several-projects-at-once}

一覧でプロジェクトにチェックを入れます。検索欄の隣に **Download**、**Change project owner**、**Delete** ボタンが表示されます。**Download** は選択したプロジェクトを 1 つの `.zip` ファイルに保存します。**Change project owner** では、チェックしたプロジェクトの現在のオーナーは選択できません。**Deleted** ビューでは、ボタンは **Restore** と **Delete permanently** になります。

<Frame caption="一括操作">
  <img src="/images/on-premises/project-management-bulk.png" alt="チェックされた 2 つのプロジェクトと Download、Change project owner、Delete ボタン" />
</Frame>

## プロジェクトページ {#the-project-page}

プロジェクトのタイトルをクリックするとそのページが開きます。上部には、プロジェクトの編集、開く、ダウンロード、削除のアイコンがあります。ページには 5 つのタブがあります。

### 概要 {#overview}

プロジェクトの詳細と設定です。鉛筆アイコンをクリックすると、**Name**、**Link sharing**、**Compiler**、**TeX Live version**、**Main document** を変更したり、**Change project owner** をクリックしたりできます。その後 **Save** をクリックします。

<Frame caption="プロジェクトを編集する">
  <img src="/images/on-premises/project-management-edit.png" alt="編集モードの Overview タブ" />
</Frame>

### ファイルツリー {#file-tree}

プロジェクトのファイルとフォルダーです。読み取り専用です。

<Frame caption="プロジェクトのファイル">
  <img src="/images/on-premises/project-management-files.png" alt="frog.jpg、main.tex、復元された bib ファイルが並ぶ File tree タブ" />
</Frame>

### メンバー {#members}

アクセスできる人です。オーナー、共同編集者、保留中の招待が表示されます。変更するには鉛筆アイコンをクリックします。

* 共同編集者に **Editor**、**Reviewer**、**Viewer** のいずれかを選びます。変更はすぐに反映されます。
* 共同編集者の横にあるゴミ箱をクリックし、**Remove access** をクリックします。
* 保留中の招待では、封筒をクリックすると **Resend invite**、ゴミ箱をクリックすると **Revoke Invite** になります。

終わったら **Done** をクリックします。ここではオーナーを変更できません。**Overview** タブの **Change project owner** を使用してください。

<Frame caption="プロジェクトのメンバーを変更する">
  <img src="/images/on-premises/project-management-members.png" alt="ロールメニュー、保留中の招待、操作アイコンがある編集モードの Members タブ" />
</Frame>

### 削除されたファイル {#deleted-files}

プロジェクトから削除されたファイルです。ファイルの横にある矢印アイコンをクリックし、**Restore file** をクリックします。名前に日付が付いたコピーがプロジェクトのルートフォルダーに作成され、その行にコピーの名前が表示されます。削除されたファイルは一覧に残ります。

コピーは、ページを再読み込みすると **File tree** タブに表示されます。

<Frame caption="復元されたファイル">
  <img src="/images/on-premises/project-management-deleted-files.png" alt="sample.bib とその復元コピーの名前が表示された Deleted files タブ" />
</Frame>

### 監査ログ {#audit-logs}

このプロジェクトで起きたことです。日付、操作、実行者、IP アドレス、詳細が表示されます。検索するか、**Operation** で絞り込めます。
