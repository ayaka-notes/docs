### オペレーティングシステム

Overleaf を最適な状態で実行するには、**Ubuntu** などの **Debian ベース**のオペレーティングシステムを使用することを強くおすすめします。これはソフトウェアの開発環境と一致しており、Overleaf ユーザーの大多数が選択しているものです。

<Danger>

Server Pro でサンドボックスコンパイルを使用する場合、アプリケーションが Docker ソケットへの root アクセスを必要とすることに**注意してください**。

</Danger>

### 依存関係

* Docker 25.0 および 29
* MongoDB 7.0 および 8.0
* Redis 6.2 および 7.5

<Info>

上記の依存関係やその他の一般的な製品のサポート終了（EOL）日は、endoflife.date サービスで確認できます：[https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

別のインストールを使用するように設定していない限り、Server CE または Server Pro の実行時に MongoDB と Redis は `docker compose` によって自動的に pull されます。

</Info>

Toolkit は次のプログラムに依存しています。

* bash
* Docker

`docker compose` は必須で、通常は Docker と一緒にインストールされます。

お使いのオペレーティングシステムで利用可能な最新バージョンの Docker をインストールすることをおすすめします。

Docker が正しくインストールされていれば、次のコマンドをエラーなく実行できるはずです。

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2)
docker compose version

# List the running Docker containers on your system
docker ps
```
