### オペレーティングシステム {#operating-systems}

共有サーバーや本番サーバーには、**Ubuntu** などの **Debian 系 Linux** システムをおすすめします。Ayakaleaf Pro は [Docker Desktop を使用した macOS](/ja/on-premises/installation/using-docker-compose/macos) や [WSL 2 と Docker Desktop を使用した Windows](/ja/on-premises/installation/using-docker-compose/windows) でも実行できます。3 つのプラットフォームはいずれも Linux コンテナと同じ Toolkit を使用します。ホストのオペレーティングシステムに対応するガイドに従ってください。

<Danger>

Sandboxed Compiles を使用する場合、アプリケーションが Docker ソケットへの root アクセスを必要とすることに**注意してください**。

</Danger>

### 依存関係 {#dependencies}

* Docker 25.0 および 29
* MongoDB 7.0 および 8.0
* Redis 6.2 および 7.5

<Info>

上記の依存関係やその他の人気製品のサポート終了（EOL）日は、endoflife.date サービスで確認できます：[https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

別のインストールを使用するよう設定していない限り、Ayakaleaf Pro を実行すると、MongoDB と Redis は `docker compose` によって自動的に pull されます。

</Info>

Toolkit は次のプログラムに依存しています。

* bash
* Docker

`docker compose` は必須で、通常は Docker と一緒にインストールされます。

お使いのオペレーティングシステムで利用可能な最新バージョンの Docker をインストールすることをおすすめします。

Docker が正しくインストールされていれば、次のコマンドをエラーなく実行できるはずです。

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2 or later, such as v5)
docker compose version

# List the running Docker containers on your system
docker ps
```
