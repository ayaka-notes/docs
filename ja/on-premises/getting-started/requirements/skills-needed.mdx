Overleaf インスタンスのオンサイト管理者には、次のスキルがあることをおすすめします。

* [x] 一般的な IT 管理スキル
* [x] Linux コマンドラインツールに精通していること
* [x] 一般的なネットワークの知識とトラブルシューティングのスキル
* [x] 本番システムのバックアップと復元の経験
* [x] Docker を使ったアプリケーション運用の経験（あれば尚可）
* [x] 稼働中の本番システムのアップグレードに向けたメンテナンス時間帯の調整経験

これらのスキルを持つオンサイト管理者であれば、組織内の Overleaf ユーザーに最良の体験を提供できると考えています。
