Overleaf のインストールを進める前に、このセクションを必ず最後までお読みください。

### Server Pro および Community Edition のインストール要件

<Warning>

Server Pro は、最新の安定版 Ubuntu（例：2025〜2026 年時点では Ubuntu 24.04）と最新バージョンの Docker 上で実行することを強く推奨します。他のシステムで Server Pro を実行することも可能ですが、デフォルト以外の Ubuntu/Docker 構成に対するサポートの提供は非常に難しくなります。また、Docker 自体の問題についてはサポートを提供できません。

</Warning>
