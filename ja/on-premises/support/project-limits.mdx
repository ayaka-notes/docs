---
title: プロジェクトの制限
icon: list-check
---

| 機能 | 制限 |
| ---- | ---- |
| コンパイルのタイムアウト | **デフォルト：** 180 秒。この値のカスタマイズについては、[プロジェクトのコンパイルタイムアウトの更新](/ja/on-premises/user-and-project-management/project-management)を参照してください。 |
| プロジェクトあたりの最大ファイル数 | 2000 |
| プロジェクトあたりの編集可能なデータの最大サイズ | **デフォルト：** 7 MB。この値のカスタマイズについては、[環境変数](/ja/on-premises/configuration/overleaf-toolkit/environment-variables)を参照してください。 |
| 個々の編集可能なテキストファイルの最大サイズ | 2 MB\* |
| 1 回のアップロードの最大サイズ | 50 MB（`MAX_UPLOAD_SIZE` で設定可能） |
| アップロードされた .zip の展開後の最大サイズ | 6 × `MAX_UPLOAD_SIZE`（デフォルトでは 300 MB） |
| プロジェクトの最大サイズ | 無制限† |
| プロジェクトの最大数 | 無制限 |

\* 状況によっては、より大きなファイルでも編集可能な場合があります。ただし、ファイルを確実に編集可能な状態に保つには、サイズを 2 MB 以下に抑える必要があります。

† プロジェクト全体のサイズに強制的な制限はありません。ただし、非常に大きなプロジェクトを扱う場合、技術的な制約が生じることがあります。プロジェクトの最大サイズは 500 MB、[Git 連携](https://www.overleaf.com/learn/how-to/Git_integration)を使用する場合は 100 MB 未満を推奨します。これらのサイズを超えるプロジェクトでも動作する場合がありますが、これらの制限内に収めることで最適な体験が得られます。
