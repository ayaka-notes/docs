---
title: LaTeX のユーザーヘルプを追加する
icon: graduation-cap
---

Toolkit の `config/variables.env` ファイルに `OVERLEAF_PROXY_LEARN=true` を追加して `bin/up` コマンドを実行するだけで、Overleaf Pro インスタンス内から Overleaf の [Learn](https://www.overleaf.com/learn) ページにアクセスできるようになります。

これにより、ユーザーはナビゲーションメニューの **Documentation** ボタンをクリックするだけで、インスタンスを離れることなく最新のドキュメントや学習リソースにアクセスできます。

<Info>

デフォルトでは、`/learn` を開けるのはログイン済みのユーザーのみです。ログインしていない訪問者にも公開するには、`OVERLEAF_ALLOW_PUBLIC_ACCESS=true` も設定してください。詳しくは [ページアクセス](/ja/on-premises/configuration/overleaf-toolkit/public-access#page-access  "mention") を参照してください。

</Info>

<Info>

Docker Compose でデプロイしている場合は、`docker-compose.yml` ファイル内の `sharelatex` サービスの **environment** セクションに環境変数 `OVERLEAF_PROXY_LEARN: true` を追加する必要があります。

</Info>

<Info>

Server Pro のデプロイ環境は、[https://learn.sharelatex.com](https://docs.overleaf.com/on-premises/welcome) への外部 `GET` リクエストを行えるよう、インターネットにアクセスできる必要があります。

</Info>

<Danger>

このオプションを初めて有効にして Overleaf の Docker を再起動すると、システムが関連する Wiki をダウンロードする必要があり、5 分以上かかる場合があります。ダウンロードが完了して初めて、Overleaf のログインページが正常に表示されるようになります。

</Danger>
