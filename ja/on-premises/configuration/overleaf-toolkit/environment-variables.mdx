このページでは、Toolkit によるデプロイメントで `config/variables.env` ファイルにおいてサポートされている環境変数について説明します。

`config/variables.env` ファイルは `NAME=value` 形式の変数定義で構成されます。`#` で始まる行はコメントとして扱われます。

<Info>

`overleaf.rc` または `variables.env` の内容を変更した後は、`bin/up` を実行して Docker コンテナを再作成する必要があります。

</Info>

### すべてのバージョン

これらの環境変数は Server CE と Server Pro の両方と互換性があり、これら 2 つのオンプレミス版の間で簡単に移行できるようにします。また、Toolkit と Docker Compose のどちらのデプロイメントでも使用できます。

<Info>

以前は、これらの環境変数の接頭辞は `OVERLEAF_` ではなく `SHARELATEX_` でした。

</Info>

<Info>

LDAP などの SSO オプションではなく、Overleaf のログインシステム（ローカルアカウント）を使用している場合は、ユーザーにパスワードの制限を課すことができます。SSO アカウントの場合、パスワードポリシーは ID プロバイダーまたはディレクトリサービスによって適用され、さらに多要素認証にも対応できます。

</Info>
