### グローバル設定

特定の認証モジュールを有効にするには、環境変数 `EXTERNAL_AUTH` が必要です。この環境変数は、どの外部認証方式を有効にするかを指定します。利用可能なオプションは次のとおりです（小文字で指定）。

* saml
* ldap
* oidc

### SSO に関する推奨事項

Overleaf で saml、ldap、oauth をテストしました。saml と oauth はどちらも Overleaf で問題なく動作しますが、ldap は環境によります。[https://docs.goauthentik.io/](https://docs.goauthentik.io/) ではうまく動作しませんが、openLDAP（[https://github.com/rroemhild/docker-test-openldap](https://github.com/rroemhild/docker-test-openldap)）では問題なく動作します。

<Info>

passport-ldapauth を更新する必要があります。最近 [https://goauthentik.io/](https://goauthentik.io/) で Overleaf の ldap をテストしたところ、失敗しました。"passport-ldapauth" を 3.0.0 に更新したところ、すべて正常に動作しました。

```text
"passport-ldapauth": "^3.0.0",
```

元のバージョンは 2.x.x で、6 年前のものです。

</Info>

LDAP（および saml、oauth）認証はすべて外部パッケージに依存しているため、原因ははっきりしていません。動作しない場合、Overleaf Server Pro でも同じ状況になる可能性があります。すべての環境変数を内部パッケージに渡しているだけなので、何らかのバグがあっても現時点では把握できません。

**そのため、ユーザーの皆さんには開発環境をセットアップし、すべてのソースコードを使って SSO をテストすることを強くおすすめします。** 手順は [開発環境のセットアップ（ローカル）](/ja/dev/environment/setup-develop-environment-local  "mention") で確認できます。開発環境ではターミナルですべてのログを確認できるため、デバッグに便利です。
