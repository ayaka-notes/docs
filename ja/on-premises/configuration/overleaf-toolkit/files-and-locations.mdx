このページでは、Toolkit が Overleaf のオンプレミスデプロイを構成するために使用する設定ファイルについて説明します。

### 永続データ

Overleaf Toolkit は、LaTeX プロジェクトのコンパイルに必要なファイルや MongoDB データベースの内容などの永続データを保存する必要があります。これは、ホストマシンのいくつかのディレクトリを Docker コンテナにマウントし、そのディレクトリにデータを書き込むことで実現されます。

#### データディレクトリ

`sharelatex` コンテナには、LaTeX のコンパイルに関連するデータを保存するディレクトリが必要です。このディレクトリは `config/overleaf.rc` の `OVERLEAF_DATA_PATH` 変数で設定します。

`mongo` コンテナを有効にしている場合、そのデータベースファイルを保存するディレクトリが必要です。`redis` コンテナも同様です。これらのディレクトリも `config/overleaf.rc` で設定できます。

#### ファイルのパーミッション

Docker は `root` として実行されるため、Toolkit を root 以外のユーザーで使用している場合でも、データディレクトリの所有者は `root` ユーザーになります。これは問題ではありませんが、コンテナの外部から永続データを変更する予定がある場合は注意してください。

### 設定ファイルの場所

ユーザーが管理するすべての設定ファイルは `config/` ディレクトリにあります。

このディレクトリは git のリビジョン管理から**除外**されているため、Toolkit のコードを更新しても変更されません。Toolkit が許可なく `config/` ディレクトリ内のデータを変更することは**ありません**。

<Info>

設定ファイルへの変更は、コンテナを（`bin/stop` と `bin/start` で）停止して再起動しても、既存のコンテナには自動的に適用されません。変更を適用するには `bin/up` を実行してください。内部では `docker compose` が設定の変更を新しいコンテナに自動的に適用します。（Docker のログにアタッチしたくない場合は `bin/up -d` を実行してください。）

</Info>

### `overleaf.rc` ファイル

`config/overleaf.rc` ファイルには、Toolkit が使用する最も重要なトップレベルの設定が含まれています。このファイルには、`VARIABLE_NAME=value` という形式で変数を設定するステートメントが含まれています。

利用可能なすべての設定オプションの詳細については、設定のセクションを参照してください。

### `variables.env` ファイル

`config/variables.env` ファイルには、`sharelatex` コンテナに読み込まれ、Overleaf のマイクロサービスの設定に使用される環境変数が含まれています。これには、Web インターフェースのヘッダーに表示されるアプリケーション名、メール送信の設定、Server Pro で使用する SSO などのその他のプレミアム設定が含まれます。

利用可能なすべての環境変数の詳細については、[環境変数](/ja/on-premises/configuration/overleaf-toolkit/environment-variables)のセクションを参照してください。

### `version` ファイル

`config/version` ファイルには、Overleaf サーバーの実行インスタンスの作成に使用される Docker イメージのバージョン番号が含まれています。

<Info>

これらの設定ファイルへの変更は、コンテナを（`bin/stop` と `bin/start` で）停止して再起動しても、既存のコンテナには自動的に適用されません。変更を適用するには `bin/up` を実行してください。Toolkit が設定の変更を適用した新しいコンテナを自動的に作成します。

</Info>

### `docker-compose.override.yml` ファイル

`config/docker-compose.override.yml` ファイルが存在する場合、`docker compose` の呼び出しに含められます。これは Docker Compose 固有の設定を上書きする場合に便利です。

詳細については、[docker-compose のドキュメント](https://docs.docker.com/compose/extends/#adding-and-overriding-configuration)を参照してください。
