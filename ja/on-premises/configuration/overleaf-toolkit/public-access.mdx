アカウントを持たない人に Overleaf インスタンスを公開する方法は 3 つあります。

* [プロジェクトアクセス](/ja/on-premises/configuration/overleaf-toolkit/public-access#project-access  "mention")：ゲストがログインせずに共有プロジェクトのリンクを開けるようにする
* [ページアクセス](/ja/on-premises/configuration/overleaf-toolkit/public-access#page-access  "mention")：未ログインの訪問者が `/learn`、`/templates`、`/devs` などのページを閲覧できるようにする
* [パブリック登録](/ja/on-premises/configuration/overleaf-toolkit/public-access#public-registration  "mention")：ユーザーが自分で登録できるようにする（オプションでメールドメインを制限可能）

### プロジェクトアクセス

<Info>

デフォルトでは、ユーザーがプロジェクトの共有リンクを入手しても、共同編集セッションに参加するには**ログイン**する必要があります。

</Info>

リンク共有されたプロジェクトへの匿名アクセスを許可するには、次の 2 つの変数を設定します。

```dotenv title="config/variables.env"
OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING=true
OVERLEAF_ALLOW_PUBLIC_ACCESS=true
```

`OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` は、リンク共有されたプロジェクトでの匿名の読み取り/書き込みを有効にします。

`OVERLEAF_ALLOW_PUBLIC_ACCESS` は、未認証のユーザーがログインページにリダイレクトされないようにします。

`bin/up` でコンテナを再作成します。その後、プライベートウィンドウでリンク共有 URL を開きます。

### ページアクセス

デフォルト（`OVERLEAF_ALLOW_PUBLIC_ACCESS` が未設定）では、ログインページと登録ページを除く**すべての**ページで、未ログインの訪問者はログインページにリダイレクトされます。これには公開を意図したページも含まれるため、それらへのリンクはすでにログインしているユーザーにしか機能しません。

`OVERLEAF_ALLOW_PUBLIC_ACCESS=true` を設定すると、未ログインの訪問者は次のページを開けます。

| ページ                                                                  | 必要な設定                         |
| --------------------------------------------------------------------- | -------------------------------- |
| `/learn` の LaTeX ヘルプ（[adding-latex-user-help.md](/ja/on-premises/configuration/overleaf-toolkit/adding-latex-user-help  "mention") を参照） | `OVERLEAF_PROXY_LEARN=true`      |
| `/templates` のテンプレートギャラリー、テンプレートページ、プレビュー、ZIP ダウンロード（[templates.md](/ja/on-premises/configuration/overleaf-toolkit/templates  "mention") を参照） | `OVERLEAF_TEMPLATE_GALLERY=true` |
| `/devs` の Overleaf Import API ページ（[overleaf-import-api.md](/ja/on-premises/configuration/overleaf-toolkit/overleaf-import-api  "mention") を参照） | —                                |

また、[Overleaf Import API](/ja/on-premises/configuration/overleaf-toolkit/overleaf-import-api#signed-out-visitors  "mention") が、未ログインの訪問者からのフォーム送信をログインするまで保持できるようになります。

プロジェクト一覧、エディター、プロジェクトの作成（テンプレートからや Import API 経由の場合も含む）には、引き続きログインが必要です。

### パブリック登録

パブリック登録は [ayaka-notes/overleaf-pro](https://github.com/ayaka-notes/overleaf-pro) でのみ利用できます。

<Danger>

パブリック登録を有効にすると、Overleaf インスタンスにアクセスできる**誰でも**ユーザーとして登録できるようになることに注意してください。

登録プロセスではメールアドレスの確認を行わないため、イントラネットまたは信頼できる環境でのみ使用するか、登録が不要になったら無効にしてください。

</Danger>

デフォルトでは、Community Edition と Overleaf Pro のいずれもパブリック登録を許可していません。

有効にするには、`config/variables.env` に次を追加します。

```dotenv title="config/variables.env"
OVERLEAF_ALLOW_PUBLIC_REGISTRATION=true
```

`bin/up` でコンテナを再作成します。

その後、**Sign up** をクリックするか、`/register` にアクセスします。

### ドメインを制限した登録

ドメインを制限したパブリック登録は [ayaka-notes/overleaf-pro](https://github.com/ayaka-notes/overleaf-pro) でのみ利用できます。

これを有効にする前に、ユーザーが招待や通知を受け取れるようにメール配信を設定してください。[メール配信](/ja/on-premises/configuration/overleaf-toolkit/email-delivery)を参照してください。

次に、`config/variables.env` に次の行を追加します。

```dotenv title="config/variables.env" wrap
OVERLEAF_ALLOW_PUBLIC_REGISTRATION=@example.domain
```

`OVERLEAF_ALLOW_PUBLIC_REGISTRATION` には次の値を設定できます。

* `true`：サイトにアクセスできる誰でも登録できるようにする
* `@example.domain`：そのドメインのメールアドレスに登録を制限する
