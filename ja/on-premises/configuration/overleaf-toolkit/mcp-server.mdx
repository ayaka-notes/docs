各プロジェクトには MCP サーバーがあり、Claude Code、Codex、Cursor、VS Code、Gemini CLI などの AI クライアントがプロジェクトで作業できます。ファイルの読み取りと編集、コンパイル、LaTeX のログの読み取り、PDF のダウンロード、コメントへの返信が可能です。

<Info>

この機能は [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro) によって開発されたものです。v6.4.0 以降で導入されています。

</Info>

### セットアップ

MCP サーバーは Git 連携に含まれています。[git-bridge](/ja/on-premises/configuration/overleaf-toolkit/git-integration) を有効にすれば、MCP サーバーも利用できるようになります。その他の設定は必要ありません。

### AI クライアントを接続する

1. **アカウント設定** で Git 認証トークンを生成します。同じトークンが MCP サーバーと Git の両方で使用されます。
2. エディターで **Integrations** を開き、**MCP server** をクリックします。プロジェクトの MCP サーバーのアドレス `https://<your-overleaf>/project/<project_id>/mcp` と、各 AI クライアントへの追加方法が表示されます。コマンドをコピーし、`<token>` を自分のトークンに置き換えてください。

### 使い方

接続したら、AI クライアントに普段の言葉で依頼します。例:

| 依頼内容 | AI クライアントが使用するツール |
| --- | --- |
| _序論の誤字を修正して。_ | `read_file`、`edit_file`: 編集はエディターにリアルタイムで表示されます |
| _プロジェクトをコンパイルして LaTeX のエラーを修正して。_ | `compile`、`get_compile_log`、`edit_file` |
| _未解決のコメントに返信してから解決済みにして。_ | `list_comments`、`reply_to_comment`、`resolve_comment` |
| _XeLaTeX に切り替えて PDF をダウンロードして。_ | `update_settings`、`compile`、`get_output_file_link` |

### ツール

| グループ | ツール |
| --- | --- |
| プロジェクト | `get_clone_info`、`get_settings`、`update_settings`、`list_versions` |
| ファイル | `list_files`、`read_file`、`edit_file`、`write_file`、`delete_file` |
| コンパイル | `compile`、`get_compile_log`、`get_output_file_link`、`word_count` |
| コメント | `list_comments`、`reply_to_comment`、`resolve_comment`、`reopen_comment` |

`edit_file` と `write_file` による編集はエディターにリアルタイムで表示され、共同編集者の編集とマージされます。多数のファイルを一度に扱う場合、バイナリファイル、名前の変更などについては、AI クライアントが Git でプロジェクトをクローンしてプッシュすることもできます。

### 権限

MCP サーバーは、Git と同様にプロジェクトの共有設定に従います。

* プロジェクトを閲覧できるユーザーは全員、プロジェクトの読み取り、コンパイル、出力のダウンロードができます。
* ファイルと設定を変更できるのは、オーナーと編集者のみです。
* レビュアーはコメントへの返信に加え、自分が開始したコメントを解決または再オープンすることもできます。
* リンクで参加した閲覧者は、エディターと同様にコメントを見ることができません。
