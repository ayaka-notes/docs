### Zotero 連携のセットアップ

1. [このリンク](https://www.zotero.org/oauth/apps)を開いて Zotero OAuth クライアントを作成します（画像を参照）
2. **Application Type** で **Browser** を選択します
3. Callback URL に `${OVERLEAF_SITE_URL}/user/zotero/oauth/callback` を設定します
4. `config/variables.env` を設定します

<Frame>
  <img src="/images/on-premises/image-41.png" alt="" width="375" />
</Frame>

```dotenv title="config/variables.env"
#################
#    Zotero     #
#################
# 'zotero' must be in ENABLED_LINKED_FILE_TYPES (set in develop/docker-compose.yml)
ENABLED_LINKED_FILE_TYPES=project_file,project_output_file,url,zotero

# From a Zotero OAuth client (register at https://www.zotero.org/oauth/apps)
# Application Type: Browser 
# Callback URL -> ${OVERLEAF_SITE_URL}/user/zotero/oauth/callback
ZOTERO_CLIENT_ID=
ZOTERO_CLIENT_SECRET=
# Encrypts the Zotero API key in mongo (set in dev to avoid writing a key file
# to /var/lib/overleaf/data, which the dev web container can't create)
# How to generate: `openssl rand -hex 32`
ZOTERO_CIPHER_PASSWORD=dev-zotero-cipher-password
# Optional: route the module's server-side Zotero requests (OAuth + API) through
# an HTTP proxy (must be reachable from the web container; same as github-sync)
# http://10.0.0.1:10808
# (Optional) ZOTERO_PROXY_URL=
```

### 注意事項

<Warning>

Zotero のリンクされた参考文献ファイルがある既存のインストールを再リリースされた 6.3.0 にアップグレードする場合は、[Zotero / Mendeley の移行手順](/ja/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention")に従ってください。新規インストールではこの移行は必要ありません。

</Warning>

<Danger>

Ayakaleaf は共同作業プラットフォームであるため、セキュリティ向上のため、バージョン 6.3.0 以降では、参考文献の `bib` ファイルを最初に作成したユーザーのみがインポートしたファイルを更新できます。

</Danger>

たとえば、プロジェクトのオーナーであるユーザー A がリンク共有を有効にし、プロジェクト内に `test.bib` ファイルを作成して自分の Zotero アカウントにリンクしたとします。別のユーザー B が共有リンクからプロジェクトにアクセスした場合、ユーザー B は `test.bib` を読み取ったりダウンロードしたりすることはできますが、Zotero からファイルを更新したり再インポートしたりすることはできません。更新を行えるのは、参考文献ファイルの最初の作成者であるユーザー A だけです。つまり、`.bib` ファイルを更新する権限を持つのは、そのファイルの最初の作成者のみです。
