Overleaf は、Simple Mail Transfer Protocol（SMTP）と [Amazon Simple Email Service（SES）](https://aws.amazon.com/ses/) の 2 つの方法によるメール送信をサポートしています。localhost 上でローカル接続を待ち受けるメールサーバーが有効になっている場合は、SMTP を使用できます。

## 設定

メールは以下の環境変数を使用して設定します。

#### 送信者の設定

| 名前                          | 説明                                                                                                                                          |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | <p>送信元アドレス。例: <a href="mailto:support@mycompany.com">`'support@mycompany.com'`</a><br /><br />- <strong>必須</strong>: はい</p> |
| `OVERLEAF_EMAIL_REPLY_TO`     | 返信先アドレス。例: `'noreply@mycompany.com'`                                                                                                  |

#### SMTP

| 名前                                    | 説明                                                                                                                                                                                                                                                              |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST`              | 接続先のホスト名または IP アドレス。Docker コンテナからアクセスできる必要があります                                                                                                                                                                               |
| `OVERLEAF_EMAIL_SMTP_PORT`              | 接続先のポート                                                                                                                                                                                                                                                   |
| `OVERLEAF_EMAIL_SMTP_SECURE`            | `true` の場合、サーバーへの接続時に TLS を使用します。`false` または未設定の場合、サーバーが `STARTTLS` 拡張をサポートしていれば TLS を使用します。ほとんどの場合、ポート `465` に接続する場合はこの値を `true` に設定し、ポート `587` または `25` の場合は `false` のままにします |
| `OVERLEAF_EMAIL_SMTP_USER`              | SMTP サーバーへの認証に使用するユーザー名                                                                                                                                                                                                 |
| `OVERLEAF_EMAIL_SMTP_PASS`              | SMTP ユーザー名に対応するパスワード                                                                                                                                                                                                                           |
| `OVERLEAF_EMAIL_SMTP_TLS_REJECT_UNAUTH` | `false` の場合、自己署名または無効な TLS 証明書を持つ TLS サーバーへの接続を許可します                                                                                                                                                                        |
| `OVERLEAF_EMAIL_SMTP_IGNORE_TLS`        | `true` かつ `OVERLEAF_EMAIL_SMTP_SECURE` が `false` の場合、サーバーが `STARTTLS` 拡張をサポートしていても TLS を使用しません                                                                                                                                            |
| `OVERLEAF_EMAIL_SMTP_NAME`              | `OVERLEAF_EMAIL_SMTP_HOST` に IP アドレスを設定した場合の TLS 検証用ホスト名（任意）。デフォルトはマシンのホスト名です。                                                                                                                                        |
| `OVERLEAF_EMAIL_SMTP_LOGGER`            | `true` の場合、ログメッセージを `web.log` に出力します。                                                                                                                                                                                                                        |

#### Amazon SES SMTP インターフェース

Amazon SES SMTP インターフェースを使用したメール送信の詳細は[こちら](https://docs.aws.amazon.com/ses/latest/dg/send-email-smtp.html)をご覧ください。

| 名前                       | 説明                                                                                |
| -------------------------- | ------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST` | 接続先のホスト名または IP アドレス。Docker コンテナからアクセスできる必要があります |
| `OVERLEAF_EMAIL_SMTP_PORT` | 接続先のポート                                                                     |
| `OVERLEAF_EMAIL_SMTP_USER` | SMTP サーバーへの認証に使用するユーザー名                   |
| `OVERLEAF_EMAIL_SMTP_PASS` | SMTP ユーザー名に対応するパスワード                                             |

#### Amazon SES API

Amazon SES API を使用したメール送信の詳細は[こちら](https://docs.aws.amazon.com/ses/latest/dg/send-email-api.html)をご覧ください。

| 名前                                   | 説明                                 |
| -------------------------------------- | ------------------------------------------- |
| `OVERLEAF_EMAIL_AWS_SES_ACCESS_KEY_ID` | AWS SES を使用する場合のアクセスキー             |
| `OVERLEAF_EMAIL_AWS_SES_SECRET_KEY`    | AWS SES を使用する場合のシークレットキー             |
| `OVERLEAF_EMAIL_AWS_SES_REGION`        | 未設定の場合、デフォルトのリージョンは US-EAST-1 です |

#### インスタンスロールを使用した AWS SES

| 名前                    | 説明                                                                                                                      |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_DRIVER` | `ses` に設定すると、メールシステムは SES API 方式を使用し、設定されたインスタンスロールに基づいてメールを送信します。 |

#### カスタマイズ

| 名前                           | 説明                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_CUSTOM_EMAIL_FOOTER` | <p>すべてのメールの末尾に追加されるカスタム HTML。例:<br /><br /><strong>例</strong>: `"<div>This system is run by department x </div> <div> If you have any questions please look at our faq <a href='`<a href="https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/https:/somwhere.com'%3Ehere&#x3C;/a%3E&#x3C;/div%3E">`https://somwhere.com'>here&#x3C;/a>&#x3C;/div>`</a>`"`</p> |
