---
title: パスワードの制限
icon: key
---

認証にネイティブの Overleaf ログインシステムを使用している場合、ユーザーアカウントにパスワードの制限を適用できます。

<Info>

SSO（LDAP/SAML 2.0）によるログインには、パスワードの制限を適用することは**できません**。これらは ID プロバイダー（IdP）側で設定する必要があります。

</Info>

パスワードの制限を有効にするには、Toolkit の `config/variables.env` ファイルで該当する環境変数を設定します。

| 名前                                      | 説明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | デフォルト |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------: |
| `OVERLEAF_PASSWORD_VALIDATION_MIN_LENGTH` | 必要な**最小**文字数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |     `8` |
| `OVERLEAF_PASSWORD_VALIDATION_MAX_LENGTH` | 許可される**最大**文字数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |    `72` |
| `OVERLEAF_PASSWORD_VALIDATION_PATTERN`    | <p>パスワードの<strong>強度</strong>の検証に使用します：</p><ul><li>`abc123` – パスワードには 3 文字の英字と 3 文字の数字が必要で、6 文字以上である必要があります</li><li>`aA` – パスワードには小文字と大文字の英字が必要で、2 文字以上である必要があります</li><li>`ab$3` – 英字、数字、記号を含み、4 文字以上である必要があります</li><li>文字は 4 つのグループに分類されます：英字、大文字の英字、数字、記号。英字でも数字でもないものはすべて記号とみなされます。</li></ul> |       — |
