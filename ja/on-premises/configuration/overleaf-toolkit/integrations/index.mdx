---
title: 連携
description: インスタンスを Git、GitHub、GitLab、Gitea、Dropbox、文献管理ツール、AI サービス、その他のサイトと接続します。
icon: puzzle-piece
---

Overleaf インポート API を除き、各連携はデフォルトで無効になっています。GitHub、GitLab、Gitea、Dropbox の同期と MCP サーバーを使用するには、[Git 連携](/ja/on-premises/configuration/overleaf-toolkit/integrations/git-integration)も必要です。いずれかを有効にした後は、`bin/up -d` でコンテナを再作成してください。
