---
title: 連携
description: Kubernetes デプロイを Git、GitHub、GitLab、Gitea、Dropbox、文献管理ツール、AI サービス、その他のサイトと接続します。
icon: puzzle-piece
---

Overleaf インポート API を除き、各連携はデフォルトで無効になっています。GitHub、GitLab、Gitea、Dropbox の同期と MCP サーバーには、[Git 連携](/ja/on-premises/configuration/kubernetes/integrations/git-integration)も必要です。ConfigMap または Secret で連携を有効にした後は、`kubectl -n overleaf rollout restart` でレプリカを再起動してください。
