オープンソースの精神を体現するために、Overleaf はオープンソースのコミュニティ版を [GitHub: Overleaf](https://github.com/overleaf/overleaf) で公開しています。しかし、いわゆる [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud) を売り込むために、Overleaf はオープンソースのコミュニティ版に意図的に多くのコード隠蔽の変更を加えており、純粋にフロントエンドだけで動作する数式用の _記号パレット_ さえも **有料** 機能として販売しています。

ここ数年、Overleaf のコンパイル時間が **1 分から 20 秒、さらには 10 秒** にまで短縮される一方で、サブスクリプション料金はどんどん上がり続けてきました。ため息をつきながらこう言わずにはいられません：**研究者たちは長い間 Overleaf に苦しめられてきた**、と。

さらに、Overleaf の価格は世界中でほぼ一律であり、最も安い学生向けメンバーシップでさえ月額 \$10 からと、欧米以外のほとんどの学生には手が届きません。さらにひどいことに、年額 \$399 の Pro プランもあり、法外な価格としか言いようがありません。

### 変化が必要だ

個人の学生であれ研究機関全体であれ、誰もがここ数年 Overleaf の値上げに振り回されてきたと言っても過言ではありません。

そして AI の時代において、Overleaf は約束された変革をもたらすどころか、古い技術に頼り続けながら、エンドユーザーからますます多くを搾り取っています。

長年にわたり、多くのコミュニティの開発者が Overleaf Community Edition の改善に大きな努力を払ってきました。その例は次のとおりです。

* [https://github.com/ertuil/overleaf](https://github.com/ertuil/overleaf)
* [https://github.com/AllanChain/lcpu-overleaf](https://github.com/AllanChain/lcpu-overleaf)
* [https://github.com/yu-i-i/overleaf-cep/](https://github.com/yu-i-i/overleaf-cep/)
* [https://github.com/ayaka-notes/overleaf](https://github.com/ayaka-notes/overleaf)
* [https://github.com/davrot/overleaf\_with\_admin\_extension](https://github.com/davrot/overleaf_with_admin_extension)
* [https://github.com/overleaf/overleaf/pull/1447](https://github.com/overleaf/overleaf/pull/1447)（Git 連携）
* [https://github.com/overleaf/overleaf/pull/1385](https://github.com/overleaf/overleaf/pull/1385)（Typst のサポート）

その中にはプルリクエスト（PR）を提出したものもありますが、残念ながら、オープンソースコミュニティにおいてこれらの PR はほとんど無視されています。そのため、私たちは Overleaf のいわゆるオープンソースが実際にはどのようなオープンソースなのか、しばしば疑問に思っています。

2026 年 1 月、OpenAI は [Prism](https://prism.openai.com/) のリリースを発表しました。多くのコミュニティで、Prism が Overleaf を葬ったと言われています。

_**これが示しているのは、企業が API の焼き直しと幾重にも重ねた機能制限だけに頼ってユーザーを囲い込もうとすれば、AI の時代には、増え続ける競合他社に最終的に追い抜かれてしまうということです。**_

本題に戻りましょう。すべての機能を備えた Overleaf Pro のリリースを発表できることを嬉しく思います。このドキュメントは、Overleaf Pro のセットアップと保守に関心のある方を対象としています。

Overleaf Pro と Community Edition はどちらも Docker コンテナ内で動作し、同じホスト上の他のアプリケーションから隔離されています。これにより、アプリケーション間の攻撃の可能性を防ぐという、追加のセキュリティ層が提供されます。

どちらもエアギャップ環境のサーバー上で実行できます。つまり、インターネットを含む他のネットワークから完全に隔離することができます。Docker には、インターネットに接続された環境からエアギャップ環境へアプリケーションを転送するためのツールが用意されています。

最初のダウンロード後はインターネット接続が不要になるため、外部からの脅威のリスクを大幅に低減できます。
