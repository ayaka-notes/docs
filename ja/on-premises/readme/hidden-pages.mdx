オープンソースの精神を体現するため、Overleaf は [GitHub: Overleaf](https://github.com/overleaf/overleaf) でオープンソースのコミュニティ版を提供しています。しかし、いわゆる [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud) を販売するために、Overleaf はオープンソースのコミュニティ版に意図的に多くのコード隠蔽の変更を加えており、純粋なフロントエンド機能である数式の _シンボルパレット_ さえ**有料**機能として販売しています。

ここ数年、Overleaf のコンパイル時間の上限が **1 分から 20 秒、さらには 10 秒** にまで短縮される一方で、サブスクリプション料金はどんどん高くなっていくのを私たちは目の当たりにしてきました。<strong>研究者たちは長い間 Overleaf に苦しめられてきた</strong>と、ため息をつかずにはいられません。

さらに、Overleaf の料金は世界中でほぼ一律で、最も安い学生向けメンバーシップでさえ月額 \$10 からとなっており、欧米以外の多くの学生にとっては手の届かない価格です。さらにひどいことに、年額 \$399 の Pro プランもあり、法外な価格としか言いようがありません。

### 変化が必要だ

個々の学生であれ研究機関全体であれ、誰もが長年にわたって Overleaf の値上げに振り回されてきたと言っても過言ではありません。

そして AI の時代において、Overleaf は約束された変革をもたらすどころか、古い技術に頼り続けながら、エンドユーザーからますます多くを搾り取っています。

長年にわたり、多くのコミュニティ開発者が Overleaf Community Edition の改良に大きな努力を払ってきました。以下がその例です。

* [https://github.com/ertuil/overleaf](https://github.com/ertuil/overleaf)
* [https://github.com/AllanChain/lcpu-overleaf](https://github.com/AllanChain/lcpu-overleaf)
* [https://github.com/yu-i-i/overleaf-cep/](https://github.com/yu-i-i/overleaf-cep/)
* [https://github.com/ayaka-notes/overleaf](https://github.com/ayaka-notes/overleaf)
* [https://github.com/davrot/overleaf\_with\_admin\_extension](https://github.com/davrot/overleaf_with_admin_extension)

その中にはプルリクエスト（PR）を出したものもありますが、残念ながらオープンソースコミュニティにおいて、これらの PR はほとんど無視されています。そのため私たちは、Overleaf のいわゆるオープンソースとは一体どのようなオープンソースなのか、しばしば疑問に思っています。

2026 年 1 月、OpenAI は [Prism](https://prism.openai.com/) のリリースを発表しました。多くのコミュニティで、Prism が Overleaf を殺したと言われています。

_<strong>これは、企業が再パッケージ化した API と幾重にも重ねた機能制限だけに頼ってユーザーを囲い込もうとすれば、AI の時代には最終的に増え続ける競合他社に追い抜かれてしまうということを示しています。</strong>_

本題に戻りましょう。すべての機能を備えた Overleaf Pro のリリースをここに発表できることを嬉しく思います。このドキュメントは、Overleaf Pro のセットアップと保守に関心のある方に向けたものです。

Overleaf Pro と Community Edition はどちらも Docker コンテナ内で動作し、同じホスト上の他のアプリケーションから隔離されています。これにより、アプリケーション間の攻撃の可能性を防ぎ、セキュリティがさらに強化されます。

これらはエアギャップ環境のサーバー上でも実行できます。つまり、インターネットを含む他のネットワークから完全に隔離できます。Docker には、インターネットに接続された環境からエアギャップ環境へアプリケーションを転送するためのツールが用意されています。

初回のダウンロード後はインターネット接続が不要になるため、外部からの脅威のリスクを大幅に低減できます。
