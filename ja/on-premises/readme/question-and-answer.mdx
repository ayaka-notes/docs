ここでは、Ayakaleaf Pro に関するよくある質問への回答をまとめています。

### 基本的な質問

<Accordion title="Q01：Ayakaleaf Pro は無料トライアルですか？ライセンスは必要ですか？">

いいえ。Ayakaleaf Pro は完全に無料で使用できます。トライアル版ではなく、ライセンスも必要ありません。

</Accordion>

<Accordion title="Q02：Ayakaleaf Pro には Overleaf Server Pro のすべての機能が含まれていますか？">

はい。Ayakaleaf Pro には、Git-Bridge 連携を含む Overleaf Server Pro のすべての機能が含まれています。また、Overleaf の SaaS プラットフォームから選ばれた機能も含まれています。私たちは引き続き Ayakaleaf Pro の開発と改善を続けています。

</Accordion>

<Accordion title="Q03：Overleaf Server Pro の価格はいくらですか？">

Overleaf Server Pro の価格は、ユーザーあたり年間約 \$300 です。最低 10 ライセンスが必要なため、導入費用は年間約 \$3,000 からとなります。米国の小規模な公共契約では、ユーザーあたり年間約 \$320〜\$370 の費用が示されています。このため、Server Pro は特に小規模なチームにとって高価です。記録されている購入事例と価格については、[#information-and-price-about-overleaf-server-pro](/ja/on-premises#information-and-price-about-overleaf-server-pro  "mention") を参照してください。

</Accordion>

<Accordion title="Q04：Overleaf Server Pro に GitHub 同期や AI 機能が含まれていないのはなぜですか？">

Overleaf Server Pro は、政府機関で広く使用されています。政府機関はプライベートネットワーク上にこれを導入し、アクセスを厳しく管理しています。機密データを保護するため、搭載されている機能はサードパーティのサービスとのデータ交換を避けるようになっています。GitHub 同期や AI など、外部と接続する機能が必要な場合、Overleaf は SaaS プラットフォームへのサブスクリプションを推奨しています。

</Accordion>

<Accordion title="Q05：Ayakaleaf Pro は安全で信頼できますか？">

Ayakaleaf Pro はオープンソースです。セキュリティと信頼性を強化するため、Codex Security などのツールを使用してコードをレビューしています。サードパーティとのデータ同期を有効にしない限り、データはお使いのサーバー上に留まります。Ayakaleaf Pro には、データを外部に送信するテレメトリは一切含まれていません。

</Accordion>

<Accordion title="Q06：Ayakaleaf Pro は長期的にメンテナンスされますか？">

私たちは、このプロジェクトを長期的にメンテナンスするためにあらゆる努力を払います。

</Accordion>

<Accordion title="Q07：Ayakaleaf Pro はライセンスに準拠していますか？">

Ayakaleaf Pro はコミュニティフォークです。そのコードと統合された機能は、コミュニティからの貢献によるものです。AGPL v3 の下でライセンスされています。導入環境は、このライセンスの要件を満たすことでライセンスに準拠できます。

</Accordion>

<Accordion title="Q08：なぜプロジェクト名が Ayakaleaf Pro なのですか？">

このプロジェクトは当初、2024 年に Overleaf Pro という名前で始まりました。開発は一時中断した後、2025 年後半に再開されました。2026 年第 1 四半期に、Overleaf は AI 対応のサブスクリプションプランの名称を Pro に変更しました。また、コミュニティからのフィードバックで、Overleaf Pro という名前は商標やなりすましのリスクを生む可能性があるとの指摘がありました。ユーザーがこのプロジェクトを公式のものだと誤解する恐れがあったのです。

こうした混乱を避けるため、プロジェクト名を Ayakaleaf Pro に変更しました。この名前は「Ayaka-notes Overleaf Pro」と読むことができます。メンテナーは学生時代から 5 年以上にわたり Overleaf のコミュニティ開発に貢献してきました。この経験が、私たちの長期的なメンテナンスへの取り組みを支えています。

</Accordion>

<Accordion title="Q09：Ayakaleaf Pro は、AI で構築された新しい LaTeX エディターとどう違うのですか？">

2026 年以降、オープンソースコミュニティでは OpenAI Prism をはじめ、AI で構築された LaTeX エディターが数多くリリースされています。Ayakaleaf Pro は、データとサービスをお使いのサーバー上に保持します。これにより、導入環境とデータを直接管理できます。

実験的なコミュニティエディターの多くには、確立された長期的なメンテナンス計画がありません。また、サードパーティの LaTeX コンパイルプラットフォームは、ユーザー基盤や収益が不十分な場合に運営を停止する可能性があります。Ayakaleaf Pro はすべてのソースコードを提供し、すべてのサービスをセルフホストできます。万が一メンテナンスが停止しても、既存のセルフホストサービスは引き続き稼働できます。

</Accordion>

### LaTeX

<Accordion title="Q01：ユーザーの LaTeX プロジェクトのコンパイルは分離されていますか？Shell Escape は有効ですか？">

サンドボックスコンパイルを有効にすると、各ユーザーのコンパイルは個別の Docker コンテナで実行され、他のユーザーのコンパイルから分離されます。サンドボックスコンパイルでは、Shell Escape はデフォルトで有効になっています。

</Accordion>

<Accordion title="Q02：サンドボックスコンパイルのイメージは信頼できますか？コンパイルが失敗することはありますか？">

私たちは過去 3 年間にわたり、サンドボックスコンパイル用の TeX Live Full イメージを改善してきました。ほとんどの場合、overleaf.com でコンパイルできるプロジェクトは Ayakaleaf Pro でも正しくコンパイルできます。必要なフォントが利用できない場合は、そのフォントを手動でプロジェクトにアップロードしてください。

</Accordion>
