<Info>

Ayakaleaf Pro は Overleaf Community Edition の拡張実装であり、Server Pro のすべてのプレミアム機能を _**無料**_ で提供します。[https://www.overleaf.com/](https://www.overleaf.com/) で利用できる Overleaf Common とは異なり、コンパイル時間の制限やユーザー数に応じたライセンス要件がなく、データを完全にセルフホストできるため、万全のセキュリティを確保できます。

Overleaf Server Pro は、公式サポート付きの商用セルフホスト型 Overleaf です。Server Pro の詳細については、[Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud) を参照してください。

</Info>

<Warning>

Overleaf Community Edition は、**すべての**ユーザーが信頼できる環境での使用を想定しています。Sandbox Compiles が利用できないため、Community Edition はユーザーの分離が必要なシナリオには**適していません**。

サンドボックス化されていない場合、LaTeX のコンパイルはコンテナと同じ権限で実行され、そのファイルシステム、ネットワーク、環境変数にアクセスできてしまいます。これにより、データ漏えいやシステム侵害のリスクが生じます。サンドボックス化されていないコンパイルは完全に信頼できる環境でのみ使用し、マルチユーザー環境や本番環境のデプロイでは Sandbox Compiles を強く推奨します。

Sandbox Compiles の詳細については、[ドキュメント](/ja/on-premises/configuration/overleaf-toolkit/sandboxed-compiles)を参照してください。

</Warning>

### コミュニティサポート

セルフホストの Overleaf インスタンスを使用している方には、GitHub の [Issues](https://github.com/ayaka-notes/overleaf-pro/issues) を通じてコミュニティによるサポートが提供されています。

サポート対象のバージョンを維持するために、以下のコマンドの出力をリリースノートで公開されている Image ID と比較して、実行中の Overleaf のバージョンを確認できます。

```bash
docker inspect --format '{{.Image}}' sharelatex | awk -F: '{print substr($2, 1, 12)}'
```
