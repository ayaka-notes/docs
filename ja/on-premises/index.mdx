### Overleaf の概要

Overleaf は、研究者や技術チームに愛用されている共同編集型の LaTeX エディターです。クラウド版は [overleaf.com](https://www.overleaf.com/) で利用でき、フル機能のオンライン LaTeX エディターを提供しています。しかし、Overleaf Common（SaaS 版）には多くの機能制限があり、_**10 秒のコンパイル時間制限**_ と高額な会員料金を受け入れなければなりません。

Overleaf はオープンソースのコミュニティ版（[GitHub: Overleaf](https://github.com/overleaf/overleaf) で公開）も提供していますが、こちらにも多くの制限があります。たとえば次のとおりです。

<Warning>

Overleaf Community Edition は、**すべての**ユーザーが信頼できる環境での使用を想定しています。Sandbox Compiles が利用できないため、Community Edition はユーザーの分離が必要なシナリオには**適していません**。

サンドボックス化されていない場合、LaTeX のコンパイルはコンテナと同じ権限で実行され、そのファイルシステム、ネットワーク、環境変数にアクセスできてしまいます。これにより、データ漏えいやシステム侵害のリスクが生じます。サンドボックス化されていないコンパイルは完全に信頼できる環境でのみ使用し、マルチユーザー環境や本番環境のデプロイでは Sandbox Compiles を強く推奨します。

Sandbox Compiles の詳細については、[sandboxed-compiles.md](/ja/on-premises/configuration/overleaf-toolkit/sandboxed-compiles  "mention") を参照してください。

</Warning>

### Overleaf Server Pro の情報と価格

Overleaf の Web サイトには Server Pro のサポート窓口への入口しかないため、Server Pro に関する情報は非常に限られています。しかし、コミュニティで収集した情報によると、**Server Pro の条件**は次のとおりです。

* _最低_ 10 人分のライセンスを購入する必要があります。
* 10 人分のライセンスは約 €3,477.61 です（2024 年）。
* 教育機関向けでは、20 ユーザーで年間 2640 ユーロ、50 ユーザーで 6050 ユーロ、100 ユーザーで 9963 ユーロです。
* Server Pro は一部の地域でのみ提供されています（例: 中国本土は対象外）。

現在入手できる情報に基づくと、Overleaf Server Pro の費用はユーザー 1 人あたり年間約 \$300 で、最低 10 ライセンスの購入が必要なため、非常に高価な選択肢です。さらに、Server Pro が提供する機能は Ayakaleaf Pro よりも大幅に少なくなっています。長年にわたるコミュニティ開発者の貢献のおかげで、私たちは Ayakaleaf Pro を構築し、最終的に機能と性能の両面で Overleaf Server Pro を上回ることができました。心より感謝いたします。

### なぜ Ayakaleaf Pro なのか？

<Info>

Ayakaleaf Pro は Overleaf, Inc. およびその親会社である Digital Science とは _**一切関係ありません**_。また、Overleaf, Inc. が提供する商用製品である _Server Pro_ Edition _でもありません_。Ayakaleaf Pro は [ayaka-notes](https://github.com/ayaka-notes) が独立したプロジェクトとして開発・保守しています。

</Info>

Ayakaleaf Pro は Overleaf Community Edition の拡張実装であり、Server Pro の _**すべての**_ プレミアム機能を _**無料**_ で提供します。[https://www.overleaf.com/](https://www.overleaf.com/) で利用できる Overleaf Common や、商用版の Server Pro とは異なり、次の特長があります。

* コンパイル時間に _**制限なし**_
* ユーザー数に応じた _**ライセンス不要**_
* Server Pro の _**すべての機能**_ を解放

さらに、データを完全にセルフホストできるため、万全のセキュリティを確保できます。詳しくは次を参照してください。
