---
title: プロジェクトのエクスポート
icon: file-export
---

Server Pro および Community Edition `5.4.0` には、管理者がすべてのユーザープロジェクト（**Deleted** および **Trashed** フォルダーにまだ表示されているものを含む）をディスク上のディレクトリにエクスポートできるスクリプトが含まれています。

<Info>

このスクリプトの実行結果は、ユーザーのプロジェクトダッシュボードからすべてのプロジェクトの Zip を手動でダウンロードした場合と同じです。スクリプトはダウンロードを開始する前に保留中の変更をフラッシュするため、エクスポートにはプロジェクトの最新バージョンが含まれます。

</Info>

### 制限事項

エクスポートスクリプトには次の制限があります。

* TeX Live イメージ名やコンパイラーなどのプロジェクト設定はエクスポートされません。これらは、プロジェクトをユーザーのアカウントにアップロードする際に設定する必要があります。
* エクスポートされたプロジェクトにはバージョン履歴が含まれません。
* 共同編集者の情報は保持されません。プロジェクトは再共有する必要があります。リンク共有を使用している場合、閲覧用および編集用のリンクは再生成されます（以前と同じものにはなりません）。
* コメントや変更履歴（トラックチェンジ）の情報はエクスポートされません。
* プロジェクトのチャット履歴はエクスポートされません。

<Danger>

このスクリプトは、システム全体のバックアップの代わりとして設計されたものでは**ありません**。災害復旧の際にインスタンスを確実に復元できるよう、[一貫性のあるバックアップ](https://docs.overleaf.com/on-premises/maintenance/#performing-a-consistent-backup)を取得することを**強く**お勧めします。

</Danger>

### **フラグ**

| 名前           | 説明                                                                                       |
| -------------- | ------------------------------------------------------------------------------------------ |
| `--help`       | ヘルプを表示                                                                               |
| `--user-id`    | ユーザー ID（`--export-all` または `--project-id` を使用しない場合は必須）                 |
| `--project-id` | 単一のプロジェクトをエクスポート（`--user-id` や `--export-all` とは併用**できません**）   |
| `--list`       | ユーザーのプロジェクトを一覧表示（`--output` とは併用**できません**）                      |
| `--output`     | 出力する zip ファイル（単一のエクスポート操作用）                                          |
| `--export-all` | 全ユーザーのプロジェクトをエクスポート（`--output-dir` が必要）                            |
| `--output-dir` | 全ユーザーのエクスポートファイルを保存するディレクトリ                                     |
| `--log-level`  | サポートされているログレベル: `trace`\|`debug`\|`info`\|`warn`\|`error`\|`fatal`           |

### **使用方法**

全ユーザーのプロジェクトをエクスポートするには、次のコマンドを使用します。

```bash wrap
# Overleaf Toolkit users
$ bin/docker-compose exec sharelatex /bin/bash -ce "cd /overleaf/services/web && node modules/server-ce-scripts/scripts/export-user-projects.mjs --export-all --output-dir=/var/lib/overleaf/data/exports"

# Legacy docker-compose.yml users
docker exec sharelatex /bin/bash -ce "cd /overleaf/services/web && node modules/server-ce-scripts/scripts/export-user-projects.mjs --export-all --output-dir=/var/lib/overleaf/data/exports"
```

<Info>

Server Pro または Community Editition &lt;= 3.5.13 を実行している場合は、上記の例を **`export-legacy-user-projects.js`** スクリプトを使用するように変更する必要があります。

</Info>

### **完了**

エクスポートが完了したら、**docker-compose.yml** ファイルで **/var/lib/overleaf** にバインドマウントされているホスト上のディレクトリ、または Toolkit を使用している場合は **config/overleaf.rc** ファイルの `OVERLEAF_DATA_PATH` 環境変数で指定されたディレクトリからファイルにアクセスできます。

<Info>

現在、Overleaf では重複したプロジェクト名が許可されています。ユーザーのプロジェクトに重複がある場合、それらのプロジェクトはユーザーの Zip エクスポートに追加されますが、展開すると 1 つのバージョンのみが残ります。Linux では、`unzip -B` を使用すると、同名のファイルを上書きせずにバックアップファイルとして書き出します。

</Info>
