### アカウント

自分自身のアカウントの管理という観点では、**すべての**ユーザーは一般ユーザーとして扱われます。`Site Admins` や `Template Users` に追加の権限が付与されることは**ありません**。ただし、認証方法によっては、一般ユーザーが実行できる操作に制限があります。

#### 設定

<strong>認証の種類: 内部アカウント | SSO（SAML/LDAP）</strong>

| 操作 | 内部アカウント | SSO（SAML/LDAP） |
| ----------------------------------------- | ----------------: | --------------: |
| アカウント情報の更新 | はい | いいえ |
| パスワードの変更 | はい | いいえ |
| Git bridge 認証トークンの生成 | はい | はい |
| Git bridge 認証トークンの削除 | はい | はい |
| セッションの管理 | はい | はい |

<Info>

Git Bridge 連携は Server Pro で**のみ**利用できます。詳細は [Server Pro と Community Edition の比較](/ja/on-premises/readme/ayakaleaf-pro-vs-server-pro) を確認してください。

</Info>

#### セッション

| 操作 | ユーザー |
| -------------------- | ---: |
| セッションのクリア | はい |
| 現在のセッションの表示 | はい |
| 他のセッションの表示 | はい |

### エディター IDE

Overleaf エディター IDE の観点では、ユーザーは `Project Owner`、`Editor`、`Reviewer`、`Viewer`、`Site Administrator`、`Template User` のいずれかのロールを持ちます。

<Info>

Server Pro と Community Edition では、プロジェクトへの匿名の**読み取り専用**アクセスおよび**読み書き**アクセスを提供する機能がサポートされています。

詳細については、[こちら](/ja/on-premises/configuration/overleaf-toolkit/environment-variables) の `OVERLEAF_ALLOW_PUBLIC_ACCESS` および `OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` 環境変数を確認してください。

</Info>
