---
title: Server Pro から Group Professional への移行
icon: rectangle-pro
noindex: true
---

セルフホストの Server Pro インスタンスから、クラウドベースの新しい Overleaf Group Professional サブスクリプションへの切り替えは大きな変更です。このプロセスをできるだけスムーズに進められるよう、以下のガイダンスをまとめました。

一般的には、更新日から始まる 3 か月間の並行稼働期間を設けることを提案しています。これにより、次のことが可能になります：

* 既存の Server Pro インスタンスと新しい Group Professional サブスクリプションの両方が完全に有効な状態になります。
* 技術チームは、Group Professional サブスクリプションのセットアップに時間を確保し、オンプレミスの Server Pro 導入環境の今後について決定できます。
* 最も重要な点として、ユーザーは自分のプロジェクトを新しい Overleaf Group Professional プラットフォームにコピーするための十分な時間を確保できます。

このクイックガイドでは、この移行の主な手順を説明します。それでは始めましょう！

<Steps>
<Step title="フェーズ 1：セットアップと設定">
(Link: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-1-setup-and-configuration)

* Overleaf が Group Professional サブスクリプションを作成し、リード管理者を追加します。
* グループ管理者は、[管理ユーザーarrow-up-right](https://docs.overleaf.com/groups/user-management/managed-user-accounts)の有効化、[シングルサインオン（SSO）arrow-up-right](https://docs.overleaf.com/groups/overleaf-group-single-sign-on/setting-up-group-sso)の設定、[エンドユーザーの招待arrow-up-right](https://docs.overleaf.com/groups/user-management/how-to-add-and-remove-users)を行えるようになります。

<Warning>

管理ユーザーの有効化と SSO の導入は、FedRAMP® LI-SaaS に準拠するために必須の手順です。組織で FedRAMP への準拠が求められる場合は、エンドユーザーを招待する前に管理ユーザーと SSO を設定してください。

</Warning>
</Step>

<Step title="フェーズ 2：ユーザーの移行とデータ管理">
(Link: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-2-user-migration-and-data-management)

これが主要な移行期間であり、次のような役割分担があります：

#### エンドユーザー

* ユーザーは、保持したいプロジェクトを Server Pro インスタンスから [overleaf.comarrow-up-right](http://overleaf.com/) 上の新しいアカウントに移行する必要があります。このプロセスでは、Server Pro から[プロジェクトをエクスポートarrow-up-right](https://www.overleaf.com/learn/how-to/Exporting_your_work_from_Overleaf)し、[overleaf.comarrow-up-right](http://overleaf.com/) 上の自分のアカウントに[アップロードarrow-up-right](https://www.overleaf.com/learn/how-to/Uploading_a_project)します。[overleaf.comarrow-up-right](http://overleaf.com/) のアカウントをまだ持っていないユーザーは、[overleaf.com/registerarrow-up-right](http://overleaf.com/register) で登録できます。

<Warning>

このエクスポート手順で転送されるのは、プロジェクトのソースコード（LaTeX ファイルとバイナリファイル）のみです。既存のプロジェクト設定、共有設定、コメント、変更履歴の追跡などは転送されません。ユーザーは移行後に共同編集者を再度招待する必要があります。

</Warning>

#### 技術スタッフ

* このフェーズでは、技術チームは移行後のオンプレミス Server Pro インスタンスとそのデータの扱いについて計画する必要があります。
* **データのバックアップ：** 廃止する前にすべてのプロジェクトをエクスポートしてアーカイブを作成しておくと、作業の移行やダウンロードを忘れたユーザーを支援できます。手順：https://docs.overleaf.com/on-premises/maintenance/data-and-backups/exporting-projects
* **Server Pro の廃止：** 移行期間が終了し、ライセンスキーが無効化された後、Server Pro インスタンス自体については主に 2 つの選択肢があります（次のステップを参照）。
</Step>

<Step title="Server Pro の廃止オプション">
<Steps>
<Step title="Server Pro を完全にアンインストールする">
アンインストールすると、Server Pro は廃止され、ソフトウェアは完全に削除されます。
</Step>

<Step title="Community Edition に切り替える">
切り替えを行うと、インスタンスが Server Pro から Community Edition に変換され、ユーザーとプロジェクトのデータベースが完全なプロジェクト履歴とともに保持されます。
</Step>
</Steps>

<Info>

Community Edition には、[サンドボックスコンパイルarrow-up-right](https://docs.overleaf.com/on-premises#overview-of-server-pro-and-community-edition)も [LDAP](/ja/on-premises/configuration/overleaf-toolkit/authentication/ldap-authentication)/[SAML](/ja/on-premises/configuration/overleaf-toolkit/authentication/saml-authentication) も含まれて**いません**。ネイティブ認証（ユーザー名／パスワード）に戻す必要がある場合は、次を参照してください：https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-to-ldap-or-saml#going-the-other-way-switching-from-ldap-saml-back-to-native-authentication

Server CE と Server Pro の比較については、次を参照してください：https://docs.overleaf.com/on-premises/welcome/server-pro-vs.-community-edition

</Info>
</Step>

<Step title="フェーズ 3：Server Pro の廃止">
(Link: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-3-server-pro-decommission)

* Overleaf チームが Server Pro のライセンスキーを正式に無効化し、完了後に確認の連絡を送ります。
* その時点で、上記の廃止作業のいずれか（Server Pro を完全にアンインストールする、または Community Edition に切り替える）を実行してください。
</Step>
</Steps>

上記で参照している追加リソースとリンクは変更されていません。
