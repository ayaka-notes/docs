---
title: Server Pro から Group Professional への移行
icon: rectangle-pro
noindex: true
---

セルフホストの Server Pro インスタンスから、クラウドベースの新しい Overleaf Group Professional サブスクリプションへの切り替えは大きな変更です。このプロセスをできるだけスムーズに進められるよう、以下のガイダンスをまとめました。

一般的に、更新日から 3 か月間の並行運用期間を設けることを提案しています。これにより、次のことが可能になります：

* 既存の Server Pro インスタンスと新しい Group Professional サブスクリプションの両方が完全に有効な状態になります。
* 技術チームは、Group Professional サブスクリプションのセットアップに時間を確保し、Server Pro のオンプレミス環境を今後どうするかを決定できます。
* 最も重要な点として、ユーザーは新しい Overleaf Group Professional プラットフォームにプロジェクトをコピーするための十分な時間を確保できます。

このクイックガイドでは、この移行の主要な手順を説明します。それでは始めましょう！

<Steps>
<Step title="フェーズ 1：セットアップと設定">
（リンク：https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-1-setup-and-configuration）

* Overleaf が Group Professional サブスクリプションを作成し、リード管理者を追加します。
* グループ管理者は、[管理対象ユーザー](https://docs.overleaf.com/groups/user-management/managed-user-accounts)の有効化、[シングルサインオン（SSO）](https://docs.overleaf.com/groups/overleaf-group-single-sign-on/setting-up-group-sso)の設定、[エンドユーザーの招待](https://docs.overleaf.com/groups/user-management/how-to-add-and-remove-users)を行うことができます。

<Warning>

管理対象ユーザーの有効化と SSO の導入は、FedRAMP® LI-SaaS への準拠に必要な手順です。組織で FedRAMP への準拠が必要な場合は、エンドユーザーを招待する前に管理対象ユーザーと SSO をセットアップしてください。

</Warning>
</Step>

<Step title="フェーズ 2：ユーザーの移行とデータ管理">
（リンク：https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-2-user-migration-and-data-management）

これは主要な移行期間であり、次の役割分担があります：

#### エンドユーザー

* ユーザーは、保持したいプロジェクトを Server Pro インスタンスから [overleaf.com](http://overleaf.com/) 上の新しいアカウントに移行する必要があります。この手順では、Server Pro から[プロジェクトをエクスポート](https://www.overleaf.com/learn/how-to/Exporting_your_work_from_Overleaf)し、[overleaf.com](http://overleaf.com/) 上の自分のアカウントに[アップロード](https://www.overleaf.com/learn/how-to/Uploading_a_project)します。[overleaf.com](http://overleaf.com/) のアカウントをまだ持っていないユーザーは、[overleaf.com/register](http://overleaf.com/register) で登録できます。

<Warning>

このエクスポート手順で移行されるのは、プロジェクトのソースコード（LaTeX ファイルとバイナリファイル）のみです。既存のプロジェクト設定、共有設定、コメント、変更履歴の追跡などは移行**されません**。ユーザーは移行後に共同編集者を再度招待する必要があります。

</Warning>

#### 技術スタッフ

* このフェーズでは、技術チームは移行後のオンプレミス Server Pro インスタンスとそのデータの扱いについて計画を立てる必要があります。
* **データのバックアップ：** 廃止する前にすべてのプロジェクトをエクスポートしてアーカイブを作成しておくと、作業の移行やダウンロードを忘れたユーザーを支援できます。手順：https://docs.overleaf.com/on-premises/maintenance/data-and-backups/exporting-projects
* **Server Pro の廃止：** 移行期間が終了し、ライセンスキーが無効化された後、Server Pro インスタンス自体については主に 2 つの選択肢があります（次のステップを参照）。
</Step>

<Step title="Server Pro の廃止方法の選択肢">
<Steps>
<Step title="Server Pro を完全にアンインストールする">
アンインストールすると、Server Pro が廃止され、ソフトウェアが完全に削除されます。
</Step>

<Step title="Community Edition に切り替える">
切り替えを行うと、インスタンスを Server Pro から Community Edition に変換することで、完全なプロジェクト履歴を含むユーザーとプロジェクトのデータベースが保持されます。
</Step>
</Steps>

<Info>

Community Edition には、[サンドボックスコンパイル](https://docs.overleaf.com/on-premises#overview-of-server-pro-and-community-edition)や [LDAP](/ja/on-premises/configuration/overleaf-toolkit/authentication/ldap-authentication)/[SAML](/ja/on-premises/configuration/overleaf-toolkit/authentication/saml-authentication) は含まれて**いません**。ネイティブ認証（ユーザー名／パスワード）に戻す必要がある場合は、次を参照してください：https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-to-ldap-or-saml#going-the-other-way-switching-from-ldap-saml-back-to-native-authentication

Server CE と Server Pro の比較については、次を参照してください：https://docs.overleaf.com/on-premises/welcome/server-pro-vs.-community-edition

</Info>
</Step>

<Step title="フェーズ 3：Server Pro の廃止">
（リンク：https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-3-server-pro-decommission）

* Overleaf チームが Server Pro のライセンスキーを正式に無効化し、完了後に確認の連絡を送ります。
* その時点で、上記の廃止方法のいずれか（Server Pro を完全にアンインストールする、または Community Edition に切り替える）を実行してください。
</Step>
</Steps>

上記で参照されている追加のリソースとリンクは変更されていません。
