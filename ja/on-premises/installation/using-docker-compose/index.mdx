単一サーバー上の Docker Compose は、Ayakaleaf Pro をデプロイするための推奨される方法です。デプロイは [Toolkit](https://github.com/ayaka-notes/toolkit) を通じて行います。Toolkit は `docker compose` をラップし、1 つの `config/` ディレクトリから設定を読み込むスクリプト群で、`docker compose up` の代わりに `bin/up` を使用します。
