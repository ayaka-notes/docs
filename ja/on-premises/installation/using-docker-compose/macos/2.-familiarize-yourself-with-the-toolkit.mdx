Toolkit は macOS でも Linux でも同じです。その構成、`config/` ディレクトリ、`bin/` のコマンドについては、Linux ガイドの [2. Toolkit に慣れる](/ja/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit)で説明しています。

macOS では、次の 3 つの違いに注意してください:

* GNU sed が `PATH` の先頭にあるターミナルからスクリプトを実行してください。[1. Toolkit をダウンロードする](/ja/on-premises/installation/using-docker-compose/macos/1.-download-the-toolkit)を参照してください。
* `bin/up`、`bin/start`、`bin/docker-compose` など、Docker とやり取りするスクリプトを実行する前に Docker Desktop を起動してください。
* `bin/doctor` には、公式の Overleaf Toolkit から引き継いだチェックが含まれています。`This system seems to not be Linux` という警告は macOS では想定どおりであり、`quay.io` にログインしていないという警告は公開されている `ghcr.io/ayaka-notes/overleaf-pro` イメージには関係ありません。レポート内のその他の問題は引き続き重要です。
