---
title: 1. Toolkit をダウンロードする
description: Mac に GNU sed をインストールし、Ayakaleaf Toolkit をクローンします。
icon: arrow-down-to-bracket
---

<Steps>
<Step title="Git と Homebrew を確認する">
```bash
git --version
brew --version
```

Git を実行したときに macOS からコマンドラインツールのインストールを求められた場合は、先にインストールしてください。Homebrew がない場合は、[公式の手順](https://brew.sh/)に従ってインストールしてください。
</Step>

<Step title="GNU sed を PATH に追加する">
Toolkit のスクリプトは、macOS に組み込まれている BSD sed では受け付けられない GNU sed のオプションを使用します。[GNU sed](https://formulae.brew.sh/formula/gnu-sed) をインストールし、このターミナルで `PATH` の先頭に追加してください:

```bash
brew install gnu-sed
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
sed --version
```

最後のコマンドで **GNU sed** と表示されるはずです。

`alias sed=gsed` のようなエイリアスでは不十分です。Toolkit は Bash スクリプトを実行しますが、Bash スクリプトからは対話シェルのエイリアスが見えません。`/usr/bin/sed` を置き換える必要はありません。

Toolkit に使用する新しいターミナルごとに `export PATH=...` の行を再度実行するか、Homebrew 自体の初期化処理の後に、シェルの起動ファイルへ追加してください。
</Step>

<Step title="Ayakaleaf Toolkit リポジトリをクローンする">
永続的なディレクトリを選んでください。稼働中のデータベースやプロジェクトデータには、`/tmp`、リムーバブルドライブ、iCloud Drive などのクラウド同期フォルダーを使用しないでください。このガイドでは `~/ayakaleaf-toolkit` を使用します:

```bash
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

<Warning>

ディレクトリにすでにインストールが含まれている場合は、そのまま使用するか、新しいインスタンス用に別のディレクトリを選んでください。既存のデプロイの上に新しい設定を初期化しないでください。

</Warning>
</Step>
</Steps>
