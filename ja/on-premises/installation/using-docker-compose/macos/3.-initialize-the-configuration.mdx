---
title: 3. 設定の初期化
description: bin/init を使用して、Mac 上で Toolkit の設定ファイルを作成します。
icon: circle-play
---

Toolkit のディレクトリで、GNU sed が `PATH` に含まれているターミナルから次のコマンドを実行します:

```bash
bin/init
```

`bin/init` は次の 3 つのファイルを作成します:

| ファイル | 用途 |
| --- | --- |
| `config/overleaf.rc` | コンテナの設定、公開ポート、データの保存場所 |
| `config/variables.env` | アプリケーションの設定とシークレット |
| `config/version` | アプリケーションイメージのバージョン |

また、`config/variables.env` に `OVERLEAF_INVITE_TOKEN_SECRET` を生成します。この値は保持し、このファイルを公開したりバージョン管理にコミットしたりしないでください。

新規インストールでは、Toolkit が選択したバージョンをそのまま使用してください。既存のインスタンスのバージョンを後で変更するには、[デプロイのアップグレード](/ja/on-premises/maintenance/upgrading-your-deployment)に従ってください。

<Warning>

`bin/init` が `sed: ... invalid command code` で停止した場合、macOS の BSD sed で実行されています。このように失敗した実行では、`config/` に 3 つのファイルがすべて作成されたまま `OVERLEAF_INVITE_TOKEN_SECRET` が空になることがあり、その後 `bin/init` を再度実行すると `Config files already exist` と表示されます。[トラブルシューティング](/ja/on-premises/installation/using-docker-compose/macos/troubleshooting#initialization-fails-with-invalid-command-code)を参照してください。

</Warning>
