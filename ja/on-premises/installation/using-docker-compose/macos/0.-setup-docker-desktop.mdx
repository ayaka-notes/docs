Ayakaleaf Pro は Docker 上で動作します。Mac では Docker Desktop を使用します。Docker Desktop は Docker エンジンを Linux 仮想マシン内で実行します。

<Steps>
<Step title="Docker Desktop をインストールして起動する">
お使いの Mac（Apple シリコンまたは Intel）向けの [Docker Desktop](https://docs.docker.com/desktop/setup/install/mac-install/) をインストールして開き、エンジンが起動するまで待ちます。ターミナルから起動することもできます:

```bash
open -a Docker
```
</Step>

<Step title="Docker エンジンを確認する">
ターミナルで次のコマンドを実行します:

```bash
docker context show
docker info
docker compose version
```

コンテキストはローカルの Docker Desktop エンジン（通常は `desktop-linux`）を指している必要があります。別のコンテキストが選択されている場合は、続行する前に Docker Desktop に切り替えてください:

```bash
docker context use desktop-linux
```

`docker info` は **Server** セクションを出力する必要があります。`docker --version` だけでは、クライアントがインストールされていることしかわかりません。
</Step>

<Step title="リソースとファイル共有を確認する">
Docker Desktop の **Settings** で、CPU、メモリ、ディスクの上限を[始める前に](/ja/on-premises/installation/using-docker-compose/macos#before-you-start)と照らし合わせて確認し、ファイル共有の設定も確認してください。[Docker Desktop の設定](https://docs.docker.com/desktop/settings-and-maintenance/settings/)を参照してください。

このガイドでは Toolkit を `/Users` 以下に置きます。このディレクトリは Docker Desktop がデフォルトで共有しています。別の場所を使用していて `bin/up` が `Mounts denied` で失敗する場合は、そのディレクトリをファイル共有に追加してください。
</Step>

<Step title="サンドボックスコンパイル用の Docker ソケットを確認する">
Toolkit は `/var/run/docker.sock` をアプリケーションにマウントし、コンパイルごとに個別の TeX Live コンテナを起動できるようにします。`config/overleaf.rc` の `DOCKER_SOCKET_PATH=/var/run/docker.sock` はそのままにしてください。

macOS の Docker CLI は `~/.docker/run/docker.sock` を通じて接続する場合があります。これは Mac 上のクライアント側のエンドポイントであり、Toolkit のマウント元を変更する理由にはなりません。コンパイラーには、Linux コンテナから見えるエンジンのソケットが必要です。

Mac に `/var/run/docker.sock` が存在しない場合は、**Settings → Advanced** で **Allow the default Docker socket to be used** をオンにしてください。[Docker の権限要件](https://docs.docker.com/desktop/setup/install/mac-permission-requirements/)を参照してください。

<Danger>

エラーを回避するためにソケットに `chmod 777` を実行しないでください。Docker ソケットへのアクセスは、Docker VM への root 相当のアクセスです。

</Danger>
</Step>
</Steps>
