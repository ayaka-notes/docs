このセクションでは、Docker Desktop と [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit) を使用して、Mac 上でローカルに Ayakaleaf Pro を実行します。このガイドでは `http://localhost:8080` を使用し、データをホームディレクトリに保存し、サンドボックス化されたコンテナ内の TeX Live 2026 でコンパイルします。

Docker Desktop は、アプリケーション、MongoDB、Redis、TeX Live コンパイラーを Linux 仮想マシン内で実行します。macOS 自体に MongoDB、Redis、MacTeX をインストールする必要はありません。

この構成は個人での使用やローカルでのテストに使用してください。常時稼働する共有サービスには、HTTPS、バックアップ、アクセス制御を備えた [Linux ガイド](/ja/on-premises/installation/using-docker-compose/linux)をおすすめします。Mac がスリープしている間や Docker Desktop が停止している間は、インスタンスを利用できません。[インスタンスを利用可能な状態に保つ](/ja/on-premises/installation/using-docker-compose/macos/6.-post-installation-tasks#keep-the-instance-available)を参照してください。

## 始める前に {#before-you-start}

必要なもの:

* [Docker Desktop for Mac](https://docs.docker.com/desktop/setup/install/mac-install/) がサポートする macOS のバージョン。
* Git、[Homebrew](https://brew.sh/)、GNU sed。Toolkit は、macOS に組み込まれている BSD sed では受け付けられない GNU sed のオプションを使用します。
* macOS と Docker の両方に十分なリソース。小規模なローカルインスタンスの場合は、まず Docker Desktop に 4 CPU と 8 GB のメモリを割り当ててください。これは推奨される出発点であり、測定された最小要件ではありません。
* フル TeX Live イメージ用に少なくとも 40 GB の空きストレージと、プロジェクト用の容量。Mac の空き容量と Docker Desktop のディスク使用量の上限の両方を確認してください。まずは 1 つの TeX Live バージョンから始めてください。バージョンを追加するたびに、ほぼ同じ容量が追加で必要になります。

アプリケーションと TeX Live のイメージは `arm64` と `amd64` 向けに公開されています。Apple シリコンでは、Docker にネイティブの ARM イメージを選択させ、`platform: linux/amd64` を強制しないでください。
