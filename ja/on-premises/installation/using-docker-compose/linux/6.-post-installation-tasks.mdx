### 最初の管理者アカウントを作成する {#creating-your-first-administrator-account}

ブラウザで [http://localhost/launchpad](http://localhost/launchpad) を開きます。`OVERLEAF_LISTEN_IP` または `OVERLEAF_PORT` を変更した場合は、代わりに `OVERLEAF_SITE_URL` を使用してください(例: `http://192.168.1.20:8080/launchpad`)。このページの他の `localhost` リンクについても同様です。メールアドレスとパスワードの入力欄があるフォームが表示されるはずです。管理者アカウントとして使用する認証情報を入力し、**Register** をクリックします。

<Info>

パスワードは 8 文字以上（72 文字以下）である必要があり、メールアドレスを含めたりメールアドレスに似すぎたりしてはならず、有効な文字のみを含む必要があります。

</Info>

![ランチパッドで最初の管理者アカウントを作成する](/images/on-premises/post-installation-launchpad.png)

その後、ログインページ（[http://localhost/login](http://localhost/login)）に移動します。認証情報を入力してログインすると、再びランチパッドが表示され、今度はステータスチェックが表示されます。

![ログイン後のランチパッドのステータスチェック](/images/on-premises/post-installation-status-checks.png)

ページ下部の緑色のボタンをクリックして、Overleaf の使用を開始します。

### 最初のサンプルプロジェクトを作成する {#creating-your-first-example-project}

ブラウザで [http://localhost/project](http://localhost/project) を開くと、最初のプロジェクトの作成を促すボタンが表示されます。

![新規プロジェクト作成メニュー](/images/on-premises/post-installation-create-project.png)

このボタンをクリックし、**Example project** を選択して、画面の指示に従います。

新しいプロジェクトが開き、テキストエディターと PDF プレビューが表示されます。

![エディターで開いたサンプルプロジェクト](/images/on-premises/post-installation-editor.png)

最後に、左上隅の Overleaf ロゴをクリックするとプロジェクトページに戻れます。
