### Toolkit のダウンロード {#downloading-the-toolkit}

Ayakaleaf Pro は **Ayakaleaf Toolkit**（[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)）を使ってインストールします。これは、Overleaf を Docker で実行するためのスクリプト一式です。

デフォルトでは、Toolkit は無料の公式 Overleaf Community Edition（CE）を起動します。[4. Ayakaleaf Pro イメージの取得](/ja/on-premises/installation/using-docker-compose/linux/4.-get-overleaf-pro-images)で 1 つの設定を変更するだけで、Ayakaleaf Pro に切り替えられます。

<Accordion title="すでに公式の Overleaf Toolkit（overleaf/toolkit）を実行していますか?">

再インストールする必要はありません。現在のインストールをそのまま使い、[4. Ayakaleaf Pro イメージの取得](/ja/on-premises/installation/using-docker-compose/linux/4.-get-overleaf-pro-images)の最後の部分の手順に従ってください。

</Accordion>

<Steps>
<Step title="Ayakaleaf Toolkit リポジトリをクローンする">
Toolkit をインストールするには、インストール先のパスに移動し、次のコマンドで Ayakaleaf Toolkit リポジトリをクローンします。

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
```

<Info>

パーミッションに関する問題を防ぐため、Toolkit はユーザーの `$HOME` ディレクトリにインストールすることをおすすめします。

</Info>
</Step>

<Step title="toolkit ディレクトリに移動する">
クローンが完了するまで待ってから、新しく作成された `overleaf-toolkit` ディレクトリに移動しましょう。

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
