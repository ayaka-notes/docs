---
title: 4. Ayakaleaf Pro イメージの取得
icon: split
---

Ayakaleaf Pro は [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/) で公開されている無料の Docker イメージです。pull するのにアカウントやログインは必要ありません。イメージは amd64 と arm64 向けにビルドされており、Docker がサーバーに合ったものを自動的に選択します。

`config/overleaf.rc` を開き、次のように設定します：

```text title="config/overleaf.rc"
SERVER_PRO=true
```

次に `bin/up` を実行すると、Toolkit は Ayakaleaf Pro イメージをダウンロードし、公式の Overleaf Community Edition の代わりに使用します。`config/` 内の設定はそのまま機能します。

<Accordion title="すでに公式の Overleaf Toolkit（overleaf/toolkit）を実行していますか?">

再インストールする必要はありません。Ayakaleaf Pro イメージを pull します：

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

次に、以下の内容で `docker-compose.override.yml` という名前のファイルを `overleaf-toolkit/config` ディレクトリに追加します：

```yml
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

次に `bin/up` を実行すると、Toolkit は Ayakaleaf Pro イメージを使用します。

</Accordion>
