このセクションでは、Docker のインストール、GitHub からの Toolkit のダウンロード、Toolkit のいくつかのコマンドの習得、基本的な設定の手順を説明します。このセクションを終えるころには、オンプレミスの Overleaf インスタンスが稼働しているはずです。

手順は最近の Ubuntu LTS を対象としています。他のディストリビューションでは、[Docker のドキュメント](https://docs.docker.com/engine/install/)の説明に従って Docker Engine と Compose プラグインをインストールしてから、[1. Toolkit をダウンロードする](/ja/on-premises/installation/using-docker-compose/linux/1.-download-the-toolkit)に進んでください。

<Info>

デフォルトでは、インスタンスはサーバー自体からの `http://localhost` での接続のみを受け付けます。他のコンピューターから、または別のポートで開くには、[5. インスタンスのカスタマイズ](/ja/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance)で説明しているように、`config/overleaf.rc` で `OVERLEAF_LISTEN_IP` と `OVERLEAF_PORT` を設定してください。

</Info>
