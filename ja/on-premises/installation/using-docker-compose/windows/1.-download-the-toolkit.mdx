---

<Steps>
<Step title="コマンドラインツールをインストールする">
**Ubuntu** で、ステップ 0 で作成した Linux のパスワードを使用して次を実行します:

```bash
sudo apt update
sudo apt install -y git ca-certificates curl perl gawk openssl
```

Ubuntu には Bash、GNU sed、coreutils がすでに含まれています。macOS とは異なり、Homebrew や GNU sed を別途インストールする必要はありません。
</Step>

<Step title="Ayakaleaf Toolkit リポジトリをクローンする">
Toolkit とそのデータは、Ubuntu の Linux ファイルシステム上のホームディレクトリ以下に置いてください:

```bash
cd "$HOME"
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

稼働中のデータベースやプロジェクトデータには、`/mnt/c`、`/mnt/d`、OneDrive、一時ディレクトリを使用しないでください。Linux ファイルシステムのパスは、コンテナが想定する権限とファイルシステムの動作を提供し、ファイルシステムをまたぐオーバーヘッドを回避できます。[Microsoft のファイルシステムに関するガイダンス](https://learn.microsoft.com/en-us/windows/wsl/filesystems)を参照してください。

<Warning>

ディレクトリにすでにインストールが含まれている場合は、そのまま使用するか、新しいインスタンス用に別のディレクトリを選んでください。既存のデプロイの設定やデータを置き換えないでください。

</Warning>
</Step>
</Steps>
