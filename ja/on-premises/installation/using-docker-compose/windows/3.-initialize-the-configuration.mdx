---
title: 3. 設定の初期化
description: bin/init を使用して、WSL 2 上の Ubuntu で Toolkit の設定ファイルを作成します。
icon: circle-play
---

**Ubuntu** で Toolkit のディレクトリから、次のコマンドを実行します:

```bash
bin/init
```

`bin/init` は次の 3 つのファイルを作成します:

| ファイル | 用途 |
| --- | --- |
| `config/overleaf.rc` | コンテナの設定、公開ポート、データの保存場所 |
| `config/variables.env` | アプリケーションの設定とシークレット |
| `config/version` | アプリケーションイメージのバージョン |

また、`config/variables.env` に `OVERLEAF_INVITE_TOKEN_SECRET` を生成します。この値は保持し、このファイルを公開したりバージョン管理にコミットしたりしないでください。

新規インストールでは、Toolkit が選択したバージョンをそのまま使用してください。既存のインスタンスのバージョンを後で変更するには、[デプロイのアップグレード](/ja/on-premises/maintenance/upgrading-your-deployment)に従ってください。

<Info>

`bin/init` は既存の設定を上書きしません。ファイルがすでに存在すると報告された場合は、続行する前に内容を確認してください。インスタンスを再起動またはアップグレードする際は、`config/` と `data/` を保持してください。

</Info>
