Toolkit は Linux と同じです。その構成、`config/` ディレクトリ、`bin/` のコマンドについては、Linux ガイドの [2. Toolkit に慣れる](/ja/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit)で説明しています。

Windows では、次の違いに注意してください:

* `bin/` のコマンドは、`~/ayakaleaf-toolkit` から **Ubuntu の Bash** で実行してください。**PowerShell** と記載されているコマンドは Windows で実行します。
* `bin/up`、`bin/start`、`bin/docker-compose` を使用する前に、Docker Desktop を起動し、Ubuntu の WSL Integration を有効にしてください。
* 設定ファイルは Linux の改行コード（LF）のままにしてください。Ubuntu の `nano` や WSL に接続したエディターで編集してください。CRLF の改行コードは Bash のエラーの原因になります。
* `bin/doctor` は Ubuntu 内で Linux のチェックを実行します。`quay.io` にログインしていないという警告は、公開されている `ghcr.io/ayaka-notes/overleaf-pro` イメージには関係ありません。その他の警告には引き続き対処が必要です。

```bash
bin/doctor
```
