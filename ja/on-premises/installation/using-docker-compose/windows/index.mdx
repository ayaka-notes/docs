このセクションでは、WSL 2、Ubuntu、Docker Desktop、[Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit) を使用して、Windows 上でローカルに Ayakaleaf Pro を実行します。このガイドでは `http://localhost:8080` を使用し、データを Ubuntu のホームディレクトリに保存し、サンドボックスコンパイルを有効にします。

アプリケーション、MongoDB、Redis、TeX Live は、Docker Desktop が管理する Linux コンテナ内で実行されます。Toolkit のコマンドは Ubuntu で実行し、アプリケーションは Windows のブラウザーで開きます。[ステップ 0](/ja/on-premises/installation/using-docker-compose/windows/0.-setup-wsl-and-docker-desktop) では、Windows と Linux の各部分がどのように連携するかを説明し、WSL のインストールから始めます。

Windows はローカルインスタンスとして使用することも、ステップ 6 の可用性の設定によって継続的に稼働させることもできます。共有サーバーや本番サーバーには、HTTPS、バックアップ、アクセス制御を備えた [Linux ガイド](/ja/on-premises/installation/using-docker-compose/linux)をおすすめします。Windows のスリープ、Docker Desktop のシャットダウン、WSL のシャットダウンにより、このローカルインスタンスは中断されます。[インスタンスを利用可能な状態に保つ](/ja/on-premises/installation/using-docker-compose/windows/6.-post-installation-tasks#keep-the-instance-available)を参照してください。

## 始める前に {#before-you-start}

必要なもの:

* [Docker Desktop for Windows](https://docs.docker.com/desktop/setup/install/windows-install/) がサポートする Windows のバージョンとプロセッサーで、ハードウェア仮想化が有効になっていること。このガイドでは x86-64 上の Windows 11 を使用します。
* WSL を有効にし、ソフトウェアをインストールする権限。WSL はバージョン 2.1.5 以降で、Ubuntu が WSL 2 モードで実行されている必要があります。
* Windows とコンテナに十分なメモリ。小規模なローカルインスタンスの場合、Docker で利用可能な 4 CPU と 8 GB は推奨される出発点であり、測定された最小要件ではありません。
* WSL と Docker のデータを保存する Windows のディスクの空きストレージ。フル TeX Live 構成とプロジェクトデータ用に少なくとも 40 GB を確保してください。[ステップ 5](/ja/on-premises/installation/using-docker-compose/windows/5.-personalizing-your-instance) の basic イメージはより小さく、最初のデプロイテストに適しています。イメージのバージョンを追加するには、追加の容量が必要です。
* Toolkit のクローンとイメージのダウンロードのための、GitHub、GitHub Container Registry（`ghcr.io`）、Docker Hub へのネットワークアクセス。

**PowerShell** のブロックは Windows で実行します。**Bash** のブロックと `bin/` のコマンドは、特に記載がない限り Ubuntu で実行します。Toolkit のスクリプトを PowerShell や Windows の Git Bash で実行しないでください。
