---
title: 4. Ayakaleaf Pro イメージの取得
description: WSL 2 上の Ubuntu の Toolkit を、公開されている Ayakaleaf Pro イメージに切り替えます。
icon: split
---

Ayakaleaf Pro は [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/) で公開されている無料の Docker イメージです。プルするのにアカウント、ログイン、商用の Overleaf ライセンスは必要ありません。

`config/overleaf.rc` を開き、次のように設定します:

```bash title="config/overleaf.rc"
SERVER_PRO=true
```

次に `bin/up` を実行すると、Toolkit は公式の Overleaf Community Edition の代わりに、`config/version` に記載されたバージョンの `ghcr.io/ayaka-notes/overleaf-pro` をプルします。

イメージは `arm64` と `amd64` 向けにビルドされており、Docker は Docker エンジンのアーキテクチャに合ったものを選択します。
