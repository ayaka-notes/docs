### 最初の管理者アカウントの作成 {#creating-your-first-administrator-account}

`OVERLEAF_SITE_URL` の後に `/launchpad` を付けたアドレス（例: `http://192.0.2.10:30080/launchpad`）を開き、[Toolkit のインストール後のタスク](/ja/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks)と同様に管理者アカウントを登録します。その後、サンプルプロジェクトを作成してコンパイルします。

コマンドラインからユーザーを作成することもできます。

```bash
kubectl -n overleaf exec deploy/overleaf -- bash -c \
  'cd /overleaf/services/web && node modules/server-ce-scripts/scripts/create-user.mjs --admin --email=admin@example.com'
```

パスワードを設定するためのリンクが出力されます。

### コンパイルがサンドボックス化されていることの確認 {#checking-that-compiles-are-sandboxed}

プロジェクトをコンパイルしてから、Pod を実行しているノードを確認します。

```bash
kubectl -n overleaf get pod -l app=overleaf -o wide   # NODE column
# on that node:
sudo docker ps -a --filter ancestor=ghcr.io/ayaka-notes/texlive-full:2026.1
ls -ln /srv/overleaf/compiles                          # owned by uid 33 (www-data)
```

各コンパイルは、`project-<project id>-<user id>-...` という名前の短命なコンテナとして表示されます。

### ログとシェル {#logs-and-a-shell}

| Toolkit          | Kubernetes                                                               |
| ---------------- | ------------------------------------------------------------------------ |
| `bin/logs web`   | `kubectl -n overleaf exec deploy/overleaf -- tail -f /var/log/overleaf/web.log` |
| `bin/shell`      | `kubectl -n overleaf exec -it deploy/overleaf -- bash`                    |
| `bin/up`         | `kubectl apply -f .` の後に `kubectl -n overleaf rollout restart deployment/overleaf` |

コンテナは `/var/log/overleaf/` にサービスごとに 1 つのログファイル（`web.log`、`clsi.log`、`real-time.log`、`document-updater.log` など）を書き込みます。`kubectl logs` には起動時の出力が表示されます。

### Q\&A {#q&a}

<Accordion title="コンパイルが失敗する、または終わらない。">

<strong>回答：</strong> Pod を実行しているノードで、Docker が動作していて `TEX_LIVE_DOCKER_IMAGE` で指定したイメージが存在すること、そして `SANDBOXED_COMPILES_HOST_DIR_*` が `hostPath` のパスと一致していることを確認してください。Pod 内の `/var/log/overleaf/clsi.log` に、失敗した手順が記録されています。

</Accordion>

<Accordion title="Pod を再起動するたびにユーザーがログアウトされる。">

<strong>回答：</strong> Secret `overleaf-secrets` に `OVERLEAF_SESSION_SECRET` がありません。[手順 2](/ja/on-premises/installation/using-kubernetes/2.-create-the-namespace-and-secrets) を参照してください。

</Accordion>
