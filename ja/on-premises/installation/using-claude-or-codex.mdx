Claude Code または Codex を使用して、Ayakaleaf Pro のデプロイを計画・実行できます。エージェントは作業中に MCP を通じてこのドキュメントを検索できます。

エージェントはデプロイを支援するだけです。コマンドの確認と認証情報の保護は引き続きあなたの責任です。

### 始める前に

SSH でアクセスできる、サポート対象の Linux サーバーを用意してください。続行する前に [要件](/ja/on-premises/getting-started/requirements  "mention") を確認してください。

<Warning>

パスワード、秘密鍵、トークン、ライセンスキーをエージェントのプロンプトに貼り付けないでください。すべてのコマンドは実行前に確認してください。特に、ファイル、ネットワーク、コンテナを変更するコマンドには注意が必要です。

</Warning>

### ドキュメントの接続

ローカルのエージェントにドキュメントの MCP エンドポイントを追加します。

<Tabs>
<Tab title="Claude Code">

```bash wrap
claude mcp add ayakaleaf-pro --scope user --transport http https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>

<Tab title="Codex">

```bash wrap
codex mcp add ayakaleaf-pro --url https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>
</Tabs>

サーバーを追加したら、新しいセッションを開始します。エージェントに Ayakaleaf Pro のドキュメントを検索できることを確認させてください。

### Ayakaleaf Pro のデプロイ

デプロイ先のサーバーでターミナルを開き、そこで Claude Code または Codex を起動します。次に、以下のプロンプトを送信します。

```text wrap
Use the Ayakaleaf Pro documentation MCP server to guide this deployment.
First, inspect the requirements and installation guides.
Ask me for missing deployment details before making changes.
Use the Ayakaleaf Toolkit unless the documentation requires another approach.
Before configuring the instance, summarize relevant optional features.
Ask which features and integrations I want to enable.
Include TLS, sandboxed compiles, Git integration, external MongoDB or Redis,
SSO (OIDC, SAML, or LDAP), GitHub Synchronisation, Zotero, S3 storage,
email delivery, branding, and localization when relevant.
Explain each selected option's prerequisites, security impact, and configuration steps.
Keep unselected optional features disabled.
Show each command before running it.
Do not expose, store, or request secrets in chat.
After deployment, verify that the service is healthy and summarize the changes.
```

エージェントは、Docker のセットアップ、Toolkit の設定、イメージの取得、起動までをガイドします。標準的なワークフローについては [using-the-toolkit](/ja/on-premises/installation/using-the-toolkit  "mention") ガイドに従ってください。

### オプション機能の選択

環境に合った機能のみを推奨するようエージェントに依頼してください。一般的な選択肢は次のとおりです。

* **アクセスとセキュリティ:** TLS、サンドボックス化されたコンパイル、OIDC・SAML・LDAP による SSO。
* **外部サービス:** MongoDB、Redis、S3 ストレージ、メール配信。
* **コラボレーション:** Git 連携、GitHub Synchronisation、Zotero。

エージェントは設定を編集する前に依存関係を説明する必要があります。本番環境で連携機能を有効にする前に、[toolkit-settings.md](/ja/on-premises/configuration/overleaf-toolkit/toolkit-settings  "mention") と [authentication](/ja/on-premises/configuration/overleaf-toolkit/authentication  "mention") を確認してください。

### デプロイの検証

エージェントが手順を完了したら、次を行います。

1. すべてのコマンドがエラーなく完了したことを確認します。
2. 設定した Ayakaleaf Pro の URL をブラウザで開きます。
3. [6.-post-installation-tasks.md](/ja/on-premises/installation/using-the-toolkit/6.-post-installation-tasks  "mention") を完了します。

既存の Community Edition インストールがある場合は、新規デプロイではなく [migrate-from-existing.md](/ja/on-premises/installation/migrate-from-existing  "mention") ガイドを使用してください。
