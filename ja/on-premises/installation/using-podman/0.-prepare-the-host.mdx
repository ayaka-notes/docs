Podman を手動でインストールする必要はありません。[2. podman-setup の実行](/ja/on-premises/installation/using-podman/2.-run-podman-setup) が、必要な他のパッケージと一緒にインストールします。ここではホストを確認し、Toolkit のダウンロードに必要な `git` をインストールするだけです。

<Steps>
<Step title="オペレーティングシステムと SELinux を確認する">
`root` ではなく、Ayakaleaf Pro を実行するユーザーでログインし、ディストリビューションと SELinux のモードを確認します：

```bash title="Check the host"
grep PRETTY_NAME /etc/os-release
getenforce
```

バージョン 9 以降の RHEL、Rocky Linux、AlmaLinux、または CentOS Stream と、`Enforcing` が表示されるはずです：

```text
PRETTY_NAME="Rocky Linux 9.9 (Blue Onyx)"
Enforcing
```
</Step>

<Step title="sudo を使えることを確認する">
`bin/podman-setup --apply` は `sudo` でパッケージをインストールし SELinux モジュールを読み込みます。必要なときにパスワードを尋ねます：

```bash title="Check sudo"
sudo -v
```

失敗した場合は、管理者にユーザーを `wheel` グループに追加してもらってください。
</Step>

<Step title="git をインストールする">
```bash title="Install git"
sudo dnf install -y git
```

<Warning>

このホストに Docker Engine をインストールしないでください。`bin/podman-setup` がインストールするパッケージ `podman-docker` が `docker` コマンドを提供し、Toolkit は `podman` コマンドが存在する限りホストを Podman として扱います。

</Warning>
</Step>
</Steps>
