### 最初の管理者アカウントを作成する {#create-your-first-administrator-account}

[http://localhost:8080/launchpad](http://localhost:8080/launchpad)、または `OVERLEAF_SITE_URL` の後に `/launchpad` を付けた URL を開き、管理者アカウントを登録します。ここから先は Docker と同じです。Docker ガイドの [6. インストール後のタスク](/ja/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks) に従い、その `localhost` のリンクではポート `8080` を使ってください。

サンプルプロジェクトを作成してコンパイルします。PDF が表示されれば、コンパイルが Podman を通じて TeX Live コンテナーで実行されていることがわかります。コンパイル用のコンテナーを確認するには：

```bash title="List the compile containers"
podman ps -a --filter name=project- --format "{{.Names}} {{.Image}} {{.Status}}"
```

### HTTPS を使う {#use-https}

Toolkit の [TLS プロキシ](/ja/on-premises/configuration/overleaf-toolkit/tls-proxy) は Podman でも動作します。`bin/init --tls` を実行し、そのページの説明に従って証明書と `NGINX_ENABLED=true` を設定します。TLS プロキシはポート `80` と `443` で待ち受けますが、rootless Podman はデフォルトではこれらのポートを使えません。非特権ユーザーが `80` 以上のポートを使えるようにします：

```bash title="Allow ports 80 and 443"
echo "net.ipv4.ip_unprivileged_port_start=80" | sudo tee /etc/sysctl.d/99-unprivileged-ports.conf
sudo sysctl --system
```

これによりサーバー上のすべてのユーザーがこれらのポートで待ち受けられるようになるため、Ayakaleaf Pro 専用のサーバーでのみ行ってください。次に、ファイアウォールでポートを開きます：

```bash title="Open ports 80 and 443"
sudo firewall-cmd --permanent --add-port=80/tcp --add-port=443/tcp
sudo firewall-cmd --reload
```

`OVERLEAF_SITE_URL` を `https://` のアドレスに設定し、`bin/up -d` を実行します。デフォルトの `NGINX_HTTP_PORT=80` と `TLS_PORT=443` はそのままにしてください。他のポートでは、HTTP から HTTPS へのリダイレクトが誤ったポートに向かいます。

<Info>

TLS プロキシを使う場合は、`OVERLEAF_LISTEN_IP` を `127.0.0.1` のままにして、ポート `8080` に他のコンピューターから到達できないようにしてください。

</Info>

### アップグレード {#upgrade}

[デプロイのアップグレード](/ja/on-premises/maintenance/upgrading-your-deployment) の説明に従い、`bin/upgrade` でアップグレードします。Podman では、新しいバージョンの seccomp プロファイルを `config/seccomp/<version>/` に抽出し、`SECCOMP_PROFILE` も更新します：

```text
Over-writing config/version with 6.3.4
Set SECCOMP_PROFILE=/home/<user>/overleaf-toolkit/config/seccomp/6.3.4/clsi-profile.json in config/variables.env
```

アップグレード後は、`bin/podman-setup` を実行してセットアップを確認してください。

### SELinux モードを変更する {#change-the-selinux-mode}

`config/overleaf.rc` の `SELINUX_MODE` は、SELinux が `sharelatex` コンテナーをどのように制限するかを決めます。これらのページでセットアップするのは `managed` です。他のモードは [Toolkit の設定](/ja/on-premises/configuration/overleaf-toolkit/toolkit-settings) で説明しています。変更後は `bin/up -d` を実行してください。
