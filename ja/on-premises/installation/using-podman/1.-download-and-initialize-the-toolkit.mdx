icon: arrow-down-to-bracket
---

<Steps>
<Step title="Toolkit をクローンする">
**Ayakaleaf Toolkit**（[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)）をホームディレクトリにクローンし、そのディレクトリに移動します：

```bash title="Clone the Toolkit" wrap
git clone https://github.com/ayaka-notes/toolkit.git ~/overleaf-toolkit
cd ~/overleaf-toolkit
```

以降のコマンドはすべてこのディレクトリで実行します。
</Step>

<Step title="設定を作成する">
```bash title="Run initialization"
bin/init
```

これにより `config/overleaf.rc`、`config/variables.env`、`config/version` が作成されます。詳しくは Docker ガイドの [3. 設定の初期化](/ja/on-premises/installation/using-docker-compose/linux/3.-initialize-the-configuration) を参照してください。`bin/init` はまだ Podman を必要としません。
</Step>

<Step title="config/overleaf.rc を設定する">
`config/overleaf.rc` を開き、次の行を変更します：

```bash title="config/overleaf.rc"
SERVER_PRO=true
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
```

続いて、ファイルの末尾に次の行を追加します：

```bash title="config/overleaf.rc"
SELINUX_MODE=managed
```

| 設定                              | 理由                                                                                                                                                                                                        |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SERVER_PRO=true`                 | `ghcr.io` の Ayakaleaf Pro イメージを使います。ログインは不要です。                                                                                                                                          |
| `OVERLEAF_PORT=8080`              | Rootless Podman は `1024` 未満のポートで待ち受けできません。デフォルトの `80` は失敗します。                                                                                                                 |
| `SIBLING_CONTAINERS_ENABLED=true` | 各コンパイルを専用の TeX Live コンテナーで実行します。デフォルトですでに `true` です。Podman のセットアップはこのモードのみをサポートします。                                                                 |
| `SELINUX_MODE=managed`            | `sharelatex` コンテナーを SELinux タイプ `sharelatex_t` で実行します。このタイプは Podman ソケットを使えますが、それ以上のことはできません。`bin/podman-setup --apply` がそのためのポリシーモジュールをインストールします。他のモードは [Toolkit の設定](/ja/on-premises/configuration/overleaf-toolkit/toolkit-settings) を参照してください。 |

`DOCKER_SOCKET_PATH` はそのままにしておきます。次のステップで `bin/podman-setup --apply` が Podman ソケットに設定します。

<Warning>

`GIT_BRIDGE_ENABLED=false` のままにしてください。Ayakaleaf Pro 6.3.4 では Git 連携が Podman 上で動作しません。[既知の制限事項](/ja/on-premises/installation/using-podman#known-limitations) を参照してください。

</Warning>
</Step>

<Step title="TeX Live イメージを選ぶ">
`config/variables.env` を開き、`TEX_LIVE_DOCKER_IMAGE` と `ALL_TEX_LIVE_DOCKER_IMAGES` の前の `#` を削除して、使用する TeX Live イメージを列挙します：

```bash title="config/variables.env" wrap
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
```

リストが空の場合、`bin/up` は `Please configure ALL_TEX_LIVE_DOCKER_IMAGES` で停止します。`texlive-full` は大きいため、テストサーバーでははるかに小さい `ghcr.io/ayaka-notes/texlive-basic:2026.1` でも構いません。利用可能なイメージは [Sandboxed Compiles](/ja/on-premises/configuration/overleaf-toolkit/sandboxed-compiles) を参照してください。

`OVERLEAF_SITE_URL` などの他の変数は、[5. インスタンスのカスタマイズ](/ja/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance#required-environment-variables) の説明に従って設定します。デフォルトの待ち受けアドレスでは `http://localhost:8080` を使います。
</Step>
</Steps>
