---
title: TeX Live のアップグレード
description: Overleaf Community Edition のデプロイで TeX Live をアップグレードしたり、パッケージをインストールしたりします。
icon: square-up
---

<Danger>

以下の手順は **Community Edition** のインストールに**のみ**適用されます。Ayakaleaf Pro のユーザーには、[Sandboxed Compiles](/ja/on-premises/configuration/overleaf-toolkit/sandboxed-compiles) を有効にすることを強くおすすめします。これにより、[overleaf.com](https://www.overleaf.com) で使用されているものとほぼ同じ TeX Live イメージを利用できるうえ、プロジェクトのコンパイル間が分離されてセキュリティも向上します。

</Danger>

帯域幅を節約するため、Overleaf Community Edition と Ayakaleaf Pro のイメージには、どちらも [TeX Live](https://www.tug.org/texlive/) の最小構成のみが含まれています。`sharelatex` コンテナ内で [tlmgr](https://www.tug.org/texlive/tlmgr.html) コマンドを使用すると、パッケージを追加インストールしたり、TeX Live の完全インストールにアップグレードしたりできます。

#### sharelatex コンテナに入る

`sharelatex` コンテナ内でシェルを起動するには、次を実行します。

```bash
bin/shell
```

次のようなプロンプトが表示されます。

```bash
root@309b192d4030:/#
```

以下の手順では、コンテナ内にいることを前提とします。

#### 現在の TeX Live のバージョンを確認する

TeX Live は毎年 4 月頃にリリースされます。`tlmgr` の使用手順は、最新リリースを使用しているか古いリリースを使用しているかによって異なります。実行中の TeX Live のバージョンは `tlmgr --version` で確認できます。たとえば、次のインストールでは TeX Live 2021 が動作しています。

```bash
# tlmgr --version
tlmgr revision 59291 (2021-05-21 05:14:40 +0200)
tlmgr using installation: /usr/local/texlive/2021
TeX Live (https://tug.org/texlive) version 2021
```

<Info>

TeX Live の最新リリースは [TeX Live のホームページ](https://www.tug.org/texlive/)で確認できます。

</Info>

古いバージョンの TeX Live を使用している場合、選択肢は 2 つあります。通常、TeX Live のリリース後まもなく Overleaf Docker イメージの新しいバージョンがリリースされるので、それを待って `bin/upgrade` スクリプトでデプロイをアップグレードすることができます。あるいは、古い TeX Live リリースを使い続けたい場合は、まず `tlmgr` に過去のリポジトリを使用するよう指定する必要があります。その手順は[こちら](https://www.tug.org/texlive/acquire.html#past)にあります。

#### パッケージのインストール

TeX Live を完全インストールするには、`sharelatex` コンテナ内で次のコマンドを実行します。

```text
tlmgr install scheme-full
```

個々のパッケージを手動でインストールすることもできます。

```bash
tlmgr install tikzlings tikzmarmots tikzducks
```

<Warning>

`3.3.0` リリース以降では、すべてのバイナリをシステムパスに正しくシンボリックリンクするため、`tlmgr install` を使用するたびに再度 `tlmgr path add` を実行することが**必須**です。

</Warning>

他にも多くのコマンドが利用できます。詳しくは次のコマンドで確認できます。

```text
tlmgr help
```

作業が終わったら、`exit` と入力するか Control-D を押してシェルを終了します。

#### 変更を保存する

ここで行った変更は `sharelatex` コンテナに加えられましたが、一時的なものです。設定の更新などで Docker Compose がコンテナを再作成すると失われます。

変更を永続化するには、`docker commit` を使用して変更を新しい Docker イメージとして保存します。

```bash
cat config/version #5.2.1
docker commit sharelatex sharelatex/sharelatex:5.2.1-with-texlive-full
echo 5.2.1-with-texlive-full > config/version
```

変更をコミットしたら、それに合わせて `config/version` を更新します。その後 `bin/up` を実行して `sharelatex` コンテナを再作成します。

<Danger>

Overleaf の新しいバージョンに[アップグレード](https://github.com/overleaf/toolkit/blob/master/doc/upgrading.md)するたびに、これらの手順を繰り返す必要があります。

</Danger>
