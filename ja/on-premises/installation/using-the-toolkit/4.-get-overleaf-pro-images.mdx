---
title: 4. Ayakaleaf Pro イメージの取得
icon: split
---

Ayakaleaf Pro は [ghcr](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/) レジストリ上で Docker イメージとして配布されており、誰でも**自由にアクセス**できます。amd64 と arm64 の両方のアーキテクチャ向けのイメージを提供しています。イメージを pull すると、システムのアーキテクチャに応じて適切なイメージが自動的に選択されます。

#### Ayaka-notes Toolkit をご利用の場合

[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) を使用している場合、Ayakaleaf Pro は Community Edition のドロップイン代替として使用できるため、既存の設定やカスタマイズをそのまま利用できます。`config/overleaf.rc` を編集して `SERVER_PRO` 環境変数を設定し、Toolkit で Pro を有効にします：

```text title="config/overleaf.rc"
SERVER_PRO=true
```

次に `bin/up` を実行すると、Toolkit が自動的に Ayakaleaf Pro イメージをダウンロードして使用します。

#### 公式 Toolkit をご利用の場合

[overleaf/toolkit](https://github.com/overleaf/toolkit) を使用している場合、Pro イメージを取得するには、次のコマンドを実行して pull します：

```bash title="Pull Docker Images"
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

次に、以下の内容で `docker-compose.override.yml` という名前のファイルを `overleaf-toolkit/config` ディレクトリに追加します：

```yml title="docker-compose.override.yml"
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

次に `bin/up` を実行すると、Toolkit が自動的に Ayakaleaf Pro イメージをダウンロードして使用します。
