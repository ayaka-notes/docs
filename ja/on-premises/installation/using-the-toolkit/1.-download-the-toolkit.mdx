### Toolkit のダウンロード

Toolkit は Server CE と Ayakaleaf Pro の両方に対応しており、推奨されるインストール方法です。Toolkit を使用すると、Server CE を簡単に使い始めることができ、必要に応じて Ayakaleaf Pro にシームレスにアップグレードできます。

<Info>

[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) は、ghcr の overleaf-pro イメージを直接使用するように変更されており、TeX Live は ayaka-notes によって提供されます。公式の overleaf-toolkit をダウンロードすることもできます。

</Info>

<Steps>
<Step title="Overleaf Toolkit リポジトリをクローンする">
Toolkit をインストールするには、インストール先のパスに移動し、次のコマンドで Overleaf Toolkit（@Ayaka-notes）の GitHub リポジトリをクローンします。

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
# official toolkit (Not Recommended)
# git clone https://github.com/overleaf/toolkit.git ./overleaf-toolkit
```

<Info>

パーミッションの問題を防ぐため、Toolkit はユーザーの `$HOME` ディレクトリにインストールすることをおすすめします。

</Info>
</Step>

<Step title="Toolkit のディレクトリに移動する">
クローンが完了するまで待ち、新しく作成された `overleaf-toolkit` ディレクトリに移動します。

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
