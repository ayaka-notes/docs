### Toolkit のダウンロード

Toolkit は Server CE と Ayakaleaf Pro の両方に対応しており、推奨されるインストール方法です。Toolkit を使えば、Server CE を簡単に使い始めることができ、必要に応じて Ayakaleaf Pro へシームレスにアップグレードできます。

<Info>

[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit) は、ghcr の overleaf-pro イメージを直接使用し、ayaka-notes が提供する TeX Live を使うように改修されています。代わりに公式の overleaf-toolkit をダウンロードすることもできます。

</Info>

<Steps>
<Step title="Overleaf Toolkit リポジトリをクローンする">
Toolkit をインストールするには、インストール先のパスに移動し、次のコマンドで Overleaf Toolkit（@Ayaka-notes）の GitHub リポジトリをクローンします。

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
# official toolkit (Not Recommended)
# git clone https://github.com/overleaf/toolkit.git ./overleaf-toolkit
```

<Info>

パーミッションに関する問題を防ぐため、Toolkit はユーザーの `$HOME` ディレクトリにインストールすることをおすすめします。

</Info>
</Step>

<Step title="toolkit ディレクトリに移動する">
クローンが完了するまで待ってから、新しく作成された `overleaf-toolkit` ディレクトリに移動しましょう。

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
