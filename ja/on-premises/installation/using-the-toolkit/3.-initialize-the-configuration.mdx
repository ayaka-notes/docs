### 設定の初期化

同梱の `bin/init` スクリプトを実行して、新しいサーバーの設定ファイルを適切なデフォルト値で初期化しましょう。

```text title="Run initialization"
bin/init
```

このスクリプトは既存の設定ファイルを上書き**しません**。

次に、`ls` コマンドを使って `config/` ディレクトリの内容を確認しましょう。

```text title="List the config directory"
ls config
```

すべてが正常に初期化されていれば、`overleaf.rc`、`variables.env`、`version` の 3 つの設定ファイルが表示されます。これらはサーバーの主要な設定ファイルであり、サーバーの動作やユーザーがインスタンスとどのようにやり取りするかをカスタマイズできます。

| 名前            | 説明                                                    |
| --------------- | ------------------------------------------------------- |
| `overleaf.rc`   | メインのトップレベル設定ファイル。                      |
| `variables.env` | Docker コンテナに読み込まれる環境変数。                 |
| `version`       | 使用する Docker イメージのバージョン。                  |

<Info>

今のところは、これらのファイルが存在することと、その場所を把握しておけば十分です。ドキュメントの後半で各ファイルを詳しく説明し、それらを使ってインスタンスをカスタマイズする方法を解説します。先に進みたい場合は、[ファイルと場所のページ](/ja/on-premises/configuration/overleaf-toolkit/files-and-locations)でこれらの設定ファイルの詳細な説明を確認できます。

</Info>
