[Toolkit](https://github.com/ayaka-notes/toolkit) は、Ayakaleaf Pro インスタンスをデプロイするための推奨方法です。

このセクションでは、GitHub から Toolkit をダウンロードし、Toolkit のいくつかのコマンドに慣れ、基本的な設定を行う手順を説明します。このページを読み終える頃には、オンプレミスの Overleaf インスタンスが稼働しているはずです。
