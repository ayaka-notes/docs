Overleaf は Docker 上で動作します。以下をインストールする必要があります。

* Docker Engine(Docker CE)
* Docker Compose プラグイン(`docker compose`、v2)

この手順は最近の Ubuntu LTS(20.04/22.04/24.04)を対象としています。

<Warning>

Ubuntu のデフォルトの apt リポジトリから `docker.io` をインストールしないでください。\
最新の Docker バージョンと `docker compose` プラグインを入手するために、Docker の公式リポジトリを使用してください。

</Warning>

公式ドキュメントはこちらです: [https://docs.docker.com/engine/install/ubuntu/](https://docs.docker.com/engine/install/ubuntu/)

<Steps>
<Step title="1) 古いパッケージや競合するパッケージを削除する(存在する場合)">
以前に別のソースから Docker をインストールしていた場合は、まずそれを削除します。

```bash wrap
sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-compose-v2 docker-doc podman-docker containerd runc | cut -f1)
```

一部のパッケージがインストールされていなくても、このコマンドは安全に実行できます。
</Step>

<Step title="2) Docker の公式 apt リポジトリを追加する">
前提パッケージをインストールします。

```bash
sudo apt update
sudo apt install -y ca-certificates curl
```

Docker の GPG キーを追加します。

```bash wrap
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```

リポジトリを追加します。

```bash wrap
# Add the repository to Apt sources:
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Signed-By: /etc/apt/keyrings/docker.asc
EOF

sudo apt update
```
</Step>

<Step title="3) Docker Engine と Compose プラグインをインストールする">
Docker と Compose プラグインをインストールします。

```bash wrap
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

起動時に Docker を開始するように設定します。

```bash
sudo systemctl enable --now docker
```
</Step>

<Step title="4) インストールを確認する">
以下のコマンドがエラーなく実行できるはずです。

```bash
docker --version
docker compose version
sudo docker run --rm hello-world
docker ps
```
</Step>

<Step title="5) (任意) sudo なしで Docker を実行する">
ユーザーを `docker` グループに追加します。

```bash
sudo usermod -aG docker $USER
```

その後、**ログアウトして再度ログイン**するか、次を実行します。

```bash
newgrp docker
```

これで `sudo` なしで次のコマンドが動作するはずです。

```bash
docker ps
```

<Danger>

`docker` グループはホスト上で root 相当のアクセス権を持ちます。\
これは一般的な Overleaf のインストールでは想定どおりであり、Sandboxed Compiles を有効にする場合は特に関係します。

</Danger>
</Step>
</Steps>
