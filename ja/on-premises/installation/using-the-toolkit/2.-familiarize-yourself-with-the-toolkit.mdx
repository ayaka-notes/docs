### 全体を確認する

Toolkit のローカルコピーが手に入ったので、`ls` コマンドを使ってリポジトリの構造を確認してみましょう。

```bash title="Run this"
ls -l
```

<Info>

`ls -l` コマンドは、ディレクトリの内容を詳細なロングリスト形式で表示し、パーミッション、所有者、サイズなどの追加のファイル情報を提供します。

</Info>

すべてが正常にクローンされていれば、次のような出力が表示されます：

```text
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 bin
-rw-r--r-- 1 fry fry  6465 Aug 30 14:16 CHANGELOG.md
drwxr-xr-x 2 fry fry  4096 Sep  6 12:43 config
drwxr-xr-x 5 fry fry  4096 Aug 30 14:22 data
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 doc
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 lib
-rw-r--r-- 1 fry fry 34520 Aug 30 14:16 LICENSE
-rw-r--r-- 1 fry fry  1178 Aug 30 14:16 README.md
```

<Info>

ユーザーが所有するすべての設定ファイルは `config/` ディレクトリにあります。このディレクトリは git のリビジョン管理から**除外**されているため、Toolkit を更新しても変更されることはありません。

</Info>

## リポジトリの構成

| 名前     | 説明                                                                                                                                                                                                                                               |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `bin`    | このフォルダには、Overleaf サーバーインスタンスの管理に役立つスクリプト群が含まれています。これらのスクリプトの詳細については、以下のコマンドのセクションを参照してください。                                                                                     |
| `config` | このフォルダには、独自のローカル設定ファイルが含まれています。                                                                                                                                                                                                  |
| `lib`    | このフォルダには、Toolkit が使用する基本設定ファイルが含まれています。                                                                                                                                                                                        |
| `data`   | デフォルトでは、このフォルダは MongoDb、Redis、Overleaf のストレージの保存場所です。詳細については、以下の[永続データ](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/files-and-locations#persistent-data)のセクションを参照してください。 |

<Warning>

`/config` フォルダ以外のファイルを直接変更**しない**ことを推奨します。変更が必要な場合は、**config/variables.env** または **config/overleaf.rc** で設定する環境変数を使用して行うことができます。\
たとえば、`mongo` サービスのイメージを設定する場合は、`lib/docker-compose.mongo.yml` を直接編集するのではなく、`config/overleaf.rc` で環境変数 `MONGO_IMAGE` を使用してイメージを設定します。詳細については、[Toolkit の設定](/ja/on-premises/configuration/overleaf-toolkit/toolkit-settings)ページを参照してください。

</Warning>

<Info>

Toolkit は、許可なく `config/` ディレクトリ内のデータを変更することは**ありません**。

</Info>
