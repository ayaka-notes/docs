## LaTeX とは？

LaTeX（「_レイ_テック」または「_ラー_テック」と発音します）は、プロフェッショナルな見た目の文書を組版するためのツールです。ただし、LaTeX の動作方式は、Microsoft Word や LibreOffice Writer など、これまでに使ったことがあるかもしれない多くの文書作成アプリケーションとはかなり異なります。それらの「[WYSIWYG](https://en.wikipedia.org/wiki/WYSIWYG)」ツールでは、ユーザーはインタラクティブなページ上でテキストを入力・編集し、さまざまなスタイルを適用します。LaTeX はまったく異なる仕組みで動作します。文書は、望む（組版された）結果を表現するための LaTeX _コマンド_が散りばめられたプレーンテキストファイルです。目に見える組版済みの文書を作成するには、LaTeX ファイルを _TeX エンジン_と呼ばれるソフトウェアで処理します。TeX エンジンは、テキストファイルに埋め込まれたコマンドに従って組版プロセスを制御し、LaTeX コマンドと文書のテキストをプロフェッショナルに組版された PDF ファイルに変換します。つまり、あなたは文書の_内容_に集中するだけでよく、_見た目_（書式）は LaTeX コマンドと TeX エンジンを通じてコンピューターが処理してくれます。

## なぜ LaTeX を学ぶのか？

他の文書作成アプリケーションではなく LaTeX の使い方を学ぶことについては、賛否さまざまな意見がありますが、最終的には好みや相性、文書作成の要件に基づく個人的な選択です。

LaTeX を支持する理由には、次のようなものがあります。

* 非常に複雑な数式、表、自然科学分野の技術的な内容の組版をサポートしていること
* 脚注、相互参照、参考文献管理の機能があること
* 索引、用語集、目次、図目次など、複雑または面倒な文書要素を簡単に作成できること
* 本質的なプログラマビリティと、数千もの[無料のアドオンパッケージ](https://www.ctan.org/pkg)による拡張性により、目的に合わせた文書作成のために高度にカスタマイズできること

全体として、LaTeX は非常に高い水準で組版される文書の作成を、ユーザーが細かく制御できるようにします。もちろん、雑誌のような出版物によく見られる「自由形式」のページデザインなど、LaTeX が得意としない種類の文書や出版物もあります。

LaTeX の重要な利点の 1 つは、文書の内容とスタイルが分離されていることです。文書の内容を書き終えた後でも、その見た目を簡単に変更できます。同様に、特定の種類の文書のレイアウトやスタイルを定義する LaTeX ファイルを作成し、そのファイルを_テンプレート_として使用して、同じ種類の文書の執筆・作成を標準化できます。たとえば、学術出版社は LaTeX で論文テンプレートを作成し、著者はそれを使ってジャーナルに投稿する論文を執筆できます。Overleaf には、学術論文、レポート、書籍から履歴書やプレゼンテーションまで、非常に幅広い種類の文書をカバーする[数千ものテンプレートを集めたギャラリー](https://www.overleaf.com/gallery)があります。これらのテンプレートが文書のレイアウトとスタイルを定義しているため、著者は Overleaf でテンプレートを開いて新しいプロジェクトを作成し、内容を書き始めるだけで済みます。

## 初めての LaTeX を書く

最初のステップは、新しい LaTeX プロジェクトを作成することです。自分のコンピューター上で新しい `.tex` ファイルを作成することもできますし、Overleaf で新しいプロジェクトを開始することもできます。

まずは、Overleaf で直接開くことができる、最もシンプルな動作例から始めましょう。

```latex
\documentclass{article}
\begin{document}
First document. This is a simple example, with no 
extra parameters or packages included.
\end{document}
```

[この例を Overleaf で開く。](https://www.overleaf.com/docs?engine=pdflatex&snip%5Fname=Simplest+working+example+LaTeX+document&snip=%5Cdocumentclass%7Barticle%7D%0A%5Cbegin%7Bdocument%7D%0AFirst+document.+This+is+a+simple+example%2C+with+no+%0Aextra+parameters+or+packages+included.%0A%5Cend%7Bdocument%7D)

この例の出力は次のとおりです。

![サンプル文書](https://images.ctfassets.net/nrgyaltdicpt/5oBbZABsWEnHZpwhfvV2PD/95ba7d5496616b4f10dffe6fb90f578a/LL30Fig1-plain.svg)

LaTeX が段落の最初の行を自動的に字下げし、書式を整えてくれていることがわかります。では、コードの各部分が何をしているのかを詳しく見ていきましょう。

コードの 1 行目の `\documentclass{article}` は、文書の_クラス_と呼ばれる文書の種類を宣言しており、文書全体の見た目を制御します。文書の種類によって必要なクラスは異なります。たとえば、履歴書には、標準の LaTeX `article` クラスを使うことが多い学術論文とは異なるクラスが必要です。作成する文書によっては、`book` や `report` などの別のクラスが必要になる場合もあります。利用可能なさまざまな LaTeX クラスについては、[CTAN（Comprehensive TeX Archive Network）の該当ページ](https://www.ctan.org/topic/class)を参照してください。

文書クラスを設定したら、文書の_本文_と呼ばれる内容を `\begin{document}` タグと `\end{document}` タグの間に記述します。上の例を開いたら、テキストを変更し、完了したら_文書を再コンパイル_して組版結果の PDF を確認できます。Overleaf でこれを行うには、次の短い動画クリップのように **Recompile** をクリックするだけです。

Overleaf のプロジェクトは、編集するたびに自動的に再コンパイルするよう設定できます。次のスクリーンショットのように、**Recompile** ボタンの横にある小さな矢印をクリックし、**Auto Compile** を **On** に設定します。

![Auto Compile を On または Off に設定する方法を示すスクリーンショット](/images/texlive/ll30autocompile.png)

文書に内容を追加する方法がわかったので、次はタイトルを付けてみましょう。そのためには、**プリアンブル**について簡単に説明する必要があります。

## 文書のプリアンブル

上のスクリーンショットでは、Overleaf が LaTeX 文書を `main.tex` というファイルとして保存しています。文書の LaTeX コードを含むファイルには、慣例として `.tex` という拡張子を使用します。

前の例では、文書の内容を `\begin{document}` コマンドの後に入力する方法を示しました。一方、`.tex` ファイル内でそれより_前_にあるものはすべて_プリアンブル_と呼ばれ、文書の「セットアップ」セクションとして機能します。プリアンブルでは、文書クラス（種類）と、文書の執筆に使用する言語などの詳細を定義し、使用したい_パッケージ_を読み込み（詳しくは[後述](/ja/texlive/latex-basics/learn-latex-in-30-minutes#Finding%5Fand%5Fusing%5FLaTeX%5Fpackages)します）、その他の設定を行います。

最小限の文書プリアンブルは次のようになります。

```latex
\documentclass[12pt, letterpaper]{article}
\usepackage{graphicx}
```

ここで、`\documentclass[12pt, letterpaper]{article}` は文書全体のクラス（種類）を定義します。追加のパラメーターはカンマで区切って角括弧（`[...]`）内に記述し、この article クラスのインスタンス、つまりこの `article` クラスベースの文書で使用したい設定を構成します。

この例では、2 つのパラメーターは次の役割を果たします。

* `12pt` はフォントサイズを設定します
* `letterpaper` は用紙サイズを設定します

もちろん、`9pt`、`11pt`、`12pt` など他のフォントサイズも使用できますが、何も指定しない場合のデフォルトのサイズは `10pt` です。用紙サイズについては、他に `a4paper` や `legalpaper` を指定できます。詳しくは、ページサイズと余白に関する記事を参照してください。

プリアンブルの次の行

```latex
\usepackage{graphicx}
```

は、外部パッケージ（ここでは [graphicx](https://ctan.org/pkg/graphicx?lang=en)）を読み込んで LaTeX の機能を拡張し、外部の画像ファイルを取り込めるようにする例です。LaTeX パッケージについては、[LaTeX パッケージの検索と使用](/ja/texlive/latex-basics/learn-latex-in-30-minutes#Finding%5Fand%5Fusing%5FLaTeX%5Fpackages)のセクションで説明します。

## タイトル、著者、日付の情報を追加する

文書にタイトル、著者、日付を追加するには、_プリアンブル_（文書の本文では_ありません_）にさらに 3 行を追加する必要があります。追加する行は次のとおりです。

* `\title{My first LaTeX document}`: 文書のタイトル
* `\author{Hubert Farnsworth}`: ここには著者名を書きます。必要に応じて、波括弧内に `\thanks` コマンドを記述することもできます。
  * `\thanks{Funded by the Overleaf team.}`: `author` コマンドの波括弧内で、著者名の後に追加できます。上付き文字と、波括弧内のテキストを含む脚注が追加されます。論文の中で機関への謝辞を述べる必要がある場合に便利です。
* `\date{August 2022}`: 日付を手動で入力するか、`\today` コマンドを使用して、文書をコンパイルするたびに現在の日付を組版できます

これらの行を追加すると、プリアンブルは次のようになります。

```latex
\documentclass[12pt, letterpaper]{article}
\title{My first LaTeX document}
\author{Hubert Farnsworth\thanks{Funded by the Overleaf team.}}
\date{August 2022}
```

タイトル、著者、日付を組版するには、文書の_本文_で `\maketitle` コマンドを使用します。

```latex
\begin{document}
\maketitle
We have now added a title, author and date to our first \LaTeX{} document!
\end{document}
```

これで、プリアンブルと本文を組み合わせて、Overleaf で開くことができる完全な文書を作成できます。

```latex
\documentclass[12pt, letterpaper]{article}
\title{My first LaTeX document}
\author{Hubert Farnsworth\thanks{Funded by the Overleaf team.}}
\date{August 2022}
\begin{document}
\maketitle
We have now added a title, author and date to our first \LaTeX{} document!
\end{document}
```

## コメントを追加する

LaTeX は一種の「プログラムコード」ですが、文書の組版に特化したものです。そのため、他のプログラミング言語で書かれたコードと同様に、文書内にコメントを含めると非常に便利です。LaTeX のコメントは、組版されず文書にまったく影響を与えないテキストの部分です。「To Do」メモの追加、説明メモの記載、複雑なマクロのインライン説明、デバッグ時に LaTeX コードの行やセクションをコメントアウトする場合などによく使われます。

LaTeX でコメントを書くには、上の例を使った次のコードのように、行頭に `%` 記号を書くだけです。

```latex
\documentclass[12pt, letterpaper]{article}
\title{My first LaTeX document}
\author{Hubert Farnsworth\thanks{Funded by the Overleaf team.}}
\date{August 2022}
\begin{document}
\maketitle
We have now added a title, author and date to our first \LaTeX{} document!

% This line here is a comment. It will not be typeset in the document.
\end{document}
```

[この例を Overleaf で開く。](https://www.overleaf.com/docs?engine=pdflatex&snip%5Fname=My+first+LaTeX+document+with+a+comment&snip=%5Cdocumentclass%5B12pt%2C+letterpaper%5D%7Barticle%7D%0A%5Ctitle%7BMy+first+LaTeX+document%7D%0A%5Cauthor%7BHubert+Farnsworth%5Cthanks%7BFunded+by+the+Overleaf+team.%7D%7D%0A%5Cdate%7BAugust+2022%7D%0A%5Cbegin%7Bdocument%7D%0A%5Cmaketitle%0AWe+have+now+added+a+title%2C+author+and+date+to+our+first+%5CLaTeX%7B%7D+document%21%0A%0A%25+This+line+here+is+a+comment.+It+will+not+be+typeset+in+the+document.%0A%5Cend%7Bdocument%7D)

## 太字、斜体、下線

次に、テキストの書式設定コマンドをいくつか見ていきましょう。

* **太字**: LaTeX で太字のテキストを組版するには `\textbf{...}` コマンドを使用します。
* _斜体_: 斜体のテキストは `\textit{...}` コマンドで作成します。
* 下線: テキストに下線を引くには `\underline{...}` コマンドを使用します。

次の例でこれらのコマンドを示します。

```latex
Some of the \textbf{greatest}
discoveries in \underline{science} 
were made by \textbf{\textit{accident}}.
```

## 画像を追加する

このセクションでは、LaTeX 文書に画像を追加する方法を見ていきます。Overleaf では、画像を挿入する方法が 3 つあります。

1. エディターのツールバーにある [**Insert Figure** ボタン](https://learn.overleaf.com/learn/Kb/How_to_insert_figures_in_Overleaf#Using%5FInsert%5FFigure%5Fto%5Fadd%5Fa%5Ffigure%5Fto%5Fyour%5Fproject)(![エディターのツールバーにある Insert Figure ボタン](https://sharelatex-wiki-cdn-671420.cdn77.org/learn-scripts/images/a/a8/InsertFigureButton.png))を使用して、**Visual Editor** または **Code Editor** に画像を挿入する。
2. 画像をコピーして **Visual Editor** または **Code Editor** に貼り付ける。
3. **Code Editor** を使用して、画像を挿入する LaTeX コードを書く。

方法 1 と 2 では画像の挿入に必要な LaTeX コードが自動的に生成されますが、ここでは方法 3 を紹介します。なお、使用する画像は Overleaf プロジェクトに[アップロード](https://docs.overleaf.com/writing-and-editing/inserting-images)しておく必要があります。次の例は、画像を含める方法を示しています。

```latex
\documentclass{article}
\usepackage{graphicx} %LaTeX package to import graphics
\graphicspath{{images/}} %configuring the graphicx package
 
\begin{document}
The universe is immense and it seems to be homogeneous, 
on a large scale, everywhere we look.

% The \includegraphics command is 
% provided (implemented) by the 
% graphicx package
\includegraphics{universe}  
 
There's a picture of a galaxy above.
\end{document}
```

[この画像の例を Overleaf で開く。](https://www.overleaf.com/project/new/template/25686?id=107971142&templateName=Example+using+images+in+LaTeX&latexEngine=pdflatex&texImage=texlive-full%3A2022.1&mainFile=)

この例の出力は次のとおりです。

![LaTeX 文書に取り込まれた画像を示す図](https://images.ctfassets.net/nrgyaltdicpt/4p5toat08FUgehv4yuNwXS/efc9e75e4342c9caeec94f26627fa337/LL30Fig5v2-plain.svg)

LaTeX 文書に画像を取り込むには、外部の画像ファイルを含めるために必要なコマンドと機能を提供する[アドオン_パッケージ_](/ja/texlive/latex-basics/learn-latex-in-30-minutes#Finding%5Fand%5Fusing%5FLaTeX%5Fpackages)が必要です。上の例では [graphicx パッケージ](https://ctan.org/pkg/graphicx?lang=en)を読み込んでいます。このパッケージは多くのコマンドを提供しており、その中には画像を取り込む `\includegraphics{...}` や、画像の場所を LaTeX に知らせる `\graphicspath{...}` があります。

`graphicx` パッケージを使用するには、Overleaf 文書のプリアンブルに次の行を追加します。

```latex
\usepackage{graphicx}
```

この例では、コマンド `\graphicspath{{images/}}` が、画像が現在のディレクトリ内の `images` というフォルダーに保存されていることを LaTeX に伝えています。

![フォルダーに保存された画像に LaTeX がアクセスする様子を示す画像](https://sharelatex-wiki-cdn-671420.cdn77.org/learn-scripts/images/1/17/ImagesInAFolder.png)

実際に文書に画像を挿入するのは `\includegraphics{universe}` コマンドです。ここで、`universe` は拡張子を除いた画像ファイルの名前です。

**注意**:

* `\includegraphics` コマンドでは拡張子を含む完全なファイル名を指定することもできますが、拡張子を省略するのがベストプラクティスとされています。そうすることで、LaTeX がサポートされているすべての形式を検索するようになるためです。
* 一般に、画像のファイル名には空白や複数のドットを含めないでください。また、Overleaf に画像ファイルをアップロードする際は、拡張子に小文字を使用することをおすすめします。

LaTeX パッケージの詳細については、このチュートリアルの最後にある [LaTeX パッケージの検索と使用](/ja/texlive/latex-basics/learn-latex-in-30-minutes#Finding%5Fand%5Fusing%5FLaTeX%5Fpackages)のセクションを参照してください。

## キャプション、ラベル、参照

次に示すように、`figure` 環境を使用して、画像にキャプションやラベルを付け、参照することができます。

```latex
\documentclass{article}
\usepackage{graphicx}
\graphicspath{{images/}}
 
\begin{document}

\begin{figure}[h]
    \centering
    \includegraphics[width=0.75\textwidth]{mesh}
    \caption{A nice plot.}
    \label{fig:mesh1}
\end{figure}
 
As you can see in figure \ref{fig:mesh1}, the function grows near the origin. This example is on page \pageref{fig:mesh1}.

\end{document}
```

この例には、注目すべきコマンドがいくつかあります。

* **`\includegraphics[width=0.75\textwidth]{mesh}`**: この形式の `\includegraphics` は、図の幅をテキスト幅（その値は `\textwidth` コマンドに格納されています）の 75% に設定するよう LaTeX に指示します。
* **`\caption{A nice plot.}`**: 名前のとおり、このコマンドは図のキャプションを設定します。キャプションは図の上または下に配置できます。図目次を作成すると、このキャプションがその一覧で使用されます。

* **`\ref{fig:mesh1}`**: このコードは、参照先の図に対応する番号に置き換えられます。

## LaTeX でリストを作成する

さまざまな種類のリストは_環境_を使って作成できます。環境は、特定の組版機能を実装するために必要な LaTeX コードをカプセル化するために使用されます。環境は `\begin{_environment-name_}` で始まり `\end{_environment-name_}` で終わります。`_environment-name_` には `figure`、`tabular`、またはリストの種類（順序なしリストの `itemize`、順序付きリストの `enumerate`）のいずれかが入ります。

### 順序なしリスト

順序なしリストは `itemize` 環境で作成します。次に示すように、リストの各項目の前には `\item` コマンドを置く必要があります。

```latex
\documentclass{article}
\begin{document}
\begin{itemize}
  \item The individual entries are indicated with a black dot, a so-called bullet.
  \item The text in the entries may be of any length.
\end{itemize}
\end{document}
```

## LaTeX に数式を追加する

LaTeX の主な利点の 1 つは、数式を簡単に書けることです。LaTeX には、数式を組版するための 2 つの記述モードがあります。

* _インライン_数式モード: 段落の一部となる数式を書くために使用します
* _ディスプレイ_数式モード: テキストや段落の一部ではなく、独立した行に組版される数式を書くために使用します

### インライン数式モード

インライン数式モードの例を見てみましょう。

```latex
\documentclass[12pt, letterpaper]{article}
\begin{document}
In physics, the mass-energy equivalence is stated 
by the equation $E=mc^2$, discovered in 1905 by Albert Einstein.
\end{document}
```

```latex
This line will start a second paragraph.

I will start the third paragraph and then add \\ a manual line break which causes this text to start on a new line but remains part of the same paragraph. Alternatively, I can use the \verb|\newline|\newline command to start a new line, which is also part of the same paragraph.
```

### 章と節

長い文書は、作成するソフトウェアにかかわらず、通常は部、章、節、小節などに分割されます。LaTeX にも文書を構造化するコマンドがありますが、利用できるコマンドとその実装（何をするか）は、使用する文書クラスによって異なる場合があります。たとえば、`book` クラスで作成した文書は部、章、節、小節などに分割できますが、`letter` クラスにはそのためのコマンドが用意されていません（サポートされていません）。

次の例は、`book` クラスに基づく文書を構造化するためのコマンドを示しています。

```latex
\documentclass{book}
\begin{document}

\chapter{First Chapter}

\section{Introduction}

This is the first section.

Lorem  ipsum  dolor  sit  amet,  consectetuer  adipiscing  
elit. Etiam  lobortisfacilisis sem.  Nullam nec mi et 
neque pharetra sollicitudin.  Praesent imperdietmi nec ante. 
Donec ullamcorper, felis non sodales...

\section{Second Section}

Etiam lobortis facilisissem.  Nullam nec mi et neque pharetra 
sollicitudin.  Praesent imperdiet mi necante...

\subsection{First Subsection}
Praesent imperdietmi nec ante. Donec ullamcorper, felis non sodales...

Etiam lobortis facilisissem...
\end{document}
```

セクション分けのコマンドの名前は、ほとんどが見たとおりの意味です。たとえば、`\chapter{First Chapter}` は `First Chapter` というタイトルの新しい章を作成し、`\section{Introduction}` は `Introduction` というタイトルの節を作成します。節はさらに `\subsection{...}` や `\subsubsection{...}` に分割できます。節や小節などの番号付けは自動ですが、`\section*{...}` や `\subsection*{...}` のように、末尾にアスタリスク（\*）が付いた該当コマンドの、いわゆる_スター付きバージョン_を使用すると無効にできます。

* `\section{section}`

### 罫線を追加する

`tabular` 環境では、表の一部として水平線と垂直線（罫線）を使用できます。

* 行の上下に水平の罫線を追加するには、`\hline` コマンドを使用します
* 列の間に垂直の罫線を追加するには、縦線パラメーター `|` を使用します

この例では、引数は `{|c|c|c|}` で、垂直線（罫線）で区切られた 3 つの（中央揃えの）列を宣言しています。さらに、`\hline` を使って最初の行の上と最後の行の下に水平の罫線を配置しています。

```latex
\begin{center}
\begin{tabular}{|c|c|c|} 
 \hline
 cell1 & cell2 & cell3 \\ 
 cell4 & cell5 & cell6 \\ 
 cell7 & cell8 & cell9 \\ 
 \hline
\end{tabular}
\end{center}
```

## LaTeX パッケージの検索と使用

LaTeX は優れた組版機能を提供するだけでなく、アドオン_パッケージ_を使った_拡張のためのフレームワーク_も提供しています。LaTeX は「何でもやろうとする」コマンドや機能を提供しようとするのではなく、_拡張可能_であるように設計されており、ユーザーはより専門的な組版機能を提供したり、表の組版など LaTeX の組み込み機能を拡張したりする外部のコード（パッケージ）を読み込むことができます。[画像を追加する](/ja/texlive/latex-basics/learn-latex-in-30-minutes#Adding%5Fimages)のセクションで見たように、`graphicx` パッケージは画像ファイルを取り込むコマンドを提供して LaTeX を拡張するもので、（プリアンブルで）次のように記述して読み込みました。

```latex
\usepackage{graphicx}
```

### パッケージの読み込み

前述のとおり、パッケージは文書のプリアンブルで `\usepackage` コマンドを使って読み込みます。ただし、（多くの）LaTeX パッケージには動作を設定するための一連の_オプション_が用意されているため、`\usepackage` コマンドは次のような形になることがよくあります。

```latex
\usepackage[options]{somepackage}
```

角括弧「`[...]`」は、`somepackage` を読み込む際に適用するオプションを LaTeX に伝えます。ユーザーが指定するオプションの中で、個々のオプションや設定は通常カンマで区切ります。たとえば、[geometry パッケージ](https://ctan.org/pkg/geometry)には LaTeX でページレイアウトを設定するための多くのオプションがあるため、`geometry` の典型的な使い方は次のようになります。

```latex
\usepackage[total={6.5in,8.75in},
top=1.2in, left=0.9in, includefoot]{geometry}
```

`geometry` パッケージは、世界中の LaTeX コミュニティのメンバーによって作成・提供され、使いたい人なら誰でも無料で利用できるパッケージの一例です。

LaTeX パッケージにオプションがない場合や、ユーザーがパッケージのオプションのデフォルト値を使用したい場合は、次のように読み込みます。

```latex
\usepackage{somepackage}
```

`\usepackage[...]{somepackage}` と書くと、LaTeX は対応する `_somepackage_.sty` というファイルを探し、それを読み込んで処理します。これにより、パッケージのコマンドが使用可能になり、そのパッケージが提供するその他のコードが実行されます。LaTeX が `_somepackage_.sty` を見つけられない場合は、次の Overleaf の例に示すように、エラーで終了します。

```latex
\documentclass[12pt, letterpaper]{article}
\usepackage{somepackage}% a NON-EXISTENT package
\begin{document}
This will fail!
\end{document}
```

### Overleaf で利用できるパッケージ: TeX Live の紹介

年に一度、CTAN でホストされているパッケージの（大きな）_サブセット_に、LaTeX 関連のフォントやその他のソフトウェアを加えたものがまとめられ、[TeX Live](https://tug.org/texlive/) と呼ばれるシステムとして配布されます。これを使って、自分の（ローカルな）LaTeX 環境をインストールできます。実は、[Overleaf のサーバーも TeX Live を使用しており](https://www.overleaf.com/learn/latex/Overleaf_and_TeX_Live)、TeX Live の新しいバージョンがリリースされると更新されます。Overleaf の TeX Live の更新はすぐには行われず、リリースから数か月後に実施されます。その間に、新しい TeX Live バージョンと[ギャラリーにある数千ものテンプレート](https://www.overleaf.com/gallery)との互換性テストを行います。たとえば、こちらは [TeX Live 2025 へのアップグレードのお知らせ](https://www.overleaf.com/blog/tex-live-2025-is-now-available)です。

TeX Live には CTAN パッケージの（大きな）_サブセット_が含まれていますが、[碁の盤面を組版する igo](https://ctan.org/pkg/igo?lang=en) のように、CTAN でホストされていても TeX Live には含まれておらず（TeX Live で配布されておらず）、そのため Overleaf では利用できない興味深いパッケージが見つかることもあります。CTAN でホストされている一部のパッケージは、さまざまな理由で TeX Live に含まれていません。たとえば、パッケージが古くなっている、ライセンスに問題がある、非常に新しい（最近アップロードされた）、Windows では動作するが Linux では動作しないなどのプラットフォーム依存性がある、といった理由です。

新しいパッケージや既存パッケージの更新は年間を通じて CTAN にアップロードされますが、TeX Live の更新は年に一度配布されます。そのため、現在のバージョンの TeX Live に含まれるパッケージは、CTAN でホストされているものほど最新ではありません。Overleaf のサーバーは TeX Live を使用しているため、サーバーにインストールされている（つまりユーザーが利用できる）パッケージが CTAN で入手できる最新バージョンではない可能性がありますが、一般的にこれが問題になることはまずありません。
