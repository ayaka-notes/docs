PDF 作成機能のアップデートが重ねられたことで、PDF のアクセシビリティが実現可能になりました。[LaTeX Tagging Project](https://latex3.github.io/tagging-project/documentation/) をはじめとする取り組みにより、LaTeX ベースの PDF もアクセシブルにできるようになり、改善は現在も続いています。

<Check>

特に [TeX Live 2025](https://www.overleaf.com/blog/tex-live-2025-is-now-available) のリリースにより、Overleaf でこのプロセスが可能になりました。MathML を使用する場合は、**LuaLaTeX** が推奨されるコンパイラであることに注意してください。

[コンパイラと TeX Live のバージョンを変更する方法](https://docs.overleaf.com/getting-started/recompiling-your-project/selecting-a-tex-live-version-and-latex-compiler)を確認して、プロジェクトの設定を適切に構成してください。

</Check>

私たちのアプローチは主に LaTeX Project の[アクセシブルな PDF に関する手順](https://latex3.github.io/tagging-project/documentation/usage-instructions)に基づいています。以下のトピックの詳細については、そちらを参照してください。

<Warning>

これらの手法を実践しても、プロジェクトのすべての要素がアクセシブルになることが保証されるわけではありません。詳細については、このページの FAQ セクションを参照してください。

</Warning>

### <Icon icon="tag" /> タグ付け

PDF のタグ付けとは、本質的には、スクリーンリーダーが容易に識別でき、現在も将来も検索しやすい「構造」を自動的に作成するプロセスです。LaTeX コードで定義された既存の構造を活用するため、スクリーンリーダーは見出し、本文、図、数式などの要素を区別できます。

TeX Live 2025 は、`\DocumentMetaData` 宣言による PDF の自動タグ付けを完全にサポートしています。この宣言は `\documentclass` の前に追加します。この宣言には、タグ付け機能に影響する 2 つの重要なキー `tagging` と `tagging-setup` があります。

#### **`tagging`**

`tagging` キーを `on` に設定して、タグ付けが有効になっていることを確認します。

```latex wrap expandable
\DocumentMetadata{tagging=on}
```

#### **`tagging-setup`**

`tagging-setup` キーの値を変更して、ドキュメントのタグ付け方法を設定します。

```latex wrap expandable
\DocumentMetadata{tagging=on,tagging-setup={math/setup=mathml-SE}}
```

<Info>

この例では、MathML 構造要素によるタグ付けのために \`math/setup=mathml-SE\` を使用していますが、\[\`\tagpdfsetup\`]\(https://ctan.math.washington.edu/tex-archive/macros/latex/contrib/tagpdf/tagpdf.pdf) がサポートする任意の値を設定できます。

</Info>

### <Icon icon="text-size" /> 説明

自動タグ付けに加えて、特にドキュメントに画像や表が含まれている場合は、要素の内容の説明を追加する必要があることもあります。

#### <Icon icon="image" /> 画像

Overleaf では、画像に重要な説明を簡単に追加できます。これは、LaTeX コードを参照する際に特定の画像の文脈を理解するのにも役立ちます。`\includegraphics` の各インスタンスに、対応する画像の説明オプションを追加するだけです。アクセシビリティの観点から区別すべき画像には、代替（alt）テキストが必要な画像、アーティファクト、実際のテキストに置き換えられる画像の 3 種類があります。

**代替テキスト**

画像に代替テキストを追加すると、その写真にビジュアルの代わりとなるテキストベースの説明が付与されます。`alt` キーを使用して、テキスト値を入力します。

```latex title="Alt text example" wrap
\includegraphics[width=0.25\linewidth,alt={Macro photo of a green frog's head and hands}]{frog.jpg}
```

**アーティファクト**

画像をスクリーンリーダーで読み上げる必要がない場合（つまり、純粋な装飾である場合）は、その画像をアーティファクトとしてマークします。値を割り当てずに `artifact` キーを使用します。

```latex title="Artifact example" wrap
\includegraphics[artifact]{.jpg}
```

**実際のテキスト**

画像が Unicode 文字の画像にすぎない場合は、テキストベースの文字を含めます。`actualtext` キーを使用し、1 文字を（括弧なしで）割り当てます。

```latex title="Actual text example" wrap
\includegraphics[actualtext=B]{.jpg}
```

#### <Icon icon="table" /> 表

表には通常テキストが含まれていますが、そのテキストが表の正しい部分に関連付けられていることが重要です。Overleaf プロジェクトの表の設定を開始するには、`tabular` の前またはプリアンブルに `\tagpdfsetup` を追加します。アクセシビリティの観点から区別すべき表には、データテーブルとプレゼンテーションテーブルの 2 種類があります。

**データテーブル**

表に少なくとも 1 つのヘッダー行がある場合は、どの行がヘッダー行であるかを指定します。`table/header-rows` キーを使用し、ヘッダー行の位置に対応する一連の数値を入力します。

```latex title="Data table example"
\tagpdfsetup{table/header-rows={1}}
\begin{tabular}{l|r}
Item & Quantity \\\hline
Widgets & 42 \\
Gadgets & 13
\end{tabular}
```

**プレゼンテーションテーブル**

表をスクリーンリーダーで表として解釈させる意図がない場合は、プレゼンテーションテーブルとしてマークします。`table/tagging=presentation` キーを使用します。

```latex title="Presentation table example"
\tagpdfsetup{table/tagging=presentation}
\begin{tabular}{cc}
\textbullet & \textbullet \\
''' & '''
\end{tabular}
```

### <Icon icon="comments-question" /> よくある質問

<Accordion title="ドキュメントがアクセシブルであることを確認するのに役立つツールはありますか？">

はい。[veraPDF](https://verapdf.org/) をはじめ、PDF/A のパートと準拠レベルを検証できる外部ツールがいくつかあります。また、[WebAIM](https://webaim.org/) などのツールを使用して、2 つの色のコントラスト比を計算することもできます。

</Accordion>

<Accordion title="Overleaf プロジェクトで使用しているパッケージは、これらの機能に対応していますか？">

LaTeX Tagging Project の[パッケージのステータス一覧](https://latex3.github.io/tagging-project/tagging-status/)を参照してください。

</Accordion>

<Accordion title="`beamer` は引き続き使用できますか？プレゼンテーション用に他のパッケージはありますか？">

`beamer` の使用には制限があります。実験的な [`ltx-talk` クラス](https://ctan.org/pkg/ltx-talk)をご確認ください。

</Accordion>

<Accordion title="Overleaf エディターはアクセシブルですか？">

はい。Overleaf は Web アプリケーションとして、アクセシビリティの専門家によって定期的に評価されている最新の Web ブラウザのアクセシビリティ機能を活用しています。最新の [Voluntary Product Accessibility Template（VPAT）](https://www.overleaf.com/for/customers/vpat)では、Web Content Accessibility Guidelines（WCAG）2.2 レベル AA への準拠が示されています。

</Accordion>

<Accordion title="Overleaf で作成した PDF は、障害を持つアメリカ人法（ADA）第 II 編およびアクセシビリティに関する欧州統一規格（EN 301 549）の要件を満たせますか？">

はい。米国と欧州の法律では、PDF が WCAG 2.1 AA を満たすことが求められています。WCAG 2.1 AA を満たすには、PDF がタグ付き PDF である必要があります。PDF のタグ付けは TeX Live 2025 でサポートされています。

</Accordion>

<Accordion title="Overleaf で作成した PDF は PDF/UA-1 規格を満たせますか？">

はい。LaTeX Project の Tagging Project は、PDF/UA-1（および今後の PDF/UA-2）で必要とされる構造タグを生成するように設計されています。ユーザーが LaTeX Project の現在のタグ付けに関する推奨事項に従えば、実質的に「PDF/UA 対応」のドキュメントを作成することになります。これは、米国と欧州の法律で求められる WCAG 2.1 AA の法的要件を満たすための最も確実な方法です。

</Accordion>

<Accordion title="コンパイラを LuaLaTeX に切り替えるにはどうすればよいですか？">

LaTeX タグ付けプロジェクトチームが推奨する LaTeX コンパイルエンジンである LuaLaTeX には、簡単に切り替えられます。Overleaf のデフォルトのコンパイラは PDFLaTeX ですが、[プロジェクト設定で LuaLaTeX に切り替える](https://docs.overleaf.com/getting-started/recompiling-your-project/selecting-a-tex-live-version-and-latex-compiler)ことができます。

</Accordion>

<Accordion title="最新バージョンの TeX Live はどこで選択できますか？">

[Overleaf Labs](https://www.overleaf.com/labs/participate) で最新版を入手できます。Overleaf Labs では、Overleaf の「rolling TeX Live」イメージにアクセスでき、最新の PDF タグ付けサポートも含まれています。この実験的な TeX Live バージョンは主に、TeX Live やパッケージの変更をテストしたり、年次の TeX Live リリースに組み込まれる前の新しいアクセシビリティ機能をプレビューしたりするためのものです。

ほとんどの PDF タグ付け機能は、標準の [TeX Live 2025](https://www.overleaf.com/blog/tex-live-2025-is-now-available) イメージで利用できます。

</Accordion>
