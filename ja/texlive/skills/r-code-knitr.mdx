Overleaf は **knitr** との連携機能を提供しており、LaTeX ドキュメントに R コードを追加して動的な出力を生成できます。

R コードを含むドキュメントは、拡張子 `.Rtex` または `.Rnw` で保存する必要があります。そうしないとコードは動作しません。例を見てみましょう。

```latex wrap
\documentclass{article}
\begin{document}

You can type R commands in your \LaTeX{} document which will be processed and their output included in the document:

<<>>=
# Create a sequence of numbers
X = 2:10

# Display basic statistical measures
summary(X)

@
\end{document}
```

![KnitrDemo1.png](/images/texlive/knitrdemo1.png)

[この `knitr` の例を Overleaf で開く](https://www.overleaf.com/project/new/template/20421?id=69881107&templateName=Knitr+demo+1&latexEngine=pdflatex&texImage=texlive-full%3A2020.1&mainFile=)

ご覧のとおり、`<<>>=` と `@` の間のテキストが R コードです。このコードとその出力は、リスト形式で出力されます。このコードの塊には、次のセクションで説明するように、動的な出力をカスタマイズするための追加パラメーターを指定できます。

### コードチャンク

前のセクションで示したようなコードブロックは、通常 _チャンク_ と呼ばれます。knitr のチャンクには追加のオプションを設定できます。以下の例を参照してください。

```latex wrap
\documentclass{article}
\begin{document}

You can type R commands in your \LaTeX{} document which will be processed and their output included in the document:

<<echo=FALSE, cache=TRUE>>=
# Create a sequence of numbers
X = 2:10

# Display basic statistical measures
summary(X)

@
\end{document}
```

![KnitrDemo2.png](/images/texlive/screenshot-2025-12-16-143420.png)

[この `knitr` の例を Overleaf で開く](https://www.overleaf.com/project/new/template/20423?id=69885763&templateName=Knitr+demo+2&latexEngine=pdflatex&texImage=texlive-full%3A2020.1&mainFile=)

`<<` と `>>` の内側に 2 つの追加オプションが渡されています。

* `echo=FALSE` コードを非表示にし、R によって生成された出力のみを表示します。
*   `cache=TRUE` cache が true に設定されている場合、チャンクは実行されず、チャンクによって生成されたオブジェクトのみが使用されます。そのチャンク内のデータが変更されていない場合、時間を節約できます。

    <Info><em>cache=TRUE オプションは現在 Overleaf ではサポートされていませんが、ローカル環境では動作するはずです。</em></Info>

その他のオプションについては、[リファレンスガイド](https://learn.overleaf.com/learn/Knitr#Reference_guide)を参照してください。

### インラインコマンド

チャンク内で生成されたオブジェクトにアクセスし、インラインで出力することができます。

```latex wrap
\documentclass{article}
\begin{document}

You can type R commands in your \LaTeX{} document which will be processed and their output included in the document:

<<echo=FALSE, cache=TRUE>>=
# Create a sequence of numbers
X = 2:10

# Display basic statistical measures
summary(X)

@

So, the mean of the data is $\Sexpr{mean(X)}$
\end{document}
```

![KnitrDemo3.png](/images/texlive/screenshot-2025-12-16-143647.png)

[この `knitr` の例を Overleaf で開く](https://www.overleaf.com/project/new/template/20425?id=69886866&templateName=Knitr+demo+3&latexEngine=pdflatex&texImage=texlive-full%3A2020.1&mainFile=)

コマンド `\Sexpr{mean(X)}` は、R コード `mean(X)` が返す出力を表示します。波括弧の中には任意の R コマンドを渡すことができます。

### プロット

次の例のように、knitr ドキュメントにはプロットも追加できます。

```latex wrap
\documentclass{article}
\begin{document}

<<plot1, fig.pos="t", fig.height=4, fig.width=4, fig.cap="First plot">>=

xdata = read.csv(file="data.txt", head=TRUE,sep=" ")

hist(xdata$data, main="Overleaf histogram", xlab="Data")

@

The figure \ref{fig:plot1} is simple histogram.

\end{document}
```

![KnitrDemo4.png](/images/texlive/screenshot-2025-12-16-143811.png)

[この `knitr` の例を Overleaf で開く](https://www.overleaf.com/project/new/template/20427?id=69890965&templateName=Knitr+demo+3&latexEngine=pdflatex&texImage=texlive-full%3A2020.1&mainFile=)

このヒストグラムは、現在の作業ディレクトリに保存された「data.txt」のデータを使用しています。チャンクには図に関連するいくつかのオプションが渡されています。

`plot1` プロットを参照するために使用するラベルです。接頭辞「fig:」は必須です。例では、図が `\ref{fig:plot1}` で参照されていることがわかります。`fig.pos="t"` 位置指定パラメーターです。これは [figure 環境](https://learn.overleaf.com/learn/Positioning_images_and_tables#The_figure_environment)で使用されるものと同じです。`fig.height=4, fig.width=4` 図の幅と高さです。`fig.cap="First plot"` 図のキャプションです。

### 外部の R スクリプト

外部の R スクリプトの一部を knitr ドキュメントにインポートできます。ドキュメントに含める前に外部プログラムでスクリプトを作成・デバッグすることはよくあるため、これは非常に便利です。

LaTeX ドキュメントに含める、`mycode.R` というファイルに次の R コードがあるとします。

```r
## ---- myrcode1
# Create a sequence of numbers
 X = 2:10

## ---- myrcode2
# Display basic statistical measures
summary(X)
```

次の行に注目してください。

```r
## ---- myrcode1
```

および

```r
## ---- myrcode2
```

これらはコードチャンクの開始を示すもので、次のコード片に示すように、このスクリプトをドキュメントで使用する場合は必須です。

```r
The chunk below will not be printed

<<echo=FALSE, cache=FALSE>>=
read_chunk("mycode.R")
@

The code must show up here

<<myrcode2>>=

@
```

![KnitrDemo5.png](/images/texlive/knitrdemo5.png)

最初のチャンクは出力されず、コマンド `read_chunk("mycode.R")` でスクリプトをインポートするためだけに使用されます。そのため、オプション `echo=FALSE` が設定されています。また、スクリプトはキャッシュしてはいけません。スクリプトをインポートしたら、`## ----` の後に設定したラベルを使ってチャンクを出力できます。この例では `myrcode2` です。

この記事のすべてのコード片を、[Overleaf で開くことができる](https://www.overleaf.com/project/new/template/20429?id=69894649&templateName=Knitr+full+demo&latexEngine=pdflatex&texImage=texlive-full%3A2020.1&mainFile=)プロジェクトにまとめています。

### リファレンスガイド

いくつかのチャンクオプション:

* `results`。R コードによって生成される結果の挙動を変更します。指定可能な値は次のとおりです。
  * `markup` LaTeX を使用して出力を整形します。
  * `asis` R の生の結果を出力します。
  * `hold` 出力結果を保持し、チャンクの末尾にまとめて出力します。
  * `hide` 結果を非表示にします。
* `echo`。R のソースコードを含めるかどうか。その他のパラメーターには次のものがあります。
  * `echo=2:3` は 2 行目と 3 行目のみを出力します。
  * `echo=-2:-3` は 2 行目と 3 行目のみを除外します。
* `cache`。コードチャンクをキャッシュするかどうか。指定可能な値は `TRUE` と `FALSE` です。
* `highlight`。ソースコードをハイライトするかどうか。指定可能な値は `TRUE` と `FALSE` です。
* `background`。チャンクの背景色。rgb および HTML 形式を使用できます。デフォルト値は _"#F7F7F7"_ です。
