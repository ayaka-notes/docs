[TeX Live](https://www.tug.org/texlive/) は、[TeX Users Group](https://www.tug.org/) が毎年公開しているフリーソフトウェアのディストリビューションです。すべての標準的なオペレーティングシステムで LaTeX ベースの組版をサポートするために必要な LaTeX パッケージ、フォント、TeX エンジン、そして数多くのソフトウェアツールを提供しています。

TeX Live は Overleaf の重要な構成要素です。Overleaf のサーバーは TeX Live を使ってあなたの LaTeX コードをコンパイルし、リアルタイムの PDF プレビューを生成しています。また、各 TeX Live リリースに含まれる 5,000 を超える LaTeX パッケージに、Overleaf のユーザーが簡単にアクセスできるようにしています。

Overleaf のサーバーでは以前の TeX Live リリースも利用できるため、プロジェクトのコンパイルに最新バージョンの TeX Live を使う必要はありません。たとえばパッケージの互換性の問題などがある場合、プロジェクトで使用する TeX Live を以前のバージョンに簡単に切り替えられます。<br />
