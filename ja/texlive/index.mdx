[TeX Live](https://www.tug.org/texlive/) は、[TeX Users Group](https://www.tug.org/) が毎年公開しているフリーソフトウェアのディストリビューションです。主要なすべての OS で LaTeX ベースの組版をサポートするために必要な LaTeX パッケージ、フォント、TeX エンジン、そして数多くのソフトウェアツールを提供しています。

TeX Live は Overleaf の重要なコンポーネントです。Overleaf のサーバーは TeX Live を使用して LaTeX コードをコンパイルし、リアルタイムの PDF プレビューを生成しています。また、各 TeX Live リリースに含まれる 5,000 以上の LaTeX パッケージを、Overleaf のユーザーが簡単に利用できるようにしています。

Overleaf のサーバーでは過去の TeX Live リリースも利用できるため、プロジェクトのコンパイルに最新バージョンの TeX Live を使う必要はありません。パッケージの互換性の問題などがある場合は、プロジェクトで以前のバージョンの TeX Live を使用するよう簡単に切り替えられます。<br />
