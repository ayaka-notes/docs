title: i18n 翻訳の更新
icon: language
---

`services/web/frontend/extracted-translations.json` というファイルがあり、Overleaf の web はこのファイル内の抽出済み翻訳のみを使用します。

コンテンツを追加した場合は、次のコマンドを実行して抽出済み翻訳を更新してください。

```bash
user ➜ ~/overleaf-pro/develop (server-pro) $ bin/shell webpack
root@432836260f8a:/overleaf/services/web# npm run extract-translations
```

基本的に、翻訳テキストファイルは編集せず、まず既存の翻訳を使用してください。これらのファイルはすべて Overleaf のアップストリームまたはサードパーティの翻訳サイトから更新されるためです。
