---
title: i18n 翻訳の更新
icon: language
---

フロントエンドが読み込むのは、`services/web/frontend/extracted-translations.json` に列挙された翻訳キーだけです（`services/web/frontend/translations-loader.js`）。バックエンドとそのテンプレートは `services/web/locales/` 内の完全なファイルを読み込みます。

初回セットアップ後に一度、また翻訳を追加したりブランチを切り替えたりした後にも、`develop` ディレクトリで次を実行してください。

```bash
bin/i18n
```

`bin/i18n` は次の 2 つを行います。

1. `services/web/locales/*.json` をコミット済みのファイルに戻し、イメージのビルドと同じ方法でロケールパッチを適用します。最も上位の `locales_patches/v*` フォルダーのファイルがロケールを置き換え、`locales_patches/added/*.json` がキー単位でその上にマージされます。
2. `webpack` コンテナ内で `node` ユーザーとして `yarn run extract-translations` を実行し、`extracted-translations.json` を書き直します。webpack イメージがない場合は、まず `bin/sync` で `yarn.lock` を同期してからイメージをビルドします。

ホストに `jq` が必要です。

<Warning>

`bin/i18n` が `services/web/locales/*.json` に加える変更はローカルのみのものです。コミットしないでください。

</Warning>

できる限り既存のキーを再利用してください。ロケールファイルは Overleaf のアップストリームまたはサードパーティの翻訳サイトから取得されるため、直接編集しないでください。新しいキーは `services/web/locales/locales_patches/added/` に、すべての言語のファイル（`en.json`、`zh-CN.json` など）に同時に追加します。
