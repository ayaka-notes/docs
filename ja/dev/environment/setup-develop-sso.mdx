開発環境では、Overleaf の LDAP、SAML、OIDC をテストする例として [goauthentik](https://goauthentik.io/) を使用しています。最も包括的な認証方式を提供しているためです。

### インストール

[goauthentik](https://goauthentik.io/) のセットアップ手順については、[こちらのページ](https://docs.goauthentik.io/install-config/install/docker-compose/)を参照してください。[goauthentik](https://goauthentik.io/) 用に新しいディレクトリを作成することを強くおすすめします。

```bash title="bash" wrap
# (Optional) mkdir ~/authentik && cd ~/authentik
wget https://docs.goauthentik.io/docker-compose.yml
echo "PG_PASS=$(openssl rand -base64 36 | tr -d '\n')" >> .env
echo "AUTHENTIK_SECRET_KEY=$(openssl rand -base64 60 | tr -d '\n')" >> .env
echo "AUTHENTIK_ERROR_REPORTING__ENABLED=true" >> .env
```

次に、以下のサービスを Overleaf の開発用ネットワークに接続します。グレーで示されたコードブロックの部分に注意してください。

```text title="authentik/docker-compose.yml" wrap expandable
services:
  postgresql:
    env_file:
    - .env
    environment:
      POSTGRES_DB: ${PG_DB:-authentik}
      POSTGRES_PASSWORD: ${PG_PASS:?database password required}
      POSTGRES_USER: ${PG_USER:-authentik}
    healthcheck:
      interval: 30s
      retries: 5
      start_period: 20s
      test:
      - CMD-SHELL
      - pg_isready -d $${POSTGRES_DB} -U $${POSTGRES_USER}
      timeout: 5s
    image: docker.io/library/postgres:16-alpine
    restart: unless-stopped
    volumes:
    - database:/var/lib/postgresql/data
    networks:
      - overleaf
  server:
    command: server
    depends_on:
      postgresql:
        condition: service_healthy
    env_file:
    - .env
    environment:
      AUTHENTIK_POSTGRESQL__HOST: postgresql
      AUTHENTIK_POSTGRESQL__NAME: ${PG_DB:-authentik}
      AUTHENTIK_POSTGRESQL__PASSWORD: ${PG_PASS}
      AUTHENTIK_POSTGRESQL__USER: ${PG_USER:-authentik}
      AUTHENTIK_SECRET_KEY: ${AUTHENTIK_SECRET_KEY:?secret key required}
    image: ${AUTHENTIK_IMAGE:-ghcr.io/goauthentik/server}:${AUTHENTIK_TAG:-2025.12.4}
    ports:
    - ${COMPOSE_PORT_HTTP:-9000}:9000
    - ${COMPOSE_PORT_HTTPS:-9443}:9443
    restart: unless-stopped
    volumes:
    - ./data:/data
    - ./custom-templates:/templates
    networks:
      - overleaf
  worker:
    command: worker
    depends_on:
      postgresql:
        condition: service_healthy
    env_file:
    - .env
    environment:
      AUTHENTIK_POSTGRESQL__HOST: postgresql
      AUTHENTIK_POSTGRESQL__NAME: ${PG_DB:-authentik}
      AUTHENTIK_POSTGRESQL__PASSWORD: ${PG_PASS}
      AUTHENTIK_POSTGRESQL__USER: ${PG_USER:-authentik}
      AUTHENTIK_SECRET_KEY: ${AUTHENTIK_SECRET_KEY:?secret key required}
    image: ${AUTHENTIK_IMAGE:-ghcr.io/goauthentik/server}:${AUTHENTIK_TAG:-2025.12.4}
    restart: unless-stopped
    user: root
    volumes:
    - /var/run/docker.sock:/var/run/docker.sock
    - ./data:/data
    - ./certs:/certs
    - ./custom-templates:/templates
    networks:
      - overleaf
volumes:
  database:
    driver: local
networks:
  overleaf:
    external: true
    name: develop_default
```

これで `docker compose up -d` を実行してすべてのコンテナを起動できます。authentik が Overleaf に正しく接続されたかどうかを確認するには、Overleaf の開発用コンテナに入り、次を実行します。

```text
zzq ➜ ~/overleaf-pro (server-pro) $ cd develop/ && bin/shell web
node@1ed855be997c:/overleaf/services/web$ curl http://server:9000/login  
<!DOCTYPE html>
```

これで問題なく動作するはずです。ブラウザーを開き、末尾のスラッシュを含む完全な URL（`http://<your server's IP or hostname>:9000/if/flow/initial-setup/`）にアクセスします。そこで `akadmin` ユーザー（デフォルトユーザー）のパスワードを設定するよう求められます。
