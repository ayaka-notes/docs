プロジェクト一覧でユーザーに表示される通知（プロジェクトへの招待など）を Mongo の `notifications` コレクションに保存します。web と third-party-datastore が呼び出します。認証はなく、Docker ネットワーク内からのみアクセスできます。

* <strong>アドレス:</strong> `http://notifications:3042`, Docker ネットワーク内
* <strong>認証:</strong> なし
* <strong>OpenAPI ファイル:</strong> [`develop/hoppscotch/openapi/notifications.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/notifications.yaml)
