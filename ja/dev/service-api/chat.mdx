プロジェクトのチャットとコメントスレッド（メッセージと解決済み状態）を Mongo の `rooms` と `messages` コレクションに保存します。web が `ChatApiHandler` を通じて呼び出します。

* <strong>アドレス:</strong> `http://chat:3010`, Docker ネットワーク内
* <strong>認証:</strong> なし
* <strong>OpenAPI ファイル:</strong> [`develop/hoppscotch/openapi/chat.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/chat.yaml)
