エディターで開かれている文書を Redis に保持し、編集を適用して、web を通じて Mongo に書き戻します。web と real-time が呼び出します。

* <strong>アドレス:</strong> `http://document-updater:3003`, Docker ネットワーク内
* <strong>認証:</strong> なし
* <strong>OpenAPI ファイル:</strong> [`develop/hoppscotch/openapi/document-updater.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/document-updater.yaml)
