Overleaf のメインアプリである web のプライベート API です。他のサービス（real-time、document-updater、project-history、third-party-datastore、git-bridge）と Server CE イメージの cron スクリプトが呼び出します。これらのルートは HTTP Basic 認証だけが必要で、CSRF トークンは不要です。プライベートルーターは web ルーターより先にマウントされ、CSRF チェックを行うのは web ルーターだけだからです。`BLOCK_CROSS_ORIGIN_REQUESTS=true`（デフォルトはオフ）の場合、web は `Origin` ヘッダーが `ALLOWED_ORIGINS`（デフォルト: サイトの URL）に含まれないリクエストに 403 を返します。ブラウザーは POST で `Origin` を送るため、この設定がオンだと、ブラウザーの Hoppscotch から送った POST は Hoppscotch のプロキシを経由しない限り 403 になります。

* <strong>アドレス:</strong> `http://web:3000`, Docker ネットワーク内
* <strong>認証:</strong> `WEB_API_USER` と `WEB_API_PASSWORD` による HTTP Basic 認証（status、health、metrics を除く）。git-bridge のルートでは代わりに個人用アクセストークンを使います。
* <strong>OpenAPI ファイル:</strong> [`develop/hoppscotch/openapi/web.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/web.yaml)
