各プロジェクトの編集を Redis のキューに入れ、履歴の変更に変換して history-v1 に送ります。また、履歴ラベル、再同期の状態、失敗の記録を Mongo に保持します。web、document-updater、history-v1、server-ce の cron スクリプトが呼び出します。認証はありません。

* <strong>アドレス:</strong> `http://project-history:3054`, Docker ネットワーク内
* <strong>認証:</strong> なし
* <strong>OpenAPI ファイル:</strong> [`develop/hoppscotch/openapi/project-history.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/project-history.yaml)
