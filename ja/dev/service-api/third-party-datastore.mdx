プロジェクトを Dropbox と同期します。ユーザーごとに 1 つの Redis ジョブキューと、Overleaf の変更を Dropbox に送り Dropbox の変更をポーリングするワーカーを持ちます。呼び出すのは web だけで、ジョブの投入とキューのサイズの取得に使います。

* <strong>アドレス:</strong> `http://third-party-datastore:3002`, Docker ネットワーク内
* <strong>認証:</strong> なし
* <strong>OpenAPI ファイル:</strong> [`develop/hoppscotch/openapi/third-party-datastore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/third-party-datastore.yaml)
