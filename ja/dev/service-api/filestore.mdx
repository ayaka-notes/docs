オブジェクトストレージからファイルを配信します。テンプレートファイル（zip、pdf とそのプレビュー画像）と、読み取り専用で history-v1 が書き込むプロジェクトおよびグローバルの blob です。web（template-gallery モジュール、コンパイルファイルの URL）と、プロジェクトのバイナリファイルをダウンロードする clsi が呼び出します。

* <strong>アドレス:</strong> `http://filestore:3009`, Docker ネットワーク内
* <strong>認証:</strong> なし
* <strong>OpenAPI ファイル:</strong> [`develop/hoppscotch/openapi/filestore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/filestore.yaml)
