CLSI（Common LaTeX Service Interface）はプロジェクトをコンパイルし、コンパイル出力に対して SyncTeX と texcount を実行し、pandoc で文書を変換します。web が呼び出します。出力ファイル自体はこのポートではなく clsi-nginx が配信します。認証はなく、Docker ネットワーク内からのみアクセスできます。

* <strong>アドレス:</strong> `http://clsi:3013`, Docker ネットワーク内
* <strong>認証:</strong> なし
* <strong>OpenAPI ファイル:</strong> [`develop/hoppscotch/openapi/clsi.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/clsi.yaml)
