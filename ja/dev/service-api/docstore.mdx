すべてのプロジェクトのすべての文書（行、バージョン、範囲）を Mongo の `docs` コレクションに保存し、バックエンドが設定されている場合は文書をオブジェクトストレージにアーカイブします。web が呼び出し、document-updater は web を経由してアクセスします。

* <strong>アドレス:</strong> `http://docstore:3016`, Docker ネットワーク内
* <strong>認証:</strong> なし
* <strong>OpenAPI ファイル:</strong> [`develop/hoppscotch/openapi/docstore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/docstore.yaml)
