すべてのプロジェクトの完全な履歴を保存します。変更のチャンクを Mongo または Postgres とオブジェクトストレージに、ファイルの内容を blob として保存します。project-history が変更を書き込み、web、project-history、git-bridge が blob、スナップショット、zip を読み取ります。

* <strong>アドレス:</strong> `http://history-v1:3100`, Docker ネットワーク内
* <strong>認証:</strong> ルートに応じて、`STAGING_PASSWORD` を使った `staging` としての HTTP Basic 認証、または JWT。
* <strong>OpenAPI ファイル:</strong> [`develop/hoppscotch/openapi/history-v1.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/history-v1.yaml)
