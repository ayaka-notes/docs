title: Messages コレクション

`messages` にはメッセージごとに 1 つのドキュメントが保存されます。プロジェクトチャットの 1 行、またはレビューコメントスレッドのコメントや返信です。書き込むのは chat サービスだけで、`services/chat/app/js/Features/Messages/MessageManager.js` で行われます。Mongoose スキーマはありません。各メッセージは [rooms](/ja/dev/data-model/rooms-collection) コレクションのルームに属します。

#### フィールド {#fields}

| フィールド | 型 | 意味 | 出典 |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | メッセージ ID。 | `MessageManager.js:13-14` |
| `room_id` | ObjectId | ルーム（`rooms._id`）。プロジェクト ID やスレッド ID ではありません。 | `MessageManager.js:8,106-108` |
| `user_id` | ObjectId | 作成者。 | `MessageManager.js:9,103-105` |
| `content` | String | メッセージの本文。1〜10240 文字（`MAX_MESSAGE_LENGTH`）。 | `MessageManager.js:7`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:3,12-15` |
| `timestamp` | Number | 送信日時。1970 年からのミリ秒数（`Date.now()`）で、Date ではありません。 | `MessageManager.js:10`, `services/chat/app/js/Features/Messages/MessageHttpController.js:288` |
| `edited_at` | Number | 最終編集日時（ミリ秒、`Date.now()`）。一度も編集されていなければ存在しません。 | `MessageManager.js:65-69`, `MessageHttpController.js:189,213` |

#### 書き込み元 {#who-writes-it}

| コード | 処理内容 |
| ---- | ------------ |
| `MessageManager.js:5-16` `createMessage` | メッセージを挿入します（`MessageHttpController.js:275-294`）。Web は `services/web/app/src/Features/Chat/ChatController.mjs:32` からプロジェクトチャットのメッセージを送り、track-changes モジュール（`services/web/modules/track-changes/app/src/TrackChangesController.mjs:95`）と mcp-server モジュール（`services/web/modules/mcp-server/app/src/CommentTools.mjs:133`）からコメントを送ります。 |
| `MessageManager.js:51-72` `updateMessage` | `content` と `edited_at` を設定します。ユーザー ID が指定された場合は、そのユーザーのメッセージだけが一致します（`MessageManager.js:62-64`）。`ChatController.mjs:135` と `TrackChangesController.mjs:110` から呼び出されます。 |
| `MessageManager.js:74-80` `deleteMessage` | メッセージを 1 件削除します。`ChatController.mjs:105` と `TrackChangesController.mjs:129` から呼び出されます。 |
| `MessageManager.js:39-49` `deleteAllMessagesInRoom(s)` | 削除されたスレッドのメッセージ（`MessageHttpController.js:172-173`）、または削除済みプロジェクトの期限切れ時にプロジェクト全体のメッセージ（`MessageHttpController.js:261-271`、`services/web/app/src/Features/Project/ProjectDeleter.mjs:391` から呼び出し）を削除します。 |
| `MessageManager.js:115-127` `duplicateRoomToOtherRoom` | すべてのメッセージの `content`、`timestamp`、`user_id` を別のルームにコピーします。`edited_at` はコピーしません。履歴の復元でスレッドが複製されるとき（`MessageHttpController.js:316-342`）と、プロジェクトが範囲付きでコピーされるとき（`MessageHttpController.js:344-357`）に使われます。 |

#### 読み取り元 {#who-reads-it}

| コード | 処理内容 |
| ---- | ------------ |
| `MessageManager.js:18-29` `getMessages` | 新しい順に、`before`（`timestamp` の値）より古いものを最大 `limit` 件（既定 50）返します。プロジェクトチャットで使われます（`ChatController.mjs:80`）。 |
| `MessageManager.js:31-37` `findAllMessagesInRooms` | いくつかのルームの全メッセージ。レビューパネルのスレッド一覧（`TrackChangesController.mjs:82`）、mcp-server モジュール（`CommentTools.mjs:83`）、履歴の復元（`services/web/app/src/Features/History/RestoreManager.mjs:259`）で使われます。Web は、レビュアーが自分で始めたスレッドだけを変更できるよう、スレッドの最初のメッセージも確認します（`services/web/app/src/Features/Authorization/AuthorizationManager.mjs:409-411`）。 |
| `MessageManager.js:90-100` `getMessage` | メッセージ 1 件。ユーザーが自分のメッセージを編集または削除する前に、Web はその `user_id` を確認します（`services/web/app/src/Features/Authorization/AuthorizationMiddleware.mjs:253-257`、`TrackChangesController.mjs:124-125`）。 |

#### 注意事項 {#notes}

* コメントのメッセージを探すには、まず `project_id` と `thread_id` でルームを検索し、次に `room_id` で検索します。ドキュメント内のコメント ID は `thread_id` であり、`room_id` ではありません。
* コメントが指すテキストは `docs.ranges.comments` の `op.c` にあり、議論はここにあります。
