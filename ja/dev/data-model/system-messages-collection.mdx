---
title: System Messages コレクション
icon: bullhorn
---

`systemmessages` は、管理者がログイン中の全ユーザー向けに掲示するサイト全体のバナーを保持します。1 つのドキュメントは 1 件のメッセージです。`web` が管理しており、スキーマは `services/web/app/src/models/SystemMessage.mjs`、コードは `services/web/app/src/Features/SystemMessages/SystemMessageManager.mjs` です。

#### フィールド {#fields}

| フィールド | 型 | 意味 | 出典 |
| --- | --- | --- | --- |
| `_id` | ObjectId | メッセージ id。ブラウザーはこの id で、ユーザーが閉じたメッセージを記憶します（`services/web/frontend/js/shared/components/system-message.tsx:10`）。 | `SystemMessage.mjs:5` |
| `content` | String | メッセージ本文。デフォルトは `''`。 | `SystemMessage.mjs:7` |
| `__v` | Number | Mongoose のバージョンキー。`message.save()` が追加します。 | `SystemMessageManager.mjs:29-30` |

#### 書き込むコード {#who-writes-it}

| コード | 動作 |
| --- | --- |
| `SystemMessageManager.mjs:28-33` (`createMessage`) | `POST /admin/messages` (`services/web/app/src/router.mjs:1150-1152`, `services/web/app/src/Features/ServerAdmin/AdminController.mjs:151-159`): メッセージを 1 件追加します。 |
| `SystemMessageManager.mjs:22-26` (`clearMessages`) | `POST /admin/messages/clear` (`router.mjs:1155-1157`, `AdminController.mjs:161-168`): すべてのメッセージを削除します。1 件だけを削除する方法はありません。 |

#### 読み取るコード {#who-reads-it}

| コード | 動作 |
| --- | --- |
| `SystemMessageManager.mjs:50-65` | 各 `web` プロセスはすべてのメッセージをメモリに保持し、20〜30 秒ごと、および自身による作成やクリアの直後に再読み込みします。 |
| `services/web/app/src/Features/SystemMessages/SystemMessageController.mjs:6-24` | `GET /system/messages` (`router.mjs:331`): キャッシュされたメッセージをログイン中のユーザーに返します。サイトが閉じている間（`siteIsOpen` が false）は、代わりに固定のお知らせを返します。これは Mongo には保存されていません。 |
| `AdminController.mjs:83-84` | `/admin` ページは Mongo から直接メッセージを一覧表示します。 |

#### インデックス {#indexes}

`systemmessages` にインデックスを作成するマイグレーションはありません。デフォルトの `_id` インデックスだけが存在します。

#### 補足 {#notes}

* `notifyOnSystemMessageChanges` が設定されていると、作成やクリアは Redis チャネル `refresh-system-messages` にも発行され、他の `web` プロセスがすぐに再読み込みします（`SystemMessageManager.mjs:9`、`:35-48`、`:75-87`）。設定がない場合は、次の定期的な再読み込みで変更を取り込みます。
