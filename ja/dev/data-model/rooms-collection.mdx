`rooms` には、プロジェクトのチャットルームごとに 1 つのドキュメントが保存されます。プロジェクトチャット、またはレビューコメントスレッド 1 つです。書き込むのは chat サービスだけで、`services/chat/app/js/Features/Threads/ThreadManager.js` で行われます。Mongoose スキーマはありません。ルームのメッセージは [messages](/ja/dev/data-model/messages-collection) コレクションにあります。

#### フィールド {#fields}

| フィールド | 型 | 意味 | 出典 |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | ルーム ID。`messages.room_id` はここを指します。 | `ThreadManager.js:57-61` |
| `project_id` | ObjectId | ルームが属するプロジェクト。 | `ThreadManager.js:43-54` |
| `thread_id` | ObjectId | コメントスレッドにのみ存在します。コメントの ID で、`docs.ranges.comments` 内のそのコメントの `id` および `op.t` と同じです（[docs](/ja/dev/data-model/docs-collection) を参照）。プロジェクトチャットのルームにはありません。 | `ThreadManager.js:38-55`, `services/docstore/app/js/RangeManager.js:54-57` |
| `resolved` | Object | スレッドが解決されると設定され、再オープンされると削除されます。これがないスレッドは未解決です。 | `ThreadManager.js:94-123` |
| `resolved.user_id` | String | スレッドを解決したユーザーの ID。ObjectId ではなく文字列で保存されます。リクエスト本文は有効な ID かどうかが確認されるだけで、変換されません。 | `ThreadManager.js:103`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:70` |
| `resolved.ts` | Date | スレッドが解決された日時。 | `ThreadManager.js:104` |

#### 注意事項 {#notes}

* プロジェクトには `thread_id` のないルームが最大 1 つあり、それがプロジェクトチャットです。chat サービスは `thread_id: { $exists: false }` で検索します（`ThreadManager.js:38-45`）。
* コメントの解決状態はここにしかありません。Docstore は範囲を保存する前に `op.resolved` を取り除きます（`services/docstore/app/js/RangeManager.js:59-61`）。
* プロジェクトをコピーすると、同じ `thread_id` が 2 つのプロジェクトに存在します。chat サービスと同様に、必ず `project_id` と `thread_id` を組み合わせて検索してください。
* 削除済みプロジェクトのルームは、そのプロジェクトの期限が切れるまで残ります。
