title: Users コレクション

---

`User` は Overleaf システム内の 1 つのユーザーアカウントを表します。認証データ、機能フラグ、エディターの設定、アクセス権限、アクティビティのメタデータを保存します。

#### コアアイデンティティと認証

* `_id`: ユーザーの一意な MongoDB ObjectId。
* `email` / `emails`: プライマリメールアドレスとメールアドレスの履歴。
* `hashedPassword`: ローカル認証に使用される BCrypt でハッシュ化されたパスワード。
* `first_name` / `last_name`: ユーザープロフィールの名前フィールド。
* `role` / `isAdmin` / `adminRoles`: ロールと管理者権限のフラグ。
* `twoFactorAuthentication`: 二要素認証の設定(有効な場合)。
* `samlIdentifiers` / `thirdPartyIdentifiers`: 外部アイデンティティプロバイダーとの紐付け。

#### アカウントの状態とライフサイクル

* `signUpDate`: アカウント作成のタイムスタンプ。
* `holdingAccount`: アカウントが確認待ちまたは制限されているかどうか。
* `must_reconfirm`: ユーザーがメールアドレスを再確認する必要があるかどうか。
* `lastPrimaryEmailCheck`: プライマリメールアドレスが最後に検証された日時。

#### ログインとアクティビティの追跡

* `lastLoginIp`: 最後に成功したログインの IP アドレス。
* `loginCount`: ログイン成功の合計回数。
* `loginEpoch`: ログインセッションの内部カウンター。
* `lastLoggedIn`: 最後のログインのタイムスタンプ。
* `lastActive`: 最後に記録されたアクティビティのタイムスタンプ。
* `lastFailedLogin`: 最後に失敗したログイン試行のタイムスタンプ。

#### エディターの設定(`ace`)

オンラインエディターに関するユーザーの設定を定義します。

* `theme` / `overallTheme`: エディターと UI のテーマ。
* `fontSize`: エディターのフォントサイズ。
* `autoComplete`、`autoPairDelimiters`: 編集支援機能。
* `spellCheckLanguage`: スペルチェックに使用する言語。
* `pdfViewer`: 選択された PDF ビューアーのバックエンド。
* `syntaxValidation`、`mathPreview`、`breadcrumbs`: エディターの UX 機能。
* `enableNewEditor`: 新しいエディター UI が有効かどうか。

#### 機能フラグと制限(`features`)

ユーザーが利用できる機能を制御します。

* `collaborators`: 共同編集者の最大数(`-1` = 無制限)。
* `versioning`、`trackChanges`: 履歴と変更追跡の機能。
* `dropbox`、`github`、`gitBridge`: 外部連携の利用可否。
* `compileTimeout`: 最大コンパイル時間(秒)。
* `compileGroup`: 割り当てられたコンパイルリソースグループ。
* `aiErrorAssistant`: AI ベースのコンパイルエラーアシスタントのフラグ。

#### アクセス制御とスタッフ権限(`staffAccess`)

スタッフやパブリッシャーのきめ細かなアクセス権を定義します。

* パブリッシャー、機関、グループ、管理者、実験に関するメトリクスと管理の権限。

#### 登録と連携

* `enrollment.sso`: 連携済みの SSO 登録。
* `refProviders`: 文献プロバイダーとの連携。
* `writefull`: Writefull 執筆アシスタントのアカウント状態。
* `dsMobileApp`: モバイルアプリの設定(存在する場合)。

#### プログラムと実験

* `alphaProgram` / `betaProgram` / `labsProgram`: アーリーアクセスプログラムへの参加状況。
* `labsExperiments`: 有効化された実験的機能。
* `awareOfV2`: ユーザーが V2 エディターを認識済みかどうか。

#### 紹介とチュートリアル

* `referal_id`、`refered_users`、`refered_user_count`: 紹介の追跡。
* `completedTutorials`: オンボーディングおよび機能チュートリアルの進捗。
