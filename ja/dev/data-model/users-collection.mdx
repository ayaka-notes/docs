`users` はアカウントごとに 1 つのドキュメントを保持します。ログインデータ、プロフィール、エディターの設定、機能、アクティビティを保存します。スキーマは `services/web/app/src/models/User.mjs` で、ほとんどの書き込みは `services/web/app/src/Features/User/UserUpdater.mjs` を経由します。ソース列では、`User.mjs:N` はこのスキーマの行を表し、パスのないその他のファイル名は `services/web/app/src/Features/` 配下、`modules/...` は `services/web/` 配下にあります。行番号は執筆時点の `server-pro` のものです。

#### 機能フラグと制限(`features`) {#feature-flags-&-limits-features}

`features` は計算結果であり、手動で編集するものではありません。`FeaturesUpdater` は `Settings.defaultFeatures` から始めて、期限切れでない `featuresOverrides` のエントリをすべてマージし、結果を `featuresUpdatedAt` とともに書き込みます(`FeaturesUpdater.mjs:220-300`、`UserFeaturesUpdater.mjs:10-24`)。本番イメージは `collaborators`、`dropbox`、`versioning`、`compileTimeout`、`compileGroup`、`trackChanges`、`references` をデフォルトとして設定します(`server-ce/config/settings.js:301-309`)。その他のキーは未設定のままです。

Ayakaleaf Pro では、管理パネルがユーザーごとに機能をオフにします。`admin-tools` モジュールはこれを `note: 'admin-panel'` を持つ `featuresOverrides` のエントリとして保存し(`modules/admin-tools/app/src/AdminFeatures.mjs:13-30`)、`instance-features` モジュールは未設定のキーをオンとして扱います(`modules/instance-features/app/src/UserFeatures.mjs:12-14`)。

#### 注意事項 {#notes}

* Mongoose の `autoIndex` はオフになっているため(`services/web/app/src/infrastructure/Mongoose.mjs:7`)、インデックスを作成するのは上記のマイグレーションだけです。
* ユーザーを削除すると、ドキュメント全体が `deletedUsers` に移動します([Deleted Users Collection](/dev/data-model/deleted-users-collection) を参照)。
