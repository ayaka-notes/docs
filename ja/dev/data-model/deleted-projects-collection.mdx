---
title: Deleted Projects コレクション
icon: trash-can
---

`deletedProjects` は削除されたプロジェクトを保持します。削除されたプロジェクトごとに 1 つのドキュメントがあり、プロジェクトドキュメント全体のコピーと削除した人が記録されます。Web が `services/web/app/src/Features/Project/ProjectDeleter.mjs` で書き込み、スキーマは `services/web/app/src/models/DeletedProject.mjs` です。完全削除までの猶予期間が過ぎると、期限切れ処理がプロジェクトのデータを破棄して `project` を空にしますが、`deleterData` を持つレコードは残ります。

ゴミ箱内のプロジェクトはここにはありません。ゴミ箱への移動は、プロジェクトの `trashed` にユーザーを追加するだけです。[Projects コレクション](/ja/dev/data-model/projects-collection) を参照してください。

#### 書き込み元 {#who-writes-it}

| コード | 処理内容 |
| ---- | ------------ |
| `ProjectDeleter.mjs:189-293`（`deleteProject`） | プロジェクトをフラッシュし、その doc を Mongo の外へアーカイブし、タグから外し、レコードを upsert して `projects` ドキュメントを削除します。 |
| `ProjectDeleter.mjs:295-342`（`undeleteProject`） | プロジェクトを `<name> (Restored)` という名前（オーナー内で一意にしたもの）で、アーカイブされていない状態で再挿入し、レコードを削除します。`project` が `null` になると `project_too_old_to_restore` で失敗します。管理パネルから呼び出されます：1 つのプロジェクトの復元（`AdminProjectManager.mjs:497-515`）、または削除されたユーザーとアカウントと一緒に削除されたプロジェクトの復元（`services/web/modules/admin-tools/app/src/AdminUserManager.mjs:678-689`）。 |
| `ProjectDeleter.mjs:344-416`（`expireDeletedProject`） | プロジェクトの doc、履歴、チャット、プロジェクト監査ログを破棄して `projectExpired` フックを発火し、`project` と `deleterData.deleterIpAddress` を `null` に設定します。プロジェクトが再び存在する場合は、古いレコードだけを削除します。 |
| `ProjectDeleter.mjs:97-146`（`expireDeletedProjectsAfterDuration`） | 猶予期間より古いレコードをまとめて期限切れにします。ルート `POST /internal/expire-deleted-projects-after-duration`（`services/web/app/src/router.mjs:842-846`）で、`ENABLE_CRON_RESOURCE_DELETION` が `true` のとき Community Edition の cron が毎時 20 分に呼び出します（`server-ce/cron/delete-projects.sh:10-23`, `server-ce/config/crontab-deletion:3`）。1 つのプロジェクトの場合：`POST /internal/project/:projectId/expire-deleted-project`（`router.mjs:852-856`）、または管理パネルの Purge（`AdminProjectManager.mjs:517-529`）。 |

#### 補足 {#notes}

* `projectExpired` をリッスンするモジュールは、そのプロジェクトの自分のデータを削除します：`git-bridge`（`services/web/modules/git-bridge/index.mjs:37`）、`github-sync`（`services/web/modules/github-sync/index.mjs:56`）、`gitlab-sync`（`services/web/modules/gitlab-sync/index.mjs:46`）、`gitea-sync`（`services/web/modules/gitea-sync/index.mjs:46`）、`dropbox`（`services/web/modules/dropbox/index.mjs:54`）。
* 期限切れのレコードが削除されることはありません。`deleterData` は永久に残り、`project` と IP アドレスだけが空になります。
* Mongoose は `deleterData` にも独自の `_id` を付けますが、それを読むものはありません。
