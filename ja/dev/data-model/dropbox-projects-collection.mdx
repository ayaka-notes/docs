title: Dropbox Projects コレクション
icon: folder-open

`dropboxProjects` は、プロジェクトを 1 人のユーザーの Dropbox 内のフォルダーに対応付けます。複数の Dropbox ユーザーと共有されているプロジェクトには、ユーザーごとに 1 つのドキュメントがあります。このコレクションは Dropbox 同期に属します。third-party-datastore（`services/third-party-datastore/app/js/StateManager.mjs`）が書き込み、web モジュール `dropbox`（`services/web/modules/dropbox/app/src/DropboxHandler.mjs`）が読み取りと削除を行います。Mongoose スキーマはありません。

#### フィールド {#fields}

| フィールド | 型 | 意味 | ソース |
| ---------- | -- | ---- | ------ |
| `_id` | ObjectId | 挿入時にドライバーが設定します。 | `StateManager.mjs:144` |
| `userId` | ObjectId | そのフォルダーがある Dropbox の持ち主である Overleaf ユーザー。 | `StateManager.mjs:145` |
| `projectId` | ObjectId | フォルダーに同期されるプロジェクト。 | `StateManager.mjs:146` |
| `dropboxId` | String | Dropbox のフォルダーメタデータにおけるフォルダーの `id`。 | `StateManager.mjs:147`、`JobProcessor.mjs:82-87`、`PullManager.mjs:138` |
| `pathLower` | String | Dropbox 内のフォルダーのパス。小文字で、末尾のスラッシュはありません。プロジェクトフォルダーは最上位にプロジェクトごとに 1 つあり、たとえば別のプロジェクトの `Thesis` の隣で Dropbox が番号を付けた場合は `/thesis (1)` になります。 | `StateManager.mjs:14-16,148`、`PullManager.mjs:112-117` |

| `JobProcessor.mjs:174-203`（`renameProject`） | プロジェクト名の変更でフォルダーが移動した後、新しいパスを記録します。フォルダーがなくなっている場合は対応付けを削除します（`:190`）。 |
| `services/third-party-datastore/app/js/PullManager.mjs:119-140`（`resolveProject`） | pull が対応付けのないフォルダーを見つけたとき、web が名前で照合したプロジェクトを記録します。 |

| `DropboxHandler.mjs:150-154`（`removeProjectState`） | 削除済みプロジェクトの期限切れ時に、そのプロジェクトのドキュメントを削除します（`index.mjs:54-56`）。 |

CE にはここに他のインデックスはありません。ユニークインデックス `projectId_userId_1` と `userId_dropboxId_1` は `tools/migrations/20220815105500_create_dropboxProjects_index.mjs` と `20220817120900_create_dropboxProjects_index.mjs` から作られますが、これらには `saas` タグしかないため、CE では実行されません。

#### 注意事項 {#notes}

* 一意性は、`setProjectFolder` で各挿入の前に行う削除だけによって保たれます（`StateManager.mjs:140-149`）。`StateManager.mjs:3-11` のコメントはユニークインデックスに触れていますが、CE にはありません。
* プロジェクトの対応付けが削除されても、そのフォルダーは Dropbox に残ります。そこでの編集は、Dropbox で作成したフォルダーと同様に新しいプロジェクトとして読み取られます（`DropboxHandler.mjs:148-149`）。
* 削除済みプロジェクトはまだ復元できるため、期限切れになるまで対応付けを保持します（`index.mjs:52-53`）。
* ユーザーの Dropbox `list_folder` カーソルはここにはありません。`users.dropbox.cursor` にあります（`StateManager.mjs:177-184`）。
