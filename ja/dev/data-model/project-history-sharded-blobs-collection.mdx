---
title: Project History Sharded Blobs コレクション
icon: cubes-stacked
---

`projectHistoryShardedBlobs` には、[projectHistoryBlobs](/dev/data-model/project-history-blobs-collection) に収まらなかった blob レコードが保存されます。ハッシュプレフィックスのバケットにすでに 8 件のレコードがある場合、以降のレコードはここに入ります。1 つのプロジェクトにつき最大 16 ドキュメントで、ハッシュの先頭の 16 進数字ごとに 1 つです。Mongoose スキーマはありません。history-v1 が `services/history-v1/storage/lib/blob_store/mongo.js` で書き込みます（レイアウトの説明は `mongo.js:1-16`）。

#### フィールド {#fields}

| フィールド | 型 | 意味 | 出典 |
| ----- | ---- | ------- | ------ |
| `_id` | Binary | 13 バイト。プロジェクトの履歴 ID（`0`）とシャード番号で、16 進数として読みます（`<history id>0<digit>`）。シャード番号はハッシュの先頭の 16 進数字です。 | `mongo.js:439-453` |
| `blobs` | Object | バケットごとにまとめられた blob レコード。バケットのキーはハッシュの 2〜4 桁目の 16 進数字です。 | `mongo.js:439-443` |
| `blobs.<bcd>` | Array of Object | バケットのレコード。コード上のサイズ制限はありません。 | `mongo.js:399-407` |
| `blobs.<bcd>[].h` | Binary | ハッシュ。20 バイトで、projectHistoryBlobs と同じです。 | `mongo.js:472` |
| `blobs.<bcd>[].b` | Number | 内容のバイト長。 | `mongo.js:473` |
| `blobs.<bcd>[].s` | Number | テキストとしての内容の長さ。内容が編集可能なテキストでない場合は `null` です。 | `mongo.js:474` |

#### 書き込み元 {#who-writes-it}

| コード | 処理内容 |
| ---- | ------------ |
| `services/history-v1/storage/lib/blob_store/mongo.js:399-407` | `insertRecordSharded`: `$addToSet` でバケットに upsert します。projectHistoryBlobs のバケットが満杯のときに `insertBlob` から呼び出されます（`mongo.js:387-389`）。 |
| `mongo.js:75-103` | `clone`: プロジェクトのシャードを別の履歴 ID にコピーします。history-v1 `POST /projects/:project_id/clone` 用ですが、Web から呼び出すコードはありません。 |
| `mongo.js:413-422` | `deleteBlobs`: history-v1 `DELETE /projects/:project_id` で、プロジェクトのすべてのシャードを projectHistoryBlobs のドキュメントとともに削除します。 |

#### 読み取り元 {#who-reads-it}

| コード | 処理内容 |
| ---- | ------------ |
| `mongo.js:144-157` | `findBlobSharded`: blob 1 件。projectHistoryBlobs のバケットに 8 件のレコードがあり、その中にない場合にだけ検索されます（`mongo.js:127-131`）。 |
| `mongo.js:217-260` | `findBlobsSharded`: `findBlobs` が projectHistoryBlobs で見つけられなかった blob（`mongo.js:202-206`）。 |
| `mongo.js:285-306` | `getProjectBlobs`: プロジェクトのすべてのシャード。 |
| `mongo.js:337-361` | `getProjectBlobsBatch`: 複数プロジェクトのすべてのシャード。blob 統計ルート用です。 |

#### インデックス {#indexes}

既定の `_id` インデックスのみです。`tools/migrations/` のマイグレーションでインデックスを追加するものはありません。

#### 注意事項 {#notes}

* 1 つのプロジェクトのシャードは `_id` の順に隣り合って並ぶため、コードは `<history id>00` から `<history id>0f` までの `_id` 範囲で検索します（`mongo.js:75-80`、`287-295`）。
* このコレクションは、あるプロジェクトで同じ 3 桁のハッシュプレフィックスを持つ blob が 8 件を超えたときに初めて現れます。そのため、小規模なインスタンスにはまったく存在しない場合があります。
