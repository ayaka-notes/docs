---
title: GitHub Sync User Credentials コレクション
icon: key
---

`githubSyncUserCredentials` は、GitHub Sync のために GitHub アカウントをリンクしたユーザーごとに 1 つのドキュメントを保持します。 ユーザーの OAuth アクセストークンを暗号化して保存します。 このコレクションは `github-sync` Web モジュール（`services/web/modules/github-sync`）に属します。スキーマは `services/web/modules/github-sync/app/models/githubSyncUserCredentials.mjs` にあり、すべてのアクセスは `services/web/modules/github-sync/app/src/TokenManager.mjs` を経由します。

#### フィールド {#fields}

| フィールド | 型 | 意味 | 出典 |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | upsert が挿入するときに Mongoose が設定します。 | |
| `userId` | ObjectId | Overleaf ユーザー。必須。スキーマには `unique: true` とありますが、インデックスは作成されません（「インデックス」を参照）。`userId` による upsert でユーザーごとに 1 つのドキュメントが保たれます。 | `githubSyncUserCredentials.mjs:8`, `TokenManager.mjs:44-48` |
| `github` | String | GitHub の OAuth アクセストークン。`@overleaf/access-token-encryptor` で暗号化されます。パスワードは `GITHUB_TOKEN_CIPHER_PASSWORD` から取得し、暗号ラベルは `GITHUB_TOKEN_CIPHER_LABEL`（デフォルト `2026.3-v3`）です。必須。 | `githubSyncUserCredentials.mjs:9`, `TokenManager.mjs:12-25` |
| `__v` | Number | Mongoose のバージョンキー。スキーマでは無効化されていません。 | Mongoose のデフォルト |

保存されるのはアクセストークンだけです。OAuth コールバックは GitHub の応答から `access_token` のみを保持します（`services/web/modules/github-sync/app/src/GitHubApiClient.mjs:180-191`）。リフレッシュトークンや有効期限はありません。

#### 書き込み元 {#who-writes-it}

| コード | 処理内容 |
| ---- | ------------ |
| `TokenManager.mjs:42-58` (`saveUserToken`) | ユーザーの暗号化されたトークンを upsert します。ユーザーが再度リンクすると、置き換えられたトークンはバックグラウンドで GitHub 上で取り消されます。OAuth コールバックから呼び出されます（`services/web/modules/github-sync/app/src/GitHubSyncController.mjs:146`）。 |
| `TokenManager.mjs:61-76` (`removeUserToken`) | GitHub でトークンを取り消し（ベストエフォート）、その後ドキュメントを削除します。リンク解除時（`GitHubSyncController.mjs:167`）と、削除済みユーザーが期限切れになったとき（`services/web/modules/github-sync/index.mjs:66-68`）に呼び出されます。 |

#### 読み取り元 {#who-reads-it}

| コード | 処理内容 |
| ---- | ------------ |
| `TokenManager.mjs:36-40` (`getUserToken`) | GitHub API を呼び出すたびにトークンを復号します: `services/web/modules/github-sync/app/src/GitHubSyncHandler.mjs`（例: `:27`）と `services/web/modules/github-sync/app/src/GitMerge.mjs:43`。ドキュメントがない場合や復号できないトークンの場合は `InvalidTokenError` をスローし、ユーザーはリンクされていないものとして扱われます（`GitHubSyncHandler.mjs:25-37`）。 |
| `services/web/modules/admin-tools/app/src/AdminUserListManager.mjs:393` | 管理パネルに表示する連携のために、ユーザーがドキュメントを持っているかを確認します。 |

#### インデックス {#indexes}

| 名前 | キー | オプション | マイグレーション |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

Mongoose の `autoIndex` は無効（`services/web/app/src/infrastructure/Mongoose.mjs:7`）なので、スキーマの `userId` にある `unique: true` は何も作成しません。 `tools/migrations/20190912145011_create_githubSyncUserCredentials_indexes.mjs`（upstream の `user_id`）は `saas` タグのみが付いており、CE では実行されません。

#### 補足 {#notes}

* `GITHUB_TOKEN_CIPHER_PASSWORD` を変更すると、保存済みのトークンが読めなくなります。それらのユーザーは、再度リンクするまでリンクされていないものとして扱われます。
* 削除済みユーザーは、期限切れになるまでドキュメントを保持します。
