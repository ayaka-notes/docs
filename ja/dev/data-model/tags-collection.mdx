`tags` は、ユーザーがプロジェクトダッシュボードでプロジェクトを分類するためのタグ（フォルダー）を保持します。1 つのドキュメントは 1 人のユーザーの 1 つのタグです。`web` が管理しており、スキーマは `services/web/app/src/models/Tag.mjs`、すべての書き込みは `services/web/app/src/Features/Tags/TagsHandler.mjs` を経由します。

#### フィールド {#fields}

| フィールド | 型 | 意味 | 出典 |
| --- | --- | --- | --- |
| `_id` | ObjectId | タグ id。`/tag/:tagId` ルートで使われます。 | `Tag.mjs:10` |
| `user_id` | String | タグの所有者。歴史的な理由により、ObjectId ではなく単なる文字列です。 | `Tag.mjs:7-12` |
| `name` | String | タグ名。最大 50 文字（`MAX_TAG_LENGTH`）。ユーザーごとに一意です。 | `Tag.mjs:13`, `TagsHandler.mjs:4` |
| `color` | String | 任意の色。`#a1b2c3` のような 16 進コード、または `hsl(<n>, 70%, 45%)` の値（`TAG_COLOR_REGEX`）。 | `Tag.mjs:5`, `Tag.mjs:14-22` |
| `project_ids` | Array of String | このタグに含まれるプロジェクトの id（文字列）。 | `Tag.mjs:23` |
| `__v` | Number | Mongoose のバージョンキー。`Tag.create` がドキュメントを作成するときに追加されます。 | `TagsHandler.mjs:27` |

#### 補足 {#notes}

* タグはユーザーごとです。同じプロジェクトの 2 人の共同編集者は、それぞれ自分のタグを持ちます。
* `user_id` と `project_ids` は文字列なので、ObjectId ではなく文字列の id でクエリしてください。
* ユーザーの削除（`services/web/app/src/Features/User/UserDeleter.mjs`）は `tags` に影響しません。
