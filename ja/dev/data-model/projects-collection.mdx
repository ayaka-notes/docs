`projects` にはプロジェクトごとに 1 つのドキュメントがあり、名前、オーナーとメンバー、共有、ファイルツリー、プロジェクト設定を保持します。ドキュメントの本文はここにはなく（[Docs コレクション](/ja/dev/data-model/docs-collection)を参照）、バイナリファイルは `hash` をキーに history-v1 の blob ストアに保存されます。スキーマは `services/web/app/src/models/Project.mjs` で、ファイルツリーは同じ場所にある `Folder.mjs`、`File.mjs`、`Doc.mjs` にあります。

「ソース」列の `Project.mjs:N` はそのスキーマの行番号です。パスのないその他のファイル名は `services/web/app/src/Features/` 配下、`modules/...` は `services/web/` 配下にあります。行番号は執筆時点の `server-pro` のものです。

#### 補足 {#notes}

* Mongoose の `autoIndex` はオフです（`services/web/app/src/infrastructure/Mongoose.mjs:7`）。スキーマ内の `index` オプションが存在するのは、上記のマイグレーションがそれらを作成するからにすぎません。
* マイグレーション `20250620152657_ensure_collaborator_arrays` は、存在しない `collaberator_refs`、`pendingEditor_refs`、`pendingReviewer_refs`、`readOnly_refs`、`reviewer_refs` を `[]` に設定します。
* プロジェクトを削除すると、ドキュメントは `deletedProjects` に移されます（[Deleted Projects Collection](/dev/data-model/deleted-projects-collection) を参照）。
