`projectHistoryLabels` には、ユーザーが履歴ビューでバージョンに付けたラベルが、ラベルごとに 1 ドキュメントとして保存されます。所有するのは project-history で、`services/project-history/app/js/LabelsManager.js` で書き込みます。Mongoose スキーマはありません。Web は project-history API を通じてのみアクセスします。

#### フィールド {#fields}

| フィールド | 型 | 意味 | 出典 |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | ラベル ID。 | `LabelsManager.js:81-85` |
| `project_id` | ObjectId | プロジェクト。 | `LabelsManager.js:73` |
| `comment` | String | ラベルのテキスト。 | `LabelsManager.js:74` |
| `version` | Number | ラベルが指すプロジェクト履歴のバージョン。 | `LabelsManager.js:75` |
| `created_at` | Date | ラベルの作成日時。リクエストで独自の時刻を渡すこともでき、渡さなければ現在時刻です。 | `LabelsManager.js:70`, `76` |
| `user_id` | ObjectId | ラベルを作成したユーザー。リクエストにユーザーがない場合は省略されます。 | `LabelsManager.js:78-80` |

#### 書き込み元 {#who-writes-it}

| コード | 処理内容 |
| ---- | ------------ |
| `services/project-history/app/js/LabelsManager.js:44-90` | `createLabel`: ラベルを挿入します。project-history `POST /project/:project_id/labels` 用です（`services/project-history/app/js/HttpController.js:1134-1171`）。ユーザーがラベルを追加すると、Web はユーザー ID 付きで呼び出します（`services/web/app/src/Features/History/HistoryController.mjs:529-546`）。 |
| `LabelsManager.js:113-126` | `deleteLabel`: プロジェクトのラベルを削除します。`DELETE /project/:project_id/labels/:label_id` 用です。プロジェクトのオーナーがラベルを削除するときに Web が使います（`HistoryController.mjs:649-670`）。 |
| `LabelsManager.js:92-111` | `deleteLabelForUser`: ユーザー自身が作成したラベルの場合にだけ削除します。`DELETE /project/:project_id/user/:user_id/labels/:label_id` 用です。オーナー以外のユーザーには Web がこれを使います。 |
| `LabelsManager.js:128-143` | `transferLabels`: あるユーザーのすべてのラベルを別のユーザーに移します。`POST /user/:from_user/labels/transfer/:to_user` 用です（`services/project-history/app/js/Router.js:52-55`）。Web にはこのルートを呼び出すコードはありません。 |
| `LabelsManager.js:7-25` | `cloneLabels`: プロジェクトのラベルを別のプロジェクトにコピーします。project-history `POST /project/:project_id/clone` 用です（`HttpController.js:113`）が、Web から呼び出すコードはありません。 |

#### 読み取り元 {#who-reads-it}

| コード | 処理内容 |
| ---- | ------------ |
| `LabelsManager.js:27-42` | `getLabels`: プロジェクトのすべてのラベルを `{ id, comment, version, user_id, created_at }` の形で返します（`LabelsManager.js:163-171`）。`GET /project/:project_id/labels` で使われ（`HttpController.js:1076-1100`）、Web は履歴ビューのためにこれを呼び出してユーザー名を補います（`HistoryController.mjs:488-499`）。 |
| `services/project-history/app/js/SummarizedUpdatesManager.js:57` | ラベルを履歴の更新一覧に追加します。 |

#### 注意事項 {#notes}

* ラベルを挿入する前に、project-history はプロジェクトのキューにある更新を処理し、history-v1 にそのバージョンの chunk があるかを確認します。ただしリクエストが `validate_exists: false` を送った場合は除きます（`LabelsManager.js:53-59`、`173-195`、`HttpController.js:1109-1115`）。
* プロジェクトが削除されても、そのラベルを削除するコードはありません。project-history `DELETE /project/:project_id` は同期状態と失敗レコードを消すだけで（`HttpController.js:1363-1396`）、ほかのサービスはこのコレクションに触れません。
