---
title: OAuth Authorization Codes コレクション
icon: lock-open
---

`oauthAuthorizationCodes` は、OAuth の認可コードフローのコードを格納するためのものです。コード 1 つにつき 1 つのドキュメントで、クライアントはこれをアクセストークンと交換します。スキーマは `services/web/app/src/models/OauthAuthorizationCode.mjs` で、ここに書き込むはずのコードは web モジュール `oauth2-server` にあります。Ayakaleaf Pro ではそのコードに到達する処理がないため、コレクションは空のままです（補足を参照）。

#### フィールド {#fields}

| フィールド | 型 | 意味 | 出典 |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | ドキュメント id。 | `OauthAuthorizationCode.mjs:6` |
| `authorizationCode` | String | コードそのもの。そのまま保存されます（ハッシュ化されません）。 | `OauthAuthorizationCode.mjs:8`, `services/web/modules/oauth2-server/app/src/OAuth2Model.mjs:280` |
| `expiresAt` | Date | 有効期限。これを過ぎると `getAuthorizationCode` はコードを拒否し、TTL インデックスが削除します。 | `OauthAuthorizationCode.mjs:9`, `OAuth2Model.mjs:150-153,281` |
| `oauthApplication_id` | ObjectId | コードを要求した [OAuth Applications](/ja/dev/data-model/oauth-applications-collection) のクライアント。 | `OauthAuthorizationCode.mjs:10`, `OAuth2Model.mjs:275-284` |
| `redirectUri` | String | リクエストのリダイレクト URI。 | `OauthAuthorizationCode.mjs:11`, `OAuth2Model.mjs:282` |
| `scope` | String | 要求されたスコープ。 | `OauthAuthorizationCode.mjs:12`, `OAuth2Model.mjs:283` |
| `user_id` | ObjectId | コードを許可したユーザー。 | `OauthAuthorizationCode.mjs:13`, `OAuth2Model.mjs:285` |
| `codeChallenge`, `codeChallengeMethod` | String | PKCE のチャレンジとその方式。 | `OauthAuthorizationCode.mjs:14-15`, `OAuth2Model.mjs:286-287` |

#### 書き込み元 {#who-writes-it}

| コード | 処理内容 |
| ---- | ------------ |
| `OAuth2Model.mjs:274-300` (`saveAuthorizationCode`) | コードを挿入します。実行されません。補足を参照してください。 |
| `OAuth2Model.mjs:307-312` (`revokeAuthorizationCode`) | 使用済みのコードを削除します。実行されません。 |

#### 読み取り元 {#who-reads-it}

| コード | 処理内容 |
| ---- | ------------ |
| `OAuth2Model.mjs:137-177` (`getAuthorizationCode`) | コードをユーザーとクライアントとともに読み込みます。実行されません。 |

#### インデックス {#indexes}

| 名前 | キー | オプション | マイグレーション |
| ---- | ---- | ------- | --------- |
| `expiresAt_1` | `{ expiresAt: 1 }` | TTL、`expireAfterSeconds: 0`、部分インデックス: `expiresAt` が存在 | `20230406125632_oauth_tokens_ttl.mjs` |

マイグレーションは `tools/migrations/` にあります。一意インデックス `authorizationCode_1` はタグ `saas` と `server-pro` のマイグレーションからのみ作成され、Community Edition はこれらを実行しません。

#### 補足 {#notes}

* 上記のモデルメソッドを呼び出すのは `@node-oauth/oauth2-server` の authorize ハンドラーと token ハンドラーだけです。web はこのライブラリを bearer トークンの検証にのみ使い（`services/web/app/src/Features/Authentication/AuthenticationController.mjs:409-450`）、`/oauth/authorize` や `/oauth/token` を提供するルートもないため、コードが書き込まれることはありません。個人アクセストークンは直接作成されます。[OAuth Access Tokens](/ja/dev/data-model/oauth-access-tokens-collection) を参照してください。
