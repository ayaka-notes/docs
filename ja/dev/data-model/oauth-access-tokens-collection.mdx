---
title: OAuth Access Tokens コレクション
icon: ticket
---

`oauthAccessTokens` には、web が受け付ける bearer トークンが格納されます。Ayakaleaf Pro では、ユーザーがアカウント設定ページで作成し、git-bridge と MCP エンドポイントに使う個人アクセストークン（Git 認証トークン）です。1 つのドキュメントが 1 つのトークンです。スキーマは `services/web/app/src/models/OauthAccessToken.mjs` で、web モジュール `oauth2-server` が主にネイティブドライバーでコレクションに書き込みます。

| フィールド | 型 | 意味 | 出典 |
| ----- | ---- | ------- | ------ |

| `refreshToken`, `refreshTokenExpiresAt` | String, Date | 書き込むのは `saveToken` だけで（リフレッシュトークンはハッシュ化）、`saveToken` を呼び出すものはありません。[OAuth Applications](/ja/dev/data-model/oauth-applications-collection) を参照してください。 | `OauthAccessToken.mjs:13-14`, `OAuth2Model.mjs:249-252` |

#### 書き込み元 {#who-writes-it}

| コード | 処理内容 |
| ---- | ------------ |
| `OAuthPersonalAccessTokenManager.mjs:53-88` (`createToken`) | 個人アクセストークンを挿入します。ルート `POST /oauth/personal-access-tokens`（`services/web/modules/oauth2-server/app/src/OAuthPersonalAccessTokenRouter.mjs:22-27`）はユーザーの `gitBridge` 機能を必要とし、ユーザーあたり 10 個までトークンを作成できます（`OAuthPersonalAccessTokenController.mjs:7,34-38`）。 |
| `OAuthPersonalAccessTokenManager.mjs:90-105` (`removeToken`) | ユーザーのトークンを 1 つ削除します。ルート `DELETE /oauth/personal-access-tokens/:token_id`（`OAuthPersonalAccessTokenRouter.mjs:29-32`）。 |
| `OAuthPersonalAccessTokenManager.mjs:136-140`, `OAuth2Model.mjs:58-61` | 検証の成功後に `lastUsedAt` を設定します。 |

#### 補足 {#notes}

* ユーザーを削除しても、そのトークンは削除されません。`UserDeleter` はフック `cleanupPersonalAccessTokens` を発火しますが（`services/web/app/src/Features/User/UserDeleter.mjs:230-234`）、これを受け取るモジュールはありません。ユーザーが存在しないため両方のトークン検証がトークンを拒否し、TTL インデックスが `accessTokenExpiresAt` の 1 日後に削除します。
* ユーザーを停止しても終了するのはセッションだけです。トークンは残り、`users.suspended` が `true` の間は両方のトークン検証が拒否します（`OAuth2Model.mjs:51-54`, `OAuthPersonalAccessTokenManager.mjs:129-134`）。
