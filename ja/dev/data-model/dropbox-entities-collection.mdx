title: Dropbox Entities コレクション
icon: file-arrow-up
---

`dropboxEntities` は、Dropbox 同期がプロジェクトと 1 人のユーザーの Dropbox との間でコピーしたファイルごとに 1 つのドキュメントと、短期間だけ存在する tombstone を保持します。このコレクションは Dropbox 同期に属します。third-party-datastore（`services/third-party-datastore/app/js/StateManager.mjs`）が書き込みと読み取りを行い、web モジュール `dropbox`（`services/web/modules/dropbox/app/src/DropboxHandler.mjs`）が削除します。Mongoose スキーマはありません。

#### フィールド {#fields}

| フィールド | 型 | 意味 | ソース |
| ---------- | -- | ---- | ------ |
| `_id` | ObjectId | 挿入時にドライバーが設定します。 | `StateManager.mjs:46,97` |
| `overleaf.userId` | ObjectId | そのファイルがある Dropbox の持ち主であるユーザー。すべてのドキュメントに設定されます。 | `StateManager.mjs:48,98` |
| `overleaf.projectId` | ObjectId | doc またはファイルのプロジェクト。判明している場合に設定され、tombstone にはありません。 | `StateManager.mjs:49-51` |
| `overleaf.id` | ObjectId | プロジェクトの `rootFolder` 内の doc またはファイルの `_id`。判明している場合に設定されます。 | `StateManager.mjs:52` |
| `overleaf.type` | String | `doc` または `file`。現在のコードは書き込みますが読み取りません。 | `StateManager.mjs:53`。値は `services/web/app/src/Features/ThirdPartyDataStore/TpdsUpdateSender.mjs:35,96` と `UpdateMerger.mjs:104,119` から |
| `dropbox.id` | String | Dropbox のファイルメタデータにおけるファイルの `id`。tombstone には設定されません。 | `StateManager.mjs:56` |
| `dropbox.pathLower` | String | Dropbox 内のファイルのパス。小文字で、末尾のスラッシュはありません。ファイルまたはそのプロジェクトフォルダーが移動すると更新されます。 | `StateManager.mjs:14-16,57,91,99` |
| `dropbox.rev` | String | 最後の同期時の Dropbox リビジョン。次のアップロードでこれを送信するため、Dropbox で変更されたファイルは上書きされません。 | `StateManager.mjs:58`、`JobProcessor.mjs:114-122` |
| `dropbox.contentHash` | String | 最後の同期時の Dropbox コンテンツハッシュ。同じハッシュの一覧内ファイルは、自分自身のアップロードか適用済みのためスキップされます。 | `StateManager.mjs:59`、`PullManager.mjs:147-149` |
| `tombstone` | Boolean | `true` は、third-party-datastore 自身が Dropbox で削除または移動したパスを示します。Dropbox がその削除を報告してきても、プロジェクトには適用されません。 | `StateManager.mjs:100`、`PullManager.mjs:189-192` |
| `createdAt` | Date | tombstone のみ：作成日時。完了した pull は、その開始前に作られた tombstone を削除します。 | `StateManager.mjs:101,115-121` |

tombstone には `overleaf.userId`、`dropbox.pathLower`、`tombstone`、`createdAt` だけがあります（`StateManager.mjs:96-103`）。

#### 注意事項 {#notes}

* 一意性は、`recordEntity` で各挿入の前に行う削除だけによって保たれます（`StateManager.mjs:38-45`）。`StateManager.mjs:3-11` のコメントはユニークインデックスに触れていますが、CE にはありません。
* ユーザーとパスによるクエリ（`findEntityByPath`、`findTombstone`、`removeEntities`）は、`overleaf.userId` についてのみインデックスを使います。
