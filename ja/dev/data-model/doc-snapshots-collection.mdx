---
title: Doc Snapshots コレクション
icon: camera
---

`docSnapshots` には、コメントや変更履歴を折りたたむ編集の直前に document-updater が取得したドキュメントのコピーが保存されます。書き込むのは document-updater だけで、`services/document-updater/app/js/SnapshotManager.js` で行われます。Web には `services/web/app/src/models/DocSnapshot.mjs` に Mongoose モデルがありますが、どのコードも使用していません。

#### フィールド {#fields}

| フィールド | 型 | 意味 | 出典 |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | スナップショット ID。 | `SnapshotManager.js:24` |
| `project_id` | ObjectId | プロジェクト。 | `SnapshotManager.js:19,26`, `DocSnapshot.mjs:7` |
| `doc_id` | ObjectId | ドキュメント（`docs._id`）。 | `SnapshotManager.js:20,27`, `DocSnapshot.mjs:8` |
| `version` | Number | 編集前のドキュメントの OT バージョン。 | `SnapshotManager.js:28`, `services/document-updater/app/js/UpdateManager.js:132,264-271`, `DocSnapshot.mjs:9` |
| `lines` | Array of String | 編集前のドキュメントの内容。 | `SnapshotManager.js:29`, `DocSnapshot.mjs:10` |
| `pathname` | String | その時点でのプロジェクト内のドキュメントのパス。 | `SnapshotManager.js:30`, `DocSnapshot.mjs:11` |
| `ranges` | Mixed | 編集前の `comments` と `changes`。`docs.ranges` と同じ形式です（[docs](/ja/dev/data-model/docs-collection) を参照）。`id`、`op.t`、`metadata.user_id` は ObjectId に、`metadata.ts` は Date に変換されます。 | `SnapshotManager.js:31,41-68`, `DocSnapshot.mjs:12` |
| `ts` | Date | スナップショットの取得日時。TTL インデックスにより 30 日後に削除されます。 | `SnapshotManager.js:32`, `DocSnapshot.mjs:13` |

#### 書き込み元 {#who-writes-it}

| コード | 処理内容 |
| ---- | ------------ |
| `UpdateManager.js:248-271` | document-updater は編集を適用した後、その編集が範囲を折りたたんだ場合（空になった範囲が増えた、または複数の範囲が削除された場合）に、編集前のドキュメントを記録します（`services/document-updater/app/js/RangesManager.js:104-106`）。 |
| `SnapshotManager.js:17-36` `recordSnapshot` | スナップショットを挿入します。 |

#### 読み取り元 {#who-reads-it}

読み取るコードはありません。Web モデルは定義されていますが、どこでも使われていません。

| `project_id_1_ts_1` | `{ project_id: 1, ts: 1 }` |  | `tools/migrations/20200120163346_atlas_recommended_indexes.mjs` |

`20190912145007_create_docSnapshots_indexes.mjs` の `project_id_1` インデックスは `20231101191643_drop_unused_indexes.mjs` によって削除されました。

#### 注意事項 {#notes}

* スナップショットが取得されるのは `UpdateManager.applyUpdate` を経由する編集だけです。`HistoryOTUpdateManager` が処理する編集では取得されません（`UpdateManager.js:74-77`）。
* `doc_id` にはインデックスがありません。ドキュメントのスナップショットは `project_id` と `ts` で検索し、`doc_id` で絞り込んでください。
