コミュニティで最も強力かつ多機能なオンライン LaTeX エディター、Ayakaleaf Pro 6.2 のリリースを発表できることを誇りに思います。貴重な貢献をしてくださった yu-i-i 氏と davrot 氏に特に感謝します。お二人は GitHub Sync を強化し、高度な引用検索と Zotero 連携を導入してくれました。

### 注意事項

* 新たに必須の環境変数 `OVERLEAF_INVITE_TOKEN_SECRET` が導入されました。`openssl rand -base64 32` で生成する必要があります。設定されていない場合、Overleaf インスタンスは起動しません。
* GitHub Sync を有効にする場合は、`GITHUB_TOKEN_CIPHER_PASSWORD` 環境変数を設定する必要があります。この変数は GitHub アクセストークンを安全に暗号化するために必要です。設定されていない場合、Overleaf インスタンスは起動しません。
* 新規プロジェクトで使用されるデフォルトのコンパイラー（pdflatex、latex、xelatex、lualatex のいずれか）を設定するための新しい環境変数 `DEFAULT_LATEX_COMPILER` を追加しました。
* 刷新されたエディターが唯一の選択肢になりました。

### 変更点

このリリースには、以下の改善と新機能が含まれています。

* `MAX_UPLOAD_SIZE` が **50 MB** に制限されず、設定可能になりました。
* サンドボックスコンパイルが無効な場合にコンテナが再起動ループに陥る問題を修正しました。
* OAuth2 において、PAT の削除を所有者のスコープに限定するようにしました。
* LDAP のインポートに関する問題を修正しました。

新機能:

* ブラウザベースの Python ランナーを追加しました。
* Markdown、DOCX などのフォーマットのインポートとエクスポートのための Pandoc サポートを追加しました。
* GitHub Sync を追加しました。
* 中国語の完全な翻訳を追加しました。
* Zotero 連携を追加しました。
* `DEFAULT_LATEX_COMPILER` を追加しました。

#### 機能 01: GitHub Sync

LaTeX プロジェクトを GitHub リポジトリと同期させ、シームレスな開発ワークフローを実現します。エディターから直接変更を push / pull し、プルリクエストを通じて共同作業を行い、既存の CI/CD パイプラインと統合できます。バージョン管理により、改訂履歴の追跡、変更のレビュー、再現可能な学術文書や技術文書の維持が容易になります。

参照: [GitHub Synchronisation](/ja/on-premises/configuration/overleaf-toolkit/github-synchronisation  "mention")。

![](https://github.com/user-attachments/assets/5137e708-77cb-4fdf-b081-4aa04b4b762e)

#### 機能 02: Pandoc によるインポート / エクスポート

Microsoft Word や Markdown の文書を完全に編集可能な LaTeX プロジェクトとしてインポートしたり、LaTeX プロジェクトをワンクリックで Markdown や DOCX にエクスポートしたりできます。Pandoc を利用したこの機能により、文書構造を可能な限り維持しながら、学術執筆、共同編集、出版のワークフロー間でシームレスな相互運用が可能になります。

参照: [Pandoc Import and Export](/ja/on-premises/configuration/overleaf-toolkit/pandoc-import-and-export  "mention")。

<img src="https://github.com/user-attachments/assets/085a94a0-c673-46fe-9da4-7a5a68e46589" alt="" width="563" />

#### 機能 03: 高度な文献検索

複数の学術データベースから文献を検索・挿入でき、インテリジェントなフィルタリングと即時の引用サポートを備えています。さまざまな研究サイトを行き来することなく、論文をすばやく見つけ、メタデータをプレビューし、正確な BibTeX エントリを作成できるため、文献調査の効率が大幅に向上します。

![image](https://github.com/user-attachments/assets/42e45b73-af4b-4d1f-81f4-9e116ba5d043)

#### 機能 04: Python ランナー

エディターを離れることなく、プロジェクト内で直接 Python コードを実行できます。図の生成、データセットの処理、文書ワークフローの自動化、再現可能な研究スクリプトの実行に最適です。結果を LaTeX 文書に組み込めるため、科学計算と執筆を一つのワークフローに統合できます。

![image](https://github.com/user-attachments/assets/a4c314b3-fdb5-4836-aea7-12eeece5cd2f)

#### 機能 05: Zotero

Zotero ライブラリを執筆ワークフローに直接接続し、エディターを離れることなく文献を管理できます。個人の Zotero コレクションを検索し、ワンクリックで引用を挿入し、BibTeX エントリを自動的に生成・同期できます。この連携により参考文献リストが常に最新の状態に保たれ、学術論文、学位論文、技術文書の文献管理が効率化されます。

参照: [Zotero Integration](/ja/on-premises/configuration/overleaf-toolkit/zotero-integration  "mention")。
