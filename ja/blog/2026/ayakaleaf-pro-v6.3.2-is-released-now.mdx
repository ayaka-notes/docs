Overleaf Pro 6.3.2 のリリースを発表できることを大変誇りに思います。アップストリームの Overleaf 6.3.2 は Node.js を更新するセキュリティリリースです。今回はそれに加えて、同期ファミリーの新しいメンバーをお届けします。GitHub、GitLab、Dropbox に続いて、プロジェクトを Gitea にも置けるようになりました。

### 変更点

* Gitea 同期（アーリープレビュー）: gitea.com またはセルフホストの Gitea と双方向に同期します。
* Node.js 24.22.1: アップストリームの Overleaf 6.3.2 に含まれるセキュリティアップデート。
* E2E テストシステムと Internal Horizon Issue Investigation によって見つかったバグの修正。

<Info>

Gitea 同期は、グレーテスト用の**アーリープレビュー**として 6.3.2 に含まれており、v6.4.0 で正式リリースされる予定です。それまでに設定や動作が変更される可能性があります。デフォルトでは無効です。問題があれば [GitHub](https://github.com/ayaka-notes/ayakaleaf-pro/issues) で報告してください。

</Info>

#### 機能 01: Gitea 同期（プレビュー）

Gitea は小さなサーバー 1 台で動かせるほど軽量なため、多くの研究室や小規模なチームが独自の Gitea を運用しています。Gitea 同期は GitHub 同期や GitLab 同期と同じように動作します。アカウントを連携し、新規プロジェクトメニューからリポジトリをインポートするか、プロジェクトを新しい Gitea リポジトリにエクスポートします。あとはエディターからプッシュとプルを行い、リポジトリ自身のマージスタイルを使ってプルリクエストでマージするだけです。Overleaf がブランチ保護を回避することはありません。プルリクエストに承認やチェックの成功が必要な場合は、あなたが Gitea でマージするのを待ちます。

gitea.com と、セルフホストの Gitea 1.23 以降で動作します。`GITEA_SYNC_ENABLED`、`GITEA_SYNC_CLIENT_ID`、`GITEA_SYNC_CLIENT_SECRET`、`GITEA_TOKEN_CIPHER_PASSWORD` を設定し、セルフホストのインスタンスの場合はさらに `GITEA_SYNC_URL` を設定してください。

セットアップ手順の詳細については、[Gitea 同期](/ja/on-premises/configuration/overleaf-toolkit/gitea-synchronisation  "mention") を参照してください。

#### バグ修正

* **Git 同期**: GitHub、GitLab、Gitea で削除されたファイルを Overleaf で削除できない場合、成功を報告してファイルを残したままにするのではなく、同期が失敗して再試行できるようになりました。ファイルを削除する `git push` も同様に失敗します。
* **Git bridge**: エディターでテキスト以外の拡張子（`.csv` など）で作成したドキュメントは、`git push` で変更されても編集可能なままになります。
* **変更履歴**: リンク共有されたプロジェクトのサインインしていない編集者は、コメントスレッドを削除できますが、解決や再オープンはできなくなりました。また、レビュアーは自分の返信を削除できます。
* **テンプレートギャラリー**: テンプレートを公開するには、プロジェクトへのアクセス権が必要です。
* **Learn**: Wiki にアクセスできない場合でも、キャッシュされたヘルプページは引き続き利用できます。

すべての変更点については、[6.3.2 のリリースノート](/ja/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.2  "mention") を参照してください。

#### アップグレード

* 6.3.1 または 6.3.0 から: 移行は不要です。新しいイメージを pull して再起動してください。
* Zotero または Mendeley を使用している 6.2.x 以前から: まず 6.3.0 の [Zotero / Mendeley の移行](/ja/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention")を実行してください。
* Gitea 同期はデフォルトで無効で、必要なのは新しい環境変数だけです。

#### Docker イメージ

Docker イメージはこちらから入手できます: [https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro)

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:6.3.2
```
