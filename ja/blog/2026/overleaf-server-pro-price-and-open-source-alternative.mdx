長年にわたり、Overleaf Community Edition を使っている多くの人々が Overleaf Server Pro に強い関心を示してきました。Overleaf CE には次のような制約が多すぎるためです。

* サンドボックスがないため、LaTeX のコンパイルがコンテナと同じ権限で実行される。
* TeX Live のバージョン切り替えに対応しておらず、バージョンごとに手動インストールが必要。
* 変更履歴（track changes）がないため、共同執筆やコメントのやり取りがかなり難しい。
* Git 連携がないため、ローカルで LaTeX を使うユーザーが共同プロジェクトに参加しにくい。

しかし、明確で信頼できる価格情報を見つけるのは困難でした。Overleaf のウェブサイトでは、営業担当に問い合わせる以外の選択肢がありません。Server Pro は個人ユーザーが直接購入できるようにはなっていないようです。検索エンジンを使って、いくつかの価格情報を見つけることができました。

コミュニティで収集した情報によると、**Server Pro の見積もり条件**は次のとおりです。

* _最低_ 10 人分のライセンスを購入する必要がある。
* 10 人分のライセンスは約 €3,477.61（2024 年時点）。
* 教育機関向けは、20 ユーザーで年間 2640 ユーロ、50 ユーザーで 6050 ユーロ、100 ユーザーで 9963 ユーロ。
* Server Pro は一部の地域でのみ提供されている（例：中国本土は対象外）。

その後 2026 年に、ChatGPT Search を使って Overleaf Server Pro を購入した組織をさらに特定しました。

Overleaf Server Pro の費用は 1 ユーザーあたり年間約 \$300 のようです。米国の小規模な契約では、1 ユーザーあたりの年間費用はおよそ \$320〜\$370 となっています。大規模な機関契約では、1 ユーザーあたりの価格がより低くなる場合があります。たとえば、マックス・プランク協会の 3 年契約では、1 ユーザーあたり年間平均約 €51 です。契約条件、サポート、導入範囲は異なる場合があります。これらの記録は Overleaf の公式価格表ではありません。

### オンライン LaTeX エディターの構築？簡単ではありません！

2026 年初頭以降、Claude や Codex のようなコードエージェントの助けを借りて、ほぼ毎月のように Overleaf の代替が登場しています。OpenAI も、科学的な LaTeX 執筆のための製品 [Prism](https://prism.openai.com/) を発表しました。

「Overleaf は終わった、Prism が最高の無料 LaTeX エディターになる」と盛んに喧伝されていますが、私たちは Prism がまだ成熟した製品には程遠いと考えています。

下のスクリーンショットは、OpenAI コミュニティでの Prism に関する議論を写したものです。ほとんどのコメントが、Prism はバグが多く、まだ日常的な使用には耐えないと述べています。

<Frame>
  <img src="/images/blog/img-36568b5f.png" alt="" />
</Frame>

<strong>信頼性の高いオンライン LaTeX エディターを構築するのは、決して簡単ではありません。</strong> 私たちの観察によると、Prism はプロジェクトを開いた時点でサンドボックスを用意し、それを実行し続けています。これはおそらく Codex をバックグラウンドで利用可能な状態に保つためです。これにより、ユーザーが AI との会話を始めたときに Codex が素早く応答できます。私たちのテストでは、各サンドボックスに約 5 vCPU、6 GB のメモリ、64 GB のディスク容量が割り当てられていました。

このアーキテクチャでは、数千人のユーザーが同時に LaTeX プロジェクトを編集する場合、かなりの計算オーバーヘッドが生じる可能性があります。Ayakaleaf は異なるアプローチを採用しています。サンドボックスはコンパイルが要求されたときにのみ作成されます。各コンパイルは 1 vCPU と 1 GB のメモリに制限され、コンパイルが完了するとサンドボックスは終了します。これにより常時のリソース消費が大幅に削減され、大規模な導入における容量計画がより予測しやすくなります。

より広い視点で見ると、Prism は、強力なモデルや成熟したオープンソースソフトウェアのエコシステムを利用できたとしても、AI の機能と信頼性の高いオンライン開発環境を組み合わせることがいかに難しいかを示しています。AI は体験を向上させることはできますが、堅実なシステムエンジニアリングの代わりにはなりません。結局のところ、ユーザーが頼りにするのは、信頼性が高く、予測可能で、安定したサービスなのです。

### なぜ Ayakaleaf Pro なのか？

**Ayakaleaf Pro** は Overleaf Community Edition のフォークで、Server Pro レベルおよび SaaS レベルの機能をセルフホスト環境にもたらします。ユーザー単位のライセンスは不要です。アップストリームの Overleaf コードベースと同期し続けているため、使い慣れたエディターとワークフローをそのまま利用でき、さらに次の機能が加わります。

* サンドボックス化された LaTeX コンパイル
* 複数の TeX Live バージョン
* 変更履歴とコメント
* Git および GitHub 連携
* SSO と管理パネル
* プライベートテンプレート管理
* Zotero と高度な参考文献検索
* Pandoc インポート/エクスポート
* Python スクリプトランナー
* ユーザー単位のライセンス料なし

私たちの目標は、Server Pro ライセンスや SaaS のサブスクリプションなしで、より完全なセルフホスト型 Overleaf 体験を提供することです。Ayakaleaf Pro は、使い慣れた Overleaf のワークフローとアップストリームとの互換性を維持しながら、コラボレーション、管理、連携、安全なコンパイルのための機能を追加しています。

### なぜ私たちは車輪の再発明を繰り返すのか？

ここで問うべき、より大きな疑問があります。_**成熟したオープンソースプロジェクトがすでに難しい問題のほとんどを解決しているのに、なぜゼロから書き直そうとする衝動がこれほど多いのか**_？

エディター、リアルタイム共同編集レイヤー、コンパイラーパイプライン、そして長年積み重ねられたエッジケースの修正を再実装するのは非常にコストがかかります。しかも、その労力の多くは、元のプロジェクトがとうの昔に解決した問題を再発見することに費やされます。多くの場合、堅実な基盤を拡張し、足りない部分をコントリビュートして還元するほうが、より実用的なエンジニアリング上の選択です。

私が本当に言いたいのはこういうことです。

> _AI の時代、人々は見せびらかすのが大好きだ。_

「自分だけの Overleaf を作った」は「Overleaf にいくつか機能を追加した」よりもはるかに印象的に聞こえます。だからこそ、人々は前者の話をしたがるのです。新しい「AI LaTeX エディター」が毎月のように現れるように見えるのも、そのためです。

しかし実際には、こうした AI 支援による書き直しは、Overleaf のように 10 年にわたって現実の環境で鍛え上げられてきたものの信頼性と成熟度には遠く及びません。2 か月もすれば、2 月のクリスマスプレゼントのように自作のエディターを放り出すでしょう。間違いありません。
