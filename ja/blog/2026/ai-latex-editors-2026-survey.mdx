## この記事を書いた理由

OpenAI は 2026-01-27 に、AI を組み込んだ LaTeX ワークスペースである Prism をリリースしました。それ以来、新しい「AI LaTeX エディター」が GitHub、Reddit、Hacker News にほぼ毎週のように登場しています。その多くは数週間で作られ、各種フォーラムで宣伝され、数百から数千の GitHub スターを集めます。改善を続けるものもあります。一方で、リリース直後に開発が止まり、スター数だけがそのまま残っているものもあります。

スター数からわかるのは、どれだけの人がそのプロジェクトに気づいたかです。誰かが今もバグを修正しているかどうかはわかりません。論文や学位論文を新しいエディターに移す前に、確認しておく価値があります。この記事では、私たちが見つけた内容を日付とともに示し、ご自身で確認する方法も紹介します。

## 一覧表

## データからわかること

1. <strong>Prism の模倣プロジェクトの多くは数週間以内に登場した。</strong> 1 月から 10 月までの月別コミット履歴を追跡したオープンソースプロジェクト 7 件のうち、4 件は Prism のリリースから 4 週間以内に作成されました。assistant-ui/open-prism は 2026-01-28、つまり 1 日以内に作成されています。OpenDCAI/OpenPrism は 30 件のコミットすべてを 2026-02-05 から 2026-02-11 の間に行い、VishiATChoudhary/open-prism は 9 件のコミットすべてを 2026-06-17 に行っています。
2. <strong>4 月に活動が全体的に落ち込んだ。</strong> ClaudePrism は 3 月の 249 コミットから 4 月には 20 コミットに、Prismer は 58 から 3 に、Octree は 21 から 5 に減りました。Ayakaleaf Pro 自身のコミットも、2 月の 39 件から 3 月〜5 月の合計 4 件に減り、6 月以降は月 22〜47 件に回復しました。コミットデータだけでは、その理由はわかりません。
3. <strong>続いているプロジェクトには、AI パネル以外の何かがある。</strong> Octree はホスト版を販売しています。ClaudePrism には作業を分担する 14 人のコントリビューターがいます。Ayakaleaf Pro は Overleaf をベースにしているため、コンパイルとコラボレーションはアップストリームから提供され、フォークは独自の追加部分をメンテナンスしています。停止したプロジェクトの多くは、単一チームによる一度きりのデモでした。
4. <strong>続いているのは、エディターそのものへの取り組みである。</strong> 同じ時期に、TeXlyre（AI なし）は 9 月に 100 コミット、texpile は 7 月から 9 月にかけて月 119〜205 コミット、TexLite は 8 月と 9 月に月 80 コミット以上を行いました。texpile と TexLite は、チャットパネルを中心に製品を組み立てるのではなく、外部エージェントを接続できるようにしています。コンパイル、コラボレーション、ファイル処理こそが長期的な取り組みです。
5. <strong>大手ベンダーも製品を終了することがある。</strong> この流れのきっかけとなった製品である OpenAI Prism は 2027-01-01 にサービスを終了し、OpenAI によればその日以降にプロジェクトデータは削除されます。誰がエディターを作っているかよりも、自分の作業を持ち出せるかどうかのほうが重要です。

## 新しいエディターに作業を移す前に

以下のチェックは、それぞれ 1〜2 分で済みます。

1. <strong>スター数ではなくコミット履歴を見る。</strong> GitHub で **Insights → Contributors** を開くと、週ごとのコミット数を確認できます。リリース時に大きな山があり、その後平坦になるパターンは、上の表で失速や停止となっている行のほとんどに共通しています。
2. <strong>メンテナーが最後に issue に返信した時期を確認する。</strong> 何か月も返信のない issue があれば、自分のバグ報告がどう扱われるかがわかります。
3. <strong>人数を数える。</strong> 1 人がほぼすべてのコミットを行っている場合、その人が止まればプロジェクトも止まります。
4. <strong>エディターに依存する前にプロジェクトをエクスポートしてみる。</strong> 他の環境でもコンパイルできる、プレーンな `.tex`、`.bib`、画像ファイルが得られるはずです。どのエディターを使う場合でも（私たちのものも含めて）、自分用のコピーを Git で保管してください。
5. <strong>自分のテキストがどこに送られるかを確認する。</strong> AI 機能は原稿をモデルプロバイダーに送信します。どのプロバイダーか、誰の API キーが使われるか、そのプロバイダーのデータポリシーがどうなっているかを確認してください。

## 名前についての注意

OpenAI Prism を除き、表に掲載されているプロジェクトはいずれも、名前から連想されるものとは異なり、OpenAI や Anthropic が公開しているものではありません。いくつかは OpenAI の製品から「Prism」という名前を借りています。

ClaudePrism（[delibae/claude-prism](https://github.com/delibae/claude-prism)）は、独立したサードパーティのプロジェクトです。Anthropic（Claude の開発元）や OpenAI（Prism の開発元）によって作られたものではなく、提携関係も承認もありません。その名前は、Claude Code 経由で呼び出すモデルである Claude と、自らが代替として位置づけている製品である OpenAI Prism を組み合わせたものです。評価できる点として、プロジェクトをローカル Git スナップショット付きでディスク上のファイルとして保持するため、開発が止まっても作業は手元に残ります。

## データの収集方法

* <strong>対象範囲。</strong> 2026 年に初めてリリースまたは公開され、LaTeX 執筆の AI 支援を主なセールスポイントとするエディター。Overleaf のフォークは、独自の開発が 2026 年に始まり、AI を追加したものを対象としています。Overleaf 自身の AI 機能、ブラウザー拡張機能、単体の MCP サーバーは対象外です。TeXlyre と overleaf-cep には AI がなく、参考としてのみ掲載しています。
* <strong>調査した場所。</strong> 検索エンジン、Hacker News、AlternativeTo、および GitHub のトピック [latex-editor](https://github.com/topics/latex-editor)、[overleaf-alternative](https://github.com/topics/overleaf-alternative)、[openai-prism](https://github.com/topics/openai-prism)、[typst-editor](https://github.com/topics/typst-editor)、[scientific-writing](https://github.com/topics/scientific-writing)、[overleaf](https://github.com/topics/overleaf)。
* <strong>オープンソースプロジェクト。</strong> 各リポジトリの全履歴を `git clone --filter=blob:none` でクローンし、月ごとのコミット数、作成者、タグを、サードパーティのスタートラッカーを使わずに自分たちで数えました。
* <strong>クローズドソースプロジェクト。</strong> サイトがオンラインかどうか、変更履歴、報道記事しか確認できなかったため、これらの行はオープンソースの行よりも確度が低くなります。
* <strong>限界。</strong> コミット数が測るのは活動量であり、品質ではありません。最近のコミットが少ない小規模なプロジェクトは、放棄されたのではなく単に完成しているだけかもしれません。2026 年 10 月または 11 月に初めて登場したプロジェクトはアクティブと表示されますが、今後も続くかどうかを判断するには早すぎます。
