コミュニティで最も強力かつ多機能なオンライン LaTeX エディター、Overleaf Pro 6.3.0 のリリースを発表できることを大変誇りに思います。私たちは常にユーザー体験の向上に注力してきましたが、今回のリリースでは、AI アシスタントやサードパーティの文献管理連携など、きっと気に入っていただける大きな変更と素晴らしい機能をお届けします。

### 変更点

* AI チャットアシスタント: 独自のプロバイダーを通じて、エディター内で AI モデルとチャットできます。
* LaTeX エラーアシスタント: LaTeX のコンパイルエラーに対して AI による修正案を得られます。
* Mendeley 連携: Zotero と同様に Mendeley から文献をインポートできます。
* Open in Overleaf API: コンテンツを Overleaf で開くための API を追加しました。
* テンプレートギャラリー: サーバーサイドでのページネーション、検索、並べ替えを追加しました。これにより、大規模なギャラリーでもすべてのテンプレートをブラウザに読み込む必要がなくなりました。
* 翻訳: 6.3.0 向けの翻訳パッチを更新し、サポートされている各言語に新しいインターフェーステキストを追加しました。
* アップストリームの Overleaf 6.3.0: タブによるファイル編集、ライトテーマとダークテーマで別々のヘッダーロゴ、依存関係とベースイメージの更新が含まれます。
* ライトテーマとダークテーマで別々のヘッダーロゴ画像をサポートするため、`OVERLEAF_HEADER_IMAGE_URL_LIGHT` と `OVERLEAF_HEADER_IMAGE_URL_DARK` を追加しました。
* エディターでファイルを別々のタブで開けるようになりました。
* 外部 URL の取得と Open in Overleaf API が、`OVERLEAF_LINKED_URL_OUTBOUND_PROXY` による HTTP(S) プロキシをサポートするようになりました。設定については [Outbound Proxy](/ja/on-premises/configuration/overleaf-toolkit/external-url#outbound-proxy  "mention") を参照してください。

#### 機能 01: AI アシスタントが利用可能に

AI アシスタントはエディターのサイドレールに常駐し、あなたが設定したモデルプロバイダーと通信します。同僚に尋ねるような質問をしてみてください。「この段落を簡潔にして」「このマクロは何をするの?」「なぜ表がそろわないの?」といった具合です。アシスタントは当てずっぽうで答えるわけではありません。プロジェクト内のファイルを読み込んで検索し、LaTeX の診断結果を確認し、プロジェクトをコンパイルし、さらにはレンダリングされた PDF ページまで確認できるため、その回答は実際の文書に基づいています。

何かを変更したい場合、アシスタントはまず差分を表示します。あなたが承認するまで何も書き込まれないので、論文の主導権は常にあなたにあります。

<img src="https://github.com/user-attachments/assets/ea4e0dad-3561-4726-b380-5d9dcfe29693" alt="AI チャットとエラーアシスタントのデモ" width="787" />

LaTeX エラーアシスタントは、おなじみの深夜のあの瞬間、つまりログに赤いエラーが表示されて意味がまったくわからないときのための機能です。エラーの横にある Suggest fix をクリックすると、アシスタントが原因となったファイルを読み込み、他の書式には手を付けずに問題を解決するための最小限の変更を提案します。問題なさそうであれば、ワンクリックで適用して再度コンパイルしてください。修正がパッケージ、コマンド、文書構造に関わる場合は、先にざっと確認しておきましょう。

<img src="https://github.com/user-attachments/assets/91b2aefb-c1e4-4e4a-a94d-9824865cdf29" alt="エラーアシスタントの使用例" width="787" />

AI 機能はデフォルトで無効になっています。Ayakaleaf Pro は、OpenAI 本体、社内のゲートウェイ、自分でホストしているモデルなど、OpenAI 互換のあらゆるエンドポイントで動作します。

プロバイダーの設定、権限、クォータ、オプションの検索サービスについては、[AI Integration](/ja/on-premises/configuration/overleaf-toolkit/ai-integration  "mention") を参照してください。

#### 機能 02: Open in Overleaf API

コースページ、テンプレートライブラリ、ドキュメントサイトを運営している場合、読者を動作するプロジェクトへ直接案内するボタンを設置できるようになりました。この機能はデフォルトで有効になっています。完全なリファレンスとライブサンプルについては、`your.overleaf.com/devs` にアクセスしてください。

<Frame>
  <img src="/images/blog/img-2fac54e7.png" alt="" />
</Frame>

必要なのはリンクか小さなフォームだけです。LaTeX スニペット（`snip` または `encoded_snip`）を送信でき、断片だけを送った場合は最小限の文書で自動的にラップされます。`snip_uri` で 1 つ以上のリモートファイル（一度に最大 50 個）を指定したり、`zip_uri` でプロジェクト全体を ZIP として渡したりすることもできます。オプションのパラメーターで、コンパイラー（`engine`）、メイン文書（`main_document`）、プロジェクト名（`name`）を設定できます。コンテンツはインスタンス内の新しいプロジェクトとして開かれ、すぐに編集・コンパイルできます。訪問者がまだサインインしていない場合は、まずログインした後、新しいプロジェクトに移動します。

```html wrap
<a href="https://your.overleaf.com/docs?snip_uri=https://example.com/paper.tex&engine=xelatex">
  Open in Overleaf
</a>
```

#### 機能 03: Mendeley 連携

6.2 で Zotero を追加して以来、Mendeley ユーザーから同様の機能を求める声が寄せられていました。Mendeley アカウントをリンクし、ライブラリまたはグループを選択すると、文献が `.bib` ファイルとして取り込まれ、ライブラリが変更されたときにいつでも更新できます。overleaf.com と同様に、共有プロジェクトではファイルをインポートした本人のみが更新できます。

管理者向け: `ENABLED_LINKED_FILE_TYPES` に `mendeley` を追加し、Mendeley 開発者アプリから取得した `MENDELEY_CLIENT_ID` と `MENDELEY_CLIENT_SECRET` を設定してください。

完全なセットアップ手順については、[Mendeley Integration](/ja/on-premises/configuration/overleaf-toolkit/mendeley-integration  "mention") を参照してください。

#### 機能 04: テンプレートのページネーション

以前のギャラリーは、すべてのテンプレートをブラウザに読み込んでからそこで並べ替えていました。50 個のテンプレートなら問題ありませんが、5,000 個となると大変です。現在はページング、検索、並べ替えがすべて MongoDB 内で行われ、ブラウザは表示中のページだけを受け取ります。

事前の準備なしで動作します。ギャラリーに数千のテンプレートがある場合は、以下のインデックスを作成すると高速性を維持できます。このスクリプトは複数回実行しても安全です。`mongo` と `sharelatex` は、ご利用のコンテナ名とデータベース名に置き換えてください:

```bash
docker exec mongo mongosh sharelatex --quiet --eval '
db.templates.createIndex({category:1,lastUpdated:-1},{name:"category_1_lastUpdated_-1",background:true});
db.templates.createIndex({lastUpdated:-1},{name:"lastUpdated_-1",background:true});
db.templates.createIndex({category:1,name:1},{name:"category_1_name_1_ci",collation:{locale:"en",strength:2},background:true});
db.templates.createIndex({name:1},{name:"name_1_ci",collation:{locale:"en",strength:2},background:true});
'
```

2 つの `*_ci` インデックスの `collation` は記載どおりに維持してください。ギャラリーは同じ照合順序でクエリを実行し、MongoDB は一致するインデックスしか使用しません。

#### その他

外部ファイルのインポートについては、`OVERLEAF_LINKED_URL_OUTBOUND_PROXY` を設定することで、ローカルでホストされているプロキシを含む HTTP(S) プロキシを使用できます。この設定は、リンクされた URL ファイルと、Open in Overleaf API を通じてインポートされるリモートの ZIP や TeX リソースの両方に適用されます。セットアップとネットワークアクセスの制限については、[External URL — Outbound Proxy](/ja/on-premises/configuration/overleaf-toolkit/external-url#outbound-proxy  "mention") を参照してください。

* ライトテーマとダークテーマで別々のヘッダーロゴ画像をサポートするため、`OVERLEAF_HEADER_IMAGE_URL_LIGHT` と `OVERLEAF_HEADER_IMAGE_URL_DARK` を追加しました。
* エディターでファイルを別々のタブで開けるようになりました。
