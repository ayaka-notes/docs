Overleaf Pro 6.3.3 のリリースを発表できることを大変誇りに思います。アップストリームの Overleaf 6.3.3 は Node.js とインストール済みパッケージを更新するセキュリティリリースです。私たちはこれを、新しい管理パネルの早期プレビュー、アカウントごとの複数メールアドレス、より大きくなった MCP サーバー、より優れた AI アシスタントとともにお届けします。

### 変更点 {#changes}

* 新しい管理パネル（早期プレビュー）：ユーザー、プロジェクト、テンプレートのページ、監査ログ、ユーザーごとの機能スイッチ。
* アカウントごとの複数メールアドレス（早期プレビュー）。
* MCP サーバー：履歴、変更履歴、コメント、チャット、ファイルの移動。
* AI アシスタント：OpenAI Responses API、PDF 添付、Web ページの読み取り、長いチャット（早期プレビュー）。
* サインアップとログイン：reCAPTCHA v2 と、公開登録用のメールドメインリスト（早期プレビュー）。
* Node.js 24.22.3 とパッケージの更新：アップストリームの Overleaf 6.3.3 のセキュリティアップデート。
* E2E テストシステムと Internal Horizon Issue Investigation によって見つかったバグの修正。

<Info>

新しい管理パネル、複数メールアドレス、AI アシスタントの添付ファイル、新しいサインアップオプションは、6.3.3 では段階的テスト向けの**早期プレビュー**として提供され、v6.4.0 で正式にリリースされます。それまでに動作が変わる可能性があります。問題があれば [GitHub](https://github.com/ayaka-notes/ayakaleaf-pro/issues) で報告してください。

</Info>

#### 機能 01: 新しい管理パネル（プレビュー） {#feature-01-new-admin-panel-preview}

研究室や学科でインスタンスを運用していると、毎週同じ質問が寄せられます。この学生はなぜログインできないのか、誰があのアカウントに管理者権限を与えたのか、昨年の論文はどこへ行ったのか。新しい管理パネルには、すべてのユーザーの一覧とすべてのプロジェクトの一覧、それぞれの個別ページ、テンプレート管理、監査ログがあります。管理者は複数のユーザーに一度に操作を行い、メールが送信されない場合はアクティベーションリンクやパスワードリンクをコピーし、Dropbox、Git、AI アシスタント、変更履歴、記号パレットなどの大きな機能を個々のユーザーごとにオン／オフできます。

#### 機能 02: アカウントごとの複数メールアドレス（プレビュー） {#feature-02-multiple-emails-per-account-preview}

ユーザーは、各アドレスに送信されるコードを使ってアカウントにメールアドレスを追加でき、別のアドレスをプライマリにすることもできます。たとえば大学のアドレスが使えなくなる前に切り替えられます。ログインとパスワードリセットに使えるのはプライマリメールアドレスだけです。インスタンスがメールを送信できる場合に有効になります。

[複数のメールアドレス](/ja/on-premises/user-guide/users/multiple-emails  "mention") を参照してください。

#### 機能 03: MCP サーバー {#feature-03-mcp-server}

Claude Code、Codex、Cursor などの AI クライアントは、プロジェクトの履歴を閲覧してバージョンを復元し、変更履歴をレビューし、自身の編集を変更履歴として記録し、テキストにコメントし、チャットメッセージを読んで送信し、ファイルを移動または名前変更できるようになりました。MCP サーバーのツールは 17 個から 33 個に増えました。

[MCP サーバー](/ja/on-premises/user-guide/users/mcp-server  "mention") を参照してください。

#### 機能 04: OpenAI Responses API {#feature-04-openai-responses-api}

gpt-6.x などの OpenAI の新しい推論モデルは Chat Completions で関数ツールを拒否するため、AI アシスタントとエラーアシスタントはこれらを使用できませんでした。代わりに OpenAI Responses API を呼び出すには `AI_API_MODE=responses` を設定します。添付ファイルとトークンクォータはこれまでどおり機能します。

[AI 連携](/ja/on-premises/configuration/overleaf-toolkit/integrations/ai-integration  "mention") を参照してください。

#### 機能 05: AI アシスタントの改善（プレビュー） {#feature-05-ai-assistant-improvements-preview}

画像に加えて最大 2 MB の PDF ファイルを添付でき、PDF を読み取れるモデル用にオプションの `AI_PDF_MODEL` を指定できます。アシスタントは linked URL プロキシを介して Web ページを読み取り、Web を検索するときに今日の日付を把握します。長いチャットは要約され、古いツール出力は圧縮されるため、モデルのコンテキストを埋め尽くすことなくチャットを続けられます。

[AI アシスタント](/ja/on-premises/user-guide/users/ai-assistant  "mention") を参照してください。

#### 機能 06: サインアップとログイン（プレビュー） {#feature-06-sign-up-and-login-preview}

`RECAPTCHA_SITE_KEY` と `RECAPTCHA_SECRET_KEY` を設定すると、ログイン、LDAP ログイン、登録、パスワードリセットを reCAPTCHA v2 で保護できます。`OVERLEAF_ALLOW_PUBLIC_REGISTRATION` は `@example.edu,@*.example.org` のようなメールドメインのリスト、または任意のドメインを表す `@*` を受け付けるようになりました。ログインページと登録ページはフォームをカードで表示します。

[reCAPTCHA](/ja/on-premises/configuration/overleaf-toolkit/authentication/recaptcha  "mention") と [パブリックアクセス](/ja/on-premises/configuration/overleaf-toolkit/authentication/public-access  "mention") を参照してください。

#### バグ修正 {#bug-fixes}

* **管理パネル**：削除された管理者は、監査ログや「Deleted by」で引き続きメールアドレスで表示され、完全に削除されると「Deleted user」と表示されます。自分のアカウントを無効化、削除、降格する直接のリクエストは拒否されます。
* **AI アシスタント**：`AI_PDF_MODEL` が未設定の場合、PDF ファイルと画像を含むチャットは、PDF ファイルを読めない可能性のある画像モデルではなく `AI_MODEL` に送られます。
* **テンプレートギャラリー**：編集はフォームのフィールドのみを受け付け、テキストでないフィールドには 500 ではなく 400 を返します。
* **Git bridge**：clone コマンドは句読点ではなく、コピーブロックの端で折り返されます。

すべての変更点については、[6.3.3 のリリースノート](/ja/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.3  "mention") を参照してください。

#### アップグレード {#upgrade}

* 6.3.2、6.3.1、6.3.0 から：移行は不要です。新しいイメージを pull して再起動してください。
* Zotero または Mendeley を使用している 6.2.x 以前から: まず 6.3.0 の [Zotero / Mendeley の移行](/ja/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention")を実行してください。
* 新しい管理パネルは旧パネルを置き換えます。複数メールアドレスにはメール配信が必要です。reCAPTCHA、ドメインリスト、`AI_API_MODE` は新しい環境変数のみが必要です。

#### Docker イメージ {#docker-image}

Docker イメージはこちらから入手できます: [https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro)

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:6.3.3
```
