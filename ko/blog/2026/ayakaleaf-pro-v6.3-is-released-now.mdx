<Warning>

**2026년 10월 3일 업데이트:** AI Assistant, Zotero, Mendeley 연동 문제를 해결하기 위해 버전 6.3.0이 재배포되었습니다. 업그레이드할 때는 최신 `6.3.0` 이미지를 받으세요. Zotero 또는 Mendeley 연결 참고문헌 파일이 있는 기존 설치는 [마이그레이션 안내](/ko/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention")도 따라야 합니다. 새로 설치하는 경우에는 이 마이그레이션이 필요하지 않습니다.

</Warning>

커뮤니티에서 가장 강력하고 기능이 풍부한 온라인 LaTeX 편집기인 Overleaf Pro 6.3.0의 출시를 매우 자랑스럽게 발표합니다. 언제나 사용자 경험 개선에 집중해 온 만큼, 이번 릴리스에는 AI 어시스턴트와 서드파티 참고문헌 연동 등 분명 마음에 드실 큰 변화와 놀라운 기능이 담겨 있습니다.

### 변경 사항

* AI 채팅 어시스턴트: 편집기 안에서 직접 사용하는 공급자를 통해 AI 모델과 대화할 수 있습니다.
* LaTeX 오류 어시스턴트: LaTeX 컴파일 오류에 대해 AI가 제안하는 수정 방법을 받을 수 있습니다.
* Mendeley 연동: Zotero와 비슷하게 Mendeley에서 참고문헌을 가져올 수 있습니다.
* Open in Overleaf API: Overleaf에서 콘텐츠를 여는 API를 추가했습니다.
* 템플릿 갤러리: 서버 측 페이지네이션, 검색, 정렬을 추가하여 대규모 갤러리에서도 더 이상 브라우저에 모든 템플릿을 불러올 필요가 없습니다.
* 번역: 지원 언어 전반의 새로운 인터페이스 텍스트를 포함하여 6.3.0용 번역 패치를 업데이트했습니다.
* 업스트림 Overleaf 6.3.0: 탭 방식 파일 편집, 라이트 및 다크 테마별 헤더 로고, 의존성 및 베이스 이미지 업데이트가 포함되어 있습니다.
* 라이트 및 다크 테마에 별도의 헤더 로고 이미지를 지원하기 위해 `OVERLEAF_HEADER_IMAGE_URL_LIGHT`와 `OVERLEAF_HEADER_IMAGE_URL_DARK`를 추가했습니다.
* 이제 편집기에서 파일을 서로 다른 탭으로 열 수 있습니다.
* 외부 URL 가져오기와 Open in Overleaf API가 이제 `OVERLEAF_LINKED_URL_OUTBOUND_PROXY`를 통해 HTTP(S) 프록시를 지원합니다. 설정 방법은 [아웃바운드 프록시](/ko/on-premises/configuration/overleaf-toolkit/external-url#outbound-proxy  "mention")를 참고하세요.

#### 기능 01: AI 어시스턴트 출시

AI 어시스턴트는 편집기의 사이드 레일에 위치하며, 사용자가 설정한 모델 공급자와 통신합니다. 동료에게 묻듯이 질문해 보세요. 이 문단을 더 간결하게 다듬어 줘, 이 매크로는 무슨 일을 해, 왜 표가 정렬되지 않지 같은 질문 말이죠. 어시스턴트는 아무 근거 없이 답하지 않습니다. 프로젝트의 파일을 읽고 검색하며, LaTeX 진단 정보를 확인하고, 프로젝트를 컴파일하고, 렌더링된 PDF 페이지까지 살펴보므로 답변은 실제 문서를 바탕으로 합니다.

무언가를 변경하려 할 때는 먼저 diff를 보여 줍니다. 승인하기 전에는 아무것도 기록되지 않으므로 논문은 온전히 여러분의 것으로 남습니다.

<img src="https://github.com/user-attachments/assets/ea4e0dad-3561-4726-b380-5d9dcfe29693" alt="AI 채팅 및 오류 어시스턴트 데모" width="787" />

LaTeX 오류 어시스턴트는 늦은 밤 익숙한 순간을 위한 기능입니다. 로그에 빨간 오류가 떴는데 무슨 뜻인지 전혀 모를 때 말이죠. 오류 옆의 Suggest fix를 클릭하면 어시스턴트가 오류를 일으킨 파일을 읽고, 나머지 서식은 그대로 둔 채 문제를 해결할 수 있는 가장 작은 변경을 제안합니다. 적절해 보이면 클릭 한 번으로 적용하고 다시 컴파일하세요. 수정 사항이 패키지, 명령, 문서 구조를 건드리는 경우에는 먼저 빠르게 확인해 보세요.

<img src="https://github.com/user-attachments/assets/91b2aefb-c1e4-4e4a-a94d-9824865cdf29" alt="오류 어시스턴트 사용 사례" width="787" />

AI 기능은 기본적으로 꺼져 있습니다. Ayakaleaf Pro는 OpenAI 자체든, 회사의 게이트웨이든, 직접 호스팅하는 모델이든 OpenAI 호환 엔드포인트라면 무엇이든 사용할 수 있습니다.

공급자 설정, 권한, 할당량, 선택적 검색 서비스에 대해서는 [AI 연동](/ko/on-premises/configuration/overleaf-toolkit/ai-integration  "mention")을 참고하세요.

#### 기능 02: Open in Overleaf API

강의 페이지, 템플릿 라이브러리, 문서 사이트를 운영한다면 이제 독자가 바로 작업 가능한 프로젝트로 이동할 수 있는 버튼을 제공할 수 있습니다. 이 기능은 기본적으로 활성화되어 있습니다. 전체 레퍼런스와 실제 예시는 `your.overleaf.com/devs`에서 확인하세요.

<Frame>
  <img src="/images/blog/img-2fac54e7.png" alt="" />
</Frame>

링크나 작은 양식 하나면 충분합니다. LaTeX 스니펫(`snip` 또는 `encoded_snip`)을 보낼 수 있으며, 단편적인 코드는 최소한의 문서로 자동으로 감싸집니다. `snip_uri`로 하나 이상의 원격 파일(한 번에 최대 50개)을 지정하거나, `zip_uri`로 프로젝트 전체를 ZIP으로 전달할 수도 있습니다. 선택적 매개변수로 컴파일러(`engine`), 메인 문서(`main_document`), 프로젝트 이름(`name`)을 설정할 수 있습니다. 콘텐츠는 인스턴스에서 새 프로젝트로 열리며 바로 편집하고 컴파일할 수 있습니다. 방문자가 아직 로그인하지 않았다면 먼저 로그인한 후 새 프로젝트로 이동합니다.

```html wrap
<a href="https://your.overleaf.com/docs?snip_uri=https://example.com/paper.tex&engine=xelatex">
  Open in Overleaf
</a>
```

#### 기능 03: Mendeley 연동

6.2에서 Zotero를 추가한 이후로 Mendeley 사용자들도 같은 기능을 요청해 왔습니다. Mendeley 계정을 연결하고 라이브러리나 그룹을 선택하면, 참고문헌이 `.bib` 파일로 들어오며 라이브러리가 변경될 때마다 새로 고칠 수 있습니다. overleaf.com과 마찬가지로 공유 프로젝트에서는 파일을 가져온 사람만 새로 고칠 수 있습니다.

관리자의 경우: `ENABLED_LINKED_FILE_TYPES`에 `mendeley`를 추가하고, Mendeley 개발자 앱에서 받은 `MENDELEY_CLIENT_ID`와 `MENDELEY_CLIENT_SECRET`을 설정하세요.

전체 설정 방법은 [Mendeley 연동](/ko/on-premises/configuration/overleaf-toolkit/mendeley-integration  "mention")을 참고하세요.

#### 기능 04: 템플릿 페이지네이션

이전에는 갤러리가 모든 템플릿을 브라우저에 불러와 그곳에서 정렬했습니다. 템플릿이 50개라면 괜찮지만 5천 개라면 고통스럽죠. 이제 페이지 나누기, 검색, 정렬이 모두 MongoDB에서 이루어지며, 브라우저는 현재 보고 있는 페이지만 받습니다.

별도의 준비 없이 바로 동작합니다. 갤러리에 템플릿이 수천 개 있다면 다음 인덱스가 속도를 유지해 줍니다. 이 스크립트는 여러 번 실행해도 안전합니다. `mongo`와 `sharelatex`를 실제 컨테이너 이름과 데이터베이스 이름으로 바꾸세요:

```bash
docker exec mongo mongosh sharelatex --quiet --eval '
db.templates.createIndex({category:1,lastUpdated:-1},{name:"category_1_lastUpdated_-1",background:true});
db.templates.createIndex({lastUpdated:-1},{name:"lastUpdated_-1",background:true});
db.templates.createIndex({category:1,name:1},{name:"category_1_name_1_ci",collation:{locale:"en",strength:2},background:true});
db.templates.createIndex({name:1},{name:"name_1_ci",collation:{locale:"en",strength:2},background:true});
'
```

두 개의 `*_ci` 인덱스에 있는 `collation`은 작성된 그대로 유지하세요. 갤러리는 동일한 collation으로 쿼리하며, MongoDB는 일치하는 인덱스만 사용합니다.

<img src="https://github.com/user-attachments/assets/f73f6c4d-4ef4-4590-9e81-666e0fcc2801" alt="템플릿 페이지네이션" width="787" />

#### 기타

외부 파일 가져오기의 경우 `OVERLEAF_LINKED_URL_OUTBOUND_PROXY`를 설정하여 로컬에서 호스팅하는 프록시를 포함한 HTTP(S) 프록시를 사용할 수 있습니다. 이 설정은 연결된 URL 파일과 Open in Overleaf API를 통해 가져오는 원격 ZIP 또는 TeX 리소스 모두에 적용됩니다. 설정 방법과 네트워크 접근 제한은 [외부 URL — 아웃바운드 프록시](/ko/on-premises/configuration/overleaf-toolkit/external-url#outbound-proxy  "mention")를 참고하세요.

* 라이트 및 다크 테마에 별도의 헤더 로고 이미지를 지원하기 위해 `OVERLEAF_HEADER_IMAGE_URL_LIGHT`와 `OVERLEAF_HEADER_IMAGE_URL_DARK`를 추가했습니다.
* 이제 편집기에서 파일을 서로 다른 탭으로 열 수 있습니다.
