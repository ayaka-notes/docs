커뮤니티에서 가장 강력하고 기능이 풍부한 온라인 LaTeX 편집기인 Ayakaleaf Pro 6.2의 출시를 자랑스럽게 발표합니다. 귀중한 기여를 해 주신 yu-i-i와 davrot에게 특별히 감사드립니다. 두 분은 GitHub Sync를 개선하고 고급 인용 검색과 Zotero 연동을 도입했습니다.

### 참고 사항

* 새로운 필수 환경 변수 `OVERLEAF_INVITE_TOKEN_SECRET`이 도입되었습니다. 반드시 `openssl rand -base64 32`로 생성해야 합니다. 구성하지 않으면 Overleaf 인스턴스가 시작되지 않습니다.
* GitHub Sync를 활성화하는 경우 `GITHUB_TOKEN_CIPHER_PASSWORD` 환경 변수를 구성해야 합니다. 이 변수는 GitHub 액세스 토큰을 안전하게 암호화하는 데 필요합니다. 이 변수가 없으면 Overleaf 인스턴스가 시작되지 않습니다.
* 새 프로젝트에서 사용할 기본 컴파일러(pdflatex, latex, xelatex 또는 lualatex)를 설정하는 `DEFAULT_LATEX_COMPILER` 환경 변수가 추가되었습니다.
* 이제 새롭게 디자인된 편집기만 사용할 수 있습니다.

### 변경 사항

이번 릴리스에는 다음과 같은 개선 사항과 새로운 기능이 포함되어 있습니다.

* `MAX_UPLOAD_SIZE`가 **50 MB**로 제한되지 않고 이제 구성 가능합니다.
* sandboxed compiles가 비활성화되었을 때 컨테이너가 반복적으로 재시작되던 문제를 수정했습니다.
* OAuth2에서 PAT 삭제를 소유자 범위로 제한했습니다.
* LDAP 가져오기 문제를 수정했습니다.

새로운 기능:

* 브라우저 기반 Python 실행기를 추가했습니다.
* Markdown, DOCX 등의 형식을 가져오고 내보내는 Pandoc 지원을 추가했습니다.
* GitHub Sync를 추가했습니다.
* 완전한 중국어 번역을 추가했습니다.
* Zotero 연동을 추가했습니다.
* `DEFAULT_LATEX_COMPILER`를 추가했습니다.

#### 기능 01: GitHub Sync

LaTeX 프로젝트를 GitHub 저장소와 동기화하여 매끄러운 개발 워크플로를 유지하세요. 편집기에서 직접 변경 사항을 push 및 pull하고, pull request로 협업하며, 기존 CI/CD 파이프라인과 통합할 수 있습니다. 버전 관리를 통해 수정 내역을 쉽게 추적하고, 변경 사항을 검토하며, 재현 가능한 학술 또는 기술 문서를 유지할 수 있습니다.

참고: [GitHub Synchronisation](/ko/on-premises/configuration/overleaf-toolkit/github-synchronisation  "mention").

#### 기능 02: Pandoc 가져오기/내보내기

Microsoft Word 및 Markdown 문서를 완전히 편집 가능한 LaTeX 프로젝트로 가져오거나, 클릭 한 번으로 LaTeX 프로젝트를 Markdown 및 DOCX로 다시 내보낼 수 있습니다. Pandoc 기반의 이 기능은 문서 구조를 최대한 보존하면서 학술 글쓰기, 공동 편집, 출판 워크플로 간의 원활한 상호 운용성을 제공합니다.

참고: [Pandoc 가져오기 및 내보내기](/ko/on-premises/configuration/overleaf-toolkit/pandoc-import-and-export  "mention").

#### 기능 03: 고급 참고 문헌 검색

지능형 필터링과 즉각적인 인용 지원으로 여러 학술 데이터베이스에서 참고 문헌을 검색하고 삽입할 수 있습니다. 여러 연구 웹사이트를 오가지 않고도 논문을 빠르게 찾고, 메타데이터를 미리 보고, 정확한 BibTeX 항목을 만들 수 있어 문헌 검토 효율이 크게 향상됩니다.

![image](https://github.com/user-attachments/assets/42e45b73-af4b-4d1f-81f4-9e116ba5d043)

#### 기능 04: Python 실행기

편집기를 떠나지 않고 프로젝트 안에서 Python 코드를 직접 실행할 수 있습니다. 그림 생성, 데이터셋 처리, 문서 워크플로 자동화, 재현 가능한 연구 스크립트 실행에 적합합니다. 결과를 LaTeX 문서에 통합할 수 있어 과학 계산과 글쓰기를 하나의 워크플로로 통합할 수 있습니다.

![image](https://github.com/user-attachments/assets/a4c314b3-fdb5-4836-aea7-12eeece5cd2f)

#### 기능 05: Zotero

Zotero 라이브러리를 글쓰기 워크플로에 직접 연결하고 편집기를 떠나지 않고 참고 문헌을 관리하세요. 개인 Zotero 컬렉션을 검색하고, 클릭 한 번으로 인용을 삽입하며, BibTeX 항목을 자동으로 생성하고 동기화할 수 있습니다. 이 연동은 참고 문헌 목록을 최신 상태로 유지하여 학술 논문, 학위 논문, 기술 문서의 문헌 관리를 간소화합니다.

참고: [Zotero 연동](/ko/on-premises/configuration/overleaf-toolkit/zotero-integration  "mention").
