수년 동안 Overleaf Community Edition을 사용하는 많은 사람들이 Overleaf Server Pro에 큰 관심을 보여 왔습니다. Overleaf CE에는 다음과 같은 제약이 너무 많기 때문입니다.

* 샌드박스가 없어 LaTeX 컴파일이 컨테이너와 동일한 권한으로 실행됩니다.
* TeX Live 버전 전환을 지원하지 않습니다. 버전마다 수동으로 설치해야 합니다.
* 변경 내용 추적 기능이 없어 공동 작성과 댓글 작업이 상당히 어렵습니다.
* Git 연동이 없어 로컬 LaTeX 사용자가 공동 프로젝트에 참여하기 어렵습니다.

하지만 명확하고 신뢰할 수 있는 가격 정보는 찾기 어려웠습니다. Overleaf 웹사이트에서는 영업팀에 문의하는 것이 유일한 방법입니다. Server Pro는 개인 사용자가 직접 구매할 수 없는 것으로 보입니다. 저희는 검색 엔진을 통해 일부 가격 정보를 찾을 수 있었습니다.

커뮤니티에서 수집한 정보에 따르면, **Server Pro의 견적은 다음과 같습니다**.

* _최소_ 10명분의 라이선스를 구매해야 합니다.
* 10인 라이선스는 약 €3,477.61입니다. (2024년 기준)
* 교육 기관의 경우 연간 20명 2640유로, 50명 6050유로, 100명 9963유로입니다.
* Server Pro는 일부 지역에서만 제공됩니다(예: 중국 본토 제외).

이후 2026년에 저희는 ChatGPT Search를 사용해 Overleaf Server Pro를 구매한 기관을 더 찾아냈습니다.

Overleaf Server Pro의 비용은 사용자당 연간 약 \$300인 것으로 보입니다. 미국의 소규모 계약을 보면 사용자당 연간 비용이 대략 \$320–\$370입니다. 대규모 기관 계약은 사용자당 더 낮은 가격을 받을 수 있습니다. 예를 들어 막스 플랑크 협회의 3년 계약은 사용자당 연평균 약 €51입니다. 계약 조건, 지원, 배포 범위는 다를 수 있습니다. 이 기록은 Overleaf의 공식 가격표가 아닙니다.

게다가 Server Pro는 Overleaf SaaS 플랫폼보다 제공하는 기능이 훨씬 적습니다. Server Pro가 엄격한 보안 요구 사항을 가진 고객(예: 정부 부처)을 포함한 사설 네트워크 배포를 대상으로 하기 때문입니다.

하지만 커뮤니티 개발자들은 수년간 Community Edition의 기능 격차를 메우기 위해 노력해 왔습니다. 저희는 현재 이용 가능한 Overleaf 포크 중 가장 완성도 높은 것 중 하나인 Ayakaleaf Pro를 추천합니다. 아래는 기능 비교표입니다.

### 온라인 LaTeX 편집기 만들기? 간단하지 않습니다!

2026년 초부터 Claude나 Codex 같은 코드 에이전트의 도움으로 거의 매달 새로운 Overleaf 대안이 등장하고 있습니다. OpenAI도 과학 LaTeX 작성을 위한 제품인 [Prism](https://prism.openai.com/)을 선보였습니다.

많은 사람들이 Overleaf는 끝났고 Prism이 최고의 무료 LaTeX 편집기가 될 것이라고 떠들썩하게 주장했지만, 저희가 보기에 Prism은 아직 성숙한 제품과는 거리가 멉니다.

아래 스크린샷은 OpenAI 커뮤니티에서 Prism에 관해 오간 논의를 담고 있습니다. 대부분의 댓글은 Prism이 버그가 많고 아직 일상적으로 사용하기에는 이르다고 평가합니다.

<Frame>
  <img src="/images/blog/img-36568b5f.png" alt="" />
</Frame>

<strong>신뢰할 수 있는 온라인 LaTeX 편집기를 만드는 일은 결코 간단하지 않습니다.</strong> 저희가 관찰한 바에 따르면 Prism은 프로젝트를 열 때 샌드박스를 프로비저닝하고 이를 계속 실행 상태로 유지하는데, 이는 Codex가 백그라운드에서 계속 대기하기 때문인 것으로 보입니다. 덕분에 사용자가 AI 대화를 시작하면 Codex가 빠르게 응답할 수 있습니다. 저희 테스트에서 각 샌드박스에는 약 5 vCPU, 6 GB 메모리, 64 GB 디스크 공간이 할당되었습니다.

이러한 아키텍처는 수천 명의 사용자가 동시에 LaTeX 프로젝트를 편집할 때 상당한 컴퓨팅 오버헤드를 유발할 수 있습니다. Ayakaleaf는 다른 접근 방식을 취합니다. 샌드박스는 컴파일이 요청될 때만 생성됩니다. 각 컴파일은 1 vCPU와 1 GB 메모리로 제한되며, 컴파일이 끝나면 샌드박스가 종료됩니다. 이를 통해 상시 리소스 소비를 크게 줄이고 대규모 배포의 용량 계획을 더 예측 가능하게 만듭니다.

더 넓게 보면, Prism은 강력한 모델과 성숙한 오픈소스 소프트웨어 생태계를 활용할 수 있더라도 AI 기능과 신뢰할 수 있는 온라인 개발 환경을 결합하는 일이 여전히 얼마나 어려운지를 보여 줍니다. AI는 경험을 개선할 수 있지만 견실한 시스템 엔지니어링을 대신할 수는 없습니다. 결국 사용자가 의존하는 것은 신뢰할 수 있고, 예측 가능하며, 안정적인 서비스입니다.

### 왜 Ayakaleaf Pro인가?

**Ayakaleaf Pro**는 Overleaf Community Edition의 포크로, 사용자별 라이선스 없이 Server Pro 수준과 SaaS 수준의 기능을 자체 호스팅 배포에 제공합니다. 업스트림 Overleaf 코드베이스와 동기화된 상태를 유지하므로 익숙한 편집기와 워크플로를 그대로 사용하면서 다음 기능도 누릴 수 있습니다.

* 샌드박스 LaTeX 컴파일
* 여러 TeX Live 버전
* 변경 내용 추적 및 댓글
* Git 및 GitHub 연동
* SSO 및 관리자 패널
* 비공개 템플릿 관리
* Zotero 및 고급 참고문헌 검색
* Pandoc 가져오기/내보내기
* Python 스크립트 실행기
* 사용자별 라이선스 비용 없음

저희의 목표는 Server Pro 라이선스나 SaaS 구독 없이도 더 완전한 자체 호스팅 Overleaf 경험을 제공하는 것입니다. Ayakaleaf Pro는 익숙한 Overleaf 워크플로와 업스트림 호환성을 유지하면서 협업, 관리, 연동, 보안 컴파일 기능을 추가합니다.

### 왜 우리는 계속 바퀴를 재발명할까?

한 번쯤 던져 볼 만한 더 큰 질문이 있습니다. _**성숙한 오픈소스 프로젝트가 이미 어려운 문제의 대부분을 해결했는데, 왜 처음부터 다시 작성하려는 경향이 그렇게 강할까요**_?&#x20;

편집기, 실시간 협업 계층, 컴파일 파이프라인, 그리고 수년간 축적된 엣지 케이스 수정 사항을 다시 구현하는 것은 엄청난 비용이 들며, 그 노력의 상당 부분은 원래 프로젝트가 오래전에 해결한 문제를 다시 발견하는 데 쓰입니다. 대부분의 경우, 탄탄한 기반을 확장하고 부족한 부분을 기여하는 것이 더 실용적인 엔지니어링 선택입니다.

제가 정말 말하고 싶은 것은 이것입니다.

> _AI 시대에 사람들은 과시하기를 좋아합니다._

"나만의 Overleaf를 만들었다"는 말은 "Overleaf에 기능 몇 가지를 추가했다"보다 훨씬 인상적으로 들립니다. 그래서 사람들은 전자의 이야기를 하고 싶어 합니다. 새로운 "AI LaTeX 편집기"가 매달 등장하는 것처럼 보이는 이유도 바로 그것입니다.

하지만 실제로 이렇게 AI의 도움으로 다시 작성된 편집기들은 Overleaf처럼 10년간 실전에서 검증되며 쌓아 온 신뢰성과 성숙도에 전혀 미치지 못합니다. 두 달만 지나면 2월의 크리스마스 장난감처럼 자신들의 편집기를 버려 둘 겁니다. 믿으셔도 됩니다.
