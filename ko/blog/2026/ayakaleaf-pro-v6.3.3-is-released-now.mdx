Overleaf Pro 6.3.3의 출시를 발표하게 되어 매우 자랑스럽습니다. 업스트림 Overleaf 6.3.3은 Node.js와 설치된 패키지를 업데이트하는 보안 릴리스이며, 저희는 이를 새 관리자 패널의 초기 프리뷰, 계정당 여러 이메일, 더 커진 MCP 서버, 더 나아진 AI 어시스턴트와 함께 제공합니다.

### 변경 사항 {#changes}

* 새 관리자 패널(초기 프리뷰): 사용자, 프로젝트, 템플릿 페이지, 감사 로그, 사용자별 기능 스위치.
* 계정당 여러 이메일(초기 프리뷰).
* MCP 서버: 기록, 추적된 변경 사항, 댓글, 채팅, 파일 이동.
* AI 어시스턴트: OpenAI Responses API, 그리고 PDF 첨부, 웹 페이지 읽기, 긴 채팅(초기 프리뷰).
* 가입 및 로그인: reCAPTCHA v2와 공개 가입용 이메일 도메인 목록(초기 프리뷰).
* Node.js 24.22.3 및 패키지 업데이트: 업스트림 Overleaf 6.3.3의 보안 업데이트.
* E2E 테스트 시스템과 Internal Horizon Issue Investigation으로 발견한 버그 수정.

<Info>

새 관리자 패널, 여러 이메일, AI 어시스턴트 첨부 파일, 새 가입 옵션은 6.3.3에서 그레이 테스트를 위한 **초기 프리뷰**로 제공되며 v6.4.0에서 정식 출시됩니다. 그 전까지 동작이 바뀔 수 있습니다. 문제가 있으면 [GitHub](https://github.com/ayaka-notes/ayakaleaf-pro/issues)에 보고해 주세요.

</Info>

#### 기능 01: 새 관리자 패널(프리뷰) {#feature-01-new-admin-panel-preview}

연구실이나 학과용 인스턴스를 운영하면 매주 같은 질문이 나옵니다. 이 학생은 왜 로그인할 수 없는지, 누가 저 계정에 관리자 권한을 주었는지, 작년 논문은 어디로 갔는지. 새 관리자 패널에는 모든 사용자 목록과 모든 프로젝트 목록, 각각의 상세 페이지, 템플릿 관리, 감사 로그가 있습니다. 관리자는 여러 사용자에게 한 번에 작업을 수행하고, 이메일이 발송되지 않을 때 활성화 링크와 비밀번호 링크를 복사하며, Dropbox, Git, AI 어시스턴트, 변경 추적, 기호 팔레트 같은 주요 기능을 사용자별로 켜거나 끌 수 있습니다.

#### 기능 02: 계정당 여러 이메일(프리뷰) {#feature-02-multiple-emails-per-account-preview}

사용자는 각 주소로 전송되는 코드를 사용해 계정에 이메일을 추가하고, 다른 이메일을 기본 이메일로 지정할 수 있습니다. 예를 들어 대학 주소가 회수되기 전에 바꿀 수 있습니다. 로그인과 비밀번호 재설정은 기본 이메일로만 가능합니다. 인스턴스가 이메일을 보낼 수 있으면 켜집니다.

[여러 이메일](/ko/on-premises/user-guide/users/multiple-emails  "mention") 문서를 참조하세요.

#### 기능 03: MCP 서버 {#feature-03-mcp-server}

Claude Code, Codex, Cursor 같은 AI 클라이언트가 이제 프로젝트 기록을 살펴보고 버전을 복원하고, 추적된 변경 사항을 검토하고, 자신의 편집을 추적된 변경 사항으로 만들고, 텍스트에 댓글을 달고, 채팅 메시지를 읽고 보내고, 파일을 이동하거나 이름을 바꿀 수 있습니다. MCP 서버의 도구는 17개에서 33개로 늘었습니다.

[MCP 서버](/on-premises/user-guide/users/mcp-server  "mention") 문서를 참조하세요.

#### 기능 04: OpenAI Responses API {#feature-04-openai-responses-api}

gpt-6.x 같은 OpenAI의 최신 추론 모델은 Chat Completions에서 함수 도구를 거부하므로 AI 어시스턴트와 오류 어시스턴트가 이를 사용할 수 없었습니다. 대신 OpenAI Responses API를 호출하려면 `AI_API_MODE=responses`를 설정하세요. 첨부 파일과 토큰 할당량은 이전과 같이 작동합니다.

[AI 통합](/ko/on-premises/configuration/overleaf-toolkit/integrations/ai-integration  "mention") 문서를 참조하세요.

#### 기능 05: AI 어시스턴트 개선(프리뷰) {#feature-05-ai-assistant-improvements-preview}

이미지와 함께 최대 2 MB의 PDF 파일을 첨부할 수 있으며, PDF를 읽는 모델을 위해 선택적으로 `AI_PDF_MODEL`을 지정할 수 있습니다. 어시스턴트는 linked URL 프록시를 통해 웹 페이지를 읽고, 웹을 검색할 때 오늘 날짜를 압니다. 긴 채팅은 요약되고 오래된 도구 출력은 압축되므로 모델의 컨텍스트를 채우지 않고 채팅을 계속할 수 있습니다.

[AI 어시스턴트](/on-premises/user-guide/users/ai-assistant  "mention") 문서를 참조하세요.

#### 기능 06: 가입 및 로그인(프리뷰) {#feature-06-sign-up-and-login-preview}

`RECAPTCHA_SITE_KEY`와 `RECAPTCHA_SECRET_KEY`를 설정하면 로그인, LDAP 로그인, 가입, 비밀번호 재설정을 reCAPTCHA v2로 보호합니다. `OVERLEAF_ALLOW_PUBLIC_REGISTRATION`은 이제 `@example.edu,@*.example.org` 같은 이메일 도메인 목록이나 모든 도메인을 뜻하는 `@*`를 받습니다. 로그인 및 가입 페이지는 양식을 카드 안에 표시합니다.

[reCAPTCHA](/ko/on-premises/configuration/overleaf-toolkit/authentication/recaptcha  "mention") 및 [공개 접근](/ko/on-premises/configuration/overleaf-toolkit/authentication/public-access  "mention") 문서를 참조하세요.

#### 버그 수정 {#bug-fixes}

* **관리자 패널**: 삭제된 관리자도 감사 로그와 "Deleted by"에서 계속 이메일로 표시되며, 완전히 삭제되면 "Deleted user"로 표시됩니다. 자기 계정을 비활성화, 삭제 또는 강등하는 직접 요청은 거부됩니다.
* **AI 어시스턴트**: `AI_PDF_MODEL`이 없으면 PDF 파일과 이미지가 있는 채팅은 PDF 파일을 읽지 못할 수 있는 이미지 모델이 아니라 `AI_MODEL`로 전송됩니다.
* **템플릿 갤러리**: 편집은 양식의 필드만 받으며, 텍스트가 아닌 필드에는 500 대신 400으로 응답합니다.
* **Git bridge**: clone 명령은 구두점이 아니라 복사 블록의 가장자리에서 줄바꿈됩니다.

전체 목록은 [6.3.3 릴리스 노트](/ko/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.3  "mention")를 참고하세요.

#### 업그레이드 {#upgrade}

* 6.3.2, 6.3.1 또는 6.3.0에서: 마이그레이션이 필요 없습니다. 새 이미지를 pull하고 재시작하세요.
* Zotero 또는 Mendeley를 사용하는 6.2.x 이하에서: 먼저 6.3.0의 [Zotero / Mendeley 마이그레이션](/ko/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention")을 실행하세요.
* 새 관리자 패널이 이전 패널을 대체합니다. 여러 이메일에는 이메일 발송이 필요하며, reCAPTCHA, 도메인 목록, `AI_API_MODE`는 새 환경 변수만 있으면 됩니다.
