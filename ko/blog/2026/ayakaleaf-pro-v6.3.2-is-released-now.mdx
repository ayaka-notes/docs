Overleaf Pro 6.3.2의 출시를 매우 자랑스럽게 발표합니다. 업스트림 Overleaf 6.3.2는 Node.js를 업데이트하는 보안 릴리스이며, 저희는 여기에 동기화 제품군의 새로운 멤버를 함께 제공합니다. GitHub, GitLab, Dropbox에 이어 이제 프로젝트를 Gitea에도 둘 수 있습니다.

### 변경 사항

* Gitea 동기화(얼리 프리뷰): gitea.com 또는 자체 호스팅 Gitea와 양방향으로 동기화합니다.
* Node.js 24.22.1: 업스트림 Overleaf 6.3.2의 보안 업데이트입니다.
* E2E 테스트 시스템과 Internal Horizon Issue Investigation으로 발견한 버그 수정.

<Info>

Gitea 동기화는 그레이 테스트를 위한 **얼리 프리뷰**로 6.3.2에 포함되며, v6.4.0에서 정식 출시될 예정입니다. 그 전까지 구성과 동작이 변경될 수 있습니다. 기본적으로 꺼져 있습니다. 문제가 있으면 [GitHub](https://github.com/ayaka-notes/ayakaleaf-pro/issues)에 보고해 주세요.

</Info>

#### 기능 01: Gitea 동기화(프리뷰)

많은 연구실과 소규모 팀은 작은 서버 한 대로도 충분할 만큼 가벼운 Gitea를 직접 운영합니다. Gitea 동기화는 GitHub 동기화 및 GitLab 동기화와 같은 방식으로 동작합니다. 계정을 연결하고, 새 프로젝트 메뉴에서 저장소를 가져오거나 프로젝트를 새 Gitea 저장소로 내보내세요. 그런 다음 편집기에서 푸시와 풀을 하고, 저장소 자체의 병합 방식에 따라 풀 리퀘스트를 통해 병합하면 됩니다. Overleaf는 브랜치 보호를 절대 우회하지 않습니다. 풀 리퀘스트에 승인이나 검사 통과가 필요한 경우, 여러분이 Gitea에서 병합할 때까지 기다립니다.

gitea.com과 자체 호스팅 Gitea 1.23 이상에서 동작합니다. `GITEA_SYNC_ENABLED`, `GITEA_SYNC_CLIENT_ID`, `GITEA_SYNC_CLIENT_SECRET`, `GITEA_TOKEN_CIPHER_PASSWORD`를 설정하고, 자체 호스팅 인스턴스의 경우 `GITEA_SYNC_URL`도 설정하세요.

전체 설정 방법은 [Gitea 동기화](/ko/on-premises/configuration/overleaf-toolkit/gitea-synchronisation  "mention")를 참고하세요.

#### 버그 수정

* **Git 동기화**: GitHub, GitLab 또는 Gitea에서 삭제된 파일을 Overleaf에서 삭제할 수 없는 경우, 이제 성공으로 보고하고 파일을 남겨 두는 대신 동기화가 실패하며 다시 시도할 수 있습니다. 파일을 삭제하는 `git push`도 같은 방식으로 실패합니다.
* **Git bridge**: 편집기에서 텍스트가 아닌 확장자(예: `.csv`)로 만든 문서는 `git push`로 변경되어도 편집 가능한 상태로 유지됩니다.
* **변경 내용 추적**: 링크로 공유된 프로젝트의 로그아웃 상태 편집자는 댓글 스레드를 삭제할 수 있지만 더 이상 해결하거나 다시 열 수 없으며, 검토자는 자신의 답글을 삭제할 수 있습니다.
* **템플릿 갤러리**: 템플릿을 게시하려면 프로젝트에 대한 접근 권한이 필요합니다.
* **Learn**: 위키에 연결할 수 없을 때도 캐시된 도움말 페이지를 계속 사용할 수 있습니다.

전체 목록은 [6.3.2 릴리스 노트](/ko/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.2  "mention")를 참고하세요.

#### 업그레이드

* 6.3.1 또는 6.3.0에서: 마이그레이션이 필요하지 않습니다. 새 이미지를 받고 다시 시작하세요.
* Zotero 또는 Mendeley를 사용하는 6.2.x 이하에서: 먼저 6.3.0의 [Zotero / Mendeley 마이그레이션](/ko/on-premises/release-notes/release-notes-6.x.x#ayakaleaf-pro-6.3.0  "mention")을 실행하세요.
* Gitea 동기화는 기본적으로 꺼져 있으며 새 환경 변수만 필요합니다.
