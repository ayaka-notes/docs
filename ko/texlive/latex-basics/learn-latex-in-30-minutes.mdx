이 입문 튜토리얼은 LaTeX 사용 경험이 전혀 없다고 가정합니다. 튜토리얼을 마칠 즈음에는 첫 LaTeX 문서를 작성했을 뿐만 아니라, LaTeX 숙련을 향한 다음 단계로 나아갈 수 있을 만큼 충분한 지식과 자신감을 얻게 되기를 바랍니다.

## LaTeX란?

LaTeX("_레이_텍" 또는 "_라_텍"으로 발음)는 전문적인 품질의 문서를 조판하는 도구입니다. 하지만 LaTeX의 작동 방식은 Microsoft Word나 LibreOffice Writer처럼 여러분이 사용해 보았을 다른 문서 작성 애플리케이션과는 상당히 다릅니다. 그러한 "[WYSIWYG](https://en.wikipedia.org/wiki/WYSIWYG)" 도구는 사용자가 텍스트를 입력·편집하고 다양한 스타일을 적용할 수 있는 대화형 페이지를 제공합니다. LaTeX는 매우 다르게 작동합니다. 문서는 원하는 (조판) 결과를 표현하는 LaTeX _명령_이 곳곳에 들어간 일반 텍스트 파일입니다. 눈에 보이는 조판된 문서를 만들기 위해 LaTeX 파일은 _TeX 엔진_이라는 소프트웨어로 처리됩니다. TeX 엔진은 텍스트 파일에 포함된 명령을 사용해 조판 과정을 안내하고 제어하며, LaTeX 명령과 문서 텍스트를 전문적으로 조판된 PDF 파일로 변환합니다. 즉, 여러분은 문서의 _내용_에만 집중하면 되고, _시각적 모양_(서식)은 컴퓨터가 LaTeX 명령과 TeX 엔진을 통해 처리합니다.

## 왜 LaTeX를 배워야 할까요?

다른 문서 작성 애플리케이션 대신 LaTeX 사용법을 배우는 것에 대해서는 찬성과 반대 의견이 다양하게 있을 수 있지만, 결국은 선호도, 성향, 문서 요구 사항에 따른 개인적인 선택입니다.

LaTeX를 지지하는 주장은 다음과 같습니다.

* 매우 복잡한 수학, 표, 자연과학 분야의 기술적 내용을 조판할 수 있습니다.
* 각주, 상호 참조, 참고문헌 관리 기능을 제공합니다.
* 색인, 용어집, 목차, 그림 목록처럼 복잡하거나 번거로운 문서 요소를 쉽게 만들 수 있습니다.
* 본질적인 프로그래밍 가능성과 수천 개의 [무료 추가 패키지](https://www.ctan.org/pkg)를 통한 확장성 덕분에, 맞춤형 문서 제작을 위해 폭넓게 사용자 지정할 수 있습니다.

전반적으로 LaTeX는 매우 높은 수준으로 조판되는 문서의 제작 과정을 사용자가 세밀하게 제어할 수 있게 해 줍니다. 물론 잡지 형태의 출판물에서 흔히 볼 수 있는 "자유 형식" 페이지 디자인처럼 LaTeX가 빛을 발하지 못하는 문서나 출판물 유형도 있습니다.

LaTeX의 중요한 장점 중 하나는 문서 내용과 문서 스타일이 분리된다는 것입니다. 문서 내용을 작성한 후에도 모양을 쉽게 바꿀 수 있습니다. 마찬가지로 특정 문서 유형의 레이아웃/스타일을 정의하는 LaTeX 파일을 만들어, 같은 유형의 다른 문서를 작성·제작할 때 표준화하는 _템플릿_으로 사용할 수 있습니다. 예를 들어 과학 출판사는 저자가 저널에 투고할 논문을 작성할 때 사용하는 논문 템플릿을 LaTeX로 만들 수 있습니다. Overleaf에는 과학 논문, 보고서, 책부터 이력서와 프레젠테이션까지 매우 다양한 문서 유형을 아우르는 [수천 개의 템플릿을 담은 갤러리](https://www.overleaf.com/gallery)가 있습니다. 이 템플릿이 문서의 레이아웃과 스타일을 정의하므로, 저자는 Overleaf에서 템플릿을 열어 새 프로젝트를 만든 다음 내용을 작성하기만 하면 됩니다.

## 첫 LaTeX 작성하기

첫 단계는 새 LaTeX 프로젝트를 만드는 것입니다. 자신의 컴퓨터에서 새 `.tex` 파일을 만들거나, Overleaf에서 새 프로젝트를 시작할 수 있습니다.

Overleaf에서 바로 열 수 있는 가장 간단한 동작 예시부터 시작해 보겠습니다.

```latex
\documentclass{article}
\begin{document}
First document. This is a simple example, with no 
extra parameters or packages included.
\end{document}
```

[이 예시를 Overleaf에서 열기](https://www.overleaf.com/docs?engine=pdflatex&snip%5Fname=Simplest+working+example+LaTeX+document&snip=%5Cdocumentclass%7Barticle%7D%0A%5Cbegin%7Bdocument%7D%0AFirst+document.+This+is+a+simple+example%2C+with+no+%0Aextra+parameters+or+packages+included.%0A%5Cend%7Bdocument%7D)

이 예시의 출력 결과는 다음과 같습니다.

![예시 문서](https://images.ctfassets.net/nrgyaltdicpt/5oBbZABsWEnHZpwhfvV2PD/95ba7d5496616b4f10dffe6fb90f578a/LL30Fig1-plain.svg)

LaTeX가 문단의 첫 줄을 자동으로 들여쓰기하여 서식을 대신 처리했음을 알 수 있습니다. 코드의 각 부분이 어떤 역할을 하는지 자세히 살펴보겠습니다.

코드의 첫 줄 `\documentclass{article}`은 _클래스_라고 하는 문서 유형을 선언하며, 이는 문서의 전체적인 모양을 제어합니다. 문서 유형마다 다른 클래스가 필요합니다. 예를 들어 이력서에는 표준 LaTeX `article` 클래스를 사용할 수 있는 과학 논문과는 다른 클래스가 필요합니다. 작업하는 다른 유형의 문서에는 `book`이나 `report` 같은 다른 클래스가 필요할 수 있습니다. 사용할 수 있는 다양한 LaTeX 클래스 유형을 알아보려면 [CTAN(Comprehensive TeX Archive Network)의 관련 페이지를 방문하세요](https://www.ctan.org/topic/class).

문서 클래스를 설정했으면, 문서의 _본문_이라고 하는 내용을 `\begin{document}`와 `\end{document}` 태그 사이에 작성합니다. 위 예시를 연 후 텍스트를 수정하고, 작업이 끝나면 _문서를 다시 컴파일_하여 조판된 PDF 결과를 확인할 수 있습니다. Overleaf에서는 다음 짧은 동영상 클립처럼 **Recompile**을 누르기만 하면 됩니다.

모든 Overleaf 프로젝트는 편집할 때마다 자동으로 다시 컴파일되도록 구성할 수 있습니다. 다음 화면 캡처처럼 **Recompile** 버튼 옆의 작은 화살표를 클릭하고 **Auto Compile**을 **On**으로 설정하세요.

![Auto Compile을 On 또는 Off로 설정하는 방법을 보여 주는 화면 캡처](/images/texlive/ll30autocompile.png)

문서에 내용을 추가하는 방법을 알아보았으니, 다음 단계는 제목을 붙이는 것입니다. 이를 위해 **프리앰블**에 대해 간단히 알아보겠습니다.

## 문서의 프리앰블

위 화면 캡처에서 Overleaf는 LaTeX 문서를 `main.tex`라는 파일로 저장하고 있습니다. 관례적으로 문서의 LaTeX 코드가 담긴 파일에는 `.tex` 파일 확장자를 사용합니다.

이전 예시에서는 `\begin{document}` 명령 다음에 문서 내용을 입력하는 방법을 보여 주었습니다. 그런데 `.tex` 파일에서 그 지점 _이전_에 나오는 모든 부분을 _프리앰블_이라고 하며, 이는 문서의 "설정" 섹션 역할을 합니다. 프리앰블에서는 문서 클래스(유형)와 함께 문서 작성에 사용할 언어 같은 세부 사항을 정의하고, 사용하려는 _패키지_를 불러오며(자세한 내용은 [뒤에서](/ko/texlive/latex-basics/learn-latex-in-30-minutes#Finding%5Fand%5Fusing%5FLaTeX%5Fpackages) 설명), 그 밖의 다양한 구성을 적용합니다.

최소한의 문서 프리앰블은 다음과 같습니다.

```latex
\documentclass[12pt, letterpaper]{article}
\usepackage{graphicx}
```

여기서 `\documentclass[12pt, letterpaper]{article}`은 문서의 전체 클래스(유형)를 정의합니다. 쉼표로 구분해야 하는 추가 매개변수는 대괄호(`[...]`) 안에 넣으며, 이 article 클래스 인스턴스를 구성하는 데 사용됩니다. 즉, 이 특정 `article` 클래스 기반 문서에 사용할 설정입니다.

이 예시에서 두 매개변수는 다음 역할을 합니다.

* `12pt`는 글꼴 크기를 설정합니다.
* `letterpaper`는 용지 크기를 설정합니다.

물론 `9pt`, `11pt`, `12pt` 같은 다른 글꼴 크기도 사용할 수 있으며, 아무것도 지정하지 않으면 기본 크기는 `10pt`입니다. 용지 크기로는 `a4paper`와 `legalpaper`도 사용할 수 있습니다. 자세한 내용은 페이지 크기와 여백에 관한 글을 참조하세요.

프리앰블의 다음 줄은

```latex
\usepackage{graphicx}
```

외부 패키지(여기서는 [graphicx](https://ctan.org/pkg/graphicx?lang=en))를 불러와 LaTeX의 기능을 확장하여 외부 그래픽 파일을 가져올 수 있게 하는 예입니다. LaTeX 패키지는 [LaTeX 패키지 찾기 및 사용하기](/ko/texlive/latex-basics/learn-latex-in-30-minutes#Finding%5Fand%5Fusing%5FLaTeX%5Fpackages) 섹션에서 다룹니다.

## 제목, 저자, 날짜 정보 넣기

문서에 제목, 저자, 날짜를 추가하려면 문서 본문이 _아닌_ _프리앰블_에 세 줄을 더 추가해야 합니다. 그 줄은 다음과 같습니다.

* `\title{My first LaTeX document}`: 문서 제목
* `\author{Hubert Farnsworth}`: 저자 이름을 작성하며, 선택적으로 중괄호 안에 `\thanks` 명령을 넣을 수 있습니다.
  * `\thanks{Funded by the Overleaf team.}`: `author` 명령의 중괄호 안에서 저자 이름 뒤에 추가할 수 있습니다. 위첨자와 함께 중괄호 안의 텍스트가 담긴 각주를 추가합니다. 논문에서 기관에 감사를 표해야 할 때 유용합니다.
* `\date{August 2022}`: 날짜를 직접 입력하거나, `\today` 명령을 사용해 문서를 컴파일할 때마다 현재 날짜를 조판할 수 있습니다.

이 줄들을 추가하면 프리앰블은 다음과 같은 모습이 됩니다.

```latex
\documentclass[12pt, letterpaper]{article}
\title{My first LaTeX document}
\author{Hubert Farnsworth\thanks{Funded by the Overleaf team.}}
\date{August 2022}
```

제목, 저자, 날짜를 조판하려면 문서 _본문_에서 `\maketitle` 명령을 사용합니다.

```latex
\begin{document}
\maketitle
We have now added a title, author and date to our first \LaTeX{} document!
\end{document}
```

이제 프리앰블과 본문을 합쳐 Overleaf에서 열 수 있는 완전한 문서를 만들 수 있습니다.

```latex
\documentclass[12pt, letterpaper]{article}
\title{My first LaTeX document}
\author{Hubert Farnsworth\thanks{Funded by the Overleaf team.}}
\date{August 2022}
\begin{document}
\maketitle
We have now added a title, author and date to our first \LaTeX{} document!
\end{document}
```

## 주석 추가하기

LaTeX는 일종의 "프로그램 코드"이지만 문서 조판에 특화되어 있습니다. 따라서 다른 프로그래밍 언어로 작성된 코드와 마찬가지로 문서 안에 주석을 넣으면 매우 유용합니다. LaTeX 주석은 조판되지 않고 문서에 아무런 영향을 주지 않는 텍스트 부분으로, "할 일" 메모를 추가하거나, 설명을 덧붙이거나, 까다로운 매크로를 인라인으로 설명하거나, 디버깅할 때 LaTeX 코드의 줄이나 섹션을 주석 처리하는 데 자주 사용됩니다.

LaTeX에서 주석을 만들려면 위 예시를 활용한 다음 코드처럼 줄의 시작 부분에 `%` 기호를 쓰기만 하면 됩니다.

```latex
\documentclass[12pt, letterpaper]{article}
\title{My first LaTeX document}
\author{Hubert Farnsworth\thanks{Funded by the Overleaf team.}}
\date{August 2022}
\begin{document}
\maketitle
We have now added a title, author and date to our first \LaTeX{} document!

% This line here is a comment. It will not be typeset in the document.
\end{document}
```

[이 예시를 Overleaf에서 열기](https://www.overleaf.com/docs?engine=pdflatex&snip%5Fname=My+first+LaTeX+document+with+a+comment&snip=%5Cdocumentclass%5B12pt%2C+letterpaper%5D%7Barticle%7D%0A%5Ctitle%7BMy+first+LaTeX+document%7D%0A%5Cauthor%7BHubert+Farnsworth%5Cthanks%7BFunded+by+the+Overleaf+team.%7D%7D%0A%5Cdate%7BAugust+2022%7D%0A%5Cbegin%7Bdocument%7D%0A%5Cmaketitle%0AWe+have+now+added+a+title%2C+author+and+date+to+our+first+%5CLaTeX%7B%7D+document%21%0A%0A%25+This+line+here+is+a+comment.+It+will+not+be+typeset+in+the+document.%0A%5Cend%7Bdocument%7D)

이 예시는 주석이 없는 이전 LaTeX 코드와 동일한 출력을 생성합니다.

## 굵게, 기울임꼴, 밑줄

이제 몇 가지 텍스트 서식 명령을 살펴보겠습니다.

* **굵게**: LaTeX에서 굵은 텍스트는 `\textbf{...}` 명령으로 조판합니다.
* _기울임꼴_: 기울임꼴 텍스트는 `\textit{...}` 명령으로 만듭니다.
* 밑줄: 텍스트에 밑줄을 그으려면 `\underline{...}` 명령을 사용합니다.

다음 예시는 이 명령들을 보여 줍니다.

```latex
Some of the \textbf{greatest}
discoveries in \underline{science} 
were made by \textbf{\textit{accident}}.
```

## 이미지 추가하기

이 섹션에서는 LaTeX 문서에 이미지를 추가하는 방법을 살펴봅니다. Overleaf는 이미지를 삽입하는 세 가지 방법을 지원합니다.

1. 에디터 도구 모음에 있는 [**Insert Figure** 버튼](https://learn.overleaf.com/learn/Kb/How_to_insert_figures_in_Overleaf#Using%5FInsert%5FFigure%5Fto%5Fadd%5Fa%5Ffigure%5Fto%5Fyour%5Fproject)(![에디터 도구 모음의 Insert Figure 버튼](https://sharelatex-wiki-cdn-671420.cdn77.org/learn-scripts/images/a/a8/InsertFigureButton.png))을 사용해 **Visual Editor** 또는 **Code Editor**에 이미지를 삽입합니다.
2. 이미지를 복사하여 **Visual Editor** 또는 **Code Editor**에 붙여 넣습니다.
3. **Code Editor**를 사용해 그래픽을 삽입하는 LaTeX 코드를 작성합니다.

1번과 2번 방법은 이미지 삽입에 필요한 LaTeX 코드를 자동으로 생성하지만, 여기서는 3번 방법을 소개합니다. 이때 해당 이미지를 Overleaf 프로젝트에 [업로드](https://docs.overleaf.com/writing-and-editing/inserting-images)해야 합니다. 다음 예시는 그림을 넣는 방법을 보여 줍니다.

```latex
\documentclass{article}
\usepackage{graphicx} %LaTeX package to import graphics
\graphicspath{{images/}} %configuring the graphicx package
 
\begin{document}
The universe is immense and it seems to be homogeneous, 
on a large scale, everywhere we look.

% The \includegraphics command is 
% provided (implemented) by the 
% graphicx package
\includegraphics{universe}  
 
There's a picture of a galaxy above.
\end{document}
```

[이 이미지 예시를 Overleaf에서 열기](https://www.overleaf.com/project/new/template/25686?id=107971142&templateName=Example+using+images+in+LaTeX&latexEngine=pdflatex&texImage=texlive-full%3A2022.1&mainFile=)

이 예시의 출력 결과는 다음과 같습니다.

![LaTeX 문서로 가져온 이미지를 보여 주는 그래픽](https://images.ctfassets.net/nrgyaltdicpt/4p5toat08FUgehv4yuNwXS/efc9e75e4342c9caeec94f26627fa337/LL30Fig5v2-plain.svg)

LaTeX 문서에 그래픽을 가져오려면 외부 그래픽 파일을 포함하는 데 필요한 명령과 기능을 제공하는 [추가 _패키지_](/ko/texlive/latex-basics/learn-latex-in-30-minutes#Finding%5Fand%5Fusing%5FLaTeX%5Fpackages)가 필요합니다. 위 예시는 [graphicx 패키지](https://ctan.org/pkg/graphicx?lang=en)를 불러오는데, 이 패키지는 여러 명령 가운데 그래픽을 가져오는 `\includegraphics{...}`와 그래픽의 위치를 LaTeX에 알려 주는 `\graphicspath{...}`를 제공합니다.

`graphicx` 패키지를 사용하려면 Overleaf 문서 프리앰블에 다음 줄을 포함하세요.

```latex
\usepackage{graphicx}
```

이 예시에서 `\graphicspath{{images/}}` 명령은 이미지가 현재 디렉터리에 있는 `images`라는 폴더에 보관되어 있음을 LaTeX에 알려 줍니다.

![폴더에 저장된 이미지에 LaTeX가 접근하는 모습을 보여 주는 이미지](https://sharelatex-wiki-cdn-671420.cdn77.org/learn-scripts/images/1/17/ImagesInAFolder.png)

실제로 문서에 이미지를 삽입하는 작업은 `\includegraphics{universe}` 명령이 수행합니다. 여기서 `universe`는 확장자를 제외한 이미지 파일 이름입니다.

**참고**:

* `\includegraphics` 명령에 확장자를 포함한 전체 파일 이름을 쓸 수도 있지만, 파일 확장자를 생략하는 것이 모범 사례로 여겨집니다. 그러면 LaTeX가 지원되는 모든 형식을 검색하기 때문입니다.
* 일반적으로 그래픽 파일 이름에는 공백이나 여러 개의 점이 포함되지 않아야 합니다. 또한 Overleaf에 이미지 파일을 업로드할 때는 파일 확장자에 소문자를 사용하는 것이 좋습니다.

LaTeX 패키지에 대한 자세한 내용은 이 튜토리얼 끝부분의 [LaTeX 패키지 찾기 및 사용하기](/ko/texlive/latex-basics/learn-latex-in-30-minutes#Finding%5Fand%5Fusing%5FLaTeX%5Fpackages) 섹션에서 확인할 수 있습니다.

## 캡션, 레이블, 참조

다음과 같이 `figure` 환경을 사용하면 이미지에 캡션과 레이블을 달고 참조할 수 있습니다.

```latex
\documentclass{article}
\usepackage{graphicx}
\graphicspath{{images/}}
 
\begin{document}

\begin{figure}[h]
    \centering
    \includegraphics[width=0.75\textwidth]{mesh}
    \caption{A nice plot.}
    \label{fig:mesh1}
\end{figure}
 
As you can see in figure \ref{fig:mesh1}, the function grows near the origin. This example is on page \pageref{fig:mesh1}.

\end{document}
```

이 예시의 출력 결과는 다음과 같습니다.

![LaTeX에서 그림 캡션의 사용을 보여 주는 그래픽](https://images.ctfassets.net/nrgyaltdicpt/4DkAWWkQqZP6QHU2EErogQ/9aa2371f2cde0f3f8bf22aa1c0b91789/LL30Fig6r-plain.svg)

이 예시에는 주목할 만한 명령이 몇 가지 있습니다.

* **`\includegraphics[width=0.75\textwidth]{mesh}`**: 이 형태의 `\includegraphics`는 그림의 너비를 텍스트 너비의 75%로 설정하도록 LaTeX에 지시합니다. 텍스트 너비 값은 `\textwidth` 명령에 저장되어 있습니다.
* **`\caption{A nice plot.}`**: 이름에서 알 수 있듯이 이 명령은 그림의 위나 아래에 놓일 그림 캡션을 설정합니다. 그림 목록을 만들면 이 캡션이 목록에 사용됩니다.
* **`\label{fig:mesh1}`**: 문서 안에서 이 이미지를 참조하려면 `\label` 명령으로 레이블을 지정합니다. 레이블은 이미지 번호를 생성하는 데 사용되며, 다음 명령과 함께 사용하면 이미지를 참조할 수 있습니다.
* **`\ref{fig:mesh1}`**: 이 코드는 참조된 그림에 해당하는 번호로 대체됩니다.

LaTeX 문서에 넣는 이미지는 `figure` 환경 또는 그와 비슷한 환경 안에 배치해야 LaTeX가 문서의 적절한 위치에 이미지를 자동으로 배치할 수 있습니다.

## LaTeX에서 목록 만들기

_환경_을 사용해 다양한 유형의 목록을 만들 수 있습니다. 환경은 특정 조판 기능을 구현하는 데 필요한 LaTeX 코드를 감싸는 데 사용됩니다. 환경은 `\begin{_environment-name_}`으로 시작해서 `\end{_environment-name_}`으로 끝나며, 여기서 `_environment-name_`은 `figure`, `tabular` 또는 목록 유형 중 하나(순서 없는 목록은 `itemize`, 순서 있는 목록은 `enumerate`)일 수 있습니다.

### 순서 없는 목록

순서 없는 목록은 `itemize` 환경으로 만듭니다. 다음과 같이 각 목록 항목 앞에는 `\item` 명령이 있어야 합니다.

```latex
\documentclass{article}
\begin{document}
\begin{itemize}
  \item The individual entries are indicated with a black dot, a so-called bullet.
  \item The text in the entries may be of any length.
\end{itemize}
\end{document}
```

### 순서 있는 목록

순서 있는 목록은 순서 없는 목록과 같은 문법을 사용하지만 `enumerate` 환경으로 만듭니다.

```latex
\documentclass{article}

  \item The list numbers increase with each entry we add.
\end{enumerate}
\end{document}
```

## LaTeX에 수식 추가하기

LaTeX의 주요 장점 중 하나는 수식을 쉽게 작성할 수 있다는 것입니다. LaTeX는 수식 조판을 위한 두 가지 작성 모드를 제공합니다.

* 문단의 일부인 수식을 작성할 때 사용하는 _인라인_ 수식 모드
* 텍스트나 문단의 일부가 아니며 별도의 줄에 조판되는 수식을 작성할 때 사용하는 _디스플레이_ 수식 모드

### 인라인 수식 모드

인라인 수식 모드의 예를 살펴보겠습니다.

```latex
\documentclass[12pt, letterpaper]{article}
\begin{document}
In physics, the mass-energy equivalence is stated 
by the equation $E=mc^2$, discovered in 1905 by Albert Einstein.
\end{document}
```

이 예시의 출력 결과는 다음과 같습니다.

```latex
\documentclass[12pt, letterpaper]{article}
```

### 디스플레이 수식 모드

디스플레이 모드로 조판한 수식에는 다음 예시처럼 번호를 붙이거나 붙이지 않을 수 있습니다.

```latex
\documentclass[12pt, letterpaper]{article}
\begin{document}
The mass-energy equivalence is described by the famous equation
\[ E=mc^2 \] discovered in 1905 by Albert Einstein. 

In natural units ($c = 1$), the formula expresses the identity
\begin{equation}
E=m
\end{equation}
\end{document}
```

### 더 완전한 예시

다음 예시는 LaTeX로 조판한 다양한 수학 내용을 보여 줍니다.

```latex
\documentclass{article}
\begin{document}
Subscripts in math mode are written as $a_b$ and superscripts are written as $a^b$. These can be combined and nested to write expressions such as

\[ T^{i_1 i_2 \dots i_p}_{j_1 j_2 \dots j_q} = T(x^{i_1},\dots,x^{i_p},e_{j_1},\dots,e_{j_q}) \]
 
We write integrals using $\int$ and fractions using $\frac{a}{b}$. Limits are placed on integrals using superscripts and subscripts:

\[ \int_0^1 \frac{dx}{e^x} =  \frac{e-1}{e} \]

Lower case Greek letters are written as $\omega$ $\delta$ etc. while upper case Greek letters are written as $\Omega$ $\Delta$.

Mathematical operators are prefixed with a backslash as $\sin(\beta)$, $\cos(\alpha)$, $\log(x)$ etc.
\end{document}
```

### 문단과 줄바꿈

초록을 작성했으니 이제 첫 문단을 쓸 수 있습니다. 다음 예시는 다음 내용을 보여 줍니다.

```latex
\end{abstract}

This line will start a second paragraph.

I will start the third paragraph and then add \\ a manual line break which causes this text to start on a new line but remains part of the same paragraph. Alternatively, I can use the \verb|\newline|\newline command to start a new line, which is also part of the same paragraph.
```

* LaTeX Error: There's no line here to end — `\\` 사용에 대한 추가 조언과 안내를 제공합니다.

### 장과 절

어떤 작성 소프트웨어를 사용하든 긴 문서는 보통 부, 장, 절, 소절 등으로 나뉩니다. LaTeX도 문서 구조화 명령을 제공하지만, 사용할 수 있는 명령과 그 구현(동작 방식)은 사용하는 문서 클래스에 따라 달라질 수 있습니다. 예를 들어 `book` 클래스로 만든 문서는 부, 장, 절, 소절 등으로 나눌 수 있지만, `letter` 클래스는 이를 위한 명령을 제공(지원)하지 않습니다.

다음 예시는 `book` 클래스 기반 문서를 구조화하는 데 사용하는 명령을 보여 줍니다.

```latex
\documentclass{book}
\begin{document}

\chapter{First Chapter}

\section{Introduction}

This is the first section.

Lorem  ipsum  dolor  sit  amet,  consectetuer  adipiscing  
elit. Etiam  lobortisfacilisis sem.  Nullam nec mi et 
neque pharetra sollicitudin.  Praesent imperdietmi nec ante. 
Donec ullamcorper, felis non sodales...

\section{Second Section}

Lorem ipsum dolor sit amet, consectetuer adipiscing elit.  
Etiam lobortis facilisissem.  Nullam nec mi et neque pharetra 
sollicitudin.  Praesent imperdiet mi necante...

\subsection{First Subsection}
Praesent imperdietmi nec ante. Donec ullamcorper, felis non sodales...

\section*{Unnumbered Section}
Lorem ipsum dolor sit amet, consectetuer adipiscing elit.  
Etiam lobortis facilisissem...
\end{document}
```

구획 명령의 이름은 대부분 이름만 봐도 의미를 알 수 있습니다. 예를 들어 `\chapter{First Chapter}`는 `First Chapter`라는 제목의 새 장을 만들고, `\section{Introduction}`은 `Introduction`이라는 제목의 절을 만듭니다. 절은 다시 `\subsection{...}`, 나아가 `\subsubsection{...}`으로 나눌 수 있습니다. 절, 소절 등의 번호는 자동으로 매겨지지만, `\section*{...}`, `\subsection*{...}`처럼 끝에 별표(\*)가 붙은 이른바 _별표 버전_ 명령을 사용하면 번호를 끌 수 있습니다.

LaTeX 문서 클래스들은 _전체적으로_ 다음과 같은 구획 명령을 제공하며, 각 클래스는 그중 관련된 일부를 지원합니다.

* `\part{part}`
* `\chapter{chapter}`
* `\section{section}`
* `\subsection{subsection}`
* `\subsubsection{subsubsection}`
* `\paragraph{paragraph}`
* `\subparagraph{subparagraph}`

특히 `\part`와 `\chapter` 명령은 `report`와 `book` 문서 클래스에서만 사용할 수 있습니다.

### 테두리 추가하기

`tabular` 환경은 표의 일부로 가로선과 세로선(rule)을 지원합니다.

* 행의 위아래에 가로선을 추가하려면 `\hline` 명령을 사용합니다.
* 열 사이에 세로선을 추가하려면 세로선 매개변수 `|`를 사용합니다.

이 예시에서 인수는 `{|c|c|c|}`로, 세로선으로 구분된 (가운데 정렬) 열 세 개를 선언합니다. 또한 `\hline`을 사용해 첫 번째 행 위와 마지막 행 아래에 가로선을 넣습니다.

```latex
\begin{center}
\begin{tabular}{|c|c|c|} 
 \hline
 cell1 & cell2 & cell3 \\ 
 cell4 & cell5 & cell6 \\ 
 cell7 & cell8 & cell9 \\ 
 \hline
\end{tabular}
\end{center}
```

### 캡션, 레이블, 참조

표에도 이미지와 거의 같은 방식으로 캡션을 달고 참조할 수 있습니다. 유일한 차이점은 **`figure`** 환경 대신 **`table`** 환경을 사용한다는 것입니다.

```latex
 1 & 6 & 87837 & 787 \\ 
 2 & 7 & 78 & 5415 \\
 3 & 545 & 778 & 7507 \\
 4 & 545 & 18744 & 7560 \\
 5 & 88 & 788 & 6344 \\ [1ex] 
 \hline
\end{tabular}

\end{table}
```

## LaTeX 패키지 찾기 및 사용하기

LaTeX는 강력한 조판 기능을 제공할 뿐만 아니라, 추가 _패키지_를 통한 _확장 프레임워크_도 제공합니다. LaTeX는 "모든 것을 다 하려는" 명령과 기능을 제공하는 대신 _확장 가능_하도록 설계되어, 사용자가 더 전문적인 조판 기능을 제공하거나 표 조판 같은 LaTeX의 내장 기능을 확장하는 외부 코드 묶음(패키지)을 불러올 수 있습니다. [이미지 추가하기](/ko/texlive/latex-basics/learn-latex-in-30-minutes#Adding%5Fimages) 섹션에서 보았듯이 `graphicx` 패키지는 그래픽 파일을 가져오는 명령을 제공해 LaTeX를 확장하며, (프리앰블에) 다음과 같이 작성해 불러왔습니다.

```latex
\usepackage{graphicx}
```

### 패키지 불러오기

앞서 언급했듯이 패키지는 문서 프리앰블에서 `\usepackage` 명령으로 불러옵니다. 그런데 (많은) LaTeX 패키지는 동작을 구성하는 데 사용할 수 있는 _옵션_ 집합을 제공하므로, `\usepackage` 명령은 흔히 다음과 같은 형태가 됩니다.

```latex
\usepackage[options]{somepackage}
```

대괄호 "`[...]`"는 `somepackage`를 불러올 때 어떤 옵션 집합을 적용해야 하는지 LaTeX에 알려 줍니다. 사용자가 요청한 옵션 집합 안에서 개별 옵션이나 설정은 보통 쉼표로 구분합니다. 예를 들어 [geometry 패키지](https://ctan.org/pkg/geometry)는 LaTeX의 페이지 레이아웃을 구성하는 다양한 옵션을 제공하므로, `geometry`의 일반적인 사용 예는 다음과 같습니다.

```latex
\usepackage[total={6.5in,8.75in},
top=1.2in, left=0.9in, includefoot]{geometry}
```

`geometry` 패키지는 전 세계 LaTeX 커뮤니티 구성원이 작성하고 기여하여 누구나 무료로 사용할 수 있도록 제공되는 패키지의 한 예입니다.

LaTeX 패키지가 옵션을 제공하지 않거나 사용자가 패키지 옵션의 기본값을 사용하려는 경우에는 다음과 같이 불러옵니다.

```latex
\usepackage{somepackage}
```

`\usepackage[...]{somepackage}`라고 작성하면 LaTeX는 이에 해당하는 `_somepackage_.sty`라는 파일을 찾아 불러오고 처리합니다. 이를 통해 패키지 명령을 사용할 수 있게 되고 패키지가 제공하는 다른 코드도 실행됩니다. LaTeX가 `_somepackage_.sty`를 찾지 못하면 다음 Overleaf 예시처럼 오류와 함께 종료됩니다.

```latex
\documentclass[12pt, letterpaper]{article}
\usepackage{somepackage}% a NON-EXISTENT package
\begin{document}
This will fail!
\end{document}
```

### 패키지 정보 찾기: CTAN

패키지는 흔히 CTAN이라고 부르는 [Comprehensive TeX Archive Network](https://www.ctan.org/)를 통해 배포되며, 이 글을 작성하는 시점에 2881명의 기여자가 만든 6287개의 패키지를 호스팅하고 있습니다. CTAN은 [스스로를](https://www.ctan.org/ctan) 다음과 같이 설명합니다.

> ... TEX 관련 자료를 다운로드할 수 있도록 제공하는 전 세계의 인터넷 사이트 모음.

### Overleaf에서 사용할 수 있는 패키지: TeX Live 소개

매년 한 번씩 CTAN에 호스팅된 패키지의 (상당히 큰) _일부_와 LaTeX 관련 글꼴 및 기타 소프트웨어를 모아 [TeX Live](https://tug.org/texlive/)라는 시스템으로 배포하며, 이를 사용해 자신만의 (로컬) LaTeX 환경을 설치할 수 있습니다. 실제로 [Overleaf 서버도 TeX Live를 사용하며](https://www.overleaf.com/learn/latex/Overleaf_and_TeX_Live), 새 버전의 TeX Live가 릴리스되면 업데이트됩니다. Overleaf의 TeX Live 업데이트는 즉시 이루어지지 않고 릴리스 후 몇 달 뒤에 진행됩니다. 그 기간 동안 새 TeX Live 버전과 [갤러리에 있는 수천 개의 템플릿](https://www.overleaf.com/gallery) 간의 호환성 테스트를 수행합니다. 예를 들어 [TeX Live 2025 업그레이드 공지](https://www.overleaf.com/blog/tex-live-2025-is-now-available)를 참조하세요.

TeX Live에는 CTAN 패키지의 (상당히 큰) _일부_가 포함되어 있지만, [바둑 기보를 조판하는 igo](https://ctan.org/pkg/igo?lang=en)처럼 CTAN에는 호스팅되어 있으나 TeX Live에는 포함되지(배포되지) 않아 Overleaf에서 사용할 수 없는 흥미로운 패키지를 발견할 수도 있습니다. CTAN에 호스팅된 일부 패키지가 TeX Live에 포함되지 않는 이유는 다양합니다. 패키지가 더 이상 사용되지 않거나, 라이선스 문제가 있거나, 아주 최근에 업로드되었거나, Windows에서는 작동하지만 Linux에서는 작동하지 않는 등 플랫폼에 의존하기 때문일 수 있습니다.

새 패키지와 기존 패키지의 업데이트는 연중 내내 CTAN에 업로드되지만, TeX Live 업데이트는 매년 배포됩니다. 따라서 현재 버전의 TeX Live에 포함된 패키지는 CTAN에 호스팅된 패키지만큼 최신이 아닐 수 있습니다. Overleaf 서버는 TeX Live를 사용하므로 서버에 설치된 패키지, 즉 사용자가 사용할 수 있는 패키지가 CTAN에서 제공되는 최신 버전이 아닐 수도 있지만, 일반적으로 이것이 문제가 될 가능성은 낮습니다.
