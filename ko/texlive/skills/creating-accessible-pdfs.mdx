title: 접근성 있는 PDF 만들기
icon: universal-access

시간이 지나면서 PDF 생성 기능이 개선되어 PDF 접근성을 확보할 수 있게 되었습니다. [LaTeX Tagging Project](https://latex3.github.io/tagging-project/documentation/)를 비롯한 진전 덕분에 LaTeX 기반 PDF도 접근성을 갖출 수 있게 되었으며, 개선은 계속 이루어지고 있습니다.

<Check>

특히 [TeX Live 2025](https://www.overleaf.com/blog/tex-live-2025-is-now-available)의 출시 덕분에 Overleaf에서 이 과정이 가능해졌습니다. MathML을 사용할 때는 **LuaLaTeX**가 권장 컴파일러라는 점에 유의하십시오.

[컴파일러와 TeX Live 버전을 변경하는 방법](https://docs.overleaf.com/getting-started/recompiling-your-project/selecting-a-tex-live-version-and-latex-compiler)을 알아보고 프로젝트 설정이 이에 맞게 구성되어 있는지 확인할 수 있습니다.

</Check>

저희의 접근 방식은 주로 LaTeX Project의 [접근성 있는 PDF 안내](https://latex3.github.io/tagging-project/documentation/usage-instructions)를 바탕으로 하며, 다음 주제에 대한 자세한 내용은 해당 문서를 참조할 수 있습니다.

<Warning>

이러한 방법을 적용한다고 해서 프로젝트의 모든 요소가 접근성을 갖춘다는 보장은 없다는 점에 유의하십시오. 자세한 내용은 이 페이지의 FAQ 섹션을 참조하십시오.

</Warning>

### <Icon icon="tag" /> 태깅

본질적으로 PDF 태깅은 화면 판독기가 쉽게 식별할 수 있고 현재와 미래 모두에서 더 잘 검색되는 "구조"를 자동으로 생성하는 과정입니다. LaTeX 코드에 정의된 기존 구조를 활용하므로 화면 판독기가 제목, 본문 텍스트, 그림, 수식 등의 요소를 구별할 수 있습니다.

TeX Live 2025는 `\DocumentMetaData` 선언을 통한 자동 PDF 태그를 완전히 지원합니다. 이 선언을 `\documentclass` 앞에 추가하십시오. 이 선언에는 태깅 기능에 영향을 주는 두 가지 중요한 키 `tagging`과 `tagging-setup`이 있습니다.

#### **`tagging`**

`tagging` 키를 `on`으로 설정하여 태깅이 활성화되도록 합니다.

```latex wrap expandable
\DocumentMetadata{tagging=on}
```

#### **`tagging-setup`**

`tagging-setup` 키의 값을 변경하여 문서의 태깅 방식을 구성합니다.

```latex wrap expandable
\DocumentMetadata{tagging=on,tagging-setup={math/setup=mathml-SE}}
```

<Info>

이 예시에서는 MathML Structure Element 태깅을 위해 \`math/setup=mathml-SE\`를 사용했지만, \[\`\tagpdfsetup\`]\(https://ctan.math.washington.edu/tex-archive/macros/latex/contrib/tagpdf/tagpdf.pdf)이 지원하는 어떤 값으로도 설정할 수 있습니다.

</Info>

### <Icon icon="text-size" /> 설명

자동 태깅 외에도, 특히 문서에 이미지나 표가 포함된 경우 요소의 내용에 대한 설명을 추가해야 할 수도 있습니다.

#### <Icon icon="image" /> 이미지

Overleaf에서는 이미지에 필수 설명을 간단히 추가할 수 있으며, 이는 LaTeX 코드를 참조할 때 특정 이미지의 맥락을 이해하는 데에도 도움이 됩니다. `\includegraphics`의 각 인스턴스에 해당 이미지 설명 옵션을 추가하기만 하면 됩니다. 접근성을 위해 구별해야 할 이미지는 크게 세 가지 유형이 있습니다: 대체(alt) 텍스트가 필요한 이미지, 아티팩트, 실제 텍스트로 변환되는 이미지입니다.

**대체 텍스트**

이미지에 대체 텍스트를 추가하면 시각 자료를 대신하는 텍스트 기반 설명을 사진에 제공할 수 있습니다. `alt` 키를 사용하고 텍스트 값을 입력하십시오.

```latex title="Alt text example" wrap
\includegraphics[width=0.25\linewidth,alt={Macro photo of a green frog's head and hands}]{frog.jpg}
```

**아티팩트**

화면 판독기가 이미지를 읽을 필요가 없는 경우(즉, 순전히 장식용인 경우) 이미지를 아티팩트로 표시하십시오. 값을 지정하지 않고 `artifact` 키를 사용합니다.

```latex title="Artifact example" wrap
\includegraphics[artifact]{.jpg}
```

**실제 텍스트**

이미지가 Unicode 문자 하나만을 나타내는 그림이라면 텍스트 기반 문자를 포함하십시오. `actualtext` 키를 사용하고 단일 문자를 (괄호 없이) 지정합니다.

```latex title="Actual text example" wrap
\includegraphics[actualtext=B]{.jpg}
```

#### <Icon icon="table" /> 표

표에는 대개 텍스트가 함께 있지만, 그 텍스트가 표의 올바른 부분과 연결되는 것이 여전히 중요합니다. Overleaf 프로젝트의 표 설정을 시작하려면 `tabular` 앞이나 프리앰블에 `\tagpdfsetup`을 추가하십시오. 접근성을 위해 구별해야 할 표는 크게 두 가지 유형이 있습니다: 데이터 표와 프레젠테이션 표입니다.

**데이터 표**

표에 헤더 행이 하나 이상 있는 경우 어떤 행이 헤더 행인지 지정하십시오. `table/header-rows` 키를 사용하고 헤더 행의 위치에 해당하는 일련의 숫자를 입력합니다.

```latex title="Data table example"
\tagpdfsetup{table/header-rows={1}}
\begin{tabular}{l|r}
Item & Quantity \\\hline
Widgets & 42 \\
Gadgets & 13
\end{tabular}
```

**프레젠테이션 표**

화면 판독기가 표를 표로 해석하지 않아야 하는 경우 프레젠테이션 표로 표시하십시오. `table/tagging=presentation` 키를 사용합니다.

```latex title="Presentation table example"
\tagpdfsetup{table/tagging=presentation}
\begin{tabular}{cc}
\textbullet & \textbullet \\
''' & '''
\end{tabular}
```

### <Icon icon="comments-question" /> FAQ

<Accordion title="문서의 접근성을 검증하는 데 도움이 되는 도구가 있나요?">

네, [veraPDF](https://verapdf.org/)를 비롯해 PDF/A 파트와 준수 수준을 검증할 수 있는 여러 외부 도구가 있습니다. 또한 [WebAIM](https://webaim.org/)과 같은 도구를 사용해 두 색상 간의 명암비를 계산할 수 있습니다.

</Accordion>

<Accordion title="제 Overleaf 프로젝트의 패키지가 이러한 기능과 호환되나요?">

LaTeX Tagging Project의 [패키지 상태 목록](https://latex3.github.io/tagging-project/tagging-status/)을 참조할 수 있습니다.

</Accordion>

<Accordion title="여전히 `beamer`를 사용할 수 있나요? 프레젠테이션용으로 사용할 수 있는 다른 패키지가 있나요?">

`beamer` 사용에는 제약이 있습니다. 실험적인 [`ltx-talk` 클래스](https://ctan.org/pkg/ltx-talk)를 확인해 보십시오.

</Accordion>

<Accordion title="Overleaf 에디터는 접근성을 갖추고 있나요?">

네. 웹 애플리케이션인 Overleaf는 접근성 전문가가 정기적으로 평가하는 최신 웹 브라우저의 접근성 기능을 활용합니다. 가장 최근에 완료된 [Voluntary Product Accessibility Template (VPAT)](https://www.overleaf.com/for/customers/vpat)은 Web Content Accessibility Guidelines (WCAG) 2.2 Level AA 준수를 보여 줍니다.

</Accordion>

<Accordion title="Overleaf에서 생성한 PDF가 미국 장애인법(ADA) Title II와 유럽 접근성 통합 표준(EN 301 549)의 요구 사항을 충족할 수 있나요?">

네. 미국과 유럽의 법률은 PDF가 WCAG 2.1 AA를 충족하도록 요구합니다. WCAG 2.1 AA를 충족하려면 PDF가 태그된 PDF여야 합니다. PDF 태깅 지원은 TeX Live 2025에서 제공됩니다.

</Accordion>

<Accordion title="Overleaf에서 생성한 PDF가 PDF/UA-1 표준을 충족할 수 있나요?">

네. LaTeX Project의 Tagging Project는 PDF/UA-1(및 향후 출시될 PDF/UA-2)에서 요구하는 구조 태그를 생성하도록 특별히 설계되었습니다. 사용자가 LaTeX Project의 현재 태깅 권장 사항을 따르면 사실상 "PDF/UA 대응" 문서를 작성하게 되며, 이는 미국과 유럽 법률에서 요구하는 WCAG 2.1 AA 법적 의무를 충족하는 가장 확실한 방법입니다.

</Accordion>

<Accordion title="컴파일러를 LuaLaTeX로 전환하려면 어떻게 하나요?">

LaTeX 태깅 프로젝트 팀이 권장하는 LaTeX 컴파일 엔진인 LuaLaTeX로 쉽게 전환할 수 있습니다. Overleaf의 기본 컴파일러는 PDFLaTeX이지만 [프로젝트 설정에서 LuaLaTeX로 전환](https://docs.overleaf.com/getting-started/recompiling-your-project/selecting-a-tex-live-version-and-latex-compiler)할 수 있습니다.

</Accordion>

<Accordion title="최신 버전의 TeX Live는 어디에서 선택할 수 있나요?">

[Overleaf Labs](https://www.overleaf.com/labs/participate)에서 최신 버전을 사용할 수 있으며, 여기에서 최신 PDF 태깅 지원을 포함한 Overleaf의 "rolling TeX Live" 이미지에 접근할 수 있습니다. 이 실험적인 TeX Live 버전은 주로 TeX Live와 패키지의 변경 사항을 테스트하고, 연례 TeX Live 릴리스에 반영되기 전에 새로운 접근성 기능을 미리 보기 위한 것입니다.

대부분의 PDF 태깅 기능은 표준 [TeX Live 2025](https://www.overleaf.com/blog/tex-live-2025-is-now-available) 이미지에서 사용할 수 있습니다.

</Accordion>

[^1]: 자동 태깅이 활성화되어 있습니다.

[^2]: 태깅 구성이 설정되어 있습니다.

[^3]: 이미지에 대체 텍스트가 있습니다.

[^4]: 이미지가 아티팩트입니다.

[^5]: 이미지가 문자입니다.

[^6]: 표에 헤더 행이 하나 있습니다.

[^7]: 표가 프레젠테이션 표입니다.
