[TeX Live](https://www.tug.org/texlive/)는 [TeX Users Group](https://www.tug.org/)이 매년 배포하는 자유 소프트웨어 배포판입니다. 모든 주요 운영 체제에서 LaTeX 기반 조판을 지원하는 데 필요한 LaTeX 패키지, 글꼴, TeX 엔진 및 다양한 소프트웨어 도구를 제공합니다.

TeX Live는 Overleaf의 중요한 구성 요소입니다. Overleaf 서버는 TeX Live를 사용해 LaTeX 코드를 컴파일하고 실시간 PDF 미리보기를 생성하기 때문입니다. 또한 Overleaf 사용자는 각 TeX Live 릴리스에 포함된 5,000개 이상의 LaTeX 패키지를 손쉽게 사용할 수 있습니다.

Overleaf 서버는 이전 TeX Live 릴리스도 제공하므로, 프로젝트를 반드시 최신 버전의 TeX Live로 컴파일할 필요는 없습니다. 예를 들어 패키지 호환성 문제가 있을 때 프로젝트가 이전 버전의 TeX Live를 사용하도록 쉽게 전환할 수 있습니다.<br />
