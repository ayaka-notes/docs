### Overleaf 개요

Overleaf는 연구자와 기술 팀이 애용하는 협업 LaTeX 편집기입니다. 클라우드 버전은 [overleaf.com](https://www.overleaf.com/)에서 이용할 수 있으며, 모든 기능을 갖춘 온라인 LaTeX 편집기를 제공합니다. 하지만 Overleaf Common(SaaS 버전)에는 수많은 기능 제한이 있으며, _**10초 컴파일 시간 제한**_과 비싼 멤버십 요금을 감수해야 합니다.

Overleaf는 오픈 소스 커뮤니티 버전([GitHub: Overleaf](https://github.com/overleaf/overleaf)에서 이용 가능)도 제공하지만, 이 역시 다음과 같은 많은 제한이 있습니다:

<Warning>

Overleaf Community Edition은 **모든** 사용자를 신뢰할 수 있는 환경에서 사용하도록 만들어졌습니다. Sandbox Compiles를 사용할 수 없기 때문에 Community Edition은 사용자 격리가 필요한 상황에는 적합하지 **않습니다**.

샌드박스 없이 실행되는 LaTeX 컴파일은 컨테이너와 동일한 권한으로 실행되므로, 컨테이너의 파일 시스템, 네트워크, 환경 변수에 접근할 수 있습니다. 이는 데이터 노출이나 시스템 침해의 위험을 초래합니다. 샌드박스가 없는 컴파일은 완전히 신뢰할 수 있는 환경에서만 사용해야 하며, 다중 사용자 또는 프로덕션 배포에서는 Sandbox Compiles를 강력히 권장합니다.

Sandbox Compiles에 대한 자세한 내용은 다음을 참고하세요: [sandboxed-compiles.md](/ko/on-premises/configuration/overleaf-toolkit/sandboxed-compiles  "mention")

</Warning>

### Overleaf Server Pro 정보 및 가격

Overleaf 웹사이트는 Server Pro에 대해 지원팀 문의 창구만 제공하므로 Server Pro에 관한 정보는 매우 제한적입니다. 하지만 커뮤니티에서 수집한 정보에 따르면 **Server Pro의 견적**은 다음과 같습니다:

* _최소_ 10명분의 라이선스를 구매해야 합니다.
* 10인 라이선스 가격은 약 €3,477.61입니다. (2024년)
* 교육용의 경우 연간 20명 2640유로, 50명 6050유로, 100명 9963유로입니다.
* Server Pro는 일부 지역에서만 이용할 수 있습니다(예: 중국 본토 제외).

현재 확인 가능한 정보에 따르면 Overleaf Server Pro는 사용자 1인당 연간 약 \$300이며 최소 10개 라이선스를 구매해야 하므로 매우 비싼 선택지입니다. 게다가 Server Pro는 Ayakaleaf Pro보다 기능이 훨씬 적습니다. 수년간 기여해 주신 커뮤니티 개발자분들 덕분에 Ayakaleaf Pro를 만들고 기능과 성능 모두에서 Overleaf Server Pro를 넘어설 수 있었습니다. 깊이 감사드립니다.

다음 공개 기록은 문서로 확인된 Overleaf Server Pro 구매 내역과 가격을 보여 줍니다. 소규모 미국 계약에서는 사용자 1인당 연간 약 \$320–\$370의 비용이 나타납니다. 대규모 기관 계약에서는 1인당 가격이 더 낮을 수 있습니다. 예를 들어 막스 플랑크 협회(Max Planck Society)의 3년 계약은 연간 사용자 1인당 평균 약 €51입니다. 계약 조건, 지원, 배포 범위는 다를 수 있습니다. 이 기록은 Overleaf의 공식 가격표가 아닙니다.

### 왜 Ayakaleaf Pro인가?

<Info>

Ayakaleaf Pro는 Overleaf, Inc. 또는 그 모회사인 Digital Science와 _**아무런**_ 관련이 없습니다. 또한 Overleaf, Inc.가 제공하는 상용 제품인 _Server Pro_ 에디션도 _아닙니다_. [ayaka-notes](https://github.com/ayaka-notes)가 독립 프로젝트로 Ayakaleaf Pro를 개발하고 유지 관리합니다.

</Info>

Ayakaleaf Pro는 Overleaf Community Edition의 강화된 구현으로, Server Pro의 _**모든**_ 기능을 _**무료 프리미엄**_ 기능으로 제공합니다. [https://www.overleaf.com/](https://www.overleaf.com/)에서 제공되는 Overleaf Common이나 상용 에디션인 Server Pro와 달리, Ayakaleaf Pro는

* 컴파일 시간에 _**제한이 없습니다**_
* 사용자 수에 대한 _**라이선스**_ 요구 사항이 _**없습니다**_
* Server Pro의 _**모든 기능**_이 잠금 해제되어 있습니다
