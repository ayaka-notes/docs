## Ayakaleaf Pro 6.3.0

**릴리스 날짜:** 2026.10.03(재릴리스, 최초 릴리스는 2026.09.24)

참조: [https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.3.0](https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.3.0)

<Warning>

Ayakaleaf Pro 6.3.0은 2026년 9월 24일에 처음 릴리스되었습니다. 이번 재릴리스는 업스트림 업데이트로 인해 발생한 AI 어시스턴트, Zotero 및 Mendeley 연동 문제를 해결합니다.

이전에 릴리스된 버전은 데이터를 손상시키지 않습니다. 최신 `6.3.0` 이미지를 pull하고 배포를 업그레이드하세요. **Zotero 또는 Mendeley로 연결된 참고 문헌 파일이 있는 기존 설치에서는 아래 마이그레이션도 실행해야 합니다.** 신규 설치에서는 이 마이그레이션이 필요하지 않습니다.

</Warning>

<Accordion title="기존 설치를 위한 Zotero / Mendeley 마이그레이션">

재릴리스된 6.3.0 이미지로 업그레이드할 때는 아래 스크립트를 사용하여 기존 Zotero/Mendeley 연결 참고 문헌 메타데이터를 마이그레이션하세요. 이 마이그레이션은 수정 사항 `12031b8dfd`와 함께 제공됩니다.

이 마이그레이션은 `zoteroGroupId` / `mendeleyGroupId`를 `group_id`로, `importedByUserId`를 `importer_id`로 이름을 바꾸고 `importedByName`을 제거합니다.

마이그레이션을 실행하기 전에 MongoDB를 백업하고 애플리케이션을 중지하세요. MongoDB는 실행 상태로 유지합니다. MongoDB 셸을 엽니다(`mongo`를 사용 중인 컨테이너 이름으로 바꾸세요):

```bash
docker exec -it mongo mongosh
```

`mongosh`에서 다음을 실행합니다(`sharelatex`를 사용 중인 데이터베이스 이름으로 바꾸세요):

```javascript
use sharelatex

(async () => {
  let updated = 0
  await db.projects.find({}, { rootFolder: 1 }).forEach(async project => {
    const changes = {}
    function visit(folders, path) {
      for (const [i, folder] of (folders || []).entries()) {
        const folderPath = `${path}.${i}`
        for (const [j, file] of (folder.fileRefs || []).entries()) {
          const data = { ...file.linkedFileData }
          if (!["zotero", "mendeley"].includes(data.provider)) continue
          const groupKey = `${data.provider}GroupId`
          if (![groupKey, "importedByUserId", "importedByName"].some(key => key in data)) continue
          for (const [oldKey, newKey] of [[groupKey, "group_id"], ["importedByUserId", "importer_id"]]) {
            if (data[oldKey] != null && data[oldKey] !== "") {
              const value = String(data[oldKey])
              if (newKey in data && data[newKey] !== value) {
                throw new Error(`Conflicting ${newKey}: project ${project._id}, file ${file._id}`)
              }
              data[newKey] = value
            }
            delete data[oldKey]
          }
          delete data.importedByName
          changes[`${folderPath}.fileRefs.${j}.linkedFileData`] = data
        }
        visit(folder.folders, `${folderPath}.folders`)
      }
    }
    visit(project.rootFolder, "rootFolder")
    if (!Object.keys(changes).length) return
    const result = await db.projects.updateOne(
      { _id: project._id, rootFolder: { $eq: project.rootFolder } },
      { $set: changes }
    )
    if (!result.matchedCount) throw new Error(`Project changed during migration: ${project._id}`)
    updated += result.modifiedCount
  })
  print(`Updated ${updated} project(s).`)
})()
```

이 스크립트는 중첩된 폴더까지 처리하며 Zotero/Mendeley 메타데이터만 변경합니다. 다시 실행해도 안전합니다. 마이그레이션이 완료된 경우 다음 실행 시 `Updated 0 project(s).`가 출력됩니다. 충돌로 인해 중지되면 보고된 프로젝트/파일을 확인하세요. 그 이전의 프로젝트는 이미 마이그레이션되었을 수 있습니다.

업데이트된 애플리케이션을 시작하고 편집기를 새로고침한 다음, 원래 가져온 사용자로 기존 참고 문헌 파일을 새로고침하세요. 과거 스냅샷은 다시 작성되지 않습니다. 이전 애플리케이션으로 다운그레이드하려면 MongoDB 백업을 복원하세요.

</Accordion>

커뮤니티에서 가장 강력하고 기능이 풍부한 온라인 LaTeX 편집기인 Overleaf Pro 6.3.0의 릴리스를 발표하게 되어 매우 자랑스럽습니다. 저희는 항상 사용자 경험 개선에 집중해 왔으며, 이번 릴리스에는 AI 어시스턴트와 서드파티 참고 문헌 연동을 포함하여 분명 마음에 드실 큰 변화와 멋진 기능이 담겨 있습니다.

### 변경 사항

* AI 채팅 어시스턴트: 자체 제공업체를 통해 편집기 안에서 바로 AI 모델과 채팅할 수 있습니다.
* LaTeX 오류 어시스턴트: LaTeX 컴파일 오류에 대해 AI가 제안하는 수정 방법을 받을 수 있습니다.
* Mendeley 연동: Zotero와 비슷하게 Mendeley에서 참고 문헌을 가져올 수 있습니다.
* Open in Overleaf API: Overleaf에서 콘텐츠를 열기 위한 API를 추가했습니다.
* 템플릿 갤러리: 서버 측 페이지 매김, 검색 및 정렬을 추가하여 대규모 갤러리에서 더 이상 모든 템플릿을 브라우저에서 불러올 필요가 없습니다.
* 번역: 지원되는 언어 전반의 새 인터페이스 텍스트를 포함하여 6.3.0용 번역 패치를 업데이트했습니다.
* 업스트림 Overleaf 6.3.0: 탭 방식 파일 편집, 라이트 및 다크 테마용 별도 헤더 로고, 종속성 및 기본 이미지 업데이트가 포함됩니다.
* 라이트 및 다크 테마에 서로 다른 헤더 로고 이미지를 지원하도록 `OVERLEAF_HEADER_IMAGE_URL_LIGHT` 및 `OVERLEAF_HEADER_IMAGE_URL_DARK`를 추가했습니다.
* 이제 편집기에서 파일을 여러 탭으로 열 수 있습니다.
* `OVERLEAF_LINKED_URL_OUTBOUND_PROXY`를 통해 로컬 호스팅 프록시를 포함한 구성 가능한 HTTP(S) 프록시 지원을 추가했으며, 이는 Open in Overleaf API에서도 사용됩니다.

#### 기능 04: 템플릿 페이지 매김

이제 갤러리는 MongoDB에서 페이지 매김, 정렬 및 검색을 수행합니다. 별도의 준비 없이 작동하지만, 템플릿이 수천 개라면 빠른 속도를 유지하기 위해 다음 인덱스를 추가할 수 있습니다(다시 실행해도 안전하며, `mongo`/`sharelatex`는 사용 중인 컨테이너 및 데이터베이스 이름입니다):

```bash
docker exec mongo mongosh sharelatex --quiet --eval '
db.templates.createIndex({category:1,lastUpdated:-1},{name:"category_1_lastUpdated_-1",background:true});
db.templates.createIndex({lastUpdated:-1},{name:"lastUpdated_-1",background:true});
db.templates.createIndex({category:1,name:1},{name:"category_1_name_1_ci",collation:{locale:"en",strength:2},background:true});
db.templates.createIndex({name:1},{name:"name_1_ci",collation:{locale:"en",strength:2},background:true});
'
```

두 `*_ci` 인덱스의 `collation`은 작성된 그대로 유지하세요. 갤러리는 동일한 collation으로 쿼리하며, MongoDB는 일치하는 인덱스만 사용합니다.

## Ayakaleaf Pro 6.2.2

**릴리스 날짜:** 2026.07.23

참조: [https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.2](https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.2)

### 변경 사항

업스트림 Overleaf `6.2.2`에 포함된 공식 핫픽스 패치를 (`6.2.1` 위에) 백포트했습니다:

* 프로젝트 초대 토큰 시크릿이 로그에 유출되지 않도록 수정했습니다. 초대 토큰 암호화기가 암호화/복호화할 때마다 자체 구성을 로그에 기록했는데, 여기에는 `OVERLEAF_INVITE_TOKEN_SECRET`에서 파생된 암호 비밀번호가 포함되어 있었습니다.
* 발신 이메일을 지원 종료된 AWS SES v1 클라이언트에서 SESv2로 마이그레이션했습니다. `ses` 이메일 드라이버로 구성된 인스턴스는 이메일을 전혀 보내지 못할 수 있었으나, 이제는 `SESv2Client`를 통해 전송됩니다.
* 프로젝트 공유 드롭다운의 그룹 항목을 새로운 `group-link-sharing` 기능 플래그로 제어하도록 하여, 해당되지 않는 인스턴스에서는 더 이상 그룹 링크 공유가 제공되지 않습니다.
* 공동 작업자의 프로젝트 공유 모달을 수정했습니다. 소유자가 아닌 사용자로 열거나 `sharing-updates` 흐름이 비활성화된 상태에서 열면 항상 실패하는 요청이 발생하여 "something went wrong" 오류가 표시되었습니다.
* document-updater에 `scripts/flush_docs_with_pending_updates.js`를 추가했습니다. 이 유지 관리 스크립트는 프로젝트가 플러시되거나 영구 삭제된 후 Redis에 `PendingUpdates` 대기열이 멈춘 채로 남은 문서를 복구합니다. `--dry-run` 및 `--estimated-docs` 안전 검사를 지원합니다.
* 종속성 업데이트: `multer` 2.2.0, `form-data` 2.5.6, `protobufjs` 7.6.3, `@grpc/grpc-js` 1.14.4.

이번 릴리스에는 Ayakaleaf Pro의 다음 수정 및 개선 사항도 포함되어 있습니다:

* 16개 언어(cs, da, de, es, fi, fr, it, ja, ko, nl, no, pl, pt, ru, sv, tr)에 대한 전체 번역을 추가하여 비밀번호 재설정 페이지 등 번역되지 않은 문자열을 수정했습니다. [#38](https://github.com/ayaka-notes/ayakaleaf-pro/issues/38)을 수정합니다.
* 관리 패널의 "show N more projects" 버튼에서 복수형 자리 표시자가 올바르게 전달되지 않아 잘못된 숫자가 표시되던 항목 수를 수정했습니다.
* GitHub 내보내기 유효성 검사 오류를 수정했습니다. 이제 원시 메시지 대신 정적 i18n 키를 통해 렌더링되며, GitHub Sync 모달에서 더 이상 사용하지 않는 오류 키를 제거했습니다.

## Ayakaleaf Pro 6.2.1

### 변경 사항

업스트림 Overleaf `6.2.1`에 포함된 공식 핫픽스 패치를 (`6.2.0` 위에) 백포트했습니다:

* 실시간 `applyOtUpdate` 메시지가 모든 객체를 허용하는 대신 엄격한 유효성 검사 스키마를 사용하도록 강화하여, 잘못된 형식의 편집 작업을 거부합니다.
* 해당 스키마를 완화하여 `meta.tc`를 선택 사항으로 만들었으므로, 유효한 업데이트가 더 엄격해진 유효성 검사에 의해 거부되지 않습니다.
* 편집기(ShareJS 클라이언트)를 수정하여 빈 작업으로 축소되는 작업(원격/동시 작업에 의해 상쇄되거나 실행 취소로 완전히 되돌려진 작업)은 서버로 전송되지 않고 버려지며, 문서가 올바르게 저장된 것으로 보고됩니다. 실행 취소 및 동시 편집과 관련된 잘못된 동기화 / "저장되지 않은 변경 사항" 문제를 방지합니다.

## Ayakaleaf Pro 6.2.0

**릴리스 날짜:** 2026.07.10

참조: [https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.0](https://github.com/ayaka-notes/ayakaleaf-pro/releases/tag/pro-v6.2.0)

커뮤니티에서 가장 강력하고 기능이 풍부한 온라인 LaTeX 편집기인 Overleaf Pro 6.2.0의 릴리스를 발표하게 되어 자랑스럽습니다. 귀중한 기여를 해 주신 yu-i-i와 davrot에게 특별히 감사드립니다. 이들은 GitHub Sync를 개선하고 고급 인용 검색과 Zotero 연동을 도입했습니다.

### 참고 사항

<Warning>

* 새로운 필수 환경 변수 `OVERLEAF_INVITE_TOKEN_SECRET`이 도입되었습니다. `openssl rand -base64 32`로 생성해야 합니다. 구성하지 않으면 Overleaf 인스턴스가 시작되지 않습니다.
* GitHub Sync를 활성화하는 경우 `GITHUB_TOKEN_CIPHER_PASSWORD` 환경 변수를 구성해야 합니다. 이 변수는 GitHub 액세스 토큰을 안전하게 암호화하는 데 필요합니다. 이 변수가 없으면 Overleaf 인스턴스가 시작되지 않습니다.

</Warning>

* 새 프로젝트에서 사용할 기본 컴파일러(`pdflatex`, `latex`, `xelatex` 또는 `lualatex`)를 설정하는 새로운 `DEFAULT_LATEX_COMPILER` 환경 변수를 추가했습니다.
* 이제 새롭게 디자인된 편집기만 사용할 수 있습니다.

### 변경 사항

이번 릴리스에는 다음과 같은 개선 사항과 새로운 기능이 포함되어 있습니다.

* `MAX_UPLOAD_SIZE`가 **50 MB**로 제한되는 대신 구성 가능해졌습니다.
* 샌드박스 컴파일이 비활성화되었을 때 컨테이너가 재시작을 반복하던 문제를 수정했습니다.
* OAuth2에서 소유자 범위로 제한된 PAT 삭제를 적용했습니다.
* LDAP 가져오기 문제를 수정했습니다.

기능은 다음과 같습니다:

* 브라우저 기반 Python 실행기를 추가했습니다.
* Markdown, DOCX 및 기타 형식의 가져오기/내보내기를 위한 Pandoc 지원을 추가했습니다.
* GitHub Sync를 추가했습니다.
* 완전한 중국어 번역을 추가했습니다.
* Zotero 연동을 추가했습니다.
* `DEFAULT_LATEX_COMPILER`를 추가했습니다.

현재 MongoDB `v6` 이하를 사용 중이라면 한 번에 하나의 메이저 버전씩(`v6 → v7 → v8`) 업데이트해야 합니다.

<Warning>

업그레이드하기 **전에** [데이터베이스](https://docs.overleaf.com/on-premises/maintenance/data-and-backups) 백업이 있는지 확인하세요. 롤백할 경우 데이터베이스 백업을 복원해야 합니다.

</Warning>

MongoDB `v6 → v7 → v8` 업그레이드 방법은 [여기](https://docs.overleaf.com/on-premises/maintenance/updating-mongodb#example-upgrading-mongodb-from-6.0-to-7.0-toolkit-users)의 단계별 가이드를 참조하세요.

* 링크가 포함된 푸터 렌더링을 수정했습니다.
* SAML 로그인 오류 시 오류 메시지를 개선했습니다.
* SSO 로그인 시 사용자의 관리자 상태가 업데이트될 때 감사 로그 항목이 추가되지 않던 문제를 수정했습니다.
* Redis에서 TLS가 활성화된 경우 기록 패널 오류를 수정했습니다.
* 이제 샌드박스가 아닌 컴파일을 사용할 때도 컴파일을 중지할 수 있습니다.

### 기타 변경 사항

* (`OVERLEAF_STATUS_PAGE_URL`로 설정된) 상태 페이지에 대한 모든 링크가 이제 `HTTPS`를 사용하며 새 브라우저 탭에서 열립니다.
