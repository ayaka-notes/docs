### Overleaf 버전 번호 이해하기

Overleaf는 **6.X.y** 형식의 시맨틱 스타일 버전 번호를 사용합니다.

* **6.X**는 메이저 릴리스 시리즈를 나타냅니다. 새로운 **6.X.0** 버전이 릴리스되면 해당 세대의 기준이 됩니다.
* **y**는 같은 메이저 시리즈 내의 패치 업데이트를 나타냅니다. 이후 릴리스(예: **6.X.1**, **6.X.2**, …)는 일반적으로 **6.X.0**을 기반으로 빌드된 유지보수 업데이트로, 대규모 기능 변경보다는 버그 수정, 보안 수정 및 소소한 개선 사항을 포함합니다.

### Ayakaleaf Pro 버전

Ayakaleaf Pro의 버전 번호는 공식 Overleaf 릴리스와 **완전히 일치**합니다. 별도로 명시되지 않는 한, 게시된 모든 릴리스는 전체 기능을 갖춘 Pro 에디션 이미지입니다.

저희는 버전을 Overleaf 커뮤니티 에디션과 엄격하게 맞춥니다. 덕분에 오픈 소스 Overleaf 플러그인을 사용할 수 있습니다. 저희는 Overleaf의 핵심 인터페이스를 변경하지 않습니다. 따라서 해당 `A.X.y` 커뮤니티 에디션 릴리스와 호환되는 모든 플러그인은 Ayakaleaf Pro `A.X.y`와 완벽하게 호환됩니다.
