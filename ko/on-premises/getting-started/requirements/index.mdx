Overleaf 설치를 진행하기 전에 이 섹션을 반드시 꼼꼼히 읽어 주십시오.

### Server Pro 및 Community Edition 설치 요구 사항

<Warning>

Server Pro는 최신의 안정적인 Ubuntu 버전(예: 2025–2026년 기준 Ubuntu 24.04)과 최신 버전의 Docker에서 실행할 것을 강력히 권장합니다. 다른 시스템에서도 Server Pro를 실행할 수는 있지만, 기본 구성이 아닌 Ubuntu/Docker 환경에 대해서는 지원을 제공하기가 훨씬 어려워집니다. 또한 Docker 자체의 문제에 대해서는 지원을 제공할 수 없습니다.

</Warning>
