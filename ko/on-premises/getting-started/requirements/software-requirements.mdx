### 운영 체제

Overleaf를 최적의 환경에서 실행하려면 **Ubuntu**와 같은 **Debian 기반** 운영 체제를 사용할 것을 적극 권장합니다. 이는 소프트웨어의 개발 환경과 일치하며 대다수 Overleaf 사용자가 선호하는 옵션입니다.

<Danger>

Server Pro를 Sandboxed Compiles와 함께 사용할 때는 애플리케이션이 Docker 소켓에 대한 root 권한을 필요로 한다는 점에 **유의**해야 합니다.

</Danger>

### 종속성

* Docker 25.0 및 29
* MongoDB 7.0 및 8.0
* Redis 6.2 및 7.5

<Info>

위 종속성 및 기타 인기 제품의 지원 종료(EOL) 날짜는 endoflife.date 서비스에서 확인할 수 있습니다: [https://endoflife.date/](https://endoflife.date/)

</Info>

<Info>

MongoDB와 Redis는 다른 설치를 사용하도록 구성하지 않는 한, Server CE 또는 Server Pro를 실행할 때 `docker compose`에 의해 자동으로 pull됩니다.

</Info>

Toolkit은 다음 프로그램에 의존합니다:

* bash
* Docker

`docker compose`가 필요하며, 일반적으로 Docker와 함께 설치됩니다.

운영 체제에서 사용할 수 있는 최신 버전의 Docker를 설치할 것을 권장합니다.

Docker가 올바르게 설치되면 다음 명령을 오류 없이 실행할 수 있어야 합니다:

```bash
# Shows the installed Docker version
docker --version

# docker compose plugin (v2)
docker compose version

# List the running Docker containers on your system
docker ps
```
