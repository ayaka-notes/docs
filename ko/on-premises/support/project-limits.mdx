---
title: 프로젝트 제한
icon: list-check
---

| 기능                                    | 제한 |
| --------------------------------------- | ---- |
| 컴파일 시간 제한                        | **기본값:** 180초. 이 값을 사용자 정의하는 방법은 [프로젝트 컴파일 시간 제한 업데이트](/ko/on-premises/user-and-project-management/project-management)를 참조하세요. |
| 프로젝트당 최대 파일 수                 | 2000 |
| 프로젝트당 편집 가능한 자료의 최대 크기 | **기본값:** 7 MB. 이 값을 사용자 정의하는 방법은 [환경 변수](/ko/on-premises/configuration/overleaf-toolkit/environment-variables)를 참조하세요. |
| 편집 가능한 개별 텍스트 파일의 최대 크기 | 2 MB\* |
| 개별 업로드의 최대 크기                 | 50 MB (`MAX_UPLOAD_SIZE`로 구성 가능) |
| 업로드된 .zip의 최대 압축 해제 크기     | 6 × `MAX_UPLOAD_SIZE` (기본값 300 MB) |
| 프로젝트 최대 크기                      | 무제한† |
| 최대 프로젝트 수                        | 무제한 |

\* 일부 더 큰 파일도 특정 상황에서는 편집 가능한 상태로 유지될 수 있습니다. 하지만 파일을 확실히 편집 가능한 상태로 유지하려면 크기를 2 MB 이하로 제한해야 합니다.

† 전체 프로젝트 크기에 강제 제한은 없습니다. 하지만 매우 큰 프로젝트로 작업할 때는 일부 기술적 제한이 있을 수 있습니다. 최대 프로젝트 크기는 500 MB, [Git 통합](https://www.overleaf.com/learn/how-to/Git_integration)을 사용하는 경우 100 MB 미만을 권장합니다. 이 크기를 초과하는 프로젝트도 작동할 수 있지만, 이 제한 내에서 사용하면 가장 좋은 경험을 얻을 수 있습니다.
