Mendeley 라이브러리를 `.bib` 파일로 프로젝트에 가져온 다음 평소처럼 인용합니다. 이 파일은 사본입니다. **Refresh**를 클릭할 때만 바뀝니다.

<Info>

**Account settings**에 Mendeley 옵션이 보이지 않으면 관리자에게 [Mendeley 통합](/ko/on-premises/configuration/overleaf-toolkit/integrations/mendeley-integration)을 켜 달라고 요청하세요.

</Info>

## Mendeley 계정 연결 {#link-your-mendeley-account}

이 작업은 한 번만 합니다.

<Steps>
<Step title="계정 설정 열기">
**Account**를 클릭한 다음 **Account settings**를 클릭합니다. **Reference managers**에서 **Mendeley**를 찾아 **Link to Mendeley**를 클릭합니다.

<Frame caption="계정 설정의 Mendeley">
  <img src="/images/on-premises/mendeley-link.png" alt="Link to Mendeley 버튼이 있는 계정 설정의 Mendeley 섹션" />
</Frame>

편집기의 **Integrations** 패널에 있는 **Mendeley** 카드도 같은 탭에서 같은 곳으로 이동합니다.

<Frame caption="Integrations 패널">
  <img src="/images/on-premises/mendeley-integrations.png" alt="Mendeley 카드가 있는 Integrations 패널" />
</Frame>
</Step>

<Step title="Mendeley에서 승인">
Mendeley가 열립니다. 요청되면 로그인한 다음 애플리케이션을 승인합니다.
</Step>

<Step title="연결 확인">
계정 설정으로 돌아옵니다. 녹색 메시지에 **Reference manager linked**가 표시되고 버튼이 **Unlink**로 바뀝니다.

<Frame caption="Mendeley 계정이 연결됨">
  <img src="/images/on-premises/mendeley-linked.png" alt="녹색 메시지와 Unlink 버튼이 있는 계정 설정의 Mendeley 섹션" />
</Frame>
</Step>
</Steps>

Mendeley에서 액세스를 허용하지 않으면 같은 섹션에 **Sorry, something went wrong**이 표시됩니다. **Link to Mendeley**를 클릭해 다시 시도하세요.

## 라이브러리에서 파일 만들기 {#create-a-file-from-your-library}

<Steps>
<Step title="Add files 대화 상자 열기">
프로젝트를 엽니다. 파일 트리에서 **New file**을 클릭한 다음 **From Mendeley**를 클릭합니다. 이 항목은 계정이 연결된 후에만 나타납니다.
</Step>

<Step title="파일 이름과 라이브러리 선택">
**File Name**의 기본값은 `mendeley.bib`입니다. `.bib` 확장자를 유지하세요. 확장자가 없으면 미리 보기가 표시되지 않고 `\cite`와 `\bibliography` 모두 항목을 찾지 못합니다.

**Library**의 기본값은 **My Library**이며 그룹도 함께 나열됩니다. 파일 하나에 라이브러리 하나가 들어갑니다.

<Frame caption="개인 라이브러리에서 만든 파일">
  <img src="/images/on-premises/mendeley-new-file.png" alt="mendeley.bib와 My Library가 지정된 Add files 대화 상자의 From Mendeley 탭" />
</Frame>
</Step>

<Step title="Create 클릭">
대화 상자가 닫히고 파일이 파일 트리에 나타납니다. 파일을 클릭하면 가져온 시각과 항목이 표시됩니다. 편집기에서 수정할 수는 없습니다.

<Frame caption="가져온 파일">
  <img src="/images/on-premises/mendeley-file.png" alt="Refresh 버튼과 함께 편집기에 열린 가져온 mendeley.bib" />
</Frame>

**Create**를 눌러도 아무 일도 일어나지 않는 것 같다면 같은 이름의 파일이 이미 있는 것입니다. 다른 이름을 선택하세요.
</Step>
</Steps>

### 그룹 가져오기 {#import-a-group}

별도의 파일 이름으로 같은 작업을 반복하고 **Library**에서 그룹을 선택합니다. 한 프로젝트에 이런 파일을 여러 개 둘 수 있습니다.

<Frame caption="그룹에서 만든 파일">
  <img src="/images/on-premises/mendeley-group.png" alt="파일 이름 journal-club.bib와 라이브러리 Journal club이 지정된 From Mendeley 탭" />
</Frame>

## 파일에서 인용하기 {#cite-from-the-file}

<Steps>
<Step title="인용 시작">
`.tex` 파일에서 `\cite{`를 입력합니다. 목록에 프로젝트의 모든 `.bib` 파일 항목이 표시됩니다. 하나를 클릭하면 삽입됩니다.

<Frame caption="가져온 파일의 항목">
  <img src="/images/on-premises/mendeley-cite.png" alt="인용 아래에 인용 키를 나열하는 편집기" />
</Frame>
</Step>

<Step title="또는 제목이나 저자로 검색">
목록 아래의 **Search**를 클릭하거나 중괄호 안에서 Ctrl+Space를 누릅니다. 입력해서 필터링하고 하나 이상의 항목을 클릭한 다음 **Insert**를 클릭합니다.

<Frame caption="참고문헌 검색">
  <img src="/images/on-premises/mendeley-search.png" alt="항목 하나가 선택된 Search the .bib files in this project 대화 상자" />
</Frame>
</Step>

<Step title="참고문헌 목록 추가">
`\end{document}` 앞에 다음 줄을 추가합니다. 파일 이름은 `.bib`를 빼고 씁니다. 파일이 여러 개이면 이름을 쉼표로 구분합니다.

```latex
\bibliographystyle{plain}
\bibliography{mendeley}
```

**Recompile**을 클릭합니다. 참고문헌이 PDF에 나타납니다.

<Frame caption="컴파일된 참고문헌">
  <img src="/images/on-premises/mendeley-compiled.png" alt="인용과 참고문헌 목록이 있는 편집기, 그리고 참고문헌이 있는 컴파일된 PDF" />
</Frame>
</Step>
</Steps>

가져온 파일은 **Settings**의 **References**, **Main bibliography file for this project**에 표시되지 않습니다. 따라서 프로젝트에 다른 `.bib` 파일이 없으면 이 목록은 비어 있습니다. 그래도 가져온 파일에서 인용할 수 있습니다.

<Frame caption="목록이 비어 있는 것이 정상입니다">
  <img src="/images/on-premises/mendeley-settings-references.png" alt="비어 있고 비활성화된 목록이 있는 프로젝트 설정의 References 탭" />
</Frame>

## 파일 새로 고침 {#refresh-the-file}

Mendeley 라이브러리의 변경 사항은 프로젝트에 자동으로 반영되지 않습니다.

<Steps>
<Step title="파일 열기">
파일 트리에서 가져온 파일을 클릭합니다.
</Step>

<Step title="Refresh 클릭">
만들 때 선택한 라이브러리에서 파일 전체를 다시 가져옵니다. 새 항목이 나타나고 삭제된 항목은 사라집니다. 위쪽의 시각이 바뀝니다.

<Frame caption="새로 고친 파일">
  <img src="/images/on-premises/mendeley-refresh.png" alt="새 항목과 새 가져오기 시각이 있는 새로 고친 mendeley.bib" />
</Frame>
</Step>

<Step title="다시 컴파일">
**Recompile**을 클릭해 PDF를 업데이트합니다.
</Step>
</Steps>

각 파일은 따로 새로 고쳐집니다. 그룹 파일은 별도로 새로 고치세요. 공유 프로젝트에서 누가 파일을 새로 고칠 수 있는지는 [관리자를 위한 참고 사항](/on-premises/configuration/overleaf-toolkit/integrations/mendeley-integration#notes)을 참고하세요.

## Mendeley 계정 연결 해제 {#unlink-your-mendeley-account}

**Account settings**의 **Mendeley**에서 **Unlink**를 클릭하고, 대화 상자에서 다시 **Unlink**를 클릭합니다. 버튼이 다시 **Link to Mendeley**로 바뀝니다.

<Frame caption="계정 연결 해제">
  <img src="/images/on-premises/mendeley-unlink.png" alt="Unlink Mendeley Account 대화 상자" />
</Frame>

가져온 파일은 프로젝트에 남아 있고 계속 컴파일됩니다. **Add files** 대화 상자에서 **From Mendeley**가 사라지고, 계정을 다시 연결할 때까지 **Refresh**는 오류를 표시합니다.

<Frame caption="연결된 계정 없이 새로 고침">
  <img src="/images/on-premises/mendeley-relink-error.png" alt="Could not load references from Mendeley, please re-link your account and try again 오류가 표시된 가져온 파일" />
</Frame>

다시 연결하면 같은 파일에서 **Refresh**가 작동합니다.

## 문제가 생기면 {#if-something-goes-wrong}

**Add files** 대화 상자에 **Could not load references from Mendeley, please re-link your account and try again** 또는 **There was an error accessing your Mendeley data**가 표시되는 경우: 예를 들어 Mendeley에서 액세스 권한을 제거해서 Overleaf가 더 이상 라이브러리를 읽을 수 없는 상태입니다. **Account settings**에서 **Unlink**를 클릭한 다음 **Link to Mendeley**를 클릭하세요. 그때까지는 **Create**도 실패하며, 자신의 프로젝트에서도 **The project that contains this file is not shared with you** 메시지가 표시됩니다.

<Frame caption="Overleaf가 더 이상 라이브러리를 읽을 수 없음">
  <img src="/images/on-premises/mendeley-access-error.png" alt="두 오류 메시지가 모두 표시된 From Mendeley 탭" />
</Frame>

**Refresh**를 클릭했을 때 **The remote service produced an error**가 표시되는 경우: Mendeley에 대한 요청이 실패했습니다. 파일 내용은 그대로 유지됩니다. 나중에 다시 **Refresh**를 클릭하세요.
