참고문헌 검색은 프로젝트의 모든 `.bib` 파일을 살펴보므로 인용 키를 기억하지 않아도 참고문헌을 찾을 수 있습니다. 설정할 것은 없습니다.

프로젝트에는 `.bib` 파일이 하나 이상 있어야 합니다. 파일을 업로드하거나 [Zotero](/ko/on-premises/user-guide/users/zotero-integration) 또는 [Mendeley](/ko/on-premises/user-guide/users/mendeley-integration)에서 라이브러리를 가져올 수 있습니다.

## 인용 삽입 {#insert-a-citation}

<Steps>
<Step title="인용 시작">
`.tex` 파일에서 `\cite{`를 입력합니다. 편집기가 닫는 중괄호를 추가합니다. 커서 아래에 인용 키와 파란 상자 **Open advanced reference search**가 보입니다.

<Frame caption="인용 아래의 파란 상자">
  <img src="/images/on-premises/reference-search-hint.png" alt="\cite{}, 인용 키 목록, Search 버튼이 있는 파란 상자가 보이는 편집기" />
</Frame>

도구 모음의 **Insert citation** 버튼과 **Insert** 다음 **Citation**도 `\cite{}`를 입력해 줍니다. 이 상자는 `\citep`, `\autocite`, `\parencite`, `\textcite` 같은 다른 인용 명령에서도 나타납니다.
</Step>

<Step title="검색 열기">
파란 상자에서 **Search**를 클릭하거나 중괄호 사이에서 Ctrl+Space를 누릅니다. 대화 상자에 모든 항목이 제목, 인용 키, 저자, 저널, 연도와 함께 나열됩니다.

<Frame caption="프로젝트의 모든 항목">
  <img src="/images/on-premises/reference-search-dialog.png" alt="항목 다섯 개를 나열한 Search the .bib files in this project 대화 상자" />
</Frame>
</Step>

<Step title="항목 찾기">
검색 상자에 입력합니다. 인용 키, 저자, 제목, 저널, 연도에서 찾고 일치한 부분을 강조 표시합니다. 모든 단어가 일치해야 하므로 `turing 1936`은 Turing의 1936년 논문을 찾습니다. 출판사 같은 다른 필드는 검색하지 않습니다.

<Frame caption="저자와 연도로 검색">
  <img src="/images/on-premises/reference-search-filter.png" alt="turing 1936이 입력된 검색 상자와 일치 부분이 빨간색으로 표시된 항목" />
</Frame>
</Step>

<Step title="하나 이상의 항목 선택">
항목을 클릭합니다. 항목이 녹색으로 바뀌고 키가 목록 위에 나타납니다. 다른 항목을 추가하려면 클릭하거나 다시 검색하세요. 선택한 항목은 유지됩니다. 하나를 빼려면 다시 클릭하거나 키 옆의 <strong>×</strong>를 클릭합니다.

<Frame caption="두 항목을 선택한 상태">
  <img src="/images/on-premises/reference-search-selected.png" alt="목록 위의 키 knuth1984와 einstein1905, 그리고 녹색으로 표시된 해당 항목" />
</Frame>
</Step>

<Step title="Insert 클릭">
키가 쉼표로 구분되어 중괄호 사이에 들어갑니다. 문서에 아직 참고문헌 목록이 없다면 `\end{document}` 앞에 다음 줄을 추가합니다. `.bib` 파일 이름은 확장자를 빼고 씁니다.

```latex
\bibliographystyle{plain}
\bibliography{refs,more}
```

**Recompile**을 클릭합니다. 참고문헌이 PDF에 나타납니다.

<Frame caption="컴파일된 인용">
  <img src="/images/on-premises/reference-search-compiled.png" alt="\cite{knuth1984, einstein1905}가 있는 편집기와 두 참고문헌이 있는 PDF" />
</Frame>
</Step>
</Steps>

**Visual** 편집기에서도 검색은 같은 방식으로 작동합니다.

## 인용 변경 {#change-a-citation}

<strong>참고문헌 추가:</strong> 기존 인용의 중괄호 사이에 커서를 두고 검색을 엽니다. **Insert**는 이미 있는 키 뒤에 새 키를 추가합니다.

<strong>참고문헌 교체:</strong> 편집기에서 키를 선택한 다음 Ctrl+Space를 누릅니다. 키가 목록 위에 나타나고 버튼이 **Replace**로 바뀝니다. 원하지 않는 키를 빼고 다른 키를 추가한 다음 **Replace**를 클릭합니다. 어떤 `.bib` 파일에도 없는 키는 직접 뺄 때까지 남아 있습니다.

<Frame caption="선택한 키 교체">
  <img src="/images/on-premises/reference-search-replace.png" alt="목록 위에 knuth1984, missing2000, turing1936이 있고 Replace 버튼이 있는 대화 상자" />
</Frame>

## 키보드 사용 {#use-the-keyboard}

| 키 | 동작 |
| --- | ------------ |
| **아래쪽 화살표** | 검색 상자에서 목록으로 이동한 다음 목록 아래로 이동합니다 |
| **위쪽 화살표** | 목록 위로 이동합니다 |
| **Space** | 항목을 선택하거나 선택에서 뺍니다 |
| **Enter** | 목록에 있을 때 선택한 항목을 삽입합니다 |
| **Tab** | 검색 상자, 목록, 버튼 사이를 이동합니다 |
| **Esc** | 아무것도 바꾸지 않고 대화 상자를 닫습니다 |

## 항목의 출처 {#where-the-entries-come-from}

검색은 Zotero나 Mendeley에서 가져온 파일을 포함해 프로젝트의 모든 `.bib` 파일을 대상으로 합니다. `.bib` 파일을 편집하면 다음 검색에서 새 항목을 찾습니다.

## 문제가 생기면 {#if-something-goes-wrong}

| 보이는 현상 | 이유 | 해결 방법 |
| ------------ | --- | ---------- |
| 대화 상자의 목록이 비어 있음 | 프로젝트에 `.bib` 파일이 없음 | 파일을 업로드하거나 만듭니다 |
| 파란 상자가 없고 Ctrl+Space를 누르면 LaTeX 명령이 나열됨 | 커서가 인용의 중괄호 사이에 있지 않음 | 중괄호 사이를 클릭합니다 |
| Ctrl+Space를 눌러도 반응이 없음 | 컴퓨터가 이 단축키를 다른 용도로 사용함 | 파란 상자에서 **Search**를 클릭합니다 |
| 항목을 찾을 수 없음 | 검색 대상은 키, 저자, 제목, 저널, 연도뿐임 | 이 중 하나로 검색합니다 |
