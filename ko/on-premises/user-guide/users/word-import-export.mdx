## 문서 가져오기 {#import-a-document}

Word 문서(`.docx`) 또는 Markdown 파일(`.md`)에서 새 LaTeX 프로젝트를 만듭니다. 프로젝트 이름은 파일 이름에서 가져옵니다.

<Steps>
<Step title="가져오기 대화 상자 열기">
프로젝트 페이지에서 **New project**를 클릭합니다. **Import** 아래에서 **Word document** 또는 **Markdown document**를 클릭합니다.

<Frame caption="New project 메뉴">
  <img src="/images/on-premises/word-import-menu.png" alt="Import 아래에 Word document와 Markdown document가 있는 New project 메뉴" />
</Frame>
</Step>

<Step title="파일 선택하기">
**Select .docx file**을 클릭하거나 파일을 대화 상자로 끌어 놓습니다. Markdown의 경우 버튼은 **Select .md file**입니다. 가져오기가 바로 시작됩니다.

<Frame caption="Word 문서 선택">
  <img src="/images/on-premises/word-import-dialog.png" alt="Select .docx file 버튼이 있는 Choose Word document 대화 상자" />
</Frame>
</Step>

<Step title="편집 시작하기">
새 프로젝트가 **Document ready for editing** 메시지와 함께 열립니다. **Start editing**을 클릭합니다.

<Frame caption="가져오기 완료">
  <img src="/images/on-premises/word-import-ready.png" alt="Start editing 버튼이 있는 Document ready for editing 대화 상자" />
</Frame>
</Step>

<Step title="결과 확인하기">
이제 문서는 `main.tex`에 있으며, 제목은 파일 개요에 표시됩니다. **Recompile**을 클릭해 PDF를 확인합니다. 스타일, 특히 표, 그림, 인용은 수정이 필요할 수 있으므로 확인하세요.

<Frame caption="가져온 프로젝트">
  <img src="/images/on-premises/word-import-project.png" alt="main.tex, 파일 개요, 컴파일된 PDF가 있는 편집기의 가져온 프로젝트" />
</Frame>
</Step>
</Steps>

### 가져오기에 실패한 경우 {#if-the-import-fails}

파일을 변환할 수 없으면 대화 상자에 **Your document couldn't be imported**가 표시됩니다. **Conversion error details**를 펼치면 이유를 볼 수 있습니다. 프로젝트는 생성되지 않습니다.

<Frame caption="가져올 수 없는 문서">
  <img src="/images/on-premises/word-import-error.png" alt="오류 메시지와 Conversion error details가 있는 가져오기 대화 상자" />
</Frame>

대화 상자는 선택한 유형만 받습니다. Word 대화 상자에서 `.md` 파일을 선택하면 **You can only upload: .docx**가 표시됩니다.

## 프로젝트 내보내기 {#export-a-project}

프로젝트를 열고 편집기 상단의 프로젝트 이름을 클릭합니다. 다음 중 하나를 클릭합니다:

| 옵션                              | 받는 결과                                       |
| ----------------------------------- | --------------------------------------------- |
| <strong>Export as Word document (.docx)</strong> | 프로젝트 이름으로 된 `.docx` 파일        |
| <strong>Export as Markdown (.md)</strong>        | `main.md`가 들어 있는 `.zip` 파일                  |
| <strong>Export as HTML (.html)</strong>          | `main.html`이 들어 있는 `.zip` 파일                |

다운로드가 자동으로 시작됩니다. 변환으로 모든 LaTeX 서식을 재현할 수는 없으므로 결과를 확인하세요.
