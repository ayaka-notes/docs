## 사용자 찾기 {#find-a-user}

**Search by name, email or ID**에 입력하세요. `Carol Novak` 같은 전체 이름도 사용할 수 있으며, 사용자의 [보조 이메일](/ko/on-premises/user-guide/users/multiple-emails)로도 찾을 수 있습니다. 목록을 좁히려면 **Login**, **Role**, **Status** 열의 필터를 사용하세요. 정렬하려면 **Name**, **Sign up**, **Last logged in**을 클릭하세요.

<Frame caption="사용자 검색">
  <img src="/images/on-premises/user-management-search.png" alt="검색어 carol로 필터링한 사용자 목록" />

## 사용자 상태 {#user-status}

모든 계정에는 정확히 하나의 상태가 있으며, **Status** 필터에 상태별 계정 수가 표시됩니다. 물음표에 마우스를 올리면 정의를 볼 수 있습니다.

<Frame caption="Status 필터">
  <img src="/images/on-premises/user-management-status-tooltip.png" alt="Active의 도움말이 표시된 Status 필터" />
</Frame>

| 상태 | 의미 | 로그인 가능 |
| --- | --- | --- |
| **All** | 삭제되지 않은 모든 계정. 아래 네 상태(Active + Pending + Inactive + Disabled)를 더하면 이 숫자가 됩니다. | |
| **Active** | 지난 12개월 안에 로그인했거나 프로젝트를 열었습니다. | 예 |
| **Pending** | 한 번도 로그인하지 않았습니다. 보통 관리자가 만든 계정이거나 활성화 이메일로 가입했지만 사용자가 아직 활성화하지 않은 계정입니다. 비밀번호로 가입한 계정은 활성화가 필요 없으며 첫 로그인 시 Active가 됩니다. | 예 |
| **Inactive** | 이전에 로그인한 적은 있지만 지난 12개월 동안 로그인하거나 프로젝트를 연 적이 없습니다. | 예 |
| **Disabled** | 관리자가 계정을 비활성화했습니다. 로그인하면 **Your account is suspended** 페이지로 이동합니다. | 아니요 |
| **Deleted user** | 관리자나 사용자가 계정을 삭제했습니다. **All**에 포함되지 않으며 이 필터를 선택할 때까지 숨겨집니다. 로그인하면 이메일 또는 비밀번호가 올바르지 않다고 표시됩니다. | 아니요 |

계정의 상태는 다음과 같이 바뀝니다.

* **Pending, Active, Inactive**는 계정 사용에 따라 정해지므로 직접 설정할 수 없습니다. Inactive 계정은 사용자가 로그인하는 즉시 Active가 됩니다.
* **Enable**과 **Restore**는 이전 상태를 되돌리지 않습니다. 상태는 마지막 로그인에 따라 정해집니다. 한 번도 로그인하지 않은 계정은 다시 Pending이 됩니다. 비활성화된 계정은 **Restore** 후에도 **Disabled**로 남습니다.
* **Delete permanently**는 되돌릴 수 없습니다. 그 밖에 삭제된 계정은 직접 제거할 때까지 남아 있습니다. 단, 인스턴스에서 [`ENABLE_CRON_RESOURCE_DELETION`](/ko/on-premises/configuration/overleaf-toolkit/environment-variables)을 설정하면 90일 후 제거됩니다.

### License 탭의 활성 사용자 {#active-users-on-the-license-tab}

**License** 탭과 **Active** 상태는 서로 다른 것을 세기 때문에 숫자가 다를 수 있습니다. **License** 탭은 Overleaf가 [Understanding license usage](https://docs.overleaf.com/on-premises/user-and-project-management/understanding-license-usage)에서 정의한 대로 Server Pro 라이선스가 적용되는 사용자를 셉니다: "any user who logs in and accesses a project is considered an active user by the system", "An active user is defined as someone who has opened a project on your Server Pro instance in the last 12 months." 로그인했지만 프로젝트를 열지 않은 사용자는 목록에서 **Active**이지만 라이선스에는 포함되지 않습니다. 프로젝트를 연 뒤 비활성화된 사용자는 라이선스에 포함되지만 목록에서는 **Disabled**입니다.

## 사용자 작업 {#actions-on-a-user}

**Actions** 열의 아이콘은 사용자 페이지 상단의 아이콘과 같습니다.

| 아이콘 | 작업 | 하는 일 |
| --- | --- | --- |
| 봉투 | **Send activation email** | 한 번도 로그인하지 않은 계정: 새 활성화 링크를 만듭니다. |
| 화살표가 있는 자물쇠 | **Send reset link** | 로그인한 적이 있는 계정: 새 비밀번호 재설정 링크를 만듭니다. |
| 폴더 | **Transfer this user's projects** | 사용자가 소유한 모든 프로젝트를 다른 사용자에게 넘깁니다. |
| 원 | **Disable** | 사용자의 로그인을 막습니다. |
| 재생 | **Enable** | 비활성화된 사용자가 다시 로그인할 수 있게 합니다. |
| 휴지통 | **Delete account** | 계정을 **Deleted user**로 옮깁니다. |
| 화살표 | **Restore** | 삭제된 계정을 되살립니다. 삭제된 계정에만 해당합니다. |
| 줄 그은 휴지통 | **Delete permanently** | 삭제된 계정을 영구히 제거합니다. 삭제된 계정에만 해당합니다. |

모든 작업은 계정 이름이 표시된 대화 상자에서 확인을 요청합니다.

### 활성화 또는 재설정 링크 보내기 {#send-an-activation-or-reset-link}

계정에는 로그인한 적이 있는지에 따라 두 아이콘 중 하나가 표시됩니다. 비활성화된 계정, SSO 계정처럼 로컬 비밀번호가 없는 계정, 본인 계정에서는 아이콘이 비활성화됩니다.

아이콘을 클릭한 다음 같은 이름의 버튼을 클릭하세요. 대화 상자는 열린 채로 링크를 보여 줍니다.

* **Email Sent**는 이메일이 발송되었다는 뜻입니다.
* <strong>No email was sent. Copy the link and pass it on.</strong>은 [이메일 발송](/ko/on-premises/configuration/overleaf-toolkit/email-delivery)이 구성되지 않았거나 이메일 발송에 실패했다는 뜻입니다. 복사 아이콘을 클릭하고 링크를 사용자에게 직접 보내세요.

활성화 링크는 7일 후, 재설정 링크는 1시간 후에 만료됩니다. 사용자는 링크를 열고 비밀번호를 설정합니다. 활성화 링크 후에는 자신의 프로젝트로 이동하고, 재설정 링크 후에는 로그인합니다.

<Frame caption="이메일 발송이 없는 인스턴스의 재설정 링크">
  <img src="/images/on-premises/user-management-reset-link.png" alt="Carol Novak의 Send reset link 대화 상자. 이메일이 발송되지 않았다는 경고, 링크, 복사 아이콘, Expires in 1 hour가 표시됨" />
</Frame>

### 계정 비활성화 또는 활성화 {#disable-or-enable-an-account}

원 아이콘을 클릭한 다음 **Disable**을 클릭하세요. 상태가 **Disabled**로 바뀌고 사용자는 더 이상 로그인할 수 없습니다. 되돌리려면 재생 아이콘을 클릭한 다음 **Enable**을 클릭하세요.

<Frame caption="계정 비활성화">
  <img src="/images/on-premises/user-management-disable.png" alt="Dave Okafor가 표시된 Disable 대화 상자" />
</Frame>

### 사용자의 프로젝트 이전 {#transfer-a-user’s-projects}

폴더 아이콘을 클릭하세요. **Select a new owner for this user's projects** 아래에 이름이나 이메일을 입력하고, 사용자를 선택한 뒤 **Transfer this user's projects**를 클릭하세요. 해당 프로젝트의 **Owner**는 [프로젝트 관리](/on-premises/user-guide/administrators/project-management)에서 바뀝니다.

비활성화된 계정은 새 소유자로 제시되지 않습니다. 선택한 뒤 텍스트를 바꾸면 선택이 취소되므로 사용자를 다시 선택하세요.

<Frame caption="사용자의 모든 프로젝트 이전">
  <img src="/images/on-premises/user-management-transfer.png" alt="새 소유자로 Carol Novak이 선택된 이전 대화 상자" />
</Frame>

### 계정 삭제 {#delete-an-account}

휴지통 아이콘을 클릭하세요. 두 가지 옵션이 있으며 기본으로 선택된 것은 없습니다.

* **Notify the user about the account deletion**은 사용자에게 이메일을 보냅니다.
* **Transfer this user's projects**를 사용하면 먼저 프로젝트의 새 소유자를 선택할 수 있습니다. 프로젝트는 새 소유자 아래에서 계속 활성 상태로 남습니다.

**Delete account**를 클릭하세요. 프로젝트를 이전하지 않으면 프로젝트는 계정과 함께 삭제되어 [프로젝트 관리](/on-premises/user-guide/administrators/project-management#project-status)의 **Deleted** 상태로 이동합니다.

<Frame caption="계정 삭제 및 프로젝트 이전">
  <img src="/images/on-premises/user-management-delete.png" alt="두 옵션이 모두 선택되고 새 소유자가 선택된 Delete account 대화 상자" />
</Frame>

### 계정 복원 또는 영구 삭제 {#restore-or-permanently-delete-an-account}

**Status** 필터에서 **Deleted user**를 선택하거나, 검색 후 **Display deleted users**를 클릭하세요.

<Frame caption="삭제된 계정">
  <img src="/images/on-premises/user-management-deleted-list.png" alt="Restore 및 Delete permanently 아이콘이 있는 삭제된 사용자 목록" />
</Frame>

* **Restore**는 계정을 되살립니다. 비활성화된 계정은 비활성화된 상태로 남습니다. 계정과 함께 삭제된 프로젝트도 돌아오며, 각 프로젝트 이름 끝에 `(Restored)`가 붙습니다. 사용자가 직접 삭제한 프로젝트는 삭제된 상태로 남습니다.
* **Delete permanently**는 계정을 제거합니다. 대화 상자에서 되돌릴 수 없다고 경고합니다.

<Frame caption="계정 영구 삭제">
  <img src="/images/on-premises/user-management-purge.png" alt="작업을 되돌릴 수 없다고 경고하는 Delete permanently 대화 상자" />
</Frame>

### 여러 계정을 한 번에 변경 {#change-several-accounts-at-once}

목록에서 계정을 선택하세요. **Create account** 옆에 버튼이 나타납니다: **Send activation email**, **Transfer this user's projects**, **Disable**, **Enable**, **Make admin**, **Remove admin**, **Delete account**. 목록 아래쪽에 선택된 계정 수가 표시됩니다. 확인하기 전에 대화 상자에 해당 계정이 나열됩니다.

<Frame caption="일괄 작업">
  <img src="/images/on-premises/user-management-bulk.png" alt="두 계정이 선택되고 목록 위에 일괄 작업 버튼이 있으며 봉투가 비활성화된 화면" />
</Frame>

선택한 계정이 모두 **Pending**이 아니면 **Send activation email**은 비활성화됩니다. 이때 대화 상자에는 계정마다 링크가 하나씩 표시됩니다. 일괄 재설정 링크는 없습니다.

<Frame caption="계정마다 하나의 활성화 링크">

</Frame>

## 사용자 페이지 {#the-user-page}

사용자 이름을 클릭하면 해당 사용자의 페이지가 열립니다. 페이지에는 탭이 여섯 개 있습니다.

### Account {#account}

계정의 세부 정보입니다. 변경하려면 연필 아이콘을 클릭하고 필드를 편집한 뒤 **Save**를 클릭하세요. 이메일, 이름, 비밀번호를 바꾸고 **Admin**을 켜거나 끌 수 있습니다.

사용자가 [이메일을 더 추가](/ko/on-premises/user-guide/users/multiple-emails)했다면 **Emails** 아래에 나열됩니다. 편집하는 동안 **Remove**를 누르면 보조 이메일이 계정에서 제거되며, 이후 다른 계정이 그 주소를 사용할 수 있습니다.

<Frame caption="이메일이 두 개인 계정">
  <img src="/images/on-premises/user-management-secondary-email.png" alt="편집 중인 Account 탭. 기본 이메일과 Remove 버튼이 있는 보조 이메일이 표시됨" />

온보딩의 [비밀번호 규칙](/ko/on-premises/user-guide/administrators/onboarding#create-the-administrator-account)이 적용됩니다. 비밀번호를 사용자에게 전달하는 것은 여러분의 몫입니다. 사용자가 직접 정하게 하려면 대신 [재설정 링크를 보내세요](/ko/on-premises/user-guide/administrators/user-management#send-an-activation-or-reset-link).

### Features {#features}

이 계정에서 켜져 있는 기능: 공동 작업, 컴파일 제한 시간, 통합, AI. 변경하려면 연필 아이콘을 클릭하고 값을 바꾼 뒤 **Save**를 클릭하세요. **Collaborators per project**에서 `-1`은 무제한을 뜻합니다. **Compile timeout**은 초 단위이며 1에서 600까지입니다.

본인 계정에서는 연필과 **AI usage**의 **Reset**이 비활성화됩니다. **Account** 탭에서는 본인의 이메일, 이름, 비밀번호를 계속 변경할 수 있습니다.
