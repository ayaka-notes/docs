---
title: 온보딩
description: 첫 관리자를 만들고, 인스턴스를 확인하고, 첫 사용자를 추가합니다.
icon: user-plus
---

[설치](/ko/on-premises/installation/introduction) 직후에 한 번만 수행하세요. 이 페이지는 기본 비밀번호 로그인을 사용합니다.

<Steps>
<Step id="open-the-launchpad" title="launchpad 열기">
인스턴스에서 `/launchpad`를 엽니다(예: `http://localhost/launchpad`). **Create the first Admin account**가 표시됩니다.

이 양식은 첫 관리자가 생성되기 전까지만 존재합니다. 그 이후에는 로그인하지 않은 방문자가 로그인 페이지로 이동합니다.
</Step>

<Step id="create-the-administrator-account" title="관리자 계정 만들기">
이메일과 비밀번호를 입력한 다음 **Register**를 클릭합니다.

<Frame caption="첫 관리자 계정">
  <img src="/images/on-premises/onboarding-launchpad-filled.png" alt="admin@example.com이 입력된 launchpad 양식" />
</Frame>

비밀번호가 거부되면 양식 위에 메시지가 나타나고 계정은 생성되지 않습니다.

<Frame caption="거부된 비밀번호">
  <img src="/images/on-premises/onboarding-password-error.png" alt="launchpad 양식 위의 메시지 password is too short" />
</Frame>

| 메시지                                     | 의미                                                                                                                                                  |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `password is too short`                    | 8자 미만입니다.                                                                                                                                       |
| `password is too long`                     | 72자를 초과합니다.                                                                                                                                    |
| `password contains an invalid character`   | 문자 `a-z`와 `A-Z`, 숫자, `@#$%^&*()-_=+[]{};:<>/?!£€.,`만 허용됩니다. 공백, 악센트가 있는 문자, 라틴 문자가 아닌 문자는 허용되지 않습니다.          |
| `password contains part of email address`  | 이메일 또는 `@` 앞부분을 포함하거나 이메일의 일부입니다. `admin@example.com`의 경우 `admin-7Tq9-demo`와 `example.com` 모두 거부됩니다.              |
| `password is too similar to email address` | 이메일과 너무 비슷합니다(예: `adm1n@example.c0m`).                                                                                                    |

기본적으로 대문자, 숫자, 기호는 필수가 아닙니다. 길이 제한을 변경하려면 [비밀번호 제한](/ko/on-premises/configuration/overleaf-toolkit/authentication/password-restrictions)을 참고하세요.
</Step>

<Step id="log-in" title="로그인하기">
**Register** 후에는 로그인 페이지가 표시됩니다. 같은 이메일과 비밀번호를 입력한 다음 **Login**을 클릭합니다.

<Frame caption="새 계정으로 로그인">
  <img src="/images/on-premises/onboarding-login.png" alt="admin@example.com이 입력된 로그인 페이지" />
</Frame>

launchpad로 돌아오며, 이제 **Status Checks**가 표시됩니다.
</Step>

<Step id="check-the-instance" title="인스턴스 확인하기">
`websockets`에 **OK**가 표시되어야 합니다.

이메일을 테스트하려면 **Send a test email** 아래에 주소를 입력하고 **Send**를 클릭한 다음 받은편지함을 확인합니다.

<Frame caption="상태 확인과 테스트 이메일">
  <img src="/images/on-premises/onboarding-launchpad-checks.png" alt="websockets가 OK이고 테스트 이메일 양식에 Email Sent가 표시되며 하단에 버튼 두 개가 있는 launchpad" />
</Frame>

<Warning>

**Email Sent**는 메시지가 서버를 떠났다는 증거가 아닙니다. [이메일 전송](/ko/on-premises/configuration/overleaf-toolkit/email-delivery)이 설정되어 있지 않아도 페이지에는 같은 문구가 표시되며 아무것도 도착하지 않습니다.

</Warning>

**Start Using** _사이트 이름_ 은 프로젝트를 엽니다. **Go To Admin Panel**은 사이트 도구를 엽니다. [기본 관리](/ko/on-premises/user-guide/administrators/basic-management)를 참고하세요.
</Step>

<Step id="create-the-first-user" title="첫 사용자 만들기">
상단 메뉴에서 **Admin**을 클릭한 다음 **Manage Users**를 클릭합니다.

<Frame caption="Admin 메뉴">
  <img src="/images/on-premises/onboarding-admin-menu.png" alt="Manage Site, Manage Users, Project/Object Lookup이 있는 Admin 메뉴" />
</Frame>

**Create account**를 클릭합니다.

<Frame caption="사용자 목록">
  <img src="/images/on-premises/onboarding-user-list.png" alt="관리자와 Create account 버튼이 있는 사용자 목록" />
</Frame>

사용자의 이메일을 입력합니다. **First name**과 **Last name**은 선택 사항입니다. **Admin**은 다른 관리자를 만들 때만 선택합니다. **Create**를 클릭합니다.

<Frame caption="Create account 대화 상자">
  <img src="/images/on-premises/onboarding-create-account.png" alt="user@example.com이 입력된 Create account 대화 상자" />
</Frame>

그러면 대화 상자에 새 계정과 활성화 링크가 표시됩니다. 링크는 7일 후 만료됩니다.

* **Email Sent**는 활성화 이메일이 발송되었다는 뜻입니다.
* <strong>No email was sent. Copy the link and pass it on.</strong>은 이메일이 발송되지 않았다는 뜻입니다. 예를 들어 [이메일 전송](/ko/on-premises/configuration/overleaf-toolkit/email-delivery)이 설정되지 않은 경우입니다.

<Frame caption="새 계정과 활성화 링크">
  <img src="/images/on-premises/onboarding-account-created.png" alt="이메일이 발송되지 않았다는 경고, 링크, 복사 아이콘, Expires in 7 days가 표시된 Demo User의 Create account 대화 상자" />
</Frame>

**Close**를 클릭합니다. 계정이 **Pending** 상태로 목록에 나타납니다.

<Frame caption="새 계정은 첫 로그인 전까지 Pending 상태로 유지됩니다">
  <img src="/images/on-premises/onboarding-user-pending.png" alt="Demo User가 Pending 상태인 사용자 목록" />
</Frame>
</Step>

<Step id="give-the-user-access" title="사용자에게 접근 권한 주기">
**이메일 전송이 설정된 경우**, 사용자는 **Set password** 링크가 포함된 활성화 이메일을 받습니다. 링크를 열면 이 페이지가 열립니다. 사용자가 비밀번호를 입력하고 **Activate**를 클릭하면 프로젝트 페이지로 이동합니다. 위의 비밀번호 규칙이 적용됩니다.

<Frame caption="링크를 연 후 사용자에게 보이는 화면">
  <img src="/images/on-premises/onboarding-activate.png" alt="사용자에게 비밀번호 설정을 요청하는 활성화 페이지" />
</Frame>

**이메일 전송이 설정되지 않은 경우**, 링크를 직접 전달합니다. **Create** 후 대화 상자에서 복사 아이콘을 클릭하고 링크를 사용자에게 보내면, 사용자가 위와 같이 비밀번호를 설정합니다.

대화 상자를 닫았거나 링크가 만료되었다면 **Manage Users**에서 사용자 행의 봉투 아이콘을 클릭한 다음 **Send activation email**을 클릭합니다. 대화 상자에 새 링크가 표시되며, 이 링크는 7일 후 만료됩니다.

<Frame caption="새 활성화 링크">
  <img src="/images/on-premises/onboarding-activation-link.png" alt="이메일이 발송되지 않았다는 경고, 링크, 복사 아이콘, Expires in 7 days가 표시된 Demo User의 Send activation email 대화 상자" />
</Frame>

비밀번호를 직접 설정할 수도 있습니다. **Manage Users**에서 사용자 이름을 클릭한 다음 연필 아이콘을 클릭합니다. **New password**를 입력하고 **Save**를 클릭합니다. 비밀번호를 사용자에게 전달하면 사용자는 `/login`에서 로그인합니다.

<Frame caption="Account 탭에서 비밀번호 설정">
  <img src="/images/on-premises/onboarding-set-password.png" alt="New password 필드가 입력된 편집 모드의 사용자 Account 탭" />
</Frame>
</Step>

<Step id="confirm-it-worked" title="제대로 되었는지 확인하기">
사용자가 처음 로그인하면 **Manage Users**의 상태가 **Active**로 바뀝니다.

<Frame caption="사용자가 로그인했습니다">
  <img src="/images/on-premises/onboarding-user-active.png" alt="Demo User가 Active 상태인 사용자 목록" />
</Frame>
</Step>
</Steps>

<Info>

기본적으로 **Sign up**은 계정을 만들지 않습니다. 이 페이지는 방문자에게 `OVERLEAF_ADMIN_EMAIL`의 주소로 연락하라고 안내합니다. 사용자가 직접 가입할 수 있게 하려면 [공개 접근](/ko/on-premises/configuration/overleaf-toolkit/authentication/public-access)을 참고하세요.

</Info>
