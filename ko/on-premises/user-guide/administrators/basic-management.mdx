**Admin**을 클릭한 다음 **Manage Site**를 클릭합니다. **Admin Panel**에는 **System Messages**, **Open Sockets**, **Open/Close Editor**의 세 탭이 있습니다.

## 시스템 메시지 {#system-messages}

시스템 메시지는 **Projects** 페이지와 편집기 상단에 표시되는 파란색 배너입니다. 모든 사용자에게 표시됩니다.

### 메시지 게시하기 {#post-a-message}

**Message** 아래에 텍스트를 입력하고 **Post Message**를 클릭합니다. 탭에는 현재 표시 중인 메시지가 나열됩니다.

<Frame caption="게시된 메시지 두 개">
  <img src="/images/on-premises/basic-management-posted.png" alt="Message 필드, Post Message 버튼, Clear all messages 버튼 위에 게시된 메시지 두 개가 나열된 System Messages 탭" />
</Frame>

<Frame caption="사용자에게 보이는 화면">
  <img src="/images/on-premises/basic-management-user-projects.png" alt="상단에 두 메시지가 파란색 배너로 표시된 사용자의 Projects 페이지" />
</Frame>

* 사용자는 <strong>×</strong>로 메시지를 닫을 수 있습니다. 해당 브라우저에서는 닫힌 상태로 유지됩니다.
* 이미 열려 있는 페이지는 15분마다 새 메시지를 확인합니다. 페이지를 새로 고치면 즉시 표시됩니다.

### 메시지 제거하기 {#remove-messages}

**Clear all messages**는 모든 메시지를 한 번에 제거하며 확인을 요청하지 않습니다. 메시지를 하나만 제거할 수는 없습니다.

## 열린 소켓 {#open-sockets}

웹 서비스가 현재 열어 둔 발신 연결을 보여 주는 진단 보기입니다. 누가 온라인인지는 보여 주지 않습니다. 사용자가 편집기에 있어도 목록이 비어 있을 수 있습니다.

## 유지 관리를 위해 편집기 닫기 {#close-the-editor-for-maintenance}

**Open/Close Editor** 탭을 사용합니다. 버튼은 확인 없이 즉시 동작하며, 탭에는 편집기가 닫혀 있는지 표시되지 않습니다. 확인하려면 **Projects**를 클릭하세요. 닫혀 있는 동안에는 **Maintenance** 페이지가 표시됩니다.

<Frame caption="Open/Close Editor 탭">
  <img src="/images/on-premises/basic-management-open-close.png" alt="Close Editor, Disconnect all users, Reopen Editor 버튼이 있는 Open/Close Editor 탭" />
</Frame>

<Steps>
<Step id="tell-your-users" title="사용자에게 알리기">
유지 관리 시간을 적어 [메시지를 게시](/ko/on-premises/user-guide/administrators/basic-management#post-a-message)합니다.
</Step>

<Step id="click-close-editor" title="Close Editor 클릭하기">
이름과 달리 이 버튼은 사이트 거의 전체를 닫습니다. 관리 패널을 제외한 모든 페이지에 **Maintenance**가 표시되며, **Projects**, **Account Settings**, **Templates**, 로그인 페이지도 포함됩니다. **Manage Users**와 **Project/Object Lookup**은 계속 작동합니다.

<Frame caption="편집기가 닫혀 있는 동안 사용자에게 보이는 화면">
  <img src="/images/on-premises/basic-management-closed-page.png" alt="인스턴스가 현재 유지 관리 중이라고 알리는 Maintenance 페이지" />
</Frame>

이미 편집기를 열어 둔 사용자는 연결된 상태로 유지됩니다. 계속 입력할 수 있고 변경 내용도 유지되지만, **Recompile**은 **Server Error**로 끝납니다.

이 페이지의 텍스트를 변경하려면 [유지 관리 페이지](/ko/on-premises/configuration/overleaf-toolkit/branding#maintenance-page)를 참고하세요.
</Step>

<Step id="click-disconnect-all-users" title="Disconnect all users 클릭하기">
편집기에 있는 사용자에게 **Please wait** 대화 상자가 표시되며 10초부터 카운트다운합니다. 그런 다음 페이지가 새로 고쳐지고 **Maintenance**가 표시됩니다.

<Frame caption="편집기에 있는 사용자에게 보이는 화면">
  <img src="/images/on-premises/basic-management-disconnect-dialog.png" alt="편집기가 8초 후 자동으로 새로 고쳐진다고 알리는 Please wait 대화 상자와 그 뒤의 편집기" />
</Frame>

먼저 편집기를 닫으세요. 그렇지 않으면 새로 고침 후 사용자가 곧바로 편집기로 돌아옵니다.
</Step>

<Step id="do-the-maintenance-then-click-reopen-editor" title="유지 관리를 수행한 다음 Reopen Editor 클릭하기">
모든 페이지가 즉시 다시 작동합니다. 사용자는 페이지를 새로 고쳐 작업을 계속합니다.
</Step>
</Steps>

<Warning>

로그인 페이지도 닫히므로 편집기를 다시 열 때까지 로그인 상태를 유지하세요. 접근이 막혔다면 인스턴스를 다시 시작하세요. 닫힌 상태는 메모리에만 유지되므로 다시 시작하면 편집기가 다시 열립니다.

</Warning>

<Info>

복제본이 여러 개인 Kubernetes에서 **Close Editor**는 요청을 처리한 복제본만 닫습니다. 대신 [유지 관리 모드](/ko/on-premises/configuration/kubernetes/branding#maintenance-mode)를 사용하세요.

</Info>
