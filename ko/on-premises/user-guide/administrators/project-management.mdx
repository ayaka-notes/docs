**Admin**을 클릭한 다음 **Project/Object Lookup**을 클릭합니다. 목록에는 모든 사용자의 프로젝트가 표시됩니다. **Projects** 옆의 **Templates** 탭에는 게시된 템플릿이 나열됩니다. [템플릿 관리](/on-premises/user-guide/administrators/template-management)를 참고하세요.

## 프로젝트 찾기 {#find-a-project}

**Search by project name, ID, owner or link**에 입력합니다. 링크는 프로젝트 주소나 공유 링크 중 하나일 수 있습니다. 목록을 좁히려면 **Status** 필터를 사용합니다. 정렬하려면 **Title** 또는 **Last modified**를 클릭합니다.

삭제된 프로젝트는 결과에 나타나지 않습니다. 검색이 삭제된 프로젝트와도 일치하면 표 위에 안내가 표시됩니다(예: **Found 1 matching deleted projects**). 보려면 **Display deleted projects**를 클릭합니다.

## 프로젝트 상태 {#project-status}

모든 프로젝트에는 하나의 상태가 있으며, **Status** 필터에는 상태별 프로젝트 수가 표시됩니다.

<Frame caption="Status 필터">
  <img src="/images/on-premises/project-management-status-filter.png" alt="All, Active, Archived, Trashed, Deleted가 있는 Status 필터" />
</Frame>

| 상태 | 의미 |
| --- | --- |
| **All** | 삭제되지 않은 모든 프로젝트. |
| **Active** | 일반 상태. |
| **Archived** | 소유자가 보관했습니다. 프로젝트는 그대로 남아 있으며 되돌릴 수 있습니다. |
| **Trashed** | 소유자가 휴지통으로 옮겼습니다. 프로젝트는 그대로 남아 있으며 되돌릴 수 있습니다. |
| **Deleted** | 소유자가 휴지통에서 삭제했거나, 관리자가 삭제했거나, 소유자 계정과 함께 삭제되었습니다. 관리자만 되돌릴 수 있습니다. |

프로젝트는 단계별로 상태를 거칩니다.

1. **Active, Archived, Trashed**는 소유자가 자신의 프로젝트 페이지에서 선택합니다. 소유자는 언제든지 되돌릴 수 있습니다. 휴지통에서 **Restore**하면 이전에 보관되어 있었더라도 항상 Active가 됩니다.
2. **Deleted**는 다음 단계입니다. 소유자는 휴지통에서만 삭제할 수 있고, 관리자는 세 상태 어디에서든 삭제할 수 있습니다.
3. **Restore**는 이전 상태와 관계없이 삭제된 프로젝트를 **Active**로 되돌리며, 이름 끝에 `(Restored)`가 붙습니다. 관리자만 할 수 있습니다. 소유자 계정도 삭제된 경우 먼저 계정을 복원하세요. 그렇지 않으면 대화 상자에 **The owner of this project is deleted: restore the owner first**가 표시됩니다.
4. **Delete permanently**는 마지막 단계이며 되돌릴 수 없습니다. 그 외에는 삭제된 프로젝트가 직접 제거할 때까지 남아 있습니다. 단, 인스턴스에 [`ENABLE_CRON_RESOURCE_DELETION`](/ko/on-premises/configuration/overleaf-toolkit/environment-variables)이 설정되어 있으면 90일 후에 제거됩니다.

<Info>

상태는 소유자만 따릅니다. 공동 작업자가 공유 프로젝트를 보관하거나 휴지통으로 옮기면 그 사람의 프로젝트 페이지에서만 이동하며, 여기의 상태는 바뀌지 않습니다.

</Info>

## 프로젝트에 대한 작업 {#actions-on-a-project}

| 아이콘 | 작업 | 기능 |
| --- | --- | --- |
| 열기 | **Open Project** | 새 탭의 편집기에서 프로젝트를 엽니다. |
| 폴더 | **Change project owner** | 프로젝트를 다른 사용자에게 넘깁니다. |
| 휴지통 | **Delete** | 프로젝트를 **Deleted**로 옮깁니다. |
| 화살표 | **Restore** | 삭제된 프로젝트를 되돌립니다. 삭제된 프로젝트에만 해당합니다. |
| X 표시 휴지통 | **Delete permanently** | 삭제된 프로젝트를 영구히 제거합니다. 삭제된 프로젝트에만 해당합니다. |

### 소유자 변경하기 {#change-the-owner}

폴더 아이콘을 클릭하고 이름이나 이메일을 입력한 뒤 사용자를 선택하고 **Change project owner**를 클릭합니다. 대화 상자는 이 작업을 되돌릴 수 없으며, 새 소유자에게 알림이 가고 새 소유자가 프로젝트의 접근 설정을 변경할 수 있다고 경고합니다. 비활성화된 계정은 후보에 나타나지 않습니다. 선택한 뒤 텍스트를 바꾸면 선택이 취소되므로 사용자를 다시 선택하세요.

<Frame caption="프로젝트 소유자 변경">
  <img src="/images/on-premises/project-management-change-owner.png" alt="경고와 선택된 새 소유자가 표시된 Change project owner 대화 상자" />
</Frame>

사용자의 모든 프로젝트를 한 번에 옮기려면 [사용자의 프로젝트 이전](/ko/on-premises/user-guide/administrators/user-management#transfer-a-users-projects)을 참고하세요.

### 삭제, 복원 또는 영구 삭제 {#delete-restore-or-permanently-delete}

휴지통 아이콘을 클릭한 다음 **Delete**를 클릭합니다. 프로젝트를 다시 찾으려면 **Status** 필터에서 **Deleted**를 선택합니다.

<Frame caption="삭제된 프로젝트">
  <img src="/images/on-premises/project-management-deleted.png" alt="Restore 및 Delete permanently 아이콘이 있는 목록의 삭제된 프로젝트" />
</Frame>

되돌리려면 화살표 아이콘을 클릭한 다음 **Restore**를, 제거하려면 X 표시 휴지통을 클릭한 다음 **Delete permanently**를 클릭합니다.

<Frame caption="프로젝트 영구 삭제">
  <img src="/images/on-premises/project-management-purge.png" alt="작업을 되돌릴 수 없다고 경고하는 Delete permanently 대화 상자" />
</Frame>

### 여러 프로젝트를 한 번에 변경하기 {#change-several-projects-at-once}

목록에서 프로젝트를 선택합니다. 검색 옆에 **Download**, **Change project owner**, **Delete** 버튼이 나타납니다. **Download**는 선택한 프로젝트를 하나의 `.zip` 파일로 저장합니다. **Change project owner**에서는 선택한 프로젝트의 현재 소유자를 고를 수 없습니다. **Deleted** 보기에서는 버튼이 **Restore**와 **Delete permanently**입니다.

<Frame caption="일괄 작업">
  <img src="/images/on-premises/project-management-bulk.png" alt="선택된 프로젝트 두 개와 Download, Change project owner, Delete 버튼" />
</Frame>

## 프로젝트 페이지 {#the-project-page}

프로젝트 제목을 클릭하면 해당 페이지가 열립니다. 상단에는 프로젝트를 편집, 열기, 다운로드, 삭제하는 아이콘이 있습니다. 페이지에는 다섯 개의 탭이 있습니다.

### 개요 {#overview}

프로젝트의 세부 정보와 설정입니다. 연필 아이콘을 클릭하면 **Name**, **Link sharing**, **Compiler**, **TeX Live version**, **Main document**를 변경하거나 **Change project owner**를 클릭할 수 있습니다. 그런 다음 **Save**를 클릭합니다.

<Frame caption="프로젝트 편집">
  <img src="/images/on-premises/project-management-edit.png" alt="편집 모드의 Overview 탭" />
</Frame>

### 파일 트리 {#file-tree}

프로젝트의 파일과 폴더이며, 읽기 전용입니다.

### 구성원 {#members}

접근 권한이 있는 사람으로, 소유자, 공동 작업자, 대기 중인 초대가 표시됩니다. 변경하려면 연필 아이콘을 클릭합니다.

* 공동 작업자에게 **Editor**, **Reviewer**, **Viewer** 중 하나를 선택합니다. 변경 사항은 즉시 적용됩니다.
* 공동 작업자 옆의 휴지통을 클릭한 다음 **Remove access**를 클릭합니다.
* 대기 중인 초대의 경우 봉투를 클릭하면 **Resend invite**, 휴지통을 클릭하면 **Revoke Invite**입니다.

완료되면 **Done**을 클릭합니다. 여기서는 소유자를 변경할 수 없습니다. **Overview** 탭의 **Change project owner**를 사용하세요.

<Frame caption="프로젝트 구성원 변경">
  <img src="/images/on-premises/project-management-members.png" alt="역할 메뉴, 대기 중인 초대, 작업 아이콘이 있는 편집 모드의 Members 탭" />
</Frame>

### 삭제된 파일 {#deleted-files}

프로젝트에서 제거된 파일입니다. 파일 옆의 화살표 아이콘을 클릭한 다음 **Restore file**을 클릭합니다. 이름에 날짜가 붙은 사본이 프로젝트 루트 폴더에 생성되고, 해당 행에 사본의 이름이 표시됩니다. 삭제된 파일은 목록에 그대로 남습니다.

사본은 페이지를 새로 고친 뒤 **File tree** 탭에 나타납니다.

</Frame>
