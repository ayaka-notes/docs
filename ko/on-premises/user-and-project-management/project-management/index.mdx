### 프로젝트 감사 로그 보기

관리자는 각 프로젝트의 **Audit Log**를 볼 수 있습니다. 이 감사 로그에는 링크 공유가 비공개/토큰 기반 간에 변경된 시점, 초대가 전송/수락된 시점, 사용자가 토큰을 사용해 프로젝트에 참여한 시점 등의 이벤트가 표시됩니다. 관리자는 **Your Instance** -> **Admin** -> **Manage Users**에서 다음과 같이 프로젝트별로 이 로그를 볼 수 있습니다:

* 사용자를 검색합니다
* **Projects** 탭을 클릭합니다
* 프로젝트를 선택합니다
* (i) 아이콘을 클릭합니다
* **Audit Log** 탭을 클릭합니다

프로젝트가 (이메일 주소를 사용해) 지정된 공동 작업자와 공유된 경우, 수신자가 참여하면 Share 모달에 권한과 함께 표시되며 프로젝트 소유자가 볼 수 있습니다. 이 정보는 관리자가 관리자 패널에서 해당 프로젝트의 Project Info 탭을 볼 때도 표시됩니다.

### 삭제된 문서 복구

1. 관리자 자격 증명으로 로그인합니다
2. **Admin**을 클릭하고 **Manage Users**를 선택합니다
3. 검색 필드에 문서를 복원할 사용자의 이메일을 입력합니다
4. 반환된 결과 목록에서 해당 이메일 주소를 클릭하여 사용자 정보 페이지를 엽니다
5. **Projects** 탭을 클릭하고 검색 필드를 사용해 프로젝트를 검색합니다
6. 프로젝트 이름 옆의 정보 아이콘을 클릭하여 **Project Info**를 엽니다
7. **Deleted Docs** 탭을 클릭합니다
8. 삭제된 문서 옆의 **Undelete** 버튼을 클릭하여 사용자 프로젝트로 복원합니다.

복원된 파일은 `FILENAME-TIMESTAMP.EXTENSION` 형식을 따릅니다. 예를 들어 `main.tex`의 복원된 버전은 `main-2024-02-23-130441542.tex`라는 파일 이름으로 프로젝트 루트에 복원됩니다.

### 프로젝트 소유권 이전

Server Pro의 관리자 패널에는 프로젝트별 전용 페이지가 있습니다. "/admin/user"에서 사용자를 검색한 다음 **Projects** 탭으로 이동하여 목록에서 프로젝트를 찾고 정보 아이콘을 클릭하거나, 알고 있는 project-id로 [**https://your-instance-url/admin/project/**](https://your-instance-url/admin/project/) 페이지로 직접 이동할 수 있습니다. 프로젝트 정보 페이지에서 **Transfer Ownership** 버튼을 찾을 수 있으며, 이 버튼을 누르면 임의의 사용자를 새 소유자로 지정할 수 있는 모달이 열립니다. 새 소유자는 해당 프로젝트의 기존 공동 작업자일 필요가 없습니다.

<Info>

소유권 이전 과정에서 이전 소유자는 프로젝트에 대한 읽기 및 쓰기 권한을 가진 공동 작업자로 추가된다는 점에 유의하세요.

</Info>

### 프로젝트 컴파일 시간 제한 업데이트

현재 프로젝트의 기본 컴파일 시간 제한은 180초로 설정되어 있습니다. 이 값은 변경할 수 있으며 두 단계의 과정이 필요합니다.

먼저 **config/variables.env** 파일을 편집하여 `COMPILE_TIMEOUT` 환경 변수를 추가하고 값을 원하는 시간 제한(초)으로 설정합니다. 예를 들어 5분으로 설정하려면 `COMPILE_TIMEOUT=300`입니다.

<Danger>

시간 제한을 10분 이상으로 늘리는 것은 의미가 없습니다. 그렇게 하면 애플리케이션의 다른 구성 요소에서 시간 초과가 발생할 가능성이 높습니다.

</Danger>

이 변경을 완료한 후에는 `bin/up -d` 명령을 실행하여 **sharelatex** 컨테이너를 다시 생성해야 합니다.

이 환경 변수를 설정하면 새 사용자에 대해서만 시간 제한 값이 업데이트되며, 이 값은 사용자가 처음 생성될 때 채워지므로 기존 사용자에게는 소급 적용되지 **않습니다**.

기존 사용자의 시간 제한을 조정하려면 데이터베이스의 각 사용자 레코드를 변경해야 합니다. 이 작업은 매우 신중하게 수행할 것을 권하며, 변경하기 전에 일관된 백업을 만들어 두는 것을 권장합니다.

백업 수행에 관한 정보는 [여기](/ko/on-premises/maintenance/data-and-backups)에서 확인할 수 있습니다.

모든 기존 사용자의 컴파일 시간 제한 값을 업데이트하려면 Docker 호스트에서 다음 셸 명령을 실행해야 합니다:

```bash wrap
echo 'db.users.updateMany({}, {$set: {"features.compileTimeout": <value>}})' | docker exec -i mongo mongosh --quiet localhost/sharelatex
```

위 쿼리의 `<value>`를 원하는 시간 제한 값(초)으로 바꿔야 합니다.

명령이 완료되면 수정된 레코드 수와 함께 확인 메시지가 표시됩니다. 그런 다음 exit를 입력하고 Enter 키를 눌러 호스트 셸로 돌아갈 수 있습니다.

### 프로젝트 접근 추적

다음 명령으로 누가 언제 프로젝트를 불러왔는지 확인할 수 있습니다:

```bash wrap
docker exec sharelatex bash -c 'grep "join project request" /var/log/overleaf/web.log'
```

이 명령은 `timestamp`, `user_id`, `project_id`를 모두 제공합니다.
