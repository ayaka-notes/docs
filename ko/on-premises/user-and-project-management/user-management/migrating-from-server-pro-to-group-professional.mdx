---
title: Server Pro에서 Group Professional로 마이그레이션
icon: rectangle-pro
noindex: true
---

자체 호스팅 Server Pro 인스턴스에서 새로운 클라우드 기반 Overleaf Group Professional 구독으로 전환하는 것은 큰 변화이므로, 이 과정을 최대한 원활하게 진행할 수 있도록 다음 안내를 준비했습니다.

일반적으로 갱신일부터 시작하는 3개월의 중첩 기간을 제안합니다. 이는 다음을 의미합니다:

* 기존 Server Pro 인스턴스와 새 Group Professional 구독이 모두 완전히 활성화된 상태로 유지됩니다.
* 기술 팀은 Group Professional 구독을 설정하고 온프레미스 Server Pro 배포의 향후 방향을 결정할 시간을 계획할 수 있습니다.
* 무엇보다도 사용자는 프로젝트를 새 Overleaf Group Professional 플랫폼으로 복사할 충분한 시간을 갖게 됩니다.

이 간단한 가이드는 마이그레이션의 주요 단계를 안내합니다. 시작해 봅시다!

<Steps>
<Step title="1단계: 설정 및 구성">
(링크: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-1-setup-and-configuration)

* Overleaf가 Group Professional 구독을 생성하고 Lead Administrator를 추가합니다.
* 그룹 관리자는 [Managed Users](https://docs.overleaf.com/groups/user-management/managed-user-accounts)를 활성화하고, [Single Sign-On (SSO)](https://docs.overleaf.com/groups/overleaf-group-single-sign-on/setting-up-group-sso)을 구성하고, [최종 사용자를 초대](https://docs.overleaf.com/groups/user-management/how-to-add-and-remove-users)할 수 있습니다.

<Warning>

Managed Users 활성화와 SSO 구현은 FedRAMP® LI-SaaS 준수를 위한 필수 단계입니다. 조직에서 FedRAMP 준수가 필요한 경우 최종 사용자를 초대하기 전에 Managed Users와 SSO를 설정하세요.

</Warning>
</Step>

<Step title="2단계: 사용자 마이그레이션 및 데이터 관리">
(링크: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-2-user-migration-and-data-management)

이 기간이 주요 마이그레이션 기간이며 다음과 같은 책임이 있습니다:

#### 최종 사용자

* 사용자는 Server Pro 인스턴스에서 보관하려는 프로젝트를 [overleaf.com](http://overleaf.com/)의 새 계정으로 마이그레이션해야 합니다. 이 과정은 Server Pro에서 [프로젝트를 내보내고](https://www.overleaf.com/learn/how-to/Exporting_your_work_from_Overleaf) [overleaf.com](http://overleaf.com/)의 계정에 [업로드](https://www.overleaf.com/learn/how-to/Uploading_a_project)하는 것으로 이루어집니다. 아직 [overleaf.com](http://overleaf.com/) 계정이 없는 사용자는 [overleaf.com/register](http://overleaf.com/register)에서 가입할 수 있습니다.

<Warning>

이 내보내기 절차를 통해서는 프로젝트 소스 코드(LaTeX 및 바이너리 파일)만 전송됩니다. 기존 프로젝트 설정, 공유 설정, 댓글, 변경 내용 추적 등은 전송되지 않습니다. 사용자는 마이그레이션 후 공동 작업자를 다시 초대해야 합니다.

</Warning>

#### 기술 담당자

* 이 단계에서 기술 팀은 마이그레이션 이후 온프레미스 Server Pro 인스턴스와 그 데이터를 어떻게 처리할지 계획해야 합니다.
* <strong>데이터 백업:</strong> 서비스를 종료하기 전에 모든 프로젝트를 내보내 아카이브를 만들어 두면, 작업을 마이그레이션하거나 다운로드하는 것을 잊은 사용자를 도울 수 있습니다. 안내: https://docs.overleaf.com/on-premises/maintenance/data-and-backups/exporting-projects
* <strong>Server Pro 서비스 종료:</strong> 마이그레이션 기간이 끝나고 라이선스 키가 비활성화되면, Server Pro 인스턴스 자체에 대해 두 가지 주요 옵션이 있습니다(다음 단계 참조).
</Step>

<Step title="Server Pro 서비스 종료 옵션">
<Steps>
<Step title="Server Pro 완전히 제거">
제거하면 Server Pro의 서비스가 종료되고 소프트웨어가 완전히 삭제됩니다.
</Step>

<Step title="Community Edition으로 전환">
전환하면 인스턴스가 Server Pro에서 Community Edition으로 변환되면서 사용자와 프로젝트 데이터베이스가 전체 프로젝트 기록과 함께 보존됩니다.
</Step>
</Steps>

<Info>

Community Edition에는 [Sandboxed Compiles](https://docs.overleaf.com/on-premises#overview-of-server-pro-and-community-edition)와 [LDAP](/ko/on-premises/configuration/overleaf-toolkit/authentication/ldap-authentication)/[SAML](/ko/on-premises/configuration/overleaf-toolkit/authentication/saml-authentication)이 포함되지 않습니다. 기본 인증(사용자 이름/비밀번호)으로 되돌려야 하는 경우 다음을 참조하세요: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-to-ldap-or-saml#going-the-other-way-switching-from-ldap-saml-back-to-native-authentication

Server CE와 Server Pro의 비교는 다음을 참조하세요: https://docs.overleaf.com/on-premises/welcome/server-pro-vs.-community-edition

</Info>
</Step>

<Step title="3단계: Server Pro 서비스 종료">
(링크: https://docs.overleaf.com/on-premises/user-and-project-management/user-management/migrating-from-server-pro-to-group-professional#phase-3-server-pro-decommission)

* Overleaf 팀이 Server Pro 라이선스 키를 공식적으로 비활성화하고 완료되면 확인 메시지를 보냅니다.
* 그 시점에 위에서 설명한 서비스 종료 작업 중 하나를 수행하세요: Server Pro를 완전히 제거하거나 Community Edition으로 전환합니다.
</Step>
</Steps>

위에서 참조한 추가 자료와 링크는 변경되지 않습니다.
