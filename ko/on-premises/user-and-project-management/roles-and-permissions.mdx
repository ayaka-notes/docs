### 계정

자신의 계정을 관리하는 관점에서는 **모든** 사용자가 일반 사용자로 취급됩니다. `Site Admins`와 `Template Users`는 추가 권한을 **받지 않습니다**. 다만 인증 방식에 따라 일반 사용자가 수행할 수 있는 작업에는 제한이 있습니다.

#### 설정

**인증 유형: 내부 계정 | SSO (SAML/LDAP)**

| 작업                                      | 내부 계정 | SSO (SAML/LDAP) |
| ----------------------------------------- | --------: | --------------: |
| 계정 정보 업데이트                        |        예 |          아니요 |
| 비밀번호 변경                             |        예 |          아니요 |
| Git bridge 인증 토큰 생성                 |        예 |              예 |
| Git bridge 인증 토큰 삭제                 |        예 |              예 |
| 세션 관리                                 |        예 |              예 |

<Info>

Git Bridge 통합은 Server Pro에서**만** 사용할 수 있습니다. 자세한 내용은 [Server Pro vs. Community Edition](/ko/on-premises/readme/ayakaleaf-pro-vs-server-pro)을 확인하세요.

</Info>

### 편집기 IDE

Overleaf 편집기 IDE 관점에서는 `Project Owner`, `Editor`, `Reviewer`, `Viewer`, `Site Administrator`, `Template User` 중 하나의 역할을 가질 수 있습니다.

<Info>

Server Pro와 Community Edition에서는 프로젝트에 대한 익명 **읽기 전용** 및 **읽기-쓰기** 접근을 제공하는 기능을 지원합니다.

이에 대한 자세한 내용은 [여기](/ko/on-premises/configuration/overleaf-toolkit/environment-variables)에서 `OVERLEAF_ALLOW_PUBLIC_ACCESS` 및 `OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING` 환경 변수를 확인하세요.

</Info>
