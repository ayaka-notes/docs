<Info>

Ayakaleaf Pro는 Overleaf Community Edition의 강화된 구현으로, Server Pro의 모든 기능을 _**무료 프리미엄**_ 기능으로 제공합니다. [https://www.overleaf.com/](https://www.overleaf.com/)에서 제공되는 Overleaf Common과 달리 컴파일 시간 제한이 없고, 사용자 수에 대한 라이선스 요구 사항이 없으며, 데이터를 완전히 직접 호스팅하여 절대적인 보안을 보장할 수 있습니다.

Overleaf Server Pro는 공식 지원이 포함된 Overleaf의 상용 자체 호스팅 배포판입니다. Server Pro에 대한 자세한 내용은 [Server Pro](https://www.overleaf.com/for/enterprises/when-to-use-overleaf-on-premises-vs-in-the-cloud)를 방문하세요.

</Info>

<Warning>

Overleaf Community Edition은 **모든** 사용자를 신뢰할 수 있는 환경에서 사용하도록 만들어졌습니다. Sandbox Compiles를 사용할 수 없기 때문에 Community Edition은 사용자 격리가 필요한 상황에는 적합하지 **않습니다**.

샌드박스 없이 실행되는 LaTeX 컴파일은 컨테이너와 동일한 권한으로 실행되므로, 컨테이너의 파일 시스템, 네트워크, 환경 변수에 접근할 수 있습니다. 이는 데이터 노출이나 시스템 침해의 위험을 초래합니다. 샌드박스가 없는 컴파일은 완전히 신뢰할 수 있는 환경에서만 사용해야 하며, 다중 사용자 또는 프로덕션 배포에서는 Sandbox Compiles를 강력히 권장합니다.

Sandbox Compiles에 대한 자세한 내용은 [문서](/ko/on-premises/configuration/overleaf-toolkit/sandboxed-compiles)를 확인하세요.

</Warning>

### 커뮤니티 지원

자체 호스팅 Overleaf 인스턴스를 사용하는 분들을 위한 지원은 GitHub [Issues](https://github.com/ayaka-notes/overleaf-pro/issues)를 통해 커뮤니티에서 제공합니다.

지원되는 상태를 유지하려면 아래 명령의 출력을 릴리스 노트에 게시된 Image ID와 비교하여 실행 중인 Overleaf 버전을 확인할 수 있습니다.

```bash
docker inspect --format '{{.Image}}' sharelatex | awk -F: '{print substr($2, 1, 12)}'
```
