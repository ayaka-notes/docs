Ayakaleaf Pro에 관해 자주 묻는 질문에 대한 답변을 모았습니다.

### 기본 질문

<Accordion title="Q01: Ayakaleaf Pro는 무료 체험판인가요? 라이선스가 필요한가요?">

아니요. Ayakaleaf Pro는 완전히 무료로 사용할 수 있습니다. 체험판이 아니며 라이선스도 필요하지 않습니다.

</Accordion>

<Accordion title="Q02: Ayakaleaf Pro에는 Overleaf Server Pro의 모든 기능이 포함되어 있나요?">

네. Ayakaleaf Pro에는 Git-Bridge 통합을 포함한 Overleaf Server Pro의 모든 기능이 포함되어 있습니다. 또한 Overleaf SaaS 플랫폼의 일부 기능도 포함되어 있습니다. 저희는 Ayakaleaf Pro를 계속 개발하고 개선하고 있습니다.

</Accordion>

<Accordion title="Q03: Overleaf Server Pro의 비용은 얼마인가요?">

Overleaf Server Pro는 사용자당 연간 약 \$300입니다. 최소 10개의 라이선스가 필요하므로 배포 비용은 연간 약 \$3,000부터 시작합니다. 미국의 소규모 공공 계약에서는 사용자당 연간 약 \$320–\$370의 비용이 나타납니다. 따라서 Server Pro는 특히 소규모 팀에게 비쌉니다. 문서화된 구매 사례와 가격은 [#information-and-price-about-overleaf-server-pro](/ko/on-premises#information-and-price-about-overleaf-server-pro  "mention")를 참조하세요.

</Accordion>

<Accordion title="Q04: Overleaf Server Pro에 GitHub Sync나 AI 기능이 포함되지 않은 이유는 무엇인가요?">

Overleaf Server Pro는 정부 기관에서 흔히 사용됩니다. 이들은 사설 네트워크에 배포하고 접근을 엄격히 통제합니다. 민감한 데이터를 보호하기 위해 포함된 기능은 제3자 서비스와 데이터를 주고받지 않습니다. GitHub Sync, AI 또는 이와 유사한 연결 기능이 필요하다면 Overleaf는 SaaS 플랫폼 구독을 권장합니다.

</Accordion>

<Accordion title="Q05: Ayakaleaf Pro는 안전하고 신뢰할 수 있나요?">

Ayakaleaf Pro는 오픈 소스입니다. 저희는 Codex Security 같은 도구로 코드를 검토하여 보안과 신뢰성을 강화합니다. 제3자 데이터 동기화를 활성화하지 않으면 데이터는 사용자의 서버에 그대로 남습니다. Ayakaleaf Pro에는 데이터를 외부로 전송하는 텔레메트리가 없습니다.

</Accordion>

<Accordion title="Q06: Ayakaleaf Pro는 장기적으로 유지 관리되나요?">

저희는 이 프로젝트를 장기적으로 유지 관리하기 위해 최선을 다할 것입니다.

</Accordion>

<Accordion title="Q07: Ayakaleaf Pro는 라이선스를 준수하나요?">

Ayakaleaf Pro는 커뮤니티 포크입니다. 코드와 통합된 기능은 커뮤니티 기여에서 비롯되었습니다. AGPL v3 라이선스로 배포됩니다. 배포 환경이 이 라이선스의 요구 사항을 충족하면 라이선스를 준수할 수 있습니다.

</Accordion>

<Accordion title="Q08: 프로젝트 이름이 Ayakaleaf Pro인 이유는 무엇인가요?">

이 프로젝트는 원래 2024년에 Overleaf Pro라는 이름이었습니다. 한동안 개발이 중단되었다가 2025년 말에 재개되었습니다. 2026년 1분기에 Overleaf는 AI 기능이 포함된 구독 플랜의 이름을 Pro로 변경했습니다. 커뮤니티 피드백에서도 Overleaf Pro라는 이름이 상표 및 사칭 위험을 초래할 수 있다는 지적이 있었습니다. 사용자가 이 프로젝트를 공식 프로젝트로 오해할 수도 있었습니다.

이러한 혼동을 피하기 위해 프로젝트 이름을 Ayakaleaf Pro로 변경했습니다. 이 이름은 "Ayaka-notes Overleaf Pro"로 읽을 수 있습니다. 메인테이너는 5년 이상 전인 학생 시절부터 Overleaf 커뮤니티 개발에 기여해 왔습니다. 이러한 경험이 장기적인 유지 관리 약속을 뒷받침합니다.

</Accordion>

<Accordion title="Q09: Ayakaleaf Pro는 최근 AI로 만들어진 LaTeX 에디터들과 무엇이 다른가요?">

2026년부터 오픈 소스 커뮤니티에서는 OpenAI Prism을 비롯해 AI로 만들어진 많은 LaTeX 에디터가 출시되었습니다. Ayakaleaf Pro는 데이터와 서비스를 사용자 자신의 서버에 유지합니다. 따라서 배포와 데이터를 직접 제어할 수 있습니다.

많은 실험적인 커뮤니티 에디터는 확립된 장기 유지 관리 계획이 없습니다. 제3자 LaTeX 컴파일 플랫폼도 사용자 기반이나 수익이 부족하면 운영을 중단할 수 있습니다. Ayakaleaf Pro는 모든 소스 코드를 제공하며 모든 서비스를 셀프 호스팅할 수 있게 해 줍니다. 유지 관리가 중단되더라도 기존 셀프 호스팅 서비스는 계속 실행될 수 있습니다.

</Accordion>

### LaTeX

<Accordion title="Q01: 사용자의 LaTeX 프로젝트 컴파일은 격리되나요? Shell Escape가 활성화되어 있나요?">

Sandbox Compiles를 활성화하면 각 사용자의 컴파일은 별도의 Docker 컨테이너에서 실행되며 다른 사용자의 컴파일과 격리됩니다. Sandbox Compiles에서는 Shell Escape가 기본적으로 활성화되어 있습니다.

</Accordion>

<Accordion title="Q02: Sandbox Compiles 이미지는 신뢰할 수 있나요? 컴파일이 실패할 수 있나요?">

저희는 지난 3년간 Sandbox Compiles용 TeX Live Full 이미지를 개선해 왔습니다. 대부분의 경우 overleaf.com에서 컴파일되는 프로젝트는 Ayakaleaf Pro에서도 올바르게 컴파일됩니다. 필요한 글꼴을 사용할 수 없는 경우 해당 글꼴을 프로젝트에 직접 업로드하세요.

</Accordion>
