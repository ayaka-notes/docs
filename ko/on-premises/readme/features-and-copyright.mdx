저희는 저작권을 존중하므로, 이 프로젝트에서 사용된 모든 기능과 코드를 여기에 나열합니다. 이 페이지에서는 Ayakaleaf Pro의 새로운 기능과 관련 코드의 저작권 정보를 제공합니다.

별도로 명시하지 않는 한, 코드 리뷰와 PR 리뷰에는 OpenAI의 Codex를 사용합니다. 이 과정에서 많은 보안 문제를 수정했으며, 이에 진심으로 감사드립니다. 자세한 내용은 [ayaka-notes/ayakaleaf-pro/pull](https://github.com/ayaka-notes/ayakaleaf-pro/pulls)을 참조하십시오.

### 개요

수년간 많은 커뮤니티 개발자들이 Overleaf Community Edition을 개선하기 위해 큰 노력을 기울여 왔습니다. 그들은 다음과 같습니다.

* [https://github.com/ertuil/overleaf](https://github.com/ertuil/overleaf)
* [https://github.com/AllanChain/lcpu-overleaf](https://github.com/AllanChain/lcpu-overleaf)
* [https://github.com/yu-i-i/overleaf-cep/](https://github.com/yu-i-i/overleaf-cep/)
* [https://github.com/ayaka-notes/overleaf](https://github.com/ayaka-notes/overleaf)
* [https://github.com/davrot/overleaf\_with\_admin\_extension](https://github.com/davrot/overleaf_with_admin_extension)
* [https://github.com/overleaf/overleaf/pull/1447](https://github.com/overleaf/overleaf/pull/1447) (GitHub 연동)
* [https://github.com/overleaf/overleaf/pull/1385](https://github.com/overleaf/overleaf/pull/1385) (Typst 지원)

저희 프로젝트에서 관련 코드를 사용했을 수 있으며, 이들에게 감사의 뜻을 전합니다.

#### 기능 01: 템플릿 시스템

이 기능은 주로 [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep)에서 개발되었습니다. 저희는 기능 향상을 위해 일부 코드를 수정하여 다음을 할 수 있도록 했습니다.

* 템플릿 페이지에서 템플릿을 직접 다운로드합니다.
* 템플릿에 해당하는 프로젝트를 엽니다.
* 더 높은 품질의 표지 이미지로 (더 짧은 시간에) 변환합니다.

#### 기능 03: ​Git 연동​

이 기능은 [ayaka-notes/overleaf-pro](https://github.com/ayaka-notes/overleaf-pro)에서 개발했습니다. Overleaf는 git-bridge라는 공식 구성 요소를 제공하며, [여기](https://github.com/overleaf/overleaf/tree/main/services/git-bridge)에서 확인할 수 있습니다.

저희는 git-bridge와 Overleaf 사이의 커넥터를 구현했을 뿐이며, 이는 Overleaf가 자사 SaaS 플랫폼에서 하는 것과 동일합니다.

#### 기능 05: 관리자 패널

<Warning>

시스템에 사용자나 프로젝트가 1000개 이상 있는 경우, 관리자 패널에는 최근 1000개의 사용자 또는 프로젝트만 표시됩니다. 특정 사용자나 프로젝트를 찾으려면 검색 패널을 사용하십시오.

</Warning>

이 기능은 주로 [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep)에서 개발되었습니다. 저희는 기능 향상을 위해 일부 코드를 수정하여 다음을 할 수 있도록 했습니다.

* 사용자가 1000명을 초과할 때 백엔드로 사용자를 검색합니다.
* 프로젝트가 1000개를 초과할 때 백엔드로 프로젝트를 검색합니다.
* 프로젝트 관리자 패널에서 프로젝트를 직접 엽니다.
* 관리자 패널에서 사용자의 컴파일 시간 제한을 확인하고 조정합니다.
* 관리자 패널에서 사용자의 비밀번호를 직접 재설정합니다.
* 기타 개선 사항...

#### 기능 07: 외부 URL

이 기능은 주로 [yu-i-i/overleaf-cep](https://github.com/yu-i-i/overleaf-cep)에서 개발되었습니다. CEP는 linked-url-proxy라는 외부 서비스를 구현했으며, 이를 통해 도메인/IP 제한을 적용하여 외부 파일을 안전하게 가져올 수 있습니다.

#### 기능 09: ARM 지원

GitHub Actions를 사용하여 x86 및 arm 아키텍처용 Docker 이미지를 빌드하고 게시합니다. 이미지를 다운로드하면 시스템에 따라 적절한 아키텍처가 자동으로 선택됩니다.

#### 기능 16: AI 채팅 및 LaTeX 오류 도우미

Ayakaleaf Pro는 AI 도우미를 제공합니다. AI 도우미는 프로젝트 문서와 현재 선택 영역을 컨텍스트로 사용하여 질문에 답하고 검토할 수 있는 편집을 제안하며, 오류 도우미는 LaTeX 컴파일 오류를 선택하면 그에 맞는 수정 사항을 제안합니다.
