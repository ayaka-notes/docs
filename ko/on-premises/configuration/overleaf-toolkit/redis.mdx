### 비밀번호 인증 활성화

외부 Redis 서비스를 사용 중이고 비밀번호를 제공해야 하는 경우, **config/variables.env** 파일에 `OVERLEAF_REDIS_PASS` 및 `REDIS_PASSWORD` 환경 변수를 설정한 뒤 `bin/up -d` 명령을 실행하여 **sharelatex** 컨테이너를 다시 생성하면 됩니다.

로컬 Redis 인스턴스를 실행 중인 경우, **redis** 서비스가 비밀번호 인증을 사용하여 시작되도록 구성해야 합니다. 위의 환경 변수를 설정한 후 다음 추가 단계도 완료해야 합니다.

**config/** 디렉터리에 다음 내용으로 **docker-compose.override.yml** 파일을 생성합니다.

```yaml title="config/docker-compose.override.yml"
services:
    redis:
        command: "redis-server --requirepass <YOUR-PASSWORD>"
```

<Warning>

AOF 지속성을 활성화한 경우 `command`에 `--appendonly yes`를 추가해야 합니다.

</Warning>

`bin/up -d`를 실행하여 컨테이너를 다시 생성합니다.

### Append-Only File 지속성 활성화

(원문: https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/redis#enabling-append-only-file-persistence)

Redis AOF(Append-Only File) 지속성은 서버가 받은 모든 쓰기 작업을 기록하여 데이터 내구성을 확실하게 보장하는 방법입니다. 데이터 세트의 특정 시점 복사본을 만드는 RDB 스냅샷과 달리, AOF는 데이터에 대한 모든 변경 사항의 완전한 기록을 유지합니다.

<Info>

RDB 비활성화는 선택 사항입니다. 일반적으로 두 가지 지속성 방식을 함께 사용하는 것이 권장됩니다. 프로덕션 환경에서 변경하기 전에 AOF와 RDB를 함께 실행할 때의 장단점을 검토하십시오.

</Info>

Redis에서 AOF 지속성을 활성화하는 방법에 대한 자세한 내용은 다음을 참조하십시오: [https://redis.io/docs/latest/operate/oss\_and\_stack/management/persistence/#how-i-can-switch-to-aof-if-im-currently-using-dumprdb-snapshotsarrow-up-right](https://redis.io/docs/latest/operate/oss_and_stack/management/persistence/#how-i-can-switch-to-aof-if-im-currently-using-dumprdb-snapshotsarrow-up-right)

1. 업그레이드를 위한 유지보수 기간을 계획합니다.
2. `bin/stop`으로 인스턴스를 중지하고 **config/** 및 **data/** 폴더를 백업합니다.
3. `bin/up`을 실행하여 인스턴스를 시작합니다.
4. `docker exec -it redis sh` 명령을 실행합니다.
5. `redis-cli` 명령을 실행하여 Redis 명령줄 인터페이스를 엽니다.
6. redis-cli에서 `config set appendonly yes` 명령을 실행합니다.
7. 이제 AOF 재작성이 데이터 저장을 완료할 때까지 기다려야 합니다. redis-cli에 `INFO persistence`를 입력하고 `aof_rewrite_in_progress`와 `aof_rewrite_scheduled`가 `0`이 될 때까지 기다린 다음, `aof_last_bgrewrite_status`가 `ok`인지 확인하면 됩니다.
8. `exit`를 입력하고 Enter 키를 눌러 redis-cli를 종료합니다.
9. `exit`를 입력하고 Enter 키를 눌러 redis 컨테이너에서 나옵니다.
10. ​`ls ./data/redis` 명령을 실행하여 **appendonly.aof** 파일이 있는지 확인합니다.
11. **config/overleaf.rc** 파일을 편집하여 `REDIS_AOF_PERSISTENCE` 환경 변수를 `false`에서 `true`로 변경합니다.
12. `bin/up -d`를 실행하고 애플리케이션이 정상적으로 작동하는지(프로젝트 에디터와 기록 창이 제대로 동작하는지) 확인합니다.
