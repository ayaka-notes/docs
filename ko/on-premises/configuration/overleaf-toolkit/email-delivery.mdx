Overleaf는 SMTP(Simple Mail Transfer Protocol)와 [Amazon SES(Simple Email Service)](https://aws.amazon.com/ses/)의 두 가지 방법으로 이메일 전송을 지원합니다. localhost에서 로컬 연결을 수신하는 이메일 서버가 활성화되어 있다면 SMTP를 사용할 수 있습니다.

## 계정당 여러 이메일 {#several-emails-per-account}

<Info>

이 기능은 [ayaka-notes/ayakaleaf-pro](https://github.com/ayaka-notes/ayakaleaf-pro)에서 개발했으며 v6.4.0부터 사용할 수 있습니다.

</Info>

이메일이 구성되어 있으면 설정 페이지에 단일 이메일 필드 대신 계정의 이메일 목록이 표시됩니다. 사용자는 해당 주소로 전송된 6자리 코드를 입력해 이메일을 추가하고, **Make primary**를 눌러 계정을 그 주소로 옮깁니다. 졸업 후 대학 주소처럼 주소를 잃게 될 때 이렇게 계정을 유지할 수 있습니다. 스크린샷이 포함된 단계는 [사용자 가이드](/ko/on-premises/user-guide/users/multiple-emails)에 있습니다.

* 기본 이메일만 로그인하고 비밀번호 재설정을 받을 수 있습니다. 보조 이메일은 둘 다 할 수 없으므로 다른 사람에게 재발급된 주소로 계정을 탈취할 수 없습니다.
* 이전 메일함이 폐쇄되기 전에 **Make primary**를 누르세요. 그 이후에는 관리자가 **Admin → Manage Users**에서 이메일을 변경해야 합니다.
* 한 번도 확인되지 않은 이전 기본 이메일은 다른 이메일이 기본이 되면 제거됩니다. 확인된 이메일은 사용자가 제거할 때까지 보조 이메일로 남습니다.
* LDAP 또는 SAML이 활성화되어 있으면 **Make primary**가 거부됩니다. 이러한 계정은 새 이메일로 로그인할 수 없기 때문입니다. [계정과 비밀번호](/ko/on-premises/configuration/overleaf-toolkit/authentication#accounts-and-passwords)를 참고하세요.
* 이메일 설정이 없으면 단일 이메일 필드가 유지됩니다.

## 구성 {#configuration}

이메일은 다음 환경 변수를 사용하여 구성합니다.

#### 발신자 구성 {#sender-configuration}

| 이름                          | 설명                                                                                                                                                 |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_FROM_ADDRESS` | <p>발신 주소. 예: <a href="mailto:support@mycompany.com">`'support@mycompany.com'`</a><br /><br />- <strong>필수</strong>: 예</p> |
| `OVERLEAF_EMAIL_REPLY_TO`     | 회신 주소. 예: `'noreply@mycompany.com'`                                                                                                             |

#### SMTP {#smtp}

| 이름                                    | 설명                                                                                                                                                                                                                                                                     |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST`              | 연결할 호스트 이름 또는 IP 주소입니다. Docker 컨테이너에서 접근할 수 있어야 합니다.                                                                                                                                                                                      |
| `OVERLEAF_EMAIL_SMTP_PORT`              | 연결할 포트입니다.                                                                                                                                                                                                                                                       |
| `OVERLEAF_EMAIL_SMTP_SECURE`            | `true`이면 서버에 연결할 때 TLS를 사용합니다. `false`이거나 설정하지 않으면 서버가 `STARTTLS` 확장을 지원하는 경우 TLS를 사용합니다. 대부분의 경우 포트 `465`에 연결한다면 이 값을 `true`로 설정하세요. 포트 `587` 또는 `25`라면 `false`로 유지하세요. |
| `OVERLEAF_EMAIL_SMTP_USER`              | SMTP 서버 인증에 사용할 사용자 이름입니다.                                                                                                                                                                                                                               |
| `OVERLEAF_EMAIL_SMTP_PASS`              | SMTP 사용자 이름에 해당하는 비밀번호입니다.                                                                                                                                                                                                                              |
| `OVERLEAF_EMAIL_SMTP_TLS_REJECT_UNAUTH` | `false`이면 자체 서명되었거나 유효하지 않은 TLS 인증서를 가진 TLS 서버에도 연결합니다.                                                                                                                                                                                   |
| `OVERLEAF_EMAIL_SMTP_IGNORE_TLS`        | `true`이고 `OVERLEAF_EMAIL_SMTP_SECURE`가 `false`이면, 서버가 `STARTTLS` 확장을 지원하더라도 TLS를 사용하지 않습니다.                                                                                                                                                    |
| `OVERLEAF_EMAIL_SMTP_NAME`              | `OVERLEAF_EMAIL_SMTP_HOST`가 IP 주소로 설정된 경우 TLS 검증에 사용할 선택적 호스트 이름이며, 기본값은 머신의 호스트 이름입니다.                                                                                                                                          |
| `OVERLEAF_EMAIL_SMTP_LOGGER`            | `true`이면 로그 메시지를 `web.log`에 출력합니다.                                                                                                                                                                                                                         |

#### Amazon SES SMTP 인터페이스 {#amazon-ses-smtp-interface}

Amazon SES SMTP 인터페이스를 사용한 이메일 전송에 대한 자세한 내용은 [여기](https://docs.aws.amazon.com/ses/latest/dg/send-email-smtp.html)에서 확인할 수 있습니다.

| 이름                       | 설명                                                                                       |
| -------------------------- | ------------------------------------------------------------------------------------------ |
| `OVERLEAF_EMAIL_SMTP_HOST` | 연결할 호스트 이름 또는 IP 주소입니다. Docker 컨테이너에서 접근할 수 있어야 합니다.        |
| `OVERLEAF_EMAIL_SMTP_PORT` | 연결할 포트입니다.                                                                         |
| `OVERLEAF_EMAIL_SMTP_USER` | SMTP 서버 인증에 사용할 사용자 이름입니다.                                                 |
| `OVERLEAF_EMAIL_SMTP_PASS` | SMTP 사용자 이름에 해당하는 비밀번호입니다.                                                |

#### Amazon SES API {#amazon-ses-api}

Amazon SES API를 사용한 이메일 전송에 대한 자세한 내용은 [여기](https://docs.aws.amazon.com/ses/latest/dg/send-email-api.html)에서 확인할 수 있습니다.

| 이름                                   | 설명                                        |
| -------------------------------------- | ------------------------------------------- |
| `OVERLEAF_EMAIL_AWS_SES_ACCESS_KEY_ID` | AWS SES를 사용하는 경우 액세스 키           |
| `OVERLEAF_EMAIL_AWS_SES_SECRET_KEY`    | AWS SES를 사용하는 경우 시크릿 키           |
| `OVERLEAF_EMAIL_AWS_SES_REGION`        | 설정하지 않으면 기본 리전은 US-EAST-1입니다 |

#### 인스턴스 역할을 사용하는 AWS SES {#aws-ses-with-instance-roles}

| 이름                    | 설명                                                                                                                             |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_EMAIL_DRIVER` | `ses`로 설정하면 이메일 시스템이 SES API 방식을 사용하며, 구성된 인스턴스 역할에 의존하여 이메일을 전송합니다.                   |

#### 사용자 지정 {#customisation}

| 이름                           | 설명                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OVERLEAF_CUSTOM_EMAIL_FOOTER` | <p>모든 이메일 끝에 추가되는 사용자 지정 HTML입니다. 예:<br /><br /><strong>예시</strong>: `"<div>This system is run by department x </div> <div> If you have any questions please look at our faq <a href='https://somwhere.com'>here</a></div>"`</p> |
