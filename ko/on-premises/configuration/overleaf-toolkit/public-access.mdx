계정이 없는 사람에게 Overleaf 인스턴스를 공개하는 방법은 세 가지입니다:

* [프로젝트 접근](/ko/on-premises/configuration/overleaf-toolkit/public-access#project-access  "mention"): 게스트가 로그인하지 않고 공유된 프로젝트 링크를 열 수 있도록 합니다
* [페이지 접근](/ko/on-premises/configuration/overleaf-toolkit/public-access#page-access  "mention"): 로그아웃한 방문자가 `/learn`, `/templates`, `/devs`와 같은 페이지를 탐색할 수 있도록 합니다
* [공개 가입](/ko/on-premises/configuration/overleaf-toolkit/public-access#public-registration  "mention"): 사용자가 직접 가입할 수 있도록 하며, 선택적으로 특정 이메일 도메인으로 제한할 수 있습니다

### 프로젝트 접근

<Info>

기본적으로 사용자가 프로젝트 공유 링크를 얻더라도 공동 프로젝트 편집 세션에 참여하려면 먼저 **로그인**해야 합니다.

</Info>

링크로 공유된 프로젝트에 대한 익명 접근을 허용하려면 아래 두 변수를 모두 설정하세요:

```dotenv title="config/variables.env"
OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING=true
OVERLEAF_ALLOW_PUBLIC_ACCESS=true
```

`OVERLEAF_ALLOW_ANONYMOUS_READ_AND_WRITE_SHARING`은 링크로 공유된 프로젝트에서 익명 읽기/쓰기를 활성화합니다.

`OVERLEAF_ALLOW_PUBLIC_ACCESS`는 인증되지 않은 사용자가 로그인 페이지로 리디렉션되는 것을 방지합니다.

`bin/up`으로 컨테이너를 다시 생성합니다. 그런 다음 시크릿 창에서 링크 공유 URL을 엽니다.

### 페이지 접근

기본적으로(`OVERLEAF_ALLOW_PUBLIC_ACCESS`가 설정되지 않은 경우) 로그인 및 가입 페이지를 제외한 **모든** 페이지는 로그아웃한 방문자를 로그인 페이지로 리디렉션합니다. 여기에는 공개용으로 의도된 페이지도 포함되므로, 해당 페이지로의 링크는 이미 로그인한 사용자에게만 작동합니다.

`OVERLEAF_ALLOW_PUBLIC_ACCESS=true`로 설정하면 로그아웃한 방문자도 다음 페이지를 열 수 있습니다:

| 페이지                                                                  | 필요 조건                         |
| --------------------------------------------------------------------- | -------------------------------- |
| `/learn`의 LaTeX 도움말([adding-latex-user-help.md](/ko/on-premises/configuration/overleaf-toolkit/adding-latex-user-help  "mention") 참조) | `OVERLEAF_PROXY_LEARN=true`      |
| `/templates`의 템플릿 갤러리, 템플릿 페이지, 미리보기 및 ZIP 다운로드([templates.md](/ko/on-premises/configuration/overleaf-toolkit/templates  "mention") 참조) | `OVERLEAF_TEMPLATE_GALLERY=true` |
| `/devs`의 Overleaf Import API 페이지([overleaf-import-api.md](/ko/on-premises/configuration/overleaf-toolkit/overleaf-import-api  "mention") 참조) | —                                |

또한 [Overleaf Import API](/ko/on-premises/configuration/overleaf-toolkit/overleaf-import-api#signed-out-visitors  "mention")가 로그아웃한 방문자의 양식 제출을 해당 방문자가 로그인할 때까지 유지할 수 있도록 합니다.

프로젝트 목록, 편집기 및 프로젝트 생성(템플릿 또는 Import API를 통한 생성 포함)에는 여전히 로그인이 필요합니다.

### 공개 가입

공개 가입은 [ayaka-notes/overleaf-pro](https://github.com/ayaka-notes/overleaf-pro)에서만 사용할 수 있습니다.

<Danger>

공개 가입을 활성화하면 Overleaf 인스턴스에 접근할 수 있는 **누구나** 사용자로 가입할 수 있다는 점에 유의하세요.

가입 과정에서는 이메일 주소를 확인하지 않으므로 인트라넷이나 신뢰할 수 있는 환경에서만 사용하거나, 더 이상 가입이 필요하지 않으면 비활성화하세요.

</Danger>

기본적으로 Community Edition과 Overleaf Pro 모두 공개 가입을 허용하지 않습니다.

활성화하려면 `config/variables.env`에 다음을 추가하세요:

```dotenv title="config/variables.env"
OVERLEAF_ALLOW_PUBLIC_REGISTRATION=true
```

`bin/up`으로 컨테이너를 다시 생성합니다.

그런 다음 **Sign up**을 클릭하거나 `/register`를 방문하세요.

### 도메인 제한 가입

도메인 제한 공개 가입은 [ayaka-notes/overleaf-pro](https://github.com/ayaka-notes/overleaf-pro)에서만 사용할 수 있습니다.

이 기능을 활성화하기 전에 사용자가 초대 및 알림을 받을 수 있도록 이메일 전송을 구성하세요. [이메일 전송](/ko/on-premises/configuration/overleaf-toolkit/email-delivery)을 참조하세요.

그런 다음 `config/variables.env`에 다음 줄을 추가하세요:

```dotenv title="config/variables.env" wrap
OVERLEAF_ALLOW_PUBLIC_REGISTRATION=@example.domain
```

`OVERLEAF_ALLOW_PUBLIC_REGISTRATION`은 다음 값으로 설정할 수 있습니다:

* `true`: 사이트에 접근할 수 있는 누구나 가입할 수 있도록 허용
* `@example.domain`: 해당 도메인의 이메일로만 가입을 제한
