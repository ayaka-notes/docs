Overleaf Import API를 제외한 모든 통합은 기본적으로 꺼져 있습니다. GitHub, GitLab, Gitea, Dropbox 동기화와 MCP 서버는 [Git 연동](/ko/on-premises/configuration/overleaf-toolkit/integrations/git-integration)도 필요합니다. 통합을 켠 후에는 `bin/up -d`로 컨테이너를 다시 생성하세요.
