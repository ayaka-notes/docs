---
title: 비밀번호 제한
icon: key
---

인증에 Overleaf 기본 로그인 시스템을 사용하는 경우 사용자 계정에 비밀번호 제한을 적용할 수 있습니다.

<Info>

SSO(LDAP/SAML 2.0) 로그인에는 비밀번호 제한을 적용할 수 **없습니다**. 이러한 제한은 ID 공급자(IdP)에서 구성해야 합니다.

</Info>

비밀번호 제한을 활성화하려면 Toolkit의 `config/variables.env` 파일에 관련 환경 변수를 설정하세요.

| 이름                                      | 설명                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | 기본값 |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------: |
| `OVERLEAF_PASSWORD_VALIDATION_MIN_LENGTH` | 필요한 **최소** 길이입니다.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |     `8` |
| `OVERLEAF_PASSWORD_VALIDATION_MAX_LENGTH` | 허용되는 **최대** 길이입니다.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |    `72` |
| `OVERLEAF_PASSWORD_VALIDATION_PATTERN`    | <p>비밀번호 <strong>강도</strong>를 검증하는 데 사용됩니다.</p><ul><li>`abc123` – 비밀번호에 문자 3개와 숫자 3개가 필요하며 길이가 6자 이상이어야 합니다</li><li>`aA` – 비밀번호에 소문자와 대문자가 필요하며 길이가 2자여야 합니다</li><li>`ab$3` – 문자, 숫자, 기호를 포함해야 하며 길이가 4자여야 합니다</li><li>문자 그룹은 문자, 대문자, 숫자, 기호의 4가지입니다. 문자도 숫자도 아닌 모든 것은 기호로 간주됩니다.</li></ul> |       — |
