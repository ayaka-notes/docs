### 전역 구성

특정 인증 모듈을 활성화하려면 환경 변수 `EXTERNAL_AUTH`가 필요합니다. 이 환경 변수는 활성화할 외부 인증 방식을 지정합니다. 사용 가능한 옵션은 다음과 같습니다(소문자).

* saml
* ldap
* oidc

### SSO 관련 제안

저는 Overleaf에서 saml, ldap, oauth를 테스트했습니다. saml과 oauth는 모두 Overleaf에서 잘 동작하지만, ldap은 상황에 따라 다릅니다. [https://docs.goauthentik.io/](https://docs.goauthentik.io/)에서는 잘 동작하지 않지만, openLDAP([https://github.com/rroemhild/docker-test-openldap](https://github.com/rroemhild/docker-test-openldap))에서는 잘 동작합니다.

<Info>

passport-ldapauth를 업데이트해야 합니다. 최근 [https://goauthentik.io/](https://goauthentik.io/)로 Overleaf ldap을 테스트해 보았는데 실패했습니다. "passport-ldapauth"를 3.0.0으로 업데이트한 후에는 모든 것이 잘 동작했습니다.

```text
"passport-ldapauth": "^3.0.0",
```

원래 버전은 6년 전의 2.x.x입니다.

</Info>

LDAP(그리고 saml, oauth) 인증은 모두 외부 패키지에 의존하기 때문에 원인이 무엇인지는 확실하지 않습니다. 동작하지 않는다면 Overleaf Server Pro에서도 상황은 같을 수 있습니다. 저희는 모든 환경 변수를 내부 패키지에 그대로 전달할 뿐이므로, 버그가 있더라도 현재로서는 알 방법이 없습니다.

**따라서 사용자분들께서 전체 소스 코드로 개발 환경을 구성하여 SSO를 테스트하실 것을 적극 권장합니다.** 개발 환경 구성 방법은 [개발 환경 설정(로컬)](/ko/dev/environment/setup-develop-environment-local  "mention")에서 확인할 수 있습니다. 개발 환경에서는 터미널에서 모든 로그를 볼 수 있어 디버깅에 편리합니다.
