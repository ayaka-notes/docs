### 헤더

이 섹션에서는 온프레미스 인스턴스의 주요 요소를 개인화하는 방법을 다룹니다. 사이트 제목, 내비게이션 링크, 헤더, 푸터, 로고를 원하는 대로 사용자 정의할 수 있습니다.

### 사이트 제목

내비게이션 바 제목은 `OVERLEAF_NAV_TITLE` 환경 변수로 사용자 정의할 수 있습니다. 로고가 설정되지 않은 경우 이 텍스트가 내비게이션 왼쪽 상단에 표시됩니다.

```bash
# add to config/variables.env
OVERLEAF_NAV_TITLE=Our Overleaf Instance
```

## 로고

환경 변수 `OVERLEAF_HEADER_IMAGE_URL`을 설정하면 텍스트 대신 사용자 정의 로고를 추가할 수 있습니다. 이 값은 외부에 호스팅된 이미지 파일을 가리켜야 합니다.

```bash title="config/variables.env"
# add to config/variables.env
OVERLEAF_HEADER_IMAGE_URL=https://mysite.somewhere.com/img/logo.png
```

#### 라이트 및 다크 테마 로고

버전 6.3.0부터는 `OVERLEAF_HEADER_IMAGE_URL_LIGHT` 및 `OVERLEAF_HEADER_IMAGE_URL_DARK` 환경 변수를 사용하여 라이트 테마와 다크 테마에 각각 별도의 로고를 설정할 수 있습니다. 두 값 모두 외부에 호스팅된 이미지 파일을 가리켜야 합니다.

```text
# add to config/variables.env
OVERLEAF_HEADER_IMAGE_URL_LIGHT=https://mysite.somewhere.com/img/logo-light.png
OVERLEAF_HEADER_IMAGE_URL_DARK=https://mysite.somewhere.com/img/logo-dark.png
```

<Info>

두 변수 중 하나가 설정되지 않은 경우, 해당 테마는 `OVERLEAF_HEADER_IMAGE_URL`에 설정된 로고를 대신 사용합니다.

</Info>

## 헤더 내비게이션 링크

`OVERLEAF_HEADER_EXTRAS` 환경 변수를 객체의 JSON 배열로 설정하면 내비게이션 헤더에 추가 항목을 넣을 수 있습니다. 예를 들면 다음과 같습니다.

```json wrap
[\
  {\
    "text": "Some link",\
    "url": "http://example.com/somelink",\
    "class": "subdued",\
    "only_when_logged_out": true\
  },\
  {\
    "text": "Help",\
    "class": "subdued",\
    "dropdown": [\
      {\
        "text": "Documentation",\
        "url": "/learn"\
      },\
      {\
        "text": "Contact Admin",\
        "url": "http://example.com/contact"\
      }\
    ]\
  }\
]
```

이스케이프된 JSON 형식을 toolkit/variables.env에 추가합니다.

```bash title="toolkit/variables.env" wrap
# add to toolkit/variables.env
OVERLEAF_HEADER_EXTRAS=[{"text":"Some link","url":"http://example.com/somelink","class":"subdued","only_when_logged_out":true},{"text":"Help","class":"subdued","dropdown":[{"text":"Documentation","url":"/learn"},{"text":"Contact Admin","url":"http://example.com/contact"}]}]
```

## 푸터

환경 변수 `OVERLEAF_LEFT_FOOTER` 및 `OVERLEAF_RIGHT_FOOTER`를 사용하여 왼쪽 푸터와 더 작은 오른쪽 푸터(`/project`와 같은 페이지에 표시됨)를 모두 사용자 정의할 수 있습니다. 두 변수 모두 삽입될 JSON 객체 배열을 값으로 받습니다.

두 변수 모두 삽입될 JSON 배열을 값으로 받습니다.

```json
[\
  {\
    "text": "This is an example text footer entry!"\
  },\
  {\
    "text": "This is an example URL footer link!", "url" : "/my-first-link.htm"\
  }\
]
```

<Info>

`text`만 사용하는 경우 값이 원시 텍스트로 렌더링되므로 HTML을 포함해서는 안 됩니다.

</Info>

이 데이터가 제대로 작동하려면 유효한 JSON이어야 하며, 환경 변수로 전달할 때는 따옴표를 이스케이프해야 합니다.

```bash title="config/variables.env" wrap
# add to config/variables.env
OVERLEAF_LEFT_FOOTER=[{"text": "This is an example text footer entry!"}]
OVERLEAF_RIGHT_FOOTER=["text": "This is an example URL footer link!", "url" : "/my-first-link.htm"]
```

<Info>

JSON 객체는 `text`와 `url` 외에도 추가 사용자 정의를 위한 `class` 및 `label` 속성을 지원합니다.

</Info>

### 유지보수 페이지

`OVERLEAF_MAINTENANCE_MESSAGE` 환경 변수로 유지보수 페이지에 표시되는 메시지를 사용자 정의할 수 있습니다. 이 텍스트는 페이지 제목 아래의 기본 메시지를 대체합니다.

```text wrap
# add to config/variables.env
OVERLEAF_MAINTENANCE_MESSAGE=Our Overleaf Instance is down for maintenance and will be back shortly.
```

링크나 기타 서식을 포함하려면 대신 `OVERLEAF_MAINTENANCE_MESSAGE_HTML`을 사용하세요. 둘 다 설정된 경우 `OVERLEAF_MAINTENANCE_MESSAGE_HTML`이 우선합니다.

```text wrap
# add to config/variables.env
OVERLEAF_MAINTENANCE_MESSAGE_HTML=Our Overleaf Instance is down for maintenance. For urgent requests, contact <a href="mailto:admin@example.com">admin@example.com</a>.
```

<Info>

`OVERLEAF_MAINTENANCE_MESSAGE`는 일반 텍스트로 렌더링되므로 HTML을 **포함해서는 안 됩니다**. `OVERLEAF_MAINTENANCE_MESSAGE_HTML`은 이스케이프 없이 HTML로 렌더링됩니다.

</Info>

둘 다 설정되지 않은 경우, 기본 메시지는 `OVERLEAF_STATUS_PAGE_URL`이 설정되어 있으면 상태 페이지로 연결되는 링크를 표시하고, 설정되어 있지 않으면 관리자 이메일 주소를 표시합니다.
