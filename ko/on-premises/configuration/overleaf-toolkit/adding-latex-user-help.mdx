Ayakaleaf Pro에는 사용자가 설정한 URL의 MediaWiki 사이트에서 페이지를 다운로드하여 인스턴스의 `/learn` 경로에서 제공하는 모듈이 포함되어 있습니다. Ayakaleaf Pro 자체는 어떠한 위키 콘텐츠도 포함, 호스팅 또는 배포하지 않습니다. 이 모듈을 활성화하려면 Toolkit의 `config/variables.env` 파일에 `OVERLEAF_PROXY_LEARN=true`를 추가하고 `bin/up` 명령을 실행하세요.

그러면 사용자는 인스턴스를 벗어나지 않고도 탐색 메뉴의 **Documentation** 버튼을 클릭하여 위키 페이지를 열 수 있습니다.

<Info>

기본적으로 로그인한 사용자만 `/learn`을 열 수 있습니다. 로그아웃한 방문자도 이용할 수 있게 하려면 `OVERLEAF_ALLOW_PUBLIC_ACCESS=true`도 설정하세요. [페이지 접근](/ko/on-premises/configuration/overleaf-toolkit/public-access#page-access  "mention")을 참고하세요.

</Info>

<Info>

Docker Compose 배포의 경우, `docker-compose.yml` 파일에서 `sharelatex` 서비스의 **environment** 섹션에 환경 변수 `OVERLEAF_PROXY_LEARN: true`를 추가해야 합니다.

</Info>

<Danger>

이 옵션을 처음 활성화하고 Overleaf docker를 재시작하면, 시스템이 관련 Wiki를 다운로드해야 하며 이 작업은 5분 이상 걸릴 수 있습니다. 다운로드가 완료된 후에야 Overleaf 로그인 페이지를 정상적으로 볼 수 있습니다.

</Danger>

### 위키 소스 선택

프록시할 위키는 `WIKI_URL`로 설정합니다. 설정하지 않으면 업스트림 Overleaf 설정(`services/web/config/settings.defaults.js`)에서 상속된 기본값이 사용됩니다.

```text
WIKI_URL=https://learnwiki.overleaf.com
```

이는 [Overleaf Learn](https://www.overleaf.com/learn) 페이지의 기반이 되는 위키입니다. 인스턴스가 이 위키에 접근하려면 인터넷 연결이 필요합니다.

<Warning>

<strong>저작권에 유의하세요.</strong> 이 모듈은 `WIKI_URL`에 지정된 URL에서만 콘텐츠를 가져오며, 콘텐츠는 해당 위키를 운영하는 측에 귀속됩니다. 모듈을 활성화하면 인스턴스는 해당 위키의 모든 페이지를 다운로드하여 서버에 사본을 보관합니다. 기본 위키는 Overleaf가 운영하며, 그 콘텐츠는 Ayakaleaf Pro가 아닌 Overleaf의 소유입니다. 모듈을 활성화하기 전에, 특히 인스턴스가 로그아웃한 방문자에게도 공개되어 있다면, 해당 페이지를 다운로드, 저장 및 제공하는 것이 Overleaf의 약관을 준수하는지 확인하세요. 확신이 서지 않는다면 `WIKI_URL`을 직접 소유하거나 사용 허가를 받은 콘텐츠의 위키로 지정하세요.

</Warning>

대신 `WIKI_URL`을 사내 지식 베이스와 같은 자체 위키로 지정할 수도 있습니다.

```text
OVERLEAF_PROXY_LEARN=true
WIKI_URL=https://wiki.example.com
```

위키는 다음을 제공하는 [MediaWiki](https://www.mediawiki.org/) 사이트여야 합니다.

* `<WIKI_URL>/learn-scripts/api.php`의 API(`action=query` 및 `action=parse`에 대한 익명 읽기 접근 허용)
* `<WIKI_URL>/learn-scripts/images/` 아래의 업로드된 이미지

* `/learn/<Page>` 형식의 문서 링크(모듈이 인스턴스에서 `/learn/latex/<Page>`로 다시 작성함)

이 경로들은 모듈에 고정되어 있으며 기본 위키의 구조를 따릅니다. 새로 설치한 MediaWiki는 다른 경로를 사용하므로, 해당 `LocalSettings.php`에 다음을 설정하세요(또는 리버스 프록시에서 경로를 매핑하세요).

```php
$wgScriptPath = "/learn-scripts";
$wgArticlePath = "/learn/$1";
```

페이지는 다음과 같이 매핑됩니다.

| 인스턴스의 경로  | MediaWiki 페이지 제목 |
| ---------------------- | -------------------- |
| `/learn`               | `Main Page`          |
| `/learn/latex/<Page>`  | `<Page>`             |
| `/learn/how-to`        | `Kb/Knowledge Base`  |
| `/learn/how-to/<Page>` | `Kb/<Page>`          |

### 캐시

가져온 페이지는 `sharelatex` 컨테이너 내부의 `/var/lib/overleaf/data/learnPages`에 캐시됩니다. 캐시된 페이지는 `WIKI_MAX_CACHE_AGE` 밀리초(기본값 `300000`, 5분)보다 오래되면 갱신됩니다. 위키에 접근할 수 없는 경우에는 캐시된 사본이 계속 제공됩니다.
