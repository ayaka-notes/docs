title: LaTeX 사용자 도움말 추가
icon: graduation-cap
---

Toolkit의 `config/variables.env` 파일에 `OVERLEAF_PROXY_LEARN=true`를 추가하고 `bin/up` 명령을 실행하기만 하면, Overleaf Pro 인스턴스 안에서 Overleaf의 [Learn](https://www.overleaf.com/learn) 페이지에 접근할 수 있도록 설정할 수 있습니다.

이렇게 하면 사용자는 인스턴스를 벗어나지 않고도 탐색 메뉴의 **Documentation** 버튼을 클릭하여 최신 문서와 학습 자료에 접근할 수 있습니다.

<Info>

기본적으로 로그인한 사용자만 `/learn`을 열 수 있습니다. 로그아웃한 방문자도 이용할 수 있게 하려면 `OVERLEAF_ALLOW_PUBLIC_ACCESS=true`도 설정하세요. [페이지 접근](/ko/on-premises/configuration/overleaf-toolkit/public-access#page-access  "mention")을 참고하세요.

</Info>

<Info>

Docker Compose 배포의 경우, `docker-compose.yml` 파일에서 `sharelatex` 서비스의 **environment** 섹션에 환경 변수 `OVERLEAF_PROXY_LEARN: true`를 추가해야 합니다.

</Info>

<Info>

Server Pro 배포가 [https://learn.sharelatex.com](https://docs.overleaf.com/on-premises/welcome)으로 외부 `GET` 요청을 보낼 수 있도록 인터넷에 접근할 수 있어야 합니다.

</Info>

<Danger>

이 옵션을 처음 활성화하고 Overleaf docker를 재시작하면, 시스템이 관련 Wiki를 다운로드해야 하며 이 작업은 5분 이상 걸릴 수 있습니다. 다운로드가 완료된 후에야 Overleaf 로그인 페이지를 정상적으로 볼 수 있습니다.

</Danger>
