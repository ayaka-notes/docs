---
title: 프로젝트 내보내기
icon: file-export
---

Server Pro 및 Community Edition `5.4.0`에는 관리자가 모든 사용자 프로젝트(**Deleted** 및 **Trashed** 폴더에 아직 표시되는 프로젝트 포함)를 디스크의 디렉터리로 내보낼 수 있는 스크립트가 포함되어 있습니다.

<Info>

이 스크립트를 실행한 결과는 사용자의 프로젝트 대시보드에서 모든 프로젝트의 Zip 파일을 수동으로 다운로드한 것과 같습니다. 스크립트는 다운로드를 시작하기 전에 보류 중인 변경 사항을 모두 플러시하여 내보내기에 프로젝트의 최신 버전이 포함되도록 합니다.

</Info>

### 제한 사항

내보내기 스크립트에는 다음과 같은 제한 사항이 있습니다.

* TeX Live 이미지 이름이나 컴파일러 같은 프로젝트 설정은 내보내지지 않습니다. 이러한 설정은 프로젝트를 사용자 계정에 업로드할 때 지정해야 합니다.
* 내보낸 프로젝트에는 버전 기록이 포함되지 않습니다.
* 공동 작업자 정보는 보존되지 않습니다. 프로젝트를 다시 공유해야 합니다. 링크 공유를 사용하는 경우 보기 및 편집 링크가 다시 생성됩니다(이전과 동일하지 않음).
* 댓글과 변경 내용 추적 정보는 내보내지지 않습니다.
* 프로젝트 채팅 기록은 내보내지지 않습니다.

<Danger>

이 스크립트는 전체 시스템 백업을 대체하도록 설계되지 **않았습니다**. 재해 복구 상황에서 인스턴스를 복구할 수 있도록 [일관된 백업](https://docs.overleaf.com/on-premises/maintenance/#performing-a-consistent-backup)을 수행할 것을 **강력히** 권장합니다.

</Danger>

### **플래그**

| 이름           | 설명                                                                     |
| -------------- | ------------------------------------------------------------------------------- |
| `--help`       | 도움말 표시                                                                       |
| `--user-id`    | 사용자 ID(`--export-all` 또는 `--project-id`를 사용하지 않는 경우 필수)            |
| `--project-id` | 단일 프로젝트 내보내기(`--user-id` 또는 `--export-all`과 함께 사용할 수 **없음**) |
| `--list`       | 사용자의 프로젝트 나열(`--output`과 함께 사용할 수 **없음**)                       |
| `--output`     | 출력 zip 파일(단일 내보내기 작업용)                                  |
| `--export-all` | 모든 사용자의 프로젝트 내보내기(`--output-dir` 필요)                            |
| `--output-dir` | 모든 사용자의 내보내기 파일을 저장할 디렉터리                                   |
| `--log-level`  | 지원되는 로그 수준: `trace`\|`debug`\|`info`\|`warn`\|`error`\|`fatal`       |

### **사용법**

다음 명령을 사용하여 모든 사용자의 프로젝트를 내보냅니다.

```bash wrap
# Overleaf Toolkit users
$ bin/docker-compose exec sharelatex /bin/bash -ce "cd /overleaf/services/web && node modules/server-ce-scripts/scripts/export-user-projects.mjs --export-all --output-dir=/var/lib/overleaf/data/exports"

# Legacy docker-compose.yml users
docker exec sharelatex /bin/bash -ce "cd /overleaf/services/web && node modules/server-ce-scripts/scripts/export-user-projects.mjs --export-all --output-dir=/var/lib/overleaf/data/exports"
```

<Info>

Server Pro 또는 Community Edition &lt;= 3.5.13을 실행 중인 경우 위 예제를 **`export-legacy-user-projects.js`** 스크립트를 사용하도록 수정해야 합니다.

</Info>

### **완료**

내보내기가 완료되면 **docker-compose.yml** 파일에서 <strong>/var/lib/overleaf</strong>에 바인드 마운트된 호스트의 디렉터리를 통해, 또는 Toolkit을 사용하는 경우 **config/overleaf.rc** 파일의 `OVERLEAF_DATA_PATH` 환경 변수에 지정된 디렉터리를 통해 파일에 접근할 수 있습니다.

<Info>

Overleaf는 현재 중복된 프로젝트 이름을 허용합니다. 사용자의 프로젝트에 중복된 이름이 있으면 해당 프로젝트는 사용자의 Zip 내보내기에 추가되지만, 압축을 풀면 하나의 버전만 남게 됩니다. Linux에서는 `unzip -B`를 사용하면 덮어쓰지 않고 같은 이름의 파일을 백업 파일로 저장합니다.

</Info>
