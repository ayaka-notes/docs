<Danger>

필요할 때 롤백할 수 있도록, 모든 메이저 버전 업그레이드 **전에** 반드시 [일관된 백업](/ko/on-premises/maintenance/data-and-backups#performing-a-consistent-backup)을 수행하세요.

</Danger>

[ayakaleaf toolkit↗](https://github.com/ayaka-notes/toolkit)은 git 저장소이므로 새로운 Toolkit 기능을 쉽게 받을 수 있습니다. `bin/upgrade` 명령을 실행하고 화면의 안내를 따르기만 하면 됩니다.

Docker 이미지 버전(`config/version`)은 Toolkit 코드 업데이트와 별도로 관리된다는 점에 유의하세요. Toolkit 코드를 업데이트해도 실행 중인 Docker 이미지 버전은 자동으로 변경되지 **않습니다**. 즉, 대부분의 경우 배포를 업그레이드하지 않고도 Toolkit 버전을 업그레이드할 수 있습니다.

#### `bin/upgrade` 스크립트

`bin/upgrade` 명령을 실행하면 스크립트가 Toolkit 코드에 사용 가능한 업데이트가 있는지 확인하고 Toolkit 업데이트를 제안합니다. 언제든지 업그레이드를 거절할 수 있으며, 그 경우 아무것도 변경되지 않습니다.

Toolkit 코드를 업데이트하기로 선택하면, 스크립트는 _기본_ Docker 이미지 버전이 변경되었는지 확인하고 로컬 버전 파일(`config/version`)을 새 기본값에 맞게 업그레이드할 것을 제안합니다.

버전을 전환하기로 선택하면, 스크립트가 Docker 서비스 종료, 백업 수행, Docker 서비스 재시작 과정을 차례로 안내합니다. 해당 버전의 Docker 이미지로 롤백해야 할 경우를 대비해 이전 버전 파일은 자동으로 `config/__old-version`에 복사됩니다.

<Info>

Docker 이미지를 수동으로 가져오는 에어갭 환경에서는 `config/overleaf.rc` 파일에 `PULL_BEFORE_UPGRADE=false`를 설정하세요.

에어갭/오프라인 환경에서의 배포에 대한 자세한 내용은 [여기](/ko/on-premises/installation/air-gapped-offline-deployments)를 확인하세요.

</Info>

### 업그레이드 경로

v6.0.0 이전 버전의 Overleaf Community를 실행 중이라면 [공식 Overleaf 문서](https://docs.overleaf.com/on-premises/maintenance/upgrading-your-deployment#upgrade-path)를 참고하여 업그레이드를 완료하세요.

Ayakaleaf Pro 내에서는 먼저 현재 버전 라인의 최신 패치 릴리스로 업그레이드한 다음 다음 버전 라인으로 업그레이드하세요. 예: `6.2.0 → 6.2.2 → 6.3.2`. 거치는 모든 버전의 [릴리스 노트](/ko/on-premises/release-notes/release-notes-6.x.x)를 읽으세요. 일부 버전은 추가 단계가 필요합니다. 최신 릴리스만 지원됩니다.
