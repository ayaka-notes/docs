---
title: 4. Ayakaleaf Pro 이미지 가져오기
icon: split
---

Ayakaleaf Pro는 [GitHub Container Registry (ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/)에 있는 무료 Docker 이미지입니다. pull하는 데 계정이나 로그인이 필요하지 않습니다. 이미지는 amd64와 arm64용으로 빌드되며, Docker가 서버에 맞는 이미지를 선택합니다.

`config/overleaf.rc`를 열고 다음과 같이 설정하세요.

```text title="config/overleaf.rc"
SERVER_PRO=true
```

다음에 `bin/up`을 실행하면 Toolkit이 Ayakaleaf Pro 이미지를 다운로드하여 공식 Overleaf Community Edition 대신 사용합니다. `config/`의 설정은 그대로 계속 작동합니다.

<Accordion title="이미 공식 Overleaf Toolkit(overleaf/toolkit)을 실행 중인가요?">

다시 설치할 필요가 없습니다. Ayakaleaf Pro 이미지를 pull하세요.

```bash
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

그런 다음 `overleaf-toolkit/config` 디렉터리에 다음 내용으로 `docker-compose.override.yml` 파일을 추가하세요.

```yml
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

다음에 `bin/up`을 실행하면 Toolkit이 Ayakaleaf Pro 이미지를 사용합니다.

</Accordion>
