---
title: 4. Ayakaleaf Pro 이미지 가져오기
icon: split
---

Ayakaleaf Pro는 [ghcr](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/) 레지스트리에서 Docker 이미지로 배포되며, 누구나 **자유롭게 접근**할 수 있습니다. amd64와 arm64 아키텍처용 이미지를 모두 제공합니다. 이미지를 pull하면 시스템 아키텍처에 맞는 이미지가 자동으로 선택됩니다.

#### Ayaka-notes Toolkit 사용자

[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)을 사용하는 경우, Ayakaleaf Pro를 Community Edition의 드롭인 대체품으로 사용할 수 있으므로 기존 설정과 사용자 정의를 그대로 사용할 수 있습니다. `config/overleaf.rc`를 편집하여 `SERVER_PRO` 환경 변수를 설정하면 Toolkit에서 Pro를 활성화할 수 있습니다:

```text title="config/overleaf.rc"
SERVER_PRO=true
```

다음에 `bin/up`을 실행하면 Toolkit이 자동으로 Ayakaleaf Pro 이미지를 다운로드하여 사용합니다.

#### 공식 Toolkit 사용자

[overleaf/toolkit](https://github.com/overleaf/toolkit)을 사용하는 경우, Pro 이미지를 받으려면 다음 명령을 실행하여 pull하세요:

```bash title="Pull Docker Images"
docker pull ghcr.io/ayaka-notes/overleaf-pro:latest
```

그런 다음 `overleaf-toolkit/config` 디렉터리에 다음 내용으로 `docker-compose.override.yml` 파일을 추가하세요:

```yml title="docker-compose.override.yml"
---
services:
    sharelatex:
        image: ghcr.io/ayaka-notes/overleaf-pro:latest # or X.x.x
```

다음에 `bin/up`을 실행하면 Toolkit이 자동으로 Ayakaleaf Pro 이미지를 다운로드하여 사용합니다.
