### 둘러보기

이제 Toolkit의 로컬 사본이 준비되었으니 `ls` 명령으로 저장소 구조를 살펴보겠습니다.

```bash title="Run this"
ls -l
```

<Info>

`ls -l` 명령은 디렉터리 내용을 자세한 긴 목록 형식으로 표시하며, 권한, 소유자, 크기 등 추가 파일 정보를 제공합니다.

</Info>

모든 것이 성공적으로 클론되었다면 다음과 비슷한 결과가 표시됩니다:

```text
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 bin
-rw-r--r-- 1 fry fry  6465 Aug 30 14:16 CHANGELOG.md
drwxr-xr-x 2 fry fry  4096 Sep  6 12:43 config
drwxr-xr-x 5 fry fry  4096 Aug 30 14:22 data
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 doc
drwxr-xr-x 3 fry fry  4096 Aug 30 14:16 lib
-rw-r--r-- 1 fry fry 34520 Aug 30 14:16 LICENSE
-rw-r--r-- 1 fry fry  1178 Aug 30 14:16 README.md
```

<Info>

사용자가 관리하는 모든 구성 파일은 `config/` 디렉터리에 있습니다. 이 디렉터리는 git 버전 관리 시스템에서 **제외**되므로 Toolkit을 업데이트해도 변경되지 않습니다.

</Info>

## 저장소 구성

| 이름     | 설명 |
| -------- | ---- |
| `bin`    | Overleaf 서버 인스턴스 관리를 돕는 스크립트 모음이 들어 있는 폴더입니다. 이 스크립트에 대한 자세한 내용은 아래 Commands 섹션에서 확인할 수 있습니다. |
| `config` | 사용자 자신의 로컬 구성 파일이 들어 있는 폴더입니다. |
| `lib`    | Toolkit에서 사용하는 기본 구성 파일이 들어 있는 폴더입니다. |
| `data`   | 기본적으로 이 폴더에는 MongoDb, Redis, Overleaf의 저장 위치가 들어 있습니다. 자세한 내용은 아래 [영구 데이터](https://docs.overleaf.com/on-premises/configuration/overleaf-toolkit/files-and-locations#persistent-data) 섹션을 참조하세요. |

<Warning>

`/config` 폴더 외부의 파일을 직접 변경하지 **않는** 것을 권장합니다. 대신 변경이 필요한 경우 **config/variables.env** 또는 **config/overleaf.rc**에 설정하는 환경 변수를 통해 변경할 수 있습니다.\
예를 들어 `mongo` 서비스 이미지를 설정하려면 `lib/docker-compose.mongo.yml`을 직접 편집하는 대신 `config/overleaf.rc`에서 환경 변수 `MONGO_IMAGE`를 사용해 이미지를 설정하세요. 자세한 내용은 [Toolkit 설정](/ko/on-premises/configuration/overleaf-toolkit/toolkit-settings) 페이지를 참조하세요.

</Warning>

<Info>

Toolkit은 사용자의 허락 없이 `config/` 디렉터리의 데이터를 변경하지 **않습니다**.

</Info>
