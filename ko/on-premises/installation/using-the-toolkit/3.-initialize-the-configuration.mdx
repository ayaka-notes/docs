### 구성 초기화하기

번들로 제공되는 `bin/init` 스크립트를 실행하여 새 서버의 구성 파일을 합리적인 기본값으로 초기화해 보겠습니다.

```text title="Run initialization"
bin/init
```

이 스크립트는 기존 구성 파일을 덮어쓰지 **않습니다**.

이제 `ls` 명령으로 `config/` 디렉터리의 내용을 확인해 보겠습니다.

```text title="List the config directory"
ls config
```

모든 것이 성공적으로 초기화되었다면 `overleaf.rc`, `variables.env`, `version`의 세 가지 구성 파일이 보일 것입니다. 이 파일들은 주요 서버 구성 파일로, 서버의 동작 방식과 사용자가 인스턴스와 상호 작용하는 방식을 사용자 지정할 수 있게 해 줍니다.

| 이름            | 설명                                             |
| --------------- | ------------------------------------------------------- |
| `overleaf.rc`   | 최상위 메인 구성 파일입니다.                  |
| `variables.env` | Docker 컨테이너에 로드되는 환경 변수입니다. |
| `version`       | 사용할 Docker 이미지의 버전입니다.                 |

<Info>

지금은 이 파일들이 존재한다는 것과 그 위치만 알아 두면 충분합니다. 이후 문서에서 각 파일을 더 자세히 살펴보고, 이를 사용해 인스턴스를 사용자 지정하는 방법을 설명합니다. 먼저 살펴보고 싶다면 [파일 및 위치 페이지](/ko/on-premises/configuration/overleaf-toolkit/files-and-locations)에서 이 구성 파일들에 대한 전체 설명을 확인할 수 있습니다.

</Info>
