### Toolkit 다운로드

Toolkit은 Server CE와 Ayakaleaf Pro 모두와 호환되며, 권장되는 설치 방법입니다. Toolkit을 사용하면 Server CE를 쉽게 시작할 수 있고, 필요한 경우 Ayakaleaf Pro로 원활하게 업그레이드할 수 있습니다.

<Info>

[ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit)은 ghcr의 overleaf-pro 이미지를 직접 사용하고 ayaka-notes가 제공하는 TeX Live를 사용하도록 수정된 버전입니다. 원한다면 공식 overleaf-toolkit을 다운로드할 수도 있습니다.

</Info>

<Steps>
<Step title="Overleaf Toolkit 저장소 클론">
Toolkit을 설치하려면 설치할 경로로 이동한 다음, 아래 명령으로 Overleaf Toolkit (@Ayaka-notes) GitHub 저장소를 클론하세요.

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
# official toolkit (Not Recommended)
# git clone https://github.com/overleaf/toolkit.git ./overleaf-toolkit
```

<Info>

권한 관련 문제를 방지하려면 Toolkit을 사용자의 `$HOME` 디렉터리에 설치하는 것을 권장합니다.

</Info>
</Step>

<Step title="Toolkit 디렉터리로 이동">
클론이 완료될 때까지 기다린 후, 새로 생성된 `overleaf-toolkit` 디렉터리로 이동합니다.

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
