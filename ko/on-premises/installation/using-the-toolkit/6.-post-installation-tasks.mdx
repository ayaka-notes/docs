### 첫 번째 관리자 계정 만들기

브라우저에서 [http://localhost/launchpad](http://localhost/launchpad)를 엽니다. 이메일과 비밀번호 입력란이 있는 양식이 표시됩니다. 관리자 계정으로 사용할 자격 증명을 입력한 다음 **Register**를 클릭하세요.

<Info>

비밀번호는 8자 이상(72자 이하)이어야 하며, 이메일 주소를 포함하거나 이메일 주소와 너무 비슷해서는 안 되고, 유효한 문자만 포함해야 합니다.

</Info>

![Overleaf Launchpad](/images/on-premises/image.jpg)

그런 다음 링크를 클릭하여 로그인 페이지([http://localhost/login](http://localhost/login))로 이동합니다. 자격 증명을 입력하세요. 로그인하면 환영 페이지가 표시됩니다.

![Overleaf 환영 페이지](/images/on-premises/image-1.jpg)

페이지 하단의 녹색 버튼을 클릭하여 Overleaf 사용을 시작하세요.

### 첫 번째 예제 프로젝트 만들기

브라우저에서 [http://localhost/project](http://localhost/project)를 열면 첫 번째 프로젝트를 만들라는 버튼이 표시됩니다.

![Overleaf에 오신 것을 환영합니다!](/images/on-premises/image-2.jpg)

이 버튼을 클릭하고 **Example Project**를 선택한 다음 화면의 안내를 따르세요.

새 프로젝트로 이동하면 텍스트 편집기와 PDF 미리보기가 표시됩니다.

![Overleaf 편집기](/images/on-premises/image-3.jpg)

마지막으로 **Home** 아이콘을 클릭하면 프로젝트 페이지로 돌아갈 수 있습니다.
