[Toolkit](https://github.com/ayaka-notes/toolkit)은 Ayakaleaf Pro 인스턴스를 배포하는 권장 방법입니다.

이 섹션에서는 GitHub에서 Toolkit을 다운로드하고, Toolkit의 몇 가지 명령에 익숙해지고, 기본 설정을 구성하는 과정을 안내합니다. 이 페이지를 마치면 실행 중인 온프레미스 Overleaf 인스턴스를 갖게 됩니다.
