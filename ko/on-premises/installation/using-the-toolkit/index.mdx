[Toolkit](https://github.com/ayaka-notes/toolkit)은 Ayakaleaf Pro 인스턴스를 배포하는 데 권장되는 방법입니다.

이 섹션에서는 GitHub에서 Toolkit을 다운로드하고, Toolkit의 몇 가지 명령에 익숙해지고, 몇 가지 기본 설정을 구성하는 과정을 안내합니다. 이 페이지를 마치면 Overleaf 온프레미스 인스턴스가 실행되고 있을 것입니다.

<Info>

기본적으로 인스턴스는 서버 자체에서 `http://localhost`로 들어오는 연결만 허용합니다. 다른 컴퓨터나 다른 포트에서 열려면 [5. 인스턴스 개인화](/ko/on-premises/installation/using-the-toolkit/5.-personalizing-your-instance)에 설명된 대로 `config/overleaf.rc`에서 `OVERLEAF_LISTEN_IP`와 `OVERLEAF_PORT`를 설정하세요.

</Info>
