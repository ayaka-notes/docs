Ayakaleaf Pro를 가장 쉽게 테스트하는 방법은 GitHub Codespace를 사용하는 것입니다. 모든 환경 변수가 미리 구성되어 있어 바로 사용할 수 있습니다.

<Warning>

GitHub Codespaces에서 Docker 컨테이너를 실행하면 Codespace가 자동으로 종료되지 않고 계속 **과금**됩니다. GitHub Codespaces 과금 규칙은 [github codespaces billing rules](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces)를 참고하세요.

GitHub Codespaces를 관리하려면 [https://github.com/codespaces](https://github.com/codespaces)를 방문하세요. 더 이상 필요하지 않으면 Codespace를 바로 삭제하세요.

</Warning>

다음 기능이 **미리 구성**되어 있습니다.

* [x] TeXLive **Basic**(2024-2026)을 사용한 샌드박스 LaTeX 컴파일
* [x] Pandoc 가져오기/내보내기(SaaS 플랫폼 기능)
* [x] Python 스크립트 실행기(SaaS 플랫폼 기능)
* [x] Git-Bridge 지원(Server Pro 기능)
* [x] 고급 참고문헌 검색(SaaS 플랫폼 기능)
* [x] 관리자 패널(전역 사용자/프로젝트 관리)
* [x] 변경 내용 추적(검토 및 댓글 패널 포함)
* [x] 전체 프로젝트 히스토리(복원 및 다운로드 포함)
* [x] 기호 팔레트(Server Pro/SaaS 플랫폼 기능)

<Warning>

표준 GitHub Codespaces는 32GB의 스토리지를 제공합니다. 이는 `texlive-full` 설치에 충분하지 않습니다. 전체 이미지를 테스트하려면 대형 러너(8코어 이상)를 사용하는 Codespace를 위해 GitHub 지원 티켓을 제출하세요.

</Warning>

GitHub 동기화, LDAP, OAuth, SSO, Zotero 통합 등의 기능은 이 플레이그라운드에서 _**구성되어 있지 않습니다**_. 자체 배포에서 이러한 기능을 구성하는 방법에 대한 자세한 내용은 [Toolkit 설정](/ko/on-premises/configuration/overleaf-toolkit/toolkit-settings)을 참고하세요.

#### TeXLive Full 이미지 사용

8코어/64GB GitHub Codespaces를 사용할 수 있다면 이 플레이그라운드에서 TeXLive Full 이미지를 사용할 수 있습니다. `toolkit/config/variables.env` 파일에서 다음 환경 변수를 변경하면 TeXLive Basic 이미지 대신 TeXLive Full 이미지를 사용할 수 있습니다.

```dotenv wrap
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1, ghcr.io/ayaka-notes/texlive-full:2025.1, ghcr.io/ayaka-notes/texlive-full:2024.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES=Texlive 2026, Texlive 2025, Texlive 2024
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
```

환경 변수를 변경한 후에는 변경 사항을 적용하기 위해 Toolkit을 재시작해야 합니다. 다음 명령을 실행하여 Toolkit을 재시작할 수 있습니다.

```bash
cd toolkit && bin/up -d
```
