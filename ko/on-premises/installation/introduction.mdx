### 하드웨어 요구 사항

관련 테스트를 수행한 결과, 2코어, 2 GB RAM 서버에서 Overleaf를 실행하면 주로 Node.js 기반인 핵심 구성 요소가 약 1 GB의 메모리를 사용합니다. Redis와 MongoDB는 추가로 0.5 GB가 필요할 수 있으며, 컴파일을 위해 샌드박스 Docker 컨테이너를 시작하면 0.3 GB가 더 사용될 수 있습니다. 즉, 2코어, 2 GB 서버는 현실적으로 한 번에 약 하나의 동시 컴파일만 처리할 수 있습니다.

* Ayakaleaf Pro 설치를 위한 최소 하드웨어 요구 사항은 2코어 CPU와 3 GB RAM입니다.
* TeX Live 이미지의 크기 때문에 샌드박스 컴파일을 활성화하려면 최소 40 GB의 스토리지가 필요합니다.
* 2020년부터 2026년까지의 TeX Live 이미지 전체를 설치하려면 최소 150 GB의 여유 디스크 공간이 있는지 확인하세요.

다음은 사용 시나리오별 권장 하드웨어 구성입니다.

| 사용 사례 | 권장 구성 |
| ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| 개인 사용, 가끔 협업 | 2 CPU 코어, 4 GB RAM, 80 GB 스토리지 |
| 소규모 팀, 가벼운 협업을 하는 최대 10명 | 2 CPU 코어, 8 GB RAM, 256 GB 스토리지 |
| 중간 규모 팀, 최대 100명 | 4 CPU 코어, 16 GB RAM, 1 TB 스토리지 |
| 대규모 또는 대학 배포 | S3 스토리지를 사용하는 분산 클러스터 배포. 배포 지원이 필요하면 문의해 주세요 |

### 소프트웨어 요구 사항

소프트웨어 요구 사항으로는 최근의 안정적인 Ubuntu 버전(예: 2025–2026년에는 Ubuntu 24.04, 2023–2024년에는 Ubuntu 22.04)과 최신 안정 버전의 Docker를 함께 사용할 것을 권장합니다.

<Info>

Ubuntu 26.04는 Linux 커널 7.0을 탑재하고 있으며, MongoDB는 Linux 커널 6.19부터 7.0.13까지에서 시작을 거부합니다([자세히 보기](https://www.mongodb.com/docs/manual/administration/production-notes/)). 이러한 커널에서 실행하려면 `overleaf-toolkit/config/docker-compose.override.yml`(Ayakaleaf Pro 이미지를 설정하는 것과 같은 파일)의 `mongo` 서비스에 다음 내용을 추가하세요. 저희 CI는 이 설정으로 Ubuntu 26.04에서 실행됩니다. 커널 7.0.14 이상에서는 필요하지 않습니다.

```yml title="docker-compose.override.yml"
services:
    mongo:
        environment:
            GLIBC_TUNABLES: glibc.pthread.rseq=1
```

</Info>

Windows나 CentOS 같은 지원되지 않는 운영 체제에 Ayakaleaf Pro를 배포하는 것은 권장하지 않습니다. 설치 및 운영 중에 호환성 문제나 예기치 않은 문제가 발생할 수 있습니다.

하지만 ARM 기반 시스템이나 macOS에서 Ayakaleaf Pro 배포를 시도해 보고 싶다면, 경험과 피드백을 커뮤니티와 공유해 주시기 바랍니다.

### LaTeX 성능

LaTeX는 단일 스레드 프로그램이므로 한 번에 하나의 CPU 코어만 사용할 수 있습니다. 단일 문서를 컴파일할 때 성능은 주로 CPU의 단일 코어 클럭 속도에 의해 제한됩니다. 따라서 CPU의 단일 코어 성능이 빠를수록 문서를 더 빨리 컴파일할 수 있습니다. CPU 코어가 많으면 여러 사용자가 동시에 문서를 컴파일할 때에만 도움이 됩니다.

[ThuThesis 템플릿](https://www.overleaf.com/latex/templates/thuthesis-tsinghua-university-thesis-latex-template/cfwgcxtvkbsx)을 예로 들면, Intel Core i9-14900K(5.6 GHz)에서는 컴파일 시간이 약 6초인 반면, AMD EPYC 7763(3.2 GHz) 기반의 Azure Standard D2as v5 인스턴스(2 vCPU, 8 GiB RAM)에서는 약 13초가 걸립니다.

물론 실제 컴파일 성능은 하드웨어 구성에 따라 달라집니다. 대부분의 서버 CPU는 14900K만큼 높은 클럭 속도로 동작하지 않으므로 비용과 컴파일 속도 사이에서 절충해야 합니다.

한편 LaTeX 컴파일 성능에 대한 심층 분석도 진행했습니다. 관심이 있다면 블로그 글 [Overleaf Benchmark: A Deep Research of Concurrent LaTeX Compilation in Overleaf (SaaS and Self-host)](/ko/blog/2026/overleaf-benchmark  "mention")를 참고하세요.
