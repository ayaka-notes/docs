Claude Code 또는 Codex를 사용하여 Ayakaleaf Pro 배포를 계획하고 실행하세요. 에이전트는 작업하는 동안 MCP를 통해 이 문서를 검색할 수 있습니다.

에이전트는 배포를 보조할 뿐입니다. 명령을 검토하고 자격 증명을 보호하는 책임은 여전히 사용자에게 있습니다.

### 시작하기 전에

SSH로 접속할 수 있는 지원되는 Linux 서버를 준비하세요. 계속하기 전에 [요구 사항](/ko/on-premises/getting-started/requirements  "mention")을 검토하세요.

<Warning>

비밀번호, 개인 키, 토큰, 라이선스 키를 에이전트 프롬프트에 붙여 넣지 마세요. 모든 명령은 실행하기 전에 검토하세요. 특히 파일, 네트워크, 컨테이너를 수정하는 명령은 반드시 확인하세요.

</Warning>

### 문서 연결하기

로컬 에이전트에 문서 MCP 엔드포인트를 추가하세요.

<Tabs>
<Tab title="Claude Code">

```bash wrap
claude mcp add ayakaleaf-pro --scope user --transport http https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>

<Tab title="Codex">

```bash wrap
codex mcp add ayakaleaf-pro --url https://ayakaleaf-pro.ayaka.space/~gitbook/mcp
```

</Tab>
</Tabs>

서버를 추가한 후 새 세션을 시작하세요. 에이전트에게 Ayakaleaf Pro 문서를 검색할 수 있는지 확인해 달라고 요청하세요.

### Ayakaleaf Pro 배포하기

배포 서버에서 터미널을 여세요. 그곳에서 Claude Code 또는 Codex를 시작한 다음, 다음 프롬프트를 보내세요:

```text wrap
Use the Ayakaleaf Pro documentation MCP server to guide this deployment.
First, inspect the requirements and installation guides.
Ask me for missing deployment details before making changes.
Use the Ayakaleaf Toolkit unless the documentation requires another approach.
Before configuring the instance, summarize relevant optional features.
Ask which features and integrations I want to enable.
Include TLS, sandboxed compiles, Git integration, external MongoDB or Redis,
SSO (OIDC, SAML, or LDAP), GitHub Synchronisation, Zotero, S3 storage,
email delivery, branding, and localization when relevant.
Explain each selected option's prerequisites, security impact, and configuration steps.
Keep unselected optional features disabled.
Show each command before running it.
Do not expose, store, or request secrets in chat.
After deployment, verify that the service is healthy and summarize the changes.
```

에이전트는 Docker 설정, Toolkit 구성, 이미지 가져오기, 시작 과정을 안내합니다. 표준 워크플로는 [using-the-toolkit](/ko/on-premises/installation/using-the-toolkit  "mention") 가이드를 따르세요.

### 선택 기능 고르기

에이전트에게 환경에 맞는 기능만 추천해 달라고 요청하세요. 일반적인 선택지는 다음과 같습니다:

* <strong>접근 및 보안:</strong> TLS, 샌드박스 컴파일, OIDC·SAML·LDAP SSO.
* <strong>외부 서비스:</strong> MongoDB, Redis, S3 스토리지, 이메일 발송.
* <strong>협업:</strong> Git 연동, GitHub 동기화, Zotero.

에이전트는 설정을 편집하기 전에 의존성을 설명해야 합니다. 프로덕션 연동을 활성화하기 전에 [toolkit-settings.md](/ko/on-premises/configuration/overleaf-toolkit/toolkit-settings  "mention")와 [authentication](/ko/on-premises/configuration/overleaf-toolkit/authentication  "mention")을 검토하세요.

### 배포 확인하기

에이전트가 단계를 완료한 후:

1. 모든 명령이 오류 없이 완료되었는지 확인합니다.
2. 브라우저에서 설정한 Ayakaleaf Pro URL을 엽니다.
3. [6.-post-installation-tasks.md](/ko/on-premises/installation/using-the-toolkit/6.-post-installation-tasks  "mention")를 완료합니다.

기존 Community Edition 설치가 있다면 새로 배포하는 대신 [migrate-from-existing.md](/ko/on-premises/installation/migrate-from-existing  "mention") 가이드를 사용하세요.
