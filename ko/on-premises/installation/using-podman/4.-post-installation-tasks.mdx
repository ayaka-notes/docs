### 첫 번째 관리자 계정 만들기 {#create-your-first-administrator-account}

[http://localhost:8080/launchpad](http://localhost:8080/launchpad) 또는 `OVERLEAF_SITE_URL` 뒤에 `/launchpad`를 붙인 주소를 열고 관리자 계정을 등록합니다. 여기서부터는 모든 것이 Docker와 같습니다. Docker 가이드의 [6. 설치 후 작업](/ko/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks)을 따르되, 그 안의 `localhost` 링크에서는 포트 `8080`을 사용하세요.

예제 프로젝트를 만들고 컴파일합니다. PDF가 생성되면 컴파일이 Podman을 통해 TeX Live 컨테이너에서 실행된다는 뜻입니다. 컴파일 컨테이너를 보려면 다음을 실행합니다.

```bash title="List the compile containers"
podman ps -a --filter name=project- --format "{{.Names}} {{.Image}} {{.Status}}"
```

### HTTPS 사용 {#use-https}

Toolkit의 [TLS 프록시](/ko/on-premises/configuration/overleaf-toolkit/tls-proxy)는 Podman에서도 동작합니다. `bin/init --tls`를 실행하고, 해당 페이지에 설명된 대로 인증서와 `NGINX_ENABLED=true`를 설정하세요. TLS 프록시는 포트 `80`과 `443`에서 수신하는데, rootless Podman은 기본적으로 이 포트를 사용할 수 없습니다. 권한 없는 사용자가 `80`번부터 포트를 사용할 수 있도록 허용합니다.

```bash title="Allow ports 80 and 443"
echo "net.ipv4.ip_unprivileged_port_start=80" | sudo tee /etc/sysctl.d/99-unprivileged-ports.conf
sudo sysctl --system
```

이렇게 하면 서버의 모든 사용자가 이 포트에서 수신할 수 있으므로, Ayakaleaf Pro 전용 서버에서만 이렇게 하세요. 그런 다음 방화벽에서 포트를 엽니다.

```bash title="Open ports 80 and 443"
sudo firewall-cmd --permanent --add-port=80/tcp --add-port=443/tcp
sudo firewall-cmd --reload
```

`OVERLEAF_SITE_URL`을 `https://` 주소로 설정하고 `bin/up -d`를 실행합니다. 기본값 `NGINX_HTTP_PORT=80`과 `TLS_PORT=443`은 그대로 두세요. 다른 포트를 사용하면 HTTP에서 HTTPS로의 리디렉션이 잘못된 포트로 연결됩니다.

<Info>

TLS 프록시를 사용할 때는 `OVERLEAF_LISTEN_IP`를 `127.0.0.1`로 두어 다른 컴퓨터에서 포트 `8080`에 접근할 수 없도록 하세요.

</Info>

### 업그레이드 {#upgrade}

[배포 업그레이드](/ko/on-premises/maintenance/upgrading-your-deployment)에 설명된 대로 `bin/upgrade`로 업그레이드합니다. Podman에서는 새 버전의 seccomp 프로필을 `config/seccomp/<version>/`에 추출하고 `SECCOMP_PROFILE`도 업데이트합니다.

```text
Over-writing config/version with 6.3.4
Set SECCOMP_PROFILE=/home/<user>/overleaf-toolkit/config/seccomp/6.3.4/clsi-profile.json in config/variables.env
```

업그레이드 후에는 `bin/podman-setup`을 실행하여 설정을 확인하세요.

### SELinux 모드 변경 {#change-the-selinux-mode}

`config/overleaf.rc`의 `SELINUX_MODE`는 SELinux가 `sharelatex` 컨테이너를 어떻게 제한할지 정합니다. 이 페이지들이 설정하는 모드는 `managed`이며, 다른 모드는 [Toolkit 설정](/ko/on-premises/configuration/overleaf-toolkit/toolkit-settings)에 설명되어 있습니다. 변경한 후에는 `bin/up -d`를 실행하세요.
