<Steps>
<Step title="Toolkit 복제">
**Ayakaleaf Toolkit**([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit))을 홈 디렉터리에 복제하고 그 디렉터리로 이동합니다.

```bash title="Clone the Toolkit" wrap
git clone https://github.com/ayaka-notes/toolkit.git ~/overleaf-toolkit
cd ~/overleaf-toolkit
```

이후의 모든 명령은 이 디렉터리에서 실행합니다.
</Step>

<Step title="구성 만들기">
```bash title="Run initialization"
bin/init
```

이 명령은 Docker 가이드의 [3. 구성 초기화하기](/ko/on-premises/installation/using-docker-compose/linux/3.-initialize-the-configuration)에 설명된 대로 `config/overleaf.rc`, `config/variables.env`, `config/version`을 만듭니다. `bin/init`은 아직 Podman이 필요하지 않습니다.
</Step>

<Step title="config/overleaf.rc 설정">
`config/overleaf.rc`를 열고 다음 줄을 변경합니다.

```bash title="config/overleaf.rc"
SERVER_PRO=true
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
```

그런 다음 파일 끝에 다음 줄을 추가합니다.

```bash title="config/overleaf.rc"
SELINUX_MODE=managed
```

| 설정                              | 이유                                                                                                                                                                                                        |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SERVER_PRO=true`                 | `ghcr.io`의 Ayakaleaf Pro 이미지를 사용합니다. 로그인이 필요하지 않습니다.                                                                                                                                   |
| `OVERLEAF_PORT=8080`              | Rootless Podman은 `1024` 미만의 포트에서 수신할 수 없습니다. 기본값 `80`은 실패합니다.                                                                                                                       |
| `SIBLING_CONTAINERS_ENABLED=true` | 각 컴파일을 별도의 TeX Live 컨테이너에서 실행합니다. 기본값이 이미 `true`이며, Podman 설정은 이 모드만 지원합니다.                                                                                          |
| `SELINUX_MODE=managed`            | `sharelatex` 컨테이너를 SELinux 타입 `sharelatex_t`로 실행합니다. 이 타입은 Podman 소켓만 사용할 수 있고 그 이상은 할 수 없습니다. `bin/podman-setup --apply`가 이를 위한 정책 모듈을 설치합니다. 다른 모드는 [Toolkit 설정](/ko/on-premises/configuration/overleaf-toolkit/toolkit-settings)을 참조하세요. |

`DOCKER_SOCKET_PATH`는 그대로 두세요. 다음 단계에서 `bin/podman-setup --apply`가 Podman 소켓으로 설정합니다.

<Warning>

`GIT_BRIDGE_ENABLED=false`로 유지하세요. Ayakaleaf Pro 6.3.4에서는 Git 통합이 Podman에서 동작하지 않습니다. [알려진 제한 사항](/ko/on-premises/installation/using-podman#known-limitations)을 참조하세요.

</Warning>
</Step>

<Step title="TeX Live 이미지 선택">
`config/variables.env`를 열고 `TEX_LIVE_DOCKER_IMAGE`와 `ALL_TEX_LIVE_DOCKER_IMAGES` 앞의 `#`을 제거한 다음 사용할 TeX Live 이미지를 나열합니다.

```bash title="config/variables.env" wrap
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
```

목록이 비어 있으면 `bin/up`은 `Please configure ALL_TEX_LIVE_DOCKER_IMAGES`와 함께 중단됩니다. `texlive-full`은 용량이 크므로, 테스트 서버에서는 훨씬 작은 `ghcr.io/ayaka-notes/texlive-basic:2026.1`도 사용할 수 있습니다. 사용 가능한 이미지는 [샌드박스 컴파일](/ko/on-premises/configuration/overleaf-toolkit/sandboxed-compiles)을 참조하세요.

`OVERLEAF_SITE_URL` 같은 다른 변수는 [5. 인스턴스 개인화](/ko/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance#required-environment-variables)에 설명된 대로 설정합니다. 기본 수신 주소를 사용하면 `http://localhost:8080`을 사용하세요.
</Step>
</Steps>
