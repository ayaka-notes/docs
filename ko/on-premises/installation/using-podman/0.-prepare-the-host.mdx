Podman을 직접 설치할 필요는 없습니다. [2. podman-setup 실행](/ko/on-premises/installation/using-podman/2.-run-podman-setup)이 필요한 다른 패키지와 함께 설치합니다. 여기서는 호스트를 확인하고 Toolkit을 다운로드하는 데 필요한 `git`만 설치합니다.

<Steps>
<Step title="운영 체제와 SELinux 확인">
`root`가 아니라 Ayakaleaf Pro를 실행할 사용자로 로그인한 다음 배포판과 SELinux 모드를 확인합니다.

```bash title="Check the host"
grep PRETTY_NAME /etc/os-release
getenforce
```

버전 9 이상의 RHEL, Rocky Linux, AlmaLinux 또는 CentOS Stream과 `Enforcing`이 표시되어야 합니다.

```text
PRETTY_NAME="Rocky Linux 9.9 (Blue Onyx)"
Enforcing
```
</Step>

<Step title="sudo를 사용할 수 있는지 확인">
`bin/podman-setup --apply`는 `sudo`로 패키지를 설치하고 SELinux 모듈을 로드하며, 필요할 때 비밀번호를 묻습니다.

```bash title="Check sudo"
sudo -v
```

실패하면 관리자에게 사용자를 `wheel` 그룹에 추가해 달라고 요청하세요.
</Step>

<Step title="git 설치">
```bash title="Install git"
sudo dnf install -y git
```

<Warning>

이 호스트에 Docker Engine을 설치하지 마세요. `bin/podman-setup`이 설치하는 `podman-docker` 패키지가 `docker` 명령을 제공하며, Toolkit은 `podman` 명령이 존재하면 항상 호스트를 Podman으로 취급합니다.

</Warning>
</Step>
</Steps>
