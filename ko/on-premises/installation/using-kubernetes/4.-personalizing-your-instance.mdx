ConfigMap `overleaf-env`는 Toolkit의 `config/variables.env`를 대신합니다. [Toolkit 문서](/ko/on-premises/configuration/overleaf-toolkit/environment-variables)의 모든 환경 변수는 여기에 넣고, 시크릿은 [2단계](/ko/on-premises/installation/using-kubernetes/2.-create-the-namespace-and-secrets)의 Secret에 넣습니다.

```yaml title="30-config.yaml" wrap
apiVersion: v1
kind: ConfigMap
metadata:
  name: overleaf-env
  namespace: overleaf
data:
  OVERLEAF_APP_NAME: Ayakaleaf Pro
  OVERLEAF_SITE_URL: http://192.0.2.10:30080      # the address users open; https://... behind TLS
  OVERLEAF_ADMIN_EMAIL: admin@example.com
  # Emails: add the sender and the SMTP server together, see Email delivery
  # All members, so that the driver finds the primary even when mongo-0 is down
  OVERLEAF_MONGO_URL: mongodb://mongo-0.mongo:27017,mongo-1.mongo:27017,mongo-2.mongo:27017/sharelatex?replicaSet=overleaf
  OVERLEAF_REDIS_HOST: redis
  REDIS_HOST: redis
  ENABLED_LINKED_FILE_TYPES: project_file,project_output_file,url
  ENABLE_CONVERSIONS: "true"
  EMAIL_CONFIRMATION_DISABLED: "true"
  # Requests arrive from kube-proxy or your ingress controller, inside the pod network
  OVERLEAF_TRUSTED_PROXY_IPS: loopback,10.244.0.0/16
  # Sandboxed compiles. The HOST_DIR paths are paths ON THE NODE: the hostPath volumes that
  # the Deployment mounts at /var/lib/overleaf/data/{compiles,output,cache}.
  SANDBOXED_COMPILES: "true"
  SANDBOXED_COMPILES_SIBLING_CONTAINERS: "true"
  DOCKER_RUNNER: "true"
  SANDBOXED_COMPILES_HOST_DIR_COMPILES: /srv/overleaf/compiles
  SANDBOXED_COMPILES_HOST_DIR_OUTPUT: /srv/overleaf/output
  SANDBOXED_COMPILES_HOST_DIR_CACHE: /srv/overleaf/cache
  # Each image must be pulled into Docker on every node that can run Ayakaleaf Pro (step 0)
  ALL_TEX_LIVE_DOCKER_IMAGES: ghcr.io/ayaka-notes/texlive-full:2026.1
  ALL_TEX_LIVE_DOCKER_IMAGE_NAMES: TeX Live 2026
  TEX_LIVE_DOCKER_IMAGE: ghcr.io/ayaka-notes/texlive-full:2026.1
```

```bash
kubectl apply -f 30-config.yaml
```

| 변수                                    | 설정 값                                                                                                                                                         |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OVERLEAF_SITE_URL`                     | 사용자가 브라우저에 입력하는 URL. [5단계](/ko/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro)의 NodePort를 사용하는 경우 임의 노드의 IP와 포트 `30080`; 인그레스 또는 로드 밸런서 뒤에서는 해당 URL. |
| `OVERLEAF_MONGO_URL`                    | 레플리카 세트. `rs.initiate`에서 지정한 이름으로 `?replicaSet=`을 사용하세요.                                                                                  |
| `OVERLEAF_REDIS_HOST` 및 `REDIS_HOST`   | 둘 다 Redis Service로 설정.                                                                                                                                    |
| `OVERLEAF_TRUSTED_PROXY_IPS`            | `loopback`과 프록시가 연결해 오는 네트워크. `10.244.0.0/16`은 flannel의 파드 네트워크이므로, 클러스터의 파드 CIDR을 사용하세요.                              |
| `SANDBOXED_COMPILES_HOST_DIR_*`         | 컴파일 볼륨의 노드 경로. [5단계](/ko/on-premises/installation/using-kubernetes/5.-deploy-ayakaleaf-pro)의 `hostPath` 볼륨과 일치해야 합니다.                  |

HTTPS 뒤에서는 `OVERLEAF_SECURE_COOKIE: "true"`도 설정하세요. [TLS 프록시](/ko/on-premises/configuration/overleaf-toolkit/tls-proxy)를 참조하세요.

<Info>

변경된 ConfigMap은 재시작 후에만 실행 중인 파드에 반영됩니다: `kubectl -n overleaf rollout restart deployment/overleaf`.

</Info>
