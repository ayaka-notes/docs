### 첫 번째 관리자 계정 만들기 {#creating-your-first-administrator-account}

`OVERLEAF_SITE_URL` 뒤에 `/launchpad`를 붙인 주소(예: `http://192.0.2.10:30080/launchpad`)를 열고, [Toolkit의 설치 후 작업](/ko/on-premises/installation/using-docker-compose/linux/6.-post-installation-tasks)에 설명된 대로 관리자 계정을 등록하세요. 그런 다음 예제 프로젝트를 만들고 컴파일하세요.

명령줄에서 사용자를 만들 수도 있습니다.

```bash
kubectl -n overleaf exec deploy/overleaf -- bash -c \
  'cd /overleaf/services/web && node modules/server-ce-scripts/scripts/create-user.mjs --admin --email=admin@example.com'
```

비밀번호를 설정하는 링크가 출력됩니다.

### 컴파일이 샌드박스에서 실행되는지 확인 {#checking-that-compiles-are-sandboxed}

프로젝트를 컴파일한 다음, 파드를 실행하는 노드를 확인하세요.

```bash
kubectl -n overleaf get pod -l app=overleaf -o wide   # NODE column
# on that node:
sudo docker ps -a --filter ancestor=ghcr.io/ayaka-notes/texlive-full:2026.1
ls -ln /srv/overleaf/compiles                          # owned by uid 33 (www-data)
```

각 컴파일은 `project-<project id>-<user id>-...`라는 이름의 수명이 짧은 컨테이너로 표시됩니다.

### 로그와 셸 {#logs-and-a-shell}

| Toolkit          | Kubernetes                                                               |
| ---------------- | ------------------------------------------------------------------------ |
| `bin/logs web`   | `kubectl -n overleaf exec deploy/overleaf -- tail -f /var/log/overleaf/web.log` |
| `bin/shell`      | `kubectl -n overleaf exec -it deploy/overleaf -- bash`                    |
| `bin/up`         | `kubectl apply -f .` 실행 후 `kubectl -n overleaf rollout restart deployment/overleaf` |

컨테이너는 `/var/log/overleaf/`에 서비스별로 로그 파일을 하나씩 기록합니다(`web.log`, `clsi.log`, `real-time.log`, `document-updater.log`, ...). `kubectl logs`는 시작 출력을 보여줍니다.

### Q\&A {#q&a}

<Accordion title="컴파일이 실패하거나 끝나지 않습니다.">

<strong>답변:</strong> 파드를 실행하는 노드에서 Docker가 실행 중이고 `TEX_LIVE_DOCKER_IMAGE`에 지정된 이미지가 있는지, 그리고 `SANDBOXED_COMPILES_HOST_DIR_*`가 `hostPath` 경로와 일치하는지 확인하세요. 파드 내 `/var/log/overleaf/clsi.log`에 실패한 단계가 표시됩니다.

</Accordion>
