<Danger>

다음 안내는 **Community Edition** 설치에**만** 적용됩니다. Ayakaleaf Pro 사용자는 [샌드박스 컴파일](/ko/on-premises/configuration/overleaf-toolkit/sandboxed-compiles)을 활성화할 것을 강력히 권장합니다. 샌드박스 컴파일을 사용하면 [overleaf.com](https://www.overleaf.com)에서 사용하는 것과 거의 동일한 TeX Live 이미지를 사용할 수 있을 뿐만 아니라, 프로젝트 컴파일 간 격리를 통해 보안도 강화됩니다.

</Danger>

대역폭을 절약하기 위해 Overleaf Community Edition과 Ayakaleaf Pro 이미지에는 [TeX Live](https://www.tug.org/texlive/)가 최소 구성으로만 설치되어 있습니다. `sharelatex` 컨테이너에서 [tlmgr](https://www.tug.org/texlive/tlmgr.html) 명령을 사용해 패키지를 추가로 설치하거나 TeX Live 전체 설치로 업그레이드할 수 있습니다.

#### sharelatex 컨테이너 내부로 들어가기

`sharelatex` 컨테이너 내부에서 셸을 시작하려면 다음을 실행하세요.

```bash
bin/shell
```

다음과 같은 프롬프트가 표시됩니다.

```bash
root@309b192d4030:/#
```

이후 안내는 컨테이너 내부에 있다고 가정합니다.

#### 현재 TeX Live 버전 확인

TeX Live는 매년 4월경에 릴리스됩니다. `tlmgr` 사용 방법은 현재 릴리스를 사용하는지 이전 릴리스를 사용하는지에 따라 다릅니다. `tlmgr --version`으로 실행 중인 TeX Live 버전을 확인할 수 있습니다. 예를 들어 다음 설치는 TeX Live 2021을 실행하고 있습니다.

```bash
# tlmgr --version
tlmgr revision 59291 (2021-05-21 05:14:40 +0200)
tlmgr using installation: /usr/local/texlive/2021
TeX Live (https://tug.org/texlive) version 2021
```

<Info>

현재 TeX Live 릴리스는 [TeX Live 홈페이지](https://www.tug.org/texlive/)에서 확인할 수 있습니다.

</Info>

이전 TeX Live 버전을 실행 중이라면 두 가지 방법이 있습니다. 일반적으로 TeX Live 릴리스 직후 새 버전의 Overleaf Docker 이미지가 릴리스되므로, 이를 기다렸다가 `bin/upgrade` 스크립트로 배포를 업그레이드할 수 있습니다. 또는 이전 TeX Live 릴리스를 유지하고 싶다면 먼저 `tlmgr`가 과거 저장소를 사용하도록 설정해야 합니다. 설정 방법은 [여기](https://www.tug.org/texlive/acquire.html#past)에서 확인할 수 있습니다.

#### 패키지 설치

TeX Live 전체를 설치하려면 `sharelatex` 컨테이너 내부에서 다음 명령을 실행하세요.

```text
tlmgr install scheme-full
```

개별 패키지를 수동으로 설치할 수도 있습니다.

```bash
tlmgr install tikzlings tikzmarmots tikzducks
```

<Warning>

`3.3.0` 릴리스부터는 모든 바이너리를 시스템 경로에 올바르게 심볼릭 링크하기 위해 `tlmgr install`을 사용할 때마다 `tlmgr path add`를 다시 실행해야 **합니다**.

</Warning>

이 밖에도 많은 명령을 사용할 수 있습니다. 자세한 내용은 다음 명령으로 확인하세요.

```text
tlmgr help
```

작업을 마쳤으면 `exit`를 입력하거나 Control-D를 눌러 셸을 종료합니다.

#### 변경 사항 저장

방금 적용한 변경 사항은 `sharelatex` 컨테이너를 변경했지만 일시적입니다. 구성 업데이트 등으로 Docker Compose가 컨테이너를 다시 생성하면 변경 사항이 사라집니다.

변경 사항을 영구적으로 유지하려면 `docker commit`을 사용해 새 Docker 이미지로 저장하세요.

```bash
cat config/version #5.2.1
docker commit sharelatex sharelatex/sharelatex:5.2.1-with-texlive-full
echo 5.2.1-with-texlive-full > config/version
```

변경 사항을 커밋한 후 `config/version`을 그에 맞게 업데이트합니다. 그런 다음 `bin/up`을 실행해 `sharelatex` 컨테이너를 다시 생성합니다.

<Danger>

새 Overleaf 버전으로 [업그레이드](https://github.com/overleaf/toolkit/blob/master/doc/upgrading.md)할 때마다 이 단계를 반복해야 합니다.

</Danger>
