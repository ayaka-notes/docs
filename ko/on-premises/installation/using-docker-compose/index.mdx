단일 서버에서 Docker Compose를 사용하는 것이 Ayakaleaf Pro를 배포하는 데 권장되는 방법입니다. 배포는 [Toolkit](https://github.com/ayaka-notes/toolkit)을 통해 실행합니다. Toolkit은 `docker compose`를 감싸고 하나의 `config/` 디렉터리에서 설정을 읽는 스크립트 모음이므로, `docker compose up` 대신 `bin/up`을 사용합니다.

Docker를 실행할 머신에 맞는 가이드를 선택하세요.
