### 첫 번째 관리자 계정 만들기 {#creating-your-first-administrator-account}

브라우저에서 [http://localhost/launchpad](http://localhost/launchpad)를 엽니다. `OVERLEAF_LISTEN_IP` 또는 `OVERLEAF_PORT`를 변경했다면 대신 `OVERLEAF_SITE_URL`을 사용하세요. 예: `http://192.168.1.20:8080/launchpad`. 이 페이지의 다른 `localhost` 링크도 마찬가지입니다. 이메일과 비밀번호 입력란이 있는 양식이 표시됩니다. 관리자 계정으로 사용할 자격 증명을 입력한 다음 **Register**를 클릭하세요.

<Info>

비밀번호는 8자 이상(72자 이하)이어야 하며, 이메일 주소를 포함하거나 이메일 주소와 너무 비슷해서는 안 되고, 유효한 문자만 포함해야 합니다.

</Info>

![런치패드에서 첫 번째 관리자 계정 만들기](/images/on-premises/post-installation-launchpad.png)

그러면 로그인 페이지([http://localhost/login](http://localhost/login))로 이동합니다. 자격 증명을 입력하세요. 로그인하면 런치패드가 다시 표시되며, 이번에는 상태 확인 항목이 함께 표시됩니다.

![로그인 후 런치패드 상태 확인](/images/on-premises/post-installation-status-checks.png)

페이지 하단의 녹색 버튼을 클릭하여 Overleaf 사용을 시작하세요.

### 첫 번째 예제 프로젝트 만들기 {#creating-your-first-example-project}

브라우저에서 [http://localhost/project](http://localhost/project)를 열면 첫 번째 프로젝트를 만들라는 버튼이 표시됩니다.

![새 프로젝트 만들기 메뉴](/images/on-premises/post-installation-create-project.png)

이 버튼을 클릭하고 **Example project**를 선택한 다음 화면의 안내를 따르세요.

새 프로젝트로 이동하면 텍스트 편집기와 PDF 미리보기가 표시됩니다.

![편집기에 열린 예제 프로젝트](/images/on-premises/post-installation-editor.png)

마지막으로 왼쪽 상단의 Overleaf 로고를 클릭하여 프로젝트 페이지로 돌아갈 수 있습니다.
