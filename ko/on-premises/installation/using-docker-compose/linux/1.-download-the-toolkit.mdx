### Toolkit 다운로드 {#downloading-the-toolkit}

Ayakaleaf Pro는 Docker에서 Overleaf를 실행해 주는 스크립트 모음인 **Ayakaleaf Toolkit**([ayaka-notes/toolkit](https://github.com/ayaka-notes/toolkit))으로 설치합니다.

기본적으로 Toolkit은 무료 공식 Overleaf Community Edition(CE)을 시작합니다. [4. Ayakaleaf Pro 이미지 가져오기](/ko/on-premises/installation/using-docker-compose/linux/4.-get-overleaf-pro-images)에서 설정 하나로 Ayakaleaf Pro로 전환할 수 있습니다.

<Accordion title="이미 공식 Overleaf Toolkit(overleaf/toolkit)을 실행 중인가요?">

다시 설치할 필요가 없습니다. 기존 설치를 유지하고 [4. Ayakaleaf Pro 이미지 가져오기](/ko/on-premises/installation/using-docker-compose/linux/4.-get-overleaf-pro-images)의 마지막 부분을 따르세요.

</Accordion>

<Steps>
<Step title="Ayakaleaf Toolkit 저장소 클론">
Toolkit을 설치하려면 설치할 경로로 이동한 다음, 아래 명령으로 Ayakaleaf Toolkit 저장소를 클론하세요.

```bash title="Clone repository" wrap
git clone https://github.com/ayaka-notes/toolkit.git ./overleaf-toolkit
```

<Info>

권한 관련 문제를 방지하려면 Toolkit을 사용자의 `$HOME` 디렉터리에 설치하는 것을 권장합니다.

</Info>
</Step>

<Step title="Toolkit 디렉터리로 이동">
클론이 완료될 때까지 기다린 후, 새로 생성된 `overleaf-toolkit` 디렉터리로 이동합니다.

```bash title="Change directory"
cd ./overleaf-toolkit
```
</Step>
</Steps>
