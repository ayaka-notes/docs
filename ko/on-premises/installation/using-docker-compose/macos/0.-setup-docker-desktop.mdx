Ayakaleaf Pro는 Docker에서 실행됩니다. Mac에서는 Linux 가상 머신에서 Docker 엔진을 실행하는 Docker Desktop을 사용합니다.

<Steps>
<Step title="Docker Desktop 설치 및 시작">
Mac(Apple silicon 또는 Intel)에 맞는 [Docker Desktop](https://docs.docker.com/desktop/setup/install/mac-install/) 빌드를 설치하고 실행한 다음 엔진이 시작될 때까지 기다리세요. 터미널에서 시작할 수도 있습니다.

```bash
open -a Docker
```
</Step>

<Step title="Docker 엔진 확인">
터미널에서 다음 명령을 실행하세요.

```bash
docker context show
docker info
docker compose version
```

컨텍스트는 로컬 Docker Desktop 엔진(일반적으로 `desktop-linux`)을 가리켜야 합니다. 다른 컨텍스트가 선택되어 있다면 계속하기 전에 Docker Desktop으로 전환하세요.

```bash
docker context use desktop-linux
```

`docker info`는 **Server** 섹션을 출력해야 합니다. `docker --version`만으로는 클라이언트가 설치되어 있다는 것만 알 수 있습니다.
</Step>

<Step title="리소스 및 파일 공유 확인">
Docker Desktop **Settings**에서 CPU, 메모리, 디스크 한도를 [시작하기 전에](/ko/on-premises/installation/using-docker-compose/macos#before-you-start)와 비교하여 확인하고, 파일 공유 설정도 확인하세요. [Docker Desktop 설정](https://docs.docker.com/desktop/settings-and-maintenance/settings/)을 참조하세요.

이 가이드는 Toolkit을 Docker Desktop이 기본적으로 공유하는 `/Users` 아래에 둡니다. 다른 위치를 사용하고 `bin/up`이 `Mounts denied`로 실패하면 해당 디렉터리를 파일 공유에 추가하세요.
</Step>

<Step title="Sandboxed Compiles를 위한 Docker 소켓 확인">
Toolkit은 컴파일마다 별도의 TeX Live 컨테이너를 시작할 수 있도록 `/var/run/docker.sock`을 애플리케이션에 마운트합니다. `config/overleaf.rc`에서 `DOCKER_SOCKET_PATH=/var/run/docker.sock`을 유지하세요.

macOS의 Docker CLI는 `~/.docker/run/docker.sock`을 통해 연결할 수 있습니다. 이는 Mac의 클라이언트 엔드포인트일 뿐, Toolkit의 마운트 소스를 변경할 이유가 아닙니다. 컴파일러에는 Linux 컨테이너에서 보이는 엔진 소켓이 필요합니다.

Mac에 `/var/run/docker.sock`이 없다면 **Settings → Advanced**에서 **Allow the default Docker socket to be used**를 켜세요. [Docker의 권한 요구 사항](https://docs.docker.com/desktop/setup/install/mac-permission-requirements/)을 참조하세요.

<Danger>

오류를 우회하기 위해 소켓에 `chmod 777`을 실행하지 마세요. Docker 소켓에 대한 접근은 Docker VM에 대한 root 수준의 접근과 같습니다.

</Danger>
</Step>
</Steps>
