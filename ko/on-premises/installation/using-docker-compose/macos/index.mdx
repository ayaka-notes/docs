이 섹션에서는 Docker Desktop과 [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit)을 사용하여 Mac에서 Ayakaleaf Pro를 로컬로 실행합니다. 이 가이드는 `http://localhost:8080`을 사용하고, 데이터를 홈 디렉터리에 보관하며, 샌드박스 컨테이너에서 TeX Live 2026으로 컴파일합니다.

Docker Desktop은 애플리케이션, MongoDB, Redis, TeX Live 컴파일러를 Linux 가상 머신에서 실행합니다. macOS 자체에 MongoDB, Redis 또는 MacTeX를 설치할 필요는 없습니다.

이 설정은 개인 사용과 로컬 테스트용으로 사용하세요. 항상 켜져 있는 공유 서비스에는 HTTPS, 백업, 접근 제어를 갖춘 [Linux 가이드](/ko/on-premises/installation/using-docker-compose/linux)를 권장합니다. Mac이 잠자기 상태이거나 Docker Desktop이 중지되어 있으면 인스턴스를 사용할 수 없습니다. [인스턴스 가용성 유지](/ko/on-premises/installation/using-docker-compose/macos/6.-post-installation-tasks#keep-the-instance-available)를 참조하세요.

## 시작하기 전에 {#before-you-start}

다음이 필요합니다.

* [Docker Desktop for Mac](https://docs.docker.com/desktop/setup/install/mac-install/)에서 지원하는 macOS 버전.
* Git, [Homebrew](https://brew.sh/), GNU sed. Toolkit은 macOS에 내장된 BSD sed가 받아들이지 않는 GNU sed 옵션을 사용합니다.
* macOS와 Docker 모두를 위한 충분한 리소스. 소규모 로컬 인스턴스라면 Docker Desktop에 CPU 4개와 메모리 8 GB를 할당하는 것으로 시작하세요. 이는 권장 시작점이며, 측정된 최소 요구 사항이 아닙니다.
* 전체 TeX Live 이미지를 위한 최소 40 GB의 여유 저장 공간과 프로젝트를 위한 공간. Mac의 여유 공간과 Docker Desktop의 디스크 사용량 한도를 모두 확인하세요. TeX Live 버전은 하나로 시작하세요. 버전을 하나 추가할 때마다 거의 같은 만큼의 공간이 더 필요합니다.

애플리케이션과 TeX Live 이미지는 `arm64`와 `amd64`용으로 게시됩니다. Apple silicon에서는 Docker가 네이티브 ARM 이미지를 선택하도록 두고 `platform: linux/amd64`를 강제하지 마세요.
