title: 3. 구성 초기화하기
description: bin/init으로 Mac에서 Toolkit 구성 파일을 만듭니다.
icon: circle-play
---

GNU sed가 `PATH`에 있는 터미널의 Toolkit 디렉터리에서 다음을 실행하세요.

```bash
bin/init
```

`bin/init`은 세 개의 파일을 만듭니다.

| 파일 | 용도 |
| --- | --- |
| `config/overleaf.rc` | 컨테이너 설정, 게시 포트, 데이터 위치 |
| `config/variables.env` | 애플리케이션 설정 및 비밀 값 |
| `config/version` | 애플리케이션 이미지 버전 |

또한 `config/variables.env`에 `OVERLEAF_INVITE_TOKEN_SECRET`을 생성합니다. 이 값을 유지하고, 이 파일을 공개하거나 버전 관리에 커밋하지 마세요.

새 설치에서는 Toolkit이 선택한 버전을 유지하세요. 나중에 기존 인스턴스의 버전을 변경하려면 [배포 업그레이드](/ko/on-premises/maintenance/upgrading-your-deployment)를 따르세요.

<Warning>

`bin/init`이 `sed: ... invalid command code`로 중지되면 macOS의 BSD sed로 실행된 것입니다. 이렇게 실패한 실행은 `config/`에 세 파일을 모두 남기면서 `OVERLEAF_INVITE_TOKEN_SECRET`을 비워 둘 수 있으며, 그 후 `bin/init`을 다시 실행하면 `Config files already exist`가 표시됩니다. [문제 해결](/ko/on-premises/installation/using-docker-compose/macos/troubleshooting#initialization-fails-with-invalid-command-code)을 참조하세요.

</Warning>
