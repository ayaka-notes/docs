Toolkit은 macOS와 Linux에서 동일합니다. 구조, `config/` 디렉터리, `bin/` 명령은 Linux 가이드의 [2. Toolkit 살펴보기](/ko/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit)에 설명되어 있습니다.

macOS에서는 세 가지 차이점을 기억하세요.

* GNU sed가 `PATH`의 맨 앞에 있는 터미널에서 스크립트를 실행하세요. [1. Toolkit 다운로드](/ko/on-premises/installation/using-docker-compose/macos/1.-download-the-toolkit)를 참조하세요.
* `bin/up`, `bin/start`, `bin/docker-compose`처럼 Docker와 통신하는 스크립트를 실행하기 전에 Docker Desktop을 시작하세요.
* `bin/doctor`에는 공식 Overleaf Toolkit에서 물려받은 검사가 포함되어 있습니다. macOS에서는 `This system seems to not be Linux` 경고가 표시되는 것이 정상이며, `quay.io`에 로그인되어 있지 않다는 경고는 공개 `ghcr.io/ayaka-notes/overleaf-pro` 이미지에는 해당되지 않습니다. 보고서의 다른 문제는 여전히 중요합니다.
