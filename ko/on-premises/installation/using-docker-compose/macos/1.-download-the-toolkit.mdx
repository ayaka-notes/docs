<Steps>
<Step title="Git 및 Homebrew 확인">
```bash
git --version
brew --version
```

Git을 실행할 때 macOS가 Command Line Tools 설치를 요청하면 먼저 설치하세요. Homebrew가 없다면 [공식 안내](https://brew.sh/)에 따라 설치하세요.
</Step>

<Step title="GNU sed를 PATH에 추가">
Toolkit 스크립트는 macOS에 내장된 BSD sed가 거부하는 GNU sed 옵션을 사용합니다. [GNU sed](https://formulae.brew.sh/formula/gnu-sed)를 설치하고 현재 터미널에서 `PATH`의 맨 앞에 두세요.

```bash
brew install gnu-sed
export PATH="$(brew --prefix gnu-sed)/libexec/gnubin:$PATH"
sed --version
```

마지막 명령은 **GNU sed**를 출력해야 합니다.

`alias sed=gsed` 같은 별칭으로는 충분하지 않습니다. Toolkit은 Bash 스크립트를 실행하며, 이 스크립트에서는 대화형 셸의 별칭이 보이지 않습니다. `/usr/bin/sed`를 교체할 필요는 없습니다.

Toolkit에 사용하는 새 터미널마다 `export PATH=...` 줄을 다시 실행하거나, Homebrew 자체 초기화 다음에 셸 시작 파일에 추가하세요.
</Step>

<Step title="Ayakaleaf Toolkit 저장소 복제">
유지되는 디렉터리를 선택하세요. 실제 데이터베이스와 프로젝트 데이터에는 `/tmp`, 이동식 드라이브, iCloud Drive 같은 클라우드 동기화 폴더를 사용하지 마세요. 이 가이드는 `~/ayakaleaf-toolkit`을 사용합니다.

```bash
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

<Warning>

디렉터리에 이미 설치가 있다면 그대로 사용하거나, 새 인스턴스를 위한 다른 디렉터리를 선택하세요. 기존 배포 위에 새 구성을 초기화하지 마세요.

</Warning>
</Step>
</Steps>
