---
title: 5. 인스턴스 개인화
description: Mac의 로컬 인스턴스에 대한 포트, 사이트 URL, TeX Live 이미지를 설정하고, Docker VM 커널을 확인한 다음 Ayakaleaf Pro를 시작합니다.
icon: square-sliders
---

<Steps>
<Step title="컨테이너 설정">
`config/overleaf.rc`에서 다음 기존 항목을 수정하세요.

```bash title="config/overleaf.rc"
PROJECT_NAME=ayakaleaf-macos
SERVER_PRO=true
OVERLEAF_LISTEN_IP=127.0.0.1
OVERLEAF_PORT=8080
SIBLING_CONTAINERS_ENABLED=true
DOCKER_SOCKET_PATH=/var/run/docker.sock
```

기본 데이터 경로와 번들된 MongoDB 및 Redis 서비스는 그대로 유지하세요. `OVERLEAF_LISTEN_IP=127.0.0.1`이면 이 Mac의 브라우저에서만 인스턴스를 열 수 있습니다.
</Step>

<Step title="애플리케이션 설정">
`config/variables.env`에서 다음 값을 설정하고, 같은 이름의 활성 항목이 있다면 교체하세요.

```dotenv title="config/variables.env"
OVERLEAF_SITE_URL=http://localhost:8080
TEX_LIVE_DOCKER_IMAGE=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGES=ghcr.io/ayaka-notes/texlive-full:2026.1
ALL_TEX_LIVE_DOCKER_IMAGE_NAMES="TeX Live 2026"
```

세션 비밀 값을 생성하세요.

```bash
openssl rand -hex 32
```

결과를 `config/variables.env`에 `OVERLEAF_SESSION_SECRET`으로 추가하세요. 이 값이 없으면 컨테이너를 다시 만드는 `bin/up`을 실행할 때마다 모든 사용자가 로그아웃됩니다. [환경 변수](/ko/on-premises/configuration/overleaf-toolkit/environment-variables)를 참조하세요.

이메일이 없는 로컬 인스턴스라면 SMTP 설정과 `OVERLEAF_EMAIL_FROM_ADDRESS`는 설정하지 않은 채로 두세요. Git Bridge, 외부 인증 및 기타 통합은 나중에 각각의 [구성 페이지](/ko/on-premises/configuration/overleaf-toolkit)에 따라 추가할 수 있습니다.
</Step>

<Step id="check-the-docker-vms-linux-kernel" title="Docker VM의 Linux 커널 확인">
MongoDB는 macOS가 아니라 Docker Desktop 가상 머신의 Linux 커널에서 실행됩니다. 처음 시작하기 전에 커널 버전을 확인하세요.

```bash
docker info --format '{{.KernelVersion}}'
```

MongoDB는 Linux 커널 **6.19부터 7.0.13까지**와의 비호환성을 문서화하고 있으며, 이는 Docker의 MongoDB에도 영향을 줍니다. 해결책은 커널 **7.0.14 이상**이며, Docker Desktop 업데이트와 함께 제공됩니다. [MongoDB의 프로덕션 노트](https://www.mongodb.com/docs/manual/administration/production-notes/)를 참조하세요.

Docker VM이 영향을 받는 커널을 사용한다면 `config/docker-compose.override.yml`에 다음을 추가하고, 이미 있는 `services`와 병합하세요.

```yaml title="config/docker-compose.override.yml"
services:
  mongo:
    environment:
      GLIBC_TUNABLES: glibc.pthread.rseq=1
```

<Warning>

수정된 커널이 제공되면 업데이트하세요. 커널이 영향을 받는 범위 밖에 있다면 이 해결 방법은 필요하지 않습니다.

</Warning>
</Step>

<Step title="인스턴스 시작">
Toolkit 디렉터리에서 다음을 실행하세요.

```bash
bin/up -d
```

Toolkit은 MongoDB의 복제본 세트를 초기화하고, TeX Live 이미지를 가져오고, 애플리케이션을 시작합니다. 첫 다운로드에는 시간이 걸립니다. 진행 상황을 확인하려면 다음을 실행하세요.

```bash
bin/docker-compose ps
bin/docker-compose logs --tail=100 -f sharelatex
```

로그 확인을 멈추려면 `Ctrl+C`를 누르세요. 컨테이너는 계속 실행됩니다.

게시된 포트와 첫 실행 페이지를 확인하세요.

```bash
bin/docker-compose port sharelatex 80
curl -I http://localhost:8080/launchpad
```

포트는 `127.0.0.1:8080`이어야 합니다.
</Step>
</Steps>

<Info>

나중에 다른 컴퓨터에서 인스턴스를 열려면 Linux 가이드의 [5. 인스턴스 개인화](/ko/on-premises/installation/using-docker-compose/linux/5.-personalizing-your-instance)에 설명된 대로 수신 주소와 사이트 URL을 변경하고 HTTPS를 설정하세요. 그러면 Mac이 잠자기 상태가 되지 않아야 합니다. [인스턴스 가용성 유지](/ko/on-premises/installation/using-docker-compose/macos/6.-post-installation-tasks#keep-the-instance-available)를 참조하세요.

</Info>
