Toolkit은 Linux와 동일합니다. 구조, `config/` 디렉터리, `bin/` 명령은 Linux 가이드의 [2. Toolkit 살펴보기](/ko/on-premises/installation/using-docker-compose/linux/2.-familiarize-yourself-with-the-toolkit)에 설명되어 있습니다.

Windows에서는 다음 차이점을 기억하세요.

* `bin/` 명령은 **Ubuntu Bash**의 `~/ayakaleaf-toolkit`에서 실행하세요. **PowerShell**로 표시된 명령은 대신 Windows에서 실행합니다.
* `bin/up`, `bin/start`, `bin/docker-compose`를 사용하기 전에 Docker Desktop을 시작하고 Ubuntu의 WSL Integration을 활성화하세요.
* 구성 파일은 Linux 줄 끝(LF)으로 유지하세요. Ubuntu의 `nano`나 WSL에 연결된 편집기로 수정하세요. CRLF 줄 끝은 Bash 오류를 일으킬 수 있습니다.
* `bin/doctor`는 Ubuntu 안에서 Linux 검사를 실행합니다. `quay.io`에 로그인되어 있지 않다는 경고는 공개 `ghcr.io/ayaka-notes/overleaf-pro` 이미지에는 해당되지 않습니다. 다른 경고는 여전히 주의가 필요합니다.

```bash
bin/doctor
```
