**Ubuntu**의 Toolkit 디렉터리에서 다음을 실행하세요.

```bash
bin/init
```

`bin/init`은 세 개의 파일을 만듭니다.

| 파일 | 용도 |
| --- | --- |
| `config/overleaf.rc` | 컨테이너 설정, 게시 포트, 데이터 위치 |
| `config/variables.env` | 애플리케이션 설정 및 비밀 값 |
| `config/version` | 애플리케이션 이미지 버전 |

또한 `config/variables.env`에 `OVERLEAF_INVITE_TOKEN_SECRET`을 생성합니다. 이 값을 유지하고, 이 파일을 공개하거나 버전 관리에 커밋하지 마세요.

새 설치에서는 Toolkit이 선택한 버전을 유지하세요. 나중에 기존 인스턴스의 버전을 변경하려면 [배포 업그레이드](/ko/on-premises/maintenance/upgrading-your-deployment)를 따르세요.

<Info>

`bin/init`은 기존 구성을 덮어쓰지 않습니다. 파일이 이미 존재한다고 보고하면 계속하기 전에 해당 파일을 확인하세요. 인스턴스를 다시 시작하거나 업그레이드할 때는 `config/`와 `data/`를 유지하세요.

</Info>
