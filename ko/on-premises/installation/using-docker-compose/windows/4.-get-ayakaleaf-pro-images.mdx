title: 4. Ayakaleaf Pro 이미지 가져오기
description: WSL 2의 Ubuntu에 있는 Toolkit을 공개 Ayakaleaf Pro 이미지로 전환합니다.
icon: split
---

Ayakaleaf Pro는 [GitHub Container Registry(ghcr.io)](https://github.com/ayaka-notes/ayakaleaf-pro/pkgs/container/overleaf-pro/)에 있는 무료 Docker 이미지입니다. 이미지를 가져오는 데 계정, 로그인 또는 상용 Overleaf 라이선스가 필요하지 않습니다.

`config/overleaf.rc`를 열고 다음을 설정하세요.

```bash title="config/overleaf.rc"
SERVER_PRO=true
```

다음에 `bin/up`을 실행하면 Toolkit은 공식 Overleaf Community Edition 대신 `config/version`에 있는 버전의 `ghcr.io/ayaka-notes/overleaf-pro`를 가져옵니다.

이미지는 `arm64`와 `amd64`용으로 빌드되며, Docker가 Docker 엔진 아키텍처에 맞는 이미지를 선택합니다.
