<Steps>
<Step title="명령줄 도구 설치">
0단계에서 만든 Linux 비밀번호를 사용하여 **Ubuntu**에서 실행하세요.

```bash
sudo apt update
sudo apt install -y git ca-certificates curl perl gawk openssl
```

Ubuntu에는 이미 Bash, GNU sed, coreutils가 포함되어 있습니다. macOS와 달리 Homebrew나 별도의 GNU sed 설치가 필요하지 않습니다.
</Step>

<Step title="Ayakaleaf Toolkit 저장소 복제">
Toolkit과 데이터를 Ubuntu의 Linux 파일 시스템, 즉 홈 디렉터리 아래에 두세요.

```bash
cd "$HOME"
git clone https://github.com/ayaka-notes/toolkit.git "$HOME/ayakaleaf-toolkit"
cd "$HOME/ayakaleaf-toolkit"
```

실제 데이터베이스와 프로젝트 데이터에는 `/mnt/c`, `/mnt/d`, OneDrive, 임시 디렉터리를 사용하지 마세요. Linux 파일 시스템 경로는 컨테이너가 기대하는 권한과 파일 시스템 동작을 제공하며, 파일 시스템 간 오버헤드를 피할 수 있습니다. [Microsoft의 파일 시스템 안내](https://learn.microsoft.com/en-us/windows/wsl/filesystems)를 참조하세요.

<Warning>

디렉터리에 이미 설치가 있다면 그대로 사용하거나, 새 인스턴스를 위한 다른 디렉터리를 선택하세요. 기존 배포의 구성이나 데이터를 교체하지 마세요.

</Warning>
</Step>
</Steps>
