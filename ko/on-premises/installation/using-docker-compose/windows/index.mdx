이 섹션에서는 WSL 2, Ubuntu, Docker Desktop, [Ayakaleaf Toolkit](https://github.com/ayaka-notes/toolkit)을 사용하여 Windows에서 Ayakaleaf Pro를 로컬로 실행합니다. 이 가이드는 `http://localhost:8080`을 사용하고, 데이터를 Ubuntu의 홈 디렉터리에 보관하며, Sandboxed Compiles를 활성화합니다.

애플리케이션, MongoDB, Redis, TeX Live는 Docker Desktop이 관리하는 Linux 컨테이너에서 실행됩니다. Toolkit 명령은 Ubuntu에서 실행하고, 애플리케이션은 Windows 브라우저에서 엽니다. [0단계](/ko/on-premises/installation/using-docker-compose/windows/0.-setup-wsl-and-docker-desktop)에서는 Windows와 Linux 부분이 어떻게 맞물리는지 설명하고 WSL 설치부터 시작합니다.

Windows는 로컬 인스턴스용으로 사용하거나, 6단계의 가용성 설정을 통해 계속 실행할 수 있습니다. 공유 서버 및 프로덕션 서버에는 HTTPS, 백업, 접근 제어를 갖춘 [Linux 가이드](/ko/on-premises/installation/using-docker-compose/linux)를 권장합니다. Windows 절전, Docker Desktop 종료, WSL 종료는 이 로컬 인스턴스를 중단시킵니다. [인스턴스 가용성 유지](/ko/on-premises/installation/using-docker-compose/windows/6.-post-installation-tasks#keep-the-instance-available)를 참조하세요.

## 시작하기 전에 {#before-you-start}

다음이 필요합니다.

* 하드웨어 가상화가 활성화된, [Docker Desktop for Windows](https://docs.docker.com/desktop/setup/install/windows-install/)에서 지원하는 Windows 버전과 프로세서. 이 가이드는 x86-64의 Windows 11을 사용합니다.
* WSL을 활성화하고 소프트웨어를 설치할 수 있는 권한. WSL은 2.1.5 이상이어야 하며, Ubuntu가 WSL 2 모드로 실행되어야 합니다.
* Windows와 컨테이너를 위한 충분한 메모리. 소규모 로컬 인스턴스라면 Docker에서 사용할 수 있는 CPU 4개와 메모리 8 GB가 권장 시작점이며, 측정된 최소 요구 사항이 아닙니다.
* WSL 및 Docker 데이터가 있는 Windows 디스크의 여유 저장 공간. 전체 TeX Live 설정과 프로젝트 데이터를 위해 최소 40 GB를 확보하세요. [5단계](/ko/on-premises/installation/using-docker-compose/windows/5.-personalizing-your-instance)의 basic 이미지는 더 작으며 초기 배포 테스트에 적합합니다. 이미지 버전을 추가하면 공간이 더 필요합니다.
* Toolkit을 복제하고 이미지를 다운로드하기 위한 GitHub, GitHub Container Registry(`ghcr.io`), Docker Hub에 대한 네트워크 접근.

**PowerShell** 블록은 Windows에서 실행합니다. **Bash** 블록과 `bin/` 명령은 별도로 언급하지 않는 한 Ubuntu에서 실행합니다. Toolkit 스크립트를 PowerShell이나 Windows Git Bash에서 실행하지 마세요.
