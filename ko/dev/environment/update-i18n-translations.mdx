---
title: i18n 번역 업데이트
icon: language
---

`services/web/frontend/extracted-translations.json` 파일이 있으며, Overleaf web은 이 파일에 추출된 번역만 사용합니다.

콘텐츠를 추가했다면 다음 명령을 실행하여 추출된 번역을 업데이트하세요.

```bash
user ➜ ~/overleaf-pro/develop (server-pro) $ bin/shell webpack
root@432836260f8a:/overleaf/services/web# npm run extract-translations
```

일반적으로 번역 텍스트 파일은 직접 편집하지 말고 기존 번역을 우선 사용하세요. 이 파일들은 모두 Overleaf 업스트림 또는 서드파티 번역 사이트에서 업데이트되기 때문입니다.
