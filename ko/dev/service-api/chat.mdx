프로젝트 채팅과 댓글 스레드(메시지와 해결 상태)를 Mongo의 `rooms` 및 `messages` 컬렉션에 저장합니다. web이 `ChatApiHandler`를 통해 호출합니다.

* <strong>주소:</strong> `http://chat:3010`, Docker 네트워크 내부
* <strong>인증:</strong> 없음
* <strong>OpenAPI 파일:</strong> [`develop/hoppscotch/openapi/chat.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/chat.yaml)
