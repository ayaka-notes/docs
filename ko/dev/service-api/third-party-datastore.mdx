프로젝트를 Dropbox와 동기화합니다. 사용자마다 하나의 Redis 작업 대기열과, Overleaf 변경을 Dropbox로 보내고 Dropbox의 변경을 폴링하는 워커를 둡니다. web만 호출하며, 작업을 대기열에 넣고 대기열 크기를 읽는 데 사용합니다.

* <strong>주소:</strong> `http://third-party-datastore:3002`, Docker 네트워크 내부
* <strong>인증:</strong> 없음
* <strong>OpenAPI 파일:</strong> [`develop/hoppscotch/openapi/third-party-datastore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/third-party-datastore.yaml)
