모든 프로젝트의 전체 기록을 저장합니다. 변경 청크는 Mongo 또는 Postgres와 객체 스토리지에, 파일 내용은 blob으로 저장합니다. project-history가 변경을 기록하고, web, project-history, git-bridge가 blob, 스냅샷, zip을 읽습니다.

* <strong>주소:</strong> `http://history-v1:3100`, Docker 네트워크 내부
* <strong>인증:</strong> 경로에 따라 `STAGING_PASSWORD`를 사용한 `staging` 계정의 HTTP 기본 인증 또는 JWT.
* <strong>OpenAPI 파일:</strong> [`develop/hoppscotch/openapi/history-v1.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/history-v1.yaml)
