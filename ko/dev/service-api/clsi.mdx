CLSI(Common LaTeX Service Interface)는 프로젝트를 컴파일하고, 컴파일 출력에 SyncTeX와 texcount를 실행하며, pandoc으로 문서를 변환합니다. web이 호출하며, 출력 파일 자체는 이 포트가 아니라 clsi-nginx가 제공합니다. 인증이 없으며 Docker 네트워크 내부에서만 접근할 수 있습니다.

* <strong>주소:</strong> `http://clsi:3013`, Docker 네트워크 내부
* <strong>인증:</strong> 없음
* <strong>OpenAPI 파일:</strong> [`develop/hoppscotch/openapi/clsi.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/clsi.yaml)
