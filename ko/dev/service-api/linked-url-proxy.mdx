web을 위해 외부 URL을 가져와 응답을 스트리밍으로 돌려주며, 사용자가 Docker 네트워크에 접근하지 못하도록 내부 주소를 거부합니다. web은 URL 파일, Open in Overleaf 가져오기, AI 에이전트의 web_fetch를 이 서비스를 통해 보냅니다.

* <strong>주소:</strong> `http://linked-url-proxy:3066`, Docker 네트워크 내부
* <strong>인증:</strong> 없음
* <strong>OpenAPI 파일:</strong> [`develop/hoppscotch/openapi/linked-url-proxy.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/linked-url-proxy.yaml)
