프로젝트 목록에서 사용자에게 표시되는 알림(예: 프로젝트 초대)을 Mongo의 `notifications` 컬렉션에 저장합니다. web과 third-party-datastore가 호출하며, 인증이 없고 Docker 네트워크 내부에서만 접근할 수 있습니다.

* <strong>주소:</strong> `http://notifications:3042`, Docker 네트워크 내부
* <strong>인증:</strong> 없음
* <strong>OpenAPI 파일:</strong> [`develop/hoppscotch/openapi/notifications.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/notifications.yaml)
