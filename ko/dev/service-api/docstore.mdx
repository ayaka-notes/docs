title: docstore
icon: database
---

모든 프로젝트의 모든 문서(줄, 버전, 범위)를 Mongo의 `docs` 컬렉션에 저장하고, 백엔드가 설정되어 있으면 문서를 객체 스토리지에 보관합니다. web이 호출하며, document-updater는 web을 거쳐 접근합니다.

* <strong>주소:</strong> `http://docstore:3016`, Docker 네트워크 내부
* <strong>인증:</strong> 없음
* <strong>OpenAPI 파일:</strong> [`develop/hoppscotch/openapi/docstore.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/docstore.yaml)
