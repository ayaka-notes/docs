Overleaf 메인 앱인 web의 비공개 API입니다. 다른 서비스(real-time, document-updater, project-history, third-party-datastore, git-bridge)와 Server CE 이미지의 cron 스크립트가 호출합니다. 이 경로에는 HTTP 기본 인증만 필요하고 CSRF 토큰은 필요 없습니다. 비공개 라우터가 web 라우터보다 먼저 마운트되며, CSRF 검사는 web 라우터만 수행하기 때문입니다. `BLOCK_CROSS_ORIGIN_REQUESTS=true`(기본값은 꺼짐)이면 web은 `Origin` 헤더가 `ALLOWED_ORIGINS`(기본값: 사이트 URL)에 없는 모든 요청에 403을 반환합니다. 브라우저는 POST에 `Origin`을 보내므로, 이 설정을 켜면 브라우저의 Hoppscotch에서 보낸 POST는 Hoppscotch 프록시를 거치지 않는 한 403을 받습니다.

* <strong>주소:</strong> `http://web:3000`, Docker 네트워크 내부
* <strong>인증:</strong> status, health, metrics를 제외하고 `WEB_API_USER` 및 `WEB_API_PASSWORD`를 사용한 HTTP 기본 인증. git-bridge 경로는 대신 개인 액세스 토큰을 사용합니다.
* <strong>OpenAPI 파일:</strong> [`develop/hoppscotch/openapi/web.yaml`](https://github.com/ayaka-notes/ayakaleaf-pro/blob/server-pro/develop/hoppscotch/openapi/web.yaml)
