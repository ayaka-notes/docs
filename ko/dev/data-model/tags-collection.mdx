`tags` 는 사용자가 프로젝트 대시보드에서 프로젝트를 분류하는 태그(폴더)를 보관합니다. 문서 하나는 한 사용자의 태그 하나입니다. `web`이 소유하며, 스키마는 `services/web/app/src/models/Tag.mjs`이고 모든 쓰기는 `services/web/app/src/Features/Tags/TagsHandler.mjs`를 거칩니다.

#### 필드 {#fields}

| 필드 | 타입 | 의미 | 출처 |
| --- | --- | --- | --- |
| `_id` | ObjectId | 태그 id로, `/tag/:tagId` 라우트에서 사용됩니다. | `Tag.mjs:10` |
| `user_id` | String | 태그의 소유자입니다. 레거시 이유로 ObjectId가 아닌 일반 문자열입니다. | `Tag.mjs:7-12` |
| `name` | String | 태그 이름으로, 최대 50자(`MAX_TAG_LENGTH`)입니다. 사용자별로 고유합니다. | `Tag.mjs:13`, `TagsHandler.mjs:4` |
| `color` | String | 선택 색상: `#a1b2c3` 같은 16진수 코드 또는 `hsl(<n>, 70%, 45%)` 값(`TAG_COLOR_REGEX`). | `Tag.mjs:5`, `Tag.mjs:14-22` |
| `project_ids` | Array of String | 이 태그에 속한 프로젝트의 id(문자열). | `Tag.mjs:23` |
| `__v` | Number | Mongoose 버전 키로, `Tag.create`가 문서를 만들 때 추가됩니다. | `TagsHandler.mjs:27` |

#### 인덱스 {#indexes}

| 이름 | 키 | 옵션 | 마이그레이션 |
| --- | --- | --- | --- |
| `user_id_1_name_1` | `{ user_id: 1, name: 1 }` | unique | `tools/migrations/20190912145029_create_tags_indexes.mjs` |

같은 마이그레이션이 `user_id_1`도 만들었지만, 복합 인덱스가 이를 포함하므로 `tools/migrations/20231031164732_drop_redundant_indexes.mjs`가 다시 삭제합니다.

#### 참고 {#notes}

* 태그는 사용자별입니다. 같은 프로젝트의 두 공동 작업자는 각자 자신의 태그를 유지합니다.
* `user_id`와 `project_ids`는 문자열이므로 ObjectId가 아닌 문자열 id로 쿼리하세요.
* 사용자 삭제(`services/web/app/src/Features/User/UserDeleter.mjs`)는 `tags`를 건드리지 않습니다.
