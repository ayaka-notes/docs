`users`는 계정마다 문서 하나를 보관합니다. 로그인 데이터, 프로필, 편집기 설정, 기능, 활동을 저장합니다. 스키마는 `services/web/app/src/models/User.mjs`이며, 대부분의 쓰기는 `services/web/app/src/Features/User/UserUpdater.mjs`를 거칩니다. 출처 열에서 `User.mjs:N`은 이 스키마의 줄이고, 경로가 없는 다른 파일 이름은 `services/web/app/src/Features/` 아래에, `modules/...`는 `services/web/` 아래에 있습니다. 줄 번호는 작성 시점의 `server-pro` 기준입니다.

#### 기능 플래그 및 제한 (`features`) {#feature-flags-&-limits-features}

`features`는 계산 결과이며 직접 편집하는 값이 아닙니다. `FeaturesUpdater`는 `Settings.defaultFeatures`에서 시작해 만료되지 않은 모든 `featuresOverrides` 항목을 병합하고, 결과를 `featuresUpdatedAt`과 함께 씁니다(`FeaturesUpdater.mjs:220-300`, `UserFeaturesUpdater.mjs:10-24`). 프로덕션 이미지는 `collaborators`, `dropbox`, `versioning`, `compileTimeout`, `compileGroup`, `trackChanges`, `references`를 기본값으로 설정하며(`server-ce/config/settings.js:301-309`), 나머지 키는 설정되지 않은 상태로 둡니다.

Ayakaleaf Pro에서는 관리자 패널이 사용자별로 기능을 끕니다. `admin-tools` 모듈은 이를 `note: 'admin-panel'`이 있는 `featuresOverrides` 항목으로 저장하고(`modules/admin-tools/app/src/AdminFeatures.mjs:13-30`), `instance-features` 모듈은 설정되지 않은 키를 켜진 것으로 처리합니다(`modules/instance-features/app/src/UserFeatures.mjs:12-14`).
