`User`는 Overleaf 시스템의 단일 사용자 계정을 나타냅니다. 인증 데이터, 기능 플래그, 에디터 환경설정, 접근 권한 및 활동 메타데이터를 저장합니다.

#### 핵심 신원 정보 및 인증

* `_id`: 사용자의 고유 MongoDB ObjectId입니다.
* `email` / `emails`: 기본 이메일 및 과거 이메일 기록입니다.
* `hashedPassword`: 로컬 인증에 사용되는 BCrypt 해시 비밀번호입니다.
* `first_name` / `last_name`: 사용자 프로필 이름 필드입니다.
* `role` / `isAdmin` / `adminRoles`: 역할 및 관리자 권한 플래그입니다.
* `twoFactorAuthentication`: 2단계 인증 구성입니다(활성화된 경우).
* `samlIdentifiers` / `thirdPartyIdentifiers`: 외부 ID 공급자 연결 정보입니다.

#### 계정 상태 및 수명 주기

* `signUpDate`: 계정 생성 타임스탬프입니다.
* `holdingAccount`: 계정이 확인 대기 중이거나 제한된 상태인지 여부입니다.
* `must_reconfirm`: 사용자가 이메일을 다시 확인해야 하는지 여부를 나타냅니다.
* `lastPrimaryEmailCheck`: 기본 이메일이 마지막으로 검증된 시각입니다.

#### 로그인 및 활동 추적

* `lastLoginIp`: 마지막으로 성공한 로그인의 IP 주소입니다.
* `loginCount`: 성공한 로그인의 총 횟수입니다.
* `loginEpoch`: 로그인 세션용 내부 카운터입니다.
* `lastLoggedIn`: 마지막 로그인 타임스탬프입니다.
* `lastActive`: 마지막으로 기록된 활동의 타임스탬프입니다.
* `lastFailedLogin`: 마지막 로그인 실패 시도의 타임스탬프입니다.

#### 에디터 환경설정(`ace`)

온라인 에디터에 대한 사용자 환경설정을 정의합니다.

* `theme` / `overallTheme`: 에디터 및 UI 테마입니다.
* `fontSize`: 에디터 글꼴 크기입니다.
* `autoComplete`, `autoPairDelimiters`: 편집 보조 기능입니다.
* `spellCheckLanguage`: 맞춤법 검사에 사용되는 언어입니다.
* `pdfViewer`: 선택된 PDF 뷰어 백엔드입니다.
* `syntaxValidation`, `mathPreview`, `breadcrumbs`: 에디터 UX 기능입니다.
* `enableNewEditor`: 새 에디터 UI의 활성화 여부입니다.

#### 기능 플래그 및 제한(`features`)

사용자가 이용할 수 있는 기능을 제어합니다.

* `collaborators`: 최대 공동 작업자 수입니다(`-1` = 무제한).
* `versioning`, `trackChanges`: 기록 및 변경 내용 추적 기능입니다.
* `dropbox`, `github`, `gitBridge`: 외부 연동 사용 가능 여부입니다.
* `compileTimeout`: 최대 컴파일 시간(초)입니다.
* `compileGroup`: 할당된 컴파일 리소스 그룹입니다.
* `aiErrorAssistant`: AI 기반 컴파일 오류 도우미 플래그입니다.

#### 접근 제어 및 스태프 권한(`staffAccess`)

스태프 또는 퍼블리셔의 세분화된 접근 권한을 정의합니다.

* 퍼블리셔, 기관, 그룹, 관리자 및 실험에 대한 지표 및 관리 권한입니다.

#### 등록 및 연동

* `enrollment.sso`: 연결된 SSO 등록 정보입니다.
* `refProviders`: 참고 문헌 공급자 연동입니다.
* `writefull`: Writefull 글쓰기 도우미 계정 상태입니다.
* `dsMobileApp`: 모바일 앱 구성입니다(있는 경우).

#### 프로그램 및 실험

* `alphaProgram` / `betaProgram` / `labsProgram`: 얼리 액세스 프로그램 참여 여부입니다.
* `labsExperiments`: 활성화된 실험적 기능입니다.
* `awareOfV2`: 사용자가 V2 에디터를 확인했는지 여부입니다.

#### 추천 및 튜토리얼

* `referal_id`, `refered_users`, `refered_user_count`: 추천 추적 정보입니다.
* `completedTutorials`: 온보딩 및 기능 튜토리얼 진행 상황입니다.
