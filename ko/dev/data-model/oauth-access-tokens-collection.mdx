`oauthAccessTokens`에는 web이 받아들이는 bearer 토큰이 저장됩니다. Ayakaleaf Pro에서는 사용자가 계정 설정 페이지에서 만들어 git-bridge와 MCP 엔드포인트에 사용하는 개인 액세스 토큰(Git 인증 토큰)입니다. 문서 하나가 토큰 하나입니다. 스키마는 `services/web/app/src/models/OauthAccessToken.mjs`이며, web 모듈 `oauth2-server`가 주로 네이티브 드라이버로 컬렉션에 씁니다.

#### 참고 {#notes}

* 사용자를 삭제해도 그 토큰은 삭제되지 않습니다. `UserDeleter`가 `cleanupPersonalAccessTokens` 훅을 실행하지만(`services/web/app/src/Features/User/UserDeleter.mjs:230-234`), 이를 수신하는 모듈은 없습니다. 사용자가 없으므로 두 토큰 검사 모두 토큰을 거부하고, TTL 인덱스가 `accessTokenExpiresAt` 하루 뒤에 제거합니다.
* 사용자를 정지하면 세션만 종료됩니다. 토큰은 남아 있으며, `users.suspended`가 `true`인 동안 두 토큰 검사 모두 이를 거부합니다(`OAuth2Model.mjs:51-54`, `OAuthPersonalAccessTokenManager.mjs:129-134`).
