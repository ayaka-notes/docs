title: Project History Labels 컬렉션

`projectHistoryLabels`에는 사용자가 기록 보기에서 버전에 붙인 라벨이 라벨마다 문서 하나로 저장됩니다. project-history가 소유하며 `services/project-history/app/js/LabelsManager.js`에서 씁니다. Mongoose 스키마는 없습니다. Web은 project-history API를 통해서만 접근합니다.

#### 필드 {#fields}

| 필드 | 타입 | 의미 | 출처 |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | 라벨 ID. | `LabelsManager.js:81-85` |
| `project_id` | ObjectId | 프로젝트. | `LabelsManager.js:73` |
| `comment` | String | 라벨 텍스트. | `LabelsManager.js:74` |
| `version` | Number | 라벨이 가리키는 프로젝트 기록 버전. | `LabelsManager.js:75` |
| `created_at` | Date | 라벨을 만든 시각. 요청에서 자체 시각을 전달할 수 있으며, 그렇지 않으면 현재 시각입니다. | `LabelsManager.js:70`, `76` |
| `user_id` | ObjectId | 라벨을 만든 사용자. 요청에 사용자가 없으면 생략됩니다. | `LabelsManager.js:78-80` |

#### 쓰는 곳 {#who-writes-it}

| 코드 | 하는 일 |
| ---- | ------------ |
| `services/project-history/app/js/LabelsManager.js:44-90` | `createLabel`: 라벨을 삽입합니다. project-history `POST /project/:project_id/labels`용입니다(`services/project-history/app/js/HttpController.js:1134-1171`). 사용자가 라벨을 추가하면 Web이 사용자 ID와 함께 호출합니다(`services/web/app/src/Features/History/HistoryController.mjs:529-546`). |
| `LabelsManager.js:113-126` | `deleteLabel`: 프로젝트의 라벨을 삭제합니다. `DELETE /project/:project_id/labels/:label_id`용입니다. 프로젝트 소유자가 라벨을 삭제할 때 Web이 사용합니다(`HistoryController.mjs:649-670`). |
| `LabelsManager.js:92-111` | `deleteLabelForUser`: 사용자가 만든 라벨인 경우에만 삭제합니다. `DELETE /project/:project_id/user/:user_id/labels/:label_id`용입니다. 그 밖의 모든 사용자에게 Web이 이것을 사용합니다. |
| `LabelsManager.js:128-143` | `transferLabels`: 한 사용자의 모든 라벨을 다른 사용자에게 옮깁니다. `POST /user/:from_user/labels/transfer/:to_user`용입니다(`services/project-history/app/js/Router.js:52-55`). Web에는 이 경로를 호출하는 코드가 없습니다. |
| `LabelsManager.js:7-25` | `cloneLabels`: 프로젝트의 라벨을 다른 프로젝트로 복사합니다. project-history `POST /project/:project_id/clone`용이며(`HttpController.js:113`), Web에는 이를 호출하는 코드가 없습니다. |

#### 읽는 곳 {#who-reads-it}

| 코드 | 하는 일 |
| ---- | ------------ |
| `LabelsManager.js:27-42` | `getLabels`: 프로젝트의 모든 라벨을 `{ id, comment, version, user_id, created_at }` 형태로 반환합니다(`LabelsManager.js:163-171`). `GET /project/:project_id/labels`에서 사용하며(`HttpController.js:1076-1100`), Web은 기록 보기를 위해 이를 호출하고 사용자 이름을 채웁니다(`HistoryController.mjs:488-499`). |
| `services/project-history/app/js/SummarizedUpdatesManager.js:57` | 라벨을 기록 업데이트 목록에 추가합니다. |

#### 참고 {#notes}

* 라벨을 삽입하기 전에 project-history는 프로젝트의 대기 중인 업데이트를 처리하고, history-v1에 해당 버전의 chunk가 있는지 확인합니다. 단, 요청이 `validate_exists: false`를 보내면 확인하지 않습니다(`LabelsManager.js:53-59`, `173-195`; `HttpController.js:1109-1115`).
* 프로젝트가 삭제되어도 라벨을 삭제하는 코드는 없습니다. project-history `DELETE /project/:project_id`는 동기화 상태와 실패 기록만 지우며(`HttpController.js:1363-1396`), 다른 서비스는 이 컬렉션을 건드리지 않습니다.
