`rooms`에는 프로젝트의 채팅방마다 문서 하나가 저장됩니다. 프로젝트 채팅이거나 리뷰 댓글 스레드 하나입니다. chat 서비스만 이 컬렉션에 쓰며, `services/chat/app/js/Features/Threads/ThreadManager.js`에서 씁니다. Mongoose 스키마는 없습니다. 방의 메시지는 [messages](/ko/dev/data-model/messages-collection) 컬렉션에 있습니다.

#### 필드 {#fields}

| 필드 | 타입 | 의미 | 출처 |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | 방 ID. `messages.room_id`가 여기를 가리킵니다. | `ThreadManager.js:57-61` |
| `project_id` | ObjectId | 방이 속한 프로젝트. | `ThreadManager.js:43-54` |
| `thread_id` | ObjectId | 댓글 스레드에만 있습니다. 댓글의 ID로, `docs.ranges.comments`에 있는 해당 댓글의 `id` 및 `op.t`와 같습니다([docs](/ko/dev/data-model/docs-collection) 참고). 프로젝트 채팅방에는 없습니다. | `ThreadManager.js:38-55`, `services/docstore/app/js/RangeManager.js:54-57` |
| `resolved` | Object | 스레드가 해결되면 설정되고 다시 열리면 제거됩니다. 이 필드가 없는 스레드는 열린 상태입니다. | `ThreadManager.js:94-123` |
| `resolved.user_id` | String | 스레드를 해결한 사용자의 ID. ObjectId가 아니라 문자열로 저장됩니다. 요청 본문은 유효한 ID인지만 확인하고 변환하지 않습니다. | `ThreadManager.js:103`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:70` |
| `resolved.ts` | Date | 스레드가 해결된 시각. | `ThreadManager.js:104` |

#### 참고 {#notes}

* 프로젝트에는 `thread_id`가 없는 방이 최대 하나 있으며, 이것이 프로젝트 채팅입니다. chat 서비스는 `thread_id: { $exists: false }`로 이를 찾습니다(`ThreadManager.js:38-45`).
* 댓글의 해결 상태는 여기에만 있습니다. Docstore는 범위를 저장하기 전에 `op.resolved`를 제거합니다(`services/docstore/app/js/RangeManager.js:59-61`).
* 프로젝트를 복사하면 같은 `thread_id`가 두 프로젝트에 존재합니다. chat 서비스처럼 항상 `project_id`와 `thread_id`를 함께 사용해 조회하세요.
* 삭제된 프로젝트의 방은 그 프로젝트가 만료될 때까지 남아 있습니다.
