`dropboxProjects`는 프로젝트를 한 사용자의 Dropbox에 있는 폴더에 연결합니다. 여러 Dropbox 사용자와 공유된 프로젝트는 사용자마다 문서가 하나씩 있습니다. 이 컬렉션은 Dropbox 동기화에 속합니다. third-party-datastore(`services/third-party-datastore/app/js/StateManager.mjs`)가 쓰고, `dropbox` 웹 모듈(`services/web/modules/dropbox/app/src/DropboxHandler.mjs`)이 읽고 비웁니다. Mongoose 스키마는 없습니다.

#### 필드 {#fields}

| 필드 | 타입 | 의미 | 출처 |
| ---- | ---- | ---- | ---- |
| `_id` | ObjectId | 삽입 시 드라이버가 설정합니다. | `StateManager.mjs:144` |
| `userId` | ObjectId | 폴더가 있는 Dropbox의 Overleaf 사용자입니다. | `StateManager.mjs:145` |
| `projectId` | ObjectId | 폴더로 동기화되는 프로젝트입니다. | `StateManager.mjs:146` |
| `dropboxId` | String | Dropbox 폴더 메타데이터에 있는 폴더의 `id`입니다. | `StateManager.mjs:147`, `JobProcessor.mjs:82-87`, `PullManager.mjs:138` |
| `pathLower` | String | Dropbox에서의 폴더 경로로, 소문자이며 끝에 슬래시가 없습니다. 프로젝트 폴더는 최상위에 프로젝트마다 하나씩 있습니다. 예를 들어 Dropbox가 다른 프로젝트의 `Thesis` 옆에서 번호를 붙였다면 `/thesis (1)`입니다. | `StateManager.mjs:14-16,148`, `PullManager.mjs:112-117` |

CE에는 여기에 다른 인덱스가 없습니다. 고유 인덱스 `projectId_userId_1`과 `userId_dropboxId_1`은 `tools/migrations/20220815105500_create_dropboxProjects_index.mjs`와 `20220817120900_create_dropboxProjects_index.mjs`에서 만들어지는데, 이 마이그레이션에는 `saas` 태그만 있어 CE는 이를 실행하지 않습니다.

#### 참고 {#notes}

* 고유성은 `setProjectFolder`에서 삽입할 때마다 먼저 수행하는 삭제로만 유지됩니다(`StateManager.mjs:140-149`). `StateManager.mjs:3-11`의 주석은 고유 인덱스를 언급하지만 CE에는 없습니다.
* 프로젝트의 연결이 제거되어도 폴더는 Dropbox에 남습니다. 그곳에서의 편집은 Dropbox에서 만든 폴더처럼 새 프로젝트로 읽힙니다(`DropboxHandler.mjs:148-149`).
* 삭제된 프로젝트는 아직 복원할 수 있으므로 만료될 때까지 연결을 유지합니다(`index.mjs:52-53`).
* 사용자의 Dropbox `list_folder` 커서는 여기에 없습니다. `users.dropbox.cursor`에 있습니다(`StateManager.mjs:177-184`).
