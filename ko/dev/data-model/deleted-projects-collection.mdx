title: Deleted Projects 컬렉션
icon: trash-can
---

`deletedProjects`는 삭제된 프로젝트를 보관합니다. 삭제된 프로젝트마다 문서 하나가 있으며, 전체 프로젝트 문서의 사본과 삭제한 사람이 담깁니다. Web이 `services/web/app/src/Features/Project/ProjectDeleter.mjs`에서 쓰며, 스키마는 `services/web/app/src/models/DeletedProject.mjs`입니다. 영구 삭제 지연 시간이 지나면 만료 처리가 프로젝트 데이터를 파기하고 `project`를 비우지만, `deleterData`가 있는 레코드는 남습니다.

휴지통에 있는 프로젝트는 여기에 없습니다. 휴지통으로 옮기면 프로젝트의 `trashed`에 사용자가 추가될 뿐입니다. [Projects 컬렉션](/ko/dev/data-model/projects-collection)을 참고하세요.

#### 쓰는 코드 {#who-writes-it}

| 코드 | 역할 |
| ---- | ------------ |
| `ProjectDeleter.mjs:189-293`(`deleteProject`) | 프로젝트를 플러시하고, 해당 doc을 Mongo 밖으로 보관(아카이브)하며, 태그에서 제거하고, 레코드를 upsert한 뒤 `projects` 문서를 삭제합니다. |
| `ProjectDeleter.mjs:295-342`(`undeleteProject`) | 프로젝트를 `<name> (Restored)`라는 이름(소유자 기준으로 고유하게 만든 이름)으로, 보관되지 않은 상태로 다시 삽입한 뒤 레코드를 삭제합니다. `project`가 `null`이 되면 `project_too_old_to_restore`로 실패합니다. 관리자 패널에서 호출됩니다. 프로젝트 하나 복원(`AdminProjectManager.mjs:497-515`), 또는 삭제된 사용자와 계정과 함께 삭제된 프로젝트 복원(`services/web/modules/admin-tools/app/src/AdminUserManager.mjs:678-689`)입니다. |
| `ProjectDeleter.mjs:344-416`(`expireDeletedProject`) | 프로젝트의 doc, 기록, 채팅, 프로젝트 감사 로그를 파기하고 `projectExpired` 훅을 실행한 뒤, `project`와 `deleterData.deleterIpAddress`를 `null`로 설정합니다. 프로젝트가 다시 존재하면 오래된 레코드만 삭제합니다. |
| `ProjectDeleter.mjs:97-146`(`expireDeletedProjectsAfterDuration`) | 지연 시간보다 오래된 레코드를 묶어서 만료시킵니다. 라우트 `POST /internal/expire-deleted-projects-after-duration`(`services/web/app/src/router.mjs:842-846`)이며, `ENABLE_CRON_RESOURCE_DELETION`이 `true`이면 Community Edition cron이 매시 20분에 호출합니다(`server-ce/cron/delete-projects.sh:10-23`, `server-ce/config/crontab-deletion:3`). 프로젝트 하나: `POST /internal/project/:projectId/expire-deleted-project`(`router.mjs:852-856`) 또는 관리자 패널의 Purge(`AdminProjectManager.mjs:517-529`). |

#### 참고 {#notes}

* `projectExpired`를 수신하는 모듈은 해당 프로젝트에 대한 자체 데이터를 삭제합니다: `git-bridge`(`services/web/modules/git-bridge/index.mjs:37`), `github-sync`(`services/web/modules/github-sync/index.mjs:56`), `gitlab-sync`(`services/web/modules/gitlab-sync/index.mjs:46`), `gitea-sync`(`services/web/modules/gitea-sync/index.mjs:46`), `dropbox`(`services/web/modules/dropbox/index.mjs:54`).
* 만료된 레코드는 절대 삭제되지 않습니다. `deleterData`는 영구히 남고, `project`와 IP 주소만 비워집니다.
* Mongoose는 `deleterData`에도 자체 `_id`를 부여하지만, 이를 읽는 곳은 없습니다.
