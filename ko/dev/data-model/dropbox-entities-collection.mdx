`dropboxEntities`는 Dropbox 동기화가 프로젝트와 한 사용자의 Dropbox 사이에서 복사한 파일마다 문서 하나와, 잠깐 존재하는 tombstone을 담습니다. 이 컬렉션은 Dropbox 동기화에 속합니다. third-party-datastore(`services/third-party-datastore/app/js/StateManager.mjs`)가 쓰고 읽으며, `dropbox` 웹 모듈(`services/web/modules/dropbox/app/src/DropboxHandler.mjs`)이 비웁니다. Mongoose 스키마는 없습니다.

#### 참고 {#notes}

* 고유성은 `recordEntity`에서 삽입할 때마다 먼저 수행하는 삭제로만 유지됩니다(`StateManager.mjs:38-45`). `StateManager.mjs:3-11`의 주석은 고유 인덱스를 언급하지만 CE에는 없습니다.
* 사용자와 경로로 하는 쿼리(`findEntityByPath`, `findTombstone`, `removeEntities`)는 `overleaf.userId`에 대해서만 인덱스를 사용합니다.
