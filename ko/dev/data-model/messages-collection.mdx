title: Messages 컬렉션

---

`messages`에는 메시지마다 문서 하나가 저장됩니다. 프로젝트 채팅의 한 줄이거나, 리뷰 댓글 스레드의 댓글 또는 답글입니다. chat 서비스만 이 컬렉션에 쓰며, `services/chat/app/js/Features/Messages/MessageManager.js`에서 씁니다. Mongoose 스키마는 없습니다. 각 메시지는 [rooms](/ko/dev/data-model/rooms-collection) 컬렉션의 방에 속합니다.

#### 필드 {#fields}

| 필드 | 타입 | 의미 | 출처 |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | 메시지 ID. | `MessageManager.js:13-14` |
| `room_id` | ObjectId | 방(`rooms._id`)이며, 프로젝트 ID나 스레드 ID가 아닙니다. | `MessageManager.js:8,106-108` |
| `user_id` | ObjectId | 작성자. | `MessageManager.js:9,103-105` |
| `content` | String | 메시지 텍스트, 1~10240자(`MAX_MESSAGE_LENGTH`). | `MessageManager.js:7`, `services/chat/app/js/Features/Messages/MessageHttpSchemas.js:3,12-15` |
| `timestamp` | Number | 보낸 시각. 1970년부터의 밀리초(`Date.now()`)이며 Date가 아닙니다. | `MessageManager.js:10`, `services/chat/app/js/Features/Messages/MessageHttpController.js:288` |
| `edited_at` | Number | 마지막으로 편집한 시각(밀리초, `Date.now()`). 편집한 적이 없으면 없습니다. | `MessageManager.js:65-69`, `MessageHttpController.js:189,213` |

#### 쓰는 곳 {#who-writes-it}

| 코드 | 하는 일 |
| ---- | ------------ |
| `MessageManager.js:5-16` `createMessage` | 메시지를 삽입합니다(`MessageHttpController.js:275-294`). Web은 `services/web/app/src/Features/Chat/ChatController.mjs:32`에서 프로젝트 채팅 메시지를 보내고, track-changes 모듈(`services/web/modules/track-changes/app/src/TrackChangesController.mjs:95`)과 mcp-server 모듈(`services/web/modules/mcp-server/app/src/CommentTools.mjs:133`)에서 댓글을 보냅니다. |
| `MessageManager.js:51-72` `updateMessage` | `content`와 `edited_at`를 설정합니다. 사용자 ID가 주어지면 그 사용자의 메시지만 일치합니다(`MessageManager.js:62-64`). `ChatController.mjs:135`와 `TrackChangesController.mjs:110`에서 호출합니다. |
| `MessageManager.js:74-80` `deleteMessage` | 메시지 하나를 삭제합니다. `ChatController.mjs:105`와 `TrackChangesController.mjs:129`에서 호출합니다. |
| `MessageManager.js:39-49` `deleteAllMessagesInRoom(s)` | 삭제된 스레드의 메시지(`MessageHttpController.js:172-173`)를 삭제하거나, 삭제된 프로젝트가 만료될 때 프로젝트 전체의 메시지(`MessageHttpController.js:261-271`, `services/web/app/src/Features/Project/ProjectDeleter.mjs:391`에서 호출)를 삭제합니다. |
| `MessageManager.js:115-127` `duplicateRoomToOtherRoom` | 모든 메시지의 `content`, `timestamp`, `user_id`를 다른 방으로 복사하며 `edited_at`는 복사하지 않습니다. 기록 복원으로 스레드가 복제될 때(`MessageHttpController.js:316-342`)와 프로젝트를 범위와 함께 복사할 때(`MessageHttpController.js:344-357`) 사용합니다. |

#### 읽는 곳 {#who-reads-it}

| 코드 | 하는 일 |
| ---- | ------------ |
| `MessageManager.js:18-29` `getMessages` | 최신순으로, `before`(`timestamp` 값)보다 오래된 메시지를 최대 `limit`개(기본값 50) 반환합니다. 프로젝트 채팅에 사용합니다(`ChatController.mjs:80`). |
| `MessageManager.js:31-37` `findAllMessagesInRooms` | 여러 방의 모든 메시지로, 리뷰 패널의 스레드 목록(`TrackChangesController.mjs:82`), mcp-server 모듈(`CommentTools.mjs:83`), 기록 복원(`services/web/app/src/Features/History/RestoreManager.mjs:259`)에 사용합니다. Web은 리뷰어가 자신이 시작한 스레드만 변경할 수 있도록 스레드의 첫 메시지도 확인합니다(`services/web/app/src/Features/Authorization/AuthorizationManager.mjs:409-411`). |
| `MessageManager.js:90-100` `getMessage` | 메시지 하나. 사용자가 자신의 메시지를 편집하거나 삭제하기 전에 Web이 그 `user_id`를 확인합니다(`services/web/app/src/Features/Authorization/AuthorizationMiddleware.mjs:253-257`, `TrackChangesController.mjs:124-125`). |

#### 참고 {#notes}

* 댓글의 메시지를 찾으려면 먼저 `project_id`와 `thread_id`로 방을 찾은 다음 `room_id`로 조회하세요. 문서 안의 댓글 ID는 `thread_id`이며 `room_id`가 아닙니다.
* 댓글이 가리키는 텍스트는 `docs.ranges.comments`의 `op.c`이고, 토론 내용은 여기에 있습니다.
