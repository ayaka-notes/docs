---
title: System Messages 컬렉션
icon: bullhorn
---

`systemmessages` 는 관리자가 로그인한 모든 사용자에게 게시하는 사이트 전체 배너를 보관합니다. 문서 하나는 메시지 하나입니다. `web`이 소유하며, 스키마는 `services/web/app/src/models/SystemMessage.mjs`이고 코드는 `services/web/app/src/Features/SystemMessages/SystemMessageManager.mjs`입니다.

#### 필드 {#fields}

| 필드 | 타입 | 의미 | 출처 |
| --- | --- | --- | --- |
| `_id` | ObjectId | 메시지 id입니다. 브라우저는 이 id로 사용자가 닫은 메시지를 기억합니다(`services/web/frontend/js/shared/components/system-message.tsx:10`). | `SystemMessage.mjs:5` |
| `content` | String | 메시지 텍스트, 기본값 `''`. | `SystemMessage.mjs:7` |
| `__v` | Number | Mongoose 버전 키로, `message.save()`가 추가합니다. | `SystemMessageManager.mjs:29-30` |

#### 쓰는 코드 {#who-writes-it}

| 코드 | 하는 일 |
| --- | --- |
| `SystemMessageManager.mjs:28-33` (`createMessage`) | `POST /admin/messages` (`services/web/app/src/router.mjs:1150-1152`, `services/web/app/src/Features/ServerAdmin/AdminController.mjs:151-159`): 메시지 하나를 추가합니다. |
| `SystemMessageManager.mjs:22-26` (`clearMessages`) | `POST /admin/messages/clear` (`router.mjs:1155-1157`, `AdminController.mjs:161-168`): 모든 메시지를 삭제합니다. 하나만 삭제하는 방법은 없습니다. |

#### 읽는 코드 {#who-reads-it}

| 코드 | 하는 일 |
| --- | --- |
| `SystemMessageManager.mjs:50-65` | 각 `web` 프로세스는 모든 메시지를 메모리에 보관하고 20~30초마다, 그리고 자신이 생성하거나 비운 직후에 다시 불러옵니다. |
| `services/web/app/src/Features/SystemMessages/SystemMessageController.mjs:6-24` | `GET /system/messages` (`router.mjs:331`): 캐시된 메시지를 로그인한 사용자에게 반환합니다. 사이트가 닫혀 있는 동안(`siteIsOpen`이 false) 대신 고정된 안내를 반환하며, 이 안내는 Mongo에 저장되지 않습니다. |
| `AdminController.mjs:83-84` | `/admin` 페이지는 Mongo에서 직접 메시지를 나열합니다. |

#### 인덱스 {#indexes}

`systemmessages`에 인덱스를 만드는 마이그레이션은 없으며, 기본 `_id` 인덱스만 있습니다.

#### 참고 {#notes}

* `notifyOnSystemMessageChanges`가 설정되어 있으면 생성이나 비우기가 Redis 채널 `refresh-system-messages`에도 게시되어 다른 `web` 프로세스가 즉시 다시 불러옵니다(`SystemMessageManager.mjs:9`, `:35-48`, `:75-87`). 설정되지 않으면 다음 정기 재로드 때 변경 사항을 반영합니다.
