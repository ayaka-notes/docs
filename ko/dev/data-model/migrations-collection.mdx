`migrations` 는 어떤 데이터베이스 마이그레이션이 실행되었는지 기록합니다. 문서 하나는 `tools/migrations/`의 마이그레이션 하나입니다. 실행 중인 서비스가 아니라 마이그레이션 도구 [east](https://github.com/okv/east)의 어댑터 `tools/migrations/lib/adapter.mjs`가 기록합니다.

#### 필드 {#fields}

| 필드 | 타입 | 의미 | 출처 |
| --- | --- | --- | --- |
| `_id` | ObjectId | 문서 id. | `adapter.mjs:103` |
| `name` | String | 확장자를 뺀 마이그레이션 파일 이름. 예: `20190912145029_create_tags_indexes`. | `adapter.mjs:104` |
| `migratedAt` | Date | 마이그레이션이 끝난 시각. | `adapter.mjs:105` |

#### 쓰는 코드 {#who-writes-it}

| 코드 | 하는 일 |
| --- | --- |
| `adapter.mjs:101-107` (`markExecuted`) | 마이그레이션이 실행된 뒤 문서를 삽입합니다. |
| `adapter.mjs:109-114` (`unmarkExecuted`) | 마이그레이션이 롤백되면 문서를 다시 삭제합니다. |

CE는 컨테이너가 시작될 때마다 `yarn run migrations migrate -t server-ce`를 실행합니다(`server-ce/init_scripts/900_run_web_migrations.sh:4-12`, `OVERLEAF_IS_SERVER_PRO=true`이면 `-t server-pro`). `tags`에 해당 환경이 포함된 마이그레이션만 실행되므로 그것들만 여기에 문서가 생깁니다.

#### 읽는 코드 {#who-reads-it}

| 코드 | 하는 일 |
| --- | --- |
| `adapter.mjs:72-99` (`getExecutedMigrationNames`) | east는 이름이 이미 여기에 있는 마이그레이션을 모두 건너뜁니다. |
| `tools/migrations/lib/helpers.mjs:67-75` (`assertDependency`) | 다른 마이그레이션이 먼저 실행되어야 하는 마이그레이션은 그 이름이 없으면 오류를 던집니다. |

#### 인덱스 {#indexes}

| 이름 | 키 | 옵션 | 마이그레이션 |
| --- | --- | --- | --- |
| `name_1` | `{ name: 1 }` | unique | `tools/migrations/20190720165251_create_migrations.mjs` |

#### 참고 {#notes}

* 문서를 삭제하면 태그가 일치하는 경우 다음 컨테이너 시작 때 해당 마이그레이션이 다시 실행됩니다.
* 보조 Mongo 클러스터(`mongo.auxUrl`)가 있으면 `auxiliary` 태그가 붙은 마이그레이션은 대신 그 클러스터의 `migrations` 컬렉션에 기록됩니다(`adapter.mjs:8-15`, `:64-70`). `mongo.auxUrl`은 `MONGO_AUX_CONNECTION_STRING`(`tools/migrations/config/settings.defaults.js:19`)에서 오며, 기본적으로 설정되어 있지 않습니다.
