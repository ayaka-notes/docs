---
title: GitHub Sync User Credentials 컬렉션
icon: key
---

`githubSyncUserCredentials`는 GitHub Sync를 위해 GitHub 계정을 연결한 사용자마다 문서 하나를 보관합니다. 사용자의 OAuth 액세스 토큰을 암호화해 저장합니다. 이 컬렉션은 `github-sync` 웹 모듈(`services/web/modules/github-sync`)에 속합니다. 스키마는 `services/web/modules/github-sync/app/models/githubSyncUserCredentials.mjs`에 있으며, 모든 접근은 `services/web/modules/github-sync/app/src/TokenManager.mjs`를 거칩니다.

#### 필드 {#fields}

| 필드 | 타입 | 의미 | 출처 |
| ----- | ---- | ------- | ------ |
| `_id` | ObjectId | upsert가 삽입할 때 Mongoose가 설정합니다. | |
| `userId` | ObjectId | Overleaf 사용자. 필수. 스키마에는 `unique: true`가 있지만 인덱스는 만들어지지 않습니다(인덱스 참고). `userId` 기준 upsert가 사용자당 문서 하나를 유지합니다. | `githubSyncUserCredentials.mjs:8`, `TokenManager.mjs:44-48` |
| `github` | String | GitHub OAuth 액세스 토큰으로, `@overleaf/access-token-encryptor`로 암호화됩니다. 비밀번호는 `GITHUB_TOKEN_CIPHER_PASSWORD`에서 가져오고, 암호 레이블은 `GITHUB_TOKEN_CIPHER_LABEL`이며 기본값은 `2026.3-v3`입니다. 필수. | `githubSyncUserCredentials.mjs:9`, `TokenManager.mjs:12-25` |
| `__v` | Number | Mongoose 버전 키. 스키마에서 끄지 않습니다. | Mongoose 기본값 |

액세스 토큰만 저장됩니다. OAuth 콜백은 GitHub 응답에서 `access_token`만 보관합니다(`services/web/modules/github-sync/app/src/GitHubApiClient.mjs:180-191`). 리프레시 토큰이나 만료 시각은 없습니다.

#### 쓰는 코드 {#who-writes-it}

| 코드 | 역할 |
| ---- | ------------ |
| `TokenManager.mjs:42-58` (`saveUserToken`) | 사용자의 암호화된 토큰을 upsert합니다. 사용자가 다시 연결하면 교체된 토큰은 백그라운드에서 GitHub에서 취소됩니다. OAuth 콜백에서 호출됩니다(`services/web/modules/github-sync/app/src/GitHubSyncController.mjs:146`). |
| `TokenManager.mjs:61-76` (`removeUserToken`) | GitHub에서 토큰을 취소(최선의 노력)한 다음 문서를 삭제합니다. 연결 해제 시(`GitHubSyncController.mjs:167`)와 삭제된 사용자가 만료될 때(`services/web/modules/github-sync/index.mjs:66-68`) 호출됩니다. |

#### 읽는 코드 {#who-reads-it}

| 코드 | 역할 |
| ---- | ------------ |
| `TokenManager.mjs:36-40` (`getUserToken`) | GitHub API를 호출할 때마다 토큰을 복호화합니다: `services/web/modules/github-sync/app/src/GitHubSyncHandler.mjs`(예: `:27`)와 `services/web/modules/github-sync/app/src/GitMerge.mjs:43`. 문서가 없거나 토큰을 복호화할 수 없으면 `InvalidTokenError`를 던지고, 사용자는 연결되지 않은 것으로 간주됩니다(`GitHubSyncHandler.mjs:25-37`). |
| `services/web/modules/admin-tools/app/src/AdminUserListManager.mjs:393` | 관리자 패널에 표시되는 통합 기능을 위해 사용자에게 문서가 있는지 확인합니다. |

#### 인덱스 {#indexes}

| 이름 | 키 | 옵션 | 마이그레이션 |
| ---- | ---- | ------- | --------- |
| `_id_` | `_id: 1` | | default |

Mongoose `autoIndex`가 꺼져 있으므로(`services/web/app/src/infrastructure/Mongoose.mjs:7`), 스키마의 `userId`에 있는 `unique: true`는 아무것도 만들지 않습니다. `tools/migrations/20190912145011_create_githubSyncUserCredentials_indexes.mjs`(upstream의 `user_id`)는 `saas` 태그만 달려 있어 CE에서는 실행되지 않습니다.

#### 참고 {#notes}

* `GITHUB_TOKEN_CIPHER_PASSWORD`를 바꾸면 저장된 토큰을 읽을 수 없게 됩니다. 그러면 해당 사용자는 다시 연결할 때까지 연결되지 않은 것으로 간주됩니다.
* 삭제된 사용자는 만료될 때까지 문서를 유지합니다.
